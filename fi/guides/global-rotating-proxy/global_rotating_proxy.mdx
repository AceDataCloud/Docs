Tässä asiakirjassa esitellään Ace Data Cloudin globaalin agentin liittämisen ohjeet, mukaan lukien hakumenetelmät, käyttömenetelmät ja muita tarkkoja tietoja.

## Hakumenetelmät

Käyttääksesi globaaleja palveluja, voit ensin mennä "[hakusivulle](https://platform.acedata.cloud/services/87ae4a5a-59d9-4c50-86d4-c0b5d393e5af)" ja tehdä hakemuksen, ensimmäisessä hakemuksessa on 1 pisteen ilmainen käyttöoikeus.

![](https://cdn.acedata.cloud/cyzvmz.png)

Jos et ole vielä kirjautunut sisään, sinut ohjataan automaattisesti kirjautumissivulle, kirjaudu sisään ja jatka hakemista.

## Käyttömenetelmät

Hakemuksen jälkeen voit tarkistaa hakemustuloksesi "ohjauspaneelista", kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/y9boi5.png)

Napsauta "Credentials", niin voit tarkistaa globaalin agenttipalvelun käyttäjänimen ja salasanan, jotka on erotettu kaksoispisteellä, käyttäjänimi on 8 merkkiä ja salasana 32 merkkiä, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/ixwm85.png)

Tämä agentti on kiertävä agentti (Rotating Proxy), joten käytettäessä tarvitset vain asettaa kiinteä agenttiosoite ja portti, agentin osoite ja portti ovat `global.proxy.acedata.cloud` ja `30007`, tämä agentti on HTTP/HTTPS/SOCKS-protokollan agentti, jota voidaan käyttää HTTP- ja HTTPS-protokollan verkkosivustojen pyyntöihin.

> Huom: Tätä agenttia voidaan käyttää vain Kiinan ulkopuolella, Kiinan mantereella se ei ole käytettävissä.

## Komentotestaus

Kun sinulla on agentin käyttäjänimi ja salasana, helpoin tapa testata on käyttää curl-komentoriviä, jos et ole vielä asentanut, voit viitata [https://curl.se/](https://curl.se/) asennukseen.

Oletetaan, että nykyinen agentin käyttäjänimi ja salasana ovat `1f78266a:eff0896726224fa2a99fe82dd1f07562`, voimme testata seuraavalla curl-komennolla:

```shell
curl -x 1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```

Tässä käytämme curlin `-x`-parametria määrittämään agenttiosoitteen, agenttiprotokolla on oletuksena HTTP/HTTPS, tässä pyydetty URL on [https://ipinfo.io](https://ipinfo.io), tämä sivusto voi palauttaa pyynnön tehneen sivuston todellisen IP-osoitteen ja IP:n sijaintialueen.

> Huom: Edellä mainittu käyttäjänimi ja salasana voivat olla voimassa vain rajoitetusti, vaihda ne omiin käyttäjänimiisi ja salasanoihisi.

Tuloksen pitäisi olla seuraavanlainen:

```json
{
  "ip": "66.206.249.77",
  "hostname": "host-66-206-249-77.public.eastlink.ca",
  "city": "Kirkland Lake",
  "region": "Ontario",
  "country": "CA",
  "loc": "48.1446,-80.0377",
  "org": "AS11260 EastLink",
  "postal": "P2N",
  "timezone": "America/Toronto",
  "readme": "https://ipinfo.io/missingauth"

```

Voit nähdä, että palautetun tuloksen country on CA, mikä tarkoittaa Kanadaa. Jos suoritat sen uudelleen, saat erilaisen tuloksen, jokainen pyyntö on satunnainen IP-osoite.

## Koodiliitäntä

Alla on esimerkki Pythonista, joka näyttää agentin asetustavan:

```python
import requests

proxy = 'http://{proxy_username}:{proxy_password}@global.proxy.acedata.cloud:30007'

proxies = {
    'http': proxy,
    'https': proxy
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io', proxies=proxies)
    print(resp.text)
```

Tässä määrittelemme ensin agentin URL-osoitteen ja määrittelemme sen proxy-muuttujaksi, protokolla on http, ja sen jälkeen seuraa tunnelin agentin käyttäjänimi ja salasana (eli ohjauspaneelissa esitetyt käyttäjänimi ja salasana, erotettuna kaksoispisteellä), sitten tulee `@`-merkki, ja sen jälkeen agentin osoite ja portti.

> Huom: Sinun on vaihdettava yllä olevassa koodissa `{proxy_username}:{proxy_password}` omiin agentin käyttäjänimiisi ja salasanoihisi, lopullinen tulos on samanlainen kuin `proxy = 'http://1f78266a:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007'`, huomaa, ettei `{` ja `}` merkkejä ole.

Seuraavaksi määrittelemme proxies-muuttujan, joka sisältää kaksi avain-arvo-paria, avaimet ovat http ja https, ja niiden arvot ovat molemmat proxy, mikä tarkoittaa, että HTTP- ja HTTPS-protokollan verkkosivustoille käytetään proxy-muuttujaa pyyntöjen tekemiseen. Seuraavaksi määritellään kolme silmukkaa agentin testaukseen.

Tietenkin yllä oleva agentin asetustapa on itse asiassa suhteellisen yksinkertainen asetus.

Itse asiassa yllä oleva koodi on ekvivalentti sille, että pyyntöä tehdessä asetetaan ylimääräinen Otsikko - Proxy Authorization, joten yllä olevaa koodia voidaan muuttaa seuraavasti:

```python
import requests
import base64

proxy_host = 'global.proxy.acedata.cloud'
proxy_port = '30007'
proxy_username = '{proxy_username}' # 8-merkkinen käyttäjänimi
proxy_password = '{proxy_password}' # 32-merkkinen salasana

credentials = base64.b64encode(
    f'{proxy_username}:{proxy_password}'.encode()).decode()

proxies = {
    'http': f'http://{proxy_host}:{proxy_port}',
    'https': f'http://{proxy_host}:{proxy_port}'
}

headers = {
    'Proxy-Authorization': f'Basic {credentials}'
}

for _ in range(3):
    resp = requests.get('https://ipinfo.io',
                        proxies=proxies, headers=headers)
    print(resp.text)

```

Voit nähdä, että tässä asetamme Proxy-Authorization-pyyntöotsikossa ylimääräisen agentin käyttäjänimen ja salasanan (jotka on koodattava Base64-muotoon), ja tällaisen koodin suoritusvaikutus on sama.

Muille kielille, kuten JavaScriptin axios, voidaan myös käyttää samanlaisia asetustapoja:
```javascript
const axios = require("axios");
const base64 = require("base64");

const proxy_host = "global.proxy.acedata.cloud";
const proxy_port = "30007";
const proxy_username = "{proxy_username}"; // 8-merkkinen käyttäjänimi
const proxy_password = "{proxy_password}"; // 32-merkkinen salasana

const credentials = base64.encode(`${proxy_username}:${proxy_password}`);

const proxies = {
  http: `http://${proxy_host}:${proxy_port}`,
  https: `http://${proxy_host}:${proxy_port}`,
};

const headers = {
  "Proxy-Authorization": `Basic ${credentials}`,
};

for (let i = 0; i < 3; i++) {
  axios
    .get("https://ipinfo.io", { proxies, headers })
    .then((resp) => console.log(resp.data))
    .catch((err) => console.error(err));
}
```

Suoritusvaikutus on sama.

Muiden kielten asetustapaa varten voit viitata edellä olevaan ja muokata sen mukaan.

## IP Kiinteä

Kuten edellä mainitussa sisällössä, voimme saavuttaa IP-kiinteyden tietyn ajan sisällä lisäämällä käyttäjänimeen `session` ja lisäämällä viiden numeron kiinteän numeron, jonka voimassaoloaika on noin 10 minuuttia.

Esimerkiksi, jos haluat saavuttaa IP-kiinteyden tietyn ajan sisällä, alkuperäinen käyttäjänimi on `1f78266a`, voit muuttaa käyttäjänimen muotoon `1f78266a-session-12345`, jossa `12345` pysyy muuttumattomana, niin IP pysyy muuttumattomana tietyn ajan. Yllä oleva curl voidaan muuttaa seuraavasti:

```
curl -x 1f78266a-session-12345:eff0896726224fa2a99fe82dd1f07562@global.proxy.acedata.cloud:30007 https://ipinfo.io
```

## Osta lisää

Jos pakettisi on jo loppunut, sinun on ostettava lisää voidaksesi jatkaa tämän välityspalvelun käyttöä.

Ostaaksesi lisää, siirry suoraan "[Hakemussivulle](https://platform.acedata.cloud/services/87ae4a5a-59d9-4c50-86d4-c0b5d393e5af)" ja napsauta "Osta lisää" -painiketta, niin voit valita. Yhden ostoksen hinta on sitä edullisempi, mitä enemmän ostat kerralla.
