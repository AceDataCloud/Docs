title: "Tripo 3D -generointi"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Kutsu `POST /tripo/generations` luodaksesi uuden mallin ja anna teksti, yksi kuva tai saman objektin useita kuvakulmia. Käytä AceDataCloud Tokenia; oletusarvoisesti tulos palautetaan synkronisesti. Kun annat `async: true` tai `callback_url`, palautetaan ensin HTTP 200 ja `task_id`. Valmistumisen takaisinkutsulla ja synkronisella tuloksella on sama JSON-rakenne.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` on oletusarvoisesti `generate`. Valitse yksi kolmesta syötteestä: `prompt` (1–1024 merkkiä), `image_url` tai `image_urls`. Kuvien on oltava julkisesti saatavilla olevia HTTPS PNG/JPEG -kuvia, joiden koko on enintään 20 MiB. Useat näkymät järjestetään etu-, vasen, taka- ja oikea-näkymän järjestyksessä; etunäkymä ja vähintään yksi muu näkymä ovat pakollisia, ja väliin jäävät kuvakulmat voi ohittaa arvolla null.

`model` on oletusarvoisesti `v3.1-20260211`, mutta voit myös valita erikseen `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` tai `P2-20260801`. `texture` on oletusarvoisesti `standard`; käytä pelkälle geometrialle arvoa `none`. Eri mallit ja tekstuuritasot kuluttavat eri määriä kiintiöstä.

Lataa GLB osoitteesta `data[0].model_url`; `image_url` on valinnainen esikatselu. Säilytä `data[0].id` myöhempiä tekstuuri-, muunnos- tai luusto-operaatioita varten. Kun yrität samaa lähetystä uudelleen, säilytä sama `Idempotency-Key` ja pyynnön runko.
