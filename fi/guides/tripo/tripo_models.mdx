---
title: "Tripo-mallien käsittely"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Käsittele olemassa olevia malleja käyttämällä `POST /tripo/models` ja antamalla tarvittava `action`. Synkroninen ja asynkroninen käsittely, takaisinkutsut, tilikohtainen omistajuus ja tehtävien kysely toimivat samalla tavalla kuin 3D-generoinnissa.

| action  | Syöte | Tulos |
| ------- | ----- | ----- |
| import  | `model_url`, julkinen HTTPS-osoite GLB-, GLTF-, FBX-, OBJ- tai STL-tiedostoon, enintään 150 MiB | Mallin ID ja GLB, joihin voidaan viitata jatkossa; jos tiedot ovat saatavilla, palautetaan `normalize_scale` ja `normalize_translation` |
| texture | `model_id` tai `model_url`; valinnaisesti yksi kolmesta: `prompt`, `image_url` tai `image_urls` | Uusi malli, tekstuurit ja valinnainen esikatselu |
| convert | `model_id` tai `model_url` sekä kohde-`format` | Muunnettu mallitiedosto |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

Tuetut tekstuurin laatutasot ovat `fast`, `standard`, `detailed` ja `extreme`. Tekstikehotetta käytettäessä voidaan lisäksi antaa `style_image_url`; kuva- ja moninäkymäviitteet noudattavat generointirajapinnan muotoa. Lisää tekstuuriparametreja on OpenAPI-kuvauksessa.

Muunnos tukee formaatteja `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` ja `3MF`. Palautetun kohteen `format` ilmaisee todellisen toimitusmuodon; esimerkiksi GLTF-pyyntöön voidaan toimittaa binäärinen GLB. OBJ pakkaa materiaalit ja pintakartat ZIP-tiedostoon. Kun pyydät FBX:ää, aseta `texture_packaging: "zip"` saadaksesi pintakartat erillisinä; pakatussa tuloksessa ilmoitetaan `container: "ZIP"`. Muiden kuin oletusarvoisten verkko- tai tekstuuriasetusten käyttöönotosta voidaan veloittaa edistyneen muunnoksen mukaisesti; lisätietoja on palvelun hinnastossa.

Viittaa tämän tilin malliin käyttämällä `data[0].id`; tuodun mallin normalisointimuunnos noudattaa kaavaa `normalized = original × normalize_scale + normalize_translation`. Mallin latausosoite on kentässä `data[0].model_url`.
