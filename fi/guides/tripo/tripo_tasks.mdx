---
title: "Tripo-mallitehtävien kysely"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Kutsu `POST /tripo/tasks` AceDataCloud-tokenilla. Kysely on maksuton, ja siinä käytetään samaa tiliä kuin generoinnissa. Käytä yksittäiseen kyselyyn `id`- tai `trace_id`-kenttää; `action` on oletusarvoisesti `retrieve`.

```bash
curl -X POST https://api.acedata.cloud/tripo/tasks \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"action\":\"retrieve\",\"id\":\"${TASK_ID}\"}"
```

Yksittäisen kyselyn tulos on tehtävätietue, joka sisältää kentät `id`, `type`, `trace_id`, alkuperäisen pyynnön `request`, `started_at` ja `progress`. Käsittelyn aikana kyselyä voi jatkaa muutaman sekunnin välein. Tarkista valmistumisen jälkeen `response.success`; onnistuneessa tapauksessa `response.data[0].model_url` on latausosoite, ja epäonnistuneessa tapauksessa `response.error` sisältää virhekoodin ja viestin. Aikaleimat, `finished_at` ja kulunut aika `elapsed` ovat tehtävätietueen ylimmällä tasolla, ja niiden yksikkö on sekunti. Jos vastaan tulee `submission_unknown`, säilytä alkuperäinen tehtävän ID tarkistusta varten.

Eräkyselyssä käytetään `{"action":"retrieve_batch","ids":["<tehtävän ID 1>","<tehtävän ID 2>"]}`, ja myös `trace_ids`-kenttää voi käyttää; kerralla enintään 100 tietuetta. Vastaus on `{"items":[...],"count":2}`, ja syötejärjestys sekä kaksoiskappaleet säilytetään. Jos tehtävää ei löydy tai sen lukemiseen ei ole oikeutta, yksittäinen kysely palauttaa `{}` ja eräkyselyssä vastaava kohta on `null`.

Tehtävätietueen `type` on `generations`, `models` tai `animations`. Luuston tarkistuksessa luetaan `response.data[0].riggable`, ja tiedostotoiminnoissa luetaan `response.data[0].model_url`.
