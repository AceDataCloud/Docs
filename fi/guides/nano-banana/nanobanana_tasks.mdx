Nano Banana Tasks API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä Nano Banana Images API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Nano Banana Tasks API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Nano Banana Tasks API:n avulla voit helposti kysyä Nano Banana Images API:n tehtävän suoritusstatus.

## Pyyntöesimerkki

Nano Banana Tasks API:ta voidaan käyttää Nano Banana Images API:n tulosten kysymiseen. Lisätietoja Nano Banana Images API:n käytöstä löytyy asiakirjasta [Nano Banana Images API](https://platform.acedata.cloud/documents/63e01dc3-eb21-499e-8049-3025c460058f).

Otetaan esimerkki yhdestä Nano Banana Images API:n palauttamasta tehtävä-ID:stä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 4d320ead-4af4-4a55-8f3e-f2afebdf4fd0, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä kohdassa on `application/json`.
- `authorization`: API:n kutsuav avain, jonka voi valita suoraan alasvetovalikosta hakemisen jälkeen.

**Pyyntökeho** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/nuiuth.png" width="500" class="m-auto"></p>

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/r1u4vl.png" width="500" class="m-auto"></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/nano-banana/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "4d320ead-4af4-4a55-8f3e-f2afebdf4fd0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Massakyselytoiminto

Tämä on tarkoitettu useiden tehtävä-ID:iden kyselyyn tehtävän yksityiskohtien osalta, ja se eroaa edellisestä siten, että `action` on valittava `retrieve_batch`.

**Pyyntökeho** sisältää:

- `ids`: ladattujen tehtävä-ID:iden taulukko.
- `action`: tehtävän toimintatapa.

Esimerkki on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed","1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed"],
  "action": "retrieve_batch"
}'
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheen, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti johtuen puuttuvista tai virheellisistä parametreista.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti johtuen puuttuvista tai virheellisistä parametreista.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
