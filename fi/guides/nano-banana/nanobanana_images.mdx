Tässä artikkelissa esitellään Nano Banana Images API -rajapinnan integrointi ja käyttö. Tämä rajapinta tukee kahta toimintoa: **kuvien luominen (generate)** ja **kuvien muokkaaminen (edit)**.

## Hakuprosessi

Nano Banana Images API -rajapinnan käyttämiseksi siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) hankkimaan API Token -tunnuksesi myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kun olet suorittanut nämä vaiheet, sinut palautetaan automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voit käyttää kaikkia alustan palveluita ilman, että sinun tarvitsee hakea tunnusta erikseen jokaiselle palvelulle.** Ensimmäisen hakemuksen yhteydessä saat ilmaista käyttökiintiötä, jonka avulla voit kokeilla palvelua maksutta. Kun kiintiö ei enää riitä, voit ladata yleistä saldoa [hallintapaneelissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Rajapinnan yleiskatsaus

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Todennusmenetelmä**：Lisää HTTP Header -otsakkeeseen `authorization: Bearer {token}`
- **Pyyntöotsakkeet**：
  - `accept: application/json`
  - `content-type: application/json`
- **Toiminto (action)**：
  - `generate`：Luo kuvia tekstikehotteiden perusteella
  - `edit`：Muokkaa annettuja kuvia
- **Malli (model)**（valinnainen）：
  - `nano-banana`（oletus）：Perustuu Gemini 2.5 Flash Image -malliin, nopea ja edullinen
  - `nano-banana-2-lite`：Perustuu Gemini 3.1 Flash Lite Image -malliin, tukee vain 1K-resoluutiota ja tarjoaa nopean kuvien luonnin
  - `nano-banana-2`：Perustuu Gemini 3.1 Flash Image Preview -malliin, Pro-tason laatu ja Flash-nopeus
  - `nano-banana-2.1`：Uuden sukupolven tehokas kuvamalli, tukee 1K-, 2K- ja 4K-resoluution kuvien luomista ja muokkaamista
  - `nano-banana-pro`：Perustuu Gemini 3 Pro Image Preview -malliin, korkein laatu
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：Vastaavien mallien virallisen kanavan versiot, parempi kuvanlaatu ja vakaus, erilainen hinnoittelu
- **Asynkroninen takaisinsoitto**：Valinnainen, vastaanota ilmoitukset tehtävän valmistumisesta ja tulokset `callback_url`-osoitteen kautta
- **Kuvien määrä**：Valinnainen, määritä 1–4 kuvaa `count`-parametrilla, oletusarvo on 1 kuva. Jokainen kuva luodaan erillisellä generointikutsulla. Tavallinen tekninen virhe tai palveluntarjoajan tekemä turvallisuussyihin perustuva hylkäys vaikuttaa vain kyseiseen kutsuun. Muut onnistuneet kuvat palautetaan normaalisti, ja veloitus perustuu todellisuudessa onnistuneiden kuvien määrään.

## Pika-aloitus: Kuvien luominen (`action=generate`)

**Vähimmäisvaaditut parametrit**：`action`、`prompt`

Kun haluat luoda kuvan suoraan tekstikehotteen perusteella, aseta `action`-arvoksi `generate` ja anna selkeä `prompt`.

### Pyyntöesimerkki (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Pyyntöesimerkki (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]

```

### Kenttien kuvaukset

- `success`：Ilmaisee, onnistuiko tämä pyyntö.
- `task_id`：Tehtävän tunnus.
- `trace_id`：Pyyntöketjun jäljitystunnus, joka helpottaa ongelmien selvittämistä.
- `count`：Pyynnössä luotavien tai muokattavien kuvien määrä. Tukee arvoja 1–4, oletusarvo on 1. `data` sisältää vain onnistuneesti luodut kuvat, ja laskutus perustuu todellisuudessa palautettujen kuvien määrään. Jokaisessa generointikutsussa käytetään pakollisesti palveluntarjoajan alkuperäistä turvallisuuskäytäntöä. Yhden kutsun hylkääminen ei vaikuta muiden onnistuneiden kutsujen tuloksiin. Jos kaikki kutsut hylätään, palautetaan 403-virhe.
- `data[]`：Tulosten luettelo.
  - `prompt`：Kuvan luomiseen käytetty tekstikehote (palautetaan vastauksessa).
  - `image_url`：Suora URL-osoite luotuun kuvaan.

> Huomautus: `/nano-banana/images`-rajapinta tarvitsee vain `action`- ja `prompt`-parametrit kuvien luomiseen.

## Kuvien muokkaaminen (`action=edit`)

Kun haluat muokata olemassa olevia kuvia, aseta `action`-arvoksi `edit` ja välitä muokattavien kuvien linkkiluettelo (yksi tai useampi kuva) `image_urls`-parametrin kautta. Anna samalla `prompt`, jossa kuvaat muokkauksen tavoitteen.

Esimerkiksi tässä annamme yhden valokuvan henkilöstä ja yhden valokuvan vaatteesta. Jos haluamme saada henkilön pukemaan kyseisen vaatteen, voimme välittää molempien kuvien linkit samanaikaisesti ja määrittää `action`-arvoksi `edit`. URL-osoite voi olla HTTP-URL-osoite, julkisesti käytettävissä oleva `https`- tai `http`-protokollan linkki tai Base64-koodattu kuva, kuten `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Pyyntöesimerkki (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Pyyntöesimerkki (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Kenttien selitykset

- `image_urls[]`: Muokattavien kuvien URL-osoitteiden luettelo (niiden on oltava julkisesti saatavilla internetissä). Voit lähettää useita kuvia, ja palvelu yhdistää nämä materiaalit ja `prompt`-kehotteen muokkauksen suorittamiseksi.
- Muut kentät ovat samat kuin kohdassa ”Kuvan luominen” palautettavat kentät.

## Asynkroninen takaisinsoitto (valinnainen, suositeltava)

Kuvan luominen tai muokkaaminen voi kestää jonkin aikaa. Pitkien yhteyksien aiheuttaman resurssien käytön välttämiseksi on suositeltavaa käyttää **Webhook-takaisinsoittoa** `callback_url`-osoitteen kautta:

1. Lisää pyyntöön `callback_url`, esimerkiksi palvelimesi Webhook-osoite (sen on oltava julkisesti saatavilla internetissä ja tuettava POST JSON -pyyntöjä).
2. API palauttaa **välittömästi** vastauksen, joka sisältää `task_id`-tunnisteen (tai perustuloksen).
3. Kun tehtävä on valmis, alusta lähettää koko JSON-tuloksen `POST`-pyyntönä `callback_url`-osoitteeseen. Voit yhdistää pyynnön ja tuloksen `task_id`-tunnisteen avulla.

**Takaisinsoiton hyötykuorman esimerkki** (kenttärakenne on sama kuin synkronisessa onnistuneessa vastauksessa):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Virheenkäsittely

Epäonnistunut kutsu palauttaa vakiomuotoisen virherakenteen ja jäljitystunnuksen. Yleiset virheet ovat seuraavat:

- **400 `token_mismatched`**: Virheellinen pyyntö tai virheelliset parametrit.
- **400 `api_not_implemented`**: Rajapintaa ei ole toteutettu (ota yhteyttä tukeen).
- **401 `invalid_token`**: Todennus epäonnistui tai Token puuttuu.
- **403 `forbidden`**: Palveluntarjoajan alkuperäinen turvallisuuskäytäntö hylkäsi pyynnön tai luodun tuloksen. Tämä kutsu ei palauta kuvaa eikä siitä veloiteta; usean kuvan pyynnöissä muut onnistuneet kutsut voidaan silti palauttaa ja laskuttaa.
- **429 `too_many_requests`**: Pyyntöjen määrä ylittää sallitun rajan.
- **500 `api_error`**: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parametrien vertailu ja huomautukset

- **Pakolliset**: `action`, `prompt`
- **Vain muokkaukseen**: `image_urls` (taulukko, vähintään 1 kohde)
- **Valinnaiset**: `model` (oletusarvo `nano-banana`, valittavissa myös `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; lukuun ottamatta mallia `nano-banana-2.1`, saatavilla on myös vastaavat virallisen kanavan versiot tunnisteella `:official`), `aspect_ratio` (`auto` tai tietty kuvasuhde, kuten `1:1`, `16:9`), `resolution` (resoluutio, kuten `1K`, `2K`, `4K`; `nano-banana-2-lite` tukee vain arvoa `1K`), `callback_url` (asynkronista takaisinsoittoa varten)
- **Headers**: `authorization: Bearer {token}` on pakollinen; `accept`-arvoksi suositellaan `application/json`
- **Kuvien saatavuus**: `image_urls`-osoitteiden on oltava suoria, julkisesti saatavilla olevia URL-osoitteita (HTTP/HTTPS). HTTPS:n käyttöä suositellaan.
- **Idempotenssi ja jäljitys**: Säilytä `task_id`- ja `trace_id`-tunnisteet vianmääritystä ja tulosten yhdistämistä varten.

Arvon `"aspect_ratio": "auto"` nimenomainen välittäminen valitsee kehotteessa ilmoitettua kuvasuhdetta, suuntaa tai asettelua lähinnä vastaavan esiasetuksen. Tämä soveltuu sekä kuvien luomiseen että muokkaamiseen. Jos kehotteessa lukee esimerkiksi ”YouTube-pikkukuva”, järjestelmä voi valita kuvasuhteen `16:9`. Jos kehotteessa ei ole kokovaatimuksia tai automaattinen valinta ei ole käytettävissä, tekstistä kuvaksi -toiminto käyttää oletuskuvasuhdetta, kun taas kuvan muokkaus seuraa ensimmäistä viitekuvaa ja käyttää lähintä tuettua kuvasuhdetta. Jos tämä kenttä jätetään pois, käytetään oletuskuvasuhdetta tai viitekuvan kuvasuhdetta. Jos kuvasuhde on jo määritelty selkeästi, välitä suoraan kyseinen arvo.
