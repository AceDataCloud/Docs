Tässä artikkelissa esitellään Nano Banana Images API:n liittyminen ja käyttö. Tämä rajapinta tukee kahta toimintoa: **kuvagenerointi (generate)** ja **kuvamuokkaus (edit)**.

## Hakuprosessi

Ennen käyttöä, siirry Ace Data Cloud -alustalla [Nano Banana Images API](https://platform.acedata.cloud/documents/23985a11-d713-41d1-ad84-24b021805b3d) -sivulle ja napsauta Acquire saadaksesi käyttöoikeuden. Ensimmäisessä hakemuksessa on yleensä saatavilla ilmaisia rajoja. Kun käyttöoikeus on myönnetty, voit saada alustan kautta Bearer Tokenin API:n kutsumista varten.

## Rajapinnan yleiskatsaus

- **Perus-URL**: `https://api.acedata.cloud`
- **Päätepiste**: `POST /nano-banana/images`
- **Todennustapa**: HTTP Headerissä on `authorization: Bearer {token}`
- **Pyyntöotsikot**:
  - `accept: application/json`
  - `content-type: application/json`
- **Toiminto (action)**:
  - `generate`: Generoi kuva tekstikehotteen perusteella
  - `edit`: Muokkaa annettua kuvaa
- **Malli (model)** (valinnainen):
  - `nano-banana` (oletus): Perustuu Gemini 2.5 Flash Imageen, nopea, edullinen
  - `nano-banana-2`: Perustuu Gemini 3.1 Flash Image Preview -kuvaan, Pro-tason laatu + Flash-nopeus
  - `nano-banana-pro`: Perustuu Gemini 3 Pro Image Preview -kuvaan, paras laatu
- **Asynkroninen palautus**: Valinnainen, vastaanota tehtävän valmistumisen ilmoitus ja tulokset `callback_url` kautta

## Nopeasti alkuun: Kuvan generointi (`action=generate`)

**Vähimmäisvaatimukset**: `action`, `prompt`
Kun haluat vain luoda kuvan kehotteen perusteella, aseta `action` arvoksi `generate` ja anna selkeä `prompt`.

### Pyyntöesimerkki (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Pyyntöesimerkki (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Kenttäselitykset

- `success`: Onko tämä pyyntö onnistunut.
- `task_id`: Tehtävän ID.
- `trace_id`: Seurantatunnus, helpottaa ongelmien selvittämistä.
- `data[]`: Tulosten lista.
  - `prompt`: Generoinnissa käytetty kehotus (palautus).
  - `image_url`: Generoidun kuvan suora URL-osoite.

> Huom: `/nano-banana/images` tarvitsee vain `action` ja `prompt` kuvan generointiin

## Kuvan muokkaus (`action=edit`)

Kun haluat muokata olemassa olevaa kuvaa, aseta `action` arvoksi `edit` ja lähetä `image_urls` -kentässä muokattavien kuvien linkkilista (1 tai useampi), samalla kun annat muokkaustavoitteesta kuvaavan `prompt`-kentän.

Esimerkiksi, jos tarjoamme kuvan henkilöstä ja kuvan vaatteista, voimme pyytää henkilöä pukeutumaan tähän vaatteeseen, jolloin voimme lähettää kuvien linkit ja määrittää actionin arvoksi `edit`. URL-osoitteet voivat olla HTTP-URL-osoitteita, jotka ovat julkisesti saatavilla `https` tai `http` -protokollan kautta, tai ne voivat olla Base64-koodattuja kuvia, kuten `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Pyyntöesimerkki (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Pyyntöesimerkki (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Kenttäselitykset

- `image_urls[]`: Muokattavien kuvien URL-osoitteiden lista (täytyy olla julkisesti saatavilla). Voit lähettää useita kuvia, palvelu yhdistää nämä materiaalit ja `prompt`-kentän muokkauksen suorittamiseksi.
- Muut kentät ovat samat kuin "kuvan generoinnin" palautuksessa.

## Asynkroninen palautus (valinnainen, suositeltava)

Generointi tai muokkaus voi viedä aikaa. Pitkien yhteyksien resurssien käytön välttämiseksi suositellaan käyttämään **Webhook-palaute**-toimintoa `callback_url`-parametrin kautta:

1. Lisää pyyntöön `callback_url`, esimerkiksi palvelimesi Webhook-osoite (täytyy olla julkisesti saatavilla, tukee POST JSON).
2. API **palauttaa heti** vastauksen, joka sisältää `task_id`:n (tai perus tuloksen).
3. Kun tehtävä on valmis, alusta lähettää täydellisen JSON:n `POST`-menetelmällä `callback_url`:iin. Voit yhdistää pyynnön ja tuloksen `task_id`:n avulla.

**Palautuskuorman esimerkki** (kenttästruktuuri on sama kuin synkronisessa onnistuneessa palautuksessa):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "valkoinen siamilainen kissa",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Virheiden käsittely

Kun kutsu epäonnistuu, palautetaan standardivirheformaatin ja jäljitystunnuksen. Yleisiä virheitä ovat:

- **400 `token_mismatched`**: Pyyntö on virheellinen tai parametrit ovat virheellisiä.
- **400 `api_not_implemented`**: Rajapintaa ei ole toteutettu (ota yhteyttä tukeen).
- **401 `invalid_token`**: Valtakirja epäonnistui tai Token puuttuu.
- **429 `too_many_requests`**: Pyyntötaajuus ylittää rajan.
- **500 `api_error`**: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Sisäinen palvelinvirhe."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parametrivertailu ja huomioitavat seikat

- **Pakolliset**: `action`, `prompt`
- **Muokkaamiseen tarkoitettu**: `image_urls` (taulukko, vähintään 1 kohde)
- **Valinnaiset**: `model` (oletusarvo `nano-banana`, valinnaiset `nano-banana-2` tai `nano-banana-pro`), `aspect_ratio` (kuvasuhde, kuten `1:1`, `16:9`), `resolution` (resoluutio, kuten `1K`, `2K`, `4K`), `callback_url` (asynkronista palautetta varten)
- **Headers**: On pakko antaa `authorization: Bearer {token}`; `accept` suositellaan asetettavaksi `application/json`
- **Kuvien saatavuus**: `image_urls` on oltava julkisesti saatavilla olevia suoria linkkejä (HTTP/HTTPS), suositellaan käyttämään HTTPS:ää
- **Idempotenttius ja jäljitys**: Säilytä `task_id` ja `trace_id`, helpottaa vianetsintää ja tulosten yhdistämistä
