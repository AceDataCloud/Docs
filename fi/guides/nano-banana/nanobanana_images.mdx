Tässä artikkelissa esitellään Nano Banana Images API:n integrointi ja käyttö. Rajapinta tukee kahta toimintoa: **kuvan luonti (generate)** ja **kuvan muokkaus (edit)**.

## Hakuprosessi

Käyttääksesi Nano Banana Images API:a hanki ensin API Token -tunnuksesi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisen hakemuksen yhteydessä saat ilmaista käyttökiintiötä maksutonta kokeilua varten; kun kiintiö ei riitä, voit lisätä yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Rajapinnan yleiskatsaus

- **Base URL**: `https://api.acedata.cloud`
- **Endpoint**: `POST /nano-banana/images`
- **Todennustapa**: HTTP Headerissa välitetään `authorization: Bearer {token}`
- **Pyyntöotsikot**:
  - `accept: application/json`
  - `content-type: application/json`
- **Toiminto (action)**:
  - `generate`: luo kuva tekstikehotteen perusteella
  - `edit`: muokkaa annettua kuvaa
- **Malli (model)** (valinnainen):
  - `nano-banana` (oletus): perustuu Gemini 2.5 Flash Imageen, nopea ja edullinen
  - `nano-banana-2-lite`: perustuu Gemini 3.1 Flash Lite Imageen, tukee vain 1K:ta ja luo kuvia nopeasti
  - `nano-banana-2`: perustuu Gemini 3.1 Flash Image Previewiin, Pro-tason laatu + Flash-nopeus
  - `nano-banana-pro`: perustuu Gemini 3 Pro Image Previewiin, korkein laatu
  - `nano-banana:official`, `nano-banana-2-lite:official`, `nano-banana-2:official`, `nano-banana-pro:official`: vastaavien mallien virallisen kanavan versiot, joiden kuvanlaatu ja vakaus ovat parempia ja laskutus erilainen
- **Asynkroninen takaisinsoitto**: valinnainen; vastaanota tehtävän valmistumisilmoitukset ja tulokset `callback_url`:n kautta
- **Kuvien määrä**: valinnainen; määritä `count`:lla 1–4 kuvaa, oletuksena 1 kuva; jokainen kuva luodaan erillisellä luontikutsulla; tavalliset tekniset epäonnistumiset tai palveluntarjoajan turvallisuushylkäykset vaikuttavat vain kyseiseen kutsuun, muut onnistuneet kuvat palautetaan normaalisti, ja laskutus perustuu todelliseen onnistuneiden kuvien määrään

## Pikakäyttö: kuvan luonti (`action=generate`)

**Vähimmäisvaatimukset**: `action`, `prompt`  
Kun haluat luoda kuvan suoraan kehotteen perusteella, aseta `action` arvoksi `generate` ja anna selkeä `prompt`.

### Pyyntöesimerkki (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Pyyntöesimerkki (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]

```

### Kenttien kuvaus

- `success`: onnistuiko tämä pyyntö.
- `task_id`: tehtävän tunnus.
- `trace_id`: ketjun seurannan tunnus, joka helpottaa ongelmien selvittämistä.
- `count`: pyydettävien luotavien tai muokattavien kuvien määrä, tukee arvoja 1–4, oletuksena 1. `data` sisältää vain onnistuneesti luodut kuvat, ja laskutus perustuu todelliseen palautettujen kuvien määrään. Jokainen luontikutsu käyttää pakotetusti palveluntarjoajan natiivia turvallisuuskäytäntöä; yhden kutsun hylkääminen ei vaikuta muihin onnistuneisiin kutsuihin, ja jos kaikki kutsut hylätään, palautetaan 403.
- `data[]`: tulosluettelo.
  - `prompt`: luontiin käytetty kehote (toistetaan vastauksessa).
  - `image_url`: luodun kuvan suora URL-osoite.

> Huomautus: `/nano-banana/images` tarvitsee kuvan luontiin vain `action`- ja `prompt`-parametrit

## Kuvan muokkaus (`action=edit`)

Kun haluat muokata olemassa olevaa kuvaa, aseta `action` arvoksi `edit`, välitä muokattavien kuvien linkkiluettelo (1 kuva tai useita) `image_urls`:n kautta ja anna samalla muokkaustavoitetta kuvaava `prompt`.

Esimerkiksi tässä tarjoamme yhden henkilökuvan ja yhden vaatekuvan. Jotta henkilö pukisi tämän vaatteen ylleen, voit välittää kuvalinkit samanaikaisesti ja määrittää actionin arvoksi `edit`. URL voi olla HTTP URL eli julkisesti käytettävissä oleva linkki `https`- tai `http`-protokollalla, tai se voi olla Base64-koodattu kuva, kuten `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Pyyntöesimerkki (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Pyyntöesimerkki (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Kenttien kuvaus

- `image_urls[]`: Muokattavien kuvien URL-osoitteiden luettelo (täytyy olla julkisesti käytettävissä). Voit lähettää useita kuvia, ja palvelu yhdistää nämä materiaalit sekä `prompt`-kehotteen muokkauksen suorittamiseksi.
- Muut kentät ovat samat kuin kohdassa ”Kuvan luominen”.

## Asynkroninen takaisinsoitto (valinnainen, suositeltu)

Luominen tai muokkaaminen voi kestää jonkin aikaa. Resurssien varaamisen välttämiseksi pitkissä yhteyksissä on suositeltavaa käyttää **Webhook-takaisinsoittoa** `callback_url`-osoitteen kautta:

1. Lisää pyyntörunkoon `callback_url`, esimerkiksi palvelimesi Webhook-osoite (täytyy olla julkisesti käytettävissä ja tukea POST JSONia).
2. API **palauttaa välittömästi** vastauksen, joka sisältää `task_id`:n (tai perustulokset).
3. Kun tehtävä on valmis, alusta lähettää täydellisen JSONin `callback_url`-osoitteeseen `POST`-menetelmällä. Voit yhdistää pyynnön ja tuloksen `task_id`:n avulla.

**Esimerkki takaisinsoiton hyötykuormasta** (kenttärakenne on sama kuin synkronisessa onnistuneessa vastauksessa):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Virheenkäsittely

Kun kutsu epäonnistuu, palautetaan vakiomuotoinen virhemuoto ja seuranta-ID. Yleisiä virheitä ovat:

- **400 `token_mismatched`**: Pyyntö on virheellinen tai parametreissa on virhe.
- **400 `api_not_implemented`**: Rajapintaa ei ole toteutettu (ota yhteyttä tukeen).
- **401 `invalid_token`**: Todennus epäonnistui tai Token puuttuu.
- **403 `forbidden`**: Tarjoajan alkuperäinen tietoturvakäytäntö hylkäsi pyynnön tai luontituloksen. Tämä kutsu ei palauta kuvaa eikä siitä veloiteta; monikuvapyynnöissä muut onnistuneet kutsut voidaan silti palauttaa ja niistä voidaan veloittaa.
- **429 `too_many_requests`**: Pyyntötiheys ylittää rajan.
- **500 `api_error`**: Palvelinpuolen poikkeus.

### Esimerkki virhevastauksesta

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Parametrien vertailu ja huomioitavat asiat

- **Pakolliset**: `action`, `prompt`
- **Vain muokkaukseen**: `image_urls` (taulukko, vähintään 1 kohde)
- **Valinnaiset**: `model` (oletus `nano-banana`; vaihtoehdot `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-pro` tai vastaavat virallisen kanavan `:official`-versiot), `aspect_ratio` (kuvasuhde, kuten `1:1`, `16:9`), `resolution` (resoluutio, kuten `1K`, `2K`, `4K`; `nano-banana-2-lite` tukee vain `1K`:ta), `callback_url` (asynkronista takaisinsoittoa varten)
- **Headers**: `authorization: Bearer {token}` on annettava; `accept` kannattaa asettaa arvoon `application/json`
- **Kuvien saavutettavuus**: `image_urls`-osoitteiden on oltava julkisesti käytettävissä olevia suoria linkkejä (HTTP/HTTPS); HTTPS:n käyttöä suositellaan
- **Idempotenssi ja seuranta**: Säilytä `task_id` ja `trace_id` vianmääritystä ja tulosten yhdistämistä varten
