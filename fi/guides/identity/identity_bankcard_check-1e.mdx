Tässä artikkelissa esitellään pankkikortin perusinformaatiohaku API -liitännäisohje, jota voidaan käyttää pankkikortin perusinformaatiohakuun.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [pankkikortin perusinformaatiohaku API](https://platform.acedata.cloud/documents/3523988d-acba-4362-9def-105657991eb4) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä pankkikortin numero, voit saada käsitellyn vahvistustuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `bank_card`-kenttä, ja voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/h41nrh.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu pyyntökeho, mukaan lukien:

- `bank_card`: pankkikortin numero.
- `encryption`: valinnainen, arkaluontoisten kenttien salausparametri (jos salattua tietoa on lähetettävä).

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/grfra7.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saimme seuraavan tuloksen:

```json
{
  "result": "0",
  "description": "Haku onnistui",
  "account_bank": "Teollisuus- ja kaupankäyntipankki",
  "account_type": 1
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `result`, vahvistustuloksen koodi, maksutiedot seuraavasti.
  - Maksutuloksen koodi:
    - 0: Haku onnistui
    - -1: Tietoja ei löytynyt
  - Ilmaisen tuloksen koodi:
    - -2: Vahvistuskeskus on kiireinen
    - -3: Pankkikorttia ei ole olemassa
- `description`, liiketoimintatuloksen kuvaus.
- `account_bank`, pankki, jossa tili on avattu.
- `account_type`, kortin luonne: 1. Pankkikortti; 2. Luottokortti; 3. Ennakkomaksukortti; 4. Hyväksytty luottokortti.

Voit nähdä, että pankkikortin perusinformaatio on jo haettu.

Lisäksi, jos haluat luoda vastaavan liitännäiskoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "bank_card": "****"
}'
```

Pythonin liitännäiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "bank_card": "****"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "haku epäonnistui"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
