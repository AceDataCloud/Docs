Tässä artikkelissa esitellään henkilötietojen ja voimassaolon tarkistuksen API-liitännäisen ohjeet, jota voidaan käyttää nimen, henkilökortin numeron ja henkilökortin voimassaolon aitouden ja yhdenmukaisuuden tarkistamiseen.

## Hakuprosessi

Käyttääksesi henkilötietojen ja voimassaolon tarkistuksen API:a, sinun on ensin mentävä [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API-tunnus riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; kun määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Henkilötietojen ja voimassaolon tarkistuksen API →](https://platform.acedata.cloud/documents/identity-idcard-check-2e)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä henkilökorttikuvan linkki, voit saada käsittelyn jälkeen vahvistustuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `name`-kenttä, ja voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/llvy1l.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi on asetettu pyyntökeho, joka sisältää:

- `name`: nimi.
- `id_card`: henkilökortin numero.
- `image_url`: käsiteltävän kasvokuvan linkki.
- `validity_end`: henkilökortin voimassaolon päättymispäivämäärä, muoto: YYYYMMDD, pitkäaikaiselle käytölle käytetään "00000000";
- `validity_begin`: henkilökortin voimassaolon alkamispäivämäärä, muoto: YYYYMMDD.
- `encryption`: valinnainen, arkaluontoisten kenttien salausparametri (jos salattua tietoa on tarpeen lähettää).

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/l77q0u.png" width="500" className="m-auto" /></p>

Napsauta "Kokeile" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavat tulokset:

```json
{
  "result": "0",
  "description": "yhteensopiva"
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `result`, vahvistustuloksen koodi, maksutilanne seuraavasti.
    - Maksulliset tuloskoodit:
        - 0: Nimi ja henkilökortin numero ovat yhteensopivia
        - -1: Nimi ja henkilökortin numero eivät ole yhteensopivia
    - Ilmaismaksulliset tuloskoodit:
        - -2: Laillinen henkilökortin numero (pituus, tarkistussumma jne. ei ole oikein)
        - -3: Laillinen nimi (pituus, muoto jne. ei ole oikein)
        - -4: Asiakirjatietokannan palveluhäiriö
        - -5: Asiakirjatietokannassa ei ole tätä henkilökortin tietoa
        - -6: Auktorisoitu vertailujärjestelmä on päivityksessä, yritä myöhemmin uudelleen
        - -7: Vahvistuskertojen määrä ylittää päivittäisen rajan.
- `description`, tässä on nimen ja henkilökortin numeron vahvistustulos.

Voimme nähdä, että henkilökortissa nimi, henkilökortin numero ja voimassaoloaika ovat aitoja ja yhteensopivia.

Jos haluat luoda vastaavan liitännäiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/identity/idcard/check-2e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "id_card": "***",
  "validity_begin": "***",
  "validity_end": "***"
}'
```

Pythonin liitännäiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/check-2e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "id_card": "***",
    "validity_begin": "***",
    "validity_end": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liikaa pyyntöjä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
