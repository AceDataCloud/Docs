Tässä artikkelissa esitellään puhelinnumeron tilan tarkistus API -integraatio-ohje, jota voidaan käyttää puhelinnumeron tilan vahvistamiseen. Voit syöttää puhelinnumeron tarkistusta varten.

## Hakuprosessi

Jotta voit käyttää puhelinnumeron tilan tarkistus API:a, sinun on ensin hankittava API Token [Ace Data Cloud -hallintapaneelista](https://platform.acedata.cloud/console/applications) ja pidettävä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API Token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen käyttöoikeuden, jonka avulla voit kokeilla palvelua ilmaiseksi; jos käyttöoikeus loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Puhelinnumeron tilan tarkistus API →](https://platform.acedata.cloud/documents/identity-phone-check-1e)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä puhelinnumero saat käsitellyn tuloksen. Sinun on ensin yksinkertaisesti välitettävä `mobile`-kenttä. Voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/r17llo.png" width="500" className="m-auto" /></p>

Täällä olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi olemme asettaneet pyyntökehon, mukaan lukien:

- `mobile`: käsiteltävä puhelinnumero, pakollinen parametri.
- `encryption`: valinnainen, arkaluontoisten kenttien salausparametri (jos salattua tietoa on lähetettävä).

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/dpun55.png" width="500" className="m-auto" /></p>

Napsauta "Kokeile" -painiketta, jotta voit testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavan tuloksen:

```json
{
  "result": "0",
  "description": "Onnistui",
  "status_code": 0
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `result`, vahvistustuloksen koodi, maksutiedot seuraavat.
    - Maksulliset tuloskoodit:
        - 0: Onnistui
    - Ilmaisten tuloskoodit:
        - -1: Tulosta ei löytynyt
        - -2: Puhelinnumeron muoto on virheellinen
        - -3: Vahvistuskeskus on ruuhkautunut
- `description`, liiketoiminnan tuloksen kuvaus.
- `status_code`, tilakoodi:
    - 0: Normaali
    - 1: Poissa käytöstä
    - 2: Numero on suljettu
    - 3: Tyhjennä numero
    - 4: Ei verkossa
    - 99: Tuntematon tila

Voimme nähdä, että tämän puhelinnumeron tila on jo tarkistettu.

Jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "mobile": "***"
}'
```

Pythonin integraatiokoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "mobile": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "haku epäonnistui"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
