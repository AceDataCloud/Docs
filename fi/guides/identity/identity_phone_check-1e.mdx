Tässä artikkelissa esitellään puhelinnumeron tilan tarkistus API -liittymän ohjeet, jota voidaan käyttää puhelinnumeron tilan vahvistamiseen. Voit syöttää puhelinnumeron tarkistusta varten.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [puhelinnumeron tilan tarkistus API](https://platform.acedata.cloud/documents/037e2b5b-d0c0-425c-9e13-955ac64d1e07) -sivulle ja haettava vastaavaa palvelua. Kun olet sivulla, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, ja voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttää puhelinnumero, jotta saat käsitellyn tuloksen. Ensimmäiseksi sinun on yksinkertaisesti välitettävä `mobile`-kenttä. Voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/r17llo.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, mukaan lukien:

- `mobile`: käsiteltävä puhelinnumero, pakollinen parametri.
- `encryption`: valinnainen, arkaluontoisten kenttien salausparametri (jos salattua tietoa on lähetettävä).

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/dpun55.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta, jotta voit testata, kuten yllä olevassa kuvassa näkyy, ja saimme seuraavanlaisen tuloksen:

```json
{
  "result": "0",
  "description": "成功",
  "status_code": 0
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `result`, vahvistustuloskoodi, maksutiedot seuraavasti.
  - Maksulliset tuloskoodit:
    - 0: onnistui
  - Ilmaismaksulliset tuloskoodit:
    - -1: tulosta ei löytynyt
    - -2: puhelinnumeron muoto on virheellinen
    - -3: vahvistuskeskus on ruuhkautunut
- `description`, liiketoimintatuloksen kuvaus.
- `status_code`, tilakoodi:
  - 0: normaali
  - 1: katkaistu
  - 2: suljettu
  - 3: tyhjennä numero
  - 4: ei verkossa
  - 99: tuntematon tila

Voit nähdä, että tämän puhelinnumeron tila on jo tarkistettu.

Lisäksi, jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/identity/phone/check-1e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "mobile": "***"
}'
```

Pythonin liittymiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/identity/phone/check-1e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "mobile": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
