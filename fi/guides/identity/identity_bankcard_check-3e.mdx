Tässä artikkelissa esitellään pankkikortin kolmen elementin tarkistus API -liitännän ohjeet, jota voidaan käyttää pankkikortin numeron, nimen ja tilin avausasiakirjan numeron tietojen aitouden ja yhdenmukaisuuden tarkistamiseen.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [pankkikortin kolmen elementin tarkistus API](https://platform.acedata.cloud/documents/eb9c6677-68db-4549-a207-41f8a1084634) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä pankkikortin numerotiedot, voit saada käsitellyn tuloskuvan. Ensimmäiseksi sinun on yksinkertaisesti välitettävä `bank_card`-kenttä. Voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/3kh6i2.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu pyyntökeho, joka sisältää:

- `bank_card`: käsiteltävä pankkikortin numerotieto, pakollinen parametri.
- `id_card`: tilin avausasiakirjan numero, pakollinen parametri.
- `name`: käyttäjän nimi, pakollinen parametri.
- `cert_type`: tilin avausasiakirjan tyyppi, joka on oltava yhdenmukainen tilin avausasiakirjan kanssa, muuten tarkistusta ei voida suorittaa.
- `encryption`: valinnainen, arkaluontoisten kenttien salausparametri (jos salattua tietoa on lähetettävä).

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/cpvguu.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "result": "0",
  "description": "Tarkistus hyväksytty"
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `result`, tarkistustuloskoodi, maksutiedot seuraavasti.
  - Maksutulokoodit:
    - 0: Tarkistus hyväksytty
    - -1: Tarkistus ei hyväksytty
    - -4: Kortinhaltijan tiedot virheelliset
    - -5: Ei ole avattu kortittomalle maksulle
    - -6: Tämä kortti on takavarikoitu
    - -7: Virheellinen korttinumero
    - -8: Tälle kortille ei ole vastaavaa myöntäjää
    - -9: Korttia ei ole alustettu tai se on lepotilassa
    - -10: Huijauskortti, kortti on nielty
    - -11: Tämä kortti on ilmoitettu kadonneeksi
    - -12: Tämä kortti on vanhentunut
    - -13: Rajoitettu kortti
    - -14: Salasanavirheiden määrä ylittää rajan
    - -15: Myöntäjä ei tue tätä transaktiota
  - Ilmaistulokoodit:
    - -2: Nimen tarkistus ei hyväksytty
    - -3: Pankkikortin numero virheellinen
    - -16: Tarkistuskeskuksen palvelu on ruuhkautunut
    - -17: Tarkistusten määrä ylittää rajan, yritä uudelleen seuraavana päivänä
- `description`, liiketoimintatuloksen kuvaus.

Voit nähdä, että tämän pankkikortin pankkikortin numero, nimi ja tilin avausasiakirjan numerotietojen aitous ja yhdenmukaisuus on hyväksytty.

Jos haluat luoda vastaavan liitännäiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-3e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "bank_card": "***",
  "id_card": "***"
}'
```

Pythonin liitännäiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-3e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "***",
    "bank_card": "***",
    "id_card": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "haku epäonnistui"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
