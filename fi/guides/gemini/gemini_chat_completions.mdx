Google Gemini on erittäin voimakas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain syöttämällä avainsanoja muutamassa sekunnissa. Gemini tarjoaa hämmästyttävää älykästä apua, mikä parantaa merkittävästi ihmisten työtehoa ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa Gemini Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista Gemini-keskustelutoimintoa.

## Hakuprosessi

Jotta voit käyttää Gemini Chat Completion API:a, voit ensin siirtyä [Gemini Chat Completion API](https://platform.acedata.cloud/documents/ae54bf9b-af41-4072-b969-3756b6d66834) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, joka valitaan suoraan alasvetovalikosta. Toinen parametri on `model`, joka tarkoittaa, että valitsemme käyttää Gemini:n virallista mallikategoriaa. Täällä meillä on pääasiassa 6 erilaista mallia, lisätietoja voit katsoa tarjoamastamme mallista. Viimeinen parametri on `messages`, joka on kysymysmerkkien taulukko, joka on taulukko, joka tarkoittaa, että voit ladata useita kysymyksiä samanaikaisesti. Jokainen kysymys sisältää `role` ja `content`, jossa `role` tarkoittaa kysyjän roolia. Olemme tarjonneet kolme identiteettiä: `user`, `assistant`, `system`. Toinen `content` on kysymyksen tarkka sisältö.

Voit myös huomata, että oikealla puolella on vastaava koodin kutsugeneraattori, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosivustojen integroinnissa, sillä se mahdollistaa sanan kerrallaan näyttämisen.

Jos haluat virtaavan palautteen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodin on myös tehtävä vastaavat muutokset virtaavan vastauksen tukemiseksi.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikoodin kutsu:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello,What model are you?"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript

    "stream": true
  })

fetch("https://api.acedata.cloud/gemini/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

## Gemini-3.1 Monimuotoinen malli

Gemini 3.1 Pro on Gemini 3.0 Pro:n päivitetty versio, jonka taustamalli on `gemini-3.1-pro-preview`, ja se tukee myös tekstin, kuvien, videoiden ja muiden monimuotoisten syötteiden käsittelyä, ja sillä on vahvemmat päättely- ja ymmärryskyvyt. Käyttötapa on täysin sama kuin Gemini 3.0 Pro:ssa, tarvitsee vain vaihtaa `model`-parametri `gemini-3.1-pro`:ksi.

Pyyntöesimerkki:

```json
{
  "model": "gemini-3.1-pro",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Mitä kuva sisältää?"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Gemini 3.1 Pro tukee myös videon ymmärtämistä:

```json
{
  "model": "gemini-3.1-pro",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Mitä video sisältää?"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/58yioe.mp4"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Palautusmuoto on sama kuin Gemini 3.0 Pro:ssa, katso yllä olevan Gemini-3.0 monimuotoisen mallin osion selitystä.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
