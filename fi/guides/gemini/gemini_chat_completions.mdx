Google Gemini on erittäin tehokas AI-keskustelujärjestelmä, joka voi tuottaa sujuvia ja luonnollisia vastauksia vain muutamassa sekunnissa, kun syötät kehotteen. Gemini voi tarjota hämmästyttävää älykästä apua, mikä parantaa huomattavasti ihmisten työtehokkuutta ja luovuutta.

Tässä dokumentissa esitellään pääasiassa Gemini Chat Completion API -toimintojen käyttöprosessi, jonka avulla voimme helposti käyttää virallisen Geminin keskustelutoimintoa.

## Hakuprosessi

Jotta voit käyttää Gemini Chat Completion API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisellä hakukerralla saat ilmaista käyttökiintiötä, jota voit kokeilla ilmaiseksi; kun kiintiö ei riitä, voit ladata yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Gemini Chat Completion API →](https://platform.acedata.cloud/documents/gemini-chat-completions)

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymään vastaavat sisällöt kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/f6ksts.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Yksi niistä on `authorization`, jonka voit valita suoraan pudotusvalikosta. Toinen parametri on `model`, `model` tarkoittaa Geminin viralliselta sivustolta valitsemaamme malliluokkaa, ja valittavissa olevat mallit määräytyvät rajapintadokumentaation `model`-luettelon mukaan. Viimeinen parametri on `messages`, `messages` on syöttämiemme kyselylauseiden taulukko. Se on taulukko, mikä tarkoittaa, että useita kyselylauseita voidaan ladata samanaikaisesti. Jokainen kyselylause sisältää `role`- ja `content`-kentät, joista `role` ilmaisee kysyjän roolin. Tarjoamme kolme roolia: `user`, `assistant` ja `system`. Toinen kenttä, `content`, on kysymyksemme tarkka sisältö.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi. Voit kopioida koodin ja suorittaa sen suoraan tai testata sitä napsauttamalla suoraan 「Try」-painiketta.

<p><img src="https://cdn.acedata.cloud/a3mdgy.png" width="400" className="m-auto" /></p>

> **Vinkki**: `gemini-3.x`-sarjan flash on päättelymalli, joka kuluttaa ensin reasoning tokeneita; aseta `max_tokens` yli 512:ksi, muuten saatetaan palauttaa vain tyhjää sisältöä. `gemini-3.8-flash` on tällä hetkellä suositeltu Flash-malli, joka tukee enintään 1 miljoonan Tokenin kontekstia, kuvasyötettä, työkalukutsuja ja suoratoistovastauksia; sitä kutsutaan tällä hetkellä Chat Completions -rajapinnan kautta.

## Kuvan ymmärtäminen (multimodaalinen syöte)

Gemini on natiivi multimodaalinen malli, joka voi suoraan 「katsoa kuvia」. Kun haluat lähettää kuvan, muuta jonkin viestin `content` merkkijonosta **sisältölohkojen taulukoksi** ja sijoita taulukkoon sekä `text`-lohko että `image_url`-lohko — tämä on täysin yhdenmukainen OpenAI:n sekä virallisen Geminin OpenAI-yhteensopivan muodon kanssa.

`image_url.url` tukee kahta kirjoitustapaa:

- **base64 `data:` URI (suositeltu, vakain)**: muoto on `data:<mediatyyppi>;base64,<data>`, esimerkiksi `data:image/jpeg;base64,/9j/4AAQ...`. **Mediatyyppi (MIME) on jo kirjoitettu `data:`-etuliitteeseen**, joten erillistä `media_type`-kenttää ei tarvita eikä sitä ole olemassa.
- **Julkisesti käytettävissä oleva kuvan URL**: esimerkiksi `https://cdn.acedata.cloud/4hfydw.jpg`.

Tuetut kuvatyypit: `png`, `jpeg`, `webp`, `heic`, `heif`.

Python-esimerkkikutsukoodi (base64 data URI):
```python
import base64
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

# 把本地图片读成 base64 data URI
with open("image.jpg", "rb") as f:
    base64_image = base64.b64encode(f.read()).decode("utf-8")
data_uri = f"data:image/jpeg;base64,{base64_image}"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-3.1-pro-preview",
    "messages": [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "请用一句话描述这张图片。"},
                {"type": "image_url", "image_url": {"url": data_uri}}
            ]
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Voit myös välittää suoraan julkisesti käytettävissä olevan kuvan URL-osoitteen:


> 💡 `image_url` hyväksyy vain `url`-kentän (arvo voi olla kuvan URL-osoite tai base64-`data:`-URI) sekä valinnaisen `detail`-kentän. **Älä välitä `media_type`-kenttää** — se on Anthropic Clauden kuvakenttä eikä kuulu OpenAI / Gemini -mallin `image_url`-muotoon.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa tekstin näyttämisen merkki kerrallaan verkkosivulla.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyyntöotsakkeessa olevan `stream ` -parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodiin on tehtävä vastaavat muutokset, jotta se tukee suoratoistovastauksia.

<p><img src="https://cdn.acedata.cloud/o2blmi.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme tulokset rivi kerrallaan.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello,What model are you?"}],
    "stream": True,
    "stream_options": {"include_usage": True}
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kuten voidaan nähdä, vastauksessa on useita `data`-osia, ja `data`-osan `choices` sisältää uusimman vastaussisällön, mikä vastaa yllä esiteltyä sisältöä. `choices` sisältää lisätyn vastaussisällön, jonka perusteella voit integroida sen järjestelmääsi. Lisäksi suoratoistovastauksen päättyminen päätellään `data`-sisällön perusteella: jos sisältö on `[DONE]`, se tarkoittaa, että suoratoistovastaus on kokonaan päättynyt. Palautettu `data`-tulos sisältää useita kenttiä, jotka esitellään seuraavaksi:
- `id`，luo tämän keskustelutehtävän ID:n, jota käytetään tämän keskustelutehtävän yksilölliseen tunnistamiseen.
- `model `，valittu Gemini-virallisen sivuston malli.
- `choices`，Geminin kyselylle antamat vastaustiedot.

Myös JavaScriptiä tuetaan, esimerkiksi Node.js:n suoratoistokutsun koodi on seuraava:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "gemini-2.5-pro",
    messages: [{ role: "user", content: "Hello, what model are you?" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

## Monikierroksinen keskustelu

Jos haluat yhdistää monikierroksisen keskustelutoiminnon, sinun on lähetettävä useita kyselyitä `messages`-kenttään. Useiden kyselyiden tarkka esimerkki näkyy alla olevassa kuvassa:

Python-esimerkkikutsu:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gemini-2.5-pro",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hello there! How can I help you today?"},{"role":"user","content":"What model are you?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Gemini-3.1-multimodaalimalli

`gemini-3.1-pro-preview` on nykyinen Gemini 3.1 Pro -mallin virallinen mallin tunnus, ja se tukee tekstin, kuvien, videoiden sekä muiden multimodaalisten syötteiden käsittelyä. Se soveltuu monimutkaisiin päättely-, koodaus- ja ymmärrystehtäviin.

Pyyntöesimerkki:

```json
{
  "model": "gemini-3.1-pro-preview",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "图片的内容是什么？"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Gemini 3.1 Pro tukee myös videoiden ymmärtämistä:

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos virheitä ilmenee. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.
