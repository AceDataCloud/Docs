Google Gemini on erittäin tehokas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia sekunneissa syöttämällä kehotteen. Tämä dokumentti kuvaa pääasiassa Gemini Generate Content API:n käyttötapoja. Se on Googlen virallinen natiivi API-muoto, joka tukee kahta päätepistettä: `generateContent` ja `streamGenerateContent`.

## Ero Chat Completions API:in

Gemini Generate Content API käyttää Googlen virallista natiivia pyyntömuotoa (`contents`-kenttä) OpenAI-yhteensopivan muodon (`messages`-kenttä) sijaan. Jos käytät jo Google Gemini SDK:ta tai tunnet virallisen API-muodon, voit käyttää tätä APIa suoraan ilman pyyntömuodon muokkaamista.

## Nykyinen tuettu laajuus

Rajapinta hyväksyy teksti-, kuva-, video- ja äänisyötteitä (`inlineData` tai `fileData`), ajattelukonfiguraatioita sekä mukautettuja funktioilmoituksia. Äänitulosteen, sisäänrakennettujen työkalujen ja eksplisiittisen kontekstivälimuistin kaltaisille natiiveille kentille ei vielä ole yhtenäistä saatavuustakuuta; noudata tietyn mallin todellista palautusta.

Kun lähetät äänitiedostoja ja muita tiedostoja käyttämällä `fileData.fileUri`-kenttää, varmista, että tiedosto on suoraan käytettävissä HTTPS:n kautta, ei riipu kirjautumistilasta, ja että allekirjoitetun linkin voimassaoloaika kattaa koko pyynnön käsittelyajan. Ei-suoratoistava äänen analysointi palauttaa tuloksen vasta, kun malli on käsitellyt tiedoston, ja se voi kestää yli 90 sekuntia; asiakkaan tulee asettaa tiedostokoon ja liiketoimintaskenaarion mukaan riittävän pitkä kokonaisaikakatkaisu, jotta yhteyttä ei katkaista palvelimen käsittelyn ollessa yhä käynnissä.

## Hakuprosessi

Ennen Gemini Generate Content API:n käyttöä käy ensin sivulla [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) ja napsauta "获取"-painiketta saadaksesi pyyntöön tarvittavat tunnistetiedot.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle. Ensimmäiseen hakemukseen sisältyy maksuton käyttökiintiö.

## Peruskäyttö

### Ei-suoratoistava（非流式）

Lähetä POST-pyyntö osoitteeseen `/v1beta/models/{model}:generateContent`:

> **Vinkki**：`gemini-3.x`-sarjan flash on ajattelumalli, joka kuluttaa ensin reasoning tokeneita; aseta `generationConfig.maxOutputTokens` yli 512:ksi, muuten se saattaa palauttaa vain tyhjää sisältöä.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Palautustulosesimerkki:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

`usageMetadata`-kentän token-kentät laskutetaan natiivin Gemini-semantiikan mukaisesti:

- `promptTokenCount` sisältää `cachedContentTokenCount`-arvon, välimuistiosuman osa lasketaan välimuistilukemisen hinnalla eikä sitä lasketa uudelleen tavalliseksi syötteeksi.
- `promptTokensDetails` ja `cacheTokensDetails` normalisoidaan `usage.prompt_tokens_details`-kentän `text_tokens`-, `image_tokens`-, `video_tokens`-, `audio_tokens`- sekä vastaaviksi `cached_*`-erittelyiksi. Nämä arvot sisältyvät vastaavasti `prompt_tokens`- ja `cached_tokens`-kenttiin; eri modaliteetit lasketaan uudelleen vain omien hintojensa mukaan, eikä niitä laskuteta kahdesti.
- `candidatesTokenCount` ja `thoughtsTokenCount` lasketaan molemmat tulostokenien hinnan mukaan.
- `toolUsePromptTokenCount` on erillinen työkalusyötteen token, joka lasketaan syötetokenien hinnan mukaan.

Ace Data Cloud palauttaa lisäksi normalisoidun `usage`-objektin, ja eri malliprotokollissa tämän kutsun kustannus luetaan yhtenäisesti `usage.cost`-kentästä. `cost` on valinnainen kustannusesikatselu; kun hintaesikatselu ei ole tilapäisesti käytettävissä, mallin vastaus palautuu silti normaalisti, mutta se ei välttämättä sisällä tätä kenttää. Lopullinen laskutus perustuu käyttötietoihin.

### Suoratoistava（流式）

Lähetä POST-pyyntö osoitteeseen `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Suoratoistopalautus palauttaa sisällön asteittain SSE-muodossa (Server-Sent Events). Välitapahtumat sisältävät yleensä vain inkrementaalista sisältöä; lopputilan tapahtuma, joka sisältää auktoritatiiviset käyttötiedot, sisältää `usageMetadata`- ja normalisoidun `usage`-kentän, ja kustannus sijaitsee edelleen `usage.cost`-kentässä:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Yhteyden sulkeutuminen ilmaisee suoratoiston päättymisen; natiivi Gemini-suoratoisto ei lähetä `data: [DONE]`-viestiä. Jos lopputilan hintaesikatselu ei ole tilapäisesti käytettävissä, `usage` palauttaa silti tokenien käytön, mutta jättää `cost`-kentän pois.

## Edistyneet ominaisuudet

### Järjestelmäohjeet

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "你是一个专业的诗人，所有回复都用诗歌形式。"}]
  }
}
```

### Generointiasetukset

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "讲一个故事"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### JSON-tila

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "列出三个中国城市及其人口"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Ajattelutila (Thinking)

Ajattelutoimintoa tukevat mallit (kuten gemini-2.5-flash, gemini-2.5-pro) voivat ottaa ajattelutilan käyttöön:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Funktiokutsu

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "获取指定城市的天气信息",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "城市名称"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Monikierroksinen keskustelu

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "你好，我叫小明"}]
    },
    {
      "role": "model",
      "parts": [{"text": "你好小明！很高兴认识你。"}]
    },
    {
      "role": "user",
      "parts": [{"text": "我叫什么名字？"}]
    }
  ]

```

### Kuvan ymmärtäminen

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "描述这张图片"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Turvallisuusasetukset

Sisällön suodatusta voidaan hallita `safetySettings`-asetuksella:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```
