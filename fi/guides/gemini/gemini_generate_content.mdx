Google Gemini on erittäin tehokas AI-keskustelujärjestelmä, joka voi tuottaa sujuvia ja luonnollisia vastauksia sekunneissa syöttämällä kehotteen. Tässä dokumentissa kuvataan pääasiassa Gemini Generate Content API:n käyttöä. Kyseessä on Googlen virallinen natiivi API-muoto, joka tukee kahta päätepistettä: `generateContent` ja `streamGenerateContent`.

## Erot Chat Completions API:in

Gemini Generate Content API käyttää Googlen virallista natiivia pyyntömuotoa (`contents`-kenttä) OpenAI-yhteensopivan muodon (`messages`-kenttä) sijaan. Jos käytät jo Google Gemini SDK:ta tai tunnet virallisen API-muodon, voit käyttää tätä API:a suoraan ilman pyyntömuodon muuttamista.

## Nykyinen tuettu laajuus

Rajapinta hyväksyy teksti-, kuva-, video- ja äänisyötteitä (`inlineData` tai `fileData`), ajattelukonfiguraatioita sekä mukautettuja funktioilmoituksia. Äänitulosteille, sisäänrakennetuille työkaluille ja eksplisiittiselle kontekstivälimuistille sekä muille natiiveille kentille ei vielä ole yhtenäistä saatavuustakuuta; tarkista asia tietyn mallin todellisen vastauksen perusteella.

Kun lähetät ääni- ja muita tiedostoja `fileData.fileUri`-osoitteella, varmista, että tiedosto on suoraan käytettävissä HTTPS:n kautta, ei ole riippuvainen kirjautumistilasta ja että allekirjoitetun linkin voimassaoloaika kattaa koko pyynnön käsittelyajan. Ei-suoratoistava äänianalyysi palauttaa tuloksen vasta, kun malli on käsitellyt sen valmiiksi, mikä voi kestää yli 90 sekuntia; asiakkaan tulee asettaa tiedoston koon ja liiketoimintaskenaarion mukaan riittävän pitkä kokonaistaikakatkaisu, jotta yhteyttä ei katkaista palvelimen käsitellessä pyyntöä edelleen.

## Hakuprosessi

Ennen Gemini Generate Content API:n käyttöä käy ensin [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) -sivulla ja napsauta "Hanki"-painiketta saadaksesi pyynnön edellyttämät tunnistetiedot.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle. Ensimmäiseen hakemukseen sisältyy maksuton käyttökiintiö.

## Peruskäyttö

### Non-Streaming（ei-suoratoisto）

Lähetä POST-pyyntö osoitteeseen `/v1beta/models/{model}:generateContent`:

> **Vihje**: `gemini-3.x`-sarjan flash on ajatteleva malli, joka kuluttaa ensin reasoning tokeneita; aseta `generationConfig.maxOutputTokens` vähintään arvoon 512, muuten se voi palauttaa vain tyhjän sisällön.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Palautustulosesimerkki:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

`usageMetadata`-objektin token-kentät laskutetaan Geminin natiivin semantiikan mukaisesti:

- `promptTokenCount` sisältää `cachedContentTokenCount`-arvon; välimuistiosuman osa lasketaan välimuistin lukuhinnalla, eikä sitä lasketa uudelleen tavalliseksi syötteeksi.
- `promptTokensDetails` ja `cacheTokensDetails` normalisoidaan `usage.prompt_tokens_details`-kohdan `text_tokens`-, `image_tokens`-, `video_tokens`-, `audio_tokens`- ja vastaaviksi `cached_*`-erittelyiksi. Nämä arvot sisältyvät vastaavasti `prompt_tokens`- ja `cached_tokens`-arvoihin; eri modaliteetit lasketaan uudelleen vain omien hintojensa mukaan, eikä niistä laskuteta kahdesti.
- `candidatesTokenCount` ja `thoughtsTokenCount` lasketaan molemmat tulostokenien hinnan mukaan.
- `toolUsePromptTokenCount` on erillinen työkalun syötetoken, joka lasketaan syötetokenien hinnan mukaan.

Ace Data Cloud palauttaa lisäksi normalisoidun `usage`-objektin, ja eri malliprotokollissa tämän kutsun kustannus luetaan yhtenäisesti kohdasta `usage.cost`. `cost` on valinnainen kustannusesikatselu; kun hintaesikatselu ei ole tilapäisesti saatavilla, mallivastaus palautuu silti normaalisti, mutta se ei välttämättä sisällä tätä kenttää. Lopullinen laskutus perustuu käyttötietueisiin.

### Streaming（suoratoisto）

Lähetä POST-pyyntö osoitteeseen `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Suoratoistopalautus palauttaa sisältöä asteittain SSE (Server-Sent Events) -muodossa. Välikohtaiset tapahtumat sisältävät yleensä vain inkrementaalisen sisällön; auktoritatiiviset käyttötiedot sisältävä lopputilan tapahtuma sisältää `usageMetadata`- ja normalisoidun `usage`-objektin, ja kustannus sijaitsee edelleen kohdassa `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Yhteyden sulkeutuminen merkitsee virran päättymistä; natiivi Gemini-virta ei lähetä `data: [DONE]`-tapahtumaa. Jos lopputilan hintaesikatselu ei ole tilapäisesti saatavilla, `usage` palauttaa silti tokenien käytön, mutta jättää `cost`-kentän pois.

`gemini-4-carbon` ja `gemini-4-hydrogen` voidaan tällä hetkellä kutsua Chat Completionsin kautta, mutta natiivi Generate Content ei ole toistaiseksi käytettävissä. Virallisissa mallimäärityksissä luetellaan teksti-, kuva-, video-, ääni- ja PDF-syötteet sekä tekstilähdöt; tämä ei tarkoita, että nykyinen alusta olisi varmistanut kaikki syötetyypit. Kun natiivi kutsu palautuu käyttöön, lähetä pyynnöt tämän sivun rajapintasopimuksen mukaisesti ja varmista erikseen tarvittavat syötteet ja parametrit. Virallisen long decode -toiminnon miljoonan Tokenin tuloste ei sisälly nykyiseen rajapintasopimukseen. Molemmat tukevat vain implisiittistä välimuistia, ajattelu-Tokenit hinnoitellaan tulostehinnan mukaan; valmiit hinnoittelusäännöt käyttävät samaa syöte-Tokenin yksikköhintaa kaikille syötemodaliteeteille, ja välimuistiosumat lasketaan välimuistiluvun yksikköhinnalla, katso lisätietoja nykyiseltä hintasivulta.

### Sisäinen ajattelu ja ajatteluyhteenveto

Mallin sisäinen ajattelu ja ajatteluyhteenvedon palauttaminen kutsujalle ovat kaksi erillistä asetusta:

- `thinkingBudget` tai `thinkingLevel` hallitsee mallin sisäistä ajattelubudjettia tai -syvyyttä, ja tuetut kentät sekä arvot riippuvat mallista.
- `includeThoughts` hallitsee, palautetaanko ajatteluyhteenveto, ja oletusarvo on `false`. Kun kenttä jätetään pois tai välitetään `false`, tavalliset JSON- ja SSE-suoratoistovastaukset eivät palauta tekstisisältöä, joka on merkitty muodossa `thought: true`; nämä tekstit säilytetään vain, kun boolean-arvo `true` välitetään nimenomaisesti.

Kun pyynnössä ei ole asetettu `includeThoughts`-kenttää, rajapinta välittää oletuksena arvoa `false` ajatteluasetuksia tukeville generatiivisille malleille välttääkseen pyytämättömät yhteenvedot; asiakkaan nimenomaisesti välittämä arvo, ajattelubudjetti ja taso säilytetään. Kenttää ei lisätä automaattisesti tunnetusti ajatteluasetuksia tukemattomalle mallille `gemini-2.5-flash-image`, eikä luontiasetuksia lisätä myöskään `countTokens`-pyyntöihin.

Yhteenvedon poistaminen käytöstä ei tarkoita sisäisen ajattelun poistamista käytöstä eikä takaa sisäisten ajattelu-tokenien vähenemistä. Jos vastaus sisältää edelleen pyytämätöntä ajattelutekstiä, tavalliset JSON- ja SSE-ulostulot suodatetaan lisäksi siten, että normaali vastaus, allekirjoitus ja todellinen käyttö säilyvät.

Kun yhteenveto halutaan nähdä, ota se nimenomaisesti käyttöön seuraavalla tavalla. Jos malli ei luo käytettävissä olevaa yhteenvetoa, ajattelutekstiä ei välttämättä ole, vaikka se olisi otettu käyttöön:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true
    }
  }
}
```

`thoughtSignature` on myöhempiin kierroksiin tarvittava salattu tila, ei ajatteluyhteenvedon tekstiä, eikä sitä hallita `includeThoughts`-kytkimellä. Allekirjoitus voi sijaita normaalissa vastauksessa, funktiokutsussa tai tyhjässä tekstiosassa (Part); ajattelutekstiä suodatettaessa allekirjoitus ja saman osan muut kentät säilytetään, joten vastauksessa voi edelleen olla osia, jotka sisältävät vain allekirjoituksen ja joiden teksti on tyhjä. Kun monikierroksista historiaa ylläpidetään manuaalisesti, näiden osien järjestys ja allekirjoituksen sijainti on säilytettävä; allekirjoituksia ei saa siirtää eikä yhdistää niitä.

`usageMetadata` ja `usage` kirjaavat edelleen todellisen käytön. Yhteenvedon piilottaminen ei nollaa `thoughtsTokenCount`-arvoa, ja laskutus tapahtuu edelleen todellisen käytön sekä nykyisten hinnoittelusääntöjen perusteella.

Katso Googlen viralliset [ajattelua ja ajatteluyhteenvetoja koskevat ohjeet](https://firebase.google.com/docs/ai-logic/thinking) sekä [ajatteluallekirjoitusten säännöt](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures).

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "北京现在的天气怎么样？"}]
    }
  ],

    {
      "functionDeclarations": [
        {

            "required": ["city"]
```

## Turvallisuusasetukset

Sisällön suodatusta voidaan hallita `safetySettings`-asetuksella:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```
