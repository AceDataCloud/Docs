Google Gemini on erittäin tehokas tekoälypohjainen keskustelujärjestelmä, joka voi tuottaa sujuvia ja luonnollisia vastauksia muutamassa sekunnissa syöttökehotteiden avulla. Tässä dokumentissa kuvataan pääasiassa Gemini Generate Content API:n käyttöä. Kyseessä on Googlen virallinen natiivi API-muoto, joka tukee kahta päätepistettä: `generateContent` ja `streamGenerateContent`.

## Erot Chat Completions API:in verrattuna

Gemini Generate Content API käyttää Googlen virallista natiivia pyyntömuotoa (`contents`-kenttä) OpenAI-yhteensopivan muodon (`messages`-kenttä) sijaan. Jos käytät jo Google Gemini SDK:ta tai tunnet virallisen API-muodon, voit käyttää tätä API:a suoraan muuttamatta pyyntömuotoa.

## Tällä hetkellä tuettu laajuus

Rajapinta hyväksyy teksti-, kuva-, video- ja äänisyötteitä (`inlineData` tai `fileData`), ajattelukonfiguraatioita sekä mukautettuja funktioilmoituksia. Äänitulosteiden, sisäänrakennettujen työkalujen ja eksplisiittisen kontekstivälimuistin kaltaisten natiivien kenttien yhdenmukaista saatavuutta ei vielä voida taata; tarkista asia tietyn mallin todellisesta vastauksesta.

Kun lähetät äänitiedostoja ja muita tiedostoja käyttämällä `fileData.fileUri`-kenttää, varmista, että tiedostoon pääsee suoraan HTTPS:n kautta, se ei ole riippuvainen kirjautumistilasta ja allekirjoitetun linkin voimassaoloaika kattaa koko pyynnön käsittelyajan. Ei-suoratoistettava äänen analysointi palauttaa tuloksen vasta, kun malli on suorittanut käsittelyn, mikä voi kestää yli 90 sekuntia; asiakkaan tulisi asettaa riittävän pitkä kokonaisaikakatkaisu tiedostokoon ja liiketoimintaskenaarion perusteella, jotta yhteyttä ei katkaista palvelimen käsittelyn ollessa edelleen käynnissä.

## Hakuprosessi

Ennen Gemini Generate Content API:n käyttöä käy ensin [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) -sivulla ja hanki pyynnössä tarvittavat tunnistetiedot napsauttamalla "Hanki"-painiketta.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle. Ensimmäinen hakemus sisältää ilmaista käyttökiintiötä.

## Peruskäyttö

### Non-Streaming (ei-suoratoistava)

Lähetä POST-pyyntö osoitteeseen `/v1beta/models/{model}:generateContent`:

> **Vihje**: `gemini-3.x`-sarjan flash on ajattelumalli, joka kuluttaa ensin reasoning tokeneita; aseta `generationConfig.maxOutputTokens` vähintään arvoon 512, muuten se saattaa palauttaa vain tyhjää sisältöä.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Esimerkki palautettavasta tuloksesta:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

`usageMetadata`-objektin token-kentät laskutetaan natiivin Gemini-semanttisen merkityksen mukaisesti:

- `promptTokenCount` sisältää `cachedContentTokenCount`-arvon, ja välimuistiosuman osuus lasketaan välimuistin lukuhinnalla eikä sitä lasketa uudelleen tavalliseksi syötteeksi.
- `promptTokensDetails` ja `cacheTokensDetails` normalisoidaan `usage.prompt_tokens_details`-kohdan `text_tokens`-, `image_tokens`-, `video_tokens`-, `audio_tokens`- ja vastaaviksi `cached_*`-erittelyiksi. Nämä arvot sisältyvät vastaavasti `prompt_tokens`- ja `cached_tokens`-kenttiin; eri modaliteetit lasketaan uudelleen vain omien hintojensa mukaan, eikä niitä laskuteta kahteen kertaan.
- `candidatesTokenCount` ja `thoughtsTokenCount` lasketaan molemmat tulostokenien hinnalla.
- `toolUsePromptTokenCount` on erillinen työkalun syötetoken, joka lasketaan syötetokenien hinnalla.

Ace Data Cloud palauttaa lisäksi normalisoidun `usage`-objektin, ja eri malliprotokollissa tämän kutsun kustannus luetaan yhtenäisesti kohdasta `usage.cost`. `cost` on valinnainen kustannusesikatselu; kun hintaesikatselu ei ole tilapäisesti saatavilla, mallin vastaus palautuu silti normaalisti, mutta se ei välttämättä sisällä tätä kenttää. Lopullinen laskutus perustuu käyttömerkintöihin.

### Streaming (suoratoistava)

Lähetä POST-pyyntö osoitteeseen `/v1beta/models/{model}:streamGenerateContent?alt=sse`:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

Suoratoistopalautus palauttaa sisältöä vaiheittain SSE-muodossa (Server-Sent Events). Välitapahtumat sisältävät yleensä vain inkrementaalista sisältöä; auktoritatiivisen käytön sisältävä lopputilatapahtuma sisältää `usageMetadata`- ja normalisoidun `usage`-kohdan, ja kustannus sijaitsee edelleen kohdassa `usage.cost`:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

Yhteyden sulkeutuminen tarkoittaa suoratoiston päättymistä; natiivi Gemini-suoratoisto ei lähetä `data: [DONE]`-arvoa. Jos lopputilan hintaesikatselu ei ole tilapäisesti saatavilla, `usage` palauttaa silti tokenien käytön, mutta jättää `cost`-kohdan pois.

### Sisäinen ajattelu ja ajattelu-yhteenveto

Mallin sisäinen ajattelu ja ajattelu-yhteenvedon palauttaminen kutsujalle ovat kaksi erillistä asetusta:

- `thinkingBudget` tai `thinkingLevel` hallitsee mallin sisäisen ajattelun budjettia tai syvyyttä; tuetut kentät ja arvot riippuvat mallista.
- `includeThoughts` hallitsee, palautetaanko ajattelu-yhteenveto; oletusarvo on `false`. Kun kenttä jätetään pois tai arvoksi annetaan `false`, tavalliset JSON- ja SSE-suoratoistovastaukset eivät palauta tekstiosia, joihin on merkitty `thought: true`; nämä tekstit säilytetään vain, kun boolean-arvo `true` annetaan nimenomaisesti.

Kun pyynnössä ei aseteta `includeThoughts`-arvoa, rajapinta välittää oletuksena arvon `false` ajatteluasetuksia tukeville generointimalleille, jotta pyydetyt yhteenvetotekstit eivät olisi tarpeettomia; asiakkaan nimenomaisesti antama arvo sekä ajattelubudjetti ja -taso säilytetään. Tunnetulle ajatteluasetuksia tukemattomalle mallille `gemini-2.5-flash-image` tätä kenttää ei lisätä automaattisesti, eikä `countTokens`-pyyntöihin lisätä generointimäärityksiä.

Yhteenvedon poistaminen käytöstä ei tarkoita sisäisen ajattelun poistamista käytöstä eikä takaa sisäisen ajattelun tokenien vähenemistä. Jos vastaus sisältää edelleen pyytämättömiä ajattelutekstejä, tavalliset JSON- ja SSE-ulostulot suodatetaan edelleen niin, että normaali vastaus, allekirjoitukset ja todellinen käyttö säilyvät.

Kun yhteenveto halutaan nähdä, ota se nimenomaisesti käyttöön seuraavasti. Jos malli ei luo käytettävissä olevaa yhteenvetoa, ajattelutekstiä ei välttämättä ole, vaikka se olisi otettu käyttöön:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true
    }
  }
}
```

`thoughtSignature` on seuraavilla kierroksilla tarvittava salattu tila, ei ajattelu-yhteenvetoteksti, eikä sitä hallita `includeThoughts`-kytkimellä. Allekirjoitus voi sijaita normaalissa vastauksessa, funktiokutsussa tai tyhjässä tekstiosassa; ajattelutekstiä suodatettaessa allekirjoitus ja saman osan muut kentät säilytetään, joten vastauksessa voi edelleen olla osia, jotka sisältävät vain allekirjoituksen ja joiden teksti on tyhjä. Kun monikierroksista historiaa ylläpidetään manuaalisesti, näiden osien järjestys ja allekirjoitusten sijainnit tulee säilyttää; älä siirrä allekirjoituksia tai yhdistä niitä.

`usageMetadata` ja `usage` tallentavat edelleen todellisen käytön. Yhteenvetojen piilottaminen ei nollaa `thoughtsTokenCount`-arvoa, ja laskutus lasketaan edelleen todellisen käytön sekä voimassa olevien hinnoittelusääntöjen mukaan.

Katso Googlen viralliset [ajattelua ja ajattelu-yhteenvetoja koskevat ohjeet](https://firebase.google.com/docs/ai-logic/thinking) ja [ajattelu-allekirjoituksia koskevat säännöt](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures).

## Turva-asetukset

Sisällön suodatusta voidaan hallita `safetySettings`-asetuksella:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```
