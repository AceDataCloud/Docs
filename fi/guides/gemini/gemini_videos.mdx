Tässä artikkelissa esitellään Gemini Videos Generation API:n integraatio-ohje. Sen avulla voidaan luoda Google Gemini (omni-flash) -videoita syöttämällä tekstikehote (sekä valinnaisesti viitekuva).

## Hakuprosessi

Käyttääksesi Gemini Videos Generation API:a hae ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Valmistumisen jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäinen hakemus sisältää ilmaista käyttökiintiötä, joten voit kokeilla palvelua ilmaiseksi; jos kiintiö ei riitä, voit ladata yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Peruskäyttö

Tutustutaan ensin peruskäyttötapaan: syötä kehote `prompt`, malli `model` ja kuvasuhde `aspect_ratio`, niin voit luoda vastaavan videon.

Tässä olemme määrittäneet Request Headers -otsakkeet, mukaan lukien:

- `accept`: Missä muodossa haluat vastaanottaa vastaustuloksen; tähän täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumisen avain, jonka voi valita suoraan pudotusvalikosta hakemisen jälkeen.

Lisäksi olemme määrittäneet Request Body -sisällön, mukaan lukien:

- `prompt`: Tekstikehote, joka kuvaa halutun videosisällön, **pakollinen**.
- `model`: Videon luomiseen käytettävä malli; tällä hetkellä tuetaan vain mallia `omni-flash`, ja oletusarvo on `omni-flash`.
- `aspect_ratio`: Luotavan videon kuvasuhde; vaihtoehdot ovat `16:9` (vaakasuuntainen) tai `9:16` (pystysuuntainen), oletusarvo on `16:9`.
- `resolution`: Valinnainen tulostusresoluutio; vaihtoehdot ovat `720p` tai `1080p`, oletusarvo on `720p`.
- `image_urls`: Valinnainen viitekuvalinkkien taulukko, jota käytetään videon luomisen ohjaamiseen; tyhjät kohteet ohitetaan. Kun videoeditointiin käytetään `video_urls`-parametria, tämä parametri on pakollinen (vähintään yksi kuva).
- `video_urls`: Valinnainen viitevideolinkkien taulukko (enintään 1), jota käytetään **videoeditointiin / videoviitteenä**; sen tarjoaminen edellyttää vähintään yhden `image_urls`-kuvan tarjoamista samanaikaisesti.
- `callback_url`: Asynkronisen takaisinsoiton osoite; asetuksen jälkeen API palauttaa välittömästi `task_id`-arvon ja POSTaa tuloksen tähän osoitteeseen tehtävän valmistuessa.
- `async`: Valinnainen; kun arvoksi asetetaan `true`, rajapinta palauttaa välittömästi `task_id`-arvon ilman `callback_url`-osoitetta, minkä jälkeen tulos haetaan kyselyrajapinnan kautta pollaamalla.

Napsauta ”Try”-painiketta testataksesi, jolloin saat seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904-418c13e0605f.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Palautustulos sisältää useita kenttiä, jotka esitellään seuraavaksi:

- `success`: Onnistuiko tämä videonluontipyyntö.
- `task_id`: Tämän videonluontitehtävän ID.
- `trace_id`: Tämän pyynnön seuranta-ID, jota käytetään ongelmien selvittämiseen.
- `data`: Luotujen videotulosten luettelo.
  - `id`: Luodun videon yksilöllinen tunniste.
  - `video_url`: Luodun videon linkkiosoite (`null`, kun `state` on `pending`).
  - `state`: Videonluontitehtävän tila; vaihtoehdot ovat `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: Tämän videon kuvasuhde, joka vastaa pyyntöparametria.
  - `prompt`: Tämän videon luomiseen käytetty kehote.

Synkronisessa vastauksessa ylimmällä tasolla ovat lisäksi kentät `started_at`, `finished_at`, `elapsed` (kesto, sekunteina) sekä `cost` (tämän kerran veloitus, yksikkönä Credit) ja muita kenttiä.

Meidän tarvitsee vain hakea luotu video tuloksessa olevan `data`-kohdan `video_url`-linkkiosoitteen perusteella.

Vastaava CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Kuvasta videoksi

Jos haluat luoda videon viitekuvien pohjalta, voit välittää yhden tai useamman kuvalinkin `image_urls`-kentässä videon luomisen ohjaamista varten:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/assets/examples/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3-5ccb6e83b402.png"
  ]
}
```

## Videoeditointi / viitevideo (syöttövideo, luotu video)

Palvelu tukee suoraan toimintoa ”syötä video, luo uusi video”: välitä yksi viitevideolinkki `video_urls`-kentässä (enintään 1) ja tarjoa **samanaikaisesti** vähintään yksi viitekuva `image_urls`-kentässä (ylävirran pakollinen vaatimus), minkä jälkeen kuvaile `prompt`-kentässä haluttu editointivaikutus (tyylin muuttaminen, kohtauksen vaihtaminen, elementtien lisääminen tai poistaminen jne.).

Seuraavassa on täydellinen todellinen esimerkki — aurinkoisen rantavideon muuttaminen lumisateiseksi talvimaisemaksi säilyttäen samalla rannan, palmujen ja veneen asettelun. Videoeditointi kestää pidempään (tässä esimerkissä noin 6,5 minuuttia), joten se lähetetään asynkronisesti käyttämällä `async: true` -asetusta:
```json
{
  "prompt": "Turn this sunny tropical beach into a snowy winter scene with heavy falling snow and overcast sky; keep the same beach, palm trees and boat layout.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/assets/examples/seedance/dd3dc063-3383-4f29-bedc-e771a096758c-044e05281a2a.mp4"
  ],
  "async": true
}
```

Lähetyksen jälkeen rajapinta palauttaa välittömästi `task_id`:n:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Käytä sen jälkeen tätä `task_id`:tä `id`:nä [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) -rajapinnan pollaamiseen. Kun tehtävä on valmis, saat luodun uuden videon (tämä on tämän esimerkin todellinen palautustulos):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://cdn.acedata.cloud/assets/examples/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284-c5603ef983da.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Turn this sunny tropical beach into a snowy winter scene with heavy falling snow and overcast sky; keep the same beach, palm trees and boat layout."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Jos tarvitset tarkemman tuloksen, voit asettaa `resolution`-arvoksi `1080p` (muut parametrit pysyvät samoina).

> Vihje: Esimerkin syöte- / tulosmedialinkit ovat kaikki todellisia luontituloksia. **Alustan luomilla video- ja kuvalinkeillä on säilytysaika, ja ne lakkaavat toimimasta vanhennuttuaan**, joten lataa ja tallenna ne omaan tallennustilaasi heti tulosten saamisen jälkeen.

> Huomautus: Viitevideoita voi olla enintään 1; ja kun `video_urls` annetaan, vähintään yksi `image_urls` on annettava, muuten palautetaan seuraava parametvirhe:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## Asynkroninen takaisinsoitto

Videon luominen vaatii tietyn verran käsittelyaikaa. Jos et halua pitää pitkää yhteyttä odottamassa, voit välittää `callback_url`:n. Tällöin API palauttaa välittömästi `task_id`:n, ja tehtävän valmistuttua lopputulos POST-lähetetään tähän osoitteeseen:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Välittömästi palautettava tulos on seuraava:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Tehtävän tuloksen kysely

Jos asynkronista takaisinsoittoa on käytetty tai haluat kysellä tehtävän tilaa aktiivisesti, voit kysellä tehtävän uusinta tilaa ja tulosta [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) -rajapinnan (`POST https://api.acedata.cloud/gemini/tasks`) kautta `task_id`:n perusteella. Välitä pyyntökehoon videota luotaessa palautettu `task_id` `id`:nä:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Tehtävän valmistuttua palautettava tulos on suunnilleen seuraavanlainen. `response.data`:n rakenne on sama kuin synkronisessa luomisessa (`state` on `pending` ja `video_url` on `null` luomisen aikana):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "A time-lapse of clouds over snow mountains at sunrise",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "A time-lapse of clouds over snow mountains at sunrise"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Virheenkäsittely

Kun pyynnössä ilmenee ongelma, API palauttaa vastaavan virhekoodin ja kuvauksen. Yleisiä ovat seuraavat:

- `400`: Pyyntöparametrit ovat virheellisiä, esimerkiksi `prompt` puuttuu tai `aspect_ratio`-arvo ei ole sallittu.
- `401`: Todennus epäonnistui, token on virheellinen tai ei vastaa API:a.
- `403`: Saldo ei riitä tai kehoteteksti osuu sisältötarkastukseen ja hylätään.
- `500`: Palvelimen sisäinen virhe tai ylävirran luominen epäonnistui.
