Tässä artikkelissa esitellään Recaptcha2 kuvantunnistus API:n liittämisohjeet, joka voi tunnistaa käyttäjän syöttämän sisällön ja Recaptcha2 vahvistuskuvan, ja lopuksi palauttaa tarvittavien klikkausten koordinaatit, jotta vahvistus voidaan suorittaa.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin haettava vastaavaa palvelua [Recaptcha2 kuvantunnistus API](https://platform.acedata.cloud/documents/b9bf7d07-b178-4881-ae45-a852ec40f53e) -sivulta. Siirry sivulle ja napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joita voit käyttää API:ta ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa. Meidän on otettava Recaptcha2 vahvistuskuva verkkosivustolta. Tässä esimerkkisivuston URL: `https://www.google.com/recaptcha/api2/demo`, ja tarkka sivu on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/3mgkjk.png" width="500" class="m-auto"></p>

Meidän on napsautettava vahvistuskuvan valintaruutua, jotta vahvistuskuva ilmestyy. Yllä olevassa kuvassa keltainen nuoli osoittaa tekstiä, joka on alla olevan `question` arvon sisältö. Ensinnäkin on välttämätöntä välittää yksinkertainen `image` kenttä, joka on itse Recaptcha2 vahvistuskuva. Tämä kuva on yllä olevassa kuvassa punaisella nuolella osoitettu kuva, ja se on myös pakko skaalata standardikokoon (100x100, 300x300, 450x450), jotta palvelu voi tunnistaa kuvatyypin. Kuvan pakkaaminen on sinun itse tehtävä, tässä artikkelissa suositellaan [pakkaussivustoa](https://www.photopea.com/), jossa voit muuttaa kuvan kokoa ja kokoa. Pakkaamisen tulos on esitetty alla olevassa kuvassa:

![](https://cdn.acedata.cloud/l7aotl.png)

Lisäksi on syötettävä vahvistuskuvaan liittyvä tunnistussisältöparametri `question`. Olemme vain tarjonneet alla olevan sisällön taulukon, jota voit käyttää viitteenä:

Yllä olevasta voidaan nähdä, että asetamme parametrin `question` palokunnan hydrantille vastaavaksi `/m/01pns0`, tarkka sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/d53oc3.png" width="500" class="m-auto"></p>

Voimme nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsuavain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, mukaan lukien:

- `image`: Base64-koodattu vahvistuskuva.
- `question`: kysymys ID, tarkista taulukosta, alkaa /m/ -alkuisena.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/bsp8g9.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavanlaisen tuloksen:

```json
{
  "solution": {
    "size": 300,
    "label": "/m/01pns0",
    "confidences": [
      0,
      0.0007,
      1,
      0.0003,
      0.0046,
      1,
      0,
      1,
      0
    ],
    "objects": [
      2,
      5,
      7
    ],
    "type": "multi"
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `solution`, tämän Recaptcha2 vahvistuskuvan tehtävän käsittelyn jälkeen saatu vahvistustulos.
  - `size`, Recaptcha2 vahvistuskuvan koko.
  - `label`, Recaptcha2 vahvistuskuvassa tunnistettu sisältö.
  - `confidences`, Recaptcha2 vahvistuskuvan tunnistusalueen luottamus, alueet alkavat nollasta.
  - `objects`, Recaptcha2 vahvistuskuvassa tunnistettujen sisältöjen alueet, alueet alkavat nollasta.
  - `type`, tämän Recaptcha2 vahvistuskuvan tehtävän tyyppi, useita alueita on `multi`.

Voimme nähdä, että olemme saaneet käsitellyn Recaptcha2 vahvistuskuvan vahvistustuloksen. Ensinnäkin jaamme vahvistuskuvan alueisiin, kuten alla olevassa kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/2d6qhx.png" width="500" class="m-auto"></p>

Voimme nähdä, että alueet alkavat nollasta. Tuloksesta `objects` saimme 2,5,7, ja meidän tarvitsee vain simuloida klikkaus näihin kolmeen alueeseen, jotta vahvistus voidaan hyväksyä.

Lisäksi, jos haluat luoda vastaavan liittämiskoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/recaptcha2' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "/m/01pns0",
  "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX..."
}'
```

Pythonin liittämiskoodi on seuraava:
```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/recaptcha2"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "/m/01pns0",
    "image": "iVBORw0KGgoAAAANSUhEUgAAASoAAAEsCAIAAAD7AWllAAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
