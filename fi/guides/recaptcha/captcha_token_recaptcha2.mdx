Tässä artikkelissa esitellään Recaptcha2-protokollin tunnistus API -liitännän ohjeet, joka mahdollistaa käyttäjille, että heidän ei tarvitse tunnistaa ja klikata Recaptcha2-varmennuskuvia, vaan he voivat yksinkertaisesti lähettää verkkosivuston avaimen, jolloin taustalla tapahtuu automaattinen purku ja vahvistus.

## Hakuprosessi

API:n käyttämiseksi on ensin mentävä [Recaptcha2-protokollin tunnistus API](https://platform.acedata.cloud/documents/597b8f11-26d8-4a1d-9a83-8d33bc4b8af7) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire"-painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joita voit käyttää API:ta ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka on syöttää käsiteltävän varmennuskuvan verkkosivuston URL-osoite, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `website_url`-kenttä. Esimerkkisivustomme on: `https://www.google.com/recaptcha/api2/demo`, ja meidän on saatava `website_key` `website_url` -sivulta. Avaa tämä verkkosivusto, paina F12 siirtyäksesi konsoliin, ja tee sitten globaalihaku Element-sivulla hakusanalla `recaptcha-demo`, jolloin saat seuraavat tulokset:

<p><img src="https://cdn.acedata.cloud/hvx41c.png" width="500" className="m-auto" /></p>

Missä `data-sitekey` -kenttä vastaa yhtä merkkijonoa, joka on `website_key` -arvo. Alla on tarkat parametrin tulokset:

<p><img src="https://cdn.acedata.cloud/8oowyw.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu pyyntökeho, mukaan lukien:

- `website_url`: käsiteltävän varmennuskuvan verkkosivuston URL-osoite.
- `website_key`: verkkosivuston avaimen tunniste Recaptcha2:ssa.

Meidän on ensin avattava F12-konsoli ja suoritettava se manuaalisesti, lopuksi voimme nähdä, että sivusto on lähettänyt POST-pyynnön. Meidän tarvitsee vain tarkastella tämän POST-pyynnön rakennetta, tarkka prosessi on seuraava:

Yllä olevasta kuvasta voidaan päätellä, että tämän POST-pyynnön URL-osoite on: `https://www.google.com/recaptcha/api2/demo`, meidän tarvitsee vain lähettää parametri `g-recaptcha-response`, ja sitten meidän tarvitsee vain siirtää käsitelty token alla olevaan dataan, tokenin vahvistamiseen liittyvä CURL-koodi on seuraava:

```shell
curl 'https://www.google.com/recaptcha/api2/demo' \
  --data-raw 'g-recaptcha-response={token}’
```

Tokenin vahvistamiseen liittyvä Python-koodi on seuraava:

```python
import requests

token = '{token}'

data = {
    'g-recaptcha-response': token,
}

response = requests.post('https://www.google.com/recaptcha/api2/demo', data=data)

if response.status_code:
    print(response.text)

```

Sitten ajamme koodin ja huomaamme, että konsoli näyttää tältä:

Lopuksi olemme läpäisseet Recaptcha2-varmenteen vahvistuksen.

Lisäksi, jos haluat luoda vastaavan integrointikoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/recaptcha2' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
  "website_url": "https://www.google.com/recaptcha/api2/demo"
}'
```

Pythonin integrointikoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki
