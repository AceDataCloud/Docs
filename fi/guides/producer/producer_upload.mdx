---

Producer sallii meidän ladata viittausäänitiedostoja toissijaista luomista varten. Tämä asiakirja selittää liittyvät API-integraatiomenetelmät.

Tässä API:ssa on vain yksi syöttöparametri, nimittäin `audio_url`, joka on julkisesti saatavilla oleva CDN-osoite, joka tukee mp3-päätettä.

Tässä syötämme `audio_url`:n, joka on `https://cdn.acedata.cloud/suno_demo.mp3`, ja se on julkisesti saatavilla oleva CDN-osoite.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Tulokset ovat seuraavat:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Pehmeät naisäänet, kirkas ja iloinen]\n\n[Verse 1]\nAurinko paistaa rannalla\nAallot nauravat kirkkaasti\nSinä ja minä rannalla\nKello pysähtyy\nJäätelö sulaa\nKäsi kädessä kävelemme\nTuuli puhaltaa kevyesti\nSydän lyö jatkuvasti\n\n[Chorus]\nKesä, kesä\nAika pysähtyy tälle päivälle\nNauraen kaikuu\nSininen taivas vierellä"
    "audio_url": "https://storage.googleapis.com/corpusant-app-public/producer/raw/d906da31-87cb-42f5-98df-2fc4969923b1.mp3"
  }
}
```

Voimme nähdä, että `data`-osion `audio_id`-kenttä on ladatun kappaleen ID.

Kun meillä on kappaleen ID, voimme käyttää [Producer Audios Generation API:a](https://platform.acedata.cloud/documents/producer-audios-integration) mukautettujen kappaleiden luomiseen, esimerkiksi `action`-parametrina voidaan käyttää `upload_extend`, ja samalla `audio_id`-parametrina voidaan käyttää palautettua kappaleen ID:tä, jolloin voimme luoda uuden kappaleen viittausäänitiedoston perusteella.
