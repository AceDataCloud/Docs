---
title: "Producer-videoiden lataus-API:n integrointiohje"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer antaa meille mahdollisuuden ladata kappaleisiin liittyviä videoita, ja tämä dokumentti selittää siihen liittyvän API:n integrointimenetelmän.

Tällä API:lla on vain yksi syöttöparametri, `audio_id`, joka on kappaleen yksilöllinen tunniste.

Tässä syötettävä `audio_id` on `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, joka on Producerin luoman kappaleen tunniste.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Tulos on seuraava:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

Kuten voidaan nähdä, `data`-objektin `video_url`-kenttä on ladattavan videon linkki.
