Producer sallii meidän ladata kappaleeseen liittyviä videoita, tämä asiakirja selittää liittyvät API-integraatiomenetelmät.

Tässä API:ssa on vain yksi syöteparametri, joka on `audio_id`, se on kappaleen ainutlaatuinen ID.

Tässä syötämme `audio_id`:n, joka on `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, se on Producerin generoima kappaleen ID.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Tulokset ovat seuraavat:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

Voimme nähdä, että `data`:n `video_url` -kenttä on latauksen video-linkki.
