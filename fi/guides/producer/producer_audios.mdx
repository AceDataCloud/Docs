Tässä artikkelissa esitellään Producer Audios Generation API -integraatio-ohjeet, jonka avulla voidaan luoda Producerin virallista musiikkia syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire"-painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joita voit käyttää API:ta ilmaiseksi.

## Peruskäyttö

Voit syöttää mitä tahansa ajatuksia kappaleista, esimerkiksi jos haluat luoda joululaulun, voit syöttää `a song for Christmas`, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/lg9bb0.png" width="600" class="m-auto"></p>

Tässä olemme asettaneet Request Headers -otsikon, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi Request Body -parametrit sisältävät:

- `action`: tämän musiikin luontitehtävän toiminto, kappaleen luominen on `generate`.
- `model`: käytettävä malli kappaleen luomiseksi, tällä hetkellä pääasiassa: **FUZZ-2.0 Pro**, **FUZZ-2.0**, **FUZZ-2.0 Raw**, **FUZZ-1.1 Pro**, **FUZZ-1.0 Pro**, **FUZZ-1.0**, **FUZZ-1.1**, **FUZZ-0.8**.
- `lyric`: kappaleen sanoitusten sisältö.
- `custom`: käytetäänkö mukautettua tapaa kappaleen luomiseen.
- `prompt`: inspiraatiotilassa käytettävä avainsana.
- `title`: kappaleen otsikkotiedot.
- `audio_id`: viittauskappaleen ID, jota käytetään jatkamiseen/kopioimiseen jne.
- `continue_at`: jatka kappaleen kirjoittamista tietystä sekunnista alkaen.
- `replace_section_start`/`replace_section_end`: korvattavan osan aloitus- ja lopetusaika, yksikkö sekunteina.
- `lyrics_strength`: sanoitusten voimakkuus, joka ilmaisee sanoitusten vaikutusta äänen luomisessa, valittavissa 0-1 välillä, oletusarvo 0.7.
- `sound_strength`: äänen avainsanojen voimakkuus, valittavissa 0.2-1 välillä, oletusarvo 0.7.
- `cover_strength`: cover-voimakkuus 0.2-1 välillä, oletusarvo 1.
- `weirdness`: tyylin erikoisuus, valittavissa 0-1 välillä, oletusarvo 0.5.
- `callback_url`: URL, johon tulokset palautetaan.
- `instrumental`: onko kyseessä sanoitukseton malli.

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämän musiikin luontitehtävän tila.
  - `data`, tämän musiikkitehtävän tulos
    - `id`, tämän musiikin luontitehtävän ID.
    - `sound`, tämän musiikin luontitehtävän avainsana.
    - `seed`, tämän musiikin luontitehtävän siemenarvo.
    - `audio_url`, tämän musiikin luontitehtävän ääni-linkki.
    - `image_url`, tämän musiikin luontitehtävän kansilinkki.

    - `duration`, tämän musiikin kesto.
    - `progress`, tämän musiikkitehtävän edistymisarvo.
    - `model`, tämän musiikin luontitehtävässä käytetty malli.
    - `lyric`, tämän musiikin luontitehtävän sanoitustiedot.

Voimme nähdä, että olemme saaneet haluamamme musiikkitiedot, ja meidän tarvitsee vain käyttää `data`-osion musiikkilinkkiä saadaksemme luodun Producer-musiikin.

Jos haluat luoda vastaavan integraatiokoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/producer/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "FUZZ-2.0 Pro",
  "prompt": "A song for Christmas"
}'
```

## Kappaleen uudelleenlaulaminen

Jos haluat laulaa uudelleen jo luotua kappaletta, voit syöttää edellä luodun kappaleen uudelleenlaulamista varten, seuraavaksi meidän on mukautettava kappaleen luomista sanoitusten ja otsikon mukaan.

Jos haluat jatkaa laulamista itse lataamastasi kappaleesta, voit asettaa parametrin `action` arvoksi `upload_cover` ja syöttää jatkettavan mukautetun ladatun kappaleen ID:n, kappaleen ID:n hankkiminen tapahtuu käyttämällä [Producer Upload API](https://platform.acedata.cloud/documents/7fd2cb52-772e-4cc4-a018-e2626ff6f447) kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/z7r5fd.png" width="500" class="m-auto"></p>

Voit määrittää seuraavat sisällöt:

- action: tämän kappaleen tehtävän toiminta, tällä hetkellä tuetaan: generate, cover, extend, upload_cover, upload_extend, replace_section, swap_vocals, swap_instrumentals, variation, tässä uudelleenlaulamisessa käytetään `cover`-parametria.
- lyric: sanoitusteksti
- title: kappaleen otsikko.
- custom: käytetäänkö mukautettua tilaa luomiseen, oletusarvoisesti false.
- audio_id: uudelleenlaulattavan kappaleen ID.

curl -X POST 'https://api.acedata.cloud/producer/audios' \

## Asynkroninen palautus

Koska Producer Audios Generation API:n generointiaika voi joskus olla suhteellisen pitkä, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: asiakas käynnistää pyynnön, kunhan määrittelee ylimääräisen `callback_url`-kentän, asiakas käynnistää API-pyynnön jälkeen, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, generointitehtävän tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten toimia.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, kehittäjän tulisi korvata se omalla rakentamallaan HTTP-palvelimen URL-osoitteella. Tässä esimerkissä käytetään julkista Webhook-esimerkkisivustoa [https://webhook.site/](https://webhook.site/), avaa tämä sivusto saadaksesi Webhook-URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheen, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki
