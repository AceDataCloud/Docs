[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) on paikallisesti toimiva ohjelmointiaineisto. Se lukee työtilan, kutsuu työkaluja ja suorittaa komentoja, ja käyttää OpenAI-yhteensopivaa Chat Completions -rajapintaa mallin kutsumiseen.

> Tämä artikkeli on tarkoitettu `deepseek-harness-sdk==0.1.0rc6` ja `deepseek-harness-runtime-bin==0.1.0rc6`. Päivitä asiakasohjelma ja suorita alla olevat vain luku -tiedostotestit uudelleen.

## Tukialue

| Projekti       | Määritys                                 |
| -------------- | ---------------------------------------- |
| API Base URL   | `https://api.acedata.cloud/v1`         |
| Malli          | `deepseek-v4-pro`                       |
| Protokolla      | OpenAI-yhteensopiva Chat Completions (virtaava) |
| Kyky           | Teksti, päättelyprosessi, funktiotyökalujen kutsu, paikallinen Bash-työkalusilmukka, käyttötilastot |

Mallihakemisto voi muuttua. Suorita ennen käyttöä Coding Planin erityisavaimella reaaliaikaisen hakemiston tarkistaminen:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY"
```

Varmista, että vastaus sisältää `deepseek-v4-pro`. Älä käytä `deepseek-v4-flash` -mallia tämän artikkelin työkalumallin vastaavana vaihtoehtona; tämän version vahvistuksessa sen monivaiheinen päättelyhistoria ja työkalun toisto eivät ole läpäisseet.

## 1. Valmistele erityisavain

Avaa [Coding Plan -sovellus](https://platform.acedata.cloud/console/applications), siirry ostettuun Coding-sovellukseen, ja luo tai kopioi kyseisen sovelluksen erityinen API-avain. Coding Plan ei käytä yleistä saldoa, muiden sovellusten avaimet eivät voi edustaa pakettioikeuksia.

Aseta avain vain nykyiseen shelliin:

```bash
export ACEDATACLOUD_API_KEY="LIITÄ_TÄHÄN_CODING_AVAIN"
export DEEPSEEK_BASE_URL="https://api.acedata.cloud/v1"
export DEEPSEEK_API_KEY="$ACEDATACLOUD_API_KEY"
```

Älä kirjoita todellista avainta skripteihin, konfiguraatiovarastoihin, terminaalikuvakaappauksiin tai istuntotallennuksiin.

## 2. Luo eristetty työtila

Harnessin pakattu runtime sisältää paikallisia Bash-työkaluja. Ensimmäisessä vahvistuksessa älä osoita todellisiin projekteihin tai pääkansioon; luo kertakäyttöinen hakemisto, jossa ei ole salaisuuksia:

```bash
mkdir -p /tmp/deepseek-harness-demo/workspace
mkdir -p /tmp/deepseek-harness-demo/sessions
printf 'yhteensopivuusliite\n' > /tmp/deepseek-harness-demo/workspace/fixture.txt
python3 -m venv /tmp/deepseek-harness-demo/venv
/tmp/deepseek-harness-demo/venv/bin/pip install \
  "deepseek-harness-sdk==0.1.0rc6"
```

Jos yritysverkko käyttää yksityistä PyPI-peiliä, varmista ensin, että peilissä on sama versio `deepseek-harness-runtime-bin`. Älä käytä `danger-full-access` -oikeuksia tiedostojen pääsyn laajentamiseen; tämän artikkelin esimerkki siirtää vain kertakäyttöisen hakemiston `cwd`:lle.

## 3. Suorita virallinen Python SDK

Tallenna alla oleva sisältö tiedostoon `/tmp/deepseek-harness-demo/run.py`:

```python
import os

from deepseek_harness import DeepSeekHarness

with DeepSeekHarness(
    provider="deepseek-official",
    model="deepseek-v4-pro",
    max_tokens=160,
    cwd="/tmp/deepseek-harness-demo/workspace",
    session_root="/tmp/deepseek-harness-demo/sessions",
    base_url=os.environ["DEEPSEEK_BASE_URL"],
    api_key=os.environ["DEEPSEEK_API_KEY"],
    request_timeout_seconds=180,
) as harness:
    result = harness.run(
        "Lue fixture.txt kerran, ja vastaa sitten tarkasti: sdk-harness-ok",
        session_id="acedatacloud-compat",
    )

print(result.final_response)
print(result.finish_reason)
```

Suorita:

```bash
/tmp/deepseek-harness-demo/venv/bin/python \
  /tmp/deepseek-harness-demo/run.py
```

Odotettu tulos:

```text
sdk-harness-ok
completed
```

Tämä vaihe vahvistaa samanaikaisesti Bearer-todennuksen, `/v1/chat/completions`, SSE:n, päättelysisällön, työkalukutsut ja työkalutulosten palautuksen. Suorittamisen jälkeen voit poistaa `/tmp/deepseek-harness-demo`; jos istuntokansio sisältää projektikontekstia, se tulisi säilyttää saman herkkyystason mukaan kuin koodivarasto.

## Usein kysytyt kysymykset

- **401**: Tarkista, onko `ACEDATACLOUD_API_KEY` viety samaan shelliin, jossa Pythonia ajetaan.
- **403 tai saldoilmoitus**: Varmista, että avain kuuluu nykyiseen Coding-sovellukseen, paketti on edelleen voimassa ja siinä on jäljellä saldoa.
- **Malli ei käytettävissä**: Tarkista uudelleen `/v1/models`, älä arvaa mallin nimeä vanhojen kuvakaappausten perusteella.
- **`reasoning_content` / työkalun toisto-virhe**: Varmista, että SDK/runtime ovat tämän artikkelin kiinteitä versioita ja käytä `deepseek-v4-pro`:ta.
- **Työkalun suoritusmäärät poikkeavat**: Lopeta mahdollisesti sivuvaikutuksia aiheuttavat tehtävät, ja käytä ensin tämän artikkelin vain luku -liitettä nykyisen palvelun version vahvistamiseen.
- **Asennus epäonnistui**: Varmista, että Python 3.10+, käyttöjärjestelmän arkkitehtuuri on tuettuna nykyisellä wheelillä, ja tarkista SDK/runtime -versioiden yhteensopivuus.

## Kykyraja

Tämä artikkeli vahvistaa vain paikallisen Python SDK:n ja Chat Completionsin tekstin ja työkalusilmukan. Kuvia, Files API:ta, `/v1/responses`, `/v1/messages`, etätyötiloja ja isännöityjä hiekkalaatikoita ei sisälly tämän oppaan lupauksiin; työtilan oikeudet ja paikallisten komentojen riskit ovat sen koneen ja konfiguraation vastuulla, jolla Harnessia ajetaan.
