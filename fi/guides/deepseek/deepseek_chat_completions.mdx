DeepSeek on erittäin tehokas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain syöttämällä avainsanoja muutamassa sekunnissa. DeepSeek-V3 erottuu alalla erinomaisella kielentunnistus- ja -tuotantokyvyllään, ja nykyään DeepSeek-V3:ta käytetään laajasti eri toimialoilla ja alueilla, ja sen vaikutus on yhä merkittävämpi. Olipa kyseessä päivittäinen keskustelu, luova kirjoittaminen tai ammatillinen konsultointi ja koodaus, DeepSeek-V3 voi tarjota hämmästyttävää älykästä apua, mikä parantaa merkittävästi ihmisten työtehoa ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa DeepSeek Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista DeepSeekin keskustelutoimintoa.

## Hakuprosessi

Käyttääksesi DeepSeek Chat Completion API:a, voit ensin siirtyä [DeepSeek Chat Completion API](https://platform.acedata.cloud/documents/2d6a9bae-9a70-4aaa-bd72-28e5bd60fa67) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/m9kxkz.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, joka valitaan suoraan alasvetovalikosta. Toinen parametri on `model`, joka tarkoittaa, että valitsemme DeepSeekin virallisen mallikategorian. Täällä meillä on pääasiassa 4 erilaista mallia, lisätietoja voit katsoa tarjoamastamme mallista. Viimeinen parametri on `messages`, joka on kysymysmerkkien taulukko, joka tarkoittaa, että voit ladata useita kysymyksiä samanaikaisesti. Jokainen kysymys sisältää `role` ja `content`, jossa `role` tarkoittaa kysyjän roolia. Tarjoamme kolme identiteettiä: `user`, `assistant`, `system`. Toinen `content` on kysymyksen tarkka sisältö.

Voit myös huomata, että oikealla puolella on vastaava koodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

Yleisesti käytettävät valinnaiset parametrit:

- `max_tokens`: rajoittaa yksittäisen vastauksen enimmäistoken-määrää.
- `temperature`: luo satunnaisuutta, 0-2 välillä, suurempi arvo tarkoittaa hajautetumpaa tulosta.
- `n`: kuinka monta ehdokasvastausta luodaan kerralla.
- `response_format`: palautusmuodon asetukset.

<p><img src="https://cdn.acedata.cloud/93k4xi.png" width="400" className="m-auto" /></p>

Kun kutsu on tehty, huomaamme, että palautustulos on seuraava:

```json

  "object": "chat.completion",

  "usage": {
    "prompt_tokens": 8,

      "refs": null,
      "logprobs": null,
      "finish_reason": "stop",
      "service_tier": null
    }

```

Palautustuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luomisen ID, jota käytetään tämän keskustelutehtävän yksilöimiseen.
- `created`, tämän keskustelutehtävän luomisaika.
- `model`, valittu DeepSeekin virallinen malli.
- `choices`, DeepSeekin antamat vastaukset kysymyksiin.
- `usage`: tämän kysymys-vastausparin token-tilastotiedot.

`choices` sisältää DeepSeekin vastaustiedot, ja sen sisällä `choices` on DeepSeekin vastaustiedot, kuten kuvassa näkyy.

<p><img src="https://cdn.acedata.cloud/0pd4q5.png" width="400" className="m-auto" /></p>

Voit nähdä, että `choices`-kentän `content` sisältää DeepSeekin antaman tarkemman sisällön.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosivustojen integroinnissa, sillä se mahdollistaa sanan kerrallaan näyttämisen.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutokset näkyvät kuvassa, mutta kutsukoodin on myös oltava vastaavasti muutettu, jotta se tukee virtaavaa vastausta.

<p><img src="https://cdn.acedata.cloud/dsoiqw.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "deepseek-v3",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `choices`, DeepSeekin antamat vastaustiedot kysymyssanoihin.

```javascript
const options = {
  method: "post",
  headers: {

    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "deepseek-v3",
    "messages": [{"role":"user","content":"hei"}],
    "stream": true
  })

fetch("https://api.acedata.cloud/deepseek/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
```

## Monivaiheinen keskustelu

Jos haluat liittää monivaiheisen keskustelutoiminnon, sinun on ladattava useita kysymyssanoja `messages`-kenttään, useiden kysymyssanojen tarkka esimerkki on alla olevassa kuvassa:
<p><img src="https://cdn.acedata.cloud/7yyhl4.png" width="400" className="m-auto" /></p>

Python esimerkkikoodin kutsu:

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "deepseek-v3",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Lähettämällä useita kysymyksiä voit helposti toteuttaa monivaiheista keskustelua ja saada seuraavanlaisen vastauksen:

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
