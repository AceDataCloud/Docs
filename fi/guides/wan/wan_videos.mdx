Tässä artikkelissa esitellään Wan Videos Generation API -integraatio-ohjeet, jonka avulla voidaan luoda virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Wan Videos Generation API](https://platform.acedata.cloud/documents/52b0f490-1bbf-4fe5-b60e-96626d333d2c) -sivulle ja haettava vastaavaa palvelua. Kun olet sivulla, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka tarkoittaa, että syötät kehotteen `prompt`, generointitoiminnon `action`, ensimmäisen kehyksen viittauskuvan `image_url` sekä mallin `model`, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `text2video`. Se sisältää pääasiassa kahta toimintoa: tekstistä video ( `text2video` ) ja kuvasta video ( `image2video` ). Sitten meidän on myös syötettävä malli `model`, joka tällä hetkellä sisältää pääasiassa mallit `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v`, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/03gqdz.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsuavain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body:n, mukaan lukien:

- `model`: videon luomiseen käytettävä malli, pääasiassa `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v` mallit.
- `action`: tämän videon luontitehtävän toiminto, joka sisältää pääasiassa kolme toimintoa: tekstistä video ( `text2video` ), kuvasta video ( `image2video` ). Kun kyseessä on tekstistä video, tällä hetkellä vain malli `wan2.6-t2v` on tuettu, ja kun kyseessä on kuvasta video, tällä hetkellä vain mallit `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash` ovat tuettuja.
- `image_url`: kun valitaan kuvasta video -toiminto `image2video`, on pakko ladata ensimmäisen kehyksen viittauskuvan linkki, tällä hetkellä vain mallit `wan2.6-i2v`, `wan2.6-i2v-flash` ovat tuettuja.
- `reference_video_urls`: valinnainen kuvasta video -toiminnossa, määrittää viittausvideon linkin luontia varten, tällä hetkellä vain malli `wan2.6-r2v` on tuettu.
- `size`: määrittää luotavan videon resoluution, muoto on leveys* korkeus. Tämän parametrin oletusarvo ja käytettävät enum-arvot riippuvat model-parametrista, tarkat säännöt löytyvät [virallisesta dokumentaatiosta](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2865250) .
- `duration`: videon luomisen kesto, pääasiassa tuetaan 5, 10, 15.
- `shot_type`: valinnainen, määrittää luotavan videon kuvatyypin, eli onko video yhdestä jatkuvasta kuvasta vai useista vaihdetuista kuvista koostuva. Voimassaoloehdot: vain kun "prompt_extend": true on voimassa. Parametrin prioriteetti: shot_type > prompt. Esimerkiksi, jos shot_type on asetettu "single", vaikka prompt sisältäisi "luo monikuvavideo", malli tuottaa silti yksittäisen kuvan videon, tarkat säännöt löytyvät [virallisesta dokumentaatiosta](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2865250).
- `negative_prompt`: valinnainen, käänteinen kehotus, jota käytetään kuvaamaan sisältöä, jota ei toivota videokuvassa näkyvän, voi rajoittaa videokuvan sisältöä. Tukee sekä suomea että englantia, pituus enintään 500 merkkiä, ylittävä osa katkaistaan automaattisesti. Esimerkkiarvot: alhainen resoluutio, virhe, huonoin laatu, huono laatu, puutteellinen, ylimääräiset sormet, huono mittasuhde jne.
- `resolution`: määrittää luotavan videon resoluutiotason, jota käytetään videon tarkkuuden säätämiseen (kokonaispikselit). Malli skaalaa automaattisesti valitun resoluutiotason mukaan, videon kuvasuhde pyritään pitämään mahdollisimman lähellä syötetyn kuvan img_url:n kuvasuhdetta, lisätietoja löytyy [virallisesta dokumentaatiosta](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2867393).
- `audio_url`: äänitiedoston URL, malli käyttää tätä ääntä videon luomiseen. Käyttötapa löytyy [virallisesta dokumentaatiosta](https://modelstudio.console.alibabacloud.com/ap-southeast-1/?tab=api#/api/?type=model&url=2867393).
- `audio`: onko video äänellinen. Parametrin prioriteetti: audio > audio_url. Kun audio=false, vaikka audio_url on annettu, tulos on silti äänetön video, ja laskutus tapahtuu äänettömän videon mukaan, oletusarvo on true.
- `prompt_extend`: onko kehotteen älykäs muokkaus käytössä. Kun se on käytössä, käytetään suurta mallia syötetyn kehotteen älykkääseen muokkaukseen. Lyhyiden kehotteiden luontitulos paranee huomattavasti, mutta se lisää aikaa, oletusarvo on true.
- `prompt`: kehotus.
- `callback_url`: URL, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/03gqdz.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta, jotta voit testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavat tulokset:

```json
{
  "success": true,
  "video_url": "https://dashscope-result-sh.oss-accelerate.aliyuncs.com/1d/db/20260124/da477ba2/0d2042f9-ba8d-496d-8ab5-182617e28f9e.mp4?Expires=1769349278&OSSAccessKeyId=LTAI5tKPD3TMqf2Lna1fASuh&Signature=SjBa4wRcDVx3SSYu/x7BYCFQk0s=",
  "state": "completed",
  "task_id": "a4bca552-d964-46a1-8ff7-fd922f916582"
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämänhetkisen videon luontitehtävän tila.
- `task_id`, tämänhetkisen videon luontitehtävän ID.
- `video_url`, tämänhetkisen videon luontitehtävän videolinkki.
- `state`, tämänhetkisen videon luontitehtävän tila.

Voit nähdä, että olemme saaneet tyydyttävää videoinformaatiota, ja meidän tarvitsee vain käyttää tuloksessa olevaa `video_url`-videolinkkiä saadaksemme luodun virallisen Wan Videos -videon.

Lisäksi, jos haluat luoda vastaavan integraatiokoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/wan/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "wan2.6-t2v",
  "prompt": "Astronauts shuttle from space to volcano",
  "duration": 5
}'
```

## Kuvasta video -toiminto
Jos haluat luoda videon viittauskuvasta tai -videosta, voit asettaa parametrin `action` arvoksi `image2video` ja syöttää tarvittavan viittauskuvan tai -videon linkin. Seuraavaksi meidän on täytettävä seuraava vaihe, joka vaatii laajennettavia avainsanoja videon mukauttamiseksi, ja voimme määrittää seuraavat sisällöt:

- `model`: Videon luomiseen käytettävä malli, pääasiassa `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`, `wan2.6-t2v` mallit.
- `image_url`: Kun valitaan kuvasta video -toiminto `image2video`, on pakko ladata ensimmäisen kehyksen viittauskuvan linkki, tällä hetkellä vain mallit `wan2.6-i2v`, `wan2.6-i2v-flash` tukevat tätä.
- `reference_video_urls`: Kuvasta video -toiminnassa valinnainen, määrittää viittausvideon linkin luontia varten, tällä hetkellä vain malli `wan2.6-r2v` tukee tätä.
- `prompt`: Avainsanat.

Esimerkin täyttö on seuraava:

<p><img src="https://cdn.acedata.cloud/94l0kk.png" width="500" className="m-auto" /></p>

Kun täyttö on valmis, se luo automaattisesti seuraavan koodin:

<p><img src="https://cdn.acedata.cloud/b5q8tt.png" width="500" className="m-auto" /></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/wan/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "wan2.6-i2v",
    "prompt": "Astronauts shuttle from space to volcano",
    "duration": 5,
    "image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "callback_url": "https://www.baidu.com/"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat tuloksen, kuten alla:

```json
{
  "success": true,
  "video_url": "https://dashscope-result-sh.oss-accelerate.aliyuncs.com/1d/db/20260124/da477ba2/0d2042f9-ba8d-496d-8ab5-182617e28f9e.mp4?Expires=1769349278&OSSAccessKeyId=LTAI5tKPD3TMqf2Lna1fASuh&Signature=SjBa4wRcDVx3SSYu/x7BYCFQk0s=",
  "state": "completed",
  "task_id": "a4bca552-d964-46a1-8ff7-fd922f916582"
}
```

Voit nähdä, että tuloksen sisältö on sama kuin edellä, mikä toteuttaa videon laajennustoiminnon.

## Asynkroninen palautus

Koska Wan Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: Kun asiakas aloittaa pyynnön, se määrittää ylimääräisen `callback_url` -kentän. Kun asiakas tekee API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id` -kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luodun videon tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id` -kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten toimia.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL-osoitteen, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioi tämä URL-osoite, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL-osoitteeseen ja täyttää vastaavat parametrit, tarkat sisällöt ovat kuvassa näkyvät:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten alla:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Odota hetki, niin voit tarkastella luodun videon tulosta osoitteessa `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/zv5u2q.png)

Sisältö on seuraava:

```json
{
  "success": true,
  "video_url": "https://dashscope-result-sh.oss-accelerate.aliyuncs.com/1d/db/20260124/da477ba2/0d2042f9-ba8d-496d-8ab5-182617e28f9e.mp4?Expires=1769349278&OSSAccessKeyId=LTAI5tKPD3TMqf2Lna1fASuh&Signature=SjBa4wRcDVx3SSYu/x7BYCFQk0s=",
  "state": "completed",
  "task_id": "a4bca552-d964-46a1-8ff7-fd922f916582"
}
```

Voit nähdä, että tuloksessa on `task_id` -kenttä, muut kentät ovat samankaltaisia kuin edellä, tämän kentän avulla voit yhdistää tehtävät.

## Virheiden käsittely

Kun kutsut API:a, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
