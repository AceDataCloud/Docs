`POST https://api.acedata.cloud/wan/videos` tukee samanaikaisesti nykyisiä Wan 2.6 -malleja ja `wan3.0-video`-mallia. Wan 3 tunnistaa automaattisesti tekstin, alku- ja loppukehyksen tai viitemateriaalitilan `media`-kentän perusteella.

## Wan 3 tekstistä videoksi

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 tukee 2–30 sekunnin kokonaislukuja tai `-1`-älykestoa, ja resoluutioina ovat `480P`, `720P`, `1080P`.

## Multimediaviitteet

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` tukee:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Alku- ja loppukehystilaa sekä viitemateriaalitilaa ei voi käyttää yhdessä. Viitevideoiden lopullinen laskutus perustuu todellisen syötevideon sekuntien ja onnistuneesti tuotetun videon sekuntien summaan; teksti-, kuva- ja äänisyötteet eivät lisää videosekunteja.

## Viralliset vakiohinnat

| Resoluutio   |      Hinta |
| ----- | ------: |
| 480P  | $0.05/sekunti |
| 720P  | $0.10/sekunti |
| 1080P | $0.20/sekunti |

## Wan 2.6 -yhteensopivuus

Nykyiset `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` ja flash-variantit käyttävät edelleen parametreja, kuten `action`, `image_url`, `reference_video_urls`, ja kutsupolku pysyy muuttumattomana.

## Asynkronisuus ja tulokset

Kun asetetaan `async: true`, `task_id` saadaan välittömästi, ja lopullinen tila haetaan `/wan/tasks`-polun kautta. Onnistuneet videot siirretään AceDataCloud CDN:ään, ja vastauksessa palautetaan todellinen usage ja cost.
