---
title: "Wan tehtäväkysely API"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` käytetään Wan-videoiden tehtävien kyselyyn, joukkokyselyyn tai poistamiseen. Tehtäväkysely ei veloita uudelleen generointimaksuja.

## Yksittäisen tehtävän kysely

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Valmiin tehtävän `response.data.video_url` on pysyvä CDN-osoite; `response.usage` sisältää resoluution, syöttö-/lähtövideon sekuntimäärän, kuvataajuuden ja suhteen; `response.cost` on generointitehtävän laskutus.

## Joukkokysely

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Palauttaa `{ "items": [...], "count": 2 }`. Tehtävän ollessa käynnissä `finished_at` ja lopullinen `response` eivät välttämättä ole vielä saatavilla.

## Tehtävähistorian poistaminen

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Poistaminen vaikuttaa vain tehtävähistorian tietoihin, eikä se poista jo generoituja CDN-videoita.
