Tässä artikkelissa esitellään Flux Images Generation API -integraatio-ohjeet, jonka avulla voidaan luoda Fluxin virallisia kuvia syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Flux Images Generation API](https://platform.acedata.cloud/documents/6b9197c5-7a3f-4878-a43f-7f94e7e66394) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen sinut ohjataan automaattisesti takaisin nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:ta ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka koostuu syötteistä `prompt`, generointitoiminnosta `action` ja kuvan koosta `size`, jotta saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`, ja sitten meidän on syötettävä myös kehotus, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/wz85jt.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, joka sisältää:

- `action`: tämän kuvan generointitehtävän toiminto.
- `size`: kuvan generointituloksen koko.
- `count`: luotavien kuvien määrä, oletusarvo on 1, tämä parametri on voimassa vain kuvan generointitehtävissä, muokkaustehtävissä se ei ole voimassa.
- `prompt`: kehotus.
- `model`: generointimalli, oletusarvo `flux-dev`.
- `callback_url`: URL, johon tulokset palautetaan.

Parametrilla `size` on joitakin erityisiä rajoituksia, jotka jakautuvat pääasiassa `width x height` -kuvasuhteeseen ja `x:y` -kuvasuhteeseen, tarkat tiedot ovat seuraavat:

| Malli                 | Alue                                 |
| ------------------ | ---------------------------------- |
| flux-2-flex        | Tukee kuvasuhdetta x >= 64, joka on 32:n kerroin          |
| flux-2-pro         | Tukee kuvasuhdetta x >= 64, joka on 32:n kerroin          |
| flux-2-max         | Tukee kuvasuhdetta x >= 64, joka on 32:n kerroin          |
| flux-pro-1.1       | Tukee kuvasuhdetta 256 &lt;= x &lt;= 1440, joka on 32:n kerroin |
| flux-dev           | Tukee kuvasuhdetta 256 &lt;= x &lt;= 1440, joka on 32:n kerroin |
| flux-pro-1.1-ultra | Ei tue kuvasuhdetta, tukee kuvasuhteita                     |
| flux-kontext-pro   | Ei tue kuvasuhdetta, tukee kuvasuhteita                     |
| flux-kontext-max   | Ei tue kuvasuhdetta, tukee kuvasuhteita                     |

Viittauskuvasuhteet: "1:1", "16:9", "21:9", "3:2", "2:3", "4:5", "5:4", "3:4", "4:3", "9:16", "9:21",

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/8q7aux.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavan tuloksen:

```json
{
  "success": true,
  "task_id": "226eb763-9eab-4d06-ad57-d59753a03307",
  "trace_id": "089f8b46-0167-4f25-88ee-3c3f88d80e84",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://fal.media/files/lion/NVhtlwwGYQD6HrGaEfrzu_341484fad6d84b21b73f4f8824a3f98a.png",
      "timings": 1752743801
    },
    {
      "prompt": "a white siamese cat",
      "image_url": "https://fal.media/files/monkey/8UEQpFbQCYVOK1wKP3aV0_9bbc26fad64049b18d0244b99ef66ad1.png",
      "timings": 1752743801
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämänhetkisen videon generointitehtävän tila.
- `task_id`, tämänhetkisen videon generointitehtävän ID.
- `trace_id`, tämänhetkisen videon generoinnin jäljitystunnus.
- `data`, tämänhetkisen kuvan generointitehtävän tuloslista.
  - `image_url`, tämänhetkisen kuvan generointitehtävän linkki.
  - `prompt`, kehotus.

Voit nähdä, että olemme saaneet tyydyttävää kuvaa koskevat tiedot, ja meidän tarvitsee vain käyttää tuloksessa `data`-kentän kuva-linkkiä saadaksemme luodun Flux-kuvan.

Lisäksi, jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/flux/images' \
-H 'authorization: Bearer {token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "a white siamese cat",
  "model": "flux-kontext-pro",
  "count": 2
}'
```

## Kuvan muokkaustehtävät

Jos haluat muokata tiettyä kuvaa, sinun on ensin syötettävä `image_url`, joka on muokattavan kuvan linkki. Tällöin `action` tukee vain `edit`-toimintoa, ja voit määrittää seuraavat sisällöt:

- model: tämän muokkaustehtävän käyttämä malli, tällä hetkellä tuetaan `flux-kontext-max` ja `flux-kontext-pro`.
- image_url: ladattava muokattava kuva.

Esimerkkitäyttö on seuraava:

<p><img src="https://cdn.acedata.cloud/jn9da5.png" width="500" className="m-auto" /></p>

Kun täyttö on valmis, se luo automaattisesti seuraavan koodin:

<p><img src="https://cdn.acedata.cloud/6cwxb8.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "edit",
    "prompt": "a white siamese cat",
    "model": "flux-kontext-pro",
    "image_url": "https://cdn.acedata.cloud/ytj2qy.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten seuraavassa:

```json
{
  "success": true,
  "task_id": "2a7979ff-1f77-4380-92c6-a2dc37c3b4c8",
  "trace_id": "732b65c0-48d9-49f7-b568-64e5acffe4c0",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://fal.media/files/monkey/aEUXJZ6Faj9YXUCQVs01Q_af0cea56c558441c9ba8df67b200812d.png",
      "timings": 1752744073
    }
  ]
}
```

Voit nähdä, että luodun efektin on tarkoitus muokata alkuperäistä kuvaa, ja tulos on samanlainen kuin edellä.

## Asynkroninen palautus
Koska Flux Images Generation API:n generointiaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös tukea asynkronisille palautteille.

Kokonaisprosessi on seuraava: Kun asiakas aloittaa pyynnön, se määrittää ylimääräisen `callback_url`-kentän. Kun asiakas tekee API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, kuvatulokset lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulokset voidaan yhdistää ID:n avulla.

Seuraavaksi tarkastellaan esimerkin avulla, miten toimia.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, ja kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL:iin ja täyttää vastaavat parametrit, tarkat tiedot näkyvät kuvassa:

<p><img src="https://cdn.acedata.cloud/wm6caw.png" width="500" className="m-auto" /></p>

Kun napsautat Suorita, huomaat, että saat heti tuloksen, kuten alla:

```
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Odota hetki, niin voit tarkastella kuvan generointituloksia osoitteessa `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/v23lot.png)

Sisältö on seuraava:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://sf-maas-uat-prod.oss-cn-shanghai.aliyuncs.com/outputs/f4f8d407-377a-408a-82d0-427a5a836f09_0.png",
      "seed": 1698551532,
      "timings": {
        "inference": 3.328
      }
    }
  ]
}
```

Voit nähdä, että tuloksessa on `task_id`-kenttä, ja muut kentät ovat samankaltaisia kuin edellä, tämän kentän avulla voit yhdistää tehtävät.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
