Flux Videos API käyttää `POST /flux/videos` -päätepistettä videon luontiin, avainruuduista videon luontiin, videon jatkamiseen ja luonnoksen parantamiseen. `action=generate` (oletus), `mode` valitsee luontitilan; tuloksia kysellään yhtenäisesti olemassa olevalla `POST /flux/tasks` -päätepisteellä.

> Tällä hetkellä Beta. Tekstistä videoksi, kuvasta videoksi, videon jatkaminen ja luonnoksen parantaminen ovat avoinna. HTTP 200 ja tehtävätunnus tarkoittavat vain, että tehtävä on vastaanotettu, ja lopullista tulosta on jatkettava kyselyllä.

## 1. Hanki API Token

1. Rekisteröidy tai kirjaudu sisään [Ace Data Cloud -konsolissa](https://platform.acedata.cloud/console/applications), luo sovellus ja hanki API Token. Yhdellä yleisellä API Tokenilla voi kutsua alustan palveluja; varmista, että sovelluksella on Flux-palvelun kutsuoikeudet ja käytettävissä oleva saldo.
2. Katso paketit ja kunkin toiminnon hinnat [Flux-palvelusivulla](https://platform.acedata.cloud/services/flux?tab=pricing). Kun saldo ei riitä, lataa saldoa [konsolin saldosivulla](https://platform.acedata.cloud/console/coin).
3. Pyynnöt käyttävät `Authorization: Bearer <sinun Tokenisi>`. Token tulee säilyttää palvelinpuolen ympäristömuuttujissa, eikä sitä saa kirjoittaa käyttöliittymäsivuille, julkisiin tietovarastoihin, kuvakaappauksiin tai takaisinsoitto-URL-osoitteisiin.

![Hae API Token konsolista](https://cdn.acedata.cloud/dvc3cg.jpg)

Tämän artikkelin koodi lukee yhtenäisesti ympäristömuuttujan:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| Kohde      | Arvo                                               |
| ------- | ----------------------------------------------- |
| API-juuriosoite | `https://api.acedata.cloud`                     |
| Lähetä videotehtävä  | `POST /flux/videos`                             |
| Kysy olemassa olevaa tehtävää  | `POST /flux/tasks`                              |
| Todennus      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Pyyntömuoto    | `Content-Type: application/json`                |

Täydelliset kentät ja verkkovianmääritys löytyvät kohdasta [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), ja tehtäväkysely kohdasta [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks)。

## 2. Valitse toiminto ja syöte

| action                      | mode            | Syöte                       | Tulos            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（oletusarvo, kun action jätetään pois） | `t2v`           | `prompt`                 | Luo video tekstistä       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Luo video yhdestä tai useammasta avainruudusta |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Jatkaa syötevideon pohjalta      |
| `generate`                  | `draft_enhance` | oman valmiin luonnoksen `draft_task_id` | Parantaa kyseistä luonnosta         |

Luontimalli on `flux-3`, ja `action` on `generate` (oletus). Valitse tekstistä videoksi, kuvasta videoksi, videon jatkaminen tai luonnoksen parantaminen `mode`-asetuksella.

### Yleiset luontiparametrit

| Parametri                 | Kuvaus                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Pakollinen; `t2v`、`i2v`、`v2v` tai `draft_enhance`                       |
| `prompt`           | Pakollinen tavallisessa luonnissa; luonnoksen parantaminen ei salli alkuperäisen kehotteen korvaamista                                        |
| `duration`         | t2v/i2v on 5–20 sekunnin kokonaisluku, v2v on 5–15 sekunnin kokonaisluku tai `auto`; lopullinen tuloskesto voi hieman poiketa pyydetystä arvosta |
| `resolution`       | `hd`、`fhd`、`qhd`、`uhd`; tavallisen luonnin oletus on `hd`, luonnoksen parantamisen oletus on `fhd`              |
| `aspect_ratio`     | `auto`、`21:9`、`2:1`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`9:21`   |
| `draft`            | Luodaanko ensin luonnos; luonnos tukee vain `hd`-tarkkuutta                                           |
| `generate_audio`   | Luodaanko synkronoitu ääni; `false` on kelvollinen arvo, säilytä eksplisiittinen totuusarvo                               |
| `safety_tolerance` | Valinnainen; kokonaisluku väliltä 0–4                                                   |
| `async`            | Suositellaan asetettavaksi arvoon `true`, palauttaa välittömästi alustan tehtävätunnuksen ja kyselee sitten tulosta                                |
| `callback_url`     | Valinnainen; HTTP(S)-osoite, joka vastaanottaa lopullisen JSON-tuloksen; asetettuna myös vastaanotetaan asynkronisesti                        |

Materiaalien URL-osoitteiden täytyy olla palvelun luettavissa. Jos käytetään väliaikaista allekirjoitettua URL-osoitetta, varaa riittävästi voimassaoloaikaa lataamista ja käsittelyä varten. Älä käytä verkkosivun osoitetta kuva- tai videotiedoston osoitteena.

## 3. Tekstistä videoksi: täydellinen testattu pyyntö ja tulos

Seuraava pyyntö suoritettiin onnistuneesti tuotantorajapinnassa ennen hinnanmuutosta 2026-10-02. `action`-kentän pois jättäminen vahvisti oletusluontitoiminnan; `async=true` välttää pitkän HTTP-yhteyden odotuksen.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Vastaanottovastaus (todellinen tehtävätunnus):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Tallenna oman vastauksesi `task_id` ja jatka kyselyä; älä käytä asiakirjan esimerkkitehtävätunnusta muiden tilien tulosten kyselyyn.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

Tehtäväkyselyn palauttama `response`-kenttä sisältää lopullisen liiketoimintatuloksen. Seuraava on tämän onnistuneen käytännön testin `response`, josta on jätetty pois ulommat tehtävämetatiedot. Asiakirjan video-URL on korvattu saman tiedoston kopiolla pitkäaikaisessa esimerkki-CDN:ssä (SHA-256 on sama); todellinen kutsu palauttaa tämän tehtävän oman tulos-URL-osoitteen:
```json
{
  "success": true,
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,
    "mode": "t2v",
    "resolution": "hd",
    "draft": true
  },
  "cost": {
    "amount": 2.6884689277500002,
    "currency": "credit",
    "list_amount": 2.9871876975000005
  }
}
```

[Katso tämän testin video](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4). Mediatarkastus vahvistaa, että tuloste on 1280×704:n, 24 fps:n ja 5,041667 sekunnin MP4-tiedosto, jonka koko on 2 607 276 tavua.

| Vastauskenttä                              | Käyttötarkoitus                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Onnistuiko lopullinen tehtävä; käsittelyvaiheessa palautettu task_id ei tarkoita success=true |
| `task_id`                         | Alustan tehtävätunnus, jota käytetään kyselyyn ja liiketoiminnan idempotenttiin käsittelyyn                      |
| `trace_id`                        | Annetaan tukihenkilöstölle ongelman selvittämistä varten                             |
| `data[].video_url`                | Luettavissa olevan videotuloksen osoite                               |
| `data[].seconds/width/height/fps` | Palvelinpuolen mittaama todellinen tulosteen kesto, koko ja kuvataajuus                       |
| `data[].draft_task_id`            | Luonnoksen parannuksen syötetunnus; näkyy vain, kun palautetaan uudelleenkäytettävä luonnos                  |
| `usage`                           | Lopullinen laskutettava käyttömäärä; älä korvaa todellista seconds-arvoa pyynnön duration-arvolla      |
| `cost.amount`                     | Tästä lopullisesti veloitetut Credits-yksiköt; `currency=credit` ei ole Yhdysvaltain dollari   |
| `cost.list_amount`                | Sovelluskäyttäjän Credits-kulutus ennen kulutusalennusta; palautetaan soveltuvin osin                 |

Tämä on historiallinen testi ennen hinnanmuutosta: `list_amount=2.9871876975` Credits-yksikköä, tilillä oli tuolloin 10 %:n kulutusalennus, ja todellinen `amount=2.68846892775` Credits-yksikköä. Uutta hintaa on laskettu 2026-10-02 noin 6,33 %; sama 5,041667 sekunnin luonnos maksaa nykyhinnalla 2,798125185 Credits-yksikköä (ennen kulutusalennusta), ja jos 10 %:n kulutusalennus on edelleen voimassa, hinta on 2,5183126665 Credits-yksikköä. Historiallisten tehtävien laskuja ei lasketa uudelleen. Muiden tilien paketit ja alennukset voivat olla erilaisia; tämä ei ole kaikille käyttäjille kiinteä Yhdysvaltain dollarimääräinen hinta.

## 4. Kuvasta videoksi: tavallinen ja ajastetuilla avainruuduilla

Seuraavat ovat parametriesimerkkejä; resurssien URL-osoitteet on vaihdettava, eikä tämä ole väite siitä, että esimerkki olisi jo suoritettu onnistuneesti. Kun luonti on valmis, tee kysely yllä olevan prosessin mukaisesti; tulosrakenne on sama.

Yhdelle tai kahdelle kuvalle käytetään tavallista taulukkoa:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

Kun avainruudun ajankohta määritetään, käytä `[sekuntimäärä, kuvan URL]` -paria:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

1–10 avainruutua on sallittu. Ajastetun taulukon on oltava ajallisesti nousevassa järjestyksessä, ajan on oltava 0–20 sekuntia, eikä tavallisia URL-osoitteita ja ajastettuja kohteita saa sekoittaa. Kolmelle tai useammalle tavalliselle avainruudulle on määritettävä eksplisiittisesti duration, autoa ei voi käyttää.

## 6. Ensin luonnos, sitten parannus

1. Luo luonnos käyttämällä `draft=true`, `resolution=hd` ja odota onnistumista.
2. Poimi alustan luonnostunnus lopullisesta `data[0].draft_task_id`:stä.
3. Lähetä parannuspyyntö saman omistajuuden sovellustunnuksilla:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "Korvaa omalla valmiin luonnoksen tunnuksellasi",
  "resolution": "fhd",
  "async": true
}
```

Luonnoksen parannuksessa ei voi välittää parametreja `prompt`, `duration`, `aspect_ratio`, `version`, `generate_audio`, `draft`, `keyframes`, `start_video` alkuperäisen sisällön korvaamiseksi. Luonnosvälimuisti on tilapäinen resurssi, joten paranna se ajoissa; pysyvää säilytystä tai kiinteää säilytyspäivien määrää ei luvata. Muiden kuin oman/nykyisen sovelluksen luonnoksia, keskeneräisiä luonnoksia ja vanhentuneita välimuisteja ei voi käyttää uudelleen. Luonnos ja parannus ovat kaksi tehtävää, ja niistä laskutetaan erikseen onnistumisen jälkeen.

## 7. Pythonin päästä päähän -kutsu

Asenna `requests`, aseta oma Tokenisi ja suorita alla oleva skripti, niin voit suorittaa ”lähetä kerran → kyselysilmukka → tulosta videon URL”. Sekä kyselyissä että verkkouusintayrityksissä tulee käyttää alkuperäistä task_id:tä, jotta maksullisia tehtäviä ei lähetetä uudelleen.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

Verkon aikakatkaisun jälkeen älä pidä tuntematonta tilaa epäonnistumisena ja lähetä pyyntöä heti uudelleen. Jos `task_id` on jo saatu, jatka kyseisen tehtävän kyselyä; tallenna `task_id` ja `trace_id` vianmääritystä varten. Itse kyselyrajapinnasta ei peritä generointimaksua.

## 8. Takaisinkutsujen käyttö

Lisää lähetyksen yhteydessä `callback_url`; tehtävän valmistuttua lopullinen JSON-tulos lähetetään tähän osoitteeseen POST-pyyntönä. Onnistuessaan rakenne on sama kuin edellä mainitussa `response`-objektissa, ja epäonnistuessaan se sisältää `error`-kentän.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Takaisinkutsuosoitteen tulee olla käytettävissä julkisesta verkosta. Käsittele ilmoitus `task_id`:n perusteella idempotentisti sen vastaanottamisen jälkeen ja palauta 2xx mahdollisimman pian; liiketoimintakäsittely voidaan lisätä jonoon. Tämä teksti ei ilmoita, että takaisinkutsulla olisi allekirjoitettua autentikointia: ennen arkaluonteisia toimia, kuten liiketoimintaetujen myöntämistä, tarkista tulos kysymällä samaa tehtävää omalla Tokenillasi. Jos takaisinkutsua ei vastaanoteta, kyselyä voidaan myös jatkaa; älä generoi uudelleen.

## 9. Nykyinen laskutus ja hinnasto

Päivitetty 2026-10-02: tämän video-API:n kaikkien tasojen yksikköhintoja on alennettu noin 6,33 %, kun taas mittaustapa, paketit ja kulutusalennussäännöt pysyvät muuttumattomina. Edellä olevien historiallisten käytännön `response`-vastausten `cost` on tehtävän valmistumishetken laskutus eikä edusta nykyistä hintaa.

Videogeneroinnista laskutetaan **todellisten tulostesekuntien** mukaan. Alla ovat nykyiset Credits-yksikköhinnat ilman tilikohtaisia kulutusalennuksia, ja ne ovat yhdenmukaiset [Flux-hintasivun](https://platform.acedata.cloud/services/flux?tab=pricing) sääntöjen kanssa.

| ------------------ | --- | ---------: |
| t2v / i2v luonnos       | hd  |  0.555 / sekunti |
| v2v luonnos             | hd  |   1.11 / sekunti |
| t2v / i2v / vastaava luonnosparannus | hd  | 1.5725 / sekunti |
| Sama kuin yllä                 | fhd | 2.6825 / sekunti |
| Sama kuin yllä                 | qhd |    3.7 / sekunti |

Muunto Yhdysvaltain dollareiksi: `todellinen kustannus (USD) = cost.amount (Credits) × paketin price / paketin amount`. Lataustasot ja kulutusalennukset vaikuttavat todelliseen hintaan, eikä Creditsejä voi suoraan pitää USD:nä. Epäonnistuneista tehtävistä ei peritä generointimaksua; lopullinen summa määräytyy valmistumistuloksen ja hallintapaneelin kutsutietojen perusteella.

## 10. Usein kysytyt kysymykset ja vianmääritys

| Tilanne                       | Suositus                                                   |
| ------------------------ | ---------------------------------------------------- |
| Parametrivirhe (400)                | Tarkista action=generate, mode, duration ja avainkehysmuoto; älä sekoita eri generointitilojen kenttiä |
| Autentikointivirhe (401)                | Tarkista Bearer Token, sovelluksen oikeudet ja tunnistetietojen voimassaolo                          |
| Sisällön moderoinnin hylkäys (403)              | Muokkaa materiaalia ja kehotetta; älä lähetä niitä toistuvasti muuttamattomina                                    |
| Nopeusrajoitus (429)                  | Vähennä samanaikaisuutta ja yritä uudelleen viiveellä                                            |
| service_unavailable (503) | Nykyinen toiminto ei ole käytettävissä; jo hyväksytyt asynkroniset tehtävät voivat ilmoittaa tästä virheestä lopullisessa `response`-vastauksessa                |
| `task_id` on palautettu, mutta videota ei vielä ole        | Jatka `response`-vastauksen kyselyä; älä pidä HTTP 200:aa generoinnin valmistumisena                     |
| Luonnosta ei voi käyttää uudelleen                   | Varmista oma/nykyinen sovellus, että tehtävä on valmistunut, alkuperäisessä pyynnössä oli `draft=true`, ja tarkista, että väliaikainen välimuisti on yhä voimassa          |

Palautetta antaessasi toimita `task_id`, `trace_id`, pyynnön ajankohta ja peitetyt parametrit; älä lähetä API Tokenia. Lisätapoja on [Flux MCP -integrointioppaassa](https://platform.acedata.cloud/documents/flux-mcp).
