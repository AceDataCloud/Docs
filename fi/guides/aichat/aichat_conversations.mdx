Tiedämme, että markkinoilla on joitakin kysymys-vastaus API:ita, joiden liittäminen ei ole niin helppoa, kuten OpenAI:n Chat Completions API, jossa on `messages`-kenttä. Jatkuvan keskustelun toteuttamiseksi meidän on välitettävä kaikki kontekstitiedot, ja meidän on myös käsiteltävä Tokenin ylitysongelmia.

AceDataCloudin tarjoama AI kysymys-vastaus API on optimoitu edellä mainittuihin tilanteisiin. Se on kapseloitu jatkuvan keskustelun toteuttamiseksi ilman, että meidän tarvitsee huolehtia `messages`-kentän välittämisestä tai Tokenin ylitysongelmista (API käsittelee sen automaattisesti). Se tarjoaa myös keskustelun kysely-, muokkaus- ja muita toimintoja, mikä yksinkertaistaa koko liittämistä merkittävästi.

Tässä asiakirjassa esitellään AI kysymys-vastaus API:n liittymisohjeet.

## Hakuprosessi

Käyttääksesi AI kysymys-vastaus API:a, sinun on ensin mentävä [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API Tokenisi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API Token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla ilmaiseksi; kun määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [AI kysymys-vastaus API →](https://platform.acedata.cloud/documents/aichat-conversations)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka on kysymyksen syöttäminen ja vastauksen saaminen. Sinun tarvitsee vain välittää yksinkertainen `question`-kenttä ja määrittää vastaava malli.

Esimerkiksi kysyttäessä: "What's your name？", voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/xqxda4.png)

Voimme nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä se on `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body:n, mukaan lukien:

- `model`: mallin valinta, kuten suosittu GPT 3.5, GPT 4 jne.
- `question`: kysyttävä kysymys, joka voi olla mitä tahansa puhdasta tekstiä.

Valinnan jälkeen voimme huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/dvkps6.png" width="500" className="m-auto" /></p>

Napsauttamalla "Try" -painiketta voimme testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "answer": "I am an AI language model developed by OpenAI and I don't have a personal name. However, you can call me GPT or simply Chatbot. How can I assist you today?"
}
```

Voimme nähdä, että palautetussa tuloksessa on `answer`-kenttä, joka on kysymyksen vastaus. Voimme syöttää mitä tahansa kysymyksiä ja saada mitä tahansa vastauksia.

Jos et tarvitse mitään monivaiheista keskustelutukea, tämä API voi huomattavasti helpottaa liittämistäsi.

Jos haluat luoda vastaavan liitännäiskoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "What's your name?"
}'
```

Pythonin liitännäiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "question": "What's your name?"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Monivaiheinen keskustelu

Jos haluat liittää monivaiheisen keskustelutoiminnon, sinun on välitettävä ylimääräinen parametri `stateful`, jonka arvo on `true`. Jokaisessa seuraavassa pyynnössä on myös mukana tämä parametri. Kun `stateful`-parametri on välitetty, API palauttaa lisäksi `id`-parametrin, joka edustaa nykyisen keskustelun ID:tä. Jatkossa tarvitsemme vain välittää tämä ID-parametri, jotta voimme helposti toteuttaa monivaiheisen keskustelun.

Seuraavaksi näytämme tarkat toimenpiteet.

Ensimmäisessä pyynnössä asetamme `stateful`-parametrin arvoksi `true` ja välitämme normaalisti `model`- ja `question`-parametrit, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/fn4bi9.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "What's your name?",
  "stateful": true
}'
```

Voimme saada seuraavanlaisen vastauksen:

```json
{
  "answer": "I am an AI language model created by OpenAI and I don't have a personal name. You can simply call me OpenAI or ChatGPT. How can I assist you today?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Toisessa pyynnössä välitämme ensimmäisestä pyynnöstä saadun `id`-kentän parametrina, ja `stateful`-parametri on edelleen asetettu `true`, kysyen "What I asked you just now?", kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/46a6kd.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
  "question": "What I asked you just now?"
}'
```

Tulokset ovat seuraavat:

```json
{
  "answer": "You asked me what my name is. As an AI language model, I do not possess a personal identity, so I don't have a specific name. However, you can refer to me as OpenAI or ChatGPT, the names used for this AI model. Is there anything else I can help you with?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Voimme nähdä, että voimme vastata kysymyksiin kontekstin perusteella.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkoliitännöissä, sillä se mahdollistaa verkkosivujen näyttävän tulokset sana kerrallaan.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikon `accept`-parametrin arvoksi `application/x-ndjson`.

Muutokset näkyvät kuvassa, mutta kutsukoodin on myös oltava vastaavasti muutettu tukemaan virtaavaa vastausta.

![](https://cdn.acedata.cloud/axt1aa.png)

Kun `accept` on muutettu `application/x-ndjson`:ksi, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:
```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/x-ndjson",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "stateful": True,
    "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
    "question": "Hei"
}

response = requests.post(url, json=payload, headers=headers, stream=True)
for line in response.iter_lines():
    print(line.decode())
```

Tulostus näyttää tältä:

```json
{"answer": "Hei", "delta_answer": "Hei", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei!", "delta_answer": "!", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei! Kuinka", "delta_answer": " Kuinka", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei! Kuinka voin", "delta_answer": " voin", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei! Kuinka voin auttaa", "delta_answer": " auttaa", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei! Kuinka voin auttaa sinua", "delta_answer": " sinua", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei! Kuinka voin auttaa sinua tänään", "delta_answer": " tänään", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hei! Kuinka voin auttaa sinua tänään?", "delta_answer": "?", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
```

Voimme nähdä, että vastauksessa `answer` on uusin vastaussisältö, ja `delta_answer` on uusi vastaussisältö, voit yhdistää tulokset järjestelmääsi.

JavaScript on myös tuettu, esimerkiksi Node.js:n virtauskutsun koodi on seuraava:

```javascript
const axios = require("axios");

const url = "https://api.acedata.cloud/aichat/conversations";
const headers = {
  "Content-Type": "application/json",
  Accept: "application/x-ndjson",
  Authorization: "Bearer {token}",
};
const body = {
  question: "Hei",
  model: "gpt-3.5",
  stateful: true,
};

axios
  .post(url, body, { headers: headers, responseType: "stream" })
  .then((response) => {
    console.log(response.status);
    response.data.on("data", (chunk) => {
      console.log(chunk.toString());
    });
  })
  .catch((error) => {
    console.error(error);
  });
```

Java-esimerkkikoodi:

```java
String url = "https://api.acedata.cloud/aichat/conversations";
OkHttpClient client = new OkHttpClient();
MediaType mediaType = MediaType.parse("application/json");
RequestBody body = RequestBody.create(mediaType, "{\"question\": \"Hei\", \"stateful\": true, \"model\": \"gpt-3.5\"}");
Request request = new Request.Builder()
        .url(url)
        .post(body)
        .addHeader("Content-Type", "application/json")
        .addHeader("Accept", "application/x-ndjson")
        .addHeader("Authorization", "Bearer {token}")
        .build();

client.newCall(request).enqueue(new Callback() {
    @Override
    public void onFailure(Call call, IOException e) {
        e.printStackTrace();
    }

    @Override
    public void onResponse(Call call, Response response) throws IOException {
        if (!response.isSuccessful()) throw new IOException("Odottamaton koodi " + response);
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(response.body().byteStream(), "UTF-8"))) {
            String responseLine;
            while ((responseLine = br.readLine()) != null) {
                System.out.println(responseLine);
            }
        }
    }
});
```

Muita kieliä voi muokata erikseen, periaate on sama.

## Mallin esiasetukset

Tiedämme, että OpenAI:n liittyvillä API:lla on vastaava `system_prompt` -käsite, joka asettaa koko mallille esiasetuksen, kuten sen nimen jne. Tämä AI-kysymys-vastaus API paljastaa myös tämän parametrin, jota kutsutaan `preset`, sen avulla voimme lisätä esiasetuksia mallille, käytämme esimerkkiä kokeillaksemme:

Tässä lisäämme ylimääräisen `preset`-kentän, jonka sisältö on `Olet ammattitaiteilija`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/ird6i9.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "question": "Mitä voit auttaa minua?",
  "preset": "Olet ammattitaiteilija"
}'
```

Suoritus tulos on seuraava:

```python
{
    "answer": "Ammattitaiteilijana voin tarjota laajan valikoiman palveluja ja apua riippuen erityistarpeistasi. Tässä on muutamia tapoja, joilla voin auttaa sinua:\n\n1. Räätälöity taide: Jos sinulla on tietty visio tai idea, voin luoda räätälöityä taidetta sinulle. Tämä voi sisältää maalauksia, piirustuksia, digitaalista taidetta tai mitä tahansa muuta medioita, joita suosittelet.\n\n2. Tilatut teokset: Jos sinulla on mielessä tietty aihe tai käsite, voin luoda tilattuja taideteoksia, jotka on räätälöity mieltymyksesi mukaan. Tämä voi olla henkilökohtaista nautintoa varten tai ainutlaatuinen lahja jollekin erityiselle.\n\n3. Taidekonsultaatio: Jos tarvitset ohjausta taiteen valinnassa, sisustussuunnittelussa tai miten esitellä ja näyttää taidetta tilassasi, voin antaa ammattimaista neuvontaa, joka auttaa parantamaan esteettistä aistiasi ja luomaan yhtenäisen ilmeen."
}
```

Voimme nähdä, että kerromme GPT:lle, että hän on robotti, ja kysymme, mitä hän voi tehdä puolestamme, ja hän voi esittää rooliaan robotina vastatakseen kysymyksiin.

## Kuvantunnistus

Tämä AI tukee myös liitteiden lisäämistä kuvantunnistusta varten, siirtämällä vastaavat kuvien linkit `references`-parametrin kautta, esimerkiksi minulla on kuva omenasta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/ht05g0.png)

Kuvan linkki on [https://cdn.acedata.cloud/ht05g0.png](https://cdn.acedata.cloud/ht05g0.png), siirrämme sen suoraan `references`-parametrina, ja on tärkeää huomata, että mallin on valittava visuaalista tunnistusta tukeva malli, tällä hetkellä tuettu on `gpt-4-vision`, joten syöte on seuraava:

![](https://cdn.acedata.cloud/cstrbq.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-4-vision",
  "question": "Kuinka monta omenaa kuvassa on?",
  "references": ["https://cdn.acedata.cloud/ht05g0.png"]
}'
```

Suoritus tulos on seuraava:

```json
{
  "answer": "Kuvassa on 5 omenaa."
}
```

Voimme nähdä, että olemme onnistuneet saamaan vastaavan kuvan vastaustuloksen.

## Verkkokysymykset

Tämä API tukee myös verkkomalleja, mukaan lukien GPT-3.5 ja GPT-4, jotka molemmat tukevat, API:n taustalla on automaattinen internetin haku ja yhteenveto, voimme valita mallin `gpt-3.5-browsing` kokeillaksemme, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/x5i8np.png)

Koodi on seuraava:
```
```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer &#123;token&#125;' \
-H 'content-type: application/json' \
-d '&#123;
  "model": "gpt-3.5-browsing",
  "question": "Mikä on sään New Yorkissa tänään?"
&#125;'
```

Tuloksen näyttö on seuraava:

```json
&#123;
  "answer": "Sää New Yorkissa tänään on seuraava:\n- Nykyinen lämpötila: 16°C (60°F)\n- Korkein: 16°C (60°F)\n- Alin: 10°C (50°F)\n- Kosteus: 47%\n- UV-indeksi: 6/11\n- Auringonnousu: 5:42\n- Auringonlasku: 20:02\n\nOn pilvistä ja mahdollisia satunnaisia sadekuuroja yöllä, ja sateen todennäköisyys on 50%.\nLisätietoja varten voit vierailla [The Weather Channel](https://weather.com/weather/tenday/l/96f2f84af9a5f5d452eb0574d4e4d8a840c71b05e22264ebdc0056433a642c84).\n\nOnko jotain muuta, mitä haluaisit tietää?"
&#125;
```

Voimme nähdä, että se automaattisesti haki tietoa The Weather Channel -sivustolta ja sai sieltä tietoa, ja palautti sitten reaaliaikaiset tulokset.

> Jos mallin vastausten laadulle on suurempia vaatimuksia, voit vaihtaa mallin `gpt-4-browsing`:iksi, jolloin vastausten laatu paranee.
