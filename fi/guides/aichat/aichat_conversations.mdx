Tiedämme, että markkinoilla on joitakin kysymys-vastaus API:ita, joiden liittäminen ei ole niin helppoa, kuten OpenAI:n Chat Completions API, jossa on `messages`-kenttä. Jatkuvan keskustelun toteuttamiseksi meidän on välitettävä kaikki kontekstitiedot, ja meidän on myös käsiteltävä Token-rajojen ylittämiseen liittyviä ongelmia.

AceDataCloudin tarjoama AI kysymys-vastaus API on optimoitu edellä mainittuja tilanteita varten. Se on kapseloitu jatkuvan keskustelun toteuttamiseksi ilman, että meidän tarvitsee huolehtia `messages`-kentän välittämisestä tai Token-rajojen ylittämisestä (API käsittelee sen automaattisesti). Se tarjoaa myös keskustelun kysely-, muokkaus- ja muita toimintoja, mikä yksinkertaistaa koko liittämisprosessia merkittävästi.

Tässä asiakirjassa esitellään AI kysymys-vastaus API:n liittymisohjeet.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [AI kysymys-vastaus API](https://platform.acedata.cloud/documents/59fb1199-6694-4afb-a222-3554d7f7d05a) -sivulle ja haettava vastaavaa palvelua. Kun olet siirtynyt sivulle, napsauta "Acquire"-painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka on kysymyksen syöttäminen ja vastauksen saaminen. Sinun tarvitsee vain välittää yksinkertainen `question`-kenttä ja määrittää vastaava malli.

Esimerkiksi kysyttäessä: "What's your name?", voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/xqxda4.png)

Voimme nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä on täytetty `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body:n, mukaan lukien:

- `model`: mallin valinta, kuten suosittu GPT 3.5, GPT 4 jne.
- `question`: kysyttävä kysymys, joka voi olla mitä tahansa puhdasta tekstiä.

Valinnan jälkeen voimme huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/dvkps6.png" width="500" class="m-auto"></p>

Napsauta "Try"-painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "answer": "I am an AI language model developed by OpenAI and I don't have a personal name. However, you can call me GPT or simply Chatbot. How can I assist you today?"
}
```

Voimme nähdä, että palautetussa tuloksessa on `answer`-kenttä, joka on kysymyksen vastaus. Voimme syöttää mitä tahansa kysymyksiä ja saada mitä tahansa vastauksia.

Jos et tarvitse tukea monivaiheiselle keskustelulle, tämä API voi huomattavasti helpottaa liittämistäsi.

Jos haluat luoda vastaavan liittämiskoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "What's your name?"
}'
```

Pythonin liittämiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "question": "What's your name?"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Monivaiheinen keskustelu

Jos haluat liittää monivaiheisen keskustelutoiminnon, sinun on välitettävä ylimääräinen parametri `stateful`, jonka arvo on `true`. Jokaisessa seuraavassa pyynnössä on myös mukana tämä parametri. Kun `stateful`-parametri on välitetty, API palauttaa lisäksi `id`-parametrin, joka edustaa nykyisen keskustelun ID:tä. Jatkossa tarvitsemme vain välittää tämä ID-parametrina, jotta voimme helposti toteuttaa monivaiheisen keskustelun.

Seuraavaksi esittelemme tarkat toimenpiteet.

Ensimmäisessä pyynnössä asetamme `stateful`-parametrin arvoksi `true` ja välitämme normaalisti `model`- ja `question`-parametrit, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/fn4bi9.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "question": "What's your name?",
  "stateful": true
}'
```

Voimme saada seuraavanlaisen vastauksen:

```json
{
  "answer": "I am an AI language model created by OpenAI and I don't have a personal name. You can simply call me OpenAI or ChatGPT. How can I assist you today?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Toisessa pyynnössä välitämme ensimmäisestä pyynnöstä saadun `id`-kentän parametrina, ja `stateful`-parametri on edelleen asetettu `true`, kysyen "What I asked you just now?", kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/46a6kd.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
  "question": "What I asked you just now?"
}'
```

Tulokset ovat seuraavat:

```json
{
  "answer": "You asked me what my name is. As an AI language model, I do not possess a personal identity, so I don't have a specific name. However, you can refer to me as OpenAI or ChatGPT, the names used for this AI model. Is there anything else I can help you with?",
  "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"
}
```

Voimme nähdä, että voimme vastata kysymyksiin kontekstin perusteella.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkoliitännöissä, sillä se mahdollistaa verkkosivujen näyttävän tuloksia sana kerrallaan.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikon `accept`-parametrin arvoksi `application/x-ndjson`.

Muutokset näkyvät kuvassa, mutta kutsukoodin on myös oltava vastaavasti muutettu tukemaan virtaavaa vastausta.

![](https://cdn.acedata.cloud/axt1aa.png)

Kun `accept` on muutettu `application/x-ndjson`:ksi, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Pythonin esimerkkikutsukoodi:
```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"

headers = {
    "accept": "application/x-ndjson",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-3.5",
    "stateful": True,
    "id": "7cdb293b-2267-4979-a1ec-48d9ad149916",
    "question": "Hello"
}

response = requests.post(url, json=payload, headers=headers, stream=True)
for line in response.iter_lines():
    print(line.decode())
```

Tulostus näyttää tältä:

```json
{"answer": "Hello", "delta_answer": "Hello", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello!", "delta_answer": "!", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How", "delta_answer": " How", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How can", "delta_answer": " can", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How can I", "delta_answer": " I", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How can I assist", "delta_answer": " assist", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How can I assist you", "delta_answer": " you", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How can I assist you today", "delta_answer": " today", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
{"answer": "Hello! How can I assist you today?", "delta_answer": "?", "id": "7cdb293b-2267-4979-a1ec-48d9ad149916"}
```

Voimme nähdä, että vastauksessa `answer` on uusin vastaussisältö, ja `delta_answer` on uusi vastaussisältö, voit yhdistää tulokset järjestelmääsi.

JavaScript on myös tuettu, esimerkiksi Node.js:n virtauskutsun koodi on seuraava:

```javascript
const axios = require("axios");

const url = "https://api.acedata.cloud/aichat/conversations";
const headers = {
  "Content-Type": "application/json",
  Accept: "application/x-ndjson",
  Authorization: "Bearer {token}",
};
const body = {
  question: "Hello",
  model: "gpt-3.5",
  stateful: true,
};

axios
  .post(url, body, { headers: headers, responseType: "stream" })
  .then((response) => {
    console.log(response.status);
    response.data.on("data", (chunk) => {
      console.log(chunk.toString());
    });
  })
  .catch((error) => {
    console.error(error);
  });
```

Java-esimerkkikoodi:

```java
String url = "https://api.acedata.cloud/aichat/conversations";
OkHttpClient client = new OkHttpClient();
MediaType mediaType = MediaType.parse("application/json");
RequestBody body = RequestBody.create(mediaType, "{\"question\": \"Hello\", \"stateful\": true, \"model\": \"gpt-3.5\"}");
Request request = new Request.Builder()
        .url(url)
        .post(body)
        .addHeader("Content-Type", "application/json")
        .addHeader("Accept", "application/x-ndjson")
        .addHeader("Authorization", "Bearer {token}")
        .build();

client.newCall(request).enqueue(new Callback() {
    @Override
    public void onFailure(Call call, IOException e) {
        e.printStackTrace();
    }

    @Override
    public void onResponse(Call call, Response response) throws IOException {
        if (!response.isSuccessful()) throw new IOException("Unexpected code " + response);
        try (BufferedReader br = new BufferedReader(
                new InputStreamReader(response.body().byteStream(), "UTF-8"))) {
            String responseLine;
            while ((responseLine = br.readLine()) != null) {
                System.out.println(responseLine);
            }
        }
    }
});
```

Muita kieliä voi muokata erikseen, periaate on sama.

## Mallin esiasetukset

Tiedämme, että OpenAI:n liittyvillä API:lla on vastaava `system_prompt` -käsite, joka asettaa koko mallille esiasetuksen, kuten sen nimen jne. Tämä AI-kysymys-vastaus API altistaa myös tämän parametrin, nimeltään `preset`, jonka avulla voimme lisätä esiasetuksia mallille. Käytämme esimerkkiä kokeillaksemme:

Tässä lisäämme ylimääräisen `preset`-kentän, jonka sisältö on `You are a professional artist`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/ird6i9.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5",
  "stateful": true,
  "question": "What can you help me?",
  "preset": "You are a professional artist"
}'
```

Suoritus tulos on seuraava:

```python
{
    "answer": "As a professional artist, I can offer a range of services and assistance depending on your specific needs. Here are a few ways I can help you:\n\n1. Custom Artwork: If you have a specific vision or idea, I can create custom artwork for you. This can include paintings, drawings, digital art, or any other medium you prefer.\n\n2. Commissioned Pieces: If you have a specific subject or concept in mind, I can create commissioned art pieces tailored to your preferences. This could be for personal enjoyment or as a unique gift for someone special.\n\n3. Art Consultation: If you need guidance on art selection, interior design, or how to showcase and display art in your space, I can provide professional advice to help enhance your aesthetic sense and create a cohesive look."
}
```

Voimme nähdä, että kerromme GPT:lle, että se on robotti, ja kysymme, mitä se voi tehdä puolestamme, ja se voi esittää rooliaan robotina vastatakseen kysymyksiin.

## Kuvantunnistus

Tämä AI tukee myös liitteiden lisäämistä kuvantunnistusta varten, siirtämällä vastaavat kuvien linkit `references`-parametrin kautta, esimerkiksi minulla on kuva omenasta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/ht05g0.png)

Kuvan linkki on [https://cdn.acedata.cloud/ht05g0.png](https://cdn.acedata.cloud/ht05g0.png), voimme siirtää sen suoraan `references`-parametrina, ja on tärkeää huomata, että mallin on oltava valittava malli, joka tukee visuaalista tunnistusta, tällä hetkellä tuettu on `gpt-4-vision`, joten syöte on seuraava:

![](https://cdn.acedata.cloud/cstrbq.png)

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-4-vision",
  "question": "How many apples in the picture?",
  "references": ["https://cdn.acedata.cloud/ht05g0.png"]
}'
```

Suoritus tulos on seuraava:

```json
{
  "answer": "There are 5 apples in the picture."
}
```

Voimme nähdä, että olemme onnistuneesti saaneet vastaustuloksen vastaavasta kuvasta.

## Verkkokysymykset

Tämä API tukee myös verkkomalleja, mukaan lukien GPT-3.5 ja GPT-4, jotka molemmat tukevat, API:n taustalla on automaattinen internetin haku ja yhteenveto, voimme valita mallin `gpt-3.5-browsing` kokeillaksemme, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/x5i8np.png)

Koodi on seuraava:
```
```shell
curl -X POST 'https://api.acedata.cloud/aichat/conversations' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "model": "gpt-3.5-browsing",
  "question": "Mikä on sään New Yorkissa tänään?"
}'
```

Tuloksen näyttö on seuraava:

```json
{
  "answer": "Sää New Yorkissa tänään on seuraava:\n- Nykyinen lämpötila: 16°C (60°F)\n- Korkein: 16°C (60°F)\n- Alin: 10°C (50°F)\n- Kosteus: 47%\n- UV-indeksi: 6/11\n- Auringonnousu: 5:42\n- Auringonlasku: 20:02\n\nOn pilvistä ja mahdollisia satunnaisia sadekuuroja yöllä, ja sateen todennäköisyys on 50%.\nLisätietoja varten voit vierailla [The Weather Channel](https://weather.com/weather/tenday/l/96f2f84af9a5f5d452eb0574d4e4d8a840c71b05e22264ebdc0056433a642c84).\n\nOnko jotain muuta, mitä haluaisit tietää?"
}
```

Voimme nähdä, että se automaattisesti haki tietoa The Weather Channel -sivustolta ja sai sieltä tietoa, ja palautti sitten reaaliaikaisen tuloksen.

> Jos mallin vastausten laadulle on suurempia vaatimuksia, voit vaihtaa mallin `gpt-4-browsing`:ksi, jolloin vastausten laatu paranee.
