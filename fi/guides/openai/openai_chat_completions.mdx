OpenAI ChatGPT on erittäin tehokas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain syöttämällä kehotussanoja muutamassa sekunnissa. ChatGPT erottuu alalla erinomaisella kielentunnistus- ja -tuotantokyvyllään, ja nykyään ChatGPT:tä käytetään laajasti eri toimialoilla ja alueilla, ja sen vaikutus on yhä merkittävämpi. Olipa kyseessä päivittäinen keskustelu, luova kirjoittaminen tai ammatillinen konsultointi, koodaus, ChatGPT voi tarjota hämmästyttävää älykästä apua, mikä parantaa merkittävästi ihmisten työtehoa ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa OpenAI Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista OpenAI ChatGPT:n keskustelutoimintoa.

## Hakuprosessi

Käyttääksesi OpenAI Chat Completion API:a, voit ensin siirtyä [OpenAI Chat Completion API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" class="m-auto"></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, jonka voit valita suoraan avattavasta valikosta. Toinen parametri on `model`, joka tarkoittaa, että valitsemme OpenAI ChatGPT:n virallisen mallikategorian. Täällä meillä on pääasiassa 20 erilaista mallia, tarkemmat tiedot voit katsoa tarjoamastamme mallista. Viimeinen parametri on `messages`, joka on kysymysmerkkien taulukko, joka tarkoittaa, että voit ladata useita kysymyksiä samanaikaisesti. Jokainen kysymys sisältää `role` ja `content`, jossa `role` tarkoittaa kysyjän roolia. Olemme tarjonneet kolme identiteettiä: `user`, `assistant`, `system`. Toinen `content` on kysymyksen tarkka sisältö.

Voit myös huomata, että oikealla puolella on vastaava koodin generointi, jonka voit kopioida ja suorittaa suoraan tai voit napsauttaa "Try" -painiketta testataksesi.

Yleisesti käytettävät valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen enimmäistoken-määrää.
- `temperature`: luo satunnaisuutta, 0-2 välillä, suurempi arvo tarkoittaa hajautetumpaa tulosta.
- `n`: kuinka monta ehdokasvastausta luodaan kerralla.
- `response_format`: palautusmuodon asetukset.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosovellusten integroinnissa, sillä se mahdollistaa verkkosivujen näyttävän tuloksia sana kerrallaan.

Jos haluat virtaavan palautteen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutokset näkyvät kuvassa, mutta kutsukoodin on myös muututtava, jotta se tukee virtaavaa vastausta.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" class="m-auto"></p>

Kun `stream` on muutettu arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Integrointi OpenAI-Python

OpenAI Chat Completion API -palvelun yläpuolella on virallinen OpenAI-palvelu, tarkempia tietoja voi katsoa virallisesta [OpenAI-Python](https://github.com/openai/openai-python) -sivustosta, tässä artikkelissa esitellään lyhyesti, kuinka käyttää virallisesti tarjottua palvelua.

1. Ensinnäkin, sinun on rakennettava paikallinen `Python`-ympäristö, tämä prosessi voidaan etsiä Googlella.
2. Asenna kehitysympäristö, kuten VSCode-editori.
3. Määritä `OpenAI`-ympäristömuuttujat.

- Luo projektikansioon tiedosto nimeltä `.env` ja tallenna se.
- `.env`-tiedoston sisältö:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Muistutuksena: jos käytät virallista OpenAI-avainta, älä käytä tätä osoitetta.
```

Korvaa `sk-xxx` omalla avaimellasi. `OPENAI_BASE_URL` on OpenAI:n välityspalvelun käyttöliittymä.

4. Asenna projektin riippuvuudet

```shell
pip install openai
```

Mac OS:ssä komento on:

```shell
pip3 install openai
```

5. Luo esimerkkilähdekooditiedosto

Oletetaan, että olemme luoneet esimerkkikoodin `index.py`, jonka sisältö on seuraava:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Visuaalinen malli

gpt-4o on OpenAI:n kehittämä monimodaalinen suuri kielimalli, joka lisää visuaalisen ymmärryksen kykyjä GPT-4:n pohjalta. Tämä malli voi käsitellä samanaikaisesti tekstin ja kuvien syötteitä, mahdollistaen monimuotoisen ymmärryksen ja generoinnin.

gpt-4o-mallin tekstinkäsittely on sama kuin edellä mainitussa peruskäytössä, seuraavassa esitellään lyhyesti, kuinka käyttää mallin kuvankäsittelykykyjä.

gpt-4o-mallin kuvankäsittelykykyjä käytetään pääasiassa lisäämällä alkuperäiseen `content`-sisältöön `type`-kenttä, jonka avulla voidaan tietää, onko ladattu tekstiä vai kuvaa, jolloin voidaan käyttää gpt-4o-mallin kuvankäsittelykykyjä. Seuraavassa käsitellään Curl- ja Python-menetelmiä tämän toiminnon kutsumiseen.

- Curl-skripti

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Python-skripti
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
