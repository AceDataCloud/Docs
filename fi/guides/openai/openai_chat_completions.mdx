OpenAI ChatGPT on erittäin tehokas tekoälypohjainen keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain muutamassa sekunnissa, kun syötät kehotteen. ChatGPT erottuu alalla poikkeuksellisilla kielen ymmärtämis- ja tuottamiskyvyillään. Nykyään ChatGPT:tä on jo laajalti käytetty eri toimialoilla ja aloilla, ja sen vaikutus kasvaa yhä merkittävämmäksi. Olipa kyse päivittäisistä keskusteluista, luovasta kirjoittamisesta, ammattimaisesta konsultoinnista tai ohjelmointikoodista, ChatGPT voi tarjota hämmästyttävää älykästä apua, joka parantaa huomattavasti ihmisten työtehokkuutta ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa OpenAI Chat Completion API -toimintojen käyttöprosessi, jonka avulla voimme helposti käyttää virallisen OpenAI ChatGPT:n keskusteluominaisuutta.

Alusta veloittaa yhteensopivien mallipyyntöjen käytöstä kyseisen mallin syötön, tulosteen ja välimuistin käytön perusteella. Chat Completionsin `prompt_tokens` sisältää välimuistissa olevat tokenit, ja raportoitu välimuistiosa laskutetaan vastaavan välimuistihinnan mukaisesti; rajapintamuodon vaihtaminen ei muutu kiinteämääräiseksi laskutukseksi. Maksut perustuvat konsolin nykyisiin mallihintoihin ja vastauksen `usage.cost`-arvoon.

## GPT-6.1 Terra

Valitse tämä malli käyttämällä `model: "gpt-6.1-terra"`. Se tukee teksti- ja kuvasyötettä sekä suoratoistotulostetta; kutsu funktiotyökalut ja strukturoitu tuloste tämän rajapinnan parametrimuodon mukaisesti. Päättelytasot tukevat arvoja `low`, `medium`, `high`, `xhigh` ja `max`, ja on suositeltavaa aloittaa arvolla `reasoning_effort: "low"`; arvoja `none` tai `minimal` ei tueta. Kun syöte ylittää 272 000 tokenia, sovelletaan pitkän kontekstin hinnoittelua. Todelliset kustannukset perustuvat konsolin nykyisiin hintoihin ja vastauksessa ilmoitettuun käyttöön.

## GPT-6.1 Sol

Valitse tämä malli käyttämällä `model: "gpt-6.1-sol"`. Se tukee suoratoistotulostetta, funktiokutsuja, strukturoitua tulostetta ja kuvasyötettä. Ensimmäisen avausviikon aikana se on saatavilla vain varmennetuille ACE T1+ -haltijoille (vähintään 100 000 ACE) tai valtuutetuille käyttäjille; tarkka avautumisaika määräytyy konsolin käyttöoikeusilmoituksen mukaan.

Päättelytasot tukevat arvoja `low`, `medium`, `high`, `xhigh` ja `max`; arvoja `none` tai `minimal` ei toistaiseksi tueta. On suositeltavaa aloittaa arvolla `reasoning_effort: "low"`. Kun syöte ylittää 272 000 tokenia, koko pyyntöön sovelletaan pitkän kontekstin hinnoittelua, ja kustannukset perustuvat konsolin nykyisiin hintoihin.

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymään vastaavat tiedot kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Yksi niistä on `authorization`, joka voidaan valita suoraan pudotusvalikosta. Toinen parametri on `model`; `model` tarkoittaa valitsemaamme OpenAI ChatGPT:n virallisen sivuston malliluokkaa. Tässä meillä on pääasiassa 20 mallia, ja lisätietoja voi katsoa tarjoamistamme malleista. Viimeinen parametri on `messages`; `messages` on syöttämiemme kyselylauseiden taulukko. Se on taulukko, mikä tarkoittaa, että useita kyselylauseita voidaan lähettää samanaikaisesti. Jokainen kyselylause sisältää `role`- ja `content`-kentät, joista `role` ilmaisee kysyjän roolin. Tarjoamme kolme roolia: `user`, `assistant` ja `system`. Toinen, `content`, on kysymyksemme tarkka sisältö.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi. Voit kopioida koodin ja suorittaa sen suoraan tai testata painamalla suoraan ”Try”-painiketta.

Yleisesti käytetyt valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen tokenien enimmäismäärää.
- `temperature`: generoinnin satunnaisuus, välillä 0–2; mitä suurempi arvo, sitä hajautuneempi.
- `n`: kuinka monta ehdokasvastausta generoidaan kerralla.
- `response_format`: palautusmuodon asetus.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa verkkosivulle sana kerrallaan näkyvän efektin.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyynnön otsikon `stream ` -parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodia on muutettava vastaavasti, jotta se tukee suoratoistovastausta.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan. Kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme tulokset rivi kerrallaan.

Python-esimerkkikutsukoodi:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Myös JavaScript on tuettu, esimerkiksi Node.js:n suoratoistokutsun koodi on seuraava:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");

MediaType mediaType = "application/json; charset=utf-8".toMediaType();
```

## OpenAI-Python-integrointi

OpenAI Chat Completion API on yhteensopiva virallisen OpenAI-rajapinnan kanssa, ja se voidaan integroida suoraan virallisella SDK:lla [OpenAI-Python](https://github.com/openai/openai-python). Tässä artikkelissa esitellään lyhyesti käyttötapa.

1. Ensin täytyy määrittää paikallinen `Python`-ympäristö; tätä prosessia voi hakea Googlesta.
2. Lataa ja asenna kehitysympäristö, esimerkiksi VSCode-editori.
3. Määritä `OpenAI`-ympäristömuuttujat.

- Luo projektikansioon `.env`-niminen tiedosto ja tallenna se
- `.env`-tiedoston sisältö:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Muistutus vielä kerran: jos käytät virallisen OpenAI-sivuston avainta, älä käytä tätä osoitetta.
```

Korvaa `sk-xxx` omalla avaimellasi. `OPENAI_BASE_URL` on OpenAI:n välityspalvelurajapinnan käyttöosoite.

4. Asenna projektin tarvitsemat paketit

```shell
pip install openai
```

Mac OS:ssä komento on:

```shell
pip3 install openai
```

5. Luo esimerkkilähdekooditiedosto

Oletetaan, että luomme esimerkkikoodin `index.py`, jonka tarkka sisältö on seuraava:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Visuaalinen malli

gpt-4o on OpenAI:n kehittämä multimodaalinen suuri kielimalli, joka on saanut GPT-4:ään perustuvan visuaalisen ymmärryskyvyn. Tämä malli voi käsitellä samanaikaisesti teksti- ja kuvasyötteitä sekä toteuttaa modaliteettien välisen ymmärryksen ja generoinnin.

gpt-4o-mallin tekstinkäsittelyn käyttö on yhdenmukaista yllä kuvatun peruskäytön kanssa. Seuraavaksi esitellään lyhyesti, kuinka mallin kuvankäsittelyominaisuuksia käytetään.

gpt-4o-mallin kuvankäsittelyominaisuuksia käytetään pääasiassa lisäämällä `content`-sisältöön `type`-kenttä. Tämän kentän avulla voidaan tietää, onko lähetetty tekstiä vai kuva, ja siten käyttää gpt-4o-mallin kuvankäsittelyominaisuuksia. Seuraavaksi kuvataan pääasiassa kaksi tapaa kutsua tätä toimintoa: Curl ja Python.

- Curl-komentosarjatapa

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

```python
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
```

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos virhe ilmenee. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Luvaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella meni jokin pieleen.

### Esimerkki virhevastaus

```
  "success": false,

    "code": "api_error",
    "message": "fetch failed"
  },

}
```
