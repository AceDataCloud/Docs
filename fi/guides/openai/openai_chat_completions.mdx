OpenAI ChatGPT on erittäin tehokas tekoälypohjainen keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain muutamassa sekunnissa, kun sille annetaan kehote. ChatGPT erottuu alalla erinomaisilla kielen ymmärtämis- ja tuottamiskyvyillään. Nykyään ChatGPT:tä käytetään jo laajasti eri toimialoilla ja aloilla, ja sen vaikutus on yhä merkittävämpi. Olipa kyse päivittäisistä keskusteluista, luovasta kirjoittamisesta, ammattimaisesta konsultoinnista tai ohjelmointikoodista, ChatGPT voi tarjota hämmästyttävää älykästä apua, joka parantaa huomattavasti ihmisten työtehokkuutta ja luovuutta.

Tässä dokumentissa esitellään pääasiassa OpenAI Chat Completion API -toimintojen käyttöprosessi, jonka avulla voimme helposti käyttää virallisen OpenAI ChatGPT:n keskustelutoimintoa.

## GPT-6.1 Sol

Valitse tämä malli käyttämällä `model: "gpt-6.1-sol"` -asetusta. Tukee suoratoistotulostusta, funktiokutsuja, strukturoitua tulostusta ja kuvasyötettä. Ensimmäisen avoimen viikon aikana se on saatavilla vain vahvistetuille ACE T1+ -haltijoille (vähintään 100 000 ACE) tai valtuutetuille käyttäjille; tarkka saatavuusaika määräytyy konsolin käyttöoikeusilmoituksen mukaan.

Päättelytasot tukevat arvoja `low`, `medium`, `high`, `xhigh` ja `max`; `none` ja `minimal` eivät ole toistaiseksi tuettuja. On suositeltavaa aloittaa asetuksella `reasoning_effort: "low"`. Kun syöte ylittää 272 000 tokenia, koko pyyntöön sovelletaan pitkän kontekstin hinnoittelua, ja maksu määräytyy konsolin nykyisen hinnan mukaan.

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavat sisällöt kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Kun käytämme tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Yksi niistä on `authorization`, joka voidaan valita suoraan avattavasta luettelosta. Toinen parametri on `model`; `model` tarkoittaa OpenAI ChatGPT:n viralliselta sivustolta valitsemaamme malliluokkaa. Täällä meillä on pääasiassa 20 mallia, ja lisätietoja voit katsoa tarjoamistamme malleista. Viimeinen parametri on `messages`; `messages` on syöttämiemme kyselysanojen taulukko. Se on taulukko, mikä tarkoittaa, että useita kyselysanoja voidaan lähettää samanaikaisesti. Jokainen kyselysana sisältää `role`- ja `content`-kentät, joista `role` ilmaisee kysyjän roolin. Tarjoamme kolme roolia: `user`, `assistant` ja `system`. Toinen kenttä, `content`, on kysymämme tarkka sisältö.

Samalla voit huomata, että oikealla on vastaava kutsukoodi luotuna. Voit kopioida koodin ja suorittaa sen suoraan tai testata sitä napsauttamalla suoraan ”Try”-painiketta.

Yleisesti käytetyt valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen tokenien enimmäismäärää.
- `temperature`: generoinnin satunnaisuus, välillä 0–2; mitä suurempi arvo, sitä hajautuneempi tulos.
- `n`: kuinka monta ehdokasvastausta generoidaan kerralla.
- `response_format`: palautusmuodon asetus.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastausta, mikä on erittäin hyödyllistä verkkosivujen integroinnissa, sillä se mahdollistaa verkkosivulle merkki kerrallaan -näyttötehosteen.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyyntöotsikon `stream `-parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodia on muutettava vastaavasti, jotta se tukee suoratoistovastausta.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan. Kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme tulokset rivi kerrallaan.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Myös JavaScript on tuettu, esimerkiksi Node.js:n suoratoistokutsun koodi on seuraava:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");
jsonObject.put("messages", [{"role":"user","content":"hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();

OkHttpClient client = new OkHttpClient();

System.out.print(response.body!!.string())
```

Muut kielet voidaan muokata erikseen itse, periaate on sama.

## OpenAI-Python-integraatio

OpenAI Chat Completion API pysyy yhteensopivana virallisen OpenAI-rajapinnan kanssa, ja se voidaan integroida suoraan virallisella SDK:lla [OpenAI-Python](https://github.com/openai/openai-python). Tässä artikkelissa esitellään lyhyesti käyttötapa.

1. Ensin on luotava paikallinen `Python`-ympäristö. Tätä prosessia voi hakea Googlesta.
2. Lataa ja asenna kehitysympäristö, esimerkiksi VSCode-editori.
3. Määritä `OpenAI`-ympäristömuuttujat.

- Luo projektikansioon `.env`-niminen tiedosto ja tallenna se.
- `.env`-tiedoston sisältö:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Muistutus jälleen: jos käytät virallisen OpenAI:n avainta, älä käytä tätä osoitetta.
```

Korvaa `sk-xxx` omalla avaimellasi. `OPENAI_BASE_URL` on OpenAI-välityspalvelurajapinnan käyttöosoite.

4. Asenna projektin tarvitsemat paketit

```shell
pip install openai
```

Mac OS:ssä komento on:

```shell
pip3 install openai
```

5. Luo esimerkkilähdekooditiedosto

Oletetaan, että luomme esimerkkikoodin `index.py`, jonka tarkka sisältö on seuraava:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Visuaalinen malli

gpt-4o on OpenAI:n kehittämä multimodaalinen suuri kielimalli, johon on lisätty visuaalisen ymmärtämisen kyky GPT-4:n pohjalta. Tämä malli voi käsitellä samanaikaisesti teksti- ja kuvasyötteitä, mikä mahdollistaa modaliteettien välisen ymmärtämisen ja tuottamisen.

gpt-4o-mallin tekstinkäsittelyn käyttö vastaa yllä kuvattua peruskäyttöä. Seuraavaksi esitellään lyhyesti, kuinka mallin kuvankäsittelykykyä käytetään.

gpt-4o-mallin kuvankäsittelykykyä käytetään pääasiassa lisäämällä `content`-sisällön alkuperäiseen pohjaan `type`-kenttä. Tämän kentän avulla voidaan tietää, onko ladattu sisältö tekstiä vai kuva, ja siten käyttää gpt-4o-mallin kuvankäsittelykykyä. Seuraavaksi kuvataan pääasiassa kaksi tapaa kutsua tätä toimintoa: Curl ja Python.

- Curl-komentosarjatapa

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Python-komentosarjatapa
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Voidaan nähdä, että vastauksen sisältö perustuu kuvaan. Näin ollen edellä mainituilla kahdella tavalla voidaan helposti hyödyntää gpt-4-vision-mallin tekstin- ja kuvankäsittelyominaisuuksia.

gpt-4o:n lisäksi on olemassa myös edullisempi malli nimeltä gpt-4o-mini. gpt-4o-mini on OpenAI:n kehittämä uusimman sukupolven suuri kielimalli. Sen lisäksi, että se vastaa nopeasti, sen hinta on myös edullisempi, ja se tukee myös multimodaalisuutta. Vision-toiminnon käytössä voidaan viitata yllä olevaan gpt-4o-mallin käyttöä koskevaan sisältöön.

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos kohdataan virhe. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella meni jokin pieleen.
