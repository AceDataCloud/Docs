---
title: "OpenAI äänisynteesin API (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Yhdistää tekstin luonnolliseksi puheeksi, **täysin yhteensopiva OpenAI:n `/v1/audio/speech`** kanssa. Mikä tahansa OpenAI SDK tarvitsee vain asettaa `base_url` osoittamaan `https://api.acedata.cloud`, vaihtaa avain omaksi AceData Tokeniksi ja se on suoraan käytettävissä. Rajapinta palauttaa ääni-bittivirran synkronoidusti.

- **Pyyntöosoite**: `POST https://api.acedata.cloud/v1/audio/speech` (alias `POST /openai/audio/speech`)
- **Todennus**: Pyyntöotsikko `Authorization: Bearer {token}`
- **Laskutus**: Laskutetaan pyynnön tekstin bittimäärän mukaan, noin 85% OpenAI:n virallisesta hinnasta (katso alla oleva taulukko).

## Pyyntöparametrit

| Kenttä             | Tyyppi   | Pakollinen | Selitys                                                        |
| ----------------- | ------ | -------- | ------------------------------------------------------------- |
| `input`           | string | Kyllä    | Yhdistettävä teksti.                                          |
| `model`           | string | Ei       | `tts-1` (nopeampi) tai `tts-1-hd` (korkeampi äänenlaatu, oletus). |
| `voice`           | string | Ei       | Yksi seuraavista: `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, oletus `alloy`. |
| `response_format` | string | Ei       | `mp3` (oletus), `opus`, `aac`, `flac`, `wav`, `pcm`.        |
| `speed`           | number | Ei       | Puheen nopeus 0.25–4.0, oletus 1.0.                          |

## Esimerkki

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Mitä jos yksi API antaisi sinulle jokaisen AI-videomallin?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Palautuksena on itse ääni-tiedosto (`Content-Type: audio/mpeg`), joka voidaan suoraan kirjoittaa `speech.mp3` ja toistaa.

Käyttäen virallista OpenAI Python SDK:ta:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Hei AceData:sta.").stream_to_file("speech.mp3")
```

## Hinnat

| Malli         | OpenAI virallinen hinta | Tämän alustan hinta (noin 85% alennus) |
| ---------- | ------------------- | --------------------- |
| `tts-1`    | $15 / 1 miljoona merkkiä | noin $12.75 / 1 miljoona merkkiä |
| `tts-1-hd` | $30 / 1 miljoona merkkiä | noin $25.5 / 1 miljoona merkkiä  |

> Laskutetaan pyynnön tekstin bittimäärän mukaan; `official_price` kenttä näyttää OpenAI:n virallisen hinnan vertailua varten.

## Virhekoodit

| Tila | koodi                    | Selitys               |
| --- | ----------------------- | -------------------- |
| 400 | `bad_request`           | `input` on tyhjää tai parametri on virheellinen. |
| 401 | `authentication_failed` | token on virheellinen. |
| 403 | `used_up`               | Saldo on riittämätön. |
| 429 | `too_many_requests`     | Pyyntöjä on liian usein. |
| 500 | `api_error`             | Ylätason/sisäinen virhe. |
