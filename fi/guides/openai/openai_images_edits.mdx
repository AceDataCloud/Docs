OpenAI:n kuvamuokkauspalvelu mahdollistaa useiden kuvien ja ohjeiden syöttämisen, ja se tuottaa muokattuja kuvia.

Tässä asiakirjassa esitellään OpenAI Images Edits API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista OpenAI:n kuvamuokkaustoimintoa.

## Hakuprosessi

Käyttääksesi OpenAI Images Edits API:a, voit ensin siirtyä [OpenAI Images Edits API](https://platform.acedata.cloud/documents/251f1efa-aaa6-462e-8af4-66854b1bc94d) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemuskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit käyttää koodia kutsumiseen, alla on esimerkki CURL-kutsusta:

```curl
curl -s -D >(grep -i x-request-id >&2) \
  -o >(jq -r '.data[0].b64_json' | base64 --decode > gift-basket.png) \
  -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F 'prompt=Create a lovely gift basket with these this items in it'
```

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään neljä kenttää: yksi on `authorization`, jonka voit valita suoraan avattavasta valikosta. Toinen parametri on `model`, joka tarkoittaa valitsemaasi OpenAI:n mallikategoriaa; tässä meillä on pääasiassa 1 malli, lisätietoja voit katsoa tarjoamastamme mallista. Kolmas parametri on `prompt`, joka on syötteesi, jonka avulla haluat luoda kuvan. Viimeinen parametri on `image`, joka on muokattavan kuvan polku, muokattava kuva on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/jw9iwu.png" width="500" class="m-auto"></p>

Saman kutsun Python-esimerkkikoodi:

```python
import base64
from openai import OpenAI
client = OpenAI()

prompt = """
Generate a photorealistic image of a gift basket on a white background 
labeled 'Relax & Unwind' with a ribbon and handwriting-like font, 
containing all the items in the reference pictures.
"""

result = client.images.edit(
    model="gpt-image-1",
    image=[
        open("test.png", "rb")
    ],
    prompt=prompt
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

# Tallenna kuva tiedostoon
with open("gift-basket.png", "wb") as f:
    f.write(image_bytes)
```

Käyttääksesi Pythonia, sinun on ensin tuontava kaksi ympäristömuuttujaa, yksi `OPENAI_BASE_URL`, joka voidaan asettaa arvoon `https://api.acedata.cloud/openai`, ja toinen käyttöoikeusmuuttuja `OPENAI_API_KEY`, jonka arvo saadaan `authorization`-kentästä. Mac OS:ssä voit asettaa ympäristömuuttujat seuraavalla komennolla:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token} 
```

Kutsun jälkeen huomaamme, että nykyiseen hakemistoon luodaan kuva `gift-basket.png`, tarkka tulos on seuraava:

<p><img src="https://cdn.acedata.cloud/574s8h.png" width="500" class="m-auto"></p>

Näin olemme suorittaneet kuvan muokkaustoiminnon. Tällä hetkellä viralliset Edits-tehtävät tukevat vain kahta mallia: `dall-e-2` ja `gpt-image-1`.

## Asynkroninen palautus

Koska OpenAI Images Edits API:n kuvien muokkaamiseen kuluva aika voi olla suhteellisen pitkä, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on seuraava: kun asiakas lähettää pyynnön, se määrittää ylimääräisen `callback_url`-kentän. Kun asiakas on lähettänyt API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, muokattujen kuvien tulokset lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulokset voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten tämä toimii.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkissä käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaksi Webhook URL:ksi ja täyttää vastaavat parametrit, kuten alla olevassa koodissa näkyy:

```shell
curl -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F "prompt=Create a lovely gift basket with these items in it" \
  -F "callback_url=https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
```

Kutsun jälkeen voimme huomata, että saamme heti tuloksen, kuten alla:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Odota hetki, niin voimme tarkkailla muokattujen kuvien tuloksia Webhook URL:lla, sisältö on seuraava:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "b64_json": "iVBORw0KGgo..."
      }
    ]
  }
}
```

Voimme nähdä, että tuloksessa on `task_id`-kenttä, ja `data`-kenttä sisältää saman kuvan muokkaustuloksen kuin synkronisessa kutsussa, ja `task_id`-kentän avulla voimme yhdistää tehtävät.

## Virheiden käsittely

Kun kutsut API:a, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
