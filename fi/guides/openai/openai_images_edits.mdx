## 1. API-avaimen hankkiminen

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

## 2. Kuvan URL-osoitteen käyttäminen muokkaukseen

Alkuperäinen kuva:

![GPT Image 2 -muokkauksen alkuperäinen kuva](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

## 3. Paikallisen kuvan lataaminen

Käytä `multipart/form-data`-muotoa:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` voidaan lähettää toistuvasti, ja GPT Image -sarja tukee enintään 16 viitekuvaa. JSON-pyynnön `image` voi olla yksittäinen URL-osoite tai URL-osoitteiden taulukko; paikalliset tiedostot ladataan multipart-muodossa.

### Mallit ja laskutustavat

| Malli                                | Soveltuvat käyttötapaukset ja laskutustavat                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Oletusarvoinen käänteinen kanava, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2:reverse`             | Valitsee käänteisen kanavan eksplisiittisesti, kiinteä laskutus onnistuneiden kuvien määrän mukaan                             |
| `gpt-image-2:official`            | Virallinen API-kanava, vakaampi, laskutus todellisen Token-kulutuksen mukaan                   |
| `gpt-image-2.5-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2.6-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2.5-flare:reverse`     | Eksplisiittinen käänteinen alias, vastaa mallia `gpt-image-2.5-flare`, kiinteä laskutus onnistuneiden kuvien määrän mukaan    |
| `gpt-image-2.6-flare:reverse`     | Eksplisiittinen käänteinen alias, vastaa mallia `gpt-image-2.6-flare`, kiinteä laskutus onnistuneiden kuvien määrän mukaan    |
| `gpt-image-2.5-flare:official`    | Virallinen API-kanava, vakaampi ja painottaa generointinopeutta, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.6-flare:official`    | Virallinen API-kanava, vakaampi ja painottaa generointinopeutta, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.5-sunburst`          | Painottaa korkeaa tarkkuutta ja hienovaraista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                           |
| `gpt-image-2.6-sunburst`          | Painottaa korkeaa tarkkuutta ja hienovaraista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                           |
| `gpt-image-2.5-sunburst:reverse`  | Eksplisiittinen käänteinen alias, vastaa mallia `gpt-image-2.5-sunburst`, kiinteä laskutus onnistuneiden kuvien määrän mukaan |
| `gpt-image-2.6-sunburst:reverse`  | Eksplisiittinen käänteinen alias, vastaa mallia `gpt-image-2.6-sunburst`, kiinteä laskutus onnistuneiden kuvien määrän mukaan |
| `gpt-image-2.5-sunburst:official` | Virallinen API-kanava, vakaampi ja painottaa korkeaa tarkkuutta sekä hienovaraista hallintaa, laskutus todellisen Token-kulutuksen mukaan        |
| `gpt-image-2.6-sunburst:official` | Virallinen API-kanava, vakaampi ja painottaa korkeaa tarkkuutta sekä hienovaraista hallintaa, laskutus todellisen Token-kulutuksen mukaan        |

2.0 / 2.5 -käänteiset mallit (mukaan lukien `:reverse`-aliakset) voivat automaattisessa palautuksessa käyttää GPT Image 2.5 Flarea pyynnön suorittamiseen; pyynnön malli ja onnistuneiden kuvien määrään perustuva laskutustapa säilyvät muuttumattomina.

Virallisen API-kanavan sivuhinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy vastauksen todellisen Token-kulutuksen ja käyttötietojen perusteella.

`quality` tukee arvoja `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare ja Sunburst (mukaan lukien `:reverse`- ja `:official`-variantit) tukevat lisäksi arvoja `xhigh`, `max`. Tämä kenttä voidaan välittää sekä JSON-kuva-URL-muokkauksessa että multipart-tiedostomuokkauksessa; virallinen kanava laskuttaa todellisen Token-kulutuksen mukaan.

## 4. Maskin käyttäminen paikalliseen muokkaukseen

Virallinen Images Edit -rajapinta määrittää `mask`-kentän avulla alueen, jota saa muokata. Ace Data Cloudin `:official`-mallit noudattavat samaa multipart-sopimusta:

- `mask`-tiedoston on oltava PNG, jossa on Alpha-kanava, ja sen koko saa olla enintään 4 Mt;
- maskin koon on oltava täsmälleen sama kuin ensimmäisen `image`-kuvan;
- Alpha-arvoltaan `0` olevat läpinäkyvät pikselit tarkoittavat, että muokkaus on sallittu, ja läpinäkymättömät pikselit tarkoittavat, että ne tulee säilyttää;
- pelkästään mustavalkoinen RGB-kuva, jossa ei ole läpinäkyvyyskanavaa, ei voi toimia kelvollisena maskina;
- kehotteen tulisi kuvata haluttu kokonainen kuva ja samalla selkeästi määrittää paikallinen muutos sekä muuttumattomina pidettävä sisältö.

Seuraavaksi luodaan ensin maski alkuperäisestä kuvasta. Esimerkki asettaa keskellä olevan suorakulmion läpinäkyväksi ja sallii mallin muokata vain tätä aluetta:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Lataa sitten alkuperäinen kuva ja maski yhdessä:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Voit myös käyttää edelleen OpenAI:n virallisen Python SDK:n `images.edit`-kutsutapaa; sinun tarvitsee vain osoittaa `base_url` Ace Data Cloudiin:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kun käytät `mask`-kenttää, alkuperäinen kuva ja maski on ladattava samassa multipart-pyynnössä erikseen kentillä `image=@input.png` ja `mask=@mask.png`. Älä välitä URL-alkuperäiskuvaa ja paikallista maskitiedostoa yhdessä; pelkät URL-muokkauspyynnöt eivät tue paikallisen `mask`-tiedoston lisäämistä. Maski rajoittaa muokkausaluetta, mutta generointimalli voi silti sulauttaa reunat luonnollisesti; jos tarvitset tiukat rajat, käytä selkeitä Alpha-reunoja ja toista kehotteessa, mikä sisältö on pidettävä muuttumattomana.

Yllä oleva kutsutapa vastaa [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit)- ja [GPT Image virallisen Cookbookin](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image) maskiesimerkkejä.

## 5. Yleiset parametrit

| Kenttä                | Kuvaus                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voi valita vastaavan `:official`-muunnelman, ja `gpt-image-2` tukee myös `:reverse`-muunnelmaa |
| `image`           | JSON käyttää yhtä URL-osoitetta tai enintään 16 URL-osoitteen taulukkoa; multipart käyttää yhtä tai useampaa `image`-tiedostokenttää. Kun käytetään `mask`-kenttää, paikallinen kuvatiedosto on ladattava                                              |
| `mask`            | Valinnainen PNG-maski, vain multipart-tiedostolataukseen; siinä on oltava Alpha-kanava, sen on oltava samankokoinen kuin ensimmäinen `image` eikä se saa ylittää 4 Mt                                                                 |
| `prompt`          | Muokkausohje                                                                                                                             |
| `size`            | `auto` tai rajoitusten mukainen `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; `response_format=b64_json` tukee vain arvoa 1                                                                                           |
| `response_format` | `url` tai `b64_json`                                                                                                               |
| `callback_url`    | Valinnainen asynkronisen takaisinsoiton osoite                                                                                                                         |

Kokosäännöt ovat samat kuin generointirajapinnassa: leveyden ja korkeuden on oltava 16:n kerrannaisia, pitkä sivu saa olla enintään 3840, kokonaispikselimäärän on oltava 655,360–8,294,400 ja kuvasuhde saa olla enintään 3:1. Kun `size` jätetään pois tai käytetään `auto`-arvoa, malli valitsee kuvasuhteen kehotteen ja ensimmäisen viitekuvan perusteella.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` ja niiden `:reverse`-aliakset laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`, `gpt-image-2.5-flare:official` ja `gpt-image-2.5-sunburst:official` laskutetaan tekstisyötteen, viitekuvasyötteen ja kuvatuotoksen todellisten Tokenien perusteella, ja lopullinen laskutus määräytyy käyttötietojen mukaan.

## 6. Asynkroniset takaisinsoitot ja vianmääritys

Pitkiin tehtäviin voidaan lisätä pyyntöön:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkroninen 200-vastaus on `{"task_id": "..."}`; valmistumisen jälkeen takaisinsoitto palauttaa lopullisen tuloksen. Synkroniset pyynnöt palauttavat sen sijaan `created` ja `data`.

| Tila  | Tarkista                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Kuvamuoto/määrä, parametriyhdistelmät ja kokomuoto; kun käytät `mask`-kenttää, tarkista PNG Alpha-kanava, 4 Mt:n rajoitus ja se, vastaako sen koko ensimmäistä alkuperäiskuvaa |
| 401 | API Key ja Bearer Header                                           |
| 429 | Pyyntötiheys                                                              |
| 504 | Siirry käyttämään asynkronista takaisinsoittoa                                                            |

Virhevastaus sisältää `trace_id`-kentän. Anna tämä ID, kun ilmoitat ongelmasta, älä anna API Key -avainta.

Täydelliset kentät ja reaaliaikaiset enum-arvot löytyvät [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) -sivulta. Pelkän tekstin perusteella tapahtuvaan kuvagenerointiin katso [GPT Image 2 / 2.5 / 2.6 -kuvagenerointi](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 käyttää edelleen 2.5:n generointi-, muokkaus-, asynkronisten tehtävien ja laskutusrajapintoja:

| Malli                                                          | Laskutus                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/kuva                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/kuva                   |
| `gpt-image-2.6-flare:official`                              | Sama kuin 2.5 official, laskutetaan todellisen Token-kulutuksen mukaan |
| `gpt-image-2.6-sunburst:official`                           | Sama kuin 2.5 official, laskutetaan todellisen Token-kulutuksen mukaan |

Laatuvaihtoehdot ovat `auto`, `low`, `medium`, `high`, `xhigh`, `max`; koossa käytetään `auto`-arvoa tai edellä mainittujen rajoitusten mukaista `WIDTHxHEIGHT`-arvoa. Tämä rajapinta tukee muotoja `png`, `jpeg`, `webp`; GPT Image 2.6 tukee lisäksi natiivisti animoitua `gif`-muotoa, mutta SVG:tä ei vielä tueta. Muokkaus tukee JSON-kuva-URL-osoitteita ja multipart-tiedostolatauksia. `:reverse` on samannimisen tavallisen version eksplisiittinen alias. Käytä täydellistä mallinimeä, älä välitä `gpt-image-2.6`.

### GPT Image 2.6 kuva GIF-animaatioksi
Flaren tavallinen versio, `:reverse`, `:official` sekä `gpt-image-2.6-sunburst:official` voivat käyttää `output_format: "gif"` -asetusta. Sunburstin tavallinen versio ja `:reverse` eivät toistaiseksi tue GIF:iä, mutta tukevat edelleen staattisten kuvien luontia ja muokkausta. Animaation kehykset, silmukkatiedot ja toistoaika säilytetään; `frame_count` tarkoittaa kehysten määrää ja `frame_duration_ms` tarkoittaa millisekuntien määrää kehystä kohden, ja molempien on oltava positiivisia kokonaislukuja sekä niitä käytetään vain GIF:eille. Jos niitä ei määritetä, oletusarvot ovat 9 kehystä ja 200 millisekuntia kehystä kohden; kun GIFin `size` jätetään pois tai sen arvona on auto, käytetään 512x512-esiasetusta.

On suositeltavaa käyttää ensin asetuksia `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF:illä on erilliset koko- ja kehysmäärärajoitukset, eikä staattisten 4K-määritysten arvoja voi käyttää suoraan; jotkin mallit säätävät todellista tulostuskokoa. `n` tarkoittaa palautettavien GIF-tiedostojen määrää, ei animaatiokehysten määrää. Tavallinen versio ja `:reverse` laskutetaan edelleen onnistuneiden tiedostojen määrän perusteella, kun taas viralliset versiot laskutetaan todellisen token-kulutuksen perusteella.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K -staattiset kuvat

Flare, Sunburst ja niiden `:reverse`- ja `:official`-variantit voivat kaikki käyttää edellä mainittuja 4K-pikseliesiasetuksia, kuten `3840x2160` ja `2160x3840`. Luonti ja muokkaus välitetään molemmat `size`-parametrin kautta tarkkoina pikseleinä; `4K` ei ole kelvollinen `size`-arvo, ja `4096x4096` ylittää myös nykyisen pikselirajan. Edellä mainitut 4K-määritykset soveltuvat staattisille PNG/JPEG/WebP-kuville; käytä GIF:eille niiden omia parametreja.
