Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

## 2. Muokkaa käyttämällä kuvan URL-osoitetta

## 3. Lataa paikallinen kuva

Käytä `multipart/form-data`-muotoa:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` voidaan välittää toistuvasti, ja GPT Image -sarja tukee enintään 16 viitekuvaa. JSON-pyyntöjen `image` voi olla yksittäinen URL-osoite tai URL-osoitteiden taulukko; paikalliset tiedostot ladataan multipart-muodossa.

### Mallit ja laskutustavat

| Malli                                | Soveltuvat käyttötapaukset ja laskutustapa                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Oletusarvoinen käänteiskanava, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2:reverse`             | Valitse käänteiskanava nimenomaisesti, kiinteä laskutus onnistuneiden kuvien määrän mukaan                             |
| `gpt-image-2:official`            | Virallinen API-kanava, vakaampi, laskutus todellisen Token-kulutuksen mukaan                   |
| `gpt-image-2.5-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2.6-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2.5-flare:reverse`     | Nimenomainen käänteinen alias, vastaa mallia `gpt-image-2.5-flare`, kiinteä laskutus onnistuneiden kuvien määrän mukaan    |
| `gpt-image-2.6-flare:reverse`     | Nimenomainen käänteinen alias, vastaa mallia `gpt-image-2.6-flare`, kiinteä laskutus onnistuneiden kuvien määrän mukaan    |
| `gpt-image-2.5-flare:official`    | Virallinen API-kanava, vakaampi ja painottaa generointinopeutta, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.6-flare:official`    | Virallinen API-kanava, vakaampi ja painottaa generointinopeutta, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.5-sunburst`          | Painottaa korkeaa tarkkuutta ja yksityiskohtaista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                           |
| `gpt-image-2.6-sunburst`          | Painottaa korkeaa tarkkuutta ja yksityiskohtaista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                           |
| `gpt-image-2.5-sunburst:reverse`  | Nimenomainen käänteinen alias, vastaa mallia `gpt-image-2.5-sunburst`, kiinteä laskutus onnistuneiden kuvien määrän mukaan |
| `gpt-image-2.6-sunburst:reverse`  | Nimenomainen käänteinen alias, vastaa mallia `gpt-image-2.6-sunburst`, kiinteä laskutus onnistuneiden kuvien määrän mukaan |
| `gpt-image-2.5-sunburst:official` | Virallinen API-kanava, vakaampi ja painottaa korkeaa tarkkuutta sekä yksityiskohtaista hallintaa, laskutus todellisen Token-kulutuksen mukaan        |
| `gpt-image-2.6-sunburst:official` | Virallinen API-kanava, vakaampi ja painottaa korkeaa tarkkuutta sekä yksityiskohtaista hallintaa, laskutus todellisen Token-kulutuksen mukaan        |

2.0 / 2.5 -käänteismallit (mukaan lukien `:reverse`-aliakset) voivat automaattisessa palautuksessa käyttää GPT Image 2.5 Flarea pyynnön suorittamiseen; pyynnön malli ja onnistuneiden kuvien määrään perustuva laskutustapa säilyvät muuttumattomina.

Virallisen API-kanavan sivuhinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy vastauksen todellisen Token-kulutuksen ja käyttötietojen perusteella.

`quality` tukee arvoja `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare ja Sunburst (mukaan lukien `:reverse`- ja `:official`-versiot) tukevat lisäksi arvoja `xhigh`, `max`. Tämä kenttä voidaan välittää sekä JSON-kuvan URL-muokkauksessa että multipart-tiedostomuokkauksessa; virallinen kanava laskuttaa todellisen Token-kulutuksen mukaan.

## 4. Käytä maskia paikalliseen muokkaukseen

Virallinen Images Edit -rajapinta määrittää `mask`-kentällä alueen, jota saa muokata. Ace Data Cloudin `:official`-mallit noudattavat samaa multipart-sopimusta:

- `mask`-tiedoston on oltava PNG, jossa on Alpha-kanava, ja sen koon on oltava enintään 4 Mt;
- maskin koon on vastattava täsmälleen ensimmäisen `image`-kuvan kokoa;
- Alpha-arvoltaan `0` olevat läpinäkyvät pikselit tarkoittavat, että muokkaus on sallittu, ja läpinäkymättömät pikselit tarkoittavat, että ne tulee säilyttää;
- pelkästään mustavalkoinen RGB-kuva, jossa ei ole läpinäkyvyyskanavaa, ei voi toimia kelvollisena maskina;
- kehotteen tulisi kuvata haluttu kokonainen kuva sekä selkeästi paikallinen muutos ja muuttumattomana säilytettävä sisältö.

Luo seuraavaksi ensin maski alkuperäisestä kuvasta. Esimerkki asettaa keskimmäisen suorakulmion läpinäkyväksi ja sallii mallin muokata vain tätä aluetta:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Lataa sitten alkuperäinen kuva ja maski yhdessä:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Voit myös käyttää edelleen OpenAI:n virallisen Python SDK:n `images.edit`-kutsutapaa; sinun tarvitsee vain osoittaa `base_url` Ace Data Cloudiin:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kun käytät `mask`-parametria, alkuperäinen kuva ja maski on ladattava samassa multipart-pyynnössä erikseen käyttäen `image=@input.png` ja `mask=@mask.png`. Älä välitä URL-alkuperäiskuvaa ja paikallista maskitiedostoa yhdessä; puhtaat URL-muokkauspyynnöt eivät tue paikallisen `mask`-tiedoston liittämistä. Maski rajoittaa muokkausaluetta, mutta generointimalli voi silti sulauttaa reunat luonnollisesti; kun tarvitaan tiukkoja rajoja, käytä selkeitä Alpha-reunoja ja toista kehotteessa, mikä sisältö on pidettävä muuttumattomana.

Yllä oleva kutsutapa vastaa [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit)- ja [GPT Image virallisen Cookbookin](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image) maskiesimerkkejä.

## 5. Yleiset parametrit

| Kenttä                | Kuvaus                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voidaan valita vastaava `:official`-variantti, ja `gpt-image-2` tukee myös `:reverse`-varianttia |
| `image`           | JSON käyttää yhtä URL-osoitetta tai enintään 16 URL-osoitteen taulukkoa; multipart käyttää yhtä tai useampaa `image`-tiedostokenttää. Kun käytetään `mask`-parametria, paikallinen kuvatiedosto on ladattava                                              |
| `mask`            | Valinnainen PNG-maski, vain multipart-tiedostolatauksiin; siinä on oltava Alpha-kanava, sen on oltava samankokoinen kuin ensimmäinen `image`-kuva eikä se saa ylittää 4 Mt:tä                                                                 |
| `prompt`          | Muokkausohje                                                                                                                             |
| `size`            | `auto` tai rajoitusten mukainen `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; `response_format=b64_json` tukee vain arvoa 1                                                                                           |
| `response_format` | `url` tai `b64_json`                                                                                                               |
| `callback_url`    | Valinnainen asynkroninen takaisinsoitto-osoite                                                                                                                         |

Kokosäännöt ovat samat kuin generointirajapinnassa: leveyden ja korkeuden on oltava 16:n kerrannaisia, pitkä sivu ei saa ylittää 3840:tä, pikselien kokonaismäärän on oltava 655 360–8 294 400 ja kuvasuhde ei saa ylittää 3:1. Kun `size` jätetään pois tai käytetään `auto`-arvoa, malli valitsee kuvasuhteen kehotteen ja ensimmäisen viitekuvan perusteella.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` ja niiden `:reverse`-aliakset laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`, `gpt-image-2.5-flare:official` ja `gpt-image-2.5-sunburst:official` laskutetaan tekstisyötteen, viitekuvasyötteen ja kuvatuotoksen todellisten Tokenien perusteella, ja lopullinen laskutus määräytyy käyttötietueiden mukaan.

## 6. Asynkroninen takaisinsoitto ja vianmääritys

Pitkiin tehtäviin voidaan lisätä pyyntöön:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkroninen 200-vastaus on `{"task_id": "..."}`; valmistumisen jälkeen lopullinen tulos palautetaan takaisinsoittona. Synkroniset pyynnöt palauttavat sen sijaan `created` ja `data`.

| Tila  | Tarkista                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Kuvamuoto/-määrä, parametrien yhdistelmät ja kokomuoto; kun käytetään `mask`-parametria, tarkista PNG Alpha-kanava, 4 Mt:n rajoitus sekä se, vastaako sen koko ensimmäistä alkuperäiskuvaa |
| 401 | API Key ja Bearer Header                                           |
| 429 | Pyyntötiheys                                                              |
| 504 | Käytä asynkronista takaisinsoittoa                                                            |

Virhevastaus sisältää `trace_id`-tunnisteen. Anna ongelmaa raportoidessasi tämä ID, älä API Keytä.

Täydelliset kentät ja reaaliaikaiset enumeraatiot löytyvät [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) -sivulta. Pelkkään tekstistä kuvaksi -generointiin katso [GPT Image 2 / 2.5 / 2.6 -kuvagenerointi](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 käyttää edelleen 2.5:n generointi-, muokkaus-, asynkronisten tehtävien ja laskutusrajapintoja:

| Malli                                                          | Laskutus                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/kuva                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/kuva                   |
| `gpt-image-2.6-flare:official`                              | Sama kuin 2.5 official, laskutetaan todellisen Token-kulutuksen mukaan |
| `gpt-image-2.6-sunburst:official`                           | Sama kuin 2.5 official, laskutetaan todellisen Token-kulutuksen mukaan |

Laaduksi voidaan valita `auto`, `low`, `medium`, `high`, `xhigh`, `max`; kokona käytetään `auto`-arvoa tai edellä mainittujen rajoitusten mukaista `WIDTHxHEIGHT`-arvoa. Tämä rajapinta tukee `png`-, `jpeg`- ja `webp`-muotoja, mutta ei toistaiseksi SVG/GIF-muotoja. Muokkaus tukee JSON-kuva-URL-osoitteita ja multipart-tiedostolatauksia. `:reverse` on samannimisen tavallisen version eksplisiittinen alias. Käytä täydellistä mallinimeä, älä välitä `gpt-image-2.6`-arvoa.
