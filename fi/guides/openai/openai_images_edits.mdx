## 1. API-avaimen hankkiminen

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

## 2. Muokkaaminen kuvan URL-osoitteella

Alkuperäinen kuva:

![GPT Image 2 -muokkauksen alkuperäinen kuva](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

## 3. Paikallisen kuvan lataaminen

Käytä `multipart/form-data`-muotoa:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` voidaan lähettää toistuvasti, ja GPT Image -sarja tukee enintään 16 viitekuvaa. JSON-pyynnön `image` voi olla yksittäinen URL-osoite tai URL-osoitteiden taulukko; paikalliset tiedostot ladataan multipart-muodossa.

### Mallit ja laskutustavat

| Malli                                | Soveltuvat käyttötapaukset ja laskutustapa                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Oletusarvoinen käänteiskanava, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2:reverse`             | Käänteiskanavan nimenomainen valinta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                             |
| `gpt-image-2:official`            | Virallinen API-kanava, vakaampi, laskutus todellisen Token-kulutuksen mukaan                   |
| `gpt-image-2.5-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                               |
| `gpt-image-2.5-flare:reverse`     | Nimenomainen käänteinen alias, vastaa mallia `gpt-image-2.5-flare`, kiinteä laskutus onnistuneiden kuvien määrän mukaan    |
| `gpt-image-2.5-flare:official`    | Virallinen API-kanava, vakaampi ja painottaa generointinopeutta, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.5-sunburst`          | Painottaa korkeaa tarkkuutta ja hienovaraista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                           |
| `gpt-image-2.5-sunburst:reverse`  | Nimenomainen käänteinen alias, vastaa mallia `gpt-image-2.5-sunburst`, kiinteä laskutus onnistuneiden kuvien määrän mukaan |
| `gpt-image-2.5-sunburst:official` | Virallinen API-kanava, vakaampi ja painottaa korkeaa tarkkuutta sekä hienovaraista hallintaa, laskutus todellisen Token-kulutuksen mukaan        |

Käänteiset mallit (mukaan lukien `:reverse`-aliakset) voivat automaattisessa palautuksessa käyttää GPT Image 2.5 Flarea pyynnön suorittamiseen; pyynnön malli ja onnistuneiden kuvien määrään perustuva laskutustapa säilyvät muuttumattomina.

Virallisen API-kanavan sivuhinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy vastauksen todellisen Token-kulutuksen ja käyttömerkintöjen perusteella.

`quality` tukee arvoja `auto`, `low`, `medium`, `high`; vain `gpt-image-2.5-flare` ja `gpt-image-2.5-sunburst` (mukaan lukien `:reverse`- ja `:official`-variantit) tukevat lisäksi arvoja `xhigh`, `max`. Kenttä voidaan välittää sekä JSON-kuva-URL-muokkauksessa että multipart-tiedostomuokkauksessa; virallinen kanava laskuttaa todellisen Token-kulutuksen mukaan.

## 4. Paikallinen muokkaaminen maskilla

Virallinen Images Edit -rajapinta määrittää `mask`-kentällä alueen, jota saa muokata. Ace Data Cloudin `:official`-mallit noudattavat samaa multipart-sopimusta:

- `mask`-kentän on oltava Alpha-kanavallinen PNG, jonka koko on enintään 4 Mt;
- maskin koon on oltava täysin sama kuin ensimmäisen `image`-kuvan;
- Alpha-arvon `0` läpinäkyvät pikselit tarkoittavat, että muokkaus on sallittu, ja ei-läpinäkyvät pikselit tarkoittavat, että ne tulee säilyttää;
- pelkästään mustavalkoiset, mutta ilman läpinäkyvyyskanavaa olevat RGB-kuvat eivät kelpaa voimassa oleviksi maskeiksi;
- kehotteen tulisi kuvata haluttu kokonaiskuva sekä samalla selvästi paikallinen muutos ja muuttumattomina pidettävä sisältö.

Luo seuraavaksi ensin maski alkuperäisestä kuvasta. Esimerkki asettaa keskimmäisen suorakulmion läpinäkyväksi ja sallii mallin muokata vain tätä aluetta:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Lataa sitten alkuperäinen kuva ja maski yhdessä:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Voit myös jatkaa OpenAI:n virallisen Python SDK:n `images.edit`-kutsutavan käyttöä; sinun tarvitsee vain osoittaa `base_url` Ace Data Cloudiin:
```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kun käytetään `mask`-parametria, alkuperäinen kuva ja maski on ladattava samassa multipart-pyynnössä erikseen käyttäen `image=@input.png`- ja `mask=@mask.png`-parametreja. Älä lähetä URL-alkuperäiskuvaa ja paikallista maskitiedostoa yhdessä; pelkkää URL-osoitetta käyttävät muokkauspyynnöt eivät tue paikallisen `mask`-tiedoston lisäämistä. Maski rajoittaa muokkausaluetta, mutta generointimalli voi silti sulauttaa reunoja luonnollisesti; jos vaaditaan tiukkoja rajoja, on käytettävä selkeitä Alpha-reunoja ja toistettava kehotteessa, minkä sisällön on säilyttävä muuttumattomana.

Yllä oleva kutsutapa vastaa [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit)- ja [GPT Image virallisen Cookbookin](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image) maskiesimerkkejä.

## 5. Yleiset parametrit

| Kenttä                | Kuvaus                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voidaan valita vastaava `:official`-versio, ja `gpt-image-2` tukee lisäksi `:reverse`-versiota |
| `image`           | JSON käyttää yhtä URL-osoitetta tai enintään 16 URL-osoitteen taulukkoa; multipart käyttää yhtä tai useampaa `image`-tiedostokenttää. `mask`-parametria käytettäessä on ladattava paikallinen kuvatiedosto                                              |
| `mask`            | Valinnainen PNG-maski, vain multipart-tiedostolataukseen; siinä on oltava Alpha-kanava, sen on oltava samankokoinen kuin ensimmäinen `image`, eikä se saa ylittää 4 Mt:tä                                                                 |
| `prompt`          | Muokkausohje                                                                                                                             |
| `size`            | `auto` tai rajoitusten mukainen `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; `response_format=b64_json` tukee vain arvoa 1                                                                                           |
| `response_format` | `url` tai `b64_json`                                                                                                               |
| `callback_url`    | Valinnainen asynkroninen takaisinsoitto-osoite                                                                                                                         |

Kokosäännöt ovat samat kuin generointirajapinnassa: leveyden ja korkeuden on oltava 16:n kerrannaisia, pidempi sivu ei saa ylittää 3840:tä, pikselien kokonaismäärän on oltava 655 360–8 294 400 ja kuvasuhde ei saa ylittää 3:1. Kun `size` jätetään pois tai käytetään arvoa `auto`, malli valitsee kuvasuhteen kehotteen ja ensimmäisen viitekuvan perusteella.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` ja niiden `:reverse`-aliakset laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`, `gpt-image-2.5-flare:official` ja `gpt-image-2.5-sunburst:official` laskutetaan tekstisyötteen, viitekuvasyötteen ja kuvatuotoksen todellisten tokenien perusteella, ja lopullinen laskutus määräytyy käyttötietojen mukaan.

## 6. Asynkroninen takaisinsoitto ja vianmääritys

Pitkiin tehtäviin voidaan lisätä pyyntöön:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkroninen 200-vastaus on `{"task_id": "..."}`; valmistumisen jälkeen takaisinsoitto palauttaa lopullisen tuloksen. Synkroniset pyynnöt palauttavat sen sijaan `created`- ja `data`-kentät.

| Tila  | Tarkista                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Kuvan muoto/määrä, parametriyhdistelmät ja kokomuoto; kun käytetään `mask`-parametria, tarkista PNG Alpha-kanava, 4 Mt:n raja ja se, vastaavatko sen mitat ensimmäistä alkuperäiskuvaa |
| 401 | API Key ja Bearer Header                                           |
| 429 | Pyyntötiheys                                                              |
| 504 | Käytä asynkronista takaisinsoittoa                                                            |

Virhevastaus sisältää `trace_id`-tunnuksen. Anna ongelmaa raportoidessasi tämä ID, älä API Key -avainta.

Täydelliset kentät ja reaaliaikaiset enumeraatiot löytyvät [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) -sivulta. Pelkkään tekstisyötteeseen perustuvaan kuvagenerointiin katso [GPT Image 2 / 2.5 -kuvagenerointi](https://platform.acedata.cloud/documents/openai-images-generations).
