## 2. Muokkaaminen kuvan URL-osoitetta käyttämällä

Alkuperäinen kuva:

![GPT Image 2 -muokkauksen alkuperäinen kuva](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

## 3. Paikallisen kuvan lataaminen

Käytä `multipart/form-data`-muotoa:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` voidaan välittää toistuvasti, ja GPT Image -sarja tukee enintään 16 referenssikuvaa. JSON-pyynnön `image` voi olla yksittäinen URL-osoite tai URL-osoitteiden taulukko; paikalliset tiedostot ladataan multipart-muodossa.

### Mallit ja laskutustavat

| Malli                                | Sovellusskenaariot ja laskutustapa                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Oletusarvoinen käänteinen kanava, kiinteä laskutus onnistuneiden kuvien määrän mukaan                        |
| `gpt-image-2:reverse`             | Valitsee käänteisen kanavan eksplisiittisesti, kiinteä laskutus onnistuneiden kuvien määrän mukaan                      |
| `gpt-image-2:official`            | Virallinen API-kanava, parempi vakaus, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.5-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                        |
| `gpt-image-2.5-flare:official`    | Virallinen API-kanava, parempi vakaus ja painotus generointinopeudessa, laskutus todellisen Token-kulutuksen mukaan     |
| `gpt-image-2.5-sunburst`          | Painottaa korkeaa tarkkuutta ja yksityiskohtaista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                    |
| `gpt-image-2.5-sunburst:official` | Virallinen API-kanava, parempi vakaus sekä painotus korkeassa tarkkuudessa ja yksityiskohtaisessa hallinnassa, laskutus todellisen Token-kulutuksen mukaan |

Virallisen API-kanavan sivuhinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy vastauksen todellisen Token-kulutuksen ja käyttötietojen mukaan.

## 4. Paikallinen muokkaus maskia käyttämällä

Virallinen Images Edit -rajapinta määrittää `mask`-parametrilla alueen, jota saa muokata. Ace Data Cloudin `:official`-malli noudattaa samaa multipart-sopimusta:

- `mask`-tiedoston on oltava Alpha-kanavalla varustettu PNG, jonka koko on enintään 4 Mt;
- maskin koon on oltava täysin sama kuin ensimmäisen `image`-kuvan;
- Alpha-arvoltaan `0` olevat läpinäkyvät pikselit tarkoittavat, että muokkaus on sallittu, ja ei-läpinäkyvät pikselit tarkoittavat, että ne tulee säilyttää;
- RGB-kuvia, jotka ovat vain mustavalkoisia mutta joissa ei ole läpinäkyvyyskanavaa, ei voi käyttää kelvollisina maskeina;
- kehotteen tulee kuvata haluttu kokonainen kuva sekä selkeästi paikallinen muutos ja muuttumattomina pidettävät sisällöt.

Luo seuraavaksi maski alkuperäisestä kuvasta. Esimerkki asettaa keskimmäisen suorakulmion läpinäkyväksi ja sallii mallin muokata vain tätä aluetta:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Lataa sitten alkuperäinen kuva ja maski yhdessä:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Voit myös jatkaa OpenAI:n virallisen Python SDK:n `images.edit`-kutsutavan käyttöä; sinun tarvitsee vain osoittaa `base_url` Ace Data Cloudiin:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Kun käytetään `mask`-parametria, alkuperäinen kuva ja maski on ladattava samassa multipart-pyynnössä erikseen `image=@input.png`- ja `mask=@mask.png`-parametreilla. Älä välitä URL-osoitteella olevaa alkuperäistä kuvaa ja paikallista maskitiedostoa yhdessä; pelkät URL-muokkauspyynnöt eivät tue paikallisen `mask`-tiedoston liittämistä. Maski rajoittaa muokkausaluetta, mutta generointimalli saattaa silti sulauttaa reunoja luonnollisesti; kun tarvitaan tarkkoja rajoja, käytä selkeitä Alpha-reunoja ja toista kehotteessa, mikä sisältö on pidettävä muuttumattomana.

Yllä oleva kutsutapa on yhdenmukainen [OpenAI Image Edit API:n](https://developers.openai.com/api/reference/python/resources/images/methods/edit) ja [GPT Image -virallisen Cookbookin](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image) maskiesimerkkien kanssa.
## 5. Yleiset parametrit

| Kenttä                | Kuvaus                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voidaan valita vastaava `:official`-muunnelma, ja `gpt-image-2` tukee myös `:reverse`-muunnelmaa |
| `image`           | JSON käyttää yhtä URL-osoitetta tai enintään 16 URL-osoitteen taulukkoa; multipart käyttää yhtä tai useampaa `image`-tiedostokenttää. Kun käytetään `mask`-kenttää, paikallinen kuvatiedosto on ladattava                                             |
| `mask`            | Valinnainen PNG-maski, vain multipart-tiedostolatauksille; siinä on oltava Alpha-kanava, sen on oltava samankokoinen kuin ensimmäinen `image` eikä se saa ylittää 4 Mt:tä                                                                 |
| `prompt`          | Muokkausohje                                                                                                                             |
| `size`            | `auto` tai rajoitusten mukainen `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; kun `response_format=b64_json`, vain 1 on tuettu                                                                                           |
| `response_format` | `url` tai `b64_json`                                                                                                               |
| `callback_url`    | Valinnainen asynkroninen takaisinsoitto-osoite                                                                                                                         |

Kokosäännöt ovat samat kuin generointirajapinnassa: leveyden ja korkeuden on oltava 16:n kerrannaisia, pidempi sivu ei saa ylittää 3840:tä, pikselien kokonaismäärän on oltava 655 360–8 294 400, eikä kuvasuhde saa ylittää 3:1:tä. Kun `size` jätetään pois tai käytetään `auto`-arvoa, malli valitsee kuvasuhteen kehotteen ja ensimmäisen viitekuvan perusteella.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` ja `gpt-image-2:reverse` laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`, `gpt-image-2.5-flare:official` ja `gpt-image-2.5-sunburst:official` laskutetaan teksti-inputin, viitekuva-inputin ja kuva-outputin todellisten tokenien perusteella, ja lopullinen veloitus määräytyy käyttötietueiden mukaan.

## 6. Asynkroninen takaisinsoitto ja vianmääritys

Pitkiin tehtäviin voidaan lisätä pyyntöön:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkroninen 200-vastaus on `{"task_id": "..."}`; valmistumisen jälkeen lopputulos palautetaan takaisinsoitolla. Synkroniset pyynnöt palauttavat puolestaan `created`- ja `data`-kentät.

| Tila  | Tarkistus                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Kuvamuoto/-määrä, parametrien yhdistelmä ja kokomuoto; kun käytetään `mask`-kenttää, tarkista PNG Alpha-kanava, 4 Mt:n rajoitus sekä se, vastaako sen koko ensimmäistä alkuperäistä kuvaa |
| 401 | API Key ja Bearer Header                                           |
| 429 | Pyyntötiheys                                                              |
| 504 | Käytä asynkronista takaisinsoittoa                                                            |

Virhevastaus sisältää `trace_id`-kentän. Anna tämä ID palautetta antaessasi, älä anna API Key -avainta.

Täydelliset kentät ja reaaliaikaiset enum-arvot löytyvät [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) -sivulta. Pelkkää tekstiä käyttävää kuvagenerointia varten katso [GPT Image 2 / 2.5 -kuvagenerointi](https://platform.acedata.cloud/documents/openai-images-generations).
