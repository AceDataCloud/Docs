## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API-avain.

## 2. Muokkaa kuvan URL-osoitteella

Alkuperäinen kuva:

![GPT Image 2 -muokkauksen alkuperäinen kuva](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

## 3. Lataa paikallinen kuva

Käytä `multipart/form-data`-muotoa:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` voidaan lähettää toistuvasti, ja GPT Image -sarja tukee enintään 16 viitekuvaa. JSON-pyynnön `image` voi olla yksittäinen URL-osoite tai URL-osoitteiden taulukko; paikalliset tiedostot ladataan multipart-muodossa.

### Mallit ja laskutustavat

| Malli                                | Sovellusskenaariot ja laskutustavat                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Oletusarvoinen käänteiskanava, kiinteä laskutus onnistuneiden kuvien määrän mukaan                        |
| `gpt-image-2:reverse`             | Valitsee käänteiskanavan nimenomaisesti, kiinteä laskutus onnistuneiden kuvien määrän mukaan                      |
| `gpt-image-2:official`            | Virallinen API-kanava, parempi vakaus, laskutus todellisen Token-kulutuksen mukaan            |
| `gpt-image-2.5-flare`             | Painottaa generointinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                        |
| `gpt-image-2.5-flare:official`    | Virallinen API-kanava, parempi vakaus ja painotus generointinopeuteen, laskutus todellisen Token-kulutuksen mukaan     |
| `gpt-image-2.5-sunburst`          | Painottaa korkeaa tarkkuutta ja yksityiskohtaista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                    |
| `gpt-image-2.5-sunburst:official` | Virallinen API-kanava, parempi vakaus ja painotus korkeaan tarkkuuteen sekä yksityiskohtaiseen hallintaan, laskutus todellisen Token-kulutuksen mukaan |

Virallisen API-kanavan sivuhinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy vastauksen todellisen Token-kulutuksen ja käyttötietojen perusteella.

`quality` tukee arvoja `auto`, `low`, `medium`, `high`; vain `gpt-image-2.5-flare` ja `gpt-image-2.5-sunburst` (mukaan lukien `:official`-variantit) tukevat lisäksi arvoja `xhigh`, `max`. Sekä JSON-kuva-URL-muokkaus että multipart-tiedostomuokkaus voivat välittää tämän kentän; virallinen kanava laskuttaa todellisen Token-kulutuksen mukaan.

## 4. Käytä maskia paikalliseen muokkaukseen

Virallinen Images Edit -rajapinta määrittää `mask`-kentän avulla alueen, jota saa muokata. Ace Data Cloudin `:official`-mallit noudattavat samaa multipart-sopimusta:

- `mask`-kuvan on oltava PNG, jossa on Alpha-kanava, ja sen koon on oltava enintään 4 Mt;
- maskin koon on vastattava täsmälleen ensimmäistä `image`-kuvaa;
- Alpha-arvon `0` läpinäkyvät pikselit tarkoittavat, että muokkaus on sallittu, ja läpinäkymättömät pikselit tarkoittavat, että ne on säilytettävä;
- pelkästään mustavalkoinen RGB-kuva, jossa ei ole läpinäkyvyyskanavaa, ei voi toimia kelvollisena maskina;
- kehotteen tulisi kuvata haluttu kokonainen kuva sekä selkeästi paikallinen muutos ja muuttumattomana säilytettävä sisältö.

Luo ensin maski alkuperäisestä kuvasta. Esimerkki asettaa keskellä olevan suorakulmion läpinäkyväksi ja sallii mallin muokata vain tätä aluetta:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Lataa sitten alkuperäinen kuva ja maski yhdessä:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Voit myös käyttää OpenAI:n virallisen Python SDK:n `images.edit`-kutsutapaa; sinun tarvitsee vain osoittaa `base_url` Ace Data Cloudiin:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```
Käytettäessä `mask`-kenttää alkuperäinen kuva ja maski on ladattava samassa multipart-pyynnössä erikseen kentillä `image=@input.png` ja `mask=@mask.png`. Älä välitä URL-alkuperäiskuvaa ja paikallista maskitiedostoa yhdessä; pelkät URL-muokkauspyynnöt eivät tue paikallisen `mask`-tiedoston liittämistä. Maski rajoittaa muokkausaluetta, mutta generointimalli voi silti tehdä reunoihin luonnollista sulautumista; kun tarvitaan tiukkoja rajoja, käytä selkeitä Alpha-reunoja ja toista kehotteessa, minkä sisällön on pysyttävä muuttumattomana.

Yllä oleva kutsutapa vastaa [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit)- ja [GPT Image virallisen Cookbookin](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image) maskiesimerkkejä.

## 5. Yleiset parametrit

| Kenttä                | Kuvaus                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voidaan valita vastaava `:official`-variantti, ja `gpt-image-2` tukee myös `:reverse`-varianttia |
| `image`           | JSON käyttää yhtä URL-osoitetta tai enintään 16 URL-osoitteen taulukkoa; multipart käyttää yhtä tai useampaa `image`-tiedostokenttää. `mask`-kenttää käytettäessä on ladattava paikallinen kuvatiedosto                                              |
| `mask`            | Valinnainen PNG-maski, vain multipart-tiedostolatauksiin; siinä on oltava Alpha-kanava, sen on oltava saman kokoinen kuin ensimmäinen `image`, eikä se saa ylittää 4 Mt:tä                                                                 |
| `prompt`          | Muokkausohje                                                                                                                             |
| `size`            | `auto` tai rajoitusten mukainen `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; kun `response_format=b64_json`, tuetaan vain arvoa 1                                                                                           |
| `response_format` | `url` tai `b64_json`                                                                                                               |
| `callback_url`    | Valinnainen asynkroninen takaisinsoitto-osoite                                                                                                                         |

Kokosäännöt ovat samat kuin generointirajapinnassa: leveyden ja korkeuden on oltava 16:n kerrannaisia, pisin sivu ei saa ylittää arvoa 3840, kokonaispikselimäärän on oltava 655,360–8,294,400 ja kuvasuhde ei saa ylittää 3:1. Kun `size` jätetään pois tai käytetään `auto`-arvoa, malli valitsee kuvasuhteen kehotteen ja ensimmäisen viitekuvan perusteella.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` ja `gpt-image-2:reverse` laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`, `gpt-image-2.5-flare:official` ja `gpt-image-2.5-sunburst:official` laskutetaan tekstisyötteen, viitekuvasyötteen ja kuvatuotoksen todellisten Tokenien perusteella, ja lopullinen tieto määräytyy käyttötietueiden mukaan.

## 6. Asynkroninen takaisinsoitto ja vianmääritys

Pitkiin tehtäviin voidaan lisätä pyyntöön:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynkroninen 200-vastaus on `{"task_id": "..."}`; valmistumisen jälkeen takaisinsoitto palauttaa lopullisen tuloksen. Synkroninen pyyntö palauttaa puolestaan `created`- ja `data`-kentät.

| Tila  | Tarkista                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Kuvamuoto/-määrä, parametrien yhdistelmä ja kokomuoto; `mask`-kenttää käytettäessä tarkista PNG Alpha-kanava, 4 Mt:n rajoitus sekä se, vastaavatko sen mitat ensimmäistä alkuperäiskuvaa |
| 401 | API Key ja Bearer Header                                           |
| 429 | Pyyntötaajuus                                                              |
| 504 | Siirry käyttämään asynkronista takaisinsoittoa                                                            |

Virhevastaus sisältää `trace_id`-kentän. Anna ongelmasta palautetta antaessasi tämä ID, älä anna API Key -avainta.

Täydelliset kentät ja reaaliaikaiset enum-arvot löytyvät [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) -sivulta. Pelkkään tekstistä kuvaksi -generointiin katso [GPT Image 2 / 2.5 -kuvagenerointi](https://platform.acedata.cloud/documents/openai-images-generations).
