OpenAI:n kuvien muokkauspalvelu mahdollistaa minkä tahansa määrän kuvien ja ohjeiden syöttämisen, ja palauttaa muokatun kuvan. Tällä hetkellä rajapinta tukee samanaikaisesti `dall-e-2`-, `gpt-image-1`-, uusinta **`gpt-image-2`** -mallia sekä saman rajapinnan kautta käytettäviä **`nano-banana` / `nano-banana-2` / `nano-banana-pro`** -mallisarjoja.

Tämä dokumentti esittelee pääasiassa OpenAI Images Edits API:n käytön prosessin, jonka avulla voimme helposti hyödyntää virallista OpenAI:n kuvien muokkaustoimintoa.

## Hakuprosessi

Käyttääksesi OpenAI Images Edits API:a, voit ensin siirtyä [OpenAI Images Edits API](https://platform.acedata.cloud/documents/251f1efa-aaa6-462e-8af4-66854b1bc94d) -sivulle ja klikata "Acquire"-painiketta saadaksesi pyynnön vaatiman tunnisteen:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, joten API:a voi käyttää ilmaiseksi.

## GPT-Image-2 -malli

`gpt-image-2` tarjoaa kuvien muokkauksessa merkittäviä parannuksia verrattuna `gpt-image-1` -malliin:

- **Rakenteen säilyminen vakaampana**: Ihon vaihtaminen, värimaailman muutos ja taustan vaihto eivät juuri riko alkuperäisen kuvan asettelua tai sommittelua.
- **Tekstin säilyminen tarkempana**: Infografiikat, julisteet, valikot ja muut tekstiä sisältävät kuvat säilyttävät tekstin selkeänä ja luettavana muokkauksen jälkeen.
- **URL-suora lähetys**: Perinteisen `multipart/form-data` -tiedostolatauksen lisäksi `gpt-image-2` tukee **kuvan URL:n syöttämistä JSON-muodossa**, joten kuvaa ei tarvitse ensin ladata paikallisesti, mikä sopii erinomaisesti palvelinpuolen työnkulkuihin.
- **Korkean resoluution uudelleenpiirto**: Voit syöttää 1K alkuperäiskuvan ja pyytää `size`-parametrilla 2K- tai 4K-tulosteen, jolloin malli suorittaa muokkauksen lisäksi kuvan suurennuksen.

### Tuetut `size`-arvot ja hinnoitteluluokat

Muokkausrajapinnan `size`-rajoitukset ovat täysin samat kuin generointirajapinnassa — `gpt-image-2` hyväksyy `size`-arvoksi `auto`, tyhjän arvon tai `WIDTHxHEIGHT`-muodon, muut muodot palauttavat 400-virheen. Hinnoittelu jakautuu kahteen luokkaan, jotka eivät riipu alkuperäisen kuvan resoluutiosta, vaan ainoastaan pyydetystä `size`-arvosta:

- **1K vakiohinta**: Alla olevassa taulukossa mikä tahansa 1K suosituskoko tai yleiset 1K nimikkeet (kuten `1254x1254`, `1672x941`, `941x1672`).
- **Muut luokat (1.5×)**: Sisältää taulukon suositellut 2K / 4K esiasetukset sekä kaikki omat `WIDTHxHEIGHT` -koot.

Ylävirran tiukat rajoitukset pätevät myös: leveys ja korkeus ovat 16:n kerrannaisia, pisin sivu ≤ 3840 ja kokonaispikselimäärä ≤ 8 294 400.

| Kuvasuhde | 1K (vakiohinta) | 2K suositus (×1.5) | 4K suositus (×1.5) |
| --- | --- | --- | --- |
| 1:1 | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3 | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4 | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

> Esimerkiksi: Jos alkuperäinen kuva on `1024x1024` ja `size` on `2048x2048`, malli piirtää ohjeiden mukaisesti 2K kuvan ja veloittaa "muu" luokan mukaan; jos `size` on `3840x2160`, tulostuu 4K vaakakuva, veloitus on myös "muu" luokka; jos `size` on `auto` tai jätetty pois, veloitetaan 1K vakiohinnan mukaan.

> **`n`-parametrista**
>
> `gpt-image-2` muokkausrajapinta **ei tue `n > 1`** -arvoja: tämä parametri ohitetaan hiljaisesti, riippumatta siitä onko arvo `n=1` vai `n=10`, yhdestä pyynnöstä palautetaan vain yksi kuva ja veloitetaan yhden kuvan mukaan. Jos haluat useita ehdokkaita kerralla, tee useita rinnakkaisia pyyntöjä. Sama rajoitus koskee myös `gpt-image-1` / `gpt-image-1.5` ja `nano-banana` / `nano-banana-2` / `nano-banana-pro` -sarjoja. `dall-e-2` on ainoa muokkausmalli, joka natiivisti tukee `n > 1` -arvoa.

Seuraavaksi esitellään kaksi todellista esimerkkiä, jotka havainnollistavat `gpt-image-2` -mallin muokkauskykyjä.

### Kutsutapa 1: JSON + kuvan URL (suositeltu)

Lähetä pyyntö `application/json` -sisältönä, `image`-kenttään annetaan kuvan URL, malli hakee kuvan ja muokkaa sitä `prompt`-ohjeen mukaan.

Esimerkiksi alla oleva alkuperäinen kuva on `gpt-image-2`:lla luotu tietokuvitus:

<p><img src="https://platform.cdn.acedata.cloud/gpt-image/5c9fa635-8794-4c6d-88f8-584d7f4716c6_0.png" width="500" className="m-auto" /></p>

Haluamme muuttaa sen "yötilaksi". Kutsu tapahtuu näin:

```shell
curl -X POST "https://api.acedata.cloud/openai/images/edits" \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform.cdn.acedata.cloud/gpt-image/5c9fa635-8794-4c6d-88f8-584d7f4716c6_0.png",
    "prompt": "Convert this infographic to dark mode: dark navy background, light cream text, deep gray rounded module cards with soft shadows. Keep all layout, structure, and module arrangement identical — only invert the color scheme.",
    "size": "1024x1536"
  }'
```

Tai Pythonilla:

```python
import requests

url = "https://api.acedata.cloud/openai/images/edits"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-image-2",
    "image": "https://platform.cdn.acedata.cloud/gpt-image/5c9fa635-8794-4c6d-88f8-584d7f4716c6_0.png",
    "prompt": "Convert this infographic to dark mode: dark navy background, light cream text, deep gray rounded module cards with soft shadows. Keep all layout, structure, and module arrangement identical — only invert the color scheme.",
    "size": "1024x1536"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautus näyttää tältä:

```json
{
  "success": true,
  "task_id": "cb104e35-af1f-45be-9fac-b62e2b256753",
  "trace_id": "3e5c77c6-6c2e-4bba-a42d-98ea049b58a8",
  "created": 1777048863,
  "data": [
    {
      "revised_prompt": "Convert this infographic to dark mode: dark navy background, light cream text, deep gray rounded module cards with soft shadows. Keep all layout, structure, and module arrangement identical — only invert the color scheme.",
      "url": "https://platform.cdn.acedata.cloud/gpt-image/cb104e35-af1f-45be-9fac-b62e2b256753_0.png"
    }
  ],
  "elapsed": 83.859
}
```

Muokattu kuva:

<p><img src="https://platform.cdn.acedata.cloud/gpt-image/cb104e35-af1f-45be-9fac-b62e2b256753_0.png" width="500" className="m-auto" /></p>

Näet, että moduulirakenne, tietojako ja fonttiasettelu säilyivät tarkasti, vain värimaailma käännettiin tummaksi teemaksi.

> **Vinkki**: `image`-kenttään voi myös antaa taulukon, esim. `"image": ["url1", "url2", "url3"]`, jolloin voit syöttää enintään 16 viitekuvaa, joista malli ottaa kokonaisarvion muokkaukseen.

### Kutsutapa 2: JSON + useita viitekuvia

### Kutsutapa 3: multipart/form-data (yhteensopiva OpenAI SDK:n kanssa)

Jos käytät virallista OpenAI Python SDK:ta, perinteinen `multipart/form-data` -tiedostolataus toimii edelleen, vaihda vain `model` arvoksi `gpt-image-2`:

```python
import base64
from openai import OpenAI
client = OpenAI()

result = client.images.edit(
    model="gpt-image-2",
    image=[open("test.png", "rb")],
    prompt="Convert this image to dark mode while keeping the layout intact."
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)
with open("edited.png", "wb") as f:
    f.write(image_bytes)
```

SDK:n käyttöä varten tuo ensin kaksi ympäristömuuttujaa, aseta `OPENAI_BASE_URL` arvoksi `https://api.acedata.cloud/openai` ja `OPENAI_API_KEY` arvoksi hakemasi token:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token}
```

## Nano Banana -mallisarja

`nano-banana` -sarja on myös liitetty `/openai/images/edits` -rajapintaan, vaihda `model` arvoksi alla olevan taulukon jokin vaihtoehto.

| Malli | Hinnoittelu (Credits / kerta) | Käyttötarkoitus |
| --- | --- | --- |
| `nano-banana` | 0.14 | Tavallinen kuvien muokkaus, nopein ja edullisin |
| `nano-banana-2` | 0.28 | Selkeä parannus laatuun ja yksityiskohtiin |
| `nano-banana-pro` | 0.35 | Lippulaivamalli, paras rakenteen, tekstin ja tyylin säilytys |

> **Tärkeää: tuetut parametrit**
>
> Nano Banana käyttää OpenAI-protokollan sovituskerrosta, tukee vain seuraavia parametreja: `model`, `prompt`, `image`.
>
> - `image` voidaan lähettää tiedostona `multipart/form-data` -muodossa (worker muuntaa sen `data:<mime>;base64,...` -muotoon ylävirralle) tai suoraan lomakekenttänä kuvan URL-osoitteena.
> - Parametreja kuten `mask`, `n`, `size`, `response_format` ei tueta; ne ohitetaan, jos annettu.
> - Palautusrakenne noudattaa OpenAI-muotoa (`data[].url`), mutta `created` on aina `0`, eikä `b64_json` tai `revised_prompt` muutu alkuperäisestä.

### Lomake + kuvan URL -kutsu

```shell
curl -X POST "https://api.acedata.cloud/openai/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=nano-banana" \
  -F "prompt=add a green leaf on top of the apple" \
  -F "image=https://platform.cdn.acedata.cloud/nanobanana/6870b330-65c4-436c-bb80-819fdae7a7a4.png"
```

Palautus:

```json

  "created": 0,
  "data": [
    {
      "url": "https://platform.cdn.acedata.cloud/nanobanana/311e95b6-5eb1-4c4a-8ee6-0cb03ee44f61.jpeg",
      "revised_prompt": "add a green leaf on top of the apple"
    }
  ]
}
```

Muokattu kuva:

<p><img src="https://platform.cdn.acedata.cloud/nanobanana/311e95b6-5eb1-4c4a-8ee6-0cb03ee44f61.jpeg" width="500" className="m-auto" /></p>

### Lomake + paikallinen tiedosto -kutsu

```python
import requests

url = "https://api.acedata.cloud/openai/images/edits"

headers = {
    "authorization": "Bearer {token}"
}

files = {
    "image": open("apple.png", "rb"),
}
data = {
    "model": "nano-banana-pro",
    "prompt": "add a green leaf on top of the apple"
}

response = requests.post(url, headers=headers, files=files, data=data)
print(response.text)
```

### Asynkroninen callback

`callback_url`-asynkroninen palautekutsu toimii myös nano-banana-mallien kanssa, kutsuprosessi on sama kuin muillakin malleilla, katso lisää alla [Asynkroninen callback](#asynkroninen-callback) -osiossa.

## Peruskäyttö

Seuraavaksi voit tehdä kutsuja koodilla. Alla esimerkki CURL-kutsusta:

```curl
curl -s -D >(grep -i x-request-id >&2) \
  -o >(jq -r '.data[0].b64_json' | base64 --decode > gift-basket.png) \
  -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F 'prompt=Create a lovely gift basket with these this items in it'
```

Ensimmäisellä käyttökerralla sinun tulee täyttää ainakin neljä asiaa: `authorization` valitaan alasvetovalikosta; `model` valitaan OpenAI:n virallisista mallivaihtoehdoista (tässä dokumentissa on yksi malli, katso tarkemmat tiedot yllä olevasta mallilistasta); `prompt` on kuvaa luova ohje; ja `image` on muokattavan kuvan tiedostopolku, kuten alla oleva kuva:

<p><img src="https://cdn.acedata.cloud/jw9iwu.png" width="500" className="m-auto" /></p>

Saman kutsun Python-esimerkki:

```python
import base64
from openai import OpenAI
client = OpenAI()

prompt = """
Generate a photorealistic image of a gift basket on a white background 
labeled 'Relax & Unwind' with a ribbon and handwriting-like font, 
containing all the items in the reference pictures.
"""

result = client.images.edit(
    model="gpt-image-1",
    image=[
        open("test.png", "rb")
    ],
    prompt=prompt
)

image_base64 = result.data[0].b64_json
image_bytes = base64.b64decode(image_base64)

# Tallenna kuva tiedostoon
with open("gift-basket.png", "wb") as f:
    f.write(image_bytes)
```

Python-kutsua varten tuo ensin kaksi ympäristömuuttujaa: `OPENAI_BASE_URL` asetetaan arvoon `https://api.acedata.cloud/openai` ja `OPENAI_API_KEY` asetetaan hakemaasi tokeniin. Mac OS:ssa voit asettaa ne näin:

```shell
export OPENAI_BASE_URL=https://api.acedata.cloud/openai
export OPENAI_API_KEY={token} 
```

Kutsun jälkeen näet, että nykyiseen hakemistoon luodaan kuva nimeltä `gift-basket.png`, tulos näyttää tältä:

<p><img src="https://cdn.acedata.cloud/574s8h.png" width="500" className="m-auto" /></p>

Näin olemme suorittaneet kuvan muokkauksen. Edits-rajapinta tukee tällä hetkellä kolmea mallia: `dall-e-2`, `gpt-image-1` ja `gpt-image-2`, joista `gpt-image-2` on suositeltavin, katso lisää yllä [GPT-Image-2 -malli](#gpt-image-2--malli) -osiossa.

## Asynkroninen callback

Koska OpenAI Images Edits API:n kuvanmuokkaus voi kestää jonkin aikaa, pitkään vastaamaton HTTP-pyyntö pitää yhteyden auki ja kuluttaa järjestelmäresursseja. Siksi API tukee myös asynkronista callback-toimintoa.

Prosessi on seuraava: asiakasohjelma lähettää pyynnön, jossa määritellään `callback_url`-kenttä. API vastaa heti tuloksella, joka sisältää `task_id`-tunnisteen. Kun tehtävä on valmis, muokattu kuva lähetetään POST-muodossa JSON-dataa käyttäen asiakkaan määrittelemään `callback_url`-osoitteeseen, mukana on myös sama `task_id`, jolla tehtävä voidaan yhdistää.

Seuraavassa esimerkki käytännöstä.

Webhook callback on HTTP-palvelu, joka vastaanottaa pyyntöjä. Kehittäjän tulee korvata se omalla palvelimellaan. Tässä esimerkissä käytetään julkista webhook-sivustoa https://webhook.site/, josta saa webhook-URL:n, kuten alla:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, esimerkiksi `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`, ja käytä sitä callback-URL:na. Lähetä pyyntö seuraavasti:

```shell
curl -X POST "https://api.acedata.cloud/v1/images/edits" \
  -H "Authorization: Bearer {token}" \
  -F "model=gpt-image-1" \
  -F "image[]=@test.png" \
  -F "prompt=Create a lovely gift basket with these items in it" \
  -F "callback_url=https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
```

Saat heti vastauksen:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Hetken kuluttua webhook-URL:ssä näkyy muokkaustulos:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "b64_json": "iVBORw0KGgo..."
      }
    ]
  }
}
```

Tuloksessa on `task_id`-kenttä ja `data`-kenttä sisältää saman kuvanmuokkaustuloksen kuin synkronisessa kutsussa. Näin tehtävän voi yhdistää tunnisteen perusteella.

## Virheiden käsittely

API-kutsun yhteydessä virhetilanteissa API palauttaa virhekoodin ja viestin. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvia tai virheellisiä parametreja.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvia tai virheellisiä parametreja.
- `401 invalid_token`: Luvaton, virheellinen tai puuttuva valtuutustunniste.
- `429 too_many_requests`: Liian monta pyyntöä, ylität rajoitukset.
- `500 api_error`: Sisäinen palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
