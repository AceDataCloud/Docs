Muunna ääni tekstiksi, **täysin yhteensopiva OpenAI:n `/v1/audio/transcriptions`** kanssa. Mikä tahansa OpenAI SDK tarvitsee vain asettaa `base_url` osoittamaan `https://api.acedata.cloud` ja vaihtaa avain omaksi AceData Tokeniksi, jotta se voidaan käyttää suoraan. Tukee normaalia täydellistä vastausta sekä `gpt-transcribe` SSE inkrementaalista transkriptiota.

- **Pyyntöosoite**: `POST https://api.acedata.cloud/v1/audio/transcriptions` (alias `POST /openai/audio/transcriptions`)
- **Todennus**: Pyyntöotsikko `Authorization: Bearer {token}`
- **Pyyntömuoto**: `multipart/form-data`
- **Laskutus**: Laskutetaan äänen keston mukaan (katso alla oleva taulukko), alle 1 sekunti laskutetaan 1 sekunnin mukaan.

## Pyyntöparametrit

| Kenttä                       | Tyyppi    | Pakollinen | Selitys                                                                                     |
| --------------------------- | ------- | -------- | ------------------------------------------------------------------------------------------ |
| `file`                      | tiedosto | Kyllä    | Muunnettava äänitiedosto, enintään 25 MB. Tukee `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`.            |
| `model`                     | merkkijono | Ei      | `whisper-1` (oletus) tai `gpt-transcribe`, kykyeroja katso alla olevalta taulukolta.                                                 |
| `language`                  | merkkijono | Ei      | Äänen kieli, ISO-639-1 koodi (esim. `zh`, `en`). Täyttämällä voi parantaa tarkkuutta ja nopeutta; tyhjää jättämällä tunnistetaan automaattisesti.                                        |
| `prompt`                    | merkkijono | Ei      | Kehotus, joka ohjaa kirjoitustyyliä tai tarjoaa erikoisnimiä, termejä tarkkuuden parantamiseksi.                                                           |
| `response_format`           | merkkijono | Ei      | `whisper-1`: `json` (oletus), `text`, `srt`, `verbose_json`, `vtt`; `gpt-transcribe`: vain `json`, `text`. |
| `temperature`               | numero   | Ei      | Näytteen lämpötila 0–1, oletus 0.                                                                             |
| `timestamp_granularities[]` | taulukko | Ei      | Aikaleiman tarkkuus, `word` tai `segment`, on käytettävä yhdessä `response_format=verbose_json` kanssa.                            |
| `languages[]`               | taulukko | Ei      | Ehdotetut kielet (ISO-639-1), **vain `gpt-transcribe`**. Eroaa `language`-kentästä, älä lähetä molempia samanaikaisesti.                              |
| `keywords[]`                | taulukko | Ei      | Erikoisnimet/termit, **vain `gpt-transcribe`**, voi merkittävästi parantaa brändin ja henkilön nimien tunnistustarkkuutta.                                        |
| `stream`                    | boolean  | Ei      | `gpt-transcribe` asetettuna `true` palauttaa SSE inkrementaaliset tapahtumat; `whisper-1` ohittaa tämän parametrin ja palauttaa täydelliset tulokset (yhteensopiva OpenAI:n virallisen käytöksen kanssa).        |

## Valitse malli

|                              | `whisper-1`      | `gpt-transcribe`      |
| ---------------------------- | ---------------- | --------------------- |
| Hinta                         | $0.0078 / minuutti | **$0.0059 / minuutti** (halvempi) |
| Tunnistustarkkuus            | Hyvä              | **Parempi**, erityisesti brändinimet, erikoisnimet    |
| Tekstityksen ulostulo (`srt`/`vtt`) | ✅                | ❌                     |
| Sanatason aikaleimat         | ✅                | ❌                     |
| `languages[]` / `keywords[]` | ❌                | ✅                     |
| Palauttaa tunnistetun kielen  | vaatii `verbose_json` | Oletuksena palauttaa                  |
| SSE inkrementaalinen palautus | ❌ ( `stream` ohitetaan)  | ✅                     |

**Tarvitsetko tekstityksiä tai sanatasoisia aikaleimoja → `whisper-1`; muissa tapauksissa suositellaan `gpt-transcribe`** (tarkempi ja halvempi).

## Esimerkki

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1
```

Palautus:

```json
{
  "text": "Ace Data Cloud Platform is testing the speech recognition endpoint. The quick brown fox jumps over the lazy dog."
}
```

Kiinalainen ääni tukee myös, eikä kielikoodia tarvitse määrittää:

```json
{
  "text": "欢迎使用 AceData Cloud 平台,我们正在测试语音识别接口,今天是 7 月 31 号。"
}
```

### Tuota tekstityksiä

Aseta `response_format` arvoksi `srt` tai `vtt`, niin saat suoraan käyttökelpoisen tekstitystiedoston:

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F response_format=srt \
  -o subtitle.srt
```

Palautussisältö ( `Content-Type: text/plain` ):

```
1
00:00:00,000 --> 00:00:03,800
Ace Data Cloud Platform is testing the speech recognition endpoint.

2
00:00:03,800 --> 00:00:06,280
The quick brown fox jumps over the lazy dog.
```

### Sanatason aikaleimat

Jos tarvitset jokaisen sanan aloitus- ja lopetusaikaa, käytä `verbose_json` yhdessä `timestamp_granularities[]=word` kanssa:

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=whisper-1 \
  -F response_format=verbose_json \
  -F 'timestamp_granularities[]=word'
```

Palautus:

```json
{
  "task": "transcribe",
  "language": "english",
  "duration": 6.29,
  "text": "Ace Data Cloud Platform is testing the speech recognition endpoint. The quick brown fox jumps over the lazy dog.",
  "words": [
    {
      "word": "Ace",
      "start": 0.0,
      "end": 0.32
    },
    {
      "word": "Data",
      "start": 0.32,
      "end": 0.54
    },
    {
      "word": "Cloud",
      "start": 0.54,
      "end": 0.86
    }
  ]
}
```

### Virtaustranskripti

`gpt-transcribe` voi palauttaa `Content-Type: text/event-stream` asettamalla `stream=true`. Palvelu lähettää OpenAI-yhteensopivia tapahtumia sellaisenaan:
`transcript.text.delta` sisältää inkrementaalista tekstiä, `transcript.text.done` sisältää täydellisen tekstin ja `usage` ja ilmoittaa normaalista valmistumisesta.

```shell
curl -N -X POST 'https://api.acedata.cloud/v1/audio/transcriptions' \
  -H 'authorization: Bearer {token}' \
  -F file=@audio.mp3 \
  -F model=gpt-transcribe \
  -F stream=true
```

Tapahtumavirran esimerkki:

```text
data: {"type":"transcript.text.delta","delta":"Hello"}

data: {"type":"transcript.text.done","text":"Hello world","usage":{"type":"tokens","input_tokens":14,"output_tokens":3,"total_tokens":17}}
```

Vastaus `transcript.text.done` merkitsee normaalin valmistumisen. Jos virran luomisen jälkeen käsittely epäonnistuu, yhteys päättyy `event: error` -tapahtuman jälkeen; asiakas, joka katkaisee yhteyden, peruuttaa tämän käsittelyn, eikä se jatka taustalla. `whisper-1` palauttaa silti tavallisen ei-virtaustuloksen, vaikka `stream=true` olisi asetettu.

### Käytä virallista SDK:ta
```python
from openai import OpenAI

client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
with open("audio.mp3", "rb") as f:
    result = client.audio.transcriptions.create(model="whisper-1", file=f)
print(result.text)
```

## Hinnat

| Malli             | Tämän alustan hinta |
| ---------------- | ------------------- |
| `whisper-1`      | $0.0078 / minuutti   |
| `gpt-transcribe` | $0.0059 / minuutti   |

> Laskutus perustuu äänen todelliseen kestoon, alle 1 sekunti laskutetaan 1 sekunnin mukaan, kerralla pisin 1 tunti.

## Huomautuksia

- Yhden tiedoston enimmäiskoko on **25 MB**. Yli tämän rajan tulee jakaa tai pakata (yleensä riittää, että alennetaan bittinopeutta, äänen tunnistus ei vaadi korkeaa äänenlaatua).
- `gpt-transcribe` tukee `stream=true` SSE; `whisper-1` ohittaa `stream` ja palauttaa täydelliset tulokset.
- Parametrit ovat yhdenmukaisia OpenAI:n virallisen `/v1/audio/transcriptions` kanssa, virallista SDK:ta voi käyttää vain muuttamalla `base_url`.
- `include[]`, `chunking_strategy`, `known_speaker_names[]`, `known_speaker_references[]` kuuluvat meidän julkaisemattomiin
  transkriptiomalleihin, niiden antaminen palauttaa 400 eikä hiljaa ohita. Mallikohtaiset parametrit (`timestamp_granularities[]` `whisper-1`:lle,
  `languages[]`/`keywords[]` `gpt-transcribe`:lle) palauttavat myös 400, jos niitä annetaan tuettuun malliin.
- Pyyntöjen käsittely vie aikaa, suosittelemme asiakaspään aikakatkaisun asettamista vähintään 300 sekuntiin.

## Virhekoodit

| Tila | koodi                  | Selitys                                                                                                                                               |
| ---- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 400  | `bad_request`         | `file` ei ole annettu, tiedostoa ei voida käsitellä tai parametrit ovat virheellisiä (`model`/`response_format` arvo ei tuettu, `temperature` yli 0–1, `timestamp_granularities[]` ei ole yhdistetty `verbose_json`:iin, annettu `whisper-1`:lle tuettu parametri). |
| 401  | `authentication_failed` | token on virheellinen.                                                                                                                                 |
| 403  | `used_up`             | Saldo on riittämätön.                                                                                                                                  |
| 413  | `request_too_large`   | Äänitiedosto ylittää 25 MB rajan.                                                                                                                        |
| 429  | `too_many_requests`    | Pyyntöjä on liian monta, yritä myöhemmin uudelleen.                                                                                                        |
| 500  | `api_error`           | Palvelinvirhe, yritä myöhemmin uudelleen.                                                                                                                |
