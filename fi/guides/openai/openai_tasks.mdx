OpenAI Tasks API:ta käytetään aiemmin **callback-tilassa** OpenAI:n kuvapalveluun lähetettyjen tehtävien tulosten kysymiseen. Kun et voi odottaa synkronista HTTP-vastausta tai haluat kysyä tehtävää myöhemmin, käytä tätä rajapintaa.

Callback-tilassa **alkuperäinen kuvapalvelu palauttaa heti `task_id`:n** käsittelyn jälkeen, ja voit käyttää tätä `task_id`:ta kysyäksesi tätä rajapintaa tarvittaessa, ilman tarvetta välittää ylimääräistä mukautettua `trace_id`:ta (vain jos haluat yhdistää sen omaan liiketoimintaasi).

> Tehtävä tallennetaan pysyvästi vain, jos alkuperäisessä kuvapyyntösi on mukana `callback_url`. Synkronisesti (ei callback) kutsuttuja pyyntöjä ei tallenneta.

## Hakuprosessi

OpenAI Tasks API jakaa valtuutuksen olemassa olevien OpenAI-palveluiden kanssa. Jos olet jo hakenut OpenAI Images Generations -palvelua, voit käyttää samaa tokenia tämän rajapinnan kutsumiseen ilman lisähakemusta.

Uusilla käyttäjillä on ensimmäisellä hakemuskerralla ilmainen käyttöoikeus.

## Rajapintosoite

```
POST https://api.acedata.cloud/openai/tasks
```

Tuetut `action`:

| Toiminto          | Selitys                                                      |
| ---------------- | ---------------------------------------------------------- |
| `retrieve`       | Kysyy yksittäistä tehtävää `id`:n tai `trace_id`:n avulla         |
| `retrieve_batch` | Kysyy useita tehtäviä `ids` / `trace_ids` / `application_id` / `user_id` avulla |

## Pyyntöotsikot

- `accept: application/json`
- `authorization: Bearer {token}`
- `content-type: application/json`

## Yksittäinen tehtäväkysely (`retrieve`)

### Pyyntöruumis

| Kenttä       | Tyyppi   | Pakollinen | Selitys                                  |
| ------------ | -------- | ---------- | ---------------------------------------- |
| `action`     | string   | Kyllä      | Kiinteästi `retrieve`                   |
| `id`         | string   | Valinnainen| Tehtävän ID, joka palautettiin synkronisessa vastauksessa (suositeltavaa käyttää) |
| `trace_id`   | string   | Valinnainen| Vain jos olet erikseen antanut mukautetun `trace_id` alkuperäisessä pyynnössä |

`id` ja `trace_id` on annettava vähintään yksi. Yleensä voit käyttää suoraan lähetetyn vastauksen `id`:tä, `trace_id` on vain tarpeen, jos haluat yhdistää sen mukautettuun liiketoimintaasi.

### Koodiesimerkki

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/openai/tasks' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "action": "retrieve",
    "id": "7489df4c-ef03-4de0-b598-e9a590793434"
  }'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/openai/tasks"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "action": "retrieve",
    "id": "7489df4c-ef03-4de0-b598-e9a590793434",
}
response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Kenttäselitykset

- `id`: Alkuperäisessä kuvapyynnössä luotu tehtävän ID.
- `trace_id`: Alkuperäisessä pyynnössä annettu mukautettu jäljitystunnus, joka helpottaa asiakasliiketoiminnan yhdistämistä.
- `type`: Tehtävän tyyppi. `gpt-image` -sarjan (kuten `gpt-image-2`) kirjoittamat tehtävät ovat `images`; `gpt-image-1`, nano-banana jne. käyttävät `images_generations` / `images_edits`, osa keskusteluliittymistä on `chat_completions_image`.
- `request`: Alkuperäisen pyynnön täydellinen pyyntöruumis.
- `response`: Callbackin valmistuttua palautettu lopullinen vastausruumis.
- `created_at` / `started_at` / `finished_at`: Unix-aikaleimat (sekunteina, liukuluku).
- `elapsed`: Suoritusajan kesto (sekunteina, liukuluku).
- `application_id` / `user_id` / `credential_id`: Kuuluvat sovellukseen, loppukäyttäjään, ja tunnistetietoihin.

## Ryhmäkysely (`retrieve_batch`)

### Pyyntöruumis

| Kenttä               | Tyyppi       | Selitys                                                       |
| ------------------- | ------------ | ------------------------------------------------------------ |
| `action`            | string       | Kiinteästi `retrieve_batch`                                   |
| `ids`               | string[]     | Kysyy tehtäviä tehtävän ID -listan mukaan                     |
| `trace_ids`         | string[]     | Kysyy tehtäviä `trace_id` -listan mukaan                     |
| `application_id`    | string       | Kysyy kaikkia tehtäviä sovelluksen mukaan                     |
| `user_id`           | string       | Kysyy kaikkia tehtäviä loppukäyttäjän mukaan                  |
| `type`              | string       | Suodattaa tehtäviä tyypin mukaan (arvot: `images`, `images_generations`, `images_edits`) |
| `offset`            | int          | Sivun aloituskohta, oletusarvo `0`                           |
| `limit`             | int          | Yhden sivun määrä, oletusarvo `12`                           |
| `created_at_min`    | float        | Aloitusaikaleima (Unix sekunteina)                           |
| `created_at_max`    | float        | Päättymisaikaleima (Unix sekunteina)                         |

`ids` / `trace_ids` / `application_id` / `user_id` tai `created_at_*` aikaraja riittää antaa.

### CURL Esimerkki

```bash
curl -X POST 'https://api.acedata.cloud/openai/tasks' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "action": "retrieve_batch",
    "trace_ids": ["my-trace-001", "my-trace-002"]
  }'
```

## Päästä päähän esimerkki: Lähetä ja kysy

Tasks API palvelee pääasiassa callback-tilassa asynkronista prosessia. Callback-tilassa, lähetysrajapinta palauttaa **välittömästi synkronoidun `task_id`:n** (eli tehtävän ID), jonka jälkeen voit suoraan käyttää tätä `task_id`:ta Tasks-rajapinnassa kyselyyn, ilman että sinun tarvitsee itse luoda `trace_id`:ta.

```python
import os, time, requests

API = "https://api.acedata.cloud"
HEADERS = {
    "authorization": f"Bearer {os.environ['ACEDATA_API_KEY']}",
    "content-type": "application/json",
}

# 1. Lähetä kuvagenerointitehtävä (callback-tila: lisäämällä callback_url saat välittömästi task_id:n)
submit = requests.post(
    f"{API}/openai/images/generations",
    headers=HEADERS,
    json={
        "model": "gpt-image-1",
        "prompt": "Vesivärityylinen kissa istuu pöydällä",
        "callback_url": "https://webhook.site/your-uuid",
    },
).json()
print("lähetetty:", submit)

task_id = submit["task_id"]

# 2. Kysy suoraan lähetetystä vastauksesta saatua task_id:ta Tasks-rajapinnasta, kunnes tehtävä on valmis
while True:
    task = requests.post(
        f"{API}/openai/tasks",
        headers=HEADERS,
        json={"action": "retrieve", "id": task_id},
    ).json()
    if task and task.get("response"):
        print("valmis:", task["response"])
        break
    time.sleep(3)
```

## Huomioitavaa

- Tasks-rajapinta itsessään **ei veloita**; voit kysyä huoletta. Vain alkuperäiset kuvagenerointi/ muokkauspyynnöt veloitetaan.
- Vain silloin, kun alkuperäinen pyyntö sisältää `callback_url`:n, kirjoitetaan tehtävärekisteri; synkroniset kutsut eivät tuota kyseltävää tehtävää.
- Alustan säilytysaikojen ylittävät tehtävärekisterit voidaan poistaa.
