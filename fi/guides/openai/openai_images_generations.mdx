DALL-E 3 on OpenAI:n kehittämä kaksi versiota kuvagenerointimallista, jotka pystyvät tuottamaan korkealaatuisia kuvia tekstikuvauksen perusteella.

Tässä asiakirjassa esitellään OpenAI Images Generations API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista OpenAI DALL-E:n kuvagenerointitoimintoa.

## Hakuprosessi

Käyttääksesi OpenAI Images Generations API:a, voit ensin siirtyä [OpenAI Images Generations API](https://platform.acedata.cloud/documents/fd932485-90c7-45d6-8394-1e14b6f07b2b) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/zv58ug.png" width="500" class="m-auto"></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, jonka voit valita suoraan avattavasta valikosta. Toinen parametri on `model`, `model` on se, mitä valitsemme käytettäväksi OpenAI DALL-E:n verkkosivuston mallikategoriasta, täällä meillä on pääasiassa 1 malli, yksityiskohdat voit nähdä tarjoamastamme mallista. Viimeinen parametri on `prompt`, `prompt` on se, mitä syötämme luodaksemme kuvan.

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

<p><img src="https://cdn.acedata.cloud/pbss4f.png" width="500" class="m-auto"></p>

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Kuvan laatuparametri `quality`

Seuraavaksi esitellään, kuinka asettaa kuvageneroinnin tulosten joitakin yksityiskohtaisia parametreja, joista kuvien laatuparametri `quality` sisältää kaksi vaihtoehtoa: ensimmäinen `standard` tarkoittaa, että luodaan standardikuvia, toinen `hd` tarkoittaa, että luodut kuvat sisältävät tarkempia yksityiskohtia ja suurempaa johdonmukaisuutta.

Asetetaan kuvien laatuparametri `standard`, tarkat asetukset näkyvät alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/1q303w.png" width="500" class="m-auto"></p>

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

<p><img src="https://cdn.acedata.cloud/c0ps6i.png" width="500" class="m-auto"></p>

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",

response = requests.post(url, json=payload, headers=headers)
```

## Asynkroninen palautus

Koska OpenAI Images Generations API:n kuvagenerointiaika voi olla suhteellisen pitkä, jos API ei vastaa pitkään, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: asiakas käynnistää pyynnön, kun se määrittää ylimääräisen `callback_url` kentän, asiakas käynnistää API-pyynnön jälkeen, API palauttaa heti tuloksen, joka sisältää `task_id` kenttäinformaation, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luodun kuvan tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, johon sisältyy myös `task_id` kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten toiminta tapahtuu.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkissä käytetään julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook-URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, ja voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook-URL:iin ja täyttää vastaavat parametrit, kuten alla olevassa koodissa näkyy:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "Söpö vauva merenotteri",
    "callback_url": "https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten alla:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Odota hetki, niin voit tarkkailla Webhook-URL:lla luodun kuvan tulosta, sisältö on seuraava:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "revised_prompt": "Ihana kuva, joka esittelee nuorta merenotteria...",
        "url": "https://dalleprodsec.blob.core.windows.net/private/images/..."
      }
    ]
  }
}
```

Voit nähdä, että tuloksessa on `task_id` kenttä, `data` kenttä sisältää samanlaisen kuvanluontituloksen kuin synkronisessa kutsussa, `task_id` kentän avulla voidaan toteuttaa tehtävän yhdistäminen.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
