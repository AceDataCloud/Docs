## 1. API Keyn hankkiminen

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ensimmäisen pyynnön lähettäminen

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Onnistuneen vastauksen kuva sijaitsee kohdassa `data[].url`. Alla on Ace Data Cloudin kautta 8. syyskuuta 2026 todellisella pyynnöllä saatu 1024×1536-tulos (tehtävä `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![GPT Image 2:n luoma valkoinen kahvimuki](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Yleiset parametrit

| Kenttä                | Kuvaus                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (oletussuositus), `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voi valita vastaavan `:official`-variantin, ja `gpt-image-2` tukee myös `:reverse`-varianttia |
| `prompt`          | Kuvan kuvaus, enintään 32 000 merkkiä                                                                                                                     |
| `size`            | `auto` tai `WIDTHxHEIGHT`; leveyden ja korkeuden on oltava 16:n kerrannaisia, pidempi sivu saa olla enintään 3840, kokonaispikselimäärä on 655,360–8,294,400 ja kuvasuhde saa olla enintään 3:1                                                       |
| `n`               | 1–10; `response_format=b64_json` tukee vain arvoa 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` tai `auto`; eri reittien tuki ja laskutustapa vaihtelevat                                                                                          |
| `response_format` | `url` tai `b64_json`                                                                                                                     |
| `callback_url`    | Valinnainen; lähettää tuloksen tähän osoitteeseen pitkän tehtävän valmistuttua                                                                                                                      |

Yleiset koot:

| Suhde   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` valitsee kuvakoon kehotteen kuvasuhteen, pikselien ja taittoaikomuksen perusteella; kun tarvitset tarkat pikselit, täytä koko suoraan.

### Mallit ja laskutustavat

| Malli                                | Soveltuvat käyttötapaukset ja laskutustapa                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Oletuskäänteinen kanava, kiinteä laskutus onnistuneiden kuvien määrän mukaan                        |
| `gpt-image-2:reverse`             | Käänteisen kanavan nimenomainen valinta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                      |
| `gpt-image-2:official`            | Virallinen API-kanava, suurempi vakaus, laskutus todellisen Token-käytön mukaan            |
| `gpt-image-2.5-flare`             | Painottaa luontinopeutta, kiinteä laskutus onnistuneiden kuvien määrän mukaan                        |
| `gpt-image-2.5-flare:official`    | Virallinen API-kanava, suurempi vakaus ja painotus luontinopeuteen, laskutus todellisen Token-käytön mukaan     |
| `gpt-image-2.5-sunburst`          | Painottaa suurta tarkkuutta ja hienovaraista hallintaa, kiinteä laskutus onnistuneiden kuvien määrän mukaan                    |
| `gpt-image-2.5-sunburst:official` | Virallinen API-kanava, suurempi vakaus ja painotus suureen tarkkuuteen sekä hienovaraiseen hallintaan, laskutus todellisen Token-käytön mukaan |

Virallisen API-kanavan sivulla näkyvä hinta on arvio ennen pyyntöä; lopullinen hinta määräytyy vastauksen todellisen Token-käytön ja käyttötietueiden perusteella.

## 4. Usean kuvan luonti

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` ja `gpt-image-2:reverse` laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`, `gpt-image-2.5-flare:official` ja `gpt-image-2.5-sunburst:official` veloitetaan vastauksessa olevan tekstisyötteen ja kuvatulosteen todellisten Tokenien perusteella. Sivulla näkyvä hinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy käyttötietueiden perusteella.

## 5. Asynkroninen takaisinsoitto

Kun pyyntöön lisätään `callback_url`, rajapinta palauttaa ensin `{"task_id": "..."}` ja lähettää valmistuttuaan lopullisen tuloksen POST-pyynnöllä tähän URL-osoitteeseen; synkroninen pyyntö palauttaa edelleen `created` ja `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Takaisinsoiton vastaanottajan tulee poistaa kaksoiskappaleet `task_id`:n avulla sekä varmistaa pyynnön alkuperä ja tietomuoto.

## 6. Vianmääritys

| Tila  | Tarkista                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`, `prompt`, kokomuoto sekä `n`- ja `response_format`-yhdistelmä    |
| 401 | Onko API Key täydellinen ja onko Header muodossa `Authorization: Bearer ...` |
| 429 | Pyyntöjä on liian tiheästi, yritä myöhemmin uudelleen                                         |
| 504 | Synkronisen luonnin aikakatkaisu; käytä `callback_url`:ää                            |

Virhevastaus sisältää `error.code`-, `error.message`- ja `trace_id`-kentät. Anna ongelmasta ilmoittaessasi `trace_id`, älä anna API Keytä.

Täydelliset kentät ja reaaliaikaiset luettelot ovat [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) -sivulla. Kuvan muokkausta varten katso [GPT Image 2 / 2.5 -kuvamuokkaus](https://platform.acedata.cloud/documents/openai-images-edits).
