OpenAI Images Generations API tukee tällä hetkellä useita kuvageneraatiomalleja, mukaan lukien klassinen `dall-e-3`, tekstin renderointikyvyltään vahvempi `gpt-image-1`, uusin sukupolvi **`gpt-image-2`**, sekä saman rajapinnan kautta käytettävät **`nano-banana` / `nano-banana-2` / `nano-banana-pro`** -mallisarjat. Ne kaikki pystyvät tuottamaan korkealaatuisia kuvia tekstikuvauksen perusteella.

Tämä dokumentti esittelee pääasiassa OpenAI Images Generations API:n käyttöprosessin, jonka avulla voimme helposti hyödyntää OpenAI:n kuvageneraatiotoimintoja.

## Hakemusprosessi

OpenAI Images Generations API:n käyttämiseksi voit ensin mennä [OpenAI Images Generations API](https://platform.acedata.cloud/documents/fd932485-90c7-45d6-8394-1e14b6f07b2b) -sivulle ja klikata "Acquire"-painiketta saadaksesi pyynnön vaatimat tunnukset:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisen käyttökiintiön, jolla voit käyttää API:a maksutta.

## GPT-Image-2 -malli

`gpt-image-2` on OpenAI:n uusi sukupolven kuvageneraatiomalli, joka tarjoaa selkeitä parannuksia verrattuna `dall-e-3` ja `gpt-image-1` malleihin seuraavilla osa-alueilla:

- **Parempi ohjeiden noudattaminen**: pystyy tarkasti ymmärtämään monimutkaisia rakenteellisia ohjeita, kuten sommittelua, laskemista ja sijaintisuhteita.
- **Selkeämpi tekstin renderointi**: englannin ja numeroiden renderointi julisteissa, menuissa, infografiikoissa ja logoissa on lähes virheetöntä.
- **Monipuolisempi tyylin ilmentäminen**: tukee natiivisti elokuvamaista muotokuvaa, retrojulisteita, lastenkirjakuvituksia, tuotekuvauksia, infografiikoita ja muita tyylejä.
- **Natiivisti useita kuvasuhteita + korkea resoluutio**: tukee 5 kuvasuhdetta (1:1, 4:3, 3:4, 16:9, 9:16) kolmella resoluutiotasolla (1K / 2K / 4K).

Käyttötapa on täysin sama kuin muilla malleilla, riittää että asetat `model`-kentän arvoksi `gpt-image-2`. Palautetun vastauksen `url` on pysyvästi `platform.cdn.acedata.cloud` -palvelimella isännöity kuvalinkki, jonka voi avata suoraan selaimessa tai upottaa verkkosivulle.

### Tuetut `size`-arvot ja hinnoittelutasot

`gpt-image-2` tarkistaa vain `size`-kentän muodon; mikäli arvo ei ole `auto` tai tyhjä, sen tulee olla muotoa `WIDTHxHEIGHT` (esim. `1024x1024`, `2048x1152`, `800x600`); muut muodot palauttavat 400-virheen. Hinnoittelu on kahdessa tasossa:

- **1K perushinta**: syöte on taulukon 1K-suosituskoko tai yleisesti käytetty 1K-ulostulon alias (`1254x1254`, `1672x941`, `941x1672` — nämä ovat yleisiä 1K-kokoluokan mittoja, jotka eivät aiheuta hintamuutoksia).
- **Muut tasot (1.5×)**: kaikki muut kuin yllä mainitut 1K-koot, mukaan lukien taulukon 2K/4K-esiasetukset ja käyttäjän määrittelemät `WIDTHxHEIGHT`-koot.

Ylärajat käyttäjän määrittelemille mitoille: leveys ja korkeus ovat 16:n kerrannaisia, pisin sivu enintään 3840, kokonaispikselimäärä enintään 8 294 400. Ylityksistä palautetaan 4xx-virhe.

| Kuvasuhde | 1K (perushinta) | 2K suositus (×1.5) | 4K suositus (×1.5) |
| --- | --- | --- | --- |
| 1:1 | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3 | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4 | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

> Voit myös asettaa `size: "auto"` tai **jättää `size`-kentän pois**, jolloin malli valitsee oletuskoko automaattisesti ja hinnoittelu on 1K-tasoa.
>
> 1K-tasolla ylävirran ulostulo ei takaa tarkkaa pikselin tarkkuutta — esimerkiksi `1024x1024` voi palauttaa `1254x1254`, mutta kuvasuhde säilyy. Jos syötät tämän takaisin `size`-arvoksi, hinnoittelu pysyy 1K-tasolla.
>
> 4K-kutsut kestävät yleensä 4–8 minuuttia, suositellaan käytettäväksi jäljempänä kuvattua `callback_url`-asynkronista palautetta.

> **`n`-parametrin käyttö**
>
> `gpt-image-2` ei tällä hetkellä tue `n > 1` -arvoja: tämä parametri ohitetaan hiljaisesti, ja riippumatta `n=1` tai `n=10` arvosta, yksittäinen pyyntö palauttaa vain yhden kuvan ja veloittaa yhden kuvan hinnan. Jos haluat useita kuvia kerralla, tee useita rinnakkaisia pyyntöjä (suositellaan käyttämään eri `prompt`- tai `seed`-arvoja, muuten kuvat voivat olla hyvin samankaltaisia). Sama rajoitus koskee myös `gpt-image-1` / `gpt-image-1.5` ja `nano-banana` / `nano-banana-2` / `nano-banana-pro` -sarjoja. `dall-e-2` on ainoa malli, joka natiivisti tukee `n > 1` -arvoja; `dall-e-3` tukee vain `n = 1`.

Seuraavaksi muutamia esimerkkitapauksia, jotka havainnollistavat `gpt-image-2` -mallin kykyjä.

### Tapaus 1: Elokuvamainen muotokuva

Promptissa voi käyttää elokuvatermejä (35mm filmi, matala syväterävyys, neonvalot jne.) tunnelman ja tekstuurin tarkkaan ohjaamiseen.

Python-esimerkkikoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-image-2",
    "prompt": "A cinematic portrait of a young woman standing in a convenience store at night, illuminated by soft pink and cyan neon signs through the window. Shot on 35mm film, shallow depth of field, slight grain, melancholic mood.",
    "size": "1024x1536"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Asynkroninen palautus

`gpt-image-2` -kutsut kestävät yleensä 60–90 sekuntia. Jos et halua pitää yhteyttä auki, voit käyttää jäljempänä kuvattua `callback_url`-asynkronista palautetta. Käyttö on sama kuin muillakin malleilla.

## Nano Banana -mallisarja

`nano-banana`-sarja perustuu Gemini-kuvageneraatiomalliin ja on liitetty samaan `/openai/images/generations` -rajapintaan. Ei tarvitse vaihtaa endpointia, riittää että vaihdat `model`-kentän alla olevaan arvoon.

| Malli | Hinnoittelu (Credits / kerta) | Käyttötarkoitus |
| --- | --- | --- |
| `nano-banana` | 0.14 | Tavallinen kuvagenerointi, nopein ja edullisin |
| `nano-banana-2` | 0.28 | Parannettu laatu ja yksityiskohdat |
| `nano-banana-pro` | 0.35 | Lippulaivamalli, paras sommittelu, yksityiskohdat ja teksti |

> **Tärkeää: tuetut parametrit**
>
> Nano Banana käyttää OpenAI-protokollan sovituskerrosta, ja tukee verrattuna `gpt-image-*` malleihin vain seuraavia parametreja: `model`, `prompt`, `size`.
>
> - `size` kartoitetaan sisäiseen `aspect_ratio`-arvoon taulukon mukaan; muut koot oletetaan `1:1`:
>   - `1024x1024` / `512x512` / `256x256` → `1:1`
>   - `1792x1024` → `16:9`
>   - `1024x1792` → `9:16`
> - Ei tue parametreja kuten `n`, `quality`, `style`, `response_format`, `background`, `output_format`; ne ohitetaan.
> - Palautusrakenne noudattaa OpenAI-muotoa (`data[].url`), mutta `created` on aina `0`, eikä `b64_json` tai `revised_prompt` muutu.

### Peruskutsu

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "nano-banana",
    "prompt": "a small red apple on a white table, photoreal",
    "size": "1024x1024"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Viimeinen parametri on kuvan linkin formaatti, jossa on kaksi vaihtoehtoa: `b64_json` koodaa kuvan Base64-muotoon, ja `url` palauttaa tavallisen kuvalinkin.

Alla asetetaan `response_format` arvoksi `url`:

Python-esimerkki:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter",
```

## Asynkroninen palautus

Koska OpenAI Images Generations API:n kuvan generointi voi kestää pitkään, API-pyyntö voi pitää HTTP-yhteyden auki pitkään, mikä kuluttaa järjestelmäresursseja. Siksi API tukee myös asynkronista palautetta.

Prosessi on seuraava: asiakas lähettää pyynnön, johon sisältyy `callback_url`-kenttä. API palauttaa heti vastauksen, joka sisältää `task_id`-kentän, joka edustaa tehtävän tunnistetta. Kun tehtävä on valmis, generoidut kuvat lähetetään POST-muodossa JSONina asiakkaan määrittelemään `callback_url`-osoitteeseen, sisältäen myös `task_id`-kentän, jolla tehtävä voidaan yhdistää.

Seuraavassa esimerkki:

Webhook-palautus on HTTP-palvelu, jonka kehittäjä määrittää omalle palvelimelleen. Tässä esimerkissä käytetään julkista Webhook-sivustoa https://webhook.site/, josta saa yksilöllisen Webhook-URL:n:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi tämä URL, esimerkiksi `https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab`.

Aseta `callback_url`-kenttään tämä URL ja muut parametrit:

```python
import requests

url = "https://api.acedata.cloud/openai/images/generations"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "dall-e-3",
    "prompt": "A cute baby sea otter",
    "callback_url": "https://webhook.site/3d32690d-6780-4187-a65c-870061e8c8ab"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Välitön vastaus:

```json
{
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c"
}
```

Hetken kuluttua Webhook-URL:ssä näkyy generoidun kuvan tulos:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": {
    "created": 1721626477,
    "data": [
      {
        "revised_prompt": "A delightful image showcasing a young sea otter...",
        "url": "https://dalleprodsec.blob.core.windows.net/private/images/..."
      }
    ]
  }
}
```

Tuloksessa on `task_id` ja `data`-kenttä, joka sisältää synkronisen kutsun kaltaisen kuvan generointituloksen. Näin tehtävä voidaan yhdistää tunnisteella.

## Virheenkäsittely

API-kutsun aikana virheen sattuessa API palauttaa virhekoodin ja viestin, esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, ylitetty rajoitus.
- `500 api_error`: Palvelinvirhe.

### Virhevastauksen esimerkki

```json

  "success": false,

}
```
