## 1. API-avaimen hankkiminen

Avaa [Ace Data Cloud -sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ensimmäisen pyynnön lähettäminen

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Onnistuneen vastauksen kuva sijaitsee kohdassa `data[].url`。Alla on Ace Data Cloudin kautta 8. syyskuuta 2026 todellisella pyynnöllä saatu 1024×1536-tulos (tehtävä `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`)：

![GPT Image 2:n luoma valkoinen kahvimuki](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Yleisesti käytetyt parametrit

| Kenttä                | Kuvaus                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (oletussuositus), `gpt-image-2.5-flare` (nopeampi) tai `gpt-image-2.5-sunburst` (suurempi tarkkuus ja hallinta); kaikille kolmelle voi valita vastaavan `:official`-muunnelman, ja `gpt-image-2` tukee lisäksi `:reverse`-muunnelmaa |
| `prompt`          | Kuvan kuvaus, enintään 32 000 merkkiä                                                                                                                     |
| `size`            | `auto` tai `WIDTHxHEIGHT`; leveyden ja korkeuden on oltava 16:n kerrannaisia, pidempi sivu saa olla enintään 3840, kokonaispikselimäärä 655 360–8 294 400 ja kuvasuhde enintään 3:1                                                       |
| `n`               | 1–10; kun `response_format=b64_json`, tuetaan vain arvoa 1                                                                                                 |
| `quality`         | GPT Image -mallit tukevat arvoja `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (mukaan lukien `:official`) tukevat lisäksi arvoja `xhigh`, `max`。Virallinen kanava laskuttaa todellisen Token-kulutuksen mukaan             |
| `response_format` | `url` tai `b64_json`                                                                                                                     |
| `callback_url`    | Valinnainen; lähettää tuloksen tähän osoitteeseen pitkän tehtävän valmistuttua                                                                                                                      |

Yleisesti käytetyt koot:

| Suhde   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` valitsee kuvasuhteen, pikselimäärän ja asettelutarkoituksen perusteella kuvakoon; kun tarvitaan tarkat pikselit, täytä koko suoraan.

2.0 / 2.5 -käänteismallit (mukaan lukien `:reverse`-aliakset) voivat automaattisessa palautuksessa käyttää GPT Image 2.5 Flarea pyynnön suorittamiseen; pyynnön malli ja onnistuneiden kuvien määrään perustuva laskutustapa säilyvät ennallaan.

Virallisen API-kanavan sivuhinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy vastauksen todellisen Token-kulutuksen ja käyttömerkintöjen perusteella.

## 4. Usean kuvan generointi

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`-, `gpt-image-2.5-flare`-, `gpt-image-2.5-sunburst`-mallit ja niiden `:reverse`-aliakset laskutetaan onnistuneiden kuvien määrän mukaan; `gpt-image-2:official`-, `gpt-image-2.5-flare:official`- ja `gpt-image-2.5-sunburst:official`-mallit laskutetaan vastauksessa olevan tekstisyötteen ja kuvatuotoksen todellisten tokenien perusteella. Sivulla näkyvä hinta on arvio ennen pyyntöä, ja lopullinen hinta määräytyy käyttötietojen mukaan.

## 5. Asynkroninen takaisinsoitto

Kun pyyntöön lisätään `callback_url`, rajapinta palauttaa ensin `{"task_id": "..."}` ja lähettää valmistuessaan lopullisen tuloksen POST-pyyntönä kyseiseen URL-osoitteeseen; synkroniset pyynnöt palauttavat edelleen `created`- ja `data`-kentät:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Takaisinsoiton vastaanottajan tulee käyttää `task_id`-kenttää duplikaattien poistamiseen sekä vahvistaa pyynnön alkuperä ja tietomuoto.

## 6. Vianmääritys

| Tila  | Tarkista                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`-, `prompt`-, kokomuoto-, `n`- ja `response_format`-yhdistelmä    |
| 401 | Onko API-avain täydellinen ja onko Header `Authorization: Bearer ...` |
| 429 | Pyyntöjä tehdään liian usein, yritä myöhemmin uudelleen                                         |
| 504 | Synkronisen luonnin aikakatkaisu; käytä `callback_url`-osoitetta                            |

Virhevastaukset sisältävät `error.code`-, `error.message`- ja `trace_id`-kentät. Anna ongelmasta palautetta lähettäessäsi `trace_id`, älä anna API-avainta.

Täydelliset kentät ja reaaliaikaiset enum-arvot löytyvät [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) -sivulta. Kuvien muokkausta varten katso [GPT Image 2 / 2.5 / 2.6 -kuvamuokkaus](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 käyttää 2.5:n luonti-, muokkaus-, asynkronisten tehtävien ja laskutusrajapintoja:

| Malli                                                          | Laskutus                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/kuva                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/kuva                   |
| `gpt-image-2.6-flare:official`                              | Sama kuin 2.5 official, laskutus todellisen Token-kulutuksen mukaan |
| `gpt-image-2.6-sunburst:official`                           | Sama kuin 2.5 official, laskutus todellisen Token-kulutuksen mukaan |

Laaduksi voi valita `auto`, `low`, `medium`, `high`, `xhigh`, `max`; kokona käytetään `auto`-arvoa tai edellä mainittujen rajoitusten mukaista `WIDTHxHEIGHT`-arvoa. Tämä rajapinta tukee `png`-, `jpeg`- ja `webp`-muotoja; GPT Image 2.6 tukee lisäksi natiivisti animoitua `gif`-muotoa, mutta SVG:tä ei toistaiseksi tueta. Muokkaus tukee JSON-kuva-URL-osoitteita ja multipart-tiedostojen lataamista. `:reverse` on samannimisen tavallisen version eksplisiittinen alias. Käytä täydellistä mallinimeä, älä välitä arvoa `gpt-image-2.6`.

### GPT Image 2.6 GIF-animaatiot

Flaren tavallinen versio, `:reverse`, `:official` sekä `gpt-image-2.6-sunburst:official` voivat käyttää arvoa `output_format: "gif"`. Sunburstin tavallinen versio ja `:reverse` eivät toistaiseksi tarjoa GIF-tukea, mutta tukevat edelleen staattisten kuvien luontia ja muokkausta. Animaation kehykset, silmukkatiedot ja toiston kesto säilyvät; `frame_count` tarkoittaa kehysten määrää ja `frame_duration_ms` tarkoittaa millisekunteja kehystä kohden, ja molempien on oltava positiivisia kokonaislukuja sekä niitä käytetään vain GIF-tiedostoille. Jos niitä ei määritetä, oletusarvona on 9 kehystä ja 200 millisekuntia kehystä kohden; kun GIF-tiedoston `size` jätetään pois tai sen arvona on auto, käytetään 512x512-esiasetusta.

On suositeltavaa käyttää ensin arvoja `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF-tiedostoilla on erilliset koko- ja kehysmäärärajoitukset, joten staattista 4K-määritystä ei voi soveltaa suoraan; jotkin mallit säätävät todellista tulostuskokoa. `n` tarkoittaa palautettavien GIF-tiedostojen määrää, ei animaatiokehysten määrää. Tavallinen versio ja `:reverse` laskutetaan edelleen onnistuneiden tiedostojen määrän perusteella, kun taas virallinen versio laskutetaan todellisen Token-kulutuksen perusteella.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K-staattiset kuvat

Flare, Sunburst ja niiden `:reverse`- ja `:official`-variantit voivat kaikki käyttää edellä mainittuja 4K-pikseliesiasetuksia, kuten `3840x2160` ja `2160x3840`. Sekä luomisessa että muokkauksessa tarkat pikselit välitetään `size`-kentän kautta; `4K` ei ole kelvollinen `size`-arvo, ja `4096x4096` ylittää myös nykyisen pikselirajan. Edellä mainitut 4K-määritykset koskevat staattisia PNG/JPEG/WebP-kuvia; GIF-tiedostoille tulee käyttää niiden omia parametreja.
