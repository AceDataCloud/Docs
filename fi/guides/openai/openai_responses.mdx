Alustan hyväksymistä yhteensopivista mallipyynnöistä veloitetaan mallin syöttö-, tuloste- ja välimuistinkäytön mukaan. Responses-syötteen kokonaismäärä sisältää raportoidut välimuisti-tokenit, ja välimuistiosa laskutetaan vastaavan välimuistihinnan mukaisesti; rajapintamuodon vaihtaminen ei muuta laskutusta kiinteäksi kertamaksuksi. Maksut perustuvat konsolin nykyisiin mallihintoihin ja vastauksen `usage.cost`-arvoon.

OpenAI on hiljattain tarjonnut rajapinnan mallivastausten luomiseen. Tarjoa teksti- tai kuvasyötteitä teksti- tai kuvatulosteiden luomiseksi. Anna mallin kutsua omaa mukautettua koodiasi tai käyttää sisäänrakennettuja työkaluja, kuten web-hakua tai tiedostohakua, käyttääksesi omia tietojasi mallivastauksen syötteenä.

Tässä asiakirjassa esitellään pääasiassa OpenAI Responses API:n käyttövaiheet, joiden avulla voimme helposti käyttää virallista OpenAI:n mallivastausten luontitoimintoa.

## GPT-6.1 Terra

Valitse tämä malli käyttämällä `model: "gpt-6.1-terra"`. Tukee teksti- ja kuvasyötteitä, suoratoistotulostetta, funktiotyökaluja ja jäsenneltyä tulostetta. Päättelytasot tukevat arvoja `low`, `medium`, `high`, `xhigh` ja `max`, ja on suositeltavaa aloittaa asetuksella `reasoning: {"effort": "low"}`; arvoja `none` tai `minimal` ei tueta. Kun syöte ylittää 272,000 tokenia, sovelletaan pitkän kontekstin hinnoittelua, ja todelliset maksut perustuvat konsolin nykyisiin hintoihin ja vastauksen käyttömäärään.

## GPT-6.1 Sol

Valitse tämä malli käyttämällä `model: "gpt-6.1-sol"`. Tukee suoratoistotulostetta, funktiokutsuja, jäsenneltyä tulostetta ja kuvasyötteitä. Ensimmäisen käyttöönottoviikon aikana se on saatavilla vain varmennetuille ACE T1+ -haltijoille (vähintään 100,000 ACE) tai valtuutetuille käyttäjille; tarkka saatavuusaika määräytyy konsolin käyttöoikeusilmoituksen mukaan.

Päättelytasot tukevat arvoja `low`, `medium`, `high`, `xhigh` ja `max`, eikä arvoja `none` tai `minimal` toistaiseksi tueta. On suositeltavaa aloittaa asetuksella `reasoning: {"effort": "low"}`. Kun syöte ylittää 272,000 tokenia, pitkän kontekstin hinnoittelu koskee koko pyyntöä, ja maksut perustuvat konsolin nykyisiin hintoihin.

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavat tiedot kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Yksi niistä on `authorization`, jonka voi valita suoraan pudotusvalikosta. Toinen parametri on `model`, ja `model` tarkoittaa viralliselta OpenAI ChatGPT -sivustolta valitsemaamme malliluokkaa. Tässä meillä on pääasiassa 20 mallia, ja lisätietoja voit katsoa tarjoamistamme malleista. Viimeinen parametri on `input`, `input` on syöttämiemme kyselysanojen taulukko, se on taulukko, mikä tarkoittaa, että useita kyselysanoja voidaan lähettää samanaikaisesti, ja jokainen kyselysana sisältää `role`- ja `content`-kohdat, joista `role` ilmaisee kysyjän roolin. Tarjoamme kolme roolia: `user`, `assistant` ja `system`. Toinen, `content`, on kyselymme tarkka sisältö.

Samalla voit huomata, että oikealla on vastaavan kutsukoodin luonti. Voit kopioida koodin ja suorittaa sen suoraan tai testata painamalla suoraan ”Try”-painiketta.

Yleisesti käytetyt valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen tokenien enimmäismäärää.
- `temperature`: generoinnin satunnaisuus, välillä 0–2; mitä suurempi arvo, sitä hajautuneempi.
- `n`: kuinka monta ehdokasvastausta generoidaan kerralla.
- `response_format`: vastausmuodon asetus.
- `tools`: funktio-/työkalukutsujen määritelmä.
- `background`: suoritetaanko taustalla asynkronisesti.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa verkkosivulla sanakohtaisen näyttöefektin.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyyntöotsikon `stream ` -parametrin arvoksi `true`.

Muutos on esitetty kuvassa, mutta kutsukoodiin on tehtävä vastaavat muutokset, jotta se tukee suoratoistovastauksia.
<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi riviltä, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivi riviltä tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `item_id`, tämän keskustelutehtävän luodun tunniste, jota käytetään tämän keskustelutehtävän yksilöivään tunnistamiseen.
- `type`, tämän keskustelu-Responses-tehtävän luodun tyypin.
- `model `, valittu OpenAI ChatGPT:n virallisen verkkosivuston malli.
- `delta`, ChatGPT:n kyselysanalle antamat vastaustiedot.

Myös JavaScript on tuettu, esimerkiksi Node.js:n suoratoistokutsun koodi on seuraava:

```javascript

  method: "post",

  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

## Visuaalinen malli

gpt-4o on OpenAI:n kehittämä multimodaalinen suuri kielimalli, joka lisää GPT-4:n pohjalta visuaalisen ymmärryksen kyvyn. Tämä malli voi käsitellä samanaikaisesti teksti- ja kuvasyötteitä sekä toteuttaa monimuotoista ymmärrystä ja generointia.

gpt-4o-mallin tekstinkäsittelyn käyttö on yhdenmukaista edellä esitetyn peruskäytön sisällön kanssa. Seuraavaksi esitellään lyhyesti, kuinka mallin kuvankäsittelyominaisuuksia käytetään.

gpt-4o-mallin kuvankäsittelyominaisuuksia käytetään pääasiassa lisäämällä alkuperäiseen `content`-sisältöön `type`-kenttä. Tämän kentän avulla voidaan tietää, onko ladattu tekstiä vai kuva, ja siten käyttää gpt-4o-mallin kuvankäsittelyominaisuuksia. Seuraavassa kuvataan pääasiassa, kuinka tätä toimintoa kutsutaan Curl- ja Python-tavoilla.

- Curl-komentosarjatapa

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }'
```

- Python-komentosarjatapa

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja -viestin, jos kohdataan virhe. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.
