OpenAI on äskettäin tarjonnut rajapinnan mallivastausten luomiseen. Voit syöttää teksti- tai kuvasyötteen tuottaaksesi tekstin tai kuvavastauksen. Anna mallille mahdollisuus kutsua omia mukautettuja koodisi tai käyttää sisäänrakennettuja työkaluja, kuten verkkohaku tai tiedostohaku, hyödyntääksesi omia tietojasi mallivastauksen syötteenä.

Tässä asiakirjassa käsitellään OpenAI Responses API:n käyttöprosessia, jonka avulla voimme helposti hyödyntää virallista OpenAI:n mallivastausten luontitoimintoa.

## Hakuprosessi

Käyttääksesi OpenAI Responses API:a, voit ensin siirtyä [OpenAI Responses API](https://platform.acedata.cloud/documents/81e285a6-d010-4a2d-a3a8-ca113d4ef82a) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme kenttää: yksi on `authorization`, joka valitaan suoraan avattavasta valikosta. Toinen parametri on `model`, joka on valitsemasi OpenAI ChatGPT:n virallisen mallin kategoria. Täällä meillä on pääasiassa 20 erilaista mallia, yksityiskohtia voit katsoa tarjoamastamme mallista. Viimeinen parametri on `input`, joka on kysymysmerkkien taulukko, joka tarkoittaa, että voit ladata useita kysymyksiä samanaikaisesti. Jokainen kysymys sisältää `role` ja `content`, jossa `role` tarkoittaa kysyjän roolia. Olemme tarjonneet kolme identiteettiä: `user`, `assistant`, `system`. Toinen `content` on kysymyksen tarkka sisältö.

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

Yleisesti käytettävät valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen enimmäistoken-määrää.
- `temperature`: luo satunnaisuutta, 0-2 välillä, suurempi arvo tarkoittaa hajautetumpaa tulosta.
- `n`: kuinka monta ehdokasvastausta luodaan kerralla.
- `response_format`: palautusmuodon asetukset.
- `tools`: funktioiden/työkalujen kutsumisen määrittely.
- `background`: suoritetaan taustalla asynkronisesti.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosivustojen integroinnissa, sillä se mahdollistaa sanan kerrallaan näyttämisen.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodin on myös oltava vastaavasti muutettu, jotta se tukee virtaavaa vastausta.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

Kun `stream` on muutettu arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi riviltä, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Visuaalinen malli

gpt-4o on OpenAI:n kehittämä monimodaalinen suuri kielimalli, joka lisää visuaalisen ymmärryksen kykyjä GPT-4:n pohjalta. Tämä malli voi käsitellä samanaikaisesti tekstin ja kuvien syötteitä, mahdollistaen monimuotoisen ymmärryksen ja tuottamisen.

gpt-4o-mallin tekstinkäsittely on yhdenmukaista edellä mainitun peruskäytön sisällön kanssa, alla esitellään lyhyesti, kuinka käyttää mallin kuvankäsittelykykyjä.

gpt-4o-mallin kuvankäsittelykykyjä käytetään pääasiassa lisäämällä alkuperäiseen `content`-sisältöön `type`-kenttä, jonka avulla voidaan tietää, onko ladattu tekstiä vai kuvaa, jolloin voidaan käyttää gpt-4o-mallin kuvankäsittelykykyjä. Alla käsitellään Curl- ja Python-menetelmiä tämän toiminnon kutsumiseen.

- Curl-skripti

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
          }
        ]
      }
    ]
  }'
```
