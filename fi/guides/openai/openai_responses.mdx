OpenAI on hiljattain tarjonnut rajapinnan mallivastausten luomiseen. Tarjoa teksti- tai kuvasyöte teksti- tai kuvatuotoksen luomiseksi. Anna mallin kutsua omaa mukautettua koodiasi tai käyttää sisäänrakennettuja työkaluja, kuten web-hakua tai tiedostohakua, käyttääksesi omia tietojasi mallivastausten syötteenä.

Tässä dokumentissa esitellään pääasiassa OpenAI Responses API -toimintojen käyttöprosessi. Sen avulla voimme helposti käyttää virallista OpenAI:n mallivastausten luontitoimintoa.

## GPT-6.1 Sol

Valitse tämä malli käyttämällä `model: "gpt-6.1-sol"`. Tukee suoratoistotulostusta, funktiokutsuja, strukturoitua tulostusta ja kuvasisältöä. Ensimmäisen avoimen viikon aikana se on saatavilla vain vahvistetuille ACE T1+ -haltijoille (vähintään 100 000 ACE) tai valtuutetuille käyttäjille; tarkka saatavuusaika määräytyy konsolin käyttöoikeusilmoituksen mukaan.

Päättelytasot tukevat `low`-, `medium`-, `high`-, `xhigh`- ja `max`-arvoja, mutta `none`- tai `minimal`-arvoja ei toistaiseksi tueta. On suositeltavaa aloittaa asetuksella `reasoning: {"effort": "low"}`. Kun syöte ylittää 272 000 tokenia, koko pyyntöön sovelletaan pitkän kontekstin hinnoittelua, ja maksu määräytyy konsolin nykyisten hintojen mukaan.

## Hakuprosessi

Käyttääksesi OpenAI Responses API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Tämän jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voidaan kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisestä hakemuksesta myönnetään ilmainen käyttökiintiö, jolla voit kokeilla palvelua ilmaiseksi; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavat sisällöt kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Yksi niistä on `authorization`, joka voidaan valita suoraan pudotusvalikosta. Toinen parametri on `model`; `model` tarkoittaa valitsemaamme OpenAI ChatGPT:n virallisen verkkosivuston malliluokkaa. Täällä meillä on pääasiassa 20 mallia, ja lisätietoja saat tarjoamistamme malleista. Viimeinen parametri on `input`; `input` on syötettävien kyselylauseiden taulukko. Se on taulukko, joka tarkoittaa, että useita kyselylauseita voidaan ladata samanaikaisesti. Jokainen kyselylause sisältää `role`- ja `content`-kentät, joista `role` ilmaisee kysyjän roolin. Tarjoamme kolme roolia: `user`, `assistant` ja `system`. Toinen, `content`, on kyselymme tarkka sisältö.

Samalla voit huomata, että oikealla on vastaavan kutsukoodin luonti. Voit kopioida koodin ja suorittaa sen suoraan tai testata sitä suoraan napsauttamalla ”Try”-painiketta.

Yleisesti käytetyt valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen tokenien enimmäismäärän.
- `temperature`: generoinnin satunnaisuus, välillä 0–2; mitä suurempi arvo, sitä hajautuneempi tulos.
- `n`: kuinka monta ehdokasvastausta luodaan kerralla.
- `response_format`: palautusmuodon asetus.
- `tools`: funktio-/työkalukutsujen määrittely.
- `background`: suoritetaanko taustalla asynkronisesti.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa verkkosivulle sanalta sanalle -näyttöefektin.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyyntöotsikon `stream ` -parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodiin on tehtävä vastaavat muutokset, jotta se tukee suoratoistovastauksia.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan. Kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme tulokset rivi kerrallaan.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Suoratoistovastaus päättyy tilaan `response.completed` tai `response.incomplete`; päätetilan `usage` on tämän pyynnön lopullinen token-käyttömäärä ja myös laskutuksen peruste.

Palautetussa `data`-tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `item_id`, tämän keskustelutehtävän luodun tunnus, jota käytetään tämän keskustelutehtävän yksilölliseen tunnistamiseen.
- `type`, tämän keskustelun Responses-tehtävän luotu tyyppi.
- `model `, valittu OpenAI ChatGPT:n virallisen verkkosivuston malli.
- `delta`, ChatGPT:n kyselysanalle antamat vastaustiedot.

Myös JavaScript on tuettu, esimerkiksi Node.js:n suoratoistokutsun koodi on seuraava:

```javascript
const options = {
  method: "post",

```

```java

```

## Visuaalinen malli

gpt-4o on OpenAI:n kehittämä multimodaalinen suuri kielimalli, johon on lisätty visuaalisen ymmärryksen kyky GPT-4:n pohjalta. Tämä malli voi käsitellä samanaikaisesti teksti- ja kuvasyötteitä ja toteuttaa monimuotoisen ymmärtämisen ja tuottamisen.
gpt-4o-mallin tekstinkäsittely vastaa yllä kuvattua peruskäyttöä, seuraavaksi esitellään lyhyesti, kuinka mallin kuvankäsittelyominaisuuksia käytetään.

gpt-4o-mallin kuvankäsittelyominaisuuksia käytetään pääasiassa lisäämällä alkuperäiseen `content`-sisältöön `type`-kenttä, jonka avulla voidaan tietää, onko ladattu sisältö tekstiä vai kuva, ja siten käyttää gpt-4o-mallin kuvankäsittelyominaisuuksia. Seuraavaksi kuvataan pääasiassa tämän toiminnon kutsumista Curl- ja Python-tavoilla.

- Curl-komentosarjatapa

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }'
```

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja viestin, jos virhe kohdataan. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, valtuutustunnus on virheellinen tai puuttuu.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella meni jokin pieleen.
