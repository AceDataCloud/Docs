OpenAI sanavektoripalvelu, joka tuottaa syötetyn tekstin sanavektorituloksia.

Tässä asiakirjassa esitellään OpenAI Embeddings API:n käyttöprosessi, jonka avulla voimme luoda syötetyn tekstin upotussanoja.

## Hakuprosessi

Käyttääksesi OpenAI Embeddings API:a, voit ensin siirtyä [OpenAI Embeddings API](https://platform.acedata.cloud/documents/0f2e63fa-5890-4bdd-84f0-1706b5c9a387) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, jonka voit valita suoraan pudotusvalikosta. Toinen parametri on `model`, `model` on se, mitä valitsemme käytettäväksi OpenAI:n verkkosivuston mallikategorioista. Täällä meillä on pääasiassa 3 erilaista mallia, lisätietoja voit katsoa tarjoamistamme malleista. Viimeinen parametri on `input`, `input` on se sanavektoriteksti, jonka haluamme muuntaa.

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

Valinnaiset parametrit:

- `dimensions`: leikkaa vektorin ulottuvuudet, oletusarvoisesti tulostaa täydet ulottuvuudet.
- `encoding_format`: palautusmuoto, valinnaisesti `float` tai `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-ada-002",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautustuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `model`, malli, jota käytettiin tämän tekstin muuntamiseen sanavektoriksi.
- `usage`, token-tiedot, joita käytettiin tämän tekstin muuntamiseen sanavektoriksi.
- `data`, tekstin muuntamisen jälkeen saadut sanavektoritulokset.

`data` sisältää tekstin vastaavat sanavektoritiedot, ja sen sisällä oleva `embedding` on luotujen sanavektorien tarkka tulos.

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki
