OpenAI-sana-vektoripalvelu, jota käytetään syötetyn tekstin sana-vektoritulosten luomiseen.

Tässä dokumentissa esitellään pääasiassa OpenAI Embeddings API:n käyttöprosessi, jonka avulla voimme luoda syötetyn tekstin esitystä vastaavia upotusvektoreita。。

## Hakuprosessi

Jotta voit käyttää OpenAI Embeddings API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säästä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä jokaista palvelua varten tarvitse hakea erikseen.** Ensimmäisellä hakukerralla saat ilmaista saldoa, jolla voit kokeilla palvelua maksutta; jos saldo ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavat tiedot, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Yksi niistä on `authorization`, jonka voi valita suoraan pudotusvalikosta. Toinen parametri on `model`; `model` tarkoittaa OpenAI:n virallisilta verkkosivuilta valitsemaamme malliluokkaa. Tällä hetkellä käytettävissä olevat mallit ovat `text-embedding-3-small` ja `text-embedding-3-large`. Mallia `text-embedding-ada-002` ei enää tarjota; jos olemassa oleva vektori-indeksi käyttää tätä vanhaa mallia, uuden mallin vektoreita ei voi suoraan käyttää yhdessä sen kanssa, vaan indeksi on rakennettava uudelleen. Viimeinen parametri on `input`; `input` on teksti, joka meidän on muunnettava sanavektoriksi.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi. Voit kopioida koodin ja suorittaa sen suoraan tai testata sitä suoraan napsauttamalla 「Try」-painiketta.

Valinnaiset parametrit:

- `dimensions`: rajaa vektorin ulottuvuudet, oletuksena tulostetaan täydet ulottuvuudet.
- `encoding_format`: palautusmuoto, vaihtoehdot ovat `float` tai `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Python-esimerkkikutsu:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `model`, malli, jota käytetään tässä tekstin muuntamisessa sanavektoriksi.
- `usage`, token-tiedot, joita käytetään tässä tekstin muuntamisessa sanavektoriksi.
- `data`, tekstin muuntamisen jälkeinen sanavektoritulos.

Näistä `data` sisältää tekstin vastaavia sanavektoreita koskevat yksityiskohtaiset tiedot, ja sen `embedding` on luodun sanavektorin varsinainen tulos.

## Virheenkäsittely

Kun API:a kutsuttaessa tapahtuu virhe, API palauttaa vastaavan virhekoodin ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutusta, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.
