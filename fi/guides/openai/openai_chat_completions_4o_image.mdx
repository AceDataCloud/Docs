OpenAI ChatGPT on erittäin voimakas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain syöttämällä kehotteita muutamassa sekunnissa. ChatGPT erottuu alalla erinomaisella kielentunnistus- ja -tuotantokyvyllään, ja nykyään ChatGPT:tä käytetään laajasti eri toimialoilla ja alueilla, ja sen vaikutus on yhä merkittävämpi. Olipa kyseessä päivittäinen keskustelu, luova kirjoittaminen tai ammatillinen konsultointi ja koodaus, ChatGPT voi tarjota hämmästyttävää älykästä apua, mikä parantaa merkittävästi ihmisten työtehoa ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa OpenAI Chat Completion 4o Image API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallisen OpenAI ChatGPT:n monimuotoista keskustelutoimintoa.

## Hakuprosessi

Käyttääksesi OpenAI Chat Completion 4o Image API:a, voit ensin siirtyä [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) -sivulle ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## GPT-4o Piirtomalli

### Kuvan luominen viittauskuvasta

Alla on esimerkki mukautetun tyylin kuvan luomisesta viittauskuvasta. Katsotaan ensin syöttämäämme kuvaa, kuten alla olevasta kuvasta näkyy:

![](https://cdn.acedata.cloud/qzx2z1.png)

Viittauskuva on todellinen kuva, ja voimme pyytää sen muuttuvan esimerkiksi anime-tyyliseksi kuvaksi. Tarkka pyyntöesimerkki:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Generoi anime-tyylinen kuva, jossa on hattu"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki
