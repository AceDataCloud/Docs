Tässä dokumentissa esitellään Sora Videos Generation API:n integrointiohjeet. Tämän API:n avulla voit syöttää mukautettuja parametreja ja luoda Sora:n virallisia videoita. API tukee kahta eri versiota:

- **Versio 1 (klassinen tila)**: tukee parametreja kuten `duration` (10/15/25 sekuntia), `orientation` (vaaka/pysty), `size` (small/large resoluutio), referenssikuvat `image_urls`, hahmon **###** `character_url` jne.
- **Versio 2 (kumppanitila)**: tukee parametreja kuten `seconds` (4/8/12 sekuntia), pikselikohtainen resoluutio `size` (esim. 1280x720), referenssikuva `input_reference` jne.

## Hakuprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua osoitteesta [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). Sivulle siirryttyäsi klikkaa "Acquire"-painiketta, kuten alla olevassa kuvassa:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, joten voit käyttää API:a maksutta.

## Peruskäyttö (Versio 1)

Ensiksi tutustutaan Version 1 peruskäyttöön: syötät `prompt`-kehotteen, referenssikuvien URL-listan `image_urls` ja mallin `model`, jolloin saat käsitellyn tuloksen. Tarkempi sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Huomaat, että asetamme Request Headers -otsikot, mukaan lukien:

- `accept`: haluttu vastausformaatti, tässä `application/json` eli JSON-muodossa.
- `authorization`: API-avaimesi, jonka voit valita alasvetovalikosta hakemisen jälkeen.

Lisäksi asetetaan Request Body, joka sisältää:

- `model`: videon luontimalli, tukee `sora-2` (standardi) ja `sora-2-pro` (HD). `sora-2-pro` tukee 25 sekunnin videoita, kun taas `sora-2` tukee vain 10 ja 15 sekuntia.
- `size`: videon resoluutio, `small` on standardi ja `large` HD (vain Versio 1).
- `duration`: videon kesto, 10, 15 tai 25 sekuntia (25 sekuntia vain `sora-2-pro`, vain Versio 1).
- `orientation`: kuvasuhde, `landscape` (vaaka) tai `portrait` (pysty) (vain Versio 1).
- `image_urls`: referenssikuvien URL-lista videon luontiin (vain Versio 1).
- `character_url`: hahmon **###** URL, videossa ei saa esiintyä oikeita ihmisiä (vain Versio 1).
- `character_start`/`character_end`: hahmon esiintymisen alku- ja loppuajat sekunteina, arvojen erotus 1-3 sekuntia (vain Versio 1).
- `prompt`: kehoteteksti (pakollinen).
- `callback_url`: asynkronisen palautteen URL.
- `version`: API-versio, `1` (oletus) tai `2`.

Palautetut kentät ovat:

```shell

-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "size": "large",
  "duration": 15,
  "orientation": "landscape",
  "prompt": "cat running on the river",
  "model": "sora-2"
}'
```

## Kuvasta video -tehtävä (Versio 1)

Jos haluat tehdä kuvasta video -tehtävän, sinun tulee syöttää `image_urls`-parametri referenssikuvien URL-listana. Voit määrittää seuraavat:

- `image_urls`: referenssikuvien URL-lista. Huomaa, ettei saa käyttää oikeiden ihmisten kasvokuvia, koska se voi aiheuttaa tehtävän epäonnistumisen.

Esimerkkisyöttö:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Syötön jälkeen generoituu koodi:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Koodi:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Hahmon luonti videoon (Versio 1)

Jos haluat tehdä hahmon luontitehtävän, sinun tulee syöttää `character_url`-parametri video-URL:llä, jota käytetään hahmon luontiin. Huomaa, ettei videossa saa esiintyä oikeita ihmisiä, muuten tehtävä epäonnistuu.

- `character_url`: videon URL hahmon luontiin, ei saa sisältää oikeita ihmisiä.

Esimerkkisyöttö:

<p><img src="https://cdn.acedata.cloud/2nhdr2.png" width="500" className="m-auto" /></p>

Syötön jälkeen generoituu koodi:

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"

## Versio 2 -tila

Versio 1:n lisäksi API tukee myös Versio 2 -tilaa, joka aktivoidaan asettamalla `version`-parametriksi `2`. Versio 2 tukee lyhyempiä videoita ja pikselikohtaista resoluution hallintaa.

### Versio 2 parametrien selitys

| Parametri       | Tyyppi   | Pakollinen | Selitys                                |
|-----------------|----------|------------|---------------------------------------|
| `version`       | integer  | Kyllä      | Aseta arvoon `2`                      |
| `prompt`        | string   | Kyllä      | Videon luontikehotus                  |
| `model`         | string   | Ei         | `sora-2` (oletus) tai `sora-2-pro`  |
| `duration`      | integer  | Ei         | Videon kesto: `4` (oletus), `8`, `12` sekuntia |
| `size`          | string   | Ei         | Resoluutio: `720x1280` (oletus), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls`    | array    | Ei         | Referenssikuvien URL-lista, käytetään vain ensimmäistä kuvaa, kuvan koko tulee vastata `size`-parametria |
| `callback_url`  | string   | Ei         | Asynkronisen palautteen URL          |

### Perusesimerkki

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "version": 2,
  "prompt": "cat running on the river",
  "model": "sora-2",
  "duration": 8,
  "size": "1280x720"
}'
```

Python-koodi vastaavaan:

### Referenssikuvan käyttö (Versio 2)

Versio 2:ssa voit käyttää `image_urls`-parametria syöttääksesi referenssikuvan videon ohjaamiseksi (käytetään vain ensimmäistä kuvaa):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Huom:** Referenssikuvan koko tulee vastata `size`-parametria, esimerkiksi jos `size` on `1280x720`, referenssikuvan tulee olla 1280×720 pikseliä.

### Versio 1 vs Versio 2 parametrit

| Parametri       | Versio 1           | Versio 2                          |
|-----------------|--------------------|----------------------------------|
| `version`       | 1 (oletus)         | 2                                |
| `prompt`        | ✅                 | ✅                               |
| `model`         | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro          |
| `duration`      | ✅ 10/15/25 sekuntia | ✅ 4/8/12 sekuntia               |
| `orientation`   | ✅ landscape/portrait | ❌                              |
| `size`          | ✅ small/large      | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls`    | ✅ useita kuvia     | ✅ vain ensimmäinen kuva          |
| `character_url` | ✅                 | ❌                               |
| `callback_url`  | ✅                 | ✅                               |

## Asynkroninen callback

Koska Sora Videos Generation API:n videon luonti kestää noin 1-2 minuuttia, API voi pitää HTTP-yhteyden auki pitkään, mikä kuluttaa järjestelmäresursseja. Siksi API tukee asynkronista callback-toimintoa.

Prosessi on seuraava: asiakasohjelma lähettää pyynnön, johon sisältyy `callback_url`. API palauttaa heti vastauksen, joka sisältää `task_id`-kentän. Kun tehtävä on valmis, API lähettää POST-pyynnön JSON-muodossa `callback_url`:iin, sisältäen myös `task_id`:n, jolla tehtävä voidaan yhdistää.

Webhook callback on HTTP-palvelu, jonka kehittäjän tulee korvata omalla palvelimellaan. Tässä esimerkissä käytämme julkista webhook-palvelua https://webhook.site/, josta saa webhook-URL:n, kuten alla:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi URL, esimerkiksi `https://webhook.site/eb238c4f-da3b-47a5-a922-a93aa5405daa`.

Aseta `callback_url` tähän webhook-osoitteeseen ja muut parametrit, kuten alla:

## Virheiden käsittely

API:n kutsuissa voi esiintyä virheitä, jolloin API palauttaa virhekoodin ja viestin. Esimerkkejä:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, ylität rajauksen.
- `500 api_error`: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
