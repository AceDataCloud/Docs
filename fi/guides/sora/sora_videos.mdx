Tässä dokumentissa esitellään Sora Videos Generation API:n integrointiohjeet. Tämän API:n avulla voit syöttää mukautettuja parametreja ja luoda virallisia Sora-videoita. API tukee kahta versiota:

- **Versio 1 (klassinen tila)**: tukee parametreja kuten `duration` (10/15/25 sekuntia), `orientation` (vaaka/pysty), `size` (small/large resoluutio), referenssikuvat `image_urls`, hahmon **###** `character_url` jne.
- **Versio 2 (kumppanien tila)**: tukee parametreja kuten `seconds` (4/8/12 sekuntia), pikselitarkka resoluutio `size` (esim. 1280x720), referenssikuva `input_reference` jne.

## Hakuprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua osoitteesta [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). Sivulla klikkaa "Acquire"-painiketta, kuten alla näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, joten voit käyttää API:a maksutta.

## Peruskäyttö (Versio 1)

Ensiksi tutustutaan Version 1 peruskäyttöön: syötät `prompt`-tekstin, referenssikuvien URL-listan `image_urls` sekä mallin `model`, ja saat käsitellyn tuloksen. Esimerkki alla:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Huomaa, että asetamme Request Headers -otsikot:

- `accept`: haluttu vastausformaatti, tässä `application/json` eli JSON-muodossa.
- `authorization`: API-avaimesi, jonka voit valita alasvetovalikosta hakemuksen jälkeen.

Lisäksi asetamme Request Body -sisällön:

- `model`: videon luontimalli, tukee `sora-2` (standardi) ja `sora-2-pro` (HD). `sora-2-pro` tukee 25 sekunnin videoita, `sora-2` vain 10 ja 15 sekuntia.
- `size`: videon resoluutio, `small` standardi ja `large` HD (vain Versio 1).
- `duration`: videon pituus, 10, 15 tai 25 sekuntia (25 sekuntia vain `sora-2-pro`, vain Versio 1).
- `orientation`: kuvasuhde, `landscape` (vaaka) tai `portrait` (pysty) (vain Versio 1).
- `image_urls`: referenssikuvien URL-lista, käytetään kuvan perusteella videon luontiin (vain Versio 1).
- `character_url`: hahmon **###** URL, video ei saa sisältää oikeita ihmisiä (vain Versio 1).
- `character_start`/`character_end`: hahmon esiintymisen aloitus- ja lopetusaika sekunneissa, arvojen erotus 1-3 sekuntia (vain Versio 1).
- `prompt`: kehoteteksti (pakollinen).
- `callback_url`: asynkronisen palautteen URL.
- `version`: API-versio, `"1.0"` (oletus) tai `"2.0"`.

Palautetut kentät:

```shell
  "duration": 15,
  "orientation": "landscape",
  "prompt": "cat running on the river",
  "model": "sora-2"

```

## Kuvasta video -tehtävä (Versio 1)

Jos haluat luoda videon kuvan perusteella, syötä `image_urls`-parametri referenssikuvien URL-listana:

- `image_urls`: referenssikuvien URL-lista. Älä käytä oikeiden ihmisten kasvoja sisältäviä kuvia, sillä se voi aiheuttaa tehtävän epäonnistumisen.

Esimerkki:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

Generoitu koodi:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Python-esimerkki:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Hahmon luonti videoon (Versio 1)

Jos haluat luoda videon hahmolla, syötä `character_url`-parametri, joka on videon URL hahmon luontia varten. Huomioi, ettei videossa saa esiintyä oikeita ihmisiä, muuten tehtävä epäonnistuu.

- `character_url`: videon URL hahmon luontiin, ei oikeita ihmisiä sisältävä video.

Esimerkki:

<p><img src="https://cdn.acedata.cloud/2nhdr2.png" width="500" className="m-auto" /></p>

Generoitu koodi:

<p><img src="https://cdn.acedata.cloud/xp8scl.png" width="500" className="m-auto" /></p>

Python-esimerkki:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "small",
    "duration": 10,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "character_url": "https://cdn.acedata.cloud/pdidf5.mp4",
    "model": "sora-2",
```

## Versio 2.0 -tila

Versio 1.0:n lisäksi API tukee myös Versio 2.0 -tilaa, joka aktivoidaan asettamalla `version`-parametriksi `"2.0"`. Versio 2.0 tukee lyhyempiä videoita ja pikselitarkkaa resoluution hallintaa.

### Versio 2.0 parametrit

| Parametri       | Tyyppi  | Pakollinen | Kuvaus                         |
|-----------------|---------|------------|-------------------------------|
| `version`       | string  | Kyllä      | Aseta arvoon `"2.0"`           |
| `prompt`        | string  | Kyllä      | Videon luontikehotus           |
| `model`         | string  | Ei         | `sora-2` (oletus) tai `sora-2-pro` |
| `duration`      | integer | Ei         | Videon pituus: `4` (oletus), `8`, `12` sekuntia |
| `size`          | string  | Ei         | Resoluutio: `720x1280` (oletus), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls`    | array   | Ei         | Referenssikuvien URL-lista, käytetään vain ensimmäistä kuvaa, kuvan koko tulee vastata `size`-parametria |
| `callback_url`  | string  | Ei         | Asynkronisen palautteen URL   |

### Perusesimerkki

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "version": "2.0",
  "prompt": "cat running on the river",
  "model": "sora-2",
  "duration": 8,

}'
```

### Referenssikuvan käyttö (Versio 2.0)

Versio 2.0:ssa voit ohjata videon luontia syöttämällä `image_urls`-parametrin, joka sisältää referenssikuvan URL:n (käytetään vain ensimmäistä kuvaa):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": "2.0",
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Huom:** Referenssikuvan koko tulee vastata `size`-parametria, esimerkiksi jos `size` on `1280x720`, kuvan koko tulee olla 1280×720.

### Versio 1.0 vs Versio 2.0 -parametrien vertailu

| Parametri       | Versio 1.0           | Versio 2.0                                  |
|-----------------|----------------------|---------------------------------------------|
| `version`       | 1.0 (oletus)         | 2.0                                         |
| `prompt`        | ✅                   | ✅                                          |
| `model`         | ✅ sora-2 / sora-2-pro| ✅ sora-2 / sora-2-pro                       |
| `duration`      | ✅ 10/15/25 sekuntia | ✅ 4/8/12 sekuntia                           |
| `orientation`   | ✅ landscape/portrait | ❌                                          |
| `size`          | ✅ small/large        | ✅ 720x1280/1280x720/1024x1792/1792x1024    |
| `image_urls`    | ✅ useita kuvia       | ✅ vain ensimmäinen kuva                      |
| `character_url` | ✅                    | ❌                                          |
| `callback_url`  | ✅                    | ✅                                          |

## Asynkroninen palautus

Koska Sora Videos Generation API:n videon luonti kestää noin 1-2 minuuttia, API voi pitää HTTP-yhteyden auki pitkään, mikä kuluttaa järjestelmäresursseja. Siksi API tukee asynkronista palautusta.

Toimintaperiaate: kun asiakas tekee pyynnön, hän voi määrittää `callback_url`-kentän. API palauttaa heti vastauksen, joka sisältää `task_id`-kentän. Kun tehtävä valmistuu, API lähettää POST-pyynnön JSON-muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, sisältäen myös `task_id`:n, jolla tehtävä voidaan yhdistää.

Webhook-palvelu on HTTP-palvelu, joka vastaanottaa pyyntöjä. Voit käyttää omaa palvelintasi tai julkista esimerkkipalvelua kuten https://webhook.site/. Avaa sivusto ja saat Webhook-URL:n, kuten alla:

![](https://cdn.acedata.cloud/cjjfly.png)

Kopioi URL, esimerkiksi `https://webhook.site/eb238c4f-da3b-47a5-a922-a93aa5405daa`.

## Virheenkäsittely

API-kutsun aikana mahdolliset virheet palautetaan virhekoodin ja viestin muodossa. Esimerkkejä:

- `400 token_mismatched`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, ylität rajapinnan käyttörajan.
- `500 api_error`: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
