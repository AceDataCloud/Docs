Tässä artikkelissa esitellään Sora Videos Generation API -liittymisohje, jonka avulla voidaan luoda Soran virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää API:n hyödyntämiseen.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka tarkoittaa, että syötät kehotteen `prompt`, viittauskuvien linkki-taulukon `image_urls` sekä mallin `model`, ja saat käsitellyn tuloksen. Tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body -osion, joka sisältää:

- `model`: videon luomiseen käytettävä malli, pääasiassa `sora-2` ja `sora-2-pro`. Tällä hetkellä `sora-2` ja `sora-2-pro` voivat valita `size` ja `duration` -parametrin videosta, jossa `sora-2-pro` tukee 25 sekunnin videota, kun taas `sora-2` tukee vain 10 ja 15 sekuntia.
- `size`: tämän videon luontitehtävän tarkkuus, vaihtoehtoina `small` ja `large`.
- `image_urls`: viittauskuvien linkit tai Base64-koodattu taulukko, joka on ladattava.
- `duration`: tämän videon luontitehtävän kesto, vaihtoehtoina 10s, 15s ja 25s. Tällä hetkellä vain `sora-2-pro` tukee 25 sekuntia.
- `character_start`/`character_end`: hahmon sijainti kuvassa (0-1), käytetään pääasiallisen sijainnin hallintaan.
- `orientation`: kuvasuhde, tukee `landscape`, `portrait` ja `square`.
- `prompt`: kehotus.
- `callback_url`: URL, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

Palautetussa tuloksessa on useita kenttiä, jotka esitetään seuraavasti:

- `success`, tämänhetkisen videon luontitehtävän tila.
- `task_id`, tämänhetkisen videon luontitehtävän ID.
- `trace_id`, tämänhetkisen videon luontiseurannan ID.
- `data`, tämänhetkisen videon luontitehtävän tuloslista.
  - `id`, tämänhetkisen videon luontitehtävän videon ID.
  - `video_url`, tämänhetkisen videon luontitehtävän videon linkki.
  - `state`, tämänhetkisen videon luontitehtävän tila.

Voit nähdä, että olemme saaneet tyydyttävän videotiedon, ja meidän tarvitsee vain käyttää `data`-osion videolinkkiä saadaksemme luodun Sora-videon.

Jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "size": "large",
  "duration": 15,
  "orientation": "landscape",
  "prompt": "cat running on the river",
  "model": "sora-2"
}'
```

## Kuvasta video -tehtävä

Jos haluat luoda videotehtävän kuvasta, sinun on ensin syötettävä parametri `image_urls`, joka sisältää viittauskuvien linkit, jolloin voit määrittää seuraavat sisällöt:

- image_urls: tämä videotehtävä käyttää viittauskuvien linkki-taulukkoa.

Esimerkki täyttämisestä on seuraava:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" class="m-auto"></p>

Kun täyttö on valmis, se luo automaattisesti seuraavan koodin:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" class="m-auto"></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Hahmon luominen videotehtävä

Jos haluat luoda hahmon videotehtävän, ensinnäkin parametri `character_url` on pakko antaa luodaksesi hahmon tarvitsema videolinkki, huomaa, että videossa ei saa näkyä oikeita ihmisiä, muuten se epäonnistuu, voit määrittää seuraavat sisällöt:

- character_url: luodaksesi hahmon tarvitsema videolinkki, huomaa, että videossa ei saa näkyä oikeita ihmisiä, muuten se epäonnistuu.

Esimerkki täyttämisestä on seuraava:

<p><img src="https://cdn.acedata.cloud/2nhdr2.png" width="500" class="m-auto"></p>

Kun täyttö on valmis, se luo automaattisesti seuraavan koodin:

<p><img src="https://cdn.acedata.cloud/xp8scl.png" width="500" class="m-auto"></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "small",
    "duration": 10,
    "orientation": "landscape",
    "prompt": "kissa juoksee joella",
    "character_url": "https://cdn.acedata.cloud/pdidf5.mp4",
    "model": "sora-2",
    "character_end": 3,
    "character_start": 1
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten alla:

```

      "state": "succeeded"

```

Voit nähdä, että luodun efektin on hahmon luominen video, ja tulos on samanlainen kuin edellä.

## Asynkroninen palautus

Koska Sora Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: asiakas aloittaa pyynnön, kun hän määrittää ylimääräisen `callback_url` kentän, asiakas aloittaa API-pyynnön jälkeen, API palauttaa heti tuloksen, joka sisältää `task_id` kenttäinformaation, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luodun videon tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id` kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheen, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
