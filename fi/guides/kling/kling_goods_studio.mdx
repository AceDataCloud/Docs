Lähetä tehtävä `POST /kling/goods-studio` -kutsulla ja käytä olemassa olevaa `POST /kling/tasks` -kutsua alustan tehtävän tilan tarkistamiseen.

## Syöte

Tarjoa 1–5 tuotekuvaa ja enintään 200 merkin tuotteen otsikko; tuotekuvaus on valinnainen ja voi olla enintään 2000 merkkiä. Kesto voi olla valinnaisesti 15, 30 tai 60 sekuntia.

Seuraava on esimerkki pyyntörakenteesta, korvaa materiaalien URL-osoitteet ennen kutsua.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Tulokset ja laskutus

Synkroninen tila palauttaa generointitulokset; asynkroninen tila palauttaa ensin `task_id`:n, ja valmistunut tulos sisältää `data`-kentässä video- tai kuvalinkin sekä palvelimen laskeman `usage`-arvon. `callback_url`-osoitetta käytetään valmistumisilmoituksiin; `watermark=true`-pyyntö palauttaa samalla myös vesileimallisen version.

720p: 2.38 Credits/sekunti; 1080p: 2.8 Credits/sekunti. Videoista veloitetaan todellisen generoidun keston mukaan, eikä generointia edeltävä sekuntikohtainen perushinta edusta koko tehtävän kokonaishintaa. Epäonnistuneista tehtävistä ei veloiteta generointimaksua.
