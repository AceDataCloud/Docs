Tässä artikkelissa esitellään eräänlainen Kling Videos Generation API -integrointiohje, jonka avulla voidaan luoda Klingin virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

Käyttääksesi Kling Videos Generation API:a, hanki ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Tokenisi ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäinen hakemus antaa ilmaista käyttökiintiötä maksuttomaan kokeiluun; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Kling Videos Generation API →](https://platform.acedata.cloud/documents/kling-videos)

## Peruskäyttö

Tutustutaan ensin peruskäyttötapaan: syöttämällä kehotteen `prompt`, luontitoiminnon `action`, ensimmäisen ruudun viitekuvan `start_image_url` sekä mallin `model` voit saada käsitellyn tuloksen. Ensin on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `text2video`; se sisältää pääasiassa kolme toimintoa: tekstistä videoksi (`text2video`), kuvasta videoksi (`image2video`) ja videon laajennus (`extend`). Tämän jälkeen meidän on myös syötettävä malli `model`; tällä hetkellä käytettävissä ovat pääasiassa mallit `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-o1`, ja tarkempi sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Voidaan nähdä, että tässä asetamme Request Headers -otsakkeet, mukaan lukien:

- `accept`: missä muodossa haluat vastaanottaa vastaustuloksen; tähän täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsuavain, joka voidaan valita suoraan pudotusvalikosta hakemisen jälkeen.

Lisäksi asetetaan Request Body, mukaan lukien:

- `model`: videoiden luomiseen käytettävä malli; pääasiassa mallit `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-o1`.
- `mode`: videoiden luontitila; valinnaiset arvot ovat vakiotila `std`, erittäin nopea tila `pro` ja natiivi 4K-tila `4k`. Näistä `4k` tukee vain malleja `kling-v3` ja `kling-v3-omni`, eikä ole yhteensopiva `camera_control`-toiminnon (kameraliikkeen hallinta) kanssa.
- `action`: tämän videonluontitehtävän toiminto, joka sisältää pääasiassa kolme toimintoa: tekstistä videoksi (`text2video`), kuvasta videoksi (`image2video`) ja videon laajennus (`extend`).
- `start_image_url`: ensimmäisen ruudun viitekuvan linkki, joka on ladattava, kun valitaan kuvasta videoksi -toiminto `image2video`.
- `end_image_url`: valinnainen kuvasta videoksi -toiminnossa, määrittää viimeisen ruudun.
- `duration`: videon kesto sekunneissa. `kling-v3` ja `kling-v3-omni` tukevat 3–15 sekunnin kokonaislukukestoja; `kling-o1` tukee vain 5 sekuntia; muut mallit tukevat 5 tai 10 sekuntia.
- `generate_audio`: luodaanko ääni samanaikaisesti; valinnainen, totuusarvo. Tukee malleja `kling-v3`, `kling-v3-omni` sekä `kling-v2-6` (vain pro-tilassa). Oletusarvo on `false`.
- `aspect_ratio`: videon kuvasuhde, valinnainen; tukee arvoja `16:9`, `9:16`, `1:1`, oletusarvona `16:9`.
- `cfg_scale`: relevanssin voimakkuus, alue [0,1]; mitä suurempi arvo, sitä paremmin se vastaa kehotetta.
- `camera_control`: valinnainen, kamera liikettä ohjaava objektiparametri; tukee type/simple-esiasetuksia sekä määrityksiä kuten horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: valinnainen, käänteinen kehote asioille, joita ei haluta näkyvän, enintään 200 merkkiä.
- `image_list`: Omni-viitekuvaluettelo, soveltuvat mallit `kling-o1` ja `kling-v3-omni`; käyttö katso jäljempää kohdasta ”Omni-monipuolinen viite”.
- `video_list`: Omni-viitevideoluettelo (tukee videon muokkausta), soveltuvat mallit `kling-o1` ja `kling-v3-omni`; käyttö katso jäljempää kohdasta ”Omni-monipuolinen viite”.
- `prompt`: kehote.
- `callback_url`: URL, johon tulos tarvitsee takaisinsoiton.
- `async`: valinnainen; kun asetetaan arvoksi `true`, rajapinta palauttaa välittömästi `task_id`:n ilman, että `callback_url`-osoitetta tarvitsee antaa, minkä jälkeen tulos haetaan kyselevästi vastaavan tehtävän kyselyrajapinnan kautta.

Valinnan jälkeen voidaan havaita, että oikealle on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Voit testata napsauttamalla ”Try”-painiketta. Kuten yllä olevassa kuvassa näkyy, saamme seuraavan tuloksen:

```json
{
  "success": true,
  "video_id": "900798310464749610",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "duration": "5.041",
  "state": "succeed",
  "task_id": "6c68c267-065b-4423-b66b-a0e4c59ee0d5"
}
```

Palautustulos sisältää useita kenttiä, jotka esitellään seuraavasti:

- `success`, videonluontitehtävän tilanne tällä hetkellä.
- `task_id`, videonluontitehtävän ID tällä hetkellä.
- `video_id`, videonluontitehtävän video-ID tällä hetkellä.
- `video_url`, videonluontitehtävän videolinkki tällä hetkellä.
- `duration`, videonluontitehtävän videolinkin kesto tällä hetkellä.
- `state`, videonluontitehtävän tila tällä hetkellä.

Voidaan nähdä, että saimme tyydyttävät videotiedot; meidän tarvitsee vain hakea luotu Kling-video tuloksen `data`-kohdassa olevan videolinkin osoitteen perusteella.

Jos haluat lisäksi luoda vastaavan integrointikoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v3",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Malliominaisuuksien matriisi

Eri mallien tuki parametreille vaihtelee huomattavasti. Seuraava matriisi on koottu [Klingin virallisesta video models -dokumentaatiosta](https://app.klingai.com/global/dev/document-api/apiReference/model/videoModels); tarkista ennen kutsua, tukeeko nykyinen `model` / `mode` / `duration` -yhdistelmä tarvitsemaasi toimintoa, sillä muuten palautetaan virheitä, kuten `model/mode/duration(...) is not supported with image_tail`.
| Malli                  | Tila             | `end_image_url`（alku- ja loppuruutu） | `generate_audio`（ääniraita） | `camera_control`（kameraliike） | Huomautukset                                           |
| ------------------- | -------------- | -------------------- | -------------------- | -------------------- | -------------------------------------------- |
| `kling-v1`          | std / pro      | ✅ Vain `duration=5`     | ❌                    | ✅ Vain `duration=5`     | `extend` ei tue `negative_prompt`- eikä `cfg_scale`-parametria |
| `kling-v1-6`        | std            | ❌                    | ❌                    | ❌                    | Useita kuvia videoksi, `extend` käytettävissä kaikissa tiloissa                         |
| `kling-v1-6`        | pro            | ✅                    | ❌                    | ❌                    |                                              |
| `kling-v2-master`   | —              | ❌                    | ❌                    | ❌                    | Yksi tila, vain `duration=5/10`                       |
| `kling-v2-1-master` | —              | ❌                    | ❌                    | ❌                    | Yksi tila, vain `duration=5/10`                       |
| `kling-v2-5-turbo`  | std            | ❌                    | ❌                    | ❌                    |                                              |
| `kling-v2-5-turbo`  | pro            | ✅                    | ❌                    | ❌                    |                                              |
| `kling-v2-6`        | std            | ❌                    | ❌                    | ❌                    |                                              |
| `kling-v2-6`        | pro            | ✅                    | ✅                    | ❌                    | Ainoa muu kuin v3 -malli, joka tukee samanaikaisesti ääniraitaa                             |
| `kling-v3`          | std / pro      | ✅                    | ✅                    | ✅                    | `duration`-alue 3–15 sekuntia                         |
| `kling-v3`          | 4k             | ✅                    | ✅                    | ❌                    | 4K-tila ei ole yhteensopiva kameraliikkeen kanssa                                  |
| `kling-v3-omni`     | std / pro / 4k | ✅                    | ✅                    | ❌                    |                                              |
| `kling-o1`          | std / pro      | ✅                    | ❌                    | ❌                    | Tukee vain `duration=5`                             |

Huomioitavaa:

- `mode=4k` on tuettu vain malleissa `kling-v3` ja `kling-v3-omni`; lisäksi se on keskenään poissulkeva `camera_control`-parametrin (kameraliike) kanssa.
- `end_image_url`-parametria voi käyttää vain yhdessä `start_image_url`-parametrin kanssa, kun `action=image2video`. Vain `end_image_url`-parametrin välittäminen (ilman `start_image_url`-parametria) hylätään.
- `kling-v3` / `kling-v3-omni` hyväksyvät minkä tahansa kokonaislukuarvon 3–15 sekunnin väliltä `duration`-parametriksi; `kling-o1` hyväksyy vain arvon 5; muut mallit hyväksyvät vain arvon 5 tai 10.
- `generate_audio` on oletuksena `false`. Vain `kling-v3`, `kling-v3-omni` ja `kling-v2-6` (pro-tila) tukevat sitä.

## Videon laajennustoiminto

Jos haluat jatkaa jo luodun Kling-videon generointia, voit asettaa parametrin `action` arvoksi `extend` ja syöttää jatkettavan videon ID:n. Videon ID saadaan peruskäytön mukaisesti, kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Tällöin voit nähdä, että videon ID on:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Huomaa, että videon `video_id` tässä on generoinnin jälkeen saadun videon ID. Jos et tiedä, miten video generoidaan, voit luoda videon viittaamalla yllä olevaan peruskäyttöön.

Seuraavaksi meidän on täytettävä seuraavassa vaiheessa laajennukseen tarvittava kehote mukauttaaksemme generoitua videota, jolloin voit määrittää seuraavan sisällön:

- `model`: Videon generointimalli, pääasiassa mallit `kling-v1`, `kling-v1-5` ja `kling-v1-6`.
- `mode`: Videon generointitila, valinnaiset arvot ovat vakiotila `std`, nopea tila `pro` ja natiivi 4K-tila `4k` (vain `kling-v3` ja `kling-v3-omni` tukevat sitä, eikä se ole yhteensopiva kameraliikkeen ohjauksen kanssa).
- `duration`: Tämän videogenerointitehtävän videon kesto, sisältää pääasiassa 5 s ja 10 s.
- `start_image_url`: Kun valitaan kuvasta videoksi -toiminto `image2video`, ensimmäisen ruudun viitekuvan linkki on ladattava.
- `prompt`: Kehote.

Täyttöesimerkki on seuraava:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Täyttämisen jälkeen koodi generoidaan automaattisesti seuraavasti:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Napsauta suorita, ja voit havaita saavasi tuloksen seuraavasti:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Voidaan nähdä, että tuloksen sisältö vastaa yllä olevaa, ja näin videon laajennustoiminto toteutuu.

## Omni-yleisviite (videoeditointi / viitevideo / monikuvaviite)

`kling-o1` ja `kling-v3-omni` ovat kaksi erillistä mallia, ja molemmat tukevat ”yleisviite”-ominaisuutta. Tekstistä videoksi -toiminnon (`action=text2video`) perusteella voidaan lisäksi välittää viitekuvia tai viitevideoita, jolloin voidaan toteuttaa **monikuvaviite, viitevideo sekä olemassa olevan videon suora editointi**.

**Keskeinen käytäntö**: Viitemateriaaleihin on viitattava `prompt`-parametrissa muodossa `&lt;&lt;<image_1>>>`, `&lt;&lt;<video_1>>>` (numerointi alkaa numerosta 1), jotta ne vastaavat `image_list`- / `video_list`-luettelon vastaavassa sijainnissa olevaa materiaalia; vasta silloin malli käyttää näitä viitteitä. Jos vain materiaali välitetään, mutta siihen ei viitata kehotteessa, materiaali ohitetaan.

> Turvallisuusohje: Nykyinen API ei tarjoa `element_list`-parametria. Kling Element Libraryn ID:t eivät ole vuokralaiseristettyjä, joten käytä `image_list`-parametria kohteen viitekuvien välittämiseen ennen kuin vuokralaiseristyksen tarjoava Element Management API on saatavilla.

Omni-pyynnöt eivät tue `negative_prompt`-, `cfg_scale`- tai `camera_control`-parametria, eikä `mode=4k`-tilaa voi käyttää. Kun mukana on viitevideoita, `generate_audio`-parametrin on oltava `false`.

### Viitevideo ja videoeditointi (`video_list`)
`video_list` käytetään viitevideon välittämiseen, ja se on tämän toiminnon yleisin käyttötapa. Taulukon elementtien kentät ovat seuraavat:

- `video_url`: viitevideon linkki, ei voi olla tyhjä. Enintään 1 MP4/MOV-video, tiedostokoko ≤200MB, kuvataajuus 24–60fps. `kling-o1` edellyttää kestoa 3–10 sekuntia sekä leveyttä ja korkeutta kumpaakin 700–2160px; `kling-v3-omni` edellyttää kestoa 3–15.5 sekuntia, leveyttä ja korkeutta kumpaakin 700–4553px, kokonaispikseleitä ≤8,294,400 sekä kuvasuhdetta 0.4–2.
- `refer_type`: viitetyyppi, valittavissa `base` (oletus, **muokattava perusvideo**, eli "videon suora muokkaaminen", jossa voidaan lisätä/poistaa/muokata elementtejä, muuttaa sommittelua, vaihtaa tyyliä, värejä, säätä jne.) tai `feature` (**ominaisuusviite**, sen tyylin / kameraliikkeen / seuraavan otoksen jatkamisen viite).
- `keep_original_sound`: säilytetäänkö alkuperäisen videon ääni, valittavissa `yes` (säilytä) tai `no` (poista).

> Huomautus: kun viitevideo on olemassa, `generate_audio`-arvon on oltava `false`. Videolle, jonka `refer_type=base`, ei voi enää määrittää alku-/loppukehystä.

CURL-esimerkki olemassa olevan videon muokkaamisesta (videon muuttaminen anime-tyyliseksi) on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-o1",
  "mode": "std",
  "duration": 5,
  "prompt": "把 <<<video_1>>> 改成电影级动漫风格，保留原有的运动和构图",
  "video_list": [
    {
      "video_url": "https://cdn.acedata.cloud/your-reference-video.mp4",
      "refer_type": "base",
      "keep_original_sound": "no"
    }
  ]
}'
```

### Monikuvaviite (`image_list`)

`image_list`-kenttää käytetään viitekuvien (elementit / kohtaukset / tyylit jne.) välittämiseen. Taulukon elementtien kentät ovat seuraavat:

- `image_url`: viitekuvan linkki, ei voi olla tyhjä. Vaatimukset: muoto .jpg/.jpeg/.png; tiedostokoko ≤10MB; lyhyin sivu ≥300px; kuvasuhde 1:2.5 ~ 2.5:1.
- `type`: valinnainen. Jos sitä ei välitetä, kuva toimii pelkkänä viitekuvana; kun välitetään `first_frame` / `end_frame`, ne toimivat vastaavasti alku-/loppukehyksenä (vastaa `start_image_url` / `end_image_url`).

Käytettäessä siihen on viitattava `prompt`-kentässä tunnisteilla `&lt;&lt;<image_1>>>`, `&lt;&lt;<image_2>>>`. Määrärajoitus: kun viitevideota ei ole, viitekuvia ≤ 7; kun viitevideo on olemassa, viitekuvia ≤ 4. Kun välitetään vain alku-/loppukehys, voidaan käyttää myös suoraan `start_image_url` / `end_image_url`, mutta loppukehystä on käytettävä yhdessä alkukehyksen kanssa.

> Huomautus: jos `start_image_url` / `end_image_url` ja `image_list` välitetään samanaikaisesti, alku-/loppukehykset sijoitetaan ennen `image_list`-kenttää, mikä voi vaikuttaa `&lt;&lt;<image_N>>>`-järjestysnumeron vastaavuuteen. On suositeltavaa valita jompikumpi: kun tarvitaan alku-/loppukehystä, määritä `type` suoraan `image_list`-kentässä, älä käytä sitä yhdessä `start_image_url` / `end_image_url`-kenttien kanssa.

CURL-esimerkki videon luomisesta monikuvaviitteellä:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-o1",
  "mode": "std",
  "duration": 5,
  "prompt": "让 <<<image_1>>> 里的人物站在 <<<image_2>>> 的场景中，电影感光线",
  "image_list": [
    { "image_url": "https://cdn.acedata.cloud/subject.png" },
    { "image_url": "https://cdn.acedata.cloud/scene.png" }
  ]
}'
```

## Asynkroninen takaisinsoitto

Koska Kling Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1–2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden jatkuvasti avoinna, mikä aiheuttaa ylimääräistä järjestelmäresurssien kulutusta. Siksi tämä API tukee myös asynkronista takaisinsoittoa.

Kokonaisprosessi on seuraava: kun asiakas käynnistää pyynnön, se määrittää lisäksi `callback_url`-kentän. Kun asiakas käynnistää API-pyynnön, API palauttaa välittömästi tuloksen, joka sisältää `task_id`-kentän tiedot, jotka edustavat nykyisen tehtävän tunnusta. Kun tehtävä on valmis, videon luomisen tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, ja se sisältää myös `task_id`-kentän, jolloin tehtävän tulos voidaan yhdistää tunnuksen avulla.

Seuraavaksi tarkastelemme esimerkin avulla, miten toimitaan käytännössä.

Ensinnäkin Webhook-takaisinsoitto on palvelu, joka voi vastaanottaa HTTP-pyyntöjä. Kehittäjän tulee korvata se oman HTTP-palvelimensa URL-osoitteella. Tässä käytetään esittelyn helpottamiseksi julkista Webhook-esimerkkisivustoa https://webhook.site/. Avaamalla tämän sivuston saat Webhook-URL-osoitteen, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioimalla tämän URL-osoitteen sitä voidaan käyttää Webhookina. Tässä esimerkissä se on `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä mainituksi Webhook-URL-osoitteeksi ja täyttää samalla vastaavat parametrit. Tarkka sisältö näkyy kuvassa:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Napsauta suorita, ja huomaat, että saat välittömästi tuloksen seuraavasti:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Odota hetki, niin voimme nähdä videon luomisen tuloksen osoitteessa `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/zv5u2q.png)

Sisältö on seuraava:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"

```

Tuloksessa näkyy `task_id`-kenttä. Muut kentät ovat samankaltaisia kuin yllä, ja tämän kentän avulla voidaan toteuttaa tehtävien yhdistäminen.

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedon, jos tapahtuu virhe. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Luvaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.
### Esimerkki virhevastauksesta

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Yhteenveto

Tämän dokumentin avulla olet oppinut, kuinka Kling Videos Generation API:a voidaan käyttää videoiden luomiseen syöttämällä kehotetekstiä sekä ensimmäisen ruudun viitekuvaa. Toivomme, että tämä dokumentti auttaa sinua paremmin integroimaan ja käyttämään tätä API:a. Jos sinulla on kysyttävää, ota milloin tahansa yhteyttä tekniseen tukitiimiimme.

### Kling 3.0 Turbo

`model="kling-v3-turbo"` tukee tekstistä videoksi- ja ensimmäisestä ruudun kuvasta videoksi -toimintoja, ja kesto voi olla 3–15 sekunnin kokonaisluku. `mode="std"` tuottaa 720p:n ja `mode="pro"` 1080p:n. Mallissa on sisäänrakennettu natiiviääni, eikä sen poistamiseen tarjota kytkintä; jätä `generate_audio` pois tai aseta sen arvoksi `true`. Tämä malli ei tue viimeistä ruutua, kameraliikeobjekteja, erillisiä negatiivisia kehotteita tai `cfg_scale`-asetusta. Kuvaile `prompt`-kentässä suoraan sisältö, jota tarvitaan tai jota halutaan välttää.

### Monikuvausvideo

`kling-v3` ja `kling-v3-omni` tukevat asetusta `multi_shot=true`. `shot_type="intelligence"` jakaa kohtaukset automaattisesti `prompt`-kentän perusteella; `shot_type="customize"` tarjoaa `multi_prompt`-kentän kautta 1–6 kohtausta, joista jokainen sisältää arvosta 1 alkaen jatkuvasti kasvavan `index`-arvon, enintään 512 merkin pituisen `prompt`-arvon ja vähintään 1 sekunnin kokonaislukuarvoisen `duration`-arvon. Kaikkien kohtausten kestojen summan on oltava yhtä suuri kuin kokonais-`duration`. Mukautetut kohtaukset eivät käytä globaalia `prompt`-kenttää. Monikuvauksesta veloitetaan valitun mallin, kuvanlaadun, äänimäärityksen ja kokonaiskeston mukaan.
