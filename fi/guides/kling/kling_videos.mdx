Tässä dokumentissa esitellään Kling Videos Generation API:n integrointiohjeet, jonka avulla voi syöttää mukautettuja parametreja ja luoda Klingin virallisia videoita.

## Hakuprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua osoitteesta [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). Sivulle siirryttyäsi klikkaa "Acquire"-painiketta, kuten kuvassa:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, jonka avulla voit käyttää API:a maksutta.

## Peruskäyttö

Ensiksi tutustutaan peruskäyttöön: syötetään prompt-teksti `prompt`, toimintatapa `action`, aloituskuvan URL `start_image_url` sekä malli `model`, jolloin saadaan käsitelty tulos. Tarvitaan yksinkertaisesti `action`-kenttä, jonka arvoksi asetetaan `text2video`. Toimintoja on kolme: tekstistä videoon (`text2video`), kuvasta videoon (`image2video`) ja videon jatkaminen (`extend`). Lisäksi valitaan malli `model`. Saatavilla on mallit `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni` ja `kling-video-o1`. Tarkemmat tiedot alla:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Request Headers -otsikot ovat:

- `accept`: haluttu vastausformaatti, tässä `application/json` eli JSON-muoto.
- `authorization`: API-avaimesi, jonka saat haun jälkeen alasvetovalikosta.

Request Body sisältää:

- `model`: videon generointimalli, kuten yllä mainitut.
- `mode`: videon generointitila, vaihtoehdot ovat standardi `std`, nopea `pro` ja natiivi 4K `4k`. 4K-tila tukee vain `kling-v3` ja `kling-v3-omni` -malleja, eikä ole yhteensopiva `camera_control`-parametrin kanssa.
- `action`: videon generointitoiminto, kolme vaihtoehtoa: `text2video`, `image2video`, `extend`.
- `start_image_url`: pakollinen, kun valitaan `image2video`, eli aloituskuvan URL.
- `end_image_url`: valinnainen, videon loppukuva `image2video`-toiminnossa.
- `duration`: videon pituus sekunteina. `kling-v3` ja `kling-v3-omni` tukevat 3–15 sekunnin pituuksia (kokonaisluku), muut mallit 5 tai 10 sekuntia.
- `generate_audio`: valinnainen, boolean-arvo, määrittää luodaanko ääni samanaikaisesti. Tukee `kling-v3`, `kling-v3-omni` ja `kling-v2-6` (vain pro-tila). Oletus `false`.
- `aspect_ratio`: videon kuvasuhde, valinnainen, tuetut arvot `16:9`, `9:16`, `1:1`, oletus `16:9`.
- `cfg_scale`: korrelaation voimakkuus, arvo välillä [0,1], suurempi arvo tarkoittaa tarkempaa vastaavuutta promptiin.
- `camera_control`: valinnainen, kameran liikkeen ohjausparametrit, tukee tyyppiä/simple-esiasetuksia sekä asetuksia kuten horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: valinnainen, ei-toivottujen elementtien kuvaus, max 200 merkkiä.
- `element_list`: pääelementtien lista, vain `kling-video-o1`-mallille, käyttöohjeet [virallisessa dokumentaatiossa](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: referenssivideot URL-muodossa, vain `kling-video-o1`-mallille, käyttöohjeet samassa dokumentaatiossa.
- `prompt`: tekstiprompti.
- `callback_url`: URL, johon palautetaan tulos asynkronisesti.

Valinnan jälkeen oikealle puolelle syntyy vastaava koodiesimerkki, kuten kuvassa:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Klikkaa "Try" -painiketta testataksesi. Saat tuloksen, esimerkiksi:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Palautetut kentät:

- `success`: videon generointitehtävän tila.
- `task_id`: tehtävän tunniste.
- `video_id`: videon tunniste.
- `video_url`: videon URL.
- `duration`: videon pituus.
- `state`: tehtävän tila.

Saat siis luodun Kling-videon `video_url`-osoitteesta.

Voit myös kopioida automaattisesti generoituja koodiesimerkkejä, kuten CURL:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Mallien ominaisuustaulukko

Mallien tuki eri parametreille vaihtelee merkittävästi. Alla oleva taulukko on koottu [Klingin virallisesta video-mallidokumentaatiosta](https://app.klingai.com/global/dev/document-api/apiReference/model/videoModels). Tarkista ennen kutsua, että valittu `model` / `mode` / `duration` -yhdistelmä tukee haluamiasi ominaisuuksia, muuten saat virheen kuten `model/mode/duration(...) is not supported with image_tail`.

| Malli | Tila | `end_image_url` (aloitus/loppukuva) | `generate_audio` (ääni) | `camera_control` (kameran liike) | Huomautukset |
|---|---|---|---|---|---|
| `kling-v1` | std / pro | ✅ vain `duration=5` | ❌ | ✅ vain `duration=5` | `extend` ei tue `negative_prompt` tai `cfg_scale` |
| `kling-v1-6` | std | ❌ | ❌ | ❌ | Monikuva-video ja `extend` kaikki tilat käytettävissä |
| `kling-v1-6` | pro | ✅ | ❌ | ❌ | |
| `kling-v2-master` | — | ❌ | ❌ | ❌ | Yksi tila, vain `duration=5/10` |
| `kling-v2-1-master` | — | ❌ | ❌ | ❌ | Yksi tila, vain `duration=5/10` |
| `kling-v2-5-turbo` | std | ❌ | ❌ | ❌ | |
| `kling-v2-5-turbo` | pro | ✅ | ❌ | ❌ | |
| `kling-v2-6` | std | ❌ | ❌ | ❌ | |
| `kling-v2-6` | pro | ✅ | ✅ | ❌ | Ainoa ei-v3-malli, joka tukee ääntä |
| `kling-v3` | std / pro | ✅ | ✅ | ✅ | `duration` 3–15 sekuntia |
| `kling-v3` | 4k | ✅ | ✅ | ❌ | 4K-tila ei tue kameran liikettä |
| `kling-v3-omni` | std / pro / 4k | ✅ | ✅ | ❌ | |
| `kling-video-o1` | std / pro | ✅ | ❌ | ❌ | Tukee vain `duration=5/10` |

Huomioita:

- `mode=4k` tukee vain `kling-v3` ja `kling-v3-omni` -malleja, eikä ole yhteensopiva `camera_control`-parametrin kanssa.
- `end_image_url` on käytettävissä vain `action=image2video` -toiminnossa yhdessä `start_image_url` kanssa. Pelkkä `end_image_url` ilman `start_image_url` hylätään.
- `kling-v3` ja `kling-v3-omni` hyväksyvät minkä tahansa 3–15 sekunnin kokonaislukupituuden; muut mallit vain 5 tai 10 sekuntia.
- `generate_audio` on oletuksena `false`. Tukee vain `kling-v3`, `kling-v3-omni` ja `kling-v2-6` (pro-tila).

## Videon jatkaminen (extend)

Jos haluat jatkaa jo luotua Kling-videota, aseta `action` arvoksi `extend` ja syötä jatkettavan videon ID. Videon ID saadaan peruskäytön yhteydessä, kuten kuvassa:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Videon ID on:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Huom: `video_id` on luodun videon tunniste. Jos et tiedä miten video luodaan, katso peruskäyttö-osio.

Seuraavaksi määrittele jatkettavan videon prompt ja muut parametrit:

- `model`: videon generointimalli, esim. `kling-v1`, `kling-v1-5`, `kling-v1-6`.
- `mode`: tila, valinnat `std`, `pro` ja `4k` (4k vain `kling-v3` ja `kling-v3-omni`, ei yhteensopiva kameran liikkeen kanssa).
- `duration`: videon pituus (5 tai 10 sekuntia).
- `start_image_url`: pakollinen, jos valitaan `image2video`.
- `prompt`: tekstiprompti.

Esimerkki:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Automaattisesti generoitu koodi:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Python-esimerkki:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Suorita koodi, saat vastauksen:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Tulokset ovat yhtenevät peruskäytön kanssa, eli videon jatkaminen onnistui.

## Asynkroninen callback

Koska Kling Videos Generation API:n generointiaika on noin 1–2 minuuttia, pitkäaikainen synkroninen HTTP-pyyntö kuormittaa järjestelmää. Siksi API tukee asynkronista callback-toimintoa.

Käyttö:

- Lähetä pyyntö, jossa on `callback_url`-kenttä.
- API palauttaa heti `task_id`-tunnisteen.
- Kun tehtävä valmistuu, API lähettää POST-pyynnön JSON-muodossa `callback_url`-osoitteeseen, sisältäen `task_id`-kentän.
- Näin voit yhdistää tehtävän tuloksen tunnisteen avulla.

Esimerkki:

Webhook on HTTP-palvelu, joka vastaanottaa pyyntöjä. Käytämme esimerkkinä julkista palvelua https://webhook.site/. Avaa sivu ja saat Webhook-URL:n, esim:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioi URL, esimerkiksi `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Aseta `callback_url` tähän osoitteeseen ja muut parametrit:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Suorita pyyntö, saat välittömästi vastauksen:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Hetken kuluttua näet Webhook-sivulla generoidun videon tuloksen:

![](https://cdn.acedata.cloud/zv5u2q.png)

Sisältö:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

`task_id` mahdollistaa tehtävien yhdistämisen.

## Virheenkäsittely

API-kutsun yhteydessä virhetilanteissa palautetaan virhekoodi ja viesti, esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Valtuutusvirhe, virheellinen tai puuttuva token.
- `429 too_many_requests`: Liian monta pyyntöä, ylitetty rajoitus.
- `500 api_error`: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
