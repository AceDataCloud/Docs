Tässä artikkelissa esitellään Kling Videos Generation API -integraatio-ohjeet, jonka avulla voidaan luoda Klingin virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka tarkoittaa, että syötät kehotteen `prompt`, generointitoiminnon `action`, ensimmäisen kehyksen viittauskuvan `start_image_url` sekä mallin `model`, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `text2video`. Tämä sisältää pääasiassa kolme toimintoa: tekstistä videoon (`text2video`), kuvasta videoon (`image2video`), ja videon laajentaminen (`extend`). Sitten meidän on myös syötettävä malli `model`, joka tällä hetkellä sisältää pääasiassa mallit `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`, tarkat sisällöt ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body:n, mukaan lukien:

- `model`: videon luomiseen käytettävä malli, pääasiassa `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1` mallit.
- `mode`: videon luontitila, pääasiassa standarditila `std` ja nopea tila `pro`.
- `action`: tämän videon luontitehtävän toiminto, joka sisältää kolme päätoimintoa: tekstistä videoon (`text2video`), kuvasta videoon (`image2video`), ja videon laajentaminen (`extend`).
- `start_image_url`: kun valitaan kuvasta videoon -toiminto `image2video`, on pakko ladata ensimmäisen kehyksen viittauskuvan linkki.
- `end_image_url`: kuvasta videoon -toiminnassa valinnainen, määrittää viimeisen kehyksen.
- `aspect_ratio`: videon kuvasuhde, valinnainen, tukee `16:9`, `9:16`, `1:1`, oletusarvo `16:9`.
- `cfg_scale`: korrelaation voimakkuus, alueella [0,1], mitä suurempi, sitä enemmän se vastaa kehotetta.
- `camera_control`: valinnainen, kameran liikkeen ohjaamiseen liittyvät parametrit, tukee type/simple -esiasetuksia sekä horisontaalisia, pystysuoria, pan, tilt, roll, zoom jne. asetuksia.
- `negative_prompt`: valinnainen, ei-toivottuja vastakkaisia kehotteita, enintään 200 merkkiä.
- `element_list`: pääasiallinen viittauslista, soveltuu vain mallille `kling-video-o1`, tämän parametrin tarkkaa käyttöä varten katso [viralliset asiakirjat](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: viittausvideo, saatavilla URL-osoitteen kautta, soveltuu vain mallille `kling-video-o1`, tämän parametrin tarkkaa käyttöä varten katso [viralliset asiakirjat](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: kehotteet.
- `callback_url`: URL, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämän videon luontitehtävän tila.
- `task_id`, tämän videon luontitehtävän ID.
- `video_id`, tämän videon luontitehtävän videon ID.
- `video_url`, tämän videon luontitehtävän videon linkki.
- `duration`, tämän videon luontitehtävän videon kesto.
- `state`, tämän videon luontitehtävän tila.

Voit nähdä, että olemme saaneet tyydyttävää videotietoa, ja meidän tarvitsee vain käyttää tuloksessa `data`-kentän videolinkkiä saadaksemme luodun Kling-videon.

Jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "Valkoinen keramiikkakahvimuki kiiltävällä marmoritasolla aamun ikkunavalossa. Kamera pyörii hitaasti 360 astetta mukin ympäri, pysähtyen hetkeksi kahvinkupin kahvaan."
}'
```

## Videon laajennustoiminto

Jos haluat jatkaa jo luodun Kling-videon luomista, voit asettaa parametrin `action` arvoksi `extend` ja syöttää videon ID:n, jonka haluat jatkaa. Videon ID:n saat peruskäytön mukaan, kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" class="m-auto"></p>

Tässä vaiheessa voit nähdä videon ID:n olevan:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Huomaa, että tässä videossa `video_id` on luodun videon ID. Jos et tiedä, miten video luodaan, voit viitata edellä mainittuun peruskäyttöön videon luomiseksi.

Seuraavaksi sinun on täytettävä seuraava vaihe, jossa on laajennettavat kehotteet videon mukauttamiseksi, jolloin voit määrittää seuraavat sisällöt:
- `model`：Videon luomiseen käytettävä malli, pääasiassa `kling-v1` , `kling-v1-5` ja `kling-v1-6` mallit.
- `mode`：Videon luomisen tila, pääasiassa standarditila `std` ja nopea tila `pro`.
- `duration`：Tämän videon luontitehtävän kesto, pääasiassa 5s ja 10s.
- `start_image_url`：Kun valitaan kuvasta video -toiminto `image2video`, on pakko ladata ensimmäisen kehyksen viittauskuvan linkki.
- `prompt`：Vihje.

Täyttöesimerkki alla:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" class="m-auto"></p>

Kun täyttö on valmis, syntyy automaattisesti seuraava koodi:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" class="m-auto"></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "Valkoinen keramiikkakahvimuki kiiltävällä marmoritasolla aamun ikkunavalossa. Kamera pyörii hitaasti 360 astetta mukin ympäri, pysähtyen hetkeksi kahvimukin kahvaan.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, voit huomata, että saat tuloksen, kuten alla:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Voit nähdä, että tuloksen sisältö on sama kuin edellä, mikä toteuttaa videon laajennustoiminnon.

## Asynkroninen palautus

Koska Kling Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: asiakas käynnistää pyynnön, kun se määrittää ylimääräisen `callback_url` kentän, asiakas käynnistää API-pyynnön jälkeen, API palauttaa heti tuloksen, joka sisältää `task_id` kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luodun videon tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url` -osoitteeseen, johon sisältyy myös `task_id` kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten toimia.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, kehittäjän tulisi korvata se omalla rakentamallaan HTTP-palvelimen URL-osoitteella. Tässä esimerkin vuoksi käytetään julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL-osoitteen, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioi tämä URL-osoite, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL-osoitteeseen ja täyttää vastaavat parametrit, tarkka sisältö on kuvassa näkyvä:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" class="m-auto"></p>

Kun napsautat suorita, voit huomata, että saat heti tuloksen, kuten alla:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Odota hetki, niin voit tarkkailla luodun videon tulosta osoitteessa `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/zv5u2q.png)

Sisältö on seuraava:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Voit nähdä, että tuloksessa on `task_id` kenttä, muut kentät ovat samankaltaisia kuin edellä, tämän kentän avulla voit yhdistää tehtävät.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
