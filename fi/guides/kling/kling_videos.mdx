Tässä dokumentissa esitellään Kling Videos Generation API:n liittäminen, jonka avulla voidaan luoda Klingin virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46) -sivulta. Sivulle tultuasi napsauta "Acquire"-painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, jolla voit käyttää API:a maksutta.

## Peruskäyttö

Ensiksi tutustutaan peruskäyttötapaan: syötetään kehoteteksti `prompt`, generointitoiminto `action`, aloituskuvan URL `start_image_url` ja malli `model`, jolloin saadaan käsitelty tulos. Lähetetään yksinkertaisesti `action`-kenttä, jonka arvoksi asetetaan `text2video`. Toimintoja on kolme: tekstistä videoon (`text2video`), kuvasta videoon (`image2video`) ja videon jatkaminen (`extend`). Lisäksi valitaan malli `model`. Tällä hetkellä käytettävissä ovat mallit `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni` ja `kling-video-o1`. Tarkemmat tiedot alla:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Huomaa, että asetamme Request Headers -otsikot, jotka sisältävät:

- `accept`: haluttu vastausmuoto, tässä `application/json` eli JSON-muodossa.
- `authorization`: API-avaimesi, jonka voit valita alasvetovalikosta haun jälkeen.

Request Body sisältää seuraavat kentät:

- `model`: videon generointimalli, kuten `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`.
- `mode`: videon generointitila, valinnat ovat standardi `std`, nopea `pro` ja alkuperäinen 4K `4k`. `4k` tukee vain `kling-v3` ja `kling-v3-omni` malleja, eikä ole yhteensopiva `camera_control`-asetuksen kanssa.
- `action`: videon generointitoiminto, kolme vaihtoehtoa: tekstistä videoon (`text2video`), kuvasta videoon (`image2video`), jatkaminen (`extend`).
- `start_image_url`: pakollinen aloituskuvan URL, kun käytetään `image2video`-toimintoa.
- `end_image_url`: valinnainen loppukuvan URL kuvasta videoon -toiminnossa.
- `duration`: videon pituus sekunteina. `kling-v3` ja `kling-v3-omni` tukevat joustavaa pituutta 3-15 sekuntia (kokonaisluku), muut mallit tukevat 5 tai 10 sekuntia.
- `generate_audio`: valinnainen, boolean-arvo, määrittää luodaanko ääni samanaikaisesti. Tuettu `kling-v3`, `kling-v3-omni` ja `kling-v2-6` (vain pro-tilassa). Oletuksena `false`.
- `aspect_ratio`: valinnainen kuvasuhde, tuetut arvot `16:9`, `9:16`, `1:1`. Oletus `16:9`.
- `cfg_scale`: korrelaation voimakkuus, arvo välillä [0,1], suurempi arvo tarkoittaa tiukempaa vastaavuutta kehotetekstiin.
- `camera_control`: valinnainen kameran liikkeen ohjausparametri, tukee tyyppiä/simple-esiasetuksia sekä asetuksia kuten horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: valinnainen kiellettyjen elementtien kehoteteksti, max 200 merkkiä.
- `element_list`: pääelementtien referenssilista, käytettävissä vain `kling-video-o1` mallissa. Tarkemmat ohjeet [virallisessa dokumentaatiossa](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: referenssivideot URL-muodossa, käytettävissä vain `kling-video-o1` mallissa. Tarkemmat ohjeet [virallisessa dokumentaatiossa](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: kehoteteksti.
- `callback_url`: URL, johon tulokset palautetaan.

Kun valinnat on tehty, oikealle puolelle generoituu vastaava koodiesimerkki, kuten alla näkyy:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Napsauttamalla "Try"-painiketta voit testata pyyntöä. Kuvassa näkyy saatu vastaus:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Vastauksessa on useita kenttiä:

- `success`: videon generointitehtävän tila.
- `task_id`: tehtävän tunniste.
- `video_id`: videon tunniste.
- `video_url`: videon URL.
- `duration`: videon pituus.
- `state`: tehtävän tila.

Näin saimme halutun videon tiedot, ja voimme hakea Kling-videon `data`-kentän videolinkin avulla.

Jos haluat luoda liitäntäkoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Videon jatkotoiminto

Jos haluat jatkaa jo luotua Kling-videota, aseta `action`-parametriksi `extend` ja syötä jatkettavan videon ID. Videon ID saadaan peruskäytön kautta, kuten alla näkyy:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Videon ID on:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Huomioi, että `video_id` on luodun videon tunniste. Jos et tiedä miten video luodaan, katso peruskäyttö-osio.

Seuraavaksi täytetään jatkokehote videon mukauttamiseksi:

- `model`: videon generointimalli, kuten `kling-v1`, `kling-v1-5` tai `kling-v1-6`.
- `mode`: generointitila, valinnat standardi `std`, nopea `pro` ja 4K `4k` (vain `kling-v3` ja `kling-v3-omni`, ei yhteensopiva kameran ohjauksen kanssa).
- `duration`: videon pituus, 5 tai 10 sekuntia.
- `start_image_url`: pakollinen aloituskuvan URL, jos käytetään `image2video`-toimintoa.
- `prompt`: kehoteteksti.

Esimerkki täytöstä:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Täytön jälkeen generoitu koodi:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Suorita koodi, saat tuloksen:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Tulokset vastaavat aiempaa, mikä mahdollistaa videon jatkamisen.

## Asynkroninen callback

Koska Kling Videos Generation API:n generointiaika on melko pitkä, noin 1-2 minuuttia, API tarjoaa asynkronisen callback-tuen. Jos API ei vastaa pitkään, HTTP-yhteys pysyy auki, mikä kuormittaa järjestelmää.

Käyttöprosessi: asiakas määrittää `callback_url`-kentän pyynnössä. API palauttaa heti vastauksen, jossa on `task_id`. Kun tehtävä valmistuu, tulos lähetetään POST-pyynnöllä JSON-muodossa asiakkaan määrittelemään `callback_url`-osoitteeseen, sisältäen myös `task_id`, jolla tehtävä voidaan yhdistää.

Esimerkki:

Webhook callback on HTTP-palvelu, johon API lähettää pyynnön. Kehittäjän tulee käyttää omaa palvelinta, mutta esimerkkinä käytämme julkista webhook-sivustoa https://webhook.site/. Sivulta saat webhook-URL:n, kuten kuvassa:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioi URL, esimerkiksi `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, ja käytä sitä `callback_url`-kentässä. Täytä muut parametrit kuten alla:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

Suorita pyyntö, saat välittömästi vastauksen:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Hetken kuluttua näet tuloksen webhook-sivulla:

![](https://cdn.acedata.cloud/zv5u2q.png)

Sisältö:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Tuloksessa on `task_id`-kenttä, jonka avulla tehtävä voidaan yhdistää.

## Virheenkäsittely

API-kutsujen virhetilanteissa palautetaan virhekoodi ja viesti. Esimerkkejä:

- `400 token_mismatched`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, ylitetty rajoitus.
- `500 api_error`: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
