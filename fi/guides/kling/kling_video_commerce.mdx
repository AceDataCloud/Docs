Lähetä tehtävä `POST /kling/video-commerce` -kutsulla ja käytä olemassa olevaa `POST /kling/tasks`-kutsua alustan tehtävän tilan tarkistamiseen.

## Syöte

Lataa yksi henkilökuva ja määritä voice_id tai käytä yhtä esiasetettua avatar_id:tä (nämä sulkevat toisensa pois, esiasetetulle hahmolle ei voi erikseen määrittää voice_id:tä). On pakko antaa enintään 2 000 merkin speech_script. Kun tuotetiedot annetaan, tarvitaan vähintään yksi ref_image ja yksi goods_title; tuotepuhevideo ei tue speech_ratea. Tavallinen henkilöpuhevideo tukee 0,8-, 1,0- tai 1,2-kertaista puhenopeutta.

Seuraava on esimerkki pyyntörakenteesta, korvaa materiaalien URL-osoitteet ennen kutsua.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Tulokset ja laskutus

Synkroninen tila palauttaa luontituloksen; asynkroninen tila palauttaa ensin `task_id`:n, ja valmistunut tulos sisältää `data`-kentässä video- tai kuvalinkit sekä palvelimen laskeman `usage`-arvon. `callback_url` käytetään valmistumisilmoitukseen; `watermark=true`-pyyntö palauttaa samalla myös vesileimaversion.

Tavallinen henkilöpuhevideo: 720p maksaa 1,4 Credits/sekunti ja 1080p 1,68 Credits/sekunti; tuotepuhevideo: 720p maksaa 1,96 Credits/sekunti ja 1080p 2,24 Credits/sekunti. Videot laskutetaan todellisen luodun keston mukaan, ja ennen luontia ilmoitettu sekuntikohtainen perushinta ei edusta koko tehtävän kokonaishintaa. Epäonnistuneista tehtävistä ei veloiteta luontimaksua.
