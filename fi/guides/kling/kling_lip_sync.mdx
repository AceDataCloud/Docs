Saa **olemassa olevan Kling-videon** (5 sekuntia tai 10 sekuntia) "puhumaan" äänen tai tekstin mukaan — eli synkronoi huulet (Lip Sync). Yhdessä `/kling/videos`-palvelun `image2video`-toiminnon (saa valokuvan liikkumaan) kanssa tästä voidaan muodostaa täydellinen "**puhuva valokuva / digitaalisen ihmisen puheenvuoro**" -prosessi.

> Tämä rajapinta on AceDataCloudin tarjoama yhden vaiheen kätevä kääre, joka on suunnattu yleisiin ääni-/tekstiohjattuihin tilanteisiin; se ei ole Klingin virallisen ”kasvojentunnistus → Advanced Lip Sync” -monivaiherajapinnan kenttien peilikuva. Noudata tämän sivun parametrien taulukkoa.

- **Rajapinnan osoite**：`POST https://api.acedata.cloud/kling/lip-sync`
- **Pyyntömuoto**：`application/json`
- **Vastausmuoto**：`application/json`
- **Laskutus**：jokainen onnistunut kutsu **2.45 Credits** (kiinteä)

## Pyyntöotsakkeet (Request Headers)

| Kenttä              | Arvo                   | Kuvaus                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | API-avaimesi, [hanki se täältä](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | Pyyntötekstin muoto                                            |
| `accept`        | `application/json`  | Vastausmuoto                                             |

## Pyyntöparametrit (Request Body)

| Parametri               | Tyyppi      | Pakollinen  | Oletus      | Kuvaus                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Kyllä   | —       | Luontitila. Luettelo: `audio2video` (ääniohjattu), `text2video` (tekstiohjattu)                                                                           |
| `video_id`       | string  | Valitse toinen | —       | Klingillä luodun videon ID (kuten `/kling/videos`-palvelun image2video-toiminnon palauttama `video_id`). **Tukee vain viimeisten 30 päivän aikana luotuja 5s/10s-videoita**. Valitse joko `video_id` tai `video_url`; molempia ei voi lähettää samanaikaisesti |
| `video_url`      | string  | Valitse toinen | —       | Julkisesti saatavilla oleva videolinkki. Rajoitukset: `.mp4`/`.mov`, ≤100MB, kesto 2–10s, vain 720p/1080p, sivun pituus 720–1920px. Valitse joko tämä tai `video_id`                                  |
| `audio_url`      | string  | Ehdollinen  | —       | Ohjaavan äänen lataus-URL, pakollinen, kun `audio2video` + `audio_type=url`. Muodot `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Ei   | `url`   | Äänen siirtotapa. Luettelo: `url`, `file` (voimassa `audio2video`-tilassa)                                                                                |
| `audio_file`     | string  | Ehdollinen  | —       | Äänitiedoston Base64, pakollinen, kun `audio_type=file`. Muoto sama kuin yllä, ≤5MB                                                                             |
| `text`           | string  | Ehdollinen  | —       | Luettava teksti, pakollinen `text2video`-tilassa, **enintään 120 merkkiä**                                                                                     |
| `voice_id`       | string  | Ehdollinen  | —       | Äänen sävyn ID, pakollinen `text2video`-tilassa                                                                                                   |
| `voice_language` | string  | Ei   | `zh`    | Äänen sävyn kieli. Luettelo: `zh`, `en` (voimassa `text2video`-tilassa)                                                                                      |
| `voice_speed`    | float   | Ei   | `1.0`   | Puheen nopeus, alue `0.8`–`2.0`, yhden desimaalin tarkkuudella (voimassa `text2video`-tilassa)                                                                              |
| `callback_url`   | string  | Ei   | —       | Takaisinkutsuosoite. Tämän tai `async=true`-arvon välittäminen tarkoittaa **asynkronista tilaa**: palauttaa heti `task_id`-arvon ja kutsuu takaisin tuloksen valmistuttua                                                                 |
| `async`          | boolean | Ei   | `false` | Onko asynkroninen. Kun `true`, palauttaa heti `task_id`-arvon; käytä yhdessä `/kling/tasks`-kyselyn tai `callback_url`-takaisinkutsun kanssa                                                      |

## Pyyntöesimerkit

### 1）Ääniohjattu (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2）Tekstiohjattu (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "哥，好久不见，我一切都好，你要照顾好自己。",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Vastausesimerkki (synkroninen onnistuminen)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Kenttä          | Tyyppi      | Kuvaus                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | Onnistuiko kutsu                                       |
| `task_id`   | string  | Tämän tehtävän ID (voidaan käyttää `/kling/tasks`-kyselyyn)             |
| `video_id`  | string  | Luodun videon Kling-ID (voidaan käyttää seuraavan `extend`/`lip-sync`-kutsun syötteenä) |
| `video_url` | string  | Luodun puhevideon URL (tallennettu tälle alustan CDN:lle, voimassa pitkään)              |
| `duration`  | string  | Videon kesto (sekunteina)                                    |
| `state`     | string  | Tehtävän tila: `succeed` / `failed`                  |

## Asynkroninen tila ja kysely

Kun välitetään `callback_url` tai `async: true`, rajapinta **palauttaa välittömästi** `task_id`-arvon; sen jälkeen voit:

- **Kysellä tilaa**：`POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }` (maksuton)
- **Takaisinkutsu**：luonnin valmistuttua tulos POSTataan sinun `callback_url`-osoitteeseesi

## Täydellinen prosessi: puhuva valokuva (image2video → lip-sync)
```bash
# Vaihe 1: Animaatioi valokuva, hae video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Vaihe 2: Synkronoi huulet äänen kanssa
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"}'
# → { "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4", ... }
```

## Virhevastaus

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "one of video_id or video_url is required" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | Merkitys                                                 |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | Parametri puuttuu tai on virheellinen (esim. modea ei välitetty, video ja audio ovat ristiriidassa, kun vain toinen niistä tulee valita, text ylittää 120 merkkiä) |
| 401  | `authorization_missing` | API-avain puuttuu tai on virheellinen                                      |
| 403  | `forbidden`             | Sisältö on riskienhallinnan estämä                                            |
| 429  | `too_many_requests`     | Ylävirran samanaikaisuusrajoitus, yritä myöhemmin uudelleen                                       |
| 500  | `api_error`             | Ylävirran tai sisäinen virhe                                            |

## Huomioitavaa

- `video_id`-tunnuksen on oltava luotu **30 päivän sisällä** Kling-videolle, ja videon on oltava **5 s tai 10 s**; muussa tapauksessa välitä rajoitukset täyttävä video käyttämällä `video_url`-kenttää.
- Syöttövideoksi suositellaan **selkeää edestä kuvattua yhden henkilön** videota, sillä se tuottaa parhaan huulisynkronointituloksen.
- Äänen/tekstin keston tulee vastata videon kestoa (ääni ei saa ylittää videon pituutta).
- Veloitus tapahtuu **onnistumisen** yhteydessä (2,45 Credits/kerta); parametrien validointivirheistä (4xx) ei veloiteta.
