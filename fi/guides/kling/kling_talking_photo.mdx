---
title: "Kling-puhuva kuva API (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Muunna **yksi valokuva + yksi äänitiedosto** yhdellä napsautuksella ”puhuvaksi videoksi”. Palvelu suorittaa sisäisesti automaattisesti kaksi vaihetta: ensin se animoi valokuvan image2video-toiminnolla, sitten se synkronoi huulet äänen mukaan lip-sync-toiminnolla. Sinun tarvitsee kutsua sitä vain **kerran**.

- **Rajapinnan osoite**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Hinnoittelu**：keston mukaan, 5 sekuntia **16.45 Credits**、10 sekuntia **30.45 Credits**(= image2video + lip-sync yhdistetty hinta)

## Pyyntöotsikot

| Kenttä              | Arvo                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Pyyntöparametrit

| Parametri             | Tyyppi      | Pakollinen  | Oletus                  | Kuvaus                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Kyllä   | —                   | Henkilökuvan julkinen URL,selkeää kasvokuvaa suositellaan                    |
| `audio_url`    | string  | Kyllä   | —                   | Ohjaavan äänen julkinen URL（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | Ei   | —                   | Toiminto-/ilmeohje valokuvan animointivaiheeseen                      |
| `model`        | string  | Ei   | `kling-v2-1-master` | Valokuvan animointiin käytettävä Kling-malli                     |
| `duration`     | integer | Ei   | `5`                 | Videon kesto（5 tai 10 sekuntia）                        |
| `mode`         | string  | Ei   | `pro`               | Animaation laatu（std/pro）                        |
| `callback_url` | string  | Ei   | —                   | Jos annetaan tai `async=true`, palautetaan asynkronisesti task_id        |
| `async`        | boolean | Ei   | `false`             | Asynkroninen tila,käytä yhdessä `/kling/tasks`-kyselyn tai takaisinsoiton kanssa          |

## Pyyntöesimerkki

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Vastausesimerkki

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Kenttä                 | Kuvaus                        |
| ------------------ | ------------------------- |
| `video_url`        | Lopullinen puhuva video（tallennettu tälle alustan CDN:lle）      |
| `source_video_url` | Välimuotoinen valokuva-animaatiovideo（image2video-tulos） |
| `video_id`         | Kling-videon ID                   |

## Huomioitavaa

- Valokuvassa suositellaan selkeää kasvokuvaa ja yhtä henkilöä.
- Äänen keston suositellaan olevan enintään videon kesto (5 s/10 s).
- Laskutus tapahtuu onnistumisen yhteydessä; parametrien validoinnin epäonnistumisesta (4xx) ei laskuteta.
- Luonti kestää noin 4–6 minuuttia (kaksi vaihetta),suosittelemme käyttämään `async=true` + `/kling/tasks`-kyselyä.
