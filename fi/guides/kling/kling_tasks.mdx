Kling Tasks API:n päätoiminto on kysellä Kling Videos Generation API:n luoman tehtävätunnuksen avulla tehtävän suoritustilannetta.

Tässä dokumentissa esitellään yksityiskohtaisesti Kling Tasks API:n integrointiohjeet, jotta voit helposti integroida ja hyödyntää tämän API:n tehokkaita ominaisuuksia täysimääräisesti. Kling Tasks API:n avulla voit helposti toteuttaa Kling Videos Generation API:n tehtävien suoritustilanteen kyselyn.

## Hakuprosessi

Käyttääksesi Kling Videos Generation API:a hae ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Token -tunnuksesi ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Tämän jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voi kutsua kaikkia alustan palveluita, eikä jokaiselle palvelulle tarvitse hakea erikseen tunnusta.** Ensimmäisestä hakemuksesta myönnetään ilmaista käyttökiintiötä, joten palvelua voi kokeilla maksutta; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Kling Videos Generation API →](https://platform.acedata.cloud/documents/kling-videos)

## Pyyntöesimerkki

Kling Tasks API:a voidaan käyttää Kling Videos Generation API:n tulosten kyselyyn. Lisätietoja Kling Videos Generation API:n käytöstä saat dokumentaatiosta [Kling Videos Generation API ](https://platform.acedata.cloud/documents/kling-videos).

### Pyyntöotsikoiden ja pyyntötekstin määrittäminen

**Request Headers** sisältää:

- `accept`: määrittää JSON-muotoisen vastaustuloksen vastaanottamisen, tähän täytetään `application/json`.
- `authorization`: API:n kutsumisen avain, joka voidaan valita suoraan pudotusvalikosta hakemuksen jälkeen.

**Request Body** sisältää:

- `id`: ladatun tehtävän tunnus.
- `action`: tehtävän toimintatapa.

Asetukset ovat seuraavan kuvan mukaiset:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/kling/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/kling/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautustulos sisältää useita kenttiä. `request`-kenttä on tehtävää käynnistettäessä annettu request body, ja `response`-kenttä on tehtävän valmistumisen jälkeen palautettu response body. Kenttien kuvaukset ovat seuraavat.

- `id`, tämän videotehtävän luomisen ID, jota käytetään tämän videonluontitehtävän yksilölliseen tunnistamiseen.
- `request`, videotehtävän kyselyn pyyntötiedot.
- `response`, videotehtävän kyselyn palautustiedot.
- `created_at`, tehtävän luontiaika, Unix-aikaleima (sekunteina, liukuluku).
- `started_at`, tehtävän suorittamisen aloitusaika, Unix-aikaleima (sekunteina, liukuluku).
- `finished_at`, tehtävän valmistumisaika, Unix-aikaleima (sekunteina, liukuluku). Tätä kenttää ei palauteta, jos tehtävä ei ole valmis.
- `elapsed`, tehtävän suorituksen kesto sekunteina (liukuluku, 3 desimaalia). Tätä kenttää ei palauteta, jos tehtävä ei ole valmis.

## Virheenkäsittely

Kun API:a kutsuttaessa ilmenee virhe, API palauttaa vastaavan virhekoodin ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutusta, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jokin virhe.
