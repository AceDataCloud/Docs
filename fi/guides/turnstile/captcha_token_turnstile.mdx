Tässä artikkelissa esitellään Cloudflare Turnstile -protokollan tunnistus API -integraatio-ohje, joka mahdollistaa käyttäjille Turnstile-vahvistuskoodin tunnistamisen ja valitsemisen sijaan vain verkkosivuston avaimen lähettämisen, jolloin taustalla tapahtuu automaattinen purku ja vahvistus.

## Hakuprosessi

Käyttääksesi Cloudflare Turnstile -protokollan tunnistus API:a, sinun tulee ensin mennä [Ace Data Cloud -ohjauspaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit käyttää myöhemmin.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa voit rekisteröityä ja kirjautua sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; jos saldo on riittämätön, voit ladata yleistä saldoa [ohjauspaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Cloudflare Turnstile -protokollan tunnistus API →](https://platform.acedata.cloud/documents/captcha-token-turnstile)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka on syöttää käsiteltävän Turnstile-vahvistuskoodin verkkosivuston URL-osoite, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `website_url`-kenttä. Esimerkkisivustomme on: `https://react-turnstile.vercel.app`, ja meidän on saatava `website_key` `website_url`-sivulta. Avaa tämä verkkosivusto, paina F12 siirtyäksesi konsoliin, ja tee globaalihaku Element-sivulla `cf-turnstile`, jolloin löydät Turnstilen sisältävän säiliöelementin, jonka `data-sitekey`-arvo on `website_key`.

Asetetut pyyntöotsikot sisältävät:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi asetetaan pyyntökeho, joka sisältää:

- `website_url`: käsiteltävän vahvistuskoodin verkkosivuston URL-osoite.
- `website_key`: Cloudflare Turnstile -sivuston avaimen tunniste (sitekey).
- `action`: valinnainen parametri, joka on tarpeen vain, jos kohdesivustolla on Turnstile-komponentille asetettu mukautettu `action`.
- `cdata`: valinnainen parametri, joka on tarpeen vain, jos kohdesivustolla on Turnstile-komponentille asetettu mukautettu `cData`.

Napsauta "Try" -painiketta testataksesi, ja saamme seuraavan tuloksen:

```json
{
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......",
  "started_at": 1784885653.0,
  "finished_at": 1784885665.4,
  "elapsed": 12.4
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `token`, tämän Cloudflare Turnstile -vahvistuskooditehtävän käsittelyn tulos.
- `started_at`, `finished_at`: tämän pyynnön käsittelyn ja tuloksen tuottamisen ajankohdat, Unix-aikaleima (sekunnit, liukuluku).
- `elapsed`: tämän käsittelyn kokonaisaika (sekunnit).

Voimme nähdä, että olemme saaneet käsitellyn Turnstile-vahvistuskoodin tuloksen, jota voimme käyttää POST- tai simuloidussa lähetyksessä kohdesivustolle, kertakäyttöinen, voimassa 120 sekuntia, suositellaan käytettäväksi 60 sekunnin sisällä. Lähetyksessä token lähetetään yleensä `cf-turnstile-response`-parametrina kohdesivustolle, tokenin vahvistamiseen liittyvä Python-koodi on seuraava:

```python
import requests

token = '{token}'

data = {
    'cf-turnstile-response': token
}

response = requests.post('https://react-turnstile.vercel.app', data=data)

if response.status_code == 200:
    print(response.text)
```

Jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/turnstile' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
  "website_url": "https://react-turnstile.vercel.app"
}'
```

Pythonin integraatiokoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/turnstile"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
    "website_url": "https://react-turnstile.vercel.app"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynkroninen tila (async)

Oletusarvoisesti API on synkroninen ja estää: yksi pyyntö odottaa aina, kunnes tokenin käsittely on valmis. Jos teet useita koodinratkaisuja (multi-solver rotation) ja haluat "saada task_id:n heti tehtävän lähettämisen jälkeen, jotta voit ohjata muita koodinratkaisijoita ja palata myöhemmin tulosten lukemiseen", voit välittää pyyntökehossa `async: true`.

Kun välität `async: true`, rajapinta palauttaa heti `task_id:n`, eikä odota:

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Jos haluat tarkistaa edistymistä aktiivisesti, voit käyttää tätä `task_id:tä` kysyäksesi `POST /captcha/tasks` (suositellaan joka 3-5 sekunti). Tämä rajapinta ei laukaise tai edistä tehtävän käsittelyä; vaikka et kysyisi, katkaise verkkoyhteys tai sulje asiakasohjelma, palvelin jatkaa edelleen käsittelyä:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Käsittelyssä palautuu `status: processing`; käsittelyn valmistuttua palautuu `status: ready` ja token:

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......"
}
```

Laskutustiedot: asynkronisessa tilassa tehtävän luominen ja "käsittelyssä" -tilan lukeminen eivät aiheuta kustannuksia; **asiakasohjelman ensimmäisestä onnistuneesta tuloksen lukemisesta veloitetaan kerran** (sama käytäntö ja hinta kuin synkronisessa tilassa). Palvelin edistää tehtävää itsenäisesti, mutta ei veloita etukäteen, vaikka taustalla olisi valmis. Tehtävä, jota ei ole onnistuneesti käsitelty 120 sekunnin kuluessa, päättyy HTTP 504 `timeout` -tilaan, eikä siitä veloiteta. `/captcha/tasks` ei vastaa tehtävän edistämisestä.

> Huomautus: Cloudflare Turnstile ei tue omia välityspalvelimia (Bring Your Own Proxy), joten tämä rajapinta ei hyväksy `proxy`-parametria; jos se välitetään, palautuu `400 invalid_proxy`.

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:
- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 invalid_proxy`：Huono pyyntö, proxy ei ole tuettu tälle captcha-tyypille.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
