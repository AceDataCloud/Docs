Tässä artikkelissa esitellään hCaptcha kuvantunnistus API -integraatio-ohje, joka voi tunnistaa käyttäjän syöttämän sisällön ja hCaptcha vahvistuskuvan, ja lopuksi palauttaa klikkauksen tarvitsevan pienen kuvan koordinaatit, jotta vahvistus voidaan suorittaa.

## Hakuprosessi

Käyttääksesi hCaptcha kuvantunnistus API:ta, mene ensin [Ace Data Cloud -ohjauspaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, jota voit käyttää myöhemmin.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API-tunnus riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jota voit kokeilla ilmaiseksi; jos määrä loppuu, voit ladata yleistä saldoa [ohjauspaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [hCaptcha kuvantunnistus API →](https://platform.acedata.cloud/documents/recognition-hcaptcha-integration)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttää käsiteltävä hCaptcha vahvistuskuva, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `queries`-kenttä, joka on kyseinen hCaptcha vahvistuskuva. Meidän on otettava kuvakaappaus tästä vahvistuskuvasta verkkosivustolta, jossa on hCaptcha vahvistus, esimerkkisivuston linkki on: `https://democaptcha.com/demo-form-eng/hcaptcha.html`, napsauttamalla valintaruutua saat näkyviin täydellisen vahvistuskuvan, kuten alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/xryo59.png" width="500" className="m-auto" /></p>

`queries`-kenttä on yllä mainitun vahvistuskuvan kuvakaappaus, kuvan koon suositellaan olevan enintään 100 kt, ja sinun on myös otettava kuvakaappaus alueesta, johon punainen nuoli osoittaa, ja lisäksi sinun on itse pakattava kuvan koko ja muunnettava se Base64-koodaukseen, kuten alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/g8ikkb.png" width="500" className="m-auto" /></p>

Sinun on myös syötettävä vahvistuskuvaan liittyvä tunnistussisältöparametri `question`, joka tukee kiinan ja englannin käännöksiä, voit suoraan syöttää asiaankuuluvan tunnistussisällön. Yllä olevan verkkosivun kuvasta, jossa keltainen nuoli osoittaa, voidaan nähdä, että `question`-syötteen tulisi olla `Please click on the UNIQUE object among the others.`. Tarkka sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/empncr.png" width="500" className="m-auto" /></p>

Voimme nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi on asetettu pyyntökeho, joka sisältää:

- `queries`: Base64-koodattujen vahvistuskuvien lista.
- `question`: vahvistuskuvaan liittyvä tunnistussisältöparametri, joka tukee suoraa syöttämistä kiinaksi ja englanniksi.

Valinnan jälkeen voit huomata, että oikealle puolelle on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/bww9b0.png" width="500" className="m-auto" /></p>

Napsauttamalla "Try" -painiketta voit testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavanlaisen tuloksen:

```json
{
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": [
      "360",
      "276"
    ],
    "confidences": 0.6354503631591797
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `solution`, tämän hCaptcha vahvistuskuvan tehtävän käsittelyn jälkeen saatu vahvistustulos.
    - `label`, hCaptcha vahvistuskuvasta tunnistettu sisältö.
    - `box`, hCaptcha vahvistuskuvan tunnistustuloksen sijaintitiedot, jotka koostuvat kuvan koordinaattitiedoista.
    - `confidences`, hCaptcha vahvistuskuvan tunnistuksen jälkeen tunnistussisältöä vastaavan luottamustason.
- `started_at`, `finished_at`: tämän pyynnön käsittelyn ja tuloksen tuottamisen aikaleimat, Unix-aikaleimat (sekunnit, liukuluku).
- `elapsed`: tämän käsittelyn kokonaisaika (sekunnit).

Voimme nähdä, että olemme saaneet hCaptcha vahvistuskuvan käsittelyn vahvistustuloksen, ja meidän tarvitsee vain simuloida napsautusta vahvistuskuvan `box`-sijaintikoordinaattitietojen perusteella, jotta voimme läpäistä vahvistuksen.

Seuraavaksi esitellään, miten tuloksen `box`-sijaintitietojen perusteella voidaan napsauttaa. Ensinnäkin luodaan suorakulmainen koordinaatisto ladatulle vahvistuskuvalle, jossa keskipiste on kuvan vasemmassa alakulmassa, 360 vastaa vaaka-koordinaattia ja 276 pystysuoraa koordinaattia. Meidän tarvitsee vain simuloida napsautusta vahvistuskuvan vastaavissa koordinaateissa, kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/4ykvbl.png" width="500" className="m-auto" /></p>

Jos haluat luoda vastaavan integraatiokoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}'
```

Pythonin integraatiokoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "Please click on the UNIQUE object among the others.",
    "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynkroninen tila (async)

Oletusarvoisesti API on synkroninen ja estää: yksi pyyntö odottaa aina, kunnes tunnistustulos on käsitelty, ennen kuin se palauttaa. Jos teet useita ratkaisijoiden kiertoja (multi-solver rotation) ja haluat "saada task_id:n heti tehtävän lähettämisen jälkeen, jotta voit ensin ohjata muita ratkaisijoita ja palata myöhemmin lukemaan tuloksia", voit lisätä pyyntökehoon `async: true`.

Kun lisäät `async: true`, rajapinta palauttaa heti `task_id:n`, eikä estä odottamista:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"],
  "async": true
}'
```
```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Jos haluat tarkistaa edistystä aktiivisesti, voit käyttää tätä `task_id` kysyäksesi `POST /captcha/tasks` (suositellaan joka 3~5 sekunti). Tämä rajapinta ei laukaise tai edistä tehtävän käsittelyä; vaikka et kysyisi, katkaise verkkoyhteys tai sulje asiakasohjelma, palvelin jatkaa edelleen käsittelyä:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Käsittelyssä palautuu `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Käsittelyn valmistuttua palautuu `status: ready` ja tunnistus tulos `solution` (kenttä rakenne on täysin sama kuin synkronisessa tilassa):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": ["360", "276"],
    "confidences": 0.6354503631591797
  }
}
```

Laskutustiedot: Asynkronisessa tilassa, tehtävän luominen ja "käsittelyssä" tilan lukeminen eivät aiheuta laskutusta; **asiakasohjelma laskutetaan kerran, kun se lukee onnistuneen tuloksen ensimmäisen kerran** (saman käytännön ja synkronisen tilan hinnan mukaisesti). Palvelin edistää tehtävää itsenäisesti, mutta ei veloita etukäteen, vaikka taustalla olisi valmis. Tehtävä, jota ei ole onnistuttu suorittamaan 120 sekunnin sisällä, päättyy HTTP 504 `timeout` -tilaan, eikä siitä veloiteta. `/captcha/tasks` ei ole vastuussa tehtävän edistämisestä.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheen, API palauttaa vastaavan virhekoodin ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
