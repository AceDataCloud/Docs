Tässä artikkelissa esitellään hCaptcha kuvantunnistus API -liittymisohje, joka voi tunnistaa käyttäjän syöttämän sisällön ja hCaptcha vahvistuskuvan, ja lopuksi palauttaa tarvittavien klikkausten koordinaatit, jotta vahvistus voidaan suorittaa.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [hCaptcha kuvantunnistus API](https://platform.acedata.cloud/documents/c9a5cc2f-e410-425f-857a-f8700205da6c) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen sinut ohjataan automaattisesti takaisin nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttää käsiteltävä hCaptcha vahvistuskuva, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `queries`-kenttä, joka on kyseinen hCaptcha vahvistuskuva. Meidän on otettava kuvakaappaus tästä vahvistuskuvasta verkkosivustolta, jossa on hCaptcha vahvistus, esimerkkisivuston linkki on: `https://democaptcha.com/demo-form-eng/hcaptcha.html`, napsauttamalla valintaruutua saat näkyviin täydellisen vahvistuskuvan, kuten alla olevassa kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/xryo59.png" width="500" className="m-auto" /></p>

`queries`-kenttä on yllä mainitun vahvistuskuvan kuvakaappaus, kuvan koon suositellaan olevan enintään 100 kt. Sinun on myös otettava kuvakaappaus alueesta, johon punainen nuoli osoittaa, ja sinun on itse pakattava kuvan koko ja muunnettava se Base64-koodaukseen, kuten alla olevassa kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/g8ikkb.png" width="500" className="m-auto" /></p>

Lisäksi sinun on syötettävä vahvistuskuvaan liittyvä tunnistussisältöparametri `question`, joka tukee käännöksiä kiinasta ja englannista. Voit suoraan syöttää asiaankuuluvan tunnistussisällön, ja yllä olevan verkkosivun kuvasta keltaisen nuolen osoittama sisältö osoittaa, että `question`-syötteen tulisi olla `Please click on the UNIQUE object among the others.`. Tarkka sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/empncr.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers -otsikon, joka sisältää:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, joka sisältää:

- `queries`: Base64-koodattu vahvistuskuvalista.
- `question`: vahvistuskuvaan liittyvä tunnistussisältöparametri, joka tukee suoraa syöttämistä kiinaksi ja englanniksi.

Valinnan jälkeen voit huomata, että oikealle puolelle on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/bww9b0.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavanlaisen tuloksen:

```json
{
  "solution": {
    "label": "Please click on the UNIQUE object among the others",
    "box": [
      "360",
      "276"
    ],
    "confidences": 0.6354503631591797
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `solution`, tämän hCaptcha vahvistuskuvan tehtävän käsittelyn jälkeen saatu vahvistustulos.
  - `label`, hCaptcha vahvistuskuvasta tunnistettu sisältö.
  - `box`, hCaptcha vahvistuskuvan tunnistustuloksen sijaintitiedot, jotka koostuvat kuvan koordinaattitiedoista.
  - `confidences`, hCaptcha vahvistuskuvan tunnistuksen jälkeen tunnistussisällön varmuusaste.

Voit nähdä, että olemme saaneet käsitellyn hCaptcha vahvistuskuvan vahvistustuloksen, ja meidän tarvitsee vain simuloida klikkausta vahvistuskuvan `box`-sijaintikoordinaattitietojen perusteella, jotta vahvistus voidaan hyväksyä.

Seuraavaksi esitellään, kuinka klikata tuloksen `box`-sijaintitietojen perusteella. Ensinnäkin luodaan suorakulmainen koordinaatisto ladatulle vahvistuskuvalle, jossa keskipiste on kuvan vasemmassa alakulmassa. 360 vastaa vaaka-koordinaattia ja 276 pystysuoraa koordinaattia. Meidän tarvitsee vain simuloida klikkausta vahvistuskuvan vastaavissa koordinaateissa, kuten alla olevassa kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/4ykvbl.png" width="500" className="m-auto" /></p>

Jos haluat luoda vastaavan liittymiskoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/hcaptcha' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "question": "Please click on the UNIQUE object among the others.",
  "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}'
}'
```

Pythonin liittymiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/hcaptcha"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "question": "Please click on the UNIQUE object among the others.",
    "queries": ["iVBORw0KGgoAAAANSU.....eY+85KVlzKHav28uq/WLVhL2kHUlFMKUcZbL31S8bpd0pEPKxNllXAE2wgu3uEfj+BfAzOGelsQNFAAAAAElFTkSuQmCC"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
