HappyHorse Tasks API:tä käytetään HappyHorse Videos API:n luomien videoiden generointi- tai muokkaustehtävien kyselyyn.

## Hakuprosessi

Käyttääksesi HappyHorse Videos API:a, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jota voit kokeilla ilmaiseksi; kun saldo on vähissä, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Pyyntöesimerkki

HappyHorse Tasks API:ta voidaan käyttää HappyHorse Videos API:n tulosten kyselyyn.

### Pyyntöotsikon ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tähän täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

**Pyyntökeho** sisältää:

- `id`: kyseltävän tehtävän ID.
- `action`: tehtävälle suoritettava toiminto, yksittäisessä kyselyssä täytetään `retrieve`.

### CURL-koodiesimerkki

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa kyseisen tehtävän tiedot. `request`-kenttä on tehtävän luomisen yhteydessä käytetty pyyntökeho, ja `response`-kenttä on tehtävän valmistuttua palautettu vastauskeho, esimerkiksi:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic shot of a white horse running across a moonlit beach",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Kenttien esittely on seuraava:

- `id`: generointitehtävän ID, jota käytetään tämän generointitehtävän yksilöimiseen.
- `request`: tehtävän luomisen yhteydessä käytetyt pyyntö tiedot.
- `response`: tehtävän nykyiset tai lopulliset palautustiedot.
- `created_at`: tehtävän luomisaika, Unix-aikaleima (sekunnit, liukuluku).
- `started_at`: tehtävän aloitusaika, Unix-aikaleima (sekunnit, liukuluku).
- `finished_at`: tehtävän valmistumisaika, Unix-aikaleima (sekunnit, liukuluku). Jos tehtävä ei ole valmis, tätä kenttää ei palauteta.
- `elapsed`: tehtävän suorittamiseen kulunut aika, yksikkönä sekunnit (liukuluku, 3 desimaalia). Jos tehtävä ei ole valmis, tätä kenttää ei palauteta.

## Erätiedustelutoiminto

Useiden tehtävä-ID:iden kyselyssä asetetaan `action` arvoksi `retrieve_batch` ja siirretään `ids`-kentässä tehtävä-ID-taulukko:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

Palautetussa tuloksessa on `items` ja `count` kentät, `items` on tehtävän yksityiskohtien taulukko ja `count` on tämän kerran osuneiden tehtävien määrä.
