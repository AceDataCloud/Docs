Tässä artikkelissa esitellään HappyHorse Videos API:n integrointitapa. Tämä rajapinta tukee teksti-videoksi-muunnosta, aloituskuva-videoksi-muunnosta, viitekuva-videoksi-muunnosta ja videoeditointia yhtenäisen `/happyhorse/videos`-päätepisteen ja `action`-parametrin kautta.

## Hakuprosessi

HappyHorse Videos API:n käyttämiseksi hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita ilman, että jokaiselle palvelulle tarvitsee hakea erikseen.** Ensimmäinen hakemus sisältää ilmaista käyttöhyvitystä, joten voit kokeilla palvelua maksutta; kun hyvitys ei riitä, voit lisätä yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Toimintotyypit

`action` määrittää tämän pyynnön luontitilan:

- `generate`: teksti-videoksi, oletustoiminto, tukee malleja `happyhorse-1.0-t2v` ja `happyhorse-1.1-t2v`, ja `prompt` on pakollinen.
- `image_to_video`: aloituskuva-videoksi, tukee malleja `happyhorse-1.0-i2v` ja `happyhorse-1.1-i2v`, ja `image_url` on pakollinen.
- `reference_to_video`: viitekuva-videoksi, tukee malleja `happyhorse-1.0-r2v` ja `happyhorse-1.1-r2v`, ja `prompt` sekä 1–9 `image_urls`-kuvaa ovat pakollisia.
- `video_edit`: videoeditointi, tukee mallia `happyhorse-1.0-video-edit`, ja `prompt` sekä `video_url` ovat pakollisia; lisäksi voidaan antaa 0–5 viitekuvaa `image_urls`.

Kukin toiminto käyttää oletuksena 1.1-mallia; `video_edit` tarjoaa tällä hetkellä vain mallin `happyhorse-1.0-video-edit`.

## Peruskäyttö

Teksti-videoksi-muunnos edellyttää vain `prompt`-parametrin antamista, ja myös parametreja `resolution`, `ratio`, `duration` jne. voidaan määrittää:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

Palautusesimerkki on seuraava:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

Kenttien kuvaukset:

- `success`: onnistuiko tämä pyyntö.
- `task_id`: tehtävätunnus Ace Data Cloudin puolella, jota voidaan käyttää tehtävän tilan kyselyyn.
- `trace_id`: tämän pyynnön seuranta-ID, jota käytetään ongelmien selvittämiseen.
- `data`: videoiden tulosluettelo.
  - `id`: tehtävätunnus HappyHorse-puolella.
  - `video_url`: luodun videon CDN-linkkiosoite.
  - `state`: tehtävän tila, mahdolliset arvot `pending` / `succeeded` / `error`.
  - `duration`: laskutettavan videon kesto sekunteina; `video_edit`-toiminnossa syöte- ja tulosvideon kokonaiskesto.
  - `resolution`: tulostarkkuus.
  - `ratio`: tulosteen kuvasuhde.

Vastaava CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Aloituskuva-videoksi

Kun käytetään `image_to_video`-toimintoa, `image_url` toimii videon aloituskuvana. Tulosteen kuvasuhde seuraa mahdollisimman tarkasti aloituskuvaa, joten tässä toiminnossa ei tarvitse antaa `ratio`-parametria.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## Viitekuva-videoksi

Kun käytetään `reference_to_video`-toimintoa, `image_urls` voi sisältää 1–9 viitekuvaa. Kehotteessa voidaan viitata vastaavassa järjestyksessä oleviin kuviin esimerkiksi nimillä `character1`, `character2` jne.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## Videoeditointi

Kun käytetään `video_edit`-toimintoa, on annettava muokattava video `video_url` ja muokkaustarkoitus `prompt`. Valinnaiset `image_urls` toimivat viitekuvina, esimerkiksi asun vaihtoon, tyylinsiirtoon tai osittaiseen korvaamiseen. `audio_setting` voi olla `auto` tai `origin`, joista `origin` tarkoittaa alkuperäisen videon äänen säilyttämistä.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://cdn.acedata.cloud/assets/examples/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1-2c108ce23554.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## Asynkroninen takaisinsoitto
Videon luominen vaatii tietyn käsittelyajan. Jos et halua pitää pitkää yhteyttä odottamassa, voit välittää `callback_url`-parametrin, jolloin API palauttaa välittömästi `task_id`:n, ja tehtävän valmistuttua lopullinen tulos lähetetään POST-pyynnöllä tähän osoitteeseen:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

Välittömästi palautettava tulos on seuraava:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

Jos haluat vain kysellä tilaa etkä tarvitse takaisinsoittoa, voit myös välittää `"async": true`-parametrin ja kysellä sitten tehtävän tulosta [HappyHorse Tasks API:n](https://platform.acedata.cloud/documents/happyhorse-tasks) kautta.

## Laskutuksen kuvaus

HappyHorse laskuttaa tuotetun videon sekuntimäärän ja resoluution mukaan:

- `720P`: alkaen noin $0.105 / sekunti.
- `1080P`: alkaen noin $0.18 / sekunti.
- `video_edit`: laskutetaan syötevideon ja tulostevideon yhteenlasketun keston mukaan; todellinen laskutettava kesto määräytyy tehtävän valmistumisen jälkeisten tilastojen perusteella.

Epäonnistuneista tehtävistä ei laskuteta, eivätkä ne kuluta ilmaista kiintiötä.

## Virheenkäsittely

Kun pyynnössä ilmenee ongelma, API palauttaa vastaavan virhekoodin ja kuvauksen. Yleisiä ovat seuraavat:

- `400`: pyyntöparametreissa on virhe, esimerkiksi action ja model eivät vastaa toisiaan, `prompt` / `image_url` / `video_url` puuttuu tai `duration` ylittää 3–15 sekunnin rajan.
- `401`: todennus epäonnistui, token on virheellinen tai ei vastaa API:a.
- `403`: saldo ei riitä tai kehote on hylätty sisällöntarkastuksen osuman vuoksi.
- `429`: pyyntöjä on liian usein, nopeusrajoitus on aktivoitunut, yritä myöhemmin uudelleen.
- `500`: palvelimen sisäinen virhe tai luominen epäonnistui.
