`POST https://api.acedata.cloud/webextrator/extract`

WebExtrator-älypoiminta-API muuntaa URL-osoitteen **tyypitetyksi, jäsennellyksi tulokseksi** — artikkeleiksi, tuotteiksi,
resepteiksi, videoiksi, keskusteluiksi, työpaikkailmoituksiksi ja muuksi — sekä sisältää puhdistetun Markdownin ja pelkän tekstin. Käytä tätä rajapintaa, kun haluat "puhdasta, jäsenneltyä dataa" raakan HTML:n sijaan.

## Hakuprosessi

WebExtrator-palvelun käyttämiseksi mene ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications) ja hae API Token, pidä se tallessa.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan, jonka jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voit kutsua kaikkia alustan palveluita, ei tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisellä haulla saat ilmaisen käyttöoikeuden kokeiluun; kun saldo loppuu, voit ladata yleistä saldoa [konsolista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [WebExtrator palvelu →](https://platform.acedata.cloud/service/webextrator)

## Todennus

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Pyyntöparametrit

Extract hyväksyy **kaikki** [Render API](/fi/guides/webextrator/webextrator_render) -parametrit
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`），sekä kaksi vain Extractille tarkoitettua kenttää:

| Kenttä | Tyyppi | Pakollinen | Oletus | Kuvaus |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Automaattinen tunnistus | Sivutyypin vihje: `product` / `article` / `general`. Määrittää odotetun tulostyypin. |
| `enable_llm` | boolean | ❌ | `false` | Sallii LLM-poiminnan käytön, kun schema.org ei täsmää. Tämä on otettava käyttöön Amazonin / HN:n / Greenhousen kaltaisilla sivuilla, joilla ei ole JSON-LD:tä, jotta tyyppimääritettyjä tuloksia voidaan saada. |

### Ylimmän tason kentät

| Kenttä | Tyyppi | Kuvaus |
|------|------|------|
| `kind` | string | Kiinteä `"extract"`. |
| `url` | string | Lähettämäsi URL-osoite. |
| `finalUrl` | string | Uudelleenohjauksen jälkeinen lopullinen URL-osoite. |
| `contentType` | enum | Sivutyyppi: `product` / `article` / `general`. |
| `title` | string | Sivun otsikko. |
| `description` | string? | Sivun kuvaus tai tiivistelmä. |
| `byline` | string? | Kirjoittaja, kanava tai yritys. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Julkaisuaika ISO 8601 -muodossa. |
| `images` | string[] | Enintään 50 `<img src />`-kohdetta, jotka on jäsennetty absoluuttisiksi URL-osoitteiksi, joista kaksoiskappaleet on poistettu ja `data:`-URI:t hylätty. |
| `links` | string[] | Enintään 100 ulkoista linkkiä. Fragmentit / `javascript:` / `mailto:` / `tel:` on suodatettu pois. |
| `markdown` | string | Sivun Markdown-sisältö. |
| `text` | string | Sivun pelkkä teksti. |
| `structured` | object | Täydellinen jäsennelty tulos, katso alla. |
| `rawSignals` | object | Vianmääritystiedot. |
| `cached` | boolean? | Välimuistiosuman yhteydessä `true`. |
| `cacheStoredAt` | number? | Välimuistimerkinnän ensimmäisen kirjoituksen Unix-aikaleima millisekunteina. |

### `data.structured`-alikentät

| Alikenttä | Milloin esiintyy | Kuvaus |
|--------|---------|------|
| `schemaOrg` | Aina | `{ primary, breadcrumbs, all }`. `primary` on korkeimman prioriteetin tyypitetty entiteetti; jos sitä ei löydy, käytetään `null`. |
| `openGraph` | Aina | `{ title, description, image, type }`, peräisin kohteesta `<meta property="og:*" />`. |
| `jsonLd` | Aina | Kaikkien `<script type="application/ld+json">`-lohkojen raaka JSON-taulukko. |
| `llm` | Kun LLM suoritettiin ja se onnistui | `{ kind, data, model, promptCharCount }`, tyypitetty tulos. |
| `llmError` | Kun LLM suoritettiin, mutta se epäonnistui | `{ kind, error, model }`, pyyntö voi silti palauttaa muita poimittuja kenttiä. |
| `amazon` | Kun URL on `amazon.*` | Vanhan Amazon-laajennuksen tulos; käytä uusissa integraatioissa tyypitettyjä tuloksia. |

## schema.org-tulostyypit

`structured.schemaOrg.primary` tukee seuraavia tulostyyppejä:

| schema.org-tyyppi | kind | Tulostuskentät |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (mukaan lukien `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (liitetään sisarobjektiin) | Tulostetaan aina kohteeseen `structured.schemaOrg.breadcrumbs[]`, ei koskaan ensisijaisena. |

## LLM-tulostyypit

Kun `enable_llm: true` ja sivulla ei ole käytettävissä schema.org-jäsenneltyä dataa, voidaan palauttaa seuraavantyyppisiä poimintatuloksia:

| Kind | Pakolliset kentät | Valinnaiset kentät |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Välimuisti

Sama URL, pyyntöparametrit, `cookies` ja `headers` voivat käyttää välimuistissa olevaa tulosta uudelleen; `async`-, `bypass_cache`- ja `cache_ttl_seconds`-arvoja käytetään suoritus- ja välimuistikäyttäytymisen hallintaan.

| Kenttä | Vaikutus |
|------|------|
| `bypass_cache: true` | Ohita lukeminen; tämän kerran tulos kirjoitetaan silti välimuistiin, joten seuraava sama pyyntö voi osua välimuistiin. |
| `cache_ttl_seconds: 0` | Tämän kerran vastausta **ei tallenneta välimuistiin**. |
| `cache_ttl_seconds: N` | Määritä tälle merkinnälle oma TTL (oletus 3600 sekuntia). |

Välimuistiin osuneissa vastauksissa on `data.cached: true` ja `data.cacheStoredAt: <unix-ms>`.

## Asynkroninen tila ja palautus

Aseta `async: true` siirtyäksesi asynkroniseen tilaan (tarjoamalla `callback_url` siirrytään myös automaattisesti). Alusta palauttaa heti (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

Tehtävän valmistuttua koko envelope `POST` lähetetään sinun `callback_url` (jos on määritetty). Voit myös jälkikäteen kysyä aktiivisesti [`/webextrator/tasks`](/fi/guides/webextrator/webextrator_tasks).

## Esimerkki

### 1. Wikipedia-artikkeli (schema.org osuu, ei tarvitse LLM)

```bash

  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://en.wikipedia.org/wiki/Diffbot",
    "expected_type": "article"
  }'

  "author": { "name": "Wikimedia-projektien osallistujat", "type": "Organisaatio" },
  "publisher": { "name": "Wikimedia Foundation, Inc." }
}
```

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "artikkeli",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "artikkeli":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'aineksia');
```

## Vinkit ja sudenkuopat

- **Anna `expected_type`, kun sivutyyppi on määritettävä.** Käytä esimerkiksi artikkelisivulle `article` ja tuotesivulle `product`.
- **`enable_llm: true` on maksuton sivuilla, joilla on osuma schema.org:ssa.** LLM:ää kutsutaan vain, kun schema.org:ssa
  ei ole primary-arvoa, joten sen pitäminen oletuksena käytössä on turvallista.
- **Tarkista vianmäärityksessä ensin `rawSignals.hasJsonLd`.** Jos se on `true` mutta `structured.schemaOrg.primary`
  on `null`, sivun `@type` ei ole vielä tuettu. Voit antaa meille palautetta.
- **`structured.llmError` on vain informatiivinen.** Pyyntö voi silti palauttaa onnistuneesti muita poimittuja kenttiä. Tarkista
  `llmError.error` syyn selvittämiseksi (aikakatkaisu, JSON-jäsennysvirhe, rakenteen validointivirhe).
- **Muiden kuin artikkelisivujen `links[]` ei tee relevanssijärjestystä.** Se puhdistaa parhaansa mukaan vain "enintään 100 kohdetta + virheellisten protokollien suodatus" -periaatteella.
  parhaansa mukaan.
- **Myös välimuistiosumista veloitetaan.**
