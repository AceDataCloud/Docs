`POST https://api.acedata.cloud/webextrator/extract`

Sisällön poiminta perustuen `/webextrator/render` -rajapintaan. Kaikkien render-rajapinnan parametrien lisäksi tuetaan:

| Kenttä | Tyyppi | Pakollinen | Oletus | Kuvaus |
|--------|--------|:----------:|--------|--------|
| `expected_type` | string | ❌ | `markdown` | Odotettu poiminnan tulos: `markdown` / `article` / `text` / `links` / `structured` |
| `enable_llm` | boolean | ❌ | false | LLM-jälkikäsittelyn käyttöönottaminen (sopii `article` / `structured`) |
| `instruction` | string | ❌ | - | LLM-poimintaohje, esim. "poimi tuotteen otsikko, hinta, tekniset tiedot" |

## Synkroninen vastaus

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "550e8400-...",
  "started_at": "2026-05-02T10:30:00.123Z",
  "finished_at": "2026-05-02T10:30:08.789Z",
  "elapsed": 8.666,
  "data": {
    "kind": "extract",
    "expected_type": "article",
    "url": "https://example.com/post/1",
    "title": "示例文章",
    "author": "张三",
    "published_at": "2026-05-01",
    "content": "# 示例文章\n\n正文 ...",
    "summary": "本文介绍 ..."
  }
}
```

Asynkroninen tila, virhekoodit ja hinnoittelusäännöt ovat täysin samat kuin `/webextrator/render` -rajapinnassa.

## Esimerkki: artikkelin tekstin poiminta (LLM käytössä)

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com/news/1",
    "expected_type": "article",
    "enable_llm": true
  }'
```

## Esimerkki: asynkroninen + mukautettu rakenteinen poiminta

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shop.example.com/item/123",
    "expected_type": "structured",
    "enable_llm": true,
    "instruction": "poimi tuotteen otsikko, hinta, varastosaldo, 3 pääkuvan URL-osoitetta",
    "callback_url": "https://your-domain.com/wbx-callback"
  }'
```
