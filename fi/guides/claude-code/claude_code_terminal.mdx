## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten lista](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Asennuksen jälkeen tarkista:

```bash
claude --version
```

## 3. Konfiguroi Ace Data Cloud

Globaalissa käytössä lisää seuraavat muuttujat `~/.zshrc` tai `~/.bashrc`:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="oma API-avain"
unset ANTHROPIC_API_KEY
```

Avaa terminaali uudelleen tai käytä `source` vastaavaa konfigurointitiedostoa.

Jos haluat, että se vaikuttaa vain nykyiseen projektiin, voit luoda `.claude/settings.local.json`, joka on lisätty `.gitignore`-tiedostoon:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "oma API-avain"
  }
}
```

Valitse jompikumpi tapa. Älä kirjoita oikeaa avainta tiimisi jaettuun `.claude/settings.json`-tiedostoon; jos ympäristössä on jo `ANTHROPIC_API_KEY`, se tulisi todella poistaa, eikä asettaa tyhjäksi merkkijonoksi.

## 4. Käynnistä ja vahvista

```bash
cd /path/to/your/project
claude
```

Siirry sisään ja lähetä vain luku -tehtävä, kuten "Lue README.md ja tiivistä se yhdellä lauseella". Kutsuhistoria ja saldo voidaan tarkistaa [käyttöhistoriasta](https://platform.acedata.cloud/console/usages) ja [sovellusten listasta](https://platform.acedata.cloud/console/applications).

Jos saat takaisin 401, tarkista, onko avain täydellinen, onko vanha `ANTHROPIC_API_KEY` poistettu ja käynnistä Claude Code kokonaan uudelleen. Mallia ei tarvitse kiinnittää liitännäiskonfiguraatioon, voit valita nykyisen käytettävissä olevan mallin Claude Codessa.
