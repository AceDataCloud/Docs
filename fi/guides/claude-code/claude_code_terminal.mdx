Claude Code on Anthropicin julkaisema **Agentic Coding** -työkalu, jota kutsutaan myös yhdeksi maailman vahvimmista ohjelmointiaineksista. Termin CLI on Claude Coden ydinkokemus, voit suorittaa `claude`-komennon missä tahansa terminaalissa ja tehdä ohjelmointiyhteistyötä AI:n kanssa luonnollisella kielellä.

Tässä asiakirjassa esitellään, kuinka asentaa, konfiguroida ja käyttää Claude Code CLI:tä AceData Cloudin välityspalvelun kautta terminaalissa.

## Hakuprosessi

Käyttääksesi Claude Codea, voit ensin siirtyä [Claude Messages -palvelusivulle](https://platform.acedata.cloud/documents/claude-messages) ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemuskerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Claude Code -palvelua ilmaiseksi.

## Claude Coden asentaminen

### Järjestelmävaatimukset

- macOS, Linux tai Windows (mukaan lukien WSL)
- Node.js ei ole pakollinen, alkuperäinen asennustapa käsittelee riippuvuudet automaattisesti

### Asennustavat

Claude Code tukee useita asennustapoja:

**Tapa 1: Alkuperäinen asennus (suositeltava)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Tapa 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Tapa 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Alkuperäinen asennus päivittää automaattisesti taustalla ja pitää aina uusimman version.

## AceData Cloud API:n konfigurointi

Asennuksen jälkeen sinua pyydetään kirjautumaan Anthropicin viralliselle tilille. Voimme käyttää AceData Cloudin välityspalvelua konfiguroimalla ympäristömuuttujat, **ilman virallista tilausta**.

### Ympäristömuuttujien konfigurointi

Ympäristömuuttujat voidaan konfiguroida kahdella tavalla, valitse kumpi tahansa.

**Tapa 1: Aseta Shell-konfiguraatiotiedostoon (suositeltava)**

Lisää seuraava sisältö Shell-konfiguraatiotiedostoosi (`~/.zshrc`, `~/.bashrc` tai `~/.bash_profile`), vaihda `{token}` AceData Cloud -hallintapaneelista saamasi API-tunnuksen mukaan:

```bash
# AceData Cloud - Claude Code -välityskonfiguraatio
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Suorita seuraava komento, jotta muutokset tulevat voimaan:

```bash
source ~/.zshrc  # tai source ~/.bashrc
```

**Tapa 2: Aseta Claude Code settings.json -tiedostoon**

Muokkaa `~/.claude/settings.json` (jos ei ole olemassa, luo se) ja lisää `env`-konfiguraatio:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Tämän menetelmän etuna on, että ympäristömuuttujat vaikuttavat vain Claude Codeen, eivätkä vaikuta muihin ohjelmiin.

> **Vihje**: API-tunnus voidaan tarkistaa [AceData Cloud -hallintapaneelista](https://platform.acedata.cloud/console). `ANTHROPIC_AUTH_TOKEN` -arvoon lisätään automaattisesti `Bearer`-etuliite, joka lähetetään palvelimelle.

## Aloita käyttö

### Käynnistä vuorovaikutustila

Avaa terminaali, siirry projektikansioosi ja suorita:

```bash
cd /path/to/your/project
claude
```

Näet Claude Coden tervetulonäytön, voit aloittaa vuorovaikutuksen kirjoittamalla luonnollista kieltä.

### Yleiset komennot

| Komento               | Selitys          | Esimerkki                   |
| ------------------- | ------------- | -------------------- |
| `claude`            | Käynnistä vuorovaikutustila      | `claude`             |
| `claude "tehtävä"`    | Suorita kertaluonteinen tehtävä     | `claude "korjaa rakennusvirhe"`    |
| `claude -p "kysely"` | Suorita kysely ja poistu     | `claude -p "selitä tämä funktio"` |
| `claude -c`         | Jatka nykyisen kansion viimeisintä keskustelua | `claude -c`          |
| `claude -r`         | Palauta aiempi keskustelu     | `claude -r`          |
| `claude commit`     | Luo Git-commit   | `claude commit`      |

### Vuorovaikutustilan komennot

Vuorovaikutustilassa voit käyttää seuraavia sisäänrakennettuja komentoja:

| Komento                | Toiminto        |
| --------------------- | ------------- |
| `/help`               | Näytä ohjeet    |
| `/clear`              | Tyhjennä keskusteluhistoria    |
| `/config`             | Avaa asetuspaneeli    |
| `/model`              | Vaihda mallia      |
| `/mcp`                | Hallitse MCP-palvelua |
| `/compact`            | Tiivistä konteksti     |
| `/memory`             | Hallitse muistia      |
| `/login`              | Vaihda tiliä      |
| `exit` tai `Ctrl+C`  | Poistu        |

### Vuorovaikutusesimerkkejä

```bash
# Analysoi projekti
> mitä tämä projekti tekee?

# Korjaa bugi
> on virhe, jossa käyttäjät voivat lähettää tyhjiä lomakkeita - korjaa se

# Kirjoita testejä
> kirjoita yksikkötestit laskinfunktioille

# Refaktoroi koodi
> refaktoroi todennusmoduuli käyttämään async/await

# Git-toiminnot
> tee commit muutoksilleni kuvaavalla viestillä
> luo pr tälle ominaisuudelle
```

## Edistyneet käyttötavat

### Putket ja skriptit

Claude Code noudattaa Unix-filosofiaa ja tukee putkia ja skriptitoimintoja:

```bash
# Seuraa lokia ja hälytä automaattisesti
tail -f app.log | claude -p "ilmoita minulle, jos löydät poikkeavuuksia"

# Käännä uudet tekstit automaattisesti
claude -p "käännä uudet tekstimerkit ranskaksi ja luo PR"

# Koodikatsaus
git diff main | claude -p "tarkista nämä muutokset"
```

### Ympäristömuuttujat

Seuraavat ovat Claude Coden tukemia yleisiä ympäristömuuttujia:

| Muuttuja                           | Selitys                                    |
| -------------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`           | Mukautetun Authorization-päätteen arvo (automaattisesti lisätään Bearer-etuliite) |
| `ANTHROPIC_API_KEY`              | API-avain (lähetetään X-Api-Key -päätteenä)              |
| `ANTHROPIC_BASE_URL`             | API:n perus-URL                            |
| `ANTHROPIC_MODEL`                | Korvataan oletusmalli                                |
| `ANTHROPIC_SMALL_FAST_MODEL`     | Haiku-tason malli (taustatehtäviin)                     |
| `MAX_THINKING_TOKENS`            | Aseta ajattelutoken-budjetti (aseta 0 poistaaksesi ajattelutilan)            |
| `DISABLE_COST_WARNINGS`          | Aseta 1 poistaaksesi kustannusvaroitukset                           |

### CLAUDE.md -projektimuisti

Luo projektin juurihakemistoon `CLAUDE.md` -tiedosto, johon voit antaa Claude Code -ohjelmalle projektikohtaisia ohjeita ja konteksteja. Claude lataa tämän tiedoston automaattisesti käynnistyessään.

```markdown
# Projektin kuvaus
Tämä on Django + Vue.js -kokonaisprojekti.

## Koodausstandardit
- Käytä Python 3.12
- Noudata PEP 8 -koodityyliä
- Kaikkien API:en on kirjoitettava yksikkötestit
```

## Usein kysytyt kysymykset

### Mitä tehdä, jos yhteys epäonnistuu?
1. Tarkista, onko `~/.claude/config.json` -tiedosto luotu oikein, ja sen sisältö on `{"primaryApiKey": "self"}`
2. Varmista, että ympäristömuuttujat on asetettu oikein:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Varmista, että API-tunnus on voimassa (voit tarkistaa sen [ohjauspaneelista](https://platform.acedata.cloud/console))
4. Yritä käynnistää terminaali uudelleen

### komento ei löytynyt: claude

Jos asennuksen jälkeen saat ilmoituksen `komento ei löytynyt`, yritä:

1. Sulje ja avaa terminaali uudelleen
2. Tarkista PATH: `echo $PATH`
3. Asenna uudelleen: `curl -fsSL https://claude.ai/install.sh | bash`

### Kuinka tarkistaa jäljellä oleva saldo?

Kirjaudu sisään [AceData Cloud -ohjauspaneeliin](https://platform.acedata.cloud/console), niin voit tarkistaa nykyisen tilisi jäljellä olevan saldon ja käyttötilanteen.
