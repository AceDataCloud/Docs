## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten luettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna CC Switch

Lataa [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), macOS:lläkin voi käyttää:

```bash
brew install --cask cc-switch
```

## 3. Lisää Provider

Avaa CC Switch, valitse **Claude Code → Add Provider → Custom**, täytä:

| Kenttä      | Arvo                          |
| ----------- | ----------------------------- |
| Nimi        | `Ace Data Cloud`             |
| Perus-URL   | `https://api.acedata.cloud`  |
| API-avain   | äsken kopioitu API-avain      |
| API-muoto   | `Anthropic Messages`         |

Jos haluat käyttää JSON-editoria, konfiguroi seuraavasti:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch kirjoittaa konfiguraation Claude Code -käyttäjäasetuksiin. Älä tallenna oikeaa avainta tiimivarastoon, äläkä pidä vanhaa `ANTHROPIC_API_KEY`-avainta samanaikaisesti.

## 4. Ota käyttöön ja vahvista

Tallenna ja ota käyttöön **Ace Data Cloud**, avaa Claude Code uudelleen. Lähetä yksinkertainen vain luku -tehtävä ja tarkista kutsu [käyttöhistoriasta](https://platform.acedata.cloud/console/usages). Jos vaihdon jälkeen käytetään edelleen vanhaa konfiguraatiota, sulje täysin Claude Code ja CC Switch ja yritä uudelleen.
