## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten luettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

Luo kohde GitHub-repositorion **Asetukset → Salaisuudet ja muuttujat → Toiminnot** uusi Salaisuus:

```text
ACEDATACLOUD_API_KEY
```

## 2. Asenna GitHub-sovellus

Asenna [Claude GitHub -sovellus](https://github.com/apps/claude) ja myönnä käyttöoikeudet kohde-repositoriolle. Tämä virallinen sovellus pyytää kiinteää täydellistä käyttöoikeusjoukkoa; Claude Code Action käyttää todellisuudessa Contents-, Issues- ja Pull requests -oikeuksia, GitHubin asennussivulla ei voi valita vain näitä kolmea. Jos organisaatio vaatii vähimmäiskäyttöoikeuksia, luo mukautettu GitHub-sovellus virallisten asiakirjojen mukaan.

## 3. Lisää Workflow

Luo `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` tarvitsee ei-tyhjää `anthropic_api_key` syötettä; tässä oleva paikkamerkki ei tule käytettäväksi alustan todennuksessa. `ANTHROPIC_CUSTOM_HEADERS` korvataan Ace Data Cloudin vaatimalla Bearer Headerilla, todellinen avain tulee vain GitHub Salaisuudesta.

## 4. Vahvista

Lähetä Workflow'n jälkeen Issue- tai PR-kommenttiin:

```text
@claude Reply only OK
```

Onnistuneesti Actions workflow valmistuu ja päivittää tulokset vastaavaan Issue/PR:ään. Jos Action ilmoittaa puuttuvista todisteista, varmista, että `dummy-not-used` on edelleen olemassa; 401-virheessä tarkista `ACEDATACLOUD_API_KEY` Salaisuus. Älä tulosta Salaisuutta lokiin. Voit käyttää `claude_args` tarpeen mukaan asettaaksesi `--max-turns` tai valita nykyisin käytettävissä olevan mallin, mutta liitäntämalli ei ole kiinteä.
