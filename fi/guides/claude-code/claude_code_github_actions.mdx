Claude Code on Anthropicin julkaisema **Agentic Coding** -työkalu, jota kutsutaan myös yhdeksi maailman vahvimmista ohjelmointiaineksista. Claude Code GitHub Actions voi integroida AI-ohjelmointikyvyt GitHub-työnkulkuusi, ja voit vain `@claude` PR:ssä tai Issue:ssa, jolloin Claude analysoi koodin, luo PR:n, toteuttaa toimintoja ja korjaa bugeja automaattisesti.

Tässä asiakirjassa esitellään, kuinka voit konfiguroida ja käyttää Claude Code GitHub Actions AceData Cloudin välityspalvelun kautta.

## Hakuprosessi

Käyttääksesi Claude Codea, voit ensin siirtyä [Claude Messages -palvelusivulle](https://platform.acedata.cloud/documents/claude-messages) ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemuskerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Claude Code -palvelua ilmaiseksi.

## Ominaisuudet

- **Välitön PR:n luominen**: Kuvaile tarve, Claude luo automaattisesti täydellisen Pull Requestin
- **Automaattinen koodin toteutus**: `@claude` Issue:ssa, muuntaa Issue:n toimivaksi koodiksi
- **Projektin standardien noudattaminen**: Lukee automaattisesti `CLAUDE.md`:n, noudattaen koodityyliäsi ja projektistandardeja
- **Turvallinen ja luotettava**: Koodi suoritetaan GitHubin Runnerilla, tietoturva on taattu

## Konfigurointivaiheet

### Vaihe 1: Asenna Claude GitHub App

Siirry [https://github.com/apps/claude](https://github.com/apps/claude) ja asenna Claude GitHub App varastollesi.

![GitHub Claude App asennussivu](https://cdn.acedata.cloud/ba4b8df66d.png)

Sovellus tarvitsee seuraavat varastokäytännöt:

| Käyttöoikeus        | Taso          | Kuvaus          |
| ----------------- | ------------ | ----------- |
| **Sisältö**       | Lue & Kirjoita | Muokkaa varastotiedostoja      |
| **Issues**        | Lue & Kirjoita | Vastaa Issueihin    |
| **Pull requests** | Lue & Kirjoita | Luo PR ja työntää muutoksia |

### Vaihe 2: Lisää API-avain

Lisää AceData Cloudin API-avain varaston Salaisuudeksi:

1. Siirry varaston **Asetukset** → **Salaisuudet ja muuttujat** → **Toiminnot**
2. Napsauta **Uusi varaston salaisuus**
3. Nimeä `ANTHROPIC_API_KEY`, ja syötä Arvoon AceData Cloudista saamasi API-token
4. Napsauta **Lisää salaisuus** tallentaaksesi

> **Vihje**: API-tokenin voi tarkistaa [AceData Cloud -hallintapaneelista](https://platform.acedata.cloud/console).

### Vaihe 3: Luo Workflow-tiedosto

Luo varastoon tiedosto `.github/workflows/claude.yml`:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]
  issues:
    types: [opened, assigned]
  pull_request:
    types: [opened, synchronize]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Jos haluat käyttää AceData Cloudin välityspalvelun API-päätettä, sinun on myös asetettava ympäristömuuttuja Workflow:ssa:

```yaml
name: Claude Code
on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

## Käyttötapa

### Käyttö Issue- tai PR-kommenteissa

Kun konfigurointi on valmis, voit käyttää `@claude` missä tahansa Issue- tai PR-kommentissa, ja Claude vastaa automaattisesti:

```
@claude toteuta toiminto tämän Issue:n kuvauksen mukaan
@claude tarkista tämän PR:n koodin turvallisuus
@claude korjaa TypeError käyttäjäpaneelissa
@claude miten käyttäjäautentikointi tälle päätepisteelle pitäisi toteuttaa?
```

### Automaattinen koodin tarkastus

Luo Workflow, joka suorittaa automaattisen koodin tarkastuksen PR:n avautuessa:

```yaml
name: Code Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "/review"
          claude_args: "--max-turns 5"
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

### Aikataulutetut automaatiotehtävät

Luo aikataulutettu automaatiotehtävä:

```yaml
name: Daily Report
on:
  schedule:
    - cron: "0 9 * * *"

jobs:
  report:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: "Tuota eilisten sitoumusten yhteenveto ja raportti avoimista Issueista"
        env:
          ANTHROPIC_BASE_URL: "https://api.acedata.cloud"
```

## Action-parametrien selitys

| Parametri              | Kuvaus                                  | Pakollinen  |
| --------------------- | ----------------------------------- | --- |
| `anthropic_api_key`   | API-avain                              | Kyllä   |
| `prompt`              | Ohje Claude:lle (teksti tai taito kuten `/review`) | Ei   |
| `claude_args`         | Parametrit, jotka annetaan Claude Code CLI:lle             | Ei   |
| `github_token`        | GitHub Token                        | Ei   |
| `trigger_phrase`      | Mukautettu laukaisulause (oletus `@claude`)               | Ei   |

### claude_args yleiset parametrit

```yaml
claude_args: "--max-turns 5 --model claude-sonnet-4-5-20250929"
```

| Parametri            | Kuvaus            |
| ------------------- | ------------- |
| `--max-turns`       | Suurin keskustelukierros (oletus 10) |
| `--model`           | Käytettävä malli         |
| `--mcp-config`      | MCP-konfiguraatiotiedoston polku    |
| `--allowed-tools`   | Sallittuja työkaluja (pilkuilla erotettuna)   |
| `--debug`           | Ota debug-tulostus käyttöön        |

## Parhaat käytännöt

### Konfiguroi CLAUDE.md

Luo varaston juurihakemistoon tiedosto `CLAUDE.md`, jossa määritellään koodityyliohjeet, tarkastusstandardit ja projektistandardit, joita Claude noudattaa automaattisesti.

### Turvallisuusnäkökohdat

- **Älä koskaan** kirjoita API-avainta suoraan Workflow-tiedostoon
- Käytä aina GitHub Secrets -toimintoa (kuten `${{ secrets.ANTHROPIC_API_KEY }}`)
- Rajoita Action-oikeudet vähimmäistarpeen mukaan
- Tarkista Claude:n ehdotukset manuaalisesti ennen yhdistämistä

### Kustannusten hallinta

- Käytä selkeitä `@claude` -ohjeita vähentääksesi tarpeettomia API-kutsuja
- Määritä kohtuullinen `--max-turns` rajoittamaan keskustelukierroksia
- Aseta Workflow-tason aikaraja
- Käytä GitHubin rinnakkaisuuden hallintaa rajoittamaan samanaikaisten suoritusten määrää

## Usein kysytyt kysymykset

### Claude ei vastaa @claude-komentoon?

1. Varmista, että Claude GitHub App on asennettu oikein
2. Tarkista, että Workflow on käytössä
3. Varmista, että API-avain on asetettu varaston Salaisuudeksi
4. Varmista, että kommentissa käytetään `@claude` (ei `/claude`)
### Varmennusvirhe?

1. Varmista, että API-avain on voimassa ja sillä on riittävät oikeudet
2. Tarkista, että salaisuuden nimi on oikein (`ANTHROPIC_API_KEY`)
3. Jos käytät `ANTHROPIC_BASE_URL`:ia, varmista, että URL-osoite on oikea

### Kuinka tarkistaa jäljellä oleva saldo?

Kirjaudu sisään [AceData Cloud -hallintapaneeliin](https://platform.acedata.cloud/console), niin voit tarkistaa nykyisen tilin jäljellä olevan saldon ja käyttötilanteen.
