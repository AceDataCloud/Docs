Claude Code yhdistää Coding Planin Anthropic Messages -protokollan kautta, ja tällä hetkellä se tarjoaa kaksi kokoonpanovaihtoehtoa: terminaali ja VS Code.

| Käyttöliittymä     | Kokoonpanosuuntaus                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| Terminaali / CLI  | [Claude Code terminaalikokoonpano](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code           | [Claude Code for VS Code -kokoonpano](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Yhteiset asetukset

- Perus-URL: `https://api.acedata.cloud`
- API-tunnus: saatavilla Coding Applicationista ja määritetään oppaan `ANTHROPIC_AUTH_TOKEN` avulla
- Mallin ID: valitaan reaaliaikaisesta malliluettelosta
- Kokoonpanon muokkaamisen jälkeen: käynnistä Claude Code uudelleen; VS Code -käyttäjien on ladattava ikkuna uudelleen

Älä säilytä vanhaa `ANTHROPIC_API_KEY` samanaikaisesti, äläkä kirjoita todellista tunnusta tiimin jaettuihin tiedostoihin.

Palaa [Coding Plan -kokoonpanokeskukseen](https://platform.acedata.cloud/documents/coding-plan-integration).
