description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code on Anthropicin julkaisema ohjelmointiin liittyvä älykäs agentti, jota voidaan käyttää eri ympäristöissä, kuten terminaalissa, IDE:ssä ja työpöytäsovelluksissa. AceData Cloud -välityspalvelun kautta voit käyttää Claude Codea edullisemmin.

Valitse käyttötapasi mukaan vastaava alustan konfigurointiohje:

| Alusta               | Kuvaus                                      | Ohje-linkki                                                                                               |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Terminaali (CLI)** | Ydinkokemus, voit aloittaa suorittamalla `claude` missä tahansa terminaalissa | [Terminaalikonfigurointiohje](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Natiivilaajennus, tukee sisäistä Diffiä, @-mainintoja, suunniteltuja tarkastuksia | [VS Code -konfigurointiohje](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | Tukee kaikkia IDE:itä, kuten IntelliJ IDEA, PyCharm, WebStorm | [JetBrains -konfigurointiohje](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Automaattinen koodin tarkastus ja Issue-käsittely `@claude` avulla | [GitHub Actions -konfigurointiohje](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Vinkki**: Ensimmäistä kertaa hakemalla voit siirtyä [Claude Messages -palvelusivulle](https://platform.acedata.cloud/documents/claude-messages) ja napsauttaa "Acquire" saadaksesi todisteen, jolloin saat ilmaisia krediittejä.
