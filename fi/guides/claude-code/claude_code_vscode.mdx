Claude Code on Anthropicin julkaisema ohjelmointityökalu, jota kutsutaan myös yhdeksi maailman vahvimmista ohjelmointiaineksista. Claude Code:n VS Code -laajennus tarjoaa natiivin graafisen käyttöliittymän, ja se on suositeltu tapa käyttää Claude Code:a VS Code:ssa.

Tässä asiakirjassa käsitellään, kuinka konfiguroida ja käyttää Claude Code -laajennusta VS Code:ssa Ace Data Cloudin välityspalvelun kautta.

## Hakuprosessi

Claude Code:n käyttämiseksi voit ensin siirtyä [Ace Data Cloudin hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit käyttää myöhemmin.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Claude Code -palvelua ilmaiseksi.

## Claude Code -laajennuksen asennus

Etsi VS Code:n laajennusmarkkinoilta **Claude Code** ja varmista, että julkaisija on **Anthropic**, ennen kuin asennat sen. Asennuksen jälkeen aktivointipalkkiin ilmestyy Claude Code -kuvake.

## Ace Data Cloud API:n konfigurointi

Kun avaat laajennuksen ensimmäisen kerran, sinua pyydetään kirjautumaan Anthropicin viralliselle tilille. Voimme ohittaa virallisen kirjautumisen ja käyttää Ace Data Cloudin välityspalvelun API:a ilman virallista tilausta.

Laajennus ja terminaali CLI lukevat samaa Claude Code -asetusta. Täydelliset todennus-, todisteiden konfliktin käsittely- ja globaalit konfigurointimenetelmät löytyvät [Claude Code -terminaalin konfigurointiohjeesta](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Jos haluat, että asetukset vaikuttavat vain nykyiseen projektiin, luo projektin juurihakemistoon .gitignoreen lisätty .claude/settings.local.json:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Missä `{token}` on juuri kopioitu API-avain. Jos VS Code:n ympäristössä on jo vanha `ANTHROPIC_API_KEY`, poista se ensin ympäristöstä `unset ANTHROPIC_API_KEY` -komennolla; älä käytä tyhjää merkkijonoa puhdistamiseen, äläkä laita todellista avainta tiimin jaettuun .claude/settings.json -tiedostoon.

Alla on esimerkki VS Code 1.136.1:n ja Claude Code -laajennuksen 2.1.251:n konfiguroinnista paikallisella koneella. Kuvakaappauksessa käytetään paikkamerkkia, jotta todelliset todisteet eivät vuotaisi:

![VS Code:n Ace Data Cloud Claude Code -konfigurointi](https://cdn.acedata.cloud/f925e9e9597b.png)

Kun konfigurointi on valmis, käynnistä VS Code uudelleen.

> Huom: Yllä oleva konfigurointi vaikuttaa vain nykyiseen projektiin, ja on suositeltavaa lisätä yllä oleva .claude/settings.local.json -konfiguraatiotiedoston polku .gitignore-tiedostoon, jotta se ei siirry etävarastoon.

Jos haluat, että kaikki projektit vaikuttavat, voit suoraan lisätä tämän konfiguraation käyttäjäkansioon. Vastava polku on `~/.claude/settings.json`,

> Huom: Konfiguroinnin jälkeen käynnistä tai lataa VS Code uudelleen, jotta yllä oleva konfiguraatio tulee voimaan.

## Peruskäyttö

Kun konfigurointi on valmis, lähetä Claude Code -paneelissa yksinkertainen vain-luku -tehtävä, kuten "Lue README.md ja tiivistä se yhdellä lauseella". Tehtävän onnistumisen jälkeen voit tarkistaa tämän kutsun [käyttöhistoriasta](https://platform.acedata.cloud/console/usages).

## Kuinka tarkistaa jäljellä oleva saldo

Voit tarkistaa nykyisen tilisi jäljellä olevan saldon [Ace Data Cloudin hallintapaneelista - Sovellusluettelosta](https://platform.acedata.cloud/console/applications).

Voit tarkistaa kaikki käyttöhistorian ja maksutiedot [Ace Data Cloudin hallintapaneelista - Käyttöhistoriasta](https://platform.acedata.cloud/console/usages).
