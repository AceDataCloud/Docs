Claude Code on Anthropicin julkaisema **Agentic Coding** -työkalu, jota kutsutaan myös yhdeksi maailman vahvimmista ohjelmointiaineksista. Claude Code:n VS Code -laajennus tarjoaa natiivin graafisen käyttöliittymän, joka tukee sisäistä Diff-näkymää, `@`-mainintoja, suunnitelman tarkastuksia ja muita toimintoja, ja se on suositeltava tapa käyttää Claude Code:a VS Code:ssa.

Tässä asiakirjassa esitellään, kuinka konfiguroidaan ja käytetään Claude Code -laajennusta VS Code:ssa AceData Cloudin välityspalvelun kautta.

## Hakuprosessi

Claude Code:n käyttämiseksi voit ensin siirtyä [Claude Messages -palvelusivulle](https://platform.acedata.cloud/documents/claude-messages) ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Claude Code -palvelua ilmaiseksi.

## Laajennuksen asennus

### Järjestelmävaatimukset

- VS Code 1.98.0 tai uudempi versio (tukee myös Cursor)

### Asennusvaiheet

Avaa VS Code / Cursorin laajennusmarkkinat painamalla `Cmd+Shift+X` (Mac) tai `Ctrl+Shift+X` (Windows/Linux), etsi **Claude Code**, löydä Anthropicin virallisesti julkaisema laajennus ja napsauta "Install" asentaaksesi sen:

![Claude Code -laajennus VS Code Marketplace:ssa](https://cdn.acedata.cloud/10ddf71320.png)

Voit myös asentaa sen suoraan seuraavan linkin kautta:

- [VS Code asennuslinkki](vscode:extension/anthropic.claude-code)
- [Cursor asennuslinkki](cursor:extension/anthropic.claude-code)

Asennuksen jälkeen valitse luottamus avautuvasta ilmoituksesta, niin asennus on valmis.

> Jos laajennus ei ilmesty asennuksen jälkeen, käynnistä VS Code uudelleen tai suorita komento "Developer: Reload Window" komento-paneelissa.

## AceData Cloud API:n konfigurointi

Kun avaat laajennuksen ensimmäisen kerran, sinua pyydetään kirjautumaan Anthropicin viralliselle tilille. Voimme ohittaa virallisen kirjautumisen konfiguroimalla AceData Cloudin välityspalvelun API:n, **ilman virallista tilausta**.

### Vaihe 1: Ympäristömuuttujien konfigurointi

Voit valita ympäristömuuttujien konfiguroimisen seuraavissa sijainneissa:

**Vaihtoehto A: Käyttäjäkohtainen konfigurointi (kaikille projekteille)**
 
Muokkaa `~/.claude/settings.json` (jos ei ole olemassa, luo se) ja lisää `env`-konfigurointi, vaihda `{token}` AceData Cloudin hallintapaneelista saamasi API-tokenin mukaan:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

**Vaihtoehto B: Projektikohtainen konfigurointi (vain nykyiselle projektille)**

Luo projektin juurihakemistoon `.claude/settings.json` (jaettu konfigurointi) tai `.claude/settings.local.json` (henkilökohtainen konfigurointi, gitignored):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Vinkki**: API-tokenin voi tarkistaa [AceData Cloud hallintapaneelista](https://platform.acedata.cloud/console). `ANTHROPIC_AUTH_TOKEN`-arvoon lisätään automaattisesti `Bearer`-etuliite, joka lähetetään palvelimelle. Projektikohtainen konfigurointi on etusijalla käyttäjäkohtaiselle konfiguroinnille. Suositellaan, että tiimiprojekteissa käytetään `.claude/settings.json`-jaettua konfigurointia, ja henkilökohtaiset arkaluontoiset tiedot sijoitetaan `.claude/settings.local.json`-tiedostoon.

### Vaihe 2: Kirjautumisviestin poistaminen käytöstä (valinnainen)

Jos et halua nähdä kirjautumisviestiä joka kerta, kun avaat, voit valita VS Code -asetuksista **Disable Login Prompt**:

Etsi asetuksista "Claude Code login", löydä **Disable Login Prompt** -vaihtoehto ja valitse se.

Kun konfigurointi on valmis, avaa Claude Code -laajennuspaneeli uudelleen, niin voit aloittaa normaalin käytön.

## Claude Code -paneelin avaaminen

Asennuksen ja konfiguroinnin jälkeen on useita tapoja avata Claude Code:

| Tapa         | Toiminto                                             |
| ---------- | ---------------------------------------------- |
| **Muokkaustyökalupalkki** | Napsauta muokkaimen oikeassa yläkulmassa olevaa ✦ Spark -kuvaketta (tarvitsee avata tiedoston)                 |
| **Tilapalkki**    | Napsauta alareunan tilapalkin oikealla puolella olevaa "✱ Claude Code" (ei tarvitse avata tiedostoa)              |
| **Komentopaneeli**   | `Cmd+Shift+P` / `Ctrl+Shift+P`, etsi "Claude Code" |
| **Pikanäppäin**    | `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux) vaihda fokusta  |

Toisin kuin Cursor / Copilot -työkalujen käyttö sivupalkissa, Claude Code käyttää oletuksena **muokkausalueen näkymää** keskustelualueena, mikä tarjoaa suuremman näkyvän alueen ja rikkaamman sisällön esittämisen. Voit myös vetää paneelin sivupalkkiin tai muualle.

![Claude Code -paneeli VS Code:ssa](https://cdn.acedata.cloud/b84b878420.jpg)

## Peruskäyttö

### Keskustelu vuorovaikutus

Kirjoita Claude Code -paneelissa suoraan luonnollista kieltä, jotta voit vuorovaikuttaa Clauden kanssa. Esimerkiksi:

- "Auta minua analysoimaan tämän projektin kokonaisarkkitehtuuri"
- "Tässä koodissa on bugi, korjaa se"
- "Refaktoroi tämä funktio parantaaksesi luettavuutta"
- "Kirjoita yksikkötesti tälle moduulille"

Claude Code ymmärtää automaattisesti koodikirjastosi kontekstin, analysoi ja muokkaa tiedostoja. Kun Claude tarvitsee muokata tiedostoa, se näyttää Diff-vertailunäkymän, josta voit valita hyväksyä tai hylätä muutokset.

![Claude Code keskustelu ja vihjeet VS Code:ssa](https://cdn.acedata.cloud/650377f5cc.png)

### Kontekstiviittaukset

Keskustelussa voit käyttää `@`-symbolia viitataksesi tiettyihin tiedostoihin tai konteksteihin:

- `@filename.py` — viittaa tiettyyn tiedostoon (tukee epätarkkaa vastaavuutta)
- `@src/components/` — viittaa koko hakemistoon (vaatii loppupään vinoviivan)
- `@terminal:name` — viittaa terminaalin tulostukseen

Valitsemalla muokkaimessa olevaa koodia ja painamalla `Option+K` (Mac) / `Alt+K` (Windows/Linux) voit nopeasti lisätä `@`-viittauksen (esim. `@app.ts#5-10`).

### Vinoviivakomennot

Napsauta keskusteluikkunassa olevaa `/`-kuvaketta tai kirjoita suoraan `/`, niin voit käyttää monia sisäänrakennettuja toimintoja:

Yleisimmät komennot sisältävät:

| Komento         | Toiminto           |
| ---------- | ------------ |
| `/new`     | Luo uusi keskustelu         |
| `/model`   | Vaihda mallia         |
| `/compact` | Tiivistä konteksti        |
| `/mcp`     | Konfiguroi MCP-palvelu    |
| `/config`  | Avaa asetukset         |
| `/usage`   | Tarkista käyttö         |
| `/memory`  | Hallitse Clauden muistia |
| `/help`    | Näytä aputiedot       |

### Tarkastele aiempia keskusteluja

Napsauta paneelin yläreunassa olevaa alasvetovalikkoa nähdäksesi aiemmat keskusteluhistorian, joka tukee avainsanojen hakua ja aikarajojen (Tänään, Eilen, Viimeiset 7 päivää jne.) selaamista, mikä helpottaa aiempien vuorovaikutusten jäljittämistä. Napsauta mitä tahansa keskustelua palauttaaksesi täydellisen viestihistorian.

### Koodimuutosten tarkastelu

Kun Claude tarvitsee muokata tiedostoa, se näyttää Diff-vertailunäkymän, joka esittää alkuperäisen koodin ja muokatun version vertailun. Voit valita hyväksyä tai hylätä jokaisen muutoksen, tai voit kertoa Claudelle, mitä erilaista haluat tehdä:
![Diff-näkymä VS Code:ssa](https://cdn.acedata.cloud/c42381ea9f.png)

### Oikeusmoodi

Voit vaihtaa eri oikeusmoodien välillä paneelin alareunassa olevan moodi-indikaattorin avulla:

| Moodi                  | Selitys                      |
| --------------------- | ----------------------- |
| **Oletus (Kysy)**      | Kysyy vahvistusta ennen jokaista toimintoa (oletus)           |
| **Suunnitelma**       | Claude laatii ensin suunnitelman odottaen hyväksyntää, suorittaa sen vasta vahvistuksen jälkeen |
| **hyväksyMuokkaukset** | Hyväksyy automaattisesti tiedostomuokkaukset, mutta terminaalikomennot vaativat edelleen vahvistuksen      |
| **ohitaOikeudet**     | Ohittaa kaikki oikeusilmoitukset, täysin automatisoitu (käytä varoen)    |

### Monikäyttöiset istunnot

Voit käynnistää useita itsenäisiä keskusteluja komento-paneelista valitsemalla **Avaa uudessa välilehdessä** tai **Avaa uudessa ikkunassa**, jokainen keskustelu ylläpitää omaa historiaansa ja kontekstiansa, ja voit käsitellä eri tehtäviä rinnakkain.

## Muut asetukset

### Mallin vaihtaminen

Claude Code tukee eri mallien vaihtamista, kuten Claude Sonnet, Claude Opus jne. Voit määrittää sen käyttämällä komentoa `/model` tai plugin-asetuksissa **Valittu malli**.

### Automaattinen moodi

Plugin-asetuksissa voit asettaa **Alkuperäinen oikeusmoodi** arvoksi `ohitaOikeudet`, jolloin Claude Code ei enää kysy vahvistusta tiedostomuokkauksille, terminaalikomennoille jne., mikä mahdollistaa täysin automatisoidun työnkulun.

Voit myös asettaa sen arvoksi `hyväksyMuokkaukset`, jolloin muokkaukset hyväksytään automaattisesti, mutta terminaalikomennot vaativat edelleen vahvistuksen puoliksi automatisoidussa moodissa.

> **Huom**: Varmista, että ymmärrät riskit ennen automaattisen moodin käyttöönottoa, suositellaan käytettäväksi luotettavissa projektikonteksteissa.

### CLI:n käyttö terminaalissa

Jos pidät enemmän komentorivityylistä, voit valita VS Code -asetuksista **Käytä terminaalia**, jolloin Claude Code toimii CLI-moodissa integroidussa terminaalissa. Voit myös avata suoraan VS Code:n integroidun terminaalin ja suorittaa `claude`-komennon.

## Usein kysytyt kysymykset

### Mitä tehdä, jos yhteys epäonnistuu?

1. Varmista, että `~/.claude/settings.json` tai `.claude/settings.json` -tiedostossa ympäristömuuttujat on määritetty oikein, erityisesti `ANTHROPIC_AUTH_TOKEN` ja `ANTHROPIC_BASE_URL`
2. Varmista, että API-tunnus on voimassa (voit tarkistaa sen [ohjauspaneelista](https://platform.acedata.cloud/console))
3. Tarkista, että verkkoyhteys on kunnossa ja että pääset käsiksi `https://api.acedata.cloud`
4. Käynnistä VS Code uudelleen ja yritä uudelleen

### Miksi Spark-ikoni ei näy?

1. Varmista, että olet avannut tiedoston (pelkkä kansion avaaminen ei riitä)
2. Varmista, että VS Code -versio on 1.98.0 tai uudempi
3. Suorita komentopaneelissa "Kehittäjä: Lataa ikkuna uudelleen"
4. Tai napsauta suoraan alareunan tilarivillä "✱ Claude Code"

### Kuinka tarkistaa jäljellä oleva saldo?

Kirjaudu sisään [AceData Cloud -ohjauspaneeliin](https://platform.acedata.cloud/console), niin voit tarkistaa nykyisen tilisi jäljellä olevan saldon ja käyttötilanteen.
