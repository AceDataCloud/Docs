## 1. Hanki API-avain

Avaa [Ace Data Cloud -sovellusten luettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä oleviin sovelluksiin ja kopioi API-avain.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Asenna CLI ja laajennus

Asenna ensin Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Asenna sitten **Claude Code** -laajennus JetBrains Marketplace -sivustolta ja käynnistä IDE uudelleen. Laajennus kutsuu paikallista `claude`-komentoa; jos saat virheilmoituksen komennon löytymisestä, täytä sen täydellinen polku **Asetukset → Työkalut → Claude Code** -osiossa.

## 3. Konfiguroi Ace Data Cloud

Aseta JetBrains backendin ympäristössä.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sinun API-avain"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "sinun API-avain"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Voit myös käyttää projektissa ohitettua `.claude/settings.local.json`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "sinun API-avain"
  }
}
```

Etäkehityksessä on konfiguroitava ja asennettava laajennus etäisäntään; WSL-käyttäjät voivat asettaa Claude-komennon muotoon `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Vahvista

Suorita `claude` IDE:n integroituun terminaaliin tai käynnistä ulkoinen terminaali ja syötä `/ide`. Kun yhteys on onnistunut, anna Clauden vastata `OK`, lue sitten testitiedosto ja tarkista pyyntö Ace Data Cloudin [käyttöhistoriasta](https://platform.acedata.cloud/console/usages).

Jos laajennus ei käynnisty, suorita ensin `claude --version` samassa terminaalissa; 401-virheessä tarkista backendin todelliset ympäristömuuttujat ja vanha `ANTHROPIC_API_KEY`.
