Tämän dokumentin tavoite on yksinkertainen: saada sinut **5 minuutissa** käyttämään AceData Cloud -välityspalvelua ja suorittamaan ensimmäinen Claude Code -komento. Täydellinen opas löytyy IDE-kohtaisista alidokumenteista ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); tässä artikkelissa käydään läpi nopein reitti: "**päätelaite CLI** + **VS Code -laajennus**".

> **Miksi käyttää AceData Cloud -välityspalvelua Claude Codeen**:
> - Suora yhteys Kiinasta ilman oman VPN:n tarvetta
> - Edullisempi hinnoittelu (maksu tokenien mukaan)
> - Sama avain tukee sekä Claude Messages API:a että Claude Code Token -protokollaa

## 1. minuutti: Hanki tunnistetiedot

Avaa [Claude Messages -palvelusivu](https://platform.acedata.cloud/documents/claude-messages) ja klikkaa "**Acquire**" -painiketta:

![](https://cdn.acedata.cloud/nyq0xz.png)

Alusta luo automaattisesti sovelluksen ja antaa ilmaisen käyttökiintiön. Tallenna **Base URL** ja **API Token** -tiedot — niitä tarvitaan seuraavissa viidessä vaiheessa.

| Kenttä | Arvo | Käyttötarkoitus |
|--------|-------|-----------------|
| `BASE_URL` | `https://api.acedata.cloud` | Claude Messages -yhteensopiva päätepiste |
| `API_TOKEN` | `sk-...` (kopioitavissa palvelusivulta) | Anthropic-yhteensopiva autentikointitunniste |

## 2. minuutti: Asenna Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Asennuksen jälkeen avaa uusi terminaali ja varmista asennus:

```bash
claude --version
```

> Näet versionumeron. Claude Code sisältää oman Node.js-ajoympäristön, joten se ei riipu koneesi Node-versiosta.

## 3. minuutti: Määritä ympäristömuuttujat AceData Cloud -välityspalvelua varten

Älä käytä virallista `claude login` -prosessia, vaan ylikirjoita asetukset ympäristömuuttujilla. Voit valita kahdesta tavasta:

**Vaihtoehto A: Väliaikainen (vain nykyiseen Shell-istuntoon)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-oma-token"
```

**Vaihtoehto B: Pysyvä (suositeltu)**

Lisää yllä olevat rivit tiedostoon `~/.zshrc` tai `~/.bashrc` ja aja `source`-komento.

> **Yleisiä virheitä**: Muuttujan nimi on `ANTHROPIC_AUTH_TOKEN`, ei `ANTHROPIC_API_KEY`; väärä nimi aiheuttaa 401-virheen, koska Claude Code yrittää käyttää virallista päätepistettä.

## 4. minuutti: Suorita ensimmäinen komento

Siirry mihin tahansa Git-repositorioon ja suorita:

```bash
claude
```

Jos kirjautumispyyntö tulee ensimmäisellä käynnistyskerralla, paina `Esc` ohittaaksesi. Kirjoita sitten:

```
Listaa tämän projektin riippuvuudet ja selitä lyhyesti kunkin käyttötarkoitus.
```

Claude käyttää työkaluja kuten `read_file`, `glob` ja `grep` tutkiakseen repositoriota ja antaa listan. Jos malli vastaa oikein eikä anna 401-virhettä, välityspalvelu toimii.

## 5. minuutti: Ota VS Code -laajennus käyttöön

1. Avaa VS Code → Laajennukset → hae "Claude Code" ja asenna Anthropicin virallinen laajennus;
2. Käynnistä VS Code uudelleen tai suorita komentopalettissa `Developer: Reload Window`, jotta laajennus lukee 3. minuutin asetukset `~/.claude/settings.json` -tiedostosta;
3. Klikkaa editorin oikeassa yläkulmassa olevaa ✦ Spark -kuvaketta tai alareunan tilapalkissa olevaa "✱ Claude Code" avataksesi paneelin;
4. Ensimmäisellä kerralla laajennus pyytää kirjautumaan viralliselle tilille, paina `Esc` ohittaaksesi — laajennus käyttää automaattisesti 3. minuutin asetuksia `ANTHROPIC_BASE_URL` ja `ANTHROPIC_AUTH_TOKEN`.

> **Vinkki**: VS Code -laajennus ja CLI käyttävät samaa `~/.claude/settings.json` -tiedostoa, joten sinun ei tarvitse määrittää asetuksia erikseen VS Codeen. Jos haluat käyttää projektikohtaisia asetuksia, luo repositorion juureen `.claude/settings.local.json` (tiedosto on gitignore-listalla).

Kun onnistut, voit vetää tiedostoja paneeliin kysymyksiä varten ja käyttää `@-mention`-viittauksia tiedostoihin muutosesityksiä varten. Kaikki laskutus menee AceData Cloudin kautta.

## Varmista, että käytät välityspalvelua

Käynnistä komento debug-tilassa ja tarkista, että pyyntö menee AceData Cloudiin:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Jos näet `https://api.acedata.cloud`, välityspalvelu toimii. Jos näkyy `api.anthropic.com` tai saat 401-virheen, tarkista 3. minuutin ympäristömuuttujien nimet (täytyy olla `ANTHROPIC_AUTH_TOKEN`, ei `ANTHROPIC_API_KEY`) ja varmista, ettei tiedostossa `~/.claude/.credentials.json` ole virallista tokenia (poista tiedosto tarvittaessa).

## 5 yleisintä kysymystä

**K: Suoritin `claude login` ja sen jälkeen vaihdoin ympäristömuuttujat AceData Cloudiin, miksi se ei toimi?**  
V: `claude login` tallentaa virallisen tokenin tiedostoon `~/.claude/.credentials.json`, jolla on etusija ympäristömuuttujiin nähden. Poista tiedosto ja aja `source ~/.zshrc` uudelleen.

**K: Voinko käyttää mallin nimeä kuten `--model claude-opus-4-7`?**  
V: Kyllä. AceData Cloud -välityspalvelu välittää mallin nimen suoraan, ja kaikki Anthropicin julkiset mallit sekä laajennuksemme `claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5` ovat tuettuja.

**K: Voinko määrittää useita profiileja (esim. henkilökohtainen ja työ)?**  
V: Kyllä. Claude Code tukee useita profiileja tiedostossa `~/.claude/settings.json`. Helpoin tapa on kirjoittaa kaksi shell-funktiota, kuten `claude_personal` ja `claude_work`, jotka asettavat eri `ANTHROPIC_AUTH_TOKEN` -arvot ja kutsuvat `claude $@`.

**K: Voinko käyttää tätä GitHub Actionsissa?**  
V: Kyllä. Katso [Claude Code GitHub Actions -integraatio](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) saadaksesi lisätietoja.

**K: Entä kun ilmainen kiintiö loppuu?**  
V: Mene [Sovellusten hallintaan](https://platform.acedata.cloud/applications) → valitse Claude-sovellus → Topup-lataus (maksu tokenien käytön mukaan) tai vaihda pistepohjaiseen tilaukseen.
