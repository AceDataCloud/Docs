Tämän dokumentin ainoa tavoite on: saada sinut **5 minuutissa** käyttämään AceData Cloud -välityspalvelinta ja suorittamaan ensimmäinen Claude Code -komento. Täydelliset ohjeet löytyvät IDE-kohtaisista alidokumenteista ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); tässä käydään läpi nopein reitti: "**päätelaite CLI** + **VS Code -laajennus**".

> **Miksi käyttää AceData Cloud -välityspalvelinta Claude Codeen**:
> - Suora yhteys Kiinasta ilman VPN:ää
> - Edullisempi hinnoittelu (maksu tokenien mukaan)
> - Sama avain tukee sekä Claude Messages API:a että Claude Code Token -protokollaa

## 1. minuutti: Hanki tunnistetiedot

Avaa [Claude Messages -palvelusivu](https://platform.acedata.cloud/documents/claude-messages) ja klikkaa "**Acquire**" -painiketta:

![](https://cdn.acedata.cloud/nyq0xz.png)

Alusta luo automaattisesti sovelluksen ja antaa ilmaisen käyttökiintiön. Kirjaa ylös **Base URL** ja **API Token** -tiedot — tarvitset niitä seuraavissa viidessä vaiheessa.

| Kenttä | Arvo | Käyttötarkoitus |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Claude Messages -yhteensopiva päätepiste |
| `API_TOKEN` | `sk-...` (kopioitavissa palvelusivulta) | Anthropic-yhteensopiva autentikointitunniste |

## 2. minuutti: Asenna Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Asennuksen jälkeen avaa uusi terminaali ja varmista asennus:

```bash
claude --version
```

> Näet versionumeron. Claude Code sisältää oman Node.js-ajoympäristön, joten se ei riipu koneesi Node-versiosta.

## 3. minuutti: Määritä ympäristömuuttujat AceData Cloudille

Älä käytä virallista `claude login` -prosessia, vaan ylikirjoita asetukset ympäristömuuttujilla. Valitse jompikumpi tapa:

**Vaihtoehto A: Väliaikainen (vain nykyisessä Shell-istunnossa)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-oma-token"
```

**Vaihtoehto B: Pysyvä (suositeltu)**

Lisää yllä olevat rivit `~/.zshrc` tai `~/.bashrc` -tiedostoon ja aja `source`-komento.

> **Yleinen virhe:** ympäristömuuttujan nimi on `ANTHROPIC_AUTH_TOKEN`, ei `ANTHROPIC_API_KEY`; väärällä nimellä Claude Code käyttää virallista päätepistettä ja saa 401-virheen.

## 4. minuutti: Suorita ensimmäinen komento

Siirry mihin tahansa Git-repositorioon ja aja:

```bash
claude
```

Jos kirjautumispyyntö tulee ensimmäisellä käynnistyskerralla, paina `Esc` ohittaaksesi. Kirjoita sitten:

```
Listaa tämän projektin riippuvuudet ja selitä lyhyesti kunkin käyttötarkoitus.
```

Claude käyttää työkaluja kuten `read_file` / `glob` / `grep` tutkiakseen repositoriota ja antaa listan. Näytön alareunassa näkyy tila `connected to api.acedata.cloud` — tämä on merkki siitä, että välityspalvelin toimii.

## 5. minuutti: Kytke myös VS Code -laajennus

1. Avaa VS Code → Laajennukset → hae "Claude Code" ja asenna Anthropicin virallinen laajennus;
2. Paina **Cmd+Shift+P** → kirjoita `Claude Code: Set Custom API Endpoint`;
3. Syötä `https://api.acedata.cloud/claude` ja paina Enter;
4. Suorita uudelleen `Claude Code: Set API Token` ja syötä oma tokenisi.

Onnistuneessa asennuksessa sivupalkkiin ilmestyy Claude Code -paneeli, johon voit raahata tiedostoja kysymyksiä varten tai käyttää `@-mainintaa` tiedoston muutosesityksiin. Kaikki laskutus tapahtuu AceData Cloudin kautta.

## Varmista, että käytät välityspalvelinta

Kirjoita Claude Code -keskusteluun:

```
Käy osoitteessa https://api.acedata.cloud/whoami ja kerro, mitä se palauttaa.
```

Jos saat vastauksena oman käyttäjätietosi (`{user_id, plan, ...}`), pyyntö kulkee AceData Cloudin kautta. Jos saat 401-virheen viralliselta domainilta, tarkista ympäristömuuttujien nimet kohdassa 3.

## 5 yleisintä kysymystä

**K: Suoritin `claude login` ja vaihdoin sitten ympäristömuuttujat AceData Cloudiin, mutta se ei toimi. Miksi?**  
V: `claude login` tallentaa virallisen tokenin tiedostoon `~/.claude/.credentials.json`, jolla on korkeampi prioriteetti kuin ympäristömuuttujilla. Poista tämä tiedosto ja aja `source ~/.zshrc` uudelleen.

**K: Voinko käyttää mallin nimeä kuten `--model claude-opus-4-7`?**  
V: Kyllä. AceData Cloud välittää mallinimen suoraan, ja kaikki Anthropicin julkiset mallit sekä laajennuksemme `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` toimivat.

**K: Voinko määrittää useita profiileja (esim. henkilökohtainen ja työ)?**  
V: Kyllä. Claude Code tukee useita profiileja tiedostossa `~/.claude/settings.json`; yksinkertaisin tapa on tehdä kaksi shell-funktiota `claude_personal` ja `claude_work`, jotka asettavat eri `ANTHROPIC_AUTH_TOKEN` -arvot ja kutsuvat `claude $@`.

**K: Voinko käyttää tätä GitHub Actions -työnkulussa?**  
V: Kyllä. Katso [Claude Code GitHub Actions -integraatio](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**K: Entä kun ilmainen kiintiö loppuu?**  
V: Mene [Sovellusten hallintaan](https://platform.acedata.cloud/applications), valitse Claude-sovellus ja tee Topup-lataus (maksu tokenien käytön mukaan) tai vaihda pisteperusteiseen tilaukseen.
