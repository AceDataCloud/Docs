Tässä artikkelissa esitellään Grok Videos Generation API:n integraatio-ohjeet, jonka avulla voidaan luoda Grok Imagine (xAI) -videoita syöttämällä tekstikehotteita, syöttämällä kuvia sekä valinnaisia viittauskuvia.

## Hakuprosessi

Käyttääksesi Grok Videos Generation API:a, sinun tulee ensin mennä [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palatessasi palaat automaattisesti nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen käyttöoikeuden, jonka avulla voit kokeilla palvelua ilmaiseksi; jos käyttöoikeus loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Mallin kuvaus

Tämä API valitsee yläpuoliset päätepisteet mallin nimen liitteen perusteella: `:reverse` käyttää nopeaa/standardi-päätepistettä (halvempi), `:official` käyttää virallista päätepistettä (korkeampi laatu, laskutus perustuu tuotettuihin sekunteihin). Yhteensä tuetaan neljää mallia:

- `grok-imagine-video-1.5-fast:reverse` (oletus): tukee tekstistä videota (vain `prompt`) ja kuvasta videota (syötä `image_url`), kesto 6–30 sekuntia, laskutus kestosta, halvin.
- `grok-imagine-video:reverse`: tukee tekstistä ja kuvasta videota, kesto 1–15 sekuntia, laskutus tuotettujen sekuntien mukaan.
- `grok-imagine-video:official`: virallinen päätepiste, tukee tekstistä ja kuvasta videota, kesto 1–15 sekuntia, laskutus tuotettujen sekuntien mukaan, korkeampi laatu.
- `grok-imagine-video-1.5:official`: virallinen päätepiste, **tukee vain kuvasta videota**, **on pakko** syöttää `image_url`, kesto 1–15 sekuntia, tukee korkeinta `1080p`, laskutus tuotettujen sekuntien mukaan.

## Peruskäyttö

Ensinnäkin, ymmärrä peruskäyttötapa, syötä kehotteet `prompt`, malli `model` jne. parametreina, niin voit luoda vastaavan videon.

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

Lisäksi on asetettu pyyntödata, mukaan lukien:

- `prompt`: teksti, joka kuvaa haluamaasi videon sisältöä. Tekstistä videota luodessa **pakollinen**; syötettäessä `image_url` valinnainen.
- `model`: videon luomiseen käytettävä malli, valittavissa `grok-imagine-video-1.5-fast:reverse` (oletus), `grok-imagine-video:reverse`, `grok-imagine-video:official` tai `grok-imagine-video-1.5:official`.
- `image_url`: kuvasta videon syöttökuvalinkki. Kun `model` on `grok-imagine-video-1.5:official`, **pakollinen**.
- `reference_image_urls`: valinnaisten viittauskuvien linkkien taulukko, jota käytetään videon tyylin tai sisällön ohjaamiseen.
- `aspect_ratio`: luotavan videon kuvasuhde, valittavissa `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: tuotettavan videon tarkkuus, valittavissa `480p` (oletus), `720p` tai `1080p`.
- `duration`: luotavan videon kesto (sekunteina). `grok-imagine-video-1.5-fast:reverse` arvoalue 6–30, muut mallit arvoalue 1–15, oletus 6. Suositellaan käyttämään 6 sekuntia tai 10 sekuntia, nämä kaksi standardikestoa ovat suhteellisen vakaita.
- `callback_url`: asynkroninen palautusosoite, asetettaessa API palauttaa heti `task_id`:n, ja kun tehtävä on valmis, tulos POSTataan tähän osoitteeseen.
- `async`: valinnainen, asetettaessa `true` rajapinta palauttaa heti `task_id`:n, eikä tarvitse antaa `callback_url`:ia, sen jälkeen voit kysyä tuloksia vastaavasta tehtävän kyselyrajapinnasta.

Napsauta "Kokeile" -painiketta testataksesi, ja saat tuloksen, joka on samanlainen kuin seuraava:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`: onnistuiko videon luontipyyntö.
- `task_id`: tämän videon luontitehtävän ID.
- `trace_id`: tämän pyynnön jäljitystunnus, jota käytetään ongelmien selvittämiseen.
- `data`: luotujen videoiden tuloslista.
  - `id`: luodun videon ainutlaatuinen tunnus.
  - `video_url`: luodun videon linkki.
  - `state`: videon luontitehtävän tila, valittavissa `pending` / `succeeded` / `failed`.

Meidän tarvitsee vain hankkia luodun videon linkki `data`-osion `video_url`:sta.

Vastaava CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "resolution": "480p",
  "duration": 6
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Kuvasta video

Jos haluat luoda videon syöttökuvasta, voit syöttää `image_url`:n. Käytettäessä `grok-imagine-video-1.5:official` on pakko antaa tämä kenttä:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5:official",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 6
}
```

## Viittauskuvien ohjaus

Jos haluat käyttää yhtä tai useampaa viittauskuvaa videon tyylin tai sisällön ohjaamiseen, voit syöttää kuvien linkit `reference_image_urls`:ssa:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Asynkroninen palautus
Videon luominen vaatii tietyn käsittelyajan. Jos et halua pitää pitkäaikaista yhteyttä odottamassa, voit antaa `callback_url`, jolloin API palauttaa heti `task_id`:n, ja tehtävän valmistuttua se POSTaa lopullisen tuloksen tähän osoitteeseen:

```json
{
  "prompt": "Kino-otoksia kissanpennusta, joka jahtaa perhosta auringonvalossa olevassa puutarhassa",
  "model": "grok-imagine-video-1.5-fast:reverse",
  "duration": 6,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Välittömästi palautettu tulos on seuraava:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Tehtävän tulosten tarkistaminen

Jos käytät asynkronista palautetta tai haluat aktiivisesti tarkistaa tehtävän tilan, voit käyttää [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) tarkistaaksesi tehtävän viimeisimmän tilan ja tuloksen `task_id`:n perusteella.

## Laskutustiedot

Tämän palvelun laskutustapa määräytyy `model`:n mukaan:

- `grok-imagine-video-1.5-fast:reverse`: laskutetaan keston mukaan, ei liity resoluutioon — `6–10` sekuntia, `11–20` sekuntia, `21–30` sekuntia vastaavat eri hintaluokkia.
- `grok-imagine-video:reverse`: laskutetaan "tuotettujen sekuntien" mukaan, kokonaishinta = yksikköhinta × `duration`.
- `grok-imagine-video:official` ja `grok-imagine-video-1.5:official`: viralliset päätepisteet, laskutetaan "tuotettujen sekuntien" mukaan, mitä korkeampi resoluutio, sitä korkeampi yksikköhinta; viralliset mallit laskuttavat myös, vaikka sisällön tarkastus epäonnistuu.

Tarkka yksikköhinta on hinnoittelusivun mukaan. Epäonnistuneista pyynnöistä ei laskuteta, eikä ne käytä ilmaista määrää.

## Virheiden käsittely

Kun pyyntö epäonnistuu, API palauttaa vastaavan virhekoodin ja selityksen, yleisimmät ovat seuraavat:

- `400`: Pyyntöparametreissa on virhe, esimerkiksi videon luomisessa puuttuu `prompt`, tai `grok-imagine-video-1.5:official` puuttuu `image_url`, tai `duration` ylittää rajan ( `grok-imagine-video-1.5-fast:reverse` on 6–30, muut mallit 1–15).
- `401`: Varmennus epäonnistui, token on virheellinen tai ei vastaa API:ta.
- `403`: Saldo on riittämätön, tai avainsana on osunut sisällön tarkastuksen hylkäykseen.
- `429`: Pyyntöjä on liian monta, yritä myöhemmin uudelleen.
- `500`: Videon luominen epäonnistui tai palvelussa on poikkeus.
