xAI Grok on erittäin voimakas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain syöttämällä kehotussanoja muutamassa sekunnissa. Grok erottuu alalla ainutlaatuisella huumorityylillään ja reaaliaikaisella verkkotietojen hankintakyvyllään, ja nykyään Grok on noussut esiin useilla innovatiivisilla alueilla, ja sen vaikutusvalta kasvaa nopeasti. Olipa kyseessä päivittäinen keskustelu, luova kirjoittaminen tai tekninen analyysi ja koodin virheenkorjaus, Grok voi tarjota oivaltavaa älykästä apua, joka tuo käyttäjien päätöksentekoon ja luomiseen täysin uuden ulottuvuuden.

Tässä asiakirjassa esitellään pääasiassa Grok Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista Grok-keskustelutoimintoa.

## Hakuprosessi

Grok Chat Completion API:n käyttämiseksi voit ensin siirtyä [Grok Chat Completion API](https://platform.acedata.cloud/documents/faf08b59-36aa-4d26-b5d9-a18f113cc2be) -sivulle ja napsauttaa "Acquire"-painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/vunnjf.png" width="400" class="m-auto"></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, joka valitaan suoraan avattavasta valikosta. Toinen parametri on `model`, joka tarkoittaa, että valitsemme Grok:n virallisen mallikategorian. Täällä meillä on pääasiassa 8 erilaista mallia, tarkemmat tiedot voit katsoa tarjoamastamme mallista. Viimeinen parametri on `messages`, joka on kysymysmerkkien taulukko, joka on taulukko, joka tarkoittaa, että voit ladata useita kysymyksiä samanaikaisesti. Jokainen kysymys sisältää `role` ja `content`, jossa `role` tarkoittaa kysyjän roolia. Olemme tarjonneet kolme identiteettiä: `user`, `assistant`, `system`. Toinen `content` on kysymyksen tarkka sisältö.

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try"-painiketta testataksesi.

Yleisesti käytettävät valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen enimmäistoken-määrää.
- `temperature`: luo satunnaisuutta, 0-2 välillä, suurempi arvo tarkoittaa hajautetumpaa tulosta.
- `n`: kuinka monta ehdokasvastausta luodaan kerralla.

Palautustuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luomisen ID, jota käytetään tämän keskustelutehtävän yksilöimiseen.
- `model`, valittu Grok:n virallinen malli.
- `choices`, Grokin antamat vastaukset kysymyksiin.
- `usage`: tämän kysymys-vastausparin token-tilastotiedot.

`choices` sisältää Grokin vastaustiedot, ja sen sisällä `choices` on Grokin antama tarkka tieto, kuten kuvassa näkyy.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosivustojen integroinnissa, sillä se mahdollistaa sanan kerrallaan näyttämisen.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodin on myös oltava vastaavasti muutettu tukemaan virtaavaa vastausta.

<p><img src="https://cdn.acedata.cloud/k883qa.png" width="400" class="m-auto"></p>

Kun `stream` on muutettu arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautetussa `data`-tuloksessa on useita kenttiä, jotka on esitelty alla:

- `choices`, Grokin antama vastaustieto kysymykseen.

JavaScript on myös tuettu, esimerkiksi Node.js:n virtaavan kutsun koodi on seuraava:

```javascript
const options = {
  method: "post",
  headers: {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    "model": "grok-3",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": true
  })
};

fetch("https://api.acedata.cloud/grok/chat/completions", options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "grok-3");

```

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"

    "accept": "application/json",

    "content-type": "application/json"
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
