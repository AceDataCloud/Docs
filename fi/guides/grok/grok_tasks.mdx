Grok Tasks API:n päätoiminto on kysyä tehtävän suoritustilaa syöttämällä Grok Videos Generation API:n tuottama tehtävä ID.

Tässä asiakirjassa käsitellään Grok Tasks API:n integrointiohjeita, jotka auttavat sinua helposti integroimaan ja kysymään Grok Videos Generation API:n tehtävän suoritustilaa.

## Hakuprosessi

Käyttääksesi Grok Videos Generation API:a, sinun on ensin hankittava API Token [Ace Data Cloud -hallintapaneelista](https://platform.acedata.cloud/console/applications) ja pidettävä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palat takaisin nykyiselle sivulle.

**Yksi API Token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; kun saldo on vähissä, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Pyyntöesimerkki

Grok Tasks API:a voidaan käyttää Grok Videos Generation API:n tulosten kysymiseen.

### Pyyntöotsikon ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

**Pyyntökeho** sisältää:

- `id`: kysyttävä tehtävä ID.
- `action`: tehtävän toimintatapa, yksittäisessä kyselyssä täytetään `retrieve`.

### CURL-koodiesimerkki

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa tämän tehtävän yksityiskohtaiset tiedot. `request`-kenttä on tehtävän käynnistämisen yhteydessä käytetty pyyntökeho, ja `response`-kenttä on tehtävän valmistuttua palautettu vastauskeho, esimerkiksi:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Kino-otoksia kissasta, joka jahtaa perhosta auringonvalossa olevassa puutarhassa",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Kenttien esittely seuraavasti:

- `id`: luodun tehtävän ID, jota käytetään tämän luontitehtävän yksilöimiseen.
- `request`: kyselytehtävän pyyntöinformaatio.
- `response`: kyselytehtävän palautusinformaatio.
- `created_at`: tehtävän luomisaika, Unix-aikaleima (sekunnit, liukuluku).
- `started_at`: tehtävän aloitusaika, Unix-aikaleima (sekunnit, liukuluku).
- `finished_at`: tehtävän valmistumisaika, Unix-aikaleima (sekunnit, liukuluku). Jos tehtävä ei ole valmis, tätä kenttää ei palauteta.
- `elapsed`: tehtävän suorittamiseen kulunut aika, yksikkönä sekunnit (liukuluku, 3 desimaalia). Jos tehtävä ei ole valmis, tätä kenttää ei palauteta.

## Massakyselytoiminto

Useiden tehtävä ID:iden kysyminen tehtävän yksityiskohtia varten, aseta `action` arvoksi `retrieve_batch` ja siirrä `ids`-kentässä tehtävä ID -taulukko:

**Pyyntökeho** sisältää:

- `ids`: kysyttävä tehtävä ID -taulukko.
- `action`: tehtävän toimintatapa, massakyselyssä täytetään `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
