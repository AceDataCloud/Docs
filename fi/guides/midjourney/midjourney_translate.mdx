Midjourney Translate API:n päätoiminto on saada englanninkielinen kuvaus syöttämällä kiinalainen kuvaussana content.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Midjourney Translate API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Midjourney Translate API:n avulla voit helposti muuntaa kiinalaisen kuvaussanan content englanninkieliseksi kuvaussanaksi content.

## Hakuprosessi

Käyttääksesi Midjourney Translate API:a, sinun on ensin mentävä hakusivulle [Midjourney Translate API](https://platform.acedata.cloud/documents/e067d19b-7a66-4458-a45f-0fe88c1d5d34) ja haettava tarvittavaa palvelua. Kun olet siirtynyt sivulle, napsauta "Acquire"-painiketta, kuten kuvassa on esitetty:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää API:n ilmaiseksi.

## Pyyntöesimerkki

Otetaan esimerkki kiinalaisesta kuvaussanasta ja näytetään, kuinka käyttää tätä API:a. Oletetaan, että kiinalainen kuvaussana on: 精致，无暇，洁白的天使, seuraavaksi näytetään, kuinka ladataan kiinalainen kuvaussana ja saadaan englanninkielinen kuvaussana.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä kohdassa on `application/json`.
- `authorization`: API:n avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `content`: ladattu kiinalainen kuvaussana.

> Vain tämä kenttä riittää käännöksen suorittamiseen, varmista, että `content` käyttää kiinalaista kuvaussanaa.

Aseta kuten alla olevassa kuvassa on esitetty:

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/oj1cck.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/translate' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "精致，无暇，洁白的天使"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/translate"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "精致，无暇，洁白的天使"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa käännetyn kiinalaisen kuvaussanan 1 kuvauksen. Esimerkiksi:

```json
{
  "content": "Exquisite, flawless, pure white angel"
}
```

Voit nähdä, että tuloksessa on `content`-kenttä, joka sisältää käännetyn englanninkielisen kuvaussanan, joka on vastaava kiinalaisen kuvaussanan käännös.

- `content`, tuottaa vastaavan englanninkielisen kuvaussanan, jota voidaan käyttää kuvagenerointitehtävien kuvaussanana.

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liikaa pyyntöjä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
