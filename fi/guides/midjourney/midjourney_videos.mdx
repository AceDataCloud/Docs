Tässä artikkelissa esitellään Midjourney Videos API -integraatio-ohje, jonka avulla voidaan syöttää mukautettuja parametreja Midjourneyn virallisten videoiden luomiseksi.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Midjourney Videos API](https://platform.acedata.cloud/documents/midjourney-videos) -sivulle ja haettava vastaavaa palvelua. Kun olet sivulla, napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka on syöttää vihje `prompt`, luontitoiminto `action`, ja alku- ja loppukehyksen viittauskuvien taulukko `image_url`, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`. Se sisältää pääasiassa kaksi toimintoa: videon luominen (`generate`) ja videon laajentaminen (`extend`). Tarkemmat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/pi72m9.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers -otsikon, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, joka sisältää:

- `image_url`: videon ensimmäisen kehyksen viittauskuvan linkki.
- `end_image_url`: valinnainen, määrittää videon loppukehyksen viittauskuvan.
- `video_id`: videon laajentamiseksi tarvitaan videon ID.
- `video_index`: videon laajentamiseksi on määritettävä, mikä video `video_id`:n mukaan, indeksi alkaa 0:sta, oletusarvo on 0.
- `action`: tämän videon luontitehtävän toiminta, pääasiassa kaksi toimintoa: videon luominen (`generate`), videon laajentaminen (`extend`).
- `prompt`: vihje.
- `mode`: videon luontinopeus, oletusarvo on fast.
- `resolution`: videon tarkkuus, oletusarvo on 720p.
- `loop`: luodaanko silmukkavideo, oletusarvo on false.
- `callback_url`: URL, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/y0cw0p.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavanlaisen tuloksen:

```json
{
  "image_url": "https://storage.fonedis.cc/upload_1751816808164156352.png",
  "image_width": 560,
  "image_height": 688,
  "progress": 100,
  "video_id": "1751816807896311",
  "video_urls": [
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_0.mp4",
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_1.mp4",
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_2.mp4",
    "https://storage.fonedis.cc//video/1c67c36c-8177-4f19-ad72-1dc1567265a6/0_3.mp4"
  ],
  "task_id": "037955e0-deee-4050-baa8-1416300d67e2",
  "success": true
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämän videon luontitehtävän tila.
- `task_id`, tämän videon luontitehtävän ID.
- `image_url`, tämän videon luontitehtävän kansikuva.
- `image_width`, tämän videon luontitehtävän kansikuvan leveys.
- `image_height`, tämän videon luontitehtävän kansikuvan korkeus.
- `video_id`, tämän videon luontitehtävän videon ID.
- `video_urls`, tämän videon luontitehtävän videolinkkien taulukko.

Voit nähdä, että olemme saaneet tyydyttävää videotietoa, ja meidän tarvitsee vain käyttää tuloksessa olevaa `video_urls`-videolinkkiä saadaksemme luodun Midjourney-videon.

Jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/midjourney/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "A cat sitting on a table",
  "image_url": "https://cdn.acedata.cloud/jgo1cw.jpg"
}'
```

## Videon laajennustoiminto

Jos haluat jatkaa jo luodun Kling-videon luomista, voit asettaa parametrin `action` arvoksi `extend` ja syöttää jatkettavan videon ID:n. Videon ID:n hankkiminen tapahtuu peruskäytön mukaan.

Tässä vaiheessa voit nähdä edellä mainitun videon ID:n olevan:

```
"video_id": "1751816807896311"
```

> Huomaa, että tässä videossa `video_id` on luodun videon ID. Jos et tiedä, miten video luodaan, voit viitata edellä mainittuun peruskäyttöön videon luomiseksi.

Seuraavaksi meidän on täytettävä seuraavaan vaiheeseen tarvittavat laajennusvihjeet mukautetun videon luomiseksi, jolloin voimme määrittää seuraavat sisällöt:

- `video_index`: valitse laajennettavan videon indeksi, joka on edellä luodun `video_urls` -taulukon indeksi, joka alkaa 0:sta, oletusarvo on 0.
- `video_id`: laajennettavan videon määritetty ID.
- `action`: tämän laajennettavan videon toiminta, on `extend`.
- `prompt`: vihje.

Esimerkki täytöstä on seuraava:

<p><img src="https://cdn.acedata.cloud/855hnj.png" width="500" class="m-auto"></p>

Kun täyttö on valmis, se luo automaattisesti seuraavan koodin:

<p><img src="https://cdn.acedata.cloud/p58w39.png" width="500" class="m-auto"></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/midjourney/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "prompt": "A cat sitting on a table",
    "video_id": "1751816807896311",
    "video_index": 1
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json
    "video_urls": [
        "https://storage.fonedis.cc//video/a4bd2f43-b925-462d-9725-8aef98403133/0_0.mp4",
        "https://storage.fonedis.cc//video/a4bd2f43-b925-462d-9725-8aef98403133/0_1.mp4",
        "https://storage.fonedis.cc//video/a4bd2f43-b925-462d-9725-8aef98403133/0_2.mp4",
```

On huomattavissa, että tuloksen sisältö on yhdenmukainen edellä mainitun kanssa, mikä toteuttaa videon laajennusvideotoiminnon.

## Asynkroninen palautus

Koska Midjourney Videos API:n generointiaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: asiakas käynnistää pyynnön, kun se määrittää ylimääräisen `callback_url`-kentän, asiakas käynnistää API-pyynnön jälkeen, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, videon tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten toiminta tapahtuu.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, kehittäjän tulisi korvata se omalla rakentamallaan HTTP-palvelimen URL-osoitteella. Tässä esimerkin vuoksi käytetään julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL-osoitteen, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/lali6d.png" width="500" class="m-auto"></p>

Kopioi tämä URL-osoite, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/556e6971-b41f-4fa8-9151-6e91acd0399f`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL-osoitteeseen ja täyttää vastaavat parametrit, tarkka sisältö on kuvassa näkyvä:

<p><img src="https://cdn.acedata.cloud/vk0l0a.png" width="500" class="m-auto"></p>

```
}
```

Odota hetki, niin voit tarkkailla generoitua videon tulosta osoitteessa `https://webhook.site/556e6971-b41f-4fa8-9151-6e91acd0399f`, kuten kuvassa näkyy:

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
