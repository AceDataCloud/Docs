Midjourney Tasks API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä Midjourney Imagine API:n tai Midjourney Describe API:n generoitu tehtävä-ID.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Midjourney Tasks API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Midjourney Tasks API:n avulla voit helposti tarkistaa Midjourney Imagine API:n tai Midjourney Describe API:n tehtävien suoritusstatus.

## Hakuprosessi

Käyttääksesi Midjourney Tasks API:a, sinun on ensin mentävä hakusivulle [Midjourney Imagine API](https://platform.acedata.cloud/documents/e52c028d-897a-4d51-b110-60fccbe6118d) ja haettava vastaavaa palvelua, sitten kopioit Imagine API:n tehtävä-ID:n, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/lx4mwb.png" width="500" class="m-auto"></p>

Lopuksi siirry Tasks API -sivulle [Midjourney Tasks API](https://platform.acedata.cloud/documents/58ea7cc1-c685-40c3-a619-f29f9ac5d8f4) ja hae vastaavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää API:n ilmaiseksi.

## Pyyntöesimerkki

Midjourney Tasks API:a voidaan käyttää Midjourney Imagine API:n ja Midjourney Describe API:n tulosten tarkistamiseen. Tietoa siitä, miten käyttää Midjourney Imagine API:a, katso asiakirjasta [Midjourney Imagine API](https://platform.acedata.cloud/documents/b0e32002-2707-41cc-b103-a15b1f1efdc1). Tietoa siitä, miten käyttää Midjourney Describea, katso [Midjourney Describe API](https://platform.acedata.cloud/documents/d2a04242-507c-4a49-a17a-01bc382c5756).

Otetaan esimerkki Midjourney Imagine API:n palvelusta palautetusta tehtävä-ID:stä ja näytetään, miten tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 7489df4c-ef03-4de0-b598-e9a590793434, seuraavaksi näytetään, miten syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n kutsuavain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `ids`: massakyselyssä käytettävien tehtävä-ID:iden taulukko.
- `action`: tehtävän toimintatapa, tukee `retrieve` (yksittäinen kysely) ja `retrieve_batch` (massakysely).

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "7489df4c-ef03-4de0-b598-e9a590793434",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "7489df4c-ef03-4de0-b598-e9a590793434",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
