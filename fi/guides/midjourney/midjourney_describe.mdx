Midjourney Describe API:n päätoiminto on saada kuvaus kuvasta sen lataamisen kautta. Tämän API:n käyttöön tarvitsee vain välittää kuvatiedoston osoite, ja API palauttaa kuvan yksityiskohtaisen kuvauksen. Monimutkaisia parametrien asetuksia ei tarvita, jotta saa korkealaatuisen kuvan kuvauksen.

Tukee useita kuvamuotoja: riippumatta siitä, onko kyseessä JPEG, PNG tai GIF, kaikki yleiset kuvamuodot voidaan helposti tunnistaa ja käsitellä.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Midjourney Describe API:n liittämisohjeita, jotka auttavat sinua integroimaan ja hyödyntämään tämän API:n voimakkaita toimintoja. Midjourney Describe API:n avulla voit helposti toteuttaa kuvien kuvauksen automatisoinnin ja parantaa liiketoiminnan tehokkuutta.

## Hakuprosessi

Käyttääksesi Midjourney Describe API:a, sinun on ensin mentävä hakusivulle [Midjourney Describe API](https://platform.acedata.cloud/documents/870e973b-712a-4686-ab8b-beae27f129ce) ja haettava vastaavaa palvelua. Kun olet siirtynyt sivulle, napsauta "Acquire"-painiketta, kuten kuvassa on esitetty:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Pyyntöesimerkki

Otetaan esimerkki yhdestä kuvasta ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on maisemakuva, ja seuraavaksi näytämme, kuinka ladataan tämä kuva ja saadaan kuvaus.

### Pyyntöesimerkkikuva

![Esimerkkikuva](https://cdn.acedata.cloud/kg7xp3.png)

### Aseta pyyntöotsikot ja pyyntökeho

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Pyyntökeho** sisältää:

- `image_url`: ladatun kuvatiedoston osoite.

Aseta kuten alla olevassa kuvassa on esitetty:

![](https://cdn.acedata.cloud/eeui10.png)

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/8edj9z.png" width="400" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/describe' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/kg7xp3.png"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/describe"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/kg7xp3.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
