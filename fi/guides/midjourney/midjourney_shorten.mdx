Midjourney Shorten API:n päätoiminto on yhdistää Midjourneyn virallinen `/shorten` (Prompt-analyysi) -komento, analysoida annettu Prompt, tunnistaa sen painoarvoltaan tärkeimmät avainsanat ja luoda 5 tiivistettyä ehdokas-Promptia. Tämä rajapinta soveltuu erinomaisesti:

- Pitkien Promptien tiivistämiseen ennen `imagine`-kutsua, kuvan osuvuuden parantamiseksi;
- Midjourneyn token-painotusten kääntäiseen ymmärtämiseen ehdokas-Promptien avulla, helpottaen Prompt-insinöörityötä;
- Automaattisten työnkulkujen kanssa käyttäjän syöttämien Promptien avainsanojen yhdistämiseen ja tiivistämiseen.

Tässä dokumentissa esitellään Midjourney Shorten API:n integrointiohjeet, jotka auttavat sinua helposti ottamaan tämän API:n käyttöön.

## Hakuprosessi

Midjourney Shorten API:n käyttämiseksi sinun tulee ensin hakea palvelua hakusivulta [Midjourney Shorten API](https://platform.acedata.cloud/documents/f0c6be1d-c084-43ac-bde6-44ef9cf824a2). Sivulle tultuasi napsauta "Acquire"-painiketta.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa voit rekisteröityä ja kirjautua. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, joten API:n käyttö on maksutonta.

## Pyyntöesimerkki

Käytämme esimerkkinä melko pitkää Promptia ja demonstroimme, kuinka API:ta käytetään sen analysointiin ja tiivistämiseen.

### Pyyntöotsikot ja pyyntörunko

**Request Headers** sisältävät:

- `accept`: määrittää vastaanotettavan vastauksen muodon, tässä `application/json`.
- `authorization`: API-avaimesi, jonka voit valita suoraan hakemisen jälkeen.

**Request Body** sisältää:

- `prompt`: analysoitava ja tiivistettävä Prompt-teksti, suositeltavasti englanniksi.

### Koodiesimerkit

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/midjourney/shorten' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "a serene mountain lake at sunrise, mist rising from the water, towering pine trees on the shore, golden hour lighting, ultra detailed, cinematic, 35mm film photography style, masterpiece --ar 16:9 --v 6"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/midjourney/shorten"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "prompt": (
        "a serene mountain lake at sunrise, mist rising from the water, "
        "towering pine trees on the shore, golden hour lighting, ultra "
        "detailed, cinematic, 35mm film photography style, masterpiece "
        "--ar 16:9 --v 6"
    )
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
```

### Vastausesimerkki

Onnistuneen pyynnön jälkeen API palauttaa enintään 5 tiivistettyä ehdokas-Promptia. Esimerkiksi:

```json
{
  "prompts": [
    "a serene mountain lake at sunrise, mist rising from the water, golden hour lighting --ar 16:9",
    "mountain lake sunrise with mist, golden light --ar 16:9 --v 6",
    "tranquil alpine lake, dawn mist, warm golden tones, cinematic --ar 16:9",
    "sunrise over a misty mountain lake, rich golden hour photography --ar 16:9 --style raw",
    "misty lake at dawn, mountains in background, golden sunrise --ar 16:9"
  ]
}
```

Näet, että vastauksessa on `prompts`-kenttä, joka sisältää useita tiivistettyjä ehdokas-Prompteja. Jokainen säilyttää Midjourneyn sisäisesti tärkeimmät avainsanat ja poistaa toistuvat tai turhat kuvaukset.

## Virheenkäsittely

API-kutsun yhteydessä esiintyessä virheitä, API palauttaa vastaavan virhekoodin ja viestin. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Luvaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt rajoituksen.
- `500 api_error`: Palvelinvirhe, jokin meni pieleen palvelimella.
