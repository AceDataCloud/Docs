AI Pass Photo Task API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä AI Pass Photo -tuotanto API:sta saatu tehtävä-ID.

Tässä asiakirjassa käsitellään yksityiskohtaisesti AI Pass Photo Task API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. AI Pass Photo Task API:n avulla voit helposti tarkistaa AI Pass Photo -tuotanto API:n tehtävän suoritusstatus.

## Hakuprosessi

Käyttääksesi AI Pass Photo Task API:a, sinun on ensin mentävä hakusivulle [AI Pass Photo -tuotanto API](https://platform.acedata.cloud/documents/bf7214a3-8447-4157-8a75-f5bb39d5ed1b) ja haettava tarvittavaa palvelua, sitten kopioi AI Pass Photo -tuotanto API:n tehtävä-ID, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/7ezmmn.png" width="500" className="m-auto" /></p>

Lopuksi siirry Tasks API -sivulle [AI Pass Photo Task API](https://platform.acedata.cloud/documents/3a23ee34-8689-406b-9042-7954224348ad) ja hae tarvittavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja kirjautumisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joita voit käyttää tämän API:n ilmaiseksi.

## Pyyntöesimerkki

AI Pass Photo Task API:a voidaan käyttää AI Pass Photo -tuotanto API:n tulosten tarkistamiseen. Lisätietoja AI Pass Photo -tuotanto API:n käytöstä löytyy asiakirjasta [AI Pass Photo -tuotanto API](https://platform.acedata.cloud/documents/d6ea75a4-836e-490a-aee5-7ca911a808fd).

Otetaan esimerkki yhdestä AI Pass Photo -tuotanto API:n palauttamasta tehtävä-ID:stä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: `16f96e95-d95c-46ef-b183-139b9bd1aebd`, seuraavaksi näytetään, kuinka siirretään tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n kutsuavain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/ezsyyd.png" width="500" className="m-auto" /></p>

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/x99wu2.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/headshots/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/headshots/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

Kun kutsut API:ta, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
