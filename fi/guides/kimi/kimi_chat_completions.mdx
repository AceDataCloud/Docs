Kimi on Moonshot AI:n julkaisema AI-mallisarja. Tällä hetkellä suositellaan `kimi-k3.1-pro`-mallia, joka soveltuu pitkän aikavälin ohjelmointiin, monimutkaiseen päättelyyn, visuaaliseen ymmärrykseen ja tietotyöhön; myös `kimi-k3` on edelleen käytettävissä. Kutsutaan OpenAI-yhteensopivan Chat Completions API:n kautta.

Tässä dokumentissa esitellään pääasiassa Kimi Chat Completion API -toimintojen käyttöprosessi, jonka avulla voimme helposti käyttää virallisen Kimin keskustelutoimintoja.

## Hakuprosessi

Kimi Chat Completion API:n käyttämiseksi hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta myönnetään ilmaista käyttökiintiötä, joten voit kokeilla palvelua maksutta; jos käyttökiintiö ei riitä, voit lisätä yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavan sisällön kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme kohtaa: `authorization` voidaan valita suoraan avattavasta luettelosta; `model`-kenttää käytetään Kimi-mallin valintaan, ja suositeltu malli on `kimi-k3.1-pro`; `messages` on keskusteluviestien taulukko, jossa jokainen viesti sisältää kentät `role` ja `content`, ja `role` tukee arvoja `user`, `assistant`, `system` ja `tool`.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi. Voit kopioida koodin ja suorittaa sen suoraan tai testata sitä napsauttamalla suoraan 「Try」-painiketta.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Seuraava on todellinen K3-vastaus, joka on saatu käyttämällä `reasoning_effort: max` -asetusta (käyttämättömät laajennuskentät on jätetty pois):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Palautustulos sisältää useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luotu ID, jota käytetään tämän keskustelutehtävän yksilöivään tunnistamiseen.
- `model `, valittu Kimin virallisen verkkosivuston malli.
- `choices`, Kimin kyselyyn antamat vastaustiedot.
- `usage `: tämän kysymys-vastausparin token-tilastotiedot.

Näistä `choices` sisältää Kimin vastaustiedot, ja sen sisällä oleva `choices` sisältää Kimin vastauksen yksityiskohtaiset tiedot, kuten kuvasta voidaan havaita.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Voidaan nähdä, että `choices`-objektin `content`-kenttä sisältää Kimin vastauksen yksityiskohtaisen sisällön; K3 voi lisäksi palauttaa `reasoning_content`-kentän päättelyprosessin esittämistä varten.

## K3.1 Pro -päättelyintensiteetti

`kimi-k3.1-pro` ottaa päättelyn aina käyttöön. Pyynnön rungon ylimmällä tasolla voidaan asettaa `reasoning_effort` arvoon `low`, `high` tai `max`; älä välitä päättelyn poistavaa määritystä. Malli tukee enintään 1 048 576 tokenin kontekstia, mutta todellinen pyyntöraja määräytyy edelleen nykyisen rajapinnan mukaan. Hinta lasketaan syötteen, tulosteen ja välimuistiosumien käytön perusteella. Katso lisätietoja malliluettelon Pricing-kortista.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

Seuraava K3-esimerkki on säilytetty olemassa olevia integraatioita varten, ja esimerkkivastaus on todella saatu K3-pyynnöstä.

## K3-päättelyintensiteetti

`kimi-k3` ottaa päättelyn aina käyttöön. Pyynnön rungon ylimmällä tasolla tuetaan `reasoning_effort`-kenttää, jonka ainoa tällä hetkellä tuettu arvo on `max`; myös silloin, kun kenttä jätetään pois, käytetään arvoa `max`. `standard`, `high` tai muut merkkijonot saatetaan hyväksyä osittain yhteensopivissa ylävirran toteutuksissa väljästi, mutta niiden ei taata muuttavan päättelykäyttäytymistä, joten älä luota niihin.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

OpenAI SDK:ta käytettäessä kenttä voidaan välittää suoraan:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

Monikierroksisissa keskusteluissa ja työkalukutsuissa palauta edellisen kierroksen täydellinen assistant-viesti takaisin `messages`-kenttään, mukaan lukien `reasoning_content` ja `tool_calls`.

### Viralliset viitteet

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort)：selittää, että Kimi K3 ottaa päättelyn aina käyttöön ja että tällä hetkellä `reasoning_effort`-kentän ainoa tuettu arvo on `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview)：vertailee K3- ja K2-sarjojen päättelyparametreja, konteksti-ikkunoita ja työkalukutsujen eroja.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat)：Moonshotin viralliset Chat Completions -pyynnöt, vastaukset ja OpenAPI-kenttämääritelmät.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa merkkikohtaisen näyttöefektin verkkosivulla.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyyntöotsikon `stream ` -parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodiin on tehtävä vastaavat muutokset, jotta se tukee suoratoistovastauksia.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi riviltä. Kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:
```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Alla on otteita saman todellisen K3 Max -suoratoistovastauksen aloitus-, päättely-, leipäteksti-, lopetus- ja käyttödatakohdista:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Voidaan nähdä, että vastauksessa on paljon `data`-kenttiä, ja `data`-kentän `choices` sisältää uusimman vastaussisällön, mikä on yhdenmukainen yllä esitellyn sisällön kanssa. `choices` sisältää lisätyn vastaussisällön, ja voit liittää sen tulosten perusteella järjestelmääsi. Samalla suoratoistovastauksen päättyminen määritetään `data`-kentän sisällön perusteella: jos sisältö on `[DONE]`, se tarkoittaa, että suoratoistovastaus on kokonaan päättynyt. Palautettu `data`-tulos sisältää useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luotu ID, jota käytetään tämän keskustelutehtävän yksilölliseen tunnistamiseen.
- `model `, valittu Kimin virallisen verkkosivuston malli.
- `choices`, Kimin kyselysanoihin antamat vastaustiedot.

Myös JavaScriptiä tuetaan, esimerkiksi Node.js:n suoratoistokutsukoodi on seuraava:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Muita kieliä voidaan muokata erikseen itse, periaate on sama.

## Monikierroksinen keskustelu

Jos haluat liittää monikierroksisen keskustelutoiminnon, sinun on lähetettävä useita kyselysanoja `messages`-kenttään. Tarkka esimerkki useista kyselysanoista näkyy alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Lähettämällä useita kyselysanoja voidaan helposti toteuttaa monikierroksinen keskustelu. Seuraava on tämän pyynnön saama todellinen K3 Max -vastaus (käyttämättömät laajennuskentät on jätetty pois):

```json
{
  "id": "msg_Rqp8nPGBDHWwBlL4VpxuafOp",
  "object": "chat.completion",
  "created": 1784466628,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "I’m Kimi, an AI assistant developed by Moonshot AI (月之暗面). I don’t have a specific public model version identifier to share from here."
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 134,
    "completion_tokens": 346,
```

Voidaan nähdä, että `choices`-kentän sisältämät tiedot ovat yhdenmukaisia peruskäytön sisällön kanssa. Se sisältää Kimin konkreettisen sisällön useisiin keskusteluihin antamista vastauksista, joten vastaaviin kysymyksiin voidaan vastata useiden keskustelujen sisällön perusteella.

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos virhe ilmenee. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Ei valtuutettu, valtuutustunnus on virheellinen tai puuttuu.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.
