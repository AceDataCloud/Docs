Kimi on Moonshotin julkaisema AI-mallisarja. Tällä hetkellä suositeltu `kimi-k3` on suunnattu pitkän aikavälin ohjelmointiin, agentteihin, monimutkaiseen päättelyyn ja tietotyöhön, ja sitä voidaan kutsua OpenAI-yhteensopivalla Chat Completions API:lla.

Tässä asiakirjassa esitellään Kimi Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista Kimi:n keskustelutoimintoa.

## Hakuprosessi

Käyttääksesi Kimi Chat Completion API:a, sinun on ensin mentävä [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisellä hakemiskerralla saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; jos saldo on riittämätön, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Ensimmäisellä kerralla, kun käytät tätä rajapintaa, sinun on täytettävä vähintään kolme tietoa: `authorization` voidaan valita suoraan alasvetovalikosta; `model` valitaan Kimi-malli, suositellaan käytettäväksi `kimi-k3`; `messages` on keskustelun viestitaulukko, jossa jokaisessa viestissä on `role` ja `content`, joissa `role` tukee `user`, `assistant`, `system` ja `tool`.

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai voit napsauttaa "Try" -painiketta testataksesi.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Seuraavassa on esimerkki todellisesta K3-vastauksesta, joka on saatu käyttämällä `reasoning_effort: max` (käytettävissä olevat laajennuskentät on jätetty pois):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luomisen ID, jota käytetään tämän keskustelutehtävän yksilöimiseen.
- `model`, valittu Kimi:n virallinen malli.
- `choices`, Kimin antamat vastaukset kysymyksiin.
- `usage`: tämän kysymys-vastausparin tokenien tilastotiedot.

`choices` sisältää Kimin vastaustiedot, ja sen sisällä oleva `choices` on Kimin antama tarkka tieto, kuten kuvassa näkyy.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Voit nähdä, että `choices`-kentän `content` sisältää Kimin antaman tarkat vastaukset; K3 voi myös palauttaa `reasoning_content`, joka kuvaa päättelyprosessia.

## K3 Päättelyvoima

`kimi-k3` on aina päättelytilassa. Pyyntökehon ylimmällä tasolla tuetaan `reasoning_effort`-kenttää, ja tällä hetkellä ainoa tuettu arvo on `max`; jos tätä kenttää ei mainita, käytetään myös `max`:ia. `standard`, `high` tai muut merkkijonot voivat olla osittain yhteensopivia, mutta niiden ei voida taata muuttavan päättelykäyttäytymistä, joten älä luota niihin.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "Tarkista tämä koodi ja anna korjaussuunnitelma"}],
    "reasoning_effort": "max"
  }'
```

Käytettäessä OpenAI SDK:ta voit suoraan välittää tämän kentän:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "Suunnittele luotettava tehtäväjono"}],
    reasoning_effort="max",
)
```

Monivaiheisissa keskusteluissa ja työkalukutsuissa, varmista, että edellisen vaiheen koko assistenttiviesti palautetaan `messages`-kenttään, mukaan lukien `reasoning_content` ja `tool_calls`.

### Viralliset viitteet

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): Selittää, että Kimi K3 on aina päättelytilassa, ja että nykyinen `reasoning_effort` ainoa tuettu arvo on `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): Vertaa K3:n ja K2-sarjan päättelyparametreja, kontekstin ikkunaa ja työkalukutsujen eroja.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): Moonshotin viralliset Chat Completions -pyynnöt, vastaukset ja OpenAPI-kenttä määritelmät.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosovelluksille, sillä se mahdollistaa sanan kerrallaan näyttämisen.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutokset näkyvät kuvassa, mutta kutsukoodin on myös tehtävä vastaavat muutokset, jotta se tukee virtaavaa vastausta.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

Kun `stream` on muutettu arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Seuraavassa on otteita samasta todellisesta K3 Max -virtaavasta vastauksesta, joka sisältää aloitus-, päättely-, runko-, lopetus- ja käyttödatapaketit:
```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

```

Voit nähdä, että vastauksessa on monia `data`-kenttiä, ja `data`-kentän `choices` on uusin vastaussisältö, joka on yhdenmukainen edellä esitetyn sisällön kanssa. `choices` on uusi vastaussisältö, jonka voit liittää järjestelmääsi. Samalla virtaavaan vastaukseen päättyminen määräytyy `data`-sisällön mukaan; jos sisältö on `[DONE]`, se tarkoittaa, että virtaava vastaus on päättynyt kokonaan. Palautetussa `data`-tuloksessa on useita kenttiä, jotka on esitelty alla:

- `id`, tämän keskustelutehtävän luomisen ID, jota käytetään tämän keskustelutehtävän yksilöimiseen.
- `model`, valittu Kimi-verkkosivuston malli.
- `choices`, Kimi:n antamat vastaustiedot kysymyksiin.

JavaScript on myös tuettu, esimerkiksi Node.js:n virtauskutsukoodi on seuraava:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hei" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hei")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Muita kieliä voi muokata erikseen, periaate on sama.

## Monivaiheinen keskustelu

Jos haluat liittää monivaiheisen keskustelutoiminnon, sinun on ladattava useita kysymyksiä `messages`-kenttään, useiden kysymysten tarkat esimerkit on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hei! Kuinka voin auttaa sinua tänään?"},{"role":"user","content":"Mikä malli olet?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Lataamalla useita kysymyksiä voit helposti toteuttaa monivaiheisen keskustelun. Alla on tämän pyynnön saama todellinen K3 Max -vastaus (ilman käyttämättömiä laajennuskenttiä):


Voit nähdä, että `choices`-kenttä sisältää tietoja, jotka ovat yhdenmukaisia peruskäytön sisällön kanssa, ja tämä sisältää Kimin vastaukset useisiin keskusteluihin, jolloin voit vastata vastaaviin kysymyksiin useiden keskustelusisältöjen perusteella.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
