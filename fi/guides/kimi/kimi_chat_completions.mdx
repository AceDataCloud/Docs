Kimi on Moonshot AI:n julkaisema tekoälymallien sarja. Tällä hetkellä suositeltu malli on `kimi-k3.1-pro`, joka soveltuu pitkäkestoiseen ohjelmointiin, monimutkaiseen päättelyyn, visuaaliseen ymmärtämiseen ja tietotyöhön. Myös mallia `kimi-k3` voidaan edelleen käyttää. Kutsut tehdään OpenAI-yhteensopivan Chat Completions API:n kautta.

Tässä dokumentissa esitellään pääasiassa Kimi Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallisen Kimi-palvelun keskustelutoimintoja.

## Tuetut mallit

Tällä hetkellä tuettuina ovat neljä mallia: `kimi-k3.1-pro`, `kimi-k3`, `kimi-k2.6` ja `kimi-k2.7-code`. K2.7 Code on suunnattu ohjelmointiin ja työkalujen kutsumiseen, ja sen hinnoittelu vastaa K2.6-mallin vastaavaa tasoa. Älä välitä sille pyynnössä `thinking`-kytkintä tai `reasoning_effort`-parametria. Muiden Kimi-mallien tuki on lopetettu, joten valitse asiakasohjelmassa nimenomaisesti jokin näistä neljästä mallista.

## Hakuprosessi

Kimi Chat Completion API:n käyttämiseksi siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) hakemaan API Token -tunnuksesi ja säilytä se myöhempää käyttöä varten.

![]()

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa voit rekisteröityä ja kirjautua sisään. Kun tämä on suoritettu, sinut palautetaan automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voit käyttää kaikkia alustan palveluita, eikä jokaista palvelua varten tarvitse hakea erillistä tunnusta.** Ensimmäisen hakemuksen yhteydessä saat ilmaista käyttösaldoa, joten voit kokeilla palvelua maksutta. Kun saldo ei riitä, voit ladata yleistä saldoa [hallintapaneelissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme kenttää: `authorization` voidaan valita suoraan avattavasta luettelosta; `model`-kenttää käytetään Kimi-mallin valitsemiseen, ja suositeltu malli on `kimi-k3.1-pro`; `messages` on keskusteluviestien taulukko, jonka jokainen viesti sisältää kentät `role` ja `content`, joista `role` tukee arvoja `user`, `assistant`, `system` ja `tool`.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi. Voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa suoraan ”Try”-painiketta testataksesi sitä.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

Seuraavassa on todellinen K3-vastaus, joka on saatu käyttämällä asetusta `reasoning_effort: max` (käyttämättömät laajennetut kentät on jätetty pois):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

Palautettu tulos sisältää useita kenttiä, jotka esitellään seuraavasti:

- `id`: Tällä luodaan kyseisen keskustelutehtävän tunnus, jonka avulla tehtävä voidaan yksilöidä.
- `model `: Valittu Kimin virallisen palvelun malli.
- `choices`: Kimin kysymykseen antama vastaustieto.
- `usage `: Tämän kysymys- ja vastauskerran tokenien tilastotiedot.

`choices` sisältää Kimin vastaustiedot. Sen sisällä oleva `choices` sisältää Kimin antaman varsinaisen vastauksen, kuten kuvasta voidaan havaita.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

Kuten voidaan nähdä, `choices`-kentän `content` sisältää Kimin vastauksen varsinaisen sisällön. K3 voi myös palauttaa `reasoning_content`-kentän, joka ilmaisee päättelyprosessin.

## K3.1 Pro -päättelyn voimakkuus

`kimi-k3.1-pro` käyttää päättelyä aina. Voit asettaa pyynnön rungon ylimmän tason `reasoning_effort`-kentän arvoksi `low`, `high` tai `max`. Älä välitä asetuksia, jotka poistavat päättelyn käytöstä. Malli tukee enintään 1 048 576 tokenin kontekstia, mutta todellinen pyyntökohtainen yläraja määräytyy edelleen nykyisen rajapinnan mukaan. Hinta lasketaan syöte-, tuloste- ja välimuistiosumien käytön perusteella. Lisätietoja on malliluettelon Pricing-kortissa.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

Seuraava K3-esimerkki säilytetään olemassa olevia integraatioita varten, ja esimerkkivastaus on todella saatu K3-pyynnöllä.

## K3-päättelyn voimakkuus

`kimi-k3` käyttää päättelyä aina. Pyyntö rungon ylimmällä tasolla tukee `reasoning_effort`-kenttää, jonka ainoa tällä hetkellä tuettu arvo on `max`. Jos kenttä jätetään pois, käytetään silti arvoa `max`. Käytä tuettua arvoa.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

OpenAI SDK:ta käytettäessä tämä kenttä voidaan välittää suoraan:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

Monivaiheisissa keskusteluissa ja työkalukutsuissa palauta edellisen kierroksen koko assistant-viesti takaisin `messages`-kenttään, mukaan lukien `reasoning_content` ja `tool_calls`.

### Viralliset viitteet

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): Selittää, että Kimi K3 käyttää päättelyä aina ja että tällä hetkellä `reasoning_effort`-kentän ainoa tuettu arvo on `max`.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): Vertailee K3- ja K2-sarjojen päättelyparametreja, konteksti-ikkunoita ja työkalukutsujen eroja.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): Moonshotin viralliset Chat Completions -pyyntöjen, vastausten ja OpenAPI-kenttien määritelmät.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastausten palauttamista, mikä on erittäin hyödyllistä verkkosivustojen integraatioissa ja mahdollistaa tekstin näyttämisen merkki kerrallaan.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyynnön otsakkeessa olevan `stream ` -parametrin arvoksi `true`.

Muutos tehdään kuvan mukaisesti, mutta kutsukoodia on myös muutettava vastaavasti, jotta se tukee suoratoistovastausta.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>
Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi riviltä. Kooditasolla meidän on tehtävä vastaavat muutokset, jotta voimme vastaanottaa tulokset rivi riviltä.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Alla on otteita saman todellisen K3 Max -suoratoistovastauksen alku-, päättely-, sisältö-, lopetus- ja käyttömäärätietolohkoista:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

Kuten voidaan nähdä, vastaus sisältää useita `data`-kenttiä. `data`-kentän sisällä oleva `choices` sisältää uusimman vastaussisällön, mikä vastaa edellä esiteltyä sisältöä. `choices` sisältää uuden vastaussisällön, ja voit integroida sen järjestelmääsi tulosten perusteella. Samalla suoratoistovastauksen päättyminen määräytyy `data`-kentän sisällön perusteella. Jos sisältö on `[DONE]`, se tarkoittaa, että suoratoistovastaus on päättynyt kokonaan. Palautettu `data`-tulos sisältää useita kenttiä, jotka esitellään seuraavasti:

- `id`, luo tämän keskustelutehtävän ID-tunnuksen, jota käytetään tehtävän yksilölliseen tunnistamiseen.
- `model `, valittu Kimin virallisen verkkosivuston malli.
- `choices`, Kimin kysymykseen antamat vastaustiedot.

Myös JavaScript tukee tätä. Esimerkiksi Node.js:n suoratoistokutsukoodi on seuraava:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java-esimerkkikoodi:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

Muut ohjelmointikielet voidaan muokata erikseen. Periaate on kaikissa sama.

## Monivuoroinen keskustelu

Jos haluat integroida monivuoroisen keskustelutoiminnon, sinun on lähetettävä useita kysymyksiä `messages`-kentässä. Konkreettinen esimerkki useista kysymyksistä on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Lähettämällä useita kysymyksiä voit toteuttaa monivuoroisen keskustelun helposti. Alla on tämän pyynnön tuottama todellinen K3 Max -vastaus (käyttämättömät laajennetut kentät on jätetty pois):


Kuten voidaan nähdä, `choices` sisältää samat tiedot kuin peruskäytössä. Se sisältää Kimin vastauksen useisiin keskustelukysymyksiin, joten vastaavat kysymykset voidaan ratkaista useiden keskustelujen sisällön perusteella.

## Virheenkäsittely

Jos API-kutsun aikana ilmenee virhe, API palauttaa vastaavan virhekoodin ja virheilmoituksen. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, valtuutustunnus on virheellinen tai puuttuu.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt pyyntöjen nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jokin virhe.
