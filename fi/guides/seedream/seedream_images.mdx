Tässä artikkelissa esitellään SeeDream Images Generation API -integrointiohje, jonka avulla voidaan luoda SeeDreamin virallisia kuvia syöttämällä mukautettuja parametreja.

## Hakuprosessi

Jotta voit käyttää SeeDream Images Generation APIa, hanki ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Token -tunnuksesi varalle.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voidaan kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäinen hakemus sisältää ilmaista käyttökiintiötä maksutonta kokeilua varten; kun kiintiö ei riitä, voit ladata yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Peruskäyttö

Tutustutaan ensin peruskäyttötapaan: syöttämällä kehote `prompt`, luontitoiminto `action` ja kuvan koko `size` voidaan saada käsitelty tulos. Ensin on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`, ja sitten on syötettävä kehote. Tarkka sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Voidaan nähdä, että tässä asetimme Request Headers -otsakkeet, mukaan lukien:

- `accept`: Millaisessa muodossa vastaustulos halutaan vastaanottaa; tähän täytetään `application/json`, eli JSON-muoto.
- `authorization`: API-kutsun avain, joka voidaan valita suoraan pudotusvalikosta hakemisen jälkeen.

Lisäksi asetettiin Request Body, mukaan lukien:

- `prompt`: Kehote.
- `model`: Luontimalli, oletuksena `doubao-seedream-5-0-lite-260128` (SeeDream 5.0 Lite, uusin). Tukee malleja `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`. Näistä `doubao-seedream-5-0-pro-260628` (SeeDream 5.0 Pro) on lippulaivamalli yksittäisille kuville ja luo vain yksittäisiä kuvia, **ei tue kuvaryhmiä (`sequential_image_generation`), suoratoistoa (`stream`) eikä verkkohakua (`tools`)**. **`model`-parametrille on välitettävä koko mallimerkkijono (kuten `doubao-seedream-5-0-lite-260128`); lyhenteen, kuten `doubao-seedream-5.0-lite`, välittäminen palauttaa virheen 400.**
- `image`: Syötetyn kuvan tiedot, tukee URL-osoitetta tai Base64-koodausta. `doubao-seedream-5-0-pro-260628` tukee yhden tai usean kuvan syöttöä (enintään 10 kuvaa), ja `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` tukevat yhden tai usean kuvan syöttöä.
- `size`: Määrittää luotavan kuvan kokotiedot ja tukee seuraavia kahta tapaa, joita ei voi käyttää yhdessä. Tapa 1 | Määritä luotavan kuvan resoluutio ja kuvaile kuvan kuvasuhde luonnollisella kielellä promptissa. **Eri mallit tukevat eri esiasetuksia**: `doubao-seedream-5-0-pro-260628` tukee arvoja `1K`/`1.5K`/`2K`; `doubao-seedream-5-0-lite-260128` tukee arvoja `2K`/`3K`/`4K`; `doubao-seedream-4-5-251128` tukee vain arvoja `2K`/`4K`; `doubao-seedream-4-0-250828` tukee arvoja `1K`/`2K`/`4K`. Tapa 2 | Määritä luotavan kuvan leveys- ja korkeuspikseliarvot: oletuksena `2048x2048`, kokonaispikselien ja kuvasuhteen arvoalue vaihtelee mallin mukaan (esimerkiksi 5.0 Pro -mallin kokonaispikselialue on [921600, 4624220], 5.0 Lite / 4.5 -mallien kokonaispikseleiden alaraja on 3,686,400 ja 4.0-mallin alaraja on 921,600).
- `sequential_image_generation`: Kuvaryhmä: syöttämäsi sisällön perusteella luotu ryhmä sisällöllisesti toisiinsa liittyviä kuvia. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` tukevat tätä parametria, oletuksena `disabled`.
- `stream`: Hallitsee, otetaanko suoratoistotulostustila käyttöön. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` tukevat tätä parametria, oletuksena `false`.
- `response_format`: Määrittää luodun kuvan palautusmuodon. Oletuksena on `url`, ja myös `b64_json` on tuettu.
- `watermark`: Lisätäänkö luotuun kuvaan vesileima. Oletuksena on `true`.
- `output_format`: Määrittää luodun kuvan tiedostomuodon, tukee muotoja `jpeg` (oletus) ja `png`. Vain `doubao-seedream-5-0-pro-260628` ja `doubao-seedream-5-0-lite-260128` tukevat tätä.
- `tools`: Määrittää työkalut, joita mallin tulee kutsua. Tällä hetkellä tuetaan `web_search`-toimintoa (verkkohaku). Vain Seedream 5.0 Lite tukee tätä.
- `optimize_prompt_options`: Kehotteen optimointiasetukset. 5.0 Pro tukee arvoja `standard`/`fast`; 5.0 Lite ja 4.5 tukevat vain arvoa `standard`; 4.0 tukee arvoja `standard`/`fast`.
- `background`: Vain 5.0 Pro -mallin yksittäisen kuvan muokkaus tukee tätä. `transparent` edellyttää yhden läpinäkyvyyskanavalla varustetun PNG-kuvan syöttämistä, ja `output_format`-arvon on oltava `png`; `opaque` tarkoittaa tavallista läpinäkymätöntä taustaa.
- `layer_decomposition`: Vain 5.0 Pro tukee tätä. Kun arvoksi asetetaan `true`, on syötettävä yksi PNG/JPEG-kuva; `prompt`-parametria ei tarvitse välittää automaattista erottelua varten, tai elementit voidaan määrittää luonnollisella kielellä/`<bbox>`-merkinnällä; `size` tukee arvoja `auto`/`1K`/`1.5K`/`2K`. Tätä tilaa ei voi käyttää yhdessä kuvaryhmien, suoratoiston, verkkonhaun tai `background`-parametrin kanssa.
- `callback_url`: URL-osoite, johon tulos pitää palauttaa takaisinsoitolla.
- `async`: Käsitelläänkö asynkronisessa tilassa. Kun arvoksi asetetaan `true`, rajapinta palauttaa välittömästi `task_id`-arvon ilman, että `callback_url`-osoitetta tarvitsee antaa, minkä jälkeen tulos haetaan kyselemällä `/seedream/tasks`-päätepistettä.

Valinnan jälkeen voidaan havaita, että oikealle puolelle luodaan myös vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Testaus voidaan suorittaa napsauttamalla 「Try」-painiketta. Kuten yllä olevassa kuvassa näkyy, saimme tässä seuraavan tuloksen:
```json
{
  "success": true,
  "task_id": "80ceeed1-17d4-4eb7-82e0-18b34290f36e",
  "trace_id": "96b7fdc8-0fc8-4e2e-82a9-83c0a82f0a08",
  "data": [
    {
      "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting",
      "size": "2048x2048",
      "image_url": "https://cdn.acedata.cloud/assets/examples/seedream/db93b46e-c302-4676-8a11-63f0ba638a27-1c6f66f6b7e8.jpg"
    }
  ]
}
```

Palautustulos sisältää useita kenttiä, jotka esitellään seuraavasti:

- `success`, videonluontitehtävän tämänhetkinen tila.
- `task_id`, videonluontitehtävän tämänhetkinen ID.
- `trace_id`, videonluonnin tämänhetkinen seuranta-ID.
- `data`, kuvantuotantotehtävän tämänhetkinen tulosluettelo.
  - `image_url`, kuvantuotantotehtävän tämänhetkinen linkki.
  - `prompt`, kehoteteksti.
  - `size`: luodun kuvan pikselit

Voimme nähdä, että saimme tyydyttävät kuvatiedot, ja meidän tarvitsee vain hakea luotu SeeDream-kuva tuloksessa olevan `data`-kohdan kuvalinkin osoitteen perusteella.

Lisäksi, jos haluat luoda vastaavan integrointikoodin, voit kopioida sen suoraan. Esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## Kuvatehtävän muokkaaminen

Jos haluat muokata jotakin kuvaa, parametrille `image` on ensin välitettävä muokattavan kuvan linkki

- model：tässä kuvamuokkaustehtävässä käytettävä malli, `doubao-seedream-5-0-pro-260628`、`doubao-seedream-5-0-lite-260128`、`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828` tukevat kaikki kuvan syöttämistä.
- image：lataa muokattava kuva, yksi tai useampi

Täyttöesimerkki on seuraava:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Napsauta suorita, niin voit huomata, että tulos saadaan välittömästi, seuraavasti:

```json
{
  "success": true,
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
  "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
  "data": [
    {
      "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
    }
  ]
}
```

Voimme nähdä, että luotu tulos on alkuperäisen kuvan muokkauksen tulos, ja tulos on samanlainen kuin yllä.

## Tasojen erottelu (Seedream 5.0 Pro)

Tasojen erottelu jakaa yhden syötekuvan yhdeksi taustakuvaksi ja enintään 16 itsenäisesti muokattavaksi läpinäkyväksi PNG-tasoksi. Seuraava pyyntö antaa mallin tunnistaa pääelementit automaattisesti; jos haluat määrittää elementtejä, voit lisätä `prompt`-kentän, ja voit myös käyttää kehotetekstissä normalisoituja `<bbox>`-koordinaatteja.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

Palautettu `data` on järjestetty `z_index`-arvon mukaan alhaalta ylös. Taustakuvan `z_index` on 0; tasot sisältävät myös `name`-, `description`- ja `bounding_box.absolute`/`normalized`-kentät. Kun sommittelet uudelleen absoluuttisia koordinaatteja käyttäen, skaalaa taso kokoon `[right-left, bottom-top]`, sijoita se kohtaan `[left, top]` ja pinoa ne sitten `z_index`-arvon nousevassa järjestyksessä. Jos minkä tahansa tason luonti epäonnistuu, koko erottelu epäonnistuu.

## Suoratoistotuloste

Kun Lite/4.x:ssä asetetaan `stream: true`, pyynnön otsakkeessa käytetään `accept: application/x-ndjson`. Rajapinta palauttaa riveittäin `image_generation.partial_succeeded`- tai `image_generation.partial_failed`-tapahtumia ja palauttaa lopuksi ainoan `image_generation.completed`-tapahtuman sekä lopullisen `usage`-arvon; vain valmistumistapahtuma käynnistää laskutuksen kerran. Suoratoistotilaa ei voi käyttää yhdessä `async`- tai `callback_url`-asetuksen kanssa.

## Asynkroninen takaisinsoitto

Koska SeeDream Images Generation API:n luontiaika on suhteellisen pitkä, noin 1–2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden jatkuvasti auki, mikä aiheuttaa ylimääräistä järjestelmäresurssien kulutusta, joten tämä API tarjoaa myös tuen asynkronisille takaisinsoitoille.

Kokonaisprosessi on seuraava: kun asiakas käynnistää pyynnön, se määrittää lisäksi `callback_url`-kentän. Kun asiakas käynnistää API-pyynnön, API palauttaa välittömästi tuloksen, joka sisältää `task_id`-kentän tiedot ja edustaa nykyisen tehtävän ID:tä. Kun tehtävä on valmis, kuvanluonnin tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, joka sisältää myös `task_id`-kentän, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Jos sinulla ei ole takaisinsoittoa varten julkista osoitetta, voit myös olla määrittämättä `callback_url`-kenttää ja asettaa pyynnössä `async`-kentän arvoksi `true`. Tällöin rajapinta palauttaa myös välittömästi `task_id`-arvon, mutta ei lähetä tulosta. Sinun on välitettävä kyseinen `task_id` ja kutsuttava `/seedream/tasks`-rajapintaa tehtävän tilan kyselyyn saadaksesi lopullisen tuloksen.

Seuraavaksi tutustumme esimerkin avulla siihen, miten toimitaan käytännössä.

Napsauta suorita, niin voit huomata, että tulos saadaan välittömästi, seuraavasti:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Sisältö on seuraava:
```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Tuloksissa näkyy `task_id`-kenttä, ja muut kentät ovat samanlaisia kuin yllä. Tämän kentän avulla voidaan toteuttaa tehtävän yhdistäminen.

## Virheenkäsittely

API:a kutsuttaessa, jos kohdataan virhe, API palauttaa vastaavan virhekoodin ja tiedon. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Ei valtuutettu, valtuutustunnus on virheellinen tai puuttuu.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, palvelimella tapahtui virhe.

### Esimerkki virhevastausta

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
