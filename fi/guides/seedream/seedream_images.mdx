Tässä dokumentissa esitellään SeeDream-kuvien generointirajapinnan (API) liittäminen, jonka avulla voi syöttää mukautettuja parametreja ja luoda SeeDreamin virallisia kuvia.

## Hakuprosessi

API:n käyttämiseksi tulee ensin hakea palvelua osoitteesta [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). Sivulle siirryttyäsi napsauta "Acquire"-painiketta, kuten alla olevassa kuvassa:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, joten API:a voi käyttää ilmaiseksi.

## Peruskäyttö

Ensiksi tutustutaan peruskäyttötapaan: syötetään kehoteteksti `prompt`, generointitoiminto `action` ja kuvan koko `size`, jolloin saadaan käsitelty tulos. Tarvitaan yksinkertaisesti `action`-kenttä, jonka arvoksi asetetaan `generate`, ja lisäksi syötetään kehoteteksti. Esimerkki:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Request Headers -otsikossa määritellään:

- `accept`: haluttu vastausmuoto, tässä `application/json` eli JSON-muodossa.
- `authorization`: API-avaimesi, jonka voit valita alasvetovalikosta hakemuksen jälkeen.

Request Body -osassa määritellään:

- `prompt`: kehoteteksti.
- `model`: generointimalli, oletuksena `doubao-seedream-5.0-lite`. Tuettuja malleja ovat `doubao-seedream-5.0-lite` (uusin), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i` ja `doubao-seededit-3.0-i2i`.
- `image`: syötettävä kuva, voi olla URL tai Base64-koodattu. `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0` tukevat yksittäistä tai useampaa kuvaa, `doubao-seededit-3.0-i2i` tukee vain yhtä kuvaa, ja `doubao-seedream-3.0-t2i` ei tue tätä parametria.
- `size`: määrittää kuvan koon, tuettu kahdella tavalla, joita ei saa yhdistää:
  - Tapa 1: määritä resoluutio ja kuvaile luonnollisella kielellä kuvasuhde promptissa. Mallien tuetut esiasetukset vaihtelevat: `doubao-seedream-5.0-lite` tukee `2K`/`3K`/`4K`; `doubao-seedream-4.5` tukee vain `2K`/`4K`; `doubao-seedream-4.0` tukee `1K`/`2K`/`4K`; `doubao-seedream-3.0-t2i` ja `doubao-seededit-3.0-i2i` eivät tue esiasetuksia, vaan hyväksyvät vain tavan 2.
  - Tapa 2: määritä kuvan leveys ja korkeus pikseleinä, oletuksena `2048x2048`. Kokonaispikselimäärän ja kuvasuhteen arvot vaihtelevat mallin mukaan (esim. 5.0/4.5 minimi 3 686 400 pikseliä, 4.0 minimi 921 600, 3.0-t2i/seededit-3.0-i2i välillä [512x512, 2048x2048]).
- `seed`: satunnaissiementä, jolla ohjataan mallin satunnaisuutta. Arvoalue [-1, 2147483647]. Tukee vain `doubao-seedream-3.0-t2i`.
- `sequential_image_generation`: sarjakuvasarja, jossa luodaan toisiinsa liittyviä kuvia syötteen perusteella. Tukee `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0`. Oletuksena `disabled`.
- `stream`: ohjaa virtaustilan käyttöä. Tukee samoja malleja kuin yllä, oletuksena `false`.
- `guidance_scale`: mallin tuloksen ja promptin yhdenmukaisuuden aste, suurempi arvo tarkoittaa vahvempaa yhteyttä. Arvoalue [1, 10]. Oletusarvot: `doubao-seedream-3.0-t2i` 2.5, `doubao-seededit-3.0-i2i` 5.5, muut mallit eivät tue.
- `response_format`: kuvan palautusmuoto, oletuksena `url`, tukee myös `b64_json`.
- `watermark`: lisätäänkö vesileima kuviin, oletuksena `true`.
- `output_format`: tiedostomuoto, tukee `jpeg` (oletus) ja `png`. Tukee vain `doubao-seedream-5.0-lite`.
- `tools`: mallin käyttämät työkalut, tällä hetkellä `web_search` (verkkohaku). Tukee vain `doubao-seedream-5.0-lite`.
- `callback_url`: URL, johon palautetaan tulokset.

Valinnan jälkeen oikealle puolelle muodostuu vastaava koodiesimerkki, kuten alla:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Napsauttamalla "Try"-painiketta voit testata pyyntöä. Kuvassa näkyy esimerkkivastaus:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Vastaus sisältää seuraavat kentät:

- `success`: kuvan generointitehtävän tila.
- `task_id`: tehtävän tunniste.
- `trace_id`: seuranta-ID.
- `data`: lista generointituloksista.
  - `image_url`: kuvan URL.
  - `prompt`: kehoteteksti.
  - `size`: kuvan pikselikoko.

Näin ollen saamme halutun kuvan osoitteesta `data`-kentän linkin kautta.

Voit myös kopioida suoraan liitäntäkoodin, esimerkiksi CURL-komento:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Kuvan muokkaustehtävä

Jos haluat muokata tiettyä kuvaa, sinun on annettava `image`-parametrina muokattavan kuvan URL.

- `model`: käytettävä malli, `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0` tukevat yksittäistä tai useampaa kuvaa, `doubao-seededit-3.0-i2i` tukee vain yhtä kuvaa.
- `image`: muokattava kuva(t), yksi tai useampi.

Esimerkki:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Suorita pyyntö, ja saat heti vastauksen:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Tuloksena on alkuperäisen kuvan muokkaus, kuten yllä.

## Asynkroninen callback

Koska SeeDream-kuvien generointi kestää noin 1–2 minuuttia, API-pyyntö voi pitää HTTP-yhteyden auki pitkään, mikä kuluttaa järjestelmäresursseja. Siksi API tukee myös asynkronista callback-mekanismia.

Prosessi on seuraava: asiakasohjelma lähettää pyynnön ja määrittää `callback_url`-kentän. API vastaa heti tehtävän `task_id`:llä. Kun tehtävä valmistuu, generoidut tulokset lähetetään POST-muodossa JSONina asiakkaan määrittelemään `callback_url`-osoitteeseen, sisältäen myös `task_id`:n, jolla tehtävät voidaan yhdistää.

Esimerkki:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Sisältö:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Vastaus sisältää `task_id`-kentän, jolla tehtävät yhdistetään.

## Virheenkäsittely

API-kutsun epäonnistuessa palautetaan virhekoodi ja viesti, esimerkiksi:

- `400 token_mismatched`: virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: virheellinen pyyntö, puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: valtuutusvirhe, virheellinen tai puuttuva token.
- `429 too_many_requests`: liikaa pyyntöjä, ylität rajoituksen.
- `500 api_error`: palvelinvirhe.

### Virhevasteen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
