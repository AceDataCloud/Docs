Tässä artikkelissa esitellään SeeDream Images Generation API -rajapinnan integrointiohje. Sen avulla voidaan luoda SeeDreamin virallisia kuvia syöttämällä mukautettuja parametreja.

## Hakuprosessi

SeeDream Images Generation API -rajapinnan käyttöä varten siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) ja hanki API Token -tunnuksesi myöhempää käyttöä varten.

![]()

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kun tämä on suoritettu, sinut palautetaan automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voidaan käyttää kaikkia alustan palveluita, eikä jokaiselle palvelulle tarvitse hakea erillistä tunnusta.** Ensimmäisen hakemuksen yhteydessä saat ilmaista käyttösaldoa, jolla voit kokeilla palvelua maksutta. Kun saldo ei riitä, voit ladata yleistä saldoa [hallintapaneelissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Mallin valinta

| Malli | Käyttötarkoitus |
| ----------------------------------------------------------- | ------------------------------- |
| `doubao-seedream-5-5-261028` | Monivaiheinen muokkaus, tekstistä läpinäkyvien kuvien luominen, useisiin viitekuviin perustuva läpinäkyvien kuvien muokkaus, tasojen erottelu ja tekstielementtien tunnistaminen |
| `doubao-seedream-5-0-flash-260915` | Yksittäisten kuvien luominen pienellä viiveellä, useisiin viitekuviin perustuva muokkaus, läpinäkyvien kuvien muokkaus ja tasojen erottelu |
| `doubao-seedream-5-0-pro-260628` | Yksittäisten kuvien luominen, tarkka muokkaus, läpinäkyvien kuvien muokkaus ja tasojen erottelu |
| `doubao-seedream-5-0-lite-260128` | Yksittäiset kuvat, kuvakokoelmat, suoratoistotulosteet ja verkkohaku |
| `doubao-seedream-4-5-251128` / `doubao-seedream-4-0-250828` | Vanhemman version kuvien luominen ja muokkaaminen |

Versiot 5.5 ja 5.0 Flash käyttävät samaa `POST /seedream/images` -rajapintaa. Molemmat tukevat tarkkuuksia `1K`, `1.5K` ja `2K` sekä enintään 10 viitekuvaa. Molempien mallien tasojen erottelutehtävä hyväksyy vain yhden kuvan ja palauttaa URL-osoitteen. Versiossa 5.5 voidaan asettaa `layer_decomposition_options: {"max_images": 12, "text_recognition": true}`. Tuloksena voidaan palauttaa enintään 100 kuvaa (mukaan lukien pohjakuva), ja tunnistetut tekstielementit palautetaan kentässä `data[].text_recognition` riveittäin tekstin ja tyylin kanssa. Versio 5.0 Flash palauttaa enintään yhden pohjakuvan ja 16 tasoa.

Versio 5.5 tukee läpinäkyvien PNG-kuvien suoraa luomista asetuksella `background: "transparent"`. Versiossa 5.0 Flash läpinäkyvän kuvan muokkaaminen edellyttää viitekuvaa, jossa on läpinäkyvyyskanava. Versio 5.5 veloittaa onnistuneesti tuotetun kuvan pikselitarkkuuden mukaan sekä lisää 0,13 Credits jokaisesta syötetystä viitekuvasta. Versio 5.0 Flash veloittaa 0,31 Credits jokaisesta onnistuneesti tuotetusta kuvasta, ja viitekuvat ovat maksuttomia. Tasojen erottelusta veloitetaan todellisuudessa onnistuneesti tuotettujen kuvien lukumäärän mukaan, ja pohjakuva lasketaan mukaan. Katso [reaaliaikainen hinnoittelu](https://platform.acedata.cloud/services/seedream?tab=pricing).

## Peruskäyttö

Tutustutaan ensin peruskäyttötapaan. Syöttämällä kehotteen `prompt`, generointitoiminnon `action` ja kuvan koon `size` voidaan saada käsitelty tulos. Ensin on välitettävä yksinkertainen `action`-kenttä, jonka arvoksi asetetaan `generate`. Tämän jälkeen meidän on syötettävä myös kehote. Tarkempi sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Kuten voidaan nähdä, tässä määritimme Request Headers -otsakkeet, mukaan lukien:

- `accept`: Määrittää, missä muodossa haluat vastaanottaa vastauksen. Tässä arvoksi asetetaan `application/json`, eli JSON-muoto.
- `authorization`: API-rajapinnan kutsumiseen käytettävä avain, jonka voi valita suoraan avattavasta valikosta hakemuksen jälkeen.

Lisäksi määritimme Request Body -sisällön, mukaan lukien:

- `prompt`: Kehote.
- `model`: Anna yllä olevassa taulukossa oleva täydellinen mallin tunniste.
- `image`: Syötekuvan URL-osoite, Base64-merkkijono tai taulukko. Versiot 5.5, 5.0 Pro ja 5.0 Flash tukevat enintään 10 viitekuvaa.
- `size`: Tarkkuustaso tai `leveysxkorkeus`. Versiot 5.5, 5.0 Pro ja 5.0 Flash tukevat arvoja `1K`, `1.5K` ja `2K`. Versio 5.0 Lite tukee arvoja `2K`, `3K` ja `4K`.
- `sequential_image_generation`: Kuvakokoelman luominen: luo syöttämäsi sisällön perusteella joukon toisiinsa liittyviä kuvia. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128` ja `doubao-seedream-4-0-250828` tukevat tätä parametria. Oletusarvo on `disabled`.
- `stream`: Määrittää, otetaanko suoratoistotulostustila käyttöön. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128` ja `doubao-seedream-4-0-250828` tukevat tätä parametria. Oletusarvo on `false`.
- `response_format`: Määrittää luodun kuvan palautusmuodon. Oletusarvo on `url`, ja myös `b64_json` on tuettu.
- `watermark`: Määrittää, lisätäänkö luotuun kuvaan vesileima. Oletusarvo on `true`.
- `output_format`: Tulostusmuoto voi olla `jpeg` tai `png`. Version 5.5 oletusarvo on PNG, kun taas versioiden 5.0 Pro/Flash/Lite oletusarvo on JPEG.
- `tools`: Määrittää mallin käyttämät työkalut. Tällä hetkellä tuettu on `web_search` (verkkohaku). Vain Seedream 5.0 Lite tukee tätä toimintoa.
- `optimize_prompt_options`: Kehotteen optimointiasetukset. Versio 5.0 Pro tukee arvoja `standard`/`fast`; versiot 5.5, 5.0 Flash, 5.0 Lite ja 4.5 tukevat vain arvoa `standard`; versio 4.0 tukee arvoja `standard`/`fast`.
- `background`: Tukee arvoja `transparent` ja `opaque`. Versio 5.5 tukee lisäksi arvoa `auto`. Läpinäkyvä tuloste käyttää PNG-muotoa.
- `layer_decomposition`: Versiot 5.5, 5.0 Pro ja 5.0 Flash tukevat tätä toimintoa. Kun arvoksi asetetaan `true`, syötteeksi on annettava yksi PNG/JPEG-kuva. `prompt`-kentän voi jättää pois automaattista tasojen erottelua varten tai elementit voidaan määrittää luonnollisella kielellä tai käyttämällä `<bbox>`-merkintää. `size` tukee arvoja `auto`/`1K`/`1.5K`/`2K`. Tätä tilaa ei voi käyttää samanaikaisesti kuvakokoelmien, suoratoiston, verkk haun tai `background`-asetuksen kanssa.
- `callback_url`: URL-osoite, johon tulokset palautetaan.
- `async`: Määrittää, käsitelläänkö pyyntö asynkronisessa tilassa. Kun arvoksi asetetaan `true`, rajapinta palauttaa välittömästi `task_id`-tunnisteen. `callback_url`-osoitetta ei tarvitse antaa, ja tulokset voidaan hakea myöhemmin kyselemällä `/seedream/tasks`-rajapintaa.

Valinnan jälkeen huomaat, että myös vastaava koodi luodaan oikealle puolelle seuraavan kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Napsauttamalla ”Try”-painiketta voit suorittaa testin. Kuten yllä olevasta kuvasta näkyy, saamme seuraavan tuloksen:
```json
{
  "success": true,
  "task_id": "80ceeed1-17d4-4eb7-82e0-18b34290f36e",
  "trace_id": "96b7fdc8-0fc8-4e2e-82a9-83c0a82f0a08",
  "data": [
    {
      "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting",
      "size": "2048x2048",
      "image_url": "https://cdn.acedata.cloud/assets/examples/seedream/db93b46e-c302-4676-8a11-63f0ba638a27-1c6f66f6b7e8.jpg"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, joiden kuvaukset ovat seuraavat:

- `success`, videon luontitehtävän senhetkinen tila.
- `task_id`, videon luontitehtävän tunnus.
- `trace_id`, videon luontitehtävän jäljitystunnus.
- `data`, kuvan luontitehtävän tulosluettelo.
  - `image_url`, kuvan luontitehtävän linkki.
  - `prompt`, kehote.
  - `size`: luodun kuvan pikselikoko.

Kuten näemme, saimme haluamamme kuvatiedot. Meidän tarvitsee vain hakea luotu SeeDream-kuva tuloksen `data`-kentässä olevan kuvan linkkiosoitteen avulla.

Lisäksi, jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan. Esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## Kuvan muokkaustehtävä

Jos haluat muokata tiettyä kuvaa, parametrille `image` on ensin annettava muokattavan kuvan linkki.

- model: Anna yllä olevassa taulukossa tuetun kuvanmuokkausmallin täydellinen mallin tunnus.
- image: Lataa muokattava kuva, yksi tai useampi.

Esimerkki täytöstä:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat Suorita, huomaat, että tulos saadaan välittömästi seuraavasti:

```json
{
  "success": true,
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
  "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
  "data": [
    {
      "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
    }
  ]
}
```

Kuten näemme, luotu tulos on alkuperäisen kuvan muokattu versio, ja tulos on samankaltainen kuin edellä.

## Tasojen erottelu (Seedream 5.0 Pro)

Tasojen erottelu jakaa yhden syötekuvan yhdeksi taustakuvaksi ja enintään 16 erikseen muokattavaksi läpinäkyväksi PNG-tasoksi. Seuraavassa pyynnössä mallia pyydetään tunnistamaan tärkeimmät elementit automaattisesti. Jos haluat määrittää elementit itse, voit lisätä `prompt`-parametrin ja käyttää kehotteessa myös normalisoituja `<bbox>`-koordinaatteja.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

Palautetun `data`-kentän sisältö on järjestetty `z_index`-arvon mukaan alimmasta ylimpään. Taustakuvan `z_index`-arvo on 0. Tasot sisältävät myös kentät `name`, `description` ja `bounding_box.absolute`/`normalized`. Kun kuva kootaan uudelleen absoluuttisten koordinaattien avulla, skaalaa taso kokoon `[right-left, bottom-top]`, sijoita se kohtaan `[left, top]` ja aseta tasot päällekkäin `z_index`-arvon nousevassa järjestyksessä. Jos minkä tahansa tason luominen epäonnistuu, koko erottelutehtävä epäonnistuu.

## Virtaava tulostus

Kun Lite/4.x-mallissa asetetaan `stream: true`, pyynnön otsakkeessa käytetään arvoa `accept: application/x-ndjson`. Rajapinta palauttaa riveittäin tapahtumia `image_generation.partial_succeeded` tai `image_generation.partial_failed` ja lopuksi yhden `image_generation.completed`-tapahtuman sekä lopullisen `usage`-tiedon. Vain valmistumistapahtuma käynnistää laskutuksen kerran. Virtaustilaa ei voi käyttää yhdessä `async`- tai `callback_url`-asetuksen kanssa.

## Asynkroninen takaisinkutsu

Koska SeeDream Images Generation API:n luontiaika on suhteellisen pitkä, noin 1–2 minuuttia, HTTP-pyyntö pysyy avoinna, jos API ei vastaa pitkään aikaan, mikä kuluttaa ylimääräisiä järjestelmäresursseja. Siksi tämä API tukee myös asynkronisia takaisinkutsuja.

Koko prosessi toimii seuraavasti: Kun asiakas lähettää pyynnön, se määrittää lisäksi `callback_url`-kentän. Kun asiakas on lähettänyt API-pyynnön, API palauttaa välittömästi tuloksen, joka sisältää `task_id`-kentän eli nykyisen tehtävän tunnuksen. Kun tehtävä on valmis, luodun kuvan tulos lähetetään asiakkaan määrittämään `callback_url`-osoitteeseen POST JSON -muodossa. Lähetys sisältää myös `task_id`-kentän, joten tehtävän tulos voidaan yhdistää tunnuksen avulla.

Jos sinulla ei ole julkista verkko-osoitetta takaisinkutsua varten, voit jättää `callback_url`-kentän määrittämättä ja asettaa pyynnön `async`-kentän arvoksi `true`. Tällöin rajapinta palauttaa myös välittömästi `task_id`-tunnuksen, mutta ei lähetä tulosta. Sinun on käytettävä kyseistä `task_id`-tunnusta `/seedream/tasks`-rajapinnan kutsumiseen ja tehtävän tilan kyselemiseen lopullisen tuloksen saamiseksi.

Seuraavaksi tutustumme esimerkin avulla siihen, miten tämä käytännössä tehdään.

Kun napsautat Suorita, huomaat, että tulos saadaan välittömästi seuraavasti:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Sisältö on seuraava:
```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Pidä mallin poseeraus ja nestemäisen vaatteen virtaava muoto muuttumattomina. Muuta vaatteen materiaali hopeametallista täysin läpinäkyväksi vedeksi (tai lasiksi). Mallin ihon yksityiskohdat näkyvät nesteen virtauksen läpi. Valon ja varjon vaikutelma muuttuu heijastuksesta taittumiseksi.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]

```

Tuloksessa näkyy `task_id`-kenttä, ja muut kentät ovat samankaltaisia kuin edellä. Tämän kentän avulla voidaan yhdistää tehtäviä toisiinsa.

## Virheiden käsittely

Jos API:n kutsumisen yhteydessä tapahtuu virhe, API palauttaa vastaavan virhekoodin ja virheilmoituksen. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Käyttöoikeus evätty, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, pyyntöraja on ylitetty.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jokin virhe.

### Esimerkki virhevastauksesta

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
