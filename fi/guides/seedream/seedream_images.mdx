Tässä artikkelissa esitellään SeeDream Images Generation API -integraatio-ohjeet, jonka avulla voidaan luoda SeeDreamin virallisia kuvia syöttämällä mukautettuja parametreja.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka on syöttää kehotussana `prompt`, toimintatapa `action` ja kuvan koko `size`, jolloin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`, ja sitten meidän on syötettävä kehotussana, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, joka sisältää:

- `prompt`: kehotussana.
- `model`: luontimalli, oletusarvo `doubao-seedream-4.0`.
- `image`: syötettävän kuvan tiedot, tukee URL-osoitteita tai Base64-koodattua tietoa. Näistä `doubao-seedream-4.5`, `doubao-seedream-4.0` tukevat yksittäistä tai useita kuvia, `doubao-seededit-3.0-i2i` tukee vain yksittäistä kuvaa, `doubao-seededit-3.0-t2i` ei tue tätä parametria.
- `size`: määrittää luotavan kuvan koon, tukee kahta tapaa, joita ei voi sekoittaa. Tapa 1 | Määritä luotavan kuvan resoluutio ja kuvaa kuvasuhde, kuvan muoto tai kuvan käyttötarkoitus luonnollisella kielellä promptissa, lopullinen koko määräytyy mallin mukaan. Tapa 2 | Määritä luotavan kuvan leveys- ja korkeuspixel-arvot: oletusarvo: `2048x2048`, joka vaihtelee mallin mukaan.
- `seed`: satunnaisluku, jota käytetään mallin luoman sisällön satunnaisuuden hallintaan. Arvojen on oltava välillä [-1, 2147483647]. Vain `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i` tukevat tätä parametria.
- `sequential_image_generation`: sarjakuva: kuvasarja, joka perustuu syöttämiisi tietoihin, luodaan joukko toisiinsa liittyviä kuvia. Vain `doubao-seedream-4.5`, `doubao-seedream-4.0` tukevat tätä parametria, oletusarvo `disabled`.
- `stream`: hallitsee, onko virtaava tulostustila käytössä. Vain `doubao-seedream-4.5`, `doubao-seedream-4.0` tukevat tätä parametria, oletusarvo on `false`.
- `guidance_scale`: mallin tulosten ja promptin yhdenmukaisuuden aste, kuvan luomisen vapausaste, myös tunnetaan tekstipainona; mitä suurempi arvo, sitä pienempi malli on vapaa, ja se on vahvemmin yhteydessä käyttäjän syöttämään kehotussanaan. Arvojen on oltava välillä [1, 10]. `doubao-seedream-3.0-t2i` oletusarvo 2.5, `doubao-seededit-3.0-i2i` oletusarvo 5.5, muut eivät tue.
- `response_format`: määrittää luotavan kuvan palautusmuodon. Oletusarvo on `url`, tukee myös `b64_json`.
- `watermark`: lisätäänkö vesileima luotavaan kuvaan. Oletusarvo on `true`.
- `callback_url`: URL, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta, niin voit testata, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämänhetkinen videon luontitehtävän tila.
- `task_id`, tämänhetkinen videon luontitehtävän ID.
- `trace_id`, tämänhetkinen videon luontiseurannan ID.
- `data`, tämänhetkisen kuvan luontitehtävän tuloslista.
  - `image_url`, tämänhetkisen kuvan luontitehtävän linkki.
  - `prompt`, kehotussana.
  - `size`: luotavan kuvan pikselit.

Voit nähdä, että olemme saaneet tyydyttävää kuvaa koskevat tiedot, ja meidän tarvitsee vain käyttää tuloksessa `data`-kuvan linkki saadaksemme luodun SeeDream-kuvan.

Lisäksi, jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Kuvan muokkaustehtävä

Jos haluat muokata tiettyä kuvaa, sinun on ensin syötettävä `image`-parametri, johon on annettava muokattavan kuvan linkki.

- model: tämän muokkaustehtävän käyttämä malli, tämä tehtävä tukee tällä hetkellä `doubao-seedream-4.5`, `doubao-seedream-4.0` tukee yksittäistä tai useita kuvia, `doubao-seededit-3.0-i2i` tukee vain yksittäistä kuvaa.
- image: lataa muokattava kuva, yksi tai useampi.

Esimerkkitäyttö on seuraava:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" class="m-auto"></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Napsauta suorita, ja voit huomata, että saat välittömästi tuloksen, kuten alla:
```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Pidä mallin asento ja nestevaatteen virtaava muoto muuttumattomana. Vaihda vaatemateriaali hopeametallista täysin läpinäkyvään veteen (tai lasiin). Nesteen virtauksen läpi mallin ihon yksityiskohdat ovat näkyvissä. Valo- ja varjoefekti siirtyy heijastuksesta taittumiseen.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Voit nähdä, että luotu efekti on alkuperäisen kuvan muokkaus, ja tulos on samanlainen kuin edellä.

## Asynkroninen palautus

Koska SeeDream Images Generation API:n luomisaika on suhteellisen pitkä, noin 1-2 minuuttia, jos API ei vastaa pitkään, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin, joten tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on: asiakas käynnistää pyynnön, kun se määrittää ylimääräisen `callback_url` kentän, asiakas käynnistää API-pyynnön jälkeen, API palauttaa heti tuloksen, joka sisältää `task_id` kenttäinformaation, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luodun kuvan tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id` kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Alla ymmärrämme esimerkin avulla, miten toimia.

Klikkaamalla suorita, voit huomata, että saat heti tuloksen, kuten seuraavassa:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Sisältö on seuraava:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Pidä mallin asento ja nestevaatteen virtaava muoto muuttumattomana. Vaihda vaatemateriaali hopeametallista täysin läpinäkyvään veteen (tai lasiin). Nesteen virtauksen läpi mallin ihon yksityiskohdat ovat näkyvissä. Valo- ja varjoefekti siirtyy heijastuksesta taittumiseen.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Voit nähdä, että tuloksessa on `task_id` kenttä, muut kentät ovat samanlaisia kuin edellä, tämän kentän avulla voit yhdistää tehtävän.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
