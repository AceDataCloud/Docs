Tässä dokumentissa esitellään SeeDream-kuvien generointirajapinnan (Images Generation API) liittäminen, jonka avulla voit luoda SeeDreamin virallisia kuvia syöttämällä mukautettuja parametreja.

## Hakuprosessi

Rajapinnan käyttämiseksi sinun tulee ensin hakea palvelua osoitteesta [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). Sivulle siirryttyäsi napsauta "Acquire"-painiketta, kuten kuvassa:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, joten API:a voi käyttää ilmaiseksi.

## Peruskäyttö

Aloitetaan peruskäyttötavasta: syötä kehoteteksti `prompt`, generointitoiminto `action` ja kuvan koko `size`, niin saat käsitellyn tuloksen. Ensiksi täytyy määrittää kenttä `action` arvolla `generate`. Lisäksi syötetään kehoteteksti, tarkemmat tiedot alla:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Näet, että määritämme Request Headers -otsikot, jotka sisältävät:

- `accept`: haluttu vastausformaatti, tässä `application/json` eli JSON-muodossa.
- `authorization`: API-avaimesi, jonka voit valita alasvetovalikosta hakemuksen jälkeen.

Lisäksi määritetään Request Body -runko, joka sisältää:

- `prompt`: kehoteteksti.
- `model`: generointimalli, oletuksena `doubao-seedream-5.0-lite`. Tuetut mallit ovat `doubao-seedream-5.0-lite` (uusin), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i` ja `doubao-seededit-3.0-i2i`.
- `image`: syötettävä kuva, tukee URL-osoitetta tai Base64-koodausta. Mallit `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0` tukevat yhden tai useamman kuvan syöttöä, `doubao-seededit-3.0-i2i` tukee vain yhtä kuvaa, ja `doubao-seedream-3.0-t2i` ei tue tätä parametria.
- `size`: määrittää generoidun kuvan koon. Tuettuja ovat kaksi vaihtoehtoa, joita ei saa yhdistää:
  - Vaihtoehto 1: määritä resoluutio (esim. `2K`, `3K`, `4K`) ja kuvaile kuvasuhde luonnollisella kielellä kehotteessa.
  - Vaihtoehto 2: määritä kuvan leveys ja korkeus pikseleinä, oletuksena `2048x2048`. Arvot vaihtelevat mallin mukaan.
- `seed`: satunnaissiementä käytetään mallin satunnaisuuden ohjaukseen. Arvoalue [-1, 2147483647]. Tuettu vain malleissa `doubao-seedream-3.0-t2i` ja `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: sarjakuva, joka luo ryhmän toisiinsa liittyviä kuvia syötteen perusteella. Tuettu malleissa `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0`. Oletuksena `disabled`.
- `stream`: ohjaa, käytetäänkö suoratoistotilaa. Tuettu malleissa `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0`. Oletuksena `false`.
- `guidance_scale`: mallin tuottaman tuloksen ja kehotteen vastaavuuden aste. Suurempi arvo tarkoittaa tiukempaa vastaavuutta. Arvoalue [1, 10]. Oletusarvot: `doubao-seedream-3.0-t2i` 2.5, `doubao-seededit-3.0-i2i` 5.5. Muut mallit eivät tue tätä.
- `response_format`: määrittää kuvan palautusmuodon. Oletuksena `url`, vaihtoehtona myös `b64_json`.
- `watermark`: määrittää, lisätäänkö vesileima kuviin. Oletuksena `true`.
- `output_format`: määrittää kuvatiedoston formaatin, tukee `jpeg` (oletus) ja `png`. Vain `doubao-seedream-5.0-lite` tukee tätä.
- `tools`: määrittää mallin käyttämät työkalut, tällä hetkellä tuettu `web_search` (verkkohaut). Vain `doubao-seedream-5.0-lite` tukee.
- `callback_url`: URL, johon tulokset lähetetään takaisin.

Valinnan jälkeen oikealle puolelle muodostuu vastaava koodiesimerkki, kuten kuvassa:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Napsauttamalla "Try"-painiketta voit testata pyyntöä. Kuvassa näkyy saatu tulos:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Palautettu vastaus sisältää useita kenttiä:

- `success`: kuvan generointitehtävän tila.
- `task_id`: tehtävän tunniste.
- `trace_id`: seurantatunniste.
- `data`: generointitulosten lista.
  - `image_url`: generoidun kuvan URL.
  - `prompt`: kehoteteksti.
  - `size`: kuvan pikselikoko.

Näin saat haluamasi kuvan `data`-kentän linkin kautta.

Jos haluat luoda liitäntäkoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Kuvan muokkaustehtävä

Jos haluat muokata kuvaa, parametri `image` on pakollinen ja siihen tulee syöttää muokattavan kuvan URL.

- `model`: käytettävä malli muokkaustehtävään. Mallit `doubao-seedream-5.0-lite`, `doubao-seedream-4.5` ja `doubao-seedream-4.0` tukevat yhden tai useamman kuvan syöttöä, `doubao-seededit-3.0-i2i` tukee vain yhtä kuvaa.
- `image`: muokattava kuva tai kuvat.

Esimerkki täytöstä:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Suorita pyyntö ja saat heti tuloksen:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Tuloksena on muokattu kuva alkuperäisen kuvan pohjalta, kuten yllä.

## Asynkroninen takaisinkutsu

Koska SeeDream-kuvien generointi voi kestää 1–2 minuuttia, API tarjoaa asynkronisen takaisinkutsun tuen. Pitkät synkroniset pyynnöt kuluttavat järjestelmäresursseja, joten tämä on tehokkaampi tapa.

Prosessi toimii siten, että asiakas määrittää pyynnön mukana `callback_url`-kentän. API vastaa välittömästi tehtävän tunnisteella `task_id`. Kun tehtävä on valmis, generoidut kuvat lähetetään POST-pyynnöllä JSON-muodossa asiakkaan määrittelemään `callback_url`-osoitteeseen, sisältäen myös `task_id`:n, jolla tehtävä voidaan yhdistää.

Esimerkki:

Suorita pyyntö ja saat välittömästi vastauksen:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Sisältö:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Vastauksessa on `task_id`-kenttä, jolla tehtävät voidaan yhdistää, muut kentät ovat samankaltaisia kuin aiemmin.

## Virheenkäsittely

API-kutsujen yhteydessä virhetilanteissa palautetaan virhekoodi ja viesti, esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, puuttuvia tai virheellisiä parametreja.
- `400 api_not_implemented`: Virheellinen pyyntö, puuttuvia tai virheellisiä parametreja.
- `401 invalid_token`: Valtuutusvirhe, virheellinen tai puuttuva token.
- `429 too_many_requests`: Liian monta pyyntöä, ylitetty rajoitus.
- `500 api_error`: Palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
