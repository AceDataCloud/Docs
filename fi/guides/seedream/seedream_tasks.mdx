SeeDream Tasks API:n päätoiminto on kysyä tehtävän suoritustilaa syöttämällä SeeDream Images Generation API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään SeeDream Tasks API:n integrointia, jotta voit helposti hyödyntää tämän API:n voimakkaita ominaisuuksia. SeeDream Tasks API:n avulla voit helposti tarkistaa SeeDream Images Generation API:n tehtävien suoritustilan.

## Hakuprosessi

Käyttääksesi SeeDream Tasks API:a, sinun on ensin mentävä hakusivulle [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images) ja haettava tarvittavaa palvelua, sitten kopioi SeeDream Images Generation API:n tehtävä-ID, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Lopuksi siirry Tasks API -sivulle [SeeDream Tasks API](https://platform.acedata.cloud/documents/seedream-tasks) ja hae tarvittavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää API:n ilmaiseksi.

## Pyyntöesimerkki

SeeDream Tasks API:a voidaan käyttää SeeDream Images Generation API:n tulosten tarkistamiseen. Lisätietoja SeeDream Images Generation API:n käytöstä löytyy asiakirjasta [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images-integration).

Otetaan esimerkki yhdestä SeeDream Images Generation API:n palauttamasta tehtävä-ID:stä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 20068983-0cc9-4c6a-aeb6-9c6a3c668be0, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa näkyy:

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/b0wt0d.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/seedream/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "a6e0d456-189b-4c78-9232-2fe72166ab39",
  "action": "retrieve"
}'
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa tämän tehtävän yksityiskohtaiset tiedot. Esimerkiksi:

```json
{
  "success": true,
  "task_id": "84d1544a-9043-4dde-a98b-e889dacd75f6",
  "trace_id": "176acf03-7ca7-4fc6-85db-e3724d4f59eb",
  "data": [
    {
      "prompt": "valkoinen siamilainen kissa",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/6e5f9085-cc4a-4801-b77b-31550129ff19.jpg"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tämänhetkinen videon luontitehtävän tila.
- `task_id`, tämänhetkinen videon luontitehtävän ID.
- `trace_id`, tämänhetkinen videon luontiseurannan ID.
- `data`, tämänhetkisen kuvan luontitehtävän tulosten lista.
  - `image_url`, tämänhetkisen kuvan luontitehtävän linkki.
  - `prompt`, vihje.
  - `size`: luodun kuvan pikselit

- `ids`: ladattujen tehtävä-ID:iden taulukko.
- `action`: tehtävän toimintatapa.

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### 错误响应示例

```json

  "error": {

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
