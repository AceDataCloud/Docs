Veo Tasks API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä Veo Videos Generation API:sta saatu tehtävä-ID.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Veo Tasks API:n integrointia, jotta voit helposti hyödyntää tämän API:n voimakkaita ominaisuuksia. Veo Tasks API:n avulla voit helposti tarkistaa Veo Videos Generation API:n tehtävien suoritusstatus.

## Hakuprosessi

Käyttääksesi Veo Videos Generation API:a, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palat takaisin nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; kun saldo on vähissä, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

## Pyyntöesimerkki

Veo Tasks API:a voidaan käyttää Veo Videos Generation API:n tulosten kysymiseen. Lisätietoja Veo Videos Generation API:n käytöstä löytyy asiakirjasta [Veo Videos Generation API](https://platform.acedata.cloud/documents/veo-videos).

Otetaan esimerkki yhdestä tehtävä-ID:stä, jonka Veo Videos Generation API on palauttanut, ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed, seuraavaksi näytetään, kuinka siirretään tämä tehtävä-ID.

### Pyyntöotsikoiden ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

**Pyyntökeho** sisältää:

- `id`: ladatun tehtävä-ID:n.
- `action`: tehtävälle suoritettavan toiminnan tyyppi.

Aseta kuten alla olevassa kuvassa:

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/bsqh3i.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/veo/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/veo/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `response`, kyselyvideotehtävän palautusinformaatio.

## Virheiden käsittely

Kun kutsut API:ta, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
