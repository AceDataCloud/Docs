Tässä artikkelissa esitellään Veo Videos Generation API -integrointiohje, jonka avulla voidaan luoda Veon virallisia videoita syöttämällä mukautettuja parametreja.

## Hakuprosessi

Käyttääksesi Veo Videos Generation APIa, hanki ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Token -avaimesi ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Token -avaimella voidaan kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäisen hakemuksen yhteydessä myönnetään maksutonta käyttökiintiötä ilmaista kokeilua varten; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

## Peruskäyttö

Tutustutaan ensin peruskäyttötapaan: syöttämällä kehotteen `prompt`, luontitoiminnon `action`, alku- ja loppukehyksen viitekuvataulukon `image_urls` sekä mallin `model` voit saada käsitellyn tuloksen. Ensin täytyy yksinkertaisesti välittää `action`-kenttä, jonka arvo on `text2video`; se sisältää pääasiassa kolme toimintoa: tekstistä videoksi (`text2video`), kuvasta videoksi (`image2video`) ja 1080p-videon hakeminen (`get1080p`). Tämän jälkeen meidän täytyy myös syöttää malli `model`; tällä hetkellä pääasialliset mallit ovat `veo31-fast`, `veo3`, `veo31`, `veo3-fast` ja `veo31-fast-ingredients`, ja tarkempi sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/vv5pe8.png" width="500" className="m-auto" /></p>

Tässä voidaan nähdä, että olemme asettaneet Request Headers -otsakkeet, mukaan lukien:

- `accept`: millaisessa muodossa haluat vastaanottaa vastaustuloksen; tähän täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, joka voidaan hakea suoraan valitsemalla se pudotusvalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, mukaan lukien:

- `model`: videon luomiseen käytettävä malli; pääasialliset mallit ovat `veo31-fast`, `veo3`, `veo31`, `veo3-fast` ja `veo31-fast-ingredients`.
- `action`: tämän videonluontitehtävän toiminto, joka sisältää pääasiassa kolme toimintoa: tekstistä videoksi (`text2video`), kuvasta videoksi (`image2video`) ja 1080p-videon hakeminen (`get1080p`).
- `image_urls`: kun valitaan kuvasta videoksi -toiminto `image2video`, on pakollista käyttää ladattujen viitekuvien linkkejä. `veo31-fast-ingredients` tukee enintään 3 kuvaa (monikuvayhdistely), muut mallit enintään 2 kuvaa (alku- ja loppukehystila).
- `resolution`: luotavan videon tarkkuus; veo31-malli tukee 4k-tarkkuutta, muut mallit eivät. Kaikki mallit tukevat 1080p- ja gif-tarkkuuksia. Jos tätä arvoa ei välitetä, käytetään oletuksena 720p-tarkkuutta. Päävaihtoehdot ovat: `1080p`, `gif`, `4k`.
- `prompt`: kehote.
- `callback_url`: URL-osoite, johon tulos tulee palauttaa takaisinsoittona.
- `async`: valinnainen; kun arvoksi asetetaan `true`, rajapinta palauttaa välittömästi `task_id`-tunnuksen, eikä `callback_url`-osoitetta tarvitse antaa, minkä jälkeen tulos haetaan kyselevällä tehtävänhakurajapinnalla.

### 📌 Mallien ominaisuuksien yhteenveto

| **Mallin nimi**                   | **Tuetut tilat**                          | **Kuvasyötteen säännöt**                        |
| -------------------------- | --------------------------------- | --------------------------------- |
| **veo3-fast**              | Tekstistä videoksi (ei kuvaa)<br />Kuvasta videoksi -tila (kuvan kanssa)           | **1 kuva** → alkukehystila<br />**2 kuvaa** → alku- ja loppukehystila |
| **veo31-fast**             | Tekstistä videoksi (ei kuvaa)<br />Kuvasta videoksi -tila (kuvan kanssa)           | **1 kuva** → alkukehystila<br />**2 kuvaa** → alku- ja loppukehystila |
| **veo31-fast-ingredients** | ❌ Tekstistä videoksi (ei tuettu)<br />✅ **Pakotettu monikuvayhdistely** (kuva on pakollinen) | **1–3 kuvaa** → monikuvayhdistelytila (enintään 3 kuvaa)        |
| **veo3**                   | Tekstistä videoksi (ei kuvaa)<br />Kuvasta videoksi -tila (kuvan kanssa)           | **1 kuva** → alkukehystila<br />**2 kuvaa** → alku- ja loppukehystila |
| **veo31**                  | Tekstistä videoksi (ei kuvaa)<br />Kuvasta videoksi -tila (kuvan kanssa)           | **1 kuva** → alkukehystila<br />**2 kuvaa** → alku- ja loppukehystila |

---

### 🔑 Keskeisten sääntöjen kuvaus

1. **Yleinen logiikka**:
   - **Ei kuvasyötettä** → tekstistä videoksi -tila käynnistyy automaattisesti.
   - **Kuvasyöte käytössä** → kuvasta videoksi -tila käynnistyy (tarkka toiminta määräytyy kuvien lukumäärän mukaan).
2. **Kuvasta videoksi -tilan tyypit**:
   - **Alkukehystila** (1 kuva): alkukehys lukitaan syötekuvaksi.
   - **Alku- ja loppukehystila** (2 kuvaa): alku- ja loppukehys lukitaan syötekuviksi.
   - **Monikuvayhdistelytila** (1–3 kuvaa): vain `veo31-fast-ingredients` tukee tätä, ja video luodaan yhdistämällä useiden kuvien sisältö.
3. **Tilojen luokittelu**:

  - **Fast-tila**: `veo3-fast`, `veo31-fast`, `veo31-fast-ingredients`.
   - **Quality-tila**: `veo3`, `veo31` (korkeampi luontilaatu).

---

### ⚠️ Huomioitavaa

- **Ainoa malli, joka pakottaa kuvien välittämisen**: `veo31-fast-ingredients` edellyttää kuvia (1–3 kuvaa), muuten sitä ei voida suorittaa.
- **Kuvien lukumäärän rajoitukset**:
  - `veo31-fast-ingredients` tukee **1–3 kuvan** syötettä (monikuvayhdistelytila).
  - Muut mallit tukevat enintään **2 kuvan** syötettä (alku- ja loppukehystila).

Palautustuloksessa on useita kenttiä, jotka esitellään seuraavasti:

Voimme nähdä, että saimme tyydyttävät videotiedot. Meidän tarvitsee vain hakea luotu Veo-video tuloksen `data`-kohdassa olevasta videolinkkiosoitteesta.

Lisäksi, jos haluat luoda vastaavan integrointikoodin, voit kopioida sen suoraan. Esimerkiksi CURL-koodi on seuraava:

```shell

-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "veo31-fast",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Kuvasta videoksi -toiminto

Jos haluat luoda videon ensimmäisen ja viimeisen ruudun kuvien perusteella, voit asettaa parametrin `action` arvoksi `image2video` ja syöttää ensimmäisen ja viimeisen ruudun kuvalinkkien taulukon `image_urls`.

Seuraavaksi meidän on täytettävä seuraavassa vaiheessa tarvittavat laajennetut kehotteet videonluonnin mukauttamiseksi, jolloin voidaan määrittää seuraava sisältö:

- `model`: videonluontimalli, pääasiassa `veo31-fast`, `veo3`, `veo31`, `veo3-fast` ja `veo31-fast-ingredients`.
- `image_urls`: kun valitaan kuvasta videoksi -toiminto `image2video`, on syötettävä ladattujen viitekuvien linkit.
- `prompt`: kehote.

Täyttöesimerkki on seuraava:

<p><img src="https://cdn.acedata.cloud/8wvlqd.png" width="500" className="m-auto" /></p>

Täyttämisen jälkeen luodaan automaattisesti seuraava koodi:

<p><img src="https://cdn.acedata.cloud/tgzfxi.png" width="500" className="m-auto" /></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "veo31-fast",
    "prompt": "Let it dance",
    "image_urls": ["https://cdn.acedata.cloud/7p1jhy.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json
    {
      "id": "59f12222b1fa4fbe9331ff2400ad1583",
      "video_url": "https://platform.cdn.acedata.cloud/veo/98e309f3-35bc-438d-8cb3-4015fc864b87.mp4",
      "created_at": "2025-07-25 16:13:07",
      "complete_at": "2025-07-25 16:16:12",
      "state": "succeeded"
    }
  ]
}
```

Voidaan nähdä, että tuloksen sisältö vastaa yllä olevaa, mikä toteuttaa videon kuvasta videoksi -toiminnon.

## Videon luominen määritetyssä koossa

Jos haluat luoda Veo-videon määritetyssä mukautetussa koossa, voit asettaa parametrin `aspect_ratio` halutuksi kooksi. Seuraavaksi meidän on täytettävä seuraavassa vaiheessa tarvittavat laajennetut kehotteet videonluonnin mukauttamiseksi, jolloin voidaan määrittää seuraava sisältö:

- `model`: videonluontimalli, pääasiassa `veo31-fast`, `veo3`, `veo31`, `veo3-fast` ja `veo31-fast-ingredients`.
- `aspect_ratio`: videon koko, tällä hetkellä tuetaan: `16:9`, `16:9`, `3:4`, `4:3`, `1:1`, oletusarvo on `16:9`.
- `translation`: otetaanko kehotteen automaattinen käännös käyttöön, oletusarvo on `false`.

## Asynkroninen takaisinsoitto

Koska Veo Videos Generation API:n luomisaika on suhteellisen pitkä, noin 1–2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden jatkuvasti avoinna, mikä johtaa ylimääräiseen järjestelmäresurssien kulutukseen, joten tämä API tarjoaa myös tuen asynkronisille takaisinsoitoille.

Kokonaisprosessi on seuraava: kun asiakas lähettää pyynnön, se määrittää lisäksi `callback_url`-kentän. Kun asiakas on lähettänyt API-pyynnön, API palauttaa välittömästi tuloksen, joka sisältää `task_id`-kentän tiedot ja edustaa nykyisen tehtävän tunnusta. Kun tehtävä on valmis, videon luomisen tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, ja se sisältää myös `task_id`-kentän, jolloin tehtävän tulos voidaan yhdistää tunnuksen avulla.

Seuraavaksi käytämme esimerkkiä ymmärtääksemme, miten tämä tehdään käytännössä.

Ensinnäkin Webhook-takaisinsoitto on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, ja kehittäjän tulee korvata se oman HTTP-palvelimensa URL-osoitteella. Esittelyn helpottamiseksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/; avaamalla tämän sivuston saat Webhook-URL-osoitteen, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

Seuraavaksi voimme asettaa `callback_url`-kentän edellä mainituksi Webhook-URL-osoitteeksi ja täyttää samalla vastaavat parametrit; tarkka sisältö näkyy kuvassa:

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos virhe ilmenee. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, valtuutustunnus on virheellinen tai puuttuu.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain odottamatonta.

### Esimerkki virhevastauksesta

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
