Claude Messages Count Tokens API voi laskea viestin syötteen Token-määrän ilman, että viestejä todella luodaan, mukaan lukien työkalut, kuvat ja asiakirjat. Tämä on erittäin hyödyllistä, kun on tarpeen arvioida kustannuksia tai tarkistaa, ylittääkö syöte mallin kontekstitason rajoitukset.

Tässä asiakirjassa esitellään pääasiassa Claude Messages Count Tokens API:n käyttöprosessi.

## 申请流程

Claude Messages Count Tokens API:n käyttämiseksi voit ensin siirtyä [Claude Messages Count Tokens API](https://platform.acedata.cloud/documents/claude-messages-count-tokens) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen sinut ohjataan automaattisesti takaisin nykyiselle sivulle.

Tämä API on täysin ilmainen käyttää, eikä se kuluta mitään kiintiötä.

## 基本使用

Claude Messages Count Tokens API:n pyyntöpolku on `/v1/messages/count_tokens`, ja se on yhdenmukainen Anthropicin virallisen API:n kanssa. Meidän on annettava vähintään kaksi pakollista parametria:

- `model`: Valitse käytettävä Claude-malli, kuten `claude-sonnet-4-5-20250929`, `claude-opus-4-20250514` jne.
- `messages`: Syötteen viestitaulukko, jossa jokaisessa viestissä on `role` (rooli) ja `content` (sisältö).

Yleisesti käytetyt valinnaiset parametrit:

- `system`: Järjestelmäkehotteet, jotka lasketaan Token-määrään.
- `tools`: Työkalumääritelmät, jotka lasketaan Token-määrään.
- `thinking`: Laajennettu ajattelukonfiguraatio.

### cURL 示例

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-sonnet-4-5-20250929",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python 示例

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-sonnet-4-5-20250929",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

返回结果示例：

```json
{
  "input_tokens": 11
}
```

### 使用 Anthropic SDK

Claude Messages Count Tokens API on täysin yhteensopiva Anthropicin virallisen SDK:n kanssa, ja voit käyttää suoraan `anthropic`-kirjastoa kutsumiseen.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## 包含工具的 Token 计数

Jos pyyntösi sisältää työkalumääritelmiä, nämä työkalut lasketaan myös Token-määrään:

```python
result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## 包含系统提示词的 Token 计数

Järjestelmäkehotteet lasketaan myös Token-määrään:

```python
result = client.messages.count_tokens(
    model="claude-sonnet-4-5-20250929",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## 注意事项

- Tämä API laskee vain syötteen Token-määrän, eikä se tuota mitään mallin ulostuloa.
- Token-laskentatuloksia voidaan käyttää arvioimaan Claude Messages API:n kutsujen kustannuksia.
- Eri mallien Token-muunnosmenetelmät voivat vaihdella, joten käytä samaa model-parametria kuin todellisessa kutsussa.
- Tämä API on täysin ilmainen, eikä se kuluta mitään kiintiötä.
