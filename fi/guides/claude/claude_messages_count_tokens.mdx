Claude Messages Count Tokens API voi laskea Message-viestin syöte-Tokenien määrän, mukaan lukien työkalujen, kuvien ja asiakirjojen kaltaisen sisällön Token-laskennan, luomatta viestiä tosiasiallisesti. Tämä on erittäin hyödyllistä, kun kustannuksia on arvioitava tai kun on tarkistettava, ylittääkö syöte mallin kontekstirajat.

Tässä asiakirjassa esitellään pääasiassa Claude Messages Count Tokens API:n käyttöprosessi.

`claude-fable-5-2` ei tällä hetkellä tarjoa Count Tokens -rajapintaa. Luontipyynnön lopullinen käyttömäärä voidaan tarkistaa Messages-vastauksen kohdasta `usage`; älä käytä muiden mallien laskentatuloksia tämän mallin tarkan käyttömäärän korvaamiseen.

## Hakuprosessi

Jos haluat käyttää Claude Messages Count Tokens API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen kullekin palvelulle.** Ensimmäisellä hakukerralla saat ilmaista käyttökiintiötä maksuttomaan kokeiluun; jos kiintiö ei riitä, voit lisätä yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

## Peruskäyttö

Claude Messages Count Tokens API:n pyyntöpolku on `/v1/messages/count_tokens`, ja se vastaa Anthropicin virallista API:a. Meidän on annettava vähintään kaksi pakollista parametria:

- `model`: Anna tämän rajapinnan malliluettelossa oleva täydellinen malli-ID ja käytä samaa mallia seuraavassa Messages-pyynnössä.
- `messages`: Syötettävä viestitaulukko, jossa jokainen viesti sisältää `role`- (rooli) ja `content`-kentän (sisältö).

Yleisesti käytetyt valinnaiset parametrit:

- `system`: Järjestelmäkehote, joka lasketaan mukaan Tokenien määrään.
- `tools`: Työkalumääritelmät, jotka lasketaan mukaan Tokenien määrään.
- `thinking`: Laajennetun ajattelun määritys.
- `tool_choice`: Työkalun valinnan määritys.
- `cache_control`: Ylätason tai sisältölohkon tason välimuistin hallinnan määritys.

`messages`, `system`, työkalukutsujen toisto, URL-kuvat ja document/PDF-sisältölohkot käyttävät samaa vakaata pyyntörakennetta kuin Messages API.

### cURL-esimerkki

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-esimerkki

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Esimerkki palautettavasta tuloksesta:

```json
{
  "input_tokens": 11
}
```

### Anthropic SDK:n käyttö

Claude Messages Count Tokens API hyväksyy Anthropic SDK:n vakaan pyyntörakenteen, ja sitä voidaan kutsua `anthropic`-kirjaston kautta. Rajapinta laskee syöte-Tokenit valitun mallin mukaan, ja sitä voidaan käyttää syötteen koon tarkistamiseen ennen Messages-pyynnön lähettämistä.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Työkaluja sisältävä Token-laskenta

Jos pyyntösi sisältää työkalumääritelmiä, myös nämä työkalut lasketaan mukaan Tokenien määrään:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Järjestelmäkehotteen sisältävä Token-laskenta

Järjestelmäkehote lasketaan myös mukaan Tokenien määrään:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Huomioitavaa

- Tämä API laskee vain syöte-Tokenien määrän eikä tuota mitään mallin tulostetta.
- Token-laskennan tuloksia voidaan käyttää syötteen koon arvioimiseen ja konteksti-ikkunan tarkistamiseen; lopullinen laskutus määräytyy todellisen Messages-vastauksen `usage`-arvon mukaan.
- Kuvat, PDF:t, työkalumääritelmät, järjestelmäkehotteet ja thinking-määritykset lasketaan tulokseen valitun mallin syötesääntöjen mukaisesti.
- Tämä API on täysin maksuton eikä kuluta mitään käyttökiintiötä.
