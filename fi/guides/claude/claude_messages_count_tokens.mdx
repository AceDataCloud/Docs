Claude Messages Count Tokens API voi laskea yhden Messagen syötteen Tokenien määrän ilman varsinaista viestin luomista, mukaan lukien työkalujen, kuvien ja asiakirjojen kaltaisen sisällön Token-laskennan. Tämä on erittäin hyödyllistä, kun on tarpeen arvioida kustannuksia tai tarkistaa, ylittääkö syöte mallin kontekstirajoituksen.

Tässä dokumentissa esitellään pääasiassa Claude Messages Count Tokens API:n käyttöprosessi.

## Hakuprosessi

Käyttääksesi Claude Messages Count Tokens API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja pidä se tallessa myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta annetaan ilmainen käyttökiintiö maksutonta kokeilua varten; jos kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Peruskäyttö

Claude Messages Count Tokens API:n pyyntöpolku on `/v1/messages/count_tokens`, joka vastaa Anthropicin virallista API:a. Meidän on annettava vähintään kaksi pakollista parametria:

- `model`: valitse käytettävä Claude-malli; `claude-opus-5-5` voidaan käyttää Messages Token Countiin, kuten uusinta lippulaivaa `claude-fable-5-1`; alkuperäinen `claude-fable-5` on edelleen yhteensopivasti säilytetty. `claude-sonnet-5-5` on lisätty natiiviin Messages-sarjan rajapintaan, ja se tukee kuvasyötettä ja mukautuvaa ajattelua; sen viralliset viitehinnat syötteelle, tulosteelle ja välimuistin lukemiselle ovat vastaavasti 2, 10 ja 0,20 Yhdysvaltain dollaria miljoonaa Tokenia kohden.
- `messages`: syötetty viestitaulukko, jossa jokainen viesti sisältää `role`-roolin ja `content`-sisällön.

Yleisesti käytetyt valinnaiset parametrit:

- `system`: järjestelmäkehote, joka lasketaan mukaan Tokenien määrään.
- `tools`: työkalumäärittelyt, jotka lasketaan mukaan Tokenien määrään.
- `thinking`: laajennetun ajattelun määritys.
- `tool_choice`: työkalun valinnan määritys.
- `cache_control`: ylimmän tason tai sisältölohkon tason välimuistin hallinnan määritys.

`messages`, `system`, työkalukutsujen toisto, URL-kuvat sekä document/PDF-sisältölohkot käyttävät samaa vakaata pyyntörakennetta kuin Messages API.

### cURL-esimerkki

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python-esimerkki

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Esimerkki palautettavasta tuloksesta:

```json
{
  "input_tokens": 11
}
```

### Anthropic SDK:n käyttäminen

Claude Messages Count Tokens API hyväksyy Anthropic SDK:n vakaan pyyntörakenteen, ja sitä voidaan kutsua `anthropic`-kirjaston kautta. Rajapinta käyttää valittua mallia vastaavaa natiivia Count Tokens -toimintoa syötteen laskemiseen, ja sitä voidaan käyttää syötteen koon tarkistamiseen ennen Messages-pyynnön lähettämistä.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Työkaluja sisältävä Token-laskenta

Jos pyyntösi sisältää työkalumäärittelyjä, myös nämä työkalut lasketaan Tokenien määrään:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Järjestelmäkehotteen sisältävä Token-laskenta

Järjestelmäkehote lasketaan myös Tokenien määrään:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Huomioitavaa

- Tämä API laskee vain syötteen Tokenien määrän eikä tuota mitään mallin tulostetta.
- Token-laskennan tulosta voidaan käyttää syötteen koon arvioimiseen ja konteksti-ikkunan tarkistamiseen; lopullinen laskutus perustuu todellisen Messages-vastauksen `usage`-arvoon.
- Kuvat, PDF-tiedostot, työkalumäärittelyt, järjestelmäkehotteet ja thinking-määritykset lasketaan tulokseen valitun mallin syötesääntöjen mukaisesti.
- Tämä API on täysin maksuton eikä kuluta mitään käyttökiintiötä.
