Anthropic Claude on erittäin tehokas AI-keskustelujärjestelmä, joka voi tuottaa sujuvia ja luonnollisia vastauksia vain muutamassa sekunnissa, kun sille annetaan kehote. Claude erottuu alalla erinomaisilla kielen ymmärtämis- ja tuottamiskyvyillään, ja nykyään Claudea käytetään jo laajasti eri toimialoilla ja aloilla, ja sen vaikutus kasvaa yhä merkittävämmäksi. Olipa kyse päivittäisistä keskusteluista, luovasta kirjoittamisesta, ammattimaisesta konsultoinnista tai koodiohjelmoinnista, Claude voi tarjota hämmästyttävää älykästä apua, joka parantaa merkittävästi ihmisten työtehokkuutta ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa Claude Chat Completion API -toiminnon käyttöprosessi, jonka avulla voimme helposti käyttää virallisen Clauden keskustelutoimintoja.

## Hakuprosessi

Jos haluat käyttää Claude Chat Completion API:a, hanki ensin API Token -avaimesi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Token -avaimella voidaan kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäisellä hakukerralla saat ilmaista käyttökiintiötä maksutonta kokeilua varten; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Claude Chat Completion API →](https://platform.acedata.cloud/documents/claude-chat-completions)

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavat tiedot kuvan mukaisesti:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme kohtaa. Ensimmäinen on `authorization`, joka voidaan valita suoraan avattavasta luettelosta. Toinen parametri on `model`, ja voit valita julkisia malleja, kuten `claude-opus-5-5` ja `claude-fable-5-1`; alkuperäistä `claude-fable-5` -mallia voi edelleen kutsua. Viimeinen parametri on `messages`, joka on kyselylauseiden taulukko, ja jokainen elementti sisältää `role`- ja `content`-kentät; `role` tukee arvoja `user`, `assistant` ja `system`, ja `content` on varsinainen sisältö. Kun tarvitset Clauden täydellisiä ajattelusisältölohkoja, allekirjoituksia ja natiivien työkalujen semantiikkaa, käytä edelleen Messages API:a.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi, jonka voit kopioida ja suorittaa suoraan, tai voit testata sitä napsauttamalla suoraan ”Try”-painiketta.

Yleisesti käytetyt valinnaiset parametrit:

- `max_tokens`: rajoittaa yksittäisen vastauksen tokenien enimmäismäärää.
- `temperature`: generoinnin satunnaisuus, välillä 0–2; mitä suurempi arvo, sitä hajautuneempi.
- `n`: kuinka monta ehdokasvastausta generoidaan kerralla.
- `response_format`: palautusmuodon asetus.

`claude-opus-5-5` tukee tavallisia ja suoratoistavia Chat Completions -toimintoja; tämä malli sallii vain `n=1`. Älä aseta sille alle 1:n `temperature`-arvoa tai muuta kuin oletusarvoista `top_p`-arvoa, ja käytä työkalukutsuissa `tool_choice: "auto"` -asetusta, älä pakota tiettyä työkalua. Chat-yhteensopiva rajapinta ei palauta natiiveja ajattelusisältölohkoja.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Kutsun jälkeen huomaamme, että palautettu tulos on seuraava:

```json
{
  "id": "msg_bdrk_01Q6WN27v95ypCa1kbanAQ6K",
  "model": "claude-opus-4-8",
  "object": "chat.completion",
  "created": 1768619365,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 12,
    "total_tokens": 20,
    "prompt_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "completion_tokens_details": {
      "reasoning_tokens": 0
    }
  }
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luotu ID, jota käytetään tämän keskustelutehtävän yksilöivään tunnistamiseen.
- `model `, valittu Clauden virallisen sivuston malli.
- `choices`, Clauden kyselylauseeseen antaman vastauksen tiedot.
- `usage `: tämän kysymys-vastausparin tokeneiden tilastotiedot.

Chat Completions -muodossa `usage.prompt_tokens` on syötteen kokonaismäärä; `prompt_tokens_details.cached_tokens` ja `prompt_tokens_details.cache_write_tokens` tallentavat vastaavasti välimuistin luku- ja kirjoitustiedot. `completion_tokens_details.reasoning_tokens` on `completion_tokens`-kentän osajoukko, eikä sitä tule lisätä uudelleen kokonaismäärää tai kustannuksia laskettaessa. Ei-suoratoistava vastaus voi myös palauttaa `usage.cost`-objektin, jossa `amount` on todellinen kiintiön kulutus, `currency` on mittayksikkö ja `list_amount` on summa ennen alennusta (jos sellainen on).

Chat-yhteensopivan rajapinnan kentän nimi on `reasoning_tokens`; natiivi Messages API käyttää `output_tokens_details.thinking_tokens`-kenttää. Näiden kahden protokollan wire schema on erilainen, eikä asiakkaan tule sekoittaa kenttien nimiä.

Näistä `choices` sisältää Clauden vastaustiedot, ja sen sisällä oleva `choices` sisältää Clauden vastauksen tarkat tiedot, kuten kuvasta voidaan nähdä.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Voidaan nähdä, että `choices`-kentän `content`-kenttä sisältää Clauden vastauksen tarkat sisällöt.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa verkkosivulla sanakohtaisen näyttötehosteen.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyynnön otsakkeessa olevan `stream ` -parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodiin on tehtävä vastaavat muutokset, jotta se tukee suoratoistovastauksia.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme tulokset rivi kerrallaan.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "claude-opus-4-20250514",
    messages: [{ role: "user", content: "Hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/v1/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

## Syvällinen päättely
Uuden sukupolven Claude-mallit voivat mahdollisesti suorittaa päättelyä mallin oletusstrategian mukaisesti ilman, että se täytyy aktivoida `-thinking`-malliliitteellä. Chat-yhteensopivat vastaukset käyttävät OpenAI-yhteensopivaa usage-kenttää `completion_tokens_details.reasoning_tokens`. `reasoning_tokens` sisältyy jo `completion_tokens`-kenttään, älä laske niitä yhteen kahdesti. Päättely ja näkyvä tekstisisältö jakavat saman tulostustokenien enimmäisrajan, joten kun `max_tokens` on pieni, tekstisisältö voi olla tyhjä tai katkennut; jos näin tapahtuu, kasvata tulostusbudjettia tai valitse pienempi päättelypanostus, jos käyttämäsi malli tukee sitä.

Jos tarvitset alkuperäistä `thinking`-toimintoa, `output_config.effort`-asetusta, thinking-sisältölohkoja ja allekirjoitusten palautusta, käytä `/v1/messages`-rajapintaa. Messages-palvelua vastaava usage-kenttä on `output_tokens_details.thinking_tokens`; älä sekoita sitä Chat-yhteensopivan palvelun `completion_tokens_details.reasoning_tokens`-kenttään.

## Visuaalinen malli

claude-sonnet-4-20250514 on Clauden kehittämä multimodaalinen suuri kielimalli, joka lisää visuaalisen ymmärryksen kyvyn claude-4:n pohjalta. Tämä malli voi käsitellä samanaikaisesti teksti- ja kuvasyötteitä sekä toteuttaa eri modaliteettien välisen ymmärryksen ja generoinnin.

claude-sonnet-4-20250514-mallin tekstinkäsittelyn käyttö on yhdenmukainen edellä kuvatun peruskäytön kanssa, ja seuraavaksi esitellään lyhyesti, kuinka mallin kuvankäsittelyominaisuuksia käytetään.

claude-sonnet-4-20250514-mallin kuvankäsittelyominaisuuksia käytetään pääasiassa lisäämällä alkuperäiseen `content`-sisältöön `type`-kenttä, jonka avulla voidaan tietää, onko ladattu sisältö tekstiä vai kuva, ja näin käyttää claude-sonnet-4-20250514-mallin kuvankäsittelyominaisuuksia. ## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos kohdataan virhe. Esimerkiksi:

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Luvaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.
