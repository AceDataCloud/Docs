Anthropic Claude on erittäin voimakas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain syöttämällä kehotussanoja muutamassa sekunnissa. Claude erottuu alalla erinomaisella kielentunnistus- ja -tuotantokyvyllään, ja nykyään Claudea käytetään laajasti eri toimialoilla ja alueilla, ja sen vaikutus on yhä merkittävämpi. Olipa kyseessä päivittäinen keskustelu, luova kirjoittaminen tai ammatillinen konsultointi, koodaus, Claude voi tarjota hämmästyttävää älykästä apua, mikä parantaa merkittävästi ihmisten työtehoa ja luovuutta.

Tässä asiakirjassa esitellään pääasiassa Claude Chat Completion API:n käyttöprosessi, jonka avulla voimme helposti hyödyntää virallista Clauden keskustelutoimintoa.

## Hakuprosessi

Claude Chat Completion API:n käyttämiseksi voit ensin siirtyä [Claude Chat Completion API](https://platform.acedata.cloud/documents/280928a2-2dce-419c-adb5-1ea835e8183a) -sivulle ja napsauttaa "Acquire" -painiketta saadaksesi tarvittavat todisteet pyyntöä varten:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:ta ilmaiseksi.

## Peruskäyttö

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" class="m-auto"></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, sinun on täytettävä vähintään kolme tietoa: yksi on `authorization`, jonka voit valita suoraan avattavasta valikosta. Toinen parametri on `model`, joka tarkoittaa, että valitsemme käytettävän Clauden verkkosivuston mallikategorian. Täällä meillä on pääasiassa 20 erilaista mallia, yksityiskohtia voit katsoa tarjoamastamme mallista. Viimeinen parametri on `messages`, joka on kysymysmerkkien taulukko, joka tarkoittaa, että voit ladata useita kysymysmerkkejä samanaikaisesti. Jokainen kysymysmerkki sisältää `role` ja `content`, jossa `role` tarkoittaa kysyjän roolia. Olemme tarjonneet kolme identiteettiä: `user`, `assistant`, `system`. Toinen `content` on kysymyksemme tarkka sisältö.

Voit myös huomata, että oikealla puolella on vastaava kutsukoodin generointi, voit kopioida koodin ja suorittaa sen suoraan tai napsauttaa "Try" -painiketta testataksesi.

Yleisesti käytettävät valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen enimmäistoken-määrää.
- `temperature`: luo satunnaisuutta, 0-2 välillä, suurempi arvo tarkoittaa hajautetumpaa tulosta.
- `n`: kuinka monta ehdokasvastausta luodaan kerralla.
- `response_format`: palautusmuodon asetukset.

## Virtaava vastaus

Tämä rajapinta tukee myös virtaavaa vastausta, mikä on erittäin hyödyllistä verkkosivustojen integroinnissa, sillä se mahdollistaa verkkosivuston näyttävän tuloksia sana sanalta.

Jos haluat virtaavan vastauksen, voit muuttaa pyyntöotsikossa `stream`-parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodin on myös oltava vastaavasti muutettu tukemaan virtaavaa vastausta.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" class="m-auto"></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa JSON-tiedot rivi riviltä, ja kooditasolla meidän on tehtävä vastaavat muutokset saadaksemme rivikohtaiset tulokset.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

## Johtopäätös

Tämän asiakirjan avulla olet oppinut, kuinka käyttää Claude Chat Completion API:ta helposti virallisten Clauden keskustelutoimintojen toteuttamiseen. Toivottavasti tämä asiakirja auttaa sinua paremmin yhdistämään ja käyttämään tätä API:ta. Jos sinulla on kysymyksiä, ota rohkeasti yhteyttä tekniseen tukitiimiimme.
