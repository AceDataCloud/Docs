Anthropic Claude on erittäin tehokas AI-keskustelujärjestelmä, joka pystyy tuottamaan sujuvia ja luonnollisia vastauksia vain muutamassa sekunnissa, kun syötät kehotteen. Claude erottuu alalla erinomaisilla kielen ymmärtämis- ja generointikyvyillään, ja nykyään Claudea on jo laajasti sovellettu eri toimialoilla ja aloilla, ja sen vaikutus kasvaa yhä merkittävämmäksi. Olipa kyse päivittäisistä keskusteluista, luovasta kirjoittamisesta tai ammatillisesta konsultoinnista ja koodiohjelmoinnista, Claude voi tarjota hämmästyttävää älykästä apua, mikä parantaa huomattavasti ihmisten työn tehokkuutta ja luovuutta.

Tässä dokumentissa esitellään pääasiassa Claude Chat Completion API -toiminnon käyttöprosessi, jonka avulla voimme helposti käyttää virallisen Clauden keskustelutoimintoja.

## Hakuprosessi

Jos haluat käyttää Claude Chat Completion API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voidaan kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta myönnetään ilmainen käyttökiintiö maksutonta kokeilua varten; kun kiintiö ei riitä, voit lisätä yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Claude Chat Completion API →](https://platform.acedata.cloud/documents/claude-chat-completions)

## Peruskäyttö

Seuraavaksi voit täyttää käyttöliittymässä vastaavat sisällöt, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

Kun käytät tätä rajapintaa ensimmäistä kertaa, meidän on täytettävä vähintään kolme sisältöä. Yksi niistä on `authorization`, jonka voit valita suoraan avattavasta luettelosta. Toinen parametri on `model`, jossa suositellaan käyttämään uusinta lippulaivamallia `claude-fable-5-1`; alkuperäistä `claude-fable-5`-mallia voidaan edelleen kutsua. Viimeinen parametri on `messages`, joka on kyselysanojen taulukko, ja jokainen elementti sisältää `role`- ja `content`-kentät; `role` tukee arvoja `user`, `assistant`, `system`, ja `content` on varsinainen sisältö. Claude Fable 5.1 tukee 1 miljoonan Tokenin kontekstia ja enintään 128K Tokenin tulostetta.

Samalla voit huomata, että oikealla puolella luodaan vastaava kutsukoodi. Voit kopioida koodin ja suorittaa sen suoraan tai testata sitä suoraan napsauttamalla ”Try”-painiketta.

Yleisesti käytetyt valinnaiset parametrit:

- `max_tokens`: rajoittaa yhden vastauksen tokenien enimmäismäärää.
- `temperature`: generoinnin satunnaisuus, välillä 0–2; mitä suurempi arvo, sitä hajautuneempi.
- `n`: kuinka monta ehdokasvastausta generoidaan kerralla.
- `response_format`: palautusmuodon asetukset.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

Kutsun jälkeen havaitsemme, että palautustulos on seuraava:

```json
{
  "id": "msg_bdrk_01Q6WN27v95ypCa1kbanAQ6K",
  "model": "claude-opus-4-8",
  "object": "chat.completion",
  "created": 1768619365,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 12,
    "total_tokens": 20,
    "prompt_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "completion_tokens_details": {
      "reasoning_tokens": 0
    }
  }
}
```

Palautustuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `id`, tämän keskustelutehtävän luotu ID, jota käytetään tämän keskustelutehtävän yksilölliseen tunnistamiseen.
- `model `, valittu Claude-verkkosivuston malli.
- `choices`, Clauden kyselysanalle antamat vastaustiedot.
- `usage `: tämän kysymys-vastausparin token-tilastotiedot.

Chat Completions -muodossa `usage.prompt_tokens` on syötteen kokonaismäärä; `prompt_tokens_details.cached_tokens` ja `prompt_tokens_details.cache_write_tokens` tallentavat vastaavasti välimuistin luku- ja kirjoituserittelyt. `completion_tokens_details.reasoning_tokens` on `completion_tokens`-kentän osajoukko, eikä sitä pidä lisätä uudelleen kokonaismäärää tai kustannuksia laskettaessa. Ei-suoratoistoiset vastaukset voivat myös palauttaa `usage.cost`-objektin, jossa `amount` on todellinen kiintiön kulutus, `currency` on mittayksikkö ja `list_amount` on summa ennen alennusta (jos sellainen on).

Chat-compatible-version kentän nimi on `reasoning_tokens`; alkuperäinen Messages API käyttää `output_tokens_details.thinking_tokens`-kenttää. Näiden kahden protokollan wire schema on erilainen, eikä asiakasohjelman tule sekoittaa kenttien nimiä.

Näistä `choices` sisältää Clauden vastaustiedot, ja sen sisällä oleva `choices` on Clauden vastauksen tarkat tiedot, kuten kuvasta voidaan havaita.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

Voidaan nähdä, että `choices`-kentän sisällä oleva `content`-kenttä sisältää Clauden vastauksen varsinaisen sisällön.

## Suoratoistovastaus

Tämä rajapinta tukee myös suoratoistovastauksia, mikä on erittäin hyödyllistä verkkosivujen integroinnissa ja mahdollistaa verkkosivulla kirjain kerrallaan näkyvän tehosteen.

Jos haluat palauttaa vastauksen suoratoistona, voit muuttaa pyyntöotsikon `stream ` -parametrin arvoksi `true`.

Muutos näkyy kuvassa, mutta kutsukoodiin on tehtävä vastaavat muutokset, jotta se tukee suoratoistovastauksia.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>

Kun `stream` muutetaan arvoksi `true`, API palauttaa vastaavat JSON-tiedot rivi kerrallaan, ja kooditasolla meidän on tehtävä vastaavia muutoksia saadaksemme tulokset rivi kerrallaan.

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {

    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "claude-opus-4-20250514",

    stream: true,
  }),
};

fetch("https://api.acedata.cloud/v1/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Python-esimerkkikutsukoodi:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

    "accept": "application/json",

    "content-type": "application/json"
```

## Syvällinen ajattelu
Uuden sukupolven Claude-mallit voivat päättellä mallin oletuskäytännön mukaisesti ilman, että se tarvitsee käynnistää `-thinking`-malliliitteellä. Chat-yhteensopivat vastaukset käyttävät OpenAI-yhteensopivaa usage-kenttää `completion_tokens_details.reasoning_tokens`. `reasoning_tokens` sisältyy jo `completion_tokens`-kenttään, älä laske niitä yhteen kahdesti. Päättely ja näkyvä leipäteksti jakavat tulostokenien ylärajan, joten kun `max_tokens` on pieni, leipäteksti voi olla tyhjä tai katkennut; tällaisessa tilanteessa kasvata tulostebudjettia tai valitse pienempi päättelypanostus, jos käytetty malli tukee sitä.

Jos tarvitset natiivin `thinking`-toiminnon, `output_config.effort`-asetuksen, thinking-sisältölohkot ja allekirjoitusten palautuksen, käytä `/v1/messages`-rajapintaa. Messages-vastaava usage-kenttä on `output_tokens_details.thinking_tokens`, älä sekoita sitä Chat-yhteensopivan rajapinnan `completion_tokens_details.reasoning_tokens`-kenttään.

## Visuaalinen malli

claude-sonnet-4-20250514 on Clauden kehittämä multimodaalinen suuri kielimalli, joka lisää visuaalisen ymmärryskyvyn claude-4:n pohjalta. Tämä malli voi käsitellä samanaikaisesti teksti- ja kuvasyötteitä, mikä mahdollistaa monimodaalisen ymmärryksen ja generoinnin.

claude-sonnet-4-20250514-mallin tekstinkäsittely vastaa yllä kuvattua peruskäyttöä. Seuraavaksi esitellään lyhyesti, kuinka mallin kuvankäsittelykykyä käytetään.

claude-sonnet-4-20250514-mallin kuvankäsittelykykyä käytetään pääasiassa lisäämällä alkuperäiseen `content`-sisältöön `type`-kenttä. Tämän kentän avulla voidaan tietää, onko ladattu sisältö tekstiä vai kuva, ja siten käyttää claude-sonnet-4-20250514-mallin kuvankäsittelykykyä. ## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedon, jos tapahtuu virhe. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Luvaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajan.
- `500 api_error`：Sisäinen palvelinvirhe, palvelimella tapahtui jotain odottamatonta.
