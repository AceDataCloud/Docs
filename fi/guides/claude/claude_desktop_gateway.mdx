Tässä oppaassa määritetään Claude Desktopin **Third-Party Inference Gateway**, ei Claude Codea eikä Claude Desktopin MCP Connectoria.

## 1. Hanki API Key

Avaa [Ace Data Cloudin sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

![Ace Data Cloud API Keyn hakeminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Avaa kolmannen osapuolen päättelyasetukset

Avaa Claude Desktopin kirjautumissivulla järjestyksessä **Help → Troubleshooting → Enable Developer Mode** ja valitse sitten **Developer → Configure Third-Party Inference…**.

![Third-Party Inferencen avaaminen Claude Desktopissa](https://cdn.acedata.cloud/713ffd7104a3.png)

> Kuva on peräisin Bifrost Apache-2.0 -arkistosta ja sitä käytetään vain Claude Desktopin valikon paikantamiseen; eri versioiden käyttöliittymät voivat poiketa hieman toisistaan.

## 3. Määritä Gateway

Valitse **Gateway** ja täytä sitten:

| Kenttä                  | Arvo                           |
| ------------------- | --------------------------- |
| Gateway base URL    | `https://api.acedata.cloud` |
| Gateway API key     | juuri kopioitu API Key               |
| Gateway auth scheme | `bearer`                    |
| Credential kind     | `Static API key`            |

![Claude Desktop Gatewayn määritysnäkymä](https://cdn.acedata.cloud/68d41fe682cb.png)

Napsauta **Apply Changes** ja sitten **Save & Restart**.

## 4. Vahvistus

Valitse uudelleenkäynnistyksen jälkeen käytettävissä oleva malli, luo uusi keskustelu ja lähetä `Reply only OK`, suorita sitten yksinkertainen työkalutehtävä. Kutsutietueita voi tarkastella [käyttöhistoriassa](https://platform.acedata.cloud/console/usages).

Ace Data Cloud Gateway tukee Claude Desktopin käyttämiä `/v1/models`-, Bearer-todennettua suoratoistavaa `/v1/messages`-, työkalukutsu- ja `tool_result`-jatkokirjoitusrajapintoja. Kehotekirjoituskentät säilytetään; se, että välimuistin kirjoitus- ja lukuarvot ovat molemmat 0, ei tarkoita välimuistiosumaa.

401 tarkoittaa yleensä, että Key ei ole oikea; jos mallia ei löydy, tarkista määritykset uudelleen ja käynnistä Claude Desktop kokonaan uudelleen. Anna ongelmista palautetta lähettäessäsi kutsutietueen trace ID, älä anna API Keytä.
