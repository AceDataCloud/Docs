Tässä artikkelissa esitellään MiniMax H3 -videonluonnin API:n integrointi ja käyttö. Tämä rajapinta tukee tekstistä videoksi -luontia, alku- ja loppukehysten hallintaa sekä multimodaalista viitemateriaalista videoksi -luontia, ja käyttää tehtävien luomiseen yhtenäistä V2-multimodaalista `content`-rakennetta.

## Hakuprosessi

Jotta voit käyttää MiniMax H3 -videonluonnin API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voit kutsua kaikkia alustan palveluita ilman, että sinun tarvitsee hakea erikseen jokaista palvelua varten.** Ensimmäisestä hakemuksesta myönnetään maksutonta käyttökiintiötä, joten voit kokeilla palvelua ilmaiseksi; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [MiniMax H3 -videonluonnin API →](https://platform.acedata.cloud/documents/minimax-videos-integration)

On suositeltavaa tallentaa Token ympäristömuuttujaan äläkä kirjoita sitä lähdekoodiin tai tallenna versionhallintaan:

```bash
export ACEDATACLOUD_API_KEY="YOUR_API_KEY"
```

## Rajapinnan yleiskatsaus

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /minimax/videos`
- **Todennustapa**：välitä HTTP Headerissa `authorization: Bearer {token}`
- **Pyyntöotsakkeet**：
  - `accept: application/json`
  - `content-type: application/json`
- **Malli（model）**：`MiniMax-H3`
- **Syöterakenne**：teksti, kuvat, videot ja ääni välitetään yhtenäisesti `content`-kentän kautta
- **Tulostila**：oletuksena odottaa synkronisesti luonnin valmistumista ja palauttaa koko `task`-objektin; kun välitetään `async: true` tai `callback_url`, palauttaa välittömästi `task_id`- ja `trace_id`-arvot
- **Tulosten kysely**：hae tila ja valmis video [MiniMax H3 -tehtäväkysely-API:n](https://platform.acedata.cloud/documents/minimax-tasks-integration) kautta
- **Asynkroninen takaisinsoitto**：valinnainen, vastaanota lopullinen tehtävätulos `callback_url`-osoitteen kautta

Sinun ei tarvitse välittää `action`-parametria luontitilan valitsemiseksi, sillä rajapinta määrittää käyttötarkoituksen automaattisesti `content`-kentän materiaalien tyyppien ja `role`-arvon perusteella.

## Mihin tilanteisiin se sopii

| Tilanne         | Syöteyhdistelmä                  | Tyypilliset käyttötarkoitukset                      |
| ---------- | --------------------- | ------------------------- |
| Tekstistä videoksi       | Teksti                    | Mainosideat, kuvakäsikirjoituksen esikatselu, lyhyet videot, tunnelmakuvat        |
| Ensimmäisestä kuvasta videoksi     | Teksti + ensimmäisen kehyksen kuva             | Tuotekuvien, julisteiden, henkilökuvien tai kuvitusten luonnollinen animointi      |
| Loppukehys / alku- ja loppukehysvideo | Teksti + loppukehys tai teksti + alku- ja loppukehys | Alun ja lopun, siirtymien, kasvumuutosten sekä ennen ja jälkeen -vertailujen hallinta      |
| Multimodaalisesta viitemateriaalista videoksi   | Teksti + viitekuva / video / ääni   | Hahmojen ja tuotteiden yhtenäisyyden säilyttäminen, liikkeiden, kameraliikkeiden, äänensävyn tai leikkausrytmin jäljittely |

## Kutsuprosessi

Kun `async`-parametria ei oletuksena välitetä, `/minimax/videos` odottaa luonnin valmistumista ja palauttaa suoraan koko `task`-objektin. Kun haluat vapauttaa yhteyden välittömästi, välitä `async: true` tai `callback_url`:

1. Tallenna välittömässä vastauksessa olevat `task_id`- ja `trace_id`-arvot.
2. Jos takaisinsoittoa ei ole määritetty, kutsu `/minimax/tasks` noin 10 sekunnin välein kerran.
3. Kun `task.status` muuttuu arvoksi `succeeded`, hae video osoitteesta `task.content.url`.
4. Kun tila on `failed` tai `cancelled`, lopeta kysely ja lue `task.error`.

## Ylimmän tason pyyntöparametrit

| Parametri             | Tyyppi       | Pakollinen   | Oletusarvo        | Kuvaus                                                |
| -------------- | -------- | ---- | ---------- | ------------------------------------------------- |
| `model`        | string   | Kyllä    | -          | Kiinteästi `MiniMax-H3`                                  |
| `content`      | object[] | Kyllä    | -          | Multimodaalinen sisältötaulukko, jonka on sisällettävä yksi ei-tyhjä `text`-kohde                         |
| `resolution`   | string   | Kyllä    | -          | `768P` tai `2K`                                     |
| `duration`     | integer  | Kyllä    | -          | Luonnin kesto, kokonaisluku 4–15 sekuntia                                     |
| `ratio`        | string   | Ehdollisesti pakollinen | `adaptive` | `adaptive`、`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` |
| `async`        | boolean  | Ei    | `false`    | Kun arvo on `true`, tehtävätunniste palautetaan välittömästi ja tulos haetaan tehtävärajapinnan kautta                       |
| `callback_url` | string   | Ei    | -          | Julkinen takaisinsoitto-URL lopullisen tehtävätuloksen vastaanottamiseen; sen antaminen ottaa asynkronisen tilan automaattisesti käyttöön                     |

`ratio`-säännöt riippuvat työnkulusta:

- **Tekstistä videoksi**：pakollinen, eikä voi olla `adaptive`.
- **Ensimmäisen kehyksen, loppukehyksen tai alku- ja loppukehysvideo**：kuvasuhde määräytyy syötekuvan mukaan, joten on suositeltavaa jättää pois tai välittää `adaptive`.
- **Multimodaalisesta viitemateriaalista videoksi**：voidaan jättää pois, oletusarvo on `adaptive`; voidaan myös määrittää selkeästi kiinteä suhde.

Rajapinta ei hyväksy vanhoja tai yhteensopivuuskenttiä, kuten `prompt`, `image_urls`, `audio_urls`, `messages` ja `first_frame_image`. Kun saat tällaisen parametrivirheen, poista vanhat kentät ja siirry käyttämään `content`-kenttää; muuta esimerkiksi `"prompt": "一只猫挥手"` muotoon `"content": [{"type": "text", "text": "一只猫挥手"}]`。Älä lähetä samanaikaisesti sekä uutta että vanhaa muotoa.

## content-sisältökohteiden parametrit

Jokaisella sisältökohteella on oltava `type`, ja muut kentät määräytyvät tyypin mukaan:

| `type`      | Tietokenttä            | `role`            | Kuvaus                                     |
| ----------- | --------------- | ----------------- | -------------------------------------- |
| `text`      | `text`          | Ei välitetä                | Jokaisen pyynnön on sisällettävä yksi ei-tyhjä tekstikohde, enintään 7000 merkkiä             |
| `image_url` | `image_url.url` | `first_frame`     | Ensimmäisen kehyksen kuva; jos kuva on vain yksi ja `role` jätetään pois, sitä käsitellään myös ensimmäisenä kehyksenä         |
| `image_url` | `image_url.url` | `last_frame`      | Loppukehyksen kuva; voidaan käyttää yksin tai yhdessä `first_frame`-arvon kanssa aloitus- ja päätepisteen hallintaan |
| `image_url` | `image_url.url` | `reference_image` | Viitekohde, hahmo, tuote, vaatetus, kohtaus tai tyyli                    |
| `video_url` | `video_url.url` | `reference_video` | Viiteliike, kameraliike, esitys tai leikkausrakenne                        |
| `audio_url` | `audio_url.url` | `reference_audio` | Viiteäänensävy, dialogi, musiikki tai rytmi                          |

Mediaosoitteet tukevat kolmea muotoa:

- Julkisesti käytettävissä oleva HTTPS-URL, suositellaan suurille tiedostoille.
- `mm_file://{file_id}`, viittaa jo ladattuun tai olemassa olevan tuloksen tiedostoon.
- Vastaavan mediatyypin Base64 data URI. Base64 kasvattaa kokoa noin kolmanneksella, joten varmista, ettei koko pyyntörunko ylitä 64 Mt:tä.

## Materiaalien määritykset ja määrärajoitukset
| Materiaali | Muoto                                          | Yksittäisen tiedoston raja | Mitat / kesto                                                         | Määräraja                        |
| --- | ------------------------------------------- | --------- | --------------------------------------------------------------- | --------------------------- |
| Kuva  | JPG、JPEG、PNG、WEBP、HEIC、HEIF                 | Enintään 30 MB | Leveys ja korkeus kumpikin 256–5760 px; kuvasuhde 0.4–2.5                                    | Enintään 1 aloitusruutu, enintään 1 lopetusruutu, enintään 9 viitekuvaa |
| Video  | MP4、MOV；H.264/AVC 或 H.265/HEVC；音轨 AAC 或 MP3 | Enintään 50 MB | Kukin osio 2–15 s, yhteensä enintään 15 s; leveys ja korkeus kumpikin 256–5760 px; kuvasuhde 0.4–2.5; 23.976–60 fps | Enintään 3 viitevideota                  |
| Ääni  | WAV、MP3                                     | Enintään 15 MB | Kukin osio 2–15 s, yhteensä enintään 15 s                                            | Enintään 3 viiteääntä                  |

Kuvia, videoita ja ääntä on multimodaalisessa viiteskenaariossa yhteensä enintään 12 tiedostoa. Aloitus- ja lopetusruutuskenaariot sekä viitemateriaaliskenaariot ovat toisensa poissulkevia: kun `reference_image`-, `reference_video`- tai `reference_audio`-objektia käytetään, `first_frame`- tai `last_frame`-objektia ei voi enää käyttää, ja päinvastoin.

## Tuotantotasoisten ominaisuuksien esittely

Seuraavat eivät ole konseptikuvia tai paikkamerkkimateriaaleja, vaan MiniMax H3:n virallisten tuotantotasoisten ominaisuuksien esimerkkien todellisia viitesyötteitä ja varsinaisia videotuotoksia. Kolme tapausta kattavat brändilyhytelokuvat, oikeiden ihmisten tarinankerronnan ja muotiverkkokaupan, ja ne soveltuvat mallin kaupallisen tuotannon kannalta keskeisimpien ominaisuuksien arviointiin.

| Ominaisuus       | Tarkastelun painopiste                        |
| -------- | --------------------------- |
| Hahmo- ja kasvoyhdenmukaisuus | Säilyvätkö kasvonpiirteet, kampaus, meikki ja hahmon olemus vakaina monen otoksen vaihdosten jälkeen     |
| Kasvojen ilmaisut     | Lähikuvien katse, mikroilmeet, emotionaalinen jännite ja luonnolliset pään liikkeet      |
| Tuoterakenteen säilyttäminen   | Silmälasien, käsilaukkujen ja muiden tuotteiden ääriviivat, materiaalit, käyttösuhteet ja peiliheijastukset    |
| Brändivisuaalisuuden toteutus   | Ovatko kohtauksen tunnelma, filmirae, värit, Logo ja leikkausrytmi yhtenäisiä |
| Elokuvallinen tarinankerronta    | Voivatko kuvakokojen muutokset, hahmojen liike, kameraliikkeet, rytmi ja ääni muodostaa kokonaisen jakson  |

Tässä ”kasvo-ominaisuuksilla” tarkoitetaan videotuotannon hahmojen ulkoasun yhdenmukaisuutta, kasvojen yksityiskohtia ja ilmaisun hallintaa, ei henkilöllisyyden tunnistamista, kasvojen vertailua tai kasvojen vaihtamisen rajapintaa.

## Tekstistä videoksi

Kun on vain yksi tekstikohde, kyseessä on tekstistä videoksi -toiminto. Se soveltuu kuvan luomiseen suoraan ideasta, käsikirjoituksesta tai otoskuvauksesta. Kehote voidaan jäsentää järjestyksessä ”kohde + toiminta + kohtaus + kamera + valaistus + ääni”.

```bash
curl -X POST 'https://api.acedata.cloud/minimax/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MiniMax-H3",
    "content": [
      {
        "type": "text",
        "text": "15 秒电影级香水广告：清晨海岸的黑色礁石上，透明香水瓶被薄雾与海浪环绕。微距展现瓶身水珠和玻璃折射，镜头从产品特写缓慢拉升到广阔海面；银蓝色调，真实自然光，高级克制，结尾定格产品。"
      }
    ],
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }'
```

Oletussynkroninen tila palauttaa valmiin tehtävän, kun luonti on valmistunut:

```json
{
  "task": {
    "id": "f5977217-ed2c-40da-adbe-93d08235618f",
    "model": "MiniMax-H3",
    "status": "succeeded",
    "content": { "url": "https://cdn.acedata.cloud/minimax/f5977217.mp4" },
    "resolution": "2K",
    "duration": 15,
    "ratio": "16:9"
  }
}
```

Jos pyyntöön lisätään `"async": true`, rajapinta palauttaa välittömästi:

```json
{
  "task_id": "f5977217-ed2c-40da-adbe-93d08235618f",
  "trace_id": "trace_7f8c2b1a"
}
```

## Ensimmäisestä ruudusta videoksi

Merkitse kuva `first_frame`-kuvaksi, jolloin malli alkaa luoda kyseisestä kuvasta. Soveltuu julisteiden, tuotekuvien, hahmosuunnitelmien ja valokuvateosten luonnolliseen elävöittämiseen.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",
      "text": "人物自然呼吸并看向窗外，衣角被微风吹动，镜头缓慢推进"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "https://cdn.acedata.cloud/b1c82e4937.png"
      },
      "role": "first_frame"
    }
  ],
  "resolution": "2K",
  "duration": 5,
  "ratio": "adaptive"
}
```

## Viimeinen ruutu sekä ensimmäisen ja viimeisen ruudun video
Pelkkä `last_frame` antaa mallin luonnollisesti generoida määritettyyn kuvaan asti; sekä `first_frame`- että `last_frame`-kuvien antaminen mahdollistaa aloitus- ja loppupisteen tarkan hallinnan. Sopii siirtymiin, muodonmuutoksiin, kasvuprosesseihin tai tuotteiden ennen ja jälkeen -vertailuihin.

```json
{
  "model": "MiniMax-H3",
  "content": [
    {
      "type": "text",

    },
```

## Multimodaalinen viite videon generointiin

Viitemateriaaleja voidaan käyttää yhdistelmänä: viitekuvat ohjaavat hahmon tai tuotteen ulkonäköä, viitevideot ohjaavat liikettä ja kameratyöskentelyä, ja viiteaudio ohjaa dialogin äänenväriä, musiikkia tai leikkausrytmiä. Kehotteessa tulisi selkeästi ilmoittaa, mitä kukin materiaalityyppi ohjaa, jotta vältetään pelkkä materiaalien lataaminen ilman yhteyksien määrittelyä.

## Takaisinkutsuilmoitus

`callback_url`-parametrin välittäminen ottaa automaattisesti käyttöön asynkronisen tilan: luontirajapinta palauttaa välittömästi `task_id`:n ja `trace_id`:n sekä lähettää tehtävän valmistuttua tähän osoitteeseen POST-pyynnöllä lopullisen tuloksen, jonka rakenne on sama kuin tehtäväkyselyn vastauksessa.

Takaisinkutsun lopullinen tila on `succeeded`, `failed` tai `cancelled`. Vaikka takaisinkutsua käytettäisiin, on suositeltavaa tallentaa myös `task_id`, jotta tehtävää voidaan kysellä aktiivisesti tai puuttuvat ilmoitukset voidaan kompensoida.

## Yleiset virheet

| HTTP-tilakoodi | Merkitys           | Käsittelysuositus                           |
| -------- | ------------ | ------------------------------ |
| `400`    | Parametrivirhe tai virheellinen materiaalien yhdistelmä | Tarkista pakolliset kentät, `role`, materiaalien määrä ja muoto          |
| `401`    | Token puuttuu tai on virheellinen  | Tarkista `Authorization: Bearer ...` |
| `402`    | Saldo tai kiintiö ei riitä      | Lisää yleistä saldoa hallintapaneelissa                     |
| `422`    | Sisällön turvallisuustarkistus ei läpäisty    | Muokkaa kehotetta tai materiaaleja ja lähetä uudelleen                  |
| `429`    | Pyyntöjä on liian usein       | Yritä uudelleen eksponentiaalisen viiveen jälkeen; tehtäväkyselyjen suositeltu väli on noin 10 sekuntia         |
| `500`    | Palvelu ei ole tilapäisesti käytettävissä      | Säilytä pyyntötiedot ja yritä myöhemmin uudelleen                    |

Synkronisen vastauksen `task.status: succeeded` tarkoittaa, että video on generoitu; asynkroninen vahvistus tarkoittaa vain, että tehtävä on siirtynyt jonoon. Veloitus tapahtuu vain, kun tehtävä onnistuu lopullisesti. Tehtävien kysely on maksutonta eikä aiheuta toistuvaa veloitusta.

### H3 Max

`MiniMax-H3-Max` tukee 480P- tai 768P-tarkkuutta sekä 5–15 sekunnin kokonaislukukestoja. Äänisyötteestä ei veloiteta erikseen, kaksi ensimmäistä kuvaa ovat ilmaisia ja ylimenevistä veloitetaan kuva kerrallaan; viitevideoista veloitetaan todellisen syötetyn keston mukaan. Tämä malli ei tue 2K-tarkkuutta.
