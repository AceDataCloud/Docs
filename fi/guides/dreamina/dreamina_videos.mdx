## Unelmien digitaalinen videonluonti API

`POST https://api.acedata.cloud/dreamina/videos`

Ääniohjattu digitaalinen henkilöhahmovideo (OmniHuman 1.5). Anna henkilön valokuva ja ääniohjattu audio, niin luodaan video, jossa henkilö puhuu ja huulensynkronointi on kohdallaan.

### Pyyntöotsikko

| Otsikko          | Arvo                     |
| ---------------- | ----------------------- |
| `Authorization`  | `Bearer <API-avain>`    |
| `Content-Type`   | `application/json`      |

### Pyyntöparametrit

| Parametri        | Tyyppi    | Pakollinen | Selitys                                                                  |
| ---------------- | --------- | ---------- | ----------------------------------------------------------------------- |
| `model`          | string    | Ei         | Malli, oletusarvo `omnihuman-1.5`                                      |
| `image_url`      | string    | Kyllä      | Henkilön valokuvan julkinen URL, suositellaan selkeää etukuvaa         |
| `audio_url`      | string    | Kyllä      | Ääniohjauksen julkinen URL (mp3/wav), suositellaan &lt; 60 sekuntia      |
| `prompt`         | string    | Ei         | Hallitsee ilmeitä, tunteita, vakautta ja tyyliä                         |
| `mask_url`       | string[]  | Ei         | Kohteen mask URL, käytetään usean henkilön kuvassa ohjattavan kohteen määrittämiseen |
| `callback_url`   | string    | Ei         | Jos annettu, palauttaa heti `task_id`, tuloksen luomisen jälkeen kutsuu tätä osoitetta |
| `async`          | boolean   | Ei         | Aseta `true`, niin palauttaa heti `task_id`, ei tarvitse `callback_url`, tuloksia kysytään `/dreamina/tasks` kautta |

### Syöttösuositukset

- **Kuva**: Selkeä, hyvin valaistu etukuva on paras; kasvot eivät saa olla peitettyinä ja niiden tulee olla kohtuullisessa osuudessa kuvassa.
- **Audio**: mp3/wav, tulee olla julkisesti saavutettavissa. Suositeltu kesto on alle 60 sekuntia (1080p suositus ≤30 sekuntia, 720p ≤60 sekuntia).
- `image_url` ja `audio_url` molempien on oltava julkisesti saavutettavissa.

### Vastausesimerkki

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": {
    "task_id": "362b4fed67bd11f1ad1100163e57d510",
    "status": "done",
    "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }
}
```

### Asynkronisuus ja kysely

Rajapinta palauttaa oletusarvoisesti lopullisen videon synkronisesti. Pitkille tehtäville voi käyttää yhtä kahta asynkronista tilaa:

- Anna `callback_url`: Rajapinta palauttaa heti `task_id`, tuloksen luomisen jälkeen kutsuu tätä osoitetta.
- Anna `async: true`: Rajapinta palauttaa heti `task_id`, ja kysytään sitten `POST /dreamina/tasks` (ilmainen) kautta `task_id` tai `trace_id` tuloksia.

Kyselysopimus löytyy [Dreamina Tasks API](https://platform.acedata.cloud/documents/dreamina-tasks-integration).

### Virheiden käsittely

| Tila | koodi                                      | Merkitys                               |
| ---- | ------------------------------------------ | -------------------------------------- |
| 400  | `bad_request`                              | Parametri puuttuu tai on virheellinen (esim. `image_url` / `audio_url`) |
| 401  | `authorization_missing` / `invalid_token` | Valtuutustunnus puuttuu tai on virheellinen |
| 403  | `forbidden`                                | Tasapaino/kiintiö riittämätön tai ylävirta ei ole valtuutettu |
| 429  | `too_many_requests`                        | Liian monta pyyntöä, ylittää nopeusrajoituksen |
| 500  | `api_error`                                | Palvelimen sisäinen virhe              |

```json
{
  "error": {
    "code": "bad_request",
    "message": "image_url is required (a public URL of a portrait image)"
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

### Laskutus

Laskutus perustuu luotujen videoiden kestoon, suurin paketti noin **¥1/sekunti** (esim. 10 sekunnin video noin ¥10).
