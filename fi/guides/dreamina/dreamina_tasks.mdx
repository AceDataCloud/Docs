## Dreamina Tasks API:n liittäminen ja käyttö

Dreamina Tasks API:tä käytetään [Dreamina Video Generation API:n](https://platform.acedata.cloud/documents/dreamina-videos-integration) luomien digitaalisten videoiden tehtävien suoritusresultaatin kysymiseen. Kun syötät `callback_url` tai `async: true` generointirajapintaan, rajapinta palauttaa välittömästi `task_id`:n, jonka avulla voit kysyä tehtävän tilaa ja lopullista videosoitetta tämän rajapinnan kautta `task_id`:n tai `trace_id`:n avulla. **Tämä rajapinta on ilmainen.**

## Hakuprosessi

Käyttääksesi Dreamina-sarjan API:a, sinun on ensin hankittava API Token [Ace Data Cloud -hallintapaneelista](https://platform.acedata.cloud/console/applications) ja pidettävä se varalla.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API Token riittää kutsumaan kaikkia palveluja, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; jos saldo on riittämätön, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

## Pyyntöparametrit

**Pyyntöotsikot**

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, täytä `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, muoto `Bearer {token}`.
- `content-type`: täytä `application/json`.

**Pyyntöruumis**

| Parametri   | Tyyppi     | Pakollinen | Selitys                                               |
| ----------- | ---------- | ---------- | ---------------------------------------------------- |
| `action`    | string     | Ei         | Toimintatyyppi, `retrieve` (oletus, yksittäinen kysely) tai `retrieve_batch` (joukkokysely) |
| `id`        | string     | Ei         | Kysyttävän tehtävän ID (luotaessa videota palautettu `task_id`)                    |
| `trace_id`  | string     | Ei         | Kysyttävän tehtävän jäljitystunnus, voidaan käyttää `id`:n sijasta                         |
| `ids`       | string[]   | Ei         | Joukkokyselyn tehtävän ID -lista, käytetään yhdessä `retrieve_batch`:n kanssa             |

> Yksittäistä tehtävää kysyttäessä, `id` ja `trace_id` on annettava vähintään yksi.

## Yksittäisen tehtävän kysyminen

### CURL

```bash
curl -X POST 'https://api.acedata.cloud/dreamina/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve",
  "id": "362b4fed-67bd-11f1-ad11-00163e57d510"
}'
```

### Python

```python
import requests

url = "https://api.acedata.cloud/dreamina/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "retrieve",
    "id": "362b4fed-67bd-11f1-ad11-00163e57d510"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa kyseisen tehtävän tiedot. `request` on tehtävän luomisen yhteydessä lähetetty pyyntöruumis, `response` on tehtävän valmistumisen jälkeen palautettu vastausruumis, jossa `data.video_url` on luodun digitaalisen videon osoite:

```json
{
  "id": "362b4fed-67bd-11f1-ad11-00163e57d510",
  "started_at": 1769262721.823,
  "finished_at": 1769262769.123,
  "elapsed": 47.3,
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "request": {
    "model": "omnihuman-1.5",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  },
  "response": {
    "success": true,
    "data": {
      "task_id": "362b4fed67bd11f1ad1100163e57d510",
      "status": "done",
      "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
      "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
      "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
    }
  }
}
```

Kenttäselitykset:

- `id`: tämän videon luontitehtävän ainutlaatuinen ID.
- `trace_id`: tämän pyynnön jäljitystunnus, käytetään ongelmien selvittämiseen.
- `request`: tehtävän luomisen yhteydessä lähetetty pyyntö.
- `response`: tehtävän valmistumisen jälkeen palautettu vastaus. Kun `response.data.status` on `done`, `response.data.video_url` on lopullinen videon osoite.
- `created_at`: tehtävän luontiaika, Unix-aikaleima (sekunnit, liukuluku).
- `started_at`: tehtävän aloitusaika, Unix-aikaleima (sekunnit, liukuluku).
- `finished_at`: tehtävän valmistumisaika, Unix-aikaleima (sekunnit, liukuluku). Jos tehtävä ei ole valmis, tätä kenttää ei palauteta.
- `elapsed`: tehtävän suorittamiseen kulunut aika, yksikkönä sekunnit (liukuluku, 3 desimaalia). Jos tehtävä ei ole valmis, tätä kenttää ei palauteta.

> Jos tehtävä ei ole vielä valmis, `status` voi olla muu kuin `done`; jos tehtävää ei ole olemassa tai tulosta ei ole vielä luotu, rajapinta palauttaa tyhjän objektin `{}`, yritä myöhemmin uudelleen.

## Joukkotehtävien kysyminen

Aseta `action` arvoksi `retrieve_batch` ja syötä `ids`-taulukko:

```bash
curl -X POST 'https://api.acedata.cloud/dreamina/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "ids": [
    "362b4fed-67bd-11f1-ad11-00163e57d510",
    "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70"
  ]
}'
```

Palautetussa tuloksessa `items` on joukkotehtävien yksityiskohtien taulukko (jokainen elementti on samanlainen kuin yksittäisen kyselyn tulos), `count` on tämän kerran palautettujen tehtävien määrä.

## Virheiden käsittely

Kun API:ta kutsuttaessa ilmenee virhe, se palauttaa vastaavan virhekoodin ja tiedot:

- `400 bad_request`: Pyyntövirhe, voi puuttua `id` / `trace_id` tai muita tarpeellisia parametreja.
- `401 invalid_token`: Ei valtuutettu, valtuutusavain on virheellinen tai puuttuu.
- `429 too_many_requests`: Liikaa pyyntöjä, ylittää nopeusrajoituksen.
- `500 api_error`: Palvelimen sisäinen virhe.

### Virhevastausesimerkki

```json
{
  "error": {
    "code": "bad_request",
    "message": "id or trace_id is required to retrieve a task"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
