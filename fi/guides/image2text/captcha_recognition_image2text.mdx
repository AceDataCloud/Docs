Tässä artikkelissa esitellään digitaalinen englanninkielinen vahvistuskoodi tunnistus API -liittymisohje, joka perustuu syväoppimisteknologiaan ja jota voidaan käyttää vaihtelevaan pituiseen englanninkieliseen numerovahvistuskoodiin tunnistamiseen. Syötä vahvistuskoodin kuva, ja saat vahvistuskoodin tuloksen.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [digitaalisen englanninkielisen vahvistuskoodin tunnistus API](https://platform.acedata.cloud/documents/cd1f56dc-e9c9-4293-9c68-80fa560c9087) -sivulle ja haettava vastaavaa palvelua. Kun olet sivulla, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, ja voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttää käsiteltävä vaihteleva pituinen englanninkielinen numerovahvistuskoodin kuva, jolloin saat käsitellyn tuloksen. Sinun on ensin yksinkertaisesti välitettävä `image`-kenttä, joka on itse englanninkielinen numerovahvistuskoodin kuva, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/c50hi9.png" width="500" className="m-auto" /></p>

Sitten meidän on muunnettava vahvistuskuva Base64-koodatuksi vahvistuskuvaksi. Suosittelemme käyttämään Google Chrome -laajennusta FeHelper Base64-koodauksen muuntamiseen. Tarkempia käyttöohjeita varten voit viitata alla olevaan kuvaan:

<p><img src="https://cdn.acedata.cloud/zy2jwh.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/pr73gn.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/ic4dbw.png" width="500" className="m-auto" /></p>

Sen jälkeen voit liittää Google Chrome -laajennus FeHelpin saaman Base64-koodauksen, muista, että se ei sisällä data:image/png;base64 -etuliitettä. Tarkka sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/5h4x4w.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers -otsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body -otsikon, mukaan lukien:

- `image`: Base64-koodattu vahvistuskuva (ilman data:image/png;base64 -etuliitettä).

Valinnan jälkeen voit huomata, että oikealle puolelle on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/202y3d.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta, jotta voit testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavan tuloksen:

```json
{
  "text": "7364"
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `text`, tämän vaihteleva pituinen englanninkielinen numerovahvistuskoodin kuva -tehtävän käsittelyn jälkeen saatu tekstisisältö.

Voit nähdä, että olemme saaneet käsitellyn vaihteleva pituinen englanninkielisen numerovahvistuskoodin kuvan vahvistustuloksen, ja voimme vahvistaa sen vain tuloksessa olevan `text`-tekstisisällön perusteella.

Jos haluat luoda vastaavan liittymiskoodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}'
```

Pythonin liittymiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
