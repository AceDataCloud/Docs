Tässä artikkelissa esitellään digitaalinen englanninkielinen vahvistuskoodi tunnistus API -liittymisohje, joka perustuu syväoppimisteknologiaan ja jota voidaan käyttää vaihtelevaan pituiseen englanninkieliseen numerovahvistuskoodiin tunnistamiseen. Syötä vahvistuskoodin kuva, ja saat vahvistuskoodin tuloksen.

## Hakuprosessi

Käyttääksesi digitaalista englanninkielistä vahvistuskoodi tunnistus API:ta, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tokenisi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API-token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla ilmaiseksi; jos määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Digitaalinen englanninkielinen vahvistuskoodi tunnistus API →](https://platform.acedata.cloud/documents/captcha-recognition-image2text)

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syötä käsiteltävä vaihteleva pituinen englanninkielinen numerovahvistuskoodikuva, niin saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `image`-kenttä, joka on kyseinen englanninkielinen numerovahvistuskoodikuva, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/c50hi9.png" width="500" className="m-auto" /></p>

Sitten meidän on muunnettava vahvistuskoodikuva Base64-koodatuksi vahvistuskoodikuvaksi. Suosittelemme käyttämään Google Chrome -laajennusta FeHelper Base64-koodauksen muuntamiseen. Tarkempia käyttöohjeita varten voit viitata alla olevaan kuvaan:

<p><img src="https://cdn.acedata.cloud/zy2jwh.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/pr73gn.png" width="500" className="m-auto" /></p>

<p><img src="https://cdn.acedata.cloud/ic4dbw.png" width="500" className="m-auto" /></p>

Sen jälkeen voit liittää Google Chrome -laajennus FeHelpin saaman Base64-koodauksen, muista, että se ei sisällä data:image/png;base64 -etuliitettä, tarkka sisältö on seuraava:

<p><img src="https://cdn.acedata.cloud/5h4x4w.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers -otsikot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body -otsikon, mukaan lukien:

- `image`: Base64-koodattu vahvistuskoodikuva (ilman data:image/png;base64 -etuliitettä).

Valinnan jälkeen voit huomata, että oikealle puolelle on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/202y3d.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavan tuloksen:

```json
{
  "text": "7364",
  "elapsed": 31.6
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `text`, tämän vaihteleva pituinen englanninkielinen numerovahvistuskoodikuva -tehtävän käsittelyn jälkeen saatu tekstisisältö.
- `started_at`, `finished_at`: tämän pyynnön käsittelyn aloitus- ja tulostusaika, Unix-aikaleima (sekunteina, liukuluku).
- `elapsed`: tämän käsittelyn kokonaisaika (sekunteina).

Voit nähdä, että olemme saaneet vahvistustuloksen vaihtelevaan pituiseen englanninkieliseen numerovahvistuskoodikuvaan, ja voimme vahvistaa sen tuloksessa olevan `text`-tekstisisällön perusteella.

Jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}'
```

Pythonin liittymiskoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX..."
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynkroninen tila (async)

Oletusarvoisesti API on synkroninen ja estää: yksi pyyntö odottaa aina, kunnes tunnistustulos on käsitelty ennen kuin se palauttaa. Jos teet useita koodinvaihtoja (multi-solver rotation) ja haluat "saada task_id:n heti tehtävän lähettämisen jälkeen, jotta voit ensin ohjata muita koodinvaihtajia ja palata myöhemmin lukemaan tuloksia", voit liittää pyyntöön `async: true`.

Kun liität `async: true`, rajapinta palauttaa heti `task_id:n`, eikä se estä odottamista:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/recognition/image2text' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image": "iVBORw0KGgoAAAANSUhEUgAAAgUAAAE3CAYAAAA6xjI2AAAAAX...",
  "async": true
}'
```

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Jos haluat tarkistaa edistymistä aktiivisesti, voit käyttää tätä `task_id:tä` kysyäksesi `POST /captcha/tasks` (suositellaan joka 3-5 sekunti). Tämä rajapinta ei laukaise tai edistä tehtävän käsittelyä; vaikka et kysyisi, katkaise verkkoyhteys tai sulje asiakasohjelma, palvelin jatkaa edelleen käsittelyä:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Käsittelyssä palautuu `status: processing`:

```json
{ "success": true, "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002", "status": "processing" }
```

Käsittelyn valmistuttua palautuu `status: ready` ja tunnistustulos `text` (kenttästruktuuri on täysin sama kuin synkronisessa tilassa):

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "text": "7364"
}
```

Laskutustiedot: asynkronisessa tilassa tehtävän luomista ja "käsittelyssä" -tilan lukemista ei laskuteta; **asiakasohjelma laskutetaan ensimmäisestä onnistuneesta tuloksen lukemisesta** (saman käytännön ja synkronisen tilan hinnan mukaisesti). Palvelin edistää tehtävää itsenäisesti, mutta se ei veloita etukäteen, vaikka taustalla olisi valmis. Tehtävä, jota ei ole onnistuneesti käsitelty 120 sekunnissa, päättyy HTTP 504 `timeout` -tilaan, eikä siitä veloiteta. `/captcha/tasks` ei vastaa tehtävän edistämisestä.

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:
- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
