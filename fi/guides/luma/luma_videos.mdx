AI:n sovellusten yleistyessä erilaiset AI-ohjelmat ovat vähitellen yleistyneet. AI on vähitellen tunkeutunut ihmisten työn ja elämän kaikille osa-alueille. Myös AI:n kattamia toimialoja on yhä enemmän, alun perin kirjoittamisesta lääketieteeseen ja koulutukseen, ja nyt videoihin.

Luma on ammattimainen ja korkealaatuinen videogenerointialusta, jossa käyttäjien tarvitsee vain ladata materiaalia, jotta korkealaatuisia videoita voidaan luoda automaattisesti eri tyylien ja tehosteiden mukaisesti. Tämän AI-videogeneraattorin on kehittänyt tunnetuista teknologiayrityksistä tulevien tiimin jäsenten ryhmä, ja sen tavoitteena on mahdollistaa erinomaisen videon luominen jokaiselle ilman monimutkaisia muokkaustyökaluja.

Luma ei kuitenkaan virallisesti tarjoa APIa. AceDataCloud tarjoaa Lumalle API-sarjan, joka simuloi Sunon virallista liitäntää ja mahdollistaa haluttujen videoiden kätevän ja nopean luomisen.

## Hakeminen ja käyttö

Jotta voit käyttää Luma Videos Generation APIa, hae ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Tokenisi ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisestä hakemuksesta myönnetään ilmainen käyttökiintiö, jolla voi kokeilla palvelua maksutta; kun kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Peruskäyttö

Voit syöttää vapaasti tekstin siitä, millaisen videon haluat luoda. Jos esimerkiksi haluan luoda videon astronauttien liikkumisesta avaruuden ja tulivuoren välillä, voin syöttää `Astronauts shuttle from space to volcano`, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/yub02j.png" width="500" className="m-auto" /></p>

Luotu koodi on seuraava:

<p><img src="https://cdn.acedata.cloud/ieq7yn.png" width="500" className="m-auto" /></p>

Tärkeimmät pyyntöparametrit:

- `prompt`: Kehoteteksti videon luomiseen.
- `aspect_ratio`: Videon kuvasuhde, oletusarvoisesti 16:9.
- `end_image_url`: Valinnainen, määrittää viimeisen ruudun.
- `enhancement`: Valinnainen, terävyyden parannuksen kytkin.
- `loop`: Luodaanko silmukassa toistuva video, oletusarvoisesti false.
- `timeout`: Valinnainen, aikakatkaisun sekuntimäärä.
- `callback_url`: Asynkronisen takaisinsoiton osoite.
- `async`: Valinnainen; kun asetetaan arvoon `true`, rajapinta palauttaa heti `task_id`:n, eikä `callback_url`:ää tarvitse antaa. Tämän jälkeen tulos haetaan kyselyrajapinnan kautta kyselemällä tehtävän tilaa.

Voit testata APIa suoraan napsauttamalla ”Try”-painiketta. Odota 1–2 minuuttia, jolloin tulos on seuraava:

```json
{
  "success": true,
  "task_id": "e4018a99-1522-4f24-9330-62c2a9b50b59",
  "video_id": "155838f8-7f1e-44d8-b387-192f3b4b509d",
  "prompt": "Astronauts shuttle from space to volcano",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "video_height": 752,
  "video_width": 1360,
  "state": "completed",
  "thumbnail_url": "https://platform.cdn.acedata.cloud/luma/e4018a99-1522-4f24-9330-62c2a9b50b59.jpg",
  "thumbnail_width": 1360,
  "thumbnail_height": 752
}
```

Tässä vaiheessa saamme tämän videon tiedot, mukaan lukien video-ID:n, videolinkin, videon kansikuvan ja muuta sisältöä.

Kenttien kuvaukset ovat seuraavat:

- success: Onnistuiko luominen; jos onnistui, arvo on `true`, muussa tapauksessa `false`
- task_id: Tämän videogenerointitehtävän yksilöllinen ID
- video_id: Tämän videogenerointitehtävän tuottaman videon yksilöllinen ID
- prompt: Tämän videogenerointitehtävän avainsanat
- video_url: Tämän videogenerointitehtävän tulosvideon linkki
- video_height: Luodun videon kansikuvan korkeus
- video_width: Luodun videon kansikuvan leveys
- state: Tämän videogenerointitehtävän tila; jos tehtävä on valmis, arvo on `completed`.
- thumbnail_url: Luodun videon kansikuvan linkki
- thumbnail_width: Luodun videon kansikuvan leveys
- thumbnail_height: Luodun videon kansikuvan korkeus

## Mukautettu ensimmäisen ja viimeisen ruudun generointi

Jos haluat luoda videon mukautettujen ensimmäisen ja viimeisen ruudun avulla, voit syöttää ensimmäisen ja viimeisen ruudun kuvalinkit:

Tässä tilanteessa videon ensimmäisen ruudun `start_image_url`-kenttään voidaan välittää seuraava kuva videon ensimmäiseksi ruuduksi:

![Ensimmäinen ruutu](https://cdn.acedata.cloud/r9vsv9.png)

Seuraavaksi, kun haluamme luoda videon mukautetusti ensimmäisen ja viimeisen ruudun sekä avainsanojen perusteella, voimme määrittää seuraavan sisällön:

- action: Videogenerointitehtävän toiminto, tavallisesti normaali luonti `generate` ja laajennettu luonti `extend`, oletusarvo on `generate`.
- start_image_url: Määrittää luotavan videon ensimmäisen ruudun.
- end_image_url: Määrittää luotavan videon viimeisen ruudun.
- prompt: Videon luomisen avainsanasisältö.

Täyttöesimerkki on seuraava:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

Kun täyttö on valmis, luodaan automaattisesti seuraava koodi:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Saatu tulos on seuraava:

```json
{
  "success": true,
  "task_id": "12a18694-fd4b-47e7-9c50-34f30862cff6",
  "video_id": "0105c090-03a5-425a-8026-523341cd575b",
  "prompt": "Astronauts shuttle from space to volcano",
  "video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4",
  "video_height": 656,
  "video_width": 1552,
  "state": "completed",
  "thumbnail_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.jpg",
  "thumbnail_width": 1552,
  "thumbnail_height": 656

```

Lopuksi saatu tulos on samanlainen kuin edellä. Luodun videon ensimmäinen ruutu sisältää välittämämme kuvan. ## Videon laajennustoiminto

Jos haluat jatkaa luodun videon luomista, voit asettaa parametrin `action` arvoksi `extend` ja syöttää videon tunnuksen tai videolinkin, jota haluat jatkaa. Video-ID ja videolinkki saadaan peruskäytön mukaisesti, kuten alla olevassa kuvassa näytetään:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

Tässä vaiheessa voidaan nähdä, että videon ID on:

```
"video_id": "0105c090-03a5-425a-8026-523341cd575b",
"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Huomaa, että videon `video_id` ja `video_url` ovat luodun videon ID ja videolinkki. Jos et tiedä, miten video luodaan, voit katsoa yllä olevasta peruskäytöstä, miten video luodaan.

Videon luomisen jatkamiseksi on ladattava videolinkki tai videon ID. Alla näytetään, miten videon ID:tä käytetään laajentamiseen. Seuraavaksi on täytettävä avainsanat videon luomisen mukauttamiseksi, ja voidaan määrittää seuraava sisältö:

- action: Videon laajentamisen toiminto, jonka tulee tässä olla `extend`.
- prompt: Laajennettavan videon avainsanat.
- video_url: Laajennettavan luodun videon linkki.
- video_id: Laajennettavan luodun videon yksilöllinen ID.
- end_image_url: Laajennettavan luodun videon loppuruutuun määritettävä kuvalinkki, valinnainen parametri.

Täyttöesimerkki on seuraava:

<p><img src="https://cdn.acedata.cloud/vv0rxk.png" width="500" className="m-auto" /></p>

```python
import requests
```

## Asynkroninen takaisinsoitto

Koska Luman videon luomisaika on suhteellisen pitkä, noin 1–2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden avoinna jatkuvasti, mikä johtaa ylimääräiseen järjestelmäresurssien kulutukseen. Siksi tämä API tarjoaa myös tuen asynkronisille takaisinsoitoille.
Kokonaisprosessi on seuraava: kun asiakas käynnistää pyynnön, se määrittää lisäksi `callback_url`-kentän. Kun asiakas käynnistää API-pyynnön, API palauttaa välittömästi tuloksen, joka sisältää `task_id`-kentän tiedot ja edustaa nykyisen tehtävän ID:tä. Kun tehtävä on valmis, musiikin luomisen tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, jossa on myös `task_id`-kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Seuraavaksi opimme esimerkin avulla, miten toimitaan konkreettisesti.

Ensinnäkin Webhook-takaisinkutsu on palvelu, joka voi vastaanottaa HTTP-pyyntöjä. Kehittäjien tulisi korvata se oman rakentamansa HTTP-palvelimen URL-osoitteella. Tässä käytetään esittelyn helpottamiseksi julkista Webhook-esimerkkisivustoa https://webhook.site/. Avaamalla tämän sivuston saat Webhook-URL-osoitteen, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/q78okf.png" width="500" className="m-auto" /></p>

Kopioi tämä URL-osoite, niin sitä voidaan käyttää Webhookina. Tässä esimerkissä se on https://webhook.site/0c87ca0e-cd74-4577-8d68-f2b80fbf8a13.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaksi Webhook-URL-osoitteeksi ja täyttää samalla `prompt`-kentän, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/n2fjvi.png" width="500" className="m-auto" /></p>

Napsauta suorita, ja huomaat, että tulos saadaan välittömästi seuraavasti:

```json
{
  "task_id": "732f8282-7cf8-401c-95f2-42c33aa079a6"
}
```

Odota hetki, niin voimme tarkastella kappaleen luomisen tulosta osoitteessa https://webhook.site/0c87ca0e-cd74-4577-8d68-f2b80fbf8a13, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/1hwm5m.png)

Sisältö on seuraava:

```json

    "prompt": "Astronauts shuttle from space to volcano",
    "video_url": "https://platform.cdn.acedata.cloud/luma/732f8282-7cf8-401c-95f2-42c33aa079a6.mp4",
    "video_height": 752,
    "video_width": 1360,
    "state": "completed",
    "thumbnail_url": "https://platform.cdn.acedata.cloud/luma/732f8282-7cf8-401c-95f2-42c33aa079a6.jpg",
    "thumbnail_width": 1360,
    "thumbnail_height": 752
```

Voidaan nähdä, että tuloksessa on `task_id`-kenttä. Muut kentät ovat samankaltaisia kuin yllä, ja tämän kentän avulla tehtävät voidaan yhdistää toisiinsa.
