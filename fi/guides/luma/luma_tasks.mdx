Luma Tasks API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä Luma Videos Generation API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään Luma Tasks API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Luma Tasks API:n avulla voit helposti kysyä Luma Videos Generation API:n tehtävän suoritusstatus.

## Hakuprosessi

Käyttääksesi Luma Videos Generation API:a, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API-tunnus riittää kutsumaan kaikkia palveluja, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla ilmaiseksi; jos saldo on riittämätön, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen asiakirja: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Pyyntöesimerkki

Luma Tasks API:a voidaan käyttää Luma Videos Generation API:n tulosten kysymiseen. Lisätietoja Luma Videos Generation API:n käytöstä löytyy asiakirjasta [Luma Videos Generation API](https://platform.acedata.cloud/documents/luma-videos-integration).

Otetaan esimerkki yhdestä tehtävä-ID:stä, jonka Luma Videos Generation API:n palvelu palautti, ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 50fc6182-fa86-4c7d-ac12-2fa27ec2f151, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikoiden ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa:

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/i4fxqf.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/luma/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/luma/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Palautetussa tuloksessa on useita kenttiä, request-kenttä on se, joka sisältää tehtävän aloitushetkellä käytetyn request bodyn, ja response-kenttä on se, joka sisältää tehtävän valmistumisen jälkeen palautetun response bodyn, jonka tulokset vastaavat Luma Videos Generation API:n pyyntöä ja vastausta. Kenttien kuvaus on seuraava.

- `id`, tämän videotehtävän ID, jota käytetään yksilöimään tämä videon generointitehtävä.
- `video_id`, tässä kyselyssä olevan videotehtävän videon yksilöivä tunnus, jota tarvitaan seuraavassa videon laajennustoiminnassa.
- `request`, kyselyvideotehtävän pyyntöinformaatio.
- `response`, kyselyvideotehtävän palautetiedot.
- `created_at`, tehtävän luontiaika, Unix-aikaleima (sekunnit, liukuluku).
- `started_at`, tehtävän aloitusaika, Unix-aikaleima (sekunnit, liukuluku).
- `finished_at`, tehtävän valmistumisaika, Unix-aikaleima (sekunnit, liukuluku). Tätä kenttää ei palauteta, jos tehtävä ei ole valmis.
- `elapsed`, tehtävän suorittamiseen kulunut aika, yksikkönä sekunnit (liukuluku, 3 desimaalia). Tätä kenttää ei palauteta, jos tehtävä ei ole valmis.

## Virheiden käsittely

Kun kutsut API:ta, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
