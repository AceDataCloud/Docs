Luma Tasks API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä Luma Videos Generation API:n tuottama tehtävä-ID.

Tässä asiakirjassa käsitellään Luma Tasks API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Luma Tasks API:n avulla voit helposti tarkistaa Luma Videos Generation API:n tehtävän suoritusstatus.

## Hakuprosessi

Käyttääksesi Luma Tasks API:a, sinun on ensin mentävä hakusivulle [Luma Videos Generation API](https://platform.acedata.cloud/documents/5bd3597d-1ff8-44ad-a580-b66b48393e7f) ja haettava vastaavaa palvelua, sitten kopioi Luma Videos Generation API:n tehtävä-ID, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/ynk4ow.png)

Lopuksi siirry Tasks API -sivulle [Luma Tasks API](https://platform.acedata.cloud/documents/7d32369c-4ead-4364-a4c5-652bc768b3ff) ja hae vastaavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), joka kutsuu sinua rekisteröitymään ja kirjautumaan sisään, ja kirjautumisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää tämän API:n ilmaiseksi.

## Pyyntöesimerkki

Luma Tasks API:a voidaan käyttää Luma Videos Generation API:n tulosten kysymiseen. Lisätietoja Luma Videos Generation API:n käytöstä löytyy asiakirjasta [Luma Videos Generation API](https://platform.acedata.cloud/documents/16bb0108-1f09-45b3-97ac-16a668750a8c).

Otetaan esimerkki yhdestä Luma Videos Generation API:n palauttamasta tehtävä-ID:stä ja näytetään, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: 50fc6182-fa86-4c7d-ac12-2fa27ec2f151, seuraavaksi näytetään, kuinka syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoisia vastauksia, tässä täytetään `application/json`.
- `authorization`: API:n kutsuavain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

Aseta kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/g6ev5b.png" width="500" class="m-auto"></p>

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodi eri kielillä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/i4fxqf.png" width="500" class="m-auto"></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/luma/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/luma/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "50fc6182-fa86-4c7d-ac12-2fa27ec2f151",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

Kun kutsut API:ta, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
