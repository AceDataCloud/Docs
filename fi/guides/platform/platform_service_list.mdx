Palauttaa sivutettuna nykyisellä sivustolla näkyvän Service-hakemiston, mukaan lukien palvelutyypit, näyttötiedot, ilmaiset kiintiöt, paketit ja niihin liittyvät API/Proxy-ID:t. Soveltuu palvelumarkkinapaikan rakentamiseen tai haettavien palvelujen valintaan.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                |
| --- | ------------------------------------------------- |
| Menetelmä  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Todennus  | Julkinen; kirjautuneena `applied` heijastaa vasta nykyistä tiliä                        |
| Sivutus  | `count` + `items`                                 |

## Kyselyparametrit

| Parametri               | Tyyppi      | Pakollinen  | Kuvaus                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Ei   | Suodata palvelu-ID:n mukaan; tukee toistuvia parametreja         |
| `private`        | boolean | Ei   | Suodata julkisen tilan mukaan; sivuston näkyvyyssäännöt ovat edelleen voimassa      |
| `type`           | string  | Ei   | Palvelutyyppi; tukee toistuvia parametreja              |
| `tag`            | string  | Ei   | Suodata tunnisteen mukaan                    |
| `include_facets` | boolean | Ei   | Kun `true`, liittää nykyisellä sivustolla käytettävissä olevat tyyppi-/tunnistetilastot |
| `limit`          | integer | Ei   | Rivien määrä sivua kohden, enintään 100              |
| `offset`         | integer | Ei   | Sivutussiirtymä                    |
| `ordering`       | string  | Ei   | Tukee vain arvoja `rank` tai `-rank`     |

Luettelo ei tue `alias`-suodatusta; jos alias on jo olemassa, pyydä suoraan `/api/v1/services/{alias}`. `applied_count` ja `updated_at` eivät ole sallittuja lajittelukenttiä.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Vastauksen kuvaus

Vastaus on `{count, items}`; `facets` lisätään vain, kun `include_facets=true`. Palvelukohde sisältää muun muassa nykyiset julkiset kentät `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost` ja `packages`.

`applied` ei anonyymissä luettelossa edusta minkään tilin hakemustilaa. Kun tarvitaan tiliin liittyvää tilaa, tulee käyttää voimassa olevaa kirjautumistilaa ja pitää [palveluhakemusluetteloa](https://platform.acedata.cloud/documents/platform-application-list) lopullisena perusteena.
