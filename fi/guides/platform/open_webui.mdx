[Open WebUI](https://openwebui.com/) (entinen Ollama WebUI) on avoimen lähdekoodin AI-asiakas, joka tukee useita käyttäjiä, tietokantoja, RAG:ia ja yksityistä käyttöönottoa. Se tukee mukautettuja OpenAI-yhteensopivia päätepisteitä, joten se voidaan yhdistää Ace Data Cloudiin. Tässä artikkelissa esitellään määritysprosessi.

## Hakuprosessi

Jotta voit yhdistää Ace Data Cloudin Open WebUI:ssa, siirry ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications), hanki API Tokenisi ja säilytä se varalla.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen tai rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisen hakemuksen yhteydessä myönnetään ilmaista käyttökiintiötä, joten voit kokeilla Ace Data Cloudin mallipalveluja maksutta.

## Ace Data Cloudin käyttöönotto ja määritys

Open WebUI yhdistyy OpenAI-yhteensopivaan päätepisteeseen ympäristömuuttujien kautta, ja se voidaan ottaa käyttöön yhdellä Docker-komennolla (korvaa `{token}` Tokenillasi):

```bash
docker run -d \
  --name open-webui \
  -p 3000:8080 \
  -e WEBUI_SECRET_KEY=$(openssl rand -base64 32) \
  -e OPENAI_API_BASE_URL=https://api.acedata.cloud/v1 \
  -e OPENAI_API_KEY={token} \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
```

| Ympäristömuuttuja                              | Toiminto                                 |
| --------------------------------- | ---------------------------------- |
| `OPENAI_API_BASE_URL`             | Ace Data Cloudin päätepiste, **on päätyttävä `/v1`** |
| `OPENAI_API_KEY`                  | Tokenisi                           |
| `WEBUI_SECRET_KEY`                | session-salausavain, luodaan automaattisesti                  |
| `-v open-webui:/app/backend/data` | Keskustelu- / käyttäjätietojen pysyvä tallennus                       |

Avaa `http://palvelimesi-IP:3000`, ensimmäiseksi rekisteröidystä tilistä tulee automaattisesti ylläpitäjä. Huomaa Base URL:n polkusäännöt:

| OPENAI_API_BASE_URL                   | Todellinen pyyntö                                                   | Tulos                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Oikein                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Myös käytettävissä                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai`-polun alla ei ole `/v1`:tä) |

Siirry kirjautumisen jälkeen kohtaan **Admin Panel → Settings → Connections** ja napsauta ”Verify Connection” vahvistaaksesi yhteyden; kohdassa **Settings → Models** voit suodattaa ja Pinata usein käytettyjä malleja.

> Ympäristömuuttujien lisäksi Open WebUI tukee myös yhteyden lisäämistä suoraan käyttöliittymässä: siirry kohtaan **Admin Settings → Connections**, napsauta ➕ ja täytä URL (`https://api.acedata.cloud/v1`) sekä API Key. Open WebUI kutsuu automaattisesti `/models`-päätepistettä hakeakseen malliluettelon. Katso lisätietoja virallisesta dokumentaatiosta [Starting With OpenAI-Compatible Servers](https://docs.openwebui.com/getting-started/quick-start/connect-a-provider/starting-with-openai-compatible).

![Open WebUI Ace Data Cloud Connection -määritysnäkymä](https://cdn.acedata.cloud/f366abfd935d.png)

> `MODEL_ID` on tarkoitettu vain valinnaisen sallittujen mallien luettelon esittelyyn; kun se jätetään tyhjäksi, näytetään kaikki `/models`-päätepisteen palauttamat mallit.

## Mallin valitseminen

Malliluettelo päivittyy jatkuvasti. Käytä ensisijaisesti asiakkaan automaattisesti lataamaa malliluetteloa; jos sinun on täytettävä tiedot manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models` saadaksesi nykyiset malli-ID:t ja valitse sitten asiakkaan tukemien konteksti-, kuva- ja työkalukutsuominaisuuksien mukaan.

## Integroinnin vahvistaminen

Jos et ole varma, onko ongelma Open WebUI:ssa vai verkossa, voit ensin vahvistaa päätepisteen suoraan curlilla (korvaa `{token}` Tokenillasi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI-yhteensopivan `chat.completion`-objektin palautuminen tarkoittaa, että sekä Token että päätepiste ovat valmiita; jos palautuu `HTTP 403 used_up`, Token on voimassa mutta saldo ei riitä, ja voit lisätä saldoa [konsolissa](https://platform.acedata.cloud/console/applications).

## Edistynyt: tietokanta ja useat käyttäjät

Open WebUI:n tietokanta (RAG) käyttää oletuksena ChromaDB:tä vektorien tallentamiseen, ja upotusmalliksi voidaan määrittää `text-embedding-3-large` (Ace Data Cloudin kautta). Asiakirjojen alkuperäiset tekstit säilyvät vain palvelimellasi, ja vain osuneet katkelmat lähetetään mallille. Kohdassa **Admin Panel → Users** voit hallita käyttäjärooleja (Pending / User / Admin); on suositeltavaa asettaa ”Default User Role” arvoksi `pending`, jolloin uudet käyttäjät voivat käyttää palvelua vasta tarkistuksen jälkeen, jotta ulkopuoliset eivät rekisteröidy vapaasti kuluttamaan käyttökiintiötä. Jos käytät nginx-käänteisvälityspalvelinta, lisää `proxy_buffering off;` ja `client_max_body_size 100M;`.

## Usein kysytyt kysymykset

### Näytetään Connection error / 404

Yleensä `OPENAI_API_BASE_URL` on kirjoitettu muodossa `.../openai/v1` tai siitä puuttuu `/v1`. Muuta se muotoon `https://api.acedata.cloud/v1`.

### Keskustelu ei onnistu asiakirjan lataamisen jälkeen

Valitse Admin Panelin RAG-asetuksissa upotusmalliksi `text-embedding-3-large` (OpenAI provider).

### Tiedot katoavat säilön uudelleenkäynnistyksen jälkeen

Tietomääritys `-v open-webui:/app/backend/data` on liitettävä käynnistyksen yhteydessä.
