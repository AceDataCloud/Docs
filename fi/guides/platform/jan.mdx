[Jan](https://jan.ai/) on offline-first avoimen lähdekoodin AI-työpöytäasiakas, joka voi sekä suorittaa malleja paikallisesti että yhdistää OpenAI-yhteensopiviin päätepisteisiin **Remote Enginen** kautta. Tässä artikkelissa esitellään, kuinka Ace Data Cloud yhdistetään.

## Hakuprosessi

Jotta voit yhdistää Ace Data Cloudin Janiin, siirry ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications), hanki API Tokenisi ja säästä se myöhempää käyttöä varten.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisen hakemuksen yhteydessä myönnetään ilmaista käyttökiintiötä, joten voit kokeilla Ace Data Cloudin mallipalveluja ilmaiseksi.

## Lataa Jan

Siirry [Janin viralliselle sivustolle](https://jan.ai/) ja lataa alustallesi sopiva versio (Windows, macOS, Linux). Apple Silicon -laitteille lataa arm64-paketti parhaan suorituskyvyn saavuttamiseksi.

## Ace Data Cloudin määrittäminen

Jan jakaa mallit kahteen luokkaan: **Local Engine** (paikallinen suoritus) ja **Remote Engine** (kolmannen osapuolen API). Ace Data Cloud käyttää OpenAI-yhteensopivaa protokollaa ja yhdistetään Remote Enginen kautta.

Avaa Jan, siirry kohtaan **Settings → Model Providers**, etsi **OpenAI**-kortti ja muokkaa sitä:

| Kenttä       | Arvo                              | Kuvaus                       |
| -------- | ------------------------------ | ------------------------ |
| API Key  | Ace Data Cloud Tokenisi        | Konsolista kopioitu Token             |
| Base URL | `https://api.acedata.cloud/v1` | **Täytyy päättyä `/v1`:een, eikä lopussa saa olla vinoviivaa** |

> Base URLin täytyy päättyä `/v1`:een, mikä on Janin virallisen dokumentaation selkeä käytäntö. Jos et halua korvata alkuperäistä OpenAI-määritystä, voit luoda uuden `openai-compatible`-tyyppisen Providerin valitsemalla 「+ Add Provider」 ja täyttää samat tiedot.

![Janin AceDataCloud Providerin lisäämisen määritysnäkymä](https://cdn.acedata.cloud/26017d28afa1.png)

Kun mukautettu Provider on tallennettu, Jan yrittää ensin kutsua `{Base URL}/models` malliluettelon hakemiseksi. Jos nykyinen versio tai päätepiste ei palauta käytettävissä olevaa luetteloa, napsauta samalla muokkaussivulla alempana **+ Add Model** ja täytä mallin ID manuaalisesti. Lisäämisen jälkeen malli näkyy vasemman yläkulman pudotusvalikossa, ja siinä on 「Cloud」-kuvake etä-/paikallismallien erottamiseksi.

![Jan Providerin mallinhallintanäkymä](https://cdn.acedata.cloud/ae485550946c.png)

> `MODEL_ID` on paikkamerkki; siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan ja korvaamaan se kohdemallin nimellä; tarkan vahvistuksen yhteydessä käytä `/v1/models`-vastauksen `id`-arvoa. Tämä arvo on API:n `model`-parametrissa käytettävä mallin nimi, ei palvelun tai API:n UUID.

## Mallin valitseminen

[Malliluettelo](https://platform.acedata.cloud/models) päivittyy jatkuvasti. Käytä ensisijaisesti asiakkaan automaattisesti lataamaa malliluetteloa; jos tiedot täytyy täyttää manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models`, kopioi kohdemallin `id`-arvo vastauksen `data`-taulukosta ja valitse sitten asiakkaan tukemien konteksti-, kuva- ja työkalukutsuominaisuuksien mukaan.

## Yhteyden vahvistaminen

Jos et ole varma, johtuuko ongelma Janista vai verkosta, voit ensin vahvistaa päätepisteen suoraan curlilla (korvaa `{token}` Tokenillasi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI-yhteensopivan `chat.completion`-objektin palautuminen tarkoittaa, että Token ja päätepiste ovat valmiita; jos palautetaan `HTTP 403 used_up`, Token on voimassa, mutta saldo ei riitä, ja voit lisätä saldoa [konsolissa](https://platform.acedata.cloud/console/applications).

## Edistynyt: paikallisen ja pilven yhdistelmä

Janissa on sisäänrakennettu käyttöön otettava paikallinen OpenAI-yhteensopiva API Server (Settings → Local API Server), joka kuuntelee käyttöönoton jälkeen osoitteessa `http://localhost:1337/v1/chat/completions` ja suorittaa lataamiasi paikallisia malleja. Näin voit suunnata Base URLin paikalliseen osoitteeseen maksutonta virheenkorjausta varten LangChainin / LlamaIndexin kaltaisissa kehyksissä ja vaihtaa monimutkaisissa tehtävissä Ace Data Cloudin etämalleihin. Keskustelukonteksti ei katoa mallia vaihdettaessa.

## Usein kysytyt kysymykset

### Näkyviin tulee Connection error tai 404

Yleensä Base URL:sta puuttuu `/v1`. Muuta se muotoon `https://api.acedata.cloud/v1` (sen täytyy päättyä `/v1`:een, eikä sitä saa kirjoittaa muotoon `.../openai/v1`).

### Näkyviin tulee 401 Unauthorized

Varmista, että API Keyhin on liitetty Ace Data Cloudin Token (ilman `Bearer`-etuliitettä ja ilman ylimääräisiä välilyöntejä) ja että siihen kuuluvan sovelluksen saldo on riittävä.

### Etämalli ei näy pudotusvalikossa

Napsauta ensin mallin päivityspainiketta käynnistääksesi `/v1/models`-kutsun; jos automaattinen havaitseminen epäonnistuu, lisää malli manuaalisesti valitsemalla **+ Add Model** ja lisää luettelossa oleva mallin `id`-arvo sellaisenaan.

### Voiko kuvia ladata mallin analysoitavaksi

Voi, mutta nykyisestä malliluettelosta on valittava malli, joka tukee selkeästi visuaalista syötettä.
