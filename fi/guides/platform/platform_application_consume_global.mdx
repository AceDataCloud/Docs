---
title: "AceDataCloud Applicationin globaalin saldon jakamisen määrittäminen"
description: "Platform API guide - Ace Data Cloud"
---

Määritä `allow_consume_global`. Kun tämä otetaan käyttöön, ehdot täyttävä käytön mukaan laskutettava Application voi jatkaa tilin globaalin saldon käyttöä, kun sen oma saldo ei riitä.

## Valmistelut

- Luo ja tallenna turvallisesti [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Hae omistamasi `application_id` [palveluhakemusluettelosta](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='tilisi tunnus'
export APPLICATION_ID='Application ID:si'
```

## Rajapinnan yleiskatsaus

| Kohta    | Sisältö                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Menetelmä   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Todennus   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Onnistunut vastaus palauttaa päivitetyn Application-objektin. Noudata vastauksessa olevaa arvoa `allow_consume_global` sen sijaan, että olettaisit pyynnön arvon varmasti tallentuneen.

> `Period`-tyyppinen Application ei saa kuluttaa globaalia saldoa. Vaikka pyynnössä annettaisiin `true`, palvelin pitää tämän kentän arvossa `false`.

## Virheenkäsittely

- `401`: Account Token on virheellinen tai puuttuu.
- `403`: Nykyinen tili ei ole tämän Applicationin omistaja.
- `404`: Application ID:tä ei ole olemassa.

Globaalin saldon latauskanava ja saatavilla olevat paketit määräytyvät alustakonsolin sekä [tilauksen luomisen](https://platform.acedata.cloud/documents/platform-order-create) palauttamien todellisten pakettien mukaan; älä oleta, että `Wallet`-tyyppisiä paketteja on olemassa.
