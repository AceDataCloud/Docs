---
title: "AceDataCloud Applicationin globaalin saldon jakamisen määrittäminen"
description: "Platform API guide - Ace Data Cloud"
---

Määritä `allow_consume_global`. Käyttöönoton jälkeen ehdot täyttävät käytön mukaan laskutettavat Applicationit voivat jatkaa tilin globaalin saldon käyttöä, kun niiden oma saldo ei riitä.

## Valmistelut

- Luo ja tallenna turvallisesti [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Hae omistamasi `application_id` [palveluhakemusluettelosta](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='sinun tilitunnuksesi'
export APPLICATION_ID='sinun Application ID:si'
```

## Rajapinnan yleiskatsaus

| Kohta    | Sisältö                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Menetelmä   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Todennus   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Onnistuneena vastauksena palautetaan päivitetty Application-objekti. Noudata vastauksen `allow_consume_global`-arvoa äläkä oleta, että pyynnön arvo on varmasti tallennettu.

> `Period`-tyyppiset Applicationit eivät saa kuluttaa globaalia saldoa. Vaikka pyytäisit arvoa `true`, palvelin säilyttää tämän kentän arvona `false`.

## Virheenkäsittely

- `401`: Account Token on virheellinen tai puuttuu.
- `403`: Nykyinen tili ei ole tämän Applicationin omistaja.
- `404`: Application ID:tä ei ole olemassa.

Globaalin saldon latauskanava ja käytettävissä olevat paketit määräytyvät alustakonsolin sekä [tilauksen luomisen](https://platform.acedata.cloud/documents/platform-order-create) palauttamien todellisten pakettien mukaan; älä oleta, että `Wallet`-tyyppisiä paketteja on olemassa.

## Sovellukset, joille on myönnetty ylitysoikeus

Kun käytön mukaan laskutettavan sovelluksen vain luku -kentän arvo on `allow_overdraft=true`, sovellus voi jatkaa maksujen veloittamista omasta saldostaan, vaikka saldo muuttuisi negatiiviseksi, eikä se vaihda globaalille tilille saldon riittämättömyyden vuoksi. Sovellukset, joilla ylitysoikeutta ei ole otettu käyttöön, noudattavat edelleen asetusta `allow_consume_global`; sen jälkeen, kun vaihto on tehty, ylityksen salliminen määräytyy todellisuudessa veloitettavan globaalin Applicationin asetusten mukaan.
