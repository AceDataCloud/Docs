## 1. Hanki API Key

Avaa [Ace Data Cloudin sovellusluettelo](https://platform.acedata.cloud/console/applications), siirry käytettävissä olevaan sovellukseen ja kopioi API Key.

![Ace Data Cloud API Keyn hakeminen](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Lisää Provider

Avaa Cherry Studio, siirry kohtaan **Asetukset → Mallipalvelut → Lisää palveluntarjoaja**, ja täytä:

| Kenttä      | Arvo                           |
| ------- | --------------------------- |
| Palveluntarjoajan nimi   | `Ace Data Cloud`            |
| Palveluntarjoajan tyyppi   | `OpenAI`                    |
| API Key | Juuri kopioitu API Key               |
| API-osoite  | `https://api.acedata.cloud` |

![Cherry Studion Ace Data Cloud Providerin lisäysmääritysnäkymä](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio täydentää OpenAI-tyypille automaattisesti `/v1/chat/completions`. Kun käytät yleistä päätepistettä, älä lisää `#`-merkkiä osoitteen loppuun, eikä Provideria tarvitse luoda useita kappaleita malliperheittäin.

## 3. Lisää ja ota malli käyttöön

1. Napsauta **Hae malliluettelo**; jos nykyinen versio ei tue automaattista hakua, siirry [malliluetteloon](https://platform.acedata.cloud/models) tarkistamaan tiedot ja lisää sitten kohdemallin nimi manuaalisesti, esimerkiksi `claude-opus-5`, `gpt-6-sol`.
2. Napsauta API Keyn vieressä olevaa tarkistuspainiketta vahvistaaksesi yhteyden.
3. Ota Providerin **Käytössä**-kytkin käyttöön.
4. Valitse juuri lisätty malli keskustelumallin valitsimessa.

![Cherry Studion Provider- ja malliluettelo](https://cdn.acedata.cloud/149de1d088bf.png)

> Kun mallin haku tai manuaalinen lisäys on valmis, ota käyttöön oikeassa yläkulmassa oleva Provider-kytkin.

Lähetä `Reply only OK` ja tarkista kutsu [käyttöhistoriasta](https://platform.acedata.cloud/console/usages). Tarkista 401-virheessä Key; jos malli ei näy, tarkista, onko Provider käytössä; tarkista 404-virheessä, vastaako manuaalisesti syötetty mallin nimi täysin luettelon `id`-arvoa.

## Tietoja GPT Image 2:sta

Cherry Studion tavallinen mukautettu keskustelu-Provider ei voi kutsua Images APIa suoraan. `gpt-image-2`-mallin luontiin ja muokkaukseen tulee käyttää Ace Data Cloudin erikoisrajapintoja:

- [GPT Image 2 -kuvanluonti](https://platform.acedata.cloud/documents/openai-images-generations)
- [GPT Image 2 -kuvanmuokkaus](https://platform.acedata.cloud/documents/openai-images-edits)

Älä syötä `/openai/images/generations` keskustelu-Provideriin.
