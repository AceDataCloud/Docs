Coze tukee virallisesti mukautettujen mallien liittämistä ja tarjoaa kolme protokollaa: OpenAI Chat API, OpenAI Responses API ja Anthropic Messages API. Kolmen reitin Base URL, polkujen yhdistely, Header, streaming ja työkalujen kutsusopimukset ovat erilaisia, joten ne on konfiguroitava ja vahvistettava erikseen.

| Reitti                     | Tila     | Opas                                                                                   |
| ----------------------- | -------- | ------------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Kokeellinen | [Chat-konfiguraatio](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Kokeellinen | [Responses-konfiguraatio](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Kokeellinen | [Messages-konfiguraatio](https://platform.acedata.cloud/documents/coze-messages-integration)   |

"Kokeellinen" tarkoittaa, että viralliset kyvyt ja konfiguraatiopisteet on vahvistettu, mutta eri Coze-alueet, versiot tai paketit saattavat näyttää erilaisia lomakkeita, Ace Data Cloudin on edelleen suoritettava kiinteän version vahvistus protokollan mukaan. Älä yritä laajentaa yhden protokollan onnistumista muihin kahteen.

## Konfigurointiperiaatteet

- Base API URL:lle on ensisijaisesti täytettävä asiakirjassa annettu base; älä lisää uudelleen asiakasta automaattisesti täydentävää endpoint polkua.
- API Key:na käytä Ace Data Cloud API Tokeniasi.
- Mallina käytä tarkkaa mallin ID:tä, joka on yhteensopiva valitun protokollan kanssa mallihakemistossa.
- Tavallisen tekstin onnistumisen jälkeen on myös vahvistettava streaming ja työkalujen kutsu.
