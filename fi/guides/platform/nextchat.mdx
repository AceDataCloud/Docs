[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (aiemmin ChatGPT-Next-Web) on avoimen lähdekoodin AI-asiakasohjelma, joka voidaan ottaa käyttöön Vercelissä, Cloudflaressa tai Dockerissa. Se tukee mukautettuja OpenAI-yhteensopivia päätepisteitä, joten siihen voidaan liittää Ace Data Cloud. Tässä artikkelissa esitellään määritysprosessi.

## Hakuprosessi

Jotta voit liittää Ace Data Cloudin NextChatiin, siirry ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications), hanki API Tokenisi ja säilytä se varalla.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla myönnetään ilmainen käyttökiintiö, jolla voit kokeilla Ace Data Cloudin mallipalvelua maksutta.

## Lataa NextChat

Voit käyttää työpöytäversiota (lataa `.exe` / `.dmg` / AppImage [Releases-sivulta](https://github.com/ChatGPTNextWeb/NextChat/releases)), [verkkoversiota](https://app.nextchat.club/) tai ottaa sen itse käyttöön Vercelissä / Cloudflaressa / Dockerissa (katso alla oleva edistynyt osio).

## Määritä Ace Data Cloud

Käynnistä NextChat ja siirry kohtaan **Asetukset → Mallipalvelu**:

| Kenttä | Arvo | Kuvaus |
| ----------- | --------------------------- | ------------------------------- |
| Mallipalveluntarjoaja | `OpenAI` | Käytä OpenAI-yhteensopivaa protokollaa |
| OpenAI-rajapinnan osoite | `https://api.acedata.cloud` | Täytä vain juuriverkkotunnus, **ilman `/openai`-osaa ja ilman `/v1`-osaa** |
| API Key | Ace Data Cloud Tokenisi | Konsolista kopioitu Token |

![NextChat Ace Data Cloud -määritysnäkymä](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat liittää automaattisesti `/v1/chat/completions` rajapinnan osoitteen perään, joten pelkkä juuriverkkotunnus riittää:

| Rajapinnan osoite | Todellinen pyyntö | Tulos |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud` | `https://api.acedata.cloud/v1/chat/completions` | Oikein |
| `https://api.acedata.cloud/openai` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai`-polun alla ei ole `/v1`-osaa) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404 |

Täytä mallit englanninkielisillä pilkuilla eroteltuna kohtaan ”Mukautettu mallin nimi”. NextChat tukee erityistä syntaksia: `+mallin_nimi` lisää, `-mallin_nimi` piilottaa, `mallin_nimi=näyttönimi` mukauttaa näyttönimen ja `-all` piilottaa ensin kaikki. Suositeltu selkein kirjoitustapa:

```text
-all,+MODEL_ID=显示名称
```

## Valitse malli

Mallihakemisto päivittyy jatkuvasti. Käytä ensisijaisesti asiakasohjelman automaattisesti lataamaa malliluetteloa; jos mallin nimi täytyy täyttää manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models` saadaksesi nykyisen mallin ID:n ja valitse sitten asiakasohjelman tukemien konteksti-, kuva- ja työkalukutsuominaisuuksien mukaan.

## Varmista integraatio

Jos et ole varma, johtuuko ongelma NextChatista vai verkosta, voit ensin varmistaa päätepisteen suoraan curlilla (korvaa `{token}` Tokenillasi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI-yhteensopivan `chat.completion`-objektin palautuminen tarkoittaa, että sekä Token että päätepiste ovat valmiina; jos palautuu `HTTP 403 used_up`, Token on kelvollinen mutta saldo on riittämätön, joten lataa saldoa [konsolissa](https://platform.acedata.cloud/console/applications).

## Edistynyt: ota käyttöön omalla verkkotunnuksellasi yhdellä komennolla

NextChat tukee oman AI-verkkosivuston käyttöönottoa. Esimerkkinä Docker (korvaa `{token}` Tokenillasi):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Vercel- / Cloudflare-käyttöönotossa määritä samat `OPENAI_API_KEY`-, `BASE_URL`-, `CODE`- ja `CUSTOM_MODELS`-asetukset projektin ympäristömuuttujissa. `CODE` tukee useita englanninkielisillä pilkuilla eroteltuja käyttöoikeussalasanoja, mikä helpottaa käytön tilastointia henkilöittäin. Katso näiden ympäristömuuttujien täydelliset ohjeet (`BASE_URL` on oletuksena `https://api.openai.com`, `CUSTOM_MODELS` tukee syntaksia `+/-/=/-all/+all`) [NextChatin virallisesta README-tiedostosta](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Usein kysytyt kysymykset

### Näyttää virheen 404 Not Found

Rajapinnan osoitteeksi on yleensä kirjoitettu `.../openai` tai `.../openai/v1`. Muuta se muotoon `https://api.acedata.cloud` ja anna NextChatin liittää itse `/v1/chat/completions`.

### Lisättyä mallia ei ole mallin pudotusvalikossa

Tarkista `CUSTOM_MODELS`-muoto: jokaisen mallin edessä on oltava `+`; jos käytit `-all`-asetusta, varmista, että lisäät tarvittavat mallit takaisin `+`-merkillä.

### Näyttää virheen 401 Unauthorized

Varmista, että API Key -kenttään liitetty arvo on Ace Data Cloudin Token (ilman `Bearer`-etuliitettä ja ilman ylimääräisiä välilyöntejä) ja että kyseiseen sovellukseen liittyvä saldo on riittävä.
