Hae yksittäisen dokumentin täydellinen sisältö ja navigaatiosuhteet dokumentin UUID:n tai aliaksen avulla. Kun alias tiedetään, pyynnön voi tehdä suoraan ilman, että sitä tarvitsee ensin suodattaa luettelosta.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                              |
| --- | --------------------------------------------------------------- |
| Menetelmä  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Todennus  | Julkinen; suora luku on mahdollista, kun UUID tai alias tiedetään                                       |

## Parametrit

- `id_or_alias`: Dokumentin UUID, nykyinen alias tai vanha alias, joka on säilytetty kentässä `redirect_from`.
- `lang`: Valinnainen kielivihje; myös `Accept-Language`-otsaketta voi käyttää. Sisällön lopullinen kieli määräytyy vastauksen `content_locale`-kentän mukaan.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Vastauksen kuvaus

Tiedot palautetaan yhtenä objektina, joka sisältää tällä hetkellä:

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags`;
- `content`, `content_mode`, `content_locale`, `content_hash`;
- `parent`, `sibling` sekä `rank`-järjestykseen lajitellut julkisten `children`-kohteiden tiivistelmät;
- `api` / `proxy` / `dataset` / `integration` -liitokset sekä `agent` (jos olemassa).

Vastauksessa ei ole `breadcrumbs`-kenttää. Murupolkuja rakennettaessa voidaan jatkaa lukemalla kohteen `parent` tiedot tai käyttää välimuistiin tallennettuja dokumenttihakemiston suhteita.

## Virheenkäsittely

- ID:tä/aliasta ei ole olemassa tai se ei vastaa nykyisen sivuston näkyvyyttä: `404`. `private` hallitsee vain luettelon näkyvyyttä eikä estä linkin tuntevia lukemasta sisältöä suoraan, joten sitä ei voi käyttää luottamuksellisuuden rajana.
- Nykyinen reitti käyttää muotoa ilman loppuviivaa; älä luota siihen, että välityskerros lisää viivan automaattisesti.
