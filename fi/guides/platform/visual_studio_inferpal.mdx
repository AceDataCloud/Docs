Inferpal on laajennus Visual Studio 2022/2026:lle, joka tukee virallisesti OpenAI-yhteensopivia palveluja. Laajennusversio voi vaikuttaa muokkaukseen, työkalujen kutsumiseen ja käyttötilastointiin; ensimmäisellä liittämisellä varmista kiinteä versio ja suorita alla olevan minimivarmistuksen.

## Konfigurointi

1. Asenna Inferpal Visual Studio Marketplace:sta tai virallisesta varastosta.
2. Avaa Inferpalin **Asetukset → Yhteys**.
3. Valitse Provideriksi OpenAI-yhteensopiva.
4. Täytä Base URL:ksi `https://api.acedata.cloud/v1`.
5. Täytä API Key:ksi oma Ace Data Cloud API Tokenisi.
6. Täytä Model:ksi mallihakemistossa tuettu Chat Completions -mallin tarkka ID.
7. Tallenna ja lähetä `Reply only OK`, ja suorita sitten uudelleen pyyntö, joka sisältää koodikontekstin.

## Nykyiset rajat

- Tämä opas kattaa vain Inferpalin, eikä se edusta Visual Studion sisäänrakennettua Copilotia tai muita laajennuksia, jotka tukevat samoja kenttiä.
- Eri versiot saattavat automaattisesti lisätä polkuja Base URL:iin; jos pyyntö epäonnistuu, tarkista ensin, että lopullinen pyyntö osuu Chat Completions -päätepisteeseen.
- Ennen kuin kiinteä versio E2E on valmis, ei voida taata, että kaikki muokkaus-, täydentämis- tai työkalukutsumallit ovat käytettävissä.
