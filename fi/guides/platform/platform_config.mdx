Lue nykyisen pyyntökontekstin julkiset toiminnallisuuskytkimet sekä maa-/aluepäätelmä. Sopii päättämään käyttöliittymän käynnistyessä, näytetäänkö toiminnallisuuksia; se ei ole sivuston brändi, yhteystiedot tai ilmoitusluettelo.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                              |
| --- | ----------------------------------------------- |
| Menetelmä  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Todennus  | Julkinen; kirjautumistilan mukana ollessa osa toiminnallisuuskytkimistä voidaan laskea käyttäjäkohtaisesti                          |

## Kyselyparametrit ja pyyntöotsakkeet

| Nimi                    | Sijainti     | Kuvaus                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Toiminnallisuuskytkinten ylikirjoituslauseke; voimassa vain asiakasylikirjoituksen salliville kytkimille tai pääkäyttäjälle |
| `X-Feature-Overrides` | header | Sama ylikirjoituslähde kuin `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Todellinen vastausrakenne

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Kenttä         | Tyyppi            | Kuvaus                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Nykyiselle pyynnölle näkyvät toiminnallisuuskytkimet; avaimet muuttuvat alustan konfiguraation mukaan, asiakkaan tulee lukea niitä tarpeen mukaan ja asettaa turvalliset oletusarvot puuttuville avaimille |
| `region`   | string / null | Pyynnön IP-osoitteen perusteella tunnistettu maa- tai aluekoodi, pienillä kirjaimilla; `null`, jos tunnistaminen ei onnistu        |

Älä lue tästä rajapinnasta sivuston nimeä, CDN:ää, valuuttaa, kieltä, asiakaspalvelun yhteystietoja tai ilmoituksia; nämä kentät eivät kuulu nykyiseen vastaussopimukseen.

## Käyttösuositukset

- Toiminnallisuuskytkimet lasketaan käyttäjän, sormenjäljen ja sivustokontekstin perusteella, älä jaa välimuistia pitkään käyttäjien välillä.
- Aluevalitsimen valinta tallennetaan vain käyttöliittymään, käytä näytettäessä ensisijaisesti valittua aluetta, muussa tapauksessa tämän rajapinnan `region`-arvoa. Tämä rajapinta ei hyväksy alueen ylikirjoitusparametreja.
- Tunnistamattomat query-parametrit ohitetaan; käytä vain tällä sivulla lueteltuja parametreja.
