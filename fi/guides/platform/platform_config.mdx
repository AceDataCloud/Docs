Lue nykyisen pyyntökontekstin julkiset ominaisuuskytkimet ja maa-/aluearvio. Soveltuu päättämään käyttöliittymän käynnistyessä, näytetäänkö toiminto; se ei ole sivuston brändi, yhteystiedot tai ilmoitushakemisto.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                              |
| --- | ----------------------------------------------- |
| Menetelmä  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Todennus  | Julkinen; kirjautumistilaa mukana kannettaessa jotkin ominaisuuskytkimet voidaan laskea käyttäjäkohtaisesti                          |

## Kyselyparametrit ja pyyntöotsakkeet

| Nimi                    | Sijainti     | Kuvaus                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Kaksikirjaiminen ASCII-maakoodi; käytetään vastausnäyttömaan ohittamiseen, ei muuta palvelinpuolen turvallisuusarvioita |
| `features`            | query  | Ominaisuuskytkimen ohituslauseke; voimassa vain kytkimille, joiden asiakaspuolen ohitus on sallittu, tai pääkäyttäjille        |
| `X-Feature-Overrides` | header | Sama ohituslähde kuin `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Todellinen vastausrakenne

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Kenttä         | Tyyppi            | Kuvaus                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Nykyiselle pyynnölle näkyvät ominaisuuskytkimet; avaimet muuttuvat alustan asetusten mukana, joten asiakkaan tulee lukea niitä tarpeen mukaan ja asettaa turvalliset oletusarvot puuttuville avaimille |
| `country`  | string / null | Pienillä kirjaimilla kirjoitettu maakoodi; tunnistamattomana se voi olla `null`                     |

Älä lue tästä rajapinnasta sivuston nimeä, CDN:ää, valuuttaa, kieltä, asiakaspalvelun yhteystietoja tai ilmoituksia; nämä kentät eivät kuulu nykyiseen vastaussopimukseen.

## Käyttösuositukset

- Ominaisuuskytkimet lasketaan käyttäjän, sormenjäljen ja sivustokontekstin mukaan, joten älä jaa välimuistia pitkäaikaisesti käyttäjien välillä.
- Asiakkaan välittämä `country` vaikuttaa vain palautusarvoon eikä ohita palvelinpuolen alue- tai turvallisuuskäytäntöjä.
- Tunnistamattomat query-parametrit jätetään huomiotta; käytä vain tällä sivulla lueteltuja parametreja.
