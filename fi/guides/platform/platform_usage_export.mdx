Lataa nykyisen tilin API-kutsujen tiedot suoraan CSV-muodossa; soveltuu taloudelliseen täsmäytykseen, offline-analyysiin tai suurten tietuemäärien tallentamiseen. Jos sinun tarvitsee tarkastella vain pientä määrää tietoja sivulla, käytä ensin [kutsutietueluetteloa](https://platform.acedata.cloud/documents/platform-usage-list).

Kutsutietueiden ja laskutusyhteenvedon hakuaika on viimeiset 60 päivää; pyyntö- ja vastaustekstit säilytetään erikseen viimeiset 30 päivää. Tekstin vanheneminen ei muuta tietueen todellista veloitusta, käyttömäärää tai koostetilastoja.

## Valmistelut

1. Kirjaudu sisään [AceDataCloud-alustalle](https://platform.acedata.cloud).
2. Luo tilitunnus [Account Token -konsolissa](https://platform.acedata.cloud/console/platform-tokens) ja tallenna se välittömästi salasanojen hallintaan tai Secret Manageriin.
3. Hae tarvittaessa suodatus-ID:t [palveluhakemusluettelosta](https://platform.acedata.cloud/documents/platform-application-list), [API-tunnistetietoluettelosta](https://platform.acedata.cloud/documents/platform-credential-list) tai [API-luettelosta](https://platform.acedata.cloud/documents/platform-api-list).

Täydellinen tunnisteen kuvaus löytyy kohdasta [tilitunnisteiden hallinta](https://platform.acedata.cloud/documents/platform-token). Tilitunnistetta ja liiketoiminnan API:en kutsumiseen käytettävää Credential-tunnistetta ei voi käyttää keskenään vaihtokelpoisesti.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

## Rajapinnan yleiskatsaus

| Kohta           | Sisältö                                                    |
| --------------- | ---------------------------------------------------------- |
| Menetelmä       | `GET`                                                      |
| URL             | `https://platform.acedata.cloud/api/v1/usage/apis/export/` |
| Todennus        | `Authorization: Bearer ${PLATFORM_TOKEN}`                  |
| OAuth Scope     | `usage:read`（`platform:read` / `platform` 可展开包含）           |
| Vastaus         | `200 text/csv; charset=utf-8`                              |
| Tiedostonimi    | `usages.csv`                                               |

Tämä rajapinta palauttaa CSV:n synkronisesti suoratoistona, ei luo vientitehtävää eikä palauta JSON:ia tai latauslinkkiä. Vain kun sekä alku- että loppuaikaa ei anneta, viedään oletuksena tietueet kuluvan kalenterikuukauden alusta nykyhetkeen; jos annetaan vain yksi raja, toista rajaa ei täydennetä automaattisesti kuluvan kuukauden rajaksi.

## Kyselyparametrit

| Parametri         | Tyyppi   | Pakollinen | Oletus | Kuvaus                                      |
| ----------------- | -------- | ---------- | ------ | ------------------------------------------- |
| `perspective`     | string   | Ei         | `both` | `billing`, `actor` tai `both`               |
| `service_id`      | UUID     | Ei         | —      | Suodatus palvelun mukaan; tukee toistuvia parametreja |
| `application_id`  | UUID     | Ei         | —      | Suodatus Applicationin mukaan; tukee toistuvia parametreja |
| `api_id`          | UUID     | Ei         | —      | Suodatus API:n mukaan; tukee toistuvia parametreja |
| `credential_id`   | UUID     | Ei         | —      | Suodatus API-tunnistetietojen mukaan; tukee toistuvia parametreja |
| `status_code`     | integer  | Ei         | —      | Tukee toistuvia tai pilkuin eroteltuja arvoja |
| `created_at_from` | datetime | Ei         | —      | ISO 8601 -alkamisaika                       |
| `created_at_to`   | datetime | Ei         | —      | ISO 8601 -päättymisaika                     |

Vientialue rajoittuu aina tietueisiin, jotka ovat nykyisen tilin nähtävissä maksajana ja/tai todellisena kutsujana; tilien välistä vientiä ei tueta.

## Pyyntöesimerkit

Tallenna kuluvan kuukauden CSV suoraan:

```shell
curl --fail-with-body --location \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Vie Applicationin, ajan ja tilakoodin mukaan:

```shell
export APPLICATION_ID='你的 Application ID'

curl --fail-with-body --get \
  'https://platform.acedata.cloud/api/v1/usage/apis/export/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'status_code=200,500' \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-08T00:00:00Z' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  --output usages.csv
```

Python suoratoistaa tallennuksen ja tarkistaa eheyden:

```python
import os
from pathlib import Path

import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/export/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {
    "created_at_from": "2026-09-01T00:00:00Z",
    "created_at_to": "2026-09-08T00:00:00Z",
    "perspective": "both",
}
output = Path("usages.csv")

with requests.get(url, headers=headers, params=params, stream=True, timeout=120) as response:
    response.raise_for_status()
    if not response.headers.get("content-type", "").startswith("text/csv"):
        raise RuntimeError("服务器没有返回 CSV")
    with output.open("wb") as file:
        for chunk in response.iter_content(chunk_size=64 * 1024):
            file.write(chunk)

last_line = output.read_text(encoding="utf-8").splitlines()[-1]
if last_line.startswith("# truncated:") or last_line.startswith("# error:"):
    raise RuntimeError(f"导出不完整：{last_line}")
```

## CSV-sarakkeet

CSV-otsikkorivien järjestys on kiinteä:

```text
Usage ID,API,Status Code,Deducted Amount,Original Amount,Trace ID,Created At
```

| Sarake             | Kuvaus                                            |
| ------------------ | ------------------------------------------------- |
| `Usage ID`         | Kutsutietueen ID                                  |
| `API`              | API-otsikko; jos vastaavuutta ei löydy, voi olla API ID tai tyhjä arvo |
| `Status Code`      | HTTP-tilakoodi                                    |
| `Deducted Amount`  | Lopullinen tosiasiallisesti vähennetty määrä      |
| `Original Amount`  | Alkuperäinen määrä ennen sovellusalennusta        |
| `Trace ID`         | Pyynnön seuranta-tunniste                         |
| `Created At`       | Tietueen luontiaika, ISO 8601                     |

Määrän yksikkö määräytyy vastaavan Applicationin `service.unit`-arvon mukaan.

## Viennin täydellisyyden määrittäminen

Yhdellä kertaa voidaan tulostaa enintään 1 000 000 tietuetta. Kun palvelin on alkanut palauttaa CSV:tä, se ei voi enää muuttaa kesken tapahtuvaa virhettä toiseksi HTTP-tilaksi, joten asiakkaan on tarkistettava viimeinen rivi:

- `# truncated:`：Rivimäärän enimmäisraja on saavutettu; vie tiedot osissa pienempiä aikaikkunoita käyttäen.
- `# error:`：Suoratoistoluku keskeytyi; pienennä aluetta ja vie uudelleen.

Täsmäytysohjelman on käsiteltävä tiedosto epätäydellisenä, jos se havaitsee kumman tahansa markerin, eikä se saa kirjata sitä hiljaisesti.

## Virheet ja uudelleenyritykset

| Tilanne                     | Käsittelytapa                                      |
| --------------------------- | -------------------------------------------------- |
| `400 usage_history_expired` | Säädä vastauksen `available_from`-arvon avulla viimeisen 60 päivän alueelle |
| `401 not_authenticated`     | Tarkista, että Account Token on olemassa, oikein ja sitä ei ole poistettu |
| Muu kuin CSV-vastaus        | Älä tallenna onnistuneena tiedostona; lue ensin virhevastaus ja korjaa pyyntö |
| Latauksen keskeytys tai marker | Pienennä aikaikkunaa ja vie uudelleen takaisinvetostrategiaa käyttäen |
