Luo maksua odottava tilaus yhdelle tai useammalle Applicationille. Luominen kirjoittaa tilauksen, mutta ei suorita maksua automaattisesti; ennen maksua tulee tarkistaa vastauksen `price`, paketti ja Application.

## Valmistelut

- Luo [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Hae `application_id` [Application-luettelosta](https://platform.acedata.cloud/documents/platform-application-list).
- Valitse [palvelun tietojen](https://platform.acedata.cloud/documents/platform-service-detail) `packages`-kohdasta Application-tyyppiä vastaava ja ostettavissa oleva `package_id`.

```shell
export PLATFORM_TOKEN='tilitunnuksesi'
export APPLICATION_ID='Application ID:si'
export PACKAGE_ID='Package ID:si'
```

## Rajapinnan yleiskatsaus

| Kohta    | Sisältö                                              |
| ---- | ----------------------------------------------- |
| Menetelmä   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Todennus   | Account Token, OAuth token tarvitsee `orders:write`      |
| Body | JSON                                            |

## Pyyntörunko

Yhden Applicationin tilaus käyttää `application_id` + `package_id`; erätilaus käyttää vastaavan pituisia `application_ids` + `package_ids`. Tavallinen tilaus valitsee maksutavan myöhemmässä `/pay/`-pyynnössä. iOS:n sovelluksen sisäisen ostoksen tilaus välittää luotaessa `pay_way: "AppleIAP"`, ja voi valita vain yhden Usage-paketin, jossa on `metadata.apple_product_id` ja `metadata.apple_price`. Applen sovelluksen sisäinen osto käyttää erillistä ennalta asetettua Yhdysvaltain dollarin hintaa, johon ei lisätä jäsenalennusta, maksutapa-alennusta tai sivuston lisähintaa; muiden alueiden paikallisessa valuutassa veloitettava summa määräytyy Applen maksuvahvistussivun mukaan.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Vastauksen kuvaus

Onnistuminen palauttaa `201` ja uuden Order-objektin. Keskeisiin kenttiin kuuluvat `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` sekä aikakentät. Uusi tilaus on yleensä `Pending`, minkä jälkeen kutsutaan [tilauksen maksua](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` on palvelimen paketin, sivuston lisähinnan ja alennusten perusteella laskema maksettava summa; asiakkaan ei tule laskea sitä itse.
- Kun Package ei vastaa Application-palvelua tai -tyyppiä, palautetaan `400`.
- Ilmaisia ja järjestelmän hallinnoimia Packageja ei voi hakea itse julkisen tilausrajapinnan kautta.
- Tilauksen luominen Applicationille, joka ei kuulu nykyiselle tilille, hylätään.
