Palauttaa sivutettuna nykyisellä sivustolla näkyvät API-päätepisteet. Soveltuu API:en hakemiseen liiketoimintapolun, palvelun tai julkaisuvaiheen mukaan; jos tarvitset vain yhden API:n täydellisen määritelmän, kutsu suoraan [API-tiedot](https://platform.acedata.cloud/documents/platform-api-detail).

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                      |
| --- | --------------------------------------------- |
| Menetelmä  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| Todennus  | Julkinen, ei vaadi tilitunnusta                                     |
| Sivutus  | `count` + `items`                             |

## Kyselyparametrit

| Parametri        | Tyyppi      | Pakollinen  | Kuvaus                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | Ei   | Täsmällinen vastaavuus kohteelle `path` tai `path2` |
| `service` | string  | Ei   | Palvelun alias tai UUID       |
| `stage`   | string  | Ei   | Suodata julkaisuvaiheen mukaan; useita arvoja voidaan välittää toistuvasti      |
| `limit`   | integer | Ei   | Rivien määrä sivua kohden, enintään 100           |
| `offset`  | integer | Ei   | Sivutussiirtymä                 |

`id`, `service_id` ja `tag` eivät tällä hetkellä ole luettelon suodatusparametreja; niiden välittäminen ei tuota vastaavaa suodatusvaikutusta.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## Vastauksen kuvaus

Tuotantoympäristön vastaus käyttää muotoa `{count, items}`. Kukin luettelokohde sisältää tällä hetkellä API-mallin kentät sekä:

- `document_id`: liittyvän kehittäjädokumentin ID, voi olla tyhjä;
- `service_id` / `service`: pääpalvelun ID ja yhteenveto, voivat olla tyhjiä;
- `definition`: OpenAPI-määritelmä, voi olla suuri;
- `method`, `path`, `path2`, `stage`, `cost`, `tags`, `metadata` jne.

Luettelon serialisoija sisältää tällä hetkellä `definition`-kentän; koko luetteloa haettaessa tulee käyttää sivutusta ja asettaa aikakatkaisu. Kenttiä voidaan lisätä taaksepäin yhteensopivasti, ja asiakkaan tulee lukea vain tarvitsemansa kentät.
