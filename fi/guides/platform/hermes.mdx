Hermes Agent liittyy Ace Data Cloudiin OpenAI Chat Completions -protokollan kautta. Valitse jokin konfigurointitapa:

| Konfigurointitapa          | Opas                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` - vuorovaikutusopas | [Opas konfigurointiin](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` - manuaalinen konfigurointi  | [Manuaalinen konfigurointi](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Alustan yksityinen käyttöönotto              | [Hoidettu käyttöönotto](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Paikallisen liittymisen yhteiset parametrit:

- Perus-URL: `https://api.acedata.cloud/v1`
- Kuljetus: `chat_completions`
- Palveluntarjoaja: `custom:acedatacloud`
- API-avain: saatavilla [sovellusluettelosta](https://platform.acedata.cloud/console/applications)

Molemmat paikalliset tavat kirjoitetaan lopulta `~/.hermes/config.yaml` -tiedostoon, älä toista konfigurointia.

Palaa [Coding Plan -konfigurointikeskukseen](https://platform.acedata.cloud/documents/coding-plan-integration).
