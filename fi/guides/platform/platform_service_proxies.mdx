title: "Hae Proxy-luettelo AceDataCloud-alustan palvelun alta"
description: "Platform API guide - Ace Data Cloud"

Palauta sivutettuna palveluun liitetyt Proxy-päätepisteet Service UUID:n kautta. Jos käytössä on vain alias, kutsu ensin [palvelun tiedot](https://platform.acedata.cloud/documents/platform-service-detail) saadaksesi `id`:n.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                                     |
| --- | ---------------------------------------------------------------------- |
| Menetelmä  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Todennus  | Julkinen, ei vaadi tilitunnusta                                                              |
| Sivutus  | `count` + `items`                                                      |

## Parametrit

| Parametri                 | Sijainti    | Pakollinen  | Kuvaus                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Kyllä   | Service UUID, ei tue aliasta           |
| `limit` / `offset` | query | Ei   | Sivutus                               |
| `ordering`         | query | Ei   | Django-lajittelulauseke; suositellaan `rank` tai `-rank` |

```shell
export SERVICE_ID='sinun Service ID:si'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Vastauksen kuvaus

Luettelon kohteet sarjallistetaan Proxy-mallista, ja tuotannossa varmennettuja kenttiä ovat muun muassa `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` sekä aikakentät.

- Liiketoiminnan pääsykenttä on `endpoint`, ei `path`.
- Hinnoittelukenttä on `price`, ei `cost`.
- Jos Service-tyyppi ei ole Proxy tai siihen ei ole liitetty Proxya, palautetaan tyhjä `items`.

Julkiset integraatiot tukeutuvat vain `endpoint`:iin ja julkaistuihin ominaisuuksiin, eikä niiden tule tukeutua julkistamattomiin toteutuksen yksityiskohtiin.
