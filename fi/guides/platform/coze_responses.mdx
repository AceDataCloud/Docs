Coze virallinen mukautettu malli dokumentaatio tukee OpenAI Responses API:ta ja tarjoaa Base API URL:n, API Key:n ja malli kentät. Eri Coze vuokraversiot voivat käsitellä polkujen yhdistämistä, virtaavaa ulostuloa ja työkalujen kutsumista eri tavoin, joten tarkista ensimmäisellä kerralla jokainen kohta alla.

## Konfigurointi

1. Siirry Coze mallinhallintaan ja lisää mukautettu malli.
2. Protokollaksi valitse OpenAI Responses API.
3. Täytä Base API URL:ksi `https://api.acedata.cloud/v1`.
4. Täytä API Key:ksi oma Ace Data Cloud API Tokenisi.
5. Täytä Malli-kenttä tarkalla mallin ID:llä, joka tukee Responses API:ta.
6. Tallenna ja suorita Cozen yhteystesti.
7. Lähetä Bot/Agentissa `Reply only OK`, ja testaa työkalun kutsu uudelleen.

## Nykyiset rajat

- Eri Coze alueet, versiot tai paketit voivat näyttää erilaisia lomakkeita.
- Base API URL:n tulisi käyttää basea, älä lisää `/responses` uudelleen; jos nykyinen UI selvästi vaatii täydellistä API URL:ää, noudata lomakkeen ohjeita.
- Chat Completions, Responses ja Anthropic Messages ovat kolme erillistä reittiä, joita ei voi korvata toistensa vahvistamisessa.
