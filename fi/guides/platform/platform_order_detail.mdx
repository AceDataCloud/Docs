Hae tilaus tilaus-ID:n avulla. Tämä päätepiste tukee kahta lukutilaa: anonyymi käyttö palauttaa vain maksusivun tarvitsemat vähimmäiskentät; tilauksen omistaja, jolla on Account Token, saa täydelliset tiedot.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                        |
| --- | --------------------------------------------------------- |
| Menetelmä  | `GET`                                                     |
| URL | `https://platform.acedata.cloud/api/v1/orders/{order_id}` |
| Todennus  | Valinnainen; anonyymi on vähimmäisprojektiona, todennettu omistaja on täydellisenä projektiona                                    |

`/orders/{id}` ja `/orders/{id}/` ovat tällä hetkellä molemmat käytettävissä. Tilaus-ID on osa maksulinkkiä, ja sitä tulee pitää arkaluonteisena läpinäkymättömänä tunnisteena, jota ei tule levittää julkisesti.

## Anonyymi kysely

Maksusivu voi lukea tiedot suoraan, kun kirjautumistila on kadonnut:

```shell
export ORDER_ID='tilauksesi ID'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json'
```

Anonyymi vastaus sisältää vain `id`-, `description`-, `price`-, `state`-, `pay_way`-, `pay_url`-, `expired_at`- ja `created_at`-kentät. Se ei palauta tiliä, Applicationia, Packagea, maksun sisäisiä tunnisteita tai metatietoja.

## Todennettu kysely

```shell
export PLATFORM_TOKEN='tilisi tunniste'
curl "https://platform.acedata.cloud/api/v1/orders/${ORDER_ID}" \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Tilauksen omistaja saa täydelliset Order-tiedot, mukaan lukien `application` / `applications`, `package` / `packages`, `bank_details`, `invoice_automation` sekä mallikentät. Jos käyttäjä on todennettu mutta ei ole tilauksen omistaja, palautetaan `403`; pääkäyttäjät ovat poikkeus.

## Keskeiset kentät

| Kenttä            | Kuvaus                                                          |
| ------------- | ----------------------------------------------------------- |
| `state`       | `Pending`, `Paid`, `Finished`, `Expired`, `Failed` tai `Refunded` |
| `pay_way`     | Tilauksen nykyinen maksutapa; kentän nimi ei ole `payment_method`                             |
| `pay_url`     | Isännöidyn maksusivun tai QR-koodin osoite, voi olla tyhjä                                           |
| `price`       | Tilauksen lopullinen maksettava summa; nykyinen tilausmalli ei tarjoa `final_price`-kenttää                         |
| `amount`      | Paketin kiintiömäärä; näkyy vain todennetussa täydellisessä vastauksessa                                            |
| `finished_at` | Tilauksen valmistumisaika; kentän nimi ei ole `paid_at`                                      |

Täydellinen vastaus voi sisältää maksutavan mukaan lisäkenttiä. Asiakkaiden tulee lukea niitä tarpeen mukaan ja aina välttää tallentamasta täydellisen vastauksen arkaluonteisia metatietoja.

## Virheenkäsittely

- `404`: Tilaus-ID:tä ei ole olemassa.
- `403`: Käyttäjä on kirjautunut sisään, mutta ei ole tilauksen omistaja.
- Anonyymit pyynnöt eivät palauta `401`-virhettä; ne saavat vain vähimmäisjulkisen projektion.
