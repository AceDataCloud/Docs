Hae yksittäisen palvelun täydelliset tiedot palvelun ID:llä (UUID) tai alias-nimellä (alias) — kentät ovat kattavammat kuin [AceDataCloud-alustapalveluiden luettelon hakeminen](https://platform.acedata.cloud/documents/platform-service-list) palauttaa, ja siihen laajennetaan lisäksi liittyvät objektit, kuten `apis`, `proxies`, `datasets` ja `packages`. Soveltuu esimerkiksi palvelun tietosivulle, hinnoittelun vertailusivulle ja Agent-työkalujen kuvauksiin.

> ℹ️ Tämä rajapinta kuuluu **AceDataCloud-alustan hallinta-APIin**, jonka yhtenäinen etuliite on `https://platform.acedata.cloud/api/v1/`. Katso täydellinen rajapintaluettelo kohdasta [AceDataCloud-alustan dokumenttiluettelon hakeminen](https://platform.acedata.cloud/documents/platform-document-list).

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                            |
| --- | ------------------------------------------------------------- |
| Menetelmä  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Todennus  | ❌ Julkinen                                                          |

Sekä `/services/{id}` että `/services/{id}/` ovat tällä hetkellä käytettävissä; esimerkeissä käytetään yhtenäisesti muotoa ilman loppuviivaa.

## Todennusta koskevat ohjeet

Tämä rajapinta on täysin julkinen. **Mutta kun tilitunnus lisätään, vastauksen `applied`-kenttä kuvastaa nykyisen tilin todellista hakemustilaa**, muussa tapauksessa se on aina `false`.

Katso tilitunnuksen hankintatapa kohdasta [AceDataCloud-alustan tilitunnusten hallinta](https://platform.acedata.cloud/documents/platform-token).

## Polkuparametrit

| Parametri           | Tyyppi            | Pakollinen  | Kuvaus                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | Palvelun ID (UUID) tai alias (kuten `midjourney`, `openai`, `webextrator`) |

## Pyyntöesimerkit

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## Vastauskenttien kuvaus

Tietorajapinta laajentaa [luettelorajapinnan](https://platform.acedata.cloud/documents/platform-service-list) kaikkien kenttien lisäksi seuraavat:

| Kenttä         | Tyyppi    | Kuvaus                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Liittyvien API-objektien täydellinen luettelo (jokainen sisältää `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Liittyvien Proxy-objektien täydellinen luettelo                                              |
| `datasets` | array | Liittyvät tietojoukot (jos `type=Dataset`)                                      |
| `packages` | array | Pakettien luettelo, sisältää `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Katso muiden kenttien määritelmät kohdasta [AceDataCloud-alustapalveluiden luettelon hakeminen → vastauskenttien kuvaus](https://platform.acedata.cloud/documents/platform-service-list).

## Virheenkäsittely

| HTTP | code        | Merkitys                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id`-arvoa (UUID tai alias) ei ole olemassa |
| 500  | —           | Yleensä URL-osoitteen loppuun on virheellisesti lisätty vinoviiva; poista se ja yritä uudelleen          |

## Käytännön vinkit

- **`alias` > `UUID`**: `alias`-arvon (kuten `midjourney`) kovakoodaus koodiin on vakaampaa; UUID muuttuu ympäristöä siirrettäessä.
- **`apis`-kenttä ei sisällä OpenAPI-määritelmää**: täydellinen OpenAPI 3.0 Schema löytyy [AceDataCloud-alustan API-tietojen hakeminen](https://platform.acedata.cloud/documents/platform-api-detail) -rajapinnasta.
- **Palvelun ”täydellisten ominaisuuksien” haku**: hae tällä rajapinnalla `api_ids` ja hae sitten tiedot yksi kerrallaan kutsumalla `/apis/{api_id}`.
- **Jos `applied=true`**, voit suoraan [luoda API-tunnuksen](https://platform.acedata.cloud/documents/platform-credential-create) saadaksesi liiketoimintarajapinnan kutsumiseen tarvittavan 32-merkkisen Tokenin ilman uutta hakemusta.
