FreeAIr on avoimen lähdekoodin laajennus Visual Studio 2022/2026:lle, ja virallisesti se voi yhdistää mihin tahansa OpenAI-yhteensopivaan API:in. Eri laajennusversioiden pyyntökäyttäytyminen voi vaihdella; ensimmäisellä kerralla liitettäessä on suositeltavaa käyttää kiinteää versiota ja suorittaa alla olevan minimivarmistuksen.

## Konfigurointi

1. Asenna FreeAIr Visual Studio Marketplace:sta tai virallisesta varastosta.
2. Avaa FreeAIr-asetukset ja lisää OpenAI-yhteensopiva yhteys.
3. Täytä Endpoint kenttä `https://api.acedata.cloud/v1`.
4. Täytä Token kenttä omalla Ace Data Cloud API Tokenillasi.
5. Täytä Model kenttä mallihakemistossa tuetun Chat Completionsin tarkalla mallin ID:llä.
6. Tallenna ja lähetä `Reply only OK`, ja testaa sitten uudelleen pyyntö, jossa on projektin konteksti.

## Nykyiset rajat

- Tämä opas kattaa vain FreeAIr:n, eikä se edusta Visual Studion sisäänrakennetun Copilotin tukea satunnaiselle Base URL:lle.
- Laajennusversio voi muuttaa endpointin yhdistämistapaa; varmista lopullinen pyyntö-URL varmistaessasi.
- Työkalukutsut ja laajennuksen sisäinen MCP-kyky tarvitsevat erillisen varmennuksen, eikä tavallista keskustelua voi käyttää onnistumisen korvikkeena.
