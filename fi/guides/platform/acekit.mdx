Olet luultavasti törmännyt tällaiseen tilanteeseen: käytät Claude Codea, Cursoria tai Codexia, koodi syntyy hyvin, ja yhtäkkiä tarvitset kuvituskuvan, pätkän taustamusiikkia, lyhyen videon tai haluat sen etsivän nopeasti uusimmat tiedot. Sitten huomaatkin — agentti ei itse osaa näitä. Sinun täytyy etsiä API, lukea dokumentaatio, määrittää avain, kirjoittaa kutsukoodi, käsitellä asynkroninen kysely, ja kun olet säätänyt kaiken tämän, inspiraatio on jo viilentynyt.

[AceKit](https://github.com/AceDataCloud/AceKit) on täällä säästääkseen sinut tältä koko säädöltä. Yhdellä komennolla se asentaa AceData Cloudin kuvageneroinnin, videogeneroinnin, musiikintuotannon, verkkoshaun, LLM-keskustelun ja muut ominaisuudet kokonaisuudessaan koodausagenttiisi. Asennuksen jälkeen puhut sille vain normaalilla kielellä, ja agentti lataa itse vastaavan taidon, hoitaa itse tunnistautumisen, kyselee itse tilaa ja suorittaa työn loppuun.

## Ymmärrä 30 sekunnissa, mitä se tekee

Ennen asennusta vs. asennuksen jälkeen:

| Mitä sanot               | Ennen asennusta                   | Asennuksen jälkeen (agentti tekee itse)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Tee tälle README:lle kansikuva" | agentti ei osaa, pyytää sinua etsimään kuvagenerointi-API:n | Kutsuu NanoBananaa / Fluxia / Midjourneytä kuvan luomiseksi |
| "Tee tästä skriptistä 30 sekunnin lyhytvideo"  | ei osaa                    | Kutsuu Soraa / Veota / Klingiä / Seedancea videon luomiseksi  |
| "Lisää tähän demoon taustamusiikkia"  | ei osaa                    | Kutsuu Sunoa musiikin luomiseksi                           |
| "Etsi uusimmat tiedot X:stä ja tee sitten yhteenveto"     | ei pääse verkkoon                  | Kutsuu Google SERPiä saadakseen reaaliaikaiset tulokset                 |
| "Lyhennä tämä pitkä linkki"         | ei osaa                    | Kutsuu lyhytlinkkipalvelua ja palauttaa surl.id-linkin                  |

Yhdellä lauseella: **koodausagenttisi muuttuu "vain koodia kirjoittavasta" agentista sellaiseksi, joka "osaa myös luoda kuvia, videoita ja musiikkia sekä tehdä verkkohakuja".**

## Aloita kolmessa vaiheessa

Koko prosessi onnistuu muutamassa minuutissa, ja vaatii Node.js 18+:n.

**Vaihe yksi · Hanki API Token.** Kopioi Token [konsolista](https://platform.acedata.cloud/console/applications) — kaikki ominaisuudet käyttävät tätä samaa tokenia, ensimmäisestä hakemuksesta saa ilmaista käyttörajaa, joten voit kokeilla ensin ilmaiseksi.

![Kopioi API Token konsolissa](https://cdn.acedata.cloud/dvc3cg.jpg)

**Vaihe kaksi · Asenna.** Yksi komento:

```bash
npx acekit
```

Se tunnistaa automaattisesti koneella olevat koodausagentit ja asentaa koko taitopaketin. Todellinen suoritus näyttää tältä (tähän koneeseen on asennettu vain Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Jos Tokenia ei ole asetettu, ensimmäinen suoritus pyytää sinua interaktiivisesti liittämään sen; voit myös tehdä asennuksen täysin ilman valvontaa asettamalla etukäteen `export ACEDATACLOUD_API_TOKEN=你的token`. Taitojen määrä muuttuu alustan ominaisuuksien lisääntyessä; katso ajantasainen luettelo komennolla `npx acekit list`.

**Vaihe kolme · Puhu normaalilla kielellä.** Lataa agentti uudelleen ja anna sitten suoraan ohje, esimerkiksi:

```text
Käytä short-url-taitoa lyhentämään https://platform.acedata.cloud/services
```

agentti lataa itse taidon, käynnistää itse kutsun ja antaa sinulle todellisen avattavan tuloksen.

## Suoritetaan se oikeasti kerran (tulosteineen)

Seuraavat neljä esimerkkiä ovat kaikki **todellisia kutsuja ja paikan päällä palautettuja tuloksia**, eivät havainnollistuksia. Komennon `$KEY` on sinun API Tokenisi.

**① Lyhennä URL-osoite (synkroninen, vastaus sekunneissa)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Palauttaa `https://surl.id/r/1uKp2kilXQ` — sen avaaminen ohjaa 302-uudelleenohjauksella takaisin alkuperäiselle services-sivulle.

**② Verkkohaku (synkroninen)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Saat reaaliaikaiset Google-tulokset (ote):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM-keskustelu (synkroninen, yksi rajapinta yhdistää yli 50 mallia)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP on protokolla mallin kontekstitietojen yhtenäiseen hallintaan ja vaihtoon.
（39 tokens，本次约 0.00007 credit）
```

**④ Kuvagenerointi (asynkroninen, noin 20 sekuntia, agentti kyselee automaattisesti kunnes kuva valmistuu)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Noin 22 sekunnin kuluttua palautuu todellinen kuva (HTTP 200 · image/png · 317 KB · tällä kertaa noin 0.13 credit):

![AceKitin todellisuudessa luoma kuva](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Sinun ei itse asiassa tarvitse muistaa näitä rajapintoja — kun taidot on asennettu, agentti muodostaa itse oikeat pyynnöt omien `SKILL.md`-tiedostojensa mukaisesti sekä käsittelee tunnistautumisen ja kyselyn. Yllä vain näytetään sinulle, "mitä se tekee taustalla".

## Mitä se tarkalleen ottaen asentaa

AceKit on AceDatan koko kehittäjätyökalupinnan "etuovi", ja tällä hetkellä yksi asennus asentaa **taitotyökalupaketin (Skills)**:

- **Joukon agenttitaitoja**: jokainen taito on valmiiksi kirjoitettu `SKILL.md`-käyttöopas — tunnistautuminen, asynkroninen kysely, virheiden uudelleenyritys ja parametrien täyttötapa on kaikki kirjoitettu selkeästi, joten agentin tarvitsee vain noudattaa niitä. Suorita `npx acekit list` nähdäksesi ajantasaisen luettelon (tätä kirjoitettaessa niitä on 19, ja määrä kasvaa jatkuvasti):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Yksi yhtenäinen Token**: yksi `ACEDATACLOUD_API_TOKEN` avaa kaikki ominaisuudet, laskutus todellisen käytön mukaan.

Luokiteltuna ominaisuuksien mukaan (katso `npx acekit list`):

| Tyyppi         | Tarjoaja                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Kuvan luonti      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Videon luonti      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Musiikin / äänen luonti | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM-keskustelu   | Yhtenäinen rajapinta yli 50 mallille（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Haku       | Google SERP（verkkosivut · kuvat · uutiset · kartat · videot）                  |
| 🔗 Työkalut       | Lyhytlinkit · kasvojen käsittely                                            |

> AceData tarjoaa samoihin ominaisuuksiin myös erilliset **MCP-palvelimet**（Suno、Midjourney、Sora、SERP… julkaistu PyPI:hin / VS Codeen / Smitheryyn / Dockeriin）、**komentorivi-CLI:n** ja **Python / TypeScript SDK:n**, joita voi käyttää erikseen tarpeen mukaan. AceKit v0.2:n on suunniteltu tukevan `acekit add <name>` -asennusta yksittäisille ominaisuuksille sekä kirjoittavan automaattisesti kunkin agentin MCP-määritykset.

## Mitä Agentteja tuetaan

| Agent                        | Taitojen asennussijainti                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode jne. | `~/.agents/skills`（ohjaa agenttisi tähän） |

Asennuksen aikana AceKit tunnistaa automaattisesti koneelle asennetut agentit ja asentaa vain niihin, jotka se havaitsee.

## Pääsiäismuna: käytä samaa Tokenia itse Claude Coden ajamiseen

AceDatan rajapinta on samalla yhteensopiva Anthropicin `/v1/messages`-muodon kanssa, joten **et tarvitse Anthropicin virallista tilausta** — voit ajaa Claude Codea samalla AceData Tokenilla. Luo projektin juurihakemistoon `.claude/settings.local.json`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Käynnistä Claude Code uudelleen — se käyttää sekä koko Claude-malliperhettä että saa AceKitin kautta kuvien, videoiden ja musiikin luomiseen tarvittavat "kädet". Katso lisätietoja [Claude Code -integraatio-oppaasta](https://platform.acedata.cloud/documents/claude-code-integration).
