[ChatBox](https://chatboxai.app/) on avoimen lähdekoodin AI-asiakasohjelma, joka tukee Windowsia, macOS:ää, Linuxia, iOS:ää, Androidia ja Webiä. Se tukee mukautettuja palveluntarjoajia tyypillä ”OpenAI API”, joten se voidaan yhdistää suoraan Ace Data Cloudiin. Tässä artikkelissa esitellään määritysprosessi.

## Hakuprosessi

Jos haluat yhdistää Ace Data Cloudin ChatBoxiin, siirry ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications), hanki API Tokenisi ja säilytä se varalla.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisen haun yhteydessä annetaan ilmainen käyttökiintiö, jonka avulla voit kokeilla Ace Data Cloudin mallipalveluja ilmaiseksi.

## ChatBoxin lataaminen

Lataa [ChatBoxin viralliselta sivustolta](https://chatboxai.app/) alustasi mukainen versio tai käytä suoraan asennuksetonta [Web-versiota](https://web.chatboxai.app/):

- Työpöytä: Windows `.exe`, macOS `.dmg` (erikseen Intel / Apple Silicon), Linux AppImage
- Mobiili: App Store, Google Play, virallisen sivuston Android-suoralinkki

## Ace Data Cloudin määrittäminen

Käynnistä ChatBox, siirry kohtaan **Asetukset → Mallit → Lisää mukautettu Provider**, aseta **API Mode** arvoksi **OpenAI API Compatible** ja täytä sitten:

| Kenttä       | Arvo                           | Selitys                                      |
| -------- | --------------------------- | --------------------------------------- |
| API-avain   | Ace Data Cloud Tokenisi     | Konsolista kopioitu Token                            |
| API Host | `https://api.acedata.cloud` | Täytä vain juuriverkkotunnus, **älä lisää `/openai` tai `/v1`**         |
| API Path | `/v1/chat/completions`      | ChatBoxin oletusarvo on `/chat/completions`, se on muutettava manuaalisesti tähän |

![ChatBox Ace Data Cloud Provider -määritysnäkymä](https://cdn.acedata.cloud/3789c8e3dd4d.png)

ChatBoxin pyyntöpolku on `{API Host} + {API Path}`, joten Host-kenttään tarvitsee täyttää vain juuriverkkotunnus:

| API Host                              | Lopullinen pyyntö                                                      | Tulos                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Oikein                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (`/openai`-polun alla ei ole `/v1`-polkua) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox ei kutsu automaattisesti `/v1/models`-päätepistettä, joten mallin asetussivun alareunassa olevaan ”Mukautetut mallit” -syöttökenttään on täytettävä mallin ID manuaalisesti (yksi riviä kohden). Tallennuksen jälkeen voit valita sen keskustelunäkymän mallin pudotusvalikosta. Kykyasetukset, konteksti-ikkuna ja tulostusraja on täytettävä valitun mallin nykyisen sopimuksen mukaisesti; älä kopioi muiden mallien arvoja.

## Mallin valitseminen

Malliluettelo päivittyy jatkuvasti. Käytä ensisijaisesti asiakkaan automaattisesti lataamaa malliluetteloa; jos sinun on täytettävä tiedot manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models` saadaksesi nykyiset mallien ID:t ja valitse sitten asiakkaan tukemien konteksti-, kuva- ja työkalukutsuominaisuuksien mukaan.

## Yhteyden vahvistaminen

Jos et ole varma, onko ongelma ChatBoxissa vai verkossa, voit ensin vahvistaa päätepisteen suoraan curlilla (korvaa `{token}` Tokenillasi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Jos palautetaan OpenAI-yhteensopiva `chat.completion`-objekti, Token ja päätepiste ovat valmiita; jos palautetaan `HTTP 403 used_up`, Token on kelvollinen mutta saldo ei riitä. Voit ladata saldoa [konsolissa](https://platform.acedata.cloud/console/applications).

## Usein kysytyt kysymykset

### Ilmoitus 404 Not Found

Yleensä API Hostiin on lisätty ylimääräinen `/openai` tai `/v1`. Täytä Host-kenttään vain `https://api.acedata.cloud` ja jätä poluksi oletusarvoinen `/v1/chat/completions`.

### Ilmoitus 401 / token_mismatched

Varmista, että ”API-avain”-kenttään on liitetty Ace Data Cloudin Token (ilman `Bearer`-etuliitettä ja ilman ylimääräisiä välilyöntejä) ja että kyseisen sovelluksen saldo on riittävä.

### Mallia ei näy mallin pudotusvalikossa

ChatBox ei hae malliluetteloa automaattisesti. Mallin ID on täytettävä manuaalisesti ”Mukautetut mallit” -kenttään ja tallennettava.

### Haluan luoda kuvia ChatBoxissa

Ace Data Cloudin kuvagenerointi on erillinen Images API (`/openai/images/generations`), jonka polku on eri kuin keskustelurajapinnalla, eikä ChatBoxin kuvaominaisuutta voi yhdistää siihen suoraan. Jos haluat luoda kuvia, katso [kuvagenerointi-API:n dokumentaatio](https://platform.acedata.cloud/documents/openai-images-generations) ja käytä curlia / SDK:ta.
