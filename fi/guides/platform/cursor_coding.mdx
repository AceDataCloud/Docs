Cursor tarjoaa tällä hetkellä OpenAI API -avaimen ja **Override OpenAI Base URL** -asetuksen, joka mahdollistaa yhteyden OpenAI-yhteensopiviin palveluihin. Tämä kyky on olemassa, mutta eri versioiden käsittely `/chat/completions`-, `/responses`-, mallilista- sekä Agent/Composer-tilojen osalta ei ole täysin johdonmukaista.

Eri Cursor-versioiden, käyttöjärjestelmien ja pyyntötilojen yhteensopivuus voi vaihdella. Suorita käytännön tilatarkistus tämän sivun ohjeiden mukaan, äläkä tee johtopäätöksiä kaikkien toimintojen saatavuudesta yhden onnistuneen keskustelun perusteella.

## Cursorin viralliset BYOK-takuut

[Cursorin virallisten Bring your own API key -asiakirjojen](https://cursor.com/help/models-and-usage/api-keys) mukaan:

- Tukee OpenAI:ta, Anthropicia, Googlea, Azure OpenAI:ta ja AWS Bedrockia varten tarkoitettuja tunnuksia;
- Mukautettu API-avain on käytettävissä vain keskustelumalleissa, Tab completion käyttää edelleen Cursorin sisäisiä malleja;
- API-avainta ei tallenneta Cursorin palvelimelle, mutta jokaisessa pyynnössä avain lähetetään Cursorin taustajärjestelmään lopullista promptin rakentamista varten;
- Kun käytetään omaa avainta, Cursorin Zero Data Retention -politiikka ei ole voimassa, ja tietojen käsittely noudattaa valitun tarjoajan politiikkaa.

## Konfigurointi

1. Avaa Cursor-asetukset → Mallit.
2. Täytä OpenAI API Key -kenttään Ace Data Cloud API -tokenisi.
3. Ota käyttöön **Override OpenAI Base URL**, ja täytä `https://api.acedata.cloud/v1`.
4. Valitse tai lisää tarkka mallin ID, joka on yhteensopiva nykyisen Cursor-protokollan kanssa.
5. Lähetä ensin `Reply only OK`, ja testaa sitten erikseen Ask/Edit/Agent-tiloja, joita käytät.

## Nykyiset rajat

- Mukautettu API-avain on käytettävissä vain keskustelumalleissa, Tab completion käyttää edelleen Cursorin sisäisiä malleja.
- Cursor voi edelleen suorittaa lopullista promptin rakentamista palvelimella; arvioi tietopolku virallisten tietosuojakuvastojen avulla.
- Base URL Override voi kattaa vain osan pyynnöistä tai vaihtua versioiden mukaan Chat Completions/Responses -välillä.
- Yhden onnistuneen keskustelupyynnön perusteella ei tule väittää, että Agent, Auto, Composer tai taustatehtävät ovat kaikki kytkettyinä.

## Täydellinen yhteensopivuustarkistus

Jos aiot käyttää tuotantotyönkuluja pitkällä aikavälillä, suorita seuraavat tarkistukset:

1. Kiinnitä Cursor-versio ja käyttöjärjestelmä;
2. Suorita todellisella asiakkaalla savutesti kyseiselle versiolle ja kirjaa lopullinen pyyntöprotokolla ja polku;
3. Tarkista, että tarkka mallin Chat Completions -pyyntö onnistuu;
4. Varmista, että työkalukutsut ja Agent-pyynnöt kulkevat todella kohde-endpointin kautta;
5. Varmista, että käyttö ja veloitus voidaan tarkistaa;
6. Kirjaa selkeästi, kulkevatko pyynnöt Cursorin palvelimen kautta ja mitkä tietosuojarajoitukset ovat voimassa.

Asiakkaan päivityksen jälkeen nämä tarkistukset on suoritettava uudelleen varmistaaksesi, että pyyntöprotokolla, työkalukutsut ja tietopolku eivät ole muuttuneet.
