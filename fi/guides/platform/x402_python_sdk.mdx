Python SDK sopii taustapalveluille, datatehtäville, automaatiolle ja eräajoskriipteille. `acedatacloud` vastaa API-kutsuista, `acedatacloud-x402` vastaa `PAYMENT-SIGNATURE` -pyyntöpään allekirjoittamisesta.

Lähdekoodi ja pakettiosoitteet:

- SDK-varasto: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- X402 Client -varasto: [https://github.com/AceDataCloud/X402Client](https://github.com/AceDataCloud/X402Client)
- PyPI SDK: [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)
- PyPI X402 Client: [https://pypi.org/project/acedatacloud-x402/](https://pypi.org/project/acedatacloud-x402/)

## Asennusriippuvuudet

```bash
pip install acedatacloud acedatacloud-x402
```

Jos haluat käyttää `upto`, sinun on myös kutsuttava Permit2 approve CLI kerralla, tämä CLI riippuu `web3`:sta:

```bash
pip install 'acedatacloud-x402[cli]'
```

Puhtaan Python venv:n asennus- ja tuontitarkistuksen tuloste:

```text
acedatacloud 2026.4.26.1
acedatacloud-x402 2026.5.31.3
imports_ok True True True True True True
usage: acedatacloud-x402 [-h] {approve-permit2} ...
approve-permit2  One-time ERC-20 approve(Permit2, amount) needed before signing upto payments.
```

Tuloksen selitys:

- `acedatacloud` ja `acedatacloud-x402` voidaan molemmat asentaa ja tuoda PyPI:stä.
- `pip install 'acedatacloud-x402[cli]'` tuo mukanaan `approve-permit2` CLI:n, jota käytetään `upto`-ennakkovaltakirjaan.

## Base tai SKALE Esimerkki

Alla oleva esimerkki ei vaadi API-tunnusta. Lompakon yksityisavain allekirjoitetaan vain paikallisesti, eikä sitä lähetetä Ace Data Cloudille.

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)

print(res["choices"][0]["message"]["content"])
```

Python SDK palauttaa tällä hetkellä `dict`, joten esimerkki käyttää `res["choices"][0]["message"]["content"]`. Älä suoraan oletakaan, että sillä on aina `.choices` -ominaisuus.

SKALE maksetun kutsun ohjelman suoritus:

```text
payer 0xd0479FA9FD8C678303d477433d24C15e3723CC1C
elapsed_ms 4786
content ADC_PY_SDK_X402_OK
id chatcmpl-DlcWajqAHOop3iebmO19XRfT5bTPz
```

Tuloksen selitys:

- Ohjelma suoritti 402 purkamisen, `PAYMENT-SIGNATURE` -allekirjoituksen ja alkuperäisen pyynnön uudelleenyrityksen.
- `content ADC_PY_SDK_X402_OK` on mallin todellinen palauttama kiinteä merkkijono, joka osoittaa, että pyyntö on kulkenut X402-maksuketjun kautta kohde-API:in.
- `id chatcmpl-DlcWajqAHOop3iebmO19XRfT5bTPz` on tämän chat completion -vastauksen ID.

SKALE:lla käytetään vain verkon nimen muuttamista:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="skale",
        evm_signer=signer,
    )
)
```

## Solana Esimerkki

Solana käyttää base58-koodattua salaisuutta:

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import SolanaKeypairSigner, create_x402_payment_handler

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="solana",
        solana_signer=SolanaKeypairSigner.from_base58(os.environ["SOLANA_SECRET_KEY"]),
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

Solana-reitti rakentaa ja lähettää SPL USDC `TransferChecked` -kaupan, ja sitten allekirjoitus laitetaan `PAYMENT-SIGNATURE` -kuoreen.

Solana maksettu uudelleenyritys on palauttanut HTTP 200 ja `ADC_SOLANA_E2E_OK` tuotantoympäristössä. Tällä kertaa julkinen RPC-kysely kohtasi rajoituksia, eikä ketjun allekirjoitusta vahvistettu vakaasti; tarvittaessa käytä omaa Solana RPC:täsi tämän kaupan tarkistamiseen.

## Asynkroninen asiakas

Sama maksukäsittelijä voidaan käyttää `AsyncAceDataCloud`:issa:

```python
import os

from acedatacloud import AsyncAceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AsyncAceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = await client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

## Käyttö `upto` jälkikäteismittauksessa

Keskustelun täydentäminen, mallikutsut ja muut API:n todelliset kustannukset saattavat olla tiedossa vasta vastauksen päätyttyä. Tällöin API voi palauttaa samanaikaisesti sekä `exact` että `upto`. Jos haluat käyttää ensisijaisesti `upto`:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
        prefer_scheme="upto",
    )
)
```

Base `upto` ohjelman suoritus:

```text
payer 0x5d4f08D5c2bb60703284bc06671Eb680fA41B105
elapsed_ms 5104
content ADC_BASE_UPTO_OK
id chatcmpl-DlcbyS4IT8kUAMo4Ri97HiIHc9T8V
settlement tx 0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
settled value 3 atomic USDC
```

Ketjun vahvistus:

```text
explorer https://basescan.org/tx/0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
block 46726437
transfer value 3 atomic USDC
```

Tuloksen selitys:

- `content ADC_BASE_UPTO_OK` osoittaa, että pyyntö on todellisuudessa mennyt mallin API:in.
- `settled value 3 atomic USDC` osoittaa, että `upto` on laskutettu todellisen käytön mukaan, eikä koko ylärajaa ole vähennetty.
- `settlement tx` voidaan avata BaseScanissa, ja tarkistuksessa on hyvä tallentaa tx hash, payer, completion id ja pyyntötiivistelmä.

`upto` käyttää Permit2:ta valtuuttaakseen ylärajan, eikä todellinen laskutussumma voi ylittää tätä ylärajaa. Ensimmäistä kertaa käytettäessä on tehtävä kerran `approve(Permit2, amount)` kohdeketjussa.

CLI-tapa:

```bash
X402_PRIVATE_KEY=0x... acedatacloud-x402 approve-permit2 --network base
```

Ohjelmatapa:

```python
from acedatacloud_x402 import EVMAccountSigner, approve_permit2

approve_permit2(
    rpc_url="https://mainnet.base.org",
    signer=EVMAccountSigner.from_private_key("0x..."),
    token_address="0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
)
```

Tämä apuri on idempotentti. Jos allowance on jo riittävä, se palauttaa `{"skipped": true}`, eikä se toista ketjun transaktiota.

## Alhaisemman tason allekirjoitus
Jos et käytä SDK:ta, voit myös suoraan kutsua matalan tason allekirjoitusfunktioita:

```python
import base64
import json

from acedatacloud_x402 import EVMAccountSigner, sign_evm_payment

envelope = sign_evm_payment(requirement, EVMAccountSigner.from_private_key("0x..."))
x_payment = base64.b64encode(json.dumps(envelope, separators=(",", ":")).encode()).decode()
```

Matalan tason funktiot sopivat testaukseen, välityskerrokseen, porttien integrointiin tai epävirallisiin SDK:ihin. Tavallisessa liiketoimintakoodissa on suositeltavaa käyttää `create_x402_payment_handler` -funktiota.
