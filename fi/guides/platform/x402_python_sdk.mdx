Python SDK sopii taustapalveluille, datatehtäville, automatisoiduille agenteille ja eräajokomentoihin. `acedatacloud` vastaa API-kutsuista, ja `acedatacloud-x402` vastaa `PAYMENT-SIGNATURE`-pyyntöotsakkeen allekirjoittamisesta.

Lähdekoodi- ja pakettiosoitteet:

- SDK-tietovarasto: [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- X402 Client -tietovarasto: [https://github.com/AceDataCloud/X402Client](https://github.com/AceDataCloud/X402Client)
- PyPI SDK: [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)
- PyPI X402 Client: [https://pypi.org/project/acedatacloud-x402/](https://pypi.org/project/acedatacloud-x402/)

## Riippuvuuksien asennus

```bash
pip install acedatacloud acedatacloud-x402
```

Jos haluat käyttää `upto`-toimintoa, sinun on myös kutsuttava kertaluonteisesti Permit2 approve CLI:tä, jonka CLI riippuu `web3`:sta:

```bash
pip install 'acedatacloud-x402[cli]'
```

Puhtaan Python venv:n asennus- ja tuontitarkistuksen tuloste:

```text
acedatacloud 2026.4.26.1
acedatacloud-x402 2026.5.31.3
imports_ok True True True True True True
usage: acedatacloud-x402 [-h] {approve-permit2} ...
approve-permit2  One-time ERC-20 approve(Permit2, amount) needed before signing upto payments.
```

Tulosten kuvaus:

- Sekä `acedatacloud` että `acedatacloud-x402` voidaan asentaa ja tuoda PyPI:stä.
- `pip install 'acedatacloud-x402[cli]'` sisältää `approve-permit2` CLI:n, jota käytetään `upto`-toiminnon ennakkovaltuutukseen.

## Base-esimerkki

Alla oleva esimerkki ei tarvitse API Tokenia. Lompakon yksityisavainta käytetään vain paikalliseen allekirjoitukseen, eikä sitä lähetetä Ace Data Cloudille.

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)

print(res["choices"][0]["message"]["content"])
```

Python SDK palauttaa tällä hetkellä `dict`-objektin, joten esimerkissä käytetään `res["choices"][0]["message"]["content"]`. Älä oleta suoraan, että sillä on `.choices`-attribuutti.

## Solana-esimerkki

Solana käyttää base58-koodattua secret keytä:

```python
import os

from acedatacloud import AceDataCloud
from acedatacloud_x402 import SolanaKeypairSigner, create_x402_payment_handler

client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="solana",
        solana_signer=SolanaKeypairSigner.from_base58(os.environ["SOLANA_SECRET_KEY"]),
    )
)

res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

Solana-polku muodostaa ja lähettää SPL USDC `TransferChecked` -tapahtuman ja sijoittaa sitten tapahtuman allekirjoituksen `PAYMENT-SIGNATURE`-envelopeen.

Solana paid retry palautti tuotanto-API:ssa HTTP 200:n ja `ADC_SOLANA_E2E_OK`:n. Tässä julkisessa RPC-kyselyssä kohdattiin nopeusrajoitus, joten ketjussa olevaa signaturea ei vahvistettu vakaasti; käytä oman Solana RPC:si kautta kyseisen tapahtuman kyselyyn, kun tarvitset täsmäytystä.

## Async-asiakas

Samaa payment handleria voidaan käyttää `AsyncAceDataCloud`in kanssa:

```python
import os

from acedatacloud import AsyncAceDataCloud
from acedatacloud_x402 import EVMAccountSigner, create_x402_payment_handler

signer = EVMAccountSigner.from_private_key(os.environ["EVM_PRIVATE_KEY"])

client = AsyncAceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
    )
)

res = await client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Say hi in 3 words"}],
    max_tokens=10,
)
```

## `upto`-jälkimittauksen käyttö

Chat completion-, mallikutsu- ja muiden API:en todellinen kustannus voidaan tietää vasta vastauksen valmistumisen jälkeen. Tällöin API voi palauttaa samanaikaisesti `exact`- ja `upto`-arvot. Jos haluat ensisijaisesti käyttää `upto`-toimintoa:

```python
client = AceDataCloud(
    payment_handler=create_x402_payment_handler(
        network="base",
        evm_signer=signer,
        prefer_scheme="upto",
    )
)
```

Base `upto` -ohjelman suoritustulos:

```text
payer 0x5d4f08D5c2bb60703284bc06671Eb680fA41B105
elapsed_ms 5104
content ADC_BASE_UPTO_OK
id chatcmpl-DlcbyS4IT8kUAMo4Ri97HiIHc9T8V
settlement tx 0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
settled value 3 atomic USDC
```

Ketjuvahvistus:

```text
explorer https://basescan.org/tx/0x4b0b836ce1cd1171cdbc37df1637150b024214ec28e7f6f2d09122f15cbfc036
block 46726437
transfer value 3 atomic USDC
```

Tulosten kuvaus:

- `content ADC_BASE_UPTO_OK` osoittaa, että pyyntö todella pääsi mallin APIin.
- `settled value 3 atomic USDC` osoittaa, että `upto` veloitetaan todellisen käytön mukaan täydellisen ylärajan sijaan.
- `settlement tx` voidaan avata BaseScanissa; tallenna täsmäytystä varten tx hash, payer, completion id ja pyynnön tiivistelmä.

`upto` käyttää Permit2-valtuutusta ylärajan hyväksymiseen, eikä todellinen selvityssumma voi ylittää tätä ylärajaa. Ennen ensimmäistä käyttöä kohdeketjun USDC:lle on tehtävä kerran `approve(Permit2, amount)`.

CLI-tapa:

```bash
X402_PRIVATE_KEY=0x... acedatacloud-x402 approve-permit2 --network base
```

Ohjelmallinen tapa:

```python
from acedatacloud_x402 import EVMAccountSigner, approve_permit2

approve_permit2(
    rpc_url="https://mainnet.base.org",
    signer=EVMAccountSigner.from_private_key("0x..."),
    token_address="0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
)
```

Tämä helper on idempotentti. Jos allowance on jo riittävä, se palauttaa `{"skipped": true}` eikä lähetä toistuvaa ketjutapahtumaa.

## Alemman tason allekirjoitus

Jos et käytä SDK:ta, voit myös kutsua suoraan alemman tason allekirjoitusfunktiota:

```python
import base64
import json

from acedatacloud_x402 import EVMAccountSigner, sign_evm_payment

envelope = sign_evm_payment(requirement, EVMAccountSigner.from_private_key("0x..."))
x_payment = base64.b64encode(json.dumps(envelope, separators=(",", ":")).encode()).decode()
```

Alemman tason funktiot sopivat testaukseen, välityskerrokseen, gateway-integraatioon tai epävirallisiin SDK:ihin. Tavallisessa liiketoimintakoodissa käytä ensisijaisesti `create_x402_payment_handler`-toimintoa.
