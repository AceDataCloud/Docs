OpenCode:n Coding Plan -mallin Provider, IDE Extension ja MCP ovat kolme itsenäistä kykyä. IDE Extension yhdistää paikallisen OpenCode runtime:n ja käyttää samaa Provider-kokoonpanoa; se ei edusta isäntäeditorin alkuperäistä tukea Ace Data Cloudille.

| Reitti                          | Kuvaus                                                    | Linkki                                                                                  | Tila      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | Käyttää `opencode.json[c]` ja Chat Completions          | [Provider-kokoonpano](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Vahvistettu kokoonpanosopimus |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium jne. isäntä yhdistää OpenCode runtimeen | [IDE-kokoonpano](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Kokeellinen |
| MCP                           | Kutsuu etätyökaluja OpenCode:n sisällä                     | [MCP yleiskatsaus](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Itsellinen kyky |

Provider-kokoonpanon onnistumisen jälkeen IDE Extensionin tulisi käyttää samaa Provideria ja mallia. IDE:n sisällä tapahtuvaa keskustelua, tiedostojen lukemista, muokkaamista ja työkalujen kutsumista on edelleen erikseen vahvistettava, eikä CLI:n yhtä tavallista pyyntöä tulisi automaattisesti laajentaa kaikkiin IDE-kykyihin.

Mallin ID on [reaaliaikaisen hakemiston](https://platform.acedata.cloud/models) mukainen.
