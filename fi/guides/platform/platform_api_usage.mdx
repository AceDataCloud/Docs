title: "Hae AceDataCloud-alustan API:n viimeaikaiset kutsunäytteet"
description: "Platform API guide - Ace Data Cloud"
---

Palauttaa julkisesti tietyn API:n viimeisten 15 minuutin kutsutietueiden näytteet, jotta viimeaikaista tilaa voidaan tarkastella nopeasti. Se ei ole tilakoodin mukaan koottu laskentarajapinta, eikä sitä voi käyttää henkilökohtaiseen laskutukseen, SLA:han tai täydellisiin käyttötilastoihin.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                           |
| --- | ------------------------------------------------------------ |
| Menetelmä  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Todennus  | Julkinen, ei vaadi tilitunnusta                                                    |
| Yläraja  | Viimeksi luodut/valmistuneet tietueet yhdistetään, minkä jälkeen palautetaan enintään 5 000 tietuetta                                    |

`api_id` haetaan [API-luettelosta](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='sinun API ID:si'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Todellinen vastausrakenne

Vastaus on suoraan taulukko, eikä käytä sivutuksen envelopea:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Kenttä            | Kuvaus        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | Tietueen luontiaika    |
| `trace_id`    | Pyynnön seurantaidentiteetti    |
| `status_code` | HTTP-tilakoodi  |
| `elapsed`     | Kutsun kesto sekunteina |

Kun API:a ei ole olemassa, se voi tällä hetkellä myös palauttaa tyhjän taulukon, koska tämä action hakee viimeaikaisen usagen suoraan ID:n perusteella eikä ensin varmista API-objektia. Onnistumisprosentin laskemiseksi asiakkaan on ryhmiteltävä palautetut näytteet itse; henkilökohtaisten veloitusten tarkasteluun käytä tilitason rajapintaa.
