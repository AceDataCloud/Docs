LMLocal on Visual Studio 2022/2026:lle suunnattu laajennus, joka tukee virallisesti OpenAI-yhteensopivaa APIa ja mukautettua Base URL:ia. Konfigurointipiste voi vaihdella laajennusversion mukaan; ensimmäisellä kerralla käytä kiinteää versiota ja tarkista todellinen muokkaus, työkalukutsut ja käyttötilastot.

## Konfigurointi

1. Asenna LMLocal Visual Studio Marketplace:sta tai virallisesta varastosta.
2. Lisää Providers-osioon Custom/OpenAI-yhteensopiva Provider.
3. Täytä Base URL:ksi `https://api.acedata.cloud/v1`.
4. Täytä Auth Key:ksi Ace Data Cloud API Tokenisi.
5. Täytä Model:ksi mallihakemistossa tuettu Chat Completions -mallin tarkka ID.
6. Tallenna ja lähetä `Reply only OK`, testaa sitten projektin muokkausprosessi uudelleen.

## Nykyiset rajat

- Tämä opas kattaa vain LMLocalin, eikä se edusta muiden Visual Studio -laajennusten yhteisiä asetuksia.
- Eri versiot voivat käsitellä keskustelu-, muokkaus-, rakennus- ja testipyyntöjä erikseen; jokainen tila on vahvistettava itsenäisesti.
- Jos asiakas lisää automaattisesti `/v1` tai endpoint-polun, vältä toistuvia polkuja.
