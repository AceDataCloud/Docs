Palauttaa alustan julkisen malliluettelon, ja vastaus käyttää OpenAI-tyylistä `{ "object": "list", "data": [...] }`-rakennetta. Tätä luetteloa käytetään mallien valintaan ja ominaisuuksien selvittämiseen, eikä se tarkoita, että nykyinen tili olisi välttämättä hakenut vastaavaa palvelua.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                              |
| --- | ----------------------------------------------- |
| Menetelmä  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Todennus  | Julkinen, ei vaadi tilitunnusta                                       |
| Sivutus  | Ei sivutusta, kaikki vastaavat kohteet sijaitsevat `data`-kentässä                              |

## Kyselyparametrit

| Parametri             | Tyyppi      | Pakollinen  | Kuvaus                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Ei   | Suodattaa tarkasti luettelon mallintarjoajan tunnisteen mukaan                        |
| `type`         | string  | Ei   | Suodattaa tarkasti mallityypin mukaan, esimerkiksi `chat`                     |
| `capability`   | string  | Ei   | Palauttaa vain mallit, joiden `capabilities` sisältää tämän ominaisuuden, esimerkiksi `vision` |
| `with_pricing` | boolean | Ei   | Lisää julkiset hintatiedot, kun arvo on `1`, `true` tai `yes`            |

`service_id`-, `tag`-, `limit`-, `offset`- ja `ordering`-parametreja ei tällä hetkellä tueta; niiden välittäminen ei aiheuta vastaavaa suodatusta tai sivutusta.

## Pyyntöesimerkit

```shell
# Kaikki julkiset mallit
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Näköä tukevat chat-mallit hintatietoineen
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Todellinen vastausrakenne

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` ja ylimmän tason `credit_usd_rate` esiintyvät vain, kun `with_pricing=true`; kaikilla malleilla ei ole laskettavissa olevaa `pricing`-hintatietoa. Malliobjektit perustuvat tiedoston `config/models.json` julkisiin kenttiin, ja asiakkaiden tulee ohittaa uudet kentät.

> Hintakentät ovat luettelon näyttötietoja. Varsinaisissa liiketoimintakutsuissa sovelletaan edelleen vastaavan API:n/palvelun laskutussääntöjä ja lopullisia käyttötietoja.
