---
title: "AceDataCloud-alustan API-tunnistetietojen kierrättäminen"
description: "Platform API guide - Ace Data Cloud"
---

Luo uusi Token tai salasana olemassa olevalle Credentialille. Tunnistetiedon ID, Application-liitos, kiintiöt ja muut kentät pysyvät muuttumattomina, vanha salaisuus mitätöityy välittömästi.

> Kierrättäminen keskeyttää asiakkaat, jotka käyttävät edelleen vanhaa salaisuutta. Valmistele ensin turvallinen jakelu- ja palautussuunnitelma, ja suorita sitten kirjoitustoiminto.

## Rajapinnan yleiskatsaus

| Kohta    | Sisältö                                                                     |
| ---- | --------------------------------------------------------------------------- |
| Menetelmä   | `POST`                                                                      |
| URL  | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Todennus   | Account Token                                                               |
| Body | Ei mitään tai `{}`                                                                     |

Hae `credential_id` [tunnistetietoluettelosta](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='tilisi token'
export CREDENTIAL_ID='kierrettävän Credentialin ID'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Onnistunut vastaus palauttaa päivitetyn Credentialin. Kun `type=Token`, lue uusi `token`; kun `type=Identity`, lue uusi `password`. Käsittele koko vastausta salaisuutena ja päivitä kutsujat välittömästi.

## Virheenkäsittely

- `401`: Account Token on virheellinen.
- `403`: Ei oikeutta hallita tätä tunnistetietoa.
- `404`: Credential ID:tä ei ole olemassa.
