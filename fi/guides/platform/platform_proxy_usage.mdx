Hae nykyisen tilin käyttöön liittyvät tietueet Proxy-tyyppisistä palveluista. Tavallisissa API-kutsuissa käytä [API-kutsutietueita](https://platform.acedata.cloud/documents/platform-usage-list). Jos et ole varma palvelutyypistä, voit ensin tarkistaa `type`-kentän [palvelun tiedoista](https://platform.acedata.cloud/documents/platform-service-detail).

## Valmistelut

1. Kirjaudu [AceDataCloud-alustalle](https://platform.acedata.cloud).
2. Luo tilitunnus [Account Token -konsolissa](https://platform.acedata.cloud/console/platform-tokens) ja tallenna se välittömästi salasananhallintaan tai Secret Manageriin.
3. Avaa [profiilisivu](https://auth.acedata.cloud/user/profile), kopioi nykyisen tilin UUID ja tallenna se muuttujaan `USER_ID`. Myös tilitunnuksen luontivastauksen `user_id`-arvoa voidaan käyttää.
4. Hae Proxy-tyyppisen palvelun `application_id` [palveluhakemusluettelosta](https://platform.acedata.cloud/documents/platform-application-list). Jos haluat suodattaa Proxy-päätepisteen mukaan, hae `proxy_id` [palvelun Proxy-luettelosta](https://platform.acedata.cloud/documents/platform-service-proxies).

Täydellinen tunnuskuvaus on kohdassa [tilitunnusten hallinta](https://platform.acedata.cloud/documents/platform-token). Tämä rajapinta käyttää Account Tokenia, ei liiketoiminta-API:n kutsumiseen käytettävää Credentialia.

```shell
export PLATFORM_TOKEN='你的账户令牌'
export USER_ID='你的账户 UUID'
export APPLICATION_ID='你的 Proxy Application ID'
```

## Rajapinnan yleiskatsaus

| Kohta     | Sisältö                                                     |
| ----- | ------------------------------------------------------ |
| Menetelmä    | `GET`                                                  |
| URL   | `https://platform.acedata.cloud/api/v1/usage/proxies/` |
| Todennus    | `Authorization: Bearer ${PLATFORM_TOKEN}`              |
| Scope | `usage:read`                                           |
| Sivutus    | `count` + `items`, oletuksena 10 kohdetta sivulla                            |

Kun Applicationin omistaja tekee kyselyn `application_id`-arvolla, palvelin synkronoi ensin kyseisen Applicationin käytettävissä olevat tietueet ja palauttaa sitten luettelon, joten vastausaika voi olla pidempi kuin tavallisessa API usage -luettelossa. Valtuutetut käyttäjät voivat lukea olemassa olevia näkyviä tietueita, mutta tämä ei käynnistä omistajapuolen synkronointia.

## Kyselyparametrit

| Parametri               | Tyyppi      | Pakollinen     | Oletus            | Kuvaus                            |
| ---------------- | ------- | ------ | ------------- | ----------------------------- |
| `user_id`        | UUID    | Pakollinen tavallisille käyttäjille | —             | Nykyisen tilin UUID; toisen tilin antaminen palauttaa `403`     |
| `application_id` | UUID    | Suositeltu     | —             | Suodata Proxy Applicationin mukaan; tukee toistuvia parametreja |
| `proxy_id`       | UUID    | Ei      | —             | Suodata Proxy-päätepisteen mukaan; tukee toistuvia parametreja           |
| `limit`          | integer | Ei      | 10            | Kohteiden määrä sivulla, enintään 100                   |
| `offset`         | integer | Ei      | 0             | Sivutuspoikkeama                         |
| `ordering`       | string  | Ei      | `-created_at` | Luontiajan mukaan laskevassa järjestyksessä                       |

Nykyinen rajapinta ei tue suoraa suodatusta mallin, HTTP-tilakoodin, Credentialin tai aikavälin mukaan, eikä se tue API usage -rajapinnan `perspective`-parametria. Älä lisää pyyntöön näitä tukemattomia parametreja ja oleta niiden olevan voimassa.

## Pyyntöesimerkki

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/proxies/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Python-sivutusesimerkki:

```python
import os
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/usage/proxies/",
    headers={"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    params={
        "user_id": os.environ["USER_ID"],
        "application_id": os.environ["APPLICATION_ID"],
        "limit": 100,
    },
    timeout=60,
)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["deducted_amount"], usage["remaining_amount"])
```

## Keskeiset kentät

| Kenttä                       | Kuvaus                       |
| ------------------------ | ------------------------ |
| `user_id`                | Tili, jolta tämä veloitus tehdään                |
| `actor_user_id`          | Todellinen kutsuja; vanhoista tietueista voi puuttua            |
| `application_id`         | Proxy Application, joka tuotti tämän tietueen |
| `proxy_id`               | Vastaava Proxy-päätepiste             |
| `credential_id`          | Liitetty tunnisteen ID; vanhoista tietueista voi puuttua          |
| `used_amount`            | Alkuperäisen tietueen käyttömäärä; voi puuttua             |
| `deducted_amount`        | Lopullinen todellisuudessa vähennetty kiintiö                 |
| `remaining_amount`       | Applicationin jäljellä oleva kiintiö veloituksen jälkeen    |
| `metadata`               | Julkinen metadata; voi puuttua               |
| `service` / `credential` | Liittyvien objektien yhteenvedot esittämistä varten; voivat puuttua, jos liittyvää objektia ei ole olemassa |

Kiintiöyksikkö määräytyy vastaavan Applicationin `service.unit`-kentän mukaan.

## Virheenkäsittely

| HTTP | Merkitys         | Käsittely                                        |
| ---- | ---------- | ------------------------------------------- |
| 401  | Tilitunnus puuttuu tai on virheellinen  | Tarkista Account Token, älä käytä vahingossa liiketoiminta-Credentialia          |
| 403  | Ei oikeutta tarkastella pyydettyjä tietueita | Käytä nykyiselle tilille kuuluvaa Applicationia, poista valtuuttamaton `user_id`      |
| 5xx  | Synkronointi tai kysely epäonnistui tilapäisesti  | Säilytä suodatusehdot ja yritä uudelleen viiveellä; jos virhe jatkuu, anna tukihenkilöstölle Application ID ja ajankohta |
