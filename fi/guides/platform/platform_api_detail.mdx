Hae yhden API-päätepisteen täydelliset tiedot API ID:n avulla — sisältää [listausrajapintaan](https://platform.acedata.cloud/documents/platform-api-list) verrattuna lisäksi kentät `definition` (OpenAPI 3.0 Schema), `service` (kuuluvan palvelun tiedot) ja `products` (liitetyt tuotteet).

Sopii esimerkiksi SDK:n automaattiseen generointiin, työkalukuvausten syöttämiseen LLM Agentille ja dokumentaatiosivuston dynaamiseen renderöintiin.

> ℹ️ Tämä rajapinta kuuluu **AceDataCloud-alustan hallinta-APIin**, jonka yhtenäinen etuliite on `https://platform.acedata.cloud/api/v1/`。Täydellinen rajapintaluettelo löytyy kohdasta [AceDataCloud-alustan dokumenttiluettelon hakeminen](https://platform.acedata.cloud/documents/platform-document-list)。

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                    |
| --- | ----------------------------------------------------- |
| Metodi  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Todennus  | ❌ Julkinen                                                  |

`/apis/{id}` ja `/apis/{id}/` ovat molemmat tällä hetkellä käytettävissä; esimerkeissä käytetään yhdenmukaisesti muotoa ilman lopussa olevaa kauttaviivaa.

## Todennusohjeet

Tämä rajapinta on **täysin julkinen, eikä vaadi tilitunnusta tai kirjautumistilaa**.

## Polkuparametrit

| Parametri       | Tyyppi   | Pakollinen  | Kuvaus                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | API ID (UUID-muoto, aliaksia ei tueta) |

## Pyyntöesimerkit

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Vastauskenttien kuvaus

Tietorajapinta sisältää [listausrajapinnan kenttien](https://platform.acedata.cloud/documents/platform-api-list) lisäksi:

| Kenttä           | Tyyppi     | Kuvaus                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Kuuluvan palvelun ydintiedot: `id`、`title`、`type`、`alias`                                                       |
| `products`   | array  | Liitettyjen tuotteiden luettelo (yleensä tyhjä, operatiivista käyttöä varten)                                                                         |
| `definition` | object | **Täydellinen OpenAPI 3.0 -määrityksen määritelmä**, sisältää esimerkiksi `paths`、`components`、`info` ja muita tietoja, ja voidaan syöttää suoraan `openapi-generator`-työkalulle asiakaskoodin generointia varten |

## Virheenkäsittely

| HTTP | code        | Merkitys                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` ei ole kelvollinen UUID |
| 404  | `not_found` | APIa ei ole olemassa tai se on poistettu käytöstä        |

## Käytännön vinkit

- **`definition`-kenttä on erittäin suuri**：Yksittäisen API:n OpenAPI Schema voi sisältää satoja JSON-rivejä. Jos tarvitset vain palveluhakemiston etkä Schemaa, käytä sen sijaan [listausrajapintaa](https://platform.acedata.cloud/documents/platform-api-list)。
- **Yleinen tapa generoida SDK**：
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **API-muutosten seuranta**：`updated_at`-kenttä on scheman viimeisimmän muutoksen aika. Tämän kentän tilaaminen mahdollistaa SDK:n automaattisen uudelleengeneroinnin OpenAPI-muutosten yhteydessä.
