OpenCode virallinen IDE-laajennus tukee VS Codea, Cursoria, Windsurfia, VSCodiumia ja muita editoria, ja se hyödyntää OpenCode paikallista runtimea ja Provider-konfiguraatiota. IDE-laajennus käyttää paikallista CLI Provideria, mutta eri editoriversioiden pyyntöketjut voivat vaihdella; ensimmäisellä kerralla liitettäessä on suositeltavaa käyttää kiinteää versiota ja suorittaa vähimmäistarkistus.

## Providerin konfigurointi

Ensiksi, seuraa [OpenCode Terminalin konfigurointia](https://platform.acedata.cloud/documents/opencode-terminal-integration) ja konfiguroi Ace Data Cloud Provider `opencode.json` tai `opencode.jsonc` tiedostoon:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## IDE-laajennuksen asentaminen

1. Suorita `opencode` editorin integroituun terminaaliin, ja asenna laajennus automaattisesti virallisen prosessin mukaan; voit myös asentaa sen manuaalisesti vastaavasta Marketplace:sta.
2. Lataa editori uudelleen.
3. Aloita OpenCode-laajennuksesta `Reply only OK`.
4. Suorita uudelleen pyyntö, joka tarvitsee tiedoston lukemista tai koodin muokkaamista, varmistaaksesi, että IDE-laajennus käyttää samaa Provideria ja mallia.

## Nykyiset rajat

- Providerin kyvyt tulevat OpenCode runtime:sta, eivätkä ne tarkoita, että isäntäeditori tukee Ace Data Cloudia natiivisti.
- VS Code ja sen forkien laajennusversiot voivat olla erilaisia, ja ne tulisi kirjata erikseen.
- Yksinkertainen keskustelu onnistuneesti ei voi korvata tiedoston lukemisen, muokkaamisen ja työkalujen kutsumisen vahvistamista.
