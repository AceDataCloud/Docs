[LibreChat](https://www.librechat.ai/) on erittäin konfiguroitava avoimen lähdekoodin AI-asiakaspalvelin, joka voi käyttää `librechat.yaml`-tiedostoa palveluntarjoajien, mallien ja reitityssääntöjen kuvaamiseen. Se tukee mukautettuja OpenAI-yhteensopivia päätepisteitä, joten Ace Data Cloud voidaan liittää. Tässä artikkelissa käsitellään konfigurointiprosessia.

## Hakuprosessi

Jotta voit liittää Ace Data Cloudin LibreChatissa, siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) ja hanki API-tokenisi, joka kannattaa säilyttää varalla.

![Hanki Ace Data Cloud API-avain](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Ace Data Cloudin mallipalveluja ilmaiseksi.

## LibreChatin käyttöönotto

LibreChat otetaan käyttöön Docker Composen avulla. Valmistele ensin hakemisto ja lataa viralliset asetukset:

```bash
mkdir -p ~/librechat && cd ~/librechat
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/.env.example
mv .env.example .env
```

Generoi `.env`-tiedostossa `JWT_SECRET`, `JWT_REFRESH_SECRET`, `CREDS_KEY`, `CREDS_IV` ja muita turvallisuusavaimia komennolla `openssl rand -hex 32`, ja aseta tarvittaessa `ALLOW_REGISTRATION`.

## Ace Data Cloudin konfigurointi

Luo `librechat.yaml` ja määritä Ace Data Cloud mukautetuksi OpenAI-yhteensopivaksi päätepisteeksi (täydelliset kenttäkuvaukset löytyvät virallisesta [Custom Endpoints -dokumentista](https://www.librechat.ai/docs/quick_start/custom_endpoints), vaihda `{token}` omaksi tokeniksesi):

```yaml
version: 1.0.5
cache: true

endpoints:
  custom:
    - name: "Ace Data Cloud"
      apiKey: "{token}"
      baseURL: "https://api.acedata.cloud/v1"
      models:
        default:
          - "MODEL_ID"
        fetch: true
      titleConvo: true
      titleModel: "MODEL_ID"
      modelDisplayLabel: "Ace Data Cloud"
```

Liitä tämä tiedosto `docker-compose.yml`-tiedoston `api`-palvelun alle ja käynnistä sitten `docker compose up -d`:

```yaml
    volumes:
      - type: bind
        source: ./librechat.yaml
        target: /app/librechat.yaml
```

Huomaa `baseURL`:n polku:

| baseURL                               | Todellinen pyyntö                                           | Tulos                     |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Oikein                   |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Myös käytettävissä       |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai` ei sisällä `/v1`) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (puuttuu `/v1`)     |

## Mallin valinta

Malliluettelo päivittyy jatkuvasti. Käytä ensisijaisesti asiakassovelluksen automaattisesti lataamaa mallilistaa; jos sinun on täytettävä se manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models` saadaksesi nykyisen mallin ID:n ja valitse sitten asiakassovelluksen tukemien kontekstien, kuvien ja työkalujen kutsumismahdollisuuksien mukaan.

## Vahvistus

Jos et ole varma, onko ongelma LibreChatissa vai verkossa, voit ensin vahvistaa päätepisteen suoraan curlilla (vaihda `{token}` omaksi tokeniksesi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Jos saat takaisin OpenAI-yhteensopivan `chat.completion`-objektin, se tarkoittaa, että token ja päätepiste ovat valmiina; jos saat `HTTP 403 used_up`, se tarkoittaa, että token on voimassa, mutta saldo on loppu, ja voit ladata lisää [hallintapaneelista](https://platform.acedata.cloud/console/applications).

## Edistykselliset: yaml-konfigurointivinkit

`librechat.yaml` tukee useita päätepisteiden ryhmiä, voit käyttää `apiKey: "user_provided"` -asetusta, jotta jokainen käyttäjä voi syöttää oman avaimensa; `titleModel` määrittää keskustelun otsikon luomiseen käytettävän mallin; `dropParams` voi poistaa yhteisesti kaikki kohde-API:n tukemat parametrit. Katso tarkemmin [librechat.yaml-konfiguroinnin yksityiskohtia](https://www.librechat.ai/docs/configuration/librechat_yaml).

## Usein kysytyt kysymykset

### Käynnistyksen jälkeen Ace Data Cloud -päätepistettä ei näy

Yleensä syynä on, että yaml-tiedostoa ei ole liitetty säiliöön tai sisennys on virheellinen. Tarkista `docker-compose.yml`-tiedoston volumes ja varmista yaml-tiedoston sisennys.

### Virhe 404

`baseURL` on kirjoitettu muotoon `.../openai/v1` tai `/v1` puuttuu. Muuta se muotoon `https://api.acedata.cloud/v1`.

### Mallivalikko on tyhjää

`fetch: true`, mutta `/v1/models` epäonnistuu, vaihda `fetch: false` ja luettele `default` manuaalisesti.

### Muutokset yaml-tiedostoon eivät vaikuta

Säiliö on käynnistettävä uudelleen: `docker compose restart api`.
