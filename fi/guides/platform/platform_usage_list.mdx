Hae nykyisen tilin viimeisten 60 päivän liiketoiminta-API-kutsujen tiedot. Soveltuu veloitusten tarkistamiseen, epäonnistuneiden pyyntöjen paikantamiseen sekä ongelmien selvittämiseen palvelun, Applicationin, API:n tai tunnistetietojen mukaan.

> Tällä sivulla haetaan tilin omia kutsulokeja. Jos haluat tarkastella vain tietyn API:n julkisia kutsutilastoja koko alustalla, käytä [API-kutsutilastoja](https://platform.acedata.cloud/documents/platform-api-usage).

## Valmistelut

### 1. Luo tilitunnus

Tämä rajapinta kuuluu alustan hallinta-API:hin ja edellyttää **Account Tokenia (tilitunnusta)**:

1. Kirjaudu [AceDataCloud-alustalle](https://platform.acedata.cloud).
2. Avaa [Account Token -konsoli](https://platform.acedata.cloud/console/platform-tokens).
3. Napsauta ”Luo” ja tallenna tunnus välittömästi salasanojen hallintaan tai Secret Manageriin.

Täydelliset ohjeet löytyvät kohdasta [AceDataCloud-alustan tilitunnusten hallinta](https://platform.acedata.cloud/documents/platform-token). Tilitunnusta käytetään kohteelle `platform.acedata.cloud/api/v1/**`; `api.acedata.cloud/**`-liiketoimintarajapintojen kutsumiseen käytetään API-tunnistetietoja (Credential), eikä niitä voi käyttää ristiin.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

Älä kirjoita tunnusta frontend-koodiin, lokeihin tai julkisiin repositorioihin; jos se vuotaa, poista se välittömästi konsolissa ja luo uusi.

### 2. Valmistele suodatustunnukset (valinnainen)

Ilman suodatusehtoja voit tarkastella tietueita, joiden tarkasteluoikeus nykyisellä tilillä on. Kun haluat rajata aluetta:

- `application_id`: hae [palveluhakemusluettelosta](https://platform.acedata.cloud/documents/platform-application-list);
- `credential_id`: hae [API-tunnistetietoluettelosta](https://platform.acedata.cloud/documents/platform-credential-list);
- `api_id`: hae [API-luettelosta](https://platform.acedata.cloud/documents/platform-api-list);
- `service_id`: hae [palveluluettelosta](https://platform.acedata.cloud/documents/platform-service-list).

Tavallisten käyttäjien ei tarvitse lähettää `user_id`-parametria; jos se annetaan nimenomaisesti, sen on vastattava nykyistä tiliä, muutoin palautetaan `403`. Järjestelmänvalvojat voivat käyttää tätä parametria suodatukseen eri tilien välillä.

## Rajapinnan yleiskatsaus

| Kohta           | Sisältö                                             |
| --------------- | --------------------------------------------------- |
| Menetelmä       | `GET`                                               |
| URL             | `https://platform.acedata.cloud/api/v1/usage/apis/` |
| Todennus        | `Authorization: Bearer ${PLATFORM_TOKEN}`           |
| OAuth Scope     | `usage:read` (`platform:read` / `platform` sisältää sen laajennettuna) |
| Sivutus         | `count` + `items`, oletuksena 10 kohdetta sivulla   |

## Kyselyalue

| `perspective` | Merkitys                                             |
| ------------- | ---------------------------------------------------- |
| `both`        | Oletusarvo; palauttaa tietueet, joista nykyinen tili maksaa tai jotka se todella kutsui |
| `billing`     | Palauttaa vain tietueet, joista nykyinen tili maksaa |
| `actor`       | Palauttaa vain tietueet, jotka nykyinen tili todella kutsui |

## Kyselyparametrit

| Parametri         | Tyyppi     | Pakollinen | Oletus        | Kuvaus                                            |
| ----------------- | --------- | ---------- | ------------- | ------------------------------------------------- |
| `perspective`     | string    | Ei         | `both`        | `billing`, `actor` tai `both`                     |
| `user_id`         | UUID      | Ei         | —             | Vain järjestelmänvalvojat suodattavat käyttäjän mukaan; tukee toistuvia parametreja |
| `service_id`      | UUID      | Ei         | —             | Suodata palvelun mukaan; tukee toistuvia parametreja |
| `application_id`  | UUID      | Ei         | —             | Suodata Applicationin mukaan; tukee toistuvia parametreja |
| `api_id`          | UUID      | Ei         | —             | Suodata API:n mukaan; tukee toistuvia parametreja |
| `credential_id`   | UUID      | Ei         | —             | Suodata API-tunnistetietojen mukaan; tukee toistuvia parametreja |
| `status_code`     | integer   | Ei         | —             | Suodata HTTP-tilakoodin mukaan; tukee toistuvia tai pilkuilla eroteltuja arvoja |
| `created_at_from` | datetime  | Ei         | —             | Luontiajan alaraja, ISO 8601                      |
| `created_at_to`   | datetime  | Ei         | —             | Luontiajan yläraja, ISO 8601                      |
| `limit`           | integer   | Ei         | 10            | Kohteiden määrä sivulla, enintään 100             |
| `offset`          | integer   | Ei         | 0             | Sivutussiirtymä                                   |
| `ordering`        | string    | Ei         | `-created_at` | Luontiajan mukaan laskevassa järjestyksessä       |

Jos pyynnön aika on yli 60 päivää sitten, rajapinta palauttaa `400`-kenttävalidointivirheen ja ilmoittaa, että täydelliset kutsutiedot säilytetään vain 60 päivää.

## Pyyntöesimerkit

Hae viimeisimmät 100 tietuetta:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode 'perspective=both' \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=-created_at' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Suodata ajan, Applicationin ja epäonnistuneen tilan mukaan:

```shell
export APPLICATION_ID='你的 Application ID'

curl --get 'https://platform.acedata.cloud/api/v1/usage/apis/' \
  --data-urlencode "application_id=${APPLICATION_ID}" \
  --data-urlencode 'created_at_from=2026-09-01T00:00:00Z' \
  --data-urlencode 'created_at_to=2026-09-02T00:00:00Z' \
  --data-urlencode 'status_code=500' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Python-sivutusesimerkki:

```python
import os
import requests

url = "https://platform.acedata.cloud/api/v1/usage/apis/"
headers = {"Authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"}
params = {"perspective": "both", "limit": 100, "offset": 0}

response = requests.get(url, headers=headers, params=params, timeout=30)
response.raise_for_status()
data = response.json()

for usage in data["items"]:
    print(usage["created_at"], usage["status_code"], usage["deducted_amount"], usage["trace_id"])

if params["offset"] + len(data["items"]) < data["count"]:
    params["offset"] += len(data["items"])
```

## Keskeiset kentät

| Kenttä                           | Kuvaus                                              |
| -------------------------------- | --------------------------------------------------- |
| `user_id`                        | Tili, jolta tämä veloitus tehdään                   |
| `actor_user_id`                  | Kutsun tosiasiallisesti käynnistävä tili; voi poiketa `user_id`:stä, kun toiselle annetaan lupa käyttää tunnistetta |
| `used_amount`                    | Tämän kutsun alkuperäisten sääntöjen mukaan laskettu käyttömäärä |
| `original_amount`                | Alkuperäinen käyttömäärä ennen sovellusalennusta    |
| `deducted_amount`                | Lopullinen tosiasiallisesti vähennetty määrä        |
| `remaining_amount`               | Applicationin jäljellä oleva saldo tämän veloituksen jälkeen |
| `elapsed`                        | Palvelinpuolen tallentama kutsun kesto sekunteina   |
| `trace_id`                       | Seurantatunniste, jota käytetään yksittäisen pyynnön selvittämisessä |
| `metadata`                       | Julkinen metatieto; luettelo ei palauta täydellistä pyynnön tai vastauksen sisältöä |
| `api` / `service` / `credential` | Näyttämistä helpottavat linkitettyjen objektien yhteenvedot; voivat olla tyhjiä, jos linkitettyä objektia ei enää ole olemassa |

Määräyksikkö määräytyy vastaavan Applicationin `service.unit`-arvon mukaan, eikä sitä tule oletusarvoisesti pitää Yhdysvaltain dollareina.

## Virheet ja uudelleenyritykset

| HTTP | `error`                   | Merkitys             | Käsittelytapa                              |
| ---- | ------------------------- | ------------------- | ------------------------------------------ |
| 400  | Kentän validointivirhe    | Kyselyalue on aiempi kuin 60 päivän säilytysaika | Säädä aloitusaika viimeisten 60 päivän sisälle |
| 401  | `not_authenticated`       | Tilin tunniste puuttuu tai on virheellinen | Tarkista Account Token, älä käytä vahingossa liiketoiminnan Credentialia |
| 403  | `permission_denied`       | Pyyntö sisältää tietueita, joihin ei ole katseluoikeutta | Poista luvattomat käyttäjän suodatusehdot |
| 429  | `usage_query_in_progress` | Täsmälleen sama kysely on yhä käynnissä | Odota `Retry-After`-ajan verran ja yritä uudelleen viiveellä |
| 503  | `usage_query_timeout`     | Kysely ylittää palvelinpuolen turvallisen aikarajan | Pienennä aikaväliä tai lisää suodatusehtoja ennen uudelleenyritystä |

Samoilla kyselyparametreilla saa olla enintään yksi käynnissä oleva pyyntö. Käytä laajoissa kyselyissä ensisijaisesti yhden päivän tai sitä pienempiä ikkunoita, äläkä kasaa samoja pyyntöjä kiintein väliajoin.
