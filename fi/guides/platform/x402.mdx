X402 on HTTP `402 Payment Required` -pohjainen ketjun maksuprotokolla. Ace Data Cloudin X402-ominaisuuden avulla kutsuja voi suorittaa ketjun maksun suoraan USDC:llä ilman API-tokenin luomista tai tilin saldon ennakkolatausta jokaisessa API-pyynnössä.

Tämä dokumenttisarja on järjestetty todellisen integrointijärjestyksen mukaan: ensin suoritetaan yksi minimaalinen pyyntö, sitten integroidaan SDK, ja sen jälkeen ymmärretään verkko, hinnoittelumallit, tilauksen maksaminen ja Facilitator. Suositellaan lukemaan taulukon mukaisesti ylhäältä alas.

## Suositeltu integrointipolku

Jos haluat vain kutsua Ace Data Cloud API:a, käytä ensisijaisesti virallista SDK:ta:

- TypeScript: `@acedatacloud/sdk` + `@acedatacloud/x402-client`
- Python: `acedatacloud` + `acedatacloud-x402`

Julkiset lähdekoodit ja pakettiosoitteet:

| Projekti                 | Osoite                                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| Ace Data Cloud SDK | [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)                                         |
| X402 Client        | [https://github.com/AceDataCloud/X402Client](https://github.com/AceDataCloud/X402Client)                           |
| X402 Facilitator   | [https://github.com/AceDataCloud/FacilitatorX402](https://github.com/AceDataCloud/FacilitatorX402)                 |
| npm SDK            | [https://www.npmjs.com/package/@acedatacloud/sdk](https://www.npmjs.com/package/@acedatacloud/sdk)                 |
| npm X402 Client    | [https://www.npmjs.com/package/@acedatacloud/x402-client](https://www.npmjs.com/package/@acedatacloud/x402-client) |
| PyPI SDK           | [https://pypi.org/project/acedatacloud/](https://pypi.org/project/acedatacloud/)                                   |
| PyPI X402 Client   | [https://pypi.org/project/acedatacloud-x402/](https://pypi.org/project/acedatacloud-x402/)                         |

SDK hoitaa automaattisesti ensimmäisen ilman todennusta olevan pyynnön, purkaa `402 Payment Required`, kutsuu maksukäsittelijää ja yrittää uudelleen näitä vaiheita `PAYMENT-SIGNATURE` mukana. Sinun tarvitsee vain valmistella lompakko, jossa on USDC, ja valita haluamasi verkko.

Jos haluat, että oma API tukee myös X402-maksamista, sinun on luettava Facilitator-dokumentaatio ja ymmärrettävä `paymentRequirements`, `paymentPayload`, `/verify` ja `/settle` -suhteet.

## Tukitila

Ace Data Cloud X402 on vahvistettu julkisessa API:ssa, virallisessa SDK:ssa, Facilitatorissa ja ketjun selvityspolussa. Taulukko kokoaa nykyiset tilat kehittäjien integroinnin yleisimmin käytettyjen ominaisuuksien mukaan.

| Ominaisuus                       | Tila                  | Selitys                                                                 |
| ------------------------ | ------------------- | ------------------------------------------------------------------ |
| Facilitator-ominaisuudet | Saatavilla                  | `https://facilitator.acedata.cloud/.well-known/x402` palauttaa maksaverkon ja protokollan päätepisteet.  |
| API 402 `accepts`        | Saatavilla                  | Maksamattomat pyynnöt palauttavat Base-, SKALE- ja Solana-maksuvaatimukset.              |
| TypeScript SDK           | Saatavilla                  | `@acedatacloud/sdk` ja `@acedatacloud/x402-client` voivat automaattisesti käsitellä 402, allekirjoitukset ja uudelleenyritykset. |
| Python SDK               | Saatavilla                  | `acedatacloud` ja `acedatacloud-x402` voivat automaattisesti käsitellä 402, allekirjoitukset ja uudelleenyritykset.              |
| Base `exact`             | Vahvistettu ketjussa               | Sopii kiinteän summan API:lle ja tilauksen maksamiselle.                                                  |
| Base `upto`              | Vahvistettu ketjussa               | Sopii keskustelun täydentämiseen ja muihin jälkikäteismaksu API:hin, tällä hetkellä ainoa verkko, joka tarjoaa `upto`.                                 |
| SKALE `exact`            | Vahvistettu ketjussa               | Sopii alhaisen kaasukustannuksen EVM-maksuskenaarioihin.                                              |
| Solana `exact`           | HTTP maksettu uudelleenyritys vahvistettu | Vahvistettu API:n maksettu uudelleenyritys ja mallivastaus; ketjussa allekirjoituksen vahvistamiseksi suositellaan oman Solana RPC:n käyttöä.               |
| Tilauksen maksaminen                     | Vahvistettu ketjussa               | Base `exact` -tilauksen maksaminen on suoritettu ketjussa ja tilauksen tila on päivitetty.                                   |

## Liittymisohjeet

Kehittäjien tulisi keskittyä ensisijaisesti nykyisen pyynnön palauttamiin reaaliaikaisiin maksuvaatimuksiin, eikä kopioida asiakirjassa olevia esimerkkimääriä tai osoitteita:

- `hyväksyy[].maxAmountRequired` on nykyisen pyynnön allekirjoitettavissa oleva suurin määrä.
- `hyväksyy[].varanto` on tämän pyynnön käyttämä USDC-sopimus tai mint.
- `hyväksyy[].extra.chainId`, `hyväksyy[].extra.facilitatorAddress` ja `hyväksyy[].extra.verifyingContract` osallistuvat EVM-tyyppisten tietojen allekirjoitukseen.
- `enintään` vaatii lompakolta ensin USDC:n valtuutuksen kohdeketjussa Permit2; ilman valtuutusta palautuu `PERMIT2_ALLOWANCE_REQUIRED`.
- Jos haluat selvästi käyttää jälkikäteen mitattavaa, lähetä TypeScript SDK: ssa `preferScheme: 'enintään'`, muuten SDK valitsee kyseisen verkon palvelimen palauttamista ensimmäisestä saatavilla olevasta vaatimuksesta.

## Julkisesti tarkistettavat alueet

Liittymisen yhteydessä voit ensin tarkistaa nämä julkiset sisäänkäynnit ja SDK:n käyttäytymisen:

- API-pyyntö, jossa ei ole `Authorization` tai `PAYMENT-SIGNATURE`, palauttaa `402 Payment Required`, ja vastauksen `hyväksyy` on tämän pyynnön ainoa allekirjoitusperuste.
- TypeScript SDK ja Python SDK tarjoavat maksuhallintajan, SDK:n siirtokerros kutsuu hallintajaa ja yrittää uudelleen saatuaan 402.
- `https://facilitator.acedata.cloud/.well-known/x402`: palauttaa Facilitatorin tukemat verkot, kaaviot ja protokollapisteet; API-hinta määräytyy edelleen kohdepyynnön reaaliaikaisesti palautetun 402 mukaan.
- `https://facilitator.acedata.cloud/supported`: palauttaa Facilitatorin tukemat verkot ja kaaviot.
- X402Client-varasto sisältää edistyneitä ketjun päällä vahvistustyökaluja, joita voidaan käyttää allekirjoitusten, uudelleenyritysten ja selvitystoimien vahvistamiseen; työkalun tulostus ei korvaa verkossa API:n palauttamaa `hyväksyy`.

`enintään` kuuluu jälkikäteen mitattavaan selvitykseen, joka sopii keskustelun täydentämiseen, mallikutsuihin ja muihin todellisiin käyttöihin, jotka tiedetään vasta vastauksessa. Tällä hetkellä vain Perus tarjoaa `enintään`; jos allekirjoituksen vahvistus epäonnistuu, tarkista, että ketjun id, helpottajan osoite, käyttäjä, USDC-sopimus ja Permit2-rahasto vastaavat 402-vastausta.
