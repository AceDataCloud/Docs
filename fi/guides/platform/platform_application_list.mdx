Palauttaa sivutettuna tilin omistamat tai käyttöön valtuutetut Application-kohteet, mukaan lukien saldo, tila, palveluyhteenveto ja siihen liittyvät tunnistetiedot. Soveltuu eräsaldon valvontaan, Application ID:n etsimiseen ja tunnistetietojen hallintaan siirtymiseen.

## Valmistelut

1. Kirjaudu [AceDataCloud-alustalle](https://platform.acedata.cloud).
2. Luo tilitunnus [Account Token -konsolissa](https://platform.acedata.cloud/console/platform-tokens).
3. Tavalliset käyttäjät käyttävät `user_id=me`; voit myös hakea oman UUID:si kohdasta `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='tilitunnuksesi'
```

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                    |
| --- | ----------------------------------------------------- |
| Menetelmä  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/` |
| Todennus  | Account Token, OAuth token vaatii `applications:read`       |
| Sivutus  | `count` + `items`                                     |

Tavallisten käyttäjien tulee välittää `user_id=me`. Jos sitä ei välitetä, kyselyä ei ensin rajata tilin mukaan, ja sivutus voi palauttaa `403`-virheen, kun kohdataan kohteita, joihin ei ole oikeuksia; järjestelmänvalvojat voivat nähdä koko taulukon, jos sitä ei välitetä.

## Kyselyparametrit

| Parametri            | Tyyppi          | Pakollinen     | Kuvaus                                                  |
| ------------- | ----------- | ------ | --------------------------------------------------- |
| `user_id`     | UUID / `me` | Pakollinen tavallisille käyttäjille | Kyselyn kohde; tukee toistuvia parametreja                                         |
| `affiliation` | string      | Ei      | `owner` (oletus) tai `granted`; molemmat voidaan välittää toistuvasti unionin hakemiseksi, voimassa vain, kun `user_id` on annettu |
| `service_id`  | UUID        | Ei      | Suodata palvelun mukaan; tukee toistuvia parametreja                                        |
| `scope`       | string      | Ei      | `Individual` tai `Global`; tukee toistuvia parametreja                      |
| `type`        | string      | Ei      | `Usage` tai `Period`; tukee toistuvia parametreja                           |
| `limit`       | integer     | Ei      | Kohteiden määrä sivua kohden, enintään 100                                         |
| `offset`      | integer     | Ei      | Sivutussiirtymä                                               |
| `ordering`    | string      | Ei      | Tukee vain `created_at` tai `-created_at`                    |

`paid`, `disabled`, `expired`, `low_balance` ja `tag` eivät tällä hetkellä ole palvelinpuolen suodatusparametreja. Saldoilmoituksia varten luettelo tulee hakea ja arvioida asiakaspuolella kunkin Application-kohteen `remaining_amount`-, `service.unit`- ja liiketoimintakynnysarvon perusteella.

## Pyyntöesimerkki

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

Näytä samanaikaisesti itse omistamasi ja muiden sinulle valtuuttamat Application-kohteet:

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'affiliation=granted' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Vastauksen kuvaus

Vastaus on muodossa `{count, items}`. Jokainen kohde sisältää Application-mallin kentät sekä lisäksi:

- `service`: `id`, `alias`, `title`, `type`, `unit`, `icon_url`;
- `credentials`: tunnistetietojen yhteenveto, jonka nykyinen kutsuja saa nähdä;
- `paid`, `remaining_amount`, `used_amount`, `disabled`, `allow_consume_global`;
- `scope`-kentän todellinen arvo on `Individual` tai `Global`;
- `type`-kentän todellinen arvo on `Usage` tai `Period`.

`remaining_amount` voi olla tyhjä; asiakkaan on ensin tarkistettava tyhjä arvo ennen numeerista vertailua. Kiintiön yksikkö määräytyy `service.unit`-kentän mukaan.
