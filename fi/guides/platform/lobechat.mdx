[LobeChat](https://lobehub.com/) on avoimen lähdekoodin AI-asiakasohjelma, joka tukee lisäosia, tietopankkeja ja itseisännöintiä, ja sitä voidaan käyttää verkkoversiona tai ottaa käyttöön Dockerilla. Se tukee mukautettuja OpenAI-yhteensopivia päätepisteitä, joten se voidaan yhdistää Ace Data Cloudiin. Tässä artikkelissa esitellään määritysprosessi.

## Hakuprosessi

Yhdistääksesi Ace Data Cloudin LobeChatiin, siirry ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications), hanki API Tokenisi ja säilytä se varalla.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisen hakemuksen yhteydessä myönnetään ilmaista käyttökiintiötä, joten voit kokeilla Ace Data Cloudin mallipalveluja ilmaiseksi.

## Ace Data Cloudin määrittäminen

Siirry LobeChatin kohtaan **Sovellusasetukset → Kielimallit**, etsi **OpenAI**-kortti ja ota se käyttöön, täytä:

| Kenttä       | Arvo                              | Kuvaus                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | Ace Data Cloud Tokenisi        | Konsolista kopioitu Token               |
| API-välityspalvelimen osoite | `https://api.acedata.cloud/v1` | **Täytyy päättyä `/v1`**           |
| Asiakasohjelman pyyntötila  | Käytössä                             | Suora yhteys selaimesta, Key ei kulje LobeChat-palvelimen kautta |

![LobeChat OpenAI Provider -määritysnäkymä](https://cdn.acedata.cloud/629ef9d3084a.png)

> Kun käytät Chat Completions -rajapintaa, pidä Responses API Specification poissa käytöstä.

LobeChat ei lisää `/v1`-osiota automaattisesti Base URL:ään, vaan pyyntöpolku on suoraan `{API-välityspalvelimen osoite}/chat/completions`:

| API-välityspalvelimen osoite                              | Todellinen pyyntö                                                   | Tulos                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Oikein                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Myös käytettävissä                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai`-kohdassa ei ole `/v1`-polkua) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (`/v1` puuttuu)             |

LobeChat kutsuu oletuksena `/v1/models`-rajapintaa mallien automaattista noutamista varten. Kun Ace Data Cloud palauttaa paljon malleja, käyttöliittymästä voi tulla hyvin pitkä, joten on suositeltavaa täyttää manuaalisesti allow list kohdassa ”Malliluettelo → Mukautetut mallinimet”, englanninkielisillä pilkuilla eroteltuna. Jos tarvitset mukautetun näyttönimen, voit käyttää `=`-merkkiä muodossa `MODEL_ID=näyttönimi`.

## Mallin valitseminen

Malliluettelo päivittyy jatkuvasti. Käytä ensisijaisesti asiakasohjelman automaattisesti lataamaa malliluetteloa; jos sinun on täytettävä tiedot manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models` saadaksesi nykyiset mallitunnukset ja valitse sitten asiakasohjelman tukemien konteksti-, kuva- ja työkalukutsuominaisuuksien mukaan.

## Integraation vahvistaminen

Jos et ole varma, johtuuko ongelma LobeChatista vai verkosta, voit ensin vahvistaa päätepisteen suoraan curlilla (korvaa `{token}` Tokenillasi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI-yhteensopivan `chat.completion`-objektin palautuminen tarkoittaa, että Token ja päätepiste ovat valmiina; jos palautetaan `HTTP 403 used_up`, Token on voimassa mutta saldo ei riitä, ja voit lisätä saldoa [konsolissa](https://platform.acedata.cloud/console/applications).

## Edistynyt: Docker-itseisännöinti

Jos haluat ottaa käyttöön yksityisen version tiimisi käyttöön, voit käynnistää sen yhdellä Docker-komennolla (korvaa `{token}` Tokenillasi):

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

Avaa `http://palvelimesi-IP:3210` ja syötä `ACCESS_CODE` käyttääksesi palvelua; tiimin jäsenten ei tarvitse täyttää omia Key-tietojaan. Yllä käytettyjen ympäristömuuttujien, kuten `OPENAI_API_KEY`, `OPENAI_PROXY_URL` ja `OPENAI_MODEL_LIST`, täydelliset kuvaukset löytyvät [LobeChatin mallipalveluntarjoajien ympäristömuuttujien dokumentaatiosta](https://lobehub.com/docs/self-hosting/environment-variables/model-provider). Jos käytät nginx-käänteistä välityspalvelinta HTTPS:n kanssa, muista ehdottomasti lisätä `proxy_buffering off;`, muuten suoratoistovastaukset puskuroituvat. Lisätietoja käyttöönottotavoista on kohdissa [LobeChatin itseisännöinnin aloitus](https://lobehub.com/docs/self-hosting/start) ja [Docker Compose -käyttöönotto](https://lobehub.com/docs/self-hosting/platform/docker-compose).

## Usein kysytyt kysymykset

### Ilmoitus 404 Not Found

Yleensä API-välityspalvelimen osoitteeksi on kirjoitettu `.../openai/v1` tai `/v1` puuttuu. Muuta se muotoon `https://api.acedata.cloud/v1`.

### Malliluettelo on tyhjä

Ota käyttöön ”Asiakasohjelman pyyntötila” -kytkin; tai täytä mallien allow list manuaalisesti kohdassa ”Mukautetut mallinimet”.

### Ilmoitus 401 Unauthorized

Varmista, että API Key -kenttään on liitetty Ace Data Cloudin Token (ilman `Bearer`-etuliitettä ja ilman ylimääräisiä välilyöntejä) ja että kyseiseen sovellukseen liittyvä saldo on riittävä.
