Ace Data Cloud tarjoaa TypeScript / Python / Go kolmea kieltä varten viralliset asiakassovellusohjelmat (SDK), jotka paketoivat `api.acedata.cloud` -sivustolla olevat chat-completions, kuvat, videot, musiikki, haku, x402 jne. vahvasti tyypitettyihin menetelmiin, säästäen käsin kirjoittamisen HTTP:n, SSE:n, tehtävien kyselyn, virheiden käsittelyn ja uudelleenyrityksen takaisinvetoamisen työstä.

Tämä luku on järjestetty todellisen liittämisjärjestyksen mukaan: ensin saat API-tokenin konsolista, sitten valitset kielen ja katsot vastaavaa lukua, lopuksi katsot tehtävien kyselyä, virtaavaa vastausta ja X402:n ketjussa maksamisen edistyneitä käyttötapoja.

## Varasto ja paketit

- SDK-lähdekoodi (monorepo): [https://github.com/AceDataCloud/SDK](https://github.com/AceDataCloud/SDK)
- TypeScript: [`@acedatacloud/sdk`](https://www.npmjs.com/package/@acedatacloud/sdk)
- Python: [`acedatacloud`](https://pypi.org/project/acedatacloud/)
- Go: [`github.com/AceDataCloud/SDK/go`](https://pkg.go.dev/github.com/AceDataCloud/SDK/go)
- X402-asiakasohjelma (TypeScript): [`@acedatacloud/x402-client`](https://www.npmjs.com/package/@acedatacloud/x402-client)
- X402-asiakasohjelma (Python): [`acedatacloud-x402`](https://pypi.org/project/acedatacloud-x402/)

## Milloin käyttää SDK:ta / MCP:ta / alkuperäistä HTTP:tä / X402:ta

| Skenaario                                          | Suositeltu tapa                                                                   |
| ------------------------------------------- | ---------------------------------------------------------------------- |
| Taustapalvelut, CLI, automaatiaskriptit, Agent-kehykset                     | **SDK** (tämä luku)                                                            |
| Claude Desktop / Cursor / Cline jne. MCP-asiakasohjelman kutsu | MCP-palvelimet                                                            |
| Kertakäyttöinen curl-todennus, virheenkorjaus, upotetut ympäristöt, jotka tukevat vain HTTP:tä              | Alkuperäinen HTTP (kunkin palvelun nopea aloitus)                                                    |
| Ei halua luoda API-tokenia, maksaa USDC:n mukaan kutsuketjussa                  | [X402-integraatio-opas](https://platform.acedata.cloud/documents/x402-integration) |

SDK ja X402 eivät ole toisiaan poissulkevia: SDK tukee sekä "token-polku" että "`paymentHandler`-polkua", katso tarkemmin [SDK + X402 maksukoukku](https://platform.acedata.cloud/documents/sdk-x402-payment).

## API-tokenin hakeminen

Käyttääksesi SDK:ta, sinun on ensin haettava API-token [Ace Data Cloud konsolista - Sovellusluettelo](https://platform.acedata.cloud/console/applications):

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, joka kutsuu sinua rekisteröitymään ja kirjautumaan sisään, ja kirjautumisen jälkeen sinut ohjataan automaattisesti takaisin nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit kokeilla Ace Data Cloudin tarjoamia erilaisia AI-palveluja ilmaiseksi.

Kopioi juuri saamasi token, jota kutsumme alla yhtenäisesti `{token}`.

## Yhtenäiset ympäristömuuttujat

Kolmen kielen SDK:t lukevat automaattisesti saman ympäristömuuttujan `ACEDATACLOUD_API_TOKEN`, suosittelemme `export`-komentoa shellissä, jotta SDK voi poimia sen automaattisesti:

```bash
export ACEDATACLOUD_API_TOKEN={token}
# Valinnainen: oletus https://api.acedata.cloud
# export ACEDATACLOUD_BASE_URL=https://api.acedata.cloud
```

Voit myös välittää sen eksplisiittisesti asiakasohjelman rakentamisen yhteydessä, kolmen kielen vastaavat parametrin nimet ovat:

- TypeScript: `new AceDataCloud({ apiToken: '{token}' })`
- Python: `AceDataCloud(api_token="{token}")`
- Go: `adc.NewClient(adc.WithAPIToken("{token}"))`

> Huomaa: AceDataCloud-projektin varastossa on vakiintunut käytäntö käyttää `ACEDATACLOUD_API_KEY` (tiedostossa `.env` / CI), mutta nämä kolme SDK:t tunnistavat vain `ACEDATACLOUD_API_TOKEN`. Jos ympäristössäsi on vain `ACEDATACLOUD_API_KEY`, muista välittää se eksplisiittisesti rakentamisen yhteydessä.

## 30 sekunnin esimerkit

Alla olevat kolme koodilohkoa tekevät samaa asiaa: kutsuvat `gpt-4o-mini`:a ja pyytävät sitä vastaamaan vain `ADC_*_OK`. Jokaisen lohkon mukana on **todellinen suorituskyky**, jonka voit toistaa omalla tokenillasi.

### TypeScript

```ts
import { AceDataCloud } from '@acedatacloud/sdk';

const client = new AceDataCloud({ apiToken: process.env.ACEDATACLOUD_API_KEY });

const t0 = Date.now();
const res = await client.openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'Reply with exactly: ADC_TS_SDK_OK' }],
  max_tokens: 20,
  temperature: 0
});
console.log('elapsed_ms', Date.now() - t0);
console.log('id', res.id);
console.log('model', res.model);
console.log('content', res.choices[0].message.content);
console.log('usage', JSON.stringify(res.usage));
```

> SDK ilmoittaa tällä hetkellä vastauksen `Record<string, unknown>`-tyyppinä, mutta ajonaikaisesti se on tavallinen JSON-objekti, johon voi suoraan viitata kenttien mukaan. Tiukoissa TS-projekteissa, jos kohtaat tyyppivirheitä, voit väliaikaisesti käyttää `as any`, tai viitata [SDK:n tehtävien kyselyyn ja virtaaviin vastauksiin](https://platform.acedata.cloud/documents/sdk-tasks-and-streaming) mukautettuun tyypitettyyn wrapperiin.

Ohjelman suorituskyky:

```text
elapsed_ms 2543
id chatcmpl-DldCcLvkTFaioST8e6SjOl0wJScQA
model gpt-4o-mini
content ADC_TS_SDK_OK
usage {"prompt_tokens":16,"completion_tokens":6,"total_tokens":22}
```

### Python
```python
import os, time, json
from acedatacloud import AceDataCloud

client = AceDataCloud(api_token=os.environ["ACEDATACLOUD_API_KEY"])

t0 = time.time()
res = client.openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Vastaa tarkalleen: ADC_PY_SDK_OK"}],
    max_tokens=20,
    temperature=0,
)
print("elapsed_ms", int((time.time() - t0) * 1000))
print("id", res["id"])
print("model", res["model"])
print("content", res["choices"][0]["message"]["content"])
print("usage", json.dumps({k: v for k, v in res["usage"].items()
                            if k in ("prompt_tokens","completion_tokens","total_tokens")}))
```

> Python SDK palauttaa tällä hetkellä `dict`, joten käytä `res["id"]` eikä `res.id`. Tämä eroaa `openai-python`-kirjastosta, joten siirryttäessä on syytä kiinnittää huomiota.

Ohjelman tulos:

```text
elapsed_ms 2963
id chatcmpl-DldFdnIlhSUXINpupgsUmZL78MnBu
model gpt-4o-mini
content ADC_PY_SDK_OK
usage {"prompt_tokens": 17, "completion_tokens": 7, "total_tokens": 24}
```

### Go

```go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    adc "github.com/AceDataCloud/SDK/go"
)

func main() {
    client, err := adc.NewClient(adc.WithAPIToken(os.Getenv("ACEDATACLOUD_API_KEY")))
    if err != nil {
        panic(err)
    }
    ctx, cancel := context.WithTimeout(context.Background(), 60*time.Second)
    defer cancel()

    t0 := time.Now()
    res, err := client.OpenAI().Chat().Completions().Create(ctx, adc.ChatCompletionRequest{
        Model:     "gpt-4o-mini",
        Messages:  []map[string]any{{"role": "user", "content": "Vastaa tarkalleen: ADC_GO_SDK_OK"}},
        MaxTokens: 20,
    })
    if err != nil {
        panic(err)
    }
    fmt.Println("elapsed_ms", time.Since(t0).Milliseconds())
    fmt.Println("id", res["id"])
    fmt.Println("model", res["model"])
    choices := res["choices"].([]any)
    msg := choices[0].(map[string]any)["message"].(map[string]any)
    fmt.Println("content", msg["content"])
    usage := res["usage"].(map[string]any)
    fmt.Printf("usage prompt=%v completion=%v total=%v\n",
        usage["prompt_tokens"], usage["completion_tokens"], usage["total_tokens"])
}
```

> Go SDK:n vastaus on aina `map[string]any`, ei ole vahvasti tyypitettyä structia, joten tyypin väittämistä on tehtävä itse. Kaikki resurssin käyttöliittymät ovat menetelmäketjuja: `client.OpenAI().Chat().Completions().Create(...)`.

Ohjelman tulos:

```text
elapsed_ms 6436
id chatcmpl-89DHExvFvBc4ciIPfolZYUOy7ivxv
model gpt-4o-mini
content ADC_GO_SDK_OK
usage prompt=16 completion=5 total=21
```

Kolmen kielen vastauksissa `id`, `elapsed_ms`, `usage` ovat peräisin samasta lähteestä: PlatformGateway-todennus → kohde OpenAI-yhteensopiva API → laskutustietojen kirjoittaminen. `content`-kenttä on mallin todellinen tuotos, ja kiinteä tunnus `ADC_*_OK` on tarkoitettu todistamaan, että vastausta ei ole muokattu SDK:lla.
