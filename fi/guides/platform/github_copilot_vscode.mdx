GitHub Copilotin virallinen BYOK-dokumentaatio listaa VS Code:n tuettuna paikallisena asiakasohjelmana ja tukee OpenAI-yhteensopivia tarjoajia. VS Code -version, yrityspolitiikan ja mallin näkyvyyden vaikutus lopulliseen päätepisteeseen; ensimmäisellä liittämisellä tarkista todellinen pyyntö alla.

## Konfigurointialue

1. Varmista, että GitHub Copilot -tilisi tai organisaatiosi on ottanut käyttöön BYOK/Räätälöidyt mallit -toiminnon.
2. Lisää VS Code:n Copilot-mallinhallintaan OpenAI-yhteensopiva tarjoaja.
3. Täytä Base URL:ksi `https://api.acedata.cloud/v1`.
4. Täytä API Key:ksi Ace Data Cloud API Tokenisi.
5. Täytä Model:ksi tarkka mallin ID, joka on yhteensopiva valitun protokollan kanssa.
6. Lähetä Copilot Chatissa `Reply only OK`, ja testaa sitten uudelleen pyyntö, jossa on työtilan konteksti.

## Nykyiset rajat

- Copilot-sovellus, CLI, GitHub Desktop, Enterprise BYOK ja VS Code:n konfigurointisopimus ovat erilaisia, eikä tätä opasta voi suoraan soveltaa muihin asiakasohjelmiin VS Code:ssa.
- Organisaatiopolitiikka voi estää henkilöitä lisäämästä tarjoajia tai malleja.
- Tab completion, Chat, Agent ja taustatehtävät voivat käyttää eri mallipolkuja, ja ne on vahvistettava erikseen.
