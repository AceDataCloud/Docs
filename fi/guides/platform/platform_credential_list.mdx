Luettele liiketoiminta-API-tunnistetiedot sivutettuna. Tämä vastaus sisältää tällä hetkellä Token- tai Identity-tunnistetietojen arkaluonteisia kenttiä, ja niitä on käsiteltävä vain palvelinpuolella; niiden kirjoittaminen lokeihin, analytiikka-alustoille, käyttöliittymän pysyvään tallennukseen tai julkisiin tietovarastoihin on kielletty.

## Valmistelut

Luo [Account Token](https://platform.acedata.cloud/documents/platform-token) ja hae nykyisen tilin UUID käyttämällä `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='tilisi tunniste'
export USER_ID='tilisi UUID'
```

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                   |
| --- | ---------------------------------------------------- |
| Menetelmä  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| Todennus  | Account Token, OAuth token tarvitsee `credentials:read`       |
| Sivutus  | `count` + `items`                                    |

Tavallisten käyttäjien tulee välittää oma `user_id`-arvonsa tai valtuutettu `application_id`, muutoin sivutus voi palauttaa `403`-virheen kohdatessaan kohteita, joihin ei ole käyttöoikeutta.

## Kyselyparametrit

| Parametri                 | Tyyppi      | Pakollinen  | Kuvaus                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | tilanteesta riippuen | Tunnistetietojen haltija; tukee toistuvia parametreja                   |
| `application_id`   | UUID    | Ei   | Suodata Applicationin mukaan; tukee toistuvia parametreja        |
| `host`             | string  | Ei   | Suodata tarkasti hostin mukaan; tukee toistuvia parametreja             |
| `name`             | string  | Ei   | Suodata tarkasti nimen mukaan; tukee toistuvia parametreja                 |
| `granted`          | boolean | Ei   | `true` tarkoittaa muille myönnettyjä tunnistetietoja, `false` omaan käyttöön tarkoitettuja tunnistetietoja |
| `limit` / `offset` | integer | Ei   | Sivutus                             |
| `ordering`         | string  | Ei   | `created_at` tai `-created_at`   |

`service_id`, `disabled` ja `expired` eivät tällä hetkellä ole suodatusparametreja.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Vastauksen kuvaus

Tuotannossa vahvistettu vastaus on `{count, items}`. Kukin kohde sisältää `id`-, `application_id`-, `application`-, `user_id`-, `creator_id`-, `name`-, `type`-, `limited_amount`-, `used_amount`-, `expired_at`-, `allowed_api_ids`-, `host`-, `granted`-, `granted_to_user_id`-, `tags`-, `metadata`- ja aikakentät, ja palauttaa tyypin mukaan `token`- tai `username/password`-arvot.

> Nykyinen luettelovastaus palauttaa täydelliset arkaluonteiset arvot. Älä näytä niitä selaimen konsolissa tai keräysjärjestelmissä, äläkä luota selväkielisten arvojen palauttamiseen luettelon kautta; asiakkaan tulee olla yhteensopiva tulevien peittostrategioiden kanssa.
