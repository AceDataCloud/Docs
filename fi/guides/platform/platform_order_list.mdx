Palauttaa tilin lataustilaukset sivutettuina; soveltuu tilaustunnusten etsimiseen, maksutilan tarkasteluun ja täsmäytykseen.

## Valmistelut

Luo [Account Token](https://platform.acedata.cloud/documents/platform-token) ja hae nykyisen tilin UUID osoitteesta `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='你的账户令牌'
export USER_ID='你的账户 UUID'
```

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                              |
| --- | ----------------------------------------------- |
| Menetelmä  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| Todennus  | Account Token, OAuth-token vaatii oikeuden `orders:read`       |
| Sivutus  | `count` + `items`                               |

Tavallisten käyttäjien on annettava oma `user_id`; muutoin sivutus voi palauttaa `403` kohdatessaan kohteita, joihin ei ole oikeutta.

## Kyselyparametrit

| Parametri                    | Tyyppi       | Pakollinen     | Kuvaus                                                        |
| --------------------- | -------- | ------ | --------------------------------------------------------- |
| `user_id`             | UUID     | Pakollinen tavallisille käyttäjille | Tili, johon tilaus kuuluu; tukee toistuvia parametreja                                             |
| `pay_way`             | string   | Ei      | Suodatetaan maksutavan mukaan; tukee toistuvia tai pilkulla eroteltuja arvoja                                        |
| `state`               | string   | Ei      | Suodatetaan tilan mukaan; tukee toistuvia tai pilkulla eroteltuja arvoja                                          |
| `created_at_from/to`  | datetime | Ei      | Luontiajan aikaväli                                                    |
| `finished_at_from/to` | datetime | Ei      | Valmistumisajan aikaväli                                                    |
| `limit` / `offset`    | integer  | Ei      | Sivutus                                                        |
| `ordering`            | string   | Ei      | `created_at`, `-created_at`, `finished_at` tai `-finished_at` |

Nykyinen luettelo ei tue suodatusta parametreilla `application_id`, `service_id`, `package_id`, `payment_method` tai `tag`; maksutapakentän nimi on `pay_way`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/orders/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'state=Paid,Finished' \
  --data-urlencode 'pay_way=Stripe' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Vastauksen kuvaus

Vastaus on muodossa `{count, items}`. Tuotantoympäristön luettelokohteet sisältävät kentät `id`, `user_id`, `application_id/application_ids`, `package_id/package_ids`, `price`, `amount`, `discount`, `remaining_amount`, `state`, `pay_way`, `pay_id`, `pay_url`, `finished_at`, `expired_at`, `invoice`, `metadata` sekä aikakentät.

- Todelliset tilat ovat `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, `Refunded`; tilaa `Cancelled` ei ole.
- Kenttien nimet ovat `pay_way`, `finished_at`, `discount` ja `price`, eivät `payment_method`, `paid_at`, `discount_rate` tai `final_price`.
- `price` on tilausmerkinnän lopullinen hinta; valuutta ja tilityksen yksityiskohdat voivat sijaita hallituissa metadata-tiedoissa, eikä niitä voi päätellä itse pelkästään maksutavan perusteella.
