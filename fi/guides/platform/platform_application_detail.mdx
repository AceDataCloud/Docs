Hae yksittäisen palveluhakemuksen täydellinen tila Application ID:n avulla — listausrajapintaan verrattuna mukana on lisäkenttiä, kuten täydellinen `service`-objekti (mukaan lukien `packages`-paketit), ja se soveltuu tietosivulle.

> ℹ️ Tämä rajapinta kuuluu **AceDataCloud-alustan hallinta-API:in**, jonka yhtenäinen etuliite on `https://platform.acedata.cloud/api/v1/`. Katso täydellinen rajapintaluettelo kohdasta [AceDataCloud-alustan dokumenttiluettelon hakeminen](https://platform.acedata.cloud/documents/platform-document-list).

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                               |
| --- | --------------------------------------------------------------------- |
| Menetelmä  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| Todennus  | ✅ Tilin tunniste vaaditaan                                                              |

`/applications/{id}` ja `/applications/{id}/` ovat tällä hetkellä molemmat käytettävissä; esimerkeissä käytetään yhtenäisesti muotoa ilman loppukauttaviivaa.

## Todennusohjeet (tilin tunnisteen hankkiminen)

Pyyntöotsikko:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Katso tarkempi hankintatapa kohdasta [AceDataCloud-alustan tilin tunnisteen hallinta](https://platform.acedata.cloud/documents/platform-token).

> ℹ️ Toisin kuin listausrajapinnassa, **tietorajapinnan käyttöoikeustarkistus tehdään suoraan yksittäiselle objektille**, joten `?user_id=`-parametria ei tarvitse välittää. Mutta jos käytät jonkun muun hakemusta, saat virheen `403 permission_denied`.

## Polkuparametrit

| Parametri               | Tyyppi   | Pakollinen  | Kuvaus             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## Pyyntöesimerkit

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## Vastauskenttien kuvaus

Kenttien merkitykset ovat samat kuin [listausrajapinnassa](https://platform.acedata.cloud/documents/platform-application-list), ja lisäksi mukana on:

| Kenttä        | Tyyppi     | Kuvaus                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | Täydellinen palveluobjekti (mukaan lukien `packages`-paketit, `unit` ja `free_amount`), jolla palvelun tietopaneeli voidaan renderöidä suoraan |

## Virheenkäsittely

| HTTP | code                | Merkitys                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | Tilin tunniste puuttuu              |
| 403  | `permission_denied` | Tämä Application ei kuulu sinulle  |
| 404  | `not_found`         | Applicationia ei ole olemassa tai se on poistettu |

## Käytännön vinkit

- **Käytä listaa ensisijaisesti massavalvontaan**: hae Application-luettelo yhdellä kertaa ja arvioi palvelukohtaisten yksiköiden ja kynnysarvojen perusteella välttääksesi yksittäiset tietopyynnöt.
- **Kun haluat tarkastella tunnisteiden määrää**: käytä [API-tunnisteiden luetteloa](https://platform.acedata.cloud/documents/platform-credential-list) ja suodata `application_id`:n mukaan.
- **`disabled=true`-vianmääritysidea**: tarkista tiketit / sähköposti-ilmoitukset nähdäksesi, onko palvelu suljettu riskienhallinnan, maksamattomien laskujen tai sääntöjenvastaisten kutsujen vuoksi; sitä ei voi poistaa käytöstä API:n kautta, vaan sinun on otettava yhteyttä asiakaspalveluun.
