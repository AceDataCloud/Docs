Palauta sivutettuna tämän palvelun tällä hetkellä käytössä olevat ja poistamatta käytöstä olevat API:t Service UUID:n avulla. Jos käytettävissä on vain alias, kutsu ensin [palvelun tiedot](https://platform.acedata.cloud/documents/platform-service-detail) saadaksesi `id`:n.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                              |
| --- | ------------------------------------------------------------------- |
| Menetelmä  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Todennus  | Julkinen, ei vaadi tilitunnusta                                                           |
| Sivutus  | `count` + `items`                                                   |

## Parametrit

| Parametri           | Sijainti    | Pakollinen  | Kuvaus                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Kyllä   | Service UUID, ei tue aliasta           |
| `limit`      | query | Ei   | Kohteiden määrä sivulla, enintään 100                      |
| `offset`     | query | Ei   | Sivutussiirtymä                            |
| `ordering`   | query | Ei   | Django-lajittelulauseke; suositellaan `rank` tai `-rank` |

Nykyinen rajapinta ei tue `stage`-suodatusta; se on jo sulkenut pois `Deprecated`-API:t.

```shell
export SERVICE_ID='Sinun Service ID:si'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Luettelokohteet käyttävät samaa indeksirakennetta kuin [alustan API-luettelo](https://platform.acedata.cloud/documents/platform-api-list), ja sisältävät tällä hetkellä `definition`:n. Kun tarvitset yksittäisen API:n vakaan päätepisteen, jatka kutsumalla `/api/v1/apis/{api_id}`.

## Virheenkäsittely

- Palvelua ei ole olemassa tai se ei näy nykyisellä sivustolla: `404`.
- `service_id`:n on oltava UUID; aliasta ei ratkaista tässä toiminnossa.
