[AnythingLLM](https://anythingllm.com/) on avoimen lähdekoodin asiakasohjelma, jonka painopiste on ”asiakirjat → yksityinen ChatGPT”, ja sen ydinkonsepti on **Workspace** — jokainen Workspace on joukko asiakirjoja, joukko käyttäjiä ja joukko Agent-työkaluja, jotka on eristetty toisistaan itsenäisesti. Se on suunniteltu erityisesti asiakirjakeskusteluja varten ja tarjoaa sekä työpöytäsovelluksen että Docker-muodon. **LLM Provider** -kohdassa se sisältää [OpenAI (Generic)](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic) -vaihtoehdon, johon voi täyttää mukautetun Base URL:n, joten keskustelumallin voi osoittaa suoraan Ace Data Cloudiin. Tässä artikkelissa esitellään määritysprosessi.

## Hakuprosessi

Jotta voit liittää Ace Data Cloudin AnythingLLM:ään, siirry ensin [Ace Data Cloud -konsoliin](https://platform.acedata.cloud/console/applications), hanki API Tokenisi ja säilytä se myöhempää käyttöä varten.

![Ace Data Cloud API Keyn hankkiminen](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaista käyttökiintiötä, jonka avulla voit kokeilla Ace Data Cloudin mallipalveluja maksutta.

## AnythingLLM:n lataaminen

Henkilökohtaiseen käyttöön voit ladata [työpöytäversion](https://anythingllm.com/download), jossa vektorikanta (LanceDB) toimii paikallisesti, asiakirjahaku on täysin offline-tilassa ja yhteys verkkoon muodostetaan vain mallia kutsuttaessa; tiimien monikäyttäjätilanteissa käytä [Docker-asennusta](https://docs.anythingllm.com/installation-docker/overview).

## Keskustelumallin määrittäminen

Käynnistä AnythingLLM ja siirry kohtaan **Settings → LLM Preference**, valitse Provideriksi **OpenAI (Generic)** (älä valitse tavallista OpenAI:ta, sillä se osoittaa kiinteästi kohteeseen `api.openai.com` eikä siinä ole mukautettua Base URL:ää). Katso virallinen dokumentaatio: [OpenAI (Generic) LLM Provider](https://docs.anythingllm.com/setup/llm-configuration/cloud/openai-generic).

| Kenttä                   | Arvo                              | Kuvaus                                       |
| -------------------- | ------------------------------ | ---------------------------------------- |
| Base URL             | `https://api.acedata.cloud/v1` | **Täytyy päättyä `/v1`**                         |
| API Key              | Ace Data Cloud Tokenisi        | Konsolista kopioitu Token                             |
| Selected Model       | Nykyinen malli-ID                        | Käytä ensisijaisesti `/models`-osoitteesta automaattisesti ladattua luetteloa; jos sitä ei palauteta, hae se yllä olevalla tavalla ja täytä manuaalisesti |
| Model context window | Täytä valitun mallin mukaan                        | Lue kontekstin yläraja nykyisestä malliluettelosta, älä kopioi muiden mallien arvoja               |

![AnythingLLM Generic OpenAI -määritysnäkymä](https://cdn.acedata.cloud/a155f5476de7.png)

> Mallin ominaisuudet ja kontekstin yläraja määräytyvät nykyisen malliluettelon mukaan.

Huomaa Base URL:n polkusäännöt:

| Base URL                              | Todellinen pyyntö                                                   | Tulos                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | Oikein                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | Myös käytettävissä                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai`-polun alla ei ole `/v1`-polkua) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 (`/v1` puuttuu)             |

## Embedding-mallin määrittäminen

AnythingLLM:n ydin on RAG, joka tarvitsee upotusmallin asiakirjojen vektorointiin. Sen **Embedding Preference** ja LLM Preference ovat kaksi toisistaan riippumatonta määritysjoukkoa — katso [Embedder-määritysten yleiskatsaus](https://docs.anythingllm.com/setup/embedder-configuration/overview). Sen sisäänrakennettu **AnythingLLM Embedder（Built-in / Native）** toimii suoraan paikallisesti, on käyttövalmis ilman määrityksiä ja on oletusarvoinen sekä suositeltu valinta:

Siirry kohtaan **Settings → Embedding Preference**, pidä Providerina oletusarvoinen **AnythingLLM Embedder**, eikä mitään avaimia tarvitse täyttää. Se suorittaa asiakirjojen vektoroinnin paikallisesti, ja sekä alkuperäisteksti että vektorit tallennetaan paikalliseen LanceDB:hen eikä niitä siirretä pilveen.

> AnythingLLM:n Embedder-vaihtoehdot (pilvi: OpenAI / Azure OpenAI / Cohere; paikallinen: Built-in, LM Studio, [LocalAI](https://docs.anythingllm.com/setup/embedder-configuration/local/localai), Ollama) liitetään kukin oman kiinteän muotonsa mukaisesti. Niistä pilvipohjainen OpenAI-upotus osoittaa kiinteästi kohteeseen `api.openai.com` eikä tue mukautettua Base URL:ää; jos haluat käyttää mukautettua päätepistettä, voit käyttää **Generic OpenAI** Embedderiä (jossa on myös Base URL -kenttä ja joka voidaan osoittaa Ace Data Cloudin `text-embedding-3-large`-malliin) tai paikallista **LocalAI** Embedderiä. Tässä artikkelissa keskustelumalli käyttää Ace Data Cloudia, kun taas upotuksiin käytetään AnythingLLM:n omaa paikallista Embedderiä, eivätkä ne vaikuta toisiinsa.

## Mallin valitseminen

Malliluettelo päivittyy jatkuvasti. Käytä ensisijaisesti asiakkaan automaattisesti lataamaa malliluetteloa; jos sinun täytyy täyttää se manuaalisesti, pyydä ensin `GET https://api.acedata.cloud/v1/models` saadaksesi nykyisen malli-ID:n ja valitse sitten asiakkaan tukemien konteksti-, kuva- ja työkalukutsuominaisuuksien mukaan.

## Integraation vahvistaminen

Jos et ole varma, onko ongelma AnythingLLM:ssä vai verkossa, voit ensin vahvistaa päätepisteen suoraan curlilla (korvaa `{token}` Tokenillasi):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI-yhteensopivan `chat.completion`-objektin palautuminen tarkoittaa, että sekä Token että päätepiste ovat valmiina; jos palautuu `HTTP 403 used_up`, Token on kelvollinen mutta saldo ei riitä, joten lisää saldoa [konsolissa](https://platform.acedata.cloud/console/applications).

## Edistynyt käyttö: Workspace ja asiakirjakeskustelu

Luo uusi Workspace ja lataa PDF-, Word-, Markdown- tai muita asiakirjoja, jolloin AnythingLLM pilkkoo ne kappaleisiin, luo vektorit paikallisella Embedderillä ja tallentaa ne paikalliseen LanceDB:hen. Keskustelun aikana se hakee ensin asiaankuuluvat katkelmat ja antaa sitten katkelmat sekä kysymyksesi yhdessä keskustelumallille (eli Ace Data Cloudille) vastattavaksi, ja merkitsee viitelähteet vastauksen alle. Jokaisen Workspacen yläreunassa voi vaihtaa **Query**-tilan (vastaa vain asiakirjojen perusteella) ja **Chat**-tilan (yhdistää yleistä tietoa) välillä; vakavissa käyttötapauksissa Query-tilaa suositellaan hallusinaatioiden välttämiseksi. Docker-asennuksessa voit esiasettaa saman keskustallimallin integraation ympäristömuuttujilla, kuten `GENERIC_OPEN_AI_BASE_PATH`, `GENERIC_OPEN_AI_API_KEY`, `GENERIC_OPEN_AI_MODEL_PREF`, ja ottaa käyttöön monikäyttäjätilan.

## Usein kysytyt kysymykset

### Ilmoitus 404 / connection fail

Yleensä Base URL on kirjoitettu muodossa `.../openai/v1` tai siitä puuttuu `/v1`. Muuta se muotoon `https://api.acedata.cloud/v1`.

### Asiakirjan lataamisen jälkeen ei voi keskustella

Varmista, että kohdassa **Settings → Embedding Preference** on valittuna käytettävissä oleva Embedder (oletusarvoinen AnythingLLM Embedder toimii paikallisesti ilman lisämäärityksiä), ja lataa asiakirja uudelleen vektorien luomiseksi.

### Ilmoitus 401 Unauthorized
Varmista, että API Key -kenttään on liitetty Ace Data Cloudin Token (ilman `Bearer`-etuliitettä ja ilman ylimääräisiä välilyöntejä) ja että kyseiseen sovellukseen liittyvä saldo on riittävä.

### Ladataanko paikalliset asiakirjat pilveen

Ei. Asiakirjojen alkuperäistekstit tallennetaan paikalliseen LanceDB:hen, ja mallille lähetetään vain haussa löytyneet katkelmat sekä kysymyksesi.
