Poista API-tunniste pysyvästi. Poistamisen jälkeen sitä **ei voi palauttaa välittömästi**, ja kaikki tätä Tokenia käyttävät liiketoimintarajapinnat saavat heti vastauksen `401`.

> ℹ️ Tämä rajapinta kuuluu **AceDataCloud-alustan hallinta-APIin**, jonka yhtenäinen etuliite on `https://platform.acedata.cloud/api/v1/`.

## Rajapinnan yleiskatsaus

| Kohta   | Sisältö                                                                  |
| --- | ------------------------------------------------------------------- |
| Menetelmä  | `DELETE`                                                            |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}` |
| Todennus  | ✅ Edellyttää tilitunnistetta                                                            |

`/credentials/{id}` ja `/credentials/{id}/` ovat tällä hetkellä molemmat käytettävissä; esimerkeissä käytetään yhtenäisesti muotoa ilman loppukauttaviivaa.

## Todennusohjeet (miten tilitunniste hankitaan)

Pyyntöotsikko:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

Hankintatapa on kuvattu kohdassa [AceDataCloud-alustan tilitunnisteen hallinta](https://platform.acedata.cloud/documents/platform-token).

## Polkuparametrit

| Parametri              | Tyyppi   | Pakollinen  | Kuvaus        |
| --------------- | ---- | --- | --------- |
| `credential_id` | UUID | ✅   | Poistettavan tunnisteen ID |

## Pyyntöesimerkit

### cURL

```shell
curl -X DELETE 'https://platform.acedata.cloud/api/v1/credentials/df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

cred_id = "df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6"
resp = requests.delete(
    f"https://platform.acedata.cloud/api/v1/credentials/{cred_id}",
    headers={"authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    timeout=10,
)
assert resp.status_code == 204, resp.text
print("✅ 已删除")
```

### Node.js

```javascript
const credId = 'df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6'
const r = await fetch(`https://platform.acedata.cloud/api/v1/credentials/${credId}`, {
  method: 'DELETE',
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log('status:', r.status) // 204
```

## Vastaus

- **Onnistuminen**: `HTTP 204 No Content`, **ei vastausrunkoa**.
- **Epäonnistuminen**: palauttaa virhe-JSONin, katso alla oleva taulukko.

## Virheenkäsittely

| HTTP | code                | Merkitys         |
| ---- | ------------------- | ---------- |
| 401  | `not_authenticated` | Tilitunniste puuttuu     |
| 403  | `permission_denied` | Tunniste ei kuulu sinulle    |
| 404  | `not_found`         | Tunnistetta ei ole olemassa tai se on jo poistettu |

## Käytännön vinkit

- **Poistamista ei voi peruuttaa** — alusta ei säilytä Token-kopioita. Jos epäilet vain vuotoa mutta haluat säilyttää seurantatiedot, käytä [AceDataCloud-alustan API-tunnisteen kiertoa](https://platform.acedata.cloud/documents/platform-credential-rotate) poistamisen sijaan.
- **Poistaminen ei palauta tunnisteen jo kuluttamaa käyttökiintiötä**. Application-saldo vähennetään reaaliaikaisesti kulutuksen mukaan, eikä tunnisteen poistaminen vaikuta saldokirjanpitoon.
- Poistamisen jälkeen voit vahvistaa jäljellä olevat tunnisteet uudelleen `application_id`:n perusteella [API-tunnisteluettelon](https://platform.acedata.cloud/documents/platform-credential-list) kautta.
- **Tarkista kutsujat ennen joukkosiivousta**: luettelossa ei tällä hetkellä ole viimeisen käyttöajan kenttää; varmista käyttöönottoasetusten ja kutsulokien avulla, ettei tunnistetta enää käytetä, ja poista ne sitten yksitellen.
