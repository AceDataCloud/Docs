SUNO sallii meidän syöttää kehotussanoja parantaaksemme kappaleen tyyliä. Tämä asiakirja selittää liittymismenetelmät liittyvään API:in.

Tässä API:ssa on vain yksi syöttöparametri, joka on `prompt`, se on tyyliin liittyvä kehotussana, jota on tarkoitus optimoida.

Tässä syötämme `prompt`-arvoksi `A song for Christmas`.

```python
import requests

url = "https://api.acedata.cloud/suno/style"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A song for Christmas"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Tulokset ovat seuraavat:

```json
{
  "success": true,
  "task_id": "8e887548-7185-48a9-b7cb-e51754f7b87b",
  "trace_id": "ac4ec363-4245-400b-9643-0b6fed8c6b20",
  "data": {
    "upsampled_tags": "Kirkkaat, juhlavat kelloäänet ja raikas akustinen kitara avaa, kun taas reki-kellot ja lämmin pystypiano täyttävät säkeistön. Runsaat jouset tulevat esiin esikohdassa, johtuen kohoavaan täysbändikohokseen, jota korostavat vaskisoittimet. Silta pehmenee glockenspielin myötä, ja palaa sitten riemukkaaseen finaaliin."
  }
}
```

Voimme nähdä, että `data`-kentän `upsampled_tags` on tyyliparametri, joka on optimoitu kehotussanan perusteella.
