Suno MP3 URL API luo olemassa olevalle musiikille toistettavan osoitteen, joka päättyy `.mp3`, ja se soveltuu tilanteisiin, joissa vanhat latauslinkit ovat voimassa, mobiililaitteilla toistaminen tai julkisen äänen URL-osoitteen uudelleen hankkiminen on tarpeen.

Pakollinen parametri `audio_id` on Suno-äänigenerointirajapinnan palauttama äänen ID. Jokaisella kutsulla luodaan itsenäinen MP3 URL -tehtävä, joka ei muokkaa alkuperäistä musiikintehtävää eikä muuta alkuperäistä äänen ID:tä.

## Synkroninen kutsu

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

Onnistuneessa tapauksessa `data[0].file_url` on toistettava äänen osoite. Rajapinta tallentaa ensisijaisesti osoitteeseen `https://cdn.acedata.cloud/suno/{audio_id}.mp3`; jos pysyvä tallennus epäonnistuu, se palauttaa nykyisen käytettävissä olevan alkuperäisen median osoitteen.

## Asynkroninen kutsu

Jos käsittelyaika on pitkä, voit siirtää `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Sen jälkeen voit kysyä `/suno/tasks` -osoitteesta `export_task_id`. Voit myös antaa `callback_url`, johon saat lopulliset tulokset tehtävän valmistuttua. Synkroninen vastaus, tehtävän kysely ja palautus käyttävät samaa lopullista tietorakennetta.

## Huomioitavaa

- `audio_id` on oltava peräisin tunnistettavasta Suno-äänestä.
- MP3 URL -tehtävät ovat itsenäisiä alkuperäisistä musiikintehtävistä.
- Pysyvä tallennus epäonnistuminen ei estä tulosta, vaan se palautuu alkuperäiseen mediaosoitteeseen; lataa se ajoissa.
- Suositellaan, että liiketoimintapuoli lataa tulokset heti ja tallentaa ne oman tietojen säilytysohjeensa mukaisesti.
