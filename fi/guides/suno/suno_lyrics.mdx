---
title: "Suno laulujen generointi API:n liittämisohjeet"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Jos haluat mukauttaa laulujen generointia, mutta et halua itse kirjoittaa sanoituksia, voit käyttää AceDataCloudin tarjoamaa laulujen generointi API:a luodaksesi sanoituksia promptin avulla. API on [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Tämän API:n pääasiallinen syöttöparametri on `prompt`, valinnainen `model` (valinnat `default`, `remi-v1`, oletusarvo `default`), täyttöesimerkki on seuraava:

![](https://cdn.acedata.cloud/p53wtj.png)

Tässä syötämme `prompt`-arvoksi `A song about winter`, joka tuottaa talveen liittyvän laulun.

Klikkaa suorita, tulos on seuraava:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nLumihelmiä putoaa taivaalta\nTalven kylmä kosketus\nOi kuinka se saa minut korkealle\nKäärin itseni kerroksiin\nOi niin mukavaa\nAstun ulos ja tunnen pakkasen nenässäni\n\n[Chorus]\nOi\nTalven kylmä kosketus\nSe on vuodenaika, josta pidän niin paljon\nLumipyry tuo niin jumalallisen tunteen\nTalven kylmä kosketus\nSe on taianomainen aika",
      "title": "Talven Kylmä Kosketus",
      "status": "complete",
      "tags": ["unelmoiva, pehmeä, balladi"]
    },
    {
      "text": "[Verse]\nMaailma on peitetty valkoiseen peittoon\nJäätiköt roikkuvat\nKimaltelevat niin kirkkaasti\nKylmä ilma täyttää keuhkoni jokaisella hengityksellä\nKävelen lumessa\nJättäen jalanjälkiä taakseni\n\n[Chorus]\nTalven ihmemaa\nKaikki on niin kirkasta\nTalven ihmemaa\nPidä minua läpi yön",
      "title": "Talven Ihmemaa",
      "status": "complete",
      "tags": ["unelmapop, pehmeä, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Voimme nähdä, että `data` on taulukko, joka palauttaa useita sanoitusehdokkaita kerralla, joissa jokaisen elementin `text`-kenttä on sanoitusten sisältö, `title` on otsikko, ja `tags` on suositellut musiikkityylitunnisteet.

Kun meillä on sanoitukset, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/suno-audios) mukautetun laulun luomiseen.
