Jos haluat mukauttaa laulujen luomista, mutta et halua itse kirjoittaa sanoituksia, voit käyttää AceDataCloudin tarjoamaa laulujen generointi API:a luodaksesi sanoituksia promptin avulla. API on [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Tämän API:n pääasiallinen syöttöparametri on `prompt`, valinnainen `model` (oletusarvo chirp-v3), esimerkkitäyttö alla:

![](https://cdn.acedata.cloud/p53wtj.png)

Tässä syötämme `prompt`-arvoksi `A song about winter`, joka luo talveen liittyvän laulun.

Klikkaa suorita, tulos on seuraava:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\nLumihelmiä putoaa taivaalta\nTalven kylmä kosketus\nOi kuinka se saa minut korkealle\nKäärin itseni kerroksiin\nOi niin mukavaa\nAstun ulos ja tunnen pakkasen nenässäni\nNäe\n\n[Verse 2]\nMaailma on peitetty valkoiseen peittoon\nJäätiköt roikkuvat\nKimaltelevat niin kirkkaasti\nKylmä ilma täyttää keuhkoni jokaisella hengityksellä\nKävelen lumessa\nJättäen jalanjälkiä, joita ei jää\n\n[Chorus]\nOi\nTalven kylmä kosketus\nSe on vuodenaika, josta pidän niin paljon\nLumipudotus tuo tunteen niin jumalaiseksi\nTalven kylmä kosketus\nSe on taianomainen aika",
    "title": "Talven Kylmä Kosketus",
    "status": "complete"
  }
}
```

Voimme nähdä, että `data`-kentän `text` on sanoitustieto.

Kun meillä on sanoitukset, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) mukautetun laulun luomiseen.
