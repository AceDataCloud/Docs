title: "Suno-sanoitusten generointi-API:n integrointiohjeet"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Jos haluat mukauttaa kappaleiden generointia, mutta et kuitenkaan erityisemmin halua kirjoittaa sanoituksia itse, voit käyttää AceDataCloudin tarjoamaa sanoitusten generointi-API:a luodaksesi sanoituksia promptin avulla. API on [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Laskutus: Onnistuneen generoinnin jälkeen jokaisen pyynnön vakiomaksu on **0.08 Credits**. Kun yksi pyyntö palauttaa useita sanoitusehdokkaita, laskutus tapahtuu silti vain kerran; sovellettavat kulutusalennukset määräytyvät todellisen laskun mukaan, eikä epäonnistuneista pyynnöistä veloiteta.

Tämän API:n pääasiallinen syöttöparametri on `prompt`, ja valinnainen `model` (valinnaiset arvot `default`, `remi-v1`, oletusarvo `default`), ja täyttöesimerkki on seuraava:

![](https://cdn.acedata.cloud/p53wtj.png)

Tässä syöttämämme `prompt` on `A song about winter`, jolla generoidaan talveen liittyvä kappale.

Napsauta suorita, ja tulos on seuraava:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Voidaan nähdä, että `data` on taulukko, joka palauttaa joka kerta useita sanoitusehdokkaita. Jokaisen elementin `text`-kenttä on sanoitussisältö, `title` on otsikko ja `tags` ovat suositeltuja musiikkityylitunnisteita.

Kun sanoitukset ovat käytettävissä, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/suno-audios) mukautettuun kappaleiden generointiin.
