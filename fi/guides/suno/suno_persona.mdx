---
title: "Suno mukautetun laulajatyylin API-integraatio-ohje"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO antaa meille mahdollisuuden määrittää laulajatyylin jo luoduille kappaleille ja tehdä sitten niiden pohjalta toissijaista luovaa työtä. Tässä dokumentissa selitetään asiaankuuluvan API:n integrointimenetelmä.

`GET /suno/persona` -listakyselyä ja `DELETE /suno/persona` -tietueiden poistamista ei laskuteta, eikä ylimääräistä laskuttamattoman pyynnön otsaketta tarvita. `POST /suno/persona` -luontitoiminto laskutetaan edelleen rajapinnan hinnoittelusääntöjen mukaisesti.

Luontireiteillä, jotka tukevat äänensävykyselyä, voidaan alkuperäistä sovellusta ja kutsujan identiteettiä käyttäen välittää luontituloksen `persona_id` parametrille `POST /suno/availability`. Kun käytettävyys vahvistetaan, palautetaan `data.available=true`. [Äänensävyn käytettävyyskyselyn opas](https://platform.acedata.cloud/documents/suno-availability-integration)

Tässä API:ssa on vain kolme syöteparametria: ensiksi `audio_id`, joka on virallisesti jo onnistuneesti luodun kappaleen ID, ja toiseksi `name` sekä `description`, jotka ovat laulajatyylin nimi ja kuvaus.

Tässä syöttämämme `audio_id` on `https://cdn.acedata.cloud/2qhzs3.png`. Voit viitata kohtaan [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) mukautetun kappaleen luomiseksi, ja lopuksi voit saada `audio_id`:n.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Tulos on seuraava:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Voidaan nähdä, että `data`-objektin `persona_id`-kenttä on luodun laulajatyylin ID.

Kun laulajatyylin ID on saatu, voimme käyttää [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) -rajapintaa mukautetun kappaleen luomiseen. Esimerkiksi välittämällä `artist_consistency` parametrille `action`, samalla kun `audio_id`:lle välitetään ladatun kappaleen ID, on myös ladattava parametri `persona_id`. Tämä arvo on yllä palautettu laulajatyylin ID, ja sen avulla voidaan luoda uusia kappaleita viitteenä olevan laulajatyylin perusteella.
