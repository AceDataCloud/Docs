---
title: "Suno mukautettu laulajan tyyli API -liitäntäohje"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO sallii meidän määrittää laulajan tyylin jo luoduille kappaleille ja tehdä niiden perusteella toissijaisia luomuksia. Tämä asiakirja selittää liittymismenetelmät API:iin.

Tässä API:ssa on vain kolme syöttöparametria, ensinnäkin `audio_id`, joka on jo virallisesti onnistuneesti luodun kappaleen ID, toiseksi `name` ja `description`, jotka ovat laulajan tyylin nimi ja kuvaus.

Syöttämämme `audio_id` on `https://cdn.acedata.cloud/2qhzs3.png`, tätä voidaan käyttää [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) mukautetun kappaleen luomiseen, ja lopuksi saadaan `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Tulokset ovat seuraavat:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Voimme nähdä, että `data`-kentän `persona_id` on luodun laulajan tyylin ID.

Kun meillä on laulajan tyylin ID, voimme käyttää [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) mukautetun kappaleen luomiseen, esimerkiksi `action` syötetään `artist_consistency`, samalla kun `audio_id` syötetään ladatun kappaleen ID, ja meidän on myös ladattava parametri `persona_id`, jonka arvo on yllä palautettu laulajan tyylin ID, jolloin voimme luoda uusia kappaleita viitatun laulajan tyylin mukaan.
