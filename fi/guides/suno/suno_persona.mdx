---
title: "Suno mukautetun laulajatyylin API-integrointiohjeet"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO antaa meidän määrittää laulajatyylin jo generoituun kappaleeseen ja tehdä sen perusteella toissijaista luovaa työtä. Tässä dokumentissa selitetään asiaankuuluvan API:n integrointimenetelmä.

`GET /suno/persona` -listakysely ja `DELETE /suno/persona` -tietueen poisto ovat maksuttomia, eivätkä ne vaadi ylimääräistä maksuttomien pyyntöjen otsaketta. `POST /suno/persona` -luontitoiminto laskutetaan edelleen rajapinnan hinnoittelusääntöjen mukaisesti.

Tällä API:lla on vain kolme syöttöparametria: ensiksi `audio_id`, joka on virallisesti jo onnistuneesti generoidun kappaleen ID, ja toiseksi `name` sekä `description`, jotka ovat eräänlainen laulajatyylin nimi ja kuvaus.

Tässä syöttämämme `audio_id` on `https://cdn.acedata.cloud/2qhzs3.png`. Voit viitata kohtaan [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) mukautetun kappaleen generointia varten, ja lopuksi voit saada `audio_id`:n.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Tulos on seuraava:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Voidaan nähdä, että `data`-kentän `persona_id`-kenttä on generoitu laulajatyylin ID.

Kun laulajatyylin ID on saatu, voimme käyttää [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) -rajapintaa mukautetun kappaleen generointiin. Esimerkiksi välitetään `action`-parametriksi `artist_consistency`, samalla välitetään `audio_id`-parametriksi ladatun kappaleen ID, ja lisäksi on ladattava parametri `persona_id`, jonka arvo on yllä palautettu laulajatyylin ID. Tällöin voidaan generoida uusi kappale viitatun laulajatyylin perusteella.
