`POST /suno/availability` vastaanottaa resurssitunnuksen. Kappaleen tarkistamiseen välitä `audio_id`, äänensävyn tarkistamiseen `persona_id`; toinen niistä on pakollinen. Tarkistus valmistuu synkronisesti, vaatii API-tokenin eikä tällä hetkellä vähennä Creditejä.

## Pyyntö

`audio_id` tulee valmiista kappaletehtävästä, ja sitä voidaan käyttää tarkistukseen ennen jatkamista tai cover-version tekemistä.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

`persona_id` tulee äänensävyn luontituloksesta. Käytä alkuperäistä sovellusta ja kutsujan identiteettiä ja lähetä seuraava pyyntörunko äänensävykyselyjä tukevalla luontireitillä.

```json
{"persona_id":"33333333-3333-4333-8333-333333333333"}
```

## Vastaus

Molemmat pyyntötyypit käyttävät samaa onnistunutta vastausta. `data.id` on tämän kyselyn resurssitunnus.

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

`available: true` tarkoittaa, että tämä tarkistus sai myönteisen näytön. Äänensävyjen osalta tarkistus varmistaa luomisen omistajuuden ja vahvistaa, että siihen liittyvän tilin ilmoitetaan olevan tällä hetkellä verkossa. Todellinen generointitulos määräytyy edelleen generointitehtävän mukaan.

`/suno/voices`-reitillä luodut yksityiset kloonatut äänensävyt riippuvat luovasta tilistä. Kun tämän tilin vahvistetaan olevan tällä hetkellä offline-tilassa, rajapinta palauttaa HTTP 200:n, ja `data` näyttää seuraavalta.

```json
{"id":"33333333-3333-4333-8333-333333333333","available":false}
```

Asiakas voi merkitä tämän äänensävyn tällä hetkellä saatavilla olemattomaksi ja tarkistaa sen myöhemmin uudelleen.

Kun vahvistaminen ei ole mahdollista, palautetaan HTTP 503 ja `availability_unknown`, esimerkiksi kun resurssia ei löydy, vanhasta tietueesta puuttuu luontireitti tai kysely aikakatkaistaan. Julkisia laulajatyylejä voidaan käyttää tilien välillä, ja ne palauttavat myös 503:n, kun luova tili on offline-tilassa. Kappalekyselyt palauttavat edelleen `available: true` vain, kun saatavuus on vahvistettu.

Lähetä jokaisessa pyynnössä vain yksi kelvollinen UUID. Kaikki reitit palauttavat HTTP 400:n pyynnöistä, joissa on kaksi tunnusta tai joista molemmat tunnukset puuttuvat. Vain kappalekyselyjä tukevat reitit palauttavat HTTP 400:n pyynnöistä, jotka sisältävät vain `persona_id`:n. Kun saat HTTP 429:n, vähennä kyselytiheyttä.
