---
title: "Suno-audion saatavuuden tarkistus-API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` etsii `audio_id`:n perusteella myönteistä näyttöä siitä, että ääntä voidaan edelleen käsitellä nykyisellä reitillä. Sitä voidaan kutsua ennen esimerkiksi jatkamista tai cover-version luomista; tulos kuvastaa vain tarkistushetken tilaa eikä takaa, että tietty toiminto onnistuu. Tämä rajapinta palauttaa vastauksen synkronisesti, vaatii API-tokenin eikä tällä hetkellä kuluta krediittejä.

`audio_id` on valmiin Suno-tehtävän palauttama kappaleen tunniste, ei `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Esimerkki onnistuneesta vastauksesta:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Kun tarkistus onnistuu, `data.available` on `true`; jos asiaa ei voida vahvistaa, palautetaan `503 availability_unknown` eikä `false` palauteta. Virheellisessä `audio_id`-muodossa palautetaan 400; myös nopeusrajoitus tai palveluhäiriö palauttaa virhevastauksen. Tila voi silti muuttua tarkistuksen valmistumisen ja varsinaisen toiminnon välillä.
