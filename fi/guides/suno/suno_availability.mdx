---
title: "Suno-audion saatavuuden tarkistus-API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` etsii `audio_id`:n perusteella myönteistä näyttöä siitä, että audiota voidaan jatkokäsitellä nykyisellä reitillä. Sitä voidaan kutsua ennen toimintoja, kuten jatkokirjoittamista ja cover-version luomista; tulos heijastaa vain tarkistushetken tilaa eikä takaa, että jokin tietty toiminto varmasti onnistuu. Tämä rajapinta palauttaa vastauksen synkronisesti, vaatii API-tokenin eikä tällä hetkellä kuluta Creditsejä.

`audio_id` on valmiin Suno-tehtävän palauttama kappaleen ID, ei `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Esimerkki onnistuneesta vastauksesta:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

Kun tarkistus onnistuu, `data.available` voi olla vain `true`. Joidenkin reittien palauttama ”ei verkossa” -tila ei voi todistaa, etteivät myöhemmät toiminnot, kuten jatkokirjoittaminen, voisi onnistua, joten tämä rajapinta palauttaa tilanteissa, joissa vahvistusta ei voida tehdä, arvon `503 availability_unknown` eikä palauta arvoa `false`. Virheellinen `audio_id`-muoto palauttaa 400:n, ja myös nopeusrajoitus tai ylävirran häiriö palauttaa virhevastausen. Tila voi silti muuttua tarkistuksen valmistumisen ja varsinaisen toiminnon välillä.
