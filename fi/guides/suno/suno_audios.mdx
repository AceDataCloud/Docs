Tekoälyn sovellusten yleistyessä erilaiset tekoälyohjelmat ovat vähitellen levinneet laajaan käyttöön. Tekoäly on vähitellen tunkeutunut ihmisten työ- ja elämän eri osa-alueille. Ja tekoälyn kattamia toimialoja on myös yhä enemmän, alkaen alkuperäisestä kirjoittamisesta, lääketieteeseen ja koulutukseen, aina nykyiseen musiikkiin asti.

Suno on ammattimainen ja korkealaatuinen tekoälykappaleiden ja -musiikin luomisalusta, jossa käyttäjän tarvitsee vain syöttää yksinkertaisia tekstikehotteita, ja se voi generoida lauluääntä sisältäviä kappaleita genren tyylin ja sanoitusten perusteella. Tämän tekoälymusiikkigeneraattorin ovat kehittäneet tiimin jäsenet tunnetuista teknologiayrityksistä, kuten Metasta, TikTokista ja Kenskosta, ja tavoitteena on, ettei mitään soitintyökaluja tarvita, jotta kaikki voivat luoda kaunista musiikkia.

> Yllä olevan taulukon `lyric`- ja `style`-rajoitukset ovat mukautetun tilan (`custom` on `true`) ylärajoja. Ei-mukautetussa inspiraatiotilassa (`custom` on `false`) täytetään vain `prompt`, jonka pituuden yläraja on 500 merkkiä (sama kaikissa malleissa).

Suno tukee nyt malleja `chirp-v6`, `chirp-v6-wild` ja `chirp-v6-mini`. `chirp-v6`:n käyttöä suositellaan; vanhat mallinimet ovat edelleen yhteensopivia.

Suno ei kuitenkaan virallisesti tarjoa APIa, mutta AceDataCloud tarjoaa Sunon API-kokonaisuuden, joka simuloi Sunon virallista integrointia ja voi kätevästi ja nopeasti generoida haluttua musiikkia.

## Hakeminen ja käyttö

Jos haluat käyttää Suno Audios Generation APIa, hae ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Tokenisi ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisestä hakemuksesta annetaan ilmainen käyttökiintiö, jolla voi kokeilla maksutta; kun käyttökiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

## Peruskäyttö

Mitä tahansa kappaleita haluatkin, voit syöttää vapaasti tekstinpätkän, esimerkiksi jos haluan generoida joulua käsittelevän kappaleen, voin syöttää `a song for Christmas`, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Tässä voidaan nähdä, että asetimme Request Headers -otsakkeet, mukaan lukien:

- `accept`: missä muodossa haluat vastaanottaa vastaustuloksen, tähän täytetään `application/json`, eli JSON-muoto.
- `authorization`: API-kutsun avain, joka voidaan hakemisen jälkeen valita suoraan pudotusvalikosta.

Lisäksi asetettiin Request Body, mukaan lukien:
- `action`: äänitehtävän tyyppi, oletusarvo on `generate`. Tukee toimintoja, kuten luontia, jatkamista, cover-version tekemistä, yhdistämistä, raitojen erottelua, ääniraidan lisäämistä, määritetyn ääniraidan poimimista, äänitehosteiden luontia ja nopeuden säätämistä, jotka kaikki kutsutaan yhtenäisesti kautta `POST /suno/audios`.
- `prompt`: Sunon virallisen inspiraatiotilan kehote (`custom` on `false`-tilassa voimassa), enintään 500 merkkiä.
- `model`: tämän musiikinluontitehtävän malli. v6-sarja sisältää `chirp-v6`-, `chirp-v6-wild`- ja `chirp-v6-mini`-mallit; vanhat mallinimet ovat edelleen yhteensopivia.
- `max_mode`: tehostettu luontitila. `generate` otetaan käyttöön vain, kun sekä `custom` että `max_mode` ovat `true`, ja hinta on 1.12 Credits; `add_stem` voidaan ottaa käyttöön suoraan, ja hinta on 1.344 Credits. Kun se on poistettu käytöstä tai jätetty pois, hinnat ovat vastaavasti 0.56 ja 0.672 Credits.
- `variety`: luontitulosten monimuotoisuuden voimakkuus, vaihtoehdot ovat `off`, `normal`, `high`, `extra`, `max`. Käytetään vain toiminnoissa `generate` ja `add_stem`; sen välittäminen muille action-arvoille palauttaa 400.
- `lyric`: Sunon virallisen mukautetun tilan sanoitussisältö. `chirp-v3-5` ja `chirp-v4` enintään 3000 merkkiä; `chirp-v4-5` ja uudemmat (mukaan lukien `chirp-v5`, `chirp-v5-5`) enintään 5000 merkkiä.
- `custom`: käytetäänkö mukautettua tilaa, oletusarvo on: `false`.
- `instrumental`: Sunon virallisen inspiraatiotilan instrumentaalimusiikkivaihtoehto.
- `title`: Sunon virallisen mukautetun tilan musiikkikappaleen nimi. `chirp-v3-5`, `chirp-v4` enintään 80 merkkiä; `chirp-v4-5` ja uudemmat enintään 100 merkkiä.
- `style`: Sunon virallisen mukautetun tilan musiikkityyli. `chirp-v3-5` ja `chirp-v4` enintään 200 merkkiä; `chirp-v4-5` ja uudemmat (mukaan lukien `chirp-v5`, `chirp-v5-5`) enintään 1000 merkkiä.
- `negative_tags`: musiikkityylit tai genret, jotka halutaan sulkea pois mukautetussa luonnissa, voidaan käyttää myös toiminnossa `replace_section`. Tälle kentälle ei tällä hetkellä ole asetettu kiinteää merkkimäärärajaa tässä rajapinnassa; liian pitkää sisältöä ei välttämättä silti voida käsitellä, joten kuvaus on suositeltavaa pitää tiiviinä.
- `audio_weight`: äänen tai ääniominaisuuksien vaikutuspaino, alue 0–1, myös `0` on kelvollinen arvo. Voidaan käyttää toiminnoissa, kuten luonti, jatkaminen, cover-version tekeminen, ääniraidan lisääminen ja äänen yhtenäisyys; ilman viiteääntä tai ääniominaisuuksia malli saattaa heikentää tai sivuuttaa tämän arvon.
- `audio_id`: viitemusiikin ID, käytetään jatkotoiminnoissa, kuten cover-version tekemisessä, jatkamisessa ja raitojen erottelussa. Äänitiedosto voidaan edelleen ladata, mutta se ei tarkoita, että tämän ID:n jatkokäsittely olisi aina käytettävissä; jos palautetaan `suno_processing_unavailable`, säilytä `task_id` ja `trace_id` ja ota yhteyttä tukeen.
- `overpainting_start`/`overpainting_end`: alku- ja lopetusaika laulun lisäämiselle olemassa olevaan instrumentaalimusiikkiin, yksikkö sekunteina.
- `underpainting_start`/`underpainting_end`: alku- ja lopetusaika säestyksen lisäämiselle a cappella -lauluun, yksikkö sekunteina.
- `persona_id`: Persona- tai äänenluontirajapinnan kautta saatu ääni-ID, ei kappaleen `audio_id`.
- `continue_at`: jatkamisen raja, yksikkö sekunteina. Esimerkiksi 213.5 tarkoittaa, että seuraavan osuuden luonti aloitetaan kohdasta 3 minuuttia 33.5 sekuntia. `lyric` ja `style` ohjaavat vain rajan jälkeistä uutta sisältöä eivätkä korvaa lähdeäänen rajan edeltäviä sanoituksia tai laulua.
- `style_influence`: tyylin vaikutusvoima mukautetussa tilassa, alue 0–1; mitä suurempi arvo, sitä paremmin tulos yleensä vastaa valittua tyyliä; `0` välitetään kelvollisena arvona.
- `replace_section_end`: korvattavan osuuden lopullinen aika.
- `replace_section_start`: korvattavan osuuden aloitusaika.
- `vocal_gender`: ohjaa nais- ja miesäänen mieltymystä, naisääni `f`, miesääni `m`, voimassa malleissa 4.5 ja uudemmissa; kyseessä on mieltymys, eikä tiukkaa noudattamista taata.
- `weirdness`: erikoisuusaste mukautetussa tilassa, alue 0–1; mitä suurempi arvo, sitä luovempi ja kokeellisempi tulos yleensä on; `0` välitetään kelvollisena arvona.
- `duration`: toivottu kappaleen kesto, yksikkö sekunteina, on oltava kokonaisluku ja arvoalue on 10–360. Tällä hetkellä vain `generate` käyttää tätä parametria, ja tarkka vaikutus riippuu tilasta ja mallista. Se on suuntaa-antava kehote eikä tiukka rajoitus: malli ottaa sen huomioon, mutta tavoitteen saavuttamista ei taata; todellinen valmiin tuotoksen kesto määräytyy vastauksen `duration`-kentän mukaan ja on yleensä toivottua arvoa lyhyempi.

### Ääni-ID:n soveltamisala

`generate`, `cover`, `upload_cover`, `artist_consistency`, `artist_consistency_vox` voivat käyttää `persona_id`:tä. Kahden viimeisen action-arvon on annettava `persona_id`; myös kyseisen Personan luomisessa käytetyn kappaleen `audio_id` voidaan antaa samanaikaisesti.

`extend`, `upload_extend` eivät käytä ylimääräistä `persona_id`:tä. Se, tukevatko `mashup`, `inspo` ääni-ID:tä, riippuu valitusta palvelukanavasta; muiden action-arvojen ei taata soveltavan tätä kenttää, joten käytä sitä kunkin toiminnon ohjeiden mukaisesti. `vocal_gender` on valinnainen sukupuolimieltymys, eikä se voi korvata ääni-ID:tä.

Jatkosisällön luontitoiminnot edellyttävät kelvollista lähde-`audio_id`:tä; `mashup` edellyttää vähintään kahta `mashup_audio_ids`:tä. Jos tarvittavat lähteet tai aikaparametrit puuttuvat, palautetaan HTTP 400.

### Kehittyneiden parametrien soveltamisala
| Parametri                | Arvo                                          | Tuettu action                              | Kuvaus                                |
| ----------------- | ------------------------------------------- | --------------------------------------- | --------------------------------- |
| `weirdness`       | 0-1                                         | Valinnainen                                      | Säätää kokeellisuutta; `0` on kelvollinen arvo; vaikutus riippuu toiminnosta, tilasta ja mallista      |
| `style_influence` | 0-1                                         | Valinnainen                                      | Säätää tyylin noudattamisen taipumusta; `0` on kelvollinen arvo; vaikutus riippuu toiminnosta, tilasta ja mallista   |
| `audio_weight`    | 0-1                                         | Valinnainen                                      | Säätää äänen tai äänipiirteiden vaikutusta; malli saattaa jättää sen huomiotta ilman viitetietoja        |
| `variety`         | `off` / `normal` / `high` / `extra` / `max` | `generate`、`add_stem`                   | Säätää tyylillistä monimuotoisuutta tulosten välillä                       |
| `max_mode`        | boolean                                     | `generate`（edellyttää `custom=true`）、`add_stem` | Parantaa johdonmukaisuutta ja laskutetaan tehostetun tilan mukaan                     |
| `vocal_gender`    | `f` / `m`                                   | Generointitoiminnot, jotka tukevat lauluäänen hallintaa                             | Asetus, jonka tarkkaa noudattamista ei taata                       |
| `duration`        | Kokonaisluku 10-360                                   | `generate`                              | Toivottu kesto; muut actionit eivät tällä hetkellä käytä tätä kenttää, todellinen pituus määräytyy tuloksen mukaan |

Alusta tarkistaa parametrityypit ja arvoalueet, mutta ei hylkää näitä valinnaisia säätöasetuksia pelkästään actionin erilaisuuden vuoksi; tarkka vaikutus määräytyy toiminnon, tilan ja mallin mukaan.

- `lyric_prompt`: prompt sanoitusten luomiseen, tulee voimaan vain, kun `custom` on `true` eikä `lyric`-arvoa ole välitetty.
- `callback_url`: URL, johon tulokset tulee palauttaa.
- `async`: valinnainen; kun asetetaan arvoon `true`, rajapinta palauttaa välittömästi `task_id`-arvon ilman, että `callback_url`-osoitetta tarvitsee antaa, minkä jälkeen tulokset haetaan kyselevällä tavalla vastaavan tehtävien kyselyrajapinnan kautta.

## Mukautettu generointi

Jos haluat mukauttaa sanoitusten generointia, voit syöttää sanoitukset:

Tällöin `lyric`-kenttään voidaan välittää esimerkiksi seuraavanlainen sisältö:
```
[Verse]\nSnowflakes falling all around\nGlistening white\nCovering the ground\nChildren laughing\nFull of delight\nIn this winter wonderland tonight\nSanta's sleigh\nUp in the sky\nRudolph's nose shining bright\nOh my\nHear the jingle bells\nRinging so clear\nBringing joy and holiday cheer\n[Verse 2]\nRoasting chestnuts by the fire's glow\nChristmas lights\nThey twinkle and show\nFamilies gathering with love and cheer\nSpreading warmth to everyone near
```

> Huomaa, että tässä sanoituksissa `\n` on rivinvaihtomerkki. Jos et tiedä, miten sanoituksia luodaan, voit käyttää AceDataCloudin tarjoamaa sanoitusten luonti-APIa luodaksesi sanoituksia promptin avulla. API on [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Seuraavaksi voimme luoda kappaleen mukautetusti sanoitusten, otsikon ja tyylin perusteella määrittämällä seuraavan sisällön:

- lyric: sanoitusteksti
- custom: täytä arvolla `true`, mikä tarkoittaa mukautettua luontia. Tämän parametrin oletusarvo on false, mikä tarkoittaa, että luontiin käytetään `prompt`-parametria.
- title: kappaleen otsikko.
- style: kappaleen tyyli, valinnainen.

Täyttöesimerkki on seuraava:

<p><img src="https://cdn.acedata.cloud/qp3iba.png" width="500" className="m-auto" /></p>

Täyttämisen jälkeen koodi luodaan automaattisesti seuraavasti:

<p><img src="https://cdn.acedata.cloud/o5haei.png" width="500" className="m-auto" /></p>

Vastaava koodi:

```shell
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "prompt": "A song for Christmas",
  "model": "chirp-v4-5",
  "lyric": "[Verse]\\nSnowflakes falling all around\\nGlistening white\\nCovering the ground\\nChildren laughing\\nFull of delight\\nIn this winter wonderland tonight\\nSanta's sleigh\\nUp in the sky\\nRudolph's nose shining bright\\nOh my\\nHear the jingle bells\\nRinging so clear\\nBringing joy and holiday cheer\\n[Verse 2]\\nRoasting chestnuts by the fire's glow\\nChristmas lights\\nThey twinkle and show\\nFamilies gathering with love and cheer\\nSpreading warmth to everyone near",
  "custom": true
}'
```

Testaus on sallittu, ja luotu tulos on samankaltainen.

## Mukautettu laulajatyylin luontitoiminto

Jos haluat käyttää laulajatyyliä kappaleen luomiseen, luo ensin kappale yllä olevan peruskäytön avulla,
ja lopuksi sinun täytyy asettaa tämä kappale laulajatyyliksi. Tämän jälkeen sinun tulee siirtyä [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) -sivulle luodaksesi virallisesti luodun musiikin ID:n `audio_id` perusteella laulajatyylin id-parametrin `persona_id`. Tarkat parametrit ovat seuraavan kuvan mukaiset:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

Täyttämisen jälkeen koodi luodaan automaattisesti seuraavasti:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Napsauta suorita, ja voit huomata, että saat seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "7628b754-4fe7-4e79-bda4-806d0dd8bf6e",
  "data": {
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b"
  }
}
```

Käytämme yllä olevia `audio_id`- ja `persona_id`-arvoja, eli `97efc9f4-0e8d-4b3e-88df-14568fa1b11f` ja `e0d7319e-aa2a-44cb-b00a-916218d7cb0b`, tämänkertaisina esimerkkitietoina. ## Luomisen jatkamistoiminto
Jos haluat jatkaa jo luodun Suno-kappaleen generointia, voit asettaa parametrin `action` arvoksi `extend` ja syöttää jatkettavan kappaleen ID:n. Kappaleen ID saadaan peruskäytön mukaisesti. Edellä olevan perusteella kappaleen ID:nä näkyy tällöin:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Huomaa, että tässä sanoitusten `id` on generoinnin jälkeen kappaleen ID. Jos et tiedä, kuinka kappale generoidaan, voit katsoa edellä olevasta peruskäytöstä, kuinka kappale luodaan.

Jos haluat jatkaa itse lataamasi kappaleen generointia, voit asettaa parametrin `action` arvoksi `upload_extend` ja syöttää jatkettavan mukautetusti ladatun kappaleen ID:n. Kappaleen ID saadaan käyttämällä [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload)-rajapintaa, kuten alla olevassa kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Seuraavaksi on täytettävä jatko-osuuden sanat, ja tyyli voidaan määrittää:

- lyric：käytetään vain `continue_at`-kohdan jälkeen generoitavan uuden osuuden sanoitusten ohjaamiseen, eikä se korvaa lähdeäänen kyseistä ajankohtaa edeltäviä sanoituksia.
- custom：arvo `true` tarkoittaa mukautettua generointia. Tämän parametrin oletusarvo on false, mikä tarkoittaa generointia käyttämällä `prompt`-parametria.
- style：jatko-osuuden kappaleen tyyli, valinnainen.
- continue_at：jatkamisen raja, yksikkönä sekunti. Esimerkiksi 213.5 tarkoittaa, että seuraava osuus generoidaan kohdasta 3 minuuttia 33,5 sekuntia alkaen.

Arvon `continue_at` on oltava suurempi kuin 0 sekä `extend`- että `upload_extend`-toiminnoissa, ja desimaalisekunteja tuetaan, esimerkiksi `30.792`; arvoa ei pyöristetä lähetettäessä.

> `extend`-toimintoa käytetään olemassa olevan kappaleen jatkamiseen, ei koko kappaleen sanoitusten vaihtamiseen. Jos haluat käyttää uusia sanoituksia koko kappaleessa alusta alkaen, käytä `generate`-toimintoa uudelleengenerointiin; jos haluat tehdä uuden tulkinnan olemassa olevaan kappaleeseen viitaten, voit käyttää `cover`-toimintoa. Kun syötät kokonaan uudet sanat, `continue_at`-kohtaa edeltäviä alkuperäisiä sanoituksia ei silti korvata.

Täyttöesimerkki on seuraava:

## Musiikkiversiointi

Kun kappaletta jatketaan alkuperäisen kappaleen pohjalta, palautetun kappaleen tyyli ei välttämättä ole sopiva. - action: sisällöksi `cover`; kun versiointi tehdään mukautetusti ladatulle musiikille, sisällöksi on määritettävä: `upload_cover`.

## Katkelman korvaaminen

`replace_section` luo valitun katkelman uudelleen lähdekappaleen aikavälin perusteella ja liittää tuloksen takaisin alkuperäiseen kappaleeseen. `replace_section_result_mode` on oletusarvoisesti `full_song`, ja se palauttaa 2 kokonaista kappaletta, jotka voidaan toistaa suoraan ilman, että `concat`-toimintoa tarvitsee kutsua uudelleen.

### Kuinka syöte täytetään
- `action`: `replace_section`.
- `audio_id`: Muokattavan kokonaisen kappaleen ID. Kun muokkaat uudelleen, käytä edellisellä kerralla valitun kokonaisen kappaleen `data[].id`:tä, älä `task_id`:tä.
- `model`: Kappaleen generointimalli, esimerkiksi `chirp-v6`.
- `lyric`: Valitulla alueella laulettavat **paikalliset uudet sanat**. Koko kappaleen sanoja ei tarvitse antaa kokonaisen kappaleen saamiseksi.
- `prompt`: Määritä selkeästi tällä kertaa korvattavat paikalliset uudet sanat. Sanoja muutettaessa on suositeltavaa täyttää sama sisältö kuin `lyric`-kenttään, jotta vältetään kahden kentän eri sanojen ilmaiseminen. Olemassa olevia pyyntöjä, joissa annetaan vain paikallinen `lyric` ja jätetään `prompt` pois, voidaan edelleen käyttää, mutta `prompt`:n lisääminen itsessään ei takaa sanojen muuttamisen onnistumista.
- `style`, `negative_tags`: Valinnaiset tyylikuvaukset ja poissuljettavat kohteet; `prompt` ei tässä toiminnossa ole tavallisen kappaleen tekemisen inspiraatiokuvaus.
- `replace_section_start`, `replace_section_end`: Valinnan alku- ja loppuaika tämänkertaisessa lähdekappaleessa, yksikkönä sekunnit ja desimaalit tuettuina. Alku ei saa olla alle 0, lopun on oltava alkua suurempi eikä se saa ylittää lähdekappaleen kestoa.
- `replace_section_result_mode`: `full_song` (oletus) palauttaa 2 kokonaista kappaletta; `candidates` palauttaa 2 vielä yhdistämätöntä korvauskandidaattia.

Älä pidä käyttöä “`lyric`-kentän on oltava korvaamisen jälkeiset täydelliset sanat ja `prompt`-kentän on oltava paikalliset sanat” yleisenä käyttötapana. Täydellisten sanojen syöttäminen voi joissakin tehtävissä tuottaa liian pitkän korvaussisällön, jolloin koko kappale pitenee merkittävästi yhdistämisen jälkeen. Paikallinen syöte ei myöskään takaa kiinteää kestoa tai sanojen noudattamista sanasta sanaan; kyseessä on generatiivinen muokkaus, joten todellinen ääni on tarkistettava.

### Käynnistä tehtävä ja hanki kokonainen kappale

Alla on esimerkki pyyntömuodosta. Korvaa `YOUR_COMPLETED_AUDIO_ID` ja aikaväli omalla lähdekappaleen ID:lläsi ja todellisella valinnallasi; esimerkissä oletetaan, että sekunnit 30–50 vastaavat seuraavia neljää lausetta.

```json
{
  "action": "replace_section",
  "audio_id": "YOUR_COMPLETED_AUDIO_ID",
  "model": "chirp-v6",
  "custom": false,
  "instrumental": false,
  "lyric": "晚风吹过安静的街巷\n绿色风筝停在我身旁\n我们沿着河岸轻轻唱\n把今天的故事放心上",
  "prompt": "晚风吹过安静的街巷\n绿色风筝停在我身旁\n我们沿着河岸轻轻唱\n把今天的故事放心上",
  "replace_section_start": 30.0,
  "replace_section_end": 50.0,
  "replace_section_result_mode": "full_song",
  "async": true

```

Lähettämisen jälkeen käytä palautettua `task_id`:tä kyselyyn `/suno/tasks`, jonka pyyntörunko on `{"action":"retrieve","id":"YOUR_TASK_ID"}`. Kun tehtävä on valmis, hae tehtävävastauksen `response.data`:sta kahden kokonaisen kappaleen `id`, `audio_url` ja `duration`, ja valitse toinen niistä kuuntelun jälkeen. `success: true` tarkoittaa, että tehtävä suoritettiin onnistuneesti, eikä sitä, että uudet sanat on laulettu sanasta sanaan tai että kesto vastaa odotuksia.

### Valinta, tulosten tarkistus ja uudelleenmuokkaus

1. Kuuntele ensin lähdekappale ja määritä sitten valinta `/suno/timing`:n aikatietojen avulla, pyrkien kattamaan kokonaisia musiikkilauseita. Älä valitse aluetta sanoitustaulukon kiinteiden indeksien mukaan, äläkä korvaa muutamalla sanoituslauseella aluetta, joka sisältää enemmän musiikkilauseita, odottaen rytmin pysyvän täysin muuttumattomana.
2. Pyri pitämään uusien sanojen lauseiden määrä, merkkimäärä ja rytmi lähellä valinnan alkuperäistä sisältöä. Vaikka muutettaisiin vain muutamaa merkkiä, kuuntelutarkistus on silti tarpeen, eikä onnistumista voida tämän perusteella taata.
3. Tarkista, lauletaanko kohdealueella uudet sanat, ovatko liitokset ennen ja jälkeen luonnollisia sekä onko koko kappaleen kesto järkevä. `full_song` tarkoittaa, että palautetaan kokonainen kappale, ei sitä, että se olisi samanpituinen kuin alkuperäinen kappale; kun korvattu osio pitenee, jälkipuoli siirtyy vastaavasti myöhemmäksi. `duration`-pyyntöparametria käytetään vain tavallisessa generoinnissa, eikä se voi lukita korvausosion kestoa.
4. Palautettu `lyric` on sanoitusmetatietoa; kokonaisen kappaleen tila yhdistää täydelliset sanat, kun lähdesanoituksen aikatiedot ovat saatavilla, ja se voi olla tyhjä, kun niitä ei voida saada. Se ei ole äänitallennekirjoitus, joten uusien sanojen esiintyminen ei todista, että äänessä on laulettu uudet sanat. Myös aikatasaustiedot on tarkistettava kuuntelun avulla, erityisesti jo muokattujen tuotosten kohdalla.
5. Kun muokkaat uudelleen, käytä valittua **kokonaisen valmiin tuotoksen ID:tä** uutena `audio_id`:nä ja tarkista uudelleen tämän tuotoksen kesto ja valinta. Älä kopioi muokkausta edeltäneitä aikakoordinaatteja, äläkä käytä suoraan viimeksi palautettua koko `lyric`-tekstiä tämänkertaisena paikallisena syötteenä.

Jos tehtävä on valmis, mutta vanhat sanat lauletaan edelleen, sanoja puuttuu tai kappale pitenee merkittävästi, tarkista ensin lähdekappaleen ID, valinta ja paikalliset sanat ja tarkista sitten toinen tulos. Tehtäväkyselyiden tiheyden lisääminen ei muuta jo generoitua sisältöä. Jos ongelma jatkuu, säilytä `task_id`, lähdekappaleen ID, pyyntökentät, valinta ja tulosääni tarkistamisen helpottamiseksi.

### Valinnainen: hae ensin kandidaatit, yhdistä sitten manuaalisesti

Aseta `replace_section_result_mode: "candidates"` vain silloin, kun sinun on valittava korvauskandidaatti itse. Kandidaatit voivat sisältää kontekstia, joten niitä ei voi pitää kokonaisena kappaleena pelkän kandidaatin keston perusteella. Valinnan jälkeen kutsu `concat` käyttämällä kandidaatin `data[].id`:tä ja hae sitten kokonainen valmis tuotos.

Oletusarvoinen `full_song` on jo yhdistetty, joten tätä vaihetta ei tarvitse suorittaa.

## Kappaleen keston hallinta

Oletusarvoisesti mallin generoiman kappaleen keston päättää malli itse, yleensä se on 30 sekunnin ja 4 minuutin välillä. Jos tarvitaan pidempi tai lyhyempi lopputuote, odotettu kesto voidaan määrittää `duration`-parametrilla, jonka yksikkö on sekunti ja arvon on oltava kokonaisluku väliltä 10–360.

Tätä parametria käytetään mukautetun tilan (`custom` on `true`) kappalegenerointiin. Erityisesti on huomattava, että `duration` on **suuntaa-antava vihje, ei sitova rajoitus**: malli ottaa tämän arvon huomioon säveltäessään, mutta ei takaa sen saavuttamista. Käytännön testeissä todellinen kesto on yleensä selvästi odotettua arvoa lyhyempi, ja saman pyynnön palauttamien kahden kappaleen kestot voivat myös erota toisistaan moninkertaisesti. Vaikka pyynnöt olisivat täysin samoja, useista lähetysten tuloksena saadut kestot voivat erota merkittävästi. Siksi sitä ei pidä käyttää tarkkana keston hallintana; jos liiketoiminnassa tarvitaan kiinteä kesto, lopputuote tulee leikata itse tai pyyntö tulee yrittää uudelleen sen saamisen jälkeen.

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

On huomattava, että pyynnön `duration` on **odotettu kesto**, kun taas vastauksen `data`-kohdan kunkin kappaleen `duration`-kenttä on kyseisen kappaleen **todellinen kesto**. Niiden nimet ovat samat, mutta merkitykset eroavat; todellista kestoa ei taata odotetun arvon mukaiseksi. Sanoitusten pituus on yksi lopputuotteen kestoon vaikuttavista päätekijöistä; jos tarvitaan pidempi lopputuote, on suositeltavaa antaa samalla täydellisemmät sanoitukset.

Rajapinta tarkistaa, että `duration` on kokonaisluku väliltä 10–360; se on silti vain generointitavoite, ei lopputuotteen pituustakuu.

- action：sisältö on `remaster`。
- audio_id：uudelleen luotavan kappaleen ID。
- model：tukee vain v4.5+- ja v5-versioita。
- variation_category：tuetaan vain v5- ja uudemmissa versioissa, ja siinä on vain 3 arvoa: high, normal, subtle。

Täyttämisen jälkeen luotu koodi on automaattisesti seuraava:

<p><img src="https://cdn.acedata.cloud/7h4zmw.png" width="500" className="m-auto" /></p>

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "remaster",
    "variation_category": "high",
    "audio_id": "21fd46d4-45c3-4826-bec9-3f3df667902e"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Inspo-inspiraatioluontitoiminto

Inspo-inspiraatioluontitoiminto voi luoda uutta musiikkia 1–4 täydellisen viiteäänen perusteella ja tukee äänitiedostojen vetämistä tai lataamista inspiraation lähteeksi. API käyttää olemassa olevaa `inspo`-toimintoa: asiakas tarjoaa julkisesti saatavilla olevan äänen URL-osoitteen, ja palvelu suorittaa automaattisesti viiteäänen valmistelun ja luomisen ilman, että asiakkaan tarvitsee erikseen lukea sanoituksia, tyyliä tai kestoa ja sitten koota pyyntöä. Se eroaa yllä olevasta alueellisesta näytteistämisestä sekä alkuperäisen kappaleen tyylin jäljittelevästä Coverista. Käytettäessä on täytettävä seuraavat parametrit:

- action: sisällönä `inspo`.
- audio_urls: viiteäänten URL-osoitteiden luettelo; on tarjottava 1–4 julkisesti saatavilla olevaa ääniosoitetta.
- model: käytettävä malli, suositellaan `chirp-v6`.
- prompt: sanoitukset tai luomiskehote (valinnainen).
- instrumental: kun asetuksena on `true`, luodaan instrumentaalimusiikkia koskevan pyynnön mukaisesti ilman sanoituksia.
- persona_id: käytä määritettyä ääntä palvelukanavalla, joka tukee tätä yhdistelmää; viiteääni sidotaan valmisteluvaiheessa kyseisen äänen edellyttämään resurssiympäristöön.
- lyric_prompt: kun `custom=true` eikä `lyric`-arvoa anneta, käytetään sanoitusten automaattiseen luomiseen.

> Huomautus: viiteäänten on oltava julkisesti saatavilla olevia äänitiedostoja. Jos viiteääni vastaa täysin alustalla tunnettua tallennetta, Suno saattaa hylätä luomisen tekijänoikeustarkistuksen vuoksi; suositellaan käyttämään omaa ääntä tai Sunon luomaa ääntä inspiraation lähteenä.

Vastaava Python-koodi:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v6",
    "audio_urls": [
        "https://cdn.acedata.cloud/uploads/a0bc051f-42c2-4a46-aeb4-582dcc884ad2"
    ],
    "prompt": "Rework these references as warm acoustic folk with soft vocals"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynkroninen takaisinsoitto

Koska Sunolla musiikin luomiseen kuluu suhteellisen pitkä aika, noin 1–2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden jatkuvasti auki, mikä johtaa ylimääräiseen järjestelmäresurssien kulutukseen, joten tämä API tarjoaa myös tuen asynkroniselle takaisinsoitolle.

Kokonaisprosessi on seuraava: kun asiakas lähettää pyynnön, se määrittää lisäksi `callback_url`-kentän. Kun asiakas on lähettänyt API-pyynnön, API palauttaa välittömästi tuloksen, joka sisältää `task_id`-kentän tiedot ja edustaa nykyisen tehtävän tunnusta. Kun tehtävä on valmis, musiikin luonnin tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`-osoitteeseen, ja siinä on myös `task_id`-kenttä, jolloin tehtävän tulokset voidaan yhdistää tunnuksen avulla.

Seuraavaksi tutustumme esimerkin avulla siihen, miten tämä tehdään käytännössä.

Ensinnäkin Webhook-takaisinsoitto on palvelu, joka voi vastaanottaa HTTP-pyyntöjä. Kehittäjän tulisi korvata se oman HTTP-palvelimensa URL-osoitteella.
