SUNO antaa meille mahdollisuuden luoda mukautettuja äänirooleja minkä tahansa äänitiedoston avulla ja toteuttaa äänikloonausta musiikin tuottamista varten. Toisin kuin olemassa oleva Persona API (joka käyttää Sunon tuottamaa `audio_id`:tä), tämä API hyväksyy julkisesti saatavilla olevan `audio_url`:n, eli oman ihmisäänitallenteesi. Tässä dokumentissa kerrotaan äänikloonaus-API:n integrointitavasta.

## Ensimmäinen vaihe: Luo äänirooli

Tällä API:lla on kolme syöttöparametria: `audio_url` (pakollinen), joka on julkisesti saatavilla olevan MP3- tai WAV-muotoisen äänitiedoston URL, joka sisältää yhden henkilön selkeän ihmisäänen; sekä `name` ja `description` (valinnaiset), jotka ovat ääniroolin nimi ja kuvaus.

> **Äänitiedoston vaatimukset**
> - Äänimuodon on oltava `WAV` tai `MP3`
> - Äänen keston on oltava `10~240 sekuntia`, ja suositellaan käyttämään `30~60 sekunnin` puhdasta, yhden henkilön kuivaa äänimateriaalia
> - Äänen tulee sisältää **selkeä, tunnistettavissa oleva yhden henkilön puhe- tai lauluääni**
> - Vältä ehdottomasti **taustamelua, säestystä, kaikua, jälkikaiuntaa**; kokonaiset säestykselliset kappaleet eivät yleensä läpäise äänenjälkitarkistusta
> - Älä sisällytä **useita puhujia** tai **useita ihmisääniä**
> - Liian hiljainen äänenvoimakkuus, epäselvä puhe tai liian voimakas melu voivat johtaa **kloonauksen epäonnistumiseen** tai **heikompaan tuotantotulokseen**
> **Käyttörajoitusten kuvaus**
> - Ääntä lataamalla luodut ääniroolit ovat **yksityisiä resursseja**
> - Tämä äänirooli **ei tue uudelleenkäyttöä eri tilien välillä**
> - On suositeltavaa käyttää sitä mahdollisimman pian onnistuneen luonnin jälkeen, sillä pitkä käyttämättömyys voi johtaa **vanhenemiseen tai käytettävyyden menettämiseen**
> - Palautettava `name` luodaan automaattisesti järjestelmän toimesta, käytä palautettavaa `persona_id`:tä ensisijaisena tietona

> **Yritä ensin uudelleen, jos kutsu epäonnistuu**
> Äänikloonaus on laskennallisesti intensiivinen tehtävä, ja vaikka materiaali olisi täysin vaatimusten mukainen, satunnainen epäonnistuminen on tietyllä todennäköisyydellä mahdollista. Tavallisia palautuksia ovat esimerkiksi
> `voices_sound_different` (äänenjälkitarkistus ei läpäisty) jne. **Tällaiset epäonnistumiset eivät liity äänenlaatuun, ja uudelleenyritys samalla materiaalilla onnistuu yleensä**,
> joten integraatiossa suositellaan toteuttamaan 1~2 automaattista uudelleenyritystä epäonnistuneille tuloksille. Epäonnistuneista pyynnöistä ei laskuteta.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Yllä oleva `https://cdn.acedata.cloud/suno_demo.mp3` on suoraan kutsuttava esimerkkimateriaali (MP3, 41 sekuntia, yhden henkilön kuiva ääni).
> Jos tarvitset `WAV`-muotoisen esimerkin, voit käyttää
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekuntia, mono 44,1 kHz).

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Voidaan nähdä, että `data`:n `persona_id`-kenttä on luodun ääniroolin ID. `is_public`-kenttä on aina `false`, koska ääntä lataamalla luodut ääniroolit ovat yksityisiä. Huomaa, että palautettava `name` luodaan automaattisesti järjestelmän toimesta; käytä jatkossa `persona_id`:tä tähän äänirooliin viittaamiseen.

## Toinen vaihe: Käytä ääniroolia musiikin tuottamiseen

Kun ääniroolin ID on saatu, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/suno-audios) musiikin tuottamiseen. Aseta `action` arvoksi `generate` ja `persona_id` yllä palautetuksi ääniroolin ID:ksi, jolloin tuotettu kappale lauletaan kloonatulla äänellä.

> **Huomio:** Äänikloonaus tukee vain malleja `chirp-v4-5` ja sitä uudemmat (kuten `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), eikä tue mallia `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id`:tä voidaan käyttää `generate`-tuotantoon, ja sitä voidaan käyttää myös `cover` / `upload_cover` -cover-versioihin. Ääntä määritettäessä `vocal_gender`:iä ei tarvitse täyttää samanaikaisesti; äänen samankaltaisuus riippuu edelleen vertailumateriaalista ja tuotantotuloksesta.

Tämän rajapinnan kautta luodut äänet ovat yksityisiä resursseja. Ennen olemassa olevan kappaleen cover-version tekemistä kutsu ensin `/suno/upload` ja välitä alkuperäiskappaleen `audio_url` sekä tämän äänen `persona_id`; kun lataus onnistuu, kutsu `/suno/audios`-rajapintaa palautettavalla `data.audio_id`:llä ja samalla `persona_id`:llä:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Äänen luomiseen, alkuperäiskappaleen lataamiseen ja cover-version tekemiseen on käytettävä samaa palvelukanavaa. Älä käytä suoraan uudelleen aiempaa kappale-ID:tä, jota ei ole liitetty tähän yksityiseen ääneen; lisätietoja on kohdassa [Sunon vertailuäänen lataaminen](https://platform.acedata.cloud/documents/suno-upload).
