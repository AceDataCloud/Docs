SUNO sallii mukautetun äänihahmon luomisen millä tahansa äänitiedostolla, mahdollistaen äänikloonauksen musiikin luomista varten. Toisin kuin olemassa oleva Persona API (joka käyttää Sunon luomaa `audio_id`:tä), tämä API hyväksyy julkisesti saatavilla olevan `audio_url`:n, eli oman ihmisäänitallenteesi. Tämä dokumentti selittää äänikloonaus-API:n integrointitavan.

Äänensävykyselyä tukevalla luontireitillä luontituloksen `persona_id` voidaan välittää `POST /suno/availability` -kutsuun alkuperäisellä sovelluksella ja kutsujan identiteetillä. Kun yhdistetty tili on verkossa, palautetaan `data.available=true`; kun sen vahvistetaan olevan offline-tilassa, palautetaan `data.available=false`. [Äänensävyn saatavuuskyselyn opas](https://platform.acedata.cloud/documents/suno-availability-integration)

## Ensimmäinen vaihe: luo äänihahmo

Laskutus: Kun äänihahmon luonti onnistuu, jokaisen pyynnön vakiohinta on **0.15 Credits**. Sovellettavat kulutusedut määräytyvät todellisen laskun mukaan, eikä epäonnistuneista pyynnöistä veloiteta.

Tässä API:ssa on kolme syöttöparametria: `audio_url` (pakollinen), joka on julkisesti saatavilla olevan MP3- tai WAV-muotoisen äänitiedoston URL, joka sisältää yhden henkilön selkeän ihmisäänen; sekä `name` ja `description` (valinnaiset), jotka ovat äänihahmon nimi ja kuvaus.

> **Äänitiedoston vaatimukset**
> - Äänimuodon on oltava `WAV` tai `MP3`
> - Äänen keston on oltava välillä `10~240 sekuntia`; suositellaan käyttämään `30~60 sekunnin` puhdasta yhden henkilön kuivaäänimateriaalia
> - Äänen tulee sisältää**selkeä, tunnistettava yhden henkilön puhe- tai lauluääni**
> - Vältä ehdottomasti**taustamelua, säestystä, kaikua ja jälkikaiuntaa**; säestykselliset kokonaiset kappaleet eivät yleensä läpäise äänijälkitarkistusta
> - Älä sisällytä**useita puhujia**tai**moninkertaisia ihmisääniä**
> - Liian matala äänenvoimakkuus, epäselvä puhe tai liiallinen kohina voivat johtaa**kloonauksen epäonnistumiseen**tai**heikompaan luontitulokseen**
> **Käyttörajoitusten kuvaus**
> - Ladatun äänen avulla luodut äänihahmot ovat**yksityisiä resursseja**
> - Tämä äänihahmo**ei tue uudelleenkäyttöä eri tilien välillä**
> - On suositeltavaa käyttää sitä mahdollisimman pian onnistuneen luonnin jälkeen; pitkä käyttämättömyysaika voi aiheuttaa**vanhenemisen tai käyttökelvottomuuden**
> - Palautettava `name` luodaan automaattisesti järjestelmän toimesta; käytä palautettavaa `persona_id`:tä

> **Käsittele epäonnistumiset selkeän uudelleenyritysmerkinnän mukaisesti**
> Virheobjektin `retryable` on valinnainen boolean-kenttä. Kun `error.retryable` on `true`, se tarkoittaa, että tämän epäonnistumisen jälkeen samaa materiaalia ja samoja parametreja saa käyttää uuteen pyyntöön myöhemmin. Selkeästi käsittelemättömät palvelun ruuhkatilanteet tai jotkin tilapäiset äänijälkitarkistuksen epäonnistumiset voivat sisältää tämän merkinnän; on suositeltavaa käyttää viiveen kasvattamista ja rajoittaa uudelleenyritysten määrää.
> Kun `retryable` on `false` tai kenttä puuttuu, älä lähetä automaattisesti uudelleen pelkästään HTTP 500:n, `busy`-tilan tai virhetekstin perusteella. Muoto-, kesto-, selkeys-, toistuvien tallenteiden- ja sisällönmoderointiongelmat tulee korjata ensin; lähetysten aikakatkaisuissa, yhteyden katkeamisissa tai epäselvissä luontituloksissa alkuperäistä `task_id`:tä tulee ensisijaisesti käyttää tehtävän kyselyyn, jotta vältetään äänensävyn luominen kahdesti. Epäonnistuneista pyynnöistä ei veloiteta, ja onnistuneista uudelleenyrityksistä veloitetaan normaalien sääntöjen mukaisesti.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Yllä oleva `https://cdn.acedata.cloud/suno_demo.mp3` on suoraan kutsuttava esimerkkimateriaali (MP3, 41 sekuntia, yhden henkilön kuiva ääni).
> Jos tarvitset `WAV`-muotoisen esimerkin, voit käyttää
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekuntia, mono 44.1kHz).

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Voidaan nähdä, että `data`:n `persona_id`-kenttä on luodun äänihahmon ID. `is_public`-kenttä on aina `false`, koska ladatun äänen avulla luodut äänihahmot ovat yksityisiä. Huomaa, että palautettava `name` luodaan automaattisesti järjestelmän toimesta; käytä myöhemmin `persona_id`:tä viitataksesi tähän äänihahmoon.

## Toinen vaihe: luo musiikkia äänihahmolla

Kun äänihahmon ID on saatu, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/suno-audios) musiikin luomiseen. Aseta `action` arvoksi `generate` ja `persona_id` yllä palautetuksi äänihahmon ID:ksi, jolloin luotu kappale lauletaan kloonatulla äänellä.

> **Huomautus:** Äänikloonaus tukee vain mallia `chirp-v4-5` ja sitä uudempia malleja (kuten `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), eikä se tue mallia `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id`:tä voidaan käyttää `generate`-luontiin, ja sitä voidaan käyttää myös `cover` / `upload_cover` -cover-versioihin. Ääntä määritettäessä `vocal_gender`:ä ei tarvitse täyttää samanaikaisesti; äänen samankaltaisuus riippuu edelleen vertailumateriaalista ja luontituloksesta.

Tämän rajapinnan kautta luodut äänet ovat yksityisiä resursseja. Ennen olemassa olevan kappaleen cover-version luomista kutsu ensin `/suno/upload`, välitä alkuperäisen kappaleen `audio_url` ja tämän äänen `persona_id`; kun lataus onnistuu, kutsu `/suno/audios` palautetulla `data.audio_id`:llä ja samalla `persona_id`:llä:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<tähän ääneen liittyvän latauksen jälkeen palautettu audio_id>",
  "persona_id": "<äänen luontirajapinnan palauttama persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\nKirjoita laulettavat sanat",
  "async": true
}
```

Äänen luomiseen, alkuperäiskappaleen lataamiseen ja cover-version tekemiseen on käytettävä samaa palvelukanavaa. Älä suoraan käytä uudelleen aiempaa kappaleen ID:tä, jota ei ole liitetty tähän yksityiseen ääneen; lisätietoja on kohdassa [Suno-viiteäänen lataaminen](https://platform.acedata.cloud/documents/suno-upload).
