SUNO mahdollistaa mukautettujen ääniroolien luomisen minkä tahansa äänitiedoston avulla, toteuttaen äänikloonausta musiikin generointia varten. Toisin kuin olemassa oleva Persona API (joka käyttää Sunon generoimaa `audio_id`-tunnistetta), tämä API hyväksyy julkisesti saatavilla olevan `audio_url`-osoitteen, eli oman ääninauhoituksesi. Tässä dokumentissa selitetään äänikloonaus-API:n integrointimenetelmä.

## Vaihe 1: Ääniroolin luominen

Tällä API:lla on kolme syöteparametria: `audio_url` (pakollinen), joka on julkisesti saatavilla olevan MP3- tai WAV-muotoisen äänitiedoston URL-osoite, sisältäen yksiselitteisen yksilön puheen; `name` ja `description` (valinnaiset), jotka ovat ääniroolin nimi ja kuvaus.

**Äänitiedoston vaatimukset:**
- Formaatti: MP3 tai WAV
- Kesto: vähintään 10 sekuntia
- Sisältö: yksiselitteinen puhe, taustamelun tai musiikin määrä mahdollisimman vähäinen

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "http://cos.aitutu.cc/mp4/ru-user-voice.mp3",
  "name": "RU User Voice Test",
  "description": "用户语音录音示例"
}'
```

Tuloksena saadaan:

```json
{
  "success": true,
  "task_id": "b9150e51-d87c-4556-a55e-100947a63bdf",
  "data": {
    "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b",
    "name": "RU User Voice Test",
    "is_public": false
  }
}
```

Huomaa, että `data`-kohdan `persona_id`-kenttä on luodun ääniroolin tunniste. `is_public`-kenttä on aina `false`, koska äänitiedoston lataamisen kautta luodut ääniroolit ovat yksityisiä.

## Vaihe 2: Ääniroolin käyttäminen musiikin generointiin

Kun ääniroolin ID on saatu, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) musiikin generointiin. Aseta `action` arvoksi `generate` ja `persona_id` yllä saaduksi ääniroolin ID:ksi. Generoitu kappale laulaa kloonattua ääntä käyttäen.

> **Huom:** Äänikloonaus tukee vain `chirp-v4-5` ja uudempia malleja (kuten `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), eikä tue `chirp-v4`-mallia.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "e95013f8-eaee-4741-a42f-1d559a9d0b2b"
}'
```

Tuloksena saadaan:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn1.suno.ai/16463960-077c-4700-bbb3-3c7897b943d3.mp3",
      "image_url": "https://cdn2.suno.ai/image_16463960-077c-4700-bbb3-3c7897b943d3.jpeg",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Näet, että generoitu kappale laulaa kloonattua ääntä käyttäen. `persona_id` voidaan myös yhdistää `cover`-toimintoon, jolloin kloonattua ääntä käytetään olemassa olevan kappaleen cover-versiossa.
