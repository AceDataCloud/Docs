---
title: "Suno-äänikloonaus-API:n integrointiohje"

---

SUNO mahdollistaa mukautetun ääniroolin luomisen minkä tahansa äänitiedoston avulla, jolloin äänikloonausta voidaan käyttää musiikin luomiseen. Toisin kuin olemassa oleva Persona API (joka käyttää Sunon luomaa `audio_id`:tä), tämä API hyväksyy julkisesti saatavilla olevan `audio_url`:n, eli oman ihmisäänitallenteesi. Tässä dokumentissa selitetään äänikloonaus-API:n integrointitapa.

## Ensimmäinen vaihe: ääniroolin luominen

Tällä API:lla on kolme syöttöparametria: `audio_url` (pakollinen), joka on julkisesti saatavilla olevan MP3- tai WAV-muotoisen äänitiedoston URL-osoite ja sisältää yhden henkilön selkeän ihmisäänen; `name` ja `description` (valinnaiset), jotka ovat ääniroolin nimi ja kuvaus.

> **Äänitiedostovaatimukset**
> - Äänimuodon tulee olla `WAV` tai `MP3`
> - Äänen keston tulee olla `10~240 sekuntia`, ja on suositeltavaa käyttää `30~60 sekunnin` puhdasta, yhden henkilön kuivaa äänimateriaalia
> - Äänen tulee sisältää**selkeä, tunnistettavissa oleva yhden henkilön puhe- tai laulamisääni**
> - Vältä ehdottomasti**taustamelua, säestystä, kaikua, jälkikaiuntaa**; säestykselliset kokonaiset kappaleet eivät yleensä läpäise äänijälkitarkistusta
> - Älä sisällytä**useita puhujia**tai**useita ihmisääniä**
> - Liian hiljainen äänenvoimakkuus, epäselvä puhe tai liian voimakas kohina voivat johtaa**kloonauksen epäonnistumiseen**tai**heikompaan luontitulokseen**
> **Käyttörajoitusten selitys**
> - Äänen lataamalla luodut ääniroolit ovat**yksityisiä resursseja**
> - Tämä äänirooli**ei tue käyttöä uudelleen eri tilien välillä**
> - On suositeltavaa käyttää sitä pian onnistuneen luomisen jälkeen; pitkä käyttämättömyysaika voi aiheuttaa**vanhenemisen tai käyttökelvottomuuden**
> - Palautettava `name` luodaan automaattisesti järjestelmän toimesta, joten käytä palautettavaa `persona_id`:tä ensisijaisena tunnisteena

> **Yritä ensin uudelleen, jos kutsu epäonnistuu**
> Äänikloonaus on laskennallisesti intensiivinen tehtävä, joten vaikka materiaali olisi täysin vaatimusten mukainen, satunnaisia epäonnistumisia voi esiintyä tietyllä todennäköisyydellä. Yleisiä palautuksia ovat esimerkiksi
> `voices_sound_different` (äänijälkitarkistus ei läpäisty) jne. **Tällaiset epäonnistumiset eivät liity äänenlaatuun, ja uudelleenyritys samalla materiaalilla onnistuu yleensä**,
> joten integroinnissa suositellaan toteuttamaan 1~2 automaattista uudelleenyritystä epäonnistuneille tuloksille. Epäonnistuneista pyynnöistä ei veloiteta.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Edellä oleva `https://cdn.acedata.cloud/suno_demo.mp3` on suoraan kutsuttava esimerkkimateriaali (MP3, 41 sekuntia, yhden henkilön kuiva ääni).
> Jos tarvitset `WAV`-muotoisen esimerkin, voit käyttää
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekuntia, mono 44.1kHz).

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Voidaan nähdä, että `data`-kohdan `persona_id`-kenttä on luodun ääniroolin ID. `is_public`-kenttä on aina `false`, koska äänen lataamalla luodut ääniroolit ovat yksityisiä. Huomaa, että palautettava `name` luodaan automaattisesti järjestelmän toimesta; käytä myöhemmin `persona_id`:tä viitataksesi tähän äänirooliin.

## Toinen vaihe: musiikin luominen ääniroolia käyttämällä

Kun ääniroolin ID on käytettävissä, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/suno-audios) musiikin luomiseen. Aseta `action` arvoon `generate` ja `persona_id` yllä palautetuksi ääniroolin ID:ksi, jolloin luodut kappaleet lauletaan kloonatulla äänellä.

> **Huomautus:** Äänikloonaus tukee vain `chirp-v4-5`- ja sitä uudempia malleja (kuten `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), eikä tue mallia `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Voidaan nähdä, että luotu kappale laulaa kloonatulla äänellä. `persona_id`:tä voidaan käyttää myös yhdessä `cover`-toiminnon kanssa olemassa olevien kappaleiden cover-versioiden laulamiseen kloonatulla äänellä.
