---
title: "Suno äänen kloonaus API:n integrointiohjeet"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO mahdollistaa meille mukautettujen ääniroolien luomisen minkä tahansa äänitiedoston avulla, mahdollistaen äänen kloonauksen musiikin tuottamiseen. Toisin kuin olemassa oleva Persona API (jossa käytetään Sunon luomaa `audio_id`:tä), tämä API hyväksyy julkisesti saatavilla olevan `audio_url`:n, eli oman ihmisen äänen nauhoituksen. Tässä asiakirjassa käsitellään äänen kloonaus API:n integrointimenetelmää.

Tässä API:ssa on kolme syöttöparametria: `audio_url` (pakollinen), joka on julkisesti saatavilla oleva MP3- tai WAV-muotoisen äänitiedoston URL-osoite, jossa on yhden henkilön selkeä ääni; `name` ja `description` (valinnainen), jotka ovat ääniroolin nimi ja kuvaus.

**Äänitiedoston vaatimukset:**

- Muoto: MP3 tai WAV
- Kesto: vähintään 10 sekuntia
- Sisältö: yhden henkilön selkeä ääni, taustamelua tai musiikkia on pyrittävä vähentämään

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

Tulokset ovat seuraavat:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

Voimme nähdä, että `data`:n `persona_id`-kenttä on luodun ääniroolin ID. `is_public`-kenttä on aina `false`, koska äänitiedoston lataamisen kautta luodut ääniroolit ovat yksityisiä.

Kun meillä on ääniroolin ID, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) musiikin tuottamiseen. Aseta `action` arvoksi `vox` ja `persona_id` yllä palautetuksi arvoksi, jolloin luotu kappale esitetään kloonatulla äänellä.
