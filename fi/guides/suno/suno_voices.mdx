SUNO antaa meidän luoda mukautettuja äänihahmoja minkä tahansa äänitiedoston kautta ja toteuttaa äänikloonauksen musiikin luomista varten. Toisin kuin olemassa oleva Persona API (joka käyttää Sunon luomaa `audio_id`:tä), tämä API hyväksyy julkisesti saavutettavan `audio_url`:n eli oman ihmisäänitallenteesi. Tämä dokumentti selittää äänikloonaus-API:n integrointimenetelmän.

## Ensimmäinen vaihe: Luo äänihahmo

Laskutus: Kun äänihahmon luonti onnistuu, kunkin pyynnön vakiomaksu on **0.15 Credits**. Sovellettavat kulutusedut määräytyvät todellisen laskun mukaan, eikä epäonnistuneista pyynnöistä veloiteta.

Tällä API:lla on kolme syöteparametria: `audio_url` (pakollinen), joka on julkisesti saavutettavan MP3- tai WAV-muotoisen äänitiedoston URL-osoite ja sisältää selkeän yhden henkilön ihmisäänen; `name` ja `description` (valinnaiset), jotka ovat äänihahmon nimi ja kuvaus.

> **Äänitiedostovaatimukset**
> - Äänimuodon tulee olla `WAV` tai `MP3`
> - Äänen keston tulee olla `10~240 sekuntia`, ja suositellaan `30~60 sekunnin` puhdasta, yhden henkilön kuivaa äänimateriaalia
> - Äänen tulee sisältää**selkeä, tunnistettavissa oleva yhden henkilön puhe- tai lauluääni**
> - Vältä ehdottomasti**taustamelua, säestystä, kaikua, jälkikaiuntaa**; säestykselliset kokonaiset kappaleet eivät yleensä läpäise äänijälkitarkistusta
> - Älä sisällytä**useita puhujia**tai**useita ääniä**
> - Liian matala äänenvoimakkuus, epäselvä puhe tai liian voimakas kohina voivat johtaa**kloonauksen epäonnistumiseen**tai**heikkoon luontitulokseen**
> **Käyttörajoituksia koskeva selitys**
> - Ladatun äänen kautta luodut äänihahmot ovat**yksityisiä resursseja**
> - Tämä äänihahmo**ei tue uudelleenkäyttöä eri tilien välillä**
> - On suositeltavaa käyttää sitä mahdollisimman pian onnistuneen luonnin jälkeen; pitkä käyttämättömyys voi johtaa**vanhenemiseen tai käytettävyyden menettämiseen**
> - Palautettu `name` luodaan automaattisesti järjestelmän toimesta, käytä palautettua `persona_id`:tä ensisijaisena tunnisteena

> **Yritä ensin uudelleen, kun kutsu epäonnistuu**
> Äänikloonaus on laskennallisesti intensiivinen tehtävä, ja vaikka materiaali olisi täysin vaatimusten mukainen, satunnaisia epäonnistumisia voi esiintyä tietyllä todennäköisyydellä, tavallisia palautuksia ovat esimerkiksi
> `voices_sound_different` (äänijälkitarkistus ei läpäisty) jne. **Tällaisilla epäonnistumisilla ei ole yhteyttä äänenlaatuun, ja uudelleenyritys samalla materiaalilla onnistuu yleensä**,
> integraatiossa suositellaan toteuttamaan 1~2 automaattista uudelleenyritystä epäonnistuneille tuloksille. Epäonnistuneista pyynnöistä ei veloiteta.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Yllä oleva `https://cdn.acedata.cloud/suno_demo.mp3` on suoraan kutsuttava esimerkkimateriaali (MP3, 41 sekuntia, yhden henkilön kuiva ääni).
> Jos tarvitset `WAV`-muotoisen esimerkin, voit käyttää
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekuntia, mono 44.1kHz).

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Voidaan nähdä, että `data`:n `persona_id`-kenttä on luodun äänihahmon ID. `is_public`-kenttä on aina `false`, koska ladatun äänen kautta luodut äänihahmot ovat yksityisiä. Huomaa, että palautettu `name` luodaan automaattisesti järjestelmän toimesta; käytä jatkossa `persona_id`:tä viitatessasi tähän äänihahmoon.

## Toinen vaihe: Luo musiikkia äänihahmoa käyttäen

Kun äänihahmon ID on saatavilla, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/suno-audios) musiikin luomiseen. Aseta `action` arvoksi `generate` ja `persona_id` yllä palautetuksi äänihahmon ID:ksi, jolloin luodut kappaleet lauletaan kloonatulla äänellä.

> **Huomautus:** Äänikloonaus tukee vain malleja `chirp-v4-5` ja sitä uudempia (kuten `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), eikä se tue mallia `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Tulos on seuraava:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id`:tä voidaan käyttää `generate`-luontiin, ja sitä voidaan käyttää myös `cover` / `upload_cover` -coverointiin. Määritettyä ääntä käytettäessä ei tarvitse täyttää samanaikaisesti `vocal_gender`-kenttää; äänen samankaltaisuus riippuu edelleen viitemateriaalista ja luontituloksesta.

Tämän rajapinnan kautta luodut äänet ovat yksityisiä resursseja. Ennen olemassa olevan kappaleen coverointia kutsu ensin `/suno/upload` ja välitä alkuperäisen kappaleen `audio_url` sekä tämän äänen `persona_id`; kun lataus onnistuu, kutsu `/suno/audios`-rajapintaa palautetulla `data.audio_id`:llä ja samalla `persona_id`:llä:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Äänen luomisessa, alkuperäisen kappaleen lataamisessa ja coveroinnissa on käytettävä samaa palvelukanavaa. Älä käytä suoraan uudelleen aiempaa kappale-ID:tä, jota ei ole liitetty tähän yksityiseen ääneen; lisätietoja on kohdassa [Sunon viiteäänen lataaminen](https://platform.acedata.cloud/documents/suno-upload).
