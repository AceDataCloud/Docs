SUNO mahdollistaa mukautettujen äänihahmojen luomisen minkä tahansa äänitiedoston avulla, jolloin äänen kloonaus voidaan hyödyntää musiikin generoinnissa. Toisin kuin olemassa oleva Persona API (joka käyttää Sunon generoimaa `audio_id`-arvoa), tämä API hyväksyy julkisesti saatavilla olevan `audio_url`-osoitteen, eli oman ihmisen äänen tallenteen. Tässä dokumentissa selitetään äänen kloonaus API:n integrointimenetelmä.

## Vaihe 1: Äänihahmon luominen

Tällä API:lla on kolme syöteparametria: `audio_url` (pakollinen), joka on julkisesti saatavilla oleva MP3- tai WAV-muotoisen äänitiedoston URL, sisältäen yhden henkilön selkeän ihmisen äänen; `name` ja `description` (valinnaiset), jotka ovat äänihahmon nimi ja kuvaus.

**Äänitiedoston vaatimukset:**
- Formaatti: MP3 tai WAV
- Kesto: vähintään 10 sekuntia
- Sisältö: yhden henkilön selkeä ihmisen ääni, taustamelun tai musiikin määrä mahdollisimman vähäinen

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Vastaus on seuraava:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Näet, että `data`-kohdan `persona_id`-kenttä on luodun äänihahmon tunniste. `is_public`-kenttä on aina `false`, koska äänitiedoston lataamisen kautta luodut äänihahmot ovat yksityisiä.

## Vaihe 2: Äänihahmon käyttäminen musiikin generointiin

Kun äänihahmon ID on saatu, voimme käyttää [Suno Audios Generation API:a](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) musiikin generointiin. Aseta `action` arvoksi `generate` ja `persona_id` arvoksi edellä saatu äänihahmon ID, jolloin generoidut kappaleet esitetään kloonatulla äänellä.

> **Huom:** Äänen kloonaus tukee vain `chirp-v4-5` ja uudempia malleja (kuten `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), eikä tue `chirp-v4`-mallia.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Vastaus on seuraava:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Näet, että generoidut kappaleet esitetään kloonatulla äänellä. `persona_id` voidaan myös yhdistää `cover`-toimintoon, jolloin voit esittää uudelleen olemassa olevia kappaleita kloonatulla äänellä.
