SUNO mahdollistaa tuotetun musiikin uudelleenkäytön, kuten sanoitusten ja äänen aikajanan hakemisen. Tässä dokumentissa selitetään kyseisen API:n liitäntätapa.

Tällä API:lla on vain yksi syöteparametri, nimeltään `audio_id`, joka on virallisesti tuotetun kappaleen tunniste.

Tässä esimerkissä syötämme `audio_id` arvoksi `ec13e502-d043-4eb2-92ee-e900c6da69d1`.

```python
import requests

url = "https://api.acedata.cloud/suno/timing"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### aligned_words-kentän selitys

Kuten nähdään, `data.aligned_words` on olioiden taulukko, jossa kukin olio edustaa aikaleimallista sanaa tai fraasia.

- `word`: Sanoituksissa esiintyvä sana tai fraasi
- `success`: Boolean-arvo, joka ilmaisee, onnistuiko sanan ajoitus
- `start_s`: Sanan aloitusaika sekunteina
- `end_s`: Sanan lopetusaika sekunteina
- `p_align`: Kohdistuksen todennäköisyys tai luottamusaste, arvo välillä 0–1
