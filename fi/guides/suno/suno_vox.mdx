SUNO mahdollistaa uuden Persona-v2-vox-version luomisen: laulajatyylin. Toisin kuin vanhassa versiossa, tässä on ensin haettava `vox_audio_id`. Tämä dokumentti selittää uuden Persona-v2-vox-version luomisen integraatiomenetelmän.

Ensiksi on käytettävä tätä APIa `vox_audio_id`-parametrin arvon hakemiseen. Tähän APIin voidaan syöttää useita syöteparametreja, kuten `audio_id`, `vocal_start` ja `vocal_end`; ne viittaavat kappaleen ID:hen ja valittuun aikaväliin.

Tässä syöttämämme `audio_id` on `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Voidaan nähdä, että `data`-kohdan `id`-kenttä on haluamamme `vox_audio_id`, minkä jälkeen siirrymme [Persona APIin](https://platform.acedata.cloud/documents/suno-persona) luomaan uuden Persona-v2-vox-version: laulajatyylin. Tarkat syötteet ovat seuraavat:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kutsun jälkeen saadaan seuraava tulos:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Tämän jälkeen voimme luoda sisältöä uuden Persona-v2-vox-version: laulajatyylin avulla yllä olevan `persona_id`-arvon perusteella. Tarkka luontimenetelmä on sama kuin kohdassa [Suno-kappaleiden luonti-API:n integraatio-ohjeet](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD), ja lopulta voimme käyttää Suno Vox APIa kappaleiden luomiseen uuden Persona-v2-vox-version: laulajatyylin avulla.
