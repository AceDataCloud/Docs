title: "Suno-erikoismusiikkimallin käyttöönottopas"

Erikoismusiikkimalli voi oppia yhtenäisiä musiikillisia ominaisuuksia 6–24 lisensoidusta äänitiedostosta ja käyttää niitä myöhempään kappaleiden luontiin. Luominen on asynkroninen toiminto; vakaampien tulosten saamiseksi suositellaan käyttämään 24 tyyliltään yhtenäistä ja äänenlaadultaan selkeää äänitiedostoa.

> Voit lähettää vain äänitiedostoja, joihin sinulla on laillinen käyttöoikeus tai joihin olet saanut valtuutuksen mallin luomista ja myöhempää generointia varten. Älä lataa luvatta musiikkia tai äänimateriaalia.

## Mallin luominen

Kutsu `POST /suno/custom-models` ja aseta `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Rajapinta palauttaa välittömästi alustan mallitunnuksen ja tehtävätunnuksen. Kun luominen on valmis, takaisinsoiton tai kyselytuloksen `status` muuttuu arvoksi `ready`. Vain onnistuneesta mallin luomisesta veloitetaan **10 Credits**; epäonnistuneesta luomisesta ei veloiteta.

## Mallin kysely

Kysy yksittäinen malli:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Kysy nykyisen sovelluksen malleja sivutettuna:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Kaikki mallit kuuluvat ne luoneelle Suno-sovellukselle. API-tunnistetietojen kierrätys ei muuta mallin omistajuutta, eivätkä muut sovellukset voi kysellä tai käyttää mallia.

## Kappaleiden generointi mallilla

Kun mallin tila on `ready`, jatka kutsumalla `POST /suno/custom-models` ja aseta `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id`-arvon on oltava nykyisen sovelluksen erikoismusiikkimalli, jonka tila on `ready`. Pyyntö epäonnistuu, jos malli ei ole käytettävissä, eikä toista mallia käytetä automaattisesti. `persona_id` ja erikoismusiikkimalli ovat keskenään poissulkevia; jos ne lähetetään samanaikaisesti, rajapinta palauttaa HTTP 400 -vastauksen ennen kuin pyyntö lähetetään generointipalveluun, eikä veloitusta synny. Jos haluat käyttää Personaa, käytä `/suno/audios`-päätepisteen `artist_consistency`- tai `artist_consistency_vox`-toimintoa.

Onnistunut kappaleen generointi kuluttaa **0.90 Credits**; epäonnistuneesta generoinnista ei veloiteta. Mallien kysely ja arkistointi ovat maksuttomia.

## Mallin arkistointi

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Nykyinen Beta-versio arkistoi mallin ja estää sen jatkokäytön; vastauksen `capacity_released=false` tarkoittaa, että arkistointi ei takaa mallikapasiteetin vapautumista. Arkistointitoimintoa voidaan kutsua toistuvasti, eikä siitä veloiteta uudelleen.
