---

SUNO sallii meidän hankkia musiikin wav-muotoisia tiedostoja, tämä asiakirja selittää liittymismenetelmät liittyvään API:in.

Tämän API:n keskeinen syöttöparametri on `audio_id`, joka on virallisesti luotu kappaleen ID; valinnaisesti tuetaan myös `callback_url` asynkronista palautusosoitetta.

Tässä syötämme `audio_id`:n, joka on `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Tulokset ovat seuraavat:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/suno/41572926-1a7a-41bc-adb8-9431e494c144.wav"
    }
  ]
}
```

Voimme nähdä, että `data`-kentän `file_url` on hankittu musiikin wav-muotoinen tiedosto, se on julkisesti saatavilla oleva CDN-osoite.

> **Tietoa WAV-linkin pysyvyydestä**
> Alusta pyrkii ensisijaisesti tallentamaan lopullisen WAV-tiedoston Ace Data Cloud CDN:ään ennen palautusta. Yllä oleva URL vain näyttää vastauksen muodon, eikä se edusta pitkäaikaista todellista objektia. Vain silloin, kun CDN:n pysyvyys ei ole valmis ja alkuperäisen median osoite on välittömästi tarkistettu ja se pystyy edelleen lataamaan voimassa olevan WAV-tiedoston, `file_url` voi mahdollisesti säilyttää tämän osoitteen; jos osoite on vanhentunut tai tiedoston tarkistus epäonnistuu, pyyntö palauttaa epäonnistumisen tai aikakatkaisun, eikä ladattavissa olevaa osoitetta palauteta onnistuneena tuloksena. Ole hyvä ja lataa ja säilytä se asianmukaisesti heti tehtävän valmistuttua, tarkka säilytysaika määräytyy alustan nykyisten tallennuspolitiikkojen mukaan.
