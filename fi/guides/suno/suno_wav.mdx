SUNO mahdollistaa musiikin wav-muotoisten tiedostojen hakemisen. Tässä dokumentissa selitetään kyseisen API:n integrointimenetelmä.

API:n keskeinen syöteparametri on `audio_id`, joka on virallisesti luotu kappaleen tunniste; valinnaisesti tuetaan myös `callback_url` asynkronista takaisinsoitto-osoitetta.

Tässä esimerkissä syötämme `audio_id` arvoksi `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer aa287fa4cc54401087a9fab3f99630af",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Tulokset ovat seuraavat:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://platform.cdn.acedata.cloud/suno/6a5a2099-d6d3-4930-9709-a30ac5dc7de5.wav"
    }
  ]
}
```

Kuten nähdään, `data`-kohdan `file_url`-kenttä sisältää haetun musiikin wav-muotoisen tiedoston URL-osoitteen, joka on julkisesti saavutettavissa oleva CDN-osoite.

> **WAV-linkkien pysyvyydestä**
>
> Ylävirran Suno CDN:ssä sijaitsevat WAV-tiedostot (`https://cdn1.suno.ai/{audio_id}.wav`) säilyvät vain muutaman päivän, minkä jälkeen ne poistetaan ja niiden käyttö palauttaa 403-virheen.
> Linkkien vanhenemisen välttämiseksi tämä rajapinta kopioi ylävirran WAV-tiedoston automaattisesti omaan CDN-verkkoomme (`https://platform.cdn.acedata.cloud/suno/{task_id}.wav`) ennen vastaamista. Palautettu `file_url` on siis kopioitu ja vakaa osoite, joka ei vanhene ylävirran CDN:n vanhentuessa.
> Kopiointi epäonnistuessa (hyvin harvinaista) palautetaan alkuperäinen ylävirran URL, jolloin toiminta säilyy ennallaan.
