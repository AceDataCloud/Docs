SUNO antaa meidän ladata viiteääntä jatkotuotantoa varten, ja tässä dokumentissa selitetään siihen liittyvä API-integrointimenetelmä.

Tavallinen lataus vaatii vain `audio_url`-kentän, joka on julkisesti käytettävissä oleva ääni-CDN-osoite. `mode` on oletusarvoisesti `standard`, joten olemassa olevia kutsuja ei tarvitse muuttaa. Tavallisen latauksen onnistuminen kuluttaa **0.06 Credits**; epäonnistunut lataus ei maksa mitään.

Tässä syöttämämme `audio_url` on `https://cdn.acedata.cloud/suno_demo.mp3`, joka on julkisesti käytettävissä oleva CDN-osoite.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Kuten voidaan nähdä, `data` on aina objekti, ja `audio_id` on ladatun kappaleen ID. Analyysitulokset, kuten `lyric`, `style`, `duration`, otsikko ja media-URL:t, ovat valinnaisia kenttiä, ja tarkat tiedot määräytyvät palautetun sisällön mukaan.

Kun kappaleen ID on saatu, [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) -rajapinnan kautta voidaan kutsua `upload_extend`-, `upload_cover`- tai alueen näytteenoton kaltaisia toimintoja, jotka vaativat `audio_id`-kentän. Jos haluat luoda uutta musiikkia Inspo-inspiraatioluontitoiminnolla 1–4 kokonaisen viiteäänen perusteella, kutsu suoraan `action=inspo` ja välitä alkuperäisten julkisten ääni-URL-osoitteiden luettelo; palvelu suorittaa latauksen ja analyysin automaattisesti, eikä asiakkaan tarvitse koota äänen metadataa.

## Alkuperäisen cover-kappaleen lataaminen yksityiselle äänelle

Kun käytetään `/suno/voices`-rajapinnalla luotua yksityistä ääntä cover-kappaleen tekemiseen, välitä kyseisen äänen `persona_id` tavalliseen latauspyyntöön alkuperäisen kappaleen ja äänen yhdistämiseksi:

```json
{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "mode": "standard",
  "persona_id": "<声音创建接口返回的 persona_id>"
}
```

Kun lataus onnistuu, kutsu palautetulla `data.audio_id`-arvolla `/suno/audios`-rajapintaa, aseta `action: "upload_cover"` ja välitä sama `persona_id`. Älä jatka sellaisen ääni-ID:n käyttöä, jota ei aiemmin yhdistetty tähän ääneen.

`persona_id` tukee vain tavallista latausta, eikä sitä voi käyttää samanaikaisesti `mode: "enhanced"` -asetuksen kanssa. `vocal_gender`-kenttää ei tarvitse määrittää erikseen; sukupuoliasetus ei voi korvata ääni-ID:tä. Äänen luomisessa, alkuperäisen kappaleen lataamisessa ja cover-kappaleen tekemisessä on käytettävä samaa palvelukanavaa.

## Tehostettu lataustila

> `audio_url` on syöteosoite, joka välitetään suoraan äänenkäsittelyprosessille, eikä päätevaiheen median pysyvä tallennuspalvelu siirrä sitä etukäteen. Varmista, että se on julkisesti käytettävissä tehtävän käsittelyn aikana.

Kun tavallinen lataus ei pysty käsittelemään ääntä, jonka omistat tai johon sinulla on käyttöoikeus, voit asettaa `mode`-asetukseksi `enhanced`. Tämä tila edellyttää myös 1–100 merkin pituista `name`-kenttää sekä julkisesti käytettävissä olevaa HTTPS-`audio_url`-osoitetta.

Tehostettu lataus käyttää kiinteästi asynkronista käsittelyä, joka kestää yleensä 2 minuuttia tai pidempään. Onnistunut käsittely kuluttaa **1.87 Credits**; epäonnistunut käsittely ei maksa mitään.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Rajapinta palauttaa välittömästi `task_id`- ja `trace_id`-arvot. Käytä [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) -rajapintaa tehtävän kyselyyn ja lue onnistumisen jälkeen ladatun äänen ID arvosta `response.data.audio_id`. Voit myös tarjota HTTPS-`callback_url`-osoitteen päätevaiheen vastaanottamista varten.
Parannetulla latauksella saatua `audio_id`:tä voidaan käyttää Coverissa, Samplesissa ja Mashupissa. Säestyksen ja MIDI:n erottamiseen, kaikkien raitojen erotteluun sekä laulun/säestyksen erotteluun saattaa edelleen liittyä rajoituksia äänen omistavan tilin perusteella; luetteloimattomien toimintojen ei taata tukevan tilien välistä käyttöä. Mitä lyhyempi ääni on, sitä korkeampi käsittelyn onnistumisprosentti yleensä on.
