Suno Tasks API:n päätoiminto on kysellä tehtävän suoritusstatus syöttämällä Suno Audios Generation API:n tai Suno Lyrics Generation API:n luoma tehtävätunnus.

Tässä dokumentissa esitellään yksityiskohtaisesti Suno Tasks API:n integrointiohjeet, jotka auttavat sinua integroimaan ja hyödyntämään tämän API:n tehokkaita toimintoja helposti. Suno Tasks API:n avulla voit helposti toteuttaa Suno Lyrics Generation API:n tai Suno Audios Generation API:n tehtävien suoritusstatusen kyselyn.

## Hakuprosessi

Käyttääksesi Suno Audios Generation API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja pidä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisellä haulla saat ilmaista saldoa, jolla voit kokeilla palvelua maksutta; kun saldo ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Pyyntöesimerkki

Suno Tasks API:a voidaan käyttää Suno Audios Generation API:n ja Suno Lyrics Generation API:n, eli kahden API:n, tulosten kyselyyn. Katso Suno Audios Generation API:n käyttöohjeet dokumentaatiosta [Suno Audios Generation API ](https://platform.acedata.cloud/documents/suno-audios-integration). Katso Suno Lyrics Generation API:n käyttöohjeet kohdasta [Suno Lyrics Generation API ](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

Otamme esimerkiksi Suno Audios Generation API -palvelun palauttaman tehtävätunnuksen ja havainnollistamme, kuinka tätä API:a käytetään. Oletetaan, että meillä on tehtävätunnus: eae26f89-b64b-404d-a80c-761996660b1c, seuraavaksi havainnollistetaan, kuinka tehtävätunnus välitetään.

### Pyyntöotsikoiden ja pyyntörungon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää JSON-muotoisen vastaustuloksen vastaanottamisen, tähän täytetään `application/json`.
- `authorization`: API:n kutsuavain, joka voidaan valita suoraan pudotusvalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladatun tehtävän tunnus.
- `action`: tehtävän käsittelytapa.

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedot, jos virhe ilmenee. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Ei valtuutusta, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Palvelimen sisäinen virhe, palvelimella tapahtui jokin virhe.
