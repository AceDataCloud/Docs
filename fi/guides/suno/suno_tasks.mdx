Suno Tasks API:n päätoiminto on kysyä tehtävän suoritusstatus syöttämällä Suno Audios Generation API:n tai Suno Lyrics Generation API:n generoitu tehtävä-ID.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Suno Tasks API:n integrointia, jotta voit helposti hyödyntää tämän API:n voimakkaita ominaisuuksia. Suno Tasks API:n avulla voit helposti tarkistaa Suno Lyrics Generation API:n tai Suno Audios Generation API:n tehtävän suoritusstatus.

## Hakuprosessi

Käyttääksesi Suno Tasks API:a, sinun on ensin mentävä hakusivulle [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) ja haettava vastaavaa palvelua, sitten kopioit Suno Audios Generation API:n tehtävä-ID:n, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/bc6754.png" width="500" class="m-auto"></p>

Lopuksi siirry Tasks API -sivulle [Suno Tasks API](https://platform.acedata.cloud/documents/b0dd9823-0e01-4c75-af83-5a6e2e05bfed) ja hae vastaavaa palvelua, siirryttyäsi sivulle, napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joita voit käyttää tämän API:n ilmaiseksi.

## Pyyntöesimerkki

Suno Tasks API:a voidaan käyttää Suno Audios Generation API:n ja Suno Lyrics Generation API:n tulosten kysymiseen. Tietoa siitä, miten käyttää Suno Audios Generation API:a, katso asiakirjasta [Suno Audios Generation API](https://platform.acedata.cloud/documents/d016ee3f-421b-4b6e-989a-8beba8701701). Tietoa siitä, miten käyttää Suno Lyrics Generation API:a, katso [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/f1c66741-a488-43ca-91fc-e53fbbda639a).

Otetaan esimerkki Suno Audios Generation API:n palvelusta palautetusta tehtävä-ID:stä ja näytetään, miten tätä API:a käytetään. Oletetaan, että meillä on tehtävä-ID: "eae26f89-b64b-404d-a80c-761996660b1c", seuraavaksi näytetään, miten syötetään tämä tehtävä-ID.

### Pyyntöotsikon ja -kehon asettaminen

**Request Headers** sisältää:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tässä täytetään `application/json`.
- `authorization`: API:n avain, joka voidaan valita suoraan alasvetovalikosta hakemisen jälkeen.

**Request Body** sisältää:

- `id`: ladattu tehtävä-ID.
- `action`: tehtävän toimintatapa.

<p><img src="https://cdn.acedata.cloud/uo7t6n.png" width="500" class="m-auto"></p>

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodia eri kielillä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/p6vi9o.png" width="500" class="m-auto"></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

返回结果一共有多个字段，request 字段就是发起任务时的 request body，同时response 字段是任务完成后返回的response body。字段介绍如下。

- `id`，生成此歌曲任务的 ID，用于唯一标识此次歌曲生成任务。
- `request`，查询歌曲任务中的请求信息。
- `response`，查询歌曲任务中的返回信息。

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
