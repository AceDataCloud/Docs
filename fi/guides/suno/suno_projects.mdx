`POST https://api.acedata.cloud/suno/projects` on Beta-rajapinta moniraitaisten projektien hallintaan. `action` erottaa luomisen, tallentamisen, ehdokkaiden luomisen, ehdokkaiden vahvistamisen ja viennin.

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: <每次写操作的新 UUID>
```

`retrieve`-toimintoa lukuun ottamatta **jokainen toiminto vaatii** `Idempotency-Key`-avaimen. Sama avain ja sama pyyntö palauttavat vain alkuperäisen tuloksen; sama avain eri pyynnön kanssa palauttaa 409-virheen. Jos maksullisessa luonnissa tapahtuu verkon aikakatkaisu tai vahvistuksen tulos on epävarma, kysely tulee ensin tehdä alkuperäisellä tehtävätunnuksella tai samalla idempotenssiavaimella; avainta ei voi vaihtaa ja lähettää pyyntöä uudelleen suoraan.

## Tunnisteet ja aikayksiköt

| Nimi                             | Mistä se saadaan                                                                                      | Missä sitä käytetään                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | `create`-vastauksen `data.id`                                                                      | Kaikissa nykyisen projektin myöhemmissä pyynnöissä                                      |
| `version_id`                   | Uusimman `retrieve`-, `save`-, `add_track`-, `commit_candidate`- tai `remove_track`-toiminnon `data.version_id` | Muokkauksessa, ehdokkaiden luonnissa ja viennissä; uusinta versiota on käytettävä                              |
| `audio_id` / `source_audio_id` | `upload`-toiminnon lopputilan `response.data.candidate.audio_id` tai olemassa olevan valmiin äänen ID                                | Alkuperäiseen ääneen viittaamiseen `add_track`-toiminnossa sekä luonnissa tai korvauksessa                          |
| `render_audio_id`              | `render`-toiminnon lopputilan `response.data.audio_id`                                                       | Projektimiksausviitteenä `generate_track`-toiminnossa                         |
| `operation_id`                 | `generate_track`- tai `replace_section`-toiminnon lopputilan `response.data.operation_id`                       | `commit_candidate`-toiminnossa; yleensä sama kuin luontitehtävän `task_id`, mutta palautusarvo tulee lukea |
| `candidate_id`                 | Luonnin lopputilan `response.data.candidates[].id`                                                       | Yhden ehdokkaan valitsemiseen vahvistettavaksi                                         |
| `track_id`                     | Projektin `data.state.tracks[].id`                                                                | Ehdokkaan vahvistamiseen tai raidan poistamiseen                                        |
| `task_id`                      | Asynkronisen toiminnon lähetysvastaus                                                                                   | Lopputilan kyselyyn `/suno/tasks`-rajapinnan kautta; se ei ole projektin ID                   |

`start_seconds` / `end_seconds` ovat **alkuperäisen äänen sekunteja**; `start_beats` / `end_beats` ovat **projektin aikajanan iskuja**. `state.timing.bps` on iskujen määrä sekunnissa, oletuksena 2. Esimerkiksi 41 sekunnin katkelma, joka alkaa iskusta 0, päättyy oletuksena iskuun 82. `generate_track`-toiminnon sekuntialuetta käytetään luontiviitteen määrittämiseen, eikä se takaa, että ehdokas on vain kyseisen alueen pituinen.

## Toimintojen kulku

| Järjestys  | `action`                             | Toiminto                         | Palautustapa         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | Luo tyhjän projektin                      | Synkroniset projektitiedot       |
| 2   | `retrieve`                           | Lukee uusimman version ja täydellisen `state`-tilan          | Synkroniset projektitiedot       |
| 3   | `save`                               | Tallentaa ensimmäisen kerran tai tallentaa muokatun `state`-tilan kokonaisuudessaan      | Synkroniset projektitiedot       |
| 4   | `upload`                             | Luo materiaalin HTTPS-ääniosoitteesta           | Asynkroninen tehtävä         |
| 5   | `add_track`                          | Lisää materiaaliäänen projektiin                  | Asynkroninen tehtävä, päivittää version    |
| 6   | `save`                               | Jos haluat vastaanottaa uusien raitojen ehdokkaita, tallenna ensin tyhjä kohderaita        | Synkroniset projektitiedot, päivittää version  |
| 7   | `render`                             | Vie nykyiset kuunneltavat raidat ja hakee miksausviitteen `audio_id` | Asynkroninen tehtävä         |
| 8   | `generate_track` tai `replace_section` | Luo vastaavasti uuden raidan ehdokkaita tai osittaisia korvausehdokkaita            | Asynkroninen tehtävä, ei vielä muuta projektia  |
| 9   | `commit_candidate`                   | Valitsee ja vahvistaa yhden ehdokkaan                  | Asynkroninen tehtävä, päivittää version onnistumisen jälkeen |
| Valinnainen  | `remove_track`                       | Poistaa määritetyn raidan                     | Synkroniset projektitiedot, päivittää version  |

Jos tehdään vain osittainen korvaus, olemassa oleva käyttökelpoinen alkuperäinen ääni riittää, eikä `render`-toimintoa tarvitse suorittaa ensin; jos alkuperäinen ääni on jo projektissa, myös `upload` ja `add_track` voidaan ohittaa. `render_audio_id` on vain `generate_track`-toiminnon pakollinen viite.

Asynkronisen toiminnon lähettäminen palauttaa ensin `{ "task_id": "...", "trace_id": "..." }`, mikä **ei tarkoita, että luonti onnistui**. Kysely:

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

Tehtävä katsotaan onnistuneeksi vasta, kun tehtävätietueessa on `finished_at` ja sen `response.success` on `true`; kun `response.success=false`, lue `response.error`. Vaikka `save` voi sisältää `task_id`-arvon, se valmistuu synkronisesti tässä rajapinnassa. `upload`, `render`, `generate_track` ja `replace_section` eivät muuta projektiversiota; `save`, `add_track`, `commit_candidate` ja `remove_track` -toimintojen onnistumisen jälkeen tulee käyttää uutta `version_id`-arvoa.

## Pyyntösopimukset

| Parametri                | Tyyppi ja soveltamisala                                                                                   | Kuvaus                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | Pakollinen merkkijono                                                                                     | Kiinteästi yksi tällä sivulla luetelluista toimintojen nimistä; yksi pyyntö suorittaa vain yhden toiminnon.                                      |
| `id`              | Pakollinen merkkijono, paitsi `create`                                                                         | Projektin ID, peräisin arvosta `create.data.id`.                                      |
| `version_id`      | Pakollinen merkkijono muokkauksessa, ehdokkaiden luonnissa ja viennissä; ensimmäisessä tyhjän projektin `save`-toiminnossa voidaan jättää pois                                                         | Käytä uusinta versiota; vanha versio hylätään. `retrieve` ei tarvitse sitä.                                 |
| `Idempotency-Key` | Pakollinen pyyntöotsake, paitsi `retrieve`, 1–128 merkkiä                                                              | Käytä uutta avainta jokaiselle uudelle toiminnolle; sama avain ja sama pyyntö palauttavat alkuperäisen tuloksen ilman uudelleenluontia tai veloitusta.                                   |
| `async`           | Valinnainen totuusarvo toiminnoille `upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`, `render` | Nämä toiminnot ovat aina asynkronisia; `false` ei muuta luontia synkroniseksi.                                    |
| `callback_url`    | Valinnainen URL asynkronisille toiminnoille                                                                                | Vastaanottaa lopputilailmoituksen; jos se jätetään pois, kysely tehdään `task_id`-arvolla `/suno/tasks`-rajapinnassa. `response.success` on silti tarkistettava. |

Seuraavat esimerkit esittävät ketjutetusti tunnusten ja versioiden välityksen toimintojen välillä. Vastauksissa luetellaan vain nykyiseen vaiheeseen liittyvät kentät; korvaa esimerkkitunnukset käyttöönoton aikana nykyisen sovelluksen vastausarvoilla.

## Tallenna projektin tila

| Parametri | Tyyppi ja kuvaus |
|---|---|
| `state` | Pakollinen objekti. Lähetä **koko projektin tila**, ei osittaista korjausta; käytä perustana viimeisimmän luku- tai muokkaustoiminnon palauttamaa `data.state`-arvoa ja säilytä tuntemattomat kentät. |
| `title` | Valinnainen merkkijono; kun se jätetään pois, käytetään `state.title`-arvoa, ja jos sitä ei myöskään ole, käytetään oletusotsikkoa. |
| `version_id` | Voidaan jättää pois, kun uusi tyhjä projekti tallennetaan ensimmäistä kertaa; sen jälkeen on käytettävä uusinta versiota. |

`state.timing.bps`-arvon on oltava positiivinen luku, oletusarvo on 2. `state.tracks` on raitojen taulukko; olemassa olevien äänileikkeiden `clipId` viittaa ääni-ID:hen, ja `startBeats`, `endBeats`, `readStartBeats` käyttävät projektin iskujen yksikköä. Turvallisin muokkaustapa on lukea koko `state`, muokata vain kohderaitaa tai -leikettä ja sitten suorittaa kokonaisuudessaan `save`. Uudella tyhjällä kohderaidalla on oltava vähintään yksilöllinen `id`, `type:"audio"`, `clips:[]`; tyhjän raidan täydellinen rakenne on esitetty kohdassa ”Luo uusi ääniraita”. Älä käytä äänen analyysitulosten iskupisteitä suoraan projektin aikajanan koordinaatteina.

## Lataa ääntä ja lisää raita

| Toiminto | Parametri | Tyyppi ja kuvaus |
|---|---|---|
| `upload` | `audio_url` | Pakollinen HTTPS-URL, joka osoittaa julkisesti käytettävissä olevaan ääneen, jonka käyttöön sinulla on oikeus. Lopputilassa olevaa `candidate.audio_id`-arvoa voidaan käyttää raidan lisäämiseen. |
| `add_track` | `audio_id` | Pakollinen merkkijono; valmiin materiaalin ääni-ID, ei URL. |
| `add_track` | `name`、`color` | Valinnaiset merkkijonot; raidan nimi otetaan oletuksena äänen otsikosta, väriksi suositellaan `#RRGGBB`, oletusarvo on `#7251F7`. |
| `add_track` | `title` | Valinnainen merkkijono; muuttaa samalla projektin otsikkoa, jätetään yleensä pois. |
| `add_track` | `start_beats`、`end_beats` | Valinnaiset ei-negatiiviset numerot, päätepisteen on oltava alkupistettä suurempi; oletuksena alkaa iskusta 0, ja päätepiste lasketaan äänen keston ja `timing.bps`-arvon perusteella. |
| `add_track` | `gain` | Valinnainen ei-negatiivinen numero, oletusarvo 1; leikkeen ja raidan äänenvoimakkuuskerroin. |

## Luo uusi ääniraita

Ehdokkaat sidotaan projektin versioon luotaessa. Tallenna ensin tyhjä raita, joka vastaanottaa ehdokkaat, vie sitten nykyinen miksaus luomisen viitteeksi; kun luominen on valmis, valitse yksi ehdokas ja lähetä se tälle tyhjälle raidalle.

### Varaa kohderaita: `save`

`generate_track`-ehdokkaat sidotaan nykyiseen projektin versioon. Lisää edellisen `add_track`-toiminnon lopputilassa palautettuun **kokonaiseen** `state`-arvoon seuraava tyhjä raita kohtaan `state.tracks` ja tallenna sitten `save`-toiminnolla; säilytä muut olemassa olevat kentät ennallaan:

### Luo ehdokkaita: `generate_track`

| Parametri | Tyyppi ja kuvaus |
|---|---|
| `source_audio_id` | Pakollinen; valmiin lähdeäänen ID. Lisää lähdeääni ensin projektiin, jotta ehdokkaiden sijainti voidaan myöhemmin määrittää. |
| `render_audio_id` | Pakollinen; yllä olevan `render`-toiminnon päätetilan `response.data.audio_id`, ei äänen URL-osoite. |
| `model` | Pakollinen; vaihtoehtoja ovat `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`, `chirp-v6`, `chirp-v6-wild`, `chirp-v6-mini`. Se, ovatko tietyt yhdistelmät käytettävissä, määräytyy tehtävän päätetilan mukaan. |
| `start_seconds`、`end_seconds` | Pakolliset numerot, `0 ≤ start_seconds < end_seconds`; sekuntiväli lähdeäänessä, ei projektin tahteja, eikä se takaa tulosteen kestoa. |
| `stem_control_tags` | Pakollinen merkkijono; uuden stemman kuvaus, esimerkiksi `add Piano`, `add Drums`, `add Bass`, ei kiinteä enumeraatio. |
| `batch_size` | Valinnainen kokonaisluku 1–4, oletusarvo 2; ehdokkaiden määrä. |
| `instrumental`、`vocal_gender` | Valinnaisia; pelkän instrumentaalin oletusarvo on `true`, lauluäänen mieltymykseksi voi asettaa `f`, `m`, `unspecified`, oletusarvo on `unspecified`. |
| `title`、`tags`、`negative_tags`、`prompt` | Valinnaiset merkkijonot; vastaavasti ehdokkaan otsikko, haluttu tyyli, vältettävä tyyli sekä uuden stemman teksti- tai sanoituskehote. |

### Ehdokkaan käyttö: `commit_candidate`

| Parametri | Tyyppi ja kuvaus |
|---|---|
| `operation_id` | Pakollinen; generointitehtävän päätetila `data.operation_id`. |
| `candidate_id` | Pakollinen; valittu `data.candidates[].id`. |
| `track_id` | Pakollinen; ennen generointia tallennetun tyhjän raidan `state.tracks[].id`. |

## Olemassa olevan leikkeen korvaaminen

`replace_section` voi käyttää suoraan olemassa olevaa lähdeääntä ilman, että miksausta tarvitsee ensin viedä. Generointi palauttaa vain ehdokkaita; lähetettäessä valitaan alkuperäinen raita, joka sisältää yksilöllisen lähdeleikkeen.

| Parametri | Tyyppi ja kuvaus |
|---|---|
| `source_audio_id` | Pakollinen; korvattavan valmiin lähdeäänen ID. |
| `model` | Pakollinen; käytä ”Generoi ehdokkaita” -kohdassa lueteltuja julkisia malleja, mallin ja toiminnon saatavuus määräytyy tehtävän päätetilan mukaan. |
| `start_seconds`、`end_seconds` | Pakolliset numerot, `0 ≤ start_seconds < end_seconds ≤ lähdeäänen kesto`; sekuntialue lähdeäänessä. |
| `prompt`、`replacement_lyrics` | Valinnaiset merkkijonot; edellinen on alkuperäinen sanoitus tai konteksti, jälkimmäinen on korvausalueen uusi sanoitus. |
| `title`、`tags`、`negative_tags` | Valinnaiset merkkijonot; ehdokkaan otsikko, toivottu tyyli ja vältettävä tyyli. |
| `fixed` | Valinnainen totuusarvo, oletusarvo `false`; kun asetetaan arvoon `true`, alueen on oltava alle 26 sekuntia, eikä malli välttämättä tue sitä. |

### Ehdokkaan kesto ei täsmää

Kun lähetät osittaisen korvauksen ehdokkaan, `track_id`:n tulee viitata alkuperäiseen raitaan, joka sisältää yksilöllisen lähdesegmentin, ja `start_beats` sekä `end_beats` tulee jättää pois. Rajapinta päivittää projektin vain, kun ehdokkaan kesto voidaan luotettavasti täsmäyttää koko lähdeaudioon tai valittuun alueeseen.

## Virheet ja palautuminen

| Tulos | Merkitys | Seuraava vaihe |
|---|---|---|
| `project_version_conflict` / `project_candidate_stale`（409） | Projektiversio on muuttunut, tai ehdokas ei kuulu nykyiseen versioon. | `retrieve` uusin projekti ja suunnittele muutokset uudelleen; älä toista vanhaa ehdokasta. |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported`（yleensä 400） | Parametrit, raidan tila, ehdokkaan kesto tai malli eivät vastaa toimintoa. | Tarkista tehtävän lopputilan virhe ja korjaa syöte; säilytä alkuperäinen projekti, jos ehdokasta ei voida liittää turvallisesti. |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`（403） | Viiteääntä ei voida käyttää kyseiseen projektitoimintoon, käyttöoikeutta ei ole, tai sisällöntarkistus hylkää sen. | Tarkista äänen lähde ja tehtävän `trace_id`; älä rinnasta jo luotua ehdokasta siihen, että koko kappale on vietävissä. |
| `too_many_requests`（429） | Pyyntöön kohdistuu nopeusrajoitus. | Kysy ensin alkuperäinen tehtävä ja päätä sitten, aloitetaanko uusi toiminto uudella idempotenssiavaimella. |
| `studio_unavailable` / `studio_model_unavailable`（503） | Projektinkäsittely tai valittu malli ei ole tilapäisesti käytettävissä. | Säilytä alkuperäisen tehtävän tulos; yritä myöhemmin uudelleen nimenomaisesti, älä vaihda mallia automaattisesti. |
| `studio_processing_failed` / aikakatkaisu（500/504） | Käsittely epäonnistui tai lopputila on epävarma. | Kysy `task_id`:n tai alkuperäisen idempotenssiavaimen perusteella, jotta vältät maksullisen luonnin toistamisen. |

Projektit ja ehdokkaat ovat sidottuja ne luoneeseen sovellukseen ja suoritusympäristöön, eikä sovellusten välistä uudelleenkäyttöä tai automaattista vikasietosiirtymää voida olettaa. Tallenna pysyvästi onnistuneesti viedyn lopullisen äänen URL ja säilytä `trace_id` vianmääritystä varten.
