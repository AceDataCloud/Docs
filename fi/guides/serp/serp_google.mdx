Google SERP (Search Engine Results Page) on tulossivu, jonka käyttäjä näkee syöttäessään kyselyn Google-hakukoneeseen. Se näyttää luonnolliset hakutulokset, mainokset, ominaisuudella varustetut tiivistelmät, tietopankit sekä kuvia, videoita ja muita sisältötyyppejä, joiden tarkoituksena on tarjota käyttäjilleen merkityksellisin tieto.

Tässä artikkelissa käsitellään Google SERP API:ta, joka voi tarjota tuloksia syöttämällä kysely Google-hakukoneeseen. Tulosten sisältöön kuuluu monenlaisia tyyppejä, kuten ominaisuudella varustetut tiivistelmät, tietopankit ja kuvat.

Tässä asiakirjassa esitellään Google SERP API:n liittymisohjeet.

## Hakuprosessi

Google SERP API:n käyttämiseksi sinun on ensin mentävä [Google SERP API](https://platform.acedata.cloud/documents/44c86226-8eaa-49bf-85f3-1fae8d2e23f1) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire"-painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, ja voit käyttää tätä API:ta ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä hakuresurssin tyyppi ja avainsana, voit saada hakutuloksia. Sinun tarvitsee vain siirtää `query`-kenttä ja määrittää vastaava malli.

Esimerkiksi etsiessäsi tietoa "apple inc":stä, voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers -asetukset, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä on täytetty `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body -asetukset, mukaan lukien:

- `type`: hakuresurssin tyyppi, tällä hetkellä tuetaan vain kuutta tyyppiä, oletus on `search`.
- `query`: hakusana.
- `country`: mukautettu hakutulosten maa, oletus on Yhdysvallat (US).
- `language`: mukautettu hakutulosten kieli, oletus on englanti (en).
- `range`: mukautettu hakutulosten aikaraja, oletus on rajoittamaton.
- `number`: mukautettu hakutulosten sivukoko, oletus on 10.
- `page`: mukautettu hakutulosten sivunumero, oletus on 1.

另外如果想生成对应的对接代码，可以直接复制生成，例如 CURL 的代码如下：

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Python 的对接代码如下：

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Mukautettu hakutyyppi

Jos haluat mukauttaa hakuresurssin tyyppiä, voimme muuttaa parametria `type`, joka sisältää tavalliset resurssit `search`, kuvareseptit `images`, uutisresurssit `news`, karttatyypit `maps`, alueresurssit `places`, videotyypit `videos`, tässä artikkelissa teemme esimerkin videotyypeistä `videos`.

Seuraavaksi näytämme tarkat toimenpiteet.

Ensinnäkin, aseta `type`-parametri arvoksi `videos` ja siirrä `query`-parametri normaalisti, kuten kuvassa näkyy:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" class="m-auto"></p>

Vastaava koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## 自定义搜索结果时间范围

  "range": "qdr:d",
