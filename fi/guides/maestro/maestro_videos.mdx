Maestro on **Agent-natiivi** videotuotantorajapinta: kuvaat haluamasi videon yhdellä luonnollisen kielen `prompt`-kehotteella (voit halutessasi liittää viitekuvia / -videoita / -ääntä `file_urls`-kentän avulla), ja päätön ”AI-ohjaaja” hoitaa automaattisesti aiheen valinnan, käsikirjoituksen kirjoittamisen, kuvien luomisen, ääninäyttelyn, taustamusiikin, koostamisen ja renderöinnin. Lopulta se tuottaa tekstityksillä varustetun valmiin videon ja lataa sen CDN:ään.

Tässä artikkelissa esitellään Maestro-videoiden luonti-API:n integrointiohjeet yksityiskohtaisesti, jotta voit integroida ja hyödyntää API:n ominaisuuksia nopeasti.

Tämä on **asynkroninen tehtävä**rajapinta: lähettämisen jälkeen se palauttaa välittömästi `task_id`-tunnuksen, jonka jälkeen tulos haetaan kyselemällä [Maestro-tehtävien haku-API:a](/fi/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (kysely on maksuton eikä siitä veloiteta). Jos haluat jatkaa olemassa olevan videon iterointia, voit käyttää `action: remix` / `edit` / `extend` yhdessä `ref_task_id`-kentän kanssa.

## Hakuprosessi

Jos haluat käyttää Maestro-videoiden luonti-API:a, hanki ensin API Token -tunnuksesi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Tämän jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Token -tunnuksella voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäinen hakemus sisältää maksuttoman käyttökiintiön, jolla voit kokeilla palvelua ilmaiseksi; kun kiintiö ei riitä, voit lisätä yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Maestro-videoiden luonti-API →](https://platform.acedata.cloud/documents/maestro-videos)

## Peruskäyttö

`POST https://api.acedata.cloud/maestro/videos`

Peruskäyttöön tarvitsee välittää vain yksi luonnollisen kielen `prompt`-kehote, ja AI-ohjaaja päättää automaattisesti käsikirjoituksen, kuvat, ääninäyttelyn ja leikkauksen. Tarkastellaan ensin määritettäviä pyyntöotsakkeita ja pyyntörungoa.

**Request Headers** sisältää:

- `accept`: missä muodossa haluat vastaanottaa vastauksen; tässä arvoksi annetaan `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voi valita suoraan pudotusvalikosta hakemisen jälkeen.
- `content-type`: pyyntörungon muoto; tässä arvoksi annetaan `application/json`.

**Request Body** sisältää pääasiassa:

- `prompt`: kuvaa luonnollisella kielellä tehtävä video (aihe, mitä näytetään, tyyli, kohdeyleisö).
- `langs`: valmiin videon kielitaulukko, välitä kerrallaan vain yksi, kuten `["zh-cn"]`; oletusarvo on `["zh-cn"]`.
- `aspect`: kuvasuhde, `9:16` (oletus) / `16:9` / `1:1`.
- `duration`: tavoitekesto (sekunteina), oletusarvo 30.

Kaikki pyyntörungon kentät on esitetty seuraavassa taulukossa:

| Kenttä            | Tyyppi       | Pakollinen  | Kuvaus                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Kyllä   | Kuvaa luonnollisella kielellä tehtävä video (aihe, mitä näytetään, tyyli, kohdeyleisö). AI päättää käsikirjoituksen, kuvat, ääninäyttelyn ja leikkauksen                                                                                                                                                                                      |
| `action`      | string   | Ei   | `generate` (oletus, luo uuden videon) / `remix` / `edit` / `extend` (iteroi olemassa olevaa videota, käytettävä yhdessä `ref_task_id`-kentän kanssa)                                                                                                                                                         |
| `ref_task_id` | string   | Ei   | Pakollinen, kun `action` on remix / edit / extend: lähtökohtana olevan aiemman tehtävän `task_id`                                                                                                                                                                            |
| `file_urls`   | string[] | Ei   | Viitemedia (kuva / video / ääni-URL), esimerkiksi tuotteesta näytettävä kuva, logo tai tekstityksillä varustettava materiaalikatkelma                                                                                                                                                                                      |
| `langs`       | string[] | Ei   | Valmiin videon kieli; kerrallaan voi välittää vain yhden, kuten `["zh-cn"]`; oletusarvo on `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | Ei   | `9:16` (oletus) / `16:9` / `1:1`, yhtenäinen tuloste 1080p/30fps                                                                                                                                                                                           |
| `duration`    | int      | Ei   | Tavoitekesto (sekunteina), oletusarvo 30, tukee **5–300 sekuntia**. Laskutus perustuu valmiin videon todelliseen kestoon, mutta se ei ylitä pyydettyä kestoa                                                                                                                                                                                      |
| `scenario`    | string   | Ei   | Videotyyppi: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` edellyttää lähdevideota, `avatar` edellyttää muotokuvaa                                                                                                                                             |
| `style`       | string   | Ei   | Visuaalisen tyylin esiasetus: `auto` (oletus) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; hyväksyy myös vapaata tekstiä pehmeänä vihjeenä. Ortogonaalinen suhteessa `scenario`-kenttään eikä muuta reititystä          |
| `voice`       | string   | Ei   | Kertojaääni (kielestä riippumaton, käytettävissä eri kielillä): `auto` (oletus) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; tukee myös 32-bittistä heksadesimaalista äänen `reference_id`-tunnusta, muut vapaamuotoiset tekstit eivät ole kelvollisia ääni-ID-tunnuksia |

Seuraavaksi havainnollistetaan asiaa konkreettisella esimerkillä. Oletetaan, että haluamme luoda kiinankielisen, pystysuuntaisen, 20 sekunnin mittaisen popularisointilyhytvideon. Vastaava CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Napsauta suorita, ja huomaat saavasi välittömästi seuraavanlaisen tuloksen:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Palautetun tuloksen kentät esitellään seuraavasti:
- `success`：onnistuiko tämä tehtävä lähettää onnistuneesti.
- `task_id`：tämän videonluontitehtävän ID, jota käytetään myöhemmin tulosten kyselyyn [Maestro-tehtävien kysely-API:ssa](/fi/guides/maestro/maestro_tasks).
- `trace_id`：tämän pyynnön seuranta-ID, joka voidaan antaa tekniselle tuelle ongelmatilanteissa paikannusta varten.

Koska videon tuottaminen kestää pitkään, rajapinta **palauttaa `task_id`:n välittömästi** eikä odota videon renderöinnin valmistumista. Seuraavaksi sinun tulee käyttää `task_id`:tä tulosten kyselyyn, katso lisätietoja osiosta ”Tulosten hakeminen”.

## Videotyypin ja tyylin määrittäminen (scenario / style)

Jos `scenario`-kenttää ei välitetä, AI määrittää sen automaattisesti (sama kuin `auto`); jos haluat kiinnittää videon tiettyyn tyyppiin, välitä se eksplisiittisesti. Esimerkiksi **pystyformaatissa olevan lyhytdraaman** tekemiseksi voit määrittää seuraavat arvot:

- `scenario`：videotyyppi, asetetaan tässä arvoon `drama` (lyhytdraama, jossa on hahmoja + dialogia).
- `style`：visuaalinen tyyli, asetetaan tässä arvoon `cinematic` (elokuvamainen tunnelma).

Täytetyn esimerkin CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Yleisiä yhdistelytapoja:

- Selostettu lyhytvideo：`scenario: "narrated"`。
- Automaattiset tekstitykset：`scenario: "captions"`，lähdevideo on välitettävä `file_urls`-kentässä。
- Digitaalinen avatar / puhevideo：`scenario: "avatar"`，henkilökuva on välitettävä `file_urls`-kentässä。
- Lyhytdraama：`scenario: "drama"`（hahmot + dialogi）。
- `style` on visuaalisen tyylin esiasetus（kuten `modern` / `neon` / `luxury`），se ei muuta tyyppiä, vaan vaikuttaa vain ulkoasuun。
- `voice`-kenttää käytetään kertojaäänen sävyn määrittämiseen（kuten `warm-female` / `deep-male`），se on kielestä riippumaton ja toimii eri kielissä。

Palautettava tulos vastaa ”Peruskäyttöä”, eli myös tässä `task_id` palautetaan välittömästi.

## Valmiin videon kieli

Yksi tehtävä toimittaa vain yhden valmiin videon yhdellä kielellä. `langs` voi sisältää vain yhden kielikoodin, kuten `["zh-cn"]` tai `["en"]`; useiden kielten välittäminen palauttaa virheen 400. Jos tarvitset videoita eri kielillä, luo tehtävät erikseen. Kielivalinta ei muuta sekuntihintaa.

## Iterointi olemassa olevan videon pohjalta (remix / edit / extend)

Välittämällä `action`-kentän ja edellisen tehtävän `ref_task_id`:n voit tehdä vaiheittaisia muutoksia alkuperäiseen projektiin (kuten ”muuta 2. kohtauksen otsikko”, ”vaihda ääninäyttely” tai ”tummenna kokonaisuutta”). Pienet muutokset ovat nopeita, suuret muutokset tehdään uudelleen:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：tulkitsee alkuperäisen videorakenteen uudelleen（säilyttää teeman, mukauttaa esitystapaa）。
- `edit`：tekee tarkkoja muokkauksia määritettyihin osiin（kuten otsikon tai ääninäyttelyn vaihto ja värimäärittely）。
- `extend`：laajentaa sisältöä alkuperäisen videon pohjalta。

Palautettava tulos on myös välittömästi palautettava uusi `task_id`, jota käyttämällä voit kysellä iteroidun valmiin videon.

## Tulosten hakeminen

Koska videon tuottaminen kestää pitkään, tämä rajapinta palauttaa `task_id`:n välittömästi lähetyksen jälkeen, ja sinun tulee käyttää sitä tulosten kyselyyn [Maestro-tehtävien kysely-API:ssa](/fi/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Kun tehtävä valmistuu, palautetaan yhden valmiin videon tiedot (sijaitsevat `variants`-taulukossa). `status` käy läpi tilat `pending → planning → producing → succeeded` (tai `failed`), **kysely on maksuton eikä kuluta krediittejä**. Katso täydellinen vastausmuoto ja historialuettelon kysely [Maestro-tehtävien kysely-API:n integraatio-ohjeesta](/fi/guides/maestro/maestro_tasks).

## Hinnoittelu

**Tehtävästä veloitetaan onnistumisen jälkeen todellisen toimitetun valmiin videon keston mukaan; epäonnistumisesta ei veloiteta.** Laskutettava kesto lasketaan kokonaisina sekunteina eikä se ylitä pyydettyä kestoa; jos valmiin videon kestoa ei voida lukea, käytetään pyydettyä kestoa. Tehtävän lähettämisestä itsestään ei veloiteta erikseen, ja `/maestro/tasks`-kysely on maksuton.

```
Krediitit = todelliset laskutettavat sekunnit × 0.7
```

Kaikissa skenaarioissa, toiminnoissa ja kielissä käytetään samaa hintaa, ilman skenaariokertoimia tai kielilisämaksuja. Jokainen tehtävä toimittaa vain yhden valmiin videon yhdellä kielellä. Pyydetty tavoitekesto tukee 5–300 sekuntia, ja tuloste on yhtenäisesti 1080p / 30fps.

| Todellinen laskutettava kesto |  Krediitit |
| ------------------- | --: |
| 30 sekuntia         |  21 |
| 60 sekuntia         |  42 |
| 120 sekuntia        |  84 |
| 300 sekuntia        | 210 |
| `/maestro/tasks`-kysely |  Maksuton |

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja viestin, jos virhe ilmenee. Esimerkiksi:

- `400 invalid_request`：Virheellinen pyyntö, mahdollisesti puuttuvan `prompt`-kentän tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `403 forbidden`：Kielletty, riittämätön saldo tai käyttöoikeus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, palvelimella meni jokin pieleen.

### Esimerkki virhevastaus

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
