Maestro on **Agent-natiivi** videotuotantorajapinta: kuvaat yhdellä luonnollisen kielen `prompt`-kehotteella haluamasi videon (voit halutessasi liittää viitekuvia / -videoita / -ääntä `file_urls`-kentällä), ja päätön ”AI-ohjaaja” suorittaa automaattisesti aiheen valinnan, käsikirjoituksen kirjoittamisen, kuvien luomisen, ääninäyttelyn, taustamusiikin, yhdistämisen ja renderöinnin sekä tuottaa lopulta tekstityksillä varustetun valmiin videon ja lataa sen CDN:ään.

Tässä artikkelissa esitellään yksityiskohtaisesti Maestro-videoiden luonti API:n integraatio-ohjeet, jotta voit integroida API:n nopeasti ja hyödyntää sen ominaisuuksia täysimääräisesti.

Tämä on **asynkroninen tehtävä**rajapinta: lähetyksen jälkeen `task_id` palautetaan välittömästi, minkä jälkeen tulos haetaan kyselemällä [Maestro-tehtävien kysely-API:a](/fi/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (kysely on maksuton eikä siitä veloiteta). Jos haluat jatkaa olemassa olevan videon iterointia, voit käyttää `action: remix` / `edit` / `extend` yhdessä `ref_task_id`-kentän kanssa.

## Hakuprosessi

Käyttääksesi Maestro-videoiden luonti API:a, hae ensin [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) API Tokenisi ja pidä se tallessa myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Tämän jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voit kutsua kaikkia alustan palveluita, eikä sinun tarvitse hakea erikseen jokaista palvelua varten.** Ensimmäisestä hakemuksesta saat ilmaista käyttökiintiötä, joten voit kokeilla palvelua maksutta; kun kiintiö ei riitä, voit lisätä yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Maestro-videoiden luonti API →](https://platform.acedata.cloud/documents/maestro-videos)

## Peruskäyttö

`POST https://api.acedata.cloud/maestro/videos`

Kaikkein perustavimmassa käytössä tarvitsee välittää vain luonnollisen kielen `prompt`-kehote, ja AI-ohjaaja päättää automaattisesti käsikirjoituksesta, kuvista, ääninäyttelystä ja leikkauksesta. Tutustutaan ensin asetettaviin pyyntöotsikoihin ja pyyntörungon sisältöön.

**Request Headers** sisältää:

- `accept`: missä muodossa haluat vastaanottaa vastaustulokset; täytä tähän `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan pudotusvalikosta hakemisen jälkeen.
- `content-type`: pyyntörungon muoto; täytä tähän `application/json`.

**Request Body** sisältää pääasiassa:

- `prompt`: kuvaile luonnollisella kielellä luotava video (aihe, mitä näytetään, tyyli, yleisö).
- `langs`: valmiin videon kielitaulukko, välitä kerrallaan vain yksi, esimerkiksi `["zh-cn"]`; oletusarvo `["zh-cn"]`.
- `aspect`: kuvasuhde, `9:16` (oletus) / `16:9` / `1:1`.
- `duration`: tavoitekesto (sekunteina), oletusarvo 30.

Kaikki pyyntörungon kentät on esitetty seuraavassa taulukossa:

| Kenttä            | Tyyppi       | Pakollinen  | Kuvaus                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Kyllä   | Kuvaile luonnollisella kielellä luotava video (aihe, mitä näytetään, tyyli, yleisö). AI päättää käsikirjoituksesta, kuvista, ääninäyttelystä ja leikkauksesta                                                                                                                                                                             |
| `action`      | string   | Ei   | `generate` (oletus, luo uuden videon) / `remix` / `edit` / `extend` (iteroi olemassa olevaa videota, käytettävä yhdessä `ref_task_id`-kentän kanssa)                                                                                                                                                |
| `ref_task_id` | string   | Ei   | Pakollinen, kun `action` on remix / edit / extend: lähtökohtana käytettävän historiallisen tehtävän `task_id`                                                                                                                                                                   |
| `file_urls`   | string[] | Ei   | Viitemedia (kuvan / videon / äänen URL), esimerkiksi tuotteesta näytettävä kuva, logo tai tekstityksiä lisättävä materiaalikatkelma                                                                                                                                                                             |
| `langs`       | string[] | Ei   | Valmiin videon kieli; kerrallaan voi välittää vain yhden, esimerkiksi `["zh-cn"]`; oletusarvo `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Ei   | `9:16` (oletus) / `16:9` / `1:1`, yhtenäinen ulostulo 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Ei   | Tavoitekesto (sekunteina), oletusarvo 30, tukee **5–300 sekuntia**. Laskutus perustuu valmiin videon todelliseen kestoon, mutta se ei ylitä pyydettyä kestoa                                                                                                                                                                             |
| `scenario`    | string   | Ei   | Videotyyppi: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` edellyttää lähdevideon välittämistä, `avatar` edellyttää henkilökuvan välittämistä                                                                                                                                    |
| `style`       | string   | Ei   | Visuaalisen tyylin esiasetus: `auto` (oletus) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; hyväksyy myös vapaata tekstiä pehmeänä vihjeenä. Ortogonaalinen `scenario`-kenttään nähden, ei muuta reititystä |
| `voice`       | string   | Ei   | Kertojaääni (kielestä riippumaton, toimii eri kielillä): `auto` (oletus) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Seuraavaksi havainnollistetaan tätä konkreettisella esimerkillä. Oletetaan, että haluamme luoda kiinankielisen, pystykuvaisen, 20 sekunnin mittaisen tieteen popularisointivideon. Vastaava CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun napsautat suorita, huomaat saavasi välittömästi tuloksen seuraavasti:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Palautettavan tuloksen kentät esitellään seuraavasti:
- `success`: onko tämä tehtävä lähetetty onnistuneesti.
- `task_id`: tämän videonluontitehtävän ID, jolla tuloksia kysellään myöhemmin [Maestro-tehtävien kysely-API:n](/fi/guides/maestro/maestro_tasks) kautta.
- `trace_id`: tämän pyynnön seuranta-ID, joka voidaan ongelmatilanteissa toimittaa tekniselle tuelle paikannusta varten.

Koska videon tuottaminen kestää pitkään, rajapinta **palauttaa `task_id`:n välittömästi** tässä vaiheessa eikä odota videon renderöinnin valmistumista. Seuraavaksi tuloksia tulee kysellä `task_id`:llä; katso lisätietoja osiosta ”Tulosten hakeminen”.

## Videotyypin ja tyylin määrittäminen (scenario / style)

Kun `scenario`-arvoa ei välitetä, AI määrittää sen automaattisesti (sama kuin `auto`); jos haluat lukita videon tiettyyn tyyppiin, välitä se eksplisiittisesti. Esimerkiksi **pystysuuntaista lyhytdraamaa** varten voidaan määrittää seuraava sisältö:

- `scenario`: videon tyyppi, asetetaan tässä arvoon `drama` (lyhytdraama, jossa on hahmoja + dialogia).
- `style`: visuaalinen tyyli, asetetaan tässä arvoon `cinematic` (elokuvallinen tunnelma).

Täytetyn esimerkin CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Yleisiä yhdistelytapoja:

- Selostettu lyhytvideo: `scenario: "narrated"`.
- Automaattiset tekstitykset: `scenario: "captions"`, lähdevideo tulee välittää `file_urls`-kentässä.
- Digitaalinen ihminen / puhevideo: `scenario: "avatar"`, kasvokuva tulee välittää `file_urls`-kentässä.
- Lyhytdraama: `scenario: "drama"` (hahmot + dialogi).
- `style` on visuaalisen tyylin esiasetus (kuten `modern` / `neon` / `luxury`), joka ei muuta tyyppiä vaan vaikuttaa vain visuaaliseen vaikutelmaan.
- `voice`-kentällä määritetään kertojaäänen sävy (kuten `warm-female` / `deep-male`); se ei riipu kielestä ja toimii kaikilla kielillä.

Palautustulos on sama kuin kohdassa ”Peruskäyttö”, ja myös tässä `task_id` palautetaan välittömästi.

## Valmiin videon kieli

Yksi tehtävä toimittaa vain yhden valmiin videon yhdellä kielellä. `langs` voi sisältää vain yhden kielikoodin, kuten `["zh-cn"]` tai `["en"]`; usean kielen välittäminen palauttaa virheen 400. Jos tarvitset videoita eri kielillä, luo tehtävät erikseen. Kielivalinta ei muuta sekuntihintaa.

## Iterointi olemassa olevalla videolla (remix / edit / extend)

Välittämällä `action`-arvon ja edellisen tehtävän `ref_task_id`:n voit tehdä alkuperäiseen projektiin muutoksia erotuksena (kuten ”vaihda kohtauksen 2 otsikko”, ”vaihda ääninäyttely” tai ”tummenna kokonaisuutta”). Pienet muutokset ovat nopeita, suuret muutokset tehdään uudelleen:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: tulkitsee alkuperäisen videorakenteen uudelleen (säilyttää teeman, muokkaa toteutusta).
- `edit`: tekee tarkkoja muokkauksia määritettyihin osiin (kuten otsikon vaihto, ääninäyttelyn vaihto tai värimäärittely).
- `extend`: laajentaa sisältöä alkuperäisen videon pohjalta.

Palautustulos palauttaa niin ikään välittömästi uuden `task_id`:n, jolla voit kysellä iteroinnin jälkeisen valmiin videon.

## Tulosten hakeminen

Koska videon tuottaminen kestää pitkään, tämä rajapinta palauttaa `task_id`:n välittömästi lähettämisen jälkeen, ja sinun tulee käyttää sitä tulosten kyselyyn [Maestro-tehtävien kysely-API:n](/fi/guides/maestro/maestro_tasks) kautta:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Kun tehtävä valmistuu, palautetaan yhden valmiin videon tiedot (sijaitsevat `variants`-taulukossa). `status` käy läpi tilat `pending → planning → producing → succeeded` (tai `failed`), **kysely on maksuton eikä kuluta krediittejä**. Katso täydellinen vastausmuoto ja historiatietojen luettelokysely [Maestro-tehtävien kysely-API:n integrointiohjeesta](/fi/guides/maestro/maestro_tasks).

## Laskutus

**Tehtävästä laskutetaan onnistumisen jälkeen todellisuudessa toimitetun valmiin videon keston mukaan; epäonnistuneesta tehtävästä ei veloiteta.** Laskutettava kesto lasketaan kokonaisina sekunteina, eikä se ylitä pyydettyä kestoa; jos valmiin videon kestoa ei voida lukea, käytetään pyydettyä kestoa. Tehtävän lähettämisestä itsestään ei laskuteta erikseen, ja `/maestro/tasks`-kysely on maksuton.

```
Krediitit = todelliset laskutettavat sekunnit × 0.7
```

Kaikissa skenaarioissa, toiminnoissa ja kielissä käytetään samaa hintaa, eikä skenaariokertoimia tai kielilisämaksuja ole. Jokainen tehtävä toimittaa vain yhden valmiin videon yhdellä kielellä. Pyydetty tuotekesto tukee 5–300 sekuntia, ja tuloste on yhtenäisesti 1080p / 30 fps.

| Todellinen laskutettava kesto | Krediitit |
| ---------------------------- | -------: |
| 30 sekuntia                  |       21 |
| 60 sekuntia                  |       42 |
| 120 sekuntia                 |       84 |
| 300 sekuntia                 |      210 |
| `/maestro/tasks`-kysely      | maksuton |

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedon, jos virhe tapahtuu. Esimerkiksi:

- `400 invalid_request`: Virheellinen pyyntö, mahdollisesti puuttuvan `prompt`:n tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `403 forbidden`: Kielletty, saldo tai käyttöoikeudet eivät riitä.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain odottamatonta.

### Esimerkki virhevastaus

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Yhteenveto

Tämän asiakirjan avulla olet oppinut käyttämään Maestro-videonluonti-API:a: vain yhdellä luonnollisen kielen `prompt`:lla voidaan automaattisesti suorittaa käsikirjoitus, materiaalit, ääninäyttely, taustamusiikki, leikkaus, tekstitykset ja valmiin videon renderöinti, ja se tukee videotyypin, tyylin, äänensävyn, valmiin videon kielen määrittämistä sekä olemassa olevan videon iterointia. Toivomme, että tämä asiakirja auttaa sinua API:n paremmassa integroinnissa ja käytössä. Jos sinulla on kysyttävää, ota milloin tahansa yhteyttä tekniseen tukitiimiimme.
