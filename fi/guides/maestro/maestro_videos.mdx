Maestro on **Agent-natiivinen** videotuotanto-API: käytät luonnollista kieltä `prompt` kuvaamaan haluamaasi videota (valinnaisesti voit liittää `file_urls` viittauskuvia / videoita / ääniä), ja päättämätön "AI-ohjaaja" hoitaa automaattisesti aiheen valinnan, käsikirjoituksen kirjoittamisen, kuvien tuottamisen, äänen nauhoittamisen, musiikin lisäämisen, yhdistämisen ja renderöinnin, lopulta tuottaen tekstityksellä varustetun valmiin videon ja lataamalla sen CDN:ään.

Tässä artikkelissa esitellään yksityiskohtaisesti Maestro videon tuottamisen API:n integrointiohjeet, jotka auttavat sinua nopeassa integroinnissa ja API:n kykyjen täysimääräisessä hyödyntämisessä.

Tämä on **asynkroninen tehtävä**-API: kun lähetät pyynnön, saat heti takaisin `task_id`:n, ja voit sen jälkeen kysyä tuloksia [Maestro tehtävien kysely API:n](/fi/guides/maestro/maestro_tasks) ( `POST /maestro/tasks` ) avulla (kysely on ilmainen eikä siitä veloiteta). Jos haluat jatkaa iterointia olemassa olevalla videolla, voit käyttää `action: remix` / `edit` / `extend` yhdessä `ref_task_id`:n kanssa.

## Hakuprosessi

Käyttääksesi Maestro videon tuottamisen API:a, mene ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) saadaksesi API-tunnuksesi, jota voit säilyttää varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API-tunnus riittää kutsumaan kaikkia palveluja, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla ilmaiseksi; kun määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Maestro videon tuottamisen API →](https://platform.acedata.cloud/documents/maestro-videos)

## Peruskäyttö

`POST https://api.acedata.cloud/maestro/videos`

Peruskäyttöön tarvitset vain luonnollisen kielen `prompt`:n, ja AI-ohjaaja päättää automaattisesti käsikirjoituksen, kuvastot, äänen ja leikkauksen. Tässä tutustumme ensin asetettaviin pyyntöotsikoihin ja pyyntökehoon.

**Pyyntöotsikot** sisältävät:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemuksen jälkeen.
- `content-type`: pyyntökehon muoto, tässä täytetään `application/json`.

**Pyyntökeho** sisältää pääasiassa:

- `prompt`: luonnollisella kielellä kuvattu video (aihe, mitä esitetään, tyyli, kohdeyleisö).
- `langs`: tulostuskielien taulukko, kuten `["zh-cn", "en"]`, oletuksena `["zh-cn"]`.
- `aspect`: kuvasuhde, `9:16` (oletus) / `16:9` / `1:1`.
- `duration`: tavoitekesto (sekuntia), oletuksena 30.

Pyyntökehon kaikki kentät on esitetty seuraavassa taulukossa:

| Kenttä         | Tyyppi    | Pakollinen | Selitys                                                                                                                                                                                                                           |
| -------------- | --------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`       | string    | Kyllä      | Luonnollisella kielellä kuvattu video (aihe, mitä esitetään, tyyli, kohdeyleisö). Käsikirjoitus, kuvat, ääni ja leikkaus päätetään AI:n toimesta.                                                                                   |
| `action`       | string    | Ei         | `generate` (oletus, luo uusi video) / `remix` / `edit` / `extend` (iteroi olemassa olevalle videolle, vaatii `ref_task_id`:n).                                                                                                   |
| `ref_task_id`  | string    | Ei         | Pakollinen, kun `action` on remix / edit / extend: historiallinen tehtävä `task_id`, jota käytetään lähtökohtana.                                                                                                               |
| `file_urls`    | string[]  | Ei         | Viittausmedia (kuva / video / ääni URL), esimerkiksi tuotteiden kuvat, logo tai tekstityksiä varten käytettävät materiaalit.                                                                                                      |
| `langs`        | string[]  | Ei         | Tulostuskielet, kuten `["zh-cn", "en"]`, oletuksena `["zh-cn"]`. Ensimmäinen on pääkieli; jokaisesta lisäkielestä käytetään samaa kuvaa, vain ääni + renderointi lisääntyy, **jokaisesta lisäyksestä +6 pistettä**.                     |
| `aspect`       | string    | Ei         | `9:16` (oletus) / `16:9` / `1:1`, kaikki ulostulo 1080p/30fps.                                                                                                                                                                   |
| `duration`     | int       | Ei         | Tavoitekesto (sekuntia), oletuksena 30, tukee **5–300 sekuntia**. Laskutus perustuu todelliseen videon kestoon, mutta ei ylitä pyyntöaikaa.                                                                                       |
| `scenario`     | string    | Ei         | Videotyyppi: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions` vaatii lähdevideon, `avatar` vaatii kuvan.                                                                                                      |
| `style`        | string    | Ei         | Visuaalinen tyylisäätö: `auto` (oletus) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, myös vapaa teksti pehmeänä vihjeenä. Ei muuta reittiä. |
| `voice`        | string    | Ei         | Kertojaääni (ei kieliriippuvainen, toimii eri kielillä): `auto` (oletus) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`. |

Seuraavaksi käymme läpi konkreettisen esimerkin. Oletetaan, että haluamme luoda kaksikielisen, pystysuoran, 20 sekunnin tietovideon, vastaava CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Kerro 20 sekunnissa, mitä vektoritietokanta on, sopii aloittelijoille, lopussa yksi muistettava asia",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Kerro 20 sekunnissa, mitä vektoritietokanta on, sopii aloittelijoille, lopussa yksi muistettava asia",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kun suoritat, huomaat, että saat heti tuloksen, kuten seuraavassa:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Palautettujen tulosten kenttien esittely on seuraava:
- `success`：Onko tämä tehtävä onnistuneesti lähetetty.
- `task_id`：Tämän videon generointitehtävän ID, jota käytetään myöhemmin [Maestro tehtäväkysely API:ssa](/fi/guides/maestro/maestro_tasks) tulosten kyselyyn.
- `trace_id`：Tämän pyynnön jäljitystunnus, jota voidaan antaa tekniselle tuelle ongelmatilanteissa.

Koska videon tuottaminen vie aikaa, rajapinta **palauttaa heti `task_id`** eikä odota videon renderöinnin valmistumista. Seuraavaksi on käytettävä `task_id`:tä tulosten kyselyyn, katso tarkemmin osio "Ota tulokset".

## Määritä videon tyyppi ja tyyli (scenario / style)

Jos `scenario`-arvoa ei anneta, AI arvioi sen automaattisesti (vastaa `auto`); jos haluat sitoa videon tiettyyn tyyppiin, voit ilmoittaa sen selvästi. Esimerkiksi, jos haluat tehdä **pystysuoran lyhytelokuvan**, voit määrittää seuraavat tiedot:

- `scenario`：Videon tyyppi, tässä asetetaan `drama` (hahmot + dialogi lyhytelokuvassa).
- `style`：Visuaalinen tyyli, tässä asetetaan `cinematic` (elokuvamainen laatu).

Esimerkin CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Kaksi kämppäkaveria riitelee ja sovittelee kissan vuoksi, kolme käännettä, lopussa lämmin",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Yleisiä yhdistelmiä:

- Selostusvideo: `scenario: "narrated"`, Lite / Standard / Pro tukevat.
- Automaattiset tekstitykset: `scenario: "captions"`, tarvitsee `file_urls` alkuperäiselle videolle, Lite / Standard / Pro tukevat.
- Digitaalinen henkilö / puhe: `scenario: "avatar"`, tarvitsee `file_urls` kuvan henkilöstä, Standard / Pro tukevat.
- Lyhytelokuva: `scenario: "drama"` (hahmot + dialogi), vain Pro tukee.
- `style` on visuaalisen tyylin esiasetus (kuten `modern` / `neon` / `luxury`), ei muuta tyyppiä, vain vaikuttaa visuaaliseen kokemukseen.
- `voice` käytetään kertojan äänen sävyn määrittämiseen (kuten `warm-female` / `deep-male`), ei liity kieleen, toimii eri kielillä.

Palautustulos on sama kuin "Peruskäyttö", se palauttaa heti `task_id`:n.

## Monikielinen tuotanto

Anna `langs`-kentässä useita kieliä, niin voit tuottaa monikielisiä versioita kerralla. Ensimmäinen on pääkieli, ja jokaiselle lisäkielelle **käytetään samaa kuvaa**, vain ääni + renderöinti lisätään, joten **jokaisesta lisäkielestä vain +6 pistettä**. Esimerkki:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Esittele älykäs asiakaspalvelutuotteemme, korosta 3 keskeistä myyntiväittämää",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

Tehtävän valmistuttua jokaiselle kielelle vastaa tuloksessa yksi `variant` (katso [Maestro tehtäväkysely API](/fi/guides/maestro/maestro_tasks)).

## Iterointi olemassa olevalla videolla (remix / edit / extend)

Anna `action` ja edellisen tehtävän `ref_task_id`, niin voit tehdä eroja alkuperäiseen projektiin (kuten "vaihda 2. näytöksen otsikko" tai "vaihda ääni" tai "tummenna kokonaisuutta"). Pienet muutokset tapahtuvat nopeasti, suuret muutokset vaativat uudelleen tekemistä:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "Vaihda avausotsikko vaikuttavammaksi, kokonaisväritys tummemmaksi"
}'
```

- `remix`：Uudelleen esittäminen alkuperäisen videorakenteen pohjalta (teema säilyy, esitystä säädetään).
- `edit`：Tietyille osille hienosäätö (kuten otsikon vaihto, äänen vaihto, värin säätö).
- `extend`：Sisällön laajentaminen alkuperäisen videon pohjalta.

Palautustulos on myös heti uusi `task_id`, jota käytetään kyselyyn, jotta saadaan iteroinnin jälkeinen valmis tuote.

## Ota tulokset

Koska videon tuottaminen vie aikaa, tämä rajapinta palauttaa heti `task_id`:n lähettämisen jälkeen, sinun on käytettävä sitä [Maestro tehtäväkysely API:ssa](/fi/guides/maestro/maestro_tasks) tulosten kyselyyn:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Tehtävän valmistuessa palautetaan valmis tuotetieto (jokaiselle kielelle yksi `variant`). `status` kulkee läpi `pending → planning → producing → succeeded` (tai `failed`), **kysely on ilmainen, ei kuluta pisteitä**. Täydellinen vastausmuoto ja historiallisten luetteloiden kyselytiedot löytyvät [Maestro tehtäväkysely API:n integrointiohjeista](/fi/guides/maestro/maestro_tasks).

## Laskutus

**Tehtävä laskutetaan valmistuneen tuotteen mukaan, epäonnistuneista tehtävistä ei veloiteta.** Laskutus perustuu todelliseen toimitettuun tuotteen kestoon ja kielimäärään, eikä laskutusaika ylitä pyyntöaikaa. Jos jokin kieli ei lopulta tuota, ei veloiteta kyseisen kielen +6 lisämaksua. Tehtävän lähettäminen itsessään ei aiheuta erillistä veloitusta, `/maestro/tasks` kysely on ilmainen.

Yhden valmiin tuotteen pisteet lasketaan seuraavalla kaavalla:

```
Pisteet = Valmiin tuotteen kesto sekuntia × 0.60 × kohtauskerroin + 6 × max(kielimäärä − 1, 0)
```

Maestro veloittaa **0.60 pistettä/ todellinen valmiin tuotteen sekunti**, tukee 5–300 sekuntia, enintään 4 kieltä ja 1080p / 30fps ulostuloa; kaikki toiminnot ja kohtaukset ovat käytettävissä.

Kohtauskerroin: `drama` 1.35× / `avatar` 1.15× / muu 1×.

| Esimerkki                  |  Pisteet |
| ------------------- | --: |
| Lite 30 sekuntia           |   6 |
| Standard 30 sekuntia       |  18 |
| Standard 60 sekuntia       |  36 |
| Standard 120 sekuntia      |  72 |
| Pro 30 sekuntia            |  36 |
| Pro 300 sekuntia           | 360 |
| Jokaisesta lisätystä toimituskielestä          |  +6 |
| `/maestro/tasks` kysely |  Ilmainen |

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheen, API palauttaa vastaavan virhekoodin ja tiedot. Esimerkiksi:

- `400 invalid_request`：Virheellinen pyyntö, mahdollisesti puuttuvan `prompt` tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `403 forbidden`：Kielletty, riittämätön saldo tai pääsy.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki
```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "haku epäonnistui"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Johtopäätös

Tämän asiakirjan avulla olet oppinut, kuinka käyttää Maestro-videon luonti API:a: tarvitset vain yhden luonnollisen kielen `prompt`-kyselyn, ja se suorittaa automaattisesti käsikirjoituksen, materiaalin, ääninäyttelyn, taustamusiikin, leikkauksen, tekstityksen ja valmiin videon renderöinnin, ja se tukee videotyypin, tyylin, äänensävyn, monikielisen ulostulon määrittämistä sekä olemassa olevien videoiden iterointia. Toivomme, että tämä asiakirja auttaa sinua paremmin yhdistämään ja käyttämään tätä API:a. Jos sinulla on kysymyksiä, ota rohkeasti yhteyttä tekniseen tukitiimiimme.
