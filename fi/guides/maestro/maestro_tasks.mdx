Maestro-tehtävien kysely-API:n päätoiminto on kysellä tehtävän suoritustilaa ja lopullista tulosta [Maestro-videonluonti-API:n](/fi/guides/maestro/maestro_videos) (`POST /maestro/videos`) palauttaman tehtävätunnuksen avulla.

Tässä dokumentissa esitellään yksityiskohtaisesti Maestro-tehtävien kysely-API:n integrointiohje. Koska videon luonti on asynkroninen tehtävä, lähettämisen jälkeen on käytettävä tätä rajapintaa edistymisen ja valmiin videon kyselyyn, **kysely on maksuton eikä kuluta krediittejä.**

`POST https://api.acedata.cloud/maestro/tasks`

## Hakuprosessi

Jotta voit käyttää Maestro-tehtävien kysely-API:a, hae ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä jokaista palvelua tarvitse hakea erikseen.** Ensimmäisellä hakukerralla saat ilmaista käyttökiintiötä, jolla voit kokeilla palvelua maksutta; jos kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Maestro-tehtävien kysely-API →](https://platform.acedata.cloud/documents/maestro-tasks)

## Yksittäisen tehtävän kysely

Lisätietoja videotehtävän luomisesta on dokumentaatiossa [Maestro-videonluonti-API](/fi/guides/maestro/maestro_videos). Käytämme esimerkkinä sen palauttamaa tehtävätunnusta: `f57e99c4f60f4373a15517742ce2357d`, ja havainnollistamme, miten sen tila ja tulos kysellään.

### Pyyntöotsikoiden ja pyyntörungon määrittäminen

**Request Headers** sisältää:

- `accept`: määrittää vastaanotettavan vastauksen JSON-muodon, tähän kirjoitetaan `application/json`.
- `authorization`: API-kutsuavain, joka voidaan valita suoraan pudotusvalikosta haun jälkeen.
- `content-type`: pyyntörungon muoto, tähän kirjoitetaan `application/json`.

**Request Body** sisältää:

| Kenttä       | Tyyppi     | Pakollinen        | Kuvaus                                                |
| -------- | ------ | --------- | ------------------------------------------------- |
| `id`     | string | pakollinen yksittäistä tehtävää kyseltäessä | `POST /maestro/videos` palauttama `task_id`              |
| `action` | string | ei         | `retrieve` (oletus, kysyy yksittäisen tehtävän); historiatietoluetteloa kyseltäessä kiinteä arvo on `retrieve_batch` |

### Koodiesimerkki

Vastaava CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa tämän videotehtävän tilan ja tuloksen. Esimerkki tehtävän valmistuttua palautettavasta vastauksesta on seuraava (`variants`-taulukko sisältää yhden valmiin videon):

```json
{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "started_at": 1769262721.823,
  "finished_at": 1769264698.3,
  "elapsed": 1976.477,
  "status": "succeeded",
  "progress": {
    "percent": 100,
    "stage": "producing",
    "message": "rendering scene 2"
  },
  "request": {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": [
      "zh-cn"
    ],
    "aspect": "9:16",
    "duration": 20
  },
  "response": {
    "success": true,
    "data": {
      "variants": [
        {
          "lang": "zh-cn",
          "aspect": "9:16",
          "kind": "video",
          "title": "什么是向量数据库",
          "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-001"
        }
      ],
      "project": {
        "tarball_url": null,
        "outputs": [
          "https://…/zh.mp4"
        ]
      },
      "percent": 100,
      "stage": "producing",
      "progress": [
        {
          "stage": "producing",
          "message": "rendering scene 2",
          "pct": 60,
          "t": 1750000000
        }
      ]
    }
  }
}
```

Palautustuloksen kenttien kuvaukset ovat seuraavat:

- `id`: tämän videotehtävän tunnus, jota käytetään tämän videonluontitehtävän yksilölliseen tunnistamiseen.
- `status`: tehtävän tila, arvot ovat `pending → planning → producing → succeeded` (tai `failed`). Tehtävän valmistuminen määräytyy tämän ylimmän tason `status`-kentän perusteella.
- `elapsed`: tehtävän tähänastinen kesto (sekunteina).
- `progress`: ylimmän tason edistymisobjekti, `percent` (0–100) asetetaan tehtävän onnistuttua vähintään arvoon 100; `stage` ja `message` heijastavat AI-ohjaajan viimeisintä edistymistapahtumaa (siksi onnistumisen jälkeen `stage` voi edelleen olla viimeinen suoritusvaihe, kuten `producing`), ja niitä voidaan käyttää suoraan edistymispalkin näyttämiseen.
- `request`: tehtävää käynnistettäessä käytetty pyyntörunko.
- `response`: tehtävän palautustiedot.
  - `success`: onnistuiko tehtävä.
  - `data.variants`: sisältää yhden valitun kielen valmiin videon objektin, mukaan lukien `lang`, `aspect`, `title`, `output_url` (valmiin videon latausosoite) jne.
  - `data.project`: koko projektin tuotokset, mukaan lukien `tarball_url` (projektipaketti) ja `outputs` (valmiiden videoiden linkit).
  - `data.progress`: vaiheittain lisättävä edistymistapahtumien taulukko (vain lisättävä loki), jota voidaan käyttää yksityiskohtaisen reaaliaikaisen edistymisen näyttämiseen.
- `created_at`: tehtävän luontiaika, Unix-aikaleima (sekunteina).
- `started_at`: tehtävän suorituksen aloitusaika, Unix-aikaleima (sekunteina). Arvo on null, jos tehtävä ei ole vielä alkanut.
- `finished_at`: tehtävän valmistumisaika, Unix-aikaleima (sekunteina). Arvo on null, jos tehtävä ei ole valmistunut.

## Historialuettelon kysely

Kun välität `action: retrieve_batch`, voit hakea tällä hetkellä kirjautuneen suorittajan viimeisimmät tehtävät (luontiajan mukaan laskevassa järjestyksessä), ja sitä voidaan käyttää ”Omat videot” -luettelosivulla. Historialuettelo on eroteltu kirjautumisidentiteetin mukaan.

**Request Body** sisältää:

| Kenttä               | Tyyppi     | Pakollinen  | Kuvaus                              |
| ---------------- | ------ | --- | ------------------------------- |
| `action`         | string | kyllä   | kiinteä arvo `retrieve_batch`            |
| `limit`          | int    | ei   | palautettavien kohteiden määrä, oletus 20; sallittu alue on 1–100          |
| `created_at_max` | int    | ei   | palauttaa vain tehtävät, jotka ovat tiukasti aiempia kuin tämä Unix-aikaleima (ei sisällä raja-arvoa, sivutusta varten) |
| `created_at_min` | int    | ei   | palauttaa vain tehtävät, jotka ovat tiukasti myöhempiä kuin tämä Unix-aikaleima (ei sisällä raja-arvoa)     |

### Koodiesimerkki

Vastaava CURL-koodi on seuraava:
```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa nykyisen käyttäjän historiallisten tehtävien luettelon:

```json

  "count": 2,
  "items": [
    {
      "id": "f57e99c4f60f4373a15517742ce2357d",
      "started_at": 1769262721.823,
      "finished_at": 1769264698.3,
      "elapsed": 1976.477,
      "status": "succeeded",
      "progress": {
        "percent": 100,
        "stage": "producing",
        "message": "rendering scene 2"
      },
      "request": {
        "prompt": "…",
        "langs": [
          "zh-cn"
        ],
        "aspect": "9:16",
        "duration": 20
      },
      "response": {
        "success": true,
        "data": {
          "variants": [
            {
              "lang": "zh-cn",
              "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-003"
            }
          ]
        }
      }
    }
  ]

```

Palautetun tuloksen kenttien kuvaukset ovat seuraavat:

- `count`: Nykyisen kirjautuneen suorittajan näkyvissä olevien tehtävien kokonaismäärä, johon eivät vaikuta aikarajoitukset tai `limit`.
- `items`: Aikarajoitusten ja `limit`-arvon mukaan suodatettu tehtävätaulukko, joka on järjestetty luontiajan mukaan laskevaan järjestykseen; kunkin elementin muoto vastaa kohdan ”Yksittäisen tehtävän kysely” palautustulosta.

## Kyselysuositukset

Koska videon tuottaminen kestää pitkään, `status` käy läpi tilat `pending → planning → producing → succeeded` (tai `failed`). On suositeltavaa kysellä kerran 5–10 sekunnin välein, kunnes `status` muuttuu arvoksi `succeeded` tai `failed`. Ylätason `progress.percent`-arvoa voidaan käyttää reaaliaikaisen edistymispalkin näyttämiseen. **Tämän rajapinnan kysely on maksutonta eikä kuluta krediittejä.**

## Virheenkäsittely

API:a kutsuttaessa API palauttaa vastaavan virhekoodin ja tiedon, jos virhe tapahtuu. Esimerkiksi:

- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutustunnus.
- `404 not_found`: Tehtävää ei löytynyt, annettua task_id:tä ei ole olemassa.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui virhe.
