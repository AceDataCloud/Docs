Maestro-tehtävien kysely-API:n päätoiminto on kysellä tehtävän suoritustilaa ja lopullista tulosta [Maestro-videonluonti-API:n](/fi/guides/maestro/maestro_videos) (`POST /maestro/videos`) palauttaman tehtävä-ID:n avulla.

Tässä dokumentissa esitellään yksityiskohtaisesti Maestro-tehtävien kysely-API:n integrointiohje. Koska videon luonti on asynkroninen tehtävä, lähetyksen jälkeen on käytettävä tätä rajapintaa etenemisen ja valmiin videon kyselyyn, **kysely on maksuton eikä kuluta krediittejä.**

`POST https://api.acedata.cloud/maestro/tasks`

## Hakuprosessi

Jos haluat käyttää Maestro-tehtävien kysely-API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäinen hakemus sisältää ilmaista käyttökiintiötä, joten voit kokeilla palvelua maksutta; jos kiintiö ei riitä, voit ladata yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Maestro-tehtävien kysely-API →](https://platform.acedata.cloud/documents/maestro-tasks)

## Yksittäisen tehtävän kysely

Lisätietoja videotehtävän luomisesta on dokumentissa [Maestro-videonluonti-API](/fi/guides/maestro/maestro_videos). Käytämme esimerkkinä sen palauttamaa tehtävä-ID:tä: `f57e99c4f60f4373a15517742ce2357d`, ja esittelemme, kuinka sen tilaa ja tulosta kysellään.

### Pyyntöotsikoiden ja pyyntörungon määrittäminen

**Request Headers** sisältää:

- `accept`: määrittää JSON-muotoisen vastaustuloksen vastaanottamisen, ja arvoksi annetaan tässä `application/json`.
- `authorization`: API:n kutsuavain, joka voidaan valita suoraan pudotusvalikosta hakemisen jälkeen.
- `content-type`: pyyntörungon muoto, ja arvoksi annetaan tässä `application/json`.

**Request Body** sisältää:

| Kenttä       | Tyyppi     | Pakollinen        | Kuvaus                                                |
| -------- | ------ | --------- | ------------------------------------------------- |
| `id`     | string | Pakollinen yksittäistä tehtävää kyseltäessä | `POST /maestro/videos` -kutsun palauttama `task_id`              |
| `action` | string | Ei         | `retrieve` (oletus, kysyy yksittäisen tehtävän); historialistaa kyseltäessä aina `retrieve_batch` |

### Koodiesimerkki

Vastaava CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

Vastaava Python-koodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Vastausesimerkki

Kun pyyntö onnistuu, API palauttaa tämän videotehtävän tilan ja tuloksen. Esimerkki palautuksesta tehtävän valmistuessa on seuraava (jokaista kieltä vastaa yksi `variant`):

```json
{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "started_at": 1769262721.823,
  "finished_at": 1769264698.3,
  "elapsed": 1976.477,
  "status": "succeeded",
  "progress": {
    "percent": 100,
    "stage": "producing",
    "message": "rendering scene 2"
  },
  "request": {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": [
      "zh-cn",
      "en"
    ],
    "aspect": "9:16",
    "duration": 20
  },
  "response": {
    "success": true,
    "data": {
      "variants": [
        {
          "lang": "zh-cn",
          "aspect": "9:16",
          "kind": "video",
          "title": "什么是向量数据库",
          "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-001"
        },
        {
          "lang": "en",
          "aspect": "9:16",
          "kind": "video",
          "title": "What is a vector database",
          "output_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4?example=video-002"
        }
      ],
      "project": {
        "tarball_url": null,
        "outputs": [
          "https://…/zh.mp4",
          "https://…/en.mp4"
        ]
      },
      "percent": 100,
      "stage": "producing",
      "progress": [
        {
          "stage": "producing",
          "message": "rendering scene 2",
          "pct": 60,
          "t": 1750000000
        }
      ]
    }
  }
}
```

Palautustuloksen kentät esitellään seuraavasti:

- `id`: tämän videotehtävän ID, jota käytetään tämän videonluontitehtävän yksilöimiseen.
- `status`: tehtävän tila, jonka arvot ovat `pending → planning → producing → succeeded` (tai `failed`). Se, onko tehtävä valmistunut, määräytyy tämän ylimmän tason `status`-arvon perusteella.
- `elapsed`: tehtävän tähänastinen kesto (sekunteina).
- `progress`: ylimmän tason etenemisobjekti, jossa `percent` (0–100) asetetaan tehtävän onnistuttua vähintään arvoon 100; `stage` ja `message` kuvastavat AI-ohjaajan viimeisintä etenemistapahtumaa (siksi onnistumisen jälkeen `stage` voi edelleen olla viimeinen suoritusvaihe, kuten `producing`), ja niitä voidaan käyttää suoraan edistymispalkin näyttämiseen.
- `request`: tehtävää käynnistettäessä lähetetty pyyntörunko.
- `response`: tehtävän palautustiedot.
  - `success`: onnistuiko tehtävä.
  - `data.variants`: jokaista kieltä vastaa yksi valmiin videon objekti, joka sisältää muun muassa `lang`, `aspect`, `title` ja `output_url` (valmiin videon latausosoite).
  - `data.project`: koko projektin tuotokset, mukaan lukien `tarball_url` (projektipaketti) ja `outputs` (kaikki valmiiden videoiden linkit).
  - `data.progress`: vaiheittain lisättävä etenemistapahtumien taulukko (vain lisättävä loki), jota voidaan käyttää yksityiskohtaisen reaaliaikaisen etenemisen näyttämiseen.
- `created_at`: tehtävän luontiaika, Unix-aikaleima (sekunteina).
- `started_at`: tehtävän suorituksen aloitusaika, Unix-aikaleima (sekunteina). Arvo on null, jos tehtävä ei ole vielä alkanut.
- `finished_at`: tehtävän valmistumisaika, Unix-aikaleima (sekunteina). Arvo on null, jos tehtävä ei ole vielä valmistunut.

## Historialistan kysely

Antamalla `action: retrieve_batch` saat nykyisen kirjautuneen suorittajan viimeisimmät tehtävät (laskevassa luontiaikajärjestyksessä), ja sitä voidaan käyttää ”Omat videot” -listasivulla. Historialista on erotettu kirjautumisidentiteetin mukaan.

**Request Body** sisältää:
| Kenttä               | Tyyppi     | Pakollinen  | Kuvaus                              |
| ---------------- | ------ | --- | ------------------------------- |
| `action`         | string | Kyllä   | Kiinteästi `retrieve_batch`            |
| `limit`          | int    | Ei   | Palautettavien tietueiden määrä, oletusarvo 20; kelvollinen alue on 1–100          |
| `created_at_max` | int    | Ei   | Palauttaa vain tehtävät, jotka ovat tiukasti ennen tätä Unix-aikaleimaa (ei sisällä raja-arvoa, sivutusta varten) |
| `created_at_min` | int    | Ei   | Palauttaa vain tehtävät, jotka ovat tiukasti tämän Unix-aikaleiman jälkeen (ei sisällä raja-arvoa)     |

### Koodiesimerkki

Vastaava CURL-koodi on seuraava:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

Kun pyyntö onnistuu, API palauttaa nykyisen käyttäjän historiallisten tehtävien luettelon:

      "elapsed": 1976.477,
      "status": "succeeded",
      "progress": {
        "percent": 100,
        "stage": "producing",
        "message": "rendering scene 2"
      },
      "request": {
        "prompt": "…",
        "langs": [
          "zh-cn",
          "en"
        ],
        "aspect": "9:16",
        "duration": 20

Palautettujen tulosten kentät esitellään seuraavasti:

- `count`: Nykyiselle kirjautuneelle suorittajalle näkyvien tehtävien kokonaismäärä, johon aikaehdot tai `limit` eivät vaikuta.
- `items`: Tehtävätaulukko, joka on suodatettu aikaehtojen ja `limit`-arvon perusteella ja järjestetty luontiajan mukaan käänteiseen järjestykseen; jokaisen elementin muoto vastaa kohdan ”Yksittäisen tehtävän kysely” palautustulosta.

## Kyselysuositukset

Koska videon tuottaminen kestää pitkään, `status` käy läpi vaiheet `pending → planning → producing → succeeded` (tai `failed`). On suositeltavaa kysellä tilaa kerran 5–10 sekunnissa, kunnes `status` muuttuu arvoksi `succeeded` tai `failed`. Ylätason `progress.percent`-arvoa voidaan käyttää reaaliaikaisen edistymispalkin näyttämiseen. **Tämän rajapinnan kysely on maksutonta eikä kuluta krediittejä.**

## Virheiden käsittely

Kun API:a kutsuttaessa kohdataan virhe, API palauttaa vastaavan virhekoodin ja tiedot. Esimerkiksi:

- `401 invalid_token`: Ei valtuutettu, valtuutustunnus on virheellinen tai puuttuu.
- `404 not_found`: Tehtävää ei löytynyt, annettua task_id:tä ei ole olemassa.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, palvelimella tapahtui jotain virheellistä.

### Virhevastausesimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
