Tässä artikkelissa esitellään kasvotunnistus sukupuolen muunnos API -liitäntäohje, joka voi käyttäjän ladatessa kasvokuvan, perustuen kasvotunnistus- ja generointialgoritmeihin, tuottaa kuvan, jossa kasvotunnistus sukupuoli on muutettu. Miehestä naiseksi voidaan saavuttaa kaunistava, kevyt meikki, otsatukka ja pitkät hiukset; naisesta mieheksi voidaan saavuttaa parta ja lyhyet hiukset.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [kasvotunnistus sukupuolen muunnos API](https://platform.acedata.cloud/documents/0e4e5318-060e-4976-8d3a-171301240f8c) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, joita voit käyttää API:ta ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä kuvalinkki ja sukupuolitiedot, voit saada käsitellyn tuloskuvan. Ensinnäkin sinun on yksinkertaisesti välitettävä `image_url` -kenttä, kasvokuva on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

Sitten meidän on myös ladattava tietoja kasvotunnistuksen sukupuolitiedoista `gender_infos`, joka on taulukko, johon voimme syöttää useita tietoja. Voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/j22eg4.png" width="500" class="m-auto"></p>

Voimme nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, mukaan lukien:

- `image_url`: käsiteltävän kasvokuvan linkki.
- `gender_infos`: tietoja kasvotunnistuksen sukupuolesta ja alueesta, jossa sukupuoli on pakollinen parametri, 0 tarkoittaa miehestä naiseksi, 1 tarkoittaa naisesta mieheksi.

Valinnan jälkeen voimme huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/5kwudj.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta, niin voit testata, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavan tuloksen:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/SwapGenderPic/1256437459/1d85ceb9-6847-41ec-a9fd-7a20ddbd13b6"
}
```

Voimme nähdä, että palautetussa tuloksessa on `image_url` -kenttä, joka on muunneltu kasvokuva syötettyjen sukupuolimuutosparametrien mukaan. Muutettu kasvotieto on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/hm7w44.png" width="500" class="m-auto"></p>

Voimme nähdä, että kuvassa kasvot ovat muuttuneet syötettyjen sukupuolitietojen mukaan.

Jos haluat luoda vastaavan liitäntäkoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-gender' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
  "gender_infos": [{"gender":1}]
}'
```

Pythonin liitäntäkoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/face/change-gender"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
    "gender_infos": [{"gender":1}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
