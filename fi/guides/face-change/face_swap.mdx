Face Swap API:n päätoiminto on vaihtaa kohdekuvassa olevan kasvokuvan lähdekuvassa olevan kasvokuvan kanssa syöttämällä lähdekuva ja kohdekuva.

Tässä asiakirjassa käsitellään yksityiskohtaisesti Face Swap API:n liittämistä, jotta voit helposti integroida ja hyödyntää tämän API:n voimakkaita ominaisuuksia. Face Swap API:n avulla voit helposti vaihtaa kohdekuvassa olevan kasvokuvan lähdekuvassa olevan kasvokuvan kanssa.

## Hakuprosessi

Käyttääksesi Face Swap API:a, sinun on ensin mentävä hakusivulle [Face Swap API](https://platform.acedata.cloud/documents/d10df07a-66a6-4c37-b114-3a003fc9bd55) ja haettava tarvittavaa palvelua. Kun olet siirtynyt sivulle, napsauta "Acquire"-painiketta, kuten kuvassa on esitetty:

![Hakusivu](https://cdn.acedata.cloud/rci31i.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti [kirjautumissivulle](https://platform.acedata.cloud), jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia käyttöoikeuksia, joiden avulla voit käyttää tätä API:a ilmaiseksi.

### Pyyntöotsikon ja -kehon asettaminen

**Pyyntöotsikot** sisältävät:

- `accept`: määrittää, että vastaanotetaan JSON-muotoista vastausta, tähän täytetään `application/json`.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

**Pyyntökeho** sisältää:

- `source_image_url`: ladatun lähdekuvan linkki.
- `target_image_url`: ladatun kohdekuvan linkki.
- `timeout`: valinnainen, käsittelyaika (sekunteina), aikakatkaisu palauttaa suoraan.

### Koodiesimerkki

Voit huomata, että sivun oikealla puolella on automaattisesti luotu koodi eri kielillä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/t8gsls.png" width="500" className="m-auto" /></p>

Osittainen koodiesimerkki on seuraava:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/face/swap' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "source_image_url": "https://cdn.acedata.cloud/n1lmd8.png",
  "target_image_url": "https://cdn.acedata.cloud/3np95r.png"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/face/swap"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "source_image_url": "https://cdn.acedata.cloud/n1lmd8.png",
    "target_image_url": "https://cdn.acedata.cloud/3np95r.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```json

  "image_size": 4006213,
```

Voit nähdä, että tuloksessa on `image_url`-kenttä, joka sisältää linkin kuvaan, jossa kohdekuvassa oleva kasvokuva on vaihdettu alkuperäisessä kuvassa olevan kasvokuvan kanssa. Muut tiedot ovat seuraavat:

- `image_url`, luodun kuvan linkki.
- `image_width`, luodun kuvan leveys.
- `image_height`, luodun kuvan korkeus.
- `image_size`, luodun kuvan koko.
- `task_id`, tämän luontitehtävän ID.

## Asynkroninen palautus

Koska Face Swapin luominen vie suhteellisen kauan, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on seuraava: asiakas käynnistää pyynnön, kun se määrittää ylimääräisen `callback_url`-kentän. Kun asiakas on käynnistänyt API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävän ID:tä. Kun tehtävä on valmis, Face Swapin tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, jossa on myös `task_id`-kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, kuinka tämä toiminta tapahtuu.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä. Kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/r8wyb7.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina. Tässä esimerkki on https://webhook.site/3b76eba5-4573-432a-b607-3000b87afc06.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL:iin ja täyttää vastaavat parametrit, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/xx08i2.png" width="500" className="m-auto" /></p>

Napsauta Suorita, ja voit huomata, että saat heti tuloksen, kuten seuraavassa:

```json
{
  "task_id": "9cba9d36-3b14-43c9-85b6-86f6dfc3b096"
}
```

Odota hetki, niin voit tarkastella luotua Face Swap -tulosta osoitteessa https://webhook.site/3b76eba5-4573-432a-b607-3000b87afc06, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/col42s.png)

Sisältö on seuraava:

```json
{
  "success": true,
  "task_id": "9cba9d36-3b14-43c9-85b6-86f6dfc3b096",
  "image_url": "https://platform.cdn.acedata.cloud/face/9cba9d36-3b14-43c9-85b6-86f6dfc3b096.png",
  "image_width": 2008,
  "image_height": 1942,
  "image_size": 4006481
}
```

Voit nähdä, että tuloksessa on `task_id`-kenttä, ja muut kentät ovat samankaltaisia kuin edellä, ja tämän kentän avulla voit yhdistää tehtävät.

## Virheiden käsittely

Kun kutsut API:a, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:
- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustunnus.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.
