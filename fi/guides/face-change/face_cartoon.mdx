Tässä artikkelissa esitellään henkilökuva-animaatio API -liitäntäohje, joka voi syöttämällä yhden kasvojen valokuvan luoda henkilökohtaisen anime-hahmon, jota voidaan käyttää persoonallisten profiilikuvien, hauskojen aktiviteettien, erikoistehosteiden sovellusten ja muiden tilanteiden luomiseen, parantaen sosiaalista viihdekokemusta.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [henkilökuva-animaatio API](https://platform.acedata.cloud/documents/6b6313f1-f398-4d29-933d-5a652cfa1c37) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia käyttöoikeuksia, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä kuvalinkki, voit saada käsitellyn tuloskuvan. Ensimmäiseksi sinun on yksinkertaisesti välitettävä `image_url`-kenttä, kasvojen kuva on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

Seuraavaksi voit täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/gflhrl.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet Request Headers, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä on täytetty `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu Request Body, mukaan lukien:

- `image_url`: käsiteltävän kasvojen kuvan linkki.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/rwbicp.png" width="500" class="m-auto"></p>

Napsauta "Try" -painiketta, niin voit testata, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavan tuloksen:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/FaceCartoonPic/1256437459/8567833b-7831-406c-9ff5-890e5f7e020e"
}
```

Voit nähdä, että palautetussa tuloksessa on `image_url`-kenttä, joka on muunneltu sarjakuvakasvokuvan linkki. Muunnellut kasvojen tiedot ovat esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/qkyga1.png" width="500" class="m-auto"></p>

Voit nähdä, että kuvassa oleva kasvokuva on jo luonut henkilökohtaisen anime-hahmon.

Jos haluat luoda vastaavan liitäntäkoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/face/cartoon' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Pythonin liitäntäkoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/face/cartoon"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
