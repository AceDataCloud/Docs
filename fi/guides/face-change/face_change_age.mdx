Tässä artikkelissa esitellään kasvokuvan ikämuutos API -integraatio-ohje, joka voi muuttaa kuvan kasvokuvan ikää syöttämällä kuvan ja iän. Peruskäyttö on, että käyttäjä lataa kasvokuvan, ja kasvojen muokkaus- ja generointialgoritmin avulla saadaan ulos kuva, jossa kasvot näyttävät vanhemmilta tai nuoremmilta, tukien eri ikämuutoksia.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [kasvokuvan ikämuutos API](https://platform.acedata.cloud/documents/0c5b4165-25ba-4dc2-8f02-e3cd74ab4238) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa voit rekisteröityä ja kirjautua sisään. Kirjautumisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia käyttöoikeuksia, ja voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä kuvalinkki ja ikätiedot, saat käsitellyn tuloskuvan. Ensinnäkin sinun on yksinkertaisesti välitettävä `image_url` -kenttä, kasvokuva on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/f5687u.png" width="500" className="m-auto" /></p>

Sitten meidän on myös ladattava kasvokuvan ikätietoparametri `age_infos`, joka on taulukko, johon voimme syöttää useita tietoja. Voimme seuraavaksi täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/cn95e8.png" width="500" className="m-auto" /></p>

Voimme nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu pyyntökeho, joka sisältää:

- `image_url`: käsiteltävän kasvokuvan linkki.
- `age_infos`: tietoa kasvokuvan iästä ja alueesta, jossa ikä on pakollinen parametri.

Valinnan jälkeen voimme huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/zk8qkl.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa on esitetty, ja saamme seuraavanlaisen tuloksen:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/ChangeAgePic/1256437459/bfce1ab8-5fd7-464d-8878-b38433f84d0e"
}
```

Voimme nähdä, että palautetussa tuloksessa on `image_url` -kenttä, joka on kasvokuvan kuva syötetyn iän muutoksen jälkeen. Muutettu kasvotiedot on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/01rmiv.png" width="500" className="m-auto" /></p>

Voimme nähdä, että kuvassa kasvot ovat muuttuneet syötetyn iän mukaan.

Jos haluat luoda vastaavan integraatiokoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-age' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "age_infos": [{"age":60}],
  "image_url": "https://cdn.acedata.cloud/f5687u.png"
}'
```

Pythonin integraatiokoodi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/face/change-age"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "age_infos": [{"age":60}],
    "image_url": "https://cdn.acedata.cloud/f5687u.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liikaa pyyntöjä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
