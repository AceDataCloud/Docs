Tässä artikkelissa esitellään kasvojen ominaisuuksien paikannus API -liittymän ohjeet, joka voi syöttää kuvia ja paikantaa kasvojen ominaisuuksia (tunnetaan myös kasvojen avainpisteiden paikannuksena), laskemalla kasvojen ääriviivoja muodostavat 90 pistettä, mukaan lukien kulmakarvat (kummassakin 8 pistettä), silmät (kummassakin 8 pistettä), nenä (13 pistettä), suu (22 pistettä), kasvojen ääriviivat (21 pistettä) ja silmän pupillit (2 pistettä).

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [kasvojen ominaisuuksien paikannus API](https://platform.acedata.cloud/documents/20945baf-b263-457b-be5f-0332c2180a57) -sivulle ja haettava vastaavaa palvelua. Sivulle päästyäsi napsauta "Acquire" -painiketta, kuten kuvassa on esitetty:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia käyttöoikeuksia, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä kuvalinkki, voit saada käsitellyn tuloskuvan. Ensimmäiseksi sinun on yksinkertaisesti välitettävä `image_url`-kenttä, kasvojen kuva on esitetty alla olevassa kuvassa:

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" class="m-auto"></p>

Seuraavaksi voimme täyttää vastaavat tiedot käyttöliittymässä, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/y3g837.png" width="500" class="m-auto"></p>

Voit nähdä, että olemme asettaneet pyyntöotsikot, mukaan lukien:

- `accept`: minkälaista vastausmuotoa haluat vastaanottaa, tässä on täytetty `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi on asetettu pyyntökeho, mukaan lukien:

- `image_url`: käsiteltävän kasvojen kuvan linkki.
- `mode`: tunnistusmoodi. 0 tarkoittaa kaikkien näkyvien kasvojen tunnistamista, 1 tarkoittaa suurimman kasvojen tunnistamista. Oletusarvo on 0.
- `face_model_version`: kasvojentunnistuspalvelussa käytettävän algoritmimallin versio, oletusarvo on `3.0`.
- `need_rotate_detection`: onko kuvan kiertotunnistustuki käytössä. 0 tarkoittaa, että se ei ole käytössä, 1 tarkoittaa, että se on käytössä. Oletusarvo on 0.

Valinnan jälkeen voit huomata, että oikealle puolelle on myös luotu vastaava koodi, kuten kuvassa on esitetty:

<p><img src="https://cdn.acedata.cloud/2ceul8.png" width="500" class="m-auto"></p>

Kenttäkuvaus on seuraava:
- `image_width` ：pyydetty kuvan leveys.
- `image_height` ：pyydetty kuvan korkeus.
- `face_model_version`：kasvojentunnistuksessa käytettävän algoritmin malliversio.
- `face_shape_set`：viiden kohdan paikannuksen (kasvojen avainpisteet) tarkka tieto.
  - `face_profile` ：kuvaa kasvojen muotoa 21 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `left_eye` ：kuvaa vasemman silmän muotoa 8 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `right_eye ` ：kuvaa oikean silmän muotoa 8 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `left_eye_brow` ：kuvaa vasemman kulmakarvan muotoa 8 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `right_eye_brow ` ：kuvaa oikean kulmakarvan muotoa 8 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `mouth` ：kuvaa suun muotoa 22 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `nose` ：kuvaa nenän muotoa 13 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `left_pupil` ：vasemman pupillin muotoa 1 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti
  - `right_pupil` ：oikean pupillin muotoa 1 pisteen avulla.
    - `x` ：x-koordinaatti
    - `y` ：y-koordinaatti

Lisäksi, jos haluat luoda vastaavan koodin, voit suoraan kopioida sen, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/face/analyze' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Pythonin koodin integrointi on seuraava:

```python
import requests

url = "https://api.acedata.cloud/face/analyze"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Virheellinen pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki


## Johtopäätös

Tämän asiakirjan avulla olet oppinut, kuinka käyttää viiden kohdan paikannus API:a syötettyjen kuvien viiden kohdan paikannukseen. Toivottavasti tämä asiakirja auttaa sinua paremmin integroimaan ja käyttämään tätä API:a. Jos sinulla on kysyttävää, ota rohkeasti yhteyttä tekniseen tukitiimiimme.
