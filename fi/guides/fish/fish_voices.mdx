Tässä artikkelissa esitellään Fish Voices Generation API -liittymisohjeet, jonka avulla voit luoda oman äänensävyn syöttämällä äänilinkin.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Fish Voices Generation API](https://platform.acedata.cloud/documents/55e61b64-ac7d-4710-a7f1-57a4ba786b17) -sivulle ja haettava vastaavaa palvelua. Kun olet sivulla, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakukerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, eli syöttämällä äänensävyn äänilinkki `voice_url`, saat käsitellyn tuloksen. Tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/278ikr.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers -asetukset, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen käytettävä avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body -asetukset, mukaan lukien:

- `voice_url`: ladatun äänensävyn äänilinkki.
- `title`: tämän äänensävyn otsikkotiedot.
- `image_urls`: tämän äänensävyn kansikuva.
- `description`: tämän äänensävyn kuvastustiedot.
- `callback_url`: URL, johon tulokset palautetaan.

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, tässä tapauksessa äänensävyn luontitehtävän tila.
  - `data`, musiikkitehtävän tulos
    - `_id`, tässä tapauksessa äänensävyn luontitehtävän ID, jota käytetään myöhemmin äänen kloonaamiseen.

    - `image_url`, äänensävyn kansainformaatio.
    - `description`, äänensävyn kuvastustiedot.

    - `default_text`, tässä tapauksessa äänensävyn luontitehtävän äänen tekstimuoto.

Voit nähdä, että olemme saaneet tyydyttävää äänensävytietoa, ja meidän tarvitsee vain kloonata äänen tehtävä tuloksessa olevan `data`-kentän `_id`:n mukaan.

Jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/fish/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "voice_url": "https://platform.r2.fish.audio/task/604133d7b3c7430385382470f67770e8.mp3",
  "title": "test",
  "description": "test"
}'
```

## Asynkroninen palautus

Koska Fish Voices Generation API:n luominen vie suhteellisen kauan, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on seuraava: asiakas aloittaa pyynnön, kun se määrittää ylimääräisen `callback_url` -kentän. Kun asiakas tekee API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id` -kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luontitehtävän tulos lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id` -kenttä, jolloin tehtävän tulos voidaan yhdistää ID:n avulla.

Katsotaanpa esimerkin avulla, miten tämä toimii.

Ensinnäkin, Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, ja kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä olevaan Webhook URL:iin ja täyttää vastaavat parametrit, tarkat tiedot ovat kuvassa näkyvät:

## Virheiden käsittely

API:ta kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`：Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`：Valtuuttamaton, virheellinen tai puuttuva valtuutustoken.
- `429 too_many_requests`：Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`：Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "haku epäonnistui"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
