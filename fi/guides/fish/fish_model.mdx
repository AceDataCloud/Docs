Tämä rajapinta perustuu [Fish Audio viralliseen Model API:iin](https://docs.fish.audio/resources/api-reference/model) ja se on tarkoitettu **luomaan pitkäaikaisesti käytettävä kloonattu äänimalli ääninäytteen perusteella**. Osoite on `POST https://api.acedata.cloud/fish/model`.

> Jos tarvitset vain tilapäisesti viiteääntä, mallin luomista ei tarvita, voit suoraan käyttää [Fish TTS API:ta](https://platform.acedata.cloud/documents/fish-tts) `references`-toimintoa kertaluonteiseen kloonaukseen. Sivutettu haku olemassa olevista äänistä löytyy [Fish Model Query API:sta](https://platform.acedata.cloud/documents/fish-model-query); yksittäisen äänen yksityiskohtien hakemiseen `_id`:n perusteella katso [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Hakuprosessi

Käyttääksesi Fish Model API:ta, sinun tulee ensin hankkia API Token [Ace Data Cloud -hallintapaneelista](https://platform.acedata.cloud/console/applications) ja säilyttää se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Valmiina palaat automaattisesti nykyiselle sivulle.

**Yksi API Token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jonka avulla voit kokeilla palvelua ilmaiseksi; jos määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Pyyntöruumiin kentät

| Kenttä                    | Tyyppi    | Pakollinen | Selitys                                                                          |
| ------------------------- | --------- | ---------- | -------------------------------------------------------------------------------- |
| `title`                   | string    | Kyllä      | Äänimallin nimi, jota käytetään hallintapaneelin luettelossa tunnistamiseen.    |
| `voices`                  | string    | Kyllä      | Ääninäytteen HTTP(S) URL (**yksi merkkijono**, ei taulukko). Tämä rajapinta ei tue multipart/binaarista latausta, laita äänitiedosto julkisesti saatavilla olevaan objektivarastoon. |
| `description`             | string    | Ei         | Äänimallin kuvaus.                                                                |
| `cover_image`             | string    | Ei         | Kansikuvan HTTP(S) URL.                                                           |
| `tags`                    | string[]  | Ei         | Julkisen kirjaston hakutunnisteet, esimerkiksi `["male","narration","zh"]`.      |
| `texts`                   | string[]  | Ei         | Viite-tekstit, jotka vastaavat näytettä (käytetään ääntämisen korjaamiseen).     |
| `enhance_audio_quality`   | boolean   | Ei         | Parannetaanko näytteen äänenlaatua ennen koulutusta.                            |
| `generate_sample`         | boolean   | Ei         | Luodaanko automaattisesti esimerkkiaudio koulutuksen jälkeen.                    |

> Kentät ovat täysin yhdenmukaisia ylävirran kanssa, katso myös [Fish virallinen dokumentaatio](https://docs.fish.audio/resources/api-reference/model).

## Esimerkki: Luo yksityinen kloonattu ääni

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Oma kloonattu ääni",
    "description": "Kloonattu kiinalainen ääni podcast-äänityksestä",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Huom: `voices` on oltava **merkkijono** (yksi äänitiedoston URL), ei taulukko. Jos se on muodossa `["..."]`, ylävirta hylkää sen.

Onnistunut vastaus palauttaa suoraan Fish-alustan ModelEntity-objektin (alla esimerkki, joka on testattu ja jossa on poistettu osia pitkistä kentistä luettavuuden vuoksi):


`_id` voidaan käyttää myöhemmin [Fish TTS API:ssä](https://platform.acedata.cloud/documents/fish-tts) `reference_id`-kentän arvona, kun käytetään tätä kloonattua ääntä puhesynteesissä:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hei, tämä on ääni, joka on syntetisoitu juuri luomallani kloonatulla äänellä.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Näytteen vaatimukset

Kokemustiedot (yhteensopiva ylävirran kanssa, katso [Fish virallinen dokumentaatio](https://docs.fish.audio/resources/api-reference/model)):

- Kesto suositellaan olevan yli 30 sekuntia, mutta alle 5 minuuttia on paras; yli 10 minuutin kohdalla marginaalinen hyöty on vähäinen.
- Näytteenottotaajuus 16 kHz tai enemmän, joko mono tai stereo.
- Sisältö mahdollisimman puhdasta: ei taustamusiikkia, kaikuja, selkeitä ympäristön meluja; sama puhuja.
- Suositeltu formaatti `mp3` / `wav`.

Jos et ole varma näytteen laadusta, voit myös lähettää `enhance_audio_quality: true`, jotta ylävirta voi ensin parantaa äänenlaatua.

## Laskutustiedot

Äänimallin kloonimallin luominen (`POST /fish/model`) on ilmaista, eikä siitä peritä maksuja; äänen hakurajapinnat ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) eivät myöskään aiheuta kuluja. Kustannuksia syntyy vain myöhemmistä [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) puhesynteesikutsuista käytön mukaan.

## Virheiden käsittely
- `400 token_mismatched`：Pyyntöparametri puuttuu tai on virheellinen (yleisin syy on, että `voices` ei ole URL-osoite tai se on annettu taulukkona).
- `401 invalid_token`：Todennus token ei ole olemassa tai se on virheellinen.
- `429 too_many_requests`：Tilin nopeusrajoitus on ylitetty.
- `500 api_error`：Palvelimen sisäinen virhe.

Virhevastauksen esimerkki:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices on pakollinen ja sen on oltava HTTP(S) URL, joka osoittaa äänitiedostoon"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Johtopäätös

Tämän rajapinnan kutsuminen vaatii vain julkisesti saatavilla olevan ääninäytteen URL-osoitteen valmistelun, jonka voit laittaa `voices`-kenttään saadaksesi `_id`, ja syöttää sen sitten `/fish/tts`-rajapinnan `reference_id`:hen, jolloin end-to-end "klonointi → synteesi" on valmis. Yleinen kompastuskivi on, että `voices` on oltava merkkijono, ei taulukko.
