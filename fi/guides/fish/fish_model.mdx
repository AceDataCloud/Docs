Tämä rajapinta perustuu [Fish Audion viralliseen Model API:in](https://docs.fish.audio/resources/api-reference/model), ja sitä käytetään **pitkäaikaisesti uudelleenkäytettävän kloonatun äänimallin luomiseen ääninäytteen perusteella**. Osoite on `POST https://api.acedata.cloud/fish/model`.

> Kun viiteääntä tarvitsee käyttää vain tilapäisesti, mallia ei tarvitse luoda, vaan voit käyttää suoraan [Fish TTS API:n](https://platform.acedata.cloud/documents/fish-tts) `references`-kenttää kertaluonteiseen välittömään kloonaukseen. Katso olemassa olevien äänien sivutettua hakua varten [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); katso yksittäisen äänen tietojen hakua `_id`:n perusteella varten [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Hakuprosessi

Käyttääksesi Fish Model API:a hae ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti tälle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita; sitä ei tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäinen hakemus sisältää ilmaista saldoa maksutonta kokeilua varten; kun saldo ei riitä, voit lisätä yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Pyynnön rungon kentät

| Kenttä                      | Tyyppi       | Pakollinen  | Kuvaus                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Kyllä   | Äänen nimi, jota käytetään tunnistamiseen konsoliluettelossa.                                                             |
| `voices`                | string   | Kyllä   | Ääninäytteen HTTP(S)-URL (**yksittäinen merkkijono**, ei taulukko). Tämä rajapinta ei tue multipart-/binäärilatauksia; tallenna ääni ensin mihin tahansa julkisesti käytettävään objektitallennukseen. |
| `description`           | string   | Ei   | Äänen kuvaus.                                                                         |
| `cover_image`           | string   | Ei   | Kansikuvan HTTP(S)-URL.                                                              |
| `tags`                  | string[] | Ei   | Julkisen kirjaston hakutunnisteet, esimerkiksi `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Ei   | Näytteitä vastaavat viitetekstit (ääntämisen korjaamiseen).                                                           |
| `enhance_audio_quality` | boolean  | Ei   | Parannetaanko näytteen äänenlaatua ennen koulutusta.                                                                |
| `generate_sample`       | boolean  | Ei   | Luodaanko esimerkkiääni automaattisesti koulutuksen valmistuttua.                                                            |

> Lisätietoja äänimalleista löytyy [Fishin virallisesta dokumentaatiosta](https://docs.fish.audio/resources/api-reference/model).

> Luodut äänet tallennetaan julkisesti pitkäaikaisesti, ja muut käyttäjät voivat mahdollisesti hakea ja käyttää niitä. `visibility`-kenttää ei tarvitse lähettää; vaikka lähettäisit `private` tai `unlist`, nykyinen rajapinta ei muuta julkisuusaluetta niiden perusteella.

## Esimerkki: julkisen kloonatun äänen luominen

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Huomautus: `voices` on oltava **merkkijono** (yksittäinen ääni-URL), ei taulukko. Ylävirta hylkää arvon, jos se lähetetään muodossa `["..."]`. Suosittelemme käyttämään julkisesti ladattavaa suoraa linkkiä, jonka pääte on `.mp3` tai `.wav`.

Onnistunut vastaus palauttaa suoraan Fish-alustan ModelEntity-objektin (alla oleva esimerkki on pienin testaamamme toimiva ääni, josta osa pitkistä kentistä on poistettu luettavuuden vuoksi):

`_id`-arvoa voidaan käyttää seuraavan [Fish TTS API:n](https://platform.acedata.cloud/documents/fish-tts) `reference_id`-kentän arvona, jotta tätä kloonattua ääntä voidaan käyttää puhesynteesiin:

Onnistuneesti luodut äänet tallennetaan julkisesti. Voit hakea nykyisen kutsuvan käyttäjän tämän alustan kautta luomat äänet käyttämällä [Fish Model Query API:n](https://platform.acedata.cloud/documents/fish-model-query) `self=true`-parametria. `self=true` suodattaa vain luetteloa eikä rajoita muiden käyttäjien mahdollisuutta käyttää tätä ääntä.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Näytevaatimukset

Kokemusperäiset arvot (ovat samat kuin ylävirrassa; katso [Fishin virallinen dokumentaatio](https://docs.fish.audio/resources/api-reference/model)):

- Suositeltu kesto on vähintään 30 sekuntia, ja paras tulos saavutetaan alle 5 minuutissa; yli 10 minuutista saatava lisähyöty on vähäinen.
- Näytteenottotaajuus vähintään 16 kHz; mono- tai stereoääni käy.
- Sisällön tulee olla mahdollisimman puhdasta: ei taustamusiikkia, kaikua tai selkeää ympäristömelua; sama puhuja.
- Suositellut muodot ovat `mp3` / `wav`.

Jos et ole varma näytteen laadusta, voit myös lähettää `enhance_audio_quality: true`, jolloin ylävirta parantaa ensin äänenlaatua.

## Hinnoitteluohjeet
音ivärikloonausmallin luominen (`POST /fish/model`) on ilmaista eikä siitä peritä mitään maksuja; myös äänivärin kyselyrajapinnoista ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) ei veloiteta. Maksuja syntyy vain, kun myöhemmin kutsutaan [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) -toimintoa puheen syntetisoimiseksi käytön mukaan.

## Virheenkäsittely

- `400 token_mismatched`: pyyntöparametrit puuttuvat tai ovat virheellisiä (yleisimmin `voices` ei ole URL tai se on välitetty taulukkona).
- `400`: jos viiteääntä ei voida ladata, sen kesto on liian lyhyt tai muotoa ei voida tunnistaa, tarkista äänen URL ja tiedostomuoto.
- `401 invalid_token`: todennustokenia ei ole olemassa tai se on virheellinen.
- `429 too_many_requests`: tilin nopeusrajoitus on aktivoitunut.
- `500 api_error`: palvelimen sisäinen virhe.

Esimerkki virhevastaus:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Johtopäätös

Tämän rajapinnan kutsumiseen tarvitsee valmistella vain julkisesti käytettävissä olevan näyteäänen URL, asettaa se `voices`-kenttään, jolloin saadaan `_id`; kun se syötetään `/fish/tts`-rajapinnan `reference_id`-kenttään, päästä päähän -prosessi ”kloonaus → synteesi” on valmis. Yleinen sudenkuoppa on, että `voices`-kentän on oltava merkkijono, ei taulukko.

## Äänivärin luominen ja uudelleenkäyttö MCP:n kautta

Kutsu Fish MCP:ssä
`fish_create_model(title="Äänivärini", voices="https://example.com/authorized-voice.wav")`。
`voices` on yksittäinen HTTP(S)-ääni-URL; myös `description`、`cover_image`、`tags`、
`texts`、`enhance_audio_quality`、`generate_sample` voidaan välittää.

Tämä työkalu tallentaa julkiset äänivärit pitkäaikaisesti, ja muut käyttäjät voivat löytää ja käyttää niitä; käytä vain ääniaineistoa, jonka käsittelyyn ja julkaisemiseen on lupa. Työkalussa ei ole yksityistä tai ei-julkista vaihtoehtoa. Onnistuneen luomisen palauttamaa `_id`:tä käytetään
`fish_generate_audio`-toiminnon `reference_id`-kentässä, ja `fish_list_models(self=true)` voi hakea itse tallennetut äänivärit. Kun viiteääntä tarvitaan vain kertaluonteisesti, käytä `fish_generate_audio`-toiminnon `references`-kenttää; pitkäaikaista ääniväriä ei tarvitse luoda.
