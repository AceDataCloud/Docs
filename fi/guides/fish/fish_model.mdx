Tässä dokumentissa esitellään Fish Model API:n liitäntäohjeet. Tämä rajapinta on täysin yhteensopiva [Fish Audio virallisen OpenAPI:n](https://docs.fish.audio/resources/api-reference/model) kanssa ja sisältää:

- `POST /fish/model`: Luo uusi kloonausäänimalli (Voice Model) ääninäytteen perusteella.
- `GET /fish/model`: Hakee sivutetun listan nykyisen tilin tai koko alustan näkyvissä olevista äänimalleista.

## Hakuprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua vastaavalta [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509) -sivulta ja klikata "Acquire"-painiketta.

Jos et ole kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakukerralla saat ilmaisen käyttökiintiön, jolla voit käyttää API:a maksutta.

## Erot viralliseen API:in verrattuna

- **Todennustapa**: Käytetään `Authorization: Bearer {token}` -otsikkoa, jossa `{token}` on tämän alustan kautta haettu avain.
- **Mallin luomisen näytteen lähetys**: Tämä rajapinta tukee tällä hetkellä vain JSON-muotoista lähettämistä, jossa `voices`-kenttään annetaan ääninäytteiden URL-osoitteet. Fish virallinen API tukee multipart/msgpack-muotoista binääridataa, mutta tämä alusta ei vielä tue sitä. URL-muoto kattaa noin 80 % yleisimmistä käyttötapauksista.
- **Vastausrakenne**: Sekä `POST /fish/model` että `GET /fish/model` välittävät Fish-alustan vastauksen suoraan ilman ylimääräistä käärettä. Virhetilanteissa käytetään alustan standardirakennetta `{success:false, error:{code,message}, trace_id}`.

## Äänimallin luominen (POST /fish/model)

Vähimmäispyyntö vaatii `title`- ja `voices`-kentät. `voices` on lista ääninäytteiden URL-osoitteista, suositeltava pituus on yli 30 sekuntia per tiedosto ja näytteenottotaajuus vähintään 16 kHz.

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "Minun kloonausäänimalli",
    "description": "Äänimalli kloonattu podcast-äänityksestä",
    "voices": [
      "https://example.com/sample-voice.mp3"
    ],
    "cover_image": "https://example.com/cover.png",
    "visibility": "private"
  }'
```

Onnistuneen vastauksen mukana palautetaan suoraan Fish-alustan ModelEntity-objekti:

```json
{
  "_id": "d7900c21663f485ab63ebdb7e5905036",
  "type": "tts",
  "title": "Minun kloonausäänimalli",
  "description": "Äänimalli kloonattu podcast-äänityksestä",
  "cover_image": "https://example.com/cover.png",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [],
  "created_at": "2025-05-09T12:34:56.789Z",
  "updated_at": "2025-05-09T12:34:56.789Z",
  "languages": ["zh", "en"],
  "visibility": "private",
  "lock_visibility": false,
  "like_count": 0,
  "mark_count": 0,
  "shared_count": 0,
  "task_count": 0,
  "author": {
    "_id": "user_id",
    "nickname": "user_nickname",
    "avatar": "user_avatar"
  }
}
```

Palautettu `_id` voidaan käyttää myöhemmissä `POST /fish/tts` -pyynnöissä `reference_id`-kentän arvona, jolloin kyseistä kloonausäänimallia käytetään puhesynteesiin.

## Äänimallien hakeminen (GET /fish/model)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

Käytettävissä olevat hakuehdot (yhtenevät Fish virallisen API:n kanssa):

- `page_size`: Sivun koko, oletus 10.
- `page_number`: Sivunumero, alkaa 1:stä.
- `title`: Haku otsikon mukaan (epätarkka haku).
- `tag`: Suodatus tunnisteen mukaan.
- `self`: Jos arvo on `true`, palauttaa vain nykyisen tilin luomat äänimallit.
- `author_id`: Suodatus tekijän mukaan.
- `language`: Suodatus äänimallin kielen mukaan.
- `title_language`: Suodatus otsikon kielen mukaan.

Onnistunut vastaus välittää suoraan Fish-alustan sivutetun rakenteen:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "Minun kloonausäänimalli",
      "description": "Äänimalli kloonattu podcast-äänityksestä",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
    }
  ],
  "total": 1
}
```

## Maksutiedot

Tämä rajapinta veloittaa ainoastaan "äänimallin luomisesta" (`POST /fish/model`, kun pyyntö sisältää `voices`-kentän). "Äänimallien hakeminen" (`GET /fish/model`) on maksutonta.

## Virheiden käsittely

- `400 token_mismatched`: Virheellinen pyyntö, mahdollisesti puuttuvat tai virheelliset parametrit.
- `400 api_not_implemented`: Virheellinen pyyntö, mahdollisesti puuttuvat tai virheelliset parametrit.
- `401 invalid_token`: Valtuuttamaton, virheellinen tai puuttuva todennustunnus.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt rajoituksen.
- `500 api_error`: Palvelinvirhe, palvelimella tapahtui virhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Yhteenveto

Fish Model API on täysin yhteensopiva Fish Audio virallisen OpenAPI:n ModelEntity-rajapinnan kanssa, joten olemassa oleva kloonausäänimallien hallintakoodi voidaan siirtää ilman koodimuutoksia. Luodun äänimallin `_id` voidaan suoraan antaa [Fish TTS API:n](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) `reference_id`-kenttään puhesynteesiä varten.
