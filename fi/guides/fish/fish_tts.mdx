Tämä rajapinta tarjoaa tekstistä puheeksi -toiminnon, tallennettujen äänten käytön ja kertaluonteisen välittömän äänikloonauksen. Osoite on `POST https://api.acedata.cloud/fish/tts`.

## Hakuprosessi

Jos haluat käyttää Fish TTS APIa, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään. Tämän jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluja, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäinen hakemus sisältää ilmaista käyttökiintiötä, joten palvelua voi kokeilla ilmaiseksi; jos kiintiö ei riitä, voit lisätä yleissaldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Fish TTS API →](https://platform.acedata.cloud/services/fish)

## Pyyntöotsakkeet

| Header          | Pakollinen  | Kuvaus                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | Kyllä   | `Bearer {token}`, jossa `{token}` on tältä alustalta haettu avain.                                                                 |
| `content-type`  | Kyllä   | `application/json`.                                                                                    |
| `accept`        | Ei   | `application/json`.                                                                                    |
| `model`         | Ei   | TTS-malli, vaihtoehdot ovat `s1`, `s2-pro` tai `s2.1-pro`, oletuksena `s2-pro`. `s2.1-pro` on uusin sukupolvi, `s2-pro` on ilmaisukykyinen; `s1` on vakaampi eikä pitkissä teksteissä helposti poikkea aiheesta. Kaikilla kolmella on sama hinta. |

## Pyyntörungon kentät

| Kenttä             | Tyyppi                 | Pakollinen  | Kuvaus                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | Kyllä   | Syntetisoitava teksti, ei-tyhjä merkkijono.                                                                                                                                                                                          |
| `format`       | string             | Ei   | Tulostettavan äänen muoto, vaihtoehdot `mp3` (oletus), `wav`, `pcm`. Sekä `wav` että `pcm` palautetaan WAV-säiliössä. `opus` ei ole tuettu, ja sen välittäminen palauttaa suoraan `400`.                                                                                                                  |
| `reference_id` | string \| string[] | Ei   | Tallennetun tai julkisen äänen mallitunnus, joka voidaan luoda [Fish Model APIlla](https://platform.acedata.cloud/documents/fish-model) tai hakea [Fish Model Queryssa](https://platform.acedata.cloud/documents/fish-model-query). Ei voida käyttää samanaikaisesti `references`-kentän kanssa. |
| `references`   | object[]           | Ei   | Kertaluonteinen välitön äänikloonaus, tukee vain yhtä `{audio, text}`-näytettä: `audio` on julkinen HTTPS MP3/WAV URL, ja `text` on äänen tarkka litterointi. Ei voida käyttää samanaikaisesti `reference_id`-kentän kanssa.                                                                                             |
| `sample_rate`  | integer            | Ei   | Näytteenottotaajuus, yleisiä arvoja ovat `16000`, `22050`, `44100`. `format=mp3` käyttää oletuksena arvoa 44100.                                                                                                                                                  |
| `mp3_bitrate`  | integer            | Ei   | MP3-bittinopeus, vaihtoehdot `64`, `128`, `192`. Vaikuttaa vain, kun `format=mp3`.                                                                                                                                                          |
| `prosody`      | object             | Ei   | Prosodian ohitus, tukee `speed`-arvoa (puheen nopeus, 1.0 on alkuperäinen nopeus) ja `volume`-arvoa (äänenvoimakkuuden vahvistus dB). Esimerkiksi `{"speed":1.2,"volume":0}`.                                                                                                                          |
| `chunk_length` | integer            | Ei   | Ylävirran lohkon pituus, oletusarvon määrittää ylävirta.                                                                                                                                                                                         |
| `temperature`  | number             | Ei   | Näytteenottolämpötila, alue noin 0.0–1.0.                                                                                                                                                                                      |
| `top_p`        | number             | Ei   | top-p-näytteenottoparametri.                                                                                                                                                                                            |
| `latency`      | string             | Ei   | `normal` tai `balanced`; jos puuttuu, tämä rajapinta täydentää automaattisesti arvon `normal` (tyhjän merkkijonon välittäminen suoraan hylätään ylävirrassa).                                                                                                                                                |
| `normalize`    | boolean            | Ei   | Normalisoidaanko teksti.                                                                                                                                                                                             |
| `callback_url` | string             | Ei   | Asynkronisen takaisinsoiton osoite, katso alempaa kohta ”Asynkroninen takaisinsoitto”. **Tämä on laajennus verrattuna viralliseen rajapintaan**.                                                                                                                                                                     |

> Kertaluonteinen kloonaus hyväksyy vain HTTPS-ääni-URL-osoitteet, eikä hyväksy MessagePackia, Base64:ää, data URI:ta tai tunnistetietoja sisältäviä URL-osoitteita. Suositeltu referenssiäänen pituus on 10–270 sekuntia; Studio käyttää varovaisempaa 10–60 sekunnin aluetta.

## Esimerkki 1: vähimmäispyyntö (`text` + `format=mp3`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

Palautus (testattu):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d-230825dfc559.mp3"
}
```

`audio_url` osoittaa tämän alustan CDN:ään, ja se voidaan ladata suoraan GET-pyynnöllä tai toistaa `<audio>`-elementissä. Lopullinen onnistunut vastaus palauttaa myös ylimmän tason `cost`-kentän, jossa `amount` on tällä kertaa todellisuudessa vähennettyjen Credits-yksiköiden määrä; jos tilillä on alennus, `list_amount` ilmaisee kiintiön ennen alennusta. Linkki on käytettävissä pitkään, mutta on silti suositeltavaa säilyttää kopio omassa tallennustilassasi.

## Esimerkki 2: kloonatun äänensävyn `reference_id` käyttö

Alla käytetään Fish-alustan julkista espanjankielistä äänensävyä (`_id` voidaan hakea [Fish Model Querylla](https://platform.acedata.cloud/documents/fish-model-query)):

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

Palautus (testattu):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/b6f161f2-a100-4818-add2-47694f234659-6532864739de.mp3"
}
```

## Esimerkki 3: kertaluonteinen välitön äänikloonaus (`references`)

Aseta referenssiääni julkiseen HTTPS-osoitteeseen ja anna siinä todella puhutun sisällön tarkka alkuperäinen teksti. Tätä ääntä käytetään vain tässä syntetisoinnissa, eikä pitkäaikaista mallia luoda:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://cdn.acedata.cloud/assets/examples/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9-570cfdf96ad9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```
Onnistuneesti testattu vastaus:

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/995dfe37-b187-474d-8323-b08d6678ed8f-6359be9f8873.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| Tapa             | Elinkaari       | Soveltuva käyttötapaus                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | Vain tämä TTS-pyyntö | Tilapäinen käyttö tai eri ääni joka kerta                   |
| `reference_id` | Uudelleenkäytettävä      | Julkinen ääni tai `/fish/model`-palvelun kautta luotu pitkäaikainen ääni |

## Esimerkki 3: puhenopeuden / äänenvoimakkuuden säätäminen (`prosody`)

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

Palautus (testattu):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
}
```

`speed`, joka on suurempi kuin 1, nopeuttaa ja pienempi kuin 1 hidastaa; `volume`-yksikkö on dB, 0 tarkoittaa muutosta, positiivinen arvo vahvistusta ja negatiivinen arvo vaimennusta.

## Esimerkki 5: mallin vaihtaminen + bittinopeuden hallinta

Vaihda vakaaseen malliin HTTP-otsakkeella `model: s1` ja lisää pyyntörunkoon `mp3_bitrate: 128` hallitaksesi MP3-bittinopeutta:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

Palautus (testattu):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e-6f11bf2f30e9.mp3"
}
```

## Esimerkki 6: PCM-raakaaaltomuoto

Tilanteissa, joissa tarvitaan reaaliaikaista yhdistämistä selaimessa tai jatkokäsittelyä asiakkaassa (miksaus, nopeuden muuttaminen), suositellaan `pcm`-muotoa:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

Palautus (testattu):

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
}
```

> Linkin tiedostopääte seuraa pyynnön `format`-arvoa: `mp3` tuottaa `.mp3`-tiedoston, `wav` ja `pcm` tuottavat `.wav`-tiedoston (WAV-säiliö, 16 bit PCM).

## Asynkroninen takaisinsoitto (`callback_url`)

Pitkän tekstin kertasyntetisointi voi kestää kymmenistä sekunneista useisiin kymmeniin sekunteihin, ja yhteyden katketessa tarvitaan uudelleenyritys. Kun pyyntörungossa välitetään `callback_url`, rajapinta palauttaa välittömästi `{task_id, started_at}`; kun palvelu valmistuu todella, se kutsuu kyseistä URL-osoitetta POST JSON -muodossa täydellisellä tuloksella, ja pyyntörunko sisältää saman `task_id`-arvon sekä tämän kerran lopullisen ylimmän tason `cost`-arvon. Alkuperäinen tehtävävahvistus ei ole vielä valmis syntetisointi, joten se ei sisällä `cost`-arvoa.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

Välitön palautus (testattu):

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

Myöhemmin `callback_url` vastaanottaa seuraavanlaisen:

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/bd66b8c5-7543-4557-b684-baa72407e336-52f2e79732f2.mp3"
}
```

Tulokset voidaan myös hakea aktiivisesti `task_id`-arvon perusteella [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) -rajapinnalla; lopputilan tietueen `response.cost` vastaa takaisinsoiton `cost`-arvoa, katso lisätiedot kyseisestä dokumentaatiosta.

## Virheenkäsittely

- `400 token_mismatched`: pyyntöparametrit puuttuvat tai ovat virheellisiä (yleisimmin `text` on tyhjä tai `format`-arvoksi annetaan muu arvo kuin `mp3`/`wav`/`pcm`).
- `401 invalid_token`: todennustunnusta ei ole tai se on virheellinen.
- `429 too_many_requests`: tilin nopeusrajoitus on laukaistu.
- `500 api_error`: palvelimen sisäinen virhe.

Esimerkki virhevastaus:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

Parametrien validointivirheet ilmoittavat virheellisen kentän `message`-kentässä, esimerkiksi:

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## Johtopäätös

Fish TTS:n käyttöönoton vähimmäiskustannus on: vaihda olemassa olevassa `api.fish.audio/v1/tts`-kutsukoodissa todennus tämän alustan tunnukseen ja lisää pyyntörunkoon **nimenomaisesti** `format: "mp3"`. Pitkän tekstin tilanteissa suositellaan `callback_url`-asynkronista takaisinsoittoa; kloonattujen äänensävyjen `reference_id`-arvojen löytämiseen käytä yhdessä [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)- ja [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) -rajapintoja.
