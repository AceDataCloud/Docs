Tässä dokumentissa esitellään Fish Model Query API:n (`GET /fish/model`) liitäntäohjeet. Tämä rajapinta on täysin yhteensopiva [Fish Audio virallisen OpenAPI:n](https://docs.fish.audio/resources/api-reference/model) kanssa, ja sitä käytetään **sivutettuun hakuun** nykyisen tilin tai koko alustan näkyvien kloonattujen äänivärien listasta.

> Äänivärin luomiseen katso [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a), yksittäisen äänivärin hakemiseen `_id`-kentän perusteella katso [Fish Model Get API](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9).

## Hakuprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua vastaavalta sivulta [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Sivulle tultuasi klikkaa "Acquire"-painiketta.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisen haun yhteydessä saat ilmaisen käyttöoikeuden, joten API:a voi käyttää ilmaiseksi.

## Erot viralliseen API:in nähden

- **Todennustapa**: Käytetään `Authorization: Bearer {token}` -otsikkoa, jossa `{token}` on alustalta haettu avain.
- **Vastausrakenne**: Fishin alkuperäinen sivutettu vastaus välitetään suoraan ilman alustan omaa envelope-rakennetta; virhetilanteissa käytetään alustan standardirakennetta `{success:false, error:{code,message}, trace_id}`.

## Pyyntöesimerkki

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=10' \
  --data-urlencode 'page_number=1' \
  --data-urlencode 'self=true'
```

## Hakuparametrit

Yhtenevät Fishin virallisen API:n kanssa:

- `page_size`: rivimäärä per sivu, oletus 10.
- `page_number`: sivunumero, alkaa arvosta 1.
- `title`: epätarkka haku otsikon perusteella.
- `tag`: suodatus tunnisteen mukaan.
- `self`: jos arvo on `true`, palautetaan vain nykyisen tilin luomat äänivärit.
- `author_id`: suodatus tekijän mukaan.
- `language`: suodatus äänivärin kielen mukaan.
- `title_language`: suodatus otsikon kielen mukaan.

## Vastausesimerkki

Onnistuneessa vastauksessa välitetään suoraan Fish-alustan sivutettu rakenne:

```json
{
  "items": [
    {
      "_id": "d7900c21663f485ab63ebdb7e5905036",
      "title": "我的克隆音色",
      "description": "用一段播客录音克隆的音色",
      "cover_image": "https://example.com/cover.png",
      "type": "tts",
      "state": "trained",
      "tags": [],
      "languages": ["zh", "en"],
      "visibility": "private",
      "created_at": "2025-05-09T12:34:56.789Z",
      "updated_at": "2025-05-09T12:34:56.789Z"
```

Palautettu `_id` voidaan käyttää myöhemmin [Fish TTS API:n](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) `reference_id`-kentän arvona, kun halutaan käyttää kyseistä kloonattua ääniväriä puhesynteesiin.

## Maksutiedot

Tämä rajapinta on maksuton — äänivärien sivutettu haku on ilmainen toimenpide. Vain `POST /fish/model` -pyyntö, jossa pyynnön rungossa on `voices`-kenttä uuden äänivärin luomiseksi, aiheuttaa maksun.

## Virheenkäsittely

- `400 token_mismatched`: puuttuvat tai virheelliset pyyntöparametrit.
- `400 api_not_implemented`: pyyntömenetelmä tai parametrit eivät ole tällä hetkellä tuettuja.
- `401 invalid_token`: puuttuva tai virheellinen todennustieto.
- `429 too_many_requests`: tilin rajoitukset ylitetty.
- `500 api_error`: palvelinvirhe.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Yhteenveto

Fish Model Query API tarjoaa täysin yhteensopivan äänivärien hakutoiminnon Fish Audion virallisen API:n kanssa, ja sitä voi käyttää oman kloonattujen äänivärien kirjaston ylläpitoon alustalla. Yhdessä [Fish Model Get API:n](https://platform.acedata.cloud/documents/dabdffe7-254b-5a3f-9eca-425d614d82b9) kanssa voi hakea yksittäisen äänivärin täydelliset tiedot ID:n perusteella.
