Tämä rajapinta perustuu [Fish Audio viralliseen Model API -rajapintaan](https://docs.fish.audio/resources/api-reference/model), ja sitä käytetään **Fishin julkisen äänikirjaston tai nykyisen tilin kloonattujen äänien sivutettuun hakuun**. Osoite on `GET https://api.acedata.cloud/fish/model`.

> Luo ääni tutustumalla [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model) -ohjeeseen; yksittäisen äänen tietojen hakemiseen `_id`:n perusteella tutustu [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get) -ohjeeseen.

## Hakuprosessi

Fish Model API:n käyttämiseksi siirry ensin [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud/console/applications) hakemaan oma API Tokenisi myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymistä ja kirjautumista varten. Kun olet valmis, sinut palautetaan automaattisesti takaisin nykyiselle sivulle.

**Yhdellä API Tokenilla voidaan kutsua kaikkia alustan palveluita, eikä jokaista palvelua varten tarvitse hakea erillistä käyttöoikeutta.** Ensimmäisen hakemuksen yhteydessä saat ilmaisen käyttömäärän, jolla voit kokeilla palvelua maksutta; kun määrä ei riitä, voit ladata yleistä saldoa [hallintapaneelissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydelliset dokumentit: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Kyselyparametrit

| Parametri          | Tyyppi    | Oletus | Kuvaus                                      |
| ---------------- | ------- | --- | --------------------------------------- |
| `page_size`      | integer | 10  | Rivien määrä sivua kohden.                                   |
| `page_number`    | integer | 1   | Sivunumero alkaen numerosta 1.                                 |
| `title`          | string  | —   | Hakee otsikon perusteella epätarkalla haulla.                                |
| `tag`            | string  | —   | Suodattaa yhden tunnisteen perusteella.                                |
| `self`           | boolean | —   | Kun arvo on `true`, palauttaa vain nykyisen tilin luomat äänet ilman lisäehtoja.          |
| `author_id`      | string  | —   | Suodattaa ylemmän tason käyttäjän `_id`:n perusteella.                         |
| `language`       | string  | —   | Suodattaa äänen kielen perusteella, kuten `en`, `zh`, `es`.               |
| `title_language` | string  | —   | Suodattaa otsikon kielen perusteella.                                |
| `sort_by`        | string  | —   | Järjestyskenttä, sama kuin ylemmällä tasolla, kuten `created_at`, `task_count`. |

> Parametrien nimet ovat täysin yhdenmukaiset ylemmän tason `GET https://api.fish.audio/model` -rajapinnan kanssa. Lisätietoja löytyy [Fishin virallisista dokumenteista](https://docs.fish.audio/resources/api-reference/model).

## Esimerkki 2: Epätarkka haku otsikon perusteella (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Palautus (testattu):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
```

Huomaa, että `title` tarkoittaa "yleistä epätarkkaa hakua", joten se löytää samanaikaisesti kaikki Fishin julkisen kirjaston äänet (ei pelkästään omiasi).

## Esimerkki 3: Luettele vain itse luodut äänet (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Palautus (testattu, nykyisellä tilillä on vain 1 ääni):

## Esimerkki 4: Suodata kielen + tunnisteen perusteella
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Ylävirta palauttaa myös tuloksia `tag`:ista, jota ei ole etikettisanastossa, mutta vastaavuus on suhteellisen löysä; jos osumien määrä on 0, suositellaan käyttämään `title` epätarkkaa vastaavuutta.

## Vastauskentät

`items[]` jokainen kohde on täydellinen ModelEntity-objekti, yleiset kentät:

| Kenttä         | Tyyppi    | Selitys                                             |
| -------------- | --------- | -------------------------------------------------- |
| `_id`          | merkkijono| Ääniväri ID, käytetään arvona `/fish/tts` sisällä `reference_id`. |
| `type`         | merkkijono| Mallin tyyppi, yleensä `tts`.                      |
| `title`        | merkkijono| Äänivärin nimi.                                    |
| `description`  | merkkijono| Äänivärin kuvaus.                                 |
| `state`        | merkkijono| Koulutustila: `trained` tarkoittaa, että se on käytettävissä. |
| `tags`         | merkkijono[] | Julkisen kirjaston etiketit.                     |
| `languages`    | merkkijono[] | Äänivärin hallitsemat kielet.                     |
| `visibility`   | merkkijono| `public` tai `private`.                            |
| `samples`      | objekti[] | Esiasetetut näytteet (sisältää `audio` suoran linkin). |
| `like_count`   | kokonaisluku| Julkisen kirjaston tykkäysten määrä.              |
| `task_count`   | kokonaisluku| Historiallisten synnin määrä.                      |
| `author`       | objekti   | Ylävirran kirjoittajan tiedot: `_id` / `nickname` / `avatar`. |
| `total` (ylätaso) | kokonaisluku| Ehtoja vastaavien kokonaismäärä.                  |
| `has_more`     | boolean?  | Ylävirran sivutuksen osoitus, voi olla `null`. Suositellaan käyttämään `total / page_size` kokonaismäärän laskemiseen. |

## Laskutusohjeet

Tämä rajapinta ei aiheuta kustannuksia - äänivärilistan sivutettu haku on ilmainen toiminto. Äänivärin luominen ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) on myös ilmaista, kustannuksia syntyy vain [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) äänen synnyttämisen yhteydessä käytön mukaan.

## Virheiden käsittely

- `400 token_mismatched`: Pyyntöparametreja puuttuu tai ne ovat virheellisiä.
- `401 invalid_token`: Valtakirja token ei ole olemassa tai se on virheellinen.
- `429 too_many_requests`: Tunnus ylittää nopeusrajoituksen.
- `500 api_error`: Palvelimen sisäinen virhe.

Virhevastauksen esimerkki:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Johtopäätös

Valitaksesi äänen Fishin julkisesta kirjastosta syötettäväksi `/fish/tts` `reference_id`:lle, käytä ensin tätä rajapintaa yhdessä `title` / `tag` / `language` hakujen kanssa, paikanna kohde `_id`, ja käytä sitten [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) saadaksesi näytteet kuunneltavaksi. Listataksesi itse luomasi äänivärit, lähetä `self=true`.
