Tämä rajapinta perustuu [Fish Audion viralliseen Model API:in](https://docs.fish.audio/resources/api-reference/model), ja sitä käytetään **Fishin julkisen äänikirjaston tai nykyisen tilin kloonattujen äänien sivutettuun hakemiseen**. Osoite on `GET https://api.acedata.cloud/fish/model`.

> Äänen luomista varten katso [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)；yksittäisen äänen tietojen hakemista `_id`:n perusteella varten katso [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)。

## Hakuprosessi

Jos haluat käyttää Fish Model API:a, hanki ensin API Tokenisi [Ace Data Cloud -konsolista](https://platform.acedata.cloud/console/applications) ja säilytä se myöhempää käyttöä varten.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle rekisteröitymään ja kirjautumaan sisään, minkä jälkeen palaat automaattisesti nykyiselle sivulle.

**Yhdellä API Tokenilla voi kutsua kaikkia alustan palveluita, eikä sitä tarvitse hakea erikseen jokaiselle palvelulle.** Ensimmäisellä hakukerralla saat ilmaista käyttökiintiötä, jolla voit kokeilla palvelua maksutta; jos käyttökiintiö ei riitä, voit lisätä yleistä saldoa [konsolissa](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Kyselyparametrit

| Parametri               | Tyyppi      | Oletus  | Kuvaus                                              |
| ---------------- | ------- | --- | ----------------------------------------------- |
| `page_size`      | integer | 10  | Tietueiden määrä sivua kohden.                                           |
| `page_number`    | integer | 1   | Sivunumero alkaen numerosta 1.                                         |
| `title`          | string  | —   | Epätarkka haku otsikon perusteella.                                        |
| `tag`            | string  | —   | Suodatus yhden tunnisteen perusteella.                                        |
| `self`           | boolean | —   | Kun arvo on `true`, palautetaan vain äänet, jotka nykyinen kutsuva tili on luonut ja tallentanut tämän alustan kautta.                 |
| `author_id`      | string  | —   | Suodatus äänen tekijän ID:n perusteella.                                    |
| `language`       | string  | —   | Suodatus äänen kielen perusteella, kuten `en`、`zh`、`es`。                       |
| `title_language` | string  | —   | Suodatus otsikon kielen perusteella julkisessa äänikirjastossa.                                 |
| `sort_by`        | string  | —   | Lajittelukenttä; kun `self=true`, tuetaan arvoja `created_at`、`task_count`。 |

> Parametrien nimet ovat täysin samat kuin ylävirran `GET https://api.fish.audio/model` -rajapinnassa, katso lisätietoja [Fishin virallisesta dokumentaatiosta](https://docs.fish.audio/resources/api-reference/model)。

## Esimerkki 1: Oletussivutus (`page_size`-parametrin mukaan)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Esimerkki 2: Epätarkka haku otsikon perusteella (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Palautus (testattu):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"

```

Huomaa, että `title` on ”globaali epätarkka vastaavuus”, joka osuu samanaikaisesti kaikkiin Fishin julkisen kirjaston ääniin (ei vain omiin).

## Esimerkki 3: Listaa vain itse luodut äänet (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Palautusesimerkki:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
`self=true` listaa nykyisen kutsutilin kautta tämän alustan avulla luodut ja tallennetut äänet; myös saman tilin eri API Token -tokeneilla luodut äänet listataan yhdessä. Tulokset sivutetaan luontiajan mukaan laskevassa järjestyksessä, ja `author_id` voi edelleen suodattaa näiden äänien tekijätunnuksen perusteella. Tämä parametri suodattaa vain listaa, äänet ovat edelleen julkisesti käytettävissä.

`self=true` ei tue `title_language`-parametria; jos haluat hakea otsikon kielen perusteella, hae julkisesta äänikirjastosta.

## Esimerkki 4: Suodatus kielen + tunnisteen perusteella

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Ylävirta palauttaa tuloksia myös sellaisille `tag`-arvoille, joita ei ole tunnistesanakirjassa, mutta vastaavuus on suhteellisen väljä; jos osumien määrä on 0, on suositeltavaa käyttää `title`-parametrilla sumeaa hakua.

## Vastauskentät

Jokainen `items[]`-kohde on täydellinen ModelEntity-objekti, yleisesti käytetyt kentät:

| Kenttä            | Tyyppi       | Kuvaus                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | Äänen ID, käytetään arvona `/fish/tts`-kohdan `reference_id`-parametrissa. |
| `type`        | string   | Mallityyppi, tavallisesti `tts`.                           |
| `title`       | string   | Äänen nimi.                                     |
| `description` | string   | Äänen kuvaus.                                     |
| `state`       | string   | Koulutustila: `trained` tarkoittaa, että se on käytettävissä.                      |
| `tags`        | string[] | Julkisen kirjaston tunnisteet.                                    |
| `languages`   | string[] | Kielet, joissa ääni on vahva.                                  |
| `visibility`  | string   | `public` tai `private`.                     |
| `samples`     | object[] | Esiasetetut näytteet (sisältää `audio`-suoralinkin).                       |
| `like_count`  | integer  | Julkisen kirjaston tykkäysten määrä.                                   |
| `task_count`  | integer  | Historiallisten synteesien määrä.                                   |
| `author`      | object   | Äänen tekijän tiedot: `_id` / `nickname` / `avatar`.     |
| `total`（ylätaso）   | integer  | Ehdot täyttävien kohteiden kokonaismäärä.                                 |
| `has_more`    | boolean? | `self=true`-tapauksessa totuusarvo; julkisen äänikirjaston kyselyissä voi olla `null`.      |

## Hinnoittelun kuvaus

Tästä rajapinnasta ei veloiteta — ääniluettelon sivutettu kysely on maksuton toiminto. Äänen luominen ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) on myös maksutonta, ja kustannuksia syntyy käytön mukaan vain, kun [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) -palvelua kutsutaan puheen synteesiä varten.

## Virheenkäsittely

- `400 token_mismatched`: Pyyntöparametri puuttuu tai on virheellinen.
- `401 invalid_token`: Todennustokenia ei ole olemassa tai se on virheellinen.
- `429 too_many_requests`: Tilin nopeusrajoitus on aktivoitunut.
- `500 api_error`: Palvelimen sisäinen virhe.

Esimerkki virhevastaus:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Johtopäätös

Jos haluat valita äänen Fishin julkisesta kirjastosta ja antaa sen `/fish/tts`-kohdan `reference_id`-parametrille, hae ensin tällä rajapinnalla käyttäen `title` / `tag` / `language`, paikanna kohde `_id` ja hae sitten näytteet kuunneltavaksi [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) -rajapinnalla. Jos haluat listata itse luomasi äänet, välitä vain `self=true`.
