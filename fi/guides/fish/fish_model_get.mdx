Tässä dokumentissa esitellään Fish Model Get API:n (`GET /fish/model/{id}`) liitäntäohje, joka on täysin yhteensopiva [Fish Audio virallisen OpenAPI:n](https://docs.fish.audio/resources/api-reference/model) kanssa. Tämä rajapinta on tarkoitettu **yksittäisen kloonatun äänen täydellisten tietojen hakemiseen äänen ID:n perusteella**.

> Äänen luomisesta katso [Fish Model Create API](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a), sivutettu listaushaku löytyy [Fish Model Query API:sta](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d).

## Hakemusprosessi

API:n käyttämiseksi sinun tulee ensin hakea palvelua vastaavalta sivulta [Fish Model API](https://platform.acedata.cloud/services/caf99abc-ddcf-4714-b2a5-862d9b469509). Sivulle siirryttyäsi klikkaa "Acquire"-painiketta.

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa voit rekisteröityä ja kirjautua sisään. Kirjautumisen jälkeen palaat automaattisesti tälle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisen käyttökiintiön, jolla voit käyttää API:a maksutta.

## Erot viralliseen API:in verrattuna

- **Todennustapa**: Käytetään `Authorization: Bearer {token}` -otsikkoa, jossa `{token}` on alustalta haettu avain.
- **Vastausrakenne**: Fishin ylävirran ModelEntity-objekti välitetään suoraan ilman alustan ympäröivää envelope-rakennetta; virhetilanteissa käytetään alustan standardirakennetta `{success:false, error:{code,message}, trace_id}`.
- **Polkuparametri**: `{id}` on äänen `_id`, joka saadaan [Fish Model Create API:n](https://platform.acedata.cloud/documents/62fdf4f1-6a05-4d92-bb15-1bf78b27a14a) luontivastauksesta tai [Fish Model Query API:n](https://platform.acedata.cloud/documents/5a9b3e03-2896-5606-a6b9-d9f4469f0e9d) sivutetusta hausta.

## Pyyntöesimerkki

```shell
curl 'https://api.acedata.cloud/fish/model/d7900c21663f485ab63ebdb7e5905036' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}'
```

Riittää, että korvaat URL-polun `{id}`:n varsinaisella äänen ID:llä, eikä muita kyselyparametreja tai pyyntörunkoa tarvita.

## Maksutiedot

Tämä rajapinta on maksuton — äänen tietojen hakeminen ID:n perusteella on ilmainen operaatio. Ainoastaan `POST /fish/model` -pyynnössä, jossa luodaan uusi ääni `voices`-kentän kanssa, veloitetaan.

## Virheenkäsittely

- `400 token_mismatched`: Pyyntöparametrit puuttuvat tai ovat virheellisiä.
- `400 api_not_implemented`: Pyyntömenetelmää tai parametreja ei tueta tällä hetkellä.
- `401 invalid_token`: Todennustiedot puuttuvat tai ovat virheellisiä.
- `404 not_found`: Määriteltyä `_id`:tä vastaavaa ääntä ei löydy tai se ei ole näkyvissä nykyiselle tilille.
- `429 too_many_requests`: Nykyisen tilin nopeusrajoitus ylittynyt.
- `500 api_error`: Palvelinvirhe.

### Virhevasteen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Yhteenveto

Fish Model Get API tarjoaa täysin yhteensopivan tavan hakea yksittäisen äänen tiedot Fish Audion virallisen rajapinnan tapaan. Saatuasi äänen ID:n voit tämän rajapinnan avulla hakea täydellisen ModelEntity-objektin (sisältäen näytteet, tilan, näkyvyyden, tilastot jne.) ja yhdistää sen [Fish TTS API:n](https://platform.acedata.cloud/documents/77adcb84-d59f-5ef9-b8a0-8b35eb42a71d) kanssa toteuttaaksesi kokonaisen kloonaus- ja synteesiprosessin.
