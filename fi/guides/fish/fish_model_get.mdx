Tämä rajapinta perustuu [Fish Audio viralliseen Model API:hin](https://docs.fish.audio/resources/api-reference/model) ja sitä käytetään **kysymään yksittäisen kloonivärin täydelliset tiedot `_id`:n mukaan**. Osoite on `GET https://api.acedata.cloud/fish/model/{id}`.

> Äänivärin luomiseen viitataan [Fish Model Create API:hin](https://platform.acedata.cloud/documents/fish-model); sivutettu haku viitataan [Fish Model Query API:hin](https://platform.acedata.cloud/documents/fish-model-query).

## Hakuprosessi

Käyttääksesi Fish Model API:ta, sinun on ensin hankittava API Token [Ace Data Cloud -hallintapaneelista](https://platform.acedata.cloud/console/applications) ja pidettävä se varalla.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään, ja sen jälkeen sinut ohjataan takaisin nykyiselle sivulle.

**Yksi API Token riittää kaikkien palveluiden kutsumiseen, eikä jokaiselle palvelulle tarvitse hakea erikseen.** Ensimmäisestä hakemuksesta saat ilmaisen määrän, jota voit kokeilla ilmaiseksi; jos määrä loppuu, voit ladata yleistä saldoa [hallintapaneelista](https://platform.acedata.cloud/console/coin).

> 📘 Täydellinen dokumentaatio: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Polkuparametrit

| Parametri | Pakollinen | Selitys                                                                                                                                                                                                |
| --------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Kyllä      | Äänivärin `_id` (32-merkkinen heksadesimaalinen merkkijono). Voit saada sen [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) -luomisen yhteydessä tai etsimällä [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) kautta. |

Ei pyyntöruumista, ei kyselyparametreja.

## Esimerkki: Hae julkisen espanjankielisen äänen täydelliset tiedot

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Ero listausrajapintaan

| Kenttä                                             | `GET /fish/model` (lista) | `GET /fish/model/{id}` (yksityiskohta) |
| -------------------------------------------------- | -------------------------- | --------------------------------------- |
| `samples[].audio`                                  | Lyhytaikainen R2-välimuisti URL | Nykyinen R2-suora linkki (sisältää kyselyn allekirjoituksen) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Samoin olemassa            | Samoin olemassa                         |
| `default_text` / `lock_visibility`                 | Samoin olemassa            | Samoin olemassa                         |

Jos haluat vain kuunnella, listausrajapinnan `samples[].audio` riittää; jos tarvitset vakaampaa latauslinkkiä, suosittelemme tämän rajapinnan käyttöä.

## Vastauskentät (poiminta)

| Kenttä          | Tyyppi    | Selitys                                          |
| --------------- | --------- | ----------------------------------------------- |
| `_id`           | string    | Äänivärin ID (käytetään `/fish/tts` -rajapinnan `reference_id`:ssä). |
| `type`          | string    | Mallin tyyppi, yleensä `tts`.                   |
| `title`         | string    | Äänivärin nimi.                                 |
| `description`   | string    | Pitkä kuvaus.                                   |
| `state`         | string    | Koulutustila: `trained` tarkoittaa käytettävissä, `training` tarkoittaa, että se on vielä koulutuksessa. |
| `tags`          | string[]  | Julkisen kirjaston tunnisteet.                 |
| `samples`       | object[]  | Esiasetetut näytteet, sisältäen `title`, `text`, `task_id`, `audio` suoran linkin. |
| `languages`     | string[]  | Äänivärin hallitsemat kielikoodit.              |
| `visibility`    | string    | `public` tai `private`.                         |
| `like_count`    | integer   | Julkisen kirjaston tykkäykset.                  |
| `task_count`    | integer   | Historiallisten synnynnäisten määrät (voidaan käyttää suosiolajittelun viitteenä). |
| `author`        | object    | Ylävirran kirjoittajan tiedot: `_id` / `nickname` / `avatar`. |
| `created_at`    | string    | ISO 8601 luontiaika.                           |
| `updated_at`    | string    | ISO 8601 viimeisin päivitysaika.                |

## Laskutustiedot

Tätä rajapintaa ei laskuteta - yksittäisen äänen tietojen kysyminen ID:n mukaan on ilmainen toimenpide. Äänivärin luominen ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) on myös ilmaista, kustannuksia syntyy vain [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) -rajapinnan äänen synnyttämisestä käytön mukaan.

## Virheiden käsittely
- `400 token_mismatched`: Polun `id` ei ole laillinen muoto, tai ylävirta ilmoittaa "Mallia ei löytynyt".
- `401 invalid_token`: Valtakirja token ei ole olemassa tai se on virheellinen.
- `404 not_found`: Määritetty `_id` ei ole näkyvissä Fish ylävirrassa (ääniprofiili on poistettu, yksityinen tai kuuluu toiselle tilille).
- `429 too_many_requests`: Käyttäjätilin nopeusrajoitus on ylitetty.
- `500 api_error`: Palvelimen sisäinen virhe.

Kun pyydetään olematonta ID:tä, ylävirta palauttaa suoraan `400 Model not found` (todistettu):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Palautus:

```json
{ "status": 400, "message": "Model not found" }
```

Virhevastauksen esimerkki:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Johtopäätös

Kun tiedetään ääniprofiilin `_id`, voidaan suoraan käyttää tätä rajapintaa saadakseen täydellinen ModelEntity, yleisimmät käyttötavat ovat: (1) kuunnella `samples[].audio`, (2) syöttää `_id` `/fish/tts`-rajapinnan `reference_id`:hen synnin loppuunsaattamiseksi. Jos vain otsikko tai tunniste on saatavilla, käytä ensin [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) -hakua.
