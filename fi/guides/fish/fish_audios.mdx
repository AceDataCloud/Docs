Tässä artikkelissa esitellään Fish Audios Generation API -liittymisohjeet, jonka avulla voit kloonata oman äänesi syöttämällä vihjeitä.

## Hakuprosessi

API:n käyttämiseksi sinun on ensin mentävä [Fish Audios Generation API](https://platform.acedata.cloud/documents/e681b715-54fd-4464-a59a-d7f14500e095) -sivulle ja haettava vastaavaa palvelua. Kun olet sivulla, napsauta "Acquire" -painiketta, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jos et ole vielä kirjautunut sisään tai rekisteröitynyt, sinut ohjataan automaattisesti kirjautumissivulle, jossa sinua kutsutaan rekisteröitymään ja kirjautumaan sisään. Kirjautumisen ja rekisteröitymisen jälkeen palaat automaattisesti nykyiselle sivulle.

Ensimmäisellä hakemiskerralla saat ilmaisia krediittejä, joiden avulla voit käyttää tätä API:a ilmaiseksi.

## Peruskäyttö

Ensinnäkin on hyvä ymmärtää peruskäyttötapa, joka sisältää vihjeen `prompt`, kloonaustoiminnan `action`, äänentunnuksen `voice_id` sekä mallin `model`, jotta saat käsitellyn tuloksen. Ensinnäkin sinun on yksinkertaisesti välitettävä `action`-kenttä, jonka arvo on `generate`, ja sitten meidän on syötettävä malli `model`, joka on tällä hetkellä pääasiassa `fish-tts`-malli, tarkat tiedot ovat seuraavat:

<p><img src="https://cdn.acedata.cloud/0jnfqb.png" width="500" className="m-auto" /></p>

Voit nähdä, että olemme asettaneet Request Headers -tiedot, mukaan lukien:

- `accept`: haluamasi vastausmuoto, tässä täytetään `application/json`, eli JSON-muoto.
- `authorization`: API:n kutsumiseen tarvittava avain, jonka voit valita suoraan alasvetovalikosta hakemisen jälkeen.

Lisäksi olemme asettaneet Request Body -tiedot, mukaan lukien:

- `model`: äänen kloonaamiseen käytettävä malli, pääasiassa `fish-tts`-malli.
- `action`: tämän äänen kloonaustehtävän toiminta.
- `prompt`: kloonattava vihje.
- `voice_id`: äänen kloonaaminen äänentunnuksen mukaan.
- `callback_url`: URL, johon tulokset palautetaan.

Valinnan jälkeen voit huomata, että oikealla puolella on myös luotu vastaava koodi, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/8uyos2.png" width="500" className="m-auto" /></p>

Napsauta "Try" -painiketta testataksesi, kuten yllä olevassa kuvassa näkyy, ja saamme seuraavan tuloksen:

```json
{
  "success": true,
  "task_id": "5872ab00-3cf4-4040-a798-8510aaa16756",
  "trace_id": "5eda3694-448a-4b72-af33-2acb3851ffe1",
  "data": [
    {
      "audio_url": "https://platform.r2.fish.audio/task/8a72ff9840234006a9f74cb2fa04f978.mp3"
    }
  ]
}
```

Palautetussa tuloksessa on useita kenttiä, jotka esitellään seuraavasti:

- `success`, kloonauksen äänen tehtävän tila.
  - `data`, kloonauksen äänen tehtävän tulos
    - `audio_url`, kloonauksen äänen tehtävän äänilinkki.

Voit nähdä, että olemme saaneet tyydyttävän äänen tiedot, ja meidän tarvitsee vain käyttää tuloksessa olevan `data`-kentän musiikkilinkkiä saadaksemme kloonatun äänen.

Jos haluat luoda vastaavan liittymiskoodin, voit kopioida sen suoraan, esimerkiksi CURL-koodi on seuraava:

```shell
curl -X POST 'https://api.acedata.cloud/fish/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "speech",
  "prompt": "a white siamese cat",
  "model": "fish-tts",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036"
}'
```

## Asynkroninen palautus

Koska Fish Audios Generation API:n luomiseen kuluu suhteellisen pitkä aika, noin 1-2 minuuttia, jos API ei vastaa pitkään aikaan, HTTP-pyyntö pitää yhteyden auki, mikä johtaa ylimääräisiin järjestelmäresurssien kulutuksiin. Siksi tämä API tarjoaa myös asynkronisen palautuksen tuen.

Kokonaisprosessi on seuraava: kun asiakas lähettää pyynnön, se määrittää ylimääräisen `callback_url`-kentän. Kun asiakas lähettää API-pyynnön, API palauttaa heti tuloksen, joka sisältää `task_id`-kentän tiedot, joka edustaa nykyistä tehtävä ID:tä. Kun tehtävä on valmis, luotujen tehtävien tulokset lähetetään POST JSON -muodossa asiakkaan määrittämään `callback_url`:iin, johon sisältyy myös `task_id`-kenttä, jolloin tehtävän tulokset voidaan liittää ID:n avulla.

Katsotaanpa esimerkin avulla, miten tämä toimii.

Ensinnäkin Webhook-palaute on palvelu, joka voi vastaanottaa HTTP-pyyntöjä, ja kehittäjän tulisi korvata se omalla HTTP-palvelimensa URL-osoitteella. Tässä esimerkin vuoksi käytämme julkista Webhook-esimerkkisivustoa https://webhook.site/, avaa tämä sivusto saadaksesi Webhook URL:n, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/tbcnai.png)

Kopioi tämä URL, niin voit käyttää sitä Webhookina, tässä esimerkki on `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`.

Seuraavaksi voimme asettaa kentän `callback_url` yllä mainituksi Webhook URL:ksi ja täyttää vastaavat parametrit, tarkat tiedot ovat seuraavat, kuten kuvassa näkyy:

<p><img src="https://cdn.acedata.cloud/8rv4te.png" width="500" className="m-auto" /></p>

Napsauta Suorita, ja huomaat, että saat heti tuloksen, kuten seuraavassa:

```
{
  "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5"
}
```

Odota hetki, ja voit tarkastella luotujen tehtävien tuloksia osoitteessa `https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34`, kuten kuvassa näkyy:

![](https://cdn.acedata.cloud/9utzve.png)

Sisältö on seuraava:

```json
{
    "success": true,
    "task_id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
    "trace_id": "e2d308bc-4df8-4c69-9369-a60f3c54f2b3",
    "data": [
        {
            "audio_url": "https://platform.r2.fish.audio/task/b627c2f7d38a4083a837570ba6d0962f.mp3"
        }
    ]
}
```

Voit nähdä, että tuloksessa on `task_id`-kenttä, ja muut kentät ovat samankaltaisia kuin edellä, ja tämän kentän avulla voit liittää tehtävät yhteen.

## Virheiden käsittely

API:a kutsuttaessa, jos kohtaat virheitä, API palauttaa vastaavat virhekoodit ja tiedot. Esimerkiksi:

- `400 token_mismatched`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `400 api_not_implemented`: Huono pyyntö, mahdollisesti puuttuvien tai virheellisten parametrien vuoksi.
- `401 invalid_token`: Ei valtuutettu, virheellinen tai puuttuva valtuutusavain.
- `429 too_many_requests`: Liian monta pyyntöä, olet ylittänyt nopeusrajoituksen.
- `500 api_error`: Sisäinen palvelinvirhe, jotain meni pieleen palvelimella.

### Virhevastauksen esimerkki

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
