Kaikki Ace Data Cloud API:t käyttävät **Bearer Token** -todennusta.

## Tokenin hankkiminen

Kirjaudu [Applications](https://platform.acedata.cloud/console/applications?lang=fi&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)-sivulle ja avaa **General Application**. Jos sovellusta ei vielä näy, valitse **Initialize General Application**. Napsauta **API KEY** -kentän vieressä olevaa kopiointipainiketta, joka on merkitty kuvaan numerolla **1**.

![Numerolla 1 merkitty API-avaimen kopiointipainike](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Säilytä avain palvelimella ja korvaa esimerkin `YOUR_API_TOKEN` kopioimallasi arvolla.

## Tokenin käyttäminen

Sisällytä Token jokaisen pyynnön `Authorization`-otsikkoon:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Nopeusrajoitukset

Nopeusrajoitukset vaihtelevat palvelun ja tilausluokan mukaan. Rajoituksen ylittäessä API palauttaa `429 Too Many Requests` -vastauksen.

## Turvallisuuden parhaat käytännöt

- Älä paljasta API Tokenia asiakaskoodissa
- Tallenna Token ympäristömuuttujiin
- Kierrätä Tokenia säännöllisesti
- Käytä eri Tokeneita kehitys- ja tuotantoympäristöissä
