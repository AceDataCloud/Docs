---
title: "Todennus"
description: "Kuinka käyttää Ace Data Cloud API:a todennukseen"
---

Kaikki Ace Data Cloud API -kutsut käyttävät **Bearer Token** -todennusta.

## Tokenin hankkiminen

1. Rekisteröidy osoitteessa [platform.acedata.cloud](https://platform.acedata.cloud)
2. Tilaa tarvittavat palvelut
3. Luo jokaiselle palvelulle tunnistetiedot (API Token)

## Tokenin käyttäminen

Sisällytä Token jokaisen pyynnön `Authorization`-otsikkoon:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Jokainen Token on sidottu tiettyyn palvelutilaukseen. Eri palvelut käyttävät eri Tokeneita, tai voit luoda **yleisen** tunnistetiedon palveluiden välillä käytettäväksi.
</Note>

## Nopeusrajoitukset

Nopeusrajoitukset vaihtelevat palvelun ja tilausluokan mukaan. Rajoituksen ylittäessä API palauttaa `429 Too Many Requests` -vastauksen.

## Turvallisuuden parhaat käytännöt

- Älä paljasta API Tokenia asiakaspuolen koodissa
- Tallenna Token ympäristömuuttujiin
- Kierrätä Tokenia säännöllisesti
- Käytä eri Tokeneita kehitys- ja tuotantoympäristöissä
