## Johdanto

Localization on Ace Data Cloudin tarjoama työkalupalvelu, joka tarjoaa tekoälypohjaisen käännöspalvelun. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Localizationin JavaScriptillä ja toteuttaa Markdown-käännöksiä, JSON-käännöksiä, 18 kieltä sekä säilyttää muotoilun.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Localization API:n päätepiste on:

```
POST https://api.acedata.cloud/localization/translate
```

Tässä esimerkissä käytetään `gpt-4`-mallia. Saatavilla olevat mallit ovat: `gpt-3.5`, `gpt-4`.

Täysi JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/localization/translate", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "input": "# 欢迎使用\n\n这是一段示例文本。",
  "locale": "en",
  "extension": "md",
  "model": "gpt-4"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callLocalization(data) {
  const response = await fetch("https://api.acedata.cloud/localization/translate", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys                         |
|-------------|--------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai pääsy evätty   |
| 429         | Liian monta pyyntöä            |
| 500         | Palvelimen sisäinen virhe      |
