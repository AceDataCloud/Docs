## Johdanto

Localization on Ace Data Cloudin tarjoama työkalupalvelu, joka tarjoaa tekoälypohjaista käännöspalvelua lokalisaatioon. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia Localization-palvelun nopeaan kutsumiseen, jolloin voit toteuttaa Markdown-käännöksiä, JSON-käännöksiä, 18 eri kielen tuen sekä säilyttää muotoilun.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkinut API-tokenin
- cURL asennettuna komentoriviympäristöön

## Peruskäyttö

Localization API:n päätepiste on:

```
POST https://api.acedata.cloud/localization/translate
```

Tässä esimerkissä käytetään `gpt-4`-mallia.
Saatavilla olevat mallit ovat: `gpt-3.5`, `gpt-4`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai pääsy estetty |
| 429         | Pyyntöjen määrä ylitti rajan     |
| 500         | Palvelimen sisäinen virhe        |
