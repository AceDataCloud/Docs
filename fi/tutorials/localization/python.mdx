## Johdanto

Localization on Ace Data Cloudin tarjoama työkalupalvelu, AI-käännöspalvelu paikallistamiseen. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää Pythonia nopeasti Localizationin integroimiseen, toteuttaen Markdown-käännöksen, JSON-käännöksen, 18 kielen tuen ja muotoilun säilyttämisen.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- Python 3.7 tai uudempi ympäristö
- Asentaa requests-kirjasto: `pip install requests`

## Peruskäyttö

Localization API:n päätepiste on:

```
POST https://api.acedata.cloud/localization/translate
```

Tässä esimerkissä käytetään `gpt-4` mallia.
Saatavilla olevat mallit: `gpt-3.5`, `gpt-4`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/localization/translate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "input": "# 欢迎使用\n\n这是一段示例文本。",
    "locale": "en",
    "extension": "md",
    "model": "gpt-4"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevien API:en kanssa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:n kautta palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API Token |
| 403       | Ei saldoa tai käyttöoikeutta |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe |
