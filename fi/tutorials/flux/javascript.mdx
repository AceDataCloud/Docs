## Johdanto

Flux on Ace Data Cloudin tarjoama tekoälykuvapalvelu, Black Forest Labsin Flux-kuvageneraatiomalli. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Fluxin nopeasti JavaScriptillä ja toteuttaa tekstistä kuvaan -toimintoja, kuvanmuokkausta, erilaisia malleja ja mukautettuja kokoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Flux API:n päätepiste on:

```
POST https://api.acedata.cloud/flux/images
```

Tässä esimerkissä käytetään `flux-pro-1.1` mallia.
Saatavilla olevat mallit: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Täysi JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/flux/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat sitting on a windowsill",
  "model": "flux-pro-1.1",
  "size": "1024x1024"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callFlux(data) {
  const response = await fetch("https://api.acedata.cloud/flux/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai ei oikeutta käyttää |
| 429 | Liian monta pyyntöä |
| 500 | Palvelinvirhe |
