---

## Johdanto

Flux on Ace Data Cloudin tarjoama tekoälykuvapalvelu, Black Forest Labsin Flux-kuvageneraatiomalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia Fluxin nopeaan kutsumiseen, toteuttaen tekstistä kuvaan -toimintoja, kuvanmuokkausta, erilaisia malleja ja mukautettuja kokoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Flux API:n päätepiste on:

```
POST https://api.acedata.cloud/flux/images
```

Tässä esimerkissä käytetään `flux-pro-1.1` mallia.
Saatavilla olevat mallit ovat: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai pääsy evätty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
