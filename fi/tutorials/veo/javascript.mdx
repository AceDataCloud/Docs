## Johdanto

Veo on Ace Data Cloudin tarjoama tekoälypohjainen videoservice, joka perustuu Google Veo -videogeneraatiomalliin. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Veon JavaScriptillä ja toteuttaa tekstistä videoon, kuvasta videoon, 4K-resoluution, erilaiset kuvasuhteet ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Veo API:n päätepiste on:

```
POST https://api.acedata.cloud/veo/videos
```

Tässä esimerkissä käytetään `veo3`-mallia.
Saatavilla olevat mallit ovat: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/veo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "prompt": "A coffee mug rotating slowly on a marble counter",
  "model": "veo3"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callVeo(data) {
  const response = await fetch("https://api.acedata.cloud/veo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys                         |
|-------------|--------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Ei riittävästi saldoa tai käyttöoikeutta |
| 429         | Pyyntöjen määrä ylitti rajan   |
| 500         | Palvelimen sisäinen virhe      |
