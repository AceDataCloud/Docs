## Johdanto

Veo on Ace Data Cloudin tarjoama AI-videopalvelu, Google Veo -videon generointimalli. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Veon nopeasti Pythonilla ja toteuttaa tekstistä videoon, kuvasta videoon, 4K-resoluution, erilaiset kuvasuhteet ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Token
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Veo API:n päätepiste on:

```
POST https://api.acedata.cloud/veo/videos
```

Tässä esimerkissä käytetään `veo3` mallia. Saatavilla olevat mallit ovat: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Kokonainen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A coffee mug rotating slowly on a marble counter",
    "model": "veo3"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Ei saldoa tai oikeuksia |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
