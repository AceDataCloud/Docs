title: "Veo cURL pikaopas"
---

## Johdanto

Veo on Ace Data Cloudin tarjoama tekoälyvideoiden palvelu, Google Veo -videomallilla. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Veon kutsumiseen ja toteuttaa tekstistä videoon, kuvasta videoon, 4K-resoluution, erilaiset kuvasuhteet ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Veo API:n päätepiste on:

```
POST https://api.acedata.cloud/veo/videos
```

Tässä esimerkissä käytetään `veo3`-mallia. Saatavilla olevat mallit ovat: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}' | jq .
```

## Virheiden käsittely

Yleiset virhekoodit:

| Tila | Selitys |
|--------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää rajan |
| 500 | Palvelinvirhe |
