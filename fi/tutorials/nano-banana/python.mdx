## Johdanto

Nano Banana on Ace Data Cloudin tarjoama tekoälypohjainen kuvapalvelu, joka perustuu Geminin kuvageneraattoripalveluun. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Nano Bananan Pythonilla ja hyödyntää tekstistä kuvaan -muunnosta, kuvanmuokkausta, erilaisia kuvasuhteita ja korkearesoluutioisia kuvia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token [Ace Data Cloud](https://platform.acedata.cloud)
- Python 3.7 tai uudempi
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Nano Banana API:n päätepiste on:

```
POST https://api.acedata.cloud/nano-banana/images
```

Tässä esimerkissä käytetään mallia `nano-banana-2`. Saatavilla olevat mallit ovat: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat",
    "model": "nano-banana-2",
    "aspect_ratio": "1:1"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

API:t, jotka tukevat asynkronisia tehtäviä, voivat palauttaa tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Ei saldoa tai oikeuksia |
| 429       | Pyynnön taajuus ylitetty |
| 500       | Palvelinvirhe |
