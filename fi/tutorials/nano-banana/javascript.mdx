## Johdanto

Nano Banana on Ace Data Cloudin tarjoama tekoälypohjainen kuvapalvelu, joka perustuu Gemini-kuvageneraattoriin. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Nano Bananan JavaScriptillä ja hyödyntää tekstistä kuvaan -toimintoja, kuvanmuokkausta, erilaisia kuvasuhteita ja korkearesoluutioisia kuvia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Nano Banana API:n päätepiste on:

```
POST https://api.acedata.cloud/nano-banana/images
```

Tässä esimerkissä käytetään `nano-banana-2` mallia.
Saatavilla olevat mallit ovat: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat",
  "model": "nano-banana-2",
  "aspect_ratio": "1:1"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausten käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callNanoBanana(data) {
  const response = await fetch("https://api.acedata.cloud/nano-banana/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelinvirhe |
