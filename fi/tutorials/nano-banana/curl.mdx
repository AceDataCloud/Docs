title: "Nano Banana cURL pikaopas"
---

## Johdanto

Nano Banana on Ace Data Cloudin tarjoama tekoälykuvapalvelu, joka perustuu Gemini-kuvageneraattoriin. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti Nano Banana -palvelun kutsumiseen ja hyödyntää tekstistä kuvaan -generointia, kuvankäsittelyä, erilaisia kuvasuhteita ja korkearesoluutioisia kuvia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Nano Banana API:n päätepiste on:

```
POST https://api.acedata.cloud/nano-banana/images
```

Tässä esimerkissä käytetään mallia `nano-banana-2`. Saatavilla olevat mallit ovat: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                        |
|-------------|-------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai käyttöoikeus puuttuu  |
| 429         | Pyyntöjen määrä ylittää rajan             |
| 500         | Palvelimen sisäinen virhe                  |
