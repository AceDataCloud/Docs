## Johdanto

ADSL HTTP Proxy on Ace Data Cloudin tarjoama verkkovälityspalvelu, joka mahdollistaa ADSL-dynaamisten välityspalvelin-IP-osoitteiden hakemisen. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida ADSL HTTP Proxyn Pythonilla ja hyödyntää HTTP/SOCKS-välityspalvelimia, monia operaattoreita, useita maakuntia, mukautettua kestoa, IP-valkoinen lista -toimintoja ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

ADSL HTTP Proxy API:n päätepiste on:

```
POST https://api.acedata.cloud/adsl/extract
```

Kokonainen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429       | Pyyntöjen taajuus ylitetty |
| 500       | Palvelimen sisäinen virhe |
