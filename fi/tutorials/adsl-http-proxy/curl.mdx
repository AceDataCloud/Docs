## Johdanto

ADSL HTTP Proxy on Ace Data Cloudin tarjoama verkkovälityspalvelu, joka tarjoaa ADSL-dynaamisia välityspalvelimen IP-osoitteita. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti kutsuaksesi ADSL HTTP Proxy -palvelua ja hyödyntää HTTP/SOCKS-välityspalvelinta, useita operaattoreita, useita maakuntia, mukautettua kestoa, IP-valkoinen lista -toimintoja ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

ADSL HTTP Proxy API:n päätepiste on:

```
POST https://api.acedata.cloud/adsl/extract
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys                         |
|-------------|--------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai pääsy estetty |
| 429         | Pyyntöjen määrä ylitti rajan    |
| 500         | Palvelimen sisäinen virhe       |
