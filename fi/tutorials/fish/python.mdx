## Johdanto

Fish TTS on Ace Data Cloudin tarjoama AI-äänipalvelu, Fish-puheensynteesipalvelu. Ace Data Cloudin yhtenäisen API:n kautta voit nopeasti integroida Fish TTS:n Pythonilla ja toteuttaa tekstistä puheeksi -muunnoksen, erilaiset äänivaihtoehdot, mukautetut äänet ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Fish TTS API:n päätepiste on:

```
POST https://api.acedata.cloud/fish/audios
```

Tässä esimerkissä käytetään `fish-tts` mallia. Saatavilla olevat mallit: `fish-tts`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/fish/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "speech",
    "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
    "voice_id": "d7900c21663f485ab63ebdb7e5905036",
    "model": "fish-tts"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelinvirhe |
