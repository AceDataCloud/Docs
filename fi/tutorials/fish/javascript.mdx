## Johdanto

Fish TTS on Ace Data Cloudin tarjoama AI-äänipalvelu, Fish-puheentunnistuspalvelu. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Fish TTS:n JavaScriptillä ja toteuttaa tekstistä puheeksi -toimintoja, monia ääniä, mukautettuja ääniä ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Fish TTS API:n päätepiste on:

```
POST https://api.acedata.cloud/fish/audios
```

Tässä esimerkissä käytetään `fish-tts` -mallia. Saatavilla olevat mallit: `fish-tts`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/fish/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "speech",
  "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036",
  "model": "fish-tts"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, tilakoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callFishTTS(data) {
  const response = await fetch("https://api.acedata.cloud/fish/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Ei saldoa tai oikeutta käyttää |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe |
