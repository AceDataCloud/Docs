title: "Fish TTS cURL pikaopas"
---

## Johdanto

Fish TTS on Ace Data Cloudin tarjoama tekoälypohjainen äänipalvelu, Fish-puheentunnistuspalvelu. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Fish TTS:n kutsumiseen ja toteuttaa tekstistä puheeksi -muunnoksen, erilaiset äänivaihtoehdot sekä mukautetut äänet.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Fish TTS API:n päätepiste on:

```
POST https://api.acedata.cloud/fish/audios
```

Tässä esimerkissä käytetään `fish-tts` -mallia.
Saatavilla olevat mallit: `fish-tts`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                         |
|-------------|--------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai pääsy estetty |
| 429         | Pyyntöjen määrä ylittää rajan   |
| 500         | Palvelimen sisäinen virhe      |
