---

## Johdanto

hCaptcha on Ace Data Cloudin tarjoama captcha-palvelu ja hCaptcha-ratkaisu. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida hCaptchan JavaScriptillä ja toteuttaa hCaptcha-tokenin hakemisen, hCaptcha-kuvantunnistuksen ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkinut API-tokenin
- Node.js 18+ tai nykyaikainen selaimen ympäristö

## Peruskäyttö

hCaptcha API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Täydellinen JavaScript-esimerkkikoodi:

```javascript
const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
  "website_url": "https://accounts.hcaptcha.com/demo"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` todellisella tokenillasi, jonka olet saanut Ace Data Cloud -alustalta.

## Vastausten käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callhCaptcha(data) {
  const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai ei oikeutta käyttää |
| 429 | Pyyntöjen määrä ylittää rajan |
| 500 | Palvelimen sisäinen virhe |
