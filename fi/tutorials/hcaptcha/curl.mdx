title: "hCaptcha cURL pikaopas"
---

## Johdanto

hCaptcha on Ace Data Cloudin tarjoama CAPTCHA-palvelu ja hCaptcha-ratkaisu. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti hCaptchan kutsumiseen, kuten hCaptcha-tokenin hankkimiseen ja hCaptcha-kuvien tunnistukseen.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkinut API-tokenin
- cURL asennettuna komentoriville

## Peruskäyttö

hCaptcha API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                      |
|-------------|-----------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai ei oikeutta käyttää |
| 429         | Pyyntöjen määrä ylittää rajan |
| 500         | Palvelimen sisäinen virhe   |
