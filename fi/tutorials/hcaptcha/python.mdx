## Johdanto

hCaptcha on Ace Data Cloudin tarjoama CAPTCHA-palvelu ja hCaptcha-ratkaisu. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida hCaptchan Pythonilla ja toteuttaa hCaptcha-tokenin hankinnan sekä hCaptcha-kuvien tunnistuksen.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

hCaptcha API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/hcaptcha"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
    "website_url": "https://accounts.hcaptcha.com/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa tulokset voidaan saada takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys                        |
|-----------|-------------------------------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo loppu tai käyttöoikeus puuttuu |
| 429       | Pyyntöjen rajoitus ylittynyt  |
| 500       | Palvelimen sisäinen virhe     |
