## Johdanto

Midjourney on Ace Data Cloudin tarjoama tekoälykuvapalvelu, Midjourney AI-kuvageneraattori. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti kutsuaksesi Midjourney-palvelua ja toteuttaa tekstistä kuvaan -toimintoja, kuvien muokkausta, kuvien kuvailua, kuvasta videoon -muunnoksia, Seed-ohjausta, asynkronisia callback-toimintoja ja muita ominaisuuksia.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkinut API-tokenin
- cURL asennettuna komentoriville

## Peruskäyttö

Midjourney API:n päätepiste on:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai pääsy estetty   |
| 429         | Pyyntöjen määrä ylitti rajan    |
| 500         | Palvelimen sisäinen virhe       |
