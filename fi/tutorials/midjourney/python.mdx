## Johdanto

Midjourney on Ace Data Cloudin tarjoama tekoälykuvapalvelu, Midjourney AI-kuvageneraattori. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Midjourneyn Pythonilla ja toteuttaa tekstistä kuvaan, kuvan muokkaus, kuvan kuvaus, kuvasta videoon, siemenen hallinta, asynkroniset callbackit ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- Python 3.7 tai uudempi ympäristö
- Asenna requests-kirjasto: `pip install requests`

## Peruskäyttö

Midjourney API:n päätepiste on:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/midjourney/imagine"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A serene Japanese garden with cherry blossoms",
    "action": "generate",
    "mode": "fast",
    "translation": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:iin palvelimellesi
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
