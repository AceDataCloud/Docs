## Johdanto

Midjourney on Ace Data Cloudin tarjoama tekoälykuvapalvelu, joka mahdollistaa Midjourney AI -kuvageneraation. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Midjourneyn JavaScriptillä ja hyödyntää tekstistä kuvaan -toimintoja, kuvien muokkausta, kuvien kuvailua, kuvasta videoon -muunnoksia, Seed-ohjausta, asynkronisia callback-toimintoja ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Midjourney API:n päätepiste on:

```
POST https://api.acedata.cloud/midjourney/imagine
```

Kokonainen JavaScript-esimerkkikoodi:

```javascript
const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A serene Japanese garden with cherry blossoms",
  "action": "generate",
  "mode": "fast",
  "translation": true
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callMidjourney(data) {
  const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai ei käyttöoikeutta |
| 429 | Liian monta pyyntöä lyhyessä ajassa |
| 500 | Palvelinvirhe |
