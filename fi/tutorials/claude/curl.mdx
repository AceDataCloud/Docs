## Johdanto

Claude on Ace Data Cloudin tarjoama tekoälypohjainen keskustelupalvelu, joka perustuu Anthropic Clauden sarjan suuriin kielimalleihin. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti Claude-palvelun kutsumiseen ja hyödyntää monikierroksisia keskusteluja, järjestelmäkehotteita, virtaavaa tulostusta, JSON-vastaustilaa ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL:n asennus komentoriviympäristöön

## Peruskäyttö

Claude API:n päätepiste on:

```
POST https://api.acedata.cloud/v1/chat/completions
```

Tässä esimerkissä käytetään mallia `claude-sonnet-4-6`. Saatavilla olevat mallit ovat: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys                      |
|-------------|-----------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai pääsy estetty |
| 429         | Pyyntöjen määrä ylittää rajan |
| 500         | Palvelimen sisäinen virhe    |
