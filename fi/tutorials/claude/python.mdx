## Johdanto

Claude on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, joka perustuu Anthropic Clauden sarjan suuriin kielimalleihin. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Clauden nopeasti Pythonilla ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, suoravirtausta, JSON-vastaustilaa ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Claude API:n päätepiste on:

```
POST https://api.acedata.cloud/v1/chat/completions
```

Tässä esimerkissä käytetään mallia `claude-sonnet-4-6`.
Saatavilla olevat mallit ovat: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "claude-sonnet-4-6",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Keskustelu-API tukee suoravirtausta reaaliaikaisten vastausten saamiseksi:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Ei saldoa tai oikeutta käyttää |
| 429       | Liian monta pyyntöä lyhyessä ajassa |
| 500       | Palvelinvirhe |
