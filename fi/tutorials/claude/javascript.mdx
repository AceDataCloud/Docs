## Johdanto

Claude on Ace Data Cloudin tarjoama tekoälypohjainen keskustelupalvelu, joka perustuu Anthropic Clauden sarjan suuriin kielimalleihin. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Clauden JavaScriptillä ja hyödyntää monikierroksisia keskusteluja, järjestelmäkehotteita, virtaavaa tulostusta, JSON-tulostustilaa ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai moderni selainympäristö

## Peruskäyttö

Claude API:n päätepiste on:

```
POST https://api.acedata.cloud/v1/chat/completions
```

Tässä esimerkissä käytetään mallia `claude-sonnet-4-6`.
Saatavilla olevat mallit ovat: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Täysi JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "claude-sonnet-4-6",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

On suositeltavaa tarkistaa vastauskoodi ja käsitellä virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, tilauskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callClaude(data) {
  const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen taajuus ylitetty |
| 500 | Palvelimen sisäinen virhe |
