## Johdanto

Producer on Ace Data Cloudin tarjoama tekoälypohjainen äänipalvelu, FUZZ Producer AI -musiikin generointi. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti kutsuaksesi Produceria ja toteuttaa tekstistä musiikin generoinnin, räätälöidyt sanoitukset, kappaleiden jatkamisen, cover-versiot, lauluerottelun, musiikkivideoiden generoinnin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Producer API:n päätepiste on:

```
POST https://api.acedata.cloud/producer/audios
```

Tässä esimerkissä käytetään mallia `FUZZ-2.0 Pro`. Saatavilla olevat mallit ovat: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/producer/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A relaxing jazz piece for a coffee shop", "model": "FUZZ-2.0 Pro", "lyric": "[Verse]\nSoft piano keys in the morning light", "custom": true}' | jq .
```

## Virheiden käsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää sallitun rajan |
| 500 | Palvelimen sisäinen virhe |
