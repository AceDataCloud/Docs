## Johdanto

Producer on Ace Data Cloudin tarjoama AI-äänipalvelu, FUZZ Producer AI -musiikin generointi. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Producerin Pythonilla ja toteuttaa tekstistä musiikin generoinnin, mukautetut sanoitukset, kappaleiden jatkamisen, cover-versiot, lauluerottelun, MV:n generoinnin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Producer API:n päätepiste on:

```
POST https://api.acedata.cloud/producer/audios
```

Tässä esimerkissä käytetään `FUZZ-2.0 Pro` -mallia. Saatavilla olevat mallit ovat: `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Täysi Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/producer/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A relaxing jazz piece for a coffee shop",
    "model": "FUZZ-2.0 Pro",
    "lyric": "[Verse]\nSoft piano keys in the morning light",
    "custom": True
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tila:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tila: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tila | Selitys |
|------|---------|
| 401  | Todennus epäonnistui, tarkista API-token |
| 403  | Saldo loppu tai pääsy evätty |
| 429  | Pyyntöjen rajoitus ylittynyt |
| 500  | Palvelimen sisäinen virhe |
