## Johdanto

OpenAI on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, joka hyödyntää OpenAI GPT -sarjan suuria kielimalleja. Ace Data Cloudin yhtenäisen API:n avulla voit integroida OpenAI:n nopeasti Pythonilla ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, suoravirtausta, JSON-vastaustilaa, tekstin upotuksia, kuvagenerointia ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

OpenAI API:n päätepiste on:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Tässä esimerkissä käytetään `gpt-4o`-mallia.
Saatavilla olevat mallit ovat: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Keskustelutyypin API tukee suoravirtausta reaaliaikaisten vastausten saamiseksi:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo loppu tai pääsy estetty |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe |
