## Johdanto

OpenAI on Ace Data Cloudin tarjoama AI-chat-palvelu, OpenAI GPT -sarjan suuri kielimalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää JavaScriptiä nopeasti integroidaksesi OpenAI:n, toteuttaen monikierroksiset keskustelut, järjestelmän kehotteet, virtaavan tulostuksen, JSON-tulostustilan, tekstin upotukset, kuvageneraation ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankinta
- Node.js 18+ tai moderni selainympäristö

## Peruskäyttö

OpenAI API:n päätepiste on:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Tässä esimerkissä käytetään `gpt-4o` mallia. Saatavilla olevat mallit ovat: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callOpenAI(data) {
  const response = await fetch("https://api.acedata.cloud/openai/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai pääsy evätty |
| 429 | Liian monta pyyntöä |
| 500 | Palvelimen sisäinen virhe |
