## Johdanto

OpenAI on Ace Data Cloudin tarjoama tekoälykeskustelupalvelu, joka perustuu OpenAI GPT -sarjan suuriin kielimalleihin. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti OpenAI:n kutsumiseen ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, virtaavaa tulostusta, JSON-tulostustilaa, tekstin upotuksia, kuvageneraatiota ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

OpenAI API:n päätepiste on:

```
POST https://api.acedata.cloud/openai/chat/completions
```

Tässä esimerkissä käytetään `gpt-4o`-mallia.
Saatavilla olevat mallit ovat: `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
