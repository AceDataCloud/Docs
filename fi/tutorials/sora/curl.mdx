## Johdanto

Sora on Ace Data Cloudin tarjoama AI-videopalvelu, OpenAI Sora -videogeneraatiomalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Soran kutsumiseen, mahdollistaen tekstistä videoon -toiminnon, erilaiset kestot, vaakasuoran ja pystysuoran kuvasuhteen, hahmojen hallinnan, referenssikuvat ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta [Ace Data Cloud](https://platform.acedata.cloud)
- cURL asennettuna komentoriville

## Peruskäyttö

Sora API:n päätepiste on:

```
POST https://api.acedata.cloud/sora/videos
```

Tässä esimerkissä käytetään `sora-2` mallia.
Saatavilla olevat mallit ovat: `sora-2`, `sora-2-pro`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
