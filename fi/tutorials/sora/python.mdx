## Johdanto

Sora on Ace Data Cloudin tarjoama AI-videopalvelu, OpenAI Sora -videonluontimalli. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Soran Pythonilla ja toteuttaa tekstistä videoon -toimintoja, erilaisia kestoja, vaakasuoran ja pystysuoran kuvasuhteen, hahmojen hallinnan, referenssikuvat ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Soran API:n päätepiste on:

```
POST https://api.acedata.cloud/sora/videos
```

Tässä esimerkissä käytetään `sora-2` mallia.
Saatavilla olevat mallit ovat: `sora-2`, `sora-2-pro`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

API, joka tukee asynkronisia tehtäviä, voi palauttaa tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
