## Johdanto

Grok on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, xAI Grok -sarjan suuri kielimalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia Grokin nopeaan kutsumiseen, mahdollistaen monikierroksiset keskustelut, järjestelmän kehotteet, suoravirtaisen tulostuksen, JSON-tulostusmuodon, visuaalisen ymmärryksen ja muita toimintoja.

## Esivaatimukset

- Omata [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- cURL asennettuna komentoriville

## Peruskäyttö

Grok API:n päätepiste on:

```
POST https://api.acedata.cloud/grok/chat/completions
```

Tässä esimerkissä käytetään `grok-3` mallia.
Saatavilla olevat mallit ovat: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/grok/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "grok-3", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selite |
|-------------|--------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai pääsy evätty |
| 429 | Pyyntöjen taajuus ylitetty |
| 500 | Palvelimen sisäinen virhe |
