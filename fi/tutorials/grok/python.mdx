## Johdanto

Grok on Ace Data Cloudin tarjoama tekoälypohjainen keskustelupalvelu, xAI Grok -sarjan suurten kielimallien pohjalta. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Grokin nopeasti Pythonilla ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, virtaavaa tulostusta, JSON-tulostustilaa, visuaalista ymmärrystä ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Grok API:n päätepiste on:

```
POST https://api.acedata.cloud/grok/chat/completions
```

Tässä esimerkissä käytetään `grok-3` -mallia. Saatavilla olevat mallit ovat: `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "grok-3",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Keskustelu-API tukee virtaavaa tulostusta reaaliaikaisten vastausten saamiseksi:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Ei saldoa tai oikeutta käyttää |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelinvirhe |
