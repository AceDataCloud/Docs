title: "Short URL cURL pikaopas"
---

## Johdanto

Short URL on Ace Data Cloudin tarjoama työkalupalvelu, lyhytlinkkien generointipalvelu. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia lyhyiden URL-osoitteiden luomiseen, mukautettujen verkkotunnusten käyttöön ja muihin toimintoihin.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- cURL asennettuna komentoriviympäristöön

## Peruskäyttö

Short URL API:n päätepiste on:

```
POST https://api.acedata.cloud/shorturl
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää sallitun rajan |
| 500 | Palvelimen sisäinen virhe |
