## Johdanto

Short URL on Ace Data Cloudin tarjoama työkalupalvelu, lyhyiden linkkien generointipalvelu. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää Pythonia nopeasti Short URL:n integroimiseen, jolloin voit toteuttaa URL-osoitteiden lyhentämisen, mukautetut domainit ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- Python 3.7 tai uudempi ympäristö
- Asennettuna requests-kirjasto: `pip install requests`

## Peruskäyttö

Short URL API:n päätepiste on:

```
POST https://api.acedata.cloud/shorturl
```

Kokonainen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/shorturl"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "content": "https://platform.acedata.cloud"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevien API-kutsujen tulokset voidaan saada takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:n kautta palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys                      |
|-----------|-----------------------------|
| 401       | Todennus epäonnistui, tarkista API Token |
| 403       | Saldo ei riitä tai pääsy evätty |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe   |
