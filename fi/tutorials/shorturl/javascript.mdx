title: "Short URL JavaScript pikaopääsy"
---

## Johdanto

Short URL on Ace Data Cloudin tarjoama työkalupalvelu, lyhytlinkkien generointipalvelu. Ace Data Cloudin yhtenäisen API:n kautta voit nopeasti integroida Short URL:n JavaScriptillä, toteuttaen URL-osoitteiden lyhentämisen, mukautetut verkkotunnukset ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Short URL API:n päätepiste on:

```
POST https://api.acedata.cloud/shorturl
```

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/shorturl", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "content": "https://platform.acedata.cloud"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, tilakoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callShortURL(data) {
  const response = await fetch("https://api.acedata.cloud/shorturl", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API Token |
| 403       | Saldo loppu tai pääsy estetty |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe |
