title: "Google Search cURL pikaopas"
---

## Johdanto

Google Search on Ace Data Cloudin tarjoama hakupalvelu, Google Search API. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Google Searchin kutsumiseen ja toteuttaa verkkohakuja, kuvahakuja, uutishakuja, karttahakuja, videohakuja ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tilin ja hankkinut API-tokenin
- cURL asennettuna komentoriville

## Peruskäyttö

Google Search API:n päätepiste on:

```
POST https://api.acedata.cloud/serp/google
```

Kokonainen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Virheiden käsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää rajan |
| 500 | Palvelimen sisäinen virhe |
