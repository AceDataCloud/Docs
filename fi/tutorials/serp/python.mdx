## Johdanto

Google Search on Ace Data Cloudin tarjoama hakupalvelu, Google-haku API. Ace Data Cloudin yhtenäisen API:n kautta voit nopeasti integroida Google Searchin Pythonilla ja toteuttaa verkkohakuja, kuvahakuja, uutishakuja, karttahakuja, videohakuja ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Google Search API:n päätepiste on:

```
POST https://api.acedata.cloud/serp/google
```

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/serp/google"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "query": "artificial intelligence latest news",
    "type": "search",
    "number": 10,
    "language": "en",
    "country": "US"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa tulokset voidaan saada takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:n kautta palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelinvirhe |
