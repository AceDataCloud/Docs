## Johdanto

Google Search on Ace Data Cloudin tarjoama hakupalvelu, Google Search API. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Google Searchin JavaScriptillä ja toteuttaa verkkohaku-, kuvahaku-, uutishaku-, karttahaku- ja videohakutoimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Google Search API:n päätepiste on:

```
POST https://api.acedata.cloud/serp/google
```

Kokonainen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/serp/google", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "query": "artificial intelligence latest news",
  "type": "search",
  "number": 10,
  "language": "en",
  "country": "US"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callGoogleSearch(data) {
  const response = await fetch("https://api.acedata.cloud/serp/google", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai ei käyttöoikeutta |
| 429 | Pyyntöjen määrä ylitetty |
| 500 | Palvelinvirhe |
