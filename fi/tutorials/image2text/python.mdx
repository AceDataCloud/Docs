## Johdanto

Image2Text on Ace Data Cloudin tarjoama captcha-palvelu, joka tunnistaa kuvacaptchat. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Image2Textin Pythonilla ja toteuttaa kuvacaptchan tunnistuksen, Base64-syötteen, URL-syötteen ym. toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Image2Text API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheiden käsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo loppu tai pääsy estetty |
| 429       | Pyyntöjen määrä ylitti rajan |
| 500       | Palvelinvirhe |
