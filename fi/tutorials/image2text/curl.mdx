title: "Image2Text cURL pikaopas"
---

## Johdanto

Image2Text on Ace Data Cloudin tarjoama CAPTCHA-palvelu, joka tunnistaa kuvassa olevat varmistuskoodit. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti Image2Text-palvelun kutsumiseen ja toteuttaa kuvien CAPTCHA-tunnistuksen, Base64-syötteen, URL-syötteen ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkinut API-tokenin
- cURL asennettuna komentoriviympäristöön

## Peruskäyttö

Image2Text API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai käyttöoikeus puuttuu      |
| 429         | Liian monta pyyntöä lyhyessä ajassa       |
| 500         | Palvelinvirhe                            |
