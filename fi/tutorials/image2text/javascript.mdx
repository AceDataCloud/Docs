## Johdanto

Image2Text on Ace Data Cloudin tarjoama CAPTCHA-palvelu, joka tunnistaa kuvassa olevat tarkistuskoodit. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Image2Textin JavaScriptillä ja toteuttaa kuvien CAPTCHA-tunnistuksen, Base64-syötteen, URL-syötteen ja muita toimintoja.

## Edellytykset

- Omata [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API Token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Image2Text API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/captcha/recognition/image2text", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callImage2Text(data) {
  const response = await fetch("https://api.acedata.cloud/captcha/recognition/image2text", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys                        |
|-------------|-------------------------------|
| 401         | Todennus epäonnistui, tarkista API Token |
| 403         | Saldo ei riitä tai ei oikeutta käyttää |
| 429         | Pyyntöjen taajuus ylitetty    |
| 500         | Palvelimen sisäinen virhe     |
