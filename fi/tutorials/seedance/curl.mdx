title: "Seedance cURL pikaopas"
---

## Johdanto

Seedance on Ace Data Cloudin tarjoama tekoälypohjainen videoservice, joka hyödyntää Bytedancen Seedance-videogeneraatiomallia. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Seedance-palvelun kutsumiseen ja toteuttaa tekstistä videoon, kuvasta videoon, äänen generoinnin sekä erilaiset resoluutiot.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Seedance API:n päätepiste on:

```
POST https://api.acedata.cloud/seedance/videos
```

Tässä esimerkissä käytetään mallia `doubao-seedance-1-0-pro-250528`. Saatavilla olevat mallit ovat: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-0-pro-250528", "content": [{"type": "text", "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"}]}' | jq .
```

## Virheiden käsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai pääsy evätty |
| 429 | Pyyntöjen määrä ylitti rajan |
| 500 | Palvelimen sisäinen virhe |
