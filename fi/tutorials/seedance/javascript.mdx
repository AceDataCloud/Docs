## Johdanto

Seedance on Ace Data Cloudin tarjoama AI-videopalvelu, joka perustuu Bytedancen Seedance-videon generointimalliin. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Seedancen nopeasti JavaScriptillä ja toteuttaa tekstistä videoon, kuvasta videoon, äänen generoinnin sekä useita resoluutioita tukevia toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Seedance API:n päätepiste on:

```
POST https://api.acedata.cloud/seedance/videos
```

Tässä esimerkissä käytetään mallia `doubao-seedance-1-0-pro-250528`. Saatavilla olevat mallit ovat: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/seedance/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "doubao-seedance-1-0-pro-250528",
  "content": [
    {
      "type": "text",
      "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
    }
  ]
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callSeedance(data) {
  const response = await fetch("https://api.acedata.cloud/seedance/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys                     |
|-------------|-----------------------------|
| 401         | Todennus epäonnistui, tarkista API Token |
| 403         | Saldo ei riitä tai pääsy evätty |
| 429         | Pyyntöjen taajuus ylitetty  |
| 500         | Palvelimen sisäinen virhe   |
