title: "Kling cURL pikaopas"
---

## Johdanto

Kling on Ace Data Cloudin tarjoama AI-videopalvelu, joka perustuu Kuaishou Kling -videon generointimalliin. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia Klingin nopeaan kutsumiseen ja toteuttaa tekstistä videoon, kuvasta videoon, videon jatkamisen, eri kestot ja eri kuvasuhteet -toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Kling API:n päätepiste on:

```
POST https://api.acedata.cloud/kling/videos
```

Tässä esimerkissä käytetään mallia `kling-v2-5-turbo`. Saatavilla olevat mallit ovat: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai pääsy estetty |
| 429         | Pyyntöjen taajuus ylitetty       |
| 500         | Palvelimen sisäinen virhe        |
