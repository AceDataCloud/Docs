## Johdanto

Kling on Ace Data Cloudin tarjoama AI-videopalvelu, Kuaishou Keling -videonluontimalli. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Klingin nopeasti Pythonilla ja toteuttaa tekstistä videoon, kuvasta videoon, videon jatkamisen sekä erilaiset kestot ja kuvasuhteet.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Kling API:n päätepiste on:

```
POST https://api.acedata.cloud/kling/videos
```

Tässä esimerkissä käytetään `kling-v2-5-turbo` -mallia. Saatavilla olevat mallit ovat: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A white cat walking in the snow",
    "model": "kling-v2-5-turbo",
    "duration": 5,
    "aspect_ratio": "16:9"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa tulokset voidaan saada callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset toimitetaan callback-URL:iin palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Ei saldoa tai oikeutta käyttää |
| 429 | Liian monta pyyntöä |
| 500 | Palvelimen sisäinen virhe |
