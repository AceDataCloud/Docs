## Johdanto

Kling on Ace Data Cloudin tarjoama AI-videopalvelu, joka mahdollistaa nopean videon generoinnin. Ace Data Cloudin yhtenäisen API:n avulla voit JavaScriptillä helposti integroida Klingin ja toteuttaa tekstistä videoon, kuvasta videoon, videon jatkamisen sekä erilaiset kesto- ja kuvasuhdevaihtoehdot.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Kling API:n päätepiste on:

```
POST https://api.acedata.cloud/kling/videos
```

Tässä esimerkissä käytetään mallia `kling-v2-5-turbo`.
Saatavilla olevat mallit ovat: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/kling/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "prompt": "A white cat walking in the snow",
  "model": "kling-v2-5-turbo",
  "duration": 5,
  "aspect_ratio": "16:9"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callKling(data) {
  const response = await fetch("https://api.acedata.cloud/kling/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Ei saldoa tai käyttöoikeutta |
| 429 | Liian monta pyyntöä |
| 500 | Palvelimen sisäinen virhe |
