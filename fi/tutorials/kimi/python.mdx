## Johdanto

Kimi on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, joka perustuu Kuun pimeän puolen Kimi-sarjan suurten kielimallien sarjaan. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Kimin nopeasti Pythonilla ja hyödyntää monikierroksista keskustelua, järjestelmän kehotteita, suoravirtausta, JSON-vastaustilaa ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Kimi API:n päätepiste on:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

Tässä esimerkissä käytetään mallia `kimi-k2.5`. Saatavilla olevat mallit ovat: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "kimi-k2.5",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Keskustelu-API tukee suoravirtausta reaaliaikaisen vastauksen saamiseksi:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo loppu tai käyttöoikeus puuttuu |
| 429       | Pyyntöjen nopeusrajoitus ylittynyt |
| 500       | Palvelinvirhe |
