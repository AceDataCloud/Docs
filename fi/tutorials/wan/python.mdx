## Johdanto

Wan on Ace Data Cloudin tarjoama AI-videopalvelu, Alibaba Wanxiang -videogeneraatiomalli. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Wanin nopeasti Pythonilla ja toteuttaa tekstistä videoon, kuvasta videoon, referenssivideon generoinnin sekä eri resoluutioiden tuen.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Wan API:n päätepiste on:

```
POST https://api.acedata.cloud/wan/videos
```

Tässä esimerkissä käytetään mallia `wan2.6-t2v`.
Saatavilla olevat mallit: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/wan/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "model": "wan2.6-t2v",
    "prompt": "Astronauts shuttle from space to volcano",
    "resolution": "720P"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo loppu tai käyttöoikeus puuttuu |
| 429       | Pyyntöjen määrän rajoitus ylittynyt |
| 500       | Palvelinvirhe |
