---

## Johdanto

Wan on Ace Data Cloudin tarjoama tekoälypohjainen videoservice, Alibaba Wanxiangin videonluontimalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Wanin kutsumiseen ja toteuttaa tekstistä videoon, kuvasta videoon, referenssivideoiden luomisen sekä useita resoluutioita.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Wan API:n päätepiste on:

```
POST https://api.acedata.cloud/wan/videos
```

Tässä esimerkissä käytetään `wan2.6-t2v` mallia.
Saatavilla olevat mallit: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen taajuus ylitetty |
| 500 | Palvelimen sisäinen virhe |
