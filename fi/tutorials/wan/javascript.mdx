## Johdanto

Wan on Ace Data Cloudin tarjoama AI-videopalvelu, Alibaba Wanxiangin videotuotantomalli. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Wanin JavaScriptillä ja toteuttaa tekstistä videoon, kuvasta videoon, referenssivideoiden generoinnin sekä erilaiset resoluutiot.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankinta
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Wan API:n päätepiste on:

```
POST https://api.acedata.cloud/wan/videos
```

Tässä esimerkissä käytetään `wan2.6-t2v` mallia. Saatavilla olevat mallit ovat: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/wan/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "model": "wan2.6-t2v",
  "prompt": "Astronauts shuttle from space to volcano",
  "resolution": "720P"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callWan(data) {
  const response = await fetch("https://api.acedata.cloud/wan/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisiä virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai pääsy estetty |
| 429 | Liian monta pyyntöä liian lyhyessä ajassa |
| 500 | Palvelinvirhe |
