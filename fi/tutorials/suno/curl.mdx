## Johdanto

Suno on Ace Data Cloudin tarjoama AI-äänipalvelu, Suno AI musiikin generointi. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti Sunon kutsumiseen, ja toteuttaa tekstistä musiikin generoinnin, mukautetut sanoitukset, kappaleiden jatkamisen, cover-versiot, lauluerottelun, sanoitusten generoinnin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Suno API:n päätepiste on:

```
POST https://api.acedata.cloud/suno/audios
```

Tässä esimerkissä käytetään `chirp-v5` mallia. Saatavilla olevat mallit ovat: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Ei tarpeeksi saldoa tai pääsy estetty |
| 429         | Liian monta pyyntöä lyhyessä ajassa |
| 500         | Palvelimen sisäinen virhe       |
