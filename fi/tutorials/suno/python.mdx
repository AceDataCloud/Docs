## Johdanto

Suno on Ace Data Cloudin tarjoama AI-äänipalvelu, Suno AI musiikin generointi. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Sunon Pythonilla ja toteuttaa tekstistä musiikin generoinnin, mukautetut sanoitukset, kappaleiden jatkamisen, cover-versiot, lauluerottelun, sanoitusten generoinnin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Token
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Suno API:n päätepiste on:

```
POST https://api.acedata.cloud/suno/audios
```

Tässä esimerkissä käytetään `chirp-v5` mallia. Saatavilla olevat mallit ovat: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` omalla Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa tulokset voidaan saada callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API Token |
| 403       | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429       | Pyyntöjen määrä ylitti rajan |
| 500       | Palvelinvirhe |
