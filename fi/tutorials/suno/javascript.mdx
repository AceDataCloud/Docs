## Johdanto

Suno on Ace Data Cloudin tarjoama AI-äänipalvelu, Suno AI musiikin generointi. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Sunon JavaScriptillä ja toteuttaa tekstistä musiikin generoinnin, mukautetut sanoitukset, kappaleiden jatkamisen, cover-versiot, lauluerottelun, sanoitusten generoinnin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Suno API:n päätepiste on:

```
POST https://api.acedata.cloud/suno/audios
```

Tässä esimerkissä käytetään `chirp-v5` mallia. Saatavilla olevat mallit ovat: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/suno/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A cheerful pop song about summer vacation",
  "model": "chirp-v5",
  "custom": false
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callSuno(data) {
  const response = await fetch("https://api.acedata.cloud/suno/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
