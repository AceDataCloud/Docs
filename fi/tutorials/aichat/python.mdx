## Johdanto

AI Chat on Ace Data Cloudin tarjoama AI-keskustelupalvelu, monimallipohjainen AI-keskustelupalvelu. Ace Data Cloudin yhtenäisen API:n avulla voit integroida AI Chatin nopeasti Pythonilla, toteuttaen monimallituen, tilalliset keskustelut, esiasetetut roolit ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankinta
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

AI Chat API:n päätepiste on:

```
POST https://api.acedata.cloud/aichat/conversations
```

Tässä esimerkissä käytetään `gpt-4o` mallia. Saatavilla olevat mallit ovat: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Täysi Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/aichat/conversations"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "question": "什么是人工智能？",
    "stateful": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevien API-kutsujen tulokset voidaan saada callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API Token |
| 403       | Saldo ei riitä tai pääsy evätty |
| 429       | Pyyntöjen taajuus ylitetty |
| 500       | Palvelimen sisäinen virhe |
