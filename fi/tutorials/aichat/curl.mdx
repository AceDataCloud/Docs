title: "AI Chat cURL pikaopas"
---

## Johdanto

AI Chat on Ace Data Cloudin tarjoama AI-keskustelupalvelu, monimallipohjainen AI-keskustelupalvelu. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia AI Chatin nopeaan kutsumiseen, jolloin saat käyttöön monimallituen, tilalliset keskustelut, ennalta määritellyt roolit ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

AI Chat API:n päätepiste on:

```
POST https://api.acedata.cloud/aichat/conversations
```

Tässä esimerkissä käytetään `gpt-4o` mallia.
Saatavilla olevat mallit ovat: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys                      |
|-------------|-----------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai pääsy estetty |
| 429         | Pyyntöjen rajoitus ylittynyt |
| 500         | Palvelimen sisäinen virhe    |
