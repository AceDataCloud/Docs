## Johdanto

AI Chat on Ace Data Cloudin tarjoama tekoälypohjainen keskustelupalvelu, joka tukee useita malleja. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida AI Chatin JavaScriptillä ja hyödyntää monimallituen, tilallisen keskustelun ja esiasetetut roolit -toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Node.js 18+ tai moderni selainympäristö

## Peruskäyttö

AI Chat API:n päätepiste on:

```
POST https://api.acedata.cloud/aichat/conversations
```

Tässä esimerkissä käytetään `gpt-4o`-mallia. Saatavilla olevat mallit ovat: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Täydellinen JavaScript-esimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/aichat/conversations", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "question": "什么是人工智能？",
  "stateful": true
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callAIChat(data) {
  const response = await fetch("https://api.acedata.cloud/aichat/conversations", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys                        |
|-------------|-------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Ei tarpeeksi saldoa tai oikeuksia |
| 429         | Pyyntöjen määrä ylitetty       |
| 500         | Palvelimen sisäinen virhe      |
