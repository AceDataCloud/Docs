---

## Johdanto

QR Art on Ace Data Cloudin tarjoama tekoälypohjainen kuvapalvelu, joka luo taiteellisia QR-koodeja. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti QR Artin kutsumiseen ja hyödyntää linkki-QR-koodeja, tekstikoodeja, esiasetettuja tyylejä ja mukautettuja parametreja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

QR Art API:n päätepiste on:

```
POST https://api.acedata.cloud/qrart/generate
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Korvaa `YOUR_API_TOKEN` todellisella tokenillasi, jonka olet saanut Ace Data Cloud -alustalta.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys                    |
|-------------|---------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Ei riittävästi saldoa tai oikeuksia |
| 429         | Pyyntöjen määrä ylitti rajan |
| 500         | Palvelimen sisäinen virhe |
