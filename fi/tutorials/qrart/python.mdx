## Johdanto

QR Art on Ace Data Cloudin tarjoama AI-kuvapalvelu, joka tuottaa AI-taidetta QR-koodeihin. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida QR Artin Pythonilla ja toteuttaa linkki-QR-koodeja, tekstikoodeja, esiasetettuja tyylejä ja mukautettuja parametreja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

QR Art API:n päätepiste on:

```
POST https://api.acedata.cloud/qrart/generate
```

Täydellinen Python-esimerkkikoodi:

```python
import requests

url = "https://api.acedata.cloud/qrart/generate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Ei saldoa tai oikeutta käyttää |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelinvirhe |
