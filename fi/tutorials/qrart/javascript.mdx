---

## Johdanto

QR Art on Ace Data Cloudin tarjoama tekoälykuvapalvelu, joka generoi tekoälytaiteellisia QR-koodeja. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida QR Artin JavaScriptillä ja toteuttaa linkki-QR-koodit, tekstikoodit, esiasetetut tyylit, mukautetut parametrit ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selaimen ympäristö

## Peruskäyttö

QR Art API:n päätepiste on:

```
POST https://api.acedata.cloud/qrart/generate
```

Kokonainen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/qrart/generate", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "type": "link",
  "content": "https://platform.acedata.cloud",
  "prompt": "sunset ocean waves",
  "preset": "neon-mech"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callQRArt(data) {
  const response = await fetch("https://api.acedata.cloud/qrart/generate", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy evätty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
