## Johdanto

Hailuo on Ace Data Cloudin tarjoama AI-videopalvelu, MiniMax Hailuo -videonluontimalli. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Hailuon Pythonilla ja toteuttaa tekstistä videoon, kuvasta videoon, ohjaajatilaan ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Token
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Hailuo API:n päätepiste on:

```
POST https://api.acedata.cloud/hailuo/videos
```

Tässä esimerkissä käytetään `minimax-t2v` mallia.
Saatavilla olevat mallit: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Täysi Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/hailuo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "model": "minimax-t2v",
    "prompt": "A golden sunset over the ocean waves"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` todellisella tokenillasi, jonka saat Ace Data Cloud -alustalta.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tila:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tila: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheiden käsittely

Yleisimmät virhekoodit:

| Tila | Selitys |
|--------|------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Ei saldoa tai oikeutta käyttää |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |
