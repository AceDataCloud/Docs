---

## Johdanto

Hailuo on Ace Data Cloudin tarjoama AI-videopalvelu, MiniMax Hailuo -videon generointimalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti kutsuaksesi Hailuo-palvelua ja toteuttaa tekstistä videoon, kuvasta videoon, ohjaajatilaa ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Hailuo API:n päätepiste on:

```
POST https://api.acedata.cloud/hailuo/videos
```

Tässä esimerkissä käytetään `minimax-t2v` mallia. Saatavilla olevat mallit ovat: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys                      |
|-------------|-----------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Ei riittävästi saldoa tai oikeuksia |
| 429         | Pyyntöjen rajoitus ylittynyt |
| 500         | Palvelimen sisäinen virhe    |
