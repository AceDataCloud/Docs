## Johdanto

Hailuo on Ace Data Cloudin tarjoama AI-videopalvelu, MiniMax Hailuo -videon generointimalli. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää JavaScriptiä integroidaksesi Hailuon nopeasti ja toteuttaa tekstistä videoon, kuvasta videoon, ohjaajatilaa ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Hailuo API:n päätepiste on:

```
POST https://api.acedata.cloud/hailuo/videos
```

Tässä esimerkissä käytetään `minimax-t2v` mallia. Saatavilla olevat mallit ovat: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "model": "minimax-t2v",
  "prompt": "A golden sunset over the ocean waves"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan paketoimaan uudelleenkäytettäväksi funktioksi:

```javascript
async function callHailuo(data) {
  const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää rajan |
| 500 | Palvelimen sisäinen virhe |
