## Johdanto

Face Change on Ace Data Cloudin tarjoama tekoälykuvapalvelu, tekoälykasvojen käsittelypalvelu. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Face Change -toiminnon nopeasti Pythonilla, ja toteuttaa kasvojen vaihdon, kasvojen kaunistamisen, iän muuttamisen, sukupuolen muuttamisen, animaatiotyylisen muokkauksen, kasvojen analysoinnin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Face Change API:n päätepiste on:

```
POST https://api.acedata.cloud/face/swap
```

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/face/swap"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "source_image_url": "https://example.com/source-face.jpg",
    "target_image_url": "https://example.com/target-face.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevien API-kutsujen tulokset voidaan saada takaisin kutsu-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään palvelimellesi callback-URL:n kautta
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää sallitun rajan |
| 500 | Palvelimen sisäinen virhe |
