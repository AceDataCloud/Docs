title: "Face Change cURL pikaopas"
---

## Johdanto

Face Change on Ace Data Cloudin tarjoama tekoälykuvapalvelu, tekoälykasvojen käsittelypalvelu. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Face Change -palvelua, jolla voi toteuttaa kasvojen vaihdon, kasvojen kaunistamisen, ikämuutokset, sukupuolen muutokset, anime-tyyliset muokkaukset, kasvoanalyysin ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tilin ja hankkinut API-tokenin
- cURL asennettuna komentoriville

## Peruskäyttö

Face Change API:n päätepiste on:

```
POST https://api.acedata.cloud/face/swap
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                    |
|-------------|----------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai pääsy evätty |
| 429         | Pyyntöjen määrä ylitti rajan |
| 500         | Palvelimen sisäinen virhe  |
