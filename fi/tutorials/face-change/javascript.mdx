## Johdanto

Face Change on Ace Data Cloudin tarjoama AI-kuvapalvelu, joka käsittelee tekoälyn avulla kasvoja. Ace Data Cloudin yhtenäisen API:n kautta voit nopeasti integroida Face Change -toiminnon JavaScriptillä ja toteuttaa kasvojen vaihdon, kasvojen kaunistuksen, ikämuutokset, sukupuolenvaihdokset, anime-tyyliset muokkaukset sekä kasvoanalyysin.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selaimen ympäristö

## Peruskäyttö

Face Change API:n päätepiste on:

```
POST https://api.acedata.cloud/face/swap
```

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/face/swap", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "source_image_url": "https://example.com/source-face.jpg",
  "target_image_url": "https://example.com/target-face.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callFaceChange(data) {
  const response = await fetch("https://api.acedata.cloud/face/swap", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelinvirhe |
