## Johdanto

Identity on Ace Data Cloudin tarjoama tunnistuspalvelu, joka mahdollistaa henkilötodistuksen, pankkikortin ja puhelinnumeron aitouden varmistamisen. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Identityn Pythonilla ja toteuttaa esimerkiksi henkilötodistuksen OCR-tunnistuksen, henkilötodistuksen tarkistuksen, pankkikortin tarkistuksen ja puhelinnumeron tarkistuksen.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Identity API:n päätepiste on:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Täydellinen Python-esimerkkikoodi:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image_url": "https://example.com/idcard-front.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevien API:en kanssa voit saada tulokset takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheiden käsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API Token |
| 403       | Saldo ei riitä tai pääsy evätty |
| 429       | Pyyntöjen määrä ylitetty |
| 500       | Palvelinvirhe |
