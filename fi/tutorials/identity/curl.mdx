---

## Johdanto

Identity on Ace Data Cloudin tarjoama tunnistuspalvelu, joka mahdollistaa henkilötunnuksen, pankkikortin ja puhelinnumeron aitouden varmistamisen. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti kutsuaksesi Identity-palvelua ja toteuttaa henkilötunnuksen OCR-tunnistuksen, henkilötunnuksen tarkistuksen, pankkikortin tarkistuksen ja puhelinnumeron tarkistuksen.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankkiminen
- cURL asennettuna komentoriville

## Peruskäyttö

Identity API:n päätepiste on:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API Token |
| 403         | Saldo ei riitä tai pääsy estetty |
| 429         | Pyyntöjen taajuus ylitetty       |
| 500         | Palvelimen sisäinen virhe        |
