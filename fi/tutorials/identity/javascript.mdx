## Johdanto

Identity on Ace Data Cloudin tarjoama tunnistuspalvelu, joka mahdollistaa henkilötunnuksen, pankkikortin ja puhelinnumeron aitouden varmistamisen. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Identityn JavaScriptillä ja toteuttaa henkilökortin OCR:n, henkilötunnuksen tarkistuksen, pankkikortin tarkistuksen ja puhelinnumeron tarkistuksen.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Identity API:n päätepiste on:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Täydellinen JavaScript-esimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image_url": "https://example.com/idcard-front.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callIdentity(data) {
  const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisiä virhekoodit:

| Statuskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai oikeudet puuttuvat |
| 429 | Pyyntöjen määrä ylitti rajan |
| 500 | Palvelimen sisäinen virhe |
