## Johdanto

DeepSeek on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, DeepSeek-sarjan suurten kielimallien avulla. Ace Data Cloudin yhtenäisen API:n kautta voit integroida DeepSeekin nopeasti JavaScriptillä ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, virtaavaa tulostusta, JSON-tulostustilaa, syvällistä päättelyä ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Node.js 18+ tai nykyaikainen selaimen ympäristö

## Peruskäyttö

DeepSeek API:n päätepiste on:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

Tässä esimerkissä käytetään `deepseek-r1` mallia.
Saatavilla olevat mallit ovat: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "deepseek-r1",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, tilakoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callDeepSeek(data) {
  const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Liian monta pyyntöä |
| 500 | Palvelimen sisäinen virhe |
