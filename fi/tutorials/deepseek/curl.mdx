---

## Johdanto

DeepSeek on Ace Data Cloudin tarjoama tekoälypohjainen keskustelupalvelu, DeepSeek-sarjan suurten kielimallien pohjalta. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti DeepSeekin kutsumiseen, mahdollistaen monikierroksiset keskustelut, järjestelmäkehotteet, virtaavan tulostuksen, JSON-tulostusmuodon, syvällisen päättelyn ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL asennettuna komentoriviympäristöön

## Peruskäyttö

DeepSeek API:n päätepiste on:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

Tässä esimerkissä käytetään mallia `deepseek-r1`. Saatavilla olevat mallit ovat: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                         |
|-------------|--------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai käyttöoikeus puuttuu |
| 429         | Pyyntöjen taajuus ylitetty      |
| 500         | Palvelimen sisäinen virhe       |
