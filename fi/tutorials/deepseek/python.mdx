## Johdanto

DeepSeek on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, DeepSeek-sarjan suurten kielimallien avulla. Ace Data Cloudin yhtenäisen API:n kautta voit integroida DeepSeekin nopeasti Pythonilla ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, virtaavaa tulostusta, JSON-tulostustilaa, syvällistä päättelyä ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

DeepSeek API:n päätepiste on:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

Tässä esimerkissä käytetään `deepseek-r1` mallia. Saatavilla olevat mallit ovat: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek-r1",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Keskustelutyypin API tukee virtaavaa tulostusta reaaliaikaisten vastausten saamiseksi:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo loppu tai ei käyttöoikeutta |
| 429       | Pyyntöjen määrä ylittää rajan |
| 500       | Palvelimen sisäinen virhe |
