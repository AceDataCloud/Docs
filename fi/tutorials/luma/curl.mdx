---

## Johdanto

Luma on Ace Data Cloudin tarjoama AI-videopalvelu, Luma Dream Machine -videon generointi. Ace Data Cloudin yhtenäisen API:n avulla voit käyttää cURL:ia nopeasti Luman kutsumiseen ja toteuttaa tekstistä videoon, kuvasta videoon, videon jatkamisen, alku- ja loppukehysten hallinnan, silmukkavideot ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkinut API-tokenin
- cURL asennettuna terminaaliympäristöön

## Peruskäyttö

Luma API:n päätepiste on:

```
POST https://api.acedata.cloud/luma/videos
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo ei riitä tai ei oikeuksia |
| 429         | Pyyntöjen taajuus ylitetty       |
| 500         | Palvelimen sisäinen virhe        |
