## Johdanto

Luma on Ace Data Cloudin tarjoama AI-videopalvelu, Luma Dream Machine -videon generointi. Ace Data Cloudin yhtenäisen API:n kautta voit nopeasti integroida Luman JavaScriptillä ja toteuttaa tekstistä videoon, kuvasta videoon, videon jatkamisen, alku- ja loppukehysten hallinnan, silmukkavideot ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tili ja hankkia API-token
- Node.js 18+ tai moderni selainympäristö

## Peruskäyttö

Luma API:n päätepiste on:

```
POST https://api.acedata.cloud/luma/videos
```

Kokonainen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/luma/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "Astronauts shuttle from space to volcano",
  "action": "generate",
  "enhancement": true
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, tilauskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callLuma(data) {
  const response = await fetch("https://api.acedata.cloud/luma/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai pääsy estetty |
| 429 | Pyyntöjen taajuus ylitetty |
| 500 | Palvelimen sisäinen virhe |
