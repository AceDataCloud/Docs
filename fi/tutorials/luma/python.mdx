## Johdanto

Luma on Ace Data Cloudin tarjoama AI-videopalvelu, Luma Dream Machine videon generointiin. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Luman Pythonilla ja toteuttaa tekstistä videoon, kuvasta videoon, videon jatkamisen, alku- ja loppukehysten hallinnan, silmukkavideot ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Luma API:n päätepiste on:

```
POST https://api.acedata.cloud/luma/videos
```

Kokonainen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "Astronauts shuttle from space to volcano",
    "action": "generate",
    "enhancement": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:iin palvelimellesi
```

## Virheenkäsittely

Yleiset virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo ei riitä tai ei oikeutta käyttää |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe |
