## Johdanto

reCAPTCHA on Ace Data Cloudin tarjoama CAPTCHA-palvelu, Google reCAPTCHA -ratkaisu. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida reCAPTCHA:n Pythonilla ja toteuttaa reCAPTCHA v2 Tokenin, reCAPTCHA v2 tunnistuksen, reCAPTCHA v3 Tokenin ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API Tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

reCAPTCHA API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API Token |
| 403 | Saldo loppu tai pääsy estetty |
| 429 | Pyyntöjen määrä ylittää rajan |
| 500 | Palvelimen sisäinen virhe |

## Muut päätepisteet

reCAPTCHA-palvelu tarjoaa myös seuraavat päätepisteet:

- `POST https://api.acedata.cloud/captcha/recognition/recaptcha2`
- `POST https://api.acedata.cloud/captcha/token/recaptcha3`
