title: "reCAPTCHA cURL pikaopas"
---

## Johdanto

reCAPTCHA on Ace Data Cloudin tarjoama CAPTCHA-palvelu, Google reCAPTCHA -ratkaisu. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti kutsuaksesi reCAPTCHAa ja hyödyntää reCAPTCHA v2 Tokenia, reCAPTCHA v2 tunnistusta, reCAPTCHA v3 Tokenia ja muita toimintoja.

## Esivaatimukset

- Omistaa [Ace Data Cloud](https://platform.acedata.cloud) -tilin ja hankkinut API Tokenin
- cURL asennettuna komentoriviympäristöön

## Peruskäyttö

reCAPTCHA API:n päätepiste on:

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella Tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys                          |
|-------------|---------------------------------|
| 401         | Todennus epäonnistui, tarkista API Token |
| 403         | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429         | Pyyntöjen määrä ylittää rajan    |
| 500         | Palvelimen sisäinen virhe        |
