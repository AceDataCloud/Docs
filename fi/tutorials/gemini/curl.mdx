title: "Gemini cURL pikaopas"
---

## Johdanto

Gemini on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, joka perustuu Google Geminin sarjan suuriin kielimalleihin. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia nopeasti Geminiin, hyödyntäen monikierroksisia keskusteluja, järjestelmän kehotteita, virtaavaa tulostusta, JSON-vastaustilaa ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen [Ace Data Cloud](https://platform.acedata.cloud) -sivustolta
- cURL asennettuna komentoriviympäristöön

## Peruskäyttö

Gemini API:n päätepiste on:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Tässä esimerkissä käytetään mallia `gemini-2.5-flash`. Saatavilla olevat mallit ovat: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Täysi cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan jq-työkalun käyttöä tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/gemini/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.5-flash", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selite |
|-------------|--------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen rajoitus ylittynyt |
| 500 | Palvelimen sisäinen virhe |

## Seuraavat askeleet

- Mene [Ace Data Cloud -hallintapaneeliin](https://platform.acedata.cloud) ja hanki API-token
- Tutustu [API-dokumentaatioon](https://docs.acedata.cloud/zh-CN/api-reference) saadaksesi täydelliset parametritiedot
- Tutki [hinnoitteluvaihtoehtoja](https://platform.acedata.cloud/services) kustannusten ymmärtämiseksi
