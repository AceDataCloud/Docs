## Johdanto

Gemini on Ace Data Cloudin tarjoama AI-chat-palvelu, Google Geminin sarjan suuri kielimalli. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Geminin Pythonilla ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, virtaavaa tulostusta, JSON-tulostustilaa ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Gemini API:n päätepiste on:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Tässä esimerkissä käytetään mallia `gemini-2.5-flash`.
Saatavilla olevat mallit ovat: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi todellisella tokenilla.

## Vastausten käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tila:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Keskustelu-API tukee virtaavaa tulostusta reaaliaikaisten vastausten saamiseksi:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai pääsy evätty |
| 429 | Pyyntöjen taajuus ylitetty |
| 500 | Palvelimen sisäinen virhe |
