## Johdanto

Gemini on Ace Data Cloudin tarjoama tekoälypohjainen chat-palvelu, joka perustuu Google Geminin sarjan suuriin kielimalleihin. Ace Data Cloudin yhtenäisen API:n avulla voit nopeasti integroida Geminin JavaScriptillä ja hyödyntää monikierroksisia keskusteluja, järjestelmän kehotteita, suoravirtausta, JSON-vastaustilaa ja muita ominaisuuksia.

## Esivaatimukset

- Ace Data Cloud -tili ja API-token
- Node.js 18+ tai nykyaikainen selainympäristö

## Peruskäyttö

Gemini API:n päätepiste on:

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Tässä esimerkissä käytetään mallia `gemini-2.5-flash`. Saatavilla olevat mallit ovat: `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Täydellinen JavaScript-koodiesimerkki:

```javascript
const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gemini-2.5-flash",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Suositellaan tarkistamaan vastauskoodi ja käsittelemään virheet:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Kutsu onnistui:", result);
} else {
  console.error(`Kutsu epäonnistui, statuskoodi: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js-kääre

Suositellaan käärittäväksi uudelleenkäytettäväksi funktioksi:

```javascript
async function callGemini(data) {
  const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API-virhe: ${response.status}`);
  return response.json();
}
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Statuskoodi | Selitys                         |
|-------------|--------------------------------|
| 401         | Todennus epäonnistui, tarkista API-token |
| 403         | Saldo loppu tai pääsy estetty  |
| 429         | Liian monta pyyntöä lyhyessä ajassa |
| 500         | Palvelimen sisäinen virhe      |
