## Johdanto

Seedream on Ace Data Cloudin tarjoama tekoälypohjainen kuvapalvelu, joka hyödyntää Bytedancen Seedream-kuvageneraatiomallia. Ace Data Cloudin yhtenäisen API:n avulla voit integroida Seedreamin nopeasti Pythonilla ja toteuttaa tekstistä kuvaan -generoinnin, kuvanmuokkauksen, useita resoluutioita, vesileiman hallinnan ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- Python 3.7 tai uudempi ympäristö
- requests-kirjaston asennus: `pip install requests`

## Peruskäyttö

Seedream API:n päätepiste on:

```
POST https://api.acedata.cloud/seedream/images
```

Tässä esimerkissä käytetään mallia `doubao-seedream-4-0-250828`. Saatavilla olevat mallit ovat: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Täydellinen Python-koodiesimerkki:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "valkoinen siamilaistyyppinen kissa istuu ikkunalaudalla",
    "model": "doubao-seedream-4-0-250828",
    "size": "1K"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Korvaa `YOUR_API_TOKEN` omalla Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastauksen käsittely

Onnistuneen kutsun jälkeen API palauttaa JSON-muotoista dataa. Suositellaan tarkistamaan HTTP-tilakoodi:

```python
if response.status_code == 200:
    result = response.json()
    print("Kutsu onnistui:", result)
else:
    print(f"Kutsu epäonnistui, tilakoodi: {response.status_code}")
    print(response.text)
```

## Edistynyt käyttö

Asynkronisia tehtäviä tukevissa API-kutsuissa voit saada tulokset takaisin callback-URL:n kautta:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Tulokset lähetetään callback-URL:ään palvelimellesi
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilakoodi | Selitys |
|-----------|---------|
| 401       | Todennus epäonnistui, tarkista API-token |
| 403       | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429       | Pyyntöjen rajoitus ylittynyt |
| 500       | Palvelimen sisäinen virhe |
