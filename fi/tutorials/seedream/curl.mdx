title: "Seedream cURL pikaopas"
---

## Johdanto

Seedream on Ace Data Cloudin tarjoama tekoälykuvapalvelu, joka perustuu Bytedancen Seedream-kuvageneraattorimalliin. Ace Data Cloudin yhtenäisen API:n kautta voit käyttää cURL:ia Seedreamin nopeaan kutsumiseen, mahdollistaen tekstistä kuvaan -generoinnin, kuvien muokkauksen, eri resoluutioiden käytön, vesileimojen hallinnan ja muita toimintoja.

## Esivaatimukset

- Ace Data Cloud -tili ja API-tokenin hankkiminen
- cURL:n asennus komentoriville

## Peruskäyttö

Seedream API:n päätepiste on:

```
POST https://api.acedata.cloud/seedream/images
```

Tässä esimerkissä käytetään mallia `doubao-seedream-4-0-250828`.
Saatavilla olevat mallit ovat: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Täydellinen cURL-komentoesimerkki:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Korvaa `YOUR_API_TOKEN` Ace Data Cloud -alustalta saamallasi tokenilla.

## Vastausesimerkki

Onnistuneen kutsun jälkeen palautetaan JSON-muotoinen data, esimerkiksi:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Vastauksen käsittely jq:lla

Suositellaan käyttämään jq-työkalua tulosteen muotoiluun:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Virheenkäsittely

Yleisimmät virhekoodit:

| Tilauskoodi | Selitys |
|-------------|---------|
| 401 | Todennus epäonnistui, tarkista API-token |
| 403 | Saldo ei riitä tai käyttöoikeus puuttuu |
| 429 | Pyyntöjen määrä ylittää rajan |
| 500 | Palvelinvirhe |
