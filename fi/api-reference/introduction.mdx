## Perus URL

Kaikkien API-päätepisteiden perusosoite:

```
https://api.acedata.cloud
```

## Todennus

Kaikki päätepisteet vaativat Bearer Token -todennuksen:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Online-testaus

Tämän viitedokumentaation jokaisessa päätepisteessä on interaktiivinen hiekkalaatikko. Syötä API Token testataksesi pyyntöjä suoraan selaimessa.

<Note title="Tip">
  Hanki API Token osoitteesta [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
