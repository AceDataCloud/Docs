## Mikä on OpenAI-yhteensopiva rajapinta

OpenAI:n Chat Completions API -formaatti on muodostunut alan de facto -standardiksi. Monet suuret kielimallit tarjoavat OpenAI-yhteensopivan rajapinnan, mikä mahdollistaa kehittäjille saman koodin käytön eri mallien kanssa.

Ace Data Cloud tarjoaa OpenAI-yhteensopivan Chat Completions -rajapinnan Claude-, Gemini-, DeepSeek-, Grok-, Kimi- ja muille malleille. Vaihtaminen onnistuu helposti muuttamalla Base URL:ia ja mallin nimeä.

## Tuetut mallit

| Palvelu | Päätepiste | Esimerkkimalli |
|---------|------------|----------------|
| Claude  | `POST /v1/chat/completions` | claude-sonnet-4-6 |
| OpenAI  | `POST /openai/chat/completions` | gpt-4o |
| Gemini  | `POST /gemini/chat/completions` | gemini-2.5-flash |
| DeepSeek| `POST /deepseek/chat/completions` | deepseek-r1 |
| Grok    | `POST /grok/chat/completions` | grok-3 |
| Kimi    | `POST /kimi/chat/completions` | kimi-k2.5 |

## Yhtenäinen kutsutapa

Kaikki chat-mallit käyttävät samaa pyyntöformaattia:

```python
import requests

def chat(endpoint, model, message):
    return requests.post(
        f"https://api.acedata.cloud{endpoint}",
        headers={
            "Authorization": "Bearer YOUR_API_TOKEN",
            "Content-Type": "application/json",
        },
        json={
            "model": model,
            "messages": [{"role": "user", "content": message}],
            "max_tokens": 1024,
            "temperature": 0.7,
        },
    ).json()

# Kutsutaan eri malleja - vaihda vain päätepistettä ja mallin nimeä
claude = chat("/v1/chat/completions", "claude-sonnet-4-6", "你好")
gpt = chat("/openai/chat/completions", "gpt-4o", "你好")
gemini = chat("/gemini/chat/completions", "gemini-2.5-flash", "你好")
deepseek = chat("/deepseek/chat/completions", "deepseek-r1", "你好")
```

## Virtaava tulostus

Kaikki chat-API:t tukevat virtaavaa tulostusta (Server-Sent Events):

```python
data = {
    "model": "claude-sonnet-4-6",
    "messages": [{"role": "user", "content": "写一首诗"}],
    "stream": True,
}

response = requests.post(
    "https://api.acedata.cloud/v1/chat/completions",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json=data,
    stream=True,
)

for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Yhteensopivuus OpenAI SDK:n kanssa

Koska rajapinta on yhteensopiva, voit käyttää suoraan OpenAI:n virallista SDK:ta, muuttaen vain base_urlin:

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_TOKEN",
    base_url="https://api.acedata.cloud/v1",  # Claude
    # base_url="https://api.acedata.cloud/openai",  # OpenAI
    # base_url="https://api.acedata.cloud/gemini",  # Gemini
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

## Yhteenveto

Ace Data Cloudin OpenAI-yhteensopivan rajapinnan avulla voit:

- Käyttää samaa koodia yli 6 eri suurikielimallin kanssa
- Vaihtaa malleja joustavasti, vertailla tuloksia ja kustannuksia
- Käyttää suoraan OpenAI SDK:ta ilman siirtymiskustannuksia
- Yhtenäinen laskutus ja seuranta

Kokeile ilmaiseksi osoitteessa [platform.acedata.cloud](https://platform.acedata.cloud).
