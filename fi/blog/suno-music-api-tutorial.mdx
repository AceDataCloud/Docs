## Suno Esittely

Suno on yksi tehokkaimmista AI-musiikin generointialustoista tällä hetkellä. Ace Data Cloudin Suno API:n avulla voit luoda korkealaatuista musiikkia yksinkertaisilla API-kutsuilla.

## API Päätepisteet

| Päätepiste | Toiminto |
|------------|----------|
| `POST /suno/audios` | Musiikin generointi (päätepiste) |
| `POST /suno/lyrics` | Sanoitusten generointi |
| `POST /suno/persona` | Laulajan tyylin hallinta |
| `POST /suno/wav` | WAV-muodon hakeminen |
| `POST /suno/mp4` | MP4-muodon hakeminen |
| `POST /suno/tasks` | Tehtävän tilan tarkistus |

## Perusgenerointi

### Tekstikuvausgenerointi

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Mukautettu sanoitusten generointi

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\nKesän aurinko valaisee rannat\nAaltojen ääni kantautuu tuulessa\n\n[Chorus]\nLähdetään yhdessä kauas pois\nJahtamaan vapaita unelmia",
        "style": "pop upbeat",
        "title": "Kesäseikkailu",
    },
)
```

## Edistyneet Toiminnot

### Kappaleen jatkaminen

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Sanoitusten generointi

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "Kirjoita laulu talvesta",
    },
)
```

## Saatavilla olevat mallit

| Malli | Ominaisuudet |
|--------|--------------|
| chirp-v5 | Uusin versio, paras äänenlaatu |
| v4-5-plus | Paranneltu versio |
| v4-5 | Vakaa versio |
| v4 | Klassinen versio |

## Yhteenveto

Suno API tarjoaa Ace Data Cloud -alustan kautta täydellisen musiikin generointikyvyn. Olipa kyse yksinkertaisesta tekstipohjaisesta generoinnista tai mukautetusta sanoitusten luomisesta, se onnistuu muutamalla koodirivillä.

Rekisteröidy ja kokeile osoitteessa [platform.acedata.cloud](https://platform.acedata.cloud).
