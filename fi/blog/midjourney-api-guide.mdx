## Yleiskatsaus

Midjourney on tällä hetkellä yksi suosituimmista tekoälypohjaisista kuvageneraattoreista. Ace Data Cloud tarjoaa täydellisen Midjourney API:n, joka tukee kuvien generointia, muokkausta, kuvausta, videoita ja muita toimintoja.

## API-päätepisteet

| Päätepiste | Toiminto |
|------------|----------|
| `POST /midjourney/imagine` | Kuvan generointi (päätepiste) |
| `POST /midjourney/edits` | Kuvan muokkaus |
| `POST /midjourney/describe` | Kuvauksen luominen |
| `POST /midjourney/videos` | Kuvasta video |
| `POST /midjourney/seed` | Seed-arvon hakeminen |
| `POST /midjourney/translate` | Kehoteiden käännös |
| `POST /midjourney/tasks` | Tehtävän tilan tarkistus |

## Peruskuvagenerointi

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A serene Japanese garden with cherry blossoms, ultra detailed --ar 16:9",
        "action": "generate",
        "mode": "fast",
    },
)
result = response.json()
print(result)
```

## Kuvan muokkaus

### Suurennus (Upscale)

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "upscale",
        "image_id": "your-image-id",
    },
)
```

### Variantti (Variation)

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "variation",
        "image_id": "your-image-id",
    },
)
```

## Kuvauksen luominen

Kuvasta tekstikuvaus:

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/describe",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "image_url": "https://example.com/your-image.jpg",
    },
)
```

## Kehoteiden vinkit

- Käytä `--ar 16:9` kuvasuhteen ohjaamiseen
- Käytä `--q 2` laadun parantamiseen
- Käytä `--style raw` realistisemman lopputuloksen saamiseksi
- Aseta `translation: true` kääntämään kiinalaiset kehoteet automaattisesti englanniksi

## Asynkroninen callback

Kuvagenerointi vie aikaa, suositellaan callback URL:n käyttöä:

```python
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A futuristic cityscape at night",
        "callback_url": "https://your-server.com/webhook",
    },
)
```

## Yhteenveto

Midjourney API tarjoaa Ace Data Cloudin kautta täydelliset kuvagenerointi- ja muokkausmahdollisuudet. Yksinkertaisesta tekstistä kuvaan -toiminnosta monimutkaisiin muokkaustoimintoihin kaikki onnistuu standardin REST API:n avulla.

Rekisteröidy ja kokeile osoitteessa [platform.acedata.cloud](https://platform.acedata.cloud).
