## Yleiskatsaus

AI-videoiden generointi kehittyy nopeasti. Ace Data Cloud tarjoaa 7 erilaista videoiden generointi API:a, jotka kattavat erilaiset käyttötapaukset tekstistä videoon ja kuvasta videoon.

## Saatavilla olevat videoiden generointipalvelut

| Palvelu | Päätepiste | Malli | Ominaisuudet |
|---------|------------|-------|--------------|
| Sora    | `POST /sora/videos` | sora-2, sora-2-pro | OpenAI:n kehittämä, elokuvatasoinen kuvanlaatu |
| Veo     | `POST /veo/videos` | veo3, veo3-fast | Googlen kehittämä, tukee 4K-tarkkuutta |
| Kling   | `POST /kling/videos` | kling-v2-5-turbo | Kuaishou’n kehittämä, nopea |
| Luma    | `POST /luma/videos` | — | Alku- ja loppukuvan ohjaus |
| Hailuo  | `POST /hailuo/videos` | minimax-t2v | MiniMaxin kehittämä |
| Seedance| `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Byten kehittämä |
| Wan     | `POST /wan/videos` | wan2.6-t2v | Alin kehittämä |

## Nopeasti alkuun

### Sora-videoiden generointi

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Kling-videoiden generointi

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Veo-videoiden generointi

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## Asynkroninen tehtävien käsittely

Videoiden generointi vie yleensä aikaa. Kaikki video-API:t tukevat:

1. **Callback-ilmoitukset**: määritä `callback_url` pyynnössä, niin valmis tulos lähetetään automaattisesti
2. **Polling-kyselyt**: tarkista tehtävän eteneminen `/tasks`-päätepisteen kautta

```python
# Käyttämällä callback URL:ää
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Tai kysely tehtävän tilasta
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## Valintasuositukset

- **Paras kuvanlaatu**: Sora (sora-2-pro)
- **Nopein**: Kling (kling-v2-5-turbo)
- **Korkein resoluutio**: Veo (tukee 4K:ta)
- **Alku- ja loppukuvan ohjaus**: Luma
- **Hinta-laatusuhde**: Wan

Kokeile ilmaiseksi osoitteessa [platform.acedata.cloud](https://platform.acedata.cloud).
