## Mikä on MCP

Model Context Protocol (MCP) on avoin protokolla, joka mahdollistaa AI-avustajien (kuten Claude, Cursor) suoran ulkoisten työkalujen ja API:en kutsumisen. MCP:n avulla AI ei ainoastaan vastaa kysymyksiin, vaan voi myös suorittaa käytännön toimintoja.

## Ace Data Cloudin tarjoamat MCP Serverit

| MCP Server | PyPI-paketti | Toiminto |
|------------|--------------|----------|
| MCPSuno | mcp-suno | AI-musiikin generointi |
| MCPSerp | mcp-serp | Google-haku |
| MCPMidjourney | mcp-midjourney | AI-kuvagenerointi |
| MCPLuma | mcp-luma | AI-videogenerointi |
| MCPSora | mcp-sora | AI-videogenerointi |
| MCPVeo | mcp-veo | AI-videogenerointi |
| MCPNanoBanana | mcp-nano-banana | AI-kuvagenerointi |

## Asennus ja käyttö

### Asennus

```bash
pip install mcp-suno  # tai jokin muu MCP Server
```

### Ympäristömuuttujan asetus

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Konfigurointi Cursorissa

Lisää Cursorin MCP-asetuksiin:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Konfigurointi Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa ja lisää MCP Server -asetukset.

## Käyttötapaukset

1. **Musiikin generointi Cursorissa**: Kerro AI:lle "Luo iloinen kappale Sunolla", AI kutsuu suoraan API:a
2. **Reaaliaikainen tiedonhaku**: AI voi hakea uusimmat tiedot SERP MCP Serverin kautta
3. **Projektimateriaalin generointi**: AI voi kutsua Midjourneytä luodakseen projektin tarvitsemia kuvia

## MCP vs suora API-kutsu

- **MCP**: Sopii AI-ohjelmointityökaluihin, AI kutsuu automaattisesti
- **API**: Sopii oman sovelluksen integrointiin, ohjelmallinen hallinta

Molemmat käyttävät samaa Ace Data Cloud API Tokenia ja kutsuvat samoja API-päätepisteitä.

## Yhteenveto

MCP mahdollistaa AI-avustajien suoran pääsyn Ace Data Cloudin eri API:hin. Kaikki MCP Serverit on julkaistu PyPI:ssä, asennus ja konfigurointi on helppoa, mikä tekee AI-työkaluistasi tehokkaampia.

Hanki API Token osoitteesta [platform.acedata.cloud](https://platform.acedata.cloud).
