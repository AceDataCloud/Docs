[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Luma MCP Serverin avulla voit suoraan luoda AI-videoita Claude Desktopissa, VS Codessa, Cursorissa ja muissa AI-asiakkaissa.

## Toimintojen yleiskatsaus

Luma MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Tekstistä video** — Luo korkealaatuisia videoita tekstikehotteiden avulla
- **Kuvasta video** — Luo videoita käyttäen kuvaa lähtö- tai päätepisteenä
- **Videon jatkaminen** — Jatka olemassa olevan videon viimeisestä kehyksestä
- **Useita kuvasuhteita** — Tukee useita suhteita, kuten 16:9, 9:16, 1:1 jne.
- **Kuvan parantaminen** — Valinnainen visuaalisen laadun parannustoiminto
- **Tehtävien tarkistus** — Seuraa luontiprosessia ja saa tulokset

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Luma Videos API](https://platform.acedata.cloud/documents/luma-videos) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus saa ilmaisia krediittejä)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-luma
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/MCPLuma.git
cd MCPLuma
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-luma` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "luma": {
      "command": "mcp-luma",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "luma": {
      "command": "uvx",
      "args": ["mcp-luma"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta voit käyttää Luma-työkaluja keskustelussa.

## Saatavilla olevat työkalut

| Työkalun nimi                       | Kuvaus                     |
| ---------------------------------- | -------------------------- |
| `luma_generate_video`              | Luo videoita tekstikehotteiden avulla |
| `luma_generate_video_from_image`   | Luo videoita kuvista      |
| `luma_extend_video`                | Jatka olemassa olevaa videota |
| `luma_extend_video_from_url`       | Jatka videota URL:n kautta |
| `luma_get_task`                    | Tarkista yksittäisen tehtävän tila |
| `luma_get_tasks_batch`             | Tarkista useiden tehtävien tila |

## Käyttöesimerkkejä

Kun konfiguraatio on valmis, voit suoraan kutsua näitä toimintoja luonnollisella kielellä AI-asiakkaassa, esimerkiksi:

- "Auta minua luomaan video auringonlaskusta meren rannalla"
- "Käytä tätä kuvaa ensimmäisenä kehys, luo 5 sekunnin video"
- "Jatka tätä videota, pidennä sitä hieman"
- "Luo pystysuuntainen video, suhde 9:16"
