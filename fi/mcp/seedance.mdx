[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin julkaisema mallikontekstiprotokolla, jonka avulla AI-mallit (kuten Claude, GPT jne.) voivat kutsua ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Seedance MCP Serverin avulla voit käyttää ByteDancen Seedancea AI-videoiden luomiseen suoraan AI-asiakkaissa, kuten Claude Desktopissa, VS Codessa ja Cursorissa.

## Toimintojen yleiskatsaus

Seedance MCP Server tarjoaa seuraavat ydintoiminnot:

- **Tekstistä videoksi** — Luo korkealaatuisia videoita tekstikehotteiden avulla
- **Kuvasta videoksi** — Luo videoita kuvan perusteella (ensimmäinen ruutu, viimeinen ruutu, referenssikuva ja muut tilat)
- **Useiden mallien tuki** — Tukee Seedance 1.x:ää, 1.5:tä, 2.0:aa ja 2.5:tä
- **Useita resoluutioita** — Tukee 480p:tä, 720p:tä ja 1080p:tä; jotkin mallit tukevat 4k:ta
- **Useita kuvasuhteita** — Tukee 16:9:ää, 9:16:ta, 1:1:tä, 4:3:a, 3:4:ää, 21:9:ää ja adaptivea
- **Joustava kesto** — Mallista riippuen tuetaan 2–30 sekuntia tai automaattista kestoa
- **Multimodaaliset videot** — Tukee äänen generointia, referenssiääntä/-videota sekä 2.5:n videoeditointia ja pidentämistä
- **Tehtävien kysely** — Seuraa generoinnin edistymistä ja hae tulokset

## Suositus: hallinnoidun MCP:n OAuth-valtuutuksen käyttö

Lisää palvelinosoite asiakkaisiin, jotka tukevat etä-MCP OAuthia:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Valitse yhdistäminen tai kirjautuminen, kirjaudu Ace Data Cloudiin, tarkista käyttöoikeudet ja valtuuta, minkä jälkeen ota työkalut käyttöön. Tämä reitti ei edellytä API-tokenin luomista tai kopioimista etukäteen. Palvelu tukee OAuth discoverya, dynaamista asiakasrekisteröintiä (DCR) ja S256 PKCE:tä; DCR rekisteröi asiakkaan, käyttäjän on silti kirjauduttava sisään ja valtuutettava, ja API-käytöstä veloitetaan normaalisti.

| Asiakas                            | Integrointitapa ja ehdot                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude-verkkoversio tai Desktop-versio, joka tarjoaa etäyhdistimiä | Lisää yllä oleva osoite yhdistimen käyttöliittymään ja valtuuta; pääsy riippuu versiosta ja tilauksesta. Älä kirjoita etä-HTTP-konfiguraatiota paikalliseen stdio-konfiguraatiotiedostoon.                      |
| VS Code, joka tukee natiivisti etä-MCP OAuthia     | Suorita **MCP: Add Server**, valitse HTTP, syötä osoite ja kirjaudu sisään ohjeiden mukaisesti; erillinen AceDataCloud-laajennus käyttää omaa API Key -asetustaan. |
| Muut asiakkaat                          | Varmista, että nykyinen versio tukee etä-HTTP:tä, OAuthia/DCR:ää, ja käytä kyseisen asiakkaan konfigurointiohjeita. Konfiguraatiotiedostomuoto ei ole yhteensopiva eri asiakkaiden välillä.                     |

## API Token -vaihtoehtoinen reitti

Paikallinen stdio, itse isännöidyt ympäristöt tai asiakkaat, jotka eivät tue etä-OAuthia, käyttävät API Tokenia. Kirjaudu sisään [Ace Data Cloud -alustalle](https://platform.acedata.cloud), valitse palvelu ja luo tarvittavilla käyttöoikeuksilla varustetut API-tunnistetiedot. Tallenna Token asiakkaan tunnistetietoasetuksiin tai paikalliseen ympäristömuuttujaan; älä sijoita sitä URL-osoitteeseen, keskustelusisältöön tai versionhallintaan. Eri asiakkaiden HTTP Header -konfiguraatiot tulee täyttää niiden version ohjeiden mukaisesti.

Avoimen lähdekoodin MCP:n asentaminen tai valtuutuksen suorittaminen ei tarkoita maksuttomien käyttökiintiöiden saamista eikä takaa generointiaikaa tai kaupallisia käyttöoikeuksia. Tarkista ennen generointia nykyiset palveluhinnat, saldo ja sovellettavat ehdot.

## Tapa kaksi: paikallinen suoritus (pip / uvx -asennus)

Jos tarvitset paikallista stdioa, mukautettua koodia tai itse isännöintiä, voit käynnistää MCP Serverin paikallisesti. Generointi edellyttää edelleen verkkoyhteyttä API-kutsuja varten, eikä se ole offline-päättelyä.

### Asennus

Asennus pipillä (suositeltu):

```bash
pip install mcp-seedance
```

Tai asennus lähdekoodista:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Asennuksen jälkeen voit käynnistää palvelun `mcp-seedance`-komennolla.

### Käyttö Claude Desktopissa (paikallinen)

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx`:ää (pakettia ei tarvitse asentaa etukäteen):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta se tulee voimaan.

### Käyttö VS Codessa (paikallinen)

Luo `.vscode/mcp.json` projektin juurihakemistoon:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Tai käytä `uvx`:ää:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Muiden paikallisten asiakkaiden osalta täytä command, args ja env niiden nykyisen version stdio-konfigurointiohjeiden mukaan; älä käytä VS Coden konfiguraatiota suoraan yleisenä muotona.

## Tulosten varmistaminen ja yleiset epäonnistumiset

Pyydä asiakasta luomaan yksinkertainen videoteos, säilytä tehtävän tunnus ja kysely samaa tehtävää, kunnes lopputila on onnistunut, ja avaa tai toista sitten lopullinen linkki. Onnistunut yhteys, ladattu työkaluluettelo, HTTP 200, tehtävän tunnus ja käsittelyssä oleva esikatselu eivät tarkoita lopullista tuotosta.

Jos kohtaat virheen 401, kirjaudu uudelleen sisään tai tarkista Token ja käyttöoikeudet; jos saldo ei riitä, tarkista laskutus; jatka kyselyä tehtävän ollessa käsittelyssä; jos lopputulos epäonnistuu, lue virhe ja päätä sitten, yritätkö uudelleen, sillä uudesta generoinnista voidaan veloittaa uudelleen.

## Käytettävissä olevien työkalujen luettelo

| Työkalun nimi                                  | Kuvaus             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Luo video tekstikehotteen avulla    |
| `seedance_generate_video_from_image` | Luo video kuvan perusteella     |
| `seedance_get_task`                  | Kysely yhden tehtävän tilasta       |
| `seedance_get_tasks_batch`           | Kysely tehtävien tiloista erissä       |
| `seedance_list_models`               | Luettele kaikki käytettävissä olevat mallit ja niiden ominaisuudet   |
| `seedance_list_resolutions`          | Luettele käytettävissä olevat resoluutiot ja kuvasuhteet   |
| `seedance_list_actions`              | Luettele kaikki käytettävissä olevat työkalut ja työnkulkuesimerkit |

- ”Luo Seedance 1.5 Pro -mallilla video, jossa on ääni”
