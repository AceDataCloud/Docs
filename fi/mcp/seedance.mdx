[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin kontekstiprotokolla, joka mahdollistaa tekoälymallien, kuten Clauden ja GPT:n, kutsua ulkoisia työkaluja standardoidun rajapinnan kautta. AceData Cloudin tarjoaman Seedance MCP Serverin avulla voit käyttää Bytedancen Seedance AI -videotuotantoa suoraan Claude Desktopissa, VS Codessa, Cursorissa ja muissa AI-asiakasohjelmissa.

## Toimintojen yleiskatsaus

Seedance MCP Server tarjoaa seuraavat keskeiset ominaisuudet:

- **Tekstistä videoon** — korkealaatuisten videoiden generointi tekstipohjaisten kehotteiden avulla
- **Kuvasta videoon** — videoiden generointi kuvia referenssinä käyttäen (alku- ja loppukehys, referenssikuvat ym.)
- **Monimallituen** — tuki Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite ja muille malleille
- **Useita resoluutioita** — tuki 480p, 720p, 1080p resoluutioille
- **Useita kuvasuhteita** — tuki 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 ja muille kuvasuhteille
- **Joustava kesto** — 2–12 sekunnin pituiset videot
- **Äänen generointi** — osassa malleja äänen samanaikainen generointi
- **Tehtävien seuranta** — generointiprosessin valvonta ja tulosten hakeminen

## Ennen aloittamista

Ennen käyttöä sinun tulee hankkia AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos) -sivulle
3. Klikkaa "Acquire" saadaksesi API Tokenin (ensihakemuksella saat ilmaisen käyttökiintiön)

## Asennus ja konfigurointi

### Vaihtoehto 1: pip-asennus (suositeltu)

```bash
pip install mcp-seedance
```

### Vaihtoehto 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Asennuksen jälkeen voit käynnistää palvelun komennolla `mcp-seedance`.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Token"
      }
    }
  }
}
```

Jos käytät `uvx`:ää (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Token"
      }
    }
  }
}
```

Tallenna asetukset ja käynnistä Claude Desktop uudelleen, jolloin Seedance-työkalut ovat käytettävissä keskusteluissa.

## Saatavilla olevat työkalut

| Työkalun nimi                     | Kuvaus                        |
|----------------------------------|------------------------------|
| `seedance_generate_video`        | Videon generointi tekstikehotteesta |
| `seedance_generate_video_from_image` | Videon generointi kuvan pohjalta |
| `seedance_get_task`               | Yhden tehtävän tilan kysely  |
| `seedance_get_tasks_batch`        | Useiden tehtävien tilojen kysely |
| `seedance_list_models`            | Kaikkien käytettävissä olevien mallien ja niiden ominaisuuksien listaus |
| `seedance_list_resolutions`       | Käytettävissä olevien resoluutioiden ja kuvasuhteiden listaus |
| `seedance_list_actions`           | Kaikkien käytettävissä olevien työkalujen ja työnkulkujen esimerkkien listaus |
