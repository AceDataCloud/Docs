[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman SERP MCP Serverin avulla voit suorittaa Google-hakuja suoraan AI-asiakkaissa, kuten Claude Desktop, VS Code, Cursor jne., ja saada verkkosivuja, kuvia, uutisia, videoita, paikkoja jne. hakutuloksia.

## Toimintojen yleiskatsaus

SERP MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Verkkohaku** — Hae Google-verkkotuloksia
- **Kuvahaku** — Hae Google-kuvia
- **Uutishaku** — Hae Google-uutisia
- **Videohaku** — Hae Google-videoita
- **Paikkahaku** — Hae Google-paikkatietoja
- **Karttahaku** — Hae Google-karttaa
- **Monikielisyys ja monialueisuus** — Tukee mukautettuja maa- ja kieliparametreja
- **Aikarajaus** — Suodata tuloksia päivittäin, viikoittain, kuukausittain, vuosittain

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Google SERP API](https://platform.acedata.cloud/documents/serp-google) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus saa ilmaisia krediittejä)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-serp
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/SerpMCP.git
cd SerpMCP
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-serp` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta voit käyttää Google-hakuun liittyviä työkaluja keskusteluissa.

| `serp_google_news`   | Google-uutishaku |
| `serp_google_videos` | Google-videohaku |
| `serp_google_places` | Google-paikkahaku |
| `serp_google_maps`   | Google-karttahaku |
