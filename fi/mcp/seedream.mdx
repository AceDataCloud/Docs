[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä malliympäristöprotokolla, joka mahdollistaa tekoälymallien, kuten Clauden ja GPT:n, kutsua ulkoisia työkaluja standardoidun rajapinnan kautta. AceData Cloudin tarjoaman Seedream MCP Serverin avulla voit käyttää Bytedancen Seedreamin AI-kuvageneraattoria ja -muokkaustyökaluja suoraan Claude Desktopissa, VS Codessa, Cursorissa ja muissa AI-asiakasohjelmissa.

## Toimintojen yleiskatsaus

Seedream MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Tekstistä kuvaan** — Luo korkealaatuisia kuvia tekstipohjaisten ohjeiden avulla (tukee sekä kiinaa että englantia)
- **Kuvien muokkaus** — Muokkaa olemassa olevien kuvien tyyliä, taustaa, ominaisuuksia jne.
- **Virtuaalinen sovitus** — Pukeudu vaatteisiin valokuvassa
- **Monimallituen** — Tukee Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I ja muita malleja
- **Moniresoluutioisuus** — Tukee 1K, 2K, 4K ja adaptiivisia resoluutioita
- **Siemenohjaus** — Mahdollistaa toistettavat tulokset seed-parametrilla
- **Tehtävien seuranta** — Seuraa generoinnin etenemistä ja hae tuloksia

## Ennen aloittamista

Tarvitset AceData Cloud API Tokenin:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images) -sivulle
3. Klikkaa "Acquire" saadaksesi API Tokenin (ensihakemuksella ilmainen käyttöoikeus)

## Asennus ja konfigurointi

### Vaihtoehto 1: pip-asennus (suositeltu)

```bash
pip install mcp-seedream-pro
```

### Vaihtoehto 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Asennuksen jälkeen käynnistä palvelu komennolla `mcp-seedream-pro`.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx`-komentoa (ei vaadi pakettien ennakkoasennusta):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Tallenna ja käynnistä Claude Desktop uudelleen, niin Seedream-työkalut ovat käytettävissä keskusteluissa.

## Saatavilla olevat työkalut

| Työkalun nimi               | Kuvaus                       |
|----------------------------|-----------------------------|
| `seedream_generate_image`  | Luo kuvia tekstipohjaisten ohjeiden avulla |
| `seedream_edit_image`      | Muokkaa tai muunna olemassa olevia kuvia |
| `seedream_get_task`        | Hae yksittäisen tehtävän tila |
| `seedream_get_tasks_batch` | Hae useiden tehtävien tilat erissä |
| `seedream_list_models`     | Listaa kaikki saatavilla olevat mallit ja niiden ominaisuudet |
| `seedream_list_sizes`      | Listaa saatavilla olevat kuvan koot ja resoluutiovaihtoehdot |
