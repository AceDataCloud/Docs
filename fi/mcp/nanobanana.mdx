[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Nano Banana MCP Serverin avulla voit suoraan luoda ja muokata AI-kuvia Claude Desktopissa, VS Codessa, Cursorissa ja muissa AI-asiakkaissa.

## Toimintojen yleiskatsaus

Nano Banana MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Kuvagenerointi** — Luo korkealaatuisia kuvia tekstikehotteiden avulla
- **Kuvamuokkaus** — Muokkaa olemassa olevia kuvia tai yhdistä useita kuvia
- **Virtuaalinen sovitus** — Pukea vaatteita henkilökuviin
- **Tuotteen upottaminen** — Aseta tuote todellisiin kohtauksiin
- **Monimallituen** — Tuki nano-banana-, nano-banana-2- ja nano-banana-pro -malleille
- **Tehtävien kysely** — Seuraa generointiprosessia ja saa tuloksia

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Nano Banana Images API](https://platform.acedata.cloud/documents/nano-banana-images) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus antaa ilmaisen määrän)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-nanobanana-pro
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/NanoBananaMCP.git
cd NanoBananaMCP
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-nanobanana-pro` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": " sinun API Token"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": " sinun API Token"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta voit käyttää Nano Banana -työkaluja keskustelussa.

## Saatavilla olevat työkalut

| Työkalun nimi                  | Kuvaus          |
| ---------------------------- | ----------- |
| `nanobanana_generate_image`  | Luo kuvia tekstikehotteiden avulla |
| `nanobanana_edit_image`      | Muokkaa tai yhdistä olemassa olevia kuvia   |
| `nanobanana_get_task`        | Kysy yksittäisen tehtävän tilaa    |
| `nanobanana_get_tasks_batch` | Kysy useiden tehtävien tilaa    |
