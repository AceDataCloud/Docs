[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallikontekstiprotokolla, joka mahdollistaa tekoälymallien (kuten Claude, GPT jne.) ulkoisten työkalujen kutsumisen standardoidun rajapinnan kautta. AceData Cloudin tarjoaman Flux MCP Serverin avulla voit suoraan luoda ja muokata tekoälykuvia Claude Desktopissa, VS Codessa, Cursorissa ja muissa tekoälyasiakasohjelmissa.

## Ominaisuuskatsaus

Flux MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Tekstistä kuviksi** — korkealaatuisten kuvien luominen tekstipohjaisten ohjeiden avulla  
- **Kuvien muokkaus** — olemassa olevien kuvien muokkaaminen tekstikäskyjen perusteella  
- **Monimallituen** — tuki useille malleille kuten Flux Pro, Flux Dev, Flux Schnell, Flux Kontext  
- **Mallien haku** — kaikkien käytettävissä olevien mallien ja niiden ominaisuuksien tarkastelu  
- **Tehtävien seuranta** — generointiprosessin valvonta ja tulosten hakeminen  

## Ennen käyttöä

Ennen käyttöä sinun tulee hankkia AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)  
2. Siirry [Flux Images API](https://platform.acedata.cloud/documents/flux-images) -sivulle  
3. Klikkaa "Acquire" saadaksesi API Tokenin (ensihakemuksella saat ilmaisen käyttökiintiön)  

## Asennus ja konfigurointi

### Vaihtoehto 1: pip-asennus (suositeltu)

```bash
pip install mcp-flux-pro
```

### Vaihtoehto 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Asennuksen jälkeen voit käynnistää palvelun komennolla `mcp-flux-pro`.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`  
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`  

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx`-komentoa (ei vaadi etukäteisasennusta):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Tokenisi"
      }
    }
  }
}
```

Tallenna asetukset ja käynnistä Claude Desktop uudelleen, niin voit käyttää Flux-työkaluja keskusteluissa.

## Käytettävissä olevat työkalut

| Työkalun nimi           | Kuvaus                        |
|------------------------|------------------------------|
| `flux_generate_image`   | Kuvan generointi tekstipohjaisella ohjeella |
| `flux_edit_image`       | Kuvan muokkaus tekstikäskyjen perusteella    |
| `flux_get_task`         | Yksittäisen tehtävän tilan haku               |
| `flux_get_tasks_batch`  | Useiden tehtävien tilan haku erissä           |
| `flux_list_models`      | Kaikkien käytettävissä olevien mallien ja niiden ominaisuuksien listaus |
| `flux_list_actions`     | Kaikkien käytettävissä olevien työkalujen ja työnkulkujen esimerkkien listaus |
