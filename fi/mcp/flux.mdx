[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallikontekstiprotokolla, jonka avulla tekoälymallit (kuten Claude, GPT jne.) voivat kutsua ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Flux MCP Serverin avulla voit luoda ja muokata AI-kuvia suoraan tekoälyasiakkaissa, kuten Claude Desktopissa, VS Codessa ja Cursorissa.

## Toimintojen yleiskatsaus

Flux MCP Server tarjoaa seuraavat ydintoiminnot:

- **Tekstistä kuvaksi -generointi** — Luo korkealaatuisia kuvia tekstikehotteiden avulla
- **Kuvien muokkaus** — Muokkaa olemassa olevia kuvia tekstiohjeiden perusteella
- **Useiden mallien tuki** — Tukee useita malleja, kuten Flux Pro, Flux Dev, Flux 2 ja Flux Kontext
- **Mallien kysely** — Tarkastele kaikkia käytettävissä olevia malleja ja niiden ominaisuuksia
- **Tehtävien kysely** — Seuraa generoinnin etenemistä ja hae tulokset

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Flux Images API](https://platform.acedata.cloud/documents/flux-images) -sivulle
3. Napsauta ”Acquire” saadaksesi API Tokenin (ensimmäiseen hakemukseen sisältyy maksutonta käyttökiintiötä)

## Tapa yksi: Käytä isännöityä MCP Serveriä (suositeltu, ei asennusta)

AceData Cloud on jo isännöinyt **Flux MCP Serverin** pilvessä, joten **sinun ei tarvitse asentaa mitään riippuvuuksia paikallisesti**. Syötä vain seuraava URL tekoälyasiakkaaseen käyttääksesi sitä:

```
https://flux.mcp.acedata.cloud/mcp
```

Todennustapa: lisää pyyntöotsikkoon `Authorization: Bearer 你的API Token` (Claude.ai hoitaa tämän automaattisesti OAuthin kautta, joten Tokenia ei tarvitse syöttää manuaalisesti).

### Claude.ai (verkkoversio, OAuth-kirjautuminen, helpoin)

1. Avaa [Claude.ai](https://claude.ai) → vasemmasta alakulmasta **Customize** → **Connectors** → **Add More**
2. Syötä URL-kohtaan: `https://flux.mcp.acedata.cloud/mcp`
3. Suorita OAuth-valtuutuskirjautuminen (sinut ohjataan automaattisesti AceData Cloudin kirjautumissivulle)
4. Palaa keskustelunäkymään, ja työkalut ovat käytettävissä

### Claude Desktop

Muokkaa määritystiedostoa:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Tallenna ja käynnistä Claude Desktop uudelleen, jotta muutokset tulevat voimaan.

### Claude Code (terminaalin komentorivi)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Muut MCP:tä tukevat asiakkaat

Mikä tahansa MCP Streamable HTTP -protokollaa tukeva asiakas (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant jne.) voidaan yhdistää täyttämällä seuraavat kaksi kohtaa:

## Tapa kaksi: Paikallinen suoritus (pip / uvx -asennus)

Jos tarvitset offline-suoritusta, mukautettua koodia tai käyttöönottoa sisäverkossa, voit asentaa MCP Serverin paikallisesti ja käynnistää sen stdion kautta.

### Asennus

Asennus pipillä (suositeltu):

```bash
pip install mcp-flux-pro
```

Tai asennus lähdekoodista:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Kun asennus on valmis, voit käynnistää palvelun komennolla `mcp-flux-pro`.

### Käyttö Claude Desktopissa (paikallinen)

Muokkaa Claude Desktopin määritystiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava määritys:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Jos käytät `uvx`:ää (pakettia ei tarvitse asentaa etukäteen):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Tallenna määritys ja käynnistä Claude Desktop uudelleen, jotta muutokset tulevat voimaan.

## Käytettävissä olevien työkalujen luettelo

| Työkalun nimi                    | Kuvaus                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Luo kuvia tekstikehotteiden avulla              |
| `flux_edit_image`      | Muokkaa olemassa olevia kuvia tekstiohjeiden perusteella             |
| `flux_generate_video`  | FLUX 3:n tekstistä kuvaksi / kuvasta videoksi / videon generointi sekä olemassa olevien luonnosten parantaminen |
| `flux_get_task`        | Kysyy yksittäisen tehtävän tilan                 |
| `flux_get_tasks_batch` | Kysyy tehtävien tilat erissä                 |
| `flux_list_models`     | Luettelee kaikki käytettävissä olevat mallit ja niiden ominaisuudet             |
| `flux_list_actions`    | Luettelee kaikki käytettävissä olevat työkalut ja työnkulkuesimerkit           |

## Mallien ja kokojen rajoitukset
`flux-2-flex`-, `flux-2-pro`-, `flux-2-max`- ja Kontext-mallien `size`-parametrin on käytettävä
kuvasuhdetta, esimerkiksi `1:1` tai `16:9`, eikä pikselimittoja, kuten `1024x1024`.
`flux-2-klein` tukee vain generointia, eikä se kuulu `flux_edit_image`-toiminnon valittaviin malleihin.

`flux_generate_video` erottaa `t2v`-, `i2v`-, `v2v`- ja
`draft_enhance`-tilat `request.mode`-parametrin avulla, ja syöte näytetään tilan mukaan. Luonnoksen parannuksen on viitattava omaan väliaikaiseen `draft_task_id`-tunnukseensa.
Lähetys on oletusarvoisesti asynkroninen; säilytä palautettu tehtävätunnus ja käytä `flux_get_task`-toimintoa tuloksen lukemiseen.
