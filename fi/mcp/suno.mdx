[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin julkaisema mallikontekstiprotokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsua ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Suno MCP Serverin avulla voit luoda musiikkia ja sanoituksia suoraan AI-asiakkaissa, kuten Claude Desktopissa, VS Codessa ja Cursorissa, sekä hallita ääniprojekteja.

## Toimintojen yleiskatsaus

Suno MCP Server tarjoaa seuraavat ydintoiminnot:

- **Musiikin luonti** — Luo AI-musiikkia tekstikehotteiden avulla
- **Mukautettu luominen** — Hallitse täysin sanoituksia, otsikkoa ja musiikkityyliä
- **Kappaleen jatkaminen** — Jatka olemassa olevan kappaleen pidentämistä mistä tahansa ajankohdasta
- **Cover/remix** — Luo cover-versioita eri tyyleillä
- **Sanoitusten luonti** — Luo jäsenneltyjä sanoituksia kuvauksen perusteella
- **Lauluroolit** — Tallenna ja käytä uudelleen äänityylejä
- **Mediakonversio** — Hae MP4-, WAV-, MIDI-tiedostoja, lauluäänien erotteluja jne.
- **Tyylin optimointi** — Optimoi musiikkityylitunnisteita
- **Tehtävien kysely** — Seuraa luomisen edistymistä ja hae tuloksia

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry sivulle [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Napsauta ”Acquire” saadaksesi API Tokenin (ensimmäinen hakemus sisältää ilmaista käyttökiintiötä)

## Tapa yksi: Käytä isännöityä MCP Serveriä (suositellaan, ei asennusta)

AceData Cloud on jo isännöinyt **Suno MCP Serverin** pilvessä, joten **sinun ei tarvitse asentaa mitään riippuvuuksia paikallisesti**. Syötä seuraava URL suoraan AI-asiakkaaseen käyttääksesi sitä:

```
https://suno.mcp.acedata.cloud/mcp
```

Todennusmenetelmä: lisää pyyntöotsikkoon `Authorization: Bearer sinun API Tokenisi` (Claude.ai suorittaa tämän automaattisesti OAuthin kautta, joten Tokenia ei tarvitse syöttää manuaalisesti).

### Claude.ai (verkkoversio, OAuth-kirjautuminen, helpoin)

1. Avaa [Claude.ai](https://claude.ai) → vasemmassa alakulmassa **Customize** → **Connectors** → **Add More**
2. Syötä URL-kohtaan: `https://suno.mcp.acedata.cloud/mcp`
3. Suorita OAuth-valtuutuskirjautuminen (sinut ohjataan automaattisesti AceData Cloudin kirjautumissivulle)
4. Palaa keskustelunäkymään, ja työkalu on käytettävissä

### Claude Desktop

Muokkaa asetustiedostoa:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Tallenna ja käynnistä Claude Desktop uudelleen, jotta muutokset tulevat voimaan.

### Claude Code (terminaalin komentorivi)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Muut MCP:tä tukevat asiakkaat

Mikä tahansa MCP Streamable HTTP -protokollaa tukeva asiakas (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant jne.) voidaan yhdistää täyttämällä seuraavat kaksi kohtaa:

## Tapa kaksi: Paikallinen suoritus (pip / uvx -asennus)

Jos tarvitset offline-suoritusta, mukautettua koodia tai käyttöönottoa sisäverkossa, voit asentaa MCP Serverin paikallisesti ja käynnistää sen stdion kautta.

### Asennus

pip-asennus (suositellaan):

```bash
pip install mcp-suno
```

Tai asennus lähdekoodista:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Kun asennus on valmis, voit käynnistää palvelun komennolla `mcp-suno`.

### Käyttö Claude Desktopissa (paikallinen)

Muokkaa Claude Desktopin asetustiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava määritys:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Jos käytät `uvx`:ää (pakettia ei tarvitse asentaa etukäteen):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Tallenna määritys ja käynnistä Claude Desktop uudelleen, jotta muutokset tulevat voimaan.

## Edistynyt hallinta ja Studio-projektit

`suno_generate_music` tukee `variety`-asetusta; `suno_generate_custom_music` tukee lisäksi
`max_mode`- ja `audio_weight`-asetuksia. `max_mode` käyttää korkeampaa API-laskutustasoa, ei ole oletuksena käytössä,
ja se tulisi asettaa, kun käyttäjä valitsee nimenomaisesti tehostetun tilan. Ajantasaiset hinnat ovat alustapalvelusivun mukaisia.

`suno_generate_with_custom_model` voi käyttää `instrumental=true`-asetusta instrumentaalimusiikin luomiseen tai käyttää
`lyric_prompt`-asetusta sanoitusten automaattiseen luomiseen; muussa tapauksessa anna `lyric`. Otsikko ja tyyli voidaan jättää pois, ja lisäksi voidaan välittää
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` ja
`callback_url`. Nimenomaiset `0`-ohjausarvot säilytetään.

`suno_manage_project`-toiminnon `request.action` voi olla `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track` tai `render`. Syötteet vaihtelevat toiminnon mukaan, ja projektimuutoksissa tulisi käyttää viimeksi takaisin haettua `version_id`-arvoa;
tallennettaessa välitä täydellinen `state`, säilyttäen olemassa olevat raidat ja kentät.

`retrieve`-toimintoa lukuun ottamatta jokaisessa kutsussa on annettava `idempotency_key`. Käytä uusissa kirjoitustoiminnoissa uutta avainta;
jos aikakatkaisu tapahtuu tai hyväksynnän tulos on epävarma, säilytä alkuperäinen avain ja yritä uudelleen täysin samalla pyynnöllä tai kysy alkuperäistä tehtävää; älä automaattisesti
vaihda avainta ja lähetä maksullista luontipyyntöä uudelleen. Lähdeäänen aikavälit ilmoitetaan sekunteina ja projektin aikajanan aikavälit iskuina. Luonti luo vain ehdokkaita,
ja raidalle kirjoitetaan vasta, kun ehdokas on valittu ja `commit_candidate` kutsuttu.

Asynkronisesti hyväksytyn pyynnön `task_id` kysytään `suno_get_task`-toiminnolla. Kun `finished_at` on tyhjä, jatka odottamista;
tarkista lopputilan jälkeen `response.success` ja virheet; älä pidä hyväksynnän onnistumista luomisen, vahvistamisen tai viennin onnistumisena.
`suno_get_tasks_batch` palauttaa täydelliset JSON-tehtävätietueet säilyttäen mukautetut mallikohteet, projektitilan,
ehdokkaat sekä erilaiset tulokset, kuten MIDI-tiedostot. Katso koko työnkulku [Studio-projektiohjeesta](https://platform.acedata.cloud/documents/suno-projects-integration).
