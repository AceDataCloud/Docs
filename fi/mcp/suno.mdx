[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Suno MCP Serverin avulla voit suoraan luoda musiikkia, sanoituksia ja hallita ääniprojekteja Claude Desktopissa, VS Codessa, Cursorissa ja muissa AI-asiakkaissa.

## Toimintojen yleiskatsaus

Suno MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Musiikin luominen** — Luo AI-musiikkia tekstikehotteiden avulla
- **Mukautettu luominen** — Täydellinen hallinta sanoituksista, otsikoista ja musiikkityyleistä
- **Kappaleen jatkaminen** — Jatka olemassa olevaa kappaletta mistä tahansa ajankohdasta
- **Kansiversiot / remixit** — Luo kansiversioita eri tyyleillä
- **Sanoitusten luominen** — Luo jäsenneltyjä sanoituksia kuvauksen perusteella
- **Ääniroolit** — Tallenna ja käytä äänen tyylejä uudelleen
- **Mediamuunnos** — Hanki MP4, WAV, MIDI, äänierottelu jne.
- **Tyylin optimointi** — Optimoi musiikkityylin tunnisteet
- **Tehtävien kysely** — Seuraa luontiprosessia ja saa tulokset

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus antaa ilmaisen määrän)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-suno
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/MCPSuno.git
cd MCPSuno
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-suno` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta voit käyttää Suno-työkaluja keskustelussa.

## Saatavilla olevat työkalut

| Työkalun nimi                  | Kuvaus           |
| ---------------------------- | ------------ |
| `suno_generate_music`        | Luo musiikkia tekstikehotteiden avulla  |
| `suno_generate_custom_music` | Luo musiikkia mukautetuilla sanoituksilla ja tyyleillä |
| `suno_extend_music`          | Jatka kappaletta määritellystä ajankohdasta   |
| `suno_cover_music`           | Luo kansiversioita       |
| `suno_concat_music`          | Yhdistä kappaleita       |
| `suno_generate_with_persona` | Luo musiikkia määritellyllä ääniroolilla |
| `suno_remaster_music`        | Uudelleen masterointi       |
| `suno_stems_music`           | Erota ääniraitoja (laulu/taustamusiikki)  |
| `suno_replace_section`       | Korvaa kappaleen tietty osa   |
| `suno_upload_extend`         | Lataa ääntä ja jatka kirjoittamista      |
| `suno_upload_cover`          | Lataa ääntä ja tee kansiversio      |
| `suno_mashup_music`          | Yhdistä useita kappaleita       |
| `suno_generate_lyrics`       | Luo sanoituksia kuvauksen perusteella     |
| `suno_create_persona`        | Luo äänirooli       |
| `suno_get_mp4`               | Hanki kappaleen MP4-video  |
| `suno_get_timing`            | Hanki sanoitusten aikajanan      |
| `suno_extract_vocals`        | Erota laulu         |
| `suno_get_wav`               | Hanki korkealaatuinen WAV    |
| `suno_get_midi`              | Hanki MIDI-tiedosto   |
| `suno_optimize_style`        | Optimoi musiikkityylin tunnisteet     |
| `suno_mashup_lyrics`         | Yhdistä sanoituksia         |
| `suno_upload_audio`          | Lataa mukautettua ääntä      |
| `suno_get_task`              | Kysy yksittäisen tehtävän tila     |
| `suno_get_tasks_batch`       | Kysy useiden tehtävien tilat     |

## Käytt esimerkit

Kun konfiguraatio on valmis, voit suoraan käyttää näitä toimintoja luonnollisella kielellä AI-asiakkaassa, esimerkiksi:

- "Auta minua luomaan kesäaiheinen popmusiikki"
- "Laula tämä kappale jazz-tyylillä"
- "Jatka tätä kappaletta 30 sekunnista alkaen"
- "Luo kiinalaiset sanoitukset, teema on matkustaminen"
- "Erota tämän kappaleen laulu"
- "Auta minua muuntamaan tämä kappale MIDI-muotoon"
