[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Veo MCP Serverin avulla voit käyttää Google Veota suoraan AI-asiakkaissa, kuten Claude Desktop, VS Code, Cursor jne., AI-videoiden luomiseen.

## Toimintojen yleiskatsaus

Veo MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Tekstistä video** — Luo korkealaatuisia videoita tekstikehotteiden avulla
- **Kuvasta video** — Luo videoita kuvien perusteella
- **Monimallituen** — Tukee malleja kuten veo3, veo2, veo31-fast-ingredient jne.
- **Monet resoluutiot** — Tukee 4K, 1080p, GIF jne. tulostusmuotoja
- **Monet kuvasuhteet** — Tukee 16:9, 9:16 jne. suhteita
- **1080p-päivitys** — Päivitä jo luotu video 1080p:hen
- **Tehtävien kysely** — Seuraa luontiprosessia ja saa tulokset

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus antaa ilmaisen määrän)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-veo
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-veo` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta voit käyttää Veo-työkaluja keskustelussa.

## Saatavilla olevat työkalut

| Työkalun nimi           | Kuvaus           |
| --------------------- | ------------ |
| `veo_text_to_video`   | Luo videoita tekstikehotteiden avulla  |
| `veo_image_to_video`  | Luo videoita kuvien perusteella   |
| `veo_get_1080p`       | Päivitä video 1080p:hen |
| `veo_get_task`        | Kysy yksittäisen tehtävän tila     |
| `veo_get_tasks_batch` | Kysy useiden tehtävien tilat     |

## Käyttöesimerkkejä

Kun konfiguraatio on valmis, voit kutsua näitä toimintoja suoraan luonnollisella kielellä AI-asiakkaassa, esimerkiksi:

- "Auta minua luomaan tähtitaivasta kuvaava aikakatkaisuvideo Veolla"
- "Luo 4K-video tästä maisemakuvasta"
- "Luo pystysuuntainen 9:16 lyhytvideo"
- "Päivitä tämä video 1080p:hen"
