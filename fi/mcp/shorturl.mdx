[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallikontekstiprotokolla, joka mahdollistaa tekoälymallien, kuten Clauden ja GPT:n, kutsua ulkoisia työkaluja standardoidun rajapinnan kautta. AceData Cloudin tarjoaman ShortURL MCP Serverin avulla voit luoda lyhyitä linkkejä suoraan AI-asiakasohjelmissa kuten Claude Desktop, VS Code ja Cursor.

## Toimintojen yleiskatsaus

ShortURL MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Yksittäisen linkin lyhentäminen** — Muuntaa pitkän URL-osoitteen lyhyeksi ja helposti jaettavaksi linkiksi
- **Linkkien massalyhennys** — Lyhentää useita URL-osoitteita kerralla (enintään 10)
- **Käyttöohjeet** — Saat täydelliset käyttöohjeet ja parhaat käytännöt
- **API-tiedot** — Näytä API-palvelun tiedot ja virhekoodien selitykset

## Ennen käyttöä

Ennen käyttöä sinun tulee hankkia AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [ShortURL API](https://platform.acedata.cloud/documents/short-url) -sivulle
3. Klikkaa "Acquire" saadaksesi API Tokenin (ensihakemuksella saat ilmaisen käyttökiintiön)

## Asennus ja konfigurointi

### Vaihtoehto 1: pip-asennus (suositeltu)

```bash
pip install mcp-shorturl
```

### Vaihtoehto 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Asennuksen jälkeen voit käynnistää palvelun komennolla `mcp-shorturl`.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Token"
      }
    }
  }
}
```

Jos käytät `uvx`:ää (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "sinun API Token"
      }
    }
  }
}
```

Tallenna asetukset ja käynnistä Claude Desktop uudelleen, niin voit käyttää ShortURL-työkaluja keskusteluissa.

## Saatavilla olevat työkalut

| Työkalun nimi           | Kuvaus                          |
|------------------------|--------------------------------|
| `shorturl_create`      | Lyhentää yksittäisen URL-osoitteen |
| `shorturl_batch_create`| Lyhentää useita URL-osoitteita kerralla (enintään 10) |
| `shorturl_get_usage_guide` | Hakee täydellisen käyttöohjeen |
| `shorturl_get_api_info`| Hakee API-palvelun tiedot       |

## Käyttöesimerkkejä

Konfiguroinnin jälkeen voit kutsua toimintoja luonnollisella kielellä AI-asiakasohjelmassa, esimerkiksi:

- "Lyhennä tämä linkki minulle"
- "Lyhennä nämä 5 URL-osoitetta kerralla"
- "Luo lyhyt linkki jaettavaksi"
