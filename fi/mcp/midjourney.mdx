[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Midjourney MCP Serverin avulla voit suoraan luoda ja muokata AI-kuvia Claude Desktopissa, VS Codessa, Cursorissa ja muissa AI-asiakkaissa.

## Toimintojen yleiskatsaus

Midjourney MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Kuvagenerointi (Imagine)** — Luo korkealaatuisia kuvia tekstikehotteiden avulla
- **Kuvamuokkaus** — Tee paikallisia muutoksia jo luotuihin kuviin
- **Kuvamuunnos** — Suurenna, pienennä tai siirrä olemassa olevia kuvia
- **Kuvayhdistäminen (Blend)** — Yhdistä useita kuvia uudeksi kuvaksi
- **Viitekuvagenerointi** — Käytä viitekuvia ohjaamaan generointia
- **Kuvakuvaus (Describe)** — Luo tekstikuvaus kuvan perusteella
- **Kehoitteiden käännös** — Käännä kiinalaiset kehoitteet englanniksi
- **Siemenen hankinta** — Hanki kuvan siemenarvo toistettavuutta varten
- **Videogenerointi** — Luo dynaaminen video kuvien perusteella
- **Tehtävien tarkistus** — Seuraa generointiprosessia ja hanki tulokset

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Midjourney Imagine API](https://platform.acedata.cloud/documents/midjourney-imagine) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus saa ilmaisia krediittejä)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-midjourney
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/MidjourneyMCP.git
cd MidjourneyMCP
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-midjourney` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jolloin voit käyttää Midjourney-työkaluja keskustelussa.

## Saatavilla olevat työkalut

| Työkalun nimi                  | Kuvaus         |
| ---------------------------- | ------------ |
| `midjourney_imagine`         | Luo kuvia tekstikehotteiden avulla  |
| `midjourney_edit`            | Muokkaa olemassa olevan kuvan osia  |
| `midjourney_transform`       | Suurenna, pienennä tai siirrä olemassa olevia kuvia |
| `midjourney_blend`           | Yhdistä useita kuvia yhdeksi   |
| `midjourney_with_reference`  | Luo kuva viitekuvasta    |
| `midjourney_describe`        | Luo tekstikuvaus kuvan perusteella   |
| `midjourney_translate`       | Käännä kehoitteet englanniksi     |
| `midjourney_get_seed`        | Hanki kuvan siemenarvo |
| `midjourney_generate_video`  | Luo video kuvien perusteella     |
| `midjourney_extend_video`    | Pidennä olemassa olevaa videota       |
| `midjourney_get_task`        | Tarkista yksittäisen tehtävän tila     |
| `midjourney_get_tasks_batch` | Tarkista useiden tehtävien tila     |
