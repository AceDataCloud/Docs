[MCP (Model Context Protocol)](https://modelcontextprotocol.io) on Anthropicin kehittämä mallin konteksti-protokolla, joka mahdollistaa AI-mallien (kuten Claude, GPT jne.) kutsuvan ulkoisia työkaluja standardoitujen rajapintojen kautta. AceData Cloudin tarjoaman Sora MCP Serverin avulla voit käyttää OpenAI Soraa suoraan AI-asiakkaissa, kuten Claude Desktop, VS Code, Cursor jne., luodaksesi AI-videoita.

## Toimintojen yleiskatsaus

Sora MCP Server tarjoaa seuraavat keskeiset toiminnot:

- **Tekstistä video** — Luo korkealaatuisia videoita tekstikehotteiden avulla
- **Kuvasta video** — Luo videoita kuvien perusteella
- **Hahmon johdonmukaisuusvideo** — Säilyttää hahmon johdonmukaisuuden viittauskuvien avulla
- **Asynkroninen luonti** — Tukee asynkronisten tehtävien lähettämistä ja tulosten kyselyä
- **Useita kuvakokoja** — Tukee vaaka- (landscape) ja pystysuoraa (portrait) kuvaa
- **Tehtävien kysely** — Seuraa luontiprosessia ja saa tulokset

## Esivalmistelut

Ennen käyttöä sinun on hankittava AceData Cloud API Token:

1. Rekisteröidy tai kirjaudu sisään [AceData Cloud -alustalle](https://platform.acedata.cloud)
2. Siirry [Sora Videos API](https://platform.acedata.cloud/documents/sora-videos) -sivulle
3. Napsauta "Acquire" saadaksesi API Token (ensimmäinen hakemus saa ilmaisia krediittejä)

## Asennus ja konfigurointi

### Tapa 1: pip-asennus (suositeltava)

```bash
pip install mcp-sora
```

### Tapa 2: Lähdekoodin asennus

```bash
git clone https://github.com/AceDataCloud/MCPSora.git
cd MCPSora
pip install -e .
```

Asennuksen jälkeen voit käyttää `mcp-sora` -komentoa palvelun käynnistämiseen.

## Käyttö Claude Desktopissa

Muokkaa Claude Desktopin konfiguraatiotiedostoa:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Lisää seuraava konfiguraatio:

```json
{
  "mcpServers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Jos käytät `uvx` (ei tarvitse asentaa paketteja etukäteen):

```json
{
  "mcpServers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "API Tokenisi"
      }
    }
  }
}
```

Tallenna konfiguraatio ja käynnistä Claude Desktop uudelleen, jotta voit käyttää Sora-työkaluja keskustelussa.

## Saatavilla olevat työkalut

| Työkalun nimi                          | Kuvaus                     |
| ------------------------------------ | ------------------------- |
| `sora_generate_video`                | Luo videoita tekstikehotteiden avulla    |
| `sora_generate_video_from_image`     | Luo videoita kuvien perusteella     |
| `sora_generate_video_with_character` | Luo johdonmukaisia videoita viittauskuvien avulla |
| `sora_generate_video_async`          | Asynkroninen videoiden luontitehtävä     |
| `sora_get_task`                      | Kysyy yksittäisen tehtävän tilan       |
| `sora_get_tasks_batch`               | Kysyy useiden tehtävien tilan       |

## Käyttöesimerkki

Kun konfiguraatio on valmis, voit kutsua näitä toimintoja suoraan luonnollisella kielellä AI-asiakkaassa, esimerkiksi:

- "Auta minua luomaan video kissasta, joka juoksee nurmikolla Soran avulla"
- "Luo video tästä henkilökuvasta, säilyttäen hahmon johdonmukaisuuden"
- "Luo pystysuora video, jonka sisältö on kaupungin auringonnousu"
- "Asynkronisesti luo video ja kysy tuloksia myöhemmin"
