## Yleiskatsaus

AI-musiikin generointi mahdollistaa luojille korkealaatuisen musiikin tuottamisen ilman ammattimaista musiikkitietämystä. Suno ja Producer edustavat kahta erilaista AI-musiikin generointilähestymistapaa, joita kutsutaan yhtenäisesti Ace Data Cloudin kautta.

## Käytettävät palvelut

- **Suno**: `POST https://api.acedata.cloud/suno/audios`
- **Producer**: `POST https://api.acedata.cloud/producer/audios`

## Tekninen ratkaisu

### Edellytykset

1. Rekisteröidy [Ace Data Cloud](https://platform.acedata.cloud) -palveluun
2. Hanki API Token
3. Asenna Python 3.7+ ja requests-kirjasto

### Toteutusvaiheet

### Vaihe 1: Valitse musiikkimoottori

Suno tukee monen tyylisiä kappaleita, kun taas Producer (FUZZ) keskittyy korkealaatuiseen musiikin tuotantoon.

### Vaihe 2: Generoi musiikki

Suno käyttää `/suno/audios`-päätepistettä, Producer käyttää `/producer/audios`-päätepistettä.

### Vaihe 3: Mukauta sanoituksia

Aseta `custom: true` ja tarjoa `lyric`-kenttä luodaksesi musiikkia mukautetuilla sanoituksilla.

## Koodiesimerkki

Alla on täydellinen Python-esimerkki Sunon käyttämisestä:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_suno():
    response = requests.post(
        "https://api.acedata.cloud/suno/audios",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
},
    )
    return response.json()

result = call_suno()
print(result)
```

## Parhaat käytännöt

- **Virheiden uudelleenyrittäminen**: Käytä eksponentiaalista takaisinvetäytymistä virheille 429 (rajoitus) ja 5xx
- **Asynkroninen käsittely**: Pitkään kestävissä tehtävissä (kuva-/video generointi) käytä callback_url:ia tulosten vastaanottamiseen asynkronisesti
- **Kustannusten hallinta**: Seuraa käyttöä ja kuluja Ace Data Cloud -konsolista
- **Tokenin turvallisuus**: Tallenna API Token ympäristömuuttujiin, älä kovakoodaa koodiin
