## Yleiskatsaus

Model Context Protocol (MCP) on uusi protokolla, jonka avulla tekoälyohjelmointiavustajat voivat suoraan kutsua ulkoisia työkaluja ja API-rajapintoja. Ace Data Cloud tarjoaa useita MCP-palvelimia (Suno, Midjourney, SERP jne.), joita voi käyttää suoraan Cursor-, Claude Desktop -työkaluissa.

## Palvelut

- **Suno**: `POST https://api.acedata.cloud/suno/audios`
- **Midjourney**: `POST https://api.acedata.cloud/midjourney/imagine`
- **Google-haku**: `POST https://api.acedata.cloud/serp/google`

## Tekninen ratkaisu

### Esivaatimukset

1. Rekisteröidy [Ace Data Cloud](https://platform.acedata.cloud) -palveluun
2. Hanki API Token
3. Asenna Python 3.7+ ja requests-kirjasto

### Toteutusvaiheet

### Vaihe 1: Asenna MCP-palvelin

Asenna pipillä: `pip install mcp-suno` (tai mcp-midjourney, mcp-serp).

### Vaihe 2: Määritä Token

Aseta ympäristömuuttuja `ACEDATACLOUD_API_TOKEN` API Tokenillesi.

### Vaihe 3: Käytä ohjelmointityökaluissa

Lisää vastaava palvelin MCP-asetuksiin Cursorissa tai Claude Desktopissa.

## Koodiesimerkki

Alla on täydellinen Python-esimerkki Sunon käytöstä:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_suno():
    response = requests.post(
        "https://api.acedata.cloud/suno/audios",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "action": "generate",
    "prompt": "A cheerful pop song about summer vacation",
    "model": "chirp-v5",
    "custom": false
},
    )
    return response.json()

result = call_suno()
print(result)
```

## Parhaat käytännöt

- **Virheiden uudelleenyrittäminen**: Käytä eksponentiaalista takaisinvetäytymistä 429 (rajoitus) ja 5xx-virheiden kohdalla
- **Asynkroninen käsittely**: Pitkään kestävissä tehtävissä (kuva-/videotuotanto) käytä callback_url:ia tulosten vastaanottamiseen asynkronisesti
- **Kustannusten hallinta**: Seuraa käyttöä ja kuluja Ace Data Cloud -hallintapaneelista
- **Tokenin turvallisuus**: Tallenna API Token ympäristömuuttujaan, älä kovakoodaa sitä koodiin
