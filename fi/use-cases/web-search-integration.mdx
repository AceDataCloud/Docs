## Yleiskatsaus

Reaaliaikaisen hakutoiminnon integroiminen sovellukseen mahdollistaa käyttäjien pääsyn ajantasaisiin tietoihin. Ace Data Cloudin SERP API tarjoaa Googlen haun jäsenneltyä dataa, tukien erilaisia hakutyyppejä kuten verkkosivut, kuvat ja uutiset.

## Käytettävät palvelut

- **Google Search**: `POST https://api.acedata.cloud/serp/google`

## Tekninen ratkaisu

### Esivaatimukset

1. Rekisteröidy tilille [Ace Data Cloudissa](https://platform.acedata.cloud)
2. Hanki API Token
3. Asenna Python 3.7+ ja requests-kirjasto

### Toteutusvaiheet

### Vaihe 1: Määritä hakuparametrit

Aseta parametrit kuten `query`, `type`, `language`, `country`.

### Vaihe 2: Kutsu hakurajapintaa

Lähetä hakupyyntö `POST /serp/google` -endpointiin.

### Vaihe 3: Jäsennä hakutulokset

Käsittele palautettu jäsennelty data, ja poimi otsikot, linkit, tiivistelmät ym.

## Koodiesimerkki

Alla on täydellinen Python-esimerkki Google Searchin käyttämisestä:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_serp():
    response = requests.post(
        "https://api.acedata.cloud/serp/google",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "query": "artificial intelligence latest news",
    "type": "search",
    "number": 10,
    "language": "en",
    "country": "US"
},
    )
    return response.json()

result = call_serp()
print(result)
```

## Parhaat käytännöt

- **Virheiden uudelleenyritys**: Käytä eksponentiaalista takaisinvetoa virheille 429 (rajoitus) ja 5xx
- **Asynkroninen käsittely**: Pitkään kestävissä tehtävissä (kuva-/videoiden generointi) käytä callback_url:ia tulosten vastaanottoon asynkronisesti
- **Kustannusten hallinta**: Seuraa käyttöä ja kuluja Ace Data Cloudin hallintapaneelista
- **Tokenin turvallisuus**: Tallenna API Token ympäristömuuttujaan, älä kovakoodaa koodiin
