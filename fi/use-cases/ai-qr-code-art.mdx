---

## Yleiskatsaus

Perinteiset QR-koodit ovat usein samanlaisia, mutta AI-taiteen QR-koodit voivat sisällyttää brändielementtejä QR-koodin suunnitteluun, mikä parantaa skannausastetta. Ace Data Cloudin QR Art API tukee useita taidetyylien esiasetuksia.

## Palvelut

- **QR Art**: `POST https://api.acedata.cloud/qrart/generate`

## Tekninen ratkaisu

### Esivaatimukset

1. Rekisteröidy tilille [Ace Data Cloudissa](https://platform.acedata.cloud)
2. Hanki API-token
3. Asenna Python 3.7+ ja requests-kirjasto

### Toteutusvaiheet

### Vaihe 1: Määritä QR-koodin sisältö

Valitse tyyppi (linkki/teksti/sähköposti/puhelin) ja aseta sisältö.

### Vaihe 2: Valitse taidetyyli

Käytä `preset`-parametria valitaksesi esiasetettu tyyli, kuten sunset, floral, neon-mech.

### Vaihe 3: Luo ja lataa

Kutsu `/qrart/generate` -rajapintaa luomiseksi, tarkista eteneminen `/qrart/tasks` -rajapinnasta.

## Koodiesimerkki

Alla on täydellinen Python-esimerkki QR Artin käytöstä:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_qrart():
    response = requests.post(
        "https://api.acedata.cloud/qrart/generate",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
},
    )
    return response.json()

result = call_qrart()
print(result)
```

## Parhaat käytännöt

- **Virheiden uudelleenyrittäminen**: Käytä eksponentiaalista takaisinvetäytymistä virheille 429 (rajoitus) ja 5xx
- **Asynkroninen käsittely**: Pitkään kestävissä tehtävissä (kuva-/videoiden luonti) käytä callback_url:ia tulosten vastaanottamiseen asynkronisesti
- **Kustannusten hallinta**: Seuraa käyttöä ja kustannuksia Ace Data Cloud -konsolista
- **Tokenin turvallisuus**: Tallenna API-token ympäristömuuttujaan, älä kovakoodaa sitä koodiin
