## Yleiskatsaus

AI-videoiden generointi on vuoden 2024–2025 kuumin AI-teknologiasuuntaus. Ace Data Cloudin avulla voit käyttää useita videon generointimalleja, kuten Sora, Luma ja Kling, ja rakentaa automatisoidun videotuotantoputken.

## Käytettävät palvelut

- **Sora**: `POST https://api.acedata.cloud/sora/videos`
- **Luma**: `POST https://api.acedata.cloud/luma/videos`
- **Kling**: `POST https://api.acedata.cloud/kling/videos`

## Tekninen ratkaisu

### Esivaatimukset

1. Rekisteröidy [Ace Data Cloudissa](https://platform.acedata.cloud)
2. Hanki API-token
3. Asenna Python 3.7+ ja requests-kirjasto

### Toteutusvaiheet

### Vaihe 1: Valitse videomalli

Sora on erikoistunut elokuvatasoiseen kuvanlaatuun, Luma tukee aloitus- ja lopetuskehyksen hallintaa, Kling tarjoaa nopean generoinnin.

### Vaihe 2: Lähetä generointitehtävä

Sora käyttää `/sora/videos`-päätepistettä, Luma `/luma/videos`-päätepistettä ja Kling `/kling/videos`-päätepistettä.

### Vaihe 3: Tarkista tehtävän tila

Kaikki video-API:t tukevat tehtävän etenemisen tarkistamista `/tasks`-päätepisteen kautta.

## Koodiesimerkki

Alla on täydellinen Python-esimerkki Soran käytöstä:

```python
import requests

API_TOKEN = "YOUR_API_TOKEN"

def call_sora():
    response = requests.post(
        "https://api.acedata.cloud/sora/videos",
        headers={
            "Authorization": f"Bearer {API_TOKEN}",
            "Content-Type": "application/json",
        },
        json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
    )
    return response.json()

result = call_sora()
print(result)
```

## Parhaat käytännöt

- **Virheiden uudelleenyrittäminen**: Käytä eksponentiaalista takaisinvetoa virheille 429 (rajoitus) ja 5xx
- **Asynkroninen käsittely**: Pitkään kestävissä tehtävissä (kuva-/videogenerointi) käytä callback_url:ia tulosten vastaanottamiseen asynkronisesti
- **Kustannusten hallinta**: Seuraa kulutusta ja kustannuksia Ace Data Cloudin hallintapaneelista
- **Tokenin turvallisuus**: Tallenna API-token ympäristömuuttujaan, älä kovakoodaa sitä koodiin
