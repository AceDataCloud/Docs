## Code examples

With Ace Data Cloud, access any image generation model through simple REST API calls:

```python
import requests

API_KEY = "YOUR_API_KEY"
headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# Midjourney — artistic, stylized images
response = requests.post(
    "https://api.acedata.cloud/midjourney/imagine",
    headers=headers,
    json={"prompt": "a futuristic cityscape at sunset, cinematic lighting"},
)
print(response.json())

# Flux — fast, photorealistic results
response = requests.post(
    "https://api.acedata.cloud/flux/images",
    headers=headers,
    json={"prompt": "a futuristic cityscape at sunset", "model": "flux-pro-1.1-ultra"},
)
print(response.json())

# Seedream — ByteDance's photorealistic model
response = requests.post(
    "https://api.acedata.cloud/seedream/images",
    headers=headers,
    json={"prompt": "a futuristic cityscape at sunset", "model": "doubao-seedream-4-5-251128"},
)
print(response.json())

# Nano Banana — Gemini-powered editing
response = requests.post(
    "https://api.acedata.cloud/nano-banana/images",
    headers=headers,
    json={"prompt": "a futuristic cityscape at sunset", "model": "nano-banana-pro"},
)
print(response.json())
```
