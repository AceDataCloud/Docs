## Code examples

With Ace Data Cloud, access any video generation model through simple REST API calls:

```python
import requests

API_KEY = "YOUR_API_KEY"
headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# Sora — OpenAI's cinematic video generation
response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers=headers,
    json={"prompt": "a drone shot over a mountain lake at sunrise", "model": "sora-2"},
)
print(response.json())

# Veo — Google DeepMind with native audio
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers=headers,
    json={"prompt": "a drone shot over a mountain lake at sunrise", "model": "veo-3"},
)
print(response.json())

# Luma Dream Machine — fast creative iterations
response = requests.post(
    "https://api.acedata.cloud/luma/videos",
    headers=headers,
    json={"prompt": "a drone shot over a mountain lake at sunrise"},
)
print(response.json())

# Kling — motion brush control
response = requests.post(
```
