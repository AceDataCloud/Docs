## Code examples

With Ace Data Cloud, access both Sora and Veo through simple REST API calls:

```python
import requests

API_KEY = "YOUR_API_KEY"
headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# Sora — cinematic video by OpenAI
response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers=headers,
    json={"prompt": "a drone shot over a mountain lake at sunrise", "model": "sora-2-pro"},
)
print(response.json())

# Veo — Google DeepMind with native audio
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers=headers,
    json={"prompt": "a drone shot over a mountain lake at sunrise", "model": "veo-3"},
)
print(response.json())
```
