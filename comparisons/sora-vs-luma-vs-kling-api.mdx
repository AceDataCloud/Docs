## 代码示例

以下示例展示如何通过 Ace Data Cloud API 分别调用 Sora vs Luma vs Kling。所有请求使用相同的 Base URL（`https://api.acedata.cloud`）和认证方式。

### 调用 Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
