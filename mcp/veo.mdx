[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文协议，允许 AI 模型（如 Claude、GPT 等）通过标准化接口调用外部工具。通过 AceData Cloud 提供的 Veo MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 客户端中直接使用 Google Veo 生成 AI 视频。

## 功能概览

Veo MCP Server 提供以下核心功能：

- **文本生成视频** — 通过文本提示词生成高质量视频
- **图片生成视频** — 以图片为基础生成视频
- **多模型支持** — 支持 veo3、veo2、veo31-fast-ingredient 等模型
- **多种分辨率** — 支持 4K、1080p、GIF 等输出格式
- **多种画面比例** — 支持 16:9、9:16 等比例
- **1080p 升级** — 将已生成视频升级到 1080p
- **任务查询** — 监控生成进度并获取结果

## 前置准备

使用前，你需要获取 AceData Cloud API Token：

1. 注册或登录 [AceData Cloud 平台](https://platform.acedata.cloud)
2. 前往 [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos) 页面
3. 点击「Acquire」获取 API Token（首次申请赠送免费额度）

## 安装配置

### 方式一：pip 安装（推荐）

```bash
pip install mcp-veo
```

### 方式二：源码安装

```bash
git clone https://github.com/AceDataCloud/MCPVeo.git
cd MCPVeo
pip install -e .
```

安装完成后，即可使用 `mcp-veo` 命令启动服务。

## 在 Claude Desktop 中使用

编辑 Claude Desktop 配置文件：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

添加以下配置：

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（无需提前安装包）：

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

保存配置后重启 Claude Desktop，即可在对话中使用 Veo 相关工具。

## 在 VS Code / Cursor 中使用

在项目根目录创建 `.vscode/mcp.json`：

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

或者使用 `uvx`：

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

## 可用工具列表

| 工具名 | 说明 |
|--------|------|
| `veo_text_to_video` | 通过文本提示词生成视频 |
| `veo_image_to_video` | 以图片为基础生成视频 |
| `veo_get_1080p` | 将视频升级到 1080p |
| `veo_get_task` | 查询单个任务状态 |
| `veo_get_tasks_batch` | 批量查询任务状态 |

## 使用示例

配置完成后，你可以在 AI 客户端中直接用自然语言调用这些功能，例如：

- 「帮我用 Veo 生成一段星空延时摄影视频」
- 「用这张风景照生成一段 4K 视频」
- 「生成一段竖屏 9:16 的短视频」
- 「把这个视频升级到 1080p」
