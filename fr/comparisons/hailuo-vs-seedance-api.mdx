## Aperçu

Hailuo vs Seedance sont des services API populaires de génération vidéo AI. Ils peuvent tous deux être appelés via la plateforme API unifiée Ace Data Cloud, utilisant le même mode d’authentification et de requête, sans besoin d’intégrer séparément les API des différents fournisseurs.

Cet article compare systématiquement Hailuo et Seedance selon cinq dimensions : fonctionnalités, modèles, tarification, vitesse et scénarios recommandés, afin d’aider les développeurs à choisir la solution la plus adaptée.

## Comparaison principale

| Dimension | Hailuo | Seedance |
|------|------|------|
| Modèles disponibles | minimax-i2v, minimax-t2v, minimax-i2v-director | doubao-seedance-1-5-pro-251215, doubao-seedance-1-0-pro-250528, doubao-seedance-1-0-pro-fast-251015 |
| Endpoint API | `/hailuo/videos` | `/seedance/videos` |
| Fonctionnalités clés | Génération vidéo à partir de texte, génération vidéo à partir d’image, mode réalisateur | Génération vidéo à partir de texte, génération vidéo à partir d’image, génération audio, multiples résolutions |

## Analyse détaillée

### Fonctionnalités

Hailuo et Seedance sont tous deux accessibles via l’API unifiée Ace Data Cloud, supportant une interface REST standard et une authentification Bearer Token.

**Hailuo** utilise principalement l’endpoint `POST https://api.acedata.cloud/hailuo/videos`, supportant la génération vidéo à partir de texte, d’image, ainsi que le mode réalisateur. Il propose également des endpoints comme `/hailuo/tasks`.

**Seedance** utilise principalement l’endpoint `POST https://api.acedata.cloud/seedance/videos`, supportant la génération vidéo à partir de texte, d’image, la génération audio, et plusieurs résolutions. Il propose aussi des endpoints tels que `/seedance/tasks`.

### Scénarios recommandés

- **Hailuo** : adapté aux scénarios nécessitant la génération vidéo à partir de texte
- **Seedance** : adapté aux scénarios nécessitant la génération vidéo à partir de texte

## Exemples de code

Les exemples suivants montrent comment appeler Hailuo et Seedance via l’API Ace Data Cloud. Toutes les requêtes utilisent la même URL de base (`https://api.acedata.cloud`) et le même mode d’authentification.

### Appeler Hailuo

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/hailuo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "action": "generate",
    "model": "minimax-t2v",
    "prompt": "A golden sunset over the ocean waves"
},
)
print(response.json())
```

### Appeler Seedance

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/seedance/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "doubao-seedance-1-0-pro-250528",
    "content": [
        {
            "type": "text",
            "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
        }
    ]
},
)
print(response.json())
```
