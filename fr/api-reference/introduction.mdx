## URL de base

L'adresse de base pour tous les points de terminaison API :

```
https://api.acedata.cloud
```

## Authentification

Tous les points de terminaison nécessitent une authentification Bearer Token :

```
Authorization: Bearer YOUR_API_TOKEN
```

## Test en ligne

Chaque point de terminaison dans cette documentation de référence inclut un bac à sable interactif. Entrez le token API pour tester directement les requêtes dans le navigateur.

<Note title="Tip">
  Obtenez un token API sur [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
