---
title: "Authentification"
description: "Comment s'authentifier avec l'API Ace Data Cloud"
---

Toutes les API Ace Data Cloud utilisent une authentification par **Bearer Token**.

## Obtention du Token

1. Créez un compte sur [platform.acedata.cloud](https://platform.acedata.cloud)
2. Abonnez-vous aux services nécessaires
3. Créez des identifiants (API Token) pour chaque service

## Utilisation du Token

Incluez le Token dans l'en-tête `Authorization` de chaque requête :

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Astuce">
  Chaque Token est lié à un abonnement de service spécifique. Utilisez des Tokens différents pour chaque service, ou créez des identifiants **globaux** pour une utilisation multi-services.
</Note>

## Limitation du débit

Les limites de débit varient selon le service et le niveau d'abonnement. En cas de dépassement, l'API renvoie un `429 Too Many Requests`.

## Bonnes pratiques de sécurité

- Ne divulguez pas les API Tokens dans le code client
- Stockez les Tokens dans des variables d'environnement
- Renouvelez régulièrement les Tokens
- Utilisez des Tokens différents pour les environnements de développement et de production
