Toutes les API Ace Data Cloud utilisent une authentification par **Bearer Token**.

## Obtention du Token

Connectez-vous à la page [Applications](https://platform.acedata.cloud/console/applications?lang=fr&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) et ouvrez **General Application**. Si cette application n’apparaît pas encore, sélectionnez **Initialize General Application**. Cliquez sur le bouton de copie repéré par le chiffre **1** à côté de **API KEY**.

![Bouton de copie de la clé de l’application, repéré par le chiffre 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Conservez la clé sur votre serveur et utilisez-la à la place de `YOUR_API_TOKEN` dans l’exemple.

## Utilisation du Token

Incluez le Token dans l'en-tête `Authorization` de chaque requête :

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Limitation du débit

Les limites de débit varient selon le service et le niveau d'abonnement. En cas de dépassement, l'API renvoie un `429 Too Many Requests`.

## Bonnes pratiques de sécurité

- Ne divulguez pas les API Tokens dans le code client
- Stockez les Tokens dans des variables d'environnement
- Renouvelez régulièrement les Tokens
- Utilisez des Tokens différents pour les environnements de développement et de production
