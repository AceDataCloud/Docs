## Introduction

Image2Text est un service de reconnaissance de captcha d'Ace Data Cloud, permettant la reconnaissance de captcha image. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Image2Text et réaliser la reconnaissance de captcha image, avec des entrées en Base64, URL, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un API Token
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'entrée principal de l'API Image2Text est :

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une fois l'appel réussi, la réponse est au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code | Description |
|--------|-------------|
| 401 | Échec d'authentification, veuillez vérifier l'API Token |
| 403 | Solde insuffisant ou accès non autorisé |
| 429 | Limite de fréquence des requêtes dépassée |
| 500 | Erreur interne du serveur |
