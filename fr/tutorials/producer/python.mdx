## Introduction

Producer est un service audio AI fourni par Ace Data Cloud, FUZZ Producer pour la génération de musique AI. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Producer en Python pour réaliser des fonctions telles que la génération de musique à partir de texte, les paroles personnalisées, la continuation de chansons, les reprises, la séparation de voix, la génération de clips vidéo, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal pour appeler l'API Producer est :

```
POST https://api.acedata.cloud/producer/audios
```

Cet exemple utilise le modèle `FUZZ-2.0 Pro`.  
Les modèles disponibles incluent : `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/producer/audios"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A relaxing jazz piece for a coffee shop",
    "model": "FUZZ-2.0 Pro",
    "lyric": "[Verse]\nSoft piano keys in the morning light",
    "custom": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l'API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez obtenir les résultats via une URL de rappel :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Les résultats seront envoyés à votre serveur via l'URL de rappel
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|------------------------------------|
| 401            | Échec d'authentification, vérifiez le jeton API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Limite de fréquence dépassée       |
| 500            | Erreur interne du serveur          |
