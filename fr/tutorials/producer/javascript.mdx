## Introduction

Producer est un service audio AI fourni par Ace Data Cloud, FUZZ Producer AI génération musicale. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Producer avec JavaScript pour générer de la musique à partir de texte, personnaliser les paroles, prolonger des chansons, faire des reprises, séparer les voix, générer des clips vidéo, et plus encore.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Node.js 18+ ou un environnement navigateur moderne

## Utilisation de base

Le point d'accès principal de l'API Producer est :

```
POST https://api.acedata.cloud/producer/audios
```

Cet exemple utilise le modèle `FUZZ-2.0 Pro`.  
Modèles disponibles : `FUZZ-2.0 Pro`, `FUZZ-2.0`, `FUZZ-1.1 Pro`, `FUZZ-1.0 Pro`.

Exemple complet de code JavaScript :

```javascript
const response = await fetch("https://api.acedata.cloud/producer/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A relaxing jazz piece for a coffee shop",
  "model": "FUZZ-2.0 Pro",
  "lyric": "[Verse]\nSoft piano keys in the morning light",
  "custom": true
}),
});

const result = await response.json();
console.log(result);
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Il est recommandé de vérifier le code de statut de la réponse et de gérer les erreurs :

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Appel réussi :", result);
} else {
  console.error(`Échec de l'appel, code de statut : ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulation Node.js

Il est conseillé d'encapsuler l'appel dans une fonction réutilisable :

```javascript
async function callProducer(data) {
  const response = await fetch("https://api.acedata.cloud/producer/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erreur API : ${response.status}`);
  return response.json();
}
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|------------------------------------|
| 401            | Échec d'authentification, vérifiez le jeton API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Limite de fréquence dépassée       |
| 500            | Erreur interne du serveur          |
