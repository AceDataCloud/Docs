## Introduction

QR Art est un service d'images IA fourni par Ace Data Cloud, générant des codes QR artistiques par IA. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement QR Art avec Python pour créer des codes QR de liens, de texte, avec des styles prédéfinis ou des paramètres personnalisés.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un token API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal de l'API QR Art est :

```
POST https://api.acedata.cloud/qrart/generate
```

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/qrart/generate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le token réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l'API retourne des données au format JSON. Il est recommandé de vérifier le code HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez récupérer les résultats via une URL de rappel (callback) :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Les résultats seront envoyés à votre serveur via l'URL de rappel
```

## Gestion des erreurs

Codes d'erreur courants :

| Code | Description |
|-------|-------------|
| 401   | Échec d'authentification, veuillez vérifier le token API |
| 403   | Solde insuffisant ou accès refusé |
| 429   | Limite de fréquence de requêtes dépassée |
| 500   | Erreur interne du serveur |
