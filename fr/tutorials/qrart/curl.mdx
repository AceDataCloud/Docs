## Introduction

QR Art est un service d'images AI fourni par Ace Data Cloud, générant des codes QR artistiques par IA. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement QR Art et créer des codes QR de liens, codes QR textuels, styles prédéfinis, paramètres personnalisés, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un API Token
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal de l'API QR Art est :

```
POST https://api.acedata.cloud/qrart/generate
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Remplacez `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une réponse réussie renvoie des données au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code | Description                          |
|-------|-----------------------------------|
| 401   | Échec d'authentification, vérifiez l'API Token |
| 403   | Solde insuffisant ou accès refusé  |
| 429   | Limite de fréquence dépassée       |
| 500   | Erreur interne du serveur          |
