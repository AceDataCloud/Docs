## Introduction

Gemini est un service de chat IA fourni par Ace Data Cloud, basé sur la série de grands modèles de langage Google Gemini. Grâce à l’API unifiée d’Ace Data Cloud, vous pouvez intégrer rapidement Gemini avec Python pour réaliser des dialogues multi-tours, des invites système, une sortie en flux continu, un mode de sortie JSON, et bien plus.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d’accès principal pour appeler l’API Gemini est :

```
POST https://api.acedata.cloud/gemini/chat/completions
```

Cet exemple utilise le modèle `gemini-2.5-flash`.  
Les modèles disponibles incluent : `gemini-2.5-flash`, `gemini-2.5-pro`, `gemini-2.0-flash`, `gemini-3.0-pro`.

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/gemini/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l’API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l’appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API de type chat, la sortie en flux continu est prise en charge afin d’obtenir des réponses en temps réel :

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Gestion des erreurs

Codes d’erreur courants :

| Code de statut | Description                          |
|----------------|------------------------------------|
| 401            | Échec d’authentification, vérifiez le jeton API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Limite de fréquence dépassée       |
| 500            | Erreur interne du serveur           |
