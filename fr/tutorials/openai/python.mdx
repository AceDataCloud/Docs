## Introduction

OpenAI est un service de chat IA fourni par Ace Data Cloud, basé sur la série de grands modèles de langage OpenAI GPT. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement OpenAI avec Python pour réaliser des conversations multi-tours, des invites système, la sortie en flux continu, le mode de sortie JSON, l'encodage de texte, la génération d'images, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal pour appeler l'API OpenAI est :

```
POST https://api.acedata.cloud/openai/chat/completions
```

Cet exemple utilise le modèle `gpt-4o`.  
Les modèles disponibles incluent : `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Traitement de la réponse

Après un appel réussi, l'API renvoie des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API de type chat, la sortie en flux continu est prise en charge afin d'obtenir une réponse en temps réel :

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                      |
|----------------|--------------------------------|
| 401            | Échec d'authentification, vérifiez le jeton API |
| 403            | Solde insuffisant ou accès refusé |
| 429            | Limite de fréquence dépassée    |
| 500            | Erreur interne du serveur       |
