## Introduction

OpenAI est un service de chat IA fourni par Ace Data Cloud, basé sur la série de grands modèles de langage OpenAI GPT. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement OpenAI, réalisant des conversations multi-tours, des invites système, une sortie en flux, un mode de sortie JSON, des embeddings de texte, la génération d'images, et bien plus.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API OpenAI est :

```
POST https://api.acedata.cloud/openai/chat/completions
```

Cet exemple utilise le modèle `gpt-4o`.
Les modèles disponibles incluent : `gpt-4o`, `gpt-4o-mini`, `o1`, `o3-mini`.

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Après un appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/openai/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code d'état | Description                          |
|-------------|-----------------------------------|
| 401         | Échec d'authentification, veuillez vérifier le jeton API |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Limite de fréquence de requêtes dépassée |
| 500         | Erreur interne du serveur          |
