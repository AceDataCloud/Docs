## Introduction

Google Search est un service de recherche fourni par Ace Data Cloud, l'API de recherche Google. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Google Search et réaliser des recherches web, images, actualités, cartes, vidéos, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API Google Search est :

```
POST https://api.acedata.cloud/serp/google
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Après un appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code statut | Description                          |
|-------------|-----------------------------------|
| 401         | Échec d'authentification, vérifiez le jeton API |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Limite de fréquence dépassée       |
| 500         | Erreur interne du serveur          |
