## Introduction

Hailuo est un service vidéo IA proposé par Ace Data Cloud, utilisant le modèle de génération vidéo MiniMax Hailuo. Grâce à l’API unifiée d’Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Hailuo et réaliser des fonctions telles que la génération vidéo à partir de texte, la génération vidéo à partir d’images, ou le mode réalisateur.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d’accès principal pour appeler l’API Hailuo est :

```
POST https://api.acedata.cloud/hailuo/videos
```

Cet exemple utilise le modèle `minimax-t2v`.  
Les modèles disponibles incluent : `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une fois l’appel réussi, une réponse au format JSON est retournée, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d’utiliser l’outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Gestion des erreurs

Codes d’erreur courants :

| Code | Description                          |
|-------|------------------------------------|
| 401   | Échec d’authentification, vérifiez le Token API |
| 403   | Solde insuffisant ou accès refusé  |
| 429   | Limite de fréquence des requêtes dépassée |
| 500   | Erreur interne du serveur          |
