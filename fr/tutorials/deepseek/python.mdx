## Introduction

DeepSeek est un service de chat IA fourni par Ace Data Cloud, une série de grands modèles de langage DeepSeek. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement DeepSeek en Python pour réaliser des dialogues multi-tours, des invites système, une sortie en flux, un mode de sortie JSON, un raisonnement approfondi, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal pour appeler l'API DeepSeek est :

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

Cet exemple utilise le modèle `deepseek-r1`.  
Les modèles disponibles incluent : `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/deepseek/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek-r1",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l'API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API de type chat, la sortie en flux est prise en charge pour obtenir des réponses en temps réel :

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                         |
|----------------|-----------------------------------|
| 401            | Échec d'authentification, vérifiez le jeton API |
| 403            | Solde insuffisant ou accès refusé |
| 429            | Fréquence des requêtes dépassée   |
| 500            | Erreur interne du serveur          |
