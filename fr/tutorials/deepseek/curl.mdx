## Introduction

DeepSeek est un service de chat IA fourni par Ace Data Cloud, une série de grands modèles de langage DeepSeek. Grâce à l’API unifiée d’Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement DeepSeek, réalisant des dialogues multi-tours, des invites système, une sortie en flux, un mode de sortie JSON, un raisonnement approfondi, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un token API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d’accès principal pour appeler l’API DeepSeek est :

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

Cet exemple utilise le modèle `deepseek-r1`.  
Les modèles disponibles incluent : `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une fois l’appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d’utiliser l’outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Gestion des erreurs

Codes d’erreur courants :

| Code | Description                          |
|-------|-----------------------------------|
| 401   | Échec d’authentification, vérifiez le token API |
| 403   | Solde insuffisant ou accès refusé  |
| 429   | Limite de fréquence dépassée       |
| 500   | Erreur interne du serveur          |
