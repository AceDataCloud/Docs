## Introduction

ADSL HTTP Proxy est un service de proxy réseau fourni par Ace Data Cloud, permettant l'extraction d'IP dynamiques ADSL. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement ADSL HTTP Proxy, et bénéficier des fonctionnalités telles que proxy HTTP/SOCKS, multi-opérateurs, multi-provinces, durée personnalisée, liste blanche d'IP, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un API Token
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API ADSL HTTP Proxy est :

```
POST https://api.acedata.cloud/adsl/extract
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une réponse réussie renvoie des données au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code | Description |
|--------|-------------|
| 401 | Échec d'authentification, veuillez vérifier l'API Token |
| 403 | Solde insuffisant ou accès non autorisé |
| 429 | Limite de fréquence des requêtes dépassée |
| 500 | Erreur interne du serveur |
