## Introduction

reCAPTCHA est un service de captcha fourni par Ace Data Cloud, solution Google reCAPTCHA. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement reCAPTCHA, et réaliser des fonctions telles que le Token reCAPTCHA v2, la reconnaissance reCAPTCHA v2, le Token reCAPTCHA v3, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API reCAPTCHA est :

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

En cas d'appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/recaptcha2 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-", "website_url": "https://www.google.com/recaptcha/api2/demo"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code d'état | Description                          |
|-------------|------------------------------------|
| 401         | Échec de l'authentification, veuillez vérifier le Token API |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Limite de fréquence des requêtes dépassée |
| 500         | Erreur interne du serveur          |
