## Introduction

reCAPTCHA est un service de captcha fourni par Ace Data Cloud, une solution Google reCAPTCHA. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement reCAPTCHA avec Python, en réalisant des fonctionnalités telles que le Token reCAPTCHA v2, la reconnaissance reCAPTCHA v2, le Token reCAPTCHA v3, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal pour appeler l'API reCAPTCHA est :

```
POST https://api.acedata.cloud/captcha/token/recaptcha2
```

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/captcha/token/recaptcha2"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "website_url": "https://www.google.com/recaptcha/api2/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel que vous avez obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l'API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez obtenir les résultats via une URL de rappel (callback) :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Les résultats seront envoyés à votre serveur via l'URL de callback
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|-----------------------------------|
| 401            | Échec d'authentification, vérifiez le Token API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Fréquence de requêtes dépassée     |
| 500            | Erreur interne du serveur          |
