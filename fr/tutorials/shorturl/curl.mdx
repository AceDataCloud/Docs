---

## Introduction

Short URL est un service d'outil fourni par Ace Data Cloud, un service de génération de liens courts. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Short URL et réaliser des fonctions telles que le raccourcissement d'URL et la personnalisation de domaine.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un token API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API Short URL est :

```
POST https://api.acedata.cloud/shorturl
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Après un appel réussi, les données au format JSON sont retournées, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code statut | Description                          |
|-------------|-----------------------------------|
| 401         | Échec d'authentification, vérifiez le token API |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Fréquence de requêtes dépassée     |
| 500         | Erreur interne du serveur          |
