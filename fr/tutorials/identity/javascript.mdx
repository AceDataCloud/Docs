## Introduction

Identity est un service d'authentification fourni par Ace Data Cloud, permettant la vérification d'identité via carte d'identité, carte bancaire et numéro de téléphone portable. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Identity avec JavaScript pour réaliser des fonctions telles que la reconnaissance optique de caractères (OCR) de carte d'identité, la vérification de carte d'identité, la vérification de carte bancaire et la vérification de numéro de téléphone portable.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API (API Token)
- Node.js 18+ ou un environnement de navigateur moderne

## Utilisation de base

Le point d'accès principal pour appeler l'API Identity est :

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Exemple complet de code JavaScript :

```javascript
const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "image_url": "https://example.com/idcard-front.jpg"
}),
});

const result = await response.json();
console.log(result);
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Il est recommandé de vérifier le code de statut de la réponse et de gérer les erreurs :

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Appel réussi :", result);
} else {
  console.error(`Échec de l'appel, code de statut : ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulation Node.js

Il est conseillé d'encapsuler dans une fonction réutilisable :

```javascript
async function callIdentity(data) {
  const response = await fetch("https://api.acedata.cloud/identity/idcard/ocr", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erreur API : ${response.status}`);
  return response.json();
}
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|------------------------------------|
| 401            | Échec d'authentification, veuillez vérifier le jeton API |
| 403            | Solde insuffisant ou accès non autorisé |
| 429            | Limite de fréquence des requêtes dépassée |
| 500            | Erreur interne du serveur          |
