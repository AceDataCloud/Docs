title: "Introduction rapide à Identity avec cURL"
---

## Présentation

Identity est un service d'authentification fourni par Ace Data Cloud, permettant la vérification d'identité via carte d'identité, carte bancaire ou numéro de téléphone. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Identity et réaliser des fonctions telles que la reconnaissance optique de caractères (OCR) de carte d'identité, la vérification de carte d'identité, la vérification de carte bancaire et la vérification de numéro de téléphone.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API Identity est :

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une fois l'appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code d'état | Description                         |
|-------------|-----------------------------------|
| 401         | Échec d'authentification, vérifiez le Token API |
| 403         | Solde insuffisant ou accès refusé |
| 429         | Limite de fréquence des requêtes dépassée |
| 500         | Erreur interne du serveur         |
