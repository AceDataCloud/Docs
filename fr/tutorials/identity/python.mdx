## Introduction

Identity est un service d'authentification fourni par Ace Data Cloud, permettant la vérification d'identité via carte d'identité, carte bancaire et numéro de téléphone portable. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Identity avec Python pour réaliser des fonctions telles que la reconnaissance optique de caractères (OCR) de carte d'identité, la vérification de carte d'identité, la vérification de carte bancaire et la vérification de numéro de téléphone.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal pour appeler l'API Identity est :

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image_url": "https://example.com/idcard-front.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Traitement de la réponse

Après un appel réussi, l'API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez obtenir les résultats via une URL de rappel (callback) :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Les résultats seront envoyés à votre serveur via l'URL de rappel
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                         |
|----------------|-----------------------------------|
| 401            | Échec d'authentification, vérifiez le Token API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Limite de fréquence dépassée       |
| 500            | Erreur interne du serveur          |
