## Introduction

Midjourney est un service d’images AI fourni par Ace Data Cloud, générant des images avec Midjourney AI. Grâce à l’API unifiée d’Ace Data Cloud, vous pouvez intégrer rapidement Midjourney en Python pour réaliser des fonctions telles que génération d’images à partir de texte, édition d’images, description d’images, génération de vidéos à partir d’images, contrôle de Seed, rappel asynchrone, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d’accès principal de l’API Midjourney est :

```
POST https://api.acedata.cloud/midjourney/imagine
```

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/midjourney/imagine"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A serene Japanese garden with cherry blossoms",
    "action": "generate",
    "mode": "fast",
    "translation": true
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l’API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l’appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez obtenir le résultat via une URL de rappel :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Le résultat sera envoyé à votre serveur via l’URL de rappel
```

## Gestion des erreurs

Codes d’erreur courants :

| Code de statut | Description                          |
|----------------|-----------------------------------|
| 401            | Échec d’authentification, vérifiez le Token API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Fréquence de requêtes dépassée     |
| 500            | Erreur interne du serveur          |

## Autres points d’accès

Le service Midjourney propose également les points d’accès suivants :

- `POST https://api.acedata.cloud/midjourney/seed`
- `POST https://api.acedata.cloud/midjourney/edits`
- `POST https://api.acedata.cloud/midjourney/videos`
- `POST https://api.acedata.cloud/midjourney/describe`
