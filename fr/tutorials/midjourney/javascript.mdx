## Introduction

Midjourney est un service d'images IA fourni par Ace Data Cloud, générant des images avec Midjourney AI. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Midjourney avec JavaScript pour réaliser des fonctionnalités telles que la génération d'images à partir de texte, l'édition d'images, la description d'images, la génération de vidéos à partir d'images, le contrôle de Seed, les callbacks asynchrones, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Node.js 18+ ou un environnement de navigateur moderne

## Utilisation de base

Le point d'accès principal pour appeler l'API Midjourney est :

```
POST https://api.acedata.cloud/midjourney/imagine
```

Exemple complet de code JavaScript :

```javascript
const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A serene Japanese garden with cherry blossoms",
  "action": "generate",
  "mode": "fast",
  "translation": true
}),
});

const result = await response.json();
console.log(result);
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Il est recommandé de vérifier le code de statut de la réponse et de gérer les erreurs :

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Appel réussi :", result);
} else {
  console.error(`Échec de l'appel, code de statut : ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Enveloppement Node.js

Il est conseillé d'encapsuler dans une fonction réutilisable :

```javascript
async function callMidjourney(data) {
  const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erreur API : ${response.status}`);
  return response.json();
}
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|-----------------------------------|
| 401            | Échec d'authentification, vérifiez le Token API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Limite de fréquence dépassée       |
| 500            | Erreur interne du serveur          |
