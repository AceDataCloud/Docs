---

## Introduction

Midjourney est un service d'images IA fourni par Ace Data Cloud, générant des images par IA Midjourney. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Midjourney et réaliser des fonctionnalités telles que la génération d'images à partir de texte, l'édition d'images, la description d'images, la génération de vidéos à partir d'images, le contrôle de Seed, les rappels asynchrones, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal de l'API Midjourney est :

```
POST https://api.acedata.cloud/midjourney/imagine
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Une fois l'appel réussi, les données au format JSON sont retournées, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/midjourney/imagine \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A serene Japanese garden with cherry blossoms", "action": "generate", "mode": "fast", "translation": true}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code | Description                          |
|-------|-----------------------------------|
| 401   | Échec d'authentification, veuillez vérifier le jeton API |
| 403   | Solde insuffisant ou accès refusé  |
| 429   | Limite de fréquence des requêtes dépassée |
| 500   | Erreur interne du serveur          |
