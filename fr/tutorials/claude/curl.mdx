## Introduction

Claude est un service de chat IA fourni par Ace Data Cloud, basé sur la série de grands modèles de langage Anthropic Claude. Grâce à l’API unifiée d’Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Claude et bénéficier de fonctionnalités telles que les conversations multi-tours, les invites système, la sortie en flux continu, le mode de sortie JSON, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d’accès principal de l’API Claude est :

```
POST https://api.acedata.cloud/v1/chat/completions
```

Cet exemple utilise le modèle `claude-sonnet-4-6`.  
Les modèles disponibles incluent : `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Après un appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d’utiliser l’outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Gestion des erreurs

Codes d’erreur courants :

| Code | Description                          |
|-------|-----------------------------------|
| 401   | Échec d’authentification, vérifiez le jeton API |
| 403   | Solde insuffisant ou accès refusé  |
| 429   | Limite de fréquence dépassée       |
| 500   | Erreur interne du serveur          |
