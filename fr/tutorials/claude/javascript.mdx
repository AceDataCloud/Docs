## Introduction

Claude est un service de chat IA fourni par Ace Data Cloud, basé sur la série de grands modèles de langage Anthropic Claude. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Claude en JavaScript pour réaliser des conversations multi-tours, des invites système, une sortie en flux continu, un mode de sortie JSON, et plus encore.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Node.js 18+ ou un environnement de navigateur moderne

## Utilisation de base

Le point d'accès principal pour appeler l'API Claude est :

```
POST https://api.acedata.cloud/v1/chat/completions
```

Cet exemple utilise le modèle `claude-sonnet-4-6`.  
Les modèles disponibles incluent : `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Exemple complet de code JavaScript :

```javascript
const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "claude-sonnet-4-6",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Il est recommandé de vérifier le code d'état de la réponse et de gérer les erreurs :

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Appel réussi :", result);
} else {
  console.error(`Échec de l'appel, code d'état : ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Encapsulation Node.js

Il est conseillé d'encapsuler dans une fonction réutilisable :

```javascript
async function callClaude(data) {
  const response = await fetch("https://api.acedata.cloud/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`Erreur API : ${response.status}`);
  return response.json();
}
```

## Gestion des erreurs

Codes d'erreur courants :

| Code d'état | Description                           |
|-------------|------------------------------------|
| 401         | Échec d'authentification, vérifiez le jeton API |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Limite de fréquence dépassée       |
| 500         | Erreur interne du serveur          |
