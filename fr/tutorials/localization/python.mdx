## Introduction

Localization est un service d'outils fourni par Ace Data Cloud, un service de traduction localisée par IA. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement Localization avec Python pour réaliser la traduction de Markdown, la traduction JSON, prendre en charge 18 langues, tout en conservant le format, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal de l'API Localization est :

```
POST https://api.acedata.cloud/localization/translate
```

Cet exemple utilise le modèle `gpt-4`.  
Les modèles disponibles incluent : `gpt-3.5`, `gpt-4`.

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/localization/translate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "input": "# 欢迎使用\n\n这是一段示例文本。",
    "locale": "en",
    "extension": "md",
    "model": "gpt-4"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel que vous avez obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l'API renvoie des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez obtenir les résultats via une URL de rappel (callback) :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Les résultats seront envoyés à votre serveur via l'URL de rappel
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|-----------------------------------|
| 401            | Échec d'authentification, vérifiez le Token API |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Fréquence de requêtes dépassée     |
| 500            | Erreur interne du serveur          |
