---

## Introduction

Localization est un service d'outils fourni par Ace Data Cloud, un service de traduction localisée par IA. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez utiliser cURL pour appeler rapidement Localization, réaliser la traduction de Markdown, la traduction JSON, prendre en charge 18 langues, conserver le format, etc.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un Token API
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'entrée principal pour appeler l'API Localization est :

```
POST https://api.acedata.cloud/localization/translate
```

Cet exemple utilise le modèle `gpt-4`.
Les modèles disponibles incluent : `gpt-3.5`, `gpt-4`.

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Après un appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code d'état | Description                          |
|-------------|-----------------------------------|
| 401         | Échec d'authentification, vérifiez le Token API |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Limite de fréquence des requêtes dépassée |
| 500         | Erreur interne du serveur          |
