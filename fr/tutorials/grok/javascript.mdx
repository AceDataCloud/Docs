## Introduction

Grok est un service de chat IA fourni par Ace Data Cloud, basé sur la série de grands modèles de langage xAI Grok. Grâce à l’API unifiée d’Ace Data Cloud, vous pouvez intégrer rapidement Grok avec JavaScript pour réaliser des dialogues multi-tours, des invites système, une sortie en flux, un mode de sortie JSON, une compréhension visuelle, et plus encore.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un jeton API
- Node.js 18+ ou un environnement de navigateur moderne

## Utilisation de base

Le point d’accès principal pour appeler l’API Grok est :

```
POST https://api.acedata.cloud/grok/chat/completions
```

Cet exemple utilise le modèle `grok-3`.
Les modèles disponibles incluent : `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision`.

Exemple complet de code JavaScript :

```javascript
const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "grok-3",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Il est recommandé de vérifier le code de statut de la réponse et de gérer les erreurs :

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Appel réussi :", result);
} else {
  console.error(`Échec de l'appel, code de statut : ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Enveloppement Node.js

Il est conseillé d’encapsuler dans une fonction réutilisable :

```javascript
async function callGrok(data) {
  const response = await fetch("https://api.acedata.cloud/grok/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Gestion des erreurs

Codes d’erreur courants :

| Code | Description                          |
|-------|------------------------------------|
| 401   | Échec d’authentification, vérifiez le jeton API |
| 403   | Solde insuffisant ou accès refusé  |
| 429   | Limite de fréquence dépassée       |
| 500   | Erreur interne du serveur          |
