## Introduction

hCaptcha est un service de captcha fourni par Ace Data Cloud. La solution hCaptcha permet, via l'API unifiée d'Ace Data Cloud, d'utiliser cURL pour appeler rapidement hCaptcha, réaliser l'obtention de jetons hCaptcha, la reconnaissance d'images hCaptcha, et d'autres fonctionnalités.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un API Token
- Avoir un environnement terminal avec cURL installé

## Utilisation de base

Le point d'accès principal pour appeler l'API hCaptcha est :

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Exemple complet de commande cURL :

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Veuillez remplacer `YOUR_API_TOKEN` par le jeton réel que vous avez obtenu sur la plateforme Ace Data Cloud.

## Exemple de réponse

Après un appel réussi, les données sont retournées au format JSON, par exemple :

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Traitement de la réponse avec jq

Il est recommandé d'utiliser l'outil jq pour formater la sortie :

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Gestion des erreurs

Codes d'erreur courants :

| Code d'état | Description                          |
|-------------|-----------------------------------|
| 401         | Échec d'authentification, veuillez vérifier l'API Token |
| 403         | Solde insuffisant ou accès refusé  |
| 429         | Limite de fréquence des requêtes dépassée |
| 500         | Erreur interne du serveur          |
