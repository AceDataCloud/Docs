## Introduction

hCaptcha est un service de captcha fourni par Ace Data Cloud, solution hCaptcha. Grâce à l'API unifiée d'Ace Data Cloud, vous pouvez intégrer rapidement hCaptcha avec Python, réaliser l'obtention du Token hCaptcha, la reconnaissance d'images hCaptcha, et d'autres fonctionnalités.

## Prérequis

- Posséder un compte [Ace Data Cloud](https://platform.acedata.cloud) et obtenir un API Token
- Environnement Python 3.7 ou supérieur
- Installer la bibliothèque requests : `pip install requests`

## Utilisation de base

Le point d'accès principal pour appeler l'API hCaptcha est :

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Exemple complet de code Python :

```python
import requests

url = "https://api.acedata.cloud/captcha/token/hcaptcha"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
    "website_url": "https://accounts.hcaptcha.com/demo"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Veuillez remplacer `YOUR_API_TOKEN` par le Token réel obtenu sur la plateforme Ace Data Cloud.

## Gestion de la réponse

Après un appel réussi, l'API retourne des données au format JSON. Il est recommandé de vérifier le code de statut HTTP :

```python
if response.status_code == 200:
    result = response.json()
    print("Appel réussi :", result)
else:
    print(f"Échec de l'appel, code de statut : {response.status_code}")
    print(response.text)
```

## Utilisation avancée

Pour les API supportant les tâches asynchrones, vous pouvez obtenir les résultats via une URL de callback :

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Les résultats seront poussés vers votre serveur via l'URL de callback
```

## Gestion des erreurs

Codes d'erreur courants :

| Code de statut | Description                          |
|----------------|------------------------------------|
| 401            | Échec d'authentification, vérifiez l'API Token |
| 403            | Solde insuffisant ou accès refusé  |
| 429            | Limite de fréquence de requêtes dépassée |
| 500            | Erreur interne du serveur          |
