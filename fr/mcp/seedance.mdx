[MCP (Model Context Protocol)](https://modelcontextprotocol.io) est un protocole de contexte de modèle lancé par Anthropic, qui permet aux modèles d’IA (tels que Claude, GPT, etc.) d’appeler des outils externes via une interface standardisée. Grâce au Seedance MCP Server fourni par AceData Cloud, vous pouvez directement utiliser ByteDance Seedance pour générer des vidéos IA dans des clients IA tels que Claude Desktop, VS Code, Cursor, etc.

## Aperçu des fonctionnalités

Seedance MCP Server fournit les fonctionnalités principales suivantes :

- **Génération de vidéo à partir de texte** — Générer des vidéos de haute qualité à partir d’invites textuelles
- **Génération de vidéo à partir d’image** — Générer des vidéos en utilisant des images comme référence (première image, dernière image, image de référence et autres modes)
- **Prise en charge de plusieurs modèles** — Prend en charge Seedance 1.x, 1.5, 2.0 et 2.5
- **Plusieurs résolutions** — Prend en charge 480p, 720p, 1080p, certains modèles prenant en charge la 4k
- **Plusieurs formats d’image** — Prend en charge 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 et adaptive
- **Durée flexible** — Prend en charge 2–30 secondes selon le modèle ou une durée automatique
- **Vidéo multimodale** — Prend en charge la génération audio, l’audio/vidéo de référence, ainsi que l’édition et l’extension vidéo de la 2.5
- **Interrogation des tâches** — Surveiller la progression de la génération et obtenir les résultats

## Recommandé : utiliser l’autorisation OAuth du MCP hébergé

Ajoutez l’adresse du serveur dans les clients prenant en charge OAuth MCP distant :

```text
https://seedance.mcp.acedata.cloud/mcp
```

Choisissez de vous connecter ou de vous authentifier, connectez-vous à Ace Data Cloud, consultez les autorisations et autorisez, puis activez les outils. Ce chemin ne nécessite pas de créer ou de copier d’abord un API Token. Le service prend en charge OAuth discovery, l’enregistrement dynamique de client (DCR) et S256 PKCE ; DCR enregistre le client, l’utilisateur doit toujours se connecter et autoriser, et l’utilisation de l’API est facturée normalement.

| Client                            | Méthode et conditions d’intégration                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Version web de Claude ou version Desktop fournissant des connecteurs distants | Ajoutez l’adresse ci-dessus dans l’interface des connecteurs et autorisez ; l’accès dépend de la version et de l’offre. N’écrivez pas la configuration HTTP distante dans le fichier de configuration stdio local.                      |
| VS Code prenant en charge nativement OAuth MCP distant     | Exécutez **MCP: Add Server**, sélectionnez HTTP, saisissez l’adresse et connectez-vous selon les invites ; l’extension dédiée AceDataCloud utilise un réglage API Key distinct. |
| Autres clients                          | Confirmez que la version actuelle prend en charge HTTP distant, OAuth/DCR, et utilisez les instructions de configuration de ce client. Le format du fichier de configuration ne peut pas être utilisé de manière interchangeable entre les différents clients.                     |

## Chemin alternatif avec API Token

Les clients locaux stdio, auto-hébergés ou ne prenant pas en charge OAuth distant utilisent un API Token. Connectez-vous à la [plateforme Ace Data Cloud](https://platform.acedata.cloud), sélectionnez le service et créez des identifiants API avec les autorisations requises. Stockez le Token dans les paramètres d’identifiants du client ou dans des variables d’environnement locales, ne le placez pas dans l’URL, le contenu de discussion ou le dépôt de versions. La configuration HTTP Header des différents clients doit être renseignée conformément aux instructions de leur version.

Installer le MCP open source ou terminer l’autorisation ne signifie pas obtenir des quotas gratuits, et ne garantit ni le temps de génération ni les droits d’utilisation commerciale. Consultez les tarifs actuels du service, le solde et les conditions applicables avant de générer.

## Méthode deux : exécution locale (installation pip / uvx)

Si vous avez besoin de stdio local, de code personnalisé ou d’auto-hébergement, vous pouvez démarrer le MCP Server localement. La génération nécessite toujours un appel API en ligne, ce n’est pas une inférence hors ligne.

### Installation

Installation avec pip (recommandée) :

```bash
pip install mcp-seedance
```

Ou installation depuis les sources :

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Une fois l’installation terminée, vous pouvez utiliser la commande `mcp-seedance` pour démarrer le service.

### Utilisation dans Claude Desktop (local)

Modifiez le fichier de configuration Claude Desktop :

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Si vous utilisez `uvx` (sans devoir installer le package à l’avance) :

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Redémarrez Claude Desktop après avoir enregistré la configuration pour qu’elle prenne effet.

### Utilisation dans VS Code (local)

Créez `.vscode/mcp.json` à la racine du projet :

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Ou utilisez `uvx` :

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Pour les autres clients locaux, renseignez command, args et env conformément aux instructions de configuration stdio de leur version actuelle ; n’utilisez pas directement la configuration VS Code comme format universel.

## Vérification des résultats et échecs fréquents

Demandez au client de générer une œuvre vidéo simple, conservez le numéro de tâche et interrogez la même tâche jusqu’à ce qu’elle atteigne l’état final de réussite, puis ouvrez ou lisez le lien final. Une connexion réussie, le chargement de la liste d’outils, HTTP 200, un numéro de tâche et un aperçu en cours de traitement ne représentent pas le produit final.

En cas de 401, reconnectez-vous ou vérifiez le Token et les autorisations ; si le solde est insuffisant, consultez la facturation ; si la tâche est en cours de traitement, continuez à l’interroger ; en cas d’échec final, lisez l’erreur puis décidez s’il faut réessayer, une nouvelle génération peut être facturée à nouveau.

## Liste des outils disponibles

| Nom de l’outil                                  | Description             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Générer une vidéo à partir d’une invite textuelle    |
| `seedance_generate_video_from_image` | Générer une vidéo en utilisant une image comme référence     |
| `seedance_get_task`                  | Interroger le statut d’une seule tâche       |
| `seedance_get_tasks_batch`           | Interroger en lot le statut des tâches       |
| `seedance_list_models`               | Lister tous les modèles disponibles et leurs capacités   |
| `seedance_list_resolutions`          | Lister les résolutions et formats d’image disponibles   |
| `seedance_list_actions`              | Lister tous les outils disponibles et les exemples de workflow |

## Exemples d’utilisation

Une fois la configuration terminée, vous pouvez directement appeler ces fonctionnalités en langage naturel dans le client IA, par exemple :

- « Aide-moi à utiliser Seedance pour générer une vidéo en accéléré d’une rue urbaine »
- « Utilise cette photo comme première image et génère une vidéo de 8 secondes »
- « Génère une courte vidéo verticale 1080p au format 9:16 »
- « Utilise le modèle Seedance 1.5 Pro pour générer une vidéo avec audio »
