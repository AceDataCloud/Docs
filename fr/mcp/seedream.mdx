[MCP (Model Context Protocol)](https://modelcontextprotocol.io) est un protocole de contexte de modèle développé par Anthropic, permettant aux modèles d'IA (comme Claude, GPT, etc.) d'appeler des outils externes via une interface standardisée. Grâce au Seedream MCP Server fourni par AceData Cloud, vous pouvez utiliser directement Seedream de ByteDance pour générer et éditer des images IA dans des clients IA tels que Claude Desktop, VS Code, Cursor, etc.

## Aperçu des fonctionnalités

Le Seedream MCP Server offre les fonctionnalités principales suivantes :

- **Génération d'images à partir de texte** — Génération d'images de haute qualité à partir de prompts textuels (prise en charge des prompts en chinois et en anglais)
- **Édition d'images** — Modification du style, de l'arrière-plan, des attributs d'images existantes
- **Essayage virtuel** — Habillage virtuel de vêtements sur des photos de personnes
- **Support multi-modèles** — Support des modèles Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I, etc.
- **Résolutions multiples** — Support des résolutions 1K, 2K, 4K et adaptatives
- **Contrôle des seeds** — Génération reproductible via le paramètre seed
- **Suivi des tâches** — Surveillance de la progression des tâches et récupération des résultats

## Pré-requis

Avant utilisation, vous devez obtenir un API Token AceData Cloud :

1. Inscrivez-vous ou connectez-vous sur la [plateforme AceData Cloud](https://platform.acedata.cloud)
2. Accédez à la page [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Cliquez sur « Acquire » pour obtenir un API Token (un quota gratuit est offert lors de la première demande)

## Installation et configuration

### Méthode 1 : Installation via pip (recommandée)

```bash
pip install mcp-seedream-pro
```

### Méthode 2 : Installation depuis le code source

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Une fois l'installation terminée, vous pouvez lancer le service avec la commande `mcp-seedream-pro`.

## Utilisation dans Claude Desktop

Modifiez le fichier de configuration de Claude Desktop :

- **macOS** : `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows** : `%APPDATA%\Claude\claude_desktop_config.json`

Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre API Token"
      }
    }
  }
}
```

Si vous utilisez `uvx` (pas besoin d’installer le package à l’avance) :

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre API Token"
      }
    }
  }
}
```

Après avoir sauvegardé la configuration, redémarrez Claude Desktop pour utiliser les outils Seedream dans vos conversations.

## Utilisation dans VS Code / Cursor

Créez un fichier `.vscode/mcp.json` à la racine de votre projet :

```json
{
  "servers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre API Token"
      }
    }
  }
}
```

Ou utilisez `uvx` :


## Liste des outils disponibles

| Nom de l'outil             | Description                          |
|----------------------------|------------------------------------|
| `seedream_generate_image`  | Génération d'images à partir de texte |
| `seedream_edit_image`      | Édition ou modification d'images existantes |
| `seedream_get_task`        | Consultation du statut d'une tâche unique |
| `seedream_get_tasks_batch` | Consultation en lot des statuts des tâches |
| `seedream_list_models`     | Liste de tous les modèles disponibles et leurs capacités |
| `seedream_list_sizes`      | Liste des tailles et résolutions d'images disponibles |

## Exemples d'utilisation

Une fois configuré, vous pouvez appeler ces fonctionnalités directement en langage naturel dans votre client IA, par exemple :

- « Aide-moi à générer une peinture de paysage en style encre de Chine avec Seedream »
- « Change l’arrière-plan de cette photo en ciel étoilé »
- « Génère un portrait HD 4K avec Seedream v4.5 »
- « Fais un essayage virtuel de ce vêtement sur cette photo »
