[MCP (Model Context Protocol)](https://modelcontextprotocol.io) est un protocole de contexte de modèle développé par Anthropic, permettant aux modèles d'IA (comme Claude, GPT, etc.) d'appeler des outils externes via une interface standardisée. Grâce au ShortURL MCP Server fourni par AceData Cloud, vous pouvez générer directement des liens courts dans des clients IA tels que Claude Desktop, VS Code, Cursor, etc.

## Aperçu des fonctionnalités

Le ShortURL MCP Server offre les fonctionnalités principales suivantes :

- **Raccourcissement d'un seul lien** — Convertir une URL longue en un lien court facile à partager
- **Raccourcissement par lot** — Raccourcir plusieurs URL en une seule fois (jusqu'à 10)
- **Guide d'utilisation** — Obtenir les instructions complètes et les meilleures pratiques
- **Informations API** — Consulter les détails du service API et les codes d'erreur

## Prérequis

Avant utilisation, vous devez obtenir un jeton API AceData Cloud :

1. Inscrivez-vous ou connectez-vous sur la [plateforme AceData Cloud](https://platform.acedata.cloud)
2. Rendez-vous sur la page [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Cliquez sur « Acquire » pour obtenir un jeton API (une allocation gratuite est offerte lors de la première demande)

## Installation et configuration

### Méthode 1 : installation via pip (recommandée)

```bash
pip install mcp-shorturl
```

### Méthode 2 : installation depuis le code source

```bash
git clone https://github.com/AceDataCloud/MCPShortURL.git
cd MCPShortURL
pip install -e .
```

Une fois l'installation terminée, vous pouvez lancer le service avec la commande `mcp-shorturl`.

## Utilisation dans Claude Desktop

Modifiez le fichier de configuration de Claude Desktop :

- **macOS** : `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows** : `%APPDATA%\Claude\claude_desktop_config.json`

Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Si vous utilisez `uvx` (sans installation préalable de paquet) :

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Après avoir enregistré la configuration, redémarrez Claude Desktop pour utiliser les outils ShortURL dans vos conversations.

## Liste des outils disponibles

| Nom de l'outil           | Description                                  |
|--------------------------|----------------------------------------------|
| `shorturl_create`        | Raccourcir une seule URL                      |
| `shorturl_batch_create`  | Raccourcir plusieurs URL en lot (jusqu'à 10)|
| `shorturl_get_usage_guide` | Obtenir le guide d'utilisation complet     |
| `shorturl_get_api_info`  | Obtenir les détails du service API            |

## Exemple d'utilisation

Une fois configuré, vous pouvez appeler ces fonctionnalités directement via langage naturel dans votre client IA, par exemple :

- « Peux-tu raccourcir ce lien pour moi ? »
- « Raccourcis ces 5 URL en lot »
- « Génère un lien court pour le partage »
