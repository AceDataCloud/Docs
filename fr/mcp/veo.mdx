[MCP (Model Context Protocol)](https://modelcontextprotocol.io) est un protocole de contexte de modèle développé par Anthropic, permettant aux modèles d'IA (comme Claude, GPT, etc.) d'appeler des outils externes via une interface standardisée. Grâce au Veo MCP Server fourni par AceData Cloud, vous pouvez directement utiliser Google Veo pour générer des vidéos IA dans des clients IA tels que Claude Desktop, VS Code, Cursor, etc.

## Aperçu des fonctionnalités

Le Veo MCP Server offre les fonctionnalités principales suivantes :

- **Génération de vidéo à partir de texte** — Génération de vidéos de haute qualité à partir d'invites textuelles
- **Génération de vidéo à partir d'images** — Génération de vidéos basées sur des images
- **Support multi-modèles** — Prise en charge des modèles veo3, veo2, veo31-fast-ingredients, etc.
- **Formats multiples** — Support des résolutions 4K, 1080p, GIF, etc.
- **Formats d'image variés** — Support des ratios 16:9, 9:16, etc.
- **Mise à niveau 1080p** — Amélioration des vidéos existantes vers la résolution 1080p
- **Suivi des tâches** — Surveillance de la progression et récupération des résultats

## Prérequis

Avant utilisation, vous devez obtenir un jeton API AceData Cloud :

1. Inscrivez-vous ou connectez-vous sur la [plateforme AceData Cloud](https://platform.acedata.cloud)
2. Rendez-vous sur la page [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Cliquez sur « Acquire » pour obtenir un jeton API (une allocation gratuite est offerte lors de la première demande)

## Installation et configuration

### Méthode 1 : installation via pip (recommandée)

```bash
pip install mcp-veo
```

### Méthode 2 : installation depuis le code source

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

Une fois l'installation terminée, vous pouvez lancer le service avec la commande `mcp-veo`.

## Utilisation dans Claude Desktop

Modifiez le fichier de configuration de Claude Desktop :

- **macOS** : `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows** : `%APPDATA%\Claude\claude_desktop_config.json`

Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Si vous utilisez `uvx` (pas besoin d’installer les paquets au préalable) :

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Après avoir sauvegardé la configuration, redémarrez Claude Desktop pour utiliser les outils Veo dans vos conversations.

## Utilisation dans VS Code / Cursor

Créez un fichier `.vscode/mcp.json` à la racine du projet :

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Ou utilisez `uvx` :

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
```

## Liste des outils disponibles

| Nom de l'outil          | Description                           |
|------------------------|-------------------------------------|
| `veo_text_to_video`     | Génération de vidéo à partir de texte |
| `veo_image_to_video`    | Génération de vidéo à partir d’image  |
| `veo_get_1080p`         | Mise à niveau des vidéos vers 1080p  |
| `veo_get_task`          | Consultation du statut d’une tâche    |
| `veo_get_tasks_batch`   | Consultation en lot des statuts des tâches |

## Exemple d'utilisation

Une fois la configuration terminée, vous pouvez appeler ces fonctionnalités directement en langage naturel dans votre client IA, par exemple :

- « Aide-moi à générer une vidéo time-lapse du ciel étoilé avec Veo »
- « Génère une vidéo 4K à partir de cette photo de paysage »
- « Crée une courte vidéo verticale au format 9:16 »
- « Améliore cette vidéo en 1080p »
