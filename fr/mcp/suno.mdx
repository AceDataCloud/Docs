[MCP (Model Context Protocol)](https://modelcontextprotocol.io) est un protocole de contexte de modèle lancé par Anthropic, qui permet aux modèles d’IA (comme Claude, GPT, etc.) d’appeler des outils externes via des interfaces standardisées. Grâce au Suno MCP Server fourni par AceData Cloud, vous pouvez générer directement de la musique, des paroles et gérer des projets audio dans des clients IA tels que Claude Desktop, VS Code, Cursor, etc.

## Aperçu des fonctionnalités

Suno MCP Server fournit les fonctionnalités principales suivantes :

- **Génération de musique** — Générer de la musique IA à partir d’invites textuelles
- **Création personnalisée** — Contrôler entièrement les paroles, le titre et le style musical
- **Continuation de chanson** — Continuer et prolonger une chanson existante à partir de n’importe quel moment
- **Reprise/remix** — Créer des versions reprises dans différents styles
- **Génération de paroles** — Générer des paroles structurées selon une description
- **Personnages vocaux** — Enregistrer et réutiliser des styles vocaux
- **Conversion de médias** — Obtenir des fichiers MP4, WAV, MIDI, des pistes vocales séparées, etc.
- **Optimisation de style** — Optimiser les étiquettes de style musical
- **Consultation des tâches** — Surveiller la progression de la génération et obtenir les résultats

## Préparation préalable

Avant utilisation, vous devez obtenir un API Token AceData Cloud :

1. Inscrivez-vous ou connectez-vous à la [plateforme AceData Cloud](https://platform.acedata.cloud)
2. Accédez à la page [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Cliquez sur « Acquire » pour obtenir un API Token (la première demande inclut un crédit gratuit)

## Méthode 1 : utiliser le MCP Server hébergé (recommandé, sans installation)

AceData Cloud a déjà hébergé le **Suno MCP Server** dans le cloud, **aucune dépendance locale n’est nécessaire**, il suffit de renseigner l’URL suivante dans le client IA pour l’utiliser directement :

```
https://suno.mcp.acedata.cloud/mcp
```

Méthode d’authentification : ajoutez `Authorization: Bearer votre API Token` dans l’en-tête de la requête (Claude.ai effectue automatiquement cette opération via OAuth, sans devoir renseigner manuellement le Token).

### Claude.ai (version web, connexion OAuth, le plus simple)

1. Ouvrez [Claude.ai](https://claude.ai) → en bas à gauche **Customize** → **Connectors** → **Add More**
2. Saisissez dans l’URL : `https://suno.mcp.acedata.cloud/mcp`
3. Terminez la connexion d’autorisation OAuth (redirection automatique vers la page de connexion AceData Cloud)
4. Revenez à l’interface de conversation, l’outil peut alors être utilisé

### Claude Desktop

Modifiez le fichier de configuration :

- macOS : `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows : `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Enregistrez puis redémarrez Claude Desktop pour que cela prenne effet.

### Claude Code (ligne de commande du terminal)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Autres clients prenant en charge MCP

Tout client prenant en charge le protocole MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant, etc.) peut être connecté en renseignant les deux éléments suivants :

- **URL** : `https://suno.mcp.acedata.cloud/mcp`
- **Header** : `Authorization: Bearer votre API Token`

## Méthode 2 : exécution locale (installation via pip / uvx)

Si vous devez exécuter hors ligne, personnaliser le code ou déployer sur un réseau interne, vous pouvez installer le MCP Server localement et le démarrer via stdio.

### Installation

Installation via pip (recommandée) :

```bash
pip install mcp-suno
```

Ou installation depuis les sources :

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Une fois l’installation terminée, vous pouvez utiliser la commande `mcp-suno` pour démarrer le service.

### Utilisation dans Claude Desktop (local)

Modifiez le fichier de configuration de Claude Desktop :

- **macOS** : `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows** : `%APPDATA%\Claude\claude_desktop_config.json`

Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Si vous utilisez `uvx` (aucune installation préalable du package nécessaire) :

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Enregistrez la configuration puis redémarrez Claude Desktop pour que cela prenne effet.

## Exemples d’utilisation

Une fois la configuration terminée, vous pouvez appeler directement ces fonctionnalités en langage naturel dans le client IA, par exemple :

- « Aide-moi à générer une chanson pop sur l’été »
- « Fais une reprise de cette chanson dans un style jazz »
- « Prolonge cette chanson, à partir de la 30e seconde »
- « Génère des paroles en chinois, sur le thème du voyage »
- « Sépare les voix de cette chanson »
- « Aide-moi à convertir cette chanson au format MIDI »

## Contrôle avancé et projets Studio

`suno_generate_music` prend en charge `variety` ; `suno_generate_custom_music` prend également en charge
`max_mode` et `audio_weight`. `max_mode` utilise un niveau de facturation API plus élevé, n’est pas activé par défaut,
et doit être défini après que l’utilisateur a explicitement choisi le mode amélioré. Les prix actuels sont ceux de la page de service de la plateforme.

`suno_generate_with_custom_model` peut utiliser `instrumental=true` pour générer de la musique instrumentale, ou utiliser
`lyric_prompt` pour générer automatiquement des paroles ; sinon, fournissez `lyric`. Le titre et le style peuvent être omis, et vous pouvez également transmettre
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` et
`callback_url`. Les valeurs de contrôle explicites de `0` seront conservées.

`request.action` de `suno_manage_project` peut être `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. Les entrées diffèrent selon l’action, les modifications du projet doivent utiliser le `version_id` lu le plus récemment ;
lors de l’enregistrement, transmettez l’intégralité de `state`, en conservant les pistes et les champs existants.

À l’exception de `retrieve`, chaque appel doit fournir un `idempotency_key`. Utilisez une nouvelle clé pour une nouvelle opération d’écriture ;
en cas de délai d’attente ou de résultat d’acceptation incertain, conservez la clé d’origine et réessayez avec une requête entièrement identique, ou interrogez la tâche d’origine, ne
changez pas automatiquement de clé pour renvoyer une génération facturée. Les intervalles de l’audio source sont en secondes, les intervalles de la chronologie du projet sont en temps. La génération ne crée que des candidats,
vous devez sélectionner un candidat et appeler `commit_candidate` pour l’écrire dans la piste.

Le `task_id` accepté de manière asynchrone est interrogé avec `suno_get_task`. Lorsque `finished_at` est vide, continuez d’attendre,
après l’état final, vérifiez `response.success` et les erreurs ; ne considérez pas une acceptation réussie comme une génération, une validation ou une exportation réussie.
`suno_get_tasks_batch` renvoie des enregistrements de tâches JSON complets, en conservant les objets de modèles personnalisés, les états de projet,
les candidats et les divers résultats tels que MIDI. Consultez le flux de travail complet dans le [guide des projets Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
