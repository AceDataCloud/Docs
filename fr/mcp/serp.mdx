[MCP (Model Context Protocol)](https://modelcontextprotocol.io) est un protocole de contexte de modèle lancé par Anthropic, permettant aux modèles d'IA (comme Claude, GPT, etc.) d'appeler des outils externes via une interface standardisée. Grâce au serveur SERP MCP fourni par AceData Cloud, vous pouvez effectuer des recherches Google directement dans des clients IA tels que Claude Desktop, VS Code, Cursor, etc., pour obtenir des résultats de recherche de pages web, d'images, de nouvelles, de vidéos, de lieux, etc.

## Vue d'ensemble des fonctionnalités

Le serveur SERP MCP offre les fonctionnalités principales suivantes :

- **Recherche de pages web** — Recherche de résultats de pages Google
- **Recherche d'images** — Recherche d'images Google
- **Recherche de nouvelles** — Recherche de nouvelles Google
- **Recherche de vidéos** — Recherche de vidéos Google
- **Recherche de lieux** — Recherche d'informations sur les lieux Google
- **Recherche de cartes** — Recherche de cartes Google
- **Multilingue et multi-régions** — Prise en charge des paramètres de pays et de langue personnalisés
- **Filtrage par plage de temps** — Filtrage des résultats par jour, semaine, mois, année

## Préparations préalables

Avant d'utiliser, vous devez obtenir un jeton API AceData Cloud :

1. Inscrivez-vous ou connectez-vous à la [plateforme AceData Cloud](https://platform.acedata.cloud)
2. Allez à la page [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. Cliquez sur « Acquire » pour obtenir un jeton API (première demande avec un quota gratuit)

## Installation et configuration

### Méthode 1 : installation avec pip (recommandée)

```bash
pip install mcp-serp
```

### Méthode 2 : installation à partir du code source

```bash
git clone https://github.com/AceDataCloud/SerpMCP.git
cd SerpMCP
pip install -e .
```

Une fois l'installation terminée, vous pouvez utiliser la commande `mcp-serp` pour démarrer le service.

## Utilisation dans Claude Desktop

Éditez le fichier de configuration de Claude Desktop :

- **macOS** : `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows** : `%APPDATA%\Claude\claude_desktop_config.json`

Ajoutez la configuration suivante :

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Si vous utilisez `uvx` (pas besoin d'installer le package à l'avance) :

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "votre jeton API"
      }
    }
  }
}
```

Après avoir enregistré la configuration, redémarrez Claude Desktop pour pouvoir utiliser les outils de recherche Google dans la conversation.

## Exemples d'utilisation

Une fois la configuration terminée, vous pouvez appeler ces fonctionnalités directement en langage naturel dans le client IA, par exemple :

- « Aide-moi à rechercher les derniers articles sur l'IA »
- « Recherche de bons restaurants de hot pot à Pékin »
- « Trouver des images sur la programmation asynchrone en Python »
- « Recherche des nouvelles technologiques d'aujourd'hui »
- « Trouver des cafés à proximité sur la carte »
