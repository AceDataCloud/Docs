## Introduction à Suno

Suno est actuellement l'une des plateformes d'IA de génération musicale les plus puissantes. Grâce à l'API Suno d'Ace Data Cloud, vous pouvez générer de la musique de haute qualité via de simples appels API.

## Points de terminaison de l'API

| Point de terminaison | Fonctionnalité |
|---------------------|---------------|
| `POST /suno/audios` | Génération de musique (point principal) |
| `POST /suno/lyrics` | Génération de paroles |
| `POST /suno/persona` | Gestion des styles de chanteur |
| `POST /suno/wav` | Obtention du format WAV |
| `POST /suno/mp4` | Obtention du format MP4 |
| `POST /suno/tasks` | Consultation du statut des tâches |

## Génération de base

### Génération à partir d'une description textuelle

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Génération personnalisée de paroles

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Fonctionnalités avancées

### Extension de chanson

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Génération de paroles

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```
