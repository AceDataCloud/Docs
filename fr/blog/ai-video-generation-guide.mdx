## Vue d'ensemble

La génération vidéo IA évolue rapidement. Ace Data Cloud propose 7 API de génération vidéo, couvrant divers scénarios allant de la vidéo générée à partir de texte à la vidéo générée à partir d'images.

## Services de génération vidéo disponibles

| Service | Endpoint | Modèle | Caractéristiques |
|---------|----------|--------|------------------|
| Sora    | `POST /sora/videos` | sora-2, sora-2-pro | Produit par OpenAI, qualité cinématographique |
| Veo     | `POST /veo/videos` | veo3, veo3-fast | Produit par Google, supporte la 4K |
| Kling   | `POST /kling/videos` | kling-v2-5-turbo | Produit par Kuaishou, rapide |
| Luma    | `POST /luma/videos` | — | Contrôle des images de début et fin |
| Hailuo  | `POST /hailuo/videos` | minimax-t2v | Produit par MiniMax |
| Seedance| `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Produit par ByteDance |
| Wan     | `POST /wan/videos` | wan2.6-t2v | Produit par Alibaba |

## Démarrage rapide

### Génération vidéo avec Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Génération vidéo avec Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Génération vidéo avec Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## Traitement des tâches asynchrones

La génération vidéo prend généralement du temps. Toutes les API vidéo supportent :

1. **Notification par callback** : définir `callback_url` dans la requête, le résultat est automatiquement envoyé une fois la génération terminée
2. **Requête en polling** : interroger l'état de la tâche via l’endpoint `/tasks`

```python
# Utilisation de l'URL de callback
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Ou interrogation de l'état de la tâche
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```

## Recommandations de choix

- **Meilleure qualité d’image** : Sora (sora-2-pro)
- **Vitesse la plus rapide** : Kling (kling-v2-5-turbo)
- **Résolution la plus élevée** : Veo (supporte la 4K)
- **Contrôle des images de début et fin** : Luma
- **Meilleur rapport qualité-prix** : Wan

Essayez gratuitement sur [platform.acedata.cloud](https://platform.acedata.cloud).
