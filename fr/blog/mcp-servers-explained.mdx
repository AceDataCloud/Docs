## Qu'est-ce que le MCP

Le Model Context Protocol (MCP) est un protocole ouvert qui permet aux assistants IA (comme Claude, Cursor) d'appeler directement des outils externes et des API. Grâce au MCP, l'IA peut non seulement répondre aux questions, mais aussi effectuer des actions concrètes.

## MCP Server fournis par Ace Data Cloud

| MCP Server      | Nom du package PyPI | Fonctionnalité       |
|-----------------|---------------------|---------------------|
| MCPSuno         | mcp-suno            | Génération musicale IA |
| MCPSerp         | mcp-serp            | Recherche Google    |
| MCPMidjourney   | mcp-midjourney      | Génération d'images IA |
| MCPLuma         | mcp-luma            | Génération vidéo IA |
| MCPSora         | mcp-sora            | Génération vidéo IA |
| MCPVeo          | mcp-veo             | Génération vidéo IA |
| MCPNanoBanana   | mcp-nano-banana     | Génération d'images IA |

## Installation et utilisation

### Installation

```bash
pip install mcp-suno  # ou un autre MCP Server
```

### Configuration des variables d'environnement

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Configuration dans Cursor

Ajouter dans les paramètres MCP de Cursor :

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Configuration dans Claude Desktop

Éditez le fichier de configuration de Claude Desktop pour ajouter la configuration du MCP Server.

## Cas d'utilisation

1. **Générer de la musique dans Cursor** : dites à l'IA « Génère une chanson joyeuse avec Suno », l'IA appellera directement l'API  
2. **Rechercher des informations en temps réel** : l'IA peut utiliser le MCP Server SERP pour rechercher les informations les plus récentes  
3. **Générer des ressources pour un projet** : l'IA peut appeler Midjourney pour créer les images nécessaires au projet

## MCP vs appel direct d'API

- **MCP** : adapté à une utilisation dans des outils de programmation IA, appelé automatiquement par l'IA  
- **API** : adapté à une intégration dans vos propres applications, contrôle programmatique

Les deux utilisent le même Ace Data Cloud API Token et appellent les mêmes points d'API en arrière-plan.

## Résumé

Le MCP permet aux assistants IA d'appeler directement diverses API d'Ace Data Cloud. Tous les MCP Server sont publiés sur PyPI, leur installation et configuration sont simples, ce qui rend vos outils IA plus puissants.

Rendez-vous sur [platform.acedata.cloud](https://platform.acedata.cloud) pour obtenir un API Token.
