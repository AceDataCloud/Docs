title: "Wan API de génération de vidéos"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/videos` prend en charge à la fois le modèle Wan 2.6 existant et `wan3.0-video`. Wan 3 reconnaît automatiquement le texte, les premières et dernières images ou les modèles de matériel de référence selon `media`.

## Wan 3 Vidéo générée par texte

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "Un bateau en papier dérivant à travers une ville néon la nuit",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 prend en charge des durées entières de 2 à 30 secondes ou `-1` pour une durée intelligente, avec des résolutions de `480P`, `720P`, `1080P`.

## Références multimédias

```json
{
  "model": "wan3.0-video",
  "prompt": "Créer une révélation de produit cinématographique",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` prend en charge :

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Les modes de première et dernière image et les modes de matériel de référence ne peuvent pas être mélangés. Les vidéos de référence sont finalement comptabilisées selon la durée réelle de la vidéo d'entrée ajoutée à la durée de la vidéo de sortie ; les entrées de texte, d'images et d'audio n'augmentent pas la durée de la vidéo.

## Prix standard officiel

| Résolution |      Prix |
| ----- | ------: |
| 480P  | $0.05/seconde |
| 720P  | $0.10/seconde |
| 1080P | $0.20/seconde |

## Compatibilité Wan 2.6

Les modèles existants `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` et les variantes flash continuent d'utiliser des paramètres tels que `action`, `image_url`, `reference_video_urls`, le chemin d'appel reste inchangé.

## Asynchrone et résultats

En définissant `async: true`, vous obtenez immédiatement un `task_id`, et vous pouvez obtenir l'état final via `/wan/tasks`. Les vidéos réussies seront transférées vers le CDN d'AceDataCloud et le véritable usage et coût seront renvoyés dans la réponse.
