---
title: "API de génération vidéo Wan"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/videos` prend en charge à la fois les modèles Wan 2.6 existants et `wan3.0-video`. Wan 3 identifie automatiquement le mode texte, première et dernière image ou ressources de référence selon `media`.

## Wan 3 texte vers vidéo

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 prend en charge des entiers de 2 à 30 secondes ou la durée intelligente `-1`, avec les résolutions `480P`, `720P`, `1080P`.

## Référence multimédia

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` prend en charge :

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Le mode première et dernière image et le mode ressources de référence ne peuvent pas être utilisés ensemble. Les vidéos de référence sont finalement facturées selon les secondes réelles de la vidéo d'entrée plus les secondes de la vidéo de sortie générée avec succès ; les entrées texte, image et audio n'ajoutent pas de secondes vidéo.

## Prix standard officiel

| Résolution   |      Prix |
| ----- | ------: |
| 480P  | $0.05/seconde |
| 720P  | $0.10/seconde |
| 1080P | $0.20/seconde |

## Compatibilité Wan 2.6

Les variantes existantes `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` et flash continuent d'utiliser des paramètres tels que `action`, `image_url`, `reference_video_urls`, etc., et le chemin d'appel reste inchangé.

## Asynchrone et résultats

Après avoir défini `async: true`, vous obtenez immédiatement un `task_id`, puis récupérez l'état final via `/wan/tasks`. Les vidéos générées avec succès seront transférées vers le CDN AceDataCloud, et l'usage et le coût réels seront renvoyés dans la réponse.
