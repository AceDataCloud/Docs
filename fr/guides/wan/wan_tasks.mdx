title: "Wan tâche de requête API"
description: "Tongyi Wansiang Video Generation API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/tasks` est utilisé pour interroger, interroger en masse ou supprimer des tâches vidéo Wan. La requête de tâche ne facture pas de frais de génération supplémentaires.

## Interroger une seule tâche

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

L'`response.data.video_url` de la tâche terminée est l'adresse CDN permanente ; `response.usage` contient la résolution, la durée des vidéos d'entrée/sortie, le taux de rafraîchissement et le rapport ; `response.cost` est le règlement de la tâche de génération.

## Interrogation en masse

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Retourne `{ "items": [...], "count": 2 }`. Lorsque la tâche est en cours, il se peut qu'il n'y ait pas encore de `finished_at` et de `response` final.

## Supprimer l'enregistrement de la tâche

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

La suppression n'affecte que l'historique des tâches, elle ne supprimera pas les vidéos CDN déjà générées.
