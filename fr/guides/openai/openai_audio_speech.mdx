---
title: "API de synthèse vocale OpenAI (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Transformez le texte en voix naturelle, **entièrement compatible avec le `/v1/audio/speech` d'OpenAI**. Tout SDK OpenAI doit simplement pointer `base_url` vers `https://api.acedata.cloud` et remplacer la clé par votre AceData Token pour une utilisation directe. L'interface renvoie un flux de bytes audio en synchronisation.

- **URL de la requête** : `POST https://api.acedata.cloud/v1/audio/speech` (alias `POST /openai/audio/speech`)
- **Authentification** : en-tête de requête `Authorization: Bearer {token}`
- **Facturation** : facturation basée sur le nombre de bytes de texte de la requête, environ 85 % du prix officiel d'OpenAI (voir le tableau ci-dessous).

## Paramètres de la requête

| Champ              | Type     | Obligatoire | Description                                                      |
| ----------------- | ------ | ----------- | ------------------------------------------------------------- |
| `input`           | string | Oui         | Texte à synthétiser.                                           |
| `model`           | string | Non         | `tts-1` (plus rapide) ou `tts-1-hd` (meilleure qualité, par défaut). |
| `voice`           | string | Non         | Un des suivants : `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, par défaut `alloy`. |
| `response_format` | string | Non         | `mp3` (par défaut), `opus`, `aac`, `flac`, `wav`, `pcm`.     |
| `speed`           | number | Non         | Vitesse de parole 0.25–4.0, par défaut 1.0.                   |

## Exemple

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Que se passerait-il si une API vous donnait tous les modèles vidéo d'IA ?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Le retour est le fichier audio lui-même (`Content-Type: audio/mpeg`), écrit directement dans `speech.mp3` pour être joué.

Utiliser le SDK Python officiel d'OpenAI :

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Bonjour d'AceData.").stream_to_file("speech.mp3")
```

## Prix

| Modèle        | Prix officiel OpenAI | Prix de cette plateforme (environ 85 % de réduction) |
| ------------ | ------------------- | ----------------------------------------------- |
| `tts-1`     | 15 $ / 1 million de caractères | environ 12,75 $ / 1 million de caractères |
| `tts-1-hd`  | 30 $ / 1 million de caractères | environ 25,5 $ / 1 million de caractères  |

> Facturation basée sur le nombre de bytes de texte de la requête ; le champ `official_price` affiche le prix officiel d'OpenAI pour comparaison.

## Codes d'erreur

| Code d'état | code                    | Description               |
| ----------- | ----------------------- | ------------------------- |
| 400         | `bad_request`           | `input` est vide ou paramètre invalide. |
| 401         | `authentication_failed` | token invalide.           |
| 403         | `used_up`               | Solde insuffisant.        |
| 429         | `too_many_requests`     | Trop de requêtes.        |
| 500         | `api_error`             | Erreur en amont/interne. |
