## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Envoyer la première requête

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer votre clé API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Illustration de produit éditorial minimaliste : une tasse à café en céramique blanche centrée sur une table en cobalt bleu solide, fond crème pâle, ombre douce, formes géométriques épurées, pas de texte, pas de logo, composition portrait",
    "size": "1024x1536"
  }'
```

L'image de réponse réussie se trouve à `data[].url`. Voici le résultat 1024×1536 obtenu par une requête réelle via Ace Data Cloud le 8 septembre 2026 (tâche `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`) :

![Tasse blanche générée par GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Paramètres courants

| Champ              | Description                                                               |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | Utilisez `gpt-image-2` ; vous pouvez également choisir explicitement `gpt-image-2:official` ou `gpt-image-2:reverse` |
| `prompt`          | Description de l'image, maximum 32 000 caractères                             |
| `size`            | `auto` ou `WIDTHxHEIGHT` ; la largeur et la hauteur doivent être des multiples de 16, la longueur maximale de 3840, le total des pixels ne dépassant pas 8 294 400        |
| `n`               | 1–10 ; uniquement 1 pris en charge lorsque `response_format=b64_json`     |
| `quality`         | `low`, `medium`, `high` ou `auto` ; le support et la facturation varient selon les lignes                          |
| `response_format` | `url` ou `b64_json`                                                   |
| `callback_url`    | Optionnel ; envoyer les résultats à cette adresse après l'achèvement des tâches longues                                   |

Tailles courantes :

| Ratio   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` choisira le format en fonction du ratio, des pixels et de l'intention de mise en page dans le prompt ; pour des pixels précis, indiquez directement la taille.

## 4. Génération multiple

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer votre clé API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Un petit renard lisant sous un champignon lumineux, illustration aquarelle",
    "size": "1536x1024",
    "n": 2
  }'
```

Le `gpt-image-2` par défaut et `:reverse` facturent en fonction du nombre d'images réussies ; `gpt-image-2:official` facture en fonction des tokens réels utilisés pour l'entrée textuelle et la sortie d'image. Les prix affichés sont des estimations avant la demande, le montant final étant basé sur les enregistrements d'utilisation.

## 5. Rappel asynchrone

Après avoir ajouté `callback_url` au corps de la requête, l'interface renverra d'abord `{"task_id": "..."}`, et enverra le résultat final à cette URL par POST une fois terminé ; les requêtes synchrones renvoient toujours `created` et `data` :

```json
{
  "model": "gpt-image-2",
  "prompt": "Une affiche de produit avec une typographie claire",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Le destinataire du rappel doit utiliser `task_id` pour éviter les doublons et vérifier l'origine de la requête ainsi que le format des données.

## 6. Dépannage

| État  | Vérification                                          |
| --- | --------------------------------------------------- |
| 400 | Combinaison de `model`, `prompt`, format de taille, `n` et `response_format`    |
| 401 | La clé API est-elle complète, l'en-tête est-il `Authorization: Bearer ...` ? |
| 429 | Trop de requêtes, veuillez réessayer plus tard                                   |
| 504 | Délai d'attente pour la génération synchrone ; utilisez `callback_url`         |

Les réponses d'erreur contiendront `error.code`, `error.message` et `trace_id`. Lors de la signalisation d'un problème, fournissez `trace_id`, ne fournissez pas la clé API.

Les champs complets et l'énumération en temps réel sont basés sur la page [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Pour l'édition d'images, veuillez consulter [GPT Image 2 Édition d'images](https://platform.acedata.cloud/documents/openai-images-edits).
