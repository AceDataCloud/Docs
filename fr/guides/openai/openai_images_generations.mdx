## 1. Obtenir une clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir une clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Envoyer la première requête

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

L’image de la réponse réussie se trouve dans `data[].url`. Voici le résultat 1024×1536 obtenu à partir d’une requête réelle via Ace Data Cloud le 8 septembre 2026 (tâche `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`) :

![Tasse blanche générée par GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Paramètres courants

| Champ                | Description                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recommandé par défaut), `gpt-image-2.5-flare` (plus rapide) ou `gpt-image-2.5-sunburst` (meilleure fidélité et contrôle) ; les trois peuvent sélectionner la variante `:official` correspondante, et `gpt-image-2` prend également en charge `:reverse` |
| `prompt`          | Description de l’image, jusqu’à 32 000 caractères                                                                                                                     |
| `size`            | `auto` ou `WIDTHxHEIGHT` ; la largeur et la hauteur doivent être des multiples de 16, le côté le plus long ne doit pas dépasser 3840, le total de pixels doit être de 655 360–8 294 400, et le rapport largeur/hauteur ne doit pas dépasser 3:1                                                       |
| `n`               | 1–10 ; seul 1 est pris en charge lorsque `response_format=b64_json`                                                                                                 |
| `quality`         | Les modèles GPT Image prennent en charge `auto`, `low`, `medium`, `high` ; 2.5 / 2.6 Flare / Sunburst (y compris `:official`) prennent également en charge `xhigh`, `max`. Le canal officiel est facturé selon l’utilisation réelle de Token             |
| `response_format` | `url` ou `b64_json`                                                                                                                     |
| `callback_url`    | Facultatif ; envoie les résultats à cette adresse après l’achèvement d’une tâche longue                                                                                                                      |

Tailles courantes :

| Ratio   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` sélectionne le format selon le ratio, les pixels et l’intention de mise en page dans le prompt ; lorsqu’un nombre précis de pixels est requis, indiquez directement les dimensions.

### Modèles et méthodes de facturation

| Modèle                                | Cas d’usage et méthode de facturation                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Canal inversé par défaut, facturation fixe par image réussie                               |
| `gpt-image-2:reverse`             | Sélection explicite du canal inversé, facturation fixe par image réussie                             |
| `gpt-image-2:official`            | Canal API officiel, stabilité supérieure, facturation selon l’utilisation réelle de Token                   |
| `gpt-image-2.5-flare`             | Axé sur la vitesse de génération, facturation fixe par image réussie                               |
| `gpt-image-2.6-flare`             | Axé sur la vitesse de génération, facturation fixe par image réussie                               |
| `gpt-image-2.5-flare:reverse`     | Alias inversé explicite, équivalent à `gpt-image-2.5-flare`, facturation fixe par image réussie    |
| `gpt-image-2.6-flare:reverse`     | Alias inversé explicite, équivalent à `gpt-image-2.6-flare`, facturation fixe par image réussie    |
| `gpt-image-2.5-flare:official`    | Canal API officiel, stabilité supérieure et axé sur la vitesse de génération, facturation selon l’utilisation réelle de Token            |
| `gpt-image-2.6-flare:official`    | Canal API officiel, stabilité supérieure et axé sur la vitesse de génération, facturation selon l’utilisation réelle de Token            |
| `gpt-image-2.5-sunburst`          | Axé sur la haute fidélité et le contrôle précis, facturation fixe par image réussie                           |
| `gpt-image-2.6-sunburst`          | Axé sur la haute fidélité et le contrôle précis, facturation fixe par image réussie                           |
| `gpt-image-2.5-sunburst:reverse`  | Alias inversé explicite, équivalent à `gpt-image-2.5-sunburst`, facturation fixe par image réussie |
| `gpt-image-2.6-sunburst:reverse`  | Alias inversé explicite, équivalent à `gpt-image-2.6-sunburst`, facturation fixe par image réussie |
| `gpt-image-2.5-sunburst:official` | Canal API officiel, stabilité supérieure et axé sur la haute fidélité et le contrôle précis, facturation selon l’utilisation réelle de Token        |
| `gpt-image-2.6-sunburst:official` | Canal API officiel, stabilité supérieure et axé sur la haute fidélité et le contrôle précis, facturation selon l’utilisation réelle de Token        |

Les modèles inversés 2.0 / 2.5 (y compris les alias `:reverse`) peuvent utiliser GPT Image 2.5 Flare pour traiter la requête lors d’une récupération automatique ; le modèle demandé et la méthode de facturation par image réussie restent inchangés.

Le prix affiché pour le canal API officiel est une estimation avant la requête ; le montant final est basé sur l’utilisation réelle de Token dans la réponse et les registres d’utilisation.

## 4. Génération de plusieurs images

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` et leurs alias `:reverse` sont facturés selon le nombre d’images réussies ; `gpt-image-2:official`, `gpt-image-2.5-flare:official` et `gpt-image-2.5-sunburst:official` sont facturés selon les Tokens réellement utilisés pour l’entrée texte et la sortie image dans la réponse. Le prix affiché sur la page est une estimation avant la requête ; le relevé d’utilisation final fait foi.

## 5. Rappel asynchrone

Après avoir ajouté `callback_url` au corps de la requête, l’interface renverra d’abord `{"task_id": "..."}`, puis enverra le résultat final par POST vers cette URL une fois terminé ; les requêtes synchrones renvoient toujours `created` et `data` :

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Le destinataire du rappel doit dédupliquer à l’aide de `task_id` et vérifier la source de la requête ainsi que le format des données.

## 6. Dépannage

| Statut | Vérifier                                                  |
| --- | --------------------------------------------------- |
| 400 | La combinaison de `model`, `prompt`, du format de taille, de `n` et de `response_format`    |
| 401 | Si la clé API est complète, et si le Header est `Authorization: Bearer ...` |
| 429 | Les requêtes sont trop fréquentes, réessayez plus tard                                         |
| 504 | Délai d’expiration de la génération synchrone ; utilisez plutôt `callback_url`                            |

Les réponses d’erreur contiennent `error.code`, `error.message` et `trace_id`. Lors d’un signalement de problème, fournissez le `trace_id`, mais ne fournissez pas la clé API.

Pour les champs complets et les énumérations en temps réel, référez-vous à la page [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Pour l’édition d’images, consultez [Édition d’images GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 reprend les interfaces de génération, d’édition, de tâches asynchrones et de facturation de la version 2.5 :

| Modèle                                                          | Facturation                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/image                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/image                   |
| `gpt-image-2.6-flare:official`                              | Identique à 2.5 official, facturé selon l’utilisation réelle de Tokens |
| `gpt-image-2.6-sunburst:official`                           | Identique à 2.5 official, facturé selon l’utilisation réelle de Tokens |

Les qualités disponibles sont `auto`, `low`, `medium`, `high`, `xhigh`, `max` ; pour les tailles, utilisez `auto` ou `WIDTHxHEIGHT` conforme aux contraintes ci-dessus. Cette interface prend en charge `png`, `jpeg`, `webp`, mais ne prend pas encore en charge SVG/GIF. L’édition prend en charge les URL d’images JSON et l’envoi de fichiers multipart. `:reverse` est un alias explicite de la version standard du même nom. Veuillez utiliser le nom de modèle complet, ne transmettez pas `gpt-image-2.6`.
