## 1. Obtenir une clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir une clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Envoyer la première requête

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

L’image de la réponse réussie se trouve dans `data[].url`. Voici le résultat 1024×1536 obtenu à partir d’une requête réelle via Ace Data Cloud le 8 septembre 2026 (tâche `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`) :

![Tasse blanche générée par GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Paramètres courants

| Champ                | Description                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (recommandé par défaut), `gpt-image-2.5-flare` (plus rapide) ou `gpt-image-2.5-sunburst` (meilleure fidélité et contrôle) ; les trois peuvent sélectionner la variante `:official` correspondante, et `gpt-image-2` prend également en charge `:reverse` |
| `prompt`          | Description de l’image, jusqu’à 32 000 caractères                                                                                                                     |
| `size`            | `auto` ou `WIDTHxHEIGHT` ; la largeur et la hauteur doivent être des multiples de 16, le côté le plus long ne doit pas dépasser 3840, le total de pixels doit être de 655 360–8 294 400, et le rapport largeur/hauteur ne doit pas dépasser 3:1                                                       |
| `n`               | 1–10 ; lorsque `response_format=b64_json`, seul 1 est pris en charge                                                                                                 |
| `quality`         | Les modèles GPT Image prennent en charge `auto`, `low`, `medium`, `high` ; 2.5 / 2.6 Flare / Sunburst (y compris `:official`) prennent également en charge `xhigh`, `max`. Le canal officiel est facturé selon l’utilisation réelle de Token             |
| `response_format` | `url` ou `b64_json`                                                                                                                     |
| `callback_url`    | Facultatif ; envoie les résultats à cette adresse une fois la tâche longue terminée                                                                                                                      |

Dimensions courantes :

| Ratio   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` sélectionne le format d’image selon les intentions de ratio, de pixels et de mise en page dans le prompt ; lorsqu’un nombre précis de pixels est nécessaire, indiquez directement les dimensions.

### Modèles et modes de facturation

| Modèle | Cas d’utilisation et mode de facturation |
| --- | --- |
| `gpt-image-2` | Canal inversé par défaut, facturation fixe par image générée avec succès |
| `gpt-image-2:reverse` | Sélection explicite du canal inversé, facturation fixe par image générée avec succès |
| `gpt-image-2:official` | Canal d’API officiel, plus stable, facturé selon l’utilisation réelle de jetons |
| `gpt-image-2.5-flare` | Privilégie la vitesse de génération, facturation fixe par image générée avec succès |
| `gpt-image-2.6-flare` | Privilégie la vitesse de génération, facturation fixe par image générée avec succès |
| `gpt-image-2.5-flare:reverse` | Alias inversé explicite, équivalent à `gpt-image-2.5-flare`, facturation fixe par image générée avec succès |
| `gpt-image-2.6-flare:reverse` | Alias inversé explicite, équivalent à `gpt-image-2.6-flare`, facturation fixe par image générée avec succès |
| `gpt-image-2.5-flare:official` | Canal API officiel, offrant une meilleure stabilité et privilégiant la vitesse de génération ; facturation selon l’utilisation réelle de jetons |
| `gpt-image-2.6-flare:official` | Canal API officiel, offrant une meilleure stabilité et privilégiant la vitesse de génération ; facturation selon l’utilisation réelle de jetons |
| `gpt-image-2.5-sunburst` | Privilégie la haute fidélité et le contrôle précis ; facturation fixe par image générée avec succès |
| `gpt-image-2.6-sunburst` | Privilégie la haute fidélité et le contrôle précis ; facturation fixe par image générée avec succès |
| `gpt-image-2.5-sunburst:reverse` | Alias inverse explicite, équivalent à `gpt-image-2.5-sunburst` ; facturation fixe par image générée avec succès |
| `gpt-image-2.6-sunburst:reverse` | Alias inverse explicite, équivalent à `gpt-image-2.6-sunburst` ; facturation fixe par image générée avec succès |
| `gpt-image-2.5-sunburst:official` | Canal API officiel, offrant une meilleure stabilité et privilégiant la haute fidélité et le contrôle précis ; facturation selon l’utilisation réelle de jetons |
| `gpt-image-2.6-sunburst:official` | Canal API officiel, offrant une meilleure stabilité et privilégiant la haute fidélité et le contrôle précis ; facturation selon l’utilisation réelle de jetons |

Le prix affiché pour le canal API officiel est une estimation avant la requête ; le montant final se base sur l’utilisation réelle de jetons et les enregistrements d’utilisation dans la réponse.

## 4. Génération de plusieurs images

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` et leurs alias `:reverse` sont facturés selon le nombre d’images réussies ; `gpt-image-2:official`, `gpt-image-2.5-flare:official` et `gpt-image-2.5-sunburst:official` sont facturés selon les Tokens réellement utilisés pour l’entrée texte et la sortie image dans la réponse. Le prix affiché sur la page est une estimation avant la requête ; le relevé d’utilisation final fait foi.

## 5. Rappel asynchrone

Après avoir ajouté `callback_url` au corps de la requête, l’interface renvoie d’abord `{"task_id": "..."}`, puis effectue un POST du résultat final vers cette URL une fois terminé ; les requêtes synchrones renvoient toujours `created` et `data` :

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Le récepteur du rappel doit utiliser `task_id` pour la déduplication, et vérifier l’origine de la requête ainsi que le format des données.

## 6. Dépannage

| Statut  | Vérifier                                                  |
| --- | --------------------------------------------------- |
| 400 | la combinaison de `model`, `prompt`, du format de taille, de `n` et de `response_format`    |
| 401 | si l’API Key est complète, et si le Header est `Authorization: Bearer ...` |
| 429 | les requêtes sont trop fréquentes, réessayez plus tard                                         |
| 504 | expiration de la génération synchrone ; utilisez plutôt `callback_url`                            |

Les réponses d’erreur contiennent `error.code`, `error.message` et `trace_id`. Lors du signalement d’un problème, fournissez le `trace_id`, mais ne fournissez pas l’API Key.

Les champs complets et les énumérations en temps réel font foi sur la page [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Pour l’édition d’images, consultez [Édition d’images GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 reprend les interfaces de génération, d’édition, de tâches asynchrones et de facturation de la version 2.5 :

| Modèle                                                          | Facturation                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/image                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/image                   |
| `gpt-image-2.6-flare:official`                              | Identique à 2.5 official, facturé selon l’utilisation réelle de Tokens |
| `gpt-image-2.6-sunburst:official`                           | Identique à 2.5 official, facturé selon l’utilisation réelle de Tokens |

Les qualités disponibles sont `auto`, `low`, `medium`, `high`, `xhigh`, `max` ; pour la taille, utilisez `auto` ou un `WIDTHxHEIGHT` conforme aux contraintes ci-dessus. Cette interface prend en charge `png`, `jpeg`, `webp` ; GPT Image 2.6 prend également en charge les GIF animés natifs, mais ne prend pas encore en charge SVG. L’édition prend en charge les URL d’images JSON et l’envoi de fichiers multipart. `:reverse` est un alias explicite de la version normale du même nom. Utilisez le nom de modèle complet, ne transmettez pas `gpt-image-2.6`.

### GIF animés GPT Image 2.6

Les versions normales, `:reverse` et `:official` de GPT Image 2.6 Flare et Sunburst peuvent toutes utiliser `output_format: "gif"`. Les images d’animation, les informations de boucle et la durée de lecture sont conservées ; `frame_count` représente le nombre d’images, `frame_duration_ms` représente le nombre de millisecondes par image, le nombre d’images doit être un entier de 2 à 16, la durée de chaque image doit être un entier de 20 à 655350 millisecondes, et ces paramètres sont réservés aux GIF ; l’encodage est arrondi au multiple de 10 ms le plus proche. Lorsqu’ils ne sont pas spécifiés, les valeurs par défaut sont 9 images et 200 millisecondes par image ; lorsque la taille du GIF est omise ou définie sur auto, le préréglage 512x512 est utilisé.

Il est recommandé d’utiliser d’abord `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. Les GIF ont des limites distinctes de taille et de nombre d’images, et les spécifications statiques 4K ne peuvent pas être appliquées directement ; certains modèles ajustent la taille réelle de sortie. `n` représente le nombre de fichiers GIF renvoyés, et non le nombre d’images de l’animation. Les versions normales et `:reverse` restent facturées selon le nombre de fichiers réussis, tandis que les versions officielles sont facturées selon l’utilisation réelle de Tokens.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Images statiques 4K GPT Image 2.6

Flare, Sunburst et leurs variantes `:reverse`, `:official` peuvent toutes utiliser les préréglages de pixels 4K susmentionnés, par exemple `3840x2160` et `2160x3840`. Pour la génération comme pour l’édition, transmettez les pixels spécifiques via `size` ; `4K` n’est pas une valeur `size` valide, et `4096x4096` dépasse également la limite actuelle de pixels. Les spécifications 4K ci-dessus s’appliquent aux PNG/JPEG/WebP statiques ; pour les GIF, utilisez leurs paramètres dédiés.

### Complexité de composition GPT Image 2.6

`complexity` peut être `low`, `medium` ou `high`, et utilise par défaut la valeur `high` du modèle lorsqu’il est omis. Il contrôle la complexité de planification, indépendamment de la qualité de rendu `quality` ; il n’entraîne pas de facturation supplémentaire par requête, et les versions officielles restent facturées selon les Tokens réellement utilisés. Les autres modèles ne prennent pas en charge ce paramètre.

Les GIF ne prennent pas en charge les masks, les images d’annotation, la compression personnalisée, la réécriture de prompt ou la sortie partiellement diffusée d’images ; les combinaisons incompatibles seront refusées avant la génération. La taille, le nombre d’images et la quantité sont conjointement soumis à la limite du budget de pixels du modèle ; `1024x1024` et 2 images ont été vérifiés comme fonctionnels pour Flare normal, mais cette conclusion ne peut pas être étendue à toutes les combinaisons 1K ou aux GIF 4K.
