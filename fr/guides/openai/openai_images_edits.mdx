## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Édition avec l'URL de l'image

Image originale :

![Édition de l'image originale GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer votre clé API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Conservez la tasse, la table, l'angle de la caméra, la mise en page portrait et l'ombre douce inchangés. Changez uniquement la couleur de la tasse du blanc à l'orange vif et l'arrière-plan crème pâle en bleu marine foncé uni. Pas de texte et pas de logo.",
    "size": "1024x1536"
  }'
```

Réponse réussie :

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Voici le résultat de l'édition réalisé le 8 septembre 2026 via Ace Data Cloud, la tasse est devenue orange, l'arrière-plan est devenu bleu marine foncé, tout en conservant la composition originale et la taille de 1024×1536 :

![Résultat de l'édition de la tasse orange GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Télécharger une image locale

Utilisez `multipart/form-data` :

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer votre clé API" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Remplacez l'arrière-plan par un studio moderne lumineux"
```

Vous pouvez transmettre plusieurs fois `image`, la série GPT Image prend en charge jusqu'à 16 images de référence. Dans la requête JSON, `image` peut être une seule URL ou un tableau d'URL ; les fichiers locaux sont téléchargés en multipart.

## 4. Paramètres courants

| Champ              | Description                                                    |
| ----------------- | ----------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` ou `gpt-image-2:reverse` |
| `image`           | JSON utilise une seule URL ou un tableau de jusqu'à 16 URL ; multipart utilise un ou plusieurs champs de fichier `image` |
| `prompt`          | Instructions d'édition                                        |
| `size`            | `auto` ou conforme aux limites `LARGEURxHAUTEUR`                  |
| `n`               | 1–10 ; uniquement 1 lorsque `response_format=b64_json`       |
| `response_format` | `url` ou `b64_json`                                        |
| `callback_url`    | Adresse de rappel asynchrone optionnelle                      |

Les règles de taille sont les mêmes que pour l'interface de génération : la largeur et la hauteur doivent être des multiples de 16, la longueur maximale ne doit pas dépasser 3840, et le nombre total de pixels ne doit pas dépasser 8 294 400. Si `size` est omis ou si `auto` est utilisé, le modèle choisira le format en fonction des instructions et de la première image de référence.

Le `gpt-image-2` par défaut et `:reverse` sont facturés en fonction du nombre de succès ; `gpt-image-2:official` est facturé en fonction des tokens d'entrée de texte, d'images de référence et de sortie d'images, le tout étant basé sur les enregistrements d'utilisation.

## 5. Rappel asynchrone et débogage

Pour les tâches longues, vous pouvez ajouter dans la requête :

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

La réponse asynchrone 200 est `{"task_id": "..."}` ; le résultat final sera rappelé après achèvement. Les requêtes synchrones renvoient alors `created` et `data`.

| État  | Vérification                  |
| --- | --------------------------- |
| 400 | Format/quantité d'image, combinaison de paramètres et format de taille |
| 401 | Clé API et en-tête Bearer   |
| 429 | Fréquence de requêtes        |
| 504 | Utilisez un rappel asynchrone |

Les réponses d'erreur contiendront `trace_id`. Lors de la signalisation d'un problème, fournissez cet ID, ne fournissez pas la clé API.

Les champs complets et l'énumération en temps réel sont disponibles sur la page [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Pour générer des images en texte brut, veuillez consulter [GPT Image 2 Génération d'images](https://platform.acedata.cloud/documents/openai-images-generations).
