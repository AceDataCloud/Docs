## 1. Obtenir une clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir une clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Éditer en utilisant l’URL d’une image

Image originale :

![Image originale pour l’édition GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Réponse réussie :

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Voici le résultat d’édition réellement finalisé via Ace Data Cloud le 8 septembre 2026 : la tasse est devenue orange, l’arrière-plan est devenu bleu marine foncé, tout en conservant la composition originale et la taille 1024×1536 :

![Résultat de l’édition de la tasse orange GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Téléverser une image locale

Utilisez `multipart/form-data` :

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Vous pouvez transmettre `image` de manière répétée ; la série GPT Image prend en charge jusqu’à 16 images de référence. Le champ `image` dans les requêtes JSON peut être une URL unique ou un tableau d’URL ; les fichiers locaux sont téléversés en multipart.

## 4. Paramètres courants

| Champ                | Description                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (plus rapide) ou `gpt-image-2.5-sunburst` (fidélité et contrôle plus élevés) ; les trois peuvent sélectionner la variante `:official` correspondante, et `gpt-image-2` prend également en charge `:reverse` |
| `image`           | JSON utilise une URL unique ou un tableau de jusqu’à 16 URL ; multipart utilise un ou plusieurs champs de fichier `image`                                                                    |
| `prompt`          | Instruction d’édition                                                                                                                             |
| `size`            | `auto` ou `WIDTHxHEIGHT` conforme aux limites                                                                                                     |
| `n`               | 1–10 ; seule la valeur 1 est prise en charge lorsque `response_format=b64_json`                                                                                           |
| `response_format` | `url` ou `b64_json`                                                                                                               |
| `callback_url`    | Adresse de rappel asynchrone facultative                                                                                                                         |

Les règles de taille sont les mêmes que pour l’interface de génération : la largeur et la hauteur doivent être des multiples de 16, le côté le plus long ne doit pas dépasser 3840, le nombre total de pixels doit être compris entre 655 360 et 8 294 400, et le ratio largeur/hauteur ne doit pas dépasser 3:1. Lorsque `size` est omis ou que `auto` est utilisé, le modèle choisit le format en fonction de l’invite et de la première image de référence.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` et `gpt-image-2:reverse` sont facturés selon le nombre d’images réussies ; `gpt-image-2:official`, `gpt-image-2.5-flare:official` et `gpt-image-2.5-sunburst:official` sont facturés selon les Tokens réels de l’entrée texte, de l’entrée des images de référence et de la sortie image ; les enregistrements d’utilisation finaux prévalent.

## 5. Rappel asynchrone et dépannage

Les tâches longues peuvent inclure ceci dans la requête :

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

La réponse asynchrone 200 est `{"task_id": "..."}` ; le résultat final est renvoyé par rappel une fois terminé. Les requêtes synchrones renvoient quant à elles `created` et `data`.

| Statut  | Vérifier                      |
| --- | ----------------------- |
| 400 | Le format/nombre d’images, la combinaison de paramètres et le format de taille       |
| 401 | La clé API et l’en-tête Bearer |
| 429 | La fréquence des requêtes                    |
| 504 | Utiliser un rappel asynchrone                  |

Les réponses d’erreur incluent `trace_id`. Fournissez cet ID lorsque vous signalez un problème, ne fournissez pas la clé API.

Pour les champs complets et les énumérations en temps réel, consultez la page [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Pour générer des images à partir de texte brut, consultez [Génération d’images GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
