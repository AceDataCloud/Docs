Le service de vecteurs de mots OpenAI est utilisé pour générer des résultats de vecteurs de mots représentant le texte d’entrée.

Ce document présente principalement le processus d’utilisation de l’API OpenAI Embeddings. Grâce à elle, nous pouvons créer des vecteurs d’intégration représentant le texte d’entrée.

## Processus de demande

Pour utiliser l’API OpenAI Embeddings, rendez-vous d’abord sur la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) pour obtenir votre API Token et le conserver en réserve.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous ne vous êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion afin de vous inviter à vous inscrire et à vous connecter ; une fois terminé, vous reviendrez automatiquement sur la page actuelle.

**Un seul API Token permet d’appeler tous les services de la plateforme, sans avoir besoin d’en demander un séparément pour chaque service.** La première demande offre un quota gratuit permettant une utilisation d’essai gratuite ; lorsque le quota est insuffisant, vous pouvez recharger le solde universel dans la [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Utilisation de base

Vous pouvez ensuite renseigner le contenu correspondant dans l’interface, comme indiqué sur l’image :

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Lors de la première utilisation de cette interface, nous devons remplir au moins trois éléments. Le premier est `authorization`, que vous pouvez sélectionner directement dans la liste déroulante. Un autre paramètre est `model` ; `model` correspond à la catégorie de modèle du site officiel d’OpenAI que nous choisissons d’utiliser. Les modèles actuellement disponibles sont `text-embedding-3-small` et `text-embedding-3-large`. `text-embedding-ada-002` n’est plus fourni ; si un index vectoriel existant utilise cet ancien modèle, les vecteurs des nouveaux modèles ne peuvent pas être mélangés directement avec lui et l’index doit être recréé. Le dernier paramètre est `input`, `input` étant le texte dont nous devons convertir les vecteurs de mots.

Vous pouvez également remarquer qu’un code d’appel correspondant est généré à droite ; vous pouvez copier le code et l’exécuter directement, ou cliquer directement sur le bouton « Try » pour effectuer un test.

Paramètres facultatifs :

- `dimensions` : tronque les dimensions du vecteur, la dimension complète est renvoyée par défaut.
- `encoding_format` : format de retour, `float` ou `base64` au choix.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Exemple de code d’appel Python :

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Le résultat renvoyé comporte plusieurs champs, présentés ci-dessous :

Parmi eux, `data` contient les informations spécifiques sur les vecteurs de mots correspondant au texte, et son `embedding` est le résultat concret des vecteurs de mots générés.

## Gestion des erreurs

Lors de l’appel de l’API, si une erreur survient, l’API renvoie le code et les informations d’erreur correspondants. Par exemple :

- `400 token_mismatched` : Mauvaise requête, possiblement en raison de paramètres manquants ou non valides.
- `400 api_not_implemented` : Mauvaise requête, possiblement en raison de paramètres manquants ou non valides.
- `401 invalid_token` : Non autorisé, token d’autorisation non valide ou manquant.
- `429 too_many_requests` : Trop de requêtes, vous avez dépassé la limite de débit.
- `500 api_error` : Erreur interne du serveur, un problème est survenu sur le serveur.

### Exemple de réponse d’erreur

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
