OpenAI ChatGPT est un système de dialogue IA très puissant qui, dès qu’on saisit un prompt, peut générer en quelques secondes une réponse fluide et naturelle. ChatGPT se distingue dans l’industrie par ses capacités exceptionnelles de compréhension et de génération de langage. Aujourd’hui, ChatGPT est largement utilisé dans divers secteurs et domaines, et son influence est de plus en plus marquée. Que ce soit pour des conversations quotidiennes, l’écriture créative, des consultations professionnelles ou la programmation, ChatGPT offre une assistance intelligente impressionnante, améliorant grandement l’efficacité et la créativité humaines.

Ce document présente principalement le processus d’utilisation de l’API OpenAI Chat Completion 4o Image, qui permet d’utiliser facilement la fonctionnalité de dialogue multimodal officielle d’OpenAI ChatGPT.

## Processus de demande

Pour utiliser l’API OpenAI Chat Completion 4o Image, vous pouvez d’abord vous rendre sur la page [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) et cliquer sur le bouton « Acquire » pour obtenir les identifiants nécessaires à la requête :

![](https://cdn.acedata.cloud/nyq0xz.png)

Si vous n’êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inscrire et vous connecter. Après connexion ou inscription, vous reviendrez automatiquement à cette page.

Lors de la première demande, un quota gratuit est offert, vous permettant d’utiliser cette API gratuitement.

## Modèle de dessin GPT-4o

### Génération d’image à partir d’une image de référence

Voici un exemple de génération d’une image personnalisée à partir d’une image, commençons par regarder l’image d’entrée, comme illustré ci-dessous :

![](https://cdn.acedata.cloud/qzx2z1.png)

On peut voir que l’image de référence est une photo d’une personne réelle. Nous pouvons la transformer en un style différent, par exemple en style anime. Voici un exemple de requête :

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "生成动漫风格的图片，并且带上个帽子"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

Exemple de résultat :

```json

  "object": "chat.completion",

    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "\n\n> 🎨 生成中...\n\n![https://pro.filesystem.site/cdn/20260609/0f7b6cf1b14843b1bab8e261fe5765b3.png](https://pro.filesystem.site/cdn/20260609/0f7b6cf1b14843b1bab8e261fe5765b3.png)\n\n[点击下载](https://pro.filesystem.site/cdn/download/20260609/0f7b6cf1b14843b1bab8e261fe5765b3.png)"
```

## Gestion des erreurs

Lors de l’appel de l’API, en cas d’erreur, l’API renvoie un code d’erreur et un message correspondant. Par exemple :

- `400 token_mismatched` : Requête incorrecte, probablement à cause de paramètres manquants ou invalides.
- `400 api_not_implemented` : Requête incorrecte, probablement à cause de paramètres manquants ou invalides.
- `401 invalid_token` : Non autorisé, jeton d’autorisation invalide ou manquant.
- `429 too_many_requests` : Trop de requêtes, vous avez dépassé la limite de fréquence.
- `500 api_error` : Erreur interne du serveur, un problème est survenu côté serveur.

### Exemple de réponse d’erreur

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
