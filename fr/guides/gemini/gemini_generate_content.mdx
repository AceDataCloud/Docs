Google Gemini est un système de conversation IA très puissant qui peut générer des réponses fluides et naturelles en quelques secondes grâce à des prompts saisis. Ce document décrit principalement comment utiliser l'API Gemini Generate Content, qui est le format d'API natif officiel de Google et prend en charge les deux points de terminaison `generateContent` et `streamGenerateContent`.

## Différences avec l'API Chat Completions

L'API Gemini Generate Content utilise le format de requête natif officiel de Google (champ `contents`), plutôt que le format compatible OpenAI (champ `messages`). Si vous utilisez déjà le SDK Google Gemini ou êtes familier avec le format officiel de l'API, vous pouvez utiliser directement cette API sans modifier le format de la requête.

## Portée actuellement prise en charge

L'interface accepte les entrées de texte, d'images, de vidéos et d'audio (`inlineData` ou `fileData`), les configurations de réflexion et les déclarations de fonctions personnalisées. La disponibilité unifiée des champs natifs tels que la sortie audio, les outils intégrés et la mise en cache explicite du contexte n'est pas encore garantie ; veuillez vous référer aux retours réels du modèle concerné.

Lors de la soumission de fichiers tels que des fichiers audio avec `fileData.fileUri`, veuillez vous assurer que le fichier est directement accessible via HTTPS, qu'il ne dépend pas d'un état de connexion, et que la période de validité du lien signé couvre l'ensemble du temps de traitement de la requête. L'analyse audio non diffusée ne renvoie des résultats qu'après que le modèle a terminé le traitement, ce qui peut dépasser 90 secondes ; le client doit définir un délai d'attente total suffisamment long selon la taille du fichier et le scénario métier, afin d'éviter de déconnecter la connexion alors que le serveur traite encore la requête.

## Processus de demande

Avant d'utiliser l'API Gemini Generate Content, veuillez d'abord visiter la page [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api), puis cliquer sur le bouton « Obtenir » pour obtenir les identifiants nécessaires à la requête.

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion. La première demande bénéficie d'un quota gratuit.

## Utilisation de base

### Non-Streaming (non diffusé)

Envoyez une requête POST vers `/v1beta/models/{model}:generateContent` :

> **Remarque** : la série `gemini-3.x` flash est constituée de modèles de réflexion, qui consomment d'abord des reasoning tokens ; veuillez définir `generationConfig.maxOutputTokens` à 512 ou plus, sinon seul un contenu vide peut être renvoyé.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

Exemple de résultat retourné :

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

Les champs token dans `usageMetadata` sont facturés selon la sémantique native de Gemini :

- `promptTokenCount` inclut `cachedContentTokenCount` ; la partie atteinte par le cache est calculée selon le prix de lecture du cache et ne sera pas comptabilisée à nouveau comme entrée ordinaire.
- `promptTokensDetails` et `cacheTokensDetails` seront normalisés sous `usage.prompt_tokens_details` en détails `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` et leurs détails `cached_*` correspondants. Ces valeurs sont incluses respectivement dans `prompt_tokens` et `cached_tokens` ; les différentes modalités ne sont recalculées qu'à leurs propres tarifs et ne sont pas facturées plusieurs fois.
- `candidatesTokenCount` et `thoughtsTokenCount` sont tous deux calculés selon le prix des tokens de sortie.
- `toolUsePromptTokenCount` correspond à des tokens d'entrée d'outil indépendants, calculés selon le prix des tokens d'entrée.

Ace Data Cloud renvoie en supplément l'objet normalisé `usage`, et les frais de cet appel sont lus de manière unifiée entre les protocoles de modèles depuis `usage.cost`. `cost` est un aperçu optionnel des frais ; lorsque l'aperçu des prix est temporairement indisponible, la réponse du modèle est tout de même renvoyée normalement, mais peut ne pas inclure ce champ. La facture finale est basée sur les enregistrements d'utilisation.

### Streaming (diffusé)

Envoyez une requête POST vers `/v1beta/models/{model}:streamGenerateContent?alt=sse` :

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

La réponse diffusée renvoie progressivement le contenu au format SSE (Server-Sent Events). Les événements intermédiaires ne contiennent généralement que du contenu incrémentiel ; l'événement final contenant les données d'utilisation faisant autorité inclut `usageMetadata` et `usage` normalisé, et les frais se trouvent toujours dans `usage.cost` :

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

La fermeture de la connexion indique la fin du flux ; le flux Gemini natif n'envoie pas `data: [DONE]`. Si l'aperçu des prix final est temporairement indisponible, `usage` renverra toujours l'utilisation des tokens, mais omettra `cost`.

| Nom du modèle                     | Description                                      |

| `gemini-3.1-flash-lite`  | Version stable d’un modèle léger                                 |
| `gemini-3.1-pro-preview` | Modèle de raisonnement complexe et de codage                               |

| `gemini-3.1-flash-image` | Modèle de génération d’images                                  |
| `gemini-3-pro-image`     | Modèle de génération d’images de haute qualité                               |
| `gemini-2.5-flash-image` | Modèle de génération d’images Gemini 2.5                       |

## Fonctionnalités avancées

### Instructions système

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "Bonjour"}]
    }
  ],
  "systemInstruction": {
    "parts": [{"text": "Tu es un poète professionnel, toutes les réponses doivent être sous forme de poésie."}]
  }
}
```

### Configuration de génération

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "Raconte une histoire"}]
    }
  ],
  "generationConfig": {
    "temperature": 0.7,
    "maxOutputTokens": 1024,
    "topP": 0.9,
    "topK": 40
  }
}
```

### Mode JSON

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "Liste trois villes chinoises et leur population"
        }
      ]
    }
  ],
  "generationConfig": {
    "responseMimeType": "application/json",
    "responseSchema": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "city": {
            "type": "string"
          },
          "population": {
            "type": "integer"
          }
        }
      }
    }
  }
}
```

### Mode réflexion (Thinking)

Les modèles prenant en charge la fonction de réflexion (comme gemini-2.5-flash et gemini-2.5-pro) peuvent activer le mode réflexion :

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "Explique l’intrication quantique"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true,
      "thinkingBudget": 2048
    }
  }
}
```

### Appel de fonction

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "Quel temps fait-il actuellement à Pékin ?"}]
    }
  ],
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "get_weather",
          "description": "Obtenir les informations météorologiques d’une ville spécifiée",
          "parameters": {
            "type": "object",
            "properties": {
              "city": {
                "type": "string",
                "description": "Nom de la ville"
              }
            },
            "required": ["city"]
          }
        }
      ]
    }
  ]
}
```

### Dialogue à plusieurs tours

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "Bonjour, je m’appelle Xiaoming"}]
    },
    {
      "role": "model",
      "parts": [{"text": "Bonjour Xiaoming ! Ravi de te rencontrer."}]
    },
    {
      "role": "user",
      "parts": [{"text": "Comment je m’appelle ?"}]
    }
  ]
}
```

### Compréhension d’images

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        {"text": "Décris cette image"},
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "base64_encoded_image_data..."
          }
        }
      ]
    }
  ]
}
```

## Paramètres de sécurité

Le filtrage du contenu peut être contrôlé via `safetySettings` :

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## Gestion des erreurs

| Code d’état HTTP | Signification             |
| -------- | -------------- |
| 400      | Paramètres de requête non valides         |
| 401      | Échec de l’authentification, veuillez vérifier le Token |
| 403      | Contenu bloqué par le filtre de sécurité     |
| 429      | Requêtes trop fréquentes         |
| 500      | Erreur interne du serveur        |
