Cet article présente les instructions d'intégration de l'API Gemini Videos Generation, qui permet de générer des vidéos Google Gemini (omni-flash) à partir de mots-clés textuels (et éventuellement d'images de référence).

## Processus de demande

Pour utiliser l'API, il faut d'abord faire une demande de service sur la page correspondante [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). Une fois sur la page, cliquez sur le bouton « Acquire », comme illustré ci-dessous :

![](https://cdn.acedata.cloud/q6ytrc.png)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inscrire et vous connecter. Après connexion, vous serez automatiquement ramené à cette page.

Lors de la première demande, un quota gratuit est offert, permettant d'utiliser l'API gratuitement.

## Utilisation de base

Commençons par la méthode d'utilisation de base : en saisissant le mot-clé `prompt`, le modèle `model` et le ratio d'aspect `aspect_ratio`, vous pouvez générer la vidéo correspondante.

Ici, nous configurons les en-têtes de la requête (Request Headers), comprenant :

- `accept` : le format de réponse souhaité, ici `application/json` pour un format JSON.
- `authorization` : la clé d'API pour appeler l'API, sélectionnable directement après la demande.

Le corps de la requête (Request Body) comprend :

- `prompt` : le texte décrivant le contenu vidéo à générer, **obligatoire**.
- `model` : le modèle de génération vidéo, actuellement seul `omni-flash` est supporté, c’est la valeur par défaut.
- `aspect_ratio` : le ratio d'aspect de la vidéo générée, options `16:9` (paysage) ou `9:16` (portrait), par défaut `16:9`.
- `image_urls` : tableau optionnel d’URL d’images (ou vidéos) de référence pour guider la génération, les entrées vides sont ignorées.
- `callback_url` : URL de rappel asynchrone, si définie, l’API retourne immédiatement un `task_id` et POST le résultat final à cette URL une fois la tâche terminée.

Cliquez sur le bouton « Try » pour tester, le résultat obtenu est similaire à ceci :

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Les champs de la réponse sont décrits comme suit :

- `success` : indique si la requête de génération vidéo a réussi.
- `task_id` : identifiant de la tâche de génération vidéo.
- `trace_id` : identifiant de suivi de la requête, utile pour le débogage.
- `data` : liste des résultats vidéo générés.
  - `id` : identifiant unique de la vidéo générée.
  - `video_url` : URL de la vidéo générée.
  - `state` : état de la tâche de génération vidéo, valeurs possibles : `pending` / `succeeded` / `failed`.

Il suffit de récupérer la vidéo via l’URL `video_url` dans `data`.

Le code CURL correspondant est :

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Le code Python correspondant est :

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Génération vidéo à partir d’images

Pour générer une vidéo basée sur des images de référence, vous pouvez passer une ou plusieurs URL d’images dans `image_urls` pour guider la génération vidéo :

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Rappel asynchrone (callback)

La génération vidéo nécessite un certain temps de traitement. Si vous ne souhaitez pas maintenir une connexion longue, vous pouvez fournir un `callback_url`. L’API retournera immédiatement un `task_id` et POSTera le résultat final à cette URL une fois la tâche terminée :

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

La réponse immédiate est :

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultation du résultat de la tâche

Si vous utilisez un rappel asynchrone ou souhaitez interroger l’état de la tâche, vous pouvez utiliser l’[API Gemini Tasks](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) pour obtenir le dernier état et résultat via le `task_id`.

## Gestion des erreurs

En cas de problème, l’API retourne un code d’erreur et une description. Les erreurs courantes sont :

- `400` : paramètres de requête incorrects, par exemple absence de `prompt` ou valeur invalide pour `aspect_ratio`.
- `401` : échec d’authentification, token invalide ou non compatible avec l’API.
- `403` : solde insuffisant ou refus dû à un contrôle de contenu sur le prompt.
- `500` : erreur interne serveur ou échec de génération en amont.
