Cet article présentera les instructions d'intégration de l'API de génération de vidéos Gemini, qui peut générer des vidéos Google Gemini (omni-flash) en entrant des mots-clés textuels (et des images de référence optionnelles).

## Processus de demande

Pour utiliser l'API de génération de vidéos Gemini, commencez par obtenir votre jeton API sur le [tableau de bord Ace Data Cloud](https://platform.acedata.cloud/console/applications) et conservez-le en lieu sûr.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter, après quoi vous serez automatiquement renvoyé à la page actuelle.

**Un jeton API suffit pour appeler tous les services de la plateforme, sans avoir besoin de demander séparément pour chaque service.** La première demande vous donnera un quota gratuit pour une expérience sans frais ; lorsque le quota est insuffisant, vous pouvez recharger le solde général dans le [tableau de bord](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [API de génération de vidéos Gemini →](https://platform.acedata.cloud/documents/gemini-videos)

## Utilisation de base

Commencez par comprendre les méthodes d'utilisation de base, en entrant les mots-clés `prompt`, le modèle `model` et le rapport d'aspect `aspect_ratio`, vous pourrez générer la vidéo correspondante.

Ici, nous avons défini les en-têtes de requête, y compris :

- `accept` : le format de réponse souhaité, ici rempli avec `application/json`, c'est-à-dire au format JSON.
- `authorization` : la clé pour appeler l'API, que vous pouvez sélectionner directement après la demande.

Nous avons également défini le corps de la requête, y compris :

- `prompt` : le texte décrivant le contenu vidéo souhaité, **obligatoire**.
- `model` : le modèle de génération vidéo, actuellement uniquement `omni-flash`, par défaut `omni-flash`.
- `aspect_ratio` : le rapport d'aspect de la vidéo générée, optionnel `16:9` (paysage) ou `9:16` (portrait), par défaut `16:9`.
- `resolution` : la résolution de sortie optionnelle, pouvant être `720p` ou `1080p`, par défaut `720p`.
- `image_urls` : un tableau de liens d'images de référence optionnelles, utilisé pour guider la génération de vidéos, les champs vides seront ignorés. Lors de l'utilisation de `video_urls` pour l'édition vidéo, ce paramètre est obligatoire (au moins une image).
- `video_urls` : un tableau de liens de vidéos de référence optionnelles (maximum 1), utilisé pour **l'édition vidéo / vidéo de référence** ; s'il est fourni, au moins une `image_urls` doit également être fournie.
- `callback_url` : adresse de rappel asynchrone, une fois définie, l'API renverra immédiatement `task_id`, et lorsque la tâche sera terminée, le résultat sera POSTé à cette adresse.
- `async` : optionnel, si défini sur `true`, l'interface renvoie immédiatement `task_id`, sans avoir besoin de fournir `callback_url`, puis vous pouvez interroger le résultat via l'interface de requête de tâche correspondante.

Cliquez sur le bouton « Essayer » pour effectuer un test, le résultat obtenu ressemblera à ceci :

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Le résultat de retour contient plusieurs champs, décrits comme suit :

- `success` : indique si la demande de génération de vidéo a réussi.
- `task_id` : l'ID de la tâche de génération de vidéo.
- `trace_id` : l'ID de suivi de cette demande, utilisé pour le dépannage.
- `data` : liste des résultats vidéo générés.
  - `id` : identifiant unique de la vidéo générée.
  - `video_url` : l'adresse du lien de la vidéo générée (`state` est `pending`, alors c'est `null`).
  - `state` : l'état de la tâche de génération vidéo, pouvant être `pending` / `succeeded` / `failed`.
  - `aspect_ratio` : le rapport d'aspect de la vidéo, identique au paramètre de demande.
  - `prompt` : les mots-clés utilisés pour générer cette vidéo.

Lors d'un retour synchronisé, le niveau supérieur inclura également `started_at`, `finished_at`, `elapsed` (temps écoulé, en secondes) et `cost` (frais de cette demande, en crédits).

Nous devons simplement récupérer la vidéo générée à partir de l'adresse du lien `video_url` dans le résultat `data`.

Le code CURL correspondant est le suivant :

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Le code Python correspondant est le suivant :

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Génération de vidéos à partir d'images

Si vous souhaitez générer une vidéo basée sur des images de référence, vous pouvez transmettre un ou plusieurs liens d'images dans `image_urls`, utilisés pour guider la génération de vidéos :

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Édition vidéo / vidéo de référence (vidéo d'entrée, génération de vidéo)

Il est possible de « saisir une vidéo et de générer une nouvelle vidéo » : dans `video_urls`, transmettez un lien de vidéo de référence (maximum 1), et **en même temps** fournissez au moins une image de référence dans `image_urls` (exigence stricte en amont), puis utilisez `prompt` pour décrire l'effet d'édition souhaité (changement de style, changement de scène, ajout ou suppression d'éléments, etc.).

Voici un exemple complet et réel — transformer une vidéo de plage ensoleillée en une scène d'hiver avec de la neige, tout en conservant la disposition de la plage, des palmiers et du petit bateau. L'édition vidéo prend plus de temps (dans cet exemple environ 6,5 minutes), donc soumettez-la de manière asynchrone avec `async: true` :
```json
{
  "prompt": "Transformez cette plage tropicale ensoleillée en une scène hivernale enneigée avec de fortes chutes de neige et un ciel couvert ; gardez la même plage, les palmiers et la disposition des bateaux.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Soumettez et l'interface renvoie immédiatement `task_id` :

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Ensuite, utilisez ce `task_id` comme `id` pour interroger [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), une fois la tâche terminée, vous pourrez obtenir la nouvelle vidéo générée (c'est le résultat réel de cet exemple) :

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Transformez cette plage tropicale ensoleillée en une scène hivernale enneigée avec de fortes chutes de neige et un ciel couvert ; gardez la même plage, les palmiers et la disposition des bateaux."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Pour des résultats de meilleure qualité, vous pouvez définir `resolution` sur `1080p` (les autres paramètres restent inchangés).

> Remarque : Les liens médias d'entrée / sortie dans l'exemple sont des résultats générés réels. **Les liens vidéo et image générés par la plateforme ont une durée de conservation, ils expireront après un certain temps**, veuillez les télécharger et les sauvegarder dans votre propre stockage dès que vous obtenez les résultats.

> Attention : Un maximum de 1 vidéo de référence ; et lorsque `video_urls` est fourni, au moins une `image_urls` doit également être fournie, sinon une erreur de paramètre sera renvoyée comme suit :

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (au moins une image de référence) est requise lorsque video_urls est fourni."
  }
}
```

## Rappel asynchrone

La génération de vidéos nécessite un certain temps de traitement. Si vous ne souhaitez pas maintenir une connexion longue en attendant, vous pouvez transmettre `callback_url`, dans ce cas, l'API renverra immédiatement `task_id`, et une fois la tâche terminée, elle enverra le résultat final par POST à cette adresse :

```json
{
  "prompt": "Une prise de vue cinématographique d'un chaton poursuivant un papillon dans un jardin ensoleillé",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Le résultat renvoyé immédiatement est le suivant :

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Vérification des résultats de la tâche

Si vous avez utilisé un rappel asynchrone ou si vous souhaitez interroger activement l'état de la tâche, vous pouvez le faire via [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) en utilisant `task_id` pour interroger l'état et les résultats les plus récents de la tâche. Dans le corps de la requête, transmettez le `task_id` renvoyé lors de la création de la vidéo comme `id` :

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Le résultat renvoyé une fois la tâche terminée est similaire à ce qui suit, la structure de `response.data` est identique à celle lors de la génération synchronisée (lors de la génération, `state` est `pending`, `video_url` est `null`) :

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Un time-lapse de nuages au-dessus des montagnes enneigées au lever du soleil",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Un time-lapse de nuages au-dessus des montagnes enneigées au lever du soleil"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Gestion des erreurs

Lorsque la demande pose problème, l'API renvoie le code d'erreur et l'explication correspondants, les plus courants sont les suivants :

- `400` : Les paramètres de la demande sont incorrects, par exemple, `prompt` ou `aspect_ratio` manquants ou illégaux.
- `401` : Échec de l'authentification, le token est invalide ou ne correspond pas à l'API.
- `403` : Solde insuffisant, ou le mot-clé a été refusé par la modération de contenu.
- `500` : Erreur interne du serveur ou échec de génération en amont.
