Cette interface est basée sur l'[API officielle Fish Audio Model](https://docs.fish.audio/resources/api-reference/model) et est utilisée pour **récupérer de manière paginée la bibliothèque publique de voix Fish ou les voix clonées sous le compte actuel**. L'adresse est `GET https://api.acedata.cloud/fish/model`.

> Pour créer une voix, veuillez consulter [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model) ; pour interroger les détails d'une seule voix par `_id`, veuillez consulter [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Processus de demande

Pour utiliser l'API Fish Model, allez d'abord dans la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) pour obtenir votre API Token et le conserver pour une utilisation ultérieure.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion qui vous invitera à vous inscrire et à vous connecter ; une fois terminé, vous reviendrez automatiquement à la page actuelle.

**Un seul API Token permet d'appeler tous les services de la plateforme, sans devoir en demander un séparément pour chaque service.** La première demande offre un quota gratuit, permettant une expérience gratuite ; lorsque le quota est insuffisant, vous pouvez recharger le solde universel dans la [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Paramètres de requête

| Paramètre             | Type    | Par défaut | Description                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | Nombre d’éléments par page.                                                                            |
| `page_number`    | integer | 1    | Numéro de page, à partir de 1.                                                                          |
| `title`          | string  | —    | Recherche approximative par titre.                                                                      |
| `tag`            | string  | —    | Filtrer par une seule étiquette.                                                                      |
| `self`           | boolean | —    | Lorsque `true` est utilisé, renvoie uniquement les voix créées et enregistrées sur cette plateforme par le compte appelant actuel.                                |
| `author_id`      | string  | —    | Filtrer par ID d’auteur de la voix.                                                                  |
| `language`       | string  | —    | Filtrer par langue de la voix, par exemple `en`, `zh`, `es`.                                                  |
| `title_language` | string  | —    | Filtrer par langue du titre dans la bibliothèque publique de voix.                                                        |
| `sort_by`        | string  | —    | Champ de tri ; lorsque `self=true` est utilisé, `created_at` et `task_count` sont pris en charge.                              |

## Exemple 2 : recherche floue par titre (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

## Exemple 3 : lister uniquement les voix créées par soi-même (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Exemple de retour :

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false

```
`self=true` répertorie les voix créées et enregistrées via cette plateforme selon le compte appelant réel ; les voix créées par le même compte avec différents API Token seront également répertoriées ensemble. Les résultats sont paginés par ordre décroissant de date de création, et `author_id` peut filtrer davantage l’ID de l’auteur de ces voix. Ce paramètre filtre uniquement la liste, les voix restent publiquement disponibles.

`self=true` ne prend pas en charge `title_language` ; si vous devez rechercher par langue du titre, veuillez interroger la bibliothèque publique de voix.

## Exemple 4 : filtrer par langue + étiquette

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> La correspondance avec `tag` est plus souple ; si le nombre de résultats est égal à 0, il est recommandé d’utiliser la correspondance approximative `title`.

## Champs de réponse

Chaque élément dans `items[]` est un objet ModelEntity complet, champs couramment utilisés :

| Champ            | Type       | Description                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID de la voix, utilisé comme valeur de `reference_id` dans `/fish/tts`. |
| `type`        | string   | Type de modèle, généralement `tts`.                           |
| `title`       | string   | Nom de la voix.                                     |
| `description` | string   | Description de la voix.                                     |
| `state`       | string   | État de l’entraînement : `trained` indique qu’elle est disponible.                      |
| `tags`        | string[] | Étiquettes de la bibliothèque publique.                                    |
| `languages`   | string[] | Langues dans lesquelles la voix excelle.                                  |
| `visibility`  | string   | `public` ou `private`.                     |
| `samples`     | object[] | Échantillons prédéfinis (incluant un lien direct `audio`).                       |
| `like_count`  | integer  | Nombre de mentions J’aime dans la bibliothèque publique.                                   |
| `task_count`  | integer  | Nombre de synthèses historiques.                                   |
| `author`      | object   | Informations sur l’auteur de la voix : `_id` / `nickname` / `avatar`.     |
| `total`（niveau supérieur）   | integer  | Nombre total d’éléments répondant aux conditions.                                 |
| `has_more`    | boolean? | Valeur booléenne lorsque `self=true` ; les requêtes de la bibliothèque publique de voix peuvent être `null`.      |

## Informations de facturation

Cette interface n’est pas facturée — la requête paginée de la liste des voix est une opération gratuite. La création de voix ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) est également gratuite, les frais sont générés uniquement selon l’utilisation lors de l’appel à [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) pour synthétiser de la parole.

## Gestion des erreurs

- `400 token_mismatched` : paramètres de requête manquants ou non valides.
- `401 invalid_token` : le token d’authentification n’existe pas ou n’est pas valide.
- `429 too_many_requests` : limite de débit du compte déclenchée.
- `500 api_error` : erreur interne du serveur.

Exemple de réponse d’erreur :

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusion

Pour sélectionner une voix depuis la bibliothèque publique Fish afin de l’utiliser comme `reference_id` de `/fish/tts`, utilisez d’abord cette interface avec `title` / `tag` / `language` pour effectuer une recherche, localisez le `_id` cible, puis utilisez [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) pour obtenir des échantillons et les écouter. Pour répertorier les voix que vous avez créées, il suffit de transmettre `self=true`.
