Cette interface est basée sur [Fish Audio Official Model API](https://docs.fish.audio/resources/api-reference/model) et est utilisée pour **rechercher par pagination dans la bibliothèque de voix publiques de Fish ou les voix clonées sous le compte actuel**. L'adresse est `GET https://api.acedata.cloud/fish/model`.

> Pour créer une voix, veuillez consulter [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model) ; pour interroger les détails d'une voix unique par `_id`, veuillez consulter [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Processus de demande

Pour utiliser l'API Fish Model, commencez par obtenir votre API Token sur [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) pour le garder en réserve.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter, après quoi vous serez automatiquement renvoyé à la page actuelle.

**Un API Token suffit pour appeler tous les services de la plateforme, il n'est pas nécessaire de demander un pour chaque service.** La première demande vous donnera un quota gratuit pour une expérience sans frais ; lorsque le quota est insuffisant, vous pouvez recharger le solde général dans la [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Paramètres de requête

| Paramètre         | Type     | Par défaut | Description                                 |
| ----------------- | -------- | ---------- | ------------------------------------------- |
| `page_size`       | integer  | 10         | Nombre d'éléments par page.                |
| `page_number`     | integer  | 1          | Numéro de page à partir de 1.              |
| `title`           | string   | —          | Recherche floue par titre.                  |
| `tag`             | string   | —          | Filtrer par un seul tag.                    |
| `self`            | boolean  | —          | Si `true`, retourne uniquement les voix créées par le compte actuel, sans conditions supplémentaires. |
| `author_id`       | string   | —          | Filtrer par l'`_id` de l'utilisateur en amont. |
| `language`        | string   | —          | Filtrer par langue de la voix, comme `en`, `zh`, `es`. |
| `title_language`  | string   | —          | Filtrer par langue du titre.                |
| `sort_by`         | string   | —          | Champ de tri, identique à l'amont, comme `created_at`, `task_count`. |

> La nomenclature des paramètres est identique à celle de l'amont `GET https://api.fish.audio/model`, voir [Documentation officielle de Fish](https://docs.fish.audio/resources/api-reference/model).

## Exemple 1 : Pagination par défaut (par `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Exemple 2 : Recherche floue par titre (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Retour (testé) :

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",

      "languages": ["en"],
      "visibility": "public",

    },
    {
```

Notez que `title` est un « match flou global », qui touchera toutes les voix de la bibliothèque publique de Fish (pas seulement les vôtres).

## Exemple 3 : Lister uniquement les voix créées par soi-même (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Retour (testé, il n'y a qu'une seule voix sous le compte actuel) :

## Exemple 4 : Filtrer par langue + tag
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> L'interface en amont renverra également des résultats pour les `tag` qui ne figurent pas dans le dictionnaire des étiquettes, mais la correspondance sera relativement lâche ; si le nombre de correspondances est de 0, il est conseillé d'utiliser un `title` en correspondance floue.

## Champs de réponse

Chaque élément dans `items[]` est un objet ModelEntity complet, champs couramment utilisés :

| Champ          | Type     | Description                                          |
| ------------- | -------- | -------------------------------------------------- |
| `_id`         | string   | ID de la voix, utilisé comme valeur de `reference_id` dans `/fish/tts`. |
| `type`        | string   | Type de modèle, généralement `tts`.                |
| `title`       | string   | Nom de la voix.                                    |
| `description` | string   | Description de la voix.                            |
| `state`       | string   | État d'entraînement : `trained` signifie disponible. |
| `tags`        | string[] | Étiquettes de la bibliothèque publique.            |
| `languages`   | string[] | Langues maîtrisées par la voix.                    |
| `visibility`  | string   | `public` ou `private`.                             |
| `samples`     | object[] | Échantillons préenregistrés (incluant des liens directs `audio`). |
| `like_count`  | integer  | Nombre de likes dans la bibliothèque publique.     |
| `task_count`  | integer  | Nombre total de synthèses historiques.             |
| `author`      | object   | Informations sur l'auteur en amont : `_id` / `nickname` / `avatar`. |
| `total` (niveau supérieur) | integer  | Nombre total d'éléments satisfaisant les conditions. |
| `has_more`    | boolean? | Indication de pagination en amont, peut être `null`. Il est conseillé de calculer le nombre total de pages avec `total / page_size`. |

## Informations de facturation

Cette interface n'entraîne pas de frais - la requête de liste des voix par pagination est gratuite. La création de voix ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) est également gratuite, des frais ne sont appliqués que lors de l'appel à [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) pour la synthèse vocale en fonction de l'utilisation.

## Gestion des erreurs

- `400 token_mismatched` : Paramètres de requête manquants ou non valides.
- `401 invalid_token` : Le token d'authentification n'existe pas ou est invalide.
- `429 too_many_requests` : Limite de taux de compte atteinte.
- `500 api_error` : Erreur interne du serveur.

Exemple de réponse d'erreur :

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusion

Pour sélectionner une voix dans la bibliothèque publique Fish à fournir à `/fish/tts` comme `reference_id`, utilisez d'abord cette interface avec `title` / `tag` / `language` pour rechercher, localisez l'`_id` cible, puis utilisez [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) pour obtenir des échantillons à écouter. Pour lister les voix que vous avez créées, il suffit de passer `self=true`.
