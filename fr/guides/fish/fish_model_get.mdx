Cette interface est basée sur [Fish Audio Official Model API](https://docs.fish.audio/resources/api-reference/model) et est utilisée pour **interroger les détails complets d'un clone de voix par `_id`**. L'adresse est `GET https://api.acedata.cloud/fish/model/{id}`.

> Pour créer une voix, veuillez consulter [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model) ; pour la recherche paginée, veuillez consulter [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Processus de demande

Pour utiliser l'API Fish Model, commencez par obtenir votre API Token sur [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) pour le garder en réserve.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter, après quoi vous serez automatiquement renvoyé à la page actuelle.

**Un API Token suffit pour appeler tous les services de la plateforme, il n'est pas nécessaire de demander séparément pour chaque service.** La première demande vous donnera un quota gratuit pour une expérience sans frais ; lorsque le quota est insuffisant, vous pouvez recharger le solde général dans la [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Paramètres de chemin

| Paramètre | Obligatoire | Description                                                                                                                                                                                                |
| --------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`      | Oui         | `_id` de la voix (chaîne hexadécimale de 32 caractères). Peut être obtenu lors de la création via [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) ou récupéré via [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Pas de corps de requête, pas de paramètres de requête.

  -H 'authorization: Bearer {token}'

L'`_id` obtenu peut être directement utilisé comme `reference_id` dans [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) pour synthétiser une voix identique :

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Différences avec l'interface de liste

| Champ                                               | `GET /fish/model` (liste) | `GET /fish/model/{id}` (détails) |
| -------------------------------------------------- | -------------------------- | --------------------------------- |
| `samples[].audio`                                  | URL de cache R2 à court terme | Lien direct R2 signé (avec signature de requête) |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Existe également            | Existe également                   |
| `default_text` / `lock_visibility`                 | Existe également            | Existe également                   |

Si vous souhaitez simplement écouter, le `samples[].audio` de l'interface de liste est suffisant ; pour un lien de téléchargement plus stable, il est recommandé d'utiliser cette interface.

## Champs de réponse (extraits)

| Champ           | Type     | Description                                      |
| --------------- | -------- | ------------------------------------------------ |
| `_id`          | string   | ID de la voix (utilisé pour `reference_id` de `/fish/tts`). |
| `type`         | string   | Type de modèle, généralement `tts`.              |
| `title`        | string   | Nom de la voix.                                  |
| `description`  | string   | Description longue.                              |
| `state`        | string   | État d'entraînement : `trained` signifie disponible, `training` signifie en cours d'entraînement. |
| `tags`         | string[] | Étiquettes de la bibliothèque publique.          |
| `samples`      | object[] | Échantillons prédéfinis, contenant `title`, `text`, `task_id`, `audio` lien direct. |
| `languages`    | string[] | Codes de langues dans lesquelles la voix excelle. |
| `visibility`   | string   | `public` ou `private`.                           |
| `like_count`   | integer  | Nombre de likes dans la bibliothèque publique.   |
| `task_count`   | integer  | Nombre total de synthèses historiques (peut être utilisé pour le tri par popularité). |
| `author`       | object   | Informations sur l'auteur : `_id` / `nickname` / `avatar`. |
| `created_at`   | string   | Date de création au format ISO 8601.            |
| `updated_at`   | string   | Date de dernière mise à jour au format ISO 8601. |

## Informations de facturation

Cette interface n'entraîne pas de frais - interroger les détails d'une voix par ID est une opération gratuite. La création de voix ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) est également gratuite, les frais ne sont générés que lors de l'appel de [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) pour synthétiser la voix.

## Gestion des erreurs
- `400 token_mismatched` : L'`id` dans le chemin n'est pas au format valide, ou l'amont renvoie « Modèle non trouvé ».
- `401 invalid_token` : Le token d'authentification n'existe pas ou est invalide.
- `404 not_found` : Le `_id` spécifié n'est pas visible en amont sur Fish (le timbre a été supprimé, est privé, ou appartient à un autre compte).
- `429 too_many_requests` : Limite de taux déclenchée pour le compte.
- `500 api_error` : Erreur interne du serveur.

Lorsqu'une demande est faite pour un ID inexistant, l'amont renvoie directement `400 Model not found` (testé) :

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Retour :

```json
{ "status": 400, "message": "Model not found" }
```

Exemple de réponse d'erreur :

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusion

Lorsque vous connaissez le `_id` du timbre, utilisez directement cette interface pour obtenir le ModelEntity complet, les usages les plus courants sont : (1) écouter `samples[].audio`, (2) fournir le `_id` à `reference_id` de `/fish/tts` pour compléter la synthèse. Si vous n'avez que le titre ou les étiquettes, veuillez d'abord utiliser [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) pour effectuer une recherche.
