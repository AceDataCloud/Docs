Cette API est basée sur l’[API Model officielle de Fish Audio](https://docs.fish.audio/resources/api-reference/model) et permet de **créer un modèle de voix clonée réutilisable à long terme à partir d’un échantillon audio**. L’adresse est `POST https://api.acedata.cloud/fish/model`.

> Lorsqu’il suffit d’utiliser temporairement une voix de référence, il n’est pas nécessaire de créer un modèle : vous pouvez utiliser directement le clonage instantané ponctuel `references` de l’[API Fish TTS](https://platform.acedata.cloud/documents/fish-tts). Pour rechercher de manière paginée des voix existantes, veuillez consulter l’[API Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) ; pour rechercher les détails d’une seule voix par `_id`, veuillez consulter l’[API Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get).

## Processus de demande

Pour utiliser l’API Fish Model, obtenez d’abord votre API Token depuis la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications), et conservez-le pour une utilisation ultérieure.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n’êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion afin de vous inviter à vous inscrire et à vous connecter ; une fois terminé, vous reviendrez automatiquement sur la page actuelle.

**Un seul API Token permet d’appeler tous les services de la plateforme ; il n’est pas nécessaire d’en demander un séparément pour chaque service.** La première demande offre un quota gratuit permettant de tester gratuitement ; lorsque le quota est insuffisant, vous pouvez recharger votre solde commun dans la [console](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Champs du corps de la requête

| Champ                      | Type       | Obligatoire  | Description                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Oui   | Nom de la voix, utilisé pour l’identifier dans la liste de la console.                                                             |
| `voices`                | string   | Oui   | URL HTTP(S) de l’échantillon audio (**une seule chaîne de caractères**, et non un tableau). Cette API ne prend pas en charge l’envoi multipart/binaire ; placez d’abord l’audio dans n’importe quel stockage d’objets accessible publiquement. |
| `description`           | string   | Non   | Description de la voix.                                                                         |
| `cover_image`           | string   | Non   | URL HTTP(S) de l’image de couverture.                                                              |
| `tags`                  | string[] | Non   | Étiquettes de recherche de la bibliothèque publique, par exemple `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Non   | Textes de référence correspondant aux échantillons (utilisés pour corriger la prononciation).                                                           |
| `enhance_audio_quality` | boolean  | Non   | Indique s’il faut améliorer la qualité audio de l’échantillon avant l’entraînement.                                                                |
| `generate_sample`       | boolean  | Non   | Indique s’il faut générer automatiquement un extrait audio après la fin de l’entraînement.                                                            |

> Pour plus d’informations sur les modèles de voix, consultez la [documentation officielle de Fish](https://docs.fish.audio/resources/api-reference/model).

> Les voix créées seront enregistrées publiquement à long terme, et d’autres utilisateurs pourront les rechercher et les utiliser. Il n’est pas nécessaire de transmettre `visibility` ; même si `private` ou `unlist` est transmis, l’API actuelle ne modifiera pas la portée publique en conséquence.

## Exemple : créer une voix clonée publique

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Remarque : `voices` doit être une **chaîne de caractères** (une seule URL audio), et non un tableau. La transmission de `["..."]` n’est pas prise en charge. Il est recommandé d’utiliser un lien direct publiquement téléchargeable avec le suffixe `.mp3` ou `.wav`.

Une réponse réussie renvoie directement l’objet ModelEntity de la plateforme Fish (l’exemple ci-dessous correspond à la voix minimale fonctionnelle que nous avons testée ; certains champs longs ont été supprimés pour faciliter la lecture) :

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Exigences relatives aux échantillons

Recommandations (voir la [documentation officielle de Fish](https://docs.fish.audio/resources/api-reference/model)) :

- Une durée de plus de 30 secondes est recommandée, avec des résultats optimaux en dessous de 5 minutes ; au-delà de 10 minutes, le gain marginal est faible.
- Une fréquence d’échantillonnage de 16 kHz ou plus, en mono ou en stéréo.
- Le contenu doit être aussi propre que possible : sans musique de fond, écho ni bruit ambiant notable ; un seul et même locuteur.
- Formats recommandés : `mp3` / `wav`.

Si vous n’êtes pas sûr de la qualité de l’échantillon, vous pouvez également transmettre `enhance_audio_quality: true` pour activer l’amélioration de la qualité audio.

## Informations de tarification
La création d’un modèle de clonage vocal (`POST /fish/model`) est gratuite, sans aucun frais ; les interfaces de requête de voix ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) ne sont également pas facturées. Les frais ne sont générés qu’en fonction de l’utilisation lors de l’appel ultérieur de [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) pour synthétiser la voix.

## Gestion des erreurs

- `400 token_mismatched` : paramètres de requête manquants ou non valides (le cas le plus fréquent est que `voices` n’est pas une URL, ou qu’il a été transmis sous forme de tableau).
- `400` : lorsque l’audio de référence ne peut pas être téléchargé, que sa durée est trop courte ou que son format ne peut pas être reconnu, veuillez vérifier l’URL audio et le format du fichier.
- `401 invalid_token` : le token d’authentification n’existe pas ou n’est pas valide.
- `429 too_many_requests` : la limite de débit du compte a été déclenchée.
- `500 api_error` : erreur interne du serveur.

Exemple de réponse d’erreur :

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Conclusion

Pour appeler cette interface, il suffit de préparer une URL d’audio d’exemple accessible publiquement, de la placer dans le champ `voices` afin d’obtenir `_id`, puis de la transmettre à `reference_id` de `/fish/tts` pour réaliser le processus de bout en bout « clonage → synthèse ». Le piège courant est que `voices` doit être une chaîne de caractères et ne peut pas être un tableau.

## Créer et réutiliser une voix via MCP

Appelez dans Fish MCP
`fish_create_model(title="Ma voix", voices="https://example.com/authorized-voice.wav")`.
`voices` est une unique URL audio HTTP(S) ; vous pouvez également transmettre `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`.

Cet outil conserve durablement les voix publiques ; d’autres utilisateurs peuvent les découvrir et les utiliser ; veuillez n’utiliser que des
ressources audio dont le traitement et la publication sont autorisés. L’outil ne propose aucune option privée ou non publique. Le `_id` renvoyé après la création réussie est utilisé pour
`reference_id` de `fish_generate_audio`, et `fish_list_models(self=true)` permet de consulter les voix
que vous avez enregistrées. Lorsqu’une voix de référence n’est nécessaire qu’une seule fois, utilisez `references` de `fish_generate_audio`,
sans créer de voix durable.
