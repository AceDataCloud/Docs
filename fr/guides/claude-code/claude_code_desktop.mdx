Claude Code est un outil de **codage agentique** lancé par Anthropic, également connu comme l'un des agents de programmation les plus puissants au monde. L'application de bureau Claude Code offre une interface graphique autonome, prenant en charge des fonctionnalités telles que la révision Diff, les sessions parallèles (isolées par Git Worktree), les sessions à distance, etc., sans dépendre d'aucun IDE.

Ce document présente principalement comment configurer et utiliser l'application de bureau Claude Code via le service proxy d'AceData Cloud.

> **Remarque** : L'application de bureau Claude Code est actuellement en phase de prévisualisation (Preview) et prend en charge uniquement macOS et Windows.

## Processus de demande

Pour utiliser Claude Code, vous pouvez d'abord vous rendre sur la [page de service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquer sur le bouton « Acquire » pour obtenir les informations d'identification nécessaires à la demande :

![](https://cdn.acedata.cloud/nyq0xz.png)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter. Après vous être connecté ou inscrit, vous serez automatiquement renvoyé à la page actuelle.

Lors de la première demande, un quota gratuit sera offert, vous permettant d'expérimenter gratuitement le service Claude Code.

## Installation de l'application de bureau

### Exigences système

- macOS (Intel et Apple Silicon) ou Windows (x64 / ARM64)
- Linux ne prend pas encore en charge l'application de bureau

### Téléchargement et installation

Rendez-vous sur la [page de téléchargement officielle de Claude](https://claude.ai) pour télécharger le package d'installation correspondant à votre plateforme :

- **macOS** : téléchargez le fichier `.dmg` et faites-le glisser dans le dossier Applications
- **Windows x64** : téléchargez le package d'installation `.exe` et suivez les instructions d'installation
- **Windows ARM64** : téléchargez la version ARM64 (remarque : ARM64 ne prend pas en charge les sessions locales, vous devez utiliser des sessions à distance)

![Page de téléchargement de l'application de bureau Claude](https://cdn.acedata.cloud/c3c8c57264.png)

Une fois l'installation terminée, lancez Claude depuis le dossier Applications (macOS) ou le menu Démarrer (Windows).

## Configuration de l'API AceData Cloud

Après le démarrage de l'application de bureau, vous devez vous connecter à votre compte Anthropic. Nous pouvons utiliser des variables d'environnement pour configurer l'API proxy d'AceData Cloud, **sans abonnement officiel**.

L'application de bureau lit les variables d'environnement à partir de votre environnement Shell, il est donc nécessaire de les configurer dans le fichier de configuration Shell.

### Configuration des variables d'environnement

**Utilisateurs de macOS**

Ajoutez le contenu suivant à `~/.zshrc` (ou `~/.bashrc`), en remplaçant `{token}` par votre jeton API :

```bash
# AceData Cloud - Configuration du proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Après avoir enregistré, exécutez :

```bash
source ~/.zshrc
```

**Utilisateurs de Windows**

Ajoutez les variables d'environnement système suivantes via « Propriétés système → Avancé → Variables d'environnement » :

| Nom de la variable          | Valeur                           |
| ---------------------- | --------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (remplacez par votre jeton API)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

Ou utilisez PowerShell :

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Vous pouvez également configurer via settings.json**

Éditez `~/.claude/settings.json` (créez-le s'il n'existe pas) :

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Astuce** : Le jeton API peut être consulté dans la [console AceData Cloud](https://platform.acedata.cloud/console). Après la configuration, il est nécessaire de **redémarrer l'application de bureau** pour que les variables d'environnement prennent effet.

## Utilisation de base

### Ouvrir un projet

1. Lancez l'application de bureau Claude
2. Cliquez sur l'onglet **Code** en haut
3. Sélectionnez le mode d'exécution **Local**
4. Cliquez sur **Select folder** pour choisir votre répertoire de projet

### Commencer une conversation

Dans la zone de saisie, décrivez vos besoins en langage naturel :

- « Trouvez les commentaires TODO et corrigez-les »
- « Ajoutez des tests à la fonction principale »
- « Expliquez l'architecture de ce projet »

Claude analysera votre code et proposera des modifications, affichant les changements dans une vue Diff.

### Mode de permission

Changez de mode à l'aide du sélecteur de mode à côté du bouton d'envoi :

| Mode       | Description                 |
| -------- | ------------------ |
| **Ask**  | Demande de confirmation avant chaque modification (recommandé pour les débutants)  |
| **Code** | Accepte automatiquement les modifications de fichiers, mais les commandes terminal doivent encore être confirmées |
| **Plan** | Établit d'abord un plan détaillé en attente d'approbation, exécute uniquement après confirmation |

### Sessions parallèles

Cliquez sur **+ New session** dans la barre latérale pour démarrer plusieurs sessions parallèles. Pour les dépôts Git, chaque session obtiendra une copie indépendante du projet via Worktree, sans interférence.

Worktree est stocké par défaut dans le répertoire `~/.claude-worktrees/`.

### Révision Diff

Lorsque Claude modifie des fichiers, il affichera des statistiques de changement (par exemple, `+12 -1`), cliquez pour ouvrir le visualiseur Diff et examiner les modifications fichier par fichier. Vous pouvez également cliquer sur des lignes de code spécifiques pour ajouter des commentaires, Claude ajustera en fonction de vos retours.

## Connexion à des outils externes

Avant de commencer une session, cliquez sur le bouton **⋯**, sélectionnez **Connectors** pour ajouter des intégrations externes :

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- Plus...

Une fois connecté, Claude peut directement lire votre calendrier, envoyer des messages, créer des problèmes, etc.

## Relation avec le CLI

L'application de bureau et le CLI utilisent le même moteur sous-jacent, partageant les configurations suivantes :

- Fichiers de mémoire de projet `CLAUDE.md` / `CLAUDE.local.md`
- Configuration du serveur MCP dans `~/.claude.json` / `.mcp.json`
- Paramètres dans `~/.claude/settings.json`
- Configuration des Hooks et Skills

Les deux peuvent fonctionner simultanément sur le même projet, chacun maintenant son propre historique de session.

## Questions fréquentes

### Que faire en cas d'échec de connexion ?

1. Vérifiez si le fichier `~/.claude/config.json` a été correctement créé
2. Assurez-vous que les variables d'environnement sont correctement définies (redémarrez l'application de bureau pour qu'elles prennent effet)
3. Vérifiez que le jeton API est valide (vous pouvez le consulter dans la [console](https://platform.acedata.cloud/console))
4. Si vous utilisez `settings.json` pour configurer les variables d'environnement, assurez-vous que le format du fichier est correct

### Que faire si les outils installés ne sont pas trouvés ?

Si Claude ne peut pas trouver des commandes comme `npm`, `node`, etc. :

1. Assurez-vous que ces outils fonctionnent correctement dans un terminal normal
2. Vérifiez que votre fichier de configuration Shell (`~/.zshrc`, `~/.bashrc`) a correctement défini le PATH
3. Redémarrez l'application de bureau pour recharger les variables d'environnement

### Comment vérifier le quota restant ?

Connectez-vous à la [console AceData Cloud](https://platform.acedata.cloud/console) pour voir le quota restant et l'utilisation actuelle de votre compte.
