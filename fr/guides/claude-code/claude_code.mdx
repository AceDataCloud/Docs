description: "Claude Code 集成指南 - Ace Data Cloud"

Claude Code est un agent intelligent de programmation développé par Anthropic, utilisable dans divers environnements tels que le terminal, les IDE et les pipelines CI/CD. Grâce au proxy AceData Cloud, vous pouvez utiliser Claude Code à un coût réduit.

Choisissez le tutoriel complet correspondant à la plateforme selon votre scénario d'utilisation :

| Plateforme | Description | Lien du tutoriel |
|------------|-------------|------------------|
| **VS Code** | Extension native, supporte le Diff en ligne, les @-mentions, la revue planifiée | [Tutoriel de configuration VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Éditeur compatible VS Code, extension Claude Code entièrement prise en charge | [Tutoriel de configuration Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **Terminal (CLI)** | Expérience principale, lancez simplement `claude` dans n'importe quel terminal | [Tutoriel de configuration Terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Supporte IntelliJ IDEA, PyCharm, WebStorm et toute la gamme d’IDE | [Tutoriel de configuration JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisation des revues de code et gestion des issues avec `@claude` | [Tutoriel de configuration GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Astuce** : Pour une première demande, rendez-vous sur la [page de service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquez sur « Acquire » pour obtenir vos identifiants et bénéficier d’un crédit gratuit.
