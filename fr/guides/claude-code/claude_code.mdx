Claude Code est un agent intelligent de programmation lancé par Anthropic, utilisable dans divers environnements tels que le terminal, les IDE, les applications de bureau, etc. Grâce au proxy AceData Cloud, vous pouvez utiliser Claude Code à un coût réduit.

> **Première connexion ?** Nous recommandons de commencer par [Claude Code : prise en main rapide en 5 minutes](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — de l’obtention des identifiants à la première commande réussie, en cinq étapes.

Choisissez le tutoriel complet correspondant à votre plateforme selon le scénario d’utilisation :

| Plateforme | Description | Lien du tutoriel |
|------------|-------------|------------------|
| **⚡ Démarrage rapide en 5 minutes** | De l’obtention des identifiants à la première commande `claude`, en cinq étapes | [Tutoriel 5 minutes](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)** | Expérience principale, lancez `claude` dans n’importe quel terminal pour commencer | [Tutoriel de configuration terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Extension native, supporte les diff en ligne, les @-mentions, la revue planifiée | [Tutoriel de configuration VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Éditeur compatible VS Code, extension Claude Code entièrement prise en charge | [Tutoriel de configuration Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **IDE JetBrains** | Supporte IntelliJ IDEA, PyCharm, WebStorm et toute la gamme d’IDE | [Tutoriel de configuration JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisation de la revue de code et gestion des issues avec `@claude` | [Tutoriel de configuration GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Application de bureau (Preview)** | Client graphique indépendant, supporte les sessions parallèles et la connexion à des outils externes | [Tutoriel de configuration application de bureau](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Astuce** : Pour une première demande, rendez-vous sur la [page du service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquez sur « Acquire » pour obtenir vos identifiants, avec un crédit gratuit offert.
