Claude Code se connecte au Coding Plan via le protocole Anthropic Messages, offrant actuellement deux points d'entrée : Terminal et VS Code.

| Point d'entrée      | Guide de configuration                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| Terminal / CLI     | [Configuration du terminal Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code            | [Configuration de Claude Code pour VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Configuration commune

- URL de base : `https://api.acedata.cloud`
- Jeton API : à obtenir depuis l'application Coding et à configurer via `ANTHROPIC_AUTH_TOKEN` dans le guide
- ID du modèle : à choisir dans le répertoire des modèles en temps réel
- Après modification de la configuration : redémarrez Claude Code ; les utilisateurs de VS Code doivent recharger la fenêtre

Ne conservez pas simultanément l'ancien `ANTHROPIC_API_KEY` et ne mettez pas de jeton réel dans les fichiers partagés de l'équipe.

Retournez au [centre de configuration du Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
