---
title: "Tutoriel de configuration de Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code est un agent intelligent de programmation lancé par Anthropic, pouvant être utilisé dans divers environnements tels que le terminal, l'IDE, les applications de bureau, etc. Grâce à l'agent AceData Cloud, vous pouvez utiliser Claude Code à un prix réduit.

Veuillez choisir le tutoriel de configuration correspondant à votre scénario d'utilisation :

| Plateforme          | Description                                 | Lien du tutoriel                                                                                          |
| ------------------ | ------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Terminal (CLI)**  | Expérience principale, exécutez `claude` dans n'importe quel terminal pour commencer | [Tutoriel de configuration du terminal](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code**        | Extension native, prend en charge les Diff en ligne, les @-mentions, la révision planifiée | [Tutoriel de configuration de VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **JetBrains IDE**  | Prend en charge tous les IDE de la série IntelliJ IDEA, PyCharm, WebStorm, etc. | [Tutoriel de configuration de JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatisez la révision de code et le traitement des problèmes avec `@claude` | [Tutoriel de configuration de GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Astuce** : Pour une première demande, vous pouvez vous rendre sur la [page de service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquer sur « Acquire » pour obtenir un certificat, ce qui vous donne un quota gratuit.
