## 1. Obtenir la clé API

Ouvrez la [liste des applications d'Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API d'Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer CC Switch

Téléchargez depuis [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), macOS peut également fonctionner :

```bash
brew install --cask cc-switch
```

## 3. Ajouter un fournisseur

Ouvrez CC Switch, sélectionnez **Claude Code → Ajouter un fournisseur → Personnalisé**, remplissez :

| Champ       | Valeur                        |
| ----------- | ----------------------------- |
| Nom         | `Ace Data Cloud`             |
| URL de base | `https://api.acedata.cloud`  |
| Clé API     | La clé API copiée précédemment |
| Format API  | `Anthropic Messages`         |

Si vous souhaitez utiliser l'éditeur JSON, configurez comme suit :

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch écrira la configuration dans les paramètres utilisateur de Claude Code. Ne conservez pas de clé réelle dans le dépôt d'équipe et ne gardez pas non plus l'ancien `ANTHROPIC_API_KEY`.

## 4. Activer et vérifier

Après avoir enregistré, activez **Ace Data Cloud**, puis rouvrez Claude Code. Envoyez une tâche simple en lecture seule et vérifiez l'appel dans [Historique d'utilisation](https://platform.acedata.cloud/console/usages). Si vous utilisez toujours l'ancienne configuration après le changement, quittez complètement Claude Code et CC Switch, puis réessayez.
