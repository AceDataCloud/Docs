Ce document a un seul objectif : vous permettre **en moins de 5 minutes** d’exécuter votre première commande Claude Code via le proxy AceData Cloud. Pour un tutoriel complet, consultez les sous-documents dédiés aux IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)) ; ici, nous suivrons uniquement la voie la plus rapide : **CLI terminal + extension VS Code**.

> **Pourquoi utiliser AceData Cloud comme proxy pour Claude Code** :
> - Connexion directe en Chine, sans besoin de VPN
> - Tarifs plus avantageux que l’officiel (facturation à la token plateforme)
> - Une même clé supporte à la fois Claude Messages API et le protocole Claude Code Token

## Minute 1 : Obtenir vos identifiants

Ouvrez la [page du service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquez sur le bouton « **Acquire** » :

![](https://cdn.acedata.cloud/nyq0xz.png)

La plateforme crée automatiquement une Application et vous offre un quota gratuit. Notez bien les deux informations **Base URL** + **API Token** dans la page de détails — elles seront nécessaires pour les 5 étapes suivantes.

| Champ | Valeur | Usage |
|-------|--------|-------|
| `BASE_URL` | `https://api.acedata.cloud` | Point d’entrée compatible Claude Messages |
| `API_TOKEN` | `sk-...` (copiable depuis la page) | En-tête d’authentification compatible Anthropic |

## Minute 2 : Installer Claude Code

macOS / Linux / WSL :

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell natif) :

```powershell
irm https://claude.ai/install.ps1 | iex
```

Une fois l’installation terminée, ouvrez un nouveau terminal et vérifiez la version :

```bash
claude --version
```

> Vous devez voir le numéro de version. Claude Code embarque son propre runtime Node.js, il ne dépend pas de la version Node installée sur votre machine.

## Minute 3 : Configurer les variables d’environnement vers AceData Cloud

Ne passez pas par le processus officiel `claude login`, mais surchargez avec des variables d’environnement. Deux méthodes au choix :

**Méthode A : temporaire (session Shell en cours uniquement)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-votre-Token"
```

**Méthode B : persistante (recommandée)**

Ajoutez ces deux lignes à `~/.zshrc` ou `~/.bashrc`, puis faites un `source` du fichier.

> **Piège courant** : le nom de la variable est `ANTHROPIC_AUTH_TOKEN`, pas `ANTHROPIC_API_KEY` ; si vous vous trompez, Claude Code retombe sur le point d’accès officiel et renvoie une erreur 401.

## Minute 4 : Exécuter la première commande

Dans n’importe quel dépôt Git, lancez :

```bash
claude
```

Si c’est la première fois et qu’une demande de connexion apparaît, appuyez sur `Esc` pour passer. Puis saisissez :

```
Liste les dépendances du projet actuel et explique brièvement l’usage de chacune.
```

Normalement, Claude utilisera les outils `read_file` / `glob` / `grep` pour parcourir le dépôt, puis affichera la liste. Si le modèle répond correctement sans erreur 401, cela signifie que le proxy fonctionne.

## Minute 5 : Connecter aussi l’extension VS Code

1. Ouvrez VS Code → panneau Extensions → cherchez « Claude Code » et installez l’extension officielle Anthropic ;
2. Redémarrez VS Code ou exécutez la commande `Developer: Reload Window` pour que l’extension charge le fichier `~/.claude/settings.json` configuré à l’étape 3 ;
3. Cliquez sur l’icône ✦ Spark en haut à droite de l’éditeur, ou sur « ✱ Claude Code » dans la barre d’état en bas pour ouvrir le panneau ;
4. La première fois, une demande de connexion au compte officiel peut apparaître, appuyez sur `Esc` pour ignorer — l’extension utilisera automatiquement `ANTHROPIC_BASE_URL` et `ANTHROPIC_AUTH_TOKEN` configurés à l’étape 3.

> **Astuce** : l’extension VS Code et la CLI partagent le même fichier `~/.claude/settings.json`, vous n’avez donc pas besoin de reconfigurer dans VS Code. Pour une configuration spécifique au projet, créez un fichier `.claude/settings.local.json` à la racine du dépôt (ce fichier est ignoré par git).

Une fois configuré, vous pouvez glisser-déposer des fichiers dans le panneau pour poser des questions, ou utiliser des `@-mention` pour proposer des modifications. Toute facturation passe par AceData Cloud.

## Vérifier que vous passez bien par le proxy

Lancez une commande en mode debug pour vérifier que les requêtes vont bien vers AceData Cloud :

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Si vous voyez `https://api.acedata.cloud`, le proxy est actif ; si vous voyez `api.anthropic.com` ou une erreur 401, retournez à l’étape 3 pour vérifier le nom des variables d’environnement (doivent être `ANTHROPIC_AUTH_TOKEN`, pas `ANTHROPIC_API_KEY`) et assurez-vous que le fichier `~/.claude/.credentials.json` ne contient pas de token officiel (supprimez ce fichier si nécessaire).

## 5 questions fréquemment posées

**Q : J’ai fait `claude login` puis changé les variables d’environnement vers AceData, pourquoi ça ne marche pas ?**  
R : `claude login` écrit le token officiel dans `~/.claude/.credentials.json`, qui a priorité sur les variables d’environnement. Supprimez ce fichier puis faites un `source ~/.zshrc`.

**Q : Puis-je utiliser un modèle comme `--model claude-opus-4-7` ?**  
R : Oui. AceData Cloud proxy transmet le champ model, tous les modèles publics Anthropic ainsi que nos extensions `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5` sont supportés.

**Q : Puis-je configurer plusieurs profils (personnel + entreprise) ?**  
R : Oui. Claude Code supporte plusieurs profils dans `~/.claude/settings.json` ; ou plus simplement, créez deux fonctions shell `claude_personal` / `claude_work` qui exportent des `ANTHROPIC_AUTH_TOKEN` différents avant d’appeler `claude $@`.

**Q : Puis-je utiliser Claude Code dans GitHub Actions ?**  
R : Oui. Voir le [tutoriel d’intégration GitHub Actions Claude Code](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q : Que faire une fois le quota gratuit épuisé ?**  
R : Rendez-vous dans [Gestion des applications](https://platform.acedata.cloud/applications) → sélectionnez votre Application Claude → Topup pour recharger (facturation à la consommation de tokens), ou passez à un abonnement par points.
