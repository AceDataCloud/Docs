Ce document a pour seul but : vous faire **exécuter la première commande Claude Code via AceData Cloud** en 5 minutes. Le tutoriel complet se trouve dans les sous-documents pour chaque IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)) ; cet article ne couvre que le chemin le plus rapide : **Terminal CLI** + **Extension VS Code**.

> **Pourquoi utiliser AceData Cloud comme proxy pour Claude Code** :
> - Connexion directe depuis la Chine, sans VPN à configurer
> - Prix inférieur à celui officiel (facturation par tokens plateforme)
> - Clé unique supporte à la fois Claude Messages API + protocole Claude Code Token

## Minute 1 : Demander ses crédits

Ouvrez la [page de service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquez sur **Acquire** :

![](https://cdn.acedata.cloud/nyq0xz.png)

La plateforme créera automatiquement une Application pour vous et vous donnera un quota gratuit. Notez **Base URL** + **API Token** sur la page de détails — vous en aurez besoin pour les 5 prochaines étapes.

| Champ | Valeur | Utilisation |
|-------|--------|--------------|
| `BASE_URL` | `https://api.acedata.cloud` | Point d’entrée compatible Claude Messages |
| `API_TOKEN` | `sk-...` (copiable depuis la page) | En-tête d’authentification compatible Anthropic |

## Minute 2 : Installer Claude Code

macOS / Linux / WSL :

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell natif) :

```powershell
irm https://claude.ai/install.ps1 | iex
```

Après installation, ouvrez un nouveau terminal et vérifiez :

```bash
claude --version
```

> Si vous voyez une version, c’est bon. Claude Code embarque Node.js Runtime, il ne dépend pas de la version de Node installée sur la machine.

## Minute 3 : Orienter l’environnement vers AceData Cloud

Au lieu de passer par le processus officiel `claude login`, écrivez vos variables d’environnement en override. Deux méthodes possibles :

**Option A : Temporaire (juste pour cette session shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-votre-Token"
```

**Option B : Persistante (recommandé)**

Ajoutez ces lignes à votre `~/.zshrc` ou `~/.bashrc`, puis exécutez `source` :

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-votre-Token"
```

> **Astuce fréquente** : le nom de variable est `ANTHROPIC_AUTH_TOKEN` et non `ANTHROPIC_API_KEY` ; une erreur à ce niveau entraîne un fallback vers l’endpoint officiel avec erreur 401 dans Claude Code.

## Minute 4 : Exécuter la première commande

Lancez dans n’importe quel dépôt Git :

```bash
claude
```

À la première utilisation, si une invite de connexion apparaît, appuyez sur `Esc` pour passer. Ensuite, tapez :

```
LISTER les dépendances du projet actuel et expliquer brièvement leur utilité.
```

Claude utilisera probablement `read_file`, `glob`, `grep` ou autres outils pour explorer le dépôt, puis vous donnera une liste. La barre d’état en bas doit afficher `connected to api.acedata.cloud` — c’est la confirmation que le proxy fonctionne.

## Minute 5 : Connecter aussi l’extension VS Code

1. Ouvrez VS Code → Panneau Extensions → Recherchez `Claude Code`, installez celui officiel Anthropic ;
2. **Cmd+Shift+P** → Tapez `Claude Code: Set Custom API Endpoint` ;
3. Entrez `https://api.acedata.cloud` et validez ;
4. Ensuite, faites `Claude Code: Set API Token` et entrez votre token.

Une fois configuré, le panneau Claude Code apparaîtra dans la barre latérale, vous permettant de glisser-déposer des fichiers pour interroger ou mentionner un fichier pour des suggestions de modification. Toute facturation est gérée via AceData Cloud.

## Vérifier que vous utilisez bien le proxy

Dans l’interaction avec Claude Code, tapez :

```
Access https://api.acedata.cloud/whoami and tell me what it returns
```

Si vous voyez vos informations personnelles (`{user_id, plan, ...}`), cela signifie que la requête passe bien par AceData Cloud. Si vous obtenez une erreur 401 en allant directement sur le domaine officiel, retournez à la Minute 3 pour vérifier le nom de variable.

## 5 questions fréquemment posées

**Q : Après `claude login`, si je modifie la variable d’environnement vers AceData, ça ne marche pas ?**  
R : `claude login` écrit un token dans `~/.claude/.credentials.json`, qui a priorité sur la variable d’environnement. Supprimez ce fichier puis `source ~/.zshrc` pour appliquer.

**Q : Peut-on utiliser `--model claude-opus-4-7` ?**  
R : Oui. AceData Cloud transmet le paramètre `model`. Tous les modèles publics d’Anthropic + nos extensions (`claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5`) sont supportés.

**Q : Peut-on configurer plusieurs profils (perso + pro) ?**  
R : Oui. Claude Code supporte plusieurs profils dans `~/.claude/settings.json`. Variante simple : écrire deux fonctions shell `claude_personal` / `claude_work`, qui exportent chacune un token différent, puis appellent `claude $@`.

**Q : Peut-on faire tourner cela dans GitHub Actions ?**  
R : Oui. Voir [Tutoriel d’intégration de Claude Code avec GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**Q : Que faire après épuisement du quota gratuit ?**  
R : Aller sur [Gestion des applications](https://platform.acedata.cloud/applications), choisir cette Application Claude, puis effectuer un top-up (en fonction de tokens consommés) ou passer à un abonnement par points.
