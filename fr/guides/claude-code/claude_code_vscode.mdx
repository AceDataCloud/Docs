Claude Code est un outil de programmation lancé par Anthropic, également connu comme l'un des agents de programmation les plus puissants au monde. L'extension Claude Code pour VS Code offre une interface graphique native, c'est la méthode recommandée pour utiliser Claude Code dans VS Code.

Ce document présente principalement comment configurer et utiliser l'extension Claude Code dans VS Code via le service proxy d'Ace Data Cloud.

## Processus de demande

Pour utiliser Claude Code, vous pouvez d'abord vous rendre sur le [tableau de bord d'Ace Data Cloud](https://platform.acedata.cloud/console/applications) pour obtenir votre jeton API, à conserver en réserve.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion vous invitant à vous inscrire et à vous connecter. Après vous être connecté ou inscrit, vous serez automatiquement renvoyé à la page actuelle.

Lors de la première demande, un quota gratuit sera offert, vous permettant d'expérimenter gratuitement le service Claude Code.

## Installation du plugin Claude Code

Recherchez **Claude Code** dans le marché des extensions de VS Code, et installez-le après avoir confirmé que l'éditeur est **Anthropic**. Une fois l'installation terminée, une entrée Claude Code apparaîtra dans la barre d'activités.

## Configuration de l'API Ace Data Cloud

Lors de la première ouverture du plugin, il vous sera demandé de vous connecter au compte officiel d'Anthropic. Nous pouvons sauter la connexion officielle et utiliser l'API proxy d'Ace Data Cloud, sans abonnement officiel.

L'extension et le CLI du terminal lisent le même ensemble de paramètres Claude Code. Pour une gestion complète de l'authentification, des conflits de crédentials et des configurations globales, voir [le tutoriel de configuration du terminal Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Si vous souhaitez que cela ne s'applique qu'au projet actuel, créez un fichier `.claude/settings.local.json` dans le répertoire racine du projet, qui est déjà inclus dans `.gitignore` :

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Où `{token}` est la clé API que vous avez copiée précédemment. Si l'environnement de démarrage de VS Code contient déjà un ancien `ANTHROPIC_API_KEY`, veuillez d'abord exécuter `unset ANTHROPIC_API_KEY` dans cet environnement ; ne considérez pas une chaîne vide comme un nettoyage, et ne mettez pas de clé réelle dans le fichier partagé `.claude/settings.json` de l'équipe.

Voici la configuration réalisée sur ma machine avec VS Code 1.136.1 et l'extension Claude Code 2.1.251. La capture d'écran utilise une clé de remplacement pour éviter la divulgation de véritables crédentials :

![Configuration de Claude Code d'Ace Data Cloud dans VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Après avoir terminé la configuration, redémarrez VS Code.

> Remarque : La configuration ci-dessus ne s'applique qu'au projet actuel, et il est conseillé d'ajouter le chemin du fichier de configuration `.claude/settings.local.json` dans le fichier `.gitignore` pour éviter qu'il ne soit poussé vers le dépôt distant.

Si vous souhaitez que cela s'applique à tous les projets, vous pouvez directement placer cette configuration dans le répertoire utilisateur. Le chemin correspondant est `~/.claude/settings.json`,

> Remarque : Après avoir terminé la configuration, veuillez redémarrer ou recharger VS Code pour que la configuration ci-dessus prenne effet.

## Utilisation de base

Une fois configuré, envoyez une tâche simple en lecture seule dans le panneau Claude Code, par exemple "lire README.md et résumer en une phrase". Une fois la tâche réussie, vous pouvez vérifier cet appel dans [l'historique d'utilisation](https://platform.acedata.cloud/console/usages).

## Comment vérifier le quota restant

Vous pouvez consulter le quota restant de votre compte via [le tableau de bord d'Ace Data Cloud - Liste des applications](https://platform.acedata.cloud/console/applications).

Vous pouvez consulter tout l'historique d'utilisation et les détails de facturation via [le tableau de bord d'Ace Data Cloud - Historique d'utilisation](https://platform.acedata.cloud/console/usages).
