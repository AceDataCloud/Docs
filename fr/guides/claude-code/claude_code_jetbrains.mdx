## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer le CLI et le plugin

Commencez par installer le CLI de Claude Code.

macOS / Linux / WSL :

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell :

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Ensuite, installez le plugin **Claude Code** depuis le JetBrains Marketplace et redémarrez l'IDE. Le plugin appelle la commande `claude` locale ; si un message d'erreur indique que la commande est introuvable, remplissez son chemin complet dans **Settings → Tools → Claude Code**.

## 3. Configurer Ace Data Cloud

Configurez dans l'environnement de démarrage du backend JetBrains.

macOS / Linux / WSL :

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="votre clé API"
unset ANTHROPIC_API_KEY
```

Windows PowerShell :

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "votre clé API"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Vous pouvez également utiliser le fichier `.claude/settings.local.json` ignoré dans le projet :

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "votre clé API"
  }
}
```

Le développement à distance doit être configuré et le plugin installé sur l'hôte distant ; les utilisateurs de WSL peuvent définir la commande Claude comme `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Vérification

Exécutez `claude` depuis le terminal intégré de l'IDE, ou démarrez un terminal externe et entrez `/ide`. Une fois connecté avec succès, demandez à Claude de répondre `OK`, puis lisez un fichier de test et vérifiez cette demande dans l'historique d'utilisation d'Ace Data Cloud [historique](https://platform.acedata.cloud/console/usages).

Si le plugin ne démarre pas, exécutez d'abord `claude --version` dans le même terminal ; si vous obtenez une erreur 401, vérifiez les variables d'environnement héritées par le backend et l'ancienne `ANTHROPIC_API_KEY`.
