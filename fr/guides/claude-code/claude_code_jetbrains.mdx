Claude Code est un outil de **codage agentique** lancé par Anthropic, également connu comme l'un des agents de programmation les plus puissants au monde. Claude Code propose un plugin dédié pour JetBrains IDE, prenant en charge toute la gamme des IDE JetBrains tels qu'IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio, etc.

Ce document présente principalement comment configurer et utiliser Claude Code dans JetBrains IDE via le service proxy d'AceData Cloud.

## Processus de demande

Pour utiliser Claude Code, vous pouvez d'abord vous rendre sur la [page de service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquer sur le bouton « Acquire » pour obtenir les informations d'identification nécessaires à la demande :

![](https://cdn.acedata.cloud/nyq0xz.png)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter. Après vous être connecté ou inscrit, vous serez automatiquement renvoyé à la page actuelle.

Lors de la première demande, un quota gratuit sera offert, vous permettant d'expérimenter gratuitement le service Claude Code.

## Installation

### Conditions préalables

Le plugin Claude Code pour JetBrains dépend de Claude Code CLI, veuillez d'abord vous assurer que le CLI est installé :

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# Ou utilisez Homebrew
brew install claude-code
```

Après l'installation, vous pouvez vérifier :

```bash
claude --version
```

### Installation du plugin

![Plugin Claude Code dans JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Ouvrez JetBrains IDE
2. Allez dans **Settings** → **Plugins** → **Marketplace**
3. Recherchez **Claude Code**
4. Cliquez sur **Install** pour installer le plugin
5. Redémarrez l'IDE

Ou visitez directement le [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) pour une installation en ligne.

> **Important** : Après l'installation du plugin, un **redémarrage complet de l'IDE** est nécessaire (il peut être nécessaire de redémarrer plusieurs fois) pour qu'il prenne effet.

## Configuration de l'API AceData Cloud

Le plugin Claude Code pour JetBrains exécute la commande `claude` via le terminal intégré, donc la méthode de configuration des variables d'environnement est la même que pour le CLI.

### Étape 1 : Créer config.json

Créez le fichier de configuration pour Claude Code :

| Système            | Chemin                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{nom d'utilisateur}\.claude\config.json` |

Écrivez le contenu suivant dans ce fichier et enregistrez :

```json
{
  "primaryApiKey": "self"
}
```

Commande rapide pour créer sur macOS / Linux :

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Étape 2 : Configurer les variables d'environnement

**Méthode 1 : Configurer dans le fichier de configuration Shell (recommandé)**

Ajoutez le contenu suivant à votre `~/.zshrc` ou `~/.bashrc`, en remplaçant `{token}` par votre jeton API :

```bash
# AceData Cloud - Configuration du proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Après modification, exécutez `source ~/.zshrc` pour que la configuration prenne effet, puis **redémarrez JetBrains IDE**.

**Méthode 2 : Configurer dans settings.json de Claude Code**

Éditez `~/.claude/settings.json` (créez-le s'il n'existe pas) :

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Astuce** : Le jeton API peut être consulté dans le [tableau de bord AceData Cloud](https://platform.acedata.cloud/console).

## Utilisation de base

### Démarrer depuis le terminal intégré de l'IDE

Ouvrez le terminal intégré de JetBrains IDE et exécutez :

```bash
claude
```

Lorsque vous exécutez dans le terminal intégré de l'IDE, toutes les fonctionnalités intégrées (vue Diff, sélection de contexte, etc.) s'activeront automatiquement.

### Se connecter depuis un terminal externe

Si vous exécutez Claude Code dans un terminal externe, vous pouvez utiliser la commande `/ide` pour vous connecter à JetBrains IDE :

```bash
claude
> /ide
```

Assurez-vous de démarrer Claude Code depuis le même chemin que le répertoire racine du projet IDE, afin que Claude puisse accéder au même ensemble de fichiers.

### Raccourcis clavier

| Raccourci                                              | Fonction                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Ouvrir rapidement Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Insérer une référence de fichier (comme `@File#L1-99`) |

### Fonctionnalités intégrées

Le plugin Claude Code pour JetBrains propose les fonctionnalités intégrées suivantes :

- **Vue Diff** : Les modifications de code sont directement affichées dans le visualiseur Diff de l'IDE
- **Sélection de contexte** : Le code et l'onglet actuellement sélectionnés sont automatiquement partagés avec Claude
- **Références de fichiers** : Utilisez des raccourcis pour référencer rapidement des fichiers et des numéros de ligne
- **Partage de diagnostics** : Les informations de diagnostic telles que Lint, erreurs de syntaxe, etc., dans l'IDE sont automatiquement partagées avec Claude

## Paramètres du plugin

Dans **Settings** → **Tools** → **Claude Code [Beta]**, vous pouvez configurer :

| Paramètre                        | Description                                         |
| ----------------------------- | ------------------------------------------ |
| **Commande Claude**            | Chemin de commande Claude personnalisé (comme `/usr/local/bin/claude`) |
| **Activer les mises à jour automatiques**  | Vérifier et installer automatiquement les mises à jour du plugin                                |
| **Activer l'utilisation de Option+Enter** | Utiliser Option+Enter sous macOS pour passer à la ligne dans la boîte de dialogue             |

### Configuration pour les utilisateurs de WSL

Si vous utilisez dans un environnement WSL, vous devez définir la commande Claude comme suit :

```
wsl -d Ubuntu -- bash -lic "claude"
```

(Remplacez `Ubuntu` par le nom de votre distribution WSL)

## Questions fréquentes

### Que faire en cas d'échec de connexion ?

1. Vérifiez si le fichier `~/.claude/config.json` a été correctement créé
2. Assurez-vous que les variables d'environnement sont correctement configurées
3. Vérifiez que le jeton API est valide (vous pouvez le consulter dans le [tableau de bord](https://platform.acedata.cloud/console))
4. Redémarrez JetBrains IDE et réessayez

### Que faire si le plugin ne fonctionne pas ?

1. Assurez-vous d'exécuter Claude Code depuis le répertoire racine du projet
2. Vérifiez si le plugin est activé dans les paramètres de l'IDE
3. Redémarrez complètement l'IDE (il peut être nécessaire de redémarrer plusieurs fois)
4. Si vous utilisez le mode de développement à distance, assurez-vous que le plugin est installé sur l'hôte distant (Settings → Plugin (Host))

### IDE non détecté ?

1. Assurez-vous que le plugin est installé et activé
2. Redémarrez l'IDE
3. Assurez-vous d'exécuter Claude Code dans le terminal intégré
4. Les utilisateurs de WSL doivent consulter le [guide de dépannage WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Si un clic sur l'icône Claude indique "command not found" :

1. Vérifiez si le CLI est installé : `which claude`
2. Configurez le chemin complet de la commande Claude dans les paramètres du plugin
3. Les utilisateurs de WSL doivent utiliser le format de commande WSL ci-dessus
### Comment vérifier le solde restant ?

Connectez-vous à [la console AceData Cloud](https://platform.acedata.cloud/console) pour voir le solde restant et l'utilisation actuelle de votre compte.
