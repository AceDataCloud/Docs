## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer Claude Code

macOS / Linux / WSL :

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell :

```powershell
irm https://claude.ai/install.ps1 | iex
```

Vérifiez après l'installation :

```bash
claude --version
```

## 3. Configurer Ace Data Cloud

Pour une utilisation globale, ajoutez les variables suivantes à `~/.zshrc` ou `~/.bashrc` :

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="votre clé API"
unset ANTHROPIC_API_KEY
```

Rouvrez le terminal ou `source` le fichier de configuration correspondant.

Pour une validité uniquement dans le projet actuel, vous pouvez créer un `.claude/settings.local.json` qui est ajouté à `.gitignore` :

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "votre clé API"
  }
}
```

Choisissez l'une des deux méthodes. Ne mettez pas de clé réelle dans le `.claude/settings.json` partagé par l'équipe ; si `ANTHROPIC_API_KEY` est déjà présent dans l'environnement, il doit être réellement annulé, et non défini comme une chaîne vide.

## 4. Démarrer et vérifier

```bash
cd /path/to/your/project
claude
```

Une fois à l'intérieur, envoyez une tâche en lecture seule, par exemple "lire README.md et résumer en une phrase". Les enregistrements d'appels et le solde peuvent être consultés dans [l'historique d'utilisation](https://platform.acedata.cloud/console/usages) et [la liste des applications](https://platform.acedata.cloud/console/applications).

Si un retour 401 se produit, vérifiez si la clé est complète, si l'ancienne `ANTHROPIC_API_KEY` a été annulée, et redémarrez complètement Claude Code. Le modèle n'a pas besoin d'être fixé dans la configuration d'accès, vous pouvez choisir le modèle disponible actuel dans Claude Code.
