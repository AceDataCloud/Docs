Claude Code est un outil de **Agentic Coding** lancé par Anthropic, également considéré comme l'un des agents de programmation les plus puissants au monde. Le terminal CLI est l'expérience centrale de Claude Code, vous pouvez exécuter la commande `claude` dans n'importe quel terminal et collaborer en programmation avec l'IA en utilisant un langage naturel.

Ce document présente principalement comment installer, configurer et utiliser Claude Code CLI via le service proxy d'AceData Cloud dans le terminal.

## Processus de demande

Pour utiliser Claude Code, vous pouvez d'abord vous rendre sur la [page de service Claude Messages](https://platform.acedata.cloud/documents/claude-messages) et cliquer sur le bouton « Acquire » pour obtenir les informations d'identification nécessaires à la demande :

![](https://cdn.acedata.cloud/nyq0xz.png)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter. Après vous être connecté ou inscrit, vous serez automatiquement renvoyé à la page actuelle.

Lors de la première demande, un quota gratuit sera offert, vous permettant d'expérimenter gratuitement le service Claude Code.

## Installation de Claude Code

### Exigences système

- macOS, Linux ou Windows (y compris WSL)
- Node.js n'est pas nécessaire, l'installation native gérera automatiquement les dépendances

### Méthodes d'installation

Claude Code prend en charge plusieurs méthodes d'installation :

**Méthode 1 : Installation native (recommandée)**

macOS / Linux / WSL :

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell :

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD :

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Méthode 2 : Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Méthode 3 : WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

L'installation native mettra automatiquement à jour en arrière-plan, garantissant que vous disposez toujours de la dernière version.

## Configuration de l'API AceData Cloud

Une fois l'installation terminée, il vous sera demandé par défaut de vous connecter à votre compte officiel Anthropic. Nous pouvons utiliser des variables d'environnement pour configurer l'API proxy d'AceData Cloud, **sans abonnement officiel**.

### Configuration des variables d'environnement

Il existe deux façons de configurer les variables d'environnement, choisissez l'une d'elles.

**Méthode 1 : Configurer dans le fichier de configuration Shell (recommandée)**

Ajoutez le contenu suivant à votre fichier de configuration Shell (`~/.zshrc`, `~/.bashrc` ou `~/.bash_profile`), en remplaçant `{token}` par le jeton API que vous avez obtenu dans le tableau de bord d'AceData Cloud :

```bash
# AceData Cloud - Configuration du proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Après modification, exécutez la commande suivante pour appliquer la configuration :

```bash
source ~/.zshrc  # ou source ~/.bashrc
```

**Méthode 2 : Configurer dans le fichier settings.json de Claude Code**

Éditez `~/.claude/settings.json` (créez-le s'il n'existe pas) et ajoutez la configuration `env` :

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

L'avantage de cette méthode est que les variables d'environnement ne s'appliquent qu'à Claude Code, sans affecter d'autres programmes.

> **Astuce** : Le jeton API peut être consulté dans le [tableau de bord d'AceData Cloud](https://platform.acedata.cloud/console). La valeur de `ANTHROPIC_AUTH_TOKEN` sera automatiquement préfixée par `Bearer` lors de l'envoi au serveur.

## Commencer à utiliser

### Démarrer le mode interactif

Ouvrez le terminal, accédez à votre répertoire de projet, puis exécutez :

```bash
cd /path/to/your/project
claude
```

Vous verrez l'écran d'accueil de Claude Code, il vous suffit de saisir un langage naturel pour commencer l'interaction.

### Commandes courantes

| Commande            | Description          | Exemple                   |
| ------------------ | ------------------- | ------------------------- |
| `claude`           | Démarrer le mode interactif | `claude`                 |
| `claude "tâche"`   | Exécuter une tâche unique | `claude "corriger l'erreur de construction"` |
| `claude -p "requête"` | Exécuter une requête puis quitter | `claude -p "expliquer cette fonction"` |
| `claude -c`       | Continuer la conversation la plus récente dans le répertoire actuel | `claude -c`              |
| `claude -r`       | Récupérer la conversation précédente | `claude -r`              |
| `claude commit`    | Créer un commit Git   | `claude commit`          |

### Commandes en mode interactif

En mode interactif, vous pouvez utiliser les commandes intégrées suivantes :

| Commande            | Fonction        |
| ------------------ | --------------- |
| `/help`            | Afficher les informations d'aide |
| `/clear`           | Effacer l'historique de la conversation |
| `/config`          | Ouvrir le panneau de configuration |
| `/model`           | Changer de modèle |
| `/mcp`             | Gérer le service MCP |
| `/compact`         | Compresser le contexte |
| `/memory`          | Gérer la mémoire |
| `/login`           | Changer de compte |
| `exit` ou `Ctrl+C` | Quitter         |

### Exemples d'interaction

```bash
# Analyser le projet
> que fait ce projet ?

# Corriger un bug
> il y a un bug où les utilisateurs peuvent soumettre des formulaires vides - corrigez-le

# Écrire des tests
> écrivez des tests unitaires pour les fonctions de calculatrice

# Refactoriser le code
> refactoriser le module d'authentification pour utiliser async/await

# Opérations Git
> valider mes modifications avec un message descriptif
> créer une PR pour cette fonctionnalité
```

## Utilisation avancée

### Pipelines et scriptage

Claude Code suit la philosophie Unix et prend en charge les opérations de pipeline et de scriptage :

```bash
# Surveiller les journaux et alerter automatiquement
tail -f app.log | claude -p "prévenez-moi s'il y a une anomalie"

# Traduire automatiquement le texte ajouté
claude -p "si de nouvelles chaînes de texte sont ajoutées, traduisez-les en français et créez une PR"

# Revue de code
git diff main | claude -p "révisez ces modifications"
```

### Référence des variables d'environnement

Voici les variables d'environnement courantes prises en charge par Claude Code :

| Variable                       | Description                                    |
| ------------------------------ | ---------------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`        | Valeur de l'en-tête Authorization personnalisé (préfixe Bearer ajouté automatiquement) |
| `ANTHROPIC_API_KEY`           | Clé API (envoyée en tant qu'en-tête X-Api-Key) |
| `ANTHROPIC_BASE_URL`          | URL de base de l'API                          |
| `ANTHROPIC_MODEL`             | Remplacer le modèle par défaut                 |
| `ANTHROPIC_SMALL_FAST_MODEL`  | Modèle de niveau Haiku (pour les tâches en arrière-plan) |
| `MAX_THINKING_TOKENS`         | Définir le budget de tokens de réflexion (mettre à 0 pour désactiver le mode de réflexion) |
| `DISABLE_COST_WARNINGS`       | Mettre à 1 pour désactiver les avertissements de coût |

### Mémoire de projet CLAUDE.md

Créez un fichier `CLAUDE.md` dans le répertoire racine du projet pour fournir des instructions et un contexte spécifiques au projet à Claude Code. Claude chargera automatiquement ce fichier au démarrage.

```markdown
# Description du projet
C'est un projet full-stack Django + Vue.js.

## Normes de codage
- Utiliser Python 3.12
- Suivre le style de code PEP 8
- Tous les API doivent avoir des tests unitaires
```

## Questions fréquentes

### Que faire en cas d'échec de connexion ?
1. Vérifiez si le fichier `~/.claude/config.json` a été correctement créé, avec le contenu `{"primaryApiKey": "self"}`
2. Confirmez que les variables d'environnement sont correctement définies :
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Vérifiez que le jeton API est valide (vous pouvez le consulter dans [le tableau de bord](https://platform.acedata.cloud/console))
4. Essayez de redémarrer le terminal

### commande introuvable : claude

Si après l'installation vous voyez `commande introuvable`, essayez :

1. Fermez et rouvrez le terminal
2. Vérifiez le PATH : `echo $PATH`
3. Réinstallez : `curl -fsSL https://claude.ai/install.sh | bash`

### Comment vérifier le solde restant ?

Connectez-vous au [tableau de bord AceData Cloud](https://platform.acedata.cloud/console) pour voir le solde restant et l'utilisation actuelle de votre compte.
