---
title: "Génération 3D Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Appelez `POST /tripo/generations` pour créer un nouveau modèle, en fournissant du texte, une seule image ou plusieurs vues d’un même objet. Utilisez un jeton AceDataCloud ; le résultat est renvoyé de manière synchrone par défaut. Lorsque `async: true` ou `callback_url` est fourni, HTTP 200 et `task_id` sont d’abord renvoyés. Le résultat du callback à la fin possède la même structure JSON que le résultat synchrone.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` vaut `generate` par défaut. Choisissez une seule des trois entrées : `prompt` (1 à 1024 caractères), `image_url`, `image_urls`. Les images doivent être des fichiers PNG/JPEG accessibles publiquement en HTTPS, d’une taille maximale de 20 MiB. Les vues multiples sont disposées dans l’ordre face, gauche, dos, droite ; la vue de face et au moins une autre vue doivent être fournies, et null peut être utilisé pour ignorer des vues intermédiaires.

`model` vaut `v3.1-20260211` par défaut, mais `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` ou `P2-20260801` peuvent aussi être sélectionnés explicitement. `texture` vaut `standard` par défaut ; utilisez `none` pour une géométrie seule. Les différents modèles et niveaux de texture consomment des quotas différents.

Téléchargez le GLB depuis `data[0].model_url` ; `image_url` est un aperçu facultatif. Conservez `data[0].id` pour les opérations ultérieures de texturation, de conversion ou de création de squelette. Lors d’une nouvelle tentative pour la même soumission, conservez la même valeur `Idempotency-Key` et le même corps de requête.
