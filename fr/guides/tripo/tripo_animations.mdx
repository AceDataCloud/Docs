title: "Animation de personnages Tripo"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Appelez `POST /tripo/animations` et utilisez `action` pour choisir la vérification du squelette, le rigging automatique ou le retargeting d’animation. Transmettez `async: true` pour interroger `/tripo/tasks`, ou `callback_url` pour recevoir le résultat final.

1. **Vérification**. Envoyez `{"action":"rig_check","model_id":"5db97adc-a877-4587-af16-bbf443aa55de"}`. L’élément de résultat contient le booléen `riggable` et, éventuellement, `rig_type`. Une vérification réussie avec `riggable: false` indique que le modèle ne convient pas au rigging. Cette opération est gratuite.
2. **Rigging**. Envoyez `{"action":"rig","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","model":"v3.0-20260909","rig_type":"biped","format":"GLB"}`. Le résultat est un nouveau modèle doté d’un squelette ; conservez son `data[0].id`. La vérification et le rigging peuvent également lire un fichier existant via `model_url`.
3. **Retargeting**. Utilisez l’ID du résultat du rigging comme `model_id`. Par exemple `{"action":"retarget","model_id":"96a66a1d-69d2-48f0-846b-bdf02ed9bcc4","animations":["preset:walk","preset:idle"],"format":"GLB","async":true}`. Choisissez des préréglages compatibles avec la version et le type de squelette ; transmettez `animation` pour un seul, ou `animations` pour un lot de cinq au maximum, facturé selon le nombre de mouvements. Une requête par lot peut livrer un fichier contenant plusieurs pistes d’animation.

Le rigging et le retargeting prennent tous deux en charge les formats GLB et FBX. Utilisez `export_with_geometry` pour contrôler si le résultat du retargeting contient la géométrie, et `animate_in_place` pour contrôler si le déplacement est conservé. L’adresse de téléchargement du fichier du modèle se trouve dans `data[0].model_url`.
