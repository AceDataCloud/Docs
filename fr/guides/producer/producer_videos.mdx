---
title: "Documentation de l'API de téléchargement de vidéos Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer nous permet de télécharger des vidéos liées aux chansons, ce document explique la méthode d'intégration de l'API correspondante.

Cette API n'a qu'un seul paramètre d'entrée, qui est `audio_id`, c'est l'ID unique de la chanson.

Ici, nous entrons l'`audio_id` qui est `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, c'est un ID de chanson généré par Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Le résultat est le suivant :

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://storage.googleapis.com/corpusant-app-public/song-videos/a54609c6-13e2-4176-be0f-4d7eebc68e1f:5178f294b214798f7d38b810ac289be75306659be24af88900a633efce334012.mp4"
  }
}
```

On peut voir que le champ `video_url` de `data` est le lien de téléchargement de la vidéo.
