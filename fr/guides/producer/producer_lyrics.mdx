Le Producteur nous permet de générer des paroles via des mots-clés, ce document explique la méthode d'intégration de l'API associée.

Cette API n'a qu'un seul paramètre d'entrée, qui est `prompt`, c'est le mot-clé pour générer les paroles.

Ici, notre `prompt` est `Une chanson sur l'hiver`, c'est le mot-clé pour générer les paroles.

```bash
curl -X POST 'https://api.acedata.cloud/producer/lyrics' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Une chanson sur l'hiver"
}'
```

Le résultat est le suivant :
