---
title: "Instructions d’intégration de l’API d’importation d’audio de référence Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer nous permet d’importer des audios de référence pour une création secondaire, ce document explique la méthode d’intégration de l’API associée.

Cette API ne possède qu’un seul paramètre d’entrée, `audio_url`, qui est une adresse CDN publiquement accessible et prend en charge l’extension mp3.

Ici, le `audio_url` que nous saisissons est `https://cdn.acedata.cloud/suno_demo.mp3`, qui est une adresse CDN publiquement accessible.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Le résultat est le suivant :

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

On peut voir que le champ `audio_id` de `data` est l’ID de la chanson après l’importation.

Après avoir obtenu l’ID de la chanson, nous pouvons utiliser la [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) pour effectuer une génération de chanson personnalisée, par exemple en transmettant `upload_extend` à `action`, tout en transmettant l’ID de chanson retourné à `audio_id`, il est alors possible de générer une nouvelle chanson à partir de l’audio de référence.
