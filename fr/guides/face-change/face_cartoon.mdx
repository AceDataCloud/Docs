Cet article présente une documentation sur l'API de transformation d'images en anime, qui permet de générer une image d'anime personnalisée à partir d'une photo de visage, pouvant être utilisée pour créer des avatars personnalisés, des activités ludiques, des applications d'effets spéciaux, etc., améliorant ainsi l'expérience sociale et de divertissement.

## Processus de demande

Pour utiliser l'API, vous devez d'abord vous rendre sur la page correspondante de l'[API de transformation d'images en anime](https://platform.acedata.cloud/documents/face-cartoon) pour demander le service correspondant. Une fois sur la page, cliquez sur le bouton « Acquire », comme indiqué dans l'image ci-dessous :

![](https://cdn.acedata.cloud/q6ytrc.png)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter. Après vous être connecté ou inscrit, vous serez automatiquement renvoyé à la page actuelle.

Lors de la première demande, un quota gratuit sera offert, vous permettant d'utiliser l'API gratuitement.

## Utilisation de base

Tout d'abord, comprenons la méthode d'utilisation de base, qui consiste à entrer un lien d'image pour obtenir l'image traitée en retour. Vous devez d'abord transmettre un champ `image_url`, l'image du visage étant illustrée ci-dessous :

<p><img src="https://cdn.acedata.cloud/lrbtcn.jpg" width="500" className="m-auto" /></p>

Nous pouvons ensuite remplir le contenu correspondant sur l'interface, comme indiqué dans l'image ci-dessous :

<p><img src="https://cdn.acedata.cloud/gflhrl.png" width="500" className="m-auto" /></p>

Ici, nous avons configuré les en-têtes de requête, y compris :

- `accept` : le format de réponse souhaité, ici rempli avec `application/json`, c'est-à-dire au format JSON.
- `authorization` : la clé d'API pour appeler l'API, que vous pouvez sélectionner directement après la demande.

De plus, nous avons configuré le corps de la requête, y compris :

- `image_url` : le lien de l'image du visage à traiter.

Après avoir fait votre sélection, vous pouvez constater que le code correspondant a également été généré à droite, comme indiqué dans l'image ci-dessous :

<p><img src="https://cdn.acedata.cloud/rwbicp.png" width="500" className="m-auto" /></p>

Cliquez sur le bouton « Try » pour effectuer un test, comme montré dans l'image ci-dessus, et nous avons obtenu le résultat suivant :

```json

```

On peut voir que le résultat retourné contient un champ `image_url`, qui est l'image du visage cartoon modifiée. Les informations du visage modifié sont illustrées ci-dessous :

<p><img src="https://cdn.acedata.cloud/qkyga1.png" width="500" className="m-auto" /></p>

On peut voir que le visage sur l'image a déjà généré une image d'anime personnalisée.

De plus, si vous souhaitez générer le code d'intégration correspondant, vous pouvez le copier directement, par exemple, le code CURL est le suivant :

```shell
curl -X POST 'https://api.acedata.cloud/face/cartoon' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}'
```

Le code d'intégration en Python est le suivant :

```python
import requests

url = "https://api.acedata.cloud/face/cartoon"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Gestion des erreurs

Lors de l'appel de l'API, si une erreur se produit, l'API renverra le code d'erreur et les informations correspondantes. Par exemple :

- `400 token_mismatched` : Mauvaise requête, probablement en raison de paramètres manquants ou invalides.
- `400 api_not_implemented` : Mauvaise requête, probablement en raison de paramètres manquants ou invalides.
- `401 invalid_token` : Non autorisé, jeton d'autorisation invalide ou manquant.
- `429 too_many_requests` : Trop de requêtes, vous avez dépassé la limite de taux.
- `500 api_error` : Erreur interne du serveur, quelque chose s'est mal passé sur le serveur.

### Exemple de réponse d'erreur

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
