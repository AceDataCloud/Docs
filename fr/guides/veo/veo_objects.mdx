Cet article présentera la documentation de l'API Veo Objects. Cette interface est utilisée pour effectuer des opérations d'**ajout ou de suppression d'objets** sur une vidéo Veo déjà générée (repeinture locale basée sur un masque).

## Processus de demande

Pour utiliser l'API, vous devez d'abord faire une demande sur la page de service Veo correspondante. Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion.

## Utilisation de base

L'appel de cette interface nécessite de transmettre les paramètres suivants :

- `video_id` (obligatoire) : l'ID de la tâche de la vidéo source. **Ne peut pas** être la vidéo de sortie de `/veo/extend`.
- `action` (obligatoire) : type d'opération, `insert` ou `remove`.
- `prompt` :
  - `action=insert` : **obligatoire**, description de l'objet à ajouter.
  - `action=remove` : optionnel, description du contenu à supprimer (principalement utilisé pour l'enregistrement des journaux, la zone réelle à effacer est déterminée par `image_mask`).
- `image_mask` :
  - `action=insert` : optionnel. Si non fourni, l'IA décidera automatiquement de l'emplacement d'insertion ; si fourni, l'insertion se fera dans la zone de pixels blancs.
  - `action=remove` : **obligatoire**, la zone de pixels blancs représente l'objet à effacer.

`image_mask` accepte deux formats :

1. Une **adresse d'image HTTP(S) accessible publiquement** (recommandé).
2. Une **chaîne JPEG encodée en base64**, pouvant avoir le préfixe `data:image/jpeg;base64,` ou être en base64 brut.

Exemple de requête (ajouter un objet, sans transmettre de masque, laisser l'IA localiser automatiquement) :

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "ajouter un cochon volant avec des ailes noires"
  }'
```

Exemple de requête (supprimer un objet selon le masque) :

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "supprimer le nuage blanc"
  }'
```

La structure des résultats retournés est identique à celle de `/veo/videos`.

## Informations de facturation

- `action=insert` ou `remove` : 1,50 Crédit / fois.

## Callback asynchrone

L'interface prend en charge le mode asynchrone, en transmettant `callback_url`, vous pouvez recevoir les résultats par une requête POST après l'achèvement de la tâche. Si vous n'avez pas d'adresse de rappel publique, vous pouvez également définir `async` sur `true`, l'interface renverra immédiatement `task_id`, puis vous pourrez interroger le résultat via l'interface de requête de tâche correspondante.
