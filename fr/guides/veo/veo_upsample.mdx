Cet article présentera les instructions d'intégration de l'API Veo Upsample. Cette interface est utilisée pour effectuer un suréchantillonnage d'une vidéo Veo déjà générée ou pour sortir un aperçu en GIF.

## Processus de demande

Pour utiliser l'API, vous devez d'abord demander sur la page de service Veo correspondante. Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion.

## Utilisation de base

L'appel de cette interface nécessite deux paramètres :

- `video_id` : l'ID de la tâche de la vidéo source. Cela peut être l'ID vidéo généré par n'importe quelle interface parmi `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action` : action de suréchantillonnage, prenant en charge les trois suivantes :
  - `1080p` : suréchantillonner la vidéo à une résolution de 1080p.
  - `4k` : suréchantillonner la vidéo à une résolution 4K.
  - `gif` : convertir la vidéo en aperçu GIF.

Exemple de requête :

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

Le résultat retourné est identique à celui de `/veo/videos`, il s'agit toujours d'une structure de tâche asynchrone, vous pouvez vérifier l'état de la tâche via `task_id` dans l'interface `/veo/tasks` :

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Description des champs retournés :

- `success` : indique si la tâche de suréchantillonnage a été soumise avec succès.
- `task_id` : l'ID de la tâche de suréchantillonnage actuelle.
- `data` : les résultats de la vidéo après suréchantillonnage.
  - `video_url` : l'adresse de la vidéo après suréchantillonnage.

## Informations de facturation

- `action=1080p` : 0,16 Crédit / fois
- `action=4k` : 0,50 Crédit / fois
- `action=gif` : 0,13 Crédit / fois

Si l'`action` transmise n'est pas dans les énumérations ci-dessus, elle sera facturée par défaut à 0,50 Crédit. Il est conseillé de transmettre explicitement les valeurs prises en charge.

## Rappel asynchrone

L'interface prend également en charge le mode asynchrone, en transmettant `callback_url`, vous pouvez recevoir les résultats par une requête POST après l'achèvement de la tâche. Si vous n'avez pas d'adresse de rappel publique, vous pouvez également définir `async` sur `true`, l'interface renverra immédiatement `task_id`, puis vous pourrez interroger les résultats via l'interface de requête de tâche correspondante.
