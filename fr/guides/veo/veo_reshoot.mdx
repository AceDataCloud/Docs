Cet article présentera les instructions pour l'intégration de l'API Veo Reshoot. Cette interface est utilisée pour **regénérer** une vidéo Veo déjà créée selon **un nouveau type de mouvement de caméra**, tout en maintenant le contenu visuel identique, mais les positions et mouvements de la caméra seront réinterprétés selon `motion_type`.

## Processus de demande

Pour utiliser l'API, vous devez d'abord faire une demande sur la page de service Veo correspondante. Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion.

## Utilisation de base

L'appel de cette interface nécessite de transmettre les paramètres suivants :

- `video_id` (obligatoire) : l'ID de la tâche de la vidéo source. **Ne peut pas** être une vidéo de sortie de `/veo/extend`.
- `motion_type` (obligatoire) : le nouveau type de mouvement de caméra, en utilisant un alias concis en style majuscules et soulignés.

### Valeurs supportées pour `motion_type`

| Alias                             | Signification           |
| ------------------------------ | --------------------- |
| `STATIONARY`                   | Caméra fixe            |
| `STATIONARY_UP`                | Caméra fixe, inclinaison vers le haut |
| `STATIONARY_DOWN`              | Caméra fixe, inclinaison vers le bas |
| `STATIONARY_LEFT`              | Caméra fixe, panoramique à gauche |
| `STATIONARY_RIGHT`             | Caméra fixe, panoramique à droite |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Caméra fixe, poussée avant + zoom arrière |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Caméra fixe, recul + zoom avant |
| `UP`                           | Caméra en montée       |
| `DOWN`                         | Caméra en descente     |
| `LEFT_TO_RIGHT`                | Caméra se déplaçant de gauche à droite |
| `RIGHT_TO_LEFT`                | Caméra se déplaçant de droite à gauche |
| `FORWARD`                      | Caméra avançant        |
| `BACKWARD`                     | Caméra reculant        |
| `DOLLY_IN_ZOOM_OUT`            | Avance en mouvement + zoom arrière |
| `DOLLY_OUT_ZOOM_IN`            | Recul en mouvement + zoom avant |

Exemple de requête :

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

La structure des résultats retournés est identique à celle de `/veo/videos`.

## Callback asynchrone

L'interface prend en charge le mode asynchrone, en transmettant `callback_url`, vous pouvez recevoir les résultats par une requête POST après l'achèvement de la tâche. Si vous n'avez pas d'adresse de rappel publique, vous pouvez également définir `async` sur `true`, l'interface renverra immédiatement `task_id`, puis vous pourrez interroger le résultat via l'interface de requête de tâche correspondante.
