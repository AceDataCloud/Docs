Cet article présentera les instructions pour l'intégration de l'API Veo Extend. Cette interface est utilisée pour **étendre la durée** d'une vidéo Veo déjà générée, l'IA écrira automatiquement les scènes suivantes.

## Processus de demande

Pour utiliser l'API, vous devez d'abord demander sur la page de service Veo correspondante. Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion.

## Utilisation de base

L'appel de cette interface nécessite de transmettre les paramètres suivants :

- `video_id` (obligatoire) : l'ID de tâche de la vidéo source (provenant de `/veo/videos` ou de cette interface elle-même).
- `model` (obligatoire) : le modèle utilisé pour l'extension, **seuls les modèles `veo31-fast` et `veo31` sont pris en charge**, d'autres modèles ne sont pas pris en charge en amont.
- `prompt` (facultatif) : un texte d'invite pour guider l'extension des scènes.
- `aspect_ratio` (facultatif) : `16:9` ou `9:16`, par défaut `16:9`.
- `resolution` (facultatif) : `720p` ou `1080p`.

Exemple de requête :

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "la caméra effectue un zoom arrière lent pour révéler davantage de paysage"
  }'
```

Le résultat de la réponse est identique à celui de `/veo/videos` :

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Limitations importantes

`video_id` doit provenir de la génération de la ligne TTAPI ou de l'ID `data[].id` après l'extension. Les ID de vidéos historiques générés par l'ancienne ligne avant le changement de TTAPI ne peuvent pas être utilisés avec cette interface, un appel renverra `400 bad_request` ; veuillez régénérer via `/veo/videos` avant d'étendre.

Les vidéos résultant de l'extension provenant de `/veo/extend` peuvent **être à nouveau étendues par `/veo/extend`**, mais **ne peuvent pas** être traitées par les interfaces suivantes :

- `/veo/reshoot` —— ne peut pas changer le mouvement de la caméra
- `/veo/objects` —— ne peut pas ajouter ou supprimer des objets

Si le `video_id` fourni est le résultat d'une extension, les interfaces connexes renverront une erreur 400, veuillez utiliser la vidéo originale comme source.

## Informations de facturation

- `model=veo31-fast` : 1.68 Crédit / fois
- `model=veo31` : 12.00 Crédits / fois

## Callback asynchrone

L'interface prend en charge le mode asynchrone, en passant `callback_url`, vous pouvez recevoir les résultats par une requête POST après l'achèvement de la tâche. Si vous n'avez pas d'adresse de rappel publique, vous pouvez également définir `async` sur `true`, l'interface renverra immédiatement `task_id`, puis vous pourrez interroger le résultat via l'interface de requête de tâche correspondante.
