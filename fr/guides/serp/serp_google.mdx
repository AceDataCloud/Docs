Google SERP (Search Engine Results Page) est la page de résultats que les utilisateurs voient après avoir saisi une requête dans le moteur de recherche Google. Elle affiche des résultats de recherche naturels, des publicités, des extraits en vedette, des graphiques de connaissances ainsi que divers contenus tels que des images et des vidéos, dans le but de fournir aux utilisateurs les informations les plus pertinentes.

Cet article présentera en détail l'API Google SERP, qui peut fournir des résultats en fonction des requêtes saisies dans le moteur de recherche Google, les résultats contenant également de nombreux types, tels que des extraits en vedette, des graphiques de connaissances et des images.

Ce document expliquera les instructions de connexion à l'API Google SERP.

## Processus de demande

Pour utiliser l'API Google SERP, vous devez d'abord vous rendre sur la page correspondante de [Google SERP API](https://platform.acedata.cloud/documents/serp-google) pour demander le service correspondant. Une fois sur la page, cliquez sur le bouton « Acquire », comme indiqué dans l'image ci-dessous :

![](https://cdn.acedata.cloud/q6ytrc.png)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion vous invitant à vous inscrire et à vous connecter. Après vous être connecté ou inscrit, vous serez automatiquement renvoyé à la page actuelle.

Lors de la première demande, un quota gratuit sera offert, vous permettant d'utiliser cette API gratuitement.

## Utilisation de base

Tout d'abord, comprenez la méthode d'utilisation de base, qui consiste à saisir le type de ressource de recherche et les mots-clés pour obtenir les résultats de recherche. Il suffit de transmettre le champ `query` et de spécifier le modèle correspondant.

Par exemple, pour rechercher des informations sur « apple inc », nous pouvons ensuite remplir le contenu correspondant sur l'interface, comme indiqué dans l'image ci-dessous :

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Nous pouvons voir ici que nous avons configuré les en-têtes de requête, y compris :

- `accept` : le format de réponse souhaité, ici rempli avec `application/json`, c'est-à-dire au format JSON.
- `authorization` : la clé d'API pour appeler l'API, que vous pouvez sélectionner directement après la demande.

De plus, nous avons configuré le corps de la requête, y compris :

- `type` : le type de ressource de recherche, actuellement seulement six types sont pris en charge, le défaut étant `search`.
- `query` : les mots-clés de recherche.
- `country` : le pays des résultats de recherche personnalisés, le défaut étant les États-Unis (US).
- `language` : la langue des résultats de recherche personnalisés, le défaut étant l'anglais (en).
- `range` : la plage de temps des résultats de recherche personnalisés, le défaut étant sans restriction.
- `number` : la taille de la page de résultats de recherche personnalisés, le défaut étant 10.
- `page` : le numéro de la page de résultats de recherche personnalisés, le défaut étant 1.

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Le code d'intégration Python est comme suit :

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Type de recherche personnalisé

Si vous personnalisez le type de ressource de recherche, nous pouvons modifier le paramètre `type`, qui comprend respectivement les ressources ordinaires `search`, les ressources d'images `images`, les ressources d'actualités `news`, les ressources de cartes `maps`, les ressources de régions `places`, les ressources vidéo `videos`, cet article fera une démonstration avec les ressources vidéo `videos`.

## Plage de temps personnalisée pour les résultats de recherche

curl -X POST 'https://api.acedata.cloud/serp/google' \

-d '{
  "range": "qdr:d",
  "query": "apple inc"
