Ce document présente l’intégration et l’utilisation de l’API Nano Banana Images. Cette interface prend en charge deux fonctionnalités : **la génération d’images (generate)** et **la modification d’images (edit)**.

## Procédure de demande

Pour utiliser l’API Nano Banana Images, rendez-vous d’abord sur le [tableau de bord Ace Data Cloud](https://platform.acedata.cloud/console/applications) afin d’obtenir votre API Token et de le conserver pour une utilisation ultérieure.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n’êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion, où vous serez invité à vous inscrire et à vous connecter. Une fois cette étape terminée, vous serez automatiquement redirigé vers la page actuelle.

**Un seul API Token suffit pour appeler tous les services de la plateforme. Il n’est pas nécessaire d’en demander un séparément pour chaque service.** Lors de votre première demande, un crédit gratuit vous sera offert pour tester le service gratuitement. Lorsque votre solde est insuffisant, vous pouvez recharger votre solde général dans le [tableau de bord](https://platform.acedata.cloud/console/coin).

> 📘 Documentation complète : [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Présentation de l’interface

- **URL de base (Base URL)** : `https://api.acedata.cloud`
- **Endpoint** : `POST /nano-banana/images`
- **Méthode d’authentification** : transmettre `authorization: Bearer {token}` dans l’en-tête HTTP.
- **En-têtes de requête** :
  - `accept: application/json`
  - `content-type: application/json`
- **Action (action)** :
  - `generate` : générer une image à partir d’un prompt textuel
  - `edit` : modifier une image fournie
- **Modèle (model)** (facultatif) :
  - `nano-banana` (par défaut) : basé sur Gemini 2.5 Flash Image, rapide et économique
  - `nano-banana-2-lite` : basé sur Gemini 3.1 Flash Lite Image, prend uniquement en charge le format 1K et offre une vitesse de génération élevée
  - `nano-banana-2` : basé sur Gemini 3.1 Flash Image Preview, qualité de niveau Pro + vitesse Flash
  - `nano-banana-2.1` : nouveau modèle d’image performant de nouvelle génération, prenant en charge la génération et la modification d’images en 1K, 2K et 4K
  - `nano-banana-pro` : basé sur Gemini 3 Pro Image Preview, qualité maximale
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official` : versions des canaux officiels des modèles correspondants, offrant une meilleure qualité d’image et une meilleure stabilité, avec une facturation différente
- **Rappel asynchrone** : facultatif, permet de recevoir une notification de fin de tâche et les résultats via `callback_url`
- **Nombre d’images** : facultatif, permet de spécifier de 1 à 4 images via `count`, avec une valeur par défaut de 1 image ; chaque image est générée par un appel indépendant ; un échec technique ordinaire ou un refus de sécurité du fournisseur n’affecte que l’appel correspondant, les autres images générées avec succès sont renvoyées normalement et la facturation est basée sur le nombre réel d’images générées avec succès.

## Démarrage rapide : générer des images (`action=generate`)

**Paramètres minimaux obligatoires** : `action`, `prompt`

Lorsque vous souhaitez simplement générer directement une image à partir d’un prompt, il suffit de définir `action` sur `generate` et de fournir un `prompt` clair.

### Exemple de requête (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Exemple de requête (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Exemple de réponse en cas de succès

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### Description des champs

- `success` : indique si la requête actuelle a réussi.
- `task_id` : ID de la tâche.
- `trace_id` : ID de suivi de la chaîne, permettant de faciliter le diagnostic des problèmes.
- `count` : nombre d’images demandées pour la génération ou la modification, prend en charge de 1 à 4 images, avec une valeur par défaut de 1. `data` contient uniquement les images générées avec succès et la facturation est calculée en fonction du nombre réel d’images renvoyées. Chaque appel de génération applique obligatoirement la politique de sécurité native du fournisseur ; le refus d’un appel n’affecte pas les autres appels réussis. Si tous les appels sont refusés, une erreur 403 est renvoyée.
- `data[]` : liste des résultats.
  - `prompt` : prompt utilisé pour la génération (renvoyé en écho).
  - `image_url` : URL directe de l’image générée.

> Remarque : `/nano-banana/images` nécessite uniquement `action` et `prompt` pour générer des images.

## Modifier des images (`action=edit`)

Lorsque vous souhaitez modifier une image existante, définissez `action` sur `edit` et transmettez la liste des liens des images à modifier (une ou plusieurs) via `image_urls`, tout en fournissant un `prompt` décrivant l’objectif de la modification.

Par exemple, si nous fournissons ici une photo d’une personne et une photo d’un vêtement, afin de faire porter ce vêtement à la personne, nous pouvons transmettre simultanément les liens des images et définir `action` sur `edit`. L’URL peut être une URL HTTP, c’est-à-dire un lien accessible publiquement via le protocole `https` ou `http`, ou une image encodée en Base64, telle que `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Exemple de requête (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Exemple de requête (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Exemple de réponse en cas de succès

```json
{
  "success": true,
  "task_id": "93f11baf-347b-4bb4-9520-8653cb46d6a3",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": [
    {
      "prompt": "let this man wear on this T-shirt",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/8e9e0253-26f4-45b9-b3f8-ac1aed1c284b.png"
    }
  ]
}
```

### Description des champs

- `image_urls[]` : liste des URL des images à modifier (elles doivent être accessibles publiquement sur Internet). Plusieurs images peuvent être transmises ; le service combinera ces ressources avec le `prompt` pour effectuer la modification.
- Les autres champs sont identiques à ceux de la réponse « Générer une image ».

## Rappel asynchrone (facultatif, recommandé)

La génération ou la modification peut prendre un certain temps. Afin d'éviter de mobiliser des ressources avec une connexion longue, il est recommandé d'utiliser un **rappel Webhook** via `callback_url` :

1. Ajoutez `callback_url` dans le corps de la requête, par exemple l'adresse Webhook de votre serveur (elle doit être accessible publiquement et prendre en charge les requêtes POST au format JSON).
2. L'API renverra **immédiatement** une réponse contenant `task_id` (ou un résultat de base).
3. Une fois la tâche terminée, la plateforme enverra le JSON complet à `callback_url` via une requête `POST`. Vous pouvez associer la requête au résultat à l'aide de `task_id`.

**Exemple de charge utile du rappel** (la structure des champs est identique à celle d'une réponse synchrone réussie) :

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Gestion des erreurs

En cas d'échec de l'appel, un format d'erreur standard accompagné d'un ID de suivi sera renvoyé. Voici les erreurs les plus courantes :

- **400 `token_mismatched`** : requête non valide ou erreur dans les paramètres.
- **400 `api_not_implemented`** : interface non implémentée (veuillez contacter le support).
- **401 `invalid_token`** : échec de l'authentification ou Token manquant.
- **403 `forbidden`** : les règles de sécurité natives du fournisseur ont refusé la requête ou le résultat généré. Cet appel ne renverra aucune image et ne sera pas facturé ; une requête contenant plusieurs images peut néanmoins renvoyer et facturer les autres appels réussis.
- **429 `too_many_requests`** : fréquence des requêtes dépassant la limite autorisée.
- **500 `api_error`** : erreur du serveur.

### Exemple de réponse d'erreur

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Correspondance des paramètres et remarques

- **Obligatoires** : `action`, `prompt`
- **Spécifique à la modification** : `image_urls` (tableau contenant au moins 1 élément)
- **Facultatifs** : `model` (par défaut `nano-banana`, avec les options `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro` ; à l'exception de `nano-banana-2.1`, des versions officielles correspondantes du canal officiel sont également disponibles avec le suffixe `:official`), `aspect_ratio` (`auto` ou rapport largeur/hauteur spécifique, tel que `1:1`, `16:9`), `resolution` (résolution, telle que `1K`, `2K`, `4K` ; `nano-banana-2-lite` prend uniquement en charge `1K`), `callback_url` (utilisé pour les rappels asynchrones)
- **En-têtes** : il est obligatoire de fournir `authorization: Bearer {token}` ; il est recommandé de définir `accept` sur `application/json`
- **Accessibilité des images** : `image_urls` doit contenir des liens directs accessibles publiquement sur Internet (HTTP/HTTPS). Il est recommandé d'utiliser HTTPS.
- **Idempotence et suivi** : conservez `task_id` et `trace_id` afin de faciliter le dépannage et l'association des résultats.

La transmission explicite de `"aspect_ratio": "auto"` permet de sélectionner le préréglage le plus proche en fonction du rapport, de l'orientation ou de la mise en page indiqués dans le prompt. Cette option convient à la génération comme à la modification. Par exemple, si le prompt indique « miniature YouTube », le format `16:9` peut être sélectionné. Si le prompt ne précise aucune exigence de dimensions ou si la détection automatique n'est pas disponible, la génération de texte en image utilise le format par défaut, tandis que la modification d'image suit la première image de référence et utilise le rapport pris en charge le plus proche. Si ce champ est omis, le format par défaut ou le rapport de l'image de référence sera utilisé. Lorsque les exigences relatives au format sont déjà clairement définies, transmettez directement le rapport spécifique.
