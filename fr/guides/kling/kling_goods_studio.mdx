Soumettez une tâche via `POST /kling/goods-studio`, utilisez le `POST /kling/tasks` existant pour interroger l’état des tâches de la plateforme.

## Entrée

Fournissez 1 à 5 images du produit et un titre de produit de 200 caractères maximum ; la description du produit est facultative, 2000 caractères maximum. La durée peut être de 15, 30 ou 60 secondes.

Voici un exemple de structure de requête, veuillez remplacer l’URL de la ressource avant l’appel.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "Votre produit ou contenu de présentation orale"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Résultats et facturation

Le mode synchrone renvoie le résultat généré ; le mode asynchrone renvoie d’abord un `task_id`, le résultat final contient les liens vers les vidéos ou images dans `data` ainsi que l’`usage` calculé par le serveur. `callback_url` est utilisé pour la notification de fin ; une requête avec `watermark=true` renvoie également une version avec filigrane.

720p : 2,38 Credits/seconde ; 1080p : 2,8 Credits/seconde. Les vidéos sont facturées selon la durée réellement générée, le prix de base par seconde avant la génération ne représente pas le prix total de l’ensemble de la tâche. Les tâches échouées ne sont pas facturées pour la génération.
