Faites "parler" une **vidéo Kling existante** (5 secondes ou 10 secondes) selon un audio ou un texte — c'est-à-dire synchronisation labiale (Lip Sync). En combinaison avec `/kling/videos` et `image2video` (pour animer des photos), cela permet de créer un processus complet de "**photo parlante / avatar numérique**".

> Cette interface est une encapsulation simple fournie par AceDataCloud, destinée aux scénarios courants basés sur l'audio/le texte ; ce n'est pas un miroir des champs de l'interface multi-étapes officielle de Kling « Reconnaissance faciale → Synchronisation labiale avancée ». Veuillez vous référer au tableau des paramètres de cette page.

- **Adresse de l'API** : `POST https://api.acedata.cloud/kling/lip-sync`
- **Format de la requête** : `application/json`
- **Format de la réponse** : `application/json`
- **Facturation** : **2,45 crédits** par appel réussi (fixe)

## En-têtes de requête (Request Headers)

| Champ              | Valeur                   | Description                                           |
| ----------------- | ----------------------- | ---------------------------------------------------- |
| `authorization`   | `Bearer ${API_KEY}`     | Votre clé API, [adresse d'obtention](https://platform.acedata.cloud) |
| `content-type`    | `application/json`      | Format du corps de la requête                        |
| `accept`          | `application/json`      | Format de la réponse                                  |

## Paramètres de requête (Request Body)

| Paramètre         | Type     | Obligatoire | Par défaut | Description                                                                                                           |
| ----------------- | -------- | ----------- | ---------- | -------------------------------------------------------------------------------------------------------------------- |
| `mode`            | string   | Oui         | —          | Mode de génération. Énumération : `audio2video` (piloté par audio), `text2video` (piloté par texte)                 |
| `video_id`        | string   | Un des deux | —          | ID de la vidéo générée par Kling (comme le `video_id` retourné par `image2video` de `/kling/videos`). **Supporte uniquement les vidéos de 5s/10s générées dans les 30 jours**. `video_id` et `video_url` sont exclusifs, ne peuvent pas être transmis simultanément |
| `video_url`       | string   | Un des deux | —          | Lien vidéo accessible publiquement. Contraintes : `.mp4`/`.mov`, ≤100MB, durée 2–10s, uniquement 720p/1080p, dimensions 720–1920px. Exclusif avec `video_id` |
| `audio_url`       | string   | Conditionnel | —          | URL de téléchargement de l'audio pilote, requis lorsque `audio2video` + `audio_type=url`. Formats `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB |
| `audio_type`      | string   | Non         | `url`      | Méthode de transmission de l'audio. Énumération : `url`, `file` (valide lors de `audio2video`)                       |
| `audio_file`      | string   | Conditionnel | —          | Fichier audio en Base64, requis lorsque `audio_type=file`. Formats comme ci-dessus, ≤5MB                             |
| `text`            | string   | Conditionnel | —          | Texte à lire, requis lors de `text2video`, **maximum 120 caractères**                                               |
| `voice_id`        | string   | Conditionnel | —          | ID de la voix, requis lors de `text2video`                                                                          |
| `voice_language`  | string   | Non         | `zh`       | Langue de la voix. Énumération : `zh`, `en` (valide lors de `text2video`)                                           |
| `voice_speed`     | float    | Non         | `1.0`      | Vitesse de la parole, plage `0.8`–`2.0`, précision à un chiffre décimal (valide lors de `text2video`)               |
| `callback_url`    | string   | Non         | —          | Adresse de rappel. Si ce champ ou `async=true` est fourni, alors **mode asynchrone** : retourne immédiatement `task_id`, puis rappelle après la génération des résultats |
| `async`           | boolean  | Non         | `false`    | Mode asynchrone. Si `true`, retourne immédiatement `task_id`, à utiliser avec `/kling/tasks` pour le polling ou `callback_url` pour le rappel |

## Exemples de requête

### 1) Piloté par audio (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Piloté par texte (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Frère, ça fait longtemps, je vais bien, prends soin de toi.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Exemple de réponse (succès synchronisé)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Champ          | Type     | Description                                     |
| -------------- | -------- | ----------------------------------------------- |
| `success`      | boolean  | Indique si l'opération a réussi                 |
| `task_id`      | string   | ID de la tâche actuelle (peut être utilisé pour interroger `/kling/tasks`) |
| `video_id`     | string   | ID Kling de la vidéo générée (peut être utilisé comme entrée pour la prochaine `extend`/`lip-sync`) |
| `video_url`    | string   | URL de la vidéo parlante générée (stockée sur le CDN de cette plateforme, valable à long terme) |
| `duration`     | string   | Durée de la vidéo (en secondes)                 |
| `state`        | string   | État de la tâche : `succeed` / `failed`        |

## Mode asynchrone et requête

En fournissant `callback_url` ou `async: true`, l'interface **retourne immédiatement** `task_id` ; ensuite, vous pouvez :

- **Interroger** : `POST /kling/tasks`, corps `{ "action": "retrieve", "id": "<task_id>" }` (gratuit)
- **Rappel** : Après la génération, le résultat est envoyé par POST à votre `callback_url`

## Processus complet : photo parlante (image2video → lip-sync)
```bash
# Étape 1 : Faites bouger la photo, obtenez le video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"regardez la caméra, naturel","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Étape 2 : Synchronisez les lèvres avec l'audio
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Réponse d'erreur

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "l'un des video_id ou video_url est requis" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | Signification                                         |
| ---- | ----------------------- | ---------------------------------------------------- |
| 400  | `bad_request`           | Paramètres manquants ou illégaux (comme mode non transmis, conflit entre video et audio, texte dépassant 120 caractères) |
| 401  | `authorization_missing` | Clé API manquante ou invalide                         |
| 403  | `forbidden`             | Contenu intercepté par le contrôle de risque          |
| 429  | `too_many_requests`     | Limite de concurrence en amont, veuillez réessayer plus tard |
| 500  | `api_error`             | Erreur en amont ou interne                            |

## Remarques

- `video_id` doit être une vidéo Kling générée **dans les 30 jours** et d'une durée de **5s ou 10s** ; sinon, veuillez utiliser `video_url` pour transmettre une vidéo conforme aux contraintes.
- La vidéo d'entrée doit être **claire, de face, et d'une seule personne**, l'effet de synchronisation des lèvres sera meilleur.
- La durée de l'audio/texte doit correspondre à la durée de la vidéo (l'audio ne doit pas dépasser la longueur de la vidéo).
- La facturation se produit lors de la **réussite** (2,45 crédits par fois) ; les échecs de validation des paramètres (4xx) ne sont pas facturés.
