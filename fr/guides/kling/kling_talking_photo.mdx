---
title: "API de Photo Parlante Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Transformez **une photo + un audio** en une vidéo « parlante » en un clic. Le service effectue automatiquement deux étapes en interne : d'abord, il utilise image2video pour animer la photo, puis il synchronise les lèvres avec l'audio. Vous n'avez qu'à appeler **une seule fois**.

- **URL de l'API** : `POST https://api.acedata.cloud/kling/talking-photo`
- **Facturation** : par durée, 5 secondes **16,45 Crédits**, 10 secondes **30,45 Crédits** (= prix combiné image2video + lip-sync)

## En-têtes de la requête

| Champ              | Valeur                 |
| ----------------- | --------------------- |
| `authorization`   | `Bearer ${API_KEY}`   |
| `content-type`    | `application/json`    |

## Paramètres de la requête

| Paramètre        | Type      | Obligatoire | Par défaut              | Description                                  |
| ---------------- | --------- | ----------- | ----------------------- | -------------------------------------------- |
| `image_url`      | string    | Oui         | —                       | URL publique de la photo de la personne, recommandé visage clair et de face |
| `audio_url`      | string    | Oui         | —                       | URL publique de l'audio ( .mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`         | string    | Non         | —                       | Mots d'indication pour les actions/expressions lors de l'animation de la photo |
| `model`          | string    | Non         | `kling-v2-1-master`    | Modèle Kling utilisé pour l'animation de la photo |
| `duration`       | integer   | Non         | `5`                     | Durée de la vidéo (5 ou 10 secondes)        |
| `mode`           | string    | Non         | `pro`                   | Qualité de l'animation (std/pro)            |
| `callback_url`   | string    | Non         | —                       | Si fourni ou `async=true`, retour asynchrone de task_id |
| `async`          | boolean   | Non         | `false`                 | Mode asynchrone, à utiliser avec `/kling/tasks` pour le polling ou le callback |

## Exemple de requête

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Exemple de réponse

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Champ                | Description                                |
| ------------------- | ------------------------------------------ |
| `video_url`         | La vidéo finale parlante (stockée sur le CDN de la plateforme) |
| `source_video_url`  | La vidéo intermédiaire d'animation de la photo (résultat de image2video) |
| `video_id`          | ID de la vidéo parlante Kling              |

## Remarques

- Il est recommandé que la photo soit claire, de face et d'une seule personne.
- La durée de l'audio ne doit pas dépasser la durée de la vidéo (5s/10s).
- La facturation se produit lors du succès ; l'échec de la validation des paramètres (4xx) ne sera pas facturé.
- Le temps de génération est d'environ 4 à 6 minutes (deux étapes), il est conseillé d'utiliser `async=true` + `/kling/tasks` pour le polling.
