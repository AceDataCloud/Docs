---
title: "API de photo parlante Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Transformez en un clic **une photo + un segment audio** en une « vidéo parlante ». Le service effectue automatiquement deux étapes en interne : utilise d'abord image2video pour animer la photo, puis lip-sync pour synchroniser les lèvres avec l'audio. Vous n'avez besoin d'effectuer **qu'un seul** appel.

- **Adresse de l'interface** : `POST https://api.acedata.cloud/kling/talking-photo`
- **Facturation** : selon la durée, 5 secondes **16.45 Credits**, 10 secondes **30.45 Credits** (= prix combiné image2video + lip-sync)

## En-têtes de requête

| Champ              | Valeur              |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Paramètres de requête

| Paramètre      | Type    | Obligatoire | Par défaut           | Description                                      |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Oui   | —                   | URL publique de la photo de la personne, un visage net de face est recommandé |
| `audio_url`    | string  | Oui   | —                   | URL publique de l'audio pilote (.mp3/.wav/.m4a/.aac,≤5MB) |
| `prompt`       | string  | Non   | —                   | Mots-clés d'action/expression pour l'étape d'animation de la photo |
| `model`        | string  | Non   | `kling-v2-1-master` | Modèle Kling utilisé pour l'animation de la photo |
| `duration`     | integer | Non   | `5`                 | Durée de la vidéo (5 ou 10 secondes) |
| `mode`         | string  | Non   | `pro`               | Qualité de l'animation (std/pro) |
| `callback_url` | string  | Non   | —                   | Si renseigné ou si `async=true`, retourne `task_id` de manière asynchrone |
| `async`        | boolean | Non   | `false`             | Mode asynchrone, à utiliser avec le polling ou le rappel de `/kling/tasks` |

## Exemple de requête

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Exemple de réponse

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Champ              | Description                        |
| ------------------ | ------------------------- |
| `video_url`        | La vidéo parlante finale (déjà transférée vers le CDN de cette plateforme) |
| `source_video_url` | La vidéo intermédiaire d'animation de la photo (résultat image2video) |
| `video_id`         | ID de vidéo Kling                   |

## Remarques

- Il est recommandé que la photo soit nette, prise de face et ne comporte qu'une seule personne.
- Il est recommandé que la durée de l'audio ne dépasse pas celle de la vidéo (5 s/10 s).
- La facturation intervient en cas de réussite ; les échecs de validation des paramètres (4xx) ne sont pas facturés.
- Le temps de génération est d'environ 4 à 6 minutes (deux étapes) ; il est recommandé d'utiliser `async=true` + le polling de `/kling/tasks`.
