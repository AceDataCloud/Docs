Soumettez des tâches via `POST /kling/apparel`, utilisez le `POST /kling/tasks` existant pour consulter l’état des tâches de la plateforme.

## Entrée

Fournissez une description de produit de 2 500 caractères maximum, une vidéo de référence de 5 à 180 secondes et 1 à 5 images du produit. Vous pouvez également fournir 1 à 5 images de mannequin, un fichier de musique de fond, et spécifier une voix de doublage ; lorsqu’aucune voix n’est spécifiée, la présentation orale native est utilisée.

Voici un exemple de structure de requête, veuillez appeler après avoir remplacé les URL des ressources.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Résultats et facturation

Le mode synchrone renvoie le résultat généré ; le mode asynchrone renvoie d’abord le `task_id`, le résultat final contient les liens de vidéo ou d’image dans `data` ainsi que le `usage` calculé par le serveur. `callback_url` est utilisé pour les notifications de fin ; une requête avec `watermark=true` renvoie simultanément une version avec filigrane.

Présentation orale native : 1,82 Credits/seconde pour 720p, 2,38 Credits/seconde pour 1080p ; doublage spécifié : 2,38 Credits/seconde pour 720p, 2,8 Credits/seconde pour 1080p. Les vidéos sont facturées selon la durée réelle générée ; le prix de base par seconde avant la génération ne représente pas le prix total de l’ensemble de la tâche. Les tâches échouées ne sont pas facturées pour la génération.
