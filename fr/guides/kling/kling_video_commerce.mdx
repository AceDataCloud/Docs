Soumettez une tâche via `POST /kling/video-commerce`, et utilisez l’existant `POST /kling/tasks` pour consulter le statut des tâches de la plateforme.

## Entrée

Téléchargez une image de personnage et spécifiez un voice_id, ou utilisez un avatar_id prédéfini (les deux s’excluent mutuellement, et un personnage prédéfini ne peut pas spécifier un voice_id séparément). Vous devez fournir un speech_script de 2 000 caractères maximum. Lorsque vous fournissez des informations sur le produit, vous avez besoin d’au moins une ref_image et d’un goods_title ; la présentation orale de produit ne prend pas en charge speech_rate. La présentation orale de personnage standard prend en charge une vitesse de parole de 0,8, 1,0 ou 1,2 fois.

Voici un exemple de structure de requête, veuillez remplacer les URL des ressources avant d’appeler.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Résultats et facturation

Le mode synchrone renvoie le résultat généré ; le mode asynchrone renvoie d’abord un `task_id`, et le résultat final contient dans `data` les liens vidéo ou image ainsi que l’`usage` calculé côté serveur. `callback_url` est utilisé pour la notification de fin ; une requête avec `watermark=true` renvoie simultanément une version avec filigrane.

Présentation orale de personnage standard : 1,4 Credits/seconde en 720p, 1,68 Credits/seconde en 1080p ; présentation orale de produit : 1,96 Credits/seconde en 720p, 2,24 Credits/seconde en 1080p. Les vidéos sont facturées selon la durée réellement générée ; le prix de base par seconde avant la génération ne représente pas le prix total de l’ensemble de la tâche. Les tâches ayant échoué ne sont pas facturées pour la génération.
