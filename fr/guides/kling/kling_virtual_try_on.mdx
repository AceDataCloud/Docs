Soumettez une tâche via `POST /kling/virtual-try-on`, utilisez l’existant `POST /kling/tasks` pour consulter l’état des tâches de la plateforme.

## Entrée

Vous devez fournir exactement une product_image et une person_image. keep_face, keep_pose, keep_background sont tous true par défaut et peuvent être désactivés indépendamment. Le côté le plus long de l’image d’entrée ne doit pas dépasser 2048px, le côté le plus court doit être supérieur à 300px, et le fichier ne doit pas dépasser 10MB.

Voici un exemple de structure de requête, veuillez appeler après avoir remplacé les URL des ressources.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Résultats et facturation

Le mode synchrone retourne le résultat généré ; le mode asynchrone retourne d’abord `task_id`, et le résultat final contient dans `data` les liens vidéo ou image ainsi que le `usage` calculé par le serveur. `callback_url` est utilisé pour les notifications de fin ; la requête `watermark=true` retourne également une version avec filigrane.

1.12 Credits/image, facturé selon le nombre réel d’images produites. Les vidéos sont facturées selon la durée réellement générée ; le prix de base par seconde avant la génération ne représente pas le prix total de l’ensemble de la tâche. Les tâches échouées ne sont pas facturées pour la génération.
