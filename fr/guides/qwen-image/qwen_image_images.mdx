---
title: "API de génération et d’édition Qwen Image"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` permet de réaliser, via la même interface, la génération d’images à partir de texte et l’édition avec 1 à 3 images de référence, avec prise en charge de `qwen-image-3.0` et `qwen-image-3.0-pro`.

## Choisir un modèle

| Modèle                   | Cas d’usage adaptés       | Prix standard officiel                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Création en lot, itération rapide  | Sortie $0.030/image             |
| `qwen-image-3.0-pro` | Mise en page complexe, rendu final haute précision | 1K $0.040/image ; 2K $0.075/image |

Les images de référence sont facturées selon la quantité réelle fournie, au prix standard officiel de $0.003/image.

## Génération synchrone

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

La réponse réussie contient une adresse d’image CDN permanente, l’usage réel et le coût de cette requête :

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Édition avec images de référence

Ajoutez `image_urls`, avec prise en charge de 1 à 3 images publiquement accessibles :

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` est uniquement utilisé pour la génération d’images à partir de texte. La plage de `n` est de 1 à 6 ; le rapport largeur-hauteur doit être compris entre 1:8 et 8:1.

## Tâches asynchrones

Après avoir défini `async: true`, l’interface renvoie immédiatement un `task_id`. Utilisez `/qwen-image/tasks` pour interroger l’état final, ou fournissez `callback_url` pour recevoir une notification de fin. La génération n’est facturée qu’une seule fois, et les requêtes de consultation des tâches ne sont pas facturées à nouveau.
