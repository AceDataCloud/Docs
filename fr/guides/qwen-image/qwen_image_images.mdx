title: "Guide d'intégration de l'API d'image Qwen"

---

`POST https://api.acedata.cloud/qwen-image/images` prend en charge la génération d'images à partir de texte pour `qwen-image-3.0` et `qwen-image-3.0-pro` ainsi que l'édition de 1 à 3 images de référence.

## Génération d'images à partir de texte

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"une affiche technologique minimaliste","size":"1024*1024","n":1}'
```

## Édition d'images

Ajoutez `image_urls` dans la même requête, prenant en charge 1 à 3 images publiques :

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "conserver le sujet, changer en style d'affiche chaude **###**",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` prend uniquement en charge la génération d'images à partir de texte. `n` varie de 1 à 6. La taille de sortie doit avoir un total de pixels compris entre 512×512 et 2048×2048, avec un rapport d'aspect de 1:8 à 8:1.

## Appel asynchrone

Définir `async: true` permet d'obtenir immédiatement `task_id` ; vous pouvez également passer `callback_url` pour recevoir le résultat final. Une fois terminé, interrogez via `/qwen-image/tasks`.

La réponse réussie contient `data[].image_url`, `usage`, `task_id` et `trace_id`. Les liens d'images seront transférés autant que possible vers le CDN d'Ace Data Cloud. Un exemple de réponse réelle sera ajouté après la validation E2E en production.
