---
title: "API de génération et d'édition d'images Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` permet de réaliser la génération d'images à partir de texte et l'édition de 1 à 3 images de référence via la même interface, prenant en charge `qwen-image-3.0` et `qwen-image-3.0-pro`.

## Choisir un modèle

| Modèle                  | Scénarios adaptés       | Prix standard officiel                   |
| ---------------------- | --------------------- | ------------------------------------- |
| `qwen-image-3.0`      | Création en masse, itération rapide  | Sortie $0.030/image             |
| `qwen-image-3.0-pro`  | Mise en page complexe, haute précision | 1K $0.040/image ; 2K $0.075/image |

Les images de référence sont facturées en fonction du nombre d'entrées réelles, prix standard officiel $0.003/image.

## Génération synchronisée

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Un simple cercle rouge centré sur un fond blanc propre.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

La réponse réussie contient l'adresse CDN permanente de l'image, l'utilisation réelle et le coût de cette opération :

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Édition d'images de référence

Ajoutez `image_urls`, prenant en charge 1 à 3 images accessibles publiquement :

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Conserver le sujet, changer l'arrière-plan en style affiche chaud **###**",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` est uniquement utilisé pour la génération d'images à partir de texte. La plage de `n` est de 1 à 6 ; le rapport largeur/hauteur doit être compris entre 1:8 et 8:1.

## Tâches asynchrones

Après avoir défini `async: true`, l'interface renvoie immédiatement `task_id`. Utilisez `/qwen-image/tasks` pour interroger l'état final, ou passez `callback_url` pour recevoir une notification de fin. La génération est facturée une seule fois, la requête de tâche n'entraîne pas de facturation répétée.
