---
title: "API de requête de tâche Qwen Image"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` est utilisé pour interroger, interroger en masse ou supprimer des tâches asynchrones Qwen Image. Cette interface ne génère pas de consommation API supplémentaire.

## Interroger une seule tâche

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Une fois la tâche terminée, `response.data` contient l'adresse de l'image CDN permanente, `response.usage` contient le nombre réel d'entrées/sorties, et `response.cost` fournit les informations de facturation de la tâche générée.

## Interrogation en masse

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Retourne `{ "items": [...], "count": 2 }`. La requête de liste prend également en charge le filtrage par utilisateur, application et plage de dates de création.

## Supprimer l'historique des tâches

```json
{"action":"delete","id":"TASK_ID"}
```

La suppression n'affecte que l'historique des tâches et ne supprimera pas les fichiers CDN déjà générés.
