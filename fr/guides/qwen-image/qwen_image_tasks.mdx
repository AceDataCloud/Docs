---
title: "Guide d'intégration de l'API de tâches d'image Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Utilisez `POST https://api.acedata.cloud/qwen-image/tasks` pour interroger les tâches de génération d'images asynchrones. Cette interface de requête est gratuite.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Pour une requête en masse, utilisez `action=retrieve_batch` et le tableau `ids`. Une fois la tâche réussie, `response.data` contient l'adresse permanente des images générées ainsi que l'utilisation réelle.
