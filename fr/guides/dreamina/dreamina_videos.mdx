## API de génération de vidéos numériques Dreamina

`POST https://api.acedata.cloud/dreamina/videos`

Génération de vidéos de narration numérique pilotées par audio (OmniHuman 1.5). Fournissez une photo de la personne et un audio de pilotage pour générer une vidéo où la personne parle avec synchronisation labiale.

### En-têtes de requête

| En-tête          | Valeur                     |
| ---------------- | ------------------------- |
| `Authorization`  | `Bearer <votre clé API>`  |
| `Content-Type`   | `application/json`        |

### Paramètres de requête

| Paramètre        | Type     | Obligatoire | Description                                                              |
| ---------------- | -------- | ----------- | ------------------------------------------------------------------------ |
| `model`          | string   | Non         | Modèle, par défaut `omnihuman-1.5`                                      |
| `image_url`      | string   | Oui         | URL publique de la photo de la personne, une image claire de face est recommandée |
| `audio_url`      | string   | Oui         | URL publique de l'audio de pilotage (mp3/wav), recommandé &lt; 60 secondes  |
| `prompt`         | string   | Non         | Contrôle des expressions, émotions, stabilité et style                   |
| `mask_url`       | string[] | Non         | URL de masque principal, utilisée pour spécifier l'objet à piloter dans une image de groupe |
| `callback_url`   | string   | Non         | Si fourni, retourne immédiatement `task_id`, et rappelle cette adresse après la génération des résultats |
| `async`          | boolean  | Non         | Si défini sur `true`, retourne immédiatement `task_id`, sans besoin de `callback_url`, en interrogeant les résultats via `/dreamina/tasks` |

### Suggestions d'entrée

- **Image** : Un portrait frontal clair et bien éclairé est optimal ; le visage doit être dégagé et occuper une proportion adéquate de l'image.
- **Audio** : mp3/wav, doit être accessible publiquement. La durée recommandée est de 60 secondes maximum (1080p recommandé ≤30 secondes, 720p ≤60 secondes).
- `image_url` et `audio_url` doivent tous deux être accessibles publiquement.

### Exemple de réponse

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": {
    "task_id": "362b4fed67bd11f1ad1100163e57d510",
    "status": "done",
    "video_url": "https://cdn.acedata.cloud/634d760216.mp4",
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }

```

### Asynchrone et requête

L'interface retourne par défaut la vidéo finale de manière synchrone. Pour des tâches plus longues, vous pouvez utiliser l'un des deux modes asynchrones :

- Fournir `callback_url` : l'interface retourne immédiatement `task_id`, et rappelle cette adresse après la génération des résultats.
- Fournir `async: true` : l'interface retourne immédiatement `task_id`, puis interrogez les résultats via `POST /dreamina/tasks` (gratuit) en utilisant `task_id` ou `trace_id`.

Pour plus de détails sur l'interrogation, voir [API des tâches Dreamina](https://platform.acedata.cloud/documents/dreamina-tasks-integration).

### Gestion des erreurs

| Code d'état | code                                      | Signification                             |
| ----------- | ----------------------------------------- | ---------------------------------------- |
| 400         | `bad_request`                             | Paramètres manquants ou invalides (comme `image_url` / `audio_url`) |
| 401         | `authorization_missing` / `invalid_token` | Jeton d'autorisation manquant ou invalide |
| 403         | `forbidden`                               | Solde/quotas insuffisants, ou non autorisé en amont |
| 429         | `too_many_requests`                       | Trop de requêtes, dépassement de la limite de taux |
| 500         | `api_error`                               | Erreur interne du serveur                |

```json
{
  "error": {
    "code": "bad_request",
    "message": "image_url is required (a public URL of a portrait image)"
  },
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

### Facturation

Facturation basée sur la durée de la vidéo générée, le tarif maximum est d'environ **¥1/seconde** (par exemple, une vidéo de 10 secondes coûte environ ¥10).
