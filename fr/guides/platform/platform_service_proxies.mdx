---
title: "Obtenir la liste des Proxy sous un service de la plateforme AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Renvoie de manière paginée les points de terminaison Proxy montés sur ce service via le Service UUID. Avec uniquement un alias, appelez d’abord les [détails du service](https://platform.acedata.cloud/documents/platform-service-detail) pour obtenir `id`.

## Aperçu de l’interface

| Élément   | Contenu                                                                |
| --- | ---------------------------------------------------------------------- |
| Méthode  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Authentification  | Public, aucun jeton de compte requis                                                              |
| Pagination  | `count` + `items`                                                      |

## Paramètres

| Paramètre                 | Emplacement    | Obligatoire  | Description                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Oui   | Service UUID, alias non pris en charge           |
| `limit` / `offset` | query | Non   | Pagination                               |
| `ordering`         | query | Non   | Expression de tri Django ; `rank` ou `-rank` recommandé |

```shell
export SERVICE_ID='votre Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Description de la réponse

Les éléments de la liste sont sérialisés par le modèle Proxy, et les champs vérifiés en ligne incluent `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` et les champs temporels.

- Le champ d’entrée métier est `endpoint`, et non `path`.
- Le champ de tarification est `price`, et non `cost`.
- Lorsque le type de Service n’est pas Proxy ou qu’aucun Proxy n’est monté, des `items` vides sont renvoyés.

Les intégrations publiques dépendent uniquement de `endpoint` et des capacités publiées, et ne doivent pas dépendre de détails d’implémentation non publics.
