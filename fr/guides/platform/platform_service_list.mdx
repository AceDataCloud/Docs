---
title: "Obtenir la liste des services de la plateforme AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Renvoie de manière paginée le catalogue des Services visibles sur le site actuel, y compris le type de service, les informations d’affichage, le quota gratuit, les forfaits et les ID d’API/Proxy associés. Convient pour construire une marketplace de services ou sélectionner des services à demander.

## Aperçu de l’interface

| Élément   | Contenu                                                |
| --- | ------------------------------------------------- |
| Méthode  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Authentification  | Public ; avec un état de connexion, `applied` reflète alors le compte actuel                        |
| Pagination  | `count` + `items`                                 |

## Paramètres de requête

| Paramètre               | Type      | Obligatoire  | Description                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Non   | Filtre par ID de service ; prend en charge les paramètres répétés         |
| `private`        | boolean | Non   | Filtre par statut public ; les règles de visibilité du site restent en vigueur      |
| `type`           | string  | Non   | Type de service ; prend en charge les paramètres répétés              |
| `tag`            | string  | Non   | Filtre par étiquette                    |
| `include_facets` | boolean | Non   | Ajoute les statistiques de types/étiquettes disponibles sur le site actuel lorsque `true` |
| `limit`          | integer | Non   | Nombre d’éléments par page, maximum 100              |
| `offset`         | integer | Non   | Décalage de pagination                    |
| `ordering`       | string  | Non   | Prend uniquement en charge `rank` ou `-rank`     |

La liste ne prend pas en charge le filtrage par `alias` ; lorsqu’un alias existe déjà, demandez directement `/api/v1/services/{alias}`. `applied_count` et `updated_at` ne sont pas des champs de tri autorisés.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Description de la réponse

La réponse est `{count, items}` ; `facets` est ajouté uniquement lorsque `include_facets=true`. Les éléments de service comprennent les champs publics actuels tels que `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages`, etc.

`applied` dans une liste anonyme ne représente pas le statut de demande d’un compte donné. Lorsqu’un statut lié au compte est nécessaire, un état de connexion valide doit être fourni, et la [liste des demandes de service](https://platform.acedata.cloud/documents/platform-application-list) doit servir de référence finale.
