LMLocal est une extension pour Visual Studio 2022/2026, prenant en charge l'API compatible OpenAI et l'URL de base personnalisée. Le point d'entrée de configuration peut varier avec les versions de l'extension ; pour une première intégration, veuillez utiliser une version fixe et vérifier l'édition réelle, les appels d'outils et l'enregistrement de l'utilisation.

## Configuration

1. Installez LMLocal depuis le Visual Studio Marketplace ou le dépôt officiel.
2. Ajoutez un fournisseur Custom/OpenAI-compatible dans Providers.
3. Remplissez l'URL de base avec `https://api.acedata.cloud/v1`.
4. Remplissez la clé d'authentification avec votre token API Ace Data Cloud.
5. Remplissez le modèle avec l'ID de modèle précis supportant les Chat Completions dans le répertoire des modèles.
6. Après avoir enregistré, envoyez `Reply only OK`, puis testez à nouveau le processus d'édition du projet.

## Limites actuelles

- Ce guide ne couvre que LMLocal et ne représente pas la configuration partagée par d'autres extensions Visual Studio.
- Différentes versions peuvent traiter séparément les demandes de chat, d'édition, de construction et de test ; chaque mode doit être validé indépendamment.
- Si le client ajoute automatiquement `/v1` ou un chemin d'endpoint, veuillez éviter les chemins en double.
