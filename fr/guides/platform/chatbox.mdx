[ChatBox](https://chatboxai.app/) est un client IA open source prenant en charge Windows, macOS, Linux, iOS, Android et le Web. Il prend en charge les fournisseurs de services personnalisés de type « OpenAI API », et peut donc être directement connecté à Ace Data Cloud. Cet article présente le processus de configuration.

## Processus de demande

Pour connecter Ace Data Cloud dans ChatBox, rendez-vous d'abord sur la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications), obtenez votre API Token et conservez-le pour une utilisation ultérieure.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n'êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inviter à vous inscrire et à vous connecter. Après la connexion et l'inscription, vous reviendrez automatiquement sur la page actuelle.

Lors de votre première demande, un quota gratuit vous sera offert, ce qui vous permettra d'essayer gratuitement les services de modèles d'Ace Data Cloud.

## Télécharger ChatBox

Rendez-vous sur le [site officiel de ChatBox](https://chatboxai.app/) pour télécharger selon votre plateforme, ou utilisez directement la [version Web](https://web.chatboxai.app/) sans installation :

- Bureau : Windows `.exe`, macOS `.dmg` (distinction entre Intel / Apple Silicon), Linux AppImage
- Mobile : App Store, Google Play, lien direct Android sur le site officiel

## Configurer Ace Data Cloud

Lancez ChatBox, accédez à **Paramètres → Modèles → Ajouter un Provider personnalisé**, définissez **API Mode** sur **OpenAI API Compatible**, puis renseignez :

| Champ       | Valeur                           | Description                                      |
| -------- | --------------------------- | --------------------------------------- |
| Clé API   | Votre Token Ace Data Cloud     | Token copié depuis la console                            |
| API Host | `https://api.acedata.cloud` | Renseignez uniquement le domaine racine, **n'ajoutez pas `/openai` ni `/v1`**         |
| API Path | `/v1/chat/completions`      | La valeur par défaut de ChatBox est `/chat/completions`, vous devez la modifier manuellement par celle-ci |

![Interface de configuration du Provider Ace Data Cloud dans ChatBox](https://cdn.acedata.cloud/3789c8e3dd4d.png)

Le chemin de requête de ChatBox est `{API Host} + {API Path}` ; il suffit donc de renseigner le domaine racine dans Host :

| API Host                              | Requête finale                                                      | Résultat                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Correct                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (il n'y a pas de `/v1` sous `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox n'appelle pas automatiquement `/v1/models` ; vous devez saisir manuellement les ID des modèles (un par ligne) dans le champ « Modèles personnalisés » en bas de la page des paramètres de modèles. Après l'enregistrement, vous pourrez les sélectionner dans la liste déroulante des modèles de l'interface de conversation. Les options de capacité, la fenêtre de contexte et la limite de sortie doivent être renseignées selon le contrat actuel du modèle sélectionné ; ne recopiez pas les valeurs d'autres modèles.

## Choisir un modèle

Le catalogue de modèles est continuellement mis à jour. Utilisez en priorité la liste de modèles chargée automatiquement par le client ; si une saisie manuelle est nécessaire, interrogez d'abord `GET https://api.acedata.cloud/v1/models` pour obtenir les ID des modèles actuels, puis choisissez selon les capacités de contexte, d'images et d'appel d'outils prises en charge par le client.

## Vérifier l'intégration

Si vous ne savez pas si le problème vient de ChatBox ou du réseau, vous pouvez d'abord vérifier directement le point de terminaison avec curl (remplacez `{token}` par votre Token) :

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Le retour d'un objet `chat.completion` compatible OpenAI indique que le Token et le point de terminaison sont tous deux prêts ; si `HTTP 403 used_up` est renvoyé, cela signifie que le Token est valide mais que le solde est insuffisant. Il suffit alors de recharger votre compte dans la [console](https://platform.acedata.cloud/console/applications).

## Questions fréquentes

### Message 404 Not Found

Habituellement, `/openai` ou `/v1` a été ajouté en trop à API Host. Renseignez uniquement `https://api.acedata.cloud` dans Host, et laissez le chemin au `/v1/chat/completions` par défaut.

### Message 401 / token_mismatched

Veuillez confirmer que la « Clé API » contient le Token d'Ace Data Cloud (sans le préfixe `Bearer`, sans espaces superflus), et que le solde de l'application concernée est suffisant.

### Aucun modèle n'apparaît dans la liste déroulante des modèles

ChatBox ne récupère pas automatiquement la liste des modèles ; vous devez saisir manuellement les ID des modèles dans le champ « Modèles personnalisés » et enregistrer.

### Vous souhaitez générer des images dans ChatBox

La génération d'images d'Ace Data Cloud est une Images API indépendante (`/openai/images/generations`), dont le chemin diffère de l'interface de conversation ; l'entrée d'images de ChatBox ne peut pas être connectée directement. Si vous avez besoin de créer des images, veuillez consulter la [documentation de l'API de génération d'images](https://platform.acedata.cloud/documents/openai-images-generations) pour effectuer l'appel avec curl / SDK.
