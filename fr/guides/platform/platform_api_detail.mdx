Obtenez les informations complètes d’un seul point de terminaison API via l’ID d’API — par rapport à [l’interface de liste](https://platform.acedata.cloud/documents/platform-api-list), elle ajoute les champs `definition` (Schéma OpenAPI 3.0), `service` (détails du service auquel elle appartient) et `products` (produits associés).

Convient aux scénarios tels que la génération automatique de SDK, l’alimentation des descriptions d’outils pour les Agents LLM, le rendu dynamique de sites de documentation, etc.

> ℹ️ Cette interface fait partie de l’**API de gestion de la plateforme AceDataCloud**, avec le préfixe unifié `https://platform.acedata.cloud/api/v1/`. Pour l’index complet des interfaces, consultez [Obtenir la liste des documents de la plateforme AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Aperçu de l’interface

| Élément   | Contenu                                                    |
| --- | ----------------------------------------------------- |
| Méthode  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Authentification  | ❌ Publique                                                  |

`/apis/{id}` et `/apis/{id}/` sont actuellement tous deux disponibles ; les exemples utilisent uniformément la forme sans barre oblique finale.

## Instructions d’authentification

Cette interface est **entièrement publique, aucun jeton de compte ni état de connexion n’est requis**.

## Paramètres de chemin

| Paramètre       | Type   | Obligatoire  | Description                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | ID d’API (format UUID, les alias ne sont pas pris en charge) |

## Exemples de requêtes

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Description des champs de réponse

L’interface de détails inclut, en plus des [champs de l’interface de liste](https://platform.acedata.cloud/documents/platform-api-list) :

| Champ           | Type     | Description                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Informations principales du service auquel elle appartient : `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Liste des produits associés (généralement vide, destinée à l’équipe des opérations)                                                                         |
| `definition` | object | **Définition complète de la spécification OpenAPI 3.0**, incluant `paths`, `components`, `info`, etc., qui peut être directement fournie à `openapi-generator` pour générer le code client |

## Gestion des erreurs

| HTTP | code        | Signification                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` n’est pas un UUID valide |
| 404  | `not_found` | L’API n’existe pas ou a été retirée        |

## Conseils pratiques

- **Le champ `definition` est très volumineux** : le schéma OpenAPI d’une seule API peut contenir plusieurs centaines de lignes JSON. Si vous souhaitez uniquement créer un index de services et n’avez pas besoin du schéma, utilisez plutôt [l’interface de liste](https://platform.acedata.cloud/documents/platform-api-list).
- **Utilisation courante pour générer un SDK** :
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Suivre les modifications de l’API** : le champ `updated_at` correspond à la dernière date de modification du schéma. S’abonner à ce champ permet de régénérer automatiquement le SDK lors de modifications d’OpenAPI.
