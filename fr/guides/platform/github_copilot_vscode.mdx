title: "VS Code : Intégration de GitHub Copilot BYOK avec Ace Data Cloud"
description: "Platform API guide - Ace Data Cloud"
---

La documentation officielle BYOK de GitHub Copilot liste VS Code comme client local supporté et prend en charge les fournisseurs compatibles avec OpenAI. La version de VS Code, la politique d'entreprise et la visibilité du modèle peuvent affecter le point de terminaison final ; pour une première intégration, veuillez vérifier la demande réelle ci-dessous.

## Portée de la configuration

1. Assurez-vous que votre compte ou organisation GitHub Copilot a activé la fonctionnalité BYOK/Modèles personnalisés.
2. Ajoutez un fournisseur compatible avec OpenAI dans la gestion des modèles de Copilot de VS Code.
3. Remplissez l'URL de base avec `https://api.acedata.cloud/v1`.
4. Remplissez la clé API avec votre jeton API Ace Data Cloud.
5. Remplissez le modèle avec l'ID de modèle précis compatible avec le protocole sélectionné dans le répertoire des modèles.
6. Dans Copilot Chat, envoyez `Reply only OK`, puis testez à nouveau une demande avec le contexte de l'espace de travail.

## Limites actuelles

- L'application Copilot, CLI, GitHub Desktop, Enterprise BYOK et la configuration de VS Code ont des contrats différents, ce guide ne s'applique pas directement aux étapes d'autres clients pour VS Code.
- La politique d'organisation peut interdire aux individus d'ajouter des fournisseurs ou des modèles.
- La complétion par onglet, le chat, l'agent et les tâches en arrière-plan peuvent utiliser différents chemins de modèle, à vérifier séparément.
