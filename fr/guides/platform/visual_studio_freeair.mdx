FreeAIr est une extension open source pour Visual Studio 2022/2026, qui, selon l'annonce officielle, peut se connecter à n'importe quelle API compatible OpenAI. Le comportement des requêtes peut varier selon les versions de l'extension ; lors de la première intégration, veuillez utiliser une version fixe et compléter la validation minimale ci-dessous.

## Configuration

1. Installez FreeAIr depuis le Visual Studio Marketplace ou le dépôt officiel.
2. Ouvrez les paramètres de FreeAIr et ajoutez une connexion compatible OpenAI.
3. Remplissez l'Endpoint avec `https://api.acedata.cloud/v1`.
4. Remplissez le Token avec votre Token API Ace Data Cloud.
5. Remplissez le Model avec l'ID de modèle précis supportant les Chat Completions dans le répertoire des modèles.
6. Après avoir enregistré, envoyez `Reply only OK`, puis testez à nouveau une requête avec le contexte du projet.

## Limites actuelles

- Ce guide ne couvre que FreeAIr et ne représente pas le support de Visual Studio pour un Base URL arbitraire intégré à Copilot.
- La version de l'extension peut modifier la manière de concaténer l'endpoint ; lors de la validation, vérifiez l'URL de requête finale.
- Les capacités d'appel d'outils et de MCP au sein de l'extension nécessitent une validation indépendante, et ne peuvent pas être remplacées par un succès de chat ordinaire.
