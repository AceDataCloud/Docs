Lire les interrupteurs de fonctionnalités publics et la détermination du pays/de la région dans le contexte de la requête actuelle. Convient pour décider si des fonctionnalités doivent être affichées au démarrage du frontend ; il ne s’agit pas de la marque du site, des coordonnées ou du catalogue des annonces.

## Aperçu de l’interface

| Élément   | Contenu                                              |
| --- | ----------------------------------------------- |
| Méthode  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Authentification  | Publique ; certains interrupteurs de fonctionnalités peuvent être calculés selon l’utilisateur lors du transport d’un état de connexion                          |

## Paramètres de requête et en-têtes de requête

| Nom                    | Emplacement     | Description                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Code pays ASCII à deux lettres ; utilisé pour remplacer le pays d’affichage dans la réponse, sans modifier la détermination de sécurité côté serveur |
| `features`            | query  | Expression de remplacement des interrupteurs de fonctionnalités ; ne s’applique qu’aux interrupteurs dont le remplacement par le client est autorisé ou au superadministrateur        |
| `X-Feature-Overrides` | header | Source de remplacement identique à `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Structure réelle de la réponse

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Champ         | Type            | Description                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Interrupteurs de fonctionnalités visibles pour la requête actuelle ; les clés varient selon la configuration de la plateforme, le client doit les lire selon les besoins et définir des valeurs par défaut sûres pour les clés manquantes |
| `country`  | string / null | Code pays en minuscules ; peut être `null` lorsqu’il ne peut pas être identifié                     |

Ne lisez pas depuis cette interface le nom du site, le CDN, la devise, la langue, les coordonnées du service client ou les annonces ; ces champs ne font pas partie du contrat de réponse actuel.

## Recommandations d’utilisation

- Les interrupteurs de fonctionnalités sont calculés selon l’utilisateur, l’empreinte et le contexte du site ; ne partagez pas un cache à long terme entre utilisateurs.
- Le `country` transmis par le client n’affecte que la valeur retournée et ne contourne pas les politiques régionales ou de sécurité côté serveur.
- Les paramètres query non reconnus seront ignorés ; utilisez uniquement les paramètres listés sur cette page.
