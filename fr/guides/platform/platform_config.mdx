Lire les interrupteurs de fonctionnalités publics et la détermination du pays/de la région dans le contexte de la requête actuelle. Convient pour décider si des fonctionnalités doivent être affichées lors du démarrage du frontend ; ce n’est pas la marque du site, les coordonnées de contact ou le répertoire des annonces.

## Aperçu de l’API

| Élément   | Contenu                                              |
| --- | ----------------------------------------------- |
| Méthode  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Authentification  | Publique ; lorsque l’état de connexion est transmis, certains interrupteurs de fonctionnalités peuvent être calculés selon l’utilisateur                          |

## Paramètres de requête et en-têtes

| Nom                    | Emplacement     | Description                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Expression de remplacement des interrupteurs de fonctionnalités ; ne prend effet que pour les interrupteurs dont le remplacement client est autorisé ou pour les super-administrateurs |
| `X-Feature-Overrides` | header | Source de remplacement identique à `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Structure réelle de la réponse

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Champ         | Type            | Description                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Interrupteurs de fonctionnalités visibles pour la requête actuelle ; les clés varient selon la configuration de la plateforme, le client doit les lire selon les besoins et définir des valeurs par défaut sûres pour les clés manquantes |
| `region`   | string / null | Code de pays ou de région détecté selon l’IP de la requête, en minuscules ; `null` lorsqu’il est impossible à identifier        |

Ne lisez pas depuis cette API le nom du site, le CDN, la devise, la langue, les coordonnées du service client ou les annonces ; ces champs ne font pas partie du contrat de réponse actuel.

## Recommandations d’utilisation

- Les interrupteurs de fonctionnalités sont calculés selon l’utilisateur, l’empreinte et le contexte du site ; ne partagez pas de cache à long terme entre les utilisateurs.
- La sélection du sélecteur de région est enregistrée uniquement dans le frontend ; lors de l’affichage, utilisez en priorité la région déjà sélectionnée, sinon utilisez `region` de cette API. Cette API n’accepte pas de paramètre de remplacement de région.
- Les paramètres query non reconnus seront ignorés ; utilisez uniquement les paramètres listés sur cette page.
