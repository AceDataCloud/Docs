---
title: "Obtenir les détails d’un document de la plateforme AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Obtenez le contenu complet et les relations de navigation d’un seul document via son UUID ou son alias. Lorsqu’un alias est connu, vous pouvez effectuer la requête directement, sans devoir d’abord filtrer depuis la liste.

## Aperçu de l’interface

| Élément   | Contenu                                                              |
| --- | --------------------------------------------------------------- |
| Méthode  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Authentification  | Public ; connaître l’UUID ou l’alias suffit pour lire directement                                       |

## Paramètres

- `id_or_alias` : UUID du document, alias actuel, ou ancien alias conservé dans `redirect_from`.
- `lang` : indication facultative de langue ; vous pouvez également utiliser `Accept-Language`. La langue finale du contenu est déterminée par le champ de réponse `content_locale`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Description de la réponse

Les détails utilisent une réponse à objet unique, qui contient actuellement :

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags` ;
- `content`, `content_mode`, `content_locale`, `content_hash` ;
- `parent`, `sibling` et les résumés publics de `children` triés par rank ;
- les associations `api` / `proxy` / `dataset` / `integration`, ainsi que `agent` (lorsqu’il existe).

La réponse ne contient pas de champ `breadcrumbs`. Lors de la construction du fil d’Ariane, vous pouvez continuer à lire les détails depuis `parent`, ou utiliser les relations de répertoire de documents déjà mises en cache.

## Gestion des erreurs

- L’ID/l’alias n’existe pas ou ne correspond pas à la visibilité actuelle du site : `404`. `private` contrôle uniquement la visibilité dans la liste, mais n’empêche pas les personnes connaissant le lien de lire directement ; il ne peut pas servir de frontière de confidentialité.
- La route actuelle utilise une forme sans barre oblique finale ; ne comptez pas sur la couche proxy pour ajouter automatiquement une barre oblique.
