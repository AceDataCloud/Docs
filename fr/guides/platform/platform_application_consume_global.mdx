---
title: "Configurer le partage du solde global d'AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Configurez `allow_consume_global`. Une fois activé, les Applications à la demande éligibles peuvent continuer à utiliser le solde global du compte lorsque leur propre solde est insuffisant.

## Préparatifs

- Créez et conservez en toute sécurité le [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Obtenez le `application_id` dont vous êtes propriétaire depuis la [liste des demandes de service](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='你的账户令牌'
export APPLICATION_ID='你的 Application ID'
```

## Aperçu de l'interface

| Élément    | Contenu                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Méthode   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Authentification   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

En cas de succès, l'objet Application mis à jour est renvoyé. Veuillez vous référer à `allow_consume_global` dans la réponse, plutôt que de supposer que la valeur demandée a nécessairement été enregistrée.

> Les Applications de type `Period` ne sont pas autorisées à consommer le solde global. Même si `true` est demandé, le serveur conservera ce champ à `false`.

## Gestion des erreurs

- `401` : Account Token invalide ou manquant.
- `403` : le compte actuel n'est pas le propriétaire de cette Application.
- `404` : l'ID de l'Application n'existe pas.

Le point d'entrée de recharge du solde global et les forfaits disponibles sont soumis à la console de la plateforme ainsi qu'aux forfaits réels renvoyés par la [création de commande](https://platform.acedata.cloud/documents/platform-order-create) ; ne supposez pas qu'il existe des forfaits de type `Wallet`.
