Vous avez probablement déjà rencontré cette situation : vous utilisez Claude Code, Cursor ou Codex, vous êtes en plein dans l’écriture de code, et soudain vous avez besoin d’une image, d’un fond musical, d’une courte vidéo, ou vous voulez lui demander de rechercher les dernières informations. Résultat — l’agent lui-même ne sait pas faire cela. Vous devez chercher des API vous-même, lire la documentation, configurer des clés, écrire le code d’appel, gérer le polling asynchrone ; après toute cette galère, l’inspiration est déjà retombée.

[AceKit](https://github.com/AceDataCloud/AceKit) est là pour vous épargner toute cette série de galères. Avec une seule commande, il installe dans votre agent de codage tout l’ensemble des capacités de génération d’images, de génération de vidéos, de génération de musique, de recherche web, de conversation LLM et plus encore d’AceData Cloud. Une fois installé, vous n’avez plus qu’à parler naturellement : l’agent chargera lui-même la compétence correspondante, s’authentifiera lui-même, effectuera lui-même le polling, et réalisera le travail.

## Comprendre ce qu’il fait en 30 secondes

Avant l’installation vs après l’installation :

| Ce que vous dites               | Avant l’installation                   | Après l’installation (l’agent le fait lui-même)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Ajoute une image de couverture à ce README" | l’agent ne sait pas faire, il vous demande de chercher vous-même une API de génération d’images | Appelle NanoBanana / Flux / Midjourney pour générer l’image |
| "Transforme ce script en une courte vidéo de 30 secondes"  | ne sait pas faire                    | Appelle Sora / Veo / Kling / Seedance pour générer la vidéo  |
| "Ajoute une musique de fond à cette démo"  | ne sait pas faire                    | Appelle Suno pour générer la musique                           |
| "Recherche les dernières informations sur X et résume-les"     | ne peut pas se connecter à Internet                  | Appelle Google SERP pour obtenir des résultats en temps réel                 |
| "Raccourcis ce long lien"         | ne sait pas faire                    | Appelle le service de liens courts et renvoie un lien surl.id                  |

En une phrase : **votre agent de codage passe de « sait seulement écrire du code » à « sait aussi générer des images, des vidéos, de la musique et effectuer des recherches en ligne ».**

## Démarrage en trois étapes

Tout le processus prend quelques minutes, Node.js 18+ est requis.

**Première étape · Obtenez un API Token.** Copiez le Token depuis la [console](https://platform.acedata.cloud/console/applications) — toutes les capacités partagent celui-ci, votre première demande inclut un crédit gratuit, vous pouvez donc d’abord l’essayer gratuitement.

![Copier l’API Token dans la console](https://cdn.acedata.cloud/dvc3cg.jpg)

**Deuxième étape · Installez.** Une seule commande :

```bash
npx acekit
```

Il détectera automatiquement les agents de codage présents sur la machine et installera tout l’ensemble de compétences. Voici à quoi ressemble une exécution réelle (cette machine n’a installé que Claude Code) :

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Si aucun Token n’est configuré, la première exécution vous invitera de manière interactive à le coller ; vous pouvez aussi faire à l’avance `export ACEDATACLOUD_API_TOKEN=你的token` pour une installation entièrement sans intervention. Le nombre de compétences évoluera avec les capacités de la plateforme ; référez-vous à la liste actuelle affichée par `npx acekit list`.

**Troisième étape · Parlez naturellement.** Rechargez l’agent, puis donnez directement une instruction, par exemple :

```text
Utilise la compétence short-url pour raccourcir https://platform.acedata.cloud/services
```

L’agent chargera lui-même la compétence, lancera lui-même l’appel et vous donnera un résultat réel accessible via le lien.

## Une exécution réelle de bout en bout (avec sortie)

Les quatre exemples ci-dessous sont tous des **appels réels avec des résultats retournés sur-le-champ**, et non des illustrations. Le `$KEY` dans les commandes est votre API Token.

**① Raccourcir une URL (synchrone, réponse en quelques secondes)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Renvoie `https://surl.id/r/1uKp2kilXQ` — l’ouvrir redirige via un 302 vers la page services originale.

**② Recherche en ligne (synchrone)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Obtient des résultats Google en temps réel (extrait) :

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Conversation LLM (synchrone, une interface pour accéder à plus de 50 modèles)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP est un protocole utilisé pour gérer et échanger de manière unifiée les informations de contexte des modèles.
（39 tokens, environ 0.00007 credit pour cette requête）
```

**④ Génération d’images (asynchrone, environ 20 secondes, l’agent effectue automatiquement le polling jusqu’à l’obtention de l’image)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Après environ 22 secondes, renvoie une image réelle (HTTP 200 · image/png · 317 KB · environ 0.13 credit pour cette requête) :

![Image réellement générée par AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

Vous n’avez en fait pas besoin de retenir ces interfaces — une fois les compétences installées, l’agent composera lui-même les requêtes correctes selon leurs `SKILL.md`, et gérera l’authentification ainsi que le polling. Ce qui précède sert seulement à vous montrer ce qu’« il fait en arrière-plan ».

## Qu’installe-t-il exactement

AceKit est la « porte d’entrée » de tout l’environnement d’outils développeur d’AceData ; actuellement, une installation installe l’**ensemble d’outils de compétences (Skills)** :

- **Un ensemble de compétences Agent** : chaque compétence est un manuel d’opération `SKILL.md` déjà rédigé — l’authentification, le polling asynchrone, les nouvelles tentatives en cas d’erreur et la manière de remplir les paramètres y sont tous clairement indiqués ; l’agent n’a qu’à les suivre. Exécutez `npx acekit list` pour voir la liste actuelle (elle compte 19 éléments au moment de la rédaction de cet article, et continue d’augmenter) :
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Un Token unique** : un `ACEDATACLOUD_API_TOKEN` déverrouille toutes les capacités, avec une facturation basée sur l'utilisation réelle.

Classées par capacité (selon `npx acekit list`) :

| Type         | Fournisseurs                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Génération d'images      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Génération de vidéos      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Génération de musique / audio | Suno · Producer · Fish Audio（TTS）                    |
| 💬 Conversation LLM   | Interface unifiée pour plus de 50 modèles（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Recherche       | Google SERP（pages web · images · actualités · cartes · vidéos）                  |
| 🔗 Outils       | Liens courts · traitement de visages                                            |

> Pour ces mêmes capacités, AceData propose également des **serveurs MCP** indépendants（Suno、Midjourney、Sora、SERP… publiés sur PyPI / VS Code / Smithery / Docker）、une **CLI en ligne de commande** et des **SDK Python / TypeScript**, utilisables séparément selon les besoins. AceKit v0.2 prévoit de prendre en charge l'installation d'une capacité unique avec `acekit add <name>`, ainsi que l'écriture automatique de la configuration MCP de chaque agent.

## Quels Agents sont pris en charge

| Agent                        | Emplacement d'installation des compétences                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode, etc. | `~/.agents/skills`（faites pointer votre agent ici） |

Lors de l'installation, AceKit détecte automatiquement les agents déjà installés sur la machine et n'installe que dans ceux qui ont été détectés.

## Bonus : utiliser le même Token pour alimenter Claude Code lui-même

L'interface d'AceData est également compatible avec le format `/v1/messages` d'Anthropic, vous **n'avez donc pas besoin d'un abonnement officiel Anthropic** : vous pouvez utiliser le même Token AceData pour alimenter Claude Code. Créez `.claude/settings.local.json` à la racine du projet :

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Redémarrez simplement Claude Code — il utilisera à la fois toute la gamme de modèles Claude et disposera, via AceKit, des « mains » pour générer des images, des vidéos et de la musique. Pour plus de détails, consultez le [guide d'intégration de Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
