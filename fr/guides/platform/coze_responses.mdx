La documentation officielle du modèle personnalisé Coze prend en charge l'API OpenAI Responses et fournit l'URL de l'API de base, la clé API et les champs du modèle. Les différentes versions des locataires Coze peuvent traiter la concaténation des chemins, la sortie en continu et les appels d'outils de manière différente. Pour une première intégration, veuillez vérifier chaque point ci-dessous.

## Configuration

1. Accédez à la gestion des modèles Coze et ajoutez un modèle personnalisé.
2. Sélectionnez le protocole OpenAI Responses API.
3. Remplissez l'URL de l'API de base avec `https://api.acedata.cloud/v1`.
4. Remplissez la clé API avec votre jeton API Ace Data Cloud.
5. Remplissez le modèle avec l'ID de modèle précis qui prend en charge l'API Responses dans le répertoire des modèles.
6. Enregistrez et terminez le test de connexion Coze.
7. Dans Bot/Agent, envoyez `Reply only OK`, puis testez à nouveau l'appel d'outils.

## Limites Actuelles

- Différentes régions, versions ou forfaits Coze peuvent afficher différents formulaires.
- L'URL de l'API de base doit utiliser la base, ne pas ajouter `/responses` à nouveau ; si l'interface utilisateur actuelle exige clairement l'URL API complète, suivez les indications du formulaire.
- Les Chat Completions, Responses et Anthropic Messages sont trois voies indépendantes et ne peuvent pas se substituer pour la validation.
