title: "Guide d'intégration de l'agent Hermes"
description: "Platform API guide - Ace Data Cloud"
---

L'agent Hermes s'intègre à Ace Data Cloud via le protocole OpenAI Chat Completions. Choisissez l'une des méthodes de configuration :

| Méthode de configuration        | Guide                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Assistant d'interaction `hermes model` | [Configuration de l'assistant](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Configuration manuelle `config.yaml`  | [Configuration manuelle](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Déploiement privé sur la plateforme              | [Déploiement géré](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Paramètres communs pour l'intégration locale :

- URL de base : `https://api.acedata.cloud/v1`
- Transport : `chat_completions`
- Fournisseur : `custom:acedatacloud`
- Clé API : à obtenir depuis [la liste des applications](https://platform.acedata.cloud/console/applications)

Les deux méthodes locales sont finalement écrites dans `~/.hermes/config.yaml`, ne pas configurer plusieurs fois.

Retourner au [Centre de configuration du plan de codage](https://platform.acedata.cloud/documents/coding-plan-integration).
