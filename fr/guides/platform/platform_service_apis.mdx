---
title: "Obtenir la liste des API sous un service de la plateforme AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Retourne de manière paginée les API actuellement activées et non obsolètes de ce service via le UUID du service. Lorsqu’il n’y a que l’alias, appelez d’abord les [détails du service](https://platform.acedata.cloud/documents/platform-service-detail) pour obtenir `id`.

## Aperçu de l’interface

| Élément   | Contenu                                                             |
| --- | ------------------------------------------------------------------- |
| Méthode  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Authentification  | Public, aucun jeton de compte requis                                                           |
| Pagination  | `count` + `items`                                                   |

## Paramètres

| Paramètre           | Emplacement    | Obligatoire  | Description                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Oui   | UUID du service, l’alias n’est pas pris en charge           |
| `limit`      | query | Non   | Nombre d’éléments par page, maximum 100                      |
| `offset`     | query | Non   | Décalage de pagination                            |
| `ordering`   | query | Non   | Expression de tri Django ; `rank` ou `-rank` est recommandé |

L’interface actuelle ne prend pas en charge le filtrage par `stage` ; elle exclut déjà les API `Deprecated`.

```shell
export SERVICE_ID='Votre Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Les éléments de la liste utilisent la même structure d’index que la [liste des API de la plateforme](https://platform.acedata.cloud/documents/platform-api-list), et contiennent actuellement `definition`. Lorsqu’un point d’entrée stable pour une API individuelle est requis, continuez à appeler `/api/v1/apis/{api_id}`.

## Gestion des erreurs

- Le service n’existe pas ou n’est pas visible sur le site actuel : `404`.
- `service_id` doit être un UUID ; l’alias ne sera pas résolu dans cette action.
