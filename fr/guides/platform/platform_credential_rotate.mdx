---
title: "Rotation des identifiants API de la plateforme AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Générez un nouveau Token ou mot de passe pour un Credential existant. L’ID du Credential, l’association Application, les quotas et les autres champs restent inchangés, et l’ancien secret devient immédiatement invalide.

> La rotation interrompra les clients qui utilisent encore l’ancien secret. Préparez d’abord une distribution sécurisée et un plan de restauration, puis effectuez l’opération d’écriture.

## Aperçu de l’interface

| Élément    | Contenu                                                                    |
| ---------- | -------------------------------------------------------------------------- |
| Méthode    | `POST`                                                                     |
| URL        | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Authentification | Account Token                                                        |
| Body       | Aucun ou `{}`                                                             |

Obtenez le `credential_id` depuis la [liste des identifiants](https://platform.acedata.cloud/documents/platform-credential-list) :

```shell
export PLATFORM_TOKEN='votre jeton de compte'
export CREDENTIAL_ID='ID du Credential à faire tourner'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

En cas de succès, le Credential mis à jour est renvoyé. Lorsque `type=Token`, lisez le nouveau `token` ; lorsque `type=Identity`, lisez le nouveau `password`. Traitez la réponse complète comme un secret et mettez immédiatement à jour les appelants.

## Gestion des erreurs

- `401` : Account Token invalide.
- `403` : Vous n’êtes pas autorisé à gérer ce Credential.
- `404` : L’ID du Credential n’existe pas.
