Inferpal est une extension pour Visual Studio 2022/2026, officiellement supportée pour se connecter aux services compatibles avec OpenAI. La version de l'extension peut affecter l'édition, les appels d'outils et l'enregistrement de l'utilisation ; pour une première connexion, veuillez fixer la version et compléter la validation minimale ci-dessous.

## Configuration

1. Installez Inferpal depuis le Visual Studio Marketplace ou le dépôt officiel.
2. Ouvrez les **Paramètres → Connexion** d'Inferpal.
3. Sélectionnez OpenAI-compatible comme fournisseur.
4. Remplissez l'URL de base avec `https://api.acedata.cloud/v1`.
5. Remplissez la clé API avec votre jeton API d'Ace Data Cloud.
6. Remplissez le modèle avec l'ID de modèle précis supportant les Chat Completions dans le répertoire des modèles.
7. Après avoir enregistré, envoyez `Reply only OK`, puis exécutez à nouveau une demande contenant le contexte du code.

## Limites actuelles

- Ce guide ne couvre que l'Inferpal et ne représente pas le Copilot intégré de Visual Studio ou d'autres extensions supportant les mêmes champs.
- Différentes versions peuvent automatiquement ajouter des chemins à l'URL de base ; si la demande échoue, veuillez d'abord vérifier si la demande finale se situe sur le point de terminaison des Chat Completions.
- Avant de finaliser la version fixe E2E, il n'est pas garanti que tous les modes d'édition, de complétion ou d'appels d'outils soient disponibles.
