[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (anciennement ChatGPT-Next-Web) est un client IA open source qui peut être déployé sur Vercel, Cloudflare ou Docker. Il prend en charge les points de terminaison personnalisés compatibles avec OpenAI, ce qui permet d’intégrer Ace Data Cloud. Cet article présente le processus de configuration.

## Processus de demande

Pour intégrer Ace Data Cloud dans NextChat, rendez-vous d’abord sur la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications), obtenez votre API Token et conservez-le pour une utilisation ultérieure.

![Obtenir l’API Key Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

Si vous n’êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion afin de vous inviter à vous inscrire et à vous connecter ; après la connexion ou l’inscription, vous reviendrez automatiquement sur cette page.

Lors de votre première demande, un quota gratuit vous sera offert, vous permettant d’essayer gratuitement les services de modèles d’Ace Data Cloud.

## Télécharger NextChat

Vous pouvez utiliser la version de bureau (téléchargez `.exe` / `.dmg` / AppImage depuis la [page Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), la [version Web en ligne](https://app.nextchat.club/), ou déployer vous-même sur Vercel / Cloudflare / Docker (voir la section avancée ci-dessous).

## Configurer Ace Data Cloud

Démarrez NextChat, puis accédez à **Paramètres → Services de modèles** :

| Champ          | Valeur                           | Description                              |
| ----------- | --------------------------- | ------------------------------- |
| Fournisseur de modèles       | `OpenAI`                    | Utilise le protocole compatible OpenAI                  |
| Adresse de l’interface OpenAI | `https://api.acedata.cloud` | Renseignez uniquement le domaine racine, **sans `/openai`, sans `/v1`** |
| API Key     | Votre Token Ace Data Cloud     | Token copié depuis la console                    |

![Interface de configuration Ace Data Cloud dans NextChat](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat ajoutera automatiquement `/v1/chat/completions` après l’adresse de l’interface, il suffit donc de renseigner le domaine racine :

| Adresse de l’interface                                  | Requête réelle                                                      | Résultat                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Correct                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (il n’y a pas de `/v1` sous `/openai`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

Dans le champ « Nom de modèle personnalisé », renseignez les modèles séparés par des virgules anglaises. NextChat prend en charge une syntaxe spéciale : `+nom_du_modèle` pour ajouter, `-nom_du_modèle` pour masquer, `nom_du_modèle=nom_d_affichage` pour personnaliser le nom affiché, et `-all` pour tout masquer d’abord. La syntaxe la plus propre recommandée est :

```text
-all,+MODEL_ID=显示名称
```

## Choisir un modèle

Le catalogue de modèles est continuellement mis à jour. Utilisez en priorité la liste des modèles chargée automatiquement par le client ; si une saisie manuelle est nécessaire, envoyez d’abord une requête à `GET https://api.acedata.cloud/v1/models` pour obtenir les ID de modèles actuels, puis choisissez selon les capacités de contexte, d’images et d’appels d’outils prises en charge par le client.

## Vérifier l’intégration

Si vous ne savez pas si le problème provient de NextChat ou du réseau, vous pouvez d’abord utiliser curl pour vérifier directement le point de terminaison (remplacez `{token}` par votre Token) :

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Le renvoi d’un objet `chat.completion` compatible avec OpenAI indique que le Token et le point de terminaison sont tous deux prêts ; si `HTTP 403 used_up` est renvoyé, cela signifie que le Token est valide mais que le solde est insuffisant. Il suffit alors de recharger votre compte dans la [console](https://platform.acedata.cloud/console/applications).

## Avancé : déployer en un clic sur votre propre domaine

NextChat permet de déployer un site IA qui vous appartient. Prenons Docker comme exemple (remplacez `{token}` par votre Token) :

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Lors d’un déploiement sur Vercel / Cloudflare, il suffit de configurer les mêmes `OPENAI_API_KEY`, `BASE_URL`, `CODE` et `CUSTOM_MODELS` dans les variables d’environnement du projet. `CODE` prend en charge plusieurs mots de passe d’accès séparés par des virgules anglaises, ce qui facilite le suivi de l’utilisation par personne. Pour la description complète des variables d’environnement ci-dessus (`BASE_URL` vaut par défaut `https://api.openai.com`, et la syntaxe `+/-/=/-all/+all` de `CUSTOM_MODELS`), référez-vous au [README officiel de NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Questions fréquentes

### Message 404 Not Found

L’adresse de l’interface est généralement renseignée comme `.../openai` ou `.../openai/v1`. Remplacez-la par `https://api.acedata.cloud` et laissez NextChat ajouter lui-même `/v1/chat/completions`.

### Le modèle ajouté n’apparaît pas dans la liste déroulante des modèles

Vérifiez le format de `CUSTOM_MODELS` : chaque modèle doit être précédé de `+` ; si vous avez utilisé `-all`, assurez-vous de rajouter les modèles nécessaires avec `+`.

### Message 401 Unauthorized

Veuillez vérifier que l’API Key contient bien le Token d’Ace Data Cloud (sans le préfixe `Bearer` et sans espaces supplémentaires), et que le solde de l’application concernée est suffisant.
