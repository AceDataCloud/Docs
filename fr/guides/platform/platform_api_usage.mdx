---
title: "Récupérer des échantillons récents d’appels de l’API de la plateforme AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Renvoie publiquement des échantillons d’enregistrements d’appels d’une API au cours des 15 dernières minutes, afin d’observer rapidement l’état récent. Il ne s’agit pas d’une interface de comptage agrégée par code d’état, et elle ne peut pas être utilisée pour la facturation personnelle, les SLA ou les statistiques complètes d’utilisation.

## Aperçu de l’interface

| Élément   | Contenu                                                           |
| --- | ------------------------------------------------------------ |
| Méthode  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Authentification  | Publique, aucun jeton de compte requis                                                    |
| Limite  | Après fusion des enregistrements récemment créés/terminés, renvoie au maximum 5 000 éléments                                    |

`api_id` est obtenu depuis la [liste des API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Structure réelle de la réponse

La réponse est directement un tableau, sans envelope de pagination :

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Champ            | Description        |
| ------------- | --------- |
| `api_id`      | ID de l’API    |
| `created_at`  | Heure de création de l’enregistrement    |
| `trace_id`    | Identifiant de traçage de la requête    |
| `status_code` | Code d’état HTTP  |
| `elapsed`     | Durée de l’appel, en secondes |

Si l’API n’existe pas, un tableau vide peut également être renvoyé actuellement, car cette action interroge directement l’utilisation récente par ID, sans d’abord vérifier l’objet API. Pour calculer le taux de réussite, le client doit regrouper lui-même les échantillons renvoyés ; pour consulter les débits personnels, veuillez utiliser l’interface au niveau du compte.
