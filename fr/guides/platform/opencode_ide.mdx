---
title: "Intégration de l'extension IDE OpenCode avec Ace Data Cloud"
description: "Platform API guide - Ace Data Cloud"
---

L'extension IDE officielle d'OpenCode prend en charge les éditeurs tels que VS Code, Cursor, Windsurf, VSCodium, et réutilise le runtime local d'OpenCode ainsi que la configuration du Provider. L'extension IDE réutilise le Provider CLI local, mais la chaîne de requêtes peut varier selon les versions des éditeurs ; pour une première intégration, veuillez fixer la version et compléter la validation minimale.

## Configuration du Provider

Commencez par configurer le Provider Ace Data Cloud dans `opencode.json` ou `opencode.jsonc` selon [la configuration du terminal OpenCode](https://platform.acedata.cloud/documents/opencode-terminal-integration) :

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Installation de l'extension IDE

1. Exécutez `opencode` dans le terminal intégré de l'éditeur pour installer automatiquement l'extension selon le processus officiel ; vous pouvez également l'installer manuellement depuis le Marketplace correspondant.
2. Rechargez l'éditeur.
3. Lancez `Reply only OK` depuis l'extension OpenCode.
4. Exécutez à nouveau une requête nécessitant la lecture de fichiers ou la modification de code, pour confirmer que l'extension IDE utilise le même Provider et modèle.

## Limites actuelles

- Les capacités du Provider proviennent du runtime OpenCode, et ne représentent pas le support natif d'Ace Data Cloud par l'éditeur hôte.
- Les versions des extensions de VS Code et de ses forks peuvent différer, et doivent être enregistrées séparément.
- Un chat ordinaire réussi ne peut pas remplacer la validation de la lecture de fichiers, de l'édition et des appels d'outils.
