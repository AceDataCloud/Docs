Coze prend officiellement en charge l'intégration de modèles personnalisés et propose trois protocoles : OpenAI Chat API, OpenAI Responses API et Anthropic Messages API. Les URL de base, la concaténation des chemins, les en-têtes, le streaming et les contrats d'appel d'outils diffèrent pour les trois routes, il est donc nécessaire de les configurer et de les valider séparément.

| Route                      | État      | Guide                                                                                  |
| ------------------------- | -------- | ------------------------------------------------------------------------------------- |
| OpenAI Chat Completions   | Expérimental | [Configuration du Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses          | Expérimental | [Configuration des Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages        | Expérimental | [Configuration des Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

"Expérimental" signifie que les capacités officielles et les points d'entrée de configuration ont été confirmés, mais différentes régions, versions ou forfaits Coze peuvent afficher différents formulaires. Ace Data Cloud doit toujours compléter la validation de version fixe selon le protocole. Ne pas extrapoler le succès d'un protocole à deux autres.

## Principes de configuration

- L'URL de base de l'API doit d'abord être remplie avec la base donnée dans la documentation ; ne pas ajouter de chemin d'endpoint que le client complétera automatiquement.
- La clé API utilise votre jeton API Ace Data Cloud.
- Le modèle utilise l'ID de modèle précis compatible avec le protocole choisi dans le répertoire des modèles.
- Après un texte ordinaire réussi, il faut également valider le streaming et l'appel d'outils.
