## 1. Obtenir une clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ajouter un Provider

Ouvrez Cherry Studio, accédez à **Paramètres → Services de modèles → Ajouter un fournisseur**, puis renseignez :

| Champ      | Valeur                           |
| ------- | --------------------------- |
| Nom du fournisseur   | `Ace Data Cloud`            |
| Type de fournisseur   | `OpenAI`                    |
| Clé API | La clé API que vous venez de copier               |
| Adresse API  | `https://api.acedata.cloud` |

![Interface de configuration de l'ajout du Provider Ace Data Cloud dans Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio complète automatiquement `/v1/chat/completions` pour le type OpenAI. Lors de l'utilisation de l'entrée générale, n'ajoutez pas `#` à la fin de l'adresse, et il n'est pas nécessaire de créer plusieurs Providers selon les familles de modèles.

## 3. Ajouter et activer des modèles

1. Cliquez sur **Obtenir la liste des modèles** ; si la version actuelle ne prend pas en charge la récupération automatique, consultez le [catalogue de modèles](https://platform.acedata.cloud/models), puis ajoutez manuellement le nom du modèle cible, par exemple `claude-opus-5`, `gpt-6-sol`.
2. Cliquez sur le bouton de vérification à côté de la clé API pour valider la connexion.
3. Activez l'interrupteur **Activer** du Provider.
4. Sélectionnez le modèle que vous venez d'ajouter dans le sélecteur de modèles de conversation.

![Liste des Providers et des modèles de Cherry Studio](https://cdn.acedata.cloud/149de1d088bf.png)

> Après avoir récupéré ou ajouté manuellement les modèles, veuillez activer l'interrupteur Provider en haut à droite.

Envoyez `Répondez uniquement OK`, puis vérifiez l'appel dans l'[historique d'utilisation](https://platform.acedata.cloud/console/usages). En cas de 401, vérifiez la clé ; si le modèle ne s'affiche pas, vérifiez si le Provider est activé ; en cas de 404, vérifiez que le nom du modèle renseigné manuellement correspond exactement à l'`id` dans le catalogue.

## À propos de GPT Image 2

Le Provider de chat personnalisé standard de Cherry Studio ne peut pas appeler directement l'API Images. La génération et l'édition de `gpt-image-2` doivent utiliser l'interface dédiée d'Ace Data Cloud :

- [Génération d'images GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Édition d'images GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Ne renseignez pas `/openai/images/generations` dans le Provider de chat.
