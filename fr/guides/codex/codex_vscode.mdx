title: "Guide de configuration de Codex pour VS Code"
description: "Codex API guide - Ace Data Cloud"
---

L'extension Codex VS Code partage `~/.codex/config.toml` avec Codex CLI.

## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer l'extension

Installez **Codex – l'agent de codage d'OpenAI** publié par OpenAI sur le marché des extensions VS Code, ou exécutez :

```bash
code --install-extension openai.chatgpt
```

## 3. Configurer la clé API

macOS / Linux :

```bash
export ACEDATACLOUD_API_KEY="votre clé API"
```

Pour une validité à long terme, ajoutez cette ligne à `~/.zshrc` ou `~/.bashrc`. Pour Windows PowerShell, utilisez :

```powershell
setx ACEDATACLOUD_API_KEY "votre clé API"
```

## 4. Configurer AceDataCloud

Éditez `~/.codex/config.toml` (pour Windows, c'est `%USERPROFILE%\.codex\config.toml`), ajoutez :

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Pour Windows, modifiez les deux dernières lignes en :

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Il n'est pas nécessaire de remplir `model` ; vous pouvez choisir le modèle dans le panneau Codex.

## 5. Redémarrer et vérifier

Quittez complètement et rouvrez VS Code, puis ouvrez le panneau Codex. Exécutez `/model`, confirmez que le Provider est `acedatacloud`, puis envoyez un message simple ; les enregistrements d'appels peuvent être consultés dans [l'historique d'utilisation](https://platform.acedata.cloud/console/usages).

Si l'extension ne peut pas lire la clé, lancez VS Code depuis un terminal où la variable d'environnement est définie, ou configurez une variable d'environnement au niveau système puis redémarrez VS Code. Remote SSH, WSL et Dev Container doivent être configurés dans l'environnement où l'extension est réellement exécutée.
