Codex CLI, Desktop et l'extension VS Code partagent `~/.codex/config.toml`. Configurez une fois le fournisseur `acedatacloud`, et vous pourrez utiliser Codex via Ace Data Cloud.

| Méthode d'utilisation | Guide de configuration                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| Terminal / CLI       | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)                     |
| Bureau               | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)                  |
| VS Code              | [Codex pour VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)             |
| Changement graphique  | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration)              |

Les configurations communes ne comportent que trois éléments :

- Fournisseur : `acedatacloud`
- URL de base : `https://api.acedata.cloud/v1`
- Clé API : obtenue à partir de [la liste des applications](https://platform.acedata.cloud/console/applications) et enregistrée dans `ACEDATACLOUD_API_KEY`

Il n'est pas nécessaire de fixer le modèle dans la configuration d'intégration ; après le démarrage de Codex, vous pouvez directement choisir le modèle.

Retour à [Centre de configuration du plan de codage](https://platform.acedata.cloud/documents/coding-plan-integration).
