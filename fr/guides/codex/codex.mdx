description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI est un agent de programmation local open source lancé par OpenAI, qui peut lire le code, modifier des fichiers, exécuter des commandes et aider à accomplir des tâches de développement directement dans le terminal. Grâce au proxy Ace Data Cloud, vous pouvez utiliser Codex CLI à moindre coût, sans avoir à souscrire séparément à un compte officiel OpenAI.

Choisissez le tutoriel complet correspondant selon le scénario d'utilisation :

| Plateforme | Description | Lien du tutoriel |
|------------|-------------|------------------|
| **VS Code** | Extension officielle, chat dans la barre latérale de l’éditeur, citation de fichiers, aperçu des diff | [Tutoriel de configuration VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminal (CLI)** | Expérience principale, lancez simplement `codex` dans n’importe quel terminal pour commencer | [Tutoriel de configuration Terminal](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Conseil** : Pour une première demande, rendez-vous sur la [console Ace Data Cloud](https://platform.acedata.cloud/console/applications) pour obtenir un token API, qui inclut un crédit gratuit. Codex CLI fonctionne via l’interface compatible OpenAI Responses de Ace Data Cloud (`/v1/responses`). Pour plus d’informations sur les modèles et la facturation, consultez la [page de service OpenAI](https://platform.acedata.cloud/documents/openai).
