## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer Codex

```bash
npm install -g @openai/codex
```

## 3. Configurer la clé API

macOS / Linux :

```bash
export ACEDATACLOUD_API_KEY="votre clé API"
```

Pour une validité à long terme, ajoutez cette ligne à `~/.zshrc` ou `~/.bashrc`. Utilisez Windows PowerShell :

```powershell
setx ACEDATACLOUD_API_KEY "votre clé API"
```

Après la configuration, rouvrez le terminal.

## 4. Configurer AceDataCloud

Éditez `~/.codex/config.toml` (pour Windows, c'est `%USERPROFILE%\.codex\config.toml`), ajoutez :

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Pour Windows, modifiez les deux dernières lignes en :

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Aucune nécessité de remplir `model` ; après le démarrage, vous pouvez choisir le modèle dans Codex. Les autres configurations existantes peuvent être conservées, ne créez pas de provider avec le même nom.

## 5. Démarrer

```bash
cd /path/to/your/project
codex
```

Une fois dans Codex, exécutez `/model`, confirmez que le Provider est `acedatacloud`, puis choisissez le modèle souhaité. Les enregistrements d'appels et le solde peuvent être consultés dans [Historique d'utilisation](https://platform.acedata.cloud/console/usages) et [Liste des applications](https://platform.acedata.cloud/console/applications).

Si un message indique qu'il manque une clé ou retourne 401, vérifiez que la variable d'environnement est bien configurée, puis fermez complètement et rouvrez le terminal et Codex.
