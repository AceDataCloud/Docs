---
title: "Guide de configuration de Codex CC Switch"
description: "Codex API guide - Ace Data Cloud"
---

CC Switch peut gérer le provider et la clé API de Codex via une interface graphique.

## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer CC Switch

Téléchargez et installez depuis [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), ou exécutez sur macOS :

```bash
brew install --cask cc-switch
```

## 3. Ajouter un provider

1. Ouvrez CC Switch, passez à **Codex**.
2. Cliquez sur **Add Provider**, choisissez **Custom**.
3. Remplissez :

| Champ     | Contenu                          |
| --------- | -------------------------------- |
| Nom       | `acedatacloud`                  |
| URL de base | `https://api.acedata.cloud/v1` |
| Clé API   | La clé API Ace Data Cloud que vous venez de copier |

Si CC Switch propose un éditeur de configuration personnalisé, la configuration doit rester comme suit :

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch enregistrera la clé API dans `~/.codex/auth.json` :

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Ne pas ajouter `env_key` ou `[model_providers.acedatacloud.auth]` dans le provider ci-dessus ; choisissez entre la configuration manuelle et la configuration CC Switch. Il n'est pas nécessaire de fixer `model`, vous pouvez le sélectionner directement dans Codex.

## 4. Activer et vérifier

Activez le provider `acedatacloud`, quittez complètement et redémarrez Codex ou VS Code. Exécutez `/model`, confirmez que le provider est `acedatacloud`, puis sélectionnez un modèle et envoyez un message simple.

Si vous obtenez un retour 401, confirmez que le provider activé est `acedatacloud`, et vérifiez si `OPENAI_API_KEY` dans `~/.codex/auth.json` correspond à la clé API Ace Data Cloud que vous avez copiée. Les enregistrements d'appels peuvent être consultés dans [Historique d'utilisation](https://platform.acedata.cloud/console/usages).
