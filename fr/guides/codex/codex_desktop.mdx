---
title: "Guide de configuration de Codex Desktop"
description: "Codex API guide - Ace Data Cloud"
---

Codex Desktop partage `~/.codex/config.toml` avec Codex CLI.

## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurer la clé API

macOS :

```bash
launchctl setenv ACEDATACLOUD_API_KEY "votre clé API"
```

Windows PowerShell :

```powershell
setx ACEDATACLOUD_API_KEY "votre clé API"
```

## 3. Configurer AceDataCloud

Éditez `~/.codex/config.toml` (pour Windows, c'est `%USERPROFILE%\.codex\config.toml`), ajoutez :

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Pour Windows, modifiez les deux dernières lignes en :

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Aucune saisie de `model` n'est nécessaire ; ouvrez Codex et sélectionnez directement le modèle.

## 4. Redémarrer et vérifier

Quittez complètement et rouvrez Codex Desktop, créez une tâche locale et envoyez un message simple. Le fournisseur doit s'afficher comme `acedatacloud` ; les appels réels peuvent être consultés dans [l'historique d'utilisation](https://platform.acedata.cloud/console/usages).

Si la configuration n'est pas effective, assurez-vous que vous modifiez le `~/.codex/config.toml` de l'utilisateur actuel, que la variable d'environnement est définie, puis redémarrez complètement l'application. Les tâches cloud ou les automatisations exécutées dans différents environnements nécessitent une configuration séparée de la clé dans l'environnement correspondant.
