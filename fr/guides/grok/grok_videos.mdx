Ce document présente les instructions d’intégration de l’API Grok Videos Generation, qui permet de générer des vidéos Grok Imagine (xAI) à partir de textes, d’images d’entrée et éventuellement d’images de référence.

## Processus de demande

Pour utiliser l’API, il faut d’abord demander le service correspondant sur la page [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). Une fois sur la page, cliquez sur le bouton « Acquire », comme illustré ci-dessous :

![](https://cdn.acedata.cloud/q6ytrc.png)

Si vous n’êtes pas encore connecté ou inscrit, vous serez automatiquement redirigé vers la page de connexion pour vous inscrire et vous connecter. Après connexion, vous reviendrez automatiquement à la page actuelle.

Lors de la première demande, un quota gratuit est offert, permettant d’utiliser l’API gratuitement.

## Description des modèles

Cette API prend en charge deux modèles :

- `grok-imagine-video` (par défaut) : supporte la génération de vidéo à partir de texte (uniquement avec `prompt`) et la génération de vidéo à partir d’image (avec `image_url`), avec un coût moindre.
- `grok-imagine-video-1.5-preview` : supporte uniquement la génération de vidéo à partir d’image, **il est obligatoire** de fournir `image_url`.

## Utilisation de base

Voici la méthode d’utilisation de base : en fournissant un texte `prompt`, un modèle `model` et d’autres paramètres, vous pouvez générer la vidéo correspondante.

Ici, nous configurons les en-têtes de la requête (Request Headers), notamment :

- `accept` : le format de réponse souhaité, ici `application/json` pour un format JSON.
- `authorization` : la clé d’API pour appeler l’API, sélectionnable directement après la demande.

Le corps de la requête (Request Body) comprend :

- `prompt` : texte décrivant le contenu vidéo à générer. Obligatoire pour la génération vidéo à partir de texte avec `grok-imagine-video` ; optionnel si `image_url` est fourni.
- `model` : modèle de génération vidéo, optionnel, `grok-imagine-video` (par défaut) ou `grok-imagine-video-1.5-preview`.
- `image_url` : URL de l’image d’entrée pour la génération vidéo à partir d’image. Obligatoire si `model` est `grok-imagine-video-1.5-preview`.
- `reference_image_urls` : tableau optionnel d’URLs d’images de référence pour guider le style ou le contenu de la vidéo.
- `aspect_ratio` : ratio largeur/hauteur de la vidéo générée, options : `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution` : résolution de sortie, options : `480p` (par défaut) ou `720p`. Plus la résolution est élevée, plus le quota consommé est important.
- `duration` : durée de la vidéo générée (en secondes), plage de 1 à 15, par défaut 8. La facturation se fait à la seconde de sortie.
- `callback_url` : URL de rappel asynchrone. Si défini, l’API retourne immédiatement un `task_id` et POSTera le résultat à cette URL une fois la tâche terminée.

Cliquez sur le bouton « Try » pour tester, le résultat obtenu est similaire à ceci :

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Les champs retournés sont :

- `success` : indique si la génération vidéo a réussi.
- `task_id` : identifiant de la tâche de génération vidéo.
- `trace_id` : identifiant de suivi de la requête, utile pour le débogage.
- `data` : liste des résultats vidéo générés.
  - `id` : identifiant unique de la vidéo générée.
  - `video_url` : URL de la vidéo générée.
  - `state` : état de la tâche vidéo, options : `pending` / `succeeded` / `failed`.

Il suffit de récupérer la vidéo via l’URL `video_url` dans `data`.

Exemple de commande CURL correspondante :

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

Exemple de code Python correspondant :

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Génération vidéo à partir d’image

Pour générer une vidéo à partir d’une image d’entrée, fournissez `image_url`. Avec `grok-imagine-video-1.5-preview`, ce champ est obligatoire :

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## Guidage par images de référence

Pour guider le style ou le contenu de la vidéo avec une ou plusieurs images de référence, transmettez un tableau d’URLs dans `reference_image_urls` :

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## Rappel asynchrone (callback)

La génération vidéo nécessite un certain temps de traitement. Si vous ne souhaitez pas maintenir une connexion longue, vous pouvez fournir `callback_url`. L’API retournera immédiatement un `task_id`, et POSTera le résultat final à cette URL une fois la tâche terminée :

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

La réponse immédiate sera :

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Consultation du résultat de la tâche

Si vous utilisez le rappel asynchrone ou souhaitez interroger l’état d’une tâche, vous pouvez utiliser l’[API Grok Tasks](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) pour consulter le statut et le résultat via le `task_id`.

## Tarification

Le service facture en fonction de la « durée de sortie » de la vidéo générée, le prix unitaire dépend du `model` et de la `resolution`. Le prix total = prix unitaire × `duration` (par défaut 8 secondes). La résolution `720p` est plus coûteuse que `480p`, et `grok-imagine-video-1.5-preview` est plus cher que `grok-imagine-video`. Les tarifs précis sont disponibles sur la page de tarification.

## Gestion des erreurs

En cas de problème, l’API retourne un code d’erreur et une description. Les erreurs courantes sont :

- `400` : paramètres de requête incorrects, par exemple absence de `prompt` pour la génération texte, absence de `image_url` pour `grok-imagine-video-1.5-preview`, ou `duration` hors plage 1–15.
- `401` : échec d’authentification, token invalide ou non compatible avec l’API.
- `403` : solde insuffisant, ou refus dû à la modération du contenu du prompt.
- `429` : trop de requêtes, limitation en amont, veuillez réessayer plus tard.
- `500` : erreur serveur interne ou échec de génération en amont.
