MiMo 2.6 Pro et MiMo 2.6 Flash sont des modèles de la série Xiaomi MiMo. Cette interface utilise le format OpenAI Chat Completions et facture selon les tokens d’entrée, de sortie et de correspondance du cache.

## Modèles et interface

| Modèle                | Positionnement           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Analyse complexe, raisonnement et appel d’outils |
| `mimo-v2.6-flash` | Conversations quotidiennes et tâches légères    |

Activez MiMo et obtenez les identifiants API correspondants, puis envoyez des requêtes à `https://api.acedata.cloud/mimo/chat/completions`. Le `base_url` du SDK OpenAI peut être défini sur `https://api.acedata.cloud/mimo`. L’entrée unifiée `/v1/chat/completions` nécessite également les autorisations de service correspondantes.

Le premier lot d’interfaces couvre les Chat Completions textuels ; les images, l’audio, la vidéo, la recherche web, Responses, Messages, Batch et UltraSpeed ne font pas partie de cette publication.

## Exemple Python

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

L’exemple présente la syntaxe de la requête ; un exemple de réponse réelle sera ajouté après la validation du service.

## Streaming, raisonnement et appel d’outils

Définissez `stream=true` pour recevoir des SSE ; si l’utilisation finale est nécessaire, transmettez `stream_options={"include_usage": true}`. Le client doit traiter les incréments de contenu, de contenu de raisonnement et d’appel d’outils, ainsi que l’événement usage final.

Utilisez `thinking.type=enabled` pour activer le raisonnement, et `disabled` pour le désactiver. `reasoning_content` et le `content` final sont renvoyés séparément ; lors de la poursuite d’appels d’outils, conservez le contenu de raisonnement du message de l’assistant, les `tool_calls` complets et le `tool_call_id` correspondant.

Ne soumettez que des déclarations d’outils avec `type=function`, et `tool_choice` ne prend en charge que `auto`. L’application est responsable d’exécuter les outils et de renvoyer les résultats ; le renvoi d’un appel d’outil par le modèle ne signifie pas que l’outil a déjà été exécuté. La recherche web intégrée au service n’est pas encore ouverte.

## Facturation

`prompt_tokens` inclut les entrées correspondant au cache ; `prompt_tokens_details.cached_tokens` est calculé au tarif du cache, et les autres entrées sont calculées au tarif d’entrée standard. `completion_tokens` inclut la sortie de raisonnement ; ne cumulez pas une seconde fois les tokens de raisonnement. Les appels en streaming sont également facturés selon l’utilisation réelle finale.

Les prix affichés dans la console prévalent, et le coût en dollars américains des Credit dépend du forfait acheté. Les requêtes échouées ne doivent pas être considérées comme terminées avec succès ; si vous devez vérifier une facturation, veuillez fournir l’identifiant de suivi présent dans la réponse.

## Gestion des erreurs

Pour les erreurs de paramètres, vérifiez le format de la requête ; pour les erreurs d’authentification ou d’autorisation, vérifiez les identifiants et l’activation du service ; en cas de 429, effectuez une nouvelle tentative avec temporisation progressive. Un code 503 peut être renvoyé lorsqu’aucun modèle sain n’a de capacité disponible. Lorsqu’une interruption survient après le début d’une réponse en streaming, vérifiez d’abord les résultats et l’utilisation déjà reçus, afin d’éviter de répéter aveuglément la requête.
