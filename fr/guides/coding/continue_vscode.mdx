Continue prend en charge l'API compatible avec OpenAI. Pour s'assurer que l'on utilise les Chat Completions, il est nécessaire de définir explicitement `useResponsesApi: false`.

## Configuration

Ajoutez dans la configuration YAML locale de Continue :

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Enregistrez `ACEDATACLOUD_API_KEY` dans la gestion des secrets de Continue, ne soumettez pas le vrai Token dans la configuration du projet. La configuration JSON de Continue est désormais obsolète, la nouvelle configuration utilise YAML.

## Vérification

Rechargez VS Code, ouvrez la barre latérale de Continue, sélectionnez le modèle dans Local Config et envoyez `Reply only OK` ; exécutez ensuite à nouveau la tâche de fichier en lecture seule. Si la requête est incorrectement envoyée à `/responses`, vérifiez si `useResponsesApi: false` se trouve dans l'entrée de ce modèle.
