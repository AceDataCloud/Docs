## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configuration

Roo Code fournit officiellement un Provider compatible OpenAI et exige que le modèle prenne en charge les outils/appels de fonctions OpenAI natifs.

1. Ouvrez les paramètres de Roo Code dans VS Code.
2. Définissez **API Provider** sur **OpenAI Compatible**.
3. Renseignez :

| Champ       | Valeur                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | La clé API que vous venez de copier                  |
| Model ID | L’ID du modèle sélectionné dans l’assistant de configuration Coding         |

![Interface de configuration Roo Code OpenAI Compatible](https://cdn.acedata.cloud/b6a0e7156438.png)

Ensuite, définissez les options context, max output, images et computer-use selon les capacités réelles du modèle. Enfin, enregistrez la configuration et rechargez VS Code.

## 3. Vérification

Envoyez d’abord `Reply only OK`, puis demandez à Roo Code de lire un fichier de test. Si le chat normal réussit mais que les outils Agent échouent, remplacez le modèle par un modèle prenant en charge le tool calling natif, et confirmez que le point de terminaison compatible peut renvoyer correctement en streaming les paramètres et les résultats des outils.
