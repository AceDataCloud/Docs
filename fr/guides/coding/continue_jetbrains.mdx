Le plugin Continue de JetBrains utilise le même format de modèle YAML que VS Code ; la configuration et le Secret doivent appartenir à l'utilisateur exécutant le plugin JetBrains.

## Configuration

Ajoutez dans la configuration YAML locale de Continue :

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Enregistrez `ACEDATACLOUD_API_KEY` dans les secrets de Continue. Le scénario de Développement à Distance doit être configuré sur l'hôte où le plugin s'exécute réellement.

## Vérification

Redémarrez l'IDE JetBrains, ouvrez la fenêtre d'outils Continue, sélectionnez le modèle Local Config et envoyez `Reply only OK` ; exécutez ensuite à nouveau la tâche de fichier en lecture seule. Si le vieux modèle est toujours utilisé, redémarrez le backend distant et vérifiez l'indentation YAML.
