## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configurer le Provider

Le plugin JetBrains de Kilo Code utilise le format Provider `kilo.jsonc`. La configuration doit se trouver dans l'environnement utilisateur où le plugin est réellement exécuté ; lors du développement à distance, il s'agit généralement de l'hôte backend distant.

Écrivez dans `~/.config/kilo/kilo.jsonc` :

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Dans l'environnement où le backend JetBrains est lancé, exportez `ACEDATACLOUD_API_KEY`, puis redémarrez l'IDE ou le backend distant.

## 3. Vérification

Sélectionnez `acedatacloud/MODEL_ID`, envoyez `Reply only OK`, puis laissez l'Agent lire un fichier de test. Si cela fonctionne localement mais échoue à distance, vérifiez en priorité si le fichier de configuration et les variables d'environnement sont correctement écrits sur l'hôte distant.
