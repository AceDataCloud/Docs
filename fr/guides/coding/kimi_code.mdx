## 1. Obtenir une clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir une clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer Kimi Code

macOS / Linux :

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell :

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Vous pouvez également l’installer via npm :

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Configurer AceDataCloud

Modifiez `~/.kimi/config.toml`, et ajoutez la configuration suivante :

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "votre clé API"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Accédez au [catalogue des modèles](https://platform.acedata.cloud/models) pour consulter les noms des modèles (par exemple `claude-opus-5`, `gpt-6-sol`), puis remplacez tous les `MODEL_ID` par le même nom ; pour une validation précise, utilisez la valeur `id` de la réponse `/v1/models` comme référence. Cette valeur est le nom du modèle utilisé par le paramètre API `model`, et non l’UUID du service ou de l’API. `type = "openai"` utilise le protocole OpenAI Chat Completions.

Le fichier de configuration contient la clé ; sous macOS / Linux, il est recommandé de limiter les autorisations :

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Vérifier et démarrer

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Après être entré dans le projet, exécutez `kimi` pour commencer à l’utiliser. Si vous obtenez une erreur 401, vérifiez la clé API ; si le message model not found s’affiche, assurez-vous que `default_model`, le nom dans la table des modèles et le champ `model` utilisent le même ID.
