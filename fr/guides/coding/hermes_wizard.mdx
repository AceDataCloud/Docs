## 1. Obtenir l’API Key

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez l’API Key.

![Obtenir l’API Key Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Exécuter l’assistant

```bash
hermes model
```

Sélectionnez **Custom endpoint**, puis renseignez dans l’ordre :

| Champ             | Valeur                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | L’API Key qui vient d’être copiée                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Accédez au [catalogue des modèles](https://platform.acedata.cloud/models) pour consulter et renseignez le nom du modèle cible tel quel, par exemple `claude-opus-5`, `gpt-6-sol` |
| Context length | Laissez vide pour une détection automatique, ou renseignez selon le catalogue des modèles                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` est le nom du modèle utilisé par le paramètre `model` dans les requêtes API, et non l’UUID du service ou de l’API. Vous pouvez d’abord le consulter dans le [catalogue des modèles](https://platform.acedata.cloud/models) ; si une vérification précise est nécessaire, utilisez ensuite l’API Key actuelle pour demander `GET https://api.acedata.cloud/v1/models`, puis copiez la valeur `id` du modèle cible depuis le tableau `data` de la réponse.

L’assistant écrira dans `~/.hermes/config.yaml` et dans le fichier d’identifiants local.

## 3. Vérification

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Si l’assistant n’a pas enregistré la configuration, vous pouvez exécuter `hermes model --reset` puis réessayer ; 401 indique que l’API Key est invalide ou qu’elle n’a pas été lue par la configuration de l’utilisateur actuel.
