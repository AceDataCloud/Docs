## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Configuration

Kilo CLI lit `kilo.jsonc` et récupère la clé API depuis le shell à partir duquel le CLI est lancé.

Écrivez dans `~/.config/kilo/kilo.jsonc` :

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Ensuite, exportez le Token dans le shell actuel :

```bash
export ACEDATACLOUD_API_KEY="COLLEZ_VOTRE_TOKEN_ACEDATACLOUD_ICI"
```

## 3. Vérification

```bash
kilo run -m acedatacloud/MODEL_ID "Répondre seulement OK"
```

Si le CLI ne peut pas lire le Token, assurez-vous que la variable a été `exportée`, et pas seulement écrite dans un fichier `.env` non chargé.
