Qwen Code utilise la configuration `modelProviders` dans `~/.qwen/settings.json` pour personnaliser le Provider. Ici, le protocole compatible avec OpenAI est utilisé.

## Configuration

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` doit être un tableau. Les entrées du Provider sont configurées de manière indépendante et n'hériteront pas automatiquement d'autres paramètres de contexte, d'en-tête ou de corps de niveau supérieur.

## Vérification

```bash
export ACEDATACLOUD_API_KEY="COLLEZ_VOTRE_JETON_API_ACEDATACLOUD_ICI"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Répondez seulement OK"
```

Entrez et envoyez `Répondez seulement OK`, puis exécutez à nouveau l'outil de lecture seule. Si l'endpoint strictement compatible refuse le format de résultat de l'outil, veuillez vérifier la version actuelle de Qwen Code et les instructions de compatibilité officielles.
