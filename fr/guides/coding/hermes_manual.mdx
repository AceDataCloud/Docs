## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Enregistrer la clé

Écrivez dans `~/.hermes/.env` :

```dotenv
ACEDATACLOUD_API_KEY=Votre clé API
```

## 3. Configurer le Provider

Ajoutez dans `~/.hermes/config.yaml` :

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Accédez au [catalogue des modèles](https://platform.acedata.cloud/models) pour voir les noms des modèles (par exemple `claude-opus-5`, `gpt-6-sol`), et remplacez tous les `MODEL_ID` par le même nom ; pour une validation précise, référez-vous à la valeur `id` dans la réponse de `/v1/models`. Cette valeur est le nom du modèle utilisé par le paramètre API `model`, et non l’UUID du service ou de l’API. N’écrivez pas de vraie clé dans le YAML et ne soumettez pas `.env`.

## 4. Vérifier

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Si vous obtenez un retour 401, vérifiez `~/.hermes/.env` ; si la configuration ne prend pas effet, quittez complètement et redémarrez Hermes.
