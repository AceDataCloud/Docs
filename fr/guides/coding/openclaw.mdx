## 1. Obtenir la clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez aux applications disponibles et copiez la clé API.

![Obtenir la clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer OpenClaw et le plugin

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Le plugin nécessite OpenClaw `2026.4.2` ou une version supérieure, offrant actuellement des capacités de Chat et de Recherche Web.

## 3. Configurer la clé

Il est recommandé d'utiliser l'onboarding :

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "votre clé API"
```

Vous pouvez également utiliser des variables d'environnement :

```bash
export ACEDATACLOUD_API_KEY="votre clé API"
```

## 4. Optionnel : configuration manuelle

Si vous n'utilisez pas l'onboarding, activez le plugin et définissez le modèle par défaut dans `~/.openclaw/openclaw.json` :

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Ne mettez pas la clé API dans ce fichier ; continuez à utiliser des variables d'environnement.

## 5. Choisir un modèle et vérifier

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Répondre seulement OK"
```

Remplacez `MODEL_ID` par le modèle actuellement fourni par Coding Plan. Pour le définir comme modèle par défaut, exécutez :

```bash
openclaw models set acedatacloud/MODEL_ID
```

Les enregistrements d'appels peuvent être consultés dans [Historique d'utilisation](https://platform.acedata.cloud/console/usages). 401 indique que la clé est invalide ; si le modèle n'existe pas, vérifiez d'abord l'ID exact et la version du plugin. Le `cost: 0` dans le répertoire des plugins indique seulement qu'il n'est pas réévalué par OpenClaw, les frais réels étant toujours enregistrés par Ace Data Cloud.

## Recherche Web

```bash
openclaw infer web search \
  --provider acedatacloud --query "derniers frameworks d'agents IA" --limit 5
```

Actuellement, ne considérez pas les capacités d'images, de vidéos ou de musique mentionnées dans la présentation du plugin comme des capacités natives du Provider OpenClaw.
