La documentation officielle du modèle personnalisé Coze prend en charge l'API Anthropic Messages. Différentes versions de locataires Coze peuvent traiter les en-têtes, la concaténation de chemins, le streaming et les appels d'outils de manière différente. Pour une première intégration, veuillez vérifier chaque point ci-dessous.

## Configuration

1. Accédez à la gestion des modèles Coze et ajoutez un modèle personnalisé.
2. Sélectionnez le protocole API Anthropic Messages.
3. Remplissez l'URL de l'API de base avec `https://api.acedata.cloud`.
4. Remplissez la clé API avec votre jeton API Ace Data Cloud.
5. Remplissez le modèle avec l'ID de modèle précis qui prend en charge les messages Anthropic dans le répertoire des modèles.
6. Enregistrez et terminez le test de connexion Coze.
7. Dans Bot/Agent, envoyez `Reply only OK`, puis testez à nouveau l'appel d'outil.

## Limites Actuelles

- Différentes régions, versions ou forfaits Coze peuvent afficher différents formulaires.
- L'URL de l'API de base ne doit pas être répétée avec `/v1/messages` ; si l'interface utilisateur actuelle exige clairement l'URL API complète, suivez les indications du formulaire.
- Messages, Chat Completions et Responses sont trois voies indépendantes et ne peuvent pas se substituer pour la validation.
