## 1. Obtenir une clé API

Ouvrez la [liste des applications Ace Data Cloud](https://platform.acedata.cloud/console/applications), accédez à une application disponible et copiez la clé API.

![Obtenir une clé API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Installer OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Vous pouvez également utiliser npm :

```bash
npm install -g opencode-ai
```

## 3. Définir la clé API

```bash
export ACEDATACLOUD_API_KEY="votre clé API"
```

Pour qu’elle soit effective à long terme, ajoutez cette ligne à `~/.zshrc` ou `~/.bashrc`, puis rouvrez le terminal.

## 4. Configurer le Provider

Modifiez `~/.config/opencode/opencode.json` :

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Accédez au [catalogue des modèles](https://platform.acedata.cloud/models) pour consulter les noms des modèles (par exemple `claude-opus-5`, `gpt-6-sol`), et remplacez tous les `MODEL_ID` par le même nom ; pour une vérification précise, référez-vous à la valeur `id` dans la réponse de `/v1/models`. Cette valeur est le nom du modèle utilisé par le paramètre API `model`, et non l’UUID du service ou de l’API. Ace Data Cloud utilise ici Chat Completions, donc l’adaptateur est `@ai-sdk/openai-compatible`.

## 5. Vérifier et démarrer

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Ensuite, exécutez `opencode` dans le répertoire du projet. Si le modèle n’apparaît pas, vérifiez le chemin du fichier de configuration, la syntaxe JSON et les variables d’environnement ; 401 indique que la clé est invalide ou n’a pas été exportée.

L’extension IDE réutilise la même configuration d’exécution OpenCode, voir [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
