Aider se connecte à l'API compatible OpenAI via le préfixe de modèle `openai/` de LiteLLM.

## Configuration

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Remplacez `MODEL_ID` par le modèle choisi dans l'assistant de configuration Coding. Vous pouvez également écrire les options correspondantes dans le fichier local `.env` ou `.aider.conf.yml`, mais ne soumettez pas de Token réel.

## Vérification

```bash
aider --model openai/MODEL_ID --message "Répondre seulement OK"
```

Lors de la première utilisation d'un modèle inconnu, Aider peut indiquer un manque de métadonnées du modèle ; cela ne correspond pas à un échec d'authentification. Vérifiez le Token pour 401, vérifiez l'ID du modèle et l'URL de base `/v1` pour 404.
