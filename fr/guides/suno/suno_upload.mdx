SUNO nous permet de télécharger des audio de référence pour une création secondaire, ce document explique la méthode d'intégration des API associées.

Le téléchargement normal nécessite seulement `audio_url`, qui est une adresse CDN audio accessible publiquement. `mode` est par défaut `standard`, donc les appels existants n'ont pas besoin d'être modifiés.

Ici, nous entrons `audio_url` comme `https://cdn.acedata.cloud/suno_demo.mp3`, qui est une adresse CDN accessible publiquement.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

## Mode de téléchargement amélioré

Lorsque le téléchargement normal ne peut pas traiter l'audio que vous possédez ou que vous avez le droit d'utiliser, vous pouvez définir `mode` sur `enhanced`. Ce mode nécessite également de fournir un `name` de 1 à 100 caractères, et d'utiliser un `audio_url` HTTPS accessible publiquement.

Le téléchargement amélioré utilise un traitement asynchrone fixe, nécessitant généralement 2 minutes ou plus. Un traitement réussi consomme **1.87 Crédits**, soit environ **¥1.20/fois** selon le forfait maximum ; un échec de traitement ne coûte rien.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

L'interface renverra immédiatement `task_id` et `trace_id`. Utilisez [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) pour interroger la tâche, et après un traitement réussi, lisez l'ID audio téléchargé à partir de `response.data.audio_id`. Vous pouvez également fournir un `callback_url` HTTPS pour recevoir l'état final.

L'`audio_id` obtenu par le téléchargement amélioré peut être utilisé pour des Cover, Samples et Mashup. L'extraction de l'accompagnement et MIDI, la séparation de pistes complètes ainsi que la séparation voix/accompagnement peuvent encore être soumises à des restrictions selon le compte auquel appartient l'audio ; les opérations non listées ne garantissent pas un support d'utilisation inter-comptes. Plus l'audio est court, plus le taux de réussite du traitement est généralement élevé.
