---
title: "Documentation de l'API de génération de paroles Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Si vous souhaitez personnaliser la génération de chansons, mais que vous ne voulez pas vraiment écrire les paroles vous-même, vous pouvez utiliser l'API de génération de paroles fournie par AceDataCloud pour générer des paroles via un prompt. L'API est [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Le principal paramètre d'entrée de cette API est `prompt`, avec un paramètre optionnel `model` (valeurs optionnelles `default`, `remi-v1`, par défaut `default`), un exemple de remplissage est donné ci-dessous :

![](https://cdn.acedata.cloud/p53wtj.png)

Ici, nous avons entré le `prompt` suivant : `A song about winter`, générant une chanson liée à l'hiver.

Cliquez sur exécuter, le résultat est le suivant :

On peut voir que `data` est un tableau, chaque fois plusieurs candidats de paroles sont retournés, où chaque élément du champ `text` est le contenu des paroles, `title` est le titre, et `tags` sont les étiquettes de style recommandées.

Une fois les paroles obtenues, nous pouvons utiliser [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) pour générer des chansons personnalisées.
