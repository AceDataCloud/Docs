---
title: "Documentation de l'API de génération de paroles Suno"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

Si vous souhaitez personnaliser la génération de chansons, mais que vous ne voulez pas vraiment écrire les paroles vous-même, vous pouvez utiliser l'API de génération de paroles fournie par AceDataCloud pour générer des paroles via un prompt. L'API est [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

Le principal paramètre d'entrée de cette API est `prompt`, avec un paramètre optionnel `model` (par défaut chirp-v3), un exemple de remplissage est donné ci-dessous :

![](https://cdn.acedata.cloud/p53wtj.png)

Ici, nous avons entré le `prompt` suivant : `A song about winter`, générant une chanson liée à l'hiver.

Cliquez sur exécuter, le résultat est le suivant :

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Verse]\nDes flocons de neige tombent du ciel\nLe froid de l'hiver\nOh comme cela me fait planer\nJe m'emmitoufle dans des couches\nOh si douillet\nSortir et sentir le gel sur mon nez\nVoir\n\n[Verse 2]\nLe monde est couvert d'une couverture blanche\nDes glaçons pendent\nScintillant si brillamment\nL'air frais remplit mes poumons à chaque respiration\nMarcher dans la neige\nLaisser des empreintes qui ne seront pas effacées\n\n[Chorus]\nOh\nLe froid de l'hiver\nC'est une saison que j'aime tant\nLa chute de neige apporte un sentiment si divin\nLe froid de l'hiver\nC'est un moment magique",
    "title": "Le Froid de l'Hiver",
    "status": "complete"
  }
}
```

On peut voir que le champ `text` de `data` contient les informations des paroles.

Une fois les paroles obtenues, nous pouvons utiliser [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) pour générer des chansons personnalisées.
