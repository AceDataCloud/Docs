---
title: "Instructions d’intégration de l’API de génération de paroles Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Si vous souhaitez générer des chansons personnalisées, mais que vous ne voulez pas vraiment écrire les paroles vous-même, vous pouvez utiliser l’API de génération de paroles fournie par AceDataCloud pour générer des paroles via un prompt. L’API est [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Facturation : après une génération réussie, le coût standard de chaque requête est de **0.08 Credits**. Lorsqu’une requête renvoie plusieurs candidats de paroles, elle n’est tout de même facturée qu’une seule fois ; les remises de consommation applicables sont soumises à la facture réelle, les requêtes échouées ne sont pas facturées.

Le principal paramètre d’entrée de cette API est `prompt`, avec `model` en option (valeurs possibles : `default`, `remi-v1`, valeur par défaut : `default`), l’exemple de remplissage est le suivant :

![](https://cdn.acedata.cloud/p53wtj.png)

Ici, le `prompt` que nous saisissons est `A song about winter`, afin de générer une chanson liée à l’hiver.

Cliquez sur exécuter, le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433

```

On peut voir que `data` est un tableau, qui renvoie plusieurs candidats de paroles à chaque fois, où le champ `text` de chaque élément est le contenu des paroles, `title` est le titre, et `tags` sont les étiquettes de style musical recommandées.

Après avoir obtenu les paroles, nous pouvons utiliser [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) pour effectuer une génération de chanson personnalisée.
