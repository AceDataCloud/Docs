---
title: "Instructions d’intégration de l’API de clonage vocal Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nous permet de créer des personnages vocaux personnalisés à partir de n’importe quel fichier audio, afin de réaliser un clonage vocal pour la génération de musique. Contrairement à l’API Persona existante (qui utilise un `audio_id` généré par Suno), cette API accepte un `audio_url` accessible publiquement, c’est-à-dire votre propre enregistrement vocal. Ce document explique la méthode d’intégration de l’API de clonage vocal.

## Première étape : créer un personnage vocal

Cette API comporte trois paramètres d’entrée : `audio_url` (obligatoire), qui est une URL de fichier audio MP3 ou WAV accessible publiquement contenant une voix claire d’une seule personne ; `name` et `description` (facultatifs), qui correspondent au nom et à la description du personnage vocal.

> **Exigences relatives au fichier audio**
> - Le format audio doit être `WAV` ou `MP3`
> - La durée audio doit être comprise entre `10~240 secondes`, il est recommandé d’utiliser un extrait vocal propre d’une seule personne de `30~60 secondes`
> - L’audio doit contenir une **voix parlée ou chantée claire et identifiable d’une seule personne**
> - Veillez à éviter les **bruits de fond, accompagnements, échos, réverbérations** ; les chansons complètes avec accompagnement ne passent généralement pas la vérification d’empreinte vocale
> - Ne pas inclure **plusieurs locuteurs** ou **plusieurs voix**
> - Les extraits dont le volume est trop faible, la voix peu claire ou le bruit trop important peuvent entraîner un **échec du clonage** ou une **qualité de génération médiocre**
> **Explication des restrictions d’utilisation**
> - Les personnages vocaux créés en téléversant un audio sont des **ressources privées**
> - Ce personnage vocal **ne prend pas en charge la réutilisation entre comptes**
> - Il est recommandé de l’utiliser dès que possible après sa création réussie ; une longue période sans utilisation peut entraîner une **expiration ou une indisponibilité**
> - Le `name` renvoyé est généré automatiquement par le système, veuillez vous référer au `persona_id` renvoyé

> **Veuillez d’abord réessayer en cas d’échec de l’appel**
> Le clonage vocal est une tâche intensive en puissance de calcul ; même si le matériau est entièrement conforme, il existe une certaine probabilité d’échec occasionnel, avec des retours courants tels que
> `voices_sound_different` (échec de la vérification d’empreinte vocale), etc. **Ce type d’échec n’est pas lié à la qualité audio ; réessayer avec le même matériau permet généralement de réussir**,
> il est recommandé d’implémenter 1 à 2 tentatives automatiques pour les résultats en échec lors de l’intégration. Les requêtes ayant échoué ne sont pas facturées.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Le `https://cdn.acedata.cloud/suno_demo.mp3` ci-dessus est un exemple de matériau pouvant être appelé directement (MP3, 41 secondes, voix seule sans accompagnement).
> Si vous avez besoin d’un exemple au format `WAV`, vous pouvez utiliser
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 secondes, mono 44,1 kHz).

Le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Comme vous pouvez le voir, le champ `persona_id` de `data` est l’ID du personnage vocal créé. Le champ `is_public` est toujours `false`, car les personnages vocaux créés en téléversant un audio sont privés. Notez que le `name` renvoyé est généré automatiquement par le système ; veuillez ensuite utiliser `persona_id` pour référencer ce personnage vocal.

## Deuxième étape : utiliser le personnage vocal pour générer de la musique

Après avoir obtenu l’ID du personnage vocal, nous pouvons utiliser la [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) pour générer de la musique. Définissez `action` sur `generate`, et définissez `persona_id` sur l’ID du personnage vocal renvoyé ci-dessus ; les chansons générées utiliseront la voix clonée pour le chant.

> **Remarque :** le clonage vocal prend uniquement en charge les modèles `chirp-v4-5` et supérieurs (tels que `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), et ne prend pas en charge `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` peut être utilisé pour la génération `generate`, et peut également être utilisé pour les reprises `cover` / `upload_cover`. Il n’est pas nécessaire de renseigner simultanément `vocal_gender` lors de la spécification d’une voix ; la similarité vocale dépend toujours du matériau de référence et du résultat généré.

Les voix créées via cette interface sont des ressources privées. Avant de reprendre une chanson existante, appelez d’abord `/suno/upload`, en transmettant l’`audio_url` de la chanson originale et le `persona_id` de cette voix ; une fois le téléversement réussi, utilisez le `data.audio_id` renvoyé et le même `persona_id` pour appeler `/suno/audios` :

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

La création de la voix, le téléversement de la chanson originale et la reprise doivent utiliser le même canal de service. Veuillez ne pas réutiliser directement des ID de chansons précédemment non associés à cette voix privée ; pour plus de détails, consultez [Téléverser un audio de référence Suno](https://platform.acedata.cloud/documents/suno-upload).
