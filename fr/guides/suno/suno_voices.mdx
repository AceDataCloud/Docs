SUNO nous permet de créer des personnages vocaux personnalisés à partir de n'importe quel fichier audio, réalisant ainsi le clonage de voix pour la génération musicale. Contrairement à l'API Persona existante (utilisant le `audio_id` généré par Suno), cette API accepte une `audio_url` accessible publiquement, c'est-à-dire votre propre enregistrement vocal. Ce document explique comment intégrer l'API de clonage de voix.

Cette API a trois paramètres d'entrée : `audio_url` (obligatoire), qui est une URL d'un fichier audio au format MP3 ou WAV accessible publiquement, contenant une voix humaine claire d'une seule personne ; `name` et `description` (facultatif), qui sont le nom et la description du personnage vocal.

**Exigences pour le fichier audio :**

- Format : MP3 ou WAV
- Durée : au moins 10 secondes
- Contenu : voix humaine claire d'une seule personne, en minimisant le bruit de fond ou la musique

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "Ma Voix",
  "description": "Une voix masculine chaleureuse"
}'
```

Le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "Ma Voix",
    "is_public": false
  }
}
```

On peut voir que le champ `persona_id` dans `data` est l'ID du personnage vocal créé. Le champ `is_public` est toujours `false`, car le personnage vocal créé par le téléchargement de l'audio est privé.

Une fois que nous avons l'ID du personnage vocal, nous pouvons utiliser l'[API de génération d'audios Suno](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) pour générer de la musique. Il suffit de définir `action` sur `vox` et de définir `persona_id` sur la valeur retournée ci-dessus, la chanson générée sera chantée avec la voix clonée.
