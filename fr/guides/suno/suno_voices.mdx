title: "Instructions d'intégration de l'API de clonage vocal Suno"

---

SUNO nous permet de créer des personnages vocaux personnalisés à partir de n'importe quel fichier audio, réalisant ainsi un clonage vocal pour la génération musicale. Contrairement à l'API Persona existante (qui utilise un `audio_id` généré par Suno), cette API accepte une `audio_url` accessible publiquement, c'est-à-dire votre propre enregistrement vocal. Ce document explique comment intégrer l'API de clonage vocal.

## Première étape : créer un personnage vocal

Cette API comporte trois paramètres d'entrée : `audio_url` (obligatoire), qui est une URL publique d'un fichier audio au format MP3 ou WAV contenant une voix claire d'une seule personne ; `name` et `description` (optionnels), qui sont le nom et la description du personnage vocal.

**Exigences pour le fichier audio :**
- Format : MP3 ou WAV
- Durée : au moins 10 secondes
- Contenu : voix claire d'une seule personne, avec un minimum de bruit de fond ou de musique

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

On peut voir que le champ `persona_id` dans `data` est l'ID du personnage vocal créé. Le champ `is_public` est toujours `false`, car les personnages vocaux créés via l'upload audio sont privés.

## Deuxième étape : générer de la musique avec le personnage vocal

Une fois que vous avez l'ID du personnage vocal, vous pouvez utiliser la [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) pour générer de la musique. Définissez `action` sur `generate` et `persona_id` sur l'ID du personnage vocal obtenu ci-dessus ; la chanson générée sera chantée avec la voix clonée.

> **Remarque :** Le clonage vocal ne prend en charge que les modèles `chirp-v4-5` et supérieurs (comme `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), il ne prend pas en charge `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

On peut voir que la chanson générée est chantée avec la voix clonée. Le `persona_id` peut également être utilisé avec l'action `cover` pour réinterpréter des chansons existantes avec la voix clonée.
