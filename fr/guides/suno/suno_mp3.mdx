---
title: "Documentation de l'API Suno MP3 URL"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

L'API Suno MP3 URL génère un chemin se terminant par `.mp3` pour un morceau de musique existant, adapté aux scénarios où les anciens liens de téléchargement sont invalides, pour la lecture sur mobile ou pour récupérer à nouveau une URL audio publique.

Le paramètre requis `audio_id` est l'ID audio retourné par l'interface de génération audio de Suno. Chaque appel crée une tâche URL MP3 indépendante, sans modifier la tâche de génération de musique originale ni changer l'ID audio d'origine.

## Appel synchrone

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

En cas de succès, `data[0].file_url` est l'adresse audio jouable. L'interface essaiera d'abord de stocker à `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3` ; si le stockage prend plus de 30 secondes ou échoue, elle renverra l'adresse audio source actuellement disponible.

## Appel asynchrone

Lorsque le temps de traitement est long, vous pouvez passer `async: true` :

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Ensuite, interrogez `export_task_id` via `/suno/tasks`. Vous pouvez également fournir `callback_url` pour recevoir le résultat final une fois la tâche terminée. La réponse synchrone, la requête de tâche et le rappel utilisent la même structure de données finale.

## Remarques

- `audio_id` doit provenir d'un audio Suno identifiable.
- Les tâches d'URL MP3 sont indépendantes des tâches de génération de musique d'origine.
- Le stockage peut attendre au maximum 30 secondes ; un dépassement de délai ou un échec de stockage ne bloquera pas le résultat et reviendra à l'adresse audio source.
- Il est conseillé que le côté métier télécharge rapidement les résultats obtenus et les conserve selon sa propre stratégie de conservation des données.
