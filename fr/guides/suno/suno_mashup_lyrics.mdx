Si vous souhaitez utiliser les paroles de deux chansons pour générer une chanson mixte, vous pouvez d'abord utiliser cette API pour générer les paroles correspondantes. L'API est [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Les principaux paramètres d'entrée de cette API sont `lyrics_a` et `lyrics_b`, un exemple de remplissage est donné ci-dessous :

![](https://cdn.acedata.cloud/g9n3t6.png)

Cliquez sur exécuter, le résultat est le suivant :

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

On peut voir que le champ `text` de `data` contient les informations des paroles.

Une fois que nous avons les paroles, nous pouvons utiliser [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) pour générer des chansons personnalisées.
