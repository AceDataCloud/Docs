---
title: "Suno API de connexion pour le style de chanteur personnalisé"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO nous permet de définir le style de chanteur pour les chansons déjà générées, puis de procéder à une création secondaire en fonction de cela. Ce document explique la méthode de connexion à l'API concernée.

Cette API n'a que trois paramètres d'entrée, d'abord `audio_id`, qui est un ID de chanson déjà générée avec succès par l'officiel, ensuite `name` et `description`, qui sont un nom et une description du style de chanteur.

Ici, nous entrons `audio_id` comme `https://cdn.acedata.cloud/2qhzs3.png`, que vous pouvez consulter dans [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) pour générer des chansons personnalisées, et finalement obtenir `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Le résultat est le suivant :

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

On peut voir que le champ `persona_id` dans `data` est l'ID du style de chanteur généré.

Une fois que nous avons l'ID du style de chanteur, nous pouvons utiliser [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) pour générer des chansons personnalisées, par exemple, en passant `action` comme `artist_consistency`, tout en passant `audio_id` comme l'ID de la chanson téléchargée, et en téléchargeant également le paramètre `persona_id`, qui est la valeur de l'ID du style de chanteur retourné ci-dessus, afin de générer de nouvelles chansons selon le style de chanteur de référence.
