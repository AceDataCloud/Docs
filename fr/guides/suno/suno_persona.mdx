---
title: "Documentation d’intégration de l’API de style de chanteur personnalisé Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO nous permet de définir un style de chanteur pour une chanson déjà générée, puis d’effectuer une création secondaire basée sur celui-ci. Ce document explique la méthode d’intégration des API associées.

La requête `GET /suno/persona` pour consulter la liste et la requête `DELETE /suno/persona` pour supprimer des enregistrements ne sont pas facturées et ne nécessitent aucun en-tête supplémentaire de requête hors facturation. L’opération de création `POST /suno/persona` reste facturée selon les règles de tarification de l’interface.

Sur les routes de création prenant en charge la vérification de la voix, vous pouvez utiliser l’application d’origine et l’identité de l’appelant pour transmettre le `persona_id` des résultats de création à `POST /suno/availability`. Lorsqu’il est confirmé comme disponible, la réponse renvoie `data.available=true`. [Guide de vérification de disponibilité de la voix](https://platform.acedata.cloud/documents/suno-availability-integration)

Cette API ne comporte que trois paramètres d’entrée : d’abord `audio_id`, qui est l’ID d’une chanson déjà générée avec succès sur la plateforme officielle ; ensuite `name` et `description`, qui correspondent à un nom et une description du style de chanteur.

Ici, le `audio_id` que nous saisissons est `https://cdn.acedata.cloud/2qhzs3.png`. Vous pouvez vous référer à [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) pour effectuer une génération de chanson personnalisée, puis obtenir finalement `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Le résultat est le suivant :

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Vous pouvez voir que le champ `persona_id` de `data` est l’ID du style de chanteur généré.

Après avoir obtenu l’ID du style de chanteur, nous pouvons utiliser [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) pour effectuer une génération de chanson personnalisée. Par exemple, transmettez `artist_consistency` à `action`, transmettez l’ID de la chanson importée à `audio_id`, et transmettez également le paramètre `persona_id`. Cette valeur est l’ID du style de chanteur renvoyé ci-dessus, ce qui permet de générer une nouvelle chanson selon le style de chanteur de référence.
