SUNO nous permet d'obtenir des fichiers audio au format wav. Ce document explique comment intégrer les API associées.

Le paramètre d'entrée principal de cette API est `audio_id`, qui est l'ID de la chanson généré par l'officiel ; il est également possible de fournir une adresse de rappel asynchrone `callback_url`.

Ici, l'`audio_id` que nous entrons est `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Le résultat est le suivant :

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

On peut voir que le champ `file_url` dans `data` est le fichier audio au format wav obtenu, c'est une adresse CDN accessible publiquement.

> **À propos de la persistance des liens WAV**
> La plateforme s'assurera de persister le fichier WAV final dans le CDN d'Ace Data Cloud avant de renvoyer la réponse. L'URL ci-dessus ne montre que le format de réponse et ne représente pas un objet réel à long terme. Le `file_url` ne pourra conserver cette adresse que si la persistance dans le CDN n'est pas terminée et que l'adresse du média original peut encore être vérifiée instantanément pour télécharger un fichier WAV valide ; si l'adresse est invalide ou si la vérification du fichier échoue, la demande renverra un échec ou un délai d'attente, et aucune adresse non téléchargeable ne sera considérée comme un résultat réussi. Veuillez télécharger et sauvegarder rapidement après l'achèvement de la tâche, la durée de conservation spécifique dépend de la politique de stockage actuelle de la plateforme.
