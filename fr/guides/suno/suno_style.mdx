SUNO nous permet d'entrer des mots-clés pour générer un style de chanson amélioré. Ce document explique comment intégrer l'API concernée.

Cette API n'a qu'un seul paramètre d'entrée, qui est `prompt`, c'est-à-dire le mot-clé de style à optimiser.

Ici, le `prompt` que nous entrons est `A song for Christmas`.

```python
import requests

url = "https://api.acedata.cloud/suno/style"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A song for Christmas"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Le résultat est le suivant :


On peut voir que le champ `upsampled_tags` de `data` est le paramètre de style optimisé en fonction du mot-clé.
