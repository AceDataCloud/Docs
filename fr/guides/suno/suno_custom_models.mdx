---
title: "Guide d’intégration des modèles musicaux personnalisés Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Les modèles musicaux personnalisés peuvent apprendre des caractéristiques musicales cohérentes à partir de 6 à 24 audios autorisés, et être utilisés pour la création ultérieure de chansons. La création est une opération asynchrone ; il est recommandé d’utiliser 24 audios de style cohérent et de qualité sonore claire afin d’obtenir des résultats plus stables.

> Vous ne pouvez soumettre que des audios pour lesquels vous détenez un droit d’utilisation légal, ou pour lesquels vous avez obtenu une autorisation de création de modèle et de génération ultérieure. Veuillez ne pas téléverser de musique ou de matériel sonore non autorisé.

## Créer un modèle

Appelez `POST /suno/custom-models`, et définissez `action=create` :

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

L’interface renvoie immédiatement l’ID de modèle de la plateforme et l’ID de tâche. Une fois la création terminée, le `status` dans le rappel ou le résultat de la requête devient `ready`. Seule la création réussie du modèle sera facturée **10 Credits** ; aucun frais ne sera déduit si la création échoue.

## Interroger un modèle

Interroger un modèle unique :

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Interroger les modèles de l’application actuelle avec pagination :

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Tous les modèles appartiennent à l’application Suno qui les a créés. La rotation des identifiants API ne modifie pas l’appartenance des modèles, et les autres applications ne peuvent ni interroger ni utiliser ce modèle.

## Utiliser un modèle pour générer une chanson

Une fois que le statut du modèle est `ready`, continuez à appeler `POST /suno/custom-models`, et définissez `action=generate` :

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` doit être un modèle musical personnalisé dont le statut est `ready` dans l’application actuelle. La requête échouera si le modèle n’est pas disponible, sans basculer automatiquement vers un autre modèle. `persona_id` est incompatible avec les modèles musicaux personnalisés ; s’ils sont soumis simultanément, l’interface renverra HTTP 400 avant que la requête ne soit envoyée au service de génération, et aucun frais ne sera déduit. Si vous devez utiliser Persona, veuillez plutôt utiliser les opérations `artist_consistency` ou `artist_consistency_vox` de `/suno/audios`.

La génération réussie d’une chanson consomme **0.90 Credits** ; aucun frais ne sera déduit si la génération échoue. L’interrogation et l’archivage des modèles sont gratuits.

## Archiver un modèle

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

La version Beta actuelle archive le modèle et interdit toute utilisation ultérieure, `capacity_released=false` dans la réponse indique que l’archivage ne garantit pas la libération de la capacité du modèle. L’opération d’archivage peut être appelée à plusieurs reprises, sans être facturée plusieurs fois.
