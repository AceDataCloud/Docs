title: "Guide d'intégration du modèle de musique exclusif Suno"

Le modèle de musique exclusif peut apprendre des caractéristiques musicales cohérentes à partir de 6 à 24 pistes audio autorisées et être utilisé pour la création de chansons ultérieures. La création est une opération asynchrone ; il est recommandé d'utiliser 24 pistes audio de style cohérent et de qualité sonore claire pour obtenir des résultats plus stables.

> Vous ne pouvez soumettre que des pistes audio pour lesquelles vous avez des droits d'utilisation légaux, ou pour lesquelles vous avez obtenu l'autorisation de créer le modèle et de générer par la suite. Veuillez ne pas télécharger de musique ou de matériel sonore sans autorisation.

## Création de modèle

Appelez `POST /suno/custom-models` et définissez `action=create`. Il est conseillé d'envoyer en même temps un en-tête de requête `Idempotency-Key` unique ; réutilisez la même clé lors des tentatives de réseau pour éviter la création en double :

```json
{
  "action": "create",
  "name": "Mon Modèle Indie",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

L'interface renvoie immédiatement l'ID du modèle de la plateforme et l'ID de la tâche. Une fois la création terminée, le `status` dans le rappel ou la requête de résultats deviendra `ready`. Seule la création réussie du modèle sera facturée ; une création échouée ne sera pas facturée.

## Interroger le modèle

Interroger un modèle unique :

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Interroger par pagination les modèles de l'application actuelle :

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Tous les modèles appartiennent à l'application Suno qui les a créés. Le changement des identifiants API ne modifiera pas l'appartenance du modèle, d'autres applications ne peuvent pas interroger ou utiliser ce modèle.

## Utiliser le modèle pour générer des chansons

Une fois que le statut du modèle est `ready`, continuez à appeler `POST /suno/custom-models` et définissez `action=generate` :

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nLes lumières de la ville tombent à travers la pluie",
  "style": "indie rock, synthétiseur analogique chaud"
}
```

`id` doit être le modèle de musique exclusif dont le statut est `ready` sous l'application actuelle. La demande échouera si le modèle n'est pas disponible et ne basculera pas automatiquement vers un autre modèle.

## Archiver le modèle

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

La version Beta actuelle archivera le modèle et interdira son utilisation ultérieure, la réponse contenant `capacity_released=false` indique que l'archivage ne garantit pas la libération de la capacité du modèle. L'opération d'archivage peut être appelée plusieurs fois sans frais supplémentaires.
