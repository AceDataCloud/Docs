SUNO nous permet de créer une nouvelle version de Persona-v2-vox : style de chanteur, qui diffère de l'ancienne version et nécessite d'abord d'obtenir la valeur du paramètre `vox_audio_id`. Ce document explique la méthode d'intégration pour créer la nouvelle version de Persona-v2-vox.

Tout d'abord, il est nécessaire d'utiliser cette API pour obtenir la valeur du paramètre `vox_audio_id`. Cette API peut accepter plusieurs paramètres d'entrée, tels que `audio_id`, `vocal_start`, `vocal_end`, qui font référence à l'ID de la chanson et à la plage de temps sélectionnée.

Ici, nous entrons `audio_id` comme `42599b24-fb14-4cd3-a444-e15ffde3661b`.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

On peut voir que le champ `id` de `data` est le `vox_audio_id` que nous voulons, puis nous allons créer la nouvelle version de Persona-v2-vox : style de chanteur via [Persona API](https://platform.acedata.cloud/documents/78bb6c62-6ce0-490f-a7df-e89d80ec0583) avec les entrées suivantes :

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Après l'appel, nous obtenons le résultat suivant :

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

Ensuite, nous pouvons utiliser la valeur de `persona_id` ci-dessus pour créer la nouvelle version de Persona-v2-vox : style de chanteur. La méthode de création est identique à celle de la [documentation d'intégration de l'API de génération de chansons Suno](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD), et enfin, nous pouvons utiliser l'API Suno Vox pour créer des chansons avec la nouvelle version de Persona-v2-vox : style de chanteur.
