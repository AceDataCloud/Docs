Germey Technology, LLC（以下簡稱“我們”或“我們的”），即Ace Data Cloud的公司，致力於保護您的隱私。本隱私政策解釋了我們如何在您訪問我們的Ace Data Cloud網站平台時收集、使用、披露和保護您的資訊。請仔細閱讀本隱私政策。使用本平台即表示您同意本隱私政策的條款。

## 我們收集的資訊

我們收集各種類型的資訊以向您提供和改進我們的服務：

1. **個人資訊**：可以用來識別您的資訊，例如您的姓名、電子郵件地址、電話號碼、支付資訊以及其他類似資料。

2. **非個人資訊**：無法用於識別您的資訊，包括但不限於您的IP地址、瀏覽器類型、作業系統、引薦URL以及您使用我們平台的相關資訊。

3. **技術資料**：關於您使用我們API的資料，包括請求次數、請求資料類型以及相關的元資料。

## 使用目的

我們收集的資訊用於以下各種目的：

1. **提供和維護服務**：運營和維護我們的平台，包括處理交易和提供客戶支援。

2. **改進我們的平台**：了解您如何使用我們的平台，並改進和增強功能和使用者體驗。

3. **與您溝通**：向您發送更新、宣傳材料和其他可能感興趣的資訊。您可以隨時選擇退出這些通訊。

4. **確保安全**：監控和分析使用情況和活動趨勢，以確保我們平台的安全性和完整性。

5. **遵守法律義務**：遵守適用的法律、法規和法律程序。

## 資訊披露

我們可能在以下情況披露您的資訊：

1. **服務提供商**：我們可能會與代表我們提供服務的第三方服務提供商共享您的資訊，例如支付處理、資料分析、電子郵件發送、託管服務和客戶支援。

2. **法律要求**：如果法律要求或回應公共當局的有效請求（例如法院或政府機構），我們可能會披露您的資訊。

3. **業務轉移**：在任何合併、公司資產出售、融資或將我們全部或部分業務出售給另一家公司時，或者在此類交易談判期間，我們可能會披露或轉移您的資訊。

4. **您的同意**：在獲得您明確同意的情況下，我們可能會為其他目的披露您的資訊。

## 安全措施

我們實施合理的安全措施，以保護您的資訊免受未經授權的訪問、使用、篡改和披露。這些措施包括：

1. **資料加密**：我們使用產業標準的加密技術來保護傳輸到我們平台和從我們平台傳輸的資料。

2. **訪問控制**：訪問您的個人資訊僅限於需要這些資訊來履行其工作職責的授權人員。

3. **定期審計**：我們定期審計我們的安全系統和流程，以確保遵守產業標準和最佳實踐。

4. **安全存儲**：我們將個人資訊存儲在安全的環境中，防止未經授權的訪問、使用或披露。

### 您的權利

您有權：

1. **訪問您的資訊**：請求訪問我們持有的關於您的個人資訊。

2. **更正您的資訊**：請求更正任何不準確或不完整的個人資訊。

3. **刪除您的資訊**：在法律規定的某些例外情況下，您可以請求刪除您的個人資訊。如果您希望刪除您的資訊，請聯繫我方支援團隊 - office@acedata.cloud。

4. **選擇退出**：透過遵循那些通信中包含的取消訂閱指示，選擇退出接收我們的宣傳通信。

## Google API 服務用戶資料政策（有限使用）

當您選擇將 Ace Data Cloud 與 Google 服務（包括 Google Workspace API、Google Drive、Gmail、Google Calendar 等）連接時，我們對從 Google API 接收到的任何資訊的使用和傳輸完全遵守 [Google API 服務用戶資料政策](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的**有限使用（Limited Use）**要求。具體而言：

1. **僅用於您請求的功能**：我們僅在您主動請求並啟用某項功能時（例如讀取您的 Drive 檔案、發送日曆邀請、整理 Gmail 郵件）訪問您的 Google 資料，且僅用於實現該功能本身。
2. **不用於廣告**：我們絕不會將從 Google API 獲取的資料用於廣告投放、廣告定向或第三方行銷目的。
3. **不出售給第三方**：我們絕不會出售從 Google API 獲取的用戶資料。
4. **不向第三方轉讓**：除非在以下情況，否則我們不會將從 Google API 獲取的資料轉讓給任何其他方：(a) 出於提供或改進直接面向用戶的功能所必需；(b) 出於安全目的（例如調查濫用行為）；(c) 遵守適用法律；或 (d) 作為合併、收購或資產出售的一部分，且經過用戶確認同意。
5. **不允許人工閱讀**：我們不允許任何人工人員閱讀從 Google API 獲取的資料，除非：(a) 已獲得您的明確同意；(b) 出於安全目的（例如調查濫用行為）；(c) 遵守適用法律；或 (d) 該資料已聚合並匿名化，僅用於內部運營。

如果您希望隨時撤銷 Ace Data Cloud 對您 Google 帳戶的訪問權限，可以前往 [Google 帳戶連接的應用](https://myaccount.google.com/connections) 頁面進行操作。
