[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文協議，允許 AI 模型（如 Claude、GPT 等）透過標準化介面呼叫外部工具。透過 AceData Cloud 提供的 Suno MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 用戶端中直接生成音樂、歌詞，並管理音訊專案。

## 功能概覽

Suno MCP Server 提供以下核心功能：

- **音樂生成** — 透過文字提示詞生成 AI 音樂
- **自訂創作** — 完全控制歌詞、標題和音樂風格
- **歌曲續寫** — 從任意時間點繼續延長既有歌曲
- **翻唱/混音** — 用不同風格建立翻唱版本
- **歌詞生成** — 根據描述生成結構化歌詞
- **人聲角色** — 儲存和重複使用聲音風格
- **媒體轉換** — 取得 MP4、WAV、MIDI、人聲分離等
- **風格最佳化** — 最佳化音樂風格標籤
- **任務查詢** — 監控生成進度並取得結果

## 前置準備

使用前，你需要取得 AceData Cloud API Token：

1. 註冊或登入 [AceData Cloud 平台](https://platform.acedata.cloud)
2. 前往 [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios) 頁面
3. 點擊「Acquire」取得 API Token（首次申請贈送免費額度）

## 方式一：使用託管 MCP Server（推薦，零安裝）

AceData Cloud 已經把 **Suno MCP Server** 託管在雲端，**無需本機安裝任何相依項目**，直接在 AI 用戶端裡填寫下面這個 URL 就能使用：

```
https://suno.mcp.acedata.cloud/mcp
```

驗證方式：在請求標頭中加上 `Authorization: Bearer 你的API Token` 即可（Claude.ai 透過 OAuth 自動完成，無需手動填寫 Token）。

### Claude.ai（網頁版，OAuth 登入，最簡單）

1. 開啟 [Claude.ai](https://claude.ai) → 左下角 **Customize** → **Connectors** → **Add More**
2. 在 URL 處填入：`https://suno.mcp.acedata.cloud/mcp`
3. 完成 OAuth 授權登入（自動跳轉 AceData Cloud 登入頁）
4. 回到對話介面，工具即可使用

### Claude Desktop

編輯設定檔：

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

儲存後重新啟動 Claude Desktop 即可生效。

### Claude Code（終端機命令列）

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### 其他支援 MCP 的用戶端

任何支援 MCP Streamable HTTP 協議的用戶端（Windsurf、Cline、ChatGPT Connectors、Gemini CLI、JetBrains AI Assistant 等）都可以透過填寫以下兩項串接：

## 方式二：本機執行（pip / uvx 安裝）

如果你需要離線執行、自訂程式碼或部署到內網，可以把 MCP Server 安裝在本機透過 stdio 啟動。

### 安裝

pip 安裝（推薦）：

```bash
pip install mcp-suno
```

或原始碼安裝：

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

安裝完成後，即可使用 `mcp-suno` 命令啟動服務。

### 在 Claude Desktop 中使用（本機）

編輯 Claude Desktop 設定檔：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

新增以下設定：

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（無需提前安裝套件）：

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

儲存設定後重新啟動 Claude Desktop 即可生效。

### 在 VS Code / Cursor 中使用（本機）

在專案根目錄建立 `.vscode/mcp.json`：

```json
{
  "servers": {
```

- 「把這首歌的人聲分離出來」
- 「幫我把這首歌轉成 MIDI 格式」

## 進階控制與 Studio 工程

`suno_generate_music` 支援 `variety`；`suno_generate_custom_music` 還支援
`max_mode` 和 `audio_weight`。`max_mode` 採用較高的 API 計費級距，預設不啟用，
應在使用者明確選擇增強模式後設定。目前價格以平台服務頁為準。

`suno_generate_with_custom_model` 可使用 `instrumental=true` 生成純音樂，或使用
`lyric_prompt` 自動生成歌詞；否則提供 `lyric`。標題、風格可省略，還可傳入
`negative_tags`、`vocal_gender`、`weirdness`、`style_influence`、`duration` 和
`callback_url`。明確的 `0` 控制值會保留。

`suno_manage_project` 的 `request.action` 可選 `create`、`retrieve`、`save`、
`upload`、`add_track`、`generate_track`、`replace_section`、`commit_candidate`、
`remove_track`、`render`。輸入依動作區分，工程修改應使用最近讀回的 `version_id`；
儲存時傳入完整 `state`，保留既有軌道和欄位。

除 `retrieve` 外，每次呼叫都必須提供 `idempotency_key`。新的寫入操作使用新鍵；
逾時或受理結果不確定時，保留原鍵和完全相同的請求重試，或查詢原任務，不要自動
換鍵重發收費生成。來源音訊區間以秒為單位，工程時間線區間以拍數為單位。生成只建立候選，
需要選定候選並呼叫 `commit_candidate` 才會寫入軌道。

非同步受理的 `task_id` 用 `suno_get_task` 查詢。`finished_at` 為空時繼續等待，
終態後檢查 `response.success` 與錯誤；不要把受理成功當成生成、提交或匯出成功。
`suno_get_tasks_batch` 回傳完整 JSON 任務記錄，保留自訂模型物件、工程狀態、
候選及 MIDI 等各類結果。完整工作流程見 [Studio 專案指南](https://platform.acedata.cloud/documents/suno-projects-integration)。
