[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文協議，允許 AI 模型（如 Claude、GPT 等）透過標準化介面呼叫外部工具。透過 AceData Cloud 提供的 Flux MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 用戶端中直接生成和編輯 AI 圖像。

## 功能概覽

Flux MCP Server 提供以下核心功能：

- **文字生成圖像** — 透過文字提示詞生成高品質圖像
- **圖像編輯** — 基於文字指令編輯既有圖像
- **多模型支援** — 支援 Flux Pro、Flux Dev、Flux 2、Flux Kontext 等多種模型
- **模型查詢** — 查看所有可用模型及其能力
- **任務查詢** — 監控生成進度並取得結果

## 前置準備

使用前，你需要取得 AceData Cloud API Token：

1. 註冊或登入 [AceData Cloud 平台](https://platform.acedata.cloud)
2. 前往 [Flux Images API](https://platform.acedata.cloud/documents/flux-images) 頁面
3. 點擊「Acquire」取得 API Token（首次申請贈送免費額度）

## 方式一：使用託管 MCP Server（推薦，免安裝）

AceData Cloud 已經把 **Flux MCP Server** 託管在雲端，**無需在本機安裝任何相依項目**，直接在 AI 用戶端裡填寫以下這個 URL 就能使用：

```
https://flux.mcp.acedata.cloud/mcp
```

驗證方式：在請求標頭中加上 `Authorization: Bearer 你的API Token` 即可（Claude.ai 透過 OAuth 自動完成，無需手動填寫 Token）。

### Claude.ai（網頁版，OAuth 登入，最簡單）

1. 開啟 [Claude.ai](https://claude.ai) → 左下角 **Customize** → **Connectors** → **Add More**
2. 在 URL 處填入：`https://flux.mcp.acedata.cloud/mcp`
3. 完成 OAuth 授權登入（自動跳轉至 AceData Cloud 登入頁面）
4. 回到對話介面，即可使用工具

### Claude Desktop

編輯設定檔：

- macOS：`~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows：`%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

儲存後重新啟動 Claude Desktop 即可生效。

### Claude Code（終端機命令列）

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### 其他支援 MCP 的用戶端

任何支援 MCP Streamable HTTP 協議的用戶端（Windsurf、Cline、ChatGPT Connectors、Gemini CLI、JetBrains AI Assistant 等）都可以透過填寫以下兩項進行串接：

- **URL**：`https://flux.mcp.acedata.cloud/mcp`
- **Header**：`Authorization: Bearer 你的API Token`

## 方式二：在本機執行（pip / uvx 安裝）

如果你需要離線執行、自訂程式碼或部署至內網，可以將 MCP Server 安裝在本機並透過 stdio 啟動。

### 安裝

pip 安裝（推薦）：

```bash
pip install mcp-flux-pro
```

或從原始碼安裝：

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

安裝完成後，即可使用 `mcp-flux-pro` 命令啟動服務。

### 在 Claude Desktop 中使用（本機）

編輯 Claude Desktop 設定檔：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

新增以下設定：

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（無需預先安裝套件）：

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

儲存設定後重新啟動 Claude Desktop 即可生效。

### 在 VS Code / Cursor 中使用（本機）

在專案根目錄建立 `.vscode/mcp.json`：

```json
{
  "servers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

或者使用 `uvx`：

```json
{
  "servers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],

        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

## 可用工具列表

| 工具名稱                    | 說明                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | 透過文字提示詞生成圖像              |
| `flux_edit_image`      | 基於文字指令編輯既有圖像             |
| `flux_generate_video`  | FLUX 3 文字生圖／圖生圖／影片生成及既有草稿增強 |
| `flux_get_task`        | 查詢單一任務狀態                 |
| `flux_get_tasks_batch` | 批次查詢任務狀態                 |
| `flux_list_models`     | 列出所有可用模型及其能力             |
| `flux_list_actions`    | 列出所有可用工具和工作流程範例           |

## 使用範例

設定完成後，你可以在 AI 用戶端中直接以自然語言呼叫這些功能，例如：

## 模型與尺寸限制
`flux-2-flex`、`flux-2-pro`、`flux-2-max` 及 Kontext 模型的 `size` 必須使用
比例，例如 `1:1` 或 `16:9`，不能使用 `1024x1024` 這類像素尺寸。
`flux-2-klein` 僅支援生成，不在 `flux_edit_image` 的可選模型內。

`flux_generate_video` 透過 `request.mode` 區分 `t2v`、`i2v`、`v2v` 與
`draft_enhance`，輸入會依模式顯示。草稿增強必須引用自己的暫存 `draft_task_id`。
提交預設為非同步，保留回傳的任務 ID，並使用 `flux_get_task` 讀取結果。
