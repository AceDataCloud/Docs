[MCP（Model Context Protocol）](https://modelcontextprotocol.io) 是由 Anthropic 推出的模型上下文協議，允許 AI 模型（如 Claude、GPT 等）透過標準化介面呼叫外部工具。透過 AceData Cloud 提供的 Seedance MCP Server，你可以在 Claude Desktop、VS Code、Cursor 等 AI 用戶端中直接使用位元組跳動 Seedance 生成 AI 影片。

## 功能概覽

Seedance MCP Server 提供以下核心功能：

- **文字生成影片** — 透過文字提示詞生成高品質影片
- **圖片生成影片** — 以圖片為參考生成影片（首幀、末幀、參考圖等模式）
- **多模型支援** — 支援 Seedance 1.x、1.5、2.0 與 2.5
- **多種解析度** — 支援 480p、720p、1080p，部分模型支援 4k
- **多種畫面比例** — 支援 16:9、9:16、1:1、4:3、3:4、21:9 與 adaptive
- **彈性時長** — 依模型支援 2–30 秒或自動時長
- **多模態影片** — 支援音訊生成、參考音訊/影片，以及 2.5 的影片編輯與延長
- **任務查詢** — 監控生成進度並取得結果

## 推薦：使用託管 MCP 的 OAuth 授權

在支援遠端 MCP OAuth 的用戶端中新增伺服器位址：

```text
https://seedance.mcp.acedata.cloud/mcp
```

選擇連線或登入，登入 Ace Data Cloud，檢視權限並授權，然後啟用工具。此路徑不需要先建立或複製 API Token。服務已支援 OAuth discovery、動態用戶端註冊（DCR）及 S256 PKCE；DCR 註冊用戶端，使用者仍需登入和授權，API 使用照常計費。

| 用戶端                            | 串接方式與條件                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude 網頁版或提供遠端連接器的 Desktop 版本 | 在連接器介面新增上述位址並授權；入口受版本與方案影響。不要將遠端 HTTP 設定寫入本機 stdio 設定檔。                      |
| 支援原生遠端 MCP OAuth 的 VS Code     | 執行 **MCP: Add Server**，選擇 HTTP，填入位址並依提示登入；專用 AceDataCloud 擴充功能使用獨立的 API Key 設定。 |
| 其他用戶端                          | 確認目前版本支援遠端 HTTP、OAuth/DCR，並使用該用戶端的設定說明。設定檔格式不能在不同用戶端間通用。                     |

## API Token 備選路徑

本機 stdio、自行託管或不支援遠端 OAuth 的用戶端使用 API Token。登入 [Ace Data Cloud 平台](https://platform.acedata.cloud)，選擇服務並建立所需權限的 API 憑證。將 Token 存入用戶端的憑證設定或本機環境變數，不要放進 URL、聊天內容或版本庫。不同用戶端的 HTTP Header 設定應依其版本說明填寫。

安裝開源 MCP 或完成授權不代表獲得免費額度，也不承諾生成時間或商業使用權。生成前檢視目前服務價格、餘額與適用條款。

## 方式二：本機執行（pip / uvx 安裝）

如果你需要本機 stdio、自訂程式碼或自行託管，可以在本機啟動 MCP Server。生成仍需連網呼叫 API，不是離線推論。

### 安裝

pip 安裝（推薦）：

```bash
pip install mcp-seedance
```

或原始碼安裝：

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

安裝完成後，即可使用 `mcp-seedance` 指令啟動服務。

### 在 Claude Desktop 中使用（本機）

編輯 Claude Desktop 設定檔：

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

新增以下設定：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

如果使用 `uvx`（無需事先安裝套件）：

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

儲存設定後重新啟動 Claude Desktop 即可生效。

### 在 VS Code 中使用（本機）

在專案根目錄建立 `.vscode/mcp.json`：

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

或者使用 `uvx`：

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

其他本機用戶端請依其目前版本的 stdio 設定說明填寫 command、args 和 env，不要將 VS Code 的設定直接當成通用格式。

## 驗證結果與常見失敗

請用戶端生成一項簡單的影片作品，保留任務編號並查詢同一個任務，直到終態成功，再開啟或播放最終連結。連線成功、工具清單載入、HTTP 200、任務編號與處理中預覽均不代表最終產物。

遇到 401，重新登入或檢查 Token 與權限；餘額不足時檢視帳單；任務處理中繼續查詢；最終失敗時閱讀錯誤後決定是否重試，新生成可能再次計費。

## 可用工具清單

| 工具名                                  | 說明             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | 透過文字提示詞生成影片    |
| `seedance_generate_video_from_image` | 以圖片為參考生成影片     |
| `seedance_get_task`                  | 查詢單一任務狀態       |
| `seedance_get_tasks_batch`           | 批次查詢任務狀態       |
| `seedance_list_models`               | 列出所有可用模型及其能力   |
| `seedance_list_resolutions`          | 列出可用解析度和畫面比例   |
| `seedance_list_actions`              | 列出所有可用工具和工作流程範例 |

## 使用範例

設定完成後，你可以在 AI 用戶端中直接用自然語言呼叫這些功能，例如：

- 「幫我用 Seedance 生成一段城市街頭縮時攝影影片」
- 「用這張照片作為第一幀，生成一段 8 秒的影片」
- 「生成一段 1080p 直式 9:16 的短影片」
- 「用 Seedance 1.5 Pro 模型生成帶音訊的影片」
