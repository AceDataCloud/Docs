本文將介紹一種 銀行卡四要素核驗 API 對接說明，它可用於輸入銀行卡號、姓名、開戶證件號、開戶手機號，校驗信息的真實性和一致性。

## 申請流程

要使用 銀行卡四要素核驗 API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[銀行卡四要素核驗 API →](https://platform.acedata.cloud/documents/identity-bankcard-check-4e)

## 基本使用

首先先了解下基本的使用方式，就是輸入銀行卡的卡號信息，便可獲得處理後結果圖片，首先需要簡單地傳遞一個 `bank_card` 字段。我們接下來就可以在界面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/1pl0y5.png" width="500" className="m-auto" /></p>

可以看到這裡我們設置了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設置了 Request Body，包括：

- `bank_card`：需要處理的銀行卡號信息，是必選參數。
- `id_card`：開戶證件號，是必選參數。
- `name`：用戶的姓名，是必選參數。
- `phone`：預留手機號。
- `cert_type`：開戶證件類型，需與開戶證件一致。
- `encryption`：可選，敏感字段加密參數（如需上送密文）。

選擇之後，可以發現右側也生成了對應代碼，如圖所示：

<p><img src="https://cdn.acedata.cloud/slajgv.png" width="500" className="m-auto" /></p>

點擊「Try」按鈕即可進行測試，如上圖所示，這裡我們就得到了如下結果：

```json
{
  "result": "0",
  "description": "認證通過"
}
```

返回結果一共有多個字段，介紹如下：

- `result `，認證結果碼，收費情況如下。
    - 收費結果碼：
        - 0: 認證通過
        - -1: 認證未通過
        - -4: 持卡人信息有誤
        - -5: 未開通無卡支付
        - -6: 此卡被沒收
        - -7: 無效卡號
        - -8: 此卡無對應發卡行
        - -9: 該卡未初始化或睡眠卡
        - -10: 作弊卡、吞卡
        - -11: 此卡已掛失
        - -12: 該卡已過期
        - -13: 受限制的卡
        - -14: 密碼錯誤次數超限
        - -15: 發卡行不支持此交易
    - 不收費結果碼：
        - -2: 姓名校驗不通過
        - -3: 銀行卡號碼有誤
        - -16: 驗證中心服務繁忙
        - -17: 驗證次數超限，請次日重試
- `description`，業務結果描述。

可以看出這張銀行卡的銀行卡號、姓名、開戶證件號、開戶手機號具有真實性和一致性。

另外如果想生成對應的對接代碼，可以直接複製生成，例如 CURL 的代碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/identity/bankcard/check-4e' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "***",
  "phone": "***",
  "id_card": "***",
  "bank_card": "***"
}'
```

Python 的對接代碼如下：

```python
import requests

url = "https://api.acedata.cloud/identity/bankcard/check-4e"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "胡印福",
    "phone": "***",
    "id_card": "***",
    "bank_card": "***"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 錯誤處理

在調用 API 時，如果遇到錯誤，API 會返回相應的錯誤代碼和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 錯誤響應示例

```json
}
```
