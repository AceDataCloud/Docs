SUNO 允許我們上傳參考音頻進行二次創作，本文檔講解相關 API 的對接方法。

該 API 只有一個輸入參數，就是 `audio_url`，它是一個可以公開訪問的 CDN 地址，支持 mp3 後綴。

這裡我們輸入的 `audio_url` 是 `https://cdn.acedata.cloud/suno_demo.mp3`，是一個可以公開訪問的 CDN 地址。

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

可以看到，`data` 的 `audio_id` 字段就是上傳後的歌曲 ID。

有了歌曲 ID 之後，我們便可以使用 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) 來進行自定義歌曲生成了，比如說 `action` 傳入 `upload_extend`，同時 `audio_id` 傳入返回的歌曲 ID，就可以根據參考音頻生成新的歌曲了。
