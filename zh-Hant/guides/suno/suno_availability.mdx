---
title: "Suno 音訊可用性檢查 API"
description: "Suno Music Generation 整合指南 - Ace Data Cloud"
---

`POST /suno/availability` 根據 `audio_id` 尋找音訊在目前線路可繼續處理的正向證據。可在續寫、翻唱等操作前呼叫；結果僅反映檢查時的狀態，不保證某個具體操作一定成功。該介面同步回傳、需要 API Token，目前不扣 Credits。

`audio_id` 是已完成的 Suno 任務回傳的歌曲 ID，不是 `task_id`。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

成功回應示意：

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

檢查成功時，`data.available` 只會是 `true`。某些線路回傳的「不在線」狀態無法證明後續續寫等操作無法成功，因此本介面在無法確認時回傳 `503 availability_unknown`，不會回傳 `false`。`audio_id` 格式錯誤回傳 400，限流或上游故障也回傳錯誤回應。檢查完成後到實際操作之間狀態仍可能變化。
