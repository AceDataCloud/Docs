---
title: "Suno 音訊可用性檢查 API"
description: "Suno Music Generation 整合指南 - Ace Data Cloud"
---

`POST /suno/availability` 會根據 `audio_id` 尋找音訊是否能在目前線路上繼續處理的正向證據。可在續寫、翻唱等操作前呼叫；結果僅反映檢查當下的狀態，不保證特定操作一定會成功。此介面會同步回傳、需要 API Token，目前不扣除 Credits。

`audio_id` 是已完成 Suno 任務回傳的歌曲 ID，而非 `task_id`。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

成功回應範例：

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

檢查成功時，`data.available` 為 `true`；無法確認時會回傳 `503 availability_unknown`，不會回傳 `false`。`audio_id` 格式錯誤時會回傳 400，限流或服務異常也會回傳錯誤回應。檢查完成後至實際操作之間，狀態仍可能變更。
