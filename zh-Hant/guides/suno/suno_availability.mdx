---

`POST /suno/availability` 接受一個資源 ID。查歌曲傳 `audio_id`，查音色傳 `persona_id`，兩者必填其一。檢查同步完成，需要 API Token，目前不扣 Credits。

## 請求

`audio_id` 來自已完成的歌曲任務，可用於續寫或翻唱前的檢查。

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

`persona_id` 來自音色建立結果。使用原應用程式和呼叫者身分，在支援音色查詢的建立線路上傳送以下請求主體。

```json
{"persona_id":"33333333-3333-4333-8333-333333333333"}
```

## 回應

兩種請求使用同一份成功回應。`data.id` 是本次查詢的資源 ID。

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

`available: true` 表示本次檢查獲得了正向證據。對音色，檢查會核實建立歸屬，並確認關聯帳號目前被回報為在線。實際生成結果仍以生成任務為準。

透過 `/suno/voices` 建立的私有克隆音色依賴建立帳號。確認該帳號目前離線時，介面回傳 HTTP 200，`data` 範例如下。

```json
{"id":"33333333-3333-4333-8333-333333333333","available":false}
```

用戶端可以將該音色標記為目前不可用，稍後再查。

無法確認時回傳 HTTP 503 和 `availability_unknown`，例如查不到資源、舊記錄缺少建立線路或查詢逾時。公開歌手風格可以跨帳號使用，建立帳號離線時同樣回傳 503。歌曲查詢仍只在確認可用時回傳 `available: true`。

每次請求只傳送一個有效 UUID。所有線路收到雙 ID 或兩個 ID 都缺失的請求時，都會回傳 HTTP 400。僅支援歌曲查詢的線路收到只含 `persona_id` 的請求時回傳 HTTP 400。遇到 HTTP 429 請降低查詢頻率。
