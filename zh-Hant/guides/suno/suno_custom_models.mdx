title: "Suno 專屬音樂模型接入指南"
description: "Suno Music Generation 整合指南 - Ace Data Cloud"
---

專屬音樂模型可以從 6 至 24 首授權音訊中學習一致的音樂特徵，並用於後續歌曲創作。建立是非同步操作；建議使用 24 首風格一致、音質清晰的音訊獲得更穩定的效果。

> 僅可提交您擁有合法使用權，或已取得模型建立及後續生成授權的音訊。請勿上傳未經許可的音樂或聲音素材。

## 建立模型

呼叫 `POST /suno/custom-models`，並設定 `action=create`：

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

介面立即回傳平台模型 ID 和任務 ID。建立完成後，回呼或查詢結果中的 `status` 會變為 `ready`。只有模型建立成功才會計費 **10 Credits**；建立失敗不會扣費。

## 查詢模型

查詢單一模型：

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

分頁查詢目前應用程式的模型：

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

所有模型均歸屬於建立它的 Suno 應用程式。API 憑證輪換不會改變模型歸屬，其他應用程式不能查詢或使用該模型。

## 使用模型生成歌曲

模型狀態為 `ready` 後，繼續呼叫 `POST /suno/custom-models`，並設定 `action=generate`：

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` 必須是目前應用程式下狀態為 `ready` 的專屬音樂模型。模型不可用時請求會失敗，不會自動改用其他模型。`persona_id` 與專屬音樂模型互斥；同時提交時介面會在請求傳送至生成服務前回傳 HTTP 400，且不會扣費。如需使用 Persona，請改用 `/suno/audios` 的 `artist_consistency` 或 `artist_consistency_vox` 操作。

歌曲生成成功消耗 **0.90 Credits**；生成失敗不扣費。查詢和封存模型免費。

## 封存模型

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

目前 Beta 版本會將模型封存並禁止繼續使用，回應中的 `capacity_released=false` 表示封存不承諾釋放模型容量。封存操作可重複呼叫，不會重複計費。
