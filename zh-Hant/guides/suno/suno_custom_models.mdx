專屬音樂模型可以從 6 至 24 首授權音頻中學習一致的音樂特徵，並用於後續歌曲創作。創建是異步操作；建議使用 24 首風格一致、音質清晰的音頻獲得更穩定的效果。

> 僅可提交您擁有合法使用權，或已取得模型創建及後續生成授權的音頻。請勿上傳未經許可的音樂或聲音素材。

## 創建模型

調用 `POST /suno/custom-models`，並設置 `action=create`。建議同時發送唯一的 `Idempotency-Key` 請求頭；網絡重試時重用相同鍵，避免重複創建：

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

接口立即返回平台模型 ID 和任務 ID。創建完成後，回調或查詢結果中的 `status` 會變為 `ready`。只有模型創建成功才會計費；創建失敗不會扣費。

## 查詢模型

查詢單個模型：

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

分頁查詢當前應用的模型：

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

所有模型均歸屬於創建它的 Suno 應用。API 憑據輪換不會改變模型歸屬，其他應用不能查詢或使用該模型。

## 使用模型生成歌曲

模型狀態為 `ready` 後，繼續調用 `POST /suno/custom-models`，並設置 `action=generate`：

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` 必須是當前應用下狀態為 `ready` 的專屬音樂模型。模型不可用時請求會失敗，不會自動改用其他模型。

## 归档模型

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

當前 Beta 版本會將模型歸檔並禁止繼續使用，響應中的 `capacity_released=false` 表示歸檔不承諾釋放模型容量。歸檔操作可重複調用，不會重複計費。
