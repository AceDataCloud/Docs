SUNO 允許我們獲取音樂的wav格式文件，本文檔講解相關 API 的對接方法。

該 API 核心輸入參數是 `audio_id`，它是官方生成的歌曲ID；可選還支持 `callback_url` 非同步回調地址。

這裡我們輸入的 `audio_id` 是 `4e43116a-bf09-472c-8e1c-655eabf02682`。

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

結果如下：

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

可以看到，`data` 的 `file_url` 欄位是獲取的音樂的 wav 格式文件，它是一個可以公開訪問的 CDN 地址。

> **關於 WAV 連結的持久化**
> 平台會在返回前優先將終態 WAV 文件持久化到 Ace Data Cloud CDN。上方 URL 僅展示響應格式，不代表一個長期存在的真實對象。只有在 CDN 持久化未完成、且原始媒體地址經即時校驗仍能下載到有效 WAV 文件時，`file_url` 才可能保留該地址；地址已失效或文件校驗失敗時，請求會返回失敗或超時，不會把不可下載的地址作為成功結果。請在任務完成後及時下載並妥善保存，具體保留週期以平台當前存儲策略為準。
