`POST https://api.acedata.cloud/suno/projects` 是管理多軌工程的 Beta 介面。一個端點透過 `action` 區分建立、儲存、生成候選、提交候選和匯出。呼叫方只需使用下面的公開欄位，不需要填寫底層生成服務的內部請求結構。

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: 每次修改操作使用新的 UUID
```

除 `retrieve` 外，**每次操作都需要** `Idempotency-Key`。相同鍵和相同請求只回讀原結果；相同鍵搭配不同請求會傳回 409。收費生成遇到網路逾時或提交結果不確定時，先用原任務 ID 或同一冪等鍵查詢，不能直接換鍵重發。

## 先區分這些 ID 和時間單位

| 名稱                             | 從哪裡取得                                                                                      | 用在哪裡                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | `create` 回應 `data.id`                                                                      | 目前工程的所有後續請求                                      |
| `version_id`                   | 最近一次 `retrieve`、`save`、`add_track`、`commit_candidate` 或 `remove_track` 的 `data.version_id` | 修改、生成候選和匯出；必須使用最新版本                              |
| `audio_id` / `source_audio_id` | `upload` 終態 `response.data.candidate.audio_id`，或已有的已完成音訊 ID                                | `add_track`、生成或替換時參照原音訊                          |
| `render_audio_id`              | `render` 終態 `response.data.audio_id`                                                       | `generate_track` 的工程混音參考                         |
| `operation_id`                 | `generate_track` 或 `replace_section` 終態 `response.data.operation_id`                       | `commit_candidate`；通常與生成任務的 `task_id` 相同，但應讀取回傳值 |
| `candidate_id`                 | 生成終態 `response.data.candidates[].id`                                                       | 選擇一個候選提交                                         |
| `track_id`                     | 工程 `data.state.tracks[].id`                                                                | 提交候選或刪除軌道                                        |
| `task_id`                      | 非同步操作提交回應                                                                                   | 使用 `/suno/tasks` 查詢終態；它不是工程 ID                   |

`start_seconds` / `end_seconds` 是**來源音訊內的秒數**；`start_beats` / `end_beats` 是**工程時間軸上的拍數**。`state.timing.bps` 是每秒拍數，預設為 2。例如 41 秒的片段從第 0 拍開始，預設終點為第 82 拍。`generate_track` 的秒數區間用於指定生成參考，不保證候選只有該區間的長度。

## 操作順序和結果判斷

| 順序  | `action`                             | 作用                         | 回傳方式         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | 建立空工程                      | 同步工程資料       |
| 2   | `retrieve`                           | 讀取最新版本和完整 `state`          | 同步工程資料       |
| 3   | `save`                               | 首次儲存或整體儲存修改後的 `state`      | 同步工程資料       |
| 4   | `upload`                             | 從 HTTPS 音訊網址建立素材           | 非同步任務         |
| 5   | `add_track`                          | 將素材音訊放入工程                  | 非同步任務，更新版本    |
| 6   | `save`                               | 如需接收新軌候選，先儲存一個空目標軌道        | 同步工程資料，更新版本  |
| 7   | `render`                             | 匯出目前可聽軌道，取得混音參考 `audio_id` | 非同步任務         |
| 8   | `generate_track` 或 `replace_section` | 分別生成新軌候選或局部替換候選            | 非同步任務，暫不修改工程  |
| 9   | `commit_candidate`                   | 選擇並提交一個候選                  | 非同步任務，成功後更新版本 |
| 可選  | `remove_track`                       | 刪除指定軌道                     | 同步工程資料，更新版本  |

如果只做局部替換，已有可用來源音訊即可，不需要先 `render`；如果來源音訊已在工程中，也可跳過 `upload` 和 `add_track`。`render_audio_id` 僅是 `generate_track` 的必填參考。

非同步操作提交時先回傳 `{ "task_id": "...", "trace_id": "..." }`，**不表示生成成功**。輪詢：

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步回傳的 task_id"}
```

任務記錄有 `finished_at`，且其中的 `response.success` 為 `true`，才算成功；`response.success=false` 時讀取 `response.error`。`save` 雖可能帶有 `task_id`，但它在本介面內同步完成。`upload`、`render`、`generate_track`、`replace_section` 不修改工程版本；`save`、`add_track`、`commit_candidate`、`remove_track` 成功後應取新的 `version_id`。

## 請求參數

### 通用欄位與請求標頭

| 參數                | 類型與適用範圍                                                                                   | 說明                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | 必填字串                                                                                     | 固定為本頁列出的一個操作名稱；一次請求只執行一個操作。                                      |
| `id`              | 除 `create` 外必填字串                                                                         | 工程 ID，來自 `create.data.id`。                                      |
| `version_id`      | 修改、生成候選、匯出時必填字串；首次空工程 `save` 可省略                                                         | 使用最新版本，舊版本會被拒絕。`retrieve` 不需要它。                                 |
| `Idempotency-Key` | 除 `retrieve` 外必填請求標頭，1–128 字元                                                              | 每個新操作使用新鍵；同鍵同請求回讀原結果，不重新生成或扣費。                                   |
| `async`           | `upload`、`add_track`、`generate_track`、`replace_section`、`commit_candidate`、`render` 可選布林值 | 這些操作始終非同步；`false` 也不會把生成變成同步。                                    |
| `callback_url`    | 上述可選非同步欄位所在操作的可選 URL                                                                       | 接收終態通知；省略時依 `task_id` 查詢 `/suno/tasks`。仍須檢查 `response.success`。 |

### 工程和素材
| `action`       | 專屬參數                        | 類型與條件                            | 說明                                                                 |
| -------------- | --------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| `create`       | `title`                     | 必填字串，1–200 個字元                   | 新專案標題。                                                             |
| `retrieve`     | 無                           | —                                | 只需 `action` 與專案 `id`；回傳完整可編輯的 `state`。                              |
| `save`         | `state`                     | 必填物件                             | **整體替換**專案狀態，不是局部修補。以最近一次 `retrieve.data.state` 為基礎修改並完整提交，保留未知欄位。 |
| `save`         | `title`                     | 可選字串                            | 專案標題；省略時沿用 `state.title`，若也沒有則使用預設標題。                              |
| `upload`       | `audio_url`                 | 必填 HTTPS URL                     | 可公開存取的音訊素材網址；成功後讀取終態 `candidate.audio_id`。素材應由呼叫方擁有使用權。            |
| `add_track`    | `audio_id`                  | 必填字串                            | 已完成素材的音訊 ID，不是 URL。                                                |
| `add_track`    | `name` / `color`            | 可選字串                            | 新軌道名稱、顏色；名稱預設取音訊標題，顏色建議 `#RRGGBB`，預設 `#7251F7`。                    |
| `add_track`    | `title`                     | 可選字串                            | 同時修改專案標題；通常省略。                                                     |
| `add_track`    | `start_beats` / `end_beats` | 可選非負數字，`end_beats > start_beats` | 片段在專案時間軸的位置。起點預設為 0；終點預設為 `起點 + 音訊時長 × timing.bps`。                  |
| `add_track`    | `gain`                      | 可選非負數字，預設為 1                      | 片段及新軌道的音量係數。                                                       |
| `remove_track` | `track_id`                  | 必填字串                            | 要刪除的現有軌道 ID。成功後使用回傳的新版本。                                           |

`state.timing.bps` 必須為正數，預設為 2。`state.tracks` 是軌道陣列；已有音訊片段的 `clipId` 參照音訊 ID，`startBeats`、`endBeats`、`readStartBeats` 使用專案拍單位。最安全的編輯方式是讀取完整 `state`，只修改目標軌道或片段，再整體 `save`。新增空目標軌道至少應有唯一的 `id`、`type:"audio"`、`clips:[]`；真實可用的完整形狀見下文第 5 步。不要把音訊分析結果中的拍點直接當作專案時間軸座標。

### 生成、提交和匯出
| `action`                             | 專屬參數                               | 類型與條件                                  | 說明                                                                                                                                                        |
| ------------------------------------ | ---------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generate_track` / `replace_section` | `source_audio_id`                  | 必填字串                                  | 已完成的來源音訊 ID。先將來源音訊加入工程，後續候選才能找到對應位置。                                                                                                                        |
| `generate_track` / `replace_section` | `model`                            | 必填列舉字串                                | 可選 `chirp-v3-5`、`chirp-v4`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`、`chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini`。模型和操作是否可用以任務終態為準；不會自動改用其他模型。 |
| `generate_track` / `replace_section` | `start_seconds` / `end_seconds`    | 必填數字，`0 ≤ start_seconds &lt; end_seconds` | 來源音訊內的起止秒數；替換時終點還必須不超過來源音訊實際時長。它們不是工程拍數，也不保證候選輸出時長。                                                                                                         |
| `generate_track`                     | `render_audio_id`                  | 必填字串                                  | 目前工程成功 `render` 後的 `response.data.audio_id`，作為生成時的混音參考。                                                                                                   |
| `generate_track`                     | `stem_control_tags`                | 必填字串                                  | 新增聲部描述，例如 `add Piano`、`add Drums`、`add Bass`；不是固定列舉。                                                                                                      |
| `generate_track`                     | `batch_size`                       | 可選整數 1–4，預設 2                          | 請求生成的候選數量。                                                                                                                                                |
| `generate_track`                     | `instrumental` / `vocal_gender`    | 可選布林值／列舉字串                            | `instrumental` 預設 `true`；聲樂偏好可填 `f`、`m`、`unspecified`，預設 `unspecified`。是否遵循偏好以實際音訊為準。                                                                     |
| `generate_track` / `replace_section` | `title` / `tags` / `negative_tags` | 可選字串                                  | 候選標題、期望風格描述、希望避開的風格標籤。`tags` 與 `negative_tags` 省略時傳空字串。                                                                                                  |
| `generate_track`                     | `prompt`                           | 可選字串                                  | 新聲部的文字或歌詞提示；純器樂可省略。                                                                                                                                       |
| `replace_section`                    | `prompt` / `replacement_lyrics`    | 可選字串                                  | 前者是原歌曲歌詞或上下文文字，後者是替換區間的新歌詞；省略時傳空字串。                                                                                                                      |
| `replace_section`                    | `fixed`                            | 可選布林值，預設 `false`                       | 請求固定長度替換；`true` 時區間須短於 26 秒，且所選模型可能不支援。本次真實範例使用預設模式，`fixed=true` 尚未驗證。                                                                                    |
| `commit_candidate`                   | `operation_id` / `candidate_id`    | 必填字串                                  | 分別取生成終態的 `data.operation_id` 和選中的 `data.candidates[].id`；候選必須屬於目前工程版本。                                                                                    |
| `commit_candidate`                   | `track_id`                         | 必填字串                                  | 新軌候選應提交到**生成前已儲存的空軌道**；局部替換候選提交到包含唯一來源片段的原軌道。                                                                                                              |
| `commit_candidate`                   | `start_beats` / `end_beats`        | 僅新軌候選可選的非負數字                           | 指定新片段在工程時間軸的位置；省略時沿用來源片段起點，並按候選實際時長計算終點。不得與目標軌道既有片段重疊。**局部替換候選必須省略**。                                                                                      |
| `commit_candidate`                   | `name` / `gain`                    | 僅新軌候選可選的字串／非負數字                       | 生成片段名稱和音量係數，`gain` 預設 1。                                                                                                                                  |
| `render`                             | `title`                            | 必填字串                                  | 匯出音訊標題。                                                                                                                                                   |
| `render`                             | `lyrics` / `tags`                  | 可選字串                                  | 匯出時的歌詞文字和風格描述；歌詞預設 `[Instrumental]`。                                                                                                                      |
| `render`                             | `start_beats` / `end_beats`        | 可選非負數字，結束須大於開始                         | 匯出工程拍數範圍；省略時取所有可聽片段的最早起點和最晚終點。靜音片段不參與，存在 solo 軌道時僅選擇 solo 軌道。                                                                                             |

生成只產生候選，**不會自動放入工程**。`commit_candidate` 會檢查候選仍屬於目前版本。局部替換候選只有在實際時長與完整來源音訊或選取區間可可靠匹配時才能自動提交；不匹配時保留原工程並傳回錯誤，不能靠手動猜測拍數強行拼接。

## 2026-10-09 真實請求與回應

以下請求本文和回應欄位均取自同一工程的真實呼叫。每組 JSON 依序為請求、受理回應（若為非同步）、任務終態回應。為便於閱讀，回應只摘錄完成本流程所需的欄位；帳戶、用量和耗時欄位未展示。範例 ID 屬於本次測試應用，串接時必須使用自己請求傳回的 ID 和新的 `Idempotency-Key`。

## 錯誤與復原

| 結果                                                                            | 含義                          | 下一步                                    |
| ----------------------------------------------------------------------------- | --------------------------- | -------------------------------------- |
| `project_version_conflict` / `project_candidate_stale`（409）                   | 工程版本已變更，或候選不屬於目前版本。         | `retrieve` 最新工程並重新規劃修改；不要重放舊候選。        |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported`（通常 400）   | 參數、軌道狀態、候選時長或模型與操作不相符。      | 查看任務終態錯誤，修正輸入；候選無法安全拼接時保留原工程。          |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`（403） | 引用音訊不可用於該工程操作、無權存取，或內容檢查拒絕。 | 檢查音訊來源和任務 `trace_id`；不要把已生成候選等同於整首曲目可匯出。 |
| `too_many_requests`（429）                                                      | 請求受到頻率限制。                   | 先查詢原任務，再決定是否以新冪等鍵發起新操作。                |
| `studio_unavailable` / `studio_model_unavailable`（503）                        | 工程處理或所選模型暫時不可用。             | 保留原任務結果；稍後明確重試，不自動切換模型。                |
| `studio_processing_failed` / 逾時（500/504）                                      | 處理失敗或終態不確定。                 | 按 `task_id` 或原冪等鍵查詢，避免重複收費生成。          |

工程和候選與建立它們的應用程式及執行環境綁定，不能假定可跨應用程式重複使用或自動容錯切換。請持久化成功匯出的最終音訊 URL，並保留 `trace_id` 以利排查。
