隨著 AI 的應用變廣，各類 AI 程式已逐漸普及。AI 已逐漸深入到人們的工作生活方方面面。而 AI 涉及的行業也越來越多，從最初的寫作，到醫療教育，再到現在的音樂。

Suno 是一個專業高品質的 AI 歌曲和音樂創作平台，用戶只需輸入簡單的文本提示詞，即可根據流派風格和歌詞生成帶有人聲的歌曲。該 AI 音樂生成器由來自 Meta、TikTok、Kensho 等知名科技公司的團隊成員開發，目標是不需要任何樂器工具，讓所有人都可以創造美妙的音樂。

以下是模型更新的進度：

| 版本    | model           | 上線時間       | lyric 限制 | style 限制 | 歌曲最長時長 |
| ----- | --------------- | ---------- | -------- | -------- | ------ |
| v5.5  | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 分鐘   |
| v5    | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 分鐘   |
| v4.5+ | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 分鐘   |
| v4.5  | chirp-v4-5      | 2025.05.03 | 5000     | 1000     | 4 分鐘   |
| v4    | chirp-v4        | 2024.12.17 | 3000     | 200      | 150 秒  |
| v3.5  | chirp-v3-5      | ---        | 3000     | 200      | 120 秒  |

> 上表的 `lyric` 與 `style` 限制為自定義模式（`custom` 為 `true`）下的上限。非自定義的靈感模式（`custom` 為 `false`）只填 `prompt`，其長度上限為 500 字符（各模型一致）。

Suno 現已支持最新的 `chirp-v5-5` 模型。調用最新版本時，將 `model` 參數設置為 `chirp-v5-5` 即可；`chirp-v5` 及更早版本仍可繼續使用。

然而 Suno 官方是並沒有提供 API 的，AceDataCloud 提供了一套 Suno 的 API，模擬對接了 Suno 官方，可以方便快捷地生成想要的音樂。

## 申請和使用

要使用 Suno Audios Generation API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/5hmkdg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

## 基本使用

想些什麼歌曲，可以任意輸入一段文字，比如我想生成一個關於聖誕的歌曲，就可以輸入 `a song for Christmas`，如圖所示：

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

可以看到這裡我們設置了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設置了 Request Body，包括：
- `action`：此次音樂生成任務的行為，默認是 `generate`，主要包含：`extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`。
- `prompt`：Suno 官方的靈感模式提示詞（`custom` 為 `false` 時生效），最大 500 字符。
- `model`：此次音樂生成任務的模型，默認是 `chirp-v4`，主要包含：`chirp-v3`、`chirp-v4`、`chirp-v3-5`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`。
- `lyric`：Suno 官方的自定義模式的歌詞內容。`chirp-v3-5` 與 `chirp-v4` 最大 3000 字符；`chirp-v4-5` 及以上（含 `chirp-v5`、`chirp-v5-5`）最大 5000 字符。
- `custom`：是否採用自定義模式，默認是: `false`。
- `instrumental`：Suno 官方的靈感模式的純音樂選項。
- `title`：Suno 官方的自定義模式的音樂標題。`chirp-v3-5`、`chirp-v4` 最大 80 字符；`chirp-v4-5` 及以上最大 100 字符。
- `style`：Suno 官方的自定義模式音樂風格。`chirp-v3-5` 與 `chirp-v4` 最大 200 字符；`chirp-v4-5` 及以上（含 `chirp-v5`、`chirp-v5-5`）最大 1000 字符。
- `style_negative`：Suno 官方的自定義模式的排除風格。
- `audio_weight`：上傳的參考音頻佔比，範圍 0-1，越大越依賴參考音頻。
- `audio_id`：參考音樂的 ID。
- `overpainting_start`/`overpainting_end`：為已有純音樂補充人聲的起止時間，單位秒。
- `underpainting_start`/`underpainting_end`：為清唱加伴奏的起止時間，單位秒。
- `persona_id`：藝術家的歌曲 ID。
- `continue_at`：以秒為單位繼續現有音頻的時間。例如，213.5 表示繼續到 3 分 33.5 秒。
- `style_influence`：自定義模式下的「Style Influence」高級參數，範圍 0-1，越大越貼合所選風格。
- `replace_section_end`：替換片段的最終時間。
- `replace_section_start`：替換片段的起始時間。
- `vocal_gender`：控制男女聲偏好，女聲 `f`，男聲 `m`，4.5 及以上模型有效；為偏好項，不保證嚴格遵循。
- `weirdness`：自定義模式下的「Weirdness」高級參數，範圍 0-1，越大越有創意和實驗性。
- `duration`：期望的歌曲時長，單位秒，需為整數，取值範圍 10 到 360。該參數用於自定義模式（`custom` 為 `true`）的歌曲生成。它是一個傾向性提示而非硬性約束：模型會參考它，但不保證達到，實際成品時長以響應中的 `duration` 字段為準，通常短於期望值。
- `lyric_prompt`：生成歌詞的 prompt，當且僅當 `custom` 為 `true` 並且 `lyric` 沒有傳的時候生效。
- `callback_url`：需要回調結果的 URL。
- `async`：可選，設為 `true` 時接口立即返回 `task_id`，無需提供 `callback_url`，隨後通過對應的任務查詢接口輪詢獲取結果。

## 自定義歌手風格生成功能
```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 獲取完整歌曲

當基於原有的歌曲繼續生成歌曲之後，返回的歌曲並不包含原來的歌曲內容。如果要獲得完整的歌曲內容，需要使用拼接功能，就可以指定如下內容：

- action：內容為 `concat`。
- audio_id：最後一個片段的 ID。

比如擴展後的歌曲 ID 是：0a1e1b10-c36a-41c9-9bfb-b26d9d25db98，那麼可以設置參數如下：

```json
{
  "action": "concat",
  "audio_id": "0a1e1b10-c36a-41c9-9bfb-b26d9d25db98"
}
```

其他參數不變，返回的就是一首完整的歌曲，就是所有歌曲片段的拼接結果，但結果只有一首歌，樣例如下：

```json
  "trace_id": "62afcce0-e7e5-44b8-8c2e-4bba12a4f414",
  "data": [
    {
      "id": "0efec7e0-11bf-4313-9981-2c0e7218d7dd",
```

## 替換片段

當生成歌曲之後需要進行替換歌曲片段單獨操作的二次創作時，可以對歌曲的某個片段進行替換操作。

> ⚠️ **注意**：`replace_section` 單獨使用時**只會返回新生成的"替換片段"本身**（即被替換那一段的新音頻，時長大約等於 `replace_section_end - replace_section_start`，並附帶少量上下文），**並不會返回拼接好的整首歌曲**。要得到與原曲拼接後的完整成品，需要在 `replace_section` 成功後，針對返回的片段 ID 再發起一次 [音樂拼接](#音樂拼接) 任務。完整流程見下文。

參數說明如下：

- action：內容為 `replace_section`。
- audio_id：原始歌曲（被替換的源歌曲）的 ID。
- model: 歌曲生成模型。
- lyric: 替換後的完整歌詞（包含被替換段及其上下文，與 `prompt` 中的內容保持一致）。
- prompt：需要替換的那一段新歌詞。
- style：歌曲的風格，選填。
- replace_section_start：被替換片段在原曲中的起始時間（秒）。
- replace_section_end：被替換片段在原曲中的終止時間（秒）。

## 控制歌曲時長

默認情況下生成的歌曲時長由模型自行決定，通常在 30 秒到 4 分鐘之間。如果需要更長或更短的成品，可以通過 `duration` 參數指定期望時長，單位是秒，取值為 10 到 360 之間的整數。

該參數用於自定義模式（`custom` 為 `true`）的歌曲生成。需要特別說明的是，`duration` 是一個**傾向性提示，而不是硬性約束**：模型在創作時會參考這個值，但不保證達到，實測中實際時長通常明顯短於期望值，同一次請求返回的兩首歌曲時長也可能相差數倍。即使是完全相同的請求，多次提交得到的時長也可能有較大差異。因此不要把它當作精確的時長控制來使用，如果業務上需要固定時長，請在拿到成品後自行裁剪或重試。

對應的 Python 代碼：

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

需要注意的是，請求中的 `duration` 是**期望時長**，而響應 `data` 中每首歌曲的 `duration` 字段是該首歌曲的**實際時長**。兩者名稱相同但含義不同，實際時長不保證等於期望值。歌詞長度是影響成品時長的主要因素之一，若需要較長的成品，建議同時提供更完整的歌詞。

接口不會對 `duration` 做額外校驗，參數會原樣傳遞給模型。如果傳入了當前模式或模型不支持的取值，可能表現為該值被忽略，建議先用一次請求確認效果再批量使用。

## Inspo 靈感創作功能

Suno 新出的 Inspo 靈感創作功能，可以根據 1 到 4 段參考音頻作為靈感來源，生成全新的音樂。與翻版（cover）不同，Inspo 並不會復刻原曲，而是從參考音頻中提取風格靈感，再結合提示詞、風格標籤等生成新作品。使用時需要填寫如下參數：

- action：內容為 `inspo`。
- audio_urls：參考音頻的 URL 列表，需提供 1 到 4 個公開可訪問的音頻地址。
- model：使用的模型，例如 `chirp-v5`。
- prompt：歌詞或創作提示詞（可選）。
- tags：音樂風格標籤，例如 `acoustic, folk, warm`（可選）。
- title：歌曲標題（可選）。
- audio_weight：參考音頻對生成結果的影響權重，取值範圍 0 到 1（可選）。

> 說明：參考音頻需為公開可訪問的音頻文件。若參考音頻與平台曲庫中的已知錄音完全匹配，Suno 可能會因版權校驗而拒絕生成，建議使用自有或由 Suno 生成的音頻作為靈感來源。

```python
import requests
```

## 異步回調

由於 Suno 生成音樂的時間相對較長，大約需要 1-2 分鐘，如果 API 長時間無響應，HTTP 請求會一直保持連接，導致額外的系統資源消耗，所以本 API 也提供了異步回調的支持。

整體流程是：客戶端發起請求的時候，額外指定一個 `callback_url` 字段，客戶端發起 API 請求之後，API 會立馬返回一個結果，包含一個 `task_id` 的字段信息，代表當前的任務 ID。當任務完成之後，生成音樂的結果會通過 POST JSON 的形式發送到客戶端指定的 `callback_url`，其中也包括了 `task_id` 字段，這樣任務結果就可以通過 ID 關聯起來了。

下面我們通過示例來了解下具體怎樣操作。
