SUNO 允許我們透過任意音訊檔案建立自訂聲音角色，實現聲音複製用於音樂生成。與既有的 Persona API（使用 Suno 生成的 `audio_id`）不同，該 API 接受一個可公開存取的 `audio_url`，即你自己的人聲錄音。本文檔講解聲音複製 API 的串接方法。

在支援音色查詢的建立線路上，可以使用原應用和呼叫者身分，將建立結果中的 `persona_id` 傳給 `POST /suno/availability`。關聯帳號在線時回傳 `data.available=true`，確認離線時回傳 `data.available=false`。[音色可用性查詢指南](https://platform.acedata.cloud/documents/suno-availability-integration)

## 第一步：建立聲音角色

計費：聲音角色建立成功後，每次請求的標準費用為 **0.15 Credits**。適用的消費優惠以實際帳單為準，失敗請求不收費。

該 API 有三個輸入參數：`audio_url`（必填），為一個可公開存取的 MP3 或 WAV 格式音訊檔案 URL，其中包含單人清晰人聲；`name` 和 `description`（選填），為聲音角色的名稱和描述。

> **音訊檔案要求**
> - 音訊格式需為 `WAV` 或 `MP3`
> - 音訊時長需在 `10~240 秒` 之間，建議使用 `30~60 秒` 的乾淨單人乾聲素材
> - 音訊中應包含**清晰、可辨識的單人說話或演唱人聲**
> - 請務必避免**背景雜訊、伴奏、回聲、混響**；帶伴奏的完整歌曲通常無法通過聲紋驗證
> - 不要包含**多位說話者**或**多重人聲**
> - 音量過低、語音不清晰、雜訊過重的素材，可能導致**複製失敗**或**生成效果較差**
> **使用限制說明**
> - 透過上傳音訊建立的聲音角色為**私有資源**
> - 該聲音角色**不支援跨帳號重複使用**
> - 建議在建立成功後盡快使用，長時間不使用可能出現**失效或不可用**
> - 回傳的 `name` 由系統自動生成，請以回傳的 `persona_id` 為準

> **依明確的重試標記處理失敗**
> 錯誤物件中的 `retryable` 為選填布林欄位。當 `error.retryable` 為 `true` 時，表示此次失敗允許使用相同素材和相同參數稍後重新請求。明確未受理的服務繁忙或部分暫時聲紋驗證失敗可能帶有此標記，建議使用退避間隔並限制重試次數。
> 當 `retryable` 為 `false` 或欄位缺失時，不要僅根據 HTTP 500、`busy` 或錯誤文字自動重送。格式、時長、清晰度、重複錄音和內容審核問題應先修正；提交逾時、連線中斷或建立結果不明確時，應優先使用原 `task_id` 查詢任務，避免重複建立音色。失敗的請求不會計費，重試成功的請求依正常規則計費。

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> 上述 `https://cdn.acedata.cloud/suno_demo.mp3` 為可直接呼叫的範例素材（MP3，41 秒，單人乾聲）。
> 如需 `WAV` 格式範例，可使用
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765`（WAV，41 秒，單聲道 44.1kHz）。

結果如下：

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

可以看到，`data` 的 `persona_id` 欄位就是建立的聲音角色 ID。`is_public` 欄位始終為 `false`，因為透過上傳音訊建立的聲音角色是私有的。注意回傳的 `name` 為系統自動生成，後續請使用 `persona_id` 參照該聲音角色。

## 第二步：使用聲音角色生成音樂

有了聲音角色 ID 之後，我們便可以使用 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) 來進行音樂生成了。將 `action` 設為 `generate`，並將 `persona_id` 設為上面回傳的聲音角色 ID，生成的歌曲將使用複製的聲音進行演唱。

> **注意：** 聲音複製僅支援 `chirp-v4-5` 及以上模型（如 `chirp-v4-5`、`chirp-v5`、`chirp-v5-5`），不支援 `chirp-v4`。

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

結果如下：

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` 可用於 `generate` 生成，也可用於 `cover` / `upload_cover` 翻唱。指定聲音無需同時填寫 `vocal_gender`；聲音相似度仍取決於參考素材與生成結果。

透過本介面建立的聲音為私有資源。翻唱既有歌曲前，先呼叫 `/suno/upload`，傳入原曲 `audio_url` 和該聲音的 `persona_id`；上傳成功後，使用回傳的 `data.audio_id` 和同一個 `persona_id` 呼叫 `/suno/audios`：
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

建立聲音、上傳原曲和翻唱須使用相同的服務通道。請勿直接重複使用先前未與該私人聲音關聯的歌曲 ID；詳情見 [Suno 上傳參考音訊](https://platform.acedata.cloud/documents/suno-upload)。
