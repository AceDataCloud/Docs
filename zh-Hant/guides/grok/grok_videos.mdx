本文將介紹 Grok Videos Generation API 的對接說明，它可以透過輸入文本提示詞、輸入圖片以及可選的參考圖片來生成 Grok Imagine（xAI）影片。

## 申請流程

要使用 API，需要先到 [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) 對應頁面申請對應的服務，進入頁面之後，點擊「Acquire」按鈕，如圖所示：

![](https://cdn.acedata.cloud/q6ytrc.png)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請您來註冊和登入，登入註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費使用該 API。

## 模型說明

本 API 支援兩種模型：

- `grok-imagine-video`（預設）：支援文生影片（僅傳 `prompt`）和圖生影片（傳 `image_url`），價格較低。
- `grok-imagine-video-1.5-preview`：僅支援圖生影片，**必須**傳入 `image_url`。

## 基本使用

首先了解下基本的使用方式，輸入提示詞 `prompt`、模型 `model` 等參數，便可生成對應的影片。

可以看到這裡我們設定了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設定了 Request Body，包括：

- `prompt`：描述想要生成影片內容的文本提示詞。使用 `grok-imagine-video` 做文生影片時**必填**；傳入 `image_url` 時可選。
- `model`：生成影片的模型，可選 `grok-imagine-video`（預設）或 `grok-imagine-video-1.5-preview`。
- `image_url`：圖生影片的輸入圖片連結。當 `model` 為 `grok-imagine-video-1.5-preview` 時**必填**。
- `reference_image_urls`：可選的參考圖片連結陣列，用於引導影片的風格或內容。
- `aspect_ratio`：生成影片的寬高比，可選 `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`。
- `resolution`：輸出解析度，可選 `480p`（預設）或 `720p`，解析度越高消耗的額度越多。
- `duration`：生成影片的時長（秒），取值範圍 1–15，預設 8。按輸出秒數計費。
- `callback_url`：非同步回調地址，設定後 API 會立即返回 `task_id`，任務完成時將結果 POST 到該地址。

點擊「Try」按鈕即可進行測試，得到的結果類似如下：

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

返回結果一共有多個欄位，介紹如下：

- `success`：本次影片生成請求是否成功。
- `task_id`：本次影片生成任務的 ID。
- `trace_id`：本次請求的追蹤 ID，用於排查問題。
- `data`：生成的影片結果列表。
  - `id`：生成影片的唯一標識。
  - `video_url`：生成影片的連結地址。
  - `state`：影片生成任務的狀態，可選 `pending` / `succeeded` / `failed`。

我們只需要根據結果中 `data` 的 `video_url` 連結地址取得生成的影片即可。

對應的 CURL 程式碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

對應的 Python 程式碼如下：

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 圖生影片

如果想基於一張輸入圖片生成影片，可以傳入 `image_url`。使用 `grok-imagine-video-1.5-preview` 時必須提供該欄位：

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## 參考圖引導

如果想用一張或多張參考圖引導生成影片的風格或內容，可以在 `reference_image_urls` 中傳入圖片連結陣列：

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## 非同步回調

影片生成需要一定的處理時間。如果不希望保持長連線等待，可以傳入 `callback_url`，此時 API 會立即返回 `task_id`，任務完成後會將最終結果 POST 到該地址：

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

立即返回的結果如下：

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## 查詢任務結果

如果使用了非同步回調或希望主動查詢任務狀態，可以透過 [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks)（`POST https://api.acedata.cloud/grok/tasks`）根據 `task_id` 查詢任務的最新狀態與結果。

## 計費說明

本服務按生成影片的「輸出秒數」計費，單價由 `model` 與 `resolution` 共同決定，總價 = 單價 × `duration`（預設 8 秒）。`720p` 比 `480p` 更貴，`grok-imagine-video-1.5-preview` 比 `grok-imagine-video` 更貴，具體單價以定價頁為準。

## 錯誤處理

當請求出現問題時，API 會返回對應的錯誤碼與說明，常見的如下：

- `400`：請求參數有誤，例如文生影片缺少 `prompt`，或 `grok-imagine-video-1.5-preview` 缺少 `image_url`，或 `duration` 超出 1–15 範圍。
- `401`：鑑權失敗，token 無效或與 API 不匹配。
- `403`：餘額不足，或提示詞命中內容審核被拒絕。
- `429`：請求過於頻繁，觸發上游限流，請稍後重試。
- `500`：伺服器內部錯誤或上游生成失敗。
