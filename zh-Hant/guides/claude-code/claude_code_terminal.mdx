## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安裝 Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

安裝後檢查：

```bash
claude --version
```

## 3. 配置 Ace Data Cloud

全局使用時，將以下變量加入 `~/.zshrc` 或 `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="你的 API Key"
unset ANTHROPIC_API_KEY
```

重新打開終端，或 `source` 對應配置文件。

只對當前項目生效時，可創建已加入 `.gitignore` 的 `.claude/settings.local.json`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "你的 API Key"
  }
}
```

兩種方式任選一種。不要把真實 Key 寫入團隊共享的 `.claude/settings.json`；如果環境中已有 `ANTHROPIC_API_KEY`，應真正取消它，而不是設為空字符串。

## 4. 啟動並驗證

```bash
cd /path/to/your/project
claude
```

進入後發送一個只讀任務，例如“讀取 README.md 並用一句話總結”。調用記錄和餘額可在 [使用歷史](https://platform.acedata.cloud/console/usages) 與 [應用列表](https://platform.acedata.cloud/console/applications) 查看。

如果返回 401，檢查 Key 是否完整、舊 `ANTHROPIC_API_KEY` 是否已取消，並完全重啟 Claude Code。模型無需在接入配置中固定，可在 Claude Code 中選擇當前可用模型。
