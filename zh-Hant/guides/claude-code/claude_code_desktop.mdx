Claude Code 是 Anthropic 推出的一款 **Agentic Coding** 工具，也被稱為世界最強編程 Agent 之一。Claude Code 桌面應用提供了獨立的圖形化介面，支持 Diff 審查、並行會話（通過 Git Worktree 隔離）、遠程會話等功能，無需依賴任何 IDE。

本文檔主要介紹如何通過 AceData Cloud 的代理服務，在 Claude Code 桌面應用中配置和使用。

> **注意**：Claude Code 桌面應用目前處於預覽階段（Preview），僅支持 macOS 和 Windows。

## 申請流程

要使用 Claude Code，首先可以到 [Claude Messages 服務頁面](https://platform.acedata.cloud/documents/claude-messages) 點擊「Acquire」按鈕，獲取請求所需要的憑證：

![](https://cdn.acedata.cloud/nyq0xz.png)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請您來註冊和登錄，登錄註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費體驗 Claude Code 服務。

## 安裝桌面應用

### 系統要求

- macOS（Intel 和 Apple Silicon）或 Windows（x64 / ARM64）
- Linux 暫不支持桌面應用

### 下載安裝

前往 [Claude 官方下載頁面](https://claude.ai) 下載對應平台的安裝包：

- **macOS**：下載 `.dmg` 文件，拖入 Applications 文件夾
- **Windows x64**：下載 `.exe` 安裝包，按提示安裝
- **Windows ARM64**：下載 ARM64 版本（注意：ARM64 不支持本地會話，需使用遠程會話）

![Claude 桌面應用下載頁面](https://cdn.acedata.cloud/c3c8c57264.png)

安裝完成後，從 Applications 文件夾（macOS）或開始菜單（Windows）啟動 Claude。

## 配置 AceData Cloud API

桌面應用啟動後需要登錄 Anthropic 帳號。我們可以通過配置環境變量來使用 AceData Cloud 的代理 API，**無需官方訂閱**。

桌面應用從你的 Shell 環境中讀取環境變量，因此需要在 Shell 配置文件中進行設置。

### 配置環境變量

**macOS 用戶**

將以下內容添加到 `~/.zshrc`（或 `~/.bashrc`）中，將 `{token}` 替換為你的 API 令牌：

```bash
# AceData Cloud - Claude Code 代理配置
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

保存後執行：

```bash
source ~/.zshrc
```

**Windows 用戶**

通過「系統屬性 → 高級 → 環境變量」添加以下系統環境變量：

| 變量名                    | 值                           |
| ---------------------- | --------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}`（替換為你的 API 令牌）     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

或者使用 PowerShell：

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**也可以通過 settings.json 配置**

編輯 `~/.claude/settings.json`（如不存在則創建）：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **提示**：API 令牌可在 [AceData Cloud 控制台](https://platform.acedata.cloud/console) 中查看。配置完成後需要**重啟桌面應用**使環境變量生效。

## 基本使用

### 打開項目

1. 啟動 Claude 桌面應用
2. 點擊頂部的 **Code** 標籤頁
3. 選擇 **Local** 運行模式
4. 點擊 **Select folder** 選擇你的項目目錄

### 開始對話

在輸入框中輸入自然語言描述你的需求：

- 「找到 TODO 註釋並修復它」
- 「為主函數添加測試」
- 「解釋這個項目的架構」

Claude 會分析你的代碼庫，提出修改方案，並以 Diff 視圖展示變更。

### 權限模式

通過發送按鈕旁邊的模式選擇器切換：

| 模式       | 說明                 |
| -------- | ------------------ |
| **Ask**  | 每次修改前詢問確認（推薦新手使用）  |
| **Code** | 自動接受文件編輯，但終端命令仍需確認 |
| **Plan** | 先制定詳細計劃等待審批，確認後才執行 |

### 並行會話

點擊側邊欄的 **+ New session** 可以啟動多個並行會話。對於 Git 倉庫，每個會話會通過 Worktree 獲得獨立的項目副本，互不干擾。

Worktree 默認存儲在 `~/.claude-worktrees/` 目錄。

### Diff 審查

當 Claude 修改了文件後，會顯示變更統計（如 `+12 -1`），點擊可以打開 Diff 查看器，逐文件審查修改。你還可以點擊具體代碼行添加評論，Claude 會根據你的反饋進行調整。

## 連接外部工具

在開始會話前，點擊 **⋯** 按鈕，選擇 **Connectors** 可以添加外部集成：

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- 更多...

連接後，Claude 可以直接讀取日曆、發送消息、創建 Issue 等。

## 與 CLI 的關係

桌面應用和 CLI 使用相同的底層引擎，共享以下配置：

- `CLAUDE.md` / `CLAUDE.local.md` 項目記憶文件
- `~/.claude.json` / `.mcp.json` 中的 MCP 伺服器配置
- `~/.claude/settings.json` 中的設置
- Hooks 和 Skills 配置

兩者可以同時運行在同一個項目上，各自維護獨立的會話歷史。

## 常見問題

### 連接失敗怎麼辦？

1. 檢查 `~/.claude/config.json` 文件是否正確創建
2. 確認環境變量已正確設置（重啟桌面應用使之生效）
3. 確認 API 令牌有效（可在 [控制台](https://platform.acedata.cloud/console) 查看）
4. 如果使用 `settings.json` 配置環境變量，確認文件格式正確

### 找不到安裝的工具？

如果 Claude 無法找到 `npm`、`node` 等命令：

1. 確認這些工具在普通終端中能正常使用
2. 檢查你的 Shell 配置文件（`~/.zshrc`、`~/.bashrc`）是否正確設置了 PATH
3. 重啟桌面應用以重新加載環境變量

### 如何查看剩余额度？

登錄 [AceData Cloud 控制台](https://platform.acedata.cloud/console)，即可查看當前帳戶的剩余额度和使用情況。
