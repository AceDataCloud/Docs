Claude Code 是 Anthropic 推出的編程智能體，可以在終端、IDE 以及 CI/CD 流水線等多種環境中使用。透過 AceData Cloud 代理，你可以以更低的價格使用 Claude Code。

按使用場景選擇對應平台的完整配置教程：

| 平台 | 說明 | 教程連結 |
|------|------|---------|
| **VS Code** | 原生擴充，支援內聯 Diff、@-mentions、計劃審查 | [VS Code 配置教程](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 相容編輯器，Claude Code 擴充完全支援 | [Cursor 配置教程](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **終端 (CLI)** | 核心體驗，在任意終端運行 `claude` 即可開始 | [終端配置教程](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **GitHub Actions** | 用 `@claude` 自動化程式碼審查和 Issue 處理 | [GitHub Actions 配置教程](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **提示**：首次申請可前往 [Claude Messages 服務頁面](https://platform.acedata.cloud/documents/claude-messages) 點擊「Acquire」獲取憑證，即贈免費額度。
