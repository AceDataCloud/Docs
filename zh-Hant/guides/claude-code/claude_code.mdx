Claude Code 透過 Anthropic Messages 協議接入 Coding Plan，當前提供終端與 VS Code 兩種配置入口。

| 使用入口           | 配置指南                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| Terminal / CLI | [Claude Code 終端配置](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code        | [Claude Code for VS Code 配置](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## 共通配置

- Base URL：`https://api.acedata.cloud`
- API Token：從 Coding Application 獲取，並透過指南中的 `ANTHROPIC_AUTH_TOKEN` 配置
- Model ID：從即時模型目錄選擇
- 修改配置後：重新啟動 Claude Code；VS Code 使用者需要重載窗口

不要同時保留舊的 `ANTHROPIC_API_KEY`，也不要把真實 Token 寫入團隊共享文件。

返回 [Coding Plan 配置中心](https://platform.acedata.cloud/documents/coding-plan-integration)。
