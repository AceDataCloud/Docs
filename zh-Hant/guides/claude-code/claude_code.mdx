Claude Code 是 Anthropic 推出的編程智能體，可以在終端、IDE、桌面應用等多種環境中使用。透過 AceData Cloud 代理，你可以以更低的價格使用 Claude Code。

> **第一次接入？** 推薦先看 [Claude Code 5 分鐘极速上手](https://platform.acedata.cloud/documents/claude-code-5min-quickstart)——從領取憑證到第一條命令成功運行，五步走完。

按使用場景選擇對應平台的完整配置教程：

| 平台 | 說明 | 教程連結 |
|------|------|---------|
| **⚡ 5 分鐘快速開始** | 從領憑證到第一條 `claude` 命令，五步走完 | [5 分鐘教程](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **終端 (CLI)** | 核心體驗，在任意終端運行 `claude` 即可開始 | [終端配置教程](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | 原生擴展，支持內聯 Diff、@-mentions、計劃審查 | [VS Code 配置教程](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 兼容編輯器，Claude Code 擴展完全支持 | [Cursor 配置教程](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | 支持 IntelliJ IDEA、PyCharm、WebStorm 等全系 IDE | [JetBrains 配置教程](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | 用 `@claude` 自動化代碼審查和 Issue 處理 | [GitHub Actions 配置教程](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **桌面應用 (Preview)** | 獨立的圖形化客戶端，支持並行會話、連接外部工具 | [桌面應用配置教程](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **提示**：首次申請可前往 [Claude Messages 服務頁面](https://platform.acedata.cloud/documents/claude-messages) 點擊「Acquire」獲取憑證，即贈免費額度。
