## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安裝 CC Switch

從 [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest) 下載，macOS 也可以運行：

```bash
brew install --cask cc-switch
```

## 3. 添加 Provider

打開 CC Switch，選擇 **Claude Code → Add Provider → Custom**，填寫：

| 字段         | 值                           |
| ---------- | --------------------------- |
| Name       | `Ace Data Cloud`            |
| Base URL   | `https://api.acedata.cloud` |
| API Key    | 剛剛複製的 API Key               |
| API Format | `Anthropic Messages`        |

如需使用 JSON 編輯器，配置為：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch 會把配置寫入 Claude Code 的用戶設置。不要在團隊倉庫中保存真實 Key，也不要同時保留舊 `ANTHROPIC_API_KEY`。

## 4. 啟用並驗證

保存後啟用 **Ace Data Cloud**，重新打開 Claude Code。發送一個簡單的只讀任務，並在 [使用歷史](https://platform.acedata.cloud/console/usages) 核對調用。如果切換後仍使用舊配置，完全退出 Claude Code 和 CC Switch 後重試。
