## 1. 获取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安裝 CLI 和插件

先安裝 Claude Code CLI。

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

再從 JetBrains Marketplace 安裝 **Claude Code** 插件並重啟 IDE。插件調用本機的 `claude` 命令；如果提示找不到命令，在 **Settings → Tools → Claude Code** 中填寫其完整路徑。

## 3. 配置 Ace Data Cloud

在啟動 JetBrains backend 的環境中設置。

macOS / Linux / WSL：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="你的 API Key"
unset ANTHROPIC_API_KEY
```

Windows PowerShell：

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "你的 API Key"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

也可以在項目中使用已忽略的 `.claude/settings.local.json`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "你的 API Key"
  }
}
```

Remote Development 要在遠程 Host 配置並安裝插件；WSL 用戶可將 Claude command 設為 `wsl -d Ubuntu -- bash -lic "claude"`。

## 4. 驗證

從 IDE 集成終端運行 `claude`，或在外部終端啟動後輸入 `/ide`。連接成功後讓 Claude 回覆 `OK`，再讀取一個測試文件，並在 Ace Data Cloud [使用歷史](https://platform.acedata.cloud/console/usages) 核對該請求。

如果插件無法啟動，先在同一終端運行 `claude --version`；401 則檢查 backend 實際繼承的環境變量和舊 `ANTHROPIC_API_KEY`。
