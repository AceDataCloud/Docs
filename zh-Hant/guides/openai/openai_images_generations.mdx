## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 發送第一個請求

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

成功響應的圖片位於 `data[].url`。下面是 2026 年 9 月 8 日通過 Ace Data Cloud 實際請求得到的 1024×1536 結果（任務 `d56455e2-e7f7-4bcd-b935-475b0a1e0948`，trace `eb938601-8192-407f-b539-1e0554b697ec`）：

![GPT Image 2 生成的白色馬克杯](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. 常用參數

| 字段                | 說明                                                                     |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | 使用 `gpt-image-2`；也可顯式選擇 `gpt-image-2:official` 或 `gpt-image-2:reverse` |
| `prompt`          | 圖片描述，最長 32,000 個字符                                                     |
| `size`            | `auto` 或 `WIDTHxHEIGHT`；寬高須為 16 的倍數，長邊不超過 3840，總像素不超過 8,294,400        |
| `n`               | 1–10；`response_format=b64_json` 時僅支持 1                                 |
| `quality`         | `low`、`medium`、`high` 或 `auto`；不同線路的支持和計費方式不同                          |
| `response_format` | `url` 或 `b64_json`                                                     |
| `callback_url`    | 可選；長任務完成後向該地址發送結果                                                      |

常用尺寸：

| 比例   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` 會根據提示詞中的比例、像素和版式意圖選擇畫幅；需要精確像素時直接填寫尺寸。

## 4. 多張生成

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

默認 `gpt-image-2` 與 `:reverse` 按成功張數計費；`gpt-image-2:official` 根據響應中的文字輸入和圖片輸出實際 Token 結算。頁面價格是請求前估算，最終以使用記錄為準。

## 5. 異步回調

請求體加入 `callback_url` 後，接口會先返回 `{"task_id": "..."}`，完成時向該 URL POST 最終結果；同步請求仍返回 `created` 和 `data`：

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

回調接收方應使用 `task_id` 去重，並驗證請求來源與數據格式。

## 6. 排錯

| 狀態  | 檢查                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`、`prompt`、尺寸格式、`n` 與 `response_format` 組合    |
| 401 | API Key 是否完整，Header 是否為 `Authorization: Bearer ...` |
| 429 | 請求過於頻繁，稍後重試                                         |
| 504 | 同步生成超時；改用 `callback_url`                            |

錯誤響應會包含 `error.code`、`error.message` 和 `trace_id`。反饋問題時提供 `trace_id`，不要提供 API Key。

完整字段和實時枚舉以 [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) 頁面為準。圖像編輯請查看 [GPT Image 2 圖像編輯](https://platform.acedata.cloud/documents/openai-images-edits)。
