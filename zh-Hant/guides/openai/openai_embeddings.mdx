OpenAI 詞向量服務，用於生成表示輸入文字的詞向量結果。

本文檔主要介紹 OpenAI Embeddings API 操作的使用流程，利用它我們可以建立表示輸入文字的嵌入向量。。

## 申請流程

要使用 OpenAI Embeddings API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果您尚未登入或註冊，會自動跳轉到登入頁面邀請您註冊和登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台所有服務，無需為每個服務個別申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## 基本使用

接下來就可以在介面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

在第一次使用該介面時，我們至少需要填寫三個內容，一個是 `authorization`，直接在下拉清單裡面選擇即可。另一個參數是 `model`， `model` 就是我們選擇使用 OpenAI 官網模型類別，目前可用模型為 `text-embedding-3-small` 和 `text-embedding-3-large`。`text-embedding-ada-002` 已停止提供；既有向量索引若使用該舊模型，不能直接混用新模型的向量，需要重新建立索引。最後一個參數是`input`，`input` 是我們需要轉換的詞向量文字。

同時您可以注意到右側有對應的呼叫程式碼生成，您可以複製程式碼直接執行，也可以直接點擊「Try」按鈕進行測試。

可選參數：

- `dimensions`：裁剪向量維度，預設輸出完整維度。
- `encoding_format`：回傳格式，可選 `float` 或 `base64`。

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Python 範例呼叫程式碼：

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

回傳結果一共有多個欄位，介紹如下：

- `model`，此次文字轉詞向量所採用的模型。
- `usage`，此次文字轉詞向量所使用的 token 資訊。
- `data`，文字轉換後的詞向量結果。

其中 `data` 是包含了文字對應的詞向量的具體資訊，它裡面的 `embedding` 是生成的詞向量具體結果。

## 錯誤處理

在呼叫 API 時，如果遇到錯誤，API 會回傳相應的錯誤代碼和資訊。例如：

- `400 token_mismatched`：錯誤請求，可能是因為缺少或無效的參數。
- `400 api_not_implemented`：錯誤請求，可能是因為缺少或無效的參數。
- `401 invalid_token`：未授權，無效或缺少授權 Token。
- `429 too_many_requests`：請求過多，您已超過速率限制。
- `500 api_error`：內部伺服器錯誤，伺服器發生了問題。

### 錯誤回應範例

```json

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
