## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 使用圖片 URL 編輯

原圖：

![GPT Image 2 編輯原圖](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "保持杯子、桌面、相機角度、肖像佈局和柔和陰影不變。僅將杯子顏色從白色改為鮮豔的橙色，並將淡奶油背景改為實心的深海軍藍。無文字和無標誌。",
    "size": "1024x1536"
  }'
```

成功響應：

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

這是 2026 年 9 月 8 日通過 Ace Data Cloud 實際完成的編輯結果，杯子變為橙色、背景變為深海軍藍，並保持原始構圖和 1024×1536 尺寸：

## 3. 上傳本地圖片

使用 `multipart/form-data`：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=將背景替換為明亮的現代工作室"
```

可重複傳入 `image`，GPT Image 系列最多支持 16 張參考圖。JSON 請求中的 `image` 可以是單個 URL 或 URL 陣列；本地文件使用 multipart 上傳。

## 4. 常用參數

| 字段                | 說明                                                            |
| ----------------- | ------------------------------------------------------------- |
| `model`           | `gpt-image-2`、`gpt-image-2:official` 或 `gpt-image-2:reverse`  |
| `image`           | JSON 使用單個 URL 或最多 16 個 URL 的陣列；multipart 使用一個或多個 `image` 文件字段 |
| `prompt`          | 編輯指令                                                          |
| `size`            | `auto` 或符合限制的 `WIDTHxHEIGHT`                                  |
| `n`               | 1–10；`response_format=b64_json` 時僅支持 1                        |
| `response_format` | `url` 或 `b64_json`                                            |
| `callback_url`    | 可選異步回調地址                                                      |

尺寸規則與生成接口一致：寬高須為 16 的倍數，長邊不超過 3840，總像素不超過 8,294,400。省略 `size` 或使用 `auto` 時，模型會結合提示詞和第一張參考圖選擇畫幅。

默認 `gpt-image-2` 與 `:reverse` 按成功張數計費；`gpt-image-2:official` 根據文字輸入、參考圖輸入和圖片輸出的實際 Token 結算，最終以使用記錄為準。

## 5. 異步回調與排錯

長任務可在請求中加入：

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

異步 200 響應為 `{"task_id": "..."}`；完成後回調最終結果。同步請求則返回 `created` 和 `data`。

| 狀態  | 檢查                      |
| --- | ----------------------- |
| 400 | 圖片格式/數量、參數組合和尺寸格式       |
| 401 | API Key 與 Bearer Header |
| 429 | 請求頻率                    |
| 504 | 改用異步回調                  |

錯誤響應會包含 `trace_id`。反饋問題時提供該 ID，不要提供 API Key。

完整字段和實時枚舉以 [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) 頁面為準。純文本生成圖片請查看 [GPT Image 2 圖像生成](https://platform.acedata.cloud/documents/openai-images-generations)。
