## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式清單](https://platform.acedata.cloud/console/applications)，進入可用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 使用圖片 URL 編輯

原圖：

![GPT Image 2 編輯原圖](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

成功回應：

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

這是 2026 年 9 月 8 日透過 Ace Data Cloud 實際完成的編輯結果，杯子變為橘色、背景變為深海軍藍，並保持原始構圖和 1024×1536 尺寸：

![GPT Image 2 橘色馬克杯編輯結果](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. 上傳本機圖片

使用 `multipart/form-data`：

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

可重複傳入 `image`，GPT Image 系列最多支援 16 張參考圖。JSON 請求中的 `image` 可以是單一 URL 或 URL 陣列；本機檔案使用 multipart 上傳。

## 4. 常用參數

| 欄位                | 說明                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`、`gpt-image-2.5-flare`（更快）或 `gpt-image-2.5-sunburst`（更高保真度與控制）；三者皆可選擇對應的 `:official` 變體，`gpt-image-2` 還支援 `:reverse` |
| `image`           | JSON 使用單一 URL 或最多 16 個 URL 的陣列；multipart 使用一個或多個 `image` 檔案欄位                                                                    |
| `prompt`          | 編輯指令                                                                                                                             |
| `size`            | `auto` 或符合限制的 `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10；`response_format=b64_json` 時僅支援 1                                                                                           |
| `response_format` | `url` 或 `b64_json`                                                                                                               |
| `callback_url`    | 可選的非同步回呼地址                                                                                                                         |

尺寸規則與生成介面一致：寬高須為 16 的倍數，長邊不超過 3840，總像素為 655,360–8,294,400，寬高比不超過 3:1。省略 `size` 或使用 `auto` 時，模型會結合提示詞和第一張參考圖選擇畫幅。

`gpt-image-2`、`gpt-image-2.5-flare`、`gpt-image-2.5-sunburst` 與 `gpt-image-2:reverse` 按成功張數計費；`gpt-image-2:official`、`gpt-image-2.5-flare:official` 和 `gpt-image-2.5-sunburst:official` 根據文字輸入、參考圖輸入和圖片輸出的實際 Token 結算，最終以使用記錄為準。

## 5. 非同步回呼與除錯

長任務可在請求中加入：

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

非同步 200 回應為 `{"task_id": "..."}`；完成後回呼最終結果。同步請求則回傳 `created` 和 `data`。

| 狀態  | 檢查                      |
| --- | ----------------------- |
| 400 | 圖片格式/數量、參數組合和尺寸格式       |
| 401 | API Key 與 Bearer Header |
| 429 | 請求頻率                    |
| 504 | 改用非同步回呼                  |

錯誤回應會包含 `trace_id`。回報問題時提供該 ID，不要提供 API Key。

完整欄位和即時列舉以 [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) 頁面為準。純文字生成圖片請查看 [GPT Image 2 / 2.5 圖像生成](https://platform.acedata.cloud/documents/openai-images-generations)。
