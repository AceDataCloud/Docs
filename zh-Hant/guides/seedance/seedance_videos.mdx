本文將介紹一種 SeeDance Videos Generation API 串接說明，它可以透過輸入自訂參數來生成 SeeDance 官方的影片。

## 申請流程

要使用 SeeDance Videos Generation API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請你註冊和登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台所有服務，無需為每個服務個別申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## 基本使用

首先先了解一下基本的使用方式，就是輸入提示詞 `content.text`、類型 `content.type=text` 以及模型 `model`，便可獲得處理後的結果，具體的內容如下：

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

可以看到這裡我們設定了 Request Headers，包括：

- `accept`：想要接收怎樣格式的回應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：呼叫 API 的金鑰，申請之後可以直接下拉選擇。

另外設定了 Request Body，包括：

- `model`：生成影片的模型。
  - **Seedance 1.x 系列**：`doubao-seedance-1-0-pro-250528`、`doubao-seedance-1-0-pro-fast-251015`、`doubao-seedance-1-5-pro-251215`、`doubao-seedance-1-0-lite-t2v-250428`、`doubao-seedance-1-0-lite-i2v-250428`。
  - **Seedance 2.0 系列**（支援角色和音影片多模態參考）：`doubao-seedance-2-0-260128`（標準）、`doubao-seedance-2-0-fast-260128`（快速）、`doubao-seedance-2-0-mini-260615`（輕量）。
  - **Seedance 2.5**：`doubao-seedance-2-5-260628`，支援最長 30 秒、純音訊參考、更多素材、影片編輯與延長。
- `content`：輸入內容陣列，`type` 可以是 `text`（提示詞）、`image_url`（參考圖片）、`audio_url`（參考音訊）、`video_url`（參考影片）。圖片可透過 `role` 指定用途：`first_frame`（首幀）/ `last_frame`（尾幀）/ `reference_image`（角色 / 主體參考）。
- `resolution`：輸出解析度，可選 `480p` / `720p` / `1080p` / `4k`。2.5 支援 480p、720p、1080p；2.0 Fast/Mini 支援 480p、720p；2.0 Standard 最高支援 4k。
- `ratio`：長寬比，可選 `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`。
- `duration`：影片時長（秒，整數）。1.0 系列 2–12；1.5 Pro 4–12；2.0 系列 4–15；2.5 為 4–30。1.5/2.x 支援 `-1`（自動時長）。
- `seed`：隨機種子，整數，-1 到 4294967295。
- `camerafixed`：是否固定攝影機，`true` / `false`。
- `watermark`：是否新增浮水印，`true` / `false`。
- `generate_audio`：是否生成有聲影片，`true` / `false`，Seedance 1.5 Pro 與 2.x 系列支援。
- `return_last_frame`：是否在結果中回傳影片最後一幀圖片 URL。
- `omni_reference_task_type`：僅 2.5；`auto` / `reference` / `edit` / `extend`。
- `output_format`：僅 2.5；`mp4` / `mov`，預設 `mp4`。
- `tools`：僅 2.5；目前支援 `web_search` 聯網檢索工具，可限制結果數、關鍵字數和搜尋來源。
- `priority`：2.5 可選任務優先級，整數 0–9，預設 0。
- `safety_identifier`：最長 64 字元的穩定匿名終端使用者識別碼；請使用雜湊或內部匿名 ID，不要傳入姓名、電子郵件或手機號碼。
- `execution_expires_after`：任務逾時時間（秒），範圍 3600–259200。
- `callback_url`：非同步回呼地址，設定後 API 立即回傳 `task_id`，任務完成時將結果 POST 到該地址。
- `async`：可選，設為 `true` 時介面立即回傳 `task_id`，無需提供 `callback_url`，隨後透過對應的任務查詢介面輪詢取得結果。

## 內聯參數說明

在 `content[].text` 提示詞末尾，可以透過追加 `--parameter value` 的形式傳入生成參數（舊方式，弱驗證，填寫有誤時自動使用預設值）。完整參數列表如下：

| 內聯參數       | 對應欄位              | 說明      | 取值範圍                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | 輸出解析度   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | 寬高比     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | 影片時長（秒） | 2–12                                                          |
| `--frames` | `frames`          | 影片影格數    | [29, 289] 中符合 25+4n 的整數（**僅 1.0 系列支援**）                       |
| `--fps`    | `framespersecond` | 幀率      | 僅支援 `24`                                                      |
| `--seed`   | `seed`            | 隨機種子    | -1 到 4294967295                                               |
| `--cf`     | `camerafixed`     | 是否固定攝影機 | `true` / `false`                                              |
| `--wm`     | `watermark`       | 是否加入浮水印  | `true` / `false`                                              |

> **建議做法**：直接在 Request Body 中使用對應的頂層欄位（如 `resolution`、`ratio` 等），為強驗證模式，參數填寫有誤時會傳回明確錯誤提示，更容易排查問題。

## 生成有聲影片

Seedance 1.5 Pro 與 2.x 系列支援透過 `generate_audio` 參數生成帶音訊的影片：

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

1.0 系列不支援此參數。

## Seedance 2.5 全模態生成、編輯與延長

`doubao-seedance-2-5-260628` 支援 480p / 720p / 1080p、4–30 秒或自動時長，並把素材上限提高到 30 張參考圖片、10 段參考影片、10 段參考音訊（總計最多 50 個）。2.5 還支援僅傳入參考音訊，不再要求同時提供圖片或影片。

一般全模態生成可省略 `omni_reference_task_type`，設為 `auto`，或明確設為 `reference`。影片編輯與延長必須傳入 `reference_video`：

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`：至少傳入一個 `reference_image`、`reference_video` 或 `reference_audio`；2.5 支援僅傳入參考音訊。
- `edit`：必須使用 `ratio: adaptive` 和 `duration: -1`；輸出時長依實際結果計費。
- `extend`：必須使用 `ratio: adaptive`；`duration` 可為 4–30 或 `-1`。
- `auto`：模型根據提示詞和素材自動選擇生成、編輯或延長。
- 任務類型與素材或提示詞不符合時，任務會失敗並傳回可定位的參數錯誤；請依上述限制調整後重新提交。

## 圖生影片首幀

如果想要圖生影片任務，首先 `content` 參數需要包含 `type` 為 `image_url` 的項目，`image_url` 欄位必須為物件格式：`{"url": "https://..."}` 或 Base64 格式 `{"url": "data:image/png;base64,..."}`。

> **注意**：`image_url` 不支援直接傳入字串格式（如 `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`），必須使用物件格式 `"image_url": {"url": "https://..."}`，否則會傳回 400 錯誤。

對應的程式碼：

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

點擊執行，可以發現會立即得到一個結果，如下：

```
{

  "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",

  "data": {
    "task_id": "cgt-20251222072003-x2259",
```

可以看到，生成的效果是圖生影片的，結果與上文類似。

## 圖生影片首尾幀

如果想要圖生影片首尾幀，首先參數`content`必須傳入類型`image_url`，並且分別設定`role`為`first_frame`和`last_frame`，就可以指定如下內容：

- role：指定首幀或尾幀。
- image_url
  - url 圖片連結
    同時 `content` 還需要輸入類型`text`作為prompt提示詞

對應的程式碼：
```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

點擊執行後，可以發現會立即得到一個結果，如下：

## 角色與音影片多模態參考（Seedance 2.0）

**Seedance 2.0 系列**（`doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-mini-260615`）支援 `reference_image`、`reference_audio` 與 `reference_video`。可使用自有或已獲授權的素材保持角色、主體、動作、運鏡、聲音與節奏的一致性。

> 請僅上傳自有或已獲授權的真人與角色素材。不同模型對真人素材的支援方式不同；請求格式保持不變，若素材不符合要求會回傳明確錯誤。

使用要點：

- 僅 **Seedance 2.0 系列**模型支援 `reference_image`；1.x 模型請使用 `first_frame` / `last_frame`（圖生影片首尾幀）。
- 圖生影片首幀、圖生影片首尾幀和全模態參考是三種互斥場景：`first_frame` / `last_frame` 不能與 `reference_image` / `reference_video` / `reference_audio` 混用。
- 若想在全模態參考中指定首尾幀，請把圖片標為 `reference_image`，並在提示詞中寫明「圖片 1 作為首幀」或「圖片 2 作為尾幀」；若需要嚴格鎖定首尾幀，則只使用 `first_frame` / `last_frame`。
- 多模態參考數量上限：`image_url` 最多 **9** 張；2.0 還支援 `audio_url`（`role` 為 `reference_audio`，最多 3 條）與 `video_url`（`role` 為 `reference_video`，最多 3 條）。
- **參考音訊（`audio_url`）素材要求**：格式 `wav` / `mp3`；**單條時長 2~15 秒**，最多 3 條且**總時長不超過 15 秒**；單條不超過 15 MB。超出時長範圍會在素材處理階段失敗。
- **參考影片（`video_url`）素材要求**：格式 `mp4` / `mov`；**單條時長 2~15 秒**，最多 3 條且**總時長不超過 15 秒**。
- 參考圖片建議使用**單人、正臉、清晰、無遮擋**的照片，人臉越清晰，相似度越高。

### 範例一：保持人物樣貌的特寫

傳入一張人臉照片，讓該人物對著鏡頭微笑揮手。對應的程式碼：

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedance-2-0-fast-260128",
    "content": [
        {
            "type": "text",
            "text": "The woman looks at the camera, gives a warm natural smile and waves her hand, soft studio lighting, gentle camera push-in."
        },
        {
            "type": "image_url",
            "role": "reference_image",
            "image_url": {
                "url": "https://cdn.acedata.cloud/assets/examples/nanobanana/8e075897-0f50-4443-8500-666751791c6c-4346f66287c0.jpg"
            }
        }
    ],
    "resolution": "480p",
    "ratio": "9:16",
    "duration": 5
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

回傳結果如下，生成的影片中人物與參考照片保持一致：

### 範例二：把同一個人放進全新場景

`reference_image` 的強大之處在於：只保留**人物身分**，而場景、服裝、動作完全由提示詞決定。下面使用同一張人臉照片，讓該人物身著米色大衣走在秋日公園裡：

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    {
      "type": "text",
      "text": "The same woman wearing a beige coat walks through a sunny autumn park, golden leaves falling around her, she smiles softly at the camera, cinematic tracking shot."
    },
    {
      "type": "image_url",
      "role": "reference_image",
      "image_url": {
        "url": "https://cdn.acedata.cloud/assets/examples/nanobanana/8e075897-0f50-4443-8500-666751791c6c-4346f66287c0.jpg"
      }
    }
  ],
  "resolution": "720p",
  "ratio": "9:16",
  "duration": 5
}
```

回傳結果如下，人物樣貌得以保留，而場景已切換為秋日公園：
```json

  "data": {
    "task_id": "32fe1537-ba3e-452a-8749-3ef8890d37fd",

}
```

> 💡 若想讓人物精確復刻照片中的構圖（而非「換個場景的同一個人」），可改用 `first_frame`（圖生影片首幀），讓影片從這張照片開始運動。

## 非同步回呼

由於 SeeDance Videos Generation API 生成時間較長（約 1-2 分鐘），可透過 `callback_url` 欄位使用非同步模式，避免 HTTP 連線長時間佔用。

整體流程：用戶端發起請求時指定 `callback_url`，API 立即回傳包含 `task_id` 的回應；任務完成後，平台將生成結果以 POST JSON 的形式傳送到 `callback_url`，結果中同樣包含 `task_id` 以便關聯。

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

任務完成時，平台推送到 `callback_url` 的內容如下：

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

結果中的 `task_id` 欄位與請求時回傳的一致，透過該欄位即可實現任務的關聯。

## 錯誤處理

在呼叫 API 時，如果遇到錯誤，API 會回傳相應的錯誤代碼和資訊。例如：

- `400 token_mismatched`：錯誤請求，可能是因為缺少或無效的參數。
- `400 api_not_implemented`：錯誤請求，可能是因為缺少或無效的參數。
- `401 invalid_token`：未授權，無效或缺少授權權杖。
- `429 too_many_requests`：請求過多，您已超出速率限制。
- `500 api_error`：內部伺服器錯誤，伺服器發生問題。

### 錯誤回應範例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
