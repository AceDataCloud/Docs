本文將介紹 Veo Objects API 的對接說明。該接口用於對一段已經生成的 Veo 視頻進行**物體增加或刪除**操作（基於蒙版的局部重繪）。

## 申請流程

要使用 API，需要先到 Veo 服務對應頁面申請。如果你尚未登錄或註冊，會自動跳轉到登錄頁面。

## 基本使用

調用本接口需要傳入下列參數：

- `video_id`（必填）：來源視頻的任務 ID。**不能**是 `/veo/extend` 的輸出視頻。
- `action`（必填）：操作類型，`insert` 或 `remove`。
- `prompt`：
  - `action=insert`：**必填**，描述要加入的物體。
  - `action=remove`：選填，描述要移除的內容（主要用於日誌記錄，實際擦除區域由 `image_mask` 決定）。
- `image_mask`：
  - `action=insert`：選填。如果不傳，AI 會自動決定插入位置；如果傳入，則在白色像素區域插入。
  - `action=remove`：**必填**，白色像素區域為要擦除的對象。

`image_mask` 接受兩種格式：

1. 一個**公開可訪問的 HTTP(S) 圖片地址**（推薦）。
2. **base64 編碼的 JPEG 字符串**，可以帶 `data:image/jpeg;base64,` 前綴，也可以是裸 base64。

請求示例（插入物體，不傳蒙版，讓 AI 自動定位）：

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

請求示例（按蒙版移除物體）：

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

返回結果結構與 `/veo/videos` 相同。

## 計費說明

- `action=insert` 或 `remove`：1.50 Credit / 次。

## 異步回調

接口支持異步模式，傳入 `callback_url` 即可在任務完成後通過 POST 請求回調結果。若無公網回調地址，也可將 `async` 設為 `true`，接口同樣立即返回 `task_id`，隨後通過對應的任務查詢接口輪詢獲取結果。
