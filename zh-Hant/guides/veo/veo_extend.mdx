本文將介紹 Veo Extend API 的對接說明。該接口用於對一段已經生成的 Veo 視頻進行**時長延展**，AI 會自動續寫後續畫面。

## 申請流程

要使用 API，需要先到 Veo 服務對應頁面申請。如果你尚未登錄或註冊，會自動跳轉到登錄頁面。

## 基本使用

調用本接口需要傳入下列參數：

- `video_id`（必填）：來源視頻的任務 ID（來自 `/veo/videos` 或本接口本身）。
- `model`（必填）：用於延展的模型，**僅支持 `veo31-fast` 和 `veo31` 兩個模型**，其他模型上游不支持。
- `prompt`（選填）：用於引導延展段畫面的文字提示。
- `aspect_ratio`（選填）：`16:9` 或 `9:16`，默認 `16:9`。
- `resolution`（選填）：`720p` 或 `1080p`。

請求示例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "the camera slowly zooms out to reveal more of the landscape"
  }'
```

返回結果與 `/veo/videos` 相同：

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## 重要限制

`video_id` 必須來自 TTAPI 線路生成或延展完成後的 `data[].id`。切換 TTAPI 之前由舊線路生成的歷史視頻 ID 無法用於該接口，調用時會返回 `400 bad_request`；請通過 `/veo/videos` 重新生成後再延展。

來自 `/veo/extend` 的延展結果視頻可以**繼續被 `/veo/extend` 再次延展**，但是**不能**再被以下接口處理：

- `/veo/reshoot` —— 不能換鏡頭運動
- `/veo/objects` —— 不能再做物體增刪

如果傳入的 `video_id` 是延展結果，相關接口會返回 400 錯誤，請改用原始視頻作為來源。

## 計費說明

- `model=veo31-fast`：1.68 Credit / 次
- `model=veo31`：12.00 Credit / 次

## 異步回調

接口支持異步模式，傳入 `callback_url` 即可在任務完成後通過 POST 請求回調結果。若無公網回調地址，也可將 `async` 設為 `true`，接口同樣立即返回 `task_id`，隨後通過對應的任務查詢接口輪詢獲取結果。
