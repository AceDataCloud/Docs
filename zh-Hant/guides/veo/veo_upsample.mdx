本文將介紹 Veo Upsample API 的對接說明。該接口用於對一段已經生成的 Veo 視頻進行升採樣或者輸出動圖預覽。

## 申請流程

要使用 API，需要先到 Veo 服務對應頁面申請。如果你尚未登錄或註冊，會自動跳轉到登錄頁面。

## 基本使用

調用本接口需要傳入兩個參數：

- `video_id`：來源視頻的任務 ID。可以是 `/veo/videos`、`/veo/extend`、`/veo/reshoot`、`/veo/objects` 任意接口生成的視頻 ID。
- `action`：升採樣動作，支持以下三種：
  - `1080p`：把視頻升採樣到 1080p 分辨率。
  - `4k`：把視頻升採樣到 4K 分辨率。
  - `gif`：把視頻轉換為動圖（GIF）預覽。

請求示例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

返回結果與 `/veo/videos` 相同，仍然是異步任務結構，可以通過 `task_id` 在 `/veo/tasks` 接口查詢任務狀態：

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

返回字段說明：

- `success`：升採樣任務是否提交成功。
- `task_id`：本次升採樣任務的 ID。
- `data`：升採樣後的視頻結果。
  - `video_url`：升採樣後的視頻地址。

## 計費說明

- `action=1080p`：0.16 Credit / 次
- `action=4k`：0.50 Credit / 次
- `action=gif`：0.13 Credit / 次

如果傳入的 `action` 不在以上枚舉內，會被默認計費為 0.50 Credit。建議顯式傳入支持的值。

## 異步回調

接口同樣支持異步模式，傳入 `callback_url` 即可在任務完成後通過 POST 請求回調結果。若無公網回調地址，也可將 `async` 設為 `true`，接口同樣立即返回 `task_id`，隨後通過對應的任務查詢接口輪詢獲取結果。
