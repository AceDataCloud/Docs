本文將介紹 Veo Reshoot API 的對接說明。該接口用於對一段已經生成的 Veo 視頻按照**新的鏡頭運動方式重新生成**，畫面內容保持一致，但鏡頭機位與運動會按 `motion_type` 重新演繹。

## 申請流程

要使用 API，需要先到 Veo 服務對應頁面申請。如果你尚未登錄或註冊，會自動跳轉到登錄頁面。

## 基本使用

調用本接口需要傳入下列參數：

- `video_id`（必填）：來源視頻的任務 ID。**不能**是 `/veo/extend` 的輸出視頻。
- `motion_type`（必填）：新的鏡頭運動方式，使用大寫下劃線風格的簡潔別名。

### `motion_type` 支持值

| 別名                             | 含義           |
| ------------------------------ | ------------ |
| `STATIONARY`                   | 鏡頭固定不動       |
| `STATIONARY_UP`                | 鏡頭固定，向上俯仰    |
| `STATIONARY_DOWN`              | 鏡頭固定，向下俯仰    |
| `STATIONARY_LEFT`              | 鏡頭固定，左搖      |
| `STATIONARY_RIGHT`             | 鏡頭固定，右搖      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | 鏡頭固定，前推 + 推焦 |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | 鏡頭固定，後退 + 拉焦 |
| `UP`                           | 鏡頭上升         |
| `DOWN`                         | 鏡頭下降         |
| `LEFT_TO_RIGHT`                | 鏡頭從左向右平移     |
| `RIGHT_TO_LEFT`                | 鏡頭從右向左平移     |
| `FORWARD`                      | 鏡頭向前推進       |
| `BACKWARD`                     | 鏡頭向後退        |
| `DOLLY_IN_ZOOM_OUT`            | 移動中前推 + 推焦   |
| `DOLLY_OUT_ZOOM_IN`            | 移動中後退 + 拉焦   |

請求示例：

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

返回結果結構與 `/veo/videos` 相同。

## 計費說明

- 單次重拍：1.20 Credit。

## 異步回調

接口支持異步模式，傳入 `callback_url` 即可在任務完成後通過 POST 請求回調結果。若無公網回調地址，也可將 `async` 設為 `true`，接口同樣立即返回 `task_id`，隨後通過對應的任務查詢接口輪詢獲取結果。
