Maestro 任務查詢 API 的主要功能是通過 [Maestro 視頻生成 API](development_maestro_videos.md)（`POST /maestro/videos`）返回的任務 ID，查詢該任務的執行狀態與最終結果。

本文檔將詳細介紹 Maestro 任務查詢 API 的對接說明。由於視頻生成是一個異步任務，提交後需要用本接口輪詢獲取進度與成片，**輪詢免費、不消耗積分。**

`POST https://api.acedata.cloud/maestro/tasks`

## 申請流程

要使用 Maestro 任務查詢 API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[Maestro 任務查詢 API →](https://platform.acedata.cloud/documents/maestro-tasks)

## 查詢單個任務

關於怎樣創建視頻任務，請參考文檔 [Maestro 視頻生成 API](development_maestro_videos.md)。我們以其返回的一個任務 ID 為例：`f57e99c4f60f4373a15517742ce2357d`，演示如何查詢它的狀態與結果。

### 設置請求頭和請求體

**Request Headers** 包括：

- `accept`：指定接收 JSON 格式的響應結果，這裡填寫為 `application/json`。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。
- `content-type`：請求體的格式，這裡填寫為 `application/json`。

**Request Body** 包括：

| 字段       | 類型     | 必填  | 說明                                                |
| -------- | ------ | --- | ------------------------------------------------- |
| `id`     | string | 是   | `POST /maestro/videos` 返回的 `task_id`              |
| `action` | string | 否   | `retrieve`（默認，查詢單個任務）/ `retrieve_batch`（查詢歷史任務列表） |

### 代碼示例

對應的 CURL 代碼如下：

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

對應的 Python 代碼如下：

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

返回結果的字段介紹如下：

- `id`：此視頻任務的 ID，用於唯一標識本次視頻生成任務。
- `status`：任務狀態，取值為 `pending → planning → producing → succeeded`（或 `failed`）。任務是否已完成，以該頂層 `status` 為準。
- `elapsed`：任務已耗時（秒）。
- `progress`：頂層進度對象，`percent`（0–100）在任務成功後會被兜底為 100；`stage` 與 `message` 反映 AI 導演最近一條進度事件（因此成功後 `stage` 可能仍是最後一個執行階段如 `producing`），可直接用於展示進度條。
- `request`：發起任務時的請求體。
- `response`：任務的返回信息。
  - `success`：任務是否成功。
  - `data.variants`：每種語言對應一個成片對象，含 `lang`、`aspect`、`title`、`output_url`（成片下載地址）等。
  - `data.project`：整個項目產物，含 `tarball_url`（工程包）與 `outputs`（所有成片鏈接）。
  - `data.progress`：按階段追加的進度事件數組（append-only 日誌），可用於展示詳細的實時進度。
- `created_at`：任務創建時間，Unix 時間戳（秒）。
- `started_at`：任務開始執行時間，Unix 時間戳（秒）。任務尚未開始時為 null。
- `finished_at`：任務完成時間，Unix 時間戳（秒）。任務未完成時為 null。

## 查詢歷史列表

傳入 `action: retrieve_batch` 即可獲取當前用戶最近的任務（按創建時間倒序），可用於「我的視頻」列表頁。

**Request Body** 包括：
| 字段               | 类型     | 必填  | 说明                      |
| ---------------- | ------ | --- | ----------------------- |
| `action`         | string | 是   | 固定为 `retrieve_batch`    |
| `limit`          | int    | 否   | 返回条数，默认 20              |
| `created_at_max` | int    | 否   | 只返回早于该 Unix 时间戳的任务（翻页用） |
| `created_at_min` | int    | 否   | 只返回晚于该 Unix 时间戳的任务      |

### 代码示例

对应的 CURL 代码如下：

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

## 轮询建议

由于视频生产耗时较长，`status` 会经历 `pending → planning → producing → succeeded`（或 `failed`）。建议每 5–10 秒轮询一次，直到 `status` 变为 `succeeded` 或 `failed` 为止。可借助顶层 `progress.percent` 展示实时进度条。**轮询本接口免费，不消耗积分。**

## 错误处理

在调用 API 时，如果遇到错误，API 会返回相应的错误代码和信息。例如：

- `401 invalid_token`：未授权，授权令牌无效或缺失。
- `404 not_found`：任务未找到，给定的 task_id 不存在。
- `429 too_many_requests`：请求过多，您已超出速率限制。
- `500 api_error`：内部服务器错误，服务器出现问题。

### 错误响应示例

```json
{

  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
