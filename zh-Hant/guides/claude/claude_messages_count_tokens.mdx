Claude Messages Count Tokens API 可以在不實際建立訊息的情況下，計算一則 Message 的輸入 Token 數量，包括工具、圖片和文件等內容的 Token 計數。這在需要預估成本或檢查輸入是否超出模型上下文限制時非常有用。

本文件主要介紹 Claude Messages Count Tokens API 的使用流程。

## 申請流程

要使用 Claude Messages Count Tokens API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果您尚未登入或註冊，會自動跳轉到登入頁面邀請您註冊和登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台所有服務，無需為每個服務個別申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## 基本使用

Claude Messages Count Tokens API 的請求路徑為 `/v1/messages/count_tokens`，與 Anthropic 官方 API 保持一致。我們至少需要提供兩個必填參數：

- `model`：選擇使用的 Claude 模型；`claude-opus-5-5` 可用於 Messages Token Count，如最新旗艦 `claude-fable-5-1`；原 `claude-fable-5` 仍相容保留。
- `messages`：輸入的訊息陣列，每則訊息包含 `role`（角色）和 `content`（內容）。

常用選填參數：

- `system`：系統提示詞，會計入 Token 數量。
- `tools`：工具定義，會計入 Token 數量。
- `thinking`：擴充思考設定。
- `tool_choice`：工具選擇設定。
- `cache_control`：頂層或內容區塊層級的快取控制設定。

`messages`、`system`、工具呼叫回放、URL 圖片和 document/PDF 內容區塊使用與 Messages API 相同的穩定請求結構。

### cURL 範例

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python 範例

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

回傳結果範例：

```json
{
  "input_tokens": 11
}
```

### 使用 Anthropic SDK

Claude Messages Count Tokens API 接受 Anthropic SDK 的穩定請求結構，可以透過 `anthropic` 函式庫呼叫。介面使用所選模型對應的原生 Count Tokens 能力統計輸入，可用於在傳送 Messages 請求前檢查輸入規模。

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## 包含工具的 Token 計數

如果您的請求中包含工具定義，這些工具也會計入 Token 數量：

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## 包含系統提示詞的 Token 計數

系統提示詞也會計入 Token 數量：

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## 注意事項

- 該 API 僅計算輸入 Token 數量，不會產生任何模型輸出。
- Token 計數結果可用於預估輸入規模和檢查上下文視窗；最終計費以實際 Messages 回應中的 `usage` 為準。
- 圖片、PDF、工具定義、系統提示詞和 thinking 設定會按照所選模型的輸入規則計入結果。
- 該 API 完全免費，不消耗任何額度。
