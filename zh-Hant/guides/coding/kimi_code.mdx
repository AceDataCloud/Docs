## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式列表](https://platform.acedata.cloud/console/applications)，進入可用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安裝 Kimi Code

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

也可以透過 npm 安裝：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. 設定 AceDataCloud

編輯 `~/.kimi/config.toml`，加入以下設定：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "你的 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

前往 [模型目錄](https://platform.acedata.cloud/models) 查看模型名稱（例如 `claude-opus-5`、`gpt-6-sol`），並將所有 `MODEL_ID` 替換為同一個名稱；進行精確驗證時，以 `/v1/models` 回應中的 `id` 值為準。該值就是 API `model` 參數所使用的模型名稱，不是服務或 API 的 UUID。`type = "openai"` 使用 OpenAI Chat Completions 協定。

設定檔包含 Key，macOS / Linux 建議限制權限：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. 驗證並啟動

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

進入專案後執行 `kimi` 即可開始使用。如果回傳 401，檢查 API Key；如果提示 model not found，確認 `default_model`、模型表名稱和 `model` 欄位使用同一個 ID。
