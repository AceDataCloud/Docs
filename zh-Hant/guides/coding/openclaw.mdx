## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安裝 OpenClaw 和插件

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

插件要求 OpenClaw `2026.4.2` 或更高版本，當前原生提供 Chat 和 Web Search 能力。

## 3. 配置 Key

推薦使用 onboarding：

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "你的 API Key"
```

也可以使用環境變量：

```bash
export ACEDATACLOUD_API_KEY="你的 API Key"
```

## 4. 可選：手動配置

不使用 onboarding 時，在 `~/.openclaw/openclaw.json` 中啟用插件並設置默認模型：

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

不要把 API Key 寫進該文件；繼續使用環境變量。

## 5. 選擇模型並驗證

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Reply only OK"
```

將 `MODEL_ID` 替換為 Coding Plan 當前提供的模型。需要設為默認模型時運行：

```bash
openclaw models set acedatacloud/MODEL_ID
```

調用記錄可在 [使用歷史](https://platform.acedata.cloud/console/usages) 查看。401 表示 Key 無效；模型不存在時先檢查 exact ID 和插件版本。插件目錄中的 `cost: 0` 僅表示不由 OpenClaw 重複估算，實際費用仍由 Ace Data Cloud 記錄。

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "latest AI agent frameworks" --limit 5
```

當前不要把插件介紹中的圖像、視頻或音樂能力當作 OpenClaw 原生 Provider 能力。
