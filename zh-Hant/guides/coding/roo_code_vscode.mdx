## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式清單](https://platform.acedata.cloud/console/applications)，進入可使用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 設定

Roo Code 官方提供 OpenAI-compatible Provider，並要求模型支援原生 OpenAI tools/function calling。

1. 在 VS Code 開啟 Roo Code 設定。
2. 將 **API Provider** 設為 **OpenAI Compatible**。
3. 填寫：

| 欄位       | 值                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | 剛才複製的 API Key                  |
| Model ID | 在 Coding 設定精靈中選擇的模型 ID         |

![Roo Code OpenAI Compatible 設定介面](https://cdn.acedata.cloud/b6a0e7156438.png)

接著根據模型實際能力設定 context、max output、圖片和 computer-use 選項。最後儲存設定並重新載入 VS Code。

## 3. 驗證

先傳送 `Reply only OK`，再讓 Roo Code 讀取一個測試檔案。若一般聊天成功但 Agent 工具失敗，請更換支援原生 tool calling 的模型，並確認相容端點能正確以串流方式傳回工具參數與結果。
