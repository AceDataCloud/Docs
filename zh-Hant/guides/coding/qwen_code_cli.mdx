Qwen Code 使用 `~/.qwen/settings.json` 的 `modelProviders` 配置自訂 Provider。這裡固定使用 OpenAI-compatible 協議。

## 配置

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` 必須是陣列。Provider 條目是獨立配置，不會自動繼承其它頂層 context、Header 或 body 參數。

## 驗證

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

進入後發送 `Reply only OK`，再運行一次只讀文件工具。嚴格兼容端點若拒絕工具結果格式，請檢查當前 Qwen Code 版本和官方 compatibility 說明。
