Continue 的 JetBrains 插件使用與 VS Code 相同的 YAML 模型格式；配置和 Secret 必須屬於運行 JetBrains 插件的用戶。

## 配置

在 Continue 的本地 YAML 配置中加入：

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

在 Continue secrets 中保存 `ACEDATACLOUD_API_KEY`。Remote Development 場景要在插件實際運行的主機配置。

## 驗證

重啟 JetBrains IDE，打開 Continue 工具窗口，選擇 Local Config 模型並發送 `Reply only OK`；再執行一次只讀文件任務。若仍使用舊模型，重啟遠程 backend 並檢查 YAML 縮進。
