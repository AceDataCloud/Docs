Aider 透過 LiteLLM 的 `openai/` 模型前綴連接 OpenAI-compatible API。

## 配置

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

把 `MODEL_ID` 替換為 Coding 配置向導中選擇的模型。也可以把對應選項寫入本地 `.env` 或 `.aider.conf.yml`，但不要提交真實 Token。

## 驗證

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

首次使用未知模型時，Aider 可能提示缺少模型元數據；這不等同於鑑權失敗。401 檢查 Token，404 檢查模型 ID 和 `/v1` Base URL。
