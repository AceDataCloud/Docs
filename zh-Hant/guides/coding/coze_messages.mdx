Coze 官方自定義模型文檔支持 Anthropic Messages API。不同 Coze 租戶版本對 Header、路徑拼接、streaming 和工具調用的處理可能不同，首次接入請按下文逐項檢查。

## 配置

1. 進入 Coze 模型管理並新增自定義模型。
2. Protocol 選擇 Anthropic Messages API。
3. Base API URL 填寫 `https://api.acedata.cloud`。
4. API Key 填寫你的 Ace Data Cloud API Token。
5. Model 填寫模型目錄中支持 Anthropic Messages 的精確模型 ID。
6. 保存並完成 Coze 的連接測試。
7. 在 Bot/Agent 中發送 `Reply only OK`，再測試一次工具調用。

## 當前邊界

- 不同 Coze 區域、版本或套餐可能顯示不同表單。
- Base API URL 不應重複追加 `/v1/messages`；若當前 UI 明確要求完整 API URL，以表單提示為準。
- Messages、Chat Completions 和 Responses 是三條獨立路線，不能互相替代驗證。
