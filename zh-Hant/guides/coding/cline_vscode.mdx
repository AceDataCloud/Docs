## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式列表](https://platform.acedata.cloud/console/applications)，進入可用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 設定 Cline

在 VS Code 安裝並開啟 Cline，然後透過 Cline 面板中的設定按鈕進入 Provider 設定，填寫：

| 欄位                                | 值                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | 剛剛複製的 API Key                                                                                  |
| Model ID                          | 前往 [模型目錄](https://platform.acedata.cloud/models) 查看，並原樣填寫目標模型名稱，例如 `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | 留空                                                                                             |
| Set Azure API version             | 留空                                                                                             |
| Use Azure Identity Authentication | 關閉                                                                                             |

![Cline OpenAI Compatible 設定介面](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` 是 API 請求中 `model` 參數使用的模型名稱，不是服務或 API 的 UUID，也不能自行縮寫。可先在 [模型目錄](https://platform.acedata.cloud/models) 查看；如需精確驗證，再使用目前 API Key 請求 `GET https://api.acedata.cloud/v1/models`，從回應的 `data` 陣列複製目標模型的 `id` 值。

其餘模型能力設定先保持預設；需要圖片或更大的上下文時，再依所選模型實際能力調整。

## 3. 驗證

儲存後新增任務並傳送 `Reply only OK`。再讓 Cline 讀取一個測試檔案，確認模型支援工具呼叫；呼叫紀錄可在 [使用歷史](https://platform.acedata.cloud/console/usages) 查看。

401 通常表示 Key 錯誤；404 通常表示 Base URL 不正確，或填寫的 Model ID 與目錄中的 `id` 不完全一致。如果模型能聊天但不能操作檔案，檢查該模型的工具呼叫能力。
