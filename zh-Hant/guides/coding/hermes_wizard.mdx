## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式清單](https://platform.acedata.cloud/console/applications)，進入可用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 執行精靈

```bash
hermes model
```

選擇 **Custom endpoint**，依序填寫：

| 欄位             | 值                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | 剛剛複製的 API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | 前往 [模型目錄](https://platform.acedata.cloud/models) 查看，並原樣填寫目標模型名稱，例如 `claude-opus-5`、`gpt-6-sol` |
| Context length | 留空自動偵測，或依模型目錄填寫                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` 是 API 請求中 `model` 參數使用的模型名稱，不是服務或 API 的 UUID。可先在 [模型目錄](https://platform.acedata.cloud/models) 查看；如需精確驗證，再使用目前 API Key 請求 `GET https://api.acedata.cloud/v1/models`，從回應的 `data` 陣列複製目標模型的 `id` 值。

精靈會寫入 `~/.hermes/config.yaml` 和本機憑證檔案。

## 3. 驗證

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

如果精靈沒有儲存設定，可執行 `hermes model --reset` 後重試；401 表示 API Key 無效或未被目前使用者設定讀取。
