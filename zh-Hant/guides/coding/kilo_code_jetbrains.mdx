## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 配置 Provider

Kilo Code 的 JetBrains 插件使用 `kilo.jsonc` Provider 格式。配置必須位於實際運行插件的用戶環境；Remote Development 時通常是遠程 backend 主機。

在 `~/.config/kilo/kilo.jsonc` 寫入：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

在啟動 JetBrains backend 的環境中導出 `ACEDATACLOUD_API_KEY`，再重啟 IDE 或遠程 backend。

## 3. 驗證

選擇 `acedatacloud/MODEL_ID`，發送 `Reply only OK`，再讓 Agent 讀取一個測試文件。若本地正常而遠程失敗，優先檢查配置文件和環境變量是否寫在遠程主機。
