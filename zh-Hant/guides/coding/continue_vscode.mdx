Continue 支援 OpenAI 相容的 API。為了固定走 Chat Completions，需要明確設定 `useResponsesApi: false`。

## 配置

在 Continue 的本地 YAML 配置中加入：

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

在 Continue 的 secrets 管理中保存 `ACEDATACLOUD_API_KEY`，不要把真實 Token 提交到專案配置。Continue 的 JSON 配置已經棄用，新配置使用 YAML。

## 驗證

重新載入 VS Code，打開 Continue 側欄，選擇 Local Config 中的模型並發送 `Reply only OK`；再執行一次只讀檔案任務。若請求錯誤地發往 `/responses`，檢查 `useResponsesApi: false` 是否位於該模型條目內。
