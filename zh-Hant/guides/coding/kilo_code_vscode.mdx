## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式列表](https://platform.acedata.cloud/console/applications)，進入可用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 新增 Custom provider

在 Kilo Code 中開啟 **Settings → Providers**，點擊 **Custom provider**，然後填寫：

| 欄位           | 值                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | 剛剛複製的 API Key                                                                                  |
| Models       | 前往 [模型目錄](https://platform.acedata.cloud/models) 查看，並新增要使用的模型名稱，例如 `claude-opus-5`、`gpt-6-sol` |

![Kilo Code Custom provider 設定介面](https://cdn.acedata.cloud/94eb5abd7a6f.png)

這裡的模型 `id` 是 API 請求中 `model` 參數使用的模型名稱，不是服務或 API 的 UUID。可先在 [模型目錄](https://platform.acedata.cloud/models) 查看；精確驗證時請從 `/v1/models` 回應的 `data` 陣列原樣複製，不要自行猜測或縮寫。

點擊 **Submit**，模型會出現在選擇器中。需要團隊共用或更細部設定時，也可依官方文件編輯使用者層級 `~/.config/kilo/kilo.jsonc` 或專案層級 `./kilo.jsonc`。

## 3. 驗證

選擇 `acedatacloud/MODEL_ID` 並傳送 `Reply only OK`，再執行一次唯讀檔案操作。若模型沒有出現，檢查 Provider 是否已提交、模型名稱是否與目錄中的 `id` 完全一致，以及 Base URL 是否正確。
