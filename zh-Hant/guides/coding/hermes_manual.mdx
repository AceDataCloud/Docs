## 1. 取得 API Key

開啟 [Ace Data Cloud 應用程式清單](https://platform.acedata.cloud/console/applications)，進入可用的應用程式並複製 API Key。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 儲存 Key

在 `~/.hermes/.env` 中寫入：

```dotenv
ACEDATACLOUD_API_KEY=你的 API Key
```

## 3. 設定 Provider

在 `~/.hermes/config.yaml` 中加入：

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

前往 [模型目錄](https://platform.acedata.cloud/models) 查看模型名稱（例如 `claude-opus-5`、`gpt-6-sol`），並將所有 `MODEL_ID` 替換為相同名稱；進行精確驗證時，以 `/v1/models` 回應中的 `id` 值為準。該值就是 API `model` 參數所使用的模型名稱，不是服務或 API 的 UUID。不要將真實 Key 寫入 YAML 或提交 `.env`。

## 4. 驗證

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

如果回傳 401，檢查 `~/.hermes/.env`；如果設定未生效，完全結束並重新啟動 Hermes。
