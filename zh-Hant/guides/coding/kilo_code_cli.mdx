## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 配置

Kilo CLI 讀取 `kilo.jsonc`，並從啟動 CLI 的 shell 讀取 API Key。

在 `~/.config/kilo/kilo.jsonc` 寫入：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

然後在當前 shell 匯出 Token：

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
```

## 3. 驗證

```bash
kilo run -m acedatacloud/MODEL_ID "Reply only OK"
```

如果 CLI 讀不到 Token，確認變數已經 `export`，而不只是寫進未加載的 `.env` 文件。
