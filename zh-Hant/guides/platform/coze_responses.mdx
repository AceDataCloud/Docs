Coze 官方自訂模型文件支援 OpenAI Responses API，並提供 Base API URL、API Key 與模型字段。不同 Coze 租戶版本對路徑拼接、串流輸出和工具調用的處理可能不同，首次接入請按下文逐項檢查。

## 配置

1. 進入 Coze 模型管理並新增自訂模型。
2. Protocol 選擇 OpenAI Responses API。
3. Base API URL 填寫 `https://api.acedata.cloud/v1`。
4. API Key 填寫你的 Ace Data Cloud API Token。
5. Model 填寫模型目錄中支援 Responses API 的精確模型 ID。
6. 保存並完成 Coze 的連接測試。
7. 在 Bot/Agent 中發送 `Reply only OK`，再測試一次工具調用。

## 當前邊界

- 不同 Coze 區域、版本或套餐可能顯示不同表單。
- Base API URL 應使用 base，不要重複追加 `/responses`；若當前 UI 明確要求完整 API URL，以表單提示為準。
- Chat Completions、Responses 和 Anthropic Messages 是三條獨立路線，不能互相替代驗證。
