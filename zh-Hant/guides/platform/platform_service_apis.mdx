透過 Service UUID 分頁回傳該服務目前啟用且未棄用的 API。只有 alias 時，先呼叫[服務詳情](https://platform.acedata.cloud/documents/platform-service-detail)取得 `id`。

## 介面概覽

| 項   | 內容                                                                  |
| --- | ------------------------------------------------------------------- |
| 方法  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| 驗證  | 公開，無需帳戶權杖                                                           |
| 分頁  | `count` + `items`                                                   |

## 參數

| 參數           | 位置    | 必填  | 說明                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | 是   | Service UUID，不支援 alias           |
| `limit`      | query | 否   | 每頁筆數，最大 100                      |
| `offset`     | query | 否   | 分頁偏移量                            |
| `ordering`   | query | 否   | Django 排序表達式；建議使用 `rank` 或 `-rank` |

目前介面不支援 `stage` 篩選；它已排除 `Deprecated` API。

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

清單項目使用與[平台 API 清單](https://platform.acedata.cloud/documents/platform-api-list)相同的索引結構，目前包含 `definition`。需要單一 API 的穩定入口時，繼續呼叫 `/api/v1/apis/{api_id}`。

## 錯誤處理

- 服務不存在或目前站點不可見：`404`。
- `service_id` 必須是 UUID；alias 不會在此 action 中解析。
