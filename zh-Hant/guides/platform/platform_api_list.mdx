分頁回傳目前站點可見的 API 端點。適合依業務路徑、服務或發布階段尋找 API；若只需要一個 API 的完整定義，請直接呼叫[API 詳情](https://platform.acedata.cloud/documents/platform-api-detail)。

## 介面概覽

| 項   | 內容                                            |
| --- | --------------------------------------------- |
| 方法  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| 驗證  | 公開，無需帳戶權杖                                     |
| 分頁  | `count` + `items`                             |

## 查詢參數

| 參數        | 類型      | 必填  | 說明                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | 否   | 精確比對 `path` 或 `path2` |
| `service` | string  | 否   | 服務 alias 或 UUID       |
| `stage`   | string  | 否   | 依發布階段篩選；可重複傳入多個值      |
| `limit`   | integer | 否   | 每頁筆數，最大 100           |
| `offset`  | integer | 否   | 分頁偏移量                 |

`id`、`service_id`、`tag` 目前不是列表篩選參數；傳入後不會產生對應篩選效果。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## 回應說明

線上回應使用 `{count, items}`。每個列表項目目前包含 API 模型欄位，以及：

- `document_id`：關聯開發者文件 ID，可能為空；
- `service_id` / `service`：主要服務 ID 與摘要，可能為空；
- `definition`：OpenAPI 定義，可能較大；
- `method`、`path`、`path2`、`stage`、`cost`、`tags`、`metadata` 等。

列表 serializer 目前包含 `definition`，拉取完整目錄時應分頁並設定逾時。欄位可能以向後相容的方式增加，客戶端只讀取所需欄位。
