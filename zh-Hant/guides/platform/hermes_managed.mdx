為每個 Application 建立獨立 Hermes 容器實例。預設使用固定發行版本的基礎映像，保留原生功能；平台提供購買、續費、持久化儲存與部署管理。

## 建立與購買

1. 開啟 [Hermes 部署](https://platform.acedata.cloud/services/hermes) 並建立 Application。
2. 在購買頁選擇時長方案，完成付款。
3. 返回設定頁，可從下拉列表選擇平台聊天模型，並查看目前模型價格。平台會為這個實例建立獨立 API 憑據；也可關閉平台接入，在原生控制台自行設定。
4. 選擇自動產生存取憑據，或設定自己的強密碼/Token，確認後開始部署。存取憑據與模型 API 憑據互相獨立。
5. 實例就緒後，從管理頁取得存取網址與登入憑據。
6. 登入原生控制台，設定自己的模型供應商、金鑰和渠道。

部署費按方案時長計費，具體美元價格、時長以購買頁為準。模型呼叫費用另計；購買部署時長不會贈送模型額度。啟用平台接入時，專用 API 憑據僅開放所選模型對應的聊天介面，呼叫從你的平台餘額另外計費。每個 Application 分別購買、續費和管理。

## 密碼、憑據與後續設定

存取憑據會在首次啟動前設定。自動產生方式使用隨機憑據，自訂密碼至少 16 個字元，OpenClaw Token 至少 32 個字元。草稿不儲存密碼；切換頁面後可能需要重新輸入。部署後，只有 Application 擁有者和管理員能查看存取憑據。

每個實例的模型 API 憑據互不共用，隨部署續費延長有效期，刪除實例時撤銷。部署初始化後，請在原生控制台修改模型和渠道；如果改選其他服務的模型，請先在平台憑據管理中調整對應介面授權，或使用相應憑據。一般重新部署不會覆蓋原生設定。未經發布驗證的部署環境會暫時拒絕新部署，請聯絡支援。

## 版本與資料

設定頁顯示目前發布的映像版本。新建實例使用服務目前發布版本；現有實例不會隨目錄更新自動替換。重新部署會套用目前服務版本，請先備份，確認所用版本的升級要求。

每個實例預設提供 1 CPU、2 GiB 記憶體上限和 10 GiB 持久化儲存。重新啟動會保留實例資料。主動刪除部署或到期回收會刪除儲存，請提前匯出需要保留的資料。

## 續費與到期

在目前 Application 的購買頁續費，有效期按平台現有時長規則延長。到期後存取入口暫停，寬限期內續費可恢復存取；超過寬限期會回收實例與資料。以管理頁的到期時間、計費狀態及刪除提示為準。

## 登入管理介面

在部署管理頁複製 Dashboard 網址、使用者名稱 `admin` 和密碼，開啟後登入。登入資訊僅向該 Application 的擁有者和平台管理員提供。模型、技能與渠道在 Hermes 原生介面中設定。

## 常見問題

- **為什麼新實例還不能回答？** 部署完成表示容器就緒；需要在原生介面設定模型和憑據才能開始使用。
- **是否預裝額外外掛或模型 fallback？** 預設不添加，按需要在原生介面設定。
- **已有實例怎麼更新？** 原有 Application 和訂單保留，重新部署時使用目前服務版本；升級前先備份資料並檢查版本相容性。
- **啟動失敗怎麼辦？** 先查看部署日誌與事件，確認實例就緒後再設定模型。不要在公開評論或截圖中暴露實例密碼和金鑰。
