---
title: "取得 AceDataCloud 平台 API 近期呼叫樣本"
description: "Platform 整合指南 - Ace Data Cloud"
---

公開傳回某個 API 最近 15 分鐘內的呼叫記錄樣本，用於快速觀察近期狀態。它不是按狀態碼彙總的計數介面，也不能用於個人帳單、SLA 或完整用量統計。

## 介面概覽

| 項   | 內容                                                           |
| --- | ------------------------------------------------------------ |
| 方法  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| 驗證  | 公開，無需帳戶權杖                                                    |
| 上限  | 合併最近建立/完成的記錄後最多傳回 5,000 筆                                    |

`api_id` 從[API 清單](https://platform.acedata.cloud/documents/platform-api-list)取得。

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## 真實回應結構

回應直接是陣列，不使用分頁 envelope：

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| 欄位            | 說明        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | 記錄建立時間    |
| `trace_id`    | 請求追蹤識別    |
| `status_code` | HTTP 狀態碼  |
| `elapsed`     | 呼叫耗時，單位為秒 |

API 不存在時目前也可能傳回空陣列，因為該 action 直接依 ID 查詢近期 usage，並不先驗證 API 物件。要計算成功率需由用戶端對傳回樣本自行分組；要查詢個人扣費請使用帳戶級介面。
