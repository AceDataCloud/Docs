[NextChat](https://github.com/ChatGPTNextWeb/NextChat)（前身為 ChatGPT-Next-Web）是開源 AI 用戶端，可部署於 Vercel、Cloudflare 或 Docker。它支援自訂 OpenAI 相容端點，因此可以串接 Ace Data Cloud。本文介紹設定流程。

## 申請流程

要在 NextChat 中串接 Ace Data Cloud，首先前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)，取得您的 API Token，以備後用。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登入或註冊，會自動跳轉至登入頁面邀請您進行註冊和登入，登入註冊之後會自動返回目前頁面。

首次申請時會贈送免費額度，可以免費體驗 Ace Data Cloud 的模型服務。

## 下載 NextChat

可以使用桌面版（於 [Releases 頁面](https://github.com/ChatGPTNextWeb/NextChat/releases) 下載 `.exe` / `.dmg` / AppImage）、[Web 線上版](https://app.nextchat.club/)，或自行部署至 Vercel / Cloudflare / Docker（見下方進階章節）。

## 設定 Ace Data Cloud

啟動 NextChat，進入 **設定 → 模型服務**：

| 欄位          | 值                           | 說明                              |
| ----------- | --------------------------- | ------------------------------- |
| 模型服務供應商       | `OpenAI`                    | 使用 OpenAI 相容協定                  |
| OpenAI 介面位址 | `https://api.acedata.cloud` | 只填根網域，**不含 `/openai`、不含 `/v1`** |
| API Key     | 你的 Ace Data Cloud Token     | 從控制台複製的 Token                    |

![NextChat Ace Data Cloud 設定介面](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat 會自動在介面位址後拼接 `/v1/chat/completions`，因此只需填寫根網域：

| 介面位址                                  | 實際請求                                                      | 結果                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | 正確                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404（`/openai` 下沒有 `/v1`） |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

在「自訂模型名稱」欄位中以英文逗號分隔填寫模型。NextChat 支援特殊語法：`+模型名` 新增、`-模型名` 隱藏、`模型名=顯示名稱` 自訂顯示名稱、`-all` 先全部隱藏。建議最乾淨的寫法：

```text
-all,+MODEL_ID=显示名称
```

## 選擇模型

模型目錄會持續更新。優先使用用戶端自動載入的模型清單；需要手動填寫時，先請求 `GET https://api.acedata.cloud/v1/models` 取得目前模型 ID，再依用戶端支援的上下文、圖片和工具呼叫能力進行選擇。

## 驗證串接

如果不確定問題出在 NextChat 還是網路，可以先使用 curl 直接驗證端點（將 `{token}` 替換為你的 Token）：

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

返回 OpenAI 相容的 `chat.completion` 物件即表示 Token 與端點皆已就緒；若返回 `HTTP 403 used_up` 則表示 Token 有效但餘額不足，前往[控制台](https://platform.acedata.cloud/console/applications)儲值即可。

## 進階：一鍵部署至自己的網域

NextChat 支援部署一個屬於自己的 AI 網站。以 Docker 為例（將 `{token}` 替換為你的 Token）：

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

Vercel / Cloudflare 部署時，在專案的環境變數中設定相同的 `OPENAI_API_KEY`、`BASE_URL`、`CODE`、`CUSTOM_MODELS` 即可。`CODE` 支援以英文逗號分隔多個存取密碼，便於依人統計用量。以上環境變數的完整說明（`BASE_URL` 預設為 `https://api.openai.com`、`CUSTOM_MODELS` 的 `+/-/=/-all/+all` 語法）請以 [NextChat 官方 README](https://github.com/ChatGPTNextWeb/NextChat#environment-variables) 為準。

## 常見問題

### 提示 404 Not Found

通常是介面位址寫成了 `.../openai` 或 `.../openai/v1`。改為 `https://api.acedata.cloud`，讓 NextChat 自行拼接 `/v1/chat/completions`。

### 模型下拉選單中沒有新增的模型

檢查 `CUSTOM_MODELS` 格式，每個模型前必須有 `+`；如果使用了 `-all`，請確保後面使用 `+` 重新加回需要的模型。

### 提示 401 Unauthorized

請確認 API Key 中貼上的是 Ace Data Cloud 的 Token（不含 `Bearer` 前綴、沒有多餘空格），且所屬應用程式的餘額充足。
