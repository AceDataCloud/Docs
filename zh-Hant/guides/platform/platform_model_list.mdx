回傳平台公開的模型目錄，回應採用 OpenAI 風格的 `{ "object": "list", "data": [...] }` 結構。該目錄用於模型選擇和能力探索，不代表目前帳戶一定已經申請了對應服務。

## 介面概覽

| 項   | 內容                                              |
| --- | ----------------------------------------------- |
| 方法  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| 鑑權  | 公開，無需帳戶權杖                                       |
| 分頁  | 不分頁，所有符合項目位於 `data`                              |

## 查詢參數

| 參數             | 類型      | 必填  | 說明                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | 否   | 依目錄中的模型提供者識別碼精確篩選                        |
| `type`         | string  | 否   | 依模型類型精確篩選，例如 `chat`                     |
| `capability`   | string  | 否   | 僅回傳 `capabilities` 包含該能力的模型，例如 `vision` |
| `with_pricing` | boolean | 否   | 為 `1`、`true` 或 `yes` 時附加公開價格資訊            |

`service_id`、`tag`、`limit`、`offset` 和 `ordering` 目前不受支援；傳入後不會產生相應篩選或分頁效果。

## 請求範例

```shell
# 所有公開模型
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# 支援視覺的 chat 模型，並附價格
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## 真實回應結構

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` 和頂層 `credit_usd_rate` 僅在 `with_pricing=true` 時出現；並非每個模型都有可計算的 `pricing`。模型物件以 `config/models.json` 的公開欄位為準，客戶端應忽略新增欄位。

> 價格欄位是目錄展示資料。實際業務呼叫仍以對應 API/Service 的計費規則和最終用量記錄為準。
