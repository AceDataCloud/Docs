GitHub Copilot 官方 BYOK 文档將 VS Code 列為支持的本地客戶端，並支持 OpenAI-compatible Provider。VS Code 版本、企業策略和模型可見性會影響最終 endpoint；首次接入請按下文檢查實際請求。

## 配置範圍

1. 確認你的 GitHub Copilot 賬戶或組織已啟用 BYOK/Custom Models 功能。
2. 在 VS Code 的 Copilot 模型管理中新增 OpenAI-compatible Provider。
3. Base URL 填寫 `https://api.acedata.cloud/v1`。
4. API Key 填寫你的 Ace Data Cloud API Token。
5. Model 填寫模型目錄中與所選協議兼容的精確模型 ID。
6. 在 Copilot Chat 中發送 `Reply only OK`，再測試一次帶工作區上下文的請求。

## 當前邊界

- Copilot App、CLI、GitHub Desktop、Enterprise BYOK 與 VS Code 的配置合同不同，本指南不把其他客戶端步驟直接套用到 VS Code。
- 組織策略可能禁止個人添加 Provider 或模型。
- Tab completion、Chat、Agent 與後台任務可能使用不同模型路徑，應分別驗證。
