透過文件 UUID 或 alias 取得單篇文件的完整內容和導覽關係。已知 alias 時可以直接請求，無需先從列表篩選。

## 介面概覽

| 項   | 內容                                                              |
| --- | --------------------------------------------------------------- |
| 方法  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| 驗證  | 公開；知道 UUID 或 alias 即可直接讀取                                       |

## 參數

- `id_or_alias`：文件 UUID、目前 alias，或保留在 `redirect_from` 中的舊 alias。
- `lang`：可選語言提示；也可使用 `Accept-Language`。最終內容語言以回應 `content_locale` 為準。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## 回應說明

詳情使用單一物件回應，目前包含：

- `id`、`alias`、`redirect_from`、`name`、`title`、`type`、`rank`、`tags`；
- `content`、`content_mode`、`content_locale`、`content_hash`；
- `parent`、`sibling` 和依 rank 排序的公開 `children` 摘要；
- `api` / `proxy` / `dataset` / `integration` 關聯，以及 `agent`（存在時）。

回應沒有 `breadcrumbs` 欄位。建構麵包屑時可從 `parent` 繼續讀取其詳情，或使用已快取的文件目錄關係。

## 錯誤處理

- ID/alias 不存在或不符合目前網站可見性：`404`。`private` 只控制列表可見性，不阻止知道連結的人直接讀取，不能作為保密邊界。
- 目前路由使用無尾斜線形式；不要依賴代理層自動補斜線。
