[LobeChat](https://lobehub.com/) 是支援外掛程式、知識庫和自行部署的開源 AI 用戶端，可使用線上版或透過 Docker 部署。它支援自訂 OpenAI 相容端點，因此可以串接 Ace Data Cloud。本文介紹設定流程。

## 申請流程

要在 LobeChat 中串接 Ace Data Cloud，首先前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications)，取得您的 API Token，留作備用。

![取得 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登入或註冊，會自動跳轉至登入頁面邀請您註冊和登入，登入註冊之後會自動返回目前頁面。

首次申請時會贈送免費額度，可以免費體驗 Ace Data Cloud 的模型服務。

## 設定 Ace Data Cloud

進入 LobeChat 的 **應用程式設定 → 語言模型**，找到 **OpenAI** 卡片並啟用，填入：

| 欄位       | 值                              | 說明                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | 你的 Ace Data Cloud Token        | 從控制台複製的 Token               |
| API 代理位址 | `https://api.acedata.cloud/v1` | **必須以 `/v1` 結尾**           |
| 用戶端請求模式  | 開啟                             | 瀏覽器直接連線，Key 不會經過 LobeChat 伺服器 |

![LobeChat OpenAI Provider 設定介面](https://cdn.acedata.cloud/629ef9d3084a.png)

> 使用 Chat Completions 介面時，請保持 Responses API Specification 關閉。

LobeChat 不會自動為 Base URL 加上 `/v1`，請求路徑直接是 `{API 代理位址}/chat/completions`：

| API 代理位址                              | 實際請求                                                   | 結果                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | 正確                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | 也可使用                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404（`/openai` 下沒有 `/v1`） |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404（缺少 `/v1`）             |

LobeChat 預設會呼叫 `/v1/models` 自動取得模型，Ace Data Cloud 回傳的模型較多時介面會很長，建議在「模型清單 → 自訂模型名稱」中手動填寫一個 allow list，以英文逗號分隔。如需自訂顯示名稱，可以使用 `=`，格式為 `MODEL_ID=顯示名稱`。

## 選擇模型

模型目錄會持續更新。優先使用用戶端自動載入的模型清單；需要手動填寫時，先請求 `GET https://api.acedata.cloud/v1/models` 取得目前模型 ID，再依用戶端支援的上下文、圖片和工具呼叫能力選擇。

## 驗證串接

如果不確定問題出在 LobeChat 還是網路，可以先使用 curl 直接驗證端點（將 `{token}` 替換為你的 Token）：

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

回傳 OpenAI 相容的 `chat.completion` 物件即表示 Token 與端點都已就緒；若回傳 `HTTP 403 used_up` 則表示 Token 有效但餘額不足，前往[控制台](https://platform.acedata.cloud/console/applications)儲值即可。

## 進階：Docker 自行部署

如果希望部署一份私有版供團隊使用，可使用 Docker 一行指令啟動（將 `{token}` 替換為你的 Token）：

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

開啟 `http://你的伺服器IP:3210`，輸入 `ACCESS_CODE` 即可使用，團隊成員無需各自填寫 Key。上面使用的 `OPENAI_API_KEY`、`OPENAI_PROXY_URL`、`OPENAI_MODEL_LIST` 等環境變數的完整說明請參閱 [LobeChat 模型服務供應商環境變數文件](https://lobehub.com/docs/self-hosting/environment-variables/model-provider)。若使用 nginx 反向代理加上 HTTPS，請務必加上 `proxy_buffering off;`，否則串流回應會被緩衝。更多部署型態請參考 [LobeChat 自行部署入門](https://lobehub.com/docs/self-hosting/start) 與 [Docker Compose 部署](https://lobehub.com/docs/self-hosting/platform/docker-compose)。

## 常見問題

### 提示 404 Not Found

通常是 API 代理位址寫成了 `.../openai/v1` 或漏了 `/v1`。改成 `https://api.acedata.cloud/v1`。

### 模型清單為空

開啟「用戶端請求模式」開關；或在「自訂模型名稱」中手動填寫模型 allow list。

### 提示 401 Unauthorized

請確認 API Key 中貼上的是 Ace Data Cloud 的 Token（不含 `Bearer` 前綴、無多餘空格），且所屬應用程式的餘額充足。
