title: "取得 AceDataCloud 平台服務下的 Proxy 列表"
description: "Platform 整合指南 - Ace Data Cloud"
---

透過 Service UUID 分頁返回該服務掛載的 Proxy 端點。只有 alias 時，先呼叫[服務詳情](https://platform.acedata.cloud/documents/platform-service-detail)取得 `id`。

## 介面概覽

| 項   | 內容                                                                     |
| --- | ---------------------------------------------------------------------- |
| 方法  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| 驗證  | 公開，無需帳戶權杖                                                              |
| 分頁  | `count` + `items`                                                      |

## 參數

| 參數                 | 位置    | 必填  | 說明                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | 是   | Service UUID，不支援 alias           |
| `limit` / `offset` | query | 否   | 分頁                               |
| `ordering`         | query | 否   | Django 排序表達式；建議使用 `rank` 或 `-rank` |

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## 回應說明

列表項目由 Proxy 模型序列化，線上已驗證的欄位包括 `id`、`service_id`、`title`、`endpoint`、`price`、`stage`、`rank`、`tags`、`metadata`、`document_id`、`service` 和時間欄位。

- 業務入口欄位是 `endpoint`，不是 `path`。
- 定價欄位是 `price`，不是 `cost`。
- Service 類型不是 Proxy 或未掛載 Proxy 時會返回空的 `items`。

公開整合僅依賴 `endpoint` 和已發布能力，不應依賴未公開的實作細節。
