讀取目前請求上下文下的公開功能開關與國家/地區判斷。適合前端啟動時決定功能是否顯示；它不是網站品牌、聯絡方式或公告目錄。

## 介面概覽

| 項   | 內容                                              |
| --- | ----------------------------------------------- |
| 方法  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| 驗證  | 公開；攜帶登入狀態時部分功能開關可能依使用者計算                          |

## 查詢參數與請求標頭

| 名稱                    | 位置     | 說明                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | 兩位 ASCII 國家代碼；用於覆寫回應中的顯示國家，不改變伺服器安全判斷 |
| `features`            | query  | 功能開關覆寫運算式；只對允許用戶端覆寫的開關或超級管理員生效        |
| `X-Feature-Overrides` | header | 與 `features` 相同的覆寫來源                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## 真實回應結構

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| 欄位         | 類型            | 說明                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | 目前請求可見的功能開關；鍵會隨平台設定變化，用戶端應視需要讀取並為缺失鍵設定安全預設值 |
| `country`  | string / null | 小寫國家代碼；無法識別時可能為 `null`                     |

不要從本介面讀取網站名稱、CDN、貨幣、語言、客服聯絡方式或公告；這些欄位不屬於目前回應契約。

## 使用建議

- 功能開關會依使用者、指紋和網站上下文計算，不要跨使用者長期共用快取。
- 用戶端傳入的 `country` 只影響回傳值，不會繞過伺服器地區或安全策略。
- 未識別的 query 參數會被忽略；只使用本頁列出的參數。
