Inferpal 是面向 Visual Studio 2022/2026 的扩展，官方支持连接 OpenAI-compatible 服务。扩展版本可能影响编辑、工具调用和用量记录；首次接入请固定版本并完成下文的最小验证。

## 配置

1. 从 Visual Studio Marketplace 或官方仓库安装 Inferpal。
2. 打开 Inferpal 的 **Settings → Connection**。
3. Provider 选择 OpenAI-compatible。
4. Base URL 填写 `https://api.acedata.cloud/v1`。
5. API Key 填写你的 Ace Data Cloud API Token。
6. Model 填写模型目录中支持 Chat Completions 的精确模型 ID。
7. 保存后发送 `Reply only OK`，再执行一次包含代码上下文的请求。

## 当前边界

- 本指南只覆盖 Inferpal，不代表 Visual Studio 内置 Copilot 或其他扩展支持相同字段。
- 不同版本可能对 Base URL 自动追加路径；若请求失败，请先核对最终请求是否落在 Chat Completions endpoint。
- 在完成固定版本 E2E 前，不承诺所有编辑、补全或工具调用模式均可用。
