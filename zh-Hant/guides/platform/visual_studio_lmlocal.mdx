LMLocal 是面向 Visual Studio 2022/2026 的扩展，官方支持 OpenAI-compatible API 和自定义 Base URL。配置入口随扩展版本可能变化；首次接入请固定版本，并检查真实编辑、工具调用和用量记录。

## 配置

1. 从 Visual Studio Marketplace 或官方仓库安装 LMLocal。
2. 在 Providers 中新增 Custom/OpenAI-compatible Provider。
3. Base URL 填写 `https://api.acedata.cloud/v1`。
4. Auth Key 填写你的 Ace Data Cloud API Token。
5. Model 填写模型目录中支持 Chat Completions 的精确模型 ID。
6. 保存后发送 `Reply only OK`，再测试一次项目编辑流程。

## 当前边界

- 本指南只覆盖 LMLocal，不代表其他 Visual Studio 扩展共享配置。
- 不同版本可能分别处理聊天、编辑、构建与测试请求；各模式需独立验证。
- 如果客户端自动追加 `/v1` 或 endpoint path，请避免重复路径。
