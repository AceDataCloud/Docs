[Ace Data Cloud Studio](https://studio.acedata.cloud) 面向創作者、營運、設計和業務團隊，統一提供 AI 對話、圖像、影片、音樂與自動成片工具。使用者從創作目標出發選擇工作流程，不需要先在多個產品之間反覆註冊、儲值和切換。

![Studio 首頁：從創作目標進入對話、圖像、影片與音樂](https://cdn.acedata.cloud/uploads/34c26779-82a4-4a9b-b81b-fb98ccd525be)

## 適合哪些情境

- **內容創作**：寫作、研究、海報、封面、短影片和配樂；
- **行銷營運**：商品圖、社群媒體素材、活動視覺和品牌內容；
- **設計探索**：參考圖編輯、風格探索、構圖和多版本方案；
- **業務團隊**：用自然語言完成跨模型、多步驟的創作任務；
- **開發者與進階使用者**：在支援的情境中設定 API Key、Connector、Skill 或本機工具。

具體可用能力會隨網站設定、地區、帳號和產品版本變化，以目前頁面實際顯示為準。

## 如何開始

1. 造訪 [studio.acedata.cloud](https://studio.acedata.cloud)；
2. 選擇頁面目前提供的登入方式；
3. 從首頁的創作目標或左側能力導覽進入工具；
4. 閱讀目前服務的價格、參數和內容要求；
5. 先用低成本任務驗證流程，再進行高解析度、長影片或批次生成。

不同服務的計費單位、處理時長和參數不同。提交前應查看目前頁面與使用紀錄，不要依據歷史截圖推算價格。

## 核心工作流程

### AI 對話

用於寫作、分析、學習、程式設計和多模態討論。具體模型、上下文能力和工具支援以目前模型選擇器為準。

### AI 圖像

涵蓋文字生成圖像、參考圖編輯、擴圖、風格轉換和視覺設計。不同圖像服務在尺寸、文字渲染、人物一致性和編輯能力上各有側重。

### AI 影片與自動成片

支援文字、圖片、參考素材或腳本驅動的影片創作。自動成片工作流程可組合腳本、畫面、配音、字幕和音樂；長任務應關注狀態查詢、失敗原因和最終輸出完整性。

### AI 音樂

支援從風格或歌詞生成歌曲，並按頁面提供的能力繼續編輯或擴展。商業使用前應自行核對內容權利和目標平台規則。

### Connector、Skill 與進階工具

部分帳號或網站可使用 Connector、Skill 和本機工具。這些入口受目前產品、權限和執行環境約束，不是所有使用者或白牌網站都預設開放。

## Web、行動版與桌面版

Studio Web 版位於 `studio.acedata.cloud`。行動版和桌面版的能力、網站管理入口可能不同：

- 白牌網站管理只在 Web 版向目前 Site 管理員顯示；
- 原生行動版和桌面版不會展示所有網站營運設定；
- 手機寬度使用底部能力導覽，複雜創作表單更適合桌面瀏覽器。

## 建立自己的品牌分站

如果需要用自己的名稱、Logo、頁面網域、能力目錄和渠道價格經營 Studio，可在官方 Studio Web 版開啟：

**使用者頭像 → 設定 → 我的分站**

建立後，從「我的分站」對目標分站點擊 **管理**，再設定品牌、登入、能力、價格、橫幅、統計和自訂網域。

## 白牌和分銷邊界

- 白牌是共享平台上的 Site 設定，不是獨立部署或獨立資料庫；
- 使用者帳號、餘額、方案和多數資產屬於共享體系；
- 隱藏儲值、能力或服務只是頁面展示控制，不是授權隔離；
- Site 加價是正常白牌購買流程的渠道價格，不是帳號在所有入口的強制租戶價；
- 分銷收益取決於有效訂單、邀請關係、等級、退款和風控，不承諾固定比例、入帳速度或收入數字。

## 使用建議

- 重要事實和生成內容需要人工複核；
- 不要在提示詞、截圖、聊天或工單中洩露密碼、API Key、身分證件或支付資訊；
- 人像、聲音、商標和版權素材應取得必要授權；
- 高成本任務先做小樣，確認參數後再擴大規模；
- 出現異常時記錄時間、服務、狀態碼和可公開請求識別碼，不要提交完整 token。

## 首頁第三方網站的 OAuth 授權

在網站元件設定中開啟 OAuth，並填寫第三方在 ACE Data Cloud 註冊的應用程式 ID 與回呼地址。網站和回呼地址必須使用同一個 HTTPS 來源，與 Studio 來源不同。不要在設定中填寫應用程式密鑰。

第三方頁面需要串接 OAuth 訊息協議。已登入訪客將在元件區域看到官方同意頁；同意後，第三方可透過 OAuth token 讀取該訪客現有的 API Key。未登入或拒絕授權時不會提供 Key。

允許讀取 Key 後，第三方可以儲存並使用它。取消 OAuth 授權不會使已複製的 Key 失效；請另外撤銷或輪換 Key。詳見「串接使用 Ace Data Cloud 登入（OAuth 2.0）」中的 Studio 元件說明。
