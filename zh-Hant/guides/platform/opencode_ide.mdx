---
title: "OpenCode IDE 擴展接入 Ace Data Cloud"

OpenCode 官方 IDE 擴展支持 VS Code、Cursor、Windsurf、VSCodium 等編輯器，並重用 OpenCode 本地 runtime 與 Provider 配置。IDE 擴展重用本地 CLI Provider，但不同編輯器版本的請求鏈可能變化；首次接入請固定版本並完成最小驗證。

## 配置 Provider

先按 [OpenCode Terminal 配置](https://platform.acedata.cloud/documents/opencode-terminal-integration) 在 `opencode.json` 或 `opencode.jsonc` 中配置 Ace Data Cloud Provider：

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## 安裝 IDE 擴展

1. 在編輯器的集成終端中運行 `opencode`，按官方流程自動安裝擴展；也可以從對應 Marketplace 手動安裝。
2. 重新載入編輯器。
3. 從 OpenCode 擴展發起 `Reply only OK`。
4. 再執行一次需要讀取文件或修改代碼的請求，確認 IDE 擴展使用同一 Provider 與模型。

## 當前邊界

- Provider 能力來自 OpenCode runtime，不代表宿主編輯器原生支持 Ace Data Cloud。
- VS Code 與各 fork 的擴展版本可能不同，應分別記錄版本。
- 普通聊天成功不能替代文件讀取、編輯和工具調用驗證。
