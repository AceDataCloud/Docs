Coze 官方支援接入自訂模型，並提供 OpenAI Chat API、OpenAI Responses API 和 Anthropic Messages API 三種協議。三條路線的 Base URL、路徑拼接、Header、streaming 和工具呼叫合約不同，因此必須分別設定和驗證。

| 路線                      | 狀態  | 指南                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | 實驗性 | [Chat 設定](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | 實驗性 | [Responses 設定](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | 實驗性 | [Messages 設定](https://platform.acedata.cloud/documents/coze-messages-integration)   |

「實驗性」表示官方能力和設定入口已確認，但不同 Coze 區域、版本或方案可能顯示不同表單，Ace Data Cloud 仍需依協議完成固定版本驗證。不要將某一條協議成功外推到另外兩條。

## 設定原則

- Base API URL 優先填寫文件提供的 base；不要重複追加用戶端會自動補齊的 endpoint path。
- API Key 使用你的 Ace Data Cloud API Token。
- Model 使用模型目錄中與所選協議相容的精確模型 ID。
- 一般文字成功後，還應驗證 streaming 和工具呼叫。
