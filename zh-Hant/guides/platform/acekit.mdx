你大概也遇過這種情況：手上用著 Claude Code、Cursor 或者 Codex，寫程式寫得正順，突然需要一張配圖、一段背景音樂、一支短影片，或者想讓它順手查一下最新資料。結果發現——agent 本身不會這些。你得自己去找 API、讀文件、配 key、寫呼叫程式碼、處理非同步輪詢，一套折騰下來，靈感早就涼了。

[AceKit](https://github.com/AceDataCloud/AceKit) 就是來省掉這一整套折騰的。一行指令，它把 AceData Cloud 上的生圖、生影片、生音樂、網頁搜尋、LLM 對話等能力，整套裝進你的編碼 agent。裝完之後你直接說人話，agent 會自己載入對應技能、自己鑑權、自己輪詢，把活幹完。

## 30 秒看懂它在幹嘛

裝之前 vs 裝之後：

| 你說的話               | 裝之前                   | 裝之後（agent 自己做）                      |
| ------------------ | --------------------- | ----------------------------------- |
| "給這篇 README 配張封面圖" | agent 不會，讓你自己去找生圖 API | 呼叫 NanoBanana / Flux / Midjourney 出圖 |
| "把這段腳本做成 30 秒短影片"  | 不會                    | 呼叫 Sora / Veo / Kling / Seedance 出片  |
| "給這個 demo 配段背景音樂"  | 不會                    | 呼叫 Suno 出歌                           |
| "搜一下最新的 X 再總結"     | 不會連網                  | 呼叫 Google SERP 拿即時結果                 |
| "把這個長連結縮短"         | 不會                    | 呼叫短連結服務回傳 surl.id 連結                  |

一句話：**你的編碼 agent 從「只會寫程式」，變成「還會生圖、生影片、生音樂、連網搜尋」。**

## 三步上手

整個過程幾分鐘跑通，需要 Node.js 18+。

**第一步 · 拿一個 API Token。** 到 [控制台](https://platform.acedata.cloud/console/applications) 複製 Token——所有能力共用這一個，首次申請送免費額度，可以先免費試。

![在控制台複製 API Token](https://cdn.acedata.cloud/dvc3cg.jpg)

**第二步 · 裝。** 一行指令：

```bash
npx acekit
```

它會自動偵測機器上的編碼 agent 並裝好整套技能。真實執行長這樣（這台機器只裝了 Claude Code）：

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> 沒設 Token 時，首次執行會互動式提示你貼上；也可以提前 `export ACEDATACLOUD_API_TOKEN=你的token` 做到完全無人值守地裝。技能數量會隨平台能力增加而變化，以 `npx acekit list` 顯示的目前清單為準。

**第三步 · 說人話。** 重載一下 agent，然後直接下指令，例如：

```text
用 short-url 技能把 https://platform.acedata.cloud/services 縮短一下
```

agent 會自己載入技能、自己發起呼叫，給你真實可跳轉的結果。

## 真實跑一遍（帶輸出）

下面四個例子全部是**真實呼叫、當場回傳的結果**，不是示意。指令裡的 `$KEY` 就是你的 API Token。

**① 縮短網址（同步，秒回）**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

回傳 `https://surl.id/r/1uKp2kilXQ`——點開會 302 跳轉回原始的 services 頁面。

**② 連網搜尋（同步）**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

拿到即時的 Google 結果（節選）：

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM 對話（同步，一個介面接 50+ 模型）**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句話解釋 MCP"}]}'
```

```text
MCP是用於統一管理和交換模型上下文資訊的協議。
（39 tokens，本次約 0.00007 credit）
```

**④ 生圖（非同步，約 20 秒，agent 自動輪詢到出圖）**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

約 22 秒後回傳一張真實圖片（HTTP 200 · image/png · 317 KB · 本次約 0.13 credit）：

![AceKit 真實生成的圖片](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

這些介面你其實不用記——裝好技能後，agent 會按照各自的 `SKILL.md` 自己拼出正確的請求、處理鑑權和輪詢。上面只是把「它在背後幹的事」攤開給你看。

## 它到底裝了什麼

AceKit 是 AceData 整個開發者工具面的「前門」，目前一次安裝裝的是**技能工具集（Skills）**：

- **一套 Agent 技能**：每個技能是一份寫好的 `SKILL.md` 操作手冊——鑑權、非同步輪詢、錯誤重試、參數怎麼填都寫清楚了，agent 照著做就行。執行 `npx acekit list` 看目前清單（寫這篇時是 19 個，且持續增加）：
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **統一一個 Token**：一個 `ACEDATACLOUD_API_TOKEN` 解鎖全部能力，按實際用量計費。

按能力分類（以 `npx acekit list` 為準）：

| 類型         | 提供方                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ 生成圖片      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 生成影片      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 生成音樂 / 音訊 | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM 對話   | 50+ 模型統一介面（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 搜尋       | Google SERP（網頁 · 圖片 · 新聞 · 地圖 · 影片）                  |
| 🔗 工具       | 短網址 · 人臉處理                                            |

> 同樣這些能力，AceData 也提供獨立的 **MCP 伺服器**（Suno、Midjourney、Sora、SERP… 已發佈到 PyPI / VS Code / Smithery / Docker）、**命令列 CLI** 和 **Python / TypeScript SDK**，可依需求單獨使用。AceKit v0.2 計畫支援 `acekit add <name>` 單一能力安裝，以及自動寫入各 agent 的 MCP 設定。

## 支援哪些 Agent

| Agent                        | 技能安裝位置                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode 等 | `~/.agents/skills`（讓你的 agent 指向這裡） |

安裝時 AceKit 自動偵測機器上已安裝的 agent，只會安裝到偵測到的那幾個中。

## 額外驚喜：用同一個 Token 驅動 Claude Code 本身

AceData 的介面同時相容 Anthropic 的 `/v1/messages` 格式，所以你**不需要 Anthropic 官方訂閱**，用同一個 AceData Token 就能驅動 Claude Code。在專案根目錄建立 `.claude/settings.local.json`：

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

重新啟動 Claude Code 即可——它既用上了 Claude 全系列模型，又透過 AceKit 擁有了生成圖片、生成影片、生成音樂的「手」。更多細節請見 [Claude Code 整合指南](https://platform.acedata.cloud/documents/claude-code-integration)。
