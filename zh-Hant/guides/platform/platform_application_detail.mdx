透過 Application ID 取得單一服務申請的完整狀態——比列表介面多出 `service` 完整物件（含 `packages` 方案）等欄位，適用於詳情頁面。

> ℹ️ 本介面屬於 **AceDataCloud 平台管理 API**，統一前綴 `https://platform.acedata.cloud/api/v1/`。完整介面索引請見[取得 AceDataCloud 平台文件列表](https://platform.acedata.cloud/documents/platform-document-list)。

## 介面概覽

| 項   | 內容                                                                    |
| --- | --------------------------------------------------------------------- |
| 方法  | `GET`                                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/{application_id}` |
| 驗證  | ✅ 需要帳戶權杖                                                              |

`/applications/{id}` 與 `/applications/{id}/` 目前皆可用；範例統一使用無結尾斜線形式。

## 驗證說明（如何取得帳戶權杖）

請求標頭：

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

詳細取得方式請見[管理 AceDataCloud 平台帳戶權杖](https://platform.acedata.cloud/documents/platform-token)。

> ℹ️ 與列表介面不同，**詳情介面的權限驗證是直接針對單一物件進行**，無需傳送 `?user_id=`。但你存取他人的申請會得到 `403 permission_denied`。

## 路徑參數

| 參數               | 類型   | 必填  | 說明             |
| ---------------- | ---- | --- | -------------- |
| `application_id` | UUID | ✅   | Application ID |

## 請求範例

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/applications/82f57141-2323-4453-8730-60f7d833a2da' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

app_id = "82f57141-2323-4453-8730-60f7d833a2da"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/applications/{app_id}",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
app = resp.json()
print(f"服务：{app['service']['title']}")
print(f"剩余 {app['remaining_amount']} {app['service']['unit']} / 已用 {app['used_amount']}")
```

### Node.js

```javascript
const appId = '82f57141-2323-4453-8730-60f7d833a2da'
const r = await fetch(`https://platform.acedata.cloud/api/v1/applications/${appId}`, {
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log(await r.json())
```

## 回應欄位說明

欄位含義同[列表介面](https://platform.acedata.cloud/documents/platform-application-list)，額外包含：

| 欄位        | 類型     | 說明                                                        |
| --------- | ------ | --------------------------------------------------------- |
| `service` | object | 完整的服務物件（含 `packages` 方案、`unit`、`free_amount`），可直接呈現服務詳情面板 |

## 錯誤處理

| HTTP | code                | 含義                  |
| ---- | ------------------- | ------------------- |
| 401  | `not_authenticated` | 缺少帳戶權杖              |
| 403  | `permission_denied` | 該 Application 不屬於你  |
| 404  | `not_found`         | Application 不存在或已刪除 |

## 實用提示

- **批次監控優先使用列表**：一次取得 Application 列表後依各服務的單位和閾值判斷，避免逐一請求詳情。
- **需要查看憑證數量時**：使用[API 憑證列表](https://platform.acedata.cloud/documents/platform-credential-list)依 `application_id` 篩選。
- **`disabled=true` 排查思路**：檢查工單 / 電子郵件通知，確認是否因風控、欠費、違規呼叫被停用；無法透過 API 解除，必須聯絡客服。
