透過服務 ID（UUID）或別名（alias）取得單一服務的完整資訊——比[取得 AceDataCloud 平台服務列表](https://platform.acedata.cloud/documents/platform-service-list) 回傳的欄位更完整，會額外展開 `apis`、`proxies`、`datasets`、`packages` 等關聯物件。適用於服務詳情頁、定價對照頁、Agent 工具描述等情境。

> ℹ️ 本介面屬於 **AceDataCloud 平台管理 API**，統一前綴 `https://platform.acedata.cloud/api/v1/`。完整介面索引見[取得 AceDataCloud 平台文件列表](https://platform.acedata.cloud/documents/platform-document-list)。

## 介面概覽

| 項   | 內容                                                            |
| --- | ------------------------------------------------------------- |
| 方法  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| 驗證  | ❌ 公開                                                          |

`/services/{id}` 與 `/services/{id}/` 目前皆可使用；範例統一使用無結尾斜線形式。

## 驗證說明

本介面完全公開。**但是帶上帳戶權杖後，回應中的 `applied` 欄位會反映目前帳戶的實際申請狀態**，否則固定為 `false`。

帳戶權杖的取得方式見[管理 AceDataCloud 平台帳戶權杖](https://platform.acedata.cloud/documents/platform-token)。

## 路徑參數

| 參數           | 類型            | 必填  | 說明                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | 服務 ID（UUID）或別名（`midjourney`、`openai`、`webextrator` 等） |

## 請求範例

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## 回應欄位說明

詳情介面在[列表介面](https://platform.acedata.cloud/documents/platform-service-list)的所有欄位之上，額外展開了：

| 欄位         | 類型    | 說明                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | 關聯 API 物件的完整列表（每筆含 `id`、`name`、`title`、`path`、`stage`、`cost`） |
| `proxies`  | array | 關聯 Proxy 物件的完整列表                                              |
| `datasets` | array | 關聯資料集（如果 `type=Dataset`）                                      |
| `packages` | array | 套餐列表，含 `type`（`Usage`/`Period`）、`price`、`amount`、`duration`   |

其餘欄位定義參見[取得 AceDataCloud 平台服務列表 → 回應欄位說明](https://platform.acedata.cloud/documents/platform-service-list)。

## 錯誤處理

| HTTP | code        | 含義                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id`（UUID 或 alias）不存在 |
| 500  | —           | 通常是 URL 結尾誤加斜線，移除後重試          |

## 實用提示

- **`alias` > `UUID`**：將 `alias`（如 `midjourney`）硬編碼到程式碼中更穩定；UUID 在遷移環境時會變動。
- **`apis` 欄位不包含 OpenAPI 定義**：完整的 OpenAPI 3.0 Schema 在[取得 AceDataCloud 平台 API 詳情](https://platform.acedata.cloud/documents/platform-api-detail) 介面中。
- **取得一個服務的「完整能力」**：使用本介面取得 `api_ids`，然後逐一呼叫 `/apis/{api_id}` 取得詳情。
- **如果 `applied=true`**，就可以直接[建立 API 憑證](https://platform.acedata.cloud/documents/platform-credential-create) 取得呼叫業務介面所需的 32 位 Token，不需要再申請。
