持有 $ACE 並驗證您的 Solana 錢包後，可在 Ace Data Cloud **支援該權益的 Credits API 服務**中獲得呼叫折扣。$ACE 始終保留在您的錢包中；平台只讀取鏈上餘額，不會託管、鎖定、轉移或消耗代幣。

> $ACE 不是平台儲值餘額，也不是支付授權或質押產品。折扣僅適用於頁面列出的 Credits API 服務，不適用於儲值訂單、x402 USDC 支付或其他非 Credits 消費路徑。

## $ACE 是什麼

$ACE 是部署在 Solana 主網上的 Ace Data Cloud 生態代幣。目前已上線的用途是持有權益：錢包中的 $ACE 餘額達到對應門檻後，平台會為支援的 API 服務自動套用折扣。

## 第一步：購買 $ACE

購買 $ACE **不需要先在平台綁定錢包**。您只需要準備：

- 一個 Solana 主網錢包，例如 Phantom 或 Solflare；
- 可用於兌換的 SOL、USDC 或頁面實際支援的其他資產；
- 少量 SOL，用於支付 Solana 網路費。

平台不會要求您提供助記詞或私鑰。任何要求您提交助記詞、私鑰或遠端控制錢包的頁面都不是正常流程。

### 1. 從平台提供的正確入口進入

開啟 [$ACE 持有權益頁面](https://platform.acedata.cloud/console/coin)，在第一步卡片中核對完整 Mint 並點擊「購買 $ACE」；也可以直接開啟：

[在 Jupiter 查看並兌換 $ACE](https://jup.ag/tokens/GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump)

該連結已經包含目前官方 Mint。不要只透過搜尋代幣簡稱選擇結果。

### 2. 連接您的 Solana 錢包

在兌換頁面連接準備好的錢包，並確認目前網路是 Solana 主網。首次使用錢包時，請先了解錢包自身的安全提示和交易確認介面。

### 3. 選擇用於兌換的資產和數量

選擇 SOL、USDC 或頁面實際支援的其他資產作為支付資產，輸入希望兌換的數量。確認頁面顯示的目標代幣 Mint 與下列地址完全一致：

```text
GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump
```

### 4. 核對兌換資訊

提交前檢查：

- 預計獲得的 $ACE 數量；
- 匯率、價格影響和最少收到數量；
- 網路費和其他頁面列出的費用；
- 錢包彈窗中的實際交易內容。

鏈上兌換價格和流動性會變化。平台不承諾成交價格、可成交數量或代幣價值；請只在理解交易內容並能承擔風險時自行確認。

### 5. 在錢包中確認

確認後等待 Solana 網路完成交易，再回到錢包查看 $ACE 餘額。不要關閉或重新整理仍在等待錢包確認的彈窗，除非錢包明確提示交易失敗或已取消。

## 第二步：購買後連接並驗證錢包

購買完成後，再回到平台連接和驗證錢包。購買前不需要綁定；購買本身也不會自動綁定帳戶。請使用**持有 $ACE 的同一個錢包**完成以下操作：

1. 返回 [$ACE 持有權益頁面](https://platform.acedata.cloud/console/coin)；
2. 點擊「連接錢包」，選擇剛才使用的錢包；
3. 點擊「驗證並綁定」；
4. 在錢包中簽署平台展示的所有權驗證訊息；
5. 等待平台同步 finalized 鏈上餘額。

所有權驗證簽名只證明您控制該錢包，**不會授權支付或轉移代幣**。正常流程簽署的是可讀訊息，不會要求您向未知地址轉帳。

驗證成功後，頁面會顯示錢包縮略地址、$ACE 餘額、最後同步時間和目前適用折扣。鏈上交易完成與平台餘額同步之間可能存在延遲，因此購買完成後折扣不一定立即顯示。

折扣依服務設定。請以持有權益頁面中的「支援 ACE 權益的服務」清單及各服務目前顯示的折扣為準，不應理解為涵蓋平台上的全部服務。

餘額由後台任務讀取 Solana finalized 狀態。Coin 類型折扣帶有效期：

- 成功同步後，符合門檻的折扣會自動套用；
- 暫時同步失敗時，頁面會提示餘額狀態異常；
- 超過有效期仍無法重新整理時，計費鏈路會暫停過期折扣；
- 錢包餘額降低或賣出 $ACE 後，下一次成功同步會按新的餘額重新計算權益。

## 常見問題

### 為什麼買完以後平台餘額仍為 0？

先確認交易已在 Solana 主網完成，並確認綁定的是持有 $ACE 的同一個錢包。平台讀取 finalized 鏈上狀態，交易確認與後台同步都可能帶來短暫延遲。如果頁面持續提示同步異常，請稍後重試或聯絡支援團隊。

### 為什麼無法簽署驗證訊息？

目前首選流程要求錢包支援 `signMessage`。請更新錢包版本，或改用支援訊息簽名的 Solana 錢包。不要透過轉帳或提交私鑰來繞過驗證。

### 連接了錯誤的錢包怎麼辦？

瀏覽器中的「中斷錢包連線」只會中斷目前瀏覽器連線，不會修改平台綁定。若要更換權益錢包，請在持有權益頁面點擊「解除錢包綁定」，確認撤銷目前 ACE 折扣後，再連接並驗證新錢包。

### 錢包簽名會轉走我的資產嗎？

不會。綁定流程簽署的是所有權驗證訊息，不是代幣轉帳或付款授權。簽名前仍應核對錢包顯示的訊息內容；如出現交易、轉帳或陌生授權請求，請拒絕。

### 購買多少 $ACE 才有折扣？

目前第一檔門檻是 100,000 $ACE，對支援的 Credits API 服務提供 1% 折扣。各檔位見上表，實際適用服務和目前折扣以持有權益頁面為準。

### 哪些服務支援 $ACE 權益？

請查看持有權益頁面的「支援 ACE 權益的服務」區域。儲值訂單、x402 USDC 付款和非 Credits 消費路徑不使用該折扣。

### 賣出或轉出 $ACE 後會怎樣？

權益按鏈上餘額計算。餘額下降後，下一次成功同步會降低或撤銷相應折扣；陳舊折扣也有有效期，不會無限保留。

### 無法存取舊錢包怎麼辦？

登入您的平台帳戶，在持有權益頁面點擊「解除錢包綁定」並確認即可。解除綁定只會撤銷平台中的錢包關聯和 ACE 折扣，不會轉移、銷毀或操作錢包內的任何資產；完成後可以連接並驗證新錢包。
