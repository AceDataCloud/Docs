OpenCode 的 Coding Plan 模型 Provider、IDE Extension 與 MCP 是三項獨立能力。IDE Extension 連接本機 OpenCode runtime，並重複使用同一份 Provider 設定；它不代表宿主編輯器原生支援 Ace Data Cloud。

| 路線                            | 說明                                                      | 連結                                                                                    | 狀態      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | 使用 `opencode.json[c]` 和 Chat Completions                | [Provider 設定](https://platform.acedata.cloud/documents/opencode-terminal-integration) | 已驗證設定合約 |
| IDE Extension                 | VS Code、Cursor、Windsurf、VSCodium 等宿主連接 OpenCode runtime | [IDE 設定](https://platform.acedata.cloud/documents/opencode-ide-integration)           | 實驗性     |
| MCP                           | 在 OpenCode 內呼叫遠端工具                                      | [MCP 總覽](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | 獨立能力    |

Provider 設定成功後，IDE Extension 應使用相同的 Provider 與模型。仍需分別驗證 IDE 內聊天、檔案讀取、編輯與工具呼叫，不應把 CLI 的一次普通請求自動外推為全部 IDE 能力。

模型 ID 以 [即時目錄](https://platform.acedata.cloud/models) 為準。
