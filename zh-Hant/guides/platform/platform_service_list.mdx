title: "取得 AceDataCloud 平台服務列表"

分頁回傳目前站點可見的 Service 目錄，包括服務類型、展示資訊、免費額度、套餐和關聯 API/Proxy ID。適合建構服務市場或選擇待申請服務。

## 介面概覽

| 項   | 內容                                                |
| --- | ------------------------------------------------- |
| 方法  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| 鑑權  | 公開；帶登入態時 `applied` 才反映目前帳戶                        |
| 分頁  | `count` + `items`                                 |

## 查詢參數

| 參數               | 類型      | 必填  | 說明                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | 否   | 按服務 ID 篩選；支援重複參數         |
| `private`        | boolean | 否   | 按公開狀態篩選；站點可見性規則仍然生效      |
| `type`           | string  | 否   | 服務類型；支援重複參數              |
| `tag`            | string  | 否   | 按標籤篩選                    |
| `include_facets` | boolean | 否   | `true` 時附加目前站點可用的類型/標籤統計 |
| `limit`          | integer | 否   | 每頁筆數，最大 100              |
| `offset`         | integer | 否   | 分頁偏移量                    |
| `ordering`       | string  | 否   | 僅支援 `rank` 或 `-rank`     |

列表不支援 `alias` 篩選；已有 alias 時直接請求 `/api/v1/services/{alias}`。`applied_count`、`updated_at` 不是允許的排序欄位。

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## 回應說明

回應為 `{count, items}`；僅在 `include_facets=true` 時增加 `facets`。服務項目包含 `id`、`alias`、`title`、`description`、`type`、`applied_count`、`free_amount`、`unit`、`private`、`need_verify`、`rank`、`tags`、`thumbnail`、`doc_url`、`demo_url`、`api_ids`、`proxy_ids`、`cost`、`packages` 等目前公開欄位。

`applied` 在匿名列表中不代表某個帳戶的申請狀態。需要帳戶相關狀態時應帶有效登入態，並以[服務申請列表](https://platform.acedata.cloud/documents/platform-application-list)為最終依據。
