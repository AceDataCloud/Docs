`POST https://api.acedata.cloud/webextrator/extract`

WebExtrator 智慧擷取 API 將一個 URL 轉換為**具型別的結構化結果**——文章、商品、
食譜、影片、討論、職缺等，同時附帶清理後的 Markdown 與純文字。當你想要「乾淨的結
構化資料」而不是原始 HTML 時，這就是應使用的介面。

## 申請流程

要使用 WebExtrator 服務頁，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[WebExtrator 服務頁 →](https://platform.acedata.cloud/service/webextrator)

## 鑑權

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## 請求參數

Extract 接受**所有**[Render API](/zh-Hant/guides/webextrator/webextrator_render) 的參數
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`），另加兩個 Extract 專屬欄位：

| 欄位 | 類型 | 必填 | 預設值 | 說明 |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | 自動判斷 | 頁面類型提示：`product` / `article` / `general`。指定預期的結果類型。 |
| `enable_llm` | boolean | ❌ | `false` | 當 schema.org 未命中時，允許呼叫 LLM 進行擷取。在 Amazon / HN / Greenhouse 這類沒有 JSON-LD 的頁面上，必須啟用才能取得類型化結果。 |

### 頂層欄位

| 欄位 | 類型 | 說明 |
|------|------|------|
| `kind` | string | 固定為 `"extract"`。 |
| `url` | string | 您提交的 URL。 |
| `finalUrl` | string | 重新導向後的最終 URL。 |
| `contentType` | enum | 頁面類型：`product` / `article` / `general`。 |
| `title` | string | 頁面標題。 |
| `description` | string? | 頁面描述或摘要。 |
| `byline` | string? | 作者、頻道或公司。 |
| `language` | string? | `<html lang>`。 |
| `siteName` | string? | `og:site_name`。 |
| `publishedAt` | string? | 發布時間，使用 ISO 8601 格式。 |
| `images` | string[] | 最多 50 個 `<img src />`，已解析為絕對 URL、去除重複，並捨棄 `data:` URI。 |
| `links` | string[] | 最多 100 個外部連結，已過濾片段 / `javascript:` / `mailto:` / `tel:`。 |
| `markdown` | string | 頁面的 Markdown 內容。 |
| `text` | string | 頁面純文字。 |
| `structured` | object | 完整的結構化結果，請見下方。 |
| `rawSignals` | object | 供偵錯使用的診斷資訊。 |
| `cached` | boolean? | 命中快取時為 `true`。 |
| `cacheStoredAt` | number? | 快取項目首次寫入時的 Unix 毫秒時間戳記。 |

### `data.structured` 子欄位

| 子欄位 | 出現時機 | 說明 |
|--------|---------|------|
| `schemaOrg` | 一律 | `{ primary, breadcrumbs, all }`。`primary` 是最高優先順序的類型化實體；找不到時為 `null`。 |
| `openGraph` | 一律 | `{ title, description, image, type }`，取自 `<meta property="og:*" />`。 |
| `jsonLd` | 一律 | 所有 `<script type="application/ld+json">` 區塊的原始 JSON 陣列。 |
| `llm` | LLM 已執行且成功時 | `{ kind, data, model, promptCharCount }`，類型化結果。 |
| `llmError` | LLM 已執行但失敗時 | `{ kind, error, model }`，請求仍可傳回其他已擷取欄位。 |
| `amazon` | URL 為 `amazon.*` 時 | 舊版 Amazon 擴充功能結果；新整合請使用類型化結果。 |

## schema.org 結果類型

`structured.schemaOrg.primary` 支援以下結果類型：

| schema.org 類型 | kind | 輸出欄位 |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event`（含 `*Event`） | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | （掛載於 sibling） | 一律輸出至 `structured.schemaOrg.breadcrumbs[]`，不會作為 primary。 |

## LLM 結果類型

當 `enable_llm: true` 且頁面沒有可用的 schema.org 結構化資料時，可傳回以下類型的擷取結果：

| Kind | 必填欄位 | 選填欄位 |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## 快取

相同的 URL、請求參數、`cookies` 和 `headers` 可以重複使用快取結果；`async`、`bypass_cache`、`cache_ttl_seconds` 用於控制執行方式和快取行為。

| 欄位 | 效果 |
|------|------|
| `bypass_cache: true` | 跳過讀取；本次結果仍會寫回快取，下次相同請求可命中。 |
| `cache_ttl_seconds: 0` | 本次回應**不會快取**。 |
| `cache_ttl_seconds: N` | 自訂此項目的 TTL（預設為 3600 秒）。 |

命中快取的回應會附帶 `data.cached: true` 與 `data.cacheStoredAt: <unix-ms>`。

## 异步模式与回调

设置 `async: true` 进入异步模式（提供 `callback_url` 也会自动进入）。平台立即返回（HTTP 200）：

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

任务完成时把完整 envelope `POST` 到你的 `callback_url`（如果配置了）。也可以事
后通过 [`/webextrator/tasks`](/zh-Hant/guides/webextrator/webextrator_tasks) 主动查询。

```bash

  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://en.wikipedia.org/wiki/Diffbot",
```

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "article",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "article":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, '種配料');
```

## 提示與注意事項

- **需要指定頁面類型時傳入 `expected_type`。** 例如文章頁使用 `article`，商品頁使用 `product`。
- **`enable_llm: true` 在命中 schema.org 的頁面上是免費的。** LLM 僅在 schema.org
  沒有 primary 時才會被呼叫，因此預設開啟也很安全。
- **偵錯時先查看 `rawSignals.hasJsonLd`。** 如果為 `true`，但 `structured.schemaOrg.primary`
  為 `null`，表示頁面的 `@type` 暫不支援，歡迎向我們回報。
- **`structured.llmError` 僅供參考。** 請求仍可能成功回傳其他已擷取欄位。查看
  `llmError.error` 以定位原因（逾時、JSON 解析失敗、結構驗證失敗）。
- **非文章頁的 `links[]` 不會依相關性排序。** 僅依「上限 100 筆 + 過濾無效通訊協定」
  盡力清理。
- **命中快取仍會計費。**
