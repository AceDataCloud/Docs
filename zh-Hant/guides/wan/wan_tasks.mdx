`POST https://api.acedata.cloud/wan/tasks` 用於查詢、批量查詢或刪除 Wan 視頻任務。任務查詢不重複收取生成費用。

## 查詢單個任務

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

完成任務的 `response.data.video_url` 為永久 CDN 地址；`response.usage` 包含解析度、輸入/輸出視頻秒數、幀率和比例；`response.cost` 為生成任務結算。

## 批量查詢

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

返回 `{ "items": [...], "count": 2 }`。任務進行中時可能尚無 `finished_at` 和最終 `response`。

## 刪除任務記錄

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

刪除只影響任務歷史記錄，不會刪除已生成的 CDN 視頻。
