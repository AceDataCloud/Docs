`POST https://api.acedata.cloud/wan/videos` 同時支持現有 Wan 2.6 模型和 `wan3.0-video`。Wan 3 根據 `media` 自動識別文本、首尾幀或參考素材模式。

## Wan 3 文生視頻

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "一艘紙船在夜晚的霓虹城市中漂流",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 支持 2–30 秒整數或 `-1` 智能時長，分辨率為 `480P`、`720P`、`1080P`。

## 多媒體參考

```json
{
  "model": "wan3.0-video",
  "prompt": "創建一個電影風格的產品揭示",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` 支持：

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

首尾幀模式和參考素材模式不能混用。參考視頻最終按真實輸入視頻秒數加成功輸出視頻秒數結算；文本、圖片和音頻輸入不增加視頻秒數。

| 480P  | $0.05/秒 |
| 720P  | $0.10/秒 |

## Wan 2.6 兼容

現有 `wan2.6-t2v`、`wan2.6-i2v`、`wan2.6-r2v` 與 flash 變體繼續使用 `action`、`image_url`、`reference_video_urls` 等參數，調用路徑不變。

## 異步與結果

設置 `async: true` 後立即獲得 `task_id`，通過 `/wan/tasks` 獲取終態。成功視頻會轉存至 AceDataCloud CDN，並在響應中返回真實 usage 與 cost。
