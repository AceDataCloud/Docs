---
title: "Qwen Image 圖片 API 集成指南"
description: "Qwen Image 3 整合指南 - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` 支援 `qwen-image-3.0` 與 `qwen-image-3.0-pro` 的文生圖和 1–3 張參考圖編輯。

## 文生圖

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"一張極簡科技海報","size":"1024*1024","n":1}'
```

## 圖像編輯

在相同請求中增加 `image_urls`，支援 1–3 張公網圖片：

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主體，改成暖**###**海報風格",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` 僅支援文生圖。`n` 範圍為 1–6。輸出尺寸總像素需在 512×512 至 2048×2048 之間，寬高比為 1:8 至 8:1。

## 非同步調用

設置 `async: true` 可立即獲得 `task_id`；也可傳入 `callback_url` 接收最終結果。完成後通過 `/qwen-image/tasks` 查詢。

成功響應包含 `data[].image_url`、`usage`、`task_id` 和 `trace_id`。圖片鏈接會儘可能轉存到 Ace Data Cloud CDN。真實響應範例將在生產 E2E 驗證後補充。
