---
title: "Qwen Image 任務查詢 API"
description: "Qwen Image 整合指南 - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks` 用於查詢、批量查詢或刪除 Qwen Image 非同步任務。該介面不產生額外 API 消耗。

## 查詢單個任務

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

任務完成後，`response.data` 包含永久 CDN 圖片地址，`response.usage` 包含真實輸入/輸出數量，`response.cost` 為生成任務的結算資訊。

## 批量查詢

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

返回 `{ "items": [...], "count": 2 }`。列表查詢還支持按用戶、應用和創建時間範圍篩選。

## 刪除任務記錄

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

刪除只影響任務歷史記錄，不會刪除已生成的 CDN 檔案。
