title: "Qwen Image 任務 API 整合指南"
description: "Qwen Image 3 整合指南 - Ace Data Cloud"
---

使用 `POST https://api.acedata.cloud/qwen-image/tasks` 查詢異步圖片生成任務。該查詢介面免費。

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

批量查詢使用 `action=retrieve_batch` 和 `ids` 陣列。任務成功後，`response.data` 中包含生成圖片的永久地址及實際使用情況。
