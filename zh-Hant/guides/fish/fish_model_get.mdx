本接口基於 [Fish Audio 官方 Model API](https://docs.fish.audio/resources/api-reference/model)，用於**按 `_id` 查詢單個克隆音色的完整詳情**。地址為 `GET https://api.acedata.cloud/fish/model/{id}`。

> 創建音色請參考 [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)；分頁檢索請參考 [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)。

## 申請流程

要使用 Fish Model API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[Fish Model API →](https://platform.acedata.cloud/services/fish)

## 路徑參數

| 參數   | 必填  | 說明                                                                                                                                                                                                |
| ---- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id` | 是   | 音色的 `_id`（32 位十六進制字符串）。可通過 [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) 創建時返回，或通過 [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) 檢索得到。 |

無請求體、無查詢參數。

  -H 'authorization: Bearer {token}'

拿到的 `_id` 直接喂給 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) 的 `reference_id` 即可合成相同音色的語音：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "兄弟們，今天是個好日子。",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## 與列表接口的差異

| 欄位                                                 | `GET /fish/model`（列表） | `GET /fish/model/{id}`（詳情） |
| -------------------------------------------------- | --------------------- | -------------------------- |
| `samples[].audio`                                  | 短期 R2 快取 URL          | 現簽的 R2 直鏈（含 query 簽名）      |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | 同樣存在                  | 同樣存在                       |
| `default_text` / `lock_visibility`                 | 同樣存在                  | 同樣存在                       |

如果只是要試聽一下，列表接口裡的 `samples[].audio` 已經夠用；要更穩定的下載鏈接，建議改用本接口。

## 響應欄位（節選）

| 欄位            | 類型       | 說明                                          |
| ------------- | -------- | ------------------------------------------- |
| `_id`         | string   | 音色 ID（用於 `/fish/tts` 的 `reference_id`）。     |
| `type`        | string   | 模型類型，通常為 `tts`。                             |
| `title`       | string   | 音色名稱。                                       |
| `description` | string   | 長描述。                                        |
| `state`       | string   | 訓練狀態：`trained` 表示可用，`training` 表示還在訓練。      |
| `tags`        | string[] | 公共庫標籤。                                      |
| `samples`     | object[] | 預置樣本，含 `title`、`text`、`task_id`、`audio` 直鏈。 |
| `languages`   | string[] | 音色擅長的語種代碼。                                  |
| `visibility`  | string   | `public` 或 `private`。                       |
| `like_count`  | integer  | 公共庫點讚數。                                     |
| `task_count`  | integer  | 歷史合成次數（可用於人氣排序參考）。                          |
| `author`      | object   | 上游作者信息：`_id` / `nickname` / `avatar`。       |
| `created_at`  | string   | ISO 8601 創建時間。                              |
| `updated_at`  | string   | ISO 8601 最近更新时间。                            |

## 計費說明

本接口不計費——按 ID 查詢單個音色詳情是免費操作。創建音色（[Fish Model Create](https://platform.acedata.cloud/documents/fish-model)）同樣免費，費用僅在調用 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) 合成語音時按用量產生。

## 錯誤處理
- `400 token_mismatched`：路徑中的 `id` 不是合法格式，或上游報「Model not found」。
- `401 invalid_token`：鑑權 token 不存在或無效。
- `404 not_found`：指定 `_id` 在 Fish 上游不可見（音色被刪除、私密、或屬於其他帳號）。
- `429 too_many_requests`：觸發帳號速率限制。
- `500 api_error`：伺服器內部錯誤。

實際請求一個不存在的 ID 時上游會直接返回 `400 Model not found`（實測）：

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

返回：

```json
{
  "status": 400,
  "message": "Model not found"
}
```

錯誤響應示例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 結論

知道音色 `_id` 時直接用本介面拿完整 ModelEntity，最常見的用法是：(1) 試聽 `samples[].audio`，(2) 把 `_id` 餵給 `/fish/tts` 的 `reference_id` 完成合成。如果只有標題或標籤，請先用 [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) 檢索。
