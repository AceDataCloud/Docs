本介面提供文字轉語音、已儲存聲音呼叫和一次性即時聲音複製，地址為 `POST https://api.acedata.cloud/fish/tts`。

## 申請流程

要使用 Fish TTS API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請你註冊和登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[Fish TTS API →](https://platform.acedata.cloud/services/fish)

## 請求標頭

| Header          | 必填  | 說明                                                                                                     |
| --------------- | --- | ------------------------------------------------------------------------------------------------------ |
| `authorization` | 是   | `Bearer {token}`，`{token}` 是在本平台申請的金鑰。                                                                 |
| `content-type`  | 是   | `application/json`。                                                                                    |
| `accept`        | 否   | `application/json`。                                                                                    |
| `model`         | 否   | TTS 模型，可選 `s1`、`s2-pro` 或 `s2.1-pro`，預設 `s2-pro`。`s2.1-pro` 為最新一代，`s2-pro` 表現力強；`s1` 更穩定，長文字不易跑偏。三者同價。 |

## 請求體欄位

| 欄位             | 類型                 | 必填  | 說明                                                                                                                                                                                                     |
| -------------- | ------------------ | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `text`         | string             | 是   | 要合成的文字，非空字串。                                                                                                                                                                                          |
| `format`       | string             | 否   | 輸出音訊格式，可選 `mp3`（預設）、`wav`、`pcm`。`wav` 與 `pcm` 返回的都是 WAV 容器。`opus` 不受支援，傳入會直接返回 `400`。                                                                                                                  |
| `reference_id` | string \| string[] | 否   | 已儲存或公共聲音的模型 ID，可由 [Fish Model API](https://platform.acedata.cloud/documents/fish-model) 建立，或在 [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) 中檢索。不能與 `references` 同時使用。 |
| `references`   | object[]           | 否   | 一次性即時聲音複製，僅支援一個 `{audio, text}` 樣本：`audio` 是公開 HTTPS MP3/WAV URL，`text` 是音訊的準確逐字稿。不能與 `reference_id` 同時使用。                                                                                             |
| `sample_rate`  | integer            | 否   | 取樣率，常用 `16000`、`22050`、`44100`。`format=mp3` 預設 44100。                                                                                                                                                  |
| `mp3_bitrate`  | integer            | 否   | MP3 位元率，可選 `64`、`128`、`192`。僅 `format=mp3` 生效。                                                                                                                                                          |
| `prosody`      | object             | 否   | 韻律覆蓋，支援 `speed`（語速，1.0 為原速）和 `volume`（音量增益 dB）。例如 `{"speed":1.2,"volume":0}`。                                                                                                                          |
| `chunk_length` | integer            | 否   | 上游分片長度，預設由上游決定。                                                                                                                                                                                         |
| `temperature`  | number             | 否   | 取樣溫度，範圍約 0.0–1.0。                                                                                                                                                                                      |
| `top_p`        | number             | 否   | top-p 取樣參數。                                                                                                                                                                                            |
| `latency`      | string             | 否   | `normal` 或 `balanced`，缺省由本介面自動補 `normal`（直接傳空字串上游會拒絕）。                                                                                                                                                |
| `normalize`    | boolean            | 否   | 是否對文字做正規化。                                                                                                                                                                                             |
| `callback_url` | string             | 否   | 非同步回呼地址，詳見下文「非同步回呼」。**這是相對官方介面的擴充**。                                                                                                                                                                     |

> 一次性複製只接受 HTTPS 音訊 URL，不接受 MessagePack、Base64、data URI 或帶憑據的 URL。參考音訊建議 10–270 秒；Studio 使用更保守的 10–60 秒範圍。

## 範例 1：最小請求（`text` + `format=mp3`）

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hello world.",
    "format": "mp3"
  }'
```

返回（實測）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/e2ffcc06-18da-4a8c-b9aa-9337d0f9ec1d-230825dfc559.mp3"
}
```

`audio_url` 指向本平台 CDN，可直接 GET 下載或在 `<audio>` 中播放。最終成功回應還會返回頂層 `cost`，其中 `amount` 是本次實際扣除的 Credits；如有帳戶折扣，`list_amount` 表示折扣前額度。連結長期可用，但仍建議在你自己的儲存裡留一份。

## 範例 2：使用複製音色 `reference_id`

下面用 Fish 平台上一個公開的西班牙語音色（`_id` 可透過 [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) 檢索取得）：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

返回（實測）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/b6f161f2-a100-4818-add2-47694f234659-6532864739de.mp3"
}
```

## 範例 3：一次性即時聲音複製（`references`）

將參考音訊放在公開 HTTPS 地址，並提供其中實際說出的準確原文。該聲音只用於本次合成，不會建立長期模型：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s2-pro' \
  -d '{
    "text": "新的旅程从这一刻开始，让我们一起向前。",
    "format": "mp3",
    "references": [{
      "audio": "https://cdn.acedata.cloud/assets/examples/fish/6220d605-39d0-4d43-9e58-0f12949dc9b9-570cfdf96ad9.mp3",
      "text": "春天的清晨，阳光穿过树叶，落在安静的小路上。"
    }]
  }'
```
實測成功回應：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/995dfe37-b187-474d-8323-b08d6678ed8f-6359be9f8873.mp3",
  "cost": {"amount": 0.007609319999999999, "currency": "credit"}
}
```

| 方式             | 生命週期       | 適用情境                          |
| -------------- | ---------- | ----------------------------- |
| `references`   | 僅本次 TTS 請求 | 臨時使用或每次聲音不同                   |
| `reference_id` | 可重複使用      | 公共聲音或透過 `/fish/model` 建立的長期聲音 |

## 範例 3：調節語速 / 音量（`prosody`）

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Faster speech with prosody overrides.",
    "prosody": { "speed": 1.2, "volume": 0 },
    "format": "mp3"
  }'
```

回傳（實測）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
}
```

`speed` 大於 1 加快，小於 1 減慢；`volume` 單位 dB，0 表示不變，正數增益，負數衰減。

## 範例 5：切換模型 + 控制位元率

透過 HTTP 標頭 `model: s1` 切換至穩定型模型，請求主體中加上 `mp3_bitrate: 128` 控制 MP3 位元率：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -H 'model: s1' \
  -d '{
    "text": "high bitrate mp3",
    "format": "mp3",
    "mp3_bitrate": 128
  }'
```

回傳（實測）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/7e7abf3d-3d72-4c9f-8eb6-8af932d7c96e-6f11bf2f30e9.mp3"
}
```

## 範例 6：PCM 原始波形

需要在瀏覽器中進行即時拼接，或在用戶端進行後續處理（混音、變速）的情境，建議使用 `pcm`：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "hi",
    "format": "pcm",
    "sample_rate": 16000
  }'
```

回傳（實測）：

```json
{
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
}
```

> 連結的副檔名會跟隨請求中的 `format`：`mp3` 得到 `.mp3`，`wav` 與 `pcm` 得到 `.wav`（WAV 容器，16 bit PCM）。

## 非同步回呼（`callback_url`）

長文字一次合成可能需要十幾秒到幾十秒，連線若中斷需要重試。請求主體中傳入 `callback_url` 後，介面會立即回傳 `{task_id, started_at}`，上游真正完成時將完整結果以 POST JSON 形式回呼至該 URL，請求主體中帶有相同的 `task_id` 和本次最終計費的頂層 `cost`。初始任務確認尚未完成合成，因此不包含 `cost`。

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "今天天气真好，我们一起出去散散步吧。",
    "format": "mp3",
    "callback_url": "https://webhook.site/4815f79f-a40f-4078-ac85-1cc126b6bb34"
  }'
```

立即回傳（實測）：

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "started_at": 1778462584.742
}
```

稍後 `callback_url` 會收到如下形式：

```json
{
  "task_id": "79d82713-2897-4eeb-9934-e7544d471aa7",
  "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/bd66b8c5-7543-4557-b684-baa72407e336-52f2e79732f2.mp3"
}
```

也可以使用 [Fish Tasks API](https://platform.acedata.cloud/documents/fish-tasks) 主動依 `task_id` 拉取結果；終態記錄的 `response.cost` 與回呼中的 `cost` 一致，詳見該文件。

## 錯誤處理

- `400 token_mismatched`：請求參數缺失或不合法（最常見是 `text` 為空，或 `format` 傳入了 `mp3`/`wav`/`pcm` 以外的值）。
- `401 invalid_token`：鑑權 token 不存在或無效。
- `429 too_many_requests`：觸發帳號速率限制。
- `500 api_error`：伺服器內部錯誤。

錯誤回應範例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

參數驗證錯誤會在 `message` 欄位說明不合法的欄位，例如：

```json
{
  "status": 400,
  "message": "[{\"type\":\"literal_error\",\"loc\":[\"format\"],\"msg\":\"Input should be 'pcm' or 'mp3'\",\"input\":\"wav\"}]"
}
```

## 結論

接入 Fish TTS 的最低成本是：在既有呼叫 `api.fish.audio/v1/tts` 的程式碼中將鑑權更換成本平台 token，並在請求主體中**明確帶上** `format: "mp3"`。長文字情境建議使用 `callback_url` 非同步回呼；對於克隆音色 `reference_id` 的發現，請搭配 [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) 與 [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)。
