Fish Tasks API 的主要功能是透過輸入 Fish Audios Generation API 生成的任務 ID 來查詢該任務的執行情況。

本文檔將詳細介紹 Fish Tasks API 的串接說明，幫助您輕鬆整合並充分利用該 API 的強大功能。透過 Fish Tasks API，您可以輕鬆實現查詢 Fish Audios Generation API 的任務執行情況。

## 申請流程

若要使用 Fish Audios Generation API，首先請前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果您尚未登入或註冊，將自動跳轉至登入頁面邀請您註冊與登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台所有服務，無需為每個服務個別申請。** 首次申請將贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[Fish Audios Generation API →](https://platform.acedata.cloud/documents/fish-tts)

## 請求範例

Fish Tasks API 可用於查詢 Fish Audios Generation API 的結果。關於如何使用 Fish Audios Generation API，請參考文件 [Fish Videos Generation API ](https://platform.acedata.cloud/documents/fish-tts-integration)。

我們以 Fish Audios Generation API 服務返回的一個任務 ID 為例，示範如何使用該 API。假設我們有一個任務 ID：2725a2d3-f87e-4905-9c53-9988d5a7b2f5，接下來示範如何透過傳入一個任務 ID 來查詢。

### 設定請求標頭和請求主體

**Request Headers** 包括：

- `accept`：指定接收 JSON 格式的回應結果，此處填寫為 `application/json`。
- `authorization`：呼叫 API 的金鑰，申請後可直接下拉選擇。

**Request Body** 包括：

- `id`：上傳的任務 ID。
- `action`：對任務的操作方式。

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/fish/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "2725a2d3-f87e-4905-9c53-9988d5a7b2f5",
  "action": "retrieve"
}'
```


返回結果共有多個欄位，request 欄位就是發起任務時的 request body，同時 response 欄位是任務完成後返回的 response body。欄位介紹如下。

- `id`，生成此任務的 ID，用於唯一識別此次生成任務。
- `request`，查詢任務中的請求資訊。
- `response`，查詢任務中的返回資訊；最終成功時其中的 `cost.amount` 是該次合成實際扣除的 Credits。
- `created_at`，任務建立時間，Unix 時間戳（秒，浮點數）。
- `started_at`，任務開始執行時間，Unix 時間戳（秒，浮點數）。
- `finished_at`，任務完成時間，Unix 時間戳（秒，浮點數）。任務未完成時不返回該欄位。
- `elapsed`，任務執行耗時，單位為秒（浮點數，保留 3 位小數）。任務未完成時不返回該欄位。

## 錯誤處理

在呼叫 API 時，如果遇到錯誤，API 會回傳相應的錯誤代碼和資訊。例如：

- `400 token_mismatched`：錯誤的請求，可能是由於缺少或無效的參數。
- `400 api_not_implemented`：錯誤的請求，可能是由於缺少或無效的參數。
- `401 invalid_token`：未授權，無效或缺少授權權杖。
- `429 too_many_requests`：請求過多，您已超過速率限制。
- `500 api_error`：內部伺服器錯誤，伺服器發生了問題。

### 錯誤回應範例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
