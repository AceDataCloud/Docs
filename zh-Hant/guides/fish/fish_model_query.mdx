本接口基於 [Fish Audio 官方 Model API](https://docs.fish.audio/resources/api-reference/model)，用於**分頁檢索 Fish 公共音色庫或當前帳號下的克隆音色**。地址為 `GET https://api.acedata.cloud/fish/model`。

> 創建音色請參考 [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)；按 `_id` 查詢單個音色詳情請參考 [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)。

## 申請流程

要使用 Fish Model API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[Fish Model API →](https://platform.acedata.cloud/services/fish)

## 查詢參數

| 參數               | 類型      | 默認  | 說明                                      |
| ---------------- | ------- | --- | --------------------------------------- |
| `page_size`      | integer | 10  | 每頁條數。                                   |
| `page_number`    | integer | 1   | 1 起的頁碼。                                 |
| `title`          | string  | —   | 按標題模糊搜索。                                |
| `tag`            | string  | —   | 按單個標籤過濾。                                |
| `self`           | boolean | —   | `true` 時僅返回當前帳號創建的音色，無需任何額外條件。          |
| `author_id`      | string  | —   | 按上游用戶 `_id` 過濾。                         |
| `language`       | string  | —   | 按音色語種過濾，如 `en`、`zh`、`es`。               |
| `title_language` | string  | —   | 按標題語種過濾。                                |
| `sort_by`        | string  | —   | 排序字段，與上游一致，如 `created_at`、`task_count`。 |

> 參數命名與上游 `GET https://api.fish.audio/model` 完全一致，詳見 [Fish 官方文檔](https://docs.fish.audio/resources/api-reference/model)。

## 示例 3：只列出自己創建的音色（`self=true`）

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

返回（實測，當前帳號下只有 1 個音色）：

## 示例 4：按語種 + 標籤過濾
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> 上游對未在標籤字典裡的 `tag` 也會返回結果，但匹配相對寬鬆；如果命中數為 0，建議改用 `title` 模糊匹配。

## 響應字段

`items[]` 中的每一項是一個完整 ModelEntity 對象，常用字段：

| 字段            | 類型       | 說明                                                |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | 音色 ID，作為 `/fish/tts` 中 `reference_id` 的值。         |
| `type`        | string   | 模型類型，通常為 `tts`。                                   |
| `title`       | string   | 音色名稱。                                             |
| `description` | string   | 音色描述。                                             |
| `state`       | string   | 訓練狀態：`trained` 表示可用。                              |
| `tags`        | string[] | 公共庫標籤。                                            |
| `languages`   | string[] | 音色擅長的語種。                                          |
| `visibility`  | string   | `public` 或 `private`。                             |
| `samples`     | object[] | 預置樣本（含 `audio` 直鏈）。                               |
| `like_count`  | integer  | 公共庫點讚數。                                           |
| `task_count`  | integer  | 歷史合成次數。                                           |
| `author`      | object   | 上游作者信息：`_id` / `nickname` / `avatar`。             |
| `total`（頂層）   | integer  | 滿足條件的總條數。                                         |
| `has_more`    | boolean? | 上游分頁指示，可能為 `null`。建議改用 `total / page_size` 計算總頁數。 |

## 計費說明

本接口不計費——分頁查詢音色列表是免費操作。創建音色（[Fish Model Create](https://platform.acedata.cloud/documents/fish-model)）同樣免費，費用僅在調用 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) 合成語音時按用量產生。

## 錯誤處理

- `400 token_mismatched`：請求參數缺失或不合法。
- `401 invalid_token`：鑑權 token 不存在或無效。
- `429 too_many_requests`：觸發帳號速率限制。
- `500 api_error`：伺服器內部錯誤。

錯誤響應示例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 結論

要從 Fish 公共庫挑選音色餵給 `/fish/tts` 的 `reference_id`，先用本接口配合 `title` / `tag` / `language` 檢索，定位到目標 `_id`，再用 [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) 拿樣本試聽。要列出自己創建的音色，傳 `self=true` 即可。
