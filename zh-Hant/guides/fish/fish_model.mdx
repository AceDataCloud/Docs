本接口基於 [Fish Audio 官方 Model API](https://docs.fish.audio/resources/api-reference/model)，用於**基於一段音頻樣本創建一個新的克隆音色**。地址為 `POST https://api.acedata.cloud/fish/model`。

> 分頁檢索現有音色請參考 [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)；按 `_id` 查詢單個音色詳情請參考 [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)。

## 申請流程

要使用 Fish Model API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[Fish Model API →](https://platform.acedata.cloud/services/fish)

## 請求體字段

| 字段                      | 類型       | 必填  | 說明                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | 是   | 音色名稱，用於在控制台列表中識別。                                                             |
| `voices`                | string   | 是   | 音頻樣本的 HTTP(S) URL（**單個字符串**，不是數組）。本接口不支持 multipart/二進制上傳，請先把音頻放到任意可公開訪問的對象存儲。 |
| `description`           | string   | 否   | 音色描述。                                                                         |
| `cover_image`           | string   | 否   | 封面圖 HTTP(S) URL。                                                              |
| `visibility`            | string   | 否   | `private` 或 `public`，默認 `private`。`public` 表示發布到 Fish 公共音色庫供他人使用。             |
| `tags`                  | string[] | 否   | 公共庫檢索標籤，例如 `["male","narration","zh"]`。                                       |
| `texts`                 | string[] | 否   | 與樣本對應的參考文本（用於糾正發音）。                                                           |
| `enhance_audio_quality` | boolean  | 否   | 訓練前是否對樣本做音質增強。                                                                |
| `generate_sample`       | boolean  | 否   | 訓練完成後是否自動生成一段示例音頻。                                                            |

> 字段與上游完全一致，請同時參考 [Fish 官方文檔](https://docs.fish.audio/resources/api-reference/model)。

## 示例：創建一個私有克隆音色

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客錄音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png",
    "visibility": "private"
  }'
```

> 注意：`voices` 必須是**字符串**（單個音頻 URL），不是數組。傳成 `["..."]` 上游會拒絕。

成功響應直接返回 Fish 平台的 ModelEntity 對象（下例為我們實測過的最小可用音色，删去了部分長字段以便閱讀）：

`_id` 即可作為後續 [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) 中 `reference_id` 字段的值，用於使用該克隆音色進行語音合成：

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，這是一段使用我剛創建的克隆音色合成的語音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## 樣本要求

經驗值（與上游一致，可參考 [Fish 官方文檔](https://docs.fish.audio/resources/api-reference/model)）：

- 時長建議 30 秒以上，5 分鐘以內效果最佳；超過 10 分鐘邊際收益不大。
- 采樣率 16 kHz 及以上，單聲道或立體聲均可。
- 內容盡量乾淨：無背景音樂、回聲、明顯環境噪聲；同一說話人。
- 格式建議 `mp3` / `wav`。

如果對樣本質量沒有把握，可以同時傳 `enhance_audio_quality: true` 讓上游先做音質增強。

## 計費說明

創建音色克隆模型（`POST /fish/model`）免費，不收取任何費用；音色的查詢接口（[Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)）同樣不計費。費用僅在後續調用 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) 合成語音時按用量產生。

## 錯誤處理
- `400 token_mismatched`：請求參數缺失或不合法（最常見是 `voices` 不是 URL，或傳成了數組）。
- `401 invalid_token`：鑑權 token 不存在或無效。
- `429 too_many_requests`：觸發帳號速率限制。
- `500 api_error`：伺服器內部錯誤。

錯誤響應示例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 結論

調用本接口只需要準備一段可公開訪問的樣本音頻 URL，把它放到 `voices` 欄位即可拿到 `_id`，再餵給 `/fish/tts` 的 `reference_id` 就完成了端到端的「克隆 → 合成」。常見坑點是 `voices` 必須是字符串、不能是數組。
