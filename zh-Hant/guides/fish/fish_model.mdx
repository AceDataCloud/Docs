本介面基於 [Fish Audio 官方 Model API](https://docs.fish.audio/resources/api-reference/model)，用於**基於一段音訊樣本建立一個可長期重複使用的克隆聲音模型**。地址為 `POST https://api.acedata.cloud/fish/model`。

> 僅需暫時使用參考聲音時，無需建立模型，可直接使用 [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) 的 `references` 一次性即時克隆。分頁檢索現有音色請參考 [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)；依 `_id` 查詢單個音色詳情請參考 [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)。

## 申請流程

要使用 Fish Model API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，留作備用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請你註冊和登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台所有服務，無需為每個服務個別申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[Fish Model API →](https://platform.acedata.cloud/services/fish)

## 請求主體欄位

| 欄位                      | 類型       | 必填  | 說明                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | 是   | 音色名稱，用於在控制台列表中識別。                                                             |
| `voices`                | string   | 是   | 音訊樣本的 HTTP(S) URL（**單一字串**，不是陣列）。本介面不支援 multipart/二進位上傳，請先把音訊放到任何可公開存取的物件儲存。 |
| `description`           | string   | 否   | 音色描述。                                                                         |
| `cover_image`           | string   | 否   | 封面圖 HTTP(S) URL。                                                              |
| `tags`                  | string[] | 否   | 公共庫檢索標籤，例如 `["male","narration","zh"]`。                                       |
| `texts`                 | string[] | 否   | 與樣本對應的參考文字（用於校正發音）。                                                           |
| `enhance_audio_quality` | boolean  | 否   | 訓練前是否對樣本做音質增強。                                                                |
| `generate_sample`       | boolean  | 否   | 訓練完成後是否自動產生一段範例音訊。                                                            |

> 音色模型的更多資訊可參考 [Fish 官方文件](https://docs.fish.audio/resources/api-reference/model)。

> 建立的音色會長期公開儲存，其他使用者可能搜尋並使用。無需傳 `visibility`；即使傳入 `private` 或 `unlist`，目前介面也不會據此改變公開範圍。

## 範例：建立一個公開的複製音色

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客錄音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> 注意：`voices` 必須是**字串**（單一音訊 URL），不是陣列。不支援傳入 `["..."]`。建議使用帶有 `.mp3` 或 `.wav` 副檔名且可公開下載的直接連結。

成功回應會直接傳回 Fish 平台的 ModelEntity 物件（下例為我們實測過的最小可用音色，為方便閱讀已刪除部分較長欄位）：

`_id` 可作為後續 [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) 中 `reference_id` 欄位的值，用於使用該複製音色進行語音合成：

建立成功的音色會公開儲存，可透過 [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) 的 `self=true` 查詢目前呼叫使用者透過本平台建立的音色。`self=true` 僅篩選清單，不限制其他使用者使用該音色。

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，這是一段使用我剛建立的克隆音色合成的語音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## 樣本要求

參考建議（詳見 [Fish 官方文件](https://docs.fish.audio/resources/api-reference/model)）：

- 建議時長為 30 秒以上，5 分鐘以內效果最佳；超過 10 分鐘的邊際效益不大。
- 取樣率為 16 kHz 以上，單聲道或立體聲皆可。
- 內容請盡量保持乾淨：無背景音樂、回音或明顯環境雜訊；且應為同一位說話者。
- 建議格式為 `mp3` / `wav`。

如果不確定樣本品質，也可以同時傳入 `enhance_audio_quality: true` 以啟用音質增強。

## 計費說明
建立音色克隆模型（`POST /fish/model`）免費，不收取任何費用；音色的查詢介面（[Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)）同樣不計費。費用僅在後續呼叫 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) 合成語音時按用量產生。

## 錯誤處理

- `400 token_mismatched`：請求參數缺失或不合法（最常見是 `voices` 不是 URL，或傳成了陣列）。
- `400`：參考音訊無法下載、時長過短或格式無法辨識時，請檢查音訊 URL 和檔案格式。
- `401 invalid_token`：驗證 token 不存在或無效。
- `429 too_many_requests`：觸發帳號速率限制。
- `500 api_error`：伺服器內部錯誤。

錯誤回應範例：

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 結論

呼叫本介面只需要準備一段可公開存取的樣本音訊 URL，把它放到 `voices` 欄位即可取得 `_id`，再餵給 `/fish/tts` 的 `reference_id` 就完成了端對端的「克隆 → 合成」。常見陷阱是 `voices` 必須是字串、不能是陣列。

## 透過 MCP 建立並重複使用音色

在 Fish MCP 中呼叫
`fish_create_model(title="我的音色", voices="https://example.com/authorized-voice.wav")`。
`voices` 是單個 HTTP(S) 音訊 URL；還可傳入 `description`、`cover_image`、`tags`、
`texts`、`enhance_audio_quality`、`generate_sample`。

該工具會長期儲存公開音色，其他使用者可能發現並使用；請僅使用獲准處理和公開的
音訊素材。工具沒有私人或不公開選項。建立成功回傳的 `_id` 用於
`fish_generate_audio` 的 `reference_id`，`fish_list_models(self=true)` 可查詢自己
儲存的音色。只需要一次性參考聲音時，使用 `fish_generate_audio` 的 `references`，
無需建立長期音色。
