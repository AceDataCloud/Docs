Gemini Tasks API 的主要功能是透過輸入 Gemini Videos Generation API 生成的任務 ID 來查詢該任務的執行情況。

本文檔將詳細介紹 Gemini Tasks API 的對接說明，幫助您輕鬆整合並查詢 Gemini Videos Generation API 的任務執行情況。

## 申請流程

要使用 Gemini Tasks API，需要先到申請頁面 [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) 申請相應的服務，並複製 Gemini Videos Generation API 返回的任務 ID。

隨後進入 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) 頁面申請相應的服務，進入頁面之後，點擊「Acquire」按鈕即可。

如果您尚未登入或註冊，會自動跳轉到[登入頁面](https://platform.acedata.cloud)邀請您來註冊和登入，登入註冊之後會自動返回當前頁面。

首次申請時會有免費額度贈送，可以免費使用該 API。

## 請求範例

Gemini Tasks API 可以用於查詢 Gemini Videos Generation API 的結果。

### 設置請求頭和請求體

**Request Headers** 包括：

- `accept`：指定接收 JSON 格式的響應結果，這裡填寫為 `application/json`。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

**Request Body** 包括：

- `id`：要查詢的任務 ID。
- `action`：對任務的操作方式，單個查詢填寫 `retrieve`。

### CURL 代碼範例

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### 響應範例

請求成功後，API 將返回此任務的詳細資訊。其中 `request` 字段是發起任務時的 request body，`response` 字段是任務完成後返回的 response body，例如：

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

字段介紹如下：

- `id`：生成任務的 ID，用於唯一標識此次生成任務。
- `request`：查詢任務中的請求資訊。
- `response`：查詢任務中的返回資訊。

## 批量查詢操作

針對多個任務 ID 查詢任務詳情時，將 `action` 設置為 `retrieve_batch`，並透過 `ids` 傳入任務 ID 陣列：

**Request Body** 包括：

- `ids`：要查詢的任務 ID 陣列。
- `action`：對任務的操作方式，批量查詢填寫 `retrieve_batch`。

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
