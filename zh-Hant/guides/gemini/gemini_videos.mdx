本文將介紹 Gemini Videos Generation API 的對接說明，它可以通過輸入文本提示詞（以及可選的參考圖片）來生成 Google Gemini（omni-flash）視頻。

## 申請流程

要使用 Gemini Videos Generation API，首先到 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取您的 API Token，留作備用。

![](https://cdn.acedata.cloud/5hmkdg.jpg)

如果你尚未登錄或註冊，會自動跳轉到登錄頁面邀請你註冊和登錄，完成後會自動返回當前頁面。

**一個 API Token 即可調用平台所有服務，無需為每個服務單獨申請。** 首次申請會贈送免費額度，可免費體驗；額度不足時可在 [控制台](https://platform.acedata.cloud/console/coin) 充值通用餘額。

> 📘 完整文檔：[Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## 基本使用

首先了解下基本的使用方式，輸入提示詞 `prompt`、模型 `model` 以及寬高比 `aspect_ratio`，便可生成對應的視頻。

可以看到這裡我們設置了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設置了 Request Body，包括：

- `prompt`：描述想要生成視頻內容的文本提示詞，**必填**。
- `model`：生成視頻的模型，目前僅支持 `omni-flash`，默認即為 `omni-flash`。
- `aspect_ratio`：生成視頻的寬高比，可選 `16:9`（橫屏）或 `9:16`（豎屏），默認 `16:9`。
- `resolution`：可選的輸出分辨率，可選 `720p` 或 `1080p`，默認 `720p`。
- `image_urls`：可選的參考圖片鏈接數組，用於引導視頻生成，留空項會被忽略。當使用 `video_urls` 進行視頻編輯時，本參數必填（至少一張）。
- `video_urls`：可選的參考視頻鏈接數組（最多 1 個），用於**視頻編輯 / 視頻參考**；提供時必須同時提供至少一張 `image_urls`。
- `callback_url`：異步回調地址，設置後 API 會立即返回 `task_id`，任務完成時將結果 POST 到該地址。
- `async`：可選，設為 `true` 時接口立即返回 `task_id`，無需提供 `callback_url`，隨後通過對應的任務查詢接口輪詢獲取結果。

點擊「Try」按鈕即可進行測試，得到的結果類似如下：

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

返回結果一共有多個字段，介紹如下：

- `success`：本次視頻生成請求是否成功。
- `task_id`：本次視頻生成任務的 ID。
- `trace_id`：本次請求的跟蹤 ID，用於排查問題。
- `data`：生成的視頻結果列表。
  - `id`：生成視頻的唯一標識。
  - `video_url`：生成視頻的鏈接地址（`state` 為 `pending` 時為 `null`）。
  - `state`：視頻生成任務的狀態，可選 `pending` / `succeeded` / `failed`。
  - `aspect_ratio`：該視頻的寬高比，與請求參數一致。
  - `prompt`：生成該視頻所使用的提示詞。

同步返回時，頂層還會附帶 `started_at`、`finished_at`、`elapsed`（耗時，秒）以及 `cost`（本次扣費，單位 Credit）等字段。

我們只需要根據結果中 `data` 的 `video_url` 鏈接地址獲取生成的視頻即可。

對應的 CURL 代碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

對應的 Python 代碼如下：

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 圖生視頻

如果想基於參考圖片生成視頻，可以在 `image_urls` 中傳入一個或多個圖片鏈接，用於引導視頻生成：

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## 視頻編輯 / 參考視頻（輸入視頻，生成視頻）

支持直接「輸入一段視頻，生成一段新視頻」：在 `video_urls` 中傳入一個參考視頻鏈接（最多 1 個），並**同時**在 `image_urls` 中提供至少一張參考圖（上游硬性要求），再用 `prompt` 描述想要的編輯效果（改風格、換場景、增刪元素等）。

下面是一個完整的真實示例——把一段陽光沙灘的視頻改成大雪紛飛的冬日場景，同時保留沙灘、椰樹和小船的佈局。視頻編輯耗時較長（本例約 6.5 分鐘），因此用 `async: true` 異步提交：
```json
{
  "prompt": "將這個陽光明媚的熱帶海灘變成一個下著大雪的冬季場景，並且天空陰雲密布；保持相同的海灘、棕櫚樹和船隻佈局。",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

提交後接口立即返回 `task_id`：

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

之後用該 `task_id` 作為 `id` 輪詢 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)，任務完成後即可拿到生成的新視頻（這是本示例的真實返回結果）：

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "將這個陽光明媚的熱帶海灘變成一個下著大雪的冬季場景，並且天空陰雲密布；保持相同的海灘、棕櫚樹和船隻佈局。"
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

如需更高清的結果，可將 `resolution` 設為 `1080p`（其餘參數不變）。

> 提示：示例中的輸入 / 輸出媒體鏈接均為真實生成結果。**平台生成的視頻、圖片鏈接有保存期限，過期後會失效**，請在拿到結果後及時下載保存到自己的存儲。

> 注意：參考視頻最多 1 個；且提供 `video_urls` 時必須提供至少一張 `image_urls`，否則會返回如下參數錯誤：

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## 異步回調

視頻生成需要一定的處理時間。如果不希望保持長連接等待，可以傳入 `callback_url`，此時 API 會立即返回 `task_id`，任務完成後會將最終結果 POST 到該地址：

```json
{
  "prompt": "一個小貓在陽光明媚的花園裡追逐蝴蝶的電影鏡頭",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

立即返回的結果如下：

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## 查詢任務結果

如果使用了異步回調或希望主動查詢任務狀態，可以通過 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)（`POST https://api.acedata.cloud/gemini/tasks`）根據 `task_id` 查詢任務的最新狀態與結果。請求體中傳入創建視頻時返回的 `task_id` 作為 `id`：

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

任務完成後返回的結果類似如下，`response.data` 的結構與同步生成時一致（生成中時 `state` 為 `pending`、`video_url` 為 `null`）：

## 錯誤處理

當請求出現問題時，API 會返回對應的錯誤碼與說明，常見的如下：

- `400`：請求參數有誤，例如缺少 `prompt` 或 `aspect_ratio` 取值非法。
- `401`：鑑權失敗，token 無效或與 API 不匹配。
- `403`：餘額不足，或提示詞命中內容審核被拒絕。
- `500`：伺服器內部錯誤或上游生成失敗。
