本文將介紹 Gemini Videos Generation API 的對接說明，它可以透過輸入文字提示詞（以及可選的參考圖片）來生成 Google Gemini（omni-flash）影片。

## 申請流程

要使用 API，需要先到 [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) 對應頁面申請對應的服務，進入頁面之後，點擊「Acquire」按鈕，如圖所示：

![](https://cdn.acedata.cloud/q6ytrc.png)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請您來註冊和登入，登入註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費使用該 API。

## 基本使用

首先了解一下基本的使用方式，輸入提示詞 `prompt`、模型 `model` 以及寬高比 `aspect_ratio`，便可生成對應的影片。

可以看到這裡我們設定了 Request Headers，包括：

- `accept`：想要接收哪種格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設定了 Request Body，包括：

- `prompt`：描述想要生成影片內容的文字提示詞，**必填**。
- `model`：生成影片的模型，目前僅支持 `omni-flash`，預設即為 `omni-flash`。
- `aspect_ratio`：生成影片的寬高比，可選 `16:9`（橫屏）或 `9:16`（直屏），預設 `16:9`。
- `image_urls`：可選的參考圖片（或影片）連結陣列，用於引導影片生成，留空項會被忽略。
- `callback_url`：異步回調地址，設定後 API 會立即返回 `task_id`，任務完成時將結果 POST 到該地址。

點擊「Try」按鈕即可進行測試，得到的結果類似如下：

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

返回結果共有多個欄位，說明如下：

- `success`：本次影片生成請求是否成功。
- `task_id`：本次影片生成任務的 ID。
- `trace_id`：本次請求的追蹤 ID，用於排查問題。
- `data`：生成的影片結果列表。
  - `id`：生成影片的唯一標識。
  - `video_url`：生成影片的連結地址。
  - `state`：影片生成任務的狀態，可選 `pending` / `succeeded` / `failed`。

我們只需要根據結果中 `data` 的 `video_url` 連結地址取得生成的影片即可。

對應的 CURL 代碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

對應的 Python 代碼如下：

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 圖生影片

如果想基於參考圖片生成影片，可以在 `image_urls` 中傳入一個或多個圖片連結，用於引導影片生成：

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## 異步回調

影片生成需要一定的處理時間。如果不希望保持長連線等待，可以傳入 `callback_url`，此時 API 會立即返回 `task_id`，任務完成後會將最終結果 POST 到該地址：

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

立即返回的結果如下：

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## 查詢任務結果

如果使用了異步回調或希望主動查詢任務狀態，可以透過 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)（`POST https://api.acedata.cloud/gemini/tasks`）根據 `task_id` 查詢任務的最新狀態與結果。

## 錯誤處理

當請求出現問題時，API 會返回對應的錯誤碼與說明，常見的如下：

- `400`：請求參數有誤，例如缺少 `prompt` 或 `aspect_ratio` 取值非法。
- `401`：鑑權失敗，token 無效或與 API 不匹配。
- `403`：餘額不足，或提示詞命中內容審核被拒絕。
- `500`：伺服器內部錯誤或上游生成失敗。
