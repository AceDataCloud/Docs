本文介紹 Nano Banana Images API 的串接與使用方式。此介面支援兩種功能：**圖像生成（generate）** 與 **圖像編輯（edit）**。

## 申請流程

若要使用 Nano Banana Images API，請先前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，以備後續使用。

![](https://cdn.acedata.cloud/dvc3cg.jpg)

如果您尚未登入或註冊，系統會自動跳轉至登入頁面，邀請您註冊並登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台上的所有服務，無需為每項服務單獨申請。** 首次申請時會贈送免費額度，可供免費體驗；額度不足時，可前往 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## 介面概覽

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **驗證方式**：在 HTTP Header 中攜帶 `authorization: Bearer {token}`
- **請求標頭**：
  - `accept: application/json`
  - `content-type: application/json`
- **動作（action）**：
  - `generate`：根據文字提示詞生成圖片
  - `edit`：根據提供的圖片進行編輯
- **模型（model）**（選填）：
  - `nano-banana`（預設）：基於 Gemini 2.5 Flash Image，速度快、成本低
  - `nano-banana-2-lite`：基於 Gemini 3.1 Flash Lite Image，僅支援 1K，生成速度快
  - `nano-banana-2`：基於 Gemini 3.1 Flash Image Preview，具備 Pro 等級的品質與 Flash 的速度
  - `nano-banana-2.1`：新一代高效能圖像模型，支援 1K、2K、4K 圖片生成與編輯
  - `nano-banana-pro`：基於 Gemini 3 Pro Image Preview，提供最高品質
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：對應模型的官方通路版本，畫質與穩定性更佳，計費方式不同
- **非同步回呼**：選填，可透過 `callback_url` 接收任務完成通知與結果
- **圖片數量**：選填，可透過 `count` 指定 1–4 張，預設為 1 張；每張圖片皆透過獨立的生成呼叫完成；一般技術錯誤或服務提供者的安全性拒絕僅會影響對應的呼叫，其餘成功的圖片仍會正常回傳，並依實際成功的圖片張數計費

## 快速開始：生成圖片（`action=generate`）

**最基本的必要參數**：`action`、`prompt`

當您只想根據提示詞直接生成圖片時，只需將 `action` 設定為 `generate`，並提供清楚的 `prompt` 即可。

### 請求範例（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### 請求範例（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]

```

### 欄位說明

- `success`：本次請求是否成功。
- `task_id`：任務 ID。
- `trace_id`：鏈路追蹤 ID，方便排查問題。
- `count`：請求生成或編輯的圖片數量，支援 1–4 張，預設為 1 張。`data` 僅包含成功生成的圖片，並依實際回傳的圖片張數計費。每次生成呼叫都強制使用服務提供者原生的安全性政策；若某次呼叫遭到拒絕，不會影響其他成功的呼叫；若所有呼叫都遭到拒絕，則會回傳 403。
- `data[]`：結果清單。
  - `prompt`：用於生成的提示詞（回傳內容）。
  - `image_url`：生成圖片的直接連結 URL。

> 註：`/nano-banana/images` 僅需提供 `action` 與 `prompt` 即可生成圖片。

## 編輯圖片（`action=edit`）

當您希望根據現有圖片進行編輯時，請將 `action` 設定為 `edit`，並透過 `image_urls` 傳入待編輯的圖片連結清單（1 張或多張），同時提供描述編輯目標的 `prompt`。

例如，這裡我們提供一張人物照片和一張服裝照片，讓人物穿上這件服裝，就可以同時傳入圖片連結，並指定 `action` 為 `edit`。URL 可以是 HTTP URL，也就是使用 `https` 或 `http` 協定的公開可存取連結；也可以是 Base64 編碼的圖片，例如 `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### 請求範例（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### 請求範例（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",

### 欄位說明

- `image_urls[]`：待編輯的圖片 URL 清單（必須可從公開網路存取）。可以傳送多張圖片，服務會結合這些素材與 `prompt` 完成編輯。
- 其餘欄位與「生成圖片」的回傳內容相同。

## 非同步回呼（選用，建議使用）

生成或編輯可能需要一些時間。為避免長連線占用資源，建議透過 `callback_url` 使用 **Webhook 回呼**：

1. 在請求主體中新增 `callback_url`，例如你的伺服器端 Webhook 位址（必須可從公開網路存取，並支援 POST JSON）。
2. API 會 **立即回傳** 包含 `task_id` 的回應（或包含基本結果）。
3. 任務完成後，平台會透過 `POST` 方法將完整 JSON 傳送至 `callback_url`。你可以透過 `task_id` 將請求與結果關聯。

**回呼載荷範例**（欄位結構與同步成功回應一致）：

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## 錯誤處理

呼叫失敗時會回傳標準錯誤格式與追蹤 ID。常見錯誤如下：

- **400 `token_mismatched`**：請求不合法或參數錯誤。
- **400 `api_not_implemented`**：介面尚未實作（請聯絡支援團隊）。
- **401 `invalid_token`**：身分驗證失敗或缺少 Token。
- **403 `forbidden`**：提供者的原生安全政策拒絕了請求或生成結果。此呼叫不會回傳圖片，也不會收費；多圖片請求仍可回傳並對其他成功的呼叫收費。
- **429 `too_many_requests`**：請求頻率超出限制。
- **500 `api_error`**：伺服器端異常。

### 錯誤回應範例

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 參數對照與注意事項

- **必填**：`action`、`prompt`
- **編輯專用**：`image_urls`（陣列，至少 1 項）
- **選填**：`model`（預設為 `nano-banana`，可選擇 `nano-banana-2-lite`、`nano-banana-2`、`nano-banana-2.1`、`nano-banana-pro`；除了 `nano-banana-2.1` 之外，也有對應的 `:official` 官方管道版本）、`aspect_ratio`（`auto` 或具體長寬比，例如 `1:1`、`16:9`）、`resolution`（解析度，例如 `1K`、`2K`、`4K`；`nano-banana-2-lite` 僅支援 `1K`）、`callback_url`（用於非同步回呼）
- **Headers**：必須提供 `authorization: Bearer {token}`；建議將 `accept` 設為 `application/json`
- **圖片可存取性**：`image_urls` 必須是可從公開網路存取的直接連結（HTTP/HTTPS），建議使用 HTTPS
- **冪等性與追蹤**：保留 `task_id` 與 `trace_id`，以便進行故障排除及關聯結果

明確傳入 `"aspect_ratio": "auto"` 時，系統會根據提示詞中的比例、方向或版面配置，選擇最接近的預設比例，適用於生成和編輯。例如，提示詞寫「YouTube 縮圖」，就可以選擇 `16:9`。如果提示詞沒有尺寸要求，或無法自動判斷，文生圖會使用預設畫幅，圖片編輯則會跟隨第一張參考圖，使用最接近的受支援比例。省略此欄位時，會使用預設畫幅或參考圖片的比例。若已有明確的畫幅要求，請直接傳入具體比例。
