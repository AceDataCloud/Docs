Codex Desktop 與 Codex CLI 共用 `~/.codex/config.toml`。

## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 設定 API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "你的 API Key"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "你的 API Key"
```

## 3. 配置 AceDataCloud

編輯 `~/.codex/config.toml`（Windows 為 `%USERPROFILE%\.codex\config.toml`），加入：

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows 將最後兩行改為：

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

無需填寫 `model`；打開 Codex 後直接選擇模型。

## 4. 重啟並驗證

完全退出並重新打開 Codex Desktop，新建本地任務並發送一條簡單消息。Provider 應顯示為 `acedatacloud`；真實調用可在 [使用歷史](https://platform.acedata.cloud/console/usages) 查看。

如果配置未生效，確認修改的是當前用戶的 `~/.codex/config.toml`，環境變量已設定，然後再次完全重啟應用。雲端任務或自動化運行在不同環境時，需要在對應環境單獨配置 Key。
