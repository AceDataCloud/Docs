Codex VS Code 擴展與 Codex CLI 共用 `~/.codex/config.toml`。

## 1. 獲取 API Key

打開 [Ace Data Cloud 應用列表](https://platform.acedata.cloud/console/applications)，進入可用的應用並複製 API Key。

![獲取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 安裝擴展

在 VS Code 擴展市場安裝 OpenAI 發布的 **Codex – OpenAI's coding agent**，或運行：

```bash
code --install-extension openai.chatgpt
```

## 3. 設定 API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="你的 API Key"
```

如需長期生效，把這一行加入 `~/.zshrc` 或 `~/.bashrc`。Windows PowerShell 使用：

```powershell
setx ACEDATACLOUD_API_KEY "你的 API Key"
```

## 4. 配置 AceDataCloud

編輯 `~/.codex/config.toml`（Windows 為 `%USERPROFILE%\.codex\config.toml`），加入：

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows 將最後兩行改為：

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

無需填寫 `model`；可在 Codex 面板中選擇模型。

## 5. 重啟並驗證

完全退出並重新打開 VS Code，再打開 Codex 面板。運行 `/model`，確認 Provider 為 `acedatacloud`，然後發送一條簡單消息；調用記錄可在 [使用歷史](https://platform.acedata.cloud/console/usages) 查看。

如果擴展讀不到 Key，請從已設定環境變量的終端啟動 VS Code，或設定系統級環境變量後重啟 VS Code。Remote SSH、WSL 和 Dev Container 需要在實際運行擴展的環境中分別配置。
