Codex CLI 是 OpenAI 推出的開源本地編程 Agent，可以在終端中閱讀代碼、修改文件、運行命令並協助完成開發任務。通過 Ace Data Cloud 代理，你可以以更低的價格使用 Codex CLI，無需單獨訂閱 OpenAI 官方帳號。

按使用場景選擇對應的完整配置教程：

| 平台 | 說明 | 教程連結 |
|------|------|---------|
| **VS Code** | 官方擴充，在編輯器側邊欄聊天、引用文件、預覽 diff | [VS Code 配置教程](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **終端 (CLI)** | 核心體驗，在任意終端運行 `codex` 即可開始 | [終端配置教程](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **提示**：首次申請可前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 獲取 API Token，即贈免費額度。Codex CLI 通過 Ace Data Cloud 的 OpenAI Responses 兼容介面（`/v1/responses`）工作，更多模型與計費資訊可參考 [OpenAI 服務頁面](https://platform.acedata.cloud/documents/openai)。
