本文檔主要介紹 ADSL Proxy API 操作的使用流程，利用它我們可以輕鬆提取 ADSL 的 IP 並且對 ADSL Proxy 添加 IP 白名單。

## 申請流程

要使用提取 ADSL 的 IP 和對 ADSL Proxy 添加 IP 白名單，首先可以到 [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract) 和 [ADSL Proxy Whitelist API](https://platform.acedata.cloud/documents/adsl-whitelist) 頁面點擊「Acquire」按鈕，獲取請求所需要的憑證：

![](https://cdn.acedata.cloud/nyq0xz.png)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請您來註冊和登入，登入註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費使用該 API。

## 提取 ADSL 的 IP

接下來就可以在介面 [ADSL Proxy Extract API](https://platform.acedata.cloud/documents/adsl-extract) 上填寫對應的內容，接下來演示如何提取 ADSL 的 IP。

### 設置請求頭和請求體

**Request Headers** 包括：

- `accept`：指定接收 JSON 格式的響應結果，這裡填寫為 `application/json`。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

**Request Body** 包括：

- `number`：提取的 ADSL 的 IP 數量，默認為 1。
- `type`：提取的 ADSL 的 IP 類型，主要分為 `http` 和 `socks`，默認為 `http` 。
- `province`：提取 IP 的所在省份，默認是隨機的。
- `city`：提取 IP 的所在城市，默認是隨機的。

對於參數 `province` 和 `city` 的設定，它是有要求的，它必須是對應的，比如`city` ：南昌必須對應 `province` ：江西，需要與省份對應起來，具體的規則如下：

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/adsl/extract' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "province": "浙江",
  "city": "溫州"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "province": "浙江",
    "city": "溫州"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `port`，此處提取 ADSL 的 IP 端口信息。
- `proxy`，提取後的 ADSL 的 IP 代理的完整信息。
- `province`，提取後的 ADSL 的 IP 所在省份。
- `city`，提取後的 ADSL 的 IP 所在城市。

可以看到我們可以輕鬆使用上面 `proxy` 來進行下一步 IP 代理工作。

首先在使用 IP 代理之前我們需要將自己的網絡 IP 地址（獲取本地網絡 IP 方法請自行查找）添加到下文的白名單之中，接下來講一下 IP 代理如何使用：

### 使用代理

> 注意：使用提取到的代理 IP 之前，請務必添加 IP 白名單，否則無法使用，關於添加白名單的說明請參考下文內容。

Curl 示例代碼：

```shell
curl -x 115.219.4.171:23456 myip.vpsnb.net # http proxy
curl --socks5 115.219.3.54:23457 myip.vpsnb.net # socks proxy
```

Python 示例代理：

```python
import requests
import socks
import socket
import time

def test_http_proxy(proxy):
    try:
        start_time = time.time()
        response = requests.get(
            'http://httpbin.org/ip', proxies={'http': proxy, 'https': proxy}, timeout=100)
        elapsed_time = time.time() - start_time
        print(response)
        if response.status_code == 200:
            print(f"HTTP Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"HTTP Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"HTTP Proxy {proxy} failed: {str(e)}")

def test_socks_proxy(proxy):
    proxy_parts = proxy.split(':')
    if len(proxy_parts) != 2:
        print(f"SOCKS failed: {proxy}")
        return

    host, port = proxy_parts
    port = int(port)

    try:
        start_time = time.time()
        socks.set_default_proxy(socks.SOCKS5, host, port)
        socket.socket = socks.socksocket
        response = requests.get('http://httpbin.org/ip', timeout=10)
        elapsed_time = time.time() - start_time

        if response.status_code == 200:
            print(f"SOCKS Proxy {proxy} success. time: {elapsed_time:.2f} s")
            print(f"IP: {response.json()['origin']}")
        else:
            print(f"SOCKS Proxy {proxy} failed. code: {response.status_code}")
    except Exception as e:
        print(f"SOCKS Proxy {proxy} failed: {str(e)}")
    finally:
        socks.set_default_proxy()
        socket.socket = socket.socket

if __name__ == "__main__":
    # HTTP Proxy
    http_proxy = "http://115.219.4.171:23456"
    test_http_proxy(http_proxy)

    # SOCKS Proxy

    test_socks_proxy(socks_proxy)

```

## 添加 IP 白名單

接下來就可以在介面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/wz4obo.png" width="500" class="m-auto"></p>

在第一次使用該介面時，我們至少需要填寫三個內容，一個是 `authorization`，直接在下拉列表裡面選擇即可。另一個參數是 `ip`， `ip` 就是我們需要使用上文提取到的 IP 代理的本機網路地址。最後一個參數是`action`，`action` 是我們對白名單進行的操作，這裡是對白名單進行添加的操作。

同時您可以注意到右側有對應的調用代碼生成，您可以複製代碼直接運行，也可以直接點擊「Try」按鈕進行測試。

<p><img src="https://cdn.acedata.cloud/cs5ib2.png" width="500" class="m-auto"></p>

Python 樣例調用代碼：

```python
import requests

url = "https://api.acedata.cloud/adsl/whitelist"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "ip": "113.112.122.132",
    "action": "add"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

調用之後，我們發現返回結果如下：

```json
{
  "success": true
}
```

返回結果一共有一個字段，介紹如下：

- `success `，此處操作結果的狀態。

其中 `success` 是包含了操作結果的狀態，我們可以看到將 IP `113.112.122.132` 已經成功添加到白名單內。

## 錯誤處理

在調用 API 時，如果遇到錯誤，API 會返回相應的錯誤代碼和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.
