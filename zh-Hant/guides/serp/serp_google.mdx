Google SERP（Search Engine Results Page）是用戶在 Google 搜尋引擎中輸入查詢後看到的結果頁面。它顯示自然搜尋結果、廣告、特色摘要、知識圖譜以及圖片、視頻等多種內容，旨在為用戶提供最相關的信息。

本文將詳細介紹 Google SERP API，它可以提供在 Google 搜尋引擎中輸入查詢獲取結果，結果的內容也是包含了許多類型，比如特色摘要、知識圖譜以及圖片等多種結果。

本文檔會介紹下 Google SERP API 的對接說明。

## 申請流程

要使用 Google SERP API，需要先到 [Google SERP API](https://platform.acedata.cloud/documents/serp-google) 對應頁面申請對應的服務，進入頁面之後，點擊「Acquire」按鈕，如圖所示：

![](https://cdn.acedata.cloud/q6ytrc.png)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請您來註冊和登入，登入註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費使用該 API。

## 基本使用

首先先了解下基本的使用方式，就是輸入搜尋資源類型和關鍵詞，就能獲得搜尋結果，只需要簡單地傳遞 `query` 欄位，並指定相應模型即可。

比如說查找：關於“apple inc”的信息，我們接下來就可以在介面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

可以看到這裡我們設置了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設置了 Request Body，包括：

- `type`：搜尋資源的類型，目前只支持六種類型，默認是 `search`。
- `query`：搜尋的關鍵詞。
- `country`：自定義搜尋結果的所在國家，默認是美國（US）。
- `language`：自定義搜尋結果的語言，默認是英語（en）。
- `range`：自定義搜尋結果的時間範圍，默認是沒有限制的。
- `number`：自定義搜尋結果的分頁頁面大小，默認是 10。
- `page`：自定義搜尋結果的分頁頁數，默認是 1。

另外如果想生成對應的對接代碼，可以直接複製生成，例如 CURL 的代碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "蘋果公司"
}'
```

Python 的對接代碼如下：

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "蘋果公司"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```
