title: "FLUX 影片整合指南"
description: "Flux 整合指南 - Ace Data Cloud"
---

透過 `POST /flux/videos` 提交任務，用 `action` 選擇生成、編輯或超分。省略 `action` 等同於 `generate`。使用既有的 `POST /flux/tasks` 查詢平台任務。支援 `async=true` 和 `callback_url`；完成結果包含平台影片連結和伺服器端測量的時長、尺寸與影格率。

## 生成：action=generate

支援 `mode=t2v/i2v/v2v/draft_enhance`。一般生成支援 5–20 秒整數或 `auto`；影片續接支援 5–15 秒。i2v 可提供 1–10 張關鍵影格，支援依序的 `[秒數, 圖片]` 對。輸出解析度為 hd/fhd/qhd/uhd，支援同步音訊。草稿僅輸出 hd，返回平台 `draft_task_id`；重複使用草稿需為相同歸屬，且受生成快取有效期限限制。草稿復現不能覆蓋原始提示詞和素材。

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "海邊日落",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

## 編輯：action=edit

傳入 `video` 和 `prompt`。編輯按實際輸出秒數計費，不接受生成的 `mode`、`duration` 等欄位。

```json
{"action":"edit","video":"https://example.com/video.mp4","prompt":"將場景改為藍色調","async":true}
```

## 超分：action=upscale

傳入 `input_video`，可選 `upscale_factor`（1.5–3）與 `creativity`（0 為精確、1 為創意）。按實際輸出 MP·秒計費：`時長 × 寬 × 高 / 1048576 × 影格率 / 24`，1 MP = 1024×1024。不接受生成參數。

```json
{"action":"upscale","input_video":"https://example.com/video.mp4","upscale_factor":2,"creativity":0,"async":true}
```

各操作採用目前 FLUX 參考定價係數，按實際輸出計費。失敗任務不收取生成費用；動態計費任務的最終費用取決於完成結果。不同操作只接受各自參數，未知 action 返回參數錯誤。
