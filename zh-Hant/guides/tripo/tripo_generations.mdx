---
title: "Tripo 3D 生成"
description: "Tripo 3D 整合指南 - Ace Data Cloud"
---

呼叫 `POST /tripo/generations` 建立新模型，傳入文字、單張圖片或同一物體的多個視角。使用 AceDataCloud Token，預設同步回傳結果。傳入 `async: true` 或 `callback_url` 時先回傳 HTTP 200 和 `task_id`。完成回呼與同步結果具有相同的 JSON 結構。

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` 預設為 `generate`。輸入三選一：`prompt`（1–1024 個字元）、`image_url`、`image_urls`。圖片為最大 20 MiB 的公開 HTTPS PNG/JPEG。多視圖按正、左、背、右排列，必須提供正面和至少另一面，可用 null 跳過中間視角。

`model` 預設為 `v3.1-20260211`，也可明確選用 `v3.0-20250812`、`v2.5-20250123`、`P1-20260311` 或 `P2-20260801`。`texture` 預設為 `standard`，純幾何使用 `none`。不同模型和紋理等級使用不同額度。

從 `data[0].model_url` 下載 GLB，`image_url` 為可選的預覽。保留 `data[0].id` 供後續紋理、轉換或骨架操作使用。重試同一提交時保留同一個 `Idempotency-Key` 和請求本文。
