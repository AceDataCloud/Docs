title: "Tripo 模型處理"

使用 `POST /tripo/models` 處理已有模型，傳入所需的 `action`。同步、非同步、回呼、帳號歸屬及任務查詢與 3D 生成相同。

| action  | 輸入                                                                | 結果                                                                   |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import  | `model_url`，公開 HTTPS 的 GLB、GLTF、FBX、OBJ 或 STL 檔案，最大 150 MiB       | 可繼續引用的模型 ID 和 GLB；有資料時回傳 `normalize_scale` 和 `normalize_translation` |
| texture | `model_id` 或 `model_url`；可選 `prompt`、`image_url`、`image_urls` 三選一 | 新模型、紋理和可選預覽                                                          |
| convert | `model_id` 或 `model_url`，以及目標 `format`                            | 轉換後的模型檔案                                                             |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

紋理品質支援 `fast`、`standard`、`detailed`、`extreme`。使用文字提示時可附加 `style_image_url`；圖片和多視圖參考遵循生成介面的格式。更多紋理參數見 OpenAPI。

轉換支援 `GLTF`、`FBX`、`USDZ`、`OBJ`、`STL` 和 `3MF`。回傳項目的 `format` 表示實際交付格式；例如請求 GLTF 可交付二進位 GLB。OBJ 以 ZIP 打包材質和貼圖。請求 FBX 時設 `texture_packaging: "zip"` 可獲得分離貼圖，打包結果註明 `container: "ZIP"`。啟用非預設網格或紋理設定可能按進階轉換計費，詳見服務價格。

使用 `data[0].id` 引用本帳戶模型，匯入的正規化轉換滿足 `normalized = original × normalize_scale + normalize_translation`。模型下載網址在 `data[0].model_url`。
