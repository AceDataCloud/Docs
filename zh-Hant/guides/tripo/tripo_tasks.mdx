---
title: "查詢 Tripo 模型任務"
description: "Tripo 3D 整合指南 - Ace Data Cloud"
---

憑 AceDataCloud Token 呼叫 `POST /tripo/tasks`。查詢免費，使用與生成相同的帳號。單筆使用 `id` 或 `trace_id`，`action` 預設為 `retrieve`。

```bash
curl -X POST https://api.acedata.cloud/tripo/tasks \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"action\":\"retrieve\",\"id\":\"${TASK_ID}\"}"
```

單筆結果是任務記錄，包含 `id`、`type`、`trace_id`、原始請求 `request`、`started_at` 和 `progress`。處理中可以間隔幾秒繼續查詢。完成後查看 `response.success`，成功時 `response.data[0].model_url` 是下載網址，失敗時 `response.error` 包含錯誤碼和訊息。時間戳記、`finished_at` 和耗時 `elapsed` 位於任務記錄頂層，單位為秒。遇到 `submission_unknown` 時保留原任務 ID 核對。

批次查詢使用 `{"action":"retrieve_batch","ids":["&lt;任務 ID 1>","&lt;任務 ID 2>"]}`，也可使用 `trace_ids`；每次最多 100 筆。回應為 `{"items":[...],"count":2}`，保留輸入順序和重複項目。查不到或無權讀取的任務，單筆查詢回傳 `{}`，批次查詢對應位置為 `null`。

任務記錄的 `type` 為 `generations`、`models` 或 `animations`。骨架檢查讀取 `response.data[0].riggable`，檔案類操作讀取 `response.data[0].model_url`。
