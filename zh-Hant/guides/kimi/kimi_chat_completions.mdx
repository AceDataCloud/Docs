Kimi 是月之暗面推出的 AI 模型系列。目前推薦使用 `kimi-k3.1-pro`，適合長程程式設計、複雜推理、視覺理解和知識工作；`kimi-k3` 仍可使用。透過與 OpenAI 相容的 Chat Completions API 進行呼叫。

本文主要介紹 Kimi Chat Completion API 的操作使用流程，透過它，我們可以輕鬆使用官方 Kimi 的對話功能。

## 支援的模型

目前支援 `kimi-k3.1-pro`、`kimi-k3`、`kimi-k2.6` 和 `kimi-k2.7-code` 四種模型。K2.7 Code 適用於程式設計與工具呼叫場景，按照 K2.6 同級價格計費；請勿在請求中為它傳入 `thinking` 開關或 `reasoning_effort`。其他 Kimi 型號已停止支援，請在用戶端明確選擇這四種型號之一。

## 申請流程

若要使用 Kimi Chat Completion API，首先請前往 [Ace Data Cloud 控制台](https://platform.acedata.cloud/console/applications) 取得您的 API Token，以備後續使用。

![]()

如果您尚未登入或註冊，系統會自動跳轉至登入頁面，邀請您註冊並登入，完成後會自動返回目前頁面。

**一個 API Token 即可呼叫平台上的所有服務，無需為每個服務個別申請。** 首次申請時會贈送免費額度，可免費體驗；額度不足時，可前往 [控制台](https://platform.acedata.cloud/console/coin) 儲值通用餘額。

> 📘 完整文件：[Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## 基本使用

接下來就可以在介面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

第一次使用此介面時，至少需要填寫三個欄位：`authorization` 可直接從下拉式清單中選擇；`model` 用於選擇 Kimi 模型，推薦使用 `kimi-k3.1-pro`；`messages` 是對話訊息陣列，每則訊息包含 `role` 和 `content`，其中 `role` 支援 `user`、`assistant`、`system` 和 `tool`。

同時，您可以注意到右側會產生對應的呼叫程式碼，您可以複製程式碼直接執行，也可以直接點擊「Try」按鈕進行測試。

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

以下是使用 `reasoning_effort: max` 所取得的真實 K3 回應（省略未使用的擴充欄位）：

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

回傳結果包含多個欄位，介紹如下：

- `id`，此次對話任務產生的 ID，用於唯一識別此次對話任務。
- `model `，所選擇的 Kimi 官方網站模型。
- `choices` Kimi 針對提問內容所提供的回答資訊。
- `usage `：此次問答中 token 的統計資訊。

其中 `choices` 包含了 Kimi 的回答資訊，其內部的 `choices` 是 Kimi 回答的具體內容，可以從圖中看到。

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

可以看到，`choices` 裡面的 `content` 欄位包含了 Kimi 回覆的具體內容；K3 還可能回傳 `reasoning_content`，用來表示推理過程。

## K3.1 Pro 推理強度

`kimi-k3.1-pro` 始終啟用推理功能。可以在請求主體的頂層設定 `reasoning_effort` 為 `low`、`high` 或 `max`；請勿傳入關閉推理的設定。模型支援最高 1,048,576 token 的上下文，但實際請求上限仍以目前介面為準。價格依照輸入、輸出及快取命中用量計算，詳情請參閱模型目錄中的 Pricing 卡片。

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "審查這段程式碼並提供修復方案"}],
    "reasoning_effort": "low"
  }'
```

以下 K3 範例保留供既有整合使用，範例回應確實是透過 K3 請求取得的。

## K3 推理強度

`kimi-k3` 始終啟用推理功能。請求主體的頂層支援 `reasoning_effort` 欄位，目前唯一支援的值是 `max`；省略此欄位時，同樣會使用 `max`。請使用支援的值。

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "審查這段程式碼並提供修復方案"}],
    "reasoning_effort": "max"
  }'
```

使用 OpenAI SDK 時，可以直接傳入此欄位：

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "設計一個可靠的任務佇列"}],
    reasoning_effort="max",
)
```

在多輪對話和工具呼叫時，請將上一輪完整的 assistant 訊息回傳至 `messages`，包括 `reasoning_content` 和 `tool_calls`。

### 官方參考資料

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort)：說明 Kimi K3 始終啟用推理功能，目前 `reasoning_effort` 唯一支援的值為 `max`。
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview)：比較 K3 與 K2 系列的推理參數、上下文視窗和工具呼叫差異。
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat)：Moonshot 官方 Chat Completions 請求、回應和 OpenAPI 欄位定義。

## 串流回應

此介面也支援串流回應，這對網頁整合非常有用，可以讓網頁實現逐字顯示的效果。

如果想要以串流方式回傳回應，可以修改請求標頭中的 `stream ` 參數，將其設定為 `true`。

修改方式如圖所示，不過呼叫程式碼也需要進行相應修改，才能支援串流回應。

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>
將 `stream` 修改為 `true` 之後，API 將逐行返回對應的 JSON 資料，在程式碼層面我們需要進行相應的修改，才能取得逐行的結果。

Python 範例呼叫程式碼：

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

以下節錄同一次真實 K3 Max 串流回應中的起始、推理、正文、結束和用量資料區塊：

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

可以看到，回應中有許多 `data`，`data` 裡面的 `choices` 即為最新的回答內容，與上文介紹的內容一致。`choices` 是新增的回答內容，您可以根據結果將其整合到您的系統中。同時，串流回應的結束是根據 `data` 的內容來判斷的，如果內容為 `[DONE]`，則表示串流回應已全部結束。返回的 `data` 結果共有多個欄位，介紹如下：

- `id`，生成此次對話任務的 ID，用於唯一識別此次對話任務。
- `model `，選擇的 Kimi 官網模型。
- `choices`，Kimi 針對提問詞提供的回答資訊。

JavaScript 也支援此功能，例如 Node.js 的串流呼叫程式碼如下：

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java 範例程式碼：

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

其他語言可以自行改寫，原理都是一樣的。

## 多輪對話

如果您想要整合多輪對話功能，需要在 `messages` 欄位中上傳多個提問詞，多個提問詞的具體範例如下圖所示：

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python 範例呼叫程式碼：

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

透過上傳多個提問詞，就可以輕鬆實現多輪對話。以下是此請求取得的真實 K3 Max 回應（省略未使用的擴充欄位）：

```json
{
  "id": "msg_Rqp8nPGBDHWwBlL4VpxuafOp",
  "object": "chat.completion",
  "created": 1784466628,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "I’m Kimi, an AI assistant developed by Moonshot AI (月之暗面). I don’t have a specific public model version identifier to share from here."
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 134,
    "completion_tokens": 346,
    "total_tokens": 480
  }
}
```

可以看到，`choices` 包含的資訊與基本使用方式中的內容一致，其中包含 Kimi 針對多輪對話所提供的具體回覆內容，這樣就可以根據多輪對話的內容回答相應的問題。

## 錯誤處理

在呼叫 API 時，如果遇到錯誤，API 會返回相應的錯誤代碼和資訊。例如：

- `400 token_mismatched`：錯誤的請求，可能是因為缺少或提供了無效的參數。
- `400 api_not_implemented`：錯誤的請求，可能是因為缺少或提供了無效的參數。
- `401 invalid_token`：未經授權，授權 Token 無效或缺失。
- `429 too_many_requests`：請求過多，您已超出速率限制。
- `500 api_error`：伺服器內部錯誤，伺服器發生了問題。

### 錯誤回應範例

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
