title: "可灵會說話的照片 API（Kling Talking Photo）"

---

一鍵把**一張照片 + 一段音頻**變成一段「會說話的視頻」。服務內部自動完成兩步:先用 image2video 讓照片動起來,再用 lip-sync 按音頻對口型。你只需調用**一次**。

- **接口地址**：`POST https://api.acedata.cloud/kling/talking-photo`
- **計費**：按時長,5 秒 **16.45 Credits**、10 秒 **30.45 Credits**(= image2video + lip-sync 合併價)

## 請求頭

| 字段              | 值                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## 請求參數

| 參數             | 類型      | 必填  | 默認                  | 說明                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | 是   | —                   | 人物照片的公開 URL,建議清晰正臉                    |
| `audio_url`    | string  | 是   | —                   | 驅動音頻的公開 URL（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | 否   | —                   | 照片動畫化階段的動作/表情提示詞                      |
| `model`        | string  | 否   | `kling-v2-1-master` | 照片動畫化使用的 Kling 模型                     |
| `duration`     | integer | 否   | `5`                 | 視頻時長（5 或 10 秒）                        |
| `mode`         | string  | 否   | `pro`               | 動畫化質量（std/pro）                        |
| `callback_url` | string  | 否   | —                   | 傳入或 `async=true` 則異步返回 task_id        |
| `async`        | boolean | 否   | `false`             | 異步模式,配合 `/kling/tasks` 輪詢或回調          |

## 請求示例

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## 響應示例

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| 字段                 | 說明                        |
| ------------------ | ------------------------- |
| `video_url`        | 最終會說話的視頻（已轉存本平台 CDN）      |
| `source_video_url` | 中間的照片動畫視頻（image2video 結果） |
| `video_id`         | 可靈視頻 ID                   |

## 注意事項

- 照片建議清晰正臉、單人。
- 音頻時長建議不超過視頻時長（5s/10s）。
- 計費在成功時發生;參數校驗失敗（4xx）不計費。
- 生成耗時約 4–6 分鐘（兩步),建議用 `async=true` + `/kling/tasks` 輪詢。
