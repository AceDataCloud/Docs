透過 `POST /kling/virtual-try-on` 提交任務，使用既有的 `POST /kling/tasks` 查詢平台任務狀態。

## 輸入

必須恰好提供一張 product_image 和一張 person_image。keep_face、keep_pose、keep_background 預設均為 true，可個別關閉。輸入圖片最長邊不得超過 2048px、最短邊大於 300px，檔案不得超過 10MB。

以下是請求結構範例，請替換素材 URL 後呼叫。

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## 結果與計費

同步模式回傳生成結果；非同步模式先回傳 `task_id`，完成結果包含 `data` 中的影片或圖片連結及伺服器端計算的 `usage`。`callback_url` 用於完成通知；`watermark=true` 請求同時回傳浮水印版本。

1.12 Credits/張，依實際輸出圖片數計費。影片依實際生成時長結算，生成前的每秒基礎價格不代表整項任務總價。失敗任務不收取生成費用。
