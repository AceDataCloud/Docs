透過 `POST /kling/apparel` 提交任務，使用現有的 `POST /kling/tasks` 查詢平台任務狀態。

## 輸入

提供一個最多 2500 字的商品說明、一個 5–180 秒的參考影片和 1–5 張商品圖片。可另外提供 1–5 張模特兒圖片、一個背景音樂檔案，以及指定配音音色；未指定音色時使用原生口播。

以下是請求結構範例，請替換素材 URL 後呼叫。

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播內容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## 結果與計費

同步模式回傳生成結果；非同步模式先回傳 `task_id`，完成結果包含 `data` 中的影片或圖片連結及伺服器端計算的 `usage`。`callback_url` 用於完成通知；`watermark=true` 請求同時回傳浮水印版本。

原生口播：720p 為 1.82 Credits/秒、1080p 為 2.38 Credits/秒；指定配音：720p 為 2.38 Credits/秒、1080p 為 2.8 Credits/秒。影片按實際生成時長結算，生成前的每秒基礎價格不代表整項任務總價。失敗任務不收取生成費用。
