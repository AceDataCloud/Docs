透過 `POST /kling/goods-studio` 提交任務，使用既有的 `POST /kling/tasks` 查詢平台任務狀態。

## 輸入

提供 1–5 張商品圖片和一個最多 200 字的商品標題；商品描述為選填，最多 2000 字。時長可選 15、30 或 60 秒。

以下是請求結構範例，請替換素材 URL 後呼叫。

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播內容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## 結果與計費

同步模式返回生成結果；非同步模式先返回 `task_id`，完成結果包含 `data` 中的影片或圖片連結及伺服器端計算的 `usage`。`callback_url` 用於完成通知；`watermark=true` 請求同時返回浮水印版本。

720p：2.38 Credits/秒；1080p：2.8 Credits/秒。影片依實際生成時長結算，生成前的每秒基礎價格不代表整項任務總價。失敗任務不收取生成費用。
