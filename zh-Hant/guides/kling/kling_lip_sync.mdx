title: "可灵對口型 API（Kling Lip Sync）"

---

讓一段**已有的可靈視頻**（5 秒或 10 秒）按音頻或文本"開口說話"——即對口型（Lip Sync）。配合 `/kling/videos` 的 `image2video`（讓照片動起來），即可串成完整的"**會說話的照片 / 數字人口播**"流程。

> 本接口是 AceDataCloud 提供的單步便捷封裝，面向常見的音頻/文本驅動場景；它不是 Kling 官方「人臉識別 → Advanced Lip Sync」多步接口的字段鏡像。請以本頁參數表為準。

- **接口地址**：`POST https://api.acedata.cloud/kling/lip-sync`
- **請求格式**：`application/json`
- **響應格式**：`application/json`
- **計費**：每次成功調用 **2.45 Credits**（固定）

## 請求頭（Request Headers）

| 字段              | 值                   | 說明                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | 你的 API 密鑰，[獲取地址](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | 請求體格式                                            |
| `accept`        | `application/json`  | 響應格式                                             |

## 請求參數（Request Body）

| 參數               | 類型      | 必填  | 默認      | 說明                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | 是   | —       | 生成模式。枚舉：`audio2video`（音頻驅動）、`text2video`（文本驅動）                                                                           |
| `video_id`       | string  | 二選一 | —       | 可靈生成視頻的 ID（如 `/kling/videos` 的 image2video 返回的 `video_id`）。**僅支持 30 天內生成的 5s/10s 視頻**。`video_id` 與 `video_url` 二選一，不可同時傳 |
| `video_url`      | string  | 二選一 | —       | 公網可訪問的視頻鏈接。約束：`.mp4`/`.mov`，≤100MB，時長 2–10s，僅 720p/1080p，邊長 720–1920px。與 `video_id` 二選一                                  |
| `audio_url`      | string  | 條件  | —       | 驅動音頻的下載 URL，`audio2video` + `audio_type=url` 時必填。格式 `.mp3`/`.wav`/`.m4a`/`.aac`，≤5MB                                     |
| `audio_type`     | string  | 否   | `url`   | 音頻傳輸方式。枚舉：`url`、`file`（`audio2video` 時生效）                                                                                |
| `audio_file`     | string  | 條件  | —       | 音頻文件的 Base64，`audio_type=file` 時必填。格式同上，≤5MB                                                                             |
| `text`           | string  | 條件  | —       | 要朗讀的文本，`text2video` 時必填，**最多 120 字**                                                                                     |
| `voice_id`       | string  | 條件  | —       | 音色 ID，`text2video` 時必填                                                                                                   |
| `voice_language` | string  | 否   | `zh`    | 音色語言。枚舉：`zh`、`en`（`text2video` 時生效）                                                                                      |
| `voice_speed`    | float   | 否   | `1.0`   | 語速，範圍 `0.8`–`2.0`，精確到一位小數（`text2video` 時生效）                                                                              |
| `callback_url`   | string  | 否   | —       | 回調地址。傳入此項或 `async=true` 則**異步模式**：立即返回 `task_id`，結果生成後回調                                                                 |
| `async`          | boolean | 否   | `false` | 是否異步。`true` 時立即返回 `task_id`，配合 `/kling/tasks` 轮询或 `callback_url` 回調                                                      |

## 請求示例

### 1）音頻驅動（audio2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2）文本驅動（text2video）

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "哥，好久不見，我一切都好，你要照顧好自己。",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## 響應示例（同步成功）

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| 字段          | 類型      | 說明                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | 是否成功                                       |
| `task_id`   | string  | 本次任務 ID（可用於 `/kling/tasks` 查詢）             |
| `video_id`  | string  | 生成視頻的可靈 ID（可作為下一次 `extend`/`lip-sync` 的輸入） |
| `video_url` | string  | 生成的說話視頻 URL（已轉存至本平台 CDN，長期有效）              |
| `duration`  | string  | 視頻時長（秒）                                    |
| `state`     | string  | 任務狀態：`succeed` / `failed`                  |

## 異步模式與查詢

傳入 `callback_url` 或 `async: true` 時，接口**立即返回** `task_id`；之後可：

- **輪詢**：`POST /kling/tasks`，body `{ "action": "retrieve", "id": "<task_id>" }`（免費）
- **回調**：生成完成後，結果 POST 到你的 `callback_url`

## 完整流程：會說話的照片（image2video → lip-sync）
```bash
# 第 1 步：讓照片動起來，拿到 video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# 第 2 步：用音頻對口型
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## 錯誤響應

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "one of video_id or video_url is required" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | code                    | 含義                                                 |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | 參數缺失或非法（如未傳 mode、video 與 audio 二選一衝突、text 超 120 字） |
| 401  | `authorization_missing` | 缺少或無效的 API 密鑰                                      |
| 403  | `forbidden`             | 內容被風控攔截                                            |
| 429  | `too_many_requests`     | 上游並發限制，請稍後重試                                       |
| 500  | `api_error`             | 上游或內部錯誤                                            |

## 注意事項

- `video_id` 必須是**30 天內**生成的可靈視頻，且為 **5s 或 10s**；否則請用 `video_url` 傳入符合約束的視頻。
- 輸入視頻建議**清晰正臉、單人**，口型效果最佳。
- 音頻/文本時長應與視頻時長匹配（音頻不超過視頻長度）。
- 計費在**成功**時發生（2.45 Credits/次）；參數校驗失敗（4xx）不計費。
