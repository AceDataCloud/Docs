本文將介紹一種 Short URL API 對接說明 對接說明，它可將較長的URL轉換為短的URL。

## 申請流程

要使用 API，需要先到 [Short URL API](https://platform.acedata.cloud/documents/shorturl) 對應頁面申請對應的服務，進入頁面之後，點擊「Acquire」按鈕，如圖所示：

![](https://cdn.acedata.cloud/q6ytrc.png)

如果你尚未登入或註冊，會自動跳轉到登入頁面邀請您來註冊和登入，登入註冊之後會自動返回當前頁面。

在首次申請時會有免費額度贈送，可以免費使用該 API。

## 基本使用

首先先了解下基本的使用方式，就是輸入需要轉換的較長URL，便可獲得處理後的結果，首先需要簡單地傳遞一個 `content` 欄位。我們接下來就可以在介面上填寫對應的內容，如圖所示：

<p><img src="https://cdn.acedata.cloud/4ascb2.png" width="500" className="m-auto" /></p>

可以看到這裡我們設定了 Request Headers，包括：

- `accept`：想要接收怎樣格式的響應結果，這裡填寫為 `application/json`，即 JSON 格式。
- `authorization`：調用 API 的密鑰，申請之後可以直接下拉選擇。

另外設定了 Request Body，包括：

- `content`：要縮短的URL的內容。

選擇之後，可以發現右側也生成了對應代碼，如圖所示：

<p><img src="https://cdn.acedata.cloud/r3uakb.png" width="500" className="m-auto" /></p>

點擊「Try」按鈕即可進行測試，如上圖所示，這裡我們就得到了如下結果：

```json
{
  "success": true,
  "data": {
    "url": "https://surl.id/1uHCs01xa5"
  }
}
```

返回結果一共有多個欄位，介紹如下：

- `success`，此處任務是否成功的狀態。
- `data`，包含了此處轉換後的URL。

可以看出 
原先較長的URL `https://platform.acedata.cloud/documents/shorturl` 已經成功轉換為短的URL `https://surl.id/1uHCs01xa5`。

另外如果想生成對應的對接代碼，可以直接複製生成，例如 CURL 的代碼如下：

```shell
curl -X POST 'https://api.acedata.cloud/shorturl' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "content": "https://platform.acedata.cloud/documents/shorturl"
}'
```

Python 的對接代碼如下：

```python
import requests

url = "https://api.acedata.cloud/shorturl"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": "https://platform.acedata.cloud/documents/shorturl"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 錯誤處理

在調用 API 時，如果遇到錯誤，API 會返回相應的錯誤代碼和信息。例如：

- `400 token_mismatched`：Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`：Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`：Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`：Too many requests, you have exceeded the rate limit.
- `500 api_error`：Internal server error, something went wrong on the server.

### 錯誤響應示例

```json

  },

}
```
