Producer 允許我們上傳參考音頻進行二次創作，本文檔講解相關 API 的對接方法。

該 API 只有一個輸入參數，就是 `audio_url`，它是一個可以公開訪問的 CDN 地址，支持 mp3 後綴。

這裡我們輸入的 `audio_url` 是 `https://cdn.acedata.cloud/suno_demo.mp3`，是一個可以公開訪問的 CDN 地址。

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

結果如下：

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n陽光灑在海邊\n浪花笑得燦爛\n你和我在沙灘\n鐘表停止轉\n冰淇淋在融化\n手牽手去散步\n風兒輕輕吹過\n心跳不停跳\n\n[Chorus]\n夏天夏天\n時間停在這一天\n笑聲迴盪\n蔚藍天空在身旁",
    "audio_url": "https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"
  }
}
```

可以看到，`data` 的 `audio_id` 欄位就是上傳後的歌曲 ID。

有了歌曲 ID 之後，我們便可以使用 [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) 來進行自定義歌曲生成了，比如說 `action` 傳入 `upload_extend`，同時 `audio_id` 傳入返回的歌曲 ID，就可以根據參考音頻生成新的歌曲了。
