---
title: "認證"
description: "如何使用 Ace Data Cloud API 進行身份認證"
---

所有 Ace Data Cloud API 使用 **Bearer Token** 認證。

## 獲取 Token

登入[應用程式列表](https://platform.acedata.cloud/console/applications?lang=zh-tw&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)，開啟**通用應用**。首次使用時，先點選**初始化通用應用**。 點選 **API KEY** 右側的複製按鈕。

![取得通用應用的 API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

請將金鑰保存在伺服器端，並用複製的值替換範例中的 `YOUR_API_TOKEN`。

## 使用 Token

在每個請求的 `Authorization` 標頭中包含 Token：

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## 速率限制

速率限制因服務和訂閱等級而異。超出限制時，API 回傳 `429 Too Many Requests`。

## 安全最佳實踐

- 不要在客戶端程式碼中暴露 API Token
- 使用環境變數儲存 Token
- 定期輪換 Token
- 開發和生產環境使用不同的 Token
