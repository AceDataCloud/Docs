## Введение

DeepSeek — это AI-сервис для общения, предоставляемый Ace Data Cloud, серия больших языковых моделей DeepSeek. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать DeepSeek с использованием JavaScript, реализуя многоходовые диалоги, системные подсказки, потоковый вывод, режим вывода JSON, глубокое рассуждение и другие функции.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная среда браузера

## Базовое использование

Основной эндпоинт для вызова DeepSeek API:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

В этом примере используется модель `deepseek-r1`. Доступные модели включают: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "deepseek-r1",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

Пожалуйста, замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять код состояния ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код состояния: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callDeepSeek(data) {
  const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|----------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов       |
| 500           | Внутренняя ошибка сервера        |
