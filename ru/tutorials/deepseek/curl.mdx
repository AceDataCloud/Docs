## Введение

DeepSeek — это AI-чат-сервис от Ace Data Cloud, серия больших языковых моделей DeepSeek. С помощью унифицированного API Ace Data Cloud вы можете быстро вызывать DeepSeek через cURL для реализации многоходового диалога, системных подсказок, потокового вывода, режима вывода JSON, глубинного вывода и других функций.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основной эндпоинт для вызова DeepSeek API:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

В этом примере используется модель `deepseek-r1`. Доступные модели: `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`.

Пример полного cURL-запроса:

```bash
curl -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/deepseek/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "deepseek-r1", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
