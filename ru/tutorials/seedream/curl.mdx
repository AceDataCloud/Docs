## Введение

Seedream — это AI-сервис обработки изображений от Ace Data Cloud, использующий модель генерации изображений Seedream от ByteDance. Через унифицированный API Ace Data Cloud вы можете быстро вызывать Seedream с помощью cURL для создания изображений по тексту, редактирования изображений, работы с различными разрешениями, управления водяными знаками и других функций.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основной endpoint для вызова Seedream API:

```
POST https://api.acedata.cloud/seedream/images
```

В этом примере используется модель `doubao-seedream-4-0-250828`.  
Доступные модели: `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`, `doubao-seedream-3-0-t2i-250415`, `doubao-seededit-3-0-i2i-250628`.

Пример полного cURL-запроса:

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "белая сиамская кошка сидит на подоконнике", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "белая сиамская кошка сидит на подоконнике", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                         |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
