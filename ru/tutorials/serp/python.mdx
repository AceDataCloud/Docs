## Введение

Google Search — это сервис поиска, предоставляемый Ace Data Cloud, API для поиска Google. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать Google Search на Python и реализовать функции веб-поиска, поиска изображений, новостей, карт, видео и другие.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python версии 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основная конечная точка вызова Google Search API:

```
POST https://api.acedata.cloud/serp/google
```

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/serp/google"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "query": "artificial intelligence latest news",
    "type": "search",
    "number": 10,
    "language": "en",
    "country": "US"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

После успешного вызова API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Расширенное использование

Для API, поддерживающих асинхронные задачи, результат можно получить через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
