## Введение

Google Search — это сервис поиска, предоставляемый Ace Data Cloud, API для поиска Google. С помощью унифицированного API Ace Data Cloud вы можете быстро вызвать Google Search с помощью cURL для выполнения поиска по веб-страницам, изображениям, новостям, картам, видео и другим функциям.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основная конечная точка для вызова Google Search API:

```
POST https://api.acedata.cloud/serp/google
```

Полный пример команды cURL:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Пожалуйста, замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                         |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |

## Следующие шаги

- Перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud) для получения API Token
- Ознакомьтесь с [документацией API](https://docs.acedata.cloud/zh-CN/api-reference) для полного описания параметров
- Изучите [тарифные планы](https://platform.acedata.cloud/services) для информации о стоимости
