## Введение

Wan — это AI видео сервис от Ace Data Cloud, модель генерации видео Wan от Alibaba. Через унифицированный API Ace Data Cloud вы можете быстро вызывать Wan с помощью cURL для создания видео из текста, изображений, видео-референсов, а также для генерации видео в различных разрешениях.

## Предварительные условия

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основной endpoint для вызова Wan API:

```
POST https://api.acedata.cloud/wan/videos
```

В этом примере используется модель `wan2.6-t2v`.
Доступные модели: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Пример полного cURL запроса:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращается JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                        |
|---------------|--------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышен лимит частоты запросов |
| 500           | Внутренняя ошибка сервера      |

## Следующие шаги
