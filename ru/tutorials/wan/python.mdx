## Введение

Wan — это AI видео-сервис от Ace Data Cloud, модель генерации видео Wan от Alibaba. С помощью единого API Ace Data Cloud вы можете быстро интегрировать Wan с помощью Python для создания видео из текста, изображений, референсных видео, а также поддерживать различные разрешения.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python версии 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основная конечная точка для вызова Wan API:

```
POST https://api.acedata.cloud/wan/videos
```

В этом примере используется модель `wan2.6-t2v`.
Доступные модели: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/wan/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "model": "wan2.6-t2v",
    "prompt": "Astronauts shuttle from space to volcano",
    "resolution": "720P"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

При успешном вызове API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Расширенное использование

Для API, поддерживающих асинхронные задачи, результат можно получить через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                         |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов      |
| 500         | Внутренняя ошибка сервера       |
