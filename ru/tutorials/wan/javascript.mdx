## Введение

Wan — это AI видео-сервис от Ace Data Cloud, модель генерации видео Wan от Alibaba. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать Wan с использованием JavaScript для создания видео на основе текста, изображений, референсных видео, а также для генерации видео в различных разрешениях.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная среда браузера

## Базовое использование

Основной эндпоинт для вызова Wan API:

```
POST https://api.acedata.cloud/wan/videos
```

В этом примере используется модель `wan2.6-t2v`. Доступные модели: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/wan/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "model": "wan2.6-t2v",
  "prompt": "Astronauts shuttle from space to volcano",
  "resolution": "720P"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код статуса: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в виде переиспользуемой функции:

```javascript
async function callWan(data) {
  const response = await fetch("https://api.acedata.cloud/wan/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов      |
| 500         | Внутренняя ошибка сервера       |
