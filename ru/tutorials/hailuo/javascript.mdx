## Введение

Hailuo — это AI видео-сервис от Ace Data Cloud, модель генерации видео MiniMax Hailuo. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать Hailuo с помощью JavaScript для создания видео на основе текста, изображений, режиссёрского режима и других функций.

## Предварительные требования

- Аккаунт [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная браузерная среда

## Базовое использование

Основная конечная точка для вызова API Hailuo:

```
POST https://api.acedata.cloud/hailuo/videos
```

В этом примере используется модель `minimax-t2v`.  
Доступные модели: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "model": "minimax-t2v",
  "prompt": "A golden sunset over the ocean waves"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, статус: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обёртка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callHailuo(data) {
  const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                         |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов      |
| 500         | Внутренняя ошибка сервера       |
