## Введение

Seedance — это AI видео-сервис от Ace Data Cloud, модель генерации видео Seedance от ByteDance. Через унифицированный API Ace Data Cloud вы можете быстро интегрировать Seedance с помощью JavaScript для создания видео из текста, изображений, генерации аудио и поддержки различных разрешений.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная браузерная среда

## Базовое использование

Основной endpoint для вызова Seedance API:

```
POST https://api.acedata.cloud/seedance/videos
```

В этом примере используется модель `doubao-seedance-1-0-pro-250528`. Доступные модели включают: `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/seedance/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "doubao-seedance-1-0-pro-250528",
  "content": [
    {
      "type": "text",
      "text": "A kitten yawning --rs 720p --rt 16:9 --dur 5"
    }
  ]
}),
});

const result = await response.json();
console.log(result);
```

Пожалуйста, замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять код состояния ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код состояния: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обёртка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callSeedance(data) {
  const response = await fetch("https://api.acedata.cloud/seedance/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание |
|---------------|----------|
| 401 | Ошибка аутентификации, проверьте API Token |
| 403 | Недостаточно средств или нет доступа |
| 429 | Превышена частота запросов |
| 500 | Внутренняя ошибка сервера |
