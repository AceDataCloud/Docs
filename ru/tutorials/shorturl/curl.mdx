## Введение

Short URL — это инструментальный сервис для создания коротких ссылок, предоставляемый Ace Data Cloud. С помощью единого API Ace Data Cloud вы можете быстро вызывать Short URL через cURL для сокращения URL, настройки пользовательских доменов и других функций.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Установленная среда терминала с cURL

## Базовое использование

Основная конечная точка API Short URL:

```
POST https://api.acedata.cloud/shorturl
```

Пример полного cURL запроса:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                         |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |

## Следующие шаги

- Перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud) для получения API Token
- Ознакомьтесь с [документацией API](https://docs.acedata.cloud/zh-CN/api-reference) для полного описания параметров
- Изучите [тарифные планы](https://platform.acedata.cloud/services) для информации о стоимости
