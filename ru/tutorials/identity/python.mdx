## Введение

Identity — это сервис аутентификации, предоставляемый Ace Data Cloud, для проверки подлинности удостоверений личности, банковских карт и номеров телефонов. С помощью единого API Ace Data Cloud вы можете быстро интегрировать Identity в Python для реализации функций OCR удостоверения личности, проверки удостоверения личности, проверки банковской карты, проверки номера телефона и других.

## Предварительные требования

- Аккаунт [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основной конечной точкой для вызова Identity API является:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/identity/idcard/ocr"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image_url": "https://example.com/idcard-front.jpg"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

После успешного вызова API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Продвинутое использование

Для API, поддерживающих асинхронные задачи, результат можно получить через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|----------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов       |
| 500           | Внутренняя ошибка сервера        |
