## Введение

Veo — это AI видео-сервис от Ace Data Cloud, использующий модель генерации видео Google Veo. Через единый API Ace Data Cloud вы можете быстро вызывать Veo с помощью cURL для создания видео из текста, изображений, с разрешением 4K, в различных соотношениях сторон и других функций.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основной endpoint для вызова Veo API:

```
POST https://api.acedata.cloud/veo/videos
```

В этом примере используется модель `veo3`. Доступные модели: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Пример полного cURL-запроса:

```bash
curl -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}'
```

Замените `YOUR_API_TOKEN` на реальный токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращается JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать утилиту jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/veo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A coffee mug rotating slowly on a marble counter", "model": "veo3"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
