## Введение

Veo — это AI видео-сервис от Ace Data Cloud, использующий модель генерации видео Google Veo. Через единый API Ace Data Cloud вы можете быстро интегрировать Veo с помощью JavaScript для создания видео из текста, изображений, с разрешением 4K и различными соотношениями сторон.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная браузерная среда

## Базовое использование

Основная конечная точка вызова Veo API:

```
POST https://api.acedata.cloud/veo/videos
```

В этом примере используется модель `veo3`. Доступные модели: `veo2`, `veo2-fast`, `veo3`, `veo3-fast`, `veo31`, `veo31-fast`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/veo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "text2video",
  "prompt": "A coffee mug rotating slowly on a marble counter",
  "model": "veo3"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять код состояния ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код состояния: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callVeo(data) {
  const response = await fetch("https://api.acedata.cloud/veo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|----------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышен лимит частоты запросов  |
| 500           | Внутренняя ошибка сервера        |
