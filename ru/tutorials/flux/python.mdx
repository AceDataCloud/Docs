## Введение

Flux — это AI-сервис обработки изображений от Ace Data Cloud, модель генерации изображений Black Forest Labs Flux. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать Flux на Python для создания изображений по тексту, редактирования изображений, использования различных моделей и настройки размеров.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Основное использование

Основной эндпоинт для вызова Flux API:

```
POST https://api.acedata.cloud/flux/images
```

В этом примере используется модель `flux-pro-1.1`. Доступные модели: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/flux/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat sitting on a windowsill",
    "model": "flux-pro-1.1",
    "size": "1024x1024"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

При успешном вызове API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Расширенное использование

Для API с поддержкой асинхронных задач можно получить результат через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|----------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов       |
| 500         | Внутренняя ошибка сервера        |
