## Введение

Flux — это AI-сервис изображений, предоставляемый Ace Data Cloud, использующий модель генерации изображений Black Forest Labs Flux. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать Flux с использованием JavaScript для создания изображений по тексту, редактирования изображений, работы с различными моделями и настройки размеров.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная браузерная среда

## Базовое использование

Основной эндпоинт для вызова Flux API:

```
POST https://api.acedata.cloud/flux/images
```

В этом примере используется модель `flux-pro-1.1`. Доступные модели: `flux-dev`, `flux-pro`, `flux-pro-1.1`, `flux-pro-1.1-ultra`, `flux-kontext-pro`, `flux-kontext-max`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/flux/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A white siamese cat sitting on a windowsill",
  "model": "flux-pro-1.1",
  "size": "1024x1024"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код статуса: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callFlux(data) {
  const response = await fetch("https://api.acedata.cloud/flux/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов      |
| 500         | Внутренняя ошибка сервера       |
