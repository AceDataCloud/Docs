## Введение

Kling — это AI видео-сервис от Ace Data Cloud, модель для генерации видео KuaiShou KeLing. Через единый API Ace Data Cloud вы можете быстро интегрировать Kling с помощью Python для создания видео на основе текста, изображений, продолжения видео, с разной длительностью и соотношением сторон.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основная конечная точка для вызова Kling API:

```
POST https://api.acedata.cloud/kling/videos
```

В этом примере используется модель `kling-v2-5-turbo`.  
Доступные модели: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A white cat walking in the snow",
    "model": "kling-v2-5-turbo",
    "duration": 5,
    "aspect_ratio": "16:9"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

При успешном вызове API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Продвинутое использование

Для API, поддерживающих асинхронные задачи, результат можно получить через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                         |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов      |
| 500         | Внутренняя ошибка сервера       |
