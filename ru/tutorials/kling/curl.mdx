## Введение

Kling — это AI видео-сервис от Ace Data Cloud, модель для генерации видео на платформе Kuaishou KeLing. Через единый API Ace Data Cloud вы можете быстро вызвать Kling с помощью cURL для создания видео из текста, создания видео из изображений, продолжения видео, с различной длительностью и соотношением сторон.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основная конечная точка для вызова API Kling:

```
POST https://api.acedata.cloud/kling/videos
```

В этом примере используется модель `kling-v2-5-turbo`.  
Доступные модели: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-video-o1`.

Пример полного cURL запроса:

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}'
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращается JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "prompt": "A white cat walking in the snow", "model": "kling-v2-5-turbo", "duration": 5, "aspect_ratio": "16:9"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
