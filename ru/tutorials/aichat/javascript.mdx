## Введение

AI Chat — это сервис AI-чата, предоставляемый Ace Data Cloud, поддерживающий многомодельные AI-разговоры. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать AI Chat на JavaScript, реализуя поддержку нескольких моделей, состояние диалога, предустановленные роли и другие функции.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная браузерная среда

## Базовое использование

Основная конечная точка для вызова AI Chat API:

```
POST https://api.acedata.cloud/aichat/conversations
```

В этом примере используется модель `gpt-4o`.
Доступные модели: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/aichat/conversations", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gpt-4o",
  "question": "什么是人工智能？",
  "stateful": true
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, статус: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callAIChat(data) {
  const response = await fetch("https://api.acedata.cloud/aichat/conversations", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|----------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышен лимит частоты запросов  |
| 500           | Внутренняя ошибка сервера        |
