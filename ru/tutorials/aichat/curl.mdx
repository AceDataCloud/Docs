## Введение

AI Chat — это сервис AI-чата, предоставляемый Ace Data Cloud, поддерживающий многомодельный AI-диалог. С помощью унифицированного API Ace Data Cloud вы можете быстро вызывать AI Chat через cURL, реализуя поддержку нескольких моделей, сохранение состояния диалога, предустановленные роли и другие функции.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основной эндпоинт для вызова AI Chat API:

```
POST https://api.acedata.cloud/aichat/conversations
```

В этом примере используется модель `gpt-4o`.
Доступные модели: `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3`.

Пример полного cURL-запроса:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
