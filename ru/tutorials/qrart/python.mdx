## Введение

QR Art — это AI-сервис изображений от Ace Data Cloud для генерации художественных QR-кодов. С помощью единого API Ace Data Cloud вы можете быстро интегрировать QR Art на Python и создавать QR-коды для ссылок, текста, использовать предустановленные стили и настраиваемые параметры.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основная конечная точка API QR Art:

```
POST https://api.acedata.cloud/qrart/generate
```

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/qrart/generate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "type": "link",
    "content": "https://platform.acedata.cloud",
    "prompt": "sunset ocean waves",
    "preset": "neon-mech"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

После успешного вызова API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус-код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Продвинутое использование

Для API с поддержкой асинхронных задач можно получать результат через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|----------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов       |
| 500         | Внутренняя ошибка сервера        |
