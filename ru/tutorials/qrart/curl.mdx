## Введение

QR Art — это AI-сервис изображений от Ace Data Cloud, генерирующий художественные QR-коды с помощью ИИ. Через унифицированный API Ace Data Cloud вы можете быстро вызывать QR Art с помощью cURL для создания QR-кодов со ссылками, текстом, предустановленными стилями и настраиваемыми параметрами.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Установленная среда терминала с cURL

## Базовое использование

Основная конечная точка API QR Art:

```
POST https://api.acedata.cloud/qrart/generate
```

Полный пример команды cURL:

```bash
curl -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}'
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматированного вывода:

```bash
curl -s -X POST https://api.acedata.cloud/qrart/generate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"type": "link", "content": "https://platform.acedata.cloud", "prompt": "sunset ocean waves", "preset": "neon-mech"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
