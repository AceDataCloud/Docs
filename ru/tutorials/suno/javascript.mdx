## Введение

Suno — это AI-аудиосервис от Ace Data Cloud для генерации музыки с помощью Suno AI. Через унифицированный API Ace Data Cloud вы можете быстро интегрировать Suno с помощью JavaScript для создания музыки по тексту, пользовательских текстов песен, продолжения песен, каверов, разделения вокала, генерации текстов и других функций.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная среда браузера

## Основное использование

Основная конечная точка вызова Suno API:

```
POST https://api.acedata.cloud/suno/audios
```

В этом примере используется модель `chirp-v5`.  
Доступные модели: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/suno/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "prompt": "A cheerful pop song about summer vacation",
  "model": "chirp-v5",
  "custom": false
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять код состояния ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код состояния: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callSuno(data) {
  const response = await fetch("https://api.acedata.cloud/suno/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|----------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов       |
| 500           | Внутренняя ошибка сервера        |
