## Введение

Claude — это AI-чат-сервис, предоставляемый Ace Data Cloud, основанный на серии больших языковых моделей Anthropic Claude. Через унифицированный API Ace Data Cloud вы можете быстро вызывать Claude с помощью cURL, реализуя многоходовые диалоги, системные подсказки, потоковый вывод, режим вывода JSON и другие функции.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основной эндпоинт для вызова Claude API:

```
POST https://api.acedata.cloud/v1/chat/completions
```

В этом примере используется модель `claude-sonnet-4-6`.  
Доступные модели включают: `claude-sonnet-4-6`, `claude-opus-4-5-20251101`, `claude-3-5-sonnet`.

Полный пример команды cURL:

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "claude-sonnet-4-6", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                       |
|---------------|-------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов    |
| 500           | Внутренняя ошибка сервера     |

## Следующие шаги

- Перейдите в [Ace Data Cloud консоль](https://platform.acedata.cloud) для получения API Token  
- Ознакомьтесь с [документацией API](https://docs.acedata.cloud/zh-CN/api-reference) для полного описания параметров  
- Изучите [тарифные планы](https://platform.acedata.cloud/services) для информации о стоимости
