## Введение

Nano Banana — это AI-сервис обработки изображений от Ace Data Cloud, основанный на сервисе генерации изображений Gemini. Через унифицированный API Ace Data Cloud вы можете быстро вызывать Nano Banana с помощью cURL для создания изображений по тексту, редактирования изображений, работы с разными соотношениями сторон и высокого разрешения.

## Предварительные условия

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Установленная среда с cURL

## Основное использование

Основной эндпоинт для вызова Nano Banana API:

```
POST https://api.acedata.cloud/nano-banana/images
```

В этом примере используется модель `nano-banana-2`.
Доступные модели: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Пример полного cURL-запроса:

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращается JSON-данные, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat", "model": "nano-banana-2", "aspect_ratio": "1:1"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов       |
| 500           | Внутренняя ошибка сервера        |
