## Введение

Nano Banana — это AI-сервис обработки изображений от Ace Data Cloud, основанный на сервисе генерации изображений Gemini. Через единый API Ace Data Cloud вы можете быстро интегрировать Nano Banana с помощью Python для создания изображений по тексту, редактирования изображений, работы с различными соотношениями сторон и высокого разрешения.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основной эндпоинт для вызова Nano Banana API:

```
POST https://api.acedata.cloud/nano-banana/images
```

В этом примере используется модель `nano-banana-2`.
Доступные модели: `nano-banana`, `nano-banana-2`, `nano-banana-pro`.

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat",
    "model": "nano-banana-2",
    "aspect_ratio": "1:1"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

После успешного вызова API возвращает данные в формате JSON. Рекомендуется проверить HTTP статус-код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Расширенное использование

Для API, поддерживающих асинхронные задачи, результат можно получить через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                              |
|---------------|-------------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов          |
| 500           | Внутренняя ошибка сервера           |
