## Введение

Sora — это AI видео-сервис от Ace Data Cloud, модель генерации видео OpenAI Sora. Через унифицированный API Ace Data Cloud вы можете быстро вызывать Sora с помощью cURL для создания видео из текста, с различной длительностью, альбомной или портретной ориентацией, управлением персонажами, использованием эталонных изображений и другими функциями.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Базовое использование

Основной эндпоинт для вызова Sora API:

```
POST https://api.acedata.cloud/sora/videos
```

В этом примере используется модель `sora-2`. Доступные модели: `sora-2`, `sora-2-pro`.

Пример полного cURL запроса:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращается JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                      |
|---------------|------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов   |
| 500           | Внутренняя ошибка сервера    |

## Следующие шаги
