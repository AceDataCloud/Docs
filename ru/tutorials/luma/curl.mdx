## Введение

Luma — это AI видео-сервис от Ace Data Cloud, обеспечивающий генерацию видео с помощью Luma Dream Machine. Через унифицированный API Ace Data Cloud вы можете быстро вызывать Luma с помощью cURL для создания видео на основе текста, изображений, продолжения видео, управления начальным и конечным кадрами, создания циклических видео и других функций.

## Предварительные условия

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Установленная среда терминала с cURL

## Основное использование

Основной endpoint для вызова Luma API:

```
POST https://api.acedata.cloud/luma/videos
```

Полный пример команды cURL:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                         |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
