## Введение

Luma — это AI видео-сервис от Ace Data Cloud, обеспечивающий генерацию видео с помощью Luma Dream Machine. Через унифицированный API Ace Data Cloud вы можете быстро интегрировать Luma с помощью JavaScript для создания видео на основе текста, изображений, продолжения видео, управления начальным и конечным кадрами, циклического воспроизведения и других функций.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная среда браузера

## Основное использование

Основная конечная точка вызова Luma API:

```
POST https://api.acedata.cloud/luma/videos
```

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/luma/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "Astronauts shuttle from space to volcano",
  "action": "generate",
  "enhancement": true
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять код состояния ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код состояния: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в виде переиспользуемой функции:

```javascript
async function callLuma(data) {
  const response = await fetch("https://api.acedata.cloud/luma/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов       |
| 500           | Внутренняя ошибка сервера        |
