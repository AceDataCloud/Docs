## Введение

Fish TTS — это AI аудиосервис от Ace Data Cloud, сервис синтеза речи Fish. Через единый API Ace Data Cloud вы можете быстро интегрировать Fish TTS с помощью JavaScript для преобразования текста в речь, использования различных голосов и настройки звука.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная среда браузера

## Базовое использование

Основной эндпоинт для вызова Fish TTS API:

```
POST https://api.acedata.cloud/fish/audios
```

В этом примере используется модель `fish-tts`.
Доступные модели: `fish-tts`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/fish/audios", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "speech",
  "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务",
  "voice_id": "d7900c21663f485ab63ebdb7e5905036",
  "model": "fish-tts"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, код статуса: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить вызов в переиспользуемую функцию:

```javascript
async function callFishTTS(data) {
  const response = await fetch("https://api.acedata.cloud/fish/audios", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|----------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов       |
| 500         | Внутренняя ошибка сервера        |
