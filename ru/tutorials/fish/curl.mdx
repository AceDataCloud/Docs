## Введение

Fish TTS — это AI аудиосервис от Ace Data Cloud, служба синтеза речи Fish. С помощью унифицированного API Ace Data Cloud вы можете быстро вызвать Fish TTS через cURL для преобразования текста в речь, использования различных голосов и настройки звука.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основная конечная точка API Fish TTS:

```
POST https://api.acedata.cloud/fish/audios
```

В этом примере используется модель `fish-tts`.  
Доступные модели: `fish-tts`.

Пример полного cURL-запроса:

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

При успешном вызове возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматирования вывода:

```bash
curl -s -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                         |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |

## Следующие шаги

- Ознакомьтесь с [документацией API](https://docs.acedata.cloud/zh-CN/api-reference) для полного описания параметров
