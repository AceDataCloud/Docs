## Введение

Localization — это инструментальный сервис от Ace Data Cloud для AI-перевода и локализации. С помощью единого API Ace Data Cloud вы можете быстро интегрировать Localization с использованием Python, реализуя перевод Markdown, JSON, поддержку 18 языков и сохранение формата.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Основное использование

Основной эндпоинт для вызова Localization API:

```
POST https://api.acedata.cloud/localization/translate
```

В этом примере используется модель `gpt-4`.
Доступные модели: `gpt-3.5`, `gpt-4`.

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/localization/translate"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "input": "# 欢迎使用\n\n这是一段示例文本。",
    "locale": "en",
    "extension": "md",
    "model": "gpt-4"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

При успешном вызове API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Продвинутое использование

Для API с поддержкой асинхронных задач можно получить результат через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результат будет отправлен на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов       |
| 500         | Внутренняя ошибка сервера        |
