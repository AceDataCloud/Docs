## Введение

Localization — это инструментальная служба, предоставляемая Ace Data Cloud, для AI-перевода и локализации. С помощью единого API Ace Data Cloud вы можете быстро интегрировать Localization с использованием JavaScript для перевода Markdown, JSON, поддержки 18 языков и сохранения формата.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная браузерная среда

## Основное использование

Основной endpoint для вызова Localization API:

```
POST https://api.acedata.cloud/localization/translate
```

В этом примере используется модель `gpt-4`. Доступные модели: `gpt-3.5`, `gpt-4`.

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/localization/translate", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "input": "# 欢迎使用\n\n这是一段示例文本。",
  "locale": "en",
  "extension": "md",
  "model": "gpt-4"
}),
});

const result = await response.json();
console.log(result);
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, статус: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить в переиспользуемую функцию:

```javascript
async function callLocalization(data) {
  const response = await fetch("https://api.acedata.cloud/localization/translate", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                         |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов      |
| 500           | Внутренняя ошибка сервера       |
