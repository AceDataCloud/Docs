## Введение

ADSL HTTP Proxy — это сервис прокси-серверов, предоставляемый Ace Data Cloud, для извлечения динамических IP-адресов ADSL. С помощью единого API Ace Data Cloud вы можете быстро интегрировать ADSL HTTP Proxy на Python, реализуя функции HTTP/SOCKS прокси, мультиоператорность, мультиобласть, настраиваемую длительность, белый список IP и другие возможности.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Среда Python 3.7 и выше
- Установка библиотеки requests: `pip install requests`

## Базовое использование

Основная конечная точка API ADSL HTTP Proxy:

```
POST https://api.acedata.cloud/adsl/extract
```

Полный пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/adsl/extract"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "number": 5,
    "type": "http",
    "duration": 300,
    "province": "广东",
    "isp": "电信"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Замените `YOUR_API_TOKEN` на ваш реальный токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

После успешного вызова API возвращает данные в формате JSON. Рекомендуется проверять HTTP статус код:

```python
if response.status_code == 200:
    result = response.json()
    print("Вызов успешен:", result)
else:
    print(f"Вызов не удался, статус код: {response.status_code}")
    print(response.text)
```

## Продвинутое использование

Для API, поддерживающих асинхронные задачи, можно получать результаты через callback URL:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Результаты будут отправлены на ваш сервер через callback URL
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                          |
|---------------|---------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов       |
| 500           | Внутренняя ошибка сервера        |
