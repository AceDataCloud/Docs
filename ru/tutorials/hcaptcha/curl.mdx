## Введение

hCaptcha — это сервис капчи, предоставляемый Ace Data Cloud. Решение hCaptcha позволяет с помощью единого API Ace Data Cloud быстро вызывать hCaptcha через cURL, реализуя получение токена hCaptcha, распознавание изображений hCaptcha и другие функции.

## Предварительные требования

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Терминальная среда с установленным cURL

## Основное использование

Основная конечная точка API hCaptcha:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Полный пример команды cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Пример ответа

После успешного вызова возвращаются данные в формате JSON, например:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Обработка ответа с помощью jq

Рекомендуется использовать инструмент jq для форматированного вывода:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Обработка ошибок

Распространённые коды ошибок:

| Код состояния | Описание                     |
|---------------|------------------------------|
| 401           | Ошибка аутентификации, проверьте API Token |
| 403           | Недостаточно средств или нет доступа |
| 429           | Превышена частота запросов   |
| 500           | Внутренняя ошибка сервера    |

## Следующие шаги
