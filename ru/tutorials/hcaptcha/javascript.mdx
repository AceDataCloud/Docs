## Введение

hCaptcha — это сервис капчи, предоставляемый Ace Data Cloud, решение hCaptcha. С помощью унифицированного API Ace Data Cloud вы можете быстро интегрировать hCaptcha на JavaScript, реализовать получение токена hCaptcha, распознавание изображений hCaptcha и другие функции.

## Предварительные условия

- Наличие аккаунта [Ace Data Cloud](https://platform.acedata.cloud) и получение API Token
- Node.js 18+ или современная среда браузера

## Базовое использование

Основная конечная точка для вызова API hCaptcha:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Полный пример кода на JavaScript:

```javascript
const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2",
  "website_url": "https://accounts.hcaptcha.com/demo"
}),
});

const result = await response.json();
console.log(result);
```

Пожалуйста, замените `YOUR_API_TOKEN` на фактический токен, полученный на платформе Ace Data Cloud.

## Обработка ответа

Рекомендуется проверять статус ответа и обрабатывать ошибки:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("Вызов успешен:", result);
} else {
  console.error(`Вызов не удался, статус: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Обертка для Node.js

Рекомендуется оформить в виде переиспользуемой функции:

```javascript
async function callhCaptcha(data) {
  const response = await fetch("https://api.acedata.cloud/captcha/token/hcaptcha", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## Обработка ошибок

Распространённые коды ошибок:

| Код статуса | Описание                          |
|-------------|---------------------------------|
| 401         | Ошибка аутентификации, проверьте API Token |
| 403         | Недостаточно средств или нет доступа |
| 429         | Превышена частота запросов      |
| 500         | Внутренняя ошибка сервера       |
