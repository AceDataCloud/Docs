[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный Anthropic, который позволяет AI-моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью ShortURL MCP Server от AceData Cloud вы можете напрямую создавать короткие ссылки в AI-клиентах, таких как Claude Desktop, VS Code, Cursor и других.

## Обзор функций

ShortURL MCP Server предоставляет следующие основные возможности:

- **Укорачивание одной ссылки** — преобразование длинного URL в короткую и удобную для обмена ссылку
- **Пакетное укорачивание ссылок** — одновременное укорачивание нескольких URL (до 10 штук)
- **Руководство по использованию** — получение полного описания и лучших практик
- **Информация об API** — просмотр деталей API и описания кодов ошибок

## Предварительная подготовка

Перед использованием необходимо получить API Token AceData Cloud:

1. Зарегистрируйтесь или войдите на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдите на страницу [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Нажмите «Acquire» для получения API Token (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: установка через pip (рекомендуется)

```bash
pip install mcp-shorturl
```

### Способ 2: установка из исходников

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

После установки можно запускать сервис командой `mcp-shorturl`.

## Использование в Claude Desktop

Отредактируйте конфигурационный файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Если используете `uvx` (не требует предварительной установки пакетов):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Ваш API Token"
      }
    }
  }
}
```

Сохраните изменения и перезапустите Claude Desktop — теперь можно использовать инструменты ShortURL в диалогах.

## Использование в VS Code / Cursor

Создайте файл `.vscode/mcp.json` в корне проекта:

      "env": {

## Список доступных инструментов

| Название инструмента       | Описание                                  |
|----------------------------|-------------------------------------------|
| `shorturl_create`          | Укорачивание одного URL                    |
| `shorturl_batch_create`    | Пакетное укорачивание нескольких URL (до 10) |
| `shorturl_get_usage_guide` | Получение полного руководства по использованию |
| `shorturl_get_api_info`    | Получение информации об API и сервисе     |

## Примеры использования

После настройки вы можете напрямую вызывать эти функции в AI-клиенте с помощью естественного языка, например:

- «Помоги укоротить эту ссылку»
- «Укороти пакет из 5 URL»
- «Создай короткую ссылку для обмена»
