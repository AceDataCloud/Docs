[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный Anthropic, который позволяет AI-моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью Seedream MCP Server от AceData Cloud вы можете напрямую использовать генерацию и редактирование AI-изображений Seedream от ByteDance в клиентах AI, таких как Claude Desktop, VS Code, Cursor и других.

## Обзор функций

Seedream MCP Server предоставляет следующие основные возможности:

- **Генерация изображений из текста** — создание высококачественных изображений по текстовым подсказкам (поддерживаются китайский и английский языки)
- **Редактирование изображений** — изменение стиля, фона, свойств существующих изображений
- **Виртуальная примерка одежды** — наложение одежды на фотографии людей
- **Поддержка нескольких моделей** — Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I и др.
- **Различные разрешения** — поддержка 1K, 2K, 4K и адаптивных разрешений
- **Управление seed-параметром** — воспроизводимые результаты генерации
- **Запросы задач** — мониторинг прогресса и получение результатов

## Предварительные требования

Для использования необходимо получить API Token AceData Cloud:

1. Зарегистрируйтесь или войдите на [AceData Cloud Platform](https://platform.acedata.cloud)
2. Перейдите на страницу [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Нажмите «Acquire» для получения API Token (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: установка через pip (рекомендуется)

```bash
pip install mcp-seedream-pro
```

### Способ 2: установка из исходников

```bash
git clone https://github.com/AceDataCloud/MCPSeedream.git
cd MCPSeedream
pip install -e .
```

После установки запустите сервис командой `mcp-seedream-pro`.

## Использование в Claude Desktop

Отредактируйте конфигурационный файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Если используете `uvx` (без необходимости предварительной установки пакетов):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сохраните изменения и перезапустите Claude Desktop, после чего можно использовать инструменты Seedream в диалогах.

## Список доступных инструментов

| Название инструмента           | Описание                         |
|-------------------------------|---------------------------------|
| `seedream_generate_image`      | Генерация изображения по тексту |
| `seedream_edit_image`          | Редактирование или изменение изображения |
| `seedream_get_task`            | Запрос статуса одной задачи     |
| `seedream_get_tasks_batch`     | Пакетный запрос статусов задач  |
| `seedream_list_models`         | Список всех доступных моделей и их возможностей |
| `seedream_list_sizes`          | Список доступных размеров и разрешений изображений |

## Примеры использования

- «Измени фон этой фотографии на звездное небо»
- «Сгенерируй 4K портрет высокого качества с Seedream v4.5»
- «Виртуально примерить эту одежду на фотографию»
