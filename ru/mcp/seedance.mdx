[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный Anthropic, который позволяет AI-моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью Seedance MCP Server от AceData Cloud вы можете напрямую использовать Seedance от ByteDance для генерации AI-видео в клиентах Claude Desktop, VS Code, Cursor и других.

## Обзор возможностей

Seedance MCP Server предоставляет следующие ключевые функции:

- **Генерация видео из текста** — создание высококачественного видео по текстовому описанию
- **Генерация видео из изображения** — создание видео с опорой на изображение (первый кадр, последний кадр, референс и др.)
- **Поддержка нескольких моделей** — Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite и другие
- **Различные разрешения** — поддержка 480p, 720p, 1080p
- **Различные соотношения сторон** — 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 и др.
- **Гибкая длительность** — видео длительностью от 2 до 12 секунд
- **Генерация аудио** — некоторые модели поддерживают одновременную генерацию аудио
- **Запрос статуса задач** — мониторинг прогресса и получение результатов

## Предварительная подготовка

Для использования необходимо получить API Token AceData Cloud:

1. Зарегистрируйтесь или войдите на [AceData Cloud платформу](https://platform.acedata.cloud)
2. Перейдите на страницу [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos)
3. Нажмите «Acquire» для получения API Token (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: установка через pip (рекомендуется)

```bash
pip install mcp-seedance
```

### Способ 2: установка из исходников

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

После установки запустите сервис командой `mcp-seedance`.

## Использование в Claude Desktop

Отредактируйте конфигурационный файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Если используете `uvx` (без необходимости предварительной установки пакетов):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сохраните изменения и перезапустите Claude Desktop — теперь Seedance доступен в диалогах.

## Список доступных инструментов

| Название инструмента               | Описание                             |
|----------------------------------|------------------------------------|
| `seedance_generate_video`         | Генерация видео по текстовому описанию |
| `seedance_generate_video_from_image` | Генерация видео с опорой на изображение |
| `seedance_get_task`               | Запрос статуса одной задачи         |
| `seedance_get_tasks_batch`        | Массовый запрос статусов задач      |
| `seedance_list_models`            | Список всех доступных моделей и их возможностей |
| `seedance_list_resolutions`       | Список доступных разрешений и соотношений сторон |
| `seedance_list_actions`            | Список всех доступных инструментов и примеры рабочих процессов |

## Примеры использования

После настройки вы можете вызывать функции естественным языком в AI-клиентах, например:

- «Помоги сгенерировать видео с таймлапсом городской улицы с помощью Seedance»
- «Используй эту фотографию как первый кадр и создай видео длительностью 8 секунд»
- «Сгенерируй короткое видео 1080p в вертикальном формате 9:16»
- «Создай видео с аудио на модели Seedance 1.5 Pro»
