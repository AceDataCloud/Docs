[MCP（Model Context Protocol）](https://modelcontextprotocol.io) — это протокол контекста модели, представленный Anthropic, который позволяет моделям ИИ (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированные интерфейсы. Через Seedance MCP Server, предоставляемый AceData Cloud, вы можете напрямую использовать ByteDance Seedance для генерации AI-видео в таких AI-клиентах, как Claude Desktop, VS Code, Cursor и других.

## Обзор функций

Seedance MCP Server предоставляет следующие ключевые функции:

- **Генерация видео по тексту** — создание высококачественных видео с помощью текстовых промптов
- **Генерация видео по изображению** — создание видео с использованием изображения в качестве референса (первый кадр, последний кадр, референсное изображение и другие режимы)
- **Поддержка нескольких моделей** — поддерживаются Seedance 1.x, 1.5, 2.0 и 2.5
- **Несколько разрешений** — поддерживаются 480p, 720p, 1080p, некоторые модели поддерживают 4k
- **Различные соотношения сторон** — поддерживаются 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 и adaptive
- **Гибкая длительность** — в зависимости от модели поддерживается 2–30 секунд или автоматическая длительность
- **Мультимодальное видео** — поддерживаются генерация аудио, референсные аудио/видео, а также редактирование и продление видео в 2.5
- **Запрос задач** — мониторинг прогресса генерации и получение результатов

## Рекомендуется: OAuth-авторизация с использованием размещённого MCP

Добавьте адрес сервера в клиентах, поддерживающих удалённый MCP OAuth:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Выберите подключение или вход, войдите в Ace Data Cloud, просмотрите разрешения и авторизуйте, затем включите инструменты. Этот путь не требует предварительного создания или копирования API Token. Сервис уже поддерживает OAuth discovery, динамическую регистрацию клиентов (DCR) и S256 PKCE; DCR регистрирует клиента, пользователю всё равно необходимо войти и авторизоваться, API тарифицируется как обычно.

| Клиент                            | Способ подключения и условия                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Веб-версия Claude или версия Desktop, предоставляющая удалённые коннекторы | Добавьте указанный выше адрес в интерфейсе коннекторов и авторизуйте; доступ зависит от версии и тарифа. Не записывайте удалённую HTTP-конфигурацию в локальный файл конфигурации stdio.                      |
| VS Code с поддержкой нативного удалённого MCP OAuth     | Выполните **MCP: Add Server**, выберите HTTP, введите адрес и войдите по подсказкам; специальное расширение AceDataCloud использует отдельную настройку API Key. |
| Другие клиенты                          | Убедитесь, что текущая версия поддерживает удалённые HTTP, OAuth/DCR, и используйте инструкции по конфигурации этого клиента. Форматы файлов конфигурации нельзя использовать взаимозаменяемо между разными клиентами.                     |

## Альтернативный путь с API Token

Для локального stdio, самостоятельного хостинга или клиентов, не поддерживающих удалённый OAuth, используется API Token. Войдите на [платформу Ace Data Cloud](https://platform.acedata.cloud), выберите сервис и создайте API-учётные данные с необходимыми разрешениями. Сохраните Token в настройках учётных данных клиента или в локальных переменных окружения, не помещайте его в URL, содержимое чата или репозиторий. Конфигурацию HTTP Header для разных клиентов следует заполнять согласно инструкциям для их версий.

Установка MCP с открытым исходным кодом или завершение авторизации не означает получение бесплатных квот и не гарантирует время генерации или права на коммерческое использование. Перед генерацией проверьте текущие цены сервиса, баланс и применимые условия.

## Способ второй: локальный запуск (установка pip / uvx)

Если вам необходимы локальный stdio, пользовательский код или самостоятельный хостинг, вы можете запустить MCP Server локально. Для генерации по-прежнему требуется подключение к интернету для вызова API, это не офлайн-инференс.

### Установка

Установка через pip (рекомендуется):

```bash
pip install mcp-seedance
```

Или установка из исходного кода:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

После завершения установки можно использовать команду `mcp-seedance` для запуска сервиса.

### Использование в Claude Desktop（локально）

Отредактируйте файл конфигурации Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

При использовании `uvx` (без предварительной установки пакета):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

После сохранения конфигурации перезапустите Claude Desktop, чтобы изменения вступили в силу.

### Использование в VS Code（локально）

Создайте `.vscode/mcp.json` в корневом каталоге проекта:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Или используйте `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Для других локальных клиентов заполните command, args и env согласно инструкциям по конфигурации stdio для их текущей версии; не используйте конфигурацию VS Code напрямую в качестве универсального формата.

## Проверка результатов и распространённые ошибки

Попросите клиента создать простое видео, сохраните номер задачи и запрашивайте ту же задачу до успешного конечного состояния, затем откройте или воспроизведите финальную ссылку. Успешное подключение, загрузка списка инструментов, HTTP 200, номер задачи и предварительный просмотр во время обработки не означают наличия конечного результата.

При 401 войдите снова или проверьте Token и разрешения; при недостатке баланса проверьте биллинг; во время обработки задачи продолжайте выполнять запросы; при окончательной ошибке прочитайте ошибку и затем решите, повторять ли попытку, поскольку новая генерация может тарифицироваться повторно.

## Список доступных инструментов

| Название инструмента                                  | Описание             |
| ------------------------------------ | -------------- |
| `seedance_generate_video`            | Генерация видео с помощью текстового промпта    |
| `seedance_generate_video_from_image` | Генерация видео с использованием изображения в качестве референса     |
| `seedance_get_task`                  | Запрос статуса одной задачи       |
| `seedance_get_tasks_batch`           | Пакетный запрос статусов задач       |
| `seedance_list_models`               | Вывод всех доступных моделей и их возможностей   |
| `seedance_list_resolutions`          | Вывод доступных разрешений и соотношений сторон   |
| `seedance_list_actions`              | Вывод всех доступных инструментов и примеров рабочих процессов |

## Примеры использования

После завершения настройки вы можете напрямую вызывать эти функции на естественном языке в AI-клиенте, например:

- «Создай короткое вертикальное видео 1080p в формате 9:16»
- «Используй модель Seedance 1.5 Pro для создания видео с аудио»
