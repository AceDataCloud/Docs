[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный Anthropic, который позволяет AI-моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью Veo MCP Server от AceData Cloud вы можете напрямую использовать Google Veo для генерации AI-видео в клиентах Claude Desktop, VS Code, Cursor и других.

## Обзор функций

Veo MCP Server предоставляет следующие основные возможности:

- **Генерация видео из текста** — создание высококачественного видео по текстовому запросу
- **Генерация видео из изображения** — создание видео на основе изображения
- **Поддержка нескольких моделей** — поддержка моделей veo3, veo2, veo31-fast-ingredients и других
- **Различные разрешения** — поддержка форматов вывода 4K, 1080p, GIF и др.
- **Различные соотношения сторон** — поддержка пропорций 16:9, 9:16 и др.
- **Апгрейд до 1080p** — повышение качества уже сгенерированного видео до 1080p
- **Запрос состояния задач** — мониторинг прогресса генерации и получение результатов

## Предварительные требования

Перед использованием необходимо получить API Token AceData Cloud:

1. Зарегистрируйтесь или войдите на [AceData Cloud Platform](https://platform.acedata.cloud)
2. Перейдите на страницу [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Нажмите «Acquire» для получения API Token (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: установка через pip (рекомендуется)

```bash
pip install mcp-veo
```

### Способ 2: установка из исходников

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

После установки можно запускать сервис командой `mcp-veo`.

## Использование в Claude Desktop

Отредактируйте конфигурационный файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Если используете `uvx` (не требует предварительной установки пакетов):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сохраните изменения и перезапустите Claude Desktop — теперь вы сможете использовать инструменты Veo в диалогах.

## Использование в VS Code / Cursor

Создайте файл `.vscode/mcp.json` в корне проекта:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Или с использованием `uvx`:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Список доступных инструментов

| Название инструмента      | Описание                          |
|--------------------------|----------------------------------|
| `veo_text_to_video`       | Генерация видео по текстовому запросу |
| `veo_image_to_video`      | Генерация видео на основе изображения |
| `veo_get_1080p`           | Апгрейд видео до 1080p            |
| `veo_get_task`            | Запрос статуса одной задачи       |
| `veo_get_tasks_batch`     | Массовый запрос статусов задач    |

## Примеры использования

После настройки вы можете напрямую вызывать эти функции в AI-клиентах с помощью естественного языка, например:

- «Помоги мне сгенерировать видео с таймлапсом звездного неба с помощью Veo»
- «Сделай 4K видео на основе этой фотографии пейзажа»
- «Создай короткое вертикальное видео с соотношением 9:16»
- «Повыши качество этого видео до 1080p»
