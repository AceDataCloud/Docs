[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный Anthropic, который позволяет AI моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью Veo MCP Server, предоставляемого AceData Cloud, вы можете напрямую использовать Google Veo для генерации AI видео в таких AI клиентах, как Claude Desktop, VS Code, Cursor и др.

## Обзор функций

Veo MCP Server предоставляет следующие ключевые функции:

- **Генерация видео из текста** — создание высококачественного видео на основе текстовых подсказок
- **Генерация видео из изображений** — создание видео на основе изображений
- **Поддержка нескольких моделей** — поддержка моделей veo3, veo2, veo31-fast-ingredient и др.
- **Разнообразные разрешения** — поддержка форматов вывода 4K, 1080p, GIF и др.
- **Разнообразные соотношения сторон** — поддержка соотношений 16:9, 9:16 и др.
- **Обновление до 1080p** — обновление уже сгенерированного видео до 1080p
- **Запрос задач** — мониторинг процесса генерации и получение результатов

## Предварительная подготовка

Перед использованием вам необходимо получить AceData Cloud API Token:

1. Зарегистрируйтесь или войдите на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдите на страницу [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos)
3. Нажмите «Acquire», чтобы получить API Token (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: установка через pip (рекомендуется)

```bash
pip install mcp-veo
```

### Способ 2: установка из исходников

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

После завершения установки вы можете использовать команду `mcp-veo` для запуска сервиса.

## Использование в Claude Desktop

Отредактируйте файл конфигурации Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Если вы используете `uvx` (не требует предварительной установки пакета):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сохраните конфигурацию и перезапустите Claude Desktop, чтобы использовать инструменты Veo в диалоге.

## Использование в VS Code / Cursor

Создайте файл `.vscode/mcp.json` в корневом каталоге проекта:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Или используйте `uvx`:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

## Список доступных инструментов

| Название инструмента       | Описание                     |
| --------------------- | --------------------------- |
| `veo_text_to_video`   | Генерация видео из текстовых подсказок  |
| `veo_image_to_video`  | Генерация видео на основе изображений   |
| `veo_get_1080p`       | Обновление видео до 1080p |
| `veo_get_task`        | Запрос статуса отдельной задачи     |
| `veo_get_tasks_batch` | Пакетный запрос статусов задач     |

## Примеры использования

После завершения настройки вы можете напрямую использовать эти функции на естественном языке в AI клиенте, например:

- «Помоги мне сгенерировать видео с таймлапсом звездного неба с помощью Veo»
- «Создай 4K видео на основе этой фотографии пейзажа»
- «Сгенерируй короткое видео в вертикальном формате 9:16»
- «Обнови это видео до 1080p»
