[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, представленный Anthropic, который позволяет моделям ИИ (таким как Claude, GPT и другим) вызывать внешние инструменты через стандартизированные интерфейсы. С помощью Suno MCP Server, предоставляемого AceData Cloud, вы можете напрямую генерировать музыку, тексты песен и управлять аудиопроектами в AI-клиентах, таких как Claude Desktop, VS Code, Cursor и других.

## Обзор функций

Suno MCP Server предоставляет следующие основные функции:

- **Генерация музыки** — создание AI-музыки с помощью текстовых подсказок
- **Пользовательское творчество** — полный контроль над текстами песен, названиями и музыкальным стилем
- **Продолжение песни** — продолжение и расширение существующей песни с любой временной точки
- **Каверы/ремиксы** — создание кавер-версий в разных стилях
- **Генерация текстов песен** — создание структурированных текстов песен на основе описания
- **Голосовые персонажи** — сохранение и повторное использование голосовых стилей
- **Конвертация медиа** — получение MP4, WAV, MIDI, разделения вокала и другого
- **Оптимизация стиля** — оптимизация тегов музыкального стиля
- **Запросы задач** — мониторинг прогресса генерации и получение результатов

## Предварительная подготовка

Перед использованием вам необходимо получить AceData Cloud API Token:

1. Зарегистрируйтесь или войдите на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдите на страницу [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Нажмите «Acquire», чтобы получить API Token (при первом запросе предоставляется бесплатный лимит)

## Способ 1: использование размещённого MCP Server (рекомендуется, без установки)

AceData Cloud уже разместил **Suno MCP Server** в облаке, **без необходимости локально устанавливать какие-либо зависимости** — просто укажите следующий URL в AI-клиенте, и можно пользоваться:

```
https://suno.mcp.acedata.cloud/mcp
```

Способ аутентификации: достаточно добавить `Authorization: Bearer ваш API Token` в заголовок запроса (Claude.ai выполняет это автоматически через OAuth, ручной ввод Token не требуется).

### Claude.ai (веб-версия, вход через OAuth, самый простой способ)

1. Откройте [Claude.ai](https://claude.ai) → в левом нижнем углу **Customize** → **Connectors** → **Add More**
2. В поле URL укажите: `https://suno.mcp.acedata.cloud/mcp`
3. Завершите вход через OAuth (автоматически произойдёт переход на страницу входа AceData Cloud)
4. Вернитесь в интерфейс диалога, и инструмент будет готов к использованию

### Claude Desktop

Отредактируйте файл конфигурации:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

После сохранения перезапустите Claude Desktop, чтобы изменения вступили в силу.

### Claude Code (терминальная командная строка)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Другие клиенты с поддержкой MCP

Любые клиенты, поддерживающие протокол MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant и другие), могут подключиться, указав следующие два параметра:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer ваш API Token`

## Способ 2: локальный запуск (установка через pip / uvx)

Если вам требуется автономная работа, пользовательский код или развёртывание во внутренней сети, вы можете установить MCP Server локально и запускать его через stdio.

### Установка

Установка через pip (рекомендуется):

```bash
pip install mcp-suno
```

Или установка из исходного кода:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

После завершения установки можно использовать команду `mcp-suno` для запуска сервиса.

### Использование в Claude Desktop (локально)

Отредактируйте файл конфигурации Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

При использовании `uvx` (без предварительной установки пакета):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

После сохранения конфигурации перезапустите Claude Desktop, чтобы изменения вступили в силу.

## Примеры использования

После завершения настройки вы можете напрямую вызывать эти функции в AI-клиенте на естественном языке, например:

- «Помоги мне создать поп-музыку о лете»
- «Сделай кавер этой песни в джазовом стиле»
- «Продолжи эту песню, начиная с 30-й секунды»
- «Создай китайский текст песни на тему путешествий»
- «Отдели вокал от этой песни»
- «Помоги мне преобразовать эту песню в формат MIDI»

## Расширенное управление и Studio-проекты

`suno_generate_music` поддерживает `variety`; `suno_generate_custom_music` также поддерживает
`max_mode` и `audio_weight`. Для `max_mode` используется более высокий тариф API, по умолчанию он не включён,
и должен быть установлен после явного выбора пользователем расширенного режима. Текущие цены указаны на странице сервиса платформы.

`suno_generate_with_custom_model` может использовать `instrumental=true` для генерации инструментальной музыки или
`lyric_prompt` для автоматической генерации текста песни; в противном случае предоставляется `lyric`. Заголовок и стиль можно опустить, также можно передать
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` и
`callback_url`. Явные управляющие значения `0` будут сохранены.

Для `suno_manage_project` в `request.action` доступны `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. Ввод различается в зависимости от действия, для изменений проекта следует использовать последний считанный `version_id`;
при сохранении передавайте полный `state`, сохраняя существующие дорожки и поля.

Кроме `retrieve`, при каждом вызове необходимо указывать `idempotency_key`. Для новых операций записи используйте новый ключ;
при тайм-ауте или неопределённости результата принятия повторите запрос с исходным ключом и полностью идентичным запросом или запросите исходную задачу, не
меняйте автоматически ключ для повторной отправки платной генерации. Интервалы исходного аудио задаются в секундах, интервалы временной шкалы проекта — в тактах. Генерация создаёт только кандидатов,
необходимо выбрать кандидата и вызвать `commit_candidate`, чтобы он был записан в дорожку.

Для асинхронно принятых задач `task_id` запрашивается через `suno_get_task`. Если `finished_at` пуст, продолжайте ожидание,
после конечного состояния проверьте `response.success` и ошибки; не считайте успешное принятие успешной генерацией, фиксацией или экспортом.
`suno_get_tasks_batch` возвращает полные JSON-записи задач, сохраняя пользовательские объекты моделей, состояние проекта,
кандидатов и различные результаты, включая MIDI. Полный рабочий процесс см. в [Руководстве по Studio-проектам](https://platform.acedata.cloud/documents/suno-projects-integration).
