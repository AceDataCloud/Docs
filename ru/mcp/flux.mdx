[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, выпущенный Anthropic, который позволяет AI-моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированные интерфейсы. Через Flux MCP Server, предоставляемый AceData Cloud, вы можете напрямую генерировать и редактировать AI-изображения в AI-клиентах, таких как Claude Desktop, VS Code, Cursor и других.

## Обзор функций

Flux MCP Server предоставляет следующие основные функции:

- **Генерация изображений из текста** — создание высококачественных изображений с помощью текстовых промптов
- **Редактирование изображений** — редактирование существующих изображений на основе текстовых инструкций
- **Поддержка нескольких моделей** — поддержка различных моделей, включая Flux Pro, Flux Dev, Flux 2, Flux Kontext и другие
- **Запрос моделей** — просмотр всех доступных моделей и их возможностей
- **Запрос задач** — мониторинг прогресса генерации и получение результатов

## Предварительная подготовка

Перед использованием вам необходимо получить AceData Cloud API Token:

1. Зарегистрируйтесь или войдите на [платформу AceData Cloud](https://platform.acedata.cloud)
2. Перейдите на страницу [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Нажмите «Acquire», чтобы получить API Token (при первом запросе предоставляется бесплатный лимит)

## Способ 1: использование размещённого MCP Server (рекомендуется, без установки)

AceData Cloud уже разместил **Flux MCP Server** в облаке, **без необходимости локальной установки каких-либо зависимостей**; просто укажите следующий URL в AI-клиенте, и можно использовать:

```
https://flux.mcp.acedata.cloud/mcp
```

Способ аутентификации: достаточно добавить `Authorization: Bearer ваш API Token` в заголовок запроса (Claude.ai автоматически выполняет это через OAuth, ручной ввод Token не требуется).

### Claude.ai (веб-версия, вход через OAuth, самый простой способ)

1. Откройте [Claude.ai](https://claude.ai) → **Customize** в нижнем левом углу → **Connectors** → **Add More**
2. В поле URL укажите: `https://flux.mcp.acedata.cloud/mcp`
3. Завершите вход с авторизацией OAuth (автоматический переход на страницу входа AceData Cloud)
4. Вернитесь в интерфейс диалога, и инструменты будут готовы к использованию

### Claude Desktop

Отредактируйте файл конфигурации:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

После сохранения перезапустите Claude Desktop, чтобы изменения вступили в силу.

### Claude Code (командная строка терминала)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Другие клиенты с поддержкой MCP

Любой клиент, поддерживающий протокол MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant и др.), может быть подключён путём указания следующих двух параметров:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer ваш API Token`

## Способ 2: локальный запуск (установка через pip / uvx)

Если вам требуется автономная работа, пользовательская настройка кода или развёртывание во внутренней сети, вы можете установить MCP Server локально и запустить его через stdio.

### Установка

Установка через pip (рекомендуется):

```bash
pip install mcp-flux-pro
```

Или установка из исходного кода:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

После завершения установки можно использовать команду `mcp-flux-pro` для запуска сервиса.

### Использование в Claude Desktop (локально)

Отредактируйте файл конфигурации Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Если используется `uvx` (без необходимости предварительной установки пакета):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

После сохранения конфигурации перезапустите Claude Desktop, чтобы изменения вступили в силу.

## Список доступных инструментов

| Название инструмента                    | Описание                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Генерация изображений с помощью текстовых промптов              |
| `flux_edit_image`      | Редактирование существующих изображений на основе текстовых инструкций             |
| `flux_generate_video`  | Генерация текста-в-видео/изображения-в-видео/видео в FLUX 3 и улучшение существующих черновиков |
| `flux_get_task`        | Запрос статуса отдельной задачи                 |
| `flux_get_tasks_batch` | Пакетный запрос статусов задач                 |
| `flux_list_models`     | Вывод всех доступных моделей и их возможностей             |
| `flux_list_actions`    | Вывод всех доступных инструментов и примеров рабочих процессов           |

## Примеры использования

После завершения настройки вы можете напрямую вызывать эти функции на естественном языке в AI-клиенте, например:

- «Помоги мне создать с помощью Flux ночной городской пейзаж в стиле киберпанк»

## Ограничения моделей и размеров
`flux-2-flex`, `flux-2-pro`, `flux-2-max` и модели Kontext должны использовать
соотношения для `size`, например `1:1` или `16:9`, нельзя использовать размеры в пикселях,
такие как `1024x1024`.
`flux-2-klein` поддерживает только генерацию и не входит в число доступных моделей в `flux_edit_image`.

`flux_generate_video` различает `t2v`, `i2v`, `v2v` и
`draft_enhance` через `request.mode`, входные данные отображаются в соответствии с режимом. Улучшение черновика должно ссылаться на собственный временный `draft_task_id`.
Отправка по умолчанию асинхронная, сохраните возвращённый ID задачи и используйте `flux_get_task` для получения результата.
