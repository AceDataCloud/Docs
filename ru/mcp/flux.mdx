[MCP (Model Context Protocol)](https://modelcontextprotocol.io) — это протокол контекста модели, разработанный Anthropic, который позволяет AI-моделям (таким как Claude, GPT и др.) вызывать внешние инструменты через стандартизированный интерфейс. С помощью Flux MCP Server от AceData Cloud вы можете напрямую создавать и редактировать AI-изображения в клиентах AI, таких как Claude Desktop, VS Code, Cursor и других.

## Обзор возможностей

Flux MCP Server предоставляет следующие основные функции:

- **Генерация изображений из текста** — создание высококачественных изображений по текстовым подсказкам
- **Редактирование изображений** — редактирование существующих изображений на основе текстовых инструкций
- **Поддержка нескольких моделей** — поддержка моделей Flux Pro, Flux Dev, Flux Schnell, Flux Kontext и других
- **Запрос моделей** — просмотр всех доступных моделей и их возможностей
- **Запрос задач** — мониторинг прогресса генерации и получение результатов

## Предварительные требования

Для использования необходимо получить API Token AceData Cloud:

1. Зарегистрируйтесь или войдите на [AceData Cloud Platform](https://platform.acedata.cloud)
2. Перейдите на страницу [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Нажмите «Acquire» для получения API Token (при первом запросе предоставляется бесплатный лимит)

## Установка и настройка

### Способ 1: установка через pip (рекомендуется)

```bash
pip install mcp-flux-pro
```

### Способ 2: установка из исходников

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

После установки можно запускать сервис командой `mcp-flux-pro`.

## Использование в Claude Desktop

Отредактируйте конфигурационный файл Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Добавьте следующую конфигурацию:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Если используете `uvx` (без необходимости предварительной установки пакетов):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Сохраните изменения и перезапустите Claude Desktop — теперь вы сможете использовать инструменты Flux в диалогах.

## Использование в VS Code / Cursor

Создайте файл `.vscode/mcp.json` в корне проекта:

```json
{
  "servers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"
      }
    }
  }
}
```

Или с использованием `uvx`:

```json
{
  "servers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "ваш API Token"

```

## Список доступных инструментов

| Название инструмента       | Описание                                   |
|---------------------------|--------------------------------------------|
| `flux_generate_image`      | Генерация изображения по текстовой подсказке |
| `flux_edit_image`          | Редактирование существующего изображения по текстовой инструкции |
| `flux_get_task`            | Запрос статуса одной задачи                 |
| `flux_get_tasks_batch`     | Пакетный запрос статусов задач              |
| `flux_list_models`         | Список всех доступных моделей и их возможностей |
| `flux_list_actions`        | Список всех доступных инструментов и примеров рабочих процессов |

## Примеры использования

После настройки вы можете напрямую вызывать эти функции в AI-клиенте с помощью естественного языка, например:

- «Помоги сгенерировать с помощью Flux изображение ночного города в стиле киберпанк»
- «Измени фон этой фотографии на пляж»
- «Отредактируй это изображение с помощью модели Flux Kontext Pro, поменяй цвет одежды на красный»
- «Покажи все доступные модели Flux»
