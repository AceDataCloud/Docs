## Базовый URL

Базовый адрес для всех конечных точек API:

```
https://api.acedata.cloud
```

## Аутентификация

Все конечные точки требуют аутентификацию с помощью Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Онлайн тестирование

Каждая конечная точка в этом справочнике содержит интерактивную песочницу. Введите API Token, чтобы протестировать запросы прямо в браузере.

<Note title="Tip">
  Получите API Token на [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
