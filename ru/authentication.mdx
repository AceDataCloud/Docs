title: "Аутентификация"
description: "Как использовать Ace Data Cloud API для аутентификации"
---

Все API Ace Data Cloud используют аутентификацию с помощью **Bearer Token**.

## Получение токена

1. Зарегистрируйтесь на [platform.acedata.cloud](https://platform.acedata.cloud)
2. Подпишитесь на необходимые сервисы
3. Создайте учетные данные (API Token) для каждого сервиса

## Использование токена

В каждом запросе включайте токен в заголовок `Authorization`:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  Каждый токен привязан к конкретной подписке на сервис. Для разных сервисов используйте разные токены или создайте **глобальные** учетные данные для использования между сервисами.
</Note>

## Ограничение скорости

Ограничения скорости зависят от сервиса и уровня подписки. При превышении лимита API возвращает `429 Too Many Requests`.

## Лучшие практики безопасности

- Не раскрывайте API Token в клиентском коде
- Храните токены в переменных окружения
- Регулярно обновляйте токены
- Используйте разные токены для разработки и продакшена
