Все Ace Data Cloud API используют аутентификацию с помощью **Bearer Token**.

## Получение токена

Войдите на страницу [Applications](https://platform.acedata.cloud/console/applications?lang=ru&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) и откройте **General Application**. Если при первом входе приложение ещё не создано, выберите **Initialize General Application**. Рядом с **API KEY** нажмите кнопку копирования, отмеченную на изображении цифрой **1**.

![Кнопка копирования ключа приложения, отмеченная цифрой 1](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

Храните ключ на сервере и подставьте его значение вместо `YOUR_API_TOKEN` в примере.

## Использование токена

Включите токен в заголовок `Authorization` каждого запроса:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Ограничение скорости

Ограничения скорости зависят от сервиса и уровня подписки. При превышении лимита API возвращает `429 Too Many Requests`.

## Лучшие практики безопасности

- Не раскрывайте API Token в клиентском коде
- Храните токены в переменных окружения
- Регулярно обновляйте токены
- Используйте разные токены для разработки и продакшена
