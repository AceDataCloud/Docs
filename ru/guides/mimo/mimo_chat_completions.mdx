MiMo 2.6 Pro и MiMo 2.6 Flash — это модели серии Xiaomi MiMo. Этот интерфейс использует формат OpenAI Chat Completions, тарификация производится по входным, выходным token и token попаданий в кэш.

## Модели и интерфейс

| Модель                | Назначение           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Сложный анализ, рассуждение и вызов инструментов |
| `mimo-v2.6-flash` | Повседневные диалоги и легковесные задачи    |

Подключите MiMo и получите соответствующие API-учетные данные, отправляйте запросы на `https://api.acedata.cloud/mimo/chat/completions`. `base_url` OpenAI SDK можно установить в `https://api.acedata.cloud/mimo`. Унифицированная точка входа `/v1/chat/completions` также требует соответствующих прав на сервис.

Первый набор интерфейсов охватывает текстовые Chat Completions; изображения, аудио, видео, сетевой поиск, Responses, Messages, Batch и UltraSpeed не входят в область этого релиза.

## Пример Python

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

Пример демонстрирует способ написания запроса; пример реального ответа будет добавлен после проверки сервиса.

## Потоковая передача, рассуждение и вызов инструментов

Установите `stream=true` для получения SSE; если требуется итоговое использование, передайте `stream_options={"include_usage": true}`. Клиент должен обрабатывать приращения содержимого, содержимого рассуждения и вызовов инструментов, а также итоговое событие usage.

Используйте `thinking.type=enabled` для включения рассуждения, `disabled` для отключения. `reasoning_content` и итоговый `content` возвращаются отдельно; при продолжении вызова инструментов сохраняйте содержимое рассуждения в сообщении ассистента, полные `tool_calls` и соответствующий `tool_call_id`.

Отправляйте только объявления инструментов с `type=function`, `tool_choice` поддерживает только `auto`. Приложение отвечает за выполнение инструментов и возврат результатов; возврат моделью вызова инструмента сам по себе не означает, что инструмент был выполнен. Встроенный в сервис сетевой поиск пока не открыт.

## Тарификация

`prompt_tokens` включает входные данные с попаданием в кэш; `prompt_tokens_details.cached_tokens` рассчитывается по цене кэша, остальные входные данные рассчитываются по обычной цене входных данных. `completion_tokens` включает вывод рассуждения, не суммируйте token рассуждения повторно. Потоковые вызовы также рассчитываются по фактическому итоговому использованию.

Цены определяются консолью, долларовая стоимость Credit зависит от приобретенного тарифа. Неуспешные запросы не должны рассматриваться как успешно завершенные; если требуется проверить списание, предоставьте идентификатор отслеживания из ответа.

## Обработка ошибок

При ошибках параметров проверьте формат запроса; при ошибках аутентификации или прав проверьте учетные данные и подключение сервиса; при 429 используйте повторные попытки с задержкой. При отсутствии емкости работоспособных моделей может возвращаться 503. При возникновении прерывания после начала потокового ответа сначала проверьте уже полученные результаты и использование, чтобы избежать необдуманного повторения запроса.
