---
title: "Инструкция по интеграции API для загрузки видео Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer позволяет нам загружать видео, связанные с песнями. В этом документе объясняется, как интегрировать соответствующий API.

Этот API имеет только один входной параметр — `audio_id`, который является уникальным идентификатором песни.

Здесь мы вводим `audio_id`, который равен `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, это ID песни, сгенерированный Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Результат будет следующим:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4"
  }
}
```

Как видно, поле `video_url` в `data` — это ссылка на загруженное видео.
