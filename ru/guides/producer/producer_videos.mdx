---
title: "Инструкция по интеграции API для скачивания видео Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer позволяет нам скачивать видео, связанные с песнями, в этом документе объясняется способ интеграции соответствующего API.

У этого API есть только один входной параметр — `audio_id`, это уникальный ID песни.

Здесь введённый нами `audio_id` — `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, это ID песни, созданной Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Результат следующий:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

Как можно увидеть, поле `video_url` в `data` является ссылкой на скачиваемое видео.
