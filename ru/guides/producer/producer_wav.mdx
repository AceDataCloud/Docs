---
title: "Инструкция по интеграции API скачивания WAV в Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer позволяет нам скачивать WAV-файлы, связанные с песнями; в этом документе объясняется способ интеграции соответствующего API.

У этого API есть только один входной параметр — `audio_id`, который является уникальным ID песни.

Здесь введённый нами `audio_id` — `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, это ID песни, созданной Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Результат выглядит следующим образом:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Можно увидеть, что поле `file_url` в `data` — это ссылка для скачивания WAV.
