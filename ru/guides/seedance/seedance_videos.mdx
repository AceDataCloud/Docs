В этой статье будет представлена инструкция по интеграции SeeDance Videos Generation API — с его помощью можно генерировать официальные видео SeeDance, вводя пользовательские параметры.

## Процесс подачи заявки

Чтобы использовать SeeDance Videos Generation API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти; после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно подавать отдельную заявку для каждого сервиса.** При первой заявке будут предоставлены бесплатные квоты, позволяющие попробовать сервис бесплатно; при недостатке квот вы можете пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## Базовое использование

Сначала ознакомьтесь с базовым способом использования: достаточно ввести промпт `content.text`, тип `content.type=text` и модель `model`, чтобы получить обработанный результат; конкретное содержимое выглядит следующим образом:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

Можно увидеть, что здесь мы настроили Request Headers, включая:

- `accept`: в каком формате вы хотите получить результат ответа; здесь указывается `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после получения можно напрямую выбрать из выпадающего списка.

Также настроен Request Body, включающий:

- `model`: модель для генерации видео.
  - **Серия Seedance 1.x**: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
  - **Серия Seedance 2.0** (поддерживает мультимодальные референсы персонажей и аудио/видео): `doubao-seedance-2-0-260128` (стандартная), `doubao-seedance-2-0-fast-260128` (быстрая), `doubao-seedance-2-0-mini-260615` (облегчённая).
  - **Seedance 2.5**: `doubao-seedance-2-5-260628`, поддерживает до 30 секунд, референсы только по аудио, больше материалов, редактирование и продление видео.
- `content`: массив входного содержимого; `type` может быть `text` (промпт), `image_url` (референсное изображение), `audio_url` (референсное аудио), `video_url` (референсное видео). Для изображения можно указать назначение через `role`: `first_frame` (первый кадр) / `last_frame` (последний кадр) / `reference_image` (референс персонажа / объекта).
- `resolution`: выходное разрешение; доступны `480p` / `720p` / `1080p` / `4k`. 2.5 поддерживает 480p, 720p, 1080p; 2.0 Fast/Mini поддерживают 480p, 720p; 2.0 Standard поддерживает до 4k.
- `ratio`: соотношение сторон; доступны `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`.
- `duration`: длительность видео (секунды, целое число). Серия 1.0: 2–12; 1.5 Pro: 4–12; серия 2.0: 4–15; 2.5: 4–30. 1.5/2.x поддерживают `-1` (автоматическая длительность).
- `seed`: случайное зерно, целое число от -1 до 4294967295.
- `camerafixed`: фиксировать ли камеру, `true` / `false`.
- `watermark`: добавлять ли водяной знак, `true` / `false`.
- `generate_audio`: генерировать ли видео со звуком, `true` / `false`, поддерживается Seedance 1.5 Pro и серией 2.x.
- `return_last_frame`: возвращать ли в результате URL изображения последнего кадра видео.
- `omni_reference_task_type`: только для 2.5; `auto` / `reference` / `edit` / `extend`.
- `output_format`: только для 2.5; `mp4` / `mov`, по умолчанию `mp4`.
- `tools`: только для 2.5; в настоящее время поддерживается инструмент онлайн-поиска `web_search`, с помощью которого можно ограничить количество результатов, количество ключевых слов и источники поиска.
- `priority`: необязательный приоритет задачи для 2.5, целое число 0–9, по умолчанию 0.
- `safety_identifier`: стабильный анонимный идентификатор конечного пользователя длиной до 64 символов; используйте хеш или внутренний анонимный ID, не передавайте имя, электронную почту или номер телефона.
- `execution_expires_after`: время ожидания задачи (секунды), диапазон 3600–259200.
- `callback_url`: адрес асинхронного обратного вызова; после настройки API немедленно возвращает `task_id`, а по завершении задачи отправляет результат методом POST на этот адрес.
- `async`: необязательно; при установке значения `true` интерфейс немедленно возвращает `task_id`, без необходимости предоставлять `callback_url`, после чего результат можно получить путём опроса соответствующего интерфейса запроса задач.


## Описание встроенных параметров

В конце промпта `content[].text` можно передавать параметры генерации, добавляя их в формате `--parameter value` (старый способ, слабая валидация; при ошибочном заполнении автоматически используются значения по умолчанию). Полный список параметров выглядит следующим образом:

| Встроенный параметр       | Соответствующее поле              | Описание      | Диапазон значений                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | Выходное разрешение   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | Соотношение сторон     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | Длительность видео (секунды) | 2–12                                                          |
| `--frames` | `frames`          | Количество кадров видео    | Целое число в диапазоне [29, 289], удовлетворяющее 25+4n (**поддерживается только серией 1.0**)                       |
| `--fps`    | `framespersecond` | Частота кадров      | Поддерживается только `24`                                                      |
| `--seed`   | `seed`            | Случайное начальное значение    | От -1 до 4294967295                                               |
| `--cf`     | `camerafixed`     | Фиксировать ли камеру | `true` / `false`                                              |
| `--wm`     | `watermark`       | Добавлять ли водяной знак  | `true` / `false`                                              |

> **Рекомендуемый способ**: напрямую использовать соответствующие поля верхнего уровня в Request Body (например, `resolution`, `ratio` и т. д.); это режим строгой валидации, при ошибочном заполнении параметров возвращаются явные сообщения об ошибках, что упрощает поиск проблем.

## Генерация видео со звуком

Seedance 1.5 Pro и серия 2.x поддерживают генерацию видео с аудио через параметр `generate_audio`:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

Серия 1.0 не поддерживает этот параметр.

## Полномодальная генерация, редактирование и продление Seedance 2.5

`doubao-seedance-2-5-260628` поддерживает 480p / 720p / 1080p, 4–30 секунд или автоматическую длительность, а также повышает лимит материалов до 30 эталонных изображений, 10 эталонных видео и 10 эталонных аудио (всего не более 50). 2.5 также поддерживает передачу только эталонного аудио, больше не требуя одновременного предоставления изображения или видео.

Для обычной полномодальной генерации можно опустить `omni_reference_task_type`, установить его в `auto` или явно установить в `reference`. Для редактирования и продления видео необходимо передать `reference_video`:

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`: передайте как минимум один `reference_image`, `reference_video` или `reference_audio`; 2.5 поддерживает передачу только эталонного аудио.
- `edit`: необходимо использовать `ratio: adaptive` и `duration: -1`; выходная длительность тарифицируется по фактическому результату.
- `extend`: необходимо использовать `ratio: adaptive`; `duration` может быть от 4 до 30 или `-1`.
- `auto`: модель автоматически выбирает генерацию, редактирование или продление на основе промпта и материалов.
- Когда тип задачи не соответствует материалам или промпту, задача завершится с ошибкой и вернёт локализуемую ошибку параметра; пожалуйста, скорректируйте согласно указанным выше ограничениям и отправьте повторно.

## Первый кадр видео из изображения

Если требуется задача генерации видео из изображения, сначала параметр `content` должен содержать элемент с `type`, равным `image_url`, а поле `image_url` должно быть в объектном формате: `{"url": "https://..."}` или в формате Base64: `{"url": "data:image/png;base64,..."}`.

> **Примечание**: `image_url` не поддерживает прямую передачу строкового формата (например, `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`), необходимо использовать объектный формат `"image_url": {"url": "https://..."}`, иначе будет возвращена ошибка 400.

Соответствующий код:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажав запуск, можно обнаружить, что сразу будет получен результат, как показано ниже:

```

  "data": {
    "task_id": "cgt-20251222072003-x2259",
```

Можно увидеть, что сгенерированный эффект представляет собой создание видео из изображения, результат аналогичен приведённому выше.

## Первый и последний кадры видео из изображения

Если требуются первый и последний кадры видео из изображения, сначала параметр `content` должен передавать тип `image_url`, а также отдельно установить `role` в `first_frame` и `last_frame`, тогда можно указать следующее содержимое:

- role: указывает первый или последний кадр.
- image_url
  - url Ссылка на изображение
    Одновременно в `content` также необходимо ввести тип `text` в качестве промпта

Соответствующий код:
```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажмите «Выполнить», и можно увидеть, что результат будет получен немедленно, как показано ниже:

## Мультимодальные референсы персонажей, аудио и видео (Seedance 2.0)

**Серия Seedance 2.0** (`doubao-seedance-2-0-260128`, `doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-0-mini-260615`) поддерживает `reference_image`, `reference_audio` и `reference_video`. Можно использовать собственные или лицензированные материалы для сохранения согласованности персонажей, субъектов, действий, движения камеры, звука и ритма.

> Загружайте только собственные или лицензированные материалы с реальными людьми и персонажами. Разные модели по-разному поддерживают материалы с реальными людьми; формат запроса остается неизменным, а при несоответствии материала требованиям будет возвращена явная ошибка.

Ключевые моменты использования:

- Только модели **серии Seedance 2.0** поддерживают `reference_image`; для моделей 1.x используйте `first_frame` / `last_frame` (первый и последний кадры для генерации видео из изображения).
- Первый кадр, первый и последний кадры при генерации видео из изображения, а также полные мультимодальные референсы — это три взаимоисключающих сценария: `first_frame` / `last_frame` нельзя использовать вместе с `reference_image` / `reference_video` / `reference_audio`.
- Если вы хотите указать первый и последний кадры в полном мультимодальном референсе, пометьте изображения как `reference_image` и укажите в промпте «изображение 1 как первый кадр» или «изображение 2 как последний кадр»; если необходимо строго зафиксировать первый и последний кадры, используйте только `first_frame` / `last_frame`.
- Максимальное количество мультимодальных референсов: до **9** изображений `image_url`; 2.0 также поддерживает `audio_url` (`role` — `reference_audio`, до 3 элементов) и `video_url` (`role` — `reference_video`, до 3 элементов).
- **Требования к материалам референсного аудио (`audio_url`)**: формат `wav` / `mp3`; **длительность каждого файла 2–15 секунд**, не более 3 файлов и **общая длительность не более 15 секунд**; каждый файл не более 15 МБ. При выходе за пределы длительности обработка материала завершится ошибкой.
- **Требования к материалам референсного видео (`video_url`)**: формат `mp4` / `mov`; **длительность каждого файла 2–15 секунд**, не более 3 файлов и **общая длительность не более 15 секунд**.
- Для референсных изображений рекомендуется использовать фотографии **одного человека, анфас, четкие, без перекрытий**; чем четче лицо, тем выше сходство.

### Пример 1: крупный план с сохранением внешности человека

Передайте фотографию лица, чтобы этот человек улыбнулся и помахал рукой в камеру. Соответствующий код:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
```

## Асинхронный обратный вызов

Поскольку API генерации видео SeeDance Videos Generation требует длительного времени для генерации (около 1–2 минут), можно использовать асинхронный режим через поле `callback_url`, чтобы избежать длительного удержания HTTP-соединения.

Общий процесс: клиент указывает `callback_url` при отправке запроса, API немедленно возвращает ответ, содержащий `task_id`; после завершения задачи платформа отправляет результат генерации на `callback_url` в виде POST JSON, при этом результат также содержит `task_id` для сопоставления.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

После завершения задачи платформа отправляет на `callback_url` следующее содержимое:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

Поле `task_id` в результате совпадает с возвращённым при запросе, и через это поле можно выполнить сопоставление задачи.

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`：Неверный запрос, возможно, из-за отсутствующих или недопустимых параметров.
- `400 api_not_implemented`：Неверный запрос, возможно, из-за отсутствующих или недопустимых параметров.
- `401 invalid_token`：Не авторизовано, недопустимый или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили ограничение скорости.
- `500 api_error`：Внутренняя ошибка сервера, на сервере что-то пошло не так.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
