Сервис векторных представлений OpenAI, используемый для генерации результатов векторных представлений входного текста.

В этом документе в основном описывается процесс использования OpenAI Embeddings API, с помощью которого мы можем создавать векторы вложений, представляющие входной текст。。

## Процесс подключения

Чтобы использовать OpenAI Embeddings API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы получить ваш API Token и сохранить его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти в систему, после чего вы автоматически вернетесь на текущую страницу.

**Одного API Token достаточно для вызова всех сервисов платформы, не требуется подавать отдельную заявку для каждого сервиса.** При первой заявке предоставляется бесплатная квота, позволяющая бесплатно ознакомиться с сервисом; при недостатке квоты вы можете пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Базовое использование

Далее вы можете заполнить соответствующее содержимое в интерфейсе, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

При первом использовании данного интерфейса нам необходимо заполнить как минимум три поля: одно из них — `authorization`, его достаточно выбрать непосредственно в выпадающем списке. Другой параметр — `model`, `model` — это категория модели с официального сайта OpenAI, которую мы выбираем для использования; доступные в настоящее время модели: `text-embedding-3-small` и `text-embedding-3-large`. `text-embedding-ada-002` больше не предоставляется; если существующий векторный индекс использует эту старую модель, нельзя напрямую смешивать векторы новой модели, необходимо заново создать индекс. Последний параметр — `input`, `input` — это текст, который нам необходимо преобразовать в векторное представление.

В то же время вы можете заметить, что справа генерируется соответствующий код вызова; вы можете скопировать код и запустить его напрямую, а также можете непосредственно нажать кнопку «Try» для тестирования.

Необязательные параметры:

- `dimensions`：обрезка размерности вектора, по умолчанию выводится полная размерность.
- `encoding_format`：формат возврата, доступны `float` или `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Пример кода вызова Python:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Возвращаемый результат содержит несколько полей, описание которых приведено ниже:

- `model` — модель, использованная для преобразования данного текста в векторное представление.
- `usage` — информация о token, использованных для преобразования данного текста в векторное представление.
- `data` — результат векторного представления после преобразования текста.

Среди них `data` содержит конкретную информацию о векторном представлении, соответствующем тексту, а его `embedding` — конкретный сгенерированный результат векторного представления.

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`：Неверный запрос, возможно, из-за отсутствующих или недопустимых параметров.
- `400 api_not_implemented`：Неверный запрос, возможно, из-за отсутствующих или недопустимых параметров.
- `401 invalid_token`：Не авторизован, недопустимый или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили ограничение частоты запросов.
- `500 api_error`：Внутренняя ошибка сервера, на сервере что-то пошло не так.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
