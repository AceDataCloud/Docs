OpenAI ChatGPT — это очень мощная система AI-диалогов: достаточно ввести подсказку, и она сможет всего за несколько секунд сгенерировать плавный и естественный ответ. ChatGPT выделяется в отрасли своими превосходными способностями к пониманию и генерации языка. Сегодня ChatGPT уже широко применяется во всех отраслях и сферах, а его влияние становится всё более заметным. Будь то повседневные диалоги, творческое письмо, профессиональные консультации или программирование кода, ChatGPT может предоставлять впечатляющую интеллектуальную помощь, значительно повышая эффективность работы и творческие способности человека.

В этом документе в основном описывается процесс использования операций OpenAI Chat Completion API, с помощью которого мы можем легко использовать функцию диалога официального OpenAI ChatGPT.

Запросы к совместимым моделям, принимаемые платформой, тарифицируются в соответствии с объёмом входных, выходных и кэшированных данных модели. `prompt_tokens` в Chat Completions включает кэшированные token, а указанная кэшированная часть рассчитывается по соответствующей цене кэша; переключение формата интерфейса не превращается в оплату за фиксированное количество раз. Стоимость определяется текущими ценами моделей в консоли и `usage.cost` в ответе.

## GPT-6.1 Terra

Используйте `model: "gpt-6.1-terra"` для выбора этой модели. Поддерживаются текстовый ввод, ввод изображений и потоковый вывод; функциональные инструменты и структурированный вывод вызывайте в соответствии с форматом параметров этого интерфейса. Поддерживаются уровни рассуждений `low`, `medium`, `high`, `xhigh` и `max`; рекомендуется начать с `reasoning_effort: "low"`; `none` и `minimal` не поддерживаются. При входных данных более 272,000 tokens применяется цена длинного контекста, фактическая стоимость определяется текущими ценами в консоли и использованием в ответе.

## GPT-6.1 Sol

Используйте `model: "gpt-6.1-sol"` для выбора этой модели. Поддерживаются потоковый вывод, вызовы функций, структурированный вывод и ввод изображений. В течение первой недели после открытия доступна только проверенным держателям ACE T1+ (минимум 100,000 ACE) или авторизованным пользователям; конкретное время открытия определяется подсказкой доступа в консоли.

Поддерживаются уровни рассуждений `low`, `medium`, `high`, `xhigh` и `max`, `none` и `minimal` пока не поддерживаются. Рекомендуется начать с `reasoning_effort: "low"`. При входных данных более 272,000 tokens ко всему запросу применяется цена длинного контекста, стоимость определяется текущими ценами в консоли.

## Процесс подачи заявки

Чтобы использовать OpenAI Chat Completion API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости подавать отдельную заявку для каждого сервиса.** При первой заявке предоставляется бесплатный лимит, который можно использовать для бесплатного тестирования; при недостаточном лимите можно пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

## Базовое использование

Далее можно заполнить соответствующее содержимое в интерфейсе, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

При первом использовании этого интерфейса нам необходимо заполнить как минимум три поля: одно из них — `authorization`, его можно непосредственно выбрать в выпадающем списке. Другой параметр — `model`, `model` — это выбранная нами категория моделей с официального сайта OpenAI ChatGPT, здесь у нас в основном есть 20 видов моделей, подробности можно посмотреть в предоставленных нами моделях. Последний параметр — `messages`, `messages` — это массив введённых нами слов запроса, это массив, означающий, что можно одновременно загрузить несколько слов запроса, каждый запрос содержит `role` и `content`, где `role` обозначает роль задающего вопрос, мы предоставляем три роли: `user`, `assistant`, `system`. Другой `content` — это конкретное содержание нашего вопроса.

Одновременно вы можете заметить, что справа генерируется соответствующий код вызова, вы можете скопировать код и запустить его напрямую, а также можете непосредственно нажать кнопку «Try» для тестирования.

Часто используемые необязательные параметры:

- `max_tokens`: ограничивает максимальное количество token в одном ответе.
- `temperature`: случайность генерации, от 0 до 2, чем больше значение, тем более разнообразен результат.
- `n`: сколько кандидатных ответов генерировать за один раз.
- `response_format`: настройка формата возврата.

## Потоковый ответ

Этот интерфейс также поддерживает потоковый ответ, что очень полезно для интеграции с веб-страницами и позволяет реализовать на веб-странице эффект посимвольного отображения.

Если вы хотите возвращать ответ в потоковом режиме, можно изменить параметр `stream ` в заголовке запроса на `true`.

Изменение показано на рисунке, однако код вызова должен быть соответствующим образом изменён для поддержки потокового ответа.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

После изменения `stream` на `true` API будет построчно возвращать соответствующие JSON-данные, на уровне кода нам необходимо внести соответствующие изменения, чтобы получать построчные результаты.

Пример кода вызова на Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Пример кода Java:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");
jsonObject.put("messages", [{"role":"user","content":"hello"}]);

OkHttpClient client = new OkHttpClient();

```

## Многораундовый диалог
Если вы хотите подключить функцию многораундового диалога, необходимо загрузить несколько фраз-вопросов в поле `messages`, конкретный пример нескольких фраз-вопросов показан на изображении ниже:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Пример кода вызова на Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Загрузив несколько фраз-вопросов, можно легко реализовать многораундовый диалог и получить следующий ответ:


## Подключение OpenAI-Python

OpenAI Chat Completion API совместим с официальным интерфейсом OpenAI, для подключения можно напрямую использовать официальный SDK [OpenAI-Python](https://github.com/openai/openai-python), в этой статье будет кратко представлено использование.

1. Сначала необходимо настроить локальную среду `Python`, этот процесс можно найти через поиск Google.
2. Скачайте и установите среду разработки, например редактор VSCode.
3. Настройте переменные среды `OpenAI`.

- В папке проекта создайте файл с именем `.env` и сохраните его.
- Содержимое файла `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Замените `sk-xxx` на собственный key. `OPENAI_BASE_URL` — это прокси-интерфейс для доступа к OpenAI.

4. Установите пакеты зависимостей проекта

```shell
pip install openai
```

В Mac OS команда следующая:

```shell
pip3 install openai
```

5. Создайте файл с исходным кодом примера

Предположим, мы создали пример кода `index.py`, его конкретное содержимое следующее:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Визуальная модель

gpt-4o — это мультимодальная большая языковая модель, разработанная OpenAI, она добавляет возможности визуального понимания на основе GPT-4. Эта модель может одновременно обрабатывать текстовые и графические входные данные, реализуя межмодальное понимание и генерацию.

Текстовая обработка с использованием модели gpt-4o соответствует содержимому базового использования выше, далее будет кратко представлено, как использовать возможности модели по обработке изображений.

Возможности обработки изображений модели gpt-4o в основном используются путем добавления поля `type` на основе исходного содержимого `content`; с помощью этого поля можно определить, загружается ли текст или изображение, и тем самым использовать возможности обработки изображений модели gpt-4o. Ниже главным образом описывается вызов этой функции двумя способами: Curl и Python.

- Способ с помощью скрипта Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Способ с помощью скрипта Python
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`：Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `400 api_not_implemented`：Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `401 invalid_token`：Не авторизовано, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили ограничение частоты запросов.
- `500 api_error`：Внутренняя ошибка сервера, на сервере что-то пошло не так.

### Пример ответа с ошибкой

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
