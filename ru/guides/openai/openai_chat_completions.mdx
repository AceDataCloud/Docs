OpenAI ChatGPT — это очень мощная система диалогов с ИИ: достаточно ввести промпт, и всего за несколько секунд можно сгенерировать плавный и естественный ответ. ChatGPT выделяется в отрасли своими превосходными возможностями понимания и генерации языка. Сегодня ChatGPT уже широко применяется в различных индустриях и сферах, а его влияние становится всё более значительным. Будь то повседневные диалоги, творческое написание текстов, профессиональные консультации или программирование кода — ChatGPT способен предоставить впечатляющую интеллектуальную помощь, значительно повышая эффективность работы и творческие способности человека.

Этот документ главным образом представляет процесс использования операций OpenAI Chat Completion API, с помощью которого мы можем легко использовать диалоговые функции официального OpenAI ChatGPT.

## GPT-6.1 Sol

Используйте `model: "gpt-6.1-sol"` для выбора этой модели. Поддерживаются потоковый вывод, вызовы функций, структурированный вывод и ввод изображений. В течение первой недели после открытия доступ предоставляется только подтверждённым держателям ACE T1+ (не менее 100 000 ACE) или авторизованным пользователям; конкретное время открытия определяется подсказками о доступе в консоли.

Поддерживаются уровни рассуждений `low`, `medium`, `high`, `xhigh` и `max`; `none` и `minimal` пока не поддерживаются. Рекомендуется начинать с `reasoning_effort: "low"`. Если ввод превышает 272 000 tokens, для всего запроса применяется цена за длинный контекст, стоимость определяется текущими ценами в консоли.

## Процесс подачи заявки

Чтобы использовать OpenAI Chat Completion API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы получить ваш API Token и сохранить его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти в систему; после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, без необходимости отдельно подавать заявку для каждого сервиса.** При первой заявке предоставляется бесплатный лимит, позволяющий бесплатно попробовать сервис; при недостатке лимита можно пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

## Базовое использование

Далее можно заполнить соответствующие поля в интерфейсе, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

При первом использовании этого интерфейса нам необходимо заполнить как минимум три поля: одно из них — `authorization`, его можно напрямую выбрать в выпадающем списке. Другой параметр — `model`, `model` — это категория модели с официального сайта OpenAI ChatGPT, которую мы выбираем для использования; здесь у нас имеется 20 моделей, подробности можно посмотреть в предоставленных нами моделях. Последний параметр — `messages`, `messages` — это массив введённых нами вопросов, это массив, который означает, что можно одновременно загрузить несколько вопросов; каждый вопрос содержит `role` и `content`, где `role` обозначает роль задающего вопрос, мы предоставляем три идентичности: `user`, `assistant`, `system`. Другой параметр `content` — это конкретное содержание нашего вопроса.

Одновременно вы можете заметить, что справа генерируется соответствующий код вызова: вы можете скопировать код и запустить его напрямую, а также можете напрямую нажать кнопку «Try» для тестирования.

Распространённые необязательные параметры:

- `max_tokens`: ограничивает максимальное количество token в одном ответе.
- `temperature`: случайность генерации, от 0 до 2; чем больше значение, тем более разрозненным будет результат.
- `n`: сколько вариантов ответов генерировать за один раз.
- `response_format`: настройка формата возврата.

## Потоковый ответ

Этот интерфейс также поддерживает потоковые ответы, что очень полезно для интеграции с веб-страницами и позволяет реализовать эффект посимвольного отображения на веб-странице.

Если вы хотите возвращать ответ потоково, можно изменить параметр `stream ` в заголовке запроса на `true`.

Изменения показаны на рисунке, однако код вызова необходимо соответствующим образом изменить, чтобы поддерживать потоковый ответ.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

После изменения `stream` на `true` API будет построчно возвращать соответствующие JSON-данные, и на уровне кода нам необходимо внести соответствующие изменения, чтобы получать построчные результаты.

Пример кода вызова Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Многораундовый диалог

Если вы хотите интегрировать функцию многораундового диалога, необходимо передать несколько запросов в поле `messages`; конкретный пример нескольких запросов показан на следующем изображении:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Пример кода вызова Python:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Загружая несколько запросов, можно легко реализовать многоэтапный диалог и получить следующий ответ:

```json
{
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "You said, \"Hello.\""
      },
      "finish_reason": "stop"
    }
  ],
  "created": 1721323012,
  "id": "chatcmpl-NWZmOTA5MDlkZjBjNDRjNGEwMzRjYzA5NmM1MzQwMWY",
  "model": "gpt-4",

  "recipient": "all",
```

Можно увидеть, что информация, содержащаяся в `choices`, совпадает с содержимым базового использования; она включает конкретное содержимое ответа ChatGPT на несколько диалогов, таким образом можно отвечать на соответствующие вопросы на основе содержимого нескольких диалогов.

## Интеграция с OpenAI-Python

OpenAI Chat Completion API совместим с официальным интерфейсом OpenAI, для интеграции можно напрямую использовать официальный SDK [OpenAI-Python](https://github.com/openai/openai-python), в этой статье будет кратко представлен способ использования.

1. Сначала необходимо настроить локальную среду `Python`, этот процесс можно поискать в Google.
2. Скачайте и установите среду разработки, например редактор VSCode.
3. Настройте переменные среды `OpenAI`.

- В папке проекта создайте файл с именем `.env` и сохраните его.
- Содержимое файла `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

Замените `sk-xxx` на собственный key. `OPENAI_BASE_URL` — это прокси-интерфейс для доступа к OpenAI.

4. Установите пакеты, от которых зависит проект.

```shell
pip install openai
```

В Mac OS команда выглядит так:

```shell
pip3 install openai
```

5. Создайте файл исходного кода примера.

Предположим, мы создали пример кода `index.py`, его конкретное содержимое следующее:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Визуальная модель

gpt-4o — это мультимодальная большая языковая модель, разработанная OpenAI, она добавляет возможности визуального понимания на основе GPT-4. Эта модель может одновременно обрабатывать текстовые и графические входные данные, реализуя межмодальное понимание и генерацию.

Текстовая обработка при использовании модели gpt-4o соответствует содержимому базового использования выше; далее будет кратко представлено, как использовать возможности модели по обработке изображений.

Возможность обработки изображений моделью gpt-4o в основном используется путем добавления поля `type` на основе исходного содержимого `content`; с помощью этого поля можно определить, загружен текст или изображение, и тем самым использовать возможности обработки изображений модели gpt-4o. Далее в основном описывается вызов этой функции двумя способами: Curl и Python.

- Способ с помощью скрипта Curl


```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`：Неверный запрос, возможно, из-за отсутствующих или недопустимых параметров.
- `400 api_not_implemented`：Неверный запрос, возможно, из-за отсутствующих или недопустимых параметров.
- `401 invalid_token`：Не авторизовано, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`：Внутренняя ошибка сервера, на сервере что-то пошло не так.

### Пример ответа с ошибкой

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
