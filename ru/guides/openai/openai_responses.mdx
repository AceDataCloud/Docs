OpenAI недавно предоставила интерфейс для создания ответов модели. Предоставляйте текстовый или графический ввод для генерации текстового или графического вывода. Позвольте модели вызывать ваш собственный пользовательский код или использовать встроенные инструменты, такие как web-поиск или поиск по файлам, чтобы использовать ваши собственные данные в качестве ввода для ответа модели.

Этот документ в основном знакомит с процессом использования операций OpenAI Responses API, с его помощью мы можем легко использовать официальную функцию OpenAI по созданию ответов модели.

## Процесс получения

Чтобы использовать OpenAI Responses API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости подавать заявку отдельно для каждого сервиса.** При первом получении будут предоставлены бесплатные средства, можно бесплатно попробовать; при недостатке средств можно пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [OpenAI Responses API →](https://platform.acedata.cloud/documents/openai-responses)

## Базовое использование

Далее можно заполнить соответствующее содержимое в интерфейсе, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

При первом использовании этого интерфейса нам необходимо заполнить как минимум три поля: одно из них — `authorization`, его можно просто выбрать в раскрывающемся списке. Другой параметр — `model`, `model` — это выбранная нами категория моделей с официального сайта OpenAI ChatGPT, здесь у нас имеется 20 моделей, подробнее можно посмотреть в предоставляемых нами моделях. Последний параметр — `input`, `input` — это массив введённых нами запросов, это массив, означающий, что можно одновременно загрузить несколько запросов, каждый запрос содержит `role` и `content`, где `role` обозначает роль задающего вопрос, мы предоставляем три роли: `user`, `assistant`, `system`. Другой параметр, `content`, — это конкретное содержание нашего вопроса.

Одновременно вы можете заметить, что справа генерируется соответствующий код вызова, вы можете скопировать код и запустить его напрямую, а также можете напрямую нажать кнопку «Try» для тестирования.

Распространённые необязательные параметры:

- `max_tokens`: ограничивает максимальное количество token в одном ответе.
- `temperature`: случайность генерации, от 0 до 2, чем больше значение, тем более разнообразным будет результат.
- `n`: сколько вариантов ответов генерировать за один раз.
- `response_format`: настройка формата возврата.
- `tools`: определение вызова функций/инструментов.
- `background`: выполнять ли асинхронно в фоновом режиме.

## Потоковый ответ

Этот интерфейс также поддерживает потоковый ответ, что очень полезно для интеграции с веб-страницами и позволяет реализовать эффект посимвольного отображения на веб-странице.

Если вы хотите получать ответ в потоковом режиме, можно изменить параметр `stream ` в заголовке запроса на `true`.

Изменение показано на рисунке, однако код вызова должен быть соответствующим образом изменён для поддержки потокового ответа.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

После изменения `stream` на `true` API будет построчно возвращать соответствующие JSON-данные, на уровне кода нам необходимо внести соответствующие изменения, чтобы получать построчные результаты.

Пример кода вызова Python:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Можно увидеть, что в ответе имеется множество `data`, а `delta` внутри `data` — это самое последнее содержимое ответа, что соответствует содержимому, представленному выше. `delta` — это добавленное содержимое ответа, вы можете интегрировать его в свою систему на основе результатов. Потоковый ответ использует `response.completed` или `response.incomplete` в качестве конечного состояния; `usage` в конечном состоянии — это итоговое количество использованных token для данного запроса, а также основание для выставления счёта.

Если клиент разрывает соединение до достижения конечного состояния, данный запрос будет зарегистрирован как закрытый клиентом (499), и плата не будет взиматься на основе локально оценённых token; если соединение завершается нормально, но конечное состояние и итоговый `usage` не получены, данный запрос будет зарегистрирован как неполный ответ (502), и плата также не будет взиматься на основе оценённых token. При возникновении этих двух ситуаций повторно отправьте запрос.

Возвращаемый результат `data` содержит несколько полей, описание которых приведено ниже:

- `item_id` — ID сгенерированной задачи данного диалога, используемый для уникальной идентификации этой задачи диалога.
- `type` — тип сгенерированной задачи Responses данного диалога.
- `model ` — выбранная модель OpenAI ChatGPT с официального сайта.
- `delta` — информация об ответе, предоставленном ChatGPT на вопрос.

JavaScript также поддерживается, например, код потокового вызова для Node.js приведён ниже:

```javascript
const options = {

  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

## Многораундовый диалог

Если вы хотите интегрировать функцию многораундового диалога, необходимо передать несколько запросов в поле `input`, конкретный пример нескольких запросов показан на рисунке ниже:

<p><img src="https://cdn.acedata.cloud/1jqwnf.png" width="400" className="m-auto" /></p>

Пример кода вызова Python:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hello! How can I help you today? 😊"},{"role":"user","content":"What did I just say?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Визуальная модель

gpt-4o — это мультимодальная большая языковая модель, разработанная OpenAI; она добавляет способность визуального понимания на основе GPT-4. Эта модель может одновременно обрабатывать текстовые и графические входные данные, обеспечивая межмодальное понимание и генерацию.
Обработка текста с использованием модели gpt-4o совпадает с основным содержанием использования, описанным выше, ниже будет кратко представлено, как использовать возможности модели по обработке изображений.

Использование возможностей обработки изображений модели gpt-4o в основном осуществляется путем добавления поля `type` на основе исходного содержимого `content`, с помощью этого поля можно узнать, загружается текст или изображение, тем самым используя возможности обработки изображений модели gpt-4o, ниже в основном описывается вызов этой функции двумя способами: Curl и Python.

- Способ с использованием скрипта Curl

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }'
```

- Способ с использованием скрипта Python

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и сообщение. Например:

- `400 token_mismatched`: Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `400 api_not_implemented`: Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `401 invalid_token`: Не авторизовано, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`: Слишком много запросов, вы превысили ограничение частоты запросов.
- `500 api_error`: Внутренняя ошибка сервера, на сервере произошел сбой.

### Пример ответа об ошибке

```
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
