## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), войдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Отправка первого запроса

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Изображение в успешном ответе находится в `data[].url`. Ниже приведён результат 1024×1536, фактически полученный через запрос Ace Data Cloud 8 сентября 2026 года (задача `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Белая кружка, сгенерированная GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Часто используемые параметры

| Поле                | Описание                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендуется по умолчанию), `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и управляемость); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `prompt`          | Описание изображения, максимум 32 000 символов                                                                                                                     |
| `size`            | `auto` или `WIDTHxHEIGHT`; ширина и высота должны быть кратны 16, длинная сторона не превышает 3840, общее количество пикселей составляет 655 360–8 294 400, соотношение сторон не превышает 3:1                                                       |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` или `auto`; поддержка и способ тарификации различаются для разных маршрутов                                                                                          |
| `response_format` | `url` или `b64_json`                                                                                                                     |
| `callback_url`    | Необязательно; отправляет результат на этот адрес после завершения длительной задачи                                                                                                                      |

Часто используемые размеры:

| Соотношение   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` выбирает формат кадра на основе соотношения сторон, пикселей и намерения компоновки в подсказке; если нужны точные пиксели, укажите размер напрямую.

## 4. Генерация нескольких изображений

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются на основе фактически использованных Token текстового ввода и вывода изображения в ответе. Цена на странице — это оценка до запроса, итоговая сумма определяется журналом использования.

## 5. Асинхронный callback

После добавления `callback_url` в тело запроса интерфейс сначала возвращает `{"task_id": "..."}`, а по завершении отправляет финальный результат методом POST на этот URL; синхронные запросы по-прежнему возвращают `created` и `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Получатель callback должен использовать `task_id` для устранения дубликатов и проверять источник запроса и формат данных.

## 6. Устранение ошибок

| Статус  | Проверка                                                  |
| --- | --------------------------------------------------- |
| 400 | Сочетание `model`, `prompt`, формата размера, `n` и `response_format`    |
| 401 | Полностью ли указан API Key, и имеет ли Header вид `Authorization: Bearer ...` |
| 429 | Слишком частые запросы, повторите попытку позже                                         |
| 504 | Тайм-аут синхронной генерации; используйте `callback_url`                            |

Ответы с ошибками содержат `error.code`, `error.message` и `trace_id`. При сообщении о проблеме предоставляйте `trace_id`, не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редактирования изображений смотрите [редактирование изображений GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
