## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Отправка первого запроса

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Изображение в успешном ответе находится в `data[].url`. Ниже приведён результат 1024×1536, фактически полученный через запрос Ace Data Cloud 8 сентября 2026 года (задача `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Белая кружка, сгенерированная GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Часто используемые параметры

| Поле                | Описание                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендуется по умолчанию), `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `prompt`          | Описание изображения, максимум 32 000 символов                                                                                                                     |
| `size`            | `auto` или `WIDTHxHEIGHT`; ширина и высота должны быть кратны 16, длинная сторона не должна превышать 3840, общее число пикселей — 655 360–8 294 400, соотношение сторон не должно превышать 3:1                                                       |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` или `auto`; поддержка и способ тарификации различаются для разных каналов                                                                                          |
| `response_format` | `url` или `b64_json`                                                                                                                     |
| `callback_url`    | Необязательно; после завершения длительной задачи результат отправляется на этот адрес                                                                                                                      |

Часто используемые размеры:

| Соотношение   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` выбирает формат кадра на основе соотношения сторон, пикселей и намерения компоновки в подсказке; если требуются точные пиксели, укажите размер напрямую.

### Модели и способы тарификации

| Модель                                | Подходящие сценарии и способ тарификации                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Обратный канал по умолчанию, фиксированная тарификация за количество успешно созданных изображений                        |
| `gpt-image-2:reverse`             | Явный выбор обратного канала, фиксированная тарификация за количество успешно созданных изображений                      |
| `gpt-image-2:official`            | Официальный API-канал, более высокая стабильность, тарификация по фактическому использованию Token            |
| `gpt-image-2.5-flare`             | Ориентирован на скорость генерации, фиксированная тарификация за количество успешно созданных изображений                        |
| `gpt-image-2.5-flare:official`    | Официальный API-канал, более высокая стабильность и ориентация на скорость генерации, тарификация по фактическому использованию Token     |
| `gpt-image-2.5-sunburst`          | Ориентирован на высокую точность и детальный контроль, фиксированная тарификация за количество успешно созданных изображений                    |
| `gpt-image-2.5-sunburst:official` | Официальный API-канал, более высокая стабильность и ориентация на высокую точность и детальный контроль, тарификация по фактическому использованию Token |

Цена на странице для официального API-канала является оценкой до отправки запроса; окончательная стоимость определяется фактическим использованием Token в ответе и записями об использовании.

## 4. Генерация нескольких изображений

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются на основе фактических Token текстового ввода и вывода изображения в ответе. Цена на странице является оценкой до отправки запроса, окончательное значение определяется записями об использовании.

## 5. Асинхронный обратный вызов

После добавления `callback_url` в тело запроса интерфейс сначала возвращает `{"task_id": "..."}`, а после завершения отправляет итоговый результат методом POST на этот URL; синхронный запрос по-прежнему возвращает `created` и `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Получатель обратного вызова должен использовать `task_id` для устранения дубликатов и проверять источник запроса и формат данных.

## 6. Устранение неполадок

| Статус  | Проверка                                                  |
| --- | --------------------------------------------------- |
| 400 | Комбинация `model`, `prompt`, формата размера, `n` и `response_format`    |
| 401 | Полнота API Key, наличие в Header значения `Authorization: Bearer ...` |
| 429 | Слишком частые запросы, повторите попытку позже                                         |
| 504 | Тайм-аут синхронной генерации; используйте `callback_url`                            |

Ответ об ошибке включает `error.code`, `error.message` и `trace_id`. При сообщении о проблеме предоставьте `trace_id`, но не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редактирования изображений смотрите [редактирование изображений GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
