## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), войдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Отправка первого запроса

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Изображение в успешном ответе находится в `data[].url`. Ниже приведён результат 1024×1536, фактически полученный через Ace Data Cloud 8 сентября 2026 года (задача `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Белая кружка, сгенерированная GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Часто используемые параметры

| Поле                | Описание                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендуется по умолчанию), `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `prompt`          | Описание изображения, максимум 32 000 символов                                                                                                                     |
| `size`            | `auto` или `WIDTHxHEIGHT`; ширина и высота должны быть кратны 16, длинная сторона не более 3840, общее количество пикселей — 655 360–8 294 400, соотношение сторон не более 3:1                                                       |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                                 |
| `quality`         | Модели GPT Image поддерживают `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (включая `:official`) дополнительно поддерживают `xhigh`, `max`. Официальный канал тарифицируется по фактическому использованию Token             |
| `response_format` | `url` или `b64_json`                                                                                                                     |
| `callback_url`    | Необязательно; после завершения длительной задачи отправляет результат на этот адрес                                                                                                                      |

Часто используемые размеры:

| Соотношение   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` выбирает формат кадра на основе пропорций, пикселей и намерения компоновки в промпте; если нужны точные пиксели, укажите размер напрямую.

## 4. Генерация нескольких изображений

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и их псевдонимы `:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются по фактическим Token текстового ввода и вывода изображения в ответе. Цены на странице являются оценкой до запроса, окончательная сумма определяется по записи об использовании.

## 5. Асинхронный callback

После добавления `callback_url` в тело запроса интерфейс сначала вернёт `{"task_id": "..."}`, а после завершения отправит итоговый результат POST-запросом на этот URL; синхронные запросы по-прежнему возвращают `created` и `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Получатель callback должен использовать `task_id` для дедупликации и проверять источник запроса и формат данных.

## 6. Устранение неполадок

| Статус  | Проверьте                                                  |
| --- | --------------------------------------------------- |
| 400 | комбинацию `model`, `prompt`, формата размера, `n` и `response_format`    |
| 401 | является ли API Key полным, имеет ли Header вид `Authorization: Bearer ...` |
| 429 | запросы слишком частые, повторите попытку позже                                         |
| 504 | истекло время ожидания синхронной генерации; используйте `callback_url`                            |

Ответы с ошибками содержат `error.code`, `error.message` и `trace_id`. При сообщении о проблеме предоставьте `trace_id`, не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редактирования изображений смотрите [Редактирование изображений GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 использует интерфейсы генерации, редактирования, асинхронных задач и тарификации версии 2.5:

| Модель                                                          | Тарификация                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/изображение                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/изображение                   |
| `gpt-image-2.6-flare:official`                              | как 2.5 official, по фактическому использованию Token |
| `gpt-image-2.6-sunburst:official`                           | как 2.5 official, по фактическому использованию Token |

Качество может быть `auto`, `low`, `medium`, `high`, `xhigh`, `max`; для размера используйте `auto` или соответствующий указанным выше ограничениям `WIDTHxHEIGHT`. Этот интерфейс поддерживает `png`, `jpeg`, `webp`; GPT Image 2.6 также поддерживает нативные анимированные `gif`, SVG пока не поддерживается. Редактирование поддерживает JSON URL изображений и загрузку файлов multipart. `:reverse` является явным псевдонимом одноимённой обычной версии. Используйте полное наименование модели, не передавайте `gpt-image-2.6`.

### Анимированный GIF GPT Image 2.6

Обычные версии, `:reverse`, `:official` GPT Image 2.6 Flare и Sunburst могут использовать `output_format: "gif"`. Кадры анимации, информация о цикличности и длительность воспроизведения сохраняются; `frame_count` обозначает количество кадров, `frame_duration_ms` обозначает количество миллисекунд на кадр, количество кадров должно быть целым числом от 2 до 16, длительность каждого кадра должна быть целым числом от 20 до 655350 миллисекунд и используется только для GIF; при кодировании выполняется округление до ближайших 10 мс. По умолчанию, если не указано, используются 9 кадров по 200 миллисекунд на кадр; если `size` GIF опущен или равен auto, используется предустановка 512x512.

Рекомендуется сначала использовать `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF имеют отдельные ограничения на размер и количество кадров, нельзя напрямую применять спецификации статического 4K; некоторые модели корректируют фактический размер вывода. `n` обозначает количество возвращаемых GIF-файлов, а не количество кадров анимации. Обычная версия и `:reverse` по-прежнему тарифицируются по количеству успешно созданных файлов, официальная версия — по фактическому использованию Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Статические изображения 4K GPT Image 2.6

Flare, Sunburst и их варианты `:reverse`, `:official` могут использовать упомянутые выше предустановки пикселей 4K, например `3840x2160` и `2160x3840`. Как генерация, так и редактирование передают конкретные пиксели через `size`; `4K` не является допустимым значением `size`, а `4096x4096` также превышает текущий лимит пикселей. Указанные спецификации 4K применимы к статическим PNG/JPEG/WebP, для GIF используйте его специальные параметры.

### Сложность композиции GPT Image 2.6

`complexity` может быть `low`, `medium`, `high`, при отсутствии используется значение модели по умолчанию `high`. Он управляет сложностью планирования и независим от качества рендеринга `quality`; дополнительная плата за запрос не взимается, официальная версия по-прежнему рассчитывается по фактическим Token. Другие модели не поддерживают этот параметр.

GIF не поддерживает mask, изображения с разметкой, пользовательское сжатие, переписывание prompt или потоковый вывод части изображения; несовместимые комбинации будут отклонены до генерации. Размер, количество кадров и количество файлов совместно ограничиваются бюджетом пикселей модели; для обычного Flare подтверждена работоспособность `1024x1024` и 2 кадров, но этот вывод нельзя распространять на все комбинации 1K или GIF 4K.
