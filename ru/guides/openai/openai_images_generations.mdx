## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Отправка первого запроса

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer ваш API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Минималистичная редакционная иллюстрация продукта: одна простая белая керамическая кружка, расположенная по центру на сплошном кобальтово-синем столе, бледно-кремовый фон, мягкая тень, чистые геометрические формы, без текста, без логотипа, портретная композиция",
    "size": "1024x1536"
  }'
```

Успешно ответившее изображение находится в `data[].url`. Ниже приведен результат 1024×1536, полученный 8 сентября 2026 года через Ace Data Cloud (задача `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, трассировка `eb938601-8192-407f-b539-1e0554b697ec`):

![Сгенерированная белая кружка GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Часто используемые параметры

| Поле               | Описание                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендуется по умолчанию), `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); также можно явно выбрать `gpt-image-2:official` или `gpt-image-2:reverse` |
| `prompt`          | Описание изображения, максимум 32,000 символов                                                                                                                     |
| `size`            | `auto` или `WIDTHxHEIGHT`; ширина и высота должны быть кратны 16, длинная сторона не более 3840, общее количество пикселей от 655,360 до 8,294,400, соотношение сторон не более 3:1                                                       |
| `n`               | 1–10; поддерживается только 1 при `response_format=b64_json`                                                                                                 |
| `quality`         | `low`, `medium`, `high` или `auto`; поддержка и способы оплаты различаются для разных линий                                                                                          |
| `response_format` | `url` или `b64_json`                                                                                                                     |
| `callback_url`    | Необязательный; отправить результат на этот адрес после завершения длительной задачи                                                                                                                      |

Часто используемые размеры:

| Соотношение | 1K          | 2K          | 4K          |
| ----------- | ----------- | ----------- | ----------- |
| 1:1         | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3         | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4         | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9        | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16        | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` выберет формат в зависимости от соотношения, пикселей и намерения макета в подсказке; для точных пикселей укажите размеры напрямую.

## 4. Генерация нескольких изображений

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer ваш API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Маленькая лиса, читающая под светящимся грибом, акварельная иллюстрация",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `:reverse` тарифицируются по количеству успешно сгенерированных изображений; `gpt-image-2:official` рассчитывается на основе фактических токенов, использованных для текстового ввода и вывода изображения. Цены на странице являются предварительными оценками перед запросом, окончательные будут основаны на записях использования.

## 5. Асинхронный обратный вызов

После добавления `callback_url` в тело запроса, интерфейс сначала вернет `{"task_id": "..."}`, а по завершении отправит окончательный результат на этот URL методом POST; синхронные запросы по-прежнему возвращают `created` и `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Постер продукта с четкой типографикой",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Получатель обратного вызова должен использовать `task_id` для устранения дубликатов и проверять источник запроса и формат данных.

## 6. Устранение ошибок

| Статус | Проверка                                                  |
| ------ | --------------------------------------------------- |
| 400    | Комбинация `model`, `prompt`, формата размера, `n` и `response_format`    |
| 401    | Полнота API Key, заголовок должен быть `Authorization: Bearer ...` |
| 429    | Слишком много запросов, попробуйте позже                                         |
| 504    | Время ожидания синхронной генерации истекло; используйте `callback_url`                            |

Ошибка ответа будет содержать `error.code`, `error.message` и `trace_id`. При сообщении о проблемах предоставьте `trace_id`, не предоставляя API Key.

Полные поля и актуальные перечисления можно найти на странице [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редактирования изображений смотрите [GPT Image 2 / 2.5 Редактирование изображений](https://platform.acedata.cloud/documents/openai-images-edits).
