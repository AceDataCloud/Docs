## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Отправка первого запроса

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Изображение в успешном ответе находится в `data[].url`. Ниже представлен результат 1024×1536, фактически полученный через Ace Data Cloud 8 сентября 2026 года (задача `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Белая кружка, сгенерированная GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Часто используемые параметры

| Поле                | Описание                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (рекомендуется по умолчанию), `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `prompt`          | Описание изображения, максимум 32 000 символов                                                                                                                     |
| `size`            | `auto` или `WIDTHxHEIGHT`; ширина и высота должны быть кратны 16, длинная сторона не более 3840, общее число пикселей — 655 360–8 294 400, соотношение сторон не более 3:1                                                       |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                                 |
| `quality`         | Модели GPT Image поддерживают `auto`, `low`, `medium`, `high`; только 2.5 Flare / Sunburst (включая `:official`) дополнительно поддерживают `xhigh`, `max`. Официальный канал тарифицируется по фактическому потреблению Token                 |
| `response_format` | `url` или `b64_json`                                                                                                                     |
| `callback_url`    | Необязательно; после завершения длительной задачи отправляет результат на этот адрес                                                                                                                      |

Часто используемые размеры:

| Соотношение   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` выбирает формат кадра на основе соотношения, пикселей и намерения компоновки в промпте; если нужны точные пиксели, укажите размер напрямую.

### Модели и способы тарификации

| Модель                                | Сценарии применения и способ тарификации                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Обратный канал по умолчанию, фиксированная тарификация за число успешно созданных изображений                        |
| `gpt-image-2:reverse`             | Явный выбор обратного канала, фиксированная тарификация за число успешно созданных изображений                      |
| `gpt-image-2:official`            | Официальный API-канал, более высокая стабильность, тарификация по фактическому потреблению Token            |
| `gpt-image-2.5-flare`             | Приоритет скорости генерации, фиксированная тарификация за число успешно созданных изображений                        |
| `gpt-image-2.5-flare:official`    | Официальный API-канал, более высокая стабильность и приоритет скорости генерации, тарификация по фактическому потреблению Token     |
| `gpt-image-2.5-sunburst`          | Приоритет высокой точности и детального контроля, фиксированная тарификация за число успешно созданных изображений                    |
| `gpt-image-2.5-sunburst:official` | Официальный API-канал, более высокая стабильность, приоритет высокой точности и детального контроля, тарификация по фактическому потреблению Token |

Цена на странице для официального API-канала является оценкой до запроса; окончательная сумма определяется фактическим потреблением Token в ответе и записями использования.

## 4. Генерация нескольких изображений

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2:reverse` тарифицируются по числу успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются по фактическим Token текстового ввода и вывода изображений в ответе. Цена на странице является оценкой до запроса, окончательная сумма определяется записями использования.

## 5. Асинхронный callback

После добавления `callback_url` в тело запроса интерфейс сначала вернёт `{"task_id": "..."}`, а после завершения отправит итоговый результат POST-запросом на этот URL; синхронные запросы по-прежнему возвращают `created` и `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Получатель callback должен использовать `task_id` для дедупликации и проверять источник запроса и формат данных.

## 6. Устранение неполадок

| Статус  | Проверьте                                                  |
| --- | --------------------------------------------------- |
| 400 | сочетание `model`, `prompt`, формата размеров, `n` и `response_format`    |
| 401 | является ли API Key полным, указан ли Header как `Authorization: Bearer ...` |
| 429 | запросы выполняются слишком часто, повторите попытку позже                                         |
| 504 | истекло время ожидания синхронной генерации; используйте `callback_url`                            |

Ответы об ошибках содержат `error.code`, `error.message` и `trace_id`. При сообщении о проблеме предоставьте `trace_id`, не предоставляйте API Key.

Полный список полей и актуальные перечисления смотрите на странице [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Для редактирования изображений смотрите [Редактирование изображений GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
