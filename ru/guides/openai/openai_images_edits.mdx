## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), войдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Редактирование с использованием URL изображения

Исходное изображение:

![Исходное изображение для редактирования GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Успешный ответ:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Это результат редактирования, фактически выполненного через Ace Data Cloud 8 сентября 2026 года: кружка стала оранжевой, фон — тёмно-синим морским, при этом сохранены исходная композиция и размер 1024×1536:

![Результат редактирования оранжевой кружки GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Загрузка локального изображения

Используйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можно передавать повторно; серия GPT Image поддерживает до 16 референсных изображений. `image` в JSON-запросе может быть одним URL или массивом URL; для локальных файлов используется загрузка multipart.

## 4. Часто используемые параметры

| Поле                | Описание                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `image`           | В JSON используется один URL или массив до 16 URL; в multipart используется одно или несколько файловых полей `image`                                                                    |
| `prompt`          | Инструкция по редактированию                                                                                                                             |
| `size`            | `auto` или соответствующий ограничениям `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                           |
| `response_format` | `url` или `b64_json`                                                                                                               |
| `callback_url`    | Необязательный адрес асинхронного обратного вызова                                                                                                                         |

Правила размеров совпадают с интерфейсом генерации: ширина и высота должны быть кратны 16, длинная сторона не должна превышать 3840, общее количество пикселей составляет 655,360–8,294,400, а соотношение сторон не должно превышать 3:1. Если не указывать `size` или использовать `auto`, модель выберет формат кадра на основе промпта и первого референсного изображения.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются по фактическим Token текстового ввода, ввода референсных изображений и вывода изображений, окончательным считается журнал использования.

## 5. Асинхронные обратные вызовы и устранение ошибок

Для длительных задач можно добавить в запрос:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронный ответ 200 имеет вид `{"task_id": "..."}`; после завершения обратный вызов возвращает итоговый результат. Синхронный запрос, напротив, возвращает `created` и `data`.

| Статус  | Проверка                      |
| --- | ----------------------- |
| 400 | Формат/количество изображений, комбинация параметров и формат размера       |
| 401 | API Key и Bearer Header |
| 429 | Частота запросов                    |
| 504 | Перейдите на асинхронный обратный вызов                  |

Ответы с ошибками содержат `trace_id`. При сообщении о проблеме предоставляйте этот ID, не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерации изображений только из текста смотрите [генерацию изображений GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
