## 3. Загрузка локального изображения

Используйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Можно повторно передавать `image`; серия GPT Image поддерживает до 16 референсных изображений. `image` в JSON-запросе может быть одним URL или массивом URL; локальные файлы загружаются через multipart.

### Модели и способы тарификации

| Модель                                | Применимые сценарии и способ тарификации                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Канал обратного инжиниринга по умолчанию, фиксированная тарификация за количество успешно созданных изображений                        |
| `gpt-image-2:reverse`             | Явный выбор канала обратного инжиниринга, фиксированная тарификация за количество успешно созданных изображений                      |
| `gpt-image-2:official`            | Официальный канал API, более высокая стабильность, тарификация по фактическому потреблению Token            |
| `gpt-image-2.5-flare`             | Ориентирован на скорость генерации, фиксированная тарификация за количество успешно созданных изображений                        |
| `gpt-image-2.5-flare:official`    | Официальный канал API, более высокая стабильность и ориентация на скорость генерации, тарификация по фактическому потреблению Token     |
| `gpt-image-2.5-sunburst`          | Ориентирован на высокую точность и детальный контроль, фиксированная тарификация за количество успешно созданных изображений                    |
| `gpt-image-2.5-sunburst:official` | Официальный канал API, более высокая стабильность и ориентация на высокую точность и детальный контроль, тарификация по фактическому потреблению Token |

Цена на странице для официального канала API является оценкой до запроса; окончательная стоимость определяется фактическим потреблением Token в ответе и записями об использовании.

## 4. Локальное редактирование с использованием маски

Официальный интерфейс Images Edit использует `mask` для указания области, в которой разрешены изменения. Модели Ace Data Cloud с `:official` следуют тому же multipart-контракту:

- `mask` должна быть PNG с Alpha-каналом размером не более 4 МБ;
- размер маски должен полностью совпадать с первой `image`;
- прозрачные пиксели с Alpha, равным `0`, обозначают разрешённые для редактирования области, непрозрачные пиксели обозначают области, которые следует сохранить;
- RGB-изображения только с чёрно-белыми цветами, но без канала прозрачности, не могут использоваться в качестве действительных масок;
- подсказка должна описывать ожидаемое полное изображение, одновременно явно указывая локальные изменения и содержимое, которое должно остаться неизменным.

Ниже сначала создаётся маска из исходного изображения. В примере центральный прямоугольник делается прозрачным, разрешая модели изменять только эту область:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Затем загрузите исходное изображение и маску вместе:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Также можно использовать способ вызова `images.edit` из официального Python SDK OpenAI, достаточно направить `base_url` на Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

При использовании `mask` исходное изображение и маска должны быть загружены в одном multipart-запросе через `image=@input.png` и `mask=@mask.png` соответственно. Не передавайте вместе исходное изображение по URL и локальный файл маски; запросы редактирования только с URL не поддерживают добавление локального файла `mask`. Маска ограничивает область редактирования, но модель генерации всё равно может естественно смешивать края; если требуются строгие границы, следует использовать чёткие Alpha-края и повторно указать в подсказке, какое содержимое должно остаться неизменным.

Приведённый выше способ вызова соответствует примерам масок из [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) и [официального Cookbook для GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Часто используемые параметры
| Поле                | Описание                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `image`           | В JSON используется один URL или массив до 16 URL; в multipart используется одно или несколько полей файлов `image`. При использовании `mask` необходимо загрузить локальный файл изображения                                              |
| `mask`            | Необязательная PNG-маска, только загрузка multipart-файла; должна иметь Alpha-канал, совпадать по размеру с первым `image` и не превышать 4 МБ                                                                 |
| `prompt`          | Инструкция по редактированию                                                                                                                             |
| `size`            | `auto` или соответствующий ограничениям `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                           |
| `response_format` | `url` или `b64_json`                                                                                                               |
| `callback_url`    | Необязательный адрес асинхронного обратного вызова                                                                                                                         |

Правила размеров совпадают с интерфейсом генерации: ширина и высота должны быть кратны 16, длинная сторона не должна превышать 3840, общее количество пикселей должно составлять 655 360–8 294 400, а соотношение сторон не должно превышать 3:1. При отсутствии `size` или использовании `auto` модель выберет формат кадра на основе промпта и первого референсного изображения.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются по фактическим токенам текстового ввода, ввода референсных изображений и вывода изображений, окончательные данные определяются журналом использования.

## 6. Асинхронные обратные вызовы и устранение ошибок

Для длительных задач в запрос можно добавить:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронный ответ 200 имеет вид `{"task_id": "..."}`; после завершения вызывается обратный вызов с окончательным результатом. Синхронные запросы возвращают `created` и `data`.

| Статус  | Проверка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/количество изображений, комбинация параметров и формат размеров; при использовании `mask` проверьте PNG Alpha-канал, ограничение 4 МБ и совпадение её размера с первым исходным изображением |
| 401 | API Key и Bearer Header                                           |
| 429 | Частота запросов                                                              |
| 504 | Перейдите на асинхронный обратный вызов                                                            |

Ответы с ошибками содержат `trace_id`. При сообщении о проблеме предоставьте этот ID, не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерации изображений только из текста смотрите [Генерация изображений GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
