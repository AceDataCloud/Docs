## 2. Редактирование с использованием URL изображения

Исходное изображение:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
```

## 3. Загрузка локального изображения

Используйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Можно многократно передавать `image`; серия GPT Image поддерживает до 16 референсных изображений. `image` в JSON-запросе может быть одним URL или массивом URL; локальные файлы загружаются через multipart.

### Модели и способ тарификации

| Модель                                | Применимые сценарии и способ тарификации                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Канал обратной обработки по умолчанию, фиксированная тарификация по количеству успешно созданных изображений                        |
| `gpt-image-2:reverse`             | Явный выбор канала обратной обработки, фиксированная тарификация по количеству успешно созданных изображений                      |
| `gpt-image-2:official`            | Канал официального API, более высокая стабильность, тарификация по фактическому потреблению Token            |
| `gpt-image-2.5-flare`             | Ориентирован на скорость генерации, фиксированная тарификация по количеству успешно созданных изображений                        |
| `gpt-image-2.5-flare:official`    | Канал официального API, более высокая стабильность и ориентация на скорость генерации, тарификация по фактическому потреблению Token     |
| `gpt-image-2.5-sunburst`          | Ориентирован на высокую точность воспроизведения и детальный контроль, фиксированная тарификация по количеству успешно созданных изображений                    |
| `gpt-image-2.5-sunburst:official` | Канал официального API, более высокая стабильность и ориентация на высокую точность воспроизведения и детальный контроль, тарификация по фактическому потреблению Token |

Цена на странице для канала официального API является оценкой до запроса; окончательная сумма определяется фактическим потреблением Token в ответе и записями об использовании.

## 4. Локальное редактирование с использованием маски

Официальный интерфейс Images Edit использует `mask` для указания области, разрешённой для изменения. Модели Ace Data Cloud с `:official` следуют тому же multipart-контракту:

- `mask` должен быть PNG с Alpha-каналом, размером не более 4 МБ;
- размер маски должен полностью совпадать с первой `image`;
- прозрачные пиксели с Alpha, равным `0`, обозначают разрешённые для редактирования области, а непрозрачные пиксели обозначают области, которые следует сохранить;
- RGB-изображение только с чёрным и белым цветами, но без прозрачного канала, не может использоваться как действительная маска;
- промпт должен описывать желаемое итоговое изображение целиком, одновременно явно указывая локальные изменения и содержимое, которое должно остаться неизменным.

Ниже сначала создаётся маска из исходного изображения. В примере центральный прямоугольник делается прозрачным, позволяя модели изменять только эту область:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Затем загрузите исходное изображение и маску вместе:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Также можно использовать способ вызова `images.edit` из официального Python SDK OpenAI, достаточно указать Ace Data Cloud в качестве `base_url`:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

При использовании `mask` исходное изображение и маска должны быть загружены в одном multipart-запросе через `image=@input.png` и `mask=@mask.png` соответственно. Не передавайте вместе URL исходного изображения и локальный файл маски; запросы редактирования только с URL не поддерживают дополнительное прикрепление локального файла `mask`. Маска ограничивает область редактирования, но модель генерации всё ещё может естественно сглаживать края; если требуются строгие границы, следует использовать чёткие Alpha-края и повторно указать в промпте, какое содержимое должно остаться неизменным.

Приведённый выше способ вызова соответствует примерам масок в [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) и [официальном Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. Часто используемые параметры

| Поле                | Описание                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `image`           | В JSON используется один URL или массив максимум из 16 URL; в multipart используется одно или несколько полей файлов `image`. При использовании `mask` необходимо загрузить локальный файл изображения                                              |
| `mask`            | Необязательная PNG-маска, только для загрузки файлов multipart; должна иметь Alpha-канал, совпадать по размеру с первым `image` и не превышать 4 МБ                                                                 |
| `prompt`          | Инструкция по редактированию                                                                                                                             |
| `size`            | `auto` или соответствующий ограничениям `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                           |
| `response_format` | `url` или `b64_json`                                                                                                               |
| `callback_url`    | Необязательный адрес асинхронного обратного вызова                                                                                                                         |

Правила размеров соответствуют интерфейсу генерации: ширина и высота должны быть кратны 16, длинная сторона не должна превышать 3840, общее количество пикселей должно составлять 655 360–8 294 400, а соотношение сторон не должно превышать 3:1. При пропуске `size` или использовании `auto` модель выберет формат кадра на основе промпта и первого референсного изображения.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются на основе фактических Token текстового ввода, ввода референсных изображений и вывода изображений, окончательные данные определяются записями об использовании.

## 6. Асинхронный обратный вызов и устранение ошибок

Для длительных задач можно добавить в запрос:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронный ответ 200 имеет вид `{"task_id": "..."}`; после завершения будет выполнен обратный вызов с итоговым результатом. Синхронный запрос возвращает `created` и `data`.

| Статус  | Проверка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/количество изображений, комбинации параметров и формат размеров; при использовании `mask` проверьте PNG Alpha-канал, ограничение 4 МБ и соответствие его размеров первой исходной картинке |
| 401 | API Key и Bearer Header                                           |
| 429 | Частота запросов                                                              |
| 504 | Перейдите на асинхронный обратный вызов                                                            |

Ответы с ошибками содержат `trace_id`. При сообщении о проблеме предоставьте этот ID, не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерации изображений только по тексту смотрите [Генерация изображений GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
