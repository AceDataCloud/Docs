## 3. Загрузка локального изображения

Используйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` можно передавать повторно; серия GPT Image поддерживает до 16 референсных изображений. `image` в JSON-запросе может быть одним URL или массивом URL; локальные файлы загружаются через multipart.

Цена на странице для официального API-канала является оценкой до запроса; окончательный расчёт основывается на фактическом потреблении Token в ответе и записях об использовании.

`quality` поддерживает `auto`, `low`, `medium`, `high`; Flare и Sunburst 2.5 / 2.6 (включая варианты `:reverse` и `:official`) дополнительно поддерживают `xhigh`, `max`. Это поле можно передавать как при редактировании URL изображения через JSON, так и при редактировании файла через multipart; официальный канал тарифицируется по фактическому потреблению Token.

## 4. Локальное редактирование с использованием маски

Официальный интерфейс Images Edit использует `mask` для указания области, разрешённой для изменения. Модели Ace Data Cloud с `:official` следуют тому же multipart-контракту:

- `mask` должна быть PNG с Alpha-каналом размером не более 4 МБ;
- размер маски должен полностью совпадать с первой `image`;
- прозрачные пиксели с Alpha, равным `0`, обозначают разрешённые для редактирования области, непрозрачные пиксели обозначают то, что следует сохранить;
- RGB-изображения только с чёрным и белым цветами, но без прозрачного канала, не могут использоваться как действительные маски;
- подсказка должна описывать желаемое полное изображение, одновременно явно указывая локальные изменения и содержимое, которое должно остаться неизменным.

Ниже сначала создаётся маска из исходного изображения. В примере центральный прямоугольник сделан прозрачным, разрешая модели изменять только эту область:
```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Затем загрузите вместе исходное изображение и маску:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Также можно использовать способ вызова `images.edit` из официального Python SDK OpenAI, нужно лишь указать `base_url` на Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

При использовании `mask` исходное изображение и маска должны быть загружены в одном multipart-запросе отдельно через `image=@input.png` и `mask=@mask.png`. Не передавайте вместе URL исходного изображения и локальный файл маски; запросы редактирования только с URL не поддерживают дополнительное прикрепление локального файла `mask`. Маска ограничивает область редактирования, но модель генерации всё ещё может естественно смешивать края; если требуются строгие границы, следует использовать чёткие Alpha-границы и повторно указать в подсказке, какой контент должен оставаться неизменным.

Указанный выше способ вызова соответствует примерам масок в [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) и [официальном Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Часто используемые параметры

| Поле                | Описание                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (быстрее) или `gpt-image-2.5-sunburst` (более высокая точность и контроль); для всех трёх можно выбрать соответствующий вариант `:official`, а `gpt-image-2` также поддерживает `:reverse` |
| `image`           | JSON использует один URL или массив максимум из 16 URL; multipart использует одно или несколько полей файлов `image`. При использовании `mask` необходимо загрузить локальный файл изображения                                              |
| `mask`            | Необязательная PNG-маска, только для загрузки multipart-файлов; должна иметь Alpha-канал, совпадать по размеру с первым `image` и не превышать 4 МБ                                                                 |
| `prompt`          | Инструкция по редактированию                                                                                                                             |
| `size`            | `auto` или соответствующий ограничениям `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; при `response_format=b64_json` поддерживается только 1                                                                                           |
| `response_format` | `url` или `b64_json`                                                                                                               |
| `callback_url`    | Необязательный адрес асинхронного обратного вызова                                                                                                                         |

Правила размеров совпадают с интерфейсом генерации: ширина и высота должны быть кратны 16, длинная сторона не должна превышать 3840, общее количество пикселей должно составлять 655,360–8,294,400, а соотношение сторон не должно превышать 3:1. Если `size` опущен или используется `auto`, модель выберет формат изображения на основе подсказки и первого референсного изображения.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и их псевдонимы `:reverse` тарифицируются по количеству успешно созданных изображений; `gpt-image-2:official`, `gpt-image-2.5-flare:official` и `gpt-image-2.5-sunburst:official` рассчитываются по фактическим токенам текстового ввода, ввода референсных изображений и вывода изображений, окончательные данные определяются записями об использовании.

## 6. Асинхронные обратные вызовы и отладка

Для длительных задач можно добавить в запрос:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронный ответ 200 имеет вид `{"task_id": "..."}`; после завершения будет выполнен обратный вызов с итоговым результатом. Синхронные запросы возвращают `created` и `data`.

| Статус  | Проверка                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Формат/количество изображений, комбинация параметров и формат размеров; при использовании `mask` проверьте PNG Alpha-канал, ограничение 4 МБ и соответствие его размеров первому исходному изображению |
| 401 | API Key и Bearer Header                                           |
| 429 | Частота запросов                                                              |
| 504 | Перейдите на асинхронный обратный вызов                                                            |

Ответы с ошибками содержат `trace_id`. При сообщении о проблеме предоставьте этот ID, не предоставляйте API Key.

Полный список полей и актуальные перечисления приведены на странице [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерации изображений только по тексту смотрите [Генерация изображений GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-generations).

## GPT Image 2.6

GPT Image 2.6 использует интерфейсы генерации, редактирования, асинхронных задач и тарификации версии 2.5:

| Модель                                                          | Тарификация                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/изображение                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/изображение                   |
| `gpt-image-2.6-flare:official`                              | Такая же, как у 2.5 official, по фактическому использованию Token |
| `gpt-image-2.6-sunburst:official`                           | Такая же, как у 2.5 official, по фактическому использованию Token |

Качество может быть `auto`, `low`, `medium`, `high`, `xhigh`, `max`; для размера используйте `auto` или соответствующий указанным выше ограничениям `WIDTHxHEIGHT`. Этот интерфейс поддерживает `png`, `jpeg`, `webp`; GPT Image 2.6 также поддерживает нативные анимированные `gif`, SVG пока не поддерживается. Редактирование поддерживает URL изображений в JSON и загрузку multipart-файлов. `:reverse` — явный псевдоним обычной версии с тем же названием. Используйте полное наименование модели, не передавайте `gpt-image-2.6`.

### Преобразование изображений GPT Image 2.6 в анимированные GIF
Обычная версия GPT Image 2.6 Flare, Sunburst, а также `:reverse` и `:official` могут использовать `output_format: "gif"`. Кадры анимации, информация о цикле и длительность воспроизведения сохраняются; `frame_count` обозначает количество кадров, `frame_duration_ms` обозначает количество миллисекунд на кадр, количество кадров должно быть целым числом от 2 до 16, длительность каждого кадра должна быть целым числом от 20 до 655350 миллисекунд и используется только для GIF; при кодировании выполняется округление до ближайших 10 мс. Если не указано, по умолчанию используются 9 кадров по 200 миллисекунд каждый; если `size` для GIF опущен или равен auto, используется предустановка 512x512.

Рекомендуется сначала использовать `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. У GIF есть отдельные ограничения на размер и количество кадров, поэтому нельзя напрямую применять спецификации статического 4K; некоторые модели корректируют фактический размер вывода. `n` обозначает количество возвращаемых GIF-файлов, а не количество кадров анимации. Обычная версия и `:reverse` по-прежнему тарифицируются по количеству успешно созданных файлов, официальная версия тарифицируется по фактическому использованию Token.

```json
{
  "model": "gpt-image-2.6-flare",
  "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",
  "prompt": "Animate the mug gently moving left and right. Keep its appearance and the background, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Статические изображения GPT Image 2.6 4K

Flare, Sunburst и их варианты `:reverse`, `:official` могут использовать вышеупомянутые предустановки 4K-пикселей, например `3840x2160` и `2160x3840`. Как генерация, так и редактирование передают конкретные пиксели через `size`; `4K` не является допустимым значением `size`, а `4096x4096` также превышает текущий лимит пикселей. Указанные выше спецификации 4K применимы к статическим PNG/JPEG/WebP; для GIF используйте его специализированные параметры.

### Сложность композиции GPT Image 2.6

`complexity` может принимать значения `low`, `medium`, `high`; если он опущен, используется значение модели по умолчанию `high`. Он управляет сложностью планирования и не зависит от качества рендеринга `quality`; дополнительная плата за запрос не взимается, официальная версия по-прежнему рассчитывается по фактическим Token. Другие модели не поддерживают этот параметр.

GIF не поддерживает mask, изображение разметки, пользовательское сжатие, переписывание подсказки или потоковый вывод части изображения; несовместимые комбинации будут отклонены до генерации. Размер, количество кадров и количество файлов совместно ограничены пиксельным бюджетом модели; для обычного Flare подтверждена работоспособность `1024x1024`, 2 кадров, но этот вывод нельзя распространять на все комбинации 1K или GIF 4K.

### Редактирование с направляющей разметкой

Статическое редактирование GPT Image 2.6 поддерживает `markup`. Загрузите прозрачный PNG того же размера, что и первое эталонное изображение, обведите на отдельном слое места, которые нужно изменить, и укажите требования к изменениям в `prompt`. Слой разметки должен содержать прозрачные пиксели; каждое из двух изображений не должно превышать 16777216 пикселей, а изображение разметки не должно превышать 40 МБ. JSON может передавать HTTPS URL, PNG base64 data URL или `{ "image_url": "https://..." }`; в multipart файл загружается через `markup`. Платформа передаёт слой разметки в виде файла. `markup` нельзя использовать вместе с `mask`, GIF или `prompt_rewriter`, `file_id` не поддерживается.

`input_fidelity` не применим к GPT Image 2.6, пожалуйста, опустите его.
