## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Редактирование с использованием URL изображения

Исходное изображение:

![GPT Image 2 Редактирование исходного изображения](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer ваш API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Сохраните кружку, стол, угол камеры, портретную компоновку и мягкую тень без изменений. Измените только цвет кружки с белого на ярко-оранжевый и бледно-кремовый фон на сплошной темно-морской синий. Без текста и логотипа.",
    "size": "1024x1536"
  }'
```

Успешный ответ:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

Это результат редактирования, выполненного 8 сентября 2026 года через Ace Data Cloud, кружка стала оранжевой, фон стал темно-морской синий, при этом сохранилась оригинальная компоновка и размер 1024×1536:

![GPT Image 2 Результат редактирования оранжевой кружки](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Загрузка локального изображения

Используйте `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer ваш API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Замените фон на яркую современную студию"
```

Можно повторно передавать `image`, серия GPT Image поддерживает до 16 изображений для справки. В JSON запросе `image` может быть одним URL или массивом URL; локальные файлы загружаются с помощью multipart.

## 4. Часто используемые параметры

| Поле                | Описание                                                        |
| ----------------- | ------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` или `gpt-image-2:reverse`  |
| `image`           | JSON использует один URL или массив из максимум 16 URL; multipart использует одно или несколько полей файла `image` |
| `prompt`          | Инструкция по редактированию                                      |
| `size`            | `auto` или соответствующий ограничению `WIDTHxHEIGHT`              |
| `n`               | 1–10; поддерживается только 1 при `response_format=b64_json`      |
| `response_format` | `url` или `b64_json`                                          |
| `callback_url`    | Необязательный адрес для асинхронного обратного вызова              |

Правила размеров аналогичны интерфейсу генерации: ширина и высота должны быть кратны 16, длинная сторона не должна превышать 3840, общее количество пикселей не должно превышать 8,294,400. Если `size` опущен или используется `auto`, модель выберет формат в зависимости от подсказки и первого изображения для справки.

По умолчанию `gpt-image-2` и `:reverse` тарифицируются по количеству успешных изображений; `gpt-image-2:official` рассчитывается на основе фактических токенов текстового ввода, ввода изображений и вывода изображений, окончательно по записям использования.

## 5. Асинхронный обратный вызов и отладка

Долгие задачи могут включать в запрос:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Асинхронный ответ 200 будет `{"task_id": "..."}`; после завершения будет вызван обратный вызов с окончательным результатом. Синхронный запрос вернет `created` и `data`.

| Статус  | Проверка                  |
| --- | ----------------------- |
| 400 | Формат/количество изображений, комбинация параметров и формат размеров |
| 401 | API Key и Bearer Header |
| 429 | Частота запросов                |
| 504 | Используйте асинхронный обратный вызов  |

Ошибка ответа будет содержать `trace_id`. При сообщении о проблемах предоставьте этот ID, не предоставляя API Key.

Полные поля и актуальная информация доступны на странице [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Для генерации изображений в чистом текстовом формате смотрите [GPT Image 2 Генерация изображений](https://platform.acedata.cloud/documents/openai-images-generations).
