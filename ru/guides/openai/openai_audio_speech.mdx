---
title: "OpenAI API для синтеза речи (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Синтезируйте текст в естественную речь, **полностью совместимо с OpenAI `/v1/audio/speech`**. Любой SDK OpenAI просто указывает `base_url` на `https://api.acedata.cloud` и заменяет ключ на ваш AceData Token для непосредственного использования. Интерфейс синхронно возвращает поток байтов аудио.

- **Адрес запроса**: `POST https://api.acedata.cloud/v1/audio/speech` (псевдоним `POST /openai/audio/speech`)
- **Аутентификация**: заголовок запроса `Authorization: Bearer {token}`
- **Оплата**: оплата по количеству байтов текста запроса, примерно 85% от официальной цены OpenAI (см. таблицу ниже).

## Параметры запроса

| Поле                | Тип     | Обязательное | Описание                                                       |
| ----------------- | ------ | ----------- | ----------------------------------------------------------- |
| `input`           | string | Да          | Текст для синтеза.                                            |
| `model`           | string | Нет         | `tts-1` (быстрее) или `tts-1-hd` (высокое качество, по умолчанию). |
| `voice`           | string | Нет         | Один из `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, по умолчанию `alloy`. |
| `response_format` | string | Нет         | `mp3` (по умолчанию), `opus`, `aac`, `flac`, `wav`, `pcm`.  |
| `speed`           | number | Нет         | Скорость речи 0.25–4.0, по умолчанию 1.0.                     |

## Пример

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Что если один API даст вам каждую модель AI видео?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Возвращается сам аудиофайл (`Content-Type: audio/mpeg`), который можно записать в `speech.mp3` для воспроизведения.

С использованием официального OpenAI Python SDK:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Привет от AceData.").stream_to_file("speech.mp3")
```

## Цены

| Модель         | Официальная цена OpenAI | Цена на этой платформе (примерно 85% скидка) |
| ---------- | ------------------- | -------------------------- |
| `tts-1`    | $15 / 1 миллион символов | примерно $12.75 / 1 миллион символов |
| `tts-1-hd` | $30 / 1 миллион символов | примерно $25.5 / 1 миллион символов  |

> Оплата по количеству байтов текста запроса; поле `official_price` показывает официальную цену OpenAI для сравнения.

## Коды ошибок

| Код состояния | code                    | Описание               |
| --- | ----------------------- | -------------------- |
| 400 | `bad_request`           | `input` пустой или параметры недействительны. |
| 401 | `authentication_failed` | токен недействителен.  |
| 403 | `used_up`               | недостаточно средств.   |
| 429 | `too_many_requests`     | запросы слишком частые.  |
| 500 | `api_error`             | ошибка на стороне сервера/внутренняя ошибка. |
