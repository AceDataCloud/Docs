Flux Videos API использует `POST /flux/videos` для генерации видео, генерации видео из ключевых кадров, продолжения видео и улучшения черновиков. `action=generate` (по умолчанию), `mode` выбирает режим генерации; для запроса результатов единообразно используется существующий `POST /flux/tasks`.

> В настоящее время Beta. Генерация видео из текста, генерация видео из изображений, продолжение видео и улучшение черновиков уже доступны. HTTP 200 и ID задачи означают только принятие задачи, необходимо продолжить запрос конечного результата.

## 1. Получение API Token

1. Зарегистрируйтесь или войдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), создайте приложение и получите API Token. Один универсальный API Token может вызывать сервисы платформы; убедитесь, что приложение имеет права на вызов сервиса Flux и доступный баланс.
2. Просмотрите тарифы и цены каждой операции на [странице сервиса Flux](https://platform.acedata.cloud/services/flux?tab=pricing). При недостаточном балансе пополните его на [странице баланса консоли](https://platform.acedata.cloud/console/coin).
3. Запросы используют `Authorization: Bearer &lt;ваш Token>`. Token должен храниться в переменных окружения сервера, не записывайте его на фронтенд-страницы, в публичные репозитории, скриншоты или callback URL.

![Получение API Token в консоли](https://cdn.acedata.cloud/dvc3cg.jpg)

Код в этой статье единообразно считывает переменную окружения:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| Пункт      | Значение                                               |
| ------- | ----------------------------------------------- |
| Корневой адрес API | `https://api.acedata.cloud`                     |
| Отправка задачи видео  | `POST /flux/videos`                             |
| Запрос существующей задачи  | `POST /flux/tasks`                              |
| Аутентификация      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Формат запроса    | `Content-Type: application/json`                |

Полный список полей и онлайн-отладку смотрите в [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), запрос задач — в [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks).

## 2. Выбор операции и входных данных

| action                      | mode            | Ввод                       | Результат            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（значение по умолчанию при пропуске action） | `t2v`           | `prompt`                 | Генерация видео из текста       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | Генерация видео из одного или нескольких ключевых кадров |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | Продолжение на основе входного видео      |
| `generate`                  | `draft_enhance` | `draft_task_id` собственного завершённого черновика | Улучшение этого черновика         |

Модель генерации — `flux-3`, `action` — `generate` (по умолчанию). Через `mode` выбираются генерация видео из текста, генерация видео из изображений, продолжение видео или улучшение черновика.

### Общие параметры генерации

| Параметр                 | Описание                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Обязательный; `t2v`, `i2v`, `v2v` или `draft_enhance`                       |
| `prompt`           | Обязателен для обычной генерации; при улучшении черновика нельзя переопределять исходный промпт                                        |
| `duration`         | Для t2v/i2v — целое число 5–20 секунд, для v2v — целое число 5–15 секунд или `auto`; итоговая длительность вывода может немного отличаться от запрошенного значения |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; по умолчанию для обычной генерации — `hd`, для улучшения черновика — `fhd`              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | Создавать ли сначала черновик; черновики поддерживают только `hd`                                           |
| `generate_audio`   | Генерировать ли синхронизированный звук; `false` является допустимым значением, сохраняйте явное булево значение                               |
| `safety_tolerance` | Необязательный; целое число от 0 до 4                                                   |
| `async`            | Рекомендуется установить в `true`, чтобы сразу вернуть ID задачи платформы, затем опрашивать результат                                |
| `callback_url`     | Необязательный; HTTP(S)-адрес для получения итогового JSON-результата; после настройки также будет асинхронно принят                        |

URL материалов должен быть доступен для чтения сервисом. При использовании временного подписанного URL следует предусмотреть достаточный срок действия для загрузки и обработки. Не используйте адрес веб-страницы как адрес файла изображения или видео.

## 3. Генерация видео из текста: полный протестированный запрос и результат

Следующий запрос был успешно выполнен в production-интерфейсе до изменения цен 2026-10-02. Пропуск `action` подтвердил поведение генерации по умолчанию; `async=true` позволяет избежать долгого ожидания HTTP-соединения.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Ответ о принятии (реальный ID задачи):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Сохраните `task_id` из собственного ответа и продолжите запрос; не используйте ID задачи из примера документации для запроса результатов других аккаунтов.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

Поле `response`, возвращаемое запросом задачи, содержит конечный бизнес-результат. Ниже приведён успешно протестированный в этот раз `response`, внешние метаданные задачи опущены. URL видео в документации был заменён копией того же файла в долгосрочном примере CDN (SHA-256 совпадает); фактический вызов вернёт URL результата собственной задачи:
```json

  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
```

[Просмотреть тестовое видео этого запуска](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。Проверка медиа подтверждает, что результатом является MP4 размером 1280×704, 24 fps и длительностью 5.041667 секунды, размер файла — 2,607,276 байт.

| Поле ответа                              | Назначение                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Успешно ли завершена конечная задача; возврат task_id на этапе принятия не равен success=true |
| `task_id`                         | ID задачи платформы, используется для опроса и идемпотентной бизнес-обработки                      |
| `trace_id`                        | Предоставляется сотрудникам поддержки при устранении неполадок                             |
| `data[].video_url`                | Доступный для чтения адрес результата видео                               |
| `data[].seconds/width/height/fps` | Фактические длительность, размеры и частота кадров выходных данных, измеренные сервером                       |
| `data[].draft_task_id`            | Входной ID улучшения черновика; появляется только при возврате повторно используемого черновика                  |
| `usage`                           | Использование для окончательного выставления счёта; не заменяйте фактические seconds запрошенным duration      |
| `cost.amount`                     | Credits, окончательно списанные за этот раз; `currency=credit` — не доллары США   |
| `cost.list_amount`                | Credits до скидки на потребление для пользователей приложения; возвращается при применимости                 |

Это исторический тест до изменения цены: `list_amount=2.9871876975` Credits, аккаунт в то время имел скидку 10% на потребление, фактический `amount=2.68846892775` Credits. Новая цена от 2026-10-02 снижена примерно на 6.33%; такой же черновик длительностью 5.041667 секунды по текущей цене составляет 2.798125185 Credits (до скидки на потребление), а при сохранении скидки на потребление 10% — 2.5183126665 Credits. Счета по историческим задачам не пересчитываются. Тарифы и скидки других аккаунтов могут отличаться; это не фиксированная цена в долларах США для всех пользователей.

## 4. Видео из изображения: обычные и с ключевыми кадрами по времени

Ниже приведены примеры параметров, в которых необходимо заменить URL материалов; это не заявление о том, что этот пример уже был успешно выполнен. После завершения генерации выполните запрос по описанному выше процессу, структура результата будет такой же.

Для одного или двух изображений используйте обычный массив:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

При указании момента ключевого кадра используйте пару `[секунды, URL изображения]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

Допускается от 1 до 10 ключевых кадров. Массив со временем должен быть отсортирован по возрастанию времени, время должно составлять от 0 до 20 секунд, нельзя смешивать обычные URL и элементы со временем. Для трёх или более обычных ключевых кадров необходимо явно указать duration, нельзя использовать auto.

Передайте адрес существующего видеофайла в `start_video`, `mode=v2v`, продолжительность — максимум 15 секунд.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "v2v",
  "prompt": "Continue the sailboat drifting forward with the same steady camera.",
  "start_video": "https://example.com/source.mp4",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

## 6. Сначала черновик, затем улучшение

1. Создайте черновик с `draft=true`、`resolution=hd` и дождитесь успеха.
2. Получите ID черновика платформы из итогового `data[0].draft_task_id`.
3. Отправьте запрос на улучшение с учётными данными приложения того же владельца:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

При улучшении черновика нельзя передавать `prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video` для переопределения исходного содержимого. Кэш черновика является временным ресурсом, пожалуйста, своевременно выполняйте улучшение; постоянное хранение или фиксированное число дней хранения не гарантируются. Черновики не от владельца/не из текущего приложения, незавершённые черновики и недействительный кэш не могут быть использованы повторно. Черновик и улучшение — это две задачи, и после успеха они тарифицируются отдельно.

## 7. Сквозной вызов Python

Установите `requests`, задайте собственный Token и запустите приведённый ниже скрипт, чтобы выполнить «одна отправка → опрос → вывод URL видео». Для запросов и повторных попыток сети следует использовать исходный task_id, чтобы избежать повторной отправки платных задач.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

После тайм-аута сети не считайте неизвестный статус ошибкой и не отправляйте запрос немедленно повторно. Если `task_id` уже получен, продолжайте запрашивать эту задачу; сохраняйте `task_id` и `trace_id` для упрощения диагностики. Сам интерфейс опроса не взимает плату за генерацию.

## 8. Использование обратного вызова

При отправке добавьте `callback_url`; после завершения задачи на этот адрес будет отправлен POST-запрос с итоговым JSON-результатом. Структура успешного результата совпадает с ранее описанным response, а при ошибке содержит error.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Адрес обратного вызова должен быть доступен из публичной сети. После получения уведомления выполняйте идемпотентную обработку по `task_id`, как можно скорее возвращайте 2xx; бизнес-обработку можно поставить в очередь. Этот документ не заявляет, что обратный вызов имеет аутентификацию подписью: перед чувствительными операциями, такими как предоставление бизнес-привилегий, используйте собственный Token для запроса той же задачи и проверки результата. Если обратный вызов не получен, также можно продолжать опрос, не генерируйте повторно.

## 10. Частые вопросы и диагностика

| Ситуация                       | Рекомендация                                                   |
| ------------------------ | ---------------------------------------------------- |
| Ошибка параметров (400)                | Проверьте action=generate, mode, duration, формат ключевых кадров; не смешивайте поля разных режимов генерации |
| Ошибка аутентификации (401)                | Проверьте Bearer Token, разрешения приложения и действительность учётных данных                          |
| Отклонено модерацией контента (403)              | Скорректируйте материалы и подсказки, не отправляйте повторно без изменений                                    |
| Ограничение скорости (429)                  | Уменьшите параллелизм, повторяйте запросы с экспоненциальной задержкой                                            |
| service_unavailable (503) | Текущая операция недоступна; принятые асинхронные задачи могут сообщить эту ошибку в итоговом response                |
| `task_id` уже возвращён, но видео ещё нет        | Продолжайте запрашивать response, не считайте HTTP 200 завершением генерации                     |
| Черновик нельзя повторно использовать                   | Убедитесь, что это ваш аккаунт/текущее приложение, задача завершена, исходный запрос содержал draft=true, и проверьте, что временный кэш всё ещё действителен          |

При отправке отзыва предоставьте `task_id`, `trace_id`, время запроса и обезличенные параметры, не отправляйте API Token. Дополнительные способы смотрите в [руководстве по интеграции Flux MCP](https://platform.acedata.cloud/documents/flux-mcp).
