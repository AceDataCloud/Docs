Claude Code — это инструмент программирования, выпущенный компанией Anthropic, также известный как один из самых мощных программных агентов в мире. Расширение Claude Code для VS Code предоставляет нативный графический интерфейс и является рекомендуемым способом использования Claude Code в VS Code.

В этом документе в основном описывается, как настроить и использовать расширение Claude Code в VS Code через прокси-сервис Ace Data Cloud.

## Процесс подачи заявки

Чтобы использовать Claude Code, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы получить ваш API Token и сохранить его на всякий случай.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправят на страницу входа, пригласив зарегистрироваться и войти в систему. После регистрации и входа вы автоматически вернетесь на текущую страницу.

При первой подаче заявки будет предоставлен бесплатный лимит, чтобы вы могли бесплатно опробовать услуги Claude Code.

## Установка плагина Claude Code

В магазине расширений VS Code найдите **Claude Code**, убедитесь, что издатель — **Anthropic**, и установите его. После завершения установки в боковой панели появится доступ к Claude Code.

## Настройка API Ace Data Cloud

При первом открытии плагина вам будет предложено войти в официальный аккаунт Anthropic. Мы можем пропустить официальный вход, настроив прокси API Ace Data Cloud для использования без официальной подписки.

Расширение и терминал CLI используют одну и ту же настройку Claude Code. Полная аутентификация, обработка конфликтов учетных данных и глобальные настройки описаны в [руководстве по настройке терминала Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Если вы хотите, чтобы это работало только для текущего проекта, создайте в корневом каталоге проекта файл `.claude/settings.local.json`, который будет добавлен в `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Где `{token}` — это только что скопированный API Key. Если в среде запуска VS Code уже есть старый `ANTHROPIC_API_KEY`, сначала выполните `unset ANTHROPIC_API_KEY` в этой среде; не используйте пустую строку для очистки и не помещайте реальный ключ в общий файл `.claude/settings.json`.

Ниже приведена конфигурация, выполненная на локальном компьютере с использованием VS Code 1.136.1 и расширения Claude Code 2.1.251. На скриншоте используется временный ключ, чтобы избежать утечки реальных учетных данных:

![Конфигурация Ace Data Cloud Claude Code в VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

После завершения настройки перезапустите VS Code.

> Внимание: указанная выше конфигурация будет действовать только для текущего проекта, и рекомендуется добавить файл `.claude/settings.local.json` в `.gitignore`, чтобы предотвратить его загрузку в удаленный репозиторий.

Если вы хотите, чтобы это работало для всех проектов, вы можете напрямую добавить эту конфигурацию в каталог пользователя. Соответствующий путь будет `~/.claude/settings.json`,

> Внимание: после завершения настройки перезапустите или перезагрузите VS Code, чтобы применить указанные настройки.

## Основное использование

После настройки отправьте простую задачу только для чтения в панели Claude Code, например, "Прочитать README.md и подвести итог в одном предложении". После успешного выполнения задачи вы можете проверить этот вызов в [истории использования](https://platform.acedata.cloud/console/usages).

## Как проверить оставшийся лимит

Вы можете проверить текущий оставшийся лимит вашего аккаунта через [консоль Ace Data Cloud - Список приложений](https://platform.acedata.cloud/console/applications).

Вы можете просмотреть всю историю использования и детали списания через [консоль Ace Data Cloud - История использования](https://platform.acedata.cloud/console/usages).
