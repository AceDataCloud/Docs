Claude Code — это инструмент **Agentic Coding**, выпущенный компанией Anthropic, также известный как один из самых мощных программных агентов в мире. Расширение Claude Code для VS Code предоставляет нативный графический интерфейс, поддерживает встроенный просмотр различий, упоминания с помощью `@`, плановые обзоры и другие функции, что делает его рекомендуемым способом использования Claude Code в VS Code.

В этом документе в основном описывается, как настроить и использовать расширение Claude Code в VS Code через прокси-сервис AceData Cloud.

## Процесс подачи заявки

Чтобы использовать Claude Code, сначала перейдите на [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите кнопку «Acquire», чтобы получить необходимые учетные данные для запроса:

![](https://cdn.acedata.cloud/nyq0xz.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправят на страницу входа, чтобы пригласить вас зарегистрироваться и войти в систему. После входа в систему вы автоматически вернетесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит, чтобы вы могли бесплатно опробовать сервис Claude Code.

## Установка плагина

### Системные требования

- VS Code версии 1.98.0 или выше (также поддерживает Cursor)

### Шаги установки

В магазине расширений VS Code / Cursor нажмите `Cmd+Shift+X` (Mac) или `Ctrl+Shift+X` (Windows/Linux), чтобы открыть представление расширений, найдите **Claude Code**, выберите плагин, выпущенный официально Anthropic, и нажмите «Install»:

![Плагин Claude Code в магазине VS Code](https://cdn.acedata.cloud/10ddf71320.png)

Также можно установить напрямую по следующим ссылкам:

- [Ссылка для установки VS Code](vscode:extension/anthropic.claude-code)
- [Ссылка для установки Cursor](cursor:extension/anthropic.claude-code)

После установки выберите доверие в появившемся уведомлении, чтобы завершить установку.

> Если расширение не появилось после установки, перезапустите VS Code или выполните в командной панели «Developer: Reload Window».

## Настройка AceData Cloud API

При первом открытии плагина будет предложено войти в официальный аккаунт Anthropic. Мы можем пропустить официальный вход, настроив прокси API AceData Cloud для использования, **без необходимости в официальной подписке**.

### Шаг 1: Настройка переменных окружения

Вы можете выбрать любое из следующих мест для настройки переменных окружения:

**Вариант A: Настройка на уровне пользователя (подходит для всех проектов)**

Отредактируйте `~/.claude/settings.json` (если не существует, создайте), добавьте конфигурацию `env`, заменив `{token}` на ваш API токен, полученный в консоли AceData Cloud:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

**Вариант B: Настройка на уровне проекта (только для текущего проекта)**

Создайте в корневом каталоге проекта `.claude/settings.json` (общая конфигурация) или `.claude/settings.local.json` (личная конфигурация, игнорируемая git):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Подсказка**: API токен можно просмотреть в [консоли AceData Cloud](https://platform.acedata.cloud/console). Значение `ANTHROPIC_AUTH_TOKEN` будет автоматически добавлено с префиксом `Bearer` при отправке на сервер. Приоритет конфигурации на уровне проекта выше, чем на уровне пользователя. Рекомендуется использовать общую конфигурацию `.claude/settings.json` в командных проектах, а личную конфиденциальную информацию хранить в `.claude/settings.local.json`.

### Шаг 2: Отключение запроса на вход (по желанию)

Если вы не хотите каждый раз видеть запрос на вход, вы можете отметить **Disable Login Prompt** в настройках VS Code:

В настройках найдите «Claude Code login», найдите опцию **Disable Login Prompt** и отметьте ее.

После завершения настройки снова откройте панель плагина Claude Code, чтобы начать нормальное использование.

## Открытие панели Claude Code

После установки и настройки есть несколько способов открыть Claude Code:

| Способ         | Действие                                             |
| ---------- | ---------------------------------------------- |
| **Панель инструментов редактора** | Нажмите на значок ✦ Spark в правом верхнем углу редактора (необходимо открыть файл)                 |
| **Статусная строка**    | Нажмите на «✱ Claude Code» справа внизу статусной строки (не требуется открывать файл)              |
| **Командная панель**   | `Cmd+Shift+P` / `Ctrl+Shift+P`, введите «Claude Code» |
| **Горячая клавиша**    | `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux) для переключения фокуса  |

В отличие от инструментов, таких как Cursor / Copilot, использующих боковую панель, Claude Code по умолчанию использует **представление области редактирования** в качестве области чата, что обеспечивает большую видимую область и более богатое отображение содержимого. Вы также можете перетащить панель в боковую панель или другое место.

![Панель Claude Code в VS Code](https://cdn.acedata.cloud/b84b878420.jpg)

## Основное использование

### Диалоговое взаимодействие

В панели Claude Code просто введите естественный язык, чтобы взаимодействовать с Claude. Например:

- «Помоги мне проанализировать общую архитектуру этого проекта»
- «В этом коде есть ошибка, помоги мне ее исправить»
- «Перепиши эту функцию, чтобы улучшить читаемость»
- «Напиши модульные тесты для этого модуля»

Claude Code автоматически поймет контекст вашего кода, анализируя и редактируя его между файлами. Когда Claude необходимо изменить файл, будет показан просмотр различий, и вы сможете выбрать, принять или отклонить изменения.

![Диалог и подсказки Claude Code в VS Code](https://cdn.acedata.cloud/650377f5cc.png)

### Ссылки на контекст

В диалоге использование символа `@` позволяет ссылаться на определенные файлы или контекст:

- `@filename.py` — ссылка на указанный файл (поддерживает нечеткое соответствие)
- `@src/components/` — ссылка на всю директорию (необходим слэш в конце)
- `@terminal:name` — ссылка на вывод терминала

Выделив код в редакторе, нажмите `Option+K` (Mac) / `Alt+K` (Windows/Linux), чтобы быстро вставить ссылку `@` (например, `@app.ts#5-10`).

### Команды со слэшем

Нажмите на значок `/` в диалоговом окне или просто введите `/`, чтобы использовать множество встроенных функций:

Распространенные команды включают:

| Команда         | Функция           |
| ---------- | ------------ |
| `/new`     | Создать новый диалог         |
| `/model`   | Переключить модель         |
| `/compact` | Сжать контекст        |
| `/mcp`     | Настроить MCP сервис    |
| `/config`  | Открыть настройки         |
| `/usage`   | Просмотреть использование         |
| `/memory`  | Управлять памятью Claude |
| `/help`    | Показать справочную информацию       |

### Просмотр истории диалогов

Нажмите на выпадающее меню в верхней части панели, чтобы просмотреть историю диалогов, поддерживающую поиск по ключевым словам и просмотр по временным периодам (Сегодня, Вчера, Последние 7 дней и т. д.), что удобно для возврата к предыдущему взаимодействию. Нажмите на любой диалог, чтобы восстановить полную историю сообщений.

### Обзор изменений кода

Когда Claude необходимо изменить файл, будет показан просмотр различий, демонстрирующий сравнение оригинального кода и измененного. Вы можете выбрать, принять или отклонить каждое изменение, а также сообщить Claude, какой подход вы хотите использовать:
![VS Code 中的 Diff 对比视图](https://cdn.acedata.cloud/c42381ea9f.png)

### Режимы разрешений

С помощью индикатора режима внизу панели можно переключаться между различными режимами разрешений:

| Режим                    | Описание                      |
| --------------------- | ----------------------- |
| **Default（Ask）**      | Запрашивает подтверждение перед каждой операцией (по умолчанию)           |
| **Plan**              | Claude сначала разрабатывает план и ждет одобрения, выполняет только после подтверждения |
| **acceptEdits**       | Автоматически принимает редактирование файлов, но команды терминала все еще требуют подтверждения      |
| **bypassPermissions** | Пропускает все запросы на разрешение, полностью автоматизировано (использовать с осторожностью)    |

### Параллельные сессии

Используя командную панель, можно запустить несколько независимых диалогов с помощью **Open in New Tab** или **Open in New Window**, каждый из которых поддерживает свою собственную историю и контекст, позволяя параллельно обрабатывать разные задачи.

## Другие настройки

### Переключение модели

Claude Code поддерживает переключение между различными моделями, такими как Claude Sonnet, Claude Opus и т.д. Это можно настроить с помощью команды `/model` или в настройках плагина в разделе **Selected Model**.

### Автоматический режим

В настройках плагина можно установить **Initial Permission Mode** на `bypassPermissions`, после чего Claude Code будет выполнять редактирование файлов, команды терминала и другие операции без необходимости подтверждения, обеспечивая полностью автоматизированный рабочий процесс.

Также можно установить на `acceptEdits`, чтобы реализовать автоматическое принятие редактирования, но команды терминала все еще требуют подтверждения в полуавтоматическом режиме.

> **Внимание**: Перед включением автоматического режима убедитесь, что вы понимаете его риски, рекомендуется использовать в доверенной проектной среде.

### Использование CLI в терминале

Если вы предпочитаете стиль командной строки, вы можете в настройках VS Code отметить **Use Terminal**, и Claude Code будет работать в режиме CLI в интегрированном терминале. Вы также можете напрямую открыть интегрированный терминал VS Code и выполнить команду `claude`.

## Часто задаваемые вопросы

### Что делать, если соединение не удалось?

1. Убедитесь, что переменные окружения в `~/.claude/settings.json` или `.claude/settings.json` настроены правильно, особенно `ANTHROPIC_AUTH_TOKEN` и `ANTHROPIC_BASE_URL`
2. Убедитесь, что API токен действителен (можно проверить в [консоли](https://platform.acedata.cloud/console))
3. Проверьте, нормально ли работает интернет-соединение, убедитесь, что можно получить доступ к `https://api.acedata.cloud`
4. Перезапустите VS Code и попробуйте снова

### Почему не появляется значок Spark?

1. Убедитесь, что открыт файл (просто открыть папку недостаточно)
2. Убедитесь, что версия VS Code 1.98.0 или выше
3. Выполните в командной панели «Developer: Reload Window»
4. Или просто нажмите на значок «✱ Claude Code» в нижней строке состояния

### Как посмотреть оставшийся лимит?

Войдите в [консоль AceData Cloud](https://platform.acedata.cloud/console), чтобы увидеть текущий остаток и использование вашего аккаунта.
