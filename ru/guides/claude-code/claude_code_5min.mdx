Цель этого документа — помочь вам **за 5 минут** с помощью прокси AceData Cloud выполнить первую команду Claude Code. Полные инструкции смотрите в поддокументах для IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); здесь же рассматривается самый быстрый путь — «**терминал CLI** + **расширение VS Code**».

> **Почему использовать прокси AceData Cloud для Claude Code**:
> - Прямое подключение из Китая без необходимости настраивать VPN
> - Стоимость ниже официальной (оплата по токенам платформы)
> - Один и тот же ключ поддерживает как Claude Messages API, так и протокол Claude Code Token

## 1 минута: получение учетных данных

Откройте [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите кнопку «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

Платформа автоматически создаст для вас Application и предоставит бесплатный лимит. Запишите значения **Base URL** и **API Token** с подробной страницы — они понадобятся на следующих 5 шагах.

| Поле | Значение | Назначение |
|------|----------|------------|
| `BASE_URL` | `https://api.acedata.cloud` | Совместимый вход Claude Messages |
| `API_TOKEN` | `sk-...` (копируется со страницы) | Заголовок аутентификации Anthropic |

## 2 минута: установка Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

После установки откройте новый терминал и проверьте:

```bash
claude --version
```

> Если видите номер версии — значит всё успешно. Claude Code включает собственное окружение Node.js и не зависит от установленной у вас версии Node.

## 3 минута: настройка переменных окружения для AceData Cloud

Не используйте официальный процесс `claude login`, вместо этого переопределите переменные окружения. Выберите один из вариантов:

**Вариант A: временно (только для текущей сессии Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-ваш-Token"
```

**Вариант B: постоянно (рекомендуется)**

Добавьте эти две строки в `~/.zshrc` или `~/.bashrc`, затем выполните `source`.

> **Распространённая ошибка**: переменная должна называться `ANTHROPIC_AUTH_TOKEN`, а не `ANTHROPIC_API_KEY`; при неправильном имени Claude Code вернёт ошибку 401, пытаясь обратиться к официальному эндпоинту.

## 4 минута: выполнение первой команды

Перейдите в любой Git-репозиторий и выполните:

```bash
claude
```

Если при первом запуске появится запрос на вход, нажмите `Esc`, чтобы пропустить. Затем введите:

```
Перечисли зависимости текущего проекта и кратко опиши назначение каждой.
```

Обычно Claude использует инструменты `read_file` / `glob` / `grep` для просмотра репозитория и выводит список. Если модель отвечает корректно и нет ошибки 401, значит прокси работает.

## 5 минута: подключение расширения VS Code

1. Откройте VS Code → панель расширений → найдите `Claude Code` и установите официальное расширение Anthropic;
2. Перезапустите VS Code или выполните в командной панели `Developer: Reload Window`, чтобы расширение подхватило настройки из `~/.claude/settings.json`, настроенные на 3-й минуте;
3. Кликните по значку ✦ Spark в правом верхнем углу редактора или по надписи «✱ Claude Code» в нижней панели, чтобы открыть панель;
4. При первом запуске будет предложено войти в официальный аккаунт — нажмите `Esc`, чтобы пропустить. Расширение автоматически использует переменные `ANTHROPIC_BASE_URL` и `ANTHROPIC_AUTH_TOKEN`, заданные на 3-й минуте.

> **Совет**: расширение VS Code и CLI используют один и тот же файл `~/.claude/settings.json`, поэтому не нужно настраивать его отдельно в VS Code. Для переопределения настроек на уровне проекта можно создать `.claude/settings.local.json` в корне репозитория (файл игнорируется Git).

После успешной настройки можно перетаскивать файлы в панель для вопросов и использовать `@-mention` для ссылок на файлы с предложениями изменений. Все расходы учитываются через AceData Cloud.

## Проверка работы прокси

Запустите с режимом отладки, чтобы убедиться, что запросы идут на AceData Cloud:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

Если видите `https://api.acedata.cloud`, значит прокси работает; если появляется `api.anthropic.com` или ошибка 401 — вернитесь к 3-й минуте и проверьте имя переменной окружения (должно быть `ANTHROPIC_AUTH_TOKEN`, а не `ANTHROPIC_API_KEY`), а также убедитесь, что в `~/.claude/.credentials.json` нет официального токена (удалите этот файл).

## 5 часто задаваемых вопросов

**В: Я выполнил `claude login`, потом сменил переменные окружения на AceData, но не работает. Почему?**  
О: `claude login` записывает официальный токен в `~/.claude/.credentials.json`, который имеет приоритет над переменными окружения. Удалите этот файл и выполните `source ~/.zshrc`.

**В: Можно ли использовать модель с именем `--model claude-opus-4-7`?**  
О: Да. Прокси AceData Cloud пропускает поле model, поддерживаются все публичные модели Anthropic и наши расширения `claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5`.

**В: Можно ли настроить несколько профилей (личный и рабочий)?**  
О: Да. Claude Code поддерживает несколько профилей в `~/.claude/settings.json`. Проще всего — создать две shell-функции `claude_personal` и `claude_work`, которые экспортируют разные `ANTHROPIC_AUTH_TOKEN` и вызывают `claude $@`.

**В: Можно ли запускать в GitHub Actions?**  
О: Да. Подробности в [руководстве по интеграции Claude Code с GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**В: Что делать, когда бесплатный лимит исчерпан?**  
О: Перейдите в [управление приложениями](https://platform.acedata.cloud/applications), выберите ваше Claude Application и пополните баланс (оплата по фактическому потреблению токенов) или переключитесь на подписку с кредитами.
