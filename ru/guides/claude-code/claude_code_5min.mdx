Цель этого документа — помочь вам **за 5 минут** с помощью прокси AceData Cloud выполнить первую команду Claude Code. Полное руководство смотрите в поддокументах для IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); здесь рассматривается самый быстрый путь — «**терминал CLI** + **расширение VS Code**».

> **Зачем использовать прокси AceData Cloud для Claude Code**:
> - Прямое подключение из Китая без необходимости VPN
> - Цены ниже официальных (оплата по токенам платформы)
> - Один ключ поддерживает одновременно Claude Messages API и протокол Claude Code Token

## 1-я минута: получение учетных данных

Откройте [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите кнопку «**Acquire**»:

![](https://cdn.acedata.cloud/nyq0xz.png)

Платформа автоматически создаст для вас Application и подарит бесплатный лимит. Запишите **Base URL** и **API Token** с подробной страницы — они понадобятся на следующих 5 шагах.

| Поле | Значение | Назначение |
|------|----------|------------|
| `BASE_URL` | `https://api.acedata.cloud` | Совместимый вход Claude Messages |
| `API_TOKEN` | `sk-...` (копируется со страницы) | Совместимый заголовок авторизации Anthropic |

## 2-я минута: установка Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

После установки откройте новый терминал и проверьте:

```bash
claude --version
```

> Если видите номер версии — значит всё успешно. Claude Code включает Node.js runtime и не зависит от установленной на вашей машине версии Node.

## 3-я минута: настройка переменных окружения на AceData Cloud

Не используйте официальный процесс `claude login`, вместо этого переопределите переменные окружения. Выберите один из вариантов:

**Вариант A: временно (только для текущей сессии Shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-ваш-Token"
```

**Вариант B: постоянно (рекомендуется)**

Добавьте эти две строки в `~/.zshrc` или `~/.bashrc`, затем выполните `source`.

> **Типичная ошибка**: переменная должна называться `ANTHROPIC_AUTH_TOKEN`, а не `ANTHROPIC_API_KEY`; при неправильном имени Claude Code переключится на официальный эндпоинт и выдаст ошибку 401.

## 4-я минута: выполнение первой команды

Перейдите в любой Git-репозиторий и выполните:

```bash
claude
```

Если при первом запуске появится запрос на вход, нажмите `Esc`, чтобы пропустить. Затем введите:

```
Перечисли зависимости текущего проекта и кратко опиши назначение каждой.
```

Обычно Claude использует инструменты `read_file` / `glob` / `grep` для просмотра репозитория и выдает список. В нижней строке состояния будет отображаться `connected to api.acedata.cloud` — это ключевой индикатор, что прокси работает.

## 5-я минута: подключение расширения VS Code

1. Откройте VS Code → панель расширений → найдите `Claude Code` и установите официальное расширение Anthropic;
2. Нажмите **Cmd+Shift+P**, введите `Claude Code: Set Custom API Endpoint`;
3. Введите `https://api.acedata.cloud` и нажмите Enter;
4. Затем выполните `Claude Code: Set API Token` и введите ваш токен.

После успешной настройки в боковой панели появится панель Claude Code, где можно перетаскивать файлы для вопросов и делать предложения по изменениям с помощью `@-mention`. Все расходы учитываются через AceData Cloud.

## Проверка работы через прокси

В диалоге Claude Code введите:

```
Посети https://api.acedata.cloud/whoami и скажи, что вернулось
```

Если вы получите информацию о своей учетной записи (`{user_id, plan, ...}`), значит запрос действительно прошёл через Edge AceData Cloud. Если же вы увидите ошибку 401 с официального домена, вернитесь к 3-й минуте и проверьте правильность имени переменных окружения.

## 5 часто задаваемых вопросов

**В: Я выполнил `claude login`, потом сменил переменные окружения на AceData — почему не работает?**  
О: `claude login` сохраняет официальный токен в `~/.claude/.credentials.json`, который имеет приоритет над переменными окружения. Удалите этот файл и выполните `source ~/.zshrc`.

**В: Можно ли использовать модель с именем `--model claude-opus-4-7`?**  
О: Да. Прокси AceData Cloud передаёт поле model напрямую, поддерживаются все публичные модели Anthropic и наши расширения `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`.

**В: Можно ли настроить несколько профилей (личный и рабочий)?**  
О: Да. Claude Code поддерживает несколько профилей в `~/.claude/settings.json`; проще всего создать две shell-функции `claude_personal` и `claude_work`, которые экспортируют разные `ANTHROPIC_AUTH_TOKEN` и вызывают `claude $@`.

**В: Можно ли запускать в GitHub Actions?**  
О: Да. Подробности в [Claude Code GitHub Actions Integration](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**В: Что делать, когда бесплатный лимит исчерпан?**  
О: Перейдите в [Управление приложениями](https://platform.acedata.cloud/applications) → выберите Claude Application → пополните баланс (оплата по фактическому потреблению токенов) или переключитесь на подписку.
