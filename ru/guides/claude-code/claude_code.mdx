title: "Руководство по настройке Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code — это программный агент с искусственным интеллектом, разработанный Anthropic, который можно использовать в терминале, IDE, а также в CI/CD конвейерах. Через прокси AceData Cloud вы можете использовать Claude Code по более низкой цене.

Выберите полное руководство по настройке для соответствующей платформы в зависимости от сценария использования:

| Платформа | Описание | Ссылка на руководство |
|-----------|----------|-----------------------|
| **VS Code** | Родное расширение, поддержка встроенного Diff, @-упоминаний, планирования обзоров | [Руководство по настройке VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Редактор, совместимый с VS Code, полная поддержка расширения Claude Code | [Руководство по настройке Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **Терминал (CLI)** | Основной опыт, запуск `claude` в любом терминале для начала работы | [Руководство по настройке терминала](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Поддержка IntelliJ IDEA, PyCharm, WebStorm и других IDE семейства JetBrains | [Руководство по настройке JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Автоматизация обзора кода и обработки Issue с помощью `@claude` | [Руководство по настройке GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Совет**: При первом запросе перейдите на [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите «Acquire» для получения учетных данных и бесплатного лимита.
