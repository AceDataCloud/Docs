title: "Руководство по настройке Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code — это программный интеллектуальный агент от Anthropic, который можно использовать в терминале, IDE, настольных приложениях и других средах. Через прокси AceData Cloud вы можете использовать Claude Code по более низкой цене.

> **Первый раз подключаетесь?** Рекомендуется сначала ознакомиться с [Claude Code: Быстрый старт за 5 минут](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — от получения учетных данных до успешного выполнения первой команды за пять шагов.

Выберите полное руководство по настройке для соответствующей платформы в зависимости от сценария использования:

| Платформа | Описание | Ссылка на руководство |
|-----------|----------|-----------------------|
| **⚡ Быстрый старт за 5 минут** | От получения учетных данных до первой команды `claude` за пять шагов | [Руководство за 5 минут](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Терминал (CLI)** | Основной опыт — запускайте `claude` в любом терминале и начинайте работу | [Руководство по настройке терминала](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Родное расширение с поддержкой встроенного Diff, упоминаний @ и планирования обзоров | [Руководство по настройке VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Редактор, совместимый с VS Code, полностью поддерживающий расширение Claude Code | [Руководство по настройке Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Поддержка IntelliJ IDEA, PyCharm, WebStorm и других IDE семейства | [Руководство по настройке JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Автоматизация обзора кода и обработки Issue с помощью `@claude` | [Руководство по настройке GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Настольное приложение (Preview)** | Отдельный графический клиент с поддержкой параллельных сессий и подключения внешних инструментов | [Руководство по настройке настольного приложения](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Совет**: для первого запроса перейдите на [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите «Acquire» для получения учетных данных и бесплатного лимита.
