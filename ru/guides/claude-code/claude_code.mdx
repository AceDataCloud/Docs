Claude Code — это программный агент, разработанный компанией Anthropic, который можно использовать в различных средах, таких как терминал, IDE, настольные приложения и т.д. С помощью прокси AceData Cloud вы можете использовать Claude Code по более низкой цене.

Пожалуйста, выберите соответствующее руководство по настройке в зависимости от вашего сценария использования:

| Платформа            | Описание                                     | Ссылка на руководство                                                                                     |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Терминал (CLI)**   | Основной опыт, просто запустите `claude` в любом терминале, чтобы начать | [Руководство по настройке терминала](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Нативное расширение, поддерживает встроенные Diff, @-упоминания, планирование обзоров | [Руководство по настройке VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | Поддерживает все IDE от IntelliJ IDEA, PyCharm, WebStorm и т.д. | [Руководство по настройке JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Автоматизация кода обзоров и обработки Issues с помощью `@claude` | [Руководство по настройке GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Совет**: Для первого запроса вы можете перейти на [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажать «Acquire», чтобы получить учетные данные, что даст вам бесплатный лимит.
