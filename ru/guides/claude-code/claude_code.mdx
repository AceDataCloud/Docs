Claude Code подключается к Coding Plan через протокол Anthropic Messages, в настоящее время предоставляет два входа для конфигурации: терминал и VS Code.

| Используемый вход   | Руководство по конфигурации                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Конфигурация терминала Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| VS Code            | [Конфигурация Claude Code для VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Общая конфигурация

- Базовый URL: `https://api.acedata.cloud`
- API Token: Получите из Coding Application и настройте через `ANTHROPIC_AUTH_TOKEN` в руководстве
- Model ID: Выберите из каталога моделей в реальном времени
- После изменения конфигурации: перезапустите Claude Code; пользователи VS Code должны перезагрузить окно

Не храните одновременно старый `ANTHROPIC_API_KEY` и не записывайте реальный токен в общие файлы команды.

Вернуться в [Центр конфигурации Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
