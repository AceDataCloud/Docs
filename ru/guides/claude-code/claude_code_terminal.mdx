## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка Claude Code

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
```

Проверьте после установки:

```bash
claude --version
```

## 3. Настройка Ace Data Cloud

Для глобального использования добавьте следующие переменные в `~/.zshrc` или `~/.bashrc`：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="ваш API Key"
unset ANTHROPIC_API_KEY
```

Перезапустите терминал или выполните `source` соответствующего конфигурационного файла.

Если нужно, чтобы это действовало только для текущего проекта, создайте файл `.claude/settings.local.json`, который будет добавлен в `.gitignore`：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "ваш API Key"
  }
}
```

Выберите один из двух способов. Не записывайте реальный Key в командный файл `.claude/settings.json`, который делится с командой; если в окружении уже есть `ANTHROPIC_API_KEY`, его следует действительно отменить, а не установить в пустую строку.

## 4. Запуск и проверка

```bash
cd /path/to/your/project
claude
```

После входа отправьте задачу только для чтения, например, "Прочитать README.md и подвести итог в одном предложении". Записи вызовов и баланс можно просмотреть в [Истории использования](https://platform.acedata.cloud/console/usages) и [Списке приложений](https://platform.acedata.cloud/console/applications).

Если возвращается 401, проверьте, полный ли Key, отменен ли старый `ANTHROPIC_API_KEY`, и полностью перезапустите Claude Code. Модель не нужно фиксировать в конфигурации подключения, ее можно выбрать в Claude Code из доступных моделей.
