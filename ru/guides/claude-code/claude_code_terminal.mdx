Claude Code — это инструмент **Agentic Coding**, выпущенный компанией Anthropic, также известный как один из самых мощных программных агентов в мире. Терминал CLI является основной частью опыта Claude Code, вы можете запускать команду `claude` в любом терминале и взаимодействовать с ИИ для совместной работы над программированием.

Этот документ в основном описывает, как установить, настроить и использовать Claude Code CLI через прокси-сервис AceData Cloud в терминале.

## Процесс подачи заявки

Чтобы использовать Claude Code, сначала перейдите на [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите кнопку «Acquire», чтобы получить необходимые учетные данные для запроса:

![](https://cdn.acedata.cloud/nyq0xz.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправят на страницу входа, чтобы пригласить вас зарегистрироваться и войти в систему, после чего вы автоматически вернетесь на текущую страницу.

При первом запросе будет предоставлен бесплатный лимит, чтобы вы могли бесплатно опробовать сервис Claude Code.

## Установка Claude Code

### Системные требования

- macOS, Linux или Windows (включая WSL)
- Node.js не является обязательным, способ установки по умолчанию автоматически обработает зависимости

### Способы установки

Claude Code поддерживает несколько способов установки:

**Способ 1: Установка по умолчанию (рекомендуется)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Способ 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Способ 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Установка по умолчанию будет автоматически обновляться в фоновом режиме, всегда поддерживая последнюю версию.

## Настройка AceData Cloud API

После завершения установки по умолчанию вам будет предложено войти в свою учетную запись Anthropic. Мы можем использовать переменные окружения для настройки прокси API AceData Cloud, **без необходимости в официальной подписке**.

### Настройка переменных окружения

Существует два способа настройки переменных окружения, выберите любой из них.

**Способ 1: Установка в конфигурационном файле Shell (рекомендуется)**

Добавьте следующий контент в ваш конфигурационный файл Shell (`~/.zshrc`, `~/.bashrc` или `~/.bash_profile`), заменив `{token}` на API токен, полученный в консоли AceData Cloud:

```bash
# AceData Cloud - Настройка прокси Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

После изменения выполните следующую команду, чтобы применить настройки:

```bash
source ~/.zshrc  # или source ~/.bashrc
```

**Способ 2: Установка в settings.json Claude Code**

Отредактируйте `~/.claude/settings.json` (если не существует, создайте), добавив конфигурацию `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Преимущество этого способа в том, что переменные окружения действуют только для Claude Code и не влияют на другие программы.

> **Подсказка**: Токен API можно просмотреть в [консоли AceData Cloud](https://platform.acedata.cloud/console). Значение `ANTHROPIC_AUTH_TOKEN` будет автоматически добавлено с префиксом `Bearer` при отправке на сервер.

## Начало работы

### Запуск интерактивного режима

Откройте терминал, перейдите в каталог вашего проекта, затем выполните:

```bash
cd /path/to/your/project
claude
```

Вы увидите приветственный экран Claude Code, просто введите естественный язык, чтобы начать взаимодействие.

### Часто используемые команды

| Команда               | Описание          | Пример                   |
| ---------------- | ----------- | -------------------- |
| `claude`         | Запуск интерактивного режима      | `claude`             |
| `claude "задача"`    | Выполнение одноразовой задачи     | `claude "исправить ошибку сборки"`    |
| `claude -p "запрос"` | Выполнение запроса и выход     | `claude -p "объяснить эту функцию"` |
| `claude -c`      | Продолжить последний диалог в текущем каталоге | `claude -c`          |
| `claude -r`      | Восстановить предыдущий диалог     | `claude -r`          |
| `claude commit`  | Создание Git коммита   | `claude commit`      |

### Команды интерактивного режима

В интерактивном режиме можно использовать следующие встроенные команды:

| Команда                | Функция        |
| ----------------- | --------- |
| `/help`           | Показать справочную информацию    |
| `/clear`          | Очистить историю диалога    |
| `/config`         | Открыть панель настроек    |
| `/model`          | Переключить модель      |
| `/mcp`            | Управление MCP сервисом |
| `/compact`        | Сжать контекст     |
| `/memory`         | Управление памятью      |
| `/login`          | Переключить учетную запись      |
| `exit` или `Ctrl+C` | Выход        |

### Примеры диалогового взаимодействия

```bash
# Анализ проекта
> что делает этот проект?

# Исправление ошибки
> есть ошибка, из-за которой пользователи могут отправлять пустые формы - исправь это

# Написание тестов
> напиши модульные тесты для функций калькулятора

# Рефакторинг кода
> рефакторинг модуля аутентификации для использования async/await

# Git операции
> зафиксируй мои изменения с описательным сообщением
> создай PR для этой функции
```

## Расширенное использование

### Конвейеры и скриптование

Claude Code следует философии Unix и поддерживает конвейеры и скриптование:

```bash
# Мониторинг логов и автоматическое уведомление
tail -f app.log | claude -p "если обнаружишь аномалию, сообщи мне"

# Автоматический перевод новых текстов
claude -p "если есть новые текстовые строки, переведи их на французский и создай PR"

# Код-ревью
git diff main | claude -p "проверь эти изменения"
```

### Справочник переменных окружения

Вот некоторые из распространенных переменных окружения, поддерживаемых Claude Code:

| Переменная                           | Описание                                    |
| ---------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`       | Значение для пользовательского заголовка Authorization (автоматически добавляется префикс Bearer) |
| `ANTHROPIC_API_KEY`          | API ключ (отправляется как заголовок X-Api-Key)              |
| `ANTHROPIC_BASE_URL`         | Базовый URL API                            |
| `ANTHROPIC_MODEL`            | Переопределение модели по умолчанию                                |
| `ANTHROPIC_SMALL_FAST_MODEL` | Модель уровня Haiku (для фоновых задач)                     |
| `MAX_THINKING_TOKENS`        | Установка бюджета токенов на размышления (установите 0, чтобы отключить режим размышлений)            |
| `DISABLE_COST_WARNINGS`      | Установите 1, чтобы отключить предупреждения о расходах                           |

### Файл памяти проекта CLAUDE.md

Создайте файл `CLAUDE.md` в корневом каталоге проекта, чтобы предоставить Claude Code специфические для проекта инструкции и контекст. Claude автоматически загрузит этот файл при запуске.

```markdown
# Описание проекта
Это полный стек проект на Django + Vue.js.

## Кодовые стандарты
- Использовать Python 3.12
- Следовать стилю кода PEP 8
- Все API должны иметь модульные тесты
```

## Часто задаваемые вопросы

### Что делать, если соединение не удалось?
1. Проверьте, правильно ли создан файл `~/.claude/config.json`, содержимое должно быть `{"primaryApiKey": "self"}`
2. Убедитесь, что переменные окружения установлены правильно:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Убедитесь, что токен API действителен (можно проверить в [консоли](https://platform.acedata.cloud/console))
4. Попробуйте перезапустить терминал

### команда не найдена: claude

Если после установки появляется сообщение `command not found`, попробуйте:

1. Закрыть и снова открыть терминал
2. Проверить PATH: `echo $PATH`
3. Переустановить: `curl -fsSL https://claude.ai/install.sh | bash`

### Как посмотреть оставшийся лимит?

Войдите в [консоль AceData Cloud](https://platform.acedata.cloud/console), чтобы увидеть текущий остаток и использование вашего аккаунта.
