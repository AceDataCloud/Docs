## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка CLI и плагина

Сначала установите Claude Code CLI.

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell：

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Затем установите плагин **Claude Code** из JetBrains Marketplace и перезапустите IDE. Плагин вызывает локальную команду `claude`; если появится сообщение о том, что команда не найдена, укажите полный путь в **Settings → Tools → Claude Code**.

## 3. Настройка Ace Data Cloud

Настройте в среде запуска JetBrains backend.

macOS / Linux / WSL：

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="ваш API Key"
unset ANTHROPIC_API_KEY
```

Windows PowerShell：

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "ваш API Key"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Также можно использовать игнорируемый файл `.claude/settings.local.json` в проекте:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "ваш API Key"
  }
}
```

Для удаленной разработки необходимо настроить и установить плагин на удаленном хосте; пользователи WSL могут установить команду Claude как `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Проверка

Запустите `claude` из интегрированного терминала IDE или введите `/ide` после запуска внешнего терминала. После успешного подключения попросите Claude ответить `OK`, затем прочитайте тестовый файл и проверьте этот запрос в [Истории использования](https://platform.acedata.cloud/console/usages) Ace Data Cloud.

Если плагин не запускается, сначала выполните `claude --version` в том же терминале; если 401, проверьте фактические унаследованные переменные окружения backend и старый `ANTHROPIC_API_KEY`.
