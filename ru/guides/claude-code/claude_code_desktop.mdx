Claude Code — это инструмент **Agentic Coding**, выпущенный компанией Anthropic, также известный как один из самых мощных программных агентов в мире. Настольное приложение Claude Code предоставляет независимый графический интерфейс, поддерживающий функции Diff-ревью, параллельные сессии (изолированные через Git Worktree), удаленные сессии и другие, без необходимости использования какого-либо IDE.

В этом документе в основном описывается, как настроить и использовать приложение Claude Code через прокси-сервис AceData Cloud.

> **Примечание**: Настольное приложение Claude Code в настоящее время находится на стадии предварительного просмотра (Preview) и поддерживает только macOS и Windows.

## Процесс подачи заявки

Чтобы использовать Claude Code, сначала перейдите на [страницу сервиса Claude Messages](https://platform.acedata.cloud/documents/claude-messages) и нажмите кнопку «Acquire», чтобы получить необходимые учетные данные для запроса:

![](https://cdn.acedata.cloud/nyq0xz.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправят на страницу входа, чтобы пригласить вас зарегистрироваться и войти в систему. После входа в систему вы автоматически вернетесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит, чтобы вы могли бесплатно опробовать сервис Claude Code.

## Установка настольного приложения

### Системные требования

- macOS (Intel и Apple Silicon) или Windows (x64 / ARM64)
- Linux в настоящее время не поддерживает настольное приложение

### Скачивание и установка

Перейдите на [официальную страницу загрузки Claude](https://claude.ai) и скачайте установочный пакет для соответствующей платформы:

- **macOS**: скачайте файл `.dmg`, перетащите в папку Applications
- **Windows x64**: скачайте установочный пакет `.exe`, следуйте инструкциям для установки
- **Windows ARM64**: скачайте версию ARM64 (внимание: ARM64 не поддерживает локальные сессии, необходимо использовать удаленные сессии)

![Страница загрузки настольного приложения Claude](https://cdn.acedata.cloud/c3c8c57264.png)

После завершения установки запустите Claude из папки Applications (macOS) или из меню «Пуск» (Windows).

## Настройка AceData Cloud API

После запуска настольного приложения необходимо войти в учетную запись Anthropic. Мы можем использовать переменные окружения для настройки прокси API AceData Cloud, **без необходимости в официальной подписке**.

Настольное приложение считывает переменные окружения из вашей оболочки, поэтому необходимо настроить их в конфигурационном файле оболочки.

### Настройка переменных окружения

**Пользователи macOS**

Добавьте следующее содержимое в `~/.zshrc` (или `~/.bashrc`), заменив `{token}` на ваш API токен:

```bash
# AceData Cloud - Настройка прокси для Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Сохраните и выполните:

```bash
source ~/.zshrc
```

**Пользователи Windows**

Добавьте следующие системные переменные окружения через «Свойства системы → Дополнительно → Переменные среды»:

| Имя переменной            | Значение                       |
| ---------------------- | ----------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}` (замените на ваш API токен) |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud`  |

Или используйте PowerShell:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**Также можно настроить через settings.json**

Отредактируйте `~/.claude/settings.json` (если не существует, создайте):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Совет**: API токен можно просмотреть в [консоли AceData Cloud](https://platform.acedata.cloud/console). После завершения настройки необходимо **перезапустить настольное приложение**, чтобы переменные окружения вступили в силу.

## Основное использование

### Открытие проекта

1. Запустите настольное приложение Claude
2. Нажмите на вкладку **Code** в верхней части
3. Выберите режим работы **Local**
4. Нажмите **Select folder**, чтобы выбрать каталог вашего проекта

### Начало диалога

Введите в текстовом поле естественный язык, описывающий ваши потребности:

- «Найти TODO комментарии и исправить их»
- «Добавить тест для основной функции»
- «Объяснить архитектуру этого проекта»

Claude проанализирует вашу кодовую базу, предложит варианты изменений и отобразит изменения в виде Diff.

### Режим разрешений

Переключайтесь между режимами с помощью селектора рядом с кнопкой отправки:

| Режим       | Описание                          |
| -------- | --------------------------------- |
| **Ask**  | Запрашивает подтверждение перед каждым изменением (рекомендуется для новичков) |
| **Code** | Автоматически принимает редактирование файлов, но команды терминала все еще требуют подтверждения |
| **Plan** | Сначала разрабатывает подробный план и ждет одобрения, выполняет только после подтверждения |

### Параллельные сессии

Нажмите на **+ New session** в боковой панели, чтобы запустить несколько параллельных сессий. Для Git-репозиториев каждая сессия получит независимую копию проекта через Worktree, не мешая друг другу.

Worktree по умолчанию хранится в каталоге `~/.claude-worktrees/`.

### Diff-ревью

Когда Claude изменяет файлы, отображается статистика изменений (например, `+12 -1`), нажав на которую можно открыть просмотрщик Diff для пофайлового ревью изменений. Вы также можете нажать на конкретные строки кода, чтобы добавить комментарии, и Claude будет корректировать свои действия в зависимости от вашего отзыва.

## Подключение внешних инструментов

Перед началом сессии нажмите кнопку **⋯**, выберите **Connectors**, чтобы добавить внешние интеграции:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- И многое другое...

После подключения Claude сможет напрямую читать календари, отправлять сообщения, создавать задачи и т.д.

## Связь с CLI

Настольное приложение и CLI используют один и тот же базовый движок, разделяя следующие настройки:

- Файлы памяти проекта `CLAUDE.md` / `CLAUDE.local.md`
- Конфигурация сервера MCP в `~/.claude.json` / `.mcp.json`
- Настройки в `~/.claude/settings.json`
- Настройки Hooks и Skills

Оба могут одновременно работать над одним проектом, поддерживая независимую историю сессий.

## Часто задаваемые вопросы

### Что делать, если соединение не удалось?

1. Проверьте, правильно ли создан файл `~/.claude/config.json`
2. Убедитесь, что переменные окружения правильно настроены (перезапустите настольное приложение, чтобы они вступили в силу)
3. Убедитесь, что API токен действителен (можно проверить в [консоли](https://platform.acedata.cloud/console))
4. Если вы используете `settings.json` для настройки переменных окружения, убедитесь, что формат файла правильный

### Что делать, если не удается найти установленные инструменты?

Если Claude не может найти команды `npm`, `node` и т.д.:

1. Убедитесь, что эти инструменты работают в обычной терминале
2. Проверьте, правильно ли настроен PATH в вашем конфигурационном файле оболочки (`~/.zshrc`, `~/.bashrc`)
3. Перезапустите настольное приложение, чтобы перезагрузить переменные окружения

### Как посмотреть оставшийся лимит?

Войдите в [консоль AceData Cloud](https://platform.acedata.cloud/console), чтобы увидеть текущий остаток и использование вашего аккаунта.
