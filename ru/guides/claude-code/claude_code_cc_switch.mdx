## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка CC Switch

Скачайте с [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), также работает на macOS:

```bash
brew install --cask cc-switch
```

## 3. Добавление Provider

Откройте CC Switch, выберите **Claude Code → Add Provider → Custom**, заполните:

| Поле        | Значение                      |
| ----------- | ----------------------------- |
| Name        | `Ace Data Cloud`             |
| Base URL    | `https://api.acedata.cloud`  |
| API Key     | Только что скопированный API Key |
| API Format  | `Anthropic Messages`         |

Если необходимо использовать JSON редактор, настройте как:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch запишет настройки в пользовательские настройки Claude Code. Не сохраняйте реальные ключи в командном репозитории и не оставляйте старый `ANTHROPIC_API_KEY`.

## 4. Включение и проверка

После сохранения включите **Ace Data Cloud**, перезапустите Claude Code. Отправьте простую задачу только для чтения и проверьте вызов в [Истории использования](https://platform.acedata.cloud/console/usages). Если после переключения все еще используется старая конфигурация, полностью выйдите из Claude Code и CC Switch и попробуйте снова.
