## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

В целевом репозитории GitHub в **Настройки → Secrets and variables → Actions** создайте новый Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. Установка GitHub App

Установите [Claude GitHub App](https://github.com/apps/claude) и предоставьте доступ к целевому репозиторию. Это официальное приложение запросит фиксированный набор полных прав; среди них Claude Code Action фактически использует права на Contents, Issues и Pull requests, страница установки GitHub не может выбрать только эти три пункта. Если организация требует минимальных прав, создайте настраиваемое приложение GitHub в соответствии с официальной документацией.

## 3. Добавление Workflow

Создайте файл `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` требует ненулевое значение для `anthropic_api_key`; здесь используемое значение не будет использоваться для аутентификации на платформе. `ANTHROPIC_CUSTOM_HEADERS` будет переопределять Bearer Header, необходимый для Ace Data Cloud, реальный Key будет поступать только из GitHub Secret.

## 4. Проверка

После отправки Workflow отправьте в комментарии Issue или PR:

```text
@claude Reply only OK
```

При успешном выполнении Actions workflow завершится и обновит результат в соответствующем Issue/PR. Если Action сообщает о нехватке учетных данных, убедитесь, что `dummy-not-used` все еще существует; при ошибке 401 проверьте Secret `ACEDATACLOUD_API_KEY`. Не выводите Secret в логах. Можно использовать `claude_args` для настройки `--max-turns` или выбора текущей доступной модели, но подключение шаблона не фиксирует модель.
