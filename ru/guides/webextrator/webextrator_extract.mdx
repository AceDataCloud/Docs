`POST https://api.acedata.cloud/webextrator/extract`

API интеллектуального извлечения WebExtrator преобразует URL в **типизированные структурированные результаты** — статьи, товары,
рецепты, видео, обсуждения, вакансии и другое, а также предоставляет очищенные Markdown и простой текст. Используйте этот интерфейс, когда вам нужны «чистые структурированные данные»,
а не исходный HTML.

## Процесс подачи заявки

Чтобы использовать страницу сервиса WebExtrator, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications) и получите ваш API Token для резервного копирования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, приглашающую вас зарегистрироваться и войти в систему, после чего вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно подавать отдельные заявки на каждый сервис.** При первой подаче заявки предоставляется бесплатный лимит, чтобы вы могли бесплатно протестировать; при недостатке лимита вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Страница сервиса WebExtrator →](https://platform.acedata.cloud/service/webextrator)

## Аутентификация

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Параметры запроса

Extract принимает **все** параметры [Render API](/ru/guides/webextrator/webextrator_render)
（`url`、`user_agent`、`timeout`、`wait_until`、`delay`、`wait_for_selector`、
`block_resources`、`headers`、`cookies`、`callback_url`、`bypass_cache`、
`cache_ttl_seconds`、`async`），а также два поля, специфичных для Extract:

| Поле | Тип | Обязательно | По умолчанию | Описание |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Автоматическое определение | Подсказка о типе страницы: `product` / `article` / `general`. Укажите ожидаемый тип результата. |
| `enable_llm` | boolean | ❌ | `false` | Разрешает извлечение с помощью LLM, если schema.org не найден. На страницах без JSON-LD, таких как Amazon / HN / Greenhouse, эту опцию необходимо включить для получения типизированных результатов. |

### Поля верхнего уровня

| Поле | Тип | Описание |
|------|------|------|
| `kind` | string | Всегда `"extract"`. |
| `url` | string | Отправленный вами URL. |
| `finalUrl` | string | Конечный URL после перенаправлений. |
| `contentType` | enum | Тип страницы: `product` / `article` / `general`. |
| `title` | string | Заголовок страницы. |
| `description` | string? | Описание или краткое содержание страницы. |
| `byline` | string? | Автор, канал или компания. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Время публикации в формате ISO 8601. |
| `images` | string[] | До 50 `<img src />`, преобразованных в абсолютные URL, без дубликатов и с исключением URI `data:`. |
| `links` | string[] | До 100 внешних ссылок; фрагменты / `javascript:` / `mailto:` / `tel:` отфильтрованы. |
| `markdown` | string | Markdown-содержимое страницы. |
| `text` | string | Простой текст страницы. |
| `structured` | object | Полный структурированный результат, см. ниже. |
| `rawSignals` | object | Диагностическая информация для отладки. |
| `cached` | boolean? | При попадании в кэш — `true`. |
| `cacheStoredAt` | number? | Временная метка Unix в миллисекундах первого добавления записи кэша. |

### Подполя `data.structured`

| Подполе | Когда появляется | Описание |
|--------|---------|------|
| `schemaOrg` | Всегда | `{ primary, breadcrumbs, all }`. `primary` — типизированная сущность с наивысшим приоритетом; если она не найдена, используется `null`. |
| `openGraph` | Всегда | `{ title, description, image, type }`, полученное из `<meta property="og:*" />`. |
| `jsonLd` | Всегда | Исходный JSON-массив всех блоков `<script type="application/ld+json">`. |
| `llm` | Когда LLM выполнялась успешно | `{ kind, data, model, promptCharCount }`, типизированный результат. |
| `llmError` | Когда LLM выполнялась, но завершилась с ошибкой | `{ kind, error, model }`, запрос всё равно может вернуть другие извлечённые поля. |
| `amazon` | Когда URL имеет значение `amazon.*` | Устаревший результат расширения Amazon; для новых интеграций используйте типизированные результаты. |

## Типы результатов schema.org

`structured.schemaOrg.primary` поддерживает следующие типы результатов:

| Тип schema.org | kind | Поля вывода |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (включая `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (прикреплён к sibling) | Всегда выводится в `structured.schemaOrg.breadcrumbs[]`, не будет использоваться в качестве primary. |

## Типы результатов LLM

Когда `enable_llm: true` и на странице нет доступных структурированных данных schema.org, могут быть возвращены результаты извлечения следующих типов:

| Kind | Обязательные поля | Необязательные поля |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Кэширование

Для одинаковых URL, параметров запроса, `cookies` и `headers` можно повторно использовать результаты из кэша; `async`, `bypass_cache` и `cache_ttl_seconds` используются для управления способом выполнения и поведением кэширования.

| Поле | Эффект |
|------|------|
| `bypass_cache: true` | Пропустить чтение; результат этого запроса всё равно будет записан в кэш, и такой же запрос в следующий раз сможет попасть в кэш. |
| `cache_ttl_seconds: 0` | Ответ на этот запрос **не кэшируется**. |
| `cache_ttl_seconds: N` | Задать пользовательский TTL для этой записи (по умолчанию 3600 секунд). |

Ответы, полученные из кэша, будут содержать `data.cached: true` и `data.cacheStoredAt: <unix-ms>`.

## Асинхронный режим и обратные вызовы

Установите `async: true`, чтобы перейти в асинхронный режим (предоставление `callback_url` также автоматически приведет к этому). Платформа немедленно возвращает (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

Когда задача завершится, полный envelope будет `POST` на ваш `callback_url` (если он настроен). Также можно
позже запросить через [`/webextrator/tasks`](/ru/guides/webextrator/webextrator_tasks).

## Пример

### 1. Статья Wikipedia (попадание schema.org, LLM не требуется)

```bash
curl -X POST https://api.acedata.cloud/webextrator/extract \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://en.wikipedia.org/wiki/Diffbot",
    "expected_type": "article"
  }'
```

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "article",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "article":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'ингредиентов');
```

## Советы и подводные камни

- **Передавайте `expected_type`, если нужно указать тип страницы.** Например, для страницы статьи используйте `article`, а для страницы товара — `product`.
- **`enable_llm: true` бесплатен на страницах, соответствующих schema.org.** LLM вызывается только тогда, когда в schema.org
  нет primary, поэтому его можно безопасно включать по умолчанию.
- **При отладке сначала проверьте `rawSignals.hasJsonLd`.** Если это `true`, но `structured.schemaOrg.primary`
  имеет значение `null`, это означает, что `@type` этой страницы пока не поддерживается; сообщите нам об этом.
- **`structured.llmError` носит информационный характер.** Запрос всё равно может успешно вернуть другие извлечённые поля. Проверяйте
  `llmError.error`, чтобы определить причину (тайм-аут, ошибка разбора JSON, ошибка проверки структуры).
- **Для `links[]` на страницах, не являющихся статьями, сортировка по релевантности не выполняется.** Выполняется только очистка по принципу «до 100 записей + фильтрация недействительных протоколов»
  по мере возможности.
- **Попадания в кэш также тарифицируются.**
