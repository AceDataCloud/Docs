---
title: "Руководство по настройке Codex"
description: "Codex API guide - Ace Data Cloud"
---

Codex CLI, Desktop и расширение VS Code используют общий файл `~/.codex/config.toml`. Настройте провайдер `acedatacloud` один раз, и вы сможете использовать Codex через Ace Data Cloud.

| Способ использования | Руководство по настройке                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| Terminal / CLI     | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)                       |
| Desktop            | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)                    |
| VS Code            | [Codex для VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)                |
| Графический переключатель | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration)          |

Общие настройки состоят из трех пунктов:

- Провайдер: `acedatacloud`
- Базовый URL: `https://api.acedata.cloud/v1`
- API Key: получить из [списка приложений](https://platform.acedata.cloud/console/applications) и сохранить в `ACEDATACLOUD_API_KEY`

Нет необходимости фиксировать модель в настройках подключения; после запуска Codex вы можете сразу выбрать модель.

Вернуться в [Центр настройки Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
