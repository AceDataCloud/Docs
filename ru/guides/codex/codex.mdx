---
title: "Руководство по настройке Codex"
description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI — это открытый локальный программный агент от OpenAI, который позволяет читать код, изменять файлы, выполнять команды и помогать в выполнении задач разработки прямо в терминале. Через прокси Ace Data Cloud вы можете использовать Codex CLI по более низкой цене, без необходимости отдельной подписки на официальный аккаунт OpenAI.

Выберите соответствующее полное руководство по настройке в зависимости от сценария использования:

| Платформа | Описание | Ссылка на руководство |
|-----------|----------|-----------------------|
| **VS Code** | Официальное расширение, чат в боковой панели редактора, ссылки на файлы, просмотр diff | [Руководство по настройке VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Терминал (CLI)** | Основной опыт, запуск `codex` в любом терминале для начала работы | [Руководство по настройке терминала](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Совет**: Для первого запроса перейдите в [Ace Data Cloud Console](https://platform.acedata.cloud/console/applications) для получения API Token и бесплатного лимита. Codex CLI работает через совместимый интерфейс OpenAI Responses Ace Data Cloud (`/v1/responses`), подробности о моделях и тарифах доступны на [странице сервиса OpenAI](https://platform.acedata.cloud/documents/openai).
