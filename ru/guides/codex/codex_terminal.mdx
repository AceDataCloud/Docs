## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка Codex

```bash
npm install -g @openai/codex
```

## 3. Установка API Key

macOS / Linux：

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

Для долгосрочного действия добавьте эту строку в `~/.zshrc` или `~/.bashrc`. В Windows PowerShell используйте:

```powershell
setx ACEDATACLOUD_API_KEY "ваш API Key"
```

После установки перезапустите терминал.

## 4. Настройка AceDataCloud

Отредактируйте `~/.codex/config.toml` (в Windows это `%USERPROFILE%\.codex\config.toml`), добавив:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

В Windows измените последние две строки на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Не нужно заполнять `model`; после запуска можно выбрать модель в Codex. Существующие другие настройки можно оставить, не создавайте повторно провайдер с тем же именем.

## 5. Запуск

```bash
cd /path/to/your/project
codex
```

После входа в Codex выполните `/model`, подтвердите, что Provider равен `acedatacloud`, затем выберите нужную модель. Записи вызовов и баланс можно просмотреть в [истории использования](https://platform.acedata.cloud/console/usages) и [списке приложений](https://platform.acedata.cloud/console/applications).

Если появится сообщение о недостатке Key или вернется 401, убедитесь, что переменная окружения установлена, и полностью выйдите, затем снова откройте терминал и Codex.
