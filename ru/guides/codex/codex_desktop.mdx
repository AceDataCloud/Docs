Codex Desktop использует общий файл `~/.codex/config.toml` с Codex CLI.

## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка API Key

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "ваш API Key"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "ваш API Key"
```

## 3. Настройка AceDataCloud

Отредактируйте `~/.codex/config.toml` (для Windows это `%USERPROFILE%\.codex\config.toml`), добавив:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Для Windows измените последние две строки на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Не нужно заполнять `model`; после открытия Codex просто выберите модель.

## 4. Перезапуск и проверка

Полностью выйдите и снова откройте Codex Desktop, создайте локальную задачу и отправьте простое сообщение. Провайдер должен отображаться как `acedatacloud`; реальные вызовы можно просмотреть в [истории использования](https://platform.acedata.cloud/console/usages).

Если настройки не вступили в силу, убедитесь, что вы изменили файл `~/.codex/config.toml` текущего пользователя, переменная окружения установлена, а затем снова полностью перезапустите приложение. Облачные задачи или автоматизация, работающие в разных средах, требуют отдельной настройки Key в соответствующей среде.
