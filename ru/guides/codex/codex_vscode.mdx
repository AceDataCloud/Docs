Расширение Codex для VS Code использует общий файл `~/.codex/config.toml` с Codex CLI.

## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка расширения

Установите **Codex – OpenAI's coding agent**, выпущенный OpenAI, из магазина расширений VS Code, или выполните:

```bash
code --install-extension openai.chatgpt
```

## 3. Настройка API Key

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

Чтобы это работало постоянно, добавьте эту строку в `~/.zshrc` или `~/.bashrc`. В Windows PowerShell используйте:

```powershell
setx ACEDATACLOUD_API_KEY "ваш API Key"
```

## 4. Настройка AceDataCloud

Отредактируйте `~/.codex/config.toml` (в Windows это `%USERPROFILE%\.codex\config.toml`), добавив:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

В Windows измените последние две строки на:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Не нужно указывать `model`; модель можно выбрать в панели Codex.

## 5. Перезапуск и проверка

Полностью закройте и снова откройте VS Code, затем откройте панель Codex. Выполните `/model`, убедитесь, что Provider установлен на `acedatacloud`, затем отправьте простое сообщение; записи вызовов можно просмотреть в [Истории использования](https://platform.acedata.cloud/console/usages).

Если расширение не может прочитать Key, запустите VS Code из терминала, где установлены переменные окружения, или настройте системные переменные окружения и перезапустите VS Code. Remote SSH, WSL и Dev Container необходимо настраивать в среде, где фактически работает расширение.
