CC Switch можно управлять провайдером и API Key Codex через графический интерфейс.

## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка CC Switch

Скачайте и установите с [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), или выполните на macOS:

```bash
brew install --cask cc-switch
```

## 3. Добавление провайдера

1. Откройте CC Switch, переключитесь на **Codex**.
2. Нажмите **Add Provider**, выберите **Custom**.
3. Заполните:

| Поле      | Содержимое                        |
| --------- | -------------------------------- |
| Name      | `acedatacloud`                  |
| Base URL  | `https://api.acedata.cloud/v1`  |
| API Key   | Только что скопированный Ace Data Cloud API Key |

Если CC Switch предоставляет редактор для настройки, конфигурация должна оставаться следующей:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch сохранит API Key в `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Не добавляйте `env_key` или `[model_providers.acedatacloud.auth]` в указанный провайдер; ручная настройка и настройка CC Switch выбираются по одному. Не нужно фиксировать `model`, просто выберите его в Codex.

## 4. Включение и проверка

Включите провайдер `acedatacloud`, полностью выйдите и перезапустите Codex или VS Code. Выполните `/model`, подтвердите, что провайдер `acedatacloud`, затем выберите модель и отправьте простое сообщение.

Если возвращается 401, подтвердите, что в данный момент включен `acedatacloud`, и проверьте, что `OPENAI_API_KEY` в `~/.codex/auth.json` соответствует только что скопированному Ace Data Cloud API Key. Записи вызовов можно просмотреть в [истории использования](https://platform.acedata.cloud/console/usages).
