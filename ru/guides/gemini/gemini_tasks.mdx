Основная функция Gemini Tasks API — это получение информации о выполнении задачи по её ID, сгенерированному с помощью Gemini Videos Generation API.

В этом документе подробно описывается процесс интеграции Gemini Tasks API, который поможет вам легко интегрировать и получать статус выполнения задач Gemini Videos Generation API.

## Процесс подачи заявки

Для использования Gemini Tasks API необходимо сначала подать заявку на соответствующий сервис на странице [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) и скопировать ID задачи, возвращаемый Gemini Videos Generation API.

Затем перейдите на страницу [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) для подачи заявки на соответствующий сервис. После перехода на страницу нажмите кнопку «Acquire».

Если вы ещё не вошли в систему или не зарегистрированы, вас автоматически перенаправит на [страницу входа](https://platform.acedata.cloud) с приглашением зарегистрироваться и войти. После входа или регистрации вы автоматически вернётесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит, позволяющий бесплатно использовать данный API.

## Пример запроса

Gemini Tasks API используется для получения результатов Gemini Videos Generation API.

### Заголовки и тело запроса

**Request Headers** включают:

- `accept`: указывает, что ожидается ответ в формате JSON, значение — `application/json`.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

**Request Body** включает:

- `id`: ID задачи, которую необходимо запросить.
- `action`: действие с задачей, для одиночного запроса указывается `retrieve`.

### Пример кода CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Пример ответа

При успешном запросе API возвращает подробную информацию о задаче. Поле `request` содержит тело запроса, отправленного при создании задачи, а поле `response` — тело ответа после завершения задачи, например:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Описание полей:

- `id`: ID задачи, используемый для уникальной идентификации данной задачи.
- `request`: информация запроса, связанного с задачей.
- `response`: информация ответа, связанного с задачей.

## Массовый запрос

Для запроса информации по нескольким задачам одновременно установите `action` в значение `retrieve_batch` и передайте массив ID задач через `ids`:

**Request Body** включает:

- `ids`: массив ID задач, которые необходимо запросить.
- `action`: действие с задачами, для массового запроса указывается `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
