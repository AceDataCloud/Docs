В этой статье описывается инструкция по интеграции Gemini Videos Generation API, который позволяет создавать видео Google Gemini (omni-flash) на основе текстовых подсказок (и, опционально, референсных изображений).

## Процесс подачи заявки

Для использования API необходимо сначала подать заявку на соответствующую услугу на странице [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). После перехода на страницу нажмите кнопку «Acquire», как показано на изображении:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа, где можно зарегистрироваться и войти. После входа вы автоматически вернётесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит для использования API.

## Основное использование

Сначала рассмотрим базовый способ использования: вводим подсказку `prompt`, модель `model` и соотношение сторон `aspect_ratio` для генерации соответствующего видео.

Здесь мы задаём заголовки запроса (Request Headers), включая:

- `accept`: формат ответа, который хотим получить, здесь указано `application/json` (формат JSON).
- `authorization`: ключ доступа к API, который можно выбрать из выпадающего списка после подачи заявки.

Также задаются параметры тела запроса (Request Body):

- `prompt`: текстовое описание желаемого содержимого видео, **обязательно**.
- `model`: модель для генерации видео, на данный момент поддерживается только `omni-flash`, по умолчанию `omni-flash`.
- `aspect_ratio`: соотношение сторон видео, можно выбрать `16:9` (горизонтальное) или `9:16` (вертикальное), по умолчанию `16:9`.
- `image_urls`: опциональный массив ссылок на референсные изображения (или видео) для направления генерации, пустые элементы игнорируются.
- `callback_url`: URL для асинхронного обратного вызова; при его указании API сразу возвращает `task_id`, а по завершении задачи отправляет результат POST-запросом на этот адрес.

Нажмите кнопку «Try» для тестирования, результат будет примерно таким:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

В ответе присутствуют следующие поля:

- `success`: успешен ли запрос на генерацию видео.
- `task_id`: ID задачи генерации видео.
- `trace_id`: ID трассировки запроса для отладки.
- `data`: список результатов сгенерированных видео.
  - `id`: уникальный идентификатор сгенерированного видео.
  - `video_url`: ссылка на сгенерированное видео.
  - `state`: статус задачи генерации видео, возможные значения: `pending` / `succeeded` / `failed`.

Для получения сгенерированного видео достаточно использовать ссылку `video_url` из поля `data`.

Пример CURL-запроса:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Генерация видео на основе изображений

Если вы хотите сгенерировать видео на основе референсных изображений, передайте одну или несколько ссылок в `image_urls` для направления генерации:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Асинхронный обратный вызов

Генерация видео требует времени. Если вы не хотите держать соединение открытым, можно указать `callback_url`. В этом случае API сразу вернёт `task_id`, а после завершения задачи отправит результат POST-запросом на указанный адрес:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Мгновенный ответ будет таким:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Запрос статуса задачи

Если вы используете асинхронный обратный вызов или хотите самостоятельно проверить статус задачи, можно использовать [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) с параметром `task_id` для получения актуального статуса и результата.

## Обработка ошибок

При возникновении ошибок API возвращает соответствующий код и описание. Часто встречающиеся ошибки:

- `400`: неверные параметры запроса, например, отсутствует `prompt` или некорректное значение `aspect_ratio`.
- `401`: ошибка аутентификации, недействительный токен или несовпадение с API.
- `403`: недостаточно средств на балансе или отказ из-за проверки содержимого подсказки.
- `500`: внутренняя ошибка сервера или сбой на стороне генерации.
