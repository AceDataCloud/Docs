В этой статье будет представлена интеграция Gemini Videos Generation API, который может генерировать видео Google Gemini (omni-flash) на основе введенных текстовых подсказок (а также необязательных ссылок на изображения).

## Процесс подачи заявки

Чтобы использовать Gemini Videos Generation API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы получить ваш API Token и сохранить его.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вас пригласят зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно запрашивать отдельный токен для каждого сервиса.** При первом запросе предоставляется бесплатный лимит, чтобы вы могли попробовать; если лимит исчерпан, вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Основное использование

Сначала ознакомьтесь с основным способом использования, введя подсказку `prompt`, модель `model` и соотношение сторон `aspect_ratio`, чтобы сгенерировать соответствующее видео.

Здесь мы установили заголовки запроса, включая:

- `accept`: в каком формате вы хотите получить ответ, здесь указано `application/json`, то есть в формате JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после запроса.

Также установлен тело запроса, включая:

- `prompt`: текстовая подсказка, описывающая желаемое содержание видео, **обязательно**.
- `model`: модель для генерации видео, в настоящее время поддерживается только `omni-flash`, по умолчанию это `omni-flash`.
- `aspect_ratio`: соотношение сторон генерируемого видео, можно выбрать `16:9` (горизонтальный) или `9:16` (вертикальный), по умолчанию `16:9`.
- `resolution`: необязательное выходное разрешение, можно выбрать `720p` или `1080p`, по умолчанию `720p`.
- `image_urls`: массив ссылок на необязательные изображения для направления генерации видео, пустые поля будут проигнорированы. При использовании `video_urls` для редактирования видео этот параметр обязателен (не менее одной ссылки).
- `video_urls`: массив ссылок на необязательные видео (максимум 1), для **редактирования видео / видео-ссылки**; если предоставляется, необходимо также предоставить хотя бы одну ссылку из `image_urls`.
- `callback_url`: адрес асинхронного обратного вызова, после установки API немедленно вернет `task_id`, а по завершении задачи отправит результат на этот адрес.
- `async`: необязательный, если установлен в `true`, интерфейс немедленно возвращает `task_id`, не требуя предоставления `callback_url`, затем результаты можно получить через соответствующий интерфейс опроса задач.

Нажмите кнопку «Try», чтобы протестировать, и получите результат, похожий на следующий:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "Кинематографический кадр котенка, гоняющегося за бабочкой в солнечном саду"
    }
  ],
  "started_at": "2026-07-15T10:55:53.856Z",
  "finished_at": "2026-07-15T10:57:01.328Z",
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Возвращаемый результат содержит несколько полей, описанных ниже:

- `success`: успешен ли запрос на генерацию видео.
- `task_id`: ID задачи на генерацию видео.
- `trace_id`: ID отслеживания запроса, используемый для устранения проблем.
- `data`: список результатов сгенерированного видео.
  - `id`: уникальный идентификатор сгенерированного видео.
  - `video_url`: ссылка на сгенерированное видео (если `state` равно `pending`, то `null`).
  - `state`: статус задачи по генерации видео, может быть `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: соотношение сторон видео, совпадающее с параметрами запроса.
  - `prompt`: подсказка, использованная для генерации этого видео.

При синхронном возврате на верхнем уровне также будут присутствовать поля `started_at`, `finished_at`, `elapsed` (время выполнения, в секундах) и `cost` (стоимость запроса, в кредитах).

Нам нужно просто получить сгенерированное видео по ссылке `video_url` из результата `data`.

Соответствующий код CURL выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Кинематографический кадр котенка, гоняющегося за бабочкой в солнечном саду",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Соответствующий код на Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "Кинематографический кадр котенка, гоняющегося за бабочкой в солнечном саду",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Генерация видео на основе изображений

Если вы хотите создать видео на основе ссылок на изображения, вы можете передать одну или несколько ссылок в `image_urls`, чтобы направить генерацию видео:

```json
{
  "prompt": "Женщина медленно поворачивается и улыбается в камеру, легкий ветерок",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Редактирование видео / Ссылки на видео (входное видео, генерируемое видео)

Поддерживается возможность «ввести видео и сгенерировать новое видео»: передайте ссылку на одно видео в `video_urls` (максимум 1) и **одновременно** предоставьте хотя бы одно изображение в `image_urls` (это жесткое требование), затем используйте `prompt`, чтобы описать желаемый эффект редактирования (изменение стиля, смена сцены, добавление или удаление элементов и т. д.).

Вот полный реальный пример — изменить видео с солнечным пляжем на зимний пейзаж с падающим снегом, при этом сохранив расположение пляжа, пальм и маленькой лодки. Редактирование видео занимает больше времени (в этом примере около 6,5 минут), поэтому используется асинхронная отправка с `async: true`:
```json
{
  "prompt": "Преобразуйте этот солнечный тропический пляж в снежную зимнюю сцену с сильным падающим снегом и облачным небом; сохраните тот же пляж, пальмы и расположение лодок.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

После отправки интерфейс немедленно возвращает `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Затем используйте этот `task_id` в качестве `id` для опроса [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), после завершения задачи вы сможете получить сгенерированное новое видео (это реальный результат данного примера):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Преобразуйте этот солнечный тропический пляж в снежную зимнюю сцену с сильным падающим снегом и облачным небом; сохраните тот же пляж, пальмы и расположение лодок."
    }
  ],
  "started_at": "2026-07-15T03:01:22.914Z",
  "finished_at": "2026-07-15T03:07:57.090Z",
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Если вам нужен более качественный результат, вы можете установить `resolution` на `1080p` (остальные параметры остаются прежними).

> Подсказка: ссылки на медиа в примере являются реальными сгенерированными результатами. **Ссылки на видео и изображения, сгенерированные платформой, имеют срок хранения, после истечения которого они станут недоступными**, пожалуйста, скачайте и сохраните их на свое хранилище сразу после получения результата.

> Внимание: максимальное количество ссылок на видео - 1; и при предоставлении `video_urls` необходимо предоставить хотя бы одно `image_urls`, в противном случае будет возвращена следующая ошибка параметров:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (по крайней мере одно изображение-референс) требуется, когда предоставлены video_urls."
  }
}
```

## Асинхронный обратный вызов

Создание видео требует определенного времени обработки. Если вы не хотите поддерживать долгое соединение в ожидании, вы можете передать `callback_url`, в этом случае API немедленно вернет `task_id`, а после завершения задачи отправит окончательный результат на этот адрес:

```json
{
  "prompt": "Кинематографический кадр котенка, гоняющегося за бабочкой в солнечном саду",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Немедленно возвращаемый результат будет следующим:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Запрос результата задачи

Если вы использовали асинхронный обратный вызов или хотите самостоятельно проверить статус задачи, вы можете использовать [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) для запроса последнего статуса и результата задачи по `task_id`, передав `task_id`, полученный при создании видео, в качестве `id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Результат, возвращаемый после завершения задачи, будет похож на следующий, структура `response.data` будет такой же, как и при синхронном создании (в процессе генерации `state` будет `pending`, а `video_url` будет `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Таймлапс облаков над снежными горами на рассвете",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Таймлапс облаков над снежными горами на рассвете"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Обработка ошибок

Когда запрос вызывает проблемы, API возвращает соответствующий код ошибки и описание, наиболее распространенные из которых:

- `400`: Ошибка в параметрах запроса, например, отсутствует `prompt` или значение `aspect_ratio` недопустимо.
- `401`: Ошибка аутентификации, токен недействителен или не соответствует API.
- `403`: Недостаточно средств, или подсказка попала под проверку контента и была отклонена.
- `500`: Внутренняя ошибка сервера или сбой генерации на стороне поставщика.
