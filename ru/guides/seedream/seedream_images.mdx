В этой статье описывается инструкция по интеграции SeeDream Images Generation API, который позволяет создавать изображения SeeDream официального качества с помощью пользовательских параметров.

## Процесс подачи заявки

Для использования API необходимо сначала подать заявку на соответствующую услугу на странице [SeeDream Images Generation API](https://platform.acedata.cloud/documents/seedream-images). После перехода на страницу нажмите кнопку «Acquire», как показано на рисунке:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа, где вы сможете зарегистрироваться и войти. После входа вы автоматически вернетесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит, позволяющий бесплатно использовать API.

## Основное использование

Сначала рассмотрим базовый способ использования: вводим подсказку `prompt`, действие `action` и размер изображения `size`, после чего получаем результат. Для начала необходимо передать поле `action` со значением `generate`, а также ввести подсказку. Пример запроса:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Здесь мы задаём заголовки запроса (Request Headers):

- `accept`: формат ответа, здесь указывается `application/json` — формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

Также задаются параметры тела запроса (Request Body):

- `prompt`: подсказка.
- `model`: модель генерации, по умолчанию `doubao-seedream-5.0-lite`. Поддерживаются модели: `doubao-seedream-5.0-lite` (новейшая), `doubao-seedream-4.5`, `doubao-seedream-4.0`, `doubao-seedream-3.0-t2i`, `doubao-seededit-3.0-i2i`.
- `image`: входное изображение, поддерживается URL или Base64-кодировка. Модели `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` поддерживают одиночные и множественные изображения, `doubao-seededit-3.0-i2i` — только одиночное, `doubao-seedream-3.0-t2i` не поддерживает этот параметр.
- `size`: размер генерируемого изображения, поддерживаются два варианта, которые нельзя смешивать. Вариант 1 — указание разрешения (например, `2K`, `3K`, `4K`) и описание соотношения сторон в подсказке. Вариант 2 — указание точных пиксельных размеров, по умолчанию `2048x2048`, диапазон зависит от модели.
- `seed`: случайное зерно для управления случайностью генерации. Диапазон [-1, 2147483647]. Поддерживается только в `doubao-seedream-3.0-t2i` и `doubao-seededit-3.0-i2i`.
- `sequential_image_generation`: генерация серии связанных изображений. Поддерживается в `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, по умолчанию `disabled`.
- `stream`: управление режимом потокового вывода. Поддерживается в `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0`, по умолчанию `false`.
- `guidance_scale`: степень соответствия результата модели подсказке, чем выше, тем сильнее связь. Диапазон [1, 10]. По умолчанию 2.5 для `doubao-seedream-3.0-t2i`, 5.5 для `doubao-seededit-3.0-i2i`, не поддерживается другими моделями.
- `response_format`: формат возвращаемого изображения, по умолчанию `url`, также поддерживается `b64_json`.
- `watermark`: добавлять ли водяной знак на изображение, по умолчанию `true`.
- `output_format`: формат файла изображения, поддерживаются `jpeg` (по умолчанию) и `png`. Поддерживается только в `doubao-seedream-5.0-lite`.
- `tools`: инструменты, которые модель должна использовать, в настоящее время поддерживается `web_search` (поиск в интернете). Поддерживается только в `doubao-seedream-5.0-lite`.
- `callback_url`: URL для обратного вызова с результатом.

После выбора параметров справа автоматически сгенерируется соответствующий код, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

Нажмите кнопку «Try» для тестирования. В результате мы получим следующий ответ:

```json
{
  "success": true,
  "task_id": "25027ba3-0430-4a1b-91c8-d2297f19ba73",
  "trace_id": "8043a9e9-692f-43b0-82f7-5890f798be38",
  "data": [
    {
      "prompt": "a white siamese cat",
      "size": "2048x2048",
      "image_url": "https://platform.cdn.acedata.cloud/seedream/3c060029-69b1-406f-a957-fcd55ddc9386.jpg"
    }
  ]
}
```

Возвращаемые поля:

- `success`: статус задачи генерации изображения.
- `task_id`: ID задачи генерации.
- `trace_id`: ID трассировки задачи.
- `data`: список результатов генерации.
  - `image_url`: ссылка на сгенерированное изображение.
  - `prompt`: подсказка.
  - `size`: размер изображения в пикселях.

Таким образом, мы получили ссылку на сгенерированное изображение SeeDream из поля `data`.

Для генерации кода интеграции можно скопировать автоматически сгенерированный код, например CURL:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-4-0-250828",
  "prompt": "a white siamese cat"
}'
```

## Задачи редактирования изображений

Для редактирования изображения необходимо передать параметр `image` с URL изображения, которое нужно отредактировать.

- `model`: модель для задачи редактирования. Модели `doubao-seedream-5.0-lite`, `doubao-seedream-4.5`, `doubao-seedream-4.0` поддерживают одиночные и множественные изображения, `doubao-seededit-3.0-i2i` — только одиночное.
- `image`: загружаемое изображение для редактирования, одно или несколько.

Пример заполнения:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Пример кода:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
    "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
    "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
    "size": "2K",
    "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

При запуске сразу получаем результат:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

Результат — отредактированное изображение, аналогично предыдущему примеру.

## Асинхронный обратный вызов

Так как генерация изображений SeeDream Images Generation API занимает относительно длительное время (около 1-2 минут), при отсутствии ответа API HTTP-соединение остается открытым, что приводит к дополнительным затратам системных ресурсов. Поэтому API поддерживает асинхронный обратный вызов.

Общий процесс: клиент при запросе указывает дополнительное поле `callback_url`. После отправки запроса API сразу возвращает ответ с полем `task_id` — идентификатором задачи. По завершении задачи результат генерации изображения отправляется методом POST в формате JSON на указанный `callback_url`, включая поле `task_id` для связи результата с задачей.

Пример работы:

При запуске сразу получаем ответ:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

Содержимое результата:

```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

В ответе есть поле `task_id`, остальные поля аналогичны предыдущим примерам, что позволяет связать результаты с задачей по ID.

## Обработка ошибок

При вызове API в случае ошибки возвращаются соответствующие коды и сообщения, например:

- `400 token_mismatched`: некорректный запрос, возможно, отсутствуют или неверны параметры.
- `400 api_not_implemented`: некорректный запрос, возможно, отсутствуют или неверны параметры.
- `401 invalid_token`: неавторизован, неверный или отсутствующий токен авторизации.
- `429 too_many_requests`: слишком много запросов, превышен лимит.
- `500 api_error`: внутренняя ошибка сервера.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
