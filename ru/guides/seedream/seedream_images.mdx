В этой статье будет представлено описание интеграции SeeDream Images Generation API, который позволяет генерировать официальные изображения SeeDream посредством ввода пользовательских параметров.

## Процесс подачи заявки

Чтобы использовать SeeDream Images Generation API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости подавать отдельную заявку для каждого сервиса.** При первой заявке предоставляется бесплатный лимит, позволяющий бесплатно протестировать сервис; при недостатке лимита можно пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## Базовое использование

Сначала рассмотрим базовый способ использования: достаточно ввести промпт `prompt`, действие генерации `action` и размер изображения `size`, чтобы получить обработанный результат; сначала необходимо просто передать поле `action` со значением `generate`, затем также нужно ввести промпт, конкретное содержимое приведено ниже:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

Можно увидеть, что здесь мы настроили Request Headers, включая:

- `accept`: какой формат ответа вы хотите получить, здесь указывается `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после подачи заявки его можно напрямую выбрать из выпадающего списка.

Также настроен Request Body, включая:

- `prompt`: промпт.
- `model`: модель генерации, по умолчанию `doubao-seedream-5-0-lite-260128` (SeeDream 5.0 Lite, новейшая). Поддерживаются `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`. Среди них `doubao-seedream-5-0-pro-260628` (SeeDream 5.0 Pro) является флагманской моделью для одиночных изображений и генерирует только одно изображение, **не поддерживает группы изображений (`sequential_image_generation`), потоковый режим (`stream`) и веб-поиск (`tools`)**. **В `model` необходимо передавать полную строку модели (например, `doubao-seedream-5-0-lite-260128`); передача сокращений вроде `doubao-seedream-5.0-lite` вернёт 400.**
- `image`: информация о входном изображении, поддерживаются URL или кодировка Base64. `doubao-seedream-5-0-pro-260628` поддерживает ввод одного или нескольких изображений (до 10), `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` поддерживают ввод одного или нескольких изображений.
- `size`: задаёт информацию о размере генерируемого изображения, поддерживаются следующие два способа, их нельзя смешивать. Способ 1 | Указать разрешение генерируемого изображения и описать соотношение сторон изображения естественным языком в prompt. **Поддерживаемые предустановки различаются для каждой модели**: `doubao-seedream-5-0-pro-260628` поддерживает `1K`/`1.5K`/`2K`; `doubao-seedream-5-0-lite-260128` поддерживает `2K`/`3K`/`4K`; `doubao-seedream-4-5-251128` поддерживает только `2K`/`4K`; `doubao-seedream-4-0-250828` поддерживает `1K`/`2K`/`4K`. Способ 2 | Указать значения ширины и высоты генерируемого изображения в пикселях: по умолчанию `2048x2048`, диапазоны общего количества пикселей и соотношения сторон различаются в зависимости от модели (например, для 5.0 Pro диапазон общего количества пикселей составляет [921600, 4624220], нижний предел для 5.0 Lite / 4.5 составляет 3,686,400, для 4.0 — 921,600).
- `sequential_image_generation`: группа изображений: набор взаимосвязанных изображений, генерируемых на основе введённого вами содержимого. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` поддерживают этот параметр, по умолчанию `disabled`.
- `stream`: управляет включением режима потокового вывода. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` поддерживают этот параметр, по умолчанию `false`.
- `response_format`: задаёт формат возврата генерируемого изображения. По умолчанию `url`, также поддерживается `b64_json`.
- `watermark`: добавлять ли водяной знак на сгенерированное изображение. По умолчанию `true`.
- `output_format`: задаёт формат файла генерируемого изображения, поддерживаются `jpeg` (по умолчанию) и `png`. Поддерживается только `doubao-seedream-5-0-pro-260628` и `doubao-seedream-5-0-lite-260128`.
- `tools`: настраивает инструменты, которые должна вызывать модель, в настоящее время поддерживается `web_search` (веб-поиск). Поддерживается только Seedream 5.0 Lite.
- `optimize_prompt_options`: конфигурация оптимизации промпта. 5.0 Pro поддерживает `standard`/`fast`; 5.0 Lite и 4.5 поддерживают только `standard`; 4.0 поддерживает `standard`/`fast`.
- `background`: поддерживается только редактирование одиночного изображения в 5.0 Pro. `transparent` требует ввода PNG с прозрачным каналом, а `output_format` должен быть `png`; `opaque` — это обычный непрозрачный фон.
- `layer_decomposition`: поддерживается только 5.0 Pro. При установке значения `true` необходимо ввести одно изображение PNG/JPEG; можно не передавать `prompt` для автоматического разделения или указать элементы с помощью естественного языка/`<bbox>`; `size` поддерживает `auto`/`1K`/`1.5K`/`2K`. Этот режим нельзя использовать вместе с группами изображений, потоковым режимом, веб-поиском или `background`.
- `callback_url`: URL, на который необходимо отправить результат обратного вызова.
- `async`: обрабатывать ли в асинхронном режиме. При установке значения `true` интерфейс немедленно возвращает `task_id`, предоставлять `callback_url` не требуется, после чего результат можно получить опросом через `/seedream/tasks`.

После выбора можно заметить, что справа также сгенерирован соответствующий код, как показано на рисунке:

Нажмите кнопку «Try», чтобы выполнить тестирование, как показано на рисунке выше, здесь мы получили следующий результат:
```json

  "task_id": "80ceeed1-17d4-4eb7-82e0-18b34290f36e",
  "trace_id": "96b7fdc8-0fc8-4e2e-82a9-83c0a82f0a08",

    }
  ]

```

Результат содержит несколько полей, описание приведено ниже:

- `success` — статус задачи генерации видео в данный момент.
- `task_id` — ID задачи генерации видео в данный момент.
- `trace_id` — ID отслеживания генерации видео в данный момент.
- `data` — список результатов задачи генерации изображений в данный момент.
  - `image_url` — ссылка задачи генерации изображения в данный момент.
  - `prompt` — промпт.
  - `size`: пиксели сгенерированного изображения

Можно увидеть, что мы получили удовлетворительную информацию об изображении, нам нужно лишь получить сгенерированное изображение SeeDream по адресу ссылки изображения в результате `data`.

Кроме того, если вы хотите сгенерировать соответствующий код интеграции, его можно непосредственно скопировать и сгенерировать, например, код CURL приведён ниже:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## Задача редактирования изображения

Если вы хотите отредактировать какое-либо изображение, сначала в параметр `image` необходимо передать ссылку на изображение, которое нужно отредактировать

- model：модель, используемая в этой задаче редактирования изображения; `doubao-seedream-5-0-pro-260628`、`doubao-seedream-5-0-lite-260128`、`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828` поддерживают ввод изображений.
- image：загрузите изображения, которые необходимо отредактировать, одно или несколько

Пример заполнения приведён ниже:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

Соответствующий код:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажмите «Выполнить», и можно увидеть, что результат будет получен немедленно, как показано ниже:

    {

Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
      "size": "2048x2048",

Можно увидеть, что сгенерированный эффект представляет собой результат редактирования исходного изображения, результат аналогичен вышеописанному.

## Разделение на слои (Seedream 5.0 Pro)

Разделение на слои разбивает одно входное изображение на 1 фоновое изображение и до 16 независимо редактируемых прозрачных PNG-слоёв. Следующий запрос позволяет модели автоматически распознать основные элементы; если необходимо указать элементы, можно добавить `prompt`, также в промпте можно использовать нормализованные координаты `<bbox>`.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

Возвращаемые `data` упорядочены по `z_index` снизу вверх. `z_index` фонового изображения равен 0; слои также содержат `name`, `description` и `bounding_box.absolute`/`normalized`. При повторной сборке с использованием абсолютных координат масштабируйте слои до `[right-left, bottom-top]`, разместите их в `[left, top]`, затем накладывайте в порядке возрастания `z_index`. Если генерация любого слоя завершается неудачей, всё разделение завершается неудачей.

## Потоковый вывод

При установке `stream: true` для Lite/4.x используйте в заголовке запроса `accept: application/x-ndjson`. Интерфейс построчно возвращает `image_generation.partial_succeeded` или `image_generation.partial_failed`, а в конце возвращает единственное событие `image_generation.completed` и итоговый `usage`; только событие завершения запускает однократное списание платы. Потоковый режим нельзя использовать вместе с `async` или `callback_url`.

## Асинхронный обратный вызов

Поскольку время генерации SeeDream Images Generation API относительно длительное, примерно 1–2 минуты, если API долго не отвечает, HTTP-запрос будет постоянно поддерживать соединение, что приведёт к дополнительному потреблению системных ресурсов, поэтому данный API также предоставляет поддержку асинхронных обратных вызовов.

Общий процесс следующий: когда клиент инициирует запрос, он дополнительно указывает поле `callback_url`; после того как клиент инициирует API-запрос, API немедленно возвращает результат, содержащий информацию поля `task_id`, представляющего ID текущей задачи. После завершения задачи результат генерации изображения будет отправлен в формате POST JSON на указанный клиентом `callback_url`, который также включает поле `task_id`, таким образом результаты задачи можно связать по ID.

Если у вас нет публичного адреса для обратного вызова, вы также можете не указывать `callback_url`, а установить в запросе поле `async` в значение `true`. В этом случае интерфейс также немедленно вернёт `task_id`, но не будет отправлять результат, вам необходимо вызвать интерфейс `/seedream/tasks` с этим `task_id` для опроса статуса задачи и получения окончательного результата.

Ниже мы на примере рассмотрим, как именно это сделать.

Содержимое следующее:

Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
            "size": "2048x2048",

Можно увидеть, что в результате есть поле `task_id`, другие поля аналогичны приведённым выше, и через это поле можно реализовать связь задач.

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`：Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `400 api_not_implemented`：Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `401 invalid_token`：Неавторизованный доступ, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили ограничение частоты запросов.
- `500 api_error`：Внутренняя ошибка сервера, на сервере что-то пошло не так.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
