Maestro — это **нативный для Agent** интерфейс видеопроизводства: вы одной фразой на естественном языке в `prompt` описываете желаемое видео (при необходимости прикладываете референсные изображения / видео / аудио через `file_urls`), а безголовый «AI-режиссёр» автоматически выполнит выбор темы, написание сценария, генерацию визуала, озвучку, подбор музыки, компоновку и рендеринг, в итоге создаст готовый ролик с субтитрами и загрузит его в CDN.

В этой статье подробно описано руководство по интеграции API генерации видео Maestro, которое поможет вам быстро выполнить интеграцию и в полной мере использовать возможности этого API.

Это интерфейс **асинхронных задач**: после отправки сразу возвращается `task_id`, затем результат можно получать путём опроса через [API запроса задач Maestro](/ru/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (опрос бесплатный и не тарифицируется). Чтобы продолжить итерации над существующим видео, можно использовать `action: remix` / `edit` / `extend` вместе с `ref_task_id`.

## Процесс получения

Чтобы использовать API генерации видео Maestro, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вас автоматически перенаправит на страницу входа с предложением зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно подавать отдельную заявку для каждого сервиса.** При первом получении предоставляется бесплатный лимит для бесплатного ознакомления; при недостаточном лимите можно пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [API генерации видео Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Базовое использование

`POST https://api.acedata.cloud/maestro/videos`

Для самого базового использования нужно передать только один `prompt` на естественном языке, AI-режиссёр автоматически определит сценарий, визуал, озвучку и монтаж. Здесь мы сначала ознакомимся с заголовками и телом запроса, которые необходимо настроить.

**Request Headers** включают:

- `accept`: в каком формате вы хотите получить результат ответа; здесь указывается `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после получения его можно напрямую выбрать из выпадающего списка.
- `content-type`: формат тела запроса; здесь указывается `application/json`.

**Request Body** в основном включает:

- `prompt`: опишите создаваемое видео на естественном языке (тема, что нужно показать, стиль, аудитория).
- `langs`: массив языков готового ролика, каждый раз передаётся только один, например `["zh-cn"]`, по умолчанию `["zh-cn"]`.
- `aspect`: соотношение сторон, `9:16` (по умолчанию) / `16:9` / `1:1`.
- `duration`: целевая длительность (секунды), по умолчанию 30.

Все поля тела запроса приведены в таблице ниже:

| Поле            | Тип       | Обязательное  | Описание                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Да   | Опишите создаваемое видео на естественном языке (тема, что нужно показать, стиль, аудитория). Сценарий, визуал, озвучка и монтаж определяются AI                                                                                                                                                                             |
| `action`      | string   | Нет   | `generate` (по умолчанию, создание нового видео) / `remix` / `edit` / `extend` (итерации над существующим видео, требуется использовать вместе с `ref_task_id`)                                                                                                                                                |
| `ref_task_id` | string   | Нет   | Обязательно, когда `action` имеет значение remix / edit / extend: `task_id` исторической задачи, используемой как отправная точка                                                                                                                                                                   |
| `file_urls`   | string[] | Нет   | Референсные медиа (URL изображений / видео / аудио), например изображение продукта или logo, которые должны появиться в кадре, либо фрагмент материала, к которому нужно добавить субтитры                                                                                                                                                                             |
| `langs`       | string[] | Нет   | Язык готового ролика; за один раз можно передавать только один, например `["zh-cn"]`, по умолчанию `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | Нет   | `9:16` (по умолчанию) / `16:9` / `1:1`, единый вывод 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | Нет   | Целевая длительность (секунды), по умолчанию 30, поддерживается **5–300 секунд**. Тарификация производится по фактической длительности готового ролика, но она не превысит запрошенную длительность                                                                                                                                                                             |
| `scenario`    | string   | Нет   | Тип видео: `auto` / `narrated` / `captions` / `avatar` / `drama`. Для `captions` необходимо передать исходное видео, для `avatar` необходимо передать портрет                                                                                                                                    |
| `style`       | string   | Нет   | Предустановки визуального стиля: `auto` (по умолчанию) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; также принимается свободный текст в качестве мягкой подсказки. Ортогонально `scenario` и не изменяет маршрутизацию |
| `voice`       | string   | Нет   | Голос закадрового текста (не зависит от языка, универсален для разных языков): `auto` (по умолчанию) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

Ниже приведена демонстрация на конкретном примере. Предположим, мы хотим создать китайское вертикальное научно-популярное короткое видео длительностью 20 секунд, соответствующий код CURL выглядит следующим образом:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Соответствующий код Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажмите «Выполнить», и можно увидеть, что сразу будет получен результат, как показано ниже:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Описание полей результата ответа приведено ниже:
- `success`: успешно ли отправлена эта задача.
- `task_id`: ID данной задачи по генерации видео; впоследствии используйте его для опроса результата через [API запросов задач Maestro](/ru/guides/maestro/maestro_tasks).
- `trace_id`: ID отслеживания данного запроса; при возникновении проблем его можно предоставить технической поддержке для диагностики.

Поскольку создание видео занимает продолжительное время, интерфейс **немедленно возвращает `task_id`** и не ожидает завершения рендеринга видео. Далее необходимо использовать `task_id` для опроса результата; подробнее см. раздел «Получение результата».

## Указание типа и стиля видео (scenario / style)

Если не передавать `scenario`, AI определит его автоматически (эквивалентно `auto`); если нужно закрепить видео за определённым типом, передайте его явно. Например, для создания **вертикальной короткой драмы** можно указать следующее:

- `scenario`: тип видео; здесь установите `drama` (короткая драма с персонажами + диалогами).
- `style`: визуальный стиль; здесь установите `cinematic` (кинематографическое качество).

Пример заполненного CURL-кода выглядит следующим образом:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Распространённые варианты сочетаний:

- Короткий ролик с озвучкой: `scenario: "narrated"`.
- Автоматические субтитры: `scenario: "captions"`; необходимо передать исходное видео через `file_urls`.
- Цифровой аватар / разговорный ролик: `scenario: "avatar"`; необходимо передать одно изображение человека через `file_urls`.
- Короткая драма: `scenario: "drama"` (персонажи + диалоги).
- `style` — это предустановка визуального стиля (например, `modern` / `neon` / `luxury`), которая не меняет тип и влияет только на восприятие.
- `voice` используется для указания тембра голоса диктора (например, `warm-female` / `deep-male`), не зависит от языка и универсален для разных языков.

Возвращаемый результат совпадает с разделом «Базовое использование»: `task_id` также возвращается немедленно.

## Язык готового видео

Одна задача предоставляет только одно готовое видео на одном языке. `langs` может содержать только один языковой код, например `["zh-cn"]` или `["en"]`; передача нескольких языков вернёт 400. Если требуются видео на разных языках, создавайте отдельные задачи. Выбор языка не меняет цену за секунду.

## Итерации над существующим видео (remix / edit / extend)

Передайте `action` и `ref_task_id` предыдущей задачи, чтобы вносить инкрементальные изменения на основе исходного проекта (например, «изменить заголовок 2-й сцены», «сменить озвучку», «сделать всё темнее»). Небольшие изменения выполняются быстро, а значительные приведут к переработке:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: новая интерпретация на основе структуры исходного видео (сохраняет тему, изменяет подачу).
- `edit`: точная доработка указанной части (например, смена заголовка, озвучки или цветокоррекции).
- `extend`: расширение контента на основе исходного видео.

Возвращаемый результат также немедленно содержит новый `task_id`; используйте его для опроса и получения готового видео после итерации.

## Получение результата

Поскольку создание видео занимает продолжительное время, данный интерфейс сразу после отправки возвращает `task_id`; вам необходимо использовать его для опроса результата через [API запросов задач Maestro](/ru/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

После завершения задачи будет возвращена информация об одном готовом видео (находится в массиве `variants`). `status` будет проходить состояния `pending → planning → producing → succeeded` (или `failed`), **опрос бесплатен и не расходует кредиты**. Полный формат ответа и запрос списка истории см. в [инструкции по интеграции API запросов задач Maestro](/ru/guides/maestro/maestro_tasks).

## Тарификация

**После успешного выполнения задачи плата взимается за фактическую продолжительность предоставленного готового видео; при неудаче плата не взимается.** Тарифицируемая продолжительность учитывается в целых секундах и не превышает запрошенную продолжительность; если продолжительность готового видео невозможно определить, используется запрошенная продолжительность. Отправка задачи сама по себе отдельно не тарифицируется, опрос `/maestro/tasks` бесплатен.

```
Кредиты = фактическое количество тарифицируемых секунд × 0.7
```

Для всех сценариев, действий и языков действует единая цена, без множителей за сценарии или доплат за языки. Каждая задача предоставляет только одно готовое видео на одном языке. Поддерживаемая целевая продолжительность запроса — 5–300 секунд, единый вывод — 1080p / 30fps.

| Фактическая тарифицируемая продолжительность | Кредиты |
| ------------------- | --: |
| 30 секунд           |  21 |
| 60 секунд           |  42 |
| 120 секунд          |  84 |
| 300 секунд          | 210 |
| Опрос `/maestro/tasks` | Бесплатно |

## Обработка ошибок

При вызове API, если возникает ошибка, API возвращает соответствующий код ошибки и сообщение. Например:

- `400 invalid_request`: Некорректный запрос, возможно из-за отсутствующего `prompt` или недопустимых параметров.
- `401 invalid_token`: Не авторизован, недопустимый или отсутствующий токен авторизации.
- `403 forbidden`: Доступ запрещён, недостаточный баланс или права доступа.
- `429 too_many_requests`: Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`: Внутренняя ошибка сервера, на сервере произошёл сбой.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
