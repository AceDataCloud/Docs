Maestro — это **Agent-нативный** интерфейс производства видео: вы одной фразой на естественном языке `prompt` описываете желаемое видео (опционально прикладывая через `file_urls` референсные изображения / видео / аудио), а безголовый «AI-режиссёр» автоматически выполнит выбор темы, написание сценария, генерацию визуала, озвучку, создание музыки, компоновку и рендеринг, в итоге создав готовый ролик с субтитрами и загрузив его в CDN.

В этой статье будет подробно представлено руководство по интеграции API генерации видео Maestro, чтобы помочь вам быстро интегрировать и в полной мере использовать возможности данного API.

Это интерфейс **асинхронных задач**: после отправки сразу возвращается `task_id`, а затем результат получается через опрос [API запросов задач Maestro](/ru/guides/maestro/maestro_tasks) (`POST /maestro/tasks`) (опрос бесплатен и не тарифицируется). Чтобы продолжить итерации над существующим видео, можно использовать `action: remix` / `edit` / `extend` вместе с `ref_task_id`.

## Процесс подачи заявки

Чтобы использовать API генерации видео Maestro, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа с приглашением зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости подавать отдельную заявку для каждого сервиса.** При первой заявке будут предоставлены бесплатные квоты, позволяющие бесплатно опробовать сервис; при недостатке квоты можно пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [API генерации видео Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Базовое использование

`POST https://api.acedata.cloud/maestro/videos`

Для самого базового использования достаточно передать описание на естественном языке `prompt`, а ИИ-режиссёр автоматически определит сценарий, визуальный ряд, озвучку и монтаж. Сначала рассмотрим необходимые заголовки и тело запроса.

**Заголовки запроса** включают:

- `accept`：формат ответа, который вы хотите получить. Укажите `application/json`, то есть формат JSON.
- `authorization`：ключ для вызова API, который после получения можно выбрать из выпадающего списка.
- `content-type`：формат тела запроса. Укажите `application/json`.

**Тело запроса** в основном включает:

- `prompt`：опишите создаваемое видео на естественном языке (тема, что показать, стиль, аудитория).
- `langs`：массив языков готового видео; за один раз передаётся только один язык, например `["zh-cn"]`; по умолчанию — `["zh-cn"]`.
- `aspect`：соотношение сторон, `9:16` (по умолчанию) / `16:9` / `1:1`.
- `duration`：целая длительность (в секундах), по умолчанию — 30.

Все поля тела запроса приведены в таблице ниже:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `prompt` | string | Да | Опишите создаваемое видео на естественном языке (тема, что показать, стиль, аудитория). Сценарий, визуальный ряд, озвучку и монтаж определяет ИИ. |
| `action` | string | Нет | `generate` (по умолчанию, создание нового видео) / `remix` / `edit` / `extend` (итерация на основе существующего видео; требуется использовать вместе с `ref_task_id`) |
| `ref_task_id` | string | Нет | Обязательно, если `action` имеет значение remix / edit / extend: `task_id` исторической задачи, используемой в качестве отправной точки. |
| `file_urls` | string[] | Нет | Референсные медиафайлы (URL изображений / видео / аудио), например изображение продукта или логотип, которые должны появиться в кадре, либо фрагмент материала, к которому нужно добавить субтитры. |
| `langs` | string[] | Нет | Язык готового видео: за раз можно передать только один, например `["zh-cn"]`; по умолчанию — `["zh-cn"]` |
| `aspect` | string | Нет | `9:16` (по умолчанию) / `16:9` / `1:1`; единый выходной формат — 1080p/30fps |
| `duration` | int | Нет | Целевая длительность (в секундах), по умолчанию 30; поддерживается **5–300 секунд**. Оплата взимается за фактическую длительность готового видео, но не превышает запрошенную длительность |
| `scenario` | string | Нет | Тип видео: `auto` / `narrated` / `captions` / `avatar` / `drama`. Для `captions` необходимо передать исходное видео, для `avatar` — портрет |
| `style` | string | Нет | Предустановки визуального стиля: `auto` (по умолчанию) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`; также принимается произвольный текст в качестве мягкой подсказки. Можно задавать независимо от `scenario` |
| `voice` | string | Нет | Голос озвучки (не зависит от языка и универсален для разных языков): `auto` (по умолчанию) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; также поддерживается 32-разрядный шестнадцатеричный reference_id голоса. Другой произвольный текст не является допустимым ID голоса |

Ниже приведён конкретный пример. Предположим, мы хотим создать 20-секундное научно-популярное короткое видео на китайском языке в вертикальном формате. Соответствующий код CURL выглядит следующим образом:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

Соответствующий код Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажмите «Выполнить» — и вы сразу получите результат, как показано ниже:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Описание полей результата приведено ниже:

- `success`: успешно ли была отправлена эта задача.
- `task_id`: ID задачи генерации видео; используйте его далее для опроса результата через [API запроса задач Maestro](/ru/guides/maestro/maestro_tasks).
- `trace_id`: ID отслеживания этого запроса; при возникновении проблем его можно предоставить технической поддержке для диагностики.

Поскольку создание видео занимает продолжительное время, API **немедленно возвращает `task_id`** и не ожидает завершения рендеринга видео. Далее необходимо использовать `task_id` для опроса результата; подробности см. в разделе «Получение результата».

## Указание типа и стиля видео（scenario / style）

Если `scenario` не передан, AI определит его автоматически (эквивалентно `auto`); если нужно закрепить видео за определённым типом, передайте его явно. Например, для создания **вертикальной короткой драмы** можно указать следующее:

- `scenario`：тип видео, здесь устанавливается в `drama`（короткая драма с персонажами + диалогами）。
- `style`：визуальный стиль, здесь устанавливается в `cinematic`（кинематографическое качество）。

CURL-код заполненного примера выглядит следующим образом:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Распространённые варианты сочетаний:

- Ролик с закадровым объяснением：`scenario: "narrated"`。
- Автоматические субтитры：`scenario: "captions"`，необходимо передать исходное видео через `file_urls`。
- Цифровой аватар / разговорный ролик：`scenario: "avatar"`，необходимо передать изображение человека через `file_urls`。
- Короткая драма：`scenario: "drama"`（персонажи + диалоги）。
- `style` — это предустановка визуального стиля（например, `modern` / `neon` / `luxury`），она не меняет тип и влияет только на восприятие.
- `voice` используется для указания тембра голоса закадрового текста（например, `warm-female` / `deep-male`），не зависит от языка и универсален для разных языков.

Возвращаемый результат аналогичен разделу «Базовое использование»: также немедленно возвращается `task_id`.

## Язык готового видео

Одна задача создаёт только одно готовое видео на одном языке. `langs` может содержать только один языковой код, например `["zh-cn"]` или `["en"]`; передача нескольких языков вернёт 400. Если нужны видео на разных языках, создайте отдельные задачи. Выбор языка не изменяет цену за секунду.

## Итерации над существующим видео（remix / edit / extend）

Передайте `action` и `ref_task_id` предыдущей задачи, чтобы внести инкрементальные изменения на основе исходного проекта（например, «изменить заголовок второй сцены», «сменить озвучку», «сделать всё темнее»）。Небольшие изменения выполняются быстро, а крупные потребуют переработки:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：новая интерпретация на основе структуры исходного видео（сохраняет тему, корректирует подачу）。
- `edit`：детальная доработка указанной части（например, смена заголовка, озвучки или цветокоррекции）。
- `extend`：расширение содержания на основе исходного видео.

Результатом также будет немедленный возврат нового `task_id`; используйте его для опроса, чтобы получить готовое видео после итерации.

## Получение результатов

Поскольку производство видео занимает длительное время, этот интерфейс немедленно возвращает `task_id` после отправки; необходимо использовать его для опроса результатов через [API запросов задач Maestro](/ru/guides/maestro/maestro_tasks)：

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

После завершения задачи будет возвращена информация об одном готовом видео（находится в массиве `variants`）。`status` будет проходить через `pending → planning → producing → succeeded`（или `failed`），**опрос бесплатен и не расходует кредиты**。Полный формат ответа и запрос списка истории см. в [инструкции по интеграции API запросов задач Maestro](/ru/guides/maestro/maestro_tasks)。

## Тарификация

**После успешного выполнения задачи оплата взимается по фактической длительности доставленного готового видео; при неудаче плата не взимается.** Тарифицируемая длительность рассчитывается в целых секундах и не превышает запрошенную длительность; если длительность готового видео невозможно определить, используется запрошенная длительность. Сама отправка задачи отдельно не тарифицируется, опрос `/maestro/tasks` бесплатен.

```
Кредиты = фактическое количество тарифицируемых секунд × 0.7
```

Для всех сценариев, действий и языков действует единая цена, без коэффициентов для сценариев или доплат за язык. Каждая задача создаёт только одно готовое видео на одном языке. Запрашиваемая целевая длительность поддерживается от 5 до 300 секунд, единый выходной формат — 1080p / 30fps.

| Фактическая тарифицируемая длительность | Кредиты |
| ------------------- | --: |
| 30 секунд           |  21 |
| 60 секунд           |  42 |
| 120 секунд          |  84 |
| 300 секунд          | 210 |
| Опрос `/maestro/tasks` | Бесплатно |

## Обработка ошибок

При вызове API в случае ошибки API вернёт соответствующий код и сообщение об ошибке. Например:

- `400 invalid_request`：Некорректный запрос, возможно из-за отсутствующего `prompt` или недопустимых параметров.
- `401 invalid_token`：Не авторизовано, недопустимый или отсутствующий токен авторизации.
- `403 forbidden`：Доступ запрещён, недостаточный баланс или права доступа.
- `429 too_many_requests`：Слишком много запросов, вы превысили лимит скорости.
- `500 api_error`：Внутренняя ошибка сервера, на сервере что-то пошло не так.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
