В данной статье будет представлено описание интеграции Veo Extend API. Этот интерфейс используется для **расширения длительности** уже сгенерированного видео Veo, AI автоматически продолжит писать последующие кадры.

## Процесс подачи заявки

Чтобы использовать API, необходимо сначала подать заявку на соответствующей странице сервиса Veo. Если вы еще не вошли в систему или не зарегистрированы, произойдет автоматический переход на страницу входа.

## Основное использование

Для вызова этого интерфейса необходимо передать следующие параметры:

- `video_id` (обязательный): ID задачи исходного видео (из `/veo/videos` или самого этого интерфейса).
- `model` (обязательный): модель, используемая для расширения, **поддерживаются только модели `veo31-fast` и `veo31`**, другие модели не поддерживаются.
- `prompt` (необязательный): текстовая подсказка для направления расширяемых кадров.
- `aspect_ratio` (необязательный): `16:9` или `9:16`, по умолчанию `16:9`.
- `resolution` (необязательный): `720p` или `1080p`.

Пример запроса:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "камера медленно отдаляется, чтобы показать больше пейзажа"
  }'
```

Результат будет аналогичен `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Важные ограничения

`video_id` должен быть получен из текущей линии `/veo/videos`, сгенерированной или завершенной после расширения `data[].id`. ID видео, сгенерированные в более ранних исторических линиях, не могут быть использованы с этим интерфейсом, при вызове будет возвращен `400 bad_request`; пожалуйста, повторно сгенерируйте через `/veo/videos`, прежде чем расширять.

Результаты видео, полученные из `/veo/extend`, могут **дальше быть расширены через `/veo/extend`**, но **не могут** обрабатываться следующими интерфейсами:

- `/veo/reshoot` — нельзя менять движение камеры
- `/veo/objects` — нельзя добавлять или удалять объекты

Если переданный `video_id` является результатом расширения, соответствующие интерфейсы вернут ошибку 400, пожалуйста, используйте оригинальное видео в качестве источника.

## Условия оплаты

- `model=veo31-fast`: 1.68 кредитов / раз
- `model=veo31`: 12.00 кредитов / раз

## Асинхронный обратный вызов

Интерфейс поддерживает асинхронный режим, передав `callback_url`, вы сможете получить результаты через POST-запрос после завершения задачи. Если нет публичного адреса для обратного вызова, вы также можете установить `async` в `true`, интерфейс сразу вернет `task_id`, после чего можно будет опрашивать соответствующий интерфейс для получения результатов.
