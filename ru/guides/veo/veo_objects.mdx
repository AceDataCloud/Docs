В данной статье будет представлено описание интеграции Veo Objects API. Этот интерфейс используется для выполнения операций **добавления или удаления объектов** в уже сгенерированном видео Veo (на основе маски для локальной перерисовки).

## Процесс подачи заявки

Чтобы использовать API, необходимо сначала подать заявку на соответствующей странице сервиса Veo. Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа.

## Основное использование

Для вызова этого интерфейса необходимо передать следующие параметры:

- `video_id` (обязательный): ID задачи исходного видео. **Не может** быть выходным видео `/veo/extend`.
- `action` (обязательный): тип операции, `insert` или `remove`.
- `prompt`:
  - `action=insert`: **обязательный**, описание объекта, который нужно добавить.
  - `action=remove`: необязательный, описание содержимого, которое нужно удалить (в основном для ведения журнала, фактическая область стирания определяется `image_mask`).
- `image_mask`:
  - `action=insert`: необязательный. Если не передан, ИИ автоматически определит место вставки; если передан, то вставка происходит в области белых пикселей.
  - `action=remove`: **обязательный**, область белых пикселей — это объекты, которые нужно стереть.

`image_mask` принимает два формата:

1. **Общедоступный HTTP(S) адрес изображения** (рекомендуется).
2. **Строка JPEG в кодировке base64**, может иметь префикс `data:image/jpeg;base64,`, а также может быть в чистом виде base64.

Пример запроса (добавление объекта, без передачи маски, чтобы ИИ автоматически определил местоположение):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "добавить летающую свинью с черными крыльями"
  }'
```

Пример запроса (удаление объекта по маске):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "удалить белое облако"
  }'
```

Структура возвращаемого результата аналогична `/veo/videos`.

## Условия оплаты

- `action=insert` или `remove`: 1.50 кредитов / раз.

## Асинхронный обратный вызов

Интерфейс поддерживает асинхронный режим, передав `callback_url`, вы сможете получить результаты через POST-запрос после завершения задачи. Если нет общедоступного адреса для обратного вызова, вы также можете установить `async` в `true`, интерфейс сразу вернет `task_id`, после чего можно будет опрашивать соответствующий интерфейс для получения результатов.
