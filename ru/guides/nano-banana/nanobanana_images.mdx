В этой статье описывается процесс интеграции и использования Nano Banana Images API. Интерфейс поддерживает две функции: **генерацию изображений (generate)** и **редактирование изображений (edit)**.

## Процесс получения доступа

Чтобы использовать Nano Banana Images API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications) и получите свой API Token для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, произойдёт автоматическое перенаправление на страницу входа с предложением зарегистрироваться и авторизоваться. После завершения процесса вы автоматически вернётесь на текущую страницу.

**Одного API Token достаточно для вызова всех сервисов платформы, отдельная заявка для каждого сервиса не требуется.** При первом оформлении заявки предоставляется бесплатный лимит для ознакомления. Если лимита недостаточно, вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Обзор API

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Способ аутентификации**：передача `authorization: Bearer {token}` в HTTP Header
- **Заголовки запроса**：
  - `accept: application/json`
  - `content-type: application/json`
- **Действие (action)**：
  - `generate`：генерация изображения на основе текстового запроса
  - `edit`：редактирование на основе предоставленного изображения
- **Модель (model)**（необязательно）：
  - `nano-banana`（по умолчанию）：основана на Gemini 2.5 Flash Image, высокая скорость и низкая стоимость
  - `nano-banana-2-lite`：основана на Gemini 3.1 Flash Lite Image, поддерживает только 1K, высокая скорость генерации
  - `nano-banana-2`：основана на Gemini 3.1 Flash Image Preview, качество уровня Pro + скорость Flash
  - `nano-banana-2.1`：новая высокоэффективная модель изображений, поддерживает генерацию и редактирование в разрешениях 1K, 2K и 4K
  - `nano-banana-pro`：основана на Gemini 3 Pro Image Preview, максимальное качество
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：официальные версии соответствующих моделей, обеспечивающие лучшее качество изображения и стабильность; тарификация отличается
- **Асинхронный обратный вызов**：необязательно, уведомления о завершении задачи и результаты можно получать через `callback_url`
- **Количество изображений**：необязательно, с помощью `count` можно указать от 1 до 4 изображений, по умолчанию — 1; каждое изображение создаётся отдельным независимым вызовом генерации; обычная техническая ошибка или отказ поставщика по соображениям безопасности затрагивает только соответствующий вызов, остальные успешно созданные изображения возвращаются как обычно, а оплата рассчитывается по фактическому количеству успешно созданных изображений

## Быстрый старт: генерация изображений (`action=generate`)

**Минимально необходимые параметры**：`action`、`prompt`

Если вы хотите напрямую создать изображение на основе текстового запроса, достаточно установить для `action` значение `generate` и предоставить чёткий `prompt`.

### Пример запроса (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Пример запроса (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Пример успешного ответа

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### Описание полей

- `success`：указывает, успешно ли выполнен текущий запрос.
- `task_id`：ID задачи.
- `trace_id`：ID трассировки запроса, предназначенный для диагностики проблем.
- `count`：количество изображений, запрошенных для генерации или редактирования. Поддерживается от 1 до 4, по умолчанию — 1. В `data` включаются только успешно созданные изображения, а оплата рассчитывается по фактическому количеству возвращённых изображений. Каждый вызов генерации принудительно использует встроенную политику безопасности поставщика; отказ одного вызова не влияет на остальные успешно выполненные вызовы. Если все вызовы будут отклонены, возвращается ошибка 403.
- `data[]`：список результатов.
  - `prompt`：текстовый запрос, использованный для генерации (возвращается в ответе).
  - `image_url`：прямая ссылка URL на сгенерированное изображение.

> Примечание: для генерации изображений через `/nano-banana/images` достаточно указать только `action` и `prompt`.

## Редактирование изображений (`action=edit`)

Если вы хотите отредактировать существующее изображение, установите для `action` значение `edit` и передайте список ссылок на изображения для редактирования (одно или несколько изображений) через `image_urls`, одновременно предоставив `prompt` с описанием цели редактирования.

Например, если мы предоставляем фотографию человека и фотографию одежды и хотим, чтобы человек надел эту одежду, можно одновременно передать ссылки на изображения и указать `action` со значением `edit`. URL может быть HTTP URL — общедоступной ссылкой, доступной по протоколу `https` или `http`, либо изображением в формате Base64, например `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Пример запроса (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "пусть этот мужчина наденет эту футболку",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Пример запроса (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "пусть этот мужчина наденет эту футболку",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Пример успешного ответа

```json
{
  "success": true,
  "task_id": "93f11baf-347b-4bb4-9520-8653cb46d6a3",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",
  "data": [
    {
      "prompt": "пусть этот мужчина наденет эту футболку",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/8e9e0253-26f4-45b9-b3f8-ac1aed1c284b.png"
    }
  ]
}
```

### Описание полей

- `image_urls[]`: список URL изображений для редактирования (должны быть доступны из публичного интернета). Можно передать несколько изображений, и сервис объединит эти материалы с `prompt` для выполнения редактирования.
- Остальные поля аналогичны полям в ответе раздела «Генерация изображений».

## Асинхронный обратный вызов (необязательно, рекомендуется)

Генерация или редактирование могут занять некоторое время. Чтобы избежать длительного удержания соединения и расходования ресурсов, рекомендуется использовать **Webhook-обратный вызов** через `callback_url`:

1. Добавьте `callback_url` в тело запроса, например адрес Webhook вашего сервера (должен быть доступен из публичного интернета и поддерживать POST JSON).
2. API **немедленно вернёт** ответ, содержащий `task_id` (или основные результаты).
3. После завершения задачи платформа отправит полный JSON на `callback_url` методом `POST`. Вы можете использовать `task_id` для сопоставления запроса с результатом.

**Пример полезной нагрузки обратного вызова** (структура полей совпадает с синхронным успешным ответом):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "белая сиамская кошка",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Обработка ошибок

При неудачном вызове возвращается стандартный формат ошибки и идентификатор отслеживания. Распространённые ошибки:

- **400 `token_mismatched`**: недопустимый запрос или ошибка параметров.
- **400 `api_not_implemented`**: интерфейс ещё не реализован (обратитесь в службу поддержки).
- **401 `invalid_token`**: ошибка аутентификации или отсутствует Token.
- **403 `forbidden`**: встроенная политика безопасности поставщика отклонила запрос или результат генерации. Этот вызов не вернёт изображение и не будет тарифицироваться; при запросе нескольких изображений другие успешные вызовы всё равно могут быть выполнены и оплачены.
- **429 `too_many_requests`**: превышена допустимая частота запросов.
- **500 `api_error`**: внутренняя ошибка сервера.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Внутренняя ошибка сервера."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Сопоставление параметров и примечания

- **Обязательные**: `action`, `prompt`
- **Только для редактирования**: `image_urls` (массив, минимум 1 элемент)
- **Необязательные**: `model` (по умолчанию `nano-banana`, доступны `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; для всех моделей, кроме `nano-banana-2.1`, также доступны официальные версии каналов с суффиксом `:official`), `aspect_ratio` (`auto` или конкретное соотношение сторон, например `1:1`, `16:9`), `resolution` (разрешение, например `1K`, `2K`, `4K`; `nano-banana-2-lite` поддерживает только `1K`), `callback_url` (для асинхронного обратного вызова)
- **Headers**: необходимо указать `authorization: Bearer {token}`; для `accept` рекомендуется установить значение `application/json`
- **Доступность изображений**: `image_urls` должны содержать прямые ссылки на изображения, доступные из публичного интернета (HTTP/HTTPS); рекомендуется использовать HTTPS
- **Идемпотентность и отслеживание**: сохраняйте `task_id` и `trace_id` для устранения неполадок и сопоставления результатов

При явной передаче `"aspect_ratio": "auto"` система выберет ближайший предустановленный формат на основе соотношения сторон, ориентации или макета, указанных в подсказке. Это подходит как для генерации, так и для редактирования. Например, если в подсказке указано «миниатюра YouTube», система сможет выбрать формат `16:9`. Если в подсказке не указаны требования к размеру или автоматическое определение недоступно, для генерации изображений по тексту будет использоваться формат по умолчанию, а для редактирования — формат первого референсного изображения с ближайшим поддерживаемым соотношением сторон. Если это поле опущено, будет использоваться формат по умолчанию или соотношение сторон референсного изображения. Если формат изображения уже чётко определён, передавайте конкретное соотношение сторон напрямую.
