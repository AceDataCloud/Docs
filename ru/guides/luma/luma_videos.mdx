С расширением применения ИИ различные программы на базе ИИ постепенно получили широкое распространение. ИИ постепенно проникает во все аспекты работы и жизни людей. Отраслей, связанных с ИИ, также становится всё больше: от первоначального написания текстов до медицины и образования, а теперь и видео.

Luma — это профессиональная платформа генерации высококачественных видео. Пользователям достаточно загрузить материалы, чтобы автоматически генерировать высококачественные видео в соответствии с различными стилями и эффектами. Этот генератор видео на базе ИИ разработан командой участников из известных технологических компаний с целью позволить каждому легко создавать превосходные видео без сложных инструментов редактирования.

Однако официально Luma не предоставляет API, AceDataCloud предоставляет набор API для Luma, имитирующий интеграцию с официальным Suno, что позволяет удобно и быстро генерировать желаемые видео.

## Получение и использование

Чтобы использовать Luma Videos Generation API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно подавать отдельную заявку для каждого сервиса.** При первом получении предоставляется бесплатный лимит, доступен бесплатный тест; при недостаточном лимите можно пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Luma Videos Generation API →](https://platform.acedata.cloud/documents/luma-videos)

## Базовое использование

Чтобы сгенерировать нужное видео, можно ввести любой текст. Например, если я хочу создать видео об астронавтах, перемещающихся между космосом и вулканом, можно ввести `Astronauts shuttle from space to volcano`, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/yub02j.png" width="500" className="m-auto" /></p>

Сгенерированный код выглядит следующим образом:

<p><img src="https://cdn.acedata.cloud/ieq7yn.png" width="500" className="m-auto" /></p>

Основные параметры запроса:

- `prompt`: текст запроса для генерации видео.
- `aspect_ratio`: соотношение сторон видео, по умолчанию 16:9.
- `end_image_url`: необязательно, указывает конечный кадр.
- `enhancement`: необязательно, переключатель улучшения чёткости.
- `loop`: следует ли генерировать зацикленное видео, по умолчанию false.
- `timeout`: необязательно, количество секунд тайм-аута.
- `callback_url`: адрес асинхронного обратного вызова.
- `async`: необязательно, когда установлено значение `true`, интерфейс немедленно возвращает `task_id`, без необходимости указывать `callback_url`, после чего результат получается путём опроса соответствующего интерфейса запроса задач.

Можно нажать кнопку «Try», чтобы напрямую протестировать API, подождать 1–2 минуты, и результат будет следующим:

```json
{
  "success": true,
  "task_id": "e4018a99-1522-4f24-9330-62c2a9b50b59",
  "video_id": "155838f8-7f1e-44d8-b387-192f3b4b509d",
  "prompt": "Astronauts shuttle from space to volcano",
  "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "video_height": 752,
  "video_width": 1360,
  "state": "completed",
  "thumbnail_url": "https://platform.cdn.acedata.cloud/luma/e4018a99-1522-4f24-9330-62c2a9b50b59.jpg",
  "thumbnail_width": 1360,
  "thumbnail_height": 752
}
```

Можно увидеть, что в этот момент мы получили связанную с этим видео информацию, включая ID видео, ссылку на видео, обложку видео и другое содержимое.

Описание полей следующее:

- success: успешно ли выполнено создание, если успешно — `true`, иначе — `false`
- task_id: уникальный ID задачи генерации видео
- video_id: уникальный ID видео, созданного задачей генерации видео
- prompt: ключевые слова задачи генерации видео
- video_url: ссылка на итоговое видео задачи генерации видео
- video_height: высота изображения обложки видео после генерации
- video_width: ширина изображения обложки видео после генерации
- state: статус задачи генерации видео, если задача завершена — `completed`.
- thumbnail_url: ссылка на изображение обложки видео после генерации
- thumbnail_width: ширина изображения обложки видео после генерации
- thumbnail_height: высота изображения обложки видео после генерации

## Генерация с пользовательскими начальным и конечным кадрами

Если вы хотите генерировать видео через пользовательские начальный и конечный кадры видео, можно ввести ссылки на изображения начального и конечного кадров:

В этот момент в поле `start_image_url` первого кадра видео можно передать следующее изображение в качестве первого кадра видео:

![Первый кадр](https://cdn.acedata.cloud/r9vsv9.png)

Далее, чтобы пользовательски сгенерировать видео на основе начального и конечного кадров и ключевых слов, можно указать следующее содержимое:

- action: действие задачи генерации видео, обычно это обычная генерация `generate` и расширенная генерация `extend`, по умолчанию — `generate`.
- start_image_url: указывает первый кадр генерируемого видео.
- end_image_url: указывает конечный кадр генерируемого видео.
- prompt: содержимое ключевых слов для генерации видео.

Пример заполнения:

<p><img src="https://cdn.acedata.cloud/zvzydx.png" width="500" className="m-auto" /></p>

После заполнения автоматически генерируется следующий код:

<p><img src="https://cdn.acedata.cloud/tx80pu.png" width="500" className="m-auto" /></p>

Соответствующий код:

```python
import requests

url = "https://api.acedata.cloud/luma/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "start_image_url": "https://cdn.acedata.cloud/r9vsv9.png",
    "action": "generate",
    "prompt": "Astronauts shuttle from space to volcano"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Функция расширения видео

Если вы хотите продолжить генерацию созданного видео, можно установить параметр `action` в значение `extend` и ввести ID или ссылку на видео, которое нужно продолжить генерировать. Получение ID видео и ссылки на видео выполняется согласно базовому использованию, как показано на рисунке ниже:

<p><img src="https://cdn.acedata.cloud/fwknj4.png" width="500" className="m-auto" /></p>

В этот момент можно увидеть, что ID видео:

```

"video_url": "https://platform.cdn.acedata.cloud/luma/12a18694-fd4b-47e7-9c50-34f30862cff6.mp4"
```

> Обратите внимание, что `video_id` и `video_url` в этом видео — это ID и ссылка на видео после генерации. Если вы не знаете, как генерировать видео, можете обратиться к базовому использованию выше для создания видео.

Для продолжения генерации видео необходимо передать ссылку на видео или ID видео. Ниже демонстрируется расширение с использованием ID видео. Далее необходимо заполнить ключевые слова для пользовательской генерации видео, можно указать следующее содержимое:

- action: поведение расширения видео, здесь должно быть `extend`.
- prompt: ключевые слова видео, которое нужно расширить.
- video_url: ссылка на видео, генерацию которого нужно расширить.
- video_id: уникальный ID видео, генерацию которого нужно расширить.
- end_image_url: ссылка на изображение последнего кадра, которое можно указать при расширенной генерации видео, необязательный параметр.

## Асинхронный обратный вызов

Поскольку время генерации видео Luma относительно длительное и составляет примерно 1–2 минуты, если API долго не отвечает, HTTP-запрос будет постоянно поддерживать соединение, что приведёт к дополнительному потреблению системных ресурсов, поэтому данный API также предоставляет поддержку асинхронных обратных вызовов.
Общий процесс таков: когда клиент инициирует запрос, он дополнительно указывает поле `callback_url`; после того как клиент инициирует API-запрос, API немедленно возвращает результат, содержащий поле `task_id`, которое представляет ID текущей задачи. После завершения задачи результат генерации музыки будет отправлен в виде POST JSON на указанный клиентом `callback_url`, где также будет включено поле `task_id`, благодаря чему результаты задачи можно связать по ID.

Ниже мы на примере рассмотрим, как именно это работает.

Прежде всего, Webhook callback — это сервис, способный принимать HTTP-запросы; разработчик должен заменить его на URL собственного HTTP-сервера. Для удобства демонстрации здесь используется публичный пример Webhook-сайта https://webhook.site/; открыв этот сайт, можно получить Webhook URL, как показано на рисунке:
