---
title: "Генерация Tripo 3D"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Вызовите `POST /tripo/generations`, чтобы создать новую модель, передав текст, одно изображение или несколько видов одного объекта. Используйте токен AceDataCloud; по умолчанию результат возвращается синхронно. При передаче `async: true` или `callback_url` сначала возвращаются HTTP 200 и `task_id`. Уведомление об завершении и синхронный результат имеют одинаковую структуру JSON.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

По умолчанию `action` имеет значение `generate`. Выберите один из трёх вариантов ввода: `prompt` (1–1024 символа), `image_url` или `image_urls`. Изображения должны быть общедоступными PNG/JPEG по HTTPS размером не более 20 MiB. Несколько видов располагаются в порядке: спереди, слева, сзади, справа; необходимо указать вид спереди и как минимум ещё один вид, для пропуска промежуточного вида можно использовать null.

По умолчанию `model` имеет значение `v3.1-20260211`; также можно явно выбрать `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` или `P2-20260801`. По умолчанию `texture` имеет значение `standard`; для чистой геометрии используйте `none`. Разные модели и уровни текстур расходуют разные квоты.

Скачайте GLB по адресу из `data[0].model_url`, `image_url` — необязательный адрес предварительного просмотра. Сохраните `data[0].id` для последующих операций с текстурами, преобразованием или скелетом. При повторной отправке того же запроса сохраняйте тот же `Idempotency-Key` и тело запроса.
