title: "Обработка моделей Tripo"

Используйте `POST /tripo/models` для обработки существующей модели, передав требуемый `action`. Синхронный и асинхронный режимы, обратные вызовы, принадлежность аккаунту и запросы задач работают так же, как при генерации 3D.

| action  | Входные данные | Результат |
| ------- | -------------- | --------- |
| import  | `model_url` — общедоступный HTTPS-файл GLB, GLTF, FBX, OBJ или STL размером не более 150 МиБ | ID модели для последующего использования и GLB; при наличии данных возвращаются `normalize_scale` и `normalize_translation` |
| texture | `model_id` или `model_url`; необязательно один из `prompt`, `image_url` или `image_urls` | Новая модель, текстуры и необязательный предварительный просмотр |
| convert | `model_id` или `model_url`, а также целевой `format` | Файл преобразованной модели |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

Поддерживаются уровни качества текстур `fast`, `standard`, `detailed`, `extreme`. При использовании текстовой подсказки можно добавить `style_image_url`; изображения и референсы с несколькими видами должны соответствовать формату интерфейса генерации. Дополнительные параметры текстур см. в OpenAPI.

Преобразование поддерживает `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` и `3MF`. Поле `format` в возвращённом элементе указывает фактический формат результата; например, при запросе GLTF может быть предоставлен бинарный GLB. Для OBJ материалы и текстуры упаковываются в ZIP. При запросе FBX установите `texture_packaging: "zip"`, чтобы получить отдельные текстуры; упакованный результат помечается как `container: "ZIP"`. Включение нестандартных настроек сетки или текстур может тарифицироваться как расширенное преобразование; подробнее см. цены сервиса.

Используйте `data[0].id` для ссылки на модель своего аккаунта; преобразование нормализации при импорте удовлетворяет формуле `normalized = original × normalize_scale + normalize_translation`. Адрес для скачивания модели находится в `data[0].model_url`.
