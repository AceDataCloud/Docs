`POST https://api.acedata.cloud/wan/tasks` используется для запроса, пакетного запроса или удаления видео задач Wan. Запрос задач не требует повторной оплаты за генерацию.

## Запрос одного задания

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Завершенное задание `response.data.video_url` является постоянным CDN адресом; `response.usage` содержит разрешение, секунды входного/выходного видео, частоту кадров и соотношение; `response.cost` является расчетом за генерацию задания.

## Пакетный запрос

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Возвращает `{ "items": [...], "count": 2 }`. Во время выполнения задания может не быть `finished_at` и окончательного `response`.

## Удаление записи задания

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Удаление влияет только на историю заданий, не удаляя уже сгенерированное видео CDN.
