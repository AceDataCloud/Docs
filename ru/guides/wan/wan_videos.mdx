`POST https://api.acedata.cloud/wan/videos` одновременно поддерживает существующие модели Wan 2.6 и `wan3.0-video`. Wan 3 автоматически распознает текст, первые и последние кадры или референсные материалы на основе `media`.

## Wan 3 文生视频

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "纸船在夜晚的霓虹城市中漂流",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 поддерживает целые числа от 2 до 30 секунд или `-1` для интеллектуальной продолжительности, разрешение `480P`, `720P`, `1080P`.

## 多媒体参考

```json
{
  "model": "wan3.0-video",
  "prompt": "Создайте кинематографический продуктовый релиз",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` поддерживает:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Режимы первых и последних кадров и референсных материалов не могут использоваться совместно. Референсное видео в конечном итоге рассчитывается по реальному времени входного видео плюс время выходного видео; текст, изображения и аудио не увеличивают время видео.

## 官方标准价

| 分辨率   |      价格 |
| ----- | ------: |
| 480P  | $0.05/秒 |
| 720P  | $0.10/秒 |
| 1080P | $0.20/秒 |

## Wan 2.6 兼容

Существующие `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` и их флеш-варианты продолжают использовать параметры `action`, `image_url`, `reference_video_urls` и т.д., путь вызова остается прежним.

## 异步与结果

Установив `async: true`, вы сразу получите `task_id`, а затем через `/wan/tasks` получите конечное состояние. Успешное видео будет сохранено в AceDataCloud CDN, и в ответе будут возвращены реальные использование и стоимость.
