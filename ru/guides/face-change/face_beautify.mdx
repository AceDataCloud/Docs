В данной статье будет представлена инструкция по интеграции API для улучшения лица, который позволяет пользователю загрузить изображение лица (максимум можно обработать информацию о пяти лицах на одном изображении), точно определить черты лица и реализовать функции улучшения кожи, осветления и удаления прыщей.

## Процесс подачи заявки

Чтобы использовать API, необходимо сначала перейти на соответствующую страницу [API для улучшения лица](https://platform.acedata.cloud/documents/face-beautify) и подать заявку на соответствующую услугу. После перехода на страницу нажмите кнопку «Acquire», как показано на изображении:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа, где будет предложено зарегистрироваться и войти. После входа или регистрации вы автоматически вернетесь на текущую страницу.

При первой подаче заявки будет предоставлен бесплатный лимит, который можно использовать для бесплатного доступа к этому API.

## Основное использование

Сначала ознакомьтесь с основным способом использования, который заключается в вводе ссылки на изображение и информации о улучшении лица, чтобы получить обработанное изображение. Сначала необходимо передать поле `image_url`, изображение лица показано на следующем изображении:

<p><img src="https://cdn.acedata.cloud/ohgrs3.png" width="500" className="m-auto" /></p>

Затем нам нужно загрузить параметры информации о улучшении лица, подробности смотрите в информации о теле запроса ниже. Далее мы можем заполнить соответствующие поля на интерфейсе, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/gjzkwv.png" width="500" className="m-auto" /></p>

Как видно, здесь мы установили заголовки запроса, включая:

- `accept`: формат ответа, который вы хотите получить, здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после подачи заявки его можно выбрать из выпадающего списка.

Также установлено тело запроса, включая:

- `image_url`: ссылка на изображение лица, которое нужно обработать.
- `smoothing`: степень сглаживания, диапазон значений [0,100]. 0 - без сглаживания, 100 - максимальная степень. Значение по умолчанию 10.
- `whitening`: степень осветления, диапазон значений [0,100]. 0 - без осветления, 100 - максимальная степень. Значение по умолчанию 30.
- `face_lifting`: степень уменьшения лица, диапазон значений [0,100]. 0 - без уменьшения, 100 - максимальная степень. Значение по умолчанию 70.
- `eye_enlarging`: степень увеличения глаз, диапазон значений [0,100]. 0 - без увеличения, 100 - максимальная степень. Значение по умолчанию 70.

После выбора можно увидеть, что справа также сгенерирован соответствующий код, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/nhq282.png" width="500" className="m-auto" /></p>

Нажмите кнопку «Try», чтобы провести тестирование, как показано на изображении, и мы получим следующий результат:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/fmu/BeautifyPic/1256437459/1a68c13b-b03c-4c7b-92a1-e4a9b5f1d7ec"
}
```

Как видно, в возвращенном результате есть поле `image_url`, которое содержит изображение лица после изменений, основанных на введенной информации о улучшении. Измененное изображение лица показано ниже:

<p><img src="https://cdn.acedata.cloud/g809b1.png" width="500" className="m-auto" /></p>

Как видно, лицо на изображении изменилось в соответствии с введенной информацией о улучшении.

Кроме того, если вы хотите сгенерировать соответствующий код интеграции, вы можете просто скопировать его, например, код CURL выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/face/beautify' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
  "smoothing": 50,
  "whitening": 50,
  "face_lifting": 50,
  "eye_enlarging": 50
}'
```

Код интеграции на Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/face/beautify"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "image_url": "https://cdn.acedata.cloud/lrbtcn.jpg",
    "smoothing": 50,
    "whitening": 50,
    "face_lifting": 50,
    "eye_enlarging": 50
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обработка ошибок

При вызове API, если возникнет ошибка, API вернет соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`: Неверный запрос, возможно, из-за отсутствия или недействительных параметров.
- `400 api_not_implemented`: Неверный запрос, возможно, из-за отсутствия или недействительных параметров.
- `401 invalid_token`: Неавторизовано, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`: Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`: Внутренняя ошибка сервера, что-то пошло не так на сервере.

### Пример ответа об ошибке

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
