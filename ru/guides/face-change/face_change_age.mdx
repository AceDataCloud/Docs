В этой статье будет представлена инструкция по интеграции API изменения возраста лица, который позволяет изменять возраст лиц на изображениях, вводя фото и возраст. Основной принцип работы заключается в том, что пользователь загружает изображение лица, и на основе алгоритмов редактирования и генерации лиц выводится изображение с измененным возрастом, поддерживающее изменение возраста лица.

## Процесс подачи заявки

Чтобы использовать API, необходимо сначала перейти на соответствующую страницу [API изменения возраста лица](https://platform.acedata.cloud/documents/face-change-age) и подать заявку на соответствующую услугу. После перехода на страницу нажмите кнопку «Acquire», как показано на изображении:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа, где вы сможете зарегистрироваться и войти. После регистрации и входа вы автоматически вернетесь на текущую страницу.

При первой подаче заявки предоставляется бесплатный лимит, который позволяет бесплатно использовать этот API.

## Основное использование

Сначала ознакомьтесь с основным способом использования, который заключается в вводе ссылки на изображение и информации о возрасте, чтобы получить обработанное изображение. Сначала необходимо передать поле `image_url`, изображение лица показано на следующем изображении:

<p><img src="https://cdn.acedata.cloud/f5687u.png" width="500" className="m-auto" /></p>

Затем нам нужно загрузить параметры информации о возрасте лица `age_infos`, который является массивом, и мы можем передать несколько значений. Далее мы можем заполнить соответствующие поля на интерфейсе, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/cn95e8.png" width="500" className="m-auto" /></p>

Как видно, здесь мы установили заголовки запроса, включая:

- `accept`: формат ответа, который вы хотите получить, здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

Также установлен тело запроса, включая:

- `image_url`: ссылка на изображение лица, которое нужно обработать.
- `age_infos`: информация о возрасте лица и области, где возраст является обязательным параметром.

После выбора можно заметить, что справа также сгенерирован соответствующий код, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/zk8qkl.png" width="500" className="m-auto" /></p>

Нажмите кнопку «Try», чтобы провести тестирование, как показано на изображении, и мы получим следующий результат:

```json
{
  "image_url": "https://faceeffect-1254418846.cos.ap-guangzhou.myqcloud.com/ft/ChangeAgePic/1256437459/bfce1ab8-5fd7-464d-8878-b38433f84d0e"
}
```

Как видно, в возвращенном результате есть поле `image_url`, которое содержит изображение лица с измененным возрастом. Измененное изображение лица показано ниже:

<p><img src="https://cdn.acedata.cloud/01rmiv.png" width="500" className="m-auto" /></p>

Как видно, лицо на изображении изменилось в соответствии с введенным возрастом.

Кроме того, если вы хотите сгенерировать соответствующий код интеграции, вы можете просто скопировать его, например, код CURL выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/face/change-age' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "age_infos": [{"age":60}],
  "image_url": "https://cdn.acedata.cloud/f5687u.png"
}'
```

Код интеграции на Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/face/change-age"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "age_infos": [{"age":60}],
    "image_url": "https://cdn.acedata.cloud/f5687u.png"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обработка ошибок

При вызове API, если возникнет ошибка, API вернет соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`: Неверный запрос, возможно, из-за отсутствия или недействительных параметров.
- `400 api_not_implemented`: Неверный запрос, возможно, из-за отсутствия или недействительных параметров.
- `401 invalid_token`: Неавторизовано, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`: Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`: Внутренняя ошибка сервера, что-то пошло не так на сервере.

### Пример ответа об ошибке

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
