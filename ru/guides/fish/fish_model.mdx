Этот интерфейс основан на [официальном Model API Fish Audio](https://docs.fish.audio/resources/api-reference/model) и используется для **создания клонированной голосовой модели, которую можно многократно использовать в течение длительного времени, на основе аудиообразца**. Адрес: `POST https://api.acedata.cloud/fish/model`.

> Если вам нужно лишь временно использовать эталонный голос, создавать модель не нужно: можно напрямую использовать одноразовое мгновенное клонирование `references` в [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts). Для постраничного поиска существующих голосов смотрите [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query); для запроса сведений об одном голосе по `_id` смотрите [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процесс получения

Чтобы использовать Fish Model API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости получать отдельный для каждого сервиса.** При первом получении предоставляется бесплатный лимит, позволяющий бесплатно ознакомиться с сервисом; при недостаточном лимите можно пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Поля тела запроса

| Поле                      | Тип       | Обязательно  | Описание                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | Да   | Название голоса, используемое для идентификации в списке консоли.                                                             |
| `voices`                | string   | Да   | HTTP(S) URL аудиообразца (**одна строка**, не массив). Этот интерфейс не поддерживает multipart/бинарную загрузку, сначала разместите аудио в любом общедоступном объектном хранилище. |
| `description`           | string   | Нет   | Описание голоса.                                                                         |
| `cover_image`           | string   | Нет   | HTTP(S) URL обложки.                                                              |
| `tags`                  | string[] | Нет   | Теги для поиска в публичной библиотеке, например `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | Нет   | Эталонные тексты, соответствующие образцам (используются для корректировки произношения).                                                           |
| `enhance_audio_quality` | boolean  | Нет   | Выполнять ли улучшение качества звука образца перед обучением.                                                                |
| `generate_sample`       | boolean  | Нет   | Генерировать ли автоматически пример аудио после завершения обучения.                                                            |

> Дополнительную информацию о голосовой модели можно найти в [официальной документации Fish](https://docs.fish.audio/resources/api-reference/model).

> Созданные голоса будут храниться публично в течение длительного времени, и другие пользователи могут искать и использовать их. Не нужно передавать `visibility`; даже если передать `private` или `unlist`, текущий интерфейс не изменит на их основании область публичного доступа.

## Пример: создание публичного клонированного голоса

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> Примечание: `voices` должен быть **строкой** (одним URL аудиофайла), а не массивом. Передача `["..."]` не поддерживается. Рекомендуется использовать прямую ссылку, доступную для публичного скачивания, с суффиксом `.mp3` или `.wav`.

При успешном ответе напрямую возвращается объект ModelEntity платформы Fish (в примере ниже — минимальный рабочий голос, протестированный нами; некоторые длинные поля удалены для удобства чтения):

`_id` можно использовать в качестве значения поля `reference_id` в последующих вызовах [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts) для синтеза речи с использованием этого клонированного голоса:

Успешно созданный голос сохраняется публично. Через `self=true` API [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query) можно запросить голоса, созданные текущим пользователем на этой платформе. `self=true` только фильтрует список и не ограничивает использование этого голоса другими пользователями.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## Требования к образцу

Рекомендации (подробнее см. в [официальной документации Fish](https://docs.fish.audio/resources/api-reference/model)):

- Рекомендуемая длительность — более 30 секунд; наилучший результат достигается при длительности до 5 минут. После 10 минут прирост качества незначителен.
- Частота дискретизации — 16 кГц или выше; допускается моно или стерео.
- Содержимое должно быть максимально чистым: без фоновой музыки, эха и заметного окружающего шума; один и тот же говорящий.
- Рекомендуемые форматы: `mp3` / `wav`.

Если вы не уверены в качестве образца, можно одновременно передать `enhance_audio_quality: true`, чтобы включить улучшение качества звука.

## Описание тарификации
Создание модели клонирования голоса (`POST /fish/model`) бесплатно и не взимает никаких сборов; интерфейсы запросов голосов ([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query)、[Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) также не тарифицируются. Расходы возникают только при последующем вызове [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтеза речи в соответствии с использованием.

## Обработка ошибок

- `400 token_mismatched`: параметры запроса отсутствуют или недопустимы (чаще всего `voices` не является URL или передаётся как массив).
- `400`: если эталонное аудио не удаётся скачать, его длительность слишком мала или формат не распознаётся, проверьте URL аудио и формат файла.
- `401 invalid_token`: токен аутентификации отсутствует или недействителен.
- `429 too_many_requests`: сработало ограничение скорости для аккаунта.
- `500 api_error`: внутренняя ошибка сервера.

Пример ответа с ошибкой:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Вывод

Для вызова этого интерфейса нужно лишь подготовить URL общедоступного образца аудио, поместить его в поле `voices`, чтобы получить `_id`, а затем передать его в `reference_id` для `/fish/tts`, и будет завершён сквозной процесс «клонирование → синтез». Распространённая ошибка заключается в том, что `voices` должен быть строкой, а не массивом.

## Создание и повторное использование голоса через MCP

В Fish MCP вызовите
`fish_create_model(title="Мой голос", voices="https://example.com/authorized-voice.wav")`。
`voices` — это один HTTP(S) URL аудио; также можно передать `description`、`cover_image`、`tags`、
`texts`、`enhance_audio_quality`、`generate_sample`。

Этот инструмент будет длительно хранить публичные голоса, и другие пользователи могут обнаружить и использовать их; используйте только аудиоматериалы, на обработку и публикацию которых получено разрешение. У инструмента нет приватного или непубличного варианта. Возвращаемый при успешном создании `_id` используется для
`reference_id` в `fish_generate_audio`, а `fish_list_models(self=true)` позволяет запросить собственные
сохранённые голоса. Если эталонный голос нужен только один раз, используйте `references` в `fish_generate_audio`,
без необходимости создавать долгосрочный голос.
