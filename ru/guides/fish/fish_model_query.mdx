Этот интерфейс основан на [Fish Audio официальном Model API](https://docs.fish.audio/resources/api-reference/model) и предназначен для **постраничного поиска в публичной библиотеке звуковых моделей Fish или клонированных звуковых моделей текущего аккаунта**. Адрес: `GET https://api.acedata.cloud/fish/model`.

> Для создания звуковой модели смотрите [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); для запроса деталей одной звуковой модели по `_id` смотрите [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Процесс запроса

Чтобы использовать Fish Model API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет использовать все сервисы платформы, не нужно запрашивать отдельный токен для каждого сервиса.** При первом запросе предоставляется бесплатный лимит, чтобы вы могли попробовать; если лимит исчерпан, вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметры запроса

| Параметр          | Тип      | По умолчанию | Описание                                   |
| ----------------- | ------- | ------------ | ------------------------------------------ |
| `page_size`       | integer | 10           | Количество элементов на странице.         |
| `page_number`     | integer | 1            | Номер страницы, начиная с 1.              |
| `title`           | string  | —            | Поиск по заголовку с нечетким совпадением. |
| `tag`             | string  | —            | Фильтрация по одному тегу.                |
| `self`            | boolean | —            | Если `true`, возвращает только звуковые модели, созданные текущим аккаунтом, без дополнительных условий. |
| `author_id`       | string  | —            | Фильтрация по `_id` пользователя.         |
| `language`        | string  | —            | Фильтрация по языку звуковой модели, например, `en`, `zh`, `es`. |
| `title_language`  | string  | —            | Фильтрация по языку заголовка.            |
| `sort_by`         | string  | —            | Поле сортировки, совпадающее с upstream, например, `created_at`, `task_count`. |

> Имена параметров полностью совпадают с upstream `GET https://api.fish.audio/model`, подробности смотрите в [официальной документации Fish](https://docs.fish.audio/resources/api-reference/model).

## Пример 2: Поиск по заголовку с нечетким совпадением (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Ответ (на практике):

```json

  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",

      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",

    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
```

Обратите внимание, что `title` является «глобальным нечетким совпадением», которое будет совпадать со всеми звуковыми моделями в публичной библиотеке Fish (не только с вашими).

## Пример 3: Только свои созданные звуковые модели (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Ответ (на практике, в текущем аккаунте только 1 звуковая модель):


## Пример 4: Фильтрация по языку + тегам
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Вверх по потоку также будет возвращать результаты для `tag`, не находящихся в словаре тегов, но соответствие будет относительно широким; если количество совпадений равно 0, рекомендуется использовать нечеткое соответствие по `title`.

## Поля ответа

Каждый элемент в `items[]` является полным объектом ModelEntity, часто используемые поля:

| Поле           | Тип       | Описание                                             |
| -------------- | -------- | -------------------------------------------------- |
| `_id`          | string   | ID голоса, используется как значение `reference_id` в `/fish/tts`. |
| `type`         | string   | Тип модели, обычно `tts`.                          |
| `title`        | string   | Название голоса.                                   |
| `description`  | string   | Описание голоса.                                   |
| `state`        | string   | Состояние обучения: `trained` означает доступно.   |
| `tags`         | string[] | Теги публичной библиотеки.                         |
| `languages`    | string[] | Языки, в которых голос преуспевает.               |
| `visibility`   | string   | `public` или `private`.                           |
| `samples`      | object[] | Предустановленные образцы (включая прямые ссылки на `audio`). |
| `like_count`   | integer  | Количество лайков в публичной библиотеке.         |
| `task_count`   | integer  | Историческое количество синтезов.                 |
| `author`       | object   | Информация об авторе вверх по потоку: `_id` / `nickname` / `avatar`. |
| `total` (верхний уровень) | integer  | Общее количество, соответствующее условиям.       |
| `has_more`     | boolean? | Указатель на пагинацию вверх по потоку, может быть `null`. Рекомендуется использовать `total / page_size` для расчета общего количества страниц. |

## Условия оплаты

Этот интерфейс не облагается платой — пагинация запроса списка голосов является бесплатной операцией. Создание голоса ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) также бесплатно, плата взимается только при вызове [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтеза речи по мере использования.

## Обработка ошибок

- `400 token_mismatched`: отсутствуют или недействительны параметры запроса.
- `401 invalid_token`: токен авторизации отсутствует или недействителен.
- `429 too_many_requests`: превышен лимит скорости аккаунта.
- `500 api_error`: внутренняя ошибка сервера.

Пример ответа об ошибке:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Заключение

Чтобы выбрать голос из публичной библиотеки Fish для передачи в `reference_id` `/fish/tts`, сначала используйте этот интерфейс в сочетании с `title` / `tag` / `language` для поиска, чтобы определить целевой `_id`, затем используйте [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) для получения образцов для прослушивания. Чтобы перечислить созданные вами голоса, передайте `self=true`.
