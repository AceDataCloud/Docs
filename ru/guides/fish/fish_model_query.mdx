Данный интерфейс основан на [официальном Model API Fish Audio](https://docs.fish.audio/resources/api-reference/model) и предназначен для **постраничного поиска в публичной библиотеке голосов Fish или среди клонированных голосов текущего аккаунта**. Адрес: `GET https://api.acedata.cloud/fish/model`.

> Для создания голоса обратитесь к [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); для запроса сведений об одном голосе по `_id` обратитесь к [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)。

## Процесс получения

Чтобы использовать Fish Model API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти; после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, и не требуется подавать отдельную заявку для каждого сервиса.** При первом получении предоставляется бесплатная квота для бесплатного ознакомления; при недостатке квоты вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметры запроса

| Параметр             | Тип    | По умолчанию | Описание                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | Количество элементов на странице.                                                                            |
| `page_number`    | integer | 1    | Номер страницы, начиная с 1.                                                                          |
| `title`          | string  | —    | Нечёткий поиск по заголовку.                                                                      |
| `tag`            | string  | —    | Фильтрация по одному тегу.                                                                      |
| `self`           | boolean | —    | При `true` возвращаются только голоса, созданные и сохранённые через эту платформу текущей учётной записью, выполняющей вызов.                                |
| `author_id`      | string  | —    | Фильтрация по идентификатору автора голоса.                                                                  |
| `language`       | string  | —    | Фильтрация по языку голоса, например `en`, `zh`, `es`.                                                  |
| `title_language` | string  | —    | Фильтрация по языку заголовка в публичной библиотеке голосов.                                                        |
| `sort_by`        | string  | —    | Поле сортировки; при `self=true` поддерживаются `created_at` и `task_count`.                              |

## Пример 2: нечёткий поиск по названию (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Ответ (проверено на практике):


Обратите внимание, что `title` — это «глобальное нечёткое сопоставление», которое одновременно находит все голоса в публичной библиотеке Fish (не только собственные).

## Пример 3: вывести только голоса, созданные вами (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Пример ответа:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
`self=true` выводит голоса, созданные и сохранённые через эту платформу для фактически вызывающего аккаунта; голоса, созданные одним и тем же аккаунтом с использованием разных API Token, также будут перечислены вместе. Результаты постранично сортируются по времени создания в обратном порядке, `author_id` может дополнительно фильтровать ID автора этих голосов. Этот параметр фильтрует только список, голоса по-прежнему доступны публично.

`self=true` не поддерживает `title_language`; если требуется поиск по языку названия, выполните запрос к публичной библиотеке голосов.

## Пример 4: фильтрация по языку + тегу

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> `tag` соответствует менее строго; если количество совпадений равно 0, рекомендуется использовать нечёткое сопоставление `title`.

## Поля ответа

Каждый элемент в `items[]` является полным объектом ModelEntity, часто используемые поля:

| Поле            | Тип       | Описание                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | ID голоса, используемый как значение `reference_id` в `/fish/tts`. |
| `type`        | string   | Тип модели, обычно `tts`.                           |
| `title`       | string   | Название голоса.                                     |
| `description` | string   | Описание голоса.                                     |
| `state`       | string   | Статус обучения: `trained` означает, что голос доступен.                      |
| `tags`        | string[] | Теги публичной библиотеки.                                    |
| `languages`   | string[] | Языки, в которых голос наиболее хорош.                                  |
| `visibility`  | string   | `public` или `private`.                     |
| `samples`     | object[] | Предустановленные образцы (включая прямую ссылку `audio`).                       |
| `like_count`  | integer  | Количество лайков в публичной библиотеке.                                   |
| `task_count`  | integer  | Количество исторических синтезов.                                   |
| `author`      | object   | Информация об авторе голоса: `_id` / `nickname` / `avatar`.     |
| `total`（верхний уровень）   | integer  | Общее количество записей, соответствующих условиям.                                 |
| `has_more`    | boolean? | При `self=true` является булевым значением; запросы к публичной библиотеке голосов могут возвращать `null`.      |

## Описание тарификации

Этот интерфейс не тарифицируется — постраничный запрос списка голосов является бесплатной операцией. Создание голосов ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) также бесплатно, расходы возникают только при вызове [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтеза речи в зависимости от использования.

## Обработка ошибок

- `400 token_mismatched`: параметры запроса отсутствуют или недопустимы.
- `401 invalid_token`: токен авторизации не существует или недействителен.
- `429 too_many_requests`: сработало ограничение скорости для аккаунта.
- `500 api_error`: внутренняя ошибка сервера.

Пример ответа с ошибкой:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Заключение

Чтобы выбрать голос из публичной библиотеки Fish и передать его в `reference_id` для `/fish/tts`, сначала используйте этот интерфейс вместе с `title` / `tag` / `language` для поиска, найдите целевой `_id`, затем используйте [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get), чтобы получить образцы для прослушивания. Чтобы вывести созданные вами голоса, достаточно передать `self=true`.
