Этот интерфейс основан на [Fish Audio официальном Model API](https://docs.fish.audio/resources/api-reference/model) и предназначен для **поиска полного описания одного клона звука по `_id`**. Адрес: `GET https://api.acedata.cloud/fish/model/{id}`.

> Для создания звука, пожалуйста, обратитесь к [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); для постраничного поиска смотрите [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Процесс подачи заявки

Чтобы использовать Fish Model API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) для резервного копирования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вас пригласят зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет использовать все услуги платформы, не нужно запрашивать отдельный токен для каждой услуги.** При первом запросе предоставляется бесплатный лимит, чтобы вы могли попробовать; если лимит исчерпан, вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Параметры пути

| Параметр | Обязательный | Описание                                                                                                                                                                                                |
| ---- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id` | Да   | `_id` звука (32-значная шестнадцатеричная строка). Его можно получить при создании через [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) или через [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Нет тела запроса, нет параметров запроса.

## Пример: Получение полного описания публичного испанского звука

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

Полученный `_id` можно использовать в качестве `reference_id` для [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтеза речи с тем же звуком:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Различия с интерфейсом списка

| Поле                                                 | `GET /fish/model` (список) | `GET /fish/model/{id}` (детали) |
| -------------------------------------------------- | --------------------- | -------------------------- |
| `samples[].audio`                                  | Краткосрочный R2 кэш URL          | Прямые ссылки R2 с подписью (включая query подпись)      |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Также присутствуют                  | Также присутствуют                       |
| `default_text` / `lock_visibility`                 | Также присутствуют                  | Также присутствуют                       |

Если вам просто нужно прослушать, то `samples[].audio` из интерфейса списка уже достаточно; для более стабильных ссылок на загрузку рекомендуется использовать этот интерфейс.

## Поля ответа (выборочно)

| Поле            | Тип       | Описание                                          |
| ------------- | -------- | ------------------------------------------- |
| `_id`         | string   | ID звука (используется в `reference_id` для `/fish/tts`).     |
| `type`        | string   | Тип модели, обычно `tts`.                             |
| `title`       | string   | Название звука.                                       |
| `description` | string   | Длинное описание.                                        |
| `state`       | string   | Статус обучения: `trained` означает доступно, `training` означает, что еще в процессе обучения.      |
| `tags`        | string[] | Теги публичной библиотеки.                                      |
| `samples`     | object[] | Предустановленные образцы, содержащие `title`, `text`, `task_id`, `audio` прямые ссылки. |
| `languages`   | string[] | Код языков, в которых звук преуспевает.                                  |
| `visibility`  | string   | `public` или `private`.                       |
| `like_count`  | integer  | Количество лайков в публичной библиотеке.                                     |
| `task_count`  | integer  | Количество историй синтеза (можно использовать для сортировки по популярности).                          |
| `author`      | object   | Информация о авторе: `_id` / `nickname` / `avatar`.       |
| `created_at`  | string   | Время создания в формате ISO 8601.                              |
| `updated_at`  | string   | Время последнего обновления в формате ISO 8601.                            |

## Условия оплаты

Этот интерфейс не подлежит оплате — запрос деталей одного звука по ID является бесплатной операцией. Создание звука ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) также бесплатно, плата взимается только при вызове [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) для синтеза речи в зависимости от использования.

## Обработка ошибок
- `400 token_mismatched`：Путь содержит `id`, который не является допустимым форматом, или upstream сообщает «Модель не найдена».
- `401 invalid_token`：Токен аутентификации отсутствует или недействителен.
- `404 not_found`：Указанный `_id` не виден на Fish upstream (тональность была удалена, является приватной или принадлежит другой учетной записи).
- `429 too_many_requests`：Сработало ограничение скорости учетной записи.
- `500 api_error`：Внутренняя ошибка сервера.

При фактическом запросе несуществующего ID upstream сразу возвращает `400 Model not found` (проверено):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Возвращает:

```json
{ "status": 400, "message": "Model not found" }
```

Пример ошибки ответа:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Заключение

Зная тональность `_id`, можно напрямую использовать этот интерфейс для получения полного ModelEntity, наиболее распространенные способы использования: (1) прослушивание `samples[].audio`, (2) передача `_id` в `reference_id` `/fish/tts` для завершения синтеза. Если есть только заголовок или метка, сначала используйте [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) для поиска.
