Claude Messages Count Tokens API позволяет вычислить количество входных Token для одного Message без фактического создания сообщения, включая подсчёт Token для таких материалов, как инструменты, изображения и документы. Это очень полезно, когда необходимо предварительно оценить стоимость или проверить, не превышает ли ввод ограничение контекста модели.

Этот документ главным образом описывает процесс использования Claude Messages Count Tokens API.

## Процесс подачи заявки

Чтобы использовать Claude Messages Count Tokens API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти в систему; после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, без необходимости отдельно подавать заявку для каждого сервиса.** При первом получении предоставляется бесплатный лимит, позволяющий бесплатно опробовать сервис; при недостатке лимита вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Базовое использование

Путь запроса Claude Messages Count Tokens API — `/v1/messages/count_tokens`, он соответствует официальному API Anthropic. Необходимо предоставить как минимум два обязательных параметра:

- `model`: выберите используемую модель Claude; `claude-opus-5-5` можно использовать для Messages Token Count, как и новейший флагман `claude-fable-5-1`; исходный `claude-fable-5` по-прежнему сохранён для обратной совместимости. `claude-sonnet-5-5` добавлен в нативные интерфейсы серии Messages, поддерживает ввод изображений и адаптивное мышление; его официальные справочные цены за миллион Token для ввода, вывода и чтения кэша составляют 2, 10 и 0,20 доллара США соответственно.
- `messages`: массив входных сообщений, где каждое сообщение содержит `role` (роль) и `content` (содержимое).

Часто используемые необязательные параметры:

- `system`: системный промпт, учитывается в количестве Token.
- `tools`: определения инструментов, учитываются в количестве Token.
- `thinking`: конфигурация расширенного мышления.
- `tool_choice`: конфигурация выбора инструмента.
- `cache_control`: конфигурация управления кэшем верхнего уровня или уровня блока содержимого.

`messages`, `system`, воспроизведение вызовов инструментов, URL-изображения и блоки содержимого document/PDF используют такую же стабильную структуру запросов, как и Messages API.

### Пример cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Пример Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Пример возвращаемого результата:

```json
{
  "input_tokens": 11
}
```

### Использование Anthropic SDK

Claude Messages Count Tokens API принимает стабильную структуру запросов Anthropic SDK и может вызываться через библиотеку `anthropic`. Интерфейс использует нативную возможность Count Tokens, соответствующую выбранной модели, для подсчёта ввода и может применяться для проверки размера ввода перед отправкой запроса Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Подсчёт Token с инструментами

Если ваш запрос содержит определения инструментов, эти инструменты также будут учитываться в количестве Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Подсчёт Token с системным промптом

Системный промпт также будет учитываться в количестве Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Примечания

- Этот API вычисляет только количество входных Token и не создаёт никакого вывода модели.
- Результат подсчёта Token может использоваться для предварительной оценки размера ввода и проверки окна контекста; окончательная тарификация определяется `usage` в фактическом ответе Messages.
- Изображения, PDF, определения инструментов, системные промпты и конфигурация thinking будут учитываться в результате согласно правилам ввода выбранной модели.
- Этот API полностью бесплатен и не расходует никакой лимит.
