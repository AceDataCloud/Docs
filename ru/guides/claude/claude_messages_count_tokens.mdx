Claude Messages Count Tokens API позволяет подсчитать количество входных Token в одном Message, включая подсчёт Token для таких материалов, как инструменты, изображения и документы, без фактического создания сообщения. Это очень полезно, когда необходимо оценить стоимость или проверить, не превышает ли ввод ограничение контекста модели.

В этом документе в основном описывается процесс использования Claude Messages Count Tokens API.

## Процесс подачи заявки

Чтобы использовать Claude Messages Count Tokens API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти, после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости подавать отдельную заявку для каждого сервиса.** При первой заявке предоставляется бесплатный лимит, позволяющий бесплатно опробовать сервис; при недостаточном лимите можно пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Базовое использование

Путь запроса Claude Messages Count Tokens API — `/v1/messages/count_tokens`, он соответствует официальному API Anthropic. Необходимо указать как минимум два обязательных параметра:

- `model`: укажите полный ID модели из списка моделей этого интерфейса и используйте ту же модель в последующих запросах Messages.
- `messages`: массив входных сообщений, каждое сообщение содержит `role` (роль) и `content` (содержимое).

Распространённые необязательные параметры:

- `system`: системный промпт, учитывается в количестве Token.
- `tools`: определения инструментов, учитываются в количестве Token.
- `thinking`: конфигурация расширенного мышления.
- `tool_choice`: конфигурация выбора инструмента.
- `cache_control`: конфигурация управления кэшем верхнего уровня или уровня блоков содержимого.

`messages`, `system`, воспроизведение вызовов инструментов, URL-изображения и блоки содержимого document/PDF используют ту же стабильную структуру запросов, что и Messages API.

### Пример cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Пример Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Пример возвращаемого результата:

```json
{
  "input_tokens": 11
}
```

### Использование Anthropic SDK

Claude Messages Count Tokens API принимает стабильную структуру запросов Anthropic SDK и может вызываться через библиотеку `anthropic`. Интерфейс подсчитывает входные Token в соответствии с выбранной моделью и может использоваться для проверки размера ввода перед отправкой запроса Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Подсчёт Token с инструментами

Если ваш запрос содержит определения инструментов, эти инструменты также будут учитываться в количестве Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Подсчёт Token с системным промптом

Системный промпт также будет учитываться в количестве Token:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Примечания

- Этот API рассчитывает только количество входных Token и не создаёт никакого вывода модели.
- Результат подсчёта Token может использоваться для оценки размера ввода и проверки контекстного окна; окончательная тарификация основывается на `usage` в фактическом ответе Messages.
- Изображения, PDF, определения инструментов, системные промпты и конфигурация thinking будут учитываться в результате согласно правилам ввода выбранной модели.
- Этот API полностью бесплатен и не расходует никакой лимит.
