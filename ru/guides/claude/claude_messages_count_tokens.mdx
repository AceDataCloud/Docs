Claude Messages Count Tokens API может вычислить количество входных токенов для сообщения, не создавая его фактически, включая токены для инструментов, изображений и документов. Это очень полезно, когда необходимо оценить стоимость или проверить, превышает ли ввод модельные ограничения контекста.

В этом документе в основном описывается процесс использования Claude Messages Count Tokens API.

## 申请流程

Чтобы использовать Claude Messages Count Tokens API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы получить ваш API Token для резервного копирования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вас пригласят зарегистрироваться и войти в систему, после чего вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно запрашивать отдельный токен для каждого сервиса.** При первом запросе предоставляется бесплатный лимит для тестирования; при недостаточном лимите вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## 基本使用

Запрос к Claude Messages Count Tokens API осуществляется по пути `/v1/messages/count_tokens`, что соответствует официальному API Anthropic. Мы должны предоставить как минимум два обязательных параметра:

- `model`: выберите используемую модель Claude, например, последнюю флагманскую `claude-fable-5-1`; оригинальная `claude-fable-5` по-прежнему совместима.
- `messages`: массив входящих сообщений, каждое сообщение содержит `role` (роль) и `content` (содержимое).

Распространенные необязательные параметры:

- `system`: системное сообщение, которое будет учитываться в количестве токенов.
- `tools`: определение инструментов, которое будет учитываться в количестве токенов.
- `thinking`: расширенная конфигурация мышления.
- `tool_choice`: конфигурация выбора инструмента.
- `cache_control`: конфигурация управления кэшированием на верхнем уровне или уровне блока содержимого.

`messages`, `system`, воспроизведение вызовов инструментов, URL-изображения и блоки содержимого document/PDF используют ту же стабильную структуру запроса, что и Messages API.

### cURL 示例

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python 示例

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

返回结果示例：

```json
{
  "input_tokens": 11
}
```

### 使用 Anthropic SDK

Claude Messages Count Tokens API принимает стабильную структуру запросов Anthropic SDK и может быть вызван через библиотеку `anthropic`. Текущие возвращаемые значения рассчитываются локальным оценщиком Ace Data Cloud и не являются точными результатами официального токенизатора Anthropic; фактическое количество токенов для мультимодальных, инструментальных и различных моделей Claude может отличаться.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## 包含工具的 Token 计数

Если ваш запрос включает определение инструментов, эти инструменты также будут учитываться в количестве токенов:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## 包含系统提示词的 Token 计数

Системные подсказки также будут учитываться в количестве токенов:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## 注意事项

- Этот API только вычисляет количество входных токенов и не генерирует никакого вывода модели.
- Результаты подсчета токенов могут использоваться для грубой оценки объема ввода и не должны использоваться в качестве точной основы для выставления счетов, контроля доступа к окну контекста или сравнения токенизаторов модели.
- Текущий оценщик не будет точно вычислять визуальные/документальные токены для изображений и PDF и не может отразить различия официальных токенизаторов различных моделей Claude.
- Этот API полностью бесплатен и не расходует никаких лимитов.
