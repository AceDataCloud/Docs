Qwen Code использует `~/.qwen/settings.json` для настройки пользовательского провайдера в `modelProviders`. Здесь фиксируется использование протокола, совместимого с OpenAI.

## Настройка

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` должен быть массивом. Записи провайдера настраиваются независимо и не наследуют автоматически другие параметры верхнего уровня, такие как context, Header или body.

## Проверка

```bash
export ACEDATACLOUD_API_KEY="PASTE_YOUR_ACEDATACLOUD_API_TOKEN_HERE"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

После входа отправьте `Reply only OK`, затем снова запустите инструмент для чтения файла. Если строго совместимый конечный пункт отклоняет формат результатов инструмента, проверьте текущую версию Qwen Code и официальные инструкции по совместимости.
