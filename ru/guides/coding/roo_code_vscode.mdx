## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Конфигурация

Roo Code официально предоставляет OpenAI-compatible Provider и требует, чтобы модель поддерживала нативный OpenAI tools/function calling.

1. Откройте настройки Roo Code в VS Code.
2. Установите **API Provider** на **OpenAI Compatible**.
3. Заполните:

| Поле       | Значение                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Только что скопированный API Key                  |
| Model ID | Model ID модели, выбранной в мастере настройки Coding         |

![Интерфейс конфигурации Roo Code OpenAI Compatible](https://cdn.acedata.cloud/b6a0e7156438.png)

Затем настройте параметры context, max output, изображения и computer-use в соответствии с фактическими возможностями модели. В конце сохраните конфигурацию и перезагрузите VS Code.

## 3. Проверка

Сначала отправьте `Reply only OK`, затем попросите Roo Code прочитать тестовый файл. Если обычный чат работает успешно, но инструменты Agent не работают, замените модель на поддерживающую нативный tool calling и убедитесь, что совместимый endpoint может корректно потоково возвращать параметры и результаты инструментов.
