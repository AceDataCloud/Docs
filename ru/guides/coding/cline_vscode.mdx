## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Настройка Cline

Установите и откройте Cline в VS Code, затем через кнопку настроек на панели Cline перейдите к настройке Provider и заполните:

| Поле                                | Значение                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | Только что скопированный API Key                                                                                  |
| Model ID                          | Перейдите в [каталог моделей](https://platform.acedata.cloud/models), посмотрите и укажите название целевой модели без изменений, например `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | Оставьте пустым                                                                                             |
| Set Azure API version             | Оставьте пустым                                                                                             |
| Use Azure Identity Authentication | Отключите                                                                                             |

![Интерфейс настройки Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` — это название модели, используемое параметром `model` в API-запросе, а не UUID сервиса или API, и его нельзя сокращать самостоятельно. Сначала можно посмотреть в [каталоге моделей](https://platform.acedata.cloud/models); если требуется точная проверка, затем используйте текущий API Key для запроса `GET https://api.acedata.cloud/v1/models` и скопируйте значение `id` целевой модели из массива `data` в ответе.

Остальные настройки возможностей модели пока оставьте по умолчанию; когда понадобятся изображения или больший контекст, затем настройте их в соответствии с фактическими возможностями выбранной модели.

## 3. Проверка

После сохранения создайте новую задачу и отправьте `Reply only OK`. Затем попросите Cline прочитать тестовый файл, чтобы подтвердить, что модель поддерживает вызов инструментов; записи вызовов можно посмотреть в [истории использования](https://platform.acedata.cloud/console/usages).

401 обычно означает ошибку Key; 404 обычно означает, что Base URL указан неверно или введённый Model ID не полностью совпадает с `id` в каталоге. Если модель может общаться в чате, но не может работать с файлами, проверьте возможности вызова инструментов этой модели.
