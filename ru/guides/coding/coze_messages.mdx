Coze официальная документация по пользовательским моделям поддерживает Anthropic Messages API. Разные версии арендаторов Coze могут по-разному обрабатывать заголовки, соединение путей, потоковую передачу и вызовы инструментов, поэтому при первом подключении проверьте каждый пункт ниже.

## Конфигурация

1. Перейдите в управление моделями Coze и добавьте новую пользовательскую модель.
2. В качестве протокола выберите Anthropic Messages API.
3. Введите базовый URL API `https://api.acedata.cloud`.
4. Введите ваш токен API Ace Data Cloud в поле API Key.
5. Укажите точный ID модели, поддерживающей Anthropic Messages, в каталоге моделей.
6. Сохраните и завершите тестирование подключения Coze.
7. В Bot/Agent отправьте `Reply only OK`, затем еще раз протестируйте вызов инструмента.

## Текущие ограничения

- Разные регионы, версии или пакеты Coze могут отображать разные формы.
- Базовый URL API не должен повторно добавлять `/v1/messages`; если текущий интерфейс явно требует полный URL API, следуйте подсказкам формы.
- Messages, Chat Completions и Responses — это три независимых маршрута, которые не могут заменять друг друга для проверки.
