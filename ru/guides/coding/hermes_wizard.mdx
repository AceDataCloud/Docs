## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Запуск мастера

```bash
hermes model
```

Выберите **Custom endpoint**, последовательно заполните:

| Поле             | Значение                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Только что скопированный API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Перейдите в [каталог моделей](https://platform.acedata.cloud/models), просмотрите и без изменений укажите название целевой модели, например `claude-opus-5`, `gpt-6-sol` |
| Context length | Оставьте пустым для автоматического определения или заполните согласно каталогу моделей                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` — это название модели, используемое параметром `model` в API-запросе, а не UUID сервиса или API. Сначала можно посмотреть в [каталоге моделей](https://platform.acedata.cloud/models); если требуется точная проверка, затем используйте текущий API Key для запроса `GET https://api.acedata.cloud/v1/models` и скопируйте значение `id` целевой модели из массива `data` ответа.

Мастер запишет данные в `~/.hermes/config.yaml` и файл учётных данных на локальном компьютере.

## 3. Проверка

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Если мастер не сохранил конфигурацию, можно выполнить `hermes model --reset`, а затем повторить попытку; 401 означает, что API Key недействителен или не считывается конфигурацией текущего пользователя.
