## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Настройка

Kilo CLI считывает `kilo.jsonc` и получает API Key из оболочки, в которой запускается CLI.

Запишите в `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Затем в текущей оболочке экспортируйте Token:

```bash
export ACEDATACLOUD_API_KEY="ВСТАВЬТЕ_ВАШ_ACEDATACLOUD_API_TOKEN_ЗДЕСЬ"
```

## 3. Проверка

```bash
kilo run -m acedatacloud/MODEL_ID "Ответьте только OK"
```

Если CLI не может прочитать Token, убедитесь, что переменная была `export`, а не просто записана в не загруженный файл `.env`.
