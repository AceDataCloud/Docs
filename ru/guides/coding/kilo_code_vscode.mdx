## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Добавление Custom provider

В Kilo Code откройте **Settings → Providers**, нажмите **Custom provider**, затем заполните:

| Поле           | Значение                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Только что скопированный API Key                                                                                  |
| Models       | Перейдите в [каталог моделей](https://platform.acedata.cloud/models), просмотрите и добавьте названия моделей, которые хотите использовать, например `claude-opus-5`, `gpt-6-sol` |

![Интерфейс настройки Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

`id` модели здесь — это название модели, используемое параметром `model` в API-запросе, а не UUID сервиса или API. Сначала его можно посмотреть в [каталоге моделей](https://platform.acedata.cloud/models); при точной проверке скопируйте его без изменений из массива `data` ответа `/v1/models`, не угадывайте и не сокращайте самостоятельно.

Нажмите **Submit**, и модель появится в селекторе. Если требуется общий доступ для команды или более тонкая настройка, также можно отредактировать пользовательский файл `~/.config/kilo/kilo.jsonc` или файл уровня проекта `./kilo.jsonc` согласно официальной документации.

## 3. Проверка

Выберите `acedatacloud/MODEL_ID` и отправьте `Reply only OK`, затем выполните одну операцию только для чтения файла. Если модель не появилась, проверьте, был ли отправлен Provider, полностью ли название модели совпадает с `id` в каталоге и корректен ли Base URL.
