Плагин Continue для JetBrains использует тот же формат YAML модели, что и VS Code; конфигурация и секреты должны принадлежать пользователю, запускающему плагин JetBrains.

## Конфигурация

Добавьте в локальную YAML конфигурацию Continue:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Сохраните `ACEDATACLOUD_API_KEY` в секрете Continue. Сценарий Remote Development должен быть настроен на хосте, где фактически работает плагин.

## Проверка

Перезапустите JetBrains IDE, откройте окно инструментов Continue, выберите модель Local Config и отправьте `Reply only OK`; затем выполните еще раз задачу только для чтения файла. Если все еще используется старая модель, перезапустите удаленный backend и проверьте отступы YAML.
