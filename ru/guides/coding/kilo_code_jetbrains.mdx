## 1. Получение API Key

Откройте [Список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Настройка Provider

Плагин Kilo Code для JetBrains использует формат `kilo.jsonc` для Provider. Конфигурация должна находиться в среде пользователя, где фактически работает плагин; при удаленной разработке это обычно удаленный хост backend.

Запишите в `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

В среде, где запускается backend JetBrains, экспортируйте `ACEDATACLOUD_API_KEY`, затем перезапустите IDE или удаленный backend.

## 3. Проверка

Выберите `acedatacloud/MODEL_ID`, отправьте `Reply only OK`, затем дайте Agent'у прочитать тестовый файл. Если локально все работает, а удаленно нет, в первую очередь проверьте, правильно ли записаны конфигурационный файл и переменные окружения на удаленном хосте.
