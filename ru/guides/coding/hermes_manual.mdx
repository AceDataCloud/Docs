## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), войдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Сохранение Key

Запишите в `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=ваш API Key
```

## 3. Настройка Provider

Добавьте в `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Перейдите в [каталог моделей](https://platform.acedata.cloud/models), чтобы посмотреть названия моделей (например, `claude-opus-5`, `gpt-6-sol`), и замените все `MODEL_ID` на одно и то же название; при точной проверке ориентируйтесь на значение `id` в ответе `/v1/models`. Это значение является названием модели, используемым параметром API `model`, а не UUID сервиса или API. Не записывайте настоящий Key в YAML и не отправляйте `.env` в репозиторий.

## 4. Проверка

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Если возвращается 401, проверьте `~/.hermes/.env`; если конфигурация не вступила в силу, полностью выйдите и перезапустите Hermes.
