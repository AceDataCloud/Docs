Coze официальная документация по пользовательским моделям поддерживает OpenAI Chat API. Разные версии арендаторов Coze могут по-разному обрабатывать соединение путей, потоковый вывод и вызовы инструментов, поэтому при первом подключении проверьте каждый пункт ниже.

## Конфигурация

1. Перейдите в управление моделями Coze и добавьте пользовательскую модель.
2. В качестве протокола выберите OpenAI Chat API.
3. В поле Base API URL укажите `https://api.acedata.cloud/v1`.
4. В поле API Key введите ваш Ace Data Cloud API Token.
5. В поле Model укажите точный ID модели, поддерживающей Chat Completions, из каталога моделей.
6. Сохраните и завершите тестирование подключения Coze.
7. В Bot/Agent отправьте `Reply only OK`, затем еще раз протестируйте вызов инструмента.

## Текущие ограничения

- Разные регионы, версии или пакеты Coze могут отображать разные формы.
- Base API URL должен использоваться как базовый, не добавляйте повторно `/chat/completions`; если текущий интерфейс явно требует полный API URL, следуйте подсказкам формы.
- Chat Completions, Responses и Anthropic Messages — это три независимых маршрута, которые не могут заменять друг друга для проверки.
