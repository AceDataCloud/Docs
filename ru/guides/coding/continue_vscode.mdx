Continue поддерживает API, совместимый с OpenAI. Чтобы зафиксировать использование Chat Completions, необходимо явно установить `useResponsesApi: false`.

## Настройка

В локальную YAML конфигурацию Continue добавьте:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Сохраните `ACEDATACLOUD_API_KEY` в управлении секретами Continue, не отправляйте реальный токен в конфигурацию проекта. JSON конфигурация Continue устарела, новая конфигурация использует YAML.

## Проверка

Перезагрузите VS Code, откройте боковую панель Continue, выберите модель в Local Config и отправьте `Reply only OK`; затем выполните еще раз задачу только для чтения файла. Если запрос ошибочно отправляется на `/responses`, проверьте, находится ли `useResponsesApi: false` в данной записи модели.
