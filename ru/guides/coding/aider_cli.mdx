Aider подключается к API, совместимому с OpenAI, через префикс модели `openai/` от LiteLLM.

## Настройка

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Замените `MODEL_ID` на модель, выбранную в мастере настройки Coding. Также можно записать соответствующие параметры в локальный `.env` или `.aider.conf.yml`, но не отправляйте реальные токены.

## Проверка

```bash
aider --model openai/MODEL_ID --message "Ответьте только OK"
```

При первом использовании неизвестной модели Aider может сообщить о нехватке метаданных модели; это не равно ошибке аутентификации. 401 проверяет токен, 404 проверяет идентификатор модели и базовый URL `/v1`.
