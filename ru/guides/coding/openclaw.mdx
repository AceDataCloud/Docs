## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите к доступным приложениям и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка OpenClaw и плагина

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Плагин требует OpenClaw `2026.4.2` или более поздней версии, в настоящее время нативно предоставляет возможности Chat и Web Search.

## 3. Настройка Key

Рекомендуется использовать onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "ваш API Key"
```

Также можно использовать переменные окружения:

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

## 4. Необязательно: ручная настройка

Если не использовать onboarding, включите плагин и установите модель по умолчанию в `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Не записывайте API Key в этот файл; продолжайте использовать переменные окружения.

## 5. Выбор модели и проверка

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Ответьте только OK"
```

Замените `MODEL_ID` на модель, предоставляемую Coding Plan в данный момент. Если нужно установить как модель по умолчанию, выполните:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Записи вызовов можно просмотреть в [истории использования](https://platform.acedata.cloud/console/usages). 401 означает, что Key недействителен; если модель не существует, сначала проверьте точный ID и версию плагина. `cost: 0` в каталоге плагинов просто означает, что OpenClaw не будет повторно оценивать, фактические расходы все еще фиксируются Ace Data Cloud.

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "последние фреймворки AI-агентов" --limit 5
```

В настоящее время не рассматривайте возможности, упомянутые в описании плагина, такие как изображения, видео или музыка, как нативные возможности OpenClaw Provider.
