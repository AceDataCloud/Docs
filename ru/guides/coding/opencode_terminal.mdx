## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), войдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Также можно использовать npm:

```bash
npm install -g opencode-ai
```

## 3. Установка API Key

```bash
export ACEDATACLOUD_API_KEY="ваш API Key"
```

Чтобы настройка действовала постоянно, добавьте эту строку в `~/.zshrc` или `~/.bashrc`, а затем заново откройте терминал.

## 4. Настройка Provider

Отредактируйте `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Перейдите в [каталог моделей](https://platform.acedata.cloud/models), чтобы посмотреть названия моделей (например, `claude-opus-5`, `gpt-6-sol`), и замените все `MODEL_ID` одним и тем же названием; для точной проверки ориентируйтесь на значение `id` в ответе `/v1/models`. Это значение является названием модели, используемым параметром API `model`, а не UUID сервиса или API. Ace Data Cloud здесь использует Chat Completions, поэтому adapter — `@ai-sdk/openai-compatible`.

## 5. Проверка и запуск

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Затем запустите `opencode` в каталоге проекта. Если модель не отображается, проверьте путь к файлу конфигурации, синтаксис JSON и переменные окружения; 401 означает, что Key недействителен или не экспортирован.

Расширение IDE повторно использует ту же конфигурацию OpenCode runtime, см. [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
