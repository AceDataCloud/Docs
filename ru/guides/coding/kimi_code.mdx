## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Установка Kimi Code

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Также можно установить через npm：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Настройка AceDataCloud

Отредактируйте `~/.kimi/config.toml`, добавьте следующую конфигурацию：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "你的 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Перейдите в [каталог моделей](https://platform.acedata.cloud/models), чтобы посмотреть названия моделей (например, `claude-opus-5`, `gpt-6-sol`), и замените все `MODEL_ID` на одно и то же название; при точной проверке ориентируйтесь на значение `id` в ответе `/v1/models`. Это значение является названием модели, используемым параметром API `model`, а не UUID сервиса или API. `type = "openai"` использует протокол OpenAI Chat Completions.

Файл конфигурации содержит Key, для macOS / Linux рекомендуется ограничить права：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Проверка и запуск

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

После входа в проект запустите `kimi`, чтобы начать использование. Если возвращается 401, проверьте API Key; если появляется сообщение model not found, убедитесь, что `default_model`, название модели в таблице моделей и поле `model` используют один и тот же ID.
