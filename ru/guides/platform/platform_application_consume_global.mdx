---
title: "Настройка глобального совместного использования баланса AceDataCloud Application"
description: "Platform API guide - Ace Data Cloud"
---

Настройте `allow_consume_global`. После включения соответствующие Application с оплатой по мере использования могут продолжать использовать глобальный баланс аккаунта при недостаточном собственном балансе.

## Подготовка

- Создайте и безопасно сохраните [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Получите принадлежащий вам `application_id` из [списка заявок на сервис](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='токен вашего аккаунта'
export APPLICATION_ID='ваш Application ID'
```

## Обзор интерфейса

| Пункт    | Содержимое                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Метод   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Авторизация   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

При успехе возвращается обновлённый объект Application. Ориентируйтесь на `allow_consume_global` в ответе, а не предполагайте, что значение запроса обязательно было сохранено.

> Application типа `Period` не разрешено расходовать глобальный баланс. Даже при запросе `true` сервер сохранит значение этого поля как `false`.

## Обработка ошибок

- `401`: Account Token недействителен или отсутствует.
- `403`: текущий аккаунт не является владельцем данного Application.
- `404`: Application ID не существует.

Точка пополнения глобального баланса и доступные пакеты определяются консолью платформы и фактическими пакетами, возвращаемыми при [создании заказа](https://platform.acedata.cloud/documents/platform-order-create); не следует предполагать существование пакетов типа `Wallet`.

## Приложения с разрешённым овердрафтом

Когда для приложения с оплатой по мере использования поле только для чтения `allow_overdraft=true`, это приложение может продолжать списывать средства со своего баланса, даже если баланс становится отрицательным, и не переключается на глобальный аккаунт из-за недостаточного баланса. Приложения без включённого овердрафта по-прежнему следуют `allow_consume_global`; разрешён ли овердрафт после переключения, определяется настройками фактически списываемого глобального Application.
