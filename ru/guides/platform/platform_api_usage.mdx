---
title: "Получение недавних образцов вызовов API платформы AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Публично возвращает образцы записей вызовов определённого API за последние 15 минут для быстрого наблюдения за текущим состоянием. Это не интерфейс подсчёта с агрегацией по кодам состояния, и его нельзя использовать для личных счетов, SLA или полной статистики использования.

## Обзор интерфейса

| Пункт   | Содержание                                                           |
| --- | ------------------------------------------------------------ |
| Метод  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Авторизация  | Публичная, токен учётной записи не требуется                                                    |
| Лимит  | После объединения недавно созданных/завершённых записей возвращается не более 5 000 записей                                    |

`api_id` можно получить из [списка API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Структура фактического ответа

Ответ напрямую представляет собой массив, без envelope пагинации:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Поле            | Описание        |
| ------------- | --------- |
| `api_id`      | ID API    |
| `created_at`  | Время создания записи    |
| `trace_id`    | Идентификатор отслеживания запроса    |
| `status_code` | Код состояния HTTP  |
| `elapsed`     | Длительность вызова, в секундах |

Если API не существует, в настоящее время также может быть возвращён пустой массив, поскольку это действие напрямую запрашивает недавнее использование по ID и не проверяет предварительно объект API. Для расчёта процента успешных вызовов клиент должен самостоятельно сгруппировать возвращённые образцы; для проверки личных списаний используйте интерфейс уровня учётной записи.
