Модель Provider, IDE Extension и MCP в Coding Plan OpenCode являются тремя независимыми возможностями. IDE Extension подключается к локальному OpenCode runtime и использует ту же конфигурацию Provider; она не представляет собой нативную поддержку Ace Data Cloud со стороны хост-редактора.

| Маршрут                        | Описание                                                  | Ссылка                                                                                  | Статус      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | --------- |
| Terminal / CLI / TUI Provider | Использует `opencode.json[c]` и Chat Completions       | [Конфигурация Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Подтвержденная конфигурация |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium и другие хосты подключаются к OpenCode runtime | [Конфигурация IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Экспериментальная     |
| MCP                           | Вызов удаленных инструментов внутри OpenCode             | [Обзор MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Независимая возможность    |

После успешной конфигурации Provider, IDE Extension должна использовать тот же Provider и модель. Необходимо отдельно проверить чат, чтение файлов, редактирование и вызов инструментов в IDE, не следует автоматически экстраполировать один обычный запрос CLI на все возможности IDE.

Идентификатор модели соответствует [реальному каталогу](https://platform.acedata.cloud/models).
