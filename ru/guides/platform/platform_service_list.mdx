---
title: "Получение списка услуг платформы AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Постранично возвращает каталог Service, видимый на текущем сайте, включая типы услуг, отображаемую информацию, бесплатные квоты, пакеты и связанные API/Proxy ID. Подходит для создания маркетплейса услуг или выбора услуги для подачи заявки.

## Обзор интерфейса

| Пункт   | Содержание                                                |
| --- | ------------------------------------------------- |
| Метод  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Авторизация  | Публичный; при наличии состояния входа `applied` отражает текущий аккаунт                        |
| Пагинация  | `count` + `items`                                 |

## Параметры запроса

| Параметр               | Тип      | Обязательный  | Описание                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Нет   | Фильтрация по ID услуги; поддерживает повторяющиеся параметры         |
| `private`        | boolean | Нет   | Фильтрация по публичному статусу; правила видимости сайта всё ещё действуют      |
| `type`           | string  | Нет   | Тип услуги; поддерживает повторяющиеся параметры              |
| `tag`            | string  | Нет   | Фильтрация по тегу                    |
| `include_facets` | boolean | Нет   | При `true` добавляет статистику типов/тегов, доступных на текущем сайте |
| `limit`          | integer | Нет   | Количество элементов на страницу, максимум 100              |
| `offset`         | integer | Нет   | Смещение пагинации                    |
| `ordering`       | string  | Нет   | Поддерживаются только `rank` или `-rank`     |

Список не поддерживает фильтрацию по `alias`; при наличии alias напрямую запрашивайте `/api/v1/services/{alias}`. `applied_count`, `updated_at` не являются допустимыми полями сортировки.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Описание ответа

Ответ имеет вид `{count, items}`; `facets` добавляется только при `include_facets=true`. Элемент услуги содержит такие текущие публичные поля, как `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` и другие.

`applied` в анонимном списке не представляет статус заявки какого-либо аккаунта. Если требуется статус, связанный с аккаунтом, следует использовать действительное состояние входа и считать [список заявок на услуги](https://platform.acedata.cloud/documents/platform-application-list) окончательным источником.
