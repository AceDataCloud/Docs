Постранично возвращает заказы на пополнение счёта, подходит для поиска ID заказа, просмотра статуса оплаты и сверки.

## Подготовка

Создайте [Account Token](https://platform.acedata.cloud/documents/platform-token) и получите UUID текущего аккаунта из `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='токен вашего аккаунта'
export USER_ID='UUID вашего аккаунта'
```

## Обзор интерфейса

| Пункт   | Содержание                                      |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/orders/` |
| Авторизация  | Account Token, OAuth token требует `orders:read`       |
| Пагинация  | `count` + `items`                               |

Обычные пользователи должны передавать собственный `user_id`; в противном случае при встрече с объектами без прав доступа при пагинации может вернуться `403`.

## Параметры запроса

| Параметр                    | Тип       | Обязательный     | Описание                                                        |
| --------------------- | -------- | ------ | --------------------------------------------------------- |
| `user_id`             | UUID     | Обязателен для обычных пользователей | Аккаунт, которому принадлежит заказ; поддерживаются повторяющиеся параметры                                             |
| `pay_way`             | string   | Нет      | Фильтрация по способу оплаты; поддерживаются повторяющиеся или разделённые запятыми значения                                        |
| `state`               | string   | Нет      | Фильтрация по статусу; поддерживаются повторяющиеся или разделённые запятыми значения                                          |
| `created_at_from/to`  | datetime | Нет      | Диапазон времени создания                                                    |
| `finished_at_from/to` | datetime | Нет      | Диапазон времени завершения                                                    |
| `limit` / `offset`    | integer  | Нет      | Пагинация                                                        |
| `ordering`            | string   | Нет      | `created_at`, `-created_at`, `finished_at` или `-finished_at` |

Текущий список не поддерживает фильтрацию по `application_id`, `service_id`, `package_id`, `payment_method` или `tag`; имя поля способа оплаты — `pay_way`.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/orders/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'state=Paid,Finished' \
  --data-urlencode 'pay_way=Stripe' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Описание ответа

Ответ имеет вид `{count, items}`. Элементы списка в продакшене содержат `id`, `user_id`, `application_id/application_ids`, `package_id/package_ids`, `price`, `amount`, `discount`, `remaining_amount`, `state`, `pay_way`, `pay_id`, `pay_url`, `finished_at`, `expired_at`, `invoice`, `metadata` и поля времени.

- Фактическими статусами являются `Pending`, `Paid`, `Finished`, `Expired`, `Failed`, `Refunded`; статуса `Cancelled` нет.
- Имена полей — `pay_way`, `finished_at`, `discount` и `price`, а не `payment_method`, `paid_at`, `discount_rate` или `final_price`.
- `price` — это окончательная цена в записи заказа; валюта и детали расчёта могут находиться в контролируемых metadata, и их нельзя самостоятельно выводить только по способу оплаты.
