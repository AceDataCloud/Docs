Вы, вероятно, тоже сталкивались с такой ситуацией: используете Claude Code, Cursor или Codex, код пишется как по маслу, и вдруг нужна иллюстрация, фоновая музыка, короткое видео или хочется, чтобы он заодно нашёл свежую информацию. В итоге оказывается — сам agent этого не умеет. Приходится самостоятельно искать API, читать документацию, настраивать key, писать код вызова, обрабатывать асинхронный опрос — после всей этой возни вдохновение уже остыло.

[AceKit](https://github.com/AceDataCloud/AceKit) создан, чтобы избавить от всей этой возни. Одной командой он устанавливает в ваш агент для программирования весь набор возможностей AceData Cloud: генерацию изображений, видео, музыки, веб-поиск, диалоги с LLM и другое. После установки вы просто говорите человеческим языком, а agent сам загрузит нужный навык, сам пройдёт авторизацию, сам выполнит опрос и завершит задачу.

## Поймите за 30 секунд, что он делает

До установки vs после установки:

| Что вы говорите               | До установки                   | После установки（agent делает сам）                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Подбери обложку для этого README" | agent не умеет, предлагает вам самим искать API генерации изображений | Вызывает NanoBanana / Flux / Midjourney для генерации изображения |
| "Сделай из этого скрипта 30-секундное короткое видео"  | Не умеет                    | Вызывает Sora / Veo / Kling / Seedance для создания видео  |
| "Подбери фоновую музыку для этого demo"  | Не умеет                    | Вызывает Suno для создания музыки                           |
| "Поищи последние новости о X и затем обобщи"     | Не умеет выходить в интернет                  | Вызывает Google SERP и получает результаты в реальном времени                 |
| "Сократи эту длинную ссылку"         | Не умеет                    | Вызывает сервис коротких ссылок и возвращает ссылку surl.id                  |

Одним предложением: **ваш агент для программирования превращается из «умеет только писать код» в «умеет ещё генерировать изображения, видео, музыку и искать в интернете».**

## Начало работы в три шага

Весь процесс займёт несколько минут, требуется Node.js 18+.

**Шаг первый · Получите API Token.** В [консоли](https://platform.acedata.cloud/console/applications) скопируйте Token — один и тот же используется для всех возможностей; при первом получении предоставляется бесплатный лимит, поэтому сначала можно попробовать бесплатно.

![Скопируйте API Token в консоли](https://cdn.acedata.cloud/dvc3cg.jpg)

**Шаг второй · Установите.** Одна команда:

```bash
npx acekit
```

Она автоматически обнаружит агенты для программирования на вашей машине и установит полный набор навыков. Реальный запуск выглядит так (на этой машине установлен только Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Если Token не задан, при первом запуске появится интерактивное приглашение вставить его; также можно заранее выполнить `export ACEDATACLOUD_API_TOKEN=вашtoken`, чтобы установить всё полностью без участия пользователя. Количество навыков будет меняться по мере появления возможностей на платформе; ориентируйтесь на текущий список, показанный в `npx acekit list`.

**Шаг третий · Говорите человеческим языком.** Перезапустите agent, а затем просто дайте команду, например:

```text
Используй навык short-url, чтобы сократить https://platform.acedata.cloud/services
```

agent сам загрузит навык, сам выполнит вызов и выдаст реальный результат, по которому можно перейти.

## Реальный запуск (с выводом)

Все четыре примера ниже — это **реальные вызовы с результатами, возвращёнными на месте**, а не демонстрация. `$KEY` в командах — это ваш API Token.

**① Сокращение URL (синхронно, ответ за секунды)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Возвращает `https://surl.id/r/1uKp2kilXQ` — при переходе по ней произойдёт 302-перенаправление обратно на исходную страницу services.

**② Поиск в интернете (синхронно)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Получаем актуальные результаты Google (фрагмент):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Диалог с LLM (синхронно, один интерфейс для 50+ моделей)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP是用于统一管理和交换模型上下文信息的协议。
（39 tokens，本次约 0.00007 credit）
```

**④ Генерация изображений (асинхронно, около 20 секунд, agent автоматически выполняет опрос до получения изображения)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Примерно через 22 секунды возвращается реальное изображение (HTTP 200 · image/png · 317 KB · около 0.13 credit за этот запрос):

![Изображение, реально сгенерированное AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

На самом деле вам не нужно запоминать эти интерфейсы — после установки навыков agent самостоятельно составит правильные запросы в соответствии со своими `SKILL.md`, обработает авторизацию и опрос. Выше лишь показано, «что он делает за кулисами».

## Что именно он устанавливает

AceKit — это «главный вход» во весь набор инструментов разработчика AceData; сейчас за одну установку устанавливается **набор инструментов навыков（Skills）**:

- **Набор Agent-навыков**: каждый навык — это готовая инструкция по эксплуатации в `SKILL.md` — авторизация, асинхронный опрос, повторные попытки при ошибках, заполнение параметров — всё подробно описано, agent достаточно следовать ей. Выполните `npx acekit list`, чтобы увидеть текущий список (на момент написания этой статьи их 19, и количество продолжает расти):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Единый Token**: один `ACEDATACLOUD_API_TOKEN` открывает все возможности, оплата по фактическому использованию.

По категориям возможностей (ориентируйтесь на `npx acekit list`):

| Тип         | Поставщики                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Генерация изображений      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Генерация видео      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Генерация музыки / аудио | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM-диалоги   | Единый интерфейс для 50+ моделей（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Поиск       | Google SERP（веб · изображения · новости · карты · видео）                  |
| 🔗 Инструменты       | Короткие ссылки · обработка лиц                                            |

> Для этих же возможностей AceData также предоставляет отдельные **MCP-серверы**（Suno、Midjourney、Sora、SERP… опубликованы в PyPI / VS Code / Smithery / Docker）、**CLI командной строки** и **Python / TypeScript SDK**, которые можно использовать отдельно по мере необходимости。В AceKit v0.2 планируется поддержка установки отдельных возможностей через `acekit add <name>`, а также автоматическая запись MCP-конфигурации для каждого agent.

## Какие Agent поддерживаются

| Agent                        | Расположение установки навыков                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode и др. | `~/.agents/skills`（направьте ваш agent сюда） |

При установке AceKit автоматически обнаруживает уже установленные на машине agent и устанавливает только в те, которые были обнаружены.

## Пасхалка: используйте один и тот же Token для запуска самого Claude Code

Интерфейс AceData также совместим с форматом Anthropic `/v1/messages`, поэтому вам**не нужна официальная подписка Anthropic** — Claude Code можно запускать с помощью того же AceData Token. Создайте `.claude/settings.local.json` в корневом каталоге проекта:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Просто перезапустите Claude Code — он не только будет использовать всю линейку моделей Claude, но и получит через AceKit «руки» для генерации изображений, видео и музыки. Подробнее смотрите в [руководстве по интеграции Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
