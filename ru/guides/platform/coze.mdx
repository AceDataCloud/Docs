Официально Coze поддерживает интеграцию пользовательских моделей и предоставляет три протокола: OpenAI Chat API, OpenAI Responses API и Anthropic Messages API. Базовый URL, пути, заголовки, потоковая передача и контракты вызова инструментов для этих трех маршрутов различаются, поэтому их необходимо настраивать и проверять отдельно.

| Маршрут                   | Статус    | Руководство                                                                                  |
| ----------------------- | -------- | ------------------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Экспериментальный | [Настройка Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Экспериментальный | [Настройка Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Экспериментальный | [Настройка Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

"Экспериментальный" означает, что официальные возможности и точки конфигурации подтверждены, но разные регионы, версии или пакеты Coze могут отображать разные формы, Ace Data Cloud все еще должен завершить проверку фиксированной версии в соответствии с протоколом. Не следует экстраполировать успешное выполнение одного протокола на другие два.

## Принципы конфигурации

- Приоритетно указывайте базовый API URL, предоставленный в документации; не добавляйте повторно путь endpoint, который клиент автоматически дополнит.
- Используйте ваш Ace Data Cloud API Token в качестве API Key.
- Используйте точный ID модели, совместимый с выбранным протоколом, из каталога моделей.
- После успешного выполнения обычного текста также следует проверить потоковую передачу и вызов инструментов.
