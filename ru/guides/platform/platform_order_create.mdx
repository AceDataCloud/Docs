---
title: "Создание заказа на пополнение платформы AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Создайте ожидающий оплаты заказ для одного или нескольких Application. Создание запишет заказ, но не завершит оплату автоматически; перед оплатой следует проверить `price`, пакет и Application в ответе.

## Подготовка

- Создайте [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Получите `application_id` из [списка Application](https://platform.acedata.cloud/documents/platform-application-list).
- Выберите в `packages` из [деталей сервиса](https://platform.acedata.cloud/documents/platform-service-detail) доступный для покупки `package_id`, соответствующий типу Application.

```shell
export PLATFORM_TOKEN='ваш токен аккаунта'
export APPLICATION_ID='ваш Application ID'
export PACKAGE_ID='ваш Package ID'
```

## Обзор интерфейса

| Параметр    | Содержание                                              |
| ---- | ----------------------------------------------- |
| Метод   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Авторизация   | Account Token, для OAuth token требуется `orders:write`      |
| Body | JSON                                            |

## Тело запроса

Заказ для одного Application использует `application_id` + `package_id`; пакетный заказ использует соответствующие по длине `application_ids` + `package_ids`. Для обычного заказа способ оплаты выбирается в последующем запросе `/pay/`. При создании заказа для покупок iOS передайте `pay_way: "AppleIAP"`, при этом можно выбрать только один Usage-пакет с `metadata.apple_product_id` и `metadata.apple_price`. Для покупок Apple используются независимые предустановленные цены в долларах США, без применения скидок участника, скидок по способу оплаты или наценок сайта; сумма списания в местной валюте в других регионах определяется страницей подтверждения оплаты Apple.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Описание ответа

При успехе возвращаются `201` и созданный объект Order. Ключевые поля включают `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` и поля времени. Новый заказ обычно имеет статус `Pending`, после чего вызовите [оплату заказа](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` — это сумма к оплате, рассчитанная сервером на основе пакета, наценки сайта и скидок; не рассчитывайте её самостоятельно на клиенте.
- При несоответствии Package сервису или типу Application возвращается `400`.
- Бесплатный и управляемый системой Package нельзя получить самостоятельно через публичный интерфейс заказа.
- Создание заказа для Application, не принадлежащего текущему аккаунту, будет отклонено.
