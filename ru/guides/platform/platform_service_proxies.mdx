---
title: "Получение списка Proxy в сервисе платформы AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Постранично возвращает конечные точки Proxy, подключённые к этому сервису, через Service UUID. Если есть только alias, сначала вызовите [детали сервиса](https://platform.acedata.cloud/documents/platform-service-detail), чтобы получить `id`.

## Обзор интерфейса

| Пункт   | Содержание                                                             |
| --- | ---------------------------------------------------------------------- |
| Метод  | `GET`                                                                  |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/proxies/` |
| Аутентификация  | Открытый, токен аккаунта не требуется                                                              |
| Пагинация  | `count` + `items`                                                      |

## Параметры

| Параметр                 | Расположение    | Обязателен  | Описание                               |
| ------------------ | ----- | --- | -------------------------------- |
| `service_id`       | path  | Да   | Service UUID, alias не поддерживается           |
| `limit` / `offset` | query | Нет   | Пагинация                               |
| `ordering`         | query | Нет   | Выражение сортировки Django; рекомендуется `rank` или `-rank` |

```shell
export SERVICE_ID='你的 Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/proxies/" \
  --data-urlencode 'limit=100' \
  -H 'Accept: application/json'
```

## Описание ответа

Элементы списка сериализуются моделью Proxy, среди проверенных в продакшене полей есть `id`, `service_id`, `title`, `endpoint`, `price`, `stage`, `rank`, `tags`, `metadata`, `document_id`, `service` и поля времени.

- Полем бизнес-входа является `endpoint`, а не `path`.
- Полем цены является `price`, а не `cost`.
- Если тип Service не является Proxy или Proxy не подключён, возвращается пустой `items`.

Публичная интеграция полагается только на `endpoint` и опубликованные возможности и не должна полагаться на неопубликованные детали реализации.
