Получите полное содержимое и навигационные связи одного документа по UUID или alias документа. Если alias уже известен, можно выполнить запрос напрямую, без предварительной фильтрации из списка.

## Обзор интерфейса

| Пункт   | Содержание                                                              |
| --- | --------------------------------------------------------------- |
| Метод  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Авторизация  | Публичный; достаточно знать UUID или alias для прямого чтения                                       |

## Параметры

- `id_or_alias`: UUID документа, текущий alias или старый alias, сохранённый в `redirect_from`.
- `lang`: необязательная языковая подсказка; также можно использовать `Accept-Language`. Окончательный язык содержимого определяется по `content_locale` в ответе.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Описание ответа

Сведения возвращаются одним объектом, который в настоящее время содержит:

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags`;
- `content`, `content_mode`, `content_locale`, `content_hash`;
- `parent`, `sibling` и сводки публичных `children`, отсортированных по rank;
- связи `api` / `proxy` / `dataset` / `integration`, а также `agent` (при наличии).

В ответе нет поля `breadcrumbs`. При построении хлебных крошек можно продолжить получение сведений о документе из `parent` или использовать кэшированные связи каталога документов.

## Обработка ошибок

- ID/alias не существует или не соответствует видимости текущего сайта: `404`. `private` контролирует только видимость в списках и не препятствует прямому чтению теми, кто знает ссылку; его нельзя использовать в качестве границы конфиденциальности.
- Текущий маршрут использует форму без завершающего слэша; не полагайтесь на автоматическое добавление слэша на уровне прокси.
