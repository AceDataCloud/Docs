## 1. Получение API Key

Откройте [список приложений Ace Data Cloud](https://platform.acedata.cloud/console/applications), перейдите в доступное приложение и скопируйте API Key.

![Получение API Key Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Добавление Provider

Откройте Cherry Studio, перейдите в **Настройки → Модельные сервисы → Добавить провайдера** и заполните:

| Поле      | Значение                           |
| ------- | --------------------------- |
| Название провайдера   | `Ace Data Cloud`            |
| Тип провайдера   | `OpenAI`                    |
| API Key | Только что скопированный API Key               |
| API-адрес  | `https://api.acedata.cloud` |

![Интерфейс настройки добавления Provider Ace Data Cloud в Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio автоматически добавит `/v1/chat/completions` для типа OpenAI. При использовании общего входа не добавляйте `#` в конец адреса, также не требуется создавать несколько Provider для разных семейств моделей.

## 3. Добавление и включение модели

1. Нажмите **Получить список моделей**; если текущая версия не поддерживает автоматическое получение, перейдите в [каталог моделей](https://platform.acedata.cloud/models), проверьте его и затем вручную добавьте название целевой модели, например `claude-opus-5`, `gpt-6-sol`.
2. Нажмите кнопку проверки рядом с API Key, чтобы проверить подключение.
3. Включите переключатель **Включить** у Provider.
4. Выберите только что добавленную модель в селекторе моделей диалога.

![Provider и список моделей Cherry Studio](https://cdn.acedata.cloud/149de1d088bf.png)

> После получения или ручного добавления модели включите переключатель Provider в правом верхнем углу.

Отправьте `Ответьте только OK` и проверьте вызов в [истории использования](https://platform.acedata.cloud/console/usages). При 401 проверьте Key; если модель не отображается, проверьте, включён ли Provider; при 404 проверьте, полностью ли совпадает вручную введённое название модели с `id` в каталоге.

## О GPT Image 2

Обычный пользовательский чат Provider в Cherry Studio не может напрямую вызывать Images API. Генерацию и редактирование `gpt-image-2` следует выполнять через специальные интерфейсы Ace Data Cloud:

- [Генерация изображений GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Редактирование изображений GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Не указывайте `/openai/images/generations` в чат Provider.
