Coze официальная документация по пользовательским моделям поддерживает OpenAI Responses API и предоставляет Base API URL, API Key и поля модели. Разные версии арендаторов Coze могут по-разному обрабатывать соединение путей, потоковый вывод и вызовы инструментов, поэтому при первом подключении проверьте каждый пункт ниже.

## Конфигурация

1. Перейдите в управление моделями Coze и добавьте пользовательскую модель.
2. Выберите Protocol OpenAI Responses API.
3. Введите Base API URL `https://api.acedata.cloud/v1`.
4. Введите API Key ваш Ace Data Cloud API Token.
5. Введите Model точный ID модели, поддерживающей Responses API, из каталога моделей.
6. Сохраните и завершите тестирование подключения Coze.
7. В Bot/Agent отправьте `Reply only OK`, затем еще раз протестируйте вызов инструмента.

## Текущие границы

- Разные регионы, версии или пакеты Coze могут отображать разные формы.
- Base API URL должен использоваться как base, не добавляйте повторно `/responses`; если текущий интерфейс явно требует полный API URL, следуйте подсказкам формы.
- Chat Completions, Responses и Anthropic Messages — это три независимых маршрута, которые не могут заменять друг друга для проверки.
