Получение общедоступных переключателей функций и определения страны/региона в контексте текущего запроса. Подходит для определения при запуске фронтенда, какие функции следует отображать; это не название бренда сайта, контактная информация или каталог объявлений.

## Обзор интерфейса

| Пункт   | Содержание                                              |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Авторизация  | Публичный; при наличии состояния входа некоторые переключатели функций могут вычисляться по пользователю                          |

## Параметры запроса и заголовки

| Название                    | Расположение     | Описание                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Выражение переопределения переключателей функций; действует только для переключателей, которым разрешено клиентское переопределение, или для суперадминистраторов |
| `X-Feature-Overrides` | header | Источник переопределения, аналогичный `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Фактическая структура ответа

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Поле         | Тип            | Описание                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Переключатели функций, видимые для текущего запроса; ключи могут меняться в зависимости от конфигурации платформы, клиент должен читать их по необходимости и устанавливать безопасные значения по умолчанию для отсутствующих ключей |
| `region`   | string / null | Код страны или региона, определённый по IP запроса, в нижнем регистре; при невозможности определения — `null`        |

Не получайте из этого интерфейса название сайта, CDN, валюту, язык, контактные данные службы поддержки или объявления; эти поля не входят в текущий контракт ответа.

## Рекомендации по использованию

- Переключатели функций вычисляются по пользователю, отпечатку и контексту сайта, не следует долго совместно использовать кэш между пользователями.
- Выбор селектора региона сохраняется только на фронтенде; при отображении в приоритете используйте уже выбранный регион, в противном случае используйте `region` из этого интерфейса. Этот интерфейс не принимает параметры переопределения региона.
- Нераспознанные query-параметры будут проигнорированы; используйте только параметры, перечисленные на этой странице.
