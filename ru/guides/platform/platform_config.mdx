Получение публичных функциональных переключателей и определения страны/региона в контексте текущего запроса. Подходит для определения при запуске фронтенда, должны ли отображаться функции; это не название бренда сайта, контактная информация или каталог объявлений.

## Обзор интерфейса

| Пункт   | Содержание                                              |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Авторизация  | Публичный; при наличии состояния входа некоторые функциональные переключатели могут вычисляться для пользователя                          |

## Параметры запроса и заголовки

| Имя                    | Расположение     | Описание                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Двухбуквенный ASCII-код страны; используется для переопределения отображаемой страны в ответе, не изменяет серверную проверку безопасности |
| `features`            | query  | Выражение переопределения функциональных переключателей; действует только для переключателей, которым разрешено клиентское переопределение, или для суперадминистратора        |
| `X-Feature-Overrides` | header | Такой же источник переопределения, как и `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Фактическая структура ответа

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Поле         | Тип            | Описание                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Функциональные переключатели, видимые в текущем запросе; ключи изменяются в зависимости от конфигурации платформы, клиент должен считывать их по необходимости и задавать безопасные значения по умолчанию для отсутствующих ключей |
| `country`  | string / null | Код страны в нижнем регистре; при невозможности распознавания может быть `null`                     |

Не получайте из этого интерфейса название сайта, CDN, валюту, язык, контактную информацию службы поддержки или объявления; эти поля не входят в текущий контракт ответа.

## Рекомендации по использованию

- Функциональные переключатели вычисляются по пользователю, отпечатку и контексту сайта; не используйте долгосрочный общий кэш между пользователями.
- Передаваемый клиентом `country` влияет только на возвращаемое значение и не обходит серверные региональные политики или политики безопасности.
- Нераспознанные query-параметры будут проигнорированы; используйте только параметры, перечисленные на этой странице.
