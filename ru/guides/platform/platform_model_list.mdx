---
title: "Получение списка моделей платформы AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Возвращает публичный каталог моделей платформы, ответ использует структуру в стиле OpenAI `{ "object": "list", "data": [...] }`. Этот каталог используется для выбора моделей и обнаружения возможностей и не означает, что текущая учётная запись обязательно уже подала заявку на соответствующие сервисы.

## Обзор интерфейса

| Пункт   | Содержание                                              |
| --- | ----------------------------------------------- |
| Метод  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| Аутентификация  | Публичный, токен учётной записи не требуется                                       |
| Пагинация  | Без пагинации, все совпадающие элементы находятся в `data`                              |

## Параметры запроса

| Параметр             | Тип      | Обязательный  | Описание                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | Нет   | Точная фильтрация по идентификатору поставщика модели в каталоге                        |
| `type`         | string  | Нет   | Точная фильтрация по типу модели, например `chat`                     |
| `capability`   | string  | Нет   | Возвращает только модели, чьи `capabilities` содержат эту возможность, например `vision` |
| `with_pricing` | boolean | Нет   | Добавляет публичную информацию о ценах при значении `1`, `true` или `yes`            |

`service_id`, `tag`, `limit`, `offset` и `ordering` в настоящее время не поддерживаются; их передача не приведёт к соответствующей фильтрации или пагинации.

## Примеры запросов

```shell
# Все публичные модели
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# Модели chat с поддержкой визуального восприятия и с ценами
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## Структура фактического ответа

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` и верхнеуровневый `credit_usd_rate` появляются только при `with_pricing=true`; не у каждой модели есть вычисляемый `pricing`. Поля объекта модели соответствуют публичным полям `config/models.json`, клиентам следует игнорировать новые поля.

> Поля цен являются данными для отображения в каталоге. Фактические бизнес-вызовы по-прежнему регулируются правилами тарификации соответствующего API/Service и итоговыми записями об использовании.
