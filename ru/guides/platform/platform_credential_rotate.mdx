Создайте новый Token или пароль для существующего Credential. ID учётных данных, связь с Application, лимиты и другие поля остаются без изменений, старый секрет немедленно становится недействительным.

> Ротация прервёт работу клиентов, которые всё ещё используют старый секрет. Перед выполнением операции записи сначала подготовьте безопасное распространение и план отката.

## Обзор интерфейса

| Пункт    | Содержание                                                                  |
| ---- | --------------------------------------------------------------------------- |
| Метод   | `POST`                                                                      |
| URL  | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}/rotate/` |
| Аутентификация   | Account Token                                                               |
| Body | Нет или `{}`                                                                     |

Получите `credential_id` из [списка учётных данных](https://platform.acedata.cloud/documents/platform-credential-list):

```shell
export PLATFORM_TOKEN='你的账户令牌'
export CREDENTIAL_ID='要轮换的 Credential ID'

curl -X POST \
  "https://platform.acedata.cloud/api/v1/credentials/${CREDENTIAL_ID}/rotate/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

При успехе возвращается обновлённый Credential. При `type=Token` прочитайте новый `token`; при `type=Identity` прочитайте новый `password`. Обрабатывайте полный ответ как секрет и немедленно обновите вызывающую сторону.

## Обработка ошибок

- `401`: Account Token недействителен.
- `403`: Нет прав на управление этими учётными данными.
- `404`: Credential ID не существует.
