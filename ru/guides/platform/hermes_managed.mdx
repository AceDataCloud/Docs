title: "Развёртывание Hermes"

Для каждого Application создаётся независимый экземпляр контейнера Hermes. По умолчанию используется базовый образ фиксированной версии выпуска с сохранением нативных функций; платформа предоставляет покупку, продление, постоянное хранилище и управление развёртыванием.

## Создание и покупка

1. Откройте [развёртывание Hermes](https://platform.acedata.cloud/services/hermes) и создайте Application.
2. На странице покупки выберите тариф по длительности и завершите оплату.
3. Вернитесь на страницу конфигурации, выберите чат-модель платформы из выпадающего списка и просмотрите текущую цену модели. Платформа создаст для этого экземпляра независимые API-учётные данные; также можно отключить доступ платформы и самостоятельно выполнить настройку в нативной консоли.
4. Выберите автоматическое создание учётных данных доступа либо задайте собственный надёжный пароль/Token; при необходимости отметьте A2A и EnvarPay, после подтверждения начнётся развёртывание. Учётные данные доступа и API-учётные данные модели независимы друг от друга.
5. После готовности экземпляра получите адрес доступа и учётные данные для входа на странице управления.
6. Войдите в нативную консоль для настройки каналов. Если при развёртывании был отключён доступ к моделям платформы, необходимо также самостоятельно настроить поставщика моделей и учётные данные, чтобы чат мог использоваться.

Плата за развёртывание рассчитывается по длительности тарифа; конкретная цена в долларах США и длительность указаны на странице покупки. Стоимость вызовов моделей рассчитывается отдельно; покупка времени развёртывания не предоставляет лимит моделей. При включённом доступе платформы выделенные API-учётные данные открывают только чат-интерфейс, соответствующий выбранной модели, а вызовы отдельно списываются с вашего баланса платформы. Каждый Application приобретается, продлевается и управляется отдельно.

## Пароли, учётные данные и последующая конфигурация

Учётные данные доступа задаются до первого запуска. При автоматическом создании используются случайные учётные данные, пользовательский пароль должен содержать не менее 16 символов, а OpenClaw Token — не менее 32 символов. Черновик не сохраняет пароли; после переключения страницы может потребоваться ввести их повторно. После развёртывания просматривать учётные данные доступа могут только владелец Application и администраторы.

API-учётные данные модели каждого экземпляра не используются повторно, их срок действия продлевается вместе с продлением развёртывания, а при удалении экземпляра они отзываются. Если при первом развёртывании модели платформы не были подключены, можно выбрать модель платформы на странице конфигурации этого Application и выполнить повторное развёртывание; платформа обновит модель по умолчанию, сохранив сессии и другие нативные настройки. После этого изменяйте модели и каналы в нативной консоли; если выбирается модель другого сервиса, сначала настройте авторизацию соответствующего интерфейса в управлении учётными данными платформы или используйте соответствующие учётные данные. Обычное повторное развёртывание не перезаписывает нативные настройки. Среды развёртывания, не прошедшие проверку публикации, временно отклоняют новые развёртывания; обратитесь в поддержку.

## Дополнительные компоненты развёртывания

После отметки A2A шаблон развёртывания запустит нативный шлюз Hermes A2A и предоставит токен владельца на странице управления. После отметки EnvarPay дополнительно будут установлены независимый сервисный контейнер и постоянный реестр, при этом сначала необходимо включить A2A. Изначально EnvarPay имеет только учётные данные доступа владельца, не имеет сервиса или платёжной идентичности и не взимает плату и не совершает покупки автоматически. Оба параметра не регистрируют экземпляр в Envar автоматически; для существующего экземпляра можно перейти к конфигурации со страницы управления, включить их и затем выполнить повторное развёртывание. Уже включённые компоненты пока нельзя отключить в этом мастере.

После включения A2A и готовности экземпляра карточка адреса доступа на странице управления отобразит копируемый адрес Agent Card. Нативный Hermes A2A использует отдельный публичный адрес; адрес входа Dashboard нельзя использовать в качестве адреса Agent Card. Если одновременно включён EnvarPay, на странице управления также будет отображаться соответствующий «адрес подключения Envar»; при подключении сервиса к Envar приоритетно копируйте этот URL.

## Версии и данные

На странице конфигурации отображается текущая опубликованная версия образа. Новые экземпляры используют текущую опубликованную версию сервиса; существующие экземпляры не заменяются автоматически при обновлении каталога. Повторное развёртывание применит текущую версию сервиса, поэтому сначала создайте резервную копию и подтвердите требования к обновлению используемой версии.

Для каждого экземпляра по умолчанию предоставляются 1 CPU, лимит памяти 2 GiB и 10 GiB постоянного хранилища. При перезапуске данные экземпляра сохраняются. При самостоятельном удалении развёртывания или при сборке после истечения срока хранения будет удалено, поэтому заранее экспортируйте данные, которые необходимо сохранить.

## Продление и истечение срока

Продлите срок на странице покупки текущего Application, и срок действия будет увеличен в соответствии с действующими правилами платформы по длительности. После истечения срока точка доступа приостанавливается, при продлении в льготный период доступ восстанавливается; после льготного периода экземпляр и данные будут собраны. Ориентируйтесь на время истечения, статус оплаты и уведомления об удалении на странице управления.

## Вход в интерфейс управления

На странице управления развёртыванием скопируйте адрес Dashboard, имя пользователя `admin` и пароль, затем откройте адрес и войдите. Информация для входа предоставляется только владельцу этого Application и администраторам платформы. Модели, навыки и каналы настраиваются в нативном интерфейсе Hermes.

## Часто задаваемые вопросы

- **Почему новый экземпляр ещё не может отвечать?** Завершение развёртывания означает только готовность контейнера. Если при развёртывании был отключён доступ к моделям платформы, необходимо выбрать модель платформы на странице конфигурации и выполнить повторное развёртывание либо самостоятельно настроить модель и учётные данные в нативном интерфейсе.
- **Устанавливаются ли дополнительные плагины или fallback моделей?** По умолчанию не добавляются, настройте их в нативном интерфейсе по необходимости.
- **Как обновить существующий экземпляр?** Исходные Application и заказ сохраняются, при повторном развёртывании используется текущая версия сервиса; перед обновлением сначала создайте резервную копию данных и проверьте совместимость версий.
- **Что делать при ошибке запуска?** Сначала просмотрите журналы и события развёртывания, настройте модель после подтверждения готовности экземпляра. Не раскрывайте пароль экземпляра и ключи в публичных комментариях или скриншотах.
