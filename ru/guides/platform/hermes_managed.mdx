Ace Data Cloud предоставляет вход для частного развертывания Hermes Agent. Этот вход является контролируемым сервисом, доступность и доступные ресурсы определяются текущим отображением в консоли.

## Шаги использования

1. Найдите на платформе **Частное развертывание Hermes Agent**.
2. Выберите доступные конфигурации и создайте сервис в соответствии с подсказками на странице.
3. Дождитесь отображения статуса готовности на платформе.
4. Используйте предоставленный на странице вход и учетные данные для доступа к экземпляру.
5. Сначала отправьте `Reply only OK`, затем начните реальную задачу.

Модель, учетные данные, хранение и действия по удалению определяются страницей создания и подтверждающим окном; не используйте YAML из локального руководства Hermes как контракт для развертывания на платформе. Перед удалением сначала экспортируйте данные, которые необходимо сохранить.

Если консоль не отображает вход для создания, это означает, что текущая учетная запись еще не открыла этот сервис, можно использовать [Интерактивный помощник Hermes](https://platform.acedata.cloud/documents/hermes-wizard-integration) или [Ручную настройку](https://platform.acedata.cloud/documents/hermes-manual-integration).
