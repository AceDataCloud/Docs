description: "Platform API guide - Ace Data Cloud"
---

Hermes Agent подключается к Ace Data Cloud через протокол OpenAI Chat Completions. Выберите один из способов конфигурации:

| Способ конфигурации         | Руководство                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Интерактивный гид `hermes model` | [Конфигурация с помощью гида](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Ручная конфигурация `config.yaml`  | [Ручная конфигурация](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Частное развертывание на платформе              | [Управляемое развертывание](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Общие параметры для локального подключения:

- Базовый URL: `https://api.acedata.cloud/v1`
- Транспорт: `chat_completions`
- Провайдер: `custom:acedatacloud`
- API Key: Получите из [списка приложений](https://platform.acedata.cloud/console/applications)

Оба способа локального подключения в конечном итоге записываются в `~/.hermes/config.yaml`, не настраивайте их повторно.

Вернуться в [Центр конфигурации Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
