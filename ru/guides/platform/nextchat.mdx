[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (ранее ChatGPT-Next-Web) — это клиент с открытым исходным кодом для ИИ, который можно развернуть на Vercel, Cloudflare или Docker. Он поддерживает пользовательские OpenAI-совместимые конечные точки, поэтому может быть подключён к Ace Data Cloud. В этой статье описан процесс настройки.

## Процесс получения

Чтобы подключить Ace Data Cloud в NextChat, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), получите ваш API Token и сохраните его для дальнейшего использования.

![Получение Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа с предложением зарегистрироваться и войти; после входа или регистрации вы автоматически вернётесь на текущую страницу.

При первом получении предоставляется бесплатный лимит, позволяющий бесплатно опробовать модельные сервисы Ace Data Cloud.

## Скачать NextChat

Можно использовать настольную версию (скачать `.exe` / `.dmg` / AppImage на [странице Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), [онлайн Web-версию](https://app.nextchat.club/) или самостоятельно развернуть на Vercel / Cloudflare / Docker (см. расширенный раздел ниже).

## Настройка Ace Data Cloud

Запустите NextChat и перейдите в **Настройки → Модельные сервисы**:

| Поле          | Значение                           | Описание                              |
| ----------- | --------------------------- | ------------------------------- |
| Поставщик модельных сервисов       | `OpenAI`                    | Использование OpenAI-совместимого протокола                  |
| Адрес OpenAI API | `https://api.acedata.cloud` | Укажите только корневой домен, **без `/openai`, без `/v1`** |
| API Key     | Ваш Ace Data Cloud Token     | Token, скопированный из консоли                    |

![Интерфейс настройки Ace Data Cloud в NextChat](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat автоматически добавит `/v1/chat/completions` после адреса API, поэтому достаточно указать только корневой домен:

| Адрес API                                  | Фактический запрос                                                      | Результат                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Верно                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (в `/openai` нет `/v1`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

В поле «Пользовательские названия моделей» укажите модели, разделяя их английскими запятыми. NextChat поддерживает специальный синтаксис: `+название модели` для добавления, `-название модели` для скрытия, `название модели=отображаемое имя` для настройки отображаемого имени, `-all` для предварительного скрытия всех. Рекомендуемый самый чистый вариант записи:

```text
-all,+MODEL_ID=Отображаемое название
```

## Выбор модели

Каталог моделей будет постоянно обновляться. В первую очередь используйте список моделей, автоматически загружаемый клиентом; если требуется ручной ввод, сначала выполните запрос `GET https://api.acedata.cloud/v1/models`, чтобы получить актуальные ID моделей, затем выберите их в соответствии с поддерживаемыми клиентом возможностями контекста, изображений и вызова инструментов.

## Проверка подключения

Если вы не уверены, связана ли проблема с NextChat или сетью, можно сначала напрямую проверить конечную точку с помощью curl (замените `{token}` на ваш Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Возврат OpenAI-совместимого объекта `chat.completion` означает, что Token и конечная точка готовы; если возвращается `HTTP 403 used_up`, это означает, что Token действителен, но баланс недостаточен — пополните его в [консоли](https://platform.acedata.cloud/console/applications).

## Расширенно: развёртывание в один клик на собственном домене

NextChat поддерживает развёртывание собственного ИИ-сайта. Например, с Docker (замените `{token}` на ваш Token):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=显示名称" \
  yidadaa/chatgpt-next-web
```

При развёртывании на Vercel / Cloudflare достаточно настроить в переменных окружения проекта те же `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS`. `CODE` поддерживает несколько паролей доступа, разделённых английскими запятыми, что удобно для учёта использования по пользователям. Полное описание перечисленных выше переменных окружения (`BASE_URL` по умолчанию — `https://api.openai.com`, синтаксис `+/-/=/-all/+all` для `CUSTOM_MODELS`) приведено в [официальном README NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Часто задаваемые вопросы

### Появляется 404 Not Found

Обычно адрес API указан как `.../openai` или `.../openai/v1`. Измените его на `https://api.acedata.cloud`, чтобы NextChat самостоятельно добавил `/v1/chat/completions`.

### Добавленная модель отсутствует в выпадающем списке моделей

Проверьте формат `CUSTOM_MODELS`: перед каждой моделью должен быть `+`; если использовался `-all`, убедитесь, что нужные модели затем снова добавлены с помощью `+`.

### Появляется 401 Unauthorized

Убедитесь, что в API Key вставлен Token Ace Data Cloud (без префикса `Bearer` и лишних пробелов), а баланс соответствующего приложения достаточен.
