Официальное расширение OpenCode IDE поддерживает редакторы VS Code, Cursor, Windsurf, VSCodium и использует локальный runtime и конфигурацию Provider OpenCode. Расширение IDE использует локальный CLI Provider, но цепочка запросов может изменяться в зависимости от версии редактора; при первом подключении зафиксируйте версию и завершите минимальную проверку.

## Конфигурация Provider

Сначала следуйте [конфигурации OpenCode Terminal](https://platform.acedata.cloud/documents/opencode-terminal-integration) для настройки Ace Data Cloud Provider в `opencode.json` или `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Установка IDE Extension

1. В интегрированном терминале редактора выполните `opencode`, чтобы автоматически установить расширение по официальному процессу; также можно установить вручную из соответствующего Marketplace.
2. Перезагрузите редактор.
3. Инициируйте `Reply only OK` из OpenCode Extension.
4. Выполните еще раз запрос, который требует чтения файла или изменения кода, чтобы подтвердить, что IDE Extension использует тот же Provider и модель.

## Текущие ограничения

- Возможности Provider исходят из OpenCode runtime и не означают, что хост-редактор нативно поддерживает Ace Data Cloud.
- Версии расширений VS Code и его форков могут отличаться, их следует фиксировать отдельно.
- Успешный обычный чат не может заменить проверку чтения файлов, редактирования и вызова инструментов.
