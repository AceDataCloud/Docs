Cursor в настоящее время предоставляет OpenAI API Key и настройку **Override OpenAI Base URL**, что позволяет подключаться к совместимым с OpenAI сервисам. Эта возможность существует, но разные версии по-разному обрабатывают `/chat/completions`, `/responses`, списки моделей, а также режимы Agent/Composer.

Совместимость различных версий Cursor, операционных систем и режимов запросов может различаться. Пожалуйста, выполните фактическую проверку режима в соответствии с настройками на этой странице, не делая выводов о доступности всех функций на основе одного успешного чата.

## Что в настоящее время гарантирует Cursor официально BYOK

Согласно [документации Cursor по Bring your own API key](https://cursor.com/help/models-and-usage/api-keys):

- Поддерживаются учетные данные OpenAI, Anthropic, Google, Azure OpenAI и AWS Bedrock;
- Пользовательский API Key используется только для чат-моделей, Tab completion продолжает использовать встроенные модели Cursor;
- API Key не сохраняется на серверах Cursor, но каждый запрос отправляет Key на сервер Cursor для окончательной сборки prompt;
- При использовании собственного Key политика Zero Data Retention Cursor не применяется, обработка данных осуществляется в соответствии с политикой выбранного провайдера.

## Настройка

1. Откройте Cursor Settings → Models.
2. Введите ваш Ace Data Cloud API Token в поле OpenAI API Key.
3. Включите **Override OpenAI Base URL**, введите `https://api.acedata.cloud/v1`.
4. Выберите или добавьте точный ID модели, совместимый с текущим протоколом Cursor.
5. Сначала отправьте `Reply only OK`, затем протестируйте режимы Ask/Edit/Agent и другие, которые вы фактически используете.

## Текущие ограничения

- Пользовательский API Key используется только для чат-моделей, Tab completion продолжает использовать встроенные модели Cursor.
- Cursor все еще может завершать окончательную сборку prompt на сервере; пожалуйста, оцените путь данных в соответствии с официальным описанием конфиденциальности.
- Base URL Override может перекрывать только часть запросов или переключаться между Chat Completions/Responses из-за изменений в версиях.
- Не следует утверждать, что Agent, Auto, Composer или фоновые задачи подключены, основываясь только на успешном запросе чата.

## Полная проверка совместимости

Если вы планируете долгосрочное использование в производственном рабочем процессе, выполните следующие проверки:

1. Зафиксируйте версию Cursor и операционную систему;
2. Проведите реальный клиентский smoke-тест для этой версии и зафиксируйте окончательный протокол и путь запроса;
3. Успешный запрос Chat Completions для точной модели;
4. Убедитесь, что вызовы инструментов и запросы Agent действительно проходят через целевой endpoint;
5. Проверьте объем и списание;
6. Ясно зафиксируйте, проходит ли запрос через сервер Cursor и соответствующие ограничения конфиденциальности.

После обновления клиента эти проверки следует повторить, чтобы убедиться, что протокол запросов, вызовы инструментов и путь данных не изменились.
