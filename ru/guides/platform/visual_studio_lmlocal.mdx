LMLocal — это расширение для Visual Studio 2022/2026, официально поддерживающее OpenAI-compatible API и пользовательский базовый URL. Точка конфигурации может изменяться с версиями расширения; при первом подключении рекомендуется зафиксировать версию и проверить фактическое редактирование, вызовы инструментов и учет использования.

## Конфигурация

1. Установите LMLocal из Visual Studio Marketplace или официального репозитория.
2. В Providers добавьте Custom/OpenAI-compatible Provider.
3. В поле Base URL укажите `https://api.acedata.cloud/v1`.
4. В поле Auth Key введите ваш Ace Data Cloud API Token.
5. В поле Model укажите точный ID модели, поддерживающей Chat Completions, из каталога моделей.
6. После сохранения отправьте `Reply only OK`, затем протестируйте процесс редактирования проекта еще раз.

## Текущие ограничения

- Этот гид охватывает только LMLocal и не представляет собой общую конфигурацию для других расширений Visual Studio.
- Разные версии могут по-разному обрабатывать запросы на чат, редактирование, сборку и тестирование; каждую модель необходимо проверять отдельно.
- Если клиент автоматически добавляет `/v1` или путь конечной точки, избегайте дублирования пути.
