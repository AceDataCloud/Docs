Получайте полную информацию об одной конечной точке API по API ID — по сравнению с [интерфейсом списка](https://platform.acedata.cloud/documents/platform-api-list) дополнительно включает поля `definition` (схема OpenAPI 3.0), `service` (сведения о принадлежащем сервисе) и `products` (связанные продукты).

Подходит для таких сценариев, как автоматическая генерация SDK, передача описаний инструментов в LLM Agent, динамический рендеринг сайтов документации и других.

> ℹ️ Этот интерфейс относится к **API управления платформой AceDataCloud**, единый префикс: `https://platform.acedata.cloud/api/v1/`. Полный индекс интерфейсов см. в разделе [Получение списка документов платформы AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Обзор интерфейса

| Пункт   | Содержание                                                    |
| --- | ----------------------------------------------------- |
| Метод  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}` |
| Аутентификация  | ❌ Публичный                                                  |

В настоящее время доступны как `/apis/{id}`, так и `/apis/{id}/`; в примерах используется единый формат без завершающего слеша.

## Описание аутентификации

Этот интерфейс **полностью публичный, не требует токена учетной записи или состояния входа**.

## Параметры пути

| Параметр       | Тип   | Обязательный  | Описание                    |
| -------- | ---- | --- | --------------------- |
| `api_id` | UUID | ✅   | API ID (формат UUID, псевдонимы не поддерживаются) |

## Примеры запросов

### cURL

```shell
curl 'https://platform.acedata.cloud/api/v1/apis/afc7917f-d89f-4dc9-95c2-863936b02cad' \
  -H 'accept: application/json'
```

### Python

```python
import requests

api_id = "afc7917f-d89f-4dc9-95c2-863936b02cad"
resp = requests.get(
    f"https://platform.acedata.cloud/api/v1/apis/{api_id}",
    headers={"accept": "application/json"},
    timeout=10,
)
api = resp.json()
print(f"API: {api['title']}")
print(f"路径: {api['path']}")
print(f"所属服务: {api['service']['title']} ({api['service']['alias']})")
print(f"OpenAPI 路径数: {len(api.get('definition', {}).get('paths', {}))}")
```

### Node.js

```javascript
const apiId = 'afc7917f-d89f-4dc9-95c2-863936b02cad'
const r = await fetch(`https://platform.acedata.cloud/api/v1/apis/${apiId}`)
const api = await r.json()
console.log(api.title, api.path, api.service.title)
```

## Описание полей ответа

Интерфейс сведений дополнительно включает, помимо [полей интерфейса списка](https://platform.acedata.cloud/documents/platform-api-list):

| Поле           | Тип     | Описание                                                                                          |
| ------------ | ------ | ------------------------------------------------------------------------------------------- |
| `service`    | object | Основная информация о принадлежащем сервисе: `id`, `title`, `type`, `alias`                                                       |
| `products`   | array  | Список связанных продуктов (обычно пуст, используется операционной стороной)                                                                         |
| `definition` | object | **Полное определение спецификации OpenAPI 3.0**, включает `paths`, `components`, `info` и другое; может напрямую передаваться в `openapi-generator` для генерации клиентского кода |

## Обработка ошибок

| HTTP | code        | Значение                 |
| ---- | ----------- | ------------------ |
| 400  | `invalid`   | `api_id` не является допустимым UUID |
| 404  | `not_found` | API не существует или был отключен        |

## Практические советы

- **Поле `definition` очень большое**: схема OpenAPI одного API может содержать сотни строк JSON. Если нужен только индекс сервисов и Schema не требуется, следует использовать [интерфейс списка](https://platform.acedata.cloud/documents/platform-api-list) вместо него.
- **Распространенный способ генерации SDK**:
  ```shell
  # 拿到 OpenAPI 文件
  curl -s 'https://platform.acedata.cloud/api/v1/apis/<api_id>' | jq '.definition' > openapi.json

  # 用 openapi-generator-cli 生成 Python 客户端
  openapi-generator-cli generate -i openapi.json -g python -o ./client
  ```
- **Отслеживание изменений API**: поле `updated_at` — это время последнего изменения schema. Подписка на это поле позволяет автоматически повторно генерировать SDK при изменениях OpenAPI.
