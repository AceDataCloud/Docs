Inferpal — это расширение для Visual Studio 2022/2026, официально поддерживающее подключение к сервисам, совместимым с OpenAI. Версия расширения может повлиять на редактирование, вызовы инструментов и учет использования; при первом подключении зафиксируйте версию и выполните минимальную проверку, описанную ниже.

## Настройка

1. Установите Inferpal из Visual Studio Marketplace или официального репозитория.
2. Откройте **Настройки Inferpal → Подключение**.
3. В поле Provider выберите OpenAI-compatible.
4. В поле Base URL укажите `https://api.acedata.cloud/v1`.
5. В поле API Key введите ваш Ace Data Cloud API Token.
6. В поле Model укажите точный ID модели, поддерживающей Chat Completions, из каталога моделей.
7. После сохранения отправьте `Reply only OK`, затем выполните еще один запрос с контекстом кода.

## Текущие ограничения

- Этот гид охватывает только Inferpal и не означает, что встроенный Copilot Visual Studio или другие расширения поддерживают те же поля.
- Разные версии могут автоматически добавлять путь к Base URL; если запрос не удался, сначала проверьте, попадает ли окончательный запрос на конечную точку Chat Completions.
- До завершения фиксированной версии E2E не гарантируется, что все режимы редактирования, дополнения или вызова инструментов будут доступны.
