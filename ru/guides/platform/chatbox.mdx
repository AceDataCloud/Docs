[ChatBox](https://chatboxai.app/) — это клиент с открытым исходным кодом для AI, поддерживающий Windows, macOS, Linux, iOS, Android и Web. Он поддерживает пользовательских провайдеров типа «OpenAI API», поэтому может напрямую подключаться к Ace Data Cloud. В этой статье описан процесс настройки.

## Процесс подачи заявки

Чтобы подключить Ace Data Cloud в ChatBox, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), получите ваш API Token и сохраните его для дальнейшего использования.

![Получение API Key Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти в систему; после входа или регистрации вы автоматически вернётесь на текущую страницу.

При первой подаче заявки предоставляется бесплатный лимит, с которым можно бесплатно опробовать модельные сервисы Ace Data Cloud.

## Скачать ChatBox

Перейдите на [официальный сайт ChatBox](https://chatboxai.app/), чтобы скачать версию для вашей платформы, или сразу используйте не требующую установки [Web-версию](https://web.chatboxai.app/):

- Настольные: Windows `.exe`, macOS `.dmg` (отдельно для Intel / Apple Silicon), Linux AppImage
- Мобильные: App Store, Google Play, прямая ссылка на Android с официального сайта

## Настройка Ace Data Cloud

Запустите ChatBox, перейдите в **Настройки → Модели → Добавить пользовательского Provider**, установите для **API Mode** значение **OpenAI API Compatible**, затем заполните:

| Поле       | Значение                           | Описание                                      |
| -------- | --------------------------- | --------------------------------------- |
| API-ключ   | Ваш Ace Data Cloud Token     | Token, скопированный из консоли                            |
| API Host | `https://api.acedata.cloud` | Укажите только корневой домен, **не добавляйте `/openai` или `/v1`**         |
| API Path | `/v1/chat/completions`      | По умолчанию в ChatBox указан `/chat/completions`, необходимо вручную изменить на этот |

![Экран настройки Provider Ace Data Cloud в ChatBox](https://cdn.acedata.cloud/3789c8e3dd4d.png)

Путь запроса ChatBox — это `{API Host} + {API Path}`, поэтому в Host достаточно указать только корневой домен:

| API Host                              | Итоговый запрос                                                      | Результат                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Правильно                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (в `/openai` нет `/v1`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

ChatBox не вызывает автоматически `/v1/models`; необходимо вручную указать ID моделей (по одному в строке) в поле «Пользовательские модели» в нижней части страницы настроек моделей. После сохранения их можно будет выбрать в выпадающем списке моделей в интерфейсе диалога. Переключатели возможностей, контекстное окно и лимит вывода необходимо указывать в соответствии с текущими условиями выбранной модели, не копируйте значения других моделей.

## Выбор модели

Каталог моделей будет постоянно обновляться. В первую очередь используйте список моделей, автоматически загружаемый клиентом; если требуется ручной ввод, сначала отправьте запрос `GET https://api.acedata.cloud/v1/models`, чтобы получить текущие ID моделей, затем выберите их в соответствии с поддерживаемыми клиентом возможностями контекста, изображений и вызова инструментов.

## Проверка подключения

Если вы не уверены, проблема в ChatBox или в сети, сначала можно напрямую проверить эндпоинт с помощью curl (замените `{token}` на ваш Token):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Возврат совместимого с OpenAI объекта `chat.completion` означает, что Token и эндпоинт готовы к использованию; если возвращается `HTTP 403 used_up`, это означает, что Token действителен, но баланса недостаточно — пополните счёт в [консоли](https://platform.acedata.cloud/console/applications).

## Частые вопросы

### Появляется 404 Not Found

Обычно это происходит, если в API Host дополнительно указан `/openai` или `/v1`. В Host укажите только `https://api.acedata.cloud`, а путь оставьте стандартным: `/v1/chat/completions`.

### Появляется 401 / token_mismatched

Убедитесь, что в поле «API-ключ» вставлен Token Ace Data Cloud (без префикса `Bearer` и лишних пробелов), а на балансе соответствующего приложения достаточно средств.

### В выпадающем списке моделей нет моделей

ChatBox не загружает список моделей автоматически; необходимо вручную указать ID моделей в поле «Пользовательские модели» и сохранить.

### Хочу генерировать изображения в ChatBox

Генерация изображений Ace Data Cloud — это отдельный Images API (`/openai/images/generations`) с путём, отличающимся от интерфейса диалогов, поэтому вход для изображений ChatBox нельзя подключить напрямую. Если вам нужно рисовать изображения, обратитесь к [документации API генерации изображений](https://platform.acedata.cloud/documents/openai-images-generations) для вызова через curl / SDK.
