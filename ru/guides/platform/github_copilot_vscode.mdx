Официальная документация GitHub Copilot BYOK перечисляет VS Code как поддерживаемый локальный клиент и поддерживает OpenAI-compatible Provider. Версия VS Code, корпоративная политика и видимость модели могут повлиять на конечную точку; для первого подключения проверьте фактический запрос ниже.

## Область конфигурации

1. Убедитесь, что ваша учетная запись или организация GitHub Copilot активировала функцию BYOK/Custom Models.
2. В управлении моделями Copilot в VS Code добавьте OpenAI-compatible Provider.
3. В поле Base URL укажите `https://api.acedata.cloud/v1`.
4. В поле API Key укажите ваш Ace Data Cloud API Token.
5. В поле Model укажите точный ID модели, совместимой с выбранным протоколом, из каталога моделей.
6. В Copilot Chat отправьте `Reply only OK`, затем протестируйте еще раз запрос с контекстом рабочего пространства.

## Текущие ограничения

- Конфигурация Copilot App, CLI, GitHub Desktop, Enterprise BYOK отличается от конфигурации VS Code, и шаги для других клиентов не следует напрямую применять к VS Code.
- Политика организации может запрещать индивидуальным пользователям добавлять Provider или модели.
- Завершение табуляции, Chat, Agent и фоновые задачи могут использовать разные пути моделей, их следует проверять отдельно.
