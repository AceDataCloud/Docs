FreeAIr — это открытое расширение для Visual Studio 2022/2026, официально заявляющее о возможности подключения к любому API, совместимому с OpenAI. Поведение запросов может изменяться в зависимости от версии расширения; при первом подключении рекомендуется зафиксировать версию и выполнить минимальную проверку, описанную ниже.

## Настройка

1. Установите FreeAIr из Visual Studio Marketplace или официального репозитория.
2. Откройте настройки FreeAIr и добавьте подключение, совместимое с OpenAI.
3. В поле Endpoint укажите `https://api.acedata.cloud/v1`.
4. В поле Token введите ваш Ace Data Cloud API Token.
5. В поле Model укажите точный ID модели, поддерживающей Chat Completions, из каталога моделей.
6. После сохранения отправьте `Reply only OK`, затем протестируйте запрос с контекстом проекта.

## Текущие ограничения

- Данный гид охватывает только FreeAIr и не означает, что встроенный Copilot в Visual Studio поддерживает произвольный базовый URL.
- Версия расширения может изменить способ соединения endpoint; при проверке следует сверять окончательный URL запроса.
- Вызовы инструментов и возможности MCP внутри расширения требуют отдельной проверки, не могут быть заменены успешным обычным чатом.
