title: "Получение списка API в рамках сервиса платформы AceDataCloud"

---

Возвращает постранично текущие включённые и не устаревшие API данного сервиса через Service UUID. Если есть только alias, сначала вызовите [детали сервиса](https://platform.acedata.cloud/documents/platform-service-detail), чтобы получить `id`.

## Обзор интерфейса

| Параметр   | Содержимое                                                          |
| --- | ------------------------------------------------------------------- |
| Метод  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Авторизация  | Публичный, токен учётной записи не требуется                                                           |
| Пагинация  | `count` + `items`                                                   |

## Параметры

| Параметр           | Расположение    | Обязательный  | Описание                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Да   | Service UUID, alias не поддерживается           |
| `limit`      | query | Нет   | Количество записей на странице, максимум 100                      |
| `offset`     | query | Нет   | Смещение пагинации                            |
| `ordering`   | query | Нет   | Выражение сортировки Django; рекомендуется `rank` или `-rank` |

Текущий интерфейс не поддерживает фильтрацию по `stage`; он уже исключает API со статусом `Deprecated`.

```shell
export SERVICE_ID='Ваш Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Элементы списка используют ту же индексную структуру, что и [список API платформы](https://platform.acedata.cloud/documents/platform-api-list), и в настоящее время включают `definition`. Если требуется стабильная точка входа для отдельного API, продолжайте вызывать `/api/v1/apis/{api_id}`.

## Обработка ошибок

- Сервис не существует или не виден на текущем сайте: `404`.
- `service_id` должен быть UUID; alias не будет разрешён в этом action.
