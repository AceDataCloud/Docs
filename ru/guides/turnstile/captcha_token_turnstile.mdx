В этой статье будет представлена инструкция по интеграции API распознавания протокола Cloudflare Turnstile, которая позволяет пользователям обойтись без распознавания и нажатия на капчу Turnstile, просто отправив Website Key для автоматической декодировки на сервере и завершения проверки.

## Процесс Заявки

Чтобы использовать API распознавания протокола Cloudflare Turnstile, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications) и получите ваш API Token для резервного копирования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вас пригласят зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно запрашивать отдельный токен для каждого сервиса.** При первом запросе предоставляется бесплатный лимит для тестирования; если лимит исчерпан, вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Cloudflare Turnstile Протокол Распознавания API →](https://platform.acedata.cloud/documents/captcha-token-turnstile)

## Основное Использование

Сначала ознакомьтесь с основным способом использования, который заключается в вводе URL сайта, на котором необходимо обработать капчу Turnstile, чтобы получить обработанный результат. Сначала нужно просто передать поле `website_url`, наш пример сайта: `https://react-turnstile.vercel.app`, нам нужно получить `website_key` на странице `website_url`. Для этого откройте эту веб-страницу, нажмите F12 для входа в консоль, выполните глобальный поиск по элементам на странице `cf-turnstile`, и вы найдете контейнерный элемент, содержащий Turnstile, где строка, соответствующая `data-sitekey`, является значением `website_key`.

Установленные заголовки запроса включают:

- `accept`: формат ответа, который вы хотите получить, здесь укажите `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после запроса.

Также установленное тело запроса включает:

- `website_url`: URL сайта, на котором необходимо обработать капчу.
- `website_key`: идентификатор сайта (sitekey) в Cloudflare Turnstile.
- `action`: необязательный параметр, который нужно передавать только если целевой сайт настроил пользовательский `action` для компонента Turnstile.
- `cdata`: необязательный параметр, который нужно передавать только если целевой сайт настроил пользовательский `cData` для компонента Turnstile.

Нажмите кнопку «Попробовать», чтобы провести тестирование, и мы получим следующий результат:

```json
{
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......",
  "started_at": 1784885653.0,
  "finished_at": 1784885665.4,
  "elapsed": 12.4
}
```

Возвращаемый результат содержит несколько полей, описание которых приведено ниже:

- `token`: результат проверки после обработки задачи капчи Cloudflare Turnstile.
- `started_at`, `finished_at`: время начала обработки запроса и получения результата, Unix временная метка (секунды, с плавающей точкой).
- `elapsed`: общее время обработки (секунды).

Мы видим, что получили результат проверки капчи Turnstile, который затем можно использовать для POST или имитации отправки на целевой сайт, одноразовое использование, срок действия 120 секунд, рекомендуется использовать в течение 60 секунд. При отправке обычно этот токен передается как параметр `cf-turnstile-response` на целевой сайт, код Python для вызова проверки токена приведен ниже:

```python
import requests

token = '{token}'

data = {
    'cf-turnstile-response': token
}

response = requests.post('https://react-turnstile.vercel.app', data=data)

if response.status_code == 200:
    print(response.text)
```

Если вы хотите сгенерировать соответствующий код интеграции, вы можете просто скопировать его, например, код CURL будет следующим:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/token/turnstile' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
  "website_url": "https://react-turnstile.vercel.app"
}'
```

Код интеграции на Python будет следующим:

```python
import requests

url = "https://api.acedata.cloud/captcha/token/turnstile"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "website_key": "0x4AAAAAAADnPIDROrmt1Wwj",
    "website_url": "https://react-turnstile.vercel.app"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Асинхронный Режим (async)

По умолчанию API является синхронным и блокирующим: один запрос будет ждать, пока токен не будет обработан, прежде чем вернуться. Если вы делаете многократную ротацию кодов (multi-solver rotation) и хотите «получить task_id сразу после отправки задачи, чтобы сначала переключиться на другие кодеры, а затем вернуться за результатом», вы можете передать `async: true` в теле запроса.

После передачи `async: true` интерфейс немедленно вернет `task_id`, не блокируя ожидание:

```json
{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "trace_id": "2efa9340-b21b-4e26-9e14-4aac95f343ab"
}
```

Если вы хотите активно отслеживать прогресс, вы можете использовать этот `task_id` для запроса `POST /captcha/tasks` (рекомендуется каждые 3-5 секунд). Этот интерфейс не будет инициировать или продвигать обработку задачи; даже если вы не запрашиваете, теряете соединение или выходите из клиента, сервер продолжит обработку:

```shell
curl -X POST 'https://api.acedata.cloud/captcha/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002"
}'
```

Во время обработки будет возвращен `status: processing`; по завершении обработки будет возвращен `status: ready` и токен:

```json
{
  "success": true,
  "task_id": "61138bb6-19aa-11ec-a9c8-0242ac110002",
  "status": "ready",
  "token": "0.mNQ2f9uP6mQ0y3H5Q8bqO7iM......"
}
```

Условия оплаты: в асинхронном режиме создание задачи и чтение статуса «в обработке» не подлежат оплате; **клиент оплачивает один раз при первом успешном чтении результата** (что соответствует существующему поведению и ценам в синхронном режиме). Сервер будет самостоятельно продвигать задачу, но не будет взимать плату заранее, если задача завершится на сервере. Если задача не будет успешно завершена в течение 120 секунд, она будет завершена с HTTP 504 `timeout`, без оплаты. `/captcha/tasks` не отвечает за продвижение задач.

> Примечание: Cloudflare Turnstile в настоящее время не поддерживает собственные прокси (Bring Your Own Proxy), поэтому этот интерфейс не принимает параметр `proxy`; если он будет передан, будет возвращена ошибка `400 invalid_proxy`.

## Обработка Ошибок

При вызове API, если возникнет ошибка, API вернет соответствующий код ошибки и информацию. Например:
- `400 token_mismatched`：Неверный запрос, возможно из-за отсутствующих или недействительных параметров.
- `400 invalid_proxy`：Неверный запрос, прокси не поддерживается для этого типа капчи.
- `401 invalid_token`：Неавторизован, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`：Внутренняя ошибка сервера, что-то пошло не так на сервере.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
