Google SERP (страница результатов поисковой системы) — это страница результатов, которую пользователи видят после ввода запроса в поисковой системе Google. Она отображает естественные результаты поиска, рекламу, специальные выписки, графики знаний, а также различные виды контента, такие как изображения и видео, с целью предоставить пользователям наиболее релевантную информацию.

В этой статье подробно рассматривается Google SERP API, который может предоставить результаты по запросу, введенному в поисковой системе Google. Содержимое результатов также включает множество типов, таких как специальные выписки, графики знаний и изображения.

В этом документе будет представлена инструкция по интеграции Google SERP API.

## Процесс подачи заявки

Чтобы использовать Google SERP API, необходимо сначала перейти на соответствующую страницу [Google SERP API](https://platform.acedata.cloud/documents/44c86226-8eaa-49bf-85f3-1fae8d2e23f1) и подать заявку на соответствующую услугу. После перехода на страницу нажмите кнопку «Acquire», как показано на изображении:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа, где вам будет предложено зарегистрироваться и войти в систему. После регистрации и входа вы автоматически вернетесь на текущую страницу.

При первой подаче заявки предоставляется бесплатный лимит, который позволяет бесплатно использовать этот API.

## Основное использование

Сначала ознакомьтесь с основным способом использования, который заключается в том, что, вводя тип ресурса поиска и ключевые слова, вы можете получить результаты поиска, просто передав поле `query` и указав соответствующую модель.

Например, чтобы найти информацию о «apple inc», мы можем заполнить соответствующее содержимое на интерфейсе, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Как видно, здесь мы настроили заголовки запроса, включая:

- `accept`: формат ответа, который вы хотите получить, здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

Кроме того, настроено тело запроса, включая:

- `type`: тип ресурса поиска, в настоящее время поддерживается только шесть типов, по умолчанию — `search`.
- `query`: ключевое слово для поиска.
- `country`: страна, в которой будут отображаться результаты поиска, по умолчанию — США (US).
- `language`: язык результатов поиска, по умолчанию — английский (en).
- `range`: временной диапазон результатов поиска, по умолчанию без ограничений.
- `number`: размер страницы результатов поиска, по умолчанию — 10.
- `page`: номер страницы результатов поиска, по умолчанию — 1.

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## 自定义搜索结果时间范围
本文还可以自定义 поиск результатов времени диапазон, включая пять видов, а именно `qdr:h` (последний час), `qdr:d` (последний день), `qdr:w` (последняя неделя), `qdr:m` (последний месяц), по умолчанию без ограничений, мы можем передать соответствующий временной диапазон через `range`, например, здесь установлено `qdr:d`, что означает поиск результатов за последний день, поэтому вводим следующее:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

Соответствующий код выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## Настройка пагинации результатов поиска

Этот API также поддерживает настройку пагинации результатов поиска, `number` и `page` обозначают размер страницы и номер страницы, в этой статье будет установлено, что на одной странице будет 20 результатов поиска для пагинации, конкретная информация, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

> Обратите внимание: когда количество результатов на странице превышает 10, списываемые баллы удваиваются.

Код выглядит следующим образом:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
}'
```
