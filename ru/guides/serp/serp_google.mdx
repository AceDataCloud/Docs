Google SERP (Search Engine Results Page) — это страница результатов, которую пользователи видят после ввода запроса в поисковой системе Google. Она отображает органические результаты поиска, рекламу, избранные фрагменты, граф знаний, а также различные типы контента, такие как изображения и видео, с целью предоставить пользователям наиболее релевантную информацию.

В этой статье будет подробно представлен Google SERP API, который позволяет получать результаты при вводе запросов в поисковой системе Google. Содержимое результатов также включает множество типов, например избранные фрагменты, граф знаний и изображения.

В этом документе будет представлено руководство по интеграции Google SERP API.

## Процесс получения

Чтобы использовать Google SERP API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти в систему; после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, нет необходимости подавать отдельную заявку для каждого сервиса.** При первом получении предоставляется бесплатный лимит, который можно использовать для бесплатного ознакомления; при недостатке лимита вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## Базовое использование

Введите ключевые слова и тип поискового ресурса, чтобы получить результаты: передайте ключевые слова через `query`, а через `type` выберите тип поиска — веб-страницы, изображения, новости и т. д.; этому интерфейсу не требуется передавать `model`.

Например, для поиска информации об «apple inc» далее можно заполнить соответствующее содержимое в интерфейсе, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

Можно увидеть, что здесь мы настроили Request Headers, включая:

- `accept`: в каком формате вы хотите получить ответ; здесь указывается `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после получения его можно напрямую выбрать из выпадающего списка.

Также настроили Request Body, включая:

- `type`: тип поискового ресурса, в настоящее время поддерживается только шесть типов, по умолчанию — `search`.
- `query`: ключевые слова для поиска.
- `country`: страна, в которой находятся пользовательские результаты поиска, по умолчанию — США (US).
- `language`: язык пользовательских результатов поиска, по умолчанию — английский (en).
- `range`: временной диапазон пользовательских результатов поиска, по умолчанию без ограничений.
- `number`: размер страницы пагинации пользовательских результатов поиска, по умолчанию — 10.
- `page`: номер страницы пагинации пользовательских результатов поиска, по умолчанию — 1.

Кроме того, если вы хотите сгенерировать соответствующий код интеграции, вы можете непосредственно скопировать его для генерации, например, код CURL выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Код интеграции на Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Пользовательские типы поиска

Если вы настраиваете тип поисковых ресурсов, мы можем изменить параметр `type`; он включает обычные ресурсы `search`, ресурсы изображений `images`, новостные ресурсы `news`, картографические ресурсы `maps`, региональные ресурсы `places` и видеоресурсы `videos`. В этой статье в качестве примера будут использованы видеоресурсы `videos`.

Ниже мы продемонстрируем конкретные действия.

Сначала установите параметр `type` в значение `videos` и обычным образом передайте параметр `query`, как показано на рисунке:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

Соответствующий код выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## Пользовательский язык результатов поиска
Мы также можем настроить язык результатов поиска, здесь мы дополнительно добавляем поле `language` со значением `zh-cn`, где оно обозначает язык упрощённого китайского, при этом также поддерживаются другие языки, но необходимо вводить сокращение нужного языка, например en（English）、fr（French）、zh-cn（Chinese（Simplified））и другие языки, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/yyrssp.png" width="500" className="m-auto" /></p>

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "news",
  "query": "apple inc",
```

## Настройка временного диапазона результатов поиска
В этой статье также можно настроить временной диапазон результатов поиска, включая пять вариантов: `qdr:h` (за последний час), `qdr:d` (за последний день), `qdr:w` (за последнюю неделю), `qdr:m` (за последний месяц), по умолчанию без ограничений. Мы можем передать соответствующий временной диапазон через `range`, например, здесь установлено значение `qdr:d`, что означает поиск результатов за последний день, поэтому ввод выглядит следующим образом:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

Соответствующий код выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## Настройка пагинации результатов поиска

Этот API также поддерживает настройку постраничного отображения результатов поиска, `number` и `page` обозначают размер страницы и номер страницы пагинации. В этой статье для постраничного отображения будет установлено по 20 результатов поиска на одной странице, конкретная информация показана на рисунке:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

Код выглядит следующим образом:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
```
