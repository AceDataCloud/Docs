Основная функция AI Услуги по созданию удостоверений Task API заключается в том, чтобы по введенному ID задачи, сгенерированному API по созданию удостоверений, проверить статус выполнения этой задачи.

В этом документе подробно описывается интеграция AI Услуги по созданию удостоверений Task API, чтобы помочь вам легко интегрировать и в полной мере использовать мощные возможности этого API. С помощью AI Услуги по созданию удостоверений Task API вы можете легко реализовать проверку статуса выполнения задач API по созданию удостоверений.

## Процесс подачи заявки

Чтобы использовать AI Услугу по созданию удостоверений Task API, сначала необходимо перейти на страницу заявки [API по созданию удостоверений](https://platform.acedata.cloud/documents/headshots-generate) и подать заявку на соответствующую услугу, затем скопировать ID задачи API по созданию удостоверений, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/7ezmmn.png" width="500" className="m-auto" /></p>

Затем перейдите на страницу Tasks API [AI Услуга по созданию удостоверений Task API](https://platform.acedata.cloud/documents/headshots-tasks) и подайте заявку на соответствующую услугу, после перехода на страницу нажмите кнопку «Acquire», как показано на рисунке:

![Страница заявки](https://cdn.acedata.cloud/rci31i.png)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на [страницу входа](https://platform.acedata.cloud), где вам будет предложено зарегистрироваться и войти в систему. После регистрации и входа вы будете автоматически возвращены на текущую страницу.

При первой подаче заявки вам будет предоставлен бесплатный лимит, который можно использовать для бесплатного доступа к этому API.

## Пример запроса

AI Услуга по созданию удостоверений Task API может использоваться для проверки результатов API по созданию удостоверений. Для получения информации о том, как использовать API по созданию удостоверений, пожалуйста, обратитесь к документу [API по созданию удостоверений](https://platform.acedata.cloud/documents/drawai-headshots-generation-integration).

### Установка заголовков запроса и тела запроса

**Request Headers** включает:

- `accept`: указывает на прием ответа в формате JSON, здесь указывается `application/json`.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

**Request Body** включает:

- `id`: загруженный ID задачи.
- `action`: способ выполнения операции над задачей.

Настройка, как показано на рисунке:

### Пример кода

Можно заметить, что на правой стороне страницы автоматически сгенерирован код на различных языках, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/x99wu2.png" width="500" className="m-auto" /></p>

Некоторые примеры кода:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/headshots/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/headshots/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "16f96e95-d95c-46ef-b183-139b9bd1aebd",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Ошибка обработки

При вызове API, если возникнет ошибка, API вернет соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`：Неверный запрос, возможно, из-за отсутствия или недопустимых параметров.
- `400 api_not_implemented`：Неверный запрос, возможно, из-за отсутствия или недопустимых параметров.
- `401 invalid_token`：Неавторизован, недопустимый или отсутствующий токен авторизации.
- `429 too_many_requests`：Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`：Внутренняя ошибка сервера, что-то пошло не так на сервере.

### Пример ответа об ошибке

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
