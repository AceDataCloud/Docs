SUNO позволяет нам загружать референс-аудио для вторичного творчества, данный документ объясняет соответствующий метод интеграции API.

Для обычной загрузки требуется только `audio_url`, это общедоступный адрес аудио CDN. `mode` по умолчанию имеет значение `standard`, поэтому существующие вызовы не требуют изменений. Успешная обычная загрузка расходует **0.06 Credits**; при неудачной загрузке плата не взимается.

Вводимый здесь `audio_url` — `https://cdn.acedata.cloud/suno_demo.mp3`, это общедоступный адрес CDN.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Как видно, `data` всегда является объектом, `audio_id` — это ID песни после загрузки. Результаты анализа, такие как `lyric`, `style`, `duration`, заголовок и медиа-URL, являются необязательными полями, конкретное содержимое определяется возвращаемыми данными.

После получения ID песни можно через [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) вызывать такие операции, требующие `audio_id`, как `upload_extend`, `upload_cover` или выборка интервала. Если необходимо с помощью функции творческого вдохновения Inspo создавать новую музыку на основе от 1 до 4 полных референс-аудио, напрямую вызовите `action=inspo` и передайте список исходных общедоступных аудио-URL; сервис автоматически выполнит загрузку и анализ, без необходимости для клиента собирать метаданные аудио.

## Расширенный режим загрузки

> `audio_url` является входным адресом, он будет напрямую передан в процесс обработки аудио и не будет предварительно сохранён сервисом постоянного хранения конечных медиа. Убедитесь, что он общедоступен в течение обработки задачи.

Когда обычная загрузка не может обработать аудио, которым вы владеете или на использование которого получили разрешение, можно установить для `mode` значение `enhanced`. Этот режим также должен предоставлять `name` длиной от 1 до 100 символов и использовать общедоступный HTTPS `audio_url`.

Расширенная загрузка всегда использует асинхронную обработку, обычно требуется 2 минуты или больше. Успешная обработка расходует **1.87 Credits**; при неудачной обработке плата не взимается.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Интерфейс немедленно вернёт `task_id` и `trace_id`. Используйте [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) для запроса задачи, после успеха считайте ID аудио после загрузки из `response.data.audio_id`. Также можно предоставить HTTPS `callback_url` для получения конечного состояния.

Полученный при расширенной загрузке `audio_id` можно использовать для Cover, Samples и Mashup. Извлечение инструментала и MIDI, разделение всех дорожек, а также разделение вокала/инструментала всё ещё могут быть ограничены аккаунтом, которому принадлежит аудио; для неуказанных операций не гарантируется поддержка межаккаунтного использования. Чем короче аудио, тем обычно выше вероятность успешной обработки.
