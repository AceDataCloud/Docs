SUNO позволяет нам загружать референсное аудио для вторичного творчества, этот документ объясняет метод интеграции соответствующего API.

Для обычной загрузки требуется только `audio_url` — это общедоступный CDN-адрес аудио. По умолчанию `mode` имеет значение `standard`, поэтому существующие вызовы не требуют изменений. Успешная обычная загрузка расходует **0.06 Credits**; при сбое загрузки плата не взимается.

Здесь введённый нами `audio_url` — `https://cdn.acedata.cloud/suno_demo.mp3`, это общедоступный CDN-адрес.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Как видно, `data` всегда является объектом, а `audio_id` — это ID песни после загрузки. Результаты анализа, такие как `lyric`, `style`, `duration`, заголовок и медиа-URL, являются необязательными полями, конкретное содержимое зависит от возвращаемых данных.

После получения ID песни можно вызвать операции `upload_extend`, `upload_cover` или выборку по диапазону и другие операции, требующие `audio_id`, через [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios). Если требуется создать новую музыку на основе от 1 до 4 полных референсных аудиозаписей через функцию творческого вдохновения Inspo, напрямую вызовите `action=inspo` и передайте список исходных общедоступных URL аудио; сервис автоматически выполнит загрузку и анализ, без необходимости формировать metadata аудио на стороне клиента.

## Расширенный режим загрузки

> `audio_url` — это входной адрес, он будет напрямую передан в процесс обработки аудио и не будет предварительно сохранён сервисом постоянного хранения конечных медиафайлов. Убедитесь, что он общедоступен в течение обработки задачи.

Когда обычная загрузка не может обработать аудио, которым вы владеете или на использование которого получили разрешение, можно установить для `mode` значение `enhanced`. Этот режим также обязательно требует `name` длиной от 1 до 100 символов и общедоступный HTTPS `audio_url`.

Расширенная загрузка всегда использует асинхронную обработку и обычно требует 2 минуты или больше. Успешная обработка расходует **1.87 Credits**; при сбое обработки плата не взимается.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

Интерфейс немедленно вернёт `task_id` и `trace_id`. Используйте [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) для запроса задачи, после успеха прочитайте ID загруженного аудио из `response.data.audio_id`. Также можно предоставить HTTPS `callback_url` для получения конечного состояния.

Полученный при расширенной загрузке `audio_id` можно использовать для Cover, Samples и Mashup. Извлечение инструментала и MIDI, разделение всех дорожек, а также разделение вокала/инструментала всё ещё могут быть ограничены аккаунтом, которому принадлежит аудио; для неуказанных операций не гарантируется поддержка межаккаунтного использования. Чем короче аудио, тем выше обычно вероятность успешной обработки.
