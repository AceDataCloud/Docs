---
title: "API проверки доступности аудио Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability` ищет по `audio_id` положительные подтверждения того, что аудио можно продолжить обрабатывать по текущему маршруту. Его можно вызвать перед операциями продолжения, кавер-версии и другими; результат отражает состояние только на момент проверки и не гарантирует успех конкретной операции. Этот API возвращает результат синхронно, требует API Token и в настоящее время не списывает Credits.

`audio_id` — это ID песни, возвращаемый завершённой задачей Suno, а не `task_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

Пример успешного ответа:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

При успешной проверке `data.available` имеет значение `true`; если подтверждение невозможно, возвращается `503 availability_unknown` без `false`. При неверном формате `audio_id` возвращается 400; при ограничении частоты запросов или сбое сервиса также возвращается ответ с ошибкой. Состояние может измениться между завершением проверки и фактическим выполнением операции.
