С расширением применения ИИ различные AI-программы постепенно становятся популярными. ИИ все больше проникает во все аспекты жизни и работы людей. От первоначального написания текстов до медицины и образования, а теперь и до музыки.

Suno — это профессиональная платформа для создания высококачественных песен и музыки с использованием ИИ. Пользователям достаточно ввести простые текстовые подсказки, чтобы сгенерировать песни с вокалом в зависимости от жанра и стиля. Этот генератор музыки был разработан командой из известных технологических компаний, таких как Meta, TikTok, Kensho, с целью позволить всем создавать прекрасную музыку без необходимости в музыкальных инструментах.

Ниже приведен прогресс обновления модели:

| Версия  | model           | Дата выхода   | Ограничение на prompt | Ограничение на стиль | Максимальная длительность песни |
| ------- | --------------- | ------------- | --------------------- | ------------------- | ------------------------------- |
| v5      | chirp-v5        | 2025.09.23   | 5000                  | 1000                | 8 минут                        |
| v4.5+   | chirp-v4-5-plus | 2025.07.17   | 5000                  | 1000                | 8 минут                        |
| v4.5    | chirp-v4-5      | 2025.05.03   | 5000                  | 1000                | 4 минуты                       |
| v4      | chirp-v4        | 2024.12.17   | 3000                  | 200                 | 150 секунд                     |
| v3.5    | chirp-v3-5      | ---           | 3000                  | 200                 | 120 секунд                     |

Suno недавно обновил модель генерации музыки до версии V5, для вызова последней версии V5 достаточно изменить параметр model на `chirp-v5`, что позволяет генерировать песни длительностью до 9 минут.

Однако официально Suno не предоставляет API, AceDataCloud предлагает набор API для Suno, который имитирует интеграцию с официальным Suno, что позволяет быстро и удобно генерировать желаемую музыку.

## Запрос и использование

Чтобы использовать Suno Audios API, сначала перейдите на страницу [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) и нажмите кнопку «Acquire», чтобы получить необходимые для запроса учетные данные:

![](https://cdn.acedata.cloud/nyq0xz.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправят на страницу входа, чтобы пригласить вас зарегистрироваться и войти. После входа или регистрации вы автоматически вернетесь на текущую страницу.

При первом запросе будет предоставлен бесплатный лимит, который можно использовать для бесплатного доступа к этому API.

## Основное использование

Если вы хотите создать какую-то песню, вы можете ввести любой текст, например, если я хочу сгенерировать песню о Рождестве, я могу ввести `a song for Christmas`, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Как видно, здесь мы настроили заголовки запроса, включая:

- `accept`: формат ответа, который вы хотите получить, здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после запроса.

Также настроено тело запроса, включая:

- `action`: действие для этой задачи генерации музыки, по умолчанию `generate`, включает: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`: подсказка для режима вдохновения от Suno.
- `model`: модель для этой задачи генерации музыки, по умолчанию `chirp-v3-5`, включает: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`.
- `lyric`: текст песни для пользовательского режима от Suno.
- `custom`: использование пользовательского режима, по умолчанию: `false`.
- `instrumental`: опция чистой музыки для режима вдохновения от Suno.
- `title`: заголовок музыки для пользовательского режима от Suno.
- `style`: стиль музыки для пользовательского режима от Suno.
- `style_negative`: исключаемый стиль для пользовательского режима от Suno.
- `audio_weight`: доля загружаемого референсного аудио, диапазон 0-1, чем больше, тем больше зависимость от референсного аудио.
- `audio_id`: ID референсной музыки.
- `overpainting_start`/`overpainting_end`: время начала и окончания добавления вокала к уже существующей чистой музыке, в секундах.
- `underpainting_start`/`underpainting_end`: время начала и окончания добавления сопровождения к акапелле, в секундах.
- `persona_id`: ID песни артиста.
- `continue_at`: время в секундах для продолжения существующего аудио. Например, 213.5 означает продолжение до 3 минут 33.5 секунд.
- `style_influence`: продвинутый параметр `style_influence`.
- `replace_section_end`: конечное время замены фрагмента.
- `replace_section_start`: начальное время замены фрагмента.
- `vocal_gender`: управление полом голоса, женский `f`, мужской `m`, эффективно для моделей 4.5 и выше.
- `weirdness`: продвинутый параметр `weirdness`.
- `lyric_prompt`: подсказка для генерации текста, активна только если `custom` равно `true` и `lyric` не передан.
- `callback_url`: URL для обратного вызова результатов.

## Пользовательская генерация

Если вы хотите настроить генерацию текста, вы можете ввести текст:

В этом случае поле `lyric` может принимать подобное содержимое:

```
[Куплет]\nСнежинки падают повсюду\nСверкающий белый\nПокрывающий землю\nДети смеются\nПолные радости\nВ этой зимней стране чудес сегодня ночью\nСани Санты\nВ небе\nНос Рудольфа светится ярко\nО, мой\nСлушайте, как звенят колокольчики\nЗвучат так ясно\nПринося радость и праздничное настроение\n[Куплет 2]\nЖарим каштаны у огня\nРождественские огни\nОни мерцают и показывают\nСемьи собираются с любовью и радостью\nРаспространяя тепло всем близким
```

> Обратите внимание, что в тексте песни `\n` является символом новой строки. Если вы не знаете, как сгенерировать текст, вы можете использовать API генерации текстов, предоставленный AceDataCloud, чтобы сгенерировать текст через prompt, API - это [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/514d82dc-f7ab-4638-9f21-8b9275916b08).

- lyric: текст песни
- custom: заполните `true`, что означает пользовательскую генерацию, этот параметр по умолчанию равен false, что означает использование генерации по prompt.
- title: заголовок песни.
- style: стиль песни, необязательный.

## Функция генерации в стиле пользовательского исполнителя
Если вы хотите использовать стиль певца для генерации песни, сначала сгенерируйте песню с помощью основных инструкций выше. В конце вам нужно установить эту песню в стиль певца, затем войдите в [Suno Persona API](https://platform.acedata.cloud/documents/78bb6c62-6ce0-490f-a7df-e89d80ec0583) и на основе сгенерированного музыкального ID `audio_id` создайте параметр ID стиля певца `persona_id`, конкретные параметры показаны на рисунке ниже:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерировался следующий код:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажмите "Запустить", и вы получите результат, как показано ниже:

Затем вы можете установить параметр `action` в `artist_consistency` (если это новая версия стиля певца Persona-v2-vox, `action` должен быть установлен в `artist_consistency_vox`), и введите ID песни, которую нужно продолжить генерировать, и ID стиля певца, пример заполнения показан ниже:

headers = {

## Функция продолжения генерации

Если вы хотите продолжить генерацию уже созданной песни Suno, вы можете установить параметр `action` в `extend`, и ввести ID песни, которую нужно продолжить генерировать. ID песни можно получить на основе основных инструкций, как видно выше, в этом случае ID песни будет:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Обратите внимание, что здесь `id` в тексте песни — это ID сгенерированной песни. Если вы не знаете, как сгенерировать песню, вы можете обратиться к основным инструкциям выше.

Если вы хотите продолжить генерацию загруженной вами песни, вы можете установить параметр `action` в `upload_extend`, и ввести ID пользовательской загруженной песни, ID песни можно получить с помощью [Suno Upload Generation API](https://platform.acedata.cloud/documents/766db278-012c-43c4-9245-5f18d8dc4d82), как показано на рисунке ниже:

Далее вам необходимо заполнить текст песни, стиль для пользовательской генерации песни, указав следующие параметры:

- lyric: текст песни
- custom: установить в `true`, что означает пользовательскую генерацию, этот параметр по умолчанию равен false, что означает использование `prompt` для генерации.
- style: стиль песни, необязательный.
- continue_at: продолжить существующий аудиофайл в секундах. Например, 213.5 означает продолжить до 3 минут 33.5 секунд.

Пример заполнения показан ниже:

## Получение полной песни

Когда на основе существующей песни продолжается генерация, возвращенная песня не содержит оригинального содержания. Чтобы получить полное содержание песни, необходимо использовать функцию конкатенации, задав следующие параметры:

- action: значение `concat`.
- audio_id: ID последнего фрагмента.

Например, ID расширенной песни: 0a1e1b10-c36a-41c9-9bfb-b26d9d25db98, тогда параметры можно установить следующим образом:

```json
{
  "action": "concat",
  "audio_id": "0a1e1b10-c36a-41c9-9bfb-b26d9d25db98"
}
```

Другие параметры остаются без изменений, возвращается полная песня, которая является результатом конкатенации всех фрагментов, но результат будет только одна песня, пример ниже:

## Музыкальная версия

- action：内容为 `cover`，当是对自定义上传的音乐进行翻版操作的时候必须指定内容为：`upload_cover`。

## 替换片段

- action：内容为 `replace_section`。
- audio_id：之前生成歌曲的 ID。
- model: 歌曲生成模型，
- lyric: 替换后的完整歌词（只需要与 prompt 有重复就行，不需要完全的歌词），
- prompt：需要替换的歌词部分。
- style：歌曲的风格，选填。
- replace_section_start：`lyric`对应的歌词时间轴的起始时间。
- replace_section_end：`lyric`对应的歌词时间轴的终点时间。

## Пользовательские высокоуровневые параметры

Официально разрешено использовать высокоуровневые параметры `weirdness`==>`Странность`, `style_influence`==>`Влияние стиля`, `audio_weight`==>`Влияние аудио` в пользовательском режиме, соответствующие следующим официальным примерам:

При этом диапазон высокоуровневых параметров находится в пределах от 0 до 1, конкретные параметры показаны на следующем изображении:

<p><img src="https://cdn.acedata.cloud/2dlbo6.png" width="500" className="m-auto" /></p>

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v4-5",
    "lyric": "Привет Привет Привет ",
    "custom": True,
    "weirdness": 0.4,
    "style_influence": 0.4,
    "audio_weight": 0.4
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Функция Add Insterumental

В августе 2025 года suno представил функцию Add Insterumental, для начала необходимо загрузить песню без фоновой музыки, чтобы suno мог помочь вам с аранжировкой. Сначала можно перейти к [Suno Upload API](https://platform.acedata.cloud/documents/766db278-012c-43c4-9245-5f18d8dc4d82) и загрузить песню без фоновой музыки, соответствующие действия показаны на следующем изображении:

<p><img src="https://cdn.acedata.cloud/fxl914.png" width="500" className="m-auto" /></p>

Затем необходимо записать загруженный `audio_id`, конкретный результат показан на следующем изображении:

<p><img src="https://cdn.acedata.cloud/47t6wj.png" width="500" className="m-auto" /></p>

В итоге получен `audio_id`: 92254cab-3372-4d9e-bce9-cdcfdbc39070, затем нам нужно заполнить следующие параметры:

- action: содержимое `underpainting`.
- underpainting_start: начальное время добавления сопровождения к загруженной песне, значение по умолчанию 0.
- underpainting_end: конечное время добавления сопровождения к загруженной песне, должно быть меньше общей продолжительности песни.
- audio_id: ID загруженной песни без фоновой музыки.
- style: стиль сопровождения, лучше всего без текста, так как это фон.

После заполнения автоматически сгенерировался следующий код:

<p><img src="https://cdn.acedata.cloud/8x1ic6.png" width="500" className="m-auto" /></p>

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "underpainting",
    "model": "chirp-v4-5",
    "style": "Поп-рэп, вдохновляющий, магнетические мужские вокалы, пиано, синтезатор, электрогитара, драйвовый бас, четкая структура",
    "audio_id": "92254cab-3372-4d9e-bce9-cdcfdbc39070",
    "underpainting_end": 120
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Функция Remaster

В декабре 2025 года suno выпустил новую функцию Remaster, которая позволяет заново генерировать песни, нельзя использовать между аккаунтами, затем нам нужно заполнить следующие параметры:

## Асинхронный обратный вызов

Поскольку время генерации музыки Suno относительно долгое, примерно 1-2 минуты, если API долго не отвечает, HTTP-запрос будет поддерживать соединение, что приведет к дополнительному расходу системных ресурсов, поэтому этот API также поддерживает асинхронные обратные вызовы.

Общий процесс таков: когда клиент инициирует запрос, дополнительно указывается поле `callback_url`, после того как клиент инициирует API-запрос, API немедленно возвращает результат, содержащий информацию о поле `task_id`, представляющем текущий идентификатор задачи. Когда задача завершена, результат генерации музыки будет отправлен на указанный клиентом `callback_url` в формате POST JSON, который также включает поле `task_id`, так что результат задачи можно связать по идентификатору.
