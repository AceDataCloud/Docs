С расширением применения AI различные AI-программы постепенно стали широко распространены. AI постепенно проник во все аспекты работы и жизни людей. И отраслей, затрагиваемых AI, становится всё больше: от первоначального написания текстов до медицины и образования, а теперь и музыки.

Suno — это профессиональная высококачественная платформа для создания AI-песен и музыки. Пользователям достаточно ввести простые текстовые подсказки, чтобы на основе жанра, стиля и текста песни генерировать песни с вокалом. Этот AI-генератор музыки разработан членами команды из известных технологических компаний, таких как Meta, TikTok, Kensho и других; его цель — не требовать никаких инструментов, чтобы каждый мог создавать прекрасную музыку.

Ниже приведён ход обновления моделей:

| v6      | chirp-v6        | 2026.09.09 | —        | —        | —      |
| v6 Wild | chirp-v6-wild   | 2026.09.09 | —        | —        | —      |
| v6 Mini | chirp-v6-mini   | 2026.09.09 | —        | —        | —      |
| v5.5    | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 минут   |
| v5      | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 минут   |
| v4.5+   | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 минут   |

| v3.5    | chirp-v3-5      | ---        | 3000     | 200      | 120 секунд  |

> Ограничения `lyric` и `style` в таблице выше являются верхними пределами в пользовательском режиме (`custom` равен `true`). В непользовательском режиме вдохновения (`custom` равен `false`) заполняется только `prompt`, максимальная длина которого составляет 500 символов (одинаково для всех моделей).

Suno теперь поддерживает `chirp-v6`, `chirp-v6-wild` и `chirp-v6-mini`. Рекомендуется использовать `chirp-v6`; старые названия моделей продолжают поддерживаться.

Однако Suno официально не предоставляет API, AceDataCloud предоставляет набор API Suno, имитирующий интеграцию с официальным Suno, с помощью которого можно удобно и быстро генерировать желаемую музыку.

## Получение и использование

Чтобы использовать Suno Audios Generation API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы сохранить его для дальнейшего использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы ещё не вошли в систему или не зарегистрировались, вы будете автоматически перенаправлены на страницу входа, где вам будет предложено зарегистрироваться и войти в систему; после завершения вы автоматически вернётесь на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно подавать отдельную заявку для каждого сервиса.** При первой заявке будет предоставлен бесплатный лимит, с которым можно бесплатно попробовать сервис; при недостатке лимита можно пополнить универсальный баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Базовое использование

О какой песне вы хотите подумать — можно произвольно ввести отрывок текста. Например, если я хочу сгенерировать песню о Рождестве, можно ввести `a song for Christmas`, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Здесь видно, что мы задали Request Headers, включая:

- `accept`: в каком формате вы хотите получить результат ответа; здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после получения можно напрямую выбрать его из выпадающего списка.

Также задан Request Body, включая:
- `action`：действие этой задачи генерации музыки, по умолчанию `generate`, в основном включает: `extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`。
- `prompt`：подсказка режима вдохновения Suno (действует, когда `custom` имеет значение `false`), максимум 500 символов.
- `model`：модель этой задачи генерации музыки. Серия v6 включает `chirp-v6`、`chirp-v6-wild` и `chirp-v6-mini`; названия старых моделей продолжают поддерживаться.
- `lyric`：содержание текста песни для пользовательского режима Suno. Для `chirp-v3-5` и `chirp-v4` максимум 3000 символов; для `chirp-v4-5` и выше (включая `chirp-v5`、`chirp-v5-5`) максимум 5000 символов.
- `custom`：использовать ли пользовательский режим, по умолчанию: `false`。
- `instrumental`：опция инструментальной музыки в режиме вдохновения Suno.
- `title`：название музыки в пользовательском режиме Suno. Для `chirp-v3-5`、`chirp-v4` максимум 80 символов; для `chirp-v4-5` и выше максимум 100 символов.
- `style`：музыкальный стиль пользовательского режима Suno. Для `chirp-v3-5` и `chirp-v4` максимум 200 символов; для `chirp-v4-5` и выше (включая `chirp-v5`、`chirp-v5-5`) максимум 1000 символов.
- `negative_tags`：музыкальные стили или жанры, которые требуется исключить из результатов генерации в пользовательском режиме (когда `custom` имеет значение `true`).
- `audio_weight`：доля загруженного эталонного аудио, диапазон 0–1; чем больше значение, тем сильнее зависимость от эталонного аудио.
- `audio_id`：ID эталонной музыки.
- `overpainting_start`/`overpainting_end`：время начала и окончания добавления вокала к существующей инструментальной музыке, в секундах.
- `underpainting_start`/`underpainting_end`：время начала и окончания добавления сопровождения к пению а капелла, в секундах.
- `persona_id`：ID песни исполнителя.
- `continue_at`：граница продолжения, в секундах. Например, 213.5 означает начало генерации последующего фрагмента с отметки 3 минуты 33.5 секунды. `lyric` и `style` направляют только новый контент после границы и не заменяют текст или вокал до границы в исходном аудио.
- `style_influence`：расширенный параметр «Style Influence» в пользовательском режиме, диапазон 0–1; чем больше значение, тем точнее соответствие выбранному стилю.
- `replace_section_end`：конечное время заменяемого фрагмента.
- `replace_section_start`：начальное время заменяемого фрагмента.
- `vocal_gender`：управляет предпочтением женского или мужского голоса: женский голос — `f`, мужской голос — `m`; действует для моделей 4.5 и выше; является параметром предпочтения и не гарантирует строгого соблюдения.
- `weirdness`：расширенный параметр «Weirdness» в пользовательском режиме, диапазон 0–1; чем больше значение, тем больше творчества и экспериментальности.
- `duration`：ожидаемая длительность песни, в секундах; должна быть целым числом в диапазоне от 10 до 360. Этот параметр используется для генерации песен в пользовательском режиме (когда `custom` имеет значение `true`). Это ориентир, а не жёсткое ограничение: модель будет учитывать его, но не гарантирует достижения; фактическая длительность готового результата определяется полем `duration` в ответе и обычно короче ожидаемой.
- `lyric_prompt`：prompt для генерации текста песни, действует тогда и только тогда, когда `custom` имеет значение `true` и `lyric` не передан.
- `callback_url`：URL, на который необходимо отправить результат обратным вызовом.
- `async`：необязательно; при установке в `true` интерфейс немедленно возвращает `task_id`, без необходимости указывать `callback_url`, после чего результат можно получить через опрос соответствующего интерфейса запроса задач.

## Пользовательская генерация

Если вы хотите пользовательски сгенерировать текст песни, можно ввести текст песни:

В это время в поле `lyric` можно передать содержимое, подобное следующему:

```
[Verse]\nSnowflakes falling all around\nGlistening white\nCovering the ground\nChildren laughing\nFull of delight\nIn this winter wonderland tonight\nSanta's sleigh\nUp in the sky\nRudolph's nose shining bright\nOh my\nHear the jingle bells\nRinging so clear\nBringing joy and holiday cheer\n[Verse 2]\nRoasting chestnuts by the fire's glow\nChristmas lights\nThey twinkle and show\nFamilies gathering with love and cheer\nSpreading warmth to everyone near
```

> Обратите внимание: `\n` в тексте песни здесь является символом переноса строки. Если вы не знаете, как сгенерировать текст песни, можно использовать предоставляемый AceDataCloud API генерации текстов песен, чтобы сгенерировать текст песни через prompt; API: [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Далее, чтобы пользовательски сгенерировать песню на основе текста, названия и стиля, можно указать следующее содержимое:

- lyric：текст песни
- custom：укажите `true`, что означает пользовательскую генерацию; по умолчанию этот параметр имеет значение false, что означает генерацию с использованием `prompt`.
- title：название песни.
- style：стиль песни, необязательно.

Пример заполнения следующий:

<p><img src="https://cdn.acedata.cloud/qp3iba.png" width="500" className="m-auto" /></p>

После заполнения автоматически генерируется следующий код:

Соответствующий код:

```shell
curl -X POST 'https://api.acedata.cloud/suno/audios' \

  "action": "generate",
  "prompt": "A song for Christmas",
  "model": "chirp-v4-5",
  "lyric": "[Verse]\\nSnowflakes falling all around\\nGlistening white\\nCovering the ground\\nChildren laughing\\nFull of delight\\nIn this winter wonderland tonight\\nSanta's sleigh\\nUp in the sky\\nRudolph's nose shining bright\\nOh my\\nHear the jingle bells\\nRinging so clear\\nBringing joy and holiday cheer\\n[Verse 2]\\nRoasting chestnuts by the fire's glow\\nChristmas lights\\nThey twinkle and show\\nFamilies gathering with love and cheer\\nSpreading warmth to everyone near",
  "custom": true
}'
```

Тестирование разрешено, и эффект генерации аналогичен.

## Функция пользовательской генерации стиля певца
Если вы хотите использовать стиль певца для генерации песни, сначала сгенерируйте песню через базовое использование выше,
в итоге необходимо задать эту песню в качестве стиля певца, затем нужно перейти в [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) и на основе официально сгенерированного музыкального ID `audio_id` сгенерировать параметр ID стиля певца `persona_id`, конкретные параметры показаны на изображении ниже:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

После заполнения автоматически генерируется следующий код:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Соответствующий Python-код:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Нажмите «Выполнить», и можно увидеть, что будет получен следующий результат:

```json
{

  "task_id": "7628b754-4fe7-4e79-bda4-806d0dd8bf6e",
  "data": {
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b"
  }
}
```

Мы используем приведённые выше `audio_id` и `persona_id`, а именно `97efc9f4-0e8d-4b3e-88df-14568fa1b11f` и `e0d7319e-aa2a-44cb-b00a-916218d7cb0b`, в качестве демонстрационных данных в этом примере. Затем можно установить параметр `action` в значение `artist_consistency` (если используется новая версия стиля певца Persona-v2-vox, `action` должен быть установлен в `artist_consistency_vox`) и ввести ID песни, для которой нужно продолжить генерацию, а также ID стиля певца, пример заполнения показан ниже:

<p><img src="https://cdn.acedata.cloud/fukijq.png" width="500" className="m-auto" /></p>

После заполнения автоматически генерируется следующий код:

<p><img src="https://cdn.acedata.cloud/5uzk9d.png" width="500" className="m-auto" /></p>

Соответствующий Python-код:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "artist_consistency",
    "prompt": "A song for Christmas",
    "model": "chirp-v4-5",
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Функция продолжения генерации

Если вы хотите продолжить генерацию уже сгенерированной песни Suno, можно установить параметр `action` в значение `extend` и ввести ID песни, для которой требуется продолжить генерацию. ID песни получается через базовое использование, из приведённого выше можно увидеть, что в этот момент ID песни равен:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Обратите внимание, что `id` в тексте песни здесь — это ID песни после генерации. Если вы не знаете, как генерировать песни, вы можете обратиться к базовому использованию выше для генерации песни.

Если вы хотите продолжить генерацию собственной загруженной песни, можно установить параметр `action` в значение `upload_extend` и ввести ID собственной загруженной песни, для которой требуется продолжить генерацию. ID песни получается с помощью [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), как показано на изображении ниже:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Далее необходимо заполнить текст песни для продолжаемого фрагмента, также можно указать стиль:

- lyric：используется только для направления текста нового сгенерированного фрагмента после `continue_at`, не заменяет текст песни до этой временной точки в исходном аудио.
- custom：установите значение `true`, что означает пользовательскую генерацию; значение этого параметра по умолчанию — false, что означает генерацию с использованием `prompt`.
- style：стиль песни продолжаемого фрагмента, необязательно.
- continue_at：граница продолжения, единица измерения — секунды. Например, 213.5 означает начало генерации последующего фрагмента с отметки 3 минуты 33.5 секунды.

> `extend` используется для продолжения создания уже существующей песни, а не для замены текста всей песни. Если вы хотите использовать новый текст с начала всей песни, используйте `generate` для повторной генерации; если вы хотите заново исполнить песню с опорой на существующую, можно использовать `cover`. При передаче полного нового текста исходный текст до `continue_at` всё равно не будет заменён.

Пример заполнения показан ниже:

<p><img src="https://cdn.acedata.cloud/zp9s42.png" width="500" className="m-auto" /></p>

После заполнения автоматически генерируется следующий код:

<p><img src="https://cdn.acedata.cloud/wwpw78.png" width="500" className="m-auto" /></p>
Ниже приведён снимок реального исторического вызова, в котором `continue_at` равен 2 секундам, поэтому только первые 2 секунды относятся к исходному содержимому до границы продолжения. При фактическом продолжении ближе к концу песни следует установить это значение на секунду, с которой ожидается начать продолжение, и предоставить в `lyric` только новый фрагмент, который нужно спеть после границы.

Соответствующий код Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "prompt": "A song for Christmas",
    "model": "chirp-v4-5",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "continue_at": 2,
    "lyric": "[Verse]\\nSnowflakes falling all around\\nGlistening white\\nCovering the ground\\nChildren laughing\\nFull of delight\\nIn this winter wonderland tonight\\nSanta's sleigh\\nUp in the sky\\nRudolph's nose shining bright\\nOh my\\nHear the jingle bells\\nRinging so clear\\nBringing joy and holiday cheer\\n[Verse 2]\\nRoasting chestnuts by the fire's glow\\nChristmas lights\\nThey twinkle and show\\nFamilies gathering with love and cheer\\nSpreading warmth to everyone near",
    "custom": True,
    "instrumental": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Получение полной песни

Результат `extend` текущей модели обычно уже включает исходное аудио до `continue_at` и новое содержимое после границы; сначала определите по фактической длительности и содержанию возвращённого аудио, является ли оно уже полной песней. Если возвращается самостоятельный продолжаемый фрагмент или необходимо явно объединить историю нескольких продолжений в одну песню, затем используйте функцию склейки:

- action: содержимое — `concat`.

Если необходимо создать кавер-версию ранее сгенерированной песни (также поддерживается пользовательская загруженная музыка), необходимо использовать метод создания кавер-версии музыки, и можно указать следующее содержимое:

- action: значение `cover`; при создании кавер-версии пользовательской загруженной музыки необходимо указать значение: `upload_cover`.

## Замена фрагмента

Когда после генерации песни необходимо выполнить вторичное создание с отдельной операцией замены фрагмента песни, можно выполнить замену определённого фрагмента песни.

> ⚠️ **Примечание**: по умолчанию `replace_section_result_mode` имеет значение `full_song`: система отдельно объединит 2 новых сгенерированных кандидата и вернёт 2 полные песни. Если нужны только ещё не объединённые кандидаты заменяемых фрагментов, явно установите значение `candidates`, затем выберите кандидата и вызовите [Объединение музыки](#音乐拼接).

Описание параметров следующее:

- action: значение `replace_section`.
- audio_id: ID исходной песни (исходной песни, в которой выполняется замена).
- model: модель генерации песни.
- lyric: полный текст песни после замены (включая заменяемый фрагмент и его контекст, соответствует содержимому в `prompt`).
- prompt: новый текст песни для заменяемого фрагмента.
- style: стиль песни, необязательный.
- replace_section_start: время начала заменяемого фрагмента в исходной песне (секунды).
- replace_section_end: время окончания заменяемого фрагмента в исходной песне (секунды).
- replace_section_result_mode: режим возврата, по умолчанию `full_song`. `full_song` отдельно объединяет 2 кандидата и возвращает 2 полные песни; `candidates` возвращает 2 ещё не объединённых фрагмента-кандидата.

Если нет необходимости сравнивать двух кандидатов, на первом шаге можно установить `replace_section_result_mode` в значение `full_song`. Интерфейс автоматически выберет первого кандидата для сборки и напрямую вернёт массив `data`, содержащий 1 полную песню; в этом случае не нужно повторно вызывать `concat`, а стоимость будет включать шаг автоматической сборки.

```json
{
  "action": "concat",
  "audio_id": "364f9d8b-ca25-463b-9a5e-d0b7139e2d6a",
  "model": "chirp-v5-5"
}
```


## Разделение вокала и музыки

- action: значение — `stems`.

```json
{
  "action": "stems",
  "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"
}
```

## Управление длительностью песни

По умолчанию длительность генерируемой песни определяется самой моделью, обычно от 30 секунд до 4 минут. Если требуется более длинный или более короткий готовый результат, можно указать желаемую длительность через параметр `duration`, единица измерения — секунды, допустимые значения — целые числа от 10 до 360.

Этот параметр используется для генерации песен в пользовательском режиме (`custom` имеет значение `true`). Следует особо отметить, что `duration` — это **ориентировочная подсказка, а не жёсткое ограничение**: модель будет учитывать это значение при создании, но не гарантирует его достижения; в тестах фактическая длительность обычно заметно короче ожидаемой, а длительность двух песен, возвращённых одним запросом, также может отличаться в несколько раз. Даже для полностью одинаковых запросов длительности, полученные при многократной отправке, также могут значительно различаться. Поэтому не следует использовать его как точное управление длительностью; если для бизнеса требуется фиксированная длительность, после получения готового результата самостоятельно обрежьте его или повторите попытку.

Соответствующий код Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Следует отметить, что `duration` в запросе — это **ожидаемая длительность**, а поле `duration` каждой песни в ответе `data` — это **фактическая длительность** этой песни. Их названия одинаковы, но значения различны; фактическая длительность не гарантированно равна ожидаемому значению. Длина текста песни является одним из основных факторов, влияющих на длительность готового результата; если требуется более длинный готовый результат, рекомендуется одновременно предоставить более полный текст песни.

Интерфейс не выполняет дополнительную проверку `duration`, параметр передаётся модели как есть. Если передано значение, не поддерживаемое текущим режимом или моделью, оно может быть проигнорировано; рекомендуется сначала подтвердить эффект одним запросом, а затем использовать массово.

## Функция вдохновляющего творчества Inspo

Функция вдохновляющего творчества Inspo может генерировать новую музыку на основе от 1 до 4 полных референсных аудиозаписей, поддерживает перетаскивание или загрузку аудио в качестве источника вдохновения. API использует существующее действие `inspo`: клиент предоставляет общедоступные URL аудио, сервис автоматически завершает подготовку референсного аудио и создание композиции, без необходимости клиенту отдельно считывать текст, стиль или длительность и затем собирать запрос. Она отличается как от описанного выше интервального сэмплирования, так и от Cover, воспроизводящего стиль оригинальной песни. При использовании необходимо заполнить следующие параметры:

- action: содержимое — `inspo`.
- audio_urls: список URL референсных аудиозаписей, необходимо предоставить от 1 до 4 общедоступных аудиоадресов.
- model: используемая модель, рекомендуется `chirp-v6`.
- prompt: текст песни или подсказка для творчества (необязательно).

> Примечание: референсное аудио должно быть общедоступным аудиофайлом. Если референсное аудио полностью совпадает с известной записью в библиотеке треков платформы, Suno может отклонить генерацию из-за проверки авторских прав; рекомендуется использовать собственное аудио или аудио, сгенерированное Suno, в качестве источника вдохновения.

Соответствующий код Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v6",
    "audio_urls": [
        "https://cdn.acedata.cloud/uploads/a0bc051f-42c2-4a46-aeb4-582dcc884ad2"
    ],
    "prompt": "Rework these references as warm acoustic folk with soft vocals"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Ниже сохранён проверенный исторический снимок ответа; в снимке использовался актуальный на тот момент `chirp-v5`, в текущем примере запроса рекомендуется `chirp-v6`, структура ответа одинакова:

## Асинхронный обратный вызов

Поскольку Suno генерирует музыку относительно долго, примерно 1–2 минуты, если API долго не отвечает, HTTP-запрос будет постоянно поддерживать соединение, что приведёт к дополнительному потреблению системных ресурсов, поэтому данный API также предоставляет поддержку асинхронных обратных вызовов.

Общий процесс таков: когда клиент инициирует запрос, он дополнительно указывает поле `callback_url`; после того как клиент инициирует API-запрос, API немедленно возвращает результат, содержащий информацию о поле `task_id`, которое представляет ID текущей задачи. После завершения задачи результат генерации музыки будет отправлен в формате POST JSON на указанный клиентом `callback_url`, где также содержится поле `task_id`, таким образом результаты задач можно связать по ID.

Ниже мы на примере рассмотрим, как именно это сделать.

Прежде всего, обратный вызов Webhook — это сервис, который может принимать HTTP-запросы; разработчик должен заменить его URL на URL самостоятельно развёрнутого HTTP-сервера. Здесь для удобства демонстрации используется публичный сайт-пример Webhook https://webhook.site/; открыв этот сайт, можно получить URL Webhook, как показано на рисунке:

![](https://cdn.acedata.cloud/fwfqin.png)
