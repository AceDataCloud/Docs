С расширением применения ИИ различные программы на его основе постепенно становятся популярными. ИИ все больше проникает во все сферы жизни и работы людей. От первоначального написания текстов до медицины и образования, а теперь и музыки.

Suno — это профессиональная платформа для создания высококачественных песен и музыки на основе ИИ, где пользователю достаточно ввести простую текстовую подсказку, чтобы сгенерировать песню с вокалом в зависимости от жанра и стиля. Этот генератор музыки на основе ИИ разработан командой специалистов из известных технологических компаний, таких как Meta, TikTok, Kensho, с целью позволить всем создавать прекрасную музыку без необходимости в музыкальных инструментах.

Ниже приведен прогресс обновления модели:

| Версия  | model           | Дата выхода   | Ограничение на текст | Ограничение на стиль | Максимальная длительность песни |
| ------- | --------------- | ------------- | -------------------- | -------------------- | ------------------------------- |
| v5.5    | chirp-v5-5      | 2026.03.27   | 5000                 | 1000                 | 8 минут                        |
| v5      | chirp-v5        | 2025.09.23   | 5000                 | 1000                 | 8 минут                        |
| v4.5+   | chirp-v4-5-plus | 2025.07.17   | 5000                 | 1000                 | 8 минут                        |
| v4.5    | chirp-v4-5      | 2025.05.03   | 5000                 | 1000                 | 4 минуты                       |
| v4      | chirp-v4        | 2024.12.17   | 3000                 | 200                  | 150 секунд                     |
| v3.5    | chirp-v3-5      | ---           | 3000                 | 200                  | 120 секунд                     |

> В таблице выше ограничения `lyric` и `style` являются верхним пределом для пользовательского режима (`custom` равно `true`). Для непользовательского режима вдохновения (`custom` равно `false`) достаточно заполнить только `prompt`, максимальная длина которого составляет 500 символов (для всех моделей одинаково).

Suno теперь поддерживает последнюю модель `chirp-v5-5`. При вызове последней версии установите параметр `model` в `chirp-v5-5`; версии `chirp-v5` и более ранние по-прежнему могут использоваться.

Однако официально Suno не предоставляет API, AceDataCloud предлагает набор API для Suno, который имитирует интеграцию с официальным Suno, что позволяет быстро и удобно генерировать желаемую музыку.

## Запрос и использование

Чтобы использовать Suno Audios Generation API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications) и получите ваш API Token для резервного копирования.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправят на страницу входа, чтобы пригласить вас зарегистрироваться и войти. После завершения вы автоматически вернетесь на текущую страницу.

**Один API Token позволяет вызывать все услуги платформы, не нужно запрашивать для каждой услуги отдельно.** При первом запросе предоставляется бесплатный лимит для тестирования; при недостатке лимита можно пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Основное использование

Что бы вы ни хотели, вы можете ввести любой текст, например, если я хочу сгенерировать песню о Рождестве, я могу ввести `a song for Christmas`, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Как видно, здесь мы настроили заголовки запроса, включая:

- `accept`: в каком формате вы хотите получить ответ, здесь указано `application/json`, то есть в формате JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после запроса.

Также настроено тело запроса, включая:
- `action`：Действие для этой задачи генерации музыки, по умолчанию `generate`, включает: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`：Подсказка для режима вдохновения от Suno (активна, если `custom` равно `false`), максимум 500 символов.
- `model`：Модель для этой задачи генерации музыки, по умолчанию `chirp-v4`, включает: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`.
- `lyric`：Текст песни для пользовательского режима от Suno. `chirp-v3-5` и `chirp-v4` максимум 3000 символов; `chirp-v4-5` и выше (включая `chirp-v5`, `chirp-v5-5`) максимум 5000 символов.
- `custom`：Использовать ли пользовательский режим, по умолчанию: `false`.
- `instrumental`：Опция чистой музыки для режима вдохновения от Suno.
- `title`：Название музыки для пользовательского режима от Suno. `chirp-v3-5`, `chirp-v4` максимум 80 символов; `chirp-v4-5` и выше максимум 100 символов.
- `style`：Стиль музыки для пользовательского режима от Suno. `chirp-v3-5` и `chirp-v4` максимум 200 символов; `chirp-v4-5` и выше (включая `chirp-v5`, `chirp-v5-5`) максимум 1000 символов.
- `style_negative`：Исключаемый стиль для пользовательского режима от Suno.
- `audio_weight`：Доля загруженного референсного аудио, диапазон 0-1, чем больше, тем больше зависимость от референсного аудио.
- `audio_id`：ID референсной музыки.
- `overpainting_start`/`overpainting_end`：Время начала и окончания добавления вокала к уже существующей чистой музыке, в секундах.
- `underpainting_start`/`underpainting_end`：Время начала и окончания добавления аккомпанемента к чистому пению, в секундах.
- `persona_id`：ID песни артиста.
- `continue_at`：Время продолжения существующего аудио в секундах. Например, 213.5 означает продолжение до 3 минут 33.5 секунд.
- `style_influence`：Расширенный параметр «Style Influence» в пользовательском режиме, диапазон 0-1, чем больше, тем ближе к выбранному стилю.
- `replace_section_end`：Конечное время замены фрагмента.
- `replace_section_start`：Начальное время замены фрагмента.
- `vocal_gender`：Контроль предпочтений по полу вокала, женский `f`, мужской `m`, эффективно для моделей 4.5 и выше; является предпочтением, не гарантирует строгого соблюдения.
- `weirdness`：Расширенный параметр «Weirdness» в пользовательском режиме, диапазон 0-1, чем больше, тем более креативно и экспериментально.
- `duration`：Ожидаемая продолжительность песни, в секундах, должна быть целым числом, диапазон от 10 до 360. Этот параметр используется для генерации песни в пользовательском режиме (`custom` равно `true`). Это склонностная подсказка, а не жесткое ограничение: модель будет учитывать это, но не гарантирует достижения, фактическая продолжительность будет указана в поле `duration` ответа, обычно меньше ожидаемого значения.
- `lyric_prompt`：Подсказка для генерации текста песни, активна только если `custom` равно `true` и `lyric` не передан.
- `callback_url`：URL для обратного вызова результатов.
- `async`：Необязательный, если установить в `true`, интерфейс сразу вернет `task_id`, не требуя предоставления `callback_url`, затем результаты можно получить через соответствующий интерфейс опроса задач.

## Пользовательская генерация

Если вы хотите настроить генерацию текста, вы можете ввести текст:

В этом случае поле `lyric` может принимать подобное содержимое:

```
[Куплет]\nСнежинки падают повсюду\nСверкающий белый\nПокрывая землю\nДети смеются\nПолны радости\nВ этой зимней стране чудес сегодня ночью\nСани Санты\nВ небе\nНос Рудольфа светится ярко\nО, мой\nСлушайте, как звенят колокольчики\nЗвучат так ясно\nПринося радость и праздничное настроение\n[Куплет 2]\nЖарим каштаны у огня\nРождественские огни\nОни мерцают и показывают\nСемьи собираются с любовью и радостью\nРаспространяя тепло всем близким

- style: стиль песни, необязательный.

## Функция генерации в стиле пользовательского исполнителя
如果想 использовать стиль певца для генерации песни, сначала сгенерируйте песню с помощью базового использования, затем необходимо установить эту песню как стиль певца, после чего нужно перейти в [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) и на основе сгенерированного музыкального ID `audio_id` получить ID параметра стиля певца `persona_id`, конкретные параметры показаны на рисунке ниже:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерировался следующий код:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

При нажатии на запуск можно увидеть результат, как показано ниже:

```json
{
  "success": true,
  "task_id": "7628b754-4fe7-4e79-bda4-806d0dd8bf6e",
  "data": {
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b"
  }
}
```

Мы используем вышеуказанные `audio_id` и `persona_id`, соответственно `97efc9f4-0e8d-4b3e-88df-14568fa1b11f` и `e0d7319e-aa2a-44cb-b00a-916218d7cb0b` в качестве примера. Затем можно установить параметр `action` как `artist_consistency` (если это новая версия стиля певца Persona-v2-vox, `action` должен быть установлен как `artist_consistency_vox`), и ввести ID для продолжения генерации песни, ID стиля певца, пример заполнения показан ниже:

<p><img src="https://cdn.acedata.cloud/fukijq.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерировался следующий код:

<p><img src="https://cdn.acedata.cloud/5uzk9d.png" width="500" className="m-auto" /></p>

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "artist_consistency",
    "prompt": "A song for Christmas",
    "model": "chirp-v4-5",
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Функция продолжения генерации

Если вы хотите продолжить генерацию уже созданной песни Suno, можно установить параметр `action` как `extend`, и ввести ID песни, которую нужно продолжить. ID песни можно получить на основе базового использования, как видно из вышеупомянутого, в этом случае ID песни будет:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Обратите внимание, что здесь `id` в тексте песни — это ID сгенерированной песни. Если вы не знаете, как сгенерировать песню, вы можете обратиться к вышеупомянутому базовому использованию для генерации песни.

Если вы хотите продолжить генерацию загруженной вами песни, можно установить параметр `action` как `upload_extend`, и ввести ID для продолжения генерации пользовательской загруженной песни. ID песни можно получить с помощью [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), как показано на рисунке ниже:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Далее необходимо заполнить текст песни, стиль для пользовательской генерации песни, указав следующие параметры:

- lyric: текст песни
- custom: установить в `true`, что означает пользовательскую генерацию, этот параметр по умолчанию равен false, что означает использование генерации по `prompt`.
- style: стиль песни, необязательный.
- continue_at: время продолжения существующего аудио в секундах. Например, 213.5 означает продолжение до 3 минут 33.5 секунд.

Пример заполнения показан ниже:

<p><img src="https://cdn.acedata.cloud/zp9s42.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерировался следующий код:

<p><img src="https://cdn.acedata.cloud/wwpw78.png" width="500" className="m-auto" /></p>

## Получение полной песни

{

}

## Замена фрагмента

Когда после генерации песни необходимо заменить отдельный фрагмент песни, можно выполнить операцию замены для определенного фрагмента песни.

> ⚠️ **Внимание**: `replace_section` при использовании отдельно **вернет только новый сгенерированный "замененный фрагмент"** (то есть новый аудиофайл замененной части, длительность примерно равна `replace_section_end - replace_section_start`, с небольшим контекстом), **и не вернет целую песню, собранную вместе**. Чтобы получить полный продукт, собранный с оригинальной песней, необходимо после успешного выполнения `replace_section` снова инициировать задачу [музыкального соединения](#музыкальное-соединение). Полный процесс описан ниже.

Описание параметров следующее:

- action: содержимое `replace_section`.
- audio_id: ID оригинальной песни (заменяемой исходной песни).
- model: модель генерации песни.
- lyric: полные слова после замены (включая заменяемый фрагмент и его контекст, соответствующий содержимому в `prompt`).
- prompt: новые слова, которые нужно заменить.
- style: стиль песни, необязательный.
- replace_section_start: начальное время заменяемого фрагмента в оригинальной песне (в секундах).
- replace_section_end: конечное время заменяемого фрагмента в оригинальной песне (в секундах).

## Разделение вокала и инструментала

После генерации песни, если требуется отдельная работа с инструменталом и вокалом, можно разделить чистый музыкальный фон и вокал. Для этого можно указать следующие параметры:

- action: значение `stems`.
- audio_id: ID ранее сгенерированной песни.

Например, если ID сгенерированной песни: ec13e502-d043-4eb2-92ee-e900c6da69d1, то параметры можно установить следующим образом:

```json
{
  "action": "stems",
  "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",

    "content-type": "application/json"
}

payload = {

    "weirdness": 0.4,
    "style_influence": 0.4,
    "audio_weight": 0.4
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)

## Управление длительностью песни

По умолчанию длительность сгенерированной песни определяется моделью и обычно составляет от 30 секунд до 4 минут. Если вам нужна более длинная или короткая версия, вы можете указать желаемую длительность с помощью параметра `duration`, единица измерения - секунды, значение должно быть целым числом от 10 до 360.

Этот параметр используется для генерации песен в пользовательском режиме (`custom` равно `true`). Следует особо отметить, что `duration` является **предпочтительным указанием, а не жестким ограничением**: модель будет учитывать это значение при создании, но не гарантирует его достижение, в реальных тестах фактическая длительность обычно значительно короче ожидаемой, а длительность двух песен, возвращаемых в одном запросе, также может отличаться в несколько раз. Даже при полностью идентичных запросах, длительность, полученная при многократной отправке, может значительно варьироваться. Поэтому не следует рассматривать это как точное управление длительностью, если в бизнесе требуется фиксированная длительность, пожалуйста, обрежьте или повторите запрос после получения готового продукта.

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Под огнями города",
    "style": "лоу-фай пиано",
    "lyric": "[Куплет]\nСолнце поднимается\nЗолото на полу\n[Припев]\nПод огнями города\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Следует отметить, что `duration` в запросе - это **ожидаемая длительность**, а поле `duration` в ответе `data` для каждой песни - это **фактическая длительность** этой песни. Оба названия совпадают, но имеют разное значение, фактическая длительность не гарантирует равенства ожидаемому значению. Длина текста является одним из основных факторов, влияющих на длительность готового продукта, если вам нужна более длинная версия, рекомендуется предоставить более полные тексты.

Интерфейс не будет выполнять дополнительную проверку `duration`, параметры будут переданы модели в неизменном виде. Если переданы значения, которые не поддерживаются текущим режимом или моделью, это может проявляться в игнорировании этого значения, рекомендуется сначала использовать один запрос для подтверждения эффекта, а затем использовать его в массовом порядке.

## Функция вдохновения Inspo

Новая функция вдохновения Inspo от Suno может создавать совершенно новую музыку, основываясь на 1-4 отрывках аудио в качестве источника вдохновения. В отличие от каверов, Inspo не воспроизводит оригинальную песню, а извлекает стилистическое вдохновение из референсного аудио и комбинирует его с подсказками, стилевыми тегами и т.д. для создания нового произведения. При использовании необходимо заполнить следующие параметры:

- action: содержимое `inspo`.
- audio_urls: список URL-адресов референсного аудио, необходимо предоставить от 1 до 4 общедоступных аудиоссылок.
- model: используемая модель, например, `chirp-v5`.
- prompt: текст песни или творческая подсказка (необязательно).
- tags: теги музыкального стиля, например, `акустика, фолк, теплый` (необязательно).
- title: заголовок песни (необязательно).
- audio_weight: вес влияния референсного аудио на результат генерации, диапазон значений от 0 до 1 (необязательно).

> Примечание: референсное аудио должно быть общедоступным аудиофайлом. Если референсное аудио полностью совпадает с известной записью в библиотеке платформы, Suno может отказать в генерации из-за проверки авторских прав, рекомендуется использовать собственное или сгенерированное Suno аудио в качестве источника вдохновения.

Соответствующий код на Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "теплая акустическая фолк с мягким вокалом",
    "tags": "акустика, фолк, теплый",
    "title": "Демо вдохновения",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Асинхронный обратный вызов

Поскольку время генерации музыки Suno относительно долгое, около 1-2 минут, если API долго не отвечает, HTTP-запрос будет поддерживать соединение, что приведет к дополнительному потреблению системных ресурсов, поэтому этот API также поддерживает асинхронные обратные вызовы.

Общий процесс таков: когда клиент инициирует запрос, дополнительно указывается поле `callback_url`, после того как клиент инициирует API-запрос, API немедленно возвращает результат, содержащий информацию о поле `task_id`, представляющем текущий ID задачи. Когда задача завершена, результат генерации музыки будет отправлен на указанный клиентом `callback_url` в формате POST JSON, который также включает поле `task_id`, так что результат задачи можно связать по ID.

Давайте рассмотрим конкретные действия на примере.

Во-первых, обратный вызов Webhook — это служба, которая может принимать HTTP-запросы, разработчики должны заменить его на URL своего HTTP-сервера. Здесь для удобства демонстрации используется публичный сайт примера Webhook https://webhook.site/, открыв этот сайт, вы получите URL Webhook, как показано на изображении:
