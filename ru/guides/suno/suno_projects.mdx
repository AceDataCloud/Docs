`POST https://api.acedata.cloud/suno/projects` — это Beta-интерфейс для управления многодорожечными проектами. Один эндпоинт различает создание, сохранение, генерацию кандидатов, подтверждение кандидатов и экспорт через `action`. Вызывающей стороне достаточно использовать публичные поля ниже, не нужно заполнять внутреннюю структуру запросов базового сервиса генерации.

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: 每次修改操作使用新的 UUID
```

Кроме `retrieve`, **каждая операция требует** `Idempotency-Key`. Одинаковый ключ и одинаковый запрос возвращают только исходный результат; одинаковый ключ с разными запросами возвращает 409. При сетевом тайм-ауте во время платной генерации или неопределённости результата отправки сначала используйте исходный ID задачи или тот же ключ идемпотентности для запроса, нельзя напрямую менять ключ и отправлять повторно.

## Сначала различайте эти ID и единицы времени

| Название                       | Откуда получить                                                                                      | Где использовать                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | Ответ `create` `data.id`                                                                      | Все последующие запросы текущего проекта                                      |
| `version_id`                   | `data.version_id` из последнего `retrieve`, `save`, `add_track`, `commit_candidate` или `remove_track` | Изменение, генерация кандидатов и экспорт; необходимо использовать последнюю версию                              |
| `audio_id` / `source_audio_id` | `response.data.candidate.audio_id` в конечном состоянии `upload`, или ID существующего завершённого аудио                                | Ссылка на исходное аудио при `add_track`, генерации или замене                          |
| `render_audio_id`              | `response.data.audio_id` в конечном состоянии `render`                                                       | Ссылка на микс проекта для `generate_track`                         |
| `operation_id`                 | `response.data.operation_id` в конечном состоянии `generate_track` или `replace_section`                       | `commit_candidate`; обычно совпадает с `task_id` задачи генерации, но следует читать возвращённое значение |
| `candidate_id`                 | `response.data.candidates[].id` в конечном состоянии генерации                                                       | Выбор кандидата для подтверждения                                         |
| `track_id`                     | `data.state.tracks[].id` проекта                                                                | Подтверждение кандидата или удаление дорожки                                        |
| `task_id`                      | Ответ отправки асинхронной операции                                                                                   | Запрос конечного состояния через `/suno/tasks`; это не ID проекта                   |

`start_seconds` / `end_seconds` — это **секунды внутри исходного аудио**; `start_beats` / `end_beats` — это** количество долей на временной шкале проекта**. `state.timing.bps` — это количество долей в секунду, по умолчанию 2. Например, фрагмент длительностью 41 секунду начинается с 0-й доли, а конечная точка по умолчанию — 82-я доля. Интервал секунд `generate_track` используется для указания ссылки генерации и не гарантирует, что кандидат будет иметь длину только этого интервала.

## Последовательность операций и определение результатов

| Последовательность  | `action`                             | Назначение                         | Способ возврата         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | Создание пустого проекта                      | Синхронные данные проекта       |
| 2   | `retrieve`                           | Чтение последней версии и полного `state`          | Синхронные данные проекта       |
| 3   | `save`                               | Первое сохранение или общее сохранение изменённого `state`      | Синхронные данные проекта       |
| 4   | `upload`                             | Создание материала из HTTPS-адреса аудио           | Асинхронная задача         |
| 5   | `add_track`                          | Добавление аудио материала в проект                  | Асинхронная задача, обновляет версию    |
| 6   | `save`                               | Если нужно получать кандидатов новой дорожки, сначала сохраните пустую целевую дорожку        | Синхронные данные проекта, обновляет версию  |
| 7   | `render`                             | Экспорт текущих слышимых дорожек, получение ссылки на микс `audio_id` | Асинхронная задача         |
| 8   | `generate_track` или `replace_section` | Соответственно генерация кандидатов новой дорожки или кандидатов локальной замены            | Асинхронная задача, пока не изменяет проект  |
| 9   | `commit_candidate`                   | Выбор и подтверждение кандидата                  | Асинхронная задача, после успеха обновляет версию |
| Необязательно  | `remove_track`                       | Удаление указанной дорожки                     | Синхронные данные проекта, обновляет версию  |

Если выполняется только локальная замена, достаточно существующего доступного исходного аудио, предварительный `render` не нужен; если исходное аудио уже находится в проекте, также можно пропустить `upload` и `add_track`. `render_audio_id` является обязательной ссылкой только для `generate_track`.

При отправке асинхронной операции сначала возвращается `{ "task_id": "...", "trace_id": "..." }`, **это не означает успешную генерацию**. Опрос:

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

Задача считается успешной только если запись задачи имеет `finished_at`, а её `response.success` равно `true`; при `response.success=false` читайте `response.error`. Хотя `save` может содержать `task_id`, оно выполняется синхронно в рамках этого интерфейса. `upload`, `render`, `generate_track`, `replace_section` не изменяют версию проекта; после успеха `save`, `add_track`, `commit_candidate`, `remove_track` следует получить новый `version_id`.

## Параметры запроса

### Общие поля и заголовки запроса

| Параметр                | Тип и область применения                                                                                   | Описание                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | Обязательная строка                                                                                     | Фиксированно одно из названий операций, перечисленных на этой странице; один запрос выполняет только одну операцию.                                      |
| `id`              | Обязательная строка, кроме `create`                                                                         | ID проекта, из `create.data.id`.                                      |
| `version_id`      | Обязательная строка при изменении, генерации кандидатов и экспорте; при первом `save` пустого проекта может быть опущена                                                         | Используйте последнюю версию, старая версия будет отклонена. Для `retrieve` не требуется.                                 |
| `Idempotency-Key` | Обязательный заголовок запроса, кроме `retrieve`, 1–128 символов                                                              | Используйте новый ключ для каждой новой операции; одинаковый ключ и запрос возвращают исходный результат, не генерируя повторно и не списывая оплату.                                   |
| `async`           | Необязательное булево значение для `upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`, `render` | Эти операции всегда асинхронны; `false` также не сделает генерацию синхронной.                                    |
| `callback_url`    | Необязательный URL для операций с указанными выше необязательными асинхронными полями                                                                       | Получение уведомления о конечном состоянии; при отсутствии запрашивайте `/suno/tasks` по `task_id`. Всё равно необходимо проверять `response.success`. |

### Проект и материалы
| `action`       | Специальный параметр        | Тип и условия                       | Описание                                                                 |
| -------------- | --------------------------- | ----------------------------------- | ------------------------------------------------------------------------ |
| `create`       | `title`                     | Обязательная строка, 1–200 символов | Заголовок нового проекта.                                                |
| `retrieve`     | Нет                         | —                                   | Требуются только `action` и `id` проекта; возвращает полное редактируемое `state`. |
| `save`         | `state`                     | Обязательный объект                 | **Полностью заменяет** состояние проекта, а не является частичным патчем. Вносите изменения на основе последнего `retrieve.data.state` и отправляйте его целиком, сохраняя неизвестные поля. |
| `save`         | `title`                     | Необязательная строка               | Заголовок проекта; если опущен, используется `state.title`, а если его также нет — заголовок по умолчанию. |
| `upload`       | `audio_url`                 | Обязательный HTTPS URL              | Общедоступный адрес аудиоматериала; после успеха считывайте конечное состояние `candidate.audio_id`. Права на использование материала должны принадлежать вызывающей стороне. |
| `add_track`    | `audio_id`                  | Обязательная строка                 | Аудио ID завершённого материала, а не URL.                               |
| `add_track`    | `name` / `color`            | Необязательные строки               | Название и цвет новой дорожки; по умолчанию название берётся из заголовка аудио, рекомендуемый цвет — `#RRGGBB`, по умолчанию `#7251F7`. |
| `add_track`    | `title`                     | Необязательная строка               | Одновременно изменяет заголовок проекта; обычно опускается.              |
| `add_track`    | `start_beats` / `end_beats` | Необязательные неотрицательные числа, `end_beats > start_beats` | Положение фрагмента на временной шкале проекта. Начальная точка по умолчанию — 0; конечная точка по умолчанию — `начальная точка + длительность аудио × timing.bps`. |
| `add_track`    | `gain`                      | Необязательное неотрицательное число, по умолчанию 1 | Коэффициент громкости фрагмента и новой дорожки.                         |
| `remove_track` | `track_id`                  | Обязательная строка                 | ID существующей дорожки, которую нужно удалить. После успеха используйте возвращённую новую версию. |

`state.timing.bps` должен быть положительным числом, по умолчанию 2. `state.tracks` — это массив дорожек; `clipId` существующих аудиофрагментов ссылается на аудио ID, а `startBeats`, `endBeats`, `readStartBeats` используют единицы тактов проекта. Самый безопасный способ редактирования — считать полное `state`, изменить только целевую дорожку или фрагмент, затем выполнить полный `save`. Новая пустая целевая дорожка должна как минимум иметь уникальный `id`, `type:"audio"`, `clips:[]`; полную форму, пригодную для реального использования, см. в шаге 5 ниже. Не используйте точки ударов из результатов аудиоанализа напрямую в качестве координат временной шкалы проекта.

### Генерация, отправка и экспорт
| `action`                             | Специальные параметры               | Тип и условия                                 | Описание                                                                                                                                                        |
| ------------------------------------ | ---------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generate_track` / `replace_section` | `source_audio_id`                  | Обязательная строка                                  | ID завершённого исходного аудио. Сначала добавьте исходное аудио в проект, чтобы последующие кандидаты могли найти соответствующую позицию.                                                                                                                        |
| `generate_track` / `replace_section` | `model`                            | Обязательная строка перечисления                                | Доступны `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`, `chirp-v6`, `chirp-v6-wild`, `chirp-v6-mini`. Доступность модели и операции определяется конечным состоянием задачи; автоматического перехода на другие модели не будет. |
| `generate_track` / `replace_section` | `start_seconds` / `end_seconds`    | Обязательные числа, `0 ≤ start_seconds &lt; end_seconds` | Начальная и конечная секунды в исходном аудио; при замене конечная точка также не должна превышать фактическую длительность исходного аудио. Это не биты проекта и не гарантирует длительность вывода кандидата.                                                                                                         |
| `generate_track`                     | `render_audio_id`                  | Обязательная строка                                  | `response.data.audio_id` после успешного `render` текущего проекта, используемый в качестве эталона микса при генерации.                                                                                                   |
| `generate_track`                     | `stem_control_tags`                | Обязательная строка                                  | Описание добавляемой партии, например `add Piano`, `add Drums`, `add Bass`; не является фиксированным перечислением.                                                                                                      |
| `generate_track`                     | `batch_size`                       | Необязательное целое число 1–4, по умолчанию 2                          | Количество запрашиваемых генерируемых кандидатов.                                                                                                                                                |
| `generate_track`                     | `instrumental` / `vocal_gender`    | Необязательное булево значение／строка перечисления                            | По умолчанию `instrumental` — `true`; для предпочтения вокала можно указать `f`, `m`, `unspecified`, по умолчанию — `unspecified`. Следование предпочтению определяется фактическим аудио.                                                                     |
| `generate_track` / `replace_section` | `title` / `tags` / `negative_tags` | Необязательная строка                                  | Заголовок кандидата, описание желаемого стиля, теги стилей, которых следует избегать. При пропуске `tags` и `negative_tags` передавайте пустые строки.                                                                                                  |
| `generate_track`                     | `prompt`                           | Необязательная строка                                  | Текстовая или лирическая подсказка для новой партии; для чистой инструментальной музыки можно пропустить.                                                                                                                                       |
| `replace_section`                    | `prompt` / `replacement_lyrics`    | Необязательная строка                                  | Первое — текст оригинальной песни или контекстный текст, второе — новый текст для заменяемого интервала; при пропуске передавайте пустые строки.                                                                                                                      |
| `replace_section`                    | `fixed`                            | Необязательное булево значение, по умолчанию `false`                       | Запрашивает замену фиксированной длины; при `true` интервал должен быть короче 26 секунд, и выбранная модель может не поддерживать это. В данном реальном примере используется режим по умолчанию, `fixed=true` ещё не проверен.                                                                                    |
| `commit_candidate`                   | `operation_id` / `candidate_id`    | Обязательная строка                                  | Соответственно берутся из `data.operation_id` в конечном состоянии генерации и из выбранного `data.candidates[].id`; кандидат должен принадлежать текущей версии проекта.                                                                                    |
| `commit_candidate`                   | `track_id`                         | Обязательная строка                                  | Кандидат новой дорожки должен быть отправлен на **пустую дорожку, сохранённую до генерации**; кандидат локальной замены отправляется на исходную дорожку, содержащую единственный исходный фрагмент.                                                                                                              |
| `commit_candidate`                   | `start_beats` / `end_beats`        | Необязательные неотрицательные числа только для кандидатов новых дорожек                           | Задаёт положение нового фрагмента на временной шкале проекта; при пропуске используется начальная точка исходного фрагмента, а конечная точка вычисляется по фактической длительности кандидата. Не должно быть перекрытия с существующими фрагментами целевой дорожки. **Для кандидатов локальной замены должны быть пропущены**.                                                                                      |
| `commit_candidate`                   | `name` / `gain`                    | Необязательная строка／неотрицательное число только для кандидатов новых дорожек                       | Название генерируемого фрагмента и коэффициент громкости, по умолчанию `gain` равен 1.                                                                                                                                  |
| `render`                             | `title`                            | Обязательная строка                                  | Заголовок экспортируемого аудио.                                                                                                                                                   |
| `render`                             | `lyrics` / `tags`                  | Необязательная строка                                  | Текст песни и описание стиля при экспорте; по умолчанию текст песни — `[Instrumental]`.                                                                                                                      |
| `render`                             | `start_beats` / `end_beats`        | Необязательные неотрицательные числа, конец должен быть больше начала                         | Экспортирует диапазон битов проекта; при пропуске берутся самая ранняя начальная и самая поздняя конечная точки всех слышимых фрагментов. Тихие фрагменты не участвуют, при наличии solo-дорожек выбираются только solo-дорожки.                                                                                             |

Генерация создаёт только кандидатов, **не добавляя их автоматически в проект**. `commit_candidate` проверяет, что кандидат всё ещё принадлежит текущей версии. Кандидат локальной замены может быть автоматически добавлен только тогда, когда его фактическая длительность может быть надёжно сопоставлена с полным исходным аудио или выбранным интервалом; при несовпадении исходный проект сохраняется и возвращается ошибка, нельзя принудительно состыковать его ручным угадыванием количества битов.

## Реальные запросы и ответы от 2026-10-09

Следующие тела запросов и поля ответов взяты из реальных вызовов одного и того же проекта. Каждая группа JSON последовательно содержит запрос, ответ о принятии (если асинхронно), ответ конечного состояния задачи. Для удобства чтения в ответах приведены только поля, необходимые для завершения данного процесса; поля аккаунта, использования и времени выполнения не показаны. Примерные ID принадлежат этому тестовому приложению, при интеграции необходимо использовать ID, возвращённые вашими собственными запросами, и новый `Idempotency-Key`.

### 1. Создание и чтение пустого проекта: `create`, `retrieve`

Запрос `create`:

```json
{
  "action": "create",
  "title": "Suno Projects Documentation Verification 2026-10-09"
}
```

```json
{
  "success": true,
  "trace_id": "42408a82-988b-4127-ba68-9b89348a7c56",
  "data": {
    "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
    "title": "Suno Projects Documentation Verification 2026-10-09",
    "state": {
      "tracks": [],
      "timing": {
        "bps": 2
      }
    }
  }
}
```

Сразу после этого вызовите `retrieve`:

```json
{
  "action": "retrieve",
  "id": "af0e104a-2a4c-40e0-9c70-7614566824a6"
}
```

```json
{
  "success": true,
  "trace_id": "a335ceac-5cb7-4b1c-9773-77b9d5c84bd7",
  "data": {
    "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
    "title": "Suno Projects Documentation Verification 2026-10-09",
    "state": {
      "tracks": [],
      "timing": {
        "bps": 2
      }
    }
  }
}
```

### 2. Первое сохранение: `save`

У нового проекта нет `version_id`, при первом сохранении пропустите его:
```json
{
  "action": "save",
  "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
  "title": "Suno Projects Documentation Verification 2026-10-09",
  "state": {
    "tracks": [],
    "timing": {
      "bps": 2
    }
  }
}
```

```json
{
  "success": true,
  "task_id": "ab172b47-4d89-404b-a10e-71f67c36ccba",
  "trace_id": "fc7b2e43-7a7a-4276-8671-27008a1153ea",
  "data": {
    "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
    "version_id": "8f0c62fb-304f-420e-9707-426e8b64b5e3",
    "state": {
      "timing": {
        "bps": 2
      },
      "tracks": []
    }
  }
}
```

### 3. Загрузка материала: `upload`

```json
{
```

| Результат                                                                            | Значение                          | Следующий шаг                                    |
| ----------------------------------------------------------------------------- | --------------------------- | -------------------------------------- |
| `project_version_conflict` / `project_candidate_stale`（409）                   | Версия проекта изменилась или кандидат не принадлежит текущей версии.         | Выполните `retrieve` последнего проекта и заново спланируйте изменения; не воспроизводите старого кандидата.        |

| `studio_unavailable` / `studio_model_unavailable`（503）                        | Обработка проекта или выбранная модель временно недоступны.             | Сохраните результат исходной задачи; позже выполните явную повторную попытку, не переключайте модель автоматически.                |
| `studio_processing_failed` / тайм-аут（500/504）                                      | Обработка завершилась сбоем или конечное состояние неопределённо.                 | Запросите по `task_id` или исходному ключу идемпотентности, чтобы избежать повторно оплачиваемой генерации.          |

Проекты и кандидаты привязаны к приложению и среде выполнения, которые их создали, поэтому нельзя предполагать повторное использование между приложениями или автоматическое аварийное переключение. Сохраняйте окончательный URL успешно экспортированного аудио и сохраняйте `trace_id` для упрощения диагностики.
