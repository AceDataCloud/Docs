API проекта Suno Studio управляет многодорожечными музыкальными проектами через одну точку входа:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

`action` в запросе определяет тип операции. Первичный ключ Project единообразно использует `id`; `version_id` обозначает текущую версию проекта, и все операции изменения и экспорта должны отправлять последнюю версию, чтобы избежать перезаписи при конкуренции.

## Обзор операций

| action             | Режим  | Назначение                      |
| ------------------ | --- | ----------------------- |
| `create`           | Синхронный  | Создать пустой проект                   |
| `retrieve`         | Синхронный  | Прочитать проект и полный редактируемый `state`      |
| `save`             | Синхронный  | Сохранить полное состояние проекта                |
| `upload`           | Асинхронный  | Инициализировать из HTTPS-адреса аудио материал, который можно добавить в проект |
| `add_track`        | Асинхронный  | Добавить существующее аудио в проект               |
| `generate_track`   | Асинхронный  | Сгенерировать кандидата новой аудиодорожки для указанного интервала            |
| `replace_section`  | Асинхронный  | Сгенерировать кандидатов локальной замены                |
| `commit_candidate` | Асинхронный  | Зафиксировать выбранного кандидата в проекте             |
| `remove_track`     | Синхронный  | Удалить указанную дорожку                  |
| `render`           | Асинхронный  | Экспортировать сохранённую версию как полную песню           |

Асинхронные операции немедленно возвращают `task_id`. Используйте бесплатный интерфейс `/suno/tasks` для опроса или передайте `callback_url` для получения результата в конечном состоянии.

## Создание и чтение

```json
{"action":"create","title":"My Studio Project"}
```

Все операции изменения должны отправлять уникальный Header `Idempotency-Key`. После успешного создания `data.id` в ответе является Project ID.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

Ответ на чтение содержит полный `state`. Рекомендуется сначала прочитать, затем изменить и сохранить на основе возвращённого значения; не конструируйте внутреннюю структуру ритма и дорожек вручную с нуля.

## Сохранение полного состояния

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

Если версия уже изменилась, интерфейс возвращает HTTP 409. В этом случае повторно выполните `retrieve`, объедините изменения и затем отправьте запрос с новым ключом идемпотентности; не повторяйте старый запрос вслепую.

## Загрузка и добавление дорожек

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

После завершения загрузки результат задачи возвращает кандидата `audio_id`. Затем добавьте его в проект:

```json
{
  "action":"add_track",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_id":"AUDIO_ID",
  "name":"Backing Vocals"
}
```

## Генерация и замена

`generate_track` генерирует кандидата аудиодорожки для интервала проекта; `replace_section` возвращает двух кандидатов локальной замены. Обе операции не выбирают художественный результат автоматически.

```json
{
  "action":"replace_section",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "source_audio_id":"AUDIO_ID",
  "start_seconds":35.12,
  "end_seconds":48.76,
  "model":"chirp-v6",
  "replacement_lyrics":"新的歌词片段",
  "async":true
}
```

После выбора кандидата зафиксируйте его:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Кандидаты привязаны к версии проекта на момент генерации. Если проект уже изменился, старых кандидатов нельзя зафиксировать напрямую.

## Экспорт полной песни

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

Сервер считывает авторитетное состояние проекта указанной версии и собирает параметры экспорта. Результат в конечном состоянии содержит `render_id`, `audio_id`, `audio_url` и длительность. Проект привязан к среде выполнения при создании и не может переноситься между средами или автоматически переключаться при сбое.

> Загружайте или обрабатывайте только аудио, на законное использование которого у вас есть права. API проекта в настоящее время находится в Beta; сохраняйте окончательный URL аудио из важных результатов.
