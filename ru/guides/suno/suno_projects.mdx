`POST https://api.acedata.cloud/suno/projects` — это Beta-интерфейс для управления многодорожечными проектами. Для различения создания, сохранения, генерации кандидатов, отправки кандидатов и экспорта используется `action`.

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: <每次写操作的新 UUID>
```

За исключением `retrieve`, **каждая операция требует** `Idempotency-Key`. Одинаковый ключ и одинаковый запрос только повторно считывают исходный результат; одинаковый ключ с разными запросами возвращает 409. Если при платной генерации возникает сетевой тайм-аут или результат отправки неопределён, сначала выполните запрос с исходным ID задачи или тем же ключом идемпотентности; нельзя напрямую сменить ключ и отправить повторно.

## Идентификаторы и единицы времени

| Название                       | Где получить                                                                                | Где использовать                                      |
| ------------------------------ | -------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| `id`                           | `data.id` в ответе `create`                                                                 | Все последующие запросы текущего проекта              |
| `version_id`                   | `data.version_id` последнего `retrieve`, `save`, `add_track`, `commit_candidate` или `remove_track` | Изменение, генерация кандидатов и экспорт; необходимо использовать последнюю версию |
| `audio_id` / `source_audio_id` | `response.data.candidate.audio_id` конечного состояния `upload` или существующий завершённый ID аудио | Ссылка на исходное аудио при `add_track`, генерации или замене |
| `render_audio_id`              | `response.data.audio_id` конечного состояния `render`                                       | Ссылка на микс проекта для `generate_track`           |
| `operation_id`                 | `response.data.operation_id` конечного состояния `generate_track` или `replace_section`     | `commit_candidate`; обычно совпадает с `task_id` задачи генерации, но следует считывать возвращённое значение |
| `candidate_id`                 | `response.data.candidates[].id` конечного состояния генерации                               | Выбор кандидата для отправки                          |
| `track_id`                     | `data.state.tracks[].id` проекта                                                            | Отправка кандидата или удаление дорожки               |
| `task_id`                      | Ответ отправки асинхронной операции                                                          | Используйте `/suno/tasks` для запроса конечного состояния; это не ID проекта |

`start_seconds` / `end_seconds` — это **секунды внутри исходного аудио**; `start_beats` / `end_beats` — это **доли на временной шкале проекта**. `state.timing.bps` — это число долей в секунду, по умолчанию 2. Например, для фрагмента длительностью 41 секунду, начинающегося с доли 0, конечной точкой по умолчанию будет доля 82. Диапазон секунд `generate_track` используется для указания ссылки генерации и не гарантирует, что кандидат будет иметь длину только этого диапазона.

## Процесс операций

| Порядок | `action`                             | Назначение                                        | Способ возврата             |
| --- | ------------------------------------ | ------------------------------------------------- | --------------------------- |
| 1   | `create`                             | Создание пустого проекта                          | Синхронные данные проекта   |
| 2   | `retrieve`                           | Чтение последней версии и полного `state`         | Синхронные данные проекта   |
| 3   | `save`                               | Первое сохранение или общее сохранение изменённого `state` | Синхронные данные проекта   |
| 4   | `upload`                             | Создание материала из HTTPS-адреса аудио          | Асинхронная задача          |
| 5   | `add_track`                          | Размещение аудио материала в проекте              | Асинхронная задача, обновляет версию |
| 6   | `save`                               | Если необходимо принимать кандидатов новой дорожки, сначала сохраните пустую целевую дорожку | Синхронные данные проекта, обновляет версию |
| 7   | `render`                             | Экспорт текущих доступных для прослушивания дорожек, получение ссылки микса `audio_id` | Асинхронная задача          |
| 8   | `generate_track` или `replace_section` | Соответственно генерация кандидатов новой дорожки или кандидатов локальной замены | Асинхронная задача, временно не изменяет проект |
| 9   | `commit_candidate`                   | Выбор и отправка кандидата                        | Асинхронная задача, после успеха обновляет версию |
| Необязательно | `remove_track`                       | Удаление указанной дорожки                        | Синхронные данные проекта, обновляет версию |

Если выполняется только локальная замена, достаточно существующего доступного исходного аудио, предварительный `render` не требуется; если исходное аудио уже находится в проекте, также можно пропустить `upload` и `add_track`. `render_audio_id` является обязательной ссылкой только для `generate_track`.

При отправке асинхронной операции сначала возвращается `{ "task_id": "...", "trace_id": "..." }`, **это не означает успешную генерацию**. Опрос:

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

Задача считается успешной только при наличии у записи задачи `finished_at` и значении `response.success` в ней, равном `true`; при `response.success=false` прочитайте `response.error`. Хотя `save` может содержать `task_id`, в этом интерфейсе он выполняется синхронно. `upload`, `render`, `generate_track`, `replace_section` не изменяют версию проекта; после успешного выполнения `save`, `add_track`, `commit_candidate`, `remove_track` следует получить новый `version_id`.

## Соглашения о запросах

| Параметр          | Тип и область применения                                                                      | Описание                                                        |
| ----------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | Обязательная строка                                                                          | Фиксированно одно из названий операций, перечисленных на этой странице; один запрос выполняет только одну операцию. |
| `id`              | Обязательная строка, кроме `create`                                                          | ID проекта, из `create.data.id`.                                |
| `version_id`      | Обязательная строка при изменении, генерации кандидатов и экспорте; при первом `save` пустого проекта может быть опущена | Используйте последнюю версию, старая версия будет отклонена. `retrieve` не требует её. |
| `Idempotency-Key` | Обязательный заголовок запроса, кроме `retrieve`, 1–128 символов                             | Используйте новый ключ для каждой новой операции; одинаковый ключ и одинаковый запрос повторно считывают исходный результат, без повторной генерации или списания средств. |
| `async`           | Необязательное логическое значение для `upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`, `render` | Эти операции всегда асинхронны; `false` также не сделает генерацию синхронной. |
| `callback_url`    | Необязательный URL для асинхронных операций                                                  | Получение уведомления о конечном состоянии; при отсутствии используйте `task_id` для запроса `/suno/tasks`. Всё равно необходимо проверять `response.success`. |

Следующие примеры последовательно показывают передачу ID и версии между операциями. В ответах перечислены только поля, относящиеся к текущему шагу; при подключении замените примерные ID значениями ответов текущего приложения.

## Сохранение состояния проекта

| Параметр | Тип и описание |
|---|---|
| `state` | Обязательный объект. Отправьте **полное состояние проекта**, а не частичный патч; используйте в качестве основы `data.state`, возвращённый последней операцией чтения или изменения, сохраняя неизвестные поля. |
| `title` | Необязательная строка; при пропуске используется `state.title`, а если его также нет — заголовок по умолчанию. |
| `version_id` | При первом сохранении нового пустого проекта может быть пропущен; после этого необходимо использовать последнюю версию. |

`state.timing.bps` должен быть положительным числом, по умолчанию 2. `state.tracks` — массив дорожек; `clipId` существующих аудиоклипов ссылается на аудио ID, `startBeats`, `endBeats`, `readStartBeats` используют единицы долей проекта. Самый безопасный способ редактирования — прочитать полное `state`, изменить только целевую дорожку или клип, а затем целиком выполнить `save`. Новая пустая целевая дорожка должна как минимум иметь уникальный `id`, `type:"audio"`, `clips:[]`; полная структура пустой дорожки приведена в примере в разделе «Генерация новой аудиодорожки». Не используйте точки долей из результатов анализа аудио напрямую в качестве координат временной шкалы проекта.

## Загрузка аудио и добавление дорожки

| Операция | Параметр | Тип и описание |
|---|---|---|
| `upload` | `audio_url` | Обязательный HTTPS URL, указывающий на общедоступное аудио, которое вы имеете право использовать. `candidate.audio_id` в конечном состоянии можно использовать для добавления дорожки. |
| `add_track` | `audio_id` | Обязательная строка; аудио ID завершённого материала, а не URL. |
| `add_track` | `name`、`color` | Необязательные строки; имя дорожки по умолчанию берётся из заголовка аудио, рекомендуемый цвет — `#RRGGBB`, по умолчанию `#7251F7`. |
| `add_track` | `title` | Необязательная строка; одновременно изменяет заголовок проекта, обычно пропускается. |
| `add_track` | `start_beats`、`end_beats` | Необязательные неотрицательные числа, конечная точка должна быть больше начальной; по умолчанию начинается с 0-й доли, конечная точка вычисляется по длительности аудио и `timing.bps`. |
| `add_track` | `gain` | Необязательное неотрицательное число, по умолчанию 1; коэффициент громкости клипа и дорожки. |

## Генерация новой аудиодорожки

Кандидаты связаны с версией проекта на момент генерации. Сначала сохраните пустую дорожку для получения кандидатов, затем экспортируйте текущий микс в качестве референса для генерации; после завершения генерации выберите одного кандидата для отправки на эту пустую дорожку.

### Резервирование целевой дорожки: `save`

Кандидаты `generate_track` связаны с текущей версией проекта. В **полном** `state`, возвращённом в конечном состоянии предыдущего `add_track`, добавьте в `state.tracks` следующую пустую дорожку, затем сохраните через `save`; все остальные существующие поля сохраните без изменений:
```

"type": "audio",
"name": "Сгенерированное пианино",
"clips": [],
"takeLanes": [],
"mute": false,
"solo": false,
"amplitude": 1,
"instrument": &#123;

&#125;,
"color": "#7251F7"
&#125;

### Генерация кандидатов: `generate_track`

Каждый раз фиксированно отправляются по 2 кандидата.

| Параметр | Тип и описание |
|---|---|
| `source_audio_id` | Обязательный; ID завершённого исходного аудио. Сначала добавьте исходное аудио в проект, только после этого можно определить расположение кандидатов. |
| `render_audio_id` | Обязательный; `response.data.audio_id` из конечного состояния указанного выше `render`, а не URL аудио. |
| `model` | Обязательный; доступны `chirp-v3-5`、`chirp-v4`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`、`chirp-v6`、`chirp-v6-wild`、`chirp-v6-mini`. Доступность конкретных комбинаций определяется конечным состоянием задачи. |

## Замена существующего клипа

`replace_section` может напрямую использовать существующее исходное аудио, без необходимости сначала экспортировать микс. Генерация возвращает только кандидатов; при принятии выберите исходную дорожку, содержащую единственный исходный клип.

| Параметр | Тип и описание |
|---|---|
| `source_audio_id` | Обязателен; ID завершённого исходного аудио, которое требуется заменить. |
| `model` | Обязателен; используйте публичные модели, перечисленные в разделе «Генерация кандидатов», доступность модели и операции определяется конечным состоянием задачи. |
| `start_seconds`、`end_seconds` | Обязательные числа, `0 ≤ start_seconds < end_seconds ≤ длительность исходного аудио`; интервал в секундах внутри исходного аудио. |
| `prompt`、`replacement_lyrics` | Необязательные строки; первая — исходный текст или контекст, вторая — новый текст для заменяемого интервала. |
| `title`、`tags`、`negative_tags` | Необязательные строки; заголовок кандидата, желаемый стиль и стили, которых следует избегать. |
| `fixed` | Необязательное булево значение, по умолчанию `false`; при значении `true` интервал должен быть короче 26 секунд, и модель может не поддерживать его. |

## Ошибки и восстановление

| Результат | Значение | Следующий шаг |
|---|---|---|
| `project_version_conflict` / `project_candidate_stale`(409) | Версия проекта изменилась или кандидат не принадлежит текущей версии. | `retrieve` Повторно откройте последний проект и внесите изменения в план; не воспроизводите старые кандидаты. |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported` (обычно 400) | Параметры, состояние дорожки, длительность кандидата или модель несовместимы с операцией. | Проверьте ошибку конечного состояния задачи и исправьте входные данные; если кандидаты нельзя безопасно объединить, сохраните исходный проект. |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`(403) | Эталонное аудио недоступно для этой операции проекта, отсутствуют права доступа или оно отклонено проверкой содержимого. | Проверьте источник аудио и задачу `trace_id`; не приравнивайте уже сгенерированный кандидат к возможности экспорта всей композиции. |
| `too_many_requests`(429) | Запрос ограничен по частоте. | Сначала запросите исходную задачу, затем решите, следует ли запускать новую операцию с новым ключом идемпотентности. |
| `studio_unavailable` / `studio_model_unavailable`(503) | Обработка проекта или выбранная модель временно недоступны. | Сохраните результат исходной задачи; повторите попытку позже явно, не переключая модель автоматически. |
| `studio_processing_failed` / тайм-аут (500/504) | Обработка не удалась или конечное состояние неопределённо. | Выполните запрос по `task_id` или исходному ключу идемпотентности, чтобы избежать повторно оплачиваемой генерации. |

Проекты и кандидаты привязаны к приложению, в котором они были созданы; используйте исходное приложение для доступа. Сохраняйте URL окончательно успешно экспортированного аудио и сохраняйте `trace_id` для диагностики.
