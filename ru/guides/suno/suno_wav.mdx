SUNO позволяет нам получать музыкальные файлы в формате wav. В этом документе объясняется, как интегрировать соответствующий API.

Основным входным параметром этого API является `audio_id`, который является официально сгенерированным ID песни; также поддерживается необязательный параметр `callback_url` для асинхронного обратного вызова.

Здесь мы вводим `audio_id`, который равен `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Результат будет следующим:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

Можно увидеть, что поле `file_url` в `data` содержит полученный музыкальный файл в формате wav, это общедоступный адрес CDN.

> **О постоянстве ссылки на WAV**
> Платформа сначала будет сохранять конечный WAV файл в Ace Data Cloud CDN перед возвратом. Указанный выше URL лишь демонстрирует формат ответа и не представляет собой долгосрочный реальный объект. Только если процесс сохранения в CDN не завершен, и оригинальный медиа-адрес по мгновенной проверке все еще может загрузить действительный WAV файл, `file_url` может сохранить этот адрес; если адрес недействителен или проверка файла не удалась, запрос вернет ошибку или тайм-аут, и недоступный адрес не будет считаться успешным результатом. Пожалуйста, скачайте и надежно сохраните файл сразу после завершения задачи, конкретный срок хранения зависит от текущей стратегии хранения платформы.
