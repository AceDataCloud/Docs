---
title: "Инструкция по интеграции API пользовательского стиля певца Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO позволяет нам задавать стиль певца для уже созданных песен, а затем выполнять вторичное творчество на его основе. В этом документе объясняется метод интеграции соответствующего API.

`GET /suno/persona` для запроса списка и `DELETE /suno/persona` для удаления записей не тарифицируются, дополнительные заголовки запросов для освобождения от тарификации не требуются. Операция создания `POST /suno/persona` по-прежнему тарифицируется согласно правилам ценообразования интерфейса.

Этот API имеет только три входных параметра: сначала `audio_id` — это ID песни, уже успешно созданной в официальном сервисе, затем `name`, `description` — это название и описание стиля певца.

Здесь введённый нами `audio_id` — это `https://cdn.acedata.cloud/2qhzs3.png`; для пользовательской генерации песни можно обратиться к [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), и в итоге можно получить `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Результат следующий:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Можно увидеть, что поле `persona_id` в `data` — это ID созданного стиля певца.

После получения ID стиля певца мы можем использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для пользовательской генерации песни. Например, передать `artist_consistency` в `action`, одновременно передать ID загруженной песни в `audio_id`, а также необходимо передать параметр `persona_id` — его значением является возвращённый выше ID стиля певца. Тогда можно создать новую песню на основе эталонного стиля певца.
