---
title: "Инструкция по интеграции API пользовательского стиля певца Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO позволяет нам задавать стиль певца для уже сгенерированных песен, а затем выполнять на его основе вторичное создание, в этом документе объясняется соответствующий метод интеграции API.

Запрос списка через `GET /suno/persona` и удаление записи через `DELETE /suno/persona` не тарифицируются, дополнительный заголовок запроса для освобождения от тарификации не требуется. Операция создания через `POST /suno/persona` по-прежнему тарифицируется в соответствии с правилами ценообразования интерфейса.

В линиях создания, поддерживающих запрос тембра голоса, можно использовать исходное приложение и идентификацию вызывающей стороны, чтобы передать `persona_id` из результата создания в `POST /suno/availability`. При подтверждении доступности возвращается `data.available=true`.[Руководство по проверке доступности тембра голоса](https://platform.acedata.cloud/documents/suno-availability-integration)

Этот API имеет только три входных параметра: сначала `audio_id`, это ID песни, уже успешно сгенерированной на официальной платформе, затем `name` и `description` — это название и описание стиля певца.

Здесь введённый нами `audio_id` — `https://cdn.acedata.cloud/2qhzs3.png`, для этого можно обратиться к [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), чтобы выполнить пользовательскую генерацию песни, и в итоге получить `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Результат выглядит следующим образом:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Можно увидеть, что поле `persona_id` в `data` — это ID стиля певца после генерации.

После получения ID стиля певца мы можем использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для пользовательской генерации песни, например, передать `artist_consistency` в `action`, одновременно передать ID загруженной песни в `audio_id`, также необходимо загрузить параметр `persona_id`, это значение является ID стиля певца, возвращённым выше, и тогда можно будет сгенерировать новую песню на основе эталонного стиля певца.
