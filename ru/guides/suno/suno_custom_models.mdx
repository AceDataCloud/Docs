Специальная музыкальная модель может обучаться последовательным музыкальным характеристикам на основе от 6 до 24 авторизованных аудиофайлов и использоваться для последующего создания песен. Создание является асинхронной операцией; рекомендуется использовать 24 аудиофайла с единым стилем и четким качеством для достижения более стабильного результата.

> Можно отправлять только аудиофайлы, на которые у вас есть законные права использования или которые вы получили разрешение на создание модели и последующую генерацию. Пожалуйста, не загружайте музыку или звуковые материалы без разрешения.

## Создание модели

Вызовите `POST /suno/custom-models` и установите `action=create`:

```json
{
  "action": "create",
  "name": "Моя инди модель",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Интерфейс немедленно возвращает ID модели платформы и ID задачи. После завершения создания, в обратном вызове или запросе результата `status` изменится на `ready`. Только успешное создание модели будет стоить **10 Credits**; неудачное создание не приведет к списанию средств.

## Запрос модели

Запрос одной модели:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Постраничный запрос текущих моделей приложения:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Все модели принадлежат приложению Suno, которое их создало. Ротация учетных данных API не изменит принадлежность модели, другие приложения не могут запрашивать или использовать эту модель.

## Использование модели для генерации песен

После того как статус модели станет `ready`, продолжайте вызывать `POST /suno/custom-models` и установите `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Неоновый дождь",
  "lyric": "[Куплет]\nГородские огни падают сквозь дождь",
  "style": "инди-рок, теплый аналоговый синтезатор"
}
```

`id` должен быть текущей моделью специальной музыки со статусом `ready`. Запрос не будет успешным, если модель недоступна, и не будет автоматически использовать другую модель. Успешная генерация песни потребляет **0.90 Credits**; неудачная генерация не приведет к списанию средств. Запросы и архивирование моделей бесплатны.

## Архивирование модели

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Текущая бета-версия архивирует модель и запрещает ее дальнейшее использование, ответ с `capacity_released=false` означает, что архивирование не гарантирует освобождение емкости модели. Операцию архивирования можно вызывать повторно, она не приведет к повторному списанию средств.
