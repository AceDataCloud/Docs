Пользовательская музыкальная модель может изучать согласованные музыкальные характеристики на основе от 6 до 24 лицензированных аудиозаписей и использовать их для последующего создания песен. Создание является асинхронной операцией; рекомендуется использовать 24 аудиозаписи в едином стиле и с чистым качеством звука для получения более стабильного результата.

> Можно отправлять только аудиозаписи, на которые вы имеете законное право использования или для которых получено разрешение на создание модели и последующую генерацию. Не загружайте музыку или звуковые материалы без разрешения.

## Создание модели

Вызовите `POST /suno/custom-models` и установите `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Интерфейс немедленно возвращает ID модели платформы и ID задачи. После завершения создания `status` в обратном вызове или результате запроса изменится на `ready`. **10 Credits** списываются только при успешном создании модели; при неудачном создании плата не взимается.

## Запрос модели

Запрос одной модели:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Постраничный запрос моделей текущего приложения:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Все модели принадлежат приложению Suno, которое их создало. Ротация API-учётных данных не изменяет принадлежность модели, другие приложения не могут запрашивать или использовать эту модель.

## Использование модели для генерации песен

После того как статус модели станет `ready`, продолжайте вызывать `POST /suno/custom-models` и установите `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` должен быть пользовательской музыкальной моделью текущего приложения со статусом `ready`. Если модель недоступна, запрос завершится ошибкой и не будет автоматически использовать другую модель. `persona_id` взаимоисключаем с пользовательской музыкальной моделью; при одновременной отправке интерфейс вернёт HTTP 400 до передачи запроса в сервис генерации, и плата не взимается. Для использования Persona применяйте операции `artist_consistency` или `artist_consistency_vox` в `/suno/audios`.

Успешная генерация песни расходует **0.90 Credits**; при неудачной генерации плата не взимается. Запрос и архивирование моделей бесплатны.

## Архивирование модели

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Текущая Beta-версия архивирует модель и запрещает её дальнейшее использование; `capacity_released=false` в ответе означает, что архивирование не гарантирует освобождение ёмкости модели. Операцию архивирования можно вызывать повторно, повторная плата не взимается.
