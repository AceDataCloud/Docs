Если вы хотите настроить генерацию песен, но не хотите писать текст самостоятельно, вы можете использовать API генерации текста песен, предоставляемый AceDataCloud, чтобы сгенерировать текст через prompt. API называется [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Основной входной параметр этого API — это `prompt`, опционально `model` (по умолчанию chirp-v3), пример заполнения ниже:

![](https://cdn.acedata.cloud/p53wtj.png)

Здесь мы вводим `prompt` как `Песня о зиме`, чтобы сгенерировать песню, связанную с зимой.

Нажмите "Запустить", результат будет следующим:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Куплет]\nСнежинки падают с неба\nХолодное прикосновение зимы\nО, как это меня поднимает\nЯ укутываюсь в слои\nО, так уютно\nВыходя на улицу и чувствуя мороз на носу\nСмотри\n\n[Куплет 2]\nМир покрыт белым одеялом\nСосульки висят\nСияя так ярко\nХолодный воздух наполняет мои легкие с каждым вдохом\nИдя по снегу\nОставляя следы, которые не будут стерты\n\n[Припев]\nО\nХолодное прикосновение зимы\nЭто сезон, который я так люблю\nСнегопад приносит чувство столь божественное\nХолодное прикосновение зимы\nЭто волшебное время",
    "title": "Холодное прикосновение зимы",
    "status": "complete"
  }
}
```

Можно увидеть, что поле `text` в `data` содержит информацию о тексте песни.

Получив текст песни, мы можем использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерации пользовательской песни.
