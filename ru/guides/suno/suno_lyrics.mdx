---

Если вы хотите настроить генерацию песен, но не хотите самостоятельно писать текст, вы можете использовать API генерации текста песен, предоставляемый AceDataCloud, чтобы сгенерировать текст через prompt. API - это [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Основной входной параметр этого API - `prompt`, опциональный `model` (допустимые значения `default`, `remi-v1`, по умолчанию `default`), пример заполнения ниже:

![](https://cdn.acedata.cloud/p53wtj.png)

Здесь мы вводим `prompt` как `Песня о зиме`, чтобы сгенерировать песню, связанную с зимой.

Нажмите "Запустить", результат будет следующим:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Куплет]\nСнежинки падают с неба\nХолодное прикосновение зимы\nО, как это меня поднимает\nЯ укутываюсь в слои\nО, так уютно\nВыходя на улицу, чувствую мороз на носу\n\n[Припев]\nО\nХолодное прикосновение зимы\nЭто сезон, который я так люблю\nСнегопад приносит чувство божественное\nХолодное прикосновение зимы\nЭто волшебное время",
      "title": "Холодное прикосновение зимы",
      "status": "complete",
      "tags": ["мечтательный, меланхоличный, баллада"]
    },
    {
      "text": "[Куплет]\nМир покрыт белым одеялом\nСосульки висят\nСияя так ярко\nХолодный воздух наполняет мои легкие с каждым вдохом\nИдя по снегу\nОставляя следы позади\n\n[Припев]\nЗимняя страна чудес\nВсе так ярко\nЗимняя страна чудес\nДержи меня всю ночь",

```

Можно увидеть, что `data` - это массив, который каждый раз возвращает несколько вариантов текста песен, где поле `text` каждого элемента - это содержание текста, `title` - заголовок, `tags` - рекомендуемые теги стиля.

Получив текст песен, мы можем использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерации пользовательских песен.
