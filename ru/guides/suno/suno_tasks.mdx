Основная функция Suno Tasks API заключается в том, чтобы запрашивать статус выполнения задачи, используя ID задачи, сгенерированный через Suno Audios Generation API или Suno Lyrics Generation API.

В этом документе подробно описывается интеграция Suno Tasks API, чтобы помочь вам легко интегрировать и в полной мере использовать мощные возможности этого API. С помощью Suno Tasks API вы можете легко реализовать запрос статуса выполнения задач Suno Lyrics Generation API или Suno Audios Generation API.

## Процесс подачи заявки

Чтобы использовать Suno Tasks API, сначала необходимо перейти на страницу заявки [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) и запросить соответствующую услугу, затем скопировать ID задачи Suno Audios Generation API, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/bc6754.png" width="500" className="m-auto" /></p>

Затем перейдите на страницу Tasks API [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks) и запросите соответствующую услугу, после перехода на страницу нажмите кнопку «Acquire», как показано на рисунке:

![Страница заявки](https://cdn.acedata.cloud/rci31i.png)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на [страницу входа](https://platform.acedata.cloud), где вас пригласят зарегистрироваться и войти в систему. После входа в систему вы будете автоматически возвращены на текущую страницу.

При первой подаче заявки предоставляется бесплатный лимит, который позволяет бесплатно использовать этот API.

## Пример запроса

Suno Tasks API можно использовать для запроса результатов двух API: Suno Audios Generation API и Suno Lyrics Generation API. Для получения информации о том, как использовать Suno Audios Generation API, пожалуйста, обратитесь к документации [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios-integration). Для получения информации о том, как использовать Suno Lyrics Generation API, пожалуйста, обратитесь к [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics-generation-integration).

Мы возьмем в качестве примера ID задачи, возвращенный службой Suno Audios Generation API, и продемонстрируем, как использовать этот API. Предположим, у нас есть ID задачи: eae26f89-b64b-404d-a80c-761996660b1c, далее мы покажем, как передать этот ID задачи.

### Установка заголовков запроса и тела запроса

**Request Headers** включает:

- `accept`: указывает на прием ответа в формате JSON, здесь указывается `application/json`.
- `authorization`: ключ для вызова API, после запроса можно выбрать из выпадающего списка.

**Request Body** включает:

- `id`: загруженный ID задачи.
- `action`: способ выполнения операции с задачей.

### Пример кода

Можно заметить, что на правой стороне страницы автоматически сгенерирован код на различных языках, как показано на рисунке:

<p><img src="https://cdn.acedata.cloud/p6vi9o.png" width="500" className="m-auto" /></p>

Некоторые примеры кода:

#### CURL

```bash
curl -X POST 'https://api.acedata.cloud/suno/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "eae26f89-b64b-404d-a80c-761996660b1c",
  "action": "retrieve"
}'
```

#### Python

```python
import requests

url = "https://api.acedata.cloud/suno/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "eae26f89-b64b-404d-a80c-761996660b1c",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Обработка ошибок

При вызове API, если возникнет ошибка, API вернет соответствующий код ошибки и информацию. Например:

- `400 token_mismatched` : Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `400 api_not_implemented` : Неверный запрос, возможно, из-за отсутствующих или недействительных параметров.
- `401 invalid_token` : Неавторизован, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests` : Слишком много запросов, вы превысили лимит частоты.
- `500 api_error` : Внутренняя ошибка сервера, что-то пошло не так на сервере.

### Пример ответа об ошибке

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
