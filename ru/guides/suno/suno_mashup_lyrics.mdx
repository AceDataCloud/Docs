Если вы хотите использовать тексты двух песен для создания смешанной песни, вы можете сначала использовать этот API для генерации соответствующих текстов, API - [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Основные входные параметры этого API - `lyrics_a`, `lyrics_b`, пример заполнения ниже:

![](https://cdn.acedata.cloud/g9n3t6.png)

Нажмите "Запустить", результат будет следующим:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Можно увидеть, что поле `text` в `data` содержит текст песни.

Получив текст, мы можем использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерации пользовательской песни.
