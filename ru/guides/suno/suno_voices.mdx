SUNO позволяет нам создавать пользовательские голосовые персонажи с помощью любого аудиофайла, реализуя клонирование голоса для генерации музыки. В отличие от существующего Persona API (использующего сгенерированный Suno `audio_id`), этот API принимает публично доступный `audio_url`, то есть вашу собственную запись голоса. В этом документе объясняется метод интеграции API клонирования голоса.

## Шаг первый: создание голосового персонажа

Этот API имеет три входных параметра: `audio_url` (обязательный), который является URL публично доступного аудиофайла в формате MP3 или WAV, содержащего чистый голос одного человека; `name` и `description` (необязательные), которые являются названием и описанием голосового персонажа.

> **Требования к аудиофайлу**
> - Формат аудио должен быть `WAV` или `MP3`
> - Длительность аудио должна быть от `10~240 секунд`, рекомендуется использовать чистый сухой материал с голосом одного человека длительностью `30~60 секунд`
> - Аудио должно содержать **чёткую, распознаваемую речь или вокал одного человека**
> - Обязательно избегайте **фонового шума, аккомпанемента, эха, реверберации**; полные песни с аккомпанементом обычно не проходят проверку голосового отпечатка
> - Не включайте **нескольких говорящих** или **множественные голоса**
> - Материалы со слишком низкой громкостью, нечёткой речью или слишком сильным шумом могут привести к **сбою клонирования** или **низкому качеству генерации**
> **Описание ограничений использования**
> - Голосовые персонажи, созданные путём загрузки аудио, являются **приватными ресурсами**
> - Этот голосовой персонаж **не поддерживает повторное использование между аккаунтами**
> - Рекомендуется использовать его как можно скорее после успешного создания; при длительном неиспользовании он может стать **недействительным или недоступным**
> - Возвращаемый `name` генерируется системой автоматически, ориентируйтесь на возвращаемый `persona_id`

> **При сбое вызова сначала повторите попытку**
> Клонирование голоса является вычислительно интенсивной задачей, и даже при полном соответствии материала требованиям существует определённая вероятность случайного сбоя, распространённые ответы включают
> `voices_sound_different` (проверка голосового отпечатка не пройдена) и другие. **Такие сбои не связаны с качеством аудио, повторная попытка с тем же материалом обычно приводит к успеху**,
> рекомендуется реализовать в интеграции 1~2 автоматические повторные попытки для результатов со сбоями. Неудачные запросы не тарифицируются.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Указанный выше `https://cdn.acedata.cloud/suno_demo.mp3` — это демонстрационный материал, который можно вызвать напрямую (MP3, 41 секунда, сухой голос одного человека).
> Если требуется пример в формате `WAV`, можно использовать
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 секунда, моно 44.1kHz).

Результат следующий:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Как видно, поле `persona_id` в `data` является ID созданного голосового персонажа. Поле `is_public` всегда имеет значение `false`, поскольку голосовые персонажи, созданные путём загрузки аудио, являются приватными. Обратите внимание, что возвращаемый `name` генерируется системой автоматически, в дальнейшем используйте `persona_id` для ссылки на этот голосовой персонаж.

## Шаг второй: генерация музыки с использованием голосового персонажа

После получения ID голосового персонажа мы можем использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) для генерации музыки. Установите `action` в `generate` и задайте `persona_id` как ID голосового персонажа, возвращённый выше, — сгенерированная песня будет исполнена клонированным голосом.

> **Примечание:** клонирование голоса поддерживается только моделями `chirp-v4-5` и выше (например, `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`) и не поддерживается `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Результат следующий:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Как видно, сгенерированная песня была исполнена с использованием клонированного голоса. `persona_id` также можно использовать совместно с действием `cover`, чтобы исполнять существующие песни клонированным голосом.
