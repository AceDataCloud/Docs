SUNO позволяет создавать пользовательские голосовые персонажи на основе любых аудиофайлов, реализуя клонирование голоса для генерации музыки. В отличие от существующего Persona API (использующего `audio_id`, сгенерированный Suno), этот API принимает публично доступный `audio_url` — вашу собственную запись голоса. В этом документе описывается метод интеграции API клонирования голоса.

## Шаг 1: Создание голосового персонажа

API принимает три входных параметра: `audio_url` (обязательный) — URL публично доступного аудиофайла в формате MP3 или WAV с чёткой записью одного голоса; `name` и `description` (необязательные) — имя и описание голосового персонажа.

**Требования к аудиофайлу:**
- Формат: MP3 или WAV
- Длительность: не менее 10 секунд
- Содержание: один чёткий голос, минимальный фоновый шум или музыка

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Ответ:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Как видно, поле `persona_id` в `data` — это ID созданного голосового персонажа. Поле `is_public` всегда `false`, так как персонажи, созданные загрузкой аудио, являются приватными.

## Шаг 2: Использование голосового персонажа для генерации музыки

Имея ID голосового персонажа, можно использовать [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) для генерации музыки. Установите `action` в значение `generate` и `persona_id` в ID созданного персонажа — сгенерированная песня будет исполнена клонированным голосом.

> **Внимание:** Клонирование голоса поддерживается только моделями `chirp-v4-5` и выше (например, `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), модели `chirp-v4` не поддерживаются.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Ответ:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Как видно, сгенерированная песня исполнена клонированным голосом. `persona_id` также можно использовать с действием `cover` для исполнения каверов существующих песен клонированным голосом.
