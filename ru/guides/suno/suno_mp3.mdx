title: "Suno MP3 URL API интеграция"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Suno MP3 URL API создает путь к воспроизводимому адресу, заканчивающемуся на `.mp3`, для уже существующей музыки, что подходит для случаев, когда старые ссылки для загрузки недействительны, требуется воспроизведение на мобильных устройствах или необходимо повторно получить публичный аудио URL.

Обязательный параметр `audio_id` — это ID аудио, возвращаемый интерфейсом генерации аудио Suno. Каждый вызов создает независимую задачу MP3 URL, не изменяя оригинальную задачу генерации музыки и не меняя оригинальный аудио ID.

## Синхронный вызов

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

При успешном выполнении `data[0].file_url` — это адрес воспроизводимого аудио. Интерфейс сначала попытается сохранить по адресу `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3`; если сохранение занимает более 30 секунд или завершается неудачей, будет возвращен текущий доступный исходный аудио адрес.

## Асинхронный вызов

Если время обработки длительное, можно передать `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Затем через `/suno/tasks` можно запросить `export_task_id`. Также можно предоставить `callback_url`, чтобы получить окончательный результат после завершения задачи. Синхронный ответ, запрос задачи и обратный вызов используют одну и ту же структуру конечных данных.

## Важные замечания

- `audio_id` должен быть из распознаваемого аудио Suno.
- Задачи MP3 URL независимы от оригинальных задач генерации музыки.
- Сохранение может занять максимум 30 секунд; тайм-аут или неудача при сохранении не блокируют результат и вернутся к исходному аудио адресу.
- Рекомендуется, чтобы бизнес-сторона своевременно загружала результаты и сохраняла их в соответствии со своей стратегией хранения данных.
