SUNO позволяет нам создавать вторичные произведения на основе сгенерированной музыки, получать тексты песен и временные метки аудио. В этом документе описывается метод интеграции соответствующего API.

Этот API принимает только один входной параметр — `audio_id`, который является официальным идентификатором сгенерированной песни.

В данном примере в качестве `audio_id` используется значение `ec13e502-d043-4eb2-92ee-e900c6da69d1`.

```python
import requests

url = "https://api.acedata.cloud/suno/timing"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "ec13e502-d043-4eb2-92ee-e900c6da69d1"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Описание поля aligned_words

Как видно, `data.aligned_words` — это массив объектов, каждый из которых представляет слово или фразу с временной информацией.

- `word`: фактическое слово или фраза из текста песни
- `success`: булево значение, указывающее, успешно ли выполнено выравнивание данного слова
- `start_s`: время начала слова в секундах
- `end_s`: время окончания слова в секундах
- `p_align`: вероятность или коэффициент уверенности выравнивания, в диапазоне от 0 до 1
