title: "Руководство по интеграции API Qwen Image"

`POST https://api.acedata.cloud/qwen-image/images` поддерживает `qwen-image-3.0` и `qwen-image-3.0-pro` для генерации изображений по тексту и редактирования 1–3 ссылок на изображения.

## Генерация изображений по тексту

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"Минималистичный технологический постер","size":"1024*1024","n":1}'
```

## Редактирование изображений

Добавьте `image_urls` в тот же запрос, поддерживается 1–3 публичных изображения:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Сохранить основной объект, изменить на теплый **###** стиль постера",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` поддерживает только генерацию изображений по тексту. `n` в диапазоне от 1 до 6. Общая пиксельная площадь выходного изображения должна быть от 512×512 до 2048×2048, соотношение сторон от 1:8 до 8:1.

## Асинхронный вызов

Установите `async: true`, чтобы сразу получить `task_id`; также можно передать `callback_url` для получения окончательного результата. После завершения выполните запрос через `/qwen-image/tasks`.

Успешный ответ содержит `data[].image_url`, `usage`, `task_id` и `trace_id`. Ссылки на изображения будут по возможности перенесены в CDN Ace Data Cloud. Примеры реальных ответов будут добавлены после проверки E2E в производственной среде.
