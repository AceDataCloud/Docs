title: "Qwen Image 生成与编辑 API"

---

`POST https://api.acedata.cloud/qwen-image/images` через один и тот же интерфейс выполняется генерация изображений и редактирование 1–3 ссылок на изображения, поддерживает `qwen-image-3.0` и `qwen-image-3.0-pro`.

## Выбор модели

| Модель                   | Подходящие сценарии       | Официальная стандартная цена                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Массовое творчество, быстрая итерация  | Выход $0.030/изображение             |
| `qwen-image-3.0-pro` | Сложная компоновка, высокая точность | 1K $0.040/изображение; 2K $0.075/изображение |

Ссылки на изображения оплачиваются по фактическому количеству, официальная стандартная цена $0.003/изображение.

## Синхронная генерация

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Простой красный круг, расположенный по центру на чистом белом фоне.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Успешный ответ содержит постоянный CDN адрес изображения, фактическое использование и стоимость:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Редактирование ссылок на изображения

Добавьте `image_urls`, поддерживает 1–3 общедоступных изображения:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Сохранить объект, изменить фон на теплый **###** постерный стиль",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` используется только для генерации изображений. `n` в диапазоне от 1 до 6; соотношение сторон должно быть от 1:8 до 8:1.

## Асинхронные задачи

Установив `async: true`, интерфейс немедленно возвращает `task_id`. Используйте `/qwen-image/tasks` для запроса конечного состояния или передайте `callback_url` для получения уведомления о завершении. Генерация оплачивается только один раз, запросы задач не облагаются повторной оплатой.
