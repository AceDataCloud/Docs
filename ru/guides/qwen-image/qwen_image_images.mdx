`POST https://api.acedata.cloud/qwen-image/images` выполняет генерацию изображения по тексту и редактирование с 1–3 референсными изображениями через один интерфейс, поддерживает `qwen-image-3.0` и `qwen-image-3.0-pro`。

## Выбор модели

| Модель                   | Подходящие сценарии       | Официальная стандартная цена                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Массовое создание, быстрые итерации  | Выходное изображение $0.030/шт.             |
| `qwen-image-3.0-pro` | Сложная вёрстка, высокоточные готовые изображения | 1K $0.040/шт.; 2K $0.075/шт. |

Референсные изображения оплачиваются по фактическому количеству входных изображений, официальная стандартная цена — $0.003/шт.

## Синхронная генерация

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Успешный ответ содержит постоянный CDN-адрес изображения, фактическое usage и стоимость этого запроса:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Редактирование по референсным изображениям

Добавьте `image_urls`, поддерживается 1–3 публично доступных изображения:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` используется только для генерации изображения по тексту. Диапазон `n` — от 1 до 6; соотношение сторон должно быть между 1:8 и 8:1.

## Асинхронные задачи

После установки `async: true` интерфейс немедленно возвращает `task_id`. Используйте `/qwen-image/tasks` для запроса конечного состояния или передайте `callback_url` для получения уведомления о завершении. Генерация оплачивается только один раз, повторная плата за запросы задач не взимается.
