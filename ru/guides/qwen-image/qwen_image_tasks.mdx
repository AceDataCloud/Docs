`POST https://api.acedata.cloud/qwen-image/tasks` используется для запроса, пакетного запроса или удаления асинхронных задач Qwen Image. Этот интерфейс не приводит к дополнительным расходам на API.

## Запрос одного задания

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

После завершения задания, `response.data` содержит постоянный адрес CDN изображения, `response.usage` содержит фактическое количество входных/выходных данных, `response.cost` — информация о расчете за выполненное задание.

## Пакетный запрос

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Возвращает `{ "items": [...], "count": 2 }`. Запрос списка также поддерживает фильтрацию по пользователю, приложению и диапазону времени создания.

## Удаление записей о заданиях

```json
{"action":"delete","id":"TASK_ID"}
```

Удаление затрагивает только историю заданий и не удаляет уже сгенерированные файлы CDN.
