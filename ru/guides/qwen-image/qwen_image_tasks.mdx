---
title: "Руководство по интеграции API задач Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Используйте `POST https://api.acedata.cloud/qwen-image/tasks` для запроса асинхронных задач генерации изображений. Этот интерфейс запроса бесплатен.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Для пакетного запроса используйте `action=retrieve_batch` и массив `ids`. После успешного выполнения задачи в `response.data` содержится постоянный адрес сгенерированных изображений и фактическое использование.
