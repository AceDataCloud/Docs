Основная функция Grok Tasks API заключается в том, чтобы запрашивать статус выполнения задачи, используя ID задачи, сгенерированный Grok Videos Generation API.

В этом документе подробно описывается интеграция Grok Tasks API, чтобы помочь вам легко интегрировать и запрашивать статус выполнения задач Grok Videos Generation API.

## Процесс подачи заявки

Чтобы использовать Grok Videos Generation API, сначала получите ваш API Token в [консоли Ace Data Cloud](https://platform.acedata.cloud/console/applications) и сохраните его для использования.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вас пригласят зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет вызывать все сервисы платформы, не нужно отдельно запрашивать для каждого сервиса.** При первом запросе предоставляется бесплатный лимит, чтобы вы могли попробовать; при недостатке лимита вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Пример запроса

Grok Tasks API можно использовать для запроса результатов Grok Videos Generation API.

### Установка заголовков запроса и тела запроса

**Request Headers** включает:

- `accept`: указывает на прием ответа в формате JSON, здесь указывается `application/json`.
- `authorization`: ключ для вызова API, после запроса можно выбрать из выпадающего списка.

**Request Body** включает:

- `id`: ID задачи, которую нужно запросить.
- `action`: способ выполнения операции над задачей, для одиночного запроса указывается `retrieve`.

### Пример кода CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Пример ответа

После успешного запроса API вернет информацию о деталях этой задачи. Поле `request` содержит тело запроса, отправленное при создании задачи, а поле `response` содержит тело ответа, возвращенное после завершения задачи, например:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262729.623,
  "elapsed": 7.8,
  "request": {
    "prompt": "Кинематографический кадр котенка, гоняющегося за бабочкой в солнечном саду",
    "model": "grok-imagine-video-1.5-fast:reverse",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video-1.5-fast:reverse:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Описание полей:

- `id`: ID сгенерированной задачи, используемый для уникальной идентификации этой задачи.
- `request`: информация о запросе в задаче.
- `response`: информация о возвращенном ответе в задаче.
- `created_at`: время создания задачи, Unix временная метка (секунды, с плавающей точкой).
- `started_at`: время начала выполнения задачи, Unix временная метка (секунды, с плавающей точкой).
- `finished_at`: время завершения задачи, Unix временная метка (секунды, с плавающей точкой). Это поле не возвращается, если задача не завершена.
- `elapsed`: время выполнения задачи, в секундах (с плавающей точкой, с 3 знаками после запятой). Это поле не возвращается, если задача не завершена.

## Пакетный запрос

Для запроса деталей нескольких ID задач установите `action` в `retrieve_batch` и передайте массив ID задач через `ids`:

**Request Body** включает:

- `ids`: массив ID задач, которые нужно запросить.
- `action`: способ выполнения операции над задачей, для пакетного запроса указывается `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
