Основная функция API Grok Tasks — это проверка статуса выполнения задачи по заданному идентификатору задачи, который генерируется API Grok Videos Generation API.

Данный документ подробно описывает процесс интеграции API Grok Tasks, чтобы помочь вам легко подключить и проверять выполнение задач API Grok Videos Generation.

## Процесс подачи заявки

Для использования API Grok Tasks необходимо сначала перейти на страницу заявки [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos), оформить соответствующую услугу и скопировать идентификатор задачи, возвращаемый API Grok Videos Generation.

Затем перейдите на страницу [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks), чтобы оформить заявку на соответствующую услугу. После входа на страницу нажмите кнопку «Acquire».

Если вы еще не вошли в систему или не зарегистрированы, произойдет автоматический переход на [страницу входа](https://platform.acedata.cloud), где вам будет предложено зарегистрироваться или войти. После входа вы автоматически вернетесь на текущую страницу.

При первом обращении предоставляется бесплатный лимит, позволяющий бесплатно использовать данный API.

## Пример запроса

API Grok Tasks предназначен для получения результатов API Grok Videos Generation.

### Настройка заголовков и тела запроса

**Заголовки запроса (Request Headers):**

- `accept`: указывается `application/json`, чтобы получать ответ в формате JSON.
- `authorization`: ключ API для вызова, после оформления можно выбрать из выпадающего списка.

**Тело запроса (Request Body):**

- `id`: идентификатор задачи, которую нужно проверить.
- `action`: способ действия с задачей, для одного запроса указывается `retrieve`.

### Пример кода CURL

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Пример ответа

При успешном запросе API возвращает подробную информацию о задаче. Поле `request` содержит тело запроса, отправленного при создании задачи, а `response` — ответ после завершения задачи, например:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "Кинематографический кадр котенка, гоняющегося за бабочкой в солнечном саду",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Описание полей:

- `id`: идентификатор созданной задачи, используется для однозначной идентификации задачи.
- `request`: информация о запросе, отправленном при создании задачи.
- `response`: информация о результате выполнения задачи.

## Множественный запрос

Для получения информации о нескольких задачах одновременно установите `action` в значение `retrieve_batch` и передайте массив идентификаторов задач в `ids`:

**Тело запроса:**

- `ids`: массив идентификаторов задач.
- `action`: указывается `retrieve_batch` для пакетной проверки.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
