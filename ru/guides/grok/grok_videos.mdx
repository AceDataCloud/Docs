В этой статье будет представлено руководство по интеграции Grok Videos Generation API, который может генерировать видео Grok Imagine (xAI) на основе текстовых подсказок, входных изображений и необязательных эталонных изображений.

## Процесс подачи заявки

Чтобы использовать Grok Videos Generation API, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications), чтобы получить ваш API Token и сохранить его для дальнейшего использования.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вас пригласят зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет вызывать все услуги платформы, не нужно подавать отдельные заявки на каждую услугу.** При первой подаче заявки предоставляется бесплатный лимит, чтобы вы могли попробовать; если лимит исчерпан, вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [Grok Videos Generation API →](https://platform.acedata.cloud/documents/grok-videos)

## Описание модели

Этот API поддерживает две модели:

- `grok-imagine-video-1.5-fast` (по умолчанию): поддерживает видео на основе текста (только передайте `prompt`) и видео на основе изображений (передайте `image_url`), максимальная продолжительность 30 секунд, цена ниже.
- `grok-imagine-video-1.5`: поддерживает только видео на основе изображений, **обязательно** передайте `image_url`, максимальная продолжительность 15 секунд.

## Основное использование

Сначала ознакомьтесь с основными способами использования, передав параметры, такие как текстовая подсказка `prompt`, модель `model` и т. д., чтобы сгенерировать соответствующее видео.

Здесь мы установили заголовки запроса, включая:

- `accept`: формат ответа, который вы хотите получить, здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, после запроса вы можете выбрать его из выпадающего списка.

Также установлен тело запроса, включая:

- `prompt`: текстовая подсказка, описывающая желаемое содержание видео. Обязательно при использовании `grok-imagine-video-1.5-fast` для видео на основе текста; при передаче `image_url` - необязательно.
- `model`: модель для генерации видео, можно выбрать `grok-imagine-video-1.5-fast` (по умолчанию) или `grok-imagine-video-1.5`.
- `image_url`: ссылка на входное изображение для видео на основе изображений. Обязательно при использовании модели `grok-imagine-video-1.5`.
- `reference_image_urls`: массив ссылок на необязательные эталонные изображения, используемые для направления стиля или содержания видео.
- `aspect_ratio`: соотношение сторон генерируемого видео, можно выбрать `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: выходное разрешение, можно выбрать `480p` (по умолчанию), `720p` или `1080p`.
- `duration`: продолжительность генерируемого видео (в секундах). Для `grok-imagine-video-1.5-fast` диапазон значений 1–30, для `grok-imagine-video-1.5` диапазон значений 1–15, по умолчанию 6. Рекомендуется использовать 6 секунд или 10 секунд, эти два стандартных времени относительно стабильны.
- `callback_url`: адрес асинхронного обратного вызова, после установки API немедленно вернет `task_id`, а по завершении задачи отправит результат на этот адрес.
- `async`: необязательно, если установить в `true`, интерфейс немедленно вернет `task_id`, не требуя предоставления `callback_url`, затем с помощью соответствующего интерфейса запроса задачи можно опрашивать для получения результата.

Нажмите кнопку «Try», чтобы протестировать, и полученный результат будет похож на следующий:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Возвращаемый результат содержит несколько полей, описанных ниже:

- `success`: успешен ли запрос на генерацию видео.
- `task_id`: ID задачи на генерацию видео.
- `trace_id`: ID отслеживания данного запроса, используемый для устранения проблем.
- `data`: список результатов сгенерированного видео.
  - `id`: уникальный идентификатор сгенерированного видео.
  - `video_url`: ссылка на сгенерированное видео.
  - `state`: состояние задачи по генерации видео, может быть `pending` / `succeeded` / `failed`.

Нам нужно просто получить сгенерированное видео по ссылке `video_url` из результата `data`.

Соответствующий код CURL выглядит следующим образом:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 6
}'
```

Соответствующий код на Python выглядит следующим образом:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Видео на основе изображений

Если вы хотите сгенерировать видео на основе входного изображения, вы можете передать `image_url`. При использовании `grok-imagine-video-1.5` это поле обязательно:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 6
}
```

## Направление с помощью эталонных изображений

Если вы хотите использовать одно или несколько эталонных изображений для направления стиля или содержания видео, вы можете передать массив ссылок на изображения в `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Асинхронный обратный вызов

Генерация видео требует определенного времени обработки. Если вы не хотите поддерживать долгое соединение в ожидании, вы можете передать `callback_url`, в этом случае API немедленно вернет `task_id`, а по завершении задачи отправит окончательный результат на этот адрес:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 6,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Немедленно возвращаемый результат будет следующим:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Запрос результата задачи
Если вы использовали асинхронный обратный вызов или хотите активно проверить статус задачи, вы можете через [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) запросить последний статус и результат задачи по `task_id`.

## Условия оплаты

Способ оплаты за данную услугу определяется `model`:

- `grok-imagine-video-1.5-fast`: оплата по длительности, не зависит от разрешения — `1–10` секунд, `11–20` секунд, `21–30` секунд соответствуют разным ценовым категориям.
- `grok-imagine-video-1.5`: оплата по «выходным секундам», общая цена = цена за единицу × `duration`, `1080p` дороже, чем `480p`/`720p`.

Конкретная цена за единицу определяется на странице с ценами. Неудачные запросы не подлежат оплате и не расходуют бесплатный лимит.

## Обработка ошибок

Когда возникает проблема с запросом, API возвращает соответствующий код ошибки и описание, наиболее распространенные из них:

- `400`: неверные параметры запроса, например, видео без `prompt`, или `grok-imagine-video-1.5` без `image_url`, или `duration` вне диапазона (`grok-imagine-video-1.5-fast` от 1 до 30, `grok-imagine-video-1.5` от 1 до 15).
- `401`: ошибка аутентификации, токен недействителен или не соответствует API.
- `403`: недостаточно средств, или подсказка попала под отказ в модерации контента.
- `429`: слишком частые запросы, пожалуйста, попробуйте позже.
- `500`: ошибка при генерации видео или сбой сервиса.
