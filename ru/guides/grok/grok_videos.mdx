В этой статье представлена инструкция по интеграции Grok Videos Generation API, который позволяет создавать видео Grok Imagine (xAI) на основе текстовых подсказок, входных изображений и необязательных референсных изображений.

## Процесс подачи заявки

Для использования API необходимо сначала подать заявку на соответствующую услугу на странице [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). После перехода на страницу нажмите кнопку «Acquire», как показано на рисунке:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы еще не вошли в систему или не зарегистрированы, вас автоматически перенаправит на страницу входа с приглашением зарегистрироваться и войти. После входа или регистрации вы автоматически вернетесь на текущую страницу.

При первой подаче заявки предоставляется бесплатный лимит, позволяющий бесплатно использовать API.

## Описание моделей

API поддерживает два типа моделей:

- `grok-imagine-video` (по умолчанию): поддерживает генерацию видео из текста (только параметр `prompt`) и из изображения (параметр `image_url`), стоимость ниже.
- `grok-imagine-video-1.5-preview`: поддерживает только генерацию видео из изображения, **обязателен** параметр `image_url`.

## Основное использование

Сначала рассмотрим базовый способ использования: вводим текстовую подсказку `prompt`, модель `model` и другие параметры для генерации соответствующего видео.

Здесь мы задаем заголовки запроса (Request Headers), включая:

- `accept`: формат ожидаемого ответа, здесь указано `application/json` (формат JSON).
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

Также задаем тело запроса (Request Body), включающее:

- `prompt`: текстовое описание содержимого видео. Обязательно при генерации видео из текста с моделью `grok-imagine-video`; при передаче `image_url` — необязательно.
- `model`: модель для генерации видео, можно выбрать `grok-imagine-video` (по умолчанию) или `grok-imagine-video-1.5-preview`.
- `image_url`: ссылка на входное изображение для генерации видео из изображения. Обязательно при использовании модели `grok-imagine-video-1.5-preview`.
- `reference_image_urls`: необязательный массив ссылок на референсные изображения для задания стиля или содержания видео.
- `aspect_ratio`: соотношение сторон видео, можно выбрать из `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: разрешение выходного видео, можно выбрать `480p` (по умолчанию) или `720p`; чем выше разрешение, тем больше расходуется лимит.
- `duration`: длительность видео в секундах, диапазон 1–15, по умолчанию 8. Оплата производится за количество секунд.
- `callback_url`: URL для асинхронного обратного вызова; при указании API сразу возвращает `task_id`, а по завершении задачи отправляет результат методом POST на этот адрес.

Нажмите кнопку «Try» для тестирования, результат будет примерно следующим:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Возвращаемые данные содержат следующие поля:

- `success`: успешность запроса на генерацию видео.
- `task_id`: ID задачи генерации видео.
- `trace_id`: ID трассировки запроса для отладки.
- `data`: список результатов сгенерированных видео.
  - `id`: уникальный идентификатор сгенерированного видео.
  - `video_url`: ссылка на сгенерированное видео.
  - `state`: статус задачи генерации видео, может быть `pending` / `succeeded` / `failed`.

Для получения сгенерированного видео достаточно использовать ссылку `video_url` из поля `data`.

Пример CURL-запроса:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

Пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Генерация видео из изображения

Если вы хотите сгенерировать видео на основе входного изображения, передайте параметр `image_url`. При использовании модели `grok-imagine-video-1.5-preview` этот параметр обязателен:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## Использование референсных изображений

Для задания стиля или содержания видео с помощью одной или нескольких референсных картинок передайте массив ссылок в параметре `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## Асинхронный обратный вызов

Генерация видео требует времени. Если не хотите держать соединение открытым, передайте параметр `callback_url`. В этом случае API сразу вернет `task_id`, а после завершения задачи отправит результат методом POST на указанный адрес:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Мгновенный ответ будет таким:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Запрос статуса задачи

Если вы используете асинхронный обратный вызов или хотите самостоятельно проверить статус задачи, можно использовать [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) и по `task_id` получить актуальный статус и результат.

## Информация о тарификации

Оплата производится за «выходные секунды» сгенерированного видео. Стоимость зависит от модели `model` и разрешения `resolution`. Общая цена = цена за секунду × `duration` (по умолчанию 8 секунд). Разрешение `720p` дороже `480p`, модель `grok-imagine-video-1.5-preview` дороже `grok-imagine-video`. Точные цены смотрите на странице с тарифами.

## Обработка ошибок

При возникновении ошибок API возвращает соответствующий код и описание. Частые ошибки:

- `400`: неверные параметры запроса, например, отсутствие `prompt` при генерации видео из текста, отсутствие `image_url` при `grok-imagine-video-1.5-preview`, или `duration` вне диапазона 1–15.
- `401`: ошибка аутентификации, недействительный токен или несовпадение с API.
- `403`: недостаточно средств на балансе или отказ из-за проверки контента подсказки.
- `429`: слишком частые запросы, превышение лимитов, попробуйте позже.
- `500`: внутренняя ошибка сервера или сбой на стороне генерации.
