Отправьте задачу через `POST /kling/apparel`, используйте существующий `POST /kling/tasks` для запроса статуса задачи на платформе.

## Входные данные

Предоставьте описание товара объёмом не более 2500 символов, эталонное видео длительностью 5–180 секунд и 1–5 изображений товара. Дополнительно можно предоставить 1–5 изображений модели, файл фоновой музыки, а также указать голос озвучки; если голос не указан, используется нативная голосовая подача.

Ниже приведён пример структуры запроса, замените URL материалов перед вызовом.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Результаты и тарификация

Синхронный режим возвращает результат генерации; асинхронный режим сначала возвращает `task_id`, а завершённый результат содержит ссылки на видео или изображения в `data` и рассчитанный сервером `usage`. `callback_url` используется для уведомления о завершении; запрос с `watermark=true` одновременно возвращает версию с водяным знаком.

Нативная голосовая подача: 1,82 Credits/сек для 720p и 2,38 Credits/сек для 1080p; указанная озвучка: 2,38 Credits/сек для 720p и 2,8 Credits/сек для 1080p. Видео тарифицируется по фактической длительности генерации, базовая цена за секунду до генерации не представляет общую стоимость всей задачи. За неудачные задачи плата за генерацию не взимается.
