Отправьте задачу через `POST /kling/goods-studio`, используйте существующий `POST /kling/tasks` для проверки статуса задачи на платформе.

## Ввод

Предоставьте 1–5 изображений товара и заголовок товара длиной до 200 символов; описание товара необязательно, до 2000 символов. Продолжительность необязательно может составлять 15, 30 или 60 секунд.

Ниже приведён пример структуры запроса, замените URL материалов перед вызовом.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Результаты и тарификация

Синхронный режим возвращает результат генерации; асинхронный режим сначала возвращает `task_id`, а завершённый результат содержит ссылки на видео или изображения в `data` и рассчитанный сервером `usage`. `callback_url` используется для уведомления о завершении; запрос с `watermark=true` одновременно возвращает версию с водяным знаком.

720p: 2.38 Credits/секунда; 1080p: 2.8 Credits/секунда. Видео тарифицируется по фактической продолжительности генерации, базовая цена за секунду до генерации не представляет общую стоимость всей задачи. За неудачные задачи плата за генерацию не взимается.
