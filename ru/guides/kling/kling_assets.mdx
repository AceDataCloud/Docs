`POST /kling/elements` и `POST /kling/voices` управляют активами платформы через `action`: `list` выводит список собственных активов, `presets` получает предустановленные активы, `retrieve` запрашивает `id`, `delete` удаляет собственный `id`. Предустановленные активы нельзя удалить. Все ссылки используют ID платформы, возвращённые интерфейсом; активы изолированы по пользователям и приложениям. Операции управления не тарифицируются.

`list` и `presets` поддерживают `page_num` (1–1000, по умолчанию 1) и `page_size` (1–500, по умолчанию 30). Предустановленные активы могут использоваться для генерации после первого чтения. После удаления активы больше нельзя использовать для новых задач.

## Создание голоса

Отправьте в `/kling/voices` `action="create"`, `voice_name` до 20 символов и `voice_url`. Аудио должно содержать чёткий голос одного человека длительностью 5–30 секунд; поддерживаются mp3, wav, mp4, mov. За одно создание взимается 0.07 Credits; для неуспешных задач применяются правила тарификации неуспешных задач платформы. При `async=true` или предоставлении `callback_url` сначала возвращается `task_id`, а итоговый результат запрашивается через `/kling/tasks`.

```json
{"action":"create","voice_name":"Narrator","voice_url":"https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3","async":true}
```

После успешного создания используйте в `/kling/videos` `voice_list=[{"voice_id":"ID голоса платформы"}]`. Поддерживаются 1–2 голоса, ограничено `model="kling-v2-6"`, `mode="pro"`, `generate_audio=true`. В `prompt` используйте `&lt;&lt;<voice_1>>>` или `&lt;&lt;<voice_2>>>` для указания выбранного голоса. Видео с указанным голосом тарифицируются по фактической длительности вывода из расчёта 1.68 Credits/секунда, поддерживаются дробные секунды; `usage.duration` в результате — это фактическая тарифицируемая длительность. Например, вывод длительностью 5.04 секунды соответствует 8.4672 Credits. Нельзя использовать вместе с `element_list`. Если сервис не предоставляет действительную длительность вывода, возвращается 502.

Расчётная общая цена до генерации рассчитывается по длительности запроса: 5 секунд — 8.4 Credits, 10 секунд — 16.8 Credits; окончательный счёт рассчитывается по фактической длительности вывода.

## Ссылки на субъекты

Используйте в `/kling/videos` `element_list=[{"element_id":"ID субъекта платформы"}]` для ссылки на полученные предустановленные субъекты. Поддерживаются 1–3 субъекта, ограничено V3, V3 Omni и O1. Общее количество субъектов и изображений для Omni/O1 — не более 7; при наличии референсного видео — не более 4. Остальные ограничения генерации по-прежнему применяются.

Создание пользовательских субъектов пока не открыто, `action="create"` возвращает 503; задачи создания не будут отправлены до подтверждения цены. Подготавливаемый контракт запроса включает `element_name` (до 20 символов), `element_description` (до 100 символов) и `reference_type`. `image_refer` использует фронтальное изображение и 1–3 референсных изображения; `video_refer` использует одно референсное видео длительностью 3–8 секунд, 1080p, размером до 200 MB. Эти две формы материалов нельзя смешивать. Этот подготавливаемый контракт не означает, что возможность создания уже запущена.
