title: "API для синхронизации губ Kling (Kling Lip Sync)"

---

Позволяет **существующему видео Kling** (5 секунд или 10 секунд) "говорить" по аудио или тексту — то есть синхронизировать губы (Lip Sync). В сочетании с `/kling/videos` и `image2video` (оживление фотографий) можно создать полный процесс "**говорящих фотографий / цифрового озвучивания**".

> Этот интерфейс представляет собой удобную обертку от AceDataCloud для распространенных сценариев, основанных на аудио/тексте; это не полевое зеркало многошагового интерфейса Kling "распознавание лиц → Advanced Lip Sync". Пожалуйста, ориентируйтесь на таблицу параметров на этой странице.

- **Адрес интерфейса**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Формат запроса**: `application/json`
- **Формат ответа**: `application/json`
- **Оплата**: каждый успешный вызов **2.45 кредитов** (фиксировано)

## Заголовки запроса (Request Headers)

| Поле              | Значение                   | Описание                                               |
| ---------------- | ------------------------- | ---------------------------------------------------- |
| `authorization`  | `Bearer ${API_KEY}`      | Ваш API-ключ, [адрес получения](https://platform.acedata.cloud) |
| `content-type`   | `application/json`       | Формат тела запроса                                    |
| `accept`         | `application/json`       | Формат ответа                                         |

## Параметры запроса (Request Body)

| Параметр          | Тип      | Обязательный | По умолчанию | Описание                                                                                                                       |
| ---------------- | ------- | ------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Да           | —            | Режим генерации. Перечисление: `audio2video` (аудио-управляемый), `text2video` (текст-управляемый)                          |
| `video_id`       | string  | Один из двух | —            | ID видео, созданного Kling (например, `video_id`, возвращаемый `image2video` из `/kling/videos`). **Поддерживаются только 5s/10s видео, созданные в течение 30 дней**. `video_id` и `video_url` выбираются по одному, не могут передаваться одновременно |
| `video_url`      | string  | Один из двух | —            | Ссылка на видео, доступная в интернете. Ограничения: `.mp4`/`.mov`, ≤100MB, длительность 2–10s, только 720p/1080p, длина стороны 720–1920px. Выбираются по одному с `video_id`                                  |
| `audio_url`      | string  | Условный     | —            | URL для загрузки управляющего аудио, обязательный при `audio2video` + `audio_type=url`. Формат `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Нет          | `url`        | Способ передачи аудио. Перечисление: `url`, `file` (действует при `audio2video`)                                               |
| `audio_file`     | string  | Условный     | —            | Base64 аудиофайла, обязательный при `audio_type=file`. Формат аналогичен выше, ≤5MB                                             |
| `text`           | string  | Условный     | —            | Текст для чтения, обязательный при `text2video`, **максимум 120 символов**                                                     |
| `voice_id`       | string  | Условный     | —            | ID голоса, обязательный при `text2video`                                                                                      |
| `voice_language` | string  | Нет          | `zh`         | Язык голоса. Перечисление: `zh`, `en` (действует при `text2video`)                                                             |
| `voice_speed`    | float   | Нет          | `1.0`        | Скорость речи, диапазон `0.8`–`2.0`, с точностью до одного знака после запятой (действует при `text2video`)                     |
| `callback_url`   | string  | Нет          | —            | URL для обратного вызова. Если передан этот параметр или `async=true`, то **асинхронный режим**: немедленно возвращает `task_id`, результат будет отправлен на обратный вызов после генерации |
| `async`          | boolean | Нет          | `false`      | Асинхронный режим. Если `true`, немедленно возвращает `task_id`, в сочетании с `/kling/tasks` для опроса или обратным вызовом `callback_url` |

## Примеры запроса

### 1) Аудио-управляемый (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Текст-управляемый (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Брат, давно не виделись, у меня все хорошо, береги себя.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Пример ответа (успешный синхронный)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Поле          | Тип      | Описание                                         |
| ------------- | ------- | ----------------------------------------------- |
| `success`     | boolean | Успешно ли выполнено                                       |
| `task_id`     | string  | ID текущей задачи (можно использовать для запроса `/kling/tasks`) |
| `video_id`    | string  | ID видео, созданного Kling (можно использовать как ввод для следующего `extend`/`lip-sync`) |
| `video_url`   | string  | URL созданного видео (долговременное хранение на платформе CDN)              |
| `duration`    | string  | Длительность видео (в секундах)                                    |
| `state`       | string  | Статус задачи: `succeed` / `failed`                  |

## Асинхронный режим и запрос

При передаче `callback_url` или `async: true` интерфейс **немедленно возвращает** `task_id`; затем можно:

- **Опрос**: `POST /kling/tasks`, тело `{ "action": "retrieve", "id": "<task_id>" }` (бесплатно)
- **Обратный вызов**: после завершения генерации результат будет отправлен на ваш `callback_url`

## Полный процесс: говорящие фотографии (image2video → lip-sync)
```bash
# Шаг 1: Дайте фотографии движение, получите video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Шаг 2: Синхронизация губ с аудио
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Ошибка ответа

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "один из video_id или video_url обязателен" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | код                    | Значение                                             |
| ---- | --------------------- | -------------------------------------------------- |
| 400  | `bad_request`         | Отсутствуют или недопустимы параметры (например, не передан mode, конфликт между video и audio, текст превышает 120 символов) |
| 401  | `authorization_missing` | Отсутствует или недействителен API-ключ                          |
| 403  | `forbidden`           | Содержимое заблокировано системой контроля рисков                  |
| 429  | `too_many_requests`   | Ограничение по количеству запросов, попробуйте позже                  |
| 500  | `api_error`           | Ошибка на стороне сервера или внутреняя ошибка                       |

## Примечания

- `video_id` должен быть **созданным в течение 30 дней** доступным видео, и длиться **5 секунд или 10 секунд**; в противном случае передайте соответствующее видео через `video_url`.
- Рекомендуется, чтобы входное видео было **четким, с лицом, одного человека**, для наилучшего эффекта синхронизации губ.
- Длительность аудио/текста должна соответствовать длительности видео (аудио не должно превышать длину видео).
- Оплата происходит при **успехе** (2.45 кредитов/раз); ошибки валидации параметров (4xx) не подлежат оплате.
