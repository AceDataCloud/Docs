Отправьте задачу через `POST /kling/virtual-try-on`, используйте существующий `POST /kling/tasks` для проверки статуса задачи на платформе.

## Ввод

Необходимо предоставить ровно одно product_image и одно person_image. Значения keep_face, keep_pose, keep_background по умолчанию все равны true и могут быть независимо отключены. Самая длинная сторона входного изображения не должна превышать 2048px, самая короткая сторона должна быть больше 300px, размер файла не должен превышать 10MB.

Ниже приведён пример структуры запроса, замените URL материалов перед вызовом.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## Результаты и тарификация

Синхронный режим возвращает результат генерации; асинхронный режим сначала возвращает `task_id`, а завершённый результат содержит ссылки на видео или изображения в `data` и рассчитанный сервером `usage`. `callback_url` используется для уведомления о завершении; запрос с `watermark=true` одновременно возвращает версию с водяным знаком.

1.12 Credits/изображение, тарификация производится по фактическому количеству выходных изображений. Для видео расчёт производится по фактической длительности генерации, базовая цена за секунду до генерации не представляет общую стоимость всей задачи. За неудачные задачи плата за генерацию не взимается.
