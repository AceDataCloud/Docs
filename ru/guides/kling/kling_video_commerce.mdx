Отправьте задачу через `POST /kling/video-commerce`, используйте существующий `POST /kling/tasks` для проверки статуса задачи на платформе.

## Ввод

Загрузите одно изображение человека и укажите voice_id или используйте предустановленный avatar_id (они взаимоисключающие, для предустановленного персонажа нельзя отдельно указывать voice_id). Необходимо предоставить speech_script длиной не более 2000 символов. При предоставлении информации о товаре требуется как минимум одно ref_image и один goods_title; товарная озвучка не поддерживает speech_rate. Обычная озвучка персонажа поддерживает скорость речи 0.8, 1.0 или 1.2 раза.

Ниже приведён пример структуры запроса, замените URL материалов перед вызовом.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Результаты и тарификация

Синхронный режим возвращает результат генерации; асинхронный режим сначала возвращает `task_id`, а завершённый результат содержит ссылки на видео или изображения в `data` и рассчитанный сервером `usage`. `callback_url` используется для уведомления о завершении; запрос с `watermark=true` одновременно возвращает версию с водяным знаком.

Обычная озвучка персонажа: 1.4 Credits/сек для 720p и 1.68 Credits/сек для 1080p; товарная озвучка: 1.96 Credits/сек для 720p и 2.24 Credits/сек для 1080p. Стоимость видео рассчитывается по фактической длительности генерации, базовая цена за секунду до генерации не представляет общую стоимость всей задачи. За неуспешные задачи плата за генерацию не взимается.
