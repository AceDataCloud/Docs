title: "API говорящего фото Kling (Kling Talking Photo)"

Одним нажатием превратите **одну фотографию + один аудиофайл** в «говорящее видео». Сервис автоматически выполняет два шага внутри: сначала использует image2video, чтобы оживить фотографию, затем применяет lip-sync для синхронизации губ с аудио. Вам нужно выполнить вызов **только один раз**.

- **Адрес API**：`POST https://api.acedata.cloud/kling/talking-photo`
- **Тарификация**：по длительности, 5 секунд **16.45 Credits**、10 секунд **30.45 Credits**(= объединённая цена image2video + lip-sync)

## Заголовки запроса

| Поле              | Значение                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Параметры запроса

| Параметр             | Тип      | Обязательный  | По умолчанию                  | Описание                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Да   | —                   | Публичный URL фотографии человека, рекомендуется чёткое изображение лица анфас                    |
| `audio_url`    | string  | Да   | —                   | Публичный URL аудио для управления（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | Нет   | —                   | Подсказка для движений/эмоций на этапе анимации фотографии                      |
| `model`        | string  | Нет   | `kling-v2-1-master` | Модель Kling, используемая для анимации фотографии                     |
| `duration`     | integer | Нет   | `5`                 | Длительность видео（5 или 10 секунд）                        |
| `mode`         | string  | Нет   | `pro`               | Качество анимации（std/pro）                        |
| `callback_url` | string  | Нет   | —                   | При передаче или `async=true` асинхронно возвращается task_id        |
| `async`        | boolean | Нет   | `false`             | Асинхронный режим, используйте с опросом `/kling/tasks` или обратным вызовом          |

## Пример запроса

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Пример ответа

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Поле                 | Описание                        |
| ------------------ | ------------------------- |
| `video_url`        | Итоговое говорящее видео（уже сохранено в CDN этой платформы）      |
| `source_video_url` | Промежуточное анимационное видео фотографии（результат image2video） |
| `video_id`         | ID видео Kling                   |

## Примечания

- Для фотографии рекомендуется чёткое изображение лица анфас, с одним человеком.
- Рекомендуется, чтобы длительность аудио не превышала длительность видео（5s/10s）。
- Тарификация происходит при успехе; при сбое проверки параметров（4xx）оплата не взимается.
- Генерация занимает примерно 4–6 минут（два шага), рекомендуется использовать `async=true` + опрос `/kling/tasks`.
