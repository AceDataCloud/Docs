В этой статье представлена инструкция по интеграции Kling Videos Generation API, который позволяет создавать официальные видео Kling с помощью ввода пользовательских параметров.

## Процесс подачи заявки

Для использования API необходимо сначала подать заявку на соответствующую услугу на странице [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). После перехода на страницу нажмите кнопку «Acquire», как показано на рисунке:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы еще не вошли в систему или не зарегистрированы, произойдет автоматический переход на страницу входа с приглашением зарегистрироваться и войти. После входа или регистрации вы автоматически вернетесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит, позволяющий бесплатно использовать API.

## Основное использование

Сначала рассмотрим базовый способ использования: вводим подсказку `prompt`, действие генерации `action`, URL начального изображения `start_image_url` и модель `model`, чтобы получить обработанный результат. Для начала необходимо передать поле `action` со значением `text2video`. Основные действия включают три типа: генерация видео из текста (`text2video`), генерация видео из изображения (`image2video`) и расширение видео (`extend`). Далее нужно указать модель `model`. В настоящее время доступны модели: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`. Подробнее на изображении:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Здесь мы видим настройки заголовков запроса (Request Headers):

- `accept`: формат ответа, здесь указано `application/json` — формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать после подачи заявки.

Также заданы параметры тела запроса (Request Body):

- `model`: модель для генерации видео, включая `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`.
- `mode`: режим генерации видео, возможные значения: стандартный `std`, ускоренный `pro` и нативный 4K `4k`. Режим `4k` поддерживается только моделями `kling-v3` и `kling-v3-omni` и несовместим с `camera_control` (управление камерой).
- `action`: действие генерации видео — `text2video`, `image2video` или `extend`.
- `start_image_url`: URL начального изображения, обязательный при выборе `image2video`.
- `end_image_url`: необязательный URL конечного изображения при генерации из изображения.
- `duration`: длительность видео в секундах. Модели `kling-v3` и `kling-v3-omni` поддерживают гибкую длительность от 3 до 15 секунд (целые числа), другие модели — 5 или 10 секунд.
- `generate_audio`: опционально, булево значение, указывает, нужно ли генерировать аудио. Поддерживается моделями `kling-v3`, `kling-v3-omni` и `kling-v2-6` (только в режиме `pro`). По умолчанию `false`.
- `aspect_ratio`: соотношение сторон видео, опционально, поддерживаются `16:9`, `9:16`, `1:1`, по умолчанию `16:9`.
- `cfg_scale`: интенсивность соответствия подсказке, диапазон [0,1], чем больше, тем точнее.
- `camera_control`: опционально, параметры управления движением камеры, поддерживаются предустановки `type/simple` и настройки `horizontal`, `vertical`, `pan`, `tilt`, `roll`, `zoom`.
- `negative_prompt`: опционально, нежелательные обратные подсказки, максимум 200 символов.
- `element_list`: список основных объектов, применяется только для модели `kling-video-o1`, подробности в [официальной документации](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: список референсных видео по URL, только для модели `kling-video-o1`, подробности в [официальной документации](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: подсказка.
- `callback_url`: URL для обратного вызова результата.

После выбора параметров справа автоматически генерируется соответствующий код, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Нажмите кнопку «Try» для теста. В результате получаем:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

Возвращаемые поля:

- `success`: статус выполнения задачи генерации видео.
- `task_id`: ID задачи генерации видео.
- `video_id`: ID сгенерированного видео.
- `video_url`: ссылка на сгенерированное видео.
- `duration`: длительность видео.
- `state`: состояние задачи.

Таким образом, вы получаете ссылку на сгенерированное видео Kling из поля `video_url`.

Для генерации кода интеграции можно скопировать автоматически сгенерированный, например CURL:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Функция расширения видео

Если необходимо продолжить генерацию уже созданного видео Kling, установите параметр `action` в значение `extend` и укажите ID видео, который можно получить согласно базовому использованию, как показано на изображении:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

ID видео:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Внимание: `video_id` — это ID уже сгенерированного видео. Если вы не знаете, как сгенерировать видео, обратитесь к разделу базового использования.

Далее необходимо указать подсказку для продолжения генерации видео и следующие параметры:

- `model`: модель генерации видео, например `kling-v1`, `kling-v1-5`, `kling-v1-6`.
- `mode`: режим генерации — `std`, `pro` или `4k` (4K поддерживается только `kling-v3` и `kling-v3-omni`, несовместим с управлением камерой).
- `duration`: длительность видео, обычно 5 или 10 секунд.
- `start_image_url`: URL начального изображения при выборе `image2video`.
- `prompt`: подсказка.

Пример заполнения:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерируется код:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Пример Python-кода:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

При запуске будет получен результат:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Результат аналогичен предыдущему, что подтверждает работу функции расширения видео.

## Асинхронный обратный вызов

Поскольку генерация видео через Kling Videos Generation API занимает около 1-2 минут, при длительном отсутствии ответа HTTP-запрос будет удерживать соединение, что приведет к дополнительным затратам ресурсов. Поэтому API поддерживает асинхронный обратный вызов.

Процесс: клиент при запросе указывает поле `callback_url`. После отправки запроса API сразу возвращает результат с полем `task_id` — ID задачи. По завершении задачи результат генерации видео отправляется методом POST в формате JSON на указанный `callback_url`, включая `task_id`, что позволяет связать результат с задачей.

Рассмотрим пример.

Webhook — это сервис, принимающий HTTP-запросы. Разработчик должен заменить URL на адрес собственного HTTP-сервера. Для демонстрации используется публичный сайт https://webhook.site/, который генерирует уникальный URL Webhook, как показано:

![](https://cdn.acedata.cloud/tbcnai.png)

Скопируйте этот URL, например `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, и используйте его как `callback_url`.

Далее задайте `callback_url` в параметрах и заполните остальные поля, как на изображении:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

При запуске сразу получаем:

```
{
  "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Через некоторое время на странице `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3` появится результат генерации видео:

![](https://cdn.acedata.cloud/zv5u2q.png)

Содержимое:

```json
{
    "success": true,
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/text2video/CjJzzGfBfqcAAAAAAKdVMQ-0_raw_video_1.mp4",
    "duration": "5.1",
    "state": "succeed",
    "task_id": "20068983-0cc9-4c6a-aeb6-9c6a3c668be0"
}
```

Видно поле `task_id`, остальные поля аналогичны предыдущим. По `task_id` можно связать результат с задачей.

## Обработка ошибок

При вызове API в случае ошибок возвращаются соответствующие коды и сообщения, например:

- `400 token_mismatched`: неверный запрос, возможно, отсутствуют или некорректны параметры.
- `400 api_not_implemented`: неверный запрос, возможно, отсутствуют или некорректны параметры.
- `401 invalid_token`: неавторизован, неверный или отсутствующий токен.
- `429 too_many_requests`: превышен лимит запросов.
- `500 api_error`: внутренняя ошибка сервера.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
