В этой статье описывается процесс интеграции Sora Videos Generation API, с помощью которого можно создавать официальные видео Sora, задавая пользовательские параметры. API поддерживает два режима:

- **Версия 1 (классический режим)**: поддерживает параметры `duration` (10/15/25 секунд), `orientation` (горизонтальная/вертикальная ориентация), `size` (small/large разрешение), ссылки на референсные изображения `image_urls`, ссылку на персонажа `character_url` и др.
- **Версия 2 (режим партнёров)**: поддерживает параметры `seconds` (4/8/12 секунд), разрешение в пикселях `size` (например, 1280x720), ссылки на референсные изображения `input_reference` и др.

## Процесс подачи заявки

Для использования API необходимо подать заявку на соответствующую услугу на странице [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e). После перехода на страницу нажмите кнопку «Acquire», как показано на изображении:

![](https://cdn.acedata.cloud/q6ytrc.png)

Если вы не вошли в систему или не зарегистрированы, произойдет автоматический переход на страницу входа/регистрации. После входа или регистрации вы автоматически вернетесь на текущую страницу.

При первом запросе предоставляется бесплатный лимит для использования API.

## Основное использование (Версия 1)

Для начала рассмотрим базовый способ использования Версии 1: вводим подсказку `prompt`, массив ссылок на референсные изображения `image_urls` и модель `model`, после чего получаем обработанный результат. Пример показан ниже:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Здесь мы видим настройки заголовков запроса:

- `accept`: формат ответа, здесь `application/json` — JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

Также задаются параметры тела запроса:

- `model`: модель для генерации видео, поддерживаются `sora-2` (стандартный режим) и `sora-2-pro` (HD режим). `sora-2-pro` поддерживает видео длительностью 25 секунд, `sora-2` — только 10 и 15 секунд.
- `size`: разрешение видео, `small` — стандартное, `large` — HD (только для Версии 1).
- `duration`: длительность видео, поддерживаются 10, 15, 25 секунд (25 секунд — только для `sora-2-pro`, Версия 1).
- `orientation`: ориентация кадра, поддерживаются `landscape` (горизонтальная) и `portrait` (вертикальная) (только Версия 1).
- `image_urls`: массив ссылок на референсные изображения для генерации видео (только Версия 1).
- `character_url`: ссылка на персонажа, в видео не должно быть реальных людей (только Версия 1).
- `character_start`/`character_end`: время появления персонажа в секундах, разница 1-3 секунды (только Версия 1).
- `prompt`: подсказка (обязательный параметр).
- `callback_url`: URL для асинхронного обратного вызова.
- `version`: версия API, `1` (по умолчанию) или `2`.

## Задача генерации видео по изображению (Версия 1)

Для генерации видео на основе изображения необходимо передать параметр `image_urls` с массивом ссылок на референсные изображения. Важно: нельзя передавать реальные фотографии с лицами, иначе задача может завершиться с ошибкой.

Пример заполнения:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерируется код:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Пример кода на Python:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]

print(response.text)
```

## Задача генерации видео с персонажем (Версия 1)

Для генерации видео с персонажем необходимо передать параметр `character_url` — ссылку на видео с персонажем. Важно, чтобы в видео не было реальных людей, иначе задача завершится с ошибкой.

```python
import requests
```

## Режим Version 2

Кроме описанного выше Version 1, API поддерживает режим Version 2, который активируется установкой параметра `version` в значение `2`. Version 2 поддерживает более короткую длительность видео и управление разрешением на уровне пикселей.

### Описание параметров Version 2

| Параметр       | Тип     | Обязателен | Описание                                   |
|----------------|---------|------------|--------------------------------------------|
| `version`      | integer | Да         | Установить значение `2`                     |
| `prompt`       | string  | Да         | Подсказка для генерации видео               |
| `model`        | string  | Нет        | `sora-2` (по умолчанию) или `sora-2-pro`  |
| `duration`     | integer | Нет        | Длительность видео: `4` (по умолчанию), `8`, `12` секунд |
| `size`         | string  | Нет        | Разрешение: `720x1280` (по умолчанию), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls`   | array   | Нет        | Массив URL референсных изображений, используется только первое изображение, размер должен соответствовать параметру `size` |
| `callback_url` | string  | Нет        | URL для асинхронного обратного вызова      |

### Пример использования

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "version": 2,
  "prompt": "cat running on the river",
  "model": "sora-2",
  "duration": 8,
  "size": "1280x720"
}'
```

Пример кода на Python:

```python

    "model": "sora-2",
    "seconds": 8,
    "size": "1280x720"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### Использование референсных изображений (Version 2)

В режиме Version 2 можно передавать параметр `image_urls` с референсным изображением для управления генерацией видео (используется только первое изображение):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Важно**: размер референсного изображения должен соответствовать параметру `size`. Например, если `size` равен `1280x720`, то изображение должно иметь размер 1280×720 пикселей.

### Сравнение параметров Version 1 и Version 2

| Параметр       | Version 1           | Version 2                                  |
|----------------|---------------------|--------------------------------------------|
| `version`      | 1 (по умолчанию)    | 2                                          |
| `prompt`       | ✅                  | ✅                                         |
| `model`        | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro                      |
| `duration`     | ✅ 10/15/25 секунд  | ✅ 4/8/12 секунд                            |
| `orientation`  | ✅ landscape/portrait | ❌                                         |
| `size`         | ✅ small/large      | ✅ 720x1280/1280x720/1024x1792/1792x1024  |
| `image_urls`   | ✅ несколько изображений | ✅ только первое изображение               |
| `character_url`| ✅                  | ❌                                         |
| `callback_url` | ✅                  | ✅                                         |

## Асинхронный обратный вызов (callback)

Поскольку генерация видео занимает относительно много времени (около 1-2 минут), HTTP-запрос может долго оставаться открытым, что приводит к дополнительной нагрузке на систему. Поэтому API поддерживает асинхронный обратный вызов.

Процесс следующий: при отправке запроса клиент указывает параметр `callback_url`. API сразу возвращает ответ с `task_id` — ID задачи. После завершения задачи API отправляет POST-запрос с JSON-данными на указанный `callback_url`, включая `task_id`, что позволяет связать результат с задачей.

Пример настройки webhook — используем публичный сервис https://webhook.site/. После открытия сайта вы получите URL для webhook, например:

`https://webhook.site/eb238c4f-da3b-47a5-a922-a93aa5405daa`

Укажите этот URL в параметре `callback_url` вместе с остальными параметрами, как показано ниже:

## Обработка ошибок

При вызове API в случае ошибок возвращаются соответствующие коды и сообщения:

- `400 token_mismatched`: некорректный запрос, возможно, отсутствуют или неверны параметры.
- `400 api_not_implemented`: некорректный запрос, возможно, отсутствуют или неверны параметры.
- `401 invalid_token`: неавторизованный доступ, неверный или отсутствующий токен.
- `429 too_many_requests`: превышен лимит запросов.
- `500 api_error`: внутренняя ошибка сервера.

### Пример ответа с ошибкой

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
