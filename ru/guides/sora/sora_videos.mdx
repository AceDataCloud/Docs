В этой статье будет представлена инструкция по интеграции API генерации видео Sora, с помощью которого можно вводить пользовательские параметры для создания видео от Sora. Этот API поддерживает два режима версий:

- **Версия 1 (классический режим)**: поддерживает параметры `duration` (10/15/25 секунд), `orientation` (горизонтальный/вертикальный), `size` (маленький/большой четкости), ссылки на изображения `image_urls`, видео персонажа `character_url` и другие.
- **Версия 2 (партнерский режим)**: поддерживает параметры `seconds` (4/8/12 секунд), разрешение на уровне пикселей `size` (например, 1280x720), ссылки на изображения `input_reference` и другие.

## Процесс подачи заявки

Чтобы использовать API генерации видео Sora, сначала перейдите в [консоль Ace Data Cloud](https://platform.acedata.cloud/console/applications) и получите ваш API Token для дальнейшего использования.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Если вы еще не вошли в систему или не зарегистрированы, вы будете автоматически перенаправлены на страницу входа, где вам предложат зарегистрироваться и войти. После завершения вы будете автоматически возвращены на текущую страницу.

**Один API Token позволяет использовать все услуги платформы, не нужно подавать отдельные заявки для каждой услуги.** При первой подаче заявки предоставляется бесплатный лимит для тестирования; при недостатке лимита вы можете пополнить общий баланс в [консоли](https://platform.acedata.cloud/console/coin).

> 📘 Полная документация: [API генерации видео Sora →](https://platform.acedata.cloud/documents/sora-videos)

## Основное использование (Версия 1)

Сначала ознакомьтесь с основным способом использования Версии 1, который заключается в вводе подсказки `prompt`, массива ссылок на изображения `image_urls` и модели `model`, чтобы получить обработанный результат. Конкретное содержание следующее:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

Как видно, мы настроили заголовки запроса, включая:

- `accept`: формат ответа, который вы хотите получить, здесь указано `application/json`, то есть формат JSON.
- `authorization`: ключ для вызова API, который можно выбрать из выпадающего списка после подачи заявки.

Также настроено тело запроса, включая:

- `model`: модель для генерации видео, поддерживает `sora-2` (стандартный режим) и `sora-2-pro` (высокое качество). При этом `sora-2-pro` поддерживает `duration` для видео длительностью 25 секунд, в то время как `sora-2` поддерживает только 10 и 15 секунд.
- `size`: четкость видео, `small` — стандартная четкость, `large` — HD четкость (только Версия 1).
- `duration`: длительность видео, поддерживает 10, 15, 25 секунд, при этом 25 секунд поддерживается только `sora-2-pro` (только Версия 1).
- `orientation`: направление кадра, поддерживает `landscape` (горизонтальный), `portrait` (вертикальный) (только Версия 1).
- `image_urls`: массив ссылок на изображения, используемых для генерации видео (только Версия 1).
- `character_url`: ссылка на видео персонажа, в видео не могут появляться реальные люди (только Версия 1).
- `character_start`/`character_end`: время появления персонажа в секундах, диапазон разницы составляет 1-3 секунды (только Версия 1).
- `prompt`: подсказка (обязательное поле).
- `callback_url`: URL для асинхронного обратного вызова результата.
- `async`: необязательный, если установлен в `true`, интерфейс немедленно возвращает `task_id`, не требуя предоставления `callback_url`, затем через соответствующий интерфейс запроса задач можно опрашивать для получения результата.
- `version`: версия API, `"1.0"` (по умолчанию) или `"2.0"`.

## Задача по генерации видео из изображений (Версия 1)

Если вы хотите выполнить задачу по генерации видео из изображений, сначала параметр `image_urls` должен содержать ссылки на изображения, чтобы можно было указать следующее содержание:

- `image_urls`: массив ссылок на изображения, используемых в этой задаче по генерации видео. Обратите внимание, что нельзя передавать реальные изображения с лицами, иначе это может привести к сбою задачи.

Пример заполнения:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

После заполнения автоматически сгенерирован следующий код:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

Соответствующий код:
```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "кот бегущий по реке",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]

print(response.text)
```

- character_url: ссылка на видео, необходимую для создания персонажа, обратите внимание, что в видео не должно быть реальных людей, иначе это приведет к ошибке.

## Режим Version 2.0

Кроме вышеупомянутого режима Version 1.0, этот API также поддерживает режим Version 2.0, который можно активировать, установив параметр `version` в `"2.0"`. Режим Version 2.0 поддерживает более короткую продолжительность видео и контроль разрешения на уровне пикселей.

### Описание параметров Version 2.0

| Параметр        | Тип      | Обязателен | Описание                                               |
| -------------- | ------- | ---- | ----------------------------------------------------- |
| `version`      | string  | Да    | Установите в `"2.0"`                                   |
| `prompt`       | string  | Да    | Подсказка для генерации видео                           |
| `model`        | string  | Нет    | `sora-2` (по умолчанию) или `sora-2-pro`               |
| `duration`     | integer | Нет    | Длительность видео: `4` (по умолчанию), `8`, `12` секунд |
| `size`         | string  | Нет    | Разрешение: `720x1280` (по умолчанию), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls`   | array   | Нет    | Массив URL изображений для справки, используется только первое изображение, размер изображения должен соответствовать параметру `size` |
| `callback_url` | string  | Нет    | URL для асинхронного обратного вызова                   |

### Использование эталонного изображения (Версия 2.0)

В режиме Версия 2.0 можно передать эталонные изображения через параметр `image_urls`, чтобы направить генерацию видео (используется только первое изображение):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": "2.0",
    "prompt": "человек, идущий по красивому саду",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **Примечание**: Размер эталонного изображения должен соответствовать параметру `size`, например, если `size` равно `1280x720`, то размер эталонного изображения должен быть 1280×720.

### Сравнение параметров Версии 1.0 и Версии 2.0

| Параметр         | Версия 1.0           | Версия 2.0                             |
| ---------------- | --------------------- | --------------------------------------- |
| `version`        | 1.0 (по умолчанию)    | 2.0                                     |
| `prompt`         | ✅                     | ✅                                       |
| `model`          | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro                   |
| `duration`       | ✅ 10/15/25 секунд      | ✅ 4/8/12 секунд                          |
| `orientation`    | ✅ ландшафт/портрет   | ❌                                       |
| `size`           | ✅ маленький/большой   | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls`     | ✅ несколько эталонных изображений | ✅ используется только первое изображение |
| `character_url`  | ✅                     | ❌                                       |
| `callback_url`   | ✅                     | ✅                                       |

## Асинхронный обратный вызов

Поскольку время генерации видео через API Sora Videos Generation относительно долгое, около 1-2 минут, если API долго не отвечает, HTTP-запрос будет поддерживать соединение, что приведет к дополнительным затратам системных ресурсов, поэтому этот API также поддерживает асинхронные обратные вызовы.

Общий процесс: когда клиент инициирует запрос, дополнительно указывается поле `callback_url`, после того как клиент инициирует API-запрос, API немедленно возвращает результат, содержащий информацию о поле `task_id`, представляющем текущий идентификатор задачи. Когда задача завершена, результат генерации видео будет отправлен на указанный клиентом `callback_url` в формате POST JSON, который также включает поле `task_id`, так что результаты задачи могут быть связаны по идентификатору.

Давайте рассмотрим, как это работает на примере.

## Обработка ошибок

При вызове API, если возникает ошибка, API вернет соответствующий код ошибки и информацию. Например:

- `400 token_mismatched`: Неверный запрос, возможно, из-за отсутствия или недействительных параметров.
- `400 api_not_implemented`: Неверный запрос, возможно, из-за отсутствия или недействительных параметров.
- `401 invalid_token`: Неавторизован, недействительный или отсутствующий токен авторизации.
- `429 too_many_requests`: Слишком много запросов, вы превысили лимит частоты.
- `500 api_error`: Внутренняя ошибка сервера, что-то пошло не так на сервере.

### Пример ответа об ошибке

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
