## Что такое MCP

Model Context Protocol (MCP) — это открытый протокол, который позволяет AI-ассистентам (таким как Claude, Cursor) напрямую вызывать внешние инструменты и API. С помощью MCP AI не только отвечает на вопросы, но и выполняет реальные действия.

## Установка и использование

### Установка

```bash
pip install mcp-suno  # или другой MCP Server
```

### Настройка переменных окружения

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Настройка в Cursor

Добавьте в настройки MCP Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Настройка в Claude Desktop

Отредактируйте конфигурационный файл Claude Desktop, добавив настройки MCP Server.

## Сценарии использования

1. **Генерация музыки в Cursor**: скажите AI "создай веселую песню с помощью Suno", и AI напрямую вызовет API
2. **Поиск актуальной информации**: AI может искать свежие данные через MCP Server SERP
3. **Создание материалов для проектов**: AI может вызывать Midjourney для генерации нужных изображений

## MCP vs прямой вызов API

- **MCP**: подходит для использования в AI-инструментах программирования, вызовы осуществляет AI автоматически
- **API**: подходит для интеграции в собственные приложения с программным управлением

Оба варианта используют один и тот же Ace Data Cloud API Token и обращаются к одинаковым API-эндпоинтам.

## Итог

MCP позволяет AI-ассистентам напрямую вызывать различные API Ace Data Cloud. Все MCP Server опубликованы на PyPI, установка и настройка просты, что делает ваши AI-инструменты мощнее.

Получите API Token на [platform.acedata.cloud](https://platform.acedata.cloud).
