## Введение в Suno

Suno — одна из самых мощных платформ для генерации музыки с помощью ИИ. Через Suno API от Ace Data Cloud вы можете создавать высококачественную музыку с помощью простых вызовов API.

## Конечные точки API

| Конечная точка | Функция |
|---------------|---------|
| `POST /suno/audios` | Генерация музыки (основная конечная точка) |
| `POST /suno/lyrics` | Генерация текста песен |
| `POST /suno/persona` | Управление стилями исполнителей |
| `POST /suno/wav` | Получение формата WAV |
| `POST /suno/mp4` | Получение формата MP4 |
| `POST /suno/tasks` | Запрос статуса задач |

## Базовая генерация

### Генерация по текстовому описанию

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Генерация с пользовательским текстом песни

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Расширенные возможности

### Продолжение песни

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Генерация текста песни

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## Доступные модели

| Модель | Особенности |
|--------|-------------|
| chirp-v5 | Последняя версия, лучшее качество звука |
| v4-5-plus | Улучшенная версия |
| v4-5 | Стабильная версия |
| v4 | Классическая версия |
