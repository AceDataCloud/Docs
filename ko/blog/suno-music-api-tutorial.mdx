## Suno 소개

Suno는 현재 가장 강력한 AI 음악 생성 플랫폼 중 하나입니다. Ace Data Cloud의 Suno API를 통해 간단한 API 호출로 고품질 음악을 생성할 수 있습니다.

## API 엔드포인트

| 엔드포인트 | 기능 |
|------|------|
| `POST /suno/audios` | 음악 생성(주요 엔드포인트) |
| `POST /suno/lyrics` | 가사 생성 |
| `POST /suno/persona` | 가수 스타일 관리 |
| `POST /suno/wav` | WAV 형식 가져오기 |
| `POST /suno/mp4` | MP4 형식 가져오기 |
| `POST /suno/tasks` | 작업 상태 조회 |

## 기본 생성

### 텍스트 설명 생성

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### 맞춤 가사 생성

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## 고급 기능

### 노래 이어쓰기

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### 가사 생성

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## 사용 가능한 모델

| 모델 | 특징 |
|------|------|
| chirp-v5 | 최신 버전, 최고의 음질 |
| v4-5-plus | 향상된 버전 |
| v4-5 | 안정 버전 |
| v4 | 클래식 버전 |
