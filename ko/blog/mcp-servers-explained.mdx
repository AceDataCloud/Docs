## MCP란 무엇인가

Model Context Protocol(MCP)은 Claude, Cursor와 같은 AI 어시스턴트가 외부 도구와 API를 직접 호출할 수 있도록 하는 오픈 프로토콜입니다. MCP를 통해 AI는 단순히 질문에 답하는 것을 넘어 실제 작업을 수행할 수 있습니다.

## Ace Data Cloud에서 제공하는 MCP Server

| MCP Server | PyPI 패키지명 | 기능 |
|------------|---------------|------|
| MCPSuno | mcp-suno | AI 음악 생성 |
| MCPSerp | mcp-serp | Google 검색 |
| MCPMidjourney | mcp-midjourney | AI 이미지 생성 |
| MCPLuma | mcp-luma | AI 비디오 생성 |
| MCPSora | mcp-sora | AI 비디오 생성 |
| MCPVeo | mcp-veo | AI 비디오 생성 |
| MCPNanoBanana | mcp-nano-banana | AI 이미지 생성 |

## 설치 및 사용법

### 설치

```bash
pip install mcp-suno  # 또는 다른 MCP Server
```

### 환경 변수 설정

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Cursor에서 설정하기

Cursor의 MCP 설정에 다음을 추가하세요:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Claude Desktop에서 설정하기

Claude Desktop 설정 파일을 편집하여 MCP Server 구성을 추가하세요.

## 사용 사례

1. **Cursor에서 음악 생성**: AI에게 "Suno로 경쾌한 노래를 만들어줘"라고 요청하면 AI가 API를 직접 호출합니다.
2. **실시간 정보 검색**: AI가 SERP MCP Server를 통해 최신 정보를 검색할 수 있습니다.
3. **프로젝트 자료 생성**: AI가 Midjourney를 호출하여 프로젝트에 필요한 이미지 자료를 생성할 수 있습니다.

## MCP와 직접 API 호출 비교

- **MCP**: AI 프로그래밍 도구 내에서 AI가 자동으로 호출하는 데 적합합니다.
- **API**: 자신의 애플리케이션에 통합하여 프로그래밍 방식으로 제어할 때 적합합니다.

두 방식 모두 동일한 Ace Data Cloud API Token을 사용하며, 내부적으로 동일한 API 엔드포인트를 호출합니다.

## 요약

MCP는 AI 어시스턴트가 Ace Data Cloud의 다양한 API를 직접 호출할 수 있게 해줍니다. 모든 MCP Server는 PyPI에 배포되어 있어 설치와 구성이 간편하며, AI 도구를 더욱 강력하게 만듭니다.

API Token은 [platform.acedata.cloud](https://platform.acedata.cloud)에서 발급받으세요.
