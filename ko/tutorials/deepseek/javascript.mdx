## 소개

DeepSeek는 Ace Data Cloud에서 제공하는 AI 채팅 서비스로, DeepSeek 시리즈 대형 언어 모델입니다. Ace Data Cloud 통합 API를 통해 JavaScript로 빠르게 DeepSeek를 통합하여 다중 대화, 시스템 프롬프트, 스트리밍 출력, JSON 출력 모드, 심층 추론 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 획득
- Node.js 18+ 또는 최신 브라우저 환경

## 기본 사용법

DeepSeek API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/deepseek/chat/completions
```

본 예제에서는 `deepseek-r1` 모델을 사용합니다. 사용 가능한 모델은 `deepseek-r1`, `deepseek-r1-0528`, `deepseek-v3`, `deepseek-v3-250324`가 있습니다.

전체 JavaScript 코드 예제:

```javascript
const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "deepseek-r1",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 획득한 실제 토큰으로 교체하세요.

## 응답 처리

응답 상태 코드를 확인하고 오류를 처리하는 것이 좋습니다:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("호출 성공:", result);
} else {
  console.error(`호출 실패, 상태 코드: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 래핑

재사용 가능한 함수로 래핑하는 것을 권장합니다:

```javascript
async function callDeepSeek(data) {
  const response = await fetch("https://api.acedata.cloud/deepseek/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
