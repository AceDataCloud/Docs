## 소개

Suno는 Ace Data Cloud에서 제공하는 AI 오디오 서비스로, Suno AI 음악 생성 기능을 제공합니다. Ace Data Cloud 통합 API를 통해 cURL로 Suno를 빠르게 호출하여 텍스트 기반 음악 생성, 맞춤 가사, 노래 이어쓰기, 커버곡, 보컬 분리, 가사 생성 등의 기능을 사용할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 발급받았을 것
- cURL이 설치된 터미널 환경

## 기본 사용법

Suno API 호출의 기본 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/suno/audios
```

이 예제에서는 `chirp-v5` 모델을 사용합니다.  
사용 가능한 모델: `chirp-v5`, `v4-5-plus`, `v4-5`, `v4`, `v3-5`

전체 cURL 명령어 예시:

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}'
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 발급받은 실제 토큰으로 교체하세요.

## 응답 예시

성공적으로 호출하면 JSON 형식의 데이터가 반환됩니다. 예:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq를 사용한 응답 처리

jq 도구를 사용하여 출력 결과를 포맷하는 것을 권장합니다:

```bash
curl -s -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A cheerful pop song about summer vacation", "model": "chirp-v5", "custom": false}' | jq .
```

## 오류 처리

자주 발생하는 오류 코드:

| 상태 코드 | 설명                         |
|-----------|------------------------------|
| 401       | 인증 실패, API 토큰을 확인하세요 |
| 403       | 잔액 부족 또는 접근 권한 없음    |
| 429       | 요청 빈도 초과                |
| 500       | 서버 내부 오류                |
