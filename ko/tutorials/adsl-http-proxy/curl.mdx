## 소개

ADSL HTTP Proxy는 Ace Data Cloud에서 제공하는 네트워크 프록시 서비스로, ADSL 동적 프록시 IP 추출 기능을 제공합니다. Ace Data Cloud의 통합 API를 통해 cURL을 사용하여 ADSL HTTP Proxy를 빠르게 호출할 수 있으며, HTTP/SOCKS 프록시, 다중 통신사, 다중 지역, 사용자 지정 기간, IP 화이트리스트 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 획득
- cURL이 설치된 터미널 환경

## 기본 사용법

ADSL HTTP Proxy API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/adsl/extract
```

전체 cURL 명령어 예시:

```bash
curl -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}'
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 획득한 실제 토큰으로 교체하세요.

## 응답 예시

성공적으로 호출하면 JSON 형식의 데이터가 반환됩니다. 예:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq를 사용한 응답 처리

jq 도구를 사용하여 출력 형식을 정리하는 것을 권장합니다:

```bash
curl -s -X POST https://api.acedata.cloud/adsl/extract \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"number": 5, "type": "http", "duration": 300, "province": "广东", "isp": "电信"}' | jq .
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
