## 소개

Grok은 Ace Data Cloud가 제공하는 AI 채팅 서비스로, xAI Grok 시리즈 대형 언어 모델입니다. Ace Data Cloud 통합 API를 통해 Python으로 Grok을 빠르게 통합하여 다중 대화, 시스템 프롬프트, 스트리밍 출력, JSON 출력 모드, 시각 이해 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 획득
- Python 3.7 이상 환경
- requests 라이브러리 설치: `pip install requests`

## 기본 사용법

Grok API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/grok/chat/completions
```

본 예제에서는 `grok-3` 모델을 사용합니다. 사용 가능한 모델은 `grok-4`, `grok-4-1-fast`, `grok-3`, `grok-3-mini`, `grok-2-vision` 등이 있습니다.

전체 Python 코드 예제:

```python
import requests

url = "https://api.acedata.cloud/grok/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "grok-3",
    "messages": [
        {
            "role": "user",
            "content": "안녕하세요, 자기소개를 해주세요"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 획득한 실제 토큰으로 교체하세요.

## 응답 처리

성공적으로 호출하면 API는 JSON 형식 데이터를 반환합니다. HTTP 상태 코드를 확인하는 것을 권장합니다:

```python
if response.status_code == 200:
    result = response.json()
    print("호출 성공:", result)
else:
    print(f"호출 실패, 상태 코드: {response.status_code}")
    print(response.text)
```

## 고급 사용법

채팅 API의 경우, 실시간 응답을 받기 위해 스트리밍 출력을 지원합니다:

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
