## 소개

Sora는 Ace Data Cloud에서 제공하는 AI 비디오 서비스로, OpenAI Sora 비디오 생성 모델입니다. Ace Data Cloud 통합 API를 통해 Python으로 빠르게 Sora를 통합하여 텍스트 기반 비디오 생성, 다양한 길이, 가로/세로 화면, 캐릭터 제어, 참조 이미지 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 획득
- Python 3.7 이상 환경
- requests 라이브러리 설치: `pip install requests`

## 기본 사용법

Sora API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/sora/videos
```

본 예제에서는 `sora-2` 모델을 사용합니다.  
사용 가능한 모델: `sora-2`, `sora-2-pro`.

전체 Python 코드 예제:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 획득한 실제 토큰으로 교체하세요.

## 응답 처리

호출 성공 시 API는 JSON 형식 데이터를 반환합니다. HTTP 상태 코드를 확인하는 것을 권장합니다:

```python
if response.status_code == 200:
    result = response.json()
    print("호출 성공:", result)
else:
    print(f"호출 실패, 상태 코드: {response.status_code}")
    print(response.text)
```

## 고급 사용법

비동기 작업을 지원하는 API의 경우 콜백 URL을 통해 결과를 받을 수 있습니다:

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 결과가 콜백 URL을 통해 귀하의 서버로 전송됩니다
```

## 오류 처리

자주 발생하는 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
