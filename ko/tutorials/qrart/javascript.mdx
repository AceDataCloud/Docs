## 소개

QR Art는 Ace Data Cloud에서 제공하는 AI 이미지 서비스로, AI 아트 QR 코드를 생성합니다. Ace Data Cloud 통합 API를 통해 JavaScript로 QR Art를 빠르게 통합하여 링크 QR 코드, 텍스트 QR 코드, 사전 설정된 스타일, 사용자 지정 매개변수 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 획득
- Node.js 18+ 또는 최신 브라우저 환경

## 기본 사용법

QR Art API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/qrart/generate
```

전체 JavaScript 코드 예제:

```javascript
const response = await fetch("https://api.acedata.cloud/qrart/generate", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "type": "link",
  "content": "https://platform.acedata.cloud",
  "prompt": "sunset ocean waves",
  "preset": "neon-mech"
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 획득한 실제 토큰으로 교체하세요.

## 응답 처리

응답 상태 코드를 확인하고 오류를 처리하는 것이 좋습니다:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("호출 성공:", result);
} else {
  console.error(`호출 실패, 상태 코드: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 래핑

재사용 가능한 함수로 래핑하는 것을 권장합니다:

```javascript
async function callQRArt(data) {
  const response = await fetch("https://api.acedata.cloud/qrart/generate", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
