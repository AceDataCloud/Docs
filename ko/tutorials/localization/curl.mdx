## 소개

Localization은 Ace Data Cloud가 제공하는 도구 서비스로, AI 번역 로컬라이제이션 서비스입니다. Ace Data Cloud 통합 API를 통해 cURL로 Localization을 빠르게 호출하여 Markdown 번역, JSON 번역, 18개 언어 지원, 형식 유지 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API Token을 발급받았을 것
- cURL이 설치된 터미널 환경

## 기본 사용법

Localization API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/localization/translate
```

본 예제에서는 `gpt-4` 모델을 사용합니다.  
사용 가능한 모델: `gpt-3.5`, `gpt-4`.

전체 cURL 명령어 예제:

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 발급받은 실제 토큰으로 교체하세요.

## 응답 예시

성공적으로 호출하면 JSON 형식의 데이터를 반환합니다. 예를 들어:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq를 사용한 응답 처리

jq 도구를 사용하여 출력 형식을 정리하는 것을 권장합니다:

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API Token을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
