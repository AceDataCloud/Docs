## 소개

Hailuo는 Ace Data Cloud에서 제공하는 AI 비디오 서비스인 MiniMax 해룡 비디오 생성 모델입니다. Ace Data Cloud 통합 API를 통해 cURL로 Hailuo를 빠르게 호출하여 텍스트 생성 비디오, 이미지 생성 비디오, 감독 모드 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 획득
- cURL이 설치된 터미널 환경

## 기본 사용법

Hailuo API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/hailuo/videos
```

본 예제에서는 `minimax-t2v` 모델을 사용합니다.  
사용 가능한 모델에는 `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`가 있습니다.

전체 cURL 명령 예제:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 획득한 실제 토큰으로 교체하세요.

## 응답 예시

성공적으로 호출하면 JSON 형식의 데이터가 반환됩니다. 예:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq를 사용한 응답 처리

jq 도구를 사용하여 출력 형식을 정리하는 것을 권장합니다:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명                     |
|-----------|--------------------------|
| 401       | 인증 실패, API 토큰 확인 |
| 403       | 잔액 부족 또는 접근 권한 없음 |
| 429       | 요청 빈도 초과           |
| 500       | 서버 내부 오류           |
