## 소개

Midjourney는 Ace Data Cloud에서 제공하는 AI 이미지 서비스로, Midjourney AI 이미지 생성 기능을 제공합니다. Ace Data Cloud 통합 API를 통해 JavaScript로 Midjourney를 빠르게 통합하여 텍스트-이미지 생성, 이미지 편집, 이미지 설명, 이미지-비디오 변환, Seed 제어, 비동기 콜백 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 발급받을 것
- Node.js 18+ 또는 최신 브라우저 환경

## 기본 사용법

Midjourney API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/midjourney/imagine
```

전체 JavaScript 코드 예제:

```javascript
const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A serene Japanese garden with cherry blossoms",
  "action": "generate",
  "mode": "fast",
  "translation": true
}),
});

const result = await response.json();
console.log(result);
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 발급받은 실제 토큰으로 교체하세요.

## 응답 처리

응답 상태 코드를 확인하고 오류를 처리하는 것을 권장합니다:

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("호출 성공:", result);
} else {
  console.error(`호출 실패, 상태 코드: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 래핑

재사용 가능한 함수로 래핑하는 것을 추천합니다:

```javascript
async function callMidjourney(data) {
  const response = await fetch("https://api.acedata.cloud/midjourney/imagine", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
