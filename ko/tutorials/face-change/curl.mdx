## 소개

Face Change는 Ace Data Cloud에서 제공하는 AI 이미지 서비스이자 AI 얼굴 처리 서비스입니다. Ace Data Cloud의 통합 API를 통해 cURL을 사용하여 Face Change를 빠르게 호출할 수 있으며, 얼굴 교체, 얼굴 미화, 나이 변환, 성별 변환, 애니메이션화, 얼굴 분석 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 발급받은 상태
- cURL이 설치된 터미널 환경

## 기본 사용법

Face Change API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/face/swap
```

전체 cURL 명령어 예시:

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 발급받은 실제 토큰으로 교체하세요.

## 응답 예시

성공적으로 호출 시 JSON 형식의 데이터가 반환됩니다. 예:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq를 사용한 응답 처리

jq 도구를 사용하여 출력 형식을 정리하는 것을 권장합니다:

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명 |
|--------|------|
| 401 | 인증 실패, API 토큰을 확인하세요 |
| 403 | 잔액 부족 또는 접근 권한 없음 |
| 429 | 요청 빈도 초과 |
| 500 | 서버 내부 오류 |
