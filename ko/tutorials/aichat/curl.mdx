## 소개

AI Chat은 Ace Data Cloud에서 제공하는 AI 채팅 서비스로, 다중 모델 AI 대화 서비스를 지원합니다. Ace Data Cloud의 통합 API를 통해 cURL을 사용하여 AI Chat을 빠르게 호출할 수 있으며, 다중 모델 지원, 상태 유지 대화, 사전 설정된 역할 등의 기능을 구현할 수 있습니다.

## 전제 조건

- [Ace Data Cloud](https://platform.acedata.cloud) 계정을 보유하고 API 토큰을 발급받은 상태
- cURL이 설치된 터미널 환경

## 기본 사용법

AI Chat API의 주요 엔드포인트는 다음과 같습니다:

```
POST https://api.acedata.cloud/aichat/conversations
```

본 예제에서는 `gpt-4o` 모델을 사용합니다.  
사용 가능한 모델은 `gpt-4o`, `gpt-4`, `deepseek-r1`, `grok-3` 등이 있습니다.

전체 cURL 명령어 예제:

```bash
curl -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}'
```

`YOUR_API_TOKEN`을 Ace Data Cloud 플랫폼에서 발급받은 실제 토큰으로 교체하세요.

## 응답 예시

성공적으로 호출하면 JSON 형식의 데이터를 반환합니다. 예:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## jq를 사용한 응답 처리

jq 도구를 사용하여 출력 형식을 정리하는 것을 권장합니다:

```bash
curl -s -X POST https://api.acedata.cloud/aichat/conversations \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o", "question": "什么是人工智能？", "stateful": true}' | jq .
```

## 오류 처리

일반적인 오류 코드:

| 상태 코드 | 설명                         |
|-----------|------------------------------|
| 401       | 인증 실패, API 토큰을 확인하세요 |
| 403       | 잔액 부족 또는 접근 권한 없음    |
| 429       | 요청 빈도 초과                 |
| 500       | 서버 내부 오류                |
