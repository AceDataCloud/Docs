Continue의 JetBrains 플러그인은 VS Code와 동일한 YAML 모델 형식을 사용합니다. 구성 및 비밀은 JetBrains 플러그인을 실행하는 사용자에 속해야 합니다.

## 구성

Continue의 로컬 YAML 구성에 다음을 추가합니다:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Continue 비밀에 `ACEDATACLOUD_API_KEY`를 저장합니다. 원격 개발 시나리오는 플러그인이 실제로 실행되는 호스트에서 구성해야 합니다.

## 검증

JetBrains IDE를 재시작하고 Continue 도구 창을 열어 Local Config 모델을 선택한 후 `Reply only OK`를 전송합니다. 그런 다음 읽기 전용 파일 작업을 한 번 더 실행합니다. 여전히 이전 모델을 사용하고 있다면 원격 백엔드를 재시작하고 YAML 들여쓰기를 확인합니다.
