## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Custom provider 추가

Kilo Code에서 **Settings → Providers**를 열고, **Custom provider**를 클릭한 다음 다음과 같이 입력합니다:

| 필드           | 값                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | 방금 복사한 API Key                                                                                |
| Models       | [모델 목록](https://platform.acedata.cloud/models)으로 이동하여 확인하고, 사용할 모델 이름을 추가합니다. 예: `claude-opus-5`, `gpt-6-sol` |

![Kilo Code Custom provider 구성 화면](https://cdn.acedata.cloud/94eb5abd7a6f.png)

여기의 모델 `id`는 API 요청에서 `model` 파라미터가 사용하는 모델 이름이며, 서비스 또는 API의 UUID가 아닙니다. 먼저 [모델 목록](https://platform.acedata.cloud/models)에서 확인할 수 있습니다. 정확한 검증 시에는 `/v1/models` 응답의 `data` 배열에서 원문 그대로 복사하고, 직접 추측하거나 축약하지 마세요.

**Submit**을 클릭하면 모델이 선택기 안에 나타납니다. 팀 공유 또는 더 세부적인 구성이 필요한 경우, 공식 문서에 따라 사용자 수준의 `~/.config/kilo/kilo.jsonc` 또는 프로젝트 수준의 `./kilo.jsonc`를 편집할 수도 있습니다.

## 3. 검증

`acedatacloud/MODEL_ID`를 선택하고 `Reply only OK`를 전송한 후, 읽기 전용 파일 작업을 한 번 더 실행합니다. 모델이 나타나지 않으면 Provider가 제출되었는지, 모델 이름이 목록의 `id`와 완전히 일치하는지, 그리고 Base URL이 올바른지 확인하세요.
