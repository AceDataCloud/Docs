## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션으로 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Cline 구성

VS Code에서 Cline을 설치하고 연 다음, Cline 패널의 설정 버튼을 통해 Provider 구성으로 이동하여 다음을 입력합니다:

| 필드                                | 값                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | 방금 복사한 API Key                                                                                  |
| Model ID                          | [모델 목록](https://platform.acedata.cloud/models)으로 이동하여 확인한 후 대상 모델 이름을 그대로 입력합니다. 예: `claude-opus-5`, `gpt-6-sol` |
| Custom Headers                    | 비워 둡니다                                                                                             |
| Set Azure API version             | 비워 둡니다                                                                                             |
| Use Azure Identity Authentication | 끕니다                                                                                             |

![Cline OpenAI Compatible 구성 화면](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID`는 API 요청의 `model` 매개변수에서 사용하는 모델 이름이며, 서비스 또는 API의 UUID가 아니고 임의로 축약할 수도 없습니다. 먼저 [모델 목록](https://platform.acedata.cloud/models)에서 확인할 수 있습니다. 정확한 검증이 필요한 경우, 현재 API Key로 `GET https://api.acedata.cloud/v1/models`를 요청한 후 응답의 `data` 배열에서 대상 모델의 `id` 값을 복사합니다.

나머지 모델 기능 구성은 우선 기본값으로 유지합니다. 이미지 또는 더 큰 컨텍스트가 필요한 경우에만 선택한 모델의 실제 기능에 따라 조정합니다.

## 3. 검증

저장한 후 새 작업을 만들고 `Reply only OK`를 전송합니다. 그런 다음 Cline이 테스트 파일을 읽도록 하여 모델이 도구 호출을 지원하는지 확인합니다. 호출 기록은 [사용 이력](https://platform.acedata.cloud/console/usages)에서 확인할 수 있습니다.

401은 일반적으로 Key 오류를 의미합니다. 404는 일반적으로 Base URL이 올바르지 않거나, 입력한 Model ID가 목록의 `id`와 완전히 일치하지 않음을 의미합니다. 모델이 대화는 가능하지만 파일을 조작할 수 없는 경우, 해당 모델의 도구 호출 기능을 확인합니다.
