## 1. API 키 받기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API 키를 복사합니다.

![Ace Data Cloud API 키 받기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. OpenClaw 및 플러그인 설치

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

플러그인은 OpenClaw `2026.4.2` 이상 버전을 요구하며, 현재 기본적으로 Chat 및 Web Search 기능을 제공합니다.

## 3. 키 구성

온보딩 사용을 권장합니다:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "당신의 API 키"
```

환경 변수를 사용할 수도 있습니다:

```bash
export ACEDATACLOUD_API_KEY="당신의 API 키"
```

## 4. 선택 사항: 수동 구성

온보딩을 사용하지 않을 경우, `~/.openclaw/openclaw.json`에서 플러그인을 활성화하고 기본 모델을 설정합니다:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

API 키를 이 파일에 작성하지 마십시오; 계속해서 환경 변수를 사용하십시오.

## 5. 모델 선택 및 검증

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "OK만 응답"
```

`MODEL_ID`를 Coding Plan에서 현재 제공하는 모델로 교체하십시오. 기본 모델로 설정해야 할 경우 다음을 실행합니다:

```bash
openclaw models set acedatacloud/MODEL_ID
```

호출 기록은 [사용 이력](https://platform.acedata.cloud/console/usages)에서 확인할 수 있습니다. 401은 키가 유효하지 않음을 나타냅니다; 모델이 존재하지 않을 경우 정확한 ID와 플러그인 버전을 먼저 확인하십시오. 플러그인 디렉토리의 `cost: 0`은 OpenClaw에서 반복적으로 추정하지 않음을 나타내며, 실제 비용은 여전히 Ace Data Cloud에서 기록됩니다.

## 웹 검색

```bash
openclaw infer web search \
  --provider acedatacloud --query "최신 AI 에이전트 프레임워크" --limit 5
```

현재 플러그인 소개에 있는 이미지, 비디오 또는 음악 기능을 OpenClaw 기본 제공 기능으로 간주하지 마십시오.
