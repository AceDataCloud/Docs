Coze 공식 사용자 정의 모델 문서는 Anthropic Messages API를 지원합니다. 서로 다른 Coze 임대 버전은 헤더, 경로 조합, 스트리밍 및 도구 호출 처리 방식이 다를 수 있으므로, 처음 접속할 때는 아래 항목을 하나씩 확인해 주세요.

## 구성

1. Coze 모델 관리에 들어가서 사용자 정의 모델을 새로 추가합니다.
2. 프로토콜에서 Anthropic Messages API를 선택합니다.
3. 기본 API URL에 `https://api.acedata.cloud`를 입력합니다.
4. API 키에 당신의 Ace Data Cloud API 토큰을 입력합니다.
5. 모델에 Anthropic Messages를 지원하는 정확한 모델 ID를 입력합니다.
6. 저장하고 Coze 연결 테스트를 완료합니다.
7. Bot/Agent에서 `Reply only OK`를 보내고, 도구 호출을 다시 테스트합니다.

## 현재 경계

- 서로 다른 Coze 지역, 버전 또는 패키지는 서로 다른 양식을 표시할 수 있습니다.
- 기본 API URL에 `/v1/messages`를 반복해서 추가해서는 안 됩니다; 현재 UI에서 전체 API URL을 명확히 요구하는 경우, 양식의 안내에 따릅니다.
- Messages, Chat Completions 및 Responses는 세 개의 독립적인 경로로, 서로 대체하여 검증할 수 없습니다.
