## 1. API 키 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API 키를 복사합니다.

![Ace Data Cloud API 키 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 구성

Kilo CLI는 `kilo.jsonc`를 읽고 CLI를 시작하는 셸에서 API 키를 읽습니다.

`~/.config/kilo/kilo.jsonc`에 다음을 작성합니다:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

그런 다음 현재 셸에서 토큰을 내보냅니다:

```bash
export ACEDATACLOUD_API_KEY="여기에_ACEDATACLOUD_API_TOKEN을_붙여넣으세요"
```

## 3. 검증

```bash
kilo run -m acedatacloud/MODEL_ID "OK만 응답"
```

CLI가 토큰을 읽지 못하면 변수가 `export`되었는지 확인하고, 단순히 로드되지 않은 `.env` 파일에 작성된 것이 아닌지 확인합니다.
