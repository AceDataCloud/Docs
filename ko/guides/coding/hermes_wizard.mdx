## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 마법사 실행

```bash
hermes model
```

**Custom endpoint**를 선택하고, 순서대로 입력합니다:

| 필드             | 값                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | 방금 복사한 API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | [모델 카탈로그](https://platform.acedata.cloud/models)로 이동하여 확인하고, 대상 모델 이름을 그대로 입력합니다. 예: `claude-opus-5`, `gpt-6-sol` |
| Context length | 비워 두면 자동 감지되며, 또는 모델 카탈로그에 따라 입력                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model`은 API 요청에서 `model` 파라미터가 사용하는 모델 이름이며, 서비스 또는 API의 UUID가 아닙니다. 먼저 [모델 카탈로그](https://platform.acedata.cloud/models)에서 확인할 수 있습니다. 정확한 검증이 필요한 경우, 현재 API Key를 사용하여 `GET https://api.acedata.cloud/v1/models`를 요청한 다음 응답의 `data` 배열에서 대상 모델의 `id` 값을 복사합니다.

마법사는 `~/.hermes/config.yaml`과 로컬 자격 증명 파일에 기록합니다.

## 3. 검증

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

마법사가 구성을 저장하지 않은 경우 `hermes model --reset`을 실행한 후 다시 시도할 수 있습니다. 401은 API Key가 유효하지 않거나 현재 사용자 구성에서 읽히지 않음을 의미합니다.
