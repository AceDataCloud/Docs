Qwen Code는 `~/.qwen/settings.json`의 `modelProviders`를 사용하여 사용자 정의 Provider를 구성합니다. 여기서는 OpenAI 호환 프로토콜을 고정적으로 사용합니다.

## 구성

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud`는 배열이어야 합니다. Provider 항목은 독립적으로 구성되며, 다른 최상위 context, Header 또는 body 매개변수를 자동으로 상속하지 않습니다.

## 검증

```bash
export ACEDATACLOUD_API_KEY="여기에_ACEDATACLOUD_API_TOKEN을_붙여넣으세요"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Reply only OK"
```

진입 후 `Reply only OK`를 전송하고, 다시 한 번 읽기 전용 파일 도구를 실행합니다. 엄격하게 호환되는 엔드포인트가 도구 결과 형식을 거부하는 경우, 현재 Qwen Code 버전과 공식 호환성 설명서를 확인하세요.
