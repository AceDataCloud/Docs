## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션으로 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 구성

Roo Code 공식은 OpenAI-compatible Provider를 제공하며, 모델이 네이티브 OpenAI tools/function calling을 지원할 것을 요구합니다.

1. VS Code에서 Roo Code 설정을 엽니다.
2. **API Provider**를 **OpenAI Compatible**으로 설정합니다.
3. 다음을 입력합니다:

| 필드       | 값                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | 방금 복사한 API Key                  |
| Model ID | Coding 구성 마법사에서 선택한 모델 ID         |

![Roo Code OpenAI Compatible 구성 화면](https://cdn.acedata.cloud/b6a0e7156438.png)

이어서 모델의 실제 기능에 따라 context, max output, 이미지 및 computer-use 옵션을 설정합니다. 마지막으로 구성을 저장하고 VS Code를 다시 로드합니다.

## 3. 확인

먼저 `Reply only OK`를 전송한 다음, Roo Code가 테스트 파일을 읽도록 합니다. 일반 채팅은 성공하지만 Agent 도구가 실패한다면, 네이티브 tool calling을 지원하는 모델로 변경하고, 호환 엔드포인트가 도구 매개변수와 결과를 올바르게 스트리밍하여 반환할 수 있는지 확인합니다.
