## 1. API 키 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API 키를 복사합니다.

![Ace Data Cloud API 키 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 공급자 구성

Kilo Code의 JetBrains 플러그인은 `kilo.jsonc` 공급자 형식을 사용합니다. 구성은 실제로 플러그인이 실행되는 사용자 환경에 있어야 하며, 원격 개발 시 일반적으로 원격 백엔드 호스트입니다.

`~/.config/kilo/kilo.jsonc`에 다음을 작성합니다:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

JetBrains 백엔드를 시작하는 환경에서 `ACEDATACLOUD_API_KEY`를 내보내고 IDE 또는 원격 백엔드를 재시작합니다.

## 3. 검증

`acedatacloud/MODEL_ID`를 선택하고 `Reply only OK`를 전송한 후 에이전트가 테스트 파일을 읽도록 합니다. 로컬에서 정상 작동하지만 원격에서 실패하는 경우, 먼저 구성 파일과 환경 변수가 원격 호스트에 올바르게 작성되었는지 확인합니다.
