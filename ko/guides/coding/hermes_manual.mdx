## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용할 수 있는 애플리케이션으로 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Key 저장

`~/.hermes/.env`에 다음을 작성합니다:

```dotenv
ACEDATACLOUD_API_KEY=당신의 API Key
```

## 3. Provider 구성

`~/.hermes/config.yaml`에 다음을 추가합니다:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

[모델 디렉터리](https://platform.acedata.cloud/models)로 이동하여 모델 이름(예: `claude-opus-5`, `gpt-6-sol`)을 확인하고, 모든 `MODEL_ID`를 동일한 이름으로 교체합니다. 정확한 검증 시에는 `/v1/models` 응답의 `id` 값을 기준으로 합니다. 이 값은 API `model` 파라미터에서 사용하는 모델 이름이며, 서비스 또는 API의 UUID가 아닙니다. 실제 Key를 YAML에 작성하거나 `.env`를 커밋하지 마십시오.

## 4. 검증

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

401이 반환되면 `~/.hermes/.env`를 확인하십시오. 구성이 적용되지 않으면 Hermes를 완전히 종료한 후 재시작하십시오.
