Aider는 LiteLLM의 `openai/` 모델 접두사를 통해 OpenAI 호환 API에 연결합니다.

## 구성

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

`MODEL_ID`를 Coding 구성 마법사에서 선택한 모델로 교체하십시오. 해당 옵션을 로컬 `.env` 또는 `.aider.conf.yml`에 작성할 수도 있지만, 실제 토큰은 제출하지 마십시오.

## 검증

```bash
aider --model openai/MODEL_ID --message "Reply only OK"
```

알 수 없는 모델을 처음 사용할 때, Aider는 모델 메타데이터가 부족하다는 메시지를 표시할 수 있습니다. 이는 인증 실패와 동일하지 않습니다. 401은 토큰을 확인하고, 404는 모델 ID와 `/v1` 기본 URL을 확인합니다.
