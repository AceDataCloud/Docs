Continue는 OpenAI 호환 API를 지원합니다. Chat Completions를 고정하려면 `useResponsesApi: false`를 명시적으로 설정해야 합니다.

## 구성

Continue의 로컬 YAML 구성에 다음을 추가합니다:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

Continue의 비밀 관리에 `ACEDATACLOUD_API_KEY`를 저장하고, 실제 토큰을 프로젝트 구성에 제출하지 마십시오. Continue의 JSON 구성은 더 이상 사용되지 않으며, 새로운 구성은 YAML을 사용합니다.

## 검증

VS Code를 다시 로드하고, Continue 사이드바를 열어 Local Config에서 모델을 선택한 후 `Reply only OK`를 전송합니다; 그 다음 읽기 전용 파일 작업을 한 번 더 실행합니다. 요청이 잘못하여 `/responses`로 전송되었다면, `useResponsesApi: false`가 해당 모델 항목 내에 있는지 확인하십시오.
