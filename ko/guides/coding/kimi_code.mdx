## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Kimi Code 설치

macOS / Linux:

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

npm을 통해 설치할 수도 있습니다:

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. AceDataCloud 구성

`~/.kimi/config.toml`을 편집하고, 다음 구성을 추가합니다:

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "귀하의 API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

[모델 디렉터리](https://platform.acedata.cloud/models)로 이동하여 모델 이름(예: `claude-opus-5`, `gpt-6-sol`)을 확인하고, 모든 `MODEL_ID`를 동일한 이름으로 교체합니다. 정확한 검증 시에는 `/v1/models` 응답의 `id` 값을 기준으로 합니다. 이 값은 API `model` 매개변수에 사용되는 모델 이름이며, 서비스 또는 API의 UUID가 아닙니다. `type = "openai"`는 OpenAI Chat Completions 프로토콜을 사용합니다.

구성 파일에는 Key가 포함되어 있으므로, macOS / Linux에서는 권한을 제한하는 것이 권장됩니다:

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. 검증 및 시작

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

프로젝트에 들어간 후 `kimi`를 실행하면 사용을 시작할 수 있습니다. 401이 반환되면 API Key를 확인하고, model not found가 표시되면 `default_model`, 모델 테이블 이름 및 `model` 필드에 동일한 ID가 사용되었는지 확인합니다.
