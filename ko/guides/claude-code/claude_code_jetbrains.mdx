Claude Code는 Anthropic에서 출시한 **Agentic Coding** 도구로, 세계에서 가장 강력한 프로그래밍 에이전트 중 하나로 알려져 있습니다. Claude Code는 JetBrains IDE 전용 플러그인을 제공하며, IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio 등 모든 JetBrains IDE를 지원합니다.

이 문서는 AceData Cloud의 프록시 서비스를 통해 JetBrains IDE에서 Claude Code를 구성하고 사용하는 방법을 주로 설명합니다.

## 신청 절차

Claude Code를 사용하려면 먼저 [Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages)에서 "Acquire" 버튼을 클릭하여 요청에 필요한 자격 증명을 얻습니다:

![](https://cdn.acedata.cloud/nyq0xz.png)

로그인 또는 등록하지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 초대합니다. 로그인 후에는 자동으로 현재 페이지로 돌아옵니다.

첫 신청 시 무료 크레딧이 제공되어 Claude Code 서비스를 무료로 체험할 수 있습니다.

## 지원하는 IDE

Claude Code 플러그인은 다음 JetBrains IDE를 지원합니다:

| IDE                | 적합한 언어/장면               |
| ------------------ | --------------------- |
| **IntelliJ IDEA**  | Java, Kotlin, Scala 등   |
| **PyCharm**        | Python                |
| **WebStorm**       | JavaScript, TypeScript |
| **GoLand**         | Go                    |
| **PhpStorm**       | PHP                   |
| **Android Studio** | Android 개발            |
| **기타**             | 대부분의 JetBrains IDE 지원 |

## 설치

### 전제 조건

Claude Code JetBrains 플러그인은 Claude Code CLI에 의존하므로, 먼저 CLI가 설치되어 있는지 확인하십시오:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# 또는 Homebrew 사용
brew install claude-code
```

설치가 완료되면 다음을 통해 확인할 수 있습니다:

```bash
claude --version
```

### 플러그인 설치

![JetBrains Marketplace의 Claude Code 플러그인](https://cdn.acedata.cloud/de78fd305b.png)

1. JetBrains IDE를 엽니다.
2. **Settings** → **Plugins** → **Marketplace**로 이동합니다.
3. **Claude Code**를 검색합니다.
4. **Install**을 클릭하여 플러그인을 설치합니다.
5. IDE를 재시작합니다.

또는 [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-)에 직접 방문하여 온라인으로 설치할 수 있습니다.

> **중요**: 플러그인을 설치한 후에는 **IDE를 완전히 재시작**해야 (여러 번 재시작이 필요할 수 있음) 효과가 나타납니다.

## AceData Cloud API 구성

Claude Code JetBrains 플러그인은 통합 터미널을 통해 `claude` 명령을 실행하므로, 환경 변수 구성 방식은 CLI와 동일합니다.

### 단계 1: config.json 생성

Claude Code의 구성 파일을 생성합니다:

| 시스템                | 경로                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{사용자 이름}\.claude\config.json` |

해당 파일에 다음 내용을 작성하고 저장합니다:

```json
{
  "primaryApiKey": "self"
}
```

macOS / Linux에서 빠르게 생성하는 명령:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### 단계 2: 환경 변수 구성

**방법 1: Shell 구성 파일에 설정 (추천)**

다음 내용을 `~/.zshrc` 또는 `~/.bashrc`에 추가하고, `{token}`을 자신의 API 토큰으로 교체합니다:

```bash
# AceData Cloud - Claude Code 프록시 구성
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

수정 후 `source ~/.zshrc`를 실행하여 구성을 적용한 다음, **JetBrains IDE를 재시작**합니다.

**방법 2: Claude Code settings.json에 설정**

`~/.claude/settings.json`을 편집합니다 (존재하지 않으면 생성):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **팁**: API 토큰은 [AceData Cloud 콘솔](https://platform.acedata.cloud/console)에서 확인할 수 있습니다.

## 기본 사용

### IDE 내부 터미널에서 시작

JetBrains IDE의 통합 터미널을 열고 다음을 실행합니다:

```bash
claude
```

IDE의 통합 터미널에서 실행할 때 모든 통합 기능(Diff 뷰, 선택 컨텍스트 등)이 자동으로 활성화됩니다.

### 외부 터미널에서 연결

외부 터미널에서 Claude Code를 실행하는 경우 `/ide` 명령을 사용하여 JetBrains IDE에 연결할 수 있습니다:

```bash
claude
> /ide
```

IDE 프로젝트의 루트 디렉토리와 동일한 경로에서 Claude Code를 시작해야 Claude가 동일한 파일 집합에 접근할 수 있습니다.

### 단축키

| 단축키                                              | 기능                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Claude Code 빠르게 열기        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | 파일 참조 삽입 (예: `@File#L1-99`) |

### 통합 기능

Claude Code JetBrains 플러그인은 다음과 같은 통합 기능을 제공합니다:

- **Diff 뷰**: 코드 변경 사항이 IDE의 Diff 뷰어에 직접 표시됩니다.
- **선택 컨텍스트**: 현재 선택된 코드와 탭이 Claude에 자동으로 공유됩니다.
- **파일 참조**: 단축키를 사용하여 파일 및 행 번호를 빠르게 참조합니다.
- **진단 공유**: IDE의 Lint, 구문 오류 등의 진단 정보가 자동으로 Claude에 공유됩니다.

## 플러그인 설정

**Settings** → **Tools** → **Claude Code [Beta]**에서 다음을 구성할 수 있습니다:

| 설정                            | 설명                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | 사용자 정의 Claude 명령 경로 (예: `/usr/local/bin/claude`) |
| **Enable automatic updates**  | 플러그인 업데이트 자동 확인 및 설치                                |
| **Enable using Option+Enter** | macOS에서 Option+Enter로 팝업에서 줄 바꿈 사용             |

### WSL 사용자 구성

WSL 환경에서 사용하는 경우 Claude command를 다음과 같이 설정해야 합니다:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(`Ubuntu`를 자신의 WSL 배포판 이름으로 교체)

## 자주 묻는 질문

### 연결 실패 시 어떻게 하나요?

1. `~/.claude/config.json` 파일이 올바르게 생성되었는지 확인합니다.
2. 환경 변수가 올바르게 설정되었는지 확인합니다.
3. API 토큰이 유효한지 확인합니다 ( [콘솔](https://platform.acedata.cloud/console)에서 확인 가능).
4. JetBrains IDE를 재시작한 후 다시 시도합니다.

### 플러그인이 작동하지 않나요?

1. 프로젝트 루트 디렉토리에서 Claude Code를 실행하고 있는지 확인합니다.
2. IDE 설정에서 플러그인이 활성화되어 있는지 확인합니다.
3. IDE를 완전히 재시작합니다 (여러 번 재시작이 필요할 수 있음).
4. 원격 개발 모드를 사용하는 경우, 플러그인이 원격 호스트에 설치되어 있는지 확인합니다 (Settings → Plugin (Host)).

### IDE가 감지되지 않나요?

1. 플러그인이 설치되어 있고 활성화되어 있는지 확인합니다.
2. IDE를 재시작합니다.
3. 통합 터미널에서 Claude Code를 실행하고 있는지 확인합니다.
4. WSL 사용자는 [WSL 문제 해결 가이드](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)를 참조하십시오.

### command not found

Claude 아이콘을 클릭할 때 "command not found"라는 메시지가 표시되면:

1. CLI가 설치되었는지 확인합니다: `which claude`
2. 플러그인 설정에서 Claude 명령의 전체 경로를 구성합니다.
3. WSL 사용자는 위의 WSL 명령 형식을 사용합니다.
### 잔여 한도를 확인하는 방법은?

[AceData Cloud 콘솔](https://platform.acedata.cloud/console)에 로그인하면 현재 계정의 잔여 한도와 사용 현황을 확인할 수 있습니다.
