## 1. API Key 받기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 받기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CLI 및 플러그인 설치

먼저 Claude Code CLI를 설치합니다.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

그 다음 JetBrains Marketplace에서 **Claude Code** 플러그인을 설치하고 IDE를 재시작합니다. 플러그인은 로컬의 `claude` 명령을 호출합니다; 명령을 찾을 수 없다는 메시지가 표시되면 **Settings → Tools → Claude Code**에서 전체 경로를 입력합니다.

## 3. Ace Data Cloud 구성

JetBrains backend 환경에서 설정합니다.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="당신의 API Key"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "당신의 API Key"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

프로젝트에서 무시된 `.claude/settings.local.json`을 사용할 수도 있습니다:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "당신의 API Key"
  }
}
```

Remote Development는 원격 호스트에서 구성하고 플러그인을 설치해야 합니다; WSL 사용자는 Claude 명령을 `wsl -d Ubuntu -- bash -lic "claude"`로 설정할 수 있습니다.

## 4. 검증

IDE 통합 터미널에서 `claude`를 실행하거나 외부 터미널을 시작한 후 `/ide`를 입력합니다. 연결이 성공하면 Claude가 `OK`라고 응답하게 하고, 테스트 파일을 읽은 후 Ace Data Cloud [사용 기록](https://platform.acedata.cloud/console/usages)에서 해당 요청을 확인합니다.

플러그인이 시작되지 않으면 동일한 터미널에서 `claude --version`을 실행합니다; 401 오류가 발생하면 backend가 실제로 상속받는 환경 변수와 이전 `ANTHROPIC_API_KEY`를 확인합니다.
