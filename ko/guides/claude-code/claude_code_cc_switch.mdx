## 1. API Key 얻기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 얻기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CC Switch 설치

[CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest)에서 다운로드하며, macOS에서도 실행할 수 있습니다:

```bash
brew install --cask cc-switch
```

## 3. Provider 추가

CC Switch를 열고 **Claude Code → Add Provider → Custom**을 선택한 후 다음을 입력합니다:

| 필드         | 값                           |
| ---------- | --------------------------- |
| Name       | `Ace Data Cloud`            |
| Base URL   | `https://api.acedata.cloud` |
| API Key    | 방금 복사한 API Key               |
| API Format | `Anthropic Messages`        |

JSON 편집기를 사용하려면 다음과 같이 구성합니다:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch는 구성을 Claude Code의 사용자 설정에 기록합니다. 팀 저장소에 실제 Key를 저장하지 말고, 이전 `ANTHROPIC_API_KEY`를 동시에 보관하지 마십시오.

## 4. 활성화 및 검증

저장한 후 **Ace Data Cloud**를 활성화하고 Claude Code를 다시 엽니다. 간단한 읽기 전용 작업을 보내고 [사용 기록](https://platform.acedata.cloud/console/usages)에서 호출을 확인합니다. 전환 후에도 이전 구성을 사용하고 있다면 Claude Code와 CC Switch를 완전히 종료한 후 다시 시도하십시오.
