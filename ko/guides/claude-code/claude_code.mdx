Claude Code는 Anthropic Messages 프로토콜을 통해 Coding Plan에 접속하며, 현재 터미널과 VS Code 두 가지 구성 진입점을 제공합니다.

| 사용 진입점           | 구성 가이드                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 터미널 / CLI | [Claude Code 터미널 구성](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code        | [Claude Code for VS Code 구성](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## 공통 구성

- 기본 URL：`https://api.acedata.cloud`
- API 토큰：Coding Application에서 가져오며, 가이드의 `ANTHROPIC_AUTH_TOKEN`으로 구성
- 모델 ID：실시간 모델 디렉토리에서 선택
- 구성 수정 후：Claude Code를 재시작；VS Code 사용자는 창을 새로 고침해야 함

구식 `ANTHROPIC_API_KEY`를 동시에 보관하지 말고, 실제 토큰을 팀 공유 파일에 작성하지 마십시오.

[Coding Plan 구성 센터](https://platform.acedata.cloud/documents/coding-plan-integration)로 돌아가기.
