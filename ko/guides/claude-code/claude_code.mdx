---
title: "Claude Code 구성 튜토리얼"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code는 Anthropic에서 출시한 프로그래밍 인텔리전트 에이전트로, 터미널, IDE 및 CI/CD 파이프라인 등 다양한 환경에서 사용할 수 있습니다. AceData Cloud 프록시를 통해 더 저렴한 가격으로 Claude Code를 이용할 수 있습니다.

사용 시나리오에 따라 해당 플랫폼의 전체 구성 튜토리얼을 선택하세요:

| 플랫폼 | 설명 | 튜토리얼 링크 |
|------|------|---------|
| **VS Code** | 네이티브 확장, 인라인 Diff, @-멘션, 계획 검토 지원 | [VS Code 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 호환 편집기, Claude Code 확장 완전 지원 | [Cursor 구성 튜토리얼](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **터미널 (CLI)** | 핵심 경험, 임의 터미널에서 `claude` 실행으로 시작 | [터미널 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | IntelliJ IDEA, PyCharm, WebStorm 등 전 시리즈 IDE 지원 | [JetBrains 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | `@claude`를 사용한 자동 코드 리뷰 및 Issue 처리 | [GitHub Actions 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **팁**: 처음 신청 시 [Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages)에서 「Acquire」를 클릭하여 인증서를 획득하면 무료 할당량을 받을 수 있습니다.
