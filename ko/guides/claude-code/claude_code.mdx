---
title: "Claude Code 구성 튜토리얼"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code는 Anthropic이 출시한 프로그래밍 인공지능으로, 터미널, IDE, 데스크탑 애플리케이션 등 다양한 환경에서 사용할 수 있습니다. AceData Cloud 프록시를 통해 더 저렴한 가격으로 Claude Code를 사용할 수 있습니다.

사용 시나리오에 따라 해당 플랫폼의 구성 튜토리얼을 선택하세요:

| 플랫폼                 | 설명                                        | 튜토리얼 링크                                                                                                   |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **터미널 (CLI)**       | 핵심 경험, 어떤 터미널에서든 `claude`를 실행하면 시작할 수 있습니다.                | [터미널 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | 네이티브 확장, 인라인 Diff, @-멘션, 계획 검토 지원            | [VS Code 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | IntelliJ IDEA, PyCharm, WebStorm 등 모든 IDE 지원 | [JetBrains 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | `@claude`를 사용하여 코드 검토 및 Issue 처리를 자동화             | [GitHub Actions 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **팁**: 처음 신청하는 경우 [Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages)로 가서 "Acquire"를 클릭하여 인증서를 받아 무료 크레딧을 받을 수 있습니다.
