---
title: "Claude Code 구성 튜토리얼"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code는 Anthropic에서 출시한 프로그래밍 인텔리전트 에이전트로, 터미널, IDE, 데스크톱 애플리케이션 등 다양한 환경에서 사용할 수 있습니다. AceData Cloud 프록시를 통해 더 저렴한 가격으로 Claude Code를 이용할 수 있습니다.

> **처음 접속하나요?** 먼저 [Claude Code 5분 빠른 시작](https://platform.acedata.cloud/documents/claude-code-5min-quickstart)을 참고하는 것을 추천합니다 — 인증서 발급부터 첫 명령어 실행까지 다섯 단계로 완료할 수 있습니다.

사용 시나리오에 맞는 플랫폼별 전체 구성 튜토리얼:

| 플랫폼 | 설명 | 튜토리얼 링크 |
|------|------|---------|
| **⚡ 5분 빠른 시작** | 인증서 발급부터 첫 `claude` 명령어 실행까지 다섯 단계로 완료 | [5분 튜토리얼](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **터미널 (CLI)** | 핵심 경험, 모든 터미널에서 `claude` 실행으로 시작 가능 | [터미널 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | 네이티브 확장, 인라인 Diff, @-멘션, 계획 검토 지원 | [VS Code 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | VS Code 호환 편집기, Claude Code 확장 완전 지원 | [Cursor 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | IntelliJ IDEA, PyCharm, WebStorm 등 전 시리즈 IDE 지원 | [JetBrains 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | `@claude`를 이용한 자동 코드 리뷰 및 이슈 처리 | [GitHub Actions 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **데스크톱 애플리케이션 (Preview)** | 독립형 그래픽 클라이언트, 병렬 세션 및 외부 도구 연결 지원 | [데스크톱 애플리케이션 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **팁**: 처음 신청 시 [Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages)에서 「Acquire」를 클릭해 인증서를 받으면 무료 할당량이 제공됩니다.
