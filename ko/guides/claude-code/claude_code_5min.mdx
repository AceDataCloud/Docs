이 문서의 목표는 단 하나입니다: **5분 이내에** AceData Cloud 프록시를 사용하여 첫 번째 Claude Code 명령어를 실행하는 방법을 알려드립니다. 전체 튜토리얼은 각 IDE 하위 문서([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations))를 참고하세요. 본 문서는 「**터미널 CLI** + **VS Code 확장**」의 가장 빠른 경로만 다룹니다.

> **왜 AceData Cloud 프록시로 Claude Code를 사용할까요?**
> - 국내 직접 연결, 별도의 VPN 설정 불필요
> - 공식 대비 저렴한 가격(플랫폼 토큰 기준 과금)
> - 동일한 키로 Claude Messages API + Claude Code Token 프로토콜 동시 지원

## 1분 차: 인증서 발급

[Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages)를 열고 「**Acquire**」 버튼을 클릭하세요:

![](https://cdn.acedata.cloud/nyq0xz.png)

플랫폼이 자동으로 Application을 생성하고 무료 할당량을 제공합니다. 상세 페이지에서 **Base URL**과 **API Token** 두 가지를 기록해 두세요 — 이후 5단계 모두에서 사용됩니다.

| 필드 | 값 | 용도 |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud` | Claude Messages 호환 진입점 |
| `API_TOKEN` | `sk-...`（상세 페이지에서 복사 가능） | Anthropic 호환 인증 헤더 |

## 2분 차: Claude Code 설치

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows(네이티브 PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 완료 후 새 터미널을 열고 실행 확인:

```bash
claude --version
```

> 버전 번호가 보이면 성공입니다. Claude Code는 Node.js 런타임을 내장하고 있어, 로컬 Node 버전에 의존하지 않습니다.

## 3분 차: 환경 변수로 AceData Cloud 지정

공식 `claude login` 절차를 사용하지 말고, 환경 변수로 덮어쓰세요. 두 가지 방법 중 하나 선택:

**방법 A: 임시 설정 (현재 쉘 세션에만 적용)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="sk-당신의-Token"
```

**방법 B: 영구 설정 (권장)**

위 두 줄을 `~/.zshrc` 또는 `~/.bashrc`에 추가한 뒤 `source` 명령어로 적용하세요.

> **자주 발생하는 실수**: 환경 변수 이름은 `ANTHROPIC_AUTH_TOKEN`이어야 하며, `ANTHROPIC_API_KEY`가 아닙니다. 잘못된 이름을 사용하면 Claude Code가 공식 엔드포인트로 돌아가 401 오류가 발생합니다.

## 4분 차: 첫 명령 실행

임의의 Git 저장소로 이동하여 다음 명령 실행:

```bash
claude
```

처음 실행 시 로그인 요청이 뜨면 `Esc`를 눌러 건너뛰세요. 그 후 다음 문장을 입력하세요:

```
현재 프로젝트의 의존성을 나열하고 각 용도를 간단히 설명해 주세요.
```

정상적으로 Claude가 `read_file` / `glob` / `grep` 등의 도구를 사용해 저장소를 탐색하고 목록을 반환하면, 모델이 올바르게 응답한 것이며 401 오류가 없으면 프록시가 정상 작동 중임을 의미합니다.

## 5분 차: VS Code 확장도 연결하기

1. VS Code를 열고 → 확장 패널 → `Claude Code` 검색 후 Anthropic 공식 확장 설치;
2. VS Code를 재시작하거나 명령 팔레트에서 `Developer: Reload Window` 실행하여 3분 차에 설정한 `~/.claude/settings.json`을 확장에 로드;
3. 편집기 우측 상단의 ✦ Spark 아이콘 또는 하단 상태 표시줄의 「✱ Claude Code」 클릭하여 패널 열기;
4. 처음 로그인 요청이 뜨면 `Esc`로 건너뛰기 — 확장이 자동으로 3분 차에 설정한 `ANTHROPIC_BASE_URL`과 `ANTHROPIC_AUTH_TOKEN`을 사용합니다.

> **팁**: VS Code 확장과 CLI는 동일한 `~/.claude/settings.json`을 공유하므로, VS Code 내에서 별도로 설정할 필요 없습니다. 프로젝트별 설정으로 덮어쓰려면 저장소 루트에 `.claude/settings.local.json` 파일을 생성하세요(해당 파일은 gitignore 처리됨).

성공하면 패널에서 파일을 드래그하여 질문하거나 `@-mention`으로 파일을 참조해 수정 제안을 할 수 있습니다. 모든 과금은 AceData Cloud를 통해 처리됩니다.

## 프록시가 정상 작동하는지 확인하기

`--debug` 모드로 한 번 실행하여 실제 요청이 AceData Cloud로 가는지 확인:

```bash
claude --debug -p "say hi" 2>&1 | grep -iE 'base.?url|api\.acedata|anthropic\.com' | head
```

`https://api.acedata.cloud` 문구가 보이면 프록시가 정상 작동 중임을 의미합니다. `api.anthropic.com`이 보이거나 401 오류가 발생하면 3분 차 환경 변수 이름(`ANTHROPIC_AUTH_TOKEN`이어야 함)을 다시 확인하고, `~/.claude/.credentials.json`에 공식 토큰이 남아 있으면 삭제하세요.

## 가장 자주 묻는 5가지 질문

**Q: `claude login` 실행 후 환경 변수를 AceData로 바꾸었는데 작동하지 않아요?**  
A: `claude login`은 `~/.claude/.credentials.json`에 공식 토큰을 기록하며, 이 파일이 환경 변수보다 우선합니다. 해당 파일을 삭제하고 `source ~/.zshrc`를 다시 실행하세요.

**Q: `--model claude-opus-4-7` 같은 모델명을 쓸 수 있나요?**  
A: 가능합니다. AceData Cloud 프록시는 model 필드를 투명하게 전달하며, 모든 Anthropic 공개 모델과 저희가 확장한 `claude-opus-4-7` / `claude-haiku-4-5` / `claude-sonnet-4-5`를 지원합니다.

**Q: 여러 프로필(개인 + 회사)을 설정할 수 있나요?**  
A: 가능합니다. Claude Code는 `~/.claude/settings.json`에서 다중 프로필을 지원합니다. 가장 간단한 방법은 두 개의 쉘 함수 `claude_personal` / `claude_work`를 만들어 각각 다른 `ANTHROPIC_AUTH_TOKEN`을 export한 후 `claude $@`를 호출하는 것입니다.

**Q: GitHub Actions에서 실행할 수 있나요?**  
A: 가능합니다. 자세한 내용은 [Claude Code GitHub Actions 설정 튜토리얼](https://platform.acedata.cloud/documents/claude-code-github-actions-integration)을 참고하세요.

**Q: 무료 할당량을 다 썼으면?**  
A: [애플리케이션 관리](https://platform.acedata.cloud/applications) → 해당 Claude Application 선택 → Topup 충전(토큰 실제 사용량에 따라 과금)하거나 포인트 구독으로 전환하세요.
