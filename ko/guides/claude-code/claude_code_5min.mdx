이 문서의 목표는 오직 하나입니다: **5분 내에** AceData Cloud 프록시를 통해 첫 번째 Claude Code 명령을 실행하는 것. 전체 튜토리얼은 각 IDE 하위 문서에서 확인하세요([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); 본 문서는 「**터미널 CLI** + **VS Code 확장**」 가장 빠른 경로만 안내합니다.

> **왜 AceData Cloud 프록시로 Claude Code를 사용하는가**：
> - 국내 직접 연결, VPN 필요 없음
> - 공식보다 저렴한 가격 (플랫폼 Token 기준 과금)
> - 동일 API Key로 Claude Messages API + Claude Code Token 프로토콜 모두 지원

## 1분 차례: 인증 정보 신청

[Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages) 열고 「**Acquire**」 버튼 클릭:

![](https://cdn.acedata.cloud/nyq0xz.png)

플랫폼이 자동으로 애플리케이션을 생성하고 무료 사용량을 제공합니다. 상세 페이지의 **Base URL**과 **API Token** 두 항목을 기록하세요 — 이후 5단계에서 모두 사용됩니다.

| 항목 | 값 | 용도 |
|------|------|------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Claude Messages 호환 진입점 |
| `API_TOKEN` | `sk-...` (상세 페이지에서 복사 가능) | Anthropic 호환 인증 헤더 |

## 2분 차례: Claude Code 설치

macOS / Linux / WSL：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows(네이티브 PowerShell)：

```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 완료 후 새 터미널 열고:

```bash
claude --version
```

> 버전 번호가 보이면 정상입니다. Claude Code는 Node.js 런타임을 내장하고 있어 기기 내 Node 버전에 영향을 받지 않습니다.

## 3분 차례: 환경 변수 AceData Cloud로 지정

공식 `claude login` 대신 환경 변수로 덮어씁니다. 두 가지 방법 중 하나 선택:

**방법 A: 임시 (현재 셸 세션 한정)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-당신의-Token"
```

**방법 B: 영구 저장 (추천)**

위 두 줄을 `~/.zshrc` 또는 `~/.bashrc`에 추가 후 `source` 실행:

> **자주 하는 실수**: 환경 변수 이름은 `ANTHROPIC_AUTH_TOKEN`이고, `ANTHROPIC_API_KEY`가 아닙니다. 이름을 잘못 쓰면 Claude Code가 공식 엔드포인트로 되돌아가 401 에러를 반환합니다.

## 4분 차례: 첫 명령 실행

任意의 Git 저장소에 들어가서:

```bash
claude
```

처음 실행 시 로그인 요청이 뜨면 `Esc`로 건너뛰기. 이후 입력:

```
列出当前项目的依赖，并简要解释每个的用途。
```

보통은 Claude가 `read_file`, `glob`, `grep` 등의 도구를 사용해 저장소를 탐색 후 리스트를 제공합니다. 화면 하단 상태바에 `connected to api.acedata.cloud`가 표시되면, 프록시가 정상 동작 중임을 의미하는 핵심 신호입니다.

## 5분 차례: VS Code 확장도 연결하기

1. VS Code 열기 → 확장 패널 → `Claude Code` 검색 후 공식 Anthropic 확장 설치
2. **Cmd+Shift+P** → `Claude Code: Set Custom API Endpoint` 입력
3. `https://api.acedata.cloud/claude` 입력 후 엔터
4. 다시 `Claude Code: Set API Token` 입력 후 본인 Token 넣기

성공하면 사이드바에 Claude Code 패널이 나타나며, 파일 드래그 후 문의하거나 `@` 멘션으로 수정 제안도 가능. 모든 과금은 AceData Cloud가 담당합니다.

## 프록시 정상 작동 여부 확인

Claude Code 대화창에 입력:

```
访问 https://api.acedata.cloud/whoami 并告诉我返回了什么
```

자신의 계정 정보 (`{user_id, plan, ...}`)가 리턴되면, 요청이 실제 AceData Cloud를 통해 가고 있음을 의미. 만약 공식 도메인으로 리다이렉트되어 401 에러가 뜬다면 3단계 환경 변수 설정을 다시 확인하세요.

## 자주 묻는 5가지 질문

**Q：`claude login` 후 환경 변수를 AceData로 바꿨는데 안 되는 경우?**  
A：`claude login`은 `~/.claude/.credentials.json`에 공식 Token 저장 → 우선순위가 높음. 해당 파일 삭제 후 `source ~/.zshrc` 또는 터미널 재시작하세요.

**Q：`--model claude-opus-4-7` 모델명 사용 가능?**  
A：가능합니다. AceData Cloud 프록시는 `model` 필드를 그대로 전달하며, 공개된 모든 Anthropic 모델 + `claude-opus-4-7`, `claude-haiku-4-5`, `claude-sonnet-4-5` 확장 지원.

**Q：여러 Profile(개인 + 회사) 설정 가능한가?**  
A：가능합니다. Claude Code는 `~/.claude/settings.json` 다중 프로필 지원 또는 간단하게 두 개 쉘 함수(`claude_personal`, `claude_work`) 만들어 각각 다른 Token을 export 후 `claude $@` 호출.

**Q：GitHub Actions에서 사용할 수 있나요?**  
A：가능합니다. [Claude Code GitHub Actions 연동 튜토리얼](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) 참고.

**Q：무료 한도 소진 후에는?**  
A：[애플리케이션 관리](https://platform.acedata.cloud/applications)에서 해당 Claude 앱 선택 후 토큰 기반 충전 또는 포인트 구독으로 이용.
