Claude Code는 Anthropic이 출시한 프로그래밍 도구로, 세계에서 가장 강력한 프로그래밍 에이전트 중 하나로 알려져 있습니다. Claude Code의 VS Code 확장은 네이티브 그래픽 인터페이스를 제공하며, VS Code에서 Claude Code를 사용하는 추천 방법입니다.

이 문서는 Ace Data Cloud의 프록시 서비스를 통해 VS Code에서 Claude Code 확장을 구성하고 사용하는 방법을 주로 설명합니다.

## 신청 절차

Claude Code를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API 토큰을 받아야 하며, 이를 백업해 두세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

로그인 또는 등록을 하지 않은 경우, 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 초대합니다. 로그인 및 등록 후에는 자동으로 현재 페이지로 돌아옵니다.

첫 신청 시 무료 크레딧이 제공되어 Claude Code 서비스를 무료로 체험할 수 있습니다.

## Claude Code 플러그인 설치

VS Code의 확장 마켓에서 **Claude Code**를 검색하고, 발행자가 **Anthropic**인지 확인한 후 설치합니다. 설치가 완료되면 활동 표시줄에 Claude Code 항목이 나타납니다.

## Ace Data Cloud API 구성

플러그인을 처음 열면 Anthropic 공식 계정으로 로그인하라는 메시지가 표시됩니다. 우리는 공식 로그인을 건너뛰고 Ace Data Cloud의 프록시 API를 구성하여 사용할 수 있으며, 공식 구독이 필요하지 않습니다.

확장과 터미널 CLI는 동일한 Claude Code 설정을 읽습니다. 전체 인증, 자격 증명 충돌 처리 및 전역 구성 방법은 [Claude Code 터미널 구성 튜토리얼](https://platform.acedata.cloud/documents/claude-code-terminal-integration)을 참조하세요. 현재 프로젝트에만 적용하려면 프로젝트 루트 디렉토리에 `.gitignore`에 추가된 `.claude/settings.local.json`을 생성합니다:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

여기서 `{token}`은 방금 복사한 API 키입니다. VS Code의 환경에 이전 `ANTHROPIC_API_KEY`가 이미 있는 경우, 해당 환경에서 `unset ANTHROPIC_API_KEY`를 먼저 실행하세요; 빈 문자열을 정리로 사용하지 말고, 실제 키를 팀 공유의 `.claude/settings.json`에 넣지 마세요.

아래는 VS Code 1.136.1과 Claude Code 확장 2.1.251을 사용하여 로컬에서 완료한 구성입니다. 스크린샷은 실제 자격 증명이 유출되지 않도록 자리 표시자 키를 사용했습니다:

![VS Code에서의 Ace Data Cloud Claude Code 구성](https://cdn.acedata.cloud/f925e9e9597b.png)

구성이 완료되면 VS Code를 재시작하세요.

> 주의: 위의 구성은 현재 프로젝트에만 적용되며, 위의 `.claude/settings.local.json` 구성 파일 경로를 `.gitignore` 파일에 추가하여 원격 저장소로 전송되지 않도록 하는 것이 좋습니다.

모든 프로젝트에 적용하고 싶다면, 해당 구성을 사용자 디렉토리에 직접 추가할 수 있습니다. 해당 경로는 `~/.claude/settings.json`입니다.

> 주의: 구성이 완료된 후에는 VS Code를 재시작하거나 다시 로드해야 위의 구성이 적용됩니다.

## 기본 사용

구성이 완료되면 Claude Code 패널에서 "README.md를 읽고 한 문장으로 요약하기"와 같은 간단한 읽기 전용 작업을 보냅니다. 작업이 성공하면 [사용 기록](https://platform.acedata.cloud/console/usages)에서 이번 호출을 확인할 수 있습니다.
