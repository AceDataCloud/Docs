## 1. API 키 받기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API 키를 복사합니다.

![Ace Data Cloud API 키 받기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Claude Code 설치

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 후 확인:

```bash
claude --version
```

## 3. Ace Data Cloud 구성

전역적으로 사용할 때는 다음 변수를 `~/.zshrc` 또는 `~/.bashrc`에 추가합니다:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="당신의 API 키"
unset ANTHROPIC_API_KEY
```

터미널을 다시 열거나 해당 구성 파일을 `source` 합니다.

현재 프로젝트에만 적용할 경우, `.gitignore`에 추가된 `.claude/settings.local.json`을 생성할 수 있습니다:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "당신의 API 키"
  }
}
```

두 가지 방법 중 하나를 선택하세요. 실제 키를 팀이 공유하는 `.claude/settings.json`에 작성하지 마세요; 환경에 `ANTHROPIC_API_KEY`가 이미 있다면, 실제로 제거해야 하며 빈 문자열로 설정하지 마세요.

## 4. 시작 및 검증

```bash
cd /path/to/your/project
claude
```

진입 후 읽기 전용 작업을 보내세요, 예를 들어 “README.md를 읽고 한 문장으로 요약하기”. 호출 기록과 잔액은 [사용 내역](https://platform.acedata.cloud/console/usages) 및 [애플리케이션 목록](https://platform.acedata.cloud/console/applications)에서 확인할 수 있습니다.

만약 401이 반환된다면, 키가 완전한지, 이전 `ANTHROPIC_API_KEY`가 제거되었는지 확인하고 Claude Code를 완전히 재시작하세요. 모델은 접속 구성에서 고정할 필요가 없으며, Claude Code에서 현재 사용 가능한 모델을 선택할 수 있습니다.
