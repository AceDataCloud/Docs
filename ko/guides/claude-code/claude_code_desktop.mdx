Claude Code는 Anthropic이 출시한 **Agentic Coding** 도구로, 세계에서 가장 강력한 프로그래밍 에이전트 중 하나로 알려져 있습니다. Claude Code 데스크탑 애플리케이션은 독립적인 그래픽 인터페이스를 제공하며, Diff 검토, 병렬 세션(기타 Git Worktree로 격리), 원격 세션 등의 기능을 지원하여 어떤 IDE에도 의존하지 않습니다.

이 문서는 AceData Cloud의 프록시 서비스를 통해 Claude Code 데스크탑 애플리케이션을 구성하고 사용하는 방법을 주로 설명합니다.

> **주의**: Claude Code 데스크탑 애플리케이션은 현재 미리보기 단계(Preview)에 있으며, macOS와 Windows만 지원합니다.

## 신청 절차

Claude Code를 사용하려면 먼저 [Claude Messages 서비스 페이지](https://platform.acedata.cloud/documents/claude-messages)로 가서 "Acquire" 버튼을 클릭하여 요청에 필요한 자격 증명을 얻습니다:

![](https://cdn.acedata.cloud/nyq0xz.png)

로그인 또는 등록하지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 요청합니다. 로그인 후에는 자동으로 현재 페이지로 돌아옵니다.

첫 신청 시 무료 크레딧이 제공되어 Claude Code 서비스를 무료로 체험할 수 있습니다.

## 데스크탑 애플리케이션 설치

### 시스템 요구 사항

- macOS(인텔 및 Apple Silicon) 또는 Windows(x64 / ARM64)
- Linux는 데스크탑 애플리케이션을 지원하지 않습니다.

### 다운로드 및 설치

[Claude 공식 다운로드 페이지](https://claude.ai)로 가서 해당 플랫폼의 설치 패키지를 다운로드합니다:

- **macOS**: `.dmg` 파일을 다운로드하여 Applications 폴더로 드래그합니다.
- **Windows x64**: `.exe` 설치 패키지를 다운로드하여 안내에 따라 설치합니다.
- **Windows ARM64**: ARM64 버전을 다운로드합니다(주의: ARM64는 로컬 세션을 지원하지 않으며 원격 세션을 사용해야 합니다).

![Claude 데스크탑 애플리케이션 다운로드 페이지](https://cdn.acedata.cloud/c3c8c57264.png)

설치가 완료되면 Applications 폴더(macOS) 또는 시작 메뉴(Windows)에서 Claude를 시작합니다.

## AceData Cloud API 구성

데스크탑 애플리케이션이 시작되면 Anthropic 계정에 로그인해야 합니다. 환경 변수를 구성하여 AceData Cloud의 프록시 API를 사용할 수 있으며, **공식 구독이 필요 없습니다**.

데스크탑 애플리케이션은 Shell 환경에서 환경 변수를 읽으므로 Shell 구성 파일에서 설정해야 합니다.

### 환경 변수 구성

**macOS 사용자**

다음 내용을 `~/.zshrc`(또는 `~/.bashrc`)에 추가하고 `{token}`을 자신의 API 토큰으로 교체합니다:

```bash
# AceData Cloud - Claude Code 프록시 구성
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

저장한 후 다음을 실행합니다:

```bash
source ~/.zshrc
```

**Windows 사용자**

"시스템 속성 → 고급 → 환경 변수"를 통해 다음 시스템 환경 변수를 추가합니다:

| 변수명                    | 값                           |
| ---------------------- | --------------------------- |
| `ANTHROPIC_AUTH_TOKEN` | `{token}`(자신의 API 토큰으로 교체)     |
| `ANTHROPIC_BASE_URL`   | `https://api.acedata.cloud` |

또는 PowerShell을 사용하여:

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "{token}", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.acedata.cloud", "User")
```

**settings.json을 통해 구성할 수도 있습니다**

`~/.claude/settings.json`을 편집합니다(존재하지 않으면 생성):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **팁**: API 토큰은 [AceData Cloud 콘솔](https://platform.acedata.cloud/console)에서 확인할 수 있습니다. 구성이 완료된 후 **데스크탑 애플리케이션을 재시작**하여 환경 변수를 적용해야 합니다.

## 기본 사용

### 프로젝트 열기

1. Claude 데스크탑 애플리케이션을 시작합니다.
2. 상단의 **Code** 탭을 클릭합니다.
3. **Local** 실행 모드를 선택합니다.
4. **Select folder**를 클릭하여 프로젝트 디렉토리를 선택합니다.

### 대화 시작

입력 상자에 자연어로 요구 사항을 설명합니다:

- "TODO 주석을 찾아 수정하세요."
- "주 함수에 테스트를 추가하세요."
- "이 프로젝트의 구조를 설명하세요."

Claude는 코드베이스를 분석하고 수정 제안을 하며, Diff 뷰로 변경 사항을 보여줍니다.

### 권한 모드

전송 버튼 옆의 모드 선택기를 통해 전환합니다:

| 모드       | 설명                 |
| -------- | ------------------ |
| **Ask**  | 매번 수정 전에 확인 요청(신규 사용자에게 추천)  |
| **Code** | 파일 편집을 자동으로 수락하지만 터미널 명령은 여전히 확인 필요 |
| **Plan** | 먼저 상세 계획을 수립하고 승인을 기다린 후 실행 |

### 병렬 세션

사이드바의 **+ New session**을 클릭하여 여러 병렬 세션을 시작할 수 있습니다. Git 저장소의 경우 각 세션은 Worktree를 통해 독립적인 프로젝트 복사본을 얻어 서로 간섭하지 않습니다.

Worktree는 기본적으로 `~/.claude-worktrees/` 디렉토리에 저장됩니다.

### Diff 검토

Claude가 파일을 수정하면 변경 통계(예: `+12 -1`)가 표시되며, 클릭하면 Diff 뷰어가 열려 파일별로 수정을 검토할 수 있습니다. 특정 코드 줄을 클릭하여 댓글을 추가할 수 있으며, Claude는 피드백에 따라 조정합니다.

## 외부 도구 연결

세션을 시작하기 전에 **⋯** 버튼을 클릭하고 **Connectors**를 선택하여 외부 통합을 추가할 수 있습니다:

- Google Calendar
- Slack
- GitHub
- Linear
- Notion
- 기타...

연결 후 Claude는 직접 캘린더를 읽고, 메시지를 보내고, Issue를 생성할 수 있습니다.

## CLI와의 관계

데스크탑 애플리케이션과 CLI는 동일한 기본 엔진을 사용하며 다음 구성을 공유합니다:

- `CLAUDE.md` / `CLAUDE.local.md` 프로젝트 메모리 파일
- `~/.claude.json` / `.mcp.json`의 MCP 서버 구성
- `~/.claude/settings.json`의 설정
- Hooks 및 Skills 구성

두 애플리케이션은 동일한 프로젝트에서 동시에 실행될 수 있으며, 각자 독립적인 세션 기록을 유지합니다.

## 자주 묻는 질문

### 연결 실패 시 어떻게 하나요?

1. `~/.claude/config.json` 파일이 올바르게 생성되었는지 확인합니다.
2. 환경 변수가 올바르게 설정되었는지 확인합니다(데스크탑 애플리케이션을 재시작하여 적용).
3. API 토큰이 유효한지 확인합니다( [콘솔](https://platform.acedata.cloud/console)에서 확인 가능).
4. `settings.json`을 통해 환경 변수를 구성한 경우 파일 형식이 올바른지 확인합니다.

### 설치된 도구를 찾을 수 없나요?

Claude가 `npm`, `node` 등의 명령을 찾을 수 없는 경우:

1. 이러한 도구가 일반 터미널에서 정상적으로 작동하는지 확인합니다.
2. Shell 구성 파일(`~/.zshrc`, `~/.bashrc`)에서 PATH가 올바르게 설정되었는지 확인합니다.
3. 환경 변수를 다시 로드하기 위해 데스크탑 애플리케이션을 재시작합니다.

### 잔여 크레딧을 어떻게 확인하나요?

[AceData Cloud 콘솔](https://platform.acedata.cloud/console)에 로그인하면 현재 계정의 잔여 크레딧과 사용 현황을 확인할 수 있습니다.
