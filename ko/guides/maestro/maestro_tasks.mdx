Maestro 작업 조회 API의 주요 기능은 [Maestro 비디오 생성 API](development_maestro_videos.md) (`POST /maestro/videos`)에서 반환된 작업 ID를 통해 해당 작업의 실행 상태와 최종 결과를 조회하는 것입니다.

본 문서에서는 Maestro 작업 조회 API의 연동 설명을 자세히 소개합니다. 비디오 생성은 비동기 작업이므로 제출 후 본 인터페이스를 통해 진행 상황과 완성된 영상을 주기적으로 조회해야 하며, **주기적 조회는 무료이며 포인트를 소모하지 않습니다.**

`POST https://api.acedata.cloud/maestro/tasks`

## 신청 절차

Maestro 작업 조회 API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 받아야 합니다. 이를 보관해 두십시오.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

로그인 또는 등록이 되어 있지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 요청합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 한도가 제공되어 무료로 체험할 수 있으며, 한도가 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Maestro 작업 조회 API →](https://platform.acedata.cloud/documents/maestro-tasks)

## 단일 작업 조회

비디오 작업을 생성하는 방법에 대한 내용은 [Maestro 비디오 생성 API](development_maestro_videos.md) 문서를 참조하십시오. 반환된 작업 ID 예시로 `f57e99c4f60f4373a15517742ce2357d`를 사용하여 상태와 결과를 조회하는 방법을 시연합니다.

### 요청 헤더 및 요청 본문 설정

**Request Headers**에는 다음이 포함됩니다:

- `accept`: JSON 형식의 응답 결과를 수신하도록 지정하며, 여기서는 `application/json`으로 설정합니다.
- `authorization`: API 호출에 필요한 키로, 신청 후 직접 드롭다운에서 선택할 수 있습니다.
- `content-type`: 요청 본문의 형식으로, 여기서는 `application/json`으로 설정합니다.

**Request Body**에는 다음이 포함됩니다:

| 필드       | 유형     | 필수  | 설명                                                |
| -------- | ------ | --- | ------------------------------------------------- |
| `id`     | string | 예   | `POST /maestro/videos`에서 반환된 `task_id`              |
| `action` | string | 아니오   | `retrieve`(기본값, 단일 작업 조회)/ `retrieve_batch`(이력 작업 목록 조회) |

### 코드 예시

해당 CURL 코드는 다음과 같습니다:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "action": "retrieve"
}'
```

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/maestro/tasks"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "id": "f57e99c4f60f4373a15517742ce2357d",
    "action": "retrieve"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

### 응답 예시

요청이 성공하면 API는 해당 비디오 작업의 상태와 결과를 반환합니다. 작업 완료 시의 반환 예시는 다음과 같습니다(각 언어에 대해 하나의 `variant`가 있습니다):

```json
{
  "id": "f57e99c4f60f4373a15517742ce2357d",
  "started_at": 1769262721.823,
  "finished_at": 1769264698.3,
  "elapsed": 1976.477,
  "status": "succeeded",
  "progress": {
    "percent": 100,
    "stage": "producing",
    "message": "rendering scene 2"
  },
  "request": {
    "prompt": "20초 안에 벡터 데이터베이스가 무엇인지 설명하고, 기초가 없는 관객에게 적합하며, 마지막에 기억할 만한 한 마디를 추가하세요.",
    "langs": [
      "zh-cn",
      "en"
    ],
    "aspect": "9:16",
    "duration": 20
  },
  "response": {
    "success": true,
    "data": {
      "variants": [
        {
          "lang": "zh-cn",
          "aspect": "9:16",
          "kind": "video",
          "title": "什么是向量数据库",
          "output_url": "https://…/zh.mp4"
        },
        {
          "lang": "en",
          "aspect": "9:16",
          "kind": "video",
          "title": "What is a vector database",
          "output_url": "https://…/en.mp4"
        }
      ],
      "project": {
        "tarball_url": "https://…/project.tar.gz",
        "outputs": [
          "https://…/zh.mp4",
          "https://…/en.mp4"
        ]
      },
      "percent": 100,
      "stage": "producing",
      "progress": [
        {
          "stage": "producing",
          "message": "rendering scene 2",
          "pct": 60,
          "t": 1750000000
        }
      ]
    }
  }
}
```

반환 결과의 필드 설명은 다음과 같습니다:

- `id`: 이 비디오 작업의 ID로, 본 비디오 생성 작업을 고유하게 식별하는 데 사용됩니다.
- `status`: 작업 상태로, `pending → planning → producing → succeeded`(또는 `failed`)의 값을 가집니다. 작업 완료 여부는 최상위 `status`로 판단합니다.
- `elapsed`: 작업에 소요된 시간(초).
- `progress`: 최상위 진행 객체로, `percent`(0–100)는 작업 성공 후 100으로 고정됩니다; `stage`와 `message`는 AI 감독의 최근 진행 이벤트를 반영합니다(따라서 성공 후에도 `stage`는 마지막 실행 단계인 `producing`일 수 있으며, 진행률 표시줄에 직접 사용할 수 있습니다).
- `request`: 작업을 시작할 때의 요청 본문.
- `response`: 작업의 반환 정보.
  - `success`: 작업이 성공했는지 여부.
  - `data.variants`: 각 언어에 해당하는 완성된 영상 객체로, `lang`, `aspect`, `title`, `output_url`(완성된 영상 다운로드 주소) 등을 포함합니다.
  - `data.project`: 전체 프로젝트 산출물로, `tarball_url`(프로젝트 패키지)와 `outputs`(모든 완성된 영상 링크)를 포함합니다.
  - `data.progress`: 단계별로 추가된 진행 이벤트 배열(append-only 로그)로, 상세한 실시간 진행 상황을 표시하는 데 사용할 수 있습니다.
- `created_at`: 작업 생성 시간, Unix 타임스탬프(초).
- `started_at`: 작업 시작 실행 시간, Unix 타임스탬프(초). 작업이 시작되지 않은 경우 null입니다.
- `finished_at`: 작업 완료 시간, Unix 타임스탬프(초). 작업이 완료되지 않은 경우 null입니다.

## 이력 목록 조회

`action: retrieve_batch`를 전달하면 현재 사용자의 최근 작업(생성 시간 역순)을 조회할 수 있으며, "내 비디오" 목록 페이지에 사용할 수 있습니다.

**Request Body**에는 다음이 포함됩니다:

| 필드               | 유형     | 필수  | 설명                      |
| ---------------- | ------ | --- | ----------------------- |
| `action`         | string | 예   | 고정값 `retrieve_batch`    |
| `limit`          | int    | 아니오   | 반환할 항목 수, 기본값 20              |
| `created_at_max` | int    | 아니오   | 해당 Unix 타임스탬프보다 이전의 작업만 반환(페이지네이션용) |
| `created_at_min` | int    | 아니오   | 해당 Unix 타임스탬프보다 이후의 작업만 반환      |

### 코드 예시

해당 CURL 코드는 다음과 같습니다:
```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "retrieve_batch",
  "limit": 20
}'
```

## 폴링 제안

비디오 제작에 시간이 오래 걸리므로, `status`는 `pending → planning → producing → succeeded`(또는 `failed`)를 거칩니다. `status`가 `succeeded` 또는 `failed`로 변할 때까지 5-10초마다 폴링하는 것이 좋습니다. 최상위 `progress.percent`를 활용하여 실시간 진행률 표시줄을 보여줄 수 있습니다. **이 인터페이스의 폴링은 무료이며, 포인트를 소모하지 않습니다.**

## 오류 처리

API를 호출할 때 오류가 발생하면, API는 해당 오류 코드와 정보를 반환합니다. 예를 들어:

- `401 invalid_token`: 인증되지 않음, 유효하지 않거나 누락된 인증 토큰.
- `404 not_found`: 작업을 찾을 수 없음, 주어진 task_id가 존재하지 않음.
- `429 too_many_requests`: 너무 많은 요청, 비율 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류, 서버에서 문제가 발생했습니다.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 결론

이 문서를 통해, 여러분은 Maestro 작업 조회 API를 사용하여 단일 작업의 상태와 결과를 조회하고, 현재 사용자의 역사적 작업 목록을 가져오는 방법을 이해하게 되었습니다. 이 문서가 여러분이 해당 API를 더 잘 연동하고 사용하는 데 도움이 되기를 바랍니다. 질문이 있으시면 언제든지 기술 지원 팀에 문의해 주십시오.
