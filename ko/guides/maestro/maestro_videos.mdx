Maestro는 **Agent 네이티브** 비디오 제작 인터페이스입니다. 한 문장의 자연어 `prompt`로 원하는 비디오를 설명하고(선택적으로 `file_urls`를 사용해 참고 이미지 / 비디오 / 오디오를 첨부), 헤드리스 「AI 감독」이 자동으로 주제 선정, 스크립트 작성, 화면 생성, 더빙, 배경음악, 합성 및 렌더링을 완료하여 최종적으로 자막이 포함된 완성본을 제작하고 CDN에 업로드합니다.

이 문서에서는 Maestro 비디오 생성 API의 연동 안내를 자세히 소개하여, 빠르게 통합하고 해당 API의 기능을 충분히 활용할 수 있도록 도와드립니다.

이것은 **비동기 작업** 인터페이스입니다. 제출 후 즉시 `task_id`가 반환되며, 이후 [Maestro 작업 조회 API](/ko/guides/maestro/maestro_tasks)(`POST /maestro/tasks`)를 통해 결과를 폴링하여 가져옵니다(폴링은 무료이며 과금되지 않음). 기존 비디오에서 계속 반복 작업하려면 `action: remix` / `edit` / `extend`와 `ref_task_id`를 함께 사용할 수 있습니다.

## 신청 절차

Maestro 비디오 생성 API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 보관해 두세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않은 경우 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스별로 별도 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

## 기본 사용법

`POST https://api.acedata.cloud/maestro/videos`

가장 기본적인 사용법은 자연어 `prompt` 하나만 전달하면 되며, AI 감독이 스크립트, 화면, 더빙 및 편집을 자동으로 결정합니다. 여기에서는 먼저 설정해야 하는 요청 헤더와 요청 본문을 알아보겠습니다.

**Request Headers**에는 다음이 포함됩니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지 지정하며, 여기서는 JSON 형식인 `application/json`을 입력합니다.
- `authorization`: API 호출 키이며, 신청 후 직접 드롭다운에서 선택할 수 있습니다.
- `content-type`: 요청 본문의 형식이며, 여기서는 `application/json`을 입력합니다.

**Request Body**에는 주로 다음이 포함됩니다:

- `prompt`: 만들 비디오를 자연어로 설명합니다(주제, 표시할 내용, 스타일, 대상).
- `langs`: 완성본 언어 배열이며, 매번 한 가지 언어만 전달합니다. 예: `["zh-cn"]`, 기본값은 `["zh-cn"]`입니다.
- `aspect`: 화면 비율이며, `9:16`(기본값) / `16:9` / `1:1`입니다.
- `duration`: 목표 길이(초)이며, 기본값은 30입니다.

요청 본문의 모든 필드는 다음 표와 같습니다:

| 필드            | 유형       | 필수  | 설명                                                                                                                                                                                                                                    |
| ------------- | -------- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | 예   | 만들 비디오를 자연어로 설명합니다(주제, 표시할 내용, 스타일, 대상). 스크립트, 화면, 더빙, 편집은 모두 AI가 결정합니다                                                                                                                                                                                      |
| `action`      | string   | 아니요   | `generate`(기본값, 새 비디오 생성) / `remix` / `edit` / `extend`(기존 비디오에서 반복 작업, `ref_task_id`와 함께 사용 필요)                                                                                                                                                         |
| `ref_task_id` | string   | 아니요   | `action`이 remix / edit / extend일 때 필수: 시작점으로 사용할 이력 작업 `task_id`                                                                                                                                                                            |
| `file_urls`   | string[] | 아니요   | 참고 미디어(이미지 / 비디오 / 오디오 URL). 예를 들어 화면에 표시할 제품 이미지, logo 또는 자막을 추가할 소스 클립                                                                                                                                                                                      |
| `langs`       | string[] | 아니요   | 완성본 언어이며, 매번 한 가지 언어만 전달할 수 있습니다. 예: `["zh-cn"]`, 기본값은 `["zh-cn"]`                                                                                                                                                                                             |
| `aspect`      | string   | 아니요   | `9:16`(기본값) / `16:9` / `1:1`, 일괄적으로 1080p/30fps 출력                                                                                                                                                                                           |
| `duration`    | int      | 아니요   | 목표 길이(초), 기본값은 30이며 **5–300초**를 지원합니다. 실제 완성본 길이를 기준으로 과금되지만 요청 길이를 초과하지 않습니다                                                                                                                                                                                      |
| `scenario`    | string   | 아니요   | 비디오 유형: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions`는 원본 비디오를 전달해야 하며, `avatar`는 인물 이미지를 전달해야 합니다                                                                                                                                             |
| `style`       | string   | 아니요   | 시각 스타일 프리셋: `auto`(기본값) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, 자유 텍스트도 소프트 힌트로 허용합니다. `scenario`와 직교하며 라우팅을 변경하지 않습니다          |
| `voice`       | string   | 아니요   | 내레이션 음색(언어와 무관하며 언어 간 공통): `auto`(기본값) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`; 32자리 16진수 음색 reference_id도 지원하며, 기타 자유 텍스트는 유효한 음색 ID가 아닙니다 |

아래에서 구체적인 예시를 통해 시연하겠습니다. 중국어, 세로 화면, 20초 길이의 과학 상식 숏폼 비디오를 생성한다고 가정하면, 해당 CURL 코드는 다음과 같습니다:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행을 클릭하면 다음과 같이 즉시 결과를 받을 수 있습니다:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

반환 결과의 필드 소개는 다음과 같습니다:
- `success`: Whether this task was submitted successfully.
- `task_id`: The ID of this video generation task, which is subsequently used to poll results through the [Maestro Task Query API](/ko/guides/maestro/maestro_tasks).
- `trace_id`: The tracking ID of this request, which can be provided to technical support for troubleshooting when issues occur.

Since video production takes a relatively long time, the API **immediately returns `task_id`** here and will not wait for video rendering to complete. Next, you need to use `task_id` to poll the results; see the "Get Results" section for details.

## Specify Video Type and Style (scenario / style)

When `scenario` is not provided, it is automatically determined by AI (equivalent to `auto`); if you want to lock the video to a certain type, explicitly provide it. For example, to create a **vertical short drama**, you can specify the following:

- `scenario`: Video type, set to `drama` here (a short drama with characters + dialogue).
- `style`: Visual style, set to `cinematic` here (a cinematic texture).

The CURL code for the example is as follows:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Common combinations:

- Narrated short video: `scenario: "narrated"`.
- Automatic subtitles: `scenario: "captions"`, requiring the source video to be passed through `file_urls`.
- Digital human / talking-head video: `scenario: "avatar"`, requiring a portrait image to be passed through `file_urls`.
- Short drama: `scenario: "drama"` (characters + dialogue).
- `style` is a visual style preset (such as `modern` / `neon` / `luxury`), which does not change the type and only affects the visual appearance.
- `voice` is used to specify the narration voice (such as `warm-female` / `deep-male`), which is language-independent and universal across languages.

The returned result is consistent with "Basic Usage", and `task_id` is also returned immediately.

## Final Video Language

A task delivers only one final video in one language. `langs` can contain only one language code, such as `["zh-cn"]` or `["en"]`; passing multiple languages will return 400. If you need videos in different languages, please create tasks separately. Language selection does not change the per-second price.

## Iterate on an Existing Video (remix / edit / extend)

Pass `action` and the `ref_task_id` of the previous task to make incremental modifications based on the original project (such as "change the title of Scene 2", "change the voice-over", or "make the overall video darker"). Minor changes are fast, while major changes will be redone:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: Reinterpret based on the original video structure (retain the theme while adjusting the presentation).
- `edit`: Fine-tune specified parts (such as changing titles, voice-overs, or color grading).
- `extend`: Extend content based on the original video.

The returned result likewise immediately provides a new `task_id`; use it for polling to obtain the iterated final video.

## Get Results

Since video production takes a relatively long time, this API immediately returns `task_id` after submission. You need to use it to poll results through the [Maestro Task Query API](/ko/guides/maestro/maestro_tasks):

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

When the task is complete, it returns a final video record (located in the `variants` array). `status` progresses through `pending → planning → producing → succeeded` (or `failed`), and **polling is free and does not consume credits**. For the complete response format and historical list queries, please refer to the [Maestro Task Query API Integration Guide](/ko/guides/maestro/maestro_tasks).

## Billing

**Billing is based on the actual duration of the delivered final video after the task succeeds; failed tasks are not charged.** The billable duration is calculated in whole seconds and does not exceed the requested duration; when the final video duration cannot be read, it falls back to the requested duration. Task submission itself is not billed separately, and `/maestro/tasks` polling is free.

```
Credits = Actual billable seconds × 0.7
```

All scenarios, actions, and languages use the same price, with no scenario multiplier or language surcharge. Each task delivers only one final video in one language. Requested target durations support 5–300 seconds, with unified output at 1080p / 30fps.

| Actual Billable Duration              | Credits |
| ------------------- | --: |
| 30 seconds                |  21 |
| 60 seconds                |  42 |
| 120 seconds               |  84 |
| 300 seconds               | 210 |
| `/maestro/tasks` polling | Free |

## Error Handling

When calling the API, if an error occurs, the API returns the corresponding error code and message. For example:

- `400 invalid_request`: Bad request, possibly due to a missing `prompt` or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `403 forbidden`: Forbidden, insufficient balance or access.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### Error Response Example

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
