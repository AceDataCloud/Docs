Maestro는 **Agent 네이티브** 비디오 제작 인터페이스입니다. 한 문장의 자연어 `prompt`로 원하는 비디오를 설명하고(선택적으로 `file_urls`를 사용해 참고 이미지 / 비디오 / 오디오를 첨부), 헤드리스 「AI 감독」이 주제 선정, 스크립트 작성, 화면 생성, 더빙, 배경 음악, 합성 및 렌더링을 자동으로 완료하며, 최종적으로 자막이 포함된 완성 영상을 생성하여 CDN에 업로드합니다.

이 문서에서는 Maestro 비디오 생성 API의 연동 안내를 자세히 소개하여, API를 빠르게 통합하고 그 기능을 충분히 활용할 수 있도록 도와드립니다.

이것은 **비동기 작업** 인터페이스입니다. 제출 후 즉시 `task_id`가 반환되며, 이후 [Maestro 작업 조회 API](/ko/guides/maestro/maestro_tasks)(`POST /maestro/tasks`)를 통해 결과를 폴링하여 가져옵니다(폴링은 무료이며 과금되지 않습니다). 기존 비디오에서 계속 반복 작업하려면 `ref_task_id`와 함께 `action: remix` / `edit` / `extend`를 사용할 수 있습니다.

## 신청 절차

Maestro 비디오 생성 API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 보관해 두세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인 또는 회원가입하지 않은 경우, 로그인 페이지로 자동 이동하여 회원가입 및 로그인을 안내하며, 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스별로 별도 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족한 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Maestro 비디오 생성 API →](https://platform.acedata.cloud/documents/maestro-videos)

## 기본 사용법

`POST https://api.acedata.cloud/maestro/videos`

가장 기본적인 사용법은 자연어 `prompt` 하나만 전달하면 되며, AI 감독이 스크립트, 화면, 더빙 및 편집을 자동으로 결정합니다. 여기서는 먼저 설정해야 하는 요청 헤더와 요청 본문을 살펴보겠습니다.

**Request Headers**에는 다음이 포함됩니다:

- `accept`: 수신하고자 하는 응답 결과의 형식으로, 여기서는 JSON 형식인 `application/json`을 입력합니다.
- `authorization`: API 호출 키이며, 신청 후 직접 드롭다운에서 선택할 수 있습니다.
- `content-type`: 요청 본문의 형식으로, 여기서는 `application/json`을 입력합니다.

**Request Body**에는 주로 다음이 포함됩니다:

- `prompt`: 만들 비디오를 자연어로 설명합니다(주제, 표시할 내용, 스타일, 대상).
- `langs`: 완성 영상의 언어 배열이며, 매번 하나의 언어만 전달합니다. 예: `["zh-cn"]`, 기본값은 `["zh-cn"]`입니다.
- `aspect`: 화면 비율, `9:16`(기본값) / `16:9` / `1:1`.
- `duration`: 목표 길이(초), 기본값은 30입니다.

요청 본문의 전체 필드는 아래 표와 같습니다:

| 필드            | 유형       | 필수  | 설명                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | 예   | 만들 비디오를 자연어로 설명합니다(주제, 표시할 내용, 스타일, 대상). 스크립트, 화면, 더빙, 편집은 모두 AI가 결정합니다                                                                                                                                                                             |
| `action`      | string   | 아니요   | `generate`(기본값, 새 비디오 생성) / `remix` / `edit` / `extend`(기존 비디오에서 반복 작업, `ref_task_id`와 함께 사용 필요)                                                                                                                                                |
| `ref_task_id` | string   | 아니요   | `action`이 remix / edit / extend인 경우 필수: 시작점으로 사용할 이전 작업 `task_id`                                                                                                                                                                   |
| `file_urls`   | string[] | 아니요   | 참고 미디어(이미지 / 비디오 / 오디오 URL). 예: 화면에 표시할 제품 이미지, logo 또는 자막을 추가할 소스 영상 클립                                                                                                                                                                             |
| `langs`       | string[] | 아니요   | 완성 영상 언어이며, 매번 하나의 언어만 전달할 수 있습니다. 예: `["zh-cn"]`, 기본값은 `["zh-cn"]`                                                                                                                                                                                    |
| `aspect`      | string   | 아니요   | `9:16`(기본값) / `16:9` / `1:1`, 출력은 모두 1080p/30fps                                                                                                                                                                                  |
| `duration`    | int      | 아니요   | 목표 길이(초), 기본값은 30이며 **5–300초**를 지원합니다. 실제 완성 영상 길이를 기준으로 과금되지만, 요청 길이를 초과하지 않습니다                                                                                                                                                                             |
| `scenario`    | string   | 아니요   | 비디오 유형: `auto` / `narrated` / `captions` / `avatar` / `drama`. `captions`는 원본 비디오를 전달해야 하며, `avatar`는 인물 이미지를 전달해야 합니다                                                                                                                                    |
| `style`       | string   | 아니요   | 시각 스타일 프리셋: `auto`(기본값) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, 자유 텍스트도 소프트 힌트로 허용됩니다. `scenario`와 직교하며 라우팅을 변경하지 않습니다 |
| `voice`       | string   | 아니요   | 내레이션 음색(언어와 무관하며, 언어 간 공통 사용 가능): `auto`(기본값) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`                                    |

아래에서는 구체적인 예시를 통해 시연합니다. 중국어, 세로 화면, 20초 길이의 과학 교양 숏폼 비디오를 생성한다고 가정하면, 해당 CURL 코드는 다음과 같습니다:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn"],
  "aspect": "9:16",
  "duration": 20
}'
```

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행을 클릭하면 다음과 같이 즉시 결과를 얻을 수 있습니다:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

반환 결과의 필드 소개는 다음과 같습니다:
- `success`：이번 작업이 성공적으로 제출되었는지 여부입니다.
- `task_id`：이번 비디오 생성 작업의 ID이며, 이후 이를 사용하여 [Maestro 작업 조회 API](/ko/guides/maestro/maestro_tasks)에서 결과를 폴링합니다.
- `trace_id`：이번 요청의 추적 ID이며, 문제가 발생했을 때 기술 지원팀에 제공하여 문제를 확인할 수 있습니다.

비디오 제작에는 비교적 긴 시간이 소요되므로, 인터페이스는 여기서 **즉시 `task_id`를 반환**하며 비디오 렌더링이 완료될 때까지 기다리지 않습니다. 다음으로 `task_id`를 사용해 결과를 폴링해야 하며, 자세한 내용은 「결과 가져오기」 섹션을 참조하세요.

## 비디오 유형 및 스타일 지정（scenario / style）

`scenario`를 전달하지 않으면 AI가 자동으로 판단합니다(`auto`와 동일). 비디오를 특정 유형으로 고정하려면 명시적으로 전달하세요. 예를 들어 **세로형 숏드라마**를 만들려면 다음 내용을 지정할 수 있습니다.

- `scenario`：비디오 유형이며, 여기서는 `drama`(캐릭터 + 대사가 있는 숏드라마)로 설정합니다.
- `style`：시각적 스타일이며, 여기서는 `cinematic`(영화 같은 질감)으로 설정합니다.

작성 예시의 CURL 코드는 다음과 같습니다.

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

일반적인 조합 방식:

- 해설 숏폼: `scenario: "narrated"`。
- 자동 자막: `scenario: "captions"`，`file_urls`를 사용하여 원본 비디오를 전달해야 합니다.
- 디지털 휴먼 / 말하기 영상: `scenario: "avatar"`，`file_urls`를 사용하여 인물 사진 한 장을 전달해야 합니다.
- 숏드라마: `scenario: "drama"`(캐릭터 + 대사)。
- `style`은 시각적 스타일 프리셋(예: `modern` / `neon` / `luxury`)이며, 유형은 변경하지 않고 시청각적 느낌에만 영향을 줍니다.
- `voice`는 내레이션 음색(예: `warm-female` / `deep-male`)을 지정하는 데 사용되며, 언어와 무관하고 여러 언어에서 공통으로 사용할 수 있습니다.

반환 결과는 「기본 사용」과 동일하며, 마찬가지로 즉시 `task_id`를 반환합니다.

## 완성본 언어

하나의 작업은 하나의 언어로 된 완성본 하나만 제공합니다. `langs`에는 `["zh-cn"]` 또는 `["en"]`처럼 하나의 언어 코드만 포함할 수 있으며, 여러 언어를 전달하면 400이 반환됩니다. 서로 다른 언어의 비디오가 필요한 경우 각각 별도로 작업을 생성하세요. 언어 선택은 초당 가격을 변경하지 않습니다.

## 기존 비디오에서 반복 작업（remix / edit / extend）

`action`과 이전 작업의 `ref_task_id`를 전달하면 원본 프로젝트를 기반으로 차이 수정(예: 「2막 제목 변경」「더빙 변경」「전체적으로 어둡게 조정」)을 수행할 수 있습니다. 작은 수정은 빠르게 처리되며, 큰 수정은 다시 제작됩니다.

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`：원본 비디오 구조를 기반으로 새롭게 연출합니다(주제는 유지하고 표현을 조정).
- `edit`：지정한 부분을 세부적으로 수정합니다(예: 제목 변경, 더빙 변경, 색보정).
- `extend`：원본 비디오를 기반으로 콘텐츠를 확장합니다.

반환 결과 역시 즉시 새 `task_id`를 반환하며, 이를 폴링하면 반복 작업 후의 완성본을 얻을 수 있습니다.

## 결과 가져오기

비디오 제작에는 비교적 긴 시간이 소요되므로, 이 인터페이스는 제출 후 즉시 `task_id`를 반환합니다. 이를 사용하여 [Maestro 작업 조회 API](/ko/guides/maestro/maestro_tasks)에서 결과를 폴링해야 합니다.

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

작업이 완료되면 완성본 정보 하나가 반환됩니다(`variants` 배열에 위치). `status`는 `pending → planning → producing → succeeded`(또는 `failed`)를 거치며, **폴링은 무료이고 크레딧을 소모하지 않습니다**. 전체 응답 형식 및 기록 목록 조회는 [Maestro 작업 조회 API 연동 안내](/ko/guides/maestro/maestro_tasks)를 참조하세요.

## 과금

**작업 성공 후 실제 제공된 완성본 길이를 기준으로 과금하며, 실패 시 과금되지 않습니다.** 과금 시간은 정수 초 단위로 계산되며 요청 시간보다 길지 않습니다. 완성본 길이를 읽을 수 없는 경우 요청 시간으로 대체됩니다. 작업 제출 자체에는 별도 과금되지 않으며, `/maestro/tasks` 폴링은 무료입니다.

```
크레딧 = 실제 과금 초 수 × 0.7
```

모든 시나리오, 작업 및 언어는 동일한 가격을 적용하며, 시나리오 배율이나 언어 추가 요금은 없습니다. 각 작업은 하나의 언어로 된 완성본 하나만 제공합니다. 요청 목표 길이는 5–300초를 지원하며, 통합적으로 1080p / 30fps로 출력됩니다.

| 실제 과금 시간              |  크레딧 |
| ------------------- | --: |
| 30초                |  21 |
| 60초                |  42 |
| 120초               |  84 |
| 300초               | 210 |
| `/maestro/tasks` 폴링 |  무료 |

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예:

- `400 invalid_request`：잘못된 요청이며, `prompt` 누락 또는 유효하지 않은 파라미터 때문일 수 있습니다.
- `401 invalid_token`：권한이 없으며, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `403 forbidden`：접근이 금지되었으며, 잔액 또는 접근 권한이 부족합니다.
- `429 too_many_requests`：요청이 너무 많으며, 속도 제한을 초과했습니다.
- `500 api_error`：내부 서버 오류이며, 서버에서 문제가 발생했습니다.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 결론

본 문서를 통해 Maestro 비디오 생성 API 사용 방법을 이해하셨습니다. 자연어 `prompt` 한 문장만으로 스크립트, 소스 자료, 더빙, 배경 음악, 편집, 자막 및 완성본 렌더링을 자동으로 완료할 수 있으며, 비디오 유형, 스타일, 음색, 완성본 언어 지정 및 기존 비디오 기반 반복 작업도 지원합니다. 본 문서가 해당 API를 더 효과적으로 연동하고 사용하는 데 도움이 되기를 바랍니다. 궁금한 점이 있으시면 언제든지 기술 지원팀에 문의해 주세요.
