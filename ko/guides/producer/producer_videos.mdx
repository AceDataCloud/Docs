title: "Producer 동영상 다운로드 API 연동 안내"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer를 사용하면 노래 관련 동영상을 다운로드할 수 있으며, 본 문서에서는 관련 API 연동 방법을 설명합니다.

이 API에는 하나의 입력 파라미터만 있으며, 그것은 곡의 고유 ID인 `audio_id`입니다.

여기에서 입력하는 `audio_id`는 `a54609c6-13e2-4176-be0f-4d7eebc68e1f`이며, Producer가 생성한 곡 ID입니다.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

결과는 다음과 같습니다:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4"
  }
}
```

확인할 수 있듯이, `data`의 `video_url` 필드가 다운로드할 동영상 링크입니다.
