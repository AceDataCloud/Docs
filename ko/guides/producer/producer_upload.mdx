---
title: "Producer 참조 오디오 업로드 API 연동 안내"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer를 사용하면 참조 오디오를 업로드하여 2차 창작을 진행할 수 있으며, 이 문서에서는 관련 API의 연동 방법을 설명합니다.

이 API에는 하나의 입력 파라미터만 있으며, 바로 `audio_url`입니다. 이는 공개적으로 접근 가능한 CDN 주소로, mp3 확장자를 지원합니다.

여기서 입력하는 `audio_url`은 `https://cdn.acedata.cloud/suno_demo.mp3`이며, 공개적으로 접근 가능한 CDN 주소입니다.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

결과는 다음과 같습니다:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

확인할 수 있듯이, `data`의 `audio_id` 필드가 업로드된 노래 ID입니다.

노래 ID를 얻은 후에는 [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration)를 사용하여 사용자 지정 노래 생성을 진행할 수 있습니다. 예를 들어 `action`에 `upload_extend`를 전달하고, 동시에 `audio_id`에 반환된 노래 ID를 전달하면 참조 오디오를 기반으로 새로운 노래를 생성할 수 있습니다.
