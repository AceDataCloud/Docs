title: "Qwen 이미지 생성 및 편집 API"

---

`POST https://api.acedata.cloud/qwen-image/images`를 통해 동일한 인터페이스로 문생图와 1–3장의 참고 이미지 편집을 완료하며, `qwen-image-3.0` 및 `qwen-image-3.0-pro`를 지원합니다.

## 모델 선택

| 모델                   | 적합한 장면       | 공식 표준 가격                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | 대량 창작, 빠른 반복  | 출력 $0.030/장             |
| `qwen-image-3.0-pro` | 복잡한 레이아웃, 고정밀 완성 | 1K $0.040/장; 2K $0.075/장 |

참고 이미지는 실제 입력 수량에 따라 요금이 부과되며, 공식 표준 가격은 $0.003/장입니다.

## 동기 생성

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "깨끗한 흰색 배경에 중앙에 위치한 간단한 빨간 원.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

성공적인 응답에는 영구 CDN 이미지 주소, 실제 사용량 및 이번 비용이 포함됩니다:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## 참고 이미지 편집

`image_urls`를 추가하여 1–3장의 공개 접근 가능한 이미지를 지원합니다:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "주제를 유지하고 배경을 따뜻한 **###** 포스터 스타일로 변경",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"
  ],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent`는 문생图에만 사용됩니다. `n`의 범위는 1–6이며, 가로 세로 비율은 1:8에서 8:1 사이여야 합니다.

## 비동기 작업

`async: true`로 설정하면 인터페이스가 즉시 `task_id`를 반환합니다. `/qwen-image/tasks`를 사용하여 최종 상태를 조회하거나 `callback_url`을 전달하여 완료 알림을 받을 수 있습니다. 생성은 한 번만 결제되며, 작업 조회는 중복 요금이 부과되지 않습니다.
