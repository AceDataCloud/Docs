---
title: "Qwen Image 이미지 API 통합 가이드"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images`는 `qwen-image-3.0` 및 `qwen-image-3.0-pro`의 문생화 및 1–3장의 참고 이미지 편집을 지원합니다.

## 문생화

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"극단적으로 간결한 기술 포스터","size":"1024*1024","n":1}'
```

## 이미지 편집

같은 요청에 `image_urls`를 추가하여 1–3장의 공개 이미지를 지원합니다:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "주제를 유지하고 따뜻한**###**포스터 스타일로 변경",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent`는 문생화에만 지원됩니다. `n`의 범위는 1–6입니다. 출력 크기의 총 픽셀은 512×512에서 2048×2048 사이여야 하며, 가로 세로 비율은 1:8에서 8:1 사이여야 합니다.

## 비동기 호출

`async: true`를 설정하면 즉시 `task_id`를 받을 수 있으며, `callback_url`을 전달하여 최종 결과를 받을 수 있습니다. 완료 후 `/qwen-image/tasks`를 통해 조회합니다.

성공적인 응답에는 `data[].image_url`, `usage`, `task_id` 및 `trace_id`가 포함됩니다. 이미지 링크는 가능한 한 Ace Data Cloud CDN에 저장됩니다. 실제 응답 샘플은 생산 E2E 검증 후 추가될 예정입니다.
