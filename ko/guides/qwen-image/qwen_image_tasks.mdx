`POST https://api.acedata.cloud/qwen-image/tasks` 는 Qwen Image 비동기 작업을 조회, 배치 조회 또는 삭제하는 데 사용됩니다. 이 인터페이스는 추가 API 소비를 발생시키지 않습니다.

## 단일 작업 조회

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

작업이 완료되면, `response.data` 에는 영구 CDN 이미지 주소가 포함되며, `response.usage` 에는 실제 입력/출력 수량이 포함되고, `response.cost` 는 생성 작업의 정산 정보입니다.

## 배치 조회

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

반환 값은 `{ "items": [...], "count": 2 }` 입니다. 목록 조회는 사용자, 애플리케이션 및 생성 시간 범위에 따라 필터링하는 것도 지원합니다.

## 작업 기록 삭제

```json
{"action":"delete","id":"TASK_ID"}
```

삭제는 작업 기록에만 영향을 미치며, 이미 생성된 CDN 파일은 삭제되지 않습니다.
