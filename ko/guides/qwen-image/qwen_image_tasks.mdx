---
title: "Qwen 이미지 작업 API 통합 가이드"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/tasks`를 사용하여 비동기 이미지 생성 작업을 조회합니다. 이 조회 인터페이스는 무료입니다.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

배치 조회는 `action=retrieve_batch`와 `ids` 배열을 사용합니다. 작업이 성공하면 `response.data`에 생성된 이미지의 영구 주소와 실제 사용량이 포함됩니다.
