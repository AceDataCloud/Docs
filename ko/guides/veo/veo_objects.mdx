본 문서는 Veo Objects API의 연동 설명을 소개합니다. 이 인터페이스는 이미 생성된 Veo 비디오에 대해 **물체 추가 또는 삭제** 작업(마스크 기반의 부분 재작성)을 수행하는 데 사용됩니다.

## 신청 절차

API를 사용하려면 먼저 Veo 서비스에 해당하는 페이지에서 신청해야 합니다. 로그인 또는 등록이 되어 있지 않은 경우 자동으로 로그인 페이지로 이동합니다.

## 기본 사용

이 인터페이스를 호출하려면 다음 매개변수를 전달해야 합니다:

- `video_id`(필수): 원본 비디오의 작업 ID. **안됨** `/veo/extend`의 출력 비디오.
- `action`(필수): 작업 유형, `insert` 또는 `remove`.
- `prompt`:
  - `action=insert`: **필수**, 추가할 물체에 대한 설명.
  - `action=remove`: 선택 사항, 제거할 내용에 대한 설명(주로 로그 기록에 사용되며, 실제 삭제 영역은 `image_mask`에 의해 결정됨).
- `image_mask`:
  - `action=insert`: 선택 사항. 전달하지 않으면 AI가 자동으로 삽입 위치를 결정합니다. 전달하면 흰색 픽셀 영역에 삽입됩니다.
  - `action=remove`: **필수**, 흰색 픽셀 영역은 삭제할 객체입니다.

`image_mask`는 두 가지 형식을 지원합니다:

1. **공개 접근 가능한 HTTP(S) 이미지 주소**(추천).
2. **base64 인코딩된 JPEG 문자열**, `data:image/jpeg;base64,` 접두사를 포함할 수 있으며, 순수 base64일 수도 있습니다.

요청 예시(물체 삽입, 마스크를 전달하지 않고 AI가 자동으로 위치 지정):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

요청 예시(마스크에 따라 물체 제거):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

반환 결과 구조는 `/veo/videos`와 동일합니다.

## 요금 설명

- `action=insert` 또는 `remove`: 1.50 Credit / 회.

## 비동기 콜백

인터페이스는 비동기 모드를 지원하며, `callback_url`을 전달하면 작업 완료 후 POST 요청으로 결과를 콜백합니다. 공용 콜백 주소가 없는 경우 `async`를 `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하며, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 가져올 수 있습니다.
