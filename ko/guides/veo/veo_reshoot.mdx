본 문서는 Veo Reshoot API의 대조 설명을 소개합니다. 이 인터페이스는 이미 생성된 Veo 비디오를 **새로운 촬영 방식으로 재생성**하는 데 사용되며, 화면 내용은 동일하지만 촬영 위치와 움직임은 `motion_type`에 따라 새롭게 연출됩니다.

## 신청 절차

API를 사용하려면 먼저 Veo 서비스에 해당하는 페이지에서 신청해야 합니다. 로그인이나 등록이 되어 있지 않으면 자동으로 로그인 페이지로 이동합니다.

## 기본 사용

이 인터페이스를 호출하려면 다음 매개변수를 전달해야 합니다:

- `video_id`(필수): 원본 비디오의 작업 ID. **/veo/extend**의 출력 비디오일 수 없습니다.
- `motion_type`(필수): 새로운 촬영 방식, 대문자 언더스코어 스타일의 간결한 별명을 사용합니다.

### `motion_type` 지원 값

| 별명                             | 의미           |
| ------------------------------ | ------------ |
| `STATIONARY`                   | 카메라 고정       |
| `STATIONARY_UP`                | 카메라 고정, 위로 기울임    |
| `STATIONARY_DOWN`              | 카메라 고정, 아래로 기울임    |
| `STATIONARY_LEFT`              | 카메라 고정, 왼쪽으로 흔듦      |
| `STATIONARY_RIGHT`             | 카메라 고정, 오른쪽으로 흔듦      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | 카메라 고정, 앞으로 밀기 + 줌 아웃 |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | 카메라 고정, 뒤로 물러서기 + 줌 인 |
| `UP`                           | 카메라 상승         |
| `DOWN`                         | 카메라 하강         |
| `LEFT_TO_RIGHT`                | 카메라 왼쪽에서 오른쪽으로 이동     |
| `RIGHT_TO_LEFT`                | 카메라 오른쪽에서 왼쪽으로 이동     |
| `FORWARD`                      | 카메라 앞으로 나아감       |
| `BACKWARD`                     | 카메라 뒤로 물러남        |
| `DOLLY_IN_ZOOM_OUT`            | 이동 중 앞으로 밀기 + 줌 아웃   |
| `DOLLY_OUT_ZOOM_IN`            | 이동 중 뒤로 물러서기 + 줌 인   |

요청 예시:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

반환 결과 구조는 `/veo/videos`와 동일합니다.

## 비동기 콜백

인터페이스는 비동기 모드를 지원하며, `callback_url`을 전달하면 작업 완료 후 POST 요청으로 결과를 콜백합니다. 공용 콜백 주소가 없으면 `async`를 `true`로 설정할 수 있으며, 인터페이스는 즉시 `task_id`를 반환하고, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 얻을 수 있습니다.
