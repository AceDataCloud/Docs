본문에서는 Veo Videos Generation API 연동 안내를 소개합니다. 이는 사용자 정의 파라미터를 입력하여 Veo 공식 비디오를 생성할 수 있습니다.

## 신청 절차

Veo Videos Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않은 경우 로그인 페이지로 자동 이동하여 등록 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스별로 별도 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Veo Videos Generation API →](https://platform.acedata.cloud/documents/veo-videos)

## 기본 사용

먼저 기본 사용 방식을 살펴보겠습니다. 즉, 프롬프트 `prompt`, 생성 동작 `action`, 첫·마지막 프레임 참조 이미지 배열 `image_urls` 및 모델 `model`을 입력하면 처리된 결과를 얻을 수 있습니다. 먼저 간단히 `action` 필드를 전달해야 하며, 그 값은 `text2video`입니다. 여기에는 주로 세 가지 동작이 포함됩니다: 텍스트-비디오(`text2video`), 이미지-비디오(`image2video`), 1080p 비디오 가져오기(`get1080p`). 그리고 모델 `model`도 입력해야 합니다. 현재 주로 `veo31-fast`, `veo3`, `veo31`, `veo3-fast`, `veo31-fast-ingredients` 모델이 있으며, 구체적인 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/vv5pe8.png" width="500" className="m-auto" /></p>

여기에서 Request Headers를 설정한 것을 확인할 수 있으며, 다음을 포함합니다:

- `accept`: 어떤 형식의 응답 결과를 받을지 지정합니다. 여기서는 JSON 형식인 `application/json`으로 작성합니다.
- `authorization`: API를 호출하는 키이며, 신청 후 직접 드롭다운에서 선택할 수 있습니다.

또한 Request Body를 설정하며, 다음을 포함합니다:

- `model`: 비디오 생성 모델로, 주로 `veo31-fast`, `veo3`, `veo31`, `veo3-fast`, `veo31-fast-ingredients` 모델이 있습니다.
- `action`: 이번 비디오 생성 작업의 동작으로, 주로 세 가지 동작을 포함합니다: 텍스트-비디오(`text2video`), 이미지-비디오(`image2video`), 1080p 비디오 가져오기(`get1080p`).
- `image_urls`: 이미지-비디오 동작 `image2video`를 선택한 경우 반드시 업로드해야 하는 참조 이미지 링크입니다. `veo31-fast-ingredients`는 최대 3장(다중 이미지 융합), 나머지 모델은 최대 2장(첫·마지막 프레임 모드)입니다.
- `resolution`: 생성할 비디오 해상도를 선택합니다. 이 중 veo31 모델은 4k 해상도를 지원하며, 다른 모델은 지원하지 않습니다. 모든 모델은 1080p 및 gif 해상도를 지원하고, 이 값을 전달하지 않으면 기본적으로 720p 해상도를 사용합니다. 주로 `1080p`, `gif`, `4k`로 구분됩니다.
- `prompt`: 프롬프트.
- `callback_url`: 결과를 콜백받을 URL입니다.
- `async`: 선택 사항이며, `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환합니다. `callback_url`을 제공할 필요가 없으며, 이후 해당 작업 조회 인터페이스를 통해 폴링하여 결과를 가져옵니다.

| **veo31**                  | 텍스트-비디오(이미지 없음)<br />이미지-비디오 모드(이미지 있음)           | **1장** → 첫 프레임 모드<br />**2장** → 첫·마지막 프레임 모드 |

### 🔑 주요 규칙 설명

1. **공통 로직**:
   - **이미지 입력 없음** → 자동으로 텍스트-비디오 모드가 실행됩니다.
   - **이미지 입력 있음** → 이미지-비디오 모드가 실행됩니다(구체적인 동작은 이미지 수에 따라 결정됨).
2. **이미지-비디오 모드 유형**:
   - **첫 프레임 모드**(이미지 1장): 첫 프레임이 입력 이미지로 고정됩니다.
   - **첫·마지막 프레임 모드**(이미지 2장): 첫 프레임과 마지막 프레임이 입력 이미지로 고정됩니다.
   - **다중 이미지 융합 모드**(이미지 1-3장): `veo31-fast-ingredients`만 지원하며, 여러 이미지의 내용을 융합하여 비디오를 생성합니다.
3. **모드 분류**:

  - **Fast 모드**: `veo3-fast`, `veo31-fast`, `veo31-fast-ingredients`.
   - **Quality 모드**: `veo3`, `veo31`(생성 품질이 더 높음).

---

### ⚠️ 주의 사항

- **유일하게 이미지 전달이 필수인 모델**: `veo31-fast-ingredients`는 반드시 이미지(1-3장)를 전달해야 하며, 그렇지 않으면 실행할 수 없습니다.
- **이미지 수 제한**:
  - `veo31-fast-ingredients`는 **1-3장** 이미지 입력을 지원합니다(다중 이미지 융합 모드).
  - 다른 모델은 최대 **2장** 이미지 입력을 지원합니다(첫·마지막 프레임 모드).


## 이미지로 동영상 생성 기능

시작 및 종료 프레임 이미지를 기반으로 동영상을 생성하려면 매개변수 `action`을 `image2video`로 설정하고, 시작 및 종료 프레임 이미지 링크 배열 `image_urls`를 입력할 수 있습니다.

다음으로 사용자 지정 동영상 생성을 위해 확장해야 하는 프롬프트를 반드시 입력해야 하며, 다음 내용을 지정할 수 있습니다:

- `model`: 동영상을 생성하는 모델로, 주로 `veo31-fast`, `veo3`, `veo31`, `veo3-fast`, `veo31-fast-ingredients`가 있습니다.
- `image_urls`: 이미지로 동영상 생성 동작 `image2video`를 선택한 경우 반드시 업로드해야 하는 참조 이미지 링크입니다.
- `prompt`: 프롬프트입니다.

입력 예시는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/8wvlqd.png" width="500" className="m-auto" /></p>

입력을 완료하면 다음과 같이 코드가 자동으로 생성됩니다:

<p><img src="https://cdn.acedata.cloud/tgzfxi.png" width="500" className="m-auto" /></p>

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/veo/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "image2video",
    "model": "veo31-fast",
    "prompt": "Let it dance",
    "image_urls": ["https://cdn.acedata.cloud/7p1jhy.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행을 클릭하면 다음과 같은 결과를 얻을 수 있습니다:

결과 내용이 위의 내용과 일치하는 것을 확인할 수 있으며, 이로써 동영상의 이미지로 동영상 생성 기능이 구현됩니다.

## 지정된 동영상 크기 생성

사용자 지정 크기의 Veo 동영상을 지정하여 생성하려면 매개변수 `aspect_ratio`를 원하는 크기로 설정할 수 있습니다. 다음으로 사용자 지정 동영상 생성을 위해 확장해야 하는 프롬프트를 반드시 입력해야 하며, 다음 내용을 지정할 수 있습니다:

- `model`: 동영상을 생성하는 모델로, 주로 `veo31-fast`, `veo3`, `veo31`, `veo3-fast`, `veo31-fast-ingredients`가 있습니다.
- `aspect_ratio`: 동영상의 크기이며, 현재 `16:9`, `16:9`, `3:4`, `4:3`, `1:1`을 지원하고, 기본값은 `16:9`입니다.
- `translation`: 프롬프트의 자동 번역을 활성화할지 여부이며, 기본값은 `false`입니다.

## 비동기 콜백

Veo Videos Generation API의 생성 시간은 비교적 길며, 약 1~2분이 필요합니다. API가 장시간 응답하지 않으면 HTTP 요청은 계속 연결 상태를 유지하게 되어 추가적인 시스템 리소스가 소모됩니다. 따라서 본 API는 비동기 콜백도 지원합니다.

전체 프로세스는 다음과 같습니다. 클라이언트가 요청을 시작할 때 `callback_url` 필드를 추가로 지정합니다. 클라이언트가 API 요청을 시작한 후, API는 즉시 현재 작업 ID를 나타내는 `task_id` 필드 정보를 포함한 결과를 반환합니다. 작업이 완료된 후 생성된 비디오의 결과는 POST JSON 형식으로 클라이언트가 지정한 `callback_url`로 전송되며, 그 안에도 `task_id` 필드가 포함됩니다. 이렇게 작업 결과를 ID를 통해 연결할 수 있습니다.

아래에서는 예제를 통해 구체적으로 어떻게 작업하는지 알아보겠습니다.

먼저, Webhook 콜백은 HTTP 요청을 수신할 수 있는 서비스이며, 개발자는 이를 직접 구축한 HTTP 서버의 URL로 교체해야 합니다. 여기서는 시연의 편의를 위해 공개 Webhook 샘플 웹사이트 https://webhook.site/를 사용합니다. 해당 웹사이트를 열면 그림과 같이 Webhook URL을 얻을 수 있습니다.

![](https://cdn.acedata.cloud/tbcnai.png)

이 URL을 복사하면 Webhook으로 사용할 수 있으며, 여기의 예시는 `https://webhook.site/aed5cd28-f8aa-4dca-9480-8ec9b42137dc`입니다.

다음으로, 필드 `callback_url`을 위의 Webhook URL로 설정하고 해당 매개변수를 입력할 수 있습니다. 구체적인 내용은 그림과 같습니다.

<p><img src="https://cdn.acedata.cloud/rgivs2.png" width="500" className="m-auto" /></p>

실행을 클릭하면 즉시 다음과 같은 결과를 얻을 수 있습니다.

```json
{
  "task_id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed"
}
```

잠시 기다리면 `https://webhook.site/aed5cd28-f8aa-4dca-9480-8ec9b42137dc`에서 그림과 같이 생성된 비디오의 결과를 확인할 수 있습니다.

![](https://cdn.acedata.cloud/238i32.png)

내용은 다음과 같습니다.

```json
{
  "success": true,
  "task_id": "1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed",
  "trace_id": "d1d53c04-58c5-4c40-bb63-f00188540e56",
  "data": [
    {
      "id": "2f43ceed37944b4d836e1a1899dad0a1",
      "video_url": "https://platform.cdn.acedata.cloud/veo/1ebe4f2b-59ba-4385-a4ea-0ce8a3fe12ed.mp4",
      "created_at": "2025-07-25 17:19:20",
      "complete_at": "2025-07-25 17:21:45",
      "state": "succeeded"
    }
  ]
}
```

결과에 `task_id` 필드가 있으며, 다른 필드는 위와 유사합니다. 이 필드를 통해 작업을 연결할 수 있습니다.

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면 다음과 같습니다.

- `400 token_mismatched`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `401 invalid_token`: 인증되지 않음, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`: 요청이 너무 많습니다. 요청 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류, 서버에서 문제가 발생했습니다.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
