본 문서는 Veo Upsample API의 대조 설명을 소개합니다. 이 인터페이스는 이미 생성된 Veo 비디오를 업샘플링하거나 GIF 미리보기를 출력하는 데 사용됩니다.

## 신청 절차

API를 사용하려면 먼저 Veo 서비스에 해당하는 페이지에서 신청해야 합니다. 로그인 또는 등록하지 않은 경우 자동으로 로그인 페이지로 이동합니다.

## 기본 사용

이 인터페이스를 호출하려면 두 개의 매개변수를 전달해야 합니다:

- `video_id`：원본 비디오의 작업 ID. `/veo/videos`、`/veo/extend`、`/veo/reshoot`、`/veo/objects`의 임의의 인터페이스에서 생성된 비디오 ID일 수 있습니다.
- `action`：업샘플링 동작으로, 다음 세 가지를 지원합니다:
  - `1080p`：비디오를 1080p 해상도로 업샘플링합니다.
  - `4k`：비디오를 4K 해상도로 업샘플링합니다.
  - `gif`：비디오를 GIF 미리보기로 변환합니다.

요청 예시:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

반환 결과는 `/veo/videos`와 동일하며, 여전히 비동기 작업 구조입니다. `task_id`를 통해 `/veo/tasks` 인터페이스에서 작업 상태를 조회할 수 있습니다:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

반환 필드 설명:

- `success`：업샘플링 작업이 성공적으로 제출되었는지 여부.
- `task_id`：이번 업샘플링 작업의 ID.
- `data`：업샘플링 후의 비디오 결과.
  - `video_url`：업샘플링 후의 비디오 주소.

## 요금 설명

- `action=1080p`：0.16 Credit / 회
- `action=4k`：0.50 Credit / 회
- `action=gif`：0.13 Credit / 회

전달된 `action`이 위의 열거형에 포함되지 않으면 기본적으로 0.50 Credit으로 청구됩니다. 지원되는 값을 명시적으로 전달하는 것이 좋습니다.

## 비동기 콜백

인터페이스는 비동기 모드도 지원하며, `callback_url`을 전달하면 작업 완료 후 POST 요청으로 결과를 콜백합니다. 공용 콜백 주소가 없는 경우 `async`를 `true`로 설정하면 인터페이스는 즉시 `task_id`를 반환하며, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 얻을 수 있습니다.
