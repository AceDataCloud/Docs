본 문서는 Veo Extend API의 대조 설명을 소개합니다. 이 인터페이스는 이미 생성된 Veo 비디오의 **길이 연장**을 위해 사용되며, AI가 자동으로 후속 장면을 이어서 작성합니다.

## 신청 절차

API를 사용하려면 먼저 Veo 서비스의 해당 페이지에서 신청해야 합니다. 로그인 또는 등록이 되어 있지 않으면 자동으로 로그인 페이지로 이동합니다.

## 기본 사용

이 인터페이스를 호출하려면 다음 매개변수를 전달해야 합니다:

- `video_id`（필수）：원본 비디오의 작업 ID（`/veo/videos` 또는 이 인터페이스 자체에서 가져옴）。
- `model`（필수）：연장에 사용할 모델, **오직 `veo31-fast`와 `veo31` 두 모델만 지원**하며, 다른 모델은 지원하지 않습니다.
- `prompt`（선택적）：연장 구간 장면을 안내하는 텍스트 힌트.
- `aspect_ratio`（선택적）：`16:9` 또는 `9:16`, 기본값은 `16:9`입니다.
- `resolution`（선택적）：`720p` 또는 `1080p`입니다.

요청 예시:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "the camera slowly zooms out to reveal more of the landscape"
  }'
```

반환 결과는 `/veo/videos`와 동일합니다:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## 중요한 제한 사항

`video_id`는 현재 `/veo/videos` 라인에서 생성되거나 연장이 완료된 후의 `data[].id`에서 가져와야 합니다. 더 이전의 역사 라인에서 생성된 비디오 ID는 이 인터페이스에서 사용할 수 없으며, 호출 시 `400 bad_request`가 반환됩니다; `/veo/videos`를 통해 다시 생성한 후 연장해야 합니다.

`/veo/extend`에서의 연장 결과 비디오는 **다시 `/veo/extend`로 연장할 수 있지만**, 다음 인터페이스로는 처리할 수 없습니다:

- `/veo/reshoot` —— 카메라 움직임을 변경할 수 없음
- `/veo/objects` —— 물체 추가 및 삭제를 할 수 없음

전달된 `video_id`가 연장 결과인 경우, 관련 인터페이스는 400 오류를 반환하며, 원본 비디오를 소스로 사용해야 합니다.

## 요금 설명

- `model=veo31-fast`：1.68 Credit / 회
- `model=veo31`：12.00 Credit / 회

## 비동기 콜백

인터페이스는 비동기 모드를 지원하며, `callback_url`을 전달하면 작업 완료 후 POST 요청으로 결과를 콜백합니다. 공용 콜백 주소가 없으면 `async`를 `true`로 설정하여 인터페이스가 즉시 `task_id`를 반환하고, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 얻을 수 있습니다.
