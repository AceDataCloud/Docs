본 문서에서는 사용자 지정 파라미터를 입력하여 SeeDream 공식 이미지를 생성할 수 있는 SeeDream Images Generation API 연동 방법을 소개합니다.

## 신청 절차

SeeDream Images Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않았다면 로그인 페이지로 자동 이동하여 등록 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## 기본 사용법

먼저 기본 사용 방식을 알아보겠습니다. 즉, 프롬프트 `prompt`, 생성 동작 `action`, 이미지 크기 `size`를 입력하면 처리된 결과를 얻을 수 있습니다. 먼저 `action` 필드를 간단히 전달해야 하며, 그 값은 `generate`입니다. 그런 다음 프롬프트도 입력해야 합니다. 구체적인 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

여기서 다음을 포함하는 Request Headers를 설정한 것을 확인할 수 있습니다:

- `accept`: 어떤 형식의 응답 결과를 받을지 지정하며, 여기서는 JSON 형식인 `application/json`으로 입력합니다.
- `authorization`: API 호출 키이며, 신청 후 드롭다운에서 직접 선택할 수 있습니다.

또한 다음을 포함하는 Request Body를 설정했습니다:

- `prompt`: 프롬프트.
- `model`: 생성 모델이며, 기본값은 `doubao-seedream-5-0-lite-260128`(SeeDream 5.0 Lite, 최신)입니다. `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`를 지원합니다. 이 중 `doubao-seedream-5-0-pro-260628`(SeeDream 5.0 Pro)는 플래그십 단일 이미지 모델로, 단일 이미지만 생성하며 **이미지 그룹(`sequential_image_generation`), 스트리밍(`stream`) 및 웹 검색(`tools`)을 지원하지 않습니다.** **`model`에는 반드시 전체 모델 문자열(예: `doubao-seedream-5-0-lite-260128`)을 전달해야 하며, `doubao-seedream-5.0-lite`와 같은 약식 표기를 전달하면 400이 반환됩니다.**
- `image`: 입력 이미지 정보이며, URL 또는 Base64 인코딩을 지원합니다. `doubao-seedream-5-0-pro-260628`는 단일 또는 다중 이미지 입력(최대 10장)을 지원하며, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`는 단일 또는 다중 이미지 입력을 지원합니다.
- `size`: 생성 이미지의 크기 정보를 지정하며, 다음 두 가지 방식을 지원하고 혼용할 수 없습니다. 방식 1 | 생성 이미지의 해상도를 지정하고 prompt에서 자연어로 이미지 종횡비를 설명합니다. **각 모델이 지원하는 프리셋은 다릅니다**: `doubao-seedream-5-0-pro-260628`는 `1K`/`1.5K`/`2K`를 지원하고, `doubao-seedream-5-0-lite-260128`는 `2K`/`3K`/`4K`를 지원하며, `doubao-seedream-4-5-251128`는 `2K`/`4K`만 지원하고, `doubao-seedream-4-0-250828`는 `1K`/`2K`/`4K`를 지원합니다. 방식 2 | 생성 이미지의 가로세로 픽셀 값을 지정합니다: 기본값은 `2048x2048`이며, 총 픽셀 수 및 종횡비 값 범위는 모델마다 다릅니다(예: 5.0 Pro의 총 픽셀 범위는 [921600, 4624220], 5.0 Lite / 4.5의 총 픽셀 하한은 3,686,400, 4.0의 하한은 921,600).
- `sequential_image_generation`: 이미지 그룹: 입력한 내용을 기반으로 내용이 연관된 이미지 그룹을 생성합니다. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`는 이 파라미터를 지원하며, 기본값은 `disabled`입니다.
- `stream`: 스트리밍 출력 모드 활성화 여부를 제어합니다. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`는 이 파라미터를 지원하며, 기본값은 `false`입니다.
- `response_format`: 생성 이미지의 반환 형식을 지정합니다. 기본값은 `url`이며, `b64_json`도 지원합니다.
- `watermark`: 생성된 이미지에 워터마크를 추가할지 여부입니다. 기본값은 `true`입니다.
- `output_format`: 생성 이미지의 파일 형식을 지정하며, `jpeg`(기본값) 및 `png`를 지원합니다. `doubao-seedream-5-0-pro-260628`와 `doubao-seedream-5-0-lite-260128`만 지원합니다.
- `tools`: 모델이 호출할 도구를 구성하며, 현재 `web_search`(웹 검색)를 지원합니다. Seedream 5.0 Lite만 지원합니다.
- `optimize_prompt_options`: 프롬프트 최적화 구성입니다. 5.0 Pro는 `standard`/`fast`를 지원하고, 5.0 Lite 및 4.5는 `standard`만 지원하며, 4.0은 `standard`/`fast`를 지원합니다.
- `background`: 5.0 Pro 단일 이미지 편집만 지원합니다. `transparent`는 투명 채널이 있는 PNG 한 장을 입력해야 하며, `output_format`은 반드시 `png`여야 합니다. `opaque`는 일반 불투명 배경입니다.
- `layer_decomposition`: 5.0 Pro만 지원합니다. `true`로 설정하면 PNG/JPEG 한 장을 반드시 입력해야 하며, `prompt`를 전달하지 않아 자동 분할하거나 자연어/`<bbox>`로 요소를 지정할 수 있습니다. `size`는 `auto`/`1K`/`1.5K`/`2K`를 지원합니다. 이 모드는 이미지 그룹, 스트리밍, 웹 검색 또는 `background`와 함께 사용할 수 없습니다.
- `callback_url`: 결과 콜백이 필요한 URL입니다.
- `async`: 비동기 모드로 처리할지 여부입니다. `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하며, `callback_url`을 제공할 필요가 없고 이후 `/seedream/tasks`를 통해 폴링하여 결과를 가져옵니다.

선택 후 오른쪽에도 해당 코드가 생성된 것을 확인할 수 있습니다. 다음 그림과 같습니다:

반환 결과에는 총 여러 필드가 있으며, 소개는 다음과 같습니다:

- `success`, 이때 비디오 생성 작업의 상태입니다.
- `task_id`, 이때 비디오 생성 작업 ID입니다.
- `trace_id`, 이때 비디오 생성 추적 ID입니다.
- `data`, 이때 이미지 생성 작업의 결과 목록입니다.
  - `image_url`, 이때 이미지 생성 작업의 링크입니다.
  - `prompt`, 프롬프트입니다.
  - `size`: 생성된 이미지의 픽셀

만족스러운 이미지 정보를 얻은 것을 확인할 수 있으며, 결과의 `data`에 있는 이미지 링크 주소를 통해 생성된 SeeDream 이미지를 가져오기만 하면 됩니다.

또한 해당 연동 코드를 생성하고 싶다면 직접 복사하여 생성할 수 있습니다. 예를 들어 CURL 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## 이미지 편집 작업

특정 이미지를 편집하려면 먼저 매개변수 `image`에 편집이 필요한 이미지 링크를 반드시 전달해야 합니다.

- model: 이번 이미지 편집 작업에 사용되는 모델이며, `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` 모두 이미지 입력을 지원합니다.
- image: 편집이 필요한 이미지를 업로드하며, 한 장 또는 여러 장일 수 있습니다.

작성 예시는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

해당 코드:

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행을 클릭하면 즉시 다음과 같은 결과를 얻을 수 있습니다:

```json
  "data": [
    {
      "prompt": "Keep the model pose and the liquid garment flowing shape unchanged. Change the clothing material from silver metal to completely transparent water (or glass). Through the liquid flow, the details of the model skin are visible. The light and shadow effect shifts from reflection to refraction.",
      "size": "2048x2048",
```

생성된 효과가 원본 이미지를 편집한 효과임을 확인할 수 있으며, 결과는 위와 유사합니다.

## 레이어 분리(Seedream 5.0 Pro)

레이어 분리는 하나의 입력 이미지를 1장의 배경 이미지와 최대 16개의 독립적으로 편집 가능한 투명 PNG 레이어로 분리합니다. 아래 요청은 모델이 주요 요소를 자동으로 인식하도록 합니다. 요소를 지정해야 하는 경우 `prompt`를 추가할 수 있으며, 프롬프트에서 정규화된 `<bbox>` 좌표를 사용할 수도 있습니다.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

반환되는 `data`는 `z_index`에 따라 아래에서 위 순으로 정렬됩니다. 배경 이미지의 `z_index`는 0이며, 레이어에는 `name`, `description`, `bounding_box.absolute`/`normalized`도 포함됩니다. 절대 좌표를 사용하여 재구성할 때는 레이어를 `[right-left, bottom-top]`으로 크기 조정하고 `[left, top]`에 배치한 다음, `z_index` 오름차순으로 겹칩니다. 어느 한 레이어라도 생성에 실패하면 전체 분리가 실패합니다.

## 스트리밍 출력

Lite/4.x에서 `stream: true`를 설정할 때 요청 헤더는 `accept: application/x-ndjson`를 사용합니다. 인터페이스는 줄 단위로 `image_generation.partial_succeeded` 또는 `image_generation.partial_failed`를 반환하며, 마지막으로 유일한 `image_generation.completed` 이벤트 및 최종 `usage`를 반환합니다. 완료 이벤트가 한 번 발생할 때만 과금됩니다. 스트리밍 모드는 `async` 또는 `callback_url`과 함께 사용할 수 없습니다.

## 비동기 콜백

SeeDream Images Generation API의 생성 시간은 비교적 길며, 약 1~2분이 소요됩니다. API가 장시간 응답하지 않으면 HTTP 요청이 계속 연결을 유지하여 추가 시스템 리소스가 소모되므로, 본 API는 비동기 콜백도 지원합니다.

전체 흐름은 다음과 같습니다. 클라이언트가 요청을 시작할 때 추가로 `callback_url` 필드를 지정합니다. 클라이언트가 API 요청을 시작한 후 API는 즉시 결과를 반환하며, 여기에는 현재 작업 ID를 나타내는 `task_id` 필드 정보가 포함됩니다. 작업이 완료된 후 생성 이미지의 결과는 POST JSON 형식으로 클라이언트가 지정한 `callback_url`로 전송되며, 여기에도 `task_id` 필드가 포함되므로 작업 결과를 ID로 연결할 수 있습니다.

콜백을 받을 수 있는 공용 주소가 없다면 `callback_url`을 지정하지 않고 요청에서 `async` 필드를 `true`로 설정할 수도 있습니다. 이때 인터페이스도 즉시 `task_id`를 반환하지만 결과를 푸시하지 않으므로, 해당 `task_id`를 가지고 `/seedream/tasks` 인터페이스를 호출하여 작업 상태를 폴링하고 최종 결과를 가져와야 합니다.

아래에서 예시를 통해 구체적으로 어떻게 조작하는지 알아보겠습니다.

실행을 클릭하면 즉시 다음과 같은 결과를 얻을 수 있습니다:

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

내용은 다음과 같습니다:
```json
{
    "success": true,
    "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde",
    "trace_id": "131a40c3-2eaf-44c9-af28-c9b408577286",
    "data": [
        {
            "prompt": "모델의 포즈와 액체 의상의 흐르는 형태를 변경하지 마세요. 의상 소재를 은색 금속에서 완전히 투명한 물(또는 유리)로 변경하세요. 액체의 흐름을 통해 모델 피부의 디테일이 보입니다. 빛과 그림자 효과는 반사에서 굴절로 전환됩니다.",
            "size": "2048x2048",
            "image_url": "https://platform.cdn.acedata.cloud/seedream/3e88db7e-4771-4f6a-adbd-5ae4590c5d59.jpg"
        }
    ]
}
```

결과에서 `task_id` 필드를 확인할 수 있으며, 다른 필드는 위와 유사합니다. 이 필드를 통해 작업을 연결할 수 있습니다.

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면 다음과 같습니다:

- `400 token_mismatched`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `401 invalid_token`: 인증되지 않음, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`: 요청이 너무 많습니다. 속도 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류, 서버에서 문제가 발생했습니다.

```json
}
```
