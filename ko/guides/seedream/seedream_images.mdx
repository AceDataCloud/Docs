본 문서에서는 SeeDream 이미지 생성 API 연동 방법을 소개합니다. 이 API는 사용자 정의 매개변수를 입력하여 SeeDream 공식 이미지를 생성할 수 있습니다.

## 신청 절차

SeeDream 이미지 생성 API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API 토큰을 받아야 합니다. 이를 보관해 두세요.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

로그인 또는 등록이 되어 있지 않으면 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 요청합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API 토큰으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스별로 별도로 신청할 필요가 없습니다.** 처음 신청 시 무료 할당량이 제공되어 무료로 체험할 수 있습니다. 할당량이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [SeeDream 이미지 생성 API →](https://platform.acedata.cloud/documents/seedream-images)

## 기본 사용법

먼저 기본 사용 방법을 이해해야 합니다. 즉, 프롬프트 `prompt`, 생성 동작 `action`, 이미지 크기 `size`를 입력하면 처리된 결과를 얻을 수 있습니다. 먼저 간단히 `action` 필드를 전달해야 하며, 그 값은 `generate`입니다. 그런 다음 프롬프트를 입력해야 하며, 구체적인 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

여기에서 요청 헤더를 설정한 것을 볼 수 있습니다. 포함된 내용은 다음과 같습니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지, 여기서는 `application/json` 즉 JSON 형식으로 작성합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 바로 드롭다운에서 선택할 수 있습니다.

또한 요청 본문을 설정했습니다. 포함된 내용은 다음과 같습니다:

- `prompt`: 프롬프트.
- `model`: 생성 모델, 기본값은 `doubao-seedream-5-0-260128` (SeeDream 5.0 Lite, 최신). 지원되는 모델은 `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`입니다. 그 중 `doubao-seedream-5-0-pro-260628` (SeeDream 5.0 Pro)는 플래그십 단일 이미지 모델로, 단일 이미지만 생성하며 **그룹 이미지(`sequential_image_generation`), 스트리밍(`stream`), 네트워크 검색(`tools`)을 지원하지 않습니다.** **`model`은 전체 모델 문자열(예: `doubao-seedream-5-0-260128`)을 전달해야 하며, `doubao-seedream-5.0-lite`와 같은 약어를 전달하면 400 오류가 발생합니다.**
- `image`: 입력 이미지 정보로, URL 또는 Base64 인코딩을 지원합니다. `doubao-seedream-5-0-pro-260628`는 단일 이미지 또는 다중 이미지 입력(다중 이미지 2-10장, 2장부터 장당 요금 부과)을 지원하며, `doubao-seedream-5-0-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`는 단일 이미지 또는 다중 이미지 입력을 지원합니다.
- `size`: 생성할 이미지의 크기 정보를 지정하며, 다음 두 가지 방법을 지원합니다. 혼용할 수 없습니다. 방법 1 | 생성할 이미지의 해상도를 지정하고 프롬프트에서 자연어로 이미지의 가로 세로 비율을 설명합니다. **각 모델이 지원하는 프리셋이 다릅니다**: `doubao-seedream-5-0-pro-260628`는 `1K`/`2K`를 지원합니다; `doubao-seedream-5-0-260128`는 `2K`/`3K`/`4K`를 지원합니다; `doubao-seedream-4-5-251128`는 `2K`/`4K`만 지원합니다; `doubao-seedream-4-0-250828`는 `1K`/`2K`/`4K`를 지원합니다. 방법 2 | 생성할 이미지의 가로 세로 픽셀 값을 지정합니다: 기본값은 `2048x2048`이며, 총 픽셀과 가로 세로 비율의 값 범위는 모델에 따라 다릅니다(예: 5.0 Pro의 총 픽셀 범위는 [921600, 4194304], 5.0 Lite / 4.5의 총 픽셀 하한은 3,686,400, 4.0의 하한은 921,600입니다).
- `sequential_image_generation`: 그룹 이미지: 입력한 내용을 기반으로 생성된 관련 이미지 그룹입니다. `doubao-seedream-5-0-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`는 이 매개변수를 지원하며, 기본값은 `disabled`입니다.
- `stream`: 스트리밍 출력 모드를 활성화할지 여부를 제어합니다. `doubao-seedream-5-0-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`는 이 매개변수를 지원하며, 기본값은 `false`입니다.
- `response_format`: 생성된 이미지의 반환 형식을 지정합니다. 기본값은 `url`이며, `b64_json`도 지원합니다.
- `watermark`: 생성된 이미지에 워터마크를 추가할지 여부입니다. 기본값은 `true`입니다.
- `output_format`: 생성된 이미지의 파일 형식을 지정합니다. `jpeg`(기본값)와 `png`를 지원합니다. 오직 `doubao-seedream-5-0-pro-260628`와 `doubao-seedream-5-0-260128`만 지원합니다.
- `tools`: 모델이 호출할 도구를 구성합니다. 현재 `web_search`(네트워크 검색)를 지원합니다. 오직 `doubao-seedream-5-0-260128`만 지원합니다.
- `callback_url`: 결과를 회신받을 URL입니다.
- `async`: 비동기 모드로 처리할지 여부입니다. `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하며, `callback_url`을 제공할 필요가 없고, 이후 `/seedream/tasks`를 통해 결과를 폴링하여 가져옵니다.

선택 후 오른쪽에도 해당 코드가 생성된 것을 확인할 수 있습니다. 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/seedream_image.png" width="500" className="m-auto" /></p>

"Try" 버튼을 클릭하면 테스트를 진행할 수 있으며, 위 그림과 같이 다음과 같은 결과를 얻을 수 있습니다:

```json
  "task_id": "81246f86-05ff-4d7d-9553-1013e0c1cd32",
  "trace_id": "ab50a78d-ab1f-457f-a46b-c2259cd5d35b",

```

반환된 결과는 여러 필드를 포함하며, 설명은 다음과 같습니다:

- `success`: 이 시점에서 비디오 생성 작업의 상태입니다.
- `task_id`: 이 시점에서 비디오 생성 작업 ID입니다.
- `trace_id`: 이 시점에서 비디오 생성 추적 ID입니다.
- `data`: 이 시점에서 이미지 생성 작업의 결과 목록입니다.
  - `image_url`: 이 시점에서 이미지 생성 작업의 링크입니다.
  - `prompt`: 프롬프트입니다.
  - `size`: 생성된 이미지의 픽셀입니다.

우리는 만족스러운 이미지 정보를 얻었으며, 결과의 `data`에서 이미지 링크 주소를 통해 생성된 SeeDream 이미지를 가져올 수 있습니다.

또한 해당 연동 코드를 생성하고 싶다면, 생성된 코드를 직접 복사할 수 있습니다. 예를 들어 CURL의 코드는 다음과 같습니다:
```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-260128",
  "prompt": "습기 있는 검은 슬레이트 위에 있는 서리 낀 유리 향수 병의 포토리얼리스틱 스튜디오 제품 샷, 단일 소프트박스 키 라이트, 물방울, 어두운 우울한 배경, 85mm 매크로."
}'
```

## 이미지 편집 작업

어떤 이미지를 편집하고 싶다면, 먼저 매개변수 `image`에 편집할 이미지 링크를 전달해야 합니다.

- model: 이번 이미지 편집 작업에 사용되는 모델, `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828` 모두 이미지 입력을 지원합니다.
- image: 편집할 이미지를 업로드합니다. 하나 또는 여러 장.

샘플 입력은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

해당 코드:

```python
import requests

url = "https://api.acedata.cloud/flux/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "모델 포즈와 액체 의상의 흐르는 형태를 변경하지 마십시오. 의류 재료를 은색 금속에서 완전히 투명한 물(또는 유리)로 변경하십시오. 액체 흐름을 통해 모델 피부의 세부 사항이 보입니다. 빛과 그림자 효과가 반사에서 굴절로 전환됩니다.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 비동기 콜백

SeeDream Images Generation API의 생성 시간은 상대적으로 길어 약 1-2분이 소요됩니다. API가 오랜 시간 응답하지 않으면 HTTP 요청이 연결을 유지하여 추가 시스템 리소스 소모를 초래하므로, 이 API는 비동기 콜백 지원도 제공합니다.

전체 프로세스는: 클라이언트가 요청을 시작할 때 추가로 `callback_url` 필드를 지정하고, 클라이언트가 API 요청을 시작한 후 API는 즉시 결과를 반환하며, 현재 작업 ID를 나타내는 `task_id` 필드 정보를 포함합니다. 작업이 완료되면 생성된 이미지 결과가 POST JSON 형식으로 클라이언트가 지정한 `callback_url`로 전송되며, 여기에도 `task_id` 필드가 포함되어 있어 작업 결과를 ID로 연결할 수 있습니다.

콜백을 위한 공용 주소가 없다면 `callback_url`을 지정하지 않고 요청에서 `async` 필드를 `true`로 설정할 수 있습니다. 이 경우 인터페이스는 즉시 `task_id`를 반환하지만 결과를 푸시하지 않으며, 해당 `task_id`를 가지고 `/seedream/tasks` 인터페이스를 호출하여 작업 상태를 폴링하여 최종 결과를 얻어야 합니다.

실행하면 즉시 결과를 얻을 수 있습니다:

```

  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

내용은 다음과 같습니다:

```json
    "data": [
        {
            "prompt": "모델 포즈와 액체 의상의 흐르는 형태를 변경하지 마십시오. 의류 재료를 은색 금속에서 완전히 투명한 물(또는 유리)로 변경하십시오. 액체 흐름을 통해 모델 피부의 세부 사항이 보입니다. 빛과 그림자 효과가 반사에서 굴절로 전환됩니다.",
```

## 오류 처리

API를 호출할 때 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들어:

- `400 token_mismatched`: 잘못된 요청, 누락되거나 잘못된 매개변수 때문일 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청, 누락되거나 잘못된 매개변수 때문일 수 있습니다.
- `401 invalid_token`: 인증되지 않음, 잘못되었거나 누락된 인증 토큰.
- `429 too_many_requests`: 너무 많은 요청, 비율 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류, 서버에서 문제가 발생했습니다.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
