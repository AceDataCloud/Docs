이 문서에서는 사용자 지정 매개변수를 입력하여 SeeDream 공식 이미지를 생성할 수 있는 SeeDream Images Generation API 연동 방법을 소개합니다.

## 신청 절차

SeeDream Images Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에 접속하여 API Token을 발급받고 나중에 사용할 수 있도록 보관하세요.

![]()

아직 로그인하거나 가입하지 않은 경우 자동으로 로그인 페이지로 이동하여 회원가입 및 로그인을 안내합니다. 완료되면 현재 페이지로 자동으로 돌아옵니다.

**API Token 하나만으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 사용량이 제공되어 무료로 체험할 수 있습니다. 사용량이 부족한 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [SeeDream Images Generation API →](https://platform.acedata.cloud/documents/seedream-images)

## 모델 선택

| 모델                                                          | 적용 시나리오                            |
| ----------------------------------------------------------- | ------------------------------- |
| `doubao-seedream-5-5-261028`                                | 다중 편집, 텍스트 기반 투명 이미지 생성, 다중 참조 이미지 투명 편집, 레이어 분리 및 텍스트 레이어 인식 |
| `doubao-seedream-5-0-flash-260915`                          | 저지연 단일 이미지 생성, 다중 참조 이미지 편집, 투명 이미지 편집 및 레이어 분리       |
| `doubao-seedream-5-0-pro-260628`                            | 단일 이미지 생성, 정밀 편집, 투명 이미지 편집 및 레이어 분리            |
| `doubao-seedream-5-0-lite-260128`                           | 단일 이미지, 이미지 그룹, 스트리밍 출력 및 웹 검색                 |
| `doubao-seedream-4-5-251128` / `doubao-seedream-4-0-250828` | 이전 버전의 이미지 생성 및 편집                       |

5.5와 5.0 Flash는 동일한 `POST /seedream/images`를 사용하며, 모두 `1K`, `1.5K`, `2K` 및 최대 10장의 참조 이미지를 지원합니다. 두 모델의 레이어 분리 작업은 모두 한 장의 이미지만 입력받으며 URL을 반환합니다. 5.5는 `layer_decomposition_options: {"max_images": 12, "text_recognition": true}`를 설정할 수 있습니다. 최대 100장의 이미지를 출력할 수 있으며(기본 이미지 포함), 인식 가능한 텍스트 레이어는 `data[].text_recognition`에서 줄별 텍스트와 스타일을 반환합니다. 5.0 Flash는 기본 이미지 최대 1장과 레이어 최대 16개를 반환합니다.

5.5는 `background: "transparent"`를 사용하여 투명 PNG를 직접 생성할 수 있습니다. 5.0 Flash의 투명 이미지 편집에는 투명 채널이 있는 참조 이미지 한 장이 필요합니다. 5.5는 성공적으로 출력된 이미지의 픽셀 등급에 따라 요금이 부과되며, 입력 참조 이미지 한 장당 0.13 Credits가 추가로 부과됩니다. 5.0 Flash는 성공적으로 출력된 이미지 한 장당 0.31 Credits가 부과되며, 참조 이미지는 무료입니다. 레이어 분리는 실제로 성공적으로 출력된 이미지 수를 기준으로 요금이 부과되며, 기본 이미지도 포함됩니다. [실시간 요금](https://platform.acedata.cloud/services/seedream?tab=pricing)을 참조하세요.

## 기본 사용법

먼저 기본적인 사용 방법을 알아보겠습니다. 프롬프트 `prompt`, 생성 동작 `action`, 이미지 크기 `size`를 입력하면 처리된 결과를 얻을 수 있습니다. 우선 `action` 필드를 간단히 전달해야 하며, 해당 값은 `generate`입니다. 그런 다음 프롬프트도 입력해야 합니다. 구체적인 내용은 다음과 같습니다.

<p><img src="https://cdn.acedata.cloud/seedream_request_body.png" width="500" className="m-auto" /></p>

여기에서 Request Headers를 설정한 것을 확인할 수 있습니다. 다음 항목이 포함됩니다.

- `accept`: 수신하려는 응답 결과의 형식을 지정합니다. 여기에서는 JSON 형식인 `application/json`을 입력합니다.
- `authorization`: API 호출에 사용하는 키입니다. 발급받은 후 드롭다운에서 직접 선택할 수 있습니다.

또한 Request Body도 설정했으며, 다음 항목이 포함됩니다.

- `prompt`: 프롬프트입니다.
- `model`: 위 표에 있는 전체 모델 ID를 입력하세요.
- `image`: 입력 이미지 URL, Base64 문자열 또는 배열입니다. 5.5, 5.0 Pro 및 5.0 Flash는 최대 10장의 참조 이미지를 지원합니다.
- `size`: 해상도 등급 또는 `너비x높이`입니다. 5.5, 5.0 Pro 및 5.0 Flash는 `1K`, `1.5K`, `2K`를 지원합니다. 5.0 Lite는 `2K`, `3K`, `4K`를 지원합니다.
- `sequential_image_generation`: 이미지 그룹 생성: 입력한 콘텐츠를 기반으로 서로 연관된 이미지 그룹을 생성합니다. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`에서 이 매개변수를 지원하며, 기본값은 `disabled`입니다.
- `stream`: 스트리밍 출력 모드를 활성화할지 여부를 제어합니다. `doubao-seedream-5-0-lite-260128`, `doubao-seedream-4-5-251128`, `doubao-seedream-4-0-250828`에서 이 매개변수를 지원하며, 기본값은 `false`입니다.
- `response_format`: 생성된 이미지의 반환 형식을 지정합니다. 기본값은 `url`이며, `b64_json`도 지원합니다.
- `watermark`: 생성된 이미지에 워터마크를 추가할지 여부를 지정합니다. 기본값은 `true`입니다.
- `output_format`: 출력 형식은 `jpeg` 또는 `png`입니다. 5.5의 기본값은 PNG이며, 5.0 Pro/Flash/Lite의 기본값은 JPEG입니다.
- `tools`: 모델이 호출할 도구를 구성합니다. 현재 `web_search`(웹 검색)를 지원합니다. Seedream 5.0 Lite만 지원합니다.
- `optimize_prompt_options`: 프롬프트 최적화 설정입니다. 5.0 Pro는 `standard`/`fast`를 지원하며, 5.5, 5.0 Flash, 5.0 Lite 및 4.5는 `standard`만 지원합니다. 4.0은 `standard`/`fast`를 지원합니다.
- `background`: `transparent` 및 `opaque`를 지원합니다. 5.5는 `auto`도 지원합니다. 투명 출력에는 PNG를 사용합니다.
- `layer_decomposition`: 5.5, 5.0 Pro 및 5.0 Flash에서 지원합니다. `true`로 설정하면 PNG/JPEG 이미지 한 장을 반드시 입력해야 합니다. `prompt`를 전달하지 않고 자동으로 분리하거나 자연어/`<bbox>`를 사용하여 요소를 지정할 수 있습니다. `size`는 `auto`/`1K`/`1.5K`/`2K`를 지원합니다. 이 모드는 이미지 그룹, 스트리밍, 웹 검색 또는 `background`와 함께 사용할 수 없습니다.
- `callback_url`: 결과를 콜백으로 받을 URL입니다.
- `async`: 비동기 모드로 처리할지 여부입니다. `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하며, `callback_url`을 제공할 필요가 없습니다. 이후 `/seedream/tasks`를 통해 결과를 폴링하여 가져올 수 있습니다.

- `task_id`: 현재 비디오 생성 작업의 ID입니다.

또한 해당 연동 코드를 생성하려면 직접 복사하여 생성할 수 있습니다. 예를 들어 CURL 코드는 다음과 같습니다.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "doubao-seedream-5-0-lite-260128",
  "prompt": "A single matte blue cube centered on a clean white studio background, neutral lighting"
}'
```

## 이미지 편집 작업

특정 이미지를 편집하려면 먼저 `image` 매개변수에 편집할 이미지 링크를 전달해야 합니다.

- model: 위 표에서 이미지 편집을 지원하는 전체 모델 ID를 전달합니다.
- image: 편집할 이미지를 한 장 또는 여러 장 업로드합니다.

입력 예시는 다음과 같습니다.

<p><img src="https://cdn.acedata.cloud/seedream_edit.png" width="500" className="m-auto" /></p>

해당 코드는 다음과 같습니다.

```python
import requests

url = "https://api.acedata.cloud/seedream/images"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedream-4-0-250828",
  "prompt": "모델의 포즈와 액체 의상의 흐르는 형태를 변경하지 않고 유지합니다. 의상의 소재를 은색 금속에서 완전히 투명한 물(또는 유리)로 변경합니다. 액체의 흐름을 통해 모델 피부의 세부적인 모습이 보입니다. 빛과 그림자 효과는 반사에서 굴절로 바뀝니다.",
  "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_5_imageToimage.png"],
  "size": "2K",
  "watermark": False
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 레이어 분리 (Seedream 5.0 Pro)

레이어 분리 기능은 입력 이미지 한 장을 기본 이미지 한 장과 독립적으로 편집할 수 있는 최대 16개의 투명 PNG 레이어로 분리합니다. 아래 요청은 모델이 주요 요소를 자동으로 식별하도록 합니다. 특정 요소를 지정하려면 `prompt`를 추가할 수 있으며, 프롬프트에서 정규화된 `<bbox>` 좌표를 사용할 수도 있습니다.

```shell
curl -X POST 'https://api.acedata.cloud/seedream/images' \
-H 'accept: application/json' \
-H 'authorization: Bearer ${token}' \
-H 'content-type: application/json' \
-d '{
  "model": "doubao-seedream-5-0-pro-260628",
  "image": "https://example.com/poster.png",
  "layer_decomposition": true,
  "size": "2K",
  "watermark": false
}'
```

반환되는 `data`는 `z_index`를 기준으로 아래쪽부터 위쪽 순서로 배열됩니다. 기본 이미지의 `z_index`는 0입니다. 각 레이어에는 `name`, `description`, `bounding_box.absolute`/`normalized`도 포함됩니다. 절대 좌표를 사용하여 재구성할 때는 레이어를 `[right-left, bottom-top]` 크기로 조정하고 `[left, top]` 위치에 배치한 다음, `z_index` 오름차순으로 겹쳐 놓습니다. 어느 하나의 레이어라도 생성에 실패하면 전체 분리 작업이 실패합니다.

## 스트리밍 출력

Lite/4.x에서 `stream: true`를 설정하면 요청 헤더에 `accept: application/x-ndjson`을 사용합니다. 인터페이스는 한 줄씩 `image_generation.partial_succeeded` 또는 `image_generation.partial_failed`를 반환하고, 마지막에는 최종 `usage`가 포함된 유일한 `image_generation.completed` 이벤트를 반환합니다. 완료 이벤트가 발생할 때만 한 번 과금됩니다. 스트리밍 모드는 `async` 또는 `callback_url`과 함께 사용할 수 없습니다.

## 비동기 콜백

SeeDream Images Generation API는 생성 시간이 비교적 길며 약 1~2분이 소요됩니다. API가 장시간 응답하지 않으면 HTTP 요청이 계속 연결된 상태로 유지되어 추가적인 시스템 리소스를 소비하게 됩니다. 따라서 이 API는 비동기 콜백 기능도 지원합니다.

전체적인 흐름은 다음과 같습니다. 클라이언트가 요청을 시작할 때 `callback_url` 필드를 추가로 지정합니다. 클라이언트가 API 요청을 시작하면 API는 `task_id` 필드 정보가 포함된 결과를 즉시 반환하며, 이는 현재 작업의 ID를 나타냅니다. 작업이 완료되면 생성된 이미지 결과가 POST JSON 형식으로 클라이언트가 지정한 `callback_url`에 전송됩니다. 여기에도 `task_id` 필드가 포함되므로 ID를 통해 작업 결과를 서로 연결할 수 있습니다.

콜백을 받을 수 있는 공개 네트워크 주소가 없다면 `callback_url`을 지정하지 않고 요청에서 `async` 필드를 `true`로 설정할 수도 있습니다. 이 경우에도 인터페이스는 `task_id`를 즉시 반환하지만 결과를 푸시하지는 않습니다. 최종 결과를 가져오려면 해당 `task_id`를 사용하여 `/seedream/tasks` 인터페이스를 호출하고 작업 상태를 폴링해야 합니다.

아래 예시를 통해 구체적인 작업 방법을 알아보겠습니다.

실행을 클릭하면 다음과 같은 결과를 즉시 얻을 수 있습니다.

```
{
  "task_id": "c9aaffa2-b8ac-40ff-8468-43e77cb9ddde"
}
```

내용은 다음과 같습니다.

## 오류 처리

API를 호출할 때 오류가 발생하면 API는 해당 오류 코드와 메시지를 반환합니다. 예를 들어 다음과 같습니다.

- `400 token_mismatched`: 잘못된 요청입니다. 매개변수가 누락되었거나 유효하지 않을 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청입니다. 매개변수가 누락되었거나 유효하지 않을 수 있습니다.
- `401 invalid_token`: 인증되지 않았습니다. 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`: 요청이 너무 많습니다. 요청 빈도 제한을 초과했습니다.
- `500 api_error`: 서버 내부 오류가 발생했습니다. 서버에서 문제가 발생했습니다.

### 오류 응답 예시
