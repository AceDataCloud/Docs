전용 음악 모델은 6개에서 24개의 승인된 오디오로부터 일관된 음악 특성을 학습하고, 이후 곡 창작에 사용할 수 있습니다. 생성은 비동기 작업입니다. 더 안정적인 효과를 위해 스타일이 일관되고 음질이 선명한 24개의 오디오를 사용하는 것이 권장됩니다.

> 귀하가 합법적인 사용 권한을 보유하거나, 모델 생성 및 이후 생성에 대한 승인을 받은 오디오만 제출할 수 있습니다. 허가받지 않은 음악 또는 음성 소재를 업로드하지 마십시오.

## 모델 생성

`POST /suno/custom-models`를 호출하고 `action=create`로 설정합니다:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

인터페이스는 즉시 플랫폼 모델 ID와 작업 ID를 반환합니다. 생성이 완료되면 콜백 또는 조회 결과의 `status`가 `ready`로 변경됩니다. 모델 생성이 성공한 경우에만 **10 Credits**가 청구되며, 생성 실패 시에는 요금이 청구되지 않습니다.

## 모델 조회

단일 모델 조회:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

현재 애플리케이션의 모델을 페이지네이션으로 조회:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

모든 모델은 이를 생성한 Suno 애플리케이션에 귀속됩니다. API 자격 증명 교체는 모델 귀속을 변경하지 않으며, 다른 애플리케이션은 해당 모델을 조회하거나 사용할 수 없습니다.

## 모델을 사용하여 곡 생성

모델 상태가 `ready`가 된 후, 계속해서 `POST /suno/custom-models`를 호출하고 `action=generate`로 설정합니다:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id`는 현재 애플리케이션 내에서 상태가 `ready`인 전용 음악 모델이어야 합니다. 모델을 사용할 수 없는 경우 요청은 실패하며, 다른 모델로 자동 전환되지 않습니다. `persona_id`는 전용 음악 모델과 상호 배타적입니다. 동시에 제출하면 인터페이스는 요청이 생성 서비스로 전송되기 전에 HTTP 400을 반환하며, 요금은 청구되지 않습니다. Persona를 사용해야 하는 경우 `/suno/audios`의 `artist_consistency` 또는 `artist_consistency_vox` 작업을 사용하십시오.

곡 생성 성공 시 **0.90 Credits**가 소모되며, 생성 실패 시에는 요금이 청구되지 않습니다. 모델 조회 및 보관은 무료입니다.

## 모델 보관

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

현재 Beta 버전에서는 모델을 보관하고 계속 사용할 수 없도록 합니다. 응답의 `capacity_released=false`는 보관이 모델 용량 해제를 보장하지 않음을 나타냅니다. 보관 작업은 반복 호출할 수 있으며, 중복 청구되지 않습니다.
