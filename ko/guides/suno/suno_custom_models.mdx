전용 음악 모델은 6에서 24개의 허가된 오디오에서 일관된 음악 특성을 학습하고 이후 곡 작곡에 사용됩니다. 생성은 비동기 작업이며, 24개의 스타일이 일관되고 음질이 선명한 오디오를 사용하는 것이 더 안정적인 효과를 얻는 데 권장됩니다.

> 귀하가 합법적으로 사용 권한을 보유하고 있거나 모델 생성 및 후속 생성 허가를 받은 오디오만 제출할 수 있습니다. 허가 없이 음악이나 음향 자료를 업로드하지 마십시오.

## 모델 생성

`POST /suno/custom-models`를 호출하고 `action=create`를 설정합니다. 고유한 `Idempotency-Key` 요청 헤더를 함께 보내는 것이 좋습니다; 네트워크 재시도 시 동일한 키를 재사용하여 중복 생성을 방지합니다:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

인터페이스는 즉시 플랫폼 모델 ID와 작업 ID를 반환합니다. 생성이 완료되면 콜백 또는 결과 조회에서 `status`가 `ready`로 변경됩니다. 모델 생성이 성공해야만 요금이 청구되며, 생성 실패 시 요금이 청구되지 않습니다.

## 모델 조회

단일 모델 조회:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

현재 애플리케이션의 모델을 페이지로 조회:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

모든 모델은 그것을 생성한 Suno 애플리케이션에 귀속됩니다. API 자격 증명 교체는 모델 귀속을 변경하지 않으며, 다른 애플리케이션은 해당 모델을 조회하거나 사용할 수 없습니다.

## 모델을 사용하여 곡 생성

모델 상태가 `ready`인 경우, 계속해서 `POST /suno/custom-models`를 호출하고 `action=generate`를 설정합니다:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id`는 현재 애플리케이션에서 상태가 `ready`인 전용 음악 모델이어야 합니다. 모델이 사용 불가능할 경우 요청이 실패하며, 자동으로 다른 모델로 변경되지 않습니다.

## 모델 아카이브

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

현재 베타 버전은 모델을 아카이브하고 계속 사용을 금지하며, 응답의 `capacity_released=false`는 아카이브가 모델 용량을 해제할 것을 보장하지 않음을 나타냅니다. 아카이브 작업은 반복 호출할 수 있으며, 중복 요금이 청구되지 않습니다.
