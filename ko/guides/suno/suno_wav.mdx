SUNO는 우리가 음악의 wav 형식 파일을 가져올 수 있도록 허용합니다. 본 문서는 관련 API의 연동 방법을 설명합니다.

이 API의 핵심 입력 매개변수는 `audio_id`로, 이는 공식적으로 생성된 곡 ID입니다; 선택적으로 `callback_url` 비동기 콜백 주소도 지원합니다.

여기서 입력하는 `audio_id`는 `4e43116a-bf09-472c-8e1c-655eabf02682`입니다.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer YOUR_API_KEY",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://cdn.acedata.cloud/e724d7f13d.png?example=image-001"
    }
  ]
}
```

볼 수 있듯이, `data`의 `file_url` 필드는 가져온 음악의 wav 형식 파일로, 공개적으로 접근 가능한 CDN 주소입니다.

> **WAV 링크의 지속성에 대한 설명**
> 플랫폼은 응답 전에 최종 상태의 WAV 파일을 Ace Data Cloud CDN에 우선적으로 지속화합니다. 위 URL은 응답 형식만을 보여주며, 장기적으로 존재하는 실제 객체를 나타내지 않습니다. CDN 지속화가 완료되지 않았고, 원본 미디어 주소가 즉시 검증되어 유효한 WAV 파일을 다운로드할 수 있는 경우에만 `file_url`이 해당 주소를 유지할 수 있습니다; 주소가 만료되거나 파일 검증에 실패한 경우 요청은 실패하거나 시간 초과로 반환되며, 다운로드할 수 없는 주소를 성공 결과로 간주하지 않습니다. 작업이 완료된 후에는 즉시 다운로드하고 적절히 보관하시기 바랍니다. 구체적인 보존 기간은 플랫폼의 현재 저장 정책에 따릅니다.
