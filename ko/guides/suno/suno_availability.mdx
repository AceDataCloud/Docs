---

`POST /suno/availability`는 `audio_id`를 기반으로 오디오가 현재 경로에서 계속 처리될 수 있다는 긍정적인 증거를 찾습니다. 이어쓰기, 커버 등의 작업 전에 호출할 수 있습니다. 결과는 확인 시점의 상태만 반영하며, 특정 작업의 성공을 보장하지는 않습니다. 이 인터페이스는 동기식으로 응답하며 API Token이 필요하고, 현재 Credits는 차감되지 않습니다.

`audio_id`는 완료된 Suno 작업이 반환한 곡 ID이며, `task_id`가 아닙니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

성공 응답 예시:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

확인에 성공하면 `data.available`는 `true`입니다. 확인할 수 없는 경우 `503 availability_unknown`가 반환되며 `false`는 반환되지 않습니다. `audio_id` 형식이 잘못되면 400이 반환되고, 요청 제한 또는 서비스 예외 시에도 오류 응답이 반환됩니다. 확인 완료 후 실제 작업을 수행하기 전까지 상태가 변경될 수 있습니다.
