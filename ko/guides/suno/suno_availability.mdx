---
title: "Suno 오디오 사용 가능 여부 확인 API"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

`POST /suno/availability`는 `audio_id`를 기반으로 현재 경로에서 오디오를 계속 처리할 수 있는 긍정적 근거를 찾습니다. 이어쓰기, 커버 등의 작업 전에 호출할 수 있습니다. 결과는 확인 시점의 상태만 반영하며, 특정 작업이 반드시 성공한다는 것을 보장하지 않습니다. 이 인터페이스는 동기식으로 반환되며 API Token이 필요하고, 현재 Credits는 차감되지 않습니다.

`audio_id`는 완료된 Suno 작업이 반환한 노래 ID이며, `task_id`가 아닙니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/availability' \
  -H 'Authorization: Bearer YOUR_API_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"audio_id":"33333333-3333-4333-8333-333333333333"}'
```

성공 응답 예시:

```json
{
  "success": true,
  "task_id": "11111111-1111-4111-8111-111111111111",
  "trace_id": "22222222-2222-4222-8222-222222222222",
  "data": {
    "id": "33333333-3333-4333-8333-333333333333",
    "available": true
  }
}
```

확인에 성공했을 때 `data.available`는 `true`만 될 수 있습니다. 일부 경로에서 반환되는 “오프라인” 상태는 이후 이어쓰기 등의 작업이 성공할 수 없음을 증명하지 못하므로, 이 인터페이스는 확인할 수 없는 경우 `503 availability_unknown`를 반환하며 `false`를 반환하지 않습니다. `audio_id` 형식 오류는 400을 반환하고, 속도 제한 또는 업스트림 장애도 오류 응답을 반환합니다. 확인 완료 후 실제 작업 사이에도 상태는 여전히 변경될 수 있습니다.
