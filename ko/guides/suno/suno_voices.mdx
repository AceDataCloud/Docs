SUNO는 임의의 오디오 파일을 통해 사용자 정의 음성 캐릭터를 생성하여, 음악 생성에 사용할 음성 복제를 구현할 수 있도록 합니다. 기존의 Persona API(Suno에서 생성한 `audio_id` 사용)와 달리, 이 API는 직접 녹음한 음성인 공개적으로 접근 가능한 `audio_url`을 받습니다. 이 문서는 음성 복제 API의 연동 방법을 설명합니다.

## 첫 번째 단계: 음성 캐릭터 생성

이 API에는 세 가지 입력 매개변수가 있습니다: `audio_url`(필수)은 선명한 단일 인물의 음성이 포함된 공개적으로 접근 가능한 MP3 또는 WAV 형식 오디오 파일 URL입니다; `name` 및 `description`(선택 사항)은 음성 캐릭터의 이름과 설명입니다.

> **오디오 파일 요구 사항**
> - 오디오 형식은 `WAV` 또는 `MP3`여야 합니다
> - 오디오 길이는 `10~240초` 사이여야 하며, `30~60초`의 깨끗한 단일 인물 무반주 음성 소재 사용을 권장합니다
> - 오디오에는 **선명하고 식별 가능한 단일 인물의 말하기 또는 노래 음성**이 포함되어야 합니다
> - **배경 소음, 반주, 에코, 리버브**를 반드시 피하십시오; 반주가 포함된 완성된 노래는 일반적으로 성문 검증을 통과할 수 없습니다
> - **여러 화자** 또는 **다중 음성**을 포함하지 마십시오
> - 볼륨이 너무 낮거나, 음성이 불분명하거나, 소음이 너무 심한 소재는 **복제 실패** 또는 **생성 효과 저하**를 초래할 수 있습니다
> **사용 제한 안내**
> - 오디오 업로드를 통해 생성된 음성 캐릭터는 **비공개 리소스**입니다
> - 해당 음성 캐릭터는 **계정 간 재사용을 지원하지 않습니다**
> - 생성 성공 후 가능한 한 빨리 사용하는 것을 권장하며, 장기간 사용하지 않으면 **만료되거나 사용할 수 없게 될 수 있습니다**
> - 반환되는 `name`은 시스템에서 자동 생성되므로, 반환되는 `persona_id`를 기준으로 하십시오

> **호출 실패 시 먼저 재시도하십시오**
> 음성 복제는 연산 집약적인 작업이므로, 소재가 완전히 규정을 준수하더라도 일정 확률로 간헐적인 실패가 발생할 수 있으며, 일반적인 반환으로는
> `voices_sound_different`(성문 검증 통과 실패) 등이 있습니다. **이러한 실패는 오디오 품질과 무관하며, 동일한 소재로 재시도하면 일반적으로 성공할 수 있습니다**,
> 연동 시 실패 결과에 대해 1~2회의 자동 재시도를 구현하는 것을 권장합니다. 실패한 요청에는 비용이 청구되지 않습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "단일 인물 선명 음성 예시"
}'
```

> 위의 `https://cdn.acedata.cloud/suno_demo.mp3`는 직접 호출 가능한 예시 소재입니다(MP3, 41초, 단일 인물 무반주 음성).
> `WAV` 형식 예시가 필요한 경우
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765`를 사용할 수 있습니다(WAV, 41초, 모노 44.1kHz).

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

확인할 수 있듯이, `data`의 `persona_id` 필드가 생성된 음성 캐릭터 ID입니다. `is_public` 필드는 업로드한 오디오를 통해 생성된 음성 캐릭터가 비공개이므로 항상 `false`입니다. 반환되는 `name`은 시스템에서 자동 생성되므로, 이후에는 `persona_id`를 사용하여 해당 음성 캐릭터를 참조하십시오.

## 두 번째 단계: 음성 캐릭터를 사용하여 음악 생성

음성 캐릭터 ID를 얻은 후에는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 사용하여 음악을 생성할 수 있습니다. `action`을 `generate`로 설정하고 `persona_id`를 위에서 반환된 음성 캐릭터 ID로 설정하면, 생성된 노래는 복제된 음성으로 노래됩니다.

> **주의:** 음성 복제는 `chirp-v4-5` 이상의 모델(예: `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`)만 지원하며, `chirp-v4`는 지원하지 않습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

확인할 수 있듯이, 생성된 노래는 복제된 음성을 사용하여 노래합니다. `persona_id`는 `cover` 작업과 함께 사용할 수도 있으며, 복제된 음성으로 기존 노래를 리메이크할 수 있습니다.
