SUNO는 임의의 오디오 파일을 통해 사용자 지정 음성 캐릭터를 생성하여, 음악 생성에 사용할 음성 클론을 구현할 수 있도록 합니다. 기존 Persona API(Suno에서 생성한 `audio_id` 사용)와 달리, 이 API는 공개적으로 접근 가능한 `audio_url`, 즉 사용자의 보컬 녹음 파일을 받습니다. 이 문서는 음성 클론 API의 연동 방법을 설명합니다.

음색 조회를 지원하는 생성 경로에서는 원래 애플리케이션과 호출자 신원을 사용하여, 생성 결과의 `persona_id`를 `POST /suno/availability`에 전달할 수 있습니다. 연결된 계정이 온라인이면 `data.available=true`를 반환하고, 오프라인으로 확인되면 `data.available=false`를 반환합니다. [음색 사용 가능 여부 조회 가이드](https://platform.acedata.cloud/documents/suno-availability-integration)

## 첫 번째 단계: 음성 캐릭터 생성

과금: 음성 캐릭터 생성이 성공한 후, 요청당 표준 비용은 **0.15 Credits**입니다. 적용되는 소비 할인은 실제 청구서를 기준으로 하며, 실패한 요청에는 과금되지 않습니다.

이 API에는 세 가지 입력 매개변수가 있습니다. `audio_url`(필수)은 단일 화자의 선명한 음성을 포함하는 공개적으로 접근 가능한 MP3 또는 WAV 형식 오디오 파일 URL입니다. `name` 및 `description`(선택 사항)은 음성 캐릭터의 이름과 설명입니다.

> **오디오 파일 요구 사항**
> - 오디오 형식은 `WAV` 또는 `MP3`여야 합니다
> - 오디오 길이는 `10~240초` 사이여야 하며, `30~60초` 길이의 깨끗한 단일 화자 드라이 보컬 소스를 사용하는 것이 권장됩니다
> - 오디오에는 **선명하고 식별 가능한 단일 화자의 말 또는 노래 보컬**이 포함되어야 합니다
> - **배경 소음, 반주, 에코, 리버브**는 반드시 피해야 합니다. 반주가 포함된 완성된 곡은 일반적으로 음성 지문 검증을 통과할 수 없습니다
> - **여러 화자** 또는 **다중 보컬**을 포함하지 마세요
> - 볼륨이 너무 낮거나, 음성이 선명하지 않거나, 노이즈가 너무 심한 소스는 **클론 실패** 또는 **낮은 생성 품질**을 초래할 수 있습니다
> **사용 제한 안내**
> - 오디오 업로드를 통해 생성된 음성 캐릭터는 **비공개 리소스**입니다
> - 이 음성 캐릭터는 **계정 간 재사용을 지원하지 않습니다**
> - 생성에 성공한 후 가능한 한 빨리 사용하는 것이 권장되며, 장기간 사용하지 않으면 **만료되거나 사용할 수 없게 될 수 있습니다**
> - 반환되는 `name`은 시스템에서 자동 생성되므로, 반환된 `persona_id`를 기준으로 하세요

> **명확한 재시도 표시에 따라 실패 처리**
> 오류 객체의 `retryable`은 선택적 불리언 필드입니다. `error.retryable`이 `true`이면, 이번 실패는 동일한 소스와 동일한 매개변수로 나중에 다시 요청할 수 있음을 의미합니다. 명확히 접수되지 않은 서비스 혼잡 또는 일부 일시적인 음성 지문 검증 실패에는 이 표시가 포함될 수 있으며, 백오프 간격을 사용하고 재시도 횟수를 제한하는 것이 권장됩니다.
> `retryable`이 `false`이거나 필드가 누락된 경우, HTTP 500, `busy` 또는 오류 문구만을 기준으로 자동 재전송하지 마세요. 형식, 길이, 선명도, 중복 녹음 및 콘텐츠 검토 문제는 먼저 수정해야 합니다. 제출 시간 초과, 연결 중단 또는 생성 결과가 불명확한 경우에는, 중복 음색 생성을 피하기 위해 원래 `task_id`로 작업을 조회하는 것을 우선해야 합니다. 실패한 요청에는 과금되지 않으며, 재시도에 성공한 요청은 일반 규칙에 따라 과금됩니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> 위의 `https://cdn.acedata.cloud/suno_demo.mp3`는 직접 호출할 수 있는 예제 소스입니다(MP3, 41초, 단일 화자 드라이 보컬).
> `WAV` 형식 예제가 필요한 경우,
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765`(WAV, 41초, 모노 44.1kHz)를 사용할 수 있습니다.

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

확인할 수 있듯이, `data`의 `persona_id` 필드가 바로 생성된 음성 캐릭터 ID입니다. 업로드한 오디오를 통해 생성된 음성 캐릭터는 비공개이므로, `is_public` 필드는 항상 `false`입니다. 반환되는 `name`은 시스템에서 자동 생성되므로, 이후에는 `persona_id`를 사용하여 해당 음성 캐릭터를 참조하세요.

## 두 번째 단계: 음성 캐릭터를 사용하여 음악 생성

음성 캐릭터 ID를 얻은 후에는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 사용하여 음악을 생성할 수 있습니다. `action`을 `generate`로 설정하고, `persona_id`를 위에서 반환된 음성 캐릭터 ID로 설정하면 생성된 곡은 클론된 음성으로 노래합니다.

> **주의:** 음성 클론은 `chirp-v4-5` 이상의 모델(예: `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`)만 지원하며, `chirp-v4`는 지원하지 않습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id`는 `generate` 생성에 사용할 수 있으며, `cover` / `upload_cover` 커버에도 사용할 수 있습니다. 지정된 음성에는 `vocal_gender`를 동시에 입력할 필요가 없으며, 음성 유사도는 여전히 참조 소스와 생성 결과에 따라 달라집니다.

이 인터페이스를 통해 생성된 음성은 비공개 리소스입니다. 기존 곡을 커버하기 전에 먼저 `/suno/upload`를 호출하여 원곡의 `audio_url`과 해당 음성의 `persona_id`를 전달하세요. 업로드에 성공한 후 반환된 `data.audio_id`와 동일한 `persona_id`를 사용하여 `/suno/audios`를 호출합니다:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

음성 생성, 원곡 업로드 및 커버에는 동일한 서비스 채널을 사용해야 합니다. 이전에 해당 개인 음성과 연결되지 않은 노래 ID를 직접 재사용하지 마십시오. 자세한 내용은 [Suno 참조 오디오 업로드](https://platform.acedata.cloud/documents/suno-upload)를 참조하십시오.
