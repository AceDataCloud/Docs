SUNO는 임의의 오디오 파일을 통해 맞춤형 음성 캐릭터를 생성하여 음악 생성에 음성 클론을 사용할 수 있도록 합니다. 기존의 Persona API(Suno가 생성한 `audio_id` 사용)와 달리, 이 API는 공개적으로 접근 가능한 `audio_url`을 입력받으며, 이는 사용자가 직접 녹음한 음성입니다. 본 문서에서는 음성 클론 API 연동 방법을 설명합니다.

## 첫 번째 단계: 음성 캐릭터 생성

이 API는 세 가지 입력 파라미터를 가집니다: `audio_url`(필수)로, 단일 인물의 명확한 음성이 포함된 공개 접근 가능한 MP3 또는 WAV 형식 오디오 파일 URL을 입력합니다; `name`과 `description`(선택)은 음성 캐릭터의 이름과 설명입니다.

**오디오 파일 요구사항:**
- 형식: MP3 또는 WAV
- 길이: 최소 10초 이상
- 내용: 단일 인물의 명확한 음성, 배경 소음이나 음악은 최대한 줄일 것

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

`data`의 `persona_id` 필드가 생성된 음성 캐릭터 ID임을 알 수 있습니다. `is_public` 필드는 항상 `false`이며, 이는 오디오 업로드를 통해 생성된 음성 캐릭터가 비공개임을 의미합니다.

## 두 번째 단계: 음성 캐릭터를 사용한 음악 생성

음성 캐릭터 ID를 확보한 후, [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9)를 사용하여 음악을 생성할 수 있습니다. `action`을 `generate`로 설정하고, `persona_id`에 위에서 받은 음성 캐릭터 ID를 지정하면, 생성된 곡은 클론된 음성으로 노래합니다.

> **주의:** 음성 클론은 `chirp-v4-5` 이상 모델(`chirp-v4-5`, `chirp-v5`, `chirp-v5-5` 등)만 지원하며, `chirp-v4`는 지원하지 않습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

생성된 곡이 클론된 음성으로 노래된 것을 확인할 수 있습니다. `persona_id`는 `cover` 액션과 함께 사용하여 클론 음성으로 기존 곡을 리메이크하는 데도 활용할 수 있습니다.
