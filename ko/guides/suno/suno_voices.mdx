title: "Suno 음성 클론 API 연동 설명"

---

SUNO는 우리가 임의의 오디오 파일을 통해 사용자 정의 음성 역할을 생성하고, 음악 생성에 사용하기 위해 음성 클론을 구현할 수 있도록 허용합니다. 기존의 Persona API(생성된 `audio_id`를 사용하는)와 달리, 이 API는 공개적으로 접근 가능한 `audio_url`을 수용하며, 이는 당신의 개인 음성 녹음입니다. 본 문서는 음성 클론 API의 연동 방법을 설명합니다.

이 API에는 세 가지 입력 매개변수가 있습니다: `audio_url`(필수), 공개적으로 접근 가능한 MP3 또는 WAV 형식의 오디오 파일 URL로, 단일 화자의 명확한 음성이 포함되어야 합니다; `name` 및 `description`(선택 사항), 음성 역할의 이름과 설명입니다.

**오디오 파일 요구 사항:**

- 형식: MP3 또는 WAV
- 길이: 최소 10초
- 내용: 단일 화자의 명확한 음성, 배경 소음이나 음악은 최대한 줄이기

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "My Voice",
  "description": "A warm male voice"
}'
```

결과는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "My Voice",
    "is_public": false
  }
}
```

볼 수 있듯이, `data`의 `persona_id` 필드는 생성된 음성 역할 ID입니다. `is_public` 필드는 항상 `false`로, 업로드된 오디오를 통해 생성된 음성 역할은 비공개입니다.

음성 역할 ID를 얻은 후, 우리는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9)를 사용하여 음악 생성을 진행할 수 있습니다. `action`을 `vox`로 설정하고, `persona_id`를 위에서 반환된 값으로 설정하면, 생성된 곡은 클론된 음성을 사용하여 노래하게 됩니다.
