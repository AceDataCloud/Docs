SUNO는 우리가 참고 오디오를 업로드하여 2차 창작을 할 수 있도록 허용합니다. 본 문서는 관련 API의 연동 방법을 설명합니다.

일반 업로드는 `audio_url`만 필요하며, 이는 공개적으로 접근 가능한 오디오 CDN 주소입니다. `mode`는 기본값이 `standard`이므로 기존 호출은 수정할 필요가 없습니다.

여기서 입력하는 `audio_url`은 `https://cdn.acedata.cloud/suno_demo.mp3`로, 공개적으로 접근 가능한 CDN 주소입니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

곡 ID를 얻은 후, 우리는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 사용하여 사용자 정의 곡 생성을 할 수 있습니다. 예를 들어 `action`에 `upload_extend`를 전달하고, `audio_id`에 반환된 곡 ID를 전달하면 참고 오디오에 따라 새로운 곡을 생성할 수 있습니다.

## 강화 업로드 모드

일반 업로드로 처리할 수 없는 오디오가 있을 경우, `mode`를 `enhanced`로 설정할 수 있습니다. 이 모드는 1에서 100자 사이의 `name`을 제공해야 하며, 공개적으로 접근 가능한 HTTPS `audio_url`을 사용해야 합니다.

강화 업로드는 고정적으로 비동기 처리되며, 일반적으로 2분 이상 소요됩니다. 성공적으로 처리되면 **1.87 크레딧**이 소모되며, 최대 패키지 기준으로 약 **¥1.20/회**입니다; 처리 실패 시 비용이 발생하지 않습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/upload' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
    "mode": "enhanced",
    "name": "My Song"
  }'
```

인터페이스는 즉시 `task_id`와 `trace_id`를 반환합니다. [Suno Tasks API](https://platform.acedata.cloud/documents/suno-tasks)를 사용하여 작업을 조회하고, 성공 후 `response.data.audio_id`에서 업로드된 오디오 ID를 읽을 수 있습니다. 또한 HTTPS `callback_url`을 제공하여 최종 상태를 받을 수 있습니다.

강화 업로드로 얻은 `audio_id`는 Cover, Samples 및 Mashup에 사용할 수 있습니다. 반주 및 MIDI 추출, 전체 트랙 분리 및 보컬/반주 분리는 여전히 오디오 소속 계정의 제한을 받을 수 있습니다; 나열되지 않은 작업은 계정 간 사용 지원을 보장하지 않습니다. 오디오가 짧을수록 처리 성공률이 일반적으로 높습니다.
