Suno MP3 URL API는 기존 음악에 대해 `.mp3`로 끝나는 재생 가능한 주소를 생성하며, 이는 오래된 다운로드 링크가 유효하지 않거나, 모바일에서 재생하거나, 공개 오디오 URL을 다시 가져와야 하는 상황에 적합합니다.

필수 매개변수 `audio_id`는 Suno 오디오 생성 인터페이스가 반환하는 오디오 ID입니다. 매번 호출할 때마다 독립적인 MP3 URL 작업이 생성되며, 원래 음악 생성 작업을 수정하지 않으며 원 오디오 ID를 변경하지 않습니다.

## 동기 호출

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

성공 시, `data[0].file_url`은 재생 가능한 오디오 주소입니다. 인터페이스는 우선 `https://platform2.cdn.acedata.cloud/suno/{audio_id}.mp3`로 전송합니다; 만약 전송이 30초를 초과하거나 실패하면 현재 사용 가능한 원 오디오 주소를 반환합니다.

## 비동기 호출

처리 시간이 길어질 경우 `async: true`를 전달할 수 있습니다:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

그 후 `/suno/tasks`를 통해 `export_task_id`를 조회합니다. `callback_url`을 제공하여 작업 완료 후 최종 결과를 받을 수도 있습니다. 동기 응답, 작업 조회 및 콜백은 동일한 최종 데이터 구조를 사용합니다.

## 주의 사항

- `audio_id`는 인식 가능한 Suno 오디오에서 가져와야 합니다.
- MP3 URL 작업은 원 음악 생성 작업과 독립적입니다.
- 전송은 최대 30초까지 대기할 수 있으며; 전송이 초과되거나 실패하면 결과를 차단하지 않고 원 오디오 주소로 되돌아갑니다.
- 비즈니스 측에서는 결과를 받은 후 즉시 다운로드하고 자신의 데이터 보존 정책에 따라 저장하는 것이 좋습니다.
