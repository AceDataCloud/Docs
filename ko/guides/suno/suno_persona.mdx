---
title: "Suno 사용자 정의 가수 스타일 API 연동 설명"
description: "Suno Music Generation 集成指南 - Ace Data Cloud"
---

SUNO는 이미 생성된 노래에 대해 가수 스타일을 설정하고 이를 기반으로 2차 창작을 할 수 있도록 허용합니다. 본 문서는 관련 API의 연동 방법을 설명합니다.

이 API는 세 개의 입력 매개변수만 필요합니다. 첫 번째는 `audio_id`로, 이는 공식적으로 생성된 후의 노래 ID입니다. 두 번째는 `name`과 `description`으로, 이는 가수 스타일에 대한 이름과 설명입니다.

여기서 입력하는 `audio_id`는 `https://cdn.acedata.cloud/2qhzs3.png`이며, 이는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 참조하여 사용자 정의 노래 생성을 진행할 수 있습니다. 마지막으로 `audio_id`를 얻을 수 있습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

결과는 다음과 같습니다:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

볼 수 있듯이, `data`의 `persona_id` 필드는 생성된 가수 스타일 ID입니다.

가수 스타일 ID를 얻은 후, 우리는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 사용하여 사용자 정의 노래 생성을 진행할 수 있습니다. 예를 들어 `action`에 `artist_consistency`를 전달하고, `audio_id`에 업로드한 노래 ID를 전달하며, `persona_id` 매개변수를 업로드해야 합니다. 이 값은 위에서 반환된 가수 스타일 ID로, 이를 기반으로 참조한 가수 스타일에 따라 새로운 노래를 생성할 수 있습니다.
