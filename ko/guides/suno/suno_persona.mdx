---
title: "Suno 사용자 정의 가수 스타일 API 연동 안내"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO는 이미 생성된 노래에 가수 스타일을 설정한 후, 이를 기반으로 2차 창작을 할 수 있도록 합니다. 본 문서는 관련 API의 연동 방법을 설명합니다.

`GET /suno/persona` 목록 조회와 `DELETE /suno/persona` 기록 삭제는 과금되지 않으며, 별도의 과금 면제 요청 헤더가 필요하지 않습니다. `POST /suno/persona` 생성 작업은 여전히 인터페이스 요금 규칙에 따라 과금됩니다.

음색 조회를 지원하는 생성 경로에서는 원래 애플리케이션과 호출자 신원을 사용하여, 생성 결과의 `persona_id`를 `POST /suno/availability`에 전달할 수 있습니다. 사용 가능 여부가 확인되면 `data.available=true`가 반환됩니다. [음색 사용 가능 여부 조회 가이드](https://platform.acedata.cloud/documents/suno-availability-integration)

이 API에는 세 개의 입력 매개변수만 있습니다. 먼저 `audio_id`는 공식적으로 생성에 성공한 노래 ID이고, 그다음 `name`, `description`은 가수 스타일에 대한 이름과 설명입니다.

여기서 입력하는 `audio_id`는 `https://cdn.acedata.cloud/2qhzs3.png`이며, 이는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 참고하여 사용자 정의 노래 생성을 진행할 수 있고, 최종적으로 `audio_id`를 얻을 수 있습니다.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

결과는 다음과 같습니다:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

확인할 수 있듯이, `data`의 `persona_id` 필드가 생성된 가수 스타일 ID입니다.

가수 스타일 ID를 얻은 후에는 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios)를 사용하여 사용자 정의 노래 생성을 진행할 수 있습니다. 예를 들어 `action`에 `artist_consistency`를 전달하고, 동시에 `audio_id`에 업로드한 노래 ID를 전달하며, 매개변수 `persona_id`도 업로드해야 합니다. 이 값은 위에서 반환된 가수 스타일 ID이며, 참고한 가수 스타일을 기반으로 새로운 노래를 생성할 수 있습니다.
