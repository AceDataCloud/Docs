AI의 활용이 넓어짐에 따라, 각종 AI 프로그램이 점차 보편화되고 있습니다. AI는 사람들의 업무와 생활의 모든 측면에 점점 더 깊숙이 들어오고 있습니다. AI가 관련된 산업도 점점 더 많아지고 있으며, 처음에는 글쓰기에서 시작하여 의료 교육, 현재는 음악에 이르기까지 다양합니다.

Suno는 전문적이고 고품질의 AI 곡 및 음악 창작 플랫폼으로, 사용자는 간단한 텍스트 프롬프트를 입력하기만 하면 장르 스타일과 가사에 따라 보컬이 포함된 곡을 생성할 수 있습니다. 이 AI 음악 생성기는 Meta, TikTok, Kensho 등 유명 기술 회사의 팀원들이 개발하였으며, 어떤 악기 도구도 필요 없이 모든 사람이 멋진 음악을 창작할 수 있도록 하는 것을 목표로 하고 있습니다.

다음은 모델 업데이트 진행 상황입니다:

| 버전    | model           | 출시일       | prompt 제한 | style 제한 | 곡 최대 길이 |
| ----- | --------------- | ---------- | --------- | -------- | ------ |
| v5    | chirp-v5        | 2025.09.23 | 5000      | 1000     | 8 분   |
| v4.5+ | chirp-v4-5-plus | 2025.07.17 | 5000      | 1000     | 8 분   |
| v4.5  | chirp-v4-5      | 2025.05.03 | 5000      | 1000     | 4 분   |
| v4    | chirp-v4        | 2024.12.17 | 3000      | 200      | 150 초  |
| v3.5  | chirp-v3-5      | ---        | 3000      | 200      | 120 초  |

Suno는 최신 음악 생성 모델을 V5 버전으로 업그레이드하였으며, 최신 V5를 호출하려면 model 매개변수를 `chirp-v5`로 수정하면 9분 길이의 곡을 생성할 수 있습니다.

그러나 Suno 공식은 API를 제공하지 않으며, AceDataCloud는 Suno의 API를 제공하여 Suno 공식과의 연동을 모방하여 원하는 음악을 쉽게 생성할 수 있도록 합니다.

## 신청 및 사용

Suno Audios API를 사용하려면 먼저 [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) 페이지에서 "Acquire" 버튼을 클릭하여 요청에 필요한 자격 증명을 얻을 수 있습니다:

![](https://cdn.acedata.cloud/nyq0xz.png)

로그인 또는 등록이 되어 있지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 초대합니다. 로그인 및 등록 후에는 자동으로 현재 페이지로 돌아옵니다.

첫 번째 신청 시 무료 한도가 제공되어 해당 API를 무료로 사용할 수 있습니다.

## 기본 사용

어떤 곡을 생각하든지, 임의로 텍스트를 입력할 수 있습니다. 예를 들어, 크리스마스에 대한 곡을 생성하고 싶다면 `a song for Christmas`를 입력하면 됩니다. 아래와 같이:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

여기서 우리는 Request Headers를 설정했습니다. 포함된 내용은 다음과 같습니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지, 여기서는 `application/json`으로 JSON 형식으로 작성합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 직접 드롭다운에서 선택할 수 있습니다.

또한 Request Body를 설정했습니다. 포함된 내용은 다음과 같습니다:

- `action`: 이번 음악 생성 작업의 행동으로, 기본값은 `generate`이며, 주요 내용은: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`입니다.
- `prompt`: Suno 공식의 영감 모드의 프롬프트입니다.
- `model`: 이번 음악 생성 작업의 모델로, 기본값은 `chirp-v3-5`이며, 주요 내용은: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`입니다.
- `lyric`: Suno 공식의 사용자 정의 모드의 가사 내용입니다.
- `custom`: 사용자 정의 모드를 사용할지 여부로, 기본값은 `false`입니다.
- `instrumental`: Suno 공식의 영감 모드의 순수 음악 옵션입니다.
- `title`: Suno 공식의 사용자 정의 모드의 음악 제목입니다.
- `style`: Suno 공식의 사용자 정의 모드의 음악 스타일입니다.
- `style_negative`: Suno 공식의 사용자 정의 모드의 제외 스타일입니다.
- `audio_weight`: 업로드된 참조 오디오의 비율로, 범위는 0-1이며, 클수록 참조 오디오에 의존합니다.
- `audio_id`: 참조 음악의 ID입니다.
- `overpainting_start`/`overpainting_end`: 기존 순수 음악에 보컬을 추가하는 시작 및 종료 시간으로, 단위는 초입니다.
- `underpainting_start`/`underpainting_end`: 클린싱에 반주를 추가하는 시작 및 종료 시간으로, 단위는 초입니다.
- `persona_id`: 아티스트의 곡 ID입니다.
- `continue_at`: 기존 오디오를 계속하는 시간을 초 단위로 나타냅니다. 예를 들어, 213.5는 3분 33.5초까지 계속함을 의미합니다.
- `style_influence`: `style_influence` 고급 매개변수입니다.
- `replace_section_end`: 교체 구간의 최종 시간입니다.
- `replace_section_start`: 교체 구간의 시작 시간입니다.
- `vocal_gender`: 남녀 목소리를 제어하며, 여성 목소리는 `f`, 남성 목소리는 `m`으로, 4.5 이상의 모델에서 유효합니다.
- `weirdness`: `weirdness` 고급 매개변수입니다.
- `lyric_prompt`: 가사를 생성하는 프롬프트로, `custom`이 `true`이고 `lyric`이 전달되지 않았을 때만 유효합니다.
- `callback_url`: 결과를 회신받을 URL입니다.

이 시점에서 우리는 두 곡의 내용을 얻었습니다. 제목, 미리보기 이미지, 가사, 오디오, 비디오 등의 내용을 포함합니다.

필드 설명은 다음과 같습니다:

- success: 생성 여부, 성공하면 `true`, 실패하면 `false`
- data: 생성된 곡의 상세 정보를 포함하는 리스트입니다.
  - state: 곡 생성 상태, 주로 네 가지가 있습니다:
    - succeeded: 생성 성공
    - pending: 대기 중
    - running: 실행 중
    - error: 실패
  - id: 곡 ID
  - title: 곡 제목
  - image_url: 곡 커버 이미지
  - lyric: 곡 가사
  - audio_url: 곡 오디오 파일, 열면 mp3 오디오입니다.
  - video_url: 곡 비디오 파일, 열면 mp4 비디오입니다.
  - created_at: 생성 시간
  - model: 사용된 모델, 일반적으로 최신 v3 모델입니다.
  - style: 스타일

## 사용자 정의 생성

가사를 사용자 정의 생성하고 싶다면, 가사를 입력할 수 있습니다:

이때 `lyric` 필드에 다음과 같은 내용을 전달할 수 있습니다:

```
[Verse]\n눈송이가 사방에 떨어지고\n반짝이는 하얀색\n땅을 덮고\n아이들이 웃고\n기쁨으로 가득 차고\n이 겨울의 원더랜드에서 오늘 밤\n산타의 썰매\n하늘 위에\n루돌프의 코가 밝게 빛나고\n오 내\n징글벨 소리가\n명확하게 울리고\n기쁨과 휴일의 즐거움을 가져오고\n[Verse 2]\n난로의 불빛 옆에서 밤밤을 굽고\n크리스마스 불빛\n반짝이고 보여주고\n가족들이 사랑과 기쁨으로 모이고\n주변의 모든 이에게 따뜻함을 전하고
```

> 주의: 여기서 가사 중 `\n`은 줄 바꿈 기호입니다. 가사를 생성하는 방법을 모른다면, AceDataCloud에서 제공하는 가사 생성 API를 사용하여 프롬프트를 통해 가사를 생성할 수 있습니다. API는 [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics)입니다.

다음으로 가사, 제목, 스타일에 따라 곡을 사용자 정의 생성하려면 다음과 같은 내용을 지정할 수 있습니다:

- lyric: 가사 텍스트
- custom: `true`로 입력하여 사용자 정의 생성을 나타내며, 이 매개변수는 기본적으로 false로 설정되어 프롬프트 생성을 사용합니다.
- title: 곡 제목.
- style: 곡 스타일, 선택 사항입니다.

## 사용자 정의 가수 스타일 생성을 위한 기능
만약 가수 스타일을 사용하여 곡을 생성하고 싶다면, 먼저 위의 기본 사용법을 통해 곡을 생성해야 합니다. 마지막으로 이 곡을 가수 스타일로 설정해야 하며, [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona)에 들어가서 공식적으로 생성된 음악 ID `audio_id`를 사용하여 가수 스타일의 ID 매개변수 `persona_id`를 생성해야 합니다. 구체적인 매개변수는 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

작성 완료 후 자동으로 생성된 코드는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

해당 Python 코드:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 계속 생성 기능

이미 생성된 Suno 곡을 계속 생성하고 싶다면, 매개변수 `action`을 `extend`로 설정하고 계속 생성할 곡의 ID를 입력해야 합니다. 곡 ID는 기본 사용법에 따라 얻을 수 있으며, 위의 내용을 통해 이때 곡의 ID는 다음과 같습니다:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> 주의: 여기서 가사 중 `id`는 생성된 곡의 ID입니다. 곡을 생성하는 방법을 모른다면, 위의 기본 사용법을 참조하여 곡을 생성할 수 있습니다.

자신이 업로드한 곡을 계속 생성하고 싶다면, 매개변수 `action`을 `upload_extend`로 설정하고 계속 생성할 사용자 정의 업로드 곡 ID를 입력해야 합니다. 곡 ID는 [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload)를 사용하여 얻을 수 있으며, 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

다음으로 우리는 가사, 스타일을 사용자 정의하여 곡을 생성해야 하며, 다음과 같은 내용을 지정할 수 있습니다:

- lyric: 가사 텍스트
- custom: `true`로 설정하여 사용자 정의 생성을 나타냅니다. 이 매개변수는 기본적으로 false로 설정되어 있으며, `prompt` 생성을 사용합니다.
- style: 곡의 스타일, 선택 사항입니다.
- continue_at: 초 단위로 현재 오디오의 시간을 계속합니다. 예를 들어, 213.5는 3분 33.5초까지 계속함을 의미합니다.

## 전체 노래 가져오기

- action: 내용은 `concat`입니다.

```json
{

}
```

## 구간 교체

노래를 생성한 후 특정 노래 구간을 교체하는 2차 창작 작업이 필요할 때, 노래의 특정 구간을 교체할 수 있습니다. 다음과 같은 내용을 지정할 수 있습니다:

- action: 내용은 `replace_section`입니다.
- audio_id: 이전에 생성된 노래의 ID입니다.
- model: 노래 생성 모델입니다.
- lyric: 교체된 전체 가사(프롬프트와 중복되는 부분만 필요하며, 전체 가사는 필요하지 않음)입니다.
- prompt: 교체할 가사 부분입니다.
- style: 노래의 스타일, 선택 사항입니다.
- replace_section_start: `lyric`에 해당하는 가사의 타임라인 시작 시간입니다.
- replace_section_end: `lyric`에 해당하는 가사의 타임라인 종료 시간입니다.

예를 들어, 원래 생성된 노래의 ID가: ade7241b-0357-4a5e-9b3d-4ec4f4b3a0c0이라면, 매개변수를 다음과 같이 설정할 수 있습니다:


## 비동기 콜백

Suno가 음악을 생성하는 데 시간이 상대적으로 길어 약 1-2분이 소요되므로, API가 오랜 시간 응답하지 않으면 HTTP 요청이 계속 연결을 유지하여 추가적인 시스템 자원 소모를 초래할 수 있습니다. 따라서 이 API는 비동기 콜백 지원도 제공합니다.

전체 프로세스는 다음과 같습니다: 클라이언트가 요청을 시작할 때 추가로 `callback_url` 필드를 지정하고, 클라이언트가 API 요청을 시작한 후 API는 즉시 결과를 반환하며, 여기에는 현재 작업 ID를 나타내는 `task_id` 필드 정보가 포함됩니다. 작업이 완료되면 생성된 음악 결과가 POST JSON 형식으로 클라이언트가 지정한 `callback_url`로 전송되며, 여기에도 `task_id` 필드가 포함되어 있어 작업 결과를 ID로 연결할 수 있습니다.

아래 예제를 통해 구체적으로 어떻게 작업하는지 알아보겠습니다.
