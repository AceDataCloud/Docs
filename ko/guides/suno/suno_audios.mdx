AI의 활용이 넓어짐에 따라, 각종 AI 프로그램이 점차 보급되고 있습니다. AI는 사람들의 업무와 생활의 모든 측면에 점점 더 깊숙이 들어오고 있습니다. AI가 관련된 산업도 점점 더 많아지고 있으며, 처음에는 글쓰기에서 시작하여 의료 교육, 현재는 음악에 이르기까지 다양합니다.

Suno는 전문 고품질 AI 곡 및 음악 창작 플랫폼으로, 사용자는 간단한 텍스트 프롬프트만 입력하면 장르 스타일과 가사에 따라 보컬이 포함된 곡을 생성할 수 있습니다. 이 AI 음악 생성기는 Meta, TikTok, Kensho 등 유명 기술 회사의 팀원들이 개발하였으며, 목표는 어떤 악기 도구 없이도 모든 사람이 멋진 음악을 창작할 수 있도록 하는 것입니다.

다음은 모델 업데이트 진행 상황입니다:

| 버전    | model           | 출시일       | lyric 제한 | style 제한 | 곡 최대 길이 |
| ----- | --------------- | ---------- | -------- | -------- | ------ |
| v5.5  | chirp-v5-5      | 2026.03.27 | 5000     | 1000     | 8 분    |
| v5    | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 분    |
| v4.5+ | chirp-v4-5-plus | 2025.07.17 | 5000     | 1000     | 8 분    |
| v4.5  | chirp-v4-5      | 2025.05.03 | 5000     | 1000     | 4 분    |
| v4    | chirp-v4        | 2024.12.17 | 3000     | 200      | 150 초  |
| v3.5  | chirp-v3-5      | ---        | 3000     | 200      | 120 초  |

> 위 표의 `lyric` 및 `style` 제한은 사용자 정의 모드(`custom`이 `true`인 경우)에서의 상한입니다. 비사용자 정의 영감 모드(`custom`이 `false`인 경우)는 `prompt`만 입력하며, 그 길이 상한은 500 문자(모델별 동일)입니다.

Suno는 현재 최신 `chirp-v5-5` 모델을 지원합니다. 최신 버전을 호출할 때는 `model` 매개변수를 `chirp-v5-5`로 설정하면 됩니다; `chirp-v5` 및 이전 버전도 계속 사용할 수 있습니다.

그러나 Suno 공식은 API를 제공하지 않으며, AceDataCloud는 Suno의 API를 제공하여 Suno 공식과의 연동을 모방하여 원하는 음악을 쉽게 생성할 수 있도록 합니다.

## 신청 및 사용

Suno Audios Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 받아두세요.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

로그인 또는 등록이 되어 있지 않으면 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 초대합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 처음 신청 시 무료 한도가 제공되어 무료로 체험할 수 있으며, 한도가 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## 기본 사용

어떤 곡을 원하든지 자유롭게 텍스트를 입력할 수 있습니다. 예를 들어, 크리스마스에 관한 곡을 생성하고 싶다면 `a song for Christmas`라고 입력하면 됩니다. 아래와 같이:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

여기서 우리는 Request Headers를 설정했습니다. 포함된 내용은 다음과 같습니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지, 여기서는 `application/json`으로 JSON 형식으로 입력합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 바로 드롭다운에서 선택할 수 있습니다.

또한 Request Body를 설정했습니다.
- `action`：이번 음악 생성 작업의 행동, 기본값은 `generate`이며, 주로 포함되는 항목: `extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`。
- `prompt`：Suno 공식의 영감 모드 프롬프트( `custom`이 `false`일 때 유효), 최대 500자.
- `model`：이번 음악 생성 작업의 모델, 기본값은 `chirp-v4`이며, 주로 포함되는 항목: `chirp-v3`、`chirp-v4`、`chirp-v3-5`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`。
- `lyric`：Suno 공식의 사용자 정의 모드의 가사 내용. `chirp-v3-5`와 `chirp-v4` 최대 3000자; `chirp-v4-5` 이상(포함 `chirp-v5`, `chirp-v5-5`) 최대 5000자.
- `custom`：사용자 정의 모드를 사용할지 여부, 기본값은: `false`.
- `instrumental`：Suno 공식의 영감 모드의 순수 음악 옵션.
- `title`：Suno 공식의 사용자 정의 모드의 음악 제목. `chirp-v3-5`, `chirp-v4` 최대 80자; `chirp-v4-5` 이상 최대 100자.
- `style`：Suno 공식의 사용자 정의 모드 음악 스타일. `chirp-v3-5`와 `chirp-v4` 최대 200자; `chirp-v4-5` 이상(포함 `chirp-v5`, `chirp-v5-5`) 최대 1000자.
- `negative_tags`：사용자 정의 모드( `custom`이 `true`일 때)에서 생성 결과에서 제외하고 싶은 음악 스타일 또는 장르.
- `audio_weight`：업로드된 참조 오디오의 비율, 범위 0-1, 클수록 참조 오디오에 의존.
- `audio_id`：참조 음악의 ID.
- `overpainting_start`/`overpainting_end`：기존 순수 음악에 보컬을 추가하는 시작 및 종료 시간, 단위 초.
- `underpainting_start`/`underpainting_end`：청창에 반주를 추가하는 시작 및 종료 시간, 단위 초.
- `persona_id`：아티스트의 곡 ID.
- `continue_at`：초 단위로 기존 오디오를 계속하는 시간. 예를 들어, 213.5는 3분 33.5초까지 계속함을 의미.
- `style_influence`：사용자 정의 모드의 "Style Influence" 고급 매개변수, 범위 0-1, 클수록 선택한 스타일에 더 부합.
- `replace_section_end`：대체 구간의 최종 시간.
- `replace_section_start`：대체 구간의 시작 시간.
- `vocal_gender`：남녀 목소리 선호를 제어, 여성 목소리 `f`, 남성 목소리 `m`, 4.5 이상 모델에서 유효; 선호 항목으로, 엄격히 준수하지 않음.
- `weirdness`：사용자 정의 모드의 "Weirdness" 고급 매개변수, 범위 0-1, 클수록 더 창의적이고 실험적.
- `duration`：기대하는 곡 길이, 단위 초, 정수여야 하며, 값 범위 10에서 360. 이 매개변수는 사용자 정의 모드( `custom`이 `true`일 때)의 곡 생성에 사용됨. 이는 경향성 프롬프트이며 강제 제약이 아님: 모델은 이를 참조하지만 보장하지 않으며, 실제 결과물의 길이는 응답의 `duration` 필드에 따라 다르며, 일반적으로 기대값보다 짧음.
- `lyric_prompt`：가사를 생성하는 프롬프트, 오직 `custom`이 `true`이고 `lyric`이 전달되지 않았을 때 유효.
- `callback_url`：결과를 회신받을 URL.
- `async`：선택 사항, `true`로 설정 시 인터페이스가 즉시 `task_id`를 반환하며, `callback_url`을 제공할 필요가 없고, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 얻음.

## 사용자 정의 생성

가사를 사용자 정의 생성하고 싶다면, 가사를 입력할 수 있습니다:

이때 `lyric` 필드에 다음과 같은 내용을 전달할 수 있습니다:

```
[Verse]\n눈송이가 사방에 떨어지고\n반짝이는 흰색\n땅을 덮고\n아이들이 웃고\n기쁨으로 가득 차고\n오늘 밤 이 겨울 원더랜드에서\n산타의 썰매\n하늘 위에\n루돌프의 코가 밝게 빛나고\n오 마이\n징글벨 소리가\n명확하게 울리고\n기쁨과 휴일의 즐거움을 가져옵니다\n[Verse 2]\n난로의 불빛 옆에서 구운 밤\n크리스마스 조명\n반짝이고 보여주고\n가족들이 사랑과 기쁨으로 모이고\n주변 모든 이에게 따뜻함을 전합니다
```

> 주의: 여기서 가사 중 `\n`은 줄 바꿈 기호입니다. 가사를 생성하는 방법을 모른다면, AceDataCloud에서 제공하는 가사 생성 API를 사용하여 프롬프트를 통해 가사를 생성할 수 있습니다. API는 [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics)입니다.

다음으로 가사, 제목, 스타일에 따라 곡을 사용자 정의 생성하려면 다음과 같은 내용을 지정할 수 있습니다:

- lyric: 가사 텍스트
- custom: `true`로 입력하여 사용자 정의 생성을 나타내며, 이 매개변수는 기본적으로 false로 설정되어 프롬프트 생성을 사용합니다.
- title: 곡 제목.
- style: 곡 스타일, 선택 사항입니다.

## 전체 노래 가져오기

- action: 내용은 `concat`입니다.
- audio_id: 마지막 조각의 ID입니다.

```json
{
  "action": "concat",
  "audio_id": "0a1e1b10-c36a-41c9-9bfb-b26d9d25db98"
}
```

## 음악 번안
기존의 노곡을 바탕으로 노곡을 계속 생성한 후, 반환된 노곡의 스타일이 적합하지 않을 수 있습니다. 원래 생성된 노곡(사용자가 업로드한 음악도 지원됨)을 커버하려면 음악 커버 방법을 사용해야 하며, 다음과 같은 내용을 지정할 수 있습니다:

- action: 내용은 `cover`이며, 사용자가 업로드한 음악에 대해 커버 작업을 수행할 때는 반드시 내용이 `upload_cover`로 지정되어야 합니다.
- audio_id: 이전에 생성된 노곡의 ID입니다.

예를 들어, 원래 생성된 노곡의 ID가: 0a1e1b10-c36a-41c9-9bfb-b26d9d25db98이라면, 매개변수를 다음과 같이 설정할 수 있습니다:

```json
{
```

## 구간 교체

노곡을 생성한 후 특정 노곡 구간을 교체하는 2차 창작 작업이 필요할 때, 노곡의 특정 구간을 교체할 수 있습니다.

> ⚠️ **주의**: `replace_section`을 단독으로 사용할 경우 **새로 생성된 "교체 구간" 자체만 반환됩니다** (즉, 교체된 그 구간의 새로운 오디오로, 길이는 대략 `replace_section_end - replace_section_start`와 같으며, 약간의 맥락이 포함됩니다). 원곡과 연결된 완전한 결과물을 얻으려면 `replace_section`이 성공한 후 반환된 구간 ID에 대해 다시 [음악 연결](#음악-연결) 작업을 시작해야 합니다. 전체 프로세스는 아래에 설명되어 있습니다.

매개변수 설명은 다음과 같습니다:

- action: 내용은 `replace_section`입니다.
- audio_id: 원본 노곡(교체되는 소스 노곡)의 ID입니다.
- model: 노곡 생성 모델입니다.
- lyric: 교체된 전체 가사(교체된 구간 및 그 맥락 포함, `prompt`의 내용과 일치해야 함)입니다.
- prompt: 교체할 새로운 가사입니다.
- style: 노곡의 스타일, 선택 사항입니다.
- replace_section_start: 교체된 구간이 원곡에서 시작되는 시간(초)입니다.
- replace_section_end: 교체된 구간이 원곡에서 종료되는 시간(초)입니다.

## 곡 길이 조절

기본적으로 생성된 곡의 길이는 모델이 스스로 결정하며, 일반적으로 30초에서 4분 사이입니다. 더 길거나 짧은 결과물이 필요할 경우 `duration` 매개변수를 통해 원하는 길이를 지정할 수 있으며, 단위는 초로 10에서 360 사이의 정수 값을 사용합니다.

이 매개변수는 사용자 정의 모드(`custom`이 `true`인 경우)에서 곡 생성에 사용됩니다. 특히 주의할 점은 `duration`이 **경향성 힌트일 뿐 강제 제약이 아니라는 것**입니다: 모델은 이 값을 참고하여 창작하지만, 이를 보장하지는 않습니다. 실제로 측정된 길이는 일반적으로 기대값보다 현저히 짧으며, 동일한 요청에서 반환된 두 곡의 길이도 수배 차이가 날 수 있습니다. 완전히 동일한 요청이라도 여러 번 제출했을 때 얻는 길이는 큰 차이를 보일 수 있습니다. 따라서 이를 정확한 길이 조절로 사용하지 마시고, 비즈니스적으로 고정된 길이가 필요하다면 결과물을 받은 후 직접 잘라내거나 재시도하시기 바랍니다.

해당하는 Python 코드:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "도시의 불빛 아래",
    "style": "로파이 피아노",
    "lyric": "[Verse]\n해가 뜨고\n바닥에 금빛\n[Chorus]\n도시의 불빛 아래\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

주의할 점은 요청의 `duration`이 **기대 길이**이며, 응답 `data`의 각 곡의 `duration` 필드는 해당 곡의 **실제 길이**입니다. 두 이름은 같지만 의미가 다르며, 실제 길이가 기대값과 같지 않을 수 있습니다. 가사 길이는 결과물 길이에 영향을 미치는 주요 요소 중 하나이며, 긴 결과물이 필요할 경우 더 완전한 가사를 제공하는 것이 좋습니다.

인터페이스는 `duration`에 대해 추가 검증을 하지 않으며, 매개변수는 그대로 모델에 전달됩니다. 현재 모드나 모델이 지원하지 않는 값을 입력하면 해당 값이 무시될 수 있으므로, 먼저 한 번 요청하여 효과를 확인한 후 일괄 사용하시기 바랍니다.

## Remaster 기능

2025년 12월에 suno에서 새롭게 출시한 Remaster 기능은, 이 기능을 통해 노래를 재생성할 수 있으며, 계정 간의 이동은 불가능합니다. 그리고 다음과 같은 매개변수를 입력해야 합니다:

- action: 내용은 `remaster`입니다.
- audio_id: 재생성할 노래의 ID입니다.
- model: v4.5+ 및 v5만 지원합니다.
- variation_category: v5 이상 버전에서만 지원되며, 3개의 값 high, normal, subtle만 가능합니다.

모든 입력이 완료되면 자동으로 다음과 같은 코드가 생성됩니다:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "remaster",
    "variation_category": "high",
    "audio_id": "21fd46d4-45c3-4826-bec9-3f3df667902e"
```

## Inspo 영감 창작 기능

Suno에서 새롭게 출시한 Inspo 영감 창작 기능은 1에서 4개의 참고 오디오를 영감의 원천으로 삼아 전혀 새로운 음악을 생성할 수 있습니다. 커버와는 달리, Inspo는 원곡을 복제하지 않고, 참고 오디오에서 스타일 영감을 추출하여, 프롬프트, 스타일 태그 등을 결합하여 새로운 작품을 생성합니다. 사용 시 다음과 같은 매개변수를 입력해야 합니다:

- action: 내용은 `inspo`입니다.
- audio_urls: 참고 오디오의 URL 목록으로, 1에서 4개의 공개적으로 접근 가능한 오디오 주소를 제공해야 합니다.
- model: 사용되는 모델, 예를 들어 `chirp-v5`입니다.
- prompt: 가사 또는 창작 프롬프트(선택 사항).
- tags: 음악 스타일 태그, 예를 들어 `acoustic, folk, warm`(선택 사항).
- title: 곡 제목(선택 사항).
- audio_weight: 생성 결과에 대한 참고 오디오의 영향 가중치, 값 범위는 0에서 1(선택 사항).

> 설명: 참고 오디오는 공개적으로 접근 가능한 오디오 파일이어야 합니다. 참고 오디오가 플랫폼 곡 라이브러리의 알려진 녹음과 완전히 일치할 경우, Suno는 저작권 검증으로 인해 생성을 거부할 수 있으므로, 자사 또는 Suno에서 생성한 오디오를 영감의 원천으로 사용하는 것이 좋습니다.

해당하는 Python 코드:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "따뜻한 어쿠스틱 포크와 부드러운 보컬",
    "tags": "어쿠스틱, 포크, 따뜻함",
    "title": "Inspo 데모",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 비동기 콜백

Suno가 음악을 생성하는 데 시간이 상대적으로 길어 약 1-2분이 소요되므로, API가 오랜 시간 응답하지 않으면 HTTP 요청이 계속 연결을 유지하여 추가 시스템 리소스 소모를 초래할 수 있습니다. 따라서 이 API는 비동기 콜백 지원도 제공합니다.

전체 프로세스는 클라이언트가 요청을 시작할 때 추가로 `callback_url` 필드를 지정하는 것입니다. 클라이언트가 API 요청을 시작한 후, API는 즉시 결과를 반환하며, 현재 작업 ID를 나타내는 `task_id` 필드 정보를 포함합니다. 작업이 완료되면 생성된 음악 결과가 POST JSON 형식으로 클라이언트가 지정한 `callback_url`로 전송되며, 여기에도 `task_id` 필드가 포함되어 있어 작업 결과를 ID로 연결할 수 있습니다.
