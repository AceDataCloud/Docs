`POST https://api.acedata.cloud/suno/projects`는 멀티트랙 프로젝트를 관리하는 Beta 인터페이스입니다. 하나의 엔드포인트는 `action`을 통해 생성, 저장, 후보 생성, 후보 제출 및 내보내기를 구분합니다. 호출자는 아래의 공개 필드만 사용하면 되며, 하위 생성 서비스의 내부 요청 구조를 작성할 필요가 없습니다.

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
Idempotency-Key: 每次修改操作使用新的 UUID
```

`retrieve`를 제외하고, **모든 작업에는** `Idempotency-Key`가 필요합니다. 동일한 키와 동일한 요청은 원래 결과만 다시 읽어 오며, 동일한 키에 다른 요청을 사용하면 409를 반환합니다. 유료 생성에서 네트워크 시간 초과가 발생하거나 제출 결과가 불확실한 경우, 먼저 원래 작업 ID 또는 동일한 멱등성 키로 조회해야 하며, 직접 키를 변경하여 재전송하면 안 됩니다.

## 먼저 이러한 ID와 시간 단위를 구분하십시오

| 이름                             | 획득 위치                                                                                      | 사용 위치                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `id`                           | `create` 응답 `data.id`                                                                      | 현재 프로젝트의 모든 후속 요청                                      |
| `version_id`                   | 가장 최근의 `retrieve`, `save`, `add_track`, `commit_candidate` 또는 `remove_track`의 `data.version_id` | 수정, 후보 생성 및 내보내기; 최신 버전을 반드시 사용                              |
| `audio_id` / `source_audio_id` | `upload` 최종 상태의 `response.data.candidate.audio_id`, 또는 기존의 완료된 오디오 ID                                | `add_track`, 생성 또는 교체 시 원본 오디오 참조                          |
| `render_audio_id`              | `render` 최종 상태의 `response.data.audio_id`                                                       | `generate_track`의 프로젝트 믹스 참조                         |
| `operation_id`                 | `generate_track` 또는 `replace_section` 최종 상태의 `response.data.operation_id`                       | `commit_candidate`; 일반적으로 생성 작업의 `task_id`와 같지만 반환값을 읽어야 함 |
| `candidate_id`                 | 생성 최종 상태의 `response.data.candidates[].id`                                                       | 하나의 후보를 선택하여 제출                                         |
| `track_id`                     | 프로젝트 `data.state.tracks[].id`                                                                | 후보 제출 또는 트랙 삭제                                        |
| `task_id`                      | 비동기 작업 제출 응답                                                                                   | `/suno/tasks`를 사용하여 최종 상태 조회; 프로젝트 ID가 아님                   |

`start_seconds` / `end_seconds`는 **원본 오디오 내의 초 단위**이고, `start_beats` / `end_beats`는 **프로젝트 타임라인상의 박자 수**입니다. `state.timing.bps`는 초당 박자 수이며, 기본값은 2입니다. 예를 들어 41초 길이의 클립이 0박자에서 시작하면 기본 종료점은 82박자입니다. `generate_track`의 초 단위 구간은 생성 참조를 지정하는 데 사용되며, 후보가 해당 구간의 길이만 갖는다고 보장하지 않습니다.

## 작업 순서와 결과 판정

| 순서  | `action`                             | 기능                         | 반환 방식         |
| --- | ------------------------------------ | -------------------------- | ------------ |
| 1   | `create`                             | 빈 프로젝트 생성                      | 동기 프로젝트 데이터       |
| 2   | `retrieve`                           | 최신 버전과 전체 `state` 읽기          | 동기 프로젝트 데이터       |
| 3   | `save`                               | 최초 저장 또는 수정된 `state` 전체 저장      | 동기 프로젝트 데이터       |
| 4   | `upload`                             | HTTPS 오디오 주소에서 소스 생성           | 비동기 작업         |
| 5   | `add_track`                          | 소스 오디오를 프로젝트에 추가                  | 비동기 작업, 버전 업데이트    |
| 6   | `save`                               | 새 트랙 후보를 받으려면 먼저 빈 대상 트랙 저장        | 동기 프로젝트 데이터, 버전 업데이트  |
| 7   | `render`                             | 현재 재생 가능한 트랙 내보내기 및 믹스 참조 `audio_id` 획득 | 비동기 작업         |
| 8   | `generate_track` 또는 `replace_section` | 각각 새 트랙 후보 생성 또는 부분 교체 후보 생성            | 비동기 작업, 아직 프로젝트 수정 안 함  |
| 9   | `commit_candidate`                   | 하나의 후보 선택 및 제출                  | 비동기 작업, 성공 후 버전 업데이트 |
| 선택  | `remove_track`                       | 지정된 트랙 삭제                     | 동기 프로젝트 데이터, 버전 업데이트  |

부분 교체만 수행하는 경우, 이미 사용 가능한 원본 오디오가 있으면 되므로 먼저 `render`할 필요가 없습니다. 원본 오디오가 이미 프로젝트에 있는 경우 `upload`와 `add_track`도 건너뛸 수 있습니다. `render_audio_id`는 `generate_track`에만 필수인 참조입니다.

비동기 작업 제출 시 먼저 `{ "task_id": "...", "trace_id": "..." }`를 반환하며, **생성 성공을 의미하지는 않습니다**. 폴링:

```http
POST /suno/tasks
Content-Type: application/json

{"action":"retrieve","id":"上一步返回的 task_id"}
```

작업 기록에 `finished_at`이 있고 그 안의 `response.success`가 `true`여야 성공으로 간주합니다. `response.success=false`인 경우 `response.error`를 읽으십시오. `save`는 `task_id`를 포함할 수 있지만, 이 인터페이스에서는 동기적으로 완료됩니다. `upload`, `render`, `generate_track`, `replace_section`은 프로젝트 버전을 수정하지 않으며, `save`, `add_track`, `commit_candidate`, `remove_track`가 성공한 후에는 새 `version_id`를 가져와야 합니다.

## 요청 매개변수

### 공통 필드와 요청 헤더

| 매개변수                | 유형 및 적용 범위                                                                                   | 설명                                                              |
| ----------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `action`          | 필수 문자열                                                                                     | 이 페이지에 나열된 작업 이름 중 하나로 고정되며, 하나의 요청은 하나의 작업만 실행합니다.                                      |
| `id`              | `create` 외 필수 문자열                                                                         | 프로젝트 ID, `create.data.id`에서 가져옵니다.                                      |
| `version_id`      | 수정, 후보 생성, 내보내기 시 필수 문자열; 최초 빈 프로젝트 `save`에서는 생략 가능                                                         | 최신 버전을 사용해야 하며, 이전 버전은 거부됩니다. `retrieve`에는 필요하지 않습니다.                                 |
| `Idempotency-Key` | `retrieve` 외 필수 요청 헤더, 1–128자                                                              | 각 새 작업에 새 키를 사용하십시오. 동일 키와 동일 요청은 원래 결과를 다시 읽어 오며, 다시 생성하거나 과금하지 않습니다.                                   |
| `async`           | `upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`, `render`에서 선택적 불리언 값 | 이러한 작업은 항상 비동기이며, `false`도 생성을 동기로 변경하지 않습니다.                                    |
| `callback_url`    | 위의 선택적 비동기 필드가 있는 작업에서 선택적 URL                                                                       | 최종 상태 알림을 수신합니다. 생략 시 `task_id`에 따라 `/suno/tasks`를 조회합니다. 여전히 `response.success`를 확인해야 합니다. |

### 프로젝트와 소스
| `action`       | 전용 매개변수                        | 유형 및 조건                            | 설명                                                                 |
| -------------- | --------------------------- | -------------------------------- | ------------------------------------------------------------------ |
| `create`       | `title`                     | 필수 문자열, 1–200자                   | 새 프로젝트 제목.                                                             |
| `retrieve`     | 없음                           | —                                | `action`과 프로젝트 `id`만 필요; 완전한 편집 가능 `state`를 반환.                              |
| `save`         | `state`                     | 필수 객체                             | 프로젝트 상태를 **전체 교체**하며, 부분 패치가 아님. 가장 최근의 `retrieve.data.state`를 기반으로 수정하여 완전히 제출하고, 알 수 없는 필드를 보존. |
| `save`         | `title`                     | 선택 문자열                            | 프로젝트 제목; 생략 시 `state.title`을 유지하고, 그것도 없으면 기본 제목 사용.                              |
| `upload`       | `audio_url`                 | 필수 HTTPS URL                     | 공개적으로 접근 가능한 오디오 소재 주소; 성공 후 최종 상태의 `candidate.audio_id`를 읽음. 소재는 호출자가 사용 권한을 보유해야 함.            |
| `add_track`    | `audio_id`                  | 필수 문자열                            | 완료된 소재의 오디오 ID이며, URL이 아님.                                                |
| `add_track`    | `name` / `color`            | 선택 문자열                            | 새 트랙 이름, 색상; 이름은 기본적으로 오디오 제목을 사용하고, 색상은 `#RRGGBB` 권장, 기본값은 `#7251F7`.                    |
| `add_track`    | `title`                     | 선택 문자열                            | 동시에 프로젝트 제목 수정; 일반적으로 생략.                                                     |
| `add_track`    | `start_beats` / `end_beats` | 선택적 음수가 아닌 숫자, `end_beats > start_beats` | 프로젝트 타임라인에서의 클립 위치. 시작점 기본값은 0; 종료점 기본값은 `시작점 + 오디오 길이 × timing.bps`.                  |
| `add_track`    | `gain`                      | 선택적 음수가 아닌 숫자, 기본값 1                      | 클립 및 새 트랙의 볼륨 계수.                                                       |
| `remove_track` | `track_id`                  | 필수 문자열                            | 삭제할 기존 트랙 ID. 성공 후 반환된 새 버전을 사용.                                           |

`state.timing.bps`는 반드시 양수여야 하며, 기본값은 2이다. `state.tracks`는 트랙 배열이다; 기존 오디오 클립의 `clipId`는 오디오 ID를 참조하고, `startBeats`, `endBeats`, `readStartBeats`는 프로젝트 비트 단위를 사용한다. 가장 안전한 편집 방식은 완전한 `state`를 읽고, 대상 트랙 또는 클립만 수정한 다음 전체 `save`하는 것이다. 새 빈 대상 트랙에는 최소한 고유한 `id`, `type:"audio"`, `clips:[]`가 있어야 한다; 실제로 사용할 수 있는 완전한 형태는 아래 5단계를 참조. 오디오 분석 결과의 비트 지점을 프로젝트 타임라인 좌표로 직접 사용하지 말 것.

### 생성, 제출 및 내보내기
| `action`                             | 전용 매개변수                           | 유형 및 조건                                  | 설명                                                                                                                                                        |
| ------------------------------------ | ---------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generate_track` / `replace_section` | `source_audio_id`                  | 필수 문자열                                  | 완료된 소스 오디오 ID입니다. 먼저 소스 오디오를 프로젝트에 추가해야 후속 후보가 해당 위치를 찾을 수 있습니다.                                                                                                                        |
| `generate_track` / `replace_section` | `model`                            | 필수 열거형 문자열                                | `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`, `chirp-v6`, `chirp-v6-wild`, `chirp-v6-mini` 중에서 선택할 수 있습니다. 모델과 작업의 사용 가능 여부는 작업 최종 상태를 기준으로 하며, 다른 모델로 자동 변경되지 않습니다. |
| `generate_track` / `replace_section` | `start_seconds` / `end_seconds`    | 필수 숫자, `0 ≤ start_seconds &lt; end_seconds` | 소스 오디오 내의 시작 및 종료 초입니다. 교체 시 종료점은 소스 오디오의 실제 길이를 초과해서는 안 됩니다. 이들은 프로젝트 박자 수가 아니며, 후보 출력 길이를 보장하지도 않습니다.                                                                                                         |
| `generate_track`                     | `render_audio_id`                  | 필수 문자열                                  | 현재 프로젝트가 성공적으로 `render`된 후의 `response.data.audio_id`이며, 생성 시 믹싱 참조로 사용됩니다.                                                                                                   |
| `generate_track`                     | `stem_control_tags`                | 필수 문자열                                  | 새 파트 설명입니다. 예: `add Piano`, `add Drums`, `add Bass`; 고정 열거형이 아닙니다.                                                                                                      |
| `generate_track`                     | `batch_size`                       | 선택 정수 1–4, 기본값 2                          | 요청하여 생성할 후보 수입니다.                                                                                                                                                |
| `generate_track`                     | `instrumental` / `vocal_gender`    | 선택 불리언 값／열거형 문자열                            | `instrumental`의 기본값은 `true`입니다. 보컬 선호에는 `f`, `m`, `unspecified`을 입력할 수 있으며, 기본값은 `unspecified`입니다. 선호가 준수되는지는 실제 오디오를 기준으로 합니다.                                                                     |
| `generate_track` / `replace_section` | `title` / `tags` / `negative_tags` | 선택 문자열                                  | 후보 제목, 원하는 스타일 설명, 피하고 싶은 스타일 태그입니다. `tags` 및 `negative_tags`를 생략할 때는 빈 문자열을 전달합니다.                                                                                                  |
| `generate_track`                     | `prompt`                           | 선택 문자열                                  | 새 파트의 텍스트 또는 가사 프롬프트입니다. 순수 연주는 생략할 수 있습니다.                                                                                                                                       |
| `replace_section`                    | `prompt` / `replacement_lyrics`    | 선택 문자열                                  | 전자는 원곡 가사 또는 컨텍스트 텍스트이고, 후자는 교체 구간의 새 가사입니다. 생략할 때는 빈 문자열을 전달합니다.                                                                                                                      |
| `replace_section`                    | `fixed`                            | 선택 불리언 값, 기본값 `false`                       | 고정 길이 교체를 요청합니다. `true`일 경우 구간은 26초보다 짧아야 하며, 선택한 모델이 지원하지 않을 수 있습니다. 이번 실제 예시는 기본 모드를 사용했으며, `fixed=true`는 아직 검증되지 않았습니다.                                                                                    |
| `commit_candidate`                   | `operation_id` / `candidate_id`    | 필수 문자열                                  | 각각 생성 최종 상태의 `data.operation_id` 및 선택한 `data.candidates[].id`를 사용합니다. 후보는 현재 프로젝트 버전에 속해야 합니다.                                                                                    |
| `commit_candidate`                   | `track_id`                         | 필수 문자열                                  | 새 트랙 후보는 **생성 전에 저장된 빈 트랙**에 커밋해야 합니다. 로컬 교체 후보는 유일한 소스 클립을 포함한 원래 트랙에 커밋합니다.                                                                                                              |
| `commit_candidate`                   | `start_beats` / `end_beats`        | 새 트랙 후보에만 선택 가능한 음수가 아닌 숫자                           | 새 클립의 프로젝트 타임라인 위치를 지정합니다. 생략하면 소스 클립 시작점을 따르고 후보의 실제 길이에 따라 종료점을 계산합니다. 대상 트랙의 기존 클립과 겹쳐서는 안 됩니다. **로컬 교체 후보는 반드시 생략해야 합니다**.                                                                                      |
| `commit_candidate`                   | `name` / `gain`                    | 새 트랙 후보에만 선택 가능한 문자열／음수가 아닌 숫자                       | 생성 클립 이름과 볼륨 계수이며, `gain`의 기본값은 1입니다.                                                                                                                                  |
| `render`                             | `title`                            | 필수 문자열                                  | 내보낼 오디오 제목입니다.                                                                                                                                                   |
| `render`                             | `lyrics` / `tags`                  | 선택 문자열                                  | 내보낼 때의 가사 텍스트와 스타일 설명입니다. 가사의 기본값은 `[Instrumental]`입니다.                                                                                                                      |
| `render`                             | `start_beats` / `end_beats`        | 선택 음수가 아닌 숫자, 종료는 시작보다 커야 함                         | 내보낼 프로젝트 박자 범위입니다. 생략하면 모든 청취 가능한 클립의 가장 이른 시작점과 가장 늦은 종료점을 사용합니다. 무음 클립은 포함되지 않으며, solo 트랙이 존재할 경우 solo 트랙만 선택합니다.                                                                                             |

생성은 후보만 만들며, **자동으로 프로젝트에 넣지 않습니다**. `commit_candidate`는 후보가 여전히 현재 버전에 속하는지 확인합니다. 로컬 교체 후보는 실제 길이가 전체 소스 오디오 또는 선택 구간과 신뢰성 있게 일치할 때만 자동으로 커밋될 수 있습니다. 일치하지 않으면 원래 프로젝트를 유지하고 오류를 반환하며, 수동으로 박자 수를 추측해 강제로 이어 붙일 수 없습니다.

## 2026-10-09 실제 요청 및 응답

### 12. 내보내기 제한 및 복구 검증

새 트랙 후보를 제출한 후, 해당 후보를 포함한 전체 곡 내보내기가 거부되었습니다. 실제 요청 및 최종 상태:

```json
{
  "action": "render",
  "id": "af0e104a-2a4c-40e0-9c70-7614566824a6",
  "version_id": "1ff01ada-e26b-444e-a618-a91f76754360",
  "title": "Suno Projects Docs Mix With Piano",
  "lyrics": "[Instrumental]",
  "async": true
}
```

제출 응답:

```json
{
  "task_id": "12fe503c-017e-46db-9d99-8cfb861ad4fc",
  "trace_id": "2f376c45-a081-4c2a-b6a5-658401fe8dc0"
}
```

```json
{
  "success": false,
  "task_id": "12fe503c-017e-46db-9d99-8cfb861ad4fc",

  "error": {
    "code": "studio_audio_unavailable",
```

해당 후보 트랙을 삭제한 후에도 원본 소스 트랙은 그대로 남아 있었으며, 최신 버전을 사용해 다시 내보내기에 성공했습니다:

위의 성공적으로 반환된 오디오 링크는 이번 검증 시 모두 미디어 바이트를 읽을 수 있었으며, 생성 및 교체 후보 링크의 처음 1,024바이트는 모두 HTTP 206, `audio/mpeg`를 반환했고, 내보내기 링크는 HTTP 206, `audio/mp4`를 반환했습니다. 이는 링크를 읽을 수 있음을 증명할 뿐, 해당 후보를 포함한 프로젝트가 반드시 내보낼 수 있음을 의미하지는 않습니다.

## 오류 및 복구

| 결과                                                                            | 의미                          | 다음 단계                                    |
| ----------------------------------------------------------------------------- | --------------------------- | -------------------------------------- |
| `project_version_conflict` / `project_candidate_stale`（409）                   | 프로젝트 버전이 변경되었거나 후보가 현재 버전에 속하지 않습니다.         | `retrieve`로 최신 프로젝트를 가져와 수정을 다시 계획하세요. 이전 후보를 재실행하지 마세요.        |
| `bad_request` / `studio_state_invalid` / `studio_model_unsupported`（보통 400）   | 매개변수, 트랙 상태, 후보 길이 또는 모델이 작업과 일치하지 않습니다.      | 작업 최종 상태 오류를 확인하고 입력을 수정하세요. 후보를 안전하게 연결할 수 없으면 원본 프로젝트를 유지하세요.          |
| `studio_audio_unavailable` / `studio_access_denied` / `content_rejected`（403） | 참조 오디오를 해당 프로젝트 작업에 사용할 수 없거나, 액세스 권한이 없거나, 콘텐츠 검사가 거부되었습니다. | 오디오 출처와 작업 `trace_id`를 확인하세요. 이미 생성된 후보를 전체 곡을 내보낼 수 있는 것과 동일시하지 마세요. |
| `too_many_requests`（429）                                                      | 요청이 빈도 제한을 받았습니다.                   | 먼저 원래 작업을 조회한 후, 새 멱등성 키로 새 작업을 시작할지 결정하세요.                |
| `studio_unavailable` / `studio_model_unavailable`（503）                        | 프로젝트 처리 또는 선택한 모델을 일시적으로 사용할 수 없습니다.             | 원래 작업 결과를 유지하세요. 나중에 명시적으로 재시도하고, 자동으로 모델을 전환하지 마세요.                |
| `studio_processing_failed` / 시간 초과（500/504）                                      | 처리에 실패했거나 최종 상태가 불확실합니다.                 | `task_id` 또는 원래 멱등성 키로 조회하여 중복 과금 생성을 피하세요.          |

프로젝트와 후보는 이를 생성한 애플리케이션 및 실행 환경에 바인딩되므로, 애플리케이션 간 재사용이나 자동 장애 조치를 가정할 수 없습니다. 성공적으로 내보낸 최종 오디오 URL을 영구 저장하고, 문제 해결을 위해 `trace_id`를 보관하세요.
