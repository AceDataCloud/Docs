SUNO는 우리가 새로운 버전의 Persona-v2-vox: 가수 스타일을 생성할 수 있도록 허용하며, 이전 버전과는 다르게 먼저 `vox_audio_id`를 얻어야 합니다. 이 문서에서는 새로운 버전의 Persona-v2-vox를 생성하는 방법을 설명합니다.

우선 해당 API를 통해 `vox_audio_id` 매개변수 값을 얻어야 하며, 이 API는 여러 입력 매개변수를 입력할 수 있습니다. 예를 들어 `audio_id`, `vocal_start`, `vocal_end` 등이 있으며, 이는 참조 곡 ID와 선택된 시간 범위를 나타냅니다.

여기서 우리가 입력하는 `audio_id`는 `42599b24-fb14-4cd3-a444-e15ffde3661b`입니다.

```python
import requests

url = "https://api.acedata.cloud/suno/vox"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

`data`의 `id` 필드가 우리가 원하는 `vox_audio_id`임을 확인할 수 있으며, 이후 [Persona API](https://platform.acedata.cloud/documents/suno-persona)를 통해 새로운 버전의 Persona-v2-vox: 가수 스타일을 생성합니다. 구체적인 입력은 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "name": "test",
    "audio_id": "42599b24-fb14-4cd3-a444-e15ffde3661b",
    "vocal_end": 30,
    "vocal_start": 20,
    "vox_audio_id": "24f0827e-5847-4011-b9b7-fc0b62032b65"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

호출 후 다음과 같은 결과를 얻습니다:

```json
{
  "success": true,
  "task_id": "e04b06a1-ff61-48e2-9fcc-15284bd18481",
  "data": {
    "persona_id": "49bef16d-6a09-49d1-8c24-a81663698b98"
  }
}
```

그 후 우리는 위의 `persona_id` 값을 바탕으로 새로운 버전의 Persona-v2-vox: 가수 스타일로 창작을 진행할 수 있으며, 구체적인 창작 방법은 [Suno 곡 생성 API 연동 설명](https://platform.acedata.cloud/documents/suno-audios-integration#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%AD%8C%E6%89%8B%E9%A3%8E%E6%A0%BC%E7%94%9F%E6%88%90%E5%8A%9F%E8%83%BD)과 동일합니다. 마지막으로 우리는 Suno Vox API를 통해 새로운 버전의 Persona-v2-vox: 가수 스타일로 곡을 창작할 수 있습니다.
