MiMo 2.6 Pro 및 MiMo 2.6 Flash는 Xiaomi MiMo 시리즈 모델입니다. 이 인터페이스는 OpenAI Chat Completions 형식을 사용하며, 입력, 출력 및 캐시 적중 token에 따라 과금됩니다.

## 모델 및 인터페이스

| 모델                | 용도           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | 복잡한 분석, 추론 및 도구 호출 |
| `mimo-v2.6-flash` | 일상 대화 및 경량 작업    |

MiMo를 활성화하고 해당 API 자격 증명을 획득한 후, `https://api.acedata.cloud/mimo/chat/completions`로 요청을 전송합니다. OpenAI SDK의 `base_url`은 `https://api.acedata.cloud/mimo`로 설정할 수 있습니다. 통합 `/v1/chat/completions` 엔드포인트에도 해당 서비스 권한이 필요합니다.

초기 인터페이스 범위는 텍스트 Chat Completions이며, 이미지, 오디오, 비디오, 웹 검색, Responses, Messages, Batch 및 UltraSpeed는 이번 출시 범위에 포함되지 않습니다.

## Python 예제

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

예제는 요청 작성 방식을 보여 줍니다. 실제 응답 예제는 서비스 검증 후 추가될 예정입니다.

## 스트리밍, 추론 및 도구 호출

`stream=true`를 설정하여 SSE를 수신합니다. 최종 사용량이 필요한 경우 `stream_options={"include_usage": true}`를 전달합니다. 클라이언트는 콘텐츠, 추론 콘텐츠 및 도구 호출 증분과 최종 usage 이벤트를 처리해야 합니다.

`thinking.type=enabled`를 사용하여 추론을 활성화하고, `disabled`로 비활성화합니다. `reasoning_content`와 최종 `content`는 분리되어 반환됩니다. 도구 호출을 이어갈 때는 어시스턴트 메시지의 추론 콘텐츠, 전체 `tool_calls` 및 해당 `tool_call_id`를 유지합니다.

`type=function`인 도구 선언만 제출하며, `tool_choice`는 `auto`만 지원합니다. 애플리케이션은 도구를 실행하고 결과를 다시 전달해야 합니다. 모델이 도구 호출을 반환하는 것 자체가 도구가 이미 실행되었음을 의미하지는 않습니다. 서비스 내장 웹 검색은 아직 제공되지 않습니다.

## 과금

`prompt_tokens`에는 캐시 적중 입력이 포함됩니다. `prompt_tokens_details.cached_tokens`는 캐시 가격으로 계산되고, 나머지 입력은 일반 입력 가격으로 계산됩니다. `completion_tokens`에는 추론 출력이 포함되므로, 추론 token을 중복 합산하지 마십시오. 스트리밍 호출도 최종 실제 사용량에 따라 정산됩니다.

가격은 콘솔을 기준으로 하며, Credit의 미국 달러 비용은 구매 패키지에 따라 달라집니다. 실패한 요청은 성공적으로 완료된 것으로 간주해서는 안 됩니다. 과금 확인이 필요한 경우 응답의 추적 식별자를 제공하십시오.

## 오류 처리

매개변수 오류는 요청 형식을 확인하십시오. 인증 또는 권한 오류는 자격 증명 및 서비스 활성화 상태를 확인하십시오. 429가 발생하면 지수 백오프로 재시도하십시오. 정상 모델 용량이 없을 경우 503이 반환될 수 있습니다. 스트리밍 응답 시작 후 중단이 발생하면, 무분별하게 요청을 반복하기 전에 수신된 결과와 사용량을 먼저 확인하십시오.
