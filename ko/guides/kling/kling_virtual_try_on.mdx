`POST /kling/virtual-try-on`을 통해 작업을 제출하고, 기존 `POST /kling/tasks`를 사용하여 플랫폼 작업 상태를 조회합니다.

## 입력

product_image 한 장과 person_image 한 장을 정확히 제공해야 합니다. keep_face, keep_pose, keep_background의 기본값은 모두 true이며, 각각 독립적으로 비활성화할 수 있습니다. 입력 이미지의 가장 긴 변은 2048px를 초과할 수 없고, 가장 짧은 변은 300px보다 커야 하며, 파일은 10MB를 초과할 수 없습니다.

다음은 요청 구조 예시입니다. 소재 URL을 교체한 후 호출하세요.

```json
{
  "contents": [
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "person_image",
      "url": "https://your-cdn.example/person.jpg"
    }
  ],
  "async": true
}
```

## 결과 및 과금

동기 모드는 생성 결과를 반환합니다. 비동기 모드는 먼저 `task_id`를 반환하며, 완료 결과에는 `data`의 비디오 또는 이미지 링크와 서버에서 계산된 `usage`가 포함됩니다. `callback_url`은 완료 알림에 사용되며, `watermark=true` 요청은 워터마크 버전도 함께 반환합니다.

1.12 Credits/장, 실제 출력 이미지 수를 기준으로 과금됩니다. 비디오는 실제 생성된 길이를 기준으로 정산되며, 생성 전의 초당 기본 가격은 전체 작업의 총가격을 의미하지 않습니다. 실패한 작업에는 생성 비용이 부과되지 않습니다.
