title: "可灵 대화형 API (Kling Lip Sync)"
description: "Kling video generation API guide - Ace Data Cloud"

기존의 **可灵 비디오**(5초 또는 10초)를 오디오 또는 텍스트에 따라 "입을 열어 말하게" 하는 기능입니다 — 즉, 대화형(입 모양 맞추기). `/kling/videos`의 `image2video`(사진을 움직이게 하는 기능)와 결합하여 완전한 "**말하는 사진 / 디지털 인구 방송**" 프로세스를 구성할 수 있습니다.

> 이 인터페이스는 AceDataCloud에서 제공하는 단일 단계의 간편한 패키지로, 일반적인 오디오/텍스트 기반의 시나리오를 대상으로 합니다; 이는 Kling 공식 "얼굴 인식 → 고급 입 모양 맞추기" 다단계 인터페이스의 필드 미러가 아닙니다. 본 페이지의 매개변수 표를 기준으로 하십시오.

- **인터페이스 주소**: `POST https://api.acedata.cloud/kling/lip-sync`
- **요청 형식**: `application/json`
- **응답 형식**: `application/json`
- **과금**: 매번 성공적으로 호출 시 **2.45 크레딧**(고정)

## 요청 헤더 (Request Headers)

| 필드              | 값                   | 설명                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | 당신의 API 키, [획득 주소](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | 요청 본문 형식                                            |
| `accept`        | `application/json`  | 응답 형식                                             |

## 요청 매개변수 (Request Body)

| 매개변수               | 유형      | 필수  | 기본값      | 설명                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | 예   | —       | 생성 모드. 열거형: `audio2video`(오디오 기반), `text2video`(텍스트 기반)                                                                           |
| `video_id`       | string  | 선택  | —       | 可灵 생성 비디오의 ID(예: `/kling/videos`의 image2video가 반환한 `video_id`). **30일 이내에 생성된 5초/10초 비디오만 지원**. `video_id`와 `video_url` 중 하나 선택, 동시에 전송 불가 |
| `video_url`      | string  | 선택  | —       | 공용으로 접근 가능한 비디오 링크. 제약: `.mp4`/`.mov`, ≤100MB, 길이 2–10초, 오직 720p/1080p, 변의 길이 720–1920px. `video_id`와 `video_url` 중 하나 선택                                  |
| `audio_url`      | string  | 조건  | —       | 구동 오디오의 다운로드 URL, `audio2video` + `audio_type=url`일 때 필수. 형식 `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | 아니   | `url`   | 오디오 전송 방식. 열거형: `url`, `file`(`audio2video`일 때 유효)                                                                                |
| `audio_file`     | string  | 조건  | —       | 오디오 파일의 Base64, `audio_type=file`일 때 필수. 형식 동일, ≤5MB                                                                             |
| `text`           | string  | 조건  | —       | 읽어야 할 텍스트, `text2video`일 때 필수, **최대 120자**                                                                                     |
| `voice_id`       | string  | 조건  | —       | 음색 ID, `text2video`일 때 필수                                                                                                   |
| `voice_language` | string  | 아니   | `zh`    | 음색 언어. 열거형: `zh`, `en`(`text2video`일 때 유효)                                                                                      |
| `voice_speed`    | float   | 아니   | `1.0`   | 말 속도, 범위 `0.8`–`2.0`, 소수점 한 자리까지 정확하게(`text2video`일 때 유효)                                                                              |
| `callback_url`   | string  | 아니   | —       | 콜백 주소. 이 항목 또는 `async=true`를 전달하면 **비동기 모드**: 즉시 `task_id`를 반환하고, 결과 생성 후 콜백                                                                 |
| `async`          | boolean | 아니   | `false` | 비동기 여부. `true`일 때 즉시 `task_id`를 반환하고, `/kling/tasks`로 폴링하거나 `callback_url`로 콜백                                                      |

## 요청 예시

### 1) 오디오 기반 (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) 텍스트 기반 (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "형, 오랜만이야, 나는 잘 지내고 있어, 너도 잘 챙겨.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## 응답 예시 (동기 성공)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| 필드          | 유형      | 설명                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | 성공 여부                                       |
| `task_id`   | string  | 이번 작업 ID( `/kling/tasks` 조회에 사용 가능)             |
| `video_id`  | string  | 생성된 비디오의 可灵 ID(다음 `extend`/`lip-sync`의 입력으로 사용 가능) |
| `video_url` | string  | 생성된 말하는 비디오 URL(본 플랫폼 CDN에 저장되어 장기 유효)              |
| `duration`  | string  | 비디오 길이(초)                                    |
| `state`     | string  | 작업 상태: `succeed` / `failed`                  |

## 비동기 모드 및 조회

`callback_url` 또는 `async: true`를 전달하면 인터페이스가 **즉시** `task_id`를 반환합니다; 이후:

- **폴링**: `POST /kling/tasks`, 본문 `{ "action": "retrieve", "id": "<task_id>" }`(무료)
- **콜백**: 생성 완료 후 결과를 당신의 `callback_url`로 POST

## 전체 프로세스: 말하는 사진 (image2video → lip-sync)
```bash
# 1단계: 사진을 움직이게 하여 video_id 얻기
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"look at camera, natural","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# 2단계: 오디오로 입 모양 맞추기
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## 오류 응답

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "video_id 또는 video_url 중 하나가 필요합니다" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | 코드                    | 의미                                                 |
| ---- | ----------------------- | -------------------------------------------------- |
| 400  | `bad_request`           | 매개변수 누락 또는 잘못됨 (예: mode 미전달, video와 audio 중 하나 충돌, text 120자 초과) |
| 401  | `authorization_missing` | 누락되었거나 유효하지 않은 API 키                                      |
| 403  | `forbidden`             | 내용이 풍제 차단됨                                            |
| 429  | `too_many_requests`     | 상위 동시 제한, 잠시 후 다시 시도하십시오                                       |
| 500  | `api_error`             | 상위 또는 내부 오류                                            |

## 주의 사항

- `video_id`는 **30일 이내** 생성된 유효한 비디오여야 하며, **5초 또는 10초**여야 합니다; 그렇지 않으면 `video_url`을 사용하여 제약 조건에 맞는 비디오를 전달하십시오.
- 입력 비디오는 **선명한 정면, 단일 인물**을 권장하며, 입 모양 효과가 최상입니다.
- 오디오/텍스트 길이는 비디오 길이와 일치해야 합니다 (오디오는 비디오 길이를 초과하지 않아야 함).
- 청구는 **성공** 시 발생합니다 (2.45 크레딧/회); 매개변수 검증 실패(4xx)는 청구되지 않습니다.
