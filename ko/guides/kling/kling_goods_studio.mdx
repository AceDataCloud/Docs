`POST /kling/goods-studio`를 통해 작업을 제출하고, 기존 `POST /kling/tasks`를 사용하여 플랫폼 작업 상태를 조회합니다.

## 입력

1–5장의 상품 이미지와 최대 200자의 상품 제목을 제공합니다. 상품 설명은 선택 사항이며 최대 2000자입니다. 길이는 선택 사항으로 15, 30 또는 60초입니다.

다음은 요청 구조 예시입니다. 소재 URL을 교체한 후 호출하세요.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "당신의 상품 또는 나레이션 내용"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## 결과 및 과금

동기 모드는 생성 결과를 반환합니다. 비동기 모드는 먼저 `task_id`를 반환하며, 완료 결과에는 `data`의 동영상 또는 이미지 링크와 서버 측에서 계산한 `usage`가 포함됩니다. `callback_url`은 완료 알림에 사용됩니다. `watermark=true` 요청은 워터마크 버전도 함께 반환합니다.

720p: 2.38 Credits/초, 1080p: 2.8 Credits/초. 동영상은 실제 생성 길이를 기준으로 정산되며, 생성 전의 초당 기본 가격은 전체 작업의 총가격을 의미하지 않습니다. 실패한 작업에는 생성 비용이 부과되지 않습니다.
