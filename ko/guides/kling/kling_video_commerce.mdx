`POST /kling/video-commerce`를 통해 작업을 제출하고, 기존 `POST /kling/tasks`를 사용하여 플랫폼 작업 상태를 조회합니다.

## 입력

인물 이미지 한 장을 업로드하고 voice_id를 지정하거나, 사전 설정된 avatar_id를 사용합니다(둘은 상호 배타적이며, 사전 설정 인물에는 voice_id를 별도로 지정할 수 없습니다). 최대 2000자의 speech_script를 반드시 제공해야 합니다. 상품 정보를 제공할 때는 최소 한 장의 ref_image와 하나의 goods_title이 필요합니다. 상품 음성 방송은 speech_rate를 지원하지 않습니다. 일반 인물 음성 방송은 0.8배, 1.0배 또는 1.2배 말하기 속도를 지원합니다.

다음은 요청 구조 예시입니다. 소재 URL을 교체한 후 호출하세요.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "你的商品或口播内容"
    },
    {
      "type": "speech_script",
      "text": "你的商品或口播内容"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## 결과 및 과금

동기 모드는 생성 결과를 반환합니다. 비동기 모드는 먼저 `task_id`를 반환하며, 완료 결과에는 `data`의 비디오 또는 이미지 링크와 서버에서 계산한 `usage`가 포함됩니다. `callback_url`은 완료 알림에 사용됩니다. `watermark=true` 요청은 워터마크 버전도 함께 반환합니다.

일반 인물 음성 방송: 720p는 1.4 Credits/초, 1080p는 1.68 Credits/초입니다. 상품 음성 방송: 720p는 1.96 Credits/초, 1080p는 2.24 Credits/초입니다. 비디오는 실제 생성된 길이에 따라 정산되며, 생성 전의 초당 기본 가격은 전체 작업의 총가격을 의미하지 않습니다. 실패한 작업에는 생성 비용이 부과되지 않습니다.
