`POST /kling/apparel`을 통해 작업을 제출하고, 기존 `POST /kling/tasks`를 사용하여 플랫폼 작업 상태를 조회합니다.

## 입력

최대 2500자의 상품 설명, 5–180초의 참고 영상 및 1–5장의 상품 이미지를 제공합니다. 추가로 1–5장의 모델 이미지, 배경 음악 파일 및 지정된 더빙 음색을 제공할 수 있으며, 음색을 지정하지 않으면 원본 음성 내레이션이 사용됩니다.

다음은 요청 구조 예시입니다. 소재 URL을 교체한 후 호출하세요.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "당신의 상품 또는 음성 내레이션 내용"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## 결과 및 과금

동기 모드는 생성 결과를 반환합니다. 비동기 모드는 먼저 `task_id`를 반환하며, 완료 결과에는 `data`의 영상 또는 이미지 링크와 서버 측에서 계산된 `usage`가 포함됩니다. `callback_url`은 완료 알림에 사용됩니다. `watermark=true` 요청은 워터마크 버전도 함께 반환합니다.

원본 음성 내레이션: 720p는 초당 1.82 Credits, 1080p는 초당 2.38 Credits입니다. 지정 더빙: 720p는 초당 2.38 Credits, 1080p는 초당 2.8 Credits입니다. 영상은 실제 생성 길이를 기준으로 정산되며, 생성 전의 초당 기본 가격은 전체 작업의 총가격을 의미하지 않습니다. 실패한 작업에는 생성 비용이 청구되지 않습니다.
