이 문서에서는 Kling Videos Generation API 연동 방법에 대해 소개합니다. 이 API는 사용자 정의 매개변수를 입력하여 Kling 공식 영상을 생성할 수 있습니다.

## 신청 절차

API를 사용하려면 먼저 [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46) 해당 페이지에서 서비스를 신청해야 합니다. 페이지에 접속한 후, 「Acquire」 버튼을 클릭하세요. 아래 그림과 같습니다:

![](https://cdn.acedata.cloud/q6ytrc.png)

로그인 또는 회원가입이 되어 있지 않은 경우, 자동으로 로그인 페이지로 이동하여 회원가입 및 로그인을 안내합니다. 로그인 및 회원가입 후에는 자동으로 현재 페이지로 돌아옵니다.

최초 신청 시 무료 할당량이 제공되어 해당 API를 무료로 사용할 수 있습니다.

## 기본 사용법

먼저 기본 사용법을 이해해야 합니다. 입력할 항목은 프롬프트 `prompt`, 생성 행동 `action`, 첫 프레임 참고 이미지 `start_image_url`, 그리고 모델 `model`입니다. 이를 통해 처리된 결과를 얻을 수 있습니다. 우선 `action` 필드에 `text2video` 값을 간단히 전달해야 하며, 주요 행동은 세 가지입니다: 텍스트로부터 영상 생성(`text2video`), 이미지로부터 영상 생성(`image2video`), 영상 확장(`extend`). 그리고 모델 `model`을 입력해야 하며, 현재 주요 모델은 `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1` 입니다. 구체 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

여기서 Request Headers를 설정한 것을 볼 수 있습니다. 주요 항목은:

- `accept`：응답 결과를 어떤 형식으로 받을지 지정하며, 여기서는 `application/json` 즉 JSON 형식입니다.
- `authorization`：API 호출을 위한 키로, 신청 후 드롭다운에서 바로 선택할 수 있습니다.

또한 Request Body에는 다음 항목들이 포함됩니다:

- `model`：영상 생성에 사용할 모델로, `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1` 모델이 있습니다.
- `mode`：영상 생성 모드로, 표준 모드 `std`, 고속 모드 `pro`, 원본 4K 모드 `4k`가 있습니다. `4k` 모드는 `kling-v3`와 `kling-v3-omni`만 지원하며, `camera_control`(카메라 제어)와는 호환되지 않습니다.
- `action`：이번 영상 생성 작업의 행동으로, 텍스트로부터 영상 생성(`text2video`), 이미지로부터 영상 생성(`image2video`), 영상 확장(`extend`) 세 가지가 있습니다.
- `start_image_url`：이미지로부터 영상 생성 시 필수로 업로드해야 하는 첫 프레임 참고 이미지 링크입니다.
- `end_image_url`：이미지로부터 영상 생성 시 선택 사항으로, 마지막 프레임을 지정합니다.
- `duration`：영상 길이(초 단위)입니다. `kling-v3`와 `kling-v3-omni` 모델은 3~15초(정수)까지 유연한 길이를 지원하며, 다른 모델은 5초 또는 10초만 지원합니다.
- `generate_audio`：음성 동시 생성 여부로 선택 사항이며, 불리언 값입니다. `kling-v3`, `kling-v3-omni`, `kling-v2-6`(pro 모드만)에서 지원하며 기본값은 `false`입니다.
- `aspect_ratio`：영상 가로세로 비율로 선택 사항이며, `16:9`, `9:16`, `1:1`을 지원하며 기본값은 `16:9`입니다.
- `cfg_scale`：관련성 강도이며, 범위는 [0,1]로 클수록 프롬프트에 더 부합합니다.
- `camera_control`：선택 사항으로 카메라 움직임을 제어하는 객체 매개변수이며, type/simple 프리셋과 horizontal, vertical, pan, tilt, roll, zoom 등의 구성을 지원합니다.
- `negative_prompt`：선택 사항으로 원하지 않는 반대 프롬프트이며 최대 200자입니다.
- `element_list`：주체 참고 리스트로 `kling-video-o1` 모델에만 적용되며, 구체 사용법은 [공식 문서](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z)를 참고하세요.
- `video_list`：참고 영상으로 URL 방식으로 가져오며, `kling-video-o1` 모델에만 적용됩니다. 구체 사용법은 [공식 문서](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z)를 참고하세요.
- `prompt`：프롬프트입니다.
- `callback_url`：결과 콜백을 받을 URL입니다.

선택 후 오른쪽에 해당 코드도 생성된 것을 볼 수 있습니다. 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

「Try」 버튼을 클릭하면 테스트할 수 있으며, 위 그림처럼 다음과 같은 결과를 얻었습니다:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",

  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"

```

반환 결과에는 여러 필드가 있으며, 설명은 다음과 같습니다:

- `success`：영상 생성 작업의 상태입니다.
- `task_id`：영상 생성 작업 ID입니다.
- `video_id`：영상 생성 작업의 영상 ID입니다.
- `video_url`：영상 생성 작업의 영상 링크입니다.
- `duration`：영상 생성 작업의 영상 길이입니다.
- `state`：영상 생성 작업의 상태입니다.

만족스러운 영상 정보를 얻었으며, 결과의 `data` 내 영상 링크 주소를 통해 생성된 Kling 영상을 얻을 수 있습니다.

또한 대응하는 연동 코드를 생성하고 싶다면 바로 복사할 수 있습니다. 예를 들어 CURL 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## 영상 확장 기능

이미 생성된 Kling 영상을 이어서 생성하고 싶다면 `action` 파라미터를 `extend`로 설정하고, 이어서 생성할 영상 ID를 입력해야 합니다. 영상 ID는 기본 사용법에 따라 얻을 수 있으며, 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

이때 영상 ID는 다음과 같습니다:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> 주의: 여기서 영상의 `video_id`는 생성된 영상의 ID입니다. 영상 생성 방법을 모른다면 위 기본 사용법을 참고하세요.

다음으로 확장할 프롬프트를 입력하여 영상 생성을 커스터마이징할 수 있습니다. 주요 내용은 다음과 같습니다:

- `model`：영상 생성 모델로 `kling-v1`, `kling-v1-5`, `kling-v1-6` 모델이 있습니다.
- `mode`：영상 생성 모드로 표준 모드 `std`, 고속 모드 `pro`, 원본 4K 모드 `4k`(`kling-v3`와 `kling-v3-omni`만 지원, 카메라 제어와 비호환)가 있습니다.
- `duration`：이번 영상 생성 작업의 영상 길이로 5초 또는 10초가 주로 포함됩니다.
- `start_image_url`：이미지로부터 영상 생성 시 필수로 업로드해야 하는 첫 프레임 참고 이미지 링크입니다.
- `prompt`：프롬프트입니다.

작성 예시는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

작성 완료 후 자동으로 생성된 코드는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행하면 다음과 같은 결과를 얻을 수 있습니다:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

결과 내용은 위와 유사하며, 영상 확장 기능이 구현된 것을 확인할 수 있습니다.

## 비동기 콜백

Kling Videos Generation API는 생성 시간이 상대적으로 길어 약 1~2분 정도 소요됩니다. 만약 API가 장시간 응답하지 않으면 HTTP 요청이 계속 연결된 상태로 유지되어 추가 시스템 자원 소모가 발생할 수 있으므로, 본 API는 비동기 콜백 기능도 제공합니다.

전체 흐름은 다음과 같습니다: 클라이언트가 요청 시 추가로 `callback_url` 필드를 지정합니다. 클라이언트가 API 요청을 보내면 API는 즉시 `task_id` 필드를 포함한 결과를 반환하여 현재 작업 ID를 알립니다. 작업 완료 후 생성된 영상 결과를 POST JSON 형식으로 클라이언트가 지정한 `callback_url`로 전송하며, 여기에도 `task_id` 필드가 포함되어 작업 결과를 ID로 연동할 수 있습니다.

아래 예시를 통해 구체적인 동작을 살펴보겠습니다.

우선 Webhook 콜백은 HTTP 요청을 받을 수 있는 서비스이며, 개발자는 직접 구축한 HTTP 서버 URL로 대체해야 합니다. 여기서는 시연을 위해 공개 Webhook 사이트 https://webhook.site/ 를 사용합니다. 해당 사이트를 열면 Webhook URL을 얻을 수 있으며, 아래 그림과 같습니다:

![](https://cdn.acedata.cloud/tbcnai.png)

이 URL을 복사하여 Webhook으로 사용할 수 있습니다. 예시는 `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3` 입니다.

다음으로 `callback_url` 필드를 위 Webhook URL로 설정하고, 관련 매개변수를 입력합니다. 구체 내용은 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/vdx12s.png" width="500" className="m-auto" /></p>

실행하면 즉시 다음과 같은 결과를 얻습니다:

```

```

잠시 후 `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3` 에서 생성된 영상 결과를 확인할 수 있습니다. 아래 그림과 같습니다:

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예시는 다음과 같습니다:

- `400 token_mismatched`：잘못된 요청, 매개변수 누락 또는 유효하지 않음.
- `400 api_not_implemented`：잘못된 요청, 매개변수 누락 또는 유효하지 않음.
- `401 invalid_token`：인증 실패, 유효하지 않거나 누락된 토큰.
- `429 too_many_requests`：요청 과다, 속도 제한 초과.
- `500 api_error`：서버 내부 오류.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
