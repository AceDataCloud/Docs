---
title: "Kling 말하는 사진 API（Kling Talking Photo）"

---

한 번의 클릭으로 **사진 한 장 + 오디오 한 개**를 「말하는 동영상」으로 변환합니다. 서비스 내부에서 두 단계를 자동으로 완료합니다: 먼저 image2video를 사용하여 사진을 움직이게 한 다음, lip-sync를 사용하여 오디오에 맞춰 립싱크합니다. **한 번만** 호출하면 됩니다.

- **인터페이스 주소**：`POST https://api.acedata.cloud/kling/talking-photo`
- **과금**：길이 기준, 5초 **16.45 Credits**, 10초 **30.45 Credits**(= image2video + lip-sync 통합 가격)

## 요청 헤더

| 필드              | 값                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## 요청 파라미터

| 파라미터             | 유형      | 필수  | 기본값                  | 설명                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | 예   | —                   | 인물 사진의 공개 URL, 선명한 정면 사진 권장                    |
| `audio_url`    | string  | 예   | —                   | 구동 오디오의 공개 URL（.mp3/.wav/.m4a/.aac,≤5MB） |
| `prompt`       | string  | 아니요   | —                   | 사진 애니메이션화 단계의 동작/표정 프롬프트                      |
| `model`        | string  | 아니요   | `kling-v2-1-master` | 사진 애니메이션화에 사용하는 Kling 모델                     |
| `duration`     | integer | 아니요   | `5`                 | 동영상 길이（5 또는 10초）                        |
| `mode`         | string  | 아니요   | `pro`               | 애니메이션화 품질（std/pro）                        |
| `callback_url` | string  | 아니요   | —                   | 전달하거나 `async=true`인 경우 비동기로 task_id 반환        |
| `async`        | boolean | 아니요   | `false`             | 비동기 모드, `/kling/tasks` 폴링 또는 콜백과 함께 사용          |

## 요청 예시

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## 응답 예시

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| 필드                 | 설명                        |
| ------------------ | ------------------------- |
| `video_url`        | 최종 말하는 동영상（이미 본 플랫폼 CDN에 저장됨）      |
| `source_video_url` | 중간 사진 애니메이션 동영상（image2video 결과） |
| `video_id`         | Kling 동영상 ID                   |

## 주의 사항

- 사진은 선명한 정면 사진, 단독 인물을 권장합니다.
- 오디오 길이는 동영상 길이(5초/10초)를 초과하지 않는 것이 좋습니다.
- 과금은 성공 시 발생합니다; 파라미터 검증 실패(4xx)는 과금되지 않습니다.
- 생성에는 약 4–6분이 소요됩니다(두 단계). `async=true` + `/kling/tasks` 폴링 사용을 권장합니다.
