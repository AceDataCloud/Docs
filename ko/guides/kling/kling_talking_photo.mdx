#可링 회화 사진 API (Kling Talking Photo)

**한 번의 클릭으로 사진 + 오디오**를 사용하여 "말하는 비디오"로 변환합니다. 서비스 내부에서 두 단계를 자동으로 완료합니다: 먼저 image2video를 사용하여 사진을 움직이게 하고, 그 다음 lip-sync를 사용하여 오디오에 맞춰 입모양을 맞춥니다. 당신은 **한 번만** 호출하면 됩니다.

- **API 주소**: `POST https://api.acedata.cloud/kling/talking-photo`
- **요금**: 시간에 따라, 5초 **16.45 크레딧**, 10초 **30.45 크레딧**(= image2video + lip-sync 통합 가격)

## 요청 헤더

| 필드              | 값                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## 요청 파라미터

| 파라미터        | 타입      | 필수  | 기본값                | 설명                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | 예   | —                   | 인물 사진의 공개 URL, 선명한 정면 사진을 권장                    |
| `audio_url`    | string  | 예   | —                   | 오디오의 공개 URL (.mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`       | string  | 아니오 | —                   | 사진 애니메이션 단계의 동작/표정 힌트                      |
| `model`        | string  | 아니오 | `kling-v2-1-master` | 사진 애니메이션에 사용되는 Kling 모델                     |
| `duration`     | integer | 아니오 | `5`                 | 비디오 길이 (5 또는 10초)                        |
| `mode`         | string  | 아니오 | `pro`               | 애니메이션 품질 (std/pro)                        |
| `callback_url` | string  | 아니오 | —                   | 전달하거나 `async=true`일 경우 비동기적으로 task_id 반환        |
| `async`        | boolean | 아니오 | `false`             | 비동기 모드, `/kling/tasks`와 함께 폴링 또는 콜백          |

## 요청 예시

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## 응답 예시

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| 필드                 | 설명                        |
| ------------------ | ------------------------- |
| `video_url`        | 최종적으로 말하는 비디오 (본 플랫폼 CDN에 저장됨)      |
| `source_video_url` | 중간의 사진 애니메이션 비디오 (image2video 결과) |
| `video_id`         | 可링 비디오 ID                   |

## 주의 사항

- 사진은 선명한 정면, 단일 인물 사진을 권장합니다.
- 오디오 길이는 비디오 길이(5초/10초)를 초과하지 않는 것이 좋습니다.
- 요금은 성공 시 발생하며; 파라미터 검증 실패(4xx)는 요금이 부과되지 않습니다.
- 생성 시간은 약 4–6분(두 단계) 소요되며, `async=true` + `/kling/tasks`로 폴링하는 것을 권장합니다.
