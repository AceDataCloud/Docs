`POST https://api.acedata.cloud/wan/tasks` 는 Wan 비디오 작업을 조회, 배치 조회 또는 삭제하는 데 사용됩니다. 작업 조회는 생성 비용을 중복으로 청구하지 않습니다.

## 단일 작업 조회

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

완료된 작업의 `response.data.video_url` 은 영구 CDN 주소입니다; `response.usage` 는 해상도, 입력/출력 비디오 초수, 프레임 속도 및 비율을 포함합니다; `response.cost` 는 생성 작업 결제입니다.

## 배치 조회

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

반환 `{ "items": [...], "count": 2 }` 입니다. 작업이 진행 중일 때는 `finished_at` 및 최종 `response` 가 없을 수 있습니다.

## 작업 기록 삭제

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

삭제는 작업 역사 기록에만 영향을 미치며, 생성된 CDN 비디오는 삭제되지 않습니다.
