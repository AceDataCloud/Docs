`POST https://api.acedata.cloud/wan/videos`는 기존 Wan 2.6 모델과 `wan3.0-video`를 동시에 지원합니다. Wan 3는 `media`를 기반으로 텍스트, 첫 번째 및 마지막 프레임 또는 참조 자료 패턴을 자동으로 인식합니다.

## Wan 3 문생 비디오

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "네온 도시에서 밤에 떠다니는 종이 배",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3는 2–30 초의 정수 또는 `-1` 스마트 길이를 지원하며, 해상도는 `480P`, `720P`, `1080P`입니다.

## 멀티미디어 참조

```json
{
  "model": "wan3.0-video",
  "prompt": "영화 같은 제품 공개 만들기",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type`은 다음을 지원합니다:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

첫 번째 및 마지막 프레임 모드와 참조 자료 모드는 혼용할 수 없습니다. 참조 비디오는 실제 입력 비디오 초 수에 성공적으로 출력 비디오 초 수가 추가되어 결산됩니다; 텍스트, 이미지 및 오디오 입력은 비디오 초 수를 증가시키지 않습니다.

## 공식 표준 가격

| 해상도   |      가격 |
| ----- | ------: |
| 480P  | $0.05/초 |
| 720P  | $0.10/초 |
| 1080P | $0.20/초 |

## Wan 2.6 호환

기존 `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` 및 flash 변형은 계속해서 `action`, `image_url`, `reference_video_urls` 등의 매개변수를 사용하며, 호출 경로는 변하지 않습니다.

## 비동기 및 결과

`async: true`로 설정하면 즉시 `task_id`를 얻고, `/wan/tasks`를 통해 최종 상태를 확인할 수 있습니다. 성공적인 비디오는 AceDataCloud CDN에 저장되며, 응답에서 실제 사용량 및 비용이 반환됩니다.
