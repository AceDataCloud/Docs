OpenAI ChatGPT는 매우 강력한 AI 대화 시스템으로, 입력한 프롬프트에 따라 단 몇 초 만에 자연스럽고 유창한 답변을 생성할 수 있습니다. ChatGPT는 탁월한 언어 이해 및 생성 능력으로 업계에서 독보적인 위치를 차지하고 있으며, 현재 다양한 산업과 분야에서 널리 활용되고 그 영향력이 점점 커지고 있습니다. 일상 대화, 창의적 글쓰기, 전문 상담, 코드 프로그래밍 등 어디에서든 ChatGPT는 놀라운 지능형 지원을 제공하여 인간의 업무 효율성과 창의성을 크게 향상시킵니다.

이 문서는 OpenAI Chat Completion 4o Image API 사용 절차를 주로 소개하며, 이를 통해 공식 OpenAI ChatGPT의 멀티모달 대화 기능을 손쉽게 활용할 수 있습니다.

## 신청 절차

OpenAI Chat Completion 4o Image API를 사용하려면 먼저 [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/openai-chat-completions) 페이지에서 「Acquire」 버튼을 클릭하여 요청에 필요한 인증 정보를 획득하세요:

![](https://cdn.acedata.cloud/nyq0xz.png)

로그인 또는 회원가입이 되어 있지 않은 경우 자동으로 로그인 페이지로 이동하여 회원가입 및 로그인을 안내합니다. 로그인 및 회원가입 후 자동으로 현재 페이지로 돌아옵니다.

최초 신청 시 무료 할당량이 제공되어 해당 API를 무료로 사용할 수 있습니다.

## GPT-4o 그림 모델

### 참고 이미지를 기반으로 원본 이미지 생성

아래는 한 장의 이미지를 기반으로 커스텀 스타일의 이미지를 생성하는 예시입니다. 먼저 입력한 이미지를 확인해 보겠습니다:

![](https://cdn.acedata.cloud/qzx2z1.png)

참고 이미지는 실제 인물 사진이며, 이를 애니메이션 스타일 이미지로 변환할 수 있습니다. 구체적인 요청 예시는 다음과 같습니다:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "생성 애니메이션 스타일 이미지, 모자도 씌워주세요"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 메시지를 반환합니다. 예를 들어:

- `400 token_mismatched`：잘못된 요청, 누락되었거나 유효하지 않은 매개변수 가능성.
- `400 api_not_implemented`：잘못된 요청, 누락되었거나 유효하지 않은 매개변수 가능성.
- `401 invalid_token`：권한 없음, 유효하지 않거나 누락된 인증 토큰.
- `429 too_many_requests`：요청 과다, 속도 제한 초과.
- `500 api_error`：서버 내부 오류, 서버 측 문제 발생.

### 오류 응답 예시

```
{
  "success": false,
  "error": {

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
