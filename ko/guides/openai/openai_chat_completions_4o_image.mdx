OpenAI ChatGPT는 매우 강력한 AI 대화 시스템으로, 입력한 프롬프트에 따라 몇 초 만에 유창하고 자연스러운 응답을 생성할 수 있습니다. ChatGPT는 뛰어난 언어 이해 및 생성 능력으로 업계에서 독보적인 존재로 자리 잡았으며, 현재 ChatGPT는 다양한 산업 및 분야에서 널리 사용되고 있으며 그 영향력이 더욱 두드러지고 있습니다. 일상 대화, 창의적 글쓰기, 전문 상담, 코드 프로그래밍 등에서 ChatGPT는 놀라운 지능적 지원을 제공하여 인간의 작업 효율성과 창의성을 크게 향상시킵니다.

이 문서는 OpenAI Chat Completion 4o Image API 작업의 사용 프로세스를 주로 소개하며, 이를 통해 공식 OpenAI ChatGPT의 다중 모드 대화 기능을 쉽게 사용할 수 있습니다.

## 신청 프로세스

OpenAI Chat Completion 4o Image API를 사용하려면 먼저 [OpenAI Chat Completion 4o Image API](https://platform.acedata.cloud/documents/1bcf3bba-102b-495d-9bba-47cd96717e45) 페이지에서 "Acquire" 버튼을 클릭하여 요청에 필요한 자격 증명을 얻을 수 있습니다:

![](https://cdn.acedata.cloud/nyq0xz.png)

로그인 또는 등록하지 않은 경우 자동으로 로그인 페이지로 이동하여 등록 및 로그인을 요청합니다. 로그인 및 등록 후에는 자동으로 현재 페이지로 돌아옵니다.

첫 번째 신청 시 무료 크레딧이 제공되어 해당 API를 무료로 사용할 수 있습니다.

## GPT-4o 그림 모델

### 참고 이미지를 기반으로 한 생화

아래는 하나의 이미지를 기반으로 사용자 정의 스타일의 이미지를 생성하는 예시입니다. 먼저 입력한 이미지를 살펴보겠습니다. 아래 그림과 같습니다:

![](https://cdn.acedata.cloud/qzx2z1.png)

참고 이미지는 실제 사람의 사진이며, 이를 애니메이션 스타일의 이미지로 변환할 수 있습니다. 구체적인 요청 샘플은 다음과 같습니다:

```json
{
  "model": "gpt-4o-image",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "애니메이션 스타일의 이미지를 생성하고 모자를 씌워주세요."
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "https://cdn.acedata.cloud/qzx2z1.png"
          }
        }
      ]
    }
  ],
  "stream": false
}
```

오류 처리

API를 호출할 때 오류가 발생하면, API는 해당 오류 코드와 정보를 반환합니다. 예를 들어:

- `400 token_mismatched`：잘못된 요청, 누락되었거나 잘못된 매개변수 때문일 수 있습니다.
- `400 api_not_implemented`：잘못된 요청, 누락되었거나 잘못된 매개변수 때문일 수 있습니다.
- `401 invalid_token`：권한 없음, 잘못되었거나 누락된 인증 토큰.
- `429 too_many_requests`：요청이 너무 많음, 비율 제한을 초과했습니다.
- `500 api_error`：내부 서버 오류, 서버에서 문제가 발생했습니다.
