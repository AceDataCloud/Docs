## 2. 이미지 URL로 편집하기

원본 이미지:

![GPT 이미지 2 편집 원본 이미지](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 당신의 API 키" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "머그컵, 테이블탑, 카메라 앵글, 초상화 레이아웃 및 부드러운 그림자는 변경하지 마십시오. 머그컵 색상만 흰색에서 선명한 오렌지색으로, 연한 크림색 배경은 단단한 다크 네이비 블루로 변경하십시오. 텍스트와 로고는 없습니다.",
    "size": "1024x1536"
  }'
```

성공 응답:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

이것은 2026년 9월 8일 Ace Data Cloud를 통해 실제로 완료된 편집 결과로, 컵은 오렌지색으로, 배경은 다크 네이비 블루로 변경되었으며 원래 구도와 1024×1536 크기를 유지합니다:

![GPT 이미지 2 오렌지색 머그컵 편집 결과](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. 로컬 이미지 업로드

`multipart/form-data` 사용:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 당신의 API 키" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=배경을 밝고 현대적인 스튜디오로 교체하십시오"
```

`image`를 반복해서 전달할 수 있으며, GPT 이미지 시리즈는 최대 16개의 참조 이미지를 지원합니다. JSON 요청의 `image`는 단일 URL 또는 URL 배열일 수 있으며, 로컬 파일은 multipart로 업로드합니다.

## 4. 자주 사용하는 매개변수

| 필드                | 설명                                                            |
| ----------------- | ------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` 또는 `gpt-image-2:reverse`  |
| `image`           | JSON은 단일 URL 또는 최대 16개의 URL 배열 사용; multipart는 하나 이상의 `image` 파일 필드 사용 |
| `prompt`          | 편집 지시                                                          |
| `size`            | `auto` 또는 제한에 맞는 `WIDTHxHEIGHT`                                  |
| `n`               | 1–10; `response_format=b64_json`일 때는 1만 지원                        |
| `response_format` | `url` 또는 `b64_json`                                            |
| `callback_url`    | 선택적 비동기 콜백 주소                                                      |

크기 규칙은 생성 인터페이스와 일치합니다: 너비와 높이는 16의 배수여야 하며, 긴 변은 3840을 초과할 수 없고, 총 픽셀 수는 8,294,400을 초과할 수 없습니다. `size`를 생략하거나 `auto`를 사용하면 모델이 프롬프트와 첫 번째 참조 이미지를 결합하여 캔버스를 선택합니다.

기본 `gpt-image-2`와 `:reverse`는 성공한 이미지 수에 따라 요금이 부과되며, `gpt-image-2:official`은 텍스트 입력, 참조 이미지 입력 및 이미지 출력의 실제 토큰에 따라 정산되며, 최종적으로 사용 기록에 따라 결정됩니다.

## 5. 비동기 콜백 및 오류 처리

긴 작업은 요청에 다음을 추가할 수 있습니다:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

비동기 200 응답은 `{"task_id": "..."}`입니다; 완료 후 최종 결과를 콜백합니다. 동기 요청은 `created`와 `data`를 반환합니다.

| 상태  | 확인                      |
| --- | ----------------------- |
| 400 | 이미지 형식/수, 매개변수 조합 및 크기 형식       |
| 401 | API 키 및 Bearer 헤더 |
| 429 | 요청 빈도                    |
| 504 | 비동기 콜백으로 변경                  |

오류 응답에는 `trace_id`가 포함됩니다. 문제를 피드백할 때 해당 ID를 제공하고 API 키는 제공하지 마십시오.

전체 필드 및 실시간 열거는 [OpenAI 이미지 편집 API](https://platform.acedata.cloud/documents/openai-images-edits) 페이지를 기준으로 합니다. 순수 텍스트로 이미지를 생성하려면 [GPT 이미지 2 이미지 생성](https://platform.acedata.cloud/documents/openai-images-generations)을 참조하십시오.
