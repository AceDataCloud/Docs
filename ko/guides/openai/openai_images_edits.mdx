## 3. 로컬 이미지 업로드

`multipart/form-data`를 사용합니다:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image`는 반복해서 전달할 수 있으며, GPT Image 시리즈는 최대 16장의 참조 이미지를 지원합니다. JSON 요청의 `image`는 단일 URL 또는 URL 배열일 수 있으며, 로컬 파일은 multipart로 업로드합니다.

### 모델 및 과금 방식

| 모델                                | 적용 시나리오 및 과금 방식                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | 기본 역방향 채널, 성공한 이미지 장수 기준 고정 과금                        |
| `gpt-image-2:reverse`             | 역방향 채널을 명시적으로 선택, 성공한 이미지 장수 기준 고정 과금                      |
| `gpt-image-2:official`            | 공식 API 채널, 안정성이 더 높으며 실제 Token 사용량 기준 과금            |
| `gpt-image-2.5-flare`             | 생성 속도에 중점, 성공한 이미지 장수 기준 고정 과금                        |
| `gpt-image-2.5-flare:official`    | 공식 API 채널, 안정성이 더 높고 생성 속도에 중점, 실제 Token 사용량 기준 과금     |
| `gpt-image-2.5-sunburst`          | 고충실도 및 정밀 제어에 중점, 성공한 이미지 장수 기준 고정 과금                    |
| `gpt-image-2.5-sunburst:official` | 공식 API 채널, 안정성이 더 높고 고충실도 및 정밀 제어에 중점, 실제 Token 사용량 기준 과금 |

공식 API 채널의 페이지 가격은 요청 전 추정치이며, 최종적으로는 응답의 실제 Token 사용량 및 사용 기록을 기준으로 합니다.

## 4. 마스크를 사용한 부분 편집

공식 Images Edit 인터페이스는 `mask`를 통해 수정이 허용되는 영역을 지정합니다. Ace Data Cloud의 `:official` 모델은 동일한 multipart 계약을 따릅니다:

- `mask`는 Alpha 채널이 있는 PNG여야 하며, 크기는 4MB를 초과할 수 없습니다;
- 마스크 크기는 첫 번째 `image`와 완전히 일치해야 합니다;
- Alpha가 `0`인 투명 픽셀은 편집 허용을 의미하며, 불투명 픽셀은 유지해야 함을 의미합니다;
- 색상이 흑백이지만 투명 채널이 없는 RGB 이미지는 유효한 마스크로 사용할 수 없습니다;
- 프롬프트는 원하는 완전한 화면을 설명하는 동시에, 부분 수정 및 변경하지 않고 유지해야 하는 내용을 명확히 해야 합니다.

아래에서는 먼저 원본 이미지에서 마스크를 생성합니다. 예시는 중앙 사각형을 투명하게 설정하여 모델이 해당 영역만 수정할 수 있도록 합니다:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

그런 다음 원본 이미지와 마스크를 함께 업로드합니다:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

OpenAI 공식 Python SDK의 `images.edit` 호출 방식을 그대로 사용할 수도 있으며, `base_url`만 Ace Data Cloud로 지정하면 됩니다:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

`mask`를 사용할 때 원본 이미지와 마스크는 동일한 multipart 요청에서 각각 `image=@input.png` 및 `mask=@mask.png`를 통해 업로드해야 합니다. URL 원본 이미지와 로컬 마스크 파일을 혼합하여 전달하지 마세요; 순수 URL 편집 요청은 로컬 `mask` 파일을 추가로 첨부하는 것을 지원하지 않습니다. 마스크는 편집 영역을 제한하지만, 생성 모델은 여전히 가장자리를 자연스럽게 혼합할 수 있습니다; 엄격한 경계가 필요한 경우, 선명한 Alpha 경계를 사용하고 프롬프트에서 변경하지 않고 유지해야 하는 내용을 반복해서 명시해야 합니다.

위 호출 방식은 [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) 및 [GPT Image 공식 Cookbook](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image)의 마스크 예시와 일치합니다.

## 5. 자주 사용하는 매개변수
| 필드                | 설명                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare`(더 빠름) 또는 `gpt-image-2.5-sunburst`(더 높은 충실도 및 제어); 세 가지 모두 해당하는 `:official` 변형을 선택할 수 있으며, `gpt-image-2`는 `:reverse`도 지원 |
| `image`           | JSON은 단일 URL 또는 최대 16개 URL의 배열을 사용하며, multipart는 하나 이상의 `image` 파일 필드를 사용합니다. `mask`를 사용할 때는 로컬 이미지 파일을 업로드해야 합니다                                              |
| `mask`            | 선택 사항인 PNG 마스크로, multipart 파일 업로드만 지원합니다. Alpha 채널을 포함해야 하며, 첫 번째 `image`와 동일한 크기이고 4MB를 초과하지 않아야 합니다                                                                 |
| `prompt`          | 편집 지시                                                                                                                             |
| `size`            | `auto` 또는 제한에 맞는 `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; `response_format=b64_json`일 때는 1만 지원                                                                                           |
| `response_format` | `url` 또는 `b64_json`                                                                                                               |
| `callback_url`    | 선택 사항인 비동기 콜백 주소                                                                                                                         |

크기 규칙은 생성 인터페이스와 동일합니다. 너비와 높이는 16의 배수여야 하고, 긴 변은 3840을 초과할 수 없으며, 총 픽셀 수는 655,360–8,294,400이고, 가로세로비는 3:1을 초과할 수 없습니다. `size`를 생략하거나 `auto`를 사용할 경우, 모델은 프롬프트와 첫 번째 참고 이미지를 결합하여 화면 비율을 선택합니다.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` 및 `gpt-image-2:reverse`는 성공한 이미지 수를 기준으로 과금됩니다. `gpt-image-2:official`, `gpt-image-2.5-flare:official` 및 `gpt-image-2.5-sunburst:official`은 텍스트 입력, 참고 이미지 입력 및 이미지 출력의 실제 Token에 따라 정산되며, 최종 기준은 사용 기록입니다.

## 6. 비동기 콜백 및 문제 해결

장시간 작업은 요청에 다음을 추가할 수 있습니다:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

비동기 200 응답은 `{"task_id": "..."}`이며, 완료 후 최종 결과가 콜백됩니다. 동기 요청은 `created`와 `data`를 반환합니다.

| 상태  | 확인 사항                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | 이미지 형식/개수, 매개변수 조합 및 크기 형식; `mask` 사용 시 PNG Alpha 채널, 4MB 제한 및 첫 번째 원본 이미지와 크기가 일치하는지 확인 |
| 401 | API Key 및 Bearer Header                                           |
| 429 | 요청 빈도                                                              |
| 504 | 비동기 콜백으로 전환                                                            |

오류 응답에는 `trace_id`가 포함됩니다. 문제를 피드백할 때 이 ID를 제공하고, API Key는 제공하지 마세요.

전체 필드와 실시간 열거값은 [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) 페이지를 기준으로 합니다. 순수 텍스트로 이미지를 생성하려면 [GPT Image 2 / 2.5 이미지 생성](https://platform.acedata.cloud/documents/openai-images-generations)을 확인하세요.
