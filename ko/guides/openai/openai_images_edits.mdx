## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션으로 들어가 API Key를 복사합니다.

## 2. 이미지 URL을 사용하여 편집

원본 이미지:

![GPT Image 2 편집 원본 이미지](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

성공 응답:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

이는 2026년 9월 8일 Ace Data Cloud를 통해 실제로 완료된 편집 결과입니다. 컵은 주황색으로, 배경은 짙은 네이비 블루로 변경되었으며, 원본 구도와 1024×1536 크기는 유지되었습니다:

![GPT Image 2 주황색 머그컵 편집 결과](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. 로컬 이미지 업로드

`multipart/form-data`를 사용합니다:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image`를 반복하여 전달할 수 있으며, GPT Image 시리즈는 최대 16장의 참조 이미지를 지원합니다. JSON 요청의 `image`는 단일 URL 또는 URL 배열일 수 있으며, 로컬 파일은 multipart로 업로드합니다.

## 4. 일반 매개변수

| 필드                | 설명                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare`(더 빠름) 또는 `gpt-image-2.5-sunburst`(더 높은 충실도 및 제어); 세 모델 모두 해당 `:official` 변형을 선택할 수 있으며, `gpt-image-2`는 `:reverse`도 지원 |
| `image`           | JSON은 단일 URL 또는 최대 16개 URL의 배열을 사용하며, multipart는 하나 이상의 `image` 파일 필드를 사용합니다                                                                    |
| `prompt`          | 편집 지시                                                                                                                             |
| `size`            | `auto` 또는 제한 조건에 맞는 `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; `response_format=b64_json`일 때는 1만 지원                                                                                           |
| `response_format` | `url` 또는 `b64_json`                                                                                                               |
| `callback_url`    | 선택적 비동기 콜백 주소                                                                                                                         |

크기 규칙은 생성 인터페이스와 동일합니다. 너비와 높이는 16의 배수여야 하고, 긴 변은 3840을 초과할 수 없으며, 총 픽셀 수는 655,360–8,294,400이고, 종횡비는 3:1을 초과할 수 없습니다. `size`를 생략하거나 `auto`를 사용할 경우, 모델은 프롬프트와 첫 번째 참조 이미지를 결합하여 화면 비율을 선택합니다.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` 및 `gpt-image-2:reverse`는 성공한 이미지 수를 기준으로 과금됩니다. `gpt-image-2:official`, `gpt-image-2.5-flare:official` 및 `gpt-image-2.5-sunburst:official`은 텍스트 입력, 참조 이미지 입력 및 이미지 출력의 실제 Token을 기준으로 정산되며, 최종적으로 사용 기록을 기준으로 합니다.

## 5. 비동기 콜백 및 문제 해결

긴 작업의 경우 요청에 다음을 추가할 수 있습니다:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

비동기 200 응답은 `{"task_id": "..."}`이며, 완료 후 최종 결과가 콜백됩니다. 동기 요청은 `created`와 `data`를 반환합니다.

| 상태  | 확인 사항                      |
| --- | ----------------------- |
| 400 | 이미지 형식/수량, 매개변수 조합 및 크기 형식       |
| 401 | API Key 및 Bearer Header |
| 429 | 요청 빈도                    |
| 504 | 비동기 콜백으로 전환                  |

오류 응답에는 `trace_id`가 포함됩니다. 문제를 피드백할 때 이 ID를 제공하고, API Key는 제공하지 마십시오.

전체 필드 및 실시간 열거형은 [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits) 페이지를 기준으로 합니다. 순수 텍스트로 이미지를 생성하려면 [GPT Image 2 / 2.5 이미지 생성](https://platform.acedata.cloud/documents/openai-images-generations)을 확인하십시오.
