## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고, 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 첫 번째 요청 보내기

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

성공 응답의 이미지는 `data[].url`에 있습니다. 아래는 2026년 9월 8일 Ace Data Cloud를 통해 실제 요청으로 얻은 1024×1536 결과입니다(작업 `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![GPT Image 2로 생성된 흰색 머그컵](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. 자주 사용하는 매개변수

| 필드                | 설명                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`(기본 권장), `gpt-image-2.5-flare`(더 빠름) 또는 `gpt-image-2.5-sunburst`(더 높은 충실도 및 제어); 세 가지 모두 해당하는 `:official` 변형을 선택할 수 있으며, `gpt-image-2`는 `:reverse`도 지원 |
| `prompt`          | 이미지 설명, 최대 32,000자                                                                                                                     |
| `size`            | `auto` 또는 `WIDTHxHEIGHT`; 너비와 높이는 16의 배수여야 하며, 긴 변은 3840을 초과할 수 없고, 총 픽셀 수는 655,360–8,294,400, 가로세로 비율은 3:1을 초과할 수 없음                                                       |
| `n`               | 1–10; `response_format=b64_json`일 때는 1만 지원                                                                                                 |
| `quality`         | GPT Image 모델은 `auto`, `low`, `medium`, `high`를 지원; 2.5 / 2.6 Flare / Sunburst( `:official` 포함)는 추가로 `xhigh`, `max`를 지원합니다. 공식 채널은 실제 Token 사용량에 따라 과금됩니다             |
| `response_format` | `url` 또는 `b64_json`                                                                                                                     |
| `callback_url`    | 선택 사항; 긴 작업이 완료된 후 해당 주소로 결과 전송                                                                                                                      |

자주 사용하는 크기:

| 비율   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"`는 프롬프트의 비율, 픽셀 및 레이아웃 의도에 따라 캔버스를 선택합니다. 정확한 픽셀이 필요한 경우 크기를 직접 입력하세요.

## 4. 여러 장 생성

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` 및 그 `:reverse` 별칭은 성공한 이미지 수에 따라 과금됩니다. `gpt-image-2:official`, `gpt-image-2.5-flare:official`, `gpt-image-2.5-sunburst:official`은 응답의 텍스트 입력 및 이미지 출력 실제 Token에 따라 정산됩니다. 페이지 가격은 요청 전 추정치이며, 최종적으로는 사용 기록을 기준으로 합니다.

## 5. 비동기 콜백

요청 본문에 `callback_url`을 추가하면, 인터페이스는 먼저 `{"task_id": "..."}`를 반환하고, 완료 시 해당 URL로 최종 결과를 POST합니다. 동기 요청은 계속해서 `created`와 `data`를 반환합니다:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

콜백 수신 측은 `task_id`를 사용해 중복을 제거하고, 요청 출처 및 데이터 형식을 검증해야 합니다.

## 6. 문제 해결

| 상태  | 확인 사항                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`, `prompt`, 크기 형식, `n` 및 `response_format` 조합    |
| 401 | API Key가 완전한지, Header가 `Authorization: Bearer ...`인지 |
| 429 | 요청이 너무 빈번함, 나중에 재시도                                         |
| 504 | 동기 생성 시간 초과; `callback_url` 사용                            |

오류 응답에는 `error.code`, `error.message`, `trace_id`가 포함됩니다. 문제를 피드백할 때는 `trace_id`를 제공하고, API Key는 제공하지 마세요.

전체 필드 및 실시간 열거형은 [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations) 페이지를 기준으로 합니다. 이미지 편집은 [GPT Image 2 / 2.5 / 2.6 이미지 편집](https://platform.acedata.cloud/documents/openai-images-edits)을 참조하세요.

## GPT Image 2.6

GPT Image 2.6은 2.5의 생성, 편집, 비동기 작업 및 과금 인터페이스를 그대로 따릅니다:

| 모델                                                          | 과금                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/장                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/장                   |
| `gpt-image-2.6-flare:official`                              | 2.5 official과 동일, 실제 Token 사용량에 따라 과금 |
| `gpt-image-2.6-sunburst:official`                           | 2.5 official과 동일, 실제 Token 사용량에 따라 과금 |

품질은 `auto`, `low`, `medium`, `high`, `xhigh`, `max` 중에서 선택할 수 있습니다. 크기는 `auto` 또는 위 제약 조건에 맞는 `WIDTHxHEIGHT`를 사용합니다. 이 인터페이스는 `png`, `jpeg`, `webp`를 지원합니다. GPT Image 2.6은 네이티브 `gif` 애니메이션도 지원하며, SVG는 현재 지원하지 않습니다. 편집은 JSON 이미지 URL 및 multipart 파일 업로드를 지원합니다. `:reverse`는 동일 이름 일반 버전의 명시적 별칭입니다. 전체 모델명을 사용하고, `gpt-image-2.6`을 전달하지 마세요.

### GPT Image 2.6 GIF 애니메이션

GPT Image 2.6 Flare, Sunburst의 일반 버전, `:reverse`, `:official` 모두 `output_format: "gif"`를 사용할 수 있습니다. 애니메이션 프레임, 반복 정보 및 재생 시간은 유지됩니다. `frame_count`는 프레임 수를 나타내고, `frame_duration_ms`는 프레임당 밀리초를 나타냅니다. 프레임 수는 2–16의 정수여야 하며, 프레임당 시간은 20–655350밀리초의 정수여야 하고 GIF에만 사용됩니다. 인코딩은 가장 가까운 10ms로 반올림됩니다. 지정하지 않으면 기본값은 9프레임, 프레임당 200밀리초입니다. GIF의 size를 생략하거나 auto로 설정하면 512x512 프리셋을 사용합니다.

먼저 `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`을 사용하는 것이 권장됩니다. GIF에는 독립적인 크기 및 프레임 수 제한이 있으므로 정적 4K 사양을 직접 적용할 수 없습니다. 일부 모델은 실제 출력 크기를 조정합니다. `n`은 반환되는 GIF 파일 수를 의미하며, 애니메이션 프레임 수가 아닙니다. 일반 버전과 `:reverse`는 계속해서 성공한 파일 수에 따라 과금되며, 공식 버전은 실제 Token 사용량에 따라 과금됩니다.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### GPT Image 2.6 4K 정적 이미지

Flare, Sunburst 및 그 `:reverse`, `:official` 변형 모두 앞서 언급한 4K 픽셀 프리셋(예: `3840x2160`, `2160x3840`)을 사용할 수 있습니다. 생성과 편집 모두 `size`를 통해 구체적인 픽셀을 전달합니다. `4K`는 유효한 `size` 값이 아니며, `4096x4096`도 현재 픽셀 상한을 초과합니다. 위 4K 사양은 정적 PNG/JPEG/WebP에 적용되며, GIF에는 전용 파라미터를 사용하세요.

### GPT Image 2.6 구도 복잡도

`complexity`는 `low`, `medium`, `high` 중에서 선택할 수 있으며, 생략하면 모델 기본값인 `high`를 사용합니다. 이는 계획 복잡도를 제어하며 `quality` 렌더링 품질과 독립적입니다. 추가 횟수 과금은 없으며, 공식 버전은 계속 실제 Token에 따라 정산됩니다. 다른 모델은 이 파라미터를 지원하지 않습니다.

GIF는 mask, 주석 이미지, 사용자 지정 압축, 프롬프트 재작성 또는 일부 이미지 스트리밍 출력을 지원하지 않습니다. 호환되지 않는 조합은 생성 전에 거부됩니다. 크기, 프레임 수 및 수량은 함께 모델 픽셀 예산 제한을 받습니다. 일반 Flare의 `1024x1024`, 2프레임은 사용 가능한 것으로 검증되었지만, 이 결론을 모든 1K 조합 또는 4K GIF로 확장할 수는 없습니다.
