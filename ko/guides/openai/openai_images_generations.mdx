## 1. API 키 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API 키를 복사합니다.

![Ace Data Cloud API 키 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 첫 번째 요청 보내기

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 당신의 API 키" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "미니멀한 편집 제품 일러스트레이션: 단순한 흰색 세라믹 커피 머그가 단단한 코발트 블루 테이블 위에 중앙에 위치, 연한 크림색 배경, 부드러운 그림자, 깨끗한 기하학적 형태, 텍스트 없음, 로고 없음, 세로 구성",
    "size": "1024x1536"
  }'
```

성공적으로 응답된 이미지는 `data[].url`에 위치합니다. 아래는 2026년 9월 8일 Ace Data Cloud를 통해 실제 요청으로 얻은 1024×1536 결과입니다(작업 `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, 추적 `eb938601-8192-407f-b539-1e0554b697ec`)：

![GPT 이미지 2 생성된 흰색 머그컵](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. 자주 사용하는 매개변수

| 필드                | 설명                                                                     |
| ----------------- | ---------------------------------------------------------------------- |
| `model`           | `gpt-image-2` 사용; 명시적으로 `gpt-image-2:official` 또는 `gpt-image-2:reverse` 선택 가능 |
| `prompt`          | 이미지 설명, 최대 32,000자                                                     |
| `size`            | `auto` 또는 `WIDTHxHEIGHT`; 너비와 높이는 16의 배수여야 하며, 긴 변은 3840을 초과할 수 없고, 총 픽셀 수는 8,294,400을 초과할 수 없음        |
| `n`               | 1–10; `response_format=b64_json`일 때는 1만 지원                                 |
| `quality`         | `low`, `medium`, `high` 또는 `auto`; 다양한 라인의 지원 및 과금 방식이 다름                          |
| `response_format` | `url` 또는 `b64_json`                                                     |
| `callback_url`    | 선택 사항; 긴 작업 완료 후 해당 주소로 결과 전송                                                      |

자주 사용하는 크기:

| 비율   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"`는 프롬프트의 비율, 픽셀 및 레이아웃 의도에 따라 캔버스를 선택합니다; 정확한 픽셀이 필요할 경우 직접 크기를 입력합니다.

## 4. 여러 장 생성

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 당신의 API 키" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "빛나는 버섯 아래에서 책을 읽고 있는 작은 여우, 수채화 일러스트레이션",
    "size": "1536x1024",
    "n": 2
  }'
```

기본적으로 `gpt-image-2`와 `:reverse`는 성공한 장 수에 따라 과금되며; `gpt-image-2:official`은 응답의 텍스트 입력과 이미지 출력에 따라 실제 토큰으로 정산됩니다. 페이지 가격은 요청 전 추정이며, 최종적으로 사용 기록에 따라 결정됩니다.

## 5. 비동기 콜백

요청 본문에 `callback_url`을 추가하면, 인터페이스는 먼저 `{"task_id": "..."}`를 반환하고, 완료 시 해당 URL로 최종 결과를 POST합니다; 동기 요청은 여전히 `created`와 `data`를 반환합니다:

```json
{
  "model": "gpt-image-2",
  "prompt": "명확한 타이포그래피가 있는 제품 포스터",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

콜백 수신자는 `task_id`를 사용하여 중복을 제거하고, 요청 출처와 데이터 형식을 검증해야 합니다.

## 6. 오류 처리

| 상태  | 확인                                                  |
| --- | --------------------------------------------------- |
| 400 | `model`, `prompt`, 크기 형식, `n` 및 `response_format` 조합    |
| 401 | API 키가 완전한지, 헤더가 `Authorization: Bearer ...`인지 확인 |
| 429 | 요청이 너무 잦음, 나중에 다시 시도                                         |
| 504 | 동기 생성 시간 초과; `callback_url`로 변경                            |

오류 응답에는 `error.code`, `error.message` 및 `trace_id`가 포함됩니다. 문제를 피드백할 때는 `trace_id`를 제공하고, API 키는 제공하지 마십시오.

전체 필드 및 실시간 열거는 [OpenAI 이미지 생성 API](https://platform.acedata.cloud/documents/openai-images-generations) 페이지를 기준으로 합니다. 이미지 편집은 [GPT 이미지 2 이미지 편집](https://platform.acedata.cloud/documents/openai-images-edits)을 참조하십시오.
