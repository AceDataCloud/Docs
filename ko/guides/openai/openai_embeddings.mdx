입력 텍스트를 나타내는 임베딩 결과를 생성하는 데 사용되는 OpenAI 임베딩 서비스입니다.

이 문서는 주로 OpenAI Embeddings API 작업의 사용 절차를 소개하며, 이를 통해 입력 텍스트를 나타내는 임베딩 벡터를 생성할 수 있습니다。。

## 신청 절차

OpenAI Embeddings API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않은 경우, 등록 및 로그인을 안내하는 로그인 페이지로 자동 이동하며, 완료 후 현재 페이지로 자동 반환됩니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 할당량이 제공되어 무료로 체험할 수 있으며, 할당량이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## 기본 사용

이제 화면에서 해당 내용을 입력할 수 있으며, 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

이 인터페이스를 처음 사용할 때는 최소 세 가지 내용을 입력해야 합니다. 하나는 `authorization`이며, 드롭다운 목록에서 직접 선택하면 됩니다. 또 다른 매개변수는 `model`이며, `model`은 OpenAI 공식 웹사이트 모델 유형 중에서 선택하여 사용하는 것입니다. 현재 사용 가능한 모델은 `text-embedding-3-small` 및 `text-embedding-3-large`입니다. `text-embedding-ada-002`는 제공이 중단되었습니다. 기존 벡터 인덱스에서 해당 이전 모델을 사용하는 경우 새 모델의 벡터와 직접 혼용할 수 없으며, 인덱스를 다시 생성해야 합니다. 마지막 매개변수는 `input`이며, `input`은 변환해야 하는 임베딩 텍스트입니다.

동시에 오른쪽에 해당 호출 코드가 생성되는 것을 확인할 수 있으며, 코드를 복사하여 직접 실행하거나 「Try」 버튼을 직접 클릭하여 테스트할 수도 있습니다.

선택 매개변수:

- `dimensions`: 벡터 차원을 자르며, 기본적으로 전체 차원을 출력합니다.
- `encoding_format`: 반환 형식으로, `float` 또는 `base64`를 선택할 수 있습니다.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Python 예시 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

반환 결과에는 여러 필드가 있으며, 다음과 같이 소개합니다:

- `model`: 이번 텍스트를 임베딩으로 변환할 때 사용한 모델입니다.
- `usage`: 이번 텍스트를 임베딩으로 변환할 때 사용한 token 정보입니다.
- `data`: 텍스트 변환 후의 임베딩 결과입니다.

그중 `data`에는 텍스트에 해당하는 임베딩의 구체적인 정보가 포함되어 있으며, 그 안의 `embedding`은 생성된 임베딩의 구체적인 결과입니다.

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면 다음과 같습니다:

- `400 token_mismatched`: Bad request, possibly due to missing or invalid parameters.
- `400 api_not_implemented`: Bad request, possibly due to missing or invalid parameters.
- `401 invalid_token`: Unauthorized, invalid or missing authorization token.
- `429 too_many_requests`: Too many requests, you have exceeded the rate limit.
- `500 api_error`: Internal server error, something went wrong on the server.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {

    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
