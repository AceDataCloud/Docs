OpenAI ChatGPT는 매우 강력한 AI 대화 시스템으로, 프롬프트를 입력하기만 하면 짧게는 몇 초 안에 매끄럽고 자연스러운 응답을 생성할 수 있습니다. ChatGPT는 뛰어난 언어 이해 및 생성 능력으로 업계에서 독보적이며, כיום ChatGPT는 이미 각종 산업과 분야에서 널리 활용되고 있고 그 영향력은 더욱 두드러지고 있습니다. 일상적인 대화, 창의적 글쓰기, 전문 상담, 코드 프로그래밍 등 무엇이든 ChatGPT는 놀라운 지능형 지원을 제공하여 인간의 업무 효율성과 창의성을 크게 향상시킬 수 있습니다.

이 문서는 주로 OpenAI Chat Completion API 작업의 사용 절차를 소개하며, 이를 활용하면 공식 OpenAI ChatGPT의 대화 기능을 손쉽게 사용할 수 있습니다.

## GPT-6.1 Sol

`model: "gpt-6.1-sol"`을 사용하여 이 모델을 선택합니다. 스트리밍 출력, 함수 호출, 구조화된 출력 및 이미지 입력을 지원합니다. 최초 공개 후 1주일 동안은 인증된 ACE T1+ 보유자(최소 100,000 ACE) 또는 권한을 부여받은 사용자에게만 공개되며, 구체적인 공개 시간은 콘솔 액세스 안내를 기준으로 합니다.

추론 수준은 `low`, `medium`, `high`, `xhigh` 및 `max`를 지원하며, 현재 `none` 또는 `minimal`은 지원하지 않습니다. `reasoning_effort: "low"`부터 시작하는 것을 권장합니다. 입력이 272,000 tokens를 초과하면 전체 요청에 긴 컨텍스트 가격이 적용되며, 비용은 콘솔의 현재 가격을 기준으로 합니다.

## 신청 절차

OpenAI Chat Completion API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않은 경우 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 반환됩니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 할당량이 제공되어 무료로 체험할 수 있으며, 할당량이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [OpenAI Chat Completion API →](https://platform.acedata.cloud/documents/openai-chat-completions)

## 기본 사용

이제 그림과 같이 인터페이스에서 해당 내용을 입력할 수 있습니다:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

이 인터페이스를 처음 사용할 때는 최소 세 가지 내용을 입력해야 합니다. 하나는 `authorization`이며, 드롭다운 목록에서 직접 선택하면 됩니다. 다른 하나의 매개변수는 `model`이며, `model`은 OpenAI ChatGPT 공식 웹사이트 모델 유형 중에서 선택하여 사용하는 것입니다. 여기에서는 주로 20가지 모델을 제공하며, 자세한 내용은 제공되는 모델을 확인할 수 있습니다. 마지막 매개변수는 `messages`이며, `messages`는 입력하는 질문 문구 배열입니다. 이는 배열로, 여러 개의 질문 문구를 동시에 업로드할 수 있음을 의미하며, 각 질문 문구에는 `role`과 `content`가 포함됩니다. 이 중 `role`은 질문자의 역할을 나타내며, `user`, `assistant`, `system`의 세 가지 역할을 제공합니다. 다른 하나인 `content`는 질문하는 구체적인 내용입니다.

동시에 오른쪽에 해당 호출 코드가 생성되는 것을 확인할 수 있으며, 코드를 복사하여 직접 실행하거나 「Try」 버튼을 직접 클릭하여 테스트할 수 있습니다.

자주 사용하는 선택 매개변수:

- `max_tokens`: 단일 응답의 최대 token 수를 제한합니다.
- `temperature`: 생성 무작위성으로, 0-2 사이이며 값이 클수록 더 발산적입니다.
- `n`: 한 번에 생성할 후보 응답 수입니다.
- `response_format`: 반환 형식 설정입니다.

## 스트리밍 응답

이 인터페이스는 스트리밍 응답도 지원하며, 이는 웹페이지 연동에 매우 유용하여 웹페이지에서 글자별 표시 효과를 구현할 수 있습니다.

응답을 스트리밍으로 반환하려면 요청 헤더의 `stream ` 매개변수를 `true`로 변경할 수 있습니다.

그림과 같이 수정하지만, 호출 코드도 스트리밍 응답을 지원하도록 համապատասխան 변경이 필요합니다.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

`stream`을 `true`로 변경한 후 API는 해당 JSON 데이터를 줄 단위로 반환하며, 코드 수준에서 줄 단위 결과를 얻기 위해 이에 맞게 수정해야 합니다.

Python 예제 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

- `id`, 이번 대화 작업을 생성한 ID로, 이번 대화 작업을 고유하게 식별하는 데 사용됩니다.

- `choices`, ChatGPT가 질문어에 대해 제공한 응답 정보입니다.

JavaScript도 지원되며, 예를 들어 Node.js의 스트리밍 호출 코드는 다음과 같습니다:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Java 예제 코드:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4");
jsonObject.put("messages", [{"role":"user","content":"hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/openai/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

다른 언어는 별도로 직접 수정하여 작성할 수 있으며, 원리는 모두 동일합니다.

## 다중 턴 대화

다중 턴 대화 기능을 연동하려면 `messages` 필드에 여러 질문어를 업로드해야 하며, 여러 질문어의 구체적인 예시는 다음 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/oz4mar.png" width="400" className="m-auto" /></p>

Python 예제 호출 코드:
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hi! How can I assist you today?"},{"role":"user","content":"What I say just now?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

여러 질문 문구를 업로드하면 여러 차례의 대화를 쉽게 구현할 수 있으며, 다음과 같은 응답을 받을 수 있습니다:

```json
{
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "You said, \"Hello.\""
      },
      "finish_reason": "stop"
    }
  ],
  "created": 1721323012,
  "id": "chatcmpl-NWZmOTA5MDlkZjBjNDRjNGEwMzRjYzA5NmM1MzQwMWY",
  "model": "gpt-4",
  "object": "chat.completion.chunk",
  "recipient": "all",
  "usage": {
    "prompt_tokens": 31,

```

확인할 수 있듯이, `choices`에 포함된 정보는 기본 사용 내용과 일치하며, 여기에는 ChatGPT가 여러 대화에 대해 응답한 구체적인 내용이 포함되어 있습니다. 이렇게 하면 여러 대화 내용을 바탕으로 해당 질문에 답변할 수 있습니다.

## OpenAI-Python 연동

OpenAI Chat Completion API는 공식 OpenAI 인터페이스와 호환되며, 공식 SDK [OpenAI-Python](https://github.com/openai/openai-python)을 직접 사용하여 연동할 수 있습니다. 이 글에서는 사용 방법을 간략히 소개합니다.

1. 먼저 로컬 `Python` 환경을 구축해야 하며, 이 과정은 구글에서 검색할 수 있습니다.
2. 개발 환경을 다운로드하여 설치합니다. 예를 들어 VSCode 편집기를 설치합니다.
3. `OpenAI` 환경 변수를 구성합니다.

- 프로젝트 폴더에 `.env`라는 이름의 파일을 생성하고 저장합니다.
- `.env` 파일 내용:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # 再次提醒：如果你使用官网OpenAI的key，不要用这个地址。
```

`sk-xxx`는 자신의 key로 교체합니다. `OPENAI_BASE_URL`은 OpenAI의 프록시 인터페이스에 접근하는 주소입니다.

4. 프로젝트에 필요한 패키지를 설치합니다

```shell
pip install openai
```

Mac OS에서는 명령어가 다음과 같습니다:

```shell
pip3 install openai
```

5. 예제 소스 코드 파일을 생성합니다

예를 들어 `index.py`라는 예제 코드를 생성했다고 가정하면, 구체적인 내용은 다음과 같습니다:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## 비전 모델

gpt-4o는 OpenAI가 개발한 멀티모달 대규모 언어 모델로, GPT-4를 기반으로 시각 이해 능력이 추가되었습니다. 이 모델은 텍스트와 이미지 입력을 동시에 처리할 수 있으며, 크로스모달 이해와 생성을 구현합니다.

gpt-4o 모델의 텍스트 처리는 위의 기본 사용 내용과 일치하며, 아래에서는 모델의 이미지 처리 능력을 사용하는 방법을 간략히 소개합니다.

gpt-4o 모델의 이미지 처리 능력은 주로 기존 `content` 내용에 `type` 필드를 추가하여 사용합니다. 이 필드를 통해 업로드된 것이 텍스트인지 이미지인지 알 수 있으며, 이를 통해 gpt-4o 모델의 이미지 처리 능력을 사용할 수 있습니다. 아래에서는 주로 Curl과 Python 두 가지 방식으로 이 기능을 호출하는 방법을 설명합니다.

- Curl 스크립트 방식

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Python 스크립트 방식
```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

그러면 아래와 같은 결과를 얻을 수 있으며, 결과 안의 필드 정보는 위 내용과 일치합니다. 구체적으로는 다음과 같습니다:

  "choices": [
    {
      "index": 0,

답변 내용이 이미지를 기반으로 답변한 것임을 확인할 수 있으므로, 위의 두 가지 방식을 통해 gpt-4-vision 모델의 텍스트 및 이미지 처리 능력을 쉽게 사용할 수 있습니다.

gpt-4o 외에도 gpt-4o-mini라는 더 저렴한 모델이 있습니다. gpt-4o-mini는 OpenAI가 개발한 최신 세대 대규모 언어 모델로, 응답 속도가 빠를 뿐만 아니라 가격도 더 저렴하고 멀티모달도 지원합니다. vision 기능의 사용 방법은 위 gpt-4o 모델 사용 내용을 참고할 수 있습니다.

## 오류 처리

API를 호출할 때 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면 다음과 같습니다:

- `400 token_mismatched`：잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `400 api_not_implemented`：잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `401 invalid_token`：인증되지 않음, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`：요청이 너무 많습니다. 속도 제한을 초과했습니다.
- `500 api_error`：내부 서버 오류, 서버에서 문제가 발생했습니다.
