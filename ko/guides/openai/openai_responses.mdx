OpenAI는 최근 모델 응답을 생성하는 인터페이스를 제공했습니다. 텍스트 또는 이미지 입력을 제공하여 텍스트 또는 이미지 출력을 생성합니다. 모델이 자체 사용자 지정 코드를 호출하거나 web 검색 또는 파일 검색과 같은 내장 도구를 사용하여, 자체 데이터를 모델 응답의 입력으로 사용하도록 합니다.

이 문서는 주로 OpenAI Responses API 작업의 사용 절차를 소개하며, 이를 통해 공식 OpenAI의 모델 응답 생성 기능을 쉽게 사용할 수 있습니다.

## 신청 절차

OpenAI Responses API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않았다면 자동으로 로그인 페이지로 이동하여 등록 및 로그인을 안내하며, 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [OpenAI Responses API →](https://platform.acedata.cloud/documents/openai-responses)

## 기본 사용

이제 화면에서 해당 내용을 입력할 수 있으며, 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/8lu8di.png" width="400" className="m-auto" /></p>

이 인터페이스를 처음 사용할 때는 최소 세 가지 내용을 입력해야 합니다. 하나는 `authorization`이며, 드롭다운 목록에서 직접 선택하면 됩니다. 또 다른 매개변수는 `model`이며, `model`은 사용할 OpenAI ChatGPT 공식 웹사이트 모델 유형을 선택하는 것입니다. 여기에서는 주로 20가지 모델을 제공하며, 자세한 내용은 제공하는 모델을 확인할 수 있습니다. 마지막 매개변수는 `input`이며, `input`은 입력하는 질문 문구 배열입니다. 이는 배열로, 여러 질문 문구를 동시에 업로드할 수 있음을 나타냅니다. 각 질문 문구에는 `role`과 `content`가 포함되며, 그중 `role`은 질문자의 역할을 나타냅니다. 세 가지 신원을 제공하며, 각각 `user`, `assistant`, `system`입니다. 또 다른 `content`는 질문의 구체적인 내용입니다.

동시에 오른쪽에 해당 호출 코드가 생성되는 것을 확인할 수 있으며, 코드를 복사하여 직접 실행하거나 「Try」 버튼을 직접 클릭하여 테스트할 수도 있습니다.

자주 사용하는 선택적 매개변수:

- `max_tokens`: 단일 응답의 최대 token 수를 제한합니다.
- `temperature`: 생성 무작위성으로, 0-2 사이이며 값이 클수록 더 분산됩니다.
- `n`: 한 번에 생성할 후보 응답 수입니다.
- `response_format`: 반환 형식 설정입니다.
- `tools`: 함수/도구 호출 정의입니다.
- `background`: 백그라운드에서 비동기로 실행할지 여부입니다.

## 스트리밍 응답

이 인터페이스는 스트리밍 응답도 지원하며, 이는 웹페이지 연동에 매우 유용하여 웹페이지에서 한 글자씩 표시되는 효과를 구현할 수 있습니다.

응답을 스트리밍으로 반환하려면 요청 헤더의 `stream ` 매개변수를 변경하여 `true`로 수정할 수 있습니다.

그림과 같이 수정하면 되지만, 호출 코드도 스트리밍 응답을 지원하도록 해당 변경이 필요합니다.

<p><img src="https://cdn.acedata.cloud/xidnao.png" width="400" className="m-auto" /></p>

`stream`을 `true`로 수정한 후 API는 해당 JSON 데이터를 줄 단위로 반환하며, 코드 수준에서 줄 단위 결과를 얻기 위해 그에 맞게 수정해야 합니다.

Python 예제 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

응답에는 많은 `data`가 있으며, `data` 내부의 `delta`가 최신 답변 내용임을 확인할 수 있습니다. 이는 위에서 소개한 내용과 일치합니다. `delta`는 새로 추가된 답변 내용이며, 결과에 따라 귀하의 시스템에 연동할 수 있습니다. 스트리밍 응답은 `response.completed` 또는 `response.incomplete`를 최종 상태로 사용합니다. 최종 상태의 `usage`는 이번 요청의 최종 token 사용량이며, 과금 기준이기도 합니다.

클라이언트가 최종 상태가 도착하기 전에 연결을 끊으면, 이번 요청은 클라이언트가 종료됨(499)으로 기록되며, 로컬 추정 token을 사용하여 과금되지 않습니다. 연결이 정상적으로 종료되었지만 최종 상태 및 최종 `usage`를 수신하지 못한 경우, 이번 요청은 응답 불완전(502)으로 기록되며, 마찬가지로 추정 token을 사용하여 과금되지 않습니다. 이 두 가지 상황이 발생하면 요청을 다시 시작하십시오.

반환되는 `data` 결과에는 여러 필드가 있으며, 다음과 같이 소개합니다:

- `item_id`, 이번 대화 작업을 생성한 ID로, 이번 대화 작업을 고유하게 식별하는 데 사용됩니다.
- `type`, 이번 대화 Responses 작업을 생성하는 유형입니다.
- `model `, 선택한 OpenAI ChatGPT 공식 웹사이트 모델입니다.
- `delta`, ChatGPT가 질문어에 대해 제공하는 답변 정보입니다.

JavaScript도 지원되며, 예를 들어 Node.js의 스트리밍 호출 코드는 다음과 같습니다:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer b82d32f570bc434d9ba9923aa0e7dce0",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4.1",
    input: [{ role: "user", content: "Hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/responses", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Java 예제 코드:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "gpt-4.1");
jsonObject.put("input", [{"role":"user","content":"Hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/openai/responses")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer b82d32f570bc434d9ba9923aa0e7dce0")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

다른 언어는 별도로 직접 수정할 수 있으며, 원리는 모두 같습니다.

## 다중 턴 대화

다중 턴 대화 기능을 연동하려면 `input` 필드에 여러 질문어를 업로드해야 하며, 여러 질문어의 구체적인 예시는 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/1jqwnf.png" width="400" className="m-auto" /></p>

Python 예제 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/openai/responses"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hello! How can I help you today? 😊"},{"role":"user","content":"What did I just say?"}]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

여러 질문어를 업로드하면 다중 턴 대화를 쉽게 구현할 수 있으며, 다음과 같은 답변을 얻을 수 있습니다:

## 비전 모델

gpt-4o는 OpenAI가 개발한 멀티모달 대규모 언어 모델로, GPT-4를 기반으로 시각 이해 능력이 추가되었습니다. 이 모델은 텍스트와 이미지 입력을 동시에 처리하여 크로스모달 이해와 생성을 구현합니다.
gpt-4o 모델을 사용한 텍스트 처리는 위의 기본 사용 내용과 일치하며, 아래에서는 모델의 이미지 처리 능력을 사용하는 방법을 간략히 소개합니다.

gpt-4o 모델의 이미지 처리 능력은 기존 `content` 내용에 `type` 필드를 추가하는 방식으로 주로 사용하며, 해당 필드를 통해 업로드된 것이 텍스트인지 이미지인지 알 수 있으므로 gpt-4o 모델의 이미지 처리 능력을 사용할 수 있습니다. 아래에서는 주로 Curl과 Python 두 가지 방식으로 해당 기능을 호출하는 방법을 설명합니다.

- Curl 스크립트 방식

```
curl -X POST 'https://api.acedata.cloud/openai/responses' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }'
```

- Python 스크립트 방식

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4.1",
    "input": [
      {
        "role": "user",
        "content": [
          {"type": "input_text", "text": "what is in this image?"},
          {
            "type": "input_image",
            "image_url": "https://cdn.acedata.cloud/e724d7f13d.png"
          }
        ]
      }
    ]
  }

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 오류 처리

API를 호출할 때 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면 다음과 같습니다:

- `400 token_mismatched`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `401 invalid_token`: 권한이 없으며, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`: 요청이 너무 많으며, 속도 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류이며, 서버에서 문제가 발생했습니다.
