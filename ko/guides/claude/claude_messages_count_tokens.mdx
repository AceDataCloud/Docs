Claude Messages Count Tokens API는 실제로 메시지를 생성하지 않고도 도구, 이미지 및 문서 등의 콘텐츠에 대한 Token 수를 포함하여 하나의 Message의 입력 Token 수를 계산할 수 있습니다. 이는 비용을 예상하거나 입력이 모델 컨텍스트 제한을 초과하는지 확인해야 할 때 매우 유용합니다.

이 문서는 주로 Claude Messages Count Tokens API의 사용 절차를 소개합니다.

## 신청 절차

Claude Messages Count Tokens API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않았다면 로그인 페이지로 자동 이동하여 등록 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공통 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## 기본 사용

Claude Messages Count Tokens API의 요청 경로는 `/v1/messages/count_tokens`이며, Anthropic 공식 API와 일치합니다. 최소한 다음 두 개의 필수 파라미터를 제공해야 합니다.

- `model`: 사용할 Claude 모델을 선택합니다. `claude-opus-5-5`는 최신 플래그십 `claude-fable-5-1`과 같이 Messages Token Count에 사용할 수 있으며, 기존 `claude-fable-5`도 계속 호환하여 유지됩니다.
- `messages`: 입력 메시지 배열이며, 각 메시지는 `role`(역할)과 `content`(내용)를 포함합니다.

일반적으로 사용하는 선택적 파라미터:

- `system`: 시스템 프롬프트이며, Token 수에 포함됩니다.
- `tools`: 도구 정의이며, Token 수에 포함됩니다.
- `thinking`: 확장 사고 구성입니다.
- `tool_choice`: 도구 선택 구성입니다.
- `cache_control`: 최상위 또는 콘텐츠 블록 수준의 캐시 제어 구성입니다.

`messages`, `system`, 도구 호출 재생, URL 이미지 및 document/PDF 콘텐츠 블록은 Messages API와 동일한 안정적인 요청 구조를 사용합니다.

### cURL 예시

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Python 예시

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

반환 결과 예시:

```json
{
  "input_tokens": 11
}
```

### Anthropic SDK 사용

Claude Messages Count Tokens API는 Anthropic SDK의 안정적인 요청 구조를 허용하며, `anthropic` 라이브러리를 통해 호출할 수 있습니다. 인터페이스는 선택한 모델에 해당하는 네이티브 Count Tokens 기능을 사용하여 입력을 집계하며, Messages 요청을 보내기 전에 입력 규모를 확인하는 데 사용할 수 있습니다.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## 도구를 포함한 Token 계산

요청에 도구 정의가 포함된 경우, 이러한 도구도 Token 수에 포함됩니다.

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## 시스템 프롬프트를 포함한 Token 계산

시스템 프롬프트도 Token 수에 포함됩니다.

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## 주의 사항

- 이 API는 입력 Token 수만 계산하며, 어떠한 모델 출력도 생성하지 않습니다.
- Token 계산 결과는 입력 규모를 예상하고 컨텍스트 창을 확인하는 데 사용할 수 있으며, 최종 청구는 실제 Messages 응답의 `usage`를 기준으로 합니다.
- 이미지, PDF, 도구 정의, 시스템 프롬프트 및 thinking 구성은 선택한 모델의 입력 규칙에 따라 결과에 포함됩니다.
- 이 API는 완전히 무료이며, 어떠한 크레딧도 소모하지 않습니다.
