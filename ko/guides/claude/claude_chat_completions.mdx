Anthropic Claude는 매우 강력한 AI 대화 시스템으로, 프롬프트를 입력하기만 하면 짧게는 몇 초 안에 매끄럽고 자연스러운 응답을 생성할 수 있습니다. Claude는 뛰어난 언어 이해 및 생성 능력으로 업계에서 독보적이며, 오늘날 Claude는 이미 다양한 산업과 분야에서 폭넓게 활용되고 있고 그 영향력은 더욱 두드러지고 있습니다. 일상 대화, 창의적 글쓰기, 전문 상담, 코드 프로그래밍을 막론하고 Claude는 놀라운 지능형 지원을 제공하여 인간의 업무 효율성과 창의성을 크게 향상할 수 있습니다.

이 문서는 주로 Claude Chat Completion API 작업의 사용 절차를 소개하며, 이를 활용하면 공식 Claude의 대화 기능을 쉽게 사용할 수 있습니다.

## Claude Fable 5.2

전체 모델명 `claude-fable-5-2`를 사용합니다. 이 모델은 복잡한 추론과 장기 작업에 적합합니다. 네이티브 사고 콘텐츠 블록 및 도구 상호작용이 필요한 경우 Messages를 우선 사용합니다. 적응형 사고는 계속 활성화되어 있으므로 `temperature`, `top_p`, `top_k`는 생략하고, 도구 선택에는 `auto`를 사용하며 도구를 강제로 지정하지 마세요. `max_tokens`는 사고와 최종 텍스트를 모두 포함합니다. 현재 이 모델에는 Responses 및 Count Tokens 인터페이스가 제공되지 않습니다.

현재 최대 요금제(142,800 Credits／$13,584) 기준으로 환산하면, Fable 5.2의 일반 입력은 백만 token당 $3.20, 출력은 $16입니다. 캐시 읽기는 $0.08이며, 5분／1시간 캐시 쓰기는 각각 백만 token당 $4／$6.40입니다. 위 가격은 공식 표준 API 단가의 40%(60% 저렴)이며, 기타 요금제 및 계정 추가 할인은 모델 가격 페이지와 청구서를 기준으로 하세요.

## 신청 절차

Claude Chat Completion API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 보관해 두세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않았다면 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스별로 별도 신청할 필요가 없습니다.** 처음 신청하면 무료 크레딧이 제공되어 무료로 체험할 수 있습니다. 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

## 기본 사용

이제 그림과 같이 인터페이스에서 해당 내용을 입력할 수 있습니다.

<p><img src="https://cdn.acedata.cloud/ejeq57.png" width="400" className="m-auto" /></p>

이 인터페이스를 처음 사용할 때는 최소 세 가지 내용을 입력해야 합니다. 하나는 `authorization`으로, 드롭다운 목록에서 직접 선택하면 됩니다. 또 다른 매개변수는 `model`이며, `claude-opus-5-5`, `claude-fable-5-1` 등의 공개 모델을 선택할 수 있습니다. 기존 `claude-fable-5`도 계속 호출할 수 있습니다. 마지막 매개변수는 `messages`이며, 이는 질문 문구 배열로 각 요소는 `role`과 `content`를 포함합니다. `role`은 `user`, `assistant`, `system`을 지원하고, `content`는 구체적인 내용입니다. 완전한 Claude 사고 콘텐츠 블록, 서명 및 네이티브 도구 의미 체계가 필요한 경우에는 여전히 Messages API를 사용하세요.

동시에 오른쪽에 해당 호출 코드가 생성되는 것을 확인할 수 있으며, 코드를 복사하여 바로 실행하거나 「Try」 버튼을 직접 클릭하여 테스트할 수 있습니다.

자주 사용하는 선택 매개변수:

- `max_tokens`: 단일 응답의 최대 token 수를 제한합니다.
- `temperature`: 생성 무작위성이며, 0-2 사이에서 값이 클수록 더 발산합니다.
- `n`: 한 번에 생성하는 후보 응답 수입니다.
- `response_format`: 반환 형식 설정입니다.

`claude-opus-5-5`는 일반 및 스트리밍 Chat Completions를 지원하며, 이 모델은 `n=1`만 허용합니다. 1보다 낮은 `temperature` 또는 기본값이 아닌 `top_p`를 설정하지 마세요. 도구 호출에는 `tool_choice: "auto"`를 사용하고 도구를 강제로 지정하지 마세요. Chat 호환 인터페이스는 네이티브 사고 콘텐츠 블록을 반환하지 않습니다.

<p><img src="https://cdn.acedata.cloud/v6lbjo.png" width="400" className="m-auto" /></p>

호출 후 반환 결과는 다음과 같습니다.

```json
{
  "id": "msg_bdrk_01Q6WN27v95ypCa1kbanAQ6K",
  "model": "claude-opus-4-8",
  "object": "chat.completion",
  "created": 1768619365,
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 8,
    "completion_tokens": 12,
    "total_tokens": 20,
    "prompt_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "completion_tokens_details": {
      "reasoning_tokens": 0
    }
  }
}
```

반환 결과에는 여러 필드가 있으며, 소개는 다음과 같습니다.

- `id`: 이번 대화 작업을 생성하는 ID로, 이번 대화 작업을 고유하게 식별하는 데 사용됩니다.
- `model `: 선택한 Claude 공식 웹사이트 모델입니다.
- `choices`: Claude가 질문 문구에 대해 제공한 응답 정보입니다.
- `usage `: 이번 질의응답 쌍의 token 통계 정보입니다.

Chat Completions 형식에서 `usage.prompt_tokens`는 총 입력량입니다. `prompt_tokens_details.cached_tokens`와 `prompt_tokens_details.cache_write_tokens`는 각각 캐시 읽기 및 쓰기 세부 정보를 기록합니다. `completion_tokens_details.reasoning_tokens`는 `completion_tokens`의 하위 집합이므로, 총량 또는 비용을 계산할 때 다시 더하지 마세요. 비스트리밍 응답은 `usage.cost` 객체를 반환할 수도 있으며, 이 중 `amount`는 실제 크레딧 소모량, `currency`는 계량 단위, `list_amount`는 할인 전 금액(해당하는 경우)입니다.

Chat-compatible의 필드명은 `reasoning_tokens`이며, 네이티브 Messages API는 `output_tokens_details.thinking_tokens`를 사용합니다. 두 프로토콜의 wire schema는 서로 다르므로 클라이언트는 필드명을 혼용해서는 안 됩니다.

그중 `choices`에는 Claude의 응답 정보가 포함되어 있으며, 그 안의 `choices`는 Claude 응답의 구체적인 정보로 그림과 같이 확인할 수 있습니다.

<p><img src="https://cdn.acedata.cloud/2ulyhw.png" width="400" className="m-auto" /></p>

`choices` 내부의 `content` 필드에는 Claude 응답의 구체적인 내용이 포함되어 있음을 확인할 수 있습니다.

## 스트리밍 응답

이 인터페이스는 스트리밍 응답도 지원하며, 이는 웹페이지 연동에 매우 유용하여 웹페이지에서 한 글자씩 표시하는 효과를 구현할 수 있습니다.

스트리밍 방식으로 응답을 반환하려면 요청 헤더의 `stream ` 매개변수를 변경하여 `true`로 수정할 수 있습니다.

그림과 같이 수정하면 되지만, 호출 코드는 스트리밍 응답을 지원하도록 해당 변경이 필요합니다.

<p><img src="https://cdn.acedata.cloud/ueugot.png" width="400" className="m-auto" /></p>
`stream`을 `true`로 수정한 후, API는 해당 JSON 데이터를 줄 단위로 반환하며, 코드 수준에서 줄 단위 결과를 얻기 위해 համապատասխան하는 수정이 필요합니다.

Python 예제 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

보시다시피 응답에는 많은 `data`가 있으며, `data` 안의 `choices`가 최신 답변 내용으로, 앞서 소개한 내용과 일치합니다. `choices`는 새로 추가된 답변 내용이며, 결과에 따라 귀하의 시스템에 연동할 수 있습니다. 또한 스트리밍 응답의 종료는 `data`의 내용에 따라 판단하며, 내용이 `[DONE]`이면 스트리밍 응답의 답변이 모두 종료되었음을 의미합니다. 반환되는 `data` 결과에는 여러 필드가 있으며, 다음과 같이 소개합니다:

- `id`, 이번 대화 작업을 생성하는 ID로, 이번 대화 작업을 고유하게 식별하는 데 사용됩니다.
- `model `, 선택한 Claude 공식 웹사이트 모델입니다.
- `choices`, Claude가 질문어에 대해 제공하는 답변 정보입니다.

JavaScript도 지원되며, 예를 들어 Node.js의 스트리밍 호출 코드는 다음과 같습니다:

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "claude-opus-4-20250514",
    messages: [{ role: "user", content: "Hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/v1/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```

Java 예제 코드:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "claude-opus-4-20250514");
jsonObject.put("messages", [{"role":"user","content":"Hello"}]);
jsonObject.put("stream", true);
MediaType mediaType = "application/json; charset=utf-8".toMediaType();
RequestBody body = jsonObject.toString().toRequestBody(mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/v1/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.print(response.body!!.string())
```

다른 언어는 별도로 직접 수정할 수 있으며, 원리는 모두 같습니다.

## 다중 턴 대화

다중 턴 대화 기능을 연동하려면 `messages` 필드에 여러 질문어를 업로드해야 하며, 여러 질문어의 구체적인 예시는 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/odwx82.png" width="400" className="m-auto" /></p>

Python 예제 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-opus-4-20250514",
    "messages": [{"role":"user","content":"Hello"},{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What I say just now?"}]

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 심층 사고

차세대 Claude 모델은 모델 기본 전략에 따라 추론할 수 있으며, `-thinking` 모델 접미사를 통해 활성화할 필요가 없을 수 있습니다. Chat-compatible 응답은 OpenAI 호환 usage 필드인 `completion_tokens_details.reasoning_tokens`를 사용합니다. `reasoning_tokens`는 이미 `completion_tokens`에 포함되어 있으므로 중복하여 더하지 마십시오. 추론과 표시되는 본문은 출력 token 상한을 공유하므로, `max_tokens`가 작으면 본문이 비어 있거나 잘릴 수 있습니다. 이 경우 출력 예산을 늘리거나, 사용하는 모델이 지원하는 경우 더 낮은 추론 투입을 선택하십시오.

네이티브 `thinking`, `output_config.effort`, thinking 콘텐츠 블록 및 서명 반환이 필요한 경우 `/v1/messages`를 사용하십시오. Messages에 해당하는 usage 필드는 `output_tokens_details.thinking_tokens`이며, Chat-compatible의 `completion_tokens_details.reasoning_tokens`와 혼용하지 마십시오.

## 비전 모델

- Python 스크립트 방식

```python
import requests

url = "https://api.acedata.cloud/v1/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "claude-sonnet-4-20250514",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "What's in this image?"
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://cdn.acedata.cloud/ueugot.png"
                    }
                },
            ],
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 오류 처리

API를 호출할 때 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면 다음과 같습니다.

- `400 token_mismatched`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `401 invalid_token`: 인증되지 않음, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`: 요청이 너무 많으며, 속도 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류이며, 서버에서 문제가 발생했습니다.
