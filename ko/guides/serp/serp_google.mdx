Google SERP(검색 엔진 결과 페이지)는 사용자가 Google 검색 엔진에 쿼리를 입력한 후 보는 결과 페이지입니다. 이 페이지는 자연 검색 결과, 광고, 특징 요약, 지식 그래프, 이미지, 비디오 등 다양한 콘텐츠를 표시하여 사용자에게 가장 관련성 높은 정보를 제공하는 것을 목표로 합니다.

본 문서에서는 Google SERP API에 대해 자세히 설명하며, Google 검색 엔진에 쿼리를 입력하여 결과를 얻을 수 있는 API로, 결과의 내용은 특징 요약, 지식 그래프, 이미지 등 다양한 유형을 포함합니다.

이 문서에서는 Google SERP API의 연동 설명을 소개합니다.

## 신청 절차

Google SERP API를 사용하려면 먼저 [Google SERP API](https://platform.acedata.cloud/documents/serp-google) 해당 페이지에서 서비스를 신청해야 하며, 페이지에 들어가면 "Acquire" 버튼을 클릭합니다. 아래 그림과 같이:

![](https://cdn.acedata.cloud/q6ytrc.png)

로그인 또는 등록이 되어 있지 않으면 자동으로 로그인 페이지로 이동하여 등록 및 로그인을 요청합니다. 로그인 및 등록 후에는 자동으로 현재 페이지로 돌아옵니다.

첫 신청 시 무료 크레딧이 제공되어 해당 API를 무료로 사용할 수 있습니다.

## 기본 사용

먼저 기본 사용 방식을 이해해야 합니다. 검색 리소스 유형과 키워드를 입력하면 검색 결과를 얻을 수 있으며, 간단히 `query` 필드를 전달하고 해당 모델을 지정하면 됩니다.

예를 들어 "apple inc"에 대한 정보를 찾고자 할 경우, 다음과 같이 인터페이스에 해당 내용을 입력할 수 있습니다. 아래 그림과 같이:

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

여기서 설정한 Request Headers는 다음과 같습니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지, 여기서는 `application/json` 즉 JSON 형식으로 입력합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 바로 드롭다운에서 선택할 수 있습니다.

또한 Request Body를 설정합니다:

- `type`: 검색 리소스의 유형으로 현재는 6가지 유형만 지원하며 기본값은 `search`입니다.
- `query`: 검색할 키워드입니다.
- `country`: 검색 결과의 국가를 사용자 정의하며 기본값은 미국(US)입니다.
- `language`: 검색 결과의 언어를 사용자 정의하며 기본값은 영어(en)입니다.
- `range`: 검색 결과의 시간 범위를 사용자 정의하며 기본값은 제한 없음입니다.
- `number`: 검색 결과의 페이지 크기를 사용자 정의하며 기본값은 10입니다.
- `page`: 검색 결과의 페이지 수를 사용자 정의하며 기본값은 1입니다.

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

## 사용자 정의 검색 결과 시간 범위
本文은 검색 결과의 시간 범위를 사용자 정의할 수 있으며, 다섯 가지가 포함되어 있습니다. 각각은 `qdr:h`(지난 한 시간), `qdr:d`(지난 하루), `qdr:w`(지난 일주일), `qdr:m`(지난 한 달), 기본적으로 제한 없음입니다. 우리는 `range`를 통해 해당 시간 범위를 전달할 수 있습니다. 예를 들어, 여기서 `qdr:d`로 설정하면 지난 하루의 결과를 검색하는 것을 의미하므로 입력은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## 사용자 정의 검색 결과 페이지 매김

이 API는 검색 결과의 페이지 매김 표시를 사용자 정의할 수 있으며, `number`와 `page`는 페이지의 크기와 페이지 수를 나타냅니다. 본문에서는 한 페이지에 20개의 검색 결과가 있는 형태로 페이지 매김을 설정할 것입니다. 구체적인 정보는 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/dqla1e.png" width="500" className="m-auto" /></p>

> 주의: 각 페이지의 결과가 10개를 초과할 경우, 차감되는 포인트가 두 배가 됩니다.

코드는 다음과 같습니다:
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
}'
```
