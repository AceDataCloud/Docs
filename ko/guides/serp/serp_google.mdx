Google SERP(Search Engine Results Page)는 사용자가 Google 검색 엔진에 검색어를 입력한 후 보게 되는 결과 페이지입니다. 자연 검색 결과, 광고, 추천 스니펫, 지식 그래프 및 이미지, 동영상 등 다양한 콘텐츠를 표시하며, 사용자에게 가장 관련성 높은 정보를 제공하는 것을 목적으로 합니다.

이 글에서는 Google SERP API를 자세히 소개합니다. 이 API는 Google 검색 엔진에 검색어를 입력하여 결과를 가져올 수 있으며, 결과 콘텐츠에는 추천 스니펫, 지식 그래프 및 이미지 등 다양한 유형의 결과도 포함됩니다.

이 문서에서는 Google SERP API의 연동 설명을 소개합니다.

## 신청 절차

Google SERP API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않은 경우, 로그인 페이지로 자동 이동하여 등록 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족한 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Google SERP API →](https://platform.acedata.cloud/documents/serp-google)

## 기본 사용

키워드와 검색 리소스 유형을 입력하면 결과를 얻을 수 있습니다. `query`로 키워드를 전달하고, `type`으로 웹페이지, 이미지, 뉴스 등의 검색 유형을 선택합니다. 이 인터페이스는 `model`을 전달할 필요가 없습니다.

예를 들어 “apple inc”에 대한 정보를 찾는 경우, 다음으로 인터페이스에 해당 내용을 입력할 수 있으며, 그림과 같습니다.

<p><img src="https://cdn.acedata.cloud/lnqiye.png" width="500" className="m-auto" /></p>

여기에서 다음을 포함한 Request Headers를 설정한 것을 확인할 수 있습니다.

- `accept`: 어떤 형식의 응답 결과를 수신할지 지정합니다. 여기서는 `application/json`, 즉 JSON 형식으로 입력합니다.
- `authorization`: API를 호출하는 키이며, 신청 후 직접 드롭다운에서 선택할 수 있습니다.

또한 다음을 포함한 Request Body를 설정했습니다.

- `type`: 검색 리소스의 유형입니다. 현재 여섯 가지 유형만 지원하며, 기본값은 `search`입니다.
- `query`: 검색 키워드입니다.
- `country`: 검색 결과의 국가를 사용자 지정하며, 기본값은 미국(US)입니다.
- `language`: 검색 결과의 언어를 사용자 지정하며, 기본값은 영어(en)입니다.
- `range`: 검색 결과의 시간 범위를 사용자 지정하며, 기본값은 제한 없음입니다.
- `number`: 검색 결과의 페이지네이션 페이지 크기를 사용자 지정하며, 기본값은 10입니다.
- `page`: 검색 결과의 페이지네이션 페이지 번호를 사용자 지정하며, 기본값은 1입니다.

반환 결과에는 여러 필드가 있으며, 다음과 같이 소개합니다:

- `knowledge_graph`, 검색 결과의 지식 그래프입니다.
- `organic`, 검색 결과의 상세 정보입니다.
- `people_also_ask`, 검색 키워드와 관련된 질문입니다.
- `related_searches`, 검색 키워드에 대한 관련 검색입니다.

여기서 반환된 결과에는 `organic` 필드가 있으며, 이는 주로 검색 키워드의 결과를 포함합니다.

또한 해당 연동 코드를 생성하려면 직접 복사하여 생성할 수 있습니다. 예를 들어 CURL 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc"
}'
```

Python 연동 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/serp/google"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "query": "apple inc"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 사용자 지정 검색 유형

검색 리소스의 유형을 사용자 지정하려면 `type` 매개변수를 수정할 수 있으며, 여기에는 일반 리소스 `search`, 이미지 리소스 `images`, 뉴스 리소스 `news`, 지도 리소스 `maps`, 지역 리소스 `places`, 동영상 리소스 `videos`가 포함됩니다. 이 글에서는 동영상 리소스 `videos`를 예시로 들어 설명하겠습니다.

아래에서 구체적인 작업을 시연해 보겠습니다.

먼저 `type` 매개변수를 `videos`로 설정하고, 정상적으로 `query` 매개변수를 전달합니다. 그림과 같습니다:
<p><img src="https://cdn.acedata.cloud/czlt12.png" width="500" className="m-auto" /></p>

해당 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "videos",
  "query": "apple inc"
}'
```

검색 결과의 언어도 사용자 지정할 수 있습니다. 여기서는 `language` 필드를 추가하고 내용을 `zh-cn`으로 설정합니다. 이는 중국어 간체 언어를 의미하며, 다른 언어도 지원하지만 en(English), fr(French), zh-cn(Chinese(Simplified)) 등의 언어 약어를 입력해야 합니다. 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/yyrssp.png" width="500" className="m-auto" /></p>

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "type": "news",
  "query": "apple inc",
  "language": "zh-cn"
}'
```

## 검색 결과 시간 범위 사용자 지정
본문에서는 검색 결과의 시간 범위도 사용자 지정할 수 있으며, 총 다섯 가지가 포함됩니다. 각각 `qdr:h`(지난 한 시간), `qdr:d`(지난 하루), `qdr:w`(지난 일주일), `qdr:m`(지난 한 달), 기본값인 제한 없음입니다. `range`를 통해 해당 시간 범위를 전달하면 됩니다. 예를 들어 여기서는 `qdr:d`로 설정했으며, 이는 지난 하루의 결과를 검색한다는 의미이므로 입력은 다음과 같습니다.

<p><img src="https://cdn.acedata.cloud/qccfib.png" width="500" className="m-auto" /></p>

해당 코드는 다음과 같습니다.

```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "range": "qdr:d",
  "query": "apple inc"
}'
```

## 검색 결과 페이지네이션 사용자 지정

본 API는 검색 결과의 페이지네이션 표시도 사용자 지정할 수 있습니다. `number`와 `page`는 페이지네이션의 페이지 크기와 페이지 수를 나타내며, 본문에서는 한 페이지에 20개의 검색 결과가 있는 형식으로 페이지네이션을 표시하도록 설정하겠습니다. 구체적인 정보는 그림과 같습니다.

코드는 다음과 같습니다.
```shell
curl -X POST 'https://api.acedata.cloud/serp/google' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "query": "apple inc",
  "number": 20,
  "page": 1
}'
```
