본 문서는 HappyHorse 비디오 API의 연동 방법을 소개합니다. 이 인터페이스는 통일된 `/happyhorse/videos` 진입점과 `action` 매개변수를 통해 문생 비디오, 첫 프레임 이미지 생 비디오, 참고 이미지 생 비디오 및 비디오 편집을 지원합니다.

## 신청 절차

HappyHorse 비디오 API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API 토큰을 받아야 합니다. 이를 보관해 두십시오.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

로그인 또는 등록이 되어 있지 않은 경우, 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 요청합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API 토큰으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스에 대해 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 할당량이 제공되어 무료로 체험할 수 있습니다; 할당량이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [HappyHorse 비디오 API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## 작업 유형

`action`은 이번 요청의 생성 모드를 결정합니다:

- `generate`: 문생 비디오, 기본 action, `happyhorse-1.0-t2v` 및 `happyhorse-1.1-t2v`를 지원하며, `prompt`를 반드시 전달해야 합니다.
- `image_to_video`: 첫 프레임 이미지 생 비디오, `happyhorse-1.0-i2v` 및 `happyhorse-1.1-i2v`를 지원하며, `image_url`을 반드시 전달해야 합니다.
- `reference_to_video`: 참고 이미지 생 비디오, `happyhorse-1.0-r2v` 및 `happyhorse-1.1-r2v`를 지원하며, `prompt`와 1–9장의 `image_urls`를 반드시 전달해야 합니다.
- `video_edit`: 비디오 편집, `happyhorse-1.0-video-edit`를 지원하며, `prompt`와 `video_url`을 반드시 전달해야 하며, 추가로 0–5장의 참고 이미지 `image_urls`를 전달할 수 있습니다.

각 동작은 기본적으로 1.1 모델을 사용하며; `video_edit`는 현재 `happyhorse-1.0-video-edit`만 지원합니다.

## 기본 사용

문생 비디오는 `prompt`만 제공하면 되며, `resolution`, `ratio`, `duration` 등의 매개변수를 지정할 수도 있습니다:

```json
{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

반환 결과 예시는 다음과 같습니다:

```json
{
  "success": true,
  "task_id": "27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1",
  "trace_id": "6071ab5e-2f37-46f0-9e07-f1e378112e69",
  "data": [
    {
      "id": "9650580f-6d9e-4bc1-823a-29011790c5cb",
      "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
      "state": "succeeded",
      "duration": 5,
      "resolution": "720P",
      "ratio": null
    }
  ]
}
```

필드 설명:

- `success`: 이번 요청이 성공했는지 여부.
- `task_id`: Ace Data Cloud 측의 작업 ID로, 작업 상태를 조회하는 데 사용할 수 있습니다.
- `trace_id`: 이번 요청의 추적 ID로, 문제를 해결하는 데 사용됩니다.
- `data`: 비디오 결과 목록.
  - `id`: HappyHorse 측의 작업 ID.
  - `video_url`: 생성된 비디오의 CDN 링크 주소.
  - `state`: 작업 상태, 선택 사항으로 `pending` / `succeeded` / `error`가 있습니다.
  - `duration`: 청구 비디오 길이, 단위는 초; `video_edit`는 입력 및 출력 비디오 길이의 합계입니다.
  - `resolution`: 출력 해상도.
  - `ratio`: 출력 가로 세로 비율.

해당 CURL 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/happyhorse/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "happyhorse-1.1-t2v",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}'
```

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/happyhorse/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}

payload = {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
    "resolution": "720P",
    "ratio": "16:9",
    "duration": 5,
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 첫 프레임 이미지 생 비디오

`image_to_video`를 사용할 때, `image_url`은 비디오의 첫 프레임으로 사용됩니다. 출력 가로 세로 비율은 첫 프레임 이미지에 최대한 맞추어지므로, 이 동작에서는 `ratio`를 전달할 필요가 없습니다.

```json
{
  "action": "image_to_video",
  "model": "happyhorse-1.1-i2v",
  "image_url": "https://cdn.acedata.cloud/b1c82e4937.png",
  "prompt": "A cinematic white horse lifts its head, the mane moves gently in the sunrise wind, slow camera push in, warm film lighting",
  "resolution": "1080P",
  "duration": 5
}
```

## 참고 이미지 생 비디오

`reference_to_video`를 사용할 때, `image_urls`에는 1–9장의 참고 이미지를 전달할 수 있습니다. 프롬프트에서는 `character1`, `character2` 등의 방식으로 해당 순서의 이미지를 참조할 수 있습니다.

```json
{
  "action": "reference_to_video",
  "model": "happyhorse-1.1-r2v",
  "prompt": "character1 walks forward through a sunrise meadow with the warm leather and gold trim style from character2",
  "image_urls": [
    "https://cdn.acedata.cloud/b1c82e4937.png",
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "ratio": "16:9",
  "duration": 5
}
```

## 비디오 편집

`video_edit`를 사용할 때는 반드시 편집할 비디오 `video_url`과 편집 의도 `prompt`를 전달해야 합니다. 선택적인 `image_urls`는 참고 이미지로 사용되며, 예를 들어 의상 변경, 스타일 전이 또는 부분 교체에 사용됩니다. `audio_setting`은 `auto` 또는 `origin`을 선택할 수 있으며, `origin`은 원본 비디오 오디오를 유지하는 것을 의미합니다.

```json
{
  "action": "video_edit",
  "model": "happyhorse-1.0-video-edit",
  "prompt": "Apply the warm leather and gold trim style from the reference image while preserving the original camera motion",
  "video_url": "https://platform2.cdn.acedata.cloud/happyhorse/27837f92-d1c1-4db4-ad9a-4e6e81d9f6c1.mp4",
  "image_urls": [
    "https://cdn.acedata.cloud/eb75d88a3f.png"
  ],
  "resolution": "720P",
  "audio_setting": "auto"
}
```

## 비동기 콜백
비디오 생성에는 일정한 처리 시간이 필요합니다. 긴 연결을 유지하고 싶지 않다면 `callback_url`을 전달할 수 있으며, 이 경우 API는 즉시 `task_id`를 반환하고, 작업이 완료되면 최종 결과를 해당 주소로 POST합니다:

```json
{
  "action": "generate",
  "prompt": "A horse running through a snowy forest",
  "duration": 5,
  "callback_url": "https://your-domain.com/callback/happyhorse"
}
```

즉시 반환된 결과는 다음과 같습니다:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

단순히 폴링만 원하고 콜백이 필요 없다면 `"async": true`를 전달할 수 있으며, 이후 [HappyHorse Tasks API](https://platform.acedata.cloud/documents/happyhorse-tasks)를 통해 작업 결과를 조회할 수 있습니다.

## 요금 설명

HappyHorse는 출력 비디오의 초수와 해상도에 따라 요금을 부과합니다:

- `720P`: 초당 약 $0.105부터 시작합니다.
- `1080P`: 초당 약 $0.18부터 시작합니다.
- `video_edit`: 입력 비디오와 출력 비디오의 총 길이에 따라 요금이 부과되며, 실제 요금은 작업 완료 후 통계에 따라 결정됩니다.

실패한 작업은 요금이 부과되지 않으며, 무료 한도를 차지하지 않습니다.

## 오류 처리

요청에 문제가 발생하면 API는 해당 오류 코드와 설명을 반환하며, 일반적인 오류는 다음과 같습니다:

- `400`: 요청 매개변수가 잘못되었습니다. 예를 들어 action과 model이 일치하지 않거나, `prompt` / `image_url` / `video_url`이 누락되었거나, `duration`이 3–15초 범위를 초과했습니다.
- `401`: 인증 실패, 토큰이 유효하지 않거나 API와 일치하지 않습니다.
- `403`: 잔액 부족 또는 프롬프트가 콘텐츠 검토에 의해 거부되었습니다.
- `429`: 요청이 너무 빈번하여 속도 제한이 발생했습니다. 잠시 후 다시 시도해 주세요.
- `500`: 서버 내부 오류 또는 생성 실패입니다.
