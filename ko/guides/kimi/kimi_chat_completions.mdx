Kimi는 Moonshot AI가 출시한 AI 모델 시리즈입니다. 현재는 장기 프로그래밍, 복잡한 추론, 시각 이해 및 지식 작업에 적합한 `kimi-k3.1-pro`를 권장하며, `kimi-k3`도 계속 사용할 수 있습니다. OpenAI 호환 Chat Completions API를 통해 호출합니다.

이 문서는 주로 Kimi Chat Completion API 작업의 사용 절차를 소개하며, 이를 통해 공식 Kimi의 대화 기능을 쉽게 사용할 수 있습니다.

## 신청 절차

Kimi Chat Completion API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인 또는 회원가입하지 않았다면 로그인 페이지로 자동 이동하여 회원가입과 로그인을 안내하며, 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Kimi Chat Completion API →](https://platform.acedata.cloud/documents/kimi-chat-completions)

## 기본 사용

이제 화면에서 해당 내용을 입력할 수 있으며, 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/ej5ozg.png" width="400" className="m-auto" /></p>

이 인터페이스를 처음 사용할 때는 최소 세 가지 내용을 입력해야 합니다: `authorization`은 드롭다운 목록에서 직접 선택할 수 있습니다; `model`은 Kimi 모델을 선택하는 데 사용되며, `kimi-k3.1-pro` 사용을 권장합니다; `messages`는 대화 메시지 배열로, 각 메시지는 `role`과 `content`를 포함하며, `role`은 `user`, `assistant`, `system`, `tool`을 지원합니다.

동시에 오른쪽에 해당 호출 코드가 생성되는 것을 확인할 수 있으며, 코드를 복사하여 바로 실행하거나 「Try」 버튼을 직접 클릭하여 테스트할 수도 있습니다.

<p><img src="https://cdn.acedata.cloud/six7e3.png" width="400" className="m-auto" /></p>

다음은 `reasoning_effort: max`를 사용하여 얻은 실제 K3 응답입니다(사용하지 않은 확장 필드는 생략):

```json
{
  "id": "msg_2D4Btbg1WgvkNE3tCYkR4xGA",
  "object": "chat.completion",
  "created": 1784466588,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help you today?"
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 86,
    "completion_tokens": 206,
    "total_tokens": 292
  }
}
```

반환 결과에는 여러 필드가 있으며, 소개는 다음과 같습니다:

- `id`, 이번 대화 작업의 ID를 생성하며, 이번 대화 작업을 고유하게 식별하는 데 사용됩니다.
- `model `, 선택한 Kimi 공식 웹사이트 모델입니다.
- `choices`Kimi가 질문어에 대해 제공한 답변 정보입니다.
- `usage `: 이번 질의응답 쌍에 대한 token 통계 정보입니다.

그중 `choices`에는 Kimi의 답변 정보가 포함되어 있으며, 그 안의 `choices`는 Kimi 답변의 구체적인 정보로, 그림과 같이 확인할 수 있습니다.

<p><img src="https://cdn.acedata.cloud/tv9rul.png" width="400" className="m-auto" /></p>

확인할 수 있듯이, `choices` 안의 `content` 필드에는 Kimi가 응답한 구체적인 내용이 포함되어 있습니다; K3는 추론 과정을 나타내기 위해 `reasoning_content`를 반환할 수도 있습니다.

## K3.1 Pro 추론 강도

`kimi-k3.1-pro`는 항상 추론을 활성화합니다. 요청 본문 최상위에서 `reasoning_effort`를 `low`, `high` 또는 `max`로 설정할 수 있습니다; 추론을 끄는 설정은 전달하지 마세요. 모델은 최대 1,048,576 token 컨텍스트를 지원하지만, 실제 요청 상한은 여전히 현재 인터페이스를 기준으로 합니다. 가격은 입력, 출력 및 캐시 적중 사용량에 따라 계산되며, 자세한 내용은 모델 디렉터리의 Pricing 카드를 참조하세요.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3.1-pro",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "low"
  }'
```

다음 K3 예시는 기존 통합을 위해 유지되며, 예시 응답은 실제로 K3 요청을 통해 얻었습니다.

## K3 추론 강도

`kimi-k3`는 항상 추론을 활성화합니다. 요청 본문 최상위에서 `reasoning_effort` 필드를 지원하며, 현재 유일하게 지원되는 값은 `max`입니다; 이 필드를 생략해도 `max`가 사용됩니다. `standard`, `high` 또는 기타 문자열은 일부 호환 업스트림에서 느슨하게 허용될 수 있지만, 추론 동작을 변경한다고 보장할 수 없으므로 의존하지 마세요.

```bash
curl https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer $ACEDATACLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kimi-k3",
    "messages": [{"role": "user", "content": "审查这段代码并给出修复方案"}],
    "reasoning_effort": "max"
  }'
```

OpenAI SDK를 사용할 때는 이 필드를 직접 전달할 수 있습니다:

```python
response = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "设计一个可靠的任务队列"}],
    reasoning_effort="max",
)
```

다중 턴 대화 및 도구 호출 시, `reasoning_content`와 `tool_calls`를 포함하여 이전 턴의 완전한 assistant 메시지를 `messages`에 다시 전달하세요.

### 공식 참고 자료

- [Thinking Effort](https://platform.kimi.ai/docs/guide/use-thinking-effort): Kimi K3가 항상 추론을 활성화하며, 현재 `reasoning_effort`에서 유일하게 지원되는 값이 `max`임을 설명합니다.
- [Model Parameter Reference](https://platform.kimi.ai/docs/api/models-overview): K3와 K2 시리즈의 추론 매개변수, 컨텍스트 윈도우 및 도구 호출 차이를 비교합니다.
- [Create Chat Completion](https://platform.kimi.ai/docs/api/chat): Moonshot 공식 Chat Completions 요청, 응답 및 OpenAPI 필드 정의입니다.

## 스트리밍 응답

이 인터페이스는 스트리밍 응답도 지원하며, 이는 웹 페이지 연동에 매우 유용하여 웹 페이지에서 한 글자씩 표시하는 효과를 구현할 수 있습니다.

응답을 스트리밍으로 반환하려면 요청 헤더의 `stream ` 매개변수를 `true`로 변경할 수 있습니다.

그림과 같이 수정하지만, 호출 코드도 스트리밍 응답을 지원할 수 있도록 해당 변경이 필요합니다.

<p><img src="https://cdn.acedata.cloud/a3nzpw.png" width="400" className="m-auto" /></p>

`stream`을 `true`로 수정한 후, API는 해당 JSON 데이터를 줄 단위로 반환하며, 코드 수준에서 줄 단위 결과를 얻기 위해 그에 맞게 수정해야 합니다.

Python 예시 호출 코드:
```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"user","content":"Hello"}],
    "reasoning_effort": "max",
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

다음은 동일한 실제 K3 Max 스트리밍 응답에서 시작, 추론, 본문, 종료 및 사용량 데이터 블록을 발췌한 것입니다:

```json
data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"","role":"assistant"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"reasoning_content":"The"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{"content":"Hello"},"finish_reason":null}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[{"index":0,"delta":{},"finish_reason":"stop"}],"usage":null}

data: {"id":"msg_er7WZjyv2kD3TG2yzbFPu5ZJ","object":"chat.completion.chunk","created":1784466598,"model":"kimi-k3","choices":[],"usage":{"prompt_tokens":172,"completion_tokens":168,"total_tokens":340}}

data: [DONE]
```

보시다시피 응답에는 많은 `data`가 있으며, `data` 내부의 `choices`가 최신 답변 내용으로, 위에서 소개한 내용과 일치합니다. `choices`는 새로 추가된 답변 내용이며, 결과에 따라 귀하의 시스템에 연동할 수 있습니다. 동시에 스트리밍 응답의 종료는 `data`의 내용에 따라 판단하며, 내용이 `[DONE]`이면 스트리밍 응답의 답변이 모두 종료되었음을 나타냅니다. 반환되는 `data` 결과에는 여러 필드가 있으며, 다음과 같습니다:

- `id`, 이번 대화 작업을 생성하는 ID로, 이번 대화 작업을 고유하게 식별하는 데 사용됩니다.
- `model `, 선택한 Kimi 공식 웹사이트 모델입니다.
- `choices`, 질문어에 대해 Kimi가 제공하는 답변 정보입니다.

JavaScript도 지원됩니다. 예를 들어 Node.js의 스트리밍 호출 코드는 다음과 같습니다:

```javascript
const options = {
  method: "POST",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json"
  },
  body: JSON.stringify({
    model: "kimi-k3",
    messages: [{ role: "user", content: "Hello" }],
    stream: true
  })
};

const response = await fetch("https://api.acedata.cloud/kimi/chat/completions", options);
const reader = response.body.getReader();
const decoder = new TextDecoder("utf-8");
while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  process.stdout.write(decoder.decode(value));
}
```

Java 예제 코드:

```java
JSONObject jsonObject = new JSONObject();
jsonObject.put("model", "kimi-k3");
jsonObject.put("messages", new JSONArray().put(new JSONObject().put("role", "user").put("content", "Hello")));
jsonObject.put("stream", true);
MediaType mediaType = MediaType.parse("application/json; charset=utf-8");
RequestBody body = RequestBody.create(jsonObject.toString(), mediaType);
Request request = new Request.Builder()
  .url("https://api.acedata.cloud/kimi/chat/completions")
  .post(body)
  .addHeader("accept", "application/json")
  .addHeader("authorization", "Bearer {token}")
  .addHeader("content-type", "application/json")
  .build();

OkHttpClient client = new OkHttpClient();
Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

다른 언어는 별도로 직접 수정할 수 있으며, 원리는 모두 동일합니다.

## 다중 턴 대화

다중 턴 대화 기능을 연동하려면 `messages` 필드에 여러 질문어를 업로드해야 하며, 여러 질문어의 구체적인 예시는 아래 그림과 같습니다:

<p><img src="https://cdn.acedata.cloud/g85v2a.png" width="400" className="m-auto" /></p>

Python 예제 호출 코드:

```python
import requests

url = "https://api.acedata.cloud/kimi/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "kimi-k3",
    "messages": [{"role":"assistant","content":"Hello! How can I help you today?"},{"role":"user","content":"What model are you?"}],
    "reasoning_effort": "max"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

여러 질문어를 업로드하면 다중 턴 대화를 쉽게 구현할 수 있습니다. 다음은 이 요청으로 얻은 실제 K3 Max 응답입니다(사용되지 않는 확장 필드는 생략):

```json
{
  "id": "msg_Rqp8nPGBDHWwBlL4VpxuafOp",
  "object": "chat.completion",
  "created": 1784466628,
  "model": "kimi-k3",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "I’m Kimi, an AI assistant developed by Moonshot AI (月之暗面). I don’t have a specific public model version identifier to share from here."
      },
      "logprobs": null,
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 134,
    "completion_tokens": 346,
    "total_tokens": 480
  }
}
```

보시다시피 `choices`에 포함된 정보는 기본 사용의 내용과 일치하며, 여기에는 여러 대화에 대해 Kimi가 응답한 구체적인 내용이 포함되어 있습니다. 이렇게 여러 대화 내용을 바탕으로 해당 질문에 답변할 수 있습니다.

## 오류 처리

API 호출 시 오류가 발생하면 API는 해당 오류 코드와 정보를 반환합니다. 예를 들면:

- `400 token_mismatched`: 잘못된 요청이며, 매개변수 누락 또는 유효하지 않은 매개변수 때문일 수 있습니다.
- `400 api_not_implemented`: 잘못된 요청이며, 매개변수 누락 또는 유효하지 않은 매개변수 때문일 수 있습니다.
- `401 invalid_token`: 권한이 없으며, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`: 요청이 너무 많으며, 속도 제한을 초과했습니다.
- `500 api_error`: 내부 서버 오류이며, 서버에서 문제가 발생했습니다.
