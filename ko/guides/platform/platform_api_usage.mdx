특정 API의 최근 15분 내 호출 기록 샘플을 공개적으로 반환하여 최근 상태를 빠르게 관찰하는 데 사용합니다. 이는 상태 코드별로 집계된 카운트 인터페이스가 아니며, 개인 청구서, SLA 또는 완전한 사용량 통계에는 사용할 수 없습니다.

## 인터페이스 개요

| 항목   | 내용                                                           |
| --- | ------------------------------------------------------------ |
| 메서드  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| 인증  | 공개, 계정 토큰 불필요                                                    |
| 상한  | 최근 생성/완료된 기록을 병합한 후 최대 5,000개 반환                                    |

`api_id`는 [API 목록](https://platform.acedata.cloud/documents/platform-api-list)에서 가져옵니다.

```shell
export API_ID='你的 API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## 실제 응답 구조

응답은 페이지네이션 envelope를 사용하지 않고 배열을 직접 반환합니다:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| 필드            | 설명        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | 기록 생성 시간    |
| `trace_id`    | 요청 추적 식별자    |
| `status_code` | HTTP 상태 코드  |
| `elapsed`     | 호출 소요 시간, 단위는 초 |

API가 존재하지 않는 경우에도 현재 빈 배열을 반환할 수 있습니다. 이 action은 API 객체를 먼저 검증하지 않고 ID로 최근 usage를 직접 조회하기 때문입니다. 성공률을 계산하려면 클라이언트가 반환된 샘플을 직접 그룹화해야 하며, 개인 차감을 조회하려면 계정 수준 인터페이스를 사용하십시오.
