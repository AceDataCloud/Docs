Ace Data Cloud는 Hermes Agent 개인 배포 진입점을 제공합니다. 이 진입점은 제어된 서비스로, 사용 가능 여부 및 선택 가능한 리소스는 콘솔 현재 표시를 기준으로 합니다.

## 사용 단계

1. 플랫폼에서 **Hermes Agent 개인 배포**를 찾습니다.
2. 페이지의 안내에 따라 사용 가능한 구성을 선택하고 서비스를 생성합니다.
3. 플랫폼이 준비 상태를 표시할 때까지 기다립니다.
4. 페이지에서 제공된 진입점과 자격 증명을 사용하여 인스턴스에 접근합니다.
5. 먼저 `Reply only OK`를 전송한 후 실제 작업을 시작합니다.

모델, 자격 증명, 저장 및 삭제 행동은 생성 페이지 및 확인 팝업을 기준으로 하며; 로컬 Hermes 튜토리얼의 YAML을 플랫폼 배포 계약으로 직접 사용하지 마십시오. 삭제하기 전에 보존할 데이터를 먼저 내보내십시오.

콘솔에 생성 진입점이 표시되지 않으면 현재 계정에서 해당 서비스가 열리지 않은 것이므로 [Hermes 인터랙티브 가이드](https://platform.acedata.cloud/documents/hermes-wizard-integration) 또는 [수동 구성](https://platform.acedata.cloud/documents/hermes-manual-integration)을 사용하십시오.
