현재 요청 컨텍스트에서 공개 기능 플래그와 국가/지역 판단을 읽습니다. 프런트엔드 시작 시 기능 표시 여부를 결정하는 데 적합합니다. 이는 사이트 브랜드, 연락처 또는 공지 디렉터리가 아닙니다.

## 인터페이스 개요

| 항목   | 내용                                              |
| --- | ----------------------------------------------- |
| 메서드  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| 인증  | 공개; 로그인 상태를 지닌 경우 일부 기능 플래그는 사용자별로 계산될 수 있음                          |

## 쿼리 매개변수 및 요청 헤더

| 이름                    | 위치     | 설명                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | 두 자리 ASCII 국가 코드; 응답의 표시 국가를 재정의하는 데 사용되며 서버 측 보안 판단은 변경하지 않음 |
| `features`            | query  | 기능 플래그 재정의 표현식; 클라이언트 재정의가 허용된 플래그 또는 슈퍼 관리자에게만 적용됨        |
| `X-Feature-Overrides` | header | `features`와 동일한 재정의 소스                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## 실제 응답 구조

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| 필드         | 유형            | 설명                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | 현재 요청에서 보이는 기능 플래그; 키는 플랫폼 구성에 따라 변경될 수 있으므로 클라이언트는 필요에 따라 읽고 누락된 키에 안전한 기본값을 설정해야 함 |
| `country`  | string / null | 소문자 국가 코드; 식별할 수 없는 경우 `null`일 수 있음                     |

이 인터페이스에서 사이트 이름, CDN, 통화, 언어, 고객 서비스 연락처 또는 공지를 읽지 마세요. 이러한 필드는 현재 응답 계약에 속하지 않습니다.

## 사용 권장 사항

- 기능 플래그는 사용자, 지문 및 사이트 컨텍스트에 따라 계산되므로 사용자 간에 장기간 캐시를 공유하지 마세요.
- 클라이언트가 전달한 `country`는 반환값에만 영향을 주며 서버 측 지역 또는 보안 정책을 우회하지 않습니다.
- 인식되지 않은 query 매개변수는 무시됩니다. 이 페이지에 나열된 매개변수만 사용하세요.
