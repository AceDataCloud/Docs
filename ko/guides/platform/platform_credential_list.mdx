비즈니스 API 자격 증명을 페이지네이션으로 나열합니다. 이 응답에는 현재 Token 또는 Identity 자격 증명의 민감한 필드가 포함되어 있으므로, 반드시 서버 측에서만 처리해야 하며 로그, 분석 플랫폼, 프런트엔드 영구 저장소 또는 공개 저장소에 기록하는 것을 금지합니다.

## 준비 작업

[Account Token](https://platform.acedata.cloud/documents/platform-token)을 생성하고, `GET /api/v1/platform-tokens/me/`를 통해 현재 계정 UUID를 가져옵니다.

```shell
export PLATFORM_TOKEN='당신의 계정 토큰'
export USER_ID='당신의 계정 UUID'
```

## 인터페이스 개요

| 항목   | 내용                                                   |
| --- | ---------------------------------------------------- |
| 메서드  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| 인증  | Account Token, OAuth token에는 `credentials:read` 필요       |
| 페이지네이션  | `count` + `items`                                    |

일반 사용자는 자신의 `user_id` 또는 권한을 부여받은 `application_id`를 전달해야 하며, 그렇지 않으면 페이지네이션 중 권한이 없는 객체를 만날 경우 `403`이 반환될 수 있습니다.

## 쿼리 파라미터

| 파라미터                 | 유형      | 필수  | 설명                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | 상황에 따라 | 자격 증명 소유자; 반복 파라미터 지원                   |
| `application_id`   | UUID    | 아니요   | Application으로 필터링; 반복 파라미터 지원        |
| `host`             | string  | 아니요   | host로 정확히 필터링; 반복 파라미터 지원             |
| `name`             | string  | 아니요   | 이름으로 정확히 필터링; 반복 파라미터 지원                 |
| `granted`          | boolean | 아니요   | `true`는 타인에게 권한을 부여한 자격 증명, `false`는 자체 사용 자격 증명 |
| `limit` / `offset` | integer | 아니요   | 페이지네이션                             |
| `ordering`         | string  | 아니요   | `created_at` 또는 `-created_at`   |

`service_id`, `disabled`, `expired`는 현재 필터링 파라미터가 아닙니다.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## 응답 설명

운영 환경에서 검증된 응답은 `{count, items}`입니다. 각 항목에는 `id`, `application_id`, `application`, `user_id`, `creator_id`, `name`, `type`, `limited_amount`, `used_amount`, `expired_at`, `allowed_api_ids`, `host`, `granted`, `granted_to_user_id`, `tags`, `metadata` 및 시간 필드가 포함되며, 유형에 따라 `token` 또는 `username/password`가 반환됩니다.

> 현재 목록 응답은 완전한 민감한 값을 반환합니다. 브라우저 콘솔이나 수집 시스템에 표시하지 말고, 목록을 통해 평문을 복구하는 방식에 의존하지도 마십시오. 클라이언트는 향후의 마스킹 정책과 호환되어야 합니다.
