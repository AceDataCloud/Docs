플랫폼에서 공개한 모델 카탈로그를 반환하며, 응답은 OpenAI 스타일의 `{ "object": "list", "data": [...] }` 구조를 사용합니다. 이 카탈로그는 모델 선택 및 기능 탐색에 사용되며, 현재 계정이 해당 서비스를 반드시 신청했음을 의미하지는 않습니다.

## 인터페이스 개요

| 항목   | 내용                                              |
| --- | ----------------------------------------------- |
| 메서드  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/models/` |
| 인증  | 공개, 계정 토큰 불필요                                       |
| 페이지네이션  | 페이지네이션 없음, 모든 일치 항목은 `data`에 위치                              |

## 쿼리 매개변수

| 매개변수             | 유형      | 필수  | 설명                                      |
| -------------- | ------- | --- | --------------------------------------- |
| `owned_by`     | string  | 아니요   | 카탈로그의 모델 제공자 식별자로 정확히 필터링                        |
| `type`         | string  | 아니요   | 모델 유형으로 정확히 필터링, 예: `chat`                     |
| `capability`   | string  | 아니요   | `capabilities`에 해당 기능이 포함된 모델만 반환, 예: `vision` |
| `with_pricing` | boolean | 아니요   | `1`, `true` 또는 `yes`일 때 공개 가격 정보 추가            |

`service_id`, `tag`, `limit`, `offset` 및 `ordering`은 현재 지원되지 않습니다. 전달해도 해당 필터링 또는 페이지네이션 효과가 발생하지 않습니다.

## 요청 예시

```shell
# 모든 공개 모델
curl 'https://platform.acedata.cloud/api/v1/models/' \
  -H 'Accept: application/json'

# 비전을 지원하는 chat 모델 및 가격 포함
curl --get 'https://platform.acedata.cloud/api/v1/models/' \
  --data-urlencode 'type=chat' \
  --data-urlencode 'capability=vision' \
  --data-urlencode 'with_pricing=true' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/models/",
    params={"type": "chat", "capability": "vision", "with_pricing": "true"},
    timeout=10,
)
response.raise_for_status()
payload = response.json()
for model in payload["data"]:
    print(model["id"], model["capabilities"], model.get("pricing"))
```

## 실제 응답 구조

```json
{
  "object": "list",
  "data": [
    {
      "id": "example-model",
      "label": "Example Model",
      "owned_by": "example",
      "service_prefix": "acedatacloud-example",
      "group_label": "Example",
      "type": "chat",
      "capabilities": [
        "vision"
      ],
      "object": "model",
      "pricing": {
        "currency": "USD",
        "unit": "token",
        "input_usd": 1e-06,
        "output_usd": 2e-06,
        "official_input_usd": 1e-06,
        "official_output_usd": 2e-06,
        "savings_pct": 0,
        "credit_usd_rate": 0.1
      }
    }
  ],
  "credit_usd_rate": 0.1
}
```

`pricing` 및 최상위 `credit_usd_rate`는 `with_pricing=true`일 때만 나타납니다. 모든 모델에 계산 가능한 `pricing`이 있는 것은 아닙니다. 모델 객체는 `config/models.json`의 공개 필드를 기준으로 하며, 클라이언트는 새로 추가된 필드를 무시해야 합니다.

> 가격 필드는 카탈로그 표시 데이터입니다. 실제 비즈니스 호출은 여전히 해당 API/Service의 과금 규칙 및 최종 사용량 기록을 기준으로 합니다.
