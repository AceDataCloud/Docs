LMLocal은 비주얼 스튜디오 2022/2026을 위한 확장으로, 공식적으로 OpenAI 호환 API와 사용자 정의 Base URL을 지원합니다. 구성 진입점은 확장 버전에 따라 변경될 수 있습니다; 처음 접속할 때는 버전을 고정하고 실제 편집, 도구 호출 및 사용량 기록을 확인하십시오.

## 구성

1. 비주얼 스튜디오 마켓플레이스 또는 공식 저장소에서 LMLocal을 설치합니다.
2. Providers에서 Custom/OpenAI 호환 Provider를 추가합니다.
3. Base URL에 `https://api.acedata.cloud/v1`을 입력합니다.
4. Auth Key에 당신의 Ace Data Cloud API Token을 입력합니다.
5. Model에 모델 디렉토리에서 지원하는 Chat Completions의 정확한 모델 ID를 입력합니다.
6. 저장 후 `Reply only OK`를 전송하고, 프로젝트 편집 프로세스를 다시 테스트합니다.

## 현재 경계

- 이 가이드는 LMLocal만 다루며, 다른 비주얼 스튜디오 확장의 공유 구성을 나타내지 않습니다.
- 서로 다른 버전은 각각 채팅, 편집, 빌드 및 테스트 요청을 처리할 수 있으며; 각 모드는 독립적으로 검증해야 합니다.
- 클라이언트가 자동으로 `/v1` 또는 엔드포인트 경로를 추가하는 경우, 중복 경로를 피하십시오.
