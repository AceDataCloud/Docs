서비스 ID(UUID) 또는 별칭(alias)을 통해 단일 서비스의 전체 정보를 가져옵니다——[AceDataCloud 플랫폼 서비스 목록 가져오기](https://platform.acedata.cloud/documents/platform-service-list)에서 반환하는 필드보다 더 완전하며, `apis`, `proxies`, `datasets`, `packages` 등 연관 객체를 추가로 확장합니다. 서비스 상세 페이지, 가격 비교 페이지, Agent 도구 설명 등의 시나리오에 적합합니다.

> ℹ️ 이 인터페이스는 **AceDataCloud 플랫폼 관리 API**에 속하며, 통합 접두사는 `https://platform.acedata.cloud/api/v1/`입니다. 전체 인터페이스 색인은 [AceDataCloud 플랫폼 문서 목록 가져오기](https://platform.acedata.cloud/documents/platform-document-list)를 참조하세요.

## 인터페이스 개요

| 항목   | 내용                                                            |
| --- | ------------------------------------------------------------- |
| 메서드  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| 인증  | ❌ 공개                                                          |

`/services/{id}` 및 `/services/{id}/`는 현재 모두 사용할 수 있으며, 예시는 통일하여 끝 슬래시 없는 형식을 사용합니다.

## 인증 설명

이 인터페이스는 완전히 공개되어 있습니다. **하지만 계정 토큰을 함께 전달하면 응답의 `applied` 필드가 현재 계정의 실제 신청 상태를 반영하며**, 그렇지 않으면 항상 `false`입니다.

계정 토큰을 얻는 방법은 [AceDataCloud 플랫폼 계정 토큰 관리](https://platform.acedata.cloud/documents/platform-token)를 참조하세요.

## 경로 매개변수

| 매개변수           | 유형            | 필수  | 설명                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | 서비스 ID(UUID) 또는 별칭(`midjourney`, `openai`, `webextrator` 등) |

## 요청 예시

### cURL

```shell
# 按 UUID 查询
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# 按 alias 查询
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# 带账户令牌看 applied 状态
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"服务: {svc['title']} ({svc['alias']})")
print(f"已申请: {svc['applied']}, 免费额度: {svc['free_amount']} {svc['unit']}")
print(f"API 数: {len(svc['apis'])}, 套餐数: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - 套餐 ${svc.packages.length} 个 - API ${svc.apis.length} 个`)
```

## 응답 필드 설명

상세 인터페이스는 [목록 인터페이스](https://platform.acedata.cloud/documents/platform-service-list)의 모든 필드에 더하여 다음을 추가로 확장합니다:

| 필드         | 유형    | 설명                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | 연관 API 객체의 전체 목록(각 항목에 `id`, `name`, `title`, `path`, `stage`, `cost` 포함) |
| `proxies`  | array | 연관 Proxy 객체의 전체 목록                                              |
| `datasets` | array | 연관 데이터셋(`type=Dataset`인 경우)                                      |
| `packages` | array | 패키지 목록으로, `type`(`Usage`/`Period`), `price`, `amount`, `duration` 포함   |

그 외 필드 정의는 [AceDataCloud 플랫폼 서비스 목록 가져오기 → 응답 필드 설명](https://platform.acedata.cloud/documents/platform-service-list)을 참조하세요.

## 오류 처리

| HTTP | code        | 의미                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id`(UUID 또는 alias)가 존재하지 않음 |
| 500  | —           | 일반적으로 URL 끝에 슬래시를 잘못 추가한 경우이므로, 제거 후 재시도          |

## 유용한 팁

- **`alias` > `UUID`**: `alias`(예: `midjourney`)를 코드에 하드코딩하는 것이 더 안정적입니다. UUID는 환경을 마이그레이션할 때 변경됩니다.
- **`apis` 필드에는 OpenAPI 정의가 포함되지 않습니다**: 전체 OpenAPI 3.0 Schema는 [AceDataCloud 플랫폼 API 세부 정보 가져오기](https://platform.acedata.cloud/documents/platform-api-detail) 인터페이스에 있습니다.
- **하나의 서비스의 "전체 기능" 가져오기**: 이 인터페이스로 `api_ids`를 가져온 후, `/apis/{api_id}`를 하나씩 호출하여 세부 정보를 가져옵니다.
- **`applied=true`인 경우**, 다시 신청할 필요 없이 직접 [API 자격 증명 생성](https://platform.acedata.cloud/documents/platform-credential-create)을 통해 비즈니스 인터페이스 호출에 필요한 32자리 Token을 얻을 수 있습니다.
