이 문서는 X402를 사용하여 Ace Data Cloud API를 호출할 때 가격이 어떻게 정해지는지, 그리고 이것이 플랫폼의 일반 **Credits**(크레딧) 가격과 어떤 관계가 있는지 설명합니다.

## 핵심 결론

X402는 독립적인 가격 체계가 아닙니다. 각 API 호출에는 원래 **Credits**로 계산되는 비용이 있으며, 이것이 모든 결제 방식(API Token 크레딧 차감, 계정 잔액, X402 온체인 결제)이 공유하는 유일한 가격 기준입니다. X402는 이 Credits 비용을 고정 환율로 온체인 USDC로 환산할 뿐입니다:

> **1 Credit = 0.095215 USDC**(즉, `95215` atomic USDC, USDC는 소수점 이하 6자리)

즉:

```text
X402 가격 (USDC) = 해당 호출의 Credits 비용 × 0.095215
```

이 환율은 임의로 정해진 것이 아니라 플랫폼 **최적 구간(대량) Credits 단가**와 같습니다. 따라서 X402로 결제하는 것은 ≈ 최적 구간 단가로 Credits를 구매한 뒤 사용하는 것과 같으며, **X402 할증은 없고**, 오히려 가장 저렴한 Credits 단가를 직접 적용받으며 사전 충전이나 API Token도 필요하지 않습니다.

## 가격 산정 기준

| 항목        | 값                              | 설명                                                    |
| --------- | ------------------------------ | ----------------------------------------------------- |
| 환산 환율      | `1 Credit = 0.095215 USDC`     | 플랫폼이 통일하여 설정한 고정 환율                                           |
| atomic 단위 | `1 Credit = 95215 atomic USDC` | USDC는 소수점 이하 6자리이며, `atomic = floor(credits × 0.095215 × 1e6)` |
| 최소 청구      | `1 atomic USDC`（$0.000001）     | 비용이 매우 낮더라도 최소 1 atomic이 정산됨                                 |
| 결제 통화      | USDC                           | Base는 ERC-20 USDC, Solana는 SPL USDC                  |

환산은 플랫폼에서 통일하여 수행하며, 금액은 지원되는 모든 네트워크(Base, Solana)에서 동일합니다. 네트워크별로 자산 계약과 서명 방식만 다르고 가격은 같습니다.

### 일반 Credits 단가와의 관계

플랫폼 Credits는 「사용량이 많을수록 단가가 낮아지는」 구간제로 판매됩니다. X402를 호출별로 과금할 때는 일관되게 최적 구간 단가를 사용합니다:

| 구매/결제 방식        | 대략적인 Credits 단가            | 설명                   |
| -------------- | ------------------------ | -------------------- |
| 입문 / 소액 충전      | 약 `$0.13 / Credit`       | 정가, 소액으로 Credits를 구매할 때의 단가 |
| 대량 / 최적 구간       | `$0.095215 / Credit`     | 가장 저렴한 단가               |
| **X402 호출별 결제** | **`$0.095215 / Credit`** | **항상 최적 구간 단가와 동일**        |

다시 말해, X402는 모든 호출을 최적 구간 Credits 단가로 정산합니다. 소액 충전으로 Credits를 구매하는 사용자의 단가는 X402보다 높고, 대량 충전 사용자의 단가만 X402와 동일합니다.

## 두 가지 가격 형태: `exact` 및 `upto`

X402의 402 응답에서 `maxAmountRequired`는 서명해야 하는 금액입니다. 두 가지 형태가 있습니다:

- **`exact`(고정 가격)**: 요청 처리 전에 가격을 확정할 수 있는 경우(이미지, 비디오, 음악, 검색, 주문 결제)입니다. `maxAmountRequired = 해당 호출 Credits 비용 × 0.095215`이며, 즉 해당 호출의 결제 금액입니다(성공 응답의 `cost.amount`와 일치).
- **`upto`(사용량 사후 계량)**: 채팅 완성과 같이 「응답이 끝나야 얼마나 많은 token을 사용했는지 알 수 있는」 인터페이스입니다. `maxAmountRequired`는 **상한**(해당 모델에 설정된 상한 크레딧으로 환산: 상한 Credits × 0.095215)이며, 실제 사용량에 따라 정산되고 상한을 초과하지 않습니다.

이 두 scheme의 프로토콜 세부 사항은 [`exact` 및 `upto` 과금 방식](https://platform.acedata.cloud/documents/x402-metered-upto)을 참조하세요. 아래에서는 가격만 설명합니다.

## Chat(채팅 완성) 가격

채팅 완성은 `upto` 계량 방식입니다: prompt / completion token의 실제 사용량에 따라 과금됩니다. 백만(1M) token당 가격 = `해당 모델의 1M token당 Credits 비용 × 0.095215`이며, 플랫폼의 공개 모델 카탈로그(`/api/v1/models?with_pricing=true`)에 표시되는 USD 단가와 완전히 일치합니다.

아래 표는 실제 가격(모델 카탈로그에서 가져와 X402 환율로 계산)이며, 단위는 USD / 1M token입니다:

| 모델                | 입력 / 1M | 출력 / 1M  | `upto` 상한             |
| ----------------- | ------- | -------- | --------------------- |
| gpt-4o-mini       | $0.0796 | $0.3183  | 1 Credit（$0.095215）   |
| gemini-2.5-flash  | $0.1591 | $1.3262  | 5 Credits（$0.476074）  |
| gpt-5 / gpt-5.1   | $0.6631 | $5.3050  | 20 Credits（$1.904299） |
| gemini-2.5-pro    | $0.6631 | $5.3050  | 50 Credits（$4.760750） |
| gpt-4.1           | $1.0610 | $4.2440  | 20 Credits（$1.904299） |
| claude-sonnet-4-5 | $0.6006 | $3.0028  | 50 Credits（$4.760750） |
| grok-4            | $1.5915 | $7.9574  | 10 Credits（$0.952149） |
| claude-opus-4-1   | $3.0028 | $15.0140 | 50 Credits（$4.760750） |

설명:

- 표의 가격은 token 기준 단가입니다. 한 요청의 비용 = 입력 token × 입력 단가 + 출력 token × 출력 단가입니다.
- `upto` 상한은 해당 모델의 한 요청에서 서명할 수 있는 최대 금액이며, 실제 차감 금액이 아닙니다. 대부분의 요청은 상한보다 훨씬 낮습니다.
- 상한은 「최대 얼마까지 차감될 수 있는지」만 결정하며, 실제 정산은 token 사용량에 따라 계산됩니다.

### 예시: 견적과 차감 금액이 일치함(`exact`)

아래는 공식 X402Client를 사용하여 `serp/google`에 보낸 한 번의 **실제 유료 호출**(Base `exact`)입니다. 이는 세 가지가 일치함을 보여 줍니다: 402 견적, 서명 금액, 그리고 성공 응답에서 반환되는 `cost`.

```text
# 1) 미결제 요청 -> 402, 견적 획득(과금 없음)
POST /serp/google  ->  402
base/exact maxAmountRequired = 952 atomic = $0.000952 = 0.01 Credit
# 0.01 × 0.095215 = 0.00095215, atomic으로 내림 = 952

# 2) 지갑으로 952 atomic의 PAYMENT-SIGNATURE에 서명하고 재시도
POST /serp/google (PAYMENT-SIGNATURE) -> 200
body.cost = {"amount": 0.000952, "currency": "usdc", "settlement": "authorized"}
```
응답으로 반환된 `cost.amount`（0.000952 USDC）은 402 견적 및 `Credits × 0.095215`와 완전히 일치합니다. `settlement` 필드는 해당 결제의 정산 상태입니다（`authorized` = 승인됨）；온체인 정산은 플랫폼에서 처리하며, 메커니즘은 [`exact` 및 `upto` 과금 방식](https://platform.acedata.cloud/documents/x402-metered-upto)을 참조하세요.

### `upto` 견적 계산（채팅）

채팅은 token 기준으로 계량됩니다. 한 요청의 견적（상한이 아님）은 다음 식으로 계산됩니다（gpt-4o-mini 예시）：

```text
Credits = 1e-6 × (0.835733 × prompt_tokens + 3.342933 × completion_tokens)
USDC    = Credits × 0.095215
```

500 prompt + 200 completion token 요청 1회：

```text
Credits = 1e-6 × (0.835733 × 500 + 3.342933 × 200) ≈ 0.001086 Credits
报价 USDC ≈ 0.001086 × 0.095215 ≈ $0.0001034
```

클라이언트는 `upto` 상한（gpt-4o-mini의 경우 1 Credit = `95215` atomic）으로 서명하며, 이는 단지 **최대 얼마나 차감될 수 있는지**를 의미합니다；해당 요청의 실제 견적（위 예시 약 $0.0001）은 상한보다 훨씬 낮으며, token 사용량에 따라 정산됩니다. `upto`의 온체인 정산 메커니즘은 [`exact` 및 `upto` 과금 방식](https://platform.acedata.cloud/documents/x402-metered-upto)을 참조하세요.

## 기타 서비스 가격（고정가 `exact`）

이미지, 비디오, 음악, 검색과 같은 인터페이스는 요청 시 가격을 확정할 수 있으며, `exact`를 사용합니다. 아래 표는 실제 가격이며, 미결제 요청에 대해 온라인 인터페이스가 반환한 402 `maxAmountRequired`에서 가져왔습니다（견적 조회는 과금되지 않음）：

| 서비스   | 예시 모델 / 파라미터                   | Credits | USDC      | atomic  |
| ---- | --------------------------- | ------- | --------- | ------- |
| 웹 검색 | serp/google，≤10개 결과         | 0.01    | $0.000952 | 952     |
| 이미지   | nano-banana                 | 0.14    | $0.013330 | 13330   |
| 이미지   | gpt-image-1，1024×1024       | 0.20    | $0.019043 | 19043   |
| 이미지   | flux-dev                    | 0.24    | $0.022851 | 22851   |
| 이미지   | midjourney imagine          | 0.27    | $0.025708 | 25708   |
| 이미지   | seedream-4                  | 0.32    | $0.030468 | 30468   |
| 음악   | suno generate               | 0.55    | $0.052368 | 52368   |
| 음악   | producer generate           | 0.68    | $0.064746 | 64746   |
| 비디오   | luma                        | 1.19    | $0.113305 | 113305  |
| 비디오   | hailuo（minimax-hailuo-2-3）  | 1.72    | $0.163769 | 163769  |
| 비디오   | kling-v2-6 std              | 2.10    | $0.199951 | 199951  |
| 비디오   | kling-v3 std                | 4.20    | $0.399903 | 399903  |
| 비디오   | veo-3 text→video            | 5.00    | $0.476074 | 476074  |
| 비디오   | seedance-1-0-pro，1080p / 5s | 5.60    | $0.533204 | 533204  |
| 비디오   | wan2.6-t2v                  | 13.50   | $1.285402 | 1285402 |

설명：

- 동일 서비스의 가격은 **모델, 해상도, 길이, 동작**에 따라 달라집니다（특히 비디오）。위 표는 특정 파라미터 조합의 실제 값이며, 규모 참고용입니다.
- 이러한 고정가（`exact`）인터페이스의 경우, 해당 요청 402 응답의 `maxAmountRequired`가 이번에 지불할 금액입니다（성공 응답의 `cost.amount`와 일치하며, 이전 절에서 이미 실측함）。
- 각 가격은 `Credits × 0.095215`를 atomic 단위로 내림하여 산출됩니다（위 과금 기준 참조），채팅과 동일한 환산 방식을 사용합니다. 부동소수점 표현과 반올림으로 인해 일부 값은 단순 곱셈 결과와 1 atomic（$0.000001）차이가 날 수 있으며, 항상 402 반환값을 기준으로 합니다.

## 주문 결제 가격

X402로 콘솔 주문（패키지 구매 / Credits 충전）을 결제할 때 가격은 주문 페이지에 표시된 내용을 기준으로 하며, 402의 `amount`가 최종 서명 기준입니다. 주문 결제는 플랫폼 API를 거치며 계정 토큰이 필요합니다. 자세한 내용은 [주문 결제 튜토리얼](https://platform.acedata.cloud/documents/x402-order-payment)을 참조하세요.

주문 결제 튜토리얼의 실제 예시 하나（10 Credits 구매）：

```text
description Ace Data Cloud Credits x 10.0
created price 1.26          # 订单创建价（USD）
settled    1.20 USDC        # 最终签名/结算金额（= 402 amount）
            = 1200000 atomic USDC
```

주의：**호출당 과금**（위 Chat / 기타 서비스）과 **주문 결제**는 서로 다른 두 경로입니다. 호출당 과금은 모두 `0.095215`/Credit의 최적 구간 단가를 사용하며；주문 결제는 패키지 가격을 따르고, 생성 가격과 최종 정산 금액의 차이는 [주문 결제 튜토리얼](https://platform.acedata.cloud/documents/x402-order-payment)을 기준으로 합니다.

## 실시간으로 가격을 가져오는 방법

가격은 모델과 파라미터에 따라 달라지므로, 하드코딩하지 말고 프로그램으로 실시간으로 가져오세요：

- **호출당 가격**：대상 API에 `PAYMENT-SIGNATURE` 없이（`Authorization`도 없이）요청을 한 번 보내고, 반환된 402 `accepts[].maxAmountRequired`를 읽으세요. 이 단계에서는 과금되지 않습니다. `exact` 인터페이스에서는 최종 가격이며；`upto` 인터페이스（채팅）에서는 상한이고 실제 사용량에 따라 정산됩니다.
- **채팅 token당 단가**：`GET https://platform.acedata.cloud/api/v1/models?with_pricing=true&type=chat`，각 모델의 `pricing.input_usd` / `pricing.output_usd`를 읽으세요（이미 `credit_usd_rate` 기준으로 계산됨）。
- **환산 검증**：`atomic = floor(Credits × 0.095215 × 1e6)`，`USDC = atomic / 1e6`（즉 `USDC ≈ Credits × 0.095215`）。

가격을 가져오는 최소 요청 예시：

```bash
curl -sS -X POST https://x402.acedata.cloud/midjourney/imagine \
  -H 'Content-Type: application/json' \
  -d '{"prompt": "a cat"}'
# 返回 402，accepts[].maxAmountRequired 即为该次（exact）调用价格
```

## 요약
- X402 가격 = 해당 호출의 Credits 비용 × `0.095215`이며, 일반 Credits 과금과 **동일한 가격**이고, 단지 온체인 USDC로 결제합니다.
- `0.095215`/Credit은 플랫폼의 **최적 구간**(대량) Credits 단가입니다. 소액 충전으로 Credits를 구매하는 단가는 더 높으므로, X402는 자동으로 최적 단가를 적용받는 것과 같습니다.
- `exact` 인터페이스(이미지 / 비디오 / 음악 / 검색 / 주문)의 서명 금액은 해당 호출의 결제 금액입니다. `upto` 인터페이스(채팅)의 서명 금액은 상한이며, 실제 사용량에 따라 정산됩니다.
- 권위 있는 가격은 402가 반환하는 `maxAmountRequired`를 기준으로 합니다. `exact`는 결제 금액이며(성공 응답의 `cost.amount`와 일치하고, 이미 실측됨), `upto`는 상한이고 성공 응답의 `cost.amount`가 사용량에 따라 정산된 실제 금액입니다(≤ 상한).
