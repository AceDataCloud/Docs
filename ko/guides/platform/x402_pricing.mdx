이 문서는 X402를 사용하여 Ace Data Cloud API를 호출할 때 가격이 어떻게 책정되는지, 그리고 그것이 플랫폼의 일반 **Credits**(크레딧) 가격과 어떤 관계가 있는지를 설명합니다.

## 핵심 결론

X402는 독립적인 가격 체계가 아닙니다. 각 API 호출은 본래 **Credits**로 계산된 비용이 있으며, 이는 모든 요금 청구 방식(API Token 차감, 계좌 잔액, X402 체인 상 지불)의 유일한 가격 출처입니다. X402는 이 Credits 비용을 고정 환율로 체인 상 USDC로 환산합니다:

> **1 Credit = 0.095215 USDC** (즉, `95215` atomic USDC, USDC는 6자리 소수)

즉, 다음과 같습니다:

```text
X402 가격 (USDC) = 해당 호출의 Credits 비용 × 0.095215
```

이 환율은 임의로 설정된 것이 아니며, 플랫폼의 **최적 등급(대량) Credits 단가**와 같습니다. 따라서 X402로 결제하는 것은 ≈ 최적 등급 단가로 Credits를 구매한 후 소비하는 것과 같으며, **X402 프리미엄이 없습니다**. 오히려 가장 저렴한 Credits 단가를 직접享受하며, 사전 충전이나 API Token이 필요 없습니다.

## 가격 기준

| 항목        | 값                              | 설명                                                    |
| --------- | ------------------------------ | ----------------------------------------------------- |
| 환산 환율      | `1 Credit = 0.095215 USDC`     | 플랫폼에서 통일적으로 설정한 고정 환율                                           |
| atomic 단위 | `1 Credit = 95215 atomic USDC` | USDC 6자리 소수, `atomic = floor(credits × 0.095215 × 1e6)` |
| 최소 청구      | `1 atomic USDC`（$0.000001）     | 비용이 극히 낮더라도 최소 1 atomic으로 결제됨                                 |
| 가격 통화      | USDC                           | Base / SKALE는 ERC-20 USDC, Solana는 SPL USDC          |

환산은 플랫폼에서 통일적으로 수행되며, 모든 지원 네트워크(Base, SKALE, Solana)에서 금액이 동일합니다; 서로 다른 네트워크는 자산 계약과 서명 방식이 다를 뿐 가격은 동일합니다.

### 일반 Credits 단가와의 관계

플랫폼 Credits는 "사용량이 많을수록 단가가 낮아지는" 단계별로 판매됩니다. X402는 호출 시 통일적으로 단계 최적 단가를 사용합니다:

| 구매/지불 방식        | 대략 Credits 단가            | 설명                   |
| -------------- | ------------------------ | -------------------- |
| 입문 / 소액 충전      | 약 `$0.13 / Credit`       | 목록 가격, 소액으로 Credits를 구매할 때의 단가 |
| 대량 / 최적 등급       | `$0.095215 / Credit`     | 가장 저렴한 단가               |
| **X402 호출당 결제** | **`$0.095215 / Credit`** | **항상 최적 등급 단가와 동일**        |

다시 말해, X402는 매 호출을 최적 등급 Credits 단가로 결제합니다. 소액 충전으로 Credits를 구매한 사용자는 단가가 X402보다 높고, 대량 충전 사용자의 단가만 X402와 일치합니다.

## 두 가지 가격 형태: `exact`와 `upto`

X402의 402 응답에서 `maxAmountRequired`는 서명해야 할 금액입니다. 두 가지 형태가 있습니다:

- **`exact`(고정가)**: 요청 처리 전에 가격을 확정할 수 있습니다(이미지, 비디오, 음악, 검색, 주문 결제). `maxAmountRequired = 해당 호출 Credits 비용 × 0.095215`로, 즉 해당 호출의 지불 금액(성공 응답의 `cost.amount`와 일치).
- **`upto`(사용량 후측정)**: 채팅 보완과 같은 "응답이 끝나야 얼마나 많은 토큰을 사용했는지 알 수 있는" 인터페이스입니다. `maxAmountRequired`는 **상한**입니다(해당 모델에 설정된 상한 금액 환산: 상한 Credits × 0.095215), 실제로는 실제 사용량에 따라 결제되며 상한을 초과하지 않습니다.

이 두 가지 스킴의 프로토콜 세부 사항은 [`exact`와 `upto` 요금제](https://platform.acedata.cloud/documents/x402-metered-upto)를 참조하십시오. 아래에서는 가격만 설명합니다.

## Chat(채팅 보완) 가격

채팅 보완은 `upto` 측정입니다: 프롬프트/완성 토큰의 실제 사용량에 따라 요금이 청구됩니다. 백만(1M) 토큰의 가격 = `해당 모델의 1M 토큰당 Credits 비용 × 0.095215`로, 플랫폼에서 공개한 모델 디렉토리(`/api/v1/models?with_pricing=true`)에 표시된 USD 단가와 완전히 일치합니다.

아래 표는 실제 가격(모델 디렉토리에서 가져온 것, X402 환율 기준)으로, 단위는 USD / 1M 토큰입니다:

| 모델                | 입력 / 1M | 출력 / 1M  | `upto` 상한             |
| ----------------- | ------- | -------- | --------------------- |
| gpt-4o-mini       | $0.0796 | $0.3183  | 1 Credit（$0.095215）   |
| gemini-2.5-flash  | $0.1591 | $1.3262  | 5 Credits（$0.476074）  |
| gpt-5 / gpt-5.1   | $0.6631 | $5.3050  | 20 Credits（$1.904299） |
| gemini-2.5-pro    | $0.6631 | $5.3050  | 50 Credits（$4.760750） |
| gpt-4.1           | $1.0610 | $4.2440  | 20 Credits（$1.904299） |
| claude-sonnet-4-5 | $0.6006 | $3.0028  | 50 Credits（$4.760750） |
| grok-4            | $1.5915 | $7.9574  | 10 Credits（$0.952149） |
| claude-opus-4-1   | $3.0028 | $15.0140 | 50 Credits（$4.760750） |

설명:

- 표는 토큰 기준의 단가입니다; 한 번의 요청 비용 = 입력 토큰 × 입력 단가 + 출력 토큰 × 출력 단가.
- `upto` 상한은 해당 모델의 한 번 요청에서 서명할 수 있는 최대 금액입니다; 실제 청구가 아니며, 대부분의 요청은 상한보다 훨씬 낮습니다.
- 상한은 "최대 얼마를 청구할 수 있는지"를 결정할 뿐, 실제 결제는 토큰 사용량에 따라 계산됩니다.

### 예시: 견적과 청구 일치(`exact`)

아래는 공식 X402Client를 사용하여 `serp/google`에 대해 수행한 **실제 유료 호출**(Base `exact`)입니다. 이는 세 가지가 일치하는 것을 보여줍니다: 402 견적, 서명 금액, 그리고 성공 응답에서 반환된 `cost`.

```text
# 1) 미지급 요청 -> 402, 견적을 받음 (청구되지 않음)
POST /serp/google  ->  402
base/exact maxAmountRequired = 952 atomic = $0.000952 = 0.01 Credit
# 0.01 × 0.095215 = 0.00095215, 아래로 내림하여 atomic = 952

# 2) 지갑으로 952 atomic의 PAYMENT-SIGNATURE 서명 후 재시도
POST /serp/google (PAYMENT-SIGNATURE) -> 200
body.cost = {"amount": 0.000952, "currency": "usdc", "settlement": "authorized"}
```
응답 반환의 `cost.amount`(0.000952 USDC)는 402 견적, `Credits × 0.095215`와 완전히 일치합니다. `settlement` 필드는 해당 결제의 결제 상태(`authorized` = 승인됨)를 나타냅니다; 체인 상 결제는 플랫폼에서 처리하며, 메커니즘은 [`exact`와 `upto` 요금제](https://platform.acedata.cloud/documents/x402-metered-upto)를 참조하십시오.

### `upto` 견적 계산(채팅)

채팅은 토큰으로 측정됩니다. 특정 요청의 견적(상한선이 아님)은 다음 식으로 계산됩니다(예: gpt-4o-mini):

```text
Credits = 1e-6 × (0.835733 × prompt_tokens + 3.342933 × completion_tokens)
USDC    = Credits × 0.095215
```

500 prompt + 200 completion 토큰의 요청:

```text
Credits = 1e-6 × (0.835733 × 500 + 3.342933 × 200) ≈ 0.001086 Credits
견적 USDC ≈ 0.001086 × 0.095215 ≈ $0.0001034
```

클라이언트는 `upto` 상한선(gpt-4o-mini의 경우 1 Credit = `95215` atomic)으로 서명하며, 이는 **최대 얼마를 차감할 수 있는지**를 나타냅니다; 해당 요청의 실제 견적(위 예시 약 $0.0001)은 상한선보다 훨씬 낮으며, 토큰 사용량에 따라 결제됩니다. `upto`의 체인 상 결제 메커니즘은 [`exact`와 `upto` 요금제](https://platform.acedata.cloud/documents/x402-metered-upto)를 참조하십시오.

## 기타 서비스 가격(고정가 `exact`)

이미지, 비디오, 음악, 검색과 같은 인터페이스는 요청 시 가격을 즉시 확인할 수 있으며, `exact`를 사용합니다. 아래 표는 실제 가격으로, 온라인 인터페이스에서 미지급 요청에 대해 반환된 402 `maxAmountRequired`에서 가져온 것입니다(견적 조회는 요금이 발생하지 않음):

| 서비스   | 예시 모델 / 매개변수                   | Credits | USDC      | atomic  |
| ---- | --------------------------- | ------- | --------- | ------- |
| 웹 검색 | serp/google, ≤10 개 결과         | 0.01    | $0.000952 | 952     |
| 이미지   | nano-banana                 | 0.14    | $0.013330 | 13330   |
| 이미지   | gpt-image-1, 1024×1024       | 0.20    | $0.019043 | 19043   |
| 이미지   | flux-dev                    | 0.24    | $0.022851 | 22851   |
| 이미지   | midjourney imagine          | 0.27    | $0.025708 | 25708   |
| 이미지   | seedream-4                  | 0.32    | $0.030468 | 30468   |
| 음악   | suno generate               | 0.55    | $0.052368 | 52368   |
| 음악   | producer generate           | 0.68    | $0.064746 | 64746   |
| 비디오   | luma                        | 1.19    | $0.113305 | 113305  |
| 비디오   | hailuo(minimax-hailuo-2-3)  | 1.72    | $0.163769 | 163769  |
| 비디오   | kling-v2-6 std              | 2.10    | $0.199951 | 199951  |
| 비디오   | kling-v3 std                | 4.20    | $0.399903 | 399903  |
| 비디오   | veo-3 text→video            | 5.00    | $0.476074 | 476074  |
| 비디오   | seedance-1-0-pro, 1080p / 5s | 5.60    | $0.533204 | 533204  |
| 비디오   | wan2.6-t2v                  | 13.50   | $1.285402 | 1285402 |

설명:

- 동일한 서비스의 가격은 **모델, 해상도, 길이, 동작**에 따라 변동합니다(특히 비디오). 위 표는 특정 매개변수 집합에 대한 실제 값으로, 대략적인 참고용입니다.
- 이러한 고정가(`exact`) 인터페이스에서, 해당 요청의 402 응답에 있는 `maxAmountRequired`는 해당 결제 금액입니다(성공적인 응답의 `cost.amount`와 일치하며, 이전 섹션에서 실측됨).
- 각 가격은 `Credits × 0.095215`를 atomic 단위로 내림하여 얻습니다(위의 가격 기준 참조), 채팅에 사용되는 것과 동일한 변환을 사용합니다. 부동 소수점 표현 및 내림으로 인해 일부 값은 단순 곱셈과 1 atomic($0.000001) 차이가 있을 수 있으며, 항상 402 반환 값을 기준으로 합니다.

## 주문 결제 가격

X402 결제 콘솔에서 주문(패키지 구매 / Credits 충전)을 할 때, 가격은 주문 페이지에 표시된 대로 하며, 402의 `amount`가 최종 서명 기준입니다. 주문 결제는 플랫폼 API를 통해 진행되며, 계정 토큰이 필요합니다. 자세한 내용은 [주문 결제 튜토리얼](https://platform.acedata.cloud/documents/x402-order-payment)을 참조하십시오.

주문 결제 튜토리얼의 실제 예시(10 Credits 구매):

```text
description Ace Data Cloud Credits x 10.0
created price 1.26          # 주문 생성 가격(USD)
settled    1.20 USDC        # 최종 서명/결제 금액(= 402 amount)
            = 1200000 atomic USDC
```

주의: **호출당 요금**(위의 채팅 / 기타 서비스)과 **주문 결제**는 두 가지 다른 경로입니다. 호출당 요금은 통일적으로 `0.095215`/Credit의 최적 단가를 사용하며; 주문 결제는 패키지 가격에 따라 다르며, 생성 가격과 최종 결제 금액의 차이는 [주문 결제 튜토리얼](https://platform.acedata.cloud/documents/x402-order-payment)을 기준으로 합니다.

## 실시간으로 가격을 얻는 방법

가격은 모델과 매개변수에 따라 변동하므로, 프로그램을 통해 실시간으로 얻어야 하며, 하드코딩하지 마십시오:

- **호출당 가격**: 목표 API에 **PAYMENT-SIGNATURE**(또는 `Authorization` 없이) 요청을 한 번 보내고, 반환된 402 `accepts[].maxAmountRequired`를 읽습니다. 이 단계에서는 요금이 발생하지 않습니다. `exact` 인터페이스의 경우 최종 가격이며; `upto` 인터페이스(채팅)의 경우 상한선으로, 실제 사용량에 따라 결제됩니다.
- **채팅 각 토큰 단가**: `GET https://platform.acedata.cloud/api/v1/models?with_pricing=true&type=chat`를 통해 각 모델의 `pricing.input_usd` / `pricing.output_usd`를 읽습니다(이미 `credit_usd_rate`에 따라 계산됨).
- **변환 검증**: `atomic = floor(Credits × 0.095215 × 1e6)`, `USDC = atomic / 1e6`(즉, `USDC ≈ Credits × 0.095215`).

가격을 얻기 위한 최소 요청 예시:

```bash
curl -sS -X POST https://x402.acedata.cloud/midjourney/imagine \
  -H 'Content-Type: application/json' \
  -d '{"prompt": "a cat"}'
# 반환 402, accepts[].maxAmountRequired가 해당 호출 가격입니다(exact)
```

## 요약
- X402 가격 = 해당 호출의 Credits 비용 × `0.095215`, 일반 Credits 요금과는 **같은 가격**이며, 단지 체인 상의 USDC로 정산됩니다.
- `0.095215`/Credit는 플랫폼의 **최적 등급** (대량) Credits 단가입니다; 소액 충전으로 구매한 Credits 단가는 더 높기 때문에 X402는 자동으로 최적 단가를 얻습니다.
- `exact` 인터페이스(이미지 / 비디오 / 음악 / 검색 / 주문) 서명 금액은 해당 시점의 지불 금액입니다; `upto` 인터페이스(채팅) 서명은 상한선으로, 실제 사용량에 따라 정산됩니다.
- 권위 있는 가격은 402가 반환한 `maxAmountRequired`를 기준으로 합니다: `exact`는 지불 금액(성공적인 응답의 `cost.amount`와 일치하며, 실제로 측정됨); `upto`는 상한선으로, 성공적인 응답의 `cost.amount`가 사용량에 따라 정산된 실제 금액입니다 (≤ 상한선).
