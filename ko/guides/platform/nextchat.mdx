[NextChat](https://github.com/ChatGPTNextWeb/NextChat)(구 ChatGPT-Next-Web)는 Vercel, Cloudflare 또는 Docker에 배포할 수 있는 오픈 소스 AI 클라이언트입니다. 사용자 지정 OpenAI 호환 엔드포인트를 지원하므로 Ace Data Cloud를 연동할 수 있습니다. 이 글에서는 구성 과정을 소개합니다.

## 신청 절차

NextChat에서 Ace Data Cloud를 연동하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 가져와 백업용으로 보관하세요.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않았다면 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 로그인 및 가입 후에는 현재 페이지로 자동 반환됩니다.

최초 신청 시 무료 할당량이 제공되므로 Ace Data Cloud의 모델 서비스를 무료로 체험할 수 있습니다.

## NextChat 다운로드

데스크톱 버전([Releases 페이지](https://github.com/ChatGPTNextWeb/NextChat/releases)에서 `.exe` / `.dmg` / AppImage 다운로드), [웹 온라인 버전](https://app.nextchat.club/)을 사용하거나, 직접 Vercel / Cloudflare / Docker에 배포할 수 있습니다(아래 고급 섹션 참조).

## Ace Data Cloud 구성

NextChat을 시작하고 **설정 → 모델 서비스**로 이동합니다:

| 필드          | 값                           | 설명                              |
| ----------- | --------------------------- | ------------------------------- |
| 모델 서비스 제공업체 | `OpenAI`                    | OpenAI 호환 프로토콜 사용                  |
| OpenAI 인터페이스 주소 | `https://api.acedata.cloud` | 루트 도메인만 입력하고, **`/openai` 및 `/v1`은 포함하지 않음** |
| API Key     | 본인의 Ace Data Cloud Token     | 콘솔에서 복사한 Token                    |

![NextChat Ace Data Cloud 구성 화면](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat은 인터페이스 주소 뒤에 자동으로 `/v1/chat/completions`를 추가하므로 루트 도메인만 입력하면 됩니다:

| 인터페이스 주소                                  | 실제 요청                                                      | 결과                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | 올바름                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404(`/openai` 아래에 `/v1`이 없음) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

「사용자 지정 모델 이름」 입력란에 영어 쉼표로 구분하여 모델을 입력합니다. NextChat은 특수 구문을 지원합니다: `+모델명` 추가, `-모델명` 숨기기, `모델명=표시명` 사용자 지정 표시명, `-all` 전체 먼저 숨기기. 가장 깔끔한 권장 작성 방식은 다음과 같습니다:

```text
-all,+MODEL_ID=표시 이름
```

## 모델 선택

모델 목록은 지속적으로 업데이트됩니다. 클라이언트가 자동으로 불러오는 모델 목록을 우선 사용하세요. 수동으로 입력해야 하는 경우 먼저 `GET https://api.acedata.cloud/v1/models`를 요청하여 현재 모델 ID를 가져온 후, 클라이언트가 지원하는 컨텍스트, 이미지 및 도구 호출 기능에 따라 선택하세요.

## 연동 검증

문제가 NextChat에 있는지 네트워크에 있는지 확실하지 않다면, 먼저 curl을 사용하여 엔드포인트를 직접 검증할 수 있습니다(`{token}`을 본인의 Token으로 바꾸세요):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI 호환 `chat.completion` 객체가 반환되면 Token과 엔드포인트가 모두 준비되었음을 의미합니다. `HTTP 403 used_up`이 반환되면 Token은 유효하지만 잔액이 부족하다는 의미이므로 [콘솔](https://platform.acedata.cloud/console/applications)에서 충전하면 됩니다.

## 고급: 자체 도메인에 원클릭 배포

NextChat은 자신만의 AI 웹사이트 배포를 지원합니다. Docker를 예로 들면 다음과 같습니다(`{token}`을 본인의 Token으로 바꾸세요):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=표시 이름" \
  yidadaa/chatgpt-next-web
```

Vercel / Cloudflare 배포 시 프로젝트 환경 변수에서 동일한 `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS`를 구성하면 됩니다. `CODE`는 영어 쉼표로 여러 액세스 비밀번호를 구분하여 지원하므로, 사용자별 사용량 통계에 편리합니다. 위 환경 변수에 대한 전체 설명(`BASE_URL` 기본값 `https://api.openai.com`, `CUSTOM_MODELS`의 `+/-/=/-all/+all` 구문)은 [NextChat 공식 README](https://github.com/ChatGPTNextWeb/NextChat#environment-variables)를 기준으로 하세요.

## 자주 묻는 질문

### 404 Not Found가 표시됨

일반적으로 인터페이스 주소를 `.../openai` 또는 `.../openai/v1`로 입력했기 때문입니다. `https://api.acedata.cloud`로 변경하고 NextChat이 직접 `/v1/chat/completions`를 추가하도록 하세요.

### 모델 드롭다운에 추가한 모델이 없음

`CUSTOM_MODELS` 형식을 확인하세요. 각 모델 앞에는 반드시 `+`가 있어야 합니다. `-all`을 사용했다면 뒤에 `+`를 사용하여 필요한 모델을 다시 추가했는지 확인하세요.

### 401 Unauthorized가 표시됨

API Key에 붙여넣은 값이 Ace Data Cloud의 Token인지(`Bearer` 접두사 없이, 불필요한 공백 없이), 그리고 해당 애플리케이션의 잔액이 충분한지 확인하세요.
