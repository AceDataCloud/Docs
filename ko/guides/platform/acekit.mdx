아마 이런 상황을 겪어본 적 있을 것입니다. Claude Code, Cursor 또는 Codex를 쓰면서 코드를 한창 작성하다가, 갑자기 이미지 한 장, 배경 음악 한 곡, 짧은 동영상 하나가 필요해지거나 최신 자료를 찾아보게 하고 싶어집니다. 그런데 곧 알게 됩니다——agent 자체는 이런 일을 할 수 없다는 것을요. 직접 API를 찾아야 하고, 문서를 읽고, key를 설정하고, 호출 코드를 작성하고, 비동기 폴링을 처리해야 합니다. 이 모든 과정을 거치고 나면 영감은 이미 식어버립니다.

[AceKit](https://github.com/AceDataCloud/AceKit)은 바로 이 모든 번거로움을 없애기 위해 나왔습니다. 명령 한 줄이면 AceData Cloud의 이미지 생성, 동영상 생성, 음악 생성, 웹 검색, LLM 대화 등의 기능을 코딩 agent에 통째로 설치합니다. 설치 후에는 자연어로 말하기만 하면 agent가 해당 스킬을 직접 로드하고, 직접 인증하고, 직접 폴링하여 작업을 끝냅니다.

## 30초 만에 이해하기

설치 전 vs 설치 후:

| 당신이 하는 말               | 설치 전                   | 설치 후（agent가 직접 수행）                      |
| ------------------ | --------------------- | ----------------------------------- |
| "이 README에 표지 이미지 하나 붙여줘" | agent는 못 하며, 직접 이미지 생성 API를 찾게 함 | NanoBanana / Flux / Midjourney를 호출해 이미지 생성 |
| "이 스크립트를 30초짜리 짧은 동영상으로 만들어줘"  | 못 함                    | Sora / Veo / Kling / Seedance를 호출해 영상 생성  |
| "이 demo에 배경 음악 한 곡 붙여줘"  | 못 함                    | Suno를 호출해 음악 생성                           |
| "최신 X를 검색해서 요약해줘"     | 인터넷 연결 불가                  | Google SERP를 호출해 실시간 결과 획득                 |
| "이 긴 링크를 짧게 줄여줘"         | 못 함                    | 단축 링크 서비스를 호출해 surl.id 링크 반환                  |

한마디로: **당신의 코딩 agent가 "코드만 작성하는" 것에서 "이미지 생성, 동영상 생성, 음악 생성, 인터넷 검색도 하는" 것으로 바뀝니다.**

## 세 단계로 시작하기

전체 과정은 몇 분이면 완료되며, Node.js 18+가 필요합니다.

**첫 번째 단계 · API Token을 받으세요.** [콘솔](https://platform.acedata.cloud/console/applications)에서 Token을 복사하세요——모든 기능이 이 하나를 공유하며, 최초 신청 시 무료 크레딧이 제공되므로 먼저 무료로 사용해볼 수 있습니다.

![콘솔에서 API Token 복사](https://cdn.acedata.cloud/dvc3cg.jpg)

**두 번째 단계 · 설치하세요.** 명령 한 줄이면 됩니다:

```bash
npx acekit
```

이 명령은 컴퓨터의 코딩 agent를 자동으로 감지하고 전체 스킬을 설치합니다. 실제 실행은 다음과 같습니다（이 컴퓨터에는 Claude Code만 설치되어 있습니다）:

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Token을 설정하지 않은 경우 첫 실행 시 붙여넣도록 대화형으로 안내합니다; 또는 미리 `export ACEDATACLOUD_API_TOKEN=당신의token`을 설정하여 완전히 무인으로 설치할 수도 있습니다. 스킬 수는 플랫폼 기능 증가에 따라 변하며, `npx acekit list`에 표시되는 현재 목록을 기준으로 합니다.

**세 번째 단계 · 자연어로 말하세요.** agent를 한 번 다시 로드한 다음, 바로 지시하면 됩니다. 예를 들면:

```text
use the short-url skill to shorten https://platform.acedata.cloud/services
```

agent가 직접 스킬을 로드하고, 직접 호출을 시작하여 실제로 이동 가능한 결과를 제공합니다.

## 실제로 한 번 실행하기（출력 포함）

아래 네 가지 예시는 모두 **실제 호출로 현장에서 반환된 결과**이며, 예시가 아닙니다. 명령어의 `$KEY`는 당신의 API Token입니다.

**① URL 단축（동기, 즉시 응답）**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

`https://surl.id/r/1uKp2kilXQ`를 반환합니다——열면 302로 원래 services 페이지로 리디렉션됩니다.

**② 인터넷 검색（동기）**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

실시간 Google 결과를 받습니다（일부 발췌）:

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ LLM 대화（동기, 하나의 인터페이스로 50개 이상의 모델 연결）**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP는 모델 컨텍스트 정보를 통합 관리하고 교환하기 위한 프로토콜입니다.
（39 tokens, 이번 약 0.00007 credit）
```

**④ 이미지 생성（비동기, 약 20초, agent가 이미지 생성까지 자동 폴링）**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

약 22초 후 실제 이미지 한 장을 반환합니다（HTTP 200 · image/png · 317 KB · 이번 약 0.13 credit）:

![AceKit이 실제로 생성한 이미지](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

사실 이 인터페이스들은 외울 필요가 없습니다——스킬을 설치한 후 agent가 각자의 `SKILL.md`에 따라 올바른 요청을 직접 구성하고, 인증과 폴링을 처리합니다. 위 내용은 단지 "백그라운드에서 수행하는 작업"을 펼쳐 보여준 것입니다.

## 실제로 무엇을 설치하나요

AceKit은 AceData 전체 개발자 도구 표면의 "정문"이며, 현재 한 번 설치하면 **스킬 툴킷（Skills）**이 설치됩니다:

- **Agent 스킬 세트**：각 스킬은 미리 작성된 `SKILL.md` 작업 매뉴얼입니다——인증, 비동기 폴링, 오류 재시도, 매개변수 입력 방법까지 모두 명확히 작성되어 있어 agent는 그대로 따르면 됩니다. `npx acekit list`를 실행해 현재 목록을 확인하세요（이 글을 작성하는 시점에는 19개이며, 계속 늘어나고 있습니다）:
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **하나의 통합 Token**: 하나의 `ACEDATACLOUD_API_TOKEN`으로 모든 기능을 해제하며, 실제 사용량에 따라 과금됩니다.

기능별 분류(`npx acekit list` 기준):

| 유형         | 제공업체                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ 이미지 생성      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 영상 생성      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 음악 / 오디오 생성 | Suno · Producer · Fish Audio（TTS）                    |
| 💬 LLM 대화   | 50개 이상의 모델 통합 인터페이스（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 검색       | Google SERP（웹 · 이미지 · 뉴스 · 지도 · 동영상）                  |
| 🔗 도구       | 단축 URL · 얼굴 처리                                            |

> 동일한 기능에 대해 AceData는 독립적인 **MCP 서버**(Suno, Midjourney, Sora, SERP… PyPI / VS Code / Smithery / Docker에 게시됨), **명령줄 CLI** 및 **Python / TypeScript SDK**도 제공하며, 필요에 따라 개별적으로 사용할 수 있습니다. AceKit v0.2는 `acekit add <name>`을 통한 단일 기능 설치와 각 agent의 MCP 구성 자동 작성을 지원할 예정입니다.

## 어떤 Agent를 지원하나요

| Agent                        | 스킬 설치 위치                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode 등 | `~/.agents/skills`（agent가 이 위치를 가리키도록 설정하세요） |

설치 시 AceKit은 머신에 이미 설치된 agent를 자동으로 감지하고, 감지된 몇 개에만 설치합니다.

## 이스터에그: 동일한 Token으로 Claude Code 자체 구동하기

AceData의 인터페이스는 Anthropic의 `/v1/messages` 형식도 호환하므로, **Anthropic 공식 구독이 필요하지 않으며**, 동일한 AceData Token으로 Claude Code를 구동할 수 있습니다. 프로젝트 루트 디렉터리에 `.claude/settings.local.json`을 만드세요:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "your-token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Claude Code를 재시작하면 됩니다. 즉, Claude 전체 모델군을 사용하면서 AceKit을 통해 이미지 생성, 영상 생성, 음악 생성의 "손"도 갖게 됩니다. 자세한 내용은 [Claude Code 통합 가이드](https://platform.acedata.cloud/documents/claude-code-integration)를 참조하세요.
