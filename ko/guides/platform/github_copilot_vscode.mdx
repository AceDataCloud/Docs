GitHub Copilot 공식 BYOK 문서는 VS Code를 지원하는 로컬 클라이언트로 나열하며, OpenAI-compatible Provider를 지원합니다. VS Code 버전, 기업 정책 및 모델 가시성이 최종 엔드포인트에 영향을 미칩니다; 처음 접속 시 아래 내용을 확인하여 실제 요청을 점검하십시오.

## 구성 범위

1. 당신의 GitHub Copilot 계정 또는 조직이 BYOK/Custom Models 기능을 활성화했는지 확인하십시오.
2. VS Code의 Copilot 모델 관리에서 OpenAI-compatible Provider를 추가하십시오.
3. Base URL에 `https://api.acedata.cloud/v1`을 입력하십시오.
4. API Key에 당신의 Ace Data Cloud API Token을 입력하십시오.
5. Model에 선택한 프로토콜과 호환되는 정확한 모델 ID를 모델 디렉토리에서 입력하십시오.
6. Copilot Chat에서 `Reply only OK`를 전송한 후, 작업 공간 컨텍스트가 포함된 요청을 다시 테스트하십시오.

## 현재 경계

- Copilot App, CLI, GitHub Desktop, Enterprise BYOK와 VS Code의 구성 계약은 다르며, 본 가이드는 다른 클라이언트의 단계를 VS Code에 직접 적용하지 않습니다.
- 조직 정책이 개인이 Provider 또는 모델을 추가하는 것을 금지할 수 있습니다.
- Tab completion, Chat, Agent 및 백그라운드 작업은 서로 다른 모델 경로를 사용할 수 있으므로 각각 검증해야 합니다.
