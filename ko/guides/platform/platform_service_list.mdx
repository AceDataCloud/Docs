페이지네이션을 통해 현재 사이트에서 표시되는 Service 디렉터리를 반환하며, 서비스 유형, 표시 정보, 무료 할당량, 요금제 및 연결된 API/Proxy ID를 포함합니다. 서비스 마켓을 구축하거나 신청할 서비스를 선택하는 데 적합합니다.

## 인터페이스 개요

| 항목   | 내용                                                |
| --- | ------------------------------------------------- |
| 메서드  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| 인증  | 공개; 로그인 상태일 때만 `applied`가 현재 계정을 반영                        |
| 페이지네이션  | `count` + `items`                                 |

## 쿼리 매개변수

| 매개변수               | 유형      | 필수  | 설명                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | 아니오   | 서비스 ID로 필터링; 반복 매개변수 지원         |
| `private`        | boolean | 아니오   | 공개 상태로 필터링; 사이트 표시 규칙은 계속 적용됨      |
| `type`           | string  | 아니오   | 서비스 유형; 반복 매개변수 지원              |
| `tag`            | string  | 아니오   | 태그로 필터링                    |
| `include_facets` | boolean | 아니오   | `true`일 때 현재 사이트에서 사용 가능한 유형/태그 통계 추가 |
| `limit`          | integer | 아니오   | 페이지당 항목 수, 최대 100              |
| `offset`         | integer | 아니오   | 페이지네이션 오프셋                    |
| `ordering`       | string  | 아니오   | `rank` 또는 `-rank`만 지원     |

목록은 `alias` 필터링을 지원하지 않습니다. 이미 alias가 있는 경우 `/api/v1/services/{alias}`를 직접 요청하세요. `applied_count`, `updated_at`는 허용되는 정렬 필드가 아닙니다.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## 응답 설명

응답은 `{count, items}`이며, `include_facets=true`일 때만 `facets`가 추가됩니다. 서비스 항목에는 `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` 등의 현재 공개 필드가 포함됩니다.

익명 목록의 `applied`는 특정 계정의 신청 상태를 나타내지 않습니다. 계정 관련 상태가 필요한 경우 유효한 로그인 상태를 포함해야 하며, 최종 기준은 [서비스 신청 목록](https://platform.acedata.cloud/documents/platform-application-list)입니다.
