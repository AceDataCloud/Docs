Coze 공식은 사용자 정의 모델 접속을 지원하며, OpenAI Chat API, OpenAI Responses API 및 Anthropic Messages API 세 가지 프로토콜을 제공합니다. 세 가지 경로의 Base URL, 경로 조합, Header, 스트리밍 및 도구 호출 계약이 다르므로 각각 구성하고 검증해야 합니다.

| 경로                      | 상태  | 가이드                                                                                  |
| ----------------------- | --- | ----------------------------------------------------------------------------------- |
| OpenAI Chat Completions | 실험적 | [Chat 구성](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | 실험적 | [Responses 구성](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | 실험적 | [Messages 구성](https://platform.acedata.cloud/documents/coze-messages-integration)   |

“실험적”은 공식 기능과 구성 진입점이 확인되었음을 나타내지만, 서로 다른 Coze 지역, 버전 또는 패키지에 따라 다른 양식이 표시될 수 있으며, Ace Data Cloud는 여전히 프로토콜에 따라 고정 버전 검증을 완료해야 합니다. 특정 프로토콜의 성공을 다른 두 프로토콜에 일반화하지 마십시오.

## 구성 원칙

- Base API URL은 문서에서 제공하는 base를 우선적으로 입력하십시오; 클라이언트가 자동으로 보완하는 endpoint path를 반복해서 추가하지 마십시오.
- API Key는 귀하의 Ace Data Cloud API Token을 사용하십시오.
- Model은 선택한 프로토콜과 호환되는 모델 디렉토리의 정확한 모델 ID를 사용하십시오.
- 일반 텍스트가 성공한 후에도 스트리밍 및 도구 호출을 검증해야 합니다.
