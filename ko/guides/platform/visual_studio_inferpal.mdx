Inferpal은 Visual Studio 2022/2026을 위한 확장으로, 공식적으로 OpenAI 호환 서비스에 연결하는 것을 지원합니다. 확장 버전은 편집, 도구 호출 및 사용량 기록에 영향을 미칠 수 있으며, 처음 접속할 때는 버전을 고정하고 아래의 최소 검증을 완료해야 합니다.

## 구성

1. Visual Studio Marketplace 또는 공식 저장소에서 Inferpal을 설치합니다.
2. Inferpal의 **Settings → Connection**을 엽니다.
3. Provider에서 OpenAI-compatible을 선택합니다.
4. Base URL에 `https://api.acedata.cloud/v1`을 입력합니다.
5. API Key에 당신의 Ace Data Cloud API Token을 입력합니다.
6. Model에 모델 디렉토리에서 지원하는 Chat Completions의 정확한 모델 ID를 입력합니다.
7. 저장한 후 `Reply only OK`를 전송하고, 코드 컨텍스트를 포함한 요청을 다시 실행합니다.

## 현재 경계

- 본 가이드는 Inferpal만 다루며, Visual Studio 내장 Copilot 또는 다른 확장이 동일한 필드를 지원한다고 보장하지 않습니다.
- 다른 버전은 Base URL에 자동으로 경로를 추가할 수 있으며; 요청이 실패할 경우 최종 요청이 Chat Completions endpoint에 해당하는지 먼저 확인하십시오.
- 고정 버전 E2E를 완료하기 전까지는 모든 편집, 보완 또는 도구 호출 모드가 사용 가능하다고 약속하지 않습니다.
