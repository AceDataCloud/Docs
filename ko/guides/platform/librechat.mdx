[LibreChat](https://www.librechat.ai/)는 서비스 제공자, 모델 및 라우팅 규칙을 설명하는 `librechat.yaml`을 통해 고도로 구성 가능한 오픈 소스 AI 클라이언트입니다. OpenAI 호환 엔드포인트를 사용자 정의할 수 있어 Ace Data Cloud에 연결할 수 있습니다. 이 문서에서는 구성 프로세스를 설명합니다.

## 신청 프로세스

LibreChat에서 Ace Data Cloud에 연결하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)로 가서 API Token을 받아두세요.

![Ace Data Cloud API Key 받기](https://cdn.acedata.cloud/dvc3cg.jpg)

로그인 또는 등록하지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 초대합니다. 로그인 및 등록 후 현재 페이지로 자동으로 돌아옵니다.

첫 신청 시 무료 크레딧이 제공되어 Ace Data Cloud의 모델 서비스를 무료로 체험할 수 있습니다.

## LibreChat 배포

LibreChat은 Docker Compose를 통해 배포되며, 먼저 디렉토리를 준비하고 공식 구성을 다운로드합니다:

```bash
mkdir -p ~/librechat && cd ~/librechat
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/docker-compose.yml
curl -O https://raw.githubusercontent.com/danny-avila/LibreChat/main/.env.example
mv .env.example .env
```

`.env`에서 `openssl rand -hex 32`를 사용하여 `JWT_SECRET`, `JWT_REFRESH_SECRET`, `CREDS_KEY`, `CREDS_IV` 등의 보안 키를 생성하고 필요에 따라 `ALLOW_REGISTRATION`을 설정합니다.

## Ace Data Cloud 구성

`librechat.yaml`을 생성하고 Ace Data Cloud를 사용자 정의 OpenAI 호환 엔드포인트로 설정합니다(전체 필드 설명은 공식 [Custom Endpoints 문서](https://www.librechat.ai/docs/quick_start/custom_endpoints)를 참조하고 `{token}`을 자신의 Token으로 교체):

```yaml
version: 1.0.5
cache: true

endpoints:
  custom:
    - name: "Ace Data Cloud"
      apiKey: "{token}"
      baseURL: "https://api.acedata.cloud/v1"
      models:
        default:
          - "MODEL_ID"
        fetch: true
      titleConvo: true
      titleModel: "MODEL_ID"
      modelDisplayLabel: "Ace Data Cloud"
```

`docker-compose.yml`의 `api` 서비스 아래에 해당 파일을 컨테이너에 마운트한 후 `docker compose up -d`로 시작합니다:

```yaml
    volumes:
      - type: bind
        source: ./librechat.yaml
        target: /app/librechat.yaml
```

`baseURL`의 경로 규칙에 유의하세요:

| baseURL                               | 실제 요청                                                   | 결과                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | 올바름                     |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | 사용 가능                  |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404 (`/openai` 아래에 `/v1` 없음) |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404 ( `/v1` 없음)         |

## 모델 선택

모델 디렉토리는 지속적으로 업데이트됩니다. 클라이언트에서 자동으로 로드된 모델 목록을 우선 사용하고, 수동으로 입력해야 할 경우 `GET https://api.acedata.cloud/v1/models`를 요청하여 현재 모델 ID를 가져온 후 클라이언트가 지원하는 컨텍스트, 이미지 및 도구 호출 능력에 따라 선택합니다.

## 검증 연결

문제가 LibreChat에 있는지 네트워크에 있는지 확실하지 않은 경우 curl을 사용하여 엔드포인트를 직접 검증할 수 있습니다( `{token}`을 자신의 Token으로 교체):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI 호환의 `chat.completion` 객체가 반환되면 Token과 엔드포인트가 준비된 것입니다; 만약 `HTTP 403 used_up`이 반환되면 Token은 유효하지만 잔액이 부족하다는 의미로, [콘솔](https://platform.acedata.cloud/console/applications)에서 충전하면 됩니다.

## 고급: yaml 구성 팁

`librechat.yaml`은 여러 엔드포인트 그룹을 지원하며, `apiKey: "user_provided"`를 사용하여 각 사용자가 자신의 Key를 입력하도록 할 수 있습니다; `titleModel`은 대화 제목 생성을 위한 모델을 지정합니다; `dropParams`는 대상 API가 지원하지 않는 매개변수를 일괄 삭제할 수 있습니다. 자세한 내용은 [librechat.yaml 구성 상세 설명](https://www.librechat.ai/docs/configuration/librechat_yaml)을 참조하세요.

## 자주 묻는 질문

### 시작 후 Ace Data Cloud 엔드포인트가 보이지 않음

대개 yaml이 컨테이너에 마운트되지 않았거나 들여쓰기가 잘못된 경우입니다. `docker-compose.yml`의 volumes를 확인하고 yaml 들여쓰기를 검증하세요.

### 404 오류

`baseURL`이 `.../openai/v1`로 잘못 작성되었거나 `/v1`이 누락되었습니다. `https://api.acedata.cloud/v1`로 수정하세요.

### 모델 드롭다운이 비어 있음

`fetch: true`이지만 `/v1/models`가 실패할 경우, `fetch: false`로 변경하고 `default`를 수동으로 나열하세요.

### yaml 수정 후 적용되지 않음

컨테이너를 재시작해야 합니다: `docker compose restart api`.
