API 자격 증명을 영구 삭제합니다. 삭제 후 **즉시 복구할 수 없으며**, 해당 Token을 사용하는 모든 비즈니스 인터페이스는 즉시 `401`을 수신합니다.

> ℹ️ 이 인터페이스는 **AceDataCloud 플랫폼 관리 API**에 속하며, 통합 접두사는 `https://platform.acedata.cloud/api/v1/`입니다.

## 인터페이스 개요

| 항목   | 내용                                                                  |
| --- | ------------------------------------------------------------------- |
| 메서드  | `DELETE`                                                            |
| URL | `https://platform.acedata.cloud/api/v1/credentials/{credential_id}` |
| 인증  | ✅ 계정 토큰 필요                                                            |

`/credentials/{id}`와 `/credentials/{id}/`는 현재 모두 사용할 수 있으며, 예시는 통일하여 후행 슬래시가 없는 형식을 사용합니다.

## 인증 안내（계정 토큰을 얻는 방법）

요청 헤더:

```http
Authorization: Bearer ${PLATFORM_TOKEN}
```

획득 방법은 [AceDataCloud 플랫폼 계정 토큰 관리](https://platform.acedata.cloud/documents/platform-token)를 참조하세요.

## 경로 매개변수

| 매개변수              | 유형   | 필수  | 설명        |
| --------------- | ---- | --- | --------- |
| `credential_id` | UUID | ✅   | 삭제할 자격 증명 ID |

## 요청 예시

### cURL

```shell
curl -X DELETE 'https://platform.acedata.cloud/api/v1/credentials/df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

cred_id = "df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6"
resp = requests.delete(
    f"https://platform.acedata.cloud/api/v1/credentials/{cred_id}",
    headers={"authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}"},
    timeout=10,
)
assert resp.status_code == 204, resp.text
print("✅ 已删除")
```

### Node.js

```javascript
const credId = 'df3e1b1b-9e72-4c4f-9a83-1e23f7c8b4d6'
const r = await fetch(`https://platform.acedata.cloud/api/v1/credentials/${credId}`, {
  method: 'DELETE',
  headers: { authorization: `Bearer ${process.env.PLATFORM_TOKEN}` },
})
console.log('status:', r.status) // 204
```

## 응답

- **성공**: `HTTP 204 No Content`, **응답 본문 없음**.
- **실패**: 오류 JSON을 반환하며, 아래 표를 참조하세요.

## 오류 처리

| HTTP | code                | 의미         |
| ---- | ------------------- | ---------- |
| 401  | `not_authenticated` | 계정 토큰 누락     |
| 403  | `permission_denied` | 해당 자격 증명이 귀하의 것이 아님    |
| 404  | `not_found`         | 자격 증명이 존재하지 않거나 이미 삭제됨 |

## 유용한 팁

- **삭제는 되돌릴 수 없습니다**——플랫폼은 Token 사본을 보관하지 않습니다. 유출이 의심되지만 모니터링 데이터를 유지하고 싶다면, 삭제 대신 [AceDataCloud 플랫폼 API 자격 증명 교체](https://platform.acedata.cloud/documents/platform-credential-rotate)를 사용해야 합니다.
- **삭제해도 해당 자격 증명으로 이미 소모된 할당량은 반환되지 않습니다**. Application 잔액은 사용량에 따라 실시간으로 차감되며, 자격 증명 삭제는 잔액 장부에 영향을 주지 않습니다.
- 삭제 후 [API 자격 증명 목록](https://platform.acedata.cloud/documents/platform-credential-list)을 통해 `application_id`별로 남은 자격 증명을 다시 확인할 수 있습니다.
- **일괄 정리 전 호출자를 먼저 확인하세요**: 목록에는 현재 마지막 사용 시간 필드가 없습니다. 배포 구성 및 호출 기록을 함께 확인하여 자격 증명이 더 이상 사용되지 않는 것을 확인한 후 하나씩 삭제해야 합니다.
