FreeAIr는 비주얼 스튜디오 2022/2026을 위한 오픈 소스 확장으로, 공식적으로 모든 OpenAI 호환 API에 연결할 수 있다고 선언합니다. 서로 다른 확장 버전의 요청 동작은 변경될 수 있으며, 처음 접속할 때는 버전을 고정하고 아래의 최소 검증을 완료해야 합니다.

## 구성

1. 비주얼 스튜디오 마켓플레이스 또는 공식 저장소에서 FreeAIr를 설치합니다.
2. FreeAIr 설정을 열고 OpenAI 호환 연결을 추가합니다.
3. Endpoint에 `https://api.acedata.cloud/v1`을 입력합니다.
4. Token에 당신의 Ace Data Cloud API Token을 입력합니다.
5. Model에 모델 디렉토리에서 지원하는 Chat Completions의 정확한 모델 ID를 입력합니다.
6. 저장 후 `Reply only OK`를 전송하고, 프로젝트 컨텍스트가 포함된 요청을 다시 테스트합니다.

## 현재 경계

- 본 가이드는 FreeAIr만 다루며, 비주얼 스튜디오 내장 Copilot이 임의의 Base URL을 지원한다는 것을 의미하지 않습니다.
- 확장 버전은 endpoint 조합 방식을 변경할 수 있으며, 검증 시 최종 요청 URL을 확인해야 합니다.
- 도구 호출 및 확장 내 MCP 기능은 독립적으로 검증해야 하며, 일반 채팅의 성공으로 대체할 수 없습니다.
