Coze 공식 사용자 정의 모델 문서는 OpenAI Responses API를 지원하며, Base API URL, API Key 및 모델 필드를 제공합니다. 서로 다른 Coze 임대 버전은 경로 조합, 스트리밍 출력 및 도구 호출 처리 방식이 다를 수 있으므로, 처음 접속할 때는 아래 항목을 하나씩 확인하십시오.

## 구성

1. Coze 모델 관리에 들어가서 사용자 정의 모델을 추가합니다.
2. Protocol을 OpenAI Responses API로 선택합니다.
3. Base API URL에 `https://api.acedata.cloud/v1`을 입력합니다.
4. API Key에 당신의 Ace Data Cloud API Token을 입력합니다.
5. Model에 모델 디렉토리에서 Responses API를 지원하는 정확한 모델 ID를 입력합니다.
6. 저장하고 Coze의 연결 테스트를 완료합니다.
7. Bot/Agent에서 `Reply only OK`를 전송한 후, 도구 호출을 다시 테스트합니다.

## 현재 경계

- 서로 다른 Coze 지역, 버전 또는 패키지는 서로 다른 양식을 표시할 수 있습니다.
- Base API URL은 base를 사용해야 하며, `/responses`를 반복해서 추가하지 마십시오; 현재 UI에서 전체 API URL을 명확히 요구하는 경우, 양식의 안내에 따릅니다.
- Chat Completions, Responses 및 Anthropic Messages는 세 개의 독립적인 경로로, 서로 대체하여 검증할 수 없습니다.
