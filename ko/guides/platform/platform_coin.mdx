$ACE를 보유하고 Solana 지갑을 검증한 후, Ace Data Cloud의 **해당 혜택을 지원하는 Credits API 서비스**에서 호출 할인을 받을 수 있습니다. $ACE는 항상 귀하의 지갑에 보관되며, 플랫폼은 온체인 잔액만 읽고 토큰을 수탁, 잠금, 전송 또는 소모하지 않습니다.

> $ACE는 플랫폼 충전 잔액이 아니며, 결제 승인 또는 스테이킹 상품도 아닙니다. 할인은 페이지에 나열된 Credits API 서비스에만 적용되며, 충전 주문, x402 USDC 결제 또는 기타 Credits가 아닌 소비 경로에는 적용되지 않습니다.

## $ACE란 무엇인가요

$ACE는 Solana 메인넷에 배포된 Ace Data Cloud 생태계 토큰입니다. 현재 출시된 용도는 보유 혜택입니다. 지갑 내 $ACE 잔액이 해당 기준에 도달하면 플랫폼이 지원되는 API 서비스에 할인을 자동 적용합니다.

**구매 또는 교환 전에 전체 Mint를 한 글자씩 확인하세요.** 토큰 약칭과 아이콘은 중복될 수 있으며, 전체 Mint만이 동일한 토큰을 식별하는 신뢰할 수 있는 기준입니다.

## 첫 번째 단계: $ACE 구매

$ACE를 구매하기 위해 **플랫폼에서 먼저 지갑을 연결할 필요는 없습니다**. 다음만 준비하면 됩니다:

- Phantom 또는 Solflare와 같은 Solana 메인넷 지갑;
- 교환에 사용할 수 있는 SOL, USDC 또는 페이지에서 실제로 지원하는 기타 자산;
- Solana 네트워크 수수료를 지불하기 위한 소량의 SOL.

플랫폼은 귀하에게 시드 구문이나 개인 키를 제공하도록 요구하지 않습니다. 시드 구문, 개인 키 또는 원격 지갑 제어를 제출하라고 요구하는 모든 페이지는 정상적인 절차가 아닙니다.

### 1. 플랫폼이 제공하는 정확한 진입점으로 이동

[$ACE 보유 혜택 페이지](https://platform.acedata.cloud/console/coin)를 열고, 첫 번째 단계 카드에서 전체 Mint를 확인한 후 “$ACE 구매”를 클릭하세요. 또는 다음을 직접 열 수 있습니다:

[Jupiter에서 $ACE 확인 및 교환](https://jup.ag/tokens/GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump)

이 링크에는 현재 공식 Mint가 포함되어 있습니다. 토큰 약칭만 검색하여 결과를 선택하지 마세요.

### 2. Solana 지갑 연결

교환 페이지에서 준비한 지갑을 연결하고, 현재 네트워크가 Solana 메인넷인지 확인하세요. 처음 지갑을 사용할 때는 먼저 지갑 자체의 보안 안내 및 거래 확인 화면을 이해하세요.

### 3. 교환에 사용할 자산과 수량 선택

SOL, USDC 또는 페이지에서 실제로 지원하는 기타 자산을 결제 자산으로 선택하고, 교환하려는 수량을 입력하세요. 페이지에 표시되는 대상 토큰 Mint가 아래 주소와 완전히 일치하는지 확인하세요:

```text
GnHpRsrcyfHSMZNzmpjAzTFQA26vnbRMzbKQ11ZKpump
```

### 4. 교환 정보 확인

제출하기 전에 다음을 확인하세요:

- 예상 수령 $ACE 수량;
- 환율, 가격 영향 및 최소 수령 수량;
- 네트워크 수수료 및 페이지에 나열된 기타 수수료;
- 지갑 팝업의 실제 거래 내용.

온체인 교환 가격과 유동성은 변동될 수 있습니다. 플랫폼은 체결 가격, 체결 가능 수량 또는 토큰 가치를 보장하지 않습니다. 거래 내용을 이해하고 위험을 감당할 수 있을 때에만 직접 확인하세요.

### 5. 지갑에서 확인

확인 후 Solana 네트워크가 거래를 완료할 때까지 기다린 다음, 지갑으로 돌아가 $ACE 잔액을 확인하세요. 지갑이 거래 실패 또는 취소를 명확히 안내하지 않는 한, 아직 지갑 확인을 기다리는 팝업을 닫거나 새로고침하지 마세요.

## 두 번째 단계: 구매 후 지갑 연결 및 검증

구매가 완료된 후 플랫폼으로 돌아가 지갑을 연결하고 검증하세요. 구매 전에 연결할 필요는 없으며, 구매 자체가 계정을 자동으로 연결하지도 않습니다. 다음 작업은 반드시 **$ACE를 보유한 동일한 지갑**으로 완료하세요:

1. [$ACE 보유 혜택 페이지](https://platform.acedata.cloud/console/coin)로 돌아갑니다;
2. “지갑 연결”을 클릭하고 방금 사용한 지갑을 선택합니다;
3. “검증 및 연결”을 클릭합니다;
4. 지갑에서 플랫폼이 표시하는 소유권 검증 메시지에 서명합니다;
5. 플랫폼이 finalized 온체인 잔액을 동기화할 때까지 기다립니다.

소유권 검증 서명은 귀하가 해당 지갑을 제어한다는 것만 증명하며, **결제 또는 토큰 전송을 승인하지 않습니다**. 정상적인 절차에서는 읽을 수 있는 메시지에 서명하며, 알 수 없는 주소로 송금하라고 요구하지 않습니다.

검증에 성공하면 페이지에 지갑 축약 주소, $ACE 잔액, 마지막 동기화 시간 및 현재 적용 할인율이 표시됩니다. 온체인 거래 완료와 플랫폼 잔액 동기화 사이에는 지연이 있을 수 있으므로, 구매 완료 후 할인이 즉시 표시되지 않을 수 있습니다.

## 할인 적용 방식

|    $ACE 보유량 | Credits API 호출 할인 |
| ----------: | ---------------: |
|     100,000 |               1% |
|     250,000 |               2% |
|     500,000 |               3% |
|   1,000,000 |               5% |
|   5,000,000 |               7% |
|  10,000,000 |              10% |
|  25,000,000 |              12% |
|  50,000,000 |              15% |
| 100,000,000 |              20% |

할인은 서비스 설정에 따라 적용됩니다. 보유 혜택 페이지의 “ACE 혜택을 지원하는 서비스” 목록 및 각 서비스에 현재 표시되는 할인율을 기준으로 하며, 플랫폼의 모든 서비스를 포괄하는 것으로 이해해서는 안 됩니다.

잔액은 백그라운드 작업이 Solana finalized 상태를 읽어 처리합니다. Coin 유형 할인에는 유효 기간이 있습니다:

- 동기화에 성공하면 기준을 충족하는 할인이 자동으로 적용됩니다;
- 일시적인 동기화 실패 시 페이지에 잔액 상태 이상이 안내됩니다;
- 유효 기간이 지난 뒤에도 새로고침할 수 없으면 청구 경로는 오래된 할인을 중지합니다;
- 지갑 잔액이 감소하거나 $ACE를 매도한 후에는, 다음 동기화 성공 시 새 잔액에 따라 혜택이 다시 계산됩니다.

## 자주 묻는 질문

### 구매 후에도 플랫폼 잔액이 여전히 0인 이유는 무엇인가요?

먼저 거래가 Solana 메인넷에서 완료되었는지 확인하고, $ACE를 보유한 동일한 지갑이 연결되어 있는지 확인하십시오. 플랫폼은 finalized 온체인 상태를 읽으므로, 거래 확인 및 백엔드 동기화 모두 일시적인 지연이 발생할 수 있습니다. 페이지에 계속 동기화 오류가 표시되면 나중에 다시 시도하거나 지원팀에 문의하십시오.

### 왜 검증 메시지에 서명할 수 없나요?

현재 기본 절차에서는 지갑이 `signMessage`를 지원해야 합니다. 지갑 버전을 업데이트하거나 메시지 서명을 지원하는 Solana 지갑을 사용하십시오. 검증을 우회하기 위해 송금하거나 개인 키를 제출하지 마십시오.

### 잘못된 지갑을 연결했다면 어떻게 하나요?

브라우저에서 “지갑 연결 해제”를 하면 현재 브라우저 연결만 해제되며, 플랫폼 연결 상태는 변경되지 않습니다. 혜택 지갑을 변경하려면 보유 혜택 페이지에서 “지갑 연결 해제”를 클릭하고 현재 ACE 할인의 철회를 확인한 후, 새 지갑을 연결하고 검증하십시오.

### 지갑 서명으로 내 자산이 이동할 수 있나요?

그렇지 않습니다. 연결 절차에서 서명하는 것은 소유권 검증 메시지이며, 토큰 전송이나 결제 승인 요청이 아닙니다. 서명하기 전에 지갑에 표시되는 메시지 내용을 계속 확인해야 하며, 거래, 전송 또는 낯선 승인 요청이 나타나면 거부하십시오.

### 얼마나 많은 $ACE를 구매해야 할인을 받을 수 있나요?

현재 첫 번째 등급의 기준은 100,000 $ACE이며, 지원되는 Credits API 서비스에 1% 할인을 제공합니다. 각 등급은 위 표를 참조하십시오. 실제 적용 서비스 및 현재 할인은 보유 혜택 페이지를 기준으로 합니다.

### 어떤 서비스가 $ACE 혜택을 지원하나요?

보유 혜택 페이지의 “ACE 혜택 지원 서비스” 영역을 확인하십시오. 충전 주문, x402 USDC 결제 및 Credits가 아닌 소비 경로에는 이 할인이 적용되지 않습니다.

### $ACE를 매도하거나 전송한 후에는 어떻게 되나요?

혜택은 온체인 잔액을 기준으로 계산됩니다. 잔액이 감소하면 다음 성공적인 동기화 시 해당 할인이 낮아지거나 철회됩니다. 오래된 할인에도 유효 기간이 있으며 무한정 유지되지 않습니다.

### 이전 지갑에 접근할 수 없으면 어떻게 하나요?

플랫폼 계정에 로그인한 후 보유 혜택 페이지에서 “지갑 연결 해제”를 클릭하고 확인하면 됩니다. 연결 해제는 플랫폼 내 지갑 연결 및 ACE 할인만 철회하며, 지갑 내 어떤 자산도 전송, 소각 또는 조작하지 않습니다. 완료 후 새 지갑을 연결하고 검증할 수 있습니다.
