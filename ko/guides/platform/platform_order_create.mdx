하나 또는 여러 Application에 대해 결제 대기 주문을 생성합니다. 생성 시 주문이 기록되지만 자동으로 결제가 완료되지는 않습니다. 결제 전에 응답의 `price`, 패키지 및 Application을 확인해야 합니다.

## 준비 작업

- [Account Token](https://platform.acedata.cloud/documents/platform-token)을 생성합니다.
- [Application 목록](https://platform.acedata.cloud/documents/platform-application-list)에서 `application_id`를 가져옵니다.
- [서비스 상세](https://platform.acedata.cloud/documents/platform-service-detail)의 `packages`에서 Application 유형에 일치하고 구매 가능한 `package_id`를 선택합니다.

```shell
export PLATFORM_TOKEN='귀하의 계정 토큰'
export APPLICATION_ID='귀하의 Application ID'
export PACKAGE_ID='귀하의 Package ID'
```

## 인터페이스 개요

| 항목   | 내용                                              |
| ---- | ----------------------------------------------- |
| 메서드   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| 인증   | Account Token, OAuth token에는 `orders:write` 필요      |
| Body | JSON                                            |

## 요청 본문

단일 Application 주문에는 `application_id` + `package_id`를 사용합니다. 일괄 주문에는 길이가 대응하는 `application_ids` + `package_ids`를 사용합니다. 일반 주문은 이후 `/pay/` 요청에서 결제 방식을 선택합니다. iOS 인앱 구매 주문은 생성 시 `pay_way: "AppleIAP"`를 전달하며, `metadata.apple_product_id` 및 `metadata.apple_price`가 있는 Usage 패키지를 하나만 선택할 수 있습니다. Apple 인앱 구매는 독립적인 미국 달러 사전 설정 가격을 사용하며, 멤버십 할인, 결제 방식 할인 또는 사이트 할증이 중첩되지 않습니다. 기타 지역의 현지 통화 청구 금액은 Apple 결제 확인 페이지를 기준으로 합니다.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## 응답 설명

성공 시 `201` 및 새로 생성된 Order 객체를 반환합니다. 주요 필드에는 `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` 및 시간 필드가 포함됩니다. 새 주문은 일반적으로 `Pending`이며, 이어서 [주문 결제](https://platform.acedata.cloud/documents/platform-order-pay)를 호출합니다.

- `price`는 서버가 패키지, 사이트 할증 및 할인을 기준으로 계산한 결제 금액입니다. 클라이언트에서 직접 계산하지 마십시오.
- Package와 Application 서비스 또는 유형이 일치하지 않으면 `400`을 반환합니다.
- 무료이며 시스템에서 관리하는 Package는 공개 주문 인터페이스를 통해 직접 수령할 수 없습니다.
- 현재 계정에 속하지 않는 Application에 대해 주문을 생성하면 거부됩니다.
