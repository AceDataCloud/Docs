[Ace Data Cloud Studio](https://studio.acedata.cloud)는 크리에이터, 운영, 디자인 및 비즈니스 팀을 대상으로 AI 대화, 이미지, 비디오, 음악 및 자동 영상 제작 도구를 통합 제공합니다. 사용자는 창작 목표에서 시작해 워크플로를 선택하며, 먼저 여러 제품 사이에서 반복적으로 가입, 충전 및 전환할 필요가 없습니다.

![Studio 홈: 창작 목표에서 대화, 이미지, 비디오 및 음악으로 진입](https://cdn.acedata.cloud/uploads/34c26779-82a4-4a9b-b81b-fb98ccd525be)

## 어떤 시나리오에 적합한가요

- **콘텐츠 제작**：글쓰기, 리서치, 포스터, 커버, 숏폼 비디오 및 배경음악；
- **마케팅 운영**：상품 이미지, 소셜 미디어 소재, 이벤트 비주얼 및 브랜드 콘텐츠；
- **디자인 탐색**：참고 이미지 편집, 스타일 탐색, 구도 및 다중 버전 시안；
- **비즈니스 팀**：자연어로 크로스 모델, 다단계 창작 작업 완료；
- **개발자 및 고급 사용자**：지원되는 시나리오에서 API Key, Connector, Skill 또는 로컬 도구 구성。

구체적으로 사용 가능한 기능은 사이트 구성, 지역, 계정 및 제품 버전에 따라 달라질 수 있으며, 현재 페이지에 실제로 표시되는 내용을 기준으로 합니다.

## 시작 방법

1. [studio.acedata.cloud](https://studio.acedata.cloud)에 접속합니다；
2. 페이지에서 현재 제공하는 로그인 방식을 선택합니다；
3. 홈의 창작 목표 또는 왼쪽 기능 탐색에서 도구로 진입합니다；
4. 현재 서비스의 가격, 매개변수 및 콘텐츠 요구사항을 읽습니다；
5. 먼저 저비용 작업으로 프로세스를 검증한 후, 고해상도, 장편 비디오 또는 일괄 생성을 진행합니다。

서비스마다 과금 단위, 처리 시간 및 매개변수가 다릅니다. 제출 전에 현재 페이지와 사용 기록을 확인해야 하며, 과거 스크린샷을 근거로 가격을 추정하지 마세요.

## 핵심 워크플로

### AI 대화

글쓰기, 분석, 학습, 프로그래밍 및 멀티모달 토론에 사용됩니다. 구체적인 모델, 컨텍스트 기능 및 도구 지원은 현재 모델 선택기를 기준으로 합니다.

### AI 이미지

텍스트 이미지 생성, 참고 이미지 편집, 이미지 확장, 스타일 변환 및 비주얼 디자인을 포괄합니다. 서로 다른 이미지 서비스는 크기, 텍스트 렌더링, 인물 일관성 및 편집 기능에서 각각 중점을 둡니다.

### AI 비디오 및 자동 영상 제작

텍스트, 이미지, 참고 소재 또는 스크립트 기반의 비디오 제작을 지원합니다. 자동 영상 제작 워크플로는 스크립트, 화면, 더빙, 자막 및 음악을 조합할 수 있으며, 장시간 작업은 상태 조회, 실패 원인 및 최종 출력의 완전성에 주의해야 합니다.

### AI 음악

스타일 또는 가사에서 노래를 생성하고, 페이지에서 제공하는 기능에 따라 계속 편집하거나 확장할 수 있습니다. 상업적 사용 전에 콘텐츠 권리와 대상 플랫폼 규칙을 직접 확인해야 합니다.

### Connector、Skill 및 고급 도구

일부 계정 또는 사이트에서는 Connector, Skill 및 로컬 도구를 사용할 수 있습니다. 이러한 진입점은 현재 제품, 권한 및 실행 환경의 제약을 받으며, 모든 사용자 또는 화이트 라벨 사이트에 기본적으로 개방되는 것은 아닙니다.

## Web, 모바일 및 데스크톱

Studio Web 버전은 `studio.acedata.cloud`에 있습니다. 모바일 및 데스크톱의 기능과 사이트 관리 진입점은 다를 수 있습니다：

- 화이트 라벨 사이트 관리는 Web 버전에서 현재 Site 관리자에게만 표시됩니다；
- 네이티브 모바일 및 데스크톱 앱에서는 모든 사이트 운영 설정이 표시되지 않습니다；
- 휴대폰 너비에서는 하단 기능 탐색을 사용하며, 복잡한 창작 양식은 데스크톱 브라우저에 더 적합합니다。

## 자신의 브랜드 서브사이트 만들기

자신의 이름, Logo, 페이지 도메인, 기능 카탈로그 및 채널 가격으로 Studio를 운영해야 하는 경우, 공식 Studio Web 버전에서 다음을 엽니다：

**사용자 아바타 → 설정 → 내 서브사이트**

## 화이트 라벨 및 배포 경계

- 화이트 라벨은 공유 플랫폼의 Site 구성이지, 독립 배포 또는 독립 데이터베이스가 아닙니다；
- 사용자 계정, 잔액, 요금제 및 대부분의 자산은 공유 체계에 속합니다；
- 충전, 기능 또는 서비스를 숨기는 것은 페이지 표시 제어일 뿐, 권한 격리가 아닙니다；
- Site 가산 가격은 일반적인 화이트 라벨 구매 프로세스의 채널 가격이며, 계정이 모든 진입점에서 강제 적용받는 테넌트 가격이 아닙니다；
- 배포 수익은 유효 주문, 초대 관계, 등급, 환불 및 리스크 관리에 따라 달라지며, 고정 비율, 입금 속도 또는 수익 수치를 보장하지 않습니다。

## 사용 권장사항

- 중요한 사실과 생성된 콘텐츠는 사람이 검토해야 합니다；
- 프롬프트, 스크린샷, 채팅 또는 티켓에 비밀번호, API Key, 신분증 또는 결제 정보를 유출하지 마세요；
- 인물 이미지, 음성, 상표 및 저작권 소재는 필요한 권한을 취득해야 합니다；
- 고비용 작업은 먼저 샘플을 만들고, 매개변수를 확인한 후 규모를 확대하세요；
- 이상이 발생하면 시간, 서비스, 상태 코드 및 공개 가능한 요청 식별자를 기록하고, 전체 token을 제출하지 마세요。

## 홈페이지 제3자 웹사이트의 OAuth 인증

웹사이트 컴포넌트 설정에서 OAuth를 활성화하고, 제3자가 ACE Data Cloud에 등록한 애플리케이션 ID와 콜백 주소를 입력합니다. 웹사이트와 콜백 주소는 Studio 출처와 다른 동일한 HTTPS 출처를 사용해야 합니다. 설정에 애플리케이션 비밀키를 입력하지 마세요.

제3자 페이지는 OAuth 메시지 프로토콜을 연동해야 합니다. 로그인한 방문자는 컴포넌트 영역에서 공식 동의 페이지를 보게 되며, 동의 후 제3자는 OAuth token을 통해 해당 방문자의 기존 API Key를 읽을 수 있습니다. 로그인하지 않았거나 인증을 거부한 경우에는 Key가 제공되지 않습니다.

Key 읽기를 허용한 후 제3자는 이를 저장하고 사용할 수 있습니다. OAuth 인증을 취소해도 이미 복사된 Key는 무효화되지 않습니다；별도로 Key를 취소하거나 교체하세요. 자세한 내용은 「Ace Data Cloud 로그인 연동 사용（OAuth 2.0）」의 Studio 컴포넌트 설명을 참조하세요.
