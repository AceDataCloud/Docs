[Ace Data Cloud Studio](https://studio.acedata.cloud)는 크리에이터, 운영, 디자인 및 비즈니스 팀을 대상으로 AI 대화, 이미지, 비디오, 음악 및 자동 영상 제작 도구를 통합 제공합니다. 사용자는 창작 목표에서 출발해 워크플로를 선택하며, 여러 제품 사이에서 반복적으로 등록, 충전 및 전환할 필요가 없습니다.

![Studio 홈: 창작 목표에서 대화, 이미지, 비디오 및 음악으로 진입](https://cdn.acedata.cloud/uploads/34c26779-82a4-4a9b-b81b-fb98ccd525be)

## 어떤 시나리오에 적합한가

- **콘텐츠 제작**: 글쓰기, 리서치, 포스터, 표지, 숏폼 영상 및 배경음악;
- **마케팅 운영**: 상품 이미지, 소셜 미디어 소재, 이벤트 비주얼 및 브랜드 콘텐츠;
- **디자인 탐색**: 참고 이미지 편집, 스타일 탐색, 구도 및 다중 버전 시안;
- **비즈니스 팀**: 자연어로 크로스 모델, 다단계 창작 작업 완료;
- **개발자 및 고급 사용자**: 지원되는 시나리오에서 API Key, Connector, Skill 또는 로컬 도구 구성.

구체적으로 사용 가능한 기능은 사이트 구성, 지역, 계정 및 제품 버전에 따라 달라질 수 있으며, 현재 페이지에 실제로 표시되는 내용을 기준으로 합니다.

## 시작하는 방법

1. [studio.acedata.cloud](https://studio.acedata.cloud)에 방문합니다;
2. 페이지에서 현재 제공하는 로그인 방식을 선택합니다;
3. 홈의 창작 목표 또는 왼쪽 기능 탐색에서 도구로 진입합니다;
4. 현재 서비스의 가격, 파라미터 및 콘텐츠 요구 사항을 읽습니다;
5. 먼저 저비용 작업으로 프로세스를 검증한 후, 고해상도, 긴 영상 또는 대량 생성으로 진행합니다.

서비스마다 과금 단위, 처리 시간 및 파라미터가 다릅니다. 제출 전에 현재 페이지와 사용 기록을 확인해야 하며, 과거 스크린샷을 근거로 가격을 추정하지 마십시오.

## 핵심 워크플로

### AI 대화

글쓰기, 분석, 학습, 프로그래밍 및 멀티모달 토론에 사용됩니다. 구체적인 모델, 컨텍스트 기능 및 도구 지원은 현재 모델 선택기를 기준으로 합니다.

### AI 이미지

텍스트 기반 이미지 생성, 참고 이미지 편집, 이미지 확장, 스타일 변환 및 비주얼 디자인을 포괄합니다. 서로 다른 이미지 서비스는 크기, 텍스트 렌더링, 인물 일관성 및 편집 기능에서 각각 중점을 둡니다.

### AI 비디오 및 자동 영상 제작

텍스트, 이미지, 참고 소재 또는 스크립트 기반의 비디오 제작을 지원합니다. 자동 영상 제작 워크플로는 스크립트, 화면, 더빙, 자막 및 음악을 조합할 수 있으며, 긴 작업은 상태 조회, 실패 원인 및 최종 출력의 완전성에 주의해야 합니다.

### AI 음악

스타일 또는 가사로부터 노래를 생성하고, 페이지에서 제공하는 기능에 따라 계속 편집하거나 확장할 수 있습니다. 상업적 사용 전에 콘텐츠 권리와 대상 플랫폼의 규칙을 직접 확인해야 합니다.

### Connector、Skill 및 고급 도구

일부 계정 또는 사이트에서는 Connector, Skill 및 로컬 도구를 사용할 수 있습니다. 이러한 진입점은 현재 제품, 권한 및 실행 환경의 제약을 받으며, 모든 사용자 또는 화이트 라벨 사이트에 기본적으로 열려 있는 것은 아닙니다.

## Web, 모바일 및 데스크톱

Studio Web 버전은 `studio.acedata.cloud`에 있습니다. 모바일 및 데스크톱 버전의 기능과 사이트 관리 진입점은 다를 수 있습니다:

- 화이트 라벨 사이트 관리는 Web 버전에서 현재 Site 관리자에게만 표시됩니다;
- 네이티브 모바일 및 데스크톱 버전에서는 모든 사이트 운영 설정이 표시되지 않습니다;
- 휴대폰 너비에서는 하단 기능 탐색을 사용하며, 복잡한 창작 양식은 데스크톱 브라우저에 더 적합합니다.

## 화이트 라벨 및 배포 경계

- 화이트 라벨은 공유 플랫폼의 Site 구성이지, 독립 배포 또는 독립 데이터베이스가 아닙니다;
- 사용자 계정, 잔액, 플랜 및 대부분의 자산은 공유 체계에 속합니다;
- 충전, 기능 또는 서비스를 숨기는 것은 페이지 표시 제어일 뿐, 권한 격리가 아닙니다;
- Site 추가 가격은 일반적인 화이트 라벨 구매 프로세스의 채널 가격이며, 계정의 모든 진입점에서 강제되는 테넌트 가격이 아닙니다;
- 배포 수익은 유효 주문, 초대 관계, 등급, 환불 및 리스크 관리에 따라 달라지며, 고정 비율, 입금 속도 또는 수익 금액을 보장하지 않습니다.

## 사용 권장 사항

- 중요한 사실과 생성 콘텐츠는 사람이 검토해야 합니다;
- 프롬프트, 스크린샷, 채팅 또는 티켓에 비밀번호, API Key, 신분증 또는 결제 정보를 노출하지 마십시오;
- 인물 이미지, 음성, 상표 및 저작권 소재는 필요한 승인을 받아야 합니다;
- 고비용 작업은 먼저 샘플을 만들고, 파라미터를 확인한 후 규모를 확대하십시오;
- 이상이 발생하면 시간, 서비스, 상태 코드 및 공개 가능한 요청 식별자를 기록하고, 전체 token을 제출하지 마십시오.

## 홈 페이지 타사 웹사이트의 OAuth 권한 부여

웹사이트 컴포넌트는 표준 OAuth 리디렉션을 채택하거나 Studio 현재 계정의 컴포넌트 권한 부여를 사용할 수 있습니다. 표준 리디렉션은 타사 버튼을 통해 권한 부여 페이지를 열고, 이후 해당 타사에 등록된 콜백 주소로 돌아갑니다; 이는 Studio 메시지 프로토콜을 요구하지 않으며, Studio 로그인 상태를 자동으로 재사용하지도 않습니다. 일반 iframe은 첫 로그인 후 계속 권한을 부여하는 과정에 현재도 공백이 있으므로, 연동 문서에 따라 검증하거나 독립 페이지／컴포넌트 권한 부여를 사용해야 합니다.

Studio 현재 계정을 사용하려는 경우, 「설정 → 홈 → 웹사이트 컴포넌트」에서 OAuth를 활성화하고 타사 애플리케이션 ID와 콜백 주소를 입력합니다. 웹사이트와 콜백 주소는 Studio 출처와 다른 동일한 HTTPS 출처를 사용해야 합니다. 설정에 애플리케이션 비밀 키를 입력하지 마십시오. 타사 페이지는 또한 컴포넌트 메시지 프로토콜을 구현해야 하며, URL만 입력한다고 OAuth 연동이 자동으로 완료되지는 않습니다.
컴포넌트는 `profile:read credentials:read`를 요청하며, `offline_access`는 포함하지 않습니다. 로그인한 방문자가 동의한 후, 제3자는 일회성 인가 코드를 받고 자신의 PKCE verifier를 사용하여 OAuth token으로 교환한 다음, `https://platform.acedata.cloud/api/v1/credentials/?user_id=<UserInfo반환된id>&limit=100`를 통해 `items[*].token`을 읽습니다. 로그인하지 않았거나 인가를 거부한 경우에는 Key가 제공되지 않습니다.

전체 설명, 실행 가능한 표준 리디렉션 예제, scope 디렉터리 및 오류 처리는 [OAuth 연동 가이드](https://docs.acedata.cloud/zh-Hans/guides/oauth)를 참조하십시오. Studio 세션을 사용하는 애플리케이션은 추가로 [컴포넌트 메시지 예제](https://github.com/AceDataCloud/Nexior/blob/main/docs/integrations/studio-home-oauth.md)를 참조하십시오.

Key 읽기가 허용된 후, 제3자는 이를 저장하고 사용할 수 있습니다. 현재 OAuth 철회 엔드포인트의 성공 응답은 JWT가 즉시 무효화됨을 의미하지 않으며, 이미 복사된 API Key도 무효화하지 않습니다. 사용자가 해당 Key를 별도로 철회하거나 교체해야 합니다.
