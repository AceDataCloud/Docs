페이지네이션을 통해 현재 사이트에서 보이는 API 엔드포인트를 반환합니다. 비즈니스 경로, 서비스 또는 배포 단계별로 API를 찾는 데 적합합니다. 하나의 API에 대한 전체 정의만 필요한 경우 직접 [API 상세](https://platform.acedata.cloud/documents/platform-api-detail)를 호출하세요.

## 인터페이스 개요

| 항목   | 내용                                            |
| --- | --------------------------------------------- |
| 메서드  | `GET`                                         |
| URL | `https://platform.acedata.cloud/api/v1/apis/` |
| 인증  | 공개, 계정 토큰 불필요                                     |
| 페이지네이션  | `count` + `items`                             |

## 쿼리 매개변수

| 매개변수        | 유형      | 필수  | 설명                    |
| --------- | ------- | --- | --------------------- |
| `path`    | string  | 아니요   | `path` 또는 `path2` 정확히 일치 |
| `service` | string  | 아니요   | 서비스 alias 또는 UUID       |
| `stage`   | string  | 아니요   | 배포 단계로 필터링; 여러 값을 반복 전달 가능      |
| `limit`   | integer | 아니요   | 페이지당 항목 수, 최대 100           |
| `offset`  | integer | 아니요   | 페이지네이션 오프셋                 |

`id`, `service_id`, `tag`는 현재 목록 필터 매개변수가 아닙니다. 전달해도 해당 필터 효과가 발생하지 않습니다.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/apis/' \
  --data-urlencode 'service=midjourney' \
  --data-urlencode 'stage=Production' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

```python
import requests

response = requests.get(
    "https://platform.acedata.cloud/api/v1/apis/",
    params={"service": "midjourney", "limit": 20},
    timeout=30,
)
response.raise_for_status()
for api in response.json()["items"]:
    print(api["id"], api["method"], api["path"])
```

## 응답 설명

온라인 응답은 `{count, items}`를 사용합니다. 각 목록 항목에는 현재 API 모델 필드와 다음이 포함됩니다.

- `document_id`: 연결된 개발자 문서 ID이며, 비어 있을 수 있습니다.
- `service_id` / `service`: 기본 서비스 ID 및 요약이며, 비어 있을 수 있습니다.
- `definition`: OpenAPI 정의이며, 클 수 있습니다.
- `method`, `path`, `path2`, `stage`, `cost`, `tags`, `metadata` 등.

목록 serializer에는 현재 `definition`이 포함되어 있으므로, 전체 카탈로그를 가져올 때는 페이지네이션을 적용하고 시간 제한을 설정해야 합니다. 필드는 하위 호환 방식으로 추가될 수 있으며, 클라이언트는 필요한 필드만 읽습니다.
