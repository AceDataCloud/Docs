[LobeChat](https://lobehub.com/)은 플러그인, 지식 베이스 및 자체 배포를 지원하는 오픈 소스 AI 클라이언트로, 온라인 버전을 사용하거나 Docker로 배포할 수 있습니다. 사용자 지정 OpenAI 호환 엔드포인트를 지원하므로 Ace Data Cloud에 연결할 수 있습니다. 이 문서에서는 구성 절차를 소개합니다.

## 신청 절차

LobeChat에서 Ace Data Cloud에 연결하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)로 이동하여 API Token을 가져와 예비용으로 보관하세요.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않은 경우, 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 로그인 및 가입 후 현재 페이지로 자동 반환됩니다.

최초 신청 시 무료 크레딧이 제공되므로 Ace Data Cloud의 모델 서비스를 무료로 체험할 수 있습니다.

## Ace Data Cloud 구성

LobeChat의 **애플리케이션 설정 → 언어 모델**로 이동하여 **OpenAI** 카드를 찾아 활성화한 후, 다음을 입력하세요:

| 필드       | 값                              | 설명                         |
| -------- | ------------------------------ | -------------------------- |
| API Key  | 당신의 Ace Data Cloud Token        | 콘솔에서 복사한 Token               |
| API 프록시 주소 | `https://api.acedata.cloud/v1` | **반드시 `/v1`로 끝나야 함**           |
| 클라이언트 요청 모드  | 활성화                             | 브라우저 직접 연결, Key가 LobeChat 서버를 거치지 않음 |

![LobeChat OpenAI Provider 구성 화면](https://cdn.acedata.cloud/629ef9d3084a.png)

> Chat Completions 인터페이스를 사용할 때는 Responses API Specification을 비활성화한 상태로 유지하세요.

LobeChat은 Base URL에 `/v1`을 자동으로 추가하지 않으며, 요청 경로는 직접 `{API 프록시 주소}/chat/completions`입니다:

| API 프록시 주소                              | 실제 요청                                                   | 결과                       |
| ------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `https://api.acedata.cloud/v1`        | `https://api.acedata.cloud/v1/chat/completions`        | 올바름                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/chat/completions`    | 사용 가능                      |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/chat/completions` | 404（`/openai` 아래에 `/v1` 없음） |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/chat/completions`           | 404（`/v1` 누락）             |

LobeChat은 기본적으로 `/v1/models`를 호출하여 모델을 자동으로 가져옵니다. Ace Data Cloud가 반환하는 모델이 많으면 화면이 매우 길어질 수 있으므로, 「모델 목록 → 사용자 지정 모델 이름」에서 영어 쉼표로 구분된 allow list를 수동으로 입력하는 것을 권장합니다. 사용자 지정 표시 이름이 필요한 경우 `=`를 사용할 수 있으며, 형식은 `MODEL_ID=표시 이름`입니다.

## 모델 선택

모델 카탈로그는 계속 업데이트됩니다. 클라이언트가 자동으로 로드한 모델 목록을 우선 사용하세요. 수동으로 입력해야 하는 경우 먼저 `GET https://api.acedata.cloud/v1/models`를 요청하여 현재 모델 ID를 가져온 후, 클라이언트가 지원하는 컨텍스트, 이미지 및 도구 호출 기능에 따라 선택하세요.

## 연결 검증

문제가 LobeChat에 있는지 네트워크에 있는지 확실하지 않다면, 먼저 curl로 엔드포인트를 직접 검증할 수 있습니다（`{token}`을 당신의 Token으로 교체하세요）:

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

OpenAI 호환 `chat.completion` 객체가 반환되면 Token과 엔드포인트가 모두 준비되었음을 의미합니다. `HTTP 403 used_up`이 반환되면 Token은 유효하지만 잔액이 부족한 것이므로 [콘솔](https://platform.acedata.cloud/console/applications)에서 충전하면 됩니다.

## 고급: Docker 자체 배포

팀에서 사용할 개인 버전을 배포하려면 Docker 한 줄 명령으로 시작할 수 있습니다（`{token}`을 당신의 Token으로 교체하세요）:

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_KEY={token} \
  -e OPENAI_PROXY_URL=https://api.acedata.cloud/v1 \
  -e ACCESS_CODE=your-secret-password \
  -e OPENAI_MODEL_LIST="MODEL_ID" \
  lobehub/lobe-chat:latest
```

`http://당신의 서버IP:3210`을 열고 `ACCESS_CODE`를 입력하면 사용할 수 있으며, 팀 구성원은 각자 Key를 입력할 필요가 없습니다. 위에서 사용한 `OPENAI_API_KEY`, `OPENAI_PROXY_URL`, `OPENAI_MODEL_LIST` 등의 환경 변수에 대한 전체 설명은 [LobeChat 모델 제공업체 환경 변수 문서](https://lobehub.com/docs/self-hosting/environment-variables/model-provider)를 참조하세요. nginx 리버스 프록시로 HTTPS를 추가하는 경우 반드시 `proxy_buffering off;`를 추가하세요. 그렇지 않으면 스트리밍 응답이 버퍼링됩니다. 더 많은 배포 형태는 [LobeChat 자체 배포 시작하기](https://lobehub.com/docs/self-hosting/start) 및 [Docker Compose 배포](https://lobehub.com/docs/self-hosting/platform/docker-compose)를 참조하세요.

## 자주 묻는 질문

### 404 Not Found가 표시됨

일반적으로 API 프록시 주소를 `.../openai/v1`로 작성했거나 `/v1`을 누락한 경우입니다. `https://api.acedata.cloud/v1`로 변경하세요.

### 모델 목록이 비어 있음

「클라이언트 요청 모드」 스위치를 켜거나, 「사용자 지정 모델 이름」에서 모델 allow list를 수동으로 입력하세요.

### 401 Unauthorized가 표시됨

API Key에 Ace Data Cloud의 Token이 붙여넣어졌는지（`Bearer` 접두사 없이, 불필요한 공백 없이）와 해당 애플리케이션의 잔액이 충분한지 확인하세요.
