OpenCode의 Coding Plan 모델 Provider, IDE Extension 및 MCP는 세 가지 독립적인 기능입니다. IDE Extension은 로컬 OpenCode 런타임에 연결하고 동일한 Provider 구성을 재사용합니다. 이는 호스트 편집기가 Ace Data Cloud를 원래 지원한다는 것을 의미하지 않습니다.

| 경로                            | 설명                                                      | 링크                                                                                    | 상태      |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------- |
| Terminal / CLI / TUI Provider | `opencode.json[c]` 및 Chat Completions 사용                | [Provider 구성](https://platform.acedata.cloud/documents/opencode-terminal-integration) | 검증된 구성 계약 |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium 등 호스트가 OpenCode 런타임에 연결 | [IDE 구성](https://platform.acedata.cloud/documents/opencode-ide-integration)           | 실험적     |
| MCP                           | OpenCode 내에서 원격 도구 호출                                      | [MCP 개요](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | 독립 기능    |

Provider 구성이 성공적으로 완료된 후, IDE Extension은 동일한 Provider와 모델을 사용해야 합니다. IDE 내의 채팅, 파일 읽기, 편집 및 도구 호출은 별도로 검증해야 하며, CLI의 일반 요청을 모든 IDE 기능으로 자동으로 외삽해서는 안 됩니다.

모델 ID는 [실시간 디렉토리](https://platform.acedata.cloud/models)를 기준으로 합니다.
