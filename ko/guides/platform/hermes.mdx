Hermes Agent는 OpenAI Chat Completions 프로토콜을 통해 Ace Data Cloud에 접속합니다. 다음 중 하나의 구성 방식을 선택하세요:

| 구성 방식                | 가이드                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| `hermes model` 상호작용 안내 | [안내 구성](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| `config.yaml` 수동 구성  | [수동 구성](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| 플랫폼 개인 배포              | [호스팅 배포](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

로컬 접속의 공통 매개변수:

- Base URL：`https://api.acedata.cloud/v1`
- Transport：`chat_completions`
- Provider：`custom:acedatacloud`
- API Key： [애플리케이션 목록](https://platform.acedata.cloud/console/applications)에서 가져오기

두 가지 로컬 방식은 최종적으로 `~/.hermes/config.yaml`에 기록되며, 중복 구성을 피하세요.

[Coding Plan 구성 센터](https://platform.acedata.cloud/documents/coding-plan-integration)로 돌아가기.
