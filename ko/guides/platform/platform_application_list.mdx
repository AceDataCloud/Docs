계정이 소유하거나 권한을 부여받아 사용할 수 있는 Application을 페이지별로 반환하며, 잔액, 상태, 서비스 요약 및 연결된 자격 증명을 포함합니다. 일괄 잔액 모니터링, Application ID 찾기 및 자격 증명 관리 진입에 적합합니다.

## 준비 작업

1. [AceDataCloud 플랫폼](https://platform.acedata.cloud)에 로그인합니다.
2. [Account Token 콘솔](https://platform.acedata.cloud/console/platform-tokens)에서 계정 토큰을 생성합니다.
3. 일반 사용자는 `user_id=me`를 사용합니다. 또는 `GET /api/v1/platform-tokens/me/`에서 자신의 UUID를 가져올 수도 있습니다.

```shell
export PLATFORM_TOKEN='你的账户令牌'
```

## 인터페이스 개요

| 항목   | 내용                                                    |
| --- | ----------------------------------------------------- |
| 메서드  | `GET`                                                 |
| URL | `https://platform.acedata.cloud/api/v1/applications/` |
| 인증  | Account Token, OAuth token에는 `applications:read` 필요       |
| 페이지네이션  | `count` + `items`                                     |

일반 사용자는 `user_id=me`를 전달해야 합니다. 전달하지 않으면 쿼리가 먼저 계정 기준으로 좁혀지지 않아, 페이지네이션 중 권한이 없는 객체를 만나면 `403`이 반환될 수 있습니다. 관리자는 전달하지 않아도 전체 테이블을 볼 수 있습니다.

## 쿼리 파라미터

| 파라미터            | 유형          | 필수     | 설명                                                  |
| ------------- | ----------- | ------ | --------------------------------------------------- |
| `user_id`     | UUID / `me` | 일반 사용자 필수 | 쿼리 주체; 반복 파라미터 지원                                         |
| `affiliation` | string      | 아니요      | `owner`(기본값) 또는 `granted`; 둘 다 반복 전달하여 합집합을 취할 수 있으며, `user_id`가 있을 때만 적용 |
| `service_id`  | UUID        | 아니요      | 서비스로 필터링; 반복 파라미터 지원                                        |
| `scope`       | string      | 아니요      | `Individual` 또는 `Global`; 반복 파라미터 지원                      |
| `type`        | string      | 아니요      | `Usage` 또는 `Period`; 반복 파라미터 지원                           |
| `limit`       | integer     | 아니요      | 페이지당 항목 수, 최대 100                                         |
| `offset`      | integer     | 아니요      | 페이지네이션 오프셋                                               |
| `ordering`    | string      | 아니요      | `created_at` 또는 `-created_at`만 지원                    |

`paid`, `disabled`, `expired`, `low_balance` 및 `tag`는 현재 서버 측 필터링 파라미터가 아닙니다. 잔액 알림은 목록을 가져온 후 각 Application의 `remaining_amount`, `service.unit` 및 비즈니스 임계값에 따라 클라이언트에서 판단해야 합니다.

## 요청 예시

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

자신이 소유한 Application과 다른 사람이 자신에게 권한을 부여한 Application을 동시에 확인합니다.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/applications/' \
  --data-urlencode 'user_id=me' \
  --data-urlencode 'affiliation=owner' \
  --data-urlencode 'affiliation=granted' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## 응답 설명

응답은 `{count, items}`입니다. 각 항목은 Application 모델 필드를 포함하며, 다음이 추가됩니다.

- `service`: `id`, `alias`, `title`, `type`, `unit`, `icon_url`;
- `credentials`: 현재 호출자가 볼 권한이 있는 자격 증명 요약;
- `paid`, `remaining_amount`, `used_amount`, `disabled`, `allow_consume_global`;
- `scope`의 실제 값은 `Individual` 또는 `Global`;
- `type`의 실제 값은 `Usage` 또는 `Period`.

`remaining_amount`는 비어 있을 수 있습니다. 클라이언트는 반드시 먼저 빈 값 여부를 확인한 후 숫자를 비교해야 합니다. 할당량 단위는 `service.unit`으로 결정됩니다.
