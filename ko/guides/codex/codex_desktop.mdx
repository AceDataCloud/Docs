Codex Desktop은 Codex CLI와 `~/.codex/config.toml`을 공유합니다.

## 1. API Key 가져오기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. API Key 설정

macOS:

```bash
launchctl setenv ACEDATACLOUD_API_KEY "당신의 API Key"
```

Windows PowerShell:

```powershell
setx ACEDATACLOUD_API_KEY "당신의 API Key"
```

## 3. AceDataCloud 구성

`~/.codex/config.toml`(Windows는 `%USERPROFILE%\.codex\config.toml`)을 편집하고 다음을 추가합니다:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows에서는 마지막 두 줄을 다음과 같이 변경합니다:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model`을 입력할 필요는 없습니다; Codex를 열고 모델을 직접 선택합니다.

## 4. 재시작 및 검증

Codex Desktop을 완전히 종료한 후 다시 열고, 로컬 작업을 새로 만들고 간단한 메시지를 보냅니다. Provider는 `acedatacloud`로 표시되어야 하며, 실제 호출은 [사용 기록](https://platform.acedata.cloud/console/usages)에서 확인할 수 있습니다.

구성이 적용되지 않았다면, 현재 사용자의 `~/.codex/config.toml`을 수정했는지, 환경 변수가 설정되었는지 확인한 후 애플리케이션을 다시 완전히 재시작합니다. 클라우드 작업이나 자동화가 다른 환경에서 실행될 때는 해당 환경에 맞게 Key를 별도로 구성해야 합니다.
