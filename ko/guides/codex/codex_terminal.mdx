## 1. API Key 얻기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 얻기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Codex 설치

```bash
npm install -g @openai/codex
```

## 3. API Key 설정

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="당신의 API Key"
```

장기적으로 유효하게 하려면 이 줄을 `~/.zshrc` 또는 `~/.bashrc`에 추가합니다. Windows PowerShell에서는 다음을 사용합니다:

```powershell
setx ACEDATACLOUD_API_KEY "당신의 API Key"
```

설정 후 터미널을 다시 엽니다.

## 4. AceDataCloud 구성

`~/.codex/config.toml`(Windows는 `%USERPROFILE%\.codex\config.toml`)을 편집하고 다음을 추가합니다:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows에서는 마지막 두 줄을 다음으로 변경합니다:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model`을 입력할 필요는 없습니다; 시작 후 Codex에서 모델을 선택할 수 있습니다. 이미 다른 구성이 있는 경우 유지하고 동일한 이름의 provider를 중복 생성하지 마십시오.

## 5. 시작

```bash
cd /path/to/your/project
codex
```

Codex에 들어간 후 `/model`을 실행하여 Provider가 `acedatacloud`인지 확인하고 필요한 모델을 선택합니다. 호출 기록과 잔액은 [사용 내역](https://platform.acedata.cloud/console/usages) 및 [애플리케이션 목록](https://platform.acedata.cloud/console/applications)에서 확인할 수 있습니다.

Key가 없거나 401이 반환되면 환경 변수가 설정되었는지 확인하고 완전히 종료한 후 터미널과 Codex를 다시 엽니다.
