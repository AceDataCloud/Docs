title: "Codex 구성 튜토리얼"
description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI는 OpenAI에서 출시한 오픈소스 로컬 프로그래밍 에이전트로, 터미널에서 코드를 읽고, 파일을 수정하며, 명령을 실행하고 개발 작업을 지원할 수 있습니다. Ace Data Cloud 프록시를 통해 별도의 OpenAI 공식 계정 구독 없이도 더 저렴한 가격으로 Codex CLI를 사용할 수 있습니다.

사용 시나리오에 맞는 전체 구성 튜토리얼을 선택하세요:

| 플랫폼 | 설명 | 튜토리얼 링크 |
|------|------|---------|
| **VS Code** | 공식 확장, 에디터 사이드바에서 채팅, 파일 참조, diff 미리보기 | [VS Code 구성 튜토리얼](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **터미널 (CLI)** | 핵심 경험, 어떤 터미널에서든 `codex` 명령어로 시작 가능 | [터미널 구성 튜토리얼](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **팁**: 처음 신청 시 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API 토큰을 받아 무료 할당량을 즉시 이용할 수 있습니다. Codex CLI는 Ace Data Cloud의 OpenAI Responses 호환 인터페이스(`/v1/responses`)를 통해 작동하며, 더 많은 모델 및 요금 정보는 [OpenAI 서비스 페이지](https://platform.acedata.cloud/documents/openai)를 참고하세요.
