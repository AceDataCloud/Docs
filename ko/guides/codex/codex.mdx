title: "Codex 구성 가이드"
description: "Codex API guide - Ace Data Cloud"
---

Codex CLI, Desktop 및 VS Code 확장은 `~/.codex/config.toml`을 공유합니다. `acedatacloud` 공급자를 한 번 구성하면 Ace Data Cloud를 통해 Codex를 사용할 수 있습니다.

| 사용 방식           | 구성 가이드                                                                                    |
| -------------- | --------------------------------------------------------------------------------------- |
| 터미널 / CLI | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)        |
| 데스크탑        | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)     |
| VS Code        | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)  |
| 그래픽 전환          | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

공통 구성 항목은 세 가지입니다:

- 공급자: `acedatacloud`
- 기본 URL: `https://api.acedata.cloud/v1`
- API 키: [애플리케이션 목록](https://platform.acedata.cloud/console/applications)에서 가져와 `ACEDATACLOUD_API_KEY`에 저장합니다.

접속 구성에서 모델을 고정할 필요가 없습니다; Codex를 시작한 후 직접 모델을 선택할 수 있습니다.

[코딩 계획 구성 센터](https://platform.acedata.cloud/documents/coding-plan-integration)로 돌아갑니다.
