CC Switch는 그래픽 인터페이스를 통해 Codex의 provider와 API Key를 관리할 수 있습니다.

## 1. API Key 가져오기

[에이스 데이터 클라우드 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![에이스 데이터 클라우드 API Key 가져오기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. CC Switch 설치

[CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest)에서 다운로드하여 설치하거나 macOS에서 다음을 실행합니다:

```bash
brew install --cask cc-switch
```

## 3. provider 추가

1. CC Switch를 열고 **Codex**로 전환합니다.
2. **Add Provider**를 클릭하고 **Custom**을 선택합니다.
3. 다음을 입력합니다:

| 필드       | 내용                             |
| -------- | ------------------------------ |
| Name     | `acedatacloud`                 |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | 방금 복사한 에이스 데이터 클라우드 API Key   |

CC Switch가 사용자 정의 구성 편집기를 제공하는 경우, 구성은 다음과 같아야 합니다:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch는 API Key를 `~/.codex/auth.json`에 저장합니다:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

위의 provider에 `env_key` 또는 `[model_providers.acedatacloud.auth]`를 추가하지 마십시오; 수동 구성과 CC Switch 구성 중 하나만 선택하십시오. `model`을 고정할 필요 없이 Codex에서 직접 선택할 수 있습니다.

## 4. 활성화 및 검증

`acedatacloud` provider를 활성화하고 Codex 또는 VS Code를 완전히 종료한 후 다시 시작합니다. `/model`을 실행하여 Provider가 `acedatacloud`인지 확인한 후 모델을 선택하고 간단한 메시지를 보냅니다.

401이 반환되면 현재 활성화된 것이 `acedatacloud`인지 확인하고 `~/.codex/auth.json`의 `OPENAI_API_KEY`가 방금 복사한 에이스 데이터 클라우드 API Key인지 확인합니다. 호출 기록은 [사용 이력](https://platform.acedata.cloud/console/usages)에서 확인할 수 있습니다.
