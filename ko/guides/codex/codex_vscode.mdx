Codex VS Code 확장과 Codex CLI는 `~/.codex/config.toml`을 공유합니다.

## 1. API Key 받기

[Ace Data Cloud 애플리케이션 목록](https://platform.acedata.cloud/console/applications)을 열고 사용 가능한 애플리케이션에 들어가 API Key를 복사합니다.

![Ace Data Cloud API Key 받기](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 확장 설치

VS Code 확장 마켓에서 OpenAI가 배포한 **Codex – OpenAI의 코딩 에이전트**를 설치하거나 다음을 실행합니다:

```bash
code --install-extension openai.chatgpt
```

## 3. API Key 설정

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="당신의 API Key"
```

장기적으로 유효하게 하려면 이 줄을 `~/.zshrc` 또는 `~/.bashrc`에 추가합니다. Windows PowerShell에서는 다음을 사용합니다:

```powershell
setx ACEDATACLOUD_API_KEY "당신의 API Key"
```

## 4. AceDataCloud 구성

`~/.codex/config.toml`(Windows는 `%USERPROFILE%\.codex\config.toml`)을 편집하고 다음을 추가합니다:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows에서는 마지막 두 줄을 다음으로 변경합니다:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

`model`을 입력할 필요는 없습니다; Codex 패널에서 모델을 선택할 수 있습니다.

## 5. 재시작 및 검증

VS Code를 완전히 종료한 후 다시 열고 Codex 패널을 엽니다. `/model`을 실행하여 Provider가 `acedatacloud`인지 확인한 후 간단한 메시지를 전송합니다; 호출 기록은 [사용 이력](https://platform.acedata.cloud/console/usages)에서 확인할 수 있습니다.

확장이 Key를 읽지 못하는 경우, 설정된 환경 변수가 있는 터미널에서 VS Code를 시작하거나 시스템 수준의 환경 변수를 설정한 후 VS Code를 재시작하십시오. Remote SSH, WSL 및 Dev Container는 실제로 확장을 실행하는 환경에서 각각 구성해야 합니다.
