title: "Tripo 캐릭터 애니메이션"
description: "Tripo 3D API guide - Ace Data Cloud"
---

`POST /tripo/animations`를 호출하고, `action`으로 골격 검사, 자동 리깅 또는 애니메이션 리타기팅을 선택합니다. `async: true`를 전달하면 `/tripo/tasks`를 폴링할 수 있고, `callback_url`을 전달하면 최종 결과를 받습니다.

1. **검사**. `{"action":"rig_check","model_id":"5db97adc-a877-4587-af16-bbf443aa55de"}`를 전송합니다. 결과 항목에는 불리언 값 `riggable`과 선택 사항인 `rig_type`이 포함됩니다. 검사가 성공했고 `riggable: false`이면 해당 모델이 리깅에 적합하지 않음을 의미합니다. 이 작업은 무료입니다.
2. **리깅**. `{"action":"rig","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","model":"v3.0-20260909","rig_type":"biped","format":"GLB"}`를 전송합니다. 결과는 골격이 포함된 새 모델이며, 해당 `data[0].id`를 보관합니다. 검사와 리깅은 `model_url`을 통해 기존 파일을 읽을 수도 있습니다.
3. **리타기팅**. 리깅 결과의 ID를 `model_id`로 사용합니다. 예를 들어 `{"action":"retarget","model_id":"96a66a1d-69d2-48f0-846b-bdf02ed9bcc4","animations":["preset:walk","preset:idle"],"format":"GLB","async":true}`입니다. 골격 버전 및 유형과 호환되는 프리셋을 선택합니다. 단일 요청에는 `animation`을, 일괄 요청에는 `animations`를 전달하며, 최대 다섯 개까지 가능하고 동작 수에 따라 요금이 부과됩니다. 일괄 요청은 여러 애니메이션 트랙이 포함된 파일 하나를 제공할 수 있습니다.

리깅과 리타기팅 모두 GLB, FBX를 지원합니다. `export_with_geometry`를 사용해 리타기팅 결과에 지오메트리를 포함할지 제어하고, `animate_in_place`로 변위를 유지할지 제어합니다. 모델 파일의 다운로드 주소는 `data[0].model_url`에 있습니다.
