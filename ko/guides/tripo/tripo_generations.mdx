`POST /tripo/generations`를 호출하여 새 모델을 만들고, 텍스트, 단일 이미지 또는 동일한 물체의 여러 시점을 전달합니다. AceDataCloud Token을 사용하며, 기본적으로 결과가 동기식으로 반환됩니다. `async: true` 또는 `callback_url`을 전달하면 먼저 HTTP 200과 `task_id`가 반환됩니다. 완료 콜백과 동기식 결과는 동일한 JSON 구조를 가집니다.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action`의 기본값은 `generate`입니다. 입력은 `prompt`(1–1024자), `image_url`, `image_urls` 중 하나를 선택합니다. 이미지는 최대 20 MiB의 공개 HTTPS PNG/JPEG입니다. 다중 시점은 정면, 왼쪽, 뒷면, 오른쪽 순서로 배열하며, 정면과 최소 한 개의 다른 면을 제공해야 하고, null을 사용하여 중간 시점을 건너뛸 수 있습니다.

`model`의 기본값은 `v3.1-20260211`이며, `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` 또는 `P2-20260801`을 명시적으로 선택할 수도 있습니다. `texture`의 기본값은 `standard`이며, 순수 지오메트리에는 `none`을 사용합니다. 모델과 텍스처 단계에 따라 서로 다른 할당량이 사용됩니다.

`data[0].model_url`에서 GLB를 다운로드하며, `image_url`은 선택적 미리보기입니다. 이후 텍스처, 변환 또는 뼈대 작업에 사용할 수 있도록 `data[0].id`를 보관합니다. 동일한 제출을 재시도할 때는 동일한 `Idempotency-Key`와 요청 본문을 유지합니다.
