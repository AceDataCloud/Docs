`POST /tripo/models`를 사용해 기존 모델을 처리하고, 필요한 `action`을 전달합니다. 동기, 비동기, 콜백, 계정 소유권 및 작업 조회는 3D 생성과 동일합니다.

| action  | 입력                                                                | 결과                                                                   |
| ------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| import  | `model_url`, 공개 HTTPS의 GLB, GLTF, FBX, OBJ 또는 STL 파일, 최대 150 MiB       | 계속 참조할 수 있는 모델 ID와 GLB; 데이터가 있으면 `normalize_scale`과 `normalize_translation` 반환 |
| texture | `model_id` 또는 `model_url`; 선택적으로 `prompt`, `image_url`, `image_urls` 중 하나 | 새 모델, 텍스처 및 선택적 미리보기                                                          |
| convert | `model_id` 또는 `model_url` 및 대상 `format`                            | 변환된 모델 파일                                                             |

```json
{"action":"texture","model_id":"5db97adc-a877-4587-af16-bbf443aa55de","prompt":"蓝色哑光表面","texture_quality":"standard","async":true}
```

텍스처 품질은 `fast`, `standard`, `detailed`, `extreme`을 지원합니다. 텍스트 프롬프트를 사용할 때 `style_image_url`을 추가할 수 있습니다. 이미지 및 다중 시점 참조는 생성 인터페이스의 형식을 따릅니다. 더 많은 텍스처 매개변수는 OpenAPI를 참조하세요.

변환은 `GLTF`, `FBX`, `USDZ`, `OBJ`, `STL` 및 `3MF`를 지원합니다. 반환 항목의 `format`은 실제 제공 형식을 나타냅니다. 예를 들어 GLTF를 요청하면 바이너리 GLB가 제공될 수 있습니다. OBJ는 머티리얼과 텍스처 맵을 ZIP으로 패키징합니다. FBX를 요청할 때 `texture_packaging: "zip"`을 설정하면 분리된 텍스처 맵을 받을 수 있으며, 패키징 결과에는 `container: "ZIP"`이 명시됩니다. 기본값이 아닌 메시 또는 텍스처 설정을 활성화하면 고급 변환 요금이 적용될 수 있습니다. 자세한 내용은 서비스 가격을 참조하세요.

`data[0].id`를 사용해 이 계정의 모델을 참조하며, 가져온 정규화 변환은 `normalized = original × normalize_scale + normalize_translation`을 만족합니다. 모델 다운로드 주소는 `data[0].model_url`에 있습니다.
