---
title: "Tripo 모델 작업 조회"
description: "Tripo 3D API guide - Ace Data Cloud"
---

AceDataCloud Token으로 `POST /tripo/tasks`를 호출합니다. 조회는 무료이며, 생성할 때와 같은 계정을 사용합니다. 단건 조회에는 `id` 또는 `trace_id`를 사용하며, `action`의 기본값은 `retrieve`입니다.

```bash
curl -X POST https://api.acedata.cloud/tripo/tasks \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{\"action\":\"retrieve\",\"id\":\"${TASK_ID}\"}"
```

단건 조회 결과는 작업 기록이며, `id`, `type`, `trace_id`, 원래 요청 `request`, `started_at` 및 `progress`를 포함합니다. 처리 중에는 몇 초 간격으로 계속 조회할 수 있습니다. 완료 후 `response.success`를 확인합니다. 성공 시 `response.data[0].model_url`이 다운로드 주소이며, 실패 시 `response.error`에 오류 코드와 메시지가 포함됩니다. 타임스탬프, `finished_at` 및 소요 시간 `elapsed`는 작업 기록의 최상위에 있으며, 단위는 초입니다. `submission_unknown`이 발생하면 원래 작업 ID를 보관하여 대조합니다.

일괄 조회에는 `{"action":"retrieve_batch","ids":["&lt;작업 ID 1>","&lt;작업 ID 2>"]}`를 사용하며, `trace_ids`도 사용할 수 있습니다. 한 번에 최대 100개까지 조회할 수 있습니다. 응답은 `{"items":[...],"count":2}`이며, 입력 순서와 중복 항목을 유지합니다. 찾을 수 없거나 읽기 권한이 없는 작업은 단건 조회 시 `{}`가 반환되고, 일괄 조회 시 해당 위치가 `null`입니다.

작업 기록의 `type`은 `generations`, `models` 또는 `animations`입니다. 골격 검사에서는 `response.data[0].riggable`을 읽고, 파일 관련 작업에서는 `response.data[0].model_url`을 읽습니다.
