Grok Tasks API의 주요 기능은 Grok Videos Generation API에서 생성된 작업 ID를 입력하여 해당 작업의 실행 상태를 조회하는 것입니다.

본 문서에서는 Grok Tasks API 연동 방법을 상세히 설명하여 Grok Videos Generation API 작업 실행 상태를 쉽게 통합하고 조회할 수 있도록 도와드립니다.

## 신청 절차

Grok Tasks API를 사용하려면 먼저 신청 페이지 [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos)에서 해당 서비스를 신청하고, Grok Videos Generation API가 반환한 작업 ID를 복사해야 합니다.

그 다음 [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) 페이지로 이동하여 해당 서비스를 신청합니다. 페이지에 접속한 후, 「Acquire」 버튼을 클릭하면 됩니다.

아직 로그인하거나 회원가입하지 않은 경우 자동으로 [로그인 페이지](https://platform.acedata.cloud)로 이동하여 회원가입 및 로그인을 안내합니다. 로그인 및 회원가입 후에는 자동으로 현재 페이지로 돌아옵니다.

최초 신청 시 무료 할당량이 제공되어 해당 API를 무료로 사용할 수 있습니다.

## 요청 예시

Grok Tasks API는 Grok Videos Generation API의 결과를 조회하는 데 사용할 수 있습니다.

### 요청 헤더 및 요청 본문 설정

**Request Headers**는 다음과 같습니다:

- `accept`：JSON 형식의 응답 결과를 수신하도록 지정하며, 여기서는 `application/json`으로 설정합니다.
- `authorization`：API 호출을 위한 키로, 신청 후 드롭다운에서 직접 선택할 수 있습니다.

**Request Body**는 다음과 같습니다:

- `id`：조회할 작업 ID입니다.
- `action`：작업에 대한 조작 방식으로, 단일 조회 시 `retrieve`를 입력합니다.

### CURL 코드 예시

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### 응답 예시

요청이 성공하면 API는 해당 작업의 상세 정보를 반환합니다. 여기서 `request` 필드는 작업을 시작할 때의 request body이며, `response` 필드는 작업 완료 후 반환된 response body입니다. 예를 들어:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
        "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

필드 설명은 다음과 같습니다:

- `id`：생성된 작업의 ID로, 이번 생성 작업을 고유하게 식별합니다.
- `request`：조회한 작업의 요청 정보입니다.
- `response`：조회한 작업의 반환 정보입니다.

## 대량 조회 작업

여러 작업 ID에 대해 작업 상세 정보를 조회할 때는 `action`을 `retrieve_batch`로 설정하고, `ids`에 작업 ID 배열을 전달합니다.

**Request Body**는 다음과 같습니다:

- `ids`：조회할 작업 ID 배열입니다.
- `action`：작업에 대한 조작 방식으로, 대량 조회 시 `retrieve_batch`를 입력합니다.

```bash
curl -X POST 'https://api.acedata.cloud/grok/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
