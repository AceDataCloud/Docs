본 문서에서는 Grok Videos Generation API의 연동 방법을 설명합니다. 이 API는 텍스트 프롬프트, 이미지 입력, 선택적으로 참고 이미지를 통해 Grok Imagine(xAI) 비디오를 생성할 수 있습니다.

## 신청 절차

API를 사용하려면 먼저 [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos) 페이지에서 서비스를 신청해야 합니다. 페이지에 접속 후 「Acquire」 버튼을 클릭하면 아래와 같이 표시됩니다:

![](https://cdn.acedata.cloud/q6ytrc.png)

아직 로그인 또는 회원가입이 되어 있지 않다면 자동으로 로그인 페이지로 이동하며, 회원가입 후 로그인하면 현재 페이지로 돌아옵니다.

처음 신청 시 무료 할당량이 제공되어 무료로 API를 사용할 수 있습니다.

## 모델 설명

이 API는 두 가지 모델을 지원합니다:

- `grok-imagine-video` (기본값): 텍스트 기반 영상 생성(프롬프트만 전달) 및 이미지 기반 영상 생성( `image_url` 전달), 가격이 더 저렴합니다.
- `grok-imagine-video-1.5-preview`: 이미지 기반 영상 생성만 지원하며, **반드시** `image_url`을 전달해야 합니다.

## 기본 사용법

먼저 기본 사용 방식을 이해합니다. 프롬프트 `prompt`, 모델 `model` 등 파라미터를 입력하면 해당 영상이 생성됩니다.

요청 헤더에는 다음과 같이 설정됩니다:

- `accept`: 응답 결과의 포맷을 지정하며, 여기서는 `application/json` (JSON 형식)으로 설정
- `authorization`: API 호출을 위한 키, 신청 후 바로 선택 가능

또한 요청 바디에는 다음과 같은 내용이 포함됩니다:

- `prompt`: 생성할 영상 내용에 대한 텍스트 프롬프트. `grok-imagine-video` 사용 시 **필수**; `image_url` 전달 시 선택적
- `model`: 영상 생성에 사용할 모델, `grok-imagine-video` (기본값) 또는 `grok-imagine-video-1.5-preview`
- `image_url`: 이미지 기반 영상 입력 이미지 링크. `model`이 `grok-imagine-video-1.5-preview`인 경우 **반드시** 필요
- `reference_image_urls`: 참고 이미지 링크 배열, 영상의 스타일 또는 내용을 유도하는 용도
- `aspect_ratio`: 영상의 가로 세로 비율, `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3` 중 선택
- `resolution`: 출력 해상도, `480p` (기본값) 또는 `720p`. 해상도가 높을수록 사용량이 증가
- `duration`: 영상 길이(초), 1~15초 범위, 기본값 8초. 출력 시간에 따라 과금
- `callback_url`: 비동기 콜백 주소. 설정 시 API는 즉시 `task_id`를 반환하며, 작업 완료 시 결과를 POST로 전달

「Try」 버튼을 클릭하면 테스트 가능하며, 결과는 다음과 유사합니다:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/grok/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

반환 결과 필드 설명:

- `success`: 이번 영상 생성 요청 성공 여부
- `task_id`: 영상 생성 작업 ID
- `trace_id`: 요청 추적 ID, 문제 해결용
- `data`: 생성된 영상 결과 리스트
  - `id`: 영상 고유 ID
  - `video_url`: 영상 링크
  - `state`: 작업 상태 (`pending` / `succeeded` / `failed`)

`data` 내 `video_url` 링크를 통해 생성된 영상을 확인하면 됩니다.

아래는 CURL 예제입니다:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "resolution": "480p",
  "duration": 8
}'
```

파이썬 예제는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 이미지 기반 영상 생성

이미지 입력으로 영상을 생성하려면 `image_url`을 전달하며, `grok-imagine-video-1.5-preview` 모델 사용 시 반드시 필요합니다:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5-preview",
  "image_url": "https://cdn.acedata.cloud/grok/example-input.png",
  "resolution": "720p",
  "duration": 8
}
```

## 참고 이미지로 스타일 또는 내용 유도

참고 이미지를 활용하려면 `reference_image_urls`에 이미지 링크 배열을 전달합니다:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/grok/example-reference.png"
  ]
}
```

## 비동기 콜백

영상 생성은 일정 시간이 소요됩니다. 대기하지 않고 바로 결과를 받고 싶다면 `callback_url`을 전달하세요. 이 경우 API는 즉시 `task_id`를 반환하며, 작업 완료 후 결과를 POST로 전달합니다:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

즉시 반환 예시:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## 작업 결과 조회

비동기 콜백 또는 수동 조회를 원한다면 [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`)를 통해 `task_id`로 최신 상태와 결과를 조회할 수 있습니다.

## 과금 정책

이 서비스는 생성 영상의 「출력 초수」에 따라 과금됩니다. 단가 결정은 `model`과 `resolution`에 따라 다르며, 총액 = 단가 × `duration`(기본값 8초). `720p`가 `480p`보다 비싸며, `grok-imagine-video-1.5-preview`가 `grok-imagine-video`보다 비쌉니다. 구체적인 단가는 가격 페이지를 참고하세요.

## 오류 처리

요청에 문제가 있을 경우, API는 적절한 오류 코드와 메시지를 반환합니다. 일반적인 오류는 다음과 같습니다:

- `400`: 요청 파라미터 오류. 예를 들어 텍스트 영상에 `prompt` 누락, `grok-imagine-video-1.5-preview`에 `image_url` 누락, `duration`이 1~15 범위 벗어남
- `401`: 인증 실패. 토큰이 무효이거나 API와 일치하지 않음
- `403`: 잔액 부족 또는 검열 거부
- `429`: 요청 과다, 상위 서버의 요청 제한 초과. 잠시 후 재시도
- `500`: 서버 내부 오류 또는 상위 서버 생성 실패
