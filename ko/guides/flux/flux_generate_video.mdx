Flux Videos API는 `POST /flux/videos`를 사용하여 동영상 생성, 키프레임 이미지-동영상 생성, 동영상 이어붙이기 및 초안 향상을 완료합니다. `action=generate`(기본값), `mode`로 생성 모드를 선택하며, 결과 조회는 모두 기존의 `POST /flux/tasks`를 사용합니다.

> 현재 Beta입니다. 텍스트-동영상, 이미지-동영상, 동영상 이어붙이기 및 초안 향상이 공개되었습니다. HTTP 200 및 작업 ID는 작업 수락만을 의미하며, 최종 결과를 계속 조회해야 합니다.

## 1. API Token 가져오기

1. [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 등록 또는 로그인하고, 애플리케이션을 생성하여 API Token을 가져옵니다. 하나의 범용 API Token으로 플랫폼 서비스를 호출할 수 있습니다. 애플리케이션에 Flux 서비스 호출 권한과 사용 가능한 잔액이 있는지 확인하세요.
2. [Flux 서비스 페이지](https://platform.acedata.cloud/services/flux?tab=pricing)에서 요금제 및 각 작업의 가격을 확인합니다. 잔액이 부족한 경우 [콘솔 잔액 페이지](https://platform.acedata.cloud/console/coin)에서 충전하세요.
3. 요청에는 `Authorization: Bearer &lt;당신의 Token>`을 사용합니다. Token은 서버 측 환경 변수에 저장해야 하며, 프런트엔드 페이지, 공개 저장소, 스크린샷 또는 콜백 URL에 작성하지 마세요.

![콘솔에서 API Token 신청](https://cdn.acedata.cloud/dvc3cg.jpg)

이 문서의 코드는 모두 환경 변수를 읽습니다:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| 항목      | 값                                               |
| ------- | ----------------------------------------------- |
| API 루트 주소 | `https://api.acedata.cloud`                     |
| 동영상 작업 제출  | `POST /flux/videos`                             |
| 기존 작업 조회  | `POST /flux/tasks`                              |
| 인증      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| 요청 형식    | `Content-Type: application/json`                |

전체 필드 및 온라인 디버깅은 [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos)를, 작업 조회는 [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks)를 참조하세요.

## 2. 작업 및 입력 선택

| action                      | mode            | 입력                       | 결과            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate`（action 생략 시 기본값） | `t2v`           | `prompt`                 | 텍스트로부터 동영상 생성       |
| `generate`                  | `i2v`           | `prompt`、`keyframes`     | 하나 또는 여러 키프레임으로부터 동영상 생성 |
| `generate`                  | `v2v`           | `prompt`、`start_video`   | 입력 동영상을 기반으로 이어붙이기      |
| `generate`                  | `draft_enhance` | 자신이 완료한 초안의 `draft_task_id` | 해당 초안 향상         |

생성 모델은 `flux-3`이고, `action`은 `generate`(기본값)입니다. `mode`를 통해 텍스트-동영상, 이미지-동영상, 동영상 이어붙이기 또는 초안 향상을 선택합니다.

### 공통 생성 파라미터

| 파라미터                 | 설명                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | 필수; `t2v`, `i2v`, `v2v` 또는 `draft_enhance`                       |
| `prompt`           | 일반 생성 시 필수; 초안 향상에서는 원본 프롬프트를 덮어쓸 수 없음                                        |
| `duration`         | t2v/i2v는 5–20초 정수, v2v는 5–15초 정수 또는 `auto`; 최종 출력 길이는 요청값과 약간 다를 수 있음 |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; 일반 생성 기본값은 `hd`, 초안 향상 기본값은 `fhd`              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | 먼저 초안을 생성할지 여부; 초안은 `hd`만 지원                                           |
| `generate_audio`   | 동기화된 오디오를 생성할지 여부; `false`는 유효한 값이므로 명시적 불리언 값을 유지하세요                               |
| `safety_tolerance` | 선택 사항; 0–4의 정수                                                   |
| `async`            | `true`로 설정하는 것을 권장하며, 플랫폼 작업 ID를 즉시 반환한 뒤 결과를 폴링합니다                                |
| `callback_url`     | 선택 사항; 최종 JSON 결과를 수신할 HTTP(S) 주소; 설정 후에도 비동기로 수락됨                        |

소재 URL은 서비스에서 읽을 수 있어야 합니다. 임시 서명 URL을 사용하는 경우, 다운로드 및 처리를 위해 충분한 유효 기간을 확보해야 합니다. 웹페이지 주소를 이미지 또는 동영상 파일 주소로 사용하지 마세요.

## 3. 텍스트-동영상: 전체 실측 요청 및 결과

다음 요청은 2026-10-02 가격 조정 전에 프로덕션 인터페이스에서 성공적으로 실행되었습니다. `action`을 생략하여 기본 생성 동작을 검증했으며, `async=true`는 HTTP 연결의 장시간 대기를 방지합니다.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

수락 응답(실제 작업 ID):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

자신의 응답에 있는 `task_id`를 저장하고 계속 조회하세요. 문서 예시의 작업 ID를 사용하여 다른 계정의 결과를 조회하지 마세요.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

작업 조회에서 반환되는 `response` 필드에는 최종 비즈니스 결과가 포함됩니다. 다음은 이번 실측에서 성공한 `response`이며, 외부 작업 메타데이터는 생략되었습니다. 문서의 동영상 URL은 장기 예시 CDN의 동일 파일 복사본(SHA-256 일치)으로 교체되었으며, 실제 호출 시에는 이번 작업 고유의 결과 URL이 반환됩니다:
```json
{
  "success": true,
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607",
  "data": [
    {
      "id": "4341eb66-3845-4972-bb86-712a6cfae845",
      "model": "flux-3",
      "video_url": "https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4",
      "seconds": 5.041667,
      "width": 1280,
      "height": 704,
      "fps": 24,
      "draft_task_id": "4341eb66-3845-4972-bb86-712a6cfae845"
    }
  ],
  "usage": {
    "action": "generate",
    "seconds": 5.041667,
    "output_mp_seconds": 4.3326825781250005,
    "mode": "t2v",
    "resolution": "hd",
    "draft": true
  },
  "cost": {
    "amount": 2.6884689277500002,
    "currency": "credit",
    "list_amount": 2.9871876975000005
  }
}
```

[이번 실측 영상 보기](https://cdn.acedata.cloud/assets/examples/flux/4341eb66-3845-4972-bb86-712a6cfae845-5f4391e1942c.mp4)。미디어 검사 결과 출력은 1280×704, 24 fps, 5.041667초의 MP4이며, 파일 크기는 2,607,276바이트임이 확인되었습니다.

| 응답 필드                              | 용도                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | 최종 작업 성공 여부; 접수 단계에서 반환되는 task_id는 success=true와 동일하지 않음 |
| `task_id`                         | 플랫폼 작업 ID로, 폴링 및 비즈니스 멱등 처리에 사용                      |
| `trace_id`                        | 문제 조사 시 지원 담당자에게 제공                             |
| `data[].video_url`                | 읽을 수 있는 비디오 결과 주소                               |
| `data[].seconds/width/height/fps` | 서버 측에서 측정한 실제 출력 길이, 크기, 프레임률                       |
| `data[].draft_task_id`            | 초안 향상의 입력 ID; 재사용 가능한 초안을 반환할 때만 표시됨                  |
| `usage`                           | 최종 청구 사용량; 요청 duration으로 실제 seconds를 덮어쓰지 말 것      |
| `cost.amount`                     | 이번에 최종 차감된 Credits; `currency=credit`은 미국 달러가 아님   |
| `cost.list_amount`                | 애플리케이션 사용자 소비 할인 전의 Credits; 해당 시 반환                 |

이는 가격 조정 전의 과거 실측입니다: `list_amount=2.9871876975` Credits, 계정은 당시 10% 소비 할인을 누렸으며, 실제 `amount=2.68846892775` Credits였습니다. 2026-10-02 새 가격은 약 6.33% 인하되었습니다; 동일한 5.041667초 초안은 현재 가격 기준 2.798125185 Credits(소비 할인 전)이며, 여전히 10% 소비 할인을 누리는 경우 2.5183126665 Credits입니다. 과거 작업 청구서는 다시 계산되지 않습니다. 다른 계정의 요금제와 할인은 다를 수 있습니다; 이는 모든 사용자에게 고정된 미국 달러 가격이 아닙니다.

## 4. 이미지-비디오: 일반 및 시간 키프레임 포함

다음은 매개변수 예시이며, 소재 URL을 교체해야 하고, 이 예시가 이미 성공적으로 실행되었다는 선언이 아닙니다. 생성 완료 후 위의 절차에 따라 조회하면 결과 구조는 동일합니다.

한 장 또는 두 장의 이미지는 일반 배열을 사용합니다:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

키프레임 시각을 지정할 때는 `[초 수, 이미지 URL]` 쌍을 사용합니다:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

1–10개의 키프레임이 허용됩니다. 시간 포함 배열은 시간 오름차순이어야 하며, 시간은 0–20초이고, 일반 URL과 시간 포함 항목을 혼용할 수 없습니다. 일반 키프레임이 세 장 이상인 경우 반드시 duration을 명시적으로 지정해야 하며, auto를 사용할 수 없습니다.

### 이미지-비디오 실측 출력

이번 실측의 일치 입력은 다음과 같습니다(전체 base64는 설명 텍스트로만 대체되었으며, 나머지 필드는 실제 요청입니다):

```json
{
  "async": true,
  "action": "generate",
  "model": "flux-3",
  "prompt": "The toy sailboat drifts slowly across calm water. A steady camera, gentle daylight, no people or text.",
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "draft": false,
  "mode": "i2v",
  "keyframes": [
    "<下图 PNG 文件的原始 base64 字符串>"
  ]
}
```

## 5. 영상 이어붙이기

`start_video`에 기존 영상 파일 주소를 전달하고, `mode=v2v`로 설정하며, 길이는 최대 15초입니다.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "v2v",
  "prompt": "Continue the sailboat drifting forward with the same steady camera.",
  "start_video": "https://example.com/source.mp4",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

### 영상 이어붙이기 실측 출력

이번 전체 실측 입력은 다음과 같습니다. 초안 강화를 재현할 때는 자신의 초안 ID로 교체해야 합니다. 소재 URL은 동일 파일의 장기 예시 사본을 사용합니다.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "v2v",
  "start_video": "https://cdn.acedata.cloud/assets/examples/flux/b41293be-94c0-4dc7-9f39-ce04f0a8798d-c055a3079059.mp4",
  "prompt": "Continue the same sailboat drifting gently across calm water in the same continuous steady shot.",
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

다음은 2026-10-01 프로덕션 작업의 실제 최종 response(모의 응답 아님)이며, 영상 URL만 해시가 동일한 장기 예시 사본으로 교체되었습니다.

## 6. 먼저 초안, 그다음 강화

1. `draft=true`, `resolution=hd`로 초안을 생성하고 성공할 때까지 기다립니다.
2. 최종 `data[0].draft_task_id`에서 플랫폼 초안 ID를 가져옵니다.
3. 동일한 소속의 애플리케이션 자격 증명으로 강화 요청을 제출합니다.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

초안 강화에는 원본 내용을 덮어쓰기 위해 `prompt`, `duration`, `aspect_ratio`, `version`, `generate_audio`, `draft`, `keyframes`, `start_video`를 전달할 수 없습니다. 초안 캐시는 임시 리소스이므로 신속히 강화하십시오. 영구 보존 또는 고정 보존 일수는 보장되지 않습니다. 본인/현재 애플리케이션의 초안이 아닌 경우, 미완료 초안 및 만료된 캐시는 재사용할 수 없습니다. 초안과 강화는 두 번의 작업이며, 성공 후 각각 과금됩니다.

## 7. Python 엔드투엔드 호출

`requests`를 설치하고, 자신의 Token을 설정한 뒤, 아래 스크립트를 실행하면 “한 번 제출 → 폴링 → 영상 URL 출력”을 완료할 수 있습니다. 조회 및 네트워크 재시도에는 모두 원래 task_id를 사용하여 유료 작업이 중복 제출되는 것을 방지해야 합니다.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

네트워크 타임아웃 후, 알 수 없는 상태를 실패로 간주하고 즉시 다시 제출하지 마세요. 이미 task_id를 획득했다면, 해당 작업을 계속 조회하세요. 문제 해결을 위해 task_id와 trace_id를 기록하세요. 폴링 인터페이스 자체에는 생성 비용이 부과되지 않습니다.

## 8. 콜백 사용

제출 시 `callback_url`을 추가하면, 작업 완료 후 해당 주소로 최종 JSON 결과를 POST합니다. 성공 구조는 앞서 언급한 response와 일치하며, 실패 시 error를 포함합니다.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

콜백 주소는 공용 인터넷에서 접근 가능해야 합니다. 알림을 받은 후 task_id에 따라 멱등적으로 처리하고, 가능한 한 빨리 2xx를 반환하세요. 비즈니스 처리는 큐에 넣을 수 있습니다. 본문은 콜백에 서명 인증이 있다고 명시하지 않습니다. 비즈니스 혜택 발급 등 민감한 작업 전에, 자체 Token을 사용하여 동일한 작업을 조회해 결과를 확인하세요. 콜백을 받지 못한 경우에도 계속 폴링할 수 있으며, 다시 생성하지 마세요.

## 9. 현재 과금 및 가격표

2026-10-02 업데이트: 이번 영상 인터페이스의 각 등급 단가가 약 6.33% 인하되었으며, 계량 방식, 요금제 및 소비 할인 규칙은 변경되지 않았습니다. 앞부분의 과거 실측 response에 있는 cost는 작업 완료 시점의 청구 금액이며, 현재 견적을 의미하지 않습니다.

영상 생성은 **실제 출력 초 수**를 기준으로 과금됩니다. 아래는 현재 계정 소비 할인이 적용되지 않은 Credits 단가이며, [Flux 가격 페이지](https://platform.acedata.cloud/services/flux?tab=pricing)의 규칙과 일치합니다.

| 작업/모드              | 해상도 | Credits 단가 |
| ------------------ | --- | ---------: |
| t2v / i2v 초안       | hd  |  0.555 / 초 |
| v2v 초안             | hd  |   1.11 / 초 |
| t2v / i2v / 해당 초안 향상 | hd  | 1.5725 / 초 |
| 동일                 | fhd | 2.6825 / 초 |
| 동일                 | qhd |    3.7 / 초 |
| 동일                 | uhd |    7.4 / 초 |
| v2v / 해당 초안 향상       | hd  | 3.7925 / 초 |
| 동일                 | fhd | 4.9025 / 초 |
| 동일                 | qhd | 6.0125 / 초 |
| 동일                 | uhd | 8.7875 / 초 |

미국 달러 환산: `실제 비용(USD) = cost.amount(Credits) × 요금제 price / 요금제 amount`। 충전 등급과 소비 할인은 실제 가격에 영향을 미치며, Credits를 직접 USD로 간주할 수 없습니다. 실패한 작업에는 생성 비용이 부과되지 않습니다. 최종 금액은 완료 결과와 콘솔 호출 기록을 기준으로 합니다.

## 10. 자주 묻는 질문 및 문제 해결

| 상황                       | 권장 사항                                                   |
| ------------------------ | ---------------------------------------------------- |
| 매개변수 오류(400)                | action=generate, mode, duration, 키프레임 형식을 확인하세요. 서로 다른 생성 모드의 필드를 혼용하지 마세요 |
| 인증 오류(401)                | Bearer Token, 애플리케이션 권한 및 자격 증명이 유효한지 확인하세요                          |
| 콘텐츠 검토 거부(403)              | 소재와 프롬프트를 조정하고, 동일한 내용으로 반복 제출하지 마세요                                    |
| 속도 제한(429)                  | 동시성을 낮추고, 백오프 재시도하세요                                            |
| service_unavailable(503) | 현재 작업을 사용할 수 없습니다. 이미 접수된 비동기 작업은 최종 response에서 해당 오류를 보고할 수 있습니다                |
| task_id는 반환되었지만 아직 영상이 없음        | response를 계속 조회하고, HTTP 200을 생성 완료로 간주하지 마세요                     |
| 초안을 재사용할 수 없음                   | 본인/현재 애플리케이션인지, 작업이 완료되었는지, 원래 요청이 draft=true였는지 확인하고, 임시 캐시가 여전히 유효한지 점검하세요          |

피드백 시 task_id, trace_id, 요청 시간 및 마스킹된 매개변수를 제공하고, API Token을 보내지 마세요. 더 많은 방법은 [Flux MCP 통합 가이드](https://platform.acedata.cloud/documents/flux-mcp)를 참조하세요.
