`POST /flux/videos`를 통해 작업을 제출하고, `action`으로 생성, 편집 또는 업스케일을 선택합니다. `action`을 생략하면 `generate`와 동일합니다. 기존 `POST /flux/tasks`를 사용하여 플랫폼 작업을 조회합니다. `async=true`와 `callback_url`을 지원하며, 완료 결과에는 플랫폼 비디오 링크와 서버에서 측정한 길이, 크기 및 프레임 레이트가 포함됩니다.

## 생성: action=generate

`mode=t2v/i2v/v2v/draft_enhance`를 지원합니다. 일반 생성은 5–20초 정수 또는 `auto`를 지원하며, 비디오 연장은 5–15초를 지원합니다. i2v는 1–10개의 키프레임을 제공할 수 있으며, 순서에 따른 `[초, 이미지]` 쌍을 지원합니다. 출력 해상도는 hd/fhd/qhd/uhd이며, 동기화 오디오를 지원합니다. 초안은 hd만 출력하고 플랫폼 `draft_task_id`를 반환합니다. 초안을 재사용하려면 동일한 소속이어야 하며 생성 캐시 유효 기간의 제한을 받습니다. 초안 재현은 원본 프롬프트와 소재를 덮어쓸 수 없습니다.

```json
{"action":"generate","model":"flux-3","mode":"t2v","prompt":"海边日落","duration":5,"resolution":"hd","async":true}
```

## 편집: action=edit

`video`와 `prompt`를 전달합니다. 편집은 실제 출력 초 수에 따라 과금되며, 생성의 `mode`, `duration` 등의 필드는 허용하지 않습니다.

```json
{"action":"edit","video":"https://example.com/video.mp4","prompt":"将场景改为蓝色调","async":true}
```

## 업스케일: action=upscale

`input_video`를 전달하고, 선택적으로 `upscale_factor`(1.5–3)와 `creativity`(0은 정확, 1은 창의적)를 사용할 수 있습니다. 실제 출력 MP·초에 따라 과금됩니다: `길이 × 너비 × 높이 / 1048576 × 프레임 레이트 / 24`, 1 MP = 1024×1024. 생성 파라미터는 허용하지 않습니다.

```json
{"action":"upscale","input_video":"https://example.com/video.mp4","upscale_factor":2,"creativity":0,"async":true}
```

각 작업은 현재 FLUX 기준 가격 계수를 적용하며, 실제 출력에 따라 과금됩니다. 실패한 작업에는 생성 비용이 청구되지 않으며, 동적 과금 작업의 최종 비용은 완료 결과에 따라 달라집니다. 서로 다른 작업은 각각의 파라미터만 허용하며, 알 수 없는 action은 파라미터 오류를 반환합니다.
