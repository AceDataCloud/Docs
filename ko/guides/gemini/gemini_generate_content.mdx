Google Gemini은 입력 프롬프트를 통해 몇 초 안에 유창하고 자연스러운 응답을 생성할 수 있는 매우 강력한 AI 대화 시스템입니다. 이 문서는 주로 Gemini Generate Content API의 사용 방법을 설명하며, 이는 Google 공식 네이티브 API 형식으로 `generateContent` 및 `streamGenerateContent` 두 엔드포인트를 지원합니다.

## Chat Completions API와의 차이점

Gemini Generate Content API는 OpenAI 호환 형식(`messages` 필드)이 아닌 Google 공식 네이티브 요청 형식(`contents` 필드)을 사용합니다. 이미 Google Gemini SDK를 사용하고 있거나 공식 API 형식에 익숙하다면, 요청 형식을 수정하지 않고 이 API를 직접 사용할 수 있습니다.

## 현재 지원 범위

인터페이스는 텍스트, 이미지, 비디오 및 오디오 입력(`inlineData` 또는 `fileData`), 사고 구성 및 사용자 정의 함수 선언을 허용합니다. 오디오 출력, 내장 도구 및 명시적 컨텍스트 캐싱 등의 네이티브 필드는 아직 통합된 가용성이 보장되지 않으므로, 구체적인 모델의 실제 반환을 기준으로 하십시오.

`fileData.fileUri`를 사용하여 오디오 등의 파일을 제출할 때는 파일이 HTTPS를 통해 직접 접근 가능하고 로그인 상태에 의존하지 않도록 하며, 서명 링크의 유효 기간이 전체 요청 처리 시간을 포괄하도록 하십시오. 비스트리밍 오디오 분석은 모델이 처리를 완료한 후에야 결과를 반환하므로 90초를 초과할 수 있습니다. 클라이언트는 파일 크기와 비즈니스 시나리오에 따라 충분히 긴 전체 타임아웃을 설정하여 서버가 여전히 처리 중일 때 연결이 끊어지는 것을 방지해야 합니다.

## 신청 절차

Gemini Generate Content API를 사용하기 전에 먼저 [Gemini Generate Content API](https://platform.acedata.cloud/documents/gemini-generate-content-api) 페이지에 접속하여 "획득" 버튼을 클릭해 요청에 필요한 자격 증명을 받으십시오.

아직 로그인하거나 등록하지 않은 경우 자동으로 로그인 페이지로 이동합니다. 최초 신청 시 무료 할당량이 제공됩니다.

## 기본 사용법

### Non-Streaming(비스트리밍)

`/v1beta/models/{model}:generateContent`로 POST 요청을 전송합니다:

> **팁**: `gemini-3.x` 시리즈 flash는 사고 모델로, 먼저 reasoning tokens를 소모합니다. `generationConfig.maxOutputTokens`를 512 이상으로 설정하십시오. 그렇지 않으면 빈 콘텐츠만 반환될 수 있습니다.

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "你好，请介绍一下你自己"
          }
        ]
      }
    ]
  }'
```

반환 결과 예시:

```json
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [{"text": "你好！很高兴与你交流。"}]
      },
      "finishReason": "MAX_TOKENS"
    }
  ],
  "usageMetadata": {
    "promptTokenCount": 6,
    "candidatesTokenCount": 19,
    "thoughtsTokenCount": 489,
    "totalTokenCount": 514
  },
  "usage": {
    "prompt_tokens": 6,
    "completion_tokens": 19,
    "total_tokens": 514,
    "thoughts_tokens": 489,
    "cost": {
      "amount": 0.008860916380159999,
      "currency": "credit",
      "list_amount": 0.009631430847999998
    }
  },
  "modelVersion": "gemini-3.5-flash",
  "model": "gemini-3.5-flash"
}
```

`usageMetadata`의 token 필드는 네이티브 Gemini 의미 체계에 따라 과금됩니다:

- `promptTokenCount`에는 `cachedContentTokenCount`가 포함되며, 캐시 적중 부분은 캐시 읽기 가격으로 계산되고 일반 입력으로 중복 계산되지 않습니다.
- `promptTokensDetails` 및 `cacheTokensDetails`는 `usage.prompt_tokens_details` 아래의 `text_tokens`, `image_tokens`, `video_tokens`, `audio_tokens` 및 해당 `cached_*` 상세 정보로 정규화됩니다. 이 값들은 각각 `prompt_tokens` 및 `cached_tokens`에 포함됩니다. 서로 다른 모달리티는 각자의 가격으로만 다시 계산되며 중복 과금되지 않습니다.
- `candidatesTokenCount`와 `thoughtsTokenCount`는 모두 출력 token 가격으로 계산됩니다.
- `toolUsePromptTokenCount`는 독립적인 도구 입력 token이며, 입력 token 가격으로 계산됩니다.

Ace Data Cloud는 정규화된 `usage` 객체를 추가로 반환하며, 모델 프로토콜 전반에서 이번 호출 비용은 통일적으로 `usage.cost`에서 읽습니다. `cost`는 선택적인 비용 미리보기입니다. 가격 미리보기를 일시적으로 사용할 수 없을 때에도 모델 응답은 정상적으로 반환되지만, 이 필드를 포함하지 않을 수 있습니다. 최종 청구서는 사용량 기록을 기준으로 합니다.

### Streaming(스트리밍)

`/v1beta/models/{model}:streamGenerateContent?alt=sse`로 POST 요청을 전송합니다:

```bash
curl -X POST "https://api.acedata.cloud/v1beta/models/gemini-2.5-flash:streamGenerateContent?alt=sse" \
  -H "Authorization: Bearer your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [
          {
            "text": "写一首关于春天的诗"
          }
        ]
      }
    ]
  }'
```

스트리밍 반환은 SSE(Server-Sent Events) 형식으로 콘텐츠를 점진적으로 반환합니다. 중간 이벤트는 일반적으로 증분 콘텐츠만 포함합니다. 권위 있는 사용량을 포함한 최종 상태 이벤트에는 `usageMetadata`와 정규화된 `usage`가 포함되며, 비용은 계속해서 `usage.cost`에 위치합니다:

```text
data: {"candidates":[{"content":{"parts":[{"text":"Hello!"}],"role":"model"},"index":0}],"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

data: {"candidates":[{"content":{"parts":[],"role":"model"},"finishReason":"STOP","index":0}],"usageMetadata":{"promptTokenCount":7,"candidatesTokenCount":89,"totalTokenCount":96},"usage":{"prompt_tokens":7,"completion_tokens":89,"total_tokens":96,"cost":{"amount":0.00026161075472,"currency":"credit","list_amount":0.000284359516}},"modelVersion":"gemini-3.1-flash-lite","model":"gemini-3.1-flash-lite"}

```

연결이 닫히면 스트림이 종료되었음을 의미합니다. 네이티브 Gemini 스트림은 `data: [DONE]`을 전송하지 않습니다. 최종 상태의 가격 미리보기를 일시적으로 사용할 수 없는 경우, `usage`는 여전히 token 사용량을 반환하지만 `cost`는 생략됩니다.

### 내부 사고 및 사고 요약

모델 내부 사고와 호출자에게 사고 요약을 반환하는 것은 두 가지 독립적인 설정입니다:

- `thinkingBudget` 또는 `thinkingLevel`은 모델 내부의 사고 예산 또는 깊이를 제어하며, 지원되는 필드와 값은 모델에 따라 다릅니다.
- `includeThoughts`는 사고 요약 반환 여부를 제어하며, 기본값은 `false`입니다. 이 필드를 생략하거나 `false`를 전달하면 일반 JSON 및 SSE 스트리밍 응답 모두 `thought: true`로 표시된 텍스트를 반환하지 않습니다. 명시적으로 불리언 값 `true`를 전달한 경우에만 이러한 텍스트가 유지됩니다.

요청에 `includeThoughts`가 설정되지 않은 경우, 인터페이스는 사고 구성 지원 생성 모델에 기본적으로 `false`를 전달하여 요청하지 않은 요약을 방지합니다. 고객이 명시적으로 전달한 값, 사고 예산 및 수준은 유지됩니다. 사고 구성을 지원하지 않는 것으로 알려진 `gemini-2.5-flash-image`에는 이 필드가 자동으로 추가되지 않으며, `countTokens` 요청에도 생성 구성이 추가되지 않습니다.

요약을 끄는 것은 내부 사고를 끄는 것과 같지 않으며, 내부 사고 토큰 감소를 보장하지도 않습니다. 응답에 여전히 요청되지 않은 사고 텍스트가 포함되어 있으면 일반 JSON 및 SSE 출력에서 추가로 필터링하여 정상 답변, 서명 및 실제 사용량을 유지합니다.

요약을 확인해야 하는 경우, 다음과 같이 명시적으로 활성화하세요. 모델이 사용 가능한 요약을 생성하지 않은 경우에는 활성화해도 사고 텍스트가 없을 수 있습니다:

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [{"text": "解释量子纠缠"}]
    }
  ],
  "generationConfig": {
    "thinkingConfig": {
      "includeThoughts": true
    }
  }
}
```

`thoughtSignature`는 이후 턴에 필요한 암호화된 상태이며, 사고 요약 텍스트가 아니고 `includeThoughts` 스위치의 제어도 받지 않습니다. 서명은 정상 답변, 함수 호출 또는 빈 텍스트 Part에 있을 수 있습니다. 사고 텍스트를 필터링할 때 서명 및 동일 Part의 다른 필드는 유지되므로, 응답에는 서명만 포함하고 텍스트가 비어 있는 Part가 여전히 있을 수 있습니다. 여러 턴의 기록을 수동으로 관리할 때는 이러한 Part의 순서와 서명 위치를 유지하고, 서명을 이동하거나 병합하지 마세요.

`usageMetadata` 및 `usage`는 계속 실제 사용량을 기록합니다. 요약을 숨겨도 `thoughtsTokenCount`가 0으로 초기화되지 않으며, 과금은 계속 실제 사용량 및 현재 가격 규칙에 따라 계산됩니다.

Google 공식 [사고 및 사고 요약 설명](https://firebase.google.com/docs/ai-logic/thinking) 및 [사고 서명 규칙](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/thinking/thought-signatures)을 참조하세요.

```json
}
```

## 안전 설정

`safetySettings`를 통해 콘텐츠 필터링을 제어할 수 있습니다:

```json
{
  "contents": [...],
  "safetySettings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_ONLY_HIGH"
    }
  ]
}
```

## 오류 처리

| HTTP 상태 코드 | 의미             |
| -------- | -------------- |
| 400      | 요청 매개변수가 유효하지 않음         |
| 401      | 인증 실패, Token을 확인하세요 |
| 403      | 콘텐츠가 보안 필터에 의해 차단됨     |
| 429      | 요청이 너무 빈번함         |
| 500      | 서버 내부 오류        |
