본 문서에서는 Gemini Videos Generation API의 연동 설명을 소개합니다. 이 API는 입력 텍스트 프롬프트(및 선택적 참조 이미지)를 통해 Google Gemini(omni-flash) 비디오를 생성할 수 있습니다.

## 신청 절차

Gemini Videos Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 받아야 하며, 이를 보관해 두십시오.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

로그인 또는 등록이 되어 있지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 요청합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## 기본 사용법

먼저 기본 사용 방법을 이해합니다. 입력 프롬프트 `prompt`, 모델 `model`, 그리고 가로 세로 비율 `aspect_ratio`를 입력하면 해당 비디오를 생성할 수 있습니다.

여기서 설정한 Request Headers는 다음과 같습니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지, 여기서는 `application/json`으로 JSON 형식으로 입력합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 드롭다운에서 직접 선택할 수 있습니다.

또한 Request Body를 설정합니다:

- `prompt`: 생성하고자 하는 비디오 내용에 대한 텍스트 프롬프트, **필수**입니다.
- `model`: 비디오를 생성할 모델로, 현재는 `omni-flash`만 지원하며 기본값은 `omni-flash`입니다.
- `aspect_ratio`: 생성할 비디오의 가로 세로 비율로, 선택적으로 `16:9`(가로) 또는 `9:16`(세로) 중 하나를 선택할 수 있으며 기본값은 `16:9`입니다.
- `resolution`: 선택 가능한 출력 해상도로, `720p` 또는 `1080p` 중 하나를 선택할 수 있으며 기본값은 `720p`입니다.
- `image_urls`: 비디오 생성을 안내하기 위한 선택적 참조 이미지 링크 배열로, 비어 있는 항목은 무시됩니다. `video_urls`를 사용하여 비디오 편집을 할 때는 이 매개변수가 필수입니다(최소 1장).
- `video_urls`: 선택적 참조 비디오 링크 배열(최대 1개)로, **비디오 편집 / 비디오 참조**에 사용됩니다; 제공할 경우 최소 1장의 `image_urls`도 함께 제공해야 합니다.
- `callback_url`: 비동기 콜백 주소로, 설정 후 API는 즉시 `task_id`를 반환하며, 작업이 완료되면 결과를 해당 주소로 POST합니다.
- `async`: 선택적이며, `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하고 `callback_url`을 제공할 필요가 없으며, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 가져올 수 있습니다.

"Try" 버튼을 클릭하여 테스트를 진행하면, 얻은 결과는 다음과 유사합니다:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": 1784112953.856,
  "finished_at": 1784113021.328,
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

반환 결과는 여러 필드를 포함하며, 설명은 다음과 같습니다:

- `success`: 이번 비디오 생성 요청이 성공했는지 여부.
- `task_id`: 이번 비디오 생성 작업의 ID.
- `trace_id`: 이번 요청의 추적 ID로, 문제를 해결하는 데 사용됩니다.
- `data`: 생성된 비디오 결과 목록.
  - `id`: 생성된 비디오의 고유 식별자.
  - `video_url`: 생성된 비디오의 링크 주소(`state`가 `pending`일 때는 `null`).
  - `state`: 비디오 생성 작업의 상태로, 선택적으로 `pending` / `succeeded` / `failed`가 있습니다.
  - `aspect_ratio`: 해당 비디오의 가로 세로 비율로, 요청 매개변수와 일치합니다.
  - `prompt`: 해당 비디오를 생성하는 데 사용된 프롬프트.

동기 반환 시, 최상위에는 `started_at`, `finished_at`, `elapsed`(소요 시간, 초) 및 `cost`(이번 비용, 단위 Credit) 등의 필드가 추가로 포함됩니다.

우리는 결과의 `data`에서 `video_url` 링크 주소를 통해 생성된 비디오를 가져오기만 하면 됩니다.

해당 CURL 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 이미지 기반 비디오 생성

참조 이미지를 기반으로 비디오를 생성하려면 `image_urls`에 하나 이상의 이미지 링크를 전달하여 비디오 생성을 안내할 수 있습니다:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## 비디오 편집 / 참조 비디오 (입력 비디오, 생성 비디오)

"입력 비디오를 통해 새로운 비디오를 생성"하는 것을 지원합니다: `video_urls`에 참조 비디오 링크(최대 1개)를 전달하고, **동시에** `image_urls`에 최소 1장의 참조 이미지를 제공해야 하며(상위 요구 사항), `prompt`를 사용하여 원하는 편집 효과(스타일 변경, 장면 변경, 요소 추가/삭제 등)를 설명합니다.

다음은 실제 예시로, 햇살이 내리쬐는 해변 비디오를 눈이 내리는 겨울 풍경으로 변경하면서 해변, 야자수, 작은 배의 배치를 유지하는 것입니다. 비디오 편집은 시간이 오래 걸리므로(이 예시는 약 6.5분 소요), `async: true`로 비동기 제출합니다:
```json
{
  "prompt": "이 화창한 열대 해변을 눈이 많이 내리고 흐린 하늘이 있는 겨울 풍경으로 바꾸세요; 같은 해변, 야자수 및 보트 배치를 유지하세요.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

제출 후 인터페이스는 즉시 `task_id`를 반환합니다:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

그 후 해당 `task_id`를 `id`로 사용하여 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks)를 폴링하여 작업이 완료되면 생성된 새 비디오를 가져올 수 있습니다(이것은 본 예제의 실제 반환 결과입니다):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "이 화창한 열대 해변을 눈이 많이 내리고 흐린 하늘이 있는 겨울 풍경으로 바꾸세요; 같은 해변, 야자수 및 보트 배치를 유지하세요."
    }
  ],
  "started_at": 1784084482.914,
  "finished_at": 1784084877.09,
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

더 고화질의 결과가 필요하면 `resolution`을 `1080p`로 설정하세요(나머지 매개변수는 변경하지 마세요).

> 팁: 예제의 입력 / 출력 미디어 링크는 모두 실제 생성 결과입니다. **플랫폼에서 생성된 비디오 및 이미지 링크는 저장 기한이 있으며, 만료 후에는 사용할 수 없습니다**, 결과를 받은 후 즉시 다운로드하여 자신의 저장소에 보관하세요.

> 주의: 참조 비디오는 최대 1개이며, `video_urls`를 제공할 때는 반드시 최소한 하나의 `image_urls`를 제공해야 합니다. 그렇지 않으면 다음과 같은 매개변수 오류가 반환됩니다:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (at least one reference image) is required when video_urls is provided."
  }
}
```

## 비동기 콜백

비디오 생성에는 일정한 처리 시간이 필요합니다. 긴 연결을 유지하고 싶지 않다면 `callback_url`을 전달할 수 있으며, 이 경우 API는 즉시 `task_id`를 반환하고 작업이 완료되면 최종 결과를 해당 주소로 POST합니다:

```json
{
  "prompt": "햇빛이 비치는 정원에서 나비를 쫓는 아기 고양이의 영화 같은 장면",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

즉시 반환되는 결과는 다음과 같습니다:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## 작업 결과 조회

비동기 콜백을 사용했거나 작업 상태를 수동으로 조회하고 싶다면 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`)를 통해 `task_id`로 작업의 최신 상태와 결과를 조회할 수 있습니다. 요청 본문에 비디오 생성 시 반환된 `task_id`를 `id`로 전달합니다:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

작업이 완료되면 반환되는 결과는 다음과 유사하며, `response.data`의 구조는 동기 생성 시와 일치합니다(생성 중일 때 `state`는 `pending`, `video_url`은 `null`입니다):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "일출 시 눈 덮인 산 위의 구름 타임랩스",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "일출 시 눈 덮인 산 위의 구름 타임랩스"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## 오류 처리

요청에 문제가 발생하면 API는 해당 오류 코드와 설명을 반환하며, 일반적인 오류는 다음과 같습니다:

- `400`: 요청 매개변수가 잘못되었습니다. 예를 들어 `prompt` 또는 `aspect_ratio`가 누락되었거나 잘못된 값입니다.
- `401`: 인증 실패, 토큰이 유효하지 않거나 API와 일치하지 않습니다.
- `403`: 잔액 부족 또는 제안어가 콘텐츠 검토에 의해 거부되었습니다.
- `500`: 서버 내부 오류 또는 상위 생성 실패입니다.
