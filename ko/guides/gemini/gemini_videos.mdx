본 문서에서는 Gemini Videos Generation API 연동 방법을 소개합니다. 이 API는 텍스트 프롬프트(및 선택적으로 참고 이미지)를 입력하여 Google Gemini(omni-flash) 영상을 생성할 수 있습니다.

## 신청 절차

API를 사용하려면 먼저 [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) 페이지에서 해당 서비스를 신청해야 합니다. 페이지에 접속 후, 「Acquire」 버튼을 클릭하세요. 아래 그림과 같습니다:

![](https://cdn.acedata.cloud/q6ytrc.png)

로그인 또는 회원가입이 되어 있지 않은 경우, 자동으로 로그인 페이지로 이동하여 회원가입 및 로그인을 안내합니다. 로그인 후 자동으로 현재 페이지로 돌아옵니다.

최초 신청 시 무료 할당량이 제공되어 API를 무료로 사용할 수 있습니다.

## 기본 사용법

먼저 기본 사용법을 이해해 봅시다. 프롬프트 `prompt`, 모델 `model`, 그리고 가로세로 비율 `aspect_ratio`를 입력하면 해당 영상이 생성됩니다.

여기서는 Request Headers를 설정했으며, 포함 내용은 다음과 같습니다:

- `accept`: 응답 결과를 어떤 형식으로 받을지 지정합니다. 여기서는 `application/json` (JSON 형식)으로 설정했습니다.
- `authorization`: API 호출에 필요한 인증 키로, 신청 후 드롭다운에서 선택할 수 있습니다.

또한 Request Body에는 다음 항목들이 포함됩니다:

- `prompt`: 생성할 영상 내용을 설명하는 텍스트 프롬프트, **필수** 입력입니다.
- `model`: 영상 생성에 사용할 모델로, 현재는 `omni-flash`만 지원하며 기본값도 `omni-flash`입니다.
- `aspect_ratio`: 영상의 가로세로 비율로, 선택 가능 값은 `16:9`(가로형) 또는 `9:16`(세로형)이며 기본값은 `16:9`입니다.
- `image_urls`: 선택 사항으로, 영상 생성에 참고할 이미지(또는 영상) URL 배열입니다. 빈 항목은 무시됩니다.
- `callback_url`: 비동기 콜백 주소로 설정 시 API가 즉시 `task_id`를 반환하며, 작업 완료 시 결과를 해당 주소로 POST합니다.

「Try」 버튼을 클릭하면 테스트할 수 있으며, 결과는 다음과 유사합니다:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

반환되는 결과에는 여러 필드가 있으며, 설명은 다음과 같습니다:

- `success`: 영상 생성 요청이 성공했는지 여부.
- `task_id`: 영상 생성 작업의 ID.
- `trace_id`: 요청 추적 ID로 문제 해결 시 사용.
- `data`: 생성된 영상 결과 목록.
  - `id`: 생성된 영상의 고유 식별자.
  - `video_url`: 생성된 영상의 URL.
  - `state`: 영상 생성 작업 상태, `pending` / `succeeded` / `failed` 중 하나.

결과의 `data` 내 `video_url` 링크를 통해 생성된 영상을 확인할 수 있습니다.

아래는 대응하는 CURL 코드입니다:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

아래는 대응하는 Python 코드입니다:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 이미지 기반 영상 생성

참고 이미지를 기반으로 영상을 생성하고 싶다면, `image_urls`에 하나 이상의 이미지 URL을 전달하여 영상 생성을 유도할 수 있습니다:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## 비동기 콜백

영상 생성에는 일정 시간이 소요됩니다. 장시간 연결을 유지하고 싶지 않은 경우 `callback_url`을 전달할 수 있습니다. 이 경우 API는 즉시 `task_id`를 반환하고, 작업 완료 시 최종 결과를 해당 주소로 POST합니다:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

즉시 반환되는 결과는 다음과 같습니다:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## 작업 결과 조회

비동기 콜백을 사용했거나 작업 상태를 직접 조회하고 싶다면, [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`)를 통해 `task_id`로 최신 상태 및 결과를 조회할 수 있습니다.

## 오류 처리

요청에 문제가 발생하면 API는 해당 오류 코드와 설명을 반환합니다. 주요 오류는 다음과 같습니다:

- `400`: 요청 파라미터 오류 (예: `prompt` 누락 또는 `aspect_ratio` 값이 유효하지 않음).
- `401`: 인증 실패 (토큰이 무효하거나 API와 불일치).
- `403`: 잔액 부족 또는 프롬프트가 콘텐츠 검열에 의해 거부됨.
- `500`: 서버 내부 오류 또는 상위 생성 실패.
