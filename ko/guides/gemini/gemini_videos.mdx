본 문서에서는 Gemini Videos Generation API의 연동 설명을 소개합니다. 이 API는 입력된 텍스트 프롬프트(및 선택적인 참조 이미지)를 통해 Google Gemini(omni-flash) 비디오를 생성할 수 있습니다.

## 신청 절차

Gemini Videos Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 받아야 하며, 이를 보관해 두십시오.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

로그인 또는 등록이 되어 있지 않은 경우, 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 요청합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 할당량이 제공되어 무료로 체험할 수 있습니다; 할당량이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## 기본 사용법

먼저 기본 사용 방법을 이해합니다. 입력 프롬프트 `prompt`, 모델 `model`, 그리고 가로 세로 비율 `aspect_ratio`를 입력하면 해당 비디오를 생성할 수 있습니다.

여기서 설정한 Request Headers는 다음과 같습니다:

- `accept`: 어떤 형식의 응답 결과를 받고 싶은지, 여기서는 `application/json`으로 입력하여 JSON 형식을 요청합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 드롭다운에서 직접 선택할 수 있습니다.

또한 Request Body를 설정합니다:

- `prompt`: 생성하고자 하는 비디오 내용에 대한 텍스트 프롬프트, **필수**입니다.
- `model`: 비디오를 생성할 모델로, 현재는 `omni-flash`만 지원하며 기본값은 `omni-flash`입니다.
- `aspect_ratio`: 생성할 비디오의 가로 세로 비율로, 선택적으로 `16:9`(가로) 또는 `9:16`(세로) 중 하나를 선택할 수 있으며 기본값은 `16:9`입니다.
- `resolution`: 선택 가능한 출력 해상도로, `720p` 또는 `1080p` 중 하나를 선택할 수 있으며 기본값은 `720p`입니다.
- `image_urls`: 비디오 생성을 유도하기 위한 선택적인 참조 이미지 링크 배열로, 비어 있는 항목은 무시됩니다. `video_urls`를 사용하여 비디오 편집을 할 경우 이 매개변수는 필수입니다(최소 1장).
- `video_urls`: 선택적인 참조 비디오 링크 배열(최대 1개)로, **비디오 편집 / 비디오 참조**에 사용됩니다; 제공할 경우 최소 1장의 `image_urls`도 함께 제공해야 합니다.
- `callback_url`: 비동기 콜백 주소로, 설정 시 API는 즉시 `task_id`를 반환하며, 작업 완료 시 결과를 해당 주소로 POST합니다.
- `async`: 선택 사항으로, `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하며 `callback_url`을 제공할 필요가 없고, 이후 해당 작업 조회 인터페이스를 통해 결과를 폴링하여 가져올 수 있습니다.

"Try" 버튼을 클릭하여 테스트를 진행하면, 얻은 결과는 다음과 유사합니다:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

반환된 결과는 여러 필드를 포함하며, 설명은 다음과 같습니다:

- `success`: 이번 비디오 생성 요청이 성공했는지 여부.
- `task_id`: 이번 비디오 생성 작업의 ID.
- `trace_id`: 이번 요청의 추적 ID로, 문제를 해결하는 데 사용됩니다.
- `data`: 생성된 비디오 결과 목록.
  - `id`: 생성된 비디오의 고유 식별자.
  - `video_url`: 생성된 비디오의 링크 주소.
  - `state`: 비디오 생성 작업의 상태로, 선택적으로 `pending` / `succeeded` / `failed`가 있습니다.

우리는 결과의 `data`에서 `video_url` 링크 주소를 통해 생성된 비디오를 가져오기만 하면 됩니다.

해당 CURL 코드는 다음과 같습니다:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

해당 Python 코드는 다음과 같습니다:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 이미지 기반 비디오 생성

참조 이미지를 기반으로 비디오를 생성하려면 `image_urls`에 하나 이상의 이미지 링크를 전달하여 비디오 생성을 유도할 수 있습니다:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## 비디오 편집 / 참조 비디오

기존 비디오를 직접 편집하거나 참조하는 것을 지원합니다: `video_urls`에 참조 비디오 링크(최대 1개)를 전달하고, **동시에** `image_urls`에 최소 1장의 참조 이미지를 제공해야 합니다(상위 요구 사항). `prompt`를 통해 원하는 편집 효과(스타일 변경, 장면 변경, 요소 추가/삭제 등)를 설명할 수 있습니다:

```json
{
  "prompt": "Restyle the video into cinematic anime, keep the motion",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> 주의: 참조 비디오는 최대 1개이며, `video_urls`를 제공할 경우 최소 1장의 `image_urls`를 제공해야 합니다(그렇지 않으면 매개변수 오류가 발생합니다).

## 비동기 콜백

비디오 생성에는 일정한 처리 시간이 필요합니다. 긴 연결을 유지하고 싶지 않은 경우 `callback_url`을 전달하면, 이때 API는 즉시 `task_id`를 반환하며, 작업 완료 후 최종 결과를 해당 주소로 POST합니다:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

즉시 반환되는 결과는 다음과 같습니다:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## 작업 결과 조회

비동기 콜백을 사용했거나 작업 상태를 적극적으로 조회하고 싶다면 [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`)를 통해 `task_id`에 따라 작업의 최신 상태와 결과를 조회할 수 있습니다.

## 오류 처리

요청에 문제가 발생할 경우, API는 해당 오류 코드와 설명을 반환하며, 일반적인 오류는 다음과 같습니다:
- `400`：요청 매개변수가 잘못되었습니다. 예를 들어 `prompt` 또는 `aspect_ratio`가 누락되었거나 값이 잘못되었습니다.
- `401`：인증 실패, 토큰이 유효하지 않거나 API와 일치하지 않습니다.
- `403`：잔액이 부족하거나 프롬프트가 콘텐츠 검토에 의해 거부되었습니다.
- `500`：서버 내부 오류 또는 상위 생성 실패.
