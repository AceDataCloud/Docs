본 문서에서는 사용자 정의 매개변수를 입력하여 SeeDance 공식 동영상을 생성할 수 있는 SeeDance Videos Generation API 연동 안내를 소개합니다.

## 신청 절차

SeeDance Videos Generation API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인 또는 등록하지 않은 경우, 로그인 페이지로 자동 이동하여 등록과 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공통 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [SeeDance Videos Generation API →](https://platform.acedata.cloud/documents/seedance-videos)

## 기본 사용법

먼저 기본 사용 방식을 살펴보겠습니다. 프롬프트 `content.text`, 유형 `content.type=text`, 그리고 모델 `model`을 입력하면 처리된 결과를 얻을 수 있으며, 구체적인 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/seedance_parameters.png" width="500" className="m-auto" /></p>

여기에서 Request Headers를 설정한 것을 확인할 수 있으며, 다음을 포함합니다:

- `accept`: 어떤 형식의 응답 결과를 받을지 지정하며, 여기서는 JSON 형식인 `application/json`으로 입력합니다.
- `authorization`: API 호출 키이며, 신청 후 드롭다운에서 직접 선택할 수 있습니다.

또한 Request Body를 설정하며, 다음을 포함합니다:

- `model`: 동영상을 생성하는 모델입니다.
  - **Seedance 1.x 시리즈**: `doubao-seedance-1-0-pro-250528`, `doubao-seedance-1-0-pro-fast-251015`, `doubao-seedance-1-5-pro-251215`, `doubao-seedance-1-0-lite-t2v-250428`, `doubao-seedance-1-0-lite-i2v-250428`.
  - **Seedance 2.0 시리즈**(캐릭터 및 오디오·비디오 멀티모달 참조 지원): `doubao-seedance-2-0-260128`(표준), `doubao-seedance-2-0-fast-260128`(고속), `doubao-seedance-2-0-mini-260615`(경량).
  - **Seedance 2.5**: `doubao-seedance-2-5-260628`, 최대 30초, 순수 오디오 참조, 더 많은 소재, 동영상 편집 및 연장을 지원합니다.
- `content`: 입력 콘텐츠 배열이며, `type`은 `text`(프롬프트), `image_url`(참조 이미지), `audio_url`(참조 오디오), `video_url`(참조 동영상)일 수 있습니다. 이미지는 `role`을 통해 용도를 지정할 수 있습니다: `first_frame`(첫 프레임) / `last_frame`(마지막 프레임) / `reference_image`(캐릭터 / 주체 참조).
- `resolution`: 출력 해상도이며, `480p` / `720p` / `1080p` / `4k`를 선택할 수 있습니다. 2.5는 480p, 720p, 1080p를 지원하며, 2.0 Fast/Mini는 480p, 720p를 지원하고, 2.0 Standard는 최대 4k를 지원합니다.
- `ratio`: 가로세로 비율이며, `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive`를 선택할 수 있습니다.
- `duration`: 동영상 길이(초, 정수)입니다. 1.0 시리즈는 2–12, 1.5 Pro는 4–12, 2.0 시리즈는 4–15, 2.5는 4–30입니다. 1.5/2.x는 `-1`(자동 길이)을 지원합니다.
- `seed`: 랜덤 시드이며, 정수이고 -1부터 4294967295까지입니다.
- `camerafixed`: 카메라 고정 여부이며, `true` / `false`입니다.
- `watermark`: 워터마크 추가 여부이며, `true` / `false`입니다.
- `generate_audio`: 오디오가 포함된 동영상 생성 여부이며, `true` / `false`이고, Seedance 1.5 Pro 및 2.x 시리즈에서 지원합니다.
- `return_last_frame`: 결과에 동영상 마지막 프레임 이미지 URL을 반환할지 여부입니다.
- `omni_reference_task_type`: 2.5 전용이며, `auto` / `reference` / `edit` / `extend`입니다.
- `output_format`: 2.5 전용이며, `mp4` / `mov`이고 기본값은 `mp4`입니다.
- `tools`: 2.5 전용이며, 현재 `web_search` 온라인 검색 도구를 지원하고 결과 수, 키워드 수 및 검색 소스를 제한할 수 있습니다.
- `priority`: 2.5의 선택 가능한 작업 우선순위이며, 정수 0–9이고 기본값은 0입니다.
- `safety_identifier`: 최대 64자 길이의 안정적인 익명 최종 사용자 식별자입니다. 해시 또는 내부 익명 ID를 사용하고, 이름, 이메일 또는 휴대폰 번호를 전달하지 마세요.
- `execution_expires_after`: 작업 타임아웃 시간(초)이며, 범위는 3600–259200입니다.
- `callback_url`: 비동기 콜백 주소이며, 설정 후 API는 즉시 `task_id`를 반환하고 작업 완료 시 결과를 해당 주소로 POST합니다.
- `async`: 선택 사항이며, `true`로 설정하면 인터페이스가 즉시 `task_id`를 반환하고 `callback_url`을 제공할 필요가 없으며, 이후 해당 작업 조회 인터페이스를 통해 폴링하여 결과를 가져옵니다.

선택 후 오른쪽에도 해당 코드가 생성된 것을 확인할 수 있으며, 그림과 같습니다:

반환 결과에는 여러 필드가 있으며, 다음과 같이 소개합니다:

- `task_id`, 이때 동영상 생성 작업 ID입니다.
- `trace_id`, 이때 동영상 생성 추적 ID입니다.
- `data`, 이때 동영상 생성 작업의 결과 목록입니다.
  - `task_id`, 이때 동영상 생성 작업의 서버 측 ID입니다.
  - `video_url`, 이때 동영상 생성 작업의 동영상 링크입니다.
  - `status`, 이때 동영상 생성 작업의 상태입니다.
    - `model`, 동영상 생성에 사용된 모델입니다.

만족스러운 동영상 정보를 얻은 것을 확인할 수 있으며, 결과에서 `data`의 동영상 링크 주소를 통해 생성된 SeeDance 동영상을 가져오기만 하면 됩니다.

또한 해당 연동 코드를 생성하려면 직접 복사하여 생성할 수 있으며, 예를 들어 CURL 코드는 다음과 같습니다:
```shell
curl -X POST 'https://api.acedata.cloud/seedance/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "content": [{"type":"text","text":"A white ceramic coffee mug on a glossy marble countertop with soft morning window light. The camera slowly orbits 360 degrees around the mug, steam gently rising."}],
  "model": "doubao-seedance-2-0-fast-260128",
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5
}'
```

## 인라인 파라미터 설명

`content[].text` 프롬프트 끝에 `--parameter value` 형식으로 생성 파라미터를 추가하여 전달할 수 있습니다(이전 방식, 약한 검증, 잘못 입력한 경우 자동으로 기본값 사용). 전체 파라미터 목록은 다음과 같습니다:

| 인라인 파라미터       | 대응 필드              | 설명      | 값 범위                                                          |
| ---------- | ----------------- | ------- | ------------------------------------------------------------- |
| `--rs`     | `resolution`      | 출력 해상도   | `480p` / `720p` / `1080p`                                     |
| `--rt`     | `ratio`           | 가로세로비     | `16:9` / `4:3` / `1:1` / `3:4` / `9:16` / `21:9` / `adaptive` |
| `--dur`    | `duration`        | 영상 길이(초) | 2–12                                                          |
| `--frames` | `frames`          | 영상 프레임 수    | [29, 289] 내에서 25+4n을 만족하는 정수（**1.0 시리즈만 지원**）                       |
| `--fps`    | `framespersecond` | 프레임률      | `24`만 지원                                                      |
| `--seed`   | `seed`            | 랜덤 시드    | -1에서 4294967295                                               |
| `--cf`     | `camerafixed`     | 카메라 고정 여부 | `true` / `false`                                              |
| `--wm`     | `watermark`       | 워터마크 추가 여부  | `true` / `false`                                              |

> **권장 방법**：Request Body에서 직접 대응되는 최상위 필드(예: `resolution`, `ratio` 등)를 사용하세요. 이는 강한 검증 모드이며, 파라미터를 잘못 입력한 경우 명확한 오류 메시지를 반환하므로 문제를 더 쉽게 추적할 수 있습니다.

## 오디오 포함 영상 생성

Seedance 1.5 Pro 및 2.x 시리즈는 `generate_audio` 파라미터를 통해 오디오가 포함된 영상을 생성할 수 있습니다:

```json
{
  "model": "doubao-seedance-1-5-pro-251215",
  "content": [
    {
      "type": "text",
      "text": "A girl holds a fox, the wind blows her hair, you can hear the sound of the wind"
    }
  ],
  "generate_audio": true,
  "ratio": "16:9",
  "duration": 5
}
```

1.0 시리즈는 이 파라미터를 지원하지 않습니다.

## Seedance 2.5 옴니모달 생성, 편집 및 연장

`doubao-seedance-2-5-260628`은 480p / 720p / 1080p, 4–30초 또는 자동 길이를 지원하며, 자료 한도를 참조 이미지 30장, 참조 영상 10개, 참조 오디오 10개(총 최대 50개)로 늘렸습니다. 2.5는 참조 오디오만 전달하는 것도 지원하며, 더 이상 이미지나 영상을 함께 제공할 필요가 없습니다.

일반 옴니모달 생성에서는 `omni_reference_task_type`을 생략하거나 `auto`로 설정하거나, 명시적으로 `reference`로 설정할 수 있습니다. 영상 편집 및 연장은 반드시 `reference_video`를 전달해야 합니다:

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "Replace the sky with a warm sunset while preserving the subject and camera motion."},
    {"type": "video_url", "role": "reference_video", "video_url": {"url": "https://cdn.acedata.cloud/input.mp4"}}
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": -1,
  "omni_reference_task_type": "edit",
  "output_format": "mov"
}
```

- `reference`：최소 하나의 `reference_image`, `reference_video` 또는 `reference_audio`를 전달합니다. 2.5는 참조 오디오만 전달하는 것을 지원합니다.
- `edit`：반드시 `ratio: adaptive` 및 `duration: -1`을 사용해야 합니다. 출력 길이는 실제 결과에 따라 과금됩니다.
- `extend`：반드시 `ratio: adaptive`를 사용해야 합니다. `duration`은 4–30 또는 `-1`일 수 있습니다.
- `auto`：모델이 프롬프트와 자료에 따라 생성, 편집 또는 연장을 자동으로 선택합니다.
- 작업 유형이 자료 또는 프롬프트와 일치하지 않으면 작업이 실패하고 위치를 파악할 수 있는 파라미터 오류를 반환합니다. 위 제약 조건에 따라 조정한 후 다시 제출하세요.

## 이미지 기반 영상 첫 프레임

이미지 기반 영상 작업을 하려면 먼저 `content` 파라미터에 `type`이 `image_url`인 항목이 포함되어야 하며, `image_url` 필드는 반드시 객체 형식이어야 합니다: `{"url": "https://..."}` 또는 Base64 형식 `{"url": "data:image/png;base64,..."}`.

> **주의**：`image_url`은 문자열 형식(예: `"image_url": "https://cdn.acedata.cloud/e724d7f13d.png"`)을 직접 전달하는 것을 지원하지 않으며, 반드시 객체 형식 `"image_url": {"url": "https://..."}`을 사용해야 합니다. 그렇지 않으면 400 오류가 반환됩니다.

대응하는 코드:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "content": [
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/i2v_foxrgirl.png"
            }
        },
        {
            "type": "text",
            "text": "A girl holds a fox in her arms. She opens her eyes and gazes tenderly at the camera, while the fox affectionately holds her back. As the camera slowly pulls away, her hair is gently blown by the wind. --ratio adaptive  --dur 5"
        }
    ],
    "model": "doubao-seedance-1-0-pro-250528"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행을 클릭하면 즉시 다음과 같은 결과를 얻을 수 있습니다:

```
{
  "success": true,
  "task_id": "dc7cceb5-3c12-4de7-a5f4-abcbba3e8e39",
  "trace_id": "b3b09de3-b7fa-4bb0-88b5-aad4b4a96fd4",
  "data": {
    "task_id": "cgt-20251222072003-x2259",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/6afb78b8-5ba8-424f-adcd-69423a700b50.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

생성된 효과가 이미지 기반 영상 생성이며, 결과는 위와 유사한 것을 볼 수 있습니다.

## 이미지 기반 영상 첫 프레임 및 마지막 프레임

이미지 기반 영상의 첫 프레임 및 마지막 프레임을 만들려면, 먼저 파라미터 `content`에 유형 `image_url`을 전달하고, 각각 `role`을 `first_frame` 및 `last_frame`으로 설정하면 다음 내용을 지정할 수 있습니다:

- role：첫 프레임 또는 마지막 프레임을 지정합니다.
- image_url
  - url 이미지 링크
    동시에 `content`에는 prompt 프롬프트로서 유형 `text`도 입력해야 합니다

대응하는 코드:
```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
   "model": "doubao-seedance-1-0-pro-250528",
    "content": [
         {
            "type": "text",
            "text": "360-degree shot"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_first_frame.jpeg"
            },
            "role": "first_frame"
        },
        {
            "type": "image_url",
            "image_url": {
                "url": "https://ark-project.tos-cn-beijing.volces.com/doc_image/seepro_last_frame.jpeg"
            },
            "role": "last_frame"
        }
    ]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

실행을 클릭하면 즉시 다음과 같은 결과를 얻을 수 있습니다:

```
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

보시다시피, 생성 효과는 캐릭터 생성 비디오이며, 결과는 위와 유사합니다.

## 캐릭터 및 오디오·비디오 멀티모달 참조（Seedance 2.0）

**Seedance 2.0 시리즈**（`doubao-seedance-2-0-260128`、`doubao-seedance-2-0-fast-260128`、`doubao-seedance-2-0-mini-260615`）는 `reference_image`, `reference_audio` 및 `reference_video`를 지원합니다. 자체 보유하거나 권한을 획득한 소재를 사용하여 캐릭터, 피사체, 동작, 카메라 워크, 사운드 및 리듬의 일관성을 유지할 수 있습니다.

> 자체 보유하거나 권한을 획득한 실제 인물 및 캐릭터 소재만 업로드하세요. 모델마다 실제 인물 소재를 지원하는 방식이 다릅니다. 요청 형식은 동일하게 유지되며, 소재가 요구 사항에 부합하지 않으면 명확한 오류가 반환됩니다.

사용 핵심 사항:

- `reference_image`는 **Seedance 2.0 시리즈** 모델만 지원합니다. 1.x 모델에서는 `first_frame` / `last_frame`(이미지-비디오 생성의 첫·마지막 프레임)을 사용하세요.
- 이미지-비디오 생성 첫 프레임, 이미지-비디오 생성 첫·마지막 프레임, 전체 모달 참조는 서로 배타적인 세 가지 시나리오입니다. `first_frame` / `last_frame`는 `reference_image` / `reference_video` / `reference_audio`와 함께 사용할 수 없습니다.
- 전체 모달 참조에서 첫·마지막 프레임을 지정하려면 이미지를 `reference_image`로 표시하고, 프롬프트에 “이미지 1을 첫 프레임으로” 또는 “이미지 2를 마지막 프레임으로”라고 명시하세요. 첫·마지막 프레임을 엄격하게 고정해야 한다면 `first_frame` / `last_frame`만 사용하세요.
- 멀티모달 참조 수량 한도: `image_url`은 최대 **9**장입니다. 2.0은 `audio_url`(`role`은 `reference_audio`, 최대 3개)과 `video_url`(`role`은 `reference_video`, 최대 3개)도 지원합니다.
- **참조 오디오(`audio_url`) 소재 요구 사항**: 형식은 `wav` / `mp3`; **각 항목 길이는 2~15초**, 최대 3개이며 **총 길이는 15초를 초과할 수 없음**; 각 항목은 15MB를 초과할 수 없습니다. 길이 범위를 초과하면 소재 처리 단계에서 실패합니다.
- **참조 비디오(`video_url`) 소재 요구 사항**: 형식은 `mp4` / `mov`; **각 항목 길이는 2~15초**, 최대 3개이며 **총 길이는 15초를 초과할 수 없음**.
- 참조 이미지는 **한 명, 정면 얼굴, 선명함, 가림 없음**의 사진을 권장합니다. 얼굴이 선명할수록 유사도가 높아집니다.

### 예시 1: 인물 외모를 유지하는 클로즈업

얼굴 사진 한 장을 전달하여, 해당 인물이 카메라를 향해 미소 짓고 손을 흔들게 합니다. 해당 코드:

```python
import requests

url = "https://api.acedata.cloud/seedance/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "doubao-seedance-2-0-fast-260128",
    "content": [
        {
            "type": "text",
            "text": "The woman looks at the camera, gives a warm natural smile and waves her hand, soft studio lighting, gentle camera push-in."
        },
        {
            "type": "image_url",
            "role": "reference_image",
            "image_url": {
                "url": "https://cdn.acedata.cloud/assets/examples/nanobanana/8e075897-0f50-4443-8500-666751791c6c-4346f66287c0.jpg"
            }
        }
    ],
    "resolution": "480p",
    "ratio": "9:16",
    "duration": 5
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

반환 결과는 다음과 같으며, 생성된 비디오 속 인물은 참조 사진과 일관성을 유지합니다:

## 비동기 콜백

SeeDance Videos Generation API의 생성 시간은 비교적 길기 때문에(약 1~2분), `callback_url` 필드를 통해 비동기 모드를 사용할 수 있으며, HTTP 연결이 장시간 점유되는 것을 방지할 수 있습니다.

전체 프로세스: 클라이언트가 요청을 시작할 때 `callback_url`을 지정하면, API는 즉시 `task_id`가 포함된 응답을 반환합니다. 작업이 완료된 후 플랫폼은 생성 결과를 POST JSON 형식으로 `callback_url`에 전송하며, 결과에도 연결을 위해 동일하게 `task_id`가 포함됩니다.

```json
{
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd"
}
```

작업이 완료되면 플랫폼은 다음 내용을 `callback_url`로 푸시합니다:

```json
{
  "success": true,
  "task_id": "f7096c6c-9430-4392-8201-d259632d7afd",
  "trace_id": "4a4a3721-00fb-43d2-aff2-3b516ac01a8a",
  "data": {
    "task_id": "cgt-20251222073134-54qcw",
    "status": "succeeded",
    "video_url": "https://platform.cdn.acedata.cloud/seedance/95f9f5f0-fc50-4c71-bc6f-e154582c141e.mp4",
    "model": "doubao-seedance-1-0-pro-250528"
  }
}
```

결과의 `task_id` 필드는 요청 시 반환된 값과 일치하며, 이 필드를 통해 작업을 연결할 수 있습니다.

## 오류 처리

API를 호출할 때 오류가 발생하면, API는 해당 오류 코드와 정보를 반환합니다. 예:

- `400 token_mismatched`：잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `400 api_not_implemented`：잘못된 요청이며, 매개변수가 누락되었거나 유효하지 않기 때문일 수 있습니다.
- `401 invalid_token`：권한이 없으며, 인증 토큰이 유효하지 않거나 누락되었습니다.
- `429 too_many_requests`：요청이 너무 많으며, 속도 제한을 초과했습니다.
- `500 api_error`：내부 서버 오류이며, 서버에서 문제가 발생했습니다.

### 오류 응답 예시

```json
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
