본 문서에서는 Sora Videos Generation API 연동 방법에 대해 소개합니다. 이 API를 통해 사용자 지정 매개변수를 입력하여 Sora 공식 영상을 생성할 수 있습니다. 본 API는 두 가지 버전 모드를 지원합니다:

- **Version 1(클래식 모드)**: `duration`(10/15/25초), `orientation`(가로/세로), `size`(small/large 해상도), 참조 이미지 `image_urls`, 캐릭터**###** `character_url` 등의 매개변수를 지원합니다.
- **Version 2(파트너 모드)**: `seconds`(4/8/12초), 픽셀 단위 해상도 `size`(예: 1280x720), 참조 이미지 `input_reference` 등의 매개변수를 지원합니다.

## 신청 절차

API를 사용하려면 먼저 [Sora Videos Generation API](https://platform.acedata.cloud/documents/99a24421-2e22-4028-8201-e19cb834b67e) 해당 페이지에서 서비스를 신청해야 합니다. 페이지에 접속한 후 「Acquire」 버튼을 클릭하세요. 아래 그림과 같습니다:

![](https://cdn.acedata.cloud/q6ytrc.png)

로그인 또는 회원가입이 되어 있지 않은 경우 자동으로 로그인 페이지로 이동하며, 로그인 및 회원가입 후 현재 페이지로 자동 복귀합니다.

첫 신청 시 무료 할당량이 제공되어 무료로 API를 사용할 수 있습니다.

## 기본 사용법 (Version 1)

먼저 Version 1의 기본 사용법을 이해해야 합니다. `prompt`(프롬프트), 참조 이미지 링크 배열 `image_urls`, 모델 `model`을 입력하면 처리된 결과를 얻을 수 있습니다. 구체적인 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/h8dyz3.png" width="500" className="m-auto" /></p>

여기서 Request Headers를 설정한 것을 볼 수 있습니다:

- `accept`: 원하는 응답 형식으로, 여기서는 `application/json` 즉 JSON 형식을 지정합니다.
- `authorization`: API 호출을 위한 키로, 신청 후 드롭다운에서 선택할 수 있습니다.

또한 Request Body를 설정했습니다:

- `model`: 영상 생성 모델로 `sora-2`(표준 모드)와 `sora-2-pro`(고화질 모드)를 지원합니다. `sora-2-pro`는 25초 영상 생성이 가능하며, `sora-2`는 10초, 15초만 지원합니다.
- `size`: 영상 해상도로 `small`은 표준 해상도, `large`는 HD 해상도입니다(Version 1만 해당).
- `duration`: 영상 길이로 10, 15, 25초를 지원하며, 25초는 `sora-2-pro`만 지원합니다(Version 1만 해당).
- `orientation`: 화면 방향으로 `landscape`(가로), `portrait`(세로)를 지원합니다(Version 1만 해당).
- `image_urls`: 참조 이미지 링크 배열로, 이미지 기반 영상 생성에 사용됩니다(Version 1만 해당).
- `character_url`: 캐릭터**###** 링크로, 영상에 실제 인물이 등장하면 안 됩니다(Version 1만 해당).
- `character_start`/`character_end`: 캐릭터 등장 시작 및 종료 초 단위, 범위는 1-3초입니다(Version 1만 해당).
- `prompt`: 프롬프트(필수).
- `callback_url`: 비동기 콜백 결과 URL.
- `version`: API 버전으로 `1`(기본) 또는 `2`를 지정합니다.


## 이미지 기반 영상 생성 작업 (Version 1)

이미지 기반 영상 생성 작업을 하려면, `image_urls` 매개변수에 참조 이미지 링크를 반드시 전달해야 하며, 다음과 같이 지정할 수 있습니다:

- `image_urls`: 이미지 기반 영상 생성 작업에 사용되는 참조 이미지 링크 배열입니다. 실제 인물의 얼굴이 포함된 이미지는 전달하지 마십시오. 작업 실패 원인이 될 수 있습니다.

작성 예시는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/ch7x3t.png" width="500" className="m-auto" /></p>

작성 후 자동으로 생성된 코드는 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/z1ud8l.png" width="500" className="m-auto" /></p>

해당 코드:

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "size": "large",
    "duration": 15,
    "orientation": "landscape",
    "prompt": "cat running on the river",
    "model": "sora-2",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## 캐릭터 생성 영상 작업 (Version 1)

캐릭터 생성 영상 작업을 하려면, `character_url` 매개변수에 캐릭터 생성에 필요한 영상 링크를 반드시 전달해야 하며, 영상에 실제 인물이 등장하면 작업이 실패합니다. 다음과 같이 지정할 수 있습니다:

- `character_url`: 캐릭터 생성에 필요한 영상 링크이며, 영상에 실제 인물이 등장하면 실패합니다.

## Version 2 모드

위 Version 1 모드 외에도 본 API는 Version 2 모드를 지원하며, `version` 매개변수를 `2`로 설정하면 활성화됩니다. Version 2 모드는 더 짧은 영상 길이와 픽셀 단위 해상도 제어를 지원합니다.

### Version 2 매개변수 설명

| 매개변수 | 타입 | 필수 여부 | 설명 |
|----------|------|-----------|------|
| `version` | integer | 예 | `2`로 설정 |
| `prompt` | string | 예 | 영상 생성 프롬프트 |
| `model` | string | 아니오 | `sora-2`(기본) 또는 `sora-2-pro` |
| `duration` | integer | 아니오 | 영상 길이: `4`(기본), `8`, `12`초 |
| `size` | string | 아니오 | 해상도: `720x1280`(기본), `1280x720`, `1024x1792`, `1792x1024` |
| `image_urls` | array | 아니오 | 참조 이미지 URL 배열, 첫 번째 이미지만 사용, 이미지 크기는 `size`와 일치해야 함 |
| `callback_url` | string | 아니오 | 비동기 콜백 URL |

### 기본 예시

```shell
curl -X POST 'https://api.acedata.cloud/sora/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \

  "version": 2,
  "prompt": "cat running on the river",
```

### 참조 이미지 사용 (Version 2)

Version 2 모드에서는 `image_urls` 매개변수로 참조 이미지를 전달하여 영상 생성을 유도할 수 있습니다(첫 번째 이미지만 사용):

```python
import requests

url = "https://api.acedata.cloud/sora/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "version": 2,
    "prompt": "a person walking through a beautiful garden",
    "model": "sora-2",
    "duration": 4,
    "size": "1280x720",
    "image_urls": ["https://cdn.acedata.cloud/11wfp4.png"]
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

> **주의**: 참조 이미지 크기는 `size` 매개변수와 일치해야 합니다. 예를 들어 `size`가 `1280x720`일 경우 참조 이미지 크기도 1280×720이어야 합니다.

### Version 1과 Version 2 매개변수 비교

| 매개변수 | Version 1 | Version 2 |
|----------|-----------|-----------|
| `version` | 1(기본) | 2 |
| `prompt` | ✅ | ✅ |
| `model` | ✅ sora-2 / sora-2-pro | ✅ sora-2 / sora-2-pro |
| `duration` | ✅ 10/15/25초 | ✅ 4/8/12초 |
| `orientation` | ✅ landscape/portrait | ❌ |
| `size` | ✅ small/large | ✅ 720x1280/1280x720/1024x1792/1792x1024 |
| `image_urls` | ✅ 다중 참조 이미지 | ✅ 첫 번째 이미지만 사용 |
| `character_url` | ✅ | ❌ |
| `callback_url` | ✅ | ✅ |

## 비동기 콜백

Sora Videos Generation API는 영상 생성에 약 1~2분이 소요되므로, API가 장시간 응답하지 않으면 HTTP 요청이 계속 연결되어 시스템 자원 낭비가 발생할 수 있습니다. 이를 위해 본 API는 비동기 콜백을 지원합니다.

전체 흐름은: 클라이언트가 요청 시 `callback_url` 필드를 추가로 지정하면, API는 즉시 `task_id`를 포함한 결과를 반환합니다. 작업 완료 후 생성된 영상 결과가 POST JSON 형태로 클라이언트가 지정한 `callback_url`로 전송되며, 이때 `task_id`도 포함되어 작업 결과를 ID로 연동할 수 있습니다.

아래 예시로 구체적인 사용법을 알아봅니다.

먼저 Webhook 콜백은 HTTP 요청을 받을 수 있는 서비스이며, 개발자가 직접 구축한 HTTP 서버 URL로 변경해야 합니다. 편의를 위해 공개 Webhook 예제 사이트 https://webhook.site/를 사용합니다. 사이트를 열면 Webhook URL을 얻을 수 있습니다:

![](https://cdn.acedata.cloud/cjjfly.png)

이 URL을 복사하여 Webhook으로 사용합니다. 예시는 `https://webhook.site/eb238c4f-da3b-47a5-a922-a93aa5405daa`입니다.

다음으로 `callback_url` 필드를 위 Webhook URL로 설정하고, 적절한 매개변수를 입력합니다. 구체 내용은 다음과 같습니다:

<p><img src="https://cdn.acedata.cloud/v1m05g.png" width="500" className="m-auto" /></p>

실행하면 즉시 다음과 같은 결과를 얻습니다:

```
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

잠시 후 `https://webhook.site/eb238c4f-da3b-47a5-a922-a93aa5405daa`에서 생성된 영상 결과를 확인할 수 있습니다:

![](https://cdn.acedata.cloud/0j7nra.png)

## 오류 처리

API 호출 시 오류가 발생하면, API는 해당 오류 코드와 메시지를 반환합니다. 예를 들어:

- `400 token_mismatched`: 잘못된 요청, 매개변수 누락 또는 유효하지 않음.
- `400 api_not_implemented`: 잘못된 요청, 매개변수 누락 또는 유효하지 않음.
- `401 invalid_token`: 인증 실패, 토큰이 없거나 유효하지 않음.
- `429 too_many_requests`: 요청 과다, 속도 제한 초과.
- `500 api_error`: 서버 내부 오류.
