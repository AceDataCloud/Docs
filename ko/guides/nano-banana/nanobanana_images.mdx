이 문서에서는 Nano Banana Images API의 연동 및 사용 방법을 소개합니다. 이 인터페이스는 **이미지 생성(generate)** 및 **이미지 편집(edit)** 두 가지 기능을 지원합니다.

## 신청 절차

Nano Banana Images API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에 접속하여 API Token을 발급받아 별도로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않은 경우 자동으로 로그인 페이지로 이동하여 회원가입 및 로그인을 안내합니다. 완료되면 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 사용량이 제공되어 무료로 체험할 수 있습니다. 사용량이 부족한 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 범용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## 인터페이스 개요

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **인증 방식**：HTTP Header에 `authorization: Bearer {token}`을 포함합니다.
- **요청 헤더**：
  - `accept: application/json`
  - `content-type: application/json`
- **작업（action）**：
  - `generate`：텍스트 프롬프트를 기반으로 이미지 생성
  - `edit`：제공된 이미지를 기반으로 편집
- **모델（model）**（선택 사항）：
  - `nano-banana`（기본값）：Gemini 2.5 Flash Image 기반으로, 속도가 빠르고 비용이 저렴합니다.
  - `nano-banana-2-lite`：Gemini 3.1 Flash Lite Image 기반으로, 1K만 지원하며 이미지 생성 속도가 빠릅니다.
  - `nano-banana-2`：Gemini 3.1 Flash Image Preview 기반으로, Pro급 품질과 Flash급 속도를 제공합니다.
  - `nano-banana-2.1`：차세대 고효율 이미지 모델로, 1K, 2K, 4K 이미지 생성 및 편집을 지원합니다.
  - `nano-banana-pro`：Gemini 3 Pro Image Preview 기반으로, 최고 수준의 품질을 제공합니다.
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：각 모델에 해당하는 공식 채널 버전으로, 이미지 품질과 안정성이 더 뛰어나며 요금 체계가 다릅니다.
- **비동기 콜백**：선택 사항이며, `callback_url`을 통해 작업 완료 알림 및 결과를 수신할 수 있습니다.
- **이미지 수량**：선택 사항이며, `count`를 통해 1~4장을 지정할 수 있습니다. 기본값은 1장입니다. 각 이미지는 독립적인 생성 호출을 통해 완성됩니다. 일반적인 기술적 실패 또는 제공업체의 안전 정책에 따른 거부는 해당 호출에만 영향을 미치며, 나머지 성공한 이미지는 정상적으로 반환됩니다. 실제 성공한 이미지 수에 따라 요금이 부과됩니다.

## 빠른 시작: 이미지 생성（`action=generate`）

**최소 필수 매개변수**：`action`、`prompt`

프롬프트를 기반으로 이미지를 바로 생성하려면 `action`을 `generate`로 설정하고 명확한 `prompt`를 제공하면 됩니다.

### 요청 예시（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### 요청 예시（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### 성공 응답 예시

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### 필드 설명

- `success`：이번 요청의 성공 여부입니다.
- `task_id`：작업 ID입니다.
- `trace_id`：문제 해결에 도움이 되는 호출 추적 ID입니다.
- `count`：요청한 생성 또는 편집 이미지 수량으로, 1~4장을 지원하며 기본값은 1장입니다. `data`에는 생성에 성공한 이미지만 포함되며, 실제 반환된 이미지 수에 따라 요금이 부과됩니다. 각 생성 호출에는 제공업체의 기본 안전 정책이 강제로 적용됩니다. 특정 호출이 거부되더라도 다른 성공한 호출에는 영향을 미치지 않습니다. 모든 호출이 거부되면 403 오류가 반환됩니다.
- `data[]`：결과 목록입니다.
  - `prompt`：이미지 생성에 사용된 프롬프트（반환값에 포함됨）。
  - `image_url`：생성된 이미지의 직접 URL입니다.

> 참고：`/nano-banana/images`는 `action`과 `prompt`만 있으면 이미지를 생성할 수 있습니다.

## 이미지 편집（`action=edit`）

기존 이미지를 기반으로 편집하려면 `action`을 `edit`로 설정하고, `image_urls`를 통해 편집할 이미지 링크 목록（1장 또는 여러 장）을 전달하는 동시에 편집 목표를 설명하는 `prompt`를 제공하면 됩니다.

예를 들어 인물 사진 한 장과 옷 사진 한 장을 제공하여 인물에게 해당 옷을 입히고 싶다면 이미지 링크를 동시에 전달하고 `action`을 `edit`로 지정하면 됩니다. URL은 HTTP URL일 수 있으며, `https` 또는 `http` 프로토콜을 사용하는 공개적으로 접근 가능한 링크이거나 Base64로 인코딩된 이미지일 수도 있습니다. 예: `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### 요청 예시（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### 요청 예시（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### 필드 설명

- `image_urls[]`: 편집할 이미지 URL 목록(공개 인터넷에서 접근 가능해야 함). 여러 장을 전달할 수 있으며, 서비스는 이러한 자료와 `prompt`를 결합하여 편집을 수행합니다.
- 나머지 필드는 '이미지 생성' 응답과 동일합니다.

## 비동기 콜백（선택 사항, 권장）

이미지 생성 또는 편집에는 어느 정도 시간이 걸릴 수 있습니다. 장시간 연결로 리소스를 점유하는 것을 방지하기 위해 `callback_url`을 통한 **Webhook 콜백** 사용을 권장합니다.

1. 요청 본문에 `callback_url`을 추가합니다. 예를 들어 공개 인터넷에서 접근할 수 있고 POST JSON을 지원하는 서버 측 Webhook 주소를 입력합니다.
2. API는 `task_id`가 포함된 응답(또는 기본 결과)을 **즉시 반환**합니다.
3. 작업이 완료되면 플랫폼은 `POST` 방식으로 전체 JSON을 `callback_url`에 전송합니다. `task_id`를 통해 요청과 결과를 연결할 수 있습니다.

**콜백 페이로드 예시**（필드 구조는 동기식 성공 응답과 동일）:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## 오류 처리

호출이 실패하면 표준 오류 형식과 추적 ID가 반환됩니다. 일반적인 오류는 다음과 같습니다.

- **400 `token_mismatched`**: 요청이 유효하지 않거나 매개변수에 오류가 있습니다.
- **400 `api_not_implemented`**: 인터페이스가 구현되지 않았습니다(지원팀에 문의하세요).
- **401 `invalid_token`**: 인증에 실패했거나 Token이 누락되었습니다.
- **403 `forbidden`**: 제공업체의 기본 보안 정책에 따라 요청 또는 생성 결과가 거부되었습니다. 해당 호출은 이미지를 반환하지 않으며 요금도 청구되지 않습니다. 여러 이미지 요청의 경우 성공한 다른 호출은 반환되고 요금이 청구될 수 있습니다.
- **429 `too_many_requests`**: 요청 빈도 제한을 초과했습니다.
- **500 `api_error`**: 서버 측 오류입니다.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 매개변수 비교 및 참고 사항

- **필수 항목**: `action`, `prompt`
- **편집 전용**: `image_urls`(배열, 최소 1개 항목)
- **선택 항목**: `model`(기본값 `nano-banana`, 선택 가능: `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; `nano-banana-2.1`을 제외한 모델에는 각각 대응하는 `:official` 공식 채널 버전도 있음), `aspect_ratio`(`auto` 또는 `1:1`, `16:9`와 같은 구체적인 가로세로 비율), `resolution`(`1K`, `2K`, `4K`와 같은 해상도; `nano-banana-2-lite`는 `1K`만 지원), `callback_url`(비동기 콜백용)
- **Headers**: 반드시 `authorization: Bearer {token}`을 제공해야 합니다. `accept`는 `application/json`으로 설정하는 것을 권장합니다.
- **이미지 접근성**: `image_urls`는 공개 인터넷에서 접근할 수 있는 직접 링크(HTTP/HTTPS)여야 하며, HTTPS 사용을 권장합니다.
- **멱등성 및 추적**: 문제 해결 및 결과 연결을 위해 `task_id`와 `trace_id`를 보관하세요.

`"aspect_ratio": "auto"`를 명시적으로 전달하면 프롬프트에 포함된 비율, 방향 또는 레이아웃에 따라 가장 가까운 사전 설정을 선택합니다. 이미지 생성과 편집 모두에 적용됩니다. 예를 들어 프롬프트에 'YouTube 썸네일'이라고 작성하면 `16:9`를 선택할 수 있습니다. 프롬프트에 크기 요구 사항이 없거나 자동 판단을 사용할 수 없는 경우, 텍스트-이미지 생성은 기본 화면 비율을 사용하고 이미지 편집은 첫 번째 참조 이미지를 따르며 지원되는 비율 중 가장 가까운 비율을 사용합니다. 해당 필드를 생략하면 기본 화면 비율 또는 참조 이미지의 비율이 사용됩니다. 이미 명확한 화면 비율 요구 사항이 있는 경우에는 구체적인 비율을 직접 전달하세요.
