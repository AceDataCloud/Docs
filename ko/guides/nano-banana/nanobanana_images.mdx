본 문서는 Nano Banana Images API의 연동 및 사용 방법을 소개합니다. 이 인터페이스는 두 가지 기능을 지원합니다: **이미지 생성(generate)** 및 **이미지 편집(edit)**.

## 신청 절차

Nano Banana Images API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 예비용으로 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인 또는 가입하지 않았다면 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스별로 별도 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## 인터페이스 개요

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **인증 방식**：HTTP Header에 `authorization: Bearer {token}` 포함
- **요청 헤더**：
  - `accept: application/json`
  - `content-type: application/json`
- **작업(action)**：
  - `generate`：텍스트 프롬프트를 기반으로 이미지 생성
  - `edit`：지정된 이미지를 기반으로 편집
- **모델(model)**（선택 사항）：
  - `nano-banana`（기본값）：Gemini 2.5 Flash Image 기반, 빠른 속도와 낮은 비용
  - `nano-banana-2-lite`：Gemini 3.1 Flash Lite Image 기반, 1K만 지원, 빠른 생성 속도
  - `nano-banana-2`：Gemini 3.1 Flash Image Preview 기반, Pro급 품질 + Flash 속도
  - `nano-banana-pro`：Gemini 3 Pro Image Preview 기반, 최고 품질
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：각 모델의 공식 채널 버전으로, 화질과 안정성이 더 우수하며 요금이 다름
- **비동기 콜백**：선택 사항이며, `callback_url`을 통해 작업 완료 알림 및 결과 수신
- **이미지 수량**：선택 사항이며, `count`를 통해 1–4장을 지정할 수 있고 기본값은 1장입니다. 각 이미지는 독립적인 생성 호출로 완료됩니다. 일반적인 기술 실패 또는 제공업체의 안전 거부는 해당 호출에만 영향을 미치며, 나머지 성공 이미지는 정상적으로 반환되고 실제 성공 장수에 따라 과금됩니다.

## 빠른 시작: 이미지 생성（`action=generate`）

**최소 필수 파라미터**：`action`、`prompt`
프롬프트를 기반으로 바로 이미지를 생성하려는 경우, `action`을 `generate`로 설정하고 명확한 `prompt`를 제공하면 됩니다.

### 요청 예시（cURL）

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### 요청 예시（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### 성공 반환 예시

```json
{
  "success": true,
  "task_id": "70e6931b-6e34-43db-9e36-8765e2809d04",
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
      "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }
  ]
}
```

### 필드 설명

- `success`：이번 요청의 성공 여부입니다.
- `task_id`：작업 ID입니다.
- `trace_id`：문제 해결에 편리한 추적 ID입니다.
- `count`：생성 또는 편집을 요청하는 이미지 수량으로, 1–4를 지원하며 기본값은 1입니다. `data`에는 생성에 성공한 이미지만 포함되며, 실제 반환 장수에 따라 과금됩니다. 각 생성 호출은 제공업체의 네이티브 안전 정책을 강제로 사용합니다. 특정 호출이 거부되어도 다른 성공 호출에는 영향을 미치지 않으며, 모든 호출이 거부되면 403이 반환됩니다.
- `data[]`：결과 목록입니다.
  - `prompt`：생성에 사용된 프롬프트(에코)입니다.
  - `image_url`：생성된 이미지의 직접 URL입니다.

> 참고: `/nano-banana/images`는 `action`과 `prompt`만으로 이미지를 생성할 수 있습니다.

## 이미지 편집（`action=edit`）

기존 이미지를 기반으로 편집하려는 경우, `action`을 `edit`로 설정하고 `image_urls`를 통해 편집할 이미지 링크 목록(한 장 또는 여러 장)을 전달하며, 편집 목표를 설명하는 `prompt`를 함께 제공하세요.

예를 들어 여기에서는 인물 사진 한 장과 의류 사진 한 장을 제공하여 인물이 해당 옷을 입도록 할 수 있습니다. 이미지 링크를 동시에 전달하고 action을 `edit`로 지정하면 됩니다. URL은 `https` 또는 `http` 프로토콜의 공개적으로 접근 가능한 링크인 HTTP URL일 수도 있고, `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`와 같은 Base64 인코딩 이미지일 수도 있습니다.

### 요청 예시（cURL）
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### 요청 예시（Python）

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

  "task_id": "93f11baf-347b-4bb4-9520-8653cb46d6a3",
  "trace_id": "a9063166-26ed-4451-85b5-54e896817c69",

### 필드 설명

- `image_urls[]`: 편집할 이미지 URL 목록(반드시 공개 인터넷에서 접근 가능해야 함). 여러 장을 전달할 수 있으며, 서비스는 이러한 소재와 `prompt`를 결합하여 편집을 완료합니다.
- 기타 필드는 「이미지 생성」 반환과 동일합니다.

## 비동기 콜백（선택 사항, 권장）

생성 또는 편집에는 일정 시간이 필요할 수 있습니다. 장기 연결이 리소스를 점유하는 것을 방지하기 위해 `callback_url`을 통해 **Webhook 콜백**을 사용하는 것이 좋습니다:

1. 요청 본문에 `callback_url`을 추가합니다. 예를 들어, 서버 측 Webhook 주소(공개 인터넷에서 접근 가능해야 하며, POST JSON을 지원해야 함)입니다.
2. API는 `task_id`를 포함한 응답(또는 기본 결과를 포함한 응답)을 **즉시 반환**합니다.
3. 작업이 완료되면 플랫폼은 `POST` 방식으로 전체 JSON을 `callback_url`로 전송합니다. `task_id`를 통해 요청과 결과를 연결할 수 있습니다.

**콜백 페이로드 예시**（필드 구조는 동기 성공 반환과 동일）:

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## 오류 처리

호출에 실패하면 표준 오류 형식과 추적 ID가 반환됩니다. 일반적인 오류는 다음과 같습니다:

- **400 `token_mismatched`**: 요청이 올바르지 않거나 매개변수 오류입니다.
- **400 `api_not_implemented`**: 인터페이스가 구현되지 않았습니다(지원팀에 문의하세요).
- **401 `invalid_token`**: 인증에 실패했거나 Token이 없습니다.
- **403 `forbidden`**: 제공업체의 네이티브 보안 정책이 요청 또는 생성 결과를 거부했습니다. 이 호출은 이미지를 반환하지 않으며 요금도 부과되지 않습니다. 여러 이미지 요청의 경우 다른 성공한 호출은 여전히 반환되고 요금이 부과될 수 있습니다.
- **429 `too_many_requests`**: 요청 빈도가 제한을 초과했습니다.
- **500 `api_error`**: 서버 측 예외입니다.

### 오류 응답 예시

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 매개변수 대조 및 주의 사항

- **필수**: `action`, `prompt`
- **편집 전용**: `image_urls`(배열, 최소 1개 항목)
- **선택 사항**: `model`(기본값 `nano-banana`, 선택 가능: `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-pro`, 또는 해당 `:official` 공식 채널 버전), `aspect_ratio`(가로세로 비율, 예: `1:1`, `16:9`), `resolution`(해상도, 예: `1K`, `2K`, `4K`; `nano-banana-2-lite`는 `1K`만 지원), `callback_url`(비동기 콜백용)
- **Headers**: 반드시 `authorization: Bearer {token}`을 제공해야 합니다. `accept`는 `application/json`으로 설정하는 것이 좋습니다.
- **이미지 접근성**: `image_urls`는 반드시 공개 인터넷에서 접근 가능한 직접 링크(HTTP/HTTPS)여야 하며, HTTPS 사용을 권장합니다.
- **멱등성 및 추적**: 장애 분석 및 결과 연결을 위해 `task_id`와 `trace_id`를 보관하세요.
