본 인터페이스는 [Fish Audio 공식 Model API](https://docs.fish.audio/resources/api-reference/model)를 기반으로 하며, **오디오 샘플을 기반으로 장기간 재사용할 수 있는 복제 음성 모델을 생성**하는 데 사용됩니다. 주소는 `POST https://api.acedata.cloud/fish/model`입니다.

> 참고 음성을 임시로만 사용해야 하는 경우 모델을 생성할 필요 없이, [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts)의 `references`를 직접 사용하여 일회성 즉시 복제를 할 수 있습니다. 기존 음색을 페이지네이션으로 검색하려면 [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)를 참고하세요. `_id`로 단일 음색 상세 정보를 조회하려면 [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)를 참고하세요.

## 신청 절차

Fish Model API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 보관하세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 가입하지 않은 경우 로그인 페이지로 자동 이동하여 가입 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 반환됩니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스별로 별도 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있으며, 크레딧이 부족한 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공통 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## 요청 본문 필드

| 필드                      | 유형       | 필수  | 설명                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | 예   | 콘솔 목록에서 식별하기 위한 음색 이름입니다.                                                             |
| `voices`                | string   | 예   | 오디오 샘플의 HTTP(S) URL(**단일 문자열**이며 배열이 아님)입니다. 본 인터페이스는 multipart/바이너리 업로드를 지원하지 않으므로, 먼저 오디오를 공개 접근 가능한 임의의 객체 스토리지에 업로드하세요. |
| `description`           | string   | 아니요   | 음색 설명입니다.                                                                         |
| `cover_image`           | string   | 아니요   | 커버 이미지 HTTP(S) URL입니다.                                                              |
| `tags`                  | string[] | 아니요   | 공용 라이브러리 검색 태그입니다. 예: `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | 아니요   | 샘플에 대응하는 참조 텍스트입니다(발음 교정용).                                                           |
| `enhance_audio_quality` | boolean  | 아니요   | 학습 전에 샘플에 대해 음질 향상을 수행할지 여부입니다.                                                                |
| `generate_sample`       | boolean  | 아니요   | 학습 완료 후 예시 오디오를 자동 생성할지 여부입니다.                                                            |

> 음색 모델에 대한 자세한 정보는 [Fish 공식 문서](https://docs.fish.audio/resources/api-reference/model)를 참고하세요.

> 생성된 음색은 장기간 공개 저장되며, 다른 사용자가 검색하고 사용할 수 있습니다. `visibility`를 전달할 필요가 없으며, `private` 또는 `unlist`를 전달하더라도 현재 인터페이스는 이에 따라 공개 범위를 변경하지 않습니다.

## 예시: 공개 클론 음색 만들기

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "我的克隆音色",
    "description": "用一段播客录音克隆的中文音色",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> 참고: `voices`는 배열이 아닌 **문자열**(단일 오디오 URL)이어야 합니다. `["..."]` 전달은 지원되지 않습니다. `.mp3` 또는 `.wav` 접미사가 포함된, 공개적으로 다운로드 가능한 직접 링크를 사용하는 것이 좋습니다.

성공 응답은 Fish 플랫폼의 ModelEntity 객체를 직접 반환합니다(아래 예시는 실제 테스트한 최소 사용 가능 음색이며, 가독성을 위해 일부 긴 필드는 생략했습니다).

```json
{
  "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
  "type": "tts",
  "title": "copilot-smoke-test",
  "description": "smoke test from api.acedata.cloud",
  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [
    {
      "title": "Default Sample",
      "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",

      "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
    }
  ],
  "created_at": "2026-05-10T03:52:55.601000Z",
  "updated_at": "2026-05-10T03:52:55.601000Z",
  "languages": ["zh"],

```

`_id`는 이후 [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts)에서 `reference_id` 필드의 값으로 사용할 수 있으며, 해당 클론 음색으로 음성 합성을 수행하는 데 사용됩니다:

성공적으로 생성된 음색은 공개적으로 저장됩니다. [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)의 `self=true`를 통해 현재 호출 사용자가 이 플랫폼에서 생성한 음색을 조회할 수 있습니다. `self=true`는 목록만 필터링하며, 다른 사용자의 해당 음색 사용을 제한하지 않습니다.

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "你好，这是一段使用我刚创建的克隆音色合成的语音。",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## 샘플 요구사항

권장 사항([Fish 공식 문서](https://docs.fish.audio/resources/api-reference/model) 참조):

- 길이는 30초 이상을 권장하며, 5분 이내가 가장 좋습니다. 10분을 초과하면 추가적인 효과는 크지 않습니다.
- 샘플링 레이트는 16kHz 이상이며, 모노 또는 스테레오 모두 가능합니다.
- 콘텐츠는 가능한 한 깨끗해야 합니다. 배경 음악, 에코, 뚜렷한 환경 소음이 없고 동일한 화자여야 합니다.
- `mp3` / `wav` 형식을 권장합니다.

샘플 품질이 확실하지 않은 경우 `enhance_audio_quality: true`도 함께 전달하여 음질 향상을 활성화할 수 있습니다.

## 과금 안내
음색 복제 모델 생성(`POST /fish/model`)은 무료이며, 어떠한 비용도 부과되지 않습니다. 음색 조회 인터페이스([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) 역시 과금되지 않습니다. 비용은 이후 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts)를 호출하여 음성을 합성할 때 사용량에 따라 발생합니다.

## 오류 처리

- `400 token_mismatched`: 요청 파라미터가 누락되었거나 올바르지 않습니다(가장 흔한 경우는 `voices`가 URL이 아니거나 배열로 전달된 경우입니다).
- `400`: 참조 오디오를 다운로드할 수 없거나, 길이가 너무 짧거나, 형식을 인식할 수 없는 경우 오디오 URL과 파일 형식을 확인하세요.
- `401 invalid_token`: 인증 token이 없거나 유효하지 않습니다.
- `429 too_many_requests`: 계정 속도 제한이 발생했습니다.
- `500 api_error`: 서버 내부 오류입니다.

오류 응답 예시:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices is required and must be an HTTP(S) URL pointing to an audio file"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 결론

이 인터페이스를 호출하려면 공개적으로 접근 가능한 샘플 오디오 URL 하나를 준비하여 `voices` 필드에 넣기만 하면 `_id`를 얻을 수 있고, 이후 이를 `/fish/tts`의 `reference_id`에 전달하면 엔드투엔드 「복제 → 합성」이 완료됩니다. 흔한 주의점은 `voices`가 반드시 문자열이어야 하며 배열일 수 없다는 것입니다.

## MCP를 통해 음색 생성 및 재사용

Fish MCP에서
`fish_create_model(title="내 음색", voices="https://example.com/authorized-voice.wav")`를 호출합니다.
`voices`는 단일 HTTP(S) 오디오 URL이며, `description`, `cover_image`, `tags`,
`texts`, `enhance_audio_quality`, `generate_sample`도 전달할 수 있습니다.

이 도구는 공개 음색을 장기간 저장하며, 다른 사용자가 발견하고 사용할 수 있습니다. 따라서 처리 및 공개가 허가된
오디오 자료만 사용하세요. 도구에는 비공개 또는 공개하지 않는 옵션이 없습니다. 생성에 성공하면 반환되는 `_id`는
`fish_generate_audio`의 `reference_id`에 사용되며, `fish_list_models(self=true)`를 통해 직접
저장한 음색을 조회할 수 있습니다. 일회성 참조 음성만 필요한 경우에는 `fish_generate_audio`의 `references`를 사용하면 되며,
장기 음색을 생성할 필요가 없습니다.
