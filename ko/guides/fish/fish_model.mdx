본 인터페이스는 [Fish Audio 공식 Model API](https://docs.fish.audio/resources/api-reference/model)를 기반으로 하여 **음성 샘플을 기반으로 새로운 클론 음색을 생성**하는 데 사용됩니다. 주소는 `POST https://api.acedata.cloud/fish/model`입니다.

> 기존 음색의 페이지 검색은 [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query)를 참조하십시오; `_id`로 단일 음색 세부정보를 조회하려면 [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)를 참조하십시오.

## 신청 절차

Fish Model API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 받아야 합니다. 이를 보관하십시오.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

로그인 또는 등록하지 않은 경우 자동으로 로그인 페이지로 리디렉션되어 등록 및 로그인을 초대합니다. 완료 후 현재 페이지로 자동으로 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 각 서비스에 대해 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 한도가 제공되어 무료로 체험할 수 있습니다; 한도가 부족할 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 일반 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## 요청 본문 필드

| 필드                      | 유형       | 필수  | 설명                                                                            |
| ----------------------- | -------- | --- | ----------------------------------------------------------------------------- |
| `title`                 | string   | 예   | 음색 이름, 콘솔 목록에서 식별하는 데 사용됩니다.                                                             |
| `voices`                | string   | 예   | 음성 샘플의 HTTP(S) URL（**단일 문자열**，배열이 아님）。본 인터페이스는 multipart/이진 업로드를 지원하지 않으므로, 음성을 공개적으로 접근 가능한 객체 저장소에 먼저 저장해야 합니다. |
| `description`           | string   | 아니오   | 음색 설명.                                                                         |
| `cover_image`           | string   | 아니오   | 커버 이미지 HTTP(S) URL.                                                              |
| `tags`                  | string[] | 아니오   | 공용 라이브러리 검색 태그, 예: `["male","narration","zh"]`.                                       |
| `texts`                 | string[] | 아니오   | 샘플에 해당하는 참조 텍스트（발음 교정을 위해 사용됨）。                                                           |
| `enhance_audio_quality` | boolean  | 아니오   | 훈련 전에 샘플의 음질을 향상시킬지 여부.                                                                |
| `generate_sample`       | boolean  | 아니오   | 훈련 완료 후 자동으로 샘플 음성을 생성할지 여부.                                                            |

> 필드는 상위와 완전히 일치하며, [Fish 공식 문서](https://docs.fish.audio/resources/api-reference/model)를 참조하십시오.

## 예시: 개인 클론 음색 생성

```shell
curl -X POST 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "title": "내 클론 음색",
    "description": "한 편의 팟캐스트 녹음을 기반으로 클론한 중국어 음색",
    "voices": "https://example.com/sample-voice.mp3",
    "cover_image": "https://cdn.acedata.cloud/e724d7f13d.png"
  }'
```

> 주의: `voices`는 **문자열**(단일 음성 URL)이어야 하며, 배열이 아닙니다. `["..."]`로 전달하면 상위에서 거부됩니다.

성공적인 응답은 Fish 플랫폼의 ModelEntity 객체를 직접 반환합니다(아래 예시는 우리가 테스트한 최소 사용 가능한 음색으로, 읽기 편하도록 일부 긴 필드를 삭제했습니다):

```json
{
  "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
  "type": "tts",
  "title": "copilot-smoke-test",
  "description": "api.acedata.cloud에서의 스모크 테스트",
  "cover_image": "coverimage/e5c6db52c3ed417f9cb2e5a33fb04667",
  "train_mode": "fast",
  "state": "trained",
  "tags": [],
  "samples": [
    {
      "title": "기본 샘플",

      "task_id": "6a1bf398dfae49dca0e23159214342a0",
      "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"

```

`_id`는 이후 [Fish TTS API](https://platform.acedata.cloud/documents/fish-tts)에서 `reference_id` 필드의 값으로 사용되어 해당 클론 음색으로 음성 합성을 수행하는 데 사용됩니다:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "안녕하세요, 이것은 제가 방금 생성한 클론 음색으로 합성한 음성입니다.",
    "reference_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
    "format": "mp3"
  }'
```

## 샘플 요구 사항

경험치(상위와 일치하며, [Fish 공식 문서](https://docs.fish.audio/resources/api-reference/model)를 참조할 수 있습니다):

- 길이는 30초 이상, 5분 이내가 가장 효과적입니다; 10분을 초과하면 한계 수익이 크지 않습니다.
- 샘플링 주파수는 16 kHz 이상, 단일 채널 또는 스테레오 모두 가능합니다.
- 내용은 최대한 깨끗해야 합니다: 배경 음악, 에코, 명백한 환경 소음이 없어야 하며; 동일한 화자여야 합니다.
- 형식은 `mp3` / `wav`를 권장합니다.

샘플 품질에 대한 확신이 없다면 `enhance_audio_quality: true`를 함께 전달하여 상위에서 먼저 음질 향상을 수행하도록 할 수 있습니다.

## 요금 설명

음색 클론 모델 생성(`POST /fish/model`)은 무료이며, 어떠한 비용도 부과되지 않습니다; 음색 조회 인터페이스([Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query), [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)) 또한 요금이 부과되지 않습니다. 비용은 이후 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts)에서 음성을 합성할 때 사용량에 따라 발생합니다.

## 오류 처리

- `400 token_mismatched`: 요청 매개변수가 누락되었거나 유효하지 않음(가장 흔한 경우는 `voices`가 URL이 아니거나 배열로 전달됨).
- `401 invalid_token`: 인증 토큰이 존재하지 않거나 유효하지 않음.
- `429 too_many_requests`: 계정 속도 제한이 발생함.
- `500 api_error`: 서버 내부 오류.

오류 응답 예시:
```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "voices는 필수이며 오디오 파일을 가리키는 HTTP(S) URL이어야 합니다"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 결론

이 API를 호출하려면 공개적으로 접근 가능한 샘플 오디오 URL을 준비하고, 이를 `voices` 필드에 넣으면 `_id`를 얻을 수 있으며, 이를 `/fish/tts`의 `reference_id`에 제공하면 엔드 투 엔드의 "클론 → 합성"이 완료됩니다. 일반적인 함정은 `voices`가 문자열이어야 하며 배열이 될 수 없다는 것입니다.
