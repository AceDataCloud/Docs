본 인터페이스는 [Fish Audio 공식 Model API](https://docs.fish.audio/resources/api-reference/model)를 기반으로 하며, **Fish 공개 음색 라이브러리 또는 현재 계정의 복제 음색을 페이지네이션하여 조회**하는 데 사용됩니다. 주소는 `GET https://api.acedata.cloud/fish/model`입니다.

> 음색 생성은 [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model)를 참고하세요. `_id`로 단일 음색 상세 정보를 조회하려면 [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get)를 참고하세요.

## 신청 절차

Fish Model API를 사용하려면 먼저 [Ace Data Cloud 콘솔](https://platform.acedata.cloud/console/applications)에서 API Token을 발급받아 보관해 두세요.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

아직 로그인하거나 등록하지 않은 경우 로그인 페이지로 자동 이동하여 등록 및 로그인을 안내하며, 완료 후 현재 페이지로 자동 돌아옵니다.

**하나의 API Token으로 플랫폼의 모든 서비스를 호출할 수 있으며, 서비스마다 별도로 신청할 필요가 없습니다.** 최초 신청 시 무료 크레딧이 제공되어 무료로 체험할 수 있습니다. 크레딧이 부족한 경우 [콘솔](https://platform.acedata.cloud/console/coin)에서 공용 잔액을 충전할 수 있습니다.

> 📘 전체 문서: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## 쿼리 매개변수

| 매개변수             | 유형    | 기본값 | 설명                                                                                  |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------- |
| `page_size`      | integer | 10   | 페이지당 항목 수.                                                                            |
| `page_number`    | integer | 1    | 1부터 시작하는 페이지 번호.                                                                          |
| `title`          | string  | —    | 제목으로 부분 일치 검색.                                                                      |
| `tag`            | string  | —    | 단일 태그로 필터링.                                                                      |
| `self`           | boolean | —    | `true`인 경우 현재 호출 계정이 이 플랫폼을 통해 생성하고 저장한 음색만 반환합니다.                                |
| `author_id`      | string  | —    | 음색 작성자 ID로 필터링.                                                                  |
| `language`       | string  | —    | 음색 언어로 필터링합니다. 예: `en`, `zh`, `es`.                                                  |
| `title_language` | string  | —    | 공개 음색 라이브러리에서 제목 언어로 필터링.                                                        |
| `sort_by`        | string  | —    | 정렬 필드. `self=true`인 경우 `created_at`, `task_count`를 지원합니다.                              |

## 예시 1: 기본 페이지네이션 (`page_size` 기준)

```shell

  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## 예시 2: 제목으로 퍼지 검색 (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

반환값(실측):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],
      "visibility": "public"
    }
  ],
  "has_more": null
}
```

`title`은 «전역 퍼지 매칭»이므로 Fish 공개 라이브러리의 모든 음색(자신의 음색만이 아님)을 동시에 검색합니다.

## 예시 3: 직접 생성한 음색만 나열 (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

반환 예시:

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
          "task_id": "6a1bf398dfae49dca0e23159214342a0",
          "audio": "https://platform.r2.fish.audio/task/6a1bf398dfae49dca0e23159214342a0.mp3"
        }
      ],
      "created_at": "2026-05-10T03:52:55.601000Z",
      "author": {
        "_id": "780f2b2f862d41a08c0507bbbda77eb6",
        "nickname": "Penny Conrad"
      }
    }
  ],
  "has_more": false
}
```
`self=true`은 실제 호출 계정 기준으로 본 플랫폼을 통해 생성 및 저장된 음색을 나열합니다. 동일한 계정이 서로 다른 API Token으로 생성한 음색도 함께 나열됩니다. 결과는 생성 시간 역순으로 페이지네이션되며, `author_id`를 사용하여 이러한 음색의 작성자 ID를 추가로 필터링할 수 있습니다. 이 파라미터는 목록만 필터링하며, 음색은 여전히 공개적으로 사용할 수 있습니다.

`self=true`는 `title_language`를 지원하지 않습니다. 제목 언어로 검색하려면 공개 음색 라이브러리를 조회하세요.

## 예시 4: 언어 + 태그로 필터링

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> `tag`는 매칭 기준이 비교적 느슨합니다. 일치 결과가 0개이면 `title` 부분 일치 검색을 사용하는 것이 좋습니다.

## 응답 필드

`items[]`의 각 항목은 완전한 ModelEntity 객체이며, 자주 사용되는 필드는 다음과 같습니다.

| 필드            | 유형       | 설명                                        |
| ------------- | -------- | ----------------------------------------- |
| `_id`         | string   | 음색 ID이며, `/fish/tts`에서 `reference_id`의 값으로 사용됩니다. |
| `type`        | string   | 모델 유형이며, 일반적으로 `tts`입니다.                           |
| `title`       | string   | 음색 이름입니다.                                     |
| `description` | string   | 음색 설명입니다.                                     |
| `state`       | string   | 학습 상태: `trained`는 사용 가능함을 나타냅니다.                      |
| `tags`        | string[] | 공개 라이브러리 태그입니다.                                    |
| `languages`   | string[] | 음색이 잘하는 언어입니다.                                  |
| `visibility`  | string   | `public` 또는 `private`입니다.                     |
| `samples`     | object[] | 사전 설정 샘플(`audio` 직접 링크 포함)입니다.                       |
| `like_count`  | integer  | 공개 라이브러리 좋아요 수입니다.                                   |
| `task_count`  | integer  | 누적 합성 횟수입니다.                                   |
| `author`      | object   | 음색 작성자 정보: `_id` / `nickname` / `avatar`입니다.     |
| `total`（최상위）   | integer  | 조건을 충족하는 총 항목 수입니다.                                 |
| `has_more`    | boolean? | `self=true`일 때는 불리언 값이며, 공개 음색 라이브러리 조회에서는 `null`일 수 있습니다.      |

## 과금 안내

본 인터페이스는 과금되지 않습니다. 음색 목록을 페이지네이션하여 조회하는 것은 무료 작업입니다. 음색 생성([Fish Model Create](https://platform.acedata.cloud/documents/fish-model))도 무료이며, 비용은 [Fish TTS](https://platform.acedata.cloud/documents/fish-tts)를 호출하여 음성을 합성할 때만 사용량에 따라 발생합니다.

## 오류 처리

- `400 token_mismatched`: 요청 파라미터가 누락되었거나 유효하지 않습니다.
- `401 invalid_token`: 인증 token이 존재하지 않거나 유효하지 않습니다.
- `429 too_many_requests`: 계정 속도 제한이 발생했습니다.
- `500 api_error`: 서버 내부 오류입니다.

오류 응답 예시:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## 결론

Fish 공개 라이브러리에서 음색을 선택하여 `/fish/tts`의 `reference_id`에 제공하려면, 먼저 본 인터페이스에서 `title` / `tag` / `language`를 함께 사용하여 검색하고, 대상 `_id`를 찾은 다음 [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get)으로 샘플을 가져와 들어 보세요. 직접 생성한 음색을 나열하려면 `self=true`를 전달하면 됩니다.
