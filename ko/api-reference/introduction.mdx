## 기본 URL

모든 API 엔드포인트의 기본 주소:

```
https://api.acedata.cloud
```

## 인증

모든 엔드포인트는 Bearer Token 인증이 필요합니다:

```
Authorization: Bearer YOUR_API_TOKEN
```

## 온라인 테스트

본 참조 문서의 각 엔드포인트는 대화형 샌드박스를 포함합니다. API Token을 입력하면 브라우저에서 직접 요청을 테스트할 수 있습니다.

<Note title="Tip">
  [platform.acedata.cloud](https://platform.acedata.cloud)에서 API Token을 받으세요.
</Note>
