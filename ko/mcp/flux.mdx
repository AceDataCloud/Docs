[MCP(Model Context Protocol)](https://modelcontextprotocol.io)는 Anthropic에서 출시한 모델 컨텍스트 프로토콜로, Claude, GPT 등 AI 모델이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있도록 합니다. AceData Cloud에서 제공하는 Flux MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 직접 AI 이미지를 생성하고 편집할 수 있습니다.

## 기능 개요

Flux MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **텍스트로 이미지 생성** — 텍스트 프롬프트를 통해 고품질 이미지 생성
- **이미지 편집** — 텍스트 명령어 기반 기존 이미지 편집
- **다중 모델 지원** — Flux Pro, Flux Dev, Flux Schnell, Flux Kontext 등 다양한 모델 지원
- **모델 조회** — 사용 가능한 모든 모델과 그 기능 확인
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 확인

## 사전 준비

사용 전에 AceData Cloud API Token을 발급받아야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud)에 가입 또는 로그인
2. [Flux Images API](https://platform.acedata.cloud/documents/flux-images) 페이지로 이동
3. 「Acquire」를 클릭하여 API Token 발급 (첫 신청 시 무료 크레딧 제공)

## 설치 및 설정

### 방법 1: pip 설치 (권장)

```bash
pip install mcp-flux-pro
```

### 방법 2: 소스코드 설치

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

설치 완료 후 `mcp-flux-pro` 명령어로 서비스를 시작할 수 있습니다.

## Claude Desktop에서 사용하기

Claude Desktop 설정 파일 편집:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 설정을 추가하세요:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

`uvx` 사용 시 (사전 패키지 설치 불필요):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

설정 저장 후 Claude Desktop을 재시작하면 대화 중 Flux 관련 도구를 사용할 수 있습니다.

## VS Code / Cursor에서 사용하기

프로젝트 루트 디렉터리에 `.vscode/mcp.json` 파일 생성:

```json
{
  "servers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

또는 `uvx` 사용:

```json
{
  "servers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

## 사용 가능한 도구 목록

| 도구명 | 설명 |
|--------|------|
| `flux_generate_image` | 텍스트 프롬프트로 이미지 생성 |
| `flux_edit_image` | 텍스트 명령어로 기존 이미지 편집 |
| `flux_get_task` | 단일 작업 상태 조회 |
| `flux_get_tasks_batch` | 작업 상태 일괄 조회 |
| `flux_list_models` | 사용 가능한 모든 모델과 기능 나열 |
| `flux_list_actions` | 사용 가능한 모든 도구 및 워크플로우 예시 나열 |

## 사용 예시

설정 완료 후 AI 클라이언트에서 자연어로 다음과 같이 기능을 호출할 수 있습니다:

- 「Flux로 사이버펑크 스타일의 도시 야경 이미지를 생성해줘」
- 「이 사진의 배경을 해변으로 바꿔줘」
- 「Flux Kontext Pro 모델로 이 이미지를 편집해서 옷 색상을 빨간색으로 바꿔줘」
- 「사용 가능한 모든 Flux 모델을 나열해줘」
