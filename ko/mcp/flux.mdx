[MCP(Model Context Protocol)](https://modelcontextprotocol.io)는 Anthropic이 출시한 모델 컨텍스트 프로토콜로, AI 모델(Claude, GPT 등)이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있도록 합니다. AceData Cloud에서 제공하는 Flux MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 AI 이미지를 직접 생성하고 편집할 수 있습니다.

## 기능 개요

Flux MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **텍스트로 이미지 생성** — 텍스트 프롬프트를 통해 고품질 이미지 생성
- **이미지 편집** — 텍스트 지침을 기반으로 기존 이미지 편집
- **다중 모델 지원** — Flux Pro, Flux Dev, Flux 2, Flux Kontext 등 다양한 모델 지원
- **모델 조회** — 사용 가능한 모든 모델 및 해당 기능 확인
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 가져오기

## 사전 준비

사용하기 전에 AceData Cloud API Token을 가져와야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud)에 가입하거나 로그인합니다
2. [Flux Images API](https://platform.acedata.cloud/documents/flux-images) 페이지로 이동합니다
3. 「Acquire」를 클릭하여 API Token을 가져옵니다(첫 신청 시 무료 크레딧 제공)

## 방법 1: 호스팅 MCP Server 사용(권장, 설치 불필요)

AceData Cloud는 이미 **Flux MCP Server**를 클라우드에 호스팅하고 있으므로, **로컬에 어떤 종속성도 설치할 필요 없이** AI 클라이언트에 아래 URL을 직접 입력하면 사용할 수 있습니다:

```
https://flux.mcp.acedata.cloud/mcp
```

인증 방식: 요청 헤더에 `Authorization: Bearer 당신의 API Token`을 추가하면 됩니다(Claude.ai는 OAuth를 통해 자동으로 완료하므로 Token을 수동으로 입력할 필요가 없습니다).

### Claude.ai(웹 버전, OAuth 로그인, 가장 간단함)

1. [Claude.ai](https://claude.ai)를 엽니다 → 왼쪽 하단 **Customize** → **Connectors** → **Add More**
2. URL에 다음을 입력합니다: `https://flux.mcp.acedata.cloud/mcp`
3. OAuth 인증 로그인을 완료합니다(AceData Cloud 로그인 페이지로 자동 이동)
4. 대화 인터페이스로 돌아가면 도구를 사용할 수 있습니다

### Claude Desktop

구성 파일을 편집합니다:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

저장한 후 Claude Desktop을 재시작하면 적용됩니다.

### Claude Code(터미널 명령줄)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### 기타 MCP 지원 클라이언트

MCP Streamable HTTP 프로토콜을 지원하는 모든 클라이언트(Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant 등)는 아래 두 항목을 입력하여 연동할 수 있습니다:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer 당신의 API Token`

## 방법 2: 로컬 실행(pip / uvx 설치)

오프라인 실행, 코드 사용자 지정 또는 사내망 배포가 필요한 경우 MCP Server를 로컬에 설치하고 stdio를 통해 시작할 수 있습니다.

### 설치

pip 설치(권장):

```bash
pip install mcp-flux-pro
```

또는 소스 코드 설치:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

설치가 완료되면 `mcp-flux-pro` 명령을 사용하여 서비스를 시작할 수 있습니다.

### Claude Desktop에서 사용(로컬)

Claude Desktop 구성 파일을 편집합니다:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 구성을 추가합니다:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

`uvx`를 사용하는 경우(패키지를 미리 설치할 필요 없음):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

구성을 저장한 후 Claude Desktop을 재시작하면 적용됩니다.

## 사용 가능한 도구 목록

| 도구명                    | 설명                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | 텍스트 프롬프트를 통해 이미지 생성              |
| `flux_edit_image`      | 텍스트 지침을 기반으로 기존 이미지 편집             |
| `flux_generate_video`  | FLUX 3 텍스트/이미지 기반 생성/비디오 생성 및 기존 초안 향상 |
| `flux_get_task`        | 단일 작업 상태 조회                 |
| `flux_get_tasks_batch` | 작업 상태 일괄 조회                 |
| `flux_list_models`     | 사용 가능한 모든 모델 및 해당 기능 나열             |
| `flux_list_actions`    | 사용 가능한 모든 도구 및 워크플로 예시 나열           |

## 사용 예시

구성이 완료된 후 AI 클라이언트에서 자연어로 이러한 기능을 직접 호출할 수 있습니다. 예를 들면:

- 「Flux로 사이버펑크 스타일의 도시 야경 한 장을 생성해 줘」
- 「이 사진의 배경을 해변으로 바꿔 줘」
- 「Flux Kontext Pro 모델로 이 이미지를 편집해서 옷 색상을 빨간색으로 바꿔 줘」
- 「사용 가능한 모든 Flux 모델을 나열해 줘」

## 모델 및 크기 제약 사항
`flux-2-flex`, `flux-2-pro`, `flux-2-max` 및 Kontext 모델의 `size`는 반드시
`1:1` 또는 `16:9`와 같은 비율을 사용해야 하며, `1024x1024` 같은 픽셀 크기는 사용할 수 없습니다.
`flux-2-klein`은 생성만 지원하며, `flux_edit_image`의 선택 가능한 모델에 포함되지 않습니다.

`flux_generate_video`는 `request.mode`를 통해 `t2v`, `i2v`, `v2v` 및
`draft_enhance`를 구분하며, 입력은 모드에 따라 표시됩니다. 초안 향상은 자체 임시 `draft_task_id`를 참조해야 합니다.
제출은 기본적으로 비동기이며, 반환된 작업 ID를 보관하고 `flux_get_task`를 사용하여 결과를 읽습니다.
