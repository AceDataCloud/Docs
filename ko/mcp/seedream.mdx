[MCP（Model Context Protocol）](https://modelcontextprotocol.io)는 Anthropic에서 출시한 모델 컨텍스트 프로토콜로, AI 모델(Claude, GPT 등)이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있도록 합니다. AceData Cloud에서 제공하는 Seedream MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 ByteDance Seedream을 사용하여 AI 이미지를 직접 생성하고 편집할 수 있습니다.

## 기능 개요

Seedream MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **텍스트로 이미지 생성** — 텍스트 프롬프트를 통해 고품질 이미지 생성(중/영어 프롬프트 지원)
- **이미지 편집** — 기존 이미지의 스타일, 배경, 속성 등 수정
- **가상 피팅** — 의류를 인물 사진에 착용시키기
- **다중 모델 지원** — Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I 등 모델 지원
- **다양한 해상도** — 1K, 2K, 4K 및 적응형 해상도 지원
- **시드 제어** — seed 파라미터로 재현 가능한 생성 결과 구현
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 확인

## 사전 준비

사용 전 AceData Cloud API Token을 발급받아야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud) 회원가입 또는 로그인
2. [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images) 페이지 접속
3. 「Acquire」 버튼 클릭하여 API Token 발급(첫 신청 시 무료 크레딧 제공)

## 설치 및 설정

### 방법 1: pip 설치(권장)

```bash
pip install mcp-seedream-pro
```

### 방법 2: 소스 코드 설치

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

설치 완료 후 `mcp-seedream-pro` 명령어로 서비스를 시작할 수 있습니다.

## Claude Desktop에서 사용하기

Claude Desktop 설정 파일 편집:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 설정 추가:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

`uvx` 사용 시(사전 패키지 설치 불필요):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

설정 저장 후 Claude Desktop을 재시작하면 Seedream 관련 도구를 대화에서 사용할 수 있습니다.

## VS Code / Cursor에서 사용하기

프로젝트 루트 디렉터리에 `.vscode/mcp.json` 파일 생성:

```json
{
  "servers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

또는 `uvx` 사용 시:

```json
{
  "servers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

## 사용 가능한 도구 목록

| 도구명                      | 설명                      |
|----------------------------|---------------------------|
| `seedream_generate_image`  | 텍스트 프롬프트로 이미지 생성 |
| `seedream_edit_image`      | 기존 이미지 편집 및 수정      |
| `seedream_get_task`        | 단일 작업 상태 조회          |
| `seedream_get_tasks_batch` | 다중 작업 상태 일괄 조회     |
| `seedream_list_models`     | 사용 가능한 모든 모델 및 기능 나열 |
| `seedream_list_sizes`      | 사용 가능한 이미지 크기 및 해상도 옵션 나열 |
