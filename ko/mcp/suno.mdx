[MCP(Model Context Protocol)](https://modelcontextprotocol.io)는 Anthropic이 출시한 모델 컨텍스트 프로토콜로, AI 모델(Claude, GPT 등)이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있도록 합니다. AceData Cloud에서 제공하는 Suno MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 직접 음악과 가사를 생성하고 오디오 프로젝트를 관리할 수 있습니다.

## 기능 개요

Suno MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **음악 생성** — 텍스트 프롬프트를 통해 AI 음악 생성
- **사용자 지정 창작** — 가사, 제목 및 음악 스타일을 완전히 제어
- **곡 이어쓰기** — 임의의 시점부터 기존 곡을 계속 연장
- **커버/리믹스** — 다양한 스타일로 커버 버전 생성
- **가사 생성** — 설명에 따라 구조화된 가사 생성
- **보컬 캐릭터** — 음성 스타일 저장 및 재사용
- **미디어 변환** — MP4, WAV, MIDI, 보컬 분리 등 가져오기
- **스타일 최적화** — 음악 스타일 태그 최적화
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 가져오기

## 사전 준비

사용하기 전에 AceData Cloud API Token을 획득해야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud)에 가입하거나 로그인합니다
2. [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios) 페이지로 이동합니다
3. 「Acquire」를 클릭하여 API Token을 획득합니다(첫 신청 시 무료 크레딧 제공)

## 방법 1: 호스팅 MCP Server 사용(권장, 설치 불필요)

AceData Cloud는 이미 **Suno MCP Server**를 클라우드에 호스팅하고 있으므로, **로컬에 어떤 종속성도 설치할 필요 없이** AI 클라이언트에 아래 URL을 직접 입력하면 사용할 수 있습니다:

```
https://suno.mcp.acedata.cloud/mcp
```

인증 방식: 요청 헤더에 `Authorization: Bearer 당신의 API Token`을 추가하면 됩니다(Claude.ai는 OAuth를 통해 자동으로 완료하므로 Token을 수동으로 입력할 필요가 없습니다).

### Claude.ai(웹 버전, OAuth 로그인, 가장 간단)

1. [Claude.ai](https://claude.ai)를 엽니다 → 왼쪽 하단의 **Customize** → **Connectors** → **Add More**
2. URL에 다음을 입력합니다: `https://suno.mcp.acedata.cloud/mcp`
3. OAuth 인증 로그인을 완료합니다(AceData Cloud 로그인 페이지로 자동 이동)
4. 대화 화면으로 돌아가면 도구를 사용할 수 있습니다

### Claude Desktop

구성 파일을 편집합니다:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

저장한 후 Claude Desktop을 재시작하면 적용됩니다.

### Claude Code(터미널 명령줄)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### 기타 MCP 지원 클라이언트

MCP Streamable HTTP 프로토콜을 지원하는 모든 클라이언트(Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant 등)는 다음 두 항목을 입력하여 연동할 수 있습니다:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer 당신의 API Token`

## 방법 2: 로컬 실행(pip / uvx 설치)

오프라인 실행, 코드 사용자 지정 또는 사내 네트워크 배포가 필요한 경우 MCP Server를 로컬에 설치하여 stdio를 통해 시작할 수 있습니다.

### 설치

pip 설치(권장):

```bash
pip install mcp-suno
```

또는 소스 코드 설치:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

설치가 완료되면 `mcp-suno` 명령을 사용하여 서비스를 시작할 수 있습니다.

### Claude Desktop에서 사용(로컬)

Claude Desktop 구성 파일을 편집합니다:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 구성을 추가합니다:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

`uvx`를 사용하는 경우(패키지를 미리 설치할 필요 없음):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

구성을 저장한 후 Claude Desktop을 재시작하면 적용됩니다.

## 고급 제어 및 Studio 프로젝트

`suno_generate_music`는 `variety`를 지원하며, `suno_generate_custom_music`는 추가로
`max_mode`와 `audio_weight`를 지원합니다. `max_mode`는 더 높은 API 과금 등급을 사용하며, 기본적으로 활성화되지 않고,
사용자가 향상 모드를 명시적으로 선택한 후 설정해야 합니다. 현재 가격은 플랫폼 서비스 페이지를 기준으로 합니다.

`suno_generate_with_custom_model`은 `instrumental=true`를 사용하여 순수 음악을 생성하거나,
`lyric_prompt`를 사용하여 가사를 자동 생성할 수 있습니다. 그렇지 않으면 `lyric`을 제공합니다. 제목과 스타일은 생략할 수 있으며,
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` 및
`callback_url`도 전달할 수 있습니다. 명시적인 `0` 제어값은 유지됩니다.

`suno_manage_project`의 `request.action`은 `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render` 중에서 선택할 수 있습니다. 입력은 작업에 따라 구분되며, 프로젝트 수정에는 가장 최근에 조회한 `version_id`를 사용해야 합니다.
저장 시에는 전체 `state`를 전달하고, 기존 트랙과 필드를 유지합니다.

`retrieve`를 제외하고, 모든 호출에는 반드시 `idempotency_key`를 제공해야 합니다. 새 쓰기 작업에는 새 키를 사용합니다.
시간 초과 또는 접수 결과가 불확실할 경우, 원래 키와 완전히 동일한 요청으로 재시도하거나 원래 작업을 조회해야 하며, 과금되는 생성을 자동으로
키를 바꿔 재전송하지 마십시오. 소스 오디오 구간은 초 단위를 사용하고, 프로젝트 타임라인 구간은 박자 단위를 사용합니다. 생성은 후보만 만들며,
후보를 선택하고 `commit_candidate`를 호출해야만 트랙에 기록됩니다.

비동기 접수의 `task_id`는 `suno_get_task`로 조회합니다. `finished_at`가 비어 있으면 계속 기다리고,
종료 상태 후 `response.success`와 오류를 확인하십시오. 접수 성공을 생성, 커밋 또는 내보내기 성공으로 간주하지 마십시오.
`suno_get_tasks_batch`는 전체 JSON 작업 기록을 반환하며, 사용자 지정 모델 객체, 프로젝트 상태,
후보 및 MIDI 등 각종 결과를 유지합니다. 전체 워크플로는 [Studio 프로젝트 가이드](https://platform.acedata.cloud/documents/suno-projects-integration)를 참조하십시오.
