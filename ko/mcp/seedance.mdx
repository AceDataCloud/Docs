[MCP（Model Context Protocol）](https://modelcontextprotocol.io)는 Anthropic에서 출시한 모델 컨텍스트 프로토콜로, AI 모델(Claude, GPT 등)이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있게 합니다. AceData Cloud에서 제공하는 Seedance MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 바로 바이트댄스 Seedance 생성 AI 비디오를 사용할 수 있습니다.

## 기능 개요

Seedance MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **텍스트 기반 비디오 생성** — 텍스트 프롬프트로 고품질 비디오 생성
- **이미지 기반 비디오 생성** — 이미지를 참고하여 비디오 생성(첫 프레임, 마지막 프레임, 참조 이미지 등 모드)
- **다중 모델 지원** — Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite 등 다양한 모델 지원
- **다양한 해상도 지원** — 480p, 720p, 1080p 등 여러 해상도 지원
- **다양한 화면 비율** — 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 등 비율 지원
- **유연한 영상 길이** — 2~12초 길이의 비디오 지원
- **오디오 생성** — 일부 모델은 오디오 동시 생성 지원
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 획득

## 사전 준비

사용 전 AceData Cloud API Token을 발급받아야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud) 회원가입 또는 로그인
2. [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos) 페이지 접속
3. 「Acquire」 클릭하여 API Token 획득(최초 신청 시 무료 할당량 제공)

## 설치 및 설정

### 방법 1: pip 설치 (추천)

```bash
pip install mcp-seedance
```

### 방법 2: 소스코드 설치

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

설치 완료 후 `mcp-seedance` 명령어로 서비스를 시작할 수 있습니다.

## Claude Desktop에서 사용하기

Claude Desktop 설정 파일 편집:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 설정 추가:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

`uvx` 사용 시(사전 패키지 설치 불필요):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

설정 저장 후 Claude Desktop 재시작하면 대화에서 Seedance 관련 도구를 사용할 수 있습니다.

## VS Code / Cursor에서 사용하기

프로젝트 루트에 `.vscode/mcp.json` 생성:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

또는 `uvx` 사용 시:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

## 사용 가능한 도구 목록

| 도구명 | 설명 |
|--------|------|
| `seedance_generate_video` | 텍스트 프롬프트로 비디오 생성 |
| `seedance_generate_video_from_image` | 이미지를 참고하여 비디오 생성 |
| `seedance_get_task` | 단일 작업 상태 조회 |
| `seedance_get_tasks_batch` | 다중 작업 상태 일괄 조회 |
| `seedance_list_models` | 사용 가능한 모든 모델 및 기능 목록 |
| `seedance_list_resolutions` | 사용 가능한 해상도 및 화면 비율 목록 |
| `seedance_list_actions` | 사용 가능한 모든 도구 및 워크플로우 예시 목록 |
