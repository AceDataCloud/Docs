[MCP(모델 컨텍스트 프로토콜)](https://modelcontextprotocol.io)은 Anthropic에서 출시한 모델 컨텍스트 프로토콜로, AI 모델(예: Claude, GPT 등)이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있도록 합니다. AceData Cloud에서 제공하는 Sora MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 OpenAI Sora를 사용하여 AI 비디오를 직접 생성할 수 있습니다.

## 기능 개요

Sora MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **텍스트 생성 비디오** — 텍스트 프롬프트를 통해 고품질 비디오 생성
- **이미지 생성 비디오** — 이미지를 기반으로 비디오 생성
- **캐릭터 일관성 비디오** — 참조 이미지를 사용하여 캐릭터 일관성 유지
- **비동기 생성** — 비동기 작업 제출 및 결과 조회 지원
- **다양한 화면 방향** — 가로(landscape) 및 세로(portrait) 지원
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 획득

## 전제 준비

사용하기 전에 AceData Cloud API Token을 확보해야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud)에서 등록 또는 로그인
2. [Sora Videos API](https://platform.acedata.cloud/documents/sora-videos) 페이지로 이동
3. 「Acquire」를 클릭하여 API Token을 획득 (첫 신청 시 무료 크레딧 제공)

## 설치 구성

### 방법 1: pip 설치(추천)

```bash
pip install mcp-sora
```

### 방법 2: 소스 코드 설치

```bash
git clone https://github.com/AceDataCloud/SoraMCP.git
cd SoraMCP
pip install -e .
```

설치가 완료되면 `mcp-sora` 명령어로 서비스를 시작할 수 있습니다.

## Claude Desktop에서 사용하기

Claude Desktop 구성 파일을 편집합니다:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 구성을 추가합니다:

```json
{
  "mcpServers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

`uvx`를 사용하는 경우(사전 패키지 설치 필요 없음):

```json
{
  "mcpServers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

구성을 저장한 후 Claude Desktop을 재시작하면 대화에서 Sora 관련 도구를 사용할 수 있습니다.

## VS Code / Cursor에서 사용하기

프로젝트 루트 디렉토리에 `.vscode/mcp.json`을 생성합니다:

```json
{
  "servers": {
    "sora": {
      "command": "mcp-sora",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

또는 `uvx`를 사용할 수 있습니다:

```json
{
  "servers": {
    "sora": {
      "command": "uvx",
      "args": ["mcp-sora"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

## 사용 가능한 도구 목록

| 도구명                                  | 설명             |
| ------------------------------------ | -------------- |
| `sora_generate_video`                | 텍스트 프롬프트를 통해 비디오 생성    |
| `sora_generate_video_from_image`     | 이미지를 기반으로 비디오 생성     |
| `sora_generate_video_with_character` | 참조 캐릭터 이미지를 사용하여 일관성 비디오 생성 |
| `sora_generate_video_async`          | 비동기 비디오 생성 작업 제출     |
| `sora_get_task`                      | 단일 작업 상태 조회       |
| `sora_get_tasks_batch`               | 배치 작업 상태 조회       |

## 사용 예시

구성이 완료되면 AI 클라이언트에서 자연어로 이러한 기능을 직접 호출할 수 있습니다, 예를 들어:

- 「Sora를 사용하여 풀밭에서 뛰어노는 고양이 비디오를 생성해줘」
- 「이 인물 사진을 사용하여 비디오를 생성하고 캐릭터 일관성을 유지해줘」
- 「도시 일출을 주제로 세로 비디오를 생성해줘」
- 「비디오를 비동기로 생성하고 나중에 결과를 조회해줘」
