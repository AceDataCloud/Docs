[MCP(모델 컨텍스트 프로토콜)](https://modelcontextprotocol.io)은 Anthropic에서 출시한 모델 컨텍스트 프로토콜로, AI 모델(예: Claude, GPT 등)이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있게 해줍니다. AceData Cloud에서 제공하는 나노 바나나 MCP 서버를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 직접 AI 이미지를 생성하고 편집할 수 있습니다.

## 기능 개요

나노 바나나 MCP 서버는 다음과 같은 핵심 기능을 제공합니다:

- **이미지 생성** — 텍스트 프롬프트를 통해 고품질 이미지를 생성
- **이미지 편집** — 기존 이미지를 수정하거나 여러 이미지를 조합
- **가상 피팅** — 의상을 인물 사진에 착용
- **제품 삽입** — 실제 장면에 제품을 배치
- **다중 모델 지원** — nano-banana, nano-banana-2 및 nano-banana-pro 모델 지원
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 획득

## 사전 준비

사용하기 전에 AceData Cloud API 토큰을 획득해야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud)에서 등록 또는 로그인
2. [나노 바나나 이미지 API](https://platform.acedata.cloud/documents/nano-banana-images) 페이지로 이동
3. 「Acquire」를 클릭하여 API 토큰을 획득 (첫 신청 시 무료 크레딧 제공)

## 설치 구성

### 방법 1: pip 설치 (추천)

```bash
pip install mcp-nanobanana-pro
```

### 방법 2: 소스 코드 설치

```bash
git clone https://github.com/AceDataCloud/NanoBananaMCP.git
cd NanoBananaMCP
pip install -e .
```

설치가 완료되면 `mcp-nanobanana-pro` 명령어로 서비스를 시작할 수 있습니다.

## Claude Desktop에서 사용하기

Claude Desktop 구성 파일을 편집합니다:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 구성을 추가합니다:

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API 토큰"
      }
    }
  }
}
```

`uvx`를 사용하는 경우(사전 설치 필요 없음):

```json
{
  "mcpServers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API 토큰"
      }
    }
  }
}
```

구성을 저장한 후 Claude Desktop을 재시작하면 대화에서 나노 바나나 관련 도구를 사용할 수 있습니다.

## VS Code / Cursor에서 사용하기

프로젝트 루트 디렉토리에 `.vscode/mcp.json`을 생성합니다:

```json
{
  "servers": {
    "nanobanana": {
      "command": "mcp-nanobanana-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API 토큰"
      }
    }
  }
}
```

또는 `uvx`를 사용할 수 있습니다:

```json
{
  "servers": {
    "nanobanana": {
      "command": "uvx",
      "args": ["mcp-nanobanana-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API 토큰"
      }
    }
  }
}
```

## 사용 가능한 도구 목록

| 도구명                          | 설명          |
| ---------------------------- | ----------- |
| `nanobanana_generate_image`  | 텍스트 프롬프트를 통해 이미지를 생성 |
| `nanobanana_edit_image`      | 기존 이미지를 편집하거나 조합   |
| `nanobanana_get_task`        | 단일 작업 상태 조회    |
| `nanobanana_get_tasks_batch` | 배치 작업 상태 조회    |

## 사용 예시

구성이 완료되면 AI 클라이언트에서 자연어로 이러한 기능을 직접 호출할 수 있습니다, 예를 들어:

- 「수채화 스타일의 산수화를 생성해줘」
- 「이 옷을 이 사람에게 PS 해줘」
- 「이 제품을 카페 장면에 배치해줘」
- 「nano-banana-pro 모델로 고품질 인물 사진을 생성해줘」
