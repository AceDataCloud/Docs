[MCP（Model Context Protocol）](https://modelcontextprotocol.io)는 Anthropic에서 출시한 모델 컨텍스트 프로토콜로, Claude, GPT 등 AI 모델이 표준화된 인터페이스를 통해 외부 도구를 호출할 수 있게 합니다. AceData Cloud에서 제공하는 Veo MCP Server를 통해 Claude Desktop, VS Code, Cursor 등 AI 클라이언트에서 Google Veo를 사용해 AI 비디오를 직접 생성할 수 있습니다.

## 기능 개요

Veo MCP Server는 다음과 같은 핵심 기능을 제공합니다:

- **텍스트 기반 비디오 생성** — 텍스트 프롬프트로 고품질 비디오 생성
- **이미지 기반 비디오 생성** — 이미지를 기반으로 비디오 생성
- **다중 모델 지원** — veo3, veo2, veo31-fast-ingredients 등 모델 지원
- **다양한 해상도** — 4K, 1080p, GIF 등 출력 포맷 지원
- **다양한 화면 비율** — 16:9, 9:16 등 비율 지원
- **1080p 업그레이드** — 생성된 비디오를 1080p로 업그레이드
- **작업 조회** — 생성 진행 상황 모니터링 및 결과 조회

## 사전 준비

사용 전, AceData Cloud API Token을 발급받아야 합니다:

1. [AceData Cloud 플랫폼](https://platform.acedata.cloud)에 가입 또는 로그인
2. [Veo Videos API](https://platform.acedata.cloud/documents/veo-videos) 페이지로 이동
3. 「Acquire」를 클릭하여 API Token 발급 (첫 신청 시 무료 크레딧 제공)

## 설치 및 설정

### 방법 1: pip 설치 (권장)

```bash
pip install mcp-veo
```

### 방법 2: 소스 코드 설치

```bash
git clone https://github.com/AceDataCloud/VeoMCP.git
cd VeoMCP
pip install -e .
```

설치 완료 후 `mcp-veo` 명령어로 서비스를 시작할 수 있습니다.

## Claude Desktop에서 사용하기

Claude Desktop 설정 파일 편집:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

다음 설정을 추가하세요:

```json
{
  "mcpServers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

`uvx` 사용 시 (사전 패키지 설치 불필요):

```json
{
  "mcpServers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

설정 저장 후 Claude Desktop을 재시작하면 대화에서 Veo 관련 도구를 사용할 수 있습니다.

## VS Code / Cursor에서 사용하기

프로젝트 루트 디렉터리에 `.vscode/mcp.json` 파일 생성:

```json
{
  "servers": {
    "veo": {
      "command": "mcp-veo",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

또는 `uvx` 사용 시:

```json
{
  "servers": {
    "veo": {
      "command": "uvx",
      "args": ["mcp-veo"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "당신의 API Token"
      }
    }
  }
}
```

## 사용 가능한 도구 목록

| 도구명 | 설명 |
|--------|------|
| `veo_text_to_video` | 텍스트 프롬프트로 비디오 생성 |
| `veo_image_to_video` | 이미지를 기반으로 비디오 생성 |
| `veo_get_1080p` | 비디오를 1080p로 업그레이드 |
| `veo_get_task` | 단일 작업 상태 조회 |
| `veo_get_tasks_batch` | 다수 작업 상태 일괄 조회 |

## 사용 예시

설정 완료 후 AI 클라이언트에서 자연어로 다음과 같이 호출할 수 있습니다:

- 「이 풍경 사진으로 4K 비디오 생성해줘」

- 「이 비디오를 1080p로 업그레이드해줘」
