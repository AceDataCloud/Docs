## Ace Data Cloud란?

Ace Data Cloud는 하나의 API Key와 일관된 인터페이스를 통해 전 세계 선도 AI 서비스에 접근할 수 있는 통합 AI API 플랫폼입니다.

## 핵심 장점

- **통합 API** — 하나의 API Key로 50개 이상의 AI 서비스 이용 가능
- **OpenAI 호환** — Claude, Gemini 등을 OpenAI 인터페이스로 직접 호출 가능
- **인터랙티브 샌드박스** — 문서 내에서 각 API를 직접 테스트 가능
- **종량제 과금** — 구독료 없이 실제 사용량에 따라 과금
- **MCP 서버** — Cursor, Claude 등 AI 프로그래밍 도구를 네이티브 지원
