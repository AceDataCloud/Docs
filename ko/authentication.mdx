모든 Ace Data Cloud API는 **Bearer Token** 인증을 사용합니다.

## 토큰 받기

[Applications](https://platform.acedata.cloud/console/applications?lang=ko&utm_source=docs&utm_medium=referral&utm_campaign=evergreen)에 로그인하고 **General Application**을 엽니다. 처음 사용할 때 앱이 보이지 않으면 **Initialize General Application**을 선택합니다. **API KEY** 옆에서 그림의 **1**로 표시된 복사 버튼을 누릅니다.

![그림에서 1로 표시된 API 키 복사 버튼](https://raw.githubusercontent.com/AceDataCloud/NanoBananaDify/2522b2f57210597af2db866445319334a1677a23/_assets/tutorial/get-api-key-en.png)

키는 서버에 보관하고 예제의 `YOUR_API_TOKEN`을 복사한 값으로 바꾸세요.

## 토큰 사용법

각 요청의 `Authorization` 헤더에 토큰 포함:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## 속도 제한

속도 제한은 서비스 및 구독 수준에 따라 다릅니다. 제한 초과 시 API는 `429 Too Many Requests`를 반환합니다.

## 보안 모범 사례

- 클라이언트 코드에 API 토큰 노출 금지
- 환경 변수를 사용해 토큰 저장
- 정기적으로 토큰 교체
- 개발 및 운영 환경에서 서로 다른 토큰 사용
