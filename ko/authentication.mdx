description: "Ace Data Cloud API를 사용한 인증 방법"
---

모든 Ace Data Cloud API는 **Bearer Token** 인증을 사용합니다.

## 토큰 받기

1. [platform.acedata.cloud](https://platform.acedata.cloud)에서 계정 등록
2. 필요한 서비스 구독
3. 각 서비스별로 자격 증명(API Token) 생성

## 토큰 사용

각 요청의 `Authorization` 헤더에 토큰 포함:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Tip">
  각 토큰은 특정 서비스 구독에 연결됩니다. 다른 서비스는 다른 토큰을 사용하거나, **글로벌** 자격 증명을 생성하여 여러 서비스에서 사용할 수 있습니다.
</Note>

## 속도 제한

속도 제한은 서비스 및 구독 수준에 따라 다릅니다. 제한을 초과하면 API가 `429 Too Many Requests`를 반환합니다.

## 보안 모범 사례

- 클라이언트 코드에 API 토큰 노출 금지
- 환경 변수를 사용하여 토큰 저장
- 토큰을 정기적으로 교체
- 개발 및 운영 환경에서 다른 토큰 사용
