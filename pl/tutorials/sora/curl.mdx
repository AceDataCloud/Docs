## Wprowadzenie

Sora to usługa AI wideo oferowana przez Ace Data Cloud, wykorzystująca model generowania wideo OpenAI Sora. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Sora za pomocą cURL, realizując funkcje takie jak generowanie wideo z tekstu, różne długości, orientacja pozioma i pionowa, kontrola postaci, obrazy referencyjne i inne.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokenu API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Sora to:

```
POST https://api.acedata.cloud/sora/videos
```

W tym przykładzie używany jest model `sora-2`.
Dostępne modele to: `sora-2`, `sora-2-pro`.

Przykładowa pełna komenda cURL:

```bash
curl -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/sora/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "A cat running across a sunny meadow", "model": "sora-2", "duration": 10, "orientation": "landscape"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                          |
|-------------|-------------------------------|
| 401         | Nieautoryzowany, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość zapytań |
| 500         | Błąd wewnętrzny serwera       |
