## Wprowadzenie

Hailuo to usługa AI wideo oferowana przez Ace Data Cloud, wykorzystująca model generowania wideo MiniMax Hailuo. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Hailuo za pomocą cURL, realizując funkcje takie jak generowanie wideo z tekstu, generowanie wideo z obrazu, tryb reżysera i inne.

## Wymagania wstępne

- Konto w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskany token API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Hailuo to:

```
POST https://api.acedata.cloud/hailuo/videos
```

W tym przykładzie używany jest model `minimax-t2v`.
Dostępne modele to: `minimax-i2v`, `minimax-t2v`, `minimax-i2v-director`.

Przykładowe pełne polecenie cURL:

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                          |
|-------------|-------------------------------|
| 401         | Nieautoryzowany, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość żądań |
| 500         | Wewnętrzny błąd serwera       |

## Następne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) w celu poznania pełnej specyfikacji parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty usługi
