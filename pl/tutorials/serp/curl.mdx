title: "Google Search cURL szybki start"
---

## Wprowadzenie

Google Search to usługa wyszukiwania oferowana przez Ace Data Cloud, Google Search API. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywoływać Google Search za pomocą cURL, realizując wyszukiwanie stron internetowych, obrazów, wiadomości, map, wideo i innych funkcji.

## Wymagania wstępne

- Posiadanie konta [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie API Token
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint do wywołania Google Search API to:

```
POST https://api.acedata.cloud/serp/google
```

Przykład pełnej komendy cURL:

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}'
```

Proszę zastąpić `YOUR_API_TOKEN` rzeczywistym tokenem uzyskanym na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zalecane jest użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "artificial intelligence latest news", "type": "search", "number": 10, "language": "en", "country": "US"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                         |
|-------------|------------------------------|
| 401         | Nieautoryzowany, sprawdź API Token |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość żądań |
| 500         | Błąd wewnętrzny serwera      |

## Kolejne kroki

- Przejdź do [Ace Data Cloud Console](https://platform.acedata.cloud), aby uzyskać API Token
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) dla pełnego opisu parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty
