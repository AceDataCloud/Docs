title: "Image2Text cURL Szybki Start"
---

## Wprowadzenie

Image2Text to usługa rozpoznawania captcha obrazkowych oferowana przez Ace Data Cloud. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Image2Text za pomocą cURL, aby rozpoznawać captcha obrazkowe, obsługiwać wejście w formacie Base64, URL i inne funkcje.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokenu API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Image2Text to:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Przykład pełnej komendy cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}'
```

Proszę zastąpić `YOUR_API_TOKEN` rzeczywistym tokenem uzyskanym na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zalecane jest użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/recognition/image2text \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                         |
|-------------|------------------------------|
| 401         | Nieautoryzowany, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczono limit zapytań   |
| 500         | Błąd wewnętrzny serwera      |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) aby poznać pełną specyfikację parametrów
- Sprawdź [cennik](https://platform.acedata.cloud/services) aby poznać koszty usług
