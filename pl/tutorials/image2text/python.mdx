## Wprowadzenie

Image2Text to usługa rozpoznawania kodów CAPTCHA oferowana przez Ace Data Cloud, umożliwiająca rozpoznawanie obrazów CAPTCHA. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko zintegrować Image2Text w Pythonie, realizując rozpoznawanie obrazów CAPTCHA, obsługę wejścia Base64, wejścia URL i inne funkcje.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokenu API
- Środowisko Python 3.7 lub nowsze
- Instalacja biblioteki requests: `pip install requests`

## Podstawowe użycie

Główny endpoint API Image2Text to:

```
POST https://api.acedata.cloud/captcha/recognition/image2text
```

Pełny przykład kodu w Python:

```python
import requests

url = "https://api.acedata.cloud/captcha/recognition/image2text"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "image": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

Proszę zastąpić `YOUR_API_TOKEN` rzeczywistym tokenem uzyskanym na platformie Ace Data Cloud.

## Obsługa odpowiedzi

Po pomyślnym wywołaniu API zwraca dane w formacie JSON. Zaleca się sprawdzenie kodu statusu HTTP:

```python
if response.status_code == 200:
    result = response.json()
    print("Wywołanie zakończone sukcesem:", result)
else:
    print(f"Wywołanie nie powiodło się, kod statusu: {response.status_code}")
    print(response.text)
```

## Zaawansowane użycie

Dla API obsługujących zadania asynchroniczne można uzyskać wynik za pomocą URL zwrotnego (callback):

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# Wynik zostanie przesłany na Twój serwer przez callback URL
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                         |
|-------------|------------------------------|
| 401         | Błąd uwierzytelniania, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczono limit zapytań   |
| 500         | Błąd wewnętrzny serwera      |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) w celu poznania pełnej specyfikacji parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty korzystania
