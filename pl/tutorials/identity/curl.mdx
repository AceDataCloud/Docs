## Wprowadzenie

Identity to usługa uwierzytelniania oferowana przez Ace Data Cloud, umożliwiająca weryfikację tożsamości za pomocą dowodu osobistego, karty bankowej lub numeru telefonu. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Identity za pomocą cURL, realizując funkcje takie jak OCR dowodu osobistego, weryfikacja dowodu osobistego, weryfikacja karty bankowej oraz weryfikacja numeru telefonu.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokenu API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Identity to:

```
POST https://api.acedata.cloud/identity/idcard/ocr
```

Przykładowe pełne polecenie cURL:

```bash
curl -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/identity/idcard/ocr \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/idcard-front.jpg"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                          |
|-------------|-------------------------------|
| 401         | Nieautoryzowany, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość żądań |
| 500         | Wewnętrzny błąd serwera       |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference), aby poznać pełne parametry
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty usług
