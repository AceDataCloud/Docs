## Wprowadzenie

Wan to usługa AI wideo oferowana przez Ace Data Cloud, oparta na modelu generowania wideo Wan Xiang firmy Alibaba. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Wan za pomocą cURL, realizując funkcje takie jak generowanie wideo z tekstu, generowanie wideo z obrazu, generowanie wideo referencyjnego oraz obsługę różnych rozdzielczości.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokenu API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny punkt końcowy API Wan to:

```
POST https://api.acedata.cloud/wan/videos
```

W tym przykładzie używany jest model `wan2.6-t2v`.  
Dostępne modele to: `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v`, `wan2.6-i2v-flash`.

Pełny przykład polecenia cURL:

```bash
curl -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/wan/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "text2video", "model": "wan2.6-t2v", "prompt": "Astronauts shuttle from space to volcano", "resolution": "720P"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                         |
|-------------|------------------------------|
| 401         | Nieautoryzowany, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość zapytań |
| 500         | Błąd wewnętrzny serwera       |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API  
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) dla pełnego opisu parametrów  
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty usługi
