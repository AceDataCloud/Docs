## Wprowadzenie

Luma to usługa AI wideo oferowana przez Ace Data Cloud, umożliwiająca generowanie wideo za pomocą Luma Dream Machine. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Luma za pomocą cURL, realizując funkcje takie jak generowanie wideo z tekstu, generowanie wideo z obrazu, kontynuacja wideo, kontrola pierwszej i ostatniej klatki oraz wideo pętli.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie API Token
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Luma to:

```
POST https://api.acedata.cloud/luma/videos
```

Przykład pełnej komendy cURL:

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}'
```

Proszę zastąpić `YOUR_API_TOKEN` rzeczywistym tokenem uzyskanym na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Astronauts shuttle from space to volcano", "action": "generate", "enhancement": true}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                          |
|-------------|-------------------------------|
| 401         | Nieautoryzowany, sprawdź API Token |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość żądań |
| 500         | Błąd wewnętrzny serwera       |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać API Token
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) w celu poznania pełnej specyfikacji parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services) aby poznać koszty korzystania
