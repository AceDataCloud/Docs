## Wprowadzenie

hCaptcha to usługa CAPTCHA oferowana przez Ace Data Cloud, rozwiązanie hCaptcha. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać hCaptcha za pomocą cURL, realizując funkcje takie jak pobieranie tokena hCaptcha czy rozpoznawanie obrazów hCaptcha.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokena API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API hCaptcha to:

```
POST https://api.acedata.cloud/captcha/token/hcaptcha
```

Przykład pełnej komendy cURL:

```bash
curl -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}'
```

Proszę zastąpić `YOUR_API_TOKEN` rzeczywistym tokenem uzyskanym na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/captcha/token/hcaptcha \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"website_key": "a5f74b19-9e45-40e0-b45d-47ff91b7a6c2", "website_url": "https://accounts.hcaptcha.com/demo"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                               |
|-------------|-----------------------------------|
| 401         | Błąd uwierzytelniania, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość żądań  |
| 500         | Błąd wewnętrzny serwera           |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference), aby poznać pełną specyfikację parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty usług
