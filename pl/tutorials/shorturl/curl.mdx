## Wprowadzenie

Short URL to narzędzie oferowane przez Ace Data Cloud, służące do generowania krótkich linków. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko korzystać z Short URL za pomocą cURL, realizując funkcje takie jak skracanie URL czy niestandardowe domeny.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokena API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Short URL to:

```
POST https://api.acedata.cloud/shorturl
```

Pełny przykład polecenia cURL:

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content": "https://platform.acedata.cloud"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                              |
|-------------|----------------------------------|
| 401         | Niepowodzenie uwierzytelnienia, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość żądań |
| 500         | Wewnętrzny błąd serwera          |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference), aby poznać pełną specyfikację parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty usług
