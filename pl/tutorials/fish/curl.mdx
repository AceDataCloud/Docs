## Wprowadzenie

Fish TTS to usługa AI audio oferowana przez Ace Data Cloud, usługa syntezy mowy Fish. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko wywołać Fish TTS za pomocą cURL, realizując funkcje takie jak konwersja tekstu na mowę, różne barwy głosu oraz dostosowywanie dźwięku.

## Wymagania wstępne

- Posiadanie konta w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskanie tokenu API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny endpoint API Fish TTS to:

```
POST https://api.acedata.cloud/fish/audios
```

W tym przykładzie używany jest model `fish-tts`.  
Dostępne modele to: `fish-tts`.

Pełny przykład polecenia cURL:

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "speech", "prompt": "你好，欢迎使用 Ace Data Cloud 的语音合成服务", "voice_id": "d7900c21663f485ab63ebdb7e5905036", "model": "fish-tts"}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis                              |
|-------------|----------------------------------|
| 401         | Nieautoryzowany, sprawdź token API |
| 403         | Niewystarczające środki lub brak dostępu |
| 429         | Przekroczona częstotliwość zapytań |
| 500         | Błąd wewnętrzny serwera          |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API  
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference), aby poznać pełną specyfikację parametrów  
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty usługi
