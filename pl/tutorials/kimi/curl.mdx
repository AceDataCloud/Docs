## Wprowadzenie

Kimi to usługa czatu AI oferowana przez Ace Data Cloud, oparta na dużych modelach językowych z serii Kimi z Moon's Dark Side. Dzięki zunifikowanemu API Ace Data Cloud możesz szybko korzystać z Kimi za pomocą cURL, realizując funkcje takie jak wieloetapowa konwersacja, systemowe podpowiedzi, strumieniowe wyjście czy tryb wyjścia JSON.

## Wymagania wstępne

- Konto w [Ace Data Cloud](https://platform.acedata.cloud) oraz uzyskany token API
- Środowisko terminalowe z zainstalowanym cURL

## Podstawowe użycie

Główny punkt końcowy API Kimi to:

```
POST https://api.acedata.cloud/kimi/chat/completions
```

W tym przykładzie używany jest model `kimi-k2.5`.
Dostępne modele to: `kimi-k2.5`, `kimi-k2-thinking-turbo`, `kimi-k2-thinking`, `kimi-k2-instruct-0905`.

Pełny przykład polecenia cURL:

```bash
curl -X POST https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k2.5", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}'
```

Zamień `YOUR_API_TOKEN` na rzeczywisty token uzyskany na platformie Ace Data Cloud.

## Przykład odpowiedzi

Po pomyślnym wywołaniu zwracane są dane w formacie JSON, na przykład:

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## Przetwarzanie odpowiedzi za pomocą jq

Zaleca się użycie narzędzia jq do formatowania wyjścia:

```bash
curl -s -X POST https://api.acedata.cloud/kimi/chat/completions \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k2.5", "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}], "max_tokens": 1024, "temperature": 0.7}' | jq .
```

## Obsługa błędów

Typowe kody błędów:

| Kod statusu | Opis |
|-------------|------|
| 401 | Nieautoryzowany, sprawdź token API |
| 403 | Niewystarczające środki lub brak uprawnień |
| 429 | Przekroczona częstotliwość zapytań |
| 500 | Błąd wewnętrzny serwera |

## Kolejne kroki

- Przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud), aby uzyskać token API
- Zapoznaj się z [dokumentacją API](https://docs.acedata.cloud/zh-CN/api-reference) dla pełnego opisu parametrów
- Sprawdź [plany cenowe](https://platform.acedata.cloud/services), aby poznać koszty
