## Podstawowy URL

Podstawowy adres wszystkich punktów końcowych API:

```
https://api.acedata.cloud
```

## Uwierzytelnianie

Wszystkie punkty końcowe wymagają uwierzytelniania Bearer Token:

```
Authorization: Bearer YOUR_API_TOKEN
```

## Testowanie online

Każdy punkt końcowy w tej dokumentacji zawiera interaktywną piaskownicę. Wprowadź token API, aby bezpośrednio testować żądania w przeglądarce.

<Note title="Tip">
  Pobierz token API na [platform.acedata.cloud](https://platform.acedata.cloud).
</Note>
