## Szczegółowa analiza

### Funkcje

Zarówno Gemini, jak i DeepSeek są wywoływane przez zunifikowane API Ace Data Cloud, obsługujące standardowy interfejs REST oraz uwierzytelnianie Bearer Token.

**Gemini** główny punkt końcowy to `POST https://api.acedata.cloud/gemini/chat/completions`, obsługujący wieloetapową rozmowę, systemowe promptowanie, strumieniowe wyjście oraz tryb wyjścia JSON.

**DeepSeek** główny punkt końcowy to `POST https://api.acedata.cloud/deepseek/chat/completions`, obsługujący wieloetapową rozmowę, systemowe promptowanie, strumieniowe wyjście oraz tryb wyjścia JSON.

## Przykłady kodu

Poniższe przykłady pokazują, jak wywołać Gemini i DeepSeek za pomocą API Ace Data Cloud. Wszystkie żądania korzystają z tego samego Base URL (`https://api.acedata.cloud`) oraz sposobu uwierzytelniania.

### Wywołanie Gemini

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/gemini/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "gemini-2.5-flash",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
},
)
print(response.json())
```
