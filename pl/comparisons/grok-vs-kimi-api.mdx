## Szczegółowa analiza

### Funkcje

Grok i Kimi są wywoływane za pomocą zunifikowanego API Ace Data Cloud, obsługują standardowy interfejs REST oraz uwierzytelnianie Bearer Token.

**Grok** główny punkt końcowy to `POST https://api.acedata.cloud/grok/chat/completions`, obsługuje wieloetapową rozmowę, systemowe podpowiedzi, strumieniowe wyjście oraz tryb wyjścia JSON.

**Kimi** główny punkt końcowy to `POST https://api.acedata.cloud/kimi/chat/completions`, obsługuje wieloetapową rozmowę, systemowe podpowiedzi, strumieniowe wyjście oraz tryb wyjścia JSON.

## Przykłady kodu

Poniższe przykłady pokazują, jak wywołać Grok i Kimi za pomocą API Ace Data Cloud. Wszystkie żądania korzystają z tego samego Base URL (`https://api.acedata.cloud`) i sposobu uwierzytelniania.

### Wywołanie Grok

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/grok/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "model": "grok-3",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
},
)
print(response.json())
```
