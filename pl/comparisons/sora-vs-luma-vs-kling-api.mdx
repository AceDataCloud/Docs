**Sora** główny punkt końcowy to `POST https://api.acedata.cloud/sora/videos`, obsługuje generowanie wideo z tekstu, różne długości, orientację poziomą/pionową, kontrolę postaci i inne funkcje. Dodatkowo dostępne są punkty końcowe takie jak `/sora/tasks`.

**Kling** główny punkt końcowy to `POST https://api.acedata.cloud/kling/videos`, obsługuje generowanie wideo z tekstu, generowanie wideo z obrazu, kontynuację wideo, różne długości i inne funkcje. Dodatkowo dostępne są punkty końcowe takie jak `/kling/tasks`, `/kling/motion`.

## Przykłady kodu

Poniższe przykłady pokazują, jak wywołać Sora, Luma i Kling za pomocą API Ace Data Cloud. Wszystkie żądania używają tego samego Base URL (`https://api.acedata.cloud`) i sposobu uwierzytelniania.

### Wywołanie Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
    "prompt": "A cat running across a sunny meadow",
    "model": "sora-2",
    "duration": 10,
    "orientation": "landscape"
},
)
print(response.json())
```
