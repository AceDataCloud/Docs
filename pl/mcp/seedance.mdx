[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstu modelu wprowadzony przez Anthropic, który pozwala modelom AI (takim jak Claude, GPT itd.) wywoływać zewnętrzne narzędzia za pośrednictwem standaryzowanych interfejsów. Dzięki Seedance MCP Server udostępnianemu przez AceData Cloud możesz bezpośrednio używać ByteDance Seedance do generowania filmów AI w klientach AI, takich jak Claude Desktop, VS Code, Cursor itd.

## Przegląd funkcji

Seedance MCP Server oferuje następujące kluczowe funkcje:

- **Generowanie wideo z tekstu** — generowanie wysokiej jakości wideo za pomocą tekstowych promptów
- **Generowanie wideo z obrazów** — generowanie wideo z obrazem jako odniesieniem (tryby pierwszej klatki, ostatniej klatki, obrazu referencyjnego itd.)
- **Obsługa wielu modeli** — obsługa Seedance 1.x, 1.5, 2.0 oraz 2.5
- **Wiele rozdzielczości** — obsługa 480p, 720p, 1080p, a niektóre modele obsługują 4k
- **Wiele proporcji obrazu** — obsługa 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 oraz adaptive
- **Elastyczny czas trwania** — w zależności od modelu obsługa 2–30 sekund lub automatycznego czasu trwania
- **Wideo multimodalne** — obsługa generowania audio, referencyjnego audio/wideo oraz edycji i wydłużania wideo w 2.5
- **Zapytania o zadania** — monitorowanie postępu generowania i pobieranie wyników

## Zalecane: użycie autoryzacji OAuth dla hostowanego MCP

Dodaj adres serwera w klientach obsługujących zdalne MCP OAuth:

```text
https://seedance.mcp.acedata.cloud/mcp
```

Wybierz połączenie lub logowanie, zaloguj się do Ace Data Cloud, sprawdź uprawnienia i autoryzuj, a następnie włącz narzędzia. Ta ścieżka nie wymaga wcześniejszego tworzenia ani kopiowania API Token. Usługa obsługuje OAuth discovery, dynamiczną rejestrację klienta (DCR) oraz S256 PKCE; DCR rejestruje klienta, użytkownik nadal musi się zalogować i autoryzować, a użycie API jest rozliczane jak zwykle.

| Klient                            | Metoda integracji i warunki                                                                       |
| ------------------------------ | ----------------------------------------------------------------------------- |
| Claude w wersji webowej lub wersja Desktop oferująca zdalne konektory | Dodaj powyższy adres w interfejsie konektorów i autoryzuj; dostęp zależy od wersji i planu. Nie zapisuj zdalnej konfiguracji HTTP w lokalnym pliku konfiguracyjnym stdio.                      |
| VS Code obsługujący natywnie zdalne MCP OAuth     | Wykonaj **MCP: Add Server**, wybierz HTTP, wpisz adres i zaloguj się zgodnie z instrukcjami; dedykowane rozszerzenie AceDataCloud używa niezależnej konfiguracji API Key. |
| Inni klienci                          | Potwierdź, że bieżąca wersja obsługuje zdalne HTTP, OAuth/DCR, i użyj instrukcji konfiguracji danego klienta. Format pliku konfiguracyjnego nie jest uniwersalny między różnymi klientami.                     |

## Alternatywna ścieżka API Token

Lokalne stdio, samodzielny hosting lub klienci nieobsługujący zdalnego OAuth używają API Token. Zaloguj się na [platformę Ace Data Cloud](https://platform.acedata.cloud), wybierz usługę i utwórz poświadczenia API z wymaganymi uprawnieniami. Zapisz Token w ustawieniach poświadczeń klienta lub w lokalnych zmiennych środowiskowych; nie umieszczaj go w adresach URL, treściach czatu ani repozytoriach kontroli wersji. Konfigurację HTTP Header dla różnych klientów należy wypełnić zgodnie z instrukcjami ich wersji.

Instalacja open-source MCP lub ukończenie autoryzacji nie oznacza otrzymania darmowych środków ani nie gwarantuje czasu generowania czy praw do użytku komercyjnego. Przed generowaniem sprawdź aktualne ceny usług, saldo i obowiązujące warunki.

## Metoda druga: uruchamianie lokalne (instalacja pip / uvx)

Jeśli potrzebujesz lokalnego stdio, własnego kodu lub samodzielnego hostingu, możesz uruchomić MCP Server lokalnie. Generowanie nadal wymaga połączenia z internetem do wywoływania API i nie jest wnioskowaniem offline.

### Instalacja

Instalacja przez pip (zalecana):

```bash
pip install mcp-seedance
```

Lub instalacja ze źródeł:

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Po zakończeniu instalacji możesz uruchomić usługę za pomocą polecenia `mcp-seedance`.

### Używanie w Claude Desktop (lokalnie)

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Jeśli używasz `uvx` (bez potrzeby wcześniejszego instalowania pakietu):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Po zapisaniu konfiguracji uruchom ponownie Claude Desktop, aby zmiany zaczęły obowiązywać.

### Używanie w VS Code (lokalnie)

Utwórz `.vscode/mcp.json` w katalogu głównym projektu:

```json
{
  "servers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Lub użyj `uvx`:

```json
{
  "servers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

W przypadku innych lokalnych klientów wypełnij command, args i env zgodnie z instrukcjami konfiguracji stdio dla ich bieżącej wersji; nie traktuj konfiguracji VS Code bezpośrednio jako uniwersalnego formatu.

## Weryfikacja wyników i częste błędy

Poproś klienta o wygenerowanie prostego materiału wideo, zachowaj numer zadania i sprawdzaj to samo zadanie, aż osiągnie końcowy stan sukcesu, a następnie otwórz lub odtwórz końcowy link. Pomyślne połączenie, załadowanie listy narzędzi, HTTP 200, numer zadania i podgląd podczas przetwarzania nie oznaczają końcowego produktu.

W przypadku 401 zaloguj się ponownie lub sprawdź Token i uprawnienia; przy niewystarczającym saldzie sprawdź rozliczenia; podczas przetwarzania zadania kontynuuj sprawdzanie; w przypadku ostatecznego niepowodzenia przeczytaj błąd, zanim zdecydujesz, czy ponowić próbę, ponieważ nowe generowanie może zostać ponownie naliczone.

## Przykłady użycia

Po ukończeniu konfiguracji możesz bezpośrednio wywoływać te funkcje naturalnym językiem w kliencie AI, na przykład:

- „Pomóż mi wygenerować za pomocą Seedance film poklatkowy z miejskiej ulicy”
- „Użyj tego zdjęcia jako pierwszej klatki i wygeneruj 8-sekundowy film”
- „Wygeneruj krótki film 1080p w pionowym formacie 9:16”
- „Użyj modelu Seedance 1.5 Pro do wygenerowania filmu z audio”
