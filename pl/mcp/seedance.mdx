[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstowy modeli opracowany przez Anthropic, który pozwala modelom AI (takim jak Claude, GPT itp.) na wywoływanie zewnętrznych narzędzi przez ustandaryzowany interfejs. Dzięki Seedance MCP Server dostarczanemu przez AceData Cloud możesz bezpośrednio korzystać z generowania AI wideo Seedance ByteDance w klientach AI takich jak Claude Desktop, VS Code, Cursor i innych.

## Przegląd funkcji

Seedance MCP Server oferuje następujące kluczowe funkcje:

- **Generowanie wideo z tekstu** — tworzenie wysokiej jakości wideo na podstawie tekstowych promptów
- **Generowanie wideo z obrazu** — generowanie wideo z odniesieniem do obrazu (tryby: pierwsza klatka, ostatnia klatka, obraz referencyjny itp.)
- **Wsparcie wielu modeli** — obsługa modeli Seedance 1.5 Pro, 1.0 Pro, 1.0 Lite i innych
- **Różne rozdzielczości** — wsparcie dla 480p, 720p, 1080p i innych rozdzielczości
- **Różne proporcje obrazu** — obsługa proporcji 16:9, 9:16, 1:1, 4:3, 3:4, 21:9 i innych
- **Elastyczna długość** — wsparcie dla długości wideo od 2 do 12 sekund
- **Generowanie audio** — niektóre modele obsługują generowanie dźwięku wraz z wideo
- **Zapytania o zadania** — monitorowanie postępu generowania i pobieranie wyników

## Wymagania wstępne

Przed użyciem musisz uzyskać AceData Cloud API Token:

1. Zarejestruj się lub zaloguj na [AceData Cloud Platform](https://platform.acedata.cloud)
2. Przejdź do strony [Seedance Videos API](https://platform.acedata.cloud/documents/seedance-videos)
3. Kliknij „Acquire”, aby uzyskać API Token (pierwsze zgłoszenie daje darmowy limit)

## Instalacja i konfiguracja

### Metoda 1: instalacja przez pip (zalecane)

```bash
pip install mcp-seedance
```

### Metoda 2: instalacja ze źródeł

```bash
git clone https://github.com/AceDataCloud/SeedanceMCP.git
cd SeedanceMCP
pip install -e .
```

Po instalacji możesz uruchomić serwer poleceniem `mcp-seedance`.

## Użycie w Claude Desktop

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "seedance": {
      "command": "mcp-seedance",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Jeśli używasz `uvx` (nie wymaga wcześniejszej instalacji pakietów):

```json
{
  "mcpServers": {
    "seedance": {
      "command": "uvx",
      "args": ["mcp-seedance"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Po zapisaniu konfiguracji i ponownym uruchomieniu Claude Desktop możesz korzystać z narzędzi Seedance w rozmowach.

## Lista dostępnych narzędzi

| Nazwa narzędzia                  | Opis                                |
|---------------------------------|-----------------------------------|
| `seedance_generate_video`        | Generowanie wideo na podstawie tekstu |
| `seedance_generate_video_from_image` | Generowanie wideo z odniesieniem do obrazu |
| `seedance_get_task`              | Zapytanie o status pojedynczego zadania |
| `seedance_get_tasks_batch`       | Masowe zapytanie o status zadań   |
| `seedance_list_models`           | Lista dostępnych modeli i ich możliwości |
| `seedance_list_resolutions`      | Lista dostępnych rozdzielczości i proporcji obrazu |
| `seedance_list_actions`          | Lista dostępnych narzędzi i przykładów workflow |

## Przykłady użycia

Po konfiguracji możesz bezpośrednio w kliencie AI wywoływać funkcje w naturalnym języku, np.:

- „Proszę wygeneruj wideo poklatkowe z miejskiej ulicy za pomocą Seedance”
- „Użyj tego zdjęcia jako pierwszej klatki i wygeneruj 8-sekundowe wideo”
- „Wygeneruj krótkie wideo 1080p w pionowym formacie 9:16”
- „Użyj modelu Seedance 1.5 Pro do wygenerowania wideo z dźwiękiem”
