[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstowy modeli opracowany przez Anthropic, który pozwala modelom AI (takim jak Claude, GPT itp.) na wywoływanie zewnętrznych narzędzi za pomocą ustandaryzowanego interfejsu. Dzięki Seedream MCP Server dostarczanemu przez AceData Cloud możesz bezpośrednio korzystać z generowania i edycji obrazów AI Seedream ByteDance w klientach AI takich jak Claude Desktop, VS Code, Cursor i innych.

## Przegląd funkcji

Seedream MCP Server oferuje następujące kluczowe funkcje:

- **Generowanie obrazów z tekstu** — tworzenie wysokiej jakości obrazów na podstawie tekstowych promptów (wspiera prompt w języku chińskim i angielskim)
- **Edycja obrazów** — modyfikacja stylu, tła, właściwości istniejących obrazów
- **Wirtualna przymiarka ubrań** — nakładanie ubrań na zdjęcia osób
- **Wsparcie wielu modeli** — obsługa Seedream v4.5, v4.0, v3.0 T2I, SeedEdit v3.0 I2I i innych modeli
- **Różne rozdzielczości** — wsparcie rozdzielczości 1K, 2K, 4K oraz adaptacyjnej
- **Kontrola ziarna (seed)** — możliwość odtworzenia wyników generowania za pomocą parametru seed
- **Zapytania o zadania** — monitorowanie postępu generowania i pobieranie wyników

## Wymagania wstępne

Przed użyciem musisz uzyskać AceData Cloud API Token:

1. Zarejestruj się lub zaloguj na [AceData Cloud Platform](https://platform.acedata.cloud)
2. Przejdź do strony [Seedream Images API](https://platform.acedata.cloud/documents/seedream-images)
3. Kliknij „Acquire”, aby uzyskać API Token (pierwsza rejestracja daje darmowy limit)

## Instalacja i konfiguracja

### Metoda 1: instalacja przez pip (zalecane)

```bash
pip install mcp-seedream-pro
```

### Metoda 2: instalacja ze źródła

```bash
git clone https://github.com/AceDataCloud/SeedreamMCP.git
cd SeedreamMCP
pip install -e .
```

Po instalacji możesz uruchomić serwer poleceniem `mcp-seedream-pro`.

## Użycie w Claude Desktop

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "seedream": {
      "command": "mcp-seedream-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Jeśli używasz `uvx` (nie wymaga wcześniejszej instalacji pakietów):

```json
{
  "mcpServers": {
    "seedream": {
      "command": "uvx",
      "args": ["mcp-seedream-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Po zapisaniu konfiguracji i ponownym uruchomieniu Claude Desktop możesz korzystać z narzędzi Seedream w rozmowach.

## Lista dostępnych narzędzi

| Nazwa narzędzia             | Opis                              |
|-----------------------------|----------------------------------|
| `seedream_generate_image`   | Generowanie obrazu z tekstowego promptu |
| `seedream_edit_image`       | Edycja lub modyfikacja istniejącego obrazu |
| `seedream_get_task`         | Zapytanie o status pojedynczego zadania |
| `seedream_get_tasks_batch`  | Masowe zapytanie o statusy zadań |
| `seedream_list_models`      | Lista dostępnych modeli i ich możliwości |
| `seedream_list_sizes`       | Lista dostępnych rozmiarów i opcji rozdzielczości obrazów |

## Przykłady użycia

Po konfiguracji możesz bezpośrednio wywoływać funkcje za pomocą naturalnego języka w kliencie AI, na przykład:

- „Pomóż mi wygenerować obraz krajobrazu w stylu tuszu za pomocą Seedream”
- „Zmień tło tego zdjęcia na gwiaździste niebo”
- „Wygeneruj portret 4K w wysokiej rozdzielczości Seedream v4.5”
- „Nałóż wirtualnie tę odzież na to zdjęcie”
