[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstu modelu wprowadzony przez Anthropic, który umożliwia modelom AI (takim jak Claude, GPT itp.) wywoływanie zewnętrznych narzędzi za pośrednictwem ustandaryzowanego interfejsu. Dzięki Suno MCP Server udostępnianemu przez AceData Cloud możesz bezpośrednio generować muzykę, teksty piosenek oraz zarządzać projektami audio w klientach AI, takich jak Claude Desktop, VS Code, Cursor i innych.

## Przegląd funkcji

Suno MCP Server oferuje następujące kluczowe funkcje:

- **Generowanie muzyki** — generowanie muzyki AI za pomocą tekstowych poleceń
- **Niestandardowe tworzenie** — pełna kontrola nad tekstami, tytułami i stylem muzycznym
- **Kontynuacja utworu** — dalsze wydłużanie istniejącego utworu od dowolnego momentu
- **Covery/remiksy** — tworzenie wersji coverowych w różnych stylach
- **Generowanie tekstów** — generowanie strukturyzowanych tekstów na podstawie opisu
- **Role wokalne** — zapisywanie i ponowne wykorzystywanie stylów głosu
- **Konwersja mediów** — uzyskiwanie MP4, WAV, MIDI, separacji wokalu i innych
- **Optymalizacja stylu** — optymalizacja tagów stylu muzycznego
- **Zapytania o zadania** — monitorowanie postępu generowania i pobieranie wyników

## Przygotowanie wstępne

Przed użyciem musisz uzyskać AceData Cloud API Token:

1. Zarejestruj się lub zaloguj na [platformie AceData Cloud](https://platform.acedata.cloud)
2. Przejdź do strony [Suno Audios API](https://platform.acedata.cloud/documents/suno-audios)
3. Kliknij „Acquire”, aby uzyskać API Token (przy pierwszym wniosku otrzymasz darmowe środki)

## Metoda pierwsza: korzystanie z hostowanego MCP Server (zalecane, bez instalacji)

AceData Cloud hostuje już **Suno MCP Server** w chmurze, **bez konieczności lokalnej instalacji jakichkolwiek zależności** — wystarczy wpisać poniższy URL bezpośrednio w kliencie AI:

```
https://suno.mcp.acedata.cloud/mcp
```

Metoda uwierzytelniania: wystarczy dodać `Authorization: Bearer twój API Token` w nagłówku żądania (Claude.ai wykonuje to automatycznie przez OAuth, bez potrzeby ręcznego wpisywania Tokena).

### Claude.ai (wersja internetowa, logowanie OAuth, najprostsze)

1. Otwórz [Claude.ai](https://claude.ai) → w lewym dolnym rogu **Customize** → **Connectors** → **Add More**
2. W polu URL wpisz: `https://suno.mcp.acedata.cloud/mcp`
3. Dokończ logowanie autoryzacyjne OAuth (automatyczne przekierowanie na stronę logowania AceData Cloud)
4. Wróć do interfejsu rozmowy, a narzędzie będzie gotowe do użycia

### Claude Desktop

Edytuj plik konfiguracyjny:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "suno": {
      "type": "http",
      "url": "https://suno.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Po zapisaniu uruchom ponownie Claude Desktop, aby zmiany zaczęły obowiązywać.

### Claude Code (wiersz poleceń terminala)

```bash
claude mcp add suno --transport http https://suno.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Inne klienty obsługujące MCP

Każdy klient obsługujący protokół MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant itd.) może zostać podłączony poprzez wypełnienie poniższych dwóch pozycji:

- **URL**: `https://suno.mcp.acedata.cloud/mcp`
- **Nagłówek**: `Authorization: Bearer twój API Token`

## Metoda druga: uruchamianie lokalne (instalacja pip / uvx)

Jeśli potrzebujesz działania offline, niestandardowego kodu lub wdrożenia w sieci wewnętrznej, możesz zainstalować MCP Server lokalnie i uruchomić go przez stdio.

### Instalacja

Instalacja przez pip (zalecane):

```bash
pip install mcp-suno
```

Lub instalacja ze źródeł:

```bash
git clone https://github.com/AceDataCloud/SunoMCP.git
cd SunoMCP
pip install -e .
```

Po zakończeniu instalacji możesz uruchomić usługę za pomocą polecenia `mcp-suno`.

### Używanie w Claude Desktop (lokalnie)

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Jeśli używasz `uvx` (bez konieczności wcześniejszej instalacji pakietu):

```json
{
  "mcpServers": {
    "suno": {
      "command": "uvx",
      "args": ["mcp-suno"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Po zapisaniu konfiguracji uruchom ponownie Claude Desktop, aby zmiany zaczęły obowiązywać.

## Przykłady użycia

Po zakończeniu konfiguracji możesz bezpośrednio wywoływać te funkcje w kliencie AI za pomocą języka naturalnego, na przykład:

- „Pomóż mi wygenerować utwór pop o lecie”
- „Przerób ten utwór na cover w stylu jazzowym”
- „Kontynuuj ten utwór, zaczynając od 30. sekundy”
- „Wygeneruj tekst piosenki po chińsku, o tematyce podróżniczej”
- „Oddziel wokal od tego utworu”
- „Pomóż mi przekonwertować ten utwór do formatu MIDI”

## Zaawansowane sterowanie i projekty Studio

`suno_generate_music` obsługuje `variety`; `suno_generate_custom_music` obsługuje dodatkowo
`max_mode` i `audio_weight`. `max_mode` korzysta z wyższego poziomu rozliczeń API, domyślnie nie jest włączony,
i powinien zostać ustawiony po wyraźnym wybraniu przez użytkownika trybu rozszerzonego. Aktualne ceny należy sprawdzić na stronie usługi platformy.

`suno_generate_with_custom_model` może używać `instrumental=true` do generowania muzyki instrumentalnej lub
`lyric_prompt` do automatycznego generowania tekstów piosenek; w przeciwnym razie należy podać
`lyric`. Tytuł i styl można pominąć, można także przekazać
`negative_tags`, `vocal_gender`, `weirdness`, `style_influence`, `duration` oraz
`callback_url`. Jawne wartości sterujące `0` zostaną zachowane.

Dla `suno_manage_project` opcje `request.action` to `create`, `retrieve`, `save`,
`upload`, `add_track`, `generate_track`, `replace_section`, `commit_candidate`,
`remove_track`, `render`. Dane wejściowe różnią się zależnie od akcji, a modyfikacje projektu powinny używać ostatnio odczytanego `version_id`;
podczas zapisywania przekaż pełny `state`, zachowując istniejące ścieżki i pola.

Poza `retrieve` każde wywołanie musi zawierać `idempotency_key`. Nowe operacje zapisu używają nowego klucza;
w przypadku limitu czasu lub niepewnego wyniku przyjęcia zachowaj oryginalny klucz i ponów próbę z dokładnie takim samym żądaniem albo sprawdź oryginalne zadanie, nie
zmieniaj automatycznie klucza, aby ponownie wysłać płatne generowanie. Zakresy źródłowego audio są podawane w sekundach, a zakresy osi czasu projektu w liczbie taktów. Generowanie tworzy wyłącznie kandydatów,
należy wybrać kandydata i wywołać `commit_candidate`, aby został zapisany na ścieżce.

`task_id` przyjęty asynchronicznie sprawdzaj za pomocą `suno_get_task`. Gdy `finished_at` jest puste, kontynuuj oczekiwanie,
a po stanie końcowym sprawdź `response.success` oraz błędy; nie traktuj pomyślnego przyjęcia jako pomyślnego wygenerowania, zatwierdzenia lub eksportu.
`suno_get_tasks_batch` zwraca pełne rekordy zadań JSON, zachowując obiekty modeli niestandardowych, stan projektu,
kandydatów oraz różne wyniki, takie jak MIDI. Pełny przepływ pracy opisano w [przewodniku po projektach Studio](https://platform.acedata.cloud/documents/suno-projects-integration).
