[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstu modelu wprowadzony przez Anthropic, który umożliwia modelom AI (takim jak Claude, GPT itp.) wywoływanie zewnętrznych narzędzi za pośrednictwem ustandaryzowanego interfejsu. Dzięki Flux MCP Server udostępnianemu przez AceData Cloud możesz bezpośrednio generować i edytować obrazy AI w klientach AI, takich jak Claude Desktop, VS Code, Cursor i innych.

## Przegląd funkcji

Flux MCP Server oferuje następujące kluczowe funkcje:

- **Generowanie obrazu z tekstu** — generowanie obrazów wysokiej jakości na podstawie podpowiedzi tekstowych
- **Edycja obrazu** — edycja istniejących obrazów na podstawie instrukcji tekstowych
- **Obsługa wielu modeli** — obsługuje różne modele, takie jak Flux Pro, Flux Dev, Flux 2, Flux Kontext i inne
- **Zapytania o modele** — wyświetlanie wszystkich dostępnych modeli i ich możliwości
- **Zapytania o zadania** — monitorowanie postępu generowania i pobieranie wyników

## Przygotowanie wstępne

Przed użyciem musisz uzyskać AceData Cloud API Token:

1. Zarejestruj się lub zaloguj na [platformie AceData Cloud](https://platform.acedata.cloud)
2. Przejdź na stronę [Flux Images API](https://platform.acedata.cloud/documents/flux-images)
3. Kliknij „Acquire”, aby uzyskać API Token (przy pierwszym wniosku otrzymasz darmowy limit)

## Metoda pierwsza: korzystanie z hostowanego MCP Server (zalecane, bez instalacji)

AceData Cloud hostuje już **Flux MCP Server** w chmurze, **bez potrzeby lokalnej instalacji jakichkolwiek zależności** — wystarczy bezpośrednio wpisać poniższy URL w kliencie AI:

```
https://flux.mcp.acedata.cloud/mcp
```

Metoda uwierzytelniania: wystarczy dodać `Authorization: Bearer Twój API Token` w nagłówku żądania (Claude.ai wykonuje to automatycznie przez OAuth, bez konieczności ręcznego wpisywania Tokena).

### Claude.ai (wersja internetowa, logowanie OAuth, najprostsze)

1. Otwórz [Claude.ai](https://claude.ai) → **Customize** w lewym dolnym rogu → **Connectors** → **Add More**
2. W polu URL wpisz: `https://flux.mcp.acedata.cloud/mcp`
3. Ukończ logowanie autoryzacyjne OAuth (automatyczne przekierowanie na stronę logowania AceData Cloud)
4. Wróć do interfejsu rozmowy, a narzędzie będzie gotowe do użycia

### Claude Desktop

Edytuj plik konfiguracyjny:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "flux": {
      "type": "http",
      "url": "https://flux.mcp.acedata.cloud/mcp",
      "headers": {
        "Authorization": "Bearer 你的API Token"
      }
    }
  }
}
```

Po zapisaniu uruchom ponownie Claude Desktop, aby zmiany zaczęły obowiązywać.

### Claude Code (wiersz poleceń terminala)

```bash
claude mcp add flux --transport http https://flux.mcp.acedata.cloud/mcp \
  -H "Authorization: Bearer 你的API Token"
```

### Inne klienty obsługujące MCP

Każdy klient obsługujący protokół MCP Streamable HTTP (Windsurf, Cline, ChatGPT Connectors, Gemini CLI, JetBrains AI Assistant itp.) może zostać podłączony przez uzupełnienie poniższych dwóch pozycji:

- **URL**: `https://flux.mcp.acedata.cloud/mcp`
- **Header**: `Authorization: Bearer Twój API Token`

## Metoda druga: uruchamianie lokalne (instalacja pip / uvx)

Jeśli potrzebujesz działania offline, niestandardowego kodu lub wdrożenia w sieci wewnętrznej, możesz zainstalować MCP Server lokalnie i uruchomić go przez stdio.

### Instalacja

Instalacja przez pip (zalecana):

```bash
pip install mcp-flux-pro
```

Lub instalacja ze źródeł:

```bash
git clone https://github.com/AceDataCloud/FluxMCP.git
cd FluxMCP
pip install -e .
```

Po zakończeniu instalacji możesz uruchomić usługę za pomocą polecenia `mcp-flux-pro`.

### Używanie w Claude Desktop (lokalnie)

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "flux": {
      "command": "mcp-flux-pro",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Jeśli używasz `uvx` (bez konieczności wcześniejszej instalacji pakietu):

```json
{
  "mcpServers": {
    "flux": {
      "command": "uvx",
      "args": ["mcp-flux-pro"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "你的API Token"
      }
    }
  }
}
```

Po zapisaniu konfiguracji uruchom ponownie Claude Desktop, aby zmiany zaczęły obowiązywać.

## Lista dostępnych narzędzi

| Nazwa narzędzia                    | Opis                       |
| ---------------------- | ------------------------ |
| `flux_generate_image`  | Generowanie obrazu na podstawie podpowiedzi tekstowej              |
| `flux_edit_image`      | Edycja istniejącego obrazu na podstawie instrukcji tekstowych             |
| `flux_generate_video`  | Generowanie tekst-na-wideo/obraz-na-wideo/wideo FLUX 3 oraz ulepszanie istniejących szkiców |
| `flux_get_task`        | Sprawdzanie statusu pojedynczego zadania                 |
| `flux_get_tasks_batch` | Wsadowe sprawdzanie statusu zadań                 |
| `flux_list_models`     | Wyświetlanie wszystkich dostępnych modeli i ich możliwości             |
| `flux_list_actions`    | Wyświetlanie wszystkich dostępnych narzędzi i przykładów przepływów pracy           |

## Ograniczenia modeli i rozmiarów
`flux-2-flex`, `flux-2-pro`, `flux-2-max` oraz modele Kontext muszą używać `size` w postaci
proporcji, na przykład `1:1` lub `16:9`, nie można używać wymiarów pikselowych takich jak `1024x1024`.
`flux-2-klein` obsługuje tylko generowanie i nie znajduje się wśród dostępnych modeli w `flux_edit_image`.

`flux_generate_video` rozróżnia `t2v`, `i2v`, `v2v` oraz
`draft_enhance` za pomocą `request.mode`, a dane wejściowe są wyświetlane zależnie od trybu. Ulepszanie szkicu musi odwoływać się do własnego tymczasowego `draft_task_id`.
Domyślnie wysłanie jest asynchroniczne, należy zachować zwrócone ID zadania i użyć `flux_get_task`, aby odczytać wynik.
