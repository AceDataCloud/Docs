[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstu modelu wprowadzony przez Anthropic, który pozwala modelom AI (takim jak Claude, GPT itp.) na wywoływanie zewnętrznych narzędzi za pomocą znormalizowanego interfejsu. Dzięki serwerowi Midjourney MCP udostępnionemu przez AceData Cloud, możesz bezpośrednio generować i edytować obrazy AI w klientach AI, takich jak Claude Desktop, VS Code, Cursor itp.

## Przegląd funkcji

Serwer Midjourney MCP oferuje następujące kluczowe funkcje:

- **Generowanie obrazów (Imagine)** — generowanie wysokiej jakości obrazów na podstawie tekstowych wskazówek
- **Edycja obrazów** — lokalne modyfikacje już wygenerowanych obrazów
- **Transformacja obrazów** — powiększanie, zmniejszanie, przesuwanie istniejących obrazów
- **Mieszanie obrazów (Blend)** — łączenie wielu obrazów w nowy obraz
- **Generowanie obrazów referencyjnych** — używanie obrazów referencyjnych do kierowania generowaniem
- **Opis obrazów (Describe)** — generowanie tekstowego opisu na podstawie obrazu
- **Tłumaczenie wskazówek** — tłumaczenie chińskich wskazówek na angielski
- **Pozyskiwanie nasion** — uzyskiwanie wartości seed obrazu do reprodukcji
- **Generowanie wideo** — generowanie dynamicznego wideo na podstawie obrazów
- **Zapytania o zadania** — monitorowanie postępu generowania i uzyskiwanie wyników

## Wymagania wstępne

Przed użyciem musisz uzyskać token API AceData Cloud:

1. Zarejestruj się lub zaloguj na [platformie AceData Cloud](https://platform.acedata.cloud)
2. Przejdź do strony [Midjourney Imagine API](https://platform.acedata.cloud/documents/midjourney-imagine)
3. Kliknij „Acquire”, aby uzyskać token API (pierwsze zgłoszenie daje darmowy limit)

## Instalacja i konfiguracja

### Metoda 1: instalacja pip (zalecana)

```bash
pip install mcp-midjourney
```

### Metoda 2: instalacja ze źródła

```bash
git clone https://github.com/AceDataCloud/MCPMidjourney.git
cd MCPMidjourney
pip install -e .
```

Po zakończeniu instalacji możesz uruchomić serwis za pomocą polecenia `mcp-midjourney`.

## Użycie w Claude Desktop

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "mcp-midjourney",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój token API"
      }
    }
  }
}
```

Jeśli używasz `uvx` (nie wymaga wcześniejszej instalacji pakietu):

```json
{
  "mcpServers": {
    "midjourney": {
      "command": "uvx",
      "args": ["mcp-midjourney"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój token API"
      }
    }
  }
}
```

Po zapisaniu konfiguracji uruchom ponownie Claude Desktop, aby móc korzystać z narzędzi związanych z Midjourney w rozmowie.

## Lista dostępnych narzędzi

| Nazwa narzędzia                  | Opis                     |
| ---------------------------- | ---------------------- |
| `midjourney_imagine`         | Generowanie obrazów na podstawie tekstowych wskazówek  |
| `midjourney_edit`            | Edytowanie lokalnych obszarów istniejących obrazów  |
| `midjourney_transform`       | Powiększanie, zmniejszanie, przesuwanie istniejących obrazów |
| `midjourney_blend`           | Łączenie wielu obrazów w jeden   |
| `midjourney_with_reference`  | Generowanie obrazów z użyciem obrazów referencyjnych    |
| `midjourney_describe`        | Generowanie tekstowego opisu na podstawie obrazu   |
| `midjourney_translate`       | Tłumaczenie wskazówek na angielski     |
| `midjourney_get_seed`        | Uzyskiwanie wartości seed obrazu |
| `midjourney_generate_video`  | Generowanie wideo na podstawie obrazów     |
| `midjourney_extend_video`    | Wydłużanie istniejącego wideo       |
| `midjourney_get_task`        | Zapytanie o status pojedynczego zadania     |
| `midjourney_get_tasks_batch` | Grupowe zapytanie o status zadań     |

## Przykłady użycia

Po zakończeniu konfiguracji możesz bezpośrednio wywoływać te funkcje w kliencie AI za pomocą naturalnego języka, na przykład:

- „Pomóż mi wygenerować obraz miasta w stylu cyberpunk”
- „Zmień tło tego obrazu na plażę”
- „Połącz te cztery obrazy w jeden”
- „Opisz, co znajduje się na tym obrazie”
- „Zrób z tego obrazu wideo”
- „Powiększ drugi wariant tego obrazu”
