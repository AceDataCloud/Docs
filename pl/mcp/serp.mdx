[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstu modelu wprowadzony przez Anthropic, który pozwala modelom AI (takim jak Claude, GPT itp.) na wywoływanie zewnętrznych narzędzi za pomocą znormalizowanego interfejsu. Dzięki SERP MCP Server dostarczonemu przez AceData Cloud, możesz bezpośrednio przeprowadzać wyszukiwania w Google w klientach AI, takich jak Claude Desktop, VS Code, Cursor, uzyskując wyniki wyszukiwania stron internetowych, obrazów, wiadomości, filmów, miejsc itp.

## Przegląd funkcji

SERP MCP Server oferuje następujące kluczowe funkcje:

- **wyszukiwanie stron internetowych** — wyszukiwanie wyników stron Google
- **wyszukiwanie obrazów** — wyszukiwanie obrazów Google
- **wyszukiwanie wiadomości** — wyszukiwanie wiadomości Google
- **wyszukiwanie filmów** — wyszukiwanie filmów Google
- **wyszukiwanie miejsc** — wyszukiwanie informacji o miejscach Google
- **wyszukiwanie map** — wyszukiwanie map Google
- **wielojęzyczność i wiele regionów** — wsparcie dla niestandardowych parametrów kraju i języka
- **filtrowanie według zakresu czasowego** — filtrowanie wyników według dni, tygodni, miesięcy, lat

## Przygotowanie wstępne

Przed użyciem musisz uzyskać token API AceData Cloud:

1. Zarejestruj się lub zaloguj na [platformie AceData Cloud](https://platform.acedata.cloud)
2. Przejdź do strony [Google SERP API](https://platform.acedata.cloud/documents/serp-google)
3. Kliknij „Acquire”, aby uzyskać token API (pierwsze zgłoszenie daje darmowy limit)

## Instalacja i konfiguracja

### Metoda 1: instalacja pip (zalecana)

```bash
pip install mcp-serp
```

### Metoda 2: instalacja ze źródła

```bash
git clone https://github.com/AceDataCloud/SerpMCP.git
cd SerpMCP
pip install -e .
```

Po zakończeniu instalacji możesz użyć polecenia `mcp-serp`, aby uruchomić serwis.

## Użycie w Claude Desktop

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "serp": {
      "command": "mcp-serp",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój token API"
      }
    }
  }
}
```

Jeśli używasz `uvx` (nie wymaga wcześniejszej instalacji pakietu):

```json
{
  "mcpServers": {
    "serp": {
      "command": "uvx",
      "args": ["mcp-serp"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój token API"
      }
    }
  }
}
```

Po zapisaniu konfiguracji uruchom ponownie Claude Desktop, aby móc korzystać z narzędzi wyszukiwania Google w rozmowie.
