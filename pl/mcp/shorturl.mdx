[MCP (Model Context Protocol)](https://modelcontextprotocol.io) to protokół kontekstowy modelu opracowany przez Anthropic, który umożliwia modelom AI (takim jak Claude, GPT itp.) wywoływanie zewnętrznych narzędzi za pomocą ustandaryzowanego interfejsu. Dzięki ShortURL MCP Server udostępnianemu przez AceData Cloud możesz bezpośrednio generować krótkie linki w klientach AI takich jak Claude Desktop, VS Code, Cursor i innych.

## Przegląd funkcji

ShortURL MCP Server oferuje następujące kluczowe funkcje:

- **Skracanie pojedynczego linku** — konwersja długiego URL na krótki, łatwy do udostępnienia link
- **Skracanie wsadowe** — jednoczesne skracanie wielu URL (maksymalnie 10)
- **Instrukcje użytkowania** — uzyskanie pełnej dokumentacji i najlepszych praktyk
- **Informacje o API** — przegląd szczegółów usługi API oraz kodów błędów

## Wymagania wstępne

Przed użyciem musisz uzyskać AceData Cloud API Token:

1. Zarejestruj się lub zaloguj na [platformie AceData Cloud](https://platform.acedata.cloud)
2. Przejdź do strony [ShortURL API](https://platform.acedata.cloud/documents/short-url)
3. Kliknij „Acquire”, aby uzyskać API Token (pierwsza rejestracja daje darmowy limit)

## Instalacja i konfiguracja

### Metoda 1: instalacja przez pip (zalecane)

```bash
pip install mcp-shorturl
```

### Metoda 2: instalacja ze źródła

```bash
git clone https://github.com/AceDataCloud/ShortURLMCP.git
cd ShortURLMCP
pip install -e .
```

Po instalacji możesz uruchomić serwer poleceniem `mcp-shorturl`.

## Użycie w Claude Desktop

Edytuj plik konfiguracyjny Claude Desktop:

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

Dodaj następującą konfigurację:

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Jeśli używasz `uvx` (nie wymaga wcześniejszej instalacji pakietów):

```json
{
  "mcpServers": {
    "shorturl": {
      "command": "uvx",
      "args": ["mcp-shorturl"],
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"
      }
    }
  }
}
```

Po zapisaniu konfiguracji i ponownym uruchomieniu Claude Desktop możesz korzystać z narzędzi ShortURL w rozmowach.

## Użycie w VS Code / Cursor

W katalogu głównym projektu utwórz plik `.vscode/mcp.json`:

```json
{

    "shorturl": {
      "command": "mcp-shorturl",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "Twój API Token"

    }
  }
}
```

Lub użyj `uvx`:

```json
{
```

## Lista dostępnych narzędzi

| Nazwa narzędzia          | Opis                                      |
|--------------------------|-------------------------------------------|
| `shorturl_create`        | Skracanie pojedynczego URL                 |
| `shorturl_batch_create`  | Skracanie wielu URL jednocześnie (do 10)  |
| `shorturl_get_usage_guide` | Uzyskanie pełnej instrukcji użytkowania  |
| `shorturl_get_api_info`  | Uzyskanie szczegółów usługi API            |

## Przykłady użycia

Po konfiguracji możesz wywoływać funkcje za pomocą naturalnego języka w klientach AI, np.:

- „Skróć ten link”
- „Skróć wsadowo tych 5 URL”
- „Wygeneruj krótki link do udostępnienia”
