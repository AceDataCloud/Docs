Niniejszy dokument przedstawia instrukcje dotyczące integracji z API Veo Extend. Interfejs ten służy do **wydłużania** już wygenerowanego wideo Veo, AI automatycznie dopisuje kolejne obrazy.

## Proces aplikacji

Aby skorzystać z API, należy najpierw złożyć wniosek na odpowiedniej stronie usługi Veo. Jeśli nie jesteś zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania.

## Podstawowe użycie

Aby wywołać ten interfejs, należy przekazać następujące parametry:

- `video_id` (wymagane): ID zadania źródłowego wideo (pochodzące z `/veo/videos` lub z samego interfejsu).
- `model` (wymagane): model używany do wydłużania, **obsługiwane są tylko modele `veo31-fast` i `veo31`**, inne modele nie są wspierane.
- `prompt` (opcjonalne): tekstowy wskazówka do prowadzenia wydłużania segmentu obrazu.
- `aspect_ratio` (opcjonalne): `16:9` lub `9:16`, domyślnie `16:9`.
- `resolution` (opcjonalne): `720p` lub `1080p`.

Przykład żądania:

```shell
curl -X POST 'https://api.acedata.cloud/veo/extend' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "model": "veo31-fast",
    "prompt": "the camera slowly zooms out to reveal more of the landscape"
  }'
```

Wynik zwrotny jest taki sam jak w przypadku `/veo/videos`:

```json
{
  "success": true,
  "task_id": "5fa2d9a6-7e54-481b-a4b0-3dc6f25dd2ab",
  "data": [
    {
      "id": "9b6f3b6b9c45419fbf2e3fe2f10b2b3a",
      "video_url": "https://platform.cdn.acedata.cloud/veo/5fa2d9a6.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

## Ważne ograniczenia

`video_id` musi pochodzić z generacji TTAPI lub z zakończonego wydłużania `data[].id`. Historyczne ID wideo wygenerowane przez starą linię przed przełączeniem TTAPI nie mogą być używane w tym interfejsie, wywołanie zwróci `400 bad_request`; proszę ponownie wygenerować przez `/veo/videos`, a następnie wydłużyć.

Wideo wynikowe z `/veo/extend` może **być ponownie wydłużane przez `/veo/extend`**, ale **nie może** być przetwarzane przez następujące interfejsy:

- `/veo/reshoot` — nie można zmieniać ruchu kamery
- `/veo/objects` — nie można dodawać ani usuwać obiektów

Jeśli przekazane `video_id` jest wynikiem wydłużania, odpowiednie interfejsy zwrócą błąd 400, proszę użyć oryginalnego wideo jako źródła.

## Opis rozliczeń

- `model=veo31-fast`: 1.68 Kredyt / raz
- `model=veo31`: 12.00 Kredyt / raz

## Asynchroniczny callback

Interfejs obsługuje tryb asynchroniczny, wystarczy przekazać `callback_url`, aby po zakończeniu zadania otrzymać wynik za pomocą żądania POST. Jeśli nie ma publicznego adresu zwrotnego, można również ustawić `async` na `true`, interfejs natychmiast zwróci `task_id`, a następnie można uzyskać wyniki, korzystając z odpowiedniego interfejsu do zapytań o zadania.
