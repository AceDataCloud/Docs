W tym dokumencie przedstawiono instrukcje dotyczące integracji z API Veo Upsample. Interfejs ten służy do podnoszenia jakości już wygenerowanego wideo Veo lub do wyjścia w formie podglądu GIF.

## Proces aplikacji

Aby skorzystać z API, należy najpierw złożyć wniosek na odpowiedniej stronie usług Veo. Jeśli nie jesteś zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania.

## Podstawowe użycie

Aby wywołać ten interfejs, należy przekazać dwa parametry:

- `video_id`: ID zadania źródłowego wideo. Może to być ID wideo wygenerowane przez dowolny z interfejsów: `/veo/videos`, `/veo/extend`, `/veo/reshoot`, `/veo/objects`.
- `action`: akcja podnoszenia jakości, obsługujące następujące trzy opcje:
  - `1080p`: podniesienie jakości wideo do rozdzielczości 1080p.
  - `4k`: podniesienie jakości wideo do rozdzielczości 4K.
  - `gif`: konwersja wideo na podgląd GIF.

Przykład żądania:

```shell
curl -X POST 'https://api.acedata.cloud/veo/upsample' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "4k"
  }'
```

Wynik zwrotny jest taki sam jak w przypadku `/veo/videos`, nadal jest to struktura zadania asynchronicznego, można sprawdzić status zadania za pomocą `task_id` w interfejsie `/veo/tasks`:

```json
{
  "success": true,
  "task_id": "8f5a90ae-3f86-4c4f-86f7-7126f5e92c76",
  "trace_id": "0f3e09c2-4c2e-46ea-9cdc-a31ec48b7c12",
  "data": [
    {
      "id": "253eedc47f1c4eb2a370ed2312168f4b",
      "video_url": "https://platform.cdn.acedata.cloud/veo/8f5a90ae.mp4",
      "created_at": "2025-07-25 16:07:43",
      "complete_at": "2025-07-25 16:10:28",
      "state": "succeeded"
    }
  ]
}
```

Opis pól zwrotnych:

- `success`: czy zadanie podnoszenia jakości zostało pomyślnie złożone.
- `task_id`: ID bieżącego zadania podnoszenia jakości.
- `data`: wyniki wideo po podniesieniu jakości.
  - `video_url`: adres wideo po podniesieniu jakości.

## Opis rozliczeń

- `action=1080p`: 0.16 Credit / raz
- `action=4k`: 0.50 Credit / raz
- `action=gif`: 0.13 Credit / raz

Jeśli przekazane `action` nie znajduje się w powyższej enumeracji, domyślnie będzie rozliczane jako 0.50 Credit. Zaleca się jawne przekazywanie obsługiwanych wartości.

## Asynchroniczny callback

Interfejs obsługuje również tryb asynchroniczny, wystarczy przekazać `callback_url`, aby po zakończeniu zadania otrzymać wynik za pomocą żądania POST. Jeśli nie ma publicznego adresu zwrotnego, można ustawić `async` na `true`, a interfejs natychmiast zwróci `task_id`, a następnie można uzyskać wyniki, wykonując zapytania do odpowiedniego interfejsu zadań.
