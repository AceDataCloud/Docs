Niniejszy dokument przedstawia opis integracji API Veo Reshoot. Interfejs ten służy do **ponownego generowania** już wygenerowanego wideo Veo zgodnie z **nowym sposobem ruchu kamery**, przy zachowaniu tej samej zawartości obrazu, ale pozycja kamery i ruch będą reinterpretowane zgodnie z `motion_type`.

## Proces aplikacji

Aby skorzystać z API, należy najpierw złożyć wniosek na odpowiedniej stronie usług Veo. Jeśli nie jesteś zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania.

## Podstawowe użycie

Aby wywołać ten interfejs, należy przekazać następujące parametry:

- `video_id` (wymagane): ID zadania źródłowego wideo. **Nie może** być to wideo wyjściowe z `/veo/extend`.
- `motion_type` (wymagane): nowy sposób ruchu kamery, używając prostych aliasów w stylu wielkich liter i podkreśleń.

### Obsługiwane wartości `motion_type`

| Alias                             | Znaczenie           |
| ------------------------------ | ------------ |
| `STATIONARY`                   | Kamera nieruchoma       |
| `STATIONARY_UP`                | Kamera nieruchoma, w górę    |
| `STATIONARY_DOWN`              | Kamera nieruchoma, w dół    |
| `STATIONARY_LEFT`              | Kamera nieruchoma, w lewo      |
| `STATIONARY_RIGHT`             | Kamera nieruchoma, w prawo      |
| `STATIONARY_DOLLY_IN_ZOOM_OUT` | Kamera nieruchoma, do przodu + zoom out |
| `STATIONARY_DOLLY_OUT_ZOOM_IN` | Kamera nieruchoma, do tyłu + zoom in |
| `UP`                           | Kamera w górę         |
| `DOWN`                         | Kamera w dół         |
| `LEFT_TO_RIGHT`                | Kamera przesuwa się z lewej do prawej     |
| `RIGHT_TO_LEFT`                | Kamera przesuwa się z prawej do lewej     |
| `FORWARD`                      | Kamera przesuwa się do przodu       |
| `BACKWARD`                     | Kamera przesuwa się do tyłu        |
| `DOLLY_IN_ZOOM_OUT`            | Ruch do przodu + zoom out   |
| `DOLLY_OUT_ZOOM_IN`            | Ruch do tyłu + zoom in   |

Przykład żądania:

```shell
curl -X POST 'https://api.acedata.cloud/veo/reshoot' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "motion_type": "LEFT_TO_RIGHT"
  }'
```

Struktura wyników jest taka sama jak w `/veo/videos`.

## Opis rozliczeń

- Jednorazowe ponowne nagranie: 1.20 kredytu.

## Asynchroniczny callback

Interfejs obsługuje tryb asynchroniczny, wystarczy przekazać `callback_url`, aby po zakończeniu zadania otrzymać wynik za pomocą żądania POST. Jeśli nie ma publicznego adresu zwrotnego, można również ustawić `async` na `true`, a interfejs natychmiast zwróci `task_id`, a następnie można uzyskać wyniki, wykonując zapytania do odpowiedniego interfejsu zadań.
