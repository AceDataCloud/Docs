W tym dokumencie przedstawiono opis integracji API Veo Objects. Interfejs ten służy do wykonywania operacji **dodawania lub usuwania obiektów** w już wygenerowanym wideo Veo (lokalne przerysowanie oparte na masce).

## Proces aplikacji

Aby skorzystać z API, należy najpierw złożyć wniosek na odpowiedniej stronie usługi Veo. Jeśli nie jesteś zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania.

## Podstawowe użycie

Aby wywołać ten interfejs, należy przekazać następujące parametry:

- `video_id` (wymagane): ID zadania źródłowego wideo. **Nie może** być to wideo wyjściowe z `/veo/extend`.
- `action` (wymagane): typ operacji, `insert` lub `remove`.
- `prompt`:
  - `action=insert`: **wymagane**, opis obiektu do dodania.
  - `action=remove`: opcjonalne, opis treści do usunięcia (głównie do rejestrowania logów, rzeczywisty obszar usunięcia jest określany przez `image_mask`).
- `image_mask`:
  - `action=insert`: opcjonalne. Jeśli nie zostanie przekazane, AI automatycznie zdecyduje o miejscu wstawienia; jeśli zostanie przekazane, obiekt zostanie wstawiony w obszarze białych pikseli.
  - `action=remove`: **wymagane**, obszar białych pikseli to obiekt do usunięcia.

`image_mask` akceptuje dwa formaty:

1. **Publicznie dostępny adres URL obrazu HTTP(S)** (zalecane).
2. **Zakodowany w base64 ciąg JPEG**, może mieć prefiks `data:image/jpeg;base64,` lub być czystym base64.

Przykład żądania (dodanie obiektu, bez przekazywania maski, pozwalając AI na automatyczne określenie lokalizacji):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "insert",
    "prompt": "add a flying pig with black wings"
  }'
```

Przykład żądania (usunięcie obiektu na podstawie maski):

```shell
curl -X POST 'https://api.acedata.cloud/veo/objects' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "video_id": "dd01fc69-e1f7-4b68-aa8c-463f6b748d11",
    "action": "remove",
    "image_mask": "https://example.com/mask.jpg",
    "prompt": "remove the white cloud"
  }'
```

Struktura wyników jest taka sama jak w `/veo/videos`.

## Opis rozliczeń

- `action=insert` lub `remove`: 1.50 Credit / raz.

## Asynchroniczny callback

Interfejs obsługuje tryb asynchroniczny, wystarczy przekazać `callback_url`, aby po zakończeniu zadania otrzymać wynik za pomocą żądania POST. Jeśli nie ma publicznego adresu zwrotnego, można również ustawić `async` na `true`, a interfejs natychmiast zwróci `task_id`, a następnie można uzyskać wyniki, wykonując zapytania do odpowiedniego interfejsu zadań.
