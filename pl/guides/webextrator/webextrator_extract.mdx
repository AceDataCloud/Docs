`POST https://api.acedata.cloud/webextrator/extract`

Inteligentne API ekstrakcji WebExtrator przekształca adres URL w **typowany, ustrukturyzowany wynik** — artykuł, produkt,
przepis, wideo, dyskusję, ofertę pracy itd. — jednocześnie dołączając oczyszczony Markdown i zwykły tekst. Użyj tego interfejsu,
gdy potrzebujesz „czystych, ustrukturyzowanych danych”, a nie surowego HTML.

## Proces aplikacji

Aby korzystać z usługi WebExtrator, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do wywołania wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Pierwsze zgłoszenie otrzyma darmowy limit, aby można było bezpłatnie przetestować; w przypadku niewystarczającego limitu można doładować ogólny bilans w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Strona usługi WebExtrator →](https://platform.acedata.cloud/service/webextrator)

## Autoryzacja

```
Authorization: Bearer YOUR_API_KEY
Content-Type:  application/json
```

## Parametry żądania

Extract akceptuje **wszystkie** parametry [Render API](/pl/guides/webextrator/webextrator_render)
(`url`, `user_agent`, `timeout`, `wait_until`, `delay`, `wait_for_selector`,
`block_resources`, `headers`, `cookies`, `callback_url`, `bypass_cache`,
`cache_ttl_seconds`, `async`), a także dwa pola specyficzne dla Extract:

| Pole | Typ | Wymagane | Domyślna | Opis |
|------|------|:----:|------|------|
| `expected_type` | enum | ❌ | Automatyczne wykrywanie | Wskazówka dotycząca typu strony: `product` / `article` / `general`. Określa oczekiwany typ wyniku. |
| `enable_llm` | boolean | ❌ | `false` | Umożliwia wywołanie ekstrakcji LLM, gdy schema.org nie znajdzie dopasowania. Na stronach bez JSON-LD, takich jak Amazon / HN / Greenhouse, należy ją włączyć, aby uzyskać wyniki z określonym typem. |

### Pola najwyższego poziomu

| Pole | Typ | Opis |
|------|------|------|
| `kind` | string | Stała wartość `"extract"`. |
| `url` | string | Przesłany adres URL. |
| `finalUrl` | string | Końcowy adres URL po przekierowaniach. |
| `contentType` | enum | Typ strony: `product` / `article` / `general`. |
| `title` | string | Tytuł strony. |
| `description` | string? | Opis lub podsumowanie strony. |
| `byline` | string? | Autor, kanał lub firma. |
| `language` | string? | `<html lang>`.  |
| `siteName` | string? | `og:site_name`.  |
| `publishedAt` | string? | Czas publikacji w formacie ISO 8601. |
| `images` | string[] | Maksymalnie 50 `<img src />`, przetworzonych na bezwzględne adresy URL, bez duplikatów, z pominięciem identyfikatorów URI `data:`. |
| `links` | string[] | Maksymalnie 100 linków zewnętrznych, z odfiltrowanymi fragmentami / `javascript:` / `mailto:` / `tel:`. |
| `markdown` | string | Treść Markdown strony. |
| `text` | string | Zwykły tekst strony. |
| `structured` | object | Pełny ustrukturyzowany wynik, patrz poniżej. |
| `rawSignals` | object | Informacje diagnostyczne do debugowania. |
| `cached` | boolean? | `true` w przypadku trafienia w pamięci podręcznej. |
| `cacheStoredAt` | number? | Znacznik czasu Unix w milisekundach, gdy wpis w pamięci podręcznej został zapisany po raz pierwszy. |

### Pola podrzędne `data.structured`

| Pole podrzędne | Kiedy występuje | Opis |
|--------|---------|------|
| `schemaOrg` | Zawsze | `{ primary, breadcrumbs, all }`. `primary` to typowana encja o najwyższym priorytecie; jeśli nie zostanie znaleziona, używane jest `null`. |
| `openGraph` | Zawsze | `{ title, description, image, type }`, pochodzące z `<meta property="og:*" />`. |
| `jsonLd` | Zawsze | Surowa tablica JSON wszystkich bloków `<script type="application/ld+json">`. |
| `llm` | Gdy LLM został uruchomiony i zakończył się pomyślnie | `{ kind, data, model, promptCharCount }`, typowany wynik. |
| `llmError` | Gdy LLM został uruchomiony, ale zakończył się niepowodzeniem | `{ kind, error, model }`, żądanie może nadal zwracać inne wyodrębnione pola. |
| `amazon` | Gdy URL jest `amazon.*` | Wyniki starszego rozszerzenia Amazon; w przypadku nowych integracji używaj wyników typowanych. |

## Typy wyników schema.org

`structured.schemaOrg.primary` obsługuje następujące typy wyników:

| Typ schema.org | kind | Pola wyjściowe |
|----------------|----------|----------|
| `Product` | product | `name, sku, gtin, model, color, brand, url, images, offer.{price,currency,availability,condition,seller}, rating.{value,count}, reviews[], properties[]` |
| `Recipe` | recipe | `name, description, image, datePublished, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords, recipeCategory, recipeCuisine` |
| `VideoObject` | video | `name, description, thumbnailUrl, uploadDate, duration, embedUrl, contentUrl, channel, interactionCount` |
| `JobPosting` | job | `title, description, datePosted, validThrough, hiringOrganization, jobLocation, baseSalary, employmentType` |
| `Event` (w tym `*Event`) | event | `name, description, startDate, endDate, location.{name,address}, organizer, offer.{url,price,currency}` |
| `Article` / `NewsArticle` / `BlogPosting` / `ScholarlyArticle` / `TechArticle` / `Report` / `*NewsArticle` | article | `subtype, headline, description, datePublished, dateModified, author, publisher, image[], url, sameAs[]` |
| `FAQPage` | faq | `questions[{question, answer}]` |
| `BreadcrumbList` | (dołączone do sibling) | Zawsze wyprowadzane do `structured.schemaOrg.breadcrumbs[]`, nigdy jako primary. |

## Typy wyników LLM

Gdy `enable_llm: true`, a strona nie zawiera dostępnych danych strukturalnych schema.org, można zwrócić wyniki ekstrakcji następujących typów:

| Kind | Pola wymagane | Pola opcjonalne |
|------|---------|---------|
| `article` | `headline` | `description, byline, publishedAt, language, topics[], sections[{heading,summary}]` |
| `product` | `name` | `description, brand, sku, price, currency, availability, rating.{value,count}, bullets[], specifications[{name,value}]` |
| `discussion` | `title` | `author, postedAt, points, commentCount, body, url` |
| `recipe` | `name` | `description, author, cookTime, prepTime, totalTime, recipeYield, ingredients[], instructions[], nutrition, rating, keywords[]` |
| `video` | `name` | `description, channel, uploadDate, duration, viewCount, likeCount, thumbnailUrl, transcript` |
| `job` | `title` | `description, company, location, remote, employmentType, datePosted, validThrough, salaryMin, salaryMax, salaryCurrency, salaryPeriod, responsibilities[], qualifications[]` |

## Pamięć podręczna

Te same URL, parametry żądania, `cookies` i `headers` mogą ponownie wykorzystać wyniki z pamięci podręcznej; `async`, `bypass_cache` i `cache_ttl_seconds` służą do kontrolowania sposobu wykonania i zachowania pamięci podręcznej.

| Pole | Działanie |
|------|------|
| `bypass_cache: true` | Pomiń odczyt; wynik tego żądania nadal zostanie zapisany w pamięci podręcznej, dzięki czemu identyczne żądanie następnym razem może trafić do cache. |
| `cache_ttl_seconds: 0` | Ta odpowiedź **nie będzie buforowana**. |
| `cache_ttl_seconds: N` | Ustaw niestandardowy TTL dla tego wpisu (domyślnie 3600 sekund). |

Odpowiedzi trafiające do pamięci podręcznej będą zawierać `data.cached: true` oraz `data.cacheStoredAt: <unix-ms>`.

## Tryb asynchroniczny i callback

Ustawienie `async: true` włącza tryb asynchroniczny (podanie `callback_url` również automatycznie włączy). Platforma natychmiast zwraca (HTTP 200):

```json
{
  "success": true,
  "task_id": "550e8400-...",
  "trace_id": "6ba7b810-...",
  "started_at": 1777717800.123
}
```

Po zakończeniu zadania pełny envelope zostanie wysłany `POST` do twojego `callback_url` (jeśli skonfigurowano). Można również
później aktywnie sprawdzić przez [`/webextrator/tasks`](/pl/guides/webextrator/webextrator_tasks).

```bash

  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://en.wikipedia.org/wiki/Diffbot",
    "expected_type": "article"
```

### Python (requests)

```python
import os, requests

API_KEY = os.environ["ACEDATA_API_KEY"]

resp = requests.post(
    "https://api.acedata.cloud/webextrator/extract",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "url": "https://en.wikipedia.org/wiki/Diffbot",
        "expected_type": "artykuł",
    },
    timeout=120,
)
resp.raise_for_status()
data = resp.json()["data"]

primary = (data.get("structured") or {}).get("schemaOrg", {}).get("primary")
print("contentType:", data["contentType"])
print("title:      ", data["title"])
print("byline:     ", data.get("byline"))
print("publishedAt:", data.get("publishedAt"))
if primary and primary["kind"] == "artykuł":
    print("headline:    ", primary["headline"])
    print("dateModified:", primary.get("dateModified"))
```

### Node.js (fetch)

```js
const apiKey = process.env.ACEDATA_API_KEY;

const res = await fetch('https://api.acedata.cloud/webextrator/extract', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${apiKey}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    url: 'https://www.allrecipes.com/recipe/16354/easy-meatloaf/',
  }),
});
const { data } = await res.json();
const recipe = data?.structured?.schemaOrg?.primary;
console.log(recipe.name, recipe.cookTime, recipe.ingredients.length, 'rodzaj składników');
```

## Wskazówki i pułapki

- **Przekaż `expected_type`, gdy musisz określić typ strony.** Na przykład dla strony artykułu użyj `article`, a dla strony produktu — `product`.
- **`enable_llm: true` jest bezpłatne na stronach dopasowanych przez schema.org.** LLM jest wywoływany tylko wtedy, gdy w schema.org
  brakuje primary, więc domyślne włączenie tej opcji jest bezpieczne.
- **Podczas debugowania najpierw sprawdź `rawSignals.hasJsonLd`.** Jeśli jest to `true`, ale `structured.schemaOrg.primary`
  ma wartość `null`, oznacza to, że `@type` strony nie jest jeszcze obsługiwane; możesz nam to zgłosić.
- **`structured.llmError` ma charakter informacyjny.** Żądanie nadal może pomyślnie zwrócić inne wyodrębnione pola. Sprawdź
  `llmError.error`, aby ustalić przyczynę (przekroczenie limitu czasu, nieudane parsowanie JSON, nieudana walidacja struktury).
- **`links[]` dla stron innych niż artykuły nie jest sortowane według trafności.** Stosowane jest jedynie czyszczenie według zasady „maksymalnie 100 pozycji + filtrowanie nieprawidłowych protokołów”
  w miarę możliwości.
- **Trafienia w pamięci podręcznej również są płatne.**
