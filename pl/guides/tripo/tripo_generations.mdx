---
title: "Generowanie Tripo 3D"
description: "Tripo 3D API guide - Ace Data Cloud"
---

Wywołaj `POST /tripo/generations`, aby utworzyć nowy model, przekazując tekst, pojedynczy obraz lub wiele widoków tego samego obiektu. Użyj tokenu AceDataCloud; domyślnie wynik jest zwracany synchronicznie. Po przekazaniu `async: true` lub `callback_url` najpierw zwracane są HTTP 200 i `task_id`. Wywołanie zwrotne po zakończeniu ma taką samą strukturę JSON jak wynik synchroniczny.

```bash
curl -X POST https://api.acedata.cloud/tripo/generations \
  -H "Authorization: Bearer ${ACEDATACLOUD_API_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"一个双臂水平伸展、双腿分开的机器人角色","async":true}'
```

`action` ma domyślnie wartość `generate`. Wybierz jedno z trzech źródeł danych: `prompt` (1–1024 znaki), `image_url` lub `image_urls`. Obrazy muszą być publicznie dostępnymi plikami PNG/JPEG przez HTTPS i mieć maksymalnie 20 MiB. Wiele widoków należy uporządkować kolejno: przód, lewa strona, tył, prawa strona; należy podać widok z przodu i co najmniej jeden inny, a pośrednie widoki można pominąć za pomocą null.

`model` ma domyślnie wartość `v3.1-20260211`; można też jawnie wybrać `v3.0-20250812`, `v2.5-20250123`, `P1-20260311` lub `P2-20260801`. `texture` ma domyślnie wartość `standard`; dla samej geometrii użyj `none`. Różne modele i poziomy tekstur zużywają różne ilości limitu.

Pobierz plik GLB z `data[0].model_url`; `image_url` to opcjonalny podgląd. Zachowaj `data[0].id` do późniejszych operacji teksturowania, konwersji lub operacji na szkielecie. Przy ponawianiu tego samego zgłoszenia zachowaj ten sam `Idempotency-Key` i treść żądania.
