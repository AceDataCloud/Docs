Niniejszy artykuł przedstawia integrację z Nano Banana Images API i sposób korzystania z niego. Interfejs obsługuje dwie funkcje: **generowanie obrazów (generate)** oraz **edycję obrazów (edit)**.

## Proces uzyskiwania dostępu

Aby korzystać z Nano Banana Images API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go do późniejszego użycia.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany lub zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, gdzie możesz się zarejestrować i zalogować. Po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden API Token wystarczy, aby korzystać ze wszystkich usług platformy. Nie ma potrzeby ubiegania się o osobny token dla każdej usługi.** Przy pierwszym uzyskaniu tokena otrzymasz bezpłatny limit, dzięki któremu możesz bezpłatnie wypróbować usługę. Gdy limit będzie niewystarczający, możesz doładować ogólne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Przegląd interfejsu

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Metoda uwierzytelniania**：przekazanie `authorization: Bearer {token}` w nagłówku HTTP
- **Nagłówki żądania**：
  - `accept: application/json`
  - `content-type: application/json`
- **Akcje (action)**：
  - `generate`：generowanie obrazu na podstawie tekstowego promptu
  - `edit`：edycja obrazu na podstawie dostarczonego obrazu
- **Model (model)** (opcjonalny)：
  - `nano-banana` (domyślny)：oparty na Gemini 2.5 Flash Image, szybki i tani
  - `nano-banana-2-lite`：oparty na Gemini 3.1 Flash Lite Image, obsługuje tylko 1K, szybkie generowanie
  - `nano-banana-2`：oparty na Gemini 3.1 Flash Image Preview, jakość klasy Pro + szybkość Flash
  - `nano-banana-2.1`：nowej generacji wydajny model obrazów, obsługuje generowanie i edycję w rozdzielczościach 1K, 2K i 4K
  - `nano-banana-pro`：oparty na Gemini 3 Pro Image Preview, najwyższa jakość
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：oficjalne wersje odpowiednich modeli, zapewniające lepszą jakość obrazu i stabilność, z innym sposobem rozliczania
- **Asynchroniczne wywołanie zwrotne**：opcjonalne, powiadomienia o zakończeniu zadania i wyniku można otrzymywać za pomocą `callback_url`
- **Liczba obrazów**：opcjonalna, za pomocą `count` można określić od 1 do 4 obrazów, domyślnie 1; każdy obraz jest generowany przez osobne wywołanie; zwykłe błędy techniczne lub odmowy bezpieczeństwa ze strony dostawcy wpływają tylko na dane wywołanie, pozostałe pomyślnie wygenerowane obrazy są zwracane normalnie, a rozliczenie odbywa się na podstawie rzeczywistej liczby wygenerowanych obrazów

## Szybki start: generowanie obrazów (`action=generate`)

**Minimalne wymagane parametry**：`action`、`prompt`

Jeśli chcesz bezpośrednio wygenerować obraz na podstawie promptu tekstowego, wystarczy ustawić `action` na `generate` i podać jasny `prompt`.

### Przykład żądania (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Przykład żądania (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

```json
  "trace_id": "60df8d38-f265-4986-aec7-75c9220bced2",
  "data": [
    {
      "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay.       "image_url": "https://cdn.acedata.cloud/assets/examples/nanobanana/1d0160b4-93f9-4229-8926-ea9ef0bed336-34b3dc2195e8.png"
    }

```

### Opis pól

- `success`：czy bieżące żądanie zakończyło się sukcesem.
- `task_id`：identyfikator zadania.
- `trace_id`：identyfikator śledzenia, ułatwiający diagnozowanie problemów.
- `count`：liczba obrazów, które mają zostać wygenerowane lub edytowane, obsługuje od 1 do 4, domyślnie 1. `data` zawiera tylko pomyślnie wygenerowane obrazy, a rozliczenie odbywa się na podstawie rzeczywistej liczby zwróconych obrazów. Każde wywołanie generowania musi korzystać z natywnej polityki bezpieczeństwa dostawcy; odmowa w jednym wywołaniu nie wpływa na pozostałe pomyślne wywołania, a jeśli wszystkie wywołania zostaną odrzucone, zwracany jest kod 403.
- `data[]`：lista wyników.
  - `prompt`：prompt użyty do generowania (zwracany w odpowiedzi).
  - `image_url`：bezpośredni URL wygenerowanego obrazu.

> Uwaga: `/nano-banana/images` wymaga jedynie parametrów `action` i `prompt`, aby wygenerować obraz.

## Edycja obrazów (`action=edit`)

Jeśli chcesz edytować istniejący obraz, ustaw `action` na `edit` i przekaż listę linków do obrazów przeznaczonych do edycji za pomocą `image_urls` (jeden lub więcej), a także podaj `prompt` opisujący cel edycji.

Na przykład, jeśli dostarczymy zdjęcie osoby i zdjęcie ubrania, aby ubrać tę osobę w dane ubranie, możemy przekazać oba linki do obrazów i ustawić `action` na `edit`. URL może być adresem HTTP, publicznie dostępnym linkiem z protokołem `https` lub `http`, albo obrazem zakodowanym w Base64, takim jak `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Przykład żądania (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Przykład żądania (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

- `image_urls[]`: lista adresów URL obrazów do edycji (muszą być publicznie dostępne). Można przekazać wiele obrazów, a usługa wykorzysta te materiały wraz z `prompt` do wykonania edycji.
- Pozostałe pola są takie same jak w odpowiedzi dotyczącej „generowania obrazów”.

## Wywołanie zwrotne asynchroniczne (opcjonalne, zalecane)

Generowanie lub edycja może zająć trochę czasu. Aby uniknąć zajmowania zasobów przez długotrwałe połączenia, zaleca się korzystanie z **wywołania zwrotnego Webhook** za pomocą `callback_url`:

1. Dodaj `callback_url` do treści żądania, na przykład adres Webhook Twojego serwera (musi być publicznie dostępny i obsługiwać POST JSON).
2. API **natychmiast zwróci** odpowiedź zawierającą `task_id` (lub podstawowy wynik).
3. Po zakończeniu zadania platforma wyśle pełny JSON na adres `callback_url` za pomocą metody `POST`. Możesz powiązać żądanie z wynikiem za pomocą `task_id`.

**Przykład ładunku wywołania zwrotnego** (struktura pól jest taka sama jak w przypadku synchronicznej pomyślnej odpowiedzi):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Obsługa błędów

W przypadku niepowodzenia wywołania zwracany jest standardowy format błędu wraz z identyfikatorem śledzenia. Typowe błędy:

- **400 `token_mismatched`**: nieprawidłowe żądanie lub błędne parametry.
- **400 `api_not_implemented`**: interfejs API nie został zaimplementowany (skontaktuj się z pomocą techniczną).
- **401 `invalid_token`**: niepowodzenie uwierzytelniania lub brak tokenu.
- **403 `forbidden`**: natywna polityka bezpieczeństwa dostawcy odrzuciła żądanie lub wygenerowany wynik. To wywołanie nie zwróci obrazu ani nie zostanie naliczona za nie opłata; w przypadku żądań obejmujących wiele obrazów inne pomyślne wywołania nadal mogą zostać zwrócone i rozliczone.
- **429 `too_many_requests`**: przekroczono limit częstotliwości żądań.
- **500 `api_error`**: błąd po stronie serwera.

### Przykład odpowiedzi z błędem

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Zestawienie parametrów i uwagi

- **Wymagane**: `action`, `prompt`
- **Tylko do edycji**: `image_urls` (tablica zawierająca co najmniej 1 element)
- **Opcjonalne**: `model` (domyślnie `nano-banana`, opcjonalnie `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-2.1`, `nano-banana-pro`; z wyjątkiem `nano-banana-2.1` dostępne są również odpowiadające im oficjalne wersje kanału `:official`), `aspect_ratio` (`auto` lub konkretny współczynnik proporcji, np. `1:1`, `16:9`), `resolution` (rozdzielczość, np. `1K`, `2K`, `4K`; `nano-banana-2-lite` obsługuje wyłącznie `1K`), `callback_url` (do asynchronicznych wywołań zwrotnych)
- **Headers**: należy podać `authorization: Bearer {token}`; zaleca się ustawienie `accept` na `application/json`
- **Dostępność obrazów**: adresy `image_urls` muszą być bezpośrednimi linkami publicznie dostępnymi przez Internet (HTTP/HTTPS); zaleca się korzystanie z HTTPS
- **Idempotencja i śledzenie**: zachowaj `task_id` i `trace_id`, aby ułatwić diagnozowanie problemów i powiązanie wyników

Jawne przekazanie `"aspect_ratio": "auto"` spowoduje wybranie najbliższego predefiniowanego formatu na podstawie proporcji, orientacji lub układu określonych w promptcie, co ma zastosowanie zarówno do generowania, jak i edycji. Na przykład, jeśli w promptcie pojawi się „miniatura YouTube”, można wybrać format `16:9`. Jeśli prompt nie określa wymiarów lub automatyczne określenie nie jest dostępne, generowanie obrazu z tekstu wykorzystuje domyślny format, natomiast edycja obrazu zachowuje proporcje pierwszego obrazu referencyjnego i wybiera najbliższy obsługiwany format. Jeśli to pole zostanie pominięte, użyty zostanie domyślny format lub proporcje obrazu referencyjnego. Jeśli wymagany format jest już jasno określony, należy bezpośrednio przekazać konkretną proporcję.
