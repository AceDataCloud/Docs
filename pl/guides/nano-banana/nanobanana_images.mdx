Ten dokument przedstawia integrację i użycie Nano Banana Images API. Interfejs obsługuje dwie możliwości: **generowanie obrazów (generate)** oraz **edycję obrazów (edit)**.

## Proces aplikacji

Aby korzystać z Nano Banana Images API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token, i zachowaj go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany lub zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania z zaproszeniem do rejestracji i zalogowania się, a po zakończeniu automatycznie wrócisz na bieżącą stronę.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, bez konieczności osobnego składania wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz darmowy limit, aby móc korzystać z bezpłatnej wersji próbnej; gdy limit będzie niewystarczający, możesz doładować ogólne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Nano Banana Images API →](https://platform.acedata.cloud/documents/nano-banana-images)

## Przegląd interfejsu

- **Base URL**：`https://api.acedata.cloud`
- **Endpoint**：`POST /nano-banana/images`
- **Metoda uwierzytelniania**：w HTTP Header należy przekazać `authorization: Bearer {token}`
- **Nagłówki żądania**：
  - `accept: application/json`
  - `content-type: application/json`
- **Akcja (action)**：
  - `generate`：generuje obraz na podstawie tekstowego promptu
  - `edit`：edytuje na podstawie podanego obrazu
- **Model (model)**（opcjonalnie）：
  - `nano-banana`（domyślnie）：oparty na Gemini 2.5 Flash Image, szybki i tani
  - `nano-banana-2-lite`：oparty na Gemini 3.1 Flash Lite Image, obsługuje tylko 1K, szybkie generowanie
  - `nano-banana-2`：oparty na Gemini 3.1 Flash Image Preview, jakość klasy Pro + szybkość Flash
  - `nano-banana-pro`：oparty na Gemini 3 Pro Image Preview, najwyższa jakość
  - `nano-banana:official`、`nano-banana-2-lite:official`、`nano-banana-2:official`、`nano-banana-pro:official`：wersje odpowiednich modeli przez oficjalne kanały, zapewniające lepszą jakość obrazu i stabilność, z innym rozliczaniem
- **Asynchroniczny callback**：opcjonalny, otrzymuj powiadomienia o ukończeniu zadania i wyniki poprzez `callback_url`
- **Liczba obrazów**：opcjonalna, określ 1–4 obrazów przez `count`, domyślnie 1 obraz; każdy obraz jest realizowany przez niezależne wywołanie generowania; zwykłe błędy techniczne lub odmowa bezpieczeństwa dostawcy wpływają tylko na odpowiednie wywołanie, pozostałe pomyślnie wygenerowane obrazy są zwracane normalnie, a opłata jest naliczana według faktycznej liczby pomyślnie wygenerowanych obrazów

## Szybki start: generowanie obrazów (`action=generate`)

**Minimalne wymagane parametry**：`action`、`prompt`
Gdy chcesz bezpośrednio wygenerować obraz wyłącznie na podstawie promptu, ustaw `action` na `generate` i podaj jasny `prompt`.

### Przykład żądania (cURL)

```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": "A photorealistic close-up portrait of an elderly Japanese ceramicist with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched workshop. The scene is illuminated by soft, golden hour light streaming through a window, highlighting the fine texture of the clay. Captured with an 85mm portrait lens, resulting in a soft, blurred background (bokeh). The overall mood is serene and masterful. Vertical portrait orientation.",
    "count": 1
  }'
```

### Przykład żądania (Python)

```python
import requests

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",
}
payload = {
    "action": "generate",
    "model": "nano-banana-pro",
    "prompt": (
        "A photorealistic close-up portrait of an elderly Japanese ceramicist "
        "with deep, sun-etched wrinkles and a warm, knowing smile. He is carefully "
        "inspecting a freshly glazed tea bowl. The setting is his rustic, sun-drenched "
        "workshop. The scene is illuminated by soft, golden hour light streaming through "
        "a window, highlighting the fine texture of the clay. Captured with an 85mm "
        "portrait lens, resulting in a soft, blurred background (bokeh). The overall mood "
        "is serene and masterful. Vertical portrait orientation."
    ),
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

### Opis pól

- `success`：czy bieżące żądanie zakończyło się pomyślnie.
- `task_id`：ID zadania.
- `trace_id`：ID śledzenia żądania, ułatwiające diagnozowanie problemów.
- `count`：liczba obrazów żądanych do wygenerowania lub edycji, obsługuje 1–4, domyślnie 1. `data` zawiera tylko pomyślnie wygenerowane obrazy, a opłata jest naliczana według faktycznej liczby zwróconych obrazów. Każde wywołanie generowania obowiązkowo korzysta z natywnej polityki bezpieczeństwa dostawcy; odrzucenie jednego wywołania nie wpływa na inne pomyślne wywołania, a jeśli wszystkie wywołania zostaną odrzucone, zwracany jest kod 403.
- `data[]`：lista wyników.
  - `prompt`：prompt użyty do generowania (zwracany ponownie).
  - `image_url`：bezpośredni URL wygenerowanego obrazu.

> Uwaga: `/nano-banana/images` wymaga jedynie `action` i `prompt`, aby wygenerować obraz

## Edycja obrazów (`action=edit`)

Gdy chcesz edytować na podstawie istniejących obrazów, ustaw `action` na `edit` i przekaż przez `image_urls` listę linków do obrazów do edycji (jeden lub wiele obrazów), jednocześnie podając `prompt` opisujący cel edycji.

Na przykład tutaj podajemy jedno zdjęcie osoby i jedno zdjęcie ubrania, aby osoba założyła to ubranie, można jednocześnie przekazać linki do obrazów i określić action jako `edit`; URL może być HTTP URL, publicznie dostępnym linkiem rozpoczynającym się od protokołu `https` lub `http`, albo obrazem zakodowanym w Base64, takim jak `data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAA+gAAAVGCAMAAAA6u2FyAAADAFBMVEXq6uwdHCEeHyMdHS....`

### Przykład żądania (cURL)
```bash
curl -X POST 'https://api.acedata.cloud/nano-banana/images' \
  -H 'authorization: Bearer {token}' \
  -H 'accept: application/json' \
  -H 'content-type: application/json' \
  -d '{
    "action": "edit",
    "prompt": "let this man wear on this T-shirt",
    "image_urls": [
      "https://cdn.acedata.cloud/v8073y.png",
      "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
  }'
```

### Przykład żądania (Python)

```python

url = "https://api.acedata.cloud/nano-banana/images"
headers = {
    "authorization": "Bearer {token}",
    "accept": "application/json",
    "content-type": "application/json",

        "https://cdn.acedata.cloud/v8073y.png",
        "https://cdn.acedata.cloud/44xlah.png"
    ],
    "count": 1
}
resp = requests.post(url, json=payload, headers=headers)
print(resp.json())
```

## Asynchroniczne wywołanie zwrotne (opcjonalne, zalecane)

Generowanie lub edycja mogą wymagać pewnego czasu. Aby uniknąć zajmowania zasobów przez długie połączenia, zaleca się użycie **wywołania zwrotnego Webhook** poprzez `callback_url`:

1. Dodaj `callback_url` do treści żądania, na przykład adres Webhook Twojego serwera (musi być publicznie dostępny i obsługiwać JSON POST).
2. API **natychmiast zwróci** odpowiedź zawierającą `task_id` (lub podstawowy wynik).
3. Po ukończeniu zadania platforma wyśle pełny JSON do `callback_url` metodą `POST`. Możesz powiązać żądanie z wynikiem za pomocą `task_id`.

**Przykład ładunku wywołania zwrotnego** (struktura pól jest taka sama jak w synchronicznej pomyślnej odpowiedzi):

```json
{
  "success": true,
  "task_id": "6a97bf49-df50-4129-9e46-119aa9fca73c",
  "trace_id": "9b4b1ff3-90f2-470f-b082-1061ec2948cc",
  "data": [
    {
      "prompt": "a white siamese cat",
      "image_url": "https://platform.cdn.acedata.cloud/nanobanana/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.png"
    }
  ]
}
```

## Obsługa błędów

W przypadku niepowodzenia wywołania zostanie zwrócony standardowy format błędu oraz identyfikator śledzenia. Typowe błędy są następujące:

- **400 `token_mismatched`**: żądanie jest nieprawidłowe lub wystąpił błąd parametrów.
- **400 `api_not_implemented`**: interfejs nie został zaimplementowany (skontaktuj się z pomocą techniczną).
- **401 `invalid_token`**: uwierzytelnianie nie powiodło się lub brakuje Tokena.
- **403 `forbidden`**: natywna polityka bezpieczeństwa dostawcy odrzuciła żądanie lub wynik generowania. To wywołanie nie zwróci obrazu i nie zostanie naliczona opłata; żądania wielu obrazów mogą nadal zwrócić i naliczyć opłatę za inne pomyślne wywołania.
- **429 `too_many_requests`**: przekroczono limit częstotliwości żądań.
- **500 `api_error`**: błąd po stronie serwera.

### Przykład odpowiedzi błędu

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "Internal server error."
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Porównanie parametrów i uwagi

- **Wymagane**: `action`, `prompt`
- **Tylko do edycji**: `image_urls` (tablica, co najmniej 1 element)
- **Opcjonalne**: `model` (domyślnie `nano-banana`, opcjonalnie `nano-banana-2-lite`, `nano-banana-2`, `nano-banana-pro` lub odpowiadające im wersje oficjalnego kanału `:official`), `aspect_ratio` (proporcje obrazu, np. `1:1`, `16:9`), `resolution` (rozdzielczość, np. `1K`, `2K`, `4K`; `nano-banana-2-lite` obsługuje tylko `1K`), `callback_url` (do asynchronicznego wywołania zwrotnego)
- **Nagłówki**: należy podać `authorization: Bearer {token}`; zaleca się ustawienie `accept` na `application/json`
- **Dostępność obrazów**: `image_urls` muszą być bezpośrednimi linkami dostępnymi publicznie (HTTP/HTTPS); zaleca się używanie HTTPS
- **Idempotencja i śledzenie**: zachowaj `task_id` oraz `trace_id`, aby ułatwić rozwiązywanie problemów i powiązanie wyników
