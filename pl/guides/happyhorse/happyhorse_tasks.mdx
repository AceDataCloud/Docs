API HappyHorse Tasks służy do zapytania o zadania związane z generowaniem lub edytowaniem wideo utworzonymi przez API HappyHorse Videos.

## Proces aplikacji

Aby korzystać z API HappyHorse Videos, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do wywołania wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Przy pierwszym wniosku otrzymasz darmowy limit, aby móc skorzystać z doświadczenia; gdy limit się wyczerpie, możesz doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [HappyHorse Videos API →](https://platform.acedata.cloud/documents/happyhorse-videos)

## Przykład zapytania

API HappyHorse Tasks może być używane do zapytania o wyniki API HappyHorse Videos.

### Ustawienie nagłówków i ciała zapytania

**Nagłówki zapytania** obejmują:

- `accept`: określa, że oczekujesz odpowiedzi w formacie JSON, tutaj wpisz `application/json`.
- `authorization`: klucz do wywołania API, po złożeniu wniosku możesz go bezpośrednio wybrać z rozwijanej listy.

**Ciało zapytania** obejmuje:

- `id`: ID zadania, które chcesz zapytać.
- `action`: sposób operacji na zadaniu, dla pojedynczego zapytania wpisz `retrieve`.

### Przykład kodu CURL

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Przykład odpowiedzi

Po pomyślnym zapytaniu API zwróci szczegóły tego zadania. Pole `request` to ciało zapytania podczas tworzenia zadania, a pole `response` to ciało odpowiedzi po zakończeniu zadania, na przykład:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262774.423,
  "elapsed": 52.6,
  "request": {
    "action": "generate",
    "model": "happyhorse-1.1-t2v",
    "prompt": "A cinematic shot of a white horse running across a moonlit beach",
    "resolution": "720P",
    "duration": 5
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "1469cfc3-3004-4d9e-ab10-xxxxxx",
        "video_url": "https://cdn.acedata.cloud/happyhorse/c8cbf53aa0.mp4",
        "state": "succeeded",
        "duration": 5,
        "resolution": "720P",
        "ratio": "16:9"
      }
    ]
  }
}
```

Opis pól jest następujący:

- `id`: ID zadania generacyjnego, używane do unikalnej identyfikacji tego zadania.
- `request`: informacje o zapytaniu podczas tworzenia zadania.
- `response`: aktualne lub ostateczne informacje zwrotne dotyczące zadania.
- `created_at`: czas utworzenia zadania, znacznik czasu Unix (sekundy, liczba zmiennoprzecinkowa).
- `started_at`: czas rozpoczęcia wykonania zadania, znacznik czasu Unix (sekundy, liczba zmiennoprzecinkowa).
- `finished_at`: czas zakończenia zadania, znacznik czasu Unix (sekundy, liczba zmiennoprzecinkowa). To pole nie jest zwracane, gdy zadanie nie jest zakończone.
- `elapsed`: czas wykonania zadania, jednostka to sekundy (liczba zmiennoprzecinkowa, z dokładnością do 3 miejsc po przecinku). To pole nie jest zwracane, gdy zadanie nie jest zakończone.

## Operacje zbiorcze

Aby zapytać o szczegóły wielu ID zadań, ustaw `action` na `retrieve_batch` i przekaż tablicę ID zadań przez `ids`:

```bash
curl -X POST 'https://api.acedata.cloud/happyhorse/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```

W zwróconym wyniku znajdą się pola `items` i `count`, gdzie `items` to tablica szczegółów zadań, a `count` to liczba zadań, które zostały dopasowane w tym zapytaniu.
