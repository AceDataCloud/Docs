Niniejszy dokument opisuje instrukcję integracji Gemini Videos Generation API, które umożliwia generowanie wideo Google Gemini (omni-flash) na podstawie wprowadzonego tekstowego promptu (oraz opcjonalnie referencyjnych obrazów).

## Proces aplikacji

Aby korzystać z API, należy najpierw złożyć wniosek o odpowiednią usługę na stronie [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos). Po wejściu na stronę kliknij przycisk „Acquire”, jak pokazano na obrazku:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jeśli nie jesteś zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania, gdzie możesz się zarejestrować i zalogować. Po zalogowaniu zostaniesz automatycznie przekierowany z powrotem na tę stronę.

Przy pierwszym wniosku otrzymasz darmowy limit, który pozwala na bezpłatne korzystanie z API.

## Podstawowe użycie

Najpierw zapoznaj się z podstawowym sposobem użycia: wprowadź prompt, model oraz proporcje obrazu (aspect_ratio), aby wygenerować odpowiednie wideo.

Widzimy tutaj ustawione nagłówki żądania (Request Headers), w tym:

- `accept`: format odpowiedzi, tutaj ustawiony na `application/json` (format JSON).
- `authorization`: klucz API do wywołania, który można wybrać z listy po złożeniu wniosku.

Dodatkowo ustawione jest ciało żądania (Request Body), które zawiera:

- `prompt`: tekstowy opis treści wideo do wygenerowania, **wymagany**.
- `model`: model generujący wideo, obecnie obsługiwany jest tylko `omni-flash`, domyślnie `omni-flash`.
- `aspect_ratio`: proporcje obrazu wideo, opcjonalnie `16:9` (poziome) lub `9:16` (pionowe), domyślnie `16:9`.
- `image_urls`: opcjonalna tablica linków do referencyjnych obrazów (lub wideo), które służą do nakierowania generowania wideo, puste elementy są ignorowane.
- `callback_url`: adres URL do asynchronicznego callbacku, po ustawieniu API zwróci natychmiast `task_id`, a po zakończeniu zadania wyśle wynik metodą POST na ten adres.

Kliknij przycisk „Try”, aby przetestować, a wynik będzie podobny do poniższego:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Zwrócone dane zawierają następujące pola:

- `success`: czy żądanie generowania wideo zakończyło się sukcesem.
- `task_id`: ID zadania generowania wideo.
- `trace_id`: ID śledzenia żądania, pomocne przy diagnozowaniu problemów.
- `data`: lista wyników wygenerowanych wideo.
  - `id`: unikalny identyfikator wygenerowanego wideo.
  - `video_url`: adres URL wygenerowanego wideo.
  - `state`: status zadania generowania wideo, może przyjmować wartości `pending` / `succeeded` / `failed`.

Wystarczy pobrać wygenerowane wideo korzystając z adresu `video_url` w polu `data`.

Przykładowy kod CURL:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Przykładowy kod w Python:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generowanie wideo na podstawie obrazów

Jeśli chcesz wygenerować wideo na podstawie referencyjnych obrazów, przekaż jeden lub więcej linków do obrazów w polu `image_urls`, które posłużą do nakierowania generowania:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Asynchroniczny callback

Generowanie wideo wymaga pewnego czasu przetwarzania. Jeśli nie chcesz utrzymywać długiego połączenia, możesz przekazać `callback_url`. Wtedy API zwróci natychmiast `task_id`, a po zakończeniu zadania wyśle wynik metodą POST na podany adres:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Natychmiast zwrócony wynik będzie wyglądał tak:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Sprawdzanie statusu zadania

Jeśli korzystasz z asynchronicznego callbacku lub chcesz aktywnie sprawdzić status zadania, możesz użyć [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`), podając `task_id`, aby uzyskać aktualny status i wynik zadania.

## Obsługa błędów

W przypadku problemów z żądaniem API zwraca odpowiedni kod błędu i opis. Najczęstsze to:

- `400`: błędne parametry żądania, np. brak `prompt` lub nieprawidłowa wartość `aspect_ratio`.
- `401`: błąd uwierzytelnienia, token jest nieważny lub niezgodny z API.
- `403`: niewystarczające środki na koncie lub prompt został odrzucony przez moderację treści.
- `500`: błąd wewnętrzny serwera lub niepowodzenie generowania w upstream.
