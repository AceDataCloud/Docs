W tym dokumencie przedstawiono instrukcje dotyczące integracji Gemini Videos Generation API, które może generować filmy Google Gemini (omni-flash) na podstawie wprowadzonych tekstowych podpowiedzi (oraz opcjonalnych zdjęć referencyjnych).

## Proces aplikacji

Aby korzystać z Gemini Videos Generation API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do korzystania ze wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Przy pierwszym wniosku przyznawana jest darmowa kwota, aby można było skorzystać z bezpłatnej wersji; w przypadku niewystarczającej kwoty można doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Podstawowe użycie

Najpierw zapoznaj się z podstawowym sposobem użycia, wprowadzając podpowiedź `prompt`, model `model` oraz proporcje `aspect_ratio`, aby wygenerować odpowiedni film.

Można zauważyć, że ustawiliśmy nagłówki żądania, w tym:

- `accept`: w jakim formacie chcesz otrzymać odpowiedź, tutaj wpisz `application/json`, czyli format JSON.
- `authorization`: klucz do wywołania API, po złożeniu wniosku można go bezpośrednio wybrać z rozwijanej listy.

Dodatkowo ustawiono ciało żądania, w tym:

- `prompt`: tekstowa podpowiedź opisująca treść filmu, **wymagana**.
- `model`: model generujący film, obecnie wspierany jest tylko `omni-flash`, domyślnie to `omni-flash`.
- `aspect_ratio`: proporcje generowanego filmu, opcjonalnie `16:9` (poziomo) lub `9:16` (pionowo), domyślnie `16:9`.
- `resolution`: opcjonalna rozdzielczość wyjściowa, opcjonalnie `720p` lub `1080p`, domyślnie `720p`.
- `image_urls`: opcjonalna tablica linków do zdjęć referencyjnych, używana do kierowania generowaniem filmu, puste elementy będą ignorowane. Gdy używasz `video_urls` do edycji filmu, ten parametr jest wymagany (przynajmniej jedno zdjęcie).
- `video_urls`: opcjonalna tablica linków do referencyjnych filmów (maksymalnie 1), używana do **edycji filmu / referencji filmu**; jeśli jest podana, musisz również dostarczyć przynajmniej jedno `image_urls`.
- `callback_url`: adres asynchronicznego wywołania zwrotnego, po ustawieniu API natychmiast zwróci `task_id`, a po zakończeniu zadania wyśle wyniki na ten adres.
- `async`: opcjonalne, ustawione na `true`, interfejs natychmiast zwraca `task_id`, nie ma potrzeby podawania `callback_url`, a następnie można uzyskać wyniki, korzystając z odpowiedniego interfejsu zapytań o zadania.

Kliknij przycisk „Try”, aby przeprowadzić test, a uzyskany wynik będzie podobny do poniższego:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
      "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
      "state": "succeeded"
    }
  ]
}
```

Zwrócony wynik zawiera wiele pól, które są opisane poniżej:

- `success`: czy żądanie generowania filmu zakończyło się sukcesem.
- `task_id`: ID zadania generowania filmu.
- `trace_id`: ID śledzenia tego żądania, używane do rozwiązywania problemów.
- `data`: lista wyników wygenerowanego filmu.
  - `id`: unikalny identyfikator wygenerowanego filmu.
  - `video_url`: adres URL wygenerowanego filmu.
  - `state`: stan zadania generowania filmu, opcjonalnie `pending` / `succeeded` / `failed`.

Musimy tylko uzyskać wygenerowany film na podstawie adresu URL `video_url` w `data`.

Odpowiedni kod CURL wygląda następująco:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Odpowiedni kod Python wygląda następująco:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generowanie wideo na podstawie obrazów

Jeśli chcesz wygenerować film na podstawie zdjęć referencyjnych, możesz wprowadzić jeden lub więcej linków do zdjęć w `image_urls`, aby kierować generowaniem filmu:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ]
}
```

## Edycja wideo / referencyjne wideo

Obsługuje bezpośrednią edycję istniejącego filmu lub referencje: wprowadź link do referencyjnego filmu w `video_urls` (maksymalnie 1) i **jednocześnie** dostarcz przynajmniej jedno zdjęcie referencyjne w `image_urls` (wymóg upstream). Możesz opisać pożądany efekt edycji w `prompt` (zmiana stylu, zmiana scenerii, dodawanie lub usuwanie elementów itp.):

```json
{
  "prompt": "Restyle the video into cinematic anime, keep the motion",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/example-reference.png"
  ],
  "video_urls": [
    "https://cdn.acedata.cloud/example-source.mp4"
  ]
}
```

> Uwaga: maksymalnie 1 referencyjne wideo; a przy podawaniu `video_urls` musisz dostarczyć przynajmniej jedno `image_urls` (w przeciwnym razie zwróci błąd parametru).

## Asynchroniczne wywołanie zwrotne

Generowanie filmu wymaga pewnego czasu przetwarzania. Jeśli nie chcesz utrzymywać długiego połączenia w oczekiwaniu, możesz podać `callback_url`, w takim przypadku API natychmiast zwróci `task_id`, a po zakończeniu zadania wyśle ostateczny wynik na ten adres:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Natychmiast zwrócony wynik wygląda następująco:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Sprawdzanie wyników zadań

Jeśli użyto asynchronicznego wywołania zwrotnego lub chcesz aktywnie sprawdzić status zadania, możesz skorzystać z [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) w celu sprawdzenia najnowszego statusu i wyników zadania na podstawie `task_id`.

## Obsługa błędów

Gdy wystąpi problem z żądaniem, API zwróci odpowiedni kod błędu i opis, najczęściej występujące to:
- `400`：Parametry żądania są nieprawidłowe, na przykład brakuje `prompt` lub wartość `aspect_ratio` jest nieprawidłowa.
- `401`：Błąd autoryzacji, token jest nieprawidłowy lub niezgodny z API.
- `403`：Niewystarczający bilans lub fraza została odrzucona w wyniku przeglądu treści.
- `500`：Błąd wewnętrzny serwera lub niepowodzenie generowania w upstream.
