Ten dokument przedstawia instrukcje integracji Gemini Videos Generation API, które może generować filmy Google Gemini (omni-flash) na podstawie wprowadzonych tekstowych podpowiedzi (oraz opcjonalnych zdjęć referencyjnych).

## Proces aplikacji

Aby korzystać z Gemini Videos Generation API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do korzystania ze wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Przy pierwszym wniosku przyznawana jest darmowa kwota, aby można było skorzystać z doświadczenia; w przypadku niewystarczającej kwoty można doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Podstawowe użycie

Najpierw zapoznaj się z podstawowym sposobem użycia, wprowadzając podpowiedź `prompt`, model `model` oraz proporcje `aspect_ratio`, aby wygenerować odpowiedni film.

Można zauważyć, że ustawiliśmy nagłówki żądania, w tym:

- `accept`: w jakim formacie chcesz otrzymać odpowiedź, tutaj wpisz `application/json`, czyli format JSON.
- `authorization`: klucz do wywołania API, po złożeniu wniosku można go bezpośrednio wybrać z rozwijanej listy.

Dodatkowo ustawiono ciało żądania, w tym:

- `prompt`: tekstowa podpowiedź opisująca treść filmu, **wymagana**.
- `model`: model generujący film, obecnie wspierany jest tylko `omni-flash`, domyślnie to `omni-flash`.
- `aspect_ratio`: proporcje filmu, opcjonalnie `16:9` (poziomo) lub `9:16` (pionowo), domyślnie `16:9`.
- `resolution`: opcjonalna rozdzielczość wyjściowa, opcjonalnie `720p` lub `1080p`, domyślnie `720p`.
- `image_urls`: opcjonalna tablica linków do zdjęć referencyjnych, używana do kierowania generowaniem filmu, puste elementy będą ignorowane. Gdy używasz `video_urls` do edycji filmu, ten parametr jest wymagany (przynajmniej jedno zdjęcie).
- `video_urls`: opcjonalna tablica linków do referencyjnych filmów (maksymalnie 1), używana do **edycji filmu / referencji filmu**; jeśli jest podana, musisz jednocześnie podać przynajmniej jedno `image_urls`.
- `callback_url`: adres asynchronicznego wywołania zwrotnego, po ustawieniu API natychmiast zwróci `task_id`, a po zakończeniu zadania wynik zostanie przesłany na ten adres.
- `async`: opcjonalne, ustawione na `true`, interfejs natychmiast zwraca `task_id`, nie ma potrzeby podawania `callback_url`, a następnie można uzyskać wyniki, korzystając z odpowiedniego interfejsu zapytań o zadania.

Kliknij przycisk „Try”, aby przeprowadzić test, a uzyskany wynik będzie podobny do poniższego:

```json
{
  "success": true,
  "task_id": "9258c45f-bed9-4dde-81c2-a70a710a6904",
  "trace_id": "862d6aae-cec0-407f-9524-bc1be2291bcb",
  "data": [
    {
      "id": "dc4b7292-070c-49a8-8183-919bdf8ad59e",
      "video_url": "https://platform2.cdn.acedata.cloud/gemini/9258c45f-bed9-4dde-81c2-a70a710a6904.mp4",
      "state": "succeeded",
      "aspect_ratio": "16:9",
      "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden"
    }
  ],
  "started_at": "2026-07-15T10:55:53.856Z",
  "finished_at": "2026-07-15T10:57:01.328Z",
  "elapsed": 67.472,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Zwracany wynik zawiera wiele pól, które są opisane poniżej:

- `success`: czy żądanie generowania filmu zakończyło się sukcesem.
- `task_id`: ID zadania generowania filmu.
- `trace_id`: ID śledzenia tego żądania, używane do rozwiązywania problemów.
- `data`: lista wyników wygenerowanych filmów.
  - `id`: unikalny identyfikator wygenerowanego filmu.
  - `video_url`: link do wygenerowanego filmu (gdy `state` to `pending`, jest `null`).
  - `state`: stan zadania generowania filmu, opcjonalnie `pending` / `succeeded` / `failed`.
  - `aspect_ratio`: proporcje tego filmu, zgodne z parametrem żądania.
  - `prompt`: podpowiedź użyta do wygenerowania tego filmu.

Podczas synchronizacji zwracane są również dodatkowe pola: `started_at`, `finished_at`, `elapsed` (czas trwania, w sekundach) oraz `cost` (koszt, jednostka Credit).

Wystarczy, że uzyskasz wygenerowany film, korzystając z linku `video_url` w `data`.

Odpowiedni kod CURL wygląda następująco:

```shell
curl -X POST 'https://api.acedata.cloud/gemini/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "omni-flash",
  "aspect_ratio": "16:9"
}'
```

Odpowiedni kod Python wygląda następująco:

```python
import requests

url = "https://api.acedata.cloud/gemini/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generowanie wideo na podstawie obrazów

Jeśli chcesz wygenerować film na podstawie zdjęć referencyjnych, możesz wprowadzić jeden lub więcej linków do zdjęć w `image_urls`, aby kierować generowaniem filmu:

```json
{
  "prompt": "The woman slowly turns around and smiles at the camera, gentle breeze",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "image_urls": [
    "https://platform2.cdn.acedata.cloud/nanobanana/e44bfceb-1458-4b4b-9d10-21024678f1a3.png"
  ]
}
```

## Edycja wideo / referencyjne wideo (wprowadź wideo, wygeneruj wideo)

Obsługuje bezpośrednie „wprowadzenie fragmentu wideo, aby wygenerować nowy film”: wprowadź link do referencyjnego wideo w `video_urls` (maksymalnie 1) i **jednocześnie** w `image_urls` podaj przynajmniej jedno zdjęcie referencyjne (wymóg upstream), a następnie użyj `prompt`, aby opisać pożądany efekt edycji (zmiana stylu, zmiana scenerii, dodawanie lub usuwanie elementów itp.).

Poniżej znajduje się pełny, rzeczywisty przykład — zmiana wideo z plaży w słoneczny dzień na zimowy krajobraz z padającym śniegiem, jednocześnie zachowując układ plaży, palm i łódki. Edycja wideo zajmuje więcej czasu (w tym przykładzie około 6,5 minuty), dlatego użyto `async: true` do asynchronicznego przesyłania:
```json
{
  "prompt": "Przekształć tę słoneczną tropikalną plażę w zaśnieżoną zimową scenerię z intensywnie padającym śniegiem i pochmurnym niebem; zachowaj tę samą plażę, palmy i układ łodzi.",
  "model": "omni-flash",
  "aspect_ratio": "9:16",
  "resolution": "720p",
  "image_urls": [
    "https://cdn.acedata.cloud/99289603bd.png"
  ],
  "video_urls": [
    "https://platform2.cdn.acedata.cloud/seedance/dd3dc063-3383-4f29-bedc-e771a096758c.mp4"
  ],
  "async": true
}
```

Po przesłaniu interfejs natychmiast zwraca `task_id`:

```json
{
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284"
}
```

Następnie użyj tego `task_id` jako `id` do sprawdzenia [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), po zakończeniu zadania możesz uzyskać nowo wygenerowane wideo (to jest rzeczywisty wynik tego przykładu):

```json
{
  "success": true,
  "task_id": "cd68b4ee-de70-4c94-ac69-997a3fed0284",
  "trace_id": "5b22104b-5a6d-4a4f-8063-69acae1dc1c6",
  "data": [
    {
      "id": "e125d316-3d26-4c65-9413-55baf6be46b8",
      "video_url": "https://platform2.cdn.acedata.cloud/sora/cd68b4ee-de70-4c94-ac69-997a3fed0284.mp4",
      "state": "succeeded",
      "aspect_ratio": "9:16",
      "prompt": "Przekształć tę słoneczną tropikalną plażę w zaśnieżoną zimową scenerię z intensywnie padającym śniegiem i pochmurnym niebem; zachowaj tę samą plażę, palmy i układ łodzi."
    }
  ],
  "started_at": "2026-07-15T03:01:22.914Z",
  "finished_at": "2026-07-15T03:07:57.090Z",
  "elapsed": 394.176,
  "cost": {
    "amount": 1.932,
    "currency": "credit",
    "list_amount": 2.1
  }
}
```

Aby uzyskać wyższej jakości wyniki, możesz ustawić `resolution` na `1080p` (pozostałe parametry pozostają bez zmian).

> Wskazówka: Linki do mediów w przykładzie są rzeczywistymi wynikami generacji. **Linki do wideo i zdjęć generowanych przez platformę mają okres przechowywania, po upływie którego wygasają**, proszę pobrać je i zapisać w swoim magazynie po uzyskaniu wyników.

> Uwaga: maksymalnie 1 referencyjne wideo; a przy podawaniu `video_urls` należy dostarczyć przynajmniej jeden `image_urls`, w przeciwnym razie zwróci błąd parametrów:

```json
{
  "success": false,
  "error": {
    "code": "bad_request",
    "message": "image_urls (przynajmniej jeden obraz referencyjny) jest wymagany, gdy podano video_urls."
  }
}
```

## Asynchroniczny callback

Generowanie wideo wymaga pewnego czasu przetwarzania. Jeśli nie chcesz utrzymywać długiego połączenia w oczekiwaniu, możesz przekazać `callback_url`, w takim przypadku API natychmiast zwróci `task_id`, a po zakończeniu zadania wyśle ostateczny wynik na ten adres:

```json
{
  "prompt": "Kinematograficzne ujęcie kociaka goniącego motyla w oświetlonym słońcem ogrodzie",
  "model": "omni-flash",
  "aspect_ratio": "16:9",
  "callback_url": "https://your-domain.com/callback/gemini"
}
```

Natychmiast zwrócone wyniki są następujące:

```json
{
  "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

## Sprawdzanie wyników zadania

Jeśli użyto asynchronicznego callbacku lub chcesz aktywnie sprawdzić status zadania, możesz to zrobić przez [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks) (`POST https://api.acedata.cloud/gemini/tasks`) na podstawie `task_id`:

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee"
}
```

Wynik po zakończeniu zadania będzie podobny do poniższego, struktura `response.data` jest zgodna z tą, która jest generowana synchronnie (gdy w trakcie generacji `state` to `pending`, a `video_url` to `null`):

```json
{
  "id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
  "type": "videos",
  "request": {
    "model": "omni-flash",
    "prompt": "Przyspieszone ujęcie chmur nad zaśnieżonymi górami o wschodzie słońca",
    "aspect_ratio": "16:9",
    "async": true
  },
  "response": {
    "success": true,
    "task_id": "04a043bd-6b23-4b4e-945c-ce48158c3eee",
    "data": [
      {
        "id": "486ebd5a-6a4b-406c-84ae-33835de4fe19",
        "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4",
        "state": "succeeded",
        "aspect_ratio": "16:9",
        "prompt": "Przyspieszone ujęcie chmur nad zaśnieżonymi górami o wschodzie słońca"
      }
    ],
    "elapsed": 96.716,
    "cost": {
      "amount": 1.932,
      "currency": "credit",
      "list_amount": 2.1
    }
  }
}
```

## Obsługa błędów

Gdy wystąpi problem z żądaniem, API zwróci odpowiedni kod błędu i opis, najczęstsze to:

- `400`: Błędne parametry żądania, na przykład brak `prompt` lub nieprawidłowa wartość `aspect_ratio`.
- `401`: Nieudana autoryzacja, token jest nieważny lub niezgodny z API.
- `403`: Niewystarczające saldo lub komunikat o treści naruszającej zasady.
- `500`: Błąd wewnętrzny serwera lub niepowodzenie generacji w górę.
