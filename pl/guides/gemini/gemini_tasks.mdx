Główną funkcją Gemini Tasks API jest możliwość sprawdzania statusu wykonania zadań za pomocą identyfikatora zadania (task ID) wygenerowanego przez Gemini Videos Generation API.

Dokument ten szczegółowo opisuje instrukcje integracji Gemini Tasks API, aby pomóc Ci łatwo zintegrować i sprawdzić status wykonania zadań Gemini Videos Generation API.

## Proces aplikacji

Aby korzystać z Gemini Videos Generation API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do wywołania wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Przy pierwszym wniosku otrzymasz darmowy limit, aby móc skorzystać z usługi; gdy limit się wyczerpie, możesz doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Gemini Videos Generation API →](https://platform.acedata.cloud/documents/gemini-videos)

## Przykład żądania

Gemini Tasks API może być używane do sprawdzania wyników Gemini Videos Generation API.

### Ustawienie nagłówków żądania i ciała żądania

**Nagłówki żądania** obejmują:

- `accept`: określa, że oczekiwany jest wynik odpowiedzi w formacie JSON, tutaj wpisz `application/json`.
- `authorization`: klucz do wywołania API, po złożeniu wniosku można go bezpośrednio wybrać z rozwijanej listy.

**Ciało żądania** obejmuje:

- `id`: identyfikator zadania do sprawdzenia.
- `action`: sposób operacji na zadaniu, dla pojedynczego zapytania wpisz `retrieve`.

### Przykład kodu CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Przykład odpowiedzi

Po pomyślnym wykonaniu żądania, API zwróci szczegółowe informacje o tym zadaniu. Pole `request` to ciało żądania, które zostało wysłane podczas inicjowania zadania, a pole `response` to ciało odpowiedzi zwrócone po zakończeniu zadania, na przykład:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "started_at": 1769262721.823,
  "finished_at": 1769262730.723,
  "elapsed": 8.9,
  "request": {
    "prompt": "Klatka filmowa kota goniącego motyla w słonecznym ogrodzie",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Opis pól jest następujący:

- `id`: identyfikator wygenerowanego zadania, używany do unikalnej identyfikacji tego zadania.
- `request`: informacje o żądaniu w zadaniu.
- `response`: informacje o odpowiedzi w zadaniu.
- `created_at`: czas utworzenia zadania, znacznik czasu Unix (sekundy, liczba zmiennoprzecinkowa).
- `started_at`: czas rozpoczęcia wykonania zadania, znacznik czasu Unix (sekundy, liczba zmiennoprzecinkowa).
- `finished_at`: czas zakończenia zadania, znacznik czasu Unix (sekundy, liczba zmiennoprzecinkowa). To pole nie jest zwracane, gdy zadanie nie jest zakończone.
- `elapsed`: czas wykonania zadania, wyrażony w sekundach (liczba zmiennoprzecinkowa, z dokładnością do 3 miejsc po przecinku). To pole nie jest zwracane, gdy zadanie nie jest zakończone.

## Operacje zbiorcze

Aby sprawdzić szczegóły wielu identyfikatorów zadań, ustaw `action` na `retrieve_batch` i przekaż tablicę identyfikatorów zadań przez `ids`:

**Ciało żądania** obejmuje:

- `ids`: tablica identyfikatorów zadań do sprawdzenia.
- `action`: sposób operacji na zadaniu, dla zapytań zbiorczych wpisz `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
