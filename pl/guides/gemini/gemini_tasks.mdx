Główną funkcją Gemini Tasks API jest możliwość zapytania o status wykonania zadania na podstawie ID zadania wygenerowanego przez Gemini Videos Generation API.

Niniejsza dokumentacja szczegółowo opisuje integrację Gemini Tasks API, pomagając łatwo zintegrować i sprawdzić status wykonania zadań Gemini Videos Generation API.

## Proces aplikacji

Aby korzystać z Gemini Tasks API, najpierw należy złożyć wniosek o odpowiednią usługę na stronie [Gemini Videos Generation API](https://platform.acedata.cloud/documents/gemini-videos) i skopiować zwrócone przez Gemini Videos Generation API ID zadania.

Następnie przejdź do strony [Gemini Tasks API](https://platform.acedata.cloud/documents/gemini-tasks), aby złożyć wniosek o odpowiednią usługę. Po wejściu na stronę kliknij przycisk „Acquire”.

Jeśli nie jesteś zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do [strony logowania](https://platform.acedata.cloud), gdzie możesz się zarejestrować i zalogować. Po zalogowaniu nastąpi automatyczny powrót do bieżącej strony.

Przy pierwszym wniosku dostępny jest darmowy limit, który pozwala na bezpłatne korzystanie z API.

## Przykład zapytania

Gemini Tasks API służy do sprawdzania wyników Gemini Videos Generation API.

### Ustawienie nagłówków i ciała zapytania

**Nagłówki zapytania** obejmują:

- `accept`: określa format odpowiedzi, tutaj ustawione na `application/json`.
- `authorization`: klucz API do wywołania, który można wybrać z listy po złożeniu wniosku.

**Ciało zapytania** obejmuje:

- `id`: ID zadania, którego status chcemy sprawdzić.
- `action`: sposób operacji na zadaniu, dla pojedynczego zapytania należy wpisać `retrieve`.

### Przykład kodu CURL

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "action": "retrieve"
}'
```

### Przykład odpowiedzi

Po pomyślnym zapytaniu API zwróci szczegóły zadania. Pole `request` zawiera ciało zapytania wysłanego przy tworzeniu zadania, a pole `response` zawiera odpowiedź po zakończeniu zadania, na przykład:

```json
{
  "id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "request": {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "omni-flash",
    "aspect_ratio": "16:9"
  },
  "type": "videos",
  "response": {
    "success": true,
    "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
    "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
    "data": [
      {
        "id": "omni-flash:job_01k777hjrbfrgs2060q5zvf2a5",
        "video_url": "https://cdn.acedata.cloud/gemini/example-video.mp4",
        "state": "succeeded"
      }
    ]
  }
}
```

Opis pól:

- `id`: ID zadania generowania, służy do jednoznacznej identyfikacji zadania.
- `request`: informacje o zapytaniu w zadaniu.
- `response`: informacje zwrotne z zadania.

## Operacje zapytań zbiorczych

Aby zapytać o szczegóły wielu zadań jednocześnie, ustaw `action` na `retrieve_batch` i przekaż tablicę ID zadań przez `ids`:

**Ciało zapytania** obejmuje:

- `ids`: tablica ID zadań do zapytania.
- `action`: sposób operacji na zadaniu, dla zapytania zbiorczego wpisz `retrieve_batch`.

```bash
curl -X POST 'https://api.acedata.cloud/gemini/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "ids": ["b8976e18-32dc-4718-9ed8-1ea090fcb6ea"],
  "action": "retrieve_batch"
}'
```
