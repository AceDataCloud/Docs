---
title: "Przewodnik po integracji API Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` wspiera `qwen-image-3.0` oraz `qwen-image-3.0-pro` do generowania obrazów z tekstu oraz edytowania 1–3 referencyjnych obrazów.

## Generowanie obrazów z tekstu

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen-image-3.0","prompt":"minimalistyczny plakat technologiczny","size":"1024*1024","n":1}'
```

## Edycja obrazów

W tym samym żądaniu dodaj `image_urls`, wspierające 1–3 publiczne obrazy:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "zachowaj główny temat, zmień na ciepły styl plakatu",
  "image_urls": ["https://cdn.acedata.cloud/r9vsv9.png"],
  "size": "2048*2048",
  "prompt_extend": true,
  "prompt_extend_mode": "direct",
  "enable_thinking": true,
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` wspiera tylko generowanie obrazów z tekstu. `n` w zakresie od 1 do 6. Całkowita liczba pikseli wyjściowych musi mieścić się w zakresie od 512×512 do 2048×2048, a proporcje szerokości do wysokości od 1:8 do 8:1.

## Wywołania asynchroniczne

Ustawienie `async: true` pozwala natychmiast uzyskać `task_id`; można również przekazać `callback_url`, aby otrzymać ostateczny wynik. Po zakończeniu można sprawdzić przez `/qwen-image/tasks`.

Udana odpowiedź zawiera `data[].image_url`, `usage`, `task_id` oraz `trace_id`. Linki do obrazów będą w miarę możliwości przechowywane w Ace Data Cloud CDN. Rzeczywisty przykład odpowiedzi zostanie uzupełniony po weryfikacji E2E w produkcji.
