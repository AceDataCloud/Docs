---
title: "Generowanie i edycja Qwen Image API"
description: "Qwen Image API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` realizuje generowanie obrazu z tekstu oraz edycję z 1–3 obrazami referencyjnymi za pomocą tego samego interfejsu, obsługuje `qwen-image-3.0` oraz `qwen-image-3.0-pro`.

## Wybór modelu

| Model                   | Odpowiednie scenariusze       | Oficjalna cena standardowa                   |
| -------------------- | ---------- | ----------------------- |
| `qwen-image-3.0`     | Tworzenie wsadowe, szybka iteracja  | Wyjście $0.030/obraz             |
| `qwen-image-3.0-pro` | Złożony układ, wysokoprecyzyjne obrazy końcowe | 1K $0.040/obraz；2K $0.075/obraz |

Obrazy referencyjne są rozliczane według rzeczywistej liczby danych wejściowych, oficjalna cena standardowa wynosi $0.003/obraz.

## Generowanie synchroniczne

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "A simple red circle centered on a clean white background.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Pomyślna odpowiedź zawiera stały adres obrazu CDN, rzeczywiste usage oraz koszt tej operacji:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22-bac6a9e9de22.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Edycja obrazów referencyjnych

Dodaj `image_urls`, obsługiwane są 1–3 publicznie dostępne obrazy:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "保留主体，将背景改成暖色电影海报风格",
  "image_urls": ["https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` jest używany wyłącznie do generowania obrazu z tekstu. Zakres `n` wynosi 1–6; proporcje szerokości do wysokości muszą mieścić się między 1:8 a 8:1.

## Zadania asynchroniczne

Po ustawieniu `async: true` interfejs natychmiast zwraca `task_id`. Użyj `/qwen-image/tasks`, aby sprawdzić stan końcowy, lub przekaż `callback_url`, aby otrzymać powiadomienie o ukończeniu. Generowanie jest rozliczane tylko raz, zapytania o zadanie nie są naliczane ponownie.
