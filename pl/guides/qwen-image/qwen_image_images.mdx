---
title: "API do generowania i edytowania obrazów Qwen"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/qwen-image/images` umożliwia generowanie obrazów na podstawie tekstu oraz edytowanie 1–3 referencyjnych obrazów za pomocą tego samego interfejsu, wspiera `qwen-image-3.0` oraz `qwen-image-3.0-pro`.

## Wybór modelu

| Model                  | Odpowiednie scenariusze | Oficjalna cena standardowa  |
| --------------------- | --------------------- | ----------------------- |
| `qwen-image-3.0`      | Tworzenie w partiach, szybka iteracja | Wyjście $0.030/obraz      |
| `qwen-image-3.0-pro`  | Złożone układy, wysoka precyzja | 1K $0.040/obraz; 2K $0.075/obraz |

Referencyjne obrazy są rozliczane według rzeczywistej liczby wejść, oficjalna cena standardowa $0.003/obraz.

## Generowanie synchronizowane

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/images' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen-image-3.0",
    "prompt": "Prosty czerwony okrąg na czystym białym tle.",
    "size": "1024*1024",
    "n": 1,
    "watermark": false
  }'
```

Odpowiedź sukcesu zawiera stały adres CDN obrazu, rzeczywiste użycie oraz koszty:

```json
{
  "success": true,
  "task_id": "565a7f55-72c6-43ed-b274-268ff046e5b4",
  "trace_id": "bb923cec-1550-43b4-8df2-288ac0977b4b",
  "data": [
    {"image_url": "https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"}
  ],
  "usage": {
    "input_image_count": 0,
    "output_image_count": 1,
    "output_image_type": "qima_output_1k",
    "output_width": 1024,
    "output_height": 1024
  },
  "cost": {"amount": 0.322, "currency": "credit", "list_amount": 0.35}
}
```

## Edytowanie obrazów referencyjnych

Dodaj `image_urls`, wspiera 1–3 publicznie dostępne obrazy:

```json
{
  "model": "qwen-image-3.0-pro",
  "prompt": "Zachowaj główny temat, zmień tło na ciepły **###** styl plakatu",
  "image_urls": ["https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"],
  "size": "2048*2048",
  "n": 1,
  "watermark": false
}
```

`prompt_extend_mode=agent` jest używane tylko do generowania obrazów na podstawie tekstu. Zakres `n` wynosi od 1 do 6; proporcje szerokości do wysokości muszą mieścić się w zakresie od 1:8 do 8:1.

## Zadania asynchroniczne

Po ustawieniu `async: true` interfejs natychmiast zwraca `task_id`. Użyj `/qwen-image/tasks`, aby sprawdzić stan końcowy, lub przekaż `callback_url`, aby otrzymać powiadomienie o zakończeniu. Generowanie jest rozliczane tylko raz, zapytania o zadania nie są powtarzane w rozliczeniach.
