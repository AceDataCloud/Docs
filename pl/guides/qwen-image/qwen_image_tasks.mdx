---
title: "Przewodnik po integracji API z zadaniami Qwen Image"
description: "Qwen Image 3 API guide - Ace Data Cloud"
---

Użyj `POST https://api.acedata.cloud/qwen-image/tasks`, aby zapytać o asynchroniczne zadania generowania obrazów. Ten interfejs zapytań jest bezpłatny.

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Aby przeprowadzić zbiorowe zapytanie, użyj `action=retrieve_batch` oraz tablicy `ids`. Po pomyślnym zakończeniu zadania, `response.data` zawiera trwały adres wygenerowanego obrazu oraz rzeczywiste użycie.
