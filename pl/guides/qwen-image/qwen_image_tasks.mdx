`POST https://api.acedata.cloud/qwen-image/tasks` służy do zapytania, zbiorczego zapytania lub usunięcia asynchronicznych zadań Qwen Image. Ten interfejs nie generuje dodatkowego zużycia API.

## Zapytanie pojedynczego zadania

```bash
curl -X POST 'https://api.acedata.cloud/qwen-image/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Po zakończeniu zadania, `response.data` zawiera stały adres CDN obrazu, `response.usage` zawiera rzeczywistą liczbę wejść/wyjść, a `response.cost` to informacje o rozliczeniu zadania.

## Zbiorcze zapytanie

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Zwraca `{ "items": [...], "count": 2 }`. Zapytania listowe wspierają również filtrowanie według użytkownika, aplikacji i zakresu czasu utworzenia.

## Usunięcie rekordów zadań

```json
{"action":"delete","id":"TASK_ID"}
```

Usunięcie wpływa tylko na historię zadań, nie usunie wygenerowanych plików CDN.
