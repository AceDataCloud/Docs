---
title: "Producent przesyłania referencyjnego audio API integracja"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producent pozwala nam na przesyłanie referencyjnego audio do dalszej obróbki, ten dokument wyjaśnia metody integracji odpowiednich API.

To API ma tylko jeden parametr wejściowy, którym jest `audio_url`, jest to publicznie dostępny adres CDN, wspierający rozszerzenie mp3.

Tutaj wprowadzamy `audio_url`, który jest `https://cdn.acedata.cloud/suno_demo.mp3`, jest to publicznie dostępny adres CDN.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Wynik jest następujący:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Delikatne żeńskie wokale, jasne i radosne]\n\n[Zwrotka 1]\nSłońce świeci na plaży\nFale śmieją się promiennie\nTy i ja na plaży\nZegar przestał tykać\nLody się topnieją\nTrzymając się za ręce idziemy na spacer\nWiatr delikatnie wieje\nSerce nie przestaje bić\n\n[Refren]\nLato, lato\nCzas zatrzymał się w tym dniu\nŚmiech rozbrzmiewa\nBłękitne niebo obok",
    "audio_url": "https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"
  }
}
```

Można zauważyć, że pole `audio_id` w `data` to ID piosenki po przesłaniu.

Mając ID piosenki, możemy użyć [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) do generowania spersonalizowanych piosenek, na przykład przekazując `action` jako `upload_extend`, a `audio_id` jako zwrócone ID piosenki, możemy wygenerować nową piosenkę na podstawie referencyjnego audio.
