---
title: "Instrukcja integracji API przesyłania referencyjnego audio Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer pozwala nam przesyłać referencyjne audio do wtórnej twórczości, ten dokument wyjaśnia metodę integracji powiązanego API.

To API ma tylko jeden parametr wejściowy, czyli `audio_url`, jest to publicznie dostępny adres CDN, obsługujący rozszerzenie mp3.

Wprowadzany tutaj `audio_url` to `https://cdn.acedata.cloud/suno_demo.mp3`, jest to publicznie dostępny adres CDN.

```bash
curl -X POST 'https://api.acedata.cloud/producer/upload' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3"
}'
```

Wynik jest następujący:

```
{
  "success": true,
  "task_id": "23e7d4ec-d1a8-429f-87d8-9f53fc3b6666",
  "data": {
    "audio_id": "d906da31-87cb-42f5-98df-2fc4969923b1",
    "lyric": "[Mandopop, Acoustic Pop]\n[Soft female vocals, bright and cheerful]\n\n[Verse 1]\n阳光洒在海边\n浪花笑得灿烂\n你和我在沙滩\n钟表停止转\n冰淇淋在融化\n手牵手去散步\n风儿轻轻吹过\n心跳不停跳\n\n[Chorus]\n夏天夏天\n时间停在这一天\n笑声回荡\n蔚蓝天空在身旁",
    "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3"
  }
}
```

Jak widać, pole `audio_id` w `data` jest identyfikatorem utworu po przesłaniu.

Po uzyskaniu identyfikatora utworu możemy użyć [Producer Audios Generation API](https://platform.acedata.cloud/documents/producer-audios-integration) do niestandardowego generowania utworów, na przykład przekazując `upload_extend` jako `action`, a jednocześnie przekazując zwrócony identyfikator utworu jako `audio_id`, można wygenerować nowy utwór na podstawie referencyjnego audio.
