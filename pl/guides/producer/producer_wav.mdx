---
title: "Instrukcja integracji API pobierania WAV Producer"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producer umożliwia nam pobieranie plików WAV związanych z utworami, ten dokument wyjaśnia metodę integracji odpowiedniego API.

To API ma tylko jeden parametr wejściowy, którym jest `audio_id`, jest to unikalny identyfikator utworu.

Wprowadzony tutaj `audio_id` to `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, jest to identyfikator utworu wygenerowanego przez Producer.

```bash
curl -X POST 'https://api.acedata.cloud/producer/wav' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Wynik jest następujący:

```
{
  "success": true,
  "task_id": "44963173-b6c5-463c-915f-96730d14ec63",
  "trace_id": "f75d6a27-54bc-49fd-a40e-6d4cd0427764",
  "data": [
    {
      "title": "Woke up with the sun in my eyes",
      "file_url": "https://cdn.acedata.cloud/assets/examples/fish/64adc04b-c196-4a0f-9070-222ba101ce6c-fc50de38c165.wav"
    }
  ]
}
```

Można zobaczyć, że pole `file_url` w `data` jest linkiem do pobrania WAV.
