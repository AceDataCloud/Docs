title: "Producent - instrukcja integracji API do pobierania wideo"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producent pozwala nam na pobieranie wideo związanych z utworami, ten dokument wyjaśnia metody integracji odpowiednich API.

To API ma tylko jeden parametr wejściowy, którym jest `audio_id`, jest to unikalny identyfikator utworu.

Tutaj wprowadzamy `audio_id`, które wynosi `a54609c6-13e2-4176-be0f-4d7eebc68e1f`, jest to identyfikator utworu wygenerowany przez Producenta.

```bash
curl -X POST 'https://api.acedata.cloud/producer/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_id": "a54609c6-13e2-4176-be0f-4d7eebc68e1f"
}'
```

Wynik jest następujący:

```
{
  "success": true,
  "task_id": "1237fc8f-ed3f-41fd-a889-a737fd7777da",
  "trace_id": "19db6190-d9ef-4a4f-a102-9f51b611c8b5",
  "data": {
    "video_url": "https://platform2.cdn.acedata.cloud/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee.mp4"
  }
}
```

Można zauważyć, że pole `video_url` w `data` to link do pobranego wideo.
