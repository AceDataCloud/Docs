---
title: "Producent - Interfejs API do generowania tekstów piosenek"
description: "Producer Music Generation API guide - Ace Data Cloud"
---

Producent pozwala nam generować teksty piosenek za pomocą słów kluczowych, ten dokument wyjaśnia metody integracji z odpowiednim API.

Ten API ma tylko jeden parametr wejściowy, którym jest `prompt`, jest to słowo kluczowe do generowania tekstu piosenki.

Tutaj wprowadzamy `prompt`, którym jest `Piosenka o zimie`, jest to słowo kluczowe do generowania tekstu piosenki.

```bash
curl -X POST 'https://api.acedata.cloud/producer/lyrics' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "Piosenka o zimie"
}'
```

Wynik jest następujący:

```
{
    "success": true,
    "task_id": "d354b519-43c0-4888-a3da-83adbf845fd6",
    "data": {
        "title": "Miłosierdzie w drzewach",
        "lyrics": "[Zwrotka 1]\nWyszedłem poza tory\nGdzie sosny rosną gęsto z szronem\nŚnieg nie obchodzi, co zrobiłem\nPrzykrywa wszystko tak samo\n\n[Zwrotka 2]\nJest kaplica z brzozowych pni\nA ołtarz to ziemia\nKlnę tam jak zdrajca\nCzekając, aż cisza wybaczy\n\n[Refren]\nZima to ciężki płaszcz\nZima to ciężki płaszcz\n\n[Zwrotka 3]\nOdeszłaś przed pierwszą burzą\nZostałem, by obserwować, jak świat bieleje\nTeraz każda gałąź to kość\nA ja tylko liczę, co pozostało\n\n[Zwrotka 4]\nMówią, że zimno cię zabije\nAle myślę, że po prostu czyni cię szczerym\nTutaj z zamarzniętą ziemią\nNie ma już gdzie ukryć rąk\n\n[Refren]\nZima to ciężki płaszcz\nZima to ciężki płaszcz\n\n[Zwrotka 5]\nZnalazłem twój list w kieszeni\nAtrament wyblakł od całego rozmrożenia\nAle wciąż mogłem przeczytać miłosierdzie\nNapisane w pustej przestrzeni między\n\n[Zakończenie]\nDrzewa nie proszą o odpuszczenie\nPo prostu stoją tam, nagie i prawdziwe\nUczę się, jak robić to samo\nPozwalając śniegowi zakopać to, co musi być zakopane"
    }
}
```

Można zauważyć, że pole `lyrics` w `data` to wygenerowana treść tekstu piosenki.
