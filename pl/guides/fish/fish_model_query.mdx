Ten interfejs oparty jest na [Fish Audio oficjalnym Model API](https://docs.fish.audio/resources/api-reference/model) i służy do **stronicowego przeszukiwania publicznej biblioteki dźwięków Fish lub klonów dźwięków w bieżącym koncie**. Adres to `GET https://api.acedata.cloud/fish/model`.

> Aby utworzyć dźwięk, zapoznaj się z [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); aby wyszukać szczegóły pojedynczego dźwięku według `_id`, zapoznaj się z [Fish Model Get API](https://platform.acedata.cloud/documents/fish-model-get).

## Proces aplikacji

Aby korzystać z Fish Model API, najpierw przejdź do [Ace Data Cloud konsoli](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do korzystania ze wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Pierwsze zgłoszenie otrzyma darmowy limit, aby móc skorzystać z doświadczenia; w przypadku niewystarczającego limitu można doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parametry zapytania

| Parametr          | Typ      | Domyślny | Opis                                      |
| ----------------- | -------- | -------- | ----------------------------------------- |
| `page_size`      | integer  | 10       | Liczba elementów na stronę.              |
| `page_number`    | integer  | 1        | Numer strony zaczynający się od 1.       |
| `title`          | string   | —        | Wyszukiwanie według tytułu.              |
| `tag`            | string   | —        | Filtrowanie według pojedynczego tagu.    |
| `self`           | boolean  | —        | Gdy `true`, zwraca tylko dźwięki utworzone przez bieżące konto, bez dodatkowych warunków. |
| `author_id`      | string   | —        | Filtrowanie według `_id` użytkownika.    |
| `language`       | string   | —        | Filtrowanie według języka dźwięku, np. `en`, `zh`, `es`. |
| `title_language` | string   | —        | Filtrowanie według języka tytułu.        |
| `sort_by`        | string   | —        | Pole sortowania, zgodne z upstream, np. `created_at`, `task_count`. |

> Nazewnictwo parametrów jest identyczne z upstream `GET https://api.fish.audio/model`, szczegóły w [oficjalnej dokumentacji Fish](https://docs.fish.audio/resources/api-reference/model).

## Przykład 1: Domyślne stronicowanie (według `page_size`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'page_size=2'
```

## Przykład 2: Wyszukiwanie według tytułu (fuzzy search) (`title`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'title=narration' \
  --data-urlencode 'page_size=2'
```

Zwrócone (testowane):

```json
{
  "total": 161,
  "items": [
    {
      "_id": "fb8fe4a94658429d9be70efd4eec35a2",
      "type": "tts",
      "title": "Miles Morales ( Narration Paw )",
      "tags": ["male", "middle-aged", "entertainment", "storytelling", "Children's Content"],
      "languages": ["en"],
      "visibility": "public",
      "task_count": 770
    },
    {
      "_id": "76b55591c758444cb95253708696dfad",
      "type": "tts",
      "title": "Joe NARRATION",
      "tags": ["male", "middle-aged", "narration", "deep", "raspy"],
      "languages": ["en"],

```

Zauważ, że `title` to „globalne dopasowanie fuzzy”, które trafi na wszystkie dźwięki w publicznej bibliotece Fish (nie tylko na własne).

## Przykład 3: Wyświetlanie tylko dźwięków utworzonych przez siebie (`self=true`)

```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'self=true' \
  --data-urlencode 'page_size=5'
```

Zwrócone (testowane, na bieżącym koncie znajduje się tylko 1 dźwięk):

```json
{
  "total": 1,
  "items": [
    {
      "_id": "e5c6db52c3ed417f9cb2e5a33fb04667",
      "type": "tts",
      "title": "copilot-smoke-test",
      "description": "smoke test from api.acedata.cloud",
      "state": "trained",
      "languages": ["zh"],
      "visibility": "public",
      "samples": [
        {
          "title": "Default Sample",
          "text": "师父，[语气坚定]我真的受够了这山上的清冷日子！...",
```

`self=true` jest równoważne z ograniczeniem w filtrze `author_id == bieżące konto upstream ID`, co jest powszechnym sposobem na uzyskanie „listy moich dźwięków”.

## Przykład 4: Filtrowanie według języka + tagu
```shell
curl -G 'https://api.acedata.cloud/fish/model' \
  -H 'authorization: Bearer {token}' \
  --data-urlencode 'language=zh' \
  --data-urlencode 'tag=narration' \
  --data-urlencode 'page_size=5'
```

> Górny strumień również zwróci wyniki dla `tag`, który nie znajduje się w słowniku tagów, ale dopasowanie jest stosunkowo luźne; jeśli liczba trafień wynosi 0, zaleca się użycie dopasowania przybliżonego dla `title`.

## Pola odpowiedzi

Każdy element w `items[]` to pełny obiekt ModelEntity, często używane pola:

| Pole            | Typ       | Opis                                                |
| ------------- | -------- | ------------------------------------------------- |
| `_id`         | string   | ID głosu, jako wartość `reference_id` w `/fish/tts`.         |
| `type`        | string   | Typ modelu, zazwyczaj `tts`.                                   |
| `title`       | string   | Nazwa głosu.                                             |
| `description` | string   | Opis głosu.                                             |
| `state`       | string   | Stan treningu: `trained` oznacza dostępny.                              |
| `tags`        | string[] | Tagi z publicznej biblioteki.                                            |
| `languages`   | string[] | Języki, w których głos jest biegły.                                          |
| `visibility`  | string   | `public` lub `private`.                             |
| `samples`     | object[] | Przykładowe próbki (zawierające bezpośrednie linki do `audio`).                               |
| `like_count`  | integer  | Liczba polubień w publicznej bibliotece.                                           |
| `task_count`  | integer  | Liczba historycznych syntez.                                           |
| `author`      | object   | Informacje o autorze: `'_id'` / `nickname` / `avatar`.             |
| `total`（górny poziom）   | integer  | Całkowita liczba spełniająca warunki.                                         |
| `has_more`    | boolean? | Wskazanie paginacji, może być `null`. Zaleca się obliczenie całkowitej liczby stron jako `total / page_size`. |

## Opis opłat

Ten interfejs nie jest płatny — zapytania o listę głosów są darmowe. Tworzenie głosów ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) również jest darmowe, opłaty powstają tylko podczas wywoływania [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) do syntezowania głosu.

## Obsługa błędów

- `400 token_mismatched`：Brak lub nieprawidłowe parametry żądania.
- `401 invalid_token`：Token autoryzacyjny nie istnieje lub jest nieprawidłowy.
- `429 too_many_requests`：Przekroczono limit szybkości konta.
- `500 api_error`：Błąd wewnętrzny serwera.

Przykład odpowiedzi błędu:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Wnioski

Aby wybrać głos z publicznej biblioteki Fish do podania do `/fish/tts` jako `reference_id`, najpierw użyj tego interfejsu w połączeniu z `title` / `tag` / `language`, aby zlokalizować docelowe `_id`, a następnie użyj [Fish Model Get](https://platform.acedata.cloud/documents/fish-model-get) do uzyskania próbek do odsłuchu. Aby wylistować własne stworzone głosy, wystarczy przekazać `self=true`.
