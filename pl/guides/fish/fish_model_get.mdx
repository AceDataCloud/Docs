Ten interfejs oparty jest na [oficjalnym API Model Fish Audio](https://docs.fish.audio/resources/api-reference/model) i służy do **wyszukiwania pełnych szczegółów pojedynczego klonu dźwięku według `_id`**. Adres to `GET https://api.acedata.cloud/fish/model/{id}`.

> Aby utworzyć dźwięk, zapoznaj się z [Fish Model Create API](https://platform.acedata.cloud/documents/fish-model); aby przeszukiwać strony, zapoznaj się z [Fish Model Query API](https://platform.acedata.cloud/documents/fish-model-query).

## Proces aplikacji

Aby korzystać z Fish Model API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do wywołania wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Pierwsze zgłoszenie otrzymuje darmowy limit, aby móc korzystać z usługi za darmo; w przypadku niewystarczającego limitu można doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Fish Model API →](https://platform.acedata.cloud/services/fish)

## Parametry ścieżki

| Parametr | Wymagane | Opis                                                                                                                                                                                                |
| ---- | --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id` | Tak   | `_id` dźwięku (32-znakowy ciąg szesnastkowy). Można go uzyskać podczas tworzenia przez [Fish Model Create](https://platform.acedata.cloud/documents/fish-model) lub wyszukiwania przez [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query). |

Brak ciała żądania, brak parametrów zapytania.

## Przykład: Pobranie pełnych szczegółów publicznego dźwięku w języku hiszpańskim

```shell
curl 'https://api.acedata.cloud/fish/model/8d2c17a9b26d4d83888ea67a1ee565b2' \
  -H 'authorization: Bearer {token}'
```

Uzyskane `_id` można bezpośrednio podać do `reference_id` w [Fish TTS](https://platform.acedata.cloud/documents/fish-tts), aby wygenerować głos o tym samym dźwięku:

```shell
curl -X POST 'https://api.acedata.cloud/fish/tts' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "text": "Hermanos míos, hoy es un buen día.",
    "reference_id": "8d2c17a9b26d4d83888ea67a1ee565b2",
    "format": "mp3"
  }'
```

## Różnice w interfejsie listy

| Pole                                                 | `GET /fish/model` (lista) | `GET /fish/model/{id}` (szczegóły) |
| -------------------------------------------------- | --------------------- | -------------------------- |
| `samples[].audio`                                  | Krótkoterminowy URL R2          | Bezpośredni link R2 z podpisem (z ciągiem zapytania)      |
| `unliked` / `liked` / `marked` / `dmca_taken_down` | Istnieje również                  | Istnieje również                       |
| `default_text` / `lock_visibility`                 | Istnieje również                  | Istnieje również                       |

Jeśli chcesz tylko posłuchać, `samples[].audio` w interfejsie listy jest wystarczające; dla bardziej stabilnego linku do pobrania, zaleca się użycie tego interfejsu.

## Pola odpowiedzi (wybrane)

| Pole          | Typ     | Opis                                                                |
| ------------- | -------- | ------------------------------------------------------------------- |
| `_id`         | string   | ID głosu (używane przez `reference_id` w `/fish/tts`).                     |
| `type`        | string   | Typ modelu, zazwyczaj `tts`.                                           |
| `title`       | string   | Nazwa głosu.                                                          |
| `description` | string   | Długi opis.                                                            |
| `state`       | string   | Status trenowania: `trained` oznacza, że model jest gotowy do użycia, a `training` oznacza, że trenowanie nadal trwa.              |
| `tags`        | string[] | Tag biblioteki publicznej.                                                        |
| `samples`     | object[] | Wstępnie ustawiona próbka zawierająca bezpośrednie linki `title`, `text`, `task_id` i `audio`.              |
| `languages`   | string[] | Kod języka, w którym głos jest wyspecjalizowany.                                                |
| `visibility`  | string   | `public` lub `private`.                                             |
| `like_count`  | integer  | Liczba polubień w bibliotece publicznej.                                                      |
| `task_count`  | integer  | Liczba historycznych syntez (może służyć jako odniesienie do sortowania według popularności).                                |
| `author`      | object   | Informacje o autorze: `_id` / `nickname` / `avatar`.                       |
| `created_at`  | string   | Czas utworzenia w formacie ISO 8601.                                                  |
| `updated_at`  | string   | Czas ostatniej aktualizacji w formacie ISO 8601.                                              |

## Informacje o opłatach

Ten interfejs nie jest płatny — zapytanie o szczegóły pojedynczego dźwięku według ID jest darmową operacją. Tworzenie dźwięku ([Fish Model Create](https://platform.acedata.cloud/documents/fish-model)) również jest darmowe, opłaty powstają tylko podczas wywoływania [Fish TTS](https://platform.acedata.cloud/documents/fish-tts) do syntezowania głosu.

## Obsługa błędów

- `400 token_mismatched`: `id` w ścieżce ma nieprawidłowy format lub głos nie istnieje.
- `401 invalid_token`: token uwierzytelniający nie istnieje lub jest nieprawidłowy.
- `404 not_found`: głos odpowiadający wskazanemu `_id` jest niedostępny (został usunięty, jest prywatny lub należy do innego konta).
- `429 too_many_requests`: osiągnięto limit szybkości dla konta.
- `500 api_error`: wewnętrzny błąd serwera.

Żądanie nieistniejącego ID może zwrócić `400 Model not found` (potwierdzone w testach):

```shell
curl 'https://api.acedata.cloud/fish/model/test123' \
  -H 'authorization: Bearer {token}'
```

Zwraca:

```json
{ "status": 400, "message": "Model not found" }
```

Przykład odpowiedzi błędu:

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```

## Wnioski

Znając `_id` brzmienia, można bezpośrednio użyć tego interfejsu do uzyskania pełnego ModelEntity, najczęstsze zastosowania to: (1) odsłuch `samples[].audio`, (2) podanie `_id` do `reference_id` w `/fish/tts` w celu zakończenia syntezy. Jeśli masz tylko tytuł lub tagi, najpierw użyj [Fish Model Query](https://platform.acedata.cloud/documents/fish-model-query) do wyszukiwania.
