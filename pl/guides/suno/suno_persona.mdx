---
title: "Instrukcja integracji API niestandardowego stylu wokalisty Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO pozwala nam ustawić styl wokalisty dla już wygenerowanych utworów, a następnie przeprowadzić na ich podstawie wtórną twórczość; ten dokument wyjaśnia powiązane metody integracji API.

Zapytanie listy `GET /suno/persona` i usuwanie rekordów `DELETE /suno/persona` nie są płatne i nie wymagają dodatkowego nagłówka żądania zwolnienia z opłaty. Operacja tworzenia `POST /suno/persona` nadal jest rozliczana zgodnie z zasadami wyceny interfejsu.

To API ma tylko trzy parametry wejściowe: najpierw `audio_id`, jest to ID utworu, który został już pomyślnie wygenerowany w oficjalnej usłudze, następnie `name`, `description`, są to nazwa i opis stylu wokalisty.

Wprowadzane tutaj `audio_id` to `https://cdn.acedata.cloud/2qhzs3.png`; możesz odwołać się do [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby przeprowadzić niestandardowe generowanie utworu, i ostatecznie uzyskać `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Wynik jest następujący:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Jak widać, pole `persona_id` w `data` jest ID wygenerowanego stylu wokalisty.

Po uzyskaniu ID stylu wokalisty możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) do niestandardowego generowania utworów, na przykład przekazać `artist_consistency` do `action`, jednocześnie przekazać ID przesłanego utworu do `audio_id`, należy również przesłać parametr `persona_id`, którego wartością jest zwrócone powyżej ID stylu wokalisty, dzięki czemu można wygenerować nowy utwór na podstawie referencyjnego stylu wokalisty.
