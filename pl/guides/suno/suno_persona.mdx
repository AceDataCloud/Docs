---
title: "Instrukcja integracji API niestandardowego stylu wokalisty Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

SUNO pozwala nam ustawić styl wokalisty dla już wygenerowanej piosenki, a następnie przeprowadzić na jego podstawie wtórną kreację. Ten dokument wyjaśnia metodę integracji powiązanego API.

Zapytanie listy `GET /suno/persona` oraz usuwanie rekordów `DELETE /suno/persona` nie są płatne i nie wymagają dodatkowego nagłówka żądania zwolnionego z opłat. Operacja tworzenia `POST /suno/persona` nadal jest rozliczana zgodnie z zasadami wyceny interfejsu.

W ścieżce tworzenia obsługującej zapytanie o barwę głosu można, używając oryginalnej aplikacji i tożsamości wywołującego, przekazać `persona_id` z wyniku tworzenia do `POST /suno/availability`. Gdy dostępność zostanie potwierdzona, zwracane jest `data.available=true`. [Przewodnik po sprawdzaniu dostępności barwy głosu](https://platform.acedata.cloud/documents/suno-availability-integration)

To API ma tylko trzy parametry wejściowe: najpierw `audio_id`, który jest identyfikatorem piosenki pomyślnie wygenerowanej wcześniej oficjalnie, a następnie `name`, `description`, które są nazwą i opisem stylu wokalisty.

Wprowadzane tutaj `audio_id` to `https://cdn.acedata.cloud/2qhzs3.png`. Można odwołać się do [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby przeprowadzić niestandardowe generowanie piosenki, a na końcu można uzyskać `audio_id`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/persona' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "name": "test",
  "audio_id": "81745564-60e7-4ad4-85a9-6f42f0f4f3b3",
  "description": "test"
}'
```

Wynik jest następujący:

```
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dae4ae5d-2b51-4af1-b286-1a4473ef4dba"
  }
}
```

Można zauważyć, że pole `persona_id` w `data` jest identyfikatorem stylu wokalisty po wygenerowaniu.

Po uzyskaniu identyfikatora stylu wokalisty możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby przeprowadzić niestandardowe generowanie piosenki. Na przykład przekazujemy `artist_consistency` do `action`, jednocześnie przekazujemy identyfikator przesłanej piosenki do `audio_id`, a także należy przesłać parametr `persona_id`. Ta wartość jest identyfikatorem stylu wokalisty zwróconym powyżej, dzięki czemu można wygenerować nową piosenkę na podstawie referencyjnego stylu wokalisty.
