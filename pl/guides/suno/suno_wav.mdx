SUNO umożliwia pobieranie plików muzycznych w formacie wav. Niniejszy dokument opisuje metody integracji z odpowiednim API.

Głównym parametrem wejściowym tego API jest `audio_id`, który jest oficjalnym identyfikatorem utworu; opcjonalnie obsługiwany jest również adres `callback_url` do asynchronicznego wywołania zwrotnego.

W tym przykładzie podajemy `audio_id` o wartości `4e43116a-bf09-472c-8e1c-655eabf02682`.

```python
import requests

url = "https://api.acedata.cloud/suno/wav"

headers = {
    "accept": "application/json",
    "authorization": "Bearer aa287fa4cc54401087a9fab3f99630af",
    "content-type": "application/json"
}

payload = {
    "audio_id": "4e43116a-bf09-472c-8e1c-655eabf02682"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Wynik wygląda następująco:

```json
{
  "success": true,
  "task_id": "6a5a2099-d6d3-4930-9709-a30ac5dc7de5",
  "trace_id": "3fa70e81-6bb7-4ca8-b718-dd16a4eda7e8",
  "data": [
    {
      "file_url": "https://platform.cdn.acedata.cloud/suno/6a5a2099-d6d3-4930-9709-a30ac5dc7de5.wav"
    }
  ]
}
```

Jak widać, pole `file_url` w `data` zawiera adres pliku muzycznego w formacie wav, który jest publicznie dostępny na CDN.

> **O trwałości linków WAV**
>
> Pliki WAV na oryginalnym CDN Suno (`https://cdn1.suno.ai/{audio_id}.wav`) są przechowywane tylko przez kilka dni, po czym są usuwane i dostęp do nich zwraca błąd 403.
> Aby uniknąć wygaśnięcia linków, to API przed zwróceniem wyniku automatycznie kopiuje plik WAV z oryginalnego źródła na własny CDN (`https://platform.cdn.acedata.cloud/suno/{task_id}.wav`), a zwracany `file_url` to stabilny adres po kopiowaniu, który nie wygasa wraz z wygaśnięciem oryginalnego CDN.
> W przypadku niepowodzenia kopiowania (co zdarza się bardzo rzadko), zwracany jest oryginalny adres źródłowy, zachowując dotychczasowe zachowanie.
