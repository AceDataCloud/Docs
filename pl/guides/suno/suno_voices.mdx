---

SUNO pozwala nam na tworzenie niestandardowych ról głosowych za pomocą dowolnego pliku audio, umożliwiając klonowanie głosu do generowania muzyki. W przeciwieństwie do istniejącego API Persona (używającego `audio_id` wygenerowanego przez Suno), to API akceptuje publicznie dostępny `audio_url`, czyli nagranie głosu, które samodzielnie wykonasz. Niniejszy dokument wyjaśnia metodę integracji API klonowania dźwięku.

To API ma trzy parametry wejściowe: `audio_url` (wymagany), który jest publicznie dostępnym URL-em pliku audio w formacie MP3 lub WAV, zawierającym wyraźny głos jednej osoby; `name` i `description` (opcjonalne), które są nazwą i opisem roli głosowej.

**Wymagania dotyczące pliku audio:**

- Format: MP3 lub WAV
- Czas trwania: co najmniej 10 sekund
- Zawartość: wyraźny głos jednej osoby, staraj się zminimalizować hałas w tle lub muzykę

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://example.com/my-vocal-recording.mp3",
  "name": "Mój Głos",
  "description": "Ciepły męski głos"
}'
```

Wynik wygląda następująco:

```json
{
  "success": true,
  "task_id": "8e808558-f056-456f-91d6-b97fd94eb3be",
  "data": {
    "persona_id": "dde0be60-5280-4bd2-89a0-4020ddd3db52",
    "name": "Mój Głos",
    "is_public": false
  }
}
```

Można zauważyć, że pole `persona_id` w `data` to ID utworzonej roli głosowej. Pole `is_public` zawsze ma wartość `false`, ponieważ rola głosowa utworzona przez przesłanie audio jest prywatna.

Mając ID roli głosowej, możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) do generowania muzyki. Ustaw `action` na `vox`, a `persona_id` na wartość zwróconą powyżej, a generowana piosenka będzie wykonywana przy użyciu sklonowanego głosu.
