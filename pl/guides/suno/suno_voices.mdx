SUNO pozwala nam tworzyć niestandardowe persony głosowe za pomocą dowolnego pliku audio, realizując klonowanie głosu do generowania muzyki. W przeciwieństwie do istniejącego API Persona (które używa wygenerowanego przez Suno `audio_id`), to API przyjmuje publicznie dostępny `audio_url`, czyli własne nagranie głosu. Ten dokument wyjaśnia metodę integracji API klonowania głosu.

## Krok pierwszy: tworzenie persony głosowej

Rozliczenie: po pomyślnym utworzeniu persony głosowej standardowy koszt każdego żądania wynosi **0.15 Credits**. Obowiązujące zniżki dotyczące zużycia są zgodne z rzeczywistym rachunkiem, a nieudane żądania nie są płatne.

To API ma trzy parametry wejściowe: `audio_url` (wymagany), czyli publicznie dostępny adres URL pliku audio w formacie MP3 lub WAV, zawierającego wyraźny głos jednej osoby; `name` i `description` (opcjonalne), czyli nazwę i opis persony głosowej.

> **Wymagania dotyczące pliku audio**
> - Format audio musi być `WAV` lub `MP3`
> - Długość audio musi wynosić od `10~240 sekund`; zaleca się użycie czystego materiału z głosem jednej osoby bez podkładu, o długości `30~60 sekund`
> - Audio powinno zawierać **wyraźny, rozpoznawalny głos jednej osoby mówiącej lub śpiewającej**
> - Należy bezwzględnie unikać **szumów tła, podkładu muzycznego, echa, pogłosu**; pełne utwory z podkładem zazwyczaj nie przechodzą weryfikacji odcisku głosu
> - Nie należy zawierać **wielu mówców** ani **wielu warstw głosowych**
> - Materiał o zbyt niskiej głośności, nieczytelnej mowie lub zbyt dużym szumie może prowadzić do **niepowodzenia klonowania** lub **gorszych efektów generowania**
> **Opis ograniczeń użycia**
> - Persony głosowe utworzone przez przesłanie audio są **zasobami prywatnymi**
> - Ta persona głosowa **nie obsługuje ponownego użycia między kontami**
> - Zaleca się użycie jej możliwie szybko po pomyślnym utworzeniu; długi okres nieużywania może skutkować **wygaśnięciem lub niedostępnością**
> - Zwrócone `name` jest generowane automatycznie przez system; należy kierować się zwróconym `persona_id`

> **W przypadku niepowodzenia wywołania najpierw spróbuj ponownie**
> Klonowanie głosu jest zadaniem intensywnym obliczeniowo, dlatego nawet jeśli materiał jest w pełni zgodny z wymaganiami, istnieje pewne prawdopodobieństwo sporadycznego niepowodzenia. Częste odpowiedzi to
> `voices_sound_different` (weryfikacja odcisku głosu nie przeszła) itp. **Tego rodzaju niepowodzenia nie są związane z jakością audio; ponowienie próby z tym samym materiałem zwykle kończy się powodzeniem**,
> zaleca się wdrożenie 1~2 automatycznych ponowień dla nieudanych wyników podczas integracji. Nieudane żądania nie są płatne.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Powyższy `https://cdn.acedata.cloud/suno_demo.mp3` jest przykładowym materiałem, który można wywołać bezpośrednio (MP3, 41 sekund, czysty głos jednej osoby).
> Jeśli potrzebujesz przykładu w formacie `WAV`, możesz użyć
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekund, mono 44.1kHz).

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Jak widać, pole `persona_id` w `data` jest ID utworzonej persony głosowej. Pole `is_public` zawsze ma wartość `false`, ponieważ persony głosowe utworzone przez przesłanie audio są prywatne. Zauważ, że zwrócone `name` jest generowane automatycznie przez system; w dalszej części należy używać `persona_id` do odwoływania się do tej persony głosowej.

## Krok drugi: generowanie muzyki przy użyciu persony głosowej

Po uzyskaniu ID persony głosowej możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) do generowania muzyki. Ustaw `action` na `generate` i `persona_id` na ID persony głosowej zwrócone powyżej, a wygenerowana piosenka będzie śpiewana sklonowanym głosem.

> **Uwaga:** Klonowanie głosu obsługuje wyłącznie modele `chirp-v4-5` i nowsze (takie jak `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nie obsługuje `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` można używać do generowania `generate`, a także do coverów `cover` / `upload_cover`. Przy określaniu głosu nie trzeba jednocześnie wypełniać `vocal_gender`; podobieństwo głosu nadal zależy od materiału referencyjnego i wyniku generowania.

Głosy utworzone przez ten interfejs są zasobami prywatnymi. Przed wykonaniem coveru istniejącej piosenki najpierw wywołaj `/suno/upload`, przekazując `audio_url` oryginalnego utworu oraz `persona_id` tego głosu; po pomyślnym przesłaniu użyj zwróconego `data.audio_id` i tego samego `persona_id`, aby wywołać `/suno/audios`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Tworzenie głosu, przesyłanie oryginalnego utworu i wykonywanie coveru muszą korzystać z tego samego kanału usługi. Nie używaj bezpośrednio ponownie ID utworów, które wcześniej nie zostały powiązane z tym prywatnym głosem; szczegóły znajdziesz w [Suno przesyłanie referencyjnego audio](https://platform.acedata.cloud/documents/suno-upload).
