SUNO umożliwia nam tworzenie niestandardowych postaci głosowych za pomocą dowolnego pliku audio, realizując klonowanie głosu do generowania muzyki. W przeciwieństwie do istniejącego API Persona (które używa wygenerowanego przez Suno `audio_id`), to API przyjmuje publicznie dostępny `audio_url`, czyli własne nagranie głosu. Ten dokument wyjaśnia metodę integracji API klonowania głosu.

W ścieżce tworzenia obsługującej sprawdzanie dostępności barwy głosu można, używając oryginalnej aplikacji i tożsamości wywołującego, przekazać `persona_id` z wyniku tworzenia do `POST /suno/availability`. Gdy powiązane konto jest online, zwracane jest `data.available=true`, a gdy potwierdzono, że jest offline, zwracane jest `data.available=false`. [Przewodnik sprawdzania dostępności barwy głosu](https://platform.acedata.cloud/documents/suno-availability-integration)

## Krok pierwszy: tworzenie postaci głosowej

Rozliczanie: po pomyślnym utworzeniu postaci głosowej standardowy koszt każdego żądania wynosi **0.15 Credits**. Obowiązujące zniżki konsumpcyjne zależą od faktycznego rachunku, nieudane żądania nie są płatne.

To API ma trzy parametry wejściowe: `audio_url` (wymagany), czyli publicznie dostępny adres URL pliku audio w formacie MP3 lub WAV, zawierającego wyraźny głos jednej osoby; `name` i `description` (opcjonalne), czyli nazwę i opis postaci głosowej.

> **Wymagania dotyczące pliku audio**
> - Format audio musi być `WAV` lub `MP3`
> - Czas trwania audio musi wynosić od `10~240 sekund`, zaleca się użycie czystego materiału z pojedynczym suchym głosem o długości `30~60 sekund`
> - Audio powinno zawierać **wyraźny, rozpoznawalny głos jednej osoby mówiącej lub śpiewającej**
> - Koniecznie unikaj **szumu tła, podkładu muzycznego, echa, pogłosu**; kompletne utwory z podkładem zazwyczaj nie przechodzą weryfikacji odcisku głosu
> - Nie należy zawierać **wielu mówców** ani **wielu głosów**
> - Materiały o zbyt niskiej głośności, nieczytelnej mowie lub zbyt dużym szumie mogą prowadzić do **niepowodzenia klonowania** lub **słabszych efektów generowania**
> **Opis ograniczeń użycia**
> - Postacie głosowe utworzone przez przesłanie audio są **zasobami prywatnymi**
> - Ta postać głosowa **nie obsługuje ponownego użycia między kontami**
> - Zaleca się użycie jej jak najszybciej po pomyślnym utworzeniu; długi okres nieużywania może spowodować **wygaśnięcie lub niedostępność**
> - Zwrócone `name` jest generowane automatycznie przez system, należy kierować się zwróconym `persona_id`

> **Obsługuj niepowodzenia według wyraźnego znacznika ponawiania**
> `retryable` w obiekcie błędu jest opcjonalnym polem logicznym. Gdy `error.retryable` ma wartość `true`, oznacza to, że po tym niepowodzeniu można później ponowić żądanie przy użyciu tego samego materiału i tych samych parametrów. Wyraźnie nieprzyjęte przeciążenie usługi lub częściowe tymczasowe niepowodzenia weryfikacji odcisku głosu mogą zawierać ten znacznik; zaleca się użycie interwałów wycofywania i ograniczenie liczby ponowień.
> Gdy `retryable` ma wartość `false` lub pole nie istnieje, nie ponawiaj automatycznie wysyłania wyłącznie na podstawie HTTP 500, `busy` lub tekstu błędu. Problemy z formatem, czasem trwania, czytelnością, powtarzającymi się nagraniami i moderacją treści należy najpierw poprawić; w przypadku przekroczenia czasu przesyłania, przerwania połączenia lub niejasnego wyniku tworzenia należy w pierwszej kolejności użyć oryginalnego `task_id` do sprawdzenia zadania, aby uniknąć wielokrotnego tworzenia barwy głosu. Nieudane żądania nie są rozliczane, a pomyślnie ponowione żądania są rozliczane według standardowych zasad.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Powyższe `https://cdn.acedata.cloud/suno_demo.mp3` jest przykładowym materiałem, który można wywołać bezpośrednio (MP3, 41 sekund, pojedynczy suchy głos).
> Jeśli potrzebny jest przykład w formacie `WAV`, można użyć
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekund, mono 44.1kHz).

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Można zobaczyć, że pole `persona_id` w `data` jest właśnie ID utworzonej postaci głosowej. Pole `is_public` zawsze ma wartość `false`, ponieważ postacie głosowe utworzone przez przesłanie audio są prywatne. Zwróć uwagę, że zwrócone `name` jest generowane automatycznie przez system, w dalszej kolejności używaj `persona_id` do odwoływania się do tej postaci głosowej.

## Krok drugi: generowanie muzyki z użyciem postaci głosowej

Po uzyskaniu ID postaci głosowej możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) do generowania muzyki. Ustaw `action` na `generate` i ustaw `persona_id` na ID postaci głosowej zwrócone powyżej, a wygenerowane utwory będą śpiewane przy użyciu sklonowanego głosu.

> **Uwaga:** Klonowanie głosu obsługuje wyłącznie modele `chirp-v4-5` i wyższe (takie jak `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nie obsługuje `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` może być używane do generowania `generate`, a także do coverów `cover` / `upload_cover`. Przy wskazaniu głosu nie trzeba jednocześnie wypełniać `vocal_gender`; podobieństwo głosu nadal zależy od materiału referencyjnego i wyniku generowania.

Głos utworzony przez ten interfejs jest zasobem prywatnym. Przed wykonaniem coveru istniejącego utworu najpierw wywołaj `/suno/upload`, przekaż `audio_url` oryginalnego utworu oraz `persona_id` tego głosu; po pomyślnym przesłaniu użyj zwróconego `data.audio_id` i tego samego `persona_id` do wywołania `/suno/audios`:
```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Tworzenie głosu, przesyłanie oryginalnego utworu i coveru muszą korzystać z tego samego kanału usługi. Nie używaj bezpośrednio ponownie identyfikatora utworu, który wcześniej nie został powiązany z tym prywatnym głosem; szczegóły znajdziesz w [Referencja audio przesłanego do Suno](https://platform.acedata.cloud/documents/suno-upload).
