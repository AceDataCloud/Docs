SUNO pozwala nam tworzyć niestandardowe postacie głosowe za pomocą dowolnego pliku audio, realizując klonowanie głosu na potrzeby generowania muzyki. W przeciwieństwie do istniejącego Persona API (które używa `audio_id` wygenerowanego przez Suno), to API akceptuje publicznie dostępny `audio_url`, czyli własne nagranie głosu. Ten dokument wyjaśnia sposób integracji API klonowania głosu.

## Krok pierwszy: utworzenie postaci głosowej

To API ma trzy parametry wejściowe: `audio_url` (wymagany), czyli publicznie dostępny adres URL pliku audio w formacie MP3 lub WAV, zawierającego wyraźny głos jednej osoby; `name` i `description` (opcjonalne), czyli nazwę i opis postaci głosowej.

> **Wymagania dotyczące pliku audio**
> - Format audio musi być `WAV` lub `MP3`
> - Długość audio musi wynosić od `10~240 sekund`; zaleca się użycie czystego materiału z głosem jednej osoby bez podkładu o długości `30~60 sekund`
> - Audio powinno zawierać **wyraźny, rozpoznawalny głos jednej osoby mówiącej lub śpiewającej**
> - Należy koniecznie unikać **szumów tła, podkładu muzycznego, echa, pogłosu**; pełne utwory z podkładem zazwyczaj nie przechodzą weryfikacji odcisku głosu
> - Nie należy zawierać **wielu mówców** ani **wielu warstw głosowych**
> - Materiały o zbyt niskiej głośności, niewyraźnej mowie lub nadmiernym szumie mogą prowadzić do **niepowodzenia klonowania** lub **słabszych efektów generowania**
> **Opis ograniczeń użycia**
> - Postacie głosowe utworzone przez przesłanie audio są **zasobami prywatnymi**
> - Ta postać głosowa **nie obsługuje ponownego użycia między kontami**
> - Zaleca się użycie jej jak najszybciej po pomyślnym utworzeniu; długi okres nieużywania może skutkować **wygaśnięciem lub niedostępnością**
> - Zwrócone `name` jest generowane automatycznie przez system; należy kierować się zwróconym `persona_id`

> **W przypadku niepowodzenia wywołania najpierw spróbuj ponownie**
> Klonowanie głosu jest zadaniem intensywnym obliczeniowo; nawet jeśli materiał jest w pełni zgodny z wymaganiami, istnieje pewne prawdopodobieństwo sporadycznego niepowodzenia, a częste odpowiedzi to
> `voices_sound_different` (weryfikacja odcisku głosu nie przeszła pomyślnie) itp. **Takie niepowodzenia nie są związane z jakością audio; ponowna próba z tym samym materiałem zwykle kończy się powodzeniem**,
> zaleca się zaimplementowanie 1~2 automatycznych ponownych prób dla nieudanych wyników podczas integracji. Nieudane żądania nie są płatne.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Powyższy `https://cdn.acedata.cloud/suno_demo.mp3` jest przykładowym materiałem, którego można użyć bezpośrednio do wywołania (MP3, 41 sekund, czysty głos jednej osoby).
> Jeśli potrzebny jest przykład w formacie `WAV`, można użyć
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekund, mono 44,1 kHz).

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Jak widać, pole `persona_id` w `data` jest właśnie identyfikatorem utworzonej postaci głosowej. Pole `is_public` zawsze ma wartość `false`, ponieważ postacie głosowe utworzone przez przesłanie audio są prywatne. Należy pamiętać, że zwrócone `name` jest generowane automatycznie przez system; w dalszej kolejności należy używać `persona_id` do odwoływania się do tej postaci głosowej.

## Krok drugi: generowanie muzyki przy użyciu postaci głosowej

Po uzyskaniu identyfikatora postaci głosowej możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) do generowania muzyki. Ustaw `action` na `generate` i `persona_id` na identyfikator postaci głosowej zwrócony powyżej, a wygenerowana piosenka użyje sklonowanego głosu do śpiewu.

> **Uwaga:** Klonowanie głosu obsługuje wyłącznie modele `chirp-v4-5` i nowsze (takie jak `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`); nie obsługuje `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

Jak widać, wygenerowana piosenka używa sklonowanego głosu do śpiewu. `persona_id` można również używać wraz z akcją `cover`, aby wykonać cover istniejącej piosenki sklonowanym głosem.
