SUNO umożliwia tworzenie niestandardowych postaci głosowych na podstawie dowolnych plików audio, realizując klonowanie głosu do generowania muzyki. W odróżnieniu od istniejącego Persona API (korzystającego z `audio_id` generowanego przez Suno), to API przyjmuje publicznie dostępny `audio_url`, czyli własne nagranie głosu. Niniejsza dokumentacja wyjaśnia, jak zintegrować API klonowania głosu.

## Krok pierwszy: utworzenie postaci głosowej

API przyjmuje trzy parametry wejściowe: `audio_url` (wymagany) – publicznie dostępny URL do pliku audio w formacie MP3 lub WAV zawierającego wyraźny głos jednej osoby; `name` oraz `description` (opcjonalne) – nazwa i opis postaci głosowej.

**Wymagania dotyczące pliku audio:**
- Format: MP3 lub WAV
- Długość: minimum 10 sekund
- Zawartość: wyraźny głos jednej osoby, z minimalnym szumem tła lub muzyką

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn1.suno.ai/f91c081c-899a-498f-8b74-afaf6b539889.mp3",
  "name": "My Custom Voice",
  "description": "A warm and expressive voice"
}'
```

Otrzymany rezultat:

```json
{
  "success": true,
  "task_id": "c771bfa1-9d78-44d7-88e5-6cffea83bfc8",
  "data": {
    "persona_id": "011816ee-570d-4c72-9786-33126cdb0106",
    "name": "My Custom Voice",
    "is_public": false
  }
}
```

Widać, że pole `persona_id` w `data` to ID utworzonej postaci głosowej. Pole `is_public` zawsze ma wartość `false`, ponieważ postacie głosowe tworzone przez przesłanie pliku audio są prywatne.

## Krok drugi: generowanie muzyki z wykorzystaniem postaci głosowej

Mając ID postaci głosowej, możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/4da95d9d-7722-4a72-857d-bf6be86036e9) do generowania muzyki. Należy ustawić `action` na `generate` oraz `persona_id` na ID postaci głosowej zwrócone powyżej. Wygenerowana piosenka będzie wykonywana głosem sklonowanym.

> **Uwaga:** Klonowanie głosu jest obsługiwane tylko przez modele `chirp-v4-5` i nowsze (np. `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nie jest wspierane przez `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v4-5",
  "prompt": "A gentle folk song about morning sunshine",
  "persona_id": "011816ee-570d-4c72-9786-33126cdb0106"
}'
```

Otrzymany rezultat:

```json
{
  "success": true,
  "task_id": "be62c0f8-9b7f-4c3b-a796-6ca8df0ada4d",
  "data": [
    {
      "id": "bb281faa-b037-4664-994c-7d3c60b45592",
      "title": "Morning On My Window Sill",
      "audio_url": "https://cdn1.suno.ai/bb281faa-b037-4664-994c-7d3c60b45592.mp3",
      "image_url": "https://cdn2.suno.ai/image_bb281faa-b037-4664-994c-7d3c60b45592.jpeg",
      "model": "chirp-v4-5",
      "state": "succeeded",
      "prompt": "A gentle folk song about morning sunshine",
      "duration": 214.96
    }
  ]
}
```

Widać, że wygenerowana piosenka została wykonana głosem sklonowanym. `persona_id` można również użyć z akcją `cover`, aby wykonać cover istniejącej piosenki przy użyciu sklonowanego głosu.
