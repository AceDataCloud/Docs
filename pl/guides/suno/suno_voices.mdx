SUNO pozwala nam tworzyć niestandardowe postacie głosowe za pomocą dowolnego pliku audio, umożliwiając klonowanie głosu do generowania muzyki. W odróżnieniu od istniejącego API Persona (które używa wygenerowanego przez Suno `audio_id`), to API przyjmuje publicznie dostępny `audio_url`, czyli własne nagranie głosu. Ten dokument wyjaśnia metodę integracji API klonowania głosu.

## Krok pierwszy: tworzenie postaci głosowej

To API ma trzy parametry wejściowe: `audio_url` (wymagany), będący publicznie dostępnym adresem URL pliku audio w formacie MP3 lub WAV, zawierającego wyraźny głos jednej osoby; oraz `name` i `description` (opcjonalne), będące nazwą i opisem postaci głosowej.

> **Wymagania dotyczące pliku audio**
> - Format audio musi być `WAV` lub `MP3`
> - Długość audio musi wynosić od `10~240 sekund`, zaleca się użycie `30~60 sekund` czystego materiału z suchym głosem jednej osoby
> - Audio powinno zawierać **wyraźny, rozpoznawalny głos jednej osoby mówiącej lub śpiewającej**
> - Należy koniecznie unikać **szumów tła, akompaniamentu, echa, pogłosu**; pełne utwory z akompaniamentem zwykle nie przechodzą weryfikacji odcisku głosowego
> - Nie należy zawierać **wielu mówców** ani **wielokrotnych głosów**
> - Materiał o zbyt niskiej głośności, niewyraźnej mowie lub zbyt dużym szumie może prowadzić do **niepowodzenia klonowania** lub **gorszych efektów generowania**
> **Opis ograniczeń użycia**
> - Postacie głosowe utworzone przez przesłanie audio są **zasobami prywatnymi**
> - Ta postać głosowa **nie obsługuje ponownego użycia między kontami**
> - Zaleca się użycie jej możliwie szybko po pomyślnym utworzeniu; długi okres nieużywania może spowodować **wygaśnięcie lub niedostępność**
> - Zwracane `name` jest generowane automatycznie przez system, należy kierować się zwróconym `persona_id`

> **W przypadku niepowodzenia wywołania najpierw spróbuj ponownie**
> Klonowanie głosu jest zadaniem intensywnie wykorzystującym moc obliczeniową, dlatego nawet jeśli materiał jest w pełni zgodny z wymaganiami, istnieje pewne prawdopodobieństwo sporadycznego niepowodzenia; częste odpowiedzi to
> `voices_sound_different` (nieudana weryfikacja odcisku głosowego) i podobne. **Ten rodzaj niepowodzenia nie jest związany z jakością audio; ponowna próba z tym samym materiałem zwykle kończy się powodzeniem**,
> zaleca się zaimplementowanie w integracji 1~2 automatycznych ponownych prób dla wyników niepowodzenia. Nieudane żądania nie są płatne.

```bash
curl -X POST 'https://api.acedata.cloud/suno/voices' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "audio_url": "https://cdn.acedata.cloud/suno_demo.mp3",
  "name": "My Voice",
  "description": "单人清晰人声示例"
}'
```

> Powyższy `https://cdn.acedata.cloud/suno_demo.mp3` to przykładowy materiał, który można wywołać bezpośrednio (MP3, 41 sekund, suchy głos jednej osoby).
> Jeśli potrzebny jest przykład w formacie `WAV`, można użyć
> `https://cdn.acedata.cloud/uploads/82d23b97-ec1c-4b41-91b8-989fc51f8765` (WAV, 41 sekund, mono 44,1 kHz).

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "0fa609a6-c8d9-4bb5-8574-e4c93bb55d02",
  "data": {
    "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16",
    "name": "VOICE_20260803037676",
    "is_public": false
  }
}
```

Jak widać, pole `persona_id` w `data` jest ID utworzonej postaci głosowej. Pole `is_public` zawsze ma wartość `false`, ponieważ postacie głosowe utworzone przez przesłanie audio są prywatne. Należy pamiętać, że zwracane `name` jest generowane automatycznie przez system; w dalszych krokach należy używać `persona_id` do odwoływania się do tej postaci głosowej.

## Krok drugi: generowanie muzyki przy użyciu postaci głosowej

Po uzyskaniu ID postaci głosowej możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios) do generowania muzyki. Ustaw `action` na `generate` i ustaw `persona_id` na ID postaci głosowej zwrócone powyżej, a wygenerowana piosenka będzie śpiewana sklonowanym głosem.

> **Uwaga:** Klonowanie głosu obsługuje wyłącznie modele `chirp-v4-5` i nowsze (takie jak `chirp-v4-5`, `chirp-v5`, `chirp-v5-5`), nie obsługuje `chirp-v4`.

```bash
curl -X POST 'https://api.acedata.cloud/suno/audios' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "generate",
  "model": "chirp-v5-5",
  "prompt": "A warm synth-pop song about city nights",
  "persona_id": "1ab79a71-a229-4350-8f02-402ff02eac16"
}'
```

Wynik jest następujący:

```json
{
  "success": true,
  "task_id": "53d8a334-a972-43c5-895e-60c4454e88d5",
  "data": [
    {
      "id": "16463960-077c-4700-bbb3-3c7897b943d3",
      "title": "Soft Neon on My Skin",
      "audio_url": "https://cdn.acedata.cloud/assets/examples/fish/5ade0339-5f11-487e-aacc-06a908271706-8e3fcb0e5547.mp3",
      "image_url": "https://cdn.acedata.cloud/e724d7f13d.png",
      "model": "chirp-v5-5",
      "state": "succeeded",
      "prompt": "A warm synth-pop song about city nights",
      "duration": 156.28
    }
  ]
}
```

`persona_id` może być używane do generowania `generate`, a także do coverów `cover` / `upload_cover`. Przy określaniu głosu nie trzeba jednocześnie wypełniać `vocal_gender`; podobieństwo głosu nadal zależy od materiału referencyjnego i wyniku generowania.

Głosy utworzone przez ten interfejs są zasobami prywatnymi. Przed wykonaniem coveru istniejącej piosenki najpierw wywołaj `/suno/upload`, przekazując `audio_url` oryginalnego utworu i `persona_id` tego głosu; po pomyślnym przesłaniu użyj zwróconego `data.audio_id` oraz tego samego `persona_id`, aby wywołać `/suno/audios`:

```json
{
  "action": "upload_cover",
  "model": "chirp-v6",
  "audio_id": "<与该声音关联上传后返回的 audio_id>",
  "persona_id": "<声音创建接口返回的 persona_id>",
  "custom": true,
  "instrumental": false,
  "lyric": "[Verse]\n填写要演唱的歌词",
  "async": true
}
```

Tworzenie głosu, przesyłanie oryginalnego utworu i wykonywanie coveru muszą korzystać z tego samego kanału usługi. Nie należy bezpośrednio ponownie używać ID piosenki, które wcześniej nie zostało powiązane z tym prywatnym głosem; szczegóły znajdziesz w [Suno przesyłanie referencyjnego audio](https://platform.acedata.cloud/documents/suno-upload).
