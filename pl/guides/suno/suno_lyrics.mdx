title: "Instrukcja integracji API generowania tekstów Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Jeśli chcesz niestandardowo generować piosenki, ale niekoniecznie chcesz samodzielnie pisać teksty, możesz użyć API generowania tekstów udostępnianego przez AceDataCloud, aby generować teksty za pomocą promptu. API to [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Rozliczenie: po pomyślnym wygenerowaniu standardowy koszt każdego żądania wynosi **0.08 Credits**. Gdy jedno żądanie zwraca wielu kandydatów tekstów, nadal jest rozliczane tylko jako jedno żądanie; obowiązujące zniżki konsumpcyjne są zgodne z faktycznym rachunkiem, nieudane żądania nie są płatne.

Głównym parametrem wejściowym tego API jest `prompt`, opcjonalnie `model` (opcjonalne wartości: `default`, `remi-v1`, domyślnie `default`), przykład wypełnienia jest następujący:

![](https://cdn.acedata.cloud/p53wtj.png)

Tutaj wprowadzony przez nas `prompt` to `A song about winter`, aby wygenerować piosenkę związaną z zimą.

Kliknij uruchom, wynik jest następujący:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Verse]\nSnowflakes falling from the sky\nWinter's cold touch\nOh how it gets me high\nI bundle up in layers\nOh so cozy\nStepping out and feeling the frost on my nose\n\n[Chorus]\nOh\nWinter's cold touch\nIt's a season that I love so much\nSnowfall brings a feeling so divine\nWinter's cold touch\nIt's a magical time",
      "title": "Winter's Cold Touch",
      "status": "complete",
      "tags": ["dreamy, mellow, ballad"]
    },
    {
      "text": "[Verse]\nThe world is covered in a blanket of white\nIcicles hanging\nShimmering so bright\nThe chilly air fills my lungs with every breath\nWalking in the snow\nLeaving footprints behind\n\n[Chorus]\nWinter wonderland\nEverything is so bright\nWinter wonderland\nHold me through the night",
      "title": "Winter Wonderland",
      "status": "complete",
      "tags": ["dream pop, mellow, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Jak widać, `data` jest tablicą i za każdym razem zwraca wielu kandydatów tekstów, gdzie pole `text` każdego elementu stanowi treść tekstu piosenki, `title` jest tytułem, a `tags` są rekomendowanymi tagami stylu muzycznego.

Po uzyskaniu tekstów możemy użyć [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby przeprowadzić niestandardowe generowanie piosenek.
