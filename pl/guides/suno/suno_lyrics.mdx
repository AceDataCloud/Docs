Jeśli chcesz dostosować generowanie piosenek, ale nie chcesz samodzielnie pisać tekstów, możesz skorzystać z API do generowania tekstów piosenek oferowanego przez AceDataCloud, aby wygenerować teksty za pomocą promptu. API to [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Głównym parametrem wejściowym tego API jest `prompt`, opcjonalnie `model` (opcjonalne wartości to `default`, `remi-v1`, domyślnie `default`), przykładowe wypełnienie wygląda następująco:

![](https://cdn.acedata.cloud/p53wtj.png)

Tutaj wprowadzamy `prompt` jako `Piosenka o zimie`, generując piosenkę związaną z zimą.

Kliknij uruchom, a wynik wygląda następująco:

```json
{
  "success": true,
  "task_id": "2e26f7ff-0b82-4a60-bb9b-78db89f98b51",
  "data": [
    {
      "text": "[Zwrotka]\nPłatki śniegu spadają z nieba\nZimny dotyk zimy\nO jak mnie to unosi\nOwijam się w warstwy\nO tak przytulnie\nWychodzę i czuję mróz na nosie\n\n[Refren]\nO\nZimny dotyk zimy\nTo pora roku, którą tak bardzo kocham\nOpad śniegu przynosi uczucie tak boskie\nZimny dotyk zimy\nTo magiczny czas",
      "title": "Zimny Dotyk Zimy",
      "status": "complete",
      "tags": ["marzycielski, łagodny, ballada"]
    },
    {
      "text": "[Zwrotka]\nŚwiat pokryty jest białym kocem\nSople lodu wiszą\nBłyszczą tak jasno\nChłodne powietrze napełnia moje płuca z każdym oddechem\nSpacerując po śniegu\nZostawiając ślady za sobą\n\n[Refren]\nZimowa kraina cudów\nWszystko jest takie jasne\nZimowa kraina cudów\nPrzytul mnie przez noc",
      "title": "Zimowa Kraina Cudów",
      "status": "complete",
      "tags": ["dream pop, łagodny, shoegaze"]
    }
  ],
  "started_at": 1780684179.15,
  "finished_at": 1780684186.583,
  "elapsed": 7.433
}
```

Można zauważyć, że `data` to tablica, która za każdym razem zwraca wiele kandydatów na teksty, gdzie każdy element ma pole `text`, które zawiera treść tekstu, `title` to tytuł, a `tags` to polecane tagi stylu muzycznego.

Mając teksty, możemy skorzystać z [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby przeprowadzić generowanie dostosowanych piosenek.
