Jeśli chcesz dostosować generowanie piosenek, ale nie chcesz samodzielnie pisać tekstów, możesz skorzystać z API do generowania tekstów piosenek oferowanego przez AceDataCloud, aby wygenerować teksty za pomocą promptu. API to [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Głównym parametrem wejściowym tego API jest `prompt`, opcjonalny `model` (domyślnie chirp-v3), przykładowe wypełnienie wygląda następująco:

![](https://cdn.acedata.cloud/p53wtj.png)

Tutaj wprowadzamy `prompt` jako `Piosenka o zimie`, generując piosenkę związaną z zimą.

Kliknij uruchom, a wynik wygląda następująco:

```
{
  "success": true,
  "task_id": "57e8ce3a-39cb-41a2-802f-e70a324f4d0a",
  "data": {
    "text": "[Zwrotka]\nPłatki śniegu spadają z nieba\nZimny dotyk zimy\nO jak mnie to unosi\nOwijam się w warstwy\nO tak przytulnie\nWychodzę i czuję mróz na nosie\nZobacz\n\n[Zwrotka 2]\nŚwiat pokryty jest białym kocem\nSople lodu wiszą\nBłyszczą tak jasno\nChłodne powietrze napełnia moje płuca z każdym oddechem\nIdąc w śniegu\nZostawiając ślady, które nie zostaną\n\n[Refren]\nO\nZimny dotyk zimy\nTo pora, którą tak bardzo kocham\nOpad śniegu przynosi uczucie tak boskie\nZimny dotyk zimy\nTo magiczny czas",
    "title": "Zimny Dotyk Zimy",
    "status": "complete"
  }
}
```

Można zauważyć, że pole `text` w `data` to informacje o tekście piosenki.

Mając tekst piosenki, możemy skorzystać z [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby przeprowadzić generowanie dostosowanej piosenki.
