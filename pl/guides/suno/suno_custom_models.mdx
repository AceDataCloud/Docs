---
title: "Przewodnik integracji dedykowanego modelu muzycznego Suno"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Dedykowany model muzyczny może uczyć się spójnych cech muzycznych z 6 do 24 autoryzowanych nagrań audio i wykorzystywać je do późniejszego tworzenia utworów. Tworzenie jest operacją asynchroniczną; zaleca się użycie 24 nagrań o spójnym stylu i wyraźnej jakości dźwięku, aby uzyskać stabilniejsze efekty.

> Można przesyłać wyłącznie nagrania audio, do których posiadasz legalne prawo użycia lub dla których uzyskałeś zgodę na utworzenie modelu i późniejsze generowanie. Nie przesyłaj muzyki ani materiałów dźwiękowych bez zezwolenia.

## Tworzenie modelu

Wywołaj `POST /suno/custom-models` i ustaw `action=create`:

```json
{
  "action": "create",
  "name": "My Indie Model",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Interfejs natychmiast zwraca identyfikator modelu platformy i identyfikator zadania. Po zakończeniu tworzenia `status` w wyniku wywołania zwrotnego lub zapytania zmieni się na `ready`. Opłata **10 Credits** zostanie naliczona tylko wtedy, gdy utworzenie modelu zakończy się pomyślnie; nieudane utworzenie nie powoduje naliczenia opłaty.

## Pobieranie modelu

Pobieranie pojedynczego modelu:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Stronicowane pobieranie modeli bieżącej aplikacji:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Wszystkie modele należą do aplikacji Suno, która je utworzyła. Rotacja poświadczeń API nie zmienia przynależności modelu, a inne aplikacje nie mogą pobierać ani używać tego modelu.

## Generowanie utworów z użyciem modelu

Gdy status modelu wynosi `ready`, ponownie wywołaj `POST /suno/custom-models` i ustaw `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Verse]\nCity lights are falling through the rain",
  "style": "indie rock, warm analog synth"
}
```

`id` musi należeć do dedykowanego modelu muzycznego o statusie `ready` w bieżącej aplikacji. Żądanie zakończy się niepowodzeniem, gdy model jest niedostępny, i nie nastąpi automatyczne użycie innego modelu. `persona_id` i dedykowany model muzyczny wzajemnie się wykluczają; w przypadku jednoczesnego przesłania interfejs zwróci HTTP 400 przed wysłaniem żądania do usługi generowania i nie zostanie naliczona opłata. Aby użyć Persona, zastosuj operację `artist_consistency` lub `artist_consistency_vox` w `/suno/audios`.

Pomyślne wygenerowanie utworu zużywa **0.90 Credits**; nieudane generowanie nie powoduje naliczenia opłaty. Pobieranie i archiwizowanie modeli jest bezpłatne.

## Archiwizowanie modelu

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Obecna wersja Beta archiwizuje model i uniemożliwia jego dalsze używanie, a `capacity_released=false` w odpowiedzi oznacza, że archiwizacja nie gwarantuje zwolnienia pojemności modelu. Operację archiwizacji można wywoływać wielokrotnie i nie zostanie naliczona opłata wielokrotnie.
