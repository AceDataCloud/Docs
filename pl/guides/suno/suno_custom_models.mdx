Dedykowany model muzyczny może uczyć się spójnych cech muzycznych z 6 do 24 autoryzowanych nagrań audio i być używany do późniejszego tworzenia piosenek. Tworzenie jest operacją asynchroniczną; zaleca się użycie 24 nagrań o spójnym stylu i wysokiej jakości dźwięku, aby uzyskać bardziej stabilny efekt.

> Można przesyłać tylko te nagrania, do których posiada się legalne prawa do użytkowania lub uzyskano autoryzację na tworzenie modelu i późniejsze generowanie. Proszę nie przesyłać muzyki lub materiałów dźwiękowych bez zezwolenia.

## Tworzenie modelu

Wywołaj `POST /suno/custom-models` i ustaw `action=create`. Zaleca się jednoczesne wysłanie unikalnego nagłówka `Idempotency-Key`; przy ponownym próbie sieciowej użyj tego samego klucza, aby uniknąć powtórnego tworzenia:

```json
{
  "action": "create",
  "name": "Mój model indie",
  "audio_urls": [
    "https://cdn.example.com/song-01.mp3",
    "https://cdn.example.com/song-02.mp3",
    "https://cdn.example.com/song-03.mp3",
    "https://cdn.example.com/song-04.mp3",
    "https://cdn.example.com/song-05.mp3",
    "https://cdn.example.com/song-06.mp3"
  ],
  "callback_url": "https://example.com/webhooks/suno"
}
```

Interfejs natychmiast zwraca identyfikator modelu platformy i identyfikator zadania. Po zakończeniu tworzenia, w odpowiedzi zwrotnej lub zapytaniu o wynik `status` zmieni się na `ready`. Tylko udane utworzenie modelu będzie obciążane; nieudane utworzenie nie będzie skutkować opłatą.

## Zapytanie o model

Zapytanie o pojedynczy model:

```json
{
  "action": "retrieve",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Paginowane zapytanie o modele aktualnej aplikacji:

```json
{
  "action": "retrieve_batch",
  "limit": 20,
  "offset": 0,
  "status": "ready"
}
```

Wszystkie modele należą do aplikacji Suno, która je stworzyła. Rotacja poświadczeń API nie zmienia przynależności modelu, inne aplikacje nie mogą zapytywać ani używać tego modelu.

## Użycie modelu do generowania piosenek

Po zmianie statusu modelu na `ready`, kontynuuj wywołanie `POST /suno/custom-models` i ustaw `action=generate`:

```json
{
  "action": "generate",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e",
  "title": "Neon Rain",
  "lyric": "[Zwrotka]\nŚwiatła miasta spadają przez deszcz",
  "style": "indie rock, ciepły analogowy syntezator"
}
```

`id` musi być identyfikatorem dedykowanego modelu muzycznego o statusie `ready` w bieżącej aplikacji. Gdy model jest niedostępny, żądanie zakończy się niepowodzeniem i nie zostanie automatycznie użyty inny model.

## Archiwizacja modelu

```json
{
  "action": "delete",
  "id": "fa518f27-3fac-45cc-9b95-ae7ae0865b5e"
}
```

Aktualna wersja Beta archiwizuje model i zabrania dalszego używania, a `capacity_released=false` w odpowiedzi oznacza, że archiwizacja nie gwarantuje zwolnienia pojemności modelu. Operacja archiwizacji może być wywoływana wielokrotnie, nie będzie to skutkować powtórnymi opłatami.
