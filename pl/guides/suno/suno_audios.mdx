Wraz z coraz szerszym zastosowaniem AI, różnego rodzaju programy AI stopniowo się upowszechniły. AI stopniowo przeniknęła do wszystkich aspektów pracy i życia ludzi. A branż objętych przez AI jest coraz więcej, od początkowego pisania, przez edukację medyczną, aż po obecną muzykę.

Suno to profesjonalna, wysokiej jakości platforma AI do tworzenia piosenek i muzyki, użytkownicy muszą jedynie wprowadzić proste tekstowe słowa podpowiedzi, aby na podstawie stylu gatunkowego i tekstu piosenki generować utwory z wokalem. Ten generator muzyki AI został opracowany przez członków zespołu z renomowanych firm technologicznych, takich jak Meta, TikTok i Kensho, a jego celem jest niewymaganie żadnych instrumentów ani narzędzi, aby każdy mógł tworzyć piękną muzykę.

Poniżej przedstawiono postęp aktualizacji modeli:

| Wersja      | model           | Data wdrożenia | Limit lyric | Limit style | Maksymalna długość piosenki |
| ------- | --------------- | ---------- | -------- | -------- | ------ |
| v6      | chirp-v6        | 2026.09.09 | —        | —        | —      |
| v6 Wild | chirp-v6-wild   | 2026.09.09 | —        | —        | —      |
| v6 Mini | chirp-v6-mini   | 2026.09.09 | —        | —        | —      |

> Limity `lyric` i `style` w powyższej tabeli są górnymi limitami w trybie niestandardowym (gdy `custom` ma wartość `true`). W nieniestandardowym trybie inspiracji (gdy `custom` ma wartość `false`) należy wypełnić tylko `prompt`, którego limit długości wynosi 500 znaków (taki sam dla wszystkich modeli).

Suno obsługuje obecnie `chirp-v6`, `chirp-v6-wild` i `chirp-v6-mini`. Zaleca się używanie `chirp-v6`; nazwy starszych modeli nadal są kompatybilne.

Jednak Suno oficjalnie nie udostępnia API, AceDataCloud udostępnia zestaw API Suno, które symuluje integrację z oficjalnym Suno i może wygodnie oraz szybko generować pożądaną muzykę.

## Aplikowanie i używanie

Aby używać Suno Audios Generation API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token, i zachowaj go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany lub zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, która zaprosi cię do rejestracji i logowania, a po zakończeniu automatycznie wrócisz na bieżącą stronę.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, bez konieczności składania osobnego wniosku dla każdej usługi.** Przy pierwszym wniosku zostanie przyznany darmowy limit, umożliwiający bezpłatne wypróbowanie; gdy limit jest niewystarczający, możesz doładować wspólne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Podstawowe użycie

Jakie piosenki chcesz, możesz dowolnie wprowadzić fragment tekstu, na przykład jeśli chcę wygenerować piosenkę o Bożym Narodzeniu, mogę wprowadzić `a song for Christmas`, jak pokazano na ilustracji:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Można zobaczyć, że tutaj ustawiliśmy Request Headers, w tym:

- `accept`: format odpowiedzi, jaki chcesz otrzymać, tutaj wpisano `application/json`, czyli format JSON.
- `authorization`: klucz do wywoływania API, po złożeniu wniosku można go bezpośrednio wybrać z listy rozwijanej.

Dodatkowo ustawiono Request Body, w tym:
- `action`: działanie tego zadania generowania muzyki, domyślnie `generate`, obejmuje głównie: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`: podpowiedź trybu inspiracji Suno Official (obowiązuje, gdy `custom` ma wartość `false`), maksymalnie 500 znaków.
- `model`: model tego zadania generowania muzyki. Seria v6 obejmuje `chirp-v6`, `chirp-v6-wild` oraz `chirp-v6-mini`; nazwy starszych modeli nadal są kompatybilne.
- `lyric`: treść tekstu piosenki w trybie niestandardowym Suno Official. Maksymalnie 3000 znaków dla `chirp-v3-5` i `chirp-v4`; maksymalnie 5000 znaków dla `chirp-v4-5` i nowszych (w tym `chirp-v5`, `chirp-v5-5`).
- `custom`: czy używać trybu niestandardowego, domyślnie: `false`.
- `instrumental`: opcja muzyki instrumentalnej w trybie inspiracji Suno Official.
- `title`: tytuł muzyki w trybie niestandardowym Suno Official. Maksymalnie 80 znaków dla `chirp-v3-5`, `chirp-v4`; maksymalnie 100 znaków dla `chirp-v4-5` i nowszych.
- `style`: styl muzyczny w trybie niestandardowym Suno Official. Maksymalnie 200 znaków dla `chirp-v3-5` i `chirp-v4`; maksymalnie 1000 znaków dla `chirp-v4-5` i nowszych (w tym `chirp-v5`, `chirp-v5-5`).
- `negative_tags`: style muzyczne lub gatunki, które mają zostać wykluczone z wyników generowania w trybie niestandardowym (gdy `custom` ma wartość `true`).
- `audio_weight`: udział przesłanego referencyjnego audio, zakres 0–1; im większa wartość, tym większa zależność od referencyjnego audio.
- `audio_id`: ID referencyjnej muzyki.
- `overpainting_start`/`overpainting_end`: czas rozpoczęcia/zakończenia dodawania wokalu do istniejącej muzyki instrumentalnej, w sekundach.
- `underpainting_start`/`underpainting_end`: czas rozpoczęcia/zakończenia dodawania akompaniamentu do śpiewu a cappella, w sekundach.
- `persona_id`: ID piosenki artysty.
- `continue_at`: granica kontynuacji, w sekundach. Na przykład 213.5 oznacza rozpoczęcie generowania kolejnego fragmentu od 3 minuty i 33.5 sekundy. `lyric` i `style` prowadzą tylko nową treść po granicy i nie zastępują tekstu ani śpiewu przed granicą w źródłowym audio.
- `style_influence`: zaawansowany parametr „Style Influence” w trybie niestandardowym, zakres 0–1; im większa wartość, tym lepiej dopasowuje się do wybranego stylu.
- `replace_section_end`: końcowy czas zastępowanego fragmentu.
- `replace_section_start`: początkowy czas zastępowanego fragmentu.
- `vocal_gender`: kontroluje preferencję głosu żeńskiego lub męskiego, głos żeński `f`, głos męski `m`; działa dla modeli 4.5 i nowszych; jest to opcja preferencji i nie gwarantuje ścisłego przestrzegania.
- `weirdness`: zaawansowany parametr „Weirdness” w trybie niestandardowym, zakres 0–1; im większa wartość, tym bardziej kreatywny i eksperymentalny rezultat.
- `duration`: oczekiwana długość piosenki, w sekundach, musi być liczbą całkowitą, zakres wartości od 10 do 360. Ten parametr jest używany do generowania piosenek w trybie niestandardowym (gdy `custom` ma wartość `true`). Jest to wskazówka preferencyjna, a nie twarde ograniczenie: model uwzględni ją, ale nie gwarantuje jej osiągnięcia; rzeczywista długość gotowego utworu zależy od pola `duration` w odpowiedzi i zazwyczaj jest krótsza od oczekiwanej wartości.
- `lyric_prompt`: prompt do generowania tekstu piosenki, obowiązuje wtedy i tylko wtedy, gdy `custom` ma wartość `true` i `lyric` nie został przekazany.
- `callback_url`: URL, na który mają zostać przesłane wyniki zwrotne.
- `async`: opcjonalne; gdy ustawione na `true`, interfejs natychmiast zwraca `task_id`, bez potrzeby podawania `callback_url`, a następnie wynik można uzyskać przez odpytywanie odpowiedniego interfejsu zapytania o zadanie.

## Generowanie niestandardowe

Jeśli chcesz niestandardowo wygenerować tekst piosenki, możesz wprowadzić tekst:

W tym momencie do pola `lyric` można przekazać treść podobną do poniższej:

```
[Verse]\nSnowflakes falling all around\nGlistening white\nCovering the ground\nChildren laughing\nFull of delight\nIn this winter wonderland tonight\nSanta's sleigh\nUp in the sky\nRudolph's nose shining bright\nOh my\nHear the jingle bells\nRinging so clear\nBringing joy and holiday cheer\n[Verse 2]\nRoasting chestnuts by the fire's glow\nChristmas lights\nThey twinkle and show\nFamilies gathering with love and cheer\nSpreading warmth to everyone near
```

> Uwaga, `\n` w tekście piosenki tutaj oznacza znak nowej linii. Jeśli nie wiesz, jak generować tekst piosenki, możesz użyć API generowania tekstów dostarczanego przez AceDataCloud, aby generować teksty za pomocą promptu; API to [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Następnie, aby niestandardowo wygenerować utwór na podstawie tekstu, tytułu i stylu, można określić następującą treść:

- lyric：tekst piosenki
- custom：ustaw na `true`, co oznacza generowanie niestandardowe; domyślna wartość tego parametru to false, co oznacza generowanie przy użyciu `prompt`.
- title：tytuł utworu.
- style：styl utworu, opcjonalnie.

Przykład wypełnienia jest następujący:

## Funkcja generowania niestandardowego stylu wokalisty
Jeśli chcesz użyć stylu piosenkarza do generowania piosenek, najpierw wygeneruj piosenkę poprzez podstawowe użycie opisane powyżej,
a następnie należy ustawić tę piosenkę jako styl piosenkarza. Następnie należy wejść do [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona), aby na podstawie oficjalnie wygenerowanego identyfikatora muzyki `audio_id` wygenerować parametr ID stylu piosenkarza `persona_id`. Konkretne parametry przedstawiono na poniższym obrazie:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

Po wypełnieniu automatycznie generowany jest następujący kod:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Funkcja kontynuowania generowania

Jeśli chcesz kontynuować generowanie już wygenerowanej piosenki Suno, możesz ustawić parametr `action` na `extend` oraz wprowadzić ID piosenki, która ma być dalej generowana. ID piosenki uzyskuje się na podstawie podstawowego użycia. Z powyższego wynika, że w tym momencie można zobaczyć, że ID piosenki wynosi:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Uwaga: `id` w tekście piosenki tutaj jest ID piosenki po jej wygenerowaniu. Jeśli nie wiesz, jak wygenerować piosenkę, możesz odnieść się do podstawowego użycia powyżej, aby wygenerować piosenkę.

Jeśli chcesz kontynuować generowanie piosenki przesłanej przez siebie, możesz ustawić parametr `action` na `upload_extend` oraz wprowadzić ID niestandardowo przesłanej piosenki, która ma być dalej generowana. ID piosenki uzyskuje się za pomocą [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), jak pokazano na poniższym obrazie:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Następnie należy wypełnić tekst utworu dla kontynuowanego fragmentu oraz można określić styl:

- lyric: używane wyłącznie do kierowania tekstem nowo wygenerowanego fragmentu po `continue_at`; nie zastąpi tekstu w źródłowym audio przed tym punktem czasowym.
- custom: ustawienie na `true` oznacza generowanie niestandardowe; domyślna wartość tego parametru to false, co oznacza generowanie przy użyciu `prompt`.
- style: styl piosenki dla kontynuowanego fragmentu, opcjonalnie.
- continue_at: granica kontynuacji, w sekundach. Na przykład 213.5 oznacza rozpoczęcie generowania kolejnego fragmentu od 3 minut i 33,5 sekundy.

> `extend` służy do dalszego tworzenia na podstawie istniejącej piosenki, a nie do zmiany tekstu całej piosenki. Jeśli chcesz użyć nowego tekstu od początku dla całej piosenki, użyj `generate`, aby wygenerować ją ponownie; jeśli chcesz ponownie zinterpretować piosenkę na podstawie istniejącej piosenki, możesz użyć `cover`. W przypadku przekazania całego nowego tekstu oryginalny tekst przed `continue_at` nadal nie zostanie zastąpiony.

## Zastępowanie fragmentu

Gdy po wygenerowaniu utworu potrzebna jest wtórna twórczość polegająca na osobnym zastąpieniu fragmentu utworu, można wykonać operację zastąpienia określonego fragmentu utworu.

> ⚠️ **Uwaga**：`replace_section_result_mode` domyślnie ma wartość `full_song`：system osobno scala 2 nowo wygenerowane kandydatury i zwraca 2 pełne utwory. Jeśli potrzebujesz wyłącznie kandydatur zastępowanych fragmentów, które nie zostały jeszcze scalone, jawnie ustaw wartość na `candidates`, a następnie wybierz kandydaturę i wywołaj [scalanie utworów](#音乐拼接)。

Opis parametrów jest następujący:

- action：wartość to `replace_section`。
- audio_id：ID oryginalnego utworu (źródłowego utworu, który jest zastępowany)。
- model: Model generowania utworu。
- lyric: Pełny tekst po zastąpieniu (w tym zastępowany fragment i jego kontekst, zgodny z treścią w `prompt`)。
- prompt：Nowy tekst dla fragmentu, który ma zostać zastąpiony。
- style：Styl utworu, opcjonalny。
- replace_section_start：Czas rozpoczęcia zastępowanego fragmentu w oryginalnym utworze (sekundy)。
- replace_section_end：Czas zakończenia zastępowanego fragmentu w oryginalnym utworze (sekundy)。
- replace_section_result_mode：Tryb zwracania, domyślnie `full_song`。`full_song` osobno scala 2 kandydatury i zwraca 2 pełne utwory；`candidates` zwraca 2 niescalone jeszcze kandydatury fragmentów。

## Separacja wokalu i muzyki

Gdy po wygenerowaniu utworu konieczne jest przeprowadzenie wtórnej twórczości obejmującej osobne operacje na akompaniamencie i wokalu, można rozdzielić czysty akompaniament instrumentalny i wokal a cappella. Można wtedy określić następującą zawartość:

- action：wartość to `stems`。

import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {

response = requests.post(url, json=payload, headers=headers)

## Kontrolowanie długości piosenki

Domyślnie długość generowanej piosenki jest określana przez model, zazwyczaj wynosi od 30 sekund do 4 minut. Jeśli potrzebny jest dłuższy lub krótszy gotowy utwór, można określić oczekiwaną długość za pomocą parametru `duration`, którego jednostką są sekundy, a wartością liczba całkowita od 10 do 360.

Ten parametr służy do generowania piosenek w trybie niestandardowym (`custom` ma wartość `true`). Należy szczególnie wyjaśnić, że `duration` jest **wskazówką preferencji, a nie sztywnym ograniczeniem**: model będzie odwoływał się do tej wartości podczas tworzenia, ale nie gwarantuje jej osiągnięcia; w testach rzeczywista długość jest zwykle wyraźnie krótsza od oczekiwanej, a długości dwóch piosenek zwróconych w tym samym żądaniu mogą również różnić się wielokrotnie. Nawet w przypadku całkowicie identycznych żądań długości uzyskane po wielokrotnym przesłaniu mogą znacznie się różnić. Dlatego nie należy używać go jako precyzyjnej kontroli długości; jeśli w zastosowaniu biznesowym potrzebna jest stała długość, po uzyskaniu gotowego utworu należy samodzielnie go przyciąć lub ponowić próbę.

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Należy zwrócić uwagę, że `duration` w żądaniu to **oczekiwana długość**, natomiast pole `duration` każdej piosenki w odpowiedzi `data` to **rzeczywista długość** tej piosenki. Obie nazwy są takie same, ale ich znaczenie jest inne; rzeczywista długość nie jest gwarantowana jako równa wartości oczekiwanej. Długość tekstu piosenki jest jednym z głównych czynników wpływających na długość gotowego utworu; jeśli potrzebny jest dłuższy gotowy utwór, zaleca się jednoczesne podanie pełniejszego tekstu.

Interfejs nie przeprowadza dodatkowej walidacji `duration`, a parametr jest przekazywany do modelu w niezmienionej postaci. Jeśli zostanie przekazana wartość nieobsługiwana przez bieżący tryb lub model, może to skutkować zignorowaniem tej wartości; zaleca się najpierw potwierdzić efekt jednym żądaniem, a następnie używać go zbiorczo.

## Funkcja tworzenia inspirowanego Inspo

Funkcja tworzenia inspirowanego Inspo może generować nową muzykę na podstawie od 1 do 4 pełnych referencyjnych nagrań audio oraz obsługuje przeciąganie lub przesyłanie plików audio jako źródeł inspiracji. API używa istniejącej akcji `inspo`: klient udostępnia publicznie dostępne adresy URL audio, a usługa automatycznie przygotowuje referencyjne nagrania audio i tworzy utwór, bez potrzeby osobnego odczytywania przez klienta tekstu, stylu lub czasu trwania, a następnie składania żądania. Różni się to zarówno od opisanego powyżej próbkowania zakresu, jak i od Cover odtwarzającego styl oryginalnego utworu. Podczas użycia należy wypełnić następujące parametry:

- action: wartość to `inspo`.
- audio_urls: lista adresów URL referencyjnych nagrań audio; należy podać od 1 do 4 publicznie dostępnych adresów audio.
- model: używany model, zalecany jest `chirp-v6`.
- prompt: tekst piosenki lub podpowiedź twórcza (opcjonalnie).

> Uwaga: referencyjne nagrania audio muszą być publicznie dostępnymi plikami audio. Jeśli referencyjne nagranie audio idealnie pasuje do znanego nagrania w bibliotece utworów platformy, Suno może odmówić generowania z powodu weryfikacji praw autorskich; zaleca się używanie własnych nagrań audio lub nagrań wygenerowanych przez Suno jako źródła inspiracji.

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v6",
    "audio_urls": [
        "https://cdn.acedata.cloud/uploads/a0bc051f-42c2-4a46-aeb4-582dcc884ad2"
    ],
    "prompt": "Rework these references as warm acoustic folk with soft vocals"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynchroniczne wywołanie zwrotne

Ponieważ generowanie muzyki przez Suno zajmuje stosunkowo dużo czasu, około 1–2 minut, jeśli API przez długi czas nie odpowiada, żądanie HTTP będzie stale utrzymywać połączenie, co prowadzi do dodatkowego zużycia zasobów systemowych, dlatego to API również oferuje obsługę asynchronicznych wywołań zwrotnych.

Ogólny proces wygląda następująco: gdy klient inicjuje żądanie, dodatkowo określa pole `callback_url`; po wysłaniu przez klienta żądania API, API natychmiast zwróci wynik zawierający informację w polu `task_id`, reprezentującym ID bieżącego zadania. Po ukończeniu zadania wynik generowania muzyki zostanie wysłany metodą POST w formacie JSON do `callback_url` określonego przez klienta, gdzie również zawarte będzie pole `task_id`, dzięki czemu wynik zadania można powiązać za pomocą ID.

Poniżej, na przykładzie, zobaczymy, jak konkretnie to zrobić.
