Wraz z rosnącym zastosowaniem AI, różne programy AI stały się coraz bardziej powszechne. AI stopniowo przenika do wszystkich aspektów życia i pracy ludzi. Branże związane z AI również się mnożą, od początkowego pisania, przez medycynę i edukację, aż po muzykę.

Suno to profesjonalna platforma do tworzenia wysokiej jakości piosenek i muzyki AI, gdzie użytkownicy muszą jedynie wprowadzić proste tekstowe wskazówki, aby wygenerować piosenki z wokalem w zależności od stylu gatunku i tekstu. Ten generator muzyki AI został opracowany przez członków zespołu z renomowanych firm technologicznych, takich jak Meta, TikTok, Kensho, a jego celem jest umożliwienie każdemu tworzenia wspaniałej muzyki bez potrzeby posiadania instrumentów.

Oto postęp aktualizacji modelu:

| Wersja | model           | Data uruchomienia | ograniczenie tekstu | ograniczenie stylu | maksymalny czas trwania piosenki |
| ------ | --------------- | ----------------- | ------------------- | ------------------ | ------------------------------- |
| v5.5   | chirp-v5-5      | 2026.03.27        | 5000                | 1000               | 8 minut                        |
| v5     | chirp-v5        | 2025.09.23        | 5000                | 1000               | 8 minut                        |
| v4.5+  | chirp-v4-5-plus | 2025.07.17        | 5000                | 1000               | 8 minut                        |
| v4.5   | chirp-v4-5      | 2025.05.03        | 5000                | 1000               | 4 minuty                       |
| v4     | chirp-v4        | 2024.12.17        | 3000                | 200                | 150 sekund                     |
| v3.5   | chirp-v3-5      | ---               | 3000                | 200                | 120 sekund                     |

> Ograniczenia `lyric` i `style` w powyższej tabeli są maksymalnymi wartościami w trybie dostosowanym (`custom` ustawione na `true`). W trybie inspiracyjnym, który nie jest dostosowany (`custom` ustawione na `false`), wystarczy wypełnić `prompt`, którego maksymalna długość wynosi 500 znaków (wszystkie modele są zgodne).

Suno obecnie obsługuje najnowszy model `chirp-v5-5`. Aby wywołać najnowszą wersję, wystarczy ustawić parametr `model` na `chirp-v5-5`; `chirp-v5` oraz wcześniejsze wersje nadal mogą być używane.

Jednak Suno oficjalnie nie udostępnia API, AceDataCloud oferuje zestaw API Suno, który symuluje integrację z oficjalnym Suno, co umożliwia szybkie i łatwe generowanie pożądanej muzyki.

## Aplikacja i użycie

Aby korzystać z API Generacji Dźwięku Suno, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do wywołania wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Pierwsze zgłoszenie daje darmowy limit, który można wykorzystać; w przypadku niewystarczającego limitu można doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [API Generacji Dźwięku Suno →](https://platform.acedata.cloud/documents/suno-audios)

## Podstawowe użycie

Czegoś chcesz w piosenkach, możesz dowolnie wpisać fragment tekstu, na przykład, jeśli chcę wygenerować piosenkę o tematyce świątecznej, mogę wpisać `a song for Christmas`, jak pokazano na obrazku:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Można zauważyć, że tutaj ustawiliśmy nagłówki żądania, w tym:

- `accept`: jakiego formatu odpowiedzi oczekujesz, tutaj wpisano `application/json`, czyli format JSON.
- `authorization`: klucz do wywołania API, po złożeniu wniosku można go bezpośrednio wybrać z rozwijanej listy.

Dodatkowo ustawiono ciało żądania, w tym:
- `action`：Zachowanie w tym zadaniu generowania muzyki, domyślnie `generate`, głównie obejmuje: `extend`, `upload_extend`, `cover`, `upload_cover`, `replace_section`, `replace_section`, `concat`, `stems`, `all_stems`, `remaster`.
- `prompt`：Oficjalny prompt inspiracyjny Suno (działa, gdy `custom` jest `false`), maksymalnie 500 znaków.
- `model`：Model w tym zadaniu generowania muzyki, domyślnie `chirp-v4`, głównie obejmuje: `chirp-v3`, `chirp-v4`, `chirp-v3-5`, `chirp-v4-5`, `chirp-v4-5-plus`, `chirp-v5`, `chirp-v5-5`.
- `lyric`：Treść tekstu piosenki w trybie dostosowanym Suno. `chirp-v3-5` i `chirp-v4` maksymalnie 3000 znaków; `chirp-v4-5` i wyżej (w tym `chirp-v5`, `chirp-v5-5`) maksymalnie 5000 znaków.
- `custom`：Czy używać trybu dostosowanego, domyślnie: `false`.
- `instrumental`：Opcja czystej muzyki w trybie inspiracyjnym Suno.
- `title`：Tytuł muzyki w trybie dostosowanym Suno. `chirp-v3-5`, `chirp-v4` maksymalnie 80 znaków; `chirp-v4-5` i wyżej maksymalnie 100 znaków.
- `style`：Styl muzyki w trybie dostosowanym Suno. `chirp-v3-5` i `chirp-v4` maksymalnie 200 znaków; `chirp-v4-5` i wyżej (w tym `chirp-v5`, `chirp-v5-5`) maksymalnie 1000 znaków.
- `negative_tags`：Style muzyczne lub gatunki, które chcemy wykluczyć z wyników generacji w trybie dostosowanym (`custom` jest `true`).
- `audio_weight`：Proporcja przesłanego referencyjnego audio, zakres 0-1, im większa, tym większa zależność od referencyjnego audio.
- `audio_id`：ID referencyjnej muzyki.
- `overpainting_start`/`overpainting_end`：Czas rozpoczęcia i zakończenia dodawania wokalu do istniejącej czystej muzyki, jednostka sekundy.
- `underpainting_start`/`underpainting_end`：Czas rozpoczęcia i zakończenia dodawania akompaniamentu do czystego śpiewu, jednostka sekundy.
- `persona_id`：ID piosenki artysty.
- `continue_at`：Granica kontynuacji, jednostka sekundy. Na przykład, 213.5 oznacza, że generowanie kolejnych fragmentów zaczyna się od 3 minuty 33.5 sekundy. `lyric` i `style` tylko kierują nową treścią po granicy, nie zastępują tekstu lub wykonania przed granicą w źródłowym audio.
- `style_influence`：Zaawansowany parametr „Style Influence” w trybie dostosowanym, zakres 0-1, im większy, tym bardziej zbliżony do wybranego stylu.
- `replace_section_end`：Ostateczny czas zastąpienia fragmentu.
- `replace_section_start`：Czas rozpoczęcia zastąpienia fragmentu.
- `vocal_gender`：Kontrola preferencji głosu męskiego lub żeńskiego, głos żeński `f`, głos męski `m`, skuteczne w modelach 4.5 i wyższych; jest to preferencja, nie gwarantuje ścisłego przestrzegania.
- `weirdness`：Zaawansowany parametr „Weirdness” w trybie dostosowanym, zakres 0-1, im większy, tym bardziej kreatywny i eksperymentalny.
- `duration`：Oczekiwana długość piosenki, jednostka sekundy, musi być liczbą całkowitą, zakres 10 do 360. Parametr ten jest używany do generowania piosenek w trybie dostosowanym (`custom` jest `true`). Jest to sugestia, a nie twarde ograniczenie: model weźmie to pod uwagę, ale nie gwarantuje osiągnięcia, rzeczywista długość produktu końcowego będzie zgodna z polem `duration` w odpowiedzi, zazwyczaj krótsza od oczekiwanej wartości.
- `lyric_prompt`：Prompt do generowania tekstu piosenki, działa tylko wtedy, gdy `custom` jest `true` i `lyric` nie jest przekazany.
- `callback_url`：URL, na który należy zwrócić wyniki.
- `async`：Opcjonalne, ustawione na `true`, interfejs natychmiast zwraca `task_id`, nie ma potrzeby podawania `callback_url`, następnie wyniki można uzyskać poprzez odpowiedni interfejs zapytań o zadania.

## Niestandardowa generacja

Jeśli chcesz niestandardowo wygenerować tekst, możesz wpisać tekst:

W tym momencie pole `lyric` może przyjąć podobną treść jak poniżej:

```
[Zwrotka]\nPłatki śniegu spadają wszędzie\nBłyszcząca biel\nPokrywająca ziemię\nDzieci śmieją się\nPełne radości\nW tej zimowej krainie czarów tej nocy\nSanie Świętego Mikołaja\nW niebie\nNos Rudolfa świeci jasno\nO mój\nSłyszy dzwonki\nDzwonią tak wyraźnie\nPrzynosząc radość i świąteczną radość\n[Zwrotka 2]\nPieczenie kasztanów przy blasku ognia\nŚwiąteczne światła\nMigoczą i pokazują\nRodziny zbierają się z miłością i radością\nRozprzestrzeniając ciepło na wszystkich w pobliżu
```

> Uwaga, w tym tekście `\n` to znak nowej linii, jeśli nie wiesz, jak wygenerować tekst, możesz skorzystać z API generacji tekstu AceDataCloud, aby wygenerować tekst za pomocą promptu, API to [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Następnie, aby dostosować generację piosenki na podstawie tekstu, tytułu i stylu, możesz określić następujące treści:

- lyric: tekst piosenki
- custom: wpisz `true`, co oznacza niestandardową generację, ten parametr domyślnie jest ustawiony na false, co oznacza użycie promptu do generacji.
- title: tytuł piosenki.
- style: styl piosenki, opcjonalnie.

## Funkcja niestandardowego stylu piosenki
如果 chcesz użyć stylu piosenkarza do generowania utworów, najpierw za pomocą podstawowego użycia z powyższego tekstu wygeneruj piosenkę, a następnie ustaw tę piosenkę na styl piosenkarza. Następnie musisz wejść do [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) i na podstawie oficjalnie wygenerowanego identyfikatora muzycznego `audio_id` wygenerować parametr identyfikatora stylu piosenkarza `persona_id`, szczegółowe parametry przedstawione są na poniższym obrazku:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

Po wypełnieniu automatycznie wygenerowano poniższy kod:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Po kliknięciu uruchomienia można zauważyć, że otrzymuje się wynik, jak poniżej:

```json

```

Używając powyższych `audio_id` i `persona_id`, odpowiednio `97efc9f4-0e8d-4b3e-88df-14568fa1b11f` oraz `e0d7319e-aa2a-44cb-b00a-916218d7cb0b`, jako dane przykładowe. Następnie można ustawić parametr `action` na `artist_consistency` (jeśli jest to nowa wersja stylu piosenkarza Persona-v2-vox, `action` musi być ustawione na `artist_consistency_vox`), a także wprowadzić identyfikator piosenki, który należy kontynuować, oraz identyfikator stylu piosenkarza, przykładowe wypełnienie wygląda następująco:

<p><img src="https://cdn.acedata.cloud/fukijq.png" width="500" className="m-auto" /></p>

Po wypełnieniu automatycznie wygenerowano poniższy kod:

<p><img src="https://cdn.acedata.cloud/5uzk9d.png" width="500" className="m-auto" /></p>

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "artist_consistency",
    "prompt": "A song for Christmas",
    "model": "chirp-v4-5",
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Funkcja kontynuacji

Jeśli chcesz kontynuować generowanie już wygenerowanej piosenki Suno, możesz ustawić parametr `action` na `extend`, a także wprowadzić identyfikator piosenki, którą chcesz kontynuować. Identyfikator piosenki można uzyskać na podstawie podstawowego użycia, jak wynika z powyższego tekstu, w tym momencie można zobaczyć, że identyfikator piosenki to:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Uwaga, tutaj w tekście `id` jest identyfikatorem wygenerowanej piosenki. Jeśli nie wiesz, jak wygenerować piosenkę, możesz odwołać się do powyższego tekstu, aby wygenerować piosenkę.

Jeśli chcesz kontynuować generowanie piosenki, którą sam przesłałeś, możesz ustawić parametr `action` na `upload_extend`, a także wprowadzić identyfikator piosenki, którą chcesz kontynuować. Identyfikator piosenki można uzyskać za pomocą [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), jak pokazano na poniższym obrazku:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

Następnie musisz wypełnić tekst kontynuacji i możesz określić styl:

- lyric: służy tylko do prowadzenia nowego fragmentu tekstu generowanego po `continue_at`, nie zastąpi tekstu źródłowego przed tym punktem czasowym.
- custom: ustaw na `true`, co oznacza, że generowanie jest dostosowane, ten parametr domyślnie jest ustawiony na false, co oznacza, że używa `prompt` do generowania.
- style: styl piosenki fragmentu kontynuacji, opcjonalne.
- continue_at: granica kontynuacji, jednostka w sekundach. Na przykład, 213.5 oznacza, że generowanie kolejnego fragmentu zaczyna się od 3 minut 33.5 sekundy.

> `extend` służy do kontynuowania istniejącej piosenki, a nie do zmiany słów całej piosenki. Jeśli chcesz, aby cała piosenka była od nowa z nowymi tekstami, użyj `generate`, aby ponownie wygenerować; jeśli chcesz, aby na podstawie istniejącej piosenki stworzyć nową interpretację, możesz użyć `cover`. Przekazując cały nowy tekst piosenki, oryginalny tekst przed `continue_at` nadal nie zostanie zastąpiony.

## Muzyczne przeróbki

- action: treść to `cover`, gdy jest to operacja przeróbki na przesłanej przez użytkownika muzyce, musisz określić treść jako: `upload_cover`.

## Zastępowanie fragmentów

Gdy po wygenerowaniu piosenki potrzebujesz przeprowadzić operację zastąpienia fragmentu piosenki w ramach drugiej twórczości, możesz zastąpić dany fragment piosenki.

> ⚠️ **Uwaga**: `replace_section_result_mode` domyślnie to `full_song`: system połączy 2 nowe wygenerowane kandydatury i zwróci 2 pełne piosenki. Jeśli potrzebujesz tylko niepołączonych kandydatur fragmentów do zastąpienia, wyraźnie ustaw na `candidates`, a następnie wybierz kandydatury do wywołania [muzycznego łączenia](#muzyczne-łączenie).

Opis parametrów jest następujący:

- action: treść to `replace_section`.
- audio_id: ID oryginalnej piosenki (źródłowej piosenki, która ma być zastąpiona).
- model: model generowania piosenek.
- lyric: pełny tekst piosenki po zastąpieniu (zawiera zastąpiony fragment oraz jego kontekst, zgodny z treścią w `prompt`).
- prompt: nowy tekst piosenki, który ma być zastąpiony.
- style: styl piosenki, opcjonalne.
- replace_section_start: czas rozpoczęcia zastępowanego fragmentu w oryginalnej piosence (sekundy).
- replace_section_end: czas zakończenia zastępowanego fragmentu w oryginalnej piosence (sekundy).
- replace_section_result_mode: tryb zwracania, domyślnie to `full_song`. `full_song` łączy 2 kandydatury i zwraca 2 pełne piosenki; `candidates` zwraca 2 niepołączone kandydatury fragmentów.

## Kontrola długości piosenki

Domyślnie długość generowanej piosenki jest określana przez model, zazwyczaj w zakresie od 30 sekund do 4 minut. Jeśli potrzebujesz dłuższego lub krótszego utworu, możesz określić oczekiwaną długość za pomocą parametru `duration`, jednostka to sekundy, a wartość to całkowita liczba z zakresu od 10 do 360.

Ten parametr jest używany do generacji piosenek w trybie niestandardowym (`custom` jest `true`). Należy szczególnie zaznaczyć, że `duration` jest **wskazówką preferencyjną, a nie sztywnym ograniczeniem**: model podczas tworzenia będzie odnosił się do tej wartości, ale nie gwarantuje jej osiągnięcia, w praktyce rzeczywista długość jest zazwyczaj znacznie krótsza od oczekiwanej, a długości dwóch piosenek zwróconych w tej samej prośbie mogą się różnić wielokrotnie. Nawet w przypadku identycznych próśb, wielokrotne przesyłanie może prowadzić do znacznych różnic w długości. Dlatego nie należy traktować tego jako precyzyjnej kontroli długości, jeśli w biznesie wymagana jest stała długość, należy samodzielnie przyciąć lub spróbować ponownie po otrzymaniu gotowego utworu.

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Pod Światłami Miasta",
    "style": "lo-fi piano",
    "lyric": "[Zwrotka]\nWschód słońca\nZłoto na podłodze\n[Refren]\nPod światłami miasta\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Należy zauważyć, że `duration` w żądaniu to **oczekiwana długość**, a pole `duration` w odpowiedzi `data` dla każdej piosenki to **rzeczywista długość** tej piosenki. Obie nazwy są takie same, ale mają różne znaczenia, rzeczywista długość nie jest gwarantowana jako równa wartości oczekiwanej. Długość tekstu piosenki jest jednym z głównych czynników wpływających na długość gotowego utworu, jeśli potrzebujesz dłuższego utworu, zaleca się jednoczesne dostarczenie bardziej kompletnych tekstów.

Interfejs nie przeprowadza dodatkowej weryfikacji `duration`, parametry są przekazywane do modelu w oryginalnej formie. Jeśli wprowadzono wartość, która nie jest obsługiwana przez bieżący tryb lub model, może to skutkować zignorowaniem tej wartości, zaleca się najpierw użycie jednego żądania, aby potwierdzić efekt, a następnie użycie go masowo.

## Funkcja Inspo

Nowa funkcja Inspo w Suno może generować całkowicie nową muzykę na podstawie 1 do 4 fragmentów audio jako źródła inspiracji. W przeciwieństwie do coverów, Inspo nie odtwarza oryginalnej piosenki, lecz wydobywa inspirację ze stylu referencyjnych nagrań, a następnie łączy je z podpowiedziami, tagami stylu itp., aby stworzyć nowe dzieło. Podczas korzystania z niej należy wypełnić następujące parametry:

- action: zawartość to `inspo`.
- audio_urls: lista URL referencyjnych nagrań audio, należy podać od 1 do 4 publicznie dostępnych adresów audio.
- model: używany model, na przykład `chirp-v5`.
- prompt: tekst piosenki lub wskazówki twórcze (opcjonalne).
- tags: tagi stylu muzycznego, na przykład `akustyczny, folk, ciepły` (opcjonalne).
- title: tytuł piosenki (opcjonalne).
- audio_weight: waga wpływu referencyjnych nagrań na wynik generacji, zakres wartości od 0 do 1 (opcjonalne).

> Uwagi: Referencyjne nagrania muszą być publicznie dostępnymi plikami audio. Jeśli referencyjne nagranie całkowicie odpowiada znanemu nagraniu w bibliotece platformy, Suno może odmówić generacji z powodu weryfikacji praw autorskich, zaleca się użycie własnych lub nagrań stworzonych przez Suno jako źródła inspiracji.

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "ciepły akustyczny folk z delikatnymi wokalami",
    "tags": "akustyczny, folk, ciepły",
    "title": "Demo Inspo",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynchroniczny callback

Ponieważ czas generowania muzyki przez Suno jest stosunkowo długi, wynosi około 1-2 minut, jeśli API nie odpowiada przez dłuższy czas, żądanie HTTP będzie utrzymywać połączenie, co prowadzi do dodatkowego zużycia zasobów systemowych, dlatego to API oferuje również wsparcie dla asynchronicznych callbacków.

Cały proces wygląda następująco: gdy klient wysyła żądanie, dodatkowo określa pole `callback_url`, po wysłaniu żądania API natychmiast zwraca wynik, zawierający informację o polu `task_id`, które reprezentuje aktualne ID zadania. Po zakończeniu zadania, wynik generowania muzyki zostanie wysłany do określonego przez klienta `callback_url` w formie POST JSON, w którym również znajduje się pole `task_id`, dzięki czemu wyniki zadania można powiązać za pomocą ID.
