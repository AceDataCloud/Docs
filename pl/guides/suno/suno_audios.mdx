Wraz z coraz szerszym zastosowaniem AI różnego rodzaju programy AI stopniowo zyskują popularność. AI coraz bardziej przenika do różnych aspektów pracy i życia ludzi. Branże, w których wykorzystywane jest AI, również stają się coraz liczniejsze — od początkowego pisania tekstów, przez medycynę i edukację, aż po obecną muzykę.

Suno to profesjonalna platforma do tworzenia wysokiej jakości piosenek i muzyki z wykorzystaniem AI. Użytkownicy muszą jedynie wprowadzić proste wskazówki tekstowe, aby wygenerować utwory z wokalem na podstawie gatunku, stylu i tekstu piosenki. Ten generator muzyki AI został opracowany przez członków zespołu pochodzących ze znanych firm technologicznych, takich jak Meta, TikTok i Kensho. Jego celem jest umożliwienie każdemu tworzenia pięknej muzyki bez potrzeby korzystania z jakichkolwiek instrumentów.

Poniżej znajduje się postęp aktualizacji modeli:

| v5    | chirp-v5        | 2025.09.23 | 5000     | 1000     | 8 minut   |

| v3.5  | chirp-v3-5      | ---        | 3000     | 200      | 120 sekund  |

> Ograniczenia `lyric` i `style` w powyższej tabeli dotyczą limitów w trybie niestandardowym (`custom` ustawione na `true`). W przypadku trybu inspiracji bez personalizacji (`custom` ustawione na `false`) wystarczy uzupełnić tylko `prompt`, a maksymalna długość wynosi 500 znaków (dla wszystkich modeli jest taka sama).

Suno obecnie obsługuje najnowszy model `chirp-v5-5`. Podczas wywoływania najnowszej wersji wystarczy ustawić parametr `model` na `chirp-v5-5`; wersja `chirp-v5` oraz wcześniejsze wersje nadal mogą być używane.

Jednak oficjalne Suno nie udostępnia API. AceDataCloud zapewnia zestaw API Suno, który symuluje integrację z oficjalnym Suno, umożliwiając szybkie i wygodne generowanie pożądanej muzyki.

## Uzyskanie dostępu i użycie

Aby korzystać z Suno Audios Generation API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go do późniejszego użycia.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Jeśli nie jesteś jeszcze zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania z zaproszeniem do rejestracji i logowania. Po zakończeniu proces automatycznie powróci do bieżącej strony.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, bez konieczności składania osobnych wniosków dla każdej usługi.** Przy pierwszym zgłoszeniu zostanie przyznany darmowy limit, dzięki czemu można bezpłatnie przetestować usługę; gdy limit będzie niewystarczający, można doładować uniwersalne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Suno Audios Generation API →](https://platform.acedata.cloud/documents/suno-audios)

## Podstawowe użycie

Możesz wpisać dowolny tekst dotyczący utworu, który chcesz stworzyć. Na przykład, jeśli chcę wygenerować piosenkę o Bożym Narodzeniu, mogę wpisać `a song for Christmas`, jak pokazano na rysunku:

<p><img src="https://cdn.acedata.cloud/2kuuup.png" width="500" className="m-auto" /></p>

Można zauważyć, że tutaj ustawiliśmy Request Headers, które obejmują:

- `accept`: jaki format odpowiedzi chcemy otrzymać; tutaj wpisujemy `application/json`, czyli format JSON.
- `authorization`: klucz używany do wywoływania API, który po uzyskaniu dostępu można bezpośrednio wybrać z listy rozwijanej.

Dodatkowo ustawiliśmy Request Body, które obejmuje:
- `action`：Zachowanie w tym zadaniu generowania muzyki, domyślnie `generate`, głównie obejmuje: `extend`、`upload_extend`、`cover`、`upload_cover`、`replace_section`、`replace_section`、`concat`、`stems`、`all_stems`、`remaster`。
- `prompt`：Oficjalny tekst inspiracyjny Suno (działa, gdy `custom` jest `false`), maksymalnie 500 znaków.
- `model`：Model w tym zadaniu generowania muzyki, domyślnie `chirp-v4`, głównie obejmuje: `chirp-v3`、`chirp-v4`、`chirp-v3-5`、`chirp-v4-5`、`chirp-v4-5-plus`、`chirp-v5`、`chirp-v5-5`。
- `lyric`：Treść tekstu piosenki w trybie dostosowanym Suno. `chirp-v3-5` i `chirp-v4` maksymalnie 3000 znaków; `chirp-v4-5` i wyżej (w tym `chirp-v5`、`chirp-v5-5`) maksymalnie 5000 znaków.
- `custom`：Czy używać trybu dostosowanego, domyślnie: `false`。
- `instrumental`：Opcja czystej muzyki w trybie inspiracyjnym Suno.
- `title`：Tytuł muzyki w trybie dostosowanym Suno. `chirp-v3-5`、`chirp-v4` maksymalnie 80 znaków; `chirp-v4-5` i wyżej maksymalnie 100 znaków.
- `style`：Styl muzyki w trybie dostosowanym Suno. `chirp-v3-5` i `chirp-v4` maksymalnie 200 znaków; `chirp-v4-5` i wyżej (w tym `chirp-v5`、`chirp-v5-5`) maksymalnie 1000 znaków.
- `style_negative`：Wykluczający styl w trybie dostosowanym Suno.
- `audio_weight`：Proporcja przesłanego referencyjnego audio, zakres 0-1, im większa, tym większa zależność od referencyjnego audio.
- `audio_id`：ID referencyjnej muzyki.
- `overpainting_start`/`overpainting_end`：Czas rozpoczęcia i zakończenia dodawania wokalu do istniejącej czystej muzyki, w sekundach.
- `underpainting_start`/`underpainting_end`：Czas rozpoczęcia i zakończenia dodawania akompaniamentu do czystego śpiewu, w sekundach.
- `persona_id`：ID piosenki artysty.
- `continue_at`：Czas w sekundach na kontynuację istniejącego audio. Na przykład, 213.5 oznacza kontynuację do 3 minut 33.5 sekund.
- `style_influence`：Zaawansowany parametr „Style Influence” w trybie dostosowanym, zakres 0-1, im większy, tym bardziej zbliżony do wybranego stylu.
- `replace_section_end`：Ostateczny czas zastąpienia fragmentu.
- `replace_section_start`：Czas rozpoczęcia zastąpienia fragmentu.
- `vocal_gender`：Kontrola preferencji głosu męskiego lub żeńskiego, głos żeński `f`, głos męski `m`, skuteczne w modelach 4.5 i wyższych; jest to preferencja, nie gwarantuje ścisłego przestrzegania.
- `weirdness`：Zaawansowany parametr „Weirdness” w trybie dostosowanym, zakres 0-1, im większy, tym bardziej kreatywny i eksperymentalny.
- `duration`：Oczekiwana długość piosenki, w sekundach, wartość całkowita od 10 do 360. Działa tylko wtedy, gdy `action` to `generate`, `custom` to `true` i `model` to `chirp-v5-5`, inne kombinacje zwrócą 400. To jest docelowy czas trwania, rzeczywisty czas trwania produktu końcowego będzie zgodny z polem `duration` w odpowiedzi, może wystąpić niewielka odchyłka.
- `lyric_prompt`：Prompt do generowania tekstu, działa tylko wtedy, gdy `custom` to `true` i `lyric` nie jest przesłany.
- `callback_url`：URL, do którego należy zwrócić wyniki.
- `async`：Opcjonalne, ustawione na `true`, gdy interfejs natychmiast zwraca `task_id`, nie ma potrzeby podawania `callback_url`, następnie za pomocą odpowiedniego interfejsu zapytania o zadanie można uzyskać wyniki.

## Niestandardowa generacja

Jeśli chcesz dostosować generację tekstu, możesz wprowadzić tekst:

W tym momencie pole `lyric` może przyjąć podobną treść jak poniżej:

```
[Zwrotka]\nPłatki śniegu spadają wszędzie\nBłyszcząca biel\nPokrywająca ziemię\nDzieci śmieją się\nPełne radości\nW tej zimowej krainie czarów tej nocy\nSanie Świętego Mikołaja\nW niebie\nNos Rudolfa świeci jasno\nO mój\nSłyszy dzwonki\nDzwoniące tak wyraźnie\nPrzynosząc radość i świąteczną radość\n[Zwrotka 2]\nPieczenie kasztanów przy blasku ognia\nŚwiąteczne światła\nMigoczą i pokazują\nRodziny zbierają się z miłością i radością\nRozprzestrzeniając ciepło na wszystkich w pobliżu
```

> Uwaga, w tym tekście `\n` to znak nowej linii, jeśli nie wiesz, jak wygenerować tekst, możesz skorzystać z API generacji tekstu AceDataCloud, aby wygenerować tekst za pomocą promptu, API to [Suno Lyrics Generation API](https://platform.acedata.cloud/documents/suno-lyrics).

Następnie, aby dostosować generację piosenki na podstawie tekstu, tytułu i stylu, możesz określić następujące treści:

- lyric: tekst piosenki
- custom: wypełnij jako `true`, co oznacza niestandardową generację, ten parametr domyślnie jest ustawiony na false, co oznacza użycie promptu do generacji.
- title: tytuł piosenki.
- style: styl piosenki, opcjonalnie.

## Funkcja niestandardowego stylu piosenki
Jeśli chcesz użyć stylu piosenkarza do generowania utworów, najpierw za pomocą podstawowego użycia z powyższego tekstu wygeneruj piosenkę, a następnie ustaw tę piosenkę na styl piosenkarza. Następnie musisz przejść do [Suno Persona API](https://platform.acedata.cloud/documents/suno-persona) i na podstawie wygenerowanego przez oficjalne ID muzyki `audio_id` wygenerować parametr ID stylu piosenkarza `persona_id`, szczegółowe parametry przedstawione są na poniższym obrazku:

<p><img src="https://cdn.acedata.cloud/pmzo3l.png" width="500" className="m-auto" /></p>

Po wypełnieniu automatycznie wygenerowany kod wygląda następująco:

<p><img src="https://cdn.acedata.cloud/a5g0nj.png" width="500" className="m-auto" /></p>

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/persona"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f",
    "name": "test"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Po kliknięciu uruchomienia można zauważyć, że otrzymuje się wynik, jak poniżej:

Używając powyższych `audio_id` i `persona_id`, odpowiednio `97efc9f4-0e8d-4b3e-88df-14568fa1b11f` oraz `e0d7319e-aa2a-44cb-b00a-916218d7cb0b`, jako dane przykładowe. Następnie można ustawić parametr `action` na `artist_consistency` (jeśli jest to nowa wersja stylu piosenkarza Persona-v2-vox, `action` musi być ustawione na `artist_consistency_vox`), a także wprowadzić ID piosenki, którą chcesz kontynuować, oraz ID stylu piosenkarza, przykładowe wypełnienie wygląda następująco:

<p><img src="https://cdn.acedata.cloud/fukijq.png" width="500" className="m-auto" /></p>

Po wypełnieniu automatycznie wygenerowany kod wygląda następująco:

<p><img src="https://cdn.acedata.cloud/5uzk9d.png" width="500" className="m-auto" /></p>

Odpowiedni kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "artist_consistency",
    "prompt": "A song for Christmas",
    "model": "chirp-v4-5",
    "persona_id": "e0d7319e-aa2a-44cb-b00a-916218d7cb0b",
    "audio_id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Funkcja kontynuacji generowania

Jeśli chcesz kontynuować generowanie już wygenerowanej piosenki Suno, możesz ustawić parametr `action` na `extend`, a także wprowadzić ID piosenki, którą chcesz kontynuować. ID piosenki można uzyskać na podstawie podstawowego użycia, jak wynika z powyższego tekstu, w tym momencie można zobaczyć, że ID piosenki to:

```
"id": "97efc9f4-0e8d-4b3e-88df-14568fa1b11f"
```

> Uwaga, tutaj w tekście piosenki `id` to ID wygenerowanej piosenki. Jeśli nie wiesz, jak wygenerować piosenkę, możesz odwołać się do powyższego tekstu, aby wygenerować piosenkę.

Jeśli chcesz kontynuować generowanie własnych przesłanych piosenek, możesz ustawić parametr `action` na `upload_extend`, a także wprowadzić ID piosenki, którą chcesz kontynuować, ID piosenki można uzyskać za pomocą [Suno Upload Generation API](https://platform.acedata.cloud/documents/suno-upload), jak pokazano na poniższym obrazku:

<p><img src="https://cdn.acedata.cloud/a0mn5e.png" width="500" className="m-auto" /></p>

- lyric: tekst piosenki
- custom: wypełnij jako `true`, co oznacza dostosowane generowanie, ten parametr domyślnie jest ustawiony na false, co oznacza użycie generowania `prompt`.
- style: styl piosenki, opcjonalne.
- continue_at: czas kontynuacji istniejącego audio w sekundach. Na przykład, 213.5 oznacza kontynuację do 3 minut 33.5 sekund.

## Replace Section

When a song has been generated and you need to perform secondary creation by replacing a song segment separately, you can replace a certain segment of the song.

> ⚠️ **Note**: When `replace_section` is used alone, it **only returns the newly generated "replacement segment" itself** (that is, the new audio of the replaced section, with a duration approximately equal to `replace_section_end - replace_section_start`, and includes a small amount of surrounding context), **and does not return the complete stitched song**. To obtain the complete finished product stitched with the original song, after `replace_section` succeeds, you need to initiate another [Music Stitching](#音乐拼接) task for the returned segment ID. The complete process is shown below.

The parameter descriptions are as follows:

- action: The content is `replace_section`.
- audio_id: The ID of the original song (the source song being replaced).
- model: Song generation model.
- lyric: The complete lyrics after replacement (including the replaced section and its context, consistent with the content in `prompt`).
- prompt: The new lyrics of the section that needs to be replaced.
- style: The style of the song, optional.
- replace_section_start: The start time of the replaced segment in the original song (seconds).
- replace_section_end: The end time of the replaced segment in the original song (seconds).

{
  "action": "all_stems",

<p><img src="https://cdn.acedata.cloud/2dlbo6.png" width="500" class="m-auto"></p>

Odpowiadający kod Python:
```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v4-5",
    "lyric": "Hello Hello Hello ",
    "custom": True,
    "weirdness": 0.4,
    "style_influence": 0.4,
    "audio_weight": 0.4
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Kontrola długości utworu

Domyślnie długość wygenerowanej piosenki jest określana przez model, zazwyczaj wynosi od 30 sekund do 4 minut. Jeśli potrzebujesz dłuższego lub krótszego utworu końcowego, możesz określić oczekiwaną długość za pomocą parametru `duration`. Jednostką są sekundy, wartość musi być liczbą całkowitą, zazwyczaj zaleca się zakres od 10 do 360.

Ten parametr jest przeznaczony głównie do generowania utworów w trybie niestandardowym (`custom` ma wartość `true`), a najlepsze efekty uzyskuje się w połączeniu z nowszymi modelami (takimi jak `chirp-v5-5`). Różne modele i operacje mają różny poziom wsparcia dla kontroli długości. Jeśli aktualna kombinacja nie obsługuje tej funkcji, parametr może zostać zignorowany lub może zostać zwrócony komunikat błędu. Można dostosować działanie na podstawie zwróconego wyniku.

Odpowiadający kod Python:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "generate",
    "model": "chirp-v5-5",
    "custom": True,
    "title": "Under the City Lights",
    "style": "lo-fi piano",
    "lyric": "[Verse]\nSunrise creepin\nGold on the floor\n[Chorus]\nUnder the city lights\n",
    "duration": 330
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Należy pamiętać, że `duration` w żądaniu oznacza **oczekiwaną długość**, natomiast pole `duration` każdej piosenki w odpowiedzi `data` oznacza **rzeczywistą długość** tej piosenki. Obie wartości mają tę samą nazwę, ale inne znaczenie. Rzeczywista długość będzie się zmieniać wokół wartości oczekiwanej i nie ma gwarancji, że będzie dokładnie taka sama.

Jeśli dany model lub operacja nie obsługuje kontroli długości, interfejs API może zignorować ten parametr lub zwrócić komunikat błędu. Zaleca się najpierw wykonać jedno żądanie w celu sprawdzenia efektu, a następnie używać go przy większej liczbie operacji.

## Funkcja Inspo

Nowa funkcja Inspo w Suno może generować całkowicie nową muzykę na podstawie 1 do 4 fragmentów audio jako źródła inspiracji. W przeciwieństwie do coverów, Inspo nie odtwarza oryginalnej piosenki, lecz wydobywa inspirację ze stylu referencyjnych nagrań, a następnie łączy je z podpowiedziami, tagami stylu itp., aby stworzyć nowe dzieło. Podczas korzystania z niej należy wypełnić następujące parametry:

- action: zawartość to `inspo`.
- audio_urls: lista URL referencyjnych nagrań audio, należy podać od 1 do 4 publicznie dostępnych adresów audio.
- model: używany model, na przykład `chirp-v5`.
- prompt: tekst piosenki lub podpowiedzi twórczej (opcjonalnie).
- tags: tagi stylu muzycznego, na przykład `akustyczny, folk, ciepły` (opcjonalnie).
- title: tytuł utworu (opcjonalnie).
- audio_weight: waga wpływu referencyjnego nagrania na wynik generacji, zakres wartości od 0 do 1 (opcjonalnie).

> Uwaga: referencyjne nagrania muszą być publicznie dostępnymi plikami audio. Jeśli referencyjne nagranie całkowicie odpowiada znanemu nagraniu w bibliotece platformy, Suno może odmówić generacji z powodu weryfikacji praw autorskich, zaleca się użycie własnych lub wygenerowanych przez Suno nagrań jako źródła inspiracji.

Odpowiedni kod w Pythonie:

```python
import requests

url = "https://api.acedata.cloud/suno/audios"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "inspo",
    "model": "chirp-v5",
    "audio_urls": [
        "https://cdn1.suno.ai/935dd2f5-ddef-43cf-8e68-5a262425694d.mp3"
    ],
    "prompt": "ciepły akustyczny folk z delikatnymi wokalami",
    "tags": "akustyczny, folk, ciepły",
    "title": "Demo Inspo",
    "audio_weight": 0.6
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Asynchroniczny callback

Ponieważ czas generowania muzyki przez Suno jest stosunkowo długi, wynosi około 1-2 minut, jeśli API nie odpowiada przez dłuższy czas, żądanie HTTP będzie utrzymywać połączenie, co prowadzi do dodatkowego zużycia zasobów systemowych, dlatego to API oferuje również wsparcie dla asynchronicznych callbacków.

Cały proces wygląda następująco: gdy klient wysyła żądanie, dodatkowo określa pole `callback_url`, po wysłaniu żądania API natychmiast zwraca wynik, zawierający pole `task_id`, które reprezentuje aktualny identyfikator zadania. Po zakończeniu zadania, wynik generowania muzyki zostanie wysłany do określonego przez klienta `callback_url` w formie POST JSON, w którym również znajduje się pole `task_id`, dzięki czemu wyniki zadania można powiązać za pomocą identyfikatora.
