API projektu Suno Studio zarządza wielościeżkowymi projektami muzycznymi przez jeden punkt wejścia:

```http
POST /suno/projects
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

`action` w żądaniu określa typ operacji. Klucz główny Project konsekwentnie używa `id`; `version_id` oznacza bieżącą wersję projektu, a wszystkie operacje modyfikacji i eksportu muszą przesyłać najnowszą wersję, aby uniknąć nadpisania przy współbieżności.

## Przegląd operacji

| action             | Tryb  | Zastosowanie                      |
| ------------------ | --- | ----------------------- |
| `create`           | Synchroniczny  | Tworzenie pustego projektu                   |
| `retrieve`         | Synchroniczny  | Odczyt projektu i pełnego edytowalnego `state`      |
| `save`             | Synchroniczny  | Zapisywanie pełnego stanu projektu                |
| `upload`           | Asynchroniczny  | Inicjalizacja materiału, który można dodać do projektu, z adresu audio HTTPS |
| `add_track`        | Asynchroniczny  | Dodawanie istniejącego audio do projektu               |
| `generate_track`   | Asynchroniczny  | Generowanie kandydatów nowej ścieżki audio dla określonego przedziału            |
| `replace_section`  | Asynchroniczny  | Generowanie kandydatów do lokalnego zastąpienia                |
| `commit_candidate` | Asynchroniczny  | Zatwierdzanie wybranego kandydata do projektu             |
| `remove_track`     | Synchroniczny  | Usuwanie określonej ścieżki                  |
| `render`           | Asynchroniczny  | Eksportowanie zapisanej wersji jako pełnego utworu           |

Operacje asynchroniczne natychmiast zwracają `task_id`. Użyj bezpłatnego interfejsu `/suno/tasks` do odpytywania lub przekaż `callback_url`, aby otrzymać wynik końcowy.

## Tworzenie i odczyt

```json
{"action":"create","title":"My Studio Project"}
```

Wszystkie operacje modyfikacji powinny wysyłać unikalny nagłówek `Idempotency-Key`. Po pomyślnym utworzeniu `data.id` w odpowiedzi jest ID Project.

```json
{"action":"retrieve","id":"PROJECT_ID"}
```

Odpowiedź odczytu zawiera pełny `state`. Zaleca się najpierw odczytać, a następnie modyfikować i zapisywać na podstawie zwróconych wartości; nie należy ręcznie konstruować od zera wewnętrznej struktury rytmu i ścieżek.

## Zapisywanie pełnego stanu

```json
{
  "action":"save",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Edited Project",
  "state":{"tracks":[],"timing":{}}
}
```

Jeśli wersja uległa zmianie, interfejs zwraca HTTP 409. W takim przypadku ponownie wykonaj `retrieve`, scal modyfikacje, a następnie prześlij je przy użyciu nowego klucza idempotencji; nie ponawiaj bezrefleksyjnie starego żądania.

## Przesyłanie i dodawanie ścieżek

```json
{
  "action":"upload",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_url":"https://cdn.example.com/reference.mp3",
  "async":true
}
```

Po zakończeniu przesyłania wynik zadania zwraca kandydata `audio_id`. Następnie dodaj go do projektu:

```json
{
  "action":"add_track",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "audio_id":"AUDIO_ID",
  "name":"Backing Vocals"
}
```

## Generowanie i zastępowanie

`generate_track` generuje kandydatów ścieżek audio dla przedziału projektu; `replace_section` zwraca dwóch kandydatów do lokalnego zastąpienia. Żadna z tych operacji nie wybiera automatycznie rezultatu artystycznego.

```json
{
  "action":"replace_section",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "source_audio_id":"AUDIO_ID",
  "start_seconds":35.12,
  "end_seconds":48.76,
  "model":"chirp-v6",
  "replacement_lyrics":"新的歌词片段",
  "async":true
}
```

Po wybraniu kandydata zatwierdź go:

```json
{
  "action":"commit_candidate",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "operation_id":"OPERATION_ID",
  "candidate_id":"CANDIDATE_ID",
  "track_id":"TRACK_ID"
}
```

Kandydaci są powiązani z wersją projektu z momentu generowania. Gdy projekt już się zmienił, starych kandydatów nie można zatwierdzić bezpośrednio.

## Eksportowanie pełnego utworu

```json
{
  "action":"render",
  "id":"PROJECT_ID",
  "version_id":"CURRENT_VERSION_ID",
  "title":"Final Mix",
  "lyrics":"[Instrumental]",
  "async":true,
  "callback_url":"https://example.com/webhooks/suno"
}
```

Serwer odczytuje autorytatywny stan projektu określonej wersji i składa parametry eksportu. Wynik końcowy zawiera `render_id`, `audio_id`, `audio_url` oraz czas trwania. Projekt jest powiązany ze środowiskiem wykonawczym z czasu utworzenia i nie może być migrowany między środowiskami ani automatycznie przełączany awaryjnie.

> Można przesyłać lub przetwarzać wyłącznie audio, do którego posiada się legalne prawa użytkowania. API projektu jest obecnie w wersji Beta; należy trwale zapisywać końcowy adres URL audio w ważnych wynikach.
