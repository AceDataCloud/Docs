Suno MP3 URL API generuje ścieżkę do istniejącej muzyki, kończącą się na `.mp3`, która jest odtwarzalna, odpowiednia dla scenariuszy, w których stare linki do pobrania są nieaktualne, odtwarzanie na urządzeniach mobilnych lub potrzeba ponownego uzyskania publicznego URL audio.

Wymaganym parametrem `audio_id` jest identyfikator audio zwrócony przez interfejs generowania audio Suno. Każde wywołanie tworzy niezależne zadanie MP3 URL, nie modyfikując oryginalnego zadania generowania muzyki ani nie zmieniając oryginalnego identyfikatora audio.

## Wywołanie synchroniczne

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={
        "accept": "application/json",
        "authorization": "Bearer <YOUR_API_TOKEN>",
        "content-type": "application/json"
    },
    json={"audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f"},
    timeout=240
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["file_url"])
```

W przypadku sukcesu, `data[0].file_url` to odtwarzalny adres audio. Interfejs najpierw spróbuje zapisać do `https://cdn.acedata.cloud/suno/{audio_id}.mp3`; jeśli zapis trwały się nie powiedzie, zwróci aktualnie dostępny oryginalny adres mediów.

## Wywołanie asynchroniczne

W przypadku dłuższego czasu przetwarzania, można przekazać `async: true`:

```python
submission = requests.post(
    "https://api.acedata.cloud/suno/mp3",
    headers={"authorization": "Bearer <YOUR_API_TOKEN>"},
    json={
        "audio_id": "ef1ec21e-1540-4eb6-8fa5-26cb8b90d28f",
        "async": True
    }
).json()

export_task_id = submission["task_id"]
```

Następnie można sprawdzić `export_task_id` za pomocą `/suno/tasks`. Można również podać `callback_url`, aby otrzymać ostateczny wynik po zakończeniu zadania. Odpowiedzi synchroniczne, zapytania o zadania i wywołania zwrotne używają tej samej struktury danych końcowych.

## Uwagi

- `audio_id` musi pochodzić z rozpoznawalnego audio Suno.
- Zadania MP3 URL są niezależne od oryginalnych zadań generowania muzyki.
- Niepowodzenie zapisu trwałego nie zablokuje wyniku, nastąpi powrót do oryginalnego adresu mediów; proszę pobrać na czas.
- Zaleca się, aby strona biznesowa pobrała wyniki i zapisała je zgodnie z własną strategią przechowywania danych.
