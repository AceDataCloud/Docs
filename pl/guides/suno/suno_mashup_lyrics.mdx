---
title: "Suno API do generowania tekstów piosenek"
description: "Suno Music Generation API guide - Ace Data Cloud"
---

Jeśli chcesz użyć tekstów dwóch piosenek do stworzenia mieszanej piosenki, możesz najpierw skorzystać z tego API, aby wygenerować odpowiednie teksty. API to jest [Suno MashupLyrics Generation API](https://platform.acedata.cloud/documents/suno-mashup-lyrics).

Główne parametry wejściowe tego API to `lyrics_a` i `lyrics_b`, przykładowe wypełnienie wygląda następująco:

![](https://cdn.acedata.cloud/g9n3t6.png)

Kliknij, aby uruchomić, a wynik będzie wyglądał następująco:

```
{
  "success": true,
  "task_id": "80aa3cd3-ca87-4ca3-82d2-1830e3d8f53a",
  "data": {
    "text": "Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nSambuy come, Sambuy come back  \nBluespawn, greenspawn are making you a spawn  \n\nSambuy come  \nSambuy come back  \nBluespawn, greenspawn are making you a spawn  \nSambuy come back",
    "title": "Lyrics Mashup",
    "tags": [],
    "status": "complete"
  }
}
```

Można zauważyć, że pole `text` w `data` zawiera informacje o tekstach.

Mając teksty, możemy skorzystać z [Suno Audios Generation API](https://platform.acedata.cloud/documents/suno-audios), aby stworzyć spersonalizowaną piosenkę.
