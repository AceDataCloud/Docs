---
title: "OpenAI API do syntezowania mowy (/v1/audio/speech)"
description: "OpenAI generation API guide - Ace Data Cloud"
---

Zamień tekst na naturalną mowę, **w pełni zgodny z OpenAI `/v1/audio/speech`**. Każde SDK OpenAI wystarczy, że wskaże `base_url` na `https://api.acedata.cloud` oraz zamieni klucz na swój token AceData, aby móc bezpośrednio korzystać. Interfejs synchronizuje zwraca strumień bajtów audio.

- **Adres żądania**: `POST https://api.acedata.cloud/v1/audio/speech` (alias `POST /openai/audio/speech`)
- **Autoryzacja**: nagłówek żądania `Authorization: Bearer {token}`
- **Rozliczenie**: opłata według liczby bajtów tekstu w żądaniu, około 85% oficjalnej ceny OpenAI (patrz poniższa tabela).

## Parametry żądania

| Pole                | Typ     | Wymagane | Opis                                                            |
| ----------------- | ------ | --- | ------------------------------------------------------------- |
| `input`           | string | Tak   | Tekst do syntezowania.                                           |
| `model`           | string | Nie   | `tts-1` (szybszy) lub `tts-1-hd` (wyższa jakość dźwięku, domyślnie).                             |
| `voice`           | string | Nie   | Jeden z `alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`, domyślnie `alloy`. |
| `response_format` | string | Nie   | `mp3` (domyślnie), `opus`, `aac`, `flac`, `wav`, `pcm`.                    |
| `speed`           | number | Nie   | Prędkość mowy 0.25–4.0, domyślnie 1.0.                                           |

## Przykład

```shell
curl -X POST 'https://api.acedata.cloud/v1/audio/speech' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -o speech.mp3 \
  -d '{
    "model": "tts-1-hd",
    "input": "Co jeśli jedno API dałoby ci każdy model wideo AI?",
    "voice": "nova",
    "response_format": "mp3"
  }'
```

Zwracany jest sam plik audio (`Content-Type: audio/mpeg`), który można bezpośrednio zapisać jako `speech.mp3` do odtworzenia.

Używając oficjalnego SDK OpenAI w Pythonie:

```python
from openai import OpenAI
client = OpenAI(base_url="https://api.acedata.cloud/v1", api_key="{token}")
client.audio.speech.create(model="tts-1-hd", voice="nova", input="Witaj z AceData.").stream_to_file("speech.mp3")
```

## Ceny

| Model         | Oficjalna cena OpenAI    | Cena na tej platformie (około 85% zniżki)       |
| ---------- | ------------- | ------------------ |
| `tts-1`    | $15 / 1 milion znaków | około $12.75 / 1 milion znaków |
| `tts-1-hd` | $30 / 1 milion znaków | około $25.5 / 1 milion znaków  |

> Opłata według liczby bajtów tekstu w żądaniu; pole `official_price` pokazuje oficjalną cenę OpenAI dla porównania.

## Kody błędów

| Kod statusu | kod                    | Opis               |
| --- | ----------------------- | ---------------- |
| 400 | `bad_request`           | `input` jest puste lub parametr jest nieprawidłowy. |
| 401 | `authentication_failed` | token jest nieprawidłowy.        |
| 403 | `used_up`               | Niewystarczające saldo.            |
| 429 | `too_many_requests`     | Zbyt wiele żądań.          |
| 500 | `api_error`             | Błąd zewnętrzny/wewnętrzny.         |
