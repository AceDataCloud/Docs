Usługa wektorów słów OpenAI, używana do generowania wyników wektorów słów reprezentujących tekst wejściowy.

Ten dokument przedstawia głównie proces korzystania z OpenAI Embeddings API, dzięki któremu możemy tworzyć wektory osadzeń reprezentujące tekst wejściowy。。

## Proces wnioskowania

Aby korzystać z OpenAI Embeddings API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, która zachęci Cię do rejestracji i zalogowania się, a po zakończeniu automatycznie powrócisz na bieżącą stronę.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, nie ma potrzeby składania osobnego wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz bezpłatny limit, który pozwala na darmowe wypróbowanie; gdy limit będzie niewystarczający, możesz doładować uniwersalne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [OpenAI Embeddings API →](https://platform.acedata.cloud/documents/openai-embeddings)

## Podstawowe użycie

Następnie możesz wypełnić odpowiednią zawartość w interfejsie, jak pokazano na ilustracji:

<p><img src="https://cdn.acedata.cloud/4qtbvr.png" width="500" className="m-auto" /></p>

Przy pierwszym użyciu tego interfejsu musimy wypełnić co najmniej trzy elementy, jednym z nich jest `authorization`, który można bezpośrednio wybrać z listy rozwijanej. Kolejnym parametrem jest `model`, `model` oznacza kategorię modelu z oficjalnej strony OpenAI, której używamy; obecnie dostępne modele to `text-embedding-3-small` i `text-embedding-3-large`. `text-embedding-ada-002` nie jest już oferowany; jeśli istniejący indeks wektorowy korzysta z tego starego modelu, nie można bezpośrednio mieszać wektorów nowego modelu i należy ponownie utworzyć indeks. Ostatnim parametrem jest `input`, `input` to tekst wektora słów, który musimy przekonwertować.

Jednocześnie możesz zauważyć, że po prawej stronie generowany jest odpowiedni kod wywołania, możesz skopiować kod i uruchomić go bezpośrednio, możesz też bezpośrednio kliknąć przycisk „Try”, aby przeprowadzić test.

Parametry opcjonalne:

- `dimensions`: przycinanie wymiarów wektora, domyślnie zwracany jest pełny wymiar.
- `encoding_format`: format zwracany, do wyboru `float` lub `base64`.

<p><img src="https://cdn.acedata.cloud/gqulm9.png" width="500" className="m-auto" /></p>

Przykładowy kod wywołania w Pythonie:

```python
import requests

url = "https://api.acedata.cloud/openai/embeddings"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "input": "The food was delicious and the waiter...",
    "model": "text-embedding-3-small",
    "encoding_format": "float"
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Zwracany wynik zawiera wiele pól, które przedstawiono poniżej:

- `model`, model użyty tym razem do konwersji tekstu na wektory słów.
- `usage`, informacje o tokenach użytych tym razem do konwersji tekstu na wektory słów.
- `data`, wynik wektorów słów po konwersji tekstu.

Wśród nich `data` zawiera szczegółowe informacje o wektorach słów odpowiadających tekstowi, a znajdujące się w nim `embedding` to konkretny wygenerowany wynik wektorów słów.

## Obsługa błędów

Podczas wywoływania API, jeśli wystąpi błąd, API zwróci odpowiedni kod błędu i informacje. Na przykład:

- `400 token_mismatched`: Nieprawidłowe żądanie, prawdopodobnie z powodu brakujących lub nieprawidłowych parametrów.
- `400 api_not_implemented`: Nieprawidłowe żądanie, prawdopodobnie z powodu brakujących lub nieprawidłowych parametrów.
- `401 invalid_token`: Brak autoryzacji, nieprawidłowy lub brakujący token autoryzacyjny.
- `429 too_many_requests`: Zbyt wiele żądań, przekroczono limit szybkości.
- `500 api_error`: Wewnętrzny błąd serwera, coś poszło nie tak na serwerze.
