OpenAI ChatGPT to bardzo potężny system konwersacyjny AI, wystarczy wprowadzić prompt, aby w zaledwie kilka sekund wygenerować płynną i naturalną odpowiedź. ChatGPT wyróżnia się w branży swoimi znakomitymi możliwościami rozumienia i generowania języka, a obecnie ChatGPT jest już szeroko stosowany w różnych branżach i dziedzinach, a jego wpływ staje się coraz bardziej znaczący. Niezależnie od tego, czy chodzi o codzienne rozmowy, kreatywne pisanie, czy profesjonalne konsultacje i programowanie kodu, ChatGPT może zapewnić zachwycającą inteligentną pomoc, znacznie zwiększając wydajność pracy i kreatywność ludzi.

Ten dokument przedstawia głównie proces korzystania z operacji OpenAI Chat Completion API, dzięki któremu możemy łatwo korzystać z funkcji konwersacji oficjalnego OpenAI ChatGPT.

## GPT-6.1 Sol

Użyj `model: "gpt-6.1-sol"`, aby wybrać ten model. Obsługuje wyjście strumieniowe, wywoływanie funkcji, ustrukturyzowane wyjście i wejście obrazów. W pierwszym tygodniu od udostępnienia jest dostępny wyłącznie dla zweryfikowanych posiadaczy ACE T1+ (co najmniej 100 000 ACE) lub autoryzowanych użytkowników; szczegółowy czas udostępnienia zależy od komunikatu o dostępie w konsoli.

Poziomy rozumowania obsługują `low`, `medium`, `high`, `xhigh` i `max`, tymczasowo nie obsługują `none` ani `minimal`. Zaleca się rozpoczęcie od `reasoning_effort: "low"`. Gdy dane wejściowe przekroczą 272 000 tokenów, do całego żądania ma zastosowanie cena za długi kontekst, a opłata zależy od aktualnej ceny w konsoli.

## Proces składania wniosku

Aby korzystać z OpenAI Chat Completion API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany lub zarejestrowany, nastąpi automatyczne przekierowanie na stronę logowania, która zaprosi Cię do rejestracji i zalogowania się, a po zakończeniu automatycznie powrócisz na obecną stronę.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, bez konieczności osobnego składania wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz bezpłatny limit, który pozwala na darmowe wypróbowanie; gdy limit jest niewystarczający, możesz doładować uniwersalne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

## Podstawowe użycie

Następnie można w interfejsie wypełnić odpowiednią treść, jak pokazano na ilustracji:

<p><img src="https://cdn.acedata.cloud/jqgg1t.png" width="400" className="m-auto" /></p>

Przy pierwszym użyciu tego interfejsu musimy wypełnić co najmniej trzy elementy, jednym z nich jest `authorization`, które można bezpośrednio wybrać z listy rozwijanej. Kolejnym parametrem jest `model`, `model` oznacza kategorię modelu z oficjalnej strony OpenAI ChatGPT, którą wybieramy do użycia, tutaj mamy głównie 20 rodzajów modeli, szczegóły można zobaczyć w udostępnianych przez nas modelach. Ostatnim parametrem jest `messages`, `messages` to tablica wpisywanych przez nas promptów, jest to tablica, co oznacza, że można jednocześnie przesłać wiele promptów, każdy prompt zawiera `role` i `content`, gdzie `role` oznacza rolę osoby zadającej pytanie, udostępniamy trzy tożsamości, odpowiednio `user`, `assistant`, `system`. Kolejny `content` to konkretna treść naszego pytania.

Jednocześnie można zauważyć, że po prawej stronie generowany jest odpowiedni kod wywołania, można skopiować kod i uruchomić go bezpośrednio, można również bezpośrednio kliknąć przycisk „Try”, aby przeprowadzić test.

Często używane opcjonalne parametry:

- `max_tokens`: ogranicza maksymalną liczbę tokenów pojedynczej odpowiedzi.
- `temperature`: losowość generowania, między 0 a 2, im większa wartość, tym większe rozproszenie.
- `n`: ile kandydackich odpowiedzi wygenerować jednocześnie.
- `response_format`: ustawienie formatu zwracanych danych.

## Odpowiedź strumieniowa

Ten interfejs również obsługuje odpowiedzi strumieniowe, co jest bardzo przydatne przy integracji ze stronami internetowymi i może pozwolić stronie uzyskać efekt wyświetlania znak po znaku.

Jeśli chcesz zwracać odpowiedź strumieniowo, możesz zmienić parametr `stream ` w nagłówku żądania na `true`.

Modyfikacja jest pokazana na ilustracji, jednak kod wywołania musi zostać odpowiednio zmieniony, aby obsługiwać odpowiedź strumieniową.

<p><img src="https://cdn.acedata.cloud/24scd4.png" width="400" className="m-auto" /></p>

Po zmianie `stream` na `true`, API będzie zwracać odpowiednie dane JSON wiersz po wierszu, na poziomie kodu musimy wprowadzić odpowiednie modyfikacje, aby uzyskać wyniki wiersz po wierszu.

Przykładowy kod wywołania Python:

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4",
    "messages": [{"role":"user","content":"hello"}],
    "stream": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

```javascript
const options = {
  method: "post",
  headers: {
    accept: "application/json",
    authorization: "Bearer {token}",
    "content-type": "application/json",
  },
  body: JSON.stringify({
    model: "gpt-4",
    messages: [{ role: "user", content: "hello" }],
    stream: true,
  }),
};

fetch("https://api.acedata.cloud/openai/chat/completions", options)
  .then((response) => response.json())
  .then((response) => console.log(response))
  .catch((err) => console.error(err));
```


## Integracja z OpenAI-Python

OpenAI Chat Completion API zachowuje kompatybilność z oficjalnym interfejsem OpenAI i może być bezpośrednio integrowane za pomocą oficjalnego SDK [OpenAI-Python](https://github.com/openai/openai-python); w tym artykule krótko przedstawimy sposób użycia.

1. Najpierw należy skonfigurować lokalne środowisko `Python`; ten proces można wyszukać w Google.
2. Pobierz i zainstaluj środowisko programistyczne, na przykład edytor VSCode.
3. Skonfiguruj zmienne środowiskowe `OpenAI`.

- W folderze projektu utwórz plik o nazwie `.env` i zapisz go.
- Zawartość pliku `.env`:

```json
OPENAI_API_KEY="sk-xxx"
OPENAI_BASE_URL="https://api.acedata.cloud/openai"  # Ponowne przypomnienie: jeśli używasz klucza OpenAI z oficjalnej strony, nie używaj tego adresu.
```

Zastąp `sk-xxx` własnym kluczem. `OPENAI_BASE_URL` to pośredniczący interfejs dostępu do OpenAI.

4. Zainstaluj pakiet zależności projektu

```shell
pip install openai
```

W Mac OS polecenie to:

```shell
pip3 install openai
```

5. Utwórz przykładowy plik kodu źródłowego

Załóżmy, że utworzyliśmy przykładowy kod `index.py`, którego konkretna zawartość jest następująca:

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "hello",
        }
    ],
    model="gpt-4",
)

print(response.text)
```

## Model wizyjny

gpt-4o to wielomodalny duży model językowy opracowany przez OpenAI; na bazie GPT-4 dodano do niego zdolność rozumienia obrazu. Model ten może jednocześnie przetwarzać dane wejściowe tekstowe i obrazowe, realizując rozumienie oraz generowanie między modalnościami.

Przetwarzanie tekstu przy użyciu modelu gpt-4o jest zgodne z opisanym powyżej podstawowym użyciem; poniżej krótko przedstawimy, jak używać możliwości przetwarzania obrazu przez model.

Możliwość przetwarzania obrazu przez model gpt-4o jest używana głównie poprzez dodanie pola `type` do oryginalnej zawartości `content`; dzięki temu polu można określić, czy przesyłany jest tekst, czy obraz, a tym samym użyć możliwości przetwarzania obrazu modelu gpt-4o. Poniżej głównie opisano wywołanie tej funkcji na dwa sposoby: za pomocą Curl i Python.

- Metoda skryptu Curl

```
curl -X POST 'https://api.acedata.cloud/openai/chat/completions' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
    "model": "gpt-4o",
    "messages": [
      {
        "role": "user",
        "content": [
          {
            "type": "text",
            "text": "What'\''s in this image?"
          },
          {
            "type": "image_url",
            "image_url": {
              "url": "https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg"
            }
          }
        ]
      }
    ]
  }'
```

- Metoda skryptu Python
```python

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "text", "text": "Co znajduje się na tym obrazie?"
                },
```

## Obsługa błędów

Podczas wywoływania API, jeśli wystąpi błąd, API zwróci odpowiedni kod błędu i informację. Na przykład:

- `400 token_mismatched`：Nieprawidłowe żądanie, prawdopodobnie z powodu brakujących lub nieprawidłowych parametrów.
- `400 api_not_implemented`：Nieprawidłowe żądanie, prawdopodobnie z powodu brakujących lub nieprawidłowych parametrów.
- `401 invalid_token`：Brak autoryzacji, nieprawidłowy lub brakujący token autoryzacyjny.
- `429 too_many_requests`：Zbyt wiele żądań, przekroczono limit częstotliwości.
- `500 api_error`：Wewnętrzny błąd serwera, coś poszło nie tak na serwerze.
