## 1. Uzyskanie API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskanie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Wysłanie pierwszego żądania

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Obraz w pomyślnej odpowiedzi znajduje się w `data[].url`. Poniżej znajduje się wynik 1024×1536 faktycznie uzyskany przez żądanie za pośrednictwem Ace Data Cloud 8 września 2026 r. (zadanie `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Biały kubek wygenerowany przez GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Często używane parametry

| Pole                | Opis                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (zalecany domyślnie), `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiadający wariant `:official`, a `gpt-image-2` obsługuje również `:reverse` |
| `prompt`          | Opis obrazu, maksymalnie 32 000 znaków                                                                                                                     |
| `size`            | `auto` lub `WIDTHxHEIGHT`; szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, łączna liczba pikseli wynosi 655 360–8 294 400, a proporcje nie mogą przekraczać 3:1                                                       |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest tylko 1                                                                                                 |
| `quality`         | `low`, `medium`, `high` lub `auto`; obsługa i sposób rozliczania różnią się w zależności od trasy                                                                                          |
| `response_format` | `url` lub `b64_json`                                                                                                                     |
| `callback_url`    | Opcjonalne; po zakończeniu długiego zadania wynik zostanie wysłany pod ten adres                                                                                                                      |

Często używane rozmiary:

| Proporcje   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wybierze format kadru na podstawie proporcji, pikseli i intencji układu w podpowiedzi; gdy potrzebujesz dokładnych pikseli, wpisz bezpośrednio rozmiar.

## 4. Generowanie wielu obrazów

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz `gpt-image-2:reverse` są rozliczane według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywistych Tokenów wejścia tekstowego i wyjścia obrazu w odpowiedzi. Cena na stronie jest szacunkiem przed żądaniem, ostatecznie obowiązuje historia użycia.

## 5. Asynchroniczne wywołanie zwrotne

Po dodaniu `callback_url` do treści żądania interfejs najpierw zwróci `{"task_id": "..."}`, a po ukończeniu wyśle końcowy wynik metodą POST na ten URL; żądania synchroniczne nadal zwracają `created` i `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Odbiorca wywołania zwrotnego powinien używać `task_id` do eliminacji duplikatów oraz zweryfikować źródło żądania i format danych.

## 6. Rozwiązywanie problemów

| Status  | Sprawdź                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombinację `model`, `prompt`, formatu rozmiaru, `n` i `response_format`    |
| 401 | Czy API Key jest kompletne oraz czy Header ma formę `Authorization: Bearer ...` |
| 429 | Żądania są zbyt częste, spróbuj ponownie później                                         |
| 504 | Limit czasu generowania synchronicznego; użyj `callback_url`                            |

Odpowiedź błędu będzie zawierać `error.code`, `error.message` i `trace_id`. Przy zgłaszaniu problemu podaj `trace_id`, nie podawaj API Key.

Pełne pola i aktualne wyliczenia znajdują się na stronie [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). W przypadku edycji obrazów zobacz [Edycja obrazów GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-edits).
