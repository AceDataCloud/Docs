## 1. Uzyskiwanie API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskiwanie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Wysłanie pierwszego żądania

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Obraz z udanej odpowiedzi znajduje się w `data[].url`. Poniżej przedstawiono rzeczywisty wynik 1024×1536 uzyskany przez Ace Data Cloud 8 września 2026 r. (zadanie `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Biały kubek wygenerowany przez GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Często używane parametry

| Pole                | Opis                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (domyślnie zalecany), `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiedni wariant `:official`, a `gpt-image-2` obsługuje również `:reverse` |
| `prompt`          | Opis obrazu, maksymalnie 32 000 znaków                                                                                                                     |
| `size`            | `auto` lub `WIDTHxHEIGHT`; szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, całkowita liczba pikseli wynosi 655 360–8 294 400, a proporcje obrazu nie mogą przekraczać 3:1                                                       |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest tylko 1                                                                                                 |
| `quality`         | Modele GPT Image obsługują `auto`, `low`, `medium`, `high`; tylko 2.5 Flare / Sunburst (w tym `:official`) dodatkowo obsługują `xhigh`, `max`. Oficjalny kanał jest rozliczany według rzeczywistego zużycia Tokenów                 |
| `response_format` | `url` lub `b64_json`                                                                                                                     |
| `callback_url`    | Opcjonalne; po zakończeniu długiego zadania wysyła wynik na ten adres                                                                                                                      |

Często używane wymiary:

| Proporcje   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wybierze format obrazu na podstawie proporcji, pikseli i zamiaru układu zawartego w poleceniu; gdy potrzebne są dokładne piksele, wpisz wymiary bezpośrednio.

### Modele i sposób rozliczania

| Model                                | Zastosowania i sposób rozliczania                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Domyślny kanał odwrotny, stałe rozliczanie według liczby udanych obrazów                        |
| `gpt-image-2:reverse`             | Jawny wybór kanału odwrotnego, stałe rozliczanie według liczby udanych obrazów                      |
| `gpt-image-2:official`            | Oficjalny kanał API, wyższa stabilność, rozliczanie według rzeczywistego zużycia Tokenów            |
| `gpt-image-2.5-flare`             | Skupia się na szybkości generowania, stałe rozliczanie według liczby udanych obrazów                        |
| `gpt-image-2.5-flare:official`    | Oficjalny kanał API, wyższa stabilność i skupienie na szybkości generowania, rozliczanie według rzeczywistego zużycia Tokenów     |
| `gpt-image-2.5-sunburst`          | Skupia się na wysokiej wierności i precyzyjnej kontroli, stałe rozliczanie według liczby udanych obrazów                    |
| `gpt-image-2.5-sunburst:official` | Oficjalny kanał API, wyższa stabilność i skupienie na wysokiej wierności oraz precyzyjnej kontroli, rozliczanie według rzeczywistego zużycia Tokenów |

Ceny na stronie oficjalnego kanału API są szacunkami przed żądaniem; ostatecznie obowiązuje rzeczywiste zużycie Tokenów w odpowiedzi i historia użycia.

## 4. Generowanie wielu obrazów

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` i `gpt-image-2:reverse` są rozliczane według liczby udanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` oraz `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywistych Tokenów wejściowych tekstu i wyjściowych obrazu w odpowiedzi. Ceny na stronie są szacunkami przed żądaniem, a ostatecznie obowiązuje historia użycia.

## 5. Asynchroniczne wywołanie zwrotne

Po dodaniu `callback_url` do treści żądania interfejs najpierw zwróci `{"task_id": "..."}`, a po zakończeniu wyśle ostateczny wynik metodą POST na ten URL; żądania synchroniczne nadal zwracają `created` i `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Odbiorca wywołania zwrotnego powinien używać `task_id` do deduplikacji oraz weryfikować źródło żądania i format danych.

## 6. Rozwiązywanie problemów

| Status  | Sprawdź                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombinację `model`, `prompt`, formatu wymiarów, `n` i `response_format`    |
| 401 | Czy API Key jest kompletny i czy Header ma postać `Authorization: Bearer ...` |
| 429 | Żądania są zbyt częste, spróbuj ponownie później                                         |
| 504 | Przekroczono limit czasu generowania synchronicznego; użyj `callback_url`                            |

Odpowiedź błędu zawiera `error.code`, `error.message` i `trace_id`. Przy zgłaszaniu problemu podaj `trace_id`, nie podawaj API Key.

Pełne pola i aktualne wyliczenia znajdują się na stronie [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Informacje o edycji obrazów znajdziesz w [GPT Image 2 / 2.5 Edycja obrazów](https://platform.acedata.cloud/documents/openai-images-edits).
