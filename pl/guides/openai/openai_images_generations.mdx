## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Wyślij pierwsze zapytanie

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer twój klucz API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimalna ilustracja produktu redakcyjnego: jedna prosta biała ceramiczna filiżanka do kawy umieszczona na solidnym niebieskim stole, jasne kremowe tło, miękki cień, czyste geometryczne kształty, bez tekstu, bez logo, kompozycja portretowa",
    "size": "1024x1536"
  }'
```

Obrazek w odpowiedzi znajduje się w `data[].url`. Poniżej znajduje się wynik 1024×1536 uzyskany 8 września 2026 roku za pośrednictwem Ace Data Cloud (zadanie `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, ślad `eb938601-8192-407f-b539-1e0554b697ec`):

![Filiżanka do kawy wygenerowana przez GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Często używane parametry

| Pole                | Opis                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (domyślnie zalecane), `gpt-image-2.5-flare` (szybsze) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); można również wybrać `gpt-image-2:official` lub `gpt-image-2:reverse` |
| `prompt`          | Opis obrazu, maksymalnie 32 000 znaków                                                                                                                     |
| `size`            | `auto` lub `WIDTHxHEIGHT`; wymiary muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, całkowita liczba pikseli wynosi 655 360–8 294 400, proporcje nie mogą przekraczać 3:1                                                       |
| `n`               | 1–10; tylko 1 jest obsługiwane, gdy `response_format=b64_json`                                                                                                 |
| `quality`         | `low`, `medium`, `high` lub `auto`; różne linie mają różne wsparcie i metody rozliczeń                                                                                          |
| `response_format` | `url` lub `b64_json`                                                                                                                     |
| `callback_url`    | Opcjonalne; adres, na który zostaną wysłane wyniki po zakończeniu długiego zadania                                                                                                                      |

Często używane rozmiary:

| Proporcja   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wybierze format na podstawie proporcji, pikseli i intencji układu w podpowiedzi; w przypadku potrzeby dokładnych pikseli należy bezpośrednio wpisać rozmiar.

## 4. Generowanie wielu obrazów

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer twój klucz API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Mały lis czytający pod świecącym grzybem, ilustracja akwarelowa",
    "size": "1536x1024",
    "n": 2
  }'
```

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz `:reverse` są rozliczane na podstawie liczby udanych obrazów; `gpt-image-2:official` rozlicza się na podstawie rzeczywistych tokenów w odpowiedzi na tekst i obraz. Ceny na stronie są szacunkowe przed zapytaniem, ostateczne rozliczenie opiera się na zapisach użycia.

## 5. Asynchroniczny callback

Po dodaniu `callback_url` do ciała zapytania, interfejs najpierw zwróci `{"task_id": "..."}`, a po zakończeniu wyśle ostateczny wynik na ten adres URL; zapytania synchroniczne nadal zwracają `created` i `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "Plakat produktu z wyraźną typografią",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Odbiorca callbacku powinien użyć `task_id` do deduplikacji i zweryfikować źródło zapytania oraz format danych.

## 6. Rozwiązywanie problemów

| Status  | Sprawdzenie                                                  |
| --- | --------------------------------------------------- |
| 400 | Kombinacja `model`, `prompt`, format rozmiaru, `n` i `response_format`    |
| 401 | Czy klucz API jest kompletny, czy nagłówek to `Authorization: Bearer ...` |
| 429 | Zbyt wiele zapytań, spróbuj ponownie później                                         |
| 504 | Czas oczekiwania na synchronizację wygasł; użyj `callback_url`                            |

Odpowiedzi z błędami będą zawierać `error.code`, `error.message` i `trace_id`. Podczas zgłaszania problemów podaj `trace_id`, nie podawaj klucza API.

Pełne pola i bieżące wyliczenia można znaleźć na stronie [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). Aby edytować obrazy, zapoznaj się z [GPT Image 2 / 2.5 edycją obrazów](https://platform.acedata.cloud/documents/openai-images-edits).
