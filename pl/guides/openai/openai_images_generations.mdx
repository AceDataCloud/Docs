## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskaj Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Wyślij pierwsze żądanie

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "Minimal editorial product illustration: one plain white ceramic coffee mug centered on a solid cobalt blue tabletop, pale cream background, soft shadow, clean geometric shapes, no text, no logo, portrait composition",
    "size": "1024x1536"
  }'
```

Obraz z udanej odpowiedzi znajduje się w `data[].url`. Poniżej znajduje się wynik 1024×1536 faktycznie uzyskany przez żądanie za pośrednictwem Ace Data Cloud 8 września 2026 r. (zadanie `d56455e2-e7f7-4bcd-b935-475b0a1e0948`, trace `eb938601-8192-407f-b539-1e0554b697ec`):

![Biały kubek wygenerowany przez GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

## 3. Często używane parametry

| Pole                | Opis                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2` (domyślnie zalecany), `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiadający wariant `:official`, a `gpt-image-2` obsługuje również `:reverse` |
| `prompt`          | Opis obrazu, maksymalnie 32 000 znaków                                                                                                                     |
| `size`            | `auto` lub `WIDTHxHEIGHT`; szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, łączna liczba pikseli wynosi 655 360–8 294 400, a proporcje obrazu nie mogą przekraczać 3:1                                                       |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest tylko 1                                                                                                 |
| `quality`         | Modele GPT Image obsługują `auto`, `low`, `medium`, `high`; 2.5 / 2.6 Flare / Sunburst (w tym `:official`) dodatkowo obsługują `xhigh`, `max`. Kanał oficjalny jest rozliczany według rzeczywistego zużycia Tokenów             |
| `response_format` | `url` lub `b64_json`                                                                                                                     |
| `callback_url`    | Opcjonalne; po zakończeniu długiego zadania wysyła wynik na ten adres                                                                                                                      |

Często używane rozmiary:

| Proporcje   | 1K          | 2K          | 4K          |
| ---- | ----------- | ----------- | ----------- |
| 1:1  | `1024x1024` | `2048x2048` | `2880x2880` |
| 4:3  | `1536x1024` | `2048x1536` | `3264x2448` |
| 3:4  | `1024x1536` | `1536x2048` | `2448x3264` |
| 16:9 | `1792x1024` | `2048x1152` | `3840x2160` |
| 9:16 | `1024x1792` | `1152x2048` | `2160x3840` |

`size: "auto"` wybierze format obrazu na podstawie proporcji, pikseli i zamierzonego układu w promptcie; jeśli potrzebujesz dokładnych pikseli, wpisz rozmiar bezpośrednio.

Modele reverse 2.0 / 2.5 (w tym alias `:reverse`) mogą podczas automatycznego odzyskiwania użyć GPT Image 2.5 Flare do ukończenia żądania; model żądania i sposób stałego rozliczania według liczby pomyślnie wygenerowanych obrazów pozostają bez zmian.

Ceny na stronie oficjalnego kanału API są szacowane przed żądaniem, a ostateczne wartości są określane na podstawie rzeczywistego zużycia Tokenów i rekordu użycia w odpowiedzi.

## 4. Generowanie wielu obrazów

```bash
curl https://api.acedata.cloud/openai/images/generations \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "A small fox reading under a glowing mushroom, watercolor illustration",
    "size": "1536x1024",
    "n": 2
  }'
```
`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz ich aliasy `:reverse` są rozliczane według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywistych Tokenów wejściowego tekstu i wyjściowego obrazu w odpowiedzi. Cena na stronie jest szacunkiem przed żądaniem, a ostateczna cena zależy od rejestru użycia.

## 5. Asynchroniczne wywołania zwrotne

Po dodaniu `callback_url` do treści żądania interfejs najpierw zwróci `{"task_id": "..."}`, a po ukończeniu wyśle końcowy wynik metodą POST na ten URL; żądania synchroniczne nadal zwracają `created` i `data`:

```json
{
  "model": "gpt-image-2",
  "prompt": "A product poster with clear typography",
  "size": "1024x1024",
  "callback_url": "https://example.com/webhooks/images"
}
```

Odbiorca wywołania zwrotnego powinien usuwać duplikaty na podstawie `task_id` oraz weryfikować źródło żądania i format danych.

## 6. Rozwiązywanie problemów

| Status  | Sprawdź                                                  |
| --- | --------------------------------------------------- |
| 400 | kombinację `model`, `prompt`, formatu rozmiaru, `n` i `response_format`    |
| 401 | czy API Key jest kompletny, czy Header ma postać `Authorization: Bearer ...` |
| 429 | żądania są zbyt częste, spróbuj ponownie później                                         |
| 504 | przekroczono limit czasu generowania synchronicznego; użyj `callback_url`                            |

Odpowiedź błędu zawiera `error.code`, `error.message` i `trace_id`. Podczas zgłaszania problemu podaj `trace_id`, nie podawaj API Key.

Pełne pola i aktualne wyliczenia znajdują się na stronie [OpenAI Images Generations API](https://platform.acedata.cloud/documents/openai-images-generations). W przypadku edycji obrazów zobacz [Edycja obrazów GPT Image 2 / 2.5 / 2.6](https://platform.acedata.cloud/documents/openai-images-edits).

## GPT Image 2.6

GPT Image 2.6 wykorzystuje interfejsy generowania, edycji, zadań asynchronicznych i rozliczeń z wersji 2.5:

| Model                                                          | Rozliczenie                               |
| ----------------------------------------------------------- | -------------------------------- |
| `gpt-image-2.6-flare` / `gpt-image-2.6-flare:reverse`       | 0.22 Credits/obraz                   |
| `gpt-image-2.6-sunburst` / `gpt-image-2.6-sunburst:reverse` | 0.22 Credits/obraz                   |
| `gpt-image-2.6-flare:official`                              | Takie samo jak official 2.5, rozliczane według rzeczywistego użycia Tokenów |
| `gpt-image-2.6-sunburst:official`                           | Takie samo jak official 2.5, rozliczane według rzeczywistego użycia Tokenów |

Dostępne wartości jakości to `auto`, `low`, `medium`, `high`, `xhigh`, `max`; dla rozmiaru użyj `auto` lub `WIDTHxHEIGHT` zgodnego z powyższymi ograniczeniami. Ten interfejs obsługuje `png`, `jpeg`, `webp`; GPT Image 2.6 obsługuje również natywne animacje `gif`, natomiast SVG nie jest obecnie obsługiwany. Edycja obsługuje adresy URL obrazów w JSON oraz przesyłanie plików multipart. `:reverse` jest jawnym aliasem zwykłej wersji o tej samej nazwie. Użyj pełnego oznaczenia modelu, nie przekazuj `gpt-image-2.6`.

### Animacje GIF GPT Image 2.6

Zwykła wersja Flare, `:reverse`, `:official` oraz `gpt-image-2.6-sunburst:official` mogą używać `output_format: "gif"`. Zwykła wersja Sunburst oraz `:reverse` nie udostępniają obecnie GIF, ale nadal obsługują generowanie i edycję obrazów statycznych. Klatki animacji, informacje o pętli i czas odtwarzania zostaną zachowane; `frame_count` oznacza liczbę klatek, a `frame_duration_ms` oznacza liczbę milisekund na klatkę — obie wartości muszą być dodatnimi liczbami całkowitymi i są używane wyłącznie dla GIF. Jeśli nie zostaną określone, domyślnie używanych jest 9 klatek po 200 milisekund każda; gdy `size` dla GIF zostanie pominięte lub ma wartość auto, używany jest preset 512x512.

Zaleca się najpierw użyć `size: "512x512"`, `frame_count: 9`, `frame_duration_ms: 200`. GIF ma niezależne ograniczenia rozmiaru i liczby klatek, dlatego nie można bezpośrednio stosować specyfikacji statycznego 4K; niektóre modele dostosują rzeczywisty rozmiar wyjściowy. `n` oznacza liczbę zwracanych plików GIF, a nie liczbę klatek animacji. Zwykła wersja i `:reverse` są nadal rozliczane według liczby pomyślnie wygenerowanych plików, natomiast wersja oficjalna według rzeczywistego użycia Tokenów.

```json
{
  "model": "gpt-image-2.6-flare",
  "prompt": "A small red ball moves left and right on a white background, seamless looping animation, no text.",
  "output_format": "gif",
  "size": "512x512",
  "quality": "medium",
  "frame_count": 9,
  "frame_duration_ms": 200,
  "n": 1,
  "async": true
}
```

### Statyczne obrazy 4K GPT Image 2.6

Flare, Sunburst oraz ich warianty `:reverse` i `:official` mogą korzystać z wyżej wymienionych presetów pikseli 4K, takich jak `3840x2160` i `2160x3840`. Zarówno generowanie, jak i edycja przekazują konkretne piksele przez `size`; `4K` nie jest prawidłową wartością `size`, a `4096x4096` również przekracza obecny limit pikseli. Powyższe specyfikacje 4K dotyczą statycznych PNG/JPEG/WebP; dla GIF użyj jego dedykowanych parametrów.
