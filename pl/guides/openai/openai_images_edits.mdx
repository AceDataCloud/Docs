## 2. Edycja przy użyciu adresu URL obrazu

Oryginalny obraz:

curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",

## 3. Przesyłanie lokalnego obrazu

Użyj `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Parametr `image` można przekazać wielokrotnie, a seria GPT Image obsługuje maksymalnie 16 obrazów referencyjnych. `image` w żądaniu JSON może być pojedynczym adresem URL lub tablicą adresów URL; pliki lokalne są przesyłane przez multipart.

### Modele i sposób rozliczania

| Model                                | Scenariusze zastosowania i sposób rozliczania                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Domyślny kanał odwrotny, stałe rozliczanie według liczby pomyślnie wygenerowanych obrazów                        |
| `gpt-image-2:reverse`             | Jawny wybór kanału odwrotnego, stałe rozliczanie według liczby pomyślnie wygenerowanych obrazów                      |
| `gpt-image-2:official`            | Oficjalny kanał API, wyższa stabilność, rozliczanie według faktycznego zużycia Tokenów            |
| `gpt-image-2.5-flare`             | Priorytet dla szybkości generowania, stałe rozliczanie według liczby pomyślnie wygenerowanych obrazów                        |
| `gpt-image-2.5-flare:official`    | Oficjalny kanał API, wyższa stabilność i priorytet dla szybkości generowania, rozliczanie według faktycznego zużycia Tokenów     |
| `gpt-image-2.5-sunburst`          | Priorytet dla wysokiej wierności i precyzyjnej kontroli, stałe rozliczanie według liczby pomyślnie wygenerowanych obrazów                    |
| `gpt-image-2.5-sunburst:official` | Oficjalny kanał API, wyższa stabilność oraz priorytet dla wysokiej wierności i precyzyjnej kontroli, rozliczanie według faktycznego zużycia Tokenów |

Cena wyświetlana dla oficjalnego kanału API jest szacowana przed wysłaniem żądania, a ostateczna wartość zależy od faktycznego zużycia Tokenów w odpowiedzi i historii użycia.

## 4. Edycja lokalna z użyciem maski

Oficjalny interfejs Images Edit określa obszar dozwolony do modyfikacji za pomocą `mask`. Modele Ace Data Cloud z `:official` przestrzegają tego samego kontraktu multipart:

- `mask` musi być plikiem PNG z kanałem Alpha o rozmiarze nie większym niż 4 MB;
- rozmiar maski musi być dokładnie taki sam jak pierwszego obrazu `image`;
- przezroczyste piksele o wartości Alpha równej `0` oznaczają obszary dozwolone do edycji, a nieprzezroczyste piksele oznaczają obszary, które należy zachować;
- obrazy RGB, które są jedynie czarno-białe, ale nie mają kanału przezroczystości, nie mogą być używane jako prawidłowe maski;
- prompt powinien opisywać oczekiwany kompletny obraz, jednocześnie jasno określając lokalne modyfikacje oraz zawartość, która ma pozostać niezmieniona.

Poniżej najpierw zostanie wygenerowana maska z oryginalnego obrazu. Przykład ustawia centralny prostokąt jako przezroczysty, pozwalając modelowi modyfikować wyłącznie ten obszar:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Następnie prześlij razem oryginalny obraz i maskę:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Można również użyć metody wywołania `images.edit` z oficjalnego Python SDK OpenAI, wystarczy wskazać Ace Data Cloud jako `base_url`:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Podczas używania `mask` oryginalny obraz i maska muszą zostać przesłane w tym samym żądaniu multipart, odpowiednio przez `image=@input.png` oraz `mask=@mask.png`. Nie mieszaj oryginalnego obrazu z adresu URL z lokalnym plikiem maski; żądania edycji wyłącznie z użyciem adresów URL nie obsługują dołączania lokalnego pliku `mask`. Maska ogranicza obszar edycji, ale model generatywny nadal może naturalnie łączyć krawędzie; gdy wymagane są ścisłe granice, należy użyć wyraźnych krawędzi Alpha i powtórzyć w prompcie, które elementy muszą pozostać niezmienione.

Powyższy sposób wywołania jest zgodny z przykładami masek w [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) oraz [oficjalnym Cookbooku GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).
## 5. Typowe parametry

| Pole                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiedni wariant `:official`, `gpt-image-2` obsługuje również `:reverse` |
| `image`           | JSON używa pojedynczego adresu URL lub tablicy zawierającej maksymalnie 16 adresów URL; multipart używa jednego lub większej liczby pól plików `image`. Podczas używania `mask` należy przesłać lokalny plik obrazu                                              |
| `mask`            | Opcjonalna maska PNG, wyłącznie do przesyłania plików multipart; musi zawierać kanał Alpha, mieć ten sam rozmiar co pierwszy `image` i nie przekraczać 4 MB                                                                 |
| `prompt`          | Instrukcja edycji                                                                                                                             |
| `size`            | `auto` lub zgodne z ograniczeniami `WIDTHxHEIGHT`                                                                                                     |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest tylko 1                                                                                           |
| `response_format` | `url` lub `b64_json`                                                                                                               |
| `callback_url`    | Opcjonalny adres asynchronicznego wywołania zwrotnego                                                                                                                         |

Zasady rozmiaru są zgodne z interfejsem generowania: szerokość i wysokość muszą być wielokrotnościami 16, dłuższy bok nie może przekraczać 3840, łączna liczba pikseli wynosi 655 360–8 294 400, a proporcje szerokości do wysokości nie mogą przekraczać 3:1. Po pominięciu `size` lub użyciu `auto` model wybierze format kadru na podstawie promptu i pierwszego obrazu referencyjnego.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz `gpt-image-2:reverse` są rozliczane według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywiście wykorzystanych tokenów wejścia tekstowego, wejścia obrazów referencyjnych i wyjścia obrazów, a ostatecznie obowiązuje zapis użycia.

## 6. Asynchroniczne wywołania zwrotne i rozwiązywanie problemów

Do długich zadań można dodać w żądaniu:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchroniczna odpowiedź 200 ma postać `{"task_id": "..."}`; po zakończeniu zostanie wywołany zwrotnie końcowy wynik. Żądania synchroniczne zwracają natomiast `created` i `data`.

| Status  | Sprawdź                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/liczbę obrazów, kombinację parametrów i format rozmiaru; podczas używania `mask` sprawdź kanał PNG Alpha, limit 4 MB oraz czy jego rozmiar jest zgodny z pierwszym oryginalnym obrazem |
| 401 | API Key i nagłówek Bearer                                           |
| 429 | Częstotliwość żądań                                                              |
| 504 | Użyj asynchronicznego wywołania zwrotnego                                                            |

Odpowiedź błędu będzie zawierać `trace_id`. Przy zgłaszaniu problemów podaj ten ID, nie podawaj API Key.

Pełne pola i aktualne wyliczenia znajdują się na stronie [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). W przypadku generowania obrazów z samego tekstu zobacz [Generowanie obrazów GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
