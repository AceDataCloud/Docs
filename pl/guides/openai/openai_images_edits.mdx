## 1. Uzyskanie API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskaj Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Edycja przy użyciu URL obrazu

Obraz oryginalny:

![Oryginalny obraz do edycji GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

Pomyślna odpowiedź:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

To jest wynik edycji faktycznie wykonanej za pośrednictwem Ace Data Cloud 8 września 2026 roku: kubek stał się pomarańczowy, tło stało się ciemnogranatowe, a oryginalna kompozycja i rozmiar 1024×1536 zostały zachowane:

![Wynik edycji pomarańczowego kubka GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Przesyłanie lokalnego obrazu

Użyj `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Możesz wielokrotnie przekazywać `image`; seria GPT Image obsługuje maksymalnie 16 obrazów referencyjnych. `image` w żądaniach JSON może być pojedynczym URL lub tablicą URL; pliki lokalne przesyła się za pomocą multipart.

## 4. Często używane parametry

| Pole                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiadający wariant `:official`, a `gpt-image-2` obsługuje także `:reverse` |
| `image`           | JSON używa pojedynczego URL lub tablicy maksymalnie 16 URL; multipart używa jednego lub wielu pól plików `image`                                                                    |
| `prompt`          | Instrukcja edycji                                                                                                                             |
| `size`            | `auto` lub `WIDTHxHEIGHT` zgodne z ograniczeniami                                                                                                     |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest tylko 1                                                                                           |
| `response_format` | `url` lub `b64_json`                                                                                                               |
| `callback_url`    | Opcjonalny adres asynchronicznego callbacku                                                                                                                         |

Reguły rozmiaru są takie same jak w interfejsie generowania: szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, łączna liczba pikseli wynosi 655,360–8,294,400, a współczynnik proporcji nie może przekraczać 3:1. Po pominięciu `size` lub użyciu `auto` model wybierze format obrazu na podstawie promptu i pierwszego obrazu referencyjnego.

Za `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz `gpt-image-2:reverse` naliczana jest opłata według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane według rzeczywistych Tokenów wejścia tekstowego, wejścia obrazu referencyjnego i wyjścia obrazu, a ostatecznym źródłem jest rejestr użycia.

## 5. Asynchroniczne callbacki i rozwiązywanie problemów

W przypadku długich zadań można dodać do żądania:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchroniczna odpowiedź 200 ma postać `{"task_id": "..."}`; po ukończeniu callback zwraca wynik końcowy. Żądania synchroniczne zwracają natomiast `created` i `data`.

| Status  | Sprawdź                      |
| --- | ----------------------- |
| 400 | Format/liczbę obrazów, kombinację parametrów i format rozmiaru       |
| 401 | API Key i Bearer Header |
| 429 | Częstotliwość żądań                    |
| 504 | Użyj asynchronicznego callbacku                  |

Odpowiedzi błędów zawierają `trace_id`. Przy zgłaszaniu problemów podaj ten ID, nie podawaj API Key.

Pełne pola i aktualne wyliczenia znajdują się na stronie [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). W przypadku generowania obrazu wyłącznie z tekstu zobacz [Generowanie obrazów GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
