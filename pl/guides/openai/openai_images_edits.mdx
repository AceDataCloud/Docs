## 2. Edycja przy użyciu URL obrazu

Obraz źródłowy:

![Obraz źródłowy do edycji GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://cdn.acedata.cloud/assets/examples/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0-18240dc44b9c.png",

```

## 3. Prześlij lokalny obraz

Użyj `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

`image` można przekazywać wielokrotnie, seria GPT Image obsługuje maksymalnie 16 obrazów referencyjnych. `image` w żądaniu JSON może być pojedynczym URL lub tablicą URL; lokalne pliki przesyła się przez multipart.

### Modele i sposób rozliczania

| Model                                | Zastosowania i sposób rozliczania                                        |
| --------------------------------- | ------------------------------------------------ |
| `gpt-image-2`                     | Domyślny kanał odwrotny, stałe rozliczanie za liczbę pomyślnie wygenerowanych obrazów                               |
| `gpt-image-2:reverse`             | Jawny wybór kanału odwrotnego, stałe rozliczanie za liczbę pomyślnie wygenerowanych obrazów                             |
| `gpt-image-2:official`            | Oficjalny kanał API, wyższa stabilność, rozliczanie według faktycznego zużycia Tokenów                   |
| `gpt-image-2.5-flare`             | Skupia się na szybkości generowania, stałe rozliczanie za liczbę pomyślnie wygenerowanych obrazów                               |
| `gpt-image-2.5-flare:reverse`     | Jawny alias odwrotny, równoważny z `gpt-image-2.5-flare`, stałe rozliczanie za liczbę pomyślnie wygenerowanych obrazów    |
| `gpt-image-2.5-flare:official`    | Oficjalny kanał API, wyższa stabilność i nacisk na szybkość generowania, rozliczanie według faktycznego zużycia Tokenów            |
| `gpt-image-2.5-sunburst`          | Skupia się na wysokiej wierności i precyzyjnej kontroli, stałe rozliczanie za liczbę pomyślnie wygenerowanych obrazów                           |
| `gpt-image-2.5-sunburst:reverse`  | Jawny alias odwrotny, równoważny z `gpt-image-2.5-sunburst`, stałe rozliczanie za liczbę pomyślnie wygenerowanych obrazów |
| `gpt-image-2.5-sunburst:official` | Oficjalny kanał API, wyższa stabilność oraz nacisk na wysoką wierność i precyzyjną kontrolę, rozliczanie według faktycznego zużycia Tokenów        |

Modele odwrotne (w tym aliasy `:reverse`) mogą podczas automatycznego odzyskiwania użyć GPT Image 2.5 Flare do wykonania żądania; model żądania i sposób rozliczania za liczbę pomyślnie wygenerowanych obrazów pozostają bez zmian.

Ceny na stronie dla oficjalnego kanału API są szacowane przed żądaniem, a ostateczna wartość zależy od faktycznego zużycia Tokenów w odpowiedzi i historii użycia.

`quality` obsługuje `auto`, `low`, `medium`, `high`; tylko `gpt-image-2.5-flare` i `gpt-image-2.5-sunburst` (w tym warianty `:reverse` i `:official`) dodatkowo obsługują `xhigh`, `max`. To pole można przekazać zarówno podczas edycji URL obrazu w JSON, jak i edycji pliku multipart; oficjalny kanał jest rozliczany według faktycznego zużycia Tokenów.

## 4. Użyj maski do lokalnej edycji

Oficjalny interfejs Images Edit używa `mask` do określenia obszaru, w którym dozwolone są modyfikacje. Modele `:official` Ace Data Cloud stosują ten sam kontrakt multipart:

- `mask` musi być plikiem PNG z kanałem Alpha, o rozmiarze nieprzekraczającym 4 MB;
- rozmiar maski musi być dokładnie taki sam jak pierwszego `image`;
- przezroczyste piksele z Alpha równą `0` oznaczają, że edycja jest dozwolona, a nieprzezroczyste piksele oznaczają, że należy je zachować;
- obrazy RGB zawierające tylko kolory czarny i biały, ale bez kanału przezroczystości, nie mogą być używane jako prawidłowe maski;
- prompt powinien opisywać oczekiwany pełny obraz, jednocześnie jasno określając lokalne modyfikacje i zawartość, która ma pozostać bez zmian.

Poniżej najpierw wygenerowano maskę z obrazu źródłowego. Przykład ustawia środkowy prostokąt jako przezroczysty, pozwalając modelowi modyfikować tylko ten obszar:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Następnie prześlij razem obraz źródłowy i maskę:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Można również zachować sposób wywołania `images.edit` z oficjalnego Python SDK OpenAI; wystarczy skierować `base_url` na Ace Data Cloud:
```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Podczas używania `mask` oryginalny obraz i maska muszą zostać przesłane osobno w tym samym żądaniu multipart za pomocą `image=@input.png` oraz `mask=@mask.png`. Nie należy mieszać oryginalnego obrazu URL z lokalnym plikiem maski; żądania edycji wyłącznie z URL nie obsługują dodatkowego dołączania lokalnego pliku `mask`. Maska ogranicza obszar edycji, ale model generujący nadal może naturalnie scalać krawędzie; gdy wymagane są ścisłe granice, należy użyć wyraźnych krawędzi Alpha i powtórzyć w promptcie, które treści muszą pozostać niezmienione.

Powyższy sposób wywołania jest zgodny z przykładami masek w [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) oraz [oficjalnym Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Często używane parametry

| Pole                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiedni wariant `:official`, a `gpt-image-2` obsługuje także `:reverse` |
| `image`           | JSON używa pojedynczego URL lub tablicy maksymalnie 16 URL; multipart używa jednego lub wielu pól plików `image`. Podczas używania `mask` należy przesłać lokalny plik obrazu                                              |
| `mask`            | Opcjonalna maska PNG, wyłącznie dla przesyłania plików multipart; musi mieć kanał Alpha, taki sam rozmiar jak pierwszy `image` i nie przekraczać 4 MB                                                                 |
| `prompt`          | Instrukcja edycji                                                                                                                             |
| `size`            | `auto` lub `WIDTHxHEIGHT` zgodne z ograniczeniami                                                                                                     |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest tylko 1                                                                                           |
| `response_format` | `url` lub `b64_json`                                                                                                               |
| `callback_url`    | Opcjonalny adres asynchronicznego wywołania zwrotnego                                                                                                                         |

Reguły rozmiaru są takie same jak dla interfejsu generowania: szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, całkowita liczba pikseli musi wynosić 655 360–8 294 400, a proporcje obrazu nie mogą przekraczać 3:1. Gdy `size` zostanie pominięte lub użyte zostanie `auto`, model wybierze format na podstawie promptu i pierwszego obrazu referencyjnego.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz ich aliasy `:reverse` są rozliczane według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywistych Tokenów wejścia tekstowego, wejścia obrazu referencyjnego i wyjścia obrazu, a ostatecznie obowiązują rekordy użycia.

## 6. Asynchroniczne wywołania zwrotne i rozwiązywanie problemów

W przypadku długich zadań można dodać do żądania:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchroniczna odpowiedź 200 ma postać `{"task_id": "..."}`; po ukończeniu wywoływany jest zwrotnie końcowy wynik. Żądania synchroniczne zwracają natomiast `created` i `data`.

| Status  | Sprawdź                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/liczbę obrazów, kombinacje parametrów i format rozmiaru; podczas używania `mask` sprawdź kanał PNG Alpha, limit 4 MB oraz czy jej rozmiar jest zgodny z pierwszym oryginalnym obrazem |
| 401 | API Key i Bearer Header                                           |
| 429 | Częstotliwość żądań                                                              |
| 504 | Użyj asynchronicznego wywołania zwrotnego                                                            |

Odpowiedzi błędów zawierają `trace_id`. Podczas zgłaszania problemu podaj ten ID, nie podawaj API Key.

Pełne pola i bieżące wartości wyliczeniowe znajdują się na stronie [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). W przypadku generowania obrazów z czystego tekstu zobacz [generowanie obrazów GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
