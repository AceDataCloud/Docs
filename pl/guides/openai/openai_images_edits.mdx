## 2. Edycja przy użyciu URL obrazu

Obraz oryginalny:

![Oryginalny obraz do edycji GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Keep the mug, tabletop, camera angle, portrait layout, and soft shadow unchanged. Change only the mug color from white to vivid orange and the pale cream background to solid dark navy blue. No text and no logo.",
    "size": "1024x1536"
  }'
```

## 3. Prześlij lokalny obraz

Użyj `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Można wielokrotnie przekazać `image`; seria GPT Image obsługuje maksymalnie 16 obrazów referencyjnych. Pole `image` w żądaniu JSON może być pojedynczym URL lub tablicą URL; lokalne pliki przesyła się za pomocą multipart.

## 4. Edycja lokalna z użyciem maski

Oficjalny interfejs Images Edit określa obszar dozwolony do modyfikacji za pomocą `mask`. Modele `:official` Ace Data Cloud stosują ten sam kontrakt multipart:

- `mask` musi być plikiem PNG z kanałem Alpha, o rozmiarze nie większym niż 4 MB;
- rozmiar maski musi być dokładnie taki sam jak pierwszego `image`;
- przezroczyste piksele z Alpha równym `0` oznaczają możliwość edycji, a nieprzezroczyste piksele oznaczają, że należy je zachować;
- obrazy RGB, które są tylko czarno-białe, ale nie mają kanału przezroczystości, nie mogą być używane jako prawidłowe maski;
- polecenie powinno opisywać oczekiwany kompletny obraz, jednocześnie wyraźnie określając lokalne modyfikacje i treści, które mają pozostać niezmienione.

Poniżej najpierw generowana jest maska z obrazu oryginalnego. Przykład ustawia środkowy prostokąt jako przezroczysty, zezwalając modelowi na modyfikację tylko tego obszaru:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Następnie prześlij razem obraz oryginalny i maskę:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Można również użyć sposobu wywołania `images.edit` z oficjalnego Python SDK OpenAI, wystarczy skierować `base_url` na Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```

Podczas używania `mask` obraz oryginalny i maska muszą zostać przesłane w tym samym żądaniu multipart osobno przez `image=@input.png` i `mask=@mask.png`. Nie mieszaj oryginalnego obrazu URL z lokalnym plikiem maski; czyste żądania edycji URL nie obsługują dodatkowego lokalnego pliku `mask`. Maska ogranicza obszar edycji, ale model generatywny może nadal naturalnie łączyć krawędzie; gdy wymagane są ścisłe granice, należy użyć wyraźnych krawędzi Alpha i wielokrotnie zaznaczyć w poleceniu, które treści muszą pozostać niezmienione.

Powyższy sposób wywołania jest zgodny z przykładami masek w [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) oraz [oficjalnym Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Często używane parametry

| Pole                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiadający wariant `:official`, a `gpt-image-2` obsługuje również `:reverse` |
| `image`           | JSON używa pojedynczego URL lub tablicy maksymalnie 16 URL; multipart używa jednego lub wielu pól plików `image`. Podczas używania `mask` należy przesłać lokalny plik obrazu                                              |
| `mask`            | Opcjonalna maska PNG, wyłącznie dla przesyłania plików multipart; musi mieć kanał Alpha, taki sam rozmiar jak pierwszy `image` i nie przekraczać 4 MB                                                                 |
| `prompt`          | Instrukcja edycji                                                                                                                             |
| `size`            | `auto` lub `WIDTHxHEIGHT` zgodne z ograniczeniami                                                                                                     |
| `n`               | 1–10; przy `response_format=b64_json` obsługiwane jest wyłącznie 1                                                                                           |
| `response_format` | `url` lub `b64_json`                                                                                                               |
| `callback_url`    | Opcjonalny adres asynchronicznego callbacku                                                                                                                         |
Zasady dotyczące rozmiaru są zgodne z interfejsem generowania: szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, łączna liczba pikseli wynosi 655 360–8 294 400, a proporcje obrazu nie mogą przekraczać 3:1. W przypadku pominięcia `size` lub użycia `auto` model wybierze format obrazu na podstawie promptu i pierwszego obrazu referencyjnego.

Za `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz `gpt-image-2:reverse` opłaty naliczane są według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywistej liczby Tokenów wejścia tekstowego, wejścia obrazów referencyjnych i wyjścia obrazu, a ostatecznym źródłem są zapisy użycia.

## 6. Asynchroniczne wywołania zwrotne i rozwiązywanie problemów

Do długich zadań można dodać w żądaniu:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchroniczna odpowiedź 200 ma postać `{"task_id": "..."}`; po ukończeniu następuje wywołanie zwrotne z końcowym wynikiem. Żądania synchroniczne zwracają natomiast `created` i `data`.

| Stan  | Sprawdź                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/liczbę obrazów, kombinację parametrów i format rozmiaru; podczas używania `mask` sprawdź kanał PNG Alpha, limit 4 MB oraz to, czy jego rozmiar jest zgodny z pierwszym obrazem źródłowym |
| 401 | API Key i Bearer Header                                           |
| 429 | Częstotliwość żądań                                                              |
| 504 | Użyj asynchronicznego wywołania zwrotnego                                                            |

Odpowiedź błędu będzie zawierać `trace_id`. Przy zgłaszaniu problemu podaj ten ID, nie podawaj API Key.

Pełne pola i bieżące wyliczenia znajdują się na stronie [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). W przypadku generowania obrazów wyłącznie z tekstu zobacz [Generowanie obrazów GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
