## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Edytuj za pomocą URL obrazu

Oryginalny obraz:

![Edycja oryginalnego obrazu GPT Image 2](https://cdn.acedata.cloud/18240dc44b9c.png)

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer twój klucz API" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "image": "https://platform2.cdn.acedata.cloud/gpt-image/d56455e2-e7f7-4bcd-b935-475b0a1e0948_0.png",
    "prompt": "Zachowaj kubek, stół, kąt kamery, układ portretowy i miękki cień bez zmian. Zmień tylko kolor kubka z białego na intensywny pomarańczowy, a jasnobeżowe tło na jednolity ciemnoniebieski. Bez tekstu i logo.",
    "size": "1024x1536"
  }'
```

Odpowiedź sukcesu:

```json
{
  "success": true,
  "task_id": "49848451-c624-4df9-9dc2-494018daaf4c",
  "trace_id": "5ac021c2-2891-4eed-bfcf-4c6668ac1be1",
  "created": 1788831893,
  "model": "gpt-image-2",
  "data": [
    {
      "url": "https://platform2.cdn.acedata.cloud/gpt-image/49848451-c624-4df9-9dc2-494018daaf4c_0.png"
    }
  ],
  "usage": {
    "input_tokens": 775,
    "output_tokens": 1372,
    "total_tokens": 2147
  }
}
```

To jest wynik edycji zrealizowanej 8 września 2026 roku przez Ace Data Cloud, kubek zmienił kolor na pomarańczowy, tło na ciemnoniebieskie, a oryginalna kompozycja i rozmiar 1024×1536 zostały zachowane:

![Wynik edycji pomarańczowego kubka GPT Image 2](https://cdn.acedata.cloud/b6d780a732ca.png)

## 3. Prześlij lokalny obraz

Użyj `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer twój klucz API" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Zamień tło na jasne nowoczesne studio"
```

Możesz wielokrotnie przekazywać `image`, seria GPT Image obsługuje maksymalnie 16 obrazów referencyjnych. W żądaniu JSON `image` może być pojedynczym URL lub tablicą URL; lokalne pliki używają przesyłania multipart.

## 4. Często używane parametry

| Pole                | Opis                                                            |
| ----------------- | ------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2:official` lub `gpt-image-2:reverse`  |
| `image`           | JSON używa pojedynczego URL lub maksymalnie 16 URL w tablicy; multipart używa jednego lub więcej pól plików `image` |
| `prompt`          | Instrukcje edycji                                                  |
| `size`            | `auto` lub zgodne z ograniczeniami `WIDTHxHEIGHT`                    |
| `n`               | 1–10; tylko 1 przy `response_format=b64_json`                     |
| `response_format` | `url` lub `b64_json`                                          |
| `callback_url`    | Opcjonalny adres do asynchronicznego wywołania                        |

Zasady dotyczące rozmiaru są zgodne z interfejsem generowania: szerokość i wysokość muszą być wielokrotnością 16, a dłuższy bok nie może przekraczać 3840, całkowita liczba pikseli nie może przekraczać 8 294 400. Pominięcie `size` lub użycie `auto` spowoduje, że model wybierze format na podstawie podpowiedzi i pierwszego obrazu referencyjnego.

Domyślnie `gpt-image-2` i `:reverse` są rozliczane na podstawie liczby udanych obrazów; `gpt-image-2:official` rozlicza na podstawie rzeczywistych tokenów wejściowych, obrazów referencyjnych i wyjściowych, ostatecznie według zapisów użycia.

## 5. Asynchroniczne wywołania zwrotne i rozwiązywanie problemów

Długie zadania mogą zawierać w żądaniu:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchroniczna odpowiedź 200 to `{"task_id": "..."}`; po zakończeniu wywołanie zwrotne zwraca ostateczny wynik. Żądania synchroniczne zwracają `created` i `data`.

| Status  | Sprawdzenie                      |
| --- | ----------------------- |
| 400 | Format/ilość obrazów, kombinacje parametrów i format rozmiaru       |
| 401 | Klucz API i nagłówek Bearer |
| 429 | Częstotliwość żądań                    |
| 504 | Użyj asynchronicznego wywołania                  |

Odpowiedzi z błędami będą zawierać `trace_id`. Podczas zgłaszania problemów podaj ten identyfikator, nie podawaj klucza API.

Pełne pola i bieżące wyliczenia są zgodne z dokumentem [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). Aby generować obrazy w formacie czystego tekstu, zapoznaj się z [GPT Image 2 generowanie obrazów](https://platform.acedata.cloud/documents/openai-images-generations).
