## 3. Przesyłanie lokalnego obrazu

Użyj `multipart/form-data`:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2" \
  -F "image=@input.png" \
  -F "prompt=Replace the background with a bright modern studio"
```

Możesz wielokrotnie przekazywać `image`; seria GPT Image obsługuje maksymalnie 16 obrazów referencyjnych. `image` w żądaniu JSON może być pojedynczym adresem URL lub tablicą adresów URL; lokalne pliki przesyłaj za pomocą multipart.

### Modele i sposób rozliczania

| Model                                | Zastosowania i sposób rozliczania                                 |
| --------------------------------- | ----------------------------------------- |
| `gpt-image-2`                     | Domyślny kanał reverse, stałe rozliczanie za liczbę pomyślnie utworzonych obrazów                        |
| `gpt-image-2:reverse`             | Jawny wybór kanału reverse, stałe rozliczanie za liczbę pomyślnie utworzonych obrazów                      |
| `gpt-image-2:official`            | Oficjalny kanał API, wyższa stabilność, rozliczanie według rzeczywistego zużycia Tokenów            |
| `gpt-image-2.5-flare`             | Skupienie na szybkości generowania, stałe rozliczanie za liczbę pomyślnie utworzonych obrazów                        |
| `gpt-image-2.5-flare:official`    | Oficjalny kanał API, wyższa stabilność i skupienie na szybkości generowania, rozliczanie według rzeczywistego zużycia Tokenów     |
| `gpt-image-2.5-sunburst`          | Skupienie na wysokiej wierności i precyzyjnej kontroli, stałe rozliczanie za liczbę pomyślnie utworzonych obrazów                    |
| `gpt-image-2.5-sunburst:official` | Oficjalny kanał API, wyższa stabilność oraz skupienie na wysokiej wierności i precyzyjnej kontroli, rozliczanie według rzeczywistego zużycia Tokenów |

Ceny na stronie dla oficjalnego kanału API są szacowane przed żądaniem, a ostateczna kwota jest ustalana na podstawie rzeczywistego zużycia Tokenów w odpowiedzi i historii użycia.

`quality` obsługuje `auto`, `low`, `medium`, `high`; tylko `gpt-image-2.5-flare` i `gpt-image-2.5-sunburst` (w tym warianty `:official`) dodatkowo obsługują `xhigh`, `max`. Zarówno edycja obrazu URL w JSON, jak i edycja pliku multipart mogą przekazywać to pole; oficjalne kanały są rozliczane według rzeczywistego zużycia Tokenów.

## 4. Lokalna edycja z użyciem maski

Oficjalny interfejs Images Edit używa `mask` do określenia obszaru, który można modyfikować. Modele `:official` Ace Data Cloud stosują ten sam kontrakt multipart:

- `mask` musi być plikiem PNG z kanałem Alpha, o rozmiarze nie większym niż 4 MB;
- rozmiar maski musi być dokładnie taki sam jak pierwszego `image`;
- przezroczyste piksele z Alpha równym `0` oznaczają możliwość edycji, a nieprzezroczyste piksele oznaczają, że należy je zachować;
- obrazy RGB zawierające tylko kolory czarny i biały, ale bez kanału przezroczystości, nie mogą być używane jako prawidłowe maski;
- prompt powinien opisywać oczekiwany pełny obraz, jednocześnie jasno określając lokalne modyfikacje i zawartość, która ma pozostać bez zmian.

Najpierw utwórz maskę na podstawie oryginalnego obrazu. Przykład ustawia środkowy prostokąt jako przezroczysty, pozwalając modelowi modyfikować tylko ten obszar:

```python
from PIL import Image, ImageDraw

source = Image.open("input.png").convert("RGBA")
mask = Image.new("RGBA", source.size, (0, 0, 0, 255))
draw = ImageDraw.Draw(mask)
width, height = source.size
draw.rectangle(
    (width // 4, height // 4, width * 3 // 4, height * 3 // 4),
    fill=(0, 0, 0, 0),
)
mask.save("mask.png")
```

Następnie prześlij razem oryginalny obraz i maskę:

```bash
curl https://api.acedata.cloud/openai/images/edits \
  -H "Authorization: Bearer 你的 API Key" \
  -F "model=gpt-image-2:official" \
  -F "image=@input.png" \
  -F "mask=@mask.png" \
  -F "prompt=Keep the composition, lighting, and all objects outside the transparent mask unchanged. Inside the masked area, replace the empty tabletop with a small blue ceramic vase."
```

Możesz również zachować sposób wywołania `images.edit` z oficjalnego Python SDK OpenAI — wystarczy wskazać `base_url` na Ace Data Cloud:

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.acedata.cloud/openai",
)

with open("input.png", "rb") as image, open("mask.png", "rb") as mask:
    result = client.images.edit(
        model="gpt-image-2:official",
        image=image,
        mask=mask,
        prompt=(
            "Keep the composition, lighting, and all objects outside the "
            "transparent mask unchanged. Inside the masked area, replace "
            "the empty tabletop with a small blue ceramic vase."
        ),
    )

print(result.data[0].url)
```
Podczas używania `mask` oryginalny obraz i maska muszą zostać przesłane osobno w tym samym żądaniu multipart za pomocą `image=@input.png` oraz `mask=@mask.png`. Nie przekazuj jednocześnie oryginalnego obrazu URL i lokalnego pliku maski; żądania edycji wyłącznie z URL nie obsługują dodatkowego dołączania lokalnego pliku `mask`. Maska ograniczy obszar edycji, lecz model generujący może nadal naturalnie scalać krawędzie; gdy wymagane są ścisłe granice, należy użyć wyraźnych krawędzi Alpha i wielokrotnie zaznaczyć w promptcie, które elementy muszą pozostać niezmienione.

Powyższy sposób wywołania jest zgodny z przykładami masek w [OpenAI Image Edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) oraz [oficjalnym Cookbook GPT Image](https://developers.openai.com/cookbook/examples/generate_images_with_gpt_image).

## 5. Często używane parametry

| Pole                | Opis                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `gpt-image-2`, `gpt-image-2.5-flare` (szybszy) lub `gpt-image-2.5-sunburst` (wyższa wierność i kontrola); wszystkie trzy mogą wybrać odpowiedni wariant `:official`, a `gpt-image-2` obsługuje również `:reverse` |
| `image`           | JSON używa pojedynczego URL lub tablicy zawierającej maksymalnie 16 URL; multipart używa jednego lub wielu pól plików `image`. Podczas używania `mask` należy przesłać lokalny plik obrazu                                              |
| `mask`            | Opcjonalna maska PNG, wyłącznie dla przesyłania plików multipart; musi zawierać kanał Alpha, mieć ten sam rozmiar co pierwszy `image` i nie przekraczać 4 MB                                                                 |
| `prompt`          | Instrukcja edycji                                                                                                                             |
| `size`            | `auto` lub `WIDTHxHEIGHT` zgodne z ograniczeniami                                                                                                     |
| `n`               | 1–10; w przypadku `response_format=b64_json` obsługiwane jest tylko 1                                                                                           |
| `response_format` | `url` lub `b64_json`                                                                                                               |
| `callback_url`    | Opcjonalny adres zwrotny asynchronicznego wywołania                                                                                                                         |

Zasady rozmiarów są zgodne z interfejsem generowania: szerokość i wysokość muszą być wielokrotnością 16, dłuższy bok nie może przekraczać 3840, łączna liczba pikseli wynosi 655 360–8 294 400, a proporcje szerokości do wysokości nie mogą przekraczać 3:1. Gdy `size` zostanie pominięte lub użyte zostanie `auto`, model wybierze format obrazu na podstawie promptu i pierwszego obrazu referencyjnego.

`gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` oraz `gpt-image-2:reverse` są rozliczane według liczby pomyślnie wygenerowanych obrazów; `gpt-image-2:official`, `gpt-image-2.5-flare:official` i `gpt-image-2.5-sunburst:official` są rozliczane na podstawie rzeczywistych Tokenów wejściowych tekstu, wejściowych obrazów referencyjnych i wyjściowych obrazów, a ostateczne dane są zgodne z rekordami użycia.

## 6. Asynchroniczne wywołania zwrotne i rozwiązywanie problemów

W przypadku długich zadań można dodać do żądania:

```json
{
  "callback_url": "https://example.com/webhooks/images"
}
```

Asynchroniczna odpowiedź 200 ma postać `{"task_id": "..."}`; po zakończeniu wywoływany jest zwrotnie końcowy wynik. Żądania synchroniczne zwracają natomiast `created` i `data`.

| Status  | Sprawdź                                                                |
| --- | ----------------------------------------------------------------- |
| 400 | Format/liczbę obrazów, kombinację parametrów i format rozmiaru; podczas używania `mask` sprawdź kanał PNG Alpha, limit 4 MB oraz czy jej rozmiar jest zgodny z pierwszym oryginalnym obrazem |
| 401 | API Key i Bearer Header                                           |
| 429 | Częstotliwość żądań                                                              |
| 504 | Użyj asynchronicznego wywołania zwrotnego                                                            |

Odpowiedzi błędów zawierają `trace_id`. Przy zgłaszaniu problemów podaj ten ID, nie podawaj API Key.

Pełne pola i aktualne wyliczenia znajdują się na stronie [OpenAI Images Edits API](https://platform.acedata.cloud/documents/openai-images-edits). W przypadku generowania obrazów z samego tekstu zobacz [Generowanie obrazów GPT Image 2 / 2.5](https://platform.acedata.cloud/documents/openai-images-generations).
