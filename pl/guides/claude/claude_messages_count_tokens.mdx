Claude Messages Count Tokens API może, bez faktycznego tworzenia wiadomości, obliczyć liczbę wejściowych Tokenów jednej Message, w tym liczbę Tokenów dla narzędzi, obrazów i dokumentów oraz innych treści. Jest to bardzo przydatne, gdy trzeba oszacować koszty lub sprawdzić, czy dane wejściowe przekraczają limit kontekstu modelu.

Ten dokument przedstawia głównie proces korzystania z Claude Messages Count Tokens API.

## Proces składania wniosku

Aby używać Claude Messages Count Tokens API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, nastąpi automatyczne przekierowanie na stronę logowania, która zaprosi Cię do rejestracji i zalogowania się; po zakończeniu automatycznie wrócisz na bieżącą stronę.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, bez konieczności osobnego składania wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz bezpłatne środki, aby korzystać bezpłatnie; gdy środki będą niewystarczające, możesz doładować wspólne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Podstawowe użycie

Ścieżka żądania Claude Messages Count Tokens API to `/v1/messages/count_tokens`, zgodna z oficjalnym API Anthropic. Musimy podać co najmniej dwa wymagane parametry:

- `model`: wybór używanego modelu Claude; `claude-opus-5-5` może być używany do Messages Token Count, podobnie jak najnowszy flagowy `claude-fable-5-1`; poprzedni `claude-fable-5` nadal jest zachowany dla kompatybilności.
- `messages`: tablica wejściowych wiadomości, gdzie każda wiadomość zawiera `role` (rolę) i `content` (treść).

Często używane parametry opcjonalne:

- `system`: systemowy prompt, który będzie wliczany do liczby Tokenów.
- `tools`: definicje narzędzi, które będą wliczane do liczby Tokenów.
- `thinking`: konfiguracja rozszerzonego myślenia.
- `tool_choice`: konfiguracja wyboru narzędzia.
- `cache_control`: konfiguracja kontroli pamięci podręcznej na poziomie najwyższym lub bloku treści.

`messages`, `system`, odtwarzanie wywołań narzędzi, obrazy URL oraz bloki treści document/PDF używają tej samej stabilnej struktury żądań co Messages API.

### Przykład cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Przykład Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Przykład zwróconego wyniku:

```json
{
  "input_tokens": 11
}
```

### Korzystanie z Anthropic SDK

Claude Messages Count Tokens API akceptuje stabilną strukturę żądań Anthropic SDK i może być wywoływane za pomocą biblioteki `anthropic`. Interfejs wykorzystuje natywną możliwość Count Tokens odpowiadającą wybranemu modelowi do zliczania danych wejściowych i może być używany do sprawdzania rozmiaru danych wejściowych przed wysłaniem żądania Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów zawierających narzędzia

Jeśli Twoje żądanie zawiera definicje narzędzi, narzędzia te również zostaną wliczone do liczby Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów zawierających systemowy prompt

Systemowy prompt również zostanie wliczony do liczby Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Uwagi

- To API oblicza wyłącznie liczbę wejściowych Tokenów i nie wygeneruje żadnego wyjścia modelu.
- Wynik liczenia Tokenów może być używany do szacowania rozmiaru danych wejściowych i sprawdzania okna kontekstu; ostateczne rozliczenie opiera się na `usage` w rzeczywistej odpowiedzi Messages.
- Obrazy, PDF-y, definicje narzędzi, systemowe prompty oraz konfiguracje thinking będą wliczane do wyniku zgodnie z zasadami wejściowymi wybranego modelu.
- To API jest całkowicie bezpłatne i nie zużywa żadnych środków.
