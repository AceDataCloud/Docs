API Claude Messages Count Tokens może obliczać liczbę wejściowych Tokenów dla pojedynczej Message bez faktycznego tworzenia wiadomości, w tym liczbę Tokenów dla narzędzi, obrazów i dokumentów oraz innych treści. Jest to bardzo przydatne, gdy trzeba oszacować koszty lub sprawdzić, czy dane wejściowe przekraczają limit kontekstu modelu.

Ten dokument przedstawia głównie proces używania API Claude Messages Count Tokens.

`claude-fable-5-2` obecnie nie udostępnia interfejsu Count Tokens. Ostateczne użycie wygenerowanych żądań można sprawdzić w `usage` odpowiedzi Messages; nie należy używać wyników liczenia innych modeli jako zamiennika dokładnego użycia tego modelu.

## Proces składania wniosku

Aby używać API Claude Messages Count Tokens, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, nastąpi automatyczne przekierowanie na stronę logowania z zaproszeniem do rejestracji i logowania, a po zakończeniu automatycznie wrócisz na bieżącą stronę.

**Jeden API Token pozwala wywoływać wszystkie usługi platformy, bez konieczności składania osobnego wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz darmowy limit, umożliwiający bezpłatne wypróbowanie; gdy limit jest niewystarczający, możesz doładować wspólne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Podstawowe użycie

Ścieżka żądania API Claude Messages Count Tokens to `/v1/messages/count_tokens`, zgodna z oficjalnym API Anthropic. Musimy podać co najmniej dwa wymagane parametry:

- `model`: wpisz pełny ID modelu z listy modeli tego interfejsu i użyj tego samego modelu w kolejnych żądaniach Messages.
- `messages`: tablica wejściowych wiadomości, gdzie każda wiadomość zawiera `role` (rolę) i `content` (treść).

Często używane parametry opcjonalne:

- `system`: komunikat systemowy, który będzie wliczany do liczby Tokenów.
- `tools`: definicje narzędzi, które będą wliczane do liczby Tokenów.
- `thinking`: konfiguracja rozszerzonego myślenia.
- `tool_choice`: konfiguracja wyboru narzędzi.
- `cache_control`: konfiguracja kontroli pamięci podręcznej na poziomie najwyższym lub bloku treści.

`messages`, `system`, odtwarzanie wywołań narzędzi, obrazy URL oraz bloki treści document/PDF używają tej samej stabilnej struktury żądania co API Messages.

### Przykład cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Przykład Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Przykład wyniku zwracanego:

```json
{
  "input_tokens": 11
}
```

### Używanie Anthropic SDK

API Claude Messages Count Tokens akceptuje stabilną strukturę żądań Anthropic SDK i może być wywoływane za pomocą biblioteki `anthropic`. Interfejs liczy wejściowe Tokeny według wybranego modelu i może być używany do sprawdzania rozmiaru danych wejściowych przed wysłaniem żądania Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów zawierających narzędzia

Jeśli Twoje żądanie zawiera definicje narzędzi, te narzędzia również zostaną wliczone do liczby Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów zawierających komunikaty systemowe

Komunikaty systemowe również będą wliczane do liczby Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Uwagi

- To API oblicza wyłącznie liczbę wejściowych Tokenów i nie wygeneruje żadnego wyjścia modelu.
- Wyniki liczenia Tokenów mogą być używane do szacowania rozmiaru danych wejściowych i sprawdzania okna kontekstu; ostateczne rozliczenie opiera się na `usage` w rzeczywistej odpowiedzi Messages.
- Obrazy, PDF-y, definicje narzędzi, komunikaty systemowe i konfiguracja thinking będą wliczane do wyniku zgodnie z regułami wejściowymi wybranego modelu.
- To API jest całkowicie bezpłatne i nie zużywa żadnego limitu.
