API Claude Messages Count Tokens może obliczać liczbę wejściowych Tokenów w Message bez faktycznego tworzenia wiadomości, w tym liczbę Tokenów dla narzędzi, obrazów i dokumentów oraz innych treści. Jest to bardzo przydatne, gdy trzeba oszacować koszty lub sprawdzić, czy dane wejściowe przekraczają limit kontekstu modelu.

Ten dokument głównie przedstawia proces korzystania z API Claude Messages Count Tokens.

## Proces składania wniosku

Aby korzystać z API Claude Messages Count Tokens, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, gdzie zostaniesz zaproszony do rejestracji i zalogowania się, a po zakończeniu automatycznie powrócisz na bieżącą stronę.

**Jeden API Token może wywoływać wszystkie usługi platformy, nie ma potrzeby składania osobnego wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz darmowy limit, aby móc korzystać bezpłatnie; gdy limit jest niewystarczający, możesz doładować uniwersalne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Podstawowe użycie

Ścieżka żądania API Claude Messages Count Tokens to `/v1/messages/count_tokens`, zgodnie z oficjalnym API Anthropic. Musimy podać co najmniej dwa wymagane parametry:

- `model`: wybierz używany model Claude, np. najnowszy flagowy `claude-fable-5-1`; poprzedni `claude-fable-5` nadal jest zachowany jako kompatybilny.
- `messages`: tablica wejściowych wiadomości, każda wiadomość zawiera `role` (rolę) i `content` (treść).

Często używane opcjonalne parametry:

- `system`: systemowy prompt, będzie wliczany do liczby Tokenów.
- `tools`: definicje narzędzi, będą wliczane do liczby Tokenów.
- `thinking`: konfiguracja rozszerzonego myślenia.
- `tool_choice`: konfiguracja wyboru narzędzia.
- `cache_control`: konfiguracja kontroli pamięci podręcznej na poziomie głównym lub bloku treści.

`messages`, `system`, odtwarzanie wywołań narzędzi, obrazy URL oraz bloki treści document/PDF używają tej samej stabilnej struktury żądania co Messages API.

### Przykład cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Przykład Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Przykład zwracanego wyniku:

```json
{
  "input_tokens": 11
}
```

### Korzystanie z Anthropic SDK

API Claude Messages Count Tokens akceptuje stabilną strukturę żądania Anthropic SDK i może być wywoływane za pomocą biblioteki `anthropic`. Interfejs wykorzystuje natywną funkcję Count Tokens odpowiadającą wybranemu modelowi do zliczania danych wejściowych i może być używany do sprawdzania rozmiaru danych wejściowych przed wysłaniem żądania Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów z narzędziami

Jeśli twoje żądanie zawiera definicje narzędzi, te narzędzia również będą wliczane do liczby Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów z systemowym promptem

Systemowy prompt również będzie wliczany do liczby Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Uwagi

- To API oblicza jedynie liczbę wejściowych Tokenów i nie wygeneruje żadnego wyjścia modelu.
- Wynik liczenia Tokenów może być używany do oszacowania rozmiaru danych wejściowych i sprawdzania okna kontekstu; ostateczne rozliczenie opiera się na `usage` w rzeczywistej odpowiedzi Messages.
- Obrazy, PDF-y, definicje narzędzi, systemowe prompty i konfiguracja thinking będą wliczane do wyniku zgodnie z regułami wejściowymi wybranego modelu.
- To API jest całkowicie bezpłatne i nie zużywa żadnego limitu.
