API Claude Messages Count Tokens może, bez faktycznego tworzenia wiadomości, obliczyć liczbę wejściowych Tokenów jednej wiadomości Message, w tym liczenie Tokenów dla narzędzi, obrazów i dokumentów oraz innych treści. Jest to bardzo przydatne, gdy trzeba oszacować koszt lub sprawdzić, czy dane wejściowe przekraczają limit kontekstu modelu.

Ten dokument przedstawia głównie proces użycia API Claude Messages Count Tokens.

## Proces składania wniosku

Aby użyć API Claude Messages Count Tokens, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go na później.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, nastąpi automatyczne przekierowanie do strony logowania z zaproszeniem do rejestracji i logowania; po ukończeniu nastąpi automatyczny powrót na bieżącą stronę.

**Jeden API Token może wywoływać wszystkie usługi platformy, bez potrzeby osobnego składania wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz bezpłatny limit, umożliwiający darmowe wypróbowanie usługi; gdy limit jest niewystarczający, możesz doładować uniwersalne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Podstawowe użycie

Ścieżka żądania API Claude Messages Count Tokens to `/v1/messages/count_tokens`, zgodna z oficjalnym API Anthropic. Musimy podać co najmniej dwa wymagane parametry:

- `model`: wybór używanego modelu Claude; `claude-opus-5-5` może być używany do Messages Token Count, podobnie jak najnowszy flagowy `claude-fable-5-1`; poprzedni `claude-fable-5` nadal pozostaje kompatybilny. `claude-sonnet-5-5` został dodany do natywnego interfejsu serii Messages, obsługuje wejście obrazu i adaptacyjne myślenie; jego oficjalne ceny referencyjne za wejście, wyjście i odczyt cache wynoszą odpowiednio 2, 10 i 0,20 USD za milion Tokenów.
- `messages`: tablica wejściowych wiadomości, gdzie każda wiadomość zawiera `role` (rolę) i `content` (treść).

Często używane parametry opcjonalne:

- `system`: systemowy prompt, będzie uwzględniony w liczbie Tokenów.
- `tools`: definicje narzędzi, będą uwzględnione w liczbie Tokenów.
- `thinking`: konfiguracja rozszerzonego myślenia.
- `tool_choice`: konfiguracja wyboru narzędzia.
- `cache_control`: konfiguracja kontroli cache na poziomie głównym lub bloku treści.

`messages`, `system`, odtwarzanie wywołań narzędzi, obrazy URL i bloki treści document/PDF używają takiej samej stabilnej struktury żądań jak API Messages.

### Przykład cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Przykład Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Przykład wyniku zwracanego:

```json
{
  "input_tokens": 11
}
```

### Użycie Anthropic SDK

API Claude Messages Count Tokens akceptuje stabilną strukturę żądań Anthropic SDK i może być wywoływane za pomocą biblioteki `anthropic`. Interfejs używa natywnej funkcji Count Tokens odpowiadającej wybranemu modelowi do obliczania danych wejściowych i może być używany do sprawdzania rozmiaru wejścia przed wysłaniem żądania Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów z narzędziami

Jeśli Twoje żądanie zawiera definicje narzędzi, te narzędzia również zostaną uwzględnione w liczbie Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów z systemowym promptem

Systemowy prompt również zostanie uwzględniony w liczbie Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Uwagi

- To API oblicza wyłącznie liczbę wejściowych Tokenów i nie generuje żadnego wyjścia modelu.
- Wynik liczenia Tokenów może być używany do oszacowania rozmiaru wejścia i sprawdzenia okna kontekstu; końcowe rozliczenie opiera się na `usage` w rzeczywistej odpowiedzi Messages.
- Obrazy, PDF-y, definicje narzędzi, systemowe prompty i konfiguracja thinking zostaną uwzględnione w wyniku zgodnie z regułami wejściowymi wybranego modelu.
- To API jest całkowicie bezpłatne i nie zużywa żadnego limitu.
