Claude Messages Count Tokens API może obliczać liczbę wejściowych Tokenów dla jednej Message bez faktycznego tworzenia wiadomości, w tym liczbę Tokenów dla narzędzi, obrazów i dokumentów. Jest to bardzo przydatne, gdy trzeba oszacować koszty lub sprawdzić, czy dane wejściowe przekraczają limit kontekstu modelu.

Niniejszy dokument przedstawia głównie proces korzystania z Claude Messages Count Tokens API.

## Proces składania wniosku

Aby korzystać z Claude Messages Count Tokens API, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój API Token i zachować go do późniejszego użycia.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, która zaprosi Cię do rejestracji i logowania, a po zakończeniu automatycznie powrócisz na bieżącą stronę.

**Jeden API Token umożliwia wywoływanie wszystkich usług platformy, bez konieczności składania osobnego wniosku dla każdej usługi.** Przy pierwszym wniosku otrzymasz darmowy limit, który pozwala na bezpłatne wypróbowanie usługi; gdy limit jest niewystarczający, możesz doładować uniwersalne saldo w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [Claude Messages Count Tokens API →](https://platform.acedata.cloud/documents/claude-messages-count-tokens)

## Podstawowe użycie

Ścieżka żądania Claude Messages Count Tokens API to `/v1/messages/count_tokens`, zgodna z oficjalnym API Anthropic. Musimy podać co najmniej dwa wymagane parametry:

- `model`: wypełnij pełny identyfikator modelu z listy modeli tego interfejsu i użyj tego samego modelu w kolejnych żądaniach Messages.
- `messages`: tablica wejściowych wiadomości, gdzie każda wiadomość zawiera `role` (rolę) i `content` (treść).

Często używane parametry opcjonalne:

- `system`: systemowy prompt, który zostanie uwzględniony w liczbie Tokenów.
- `tools`: definicje narzędzi, które zostaną uwzględnione w liczbie Tokenów.
- `thinking`: rozszerzona konfiguracja myślenia.
- `tool_choice`: konfiguracja wyboru narzędzia.
- `cache_control`: konfiguracja kontroli pamięci podręcznej na poziomie głównym lub bloku treści.

`messages`, `system`, odtwarzanie wywołań narzędzi, obrazy URL oraz bloki treści document/PDF używają tej samej stabilnej struktury żądania co Messages API.

### Przykład cURL

```bash
curl -X POST 'https://api.acedata.cloud/v1/messages/count_tokens' \
  -H 'accept: application/json' \
  -H 'authorization: Bearer {token}' \
  -H 'content-type: application/json' \
  -d '{
    "model": "claude-fable-5-1",
    "messages": [
      {
        "role": "user",
        "content": "Hello, Claude"
      }
    ]
  }'
```

### Przykład Python

```python
import httpx

url = "https://api.acedata.cloud/v1/messages/count_tokens"
headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json",
}
payload = {
    "model": "claude-fable-5-1",
    "messages": [
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
}
response = httpx.post(url, headers=headers, json=payload)
print(response.json())
```

Przykład wyniku zwracanego:

```json
{
  "input_tokens": 11
}
```

### Korzystanie z Anthropic SDK

Claude Messages Count Tokens API akceptuje stabilną strukturę żądania Anthropic SDK i może być wywoływane za pomocą biblioteki `anthropic`. Interfejs liczy wejściowe Tokeny według wybranego modelu i może być używany do sprawdzania rozmiaru danych wejściowych przed wysłaniem żądania Messages.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="{token}",
    base_url="https://api.acedata.cloud",
)

result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "Hello, Claude"
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów zawierających narzędzia

Jeśli Twoje żądanie zawiera definicje narzędzi, te narzędzia również zostaną uwzględnione w liczbie Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    messages=[
        {
            "role": "user",
            "content": "What is the weather in San Francisco?"
        }
    ],
    tools=[
        {
            "name": "get_weather",
            "description": "Get the current weather in a given location",
            "input_schema": {
                "type": "object",
                "properties": {
                    "location": {
                        "type": "string",
                        "description": "The city and state, e.g. San Francisco, CA"
                    }
                },
                "required": ["location"]
            }
        }
    ],
)
print(result.input_tokens)
```

## Liczenie Tokenów zawierających systemowy prompt

Systemowy prompt również zostanie uwzględniony w liczbie Tokenów:

```python
result = client.messages.count_tokens(
    model="claude-opus-4-8",
    system="You are a helpful assistant that speaks Chinese.",
    messages=[
        {
            "role": "user",
            "content": "Hello"
        }
    ],
)
print(result.input_tokens)
```

## Uwagi

- To API oblicza wyłącznie liczbę wejściowych Tokenów i nie generuje żadnego wyjścia modelu.
- Wynik liczenia Tokenów może być używany do szacowania rozmiaru danych wejściowych i sprawdzania okna kontekstowego; ostateczne rozliczenie opiera się na `usage` w rzeczywistej odpowiedzi Messages.
- Obrazy, pliki PDF, definicje narzędzi, systemowe prompty i konfiguracja thinking zostaną uwzględnione w wyniku zgodnie z zasadami wejściowymi wybranego modelu.
- To API jest całkowicie bezpłatne i nie zużywa żadnego limitu.
