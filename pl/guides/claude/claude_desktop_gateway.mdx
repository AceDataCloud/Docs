Ten przewodnik konfiguruje **Third-Party Inference Gateway** w Claude Desktop, a nie Claude Code ani MCP Connector w Claude Desktop.

## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskaj Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Otwórz konfigurację wnioskowania innej firmy

Na stronie logowania Claude Desktop kolejno otwórz **Help → Troubleshooting → Enable Developer Mode**, a następnie wybierz **Developer → Configure Third-Party Inference…**.

![Claude Desktop — otwieranie Third-Party Inference](https://cdn.acedata.cloud/713ffd7104a3.png)

> Obraz pochodzi z repozytorium Bifrost Apache-2.0 i służy wyłącznie do wskazania menu Claude Desktop; interfejs różnych wersji może nieznacznie się różnić.

## 3. Skonfiguruj Gateway

Wybierz **Gateway**, a następnie wypełnij:

| Pole                  | Wartość                     |
| ------------------- | --------------------------- |
| Gateway base URL    | `https://api.acedata.cloud` |
| Gateway API key     | Skopiowany przed chwilą API Key |
| Gateway auth scheme | `bearer`                    |
| Credential kind     | `Static API key`            |

![Ekran konfiguracji Claude Desktop Gateway](https://cdn.acedata.cloud/68d41fe682cb.png)

Kliknij **Apply Changes**, a następnie **Save & Restart**.

## 4. Weryfikacja

Po ponownym uruchomieniu wybierz dostępny model, utwórz nową rozmowę i wyślij `Reply only OK`, a następnie wykonaj proste zadanie narzędziowe. Historię wywołań można sprawdzić w [historii użycia](https://platform.acedata.cloud/console/usages).

Ace Data Cloud Gateway obsługuje używane przez Claude Desktop `/v1/models`, strumieniowe `/v1/messages` z uwierzytelnianiem Bearer, wywołania narzędzi oraz kontynuację `tool_result`. Pola pamięci podręcznej promptów zostaną zachowane; wartości zapisu i odczytu pamięci podręcznej równe 0 nie oznaczają, że nastąpiło trafienie pamięci podręcznej.

401 zwykle oznacza, że Key jest nieprawidłowy; jeśli nie można znaleźć modelu, ponownie sprawdź konfigurację i całkowicie uruchom ponownie Claude Desktop. Podczas zgłaszania problemów podaj trace ID z historii wywołań, nie podawaj API Key.
