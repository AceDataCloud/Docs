Ten dokument przedstawia instrukcję integracji Grok Videos Generation API, które umożliwia generowanie wideo Grok Imagine (xAI) na podstawie tekstowych promptów, obrazów wejściowych oraz opcjonalnych obrazów referencyjnych.

## Proces rejestracji

Aby korzystać z API, należy najpierw zarejestrować się na stronie [Grok Videos Generation API](https://platform.acedata.cloud/documents/grok-videos). Po wejściu na stronę kliknij przycisk „Acquire”, jak pokazano na obrazku:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jeśli nie jesteś zalogowany lub zarejestrowany, zostaniesz automatycznie przekierowany do strony logowania, gdzie możesz się zarejestrować i zalogować. Po zalogowaniu wrócisz automatycznie na tę stronę.

Przy pierwszym wniosku otrzymasz darmowy limit, który pozwala na bezpłatne korzystanie z API.

## Opis modeli

API obsługuje dwa modele:

- `grok-imagine-video-1.5-fast` (domyślny): obsługuje generowanie wideo z tekstu (tylko `prompt`) oraz z obrazu (podając `image_url`), jest tańszy.
- `grok-imagine-video-1.5`: obsługuje tylko generowanie wideo z obrazu, **wymaga** podania `image_url`.

## Podstawowe użycie

Najpierw zapoznaj się z podstawowym sposobem użycia: podając prompt `prompt`, model `model` i inne parametry, możesz wygenerować odpowiednie wideo.

W nagłówkach żądania (Request Headers) ustawiamy:

- `accept`: format odpowiedzi, tutaj `application/json` (format JSON).
- `authorization`: klucz API do wywołania, który można wybrać po rejestracji.

W ciele żądania (Request Body) ustawiamy:

- `prompt`: tekstowy prompt opisujący treść wideo. W przypadku modelu `grok-imagine-video-1.5-fast` przy generowaniu wideo z tekstu jest **wymagany**; przy podaniu `image_url` jest opcjonalny.
- `model`: model generujący wideo, opcje to `grok-imagine-video-1.5-fast` (domyślny) lub `grok-imagine-video-1.5`.
- `image_url`: URL obrazu wejściowego do generowania wideo z obrazu. Przy modelu `grok-imagine-video-1.5` jest **wymagany**.
- `reference_image_urls`: opcjonalna tablica URL-i obrazów referencyjnych, które służą do nakierowania stylu lub treści wideo.
- `aspect_ratio`: proporcje obrazu wideo, opcje: `1:1` / `16:9` / `9:16` / `4:3` / `3:4` / `3:2` / `2:3`.
- `resolution`: rozdzielczość wyjściowa, opcje: `480p` (domyślna) lub `720p`. Wyższa rozdzielczość zużywa więcej limitu.
- `duration`: długość wideo w sekundach, zakres 1–15, domyślnie 8. Opłata naliczana jest za liczbę sekund.
- `callback_url`: adres URL do asynchronicznego callbacku. Po ustawieniu API zwraca natychmiast `task_id`, a po zakończeniu zadania wynik zostanie przesłany metodą POST na ten adres.

Kliknij przycisk „Try”, aby przetestować, wynik będzie podobny do poniższego:

```json
{
  "success": true,
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea",
  "trace_id": "fb751e1e-4705-49ea-9fd4-5024b7865ea2",
  "data": [
    {
      "id": "grok-imagine-video-1.5-fast:41eb9a5f-3b2d-4d1e-9f5a-6c2f1a0b9e77",
      "video_url": "https://cdn.acedata.cloud/c8cbf53aa0.mp4",
      "state": "succeeded"
    }
  ]
}
```

Odpowiedź zawiera następujące pola:

- `success`: czy żądanie generowania wideo zakończyło się sukcesem.
- `task_id`: ID zadania generowania wideo.
- `trace_id`: ID śledzenia żądania, pomocne przy debugowaniu.
- `data`: lista wyników wygenerowanych wideo.
  - `id`: unikalny identyfikator wygenerowanego wideo.
  - `video_url`: URL do wygenerowanego wideo.
  - `state`: status zadania, możliwe wartości: `pending` / `succeeded` / `failed`.

Wystarczy pobrać wideo pod adresem `video_url` z pola `data`.

Przykładowy kod CURL:

```shell
curl -X POST 'https://api.acedata.cloud/grok/videos' \
-H 'authorization: Bearer ${bearer_token}' \
-H 'accept: application/json' \
-H 'content-type: application/json' \
-d '{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "resolution": "480p",
  "duration": 8
}'
```

Przykładowy kod Python:

```python
import requests

url = "https://api.acedata.cloud/grok/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
    "model": "grok-imagine-video-1.5-fast",
    "resolution": "480p",
    "duration": 8
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

## Generowanie wideo z obrazu

Jeśli chcesz wygenerować wideo na podstawie obrazu wejściowego, podaj `image_url`. Przy użyciu modelu `grok-imagine-video-1.5` jest to pole **wymagane**:

```json
{
  "prompt": "The character slowly turns around and smiles at the camera",
  "model": "grok-imagine-video-1.5",
  "image_url": "https://cdn.acedata.cloud/5hmkdg.jpg",
  "resolution": "720p",
  "duration": 8
}
```

## Sterowanie stylem za pomocą obrazów referencyjnych

Aby nakierować styl lub treść generowanego wideo za pomocą jednego lub więcej obrazów referencyjnych, przekaż tablicę URL-i w polu `reference_image_urls`:

```json
{
  "prompt": "A character dancing in the same art style",
  "model": "grok-imagine-video-1.5-fast",
  "reference_image_urls": [
    "https://cdn.acedata.cloud/vunnjf.png"
  ]
}
```

## Asynchroniczny callback

Generowanie wideo wymaga czasu. Jeśli nie chcesz utrzymywać połączenia, możesz podać `callback_url`. Wtedy API zwróci natychmiast `task_id`, a po zakończeniu zadania wynik zostanie przesłany metodą POST na ten adres:

```json
{
  "prompt": "A cinematic shot of a kitten chasing a butterfly in a sunlit garden",
  "model": "grok-imagine-video-1.5-fast",
  "duration": 8,
  "callback_url": "https://your-domain.com/callback/grok"
}
```

Natychmiastowa odpowiedź będzie wyglądać tak:

```json
{
  "task_id": "b8976e18-32dc-4718-9ed8-1ea090fcb6ea"
}
```

## Sprawdzanie statusu zadania

Jeśli korzystasz z asynchronicznego callbacku lub chcesz samodzielnie sprawdzić status zadania, możesz użyć [Grok Tasks API](https://platform.acedata.cloud/documents/grok-tasks) (`POST https://api.acedata.cloud/grok/tasks`) z `task_id`, aby uzyskać aktualny status i wynik.

## Informacje o rozliczeniach

Usługa nalicza opłatę za „liczbę sekund wyjściowego wideo”. Cena zależy od `model` i `resolution`. Całkowity koszt = cena jednostkowa × `duration` (domyślnie 8 sekund). `720p` jest droższe niż `480p`, a `grok-imagine-video-1.5` jest droższy niż `grok-imagine-video-1.5-fast`. Szczegółowe ceny znajdują się na stronie cennika.

## Obsługa błędów

W przypadku problemów API zwraca odpowiedni kod błędu i opis. Najczęstsze to:

- `400`: błędne parametry, np. brak `prompt` przy generowaniu z tekstu, brak `image_url` przy `grok-imagine-video-1.5`, lub `duration` poza zakresem 1–15.
- `401`: błąd uwierzytelniania, nieprawidłowy token lub niezgodny z API.
- `403`: niewystarczający stan konta lub prompt odrzucony w wyniku moderacji.
- `429`: zbyt wiele żądań, przekroczono limit, spróbuj ponownie później.
- `500`: błąd serwera lub niepowodzenie generowania po stronie serwera.
