## 1. 获取 API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj API Key.

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

W docelowym repozytorium GitHub w **Ustawienia → Sekrety i zmienne → Akcje** utwórz nowy Secret:

```text
ACEDATACLOUD_API_KEY
```

## 2. 安装 GitHub App

Zainstaluj [Claude GitHub App](https://github.com/apps/claude) i autoryzuj docelowe repozytorium. Ta oficjalna aplikacja poprosi o stały zestaw pełnych uprawnień; w tym Claude Code Action faktycznie używa uprawnień do Zawartości, Zgłoszeń i Pull requests, strona instalacji GitHub nie może zaznaczyć tylko tych trzech opcji. Jeśli organizacja wymaga minimalnych uprawnień, utwórz niestandardową aplikację GitHub zgodnie z dokumentacją.

## 3. 添加 Workflow

Utwórz `.github/workflows/claude.yml`:

```yaml
name: Claude Code

on:
  issue_comment:
    types: [created]
  pull_request_review_comment:
    types: [created]

jobs:
  claude:
    if: contains(github.event.comment.body, '@claude')
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
      issues: write
      actions: read
      id-token: write
    env:
      ANTHROPIC_BASE_URL: https://api.acedata.cloud
      ANTHROPIC_CUSTOM_HEADERS: "Authorization: Bearer ${{ secrets.ACEDATACLOUD_API_KEY }}"
    steps:
      - uses: actions/checkout@v6
        with:
          fetch-depth: 1
      - uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: dummy-not-used
```

`claude-code-action` wymaga niepustego wejścia `anthropic_api_key`; wartość zastępcza tutaj nie będzie używana do autoryzacji na platformie. `ANTHROPIC_CUSTOM_HEADERS` nadpisze wymagany przez Ace Data Cloud nagłówek Bearer, prawdziwy klucz pochodzi tylko z GitHub Secret.

## 4. 验证

Po przesłaniu Workflow, wyślij w komentarzu do Issue lub PR:

```text
@claude Reply only OK
```

W przypadku sukcesu workflow Akcji zakończy się, a w odpowiednim Issue/PR zaktualizuje wyniki. Jeśli Akcja zgłasza brak poświadczeń, upewnij się, że `dummy-not-used` nadal istnieje; w przypadku 401 sprawdź Secret `ACEDATACLOUD_API_KEY`. Nie drukuj Secret w logach. Można użyć `claude_args`, aby w razie potrzeby ustawić `--max-turns` lub wybrać aktualnie dostępny model, ale integracja z szablonem nie jest stała.
