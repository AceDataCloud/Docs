---
title: "Instrukcja konfiguracji Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code to inteligentny asystent programistyczny opracowany przez Anthropic, który można używać w terminalu, IDE oraz w pipeline’ach CI/CD. Dzięki proxy AceData Cloud możesz korzystać z Claude Code po niższych kosztach.

Wybierz pełną instrukcję konfiguracji odpowiednią dla swojego środowiska:

| Platforma | Opis | Link do instrukcji |
|-----------|------|--------------------|
| **VS Code** | Natywne rozszerzenie, obsługuje inline Diff, @-wzmianki, planowanie przeglądów | [Instrukcja konfiguracji VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Edytor kompatybilny z VS Code, pełne wsparcie rozszerzenia Claude Code | [Instrukcja konfiguracji Cursor](https://platform.acedata.cloud/documents/development_cursor_coding) |
| **Terminal (CLI)** | Podstawowe doświadczenie, wystarczy uruchomić `claude` w dowolnym terminalu | [Instrukcja konfiguracji terminala](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **JetBrains IDE** | Obsługuje IntelliJ IDEA, PyCharm, WebStorm i inne IDE z rodziny JetBrains | [Instrukcja konfiguracji JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatyzuj przegląd kodu i obsługę Issue za pomocą `@claude` | [Instrukcja konfiguracji GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Wskazówka**: Przy pierwszym zgłoszeniu odwiedź [Claude Messages service page](https://platform.acedata.cloud/documents/claude-messages) i kliknij „Acquire”, aby uzyskać poświadczenia oraz darmowy limit.
