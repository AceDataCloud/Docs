---
title: "Instrukcja konfiguracji Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code to inteligentny agent programistyczny opracowany przez Anthropic, który można używać w różnych środowiskach, takich jak terminal, IDE czy aplikacje desktopowe. Dzięki proxy AceData Cloud możesz korzystać z Claude Code po niższych kosztach.

> **Pierwsze podłączenie?** Zalecamy najpierw zapoznać się z [Claude Code 5-minutowy szybki start](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) — od uzyskania poświadczeń do uruchomienia pierwszego polecenia w pięciu krokach.

Wybierz pełną instrukcję konfiguracji odpowiednią dla swojego środowiska:

| Platforma | Opis | Link do instrukcji |
|-----------|------|--------------------|
| **⚡ Szybki start w 5 minut** | Od uzyskania poświadczeń do pierwszego polecenia `claude` w pięciu krokach | [Instrukcja 5 minut](https://platform.acedata.cloud/documents/claude-code-5min-quickstart) |
| **Terminal (CLI)** | Podstawowe doświadczenie, rozpocznij działanie wpisując `claude` w dowolnym terminalu | [Instrukcja konfiguracji terminala](https://platform.acedata.cloud/documents/claude-code-terminal-integration) |
| **VS Code** | Natywne rozszerzenie z obsługą inline Diff, @-wzmiankami, planowaniem przeglądów | [Instrukcja konfiguracji VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |
| **Cursor** | Edytor kompatybilny z VS Code, pełne wsparcie rozszerzenia Claude Code | [Instrukcja konfiguracji Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) |
| **JetBrains IDE** | Obsługa IntelliJ IDEA, PyCharm, WebStorm i innych IDE z rodziny JetBrains | [Instrukcja konfiguracji JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations) |
| **GitHub Actions** | Automatyzacja przeglądu kodu i obsługi Issue za pomocą `@claude` | [Instrukcja konfiguracji GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |
| **Aplikacja desktopowa (Preview)** | Niezależny klient graficzny z obsługą równoległych sesji i podłączania zewnętrznych narzędzi | [Instrukcja konfiguracji aplikacji desktopowej](https://platform.acedata.cloud/documents/claude-code-desktop-integration) |

> **Wskazówka**: Przy pierwszym zgłoszeniu odwiedź [stronę usługi Claude Messages](https://platform.acedata.cloud/documents/claude-messages) i kliknij „Acquire”, aby uzyskać poświadczenia oraz darmowy limit.
