title: "Przewodnik konfiguracji Claude Code"
description: "Claude Code 集成指南 - Ace Data Cloud"
---

Claude Code to inteligentny agent programistyczny wprowadzony przez Anthropic, który można używać w różnych środowiskach, takich jak terminal, IDE, aplikacje desktopowe itp. Dzięki agentowi AceData Cloud możesz korzystać z Claude Code po niższej cenie.

Proszę wybrać odpowiedni przewodnik konfiguracji w zależności od swojego scenariusza użycia:

| Platforma           | Opis                                        | Link do przewodnika                                                                                       |
| ------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Terminal (CLI)**   | Podstawowe doświadczenie, uruchom `claude` w dowolnym terminalu, aby rozpocząć                | [Przewodnik konfiguracji terminala](https://platform.acedata.cloud/documents/claude-code-terminal-integration)                    |
| **VS Code**        | Natywne rozszerzenie, wspiera inline Diff, @-wzmianki, planowanie przeglądów            | [Przewodnik konfiguracji VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations)               |
| **JetBrains IDE**  | Wspiera wszystkie IDE z rodziny IntelliJ IDEA, PyCharm, WebStorm itp. | [Przewodnik konfiguracji JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)          |
| **GitHub Actions** | Automatyzacja przeglądów kodu i obsługi problemów za pomocą `@claude`             | [Przewodnik konfiguracji GitHub Actions](https://platform.acedata.cloud/documents/claude-code-github-actions-integration) |

> **Wskazówka**: Przy pierwszym wniosku można przejść do [strony usługi Claude Messages](https://platform.acedata.cloud/documents/claude-messages) i kliknąć „Acquire”, aby uzyskać poświadczenia, co daje darmowy limit.
