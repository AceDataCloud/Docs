Claude Code łączy się z Coding Plan za pomocą protokołu Anthropic Messages, obecnie oferując dwa punkty dostępu: terminal i VS Code.

| Punkt dostępu      | Przewodnik konfiguracyjny                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------ |
| Terminal / CLI    | [Konfiguracja terminala Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration)          |
| VS Code           | [Konfiguracja Claude Code dla VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) |

## Wspólna konfiguracja

- Podstawowy URL: `https://api.acedata.cloud`
- Token API: uzyskaj z aplikacji Coding i skonfiguruj za pomocą `ANTHROPIC_AUTH_TOKEN` w przewodniku
- ID modelu: wybierz z katalogu modeli na żywo
- Po zmianie konfiguracji: zrestartuj Claude Code; użytkownicy VS Code muszą przeładować okno

Nie przechowuj jednocześnie starego `ANTHROPIC_API_KEY` i nie zapisuj prawdziwego tokena w plikach współdzielonych z zespołem.

Powróć do [Centrum konfiguracji Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
