Claude Code to narzędzie programistyczne wydane przez Anthropic, znane również jako jeden z najsilniejszych agentów programistycznych na świecie. Rozszerzenie Claude Code dla VS Code oferuje natywny interfejs graficzny i jest zalecaną metodą korzystania z Claude Code w VS Code.

Dokument ten opisuje, jak skonfigurować i używać rozszerzenia Claude Code w VS Code za pośrednictwem usługi proxy Ace Data Cloud.

## Proces aplikacji

Aby korzystać z Claude Code, najpierw należy przejść do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować. Po zalogowaniu lub rejestracji automatycznie wrócisz na bieżącą stronę.

Podczas pierwszej aplikacji otrzymasz darmowy limit, aby bezpłatnie przetestować usługi Claude Code.

## Instalacja wtyczki Claude Code

Wyszukaj **Claude Code** w rynku rozszerzeń VS Code, upewnij się, że wydawcą jest **Anthropic**, a następnie zainstaluj. Po zakończeniu instalacji w pasku aktywności pojawi się ikona Claude Code.

## Konfiguracja API Ace Data Cloud

Podczas pierwszego otwarcia wtyczki zostaniesz poproszony o zalogowanie się na oficjalne konto Anthropic. Możemy pominąć logowanie do oficjalnego konta, konfigurując API proxy Ace Data Cloud, aby z niego korzystać, bez potrzeby subskrypcji oficjalnej.

Rozszerzenie i terminal CLI odczytują tę samą konfigurację Claude Code. Pełna autoryzacja, obsługa konfliktów poświadczeń oraz globalne metody konfiguracji są opisane w [instrukcji konfiguracji terminala Claude Code](https://platform.acedata.cloud/documents/claude-code-terminal-integration). Jeśli chcesz, aby konfiguracja dotyczyła tylko bieżącego projektu, utwórz w katalogu głównym projektu plik `.claude/settings.local.json`, który został dodany do `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Gdzie `{token}` to właśnie skopiowany klucz API. Jeśli w środowisku, w którym uruchamiasz VS Code, istnieje stary `ANTHROPIC_API_KEY`, najpierw w tym środowisku wykonaj `unset ANTHROPIC_API_KEY`; nie traktuj pustego ciągu jako czyszczenia i nie umieszczaj prawdziwego klucza w współdzielonym pliku `.claude/settings.json`.

Poniżej znajduje się konfiguracja wykonana na lokalnym komputerze przy użyciu VS Code 1.136.1 i rozszerzenia Claude Code 2.1.251. Zrzut ekranu używa klucza zastępczego, aby uniknąć ujawnienia prawdziwych poświadczeń:

![Konfiguracja Ace Data Cloud Claude Code w VS Code](https://cdn.acedata.cloud/f925e9e9597b.png)

Po zakończeniu konfiguracji uruchom ponownie VS Code.

> Uwaga: powyższa konfiguracja dotyczy tylko bieżącego projektu, a także zaleca się dodanie powyższego pliku konfiguracyjnego `.claude/settings.local.json` do pliku `.gitignore`, aby zapobiec przesyłaniu go do zdalnego repozytorium.

Jeśli chcesz, aby wszystkie projekty korzystały z tej konfiguracji, możesz bezpośrednio umieścić tę konfigurację w katalogu użytkownika. Odpowiednia ścieżka to `~/.claude/settings.json`,

> Uwaga: po zakończeniu konfiguracji uruchom ponownie lub przeładuj VS Code, aby powyższa konfiguracja zaczęła działać.

## Podstawowe użycie

Po skonfigurowaniu, w panelu Claude Code wyślij proste zadanie tylko do odczytu, na przykład „przeczytaj README.md i podsumuj w jednym zdaniu”. Po pomyślnym wykonaniu zadania możesz sprawdzić to w [historii użycia](https://platform.acedata.cloud/console/usages).

## Jak sprawdzić pozostały limit

Możesz sprawdzić aktualny pozostały limit konta przez [konsolę Ace Data Cloud - lista aplikacji](https://platform.acedata.cloud/console/applications).

Możesz również sprawdzić całą historię użycia i szczegóły opłat przez [konsolę Ace Data Cloud - historia użycia](https://platform.acedata.cloud/console/usages).
