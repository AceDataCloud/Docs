Claude Code to narzędzie **Agentic Coding** wydane przez Anthropic, znane również jako jeden z najsilniejszych agentów programistycznych na świecie. Rozszerzenie Claude Code dla VS Code oferuje natywny interfejs graficzny, wspierający widok Diff w linii, odniesienia `@`-mentions, przegląd planów i inne funkcje, co czyni go zalecaną metodą korzystania z Claude Code w VS Code.

Dokument ten głównie opisuje, jak skonfigurować i używać rozszerzenia Claude Code w VS Code za pośrednictwem usługi proxy AceData Cloud.

## Proces aplikacji

Aby korzystać z Claude Code, najpierw można przejść do [strony usługi Claude Messages](https://platform.acedata.cloud/documents/claude-messages) i kliknąć przycisk „Acquire”, aby uzyskać wymagane poświadczenia:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zalogowaniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

Podczas pierwszej aplikacji przyznawana jest darmowa kwota, co pozwala na bezpłatne wypróbowanie usługi Claude Code.

## Instalacja wtyczki

### Wymagania systemowe

- VS Code 1.98.0 lub nowsza wersja (obsługuje również Cursor)

### Kroki instalacji

W sklepie z rozszerzeniami VS Code / Cursor naciśnij `Cmd+Shift+X` (Mac) lub `Ctrl+Shift+X` (Windows/Linux), aby otworzyć widok rozszerzeń, wyszukaj **Claude Code**, znajdź wtyczkę wydaną przez Anthropic i kliknij „Install”, aby ją zainstalować:

![Wtyczka Claude Code w VS Code Marketplace](https://cdn.acedata.cloud/10ddf71320.png)

Możesz również zainstalować ją bezpośrednio za pomocą poniższych linków:

- [Link do instalacji VS Code](vscode:extension/anthropic.claude-code)
- [Link do instalacji Cursor](cursor:extension/anthropic.claude-code)

Po instalacji wybierz opcję zaufania w wyskakującym oknie, aby zakończyć instalację.

> Jeśli po instalacji rozszerzenie się nie pojawi, zrestartuj VS Code lub wykonaj polecenie „Developer: Reload Window” w panelu poleceń.

## Konfiguracja API AceData Cloud

Podczas pierwszego otwarcia wtyczki zostaniesz poproszony o zalogowanie się na oficjalne konto Anthropic. Możemy pominąć oficjalne logowanie, konfigurując API proxy AceData Cloud, **bez potrzeby subskrypcji oficjalnej**.

### Krok 1: Konfiguracja zmiennych środowiskowych

Możesz skonfigurować zmienne środowiskowe w dowolnym z poniższych miejsc:

**Opcja A: Konfiguracja na poziomie użytkownika (dotyczy wszystkich projektów)**

Edytuj `~/.claude/settings.json` (jeśli nie istnieje, utwórz), dodaj konfigurację `env`, zastępując `{token}` tokenem API uzyskanym w konsoli AceData Cloud:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

**Opcja B: Konfiguracja na poziomie projektu (tylko dla bieżącego projektu)**

Utwórz w katalogu głównym projektu plik `.claude/settings.json` (konfiguracja współdzielona) lub `.claude/settings.local.json` (konfiguracja osobista, ignorowana przez git):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Wskazówka**: Token API można zobaczyć w [konsoli AceData Cloud](https://platform.acedata.cloud/console). Wartość `ANTHROPIC_AUTH_TOKEN` zostanie automatycznie dodana z prefiksem `Bearer` i wysłana do serwera. Konfiguracja na poziomie projektu ma wyższy priorytet niż konfiguracja na poziomie użytkownika. Zaleca się używanie współdzielonej konfiguracji `.claude/settings.json` w projektach zespołowych, a osobistych informacji w `.claude/settings.local.json`.

### Krok 2: Wyłączenie powiadomienia o logowaniu (opcjonalnie)

Jeśli nie chcesz widzieć powiadomienia o logowaniu za każdym razem, gdy otwierasz, możesz zaznaczyć opcję **Disable Login Prompt** w ustawieniach VS Code:

W ustawieniach wyszukaj „Claude Code login”, znajdź opcję **Disable Login Prompt** i zaznacz ją.

Po zakończeniu konfiguracji ponownie otwórz panel wtyczki Claude Code, aby normalnie rozpocząć korzystanie.

## Otwieranie panelu Claude Code

Po zainstalowaniu i skonfigurowaniu istnieje wiele sposobów na otwarcie Claude Code:

| Sposób         | Działanie                                             |
| ---------- | ---------------------------------------------- |
| **Pasek narzędzi edytora** | Kliknij ikonę ✦ Spark w prawym górnym rogu edytora (musisz otworzyć plik)                 |
| **Pasek stanu**    | Kliknij „✱ Claude Code” po prawej stronie dolnego paska stanu (nie musisz otwierać pliku)              |
| **Panel poleceń**   | `Cmd+Shift+P` / `Ctrl+Shift+P`, wyszukaj „Claude Code” |
| **Skrót klawiszowy**    | `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux) przełącz fokus  |

W przeciwieństwie do narzędzi takich jak Cursor / Copilot, które używają paska bocznego, Claude Code domyślnie przyjmuje **widok obszaru edycji** jako obszar czatu, co zapewnia większą widoczność i bogatszą prezentację treści. Możesz również przeciągnąć panel do paska bocznego lub innej lokalizacji.

![Panel Claude Code w VS Code](https://cdn.acedata.cloud/b84b878420.jpg)

## Podstawowe użycie

### Interakcja w rozmowie

W panelu Claude Code możesz bezpośrednio wprowadzać naturalny język, aby wchodzić w interakcje z Claude. Na przykład:

- „Pomóż mi przeanalizować ogólną architekturę tego projektu”
- „Ten kod ma błąd, napraw to”
- „Przebuduj tę funkcję, aby poprawić czytelność”
- „Napisz test jednostkowy dla tego modułu”

Claude Code automatycznie zrozumie kontekst twojego repozytorium kodu, analizując i edytując w różnych plikach. Gdy Claude potrzebuje zmodyfikować plik, wyświetli widok porównania Diff, a ty możesz wybrać, czy zaakceptować, czy odrzucić zmiany.

![Rozmowa i wskazówki Claude Code w VS Code](https://cdn.acedata.cloud/650377f5cc.png)

### Odniesienia kontekstowe

W rozmowie użyj symbolu `@`, aby odwołać się do konkretnego pliku lub kontekstu:

- `@filename.py` — odniesienie do określonego pliku (obsługuje dopasowanie przybliżone)
- `@src/components/` — odniesienie do całego katalogu (wymaga ukośnika na końcu)
- `@terminal:name` — odniesienie do wyjścia terminala

Po zaznaczeniu kodu w edytorze naciśnij `Option+K` (Mac) / `Alt+K` (Windows/Linux), aby szybko wstawić odniesienie `@` (np. `@app.ts#5-10`).

### Komendy ukośnika

Kliknij ikonę `/` w oknie rozmowy lub po prostu wpisz `/`, aby skorzystać z bogatych funkcji wbudowanych:

Najczęściej używane komendy to:

| Komenda         | Funkcja           |
| ---------- | ------------ |
| `/new`     | Nowa rozmowa         |
| `/model`   | Zmień model         |
| `/compact` | Skondensuj kontekst        |
| `/mcp`     | Skonfiguruj usługę MCP    |
| `/config`  | Otwórz ustawienia         |
| `/usage`   | Zobacz zużycie         |
| `/memory`  | Zarządzaj pamięcią Claude |
| `/help`    | Wyświetl informacje pomocy       |

### Przeglądanie historii rozmów

Kliknij rozwijane menu na górze panelu, aby zobaczyć historię rozmów, wspierając przeszukiwanie według słów kluczowych oraz przeglądanie według okresów (Dziś, Wczoraj, Ostatnie 7 dni itp.), co ułatwia powrót do wcześniejszych interakcji. Kliknij dowolną rozmowę, aby przywrócić pełną historię wiadomości.

### Przeglądanie zmian w kodzie

Gdy Claude potrzebuje zmodyfikować plik, wyświetli widok porównania Diff, pokazując porównanie oryginalnego kodu i zmodyfikowanego. Możesz wybrać, czy zaakceptować, czy odrzucić każdą zmianę, a także powiedzieć Claude, jakich zmian oczekujesz:
![Widok porównania Diff w VS Code](https://cdn.acedata.cloud/c42381ea9f.png)

### Tryb uprawnień

Możesz przełączać różne tryby uprawnień za pomocą wskaźnika trybu na dole panelu:

| Tryb                    | Opis                      |
| --------------------- | ----------------------- |
| **Domyślny (Zapytaj)**      | Zapytaj o potwierdzenie przed każdą operacją (domyślnie)           |
| **Plan**              | Claude najpierw opracowuje plan, czeka na zatwierdzenie, a następnie wykonuje |
| **acceptEdits**       | Automatycznie akceptuje edycje plików, ale polecenia terminala nadal wymagają potwierdzenia      |
| **bypassPermissions** | Pomija wszystkie powiadomienia o uprawnieniach, całkowita automatyzacja (używaj ostrożnie)    |

### Równoległe sesje

Używając polecenia w panelu poleceń **Otwórz w nowej karcie** lub **Otwórz w nowym oknie**, możesz uruchomić wiele niezależnych rozmów, z których każda utrzymuje własną historię i kontekst, co pozwala na równoległe przetwarzanie różnych zadań.

## Inne ustawienia

### Przełączanie modeli

Claude Code obsługuje przełączanie różnych modeli, takich jak Claude Sonnet, Claude Opus itp. Można to skonfigurować za pomocą polecenia `/model` lub w ustawieniach wtyczki w **Wybranym modelu**.

### Tryb automatyczny

W ustawieniach wtyczki można ustawić **Początkowy tryb uprawnień** na `bypassPermissions`, co po włączeniu sprawi, że Claude Code nie będzie już wyświetlał okienek potwierdzenia przy edycji plików, poleceniach terminala itp., co umożliwi całkowitą automatyzację pracy.

Można również ustawić na `acceptEdits`, aby uzyskać półautomatyczny tryb, w którym edycje są automatycznie akceptowane, ale polecenia terminala nadal wymagają potwierdzenia.

> **Uwaga**: Przed włączeniem trybu automatycznego upewnij się, że rozumiesz związane z tym ryzyko, zaleca się korzystanie w zaufanym środowisku projektowym.

### Używanie CLI w terminalu

Jeśli preferujesz styl wiersza poleceń, możesz zaznaczyć **Użyj terminala** w ustawieniach VS Code, a Claude Code będzie działać w trybie CLI w zintegrowanym terminalu. Możesz również bezpośrednio otworzyć zintegrowany terminal VS Code i uruchomić polecenie `claude`.

## Często zadawane pytania

### Co zrobić, gdy połączenie się nie powiodło?

1. Upewnij się, że zmienne środowiskowe w `~/.claude/settings.json` lub `.claude/settings.json` są poprawnie skonfigurowane, szczególnie `ANTHROPIC_AUTH_TOKEN` i `ANTHROPIC_BASE_URL`
2. Upewnij się, że token API jest ważny (można to sprawdzić w [konsoli](https://platform.acedata.cloud/console))
3. Sprawdź, czy połączenie sieciowe jest prawidłowe, upewnij się, że możesz uzyskać dostęp do `https://api.acedata.cloud`
4. Uruchom ponownie VS Code i spróbuj ponownie

### Co zrobić, gdy ikona Spark się nie pojawia?

1. Upewnij się, że otworzyłeś plik (samo otwarcie folderu nie wystarczy)
2. Upewnij się, że wersja VS Code to 1.98.0 lub wyższa
3. Wykonaj w panelu poleceń „Developer: Przeładuj okno”
4. Lub po prostu kliknij na „✱ Claude Code” w dolnym pasku stanu

### Jak sprawdzić pozostały limit?

Zaloguj się do [konsoli AceData Cloud](https://platform.acedata.cloud/console), aby zobaczyć aktualny limit i wykorzystanie konta.
