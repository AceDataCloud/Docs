## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj CLI i wtyczki

Najpierw zainstaluj Claude Code CLI.

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
claude --version
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Następnie zainstaluj wtyczkę **Claude Code** z JetBrains Marketplace i uruchom ponownie IDE. Wtyczka wywołuje lokalne polecenie `claude`; jeśli pojawi się komunikat o braku polecenia, wypełnij jego pełną ścieżkę w **Ustawienia → Narzędzia → Claude Code**.

## 3. Skonfiguruj Ace Data Cloud

Ustaw w środowisku uruchamiającym backend JetBrains.

macOS / Linux / WSL:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="twój klucz API"
unset ANTHROPIC_API_KEY
```

Windows PowerShell:

```powershell
$env:ANTHROPIC_BASE_URL = "https://api.acedata.cloud"
$env:ANTHROPIC_AUTH_TOKEN = "twój klucz API"
Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue
```

Możesz również użyć zignorowanego pliku `.claude/settings.local.json` w projekcie:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "twój klucz API"
  }
}
```

W przypadku zdalnego rozwoju należy skonfigurować i zainstalować wtyczkę na zdalnym hoście; użytkownicy WSL mogą ustawić polecenie Claude jako `wsl -d Ubuntu -- bash -lic "claude"`.

## 4. Weryfikacja

Uruchom `claude` z zintegrowanego terminala IDE lub po uruchomieniu zewnętrznego terminala wpisz `/ide`. Po pomyślnym połączeniu poproś Claude'a o odpowiedź `OK`, a następnie odczytaj plik testowy i sprawdź to żądanie w historii użycia Ace Data Cloud [użycia](https://platform.acedata.cloud/console/usages).

Jeśli wtyczka nie uruchamia się, najpierw uruchom `claude --version` w tym samym terminalu; 401 oznacza, że należy sprawdzić rzeczywiste zmienne środowiskowe dziedziczone przez backend oraz stary `ANTHROPIC_API_KEY`.
