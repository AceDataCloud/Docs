Claude Code to narzędzie **Agentic Coding** wydane przez Anthropic, znane również jako jeden z najsilniejszych agentów programistycznych na świecie. Claude Code oferuje dedykowany plugin dla JetBrains IDE, wspierający IntelliJ IDEA, PyCharm, WebStorm, GoLand, PhpStorm, Android Studio oraz całą gamę IDE JetBrains.

Dokument ten opisuje, jak skonfigurować i używać Claude Code w JetBrains IDE za pośrednictwem usługi proxy AceData Cloud.

## Proces aplikacji

Aby korzystać z Claude Code, najpierw przejdź do [strony usługi Claude Messages](https://platform.acedata.cloud/documents/claude-messages) i kliknij przycisk „Acquire”, aby uzyskać wymagane poświadczenia:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zalogowaniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

Podczas pierwszej aplikacji otrzymasz darmowy limit, aby bezpłatnie wypróbować usługi Claude Code.

## Instalacja

### Wymagania wstępne

Plugin Claude Code dla JetBrains zależy od Claude Code CLI, upewnij się, że CLI jest zainstalowane:

```bash
# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# lub użyj Homebrew
brew install claude-code
```

Po zakończeniu instalacji możesz to zweryfikować:

```bash
claude --version
```

### Instalacja pluginu

![Plugin Claude Code w JetBrains Marketplace](https://cdn.acedata.cloud/de78fd305b.png)

1. Otwórz JetBrains IDE
2. Przejdź do **Settings** → **Plugins** → **Marketplace**
3. Wyszukaj **Claude Code**
4. Kliknij **Install**, aby zainstalować plugin
5. Uruchom ponownie IDE

Lub odwiedź bezpośrednio [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/27310-claude-code-beta-) w celu instalacji online.

> **Ważne**: Po zainstalowaniu pluginu należy **całkowicie zrestartować IDE** (może być konieczne wielokrotne uruchomienie ponowne), aby zmiany zaczęły obowiązywać.

## Konfiguracja AceData Cloud API

Plugin Claude Code dla JetBrains uruchamia polecenie `claude` w zintegrowanym terminalu, dlatego sposób konfiguracji zmiennych środowiskowych jest taki sam jak w CLI.

### Krok 1: Utwórz config.json

Utwórz plik konfiguracyjny dla Claude Code:

| System              | Ścieżka                                   |
| ----------------- | ------------------------------------ |
| **macOS / Linux** | `~/.claude/config.json`              |
| **Windows**       | `C:\Users\{nazwa_użytkownika}\.claude\config.json` |

Wpisz poniższe treści w tym pliku i zapisz:

```json
{
  "primaryApiKey": "self"
}
```

Szybka komenda do utworzenia na macOS / Linux:

```bash
mkdir -p ~/.claude && echo '{"primaryApiKey": "self"}' > ~/.claude/config.json
```

### Krok 2: Skonfiguruj zmienne środowiskowe

**Metoda 1: Ustaw w pliku konfiguracyjnym Shell (zalecane)**

Dodaj poniższe treści do swojego `~/.zshrc` lub `~/.bashrc`, zastępując `{token}` swoim tokenem API:

```bash
# AceData Cloud - Konfiguracja proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Po modyfikacji wykonaj `source ~/.zshrc`, aby zastosować konfigurację, a następnie **uruchom ponownie JetBrains IDE**.

**Metoda 2: Ustaw w settings.json Claude Code**

Edytuj `~/.claude/settings.json` (jeśli nie istnieje, utwórz):

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

> **Wskazówka**: Token API można znaleźć w [konsoli AceData Cloud](https://platform.acedata.cloud/console).

## Podstawowe użycie

### Uruchomienie z zintegrowanego terminala IDE

Otwórz zintegrowany terminal JetBrains IDE i uruchom:

```bash
claude
```

Podczas uruchamiania w zintegrowanym terminalu IDE wszystkie funkcje integracyjne (widok Diff, kontekst wyboru itp.) będą automatycznie aktywowane.

### Połączenie z zewnętrznego terminala

Jeśli uruchamiasz Claude Code w zewnętrznym terminalu, możesz użyć polecenia `/ide`, aby połączyć się z JetBrains IDE:

```bash
claude
> /ide
```

Upewnij się, że uruchamiasz Claude Code z tej samej ścieżki, co katalog główny projektu IDE, aby Claude miał dostęp do tej samej grupy plików.

### Skróty klawiszowe

| Skrót klawiszowy                                      | Funkcja                      |
| ------------------------------------------------ | ----------------------- |
| `Cmd+Esc` (Mac) / `Ctrl+Esc` (Windows/Linux)        | Szybkie otwarcie Claude Code        |
| `Cmd+Option+K` (Mac) / `Alt+Ctrl+K` (Windows/Linux) | Wstawianie odniesienia do pliku (np. `@File#L1-99`) |

### Funkcje integracyjne

Plugin Claude Code dla JetBrains oferuje następujące funkcje integracyjne:

- **Widok Diff**: Zmiany w kodzie są bezpośrednio wyświetlane w widoku Diff IDE
- **Kontekst wyboru**: Aktualnie wybrany kod i zakładki są automatycznie udostępniane Claude
- **Odniesienia do plików**: Szybkie odniesienia do plików i numerów linii za pomocą skrótów klawiszowych
- **Udostępnianie diagnostyki**: Informacje diagnostyczne, takie jak Lint, błędy składniowe itp., są automatycznie udostępniane Claude

## Ustawienia pluginu

W **Settings** → **Tools** → **Claude Code [Beta]** można skonfigurować:

| Ustawienie                        | Opis                                         |
| ----------------------------- | ------------------------------------------ |
| **Claude command**            | Niestandardowa ścieżka do polecenia Claude (np. `/usr/local/bin/claude`) |
| **Włącz automatyczne aktualizacje**  | Automatyczne sprawdzanie i instalowanie aktualizacji pluginu                                |
| **Włącz użycie Option+Enter** | Użyj Option+Enter w oknie dialogowym na macOS, aby przejść do nowej linii             |

### Konfiguracja dla użytkowników WSL

Jeśli korzystasz w środowisku WSL, ustaw polecenie Claude na:

```
wsl -d Ubuntu -- bash -lic "claude"
```

(zamień `Ubuntu` na nazwę swojej dystrybucji WSL)

## Często zadawane pytania

### Co zrobić, gdy połączenie nie działa?

1. Sprawdź, czy plik `~/.claude/config.json` został poprawnie utworzony
2. Upewnij się, że zmienne środowiskowe zostały poprawnie ustawione
3. Upewnij się, że token API jest ważny (można go sprawdzić w [konsoli](https://platform.acedata.cloud/console))
4. Uruchom ponownie JetBrains IDE i spróbuj ponownie

### Co zrobić, gdy plugin nie działa?

1. Upewnij się, że uruchamiasz Claude Code z katalogu głównego projektu
2. Sprawdź, czy plugin jest włączony w ustawieniach IDE
3. Całkowicie uruchom ponownie IDE (może być konieczne wielokrotne uruchomienie)
4. Jeśli korzystasz z trybu zdalnego, upewnij się, że plugin jest zainstalowany na zdalnym hoście (Settings → Plugin (Host))

### Co zrobić, gdy IDE nie zostało wykryte?

1. Upewnij się, że plugin jest zainstalowany i włączony
2. Uruchom ponownie IDE
3. Upewnij się, że uruchamiasz Claude Code w zintegrowanym terminalu
4. Użytkownicy WSL proszeni są o zapoznanie się z [przewodnikiem rozwiązywania problemów WSL](https://code.claude.com/docs/en/troubleshooting#jetbrains-ide-not-detected-on-wsl2)

### command not found

Jeśli kliknięcie ikony Claude wyświetla komunikat "command not found":

1. Upewnij się, że CLI jest zainstalowane: `which claude`
2. Skonfiguruj pełną ścieżkę do polecenia Claude w ustawieniach pluginu
3. Użytkownicy WSL powinni używać powyższego formatu polecenia WSL
### Jak sprawdzić pozostały limit?

Zaloguj się do [konsoli AceData Cloud](https://platform.acedata.cloud/console), aby zobaczyć aktualny pozostały limit i stan wykorzystania konta.
