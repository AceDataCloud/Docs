## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj CC Switch

Pobierz z [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), macOS również może działać:

```bash
brew install --cask cc-switch
```

## 3. Dodaj dostawcę

Otwórz CC Switch, wybierz **Claude Code → Dodaj dostawcę → Niestandardowy**, wypełnij:

| Pole        | Wartość                       |
| ----------- | ----------------------------- |
| Nazwa       | `Ace Data Cloud`              |
| Podstawowy URL | `https://api.acedata.cloud` |
| Klucz API   | Właśnie skopiowany klucz API       |
| Format API  | `Anthropic Messages`          |

Jeśli chcesz użyć edytora JSON, skonfiguruj jako:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "{token}"
  }
}
```

CC Switch zapisze konfigurację w ustawieniach użytkownika Claude Code. Nie przechowuj prawdziwego klucza w repozytorium zespołu i nie zachowuj jednocześnie starego `ANTHROPIC_API_KEY`.

## 4. Włącz i zweryfikuj

Po zapisaniu włącz **Ace Data Cloud**, ponownie otwórz Claude Code. Wyślij prostą, tylko do odczytu, prośbę i sprawdź wywołania w [historii użycia](https://platform.acedata.cloud/console/usages). Jeśli po przełączeniu nadal używasz starej konfiguracji, całkowicie zamknij Claude Code i CC Switch, a następnie spróbuj ponownie.
