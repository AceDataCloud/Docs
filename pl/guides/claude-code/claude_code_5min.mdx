Celem tego dokumentu jest jedno: pozwolić Ci **w ciągu 5 minut** uruchomić pierwsze polecenie Claude Code za pomocą proxy AceData Cloud. Pełne tutoriale znajdziesz w poddokumentach dla poszczególnych IDE ([VS Code](https://platform.acedata.cloud/documents/claude-code-vscode-integrations) / [Cursor](https://platform.acedata.cloud/documents/claude-code-cursor-integration) / [JetBrains](https://platform.acedata.cloud/documents/claude-code-jetbrains-integrations)); tutaj idziemy najszybszą ścieżką „**terminal CLI** + **rozszerzenie VS Code**”.

> **Dlaczego używać proxy AceData Cloud dla Claude Code**:
> - Bezpośrednie połączenie z Chin, bez potrzeby VPN
> - Niższe ceny niż oficjalne (rozliczanie według tokenów platformy)
> - Ten sam klucz obsługuje jednocześnie Claude Messages API + protokół Claude Code Token

## Minuta 1: Uzyskanie poświadczeń

Otwórz [stronę usługi Claude Messages](https://platform.acedata.cloud/documents/claude-messages) i kliknij przycisk „**Acquire**”:

![](https://cdn.acedata.cloud/nyq0xz.png)

Platforma automatycznie utworzy dla Ciebie aplikację i przyzna darmowy limit. Zapisz sobie z ekranu szczegółów **Base URL** oraz **API Token** — będą potrzebne w kolejnych 5 krokach.

| Pole | Wartość | Zastosowanie |
|------|---------|--------------|
| `BASE_URL` | `https://api.acedata.cloud/claude` | Punkt wejścia kompatybilny z Claude Messages |
| `API_TOKEN` | `sk-...` (do skopiowania ze strony szczegółów) | Nagłówek autoryzacji kompatybilny z Anthropic |

## Minuta 2: Instalacja Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell natywny):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Po instalacji otwórz nowy terminal i sprawdź działanie:

```bash
claude --version
```

> Powinieneś zobaczyć numer wersji. Claude Code zawiera własne środowisko Node.js, nie zależy od wersji Node zainstalowanej na Twoim komputerze.

## Minuta 3: Skierowanie zmiennych środowiskowych na AceData Cloud

Nie korzystaj z oficjalnego procesu `claude login`, zamiast tego nadpisz zmienne środowiskowe. Wybierz jedną z dwóch metod:

**Metoda A: Tymczasowo (tylko dla bieżącej sesji shell)**

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud/claude"
export ANTHROPIC_AUTH_TOKEN="sk-Twój-Token"
```

**Metoda B: Trwale (zalecane)**

Dodaj powyższe dwie linie do `~/.zshrc` lub `~/.bashrc`, a następnie wykonaj `source`.

> **Typowy błąd**: nazwa zmiennej to `ANTHROPIC_AUTH_TOKEN`, a nie `ANTHROPIC_API_KEY`; jeśli użyjesz złej nazwy, Claude Code wróci do oficjalnego endpointu i zwróci błąd 401.

## Minuta 4: Uruchom pierwsze polecenie

Wejdź do dowolnego repozytorium Git i wpisz:

```bash
claude
```

Jeśli przy pierwszym uruchomieniu pojawi się prośba o logowanie, naciśnij `Esc`, aby pominąć. Następnie wpisz:

```
Wypisz zależności obecnego projektu i krótko wyjaśnij zastosowanie każdej z nich.
```

Claude powinien wywołać narzędzia takie jak `read_file` / `glob` / `grep`, aby przeszukać repozytorium i zwrócić listę. Na dolnym pasku stanu pojawi się komunikat `connected to api.acedata.cloud` — to kluczowy znak, że proxy działa.

## Minuta 5: Podłącz rozszerzenie VS Code

1. Otwórz VS Code → panel rozszerzeń → wyszukaj `Claude Code` i zainstaluj oficjalne rozszerzenie Anthropic;
2. **Cmd+Shift+P** → wpisz `Claude Code: Set Custom API Endpoint`;
3. Wprowadź `https://api.acedata.cloud/claude` i zatwierdź;
4. Ponownie wykonaj `Claude Code: Set API Token` i wprowadź swój Token.

Po poprawnej konfiguracji w panelu bocznym pojawi się panel Claude Code, gdzie możesz przeciągać pliki do zadawania pytań lub używać `@-mention` do proponowania zmian w plikach. Wszystkie opłaty są rozliczane przez AceData Cloud.

## Sprawdź, czy faktycznie korzystasz z proxy

W rozmowie Claude Code wpisz:

```
Odwiedź https://api.acedata.cloud/whoami i powiedz mi, co zwróciło.
```

Jeśli otrzymasz informacje o swoim koncie (`{user_id, plan, ...}`), oznacza to, że zapytanie faktycznie przeszło przez brzeg AceData Cloud. Jeśli natomiast przekieruje do oficjalnej domeny i pojawi się błąd 401, wróć do minuty 3 i sprawdź nazwę zmiennej środowiskowej.

## 5 najczęściej zadawanych pytań

**P: Po wykonaniu `claude login` i zmianie zmiennych środowiskowych na AceData, dlaczego to nie działa?**  
O: `claude login` zapisuje oficjalny token w `~/.claude/.credentials.json`, który ma wyższy priorytet niż zmienne środowiskowe. Usuń ten plik i wykonaj `source ~/.zshrc`.

**P: Czy można używać modeli o nazwach typu `--model claude-opus-4-7`?**  
O: Tak. Proxy AceData Cloud przekazuje pole model, obsługując wszystkie publiczne modele Anthropic oraz rozszerzenia takie jak `claude-opus-4-7`, `claude-haiku-4-5` i `claude-sonnet-4-5`.

**P: Czy można skonfigurować wiele profili (osobisty + firmowy)?**  
O: Tak. Claude Code obsługuje wiele profili w `~/.claude/settings.json`; najprościej jednak stworzyć dwie funkcje shellowe `claude_personal` i `claude_work`, które eksportują różne wartości `ANTHROPIC_AUTH_TOKEN` i wywołują `claude $@`.

**P: Czy można uruchamiać Claude Code w GitHub Actions?**  
O: Tak. Szczegóły znajdziesz w [Claude Code GitHub Actions tutorial](https://platform.acedata.cloud/documents/claude-code-github-actions-integration).

**P: Co po wyczerpaniu darmowego limitu?**  
O: Przejdź do [Zarządzania aplikacjami](https://platform.acedata.cloud/applications) → wybierz aplikację Claude → doładuj środki (płatność według faktycznego zużycia tokenów) lub przejdź na subskrypcję punktową.
