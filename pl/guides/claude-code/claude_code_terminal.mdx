Claude Code to narzędzie **Agentic Coding** wprowadzone przez Anthropic, znane również jako jeden z najsilniejszych agentów programistycznych na świecie. Terminal CLI jest kluczowym doświadczeniem Claude Code, możesz uruchomić polecenie `claude` w dowolnym terminalu, aby współpracować z AI w programowaniu za pomocą naturalnego języka.

Dokument ten głównie opisuje, jak zainstalować, skonfigurować i używać Claude Code CLI za pośrednictwem usługi proxy AceData Cloud w terminalu.

## Proces aplikacji

Aby korzystać z Claude Code, najpierw możesz przejść do [strony usługi Claude Messages](https://platform.acedata.cloud/documents/claude-messages) i kliknąć przycisk „Acquire”, aby uzyskać wymagane poświadczenia:

![](https://cdn.acedata.cloud/nyq0xz.png)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, po zalogowaniu lub rejestracji automatycznie wrócisz na bieżącą stronę.

Podczas pierwszej aplikacji otrzymasz darmowy limit, aby bezpłatnie wypróbować usługi Claude Code.

## Instalacja Claude Code

### Wymagania systemowe

- macOS, Linux lub Windows (w tym WSL)
- Node.js nie jest wymagany, natywna metoda instalacji automatycznie obsługuje zależności

### Metody instalacji

Claude Code obsługuje różne metody instalacji:

**Metoda 1: Natywna instalacja (zalecana)**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows CMD:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

**Metoda 2: Homebrew (macOS / Linux)**

```bash
brew install claude-code
```

**Metoda 3: WinGet (Windows)**

```cmd
winget install Claude.ClaudeCode
```

Natywna instalacja automatycznie aktualizuje się w tle, zawsze utrzymując najnowszą wersję.

## Konfiguracja AceData Cloud API

Po zakończeniu instalacji domyślnie poprosi cię o zalogowanie się na oficjalne konto Anthropic. Możemy skonfigurować zmienne środowiskowe, aby korzystać z API proxy AceData Cloud, **bez potrzeby subskrypcji oficjalnej**.

### Konfiguracja zmiennych środowiskowych

Istnieją dwie metody konfiguracji zmiennych środowiskowych, wybierz jedną z nich.

**Metoda 1: Ustawienie w pliku konfiguracyjnym Shell (zalecana)**

Dodaj poniższe treści do swojego pliku konfiguracyjnego Shell (`~/.zshrc`, `~/.bashrc` lub `~/.bash_profile`), zastępując `{token}` tokenem API uzyskanym w konsoli AceData Cloud:

```bash
# AceData Cloud - konfiguracja proxy Claude Code
export ANTHROPIC_AUTH_TOKEN="{token}"
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
```

Po modyfikacji wykonaj poniższe polecenie, aby zastosować konfigurację:

```bash
source ~/.zshrc  # lub source ~/.bashrc
```

**Metoda 2: Ustawienie w pliku settings.json Claude Code**

Edytuj `~/.claude/settings.json` (jeśli nie istnieje, utwórz go), dodaj konfigurację `env`:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "{token}",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Zaletą tej metody jest to, że zmienne środowiskowe działają tylko w Claude Code, nie wpływając na inne programy.

> **Wskazówka**: Token API można zobaczyć w [konsoli AceData Cloud](https://platform.acedata.cloud/console). Wartość `ANTHROPIC_AUTH_TOKEN` zostanie automatycznie dodana z prefiksem `Bearer` wysyłanym do serwera.

## Rozpocznij użycie

### Uruchom tryb interaktywny

Otwórz terminal, przejdź do katalogu swojego projektu, a następnie uruchom:

```bash
cd /path/to/your/project
claude
```

Zobaczysz ekran powitalny Claude Code, wystarczy wpisać naturalny język, aby rozpocząć interakcję.

### Często używane polecenia

| Polecenie               | Opis          | Przykład                   |
| ---------------------- | ----------- | -------------------- |
| `claude`               | Uruchom tryb interaktywny      | `claude`             |
| `claude "zadanie"`     | Wykonaj jednorazowe zadanie     | `claude "napraw błąd kompilacji"`    |
| `claude -p "zapytanie"`| Wykonaj zapytanie i wyjdź     | `claude -p "wyjaśnij tę funkcję"` |
| `claude -c`           | Kontynuuj ostatnią rozmowę w bieżącym katalogu | `claude -c`          |
| `claude -r`           | Przywróć poprzednią rozmowę     | `claude -r`          |
| `claude commit`       | Utwórz commit Git   | `claude commit`      |

### Polecenia w trybie interaktywnym

W trybie interaktywnym można używać następujących wbudowanych poleceń:

| Polecenie              | Funkcja        |
| --------------------- | --------- |
| `/help`               | Wyświetl informacje pomocy    |
| `/clear`              | Wyczyść historię rozmowy    |
| `/config`             | Otwórz panel ustawień    |
| `/model`              | Zmień model      |
| `/mcp`                | Zarządzaj usługą MCP |
| `/compact`            | Skondensuj kontekst     |
| `/memory`             | Zarządzaj pamięcią      |
| `/login`              | Zmień konto      |
| `exit` lub `Ctrl+C`  | Wyjdź        |

### Przykłady interakcji w rozmowie

```bash
# Analiza projektu
> co robi ten projekt?

# Naprawa błędu
> jest błąd, w którym użytkownicy mogą przesyłać puste formularze - napraw to

# Pisanie testów
> napisz testy jednostkowe dla funkcji kalkulatora

# Refaktoryzacja kodu
> refaktoryzuj moduł uwierzytelniania, aby używał async/await

# Operacje Git
> zatwierdź moje zmiany z opisowym komunikatem
> utwórz PR dla tej funkcji
```

## Zaawansowane użycie

### Potoki i skryptowanie

Claude Code przestrzega filozofii Unix, wspiera potoki i operacje skryptowe:

```bash
# Monitorowanie logów i automatyczne powiadamianie
tail -f app.log | claude -p "jeśli wykryjesz wyjątek, powiadom mnie"

# Automatyczne tłumaczenie nowych tekstów
claude -p "jeśli pojawią się nowe ciągi tekstowe, przetłumacz je na francuski i utwórz PR"

# Przegląd kodu
git diff main | claude -p "przejrzyj te zmiany"
```

### Referencje zmiennych środowiskowych

Oto powszechnie używane zmienne środowiskowe wspierane przez Claude Code:

| Zmienna                           | Opis                                    |
| ------------------------------- | ------------------------------------- |
| `ANTHROPIC_AUTH_TOKEN`          | Wartość niestandardowego nagłówka Authorization (automatycznie dodaje prefiks Bearer) |
| `ANTHROPIC_API_KEY`             | Klucz API (wysyłany jako nagłówek X-Api-Key)              |
| `ANTHROPIC_BASE_URL`            | Podstawowy URL API                            |
| `ANTHROPIC_MODEL`               | Nadpisuje domyślny model                                |
| `ANTHROPIC_SMALL_FAST_MODEL`    | Model na poziomie Haiku (do zadań w tle)                     |
| `MAX_THINKING_TOKENS`           | Ustawia budżet tokenów myślenia (ustaw na 0, aby wyłączyć tryb myślenia)            |
| `DISABLE_COST_WARNINGS`         | Ustaw na 1, aby wyłączyć powiadomienia o kosztach                           |

### Pamięć projektu CLAUDE.md

Utwórz plik `CLAUDE.md` w katalogu głównym projektu, aby dostarczyć Claude Code specyficzne instrukcje i kontekst projektu. Claude automatycznie załaduje ten plik przy uruchomieniu.

```markdown
# Opis projektu
To jest projekt full-stack Django + Vue.js.

## Zasady kodowania
- Używaj Pythona 3.12
- Przestrzegaj stylu kodu PEP 8
- Wszystkie API muszą mieć napisane testy jednostkowe
```

## Często zadawane pytania

### Co zrobić, gdy połączenie nie działa?
1. Sprawdź, czy plik `~/.claude/config.json` został poprawnie utworzony, a jego zawartość to `{"primaryApiKey": "self"}`
2. Potwierdź, że zmienne środowiskowe zostały poprawnie ustawione:
   ```bash
   echo $ANTHROPIC_AUTH_TOKEN
   echo $ANTHROPIC_BASE_URL
   ```
3. Upewnij się, że token API jest ważny (można go sprawdzić w [konsoli](https://platform.acedata.cloud/console))
4. Spróbuj ponownie uruchomić terminal

### command not found: claude

Jeśli po instalacji pojawi się komunikat `command not found`, spróbuj:

1. Zamknąć i ponownie otworzyć terminal
2. Sprawdzić PATH: `echo $PATH`
3. Ponownie zainstalować: `curl -fsSL https://claude.ai/install.sh | bash`

### Jak sprawdzić pozostały limit?

Zaloguj się do [konsoli AceData Cloud](https://platform.acedata.cloud/console), aby zobaczyć aktualny limit i wykorzystanie konta.
