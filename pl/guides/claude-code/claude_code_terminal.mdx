## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj Claude Code

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Sprawdź po instalacji:

```bash
claude --version
```

## 3. Skonfiguruj Ace Data Cloud

Aby używać globalnie, dodaj poniższe zmienne do `~/.zshrc` lub `~/.bashrc`:

```bash
export ANTHROPIC_BASE_URL="https://api.acedata.cloud"
export ANTHROPIC_AUTH_TOKEN="twój klucz API"
unset ANTHROPIC_API_KEY
```

Otwórz ponownie terminal lub użyj `source` odpowiedniego pliku konfiguracyjnego.

Aby działało tylko w bieżącym projekcie, możesz utworzyć plik `.claude/settings.local.json`, który został dodany do `.gitignore`:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud",
    "ANTHROPIC_AUTH_TOKEN": "twój klucz API"
  }
}
```

Wybierz jedną z dwóch metod. Nie zapisuj prawdziwego klucza w zespołowym `.claude/settings.json`; jeśli w środowisku istnieje już `ANTHROPIC_API_KEY`, powinien być rzeczywiście usunięty, a nie ustawiony na pusty ciąg.

## 4. Uruchom i zweryfikuj

```bash
cd /path/to/your/project
claude
```

Po wejściu wyślij zadanie tylko do odczytu, na przykład „przeczytaj README.md i podsumuj w jednym zdaniu”. Rejestry wywołań i saldo można sprawdzić w [historii użycia](https://platform.acedata.cloud/console/usages) oraz [liście aplikacji](https://platform.acedata.cloud/console/applications).

Jeśli zwróci 401, sprawdź, czy klucz jest kompletny, czy stary `ANTHROPIC_API_KEY` został usunięty i całkowicie uruchom ponownie Claude Code. Model nie musi być ustalony w konfiguracji połączenia, można go wybrać w Claude Code spośród aktualnie dostępnych modeli.
