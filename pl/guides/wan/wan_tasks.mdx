`POST https://api.acedata.cloud/wan/tasks` służy do zapytania, zbiorczego zapytania lub usunięcia zadań wideo Wan. Zapytanie o zadania nie wiąże się z dodatkowymi kosztami generacji.

## Zapytanie o pojedyncze zadanie

```bash
curl -X POST 'https://api.acedata.cloud/wan/tasks' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"TASK_ID"}'
```

Zakończone zadanie `response.data.video_url` to stały adres CDN; `response.usage` zawiera rozdzielczość, czas trwania wideo wejściowego/wyjściowego, liczbę klatek na sekundę i proporcje; `response.cost` to rozliczenie za wygenerowane zadanie.

## Zbiorcze zapytanie

```json
{
  "action": "retrieve_batch",
  "ids": [
    "TASK_ID_1",
    "TASK_ID_2"
  ]
}
```

Zwraca `{ "items": [...], "count": 2 }`. W przypadku zadań w trakcie realizacji może nie być jeszcze `finished_at` i ostatecznego `response`.

## Usunięcie rekordu zadania

```json
{
  "action": "delete",
  "id": "TASK_ID"
}
```

Usunięcie wpływa tylko na historię zadań, nie usunie wygenerowanego wideo CDN.
