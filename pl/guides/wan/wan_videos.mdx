title: "Interfejs API generowania wideo Wan"
description: "Wan API guide - Ace Data Cloud"
---

`POST https://api.acedata.cloud/wan/videos` obsługuje jednocześnie istniejące modele Wan 2.6 i `wan3.0-video`. Wan 3 automatycznie rozpoznaje tryb tekstu, pierwszej i ostatniej klatki lub materiałów referencyjnych na podstawie `media`.

## Generowanie wideo z tekstu w Wan 3

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "A paper boat drifting through a neon city at night",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 obsługuje całkowite liczby sekund od 2 do 30 lub inteligentny czas trwania `-1`, a dostępne rozdzielczości to `480P`, `720P`, `1080P`.

## Referencje multimedialne

```json
{
  "model": "wan3.0-video",
  "prompt": "Create a cinematic product reveal",
  "media": [
    {"type":"first_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622-bac6a9e9de22.png"},
    {"type":"last_frame","url":"https://cdn.acedata.cloud/assets/examples/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460-a2a2c1afbf39.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` obsługuje:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Trybu pierwszej i ostatniej klatki nie można łączyć z trybem materiałów referencyjnych. Wideo referencyjne jest ostatecznie rozliczane na podstawie rzeczywistej liczby sekund wejściowego wideo plus liczby sekund pomyślnie wygenerowanego wideo; wejścia tekstowe, obrazowe i dźwiękowe nie zwiększają liczby sekund wideo.

## Oficjalne ceny standardowe

| Rozdzielczość | Cena |
| ----- | ------: |
| 480P  | $0.05/s |
| 720P  | $0.10/s |
| 1080P | $0.20/s |

## Zgodność z Wan 2.6

Istniejące warianty `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` oraz flash nadal używają parametrów takich jak `action`, `image_url`, `reference_video_urls`, a ścieżka wywołania pozostaje bez zmian.

## Asynchroniczność i wyniki

Po ustawieniu `async: true` natychmiast otrzymasz `task_id`; stan końcowy można uzyskać przez `/wan/tasks`. Pomyślnie wygenerowane wideo zostanie zapisane w AceDataCloud CDN, a w odpowiedzi zostaną zwrócone rzeczywiste wartości usage i cost.
