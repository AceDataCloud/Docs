title: "Wan API do generowania wideo"

---

`POST https://api.acedata.cloud/wan/videos` obsługuje zarówno istniejący model Wan 2.6, jak i `wan3.0-video`. Wan 3 automatycznie rozpoznaje tekst, pierwszą i ostatnią klatkę lub wzór materiału referencyjnego na podstawie `media`.

## Wan 3 generowanie wideo

```bash
curl -X POST 'https://api.acedata.cloud/wan/videos' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "wan3.0-video",
    "prompt": "Papierowa łódka dryfująca przez neonowe miasto w nocy",
    "duration": 5,
    "resolution": "720P",
    "ratio": "16:9",
    "audio": true,
    "async": true
  }'
```

Wan 3 obsługuje całkowite czasy trwania od 2 do 30 sekund lub `-1` inteligentny czas trwania, rozdzielczości `480P`, `720P`, `1080P`.

## Materiały referencyjne

```json
{
  "model": "wan3.0-video",
  "prompt": "Stwórz filmowy pokaz produktu",
  "media": [
    {"type":"first_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/40d5c76b-2f84-4b04-9ea0-b706417ae622.png"},
    {"type":"last_frame","url":"https://platform2.cdn.acedata.cloud/qwen-image/7a5a490c-1d60-4498-a362-a9334148f460.png"}
  ],
  "duration": 8,
  "resolution": "1080P",
  "ratio": "16:9",
  "async": true
}
```

`media.type` obsługuje:

- `first_frame` / `last_frame`
- `reference_image`
- `reference_video`
- `reference_audio`
- `file` / `link`

Tryby pierwszej i ostatniej klatki oraz wzór materiału referencyjnego nie mogą być używane jednocześnie. Czas trwania wideo z materiałem referencyjnym jest obliczany na podstawie rzeczywistego czasu trwania wideo wejściowego, a tekst, obrazy i dźwięki nie zwiększają czasu trwania wideo.

## Oficjalne ceny standardowe

| Rozdzielczość |      Cena |
| ----- | ------: |
| 480P  | $0.05/sek |
| 720P  | $0.10/sek |
| 1080P | $0.20/sek |

## Kompatybilność z Wan 2.6

Istniejące `wan2.6-t2v`, `wan2.6-i2v`, `wan2.6-r2v` oraz warianty flash nadal używają parametrów takich jak `action`, `image_url`, `reference_video_urls`, a ścieżka wywołania pozostaje niezmieniona.

## Asynchroniczność i wyniki

Po ustawieniu `async: true` natychmiast otrzymasz `task_id`, a przez `/wan/tasks` uzyskasz stan końcowy. Udane wideo zostanie zapisane w AceDataCloud CDN, a w odpowiedzi zwrócone zostaną rzeczywiste zużycie i koszt.
