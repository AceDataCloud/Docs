Maestro to **natywne API** do produkcji wideo: opisujesz pożądane wideo za pomocą naturalnego języka `prompt` (opcjonalnie dołączając `file_urls` z referencyjnymi obrazami / wideo / dźwiękiem), a bezgłowy „AI reżyser” automatycznie zajmie się wyborem tematu, pisaniem scenariusza, generowaniem obrazów, lektorem, muzyką, kompozycją i renderowaniem, ostatecznie produkując gotowy film z napisami i przesyłając go do CDN.

W tym dokumencie szczegółowo opisano integrację API do generowania wideo Maestro, aby pomóc Ci szybko zintegrować i w pełni wykorzystać możliwości tego API.

Jest to **interfejs asynchroniczny**: po przesłaniu natychmiast zwraca `task_id`, a następnie można za pomocą [API zapytań o zadania Maestro](development_maestro_tasks.md) (`POST /maestro/tasks`) cyklicznie uzyskiwać wyniki (cykliczne zapytania są bezpłatne). Aby kontynuować iterację na istniejącym wideo, można użyć `action: remix` / `edit` / `extend` w połączeniu z `ref_task_id`.

## Proces aplikacji

Aby korzystać z API do generowania wideo Maestro, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), aby uzyskać swój token API, który należy zachować na przyszłość.

![](https://cdn.acedata.cloud/5hmkdg.jpg)

Jeśli nie jesteś zalogowany lub zarejestrowany, automatycznie zostaniesz przekierowany na stronę logowania, aby zarejestrować się i zalogować, a po zakończeniu zostaniesz automatycznie przekierowany z powrotem na bieżącą stronę.

**Jeden token API wystarczy do wywołania wszystkich usług platformy, nie ma potrzeby składania osobnych wniosków dla każdej usługi.** Pierwsze zgłoszenie daje darmowy limit, aby móc skorzystać z doświadczenia; gdy limit się wyczerpie, można doładować saldo ogólne w [konsoli](https://platform.acedata.cloud/console/coin).

> 📘 Pełna dokumentacja: [API do generowania wideo Maestro →](https://platform.acedata.cloud/documents/maestro-videos)

## Podstawowe użycie

`POST https://api.acedata.cloud/maestro/videos`

Najprostsze użycie wymaga jedynie przesłania naturalnego języka `prompt`, a AI reżyser automatycznie zdecyduje o scenariuszu, obrazach, lektorze i montażu. Najpierw zapoznajmy się z nagłówkami żądania i ciałem żądania, które należy ustawić.

**Nagłówki żądania** obejmują:

- `accept`: format odpowiedzi, który chcesz otrzymać, tutaj wpisz `application/json`, czyli format JSON.
- `authorization`: klucz do wywołania API, po złożeniu wniosku można go bezpośrednio wybrać z rozwijanej listy.
- `content-type`: format ciała żądania, tutaj wpisz `application/json`.

**Ciało żądania** głównie obejmuje:

- `prompt`: opis w naturalnym języku wideo, które chcesz stworzyć (temat, co ma być pokazane, styl, odbiorcy).
- `langs`: tablica języków wyjściowych, np. `["zh-cn", "en"]`, domyślnie `["zh-cn"]`.
- `aspect`: proporcje obrazu, `9:16` (domyślnie) / `16:9` / `1:1`.
- `duration`: docelowy czas trwania (sekundy), domyślnie 30.

Wszystkie pola ciała żądania przedstawione są w poniższej tabeli:

| Pole            | Typ       | Wymagane | Opis                                                                                                                                                                                                                           |
| ------------- | -------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`      | string   | Tak   | Opis w naturalnym języku wideo, które chcesz stworzyć (temat, co ma być pokazane, styl, odbiorcy). Scenariusz, obrazy, lektor i montaż są ustalane przez AI.                                                                                                                                                                             |
| `action`      | string   | Nie   | `generate` (domyślnie, generowanie nowego wideo) / `remix` / `edit` / `extend` (iteracja na istniejącym wideo, wymaga `ref_task_id`).                                                                                                                                                |
| `ref_task_id` | string   | Nie   | Wymagane, gdy `action` to remix / edit / extend: historyczne `task_id`, które jest punktem wyjścia.                                                                                                                                                                   |
| `file_urls`   | string[] | Nie   | Referencyjne media (obrazy / wideo / dźwięki URL), na przykład zdjęcia produktów, logo lub fragmenty materiałów, do których mają być dodane napisy.                                                                                                                                                                             |
| `langs`       | string[] | Nie   | Języki wyjściowe, np. `["zh-cn", "en"]`, domyślnie `["zh-cn"]`. Pierwszy to język główny; za każdą dodatkową wersję językową, która wykorzystuje te same obrazy, dodawane są tylko lektory + renderowanie, **za każdą dodatkową +6 punktów**.                                                                                                                                          |
| `aspect`      | string   | Nie   | `9:16` (domyślnie) / `16:9` / `1:1` (wskazówka dotycząca proporcji obrazu, AI może dostosować na podstawie promptu).                                                                                                                                                                         |
| `duration`    | int      | Nie   | Docelowy czas trwania (sekundy, **1–600**, maksymalnie 10 minut), domyślnie 30. **Opłaty są naliczane na podstawie rzeczywistego czasu trwania filmu**, im dłuższy, tym droższy (patrz poniżej za opłaty).                                                                                                                                                                  |
| `quality`     | string   | Nie   | Poziom produkcji (współczynnik wpływający na cenę za czas trwania): `draft` (szybki podgląd, około **0.5×** standardowego poziomu) / `standard` (domyślnie, zrównoważony, **1×**) / `premium` (bardziej szczegółowy, bardziej efektowny, dłuższy czas realizacji, około **2×** standardowego poziomu).                                                                                                             |
| `scenario`    | string   | Nie   | Wskazówka dotycząca typu wideo (tylko wskazówka, AI reżyser nadal decyduje o ostatecznej strukturze): `auto` (domyślnie) / `narrated` (wieloscenowe prawdziwe zdjęcia + narracja + karty danych) / `drama` (krótkie przedstawienie z postaciami + dialogami) / `avatar` (cyfrowa osoba / lektor, wymaga przesłania wizerunku za pomocą `file_urls`) / `motion` (abstrakcyjne dynamiczne napisy / dane / animacje logo) / `slideshow` (prezentacja / deck roadshow).                               |
| `style`       | string   | Nie   | Ustawienia stylu wizualnego: `auto` (domyślnie) / `cinematic` / `glass` / `luxury` / `swiss` / `modern` / `editorial` / `warm` / `vibrant` / `neon` / `mono` / `pastel` / `bold` / `industrial` / `futuristic` / `retro`, akceptuje również tekst swobodny jako miękką wskazówkę. Nie zmienia trasy, jest ortogonalne do `scenario`. |
| `voice`       | string   | Nie   | Głos narratora (niezależny od języka, uniwersalny): `auto` (domyślnie) / `warm-female` / `bright-female` / `anchor-female` / `clean-female` / `calm-male` / `deep-male` / `documentary-male` / `energetic-male` / `storyteller-male`.                                    |

Poniżej przedstawiamy konkretny przykład. Załóżmy, że chcemy wygenerować dwujęzyczne (chińsko-angielskie), pionowe, 20-sekundowe wideo popularnonaukowe, odpowiadający kod CURL wygląda następująco:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
  "langs": ["zh-cn", "en"],
  "aspect": "9:16",
  "duration": 20
}'
```

Odpowiedni kod w Pythonie wygląda następująco:
```python
import requests

url = "https://api.acedata.cloud/maestro/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "prompt": "用 20 秒讲清楚什么是向量数据库，适合零基础观众，结尾给一句记忆点",
    "langs": ["zh-cn", "en"],
    "aspect": "9:16",
    "duration": 20
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Kliknij uruchom, a natychmiast otrzymasz wynik, jak poniżej:

```json
{
  "success": true,
  "task_id": "f57e99c4f60f4373a15517742ce2357d",
  "trace_id": "70e1cb12-c619-4292-a416-90191205996b"
}
```

Opis pól w zwróconym wyniku jest następujący:

- `success`: Czy zadanie zostało pomyślnie złożone.
- `task_id`: ID zadania generowania wideo, które można wykorzystać do późniejszego sprawdzenia wyników za pomocą [API zapytań o zadania Maestro](development_maestro_tasks.md).
- `trace_id`: ID śledzenia tego żądania, które można podać wsparciu technicznemu w przypadku problemów.

Ponieważ produkcja wideo zajmuje dużo czasu, interfejs **natychmiast zwraca `task_id`**, nie czekając na zakończenie renderowania wideo. Następnie należy użyć `task_id` do sprawdzenia wyników, szczegóły w sekcji „Pobierz wyniki”.

## Określenie typu i stylu wideo (scenariusz / styl)

Jeśli nie przekażesz `scenariusza`, AI automatycznie go oceni (równoznaczne z `auto`); jeśli chcesz przypisać wideo do konkretnego typu, przekaż to wyraźnie. Na przykład, aby stworzyć **pionowy krótkometrażowy film**, można określić następujące treści:

- `scenariusz`: Typ wideo, tutaj ustawiony na `drama` (krótkometrażowy film z postaciami + dialogami).
- `styl`: Styl wizualny, tutaj ustawiony na `cinematic` (filmowa jakość).

Przykładowy kod CURL wygląda następująco:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "两个合租室友因为一只猫闹翻又和好，三幕反转，结尾温暖",
  "scenario": "drama",
  "style": "cinematic",
  "aspect": "9:16",
  "duration": 40
}'
```

Typowe kombinacje:

- Krótkometrażowy film: `scenario: "drama"` (postacie + dialogi).
- Cyfrowa postać / narracja: `scenario: "avatar"` i przekaż `file_urls` z wizerunkiem.
- Dynamiczne napisy / animacja danych: `scenario: "motion"`; prezentacja / roadshow: `scenario: "slideshow"`.
- `style` to wstępnie zdefiniowany styl wizualny (np. `modern` / `neon` / `luxury`), nie zmieniający typu, tylko wpływający na wrażenia wizualne.
- `voice` służy do określenia tonu narracji (np. `warm-female` / `deep-male`), niezależnie od języka, uniwersalne w różnych językach.

Wynik zwracany jest zgodny z „Podstawowym użyciem”, również natychmiast zwraca `task_id`.

## Wielojęzyczne wyjście

W `langs` można przekazać wiele języków, aby jednocześnie wygenerować wersje wielojęzyczne. Pierwszy język to język główny, a każda dodatkowa wersja językowa **używa tej samej grafiki**, tylko dodatkowo nagrywa głos + renderuje, dlatego **każdy dodatkowy język to tylko +6 punktów**. Przykład:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "prompt": "介绍我们的智能客服产品，突出 3 个核心卖点",
  "langs": ["zh-cn", "en", "ja"],
  "aspect": "16:9",
  "duration": 30
}'
```

Po zakończeniu zadania każdemu językowi odpowiada jeden `variant` w wynikach (patrz [API zapytań o zadania Maestro](development_maestro_tasks.md)).

## Iteracja na istniejącym wideo (remix / edytuj / rozszerz)

Przekazując `action` oraz `ref_task_id` z poprzedniego zadania, można wprowadzić zmiany w oparciu o oryginalny projekt (np. „zmień tytuł drugiego aktu”, „zmień głos”, „ogólnie przyciemnij”). Małe zmiany są szybkie, duże zmiany będą wymagały ponownego wykonania:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "remix",
  "ref_task_id": "f57e99c4f60f4373a15517742ce2357d",
  "prompt": "把开场标题换成更有冲击力的一句，整体配色更暗一些"
}'
```

- `remix`: Nowa interpretacja w oparciu o oryginalną strukturę wideo (zachowując temat, dostosowując wykonanie).
- `edit`: Drobne poprawki w określonym obszarze (np. zmiana tytułu, zmiana głosu, korekcja kolorów).
- `extend`: Rozszerzenie treści na podstawie oryginalnego wideo.

Wynik również natychmiast zwraca nowe `task_id`, które można wykorzystać do sprawdzenia wyników po iteracji.

## Pobierz wyniki

Ponieważ produkcja wideo zajmuje dużo czasu, ten interfejs natychmiast zwraca `task_id` po złożeniu, musisz użyć go do [API zapytań o zadania Maestro](development_maestro_tasks.md) w celu sprawdzenia wyników:

```bash
curl -X POST 'https://api.acedata.cloud/maestro/tasks' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "id": "f57e99c4f60f4373a15517742ce2357d"
}'
```

Po zakończeniu zadania zwróci informacje o gotowym materiale (każdy język odpowiada jednemu `variant`). `status` przechodzi przez `pending → planning → producing → succeeded` (lub `failed`), **sprawdzanie jest darmowe, nie zużywa punktów**. Pełny format odpowiedzi oraz historia zapytań są opisane w [Dokumentacji API zapytań o zadania Maestro](development_maestro_tasks.md).

## Rozliczenia

**Opłaty są naliczane po zakończeniu zadania na podstawie rzeczywistego materiału, a nieudane zadania nie są obciążane opłatami.** Opłaty są naliczane na podstawie rzeczywistego czasu trwania dostarczonego materiału oraz liczby języków, które zostały wygenerowane — na przykład, jeśli złożono wniosek o 600 sekund, ale ostatecznie materiał trwa 50 sekund, opłata będzie naliczana tylko za około 50 sekund; jeśli dany język nie został ostatecznie wygenerowany, nie zostanie naliczona dodatkowa opłata +6 za ten język. Złożenie zadania samo w sobie nie jest obciążane opłatami (wyniki można sprawdzać za pomocą `/maestro/tasks` bezpłatnie).

Punkty za pojedynczy materiał można oszacować według następującego wzoru:

```
punkty ≈ 0.85 × czas trwania materiału w sekundach × mnożnik jakości × mnożnik scenariusza + 6 × max(liczba języków − 1, 0)
```

- Mnożnik jakości: `draft` 0.5× / `standard` 1× (domyślnie) / `premium` 2×.
- Mnożnik scenariusza: `drama` 1.35× / `avatar` 1.15× / inne 1×.

Na przykład dla standardowej jakości, nie będącej krótkometrażowym filmem / cyfrową postacią, w przypadku jednego języka, punkty za różne czasy trwania materiału wynoszą około:
| Czas trwania filmu                | Punkty standardowe |
| --------------------------- | ----- |
| 30s                         | 25.5  |
| 60s                         | 51    |
| 120s (2 minuty)                  | 102   |
| 300s (5 minut)                  | 255   |
| 600s (10 minut, limit)              | 510   |
| Każdy dodatkowy język (`langs` powyżej 1) | +6    |
| Polling `/maestro/tasks`         | Darmowe    |

## Obsługa błędów

Podczas wywoływania API, jeśli wystąpi błąd, API zwróci odpowiedni kod błędu i informacje. Na przykład:

- `400 invalid_request`: Złe żądanie, prawdopodobnie z powodu brakującego `prompt` lub nieprawidłowych parametrów.
- `401 invalid_token`: Nieautoryzowany, nieprawidłowy lub brakujący token autoryzacyjny.
- `403 forbidden`: Zabronione, niewystarczający balans lub dostęp.
- `429 too_many_requests`: Zbyt wiele żądań, przekroczono limit szybkości.
- `500 api_error`: Błąd wewnętrzny serwera, coś poszło nie tak na serwerze.

### Przykład odpowiedzi błędu

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
