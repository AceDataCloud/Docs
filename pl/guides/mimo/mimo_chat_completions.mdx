MiMo 2.6 Pro i MiMo 2.6 Flash to modele z serii Xiaomi MiMo. Ten interfejs korzysta z formatu OpenAI Chat Completions i rozlicza tokeny wejściowe, wyjściowe oraz trafienia w pamięci podręcznej.

## Modele i interfejsy

| Model                | Pozycjonowanie           |
| ----------------- | ------------ |
| `mimo-v2.6-pro`   | Złożona analiza, wnioskowanie i wywoływanie narzędzi |
| `mimo-v2.6-flash` | Codzienne konwersacje i lekkie zadania    |

Aktywuj MiMo i uzyskaj odpowiednie poświadczenia API, aby wysyłać żądania do `https://api.acedata.cloud/mimo/chat/completions`. `base_url` pakietu OpenAI SDK można ustawić na `https://api.acedata.cloud/mimo`. Ujednolicony punkt wejścia `/v1/chat/completions` również wymaga odpowiednich uprawnień do usługi.

Początkowy zakres interfejsu obejmuje tekstowe Chat Completions; obrazy, dźwięk, wideo, wyszukiwanie w sieci, Responses, Messages, Batch i UltraSpeed nie są objęte tym wydaniem.

## Przykład w Pythonie

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["ACEDATACLOUD_API_KEY"],
    base_url="https://api.acedata.cloud/mimo",
)
response = client.chat.completions.create(
    model="mimo-v2.6-pro",
    messages=[{"role": "user", "content": "解释彩虹形成的原因。"}],
    max_completion_tokens=256,
    extra_body={"thinking": {"type": "disabled"}},
)
print(response.choices[0].message.content)
print(response.usage)
```

Przykład przedstawia sposób zapisu żądania; rzeczywisty przykład odpowiedzi zostanie uzupełniony po weryfikacji usługi.

## Strumieniowanie, wnioskowanie i wywoływanie narzędzi

Ustaw `stream=true`, aby odbierać SSE; jeśli potrzebujesz końcowego użycia, przekaż `stream_options={"include_usage": true}`. Klient powinien obsługiwać przyrosty treści, treści wnioskowania i wywołań narzędzi, a także końcowe zdarzenie usage.

Użyj `thinking.type=enabled`, aby włączyć wnioskowanie, oraz `disabled`, aby je wyłączyć. `reasoning_content` i końcowy `content` są zwracane osobno; podczas kontynuowania wywołania narzędzia zachowaj treść wnioskowania w wiadomości asystenta, pełne `tool_calls` oraz odpowiadający im `tool_call_id`.

Przesyłaj wyłącznie deklaracje narzędzi typu `type=function`, a `tool_choice` obsługuje wyłącznie `auto`. Aplikacja odpowiada za wykonanie narzędzia i przekazanie wyniku; zwrócenie przez model wywołania narzędzia samo w sobie nie oznacza, że narzędzie zostało wykonane. Wbudowane wyszukiwanie w sieci w usłudze nie jest jeszcze dostępne.

## Rozliczenia

`prompt_tokens` obejmuje dane wejściowe trafiające do pamięci podręcznej; `prompt_tokens_details.cached_tokens` jest rozliczane według ceny pamięci podręcznej, a pozostałe dane wejściowe według zwykłej ceny wejściowej. `completion_tokens` obejmuje wynik wnioskowania, nie należy ponownie sumować tokenów wnioskowania. Wywołania strumieniowe są również rozliczane według końcowego rzeczywistego użycia.

Ceny obowiązujące są dostępne w konsoli, a koszt Credit w dolarach amerykańskich zależy od zakupionego pakietu. Nieudane żądania nie powinny być traktowane jako pomyślnie ukończone; jeśli chcesz zweryfikować naliczenie opłat, podaj identyfikator śledzenia z odpowiedzi.

## Obsługa błędów

W przypadku błędów parametrów sprawdź format żądania; w przypadku błędów uwierzytelniania lub uprawnień sprawdź poświadczenia i stan aktywacji usługi; w przypadku 429 zastosuj ponowienie z wycofaniem. Gdy nie ma dostępnej pojemności sprawnych modeli, może zostać zwrócone 503. Jeśli po rozpoczęciu odpowiedzi strumieniowej wystąpi przerwanie, najpierw sprawdź otrzymane wyniki i użycie, aby uniknąć bezrefleksyjnego powtarzania żądania.
