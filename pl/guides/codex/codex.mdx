---
title: "Instrukcja konfiguracji Codex"
description: "Codex 集成指南 - Ace Data Cloud"
---

Codex CLI to otwartoźródłowy lokalny agent programistyczny stworzony przez OpenAI, który pozwala na czytanie kodu, modyfikowanie plików, uruchamianie poleceń oraz wspomaganie zadań programistycznych bezpośrednio w terminalu. Dzięki proxy Ace Data Cloud możesz korzystać z Codex CLI po niższych kosztach, bez konieczności osobnej subskrypcji oficjalnego konta OpenAI.

Wybierz odpowiednią instrukcję konfiguracji w zależności od scenariusza użycia:

| Platforma | Opis | Link do instrukcji |
|-----------|------|--------------------|
| **VS Code** | Oficjalne rozszerzenie, czat w panelu bocznym edytora, odwołania do plików, podgląd różnic | [Instrukcja konfiguracji VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration) |
| **Terminal (CLI)** | Podstawowe doświadczenie, uruchom `codex` w dowolnym terminalu, aby rozpocząć | [Instrukcja konfiguracji terminala](https://platform.acedata.cloud/documents/codex-terminal-integration) |

> **Wskazówka**: Aby uzyskać token API i darmowy limit, odwiedź [Konsolę Ace Data Cloud](https://platform.acedata.cloud/console/applications). Codex CLI działa przez kompatybilny interfejs OpenAI Responses Ace Data Cloud (`/v1/responses`). Więcej informacji o modelach i rozliczeniach znajdziesz na [stronie usług OpenAI](https://platform.acedata.cloud/documents/openai).
