Codex CLI, Desktop i rozszerzenie VS Code korzystają z `~/.codex/config.toml`. Skonfiguruj raz dostawcę `acedatacloud`, aby móc korzystać z Codex przez Ace Data Cloud.

| Sposób użycia     | Przewodnik konfiguracji                                                                  |
| ---------------- | ------------------------------------------------------------------------------------- |
| Terminal / CLI   | [Codex CLI](https://platform.acedata.cloud/documents/codex-terminal-integration)      |
| Desktop          | [Codex Desktop](https://platform.acedata.cloud/documents/codex-desktop-integration)   |
| VS Code          | [Codex for VS Code](https://platform.acedata.cloud/documents/codex-vscode-integration)|
| Graficzne przełączanie | [Codex CC Switch](https://platform.acedata.cloud/documents/codex-cc-switch-integration) |

Wspólna konfiguracja składa się z trzech elementów:

- Dostawca: `acedatacloud`
- Podstawowy URL: `https://api.acedata.cloud/v1`
- Klucz API: uzyskaj z [listy aplikacji](https://platform.acedata.cloud/console/applications) i zapisz w `ACEDATACLOUD_API_KEY`

Nie ma potrzeby ustalania modelu w konfiguracji dostępu; po uruchomieniu Codex można bezpośrednio wybrać model.

Powrót do [Centrum konfiguracji planu kodowania](https://platform.acedata.cloud/documents/coding-plan-integration).
