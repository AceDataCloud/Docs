Rozszerzenie Codex VS Code dzieli `~/.codex/config.toml` z Codex CLI.

## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnej aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj rozszerzenie

Zainstaluj **Codex – OpenAI's coding agent** wydane przez OpenAI w rynku rozszerzeń VS Code lub uruchom:

```bash
code --install-extension openai.chatgpt
```

## 3. Ustaw klucz API

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="twój klucz API"
```

Aby był trwały, dodaj ten wiersz do `~/.zshrc` lub `~/.bashrc`. Windows PowerShell używa:

```powershell
setx ACEDATACLOUD_API_KEY "twój klucz API"
```

## 4. Skonfiguruj AceDataCloud

Edytuj `~/.codex/config.toml` (Windows to `%USERPROFILE%\.codex\config.toml`), dodaj:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

Windows zmień ostatnie dwie linie na:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Nie musisz wypełniać `model`; możesz wybrać model w panelu Codex.

## 5. Zrestartuj i zweryfikuj

Całkowicie zamknij i ponownie otwórz VS Code, a następnie otwórz panel Codex. Uruchom `/model`, upewnij się, że Provider to `acedatacloud`, a następnie wyślij prostą wiadomość; rejestr wywołań można zobaczyć w [historii użycia](https://platform.acedata.cloud/console/usages).

Jeśli rozszerzenie nie może odczytać klucza, uruchom VS Code z terminala, w którym ustawiono zmienną środowiskową, lub ustaw zmienną środowiskową na poziomie systemu, a następnie zrestartuj VS Code. Remote SSH, WSL i Dev Container muszą być skonfigurowane w rzeczywistym środowisku, w którym działa rozszerzenie.
