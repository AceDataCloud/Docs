CC Switch można zarządzać providerem i kluczem API Codex za pomocą interfejsu graficznego.

## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj CC Switch

Pobierz i zainstaluj z [CC Switch Releases](https://github.com/farion1231/cc-switch/releases/latest), lub uruchom na macOS:

```bash
brew install --cask cc-switch
```

## 3. Dodaj provider

1. Otwórz CC Switch, przełącz się na **Codex**.
2. Kliknij **Add Provider**, wybierz **Custom**.
3. Wypełnij:

| Pole      | Zawartość                        |
| --------- | ------------------------------- |
| Name      | `acedatacloud`                 |
| Base URL  | `https://api.acedata.cloud/v1` |
| API Key   | Właśnie skopiowany klucz API Ace Data Cloud   |

Jeśli CC Switch oferuje edytor konfiguracji niestandardowej, konfiguracja powinna pozostać jako:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"
requires_openai_auth = true
```

CC Switch zapisze klucz API w `~/.codex/auth.json`:

```json
{
  "OPENAI_API_KEY": "{token}"
}
```

Nie dodawaj `env_key` ani `[model_providers.acedatacloud.auth]` w powyższym providerze; ręczna konfiguracja lub konfiguracja CC Switch, wybierz jedną. Nie ma potrzeby ustalania `model`, można go wybrać bezpośrednio w Codex.

## 4. Włącz i zweryfikuj

Włącz provider `acedatacloud`, całkowicie zamknij i uruchom ponownie Codex lub VS Code. Uruchom `/model`, potwierdź, że provider to `acedatacloud`, a następnie wybierz model i wyślij prostą wiadomość.

Jeśli zwróci 401, upewnij się, że aktualnie włączony jest `acedatacloud`, i sprawdź, czy `OPENAI_API_KEY` w `~/.codex/auth.json` to właśnie skopiowany klucz API Ace Data Cloud. Rejestr wywołań można zobaczyć w [historii użycia](https://platform.acedata.cloud/console/usages).
