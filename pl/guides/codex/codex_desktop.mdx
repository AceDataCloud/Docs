title: "Przewodnik konfiguracji Codex Desktop"
description: "Codex API guide - Ace Data Cloud"
---

Codex Desktop dzieli `~/.codex/config.toml` z Codex CLI.

## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnej aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Ustaw klucz API

macOS：

```bash
launchctl setenv ACEDATACLOUD_API_KEY "twój klucz API"
```

Windows PowerShell：

```powershell
setx ACEDATACLOUD_API_KEY "twój klucz API"
```

## 3. Konfiguracja AceDataCloud

Edytuj `~/.codex/config.toml` (w Windows to `%USERPROFILE%\.codex\config.toml`), dodaj:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

W Windows zmień ostatnie dwie linie na:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Nie ma potrzeby wypełniania `model`; po otwarciu Codex wybierz model bezpośrednio.

## 4. Uruchom ponownie i zweryfikuj

Całkowicie zamknij i ponownie otwórz Codex Desktop, utwórz lokalne zadanie i wyślij prostą wiadomość. Provider powinien być wyświetlany jako `acedatacloud`; rzeczywiste wywołania można zobaczyć w [historii użycia](https://platform.acedata.cloud/console/usages).

Jeśli konfiguracja nie działa, upewnij się, że edytujesz `~/.codex/config.toml` dla bieżącego użytkownika, zmienna środowiskowa została ustawiona, a następnie ponownie całkowicie uruchom aplikację. Zadania w chmurze lub automatyzacja działają w różnych środowiskach, więc klucz należy skonfigurować osobno w odpowiednim środowisku.
