## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj Codex

```bash
npm install -g @openai/codex
```

## 3. Ustaw klucz API

macOS / Linux:

```bash
export ACEDATACLOUD_API_KEY="twój klucz API"
```

Aby był trwały, dodaj ten wiersz do `~/.zshrc` lub `~/.bashrc`. Windows PowerShell użyj:

```powershell
setx ACEDATACLOUD_API_KEY "twój klucz API"
```

Po ustawieniu ponownie otwórz terminal.

## 4. Skonfiguruj AceDataCloud

Edytuj `~/.codex/config.toml` (w Windows `%USERPROFILE%\.codex\config.toml`), dodaj:

```toml
model_provider = "acedatacloud"

[model_providers.acedatacloud]
name = "acedatacloud"
base_url = "https://api.acedata.cloud/v1"

[model_providers.acedatacloud.auth]
command = "sh"
args = ["-c", "echo $ACEDATACLOUD_API_KEY"]
```

W Windows zmień ostatnie dwie linie na:

```toml
command = "powershell"
args = ["-NoProfile", "-Command", "Write-Output $env:ACEDATACLOUD_API_KEY"]
```

Nie musisz wypełniać `model`; po uruchomieniu możesz wybrać model w Codex. Istniejące inne konfiguracje można zachować, nie twórz ponownie dostawcy o tej samej nazwie.

## 5. Uruchom

```bash
cd /path/to/your/project
codex
```

Po wejściu do Codex uruchom `/model`, aby potwierdzić, że dostawca to `acedatacloud`, a następnie wybierz potrzebny model. Historia wywołań i saldo można sprawdzić w [historii użycia](https://platform.acedata.cloud/console/usages) oraz [liście aplikacji](https://platform.acedata.cloud/console/applications).

Jeśli pojawi się komunikat o braku klucza lub zwróci 401, upewnij się, że zmienna środowiskowa została ustawiona, a następnie całkowicie zamknij i ponownie otwórz terminal oraz Codex.
