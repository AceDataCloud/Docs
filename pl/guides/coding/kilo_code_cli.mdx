## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguracja

Kilo CLI odczytuje `kilo.jsonc` i pobiera klucz API z powłoki, w której uruchamiasz CLI.

Wpisz w `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

Następnie w bieżącej powłoce wyeksportuj token:

```bash
export ACEDATACLOUD_API_KEY="WSTAW_TUTAJ_SWÓJ_TOKEN_ACEDATACLOUD_API"
```

## 3. Weryfikacja

```bash
kilo run -m acedatacloud/MODEL_ID "Odpowiedz tylko OK"
```

Jeśli CLI nie może odczytać tokena, upewnij się, że zmienna została `export`, a nie tylko zapisana w niezładowanym pliku `.env`.
