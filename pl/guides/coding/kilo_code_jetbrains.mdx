## 1. 获取 API Key

Otwórz [Ace Data Cloud 应用列表](https://platform.acedata.cloud/console/applications)，进入可用的应用并复制 API Key。

![获取 Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. 配置 Provider

Wtyczka Kilo Code dla JetBrains używa formatu `kilo.jsonc` Provider. Konfiguracja musi znajdować się w rzeczywistym środowisku użytkownika, w którym działa wtyczka; podczas zdalnego rozwoju zazwyczaj jest to zdalny host backend.

Wpisz w `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": { "MODEL_ID": { "name": "MODEL_ID" } }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

W środowisku uruchamiającym backend JetBrains wyeksportuj `ACEDATACLOUD_API_KEY`, a następnie zrestartuj IDE lub zdalny backend.

## 3. 验证

Wybierz `acedatacloud/MODEL_ID`, wyślij `Reply only OK`, a następnie pozwól Agentowi odczytać plik testowy. Jeśli lokalnie działa poprawnie, a zdalnie nie, najpierw sprawdź, czy plik konfiguracyjny i zmienne środowiskowe są zapisane na zdalnym hoście.
