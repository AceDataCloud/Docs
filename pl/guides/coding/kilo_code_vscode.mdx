## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), wejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskiwanie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Dodaj Custom provider

W Kilo Code otwórz **Settings → Providers**, kliknij **Custom provider**, a następnie wypełnij:

| Pole           | Wartość                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------- |
| Provider ID  | `acedatacloud`                                                                                 |
| Display name | `AceDataCloud`                                                                                 |
| Provider API | `OpenAI Compatible`                                                                            |
| Base URL     | `https://api.acedata.cloud/v1`                                                                 |
| API key      | Właśnie skopiowany API Key                                                                       |
| Models       | Przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić i dodać nazwę modelu do użycia, na przykład `claude-opus-5`, `gpt-6-sol` |

![Interfejs konfiguracji Kilo Code Custom provider](https://cdn.acedata.cloud/94eb5abd7a6f.png)

`id` modelu tutaj to nazwa modelu używana przez parametr `model` w żądaniu API, a nie UUID usługi ani API. Najpierw można sprawdzić w [katalogu modeli](https://platform.acedata.cloud/models); podczas dokładnej weryfikacji skopiuj bez zmian z tablicy `data` odpowiedzi `/v1/models`, nie zgaduj ani nie skracaj samodzielnie.

Kliknij **Submit**, a model pojawi się w selektorze. Gdy wymagane jest udostępnianie zespołowe lub bardziej szczegółowa konfiguracja, można także zgodnie z oficjalną dokumentacją edytować plik na poziomie użytkownika `~/.config/kilo/kilo.jsonc` lub na poziomie projektu `./kilo.jsonc`.

## 3. Weryfikacja

Wybierz `acedatacloud/MODEL_ID` i wyślij `Reply only OK`, a następnie wykonaj jeszcze raz operację tylko do odczytu pliku. Jeśli model się nie pojawi, sprawdź, czy Provider został przesłany, czy nazwa modelu jest całkowicie zgodna z `id` w katalogu oraz czy Base URL jest poprawny.
