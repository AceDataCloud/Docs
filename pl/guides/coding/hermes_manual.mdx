## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskaj Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zapisz Key

Wpisz w `~/.hermes/.env`:

```dotenv
ACEDATACLOUD_API_KEY=twój API Key
```

## 3. Skonfiguruj Provider

Dodaj do `~/.hermes/config.yaml`:

```yaml
providers:
  acedatacloud:
    api: https://api.acedata.cloud/v1
    key_env: ACEDATACLOUD_API_KEY
    transport: chat_completions
    default_model: MODEL_ID

model:
  provider: custom:acedatacloud
  default: MODEL_ID
```

Przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić nazwy modeli (na przykład `claude-opus-5`, `gpt-6-sol`), i zastąp wszystkie `MODEL_ID` tą samą nazwą; w przypadku dokładnej weryfikacji kieruj się wartością `id` w odpowiedzi `/v1/models`. Ta wartość jest nazwą modelu używaną przez parametr API `model`, a nie UUID usługi ani API. Nie zapisuj prawdziwego Key w YAML ani nie przesyłaj `.env`.

## 4. Weryfikacja

```bash
hermes config check
hermes -z "Reply only OK" --provider custom:acedatacloud --model MODEL_ID --ignore-rules
```

Jeśli zwracany jest 401, sprawdź `~/.hermes/.env`; jeśli konfiguracja nie weszła w życie, całkowicie zamknij i uruchom ponownie Hermes.
