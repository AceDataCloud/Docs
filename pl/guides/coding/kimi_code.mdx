## 1. Uzyskiwanie API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskiwanie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Instalacja Kimi Code

macOS / Linux：

```bash
curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://code.kimi.com/kimi-code/install.ps1 | iex
```

Można również zainstalować przez npm：

```bash
npm install -g @moonshot-ai/kimi-code
```

## 3. Konfiguracja AceDataCloud

Edytuj `~/.kimi/config.toml`, dodaj następującą konfigurację：

```toml
default_model = "acedatacloud/MODEL_ID"

[providers.acedatacloud]
type = "openai"
base_url = "https://api.acedata.cloud/v1"
api_key = "twoje API Key"

[models."acedatacloud/MODEL_ID"]
provider = "acedatacloud"
model = "MODEL_ID"
```

Przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić nazwy modeli (na przykład `claude-opus-5`, `gpt-6-sol`), i zastąp wszystkie `MODEL_ID` tą samą nazwą; w przypadku dokładnej weryfikacji, kieruj się wartością `id` w odpowiedzi `/v1/models`. Ta wartość jest nazwą modelu używaną przez parametr API `model`, a nie UUID usługi lub API. `type = "openai"` używa protokołu OpenAI Chat Completions.

Plik konfiguracyjny zawiera Key, w systemach macOS / Linux zaleca się ograniczenie uprawnień：

```bash
chmod 600 ~/.kimi/config.toml
```

## 4. Weryfikacja i uruchomienie

```bash
kimi doctor
kimi provider list
kimi -p "Reply only OK"
```

Po wejściu do projektu uruchom `kimi`, aby rozpocząć korzystanie. Jeśli zwrócony zostanie błąd 401, sprawdź API Key; jeśli pojawi się komunikat model not found, upewnij się, że `default_model`, nazwa w tabeli modeli i pole `model` używają tego samego ID.
