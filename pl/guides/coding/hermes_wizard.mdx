## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskaj Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Uruchom kreator

```bash
hermes model
```

Wybierz **Custom endpoint**, a następnie kolejno wypełnij:

| Pole             | Wartość                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Base URL       | `https://api.acedata.cloud/v1`                                                                 |
| API Key        | Właśnie skopiowany API Key                                                                                  |
| API mode       | `chat_completions`                                                                             |
| Model          | Przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić, i wpisz dokładną nazwę docelowego modelu, na przykład `claude-opus-5`, `gpt-6-sol` |
| Context length | Pozostaw puste, aby wykryć automatycznie, lub wypełnij zgodnie z katalogiem modeli                                                                                |
| Display name   | `Ace Data Cloud`                                                                               |

`Model` to nazwa modelu używana przez parametr `model` w żądaniu API, a nie UUID usługi ani API. Możesz najpierw sprawdzić ją w [katalogu modeli](https://platform.acedata.cloud/models); jeśli potrzebujesz dokładnej weryfikacji, użyj następnie bieżącego API Key, aby wysłać żądanie `GET https://api.acedata.cloud/v1/models`, i skopiuj wartość `id` docelowego modelu z tablicy `data` w odpowiedzi.

Kreator zapisze dane w `~/.hermes/config.yaml` oraz w lokalnym pliku poświadczeń.

## 3. Weryfikacja

```bash
hermes config check
hermes -z "Reply only OK" --provider custom --model MODEL_ID --ignore-rules
```

Jeśli kreator nie zapisał konfiguracji, możesz uruchomić `hermes model --reset`, a następnie spróbować ponownie; 401 oznacza, że API Key jest nieprawidłowy albo nie został odczytany przez konfigurację bieżącego użytkownika.
