Qwen Code używa konfiguracji `modelProviders` w `~/.qwen/settings.json` do dostosowania dostawcy. Tutaj używamy protokołu zgodnego z OpenAI.

## Konfiguracja

```json
{
  "modelProviders": {
    "acedatacloud": [
      {
        "id": "MODEL_ID",
        "name": "MODEL_ID",
        "envKey": "ACEDATACLOUD_API_KEY",
        "baseUrl": "https://api.acedata.cloud/v1",
        "provider": "openai"
      }
    ]
  },
  "providerProtocol": { "acedatacloud": "openai" }
}
```

`modelProviders.acedatacloud` musi być tablicą. Pozycje dostawcy są niezależnie konfigurowane i nie dziedziczą automatycznie innych parametrów kontekstu, nagłówka ani ciała.

## Weryfikacja

```bash
export ACEDATACLOUD_API_KEY="WSTAW_TWÓJ_TOKEN_API_ACEDATACLOUD_TUTAJ"
qwen --auth-type openai --model MODEL_ID --output-format stream-json \
  --prompt "Odpowiedz tylko OK"
```

Po wejściu wyślij `Odpowiedz tylko OK`, a następnie uruchom ponownie narzędzie do odczytu plików. Jeśli ściśle zgodny punkt końcowy odrzuca format wyników narzędzia, sprawdź bieżącą wersję Qwen Code i oficjalne informacje o zgodności.
