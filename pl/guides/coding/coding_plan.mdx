Cztery warianty planu mają ten sam zakres dostępu do modeli; ceny i limity promocyjne są zgodne ze [stroną cenową Coding Plan](https://platform.acedata.cloud/services/coding?tab=pricing). Coding Application nie korzysta z salda ogólnego.

Konkretne poświadczenia mogą również podlegać ograniczeniom `allowed_api_ids` i zakresu uprawnień aplikacji.

## Dynamiczny katalog modeli

Możesz najpierw otworzyć [katalog modeli](https://platform.acedata.cloud/models), aby sprawdzić aktualne nazwy modeli, na przykład `claude-opus-5`, `gpt-6-sol`. Gdy potrzebujesz potwierdzić, czy poświadczenia Coding i protokół API są zgodne, użyj prawidłowych poświadczeń Coding Application, aby wysłać żądanie:

```bash
curl https://api.acedata.cloud/v1/models \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

Katalog modeli będzie stale się zmieniał; w tym dokumencie nie jest utrzymywana stała liczba ani statyczna lista modeli. `id` każdego wpisu w odpowiedzi jest **nazwą modelu**, którą można bezpośrednio przekazać do parametru API `model`, na przykład `{"id":"deepseek-v4-pro"}` odpowiada wpisaniu `deepseek-v4-pro`; nie jest to UUID usługi, API ani Application. `/v1/models` zwraca globalny katalog modeli i nie jest automatycznie filtrowany według poświadczeń Coding; przed konfiguracją nadal należy krzyżowo potwierdzić zakres API poświadczeń, wybrany protokół i zakres kompatybilności klienta.

## Częste rozwiązywanie problemów

- **Niewystarczające saldo**: przejdź do [konsoli Applications](https://platform.acedata.cloud/console/applications), znajdź Coding Application i aktywnie odnów zakup.
- **Klient nadal wysyła żądania na pierwotny adres**: potwierdź, że konfiguracja należy do tego samego użytkownika i obszaru roboczego, który uruchamia klienta, a następnie całkowicie zamknij i ponownie uruchom klienta.
- **Nazwa modelu jest niedostępna**: ponownie wyślij żądanie do `/v1/models`, sprawdź, czy wpisana nazwa modelu jest dokładnie zgodna z `id` w katalogu, zakresem API poświadczeń i protokołem obsługiwanym przez klienta.
- **Token nie może wywołać interfejsu**: potwierdź, że poświadczenia należą do Coding Application, i sprawdź `allowed_api_ids` oraz uprawnienia API aplikacji.
