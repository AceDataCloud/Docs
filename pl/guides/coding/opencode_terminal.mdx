## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskaj Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj OpenCode

```bash
curl -fsSL https://opencode.ai/install | bash
```

Możesz również użyć npm:

```bash
npm install -g opencode-ai
```

## 3. Ustaw API Key

```bash
export ACEDATACLOUD_API_KEY="Twój API Key"
```

Aby ustawienie działało długoterminowo, dodaj tę linię do `~/.zshrc` lub `~/.bashrc`, a następnie ponownie otwórz terminal.

## 4. Skonfiguruj Provider

Edytuj `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ace Data Cloud",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  }
}
```

Przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić nazwę modelu (na przykład `claude-opus-5`, `gpt-6-sol`), i zastąp wszystkie `MODEL_ID` tą samą nazwą; przy precyzyjnej weryfikacji kieruj się wartością `id` w odpowiedzi `/v1/models`. Ta wartość jest nazwą modelu używaną przez parametr API `model`, a nie UUID usługi ani API. Ace Data Cloud używa tutaj Chat Completions, więc adapterem jest `@ai-sdk/openai-compatible`.

## 5. Zweryfikuj i uruchom

```bash
opencode auth list
opencode models acedatacloud
opencode run --model acedatacloud/MODEL_ID "Reply only OK"
```

Następnie uruchom `opencode` w katalogu projektu. Jeśli model się nie pojawia, sprawdź ścieżkę pliku konfiguracyjnego, składnię JSON i zmienne środowiskowe; 401 oznacza, że Key jest nieprawidłowy lub nie został wyeksportowany.

Rozszerzenie IDE ponownie wykorzystuje tę samą konfigurację runtime OpenCode, zobacz [OpenCode IDE Extension](https://platform.acedata.cloud/documents/opencode-ide-integration).
