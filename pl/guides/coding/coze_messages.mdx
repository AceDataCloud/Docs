Dokumentacja oficjalna Coze dotycząca modeli niestandardowych wspiera API Anthropic Messages. Różne wersje najemców Coze mogą różnić się w obsłudze nagłówków, łączenia ścieżek, streamingu i wywołań narzędzi, dlatego przy pierwszym połączeniu proszę sprawdzić każdy punkt poniżej.

## Konfiguracja

1. Wejdź do zarządzania modelami Coze i dodaj nowy model niestandardowy.
2. Wybierz protokół Anthropic Messages API.
3. Wypełnij Base API URL jako `https://api.acedata.cloud`.
4. Wypełnij API Key swoim tokenem API Ace Data Cloud.
5. Wypełnij Model dokładnym identyfikatorem modelu wspierającym Anthropic Messages w katalogu modeli.
6. Zapisz i zakończ test połączenia Coze.
7. W Bot/Agent wyślij `Reply only OK`, a następnie przetestuj ponownie wywołanie narzędzia.

## Aktualne ograniczenia

- Różne regiony, wersje lub plany Coze mogą wyświetlać różne formularze.
- Base API URL nie powinien być powtarzająco uzupełniany o `/v1/messages`; jeśli obecny interfejs użytkownika wyraźnie wymaga pełnego URL API, należy kierować się wskazówkami formularza.
- Messages, Chat Completions i Responses to trzy niezależne ścieżki, które nie mogą się wzajemnie zastępować w weryfikacji.
