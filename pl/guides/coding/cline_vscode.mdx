## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskiwanie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Skonfiguruj Cline

Zainstaluj i otwórz Cline w VS Code, a następnie przejdź do konfiguracji Provider za pomocą przycisku ustawień w panelu Cline i wypełnij:

| Pole                                | Wartość                                                                                              |
| --------------------------------- | ---------------------------------------------------------------------------------------------- |
| API Provider                      | `OpenAI Compatible`                                                                            |
| Base URL                          | `https://api.acedata.cloud/v1`                                                                 |
| API Key                           | Właśnie skopiowany API Key                                                                                  |
| Model ID                          | Przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić, i wpisz dokładnie nazwę docelowego modelu, na przykład `claude-opus-5`、`gpt-6-sol` |
| Custom Headers                    | Pozostaw puste                                                                                             |
| Set Azure API version             | Pozostaw puste                                                                                             |
| Use Azure Identity Authentication | Wyłącz                                                                                             |

![Interfejs konfiguracji Cline OpenAI Compatible](https://cdn.acedata.cloud/8f356c2f1378.png)

`Model ID` jest nazwą modelu używaną przez parametr `model` w żądaniu API, a nie UUID usługi lub API, i nie można go samodzielnie skracać. Możesz najpierw sprawdzić go w [katalogu modeli](https://platform.acedata.cloud/models); jeśli potrzebujesz dokładnej weryfikacji, użyj bieżącego API Key, aby wysłać żądanie `GET https://api.acedata.cloud/v1/models`, a następnie skopiuj wartość `id` docelowego modelu z tablicy `data` w odpowiedzi.

Pozostałe konfiguracje możliwości modelu pozostaw na razie domyślne; gdy potrzebujesz obrazów lub większego kontekstu, dostosuj je zgodnie z rzeczywistymi możliwościami wybranego modelu.

## 3. Weryfikacja

Po zapisaniu utwórz nowe zadanie i wyślij `Reply only OK`. Następnie poproś Cline o odczytanie pliku testowego, aby potwierdzić, że model obsługuje wywoływanie narzędzi; historię wywołań można sprawdzić w [historii użycia](https://platform.acedata.cloud/console/usages).

401 zazwyczaj oznacza nieprawidłowy Key; 404 zazwyczaj oznacza, że Base URL jest niepoprawny lub podany Model ID nie jest całkowicie zgodny z `id` w katalogu. Jeśli model potrafi prowadzić rozmowę, ale nie może operować na plikach, sprawdź możliwości wywoływania narzędzi tego modelu.
