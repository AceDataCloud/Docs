## 1. Uzyskaj API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Uzyskiwanie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Konfiguracja

Roo Code oficjalnie udostępnia OpenAI-compatible Provider i wymaga, aby model obsługiwał natywne OpenAI tools/function calling.

1. Otwórz ustawienia Roo Code w VS Code.
2. Ustaw **API Provider** na **OpenAI Compatible**.
3. Wypełnij:

| Pole       | Wartość                              |
| -------- | ------------------------------ |
| Base URL | `https://api.acedata.cloud/v1` |
| API Key  | Właśnie skopiowany API Key                  |
| Model ID | Model ID wybrany w kreatorze konfiguracji Coding         |

![Interfejs konfiguracji Roo Code OpenAI Compatible](https://cdn.acedata.cloud/b6a0e7156438.png)

Następnie ustaw opcje context, max output, obrazu i computer-use zgodnie z rzeczywistymi możliwościami modelu. Na końcu zapisz konfigurację i ponownie załaduj VS Code.

## 3. Weryfikacja

Najpierw wyślij `Reply only OK`, a następnie poproś Roo Code o odczytanie pliku testowego. Jeśli zwykły czat działa pomyślnie, ale narzędzia Agent nie działają, zmień model na taki, który obsługuje natywne tool calling, i potwierdź, że kompatybilny endpoint może poprawnie strumieniowo zwracać parametry oraz wyniki narzędzi.
