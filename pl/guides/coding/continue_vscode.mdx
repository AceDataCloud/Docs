Continue wspiera API zgodne z OpenAI. Aby wymusić korzystanie z Chat Completions, należy jawnie ustawić `useResponsesApi: false`.

## Konfiguracja

W lokalnej konfiguracji YAML Continue dodaj:

```yaml
models:
  - name: MODEL_ID
    provider: openai
    model: MODEL_ID
    apiBase: https://api.acedata.cloud/v1
    apiKey: ${{ secrets.ACEDATACLOUD_API_KEY }}
    useResponsesApi: false
```

W zarządzaniu sekretami Continue zapisz `ACEDATACLOUD_API_KEY`, nie przesyłaj prawdziwego tokena do konfiguracji projektu. JSON konfiguracja Continue została porzucona, nowa konfiguracja używa YAML.

## Weryfikacja

Przeładuj VS Code, otwórz boczny panel Continue, wybierz model w Local Config i wyślij `Reply only OK`; następnie wykonaj ponownie zadanie tylko do odczytu. Jeśli żądanie błędnie trafi do `/responses`, sprawdź, czy `useResponsesApi: false` znajduje się w tym wpisie modelu.
