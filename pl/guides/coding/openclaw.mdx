## 1. Uzyskaj klucz API

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnych aplikacji i skopiuj klucz API.

![Uzyskaj klucz API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Zainstaluj OpenClaw i wtyczkę

```bash
npm install -g openclaw@latest
openclaw plugins install npm:@acedatacloud/openclaw-provider@2026.5.34 --pin
```

Wtyczka wymaga OpenClaw `2026.4.2` lub wyższej wersji, obecnie natywnie oferuje możliwości Chat i Web Search.

## 3. Skonfiguruj klucz

Zaleca się użycie onboarding:

```bash
openclaw onboard \
  --auth-choice acedatacloud-api-key \
  --acedata-api-key "twój klucz API"
```

Można również użyć zmiennych środowiskowych:

```bash
export ACEDATACLOUD_API_KEY="twój klucz API"
```

## 4. Opcjonalnie: ręczna konfiguracja

Nie używając onboarding, włącz wtyczkę i ustaw domyślny model w `~/.openclaw/openclaw.json`:

```json
{
  "agents": {
    "defaults": {
      "model": { "primary": "acedatacloud/MODEL_ID" }
    }
  },
  "plugins": {
    "allow": ["acedatacloud"],
    "entries": {
      "acedatacloud": { "enabled": true }
    }
  }
}
```

Nie zapisuj klucza API w tym pliku; kontynuuj używanie zmiennych środowiskowych.

## 5. Wybierz model i zweryfikuj

```bash
openclaw plugins info acedatacloud --runtime
openclaw plugins doctor
openclaw models list --all --provider acedatacloud
openclaw agent --local --session-id coding-plan-check \
  --model acedatacloud/MODEL_ID --json -m "Odpowiedz tylko OK"
```

Zamień `MODEL_ID` na model aktualnie oferowany przez Coding Plan. Aby ustawić go jako domyślny model, uruchom:

```bash
openclaw models set acedatacloud/MODEL_ID
```

Rekordy wywołań można zobaczyć w [historii użycia](https://platform.acedata.cloud/console/usages). 401 oznacza, że klucz jest nieprawidłowy; jeśli model nie istnieje, najpierw sprawdź dokładny identyfikator i wersję wtyczki. `cost: 0` w katalogu wtyczek oznacza tylko, że OpenClaw nie oszacowuje ponownie, rzeczywiste koszty są nadal rejestrowane przez Ace Data Cloud.

## Web Search

```bash
openclaw infer web search \
  --provider acedatacloud --query "najlepsze ramy agentów AI" --limit 5
```

Obecnie nie traktuj możliwości przedstawionych w wtyczce, takich jak obrazy, wideo czy muzyka, jako natywnych możliwości dostawcy OpenClaw.
