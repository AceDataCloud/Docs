Aider łączy się z API zgodnym z OpenAI za pomocą prefiksu modelu `openai/` LiteLLM.

## Konfiguracja

```bash
export AIDER_OPENAI_API_BASE="https://api.acedata.cloud/v1"
export AIDER_OPENAI_API_KEY="$ACEDATACLOUD_API_KEY"
aider --model openai/MODEL_ID
```

Zamień `MODEL_ID` na model wybrany w kreatorze konfiguracji Coding. Możesz również wpisać odpowiednie opcje do lokalnego pliku `.env` lub `.aider.conf.yml`, ale nie przesyłaj prawdziwego Tokena.

## Weryfikacja

```bash
aider --model openai/MODEL_ID --message "Odpowiedz tylko OK"
```

Podczas pierwszego użycia nieznanego modelu Aider może zgłosić brak metadanych modelu; nie jest to równoznaczne z niepowodzeniem autoryzacji. 401 sprawdza Token, 404 sprawdza ID modelu i adres URL Base `/v1`.
