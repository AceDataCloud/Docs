---
title: "API zdjęcia mówiącego (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Jednym kliknięciem przekształć **zdjęcie + audio** w „mówiące wideo”. Usługa automatycznie wykonuje dwa kroki: najpierw używa image2video, aby ożywić zdjęcie, a następnie synchronizuje ruch warg z dźwiękiem. Musisz tylko wywołać **raz**.

- **Adres API**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Rozliczenie**: według długości, 5 sekund **16.45 Kredytów**, 10 sekund **30.45 Kredytów** (= cena połączenia image2video + lip-sync)

## Nagłówki żądania

| Pole              | Wartość                |
| ---------------- | --------------------- |
| `authorization`  | `Bearer ${API_KEY}`   |
| `content-type`   | `application/json`    |

## Parametry żądania

| Parametr         | Typ      | Wymagane | Domyślne              | Opis                                      |
| ---------------- | ------- | -------- | --------------------- | ----------------------------------------- |
| `image_url`      | string  | Tak      | —                     | Publiczny URL zdjęcia osoby, zaleca się wyraźne zdjęcie twarzy |
| `audio_url`      | string  | Tak      | —                     | Publiczny URL audio (mp3/wav/m4a/aac, ≤5MB) |
| `prompt`         | string  | Nie      | —                     | Słowa kluczowe dotyczące ruchów/wyrazów twarzy w fazie animacji zdjęcia |
| `model`          | string  | Nie      | `kling-v2-1-master`  | Model Kling używany do animacji zdjęcia   |
| `duration`       | integer | Nie      | `5`                   | Długość wideo (5 lub 10 sekund)           |
| `mode`           | string  | Nie      | `pro`                 | Jakość animacji (std/pro)                 |
| `callback_url`   | string  | Nie      | —                     | Jeśli podano lub `async=true`, zwróci asynchronicznie task_id |
| `async`          | boolean | Nie      | `false`               | Tryb asynchroniczny, współpracuje z `/kling/tasks` do polling lub callback |

## Przykład żądania

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Przykład odpowiedzi

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "source_video_url": "https://platform2.cdn.acedata.cloud/kling/163ac822-1a15-4f5e-a2eb-465154df15af.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Pole                | Opis                                      |
| ------------------- | ----------------------------------------- |
| `video_url`         | Ostateczne mówiące wideo (przechowywane na CDN tej platformy) |
| `source_video_url`  | Pośrednie wideo animacji zdjęcia (wynik image2video) |
| `video_id`          | ID wideo mówiącego Kling                  |

## Uwagi

- Zaleca się, aby zdjęcie było wyraźne, przedstawiające jedną osobę.
- Długość audio nie powinna przekraczać długości wideo (5s/10s).
- Rozliczenie następuje w momencie sukcesu; błędy walidacji parametrów (4xx) nie są rozliczane.
- Generowanie trwa około 4–6 minut (dwa kroki), zaleca się użycie `async=true` + `/kling/tasks` do polling.
