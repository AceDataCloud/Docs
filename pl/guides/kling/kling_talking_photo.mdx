---
title: "API mówiącego zdjęcia Kling (Kling Talking Photo)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Jednym kliknięciem przekształć **jedno zdjęcie + jedno nagranie audio** w „mówiący film”. Usługa automatycznie wykonuje wewnętrznie dwa kroki: najpierw używa image2video, aby ożywić zdjęcie, a następnie używa lip-sync, aby zsynchronizować ruch ust z dźwiękiem. Musisz wykonać tylko **jedno** wywołanie.

- **Adres endpointu**: `POST https://api.acedata.cloud/kling/talking-photo`
- **Rozliczenie**: według czasu trwania, 5 sekund **16.45 Credits**, 10 sekund **30.45 Credits** (= cena łączona image2video + lip-sync)

## Nagłówki żądania

| Pole              | Wartość                   |
| --------------- | ------------------- |
| `authorization` | `Bearer ${API_KEY}` |
| `content-type`  | `application/json`  |

## Parametry żądania

| Parametr             | Typ      | Wymagany  | Domyślna                  | Opis                                    |
| -------------- | ------- | --- | ------------------- | ------------------------------------- |
| `image_url`    | string  | Tak   | —                   | Publiczny URL zdjęcia osoby, zalecane wyraźne zdjęcie twarzy z przodu                    |
| `audio_url`    | string  | Tak   | —                   | Publiczny URL nagrania audio sterującego ruchem (.mp3/.wav/.m4a/.aac, ≤5MB) |
| `prompt`       | string  | Nie   | —                   | Podpowiedź dotycząca ruchu/wyrazu twarzy na etapie animacji zdjęcia                      |
| `model`        | string  | Nie   | `kling-v2-1-master` | Model Kling używany do animacji zdjęcia                     |
| `duration`     | integer | Nie   | `5`                 | Czas trwania filmu (5 lub 10 sekund)                        |
| `mode`         | string  | Nie   | `pro`               | Jakość animacji (std/pro)                        |
| `callback_url` | string  | Nie   | —                   | Przekazanie lub ustawienie `async=true` powoduje asynchroniczne zwrócenie task_id        |
| `async`        | boolean | Nie   | `false`             | Tryb asynchroniczny, używany z odpytywaniem `/kling/tasks` lub callbackiem          |

## Przykład żądania

```bash
curl -X POST 'https://api.acedata.cloud/kling/talking-photo' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "image_url": "https://cdn.acedata.cloud/4hfydw.jpg",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav",
    "duration": 5
  }'
```

## Przykład odpowiedzi

```json
{
  "success": true,
  "task_id": "0c0b4d3a-2f1e-4a6b-9c2d-2b3c4d5e6f70",
  "video_id": "895055968777281546",
  "video_url": "https://cdn.acedata.cloud/assets/examples/kling/6c68c267-065b-4423-b66b-a0e4c59ee0d5-6a664a591a53.mp4",
  "source_video_url": "https://cdn.acedata.cloud/assets/examples/gemini/04a043bd-6b23-4b4e-945c-ce48158c3eee-3a89912507c7.mp4",
  "duration": 5,
  "state": "succeed"
}
```

| Pole                 | Opis                        |
| ------------------ | ------------------------- |
| `video_url`        | Końcowy mówiący film (zapisany na CDN tej platformy)      |
| `source_video_url` | Pośredni film animujący zdjęcie (wynik image2video) |
| `video_id`         | ID filmu Kling                   |

## Uwagi

- Zalecane jest wyraźne zdjęcie twarzy z przodu, z jedną osobą.
- Zalecane jest, aby czas trwania dźwięku nie przekraczał czasu trwania filmu (5 s/10 s).
- Opłata jest naliczana po pomyślnym wykonaniu; nieudana walidacja parametrów (4xx) nie jest płatna.
- Generowanie trwa około 4–6 minut (dwa kroki); zalecane jest użycie `async=true` + odpytywanie `/kling/tasks`.
