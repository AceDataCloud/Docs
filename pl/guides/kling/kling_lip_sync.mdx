title: "API do synchronizacji ruchu warg Kling (Kling Lip Sync)"
description: "Kling video generation API guide - Ace Data Cloud"
---

Pozwól, aby istniejące **wideo Kling** (5 sekund lub 10 sekund) "mówiło" zgodnie z dźwiękiem lub tekstem — czyli synchronizowało ruch warg (Lip Sync). W połączeniu z `/kling/videos` `image2video` (ożywiając zdjęcia), można stworzyć kompletny proces "**mówiącego zdjęcia / cyfrowego narratora**".

> Ten interfejs to jednoczesne, wygodne opakowanie dostarczone przez AceDataCloud, skierowane do powszechnych scenariuszy napędzanych dźwiękiem/tekstem; nie jest to pole odzwierciedlające wieloetapowy interfejs Kling "rozpoznawanie twarzy → Zaawansowana synchronizacja ruchu warg". Proszę kierować się tabelą parametrów na tej stronie.

- **Adres interfejsu**: `POST https://api.acedata.cloud/kling/lip-sync`
- **Format żądania**: `application/json`
- **Format odpowiedzi**: `application/json`
- **Opłata**: Każde udane wywołanie **2.45 Kredytów** (stałe)

## Nagłówki żądania (Request Headers)

| Pole              | Wartość                   | Opis                                               |
| --------------- | ------------------- | ------------------------------------------------ |
| `authorization` | `Bearer ${API_KEY}` | Twój klucz API, [adres uzyskania](https://platform.acedata.cloud) |
| `content-type`  | `application/json`  | Format ciała żądania                                            |
| `accept`        | `application/json`  | Format odpowiedzi                                             |

## Parametry żądania (Request Body)

| Parametr               | Typ      | Wymagane  | Domyślnie      | Opis                                                                                                                       |
| ---------------- | ------- | --- | ------- | ------------------------------------------------------------------------------------------------------------------------ |
| `mode`           | string  | Tak   | —       | Tryb generacji. Enum: `audio2video` (napędzany dźwiękiem), `text2video` (napędzany tekstem)                                                                           |
| `video_id`       | string  | Wybór  | —       | ID wideo wygenerowanego przez Kling (np. `video_id` zwrócone przez image2video z `/kling/videos`). **Obsługuje tylko wideo 5s/10s wygenerowane w ciągu ostatnich 30 dni**. `video_id` i `video_url` są opcjonalne, nie można ich przesyłać jednocześnie |
| `video_url`      | string  | Wybór  | —       | Link do wideo dostępnego publicznie. Ograniczenia: `.mp4`/`.mov`, ≤100MB, czas trwania 2–10s, tylko 720p/1080p, długość boku 720–1920px. Z `video_id` są opcjonalne                                  |
| `audio_url`      | string  | Warunkowe  | —       | URL do pobrania dźwięku, wymagane przy `audio2video` + `audio_type=url`. Format `.mp3`/`.wav`/`.m4a`/`.aac`, ≤5MB                                     |
| `audio_type`     | string  | Nie   | `url`   | Sposób przesyłania dźwięku. Enum: `url`, `file` (działa przy `audio2video`)                                                                                |
| `audio_file`     | string  | Warunkowe  | —       | Plik dźwiękowy w formacie Base64, wymagane przy `audio_type=file`. Format jak wyżej, ≤5MB                                                                             |
| `text`           | string  | Warunkowe  | —       | Tekst do przeczytania, wymagane przy `text2video`, **maksymalnie 120 znaków**                                                                                     |
| `voice_id`       | string  | Warunkowe  | —       | ID głosu, wymagane przy `text2video`                                                                                                   |
| `voice_language` | string  | Nie   | `zh`    | Język głosu. Enum: `zh`, `en` (działa przy `text2video`)                                                                                      |
| `voice_speed`    | float   | Nie   | `1.0`   | Prędkość mówienia, zakres `0.8`–`2.0`, dokładność do jednej liczby po przecinku (działa przy `text2video`)                                                                              |
| `callback_url`   | string  | Nie   | —       | Adres zwrotny. Przekazanie tej opcji lub `async=true` oznacza **tryb asynchroniczny**: natychmiastowe zwrócenie `task_id`, a po wygenerowaniu wyników zwrotka                                                                 |
| `async`          | boolean | Nie   | `false` | Czy asynchronicznie. `true` oznacza natychmiastowe zwrócenie `task_id`, w połączeniu z `/kling/tasks` do sprawdzania lub zwrotka `callback_url`                                                      |

## Przykład żądania

### 1) Napędzany dźwiękiem (audio2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "audio2video",
    "video_id": "895055164389466178",
    "audio_url": "https://cdn.acedata.cloud/6f7d62b18b.wav"
  }'
```

### 2) Napędzany tekstem (text2video)

```bash
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' \
  -H 'content-type: application/json' \
  -d '{
    "mode": "text2video",
    "video_id": "895055164389466178",
    "text": "Bracie, dawno się nie widzieliśmy, wszystko u mnie w porządku, dbaj o siebie.",
    "voice_id": "genshin_vindi2",
    "voice_language": "zh",
    "voice_speed": 1.0
  }'
```

## Przykład odpowiedzi (sukces synchronizacji)

```json
{
  "success": true,
  "task_id": "07a3ec65-9f7e-4a09-b7b7-282684082527",
  "video_id": "895055968777281546",
  "video_url": "https://platform2.cdn.acedata.cloud/kling/07a3ec65-9f7e-4a09-b7b7-282684082527.mp4",
  "duration": "4.966",
  "state": "succeed"
}
```

| Pole          | Typ      | Opis                                         |
| ----------- | ------- | ------------------------------------------ |
| `success`   | boolean | Czy operacja zakończona sukcesem                                       |
| `task_id`   | string  | ID bieżącego zadania (można użyć do zapytania `/kling/tasks`)             |
| `video_id`  | string  | ID wideo wygenerowanego przez Kling (można użyć jako wejście do następnego `extend`/`lip-sync`) |
| `video_url` | string  | URL wygenerowanego wideo mówiącego (przechowywane na CDN tej platformy, ważne na dłużej)              |
| `duration`  | string  | Czas trwania wideo (sekundy)                                    |
| `state`     | string  | Stan zadania: `succeed` / `failed`                  |

## Tryb asynchroniczny i zapytania

Przekazanie `callback_url` lub `async: true` powoduje, że interfejs **natychmiast zwraca** `task_id`; następnie można:

- **Sprawdzać**: `POST /kling/tasks`, body `{ "action": "retrieve", "id": "<task_id>" }` (bezpłatnie)
- **Zwrotka**: Po zakończeniu generowania, wyniki są przesyłane na twój `callback_url`

## Pełny proces: mówiące zdjęcie (image2video → lip-sync)
```bash
# Krok 1: Ożyw zdjęcie, uzyskaj video_id
curl -X POST 'https://api.acedata.cloud/kling/videos' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"model":"kling-v2-1-master","action":"image2video","start_image_url":"https://cdn.acedata.cloud/4hfydw.jpg","prompt":"spójrz w kamerę, naturalnie","duration":5,"mode":"pro"}'
# → { "video_id": "895055164389466178", ... }

# Krok 2: Synchronizuj ruch ust z dźwiękiem
curl -X POST 'https://api.acedata.cloud/kling/lip-sync' \
  -H 'authorization: Bearer ${API_KEY}' -H 'content-type: application/json' \
  -d '{"mode":"audio2video","video_id":"895055164389466178","audio_url":"https://platform2.cdn.acedata.cloud/fish/5ade0339-5f11-487e-aacc-06a908271706.mp3"}'
# → { "video_url": "https://platform2.cdn.acedata.cloud/kling/....mp4", ... }
```

## Odpowiedź błędu

```json
{
  "success": false,
  "error": { "code": "bad_request", "message": "jeden z video_id lub video_url jest wymagany" },
  "trace_id": "f07cab09-3c18-4d74-9030-64ee840d9f16",
  "task_id": "f490537f-2e5c-4739-8149-6252fba2091c"
}
```

| HTTP | kod                    | znaczenie                                             |
| ---- | --------------------- | ---------------------------------------------------- |
| 400  | `bad_request`         | Brakujące lub nieprawidłowe parametry (np. brak mode, konflikt między video a audio, tekst przekracza 120 znaków) |
| 401  | `authorization_missing` | Brak lub nieprawidłowy klucz API                          |
| 403  | `forbidden`           | Treść została zablokowana przez system kontroli treści  |
| 429  | `too_many_requests`   | Ograniczenia współbieżności, spróbuj ponownie później     |
| 500  | `api_error`           | Błąd zewnętrzny lub wewnętrzny                          |

## Uwagi

- `video_id` musi być **wygenerowane w ciągu 30 dni** i być **5s lub 10s**; w przeciwnym razie użyj `video_url`, aby przesłać odpowiednie wideo.
- Zaleca się, aby wideo było **wyraźne, z przodu, z jedną osobą**, aby uzyskać najlepszy efekt ruchu ust.
- Czas trwania audio/tekstu powinien odpowiadać czasowi trwania wideo (audio nie może przekraczać długości wideo).
- Opłaty są naliczane w momencie **sukcesu** (2.45 kredytów/raz); błędy walidacji parametrów (4xx) nie są obciążane.
