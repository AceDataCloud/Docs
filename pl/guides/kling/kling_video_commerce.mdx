Prześlij zadanie przez `POST /kling/video-commerce`, użyj istniejącego `POST /kling/tasks` do sprawdzania statusu zadania na platformie.

## Dane wejściowe

Prześlij jedno zdjęcie osoby i określ voice_id lub użyj jednego predefiniowanego avatar_id (te opcje wzajemnie się wykluczają, dla predefiniowanej postaci nie można dodatkowo określić voice_id). Należy podać speech_script o długości maksymalnie 2000 znaków. W przypadku podania informacji o produkcie wymagane jest co najmniej jedno ref_image i jeden goods_title; voice-over produktu nie obsługuje speech_rate. Zwykły voice-over postaci obsługuje prędkość mowy 0.8, 1.0 lub 1.2 razy.

Poniżej znajduje się przykład struktury żądania, zastąp adresy URL materiałów przed wywołaniem.

```json
{
  "contents": [
    {
      "type": "avatar_image",
      "url": "https://your-cdn.example/person.jpg"
    },
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "twoje treści produktu lub voice-over"
    },
    {
      "type": "speech_script",
      "text": "twoje treści produktu lub voice-over"
    }
  ],
  "settings": {
    "resolution": "720p",
    "voice_id": "male_calm_informative"
  },
  "async": true
}
```

## Wyniki i rozliczenia

Tryb synchroniczny zwraca wynik generowania; tryb asynchroniczny najpierw zwraca `task_id`, a ukończony wynik zawiera w `data` linki do wideo lub obrazów oraz obliczone przez serwer `usage`. `callback_url` służy do powiadamiania o ukończeniu; żądanie z `watermark=true` jednocześnie zwraca wersję ze znakiem wodnym.

Zwykły voice-over postaci: 720p kosztuje 1.4 Credits/sekundę, a 1080p 1.68 Credits/sekundę; voice-over produktu: 720p kosztuje 1.96 Credits/sekundę, a 1080p 2.24 Credits/sekundę. Wideo jest rozliczane według rzeczywistego czasu trwania generowania, a cena bazowa za sekundę przed generowaniem nie stanowi całkowitej ceny całego zadania. Za nieudane zadania nie są pobierane opłaty za generowanie.
