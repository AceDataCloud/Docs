Prześlij zadanie przez `POST /kling/goods-studio`, używając istniejącego `POST /kling/tasks` do sprawdzania statusu zadania na platformie.

## Dane wejściowe

Podaj 1–5 zdjęć produktu oraz tytuł produktu o długości maksymalnie 200 znaków; opis produktu jest opcjonalny i może mieć maksymalnie 2000 znaków. Czas trwania może opcjonalnie wynosić 15, 30 lub 60 sekund.

Poniżej znajduje się przykład struktury żądania; wywołaj po zastąpieniu adresu URL materiału.

```json
{
  "contents": [
    {
      "type": "ref_image",
      "url": "https://your-cdn.example/product.jpg"
    },
    {
      "type": "goods_title",
      "text": "Twój produkt lub treść lektorska"
    }
  ],
  "settings": {
    "resolution": "720p",
    "aspect_ratio": "16:9",
    "duration": 15
  },
  "async": true
}
```

## Wyniki i rozliczenia

Tryb synchroniczny zwraca wynik generowania; tryb asynchroniczny najpierw zwraca `task_id`, a ukończony wynik zawiera w `data` linki do wideo lub obrazów oraz obliczone po stronie serwera `usage`. `callback_url` służy do powiadomień o ukończeniu; żądanie z `watermark=true` zwraca jednocześnie wersję ze znakiem wodnym.

720p: 2,38 Credits/sekundę; 1080p: 2,8 Credits/sekundę. Wideo jest rozliczane według rzeczywistego czasu trwania generowania, a podstawowa cena za sekundę przed generowaniem nie reprezentuje całkowitej ceny całego zadania. Za nieudane zadania nie są pobierane opłaty za generowanie.
