Prześlij zadanie przez `POST /kling/apparel`, użyj istniejącego `POST /kling/tasks` do sprawdzania statusu zadania na platformie.

## Dane wejściowe

Podaj opis produktu o długości maksymalnie 2500 znaków, film referencyjny trwający 5–180 sekund oraz 1–5 zdjęć produktu. Można dodatkowo podać 1–5 zdjęć modela, plik muzyki w tle oraz wskazać głos lektora; gdy głos nie jest wskazany, używany jest natywny przekaz ustny.

Poniżej znajduje się przykład struktury żądania, zastąp adresy URL materiałów, a następnie wywołaj.

```json
{
  "contents": [
    {
      "type": "product_info",
      "text": "你的商品或口播内容"
    },
    {
      "type": "source_video",
      "url": "https://your-cdn.example/reference.mp4"
    },
    {
      "type": "product_image",
      "url": "https://your-cdn.example/product.jpg"
    }
  ],
  "async": true
}
```

## Wyniki i rozliczenia

Tryb synchroniczny zwraca wynik generowania; tryb asynchroniczny najpierw zwraca `task_id`, a ukończony wynik zawiera w `data` linki do wideo lub obrazów oraz obliczone przez serwer `usage`. `callback_url` służy do powiadomienia o ukończeniu; żądanie `watermark=true` zwraca jednocześnie wersję ze znakiem wodnym.

Natywny przekaz ustny: 720p kosztuje 1.82 Credits/sekundę, 1080p kosztuje 2.38 Credits/sekundę; wskazany głos lektora: 720p kosztuje 2.38 Credits/sekundę, 1080p kosztuje 2.8 Credits/sekundę. Wideo jest rozliczane według rzeczywistego czasu trwania generowania, a cena podstawowa za sekundę przed generowaniem nie reprezentuje całkowitej ceny całego zadania. Za nieudane zadania nie są pobierane opłaty za generowanie.
