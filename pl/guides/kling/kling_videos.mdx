W tym dokumencie przedstawiono instrukcję integracji z API generowania filmów Kling, które umożliwia tworzenie oficjalnych filmów Kling na podstawie wprowadzonych parametrów.

## Proces rejestracji

Aby korzystać z API, należy najpierw zarejestrować odpowiednią usługę na stronie [Kling Videos Generation API](https://platform.acedata.cloud/documents/3b921a16-a411-4557-8335-53f21d3f9e46). Po wejściu na stronę kliknij przycisk „Acquire”, jak pokazano na ilustracji:

![](https://cdn.acedata.cloud/q6ytrc.png)

Jeśli nie jesteś zalogowany lub zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, gdzie możesz się zarejestrować lub zalogować. Po zalogowaniu nastąpi automatyczny powrót do bieżącej strony.

Przy pierwszym zgłoszeniu otrzymasz darmowy limit, który pozwala na bezpłatne korzystanie z API.

## Podstawowe użycie

Najpierw zapoznaj się z podstawowym sposobem użycia, polegającym na wprowadzeniu słowa kluczowego `prompt`, akcji `action`, adresu URL pierwszej klatki referencyjnej `start_image_url` oraz modelu `model`, aby uzyskać przetworzony wynik. Najpierw należy podać pole `action` o wartości `text2video`. Dostępne są trzy główne akcje: generowanie filmu z tekstu (`text2video`), generowanie filmu z obrazu (`image2video`) oraz rozszerzanie filmu (`extend`). Następnie należy wybrać model `model`. Obecnie dostępne modele to: `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`. Szczegóły przedstawiono poniżej:

<p><img src="https://cdn.acedata.cloud/ke1bok.png" width="500" className="m-auto" /></p>

Widzimy tutaj ustawienia nagłówków żądania (Request Headers), które obejmują:

- `accept`: format odpowiedzi, tutaj ustawiony na `application/json` (format JSON).
- `authorization`: klucz API do wywołania, który można wybrać z listy po rejestracji.

Dodatkowo ustawiono ciało żądania (Request Body), które zawiera:

- `model`: model generujący film, dostępne modele to `kling-v1`, `kling-v1-6`, `kling-v2-master`, `kling-v2-1-master`, `kling-v2-5-turbo`, `kling-v2-6`, `kling-v3`, `kling-v3-omni`, `kling-video-o1`.
- `mode`: tryb generowania filmu, do wyboru: standardowy `std`, szybki `pro` oraz natywny 4K `4k`. Tryb `4k` jest dostępny tylko dla modeli `kling-v3` i `kling-v3-omni` i nie jest kompatybilny z `camera_control` (kontrola ruchu kamery).
- `action`: rodzaj zadania generowania filmu, obejmuje trzy akcje: generowanie filmu z tekstu (`text2video`), generowanie filmu z obrazu (`image2video`), rozszerzanie filmu (`extend`).
- `start_image_url`: adres URL pierwszej klatki referencyjnej, wymagany przy akcji `image2video`.
- `end_image_url`: opcjonalny adres URL ostatniej klatki przy generowaniu filmu z obrazu.
- `duration`: długość filmu w sekundach. Modele `kling-v3` i `kling-v3-omni` obsługują długość od 3 do 15 sekund (liczby całkowite), pozostałe modele obsługują 5 lub 10 sekund.
- `generate_audio`: opcjonalnie, czy generować audio, wartość logiczna. Obsługiwane przez modele `kling-v3`, `kling-v3-omni` oraz `kling-v2-6` (tylko w trybie `pro`). Domyślnie `false`.
- `aspect_ratio`: proporcje obrazu filmu, opcjonalne, obsługiwane wartości to `16:9`, `9:16`, `1:1`, domyślnie `16:9`.
- `cfg_scale`: intensywność dopasowania, zakres [0,1], im większa wartość, tym bardziej film odpowiada podanemu promptowi.
- `camera_control`: opcjonalne parametry kontroli ruchu kamery, obsługiwane są predefiniowane typy `type/simple` oraz konfiguracje takie jak horizontal, vertical, pan, tilt, roll, zoom.
- `negative_prompt`: opcjonalne negatywne słowa kluczowe, których nie chcemy w filmie, maksymalnie 200 znaków.
- `element_list`: lista referencyjnych elementów, dostępna tylko dla modelu `kling-video-o1`. Szczegóły użycia w [dokumentacji oficjalnej](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `video_list`: lista referencyjnych filmów dostępnych pod URL, tylko dla modelu `kling-video-o1`. Szczegóły w [dokumentacji oficjalnej](https://docs.qingque.cn/d/home/eZQAyImcbaS0fz-8ANjXvU5ed?identityId=1oEG9JKKMFv#section=h.5t7wme23nn6z).
- `prompt`: słowo kluczowe (prompt).
- `callback_url`: adres URL do wywołania zwrotnego (callback).

Po wybraniu tych parametrów po prawej stronie wygenerowany zostanie odpowiedni kod, jak pokazano na ilustracji:

<p><img src="https://cdn.acedata.cloud/3yjql0.png" width="500" className="m-auto" /></p>

Kliknij przycisk „Try”, aby przetestować. W powyższym przykładzie uzyskano następujący wynik:

```json
{
  "success": true,
  "video_id": "af9a1af0-9aa0-4638-81c1-d41d6143c508",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7485378259/text2video/Cjil4mfBfs0AAAAAAKbMQQ-0_raw_video_1.mp4",
  "duration": "5.1",
  "state": "succeed",
  "task_id": "e3a575aa-a4bd-49c8-9b12-cde38d5462e0"
}
```

W odpowiedzi znajduje się kilka pól, opisanych poniżej:

- `success`: status zadania generowania filmu.
- `task_id`: identyfikator zadania generowania filmu.
- `video_id`: identyfikator wygenerowanego filmu.
- `video_url`: adres URL wygenerowanego filmu.
- `duration`: długość filmu.
- `state`: status zadania.

Widzimy, że otrzymaliśmy satysfakcjonujące informacje o filmie. Wystarczy pobrać film z adresu URL podanego w polu `video_url`.

Jeśli chcesz wygenerować kod integracji, możesz go skopiować bezpośrednio, np. kod CURL wygląda następująco:

```shell
curl -X POST 'https://api.acedata.cloud/kling/videos' \
-H 'accept: application/json' \
-H 'authorization: Bearer {token}' \
-H 'content-type: application/json' \
-d '{
  "action": "text2video",
  "model": "kling-v1",
  "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle."
}'
```

## Funkcja rozszerzania filmu

Jeśli chcesz kontynuować generowanie na bazie już wygenerowanego filmu Kling, ustaw parametr `action` na `extend` i podaj identyfikator filmu, który chcesz rozszerzyć. Identyfikator filmu można uzyskać zgodnie z podstawowym użyciem, jak pokazano na ilustracji:

<p><img src="https://cdn.acedata.cloud/om6p6g.png" width="500" className="m-auto" /></p>

Identyfikator filmu to:

```
"video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c"
```

> Uwaga: `video_id` to identyfikator wygenerowanego filmu. Jeśli nie wiesz, jak wygenerować film, zapoznaj się z sekcją podstawowego użycia.

Następnie należy podać prompt do dalszego generowania filmu, a także inne parametry:

- `model`: model generujący film, dostępne modele to `kling-v1`, `kling-v1-5` oraz `kling-v1-6`.
- `mode`: tryb generowania filmu, do wyboru: standardowy `std`, szybki `pro` oraz natywny 4K `4k` (dostępny tylko dla `kling-v3` i `kling-v3-omni`, niekompatybilny z kontrolą ruchu kamery).
- `duration`: długość filmu, dostępne wartości to 5 lub 10 sekund.
- `start_image_url`: adres URL pierwszej klatki referencyjnej, wymagany przy akcji `image2video`.
- `prompt`: słowo kluczowe.

Przykład wypełnienia formularza:

<p><img src="https://cdn.acedata.cloud/ejimqy.png" width="500" className="m-auto" /></p>

Po wypełnieniu automatycznie wygenerowany zostanie kod:

<p><img src="https://cdn.acedata.cloud/52x4u5.png" width="500" className="m-auto" /></p>

Odpowiedni kod w Python:

```python
import requests

url = "https://api.acedata.cloud/kling/videos"

headers = {
    "accept": "application/json",
    "authorization": "Bearer {token}",
    "content-type": "application/json"
}

payload = {
    "action": "extend",
    "model": "kling-v1",
    "video_id": "030bb06d-98d4-4044-9042-0aa0822e8c8c",
    "prompt": "White ceramic coffee mug on glossy marble countertop with morning window light. Camera slowly rotates 360 degrees around the mug, pausing briefly at the handle.",
    "duration": 10
}

response = requests.post(url, json=payload, headers=headers)
print(response.text)
```

Po uruchomieniu otrzymamy wynik:

```json
{
  "success": true,
  "video_id": "bbc3b105-ac72-4de2-8390-0cb37dc7d41e",
  "video_url": "https://cdn.klingai.com/bs2/upload-kling-api/7822108635/extendVideo/Cjil4mfBfs0AAAAAAKhr6A-0_raw_video_1.mp4",
  "duration": "9.6",
  "state": "succeed",
  "task_id": "3ece87e6-3ee3-4f5e-bd70-5ae5eca89a23"
}
```

Wynik jest zgodny z poprzednim, co potwierdza działanie funkcji rozszerzania filmu.

## Asynchroniczne wywołanie zwrotne (callback)

Ponieważ generowanie filmów w Kling Videos Generation API trwa stosunkowo długo (około 1-2 minut), a żądanie HTTP może utrzymywać połączenie, co powoduje dodatkowe obciążenie systemu, API obsługuje również asynchroniczne wywołania zwrotne.

Proces jest następujący: klient wysyła żądanie z dodatkowym polem `callback_url`. Po wysłaniu API natychmiast zwraca wynik z polem `task_id`, które identyfikuje zadanie. Po zakończeniu generowania filmu wynik zostanie przesłany metodą POST w formacie JSON na podany `callback_url`, zawierając również `task_id`, co umożliwia powiązanie wyników z zadaniem.

Poniżej przykład działania.

Webhook to usługa HTTP zdolna do odbierania żądań. Programista powinien podać adres swojego serwera HTTP. Dla demonstracji użyto publicznej strony Webhook https://webhook.site/, gdzie po wejściu otrzymujemy unikalny URL webhooka, jak na ilustracji:

![](https://cdn.acedata.cloud/tbcnai.png)

Skopiuj ten URL, np. `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3`, i użyj go jako `callback_url`. Następnie ustaw pole `callback_url` na ten adres i wprowadź pozostałe parametry, jak pokazano poniżej:

Po chwili na stronie `https://webhook.site/624b2c78-6dbd-4618-9d2b-b32eade6d8c3` pojawi się wynik generowania filmu:

## Obsługa błędów

Podczas wywoływania API, w przypadku błędów, API zwraca odpowiedni kod i komunikat błędu, np.:

- `400 token_mismatched`: błędne żądanie, możliwe brak lub nieprawidłowe parametry.
- `400 api_not_implemented`: błędne żądanie, możliwe brak lub nieprawidłowe parametry.
- `401 invalid_token`: brak autoryzacji, nieprawidłowy lub brakujący token.
- `429 too_many_requests`: zbyt wiele żądań, przekroczono limit.
- `500 api_error`: błąd wewnętrzny serwera.

### Przykład odpowiedzi błędu

```json
{
  "success": false,
  "error": {
    "code": "api_error",
    "message": "fetch failed"
  },
  "trace_id": "2cf86e86-22a4-46e1-ac2f-032c0f2a4e89"
}
```
