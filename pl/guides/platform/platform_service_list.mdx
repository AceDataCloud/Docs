title: "Pobieranie listy usług platformy AceDataCloud"

Zwraca stronicowaną listę katalogu Service widocznego w bieżącej witrynie, w tym typ usługi, informacje prezentacyjne, bezpłatny limit, pakiety oraz powiązane ID API/Proxy. Odpowiednie do budowy rynku usług lub wyboru usługi do złożenia wniosku.

## Przegląd interfejsu

| Pozycja   | Treść                                                |
| --- | ------------------------------------------------- |
| Metoda  | `GET`                                             |
| URL | `https://platform.acedata.cloud/api/v1/services/` |
| Uwierzytelnianie  | Publiczne; przy stanie zalogowania `applied` odzwierciedla bieżące konto                        |
| Stronicowanie  | `count` + `items`                                 |

## Parametry zapytania

| Parametr               | Typ      | Wymagany  | Opis                       |
| ---------------- | ------- | --- | ------------------------ |
| `id`             | UUID    | Nie   | Filtruje według ID usługi; obsługuje powtarzane parametry         |
| `private`        | boolean | Nie   | Filtruje według statusu publicznego; reguły widoczności witryny nadal obowiązują      |
| `type`           | string  | Nie   | Typ usługi; obsługuje powtarzane parametry              |
| `tag`            | string  | Nie   | Filtruje według tagu                    |
| `include_facets` | boolean | Nie   | Przy `true` dołącza statystyki dostępnych w bieżącej witrynie typów/tagów |
| `limit`          | integer | Nie   | Liczba elementów na stronę, maksymalnie 100              |
| `offset`         | integer | Nie   | Przesunięcie stronicowania                    |
| `ordering`       | string  | Nie   | Obsługuje tylko `rank` lub `-rank`     |

Lista nie obsługuje filtrowania `alias`; jeśli alias już istnieje, bezpośrednio zażądaj `/api/v1/services/{alias}`. `applied_count` i `updated_at` nie są dozwolonymi polami sortowania.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/services/' \
  --data-urlencode 'type=Api' \
  --data-urlencode 'include_facets=true' \
  --data-urlencode 'limit=20' \
  -H 'Accept: application/json'
```

## Opis odpowiedzi

Odpowiedź ma postać `{count, items}`; `facets` jest dodawane tylko przy `include_facets=true`. Element usługi zawiera bieżące publiczne pola, takie jak `id`, `alias`, `title`, `description`, `type`, `applied_count`, `free_amount`, `unit`, `private`, `need_verify`, `rank`, `tags`, `thumbnail`, `doc_url`, `demo_url`, `api_ids`, `proxy_ids`, `cost`, `packages` itd.

`applied` na anonimowej liście nie reprezentuje statusu wniosku żadnego konta. Gdy wymagany jest status związany z kontem, należy użyć ważnego stanu zalogowania i traktować [listę wniosków o usługę](https://platform.acedata.cloud/documents/platform-application-list) jako ostateczną podstawę.
