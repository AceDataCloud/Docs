---
title: "Pobieranie szczegółów dokumentu platformy AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Pobieranie pełnej treści i relacji nawigacyjnych pojedynczego dokumentu za pomocą UUID lub aliasu dokumentu. Gdy alias jest znany, można wysłać żądanie bezpośrednio, bez wcześniejszego filtrowania z listy.

## Przegląd interfejsu

| Pozycja   | Treść                                                              |
| --- | --------------------------------------------------------------- |
| Metoda  | `GET`                                                           |
| URL | `https://platform.acedata.cloud/api/v1/documents/{id_or_alias}` |
| Uwierzytelnianie  | Publiczne; wystarczy znać UUID lub alias, aby odczytać bezpośrednio                                       |

## Parametry

- `id_or_alias`: UUID dokumentu, bieżący alias lub stary alias zachowany w `redirect_from`.
- `lang`: opcjonalna wskazówka językowa; można również użyć `Accept-Language`. Ostateczny język treści jest określany przez `content_locale` w odpowiedzi.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/documents/platform-token' \
  --data-urlencode 'lang=zh-CN' \
  -H 'Accept: application/json'
```

## Opis odpowiedzi

Szczegóły są zwracane jako pojedynczy obiekt, obecnie zawierający:

- `id`, `alias`, `redirect_from`, `name`, `title`, `type`, `rank`, `tags`;
- `content`, `content_mode`, `content_locale`, `content_hash`;
- `parent`, `sibling` oraz publiczne podsumowania `children` posortowane według rank;
- powiązania `api` / `proxy` / `dataset` / `integration`, a także `agent` (jeśli istnieje).

Odpowiedź nie zawiera pola `breadcrumbs`. Podczas budowania okruszków nawigacyjnych można dalej odczytać szczegóły z `parent` lub użyć relacji katalogu dokumentów zapisanych w pamięci podręcznej.

## Obsługa błędów

- ID/alias nie istnieje lub nie spełnia widoczności bieżącej witryny: `404`. `private` kontroluje tylko widoczność na liście, nie blokuje bezpośredniego odczytu osobom znającym link i nie może być traktowane jako granica poufności.
- Bieżąca trasa używa formy bez końcowego ukośnika; nie należy polegać na automatycznym dodawaniu ukośnika przez warstwę proxy.
