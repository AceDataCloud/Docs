Hermes Agent łączy się z Ace Data Cloud za pomocą protokołu OpenAI Chat Completions. Wybierz jedną z metod konfiguracji:

| Metoda konfiguracji         | Przewodnik                                                                                     |
| ------------------- | -------------------------------------------------------------------------------------- |
| Interaktywny przewodnik `hermes model` | [Konfiguracja przewodnika](https://platform.acedata.cloud/documents/hermes-wizard-integration)             |
| Ręczna konfiguracja `config.yaml`  | [Ręczna konfiguracja](https://platform.acedata.cloud/documents/hermes-manual-integration)             |
| Prywatne wdrożenie na platformie              | [Wdrożenie zarządzane](https://platform.acedata.cloud/documents/hermes-managed-deployment-integration) |

Wspólne parametry dla lokalnej integracji:

- Base URL: `https://api.acedata.cloud/v1`
- Transport: `chat_completions`
- Provider: `custom:acedatacloud`
- API Key: uzyskaj z [listy aplikacji](https://platform.acedata.cloud/console/applications)

Obie lokalne metody ostatecznie zapisują się w `~/.hermes/config.yaml`, nie konfiguruj ich ponownie.

Powróć do [Centrum konfiguracji Coding Plan](https://platform.acedata.cloud/documents/coding-plan-integration).
