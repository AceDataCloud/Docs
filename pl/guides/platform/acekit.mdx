Prawdopodobnie też spotkałeś się z taką sytuacją: używasz Claude Code, Cursor albo Codex, kodowanie idzie świetnie, a nagle potrzebujesz obrazka, fragmentu muzyki w tle, krótkiego wideo albo chcesz, żeby przy okazji sprawdził najnowsze informacje. I wtedy okazuje się — sam agent tego nie potrafi. Musisz sam znaleźć API, przeczytać dokumentację, skonfigurować klucz, napisać kod wywołania, obsłużyć asynchroniczne odpytywanie; po przejściu przez cały ten proces inspiracja już dawno ostygła.

[AceKit](https://github.com/AceDataCloud/AceKit) służy właśnie do pominięcia całej tej pracy. Jednym poleceniem umieszcza w twoim agencie kodującym cały zestaw możliwości z AceData Cloud: generowanie obrazów, generowanie wideo, generowanie muzyki, wyszukiwanie w sieci, rozmowy z LLM i inne. Po instalacji po prostu mówisz ludzkim językiem, a agent sam załaduje odpowiednią umiejętność, sam się uwierzytelni, sam wykona odpytywanie i dokończy zadanie.

## Zrozum, co robi, w 30 sekund

Przed instalacją vs po instalacji:

| Co mówisz               | Przed instalacją                   | Po instalacji (agent robi to sam)                      |
| ------------------ | --------------------- | ----------------------------------- |
| "Dodaj obrazek okładkowy do tego README" | agent tego nie potrafi, każe ci samemu znaleźć API do generowania obrazów | wywołuje NanoBanana / Flux / Midjourney, aby wygenerować obraz |
| "Zamień ten skrypt w 30-sekundowe krótkie wideo"  | nie potrafi                    | wywołuje Sora / Veo / Kling / Seedance, aby stworzyć materiał  |
| "Dodaj fragment muzyki w tle do tego demo"  | nie potrafi                    | wywołuje Suno, aby wygenerować utwór                           |
| "Wyszukaj najnowsze informacje o X i je podsumuj"     | nie ma dostępu do internetu                  | wywołuje Google SERP, aby uzyskać wyniki w czasie rzeczywistym                 |
| "Skróć ten długi link"         | nie potrafi                    | wywołuje usługę skracania linków i zwraca link surl.id                  |

Jednym zdaniem: **twój agent kodujący zmienia się z „umie tylko pisać kod” w „potrafi też generować obrazy, wideo, muzykę i wyszukiwać w internecie”.**

## Pierwsze kroki w trzech krokach

Cały proces można przejść w kilka minut, wymagany jest Node.js 18+.

**Krok pierwszy · Zdobądź API Token.** W [konsoli](https://platform.acedata.cloud/console/applications) skopiuj Token — wszystkie możliwości współdzielą ten jeden token, przy pierwszym wniosku otrzymasz darmowy limit, więc możesz najpierw wypróbować za darmo.

![Skopiuj API Token w konsoli](https://cdn.acedata.cloud/dvc3cg.jpg)

**Krok drugi · Zainstaluj.** Jedno polecenie:

```bash
npx acekit
```

Automatycznie wykryje agenty kodujące na komputerze i zainstaluje cały zestaw umiejętności. Rzeczywiste uruchomienie wygląda tak (na tej maszynie zainstalowano tylko Claude Code):

```text
🃏  AceKit — wiring AI into your coding agent
✓  Detected: Claude Code
📦  Installing the AceData skill toolkit via @acedatacloud/skills …
Installed 19 skills to ~/.claude/skills
✅  Done. Try it now — ask your agent:
      "generate a hero image for this README"
      "turn this script into a 30-second video"
```

> Jeśli Token nie jest ustawiony, przy pierwszym uruchomieniu pojawi się interaktywny monit o wklejenie go; możesz też wcześniej wykonać `export ACEDATACLOUD_API_TOKEN=twójtoken`, aby instalacja przebiegła całkowicie bezobsługowo. Liczba umiejętności będzie zmieniać się wraz z rozwojem możliwości platformy; obowiązuje aktualna lista wyświetlana przez `npx acekit list`.

**Krok trzeci · Mów ludzkim językiem.** Przeładuj agenta, a następnie wydaj bezpośrednie polecenie, na przykład:

```text
Użyj umiejętności short-url, aby skrócić https://platform.acedata.cloud/services
```

Agent sam załaduje umiejętność, sam wykona wywołanie i poda rzeczywisty wynik, do którego można przejść.

## Uruchomione naprawdę (z wynikami)

Poniższe cztery przykłady to **rzeczywiste wywołania i wyniki zwrócone na miejscu**, a nie demonstracje. `$KEY` w poleceniach to twój API Token.

**① Skracanie adresu URL (synchronicznie, odpowiedź w kilka sekund)**

```bash
curl -X POST https://api.acedata.cloud/shorturl \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"content":"https://platform.acedata.cloud/services"}'
```

Zwraca `https://surl.id/r/1uKp2kilXQ` — po kliknięciu następuje przekierowanie 302 z powrotem do oryginalnej strony services.

**② Wyszukiwanie w internecie (synchronicznie)**

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"query":"OpenAI Sora release date","type":"search","number":3}'
```

Otrzymujesz bieżące wyniki Google (fragment):

```text
- Sora is here — OpenAI                       https://openai.com/index/sora-is-here/
- Sora (text-to-video model) — Wikipedia
- What to know about the Sora discontinuation — OpenAI Help
```

**③ Rozmowa z LLM (synchronicznie, jeden interfejs obsługuje ponad 50 modeli)**

```bash
curl -X POST https://api.acedata.cloud/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"model":"gpt-4.1-mini","messages":[{"role":"user","content":"用一句话解释 MCP"}]}'
```

```text
MCP to protokół służący do ujednoliconego zarządzania i wymiany informacji o kontekście modeli.
（39 tokens，本次约 0.00007 credit）
```

**④ Generowanie obrazów (asynchronicznie, około 20 sekund, agent automatycznie odpytuje do momentu wygenerowania obrazu)**

```bash
curl -X POST https://api.acedata.cloud/nano-banana/images \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"action":"generate","model":"nano-banana",
       "prompt":"a cute cartoon banana mascot waving hello, flat vector logo, white background"}'
```

Po około 22 sekundach zwracany jest rzeczywisty obraz (HTTP 200 · image/png · 317 KB · tym razem około 0,13 credit):

![Obraz rzeczywiście wygenerowany przez AceKit](https://cdn.acedata.cloud/assets/examples/nanobanana/957be0ef-5eaf-49cb-b3ed-3268e506db6e-130096c7ecec.png)

W rzeczywistości nie musisz pamiętać tych interfejsów — po zainstalowaniu umiejętności agent, zgodnie z ich własnymi `SKILL.md`, sam zbuduje poprawne żądania, obsłuży uwierzytelnianie i odpytywanie. Powyżej jedynie pokazano ci otwarcie „co robi w tle”.

## Co dokładnie instaluje

AceKit jest „głównym wejściem” do całego zestawu narzędzi deweloperskich AceData; obecnie jedna instalacja instaluje **zestaw narzędzi umiejętności (Skills)**:

- **Zestaw umiejętności Agenta**: każda umiejętność to gotowa instrukcja obsługi `SKILL.md` — uwierzytelnianie, asynchroniczne odpytywanie, ponawianie po błędach i sposób wypełniania parametrów są jasno opisane, więc agent po prostu postępuje zgodnie z instrukcją. Uruchom `npx acekit list`, aby zobaczyć aktualną listę (w chwili pisania tego tekstu było ich 19 i ich liczba stale rośnie):
```text
acedatacloud-api   ai-chat            face-transform     fish-audio
flux-image         google-search      hailuo-video       kling-video
luma-video         midjourney-image   nano-banana-image  producer-music
seedance-video     seedream-image     short-url          sora-video
suno-music         veo-video          wan-video
```

- **Jeden Token**: jeden `ACEDATACLOUD_API_TOKEN` odblokowuje wszystkie możliwości, rozliczane według rzeczywistego użycia.

Podział według możliwości (zgodnie z `npx acekit list`):

| Typ         | Dostawcy                                                  |
| ---------- | ---------------------------------------------------- |
| 🖼️ Generowanie obrazów      | Midjourney · Flux · Seedream · NanoBanana            |
| 🎬 Generowanie wideo      | Sora · Veo · Kling · Luma · Hailuo · Seedance · Wan  |
| 🎵 Generowanie muzyki / audio | Suno · Producer · Fish Audio（TTS）                    |
| 💬 Rozmowy LLM   | Ujednolicony interfejs dla ponad 50 modeli（GPT · Claude · Gemini · DeepSeek · Grok…） |
| 🔎 Wyszukiwanie       | Google SERP（strony internetowe · obrazy · wiadomości · mapy · wideo）                  |
| 🔗 Narzędzia       | Krótkie linki · przetwarzanie twarzy                                            |

> Te same możliwości AceData oferuje również jako niezależne **serwery MCP**（Suno、Midjourney、Sora、SERP… opublikowane w PyPI / VS Code / Smithery / Docker）、**CLI wiersza poleceń** oraz **SDK Python / TypeScript**, które można używać osobno w zależności od potrzeb. AceKit v0.2 planuje obsługę instalacji pojedynczych możliwości za pomocą `acekit add <name>` oraz automatyczne zapisywanie konfiguracji MCP dla każdego agenta.

## Które Agenty są obsługiwane

| Agent                        | Lokalizacja instalacji umiejętności                             |
| ---------------------------- | ---------------------------------- |
| Claude Code                  | `~/.claude/skills`                 |
| Codex CLI                    | `~/.agents/skills`                 |
| Cursor / Gemini / OpenCode itd. | `~/.agents/skills`（skieruj tutaj swojego agenta） |

Podczas instalacji AceKit automatycznie wykrywa agentów już zainstalowanych na komputerze i instaluje się tylko w tych, które wykryje.

## Ukryta funkcja: używaj tego samego Tokenu do zasilania samego Claude Code

Interfejs AceData jest jednocześnie kompatybilny z formatem Anthropic `/v1/messages`, więc **nie potrzebujesz oficjalnej subskrypcji Anthropic** — możesz zasilać Claude Code tym samym Tokenem AceData. Utwórz `.claude/settings.local.json` w katalogu głównym projektu:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "你的token",
    "ANTHROPIC_BASE_URL": "https://api.acedata.cloud"
  }
}
```

Wystarczy ponownie uruchomić Claude Code — korzysta on zarówno z całej rodziny modeli Claude, jak i zyskuje „ręce” do generowania obrazów, wideo i muzyki dzięki AceKit. Więcej szczegółów znajdziesz w [przewodniku integracji Claude Code](https://platform.acedata.cloud/documents/claude-code-integration).
