---
title: "Ustawianie globalnego współdzielenia salda dla Application AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Ustaw `allow_consume_global`. Po włączeniu kwalifikujące się rozliczane według użycia Application mogą nadal korzystać z globalnego salda konta, gdy ich własne saldo jest niewystarczające.

## Przygotowanie

- Utwórz i bezpiecznie zapisz [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Pobierz należący do Ciebie `application_id` z [listy wniosków o usługę](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='Twój token konta'
export APPLICATION_ID='Twój Application ID'
```

## Przegląd interfejsu

| Element    | Treść                                                                                              |
| ---------- | -------------------------------------------------------------------------------------------------- |
| Metoda     | `POST`                                                                                             |
| URL        | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Autoryzacja | Account Token                                                                                      |
| Body       | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

Po powodzeniu zwracany jest zaktualizowany obiekt Application. Należy kierować się wartością `allow_consume_global` w odpowiedzi, zamiast zakładać, że wartość żądania została na pewno zapisana.

> Application typu `Period` nie może zużywać globalnego salda. Nawet jeśli zostanie wysłane żądanie z `true`, serwer zachowa wartość tego pola jako `false`.

## Obsługa błędów

- `401`: Account Token jest nieprawidłowy lub nieobecny.
- `403`: Bieżące konto nie jest właścicielem tego Application.
- `404`: Application ID nie istnieje.

Punkt doładowania globalnego salda i dostępne pakiety zależą od konsoli platformy oraz rzeczywistych pakietów zwróconych przez [utworzenie zamówienia](https://platform.acedata.cloud/documents/platform-order-create); nie należy zakładać istnienia pakietu typu `Wallet`.

## Aplikacje z autoryzowanym debetem

Gdy pole tylko do odczytu `allow_overdraft=true` w aplikacji rozliczanej według użycia, aplikacja może nadal pobierać opłaty z własnego salda, nawet jeśli saldo stanie się ujemne, i nie przełączy się na konto globalne z powodu niewystarczającego salda. Aplikacje bez włączonego debetu nadal stosują się do `allow_consume_global`; to, czy debet jest dozwolony po przełączeniu, zależy od ustawień globalnego Application, z którego faktycznie pobierana jest opłata.
