---
title: "Ustawienie globalnego współdzielenia salda dla Application AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Ustaw `allow_consume_global`. Po włączeniu kwalifikujące się Application rozliczane według zużycia mogą nadal korzystać z globalnego salda konta, gdy ich własne saldo jest niewystarczające.

## Przygotowanie

- Utwórz i bezpiecznie zapisz [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Pobierz należący do Ciebie `application_id` z [listy wniosków o usługę](https://platform.acedata.cloud/documents/platform-application-list).

```shell
export PLATFORM_TOKEN='twój token konta'
export APPLICATION_ID='twój Application ID'
```

## Przegląd interfejsu

| Pozycja    | Treść                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------- |
| Metoda   | `POST`                                                                                             |
| URL  | `https://platform.acedata.cloud/api/v1/applications/{application_id}/update-allow-consume-global/` |
| Uwierzytelnianie   | Account Token                                                                                      |
| Body | JSON                                                                                               |

```shell
curl -X POST \
  "https://platform.acedata.cloud/api/v1/applications/${APPLICATION_ID}/update-allow-consume-global/" \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d '{"allow_consume_global": true}'
```

W przypadku powodzenia zwracany jest zaktualizowany obiekt Application. Należy kierować się wartością `allow_consume_global` w odpowiedzi, zamiast zakładać, że wartość żądania na pewno została zapisana.

> Application typu `Period` nie mogą zużywać globalnego salda. Nawet jeśli zostanie wysłane żądanie `true`, serwer zachowa wartość tego pola jako `false`.

## Obsługa błędów

- `401`: Account Token jest nieprawidłowy lub nieobecny.
- `403`: Bieżące konto nie jest właścicielem tego Application.
- `404`: Application ID nie istnieje.

Wejście do doładowania globalnego salda i dostępne pakiety są zgodne z panelem kontrolnym platformy oraz rzeczywistymi pakietami zwróconymi przez [tworzenie zamówienia](https://platform.acedata.cloud/documents/platform-order-create); nie należy zakładać istnienia pakietów typu `Wallet`.
