Odczytuje publiczne przełączniki funkcji i określenie kraju/regionu w kontekście bieżącego żądania. Nadaje się do decydowania podczas uruchamiania frontendu, czy funkcja powinna być wyświetlana; nie dotyczy marki witryny, danych kontaktowych ani katalogu ogłoszeń.

## Przegląd interfejsu

| Pozycja   | Treść                                           |
| --- | ----------------------------------------------- |
| Metoda  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Uwierzytelnianie  | Publiczne; przy przenoszeniu stanu logowania niektóre przełączniki funkcji mogą być obliczane według użytkownika                          |

## Parametry zapytania i nagłówki żądania

| Nazwa                    | Lokalizacja     | Opis                             |
| --------------------- | ------ | ------------------------------ |
| `features`            | query  | Wyrażenie nadpisania przełączników funkcji; obowiązuje tylko dla przełączników, dla których dozwolone jest nadpisanie przez klienta, lub dla superadministratora |
| `X-Feature-Overrides` | header | To samo źródło nadpisania co `features`           |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  -H 'Accept: application/json'
```

## Rzeczywista struktura odpowiedzi

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "region": "us"
}
```

| Pole         | Typ            | Opis                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Przełączniki funkcji widoczne dla bieżącego żądania; klucze mogą się zmieniać wraz z konfiguracją platformy, klient powinien odczytywać je według potrzeb i ustawiać bezpieczne wartości domyślne dla brakujących kluczy |
| `region`   | string / null | Kod kraju lub regionu wykryty na podstawie IP żądania, małymi literami; gdy nie można go rozpoznać, wynosi `null`        |

Nie pobieraj z tego interfejsu nazwy witryny, CDN, waluty, języka, danych kontaktowych obsługi klienta ani ogłoszeń; te pola nie należą do bieżącego kontraktu odpowiedzi.

## Zalecenia dotyczące użycia

- Przełączniki funkcji są obliczane według użytkownika, odcisku i kontekstu witryny, nie udostępniaj długoterminowo pamięci podręcznej między użytkownikami.
- Wybór selektora regionu jest przechowywany tylko we frontendzie; podczas wyświetlania priorytetowo używaj wybranego regionu, w przeciwnym razie użyj `region` z tego interfejsu. Ten interfejs nie przyjmuje parametrów nadpisania regionu.
- Nierozpoznane parametry query będą ignorowane; używaj wyłącznie parametrów wymienionych na tej stronie.
