Odczytuje publiczne przełączniki funkcji oraz ustalenie kraju/regionu w kontekście bieżącego żądania. Nadaje się do określania podczas uruchamiania frontendu, czy funkcja powinna być wyświetlana; nie służy do uzyskiwania marki witryny, danych kontaktowych ani katalogu ogłoszeń.

## Przegląd interfejsu API

| Pozycja   | Treść                                              |
| --- | ----------------------------------------------- |
| Metoda  | `GET`                                           |
| URL | `https://platform.acedata.cloud/api/v1/config/` |
| Uwierzytelnianie  | Publiczne; przy przekazaniu stanu logowania niektóre przełączniki funkcji mogą być obliczane na podstawie użytkownika                          |

## Parametry zapytania i nagłówki żądania

| Nazwa                    | Lokalizacja     | Opis                                    |
| --------------------- | ------ | ------------------------------------- |
| `country`             | query  | Dwuliterowy kod kraju ASCII; służy do zastąpienia kraju wyświetlanego w odpowiedzi, nie zmienia oceny bezpieczeństwa po stronie serwera |
| `features`            | query  | Wyrażenie nadpisania przełączników funkcji; działa tylko dla przełączników, których nadpisanie przez klienta jest dozwolone, lub dla superadministratora        |
| `X-Feature-Overrides` | header | Źródło nadpisania takie samo jak `features`                  |

```shell
curl --get 'https://platform.acedata.cloud/api/v1/config/' \
  --data-urlencode 'country=US' \
  -H 'Accept: application/json'
```

## Rzeczywista struktura odpowiedzi

```json
{
  "features": {
    "AUTO_RECHARGE_ENABLED": false,
    "DISCOUNT_FOR_X402": 0.0
  },
  "country": "us"
}
```

| Pole         | Typ            | Opis                                         |
| ---------- | ------------- | ------------------------------------------ |
| `features` | object        | Przełączniki funkcji widoczne dla bieżącego żądania; klucze zmieniają się wraz z konfiguracją platformy, klient powinien odczytywać je w razie potrzeby i ustawiać bezpieczne wartości domyślne dla brakujących kluczy |
| `country`  | string / null | Kod kraju małymi literami; w przypadku braku możliwości rozpoznania może mieć wartość `null`                     |

Nie pobieraj z tego interfejsu API nazwy witryny, CDN, waluty, języka, danych kontaktowych obsługi klienta ani ogłoszeń; te pola nie należą do bieżącego kontraktu odpowiedzi.

## Zalecenia dotyczące użycia

- Przełączniki funkcji są obliczane według użytkownika, odcisku urządzenia i kontekstu witryny, nie należy długotrwale współdzielić pamięci podręcznej między użytkownikami.
- Przekazane przez klienta `country` wpływa tylko na wartość zwracaną i nie omija polityk regionalnych ani polityk bezpieczeństwa po stronie serwera.
- Nierozpoznane parametry query są ignorowane; używaj wyłącznie parametrów wymienionych na tej stronie.
