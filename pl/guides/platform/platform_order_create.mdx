---
title: "Tworzenie zamówienia doładowania na platformie AceDataCloud"

Utwórz zamówienie oczekujące na płatność dla jednej lub wielu Application. Utworzenie zapisze zamówienie, ale nie zakończy automatycznie płatności; przed płatnością należy sprawdzić w odpowiedzi `price`, pakiet i Application.

## Przygotowanie

- Utwórz [Account Token](https://platform.acedata.cloud/documents/platform-token).
- Pobierz `application_id` z [listy Application](https://platform.acedata.cloud/documents/platform-application-list).
- Wybierz `package_id` zgodny z typem Application i dostępny do zakupu z `packages` w [szczegółach usługi](https://platform.acedata.cloud/documents/platform-service-detail).

```shell
export PLATFORM_TOKEN='twoje konto token'
export APPLICATION_ID='twoje Application ID'
export PACKAGE_ID='twoje Package ID'
```

## Przegląd interfejsu

| Pozycja    | Treść                                              |
| ---- | ----------------------------------------------- |
| Metoda   | `POST`                                          |
| URL  | `https://platform.acedata.cloud/api/v1/orders/` |
| Uwierzytelnianie   | Account Token, token OAuth wymaga `orders:write`      |
| Body | JSON                                            |

## Treść żądania

Zamówienie dla pojedynczego Application używa `application_id` + `package_id`; zamówienie zbiorcze używa odpowiadających długością `application_ids` + `package_ids`. Zwykłe zamówienia wybierają metodę płatności w późniejszym żądaniu `/pay/`. Zamówienie zakupu w aplikacji iOS podczas tworzenia przekazuje `pay_way: "AppleIAP"` i może wybrać tylko jeden pakiet Usage z `metadata.apple_product_id` oraz `metadata.apple_price`. Zakupy w aplikacji Apple używają niezależnej, wstępnie ustawionej ceny w dolarach amerykańskich, bez nakładania zniżki członkowskiej, zniżki za metodę płatności ani dopłaty za witrynę; kwota obciążenia w lokalnej walucie w innych regionach zależy od strony potwierdzenia płatności Apple.

```shell
curl -X POST 'https://platform.acedata.cloud/api/v1/orders/' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}" \
  -H 'Content-Type: application/json' \
  -d "{\"application_id\":\"${APPLICATION_ID}\",\"package_id\":\"${PACKAGE_ID}\"}"
```

## Opis odpowiedzi

Sukces zwraca `201` i nowo utworzony obiekt Order. Kluczowe pola obejmują `id`, `price`, `discount`, `state`, `application_id/application_ids`, `package_id/package_ids`, `expired_at` oraz pola czasu. Nowe zamówienia zazwyczaj mają status `Pending`, następnie wywołaj [opłać zamówienie](https://platform.acedata.cloud/documents/platform-order-pay).

- `price` to kwota do zapłaty obliczona przez serwer na podstawie pakietu, dopłaty za witrynę i zniżek; nie obliczaj jej samodzielnie po stronie klienta.
- Gdy Package nie pasuje do usługi lub typu Application, zwracane jest `400`.
- Bezpłatnych i zarządzanych przez system Package nie można odebrać samodzielnie przez publiczny interfejs zamówień.
- Utworzenie zamówienia dla Application, które nie należy do bieżącego konta, zostanie odrzucone.
