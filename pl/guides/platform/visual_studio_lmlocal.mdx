LMLocal to rozszerzenie dla Visual Studio 2022/2026, które oficjalnie wspiera API zgodne z OpenAI oraz niestandardowy adres URL bazowy. Miejsce konfiguracji może się zmieniać w zależności od wersji rozszerzenia; przy pierwszej integracji proszę ustalić wersję i sprawdzić rzeczywiste edytowanie, wywołania narzędzi oraz rejestrację użycia.

## Konfiguracja

1. Zainstaluj LMLocal z Visual Studio Marketplace lub oficjalnego repozytorium.
2. W sekcji Providers dodaj niestandardowego dostawcę OpenAI-compatible.
3. W polu Base URL wpisz `https://api.acedata.cloud/v1`.
4. W polu Auth Key wpisz swój token API Ace Data Cloud.
5. W polu Model wpisz dokładny identyfikator modelu wspierającego Chat Completions w katalogu modeli.
6. Po zapisaniu wyślij `Reply only OK`, a następnie przetestuj ponownie proces edytowania projektu.

## Aktualne ograniczenia

- Niniejszy przewodnik dotyczy tylko LMLocal i nie reprezentuje wspólnej konfiguracji innych rozszerzeń Visual Studio.
- Różne wersje mogą osobno obsługiwać zapytania dotyczące czatu, edytowania, budowania i testowania; każdy tryb należy niezależnie weryfikować.
- Jeśli klient automatycznie dodaje `/v1` lub ścieżkę endpointu, należy unikać powtarzających się ścieżek.
