Model Provider, IDE Extension i MCP w OpenCode to trzy niezależne możliwości. IDE Extension łączy lokalne środowisko uruchomieniowe OpenCode i ponownie wykorzystuje tę samą konfigurację Provider; nie oznacza to, że natywny edytor obsługuje Ace Data Cloud.

| Trasa                          | Opis                                                      | Link                                                                                     | Status      |
| ----------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------- |
| Terminal / CLI / TUI Provider | Używa `opencode.json[c]` i Chat Completions                | [Konfiguracja Provider](https://platform.acedata.cloud/documents/opencode-terminal-integration) | Zweryfikowana umowa konfiguracji |
| IDE Extension                 | VS Code, Cursor, Windsurf, VSCodium i inne hosty łączące się z OpenCode runtime | [Konfiguracja IDE](https://platform.acedata.cloud/documents/opencode-ide-integration)           | Eksperymentalny     |
| MCP                           | Wywoływanie zdalnych narzędzi w OpenCode                                      | [Przegląd MCP](https://platform.acedata.cloud/documents/opencode-mcp-all)                   | Niezależna możliwość    |

Po pomyślnej konfiguracji Provider, IDE Extension powinno używać tego samego Provider i modelu. Należy nadal osobno weryfikować czat w IDE, odczyt plików, edycję i wywołania narzędzi, nie należy automatycznie rozszerzać jednego zwykłego żądania CLI na wszystkie możliwości IDE.

ID modelu jest zgodne z [katalogiem na żywo](https://platform.acedata.cloud/models).
