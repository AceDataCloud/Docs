Pobierz pełne informacje o pojedynczej usłudze za pomocą ID usługi (UUID) lub aliasu (alias) — pola są pełniejsze niż te zwracane przez [Pobieranie listy usług platformy AceDataCloud](https://platform.acedata.cloud/documents/platform-service-list), dodatkowo rozwijane są powiązane obiekty, takie jak `apis`, `proxies`, `datasets`, `packages` itp. Nadaje się do scenariuszy takich jak strona szczegółów usługi, strona porównania cen, opis narzędzia Agent itd.

> ℹ️ Ten interfejs należy do **API zarządzania platformą AceDataCloud**, ze wspólnym prefiksem `https://platform.acedata.cloud/api/v1/`. Pełny indeks interfejsów znajdziesz w [Pobieranie listy dokumentów platformy AceDataCloud](https://platform.acedata.cloud/documents/platform-document-list).

## Przegląd interfejsu

| Pozycja   | Treść                                                        |
| --- | ------------------------------------------------------------- |
| Metoda  | `GET`                                                         |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}` |
| Uwierzytelnianie  | ❌ Publiczne                                                          |

`/services/{id}` oraz `/services/{id}/` są obecnie dostępne; w przykładach jednolicie używany jest format bez końcowego ukośnika.

## Informacje o uwierzytelnianiu

Ten interfejs jest całkowicie publiczny. **Jednak po dołączeniu tokenu konta pole `applied` w odpowiedzi będzie odzwierciedlać rzeczywisty status aplikacji bieżącego konta**, w przeciwnym razie zawsze będzie miało wartość `false`.

Sposób uzyskania tokenu konta znajdziesz w [Zarządzanie tokenami konta platformy AceDataCloud](https://platform.acedata.cloud/documents/platform-token).

## Parametry ścieżki

| Parametr           | Typ            | Wymagany  | Opis                                                    |
| ------------ | ------------- | --- | ----------------------------------------------------- |
| `service_id` | UUID / string | ✅   | ID usługi (UUID) lub alias (`midjourney`, `openai`, `webextrator` itd.) |

## Przykłady żądań

### cURL

```shell
# Zapytanie według UUID
curl 'https://platform.acedata.cloud/api/v1/services/8efa1d83-9b75-4562-b44a-af95ce563d05' \
  -H 'accept: application/json'

# Zapytanie według aliasu
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json'

# Sprawdzenie statusu applied z tokenem konta
curl 'https://platform.acedata.cloud/api/v1/services/midjourney' \
  -H 'accept: application/json' \
  -H "authorization: Bearer ${PLATFORM_TOKEN}"
```

### Python

```python
import os
import requests

resp = requests.get(
    "https://platform.acedata.cloud/api/v1/services/midjourney",
    headers={
        "accept": "application/json",
        "authorization": f"Bearer {os.environ['PLATFORM_TOKEN']}",
    },
    timeout=10,
)
svc = resp.json()
print(f"Usługa: {svc['title']} ({svc['alias']})")
print(f"Złożono wniosek: {svc['applied']}, darmowy limit: {svc['free_amount']} {svc['unit']}")
print(f"Liczba API: {len(svc['apis'])}, liczba pakietów: {len(svc['packages'])}")
for pkg in svc["packages"]:
    print(f"  ¥{pkg['price']:>7.2f}  ->  {pkg['amount']} {svc['unit']}")
```

### Node.js

```javascript
const r = await fetch('https://platform.acedata.cloud/api/v1/services/midjourney', {
  headers: { accept: 'application/json' },
})
const svc = await r.json()
console.log(`${svc.title} - pakietów ${svc.packages.length} - API ${svc.apis.length}`)
```

## Opis pól odpowiedzi

Interfejs szczegółów, oprócz wszystkich pól z [interfejsu listy](https://platform.acedata.cloud/documents/platform-service-list), dodatkowo rozwija:

| Pole         | Typ    | Opis                                                            |
| ---------- | ----- | ------------------------------------------------------------- |
| `apis`     | array | Pełna lista powiązanych obiektów API (każdy zawiera `id`, `name`, `title`, `path`, `stage`, `cost`) |
| `proxies`  | array | Pełna lista powiązanych obiektów Proxy                                              |
| `datasets` | array | Powiązane zbiory danych (jeśli `type=Dataset`)                                      |
| `packages` | array | Lista pakietów, zawiera `type` (`Usage`/`Period`), `price`, `amount`, `duration`   |

Definicje pozostałych pól znajdziesz w [Pobieranie listy usług platformy AceDataCloud → Opis pól odpowiedzi](https://platform.acedata.cloud/documents/platform-service-list).

## Obsługa błędów

| HTTP | code        | Znaczenie                            |
| ---- | ----------- | ----------------------------- |
| 404  | `not_found` | `service_id` (UUID lub alias) nie istnieje |
| 500  | —           | Zwykle końcowy ukośnik został błędnie dodany do URL, usuń go i spróbuj ponownie          |

## Praktyczne wskazówki

- **`alias` > `UUID`**: zakodowanie na stałe w kodzie `aliasu` (np. `midjourney`) jest bardziej stabilne; UUID zmienia się podczas migracji środowiska.
- **Pole `apis` nie zawiera definicji OpenAPI**: kompletny schemat OpenAPI 3.0 znajduje się w interfejsie [Pobieranie szczegółów API platformy AceDataCloud](https://platform.acedata.cloud/documents/platform-api-detail).
- **Pobranie „pełnych możliwości” usługi**: użyj tego interfejsu, aby uzyskać `api_ids`, a następnie wywołuj kolejno `/apis/{api_id}`, aby pobrać szczegóły.
- **Jeśli `applied=true`**, można bezpośrednio [utworzyć poświadczenia API](https://platform.acedata.cloud/documents/platform-credential-create), aby uzyskać 32-znakowy Token wymagany do wywoływania interfejsu biznesowego, bez potrzeby ponownego składania wniosku.
