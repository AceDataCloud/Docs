---
title: "Pobieranie listy API w ramach usługi platformy AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Zwraca stronicowaną listę aktualnie włączonych i niewycofanych API tej usługi za pomocą Service UUID. Jeśli dostępny jest tylko alias, najpierw wywołaj [szczegóły usługi](https://platform.acedata.cloud/documents/platform-service-detail), aby uzyskać `id`.

## Przegląd interfejsu

| Element   | Treść                                                                  |
| --- | ------------------------------------------------------------------- |
| Metoda  | `GET`                                                               |
| URL | `https://platform.acedata.cloud/api/v1/services/{service_id}/apis/` |
| Uwierzytelnianie  | Publiczne, token konta nie jest wymagany                                                           |
| Paginacja  | `count` + `items`                                                   |

## Parametry

| Parametr           | Lokalizacja    | Wymagany  | Opis                               |
| ------------ | ----- | --- | -------------------------------- |
| `service_id` | path  | Tak   | Service UUID, alias nie jest obsługiwany           |
| `limit`      | query | Nie   | Liczba elementów na stronę, maksymalnie 100                      |
| `offset`     | query | Nie   | Przesunięcie paginacji                            |
| `ordering`   | query | Nie   | Wyrażenie sortowania Django; zalecane `rank` lub `-rank` |

Obecny interfejs nie obsługuje filtrowania `stage`; wyklucza już API `Deprecated`.

```shell
export SERVICE_ID='Twój Service ID'
curl --get "https://platform.acedata.cloud/api/v1/services/${SERVICE_ID}/apis/" \
  --data-urlencode 'limit=100' \
  --data-urlencode 'ordering=rank' \
  -H 'Accept: application/json'
```

Elementy listy używają tej samej struktury indeksu co [lista API platformy](https://platform.acedata.cloud/documents/platform-api-list) i obecnie zawierają `definition`. Jeśli potrzebujesz stabilnego punktu wejścia dla pojedynczego API, kontynuuj wywołaniem `/api/v1/apis/{api_id}`.

## Obsługa błędów

- Usługa nie istnieje lub nie jest widoczna w bieżącej witrynie: `404`.
- `service_id` musi być UUID; alias nie zostanie rozwiązany w tej akcji.
