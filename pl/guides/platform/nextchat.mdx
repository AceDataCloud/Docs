[NextChat](https://github.com/ChatGPTNextWeb/NextChat) (wcześniej ChatGPT-Next-Web) to otwartoźródłowy klient AI, który można wdrożyć na Vercel, Cloudflare lub Dockerze. Obsługuje niestandardowe endpointy zgodne z OpenAI, dlatego można go połączyć z Ace Data Cloud. Ten artykuł przedstawia proces konfiguracji.

## Proces aplikacji

Aby połączyć Ace Data Cloud w NextChat, najpierw przejdź do [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), pobierz swój API Token i zachowaj go na później.

![Pobieranie klucza API Ace Data Cloud](https://cdn.acedata.cloud/dvc3cg.jpg)

Jeśli nie jesteś jeszcze zalogowany ani zarejestrowany, zostaniesz automatycznie przekierowany na stronę logowania, aby się zarejestrować i zalogować, a po zalogowaniu i rejestracji automatycznie wrócisz na bieżącą stronę.

Przy pierwszej aplikacji otrzymasz bezpłatny limit, dzięki któremu możesz bezpłatnie wypróbować usługi modeli Ace Data Cloud.

## Pobieranie NextChat

Możesz użyć wersji desktopowej (pobierz `.exe` / `.dmg` / AppImage ze [strony Releases](https://github.com/ChatGPTNextWeb/NextChat/releases)), [wersji internetowej](https://app.nextchat.club/) lub wdrożyć ją samodzielnie na Vercel / Cloudflare / Dockerze (zobacz zaawansowaną sekcję poniżej).

## Konfiguracja Ace Data Cloud

Uruchom NextChat i przejdź do **Ustawienia → Usługa modeli**:

| Pole          | Wartość                           | Opis                              |
| ----------- | --------------------------- | ------------------------------- |
| Dostawca usług modeli       | `OpenAI`                    | Używa protokołu zgodnego z OpenAI                  |
| Adres interfejsu OpenAI | `https://api.acedata.cloud` | Wpisz tylko domenę główną, **bez `/openai`, bez `/v1`** |
| API Key     | Twój Token Ace Data Cloud     | Token skopiowany z konsoli                    |

![Interfejs konfiguracji Ace Data Cloud w NextChat](https://cdn.acedata.cloud/47e0aed34570.png)

NextChat automatycznie dołącza `/v1/chat/completions` po adresie interfejsu, dlatego wystarczy wpisać domenę główną:

| Adres interfejsu                                  | Rzeczywiste żądanie                                                      | Wynik                       |
| ------------------------------------- | --------------------------------------------------------- | ------------------------ |
| `https://api.acedata.cloud`           | `https://api.acedata.cloud/v1/chat/completions`           | Poprawne                       |
| `https://api.acedata.cloud/openai`    | `https://api.acedata.cloud/openai/v1/chat/completions`    | 404 (pod `/openai` nie ma `/v1`) |
| `https://api.acedata.cloud/openai/v1` | `https://api.acedata.cloud/openai/v1/v1/chat/completions` | 404                      |

W polu „Niestandardowa nazwa modelu” wpisz modele rozdzielone przecinkami angielskimi. NextChat obsługuje specjalną składnię: `+nazwa_modelu` dodaje, `-nazwa_modelu` ukrywa, `nazwa_modelu=wyświetlana_nazwa` ustawia niestandardową nazwę wyświetlaną, a `-all` najpierw ukrywa wszystkie. Zalecany najczystszy zapis:

```text
-all,+MODEL_ID=wyświetlana_nazwa
```

## Wybór modelu

Katalog modeli będzie stale aktualizowany. W pierwszej kolejności korzystaj z listy modeli automatycznie ładowanej przez klienta; gdy potrzebujesz wprowadzić je ręcznie, najpierw wyślij żądanie `GET https://api.acedata.cloud/v1/models`, aby uzyskać aktualne ID modeli, a następnie wybierz zgodnie z obsługiwanym przez klienta kontekstem, obrazami i możliwościami wywoływania narzędzi.

## Weryfikacja integracji

Jeśli nie masz pewności, czy problem leży po stronie NextChat czy sieci, możesz najpierw bezpośrednio zweryfikować endpoint za pomocą curl (zastąp `{token}` swoim Tokenem):

```bash
curl -X POST 'https://api.acedata.cloud/v1/chat/completions' \
  -H 'Authorization: Bearer {token}' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "MODEL_ID",
    "messages": [{"role": "user", "content": "ping"}]
  }'
```

Zwrócenie obiektu `chat.completion` zgodnego z OpenAI oznacza, że zarówno Token, jak i endpoint są gotowe; jeśli zwrócone zostanie `HTTP 403 used_up`, oznacza to, że Token jest ważny, ale saldo jest niewystarczające — wystarczy doładować konto w [konsoli](https://platform.acedata.cloud/console/applications).

## Zaawansowane: wdrożenie jednym kliknięciem pod własną domeną

NextChat obsługuje wdrożenie własnej strony AI. Przykład z Dockerem (zastąp `{token}` swoim Tokenem):

```bash
docker run -d \
  --name nextchat \
  -p 3000:3000 \
  -e OPENAI_API_KEY={token} \
  -e BASE_URL=https://api.acedata.cloud \
  -e CODE=your-password \
  -e CUSTOM_MODELS="-all,+MODEL_ID=wyświetlana_nazwa" \
  yidadaa/chatgpt-next-web
```

Podczas wdrażania na Vercel / Cloudflare skonfiguruj te same zmienne `OPENAI_API_KEY`, `BASE_URL`, `CODE`, `CUSTOM_MODELS` w zmiennych środowiskowych projektu. `CODE` obsługuje wiele haseł dostępu rozdzielonych przecinkami angielskimi, co ułatwia statystyki użycia według osób. Pełny opis powyższych zmiennych środowiskowych (domyślne `BASE_URL` to `https://api.openai.com`, składnia `+/-/=/-all/+all` dla `CUSTOM_MODELS`) należy sprawdzić w [oficjalnym README NextChat](https://github.com/ChatGPTNextWeb/NextChat#environment-variables).

## Często zadawane pytania

### Komunikat 404 Not Found

Zwykle adres interfejsu został wpisany jako `.../openai` lub `.../openai/v1`. Zmień go na `https://api.acedata.cloud`, aby NextChat sam dołączył `/v1/chat/completions`.

### Dodanego modelu nie ma na liście rozwijanej modeli

Sprawdź format `CUSTOM_MODELS` — przed każdym modelem musi znajdować się `+`; jeśli użyto `-all`, upewnij się, że potrzebne modele zostały ponownie dodane za pomocą `+`.

### Komunikat 401 Unauthorized

Upewnij się, że w API Key wklejono Token Ace Data Cloud (bez prefiksu `Bearer`, bez dodatkowych spacji) oraz że saldo przypisanej aplikacji jest wystarczające.
