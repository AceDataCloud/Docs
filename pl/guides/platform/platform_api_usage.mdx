---
title: "Pobieranie ostatnich próbek wywołań API platformy AceDataCloud"
description: "Platform API guide - Ace Data Cloud"
---

Publicznie zwraca próbki rekordów wywołań określonego API z ostatnich 15 minut, używane do szybkiego obserwowania bieżącego stanu. Nie jest to interfejs zliczający agregowany według kodów statusu ani nie może być używany do osobistych rozliczeń, SLA lub pełnych statystyk użycia.

## Przegląd interfejsu

| Pozycja   | Treść                                                        |
| --- | ------------------------------------------------------------ |
| Metoda  | `GET`                                                        |
| URL | `https://platform.acedata.cloud/api/v1/apis/{api_id}/usage/` |
| Uwierzytelnianie  | Publiczne, nie wymaga tokena konta                                                    |
| Limit  | Po połączeniu ostatnio utworzonych/zakończonych rekordów zwracanych jest maksymalnie 5 000 pozycji                                    |

`api_id` można uzyskać z [listy API](https://platform.acedata.cloud/documents/platform-api-list).

```shell
export API_ID='Twój API ID'
curl "https://platform.acedata.cloud/api/v1/apis/${API_ID}/usage/" \
  -H 'Accept: application/json'
```

## Rzeczywista struktura odpowiedzi

Odpowiedź jest bezpośrednio tablicą, bez użycia envelope paginacji:

```json
[
  {
    "api_id": "00000000-0000-4000-8000-000000000001",
    "created_at": "2026-09-25T08:00:00Z",
    "trace_id": "example-trace-id",
    "status_code": 200,
    "elapsed": 1.25
  }
]
```

| Pole            | Opis        |
| ------------- | --------- |
| `api_id`      | API ID    |
| `created_at`  | Czas utworzenia rekordu    |
| `trace_id`    | Identyfikator śledzenia żądania    |
| `status_code` | Kod statusu HTTP  |
| `elapsed`     | Czas trwania wywołania, w sekundach |

Gdy API nie istnieje, obecnie również może zostać zwrócona pusta tablica, ponieważ ta akcja bezpośrednio wyszukuje ostatnie usage według ID, bez wcześniejszej weryfikacji obiektu API. Aby obliczyć wskaźnik powodzenia, klient musi samodzielnie grupować zwrócone próbki; aby sprawdzić osobiste opłaty, użyj interfejsu na poziomie konta.
