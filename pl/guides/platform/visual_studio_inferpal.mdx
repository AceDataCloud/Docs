Inferpal to rozszerzenie dla Visual Studio 2022/2026, które oficjalnie wspiera połączenie z usługami zgodnymi z OpenAI. Wersja rozszerzenia może wpływać na edytowanie, wywoływanie narzędzi i rejestrowanie użycia; przy pierwszej integracji proszę ustalić wersję i przeprowadzić minimalną weryfikację opisaną poniżej.

## Konfiguracja

1. Zainstaluj Inferpal z Visual Studio Marketplace lub oficjalnego repozytorium.
2. Otwórz **Ustawienia Inferpal → Połączenie**.
3. Wybierz Provider jako OpenAI-compatible.
4. Wypełnij Base URL jako `https://api.acedata.cloud/v1`.
5. Wypełnij API Key swoim tokenem API Ace Data Cloud.
6. Wypełnij Model dokładnym identyfikatorem modelu wspierającym Chat Completions w katalogu modeli.
7. Po zapisaniu wyślij `Odpowiedz tylko OK`, a następnie wykonaj ponownie żądanie zawierające kontekst kodu.

## Aktualne ograniczenia

- Ten przewodnik dotyczy tylko Inferpal i nie oznacza, że wbudowany Copilot Visual Studio lub inne rozszerzenia wspierają te same pola.
- Różne wersje mogą automatycznie dodawać ścieżkę do Base URL; jeśli żądanie nie powiedzie się, najpierw sprawdź, czy ostateczne żądanie trafia na punkt końcowy Chat Completions.
- Nie zobowiązujemy się do zapewnienia dostępności wszystkich trybów edytowania, uzupełniania lub wywoływania narzędzi przed zakończeniem ustalonej wersji E2E.
