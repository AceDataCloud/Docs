FreeAIr to otwarta wtyczka dla Visual Studio 2022/2026, która według oficjalnych informacji może łączyć się z dowolnym API zgodnym z OpenAI. Zachowanie żądań w różnych wersjach wtyczki może się różnić; przy pierwszej integracji proszę ustalić wersję i przeprowadzić minimalną weryfikację opisaną poniżej.

## Konfiguracja

1. Zainstaluj FreeAIr z Visual Studio Marketplace lub oficjalnego repozytorium.
2. Otwórz ustawienia FreeAIr i dodaj połączenie zgodne z OpenAI.
3. W polu Endpoint wpisz `https://api.acedata.cloud/v1`.
4. W polu Token wpisz swój token API Ace Data Cloud.
5. W polu Model wpisz dokładny identyfikator modelu wspierającego Chat Completions w katalogu modeli.
6. Po zapisaniu wyślij `Reply only OK`, a następnie przetestuj ponownie żądanie z kontekstem projektu.

## Aktualne ograniczenia

- Ten przewodnik dotyczy tylko FreeAIr i nie oznacza, że wbudowany Copilot w Visual Studio wspiera dowolny Base URL.
- Wersja wtyczki może zmienić sposób łączenia endpointów; podczas weryfikacji należy sprawdzić ostateczny URL żądania.
- Wykorzystanie narzędzi i możliwości MCP w wtyczce wymaga niezależnej weryfikacji, nie można zastąpić tego zwykłym czatem.
