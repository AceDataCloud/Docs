Coze oficjalnie wspiera integrację modeli niestandardowych i oferuje trzy protokoły: OpenAI Chat API, OpenAI Responses API oraz Anthropic Messages API. Trzy ścieżki różnią się Base URL, łączeniem ścieżek, nagłówkami, streamingiem i umowami dotyczącymi wywołań narzędzi, dlatego muszą być konfigurowane i weryfikowane osobno.

| Ścieżka                   | Status     | Przewodnik                                                                                  |
| ----------------------- | -------- | ----------------------------------------------------------------------------------------- |
| OpenAI Chat Completions | Eksperymentalny | [Konfiguracja Chat](https://platform.acedata.cloud/documents/coze-chat-integration)           |
| OpenAI Responses        | Eksperymentalny | [Konfiguracja Responses](https://platform.acedata.cloud/documents/coze-responses-integration) |
| Anthropic Messages      | Eksperymentalny | [Konfiguracja Messages](https://platform.acedata.cloud/documents/coze-messages-integration)   |

„Eksperymentalny” oznacza, że oficjalne możliwości i punkty konfiguracji zostały potwierdzone, ale różne obszary Coze, wersje lub plany mogą wyświetlać różne formularze, Ace Data Cloud nadal musi zakończyć weryfikację stałej wersji zgodnie z protokołem. Nie należy sukcesu jednego protokołu ekstrapolować na pozostałe dwa.

## Zasady konfiguracji

- Base API URL należy wypełnić zgodnie z dokumentacją; nie należy powtarzać dodawania endpoint path, które klient automatycznie uzupełni.
- API Key użyj swojego tokena API Ace Data Cloud.
- Model użyj dokładnego identyfikatora modelu zgodnego z wybranym protokołem w katalogu modeli.
- Po pomyślnym zakończeniu zwykłego tekstu, należy również zweryfikować streaming i wywołania narzędzi.
