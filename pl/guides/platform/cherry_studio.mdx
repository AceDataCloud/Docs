## 1. Pobierz API Key

Otwórz [listę aplikacji Ace Data Cloud](https://platform.acedata.cloud/console/applications), przejdź do dostępnej aplikacji i skopiuj API Key.

![Pobieranie Ace Data Cloud API Key](https://cdn.acedata.cloud/dvc3cg.jpg)

## 2. Dodaj Provider

Otwórz Cherry Studio, przejdź do **Ustawienia → Usługi modeli → Dodaj dostawcę**, wypełnij:

| Pole      | Wartość                           |
| ------- | --------------------------- |
| Nazwa dostawcy   | `Ace Data Cloud`            |
| Typ dostawcy   | `OpenAI`                    |
| API Key | Właśnie skopiowany API Key               |
| Adres API  | `https://api.acedata.cloud` |

![Ekran konfiguracji dodawania Ace Data Cloud Provider w Cherry Studio](https://cdn.acedata.cloud/b67a927eae62.png)

Cherry Studio automatycznie uzupełni `/v1/chat/completions` dla typu OpenAI. Przy używaniu ogólnego punktu wejścia nie dodawaj `#` na końcu adresu ani nie musisz tworzyć wielu Providerów według rodzin modeli.

## 3. Dodaj i włącz model

1. Kliknij **Pobierz listę modeli**; jeśli bieżąca wersja nie obsługuje automatycznego pobierania, przejdź do [katalogu modeli](https://platform.acedata.cloud/models), aby sprawdzić, a następnie ręcznie dodaj nazwę docelowego modelu, na przykład `claude-opus-5`, `gpt-6-sol`.
2. Kliknij przycisk sprawdzania obok API Key, aby zweryfikować połączenie.
3. Włącz przełącznik **Włącz** dla Providera.
4. Wybierz właśnie dodany model w selektorze modeli rozmów.

![Lista Providerów i modeli Cherry Studio](https://cdn.acedata.cloud/149de1d088bf.png)

> Po zakończeniu pobierania lub ręcznego dodawania modeli włącz przełącznik Providera w prawym górnym rogu.

Wyślij `Reply only OK` i sprawdź wywołanie w [historii użycia](https://platform.acedata.cloud/console/usages). W przypadku 401 sprawdź Key; jeśli model nie jest wyświetlany, sprawdź, czy Provider jest włączony; w przypadku 404 sprawdź, czy ręcznie wpisana nazwa modelu jest dokładnie zgodna z `id` w katalogu.

## O GPT Image 2

Zwykły niestandardowy Provider czatu w Cherry Studio nie może bezpośrednio wywoływać Images API. Generowanie i edycja `gpt-image-2` powinny korzystać ze specjalnego interfejsu Ace Data Cloud:

- [Generowanie obrazów GPT Image 2](https://platform.acedata.cloud/documents/openai-images-generations)
- [Edycja obrazów GPT Image 2](https://platform.acedata.cloud/documents/openai-images-edits)

Nie wpisuj `/openai/images/generations` do Providera czatu.
