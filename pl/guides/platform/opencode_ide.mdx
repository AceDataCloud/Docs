Oficjalny rozszerzenie IDE OpenCode wspiera edytory takie jak VS Code, Cursor, Windsurf, VSCodium i wykorzystuje lokalny runtime OpenCode oraz konfigurację Provider. Rozszerzenie IDE wykorzystuje lokalnego CLI Provider, ale łańcuch żądań może się różnić w zależności od wersji edytora; przy pierwszej integracji proszę ustalić wersję i przeprowadzić minimalną weryfikację.

## Konfiguracja Provider

Najpierw zgodnie z [konfiguracją OpenCode Terminal](https://platform.acedata.cloud/documents/opencode-terminal-integration) skonfiguruj Ace Data Cloud Provider w `opencode.json` lub `opencode.jsonc`:

```jsonc
{
  "provider": {
    "acedatacloud": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.acedata.cloud/v1",
        "apiKey": "{env:ACEDATACLOUD_API_KEY}"
      },
      "models": {
        "MODEL_ID": { "name": "MODEL_ID" }
      }
    }
  },
  "model": "acedatacloud/MODEL_ID"
}
```

## Instalacja IDE Extension

1. W zintegrowanym terminalu edytora uruchom `opencode`, aby automatycznie zainstalować rozszerzenie zgodnie z oficjalnym procesem; można również ręcznie zainstalować z odpowiedniego Marketplace.
2. Przeładuj edytor.
3. Zainicjuj `Reply only OK` z OpenCode Extension.
4. Wykonaj ponownie żądanie, które wymaga odczytu pliku lub modyfikacji kodu, aby potwierdzić, że IDE Extension używa tego samego Provider i modelu.

## Aktualne ograniczenia

- Możliwości Provider pochodzą z runtime OpenCode, nie oznacza to, że hostujący edytor natywnie wspiera Ace Data Cloud.
- Wersje rozszerzeń VS Code i różnych forków mogą się różnić, należy je rejestrować osobno.
- Sukces zwykłej rozmowy nie zastępuje weryfikacji odczytu plików, edycji i wywołań narzędzi.
