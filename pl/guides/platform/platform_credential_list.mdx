Stronicowane wyświetlanie poświadczeń biznesowego API. Ta odpowiedź obecnie zawiera wrażliwe pola poświadczeń Token lub Identity i musi być przetwarzana wyłącznie po stronie serwera; zapisywanie jej w logach, platformach analitycznych, trwałej pamięci frontendu lub publicznych repozytoriach jest zabronione.

## Przygotowanie

Utwórz [Account Token](https://platform.acedata.cloud/documents/platform-token) i pobierz UUID bieżącego konta za pomocą `GET /api/v1/platform-tokens/me/`.

```shell
export PLATFORM_TOKEN='twój token konta'
export USER_ID='UUID twojego konta'
```

## Przegląd interfejsu

| Element   | Zawartość                                                   |
| --- | ---------------------------------------------------- |
| Metoda  | `GET`                                                |
| URL | `https://platform.acedata.cloud/api/v1/credentials/` |
| Uwierzytelnianie  | Account Token, token OAuth wymaga `credentials:read`       |
| Stronicowanie  | `count` + `items`                                    |

Zwykli użytkownicy powinni przekazać własne `user_id` lub autoryzowane `application_id`; w przeciwnym razie podczas stronicowania napotkanie obiektu bez uprawnień może zwrócić `403`.

## Parametry zapytania

| Parametr                 | Typ      | Wymagany  | Opis                             |
| ------------------ | ------- | --- | ------------------------------ |
| `user_id`          | string  | Zależnie od scenariusza | Właściciel poświadczeń; obsługuje powtarzane parametry                   |
| `application_id`   | UUID    | Nie   | Filtruje według Application; obsługuje powtarzane parametry        |
| `host`             | string  | Nie   | Filtruje dokładnie według hosta; obsługuje powtarzane parametry             |
| `name`             | string  | Nie   | Filtruje dokładnie według nazwy; obsługuje powtarzane parametry                 |
| `granted`          | boolean | Nie   | `true` oznacza poświadczenia przyznane innym, `false` oznacza poświadczenia do własnego użytku |
| `limit` / `offset` | integer | Nie   | Stronicowanie                             |
| `ordering`         | string  | Nie   | `created_at` lub `-created_at`   |

`service_id`, `disabled`, `expired` obecnie nie są parametrami filtrowania.

```shell
curl --get 'https://platform.acedata.cloud/api/v1/credentials/' \
  --data-urlencode "user_id=${USER_ID}" \
  --data-urlencode 'limit=100' \
  -H "Authorization: Bearer ${PLATFORM_TOKEN}"
```

## Opis odpowiedzi

Zweryfikowana odpowiedź produkcyjna ma postać `{count, items}`. Każdy element zawiera `id`, `application_id`, `application`, `user_id`, `creator_id`, `name`, `type`, `limited_amount`, `used_amount`, `expired_at`, `allowed_api_ids`, `host`, `granted`, `granted_to_user_id`, `tags`, `metadata` oraz pola czasowe, a także zwraca `token` lub `username/password` zależnie od typu.

> Bieżąca odpowiedź listy zwraca pełne wartości wrażliwe. Nie wyświetlaj ich w konsoli przeglądarki ani systemach zbierania danych i nie polegaj na odzyskiwaniu jawnego tekstu za pośrednictwem listy; klient powinien być zgodny z przyszłymi strategiami maskowania.
