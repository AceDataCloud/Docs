Oficjalna dokumentacja BYOK GitHub Copilot wymienia VS Code jako wspierany lokalny klient oraz wspiera dostawcę zgodnego z OpenAI. Wersja VS Code, polityka przedsiębiorstwa i widoczność modelu mogą wpływać na ostateczny punkt końcowy; przy pierwszej integracji proszę sprawdzić rzeczywiste żądanie zgodnie z poniższymi wskazówkami.

## Zakres konfiguracji

1. Upewnij się, że Twoje konto lub organizacja GitHub Copilot ma włączoną funkcję BYOK/Custom Models.
2. W zarządzaniu modelami Copilot w VS Code dodaj nowego dostawcę zgodnego z OpenAI.
3. Wypełnij Base URL jako `https://api.acedata.cloud/v1`.
4. Wypełnij API Key swoim tokenem API Ace Data Cloud.
5. Wypełnij Model dokładnym identyfikatorem modelu zgodnym z wybranym protokołem w katalogu modeli.
6. W Copilot Chat wyślij `Reply only OK`, a następnie przetestuj ponownie żądanie z kontekstem roboczym.

## Aktualne ograniczenia

- Konfiguracja Copilot App, CLI, GitHub Desktop, Enterprise BYOK różni się od konfiguracji w VS Code, dlatego niniejszy przewodnik nie stosuje kroków z innych klientów bezpośrednio do VS Code.
- Polityka organizacji może zabraniać osobom dodawania dostawców lub modeli.
- Uzupełnianie tabulacji, Chat, Agent i zadania w tle mogą korzystać z różnych ścieżek modeli, które należy weryfikować osobno.
