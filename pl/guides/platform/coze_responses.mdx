Dokumentacja Coze dotycząca niestandardowych modeli obsługuje OpenAI Responses API i dostarcza Base API URL, API Key oraz pola modelu. Różne wersje najmu Coze mogą różnić się w obsłudze łączenia ścieżek, strumieniowego wyjścia i wywołań narzędzi, dlatego przy pierwszym połączeniu proszę sprawdzić każdy punkt poniżej.

## Konfiguracja

1. Wejdź do zarządzania modelami Coze i dodaj nowy niestandardowy model.
2. Wybierz protokół OpenAI Responses API.
3. Wypełnij Base API URL jako `https://api.acedata.cloud/v1`.
4. Wypełnij API Key swoim tokenem API Ace Data Cloud.
5. Wypełnij Model dokładnym identyfikatorem modelu wspierającym Responses API w katalogu modeli.
6. Zapisz i zakończ test połączenia Coze.
7. W Bot/Agent wyślij `Reply only OK`, a następnie przetestuj ponownie wywołanie narzędzia.

## Aktualne ograniczenia

- Różne obszary, wersje lub pakiety Coze mogą wyświetlać różne formularze.
- Base API URL powinno używać base, nie dodawaj ponownie `/responses`; jeśli obecny interfejs użytkownika wyraźnie wymaga pełnego URL API, kieruj się wskazówkami formularza.
- Chat Completions, Responses i Anthropic Messages to trzy niezależne ścieżki, które nie mogą się wzajemnie zastępować w weryfikacji.
