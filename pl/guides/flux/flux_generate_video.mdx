---
title: "Przewodnik integracji wideo FLUX"
description: "Flux API guide - Ace Data Cloud"
---

Przesyłaj zadania przez `POST /flux/videos`, używaj `action`, aby wybrać generowanie, edycję lub upscaling. Pominięcie `action` jest równoznaczne z `generate`. Używaj istniejącego `POST /flux/tasks`, aby sprawdzać zadania platformy. Obsługiwane są `async=true` i `callback_url`; ukończone wyniki zawierają link do wideo platformy oraz zmierzone przez serwer czas trwania, wymiary i liczbę klatek na sekundę.

## Generowanie: action=generate

Obsługiwane są `mode=t2v/i2v/v2v/draft_enhance`. Zwykłe generowanie obsługuje całkowite 5–20 sekund lub `auto`; kontynuacja wideo obsługuje 5–15 sekund. i2v może udostępniać 1–10 klatek kluczowych, obsługiwane są uporządkowane pary `[sekunda, obraz]`. Rozdzielczość wyjściowa to hd/fhd/qhd/uhd, obsługiwane jest synchroniczne audio. Szkic wyprowadza tylko hd i zwraca platformowe `draft_task_id`; ponowne użycie szkicu wymaga tego samego przypisania i podlega ograniczeniu okresu ważności pamięci podręcznej generowania. Odtworzenie szkicu nie może nadpisywać oryginalnego promptu i materiałów.

```json
{"action":"generate","model":"flux-3","mode":"t2v","prompt":"海边日落","duration":5,"resolution":"hd","async":true}
```

## Edycja: action=edit

Przekaż `video` i `prompt`. Edycja jest rozliczana według rzeczywistej liczby sekund wyjściowych i nie przyjmuje pól generowania, takich jak `mode`, `duration` itd.

```json
{"action":"edit","video":"https://example.com/video.mp4","prompt":"将场景改为蓝色调","async":true}
```

## Upscaling: action=upscale

Przekaż `input_video`, opcjonalnie `upscale_factor` (1.5–3) i `creativity` (0 oznacza dokładny, 1 oznacza kreatywny). Rozliczanie odbywa się według rzeczywistych wyjściowych MP·sekund: `czas trwania × szerokość × wysokość / 1048576 × liczba klatek na sekundę / 24`, 1 MP = 1024×1024. Parametry generowania nie są akceptowane.

```json
{"action":"upscale","input_video":"https://example.com/video.mp4","upscale_factor":2,"creativity":0,"async":true}
```

Każda operacja stosuje bieżące współczynniki cen referencyjnych FLUX i jest rozliczana według rzeczywistych wyników wyjściowych. Za nieudane zadania nie są naliczane opłaty za generowanie; ostateczny koszt zadań z dynamicznym rozliczaniem zależy od ukończonych wyników. Różne operacje akceptują wyłącznie własne parametry, nieznane action zwraca błąd parametrów.
