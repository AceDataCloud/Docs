Flux Videos API używa `POST /flux/videos` do generowania wideo, generowania wideo z obrazów klatek kluczowych, kontynuacji wideo i ulepszania szkiców. `action=generate` (domyślnie), `mode` wybiera tryb generowania; do zapytań o wyniki jednolicie używany jest istniejący `POST /flux/tasks`.

> Obecnie w wersji Beta. Generowanie wideo z tekstu, generowanie wideo z obrazów, kontynuacja wideo i ulepszanie szkiców są dostępne. HTTP 200 i ID zadania oznaczają jedynie przyjęcie zadania, należy kontynuować zapytania o wynik końcowy.

## 1. Uzyskiwanie API Token

1. Zarejestruj się lub zaloguj w [konsoli Ace Data Cloud](https://platform.acedata.cloud/console/applications), utwórz aplikację i uzyskaj API Token. Jeden uniwersalny API Token może wywoływać usługi platformy; upewnij się, że aplikacja ma uprawnienia do wywoływania usługi Flux oraz dostępne saldo.
2. Na [stronie usługi Flux](https://platform.acedata.cloud/services/flux?tab=pricing) sprawdź plany oraz ceny poszczególnych operacji. Gdy saldo jest niewystarczające, doładuj je na [stronie salda konsoli](https://platform.acedata.cloud/console/coin).
3. Żądania używają `Authorization: Bearer <twój Token>`. Token powinien być przechowywany w zmiennych środowiskowych po stronie serwera; nie zapisuj go na stronach frontendowych, w publicznych repozytoriach, zrzutach ekranu ani adresach URL callbacków.

![Uzyskiwanie API Token w konsoli](https://cdn.acedata.cloud/dvc3cg.jpg)

Kod w tym artykule jednolicie odczytuje zmienną środowiskową:

```bash
export ACEDATACLOUD_API_TOKEN='替换为你自己的 API Token'
```

| Element      | Wartość                                               |
| ------- | ----------------------------------------------- |
| Główny adres API | `https://api.acedata.cloud`                     |
| Przesyłanie zadań wideo  | `POST /flux/videos`                             |
| Zapytanie o istniejące zadania  | `POST /flux/tasks`                              |
| Uwierzytelnianie      | `Authorization: Bearer $ACEDATACLOUD_API_TOKEN` |
| Format żądania    | `Content-Type: application/json`                |

Pełne pola i debugowanie online znajdziesz w [Flux Videos API](https://platform.acedata.cloud/documents/flux-videos), a zapytania o zadania w [Flux Tasks API](https://platform.acedata.cloud/documents/flux-tasks).

## 2. Wybór operacji i danych wejściowych

| action                      | mode            | Dane wejściowe                       | Wynik            |
| --------------------------- | --------------- | ------------------------ | ------------- |
| `generate` (wartość domyślna po pominięciu action) | `t2v`           | `prompt`                 | Generowanie wideo z tekstu       |
| `generate`                  | `i2v`           | `prompt`, `keyframes`     | Generowanie wideo z jednej lub wielu klatek kluczowych |
| `generate`                  | `v2v`           | `prompt`, `start_video`   | Kontynuacja na podstawie wejściowego wideo      |
| `generate`                  | `draft_enhance` | `draft_task_id` własnego ukończonego szkicu | Ulepszanie tego szkicu         |

Model generowania to `flux-3`, a `action` to `generate` (domyślnie). Za pomocą `mode` wybiera się generowanie wideo z tekstu, generowanie wideo z obrazów, kontynuację wideo lub ulepszanie szkicu.

### Wspólne parametry generowania

| Parametr                 | Opis                                                           |
| ------------------ | ------------------------------------------------------------ |
| `mode`             | Wymagany; `t2v`, `i2v`, `v2v` lub `draft_enhance`                       |
| `prompt`           | Wymagany dla zwykłego generowania; ulepszanie szkicu nie pozwala nadpisać oryginalnego promptu                                        |
| `duration`         | Dla t2v/i2v liczba całkowita 5–20 sekund, dla v2v liczba całkowita 5–15 sekund lub `auto`; końcowy czas trwania może nieznacznie różnić się od żądanej wartości |
| `resolution`       | `hd`, `fhd`, `qhd`, `uhd`; domyślnie `hd` dla zwykłego generowania, domyślnie `fhd` dla ulepszania szkicu              |
| `aspect_ratio`     | `auto`, `21:9`, `2:1`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `9:21`   |
| `draft`            | Czy najpierw wygenerować szkic; szkic obsługuje tylko `hd`                                           |
| `generate_audio`   | Czy generować zsynchronizowane audio; `false` jest prawidłową wartością, zachowaj jawną wartość logiczną                               |
| `safety_tolerance` | Opcjonalny; liczba całkowita 0–4                                                   |
| `async`            | Zaleca się ustawienie na `true`, aby natychmiast zwrócić ID zadania platformy, a następnie odpytywać o wynik                                |
| `callback_url`     | Opcjonalny; adres HTTP(S) odbierający końcowy wynik JSON; po ustawieniu również będzie przyjmowany asynchronicznie                        |

Adres URL materiału musi być dostępny dla usługi. W przypadku tymczasowego podpisanego adresu URL należy zapewnić wystarczający okres ważności na pobranie i przetworzenie. Nie używaj adresu strony internetowej jako adresu pliku obrazu lub wideo.

## 3. Generowanie wideo z tekstu: pełne przetestowane żądanie i wynik

Poniższe żądanie zostało pomyślnie wykonane w interfejsie produkcyjnym przed zmianą cen 2026-10-02. Pominięcie `action` zweryfikowało domyślne zachowanie generowania; `async=true` pozwala uniknąć długiego oczekiwania na połączenie HTTP.

```bash
curl -X POST 'https://api.acedata.cloud/flux/videos' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light, steady camera, no text.",
    "duration": 5,
    "resolution": "hd",
    "draft": true,
    "async": true
  }'
```

Odpowiedź przyjęcia (rzeczywiste ID zadania):

```json
{
  "task_id": "4341eb66-3845-4972-bb86-712a6cfae845",
  "trace_id": "b0f851bd-0925-43ca-acc3-6f634c70d607"
}
```

Zapisz `task_id` z własnej odpowiedzi i kontynuuj zapytania; nie używaj ID zadania z przykładu w dokumentacji do zapytań o wyniki innych kont.

```bash
curl -X POST 'https://api.acedata.cloud/flux/tasks' \
  -H "Authorization: Bearer $ACEDATACLOUD_API_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"action":"retrieve","id":"替换为本次返回的 task_id"}'
```

Pole `response` zwracane przez zapytanie o zadanie zawiera końcowy wynik biznesowy. Poniżej znajduje się pomyślny `response` z tego testu, z pominięciem zewnętrznych metadanych zadania. | Pole odpowiedzi                              | Zastosowanie                                       |
| --------------------------------- | ---------------------------------------- |
| `success`                         | Czy końcowe zadanie zakończyło się powodzeniem; zwrócenie task_id na etapie przyjęcia nie jest równoznaczne z success=true |
| `task_id`                         | ID zadania platformy, używane do odpytywania i obsługi idempotencji biznesowej                      |
| `trace_id`                        | Należy przekazać personelowi wsparcia podczas rozwiązywania problemów                             |
| `data[].video_url`                | Adres dostępnego do odczytu wyniku wideo                               |
| `data[].seconds/width/height/fps` | Rzeczywisty czas trwania, wymiary i liczba klatek na sekundę wyjścia zmierzone przez serwer                       |
| `data[].draft_task_id`            | Wejściowe ID ulepszenia szkicu; występuje tylko przy zwracaniu szkicu możliwego do ponownego użycia                  |
| `usage`                           | Końcowe rozliczane użycie; nie zastępuj rzeczywistego seconds żądanym duration      |
| `cost.amount`                     | Ostatecznie pobrane Credits za ten raz; `currency=credit` nie oznacza dolarów   |
| `cost.list_amount`                | Credits przed rabatem na konsumpcję dla użytkownika aplikacji; zwracane, gdy ma zastosowanie                 |

To jest historyczny rzeczywisty test sprzed zmiany cen: `list_amount=2.9871876975` Credits, konto miało wówczas 10% rabatu na konsumpcję, a rzeczywiste `amount=2.68846892775` Credits. Nowa cena z 2026-10-02 została obniżona o około 6.33%; ten sam szkic o długości 5.041667 sekundy kosztuje według aktualnej ceny 2.798125185 Credits (przed rabatem na konsumpcję), a przy nadal obowiązującym 10% rabacie na konsumpcję — 2.5183126665 Credits. Rozliczenia historycznych zadań nie są przeliczane ponownie. Plany i rabaty dla innych kont mogą się różnić; nie jest to stała cena w dolarach dla wszystkich użytkowników.

## 4. Obraz do wideo: zwykłe i z klatkami kluczowymi z czasem

Poniżej znajdują się przykłady parametrów, wymagające zastąpienia adresów URL materiałów; nie stanowią one deklaracji, że ten przykład został już pomyślnie wykonany. Po zakończeniu generowania wykonaj zapytanie zgodnie z powyższym procesem; struktura wyniku jest taka sama.

Dla jednego lub dwóch obrazów użyj zwykłej tablicy:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "The camera slowly moves around the product in soft studio light.",
  "keyframes": ["https://example.com/first-frame.jpg"],
  "duration": 5,
  "resolution": "hd",
  "generate_audio": false,
  "async": true
}
```

Przy określaniu momentów klatek kluczowych użyj par `[liczba sekund, URL obrazu]`:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "i2v",
  "prompt": "A smooth transition from morning light to a warm sunset.",
  "keyframes": [[0, "https://example.com/start.jpg"], [5, "https://example.com/end.jpg"]],
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

Dozwolonych jest 1–10 klatek kluczowych. Tablica z czasem musi być uporządkowana rosnąco według czasu, czas wynosi 0–20 sekund i nie można mieszać zwykłych URL-i z elementami zawierającymi czas. Trzy lub więcej zwykłych klatek kluczowych musi mieć wyraźnie określone duration, nie można używać auto.

## 5. Kontynuacja wideo

Do `start_video` przekaż adres istniejącego pliku wideo, `mode=v2v`, czas trwania maksymalnie 15 sekund.

```json

  "model": "flux-3",
  "mode": "v2v",
  "prompt": "Continue the sailboat drifting forward with the same steady camera.",
  "start_video": "https://example.com/source.mp4",
  "duration": 5,
  "resolution": "hd",
  "async": true
}
```

## 6. Najpierw szkic, następnie ulepszenie

1. Wygeneruj szkic za pomocą `draft=true`、`resolution=hd` i poczekaj na powodzenie.
2. Pobierz ID szkicu platformy z końcowego `data[0].draft_task_id`.
3. Prześlij żądanie ulepszenia przy użyciu poświadczeń aplikacji o tym samym przypisaniu:

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "draft_enhance",
  "draft_task_id": "替换为自己的已完成草稿 ID",
  "resolution": "fhd",
  "async": true
}
```

Do ulepszenia szkicu nie można przekazywać `prompt`、`duration`、`aspect_ratio`、`version`、`generate_audio`、`draft`、`keyframes`、`start_video`, aby nadpisać oryginalną zawartość. Pamięć podręczna szkicu jest zasobem tymczasowym, prosimy o terminowe ulepszenie; nie gwarantuje się stałego przechowywania ani określonej liczby dni przechowywania. Szkice niebędące własnymi/niepochodzące z bieżącej aplikacji, nieukończone szkice oraz wygasłe pamięci podręczne nie mogą być ponownie użyte. Szkic i ulepszenie to dwa zadania, za które po powodzeniu naliczane są opłaty osobno.

## 7. Wywołanie Python end-to-end

Zainstaluj `requests`, ustaw własny Token, a uruchomienie poniższego skryptu pozwoli zakończyć „jedno przesłanie → odpytywanie → wyprowadzenie URL wideo”. Zarówno zapytania, jak i ponowienia sieciowe powinny używać oryginalnego task_id, aby uniknąć wielokrotnego przesyłania płatnych zadań.
```python
import os
import time
import requests

base_url = "https://api.acedata.cloud"
headers = {
    "Authorization": "Bearer " + os.environ["ACEDATACLOUD_API_TOKEN"],
    "Accept": "application/json",
}
payload = {
    "action": "generate",
    "model": "flux-3",
    "mode": "t2v",
    "prompt": "A small toy sailboat floating on calm blue water in warm morning light.",
    "duration": 5,
    "resolution": "hd",
    "draft": True,
    "async": True,
}
submitted = requests.post(base_url + "/flux/videos", json=payload, headers=headers, timeout=120)
submitted.raise_for_status()
accepted = submitted.json()
if accepted.get("error"):
    raise RuntimeError(accepted["error"])
task_id = accepted["task_id"]
print("Task ID:", task_id)  # 持久化保存，用于恢复轮询

# 30 分钟是本示例的客户端等待上限，不是服务的完成时限承诺。
deadline = time.monotonic() + 30 * 60
while time.monotonic() < deadline:
    polled = requests.post(
        base_url + "/flux/tasks",
        json={"action": "retrieve", "id": task_id},
        headers=headers,
        timeout=30,
    )
    polled.raise_for_status()
    task = polled.json()
    if task.get("error"):
        raise RuntimeError(task["error"])
    result = task.get("response") or task.get("result")
    if isinstance(result, dict) and result.get("success") is True:
        print("Video:", result["data"][0]["video_url"])
        print("Usage:", result.get("usage"))
        print("Cost:", result.get("cost"))
        break
    if isinstance(result, dict) and result.get("error"):
        raise RuntimeError(result["error"])
    time.sleep(10)
else:
    raise TimeoutError("Still processing; resume polling with task_id=" + task_id)
```

Po przekroczeniu limitu czasu sieciowego nie traktuj nieznanego stanu jako niepowodzenia i nie przesyłaj natychmiast ponownie. Jeżeli uzyskano już `task_id`, kontynuuj odpytywanie tego zadania; zapisuj `task_id` i `trace_id`, aby ułatwić diagnozowanie. Sam interfejs odpytywania nie pobiera opłat za generowanie.

## 8. Korzystanie z callbacków

Podczas przesyłania dodaj `callback_url`; po ukończeniu zadania końcowy wynik JSON zostanie wysłany metodą POST pod ten adres. Struktura sukcesu jest zgodna z opisanym wcześniej response, a w przypadku niepowodzenia zawiera error.

```json
{
  "action": "generate",
  "model": "flux-3",
  "mode": "t2v",
  "prompt": "A small sailboat on calm water.",
  "duration": 5,
  "resolution": "hd",
  "draft": true,
  "callback_url": "https://your-server.example/flux-callback"
}
```

Adres callbacka powinien być dostępny z publicznego Internetu. Po otrzymaniu powiadomienia przetwarzaj je idempotentnie według task_id i jak najszybciej zwróć 2xx; przetwarzanie biznesowe można umieścić w kolejce. Niniejszy dokument nie deklaruje, że callback posiada uwierzytelnianie podpisem: przed wykonaniem wrażliwych operacji, takich jak przyznanie uprawnień biznesowych, użyj własnego Tokena, aby zapytać o to samo zadanie i zweryfikować wynik. Jeżeli callback nie zostanie otrzymany, można również kontynuować odpytywanie; nie generuj ponownie.

Nieudane zadania nie są obciążane opłatą za generowanie; ostateczna kwota zależy od wyniku ukończenia i zapisów wywołań w konsoli.

## 10. Częste problemy i diagnostyka

| Sytuacja                       | Zalecenie                                                   |
| ------------------------ | ---------------------------------------------------- |
| Błąd parametrów (400)                | Sprawdź action=generate, mode, duration i format klatki kluczowej; nie mieszaj pól różnych trybów generowania |
| Błąd uwierzytelniania (401)                | Sprawdź Bearer Token, uprawnienia aplikacji oraz ważność poświadczeń                          |
| Odrzucenie przez moderację treści (403)              | Dostosuj materiały i prompt, nie przesyłaj wielokrotnie identycznej wersji                                    |
| Ograniczenie liczby żądań (429)                  | Zmniejsz równoległość, ponawiaj z wycofywaniem                                            |
| service_unavailable (503) | Bieżąca operacja jest niedostępna; zaakceptowane zadania asynchroniczne mogą zgłosić ten błąd w końcowym response                |
| task_id został zwrócony, ale nadal nie ma wideo        | Kontynuuj odpytywanie response, nie traktuj HTTP 200 jako ukończenia generowania                     |
| Szkicu nie można ponownie wykorzystać                   | Potwierdź własnego/bieżącego aplikację, ukończenie zadania, oryginalne żądanie draft=true oraz sprawdź, czy tymczasowy cache jest nadal ważny          |

Przy zgłaszaniu opinii podaj task_id, trace_id, czas żądania i zanonimizowane parametry; nie wysyłaj API Tokena. Więcej metod znajdziesz w [przewodniku integracji Flux MCP](https://platform.acedata.cloud/documents/flux-mcp).
