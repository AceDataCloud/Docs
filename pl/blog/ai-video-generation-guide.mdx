## Przegląd

Generowanie wideo AI rozwija się bardzo szybko. Ace Data Cloud oferuje 7 różnych API do generowania wideo, obejmujących scenariusze od tekstu do wideo po generowanie wideo z obrazów.

## Dostępne usługi generowania wideo

| Usługa | Endpoint | Model | Cechy |
|--------|----------|-------|-------|
| Sora   | `POST /sora/videos` | sora-2, sora-2-pro | Produkcja OpenAI, jakość kinowa |
| Veo    | `POST /veo/videos` | veo3, veo3-fast | Produkcja Google, obsługa 4K |
| Kling  | `POST /kling/videos` | kling-v2-5-turbo | Produkcja Kuaishou, szybka prędkość |
| Luma   | `POST /luma/videos` | — | Kontrola klatek początkowych i końcowych |
| Hailuo | `POST /hailuo/videos` | minimax-t2v | Produkcja MiniMax |
| Seedance | `POST /seedance/videos` | doubao-seedance-1-0-pro-250528 | Produkcja ByteDance |
| Wan    | `POST /wan/videos` | wan2.6-t2v | Produkcja Alibaba |

## Szybki start

### Generowanie wideo Sora

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/sora/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "A cat playing in a sunny garden",
        "model": "sora-2",
        "duration": 10,
        "orientation": "landscape",
    },
)
print(response.json())
```

### Generowanie wideo Kling

```python
response = requests.post(
    "https://api.acedata.cloud/kling/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A white cat walking in the snow",
        "model": "kling-v2-5-turbo",
        "duration": 5,
        "aspect_ratio": "16:9",
    },
)
print(response.json())
```

### Generowanie wideo Veo

```python
response = requests.post(
    "https://api.acedata.cloud/veo/videos",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "text2video",
        "prompt": "A coffee mug rotating on a marble counter",
        "model": "veo3",
    },
)
print(response.json())
```

## Obsługa zadań asynchronicznych

Generowanie wideo zwykle wymaga więcej czasu. Wszystkie API wideo obsługują:

1. **Powiadomienia zwrotne (callback)**: ustaw `callback_url` w żądaniu, wynik zostanie automatycznie przesłany po zakończeniu generowania
2. **Zapytania cykliczne (polling)**: sprawdzanie statusu zadania przez endpoint `/tasks`

```python
# Użycie callback URL
data = {
    "prompt": "A sunrise over mountains",
    "model": "sora-2",
    "callback_url": "https://your-server.com/webhook",
}

# Lub sprawdzanie statusu zadania
task_response = requests.post("https://api.acedata.cloud/sora/tasks",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"},
    json={"task_id": "your-task-id"})
```
