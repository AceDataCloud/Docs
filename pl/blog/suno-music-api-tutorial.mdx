## Wprowadzenie do Suno

Suno jest jednym z najpotężniejszych obecnie dostępnych platform AI do generowania muzyki. Dzięki Suno API od Ace Data Cloud możesz generować wysokiej jakości muzykę za pomocą prostych wywołań API.

## Punkty końcowe API

| Punkt końcowy | Funkcja |
|---------------|---------|
| `POST /suno/audios` | Generowanie muzyki (główny punkt końcowy) |
| `POST /suno/lyrics` | Generowanie tekstów piosenek |
| `POST /suno/persona` | Zarządzanie stylem wokalisty |
| `POST /suno/wav` | Pobieranie formatu WAV |
| `POST /suno/mp4` | Pobieranie formatu MP4 |
| `POST /suno/tasks` | Sprawdzanie statusu zadań |

## Podstawowa generacja

### Generowanie na podstawie opisu tekstowego

```python
import requests

response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "prompt": "A cheerful pop song about summer vacation",
        "model": "chirp-v5",
    },
)
print(response.json())
```

### Generowanie niestandardowych tekstów piosenek

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "generate",
        "model": "chirp-v5",
        "custom": True,
        "lyric": "[Verse]\n夏日的阳光洒满了海岸\n微风中传来浪花的声音\n\n[Chorus]\n让我们一起去远方\n追逐那自由的梦想",
        "style": "pop upbeat",
        "title": "夏日冒险",
    },
)
```

## Zaawansowane funkcje

### Kontynuacja utworu

```python
response = requests.post(
    "https://api.acedata.cloud/suno/audios",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "action": "extend",
        "audio_id": "your-existing-audio-id",
        "model": "chirp-v5",
    },
)
```

### Generowanie tekstów piosenek

```python
response = requests.post(
    "https://api.acedata.cloud/suno/lyrics",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json",
    },
    json={
        "prompt": "写一首关于冬天的歌",
    },
)
```

## Dostępne modele

| Model | Charakterystyka |
|-------|----------------|
| chirp-v5 | Najnowsza wersja, najlepsza jakość dźwięku |
| v4-5-plus | Wersja ulepszona |
| v4-5 | Wersja stabilna |
| v4 | Wersja klasyczna |

## Podsumowanie

Suno API oferuje pełne możliwości generowania muzyki za pośrednictwem platformy Ace Data Cloud. Zarówno proste generowanie na podstawie tekstu, jak i tworzenie niestandardowych tekstów piosenek można zrealizować za pomocą kilku linijek kodu.

Zarejestruj się i wypróbuj na [platform.acedata.cloud](https://platform.acedata.cloud).
