## Co to jest MCP

Model Context Protocol (MCP) to otwarty protokół, który pozwala asystentom AI (takim jak Claude, Cursor) bezpośrednio wywoływać zewnętrzne narzędzia i API. Dzięki MCP AI nie tylko odpowiada na pytania, ale także wykonuje rzeczywiste operacje.

## MCP Server oferowane przez Ace Data Cloud

| MCP Server       | Nazwa pakietu PyPI | Funkcje            |
|------------------|--------------------|--------------------|
| MCPSuno          | mcp-suno           | Generowanie muzyki AI |
| MCPSerp          | mcp-serp           | Wyszukiwanie Google |
| MCPMidjourney    | mcp-midjourney     | Generowanie obrazów AI |
| MCPLuma          | mcp-luma           | Generowanie wideo AI |
| MCPSora          | mcp-sora           | Generowanie wideo AI |
| MCPVeo           | mcp-veo            | Generowanie wideo AI |
| MCPNanoBanana    | mcp-nano-banana    | Generowanie obrazów AI |

## Instalacja i użycie

### Instalacja

```bash
pip install mcp-suno  # lub inny MCP Server
```

### Konfiguracja zmiennych środowiskowych

```bash
export ACEDATACLOUD_API_TOKEN="YOUR_API_TOKEN"
```

### Konfiguracja w Cursor

Dodaj w ustawieniach MCP Cursor:

```json
{
  "mcpServers": {
    "suno": {
      "command": "mcp-suno",
      "env": {
        "ACEDATACLOUD_API_TOKEN": "YOUR_API_TOKEN"
      }
    }
  }
}
```

### Konfiguracja w Claude Desktop

Edytuj plik konfiguracyjny Claude Desktop, dodając konfigurację MCP Server.

## Przypadki użycia

1. **Generowanie muzyki w Cursor**: Powiedz AI „wygeneruj radosną piosenkę za pomocą Suno”, AI bezpośrednio wywoła API  
2. **Wyszukiwanie informacji na żywo**: AI może korzystać z MCP Serp do wyszukiwania najnowszych informacji  
3. **Generowanie materiałów projektowych**: AI może wywołać Midjourney, aby wygenerować obrazy potrzebne do projektu

## MCP a bezpośrednie wywołanie API

- **MCP**: odpowiedni do użycia w narzędziach programistycznych AI, wywoływany automatycznie przez AI  
- **API**: odpowiednie do integracji w własnych aplikacjach, kontrolowane programistycznie  

Oba korzystają z tego samego tokenu API Ace Data Cloud i wywołują te same punkty końcowe API.

## Podsumowanie

MCP pozwala asystentom AI bezpośrednio wywoływać różne API Ace Data Cloud. Wszystkie MCP Server są dostępne na PyPI, instalacja i konfiguracja są proste, co czyni twoje narzędzia AI potężniejszymi.

Odwiedź [platform.acedata.cloud](https://platform.acedata.cloud), aby uzyskać token API.
