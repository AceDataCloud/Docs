Wszystkie Ace Data Cloud API używają uwierzytelniania **Bearer Token**.

## Uzyskiwanie Tokena

Zaloguj się do [listy aplikacji](https://platform.acedata.cloud/console/applications?lang=pl&utm_source=docs&utm_medium=referral&utm_campaign=evergreen) i otwórz **General Application**. Przy pierwszym użyciu wybierz **Initialize General Application**. Kliknij przycisk kopiowania obok pola **API KEY**.

![Klucz API aplikacji ogólnej](https://cdn.acedata.cloud/dvc3cg.jpg)

Przechowuj klucz na serwerze i wstaw jego wartość w miejsce `YOUR_API_TOKEN` w przykładzie.

## Używanie Tokena

Do każdego żądania dołącz Token w nagłówku `Authorization`:

```bash
Authorization: Bearer YOUR_API_TOKEN
```


## Ograniczenia szybkości

Ograniczenia szybkości zależą od usługi i poziomu subskrypcji. Po przekroczeniu limitu API zwraca `429 Too Many Requests`.

## Najlepsze praktyki bezpieczeństwa

- Nie ujawniaj API Token w kodzie klienta
- Przechowuj Token w zmiennych środowiskowych
- Regularnie rotuj Tokeny
- Używaj różnych Tokenów dla środowisk deweloperskich i produkcyjnych
