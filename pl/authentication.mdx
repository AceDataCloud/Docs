Wszystkie Ace Data Cloud API używają uwierzytelniania **Bearer Token**.

## Uzyskiwanie Tokena

1. Zarejestruj konto na [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subskrybuj wymagane usługi
3. Utwórz poświadczenia (API Token) dla każdej usługi

## Używanie Tokena

Do każdego żądania dołącz Token w nagłówku `Authorization`:

```bash
Authorization: Bearer YOUR_API_TOKEN
```

<Note title="Wskazówka">
  Każdy Token jest powiązany z konkretną subskrypcją usługi. Różne usługi używają różnych Tokenów lub można utworzyć **globalne** poświadczenia do użytku między usługami.
</Note>

## Ograniczenia szybkości

Ograniczenia szybkości zależą od usługi i poziomu subskrypcji. Po przekroczeniu limitu API zwraca `429 Too Many Requests`.

## Najlepsze praktyki bezpieczeństwa

- Nie ujawniaj API Token w kodzie klienta
- Przechowuj Token w zmiennych środowiskowych
- Regularnie rotuj Tokeny
- Używaj różnych Tokenów dla środowisk deweloperskich i produkcyjnych
