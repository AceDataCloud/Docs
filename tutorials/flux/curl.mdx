## 简介

Flux 是 Ace Data Cloud 提供的AI 图像服务，Black Forest Labs Flux 图像生成模型。通过 Ace Data Cloud 统一 API，你可以使用 cURL 快速调用 Flux，实现文生图、图片编辑、多种模型、自定义尺寸等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- 安装了 cURL 的终端环境

## 基础用法

调用 Flux API 的主端点为：

```
POST https://api.acedata.cloud/flux/images
```

本示例使用 `flux-pro-1.1` 模型。
可用模型包括：`flux-dev`、`flux-pro`、`flux-pro-1.1`、`flux-pro-1.1-ultra`、`flux-kontext-pro`、`flux-kontext-max`。

完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}'
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应示例

成功调用后返回 JSON 格式数据，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 处理响应

推荐使用 jq 工具格式化输出：

```bash
curl -s -X POST https://api.acedata.cloud/flux/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "prompt": "A white siamese cat sitting on a windowsill", "model": "flux-pro-1.1", "size": "1024x1024"}' | jq .
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
