## 简介

Flux 是 Ace Data Cloud 提供的AI 图像服务，Black Forest Labs Flux 图像生成模型。通过 Ace Data Cloud 统一 API，你可以使用 Python 快速集成 Flux，实现文生图、图片编辑、多种模型、自定义尺寸等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- Python 3.7 及以上环境
- 安装 requests 库：`pip install requests`

## 基础用法

调用 Flux API 的主端点为：

```
POST https://api.acedata.cloud/flux/images
```

本示例使用 `flux-pro-1.1` 模型。
可用模型包括：`flux-dev`、`flux-pro`、`flux-pro-1.1`、`flux-pro-1.1-ultra`、`flux-kontext-pro`、`flux-kontext-max`。

完整 Python 代码示例：

```python
import requests

url = "https://api.acedata.cloud/flux/images"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "generate",
    "prompt": "A white siamese cat sitting on a windowsill",
    "model": "flux-pro-1.1",
    "size": "1024x1024"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应处理

成功调用后，API 返回 JSON 格式数据。建议检查 HTTP 状态码：

```python
if response.status_code == 200:
    result = response.json()
    print("调用成功:", result)
else:
    print(f"调用失败，状态码: {response.status_code}")
    print(response.text)
```

## 进阶用法

对于支持异步任务的 API，可以通过回调 URL 获取结果：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 结果将通过回调 URL 推送到你的服务器
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
