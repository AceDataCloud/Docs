## 简介

Face Change 是 Ace Data Cloud 提供的AI 图像服务，AI 人脸处理服务。通过 Ace Data Cloud 统一 API，你可以使用 cURL 快速调用 Face Change，实现人脸替换、人脸美化、年龄变换、性别变换、动漫化、人脸分析等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- 安装了 cURL 的终端环境

## 基础用法

调用 Face Change API 的主端点为：

```
POST https://api.acedata.cloud/face/swap
```



完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}'
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应示例

成功调用后返回 JSON 格式数据，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 处理响应

推荐使用 jq 工具格式化输出：

```bash
curl -s -X POST https://api.acedata.cloud/face/swap \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"source_image_url": "https://example.com/source-face.jpg", "target_image_url": "https://example.com/target-face.jpg"}' | jq .
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
