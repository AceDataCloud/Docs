This tutorial shows you how to use the **Luma Dream Machine API** with Python through Ace Data Cloud's unified API platform.

## What you'll build

By the end of this tutorial, you'll have a working Python script that calls the Luma Dream Machine API. Key capabilities:

- text-to-video
- image-to-video
- fast generation
- async/webhook

## Prerequisites

- Python 3.8+
- An [Ace Data Cloud API key](https://platform.acedata.cloud) (free trial available)
- `requests` library (`pip install requests`)

## Step 1: Get your API key

<Steps>
<Step title="Create an account">
    Sign up at [platform.acedata.cloud](https://platform.acedata.cloud).
</Step>
<Step title="Subscribe to Luma Dream Machine">
    Go to the [Luma Dream Machine service page](https://platform.acedata.cloud) and click **Acquire**. You'll get free trial credits.
</Step>
<Step title="Copy your API key">
    Navigate to your credentials and copy the Bearer token.
</Step>
</Steps>

## Step 2: Make your first request

```python
import requests

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.acedata.cloud"

response = requests.post(
    f"{BASE_URL}/luma/videos",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
  "model": "ray-2",
  "prompt": "Ocean waves crashing on a tropical beach at golden hour"
},
)

data = response.json()
print(data)
```

## Step 3: Handle the response

The API returns a JSON response. Here's how to parse it:

```python
if response.status_code == 200:
    result = response.json()
    print("Success:", result)
elif response.status_code == 401:
    print("Error: Invalid API key")
elif response.status_code == 429:
    print("Error: Rate limit exceeded, try again later")
else:
    print(f"Error {response.status_code}:", response.text)
```

## Step 4: Async processing with webhooks

For long-running tasks, use webhooks to receive results asynchronously:

```python
response = requests.post(
    f"{BASE_URL}/luma/videos",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "model": "ray-2",
        "prompt": "Ocean waves crashing on a tropical beach at golden hour",
        "callback_url": "https://your-server.com/webhook",
    },
)

task = response.json()
print("Task ID:", task.get("task_id"))
# Results will be sent to your callback_url when ready
```

## Error handling

| Status code | Meaning | What to do |
|---|---|---|
| 200 | Success | Parse the response |
| 400 | Bad request | Check your request parameters |
| 401 | Unauthorized | Verify your API key |
| 403 | Forbidden | Content may violate usage policies |
| 429 | Rate limited | Wait and retry with exponential backoff |
| 500 | Server error | Retry after a short delay |
