Test the **Luma Dream Machine API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "ray-2", "prompt": "Ocean waves crashing on a tropical beach at golden hour"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/luma/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "ray-2", "prompt": "Ocean waves crashing on a tropical beach at golden hour", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Luma Dream Machine service
3. Create a credential and copy the token
