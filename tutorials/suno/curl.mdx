Test the **Suno API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "An upbeat pop song about summer adventures", "model": "chirp-v4", "custom": false, "action": "generate"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/suno/audios \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "An upbeat pop song about summer adventures", "model": "chirp-v4", "custom": false, "action": "generate", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Suno service
3. Create a credential and copy the token
