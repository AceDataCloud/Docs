Test the **Fish Audio API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Welcome to Ace Data Cloud, your unified AI API platform.", "reference_id": "default"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/fish/audios \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Welcome to Ace Data Cloud, your unified AI API platform.", "reference_id": "default", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Fish Audio service
3. Create a credential and copy the token
