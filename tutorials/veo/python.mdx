## 简介

Veo 是 Ace Data Cloud 提供的AI 视频服务，Google Veo 视频生成模型。通过 Ace Data Cloud 统一 API，你可以使用 Python 快速集成 Veo，实现文生视频、图生视频、4K 分辨率、多种比例等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- Python 3.7 及以上环境
- 安装 requests 库：`pip install requests`

## 基础用法

调用 Veo API 的主端点为：

```
POST https://api.acedata.cloud/veo/videos
```

本示例使用 `veo3` 模型。
可用模型包括：`veo2`、`veo2-fast`、`veo3`、`veo3-fast`、`veo31`、`veo31-fast`。

完整 Python 代码示例：

```python
import requests

url = "https://api.acedata.cloud/veo/videos"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "action": "text2video",
    "prompt": "A coffee mug rotating slowly on a marble counter",
    "model": "veo3"
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应处理

成功调用后，API 返回 JSON 格式数据。建议检查 HTTP 状态码：

```python
if response.status_code == 200:
    result = response.json()
    print("调用成功:", result)
else:
    print(f"调用失败，状态码: {response.status_code}")
    print(response.text)
```

## 进阶用法

对于支持异步任务的 API，可以通过回调 URL 获取结果：

```python
data['callback_url'] = 'https://your-server.com/callback'
response = requests.post(url, headers=headers, json=data)
# 结果将通过回调 URL 推送到你的服务器
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
