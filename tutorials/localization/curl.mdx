## 简介

Localization 是 Ace Data Cloud 提供的工具服务，AI 翻译本地化服务。通过 Ace Data Cloud 统一 API，你可以使用 cURL 快速调用 Localization，实现Markdown 翻译、JSON 翻译、18 种语言、保持格式等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- 安装了 cURL 的终端环境

## 基础用法

调用 Localization API 的主端点为：

```
POST https://api.acedata.cloud/localization/translate
```

本示例使用 `gpt-4` 模型。
可用模型包括：`gpt-3.5`、`gpt-4`。

完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}'
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应示例

成功调用后返回 JSON 格式数据，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 处理响应

推荐使用 jq 工具格式化输出：

```bash
curl -s -X POST https://api.acedata.cloud/localization/translate \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"input": "# 欢迎使用\n\n这是一段示例文本。", "locale": "en", "extension": "md", "model": "gpt-4"}' | jq .
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
