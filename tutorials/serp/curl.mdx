Test the **Google Search (SERP) API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type": "search", "query": "best AI APIs 2026"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/serp/google \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type": "search", "query": "best AI APIs 2026", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Google Search (SERP) service
3. Create a credential and copy the token
