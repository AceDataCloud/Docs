## 简介

Gemini 是 Ace Data Cloud 提供的AI 聊天服务，Google Gemini 系列大语言模型。通过 Ace Data Cloud 统一 API，你可以使用 JavaScript 快速集成 Gemini，实现多轮对话、系统提示词、流式输出、JSON 输出模式等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- Node.js 18+ 或现代浏览器环境

## 基础用法

调用 Gemini API 的主端点为：

```
POST https://api.acedata.cloud/gemini/chat/completions
```

本示例使用 `gemini-2.5-flash` 模型。
可用模型包括：`gemini-2.5-flash`、`gemini-2.5-pro`、`gemini-2.0-flash`、`gemini-3.0-pro`。

完整 JavaScript 代码示例：

```javascript
const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "model": "gemini-2.5-flash",
  "messages": [
    {
      "role": "user",
      "content": "你好，请介绍一下你自己"
    }
  ],
  "max_tokens": 1024,
  "temperature": 0.7
}),
});

const result = await response.json();
console.log(result);
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应处理

建议检查响应状态码并处理错误：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("调用成功:", result);
} else {
  console.error(`调用失败，状态码: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 封装

推荐封装为可复用函数：

```javascript
async function callGemini(data) {
  const response = await fetch("https://api.acedata.cloud/gemini/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
