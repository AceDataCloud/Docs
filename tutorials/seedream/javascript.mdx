## 简介

Seedream 是 Ace Data Cloud 提供的AI 图像服务，字节跳动 Seedream 图像生成模型。通过 Ace Data Cloud 统一 API，你可以使用 JavaScript 快速集成 Seedream，实现文生图、图片编辑、多种分辨率、水印控制等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- Node.js 18+ 或现代浏览器环境

## 基础用法

调用 Seedream API 的主端点为：

```
POST https://api.acedata.cloud/seedream/images
```

本示例使用 `doubao-seedream-4-0-250828` 模型。
可用模型包括：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

完整 JavaScript 代码示例：

```javascript
const response = await fetch("https://api.acedata.cloud/seedream/images", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "一只白色的暹罗猫坐在窗台上",
  "model": "doubao-seedream-4-0-250828",
  "size": "1K"
}),
});

const result = await response.json();
console.log(result);
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应处理

建议检查响应状态码并处理错误：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("调用成功:", result);
} else {
  console.error(`调用失败，状态码: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 封装

推荐封装为可复用函数：

```javascript
async function callSeedream(data) {
  const response = await fetch("https://api.acedata.cloud/seedream/images", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
