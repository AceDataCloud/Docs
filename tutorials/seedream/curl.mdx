Test the **Seedream API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "seedream-3.0", "prompt": "A photorealistic portrait of a robot reading a book"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "seedream-3.0", "prompt": "A photorealistic portrait of a robot reading a book", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Seedream service
3. Create a credential and copy the token
