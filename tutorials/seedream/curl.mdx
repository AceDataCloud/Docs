## 简介

Seedream 是 Ace Data Cloud 提供的AI 图像服务，字节跳动 Seedream 图像生成模型。通过 Ace Data Cloud 统一 API，你可以使用 cURL 快速调用 Seedream，实现文生图、图片编辑、多种分辨率、水印控制等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- 安装了 cURL 的终端环境

## 基础用法

调用 Seedream API 的主端点为：

```
POST https://api.acedata.cloud/seedream/images
```

本示例使用 `doubao-seedream-4-0-250828` 模型。
可用模型包括：`doubao-seedream-4-5-251128`、`doubao-seedream-4-0-250828`、`doubao-seedream-3-0-t2i-250415`、`doubao-seededit-3-0-i2i-250628`。

完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}'
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应示例

成功调用后返回 JSON 格式数据，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 处理响应

推荐使用 jq 工具格式化输出：

```bash
curl -s -X POST https://api.acedata.cloud/seedream/images \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "一只白色的暹罗猫坐在窗台上", "model": "doubao-seedream-4-0-250828", "size": "1K"}' | jq .
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
