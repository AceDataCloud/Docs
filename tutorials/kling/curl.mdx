Test the **Kling API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "kling-v2", "prompt": "A drone shot flying over a mountain range at dawn"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/kling/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "kling-v2", "prompt": "A drone shot flying over a mountain range at dawn", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Kling service
3. Create a credential and copy the token
