Test the **Seedance API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-5-pro-251215", "content": [{"type": "text", "text": "A dancer performing contemporary ballet"}]}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/seedance/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "doubao-seedance-1-5-pro-251215", "content": [{"type": "text", "text": "A dancer performing contemporary ballet"}], "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Seedance service
3. Create a credential and copy the token
