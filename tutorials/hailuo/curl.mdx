## 简介

Hailuo 是 Ace Data Cloud 提供的AI 视频服务，MiniMax 海螺视频生成模型。通过 Ace Data Cloud 统一 API，你可以使用 cURL 快速调用 Hailuo，实现文生视频、图生视频、导演模式等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- 安装了 cURL 的终端环境

## 基础用法

调用 Hailuo API 的主端点为：

```
POST https://api.acedata.cloud/hailuo/videos
```

本示例使用 `minimax-t2v` 模型。
可用模型包括：`minimax-i2v`、`minimax-t2v`、`minimax-i2v-director`。

完整 cURL 命令示例：

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}'
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应示例

成功调用后返回 JSON 格式数据，例如：

```json
{
  "status": "success",
  "data": {
    ...
  }
}
```

## 使用 jq 处理响应

推荐使用 jq 工具格式化输出：

```bash
curl -s -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"action": "generate", "model": "minimax-t2v", "prompt": "A golden sunset over the ocean waves"}' | jq .
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
