Test the **Hailuo (MiniMax) API** directly from your terminal — no SDK needed.

## Basic request

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "T2V-01-Director", "prompt": "A child running through a field of sunflowers, slow motion"}'
```

## With webhook callback

```bash
curl -X POST https://api.acedata.cloud/hailuo/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "T2V-01-Director", "prompt": "A child running through a field of sunflowers, slow motion", "callback_url": "https://your-server.com/webhook"}'
```

## Get your API key

1. Sign up at [platform.acedata.cloud](https://platform.acedata.cloud)
2. Subscribe to the Hailuo (MiniMax) service
3. Create a credential and copy the token
