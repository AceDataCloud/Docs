## 简介

Hailuo 是 Ace Data Cloud 提供的AI 视频服务，MiniMax 海螺视频生成模型。通过 Ace Data Cloud 统一 API，你可以使用 JavaScript 快速集成 Hailuo，实现文生视频、图生视频、导演模式等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- Node.js 18+ 或现代浏览器环境

## 基础用法

调用 Hailuo API 的主端点为：

```
POST https://api.acedata.cloud/hailuo/videos
```

本示例使用 `minimax-t2v` 模型。
可用模型包括：`minimax-i2v`、`minimax-t2v`、`minimax-i2v-director`。

完整 JavaScript 代码示例：

```javascript
const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
  method: "POST",
  headers: {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "action": "generate",
  "model": "minimax-t2v",
  "prompt": "A golden sunset over the ocean waves"
}),
});

const result = await response.json();
console.log(result);
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应处理

建议检查响应状态码并处理错误：

```javascript
if (response.ok) {
  const result = await response.json();
  console.log("调用成功:", result);
} else {
  console.error(`调用失败，状态码: ${response.status}`);
  const error = await response.text();
  console.error(error);
}
```

## Node.js 封装

推荐封装为可复用函数：

```javascript
async function callHailuo(data) {
  const response = await fetch("https://api.acedata.cloud/hailuo/videos", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.ACE_API_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(data),
  });
  if (!response.ok) throw new Error(`API error: ${response.status}`);
  return response.json();
}
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
