This tutorial shows you how to use the **OpenAI GPT API** with Python through Ace Data Cloud's unified API platform.

## What you'll build

By the end of this tutorial, you'll have a working Python script that calls the OpenAI GPT API. Key capabilities:

- streaming
- vision
- function calling
- JSON mode
- image generation

## Prerequisites

- Python 3.8+
- An [Ace Data Cloud API key](https://platform.acedata.cloud) (free trial available)
- `requests` library (`pip install requests`)

## Step 2: Make your first request

```python
import requests

API_KEY = "YOUR_API_KEY"
BASE_URL = "https://api.acedata.cloud"

response = requests.post(
    f"{BASE_URL}/v1/chat/completions",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
  "model": "gpt-4o",
  "messages": [
    {
      "role": "user",
      "content": "Explain quantum computing in simple terms."
    }
  ]
},
)

data = response.json()
print(data)
```

## Step 3: Handle the response

The API returns a JSON response. Here's how to parse it:

```python
if response.status_code == 200:
    result = response.json()
    print("Success:", result)
elif response.status_code == 401:
    print("Error: Invalid API key")
elif response.status_code == 429:
    print("Error: Rate limit exceeded, try again later")
else:
    print(f"Error {response.status_code}:", response.text)
```

## Step 4: Streaming (real-time response)

For chat models, you can stream responses token by token:

```python
import requests

response = requests.post(
    f"{BASE_URL}/v1/chat/completions",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
        "Accept": "text/event-stream",
    },
    json={
        "model": "gpt-4o",
        "messages": [{"role": "user", "content": "Tell me a story"}],
        "stream": True,
    },
    stream=True,
)

for line in response.iter_lines():
    if line:
        decoded = line.decode("utf-8")
        if decoded.startswith("data: ") and decoded != "data: [DONE]":
            print(decoded[6:], end="", flush=True)
```

## Error handling

| Status code | Meaning | What to do |
|---|---|---|
| 200 | Success | Parse the response |
| 400 | Bad request | Check your request parameters |
| 401 | Unauthorized | Verify your API key |
| 403 | Forbidden | Content may violate usage policies |
| 429 | Rate limited | Wait and retry with exponential backoff |
| 500 | Server error | Retry after a short delay |
