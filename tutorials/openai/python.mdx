## 简介

OpenAI 是 Ace Data Cloud 提供的AI 聊天服务，OpenAI GPT 系列大语言模型。通过 Ace Data Cloud 统一 API，你可以使用 Python 快速集成 OpenAI，实现多轮对话、系统提示词、流式输出、JSON 输出模式、文本嵌入、图像生成等功能。

## 前置条件

- 拥有 [Ace Data Cloud](https://platform.acedata.cloud) 账号并获取 API Token
- Python 3.7 及以上环境
- 安装 requests 库：`pip install requests`

## 基础用法

调用 OpenAI API 的主端点为：

```
POST https://api.acedata.cloud/openai/chat/completions
```

本示例使用 `gpt-4o` 模型。
可用模型包括：`gpt-4o`、`gpt-4o-mini`、`o1`、`o3-mini`。

完整 Python 代码示例：

```python
import requests

url = "https://api.acedata.cloud/openai/chat/completions"
headers = {
    "Authorization": "Bearer YOUR_API_TOKEN",
    "Content-Type": "application/json"
}
data = {
    "model": "gpt-4o",
    "messages": [
        {
            "role": "user",
            "content": "你好，请介绍一下你自己"
        }
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result)
```

请将 `YOUR_API_TOKEN` 替换为你在 Ace Data Cloud 平台获取的实际 Token。

## 响应处理

成功调用后，API 返回 JSON 格式数据。建议检查 HTTP 状态码：

```python
if response.status_code == 200:
    result = response.json()
    print("调用成功:", result)
else:
    print(f"调用失败，状态码: {response.status_code}")
    print(response.text)
```

## 进阶用法

对于聊天类 API，支持流式输出以获取实时响应：

```python
import requests

data['stream'] = True
response = requests.post(url, headers=headers, json=data, stream=True)
for line in response.iter_lines():
    if line:
        print(line.decode())
```

## 错误处理

常见错误码：

| 状态码 | 说明 |
|--------|------|
| 401 | 认证失败，请检查 API Token |
| 403 | 余额不足或无权访问 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误 |
