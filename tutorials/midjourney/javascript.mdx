This tutorial shows you how to call the **Midjourney API** from JavaScript (Node.js or browser) using Ace Data Cloud.

## What you'll learn

- text-to-image
- upscale
- variation
- in-painting
- blending
- async/webhook

## Prerequisites

- Node.js 18+ (for server-side) or a modern browser
- An [Ace Data Cloud API key](https://platform.acedata.cloud) (free trial available)

## Quick start

### Using fetch (Node.js 18+ / Browser)

```javascript
const API_KEY = "YOUR_API_KEY";
const BASE_URL = "https://api.acedata.cloud";

const response = await fetch(`${BASE_URL}/midjourney/imagine`, {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
  "prompt": "A futuristic city at sunset, cyberpunk style --ar 16:9",
  "mode": "fast"
}),
});

const data = await response.json();
console.log(data);
```

### Async processing

```javascript
// Submit task and poll for results
const task = await response.json();
console.log("Task submitted:", task.task_id);
// Use callback_url for webhook delivery, or poll the tasks endpoint
```

## Error handling

```javascript
if (!response.ok) {
  const error = await response.json();
  switch (response.status) {
    case 401: console.error("Invalid API key"); break;
    case 429: console.error("Rate limited — retry later"); break;
    default: console.error(`Error ${response.status}:`, error);
  }
}
```
