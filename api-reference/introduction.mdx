## 基础 URL

所有 API 端点的基础地址：

```
https://api.acedata.cloud
```

## 认证

所有端点需要 Bearer Token 认证：

```
Authorization: Bearer YOUR_API_TOKEN
```

## 在线测试

本参考文档中的每个端点都包含交互式沙盒。输入 API Token 即可直接在浏览器中测试请求。

<Note>
  在 [platform.acedata.cloud](https://platform.acedata.cloud) 获取 API Token。
</Note>
